## **Introduction**

Format shapes in PowerPoint by adjusting their outlines, fills, and effects. Aspose.Slides for .NET lets you control these settings programmatically, including transparency, rotation, and 3D formatting.

![Shape formatting options in PowerPoint](/net/slides/images/f0bff1f0c7934717-format-shape-powerpoint.png)

Aspose.Slides for .NET provides interfaces and properties that allow you to format shapes using the same options available in PowerPoint.

## **Format Lines**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ishape/lineformat/" target="_blank" rel="nofollow noopener noreferrer">IShape.LineFormat</a> to control a shape's outline. This example creates an unfilled rectangle with a blue, dashed outline. <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/style/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.Style</a> selects a thick-thin compound line, while <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/width/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.Width</a> sets its width to 7 points and <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/dashstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.DashStyle</a> selects the dash pattern.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 150, 75);
shape.FillFormat.FillType = FillType.NoFill;
shape.LineFormat.Style = LineStyle.ThickThin;
shape.LineFormat.Width = 7;
shape.LineFormat.DashStyle = LineDashStyle.Dash;
shape.LineFormat.FillFormat.FillType = FillType.Solid;
shape.LineFormat.FillFormat.SolidFillColor.Color = Color.Blue;

presentation.Save("formatted_lines.pptx", SaveFormat.Pptx);
```

### **Set Custom Line Dash Patterns**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/customdashpattern/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.CustomDashPattern</a> when predefined line styles do not provide the dash lengths and gaps you need, for example for branded outlines or technical diagrams. Assigning a pattern automatically sets <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/dashstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.DashStyle</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/linedashstyle/" target="_blank" rel="nofollow noopener noreferrer">LineDashStyle.Custom</a>.

Array entries alternate between dash and gap lengths, starting with a dash. Each value is a multiple of the line width: `{ 4, 2 }` at a width of 3 points produces a 12-point dash followed by a 6-point gap. Use pairs of finite, nonnegative values to define complete dash-and-gap segments. The example uses positive values to keep every dash and gap visible.

This example creates five blue lines with the same length and flat caps. The first three compare patterns at a width of 3 points. The fourth repeats the first pattern at twice the width, doubling both the dash and gap lengths. The fifth switches from a custom pattern to a solid line.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(600, 300, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var patterns = new[]
{
    new float[] { 4, 2 },
    new float[] { 1, 2 },
    new float[] { 6, 2, 1, 2 },
    new float[] { 4, 2 },
    new float[] { 4, 2 }
};

for (var i = 0; i < patterns.Length; i++)
{
    var line = slide.Shapes.AddAutoShape(ShapeType.Line, 50, 50 + i * 50, 500, 0);
    line.LineFormat.Width = i == 3 ? 6 : 3;
    line.LineFormat.FillFormat.FillType = FillType.Solid;
    line.LineFormat.FillFormat.SolidFillColor.Color = Color.DarkBlue;
    line.LineFormat.CapStyle = LineCapStyle.Flat;
    line.LineFormat.BeginArrowheadStyle = LineArrowheadStyle.None;
    line.LineFormat.EndArrowheadStyle = LineArrowheadStyle.None;
    line.LineFormat.CustomDashPattern = patterns[i];
}

// Return the last line to a solid style.
slide.Shapes[4].LineFormat.DashStyle = LineDashStyle.Solid;

presentation.Save("custom_dash_patterns.pptx", SaveFormat.Pptx);
```

To return to a predefined dashed style instead, assign <a href="https://reference.aspose.com/slides/net/aspose.slides/linedashstyle/" target="_blank" rel="nofollow noopener noreferrer">LineDashStyle.Dash</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/dashstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.DashStyle</a>. The selected style controls the line's appearance.

The result in PowerPoint, from top to bottom: **\{4, 2\}, 3 pt**; **\{1, 2\}, 3 pt**; **\{6, 2, 1, 2\}, 3 pt**; **\{4, 2\}, 6 pt**; and **Solid, 3 pt**.

![Three custom dash patterns, a wider line using the first pattern, and a solid line in PowerPoint](/net/slides/images/982aaf435dab3653-custom-dash-patterns.png)

### **Set Line Caps**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/capstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.CapStyle</a> to set the ends of an open line. The <a href="https://reference.aspose.com/slides/net/aspose.slides/linecapstyle/" target="_blank" rel="nofollow noopener noreferrer">LineCapStyle</a> enumeration provides three explicit cap styles:

- `Flat`: The stroke stops at the endpoint.
- `Round`: A semicircular cap extends beyond the endpoint by half the line width.
- `Square`: A square cap extends beyond the endpoint by half the line width.

The enumeration also includes `NotDefined`, which means that no cap style is explicitly assigned.

Caps are different from arrowheads, which add symbols to line ends, and joins, which control corners between line segments. This example disables arrowheads through <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/beginarrowheadstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.BeginArrowheadStyle</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/endarrowheadstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.EndArrowheadStyle</a> so that only the cap shapes are compared.

The following example creates three otherwise identical horizontal lines, 20 points wide. From top to bottom, they use flat, round, and square caps. Their endpoints have the same horizontal coordinates; the round and square caps extend 10 points beyond each endpoint.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(500, 240, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var capStyles = new[] { LineCapStyle.Flat, LineCapStyle.Round, LineCapStyle.Square };

for (var i = 0; i < capStyles.Length; i++)
{
    var line = slide.Shapes.AddAutoShape(ShapeType.Line, 100, 50 + i * 70, 300, 0);
    line.LineFormat.Width = 20;
    line.LineFormat.FillFormat.FillType = FillType.Solid;
    line.LineFormat.FillFormat.SolidFillColor.Color = Color.DarkBlue;
    line.LineFormat.DashStyle = LineDashStyle.Solid;
    line.LineFormat.CapStyle = capStyles[i];
    line.LineFormat.BeginArrowheadStyle = LineArrowheadStyle.None;
    line.LineFormat.EndArrowheadStyle = LineArrowheadStyle.None;
}

presentation.Save("line_caps.pptx", SaveFormat.Pptx);
```

The result in PowerPoint, from top to bottom: **Flat**, **Round**, and **Square**.

![Flat, round, and square caps on identical thick lines in PowerPoint](/net/slides/images/ffc91ee0bc9a2b3c-line-caps.png)

## **Apply Sketch Effects to Shape Lines**

A sketch effect makes a shape line look hand-drawn. Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ishape/lineformat/" target="_blank" rel="nofollow noopener noreferrer">IShape.LineFormat</a> to access the line settings, <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/sketchformat/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.SketchFormat</a> to access the sketch settings, and <a href="https://reference.aspose.com/slides/net/aspose.slides/isketchformat/sketchtype/" target="_blank" rel="nofollow noopener noreferrer">ISketchFormat.SketchType</a> to select a value from the <a href="https://reference.aspose.com/slides/net/aspose.slides/linesketchtype/" target="_blank" rel="nofollow noopener noreferrer">LineSketchType</a> enumeration.

The following C# code shows how to apply a <a href="https://reference.aspose.com/slides/net/aspose.slides/linesketchtype/" target="_blank" rel="nofollow noopener noreferrer">LineSketchType.Curved</a> effect, read the explicitly assigned value, and remove the effect with <a href="https://reference.aspose.com/slides/net/aspose.slides/linesketchtype/" target="_blank" rel="nofollow noopener noreferrer">LineSketchType.None</a>:

```csharp
using System;
using Aspose.Slides;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 200, 100);

var sketchFormat = shape.LineFormat.SketchFormat;
sketchFormat.SketchType = LineSketchType.Curved;
var explicitSketchType = sketchFormat.SketchType;
Console.WriteLine($"Explicit sketch type: {explicitSketchType}");
sketchFormat.SketchType = LineSketchType.None;
```

The value returned by <a href="https://reference.aspose.com/slides/net/aspose.slides/isketchformat/sketchtype/" target="_blank" rel="nofollow noopener noreferrer">ISketchFormat.SketchType</a> represents the setting assigned directly to the shape. If the line formatting can be inherited from a theme, master slide, or layout slide, use <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/geteffective/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.GetEffective</a>, access <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformateffectivedata/sketchformat/" target="_blank" rel="nofollow noopener noreferrer">ILineFormatEffectiveData.SketchFormat</a>, and read <a href="https://reference.aspose.com/slides/net/aspose.slides/isketchformateffectivedata/sketchtype/" target="_blank" rel="nofollow noopener noreferrer">ISketchFormatEffectiveData.SketchType</a>. The effective value reflects the formatting that is actually applied after inheritance is resolved. This example requires an existing presentation with at least one shape on its first slide and prints both values:

```csharp
using System;
using Aspose.Slides;

using var presentation = new Presentation("presentation.pptx");
var shape = presentation.Slides[0].Shapes[0];

var lineFormat = shape.LineFormat;
var explicitSketchType = lineFormat.SketchFormat.SketchType;
var effectiveLineFormat = lineFormat.GetEffective();
var effectiveSketchType = effectiveLineFormat.SketchFormat.SketchType;

Console.WriteLine($"Explicit sketch type: {explicitSketchType}");
Console.WriteLine($"Effective sketch type: {effectiveSketchType}");
```

## **Format Join Styles**

Here are the three join type options:

- Round
- Miter
- Bevel

The join style controls how two outline segments meet at a corner. Use **Round** for rounded corners, **Miter** for sharp corners, or **Bevel** for flattened corners.

![The join style in the presentation](/net/slides/images/22f48c1b06de9438-join-style-powerpoint.png)

This example creates three black rectangles with blue outlines 15 points wide. It sets <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/joinstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.JoinStyle</a> to the miter, bevel, and round values of <a href="https://reference.aspose.com/slides/net/aspose.slides/linejoinstyle/" target="_blank" rel="nofollow noopener noreferrer">LineJoinStyle</a>, respectively, to compare how the corners are drawn.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var miterShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 150, 75);
var bevelShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 210, 20, 150, 75);
var roundShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 135, 150, 75);

miterShape.FillFormat.FillType = FillType.Solid;
miterShape.FillFormat.SolidFillColor.Color = Color.Black;
bevelShape.FillFormat.FillType = FillType.Solid;
bevelShape.FillFormat.SolidFillColor.Color = Color.Black;
roundShape.FillFormat.FillType = FillType.Solid;
roundShape.FillFormat.SolidFillColor.Color = Color.Black;

miterShape.LineFormat.Width = 15;
bevelShape.LineFormat.Width = 15;
roundShape.LineFormat.Width = 15;

miterShape.LineFormat.FillFormat.FillType = FillType.Solid;
miterShape.LineFormat.FillFormat.SolidFillColor.Color = Color.Blue;
bevelShape.LineFormat.FillFormat.FillType = FillType.Solid;
bevelShape.LineFormat.FillFormat.SolidFillColor.Color = Color.Blue;
roundShape.LineFormat.FillFormat.FillType = FillType.Solid;
roundShape.LineFormat.FillFormat.SolidFillColor.Color = Color.Blue;

miterShape.LineFormat.JoinStyle = LineJoinStyle.Miter;
bevelShape.LineFormat.JoinStyle = LineJoinStyle.Bevel;
roundShape.LineFormat.JoinStyle = LineJoinStyle.Round;

miterShape.TextFrame.Text = "Miter Join Style";
bevelShape.TextFrame.Text = "Bevel Join Style";
roundShape.TextFrame.Text = "Round Join Style";

presentation.Save("join_styles.pptx", SaveFormat.Pptx);
```

### **Limit Miter Joins at Sharp Corners**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/miterlimit/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.MiterLimit</a> with <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/joinstyle/" target="_blank" rel="nofollow noopener noreferrer">ILineFormat.JoinStyle</a> set to <a href="https://reference.aspose.com/slides/net/aspose.slides/linejoinstyle/" target="_blank" rel="nofollow noopener noreferrer">LineJoinStyle.Miter</a> to limit how far a sharp corner can extend.

The limit is a ratio of the distance between the inner and outer corners of the join to the line width. For example, a value of `8` permits a miter length of up to eight times the line width; it is not a measurement in points. If the corner would exceed the limit, PowerPoint uses a beveled join at that corner. A larger limit allows sharper points. The setting affects miter joins only, and changing it has no visible effect when the corner remains within both limits.

This example creates two identical, unfilled triangles with outlines 20 points wide. The left triangle uses a limit of `2`, and the right uses `8`. Each triangle is 80 points wide and 160 points high, giving its top corner a miter-length-to-line-width ratio of approximately `4.12`. Consequently, PowerPoint bevels the left apex and preserves the right apex.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(500, 320, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var miterLimits = new[] { 2f, 8f };

for (var i = 0; i < miterLimits.Length; i++)
{
    var triangle = slide.Shapes.AddAutoShape(ShapeType.Triangle, 90 + i * 240, 110, 80, 160);
    triangle.FillFormat.FillType = FillType.NoFill;
    triangle.LineFormat.Width = 20;
    triangle.LineFormat.FillFormat.FillType = FillType.Solid;
    triangle.LineFormat.FillFormat.SolidFillColor.Color = Color.DarkBlue;
    triangle.LineFormat.JoinStyle = LineJoinStyle.Miter;
    triangle.LineFormat.MiterLimit = miterLimits[i];
}

presentation.Save("miter_limits.pptx", SaveFormat.Pptx);
```

The result in PowerPoint: **Miter limit 2** on the left and **miter limit 8** on the right.

![A beveled apex with miter limit 2 and a pointed apex with miter limit 8 in PowerPoint](/net/slides/images/083d6a4d86173367-miter-limits.png)

## **Gradient Fill**

A gradient fill blends colors across a shape. This example fills an ellipse with a linear gradient at a 45-degree angle from red to purple using <a href="https://reference.aspose.com/slides/net/aspose.slides/ifillformat/gradientformat/" target="_blank" rel="nofollow noopener noreferrer">IFillFormat.GradientFormat</a>. The <a href="https://reference.aspose.com/slides/net/aspose.slides/igradientstopcollection/add/" target="_blank" rel="nofollow noopener noreferrer">IGradientStopCollection.Add</a> method places the color stops at 0 and 1, the beginning and end of the gradient. Clearing the existing stops ensures that only these two colors are used.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Ellipse, 50, 50, 150, 75);
shape.FillFormat.FillType = FillType.Gradient;
shape.FillFormat.GradientFormat.GradientShape = GradientShape.Linear;
shape.FillFormat.GradientFormat.LinearGradientAngle = 45;
shape.FillFormat.GradientFormat.GradientStops.Clear();
shape.FillFormat.GradientFormat.GradientStops.Add(1.0f, PresetColor.Purple);
shape.FillFormat.GradientFormat.GradientStops.Add(0.0f, PresetColor.Red);

presentation.Save("gradient_fill.pptx", SaveFormat.Pptx);
```

The result:

![The ellipse with gradient fill](/net/slides/images/f052a4cf8f7864b2-gradient-fill.png)

If a gradient looks different in an exported image than it does in PowerPoint, see [Choose a Gradient Rendering Style](/net/slides/convert-powerpoint-to-png/#choose-a-gradient-rendering-style). You can select a rendering style without changing the gradient fill stored in the presentation.

### **Set the Linear Gradient Angle**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/igradientformat/lineargradientangle/" target="_blank" rel="nofollow noopener noreferrer">IGradientFormat.LinearGradientAngle</a> to control the orientation of a <a href="https://reference.aspose.com/slides/net/aspose.slides/gradientshape/" target="_blank" rel="nofollow noopener noreferrer">GradientShape.Linear</a> fill. The angle is measured in degrees and increases clockwise: `0` runs from left to right, `90` from top to bottom, `180` from right to left, and `270` from bottom to top. Fractional angles are supported. Finite angles outside `[0, 360)` are normalized to one revolution; for example, `-45` becomes `315` and `360` becomes `0`.

This example creates six rectangles with identical red, green, and blue stops at positions `0`, `0.5`, and `1`. Scaling is disabled so that the angle can be compared independently of the rectangles' proportions. The angles, from left to right, are `0`, `45`, and `90` in the first row, and `135`, `180`, and `270` in the second row.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(720, 400, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var angles = new float[] { 0, 45, 90, 135, 180, 270 };

for (var i = 0; i < angles.Length; i++)
{
    var x = 30 + (i % 3) * 230;
    var y = 30 + (i / 3) * 190;

    var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, x, y, 200, 150);
    shape.LineFormat.FillFormat.FillType = FillType.NoFill;
    shape.FillFormat.FillType = FillType.Gradient;

    var gradient = shape.FillFormat.GradientFormat;
    gradient.GradientShape = GradientShape.Linear;
    gradient.GradientStops.Clear();
    gradient.GradientStops.Add(0f, Color.Red);
    gradient.GradientStops.Add(0.5f, Color.Lime);
    gradient.GradientStops.Add(1f, Color.Blue);
    gradient.LinearGradientScaled = NullableBool.False;
    gradient.LinearGradientAngle = angles[i];
}

presentation.Save("linear_gradient_angles.pptx", SaveFormat.Pptx);
```

The result in PowerPoint:

![Linear gradients at 0, 45, and 90 degrees in the top row, and 135, 180, and 270 degrees in the bottom row](/net/slides/images/bfd7db60cc62785f-linear-gradient-angles.png)

### **Scale a Linear Gradient with the Shape**

<a href="https://reference.aspose.com/slides/net/aspose.slides/igradientformat/lineargradientscaled/" target="_blank" rel="nofollow noopener noreferrer">IGradientFormat.LinearGradientScaled</a> accepts a <a href="https://reference.aspose.com/slides/net/aspose.slides/nullablebool/" target="_blank" rel="nofollow noopener noreferrer">NullableBool</a> value. Set it explicitly to `False` to keep the geometric gradient angle as the shape's proportions change, or to `True` to scale the gradient with the shape's width and height. With scaling enabled, the visible angle can differ from the assigned angle on a non-square shape.

The following example uses a `45`-degree angle and the same color stops as the angle comparison. The left column uses `False`; the right column uses `True`. Each column contains a wide rectangle above a tall rectangle. Both start with the same wide dimensions; changing the second rectangle's width and height demonstrates how the fill responds to resizing without changing its gradient settings.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(720, 460, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var scalingOptions = new[] { NullableBool.False, NullableBool.True };

for (var column = 0; column < scalingOptions.Length; column++)
{
    for (var row = 0; row < 2; row++)
    {
        var x = 30 + column * 360;
        var y = row == 0 ? 30 : 150;
        
        var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, x, y, 300, 90);
        shape.LineFormat.FillFormat.FillType = FillType.NoFill;
        shape.FillFormat.FillType = FillType.Gradient;

        var gradient = shape.FillFormat.GradientFormat;
        gradient.GradientShape = GradientShape.Linear;
        gradient.GradientStops.Clear();
        gradient.GradientStops.Add(0f, Color.Red);
        gradient.GradientStops.Add(0.5f, Color.Lime);
        gradient.GradientStops.Add(1f, Color.Blue);
        gradient.LinearGradientAngle = 45;
        gradient.LinearGradientScaled = scalingOptions[column];

        if (row == 1)
        {
            shape.Width = 90;
            shape.Height = 280;
        }
    }
}

presentation.Save("linear_gradient_scaling.pptx", SaveFormat.Pptx);
```

The result in PowerPoint, with scaling disabled on the left and enabled on the right:

![Wide and tall rectangles with a 45-degree gradient, comparing LinearGradientScaled False on the left with True on the right](/net/slides/images/7db22ced6f457333-linear-gradient-scaling.png)

With scaling disabled, the diagonal color bands keep the same orientation in both rectangles. With scaling enabled, the bands stretch with the shape's proportions. This helps reproduce a template's gradient when adapting a shape to a different size. On a square, enabling scaling does not change the appearance of this `45`-degree gradient.

Both the angle and scaling settings apply to linear gradients. They do not control <a href="https://reference.aspose.com/slides/net/aspose.slides/gradientshape/" target="_blank" rel="nofollow noopener noreferrer">GradientShape.Radial or GradientShape.Rectangle</a> fills.

### **Combine the Angle with Gradient Direction**

<a href="https://reference.aspose.com/slides/net/aspose.slides/igradientformat/gradientdirection/" target="_blank" rel="nofollow noopener noreferrer">IGradientFormat.GradientDirection</a> selects a gradient style from the <a href="https://reference.aspose.com/slides/net/aspose.slides/gradientdirection/" target="_blank" rel="nofollow noopener noreferrer">GradientDirection</a> enumeration; it is not a substitute for a numeric angle. For a linear gradient, the corner styles can change the area over which the colors are distributed without changing <a href="https://reference.aspose.com/slides/net/aspose.slides/igradientformat/lineargradientangle/" target="_blank" rel="nofollow noopener noreferrer">LinearGradientAngle</a>. Keep the direction unchanged when comparing angles or scaling.

The following example applies the same settings in opposite orders. The two rectangles have the same appearance: assigning the direction before or after the angle does not change the result.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

for (var i = 0; i < 2; i++)
{
    var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 30, 30 + i * 140, 320, 100);
    shape.LineFormat.FillFormat.FillType = FillType.NoFill;
    shape.FillFormat.FillType = FillType.Gradient;

    var gradient = shape.FillFormat.GradientFormat;
    gradient.GradientShape = GradientShape.Linear;
    gradient.GradientStops.Clear();
    gradient.GradientStops.Add(0f, Color.Red);
    gradient.GradientStops.Add(0.5f, Color.Lime);
    gradient.GradientStops.Add(1f, Color.Blue);
    gradient.LinearGradientScaled = NullableBool.True;

    if (i == 0)
    {
        gradient.GradientDirection = GradientDirection.FromCorner1;
        gradient.LinearGradientAngle = 30;
    }
    else
    {
        gradient.LinearGradientAngle = 30;
        gradient.GradientDirection = GradientDirection.FromCorner1;
    }
}

presentation.Save("linear_gradient_direction.pptx", SaveFormat.Pptx);
```

### **Tile Picture As Texture**

If you want to set a tiled picture as a texture and customize the tiling behavior, you can use the following properties of the <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/" target="_blank" rel="nofollow noopener noreferrer">IPictureFillFormat</a> interface and <a href="https://reference.aspose.com/slides/net/aspose.slides/picturefillformat/" target="_blank" rel="nofollow noopener noreferrer">PictureFillFormat</a> class:

- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/picturefillmode/" target="_blank" rel="nofollow noopener noreferrer">PictureFillMode</a>: Sets the picture fill mode-either `Tile` or `Stretch`.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tilealignment/" target="_blank" rel="nofollow noopener noreferrer">TileAlignment</a>: Specifies the alignment of the tiles within the shape.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tileflip/" target="_blank" rel="nofollow noopener noreferrer">TileFlip</a>: Controls whether the tile is flipped horizontally, vertically, or both.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tileoffsetx/" target="_blank" rel="nofollow noopener noreferrer">TileOffsetX</a>: Sets the horizontal offset of the tile (in points) from the shape's origin.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tileoffsety/" target="_blank" rel="nofollow noopener noreferrer">TileOffsetY</a>: Sets the vertical offset of the tile (in points) from the shape's origin.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tilescalex/" target="_blank" rel="nofollow noopener noreferrer">TileScaleX</a>: Defines the horizontal scale of the tile as a percentage.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/tilescaley/" target="_blank" rel="nofollow noopener noreferrer">TileScaleY</a>: Defines the vertical scale of the tile as a percentage.

This example requires a local image and configures <a href="https://reference.aspose.com/slides/net/aspose.slides/ipicturefillformat/" target="_blank" rel="nofollow noopener noreferrer">IPictureFillFormat</a> to repeat it at 50% of its original size. Offsets of −32 points shift the tiles horizontally and vertically; bottom-right alignment and flipping in both directions determine how the repeated texture is arranged.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var firstSlide = presentation.Slides[0];

var shape = firstSlide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 190, 95);

pictureFillFormat.Picture.Image = presentationImage;
pictureFillFormat.PictureFillMode = PictureFillMode.Tile;
pictureFillFormat.TileOffsetX = -32;
pictureFillFormat.TileOffsetY = -32;
pictureFillFormat.TileScaleX = 50;
pictureFillFormat.TileScaleY = 50;
pictureFillFormat.TileAlignment = RectangleAlignment.BottomRight;
pictureFillFormat.TileFlip = TileFlip.FlipBoth;

presentation.Save("tile.pptx", SaveFormat.Pptx);
```

### **Copy Colors While Preserving Theme References**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/icolorformat/copyfrom/" target="_blank" rel="nofollow noopener noreferrer">IColorFormat.CopyFrom</a> to copy a color definition, including its color type, theme reference, and transformations. This is useful when transferring a fill color between shapes that should continue to follow the presentation theme. The method copies only the color: it does not copy the fill type, outline, or other shape formatting. Set the destination's <a href="https://reference.aspose.com/slides/net/aspose.slides/ifillformat/filltype/" target="_blank" rel="nofollow noopener noreferrer">IFillFormat.FillType</a> explicitly.

This example creates three rectangles, from left to right: the source, a theme-aware copy, and a fixed RGB copy. The source uses <a href="https://reference.aspose.com/slides/net/aspose.slides/icolorformat/schemecolor/" target="_blank" rel="nofollow noopener noreferrer">IColorFormat.SchemeColor</a> to reference the first accent color and adds a tint through <a href="https://reference.aspose.com/slides/net/aspose.slides/icoloroperationcollection/add/" target="_blank" rel="nofollow noopener noreferrer">IColorOperationCollection.Add</a>. The RGB copy uses the source's effective fill color so all three initially look identical. Assigning <a href="https://reference.aspose.com/slides/net/aspose.slides/icolorformat/color/" target="_blank" rel="nofollow noopener noreferrer">IColorFormat.Color</a> sets a fixed RGB value and clears any existing color transformations.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(660, 220, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

presentation.MasterTheme.ColorScheme.Accent1.Color = Color.RoyalBlue;

var source = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 30, 40, 180, 140);
var themeCopy = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 240, 40, 180, 140);
var rgbCopy = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 450, 40, 180, 140);

foreach (var shape in new[] { source, themeCopy, rgbCopy })
{
    shape.FillFormat.FillType = FillType.Solid;
    shape.LineFormat.FillFormat.FillType = FillType.NoFill;
}

var sourceColor = source.FillFormat.SolidFillColor;
sourceColor.SchemeColor = SchemeColor.Accent1;
sourceColor.ColorTransform.Add(ColorTransformOperation.Tint, 0.75f);

themeCopy.FillFormat.SolidFillColor.CopyFrom(sourceColor);
rgbCopy.FillFormat.SolidFillColor.Color = source.FillFormat.GetEffective().SolidFillColor;

using var before = slide.GetImage(1f, 1f);
before.Save("color-copy-before.png", ImageFormat.Png);

// Theme references follow the new accent color; the fixed RGB value does not.
presentation.MasterTheme.ColorScheme.Accent1.Color = Color.OrangeRed;

using var after = slide.GetImage(1f, 1f);
after.Save("color-copy-after.png", ImageFormat.Png);
presentation.Save("copied_colors.pptx", SaveFormat.Pptx);
```

Before the theme change, all three fills match:

![Source, CopyFrom destination, and fixed RGB destination with identical blue fills](/net/slides/images/d4d806157c194a40-color-copy-before.png)

After the theme change, the source and the theme-aware copy follow the new accent color and retain their tint. The fixed RGB copy remains blue:

![Source and CopyFrom destination with orange fills, while the fixed RGB destination remains blue](/net/slides/images/e9085b8885ed897e-color-copy-after.png)

The copied definition is independent of the source. Subsequently changing the source's theme reference, assigning another color, or adding or removing its transformations does not change the destination. A theme change still affects both shapes because each independently refers to the same theme color.

Saving and reopening the PPTX preserves the copied color's <a href="https://reference.aspose.com/slides/net/aspose.slides/icolorformat/colortype/" target="_blank" rel="nofollow noopener noreferrer">IColorFormat.ColorType</a>, theme reference, and <a href="https://reference.aspose.com/slides/net/aspose.slides/icolorformat/colortransform/" target="_blank" rel="nofollow noopener noreferrer">IColorFormat.ColorTransform</a> collection; it does not flatten the definition to RGB.

When copying between different theme contexts, such as presentations with different accent palettes, the copied reference resolves against the destination's theme. The same reference and transformations can therefore produce a different visible color. See [Presentation Theme](/net/slides/presentation-theme/) for more about configuring theme colors.

## **Use the Slide Background as a Shape Fill**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/iautoshape/usebackgroundfill/" target="_blank" rel="nofollow noopener noreferrer">IAutoShape.UseBackgroundFill</a> when a shape should match the slide background, for example in a presentation template. Set <a href="https://reference.aspose.com/slides/net/aspose.slides/ifillformat/filltype/" target="_blank" rel="nofollow noopener noreferrer">IFillFormat.FillType</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/filltype/" target="_blank" rel="nofollow noopener noreferrer">FillType.NotDefined</a> first to remove any explicit fill. With this combination, the shape uses the slide background instead of its style fill. Enabling the flag alone does not remove an existing explicit fill.

This differs from <a href="https://reference.aspose.com/slides/net/aspose.slides/filltype/" target="_blank" rel="nofollow noopener noreferrer">FillType.NoFill</a>: background fill covers objects behind the shape with the corresponding area of the slide background, while no fill leaves those objects visible. A gradient remains aligned with the slide rather than restarting inside each shape.

The following example creates a master background inherited by the slide and places a magenta band behind three rectangles. The left rectangle uses the background, the middle rectangle has no fill, and the right rectangle switches from background fill to an explicit orange fill.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(720, 400, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

// Inherit the gradient from the master.
slide.Background.Type = BackgroundType.NotDefined;
slide.LayoutSlide.Background.Type = BackgroundType.NotDefined;
var background = slide.LayoutSlide.MasterSlide.Background;
background.Type = BackgroundType.OwnBackground;
background.FillFormat.FillType = FillType.Gradient;
var gradient = background.FillFormat.GradientFormat;
gradient.GradientShape = GradientShape.Linear;
gradient.LinearGradientAngle = 0;
gradient.GradientStops.Clear();
gradient.GradientStops.Add(0, Color.DarkBlue);
gradient.GradientStops.Add(1, Color.LightSkyBlue);

// Add this object first so it appears behind the rectangles.
var band = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 25, 150, 670, 100);
band.FillFormat.FillType = FillType.Solid;
band.FillFormat.SolidFillColor.Color = Color.Magenta;
band.LineFormat.FillFormat.FillType = FillType.NoFill;

var backgroundShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 100, 160, 200);
backgroundShape.FillFormat.FillType = FillType.NotDefined;
backgroundShape.UseBackgroundFill = true;

var noFillShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 280, 100, 160, 200);
noFillShape.FillFormat.FillType = FillType.NoFill;

var explicitShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 510, 100, 160, 200);
explicitShape.FillFormat.FillType = FillType.NotDefined;
explicitShape.UseBackgroundFill = true;

// Disable background fill before applying an explicit fill.
explicitShape.UseBackgroundFill = false;
explicitShape.FillFormat.FillType = FillType.Solid;
explicitShape.FillFormat.SolidFillColor.Color = Color.Orange;

presentation.Save("background_fill.pptx", SaveFormat.Pptx);
```

The result, from left to right: **background fill**, **no fill**, and **explicit fill**. The magenta band is hidden by the left and right rectangles but remains visible through the middle rectangle.

![Background fill, no fill, and explicit orange fill over a magenta band](/net/slides/images/94d98a131a13e202-background-fill.png)

The same behavior applies to a background defined directly on the slide or inherited from a layout. The shape uses the slide's resolved background; the example leaves both the slide and layout backgrounds undefined so the master supplies it.

## **Control Black-and-White Rendering for Shapes**

The <a href="https://reference.aspose.com/slides/net/aspose.slides/ishape/blackwhitemode/" target="_blank" rel="nofollow noopener noreferrer">IShape.BlackWhiteMode</a> property specifies how an individual shape is rendered when a presentation is viewed or processed in black-and-white mode. It does not enable black-and-white display by itself, and it does not change the shape's fill, line, or other formatting in normal color mode.

Use a value from the <a href="https://reference.aspose.com/slides/net/aspose.slides/blackwhitemode/" target="_blank" rel="nofollow noopener noreferrer">BlackWhiteMode</a> enumeration to select the desired behavior. For example, `Automatic` lets the rendering application choose the conversion, `Gray` and `LightGray` use gray coloring, `BlackWhite` uses only black and white, `Black` and `White` force a single color, `Color` preserves normal coloring, and `Hidden` omits the shape in black-and-white mode. `NotDefined` means that no shape-level mode is assigned.

This example creates an orange rectangle and sets <a href="https://reference.aspose.com/slides/net/aspose.slides/ishape/blackwhitemode/" target="_blank" rel="nofollow noopener noreferrer">IShape.BlackWhiteMode</a> to gray. The saved shape retains its orange fill for normal color display and requests gray coloring from applications that honor black-and-white display settings:

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 200, 100);
shape.FillFormat.FillType = FillType.Solid;
shape.FillFormat.SolidFillColor.Color = Color.Orange;
shape.BlackWhiteMode = BlackWhiteMode.Gray;

presentation.Save("shape_black_white_mode.pptx", SaveFormat.Pptx);
```

In normal color mode, the rectangle retains its orange fill. In a black-and-white display workflow, it uses gray coloring because its mode is set to `Gray`. This lets you preserve a full-color slide while defining a distinct appearance for printing, previewing, or other workflows that honor the presentation's black-and-white display settings.

## **FAQ**

**Does shape formatting affect the final presentation file size?**

Colors, line styles, and effect settings generally add little data compared with embedded images and media. Picture fills can increase the file size because their images are stored in the presentation.

**How can I detect shapes on a slide that share identical formatting so I can group them?**

Compare each shape's key formatting properties-fill, line, and effect settings. If all corresponding values match, treat their styles as identical and logically group those shapes, which simplifies later style management.

**Can I save a set of custom shape styles to a separate file for reuse in other presentations?**

Yes. Store sample shapes with the desired styles in a template slide deck or a .POTX template file. When creating a new presentation, open the template, clone the styled shapes you need, and reapply their formatting wherever required.

> See which file formats Aspose.Slides for .NET can load, import, save, and render, and which API reads or writes each one.

## **Overview**

Aspose.Slides for .NET opens and saves PowerPoint and OpenDocument presentations. It also imports PDF and HTML content into slides, saves presentations to document, web, and image formats, and renders individual slides and shapes as images. This article lists each supported format and names the API that reads or writes it.

Both NuGet packages, Aspose.Slides.NET and Aspose.Slides.NET6.CrossPlatform, support the same formats; see [Installation](/net/slides/installation/) to choose between them. For an overview of editing features, see [Features Overview](/net/slides/features-overview/).

## **Supported Microsoft PowerPoint Versions**

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint for Mac
- PowerPoint for Microsoft 365 (formerly Office 365)

:::info[Note]
Presentations saved by PowerPoint 95 and earlier versions cannot be opened. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a> recognizes a PowerPoint 95 file and reports `LoadFormat.Ppt95`, but the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> constructor throws <a href="https://reference.aspose.com/slides/net/aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> for it.
:::

## **Supported File Formats**

The table uses four operations:

- **Load**: the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> constructor opens the file as an editable presentation.
- **Import**: a <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection</a> method creates slides from the file's content and adds them to an existing presentation. The Presentation constructor does not load these files as presentations.
- **Save**: <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> writes the presentation to a file or stream. Every format except XAML is selected with a <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a> value.
- **Render**: a rendering method draws a slide or a shape as an image. Formats that are only rendered are not SaveFormat values.

## **Load and Import**

- **Load:** Pass a file path or a stream to the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> constructor. The format is detected from the content; <a href="https://reference.aspose.com/slides/net/aspose.slides/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> supplies settings such as a password. To check a file before opening it, call <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a>, which reports a <a href="https://reference.aspose.com/slides/net/aspose.slides/loadformat/" target="_blank" rel="nofollow noopener noreferrer">LoadFormat</a> value. It reports `LoadFormat.Unknown` for PowerPoint XML, but the constructor opens such a file, and <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/sourceformat/" target="_blank" rel="nofollow noopener noreferrer">Presentation.SourceFormat</a> then returns `SourceFormat.Xml`. See [Open Presentations](/net/slides/open-presentation/) and [Determine the Original Presentation Format](/net/slides/detect-presentation-source-format/).
- **Import:** <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.AddFromPdf</a> adds one slide per PDF page to the end of a presentation. <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.AddFromHtml</a> adds slides created from HTML, and <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/insertfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.InsertFromHtml</a> inserts them at a given position. The Presentation constructor does not import: it throws <a href="https://reference.aspose.com/slides/net/aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> for a PDF file and does not convert HTML markup into slide content. See [Import Presentations from PDF or HTML](/net/slides/import-presentation/).

## **Save and Render**

- **Save:** <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> writes the presentation in the format of a <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a> value. Overloads that also take an options object control the output, for example <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/htmloptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/html5options/" target="_blank" rel="nofollow noopener noreferrer">Html5Options</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/tiffoptions/" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides.export/gifoptions/" target="_blank" rel="nofollow noopener noreferrer">GifOptions</a>. Overloads that take an array of slide positions, starting from 1, write only those slides; they accept PDF, XPS, TIFF, HTML, HTML5, SWF, GIF, and Markdown, but not the presentation formats or PowerPoint XML. XAML has its own overload that takes <a href="https://reference.aspose.com/slides/net/aspose.slides.export.xaml/ixamloptions/" target="_blank" rel="nofollow noopener noreferrer">IXamlOptions</a>. See [Save Presentations](/net/slides/save-presentation/), [Convert Presentations](/net/slides/convert-presentation/), and [Export Presentations to XAML](/net/slides/export-to-xaml/).
- **Render:** <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/getimage/" target="_blank" rel="nofollow noopener noreferrer">Slide.GetImage</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/getimage/" target="_blank" rel="nofollow noopener noreferrer">Shape.GetImage</a> return an <a href="https://reference.aspose.com/slides/net/aspose.slides/iimage/" target="_blank" rel="nofollow noopener noreferrer">IImage</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides/iimage/save/" target="_blank" rel="nofollow noopener noreferrer">IImage.Save</a> writes it as PNG, JPEG, BMP, GIF, or TIFF, selected with an <a href="https://reference.aspose.com/slides/net/aspose.slides/imageformat/" target="_blank" rel="nofollow noopener noreferrer">ImageFormat</a> value. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/getimages/" target="_blank" rel="nofollow noopener noreferrer">Presentation.GetImages</a> renders all slides or selected slides at once. <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/writeassvg/" target="_blank" rel="nofollow noopener noreferrer">Slide.WriteAsSvg</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/writeassvg/" target="_blank" rel="nofollow noopener noreferrer">Shape.WriteAsSvg</a> write SVG, and <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/writeasemf/" target="_blank" rel="nofollow noopener noreferrer">Slide.WriteAsEmf</a> writes EMF. See [Convert Presentation Slides to Images](/net/slides/convert-slide/) and [Render a Slide as an SVG Image](/net/slides/render-a-slide-as-an-svg-image/).

:::warning[Warning]
ImageFormat also has `Emf`, `Wmf`, `Icon`, `Exif`, and `MemoryBmp` values, but IImage.Save does not produce those formats: the file it writes contains PNG data. To get an EMF image of a slide, use Slide.WriteAsEmf.
:::

## **FAQ**

**Can I convert a PPT presentation to PPTX or ODP?**

Yes. Open the PPT file with the Presentation constructor and save it with `SaveFormat.Pptx` or `SaveFormat.Odp`. See [Convert PPT to PPTX](/net/slides/convert-ppt-to-pptx/).

**Can I open a PDF or HTML file as a presentation?**

No. Create or open a presentation, import the PDF pages or HTML content into it with the slide collection methods described above, and then save it in any supported format.

**Can I load an exported PNG or SVG image as an editable presentation?**

No. Image output records how a slide looks, not its text, shapes, or charts. Keep the source presentation if you need to edit it later.

**Can I save PDF/A or PDF/UA documents?**

Yes. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/compliance/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions.Compliance</a> to a <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfcompliance/" target="_blank" rel="nofollow noopener noreferrer">PdfCompliance</a> value: PDF/A-1a, PDF/A-1b, PDF/A-2a, PDF/A-2b, PDF/A-2u, PDF/A-3a, PDF/A-3b, or PDF/UA.

**Can I check whether a file is password-protected before opening it?**

Yes. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a> inspects a file without creating a Presentation object, and its <a href="https://reference.aspose.com/slides/net/aspose.slides/ipresentationinfo/ispasswordprotected/" target="_blank" rel="nofollow noopener noreferrer">IsPasswordProtected</a> property reports whether a password is needed. See [Password-Protect Presentations](/net/slides/password-protected-presentation/).

**Do the two NuGet packages support different formats?**

No. Aspose.Slides.NET and Aspose.Slides.NET6.CrossPlatform have the same LoadFormat and SaveFormat values and the same import and rendering methods. They differ in the platforms they run on and in what those platforms need; see [Installation](/net/slides/installation/).

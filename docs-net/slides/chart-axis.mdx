> Discover how to use Aspose.Slides for .NET to customize chart axes in PowerPoint presentations for reports and visualizations.
> 0

## **Overview**

This article explains how to customize chart axes with Aspose.Slides for .NET. It covers calculated axis values, switching chart rows and columns, axis visibility, category label and tick-mark intervals, date categories and formatting, title rotation, axis positioning, display units, and logarithmic scaling.

## **Get the Max Values on the Vertical Axis on Charts**

Create a <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> and add an area chart with default data. Call <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/chart/validatechartlayout/" target="_blank" rel="nofollow noopener noreferrer">ValidateChartLayout</a> before reading calculated axis values so that the chart layout is up to date.

Read <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualmaxvalue/" target="_blank" rel="nofollow noopener noreferrer">ActualMaxValue</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualminvalue/" target="_blank" rel="nofollow noopener noreferrer">ActualMinValue</a> for the axis limits, and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualmajorunit/" target="_blank" rel="nofollow noopener noreferrer">ActualMajorUnit</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualminorunit/" target="_blank" rel="nofollow noopener noreferrer">ActualMinorUnit</a> for the tick intervals. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualmajorunitscale/" target="_blank" rel="nofollow noopener noreferrer">ActualMajorUnitScale</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/actualminorunitscale/" target="_blank" rel="nofollow noopener noreferrer">ActualMinorUnitScale</a> provide time-unit scales, which are relevant to date axes. The example stores these values in local variables and saves the chart.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Area, 100, 100, 500, 350);
chart.ValidateChartLayout();

var maxValue = chart.Axes.VerticalAxis.ActualMaxValue;
var minValue = chart.Axes.VerticalAxis.ActualMinValue;

var majorUnit = chart.Axes.VerticalAxis.ActualMajorUnit;
var minorUnit = chart.Axes.VerticalAxis.ActualMinorUnit;

var majorUnitScale = chart.Axes.VerticalAxis.ActualMajorUnitScale;
var minorUnitScale = chart.Axes.VerticalAxis.ActualMinorUnitScale;

presentation.Save("AxisValues_out.pptx", SaveFormat.Pptx);
```

## **Swap the Data between Axes**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/chartdata/switchrowcolumn/" target="_blank" rel="nofollow noopener noreferrer">SwitchRowColumn</a> to exchange the roles of series and categories in chart data. Each former category becomes a series, and each former series becomes a category. This changes how the data is grouped; it does not exchange the horizontal and vertical axes. The example uses <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/chartdata/setrange/" target="_blank" rel="nofollow noopener noreferrer">SetRange</a> to bind the default data to `Sheet1!A1:D5`, including the header row and category column, before switching rows and columns. It saves a chart with four series and three categories.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 100, 100, 400, 300);

chart.ChartData.SetRange("Sheet1!A1:D5");
chart.ChartData.SwitchRowColumn();

presentation.Save("SwitchChartRowColumns_out.pptx", SaveFormat.Pptx);
```

## **Reverse the Plotting Order of an Axis**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isplotorderreversed/" target="_blank" rel="nofollow noopener noreferrer">IsPlotOrderReversed</a> to reverse a category or value axis. For example, a horizontal bar chart can show project stages from top to bottom in the same order as the worksheet: Planning, Development, Testing. Reversing an axis changes the plotting direction; it does not sort or rearrange the workbook data. By comparison, <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/chartdata/switchrowcolumn/" target="_blank" rel="nofollow noopener noreferrer">SwitchRowColumn</a> exchanges the roles of series and categories.

The following example creates a horizontal bar chart with three stages and one series. It saves a presentation with three slides: normal order, reversed categories, and reversed values. Each copy uses the same dataset, and only one axis is reversed on each copy.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredBar, 50, 40, 620, 320);
chart.HasLegend = false;

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var series = chart.ChartData.Series.Add(ChartType.ClusteredBar);
var stages = new[] { "Planning", "Development", "Testing" };
var values = new[] { 10, 30, 20 };
for (var i = 0; i < stages.Length; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0, stages[i]);
    chart.ChartData.Categories.Add(categoryCell);
    var valueCell = workbook.GetCell(0, i + 1, 1, values[i]);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
}

// Slide 2: display the first category at the top.
var categorySlide = presentation.Slides.AddClone(slide);
var categoryChart = (IChart)categorySlide.Shapes[0];
categoryChart.Axes.VerticalAxis.IsPlotOrderReversed = true;
// Keep the horizontal value axis at the bottom.
categoryChart.Axes.VerticalAxis.CrossType = CrossesType.Maximum;

// Slide 3: reverse only the horizontal numeric scale.
var valueSlide = presentation.Slides.AddClone(slide);
var valueChart = (IChart)valueSlide.Shapes[0];
valueChart.Axes.HorizontalAxis.IsPlotOrderReversed = true;

presentation.Save("ReversedAxes.pptx", SaveFormat.Pptx);
```

Reversing an axis can also move the perpendicular axis to the opposite side of the plot. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/crosstype/" target="_blank" rel="nofollow noopener noreferrer">CrossType</a> controls where the other axis crosses the axis being configured. In slide 2, setting it to `Maximum` on the reversed category axis keeps the horizontal value axis at the bottom. For a specific crossing point, use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/crossat/" target="_blank" rel="nofollow noopener noreferrer">CrossAt</a>. Check the crossing settings when changing direction, especially if the chart already has a custom crossing point. Set `IsPlotOrderReversed` back to `false` to restore the normal plotting direction; crossing settings are separate.

## **Disable the Vertical Axis for Line Charts**

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isvisible/" target="_blank" rel="nofollow noopener noreferrer">IsVisible</a> to `false` on the vertical axis to hide it. The example creates a line chart with default data and saves it with the vertical axis hidden.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Line, 100, 100, 400, 300);
chart.Axes.VerticalAxis.IsVisible = false;

presentation.Save("HiddenVerticalAxis.pptx", SaveFormat.Pptx);
```

## **Show or Hide Chart Gridlines**

Read <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/showmajorgridlines/" target="_blank" rel="nofollow noopener noreferrer">ShowMajorGridLines</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/showminorgridlines/" target="_blank" rel="nofollow noopener noreferrer">ShowMinorGridLines</a> to check which gridlines an axis displays. Both properties are read-only. Use the line fill of <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/minorgridlinesformat/" target="_blank" rel="nofollow noopener noreferrer">MinorGridLinesFormat</a> to show or hide minor gridlines. Set a solid fill with a visible color to show them, or use `FillType.NoFill` to hide them. The corresponding setting for major gridlines is <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/majorgridlinesformat/" target="_blank" rel="nofollow noopener noreferrer">MajorGridLinesFormat</a>`.Line.FillFormat`. Changing a gridline fill preserves the axis visibility and tick marks.

The vertical axis of this clustered column chart starts with major gridlines visible and minor gridlines hidden. The example shows the minor gridlines in orange, then hides them again before saving the presentation.

```csharp
using System;
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 30, 30, 660, 230);
var axis = chart.Axes.VerticalAxis;
Console.WriteLine($"Initial: major={axis.ShowMajorGridLines}, minor={axis.ShowMinorGridLines}");

var minorFill = axis.MinorGridLinesFormat.Line.FillFormat;
minorFill.FillType = FillType.Solid;
minorFill.SolidFillColor.Color = Color.DarkOrange;
Console.WriteLine($"Enabled: minor={axis.ShowMinorGridLines}");

minorFill.FillType = FillType.NoFill;
Console.WriteLine($"Hidden: major={axis.ShowMajorGridLines}, minor={axis.ShowMinorGridLines}");

presentation.Save("ChartGridlines.pptx", SaveFormat.Pptx);
```

## **Change a Category Axis**

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/categoryaxistype/" target="_blank" rel="nofollow noopener noreferrer">CategoryAxisType</a> to choose a date or text category axis. This example requires `ExistingChart.pptx`, with a chart as the first shape on the first slide and category cells containing numeric Excel date values. It changes the horizontal axis to a date axis. Setting <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isautomaticmajorunit/" target="_blank" rel="nofollow noopener noreferrer">IsAutomaticMajorUnit</a> to `false`, <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/majorunit/" target="_blank" rel="nofollow noopener noreferrer">MajorUnit</a> to `1`, and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/majorunitscale/" target="_blank" rel="nofollow noopener noreferrer">MajorUnitScale</a> to months places major ticks at one-month intervals.

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation("ExistingChart.pptx");
var slide = presentation.Slides[0];

var chart = (IChart) slide.Shapes[0];
chart.Axes.HorizontalAxis.CategoryAxisType = CategoryAxisType.Date;
chart.Axes.HorizontalAxis.IsAutomaticMajorUnit = false;
chart.Axes.HorizontalAxis.MajorUnit = 1;
chart.Axes.HorizontalAxis.MajorUnitScale = TimeUnitType.Months;

presentation.Save("ChangeChartCategoryAxis_out.pptx", SaveFormat.Pptx);
```

### **Determine the Category Axis Type from Data**

Call <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/setcategoryaxistypeautomatically/" target="_blank" rel="nofollow noopener noreferrer">SetCategoryAxisTypeAutomatically</a> after populating the categories, then read <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/categoryaxistype/" target="_blank" rel="nofollow noopener noreferrer">CategoryAxisType</a> to inspect the selection. This is useful when the same chart receives either text labels or numeric date values. The method determines the type when called; it does not enable a persistent mode that reevaluates later data changes. Call it again after replacing the categories.

The following example creates a chart with text categories and prints `Text`. It then replaces the category cell values with dates and calls the method again, which prints `Date`. Dates are stored as numeric OLE Automation values returned by <a href="https://learn.microsoft.com/en-us/dotnet/api/system.datetime.tooadate" target="_blank" rel="nofollow noopener noreferrer">DateTime.ToOADate</a>, rather than date strings. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatacell/customnumberformat/" target="_blank" rel="nofollow noopener noreferrer">CustomNumberFormat</a> controls how those values are displayed; it does not convert text into numeric dates. For more on category cells, see [Chart Workbook](/net/slides/chart-workbook/).

Use automatic determination when the input is known to contain text categories or numeric dates, as in this example. For ordinary numeric labels, mixed categories, or empty data, explicitly set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/categoryaxistype/" target="_blank" rel="nofollow noopener noreferrer">CategoryAxisType</a> to match the intended meaning. Numeric values alone do not establish that the categories represent dates.

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 30, 40, 660, 320);

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var seriesName = workbook.GetCell(0, 0, 1, "Sales");
var series = chart.ChartData.Series.Add(seriesName, chart.Type);
var labels = new[] { "First", "Second", "Third" };

for (var i = 0; i < labels.Length; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0, labels[i]);
    chart.ChartData.Categories.Add(categoryCell);

    var valueCell = workbook.GetCell(0, i + 1, 1, (i + 1) * 10);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
}

var axis = chart.Axes.HorizontalAxis;
axis.SetCategoryAxisTypeAutomatically();
Console.WriteLine(axis.CategoryAxisType); // Text

var dates = new[] { new DateTime(2026, 1, 1), new DateTime(2026, 1, 2), new DateTime(2026, 2, 1) };

for (var i = 0; i < dates.Length; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0);
    categoryCell.Value = dates[i].ToOADate();
    categoryCell.CustomNumberFormat = "yyyy-mm-dd";
}

axis.SetCategoryAxisTypeAutomatically();
Console.WriteLine(axis.CategoryAxisType); // Date

presentation.Save("AutomaticCategoryAxis.pptx", SaveFormat.Pptx);
```

## **Control Category Axis Label Intervals**

When a chart has many categories, reduce the number of visible axis labels without removing categories or data points. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/isautomaticticklabelspacing/" target="_blank" rel="nofollow noopener noreferrer">IsAutomaticTickLabelSpacing</a> to `false`, then set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/ticklabelspacing/" target="_blank" rel="nofollow noopener noreferrer">TickLabelSpacing</a> to the desired category interval. For text categories in their normal order, counting starts at the first category:

<div className="docs-owner-markdown-table">

| Interval | Labels displayed in the example |
| -------- | --------------------------------------------------- |
| `1` | Category 1, Category 2, Category 3, ... Category 24 |
| `2` | Category 1, Category 3, Category 5, ... Category 23 |
| `3` | Category 1, Category 4, Category 7, ... Category 22 |

</div>

An interval of `3` displays every third label, leaving two labels hidden between displayed labels. It does not remove the corresponding columns. Automatic spacing chooses an interval based on the available space; it does not necessarily display every label.

Tick marks have separate controls. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/isautomatictickmarksspacing/" target="_blank" rel="nofollow noopener noreferrer">IsAutomaticTickMarksSpacing</a> to `false` and use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/tickmarksspacing/" target="_blank" rel="nofollow noopener noreferrer">TickMarksSpacing</a> to set their interval. For example, `1` keeps a tick mark at every category interval while labels appear only every third category. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/majortickmark/" target="_blank" rel="nofollow noopener noreferrer">MajorTickMark</a> to a visible style so you can see the result. Setting either automatic-spacing property back to `true` lets the chart choose that interval again.

The following self-contained example creates 24 categories and one series, then saves three slides in `CategoryAxisIntervals.pptx`: automatic spacing, manual label spacing with independent tick marks, and restored automatic spacing. The two copies retain the original chart data. No input presentation is required. Horizontal label text makes the difference in density easy to see.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 30, 40, 660, 320);

chart.HasLegend = false;
chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var series = chart.ChartData.Series.Add(ChartType.ClusteredColumn);
for (var i = 0; i < 24; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0, $"Category {i + 1}");
    chart.ChartData.Categories.Add(categoryCell);
    var valueCell = workbook.GetCell(0, i + 1, 1, 10 + i % 6 * 5);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
}

var axis = chart.Axes.HorizontalAxis;
axis.CategoryAxisType = CategoryAxisType.Text;
axis.TextFormat.TextBlockFormat.RotationAngle = 0;
axis.TextFormat.PortionFormat.FontHeight = 12;
axis.MajorTickMark = TickMarkType.Outside;
axis.IsAutomaticTickLabelSpacing = true;
axis.IsAutomaticTickMarksSpacing = true;

// Slide 2: show every third label, but keep a tick mark for every category.
var manualSlide = presentation.Slides.AddClone(slide);
var manualChart = (IChart)manualSlide.Shapes[0];
var manualAxis = manualChart.Axes.HorizontalAxis;
manualAxis.IsAutomaticTickLabelSpacing = false;
manualAxis.TickLabelSpacing = 3;
manualAxis.IsAutomaticTickMarksSpacing = false;
manualAxis.TickMarksSpacing = 1;

// Slide 3: let the chart choose both intervals again.
var restoredSlide = presentation.Slides.AddClone(manualSlide);
var restoredChart = (IChart)restoredSlide.Shapes[0];
restoredChart.Axes.HorizontalAxis.IsAutomaticTickLabelSpacing = true;
restoredChart.Axes.HorizontalAxis.IsAutomaticTickMarksSpacing = true;

presentation.Save("CategoryAxisIntervals.pptx", SaveFormat.Pptx);
```

**Automatic spacing (slide 1):** In this rendering, every second category label is displayed and wraps onto two lines. The automatic result can vary with chart size, fonts, and the renderer.

![Automatic category label spacing with all 24 columns visible](/net/slides/images/120853ab61db9bc2-category-axis-automatic.png)

**Manual spacing (slide 2):** Every third label is displayed on one line, while tick marks remain at every category interval. All 24 columns, including those without labels, remain visible with the same values. Slide 3 restores the automatic appearance shown above.

![Manual category label interval of three with all 24 columns visible](/net/slides/images/d97feffb5134cd3e-category-axis-manual.png)

### **Choose the Correct Axis and Interval**

Use this category-count interval for a text category axis, such as the category axis of a column, line, area, or bar chart. In a column chart, it is the horizontal axis. In a horizontal bar chart, the category axis is vertical, so apply these settings to <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxesmanager/verticalaxis/" target="_blank" rel="nofollow noopener noreferrer">VerticalAxis</a>. Tick-mark spacing also applies to a series axis in charts that have one.

Do not use category label spacing to set the numeric scale of a value axis. On a value axis, <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxis/majorunit/" target="_blank" rel="nofollow noopener noreferrer">MajorUnit</a> specifies a difference in values: for example, a major unit of `10` produces ticks at 0, 10, 20, and so on when the axis starts at zero. A category label interval of `3` instead counts category positions, regardless of their data values. Scatter and bubble charts use value axes rather than a text category axis. For a date axis, use time-based major units and scales as described in [Change a Category Axis](/net/slides/chart-axis/#change-a-category-axis).

## **Set the Date Format for Category Axis Values**

The example replaces the default chart data with four annual values. Dates are stored as OLE Automation serial numbers in the first worksheet (index `0`). Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/categoryaxistype/" target="_blank" rel="nofollow noopener noreferrer">CategoryAxisType</a> to a date axis, disable <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isnumberformatlinkedtosource/" target="_blank" rel="nofollow noopener noreferrer">IsNumberFormatLinkedToSource</a>, and assign `yyyy` to <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/numberformat/" target="_blank" rel="nofollow noopener noreferrer">NumberFormat</a> so the category labels display four-digit years independently of the cell formatting.

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Line, 50, 50, 450, 300);

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var series = chart.ChartData.Series.Add(ChartType.Line);
for (var i = 0; i < 4; i++)
{
    var date = new DateTime(2015 + i, 1, 1);
    var categoryCell = workbook.GetCell(0, i + 1, 0, date.ToOADate());
    chart.ChartData.Categories.Add(categoryCell);

    var valueCell = workbook.GetCell(0, i + 1, 1, i + 1);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
}

chart.Axes.HorizontalAxis.CategoryAxisType = CategoryAxisType.Date;
chart.Axes.HorizontalAxis.IsNumberFormatLinkedToSource = false;
chart.Axes.HorizontalAxis.NumberFormat = "yyyy";

presentation.Save("DateAxisFormat.pptx", SaveFormat.Pptx);
```

## **Set a Rotation Angle for a Chart Axis Title**

## **Configure a Logarithmic Value Axis**

A logarithmic value axis is useful when positive values span several orders of magnitude. For example, a service might receive 10, 100, 1,000, 10,000, and 100,000 requests over five periods. On a linear scale, the smaller values appear close together near zero. A logarithmic scale makes their relative growth easier to compare: equal distances represent equal ratios rather than equal differences.

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/islogarithmic/" target="_blank" rel="nofollow noopener noreferrer">IsLogarithmic</a> to `true` on the value axis and use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/logbase/" target="_blank" rel="nofollow noopener noreferrer">LogBase</a> to choose the base. This changes how the existing values are displayed; it does not change the data or add a logarithmic trend line. A trend line represents a fitted relationship in the data and is a separate feature.

### **Choose the Value Axis and Base**

For a line or column chart, the value axis is <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxesmanager/verticalaxis/" target="_blank" rel="nofollow noopener noreferrer">VerticalAxis</a>. For a horizontal bar chart, it is <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/iaxesmanager/horizontalaxis/" target="_blank" rel="nofollow noopener noreferrer">HorizontalAxis</a>. Scatter and bubble charts have two value axes, so choose the horizontal axis for X values, the vertical axis for Y values, or both. Do not apply logarithmic scaling to a category axis.

The default logarithmic base is `10`. For PPTX charts, use a base from `2` through `1000`, inclusive; fractional bases such as `2.5` are also supported. With base `10`, successive powers such as 10, 100, 1,000, and 10,000 are equally spaced.

### **Compare Linear and Logarithmic Scaling**

The following self-contained example creates a line chart with the five request counts on the first slide, then clones that slide and enables a base-10 logarithmic value axis on the second. Both slides retain the same data.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Line, 30, 40, 660, 200);

chart.HasLegend = false;

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var series = chart.ChartData.Series.Add(ChartType.Line);
var values = new double[] { 10, 100, 1000, 10000, 100000 };

for (var i = 0; i < values.Length; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0, $"Period {i + 1}");
    chart.ChartData.Categories.Add(categoryCell);

    var valueCell = workbook.GetCell(0, i + 1, 1, values[i]);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
}

// Keep the first slide linear and change only the copy's value-axis scale.
var logarithmicSlide = presentation.Slides.AddClone(slide);
var logarithmicChart = (IChart)logarithmicSlide.Shapes[0];
var valueAxis = logarithmicChart.Axes.VerticalAxis;
valueAxis.IsLogarithmic = true;
valueAxis.LogBase = 10;

presentation.Save("LogarithmicAxis.pptx", SaveFormat.Pptx);
```

**Linear scale (slide 1):** Equal vertical distances represent equal differences in request counts. The largest value dominates the chart, making the smaller values difficult to distinguish.

![Line chart in PowerPoint showing five request counts on a linear value axis](/net/slides/images/00d943a65a682b27-value-axis-linear.png)

**Logarithmic scale (slide 2):** Equal vertical distances represent equal ratios. Each period has ten times as many requests as the previous one, so the points form a straight rising line on the base-10 scale. The axis labels still show the original request counts.

![The same five request counts in PowerPoint on a base-10 logarithmic value axis](/net/slides/images/bdac94e59d4b8099-value-axis-logarithmic.png)

### **Handle Zero and Negative Values**

A logarithmic scale can display only strictly positive values. Check the data before enabling it. If zero or negative values are meaningful, keep a linear scale or show them separately. If excluding those values is appropriate for the analysis, explain the omission. Do not silently replace them with small positive numbers, as this changes the meaning of the data. Any manually configured minimum or maximum for a logarithmic axis must also be positive.

## **FAQ**

**How do I set the value at which one axis crosses the other (axis crossing)?**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/crosstype/" target="_blank" rel="nofollow noopener noreferrer">CrossType</a> to select the crossing behavior. To specify a numeric crossing value, set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/crossat/" target="_blank" rel="nofollow noopener noreferrer">CrossAt</a>. These settings let you move the axis crossing to a suitable baseline.

**How can I position tick labels relative to the axis?**

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/ticklabelposition/" target="_blank" rel="nofollow noopener noreferrer">TickLabelPosition</a> using <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ticklabelpositiontype/" target="_blank" rel="nofollow noopener noreferrer">TickLabelPositionType</a>: `Low`, `High`, `NextTo`, or `None`. To control the tick marks themselves, use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/majortickmark/" target="_blank" rel="nofollow noopener noreferrer">MajorTickMark</a> or <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/minortickmark/" target="_blank" rel="nofollow noopener noreferrer">MinorTickMark</a>; these are separate from label positioning.

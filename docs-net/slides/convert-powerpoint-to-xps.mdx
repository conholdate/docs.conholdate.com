## **Overview**

Aspose.Slides allows you to convert PowerPoint presentations to XPS by saving a PPT or PPTX file in the XPS format. This article explains when the XPS format may be useful and shows how to perform the conversion with Aspose.Slides using either default settings or custom <a href="https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions/" target="_blank" rel="nofollow noopener noreferrer">XpsOptions</a> settings.

## **About XPS**

Microsoft developed <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a> as an alternative to <a href="https://docs.fileformat.com/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>.  It allows you to print content by outputting a file very similar to a PDF. The XPS format is based on XML. The layout or structure of an XPS file remains the same on all operating systems and printers.

## **When to Use Microsoft XPS Format**

To see how Aspose.Slides converts PPT or PPTX presentation to the XPS format, you can check out <a href="https://products.aspose.app/slides/conversion" target="_blank" rel="nofollow noopener noreferrer">this free online converter app</a>.

If you want to cut down on storage costs, you can convert your Microsoft PowerPoint presentation to the XPS format. This way, you will find it easier to save, share, and print your documents.

Microsoft continues to implement strong support for XPS in Windows (even in Windows 10), so you may want to consider saving files to this format. If you are dealing with Windows 8.1, Windows 8, Windows 7, and Windows Vista, then XPS might actually be your best option for certain operations.

- **Windows 8** uses the OXPS (Open XPS) format for XPS files. OXPS is a standardized version of the original XPS format. Windows 8 provides better support for XPS files than it does for PDF files.
  - **XPS:** Built-in XPS viewer/reader and printing to XPS feature available.
  - **PDF**: PDF reader available but no printing to PDF feature.

- **Windows 7 and Windows Vista** use the original XPS format. These operating systems also provide better support for XPS files than they do for PDFs.

- **XPS**: Built-in XPS viewer and printing to XPS feature available.

- **PDF**: No PDF reader. No printing to PDF feature.

## **XPS Conversion with Aspose.Slides**

In <a href="https://products.aspose.com/slides/net/" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Slides**</a> for .NET, you can use the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">**Save**</a> method exposed by the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> class to convert the entire presentation into an XPS document.

When converting a presentation to XPS, you have to save the presentation using either of these settings:

- Default settings (without <a href="https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions" target="_blank" rel="nofollow noopener noreferrer">**XPSOptions**</a>)
- Custom settings (with <a href="https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions" target="_blank" rel="nofollow noopener noreferrer">**XPSOptions**</a>)

### **Convert Presentations to XPS Using Default Settings**

This sample code in C# shows you how to convert a presentation to an XPS document using standard settings:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

// Instantiate a Presentation object that represents a presentation file
using (Presentation pres = new Presentation("Convert_XPS.pptx"))
{
    // Saving the presentation to XPS document
    pres.Save("XPS_Output_Without_XPSOption_out.xps", SaveFormat.Xps);
}
```

### **Convert Presentations to XPS Using Custom Settings**

This sample code shows you how to convert a presentation to an XPS document using custom settings in C#:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

// Instantiate a Presentation object that represents a presentation file
using (Presentation pres = new Presentation("Convert_XPS_Options.pptx"))
{
    // Instantiate the TiffOptions class
    XpsOptions options = new XpsOptions();

    // Save MetaFiles as PNG
    options.SaveMetafilesAsPng = true;

    // Save the presentation to XPS document
    pres.Save("XPS_With_Options_out.xps", SaveFormat.Xps, options);
}
```

## **FAQ**

### Can I save to XPS into a stream instead of a file?

Yes-Aspose.Slides lets you export directly to a stream, which is ideal for web APIs, server-side pipelines, or any scenario where you want to send the XPS without touching the file system.

### Are hidden slides carried over to XPS, and can I exclude them?

By default, only regular (visible) slides are rendered. You can <a href="https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions/showhiddenslides/" target="_blank" rel="nofollow noopener noreferrer">include or exclude hidden slides</a> through <a href="https://reference.aspose.com/slides/net/aspose.slides.export/xpsoptions/" target="_blank" rel="nofollow noopener noreferrer">export settings</a> before saving to XPS, ensuring the output contains exactly the pages you intend.

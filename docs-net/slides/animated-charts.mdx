## **Introduction**

Aspose.Slides for .NET supports animating the chart elements. **Series**, **Categories**, **Series Elements**, **Categories Elements** can be animated with <a href="https://reference.aspose.com/slides/net/aspose.slides.animation/isequence/methods/addeffect" target="_blank" rel="nofollow noopener noreferrer">ISequence.AddEffect</a> method and two enums <a href="https://reference.aspose.com/slides/net/aspose.slides.animation/effectchartmajorgroupingtype" target="_blank" rel="nofollow noopener noreferrer">EffectChartMajorGroupingType</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.animation/effectchartminorgroupingtype" target="_blank" rel="nofollow noopener noreferrer">EffectChartMinorGroupingType</a>.

## **Chart Series Animation**

If you want to animate a chart series, write the code according to the steps listed below:

1. Load a presentation.
2. Get reference of the chart object.
3. Animate the series.
4. Write the presentation file to disk.

In the example given below, we animated chart series.

```csharp
using Aspose.Slides;
using Aspose.Slides.Animation;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

// Instantiate Presentation class that represents a presentation file 
using (Presentation presentation = new Presentation("ExistingChart.pptx"))
{
    // Get reference of the chart object
    var slide = presentation.Slides[0] as Slide;
    var shapes = slide.Shapes as ShapeCollection;
    var chart = shapes[0] as IChart;

    // Animate the series
    slide.Timeline.MainSequence.AddEffect(chart, EffectType.Fade, EffectSubtype.None,
    EffectTriggerType.AfterPrevious);

    ((Sequence)slide.Timeline.MainSequence).AddEffect(chart,
    EffectChartMajorGroupingType.BySeries, 0,
    EffectType.Appear, EffectSubtype.None, EffectTriggerType.AfterPrevious);

    ((Sequence)slide.Timeline.MainSequence).AddEffect(chart,
    EffectChartMajorGroupingType.BySeries, 1,
    EffectType.Appear, EffectSubtype.None, EffectTriggerType.AfterPrevious);

    ((Sequence)slide.Timeline.MainSequence).AddEffect(chart,
    EffectChartMajorGroupingType.BySeries, 2,
    EffectType.Appear, EffectSubtype.None, EffectTriggerType.AfterPrevious);

    ((Sequence)slide.Timeline.MainSequence).AddEffect(chart,
    EffectChartMajorGroupingType.BySeries, 3,
    EffectType.Appear, EffectSubtype.None, EffectTriggerType.AfterPrevious);

    // Write the modified presentation to disk 
    presentation.Save("AnimatingSeries_out.pptx", SaveFormat.Pptx);
}
```

## **FAQ**

### Are different effect types (e.g., entrance, emphasis, exit) supported for charts like for regular shapes?

Yes. A chart is treated as a shape, so it supports the standard animation effect types, including entrance, emphasis, and exit, with full control via the slide's timeline and animation sequences.

### Can I combine chart animation with slide transitions?

Yes. [Transitions](/net/slides/slide-transition/) apply to the slide, while animation effects apply to objects on the slide. You can use both together in the same presentation and control them independently.

### Are chart animations preserved when saving to PPTX?

Yes. When you [save to PPTX](/net/slides/save-presentation/), all animation effects and their ordering are preserved because they are part of the presentation's native animation model.

### Can I read existing chart animations from a presentation and modify them?

Yes. The <a href="https://reference.aspose.com/slides/net/aspose.slides.animation/" target="_blank" rel="nofollow noopener noreferrer">API</a> provides access to the slide timeline, sequences, and effects, allowing you to inspect existing chart animations and adjust them without recreating everything from scratch.

### Can I produce a video that includes chart animations using Aspose.Slides?

Yes. You can [export a presentation to video](/net/slides/convert-powerpoint-to-video/) while preserving animations, configuring timings and other export settings so the resulting clip reflects the animated playback.

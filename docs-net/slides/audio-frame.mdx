> Embed audio in slides, change the audio icon, configure playback, manage WebVTT captions, and extract slide transition sounds with Aspose.Slides for .NET.

## **Overview**

An audio frame lets you play a sound on a slide. With Aspose.Slides for .NET, you can embed an audio clip, choose the image that represents it, adjust playback, and attach captions. You can also retrieve a sound assigned to a slide transition.

## **Create Audio Frames**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addaudioframeembedded/" target="_blank" rel="nofollow noopener noreferrer">AddAudioFrameEmbedded</a> to embed a local audio clip on the first slide. The first two coordinates position the frame on the slide, and the next two values set its width and height, all in points. This example sets <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/playmode/" target="_blank" rel="nofollow noopener noreferrer">PlayMode</a> to start the clip automatically and <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/volume/" target="_blank" rel="nofollow noopener noreferrer">Volume</a> to the loud preset.

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

using var audioStream = File.OpenRead("audio.wav");
var audioFrame = slide.Shapes.AddAudioFrameEmbedded(50, 150, 100, 100, audioStream);
audioFrame.PlayMode = AudioPlayModePreset.Auto;
audioFrame.Volume = AudioVolumeMode.Loud;

presentation.Save("AudioFrameEmbed_out.pptx", SaveFormat.Pptx);
```

## **Change the Audio Frame Thumbnail**

By default, an audio frame displays a speaker icon. To display a custom thumbnail, add an image to the presentation with <a href="https://reference.aspose.com/slides/net/aspose.slides/iimagecollection/addimage/" target="_blank" rel="nofollow noopener noreferrer">AddImage</a> and assign it to the frame's <a href="https://reference.aspose.com/slides/net/aspose.slides/islidespicture/image/" target="_blank" rel="nofollow noopener noreferrer">Picture.Image</a> property. The example uses a JPEG as the thumbnail for an embedded audio clip.

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

using var imageStream = File.OpenRead("eagle.jpeg");
var thumbnail = presentation.Images.AddImage(imageStream);

using var audioStream = File.OpenRead("audio.wav");
var audioFrame = slide.Shapes.AddAudioFrameEmbedded(150, 100, 50, 50, audioStream);
audioFrame.PictureFormat.Picture.Image = thumbnail;

presentation.Save("example_out.pptx", SaveFormat.Pptx);
```

The example finds the first audio frame on the first slide, sets <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/playmode/" target="_blank" rel="nofollow noopener noreferrer">PlayMode</a> to start playback on a click, and selects the low volume preset. The clip continues across slides with looping disabled. The icon stays hidden during the show, and the clip rewinds after playback.

```csharp
using System;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("AudioFrameEmbed_out.pptx");
var slide = presentation.Slides[0];

var audioFrame = slide.Shapes.OfType<IAudioFrame>().FirstOrDefault();
if (audioFrame == null)
{
    Console.WriteLine("The first slide has no audio frame.");
    return;
}

audioFrame.PlayMode = AudioPlayModePreset.OnClick;
audioFrame.Volume = AudioVolumeMode.Low;
audioFrame.PlayAcrossSlides = true;
audioFrame.PlayLoopMode = false;
audioFrame.HideAtShowing = true;
audioFrame.RewindAudio = true;

presentation.Save("AudioFrameEmbed_changed.pptx", SaveFormat.Pptx);
```

For a clip longer than 3.5 seconds, this example skips the first 1.5 seconds and the last 2 seconds. <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/trimfromend/" target="_blank" rel="nofollow noopener noreferrer">TrimFromEnd</a> measures the duration to omit from the end of the clip. To get the end time shown in PowerPoint, subtract that offset from the full clip duration. The trimmed clip fades in over 200 milliseconds and fades out over 500 milliseconds. All four properties take values in milliseconds.

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

using var audioStream = File.OpenRead("audio.wav");
var audioFrame = slide.Shapes.AddAudioFrameEmbedded(50, 50, 100, 100, audioStream);
audioFrame.TrimFromStart = 1500f;
audioFrame.TrimFromEnd = 2000f;
audioFrame.FadeInDuration = 200f;
audioFrame.FadeOutDuration = 500f;

presentation.Save("AudioFrameTrimFade_out.pptx", SaveFormat.Pptx);
```

To set the playback volume to a specific percentage, use <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/volumevalue/" target="_blank" rel="nofollow noopener noreferrer">VolumeValue</a>. This example sets the first audio frame on the first slide to 85%.

```csharp
using System;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("AudioFrameEmbed_out.pptx");
var slide = presentation.Slides[0];

var audioFrame = slide.Shapes.OfType<IAudioFrame>().FirstOrDefault();
if (audioFrame == null)
{
    Console.WriteLine("The first slide has no audio frame.");
    return;
}

audioFrame.VolumeValue = 85f;

presentation.Save("AudioFrameValue_out.pptx", SaveFormat.Pptx);
```

## **Manage Audio Captions**

Each audio frame has a <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/captiontracks/" target="_blank" rel="nofollow noopener noreferrer">CaptionTracks</a> collection. Use it to attach WebVTT captions to the clip, export existing tracks, or remove them.

### **Add Audio Captions**

The example embeds an audio clip on the first slide and uses <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptionscollection/add/" target="_blank" rel="nofollow noopener noreferrer">ICaptionsCollection.Add</a> to attach a local WebVTT track. The first argument supplies the track label, and the second identifies the file containing the timed captions.

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

using var audioStream = File.OpenRead("audio.wav");
var audioFrame = slide.Shapes.AddAudioFrameEmbedded(10, 10, 50, 50, audioStream);
audioFrame.CaptionTracks.Add("English", "track.vtt");

presentation.Save("audio_with_captions.pptx", SaveFormat.Pptx);
```

### **Extract Audio Captions**

This example exports each caption track attached to an audio frame on the first slide. It writes the track's <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptions/binarydata/" target="_blank" rel="nofollow noopener noreferrer">BinaryData</a> to a WebVTT file and uses its <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptions/captionid/" target="_blank" rel="nofollow noopener noreferrer">CaptionId</a> as the file name so that each track has a separate output.

```csharp
using System.IO;
using System.Linq;
using Aspose.Slides;

using var presentation = new Presentation("audio_with_captions.pptx");
var slide = presentation.Slides[0];

foreach (var audioFrame in slide.Shapes.OfType<IAudioFrame>())
{
    foreach (var track in audioFrame.CaptionTracks)
    {
        File.WriteAllBytes($"{track.CaptionId}.vtt", track.BinaryData);
    }
}
```

### **Remove Audio Captions**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptionscollection/remove/" target="_blank" rel="nofollow noopener noreferrer">Remove</a> or <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptionscollection/removeat/" target="_blank" rel="nofollow noopener noreferrer">RemoveAt</a> to delete an individual track. The example uses <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptionscollection/clear/" target="_blank" rel="nofollow noopener noreferrer">Clear</a> to remove all captions from the first audio frame on the first slide while preserving the clip.

```csharp
using System;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("audio_with_captions.pptx");
var slide = presentation.Slides[0];

var audioFrame = slide.Shapes.OfType<IAudioFrame>().FirstOrDefault();
if (audioFrame == null)
{
    Console.WriteLine("The first slide has no audio frame.");
    return;
}

audioFrame.CaptionTracks.Clear();

presentation.Save("audio_without_captions.pptx", SaveFormat.Pptx);
```

### **Find a Line in Audio Captions**

To find a line in the audio captions on the first slide, read each track's <a href="https://reference.aspose.com/slides/net/aspose.slides/icaptions/dataasstring/" target="_blank" rel="nofollow noopener noreferrer">DataAsString</a> in memory. In a plain-text WebVTT cue, the timing line contains `-->`, the caption lines follow it, and a blank line ends the cue. This example prints the track label and each caption line containing "café".

```csharp
using System;
using System.IO;
using System.Linq;
using Aspose.Slides;

using var presentation = new Presentation("audio_with_captions.pptx");
var slide = presentation.Slides[0];

foreach (var frame in slide.Shapes.OfType<IAudioFrame>())
{
    foreach (var track in frame.CaptionTracks)
    {
        using var reader = new StringReader(track.DataAsString);
        var inCue = false;
        while (reader.ReadLine() is string line)
        {
            if (line.Length == 0)
                inCue = false;
            else if (line.Contains("-->"))
                inCue = true;
            else if (inCue && line.Contains("café", StringComparison.OrdinalIgnoreCase))
                Console.WriteLine($"{track.Label}: {line}");
        }
    }
}
```

## **Extract Audio**

A slide transition can have its own sound. To retrieve it, read the transition's <a href="https://reference.aspose.com/slides/net/aspose.slides/islideshowtransition/sound/" target="_blank" rel="nofollow noopener noreferrer">Sound</a> property. The example accesses the sound's <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudio/binarydata/" target="_blank" rel="nofollow noopener noreferrer">BinaryData</a> and prints its size in bytes. If the first slide has no transition sound, it prints a message instead.

```csharp
using System;
using Aspose.Slides;

using var presentation = new Presentation("AudioSlide.pptx");
var slide = presentation.Slides[0];

var sound = slide.SlideShowTransition.Sound;
if (sound == null)
{
    Console.WriteLine("The first slide has no transition sound.");
    return;
}

var audioData = sound.BinaryData;
Console.WriteLine($"Transition sound: {audioData.Length} bytes.");
```

## **FAQ**

**Can I reuse the same audio clip across multiple slides without duplicating it?**

Yes. Add the clip once to the presentation's <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/audios/" target="_blank" rel="nofollow noopener noreferrer">audio collection</a> and pass the same audio object to <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addaudioframeembedded/" target="_blank" rel="nofollow noopener noreferrer">AddAudioFrameEmbedded</a> for each slide.

**Can I replace the sound in an existing audio frame?**

Yes. For a linked sound, update <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/linkpathlong/" target="_blank" rel="nofollow noopener noreferrer">LinkPathLong</a> to point to the replacement file. For an embedded sound, assign another clip from the presentation's audio collection to <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/embeddedaudio/" target="_blank" rel="nofollow noopener noreferrer">EmbeddedAudio</a>. Both approaches preserve the existing frame.

**Does trimming change the audio data stored in the presentation?**

No. <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/trimfromstart/" target="_blank" rel="nofollow noopener noreferrer">TrimFromStart</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/trimfromend/" target="_blank" rel="nofollow noopener noreferrer">TrimFromEnd</a> set playback boundaries. You can still retrieve the full clip from <a href="https://reference.aspose.com/slides/net/aspose.slides/iaudioframe/embeddedaudio/" target="_blank" rel="nofollow noopener noreferrer">EmbeddedAudio</a>.

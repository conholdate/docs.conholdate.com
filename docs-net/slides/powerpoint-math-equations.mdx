## **Overview**

PowerPoint stores equations as Office Math Markup Language (OMML). With Aspose.Slides for .NET, you can create the same kind of math content programmatically: fractions, radicals, functions, limits, N-ary operators, matrices, arrays, and formatted math blocks.

In PowerPoint, users normally add equations from **Insert &gt; Equation**:

![PowerPoint Insert tab with the Equation command selected](/net/slides/images/56aa77b4a9073cd4-powerpoint-math-equations_1.png)

The result is editable math text on the slide:

![A PowerPoint slide containing an editable math equation](/net/slides/images/c3e05f23ce5e1207-powerpoint-math-equations_2.png)

Aspose.Slides builds that math text through three main objects:

- A math shape, created with <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addmathshape/" target="_blank" rel="nofollow noopener noreferrer">AddMathShape</a>, is the shape that contains the equation.
- <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a> stores math content inside the shape text frame.
- <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathparagraph/" target="_blank" rel="nofollow noopener noreferrer">MathParagraph</a> contains one or more <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathblock/" target="_blank" rel="nofollow noopener noreferrer">MathBlock</a> objects.

Most examples below use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a> and the fluent methods from <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/" target="_blank" rel="nofollow noopener noreferrer">IMathElement</a> to keep the code short and readable.

For MathML export scenarios, see [Export Math Equations from Presentations in .NET](/net/slides/exporting-math-equations/).

## **Create an Equation**

This example uses <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addmathshape/" target="_blank" rel="nofollow noopener noreferrer">AddMathShape</a> to create a math shape and adds the Pythagorean theorem:

![The equation c squared equals a squared plus b squared](/net/slides/images/81003d16cc005d98-powerpoint-math-equations_3.png)

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var mathShape = slide.Shapes.AddMathShape(20, 20, 700, 120);
var mathParagraph = ((MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var equation = new MathematicalText("c")
    .SetSuperscript("2")
    .Join("=")
    .Join(new MathematicalText("a").SetSuperscript("2"))
    .Join("+")
    .Join(new MathematicalText("b").SetSuperscript("2"));

mathParagraph.Add(equation);

presentation.Save("pythagorean-theorem.pptx", SaveFormat.Pptx);
```

<a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addmathshape/" target="_blank" rel="nofollow noopener noreferrer">AddMathShape</a> creates a shape that already contains a math paragraph. Access the first <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a>, get its <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/mathparagraph/" target="_blank" rel="nofollow noopener noreferrer">MathParagraph</a>, and add math blocks or math elements to it.

### **Combine Math Blocks**

When parts of an equation are built independently as <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathblock/" target="_blank" rel="nofollow noopener noreferrer">IMathBlock</a> objects, use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathblock/joinblock/" target="_blank" rel="nofollow noopener noreferrer">JoinBlock</a> to combine them. The example builds `c² =` in the left block and `a² + b²` in the right block. <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/setsuperscript/" target="_blank" rel="nofollow noopener noreferrer">SetSuperscript</a> creates editable mathematical superscripts for all three powers.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddMathShape(20, 20, 600, 100);
var mathParagraph = ((IMathPortion)shape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var leftBlock = new MathBlock();
leftBlock.Add(new MathematicalText("c").SetSuperscript("2"));
leftBlock.Add(new MathematicalText("="));

var rightBlock = new MathBlock();
rightBlock.Add(new MathematicalText("a").SetSuperscript("2"));
rightBlock.Add(new MathematicalText("+"));
rightBlock.Add(new MathematicalText("b").SetSuperscript("2"));

var combinedBlock = leftBlock.JoinBlock(rightBlock);
mathParagraph.Add(combinedBlock);

presentation.Save("equation.pptx", SaveFormat.Pptx);
```

<a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathblock/joinblock/" target="_blank" rel="nofollow noopener noreferrer">JoinBlock</a> returns `leftBlock` itself, now containing both parts in order, and leaves `rightBlock` empty. Add the combined block to the <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathparagraph/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph</a> only once. After reopening `equation.pptx`, the paragraph contains one block representing `c² = a² + b²`, with all three powers preserved as mathematical superscripts.

Calling <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelementcollection/add/" target="_blank" rel="nofollow noopener noreferrer">Add</a> as `leftBlock.Add(rightBlock)` instead attempts to nest one block directly inside another and throws `InvalidOperationException`.

## **Add Fractions**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/divide/" target="_blank" rel="nofollow noopener noreferrer">Divide</a> to create a fraction. You can choose a fraction style with <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathfractiontypes/" target="_blank" rel="nofollow noopener noreferrer">MathFractionTypes</a>.

![A skewed math fraction showing one divided by x](/net/slides/images/b3c6ff0c3496b955-powerpoint-math-equations_4.png)

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var mathShape = slide.Shapes.AddMathShape(20, 20, 700, 100);
var mathParagraph = ((MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var fraction = new MathematicalText("1")
    .Divide("x", MathFractionTypes.Skewed);

mathParagraph.Add(new MathBlock(fraction));

presentation.Save("fraction.pptx", SaveFormat.Pptx);
```

For a stacked fraction, use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathfractiontypes/" target="_blank" rel="nofollow noopener noreferrer">MathFractionTypes.Bar</a>:

```csharp
using Aspose.Slides.MathText;

var stackedFraction = new MathematicalText("x + 1").Divide("y - 1", MathFractionTypes.Bar);
```

### **Show or Hide the Degree of a Square Root**

A square root can display an explicit 2 or use the conventional √x notation. The <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathradical/hidedegree/" target="_blank" rel="nofollow noopener noreferrer">HideDegree</a> property of <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathradical/" target="_blank" rel="nofollow noopener noreferrer">IMathRadical</a> controls which form appears. Both forms retain the degree 2 and the radicand x in the editable equation.

![The same square root with HideDegree set to false on the left and true on the right](/net/slides/images/1dfe7404d270f697-square-root-degree.png)

The example saves the same square root twice. In `visible-degree.pptx` the 2 is visible. In `hidden-degree.pptx` it is hidden.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var radical = new MathematicalText("x").Radical("2");

var shape = slide.Shapes.AddMathShape(20, 20, 200, 100);
var portion = (IMathPortion)shape.TextFrame.Paragraphs[0].Portions[0];
portion.MathParagraph.Add(new MathBlock(radical));

radical.HideDegree = false;
presentation.Save("visible-degree.pptx", SaveFormat.Pptx);

radical.HideDegree = true;
presentation.Save("hidden-degree.pptx", SaveFormat.Pptx);
```

## **Add Functions and Limits**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/asargumentoffunction/" target="_blank" rel="nofollow noopener noreferrer">AsArgumentOfFunction</a> or <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/function/" target="_blank" rel="nofollow noopener noreferrer">Function</a> for functions such as `sin(x)`, `log(x)`, or custom function names. For limits, put `lim` in a <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathlimit/" target="_blank" rel="nofollow noopener noreferrer">MathLimit</a> or use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/setlowerlimit/" target="_blank" rel="nofollow noopener noreferrer">SetLowerLimit</a>.

![The limit of x as x approaches infinity](/net/slides/images/46a206162ccb53c7-powerpoint-math-equations_8.png)

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var mathShape = slide.Shapes.AddMathShape(20, 20, 700, 100);
var mathParagraph = ((MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var limit = new MathematicalText("lim")
    .SetLowerLimit("x→∞")
    .Function("x");

mathParagraph.Add(new MathBlock(limit));

presentation.Save("functions-and-limits.pptx", SaveFormat.Pptx);
```

For a custom function name, make the function name the current element and call <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/function/" target="_blank" rel="nofollow noopener noreferrer">Function</a> with its argument:

```csharp
using Aspose.Slides.MathText;

var customFunction = new MathematicalText("f").Function("x + 1");
```

## **Add N-ary Operators and Integrals**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/nary/" target="_blank" rel="nofollow noopener noreferrer">Nary</a> for summations, unions, intersections, and other large operators. Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/integral/" target="_blank" rel="nofollow noopener noreferrer">Integral</a> for integrals. Both methods let you set lower and upper limits.

![A summation with lower and upper limits](/net/slides/images/776e514436eb06a3-powerpoint-math-equations_7.png)

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var mathShape = slide.Shapes.AddMathShape(20, 20, 700, 120);
var mathParagraph = ((MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var summationBase = new MathematicalText("x")
    .SetSuperscript("k")
    .Join(new MathematicalText("a").SetSuperscript("n-k"));

var summation = summationBase.Nary(MathNaryOperatorTypes.Summation, "k=0", "n");

mathParagraph.Add(new MathBlock(summation));

presentation.Save("nary-operators.pptx", SaveFormat.Pptx);
```

N-ary operators are for large operators with optional limits. Simple operators such as `+`, `-`, and `=` are usually added as <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a> and joined into the expression.

For an integral, use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/integral/" target="_blank" rel="nofollow noopener noreferrer">Integral</a>:

```csharp
using Aspose.Slides.MathText;

var integralBase = new MathematicalText("x").Join(new MathematicalText("dx").ToBox());
var integral = integralBase.Integral(MathIntegralTypes.Simple, "0", "1");
```

## **Add Matrices**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathmatrix/" target="_blank" rel="nofollow noopener noreferrer">MathMatrix</a> for rows and columns. Matrices do not include brackets by default, so enclose the matrix when you need parentheses, brackets, or braces.

![A two-row math matrix with one empty cell](/net/slides/images/db139c375bd3c7bd-powerpoint-math-equations_10.png)

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var mathShape = slide.Shapes.AddMathShape(20, 20, 700, 120);
var mathParagraph = ((MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;

var matrix = new MathMatrix(2, 3);
matrix[0, 0] = new MathematicalText("1");
matrix[0, 1] = new MathematicalText("x");
matrix[1, 0] = new MathematicalText("x");
matrix[1, 1] = new MathematicalText("2");
matrix[1, 2] = new MathematicalText("y");

mathParagraph.Add(new MathBlock(matrix));

presentation.Save("matrix.pptx", SaveFormat.Pptx);
```

### **Edit an Existing Matrix**

Suppose a linear algebra lesson starts with the coefficient matrix in `matrix.pptx`, saved by the preceding example. For the next exercise, keep the first equation, replace the second with two new equations, and revise the set of variables. Open the existing matrix through <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathmatrix/" target="_blank" rel="nofollow noopener noreferrer">IMathMatrix</a> to keep the coefficients that still apply.

![Original two-row coefficient matrix with entries 1, x, and an empty cell in the first row and x, 2, and y in the second](/net/slides/images/8afb2aecda93f822-matrix-before-edit.png)

Row and column indices start at zero and refer to the matrix as it stands at each call. Inserting a row before index 1 moves the original second row to index 2. Inserting after index 2 then appends a row. Deleting row 2 removes the original second equation and moves the appended row up one position. Columns shift in the same way.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation("matrix.pptx");

var shape = (IAutoShape)presentation.Slides[0].Shapes[0];
var portion = (IMathPortion)shape.TextFrame.Paragraphs[0].Portions[0];
var matrix = (IMathMatrix)portion.MathParagraph[0][0];

matrix.InsertRowBefore(1);
matrix.InsertRowAfter(2);
matrix.DeleteRow(2);

matrix.InsertColumnBefore(1);
matrix.InsertColumnAfter(3);
matrix.DeleteColumn(3);

// New cells are initially null. Set the nonzero coefficients first.
matrix[1, 0] = new MathematicalText("12");
matrix[1, 1] = new MathematicalText("1");
matrix[2, 2] = new MathematicalText("10");
matrix[2, 3] = new MathematicalText("1");
for (var row = 0; row < matrix.RowCount; row++)
{
    for (var column = 0; column < matrix.ColumnCount; column++)
    {
        matrix[row, column] ??= new MathematicalText("0");
    }
}

matrix.SetColumnAlignment(0, MathHorizontalAlignment.Left);
matrix.SetColumnsAlignment(1, 3, MathHorizontalAlignment.Right);

presentation.Save("updated-matrix.pptx", SaveFormat.Pptx);
```

<a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathmatrix/setcolumnalignment/" target="_blank" rel="nofollow noopener noreferrer">SetColumnAlignment</a> aligns the first column to the left. <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathmatrix/setcolumnsalignment/" target="_blank" rel="nofollow noopener noreferrer">SetColumnsAlignment</a> aligns three consecutive columns to the right, starting at index 1. In `updated-matrix.pptx`, the matrix has three equations and four variables. The original first-row coefficients `1` and `x` now appear in the first and third columns.

![Updated three-row matrix showing the rows 1, 0, x, 0; 12, 1, 0, 0; and 0, 0, 10, 1](/net/slides/images/72c7174520d1e1ca-matrix-after-edit.png)

### **Align an Array with Surrounding Elements**

<a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imatharray/basejustification/" target="_blank" rel="nofollow noopener noreferrer">IMathArray.BaseJustification</a> controls the vertical alignment of an array relative to the mathematical elements beside it. The example below compares alignment with the first row, the center of the array, and the last row.

The following example creates three identical arrays, each with three rows and the neighboring elements `A=` and `=B`. All mathematical text uses Cambria Math at 24 points. Only the array alignment changes.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(780, 200, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var alignments = new[] { MathVerticalAlignment.Top, MathVerticalAlignment.Center, MathVerticalAlignment.Bottom };

for (int i = 0; i < alignments.Length; i++)
{
    var label = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20 + i * 260, 10, 240, 30);
    label.FillFormat.FillType = FillType.NoFill;
    label.LineFormat.FillFormat.FillType = FillType.NoFill;
    label.TextFrame.Text = alignments[i].ToString();
    var labelFormat = label.TextFrame.Paragraphs[0].Portions[0].PortionFormat;
    labelFormat.FontHeight = 16;
    labelFormat.FillFormat.FillType = FillType.Solid;
    labelFormat.FillFormat.SolidFillColor.Color = System.Drawing.Color.Black;

    var mathShape = slide.Shapes.AddMathShape(20 + i * 260, 60, 240, 130);
    mathShape.TextFrame.TextFrameFormat.AnchoringType = TextAnchorType.Top;
    var mathParagraph = ((IMathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;
    mathParagraph.Justification = MathJustification.LeftJustified;

    var rows = new IMathElement[] { CreateText("x+y=3"), CreateText("x-y=1"), CreateText("x=2") };
    var equationArray = new MathArray(rows);
    equationArray.BaseJustification = alignments[i];
    var equation = new MathBlock(CreateText("A=")).Join(equationArray).Join(CreateText("=B"));
    mathParagraph.Add(equation);
}

presentation.Save("equation-array-alignment.pptx", SaveFormat.Pptx);

MathematicalText CreateText(string value)
{
    var text = new MathematicalText(value);
    text.Format.FontHeight = 24;
    text.Format.LatinFont = new FontData("Cambria Math");
    return text;
}
```

### **Configure Row Spacing**

<a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imatharray/rowspacingrule/" target="_blank" rel="nofollow noopener noreferrer">RowSpacingRule</a> selects the spacing rule for rows within the array. <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imatharray/rowspacing/" target="_blank" rel="nofollow noopener noreferrer">RowSpacing</a> supplies a numeric value for an explicit spacing rule and is ignored by the preset rules.

For exact spacing, the value is measured in points. For proportional spacing, it is measured in half-lines: the value `3` in the example specifies 1.5 lines. Set both properties when specifying an explicit value; changing the numeric value alone does not select a spacing rule.

The example below saves five presentations with the same equations, alignment, and font settings. The first three use presets; the last two show explicit values.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

var settings = new (MathRowSpacingRule Rule, uint Spacing)[]
{
    (MathRowSpacingRule.SingleLineGap, 0),
    (MathRowSpacingRule.OneAndAHalfLineGap, 0),
    (MathRowSpacingRule.TwoLineGap, 0),
    (MathRowSpacingRule.Exactly, 20),
    (MathRowSpacingRule.Multiple, 3)
};

foreach (var setting in settings)
{
    var fileName = $"equation-array-{setting.Rule}.pptx";
    using (var presentation = new Presentation())
    {
        var mathShape = presentation.Slides[0].Shapes.AddMathShape(20, 20, 600, 300);
        var paragraph = mathShape.TextFrame.Paragraphs[0];
        paragraph.ParagraphFormat.SpaceBefore = 0;
        paragraph.ParagraphFormat.SpaceAfter = 0;
        var mathParagraph = ((IMathPortion)paragraph.Portions[0]).MathParagraph;
        mathParagraph.Justification = MathJustification.LeftJustified;

        var rows = new IMathElement[] { CreateText("x+y=3"), CreateText("x-y=1"), CreateText("x=2") };
        var equationArray = new MathArray(rows);
        equationArray.BaseJustification = MathVerticalAlignment.Center;
        equationArray.RowSpacingRule = setting.Rule;
        equationArray.RowSpacing = setting.Spacing;
        var equation = new MathBlock(CreateText("A=")).Join(equationArray).Join(CreateText("=B"));
        mathParagraph.Add(equation);

        presentation.Save(fileName, SaveFormat.Pptx);
    }

}

MathematicalText CreateText(string value)
{
    var text = new MathematicalText(value);
    text.Format.FontHeight = 24;
    text.Format.LatinFont = new FontData("Cambria Math");
    return text;
}
```

Array row spacing is separate from paragraph spacing. <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/spacebefore/" target="_blank" rel="nofollow noopener noreferrer">SpaceBefore</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/spaceafter/" target="_blank" rel="nofollow noopener noreferrer">SpaceAfter</a> add space around the containing paragraph, not between array rows. Likewise, <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathparagraph/justification/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph.Justification</a> positions the whole math paragraph horizontally; it does not replace the array's vertical alignment setting.

### **Align Right Subscripts and Superscripts**

When both scripts belong to the same base, use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathrightsubsuperscriptelement/" target="_blank" rel="nofollow noopener noreferrer">MathRightSubSuperscriptElement</a>. Its <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathrightsubsuperscriptelement/alignscripts/" target="_blank" rel="nofollow noopener noreferrer">AlignScripts</a> property controls their horizontal positions: `false` (the default) lets them follow the contour of the base, while `true` aligns the scripts horizontally with each other.

This example places two copies of the same editable expression side by side. Both use mathematical italic f (U+1D453), a lower script of 1, an upper script of 2, and Cambria Math at 72 points. The sloping base makes the difference visible in PowerPoint. Install Cambria Math before running the example.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(900, 250, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var format = new PortionFormat
{
    FontHeight = 72,
    LatinFont = new FontData("Cambria Math")
};

for (var i = 0; i < 2; i++)
{
    var left = 40 + i * 440;
    var shape = slide.Shapes.AddMathShape(left, 75, 380, 150);

    var baseText = new MathematicalText("\U0001D453", format);
    var subscript = new MathematicalText("1", format);
    var superscript = new MathematicalText("2", format);
    var scripts = new MathRightSubSuperscriptElement(baseText, subscript, superscript);
    scripts.AlignScripts = i == 1;

    var portion = (MathPortion)shape.TextFrame.Paragraphs[0].Portions[0];
    portion.PortionFormat.FontHeight = format.FontHeight;
    portion.PortionFormat.LatinFont = format.LatinFont;
    portion.MathParagraph.Add(new MathBlock(scripts));
}

presentation.Save("aligned-scripts.pptx", SaveFormat.Pptx);
```

![Two editable expressions in PowerPoint with AlignScripts set to false on the left and true on the right](/net/slides/images/f8f97aa6db8ac6ed-aligned-scripts.png)

On the left, the lower script starts farther left than the upper script, following the base contour. On the right, the two scripts align horizontally with each other.

### **Size and Align Delimiters**

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathdelimiter/growtomatchoperandheight/" target="_blank" rel="nofollow noopener noreferrer">GrowToMatchOperandHeight</a> to `true` to let the parentheses grow around a tall operand, or to `false` to keep them at their normal size. <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathdelimiter/delimitershape/" target="_blank" rel="nofollow noopener noreferrer">DelimiterShape</a> takes one of two <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathdelimitershape/" target="_blank" rel="nofollow noopener noreferrer">MathDelimiterShape</a> values. `Centered` centers the parentheses on the math axis, which runs through the middle of the equals sign. `Match` aligns them with the enclosed content. Both settings affect only the delimiters. The expression inside stays the same.

The example places a fraction in the exponent of `x` so the expression extends farther above the baseline than below it. All four equations use the same parentheses and font settings.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

void AddExpression(float left, float top, bool grow, MathDelimiterShape shape)
{
    var fraction = new MathematicalText("a + b").Divide("c + d");
    var power = new MathematicalText("x").SetSuperscript(fraction);
    var delimiter = power.Enclose('(', ')');
    delimiter.GrowToMatchOperandHeight = grow;
    delimiter.DelimiterShape = shape;

    var mathShape = slide.Shapes.AddMathShape(left, top, 300, 100);
    var portion = (MathPortion)mathShape.TextFrame.Paragraphs[0].Portions[0];
    portion.PortionFormat.FontHeight = 32;
    var equation = new MathematicalText("y = ").Join(delimiter);
    portion.MathParagraph.Add(equation);
}

AddExpression(20, 20, true, MathDelimiterShape.Centered);
AddExpression(350, 20, true, MathDelimiterShape.Match);
AddExpression(20, 140, false, MathDelimiterShape.Centered);
AddExpression(350, 140, false, MathDelimiterShape.Match);

presentation.Save("delimiter-sizing.pptx", SaveFormat.Pptx);
```

In PowerPoint, compare the rows to see the effect of growth. In the top row, the parentheses grow to enclose the exponent and look alike for both shapes. In the bottom row, growth is off. The smaller parentheses on the left (`Centered`) align with the equals sign, while those on the right (`Match`) sit higher around the expression.

## **Add a Border Box**

Call <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/toborderbox/" target="_blank" rel="nofollow noopener noreferrer">ToBorderBox</a> on a fraction to frame the entire expression. The returned <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/" target="_blank" rel="nofollow noopener noreferrer">IMathBorderBox</a> shows all four sides by default. Use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/hidetop/" target="_blank" rel="nofollow noopener noreferrer">HideTop</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/hidebottom/" target="_blank" rel="nofollow noopener noreferrer">HideBottom</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/hideleft/" target="_blank" rel="nofollow noopener noreferrer">HideLeft</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/hideright/" target="_blank" rel="nofollow noopener noreferrer">HideRight</a> to remove individual sides.

The example places six copies of the same fraction on one slide. To show cancellation, hide all four sides and set <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/strikethroughbottomlefttotopright/" target="_blank" rel="nofollow noopener noreferrer">StrikethroughBottomLeftToTopRight</a> for a rising diagonal (↗) or <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/strikethroughtoplefttobottomright/" target="_blank" rel="nofollow noopener noreferrer">StrikethroughTopLeftToBottomRight</a> for a falling diagonal (↘). You can also use <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/strikethroughhorizontal/" target="_blank" rel="nofollow noopener noreferrer">StrikethroughHorizontal</a> or <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathborderbox/strikethroughvertical/" target="_blank" rel="nofollow noopener noreferrer">StrikethroughVertical</a> with any combination of visible sides.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(540, 220, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

IMathBorderBox AddFraction(float x, float y, bool hideBorder = false)
{
    var fraction = new MathematicalText("x+1").Divide("y+2");
    var box = fraction.ToBorderBox();
    box.HideTop = box.HideBottom = box.HideLeft = box.HideRight = hideBorder;

    var shape = slide.Shapes.AddMathShape(x, y, 160, 90);
    var portion = (MathPortion)shape.TextFrame.Paragraphs[0].Portions[0];
    portion.PortionFormat.FontHeight = 28;
    portion.MathParagraph.Add(new MathBlock(box));
    return box;
}

AddFraction(10, 10);

var partial = AddFraction(190, 10);
partial.HideTop = true;
partial.HideRight = true;

AddFraction(370, 10, hideBorder: true).StrikethroughBottomLeftToTopRight = true;
AddFraction(10, 120, hideBorder: true).StrikethroughTopLeftToBottomRight = true;
AddFraction(190, 120, hideBorder: true).StrikethroughHorizontal = true;
AddFraction(370, 120).StrikethroughVertical = true;

presentation.Save("border-box.pptx", SaveFormat.Pptx);
```

![Six editable fractions in PowerPoint. Top row: full border, bottom and left sides, rising diagonal. Bottom row: falling diagonal, horizontal strike, vertical strike with a full border.](/net/slides/images/49cae5fcd9d35081-border-box-fractions.png)

On this fraction, the horizontal strike overlaps the fraction bar. The vertical strike crosses both the numerator and the denominator while the surrounding border stays visible. These lines decorate the whole expression. Ordinary text strikethrough applies to characters in a text run. After reopening the presentation in PowerPoint, you can still edit the numerator and denominator independently.

## **Control Visibility and Layout with Phantom Elements**

Wrap an expression in <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathphantom/" target="_blank" rel="nofollow noopener noreferrer">MathPhantom</a> to control its visibility and the space it contributes to an equation independently. The <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/" target="_blank" rel="nofollow noopener noreferrer">IMathPhantom</a> properties control the following:

<div className="docs-owner-markdown-table">

| Property | Effect |
| --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/show/" target="_blank" rel="nofollow noopener noreferrer">Show</a> | Set to `false` to hide the expression. Its dimensions still contribute to layout unless the corresponding properties below are `true`. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/zerowidth/" target="_blank" rel="nofollow noopener noreferrer">ZeroWidth</a> | Treat the expression's horizontal width as zero, allowing neighboring elements to move closer together. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/zeroasc/" target="_blank" rel="nofollow noopener noreferrer">ZeroAsc</a> | Treat its ascent, the height above the baseline, as zero. This can reduce the space reserved above neighboring elements. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/zerodesc/" target="_blank" rel="nofollow noopener noreferrer">ZeroDesc</a> | Treat its descent, the depth below the baseline, as zero. This can move a fraction bar or other content below the expression closer to its neighbors. |

</div>

The baseline is the reference line on which ordinary mathematical letters sit. Hiding content does not remove its dimensions, and treating a dimension as zero does not delete the expression. The underlying expression remains available through <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/base/" target="_blank" rel="nofollow noopener noreferrer">Base</a>. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathphantom/show/" target="_blank" rel="nofollow noopener noreferrer">Show</a> back to `true` to display it again; the dimension settings remain unchanged.

The example below creates five side-by-side variants: a visible fraction, a hidden fraction that reserves space, and three hidden fractions with one dimension treated as zero. Each variant uses the same surrounding expression and Cambria Math at 24 points. All equation shapes have the same top position, marked by the gray guide. Placing the phantom in the numerator of an outer fraction makes the vertical layout changes easier to see.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation();
presentation.SlideSize.SetSize(1000, 180, SlideSizeScaleType.DoNotScale);
var slide = presentation.Slides[0];

var labels = new[] { "Visible", "Hidden: reserves space", "Hidden: ZeroWidth", "Hidden: ZeroAsc", "Hidden: ZeroDesc" };

var guide = slide.Shapes.AddAutoShape(ShapeType.Line, 10, 60, 980, 0);
guide.LineFormat.FillFormat.FillType = FillType.Solid;
guide.LineFormat.FillFormat.SolidFillColor.Color = System.Drawing.Color.LightGray;

for (var i = 0; i < labels.Length; i++)
{
    var left = 10 + i * 200;
    
    var label = slide.Shapes.AddAutoShape(ShapeType.Rectangle, left, 10, 190, 30);
    label.FillFormat.FillType = FillType.NoFill;
    label.LineFormat.FillFormat.FillType = FillType.NoFill;
    label.TextFrame.Text = labels[i];

    var labelFormat = label.TextFrame.Paragraphs[0].Portions[0].PortionFormat;
    labelFormat.FontHeight = 14;
    labelFormat.FillFormat.FillType = FillType.Solid;
    labelFormat.FillFormat.SolidFillColor.Color = System.Drawing.Color.Black;

    var fraction = new MathFraction(CreateText("a+b"), CreateText("c+d"));
    var phantom = new MathPhantom(fraction);
    phantom.Show = i == 0;
    phantom.ZeroWidth = i == 2;
    phantom.ZeroAsc = i == 3;
    phantom.ZeroDesc = i == 4;

    var numerator = new MathBlock(CreateText("x+")).Join(phantom).Join(CreateText("+y"));
    var equation = new MathFraction(numerator, CreateText("z"));

    var shape = slide.Shapes.AddMathShape(left, 60, 190, 100);
    shape.TextFrame.TextFrameFormat.AnchoringType = TextAnchorType.Top;

    var mathParagraph = ((IMathPortion)shape.TextFrame.Paragraphs[0].Portions[0]).MathParagraph;
    mathParagraph.Add(new MathBlock(equation));
}

presentation.Save("math-phantom.pptx", SaveFormat.Pptx);

MathematicalText CreateText(string value)
{
    var text = new MathematicalText(value);
    text.Format.FontHeight = 24;
    text.Format.LatinFont = new FontData("Cambria Math");
    return text;
}
```

![Five equations in PowerPoint comparing a visible fraction, a hidden fraction that reserves space, and hidden fractions with ZeroWidth, ZeroAsc, or ZeroDesc enabled](/net/slides/images/10f45a9759cd8dfd-math-phantom.png)

### **Format Text in an Existing Equation**

To format text throughout an existing equation, traverse each math block's element tree. <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathelement/getchildren/" target="_blank" rel="nofollow noopener noreferrer">IMathElement.GetChildren</a> returns only the immediate children, so call it recursively to reach text inside fractions, scripts, radicals, and other nested structures. Check the current element as well as its children to include the starting element when it is <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a>.

This example assumes that a presentation contains an equation such as `z = xᵢ / ∛y`, with a fraction containing a subscript in its numerator and a radical in its denominator. Processing only the block's top-level elements would miss the text inside the fraction. The example finds mathematical portions in slide text frames, accesses their blocks through <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathportion/mathparagraph/" target="_blank" rel="nofollow noopener noreferrer">IMathPortion.MathParagraph</a>, and sets <a href="https://reference.aspose.com/slides/net/aspose.slides/baseportionformat/fontheight/" target="_blank" rel="nofollow noopener noreferrer">FontHeight</a> to 28 points through each text element's <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathematicaltext/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> property.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.MathText;

using var presentation = new Presentation("input.pptx");

foreach (var slide in presentation.Slides)
{
    foreach (var shape in slide.Shapes)
    {
        if (shape is not IAutoShape autoShape || autoShape.TextFrame == null)
            continue;

        foreach (var paragraph in autoShape.TextFrame.Paragraphs)
        {
            foreach (var portion in paragraph.Portions)
            {
                if (portion is IMathPortion mathPortion)
                {
                    foreach (var block in mathPortion.MathParagraph)
                        FormatMathText(block);
                }
            }
        }
    }
}

presentation.Save("formatted-equations.pptx", SaveFormat.Pptx);

void FormatMathText(IMathElement element)
{
    if (element is MathematicalText text)
        text.Format.FontHeight = 28;

    foreach (var child in element.GetChildren())
        FormatMathText(child);
}
```

The saved presentation contains the updated text formatting at every level of each processed equation, while preserving its text content and mathematical structure.

## **FAQ**

**Can I edit an existing PowerPoint equation?**

Yes. Open the presentation, find the shape that contains a <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a>, get its <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/mathparagraph/" target="_blank" rel="nofollow noopener noreferrer">MathParagraph</a>, and update the math blocks in that paragraph.

**Are equations saved as editable PowerPoint math?**

Yes. When you save to PPTX, Aspose.Slides writes the equation as editable Office math content.

**Can I export equations to LaTeX?**

Yes. Get the equation's <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathparagraph/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph</a> from its <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a>, and call <a href="https://reference.aspose.com/slides/net/aspose.slides.mathtext/imathparagraph/tolatex/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph.ToLatex</a> to export it directly. For a complete example, see [Export Math Equations from Presentations in .NET](/net/slides/exporting-math-equations/#export-math-equations-to-latex).

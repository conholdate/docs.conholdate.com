## **Introduction**

Aspose.Slides for .NET can turn PDF pages or HTML content into PowerPoint slides without Microsoft PowerPoint. The <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection</a> class provides <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">AddFromPdf</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfromhtml/" target="_blank" rel="nofollow noopener noreferrer">AddFromHtml</a> for appending imported content to a presentation.

For more control over HTML placement, <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/insertfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.InsertFromHtml</a> can insert generated slides at a collection index or begin filling available space on an existing slide. Long HTML is paginated across additional slides automatically, the source can be supplied as a string or stream, and external assets can be loaded through <a href="https://reference.aspose.com/slides/net/aspose.slides.import/iexternalresourceresolver/" target="_blank" rel="nofollow noopener noreferrer">IExternalResourceResolver</a> with a base URI. The returned <a href="https://reference.aspose.com/slides/net/aspose.slides/islide/" target="_blank" rel="nofollow noopener noreferrer">ISlide</a> array identifies the affected and newly created slides.

## **Import from PDF**

To convert a PDF document to a PowerPoint presentation, import its content into the slide collection and save the result as a PPTX file.

![pdf-to-powerpoint](/net/slides/images/edb12355e7340c85-pdf-to-powerpoint.png)

1. Create a new <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> object.
2. Call <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">AddFromPdf</a> with the path to the PDF file.
3. Call <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Save</a> with <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat.Pptx</a> to write the presentation to a PPTX file.

The following C# example imports a PDF document and saves the generated slides as a PowerPoint presentation:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.Slides.AddFromPdf("document.pdf");
presentation.Save("presentation.pptx", SaveFormat.Pptx);
```

The <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">AddFromPdf</a> method returns the slides it adds, which is useful when you need to process only the imported slides.

Try the free <a href="https://products.conholdate.app/conversion/pdf-to-pptx" target="_blank">PDF to PowerPoint</a> web app to see this conversion workflow in action.

## **Import from HTML**

Aspose.Slides can also create slides from an HTML document. The source can be supplied as HTML text, a text reader, or a stream. The following steps use a file stream:

1. Create a new <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> object.
2. Open the HTML file for reading and pass the stream to <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfromhtml/" target="_blank" rel="nofollow noopener noreferrer">AddFromHtml</a>.
3. Call <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Save</a> with <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat.Pptx</a> to write the result to a PPTX file.

The following C# example imports an HTML document and saves the generated slides as a PowerPoint presentation:

```csharp
using System.IO;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
using var htmlStream = File.OpenRead("page.html");
presentation.Slides.AddFromHtml(htmlStream);
presentation.Save("presentation.pptx", SaveFormat.Pptx);
```

## **Insert HTML Content**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/insertfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.InsertFromHtml</a> when HTML-generated slides must be placed at a specific position instead of appended. The index is zero-based and identifies the position at which the import starts. The method is also available through <a href="https://reference.aspose.com/slides/net/aspose.slides/islidecollection/" target="_blank" rel="nofollow noopener noreferrer">ISlideCollection</a>.

The `useSlideWithIndexAsStart` argument controls how the importer uses that position:

- When it is `false`, the importer creates new slides at the specified index and shifts the slides that follow them.
- When it is `true`, the importer starts placing content in the available space on the existing slide at that index. If the HTML does not fit, Aspose.Slides paginates it automatically and inserts additional slides immediately after the starting slide.

<a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/insertfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.InsertFromHtml</a> returns an array of <a href="https://reference.aspose.com/slides/net/aspose.slides/islide/" target="_blank" rel="nofollow noopener noreferrer">ISlide</a> objects. When insertion starts on new slides, every returned item is newly created. When an existing slide is used as the start, the array includes that affected slide followed by any new overflow slides. You can inspect this array instead of calculating the affected range from the presentation's slide count.

### **Insert HTML as New Slides**

The following example supplies HTML as a string and inserts the generated slides at collection index `1`. Passing `false` leaves the existing slides unchanged except for shifting them to make room.

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var layoutSlide = presentation.LayoutSlides[0];
presentation.Slides.AddEmptySlide(layoutSlide);
presentation.Slides.AddEmptySlide(layoutSlide);

var insertIndex = 1;
var html = "<html><body><h1>Quarterly update</h1><p>This content is inserted before the slide that was at index 1.</p></body></html>";
var insertedSlides = presentation.Slides.InsertFromHtml(insertIndex, html, useSlideWithIndexAsStart: false);

foreach (var slide in insertedSlides)
{
    Console.WriteLine($"Inserted slide index: {presentation.Slides.IndexOf(slide)}");
}

presentation.Save("presentation-with-inserted-html.pptx", SaveFormat.Pptx);
```

### **Start on an Existing Slide**

The next example supplies the HTML through a stream. It keeps a header shape on the existing template slide, starts importing below the occupied area, and lets the long body continue onto new slides.

The HTML also contains a relative image URL. An <a href="https://reference.aspose.com/slides/net/aspose.slides.import/iexternalresourceresolver/" target="_blank" rel="nofollow noopener noreferrer">IExternalResourceResolver</a> obtains the resource, while the base URI tells the importer how to resolve `images/logo.png`. In this example, that file is expected at `html-assets/images/logo.png`.

```csharp
using System;
using System.IO;
using System.Text;
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.Import;

using var presentation = new Presentation();
var templateSlide = presentation.Slides[0];
var header = templateSlide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 680, 60);
header.TextFrame.Text = "Product roadmap";

var htmlBuilder = new StringBuilder("<html><body><img src='images/logo.png' width='120' height='60'><h2>Roadmap details</h2>");
for (var itemIndex = 1; itemIndex <= 60; itemIndex++)
{
    htmlBuilder.Append($"<p style='font-size:24pt'>Roadmap item {itemIndex}: detailed implementation notes.</p>");
}
htmlBuilder.Append("</body></html>");

var html = htmlBuilder.ToString();
var htmlData = Encoding.UTF8.GetBytes(html);
using var htmlStream = new MemoryStream(htmlData);
var resolver = new ExternalResourceResolver();
var basePath = Path.GetFullPath("html-assets") + Path.DirectorySeparatorChar;
var baseUri = new Uri(basePath).AbsoluteUri;
var affectedSlides = presentation.Slides.InsertFromHtml(0, htmlStream, resolver, baseUri, useSlideWithIndexAsStart: true);

foreach (var slide in affectedSlides)
{
    Console.WriteLine($"Affected slide index: {presentation.Slides.IndexOf(slide)}");
}

presentation.Save("presentation-with-html-overflow.pptx", SaveFormat.Pptx);
```

An unrestricted external resource resolver can read local or network resources referenced by the HTML. For untrusted input, implement <a href="https://reference.aspose.com/slides/net/aspose.slides.import/iexternalresourceresolver/" target="_blank" rel="nofollow noopener noreferrer">IExternalResourceResolver</a> with an allowlist for permitted schemes, directories, and hosts, and reject all other URIs.

## **FAQ**

**Can Aspose.Slides detect tables when importing a PDF?**

Yes. Create a <a href="https://reference.aspose.com/slides/net/aspose.slides.import/pdfimportoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfImportOptions</a> object, set its <a href="https://reference.aspose.com/slides/net/aspose.slides.import/pdfimportoptions/detecttables/" target="_blank" rel="nofollow noopener noreferrer">DetectTables</a> property to `true`, and pass the options to <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">AddFromPdf</a>. The quality of table recognition depends on the structure and complexity of the source PDF.

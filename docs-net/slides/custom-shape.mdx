> Create and customize shapes in PowerPoint presentations with Aspose.Slides for .NET: geometry paths, curved corners, composite shapes.
> 2

## **Overview**

This article explains how to customize presentation shapes in Aspose.Slides by editing shape geometry through edit points and geometry paths. It shows how to work with <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath</a> to modify existing shapes, perform basic path editing operations, add or remove points, and apply updated geometry back to a shape.

It also demonstrates how to create custom and composite shapes, build shapes with curved corners, determine whether a shape geometry is closed, and use the legacy conversion between <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> and <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath" target="_blank" rel="nofollow noopener noreferrer">GraphicsPath</a> for additional geometry customization scenarios.

## **Change a Shape Using Edit Points**

In PowerPoint, you can use **Edit Points** to modify a square:

- Move a corner inward or outward.
- Adjust the curvature at a point.
- Add new points.

Editing points lets you modify a shape's outline or use an existing shape as the basis for a new one.

## **Shape Editing Tips**

![overview_image](/net/slides/images/07c2b5a10b37891d-custom_shape_0.png)

When editing PowerPoint shapes, keep these concepts in mind:

- A shape (or its path) can either be closed or open.
- A shape's path consists of anchor points connected by segments.
- A segment can be straight or curved. Anchor points and control handles determine its shape.
- Anchor points exist as corner points, straight points, or smooth points:
  - At a corner point, adjoining segments can meet at an angle.
  - At a smooth point, the two control handles are aligned and equally distant from the anchor point.
  - At a straight point, the two control handles are aligned but can be different distances from the anchor point.
- Moving anchor points or adjusting their handles changes the shape's outline.

To edit PowerPoint shapes through edit points, **Aspose.Slides** provides the <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> class and <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath</a> interface.

- A <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> instance represents a geometry path of the <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape</a> object.
- To retrieve the <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> from the <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape</a> instance, you can use the <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/getgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.GetGeometryPaths</a> method.
- To set the <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> for a shape, you can use these methods: <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPath</a> for shapes with a single path and <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPaths</a> for shapes with multiple paths.
- To add segments, you can use the methods under <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath</a>.
- Using the <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/stroke/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath.Stroke</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/fillmode/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath.FillMode</a> properties, you can set the appearance for a geometry path.
- Using the <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/pathdata/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath.PathData</a> property, you can retrieve the geometry path of a <a href="https://reference.aspose.com/slides/net/aspose.slides/geometryshape/" target="_blank" rel="nofollow noopener noreferrer">GeometryShape</a> as an array of path segments.
- In legacy versions that support the conversion methods below, you can convert <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> to <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath" target="_blank" rel="nofollow noopener noreferrer">GraphicsPath</a>.
- Use <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/geometrypathtographicspath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPathToGraphicsPath</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/graphicspathtogeometrypath/" target="_blank" rel="nofollow noopener noreferrer">GraphicsPathToGeometryPath</a> methods (from the <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/" target="_blank" rel="nofollow noopener noreferrer">ShapeUtil</a> class) to convert between <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> and <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath" target="_blank" rel="nofollow noopener noreferrer">GraphicsPath</a>.

## **Add Custom Points to a Shape**

This example inserts two points into a rectangular shape using <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/lineto/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath.LineTo</a> and applies the edited path with <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPath</a>. The coordinates are local to the shape: both new points are at its center, 100 points from the left and 50 points from the top. Segment indices 1 and 4 place them on the top and bottom edges, pulling those edges inward.

```csharp
using Aspose.Slides;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 100, 100, 200, 100);

var geometryPath = shape.GetGeometryPaths()[0];
geometryPath.LineTo(100, 50, 1);
geometryPath.LineTo(100, 50, 4);

shape.SetGeometryPath(geometryPath);
```

## **Remove Points from a Shape**

This example changes a heart-shaped outline by removing the segment at zero-based index 2 with <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/removeat/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath.RemoveAt</a>. Applying the modified path with <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPath</a> updates the shape's contour.

```csharp
using Aspose.Slides;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Heart, 100, 100, 300, 300);

var path = shape.GetGeometryPaths()[0];
path.RemoveAt(2);

shape.SetGeometryPath(path);
```

## **Create a Custom Shape**

This example builds a five-pointed star with <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a>. Alternating outer and inner radii of 100 and 50 points define the tips and indentations; a 72-degree step spaces the five tips evenly. The path is closed with <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/closefigure/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath.CloseFigure</a> and applied to a rectangular shape using <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPath</a>, replacing its outline.

```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using Aspose.Slides;

var points = new List<PointF>();

var outerRadius = 100f;
var innerRadius = 50f;
var angleStep = 72;

for (var angle = -90; angle < 270; angle += angleStep)
{
    var radians = angle * (Math.PI / 180f);
    var x = outerRadius * Math.Cos(radians);
    var y = outerRadius * Math.Sin(radians);
    points.Add(new PointF((float)x + outerRadius, (float)y + outerRadius));

    radians = Math.PI * (angle + angleStep / 2) / 180.0;
    x = innerRadius * Math.Cos(radians);
    y = innerRadius * Math.Sin(radians);
    points.Add(new PointF((float)x + outerRadius, (float)y + outerRadius));
}

var starPath = new GeometryPath();
starPath.MoveTo(points[0]);

for (var i = 1; i < points.Count; i++)
{
    starPath.LineTo(points[i]);
}

starPath.CloseFigure();

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 100, 100, outerRadius * 2, outerRadius * 2);
shape.SetGeometryPath(starPath);
```

## **Create a Composite Custom Shape**

This example defines two closed <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath</a> objects for the top and bottom thirds of a shape. Applying both paths with <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPaths</a> creates a single composite shape with a gap across its middle third.

```csharp
using Aspose.Slides;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 100, 100, 200, 100);

var topPath = new GeometryPath();
topPath.MoveTo(0, 0);
topPath.LineTo(shape.Width, 0);
topPath.LineTo(shape.Width, shape.Height / 3);
topPath.LineTo(0, shape.Height / 3);
topPath.CloseFigure();

var bottomPath = new GeometryPath();
bottomPath.MoveTo(0, shape.Height / 3 * 2);
bottomPath.LineTo(shape.Width, shape.Height / 3 * 2);
bottomPath.LineTo(shape.Width, shape.Height);
bottomPath.LineTo(0, shape.Height);
bottomPath.CloseFigure();

shape.SetGeometryPaths(new GeometryPath[] { topPath, bottomPath });
```

## **Create a Custom Shape with Curved Corners**

This example combines straight segments with <a href="https://reference.aspose.com/slides/net/aspose.slides/geometrypath/arcto/" target="_blank" rel="nofollow noopener noreferrer">GeometryPath.ArcTo</a> to create a shape with inward-curved corners. Each corner size sets the arc's width and height in points, and the -90-degree sweep draws a counterclockwise quarter ellipse. The completed path is applied with <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPath</a>, and the presentation is saved in PPTX format.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

var shapeX = 20f;
var shapeY = 20f;
var shapeWidth = 300f;
var shapeHeight = 200f;

var leftTopSize = 50f;
var rightTopSize = 20f;
var rightBottomSize = 40f;
var leftBottomSize = 10f;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var topLeft = new PointF(leftTopSize, 0);
var topRight = new PointF(shapeWidth - rightTopSize, 0);
var rightBottom = new PointF(shapeWidth, shapeHeight - rightBottomSize);
var bottomLeft = new PointF(leftBottomSize, shapeHeight);
var leftTop = new PointF(0, leftTopSize);

var geometryPath = new GeometryPath();
geometryPath.MoveTo(topLeft);
geometryPath.LineTo(topRight);
geometryPath.ArcTo(rightTopSize, rightTopSize, 180, -90);
geometryPath.LineTo(rightBottom);
geometryPath.ArcTo(rightBottomSize, rightBottomSize, -90, -90);
geometryPath.LineTo(bottomLeft);
geometryPath.ArcTo(leftBottomSize, leftBottomSize, 0, -90);
geometryPath.LineTo(leftTop);
geometryPath.ArcTo(leftTopSize, leftTopSize, 90, -90);
geometryPath.CloseFigure();

var shape = slide.Shapes.AddAutoShape(ShapeType.Custom, shapeX, shapeY, shapeWidth, shapeHeight);
shape.SetGeometryPath(geometryPath);

presentation.Save("output.pptx", SaveFormat.Pptx);
```

## **Find Out If a Shape Geometry Is Closed**

The following helper checks whether every nonempty geometry path ends with a closing segment. It reads <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/pathdata/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath.PathData</a> and compares the final segment's <a href="https://reference.aspose.com/slides/net/aspose.slides/ipathsegment/pathcommand/" target="_blank" rel="nofollow noopener noreferrer">IPathSegment.PathCommand</a> with <a href="https://reference.aspose.com/slides/net/aspose.slides/pathcommandtype/" target="_blank" rel="nofollow noopener noreferrer">PathCommandType.Close</a>. It returns false when there are no nonempty paths. This checks the final command of each path; it does not inspect every subfigure within a path. The example prints `True` for a rectangle.

```csharp
using System;
using Aspose.Slides;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 100, 100, 200, 100);
Console.WriteLine(IsGeometryClosed(shape));

bool IsGeometryClosed(IGeometryShape geometryShape)
{
    var hasNonemptyPath = false;

    foreach (var geometryPath in geometryShape.GetGeometryPaths())
    {
        var segments = geometryPath.PathData;
        if (segments.Length == 0)
        {
            continue;
        }

        hasNonemptyPath = true;
        var lastSegment = segments[segments.Length - 1];
        if (lastSegment.PathCommand != PathCommandType.Close)
        {
            return false;
        }
    }

    return hasNonemptyPath;
}
```

## **Extract and Inspect Shape Elements**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/createshapeelements/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.CreateShapeElements</a> to inspect an existing shape as elements containing path points and point types. Cast each returned <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapeelement/" target="_blank" rel="nofollow noopener noreferrer">IShapeElement</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/shapeelement/" target="_blank" rel="nofollow noopener noreferrer">ShapeElement</a> to read its <a href="https://reference.aspose.com/slides/net/aspose.slides/shapeelement/pathpoints/" target="_blank" rel="nofollow noopener noreferrer">PathPoints</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/shapeelement/pathtypes/" target="_blank" rel="nofollow noopener noreferrer">PathTypes</a> arrays. This representation is useful for contour analysis or passing geometry to custom drawing tools.

The example opens a presentation, finds the first geometry shape directly on the first slide, and prints its path segments. Use a presentation containing a shape with straight and curved segments to see both kinds of output. It does not search inside groups.

```csharp
using System;
using System.Linq;
using Aspose.Slides;

using var presentation = new Presentation("input.pptx");
var slide = presentation.Slides[0];

var shape = slide.Shapes.OfType<IGeometryShape>().FirstOrDefault();
if (shape == null)
{
    Console.WriteLine("No geometry shape found on the first slide.");
    return;
}

foreach (IShapeElement element in shape.CreateShapeElements())
{
    var shapeElement = (ShapeElement)element;
    var points = shapeElement.PathPoints;
    var types = shapeElement.PathTypes;
    Console.WriteLine("Shape element:");

    for (var i = 0; i < points.Length; i++)
    {
        var pointType = types[i] & 0x07; // Keep the segment type, excluding flags.
        switch (pointType)
        {
            case 0:
                Console.WriteLine($"Start figure at {points[i]}");
                break;
            case 1:
                Console.WriteLine($"Line to {points[i]}");
                break;
            case 3:
                Console.WriteLine($"Cubic Bezier: controls {points[i]}, {points[i + 1]}; end {points[i + 2]}");
                i += 2; // Consume both control points and the endpoint.
                break;
        }

        if ((types[i] & 0x80) != 0)
        {
            Console.WriteLine("Close subpath back to its starting point.");
        }
    }
}
```

The arrays correspond by index: `points[i]` is a point and `types[i]` describes its role. Type `0` starts a figure, and type `1` draws a line from the previous point to the current point. A cubic Bézier segment starts at the previous endpoint and uses three consecutive type-`3` entries: two control points followed by the new endpoint. The loop consumes these three entries together and checks the endpoint for closure.

Point types also contain flags. Mask with `0x07` to identify the segment type, and test `0x80` separately to detect a closed subpath. For example, `129` (`0x81`) means a line endpoint that closes a subpath, and `131` (`0x83`) means a Bézier endpoint that closes one. Comparing the raw value only with `1` or `3` would miss these cases. Other flags, such as dash (`0x10`) and marker (`0x20`), do not change the base segment type.

**Coordinates and transformations.** Points are measured in points (1/72 inch), with X increasing to the right and Y increasing downward. For an ungrouped shape, the extracted coordinates already include its <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/x/" target="_blank" rel="nofollow noopener noreferrer">X</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/y/" target="_blank" rel="nofollow noopener noreferrer">Y</a> position and reflect its current width and height. For example, an unrotated rectangle at `(100, 200)` with size `120 × 80` has contour bounds `(100, 200)`-`(220, 280)`. Do not add the shape's position again. Subtract its X and Y to obtain coordinates relative to its unrotated frame.

The extracted points do not apply the shape's <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/rotation/" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> or horizontal and vertical flips. To reproduce the displayed contour, apply those transformations around the shape's center. For grouped shapes, also account for the group coordinate mapping and transformations; do not assume that the extracted points are the final rendered slide coordinates or apply a translation or scale twice if it is already reflected in the child's frame.

**Inspection versus editing.** Extracted arrays describe the contour; changing them does not update the original shape. Choose this approach when your analysis or drawing code needs point/type arrays. Use <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/getgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">GetGeometryPaths</a> when you need geometry commands in the shape's local coordinate system or want to edit its geometry. Apply edited paths through <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypath/" target="_blank" rel="nofollow noopener noreferrer">SetGeometryPath</a> or <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">SetGeometryPaths</a>.

## **Convert GeometryPath to GraphicsPath (System.Drawing.Drawing2D)**

The following example requires a legacy Aspose.Slides for .NET assembly that supports <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/graphicspathtogeometrypath/" target="_blank" rel="nofollow noopener noreferrer">ShapeUtil.GraphicsPathToGeometryPath</a>, such as version 25.10, and a Windows environment with `System.Drawing.Common`. The conversion methods were removed in <a href="https://releases.aspose.com/slides/net/release-notes/2025/aspose-slides-for-net-25-11-release-notes/" target="_blank" rel="nofollow noopener noreferrer">version 25.11</a>.

This example combines a rectangular outline with text converted to geometry. The outline's <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometrypath/fillmode/" target="_blank" rel="nofollow noopener noreferrer">IGeometryPath.FillMode</a> is set to disable its fill. A <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath" target="_blank" rel="nofollow noopener noreferrer">GraphicsPath</a> stores the text outline, which <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/graphicspathtogeometrypath/" target="_blank" rel="nofollow noopener noreferrer">ShapeUtil.GraphicsPathToGeometryPath</a> converts to a filled geometry path. Applying both paths with <a href="https://reference.aspose.com/slides/net/aspose.slides/igeometryshape/setgeometrypaths/" target="_blank" rel="nofollow noopener noreferrer">IGeometryShape.SetGeometryPaths</a> produces a single shape containing the rectangle and text. For conversion in the opposite direction, use <a href="https://reference.aspose.com/slides/net/aspose.slides.util/shapeutil/geometrypathtographicspath/" target="_blank" rel="nofollow noopener noreferrer">ShapeUtil.GeometryPathToGraphicsPath</a>.

```csharp
using System.Drawing;
using System.Drawing.Drawing2D;
using Aspose.Slides;
using Aspose.Slides.Util;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 100, 100, 300, 100);

var originalPath = shape.GetGeometryPaths()[0];
originalPath.FillMode = PathFillModeType.None;

using var graphicsPath = new GraphicsPath();
using var fontFamily = new FontFamily("Arial");
using var stringFormat = StringFormat.GenericDefault;

graphicsPath.AddString("Text in shape", fontFamily, (int)FontStyle.Bold, 40, new PointF(10, 10), stringFormat);

var textPath = ShapeUtil.GraphicsPathToGeometryPath(graphicsPath);
textPath.FillMode = PathFillModeType.Normal;

shape.SetGeometryPaths(new[] { originalPath, textPath });
```

## **FAQ**

**What will happen to the fill and outline after replacing the geometry?**

The style remains with the shape; only the contour changes. The fill and outline are automatically applied to the new geometry.

**How do I correctly rotate a custom shape along with its geometry?**

Use the shape's <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/rotation/" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> property; the geometry rotates with the shape because it's bound to the shape's own coordinate system.

**Can I convert a custom shape to an image to "lock in" the result?**

Yes. Export the required [slide](/net/slides/convert-powerpoint-to-png/) area or the [shape](/net/slides/create-shape-thumbnails/) itself to a raster format; this simplifies further work with complex geometries.

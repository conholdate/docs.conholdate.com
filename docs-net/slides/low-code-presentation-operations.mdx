> Use the Aspose.Slides low-code API in .NET to convert and merge presentations, iterate through content, collect shapes, and reduce presentation size.
> 7

## **Overview**

The <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Slides.LowCode</a> namespace provides static helper classes for common presentation operations. These helpers wrap frequently used object-model workflows in focused methods, so you can convert or merge files, process presentation elements, collect shapes, and remove unused content with less code.

Low-code helpers are most useful when the operation applies to an entire file or presentation and the default workflow matches your requirements. Use the full <a href="https://reference.aspose.com/slides/net/aspose.slides/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Slides object model</a> when you need fine-grained control over individual slides, masters, layouts, shapes, export settings, or relationships between presentation elements.

The following table summarizes the available helpers:

<div className="docs-owner-markdown-table">

| Helper | Use it for |
| ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert</a> | Converting a presentation to another format with a direct file-to-file call. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/merger/" target="_blank" rel="nofollow noopener noreferrer">Merger</a> | Combining complete presentation files of the same format. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> | Running an action for every slide, shape, paragraph, or text portion. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/collect/" target="_blank" rel="nofollow noopener noreferrer">Collect</a> | Retrieving shapes from the entire presentation for repeated processing or analysis. |
| <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> | Removing unused masters/layouts, reducing embedded font data and compressing pictures. |

</div>

## **Convert a Presentation**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/convert/autobyextension/" target="_blank" rel="nofollow noopener noreferrer">Convert.AutoByExtension</a> when the output file extension is sufficient to select the export format. The method opens the source presentation, determines the required format from the output path, and writes the result.

```csharp
using Aspose.Slides.LowCode;

Convert.AutoByExtension("input.pptx", "output.pdf");
```

The <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert</a> class also provides dedicated methods for PDF, SVG, JPEG, PNG, and TIFF output. Use the full object model when you need to inspect or modify the presentation before export or configure an export option that is not exposed by the selected helper. See [Convert Presentation](/net/slides/convert-presentation/) for format-specific workflows and options.

## **Merge Presentations**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/merger/process/" target="_blank" rel="nofollow noopener noreferrer">Merger.Process</a> to combine complete presentation files with one call. The input presentations must have the same file format.

```csharp
using Aspose.Slides.LowCode;

var inputFiles = new[] { "part-1.pptx", "part-2.pptx" };
Merger.Process(inputFiles, "merged.pptx");
```

The helper is appropriate when all slides should be appended to one result without selecting or remapping them individually. Use the full object model when you need to merge selected slides, apply a destination master or layout, preserve sections explicitly, or reconcile different slide sizes. See [Merge Presentations](/net/slides/merge-presentation/) for those scenarios.

## **Iterate Through Presentation Elements**

The <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> class invokes a callback for each requested type of presentation element. It avoids nested collection loops and is convenient for presentation-wide inspection or formatting changes.

The following example uses <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/slide/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Slide</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/shape/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Shape</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/paragraph/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Paragraph</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/portion/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Portion</a> to inspect the corresponding elements:

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.LowCode;

using var presentation = new Presentation("input.pptx");

ForEach.Slide(presentation, (slide, index) =>
{
    Console.WriteLine($"Slide {index}: {slide.Shapes.Count} shapes");
});

ForEach.Shape(presentation, (shape, slide, index) =>
{
    Console.WriteLine($"Shape {index} on {slide.GetType().Name}: {shape.Name}");
});

ForEach.Paragraph(presentation, (paragraph, slide, index) =>
{
    Console.WriteLine($"Paragraph {index} on {slide.GetType().Name}: {paragraph.Text}");
});

ForEach.Portion(presentation, (portion, paragraph, slide, index) =>
{
    Console.WriteLine($"Portion {index} on {slide.GetType().Name}: {portion.Text}");
});
```

By default, presentation-wide shape and text traversal includes normal, master, and layout slides. Overloads with an `includeNotes` parameter can also process notes slides. Use direct collection loops when traversal order, early exit, filtering before callback invocation, or detailed parent-child control is important.

## **Collect Shapes**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/collect/shapes/" target="_blank" rel="nofollow noopener noreferrer">Collect.Shapes</a> when you need a collection of all shapes in a presentation rather than a callback for each shape. This is useful when the same set will be filtered, counted, or processed more than once.

```csharp
using System;
using Aspose.Slides;
using Aspose.Slides.LowCode;

using var presentation = new Presentation("input.pptx");
var shapes = Collect.Shapes(presentation);

foreach (var shape in shapes)
{
    Console.WriteLine($"{shape.Name}: {shape.GetType().Name}");
}
```

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/shape/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Shape</a> instead when each shape can be handled immediately and you do not need to retain the collected result.

## **Compress Presentation Content**

The <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> class can remove unused structural elements and reduce embedded font data:

- <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/removeunusedlayoutslides/" target="_blank" rel="nofollow noopener noreferrer">Compress.RemoveUnusedLayoutSlides</a> removes layout slides that no normal slide references.
- <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/removeunusedmasterslides/" target="_blank" rel="nofollow noopener noreferrer">Compress.RemoveUnusedMasterSlides</a> removes master slides that are no longer used.
- <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/compressembeddedfonts/" target="_blank" rel="nofollow noopener noreferrer">Compress.CompressEmbeddedFonts</a> removes unused characters from embedded fonts.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.LowCode;

using var presentation = new Presentation("input.pptx");

Compress.RemoveUnusedLayoutSlides(presentation);
Compress.RemoveUnusedMasterSlides(presentation);
Compress.CompressEmbeddedFonts(presentation);

presentation.Save("compressed.pptx", SaveFormat.Pptx);
```

Remove unused layouts before unused masters so a master that becomes unreferenced after layout cleanup can also be removed. Save the optimized presentation to a new file if you may need the original masters, layouts, or complete embedded font data later. For more detail, see [Slide Master](/net/slides/slide-master/) and [Embedded Font](/net/slides/embedded-font/).

### **Compress the Whole Presentation**

Aspose.Slides for .NET 26.11 adds <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/compresspresentation/" target="_blank" rel="nofollow noopener noreferrer">Compress.CompressPresentation</a>. It combines removal of unused layout/master slides, subsetting of embedded fonts to used characters, and picture compression at 150 DPI. Use the individual operations above when you need to control which changes are applied.

Install [Aspose.Slides for .NET](/net/slides/installation/) 26.11 or later and provide `input.pptx`. Save to a separate file: removed layouts, font characters and cropped picture pixels may be needed for later editing.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.LowCode;

using var presentation = new Presentation("input.pptx");
Compress.CompressPresentation(presentation);
presentation.Save("compressed.pptx", SaveFormat.Pptx);
```

### **Compress Images at a Chosen Resolution**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/compressimages/" target="_blank" rel="nofollow noopener noreferrer">Compress.CompressImages</a> to process eligible pictures without also removing layouts or subsetting fonts. This example uses 96 DPI; select another <a href="https://reference.aspose.com/slides/net/aspose.slides.export/picturescompression/" target="_blank" rel="nofollow noopener noreferrer">PicturesCompression</a> value for your output needs.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;
using Aspose.Slides.LowCode;

using var presentation = new Presentation("input.pptx");
Compress.CompressImages(presentation, PicturesCompression.Dpi96);
presentation.Save("compressed-images.pptx", SaveFormat.Pptx);
```

Both helpers use the following picture-processing scope:

<div className="docs-owner-markdown-table">

| Content | Treatment |
| ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Raster pictures and shape picture fills on normal, master and layout slides, including grouped shapes | Eligible for compression. |
| Pictures already at or below the requested resolution | Not upscaled. Cropped areas can still be removed. |
| Cropped picture areas | Hidden pixels are permanently removed and crop offsets are reset. |
| Slide backgrounds and table-cell fills | Not processed by these helpers. |
| Chart/SmartArt internals, GIF and vector formats such as SVG, EMF and WMF | Outside the documented image-compression scope. |

</div>

In 26.11, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/picturescompression/" target="_blank" rel="nofollow noopener noreferrer">PicturesCompression.DocumentResolution</a> avoids resolution-based downsampling of an uncropped picture, but **does not preserve cropped pixels**. A cropped picture can still be rewritten with its hidden areas removed. Neither helper exposes a preserve-crop option. For individual control, see the <a href="https://docs.aspose.com/slides/net/examples/optimization-batch/compression/" target="_blank" rel="nofollow noopener noreferrer">per-picture compression example</a>.

Compare the output's appearance and file size before replacing the original. Savings depend on the source pictures, their displayed size and unused content; compression does not guarantee a smaller file. See [Embedded Fonts](/net/slides/embedded-font/) for the implications of font subsetting.

## **FAQ**

**When should I use the low-code API instead of the full object model?**

Use low-code helpers when a standard operation applies to a complete file or presentation and does not require detailed control over individual elements. Use the full object model when you need to select specific slides, control master and layout relationships, inspect intermediate state, or configure behavior that the helper does not expose.

**Can Merger combine presentations in different file formats?**

No. <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/merger/process/" target="_blank" rel="nofollow noopener noreferrer">Merger.Process</a> requires input presentations in the same format. Convert the input files to a common format first, for example with <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/convert/autobyextension/" target="_blank" rel="nofollow noopener noreferrer">Convert.AutoByExtension</a>, and then merge the converted files.

**Does ForEach process master, layout, and notes slides?**

<a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/slide/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Slide</a> iterates through normal presentation slides. Presentation-wide <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/shape/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Shape</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/paragraph/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Paragraph</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/portion/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Portion</a> operations include normal, master, and layout slides by default. Use their overloads with `includeNotes` set to `true` to include notes slides.

**What is the difference between ForEach.Shape and Collect.Shapes?**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/shape/" target="_blank" rel="nofollow noopener noreferrer">ForEach.Shape</a> to process each shape immediately through a callback. Use <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/collect/shapes/" target="_blank" rel="nofollow noopener noreferrer">Collect.Shapes</a> when you need an enumerable result that can be retained, filtered, counted, or traversed multiple times.

**Does Compress always make the presentation file smaller?**

Not necessarily. Savings depend on unused layouts/masters, embedded fonts with unused characters, and pictures that benefit from compression. The <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> helpers may leave the size unchanged or produce a larger file for some inputs. Compare both size and rendered quality, and keep the original.

**Are changes made by ForEach or Compress saved automatically?**

No. These helpers operate on the loaded <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> object in memory. After changing elements in a <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> callback or running <a href="https://reference.aspose.com/slides/net/aspose.slides.lowcode/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a>, call <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> to write the result.

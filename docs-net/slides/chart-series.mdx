## **Overview**

A chart can store its plotted values in workbook cells or directly as numeric literals. An <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries</a> represents one set of related values, and each <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint</a> represents a point in that series. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartcategory/" target="_blank" rel="nofollow noopener noreferrer">IChartCategory</a> objects provide the labels or grouping values shared by the series. In charts created with default data, series names, categories, and point values use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatacell/" target="_blank" rel="nofollow noopener noreferrer">IChartDataCell</a> objects from the chart workbook.

For a typical category chart, the default workbook uses row 0 for series names, column 0 for category names, and the remaining cells for series values. Worksheet, row, and column indexes passed to <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/getcell/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook.GetCell</a> are zero-based. This layout is useful when you create a chart with default data, but do not assume that every existing chart uses it. For a loaded presentation, inspect the cells referenced by the series, categories, and data points before changing workbook values.

Chart settings have three different scopes:

- Series-level settings, such as <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/format/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Format</a>, provide the default appearance for all points in one series.
- Data-point settings, such as <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/format/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint.Format</a>, override the series appearance for one point.
- Group settings apply to compatible series that belong to the same <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup</a>. Access the group through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/parentseriesgroup/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.ParentSeriesGroup</a> when you need to set options such as overlap or gap width.

When no explicit point or series fill is set, the chart style and theme determine the automatic appearance. When both series and point formatting are present, the point formatting takes precedence for that point.

For a clustered cylinder chart, see how [changing the 3D series type or bar shape](/net/slides/3d-chart/#change-the-3d-series-type-and-bar-shape) affects the first series.

## **Set Series Values Using Numeric Literals**

Use numeric literals when series values come from application data or calculations and do not need worksheet cell references. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/datasourcetypeforvalues/" target="_blank" rel="nofollow noopener noreferrer">DataSourceTypeForValues</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/datasourcetype/" target="_blank" rel="nofollow noopener noreferrer">DataSourceType.DoubleLiterals</a> before assigning each point's <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/value/" target="_blank" rel="nofollow noopener noreferrer">Value</a> through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/idoublechartvalue/asliteraldouble/" target="_blank" rel="nofollow noopener noreferrer">AsLiteralDouble</a>.

The collection setting controls the source type of all point values in that series. Each point's <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ibasechartvalue/datasourcetype/" target="_blank" rel="nofollow noopener noreferrer">Value.DataSourceType</a> reports the selected type; change it through the collection setting. With `Worksheet`, use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/isinglecellchartvalue/ascell/" target="_blank" rel="nofollow noopener noreferrer">AsCell</a> to access the referenced cell. With `DoubleLiterals`, use `AsLiteralDouble` to read or write the number directly.

The following example creates a column chart with default series and categories, then assigns calculated values of 10, 20, and so on to the existing points of its first series. It saves the presentation, reopens it, and prints the stored values.

```cs
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 300);
var series = chart.ChartData.Series[0];

series.DataPoints.DataSourceTypeForValues = DataSourceType.DoubleLiterals;
for (var i = 0; i < series.DataPoints.Count; i++)
{
    series.DataPoints[i].Value.AsLiteralDouble = (i + 1) * 10;
}

presentation.Save("numeric_literals.pptx", SaveFormat.Pptx);

using var reopenedPresentation = new Presentation("numeric_literals.pptx");
var reopenedSlide = reopenedPresentation.Slides[0];
var reopenedChart = (IChart)reopenedSlide.Shapes[0];
var reopenedSeries = reopenedChart.ChartData.Series[0];
foreach (var point in reopenedSeries.DataPoints)
{
    Console.WriteLine(point.Value.AsLiteralDouble);
}
```

The point value source type is separate from <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdata/datasourcetype/" target="_blank" rel="nofollow noopener noreferrer">IChartData.DataSourceType</a>, which identifies the chart's internal or external workbook configuration. Using numeric literals does not, by itself, remove the embedded workbook. In this example, the workbook remains available for category labels, series names, and the other series. See [Chart Workbook](/net/slides/chart-workbook/) for workbook management.

For scatter and bubble charts, set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/datasourcetypeforxvalues/" target="_blank" rel="nofollow noopener noreferrer">DataSourceTypeForXValues</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/datasourcetypeforyvalues/" target="_blank" rel="nofollow noopener noreferrer">DataSourceTypeForYValues</a> to choose the sources for <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/xvalue/" target="_blank" rel="nofollow noopener noreferrer">XValue</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/yvalue/" target="_blank" rel="nofollow noopener noreferrer">YValue</a>. Bubble charts also use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/datasourcetypeforbubblesizes/" target="_blank" rel="nofollow noopener noreferrer">DataSourceTypeForBubbleSizes</a> for <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/bubblesize/" target="_blank" rel="nofollow noopener noreferrer">BubbleSize</a>. Set each applicable source to `DoubleLiterals` before assigning numbers through that value's `AsLiteralDouble` property.

## **Set the Chart Series Overlap**

<a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/overlap/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Overlap</a> reports how much bars or columns overlap in a 2D chart, from -100 through 100 percent. It is a read-only projection of the setting on the parent series group. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/overlap/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup.Overlap</a> to update every compatible series in that group. This option applies to chart types that display grouped bars or columns; it does not affect unrelated series groups in a combination chart.

The following example sets the overlap for the group that contains the first series:

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;
const sbyte overlapPercent = 30;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

// The new chart contains sample series, categories, and values.
var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
series.ParentSeriesGroup.Overlap = overlapPercent;

presentation.Save("series_overlap.pptx", SaveFormat.Pptx);
```

## **Change the Series Fill Color**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/format/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Format</a> to set the default fill for an entire series. If a point already has an explicit fill, its <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/format/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint.Format</a> setting overrides the series fill for that point.

The following example applies a solid blue fill to the first series:

```cs
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
series.Format.Fill.FillType = FillType.Solid;
series.Format.Fill.SolidFillColor.Color = Color.Blue;

presentation.Save("series_color.pptx", SaveFormat.Pptx);
```

The result:

![The color of the series](/net/slides/images/e73a9cf931fe1415-series_color.png)

## **Change the Series Name**

A series name is stored in the chart data workbook and is normally displayed in the legend. In the default workbook created for a clustered column chart, cell B1 is at row 0, column 1 and contains the name of the first series. The named constants in the following example make that structure explicit:

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int worksheetIndex = 0;
const int seriesNameRowIndex = 0;
const int firstSeriesColumnIndex = 1;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var workbook = chart.ChartData.ChartDataWorkbook;
var seriesNameCell = workbook.GetCell(worksheetIndex, seriesNameRowIndex, firstSeriesColumnIndex);
seriesNameCell.Value = "Revenue";

presentation.Save("series_name.pptx", SaveFormat.Pptx);
```

You can also update the cell already referenced by <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/name/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Name</a>. This approach avoids assuming a particular row and column in an existing chart:

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;
const int firstNameCellIndex = 0;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
var seriesNameCell = series.Name.AsCells[firstNameCellIndex];
seriesNameCell.Value = "Revenue";

presentation.Save("series_name.pptx", SaveFormat.Pptx);
```

The result:

### **Create a Series with a Name from Multiple Cells**

A composite series name is useful when a product name and a reporting period are stored in separate workbook cells. For example, you can combine `Product A` in B1 and `2026` in C1 into a single series name while keeping both parts linked to their source cells.

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/getcellcollection/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook.GetCellCollection</a> to retrieve the name range, then pass that collection to <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriescollection/add/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesCollection.Add</a>. The `skipHiddenCells` argument controls whether hidden cells are included: `true` excludes them, while `false` includes them. This example uses `false` to include every cell in the name range.

The following example creates a presentation with one series and two data points. Cells B1:C1 supply only the series name; A2:A3 supply the category labels, and B2:B3 supply the numeric values.

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 50, 50, 620, 180);

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();
chart.HasLegend = true;

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

// These two cells supply the series name.
workbook.GetCell(0, 0, 1, "Product A");
workbook.GetCell(0, 0, 2, "2026");
var nameCells = workbook.GetCellCollection("Sheet1!$B$1:$C$1", skipHiddenCells: false);
var series = chart.ChartData.Series.Add(nameCells, ChartType.ClusteredColumn);

// Separate cells supply the categories and numeric data points.
var northCategory = workbook.GetCell(0, 1, 0, "North");
var southCategory = workbook.GetCell(0, 2, 0, "South");
chart.ChartData.Categories.Add(northCategory);
chart.ChartData.Categories.Add(southCategory);
var northValue = workbook.GetCell(0, 1, 1, 120);
var southValue = workbook.GetCell(0, 2, 1, 150);
series.DataPoints.AddDataPointForBarSeries(northValue);
series.DataPoints.AddDataPointForBarSeries(southValue);

presentation.Save("composite_series_name.pptx", SaveFormat.Pptx);
```

The resulting series name is `Product A 2026`, with a space between the two cell values. The legend displays this as one entry for both columns. The image below was rendered from the saved presentation:

![Column chart with North and South values and the composite series name Product A 2026 in the legend](/net/slides/images/0ffa1088600fe420-composite_series_name.png)

## **Get the Automatic Series Fill Color**

<a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/getautomaticseriescolor/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.GetAutomaticSeriesColor</a> returns the color calculated from the series index and the chart style. This is the color used when the series fill has not been explicitly defined. Calling the method reads the calculated color; it does not assign a new fill.

The following example prints the automatic color of each default series:

```cs
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;

const int firstSlideIndex = 0;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var seriesCount = chart.ChartData.Series.Count;
for (var seriesIndex = 0; seriesIndex < seriesCount; seriesIndex++)
{
    var series = chart.ChartData.Series[seriesIndex];
    var automaticColor = series.GetAutomaticSeriesColor();
    Console.WriteLine($"Series {seriesIndex}: {automaticColor.Name}");
}
```

Example output for the default chart style:

```text
Series 0: ff4f81bd
Series 1: ffc0504d
Series 2: ff9bbb59
```

The exact colors depend on the chart style and theme.

## **Set Invert Fill Color for a Chart Series**

For bar, column, and bubble series, <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/invertifnegative/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.InvertIfNegative</a> can display negative values with a different fill. Set the regular series fill to solid, enable inversion, and assign the negative-value color through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/invertedsolidfillcolor/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.InvertedSolidFillColor</a>. Negative numbers remain unchanged in the workbook; only their display color changes.

The following example replaces the default chart data with one series. Worksheet row 0 contains the series name, column 0 contains category names, and column 1 contains the values:

```cs
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int worksheetIndex = 0;
const int headerRowIndex = 0;
const int categoryColumnIndex = 0;
const int firstSeriesColumnIndex = 1;
const int firstDataRowIndex = 1;

var categoryNames = new[] { "Category 1", "Category 2", "Category 3" };
var seriesValues = new[] { -20, 50, -30 };

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);
var chartData = chart.ChartData;
var workbook = chartData.ChartDataWorkbook;

chartData.Series.Clear();
chartData.Categories.Clear();

var seriesNameCell = workbook.GetCell(worksheetIndex, headerRowIndex, firstSeriesColumnIndex, "Series 1");
var series = chartData.Series.Add(seriesNameCell, chart.Type);

for (var categoryIndex = 0; categoryIndex < categoryNames.Length; categoryIndex++)
{
    var dataRowIndex = firstDataRowIndex + categoryIndex;
    var categoryName = categoryNames[categoryIndex];
    var seriesValue = seriesValues[categoryIndex];

    var categoryCell = workbook.GetCell(worksheetIndex, dataRowIndex, categoryColumnIndex, categoryName);
    chartData.Categories.Add(categoryCell);

    var valueCell = workbook.GetCell(worksheetIndex, dataRowIndex, firstSeriesColumnIndex, seriesValue);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
}

var automaticSeriesColor = series.GetAutomaticSeriesColor();
series.Format.Fill.FillType = FillType.Solid;
series.Format.Fill.SolidFillColor.Color = automaticSeriesColor;
series.InvertIfNegative = true;
series.InvertedSolidFillColor.Color = Color.Red;

presentation.Save("inverted_solid_fill_color.pptx", SaveFormat.Pptx);
```

The result:

![The inverted solid fill color](/net/slides/images/28db2385c0fe44f8-inverted_solid_fill_color.png)

You can enable inversion for one point through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/invertifnegative/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint.InvertIfNegative</a>. In the following example, inversion is disabled for the series and enabled only for the selected point. The point is also assigned a negative value so that the effect is visible:

```cs
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;
const int targetDataPointIndex = 2;
const int negativeValue = -30;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
var automaticSeriesColor = series.GetAutomaticSeriesColor();
series.Format.Fill.FillType = FillType.Solid;
series.Format.Fill.SolidFillColor.Color = automaticSeriesColor;
series.InvertedSolidFillColor.Color = Color.Red;
series.InvertIfNegative = false;

var dataPoint = series.DataPoints[targetDataPointIndex];
dataPoint.YValue.AsCell.Value = negativeValue;
dataPoint.InvertIfNegative = true;

presentation.Save("data_point_invert_color_if_negative.pptx", SaveFormat.Pptx);
```

## **Clear a Specific Data Point Value**

To make one point empty without removing the other points, set its backing workbook cell to `null`. For a column chart, the plotted value is available through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/yvalue/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint.YValue</a>. The data point stays at the same category position, but the chart treats its value as blank according to the chart's blank-value settings.

The following example clears only the second point in the first series:

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;
const int targetDataPointIndex = 1;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
var dataPoint = series.DataPoints[targetDataPointIndex];
dataPoint.YValue.AsCell.Value = null;

presentation.Save("clear_data_point_value.pptx", SaveFormat.Pptx);
```

Scatter charts use separate X and Y cells, and bubble charts also use a size cell. Clear only the cell that represents the value you intend to remove. Do not call <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/clear/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPointCollection.Clear</a> when you want to keep the other points, because that method removes every data point from the collection.

## **Control the Display of Empty Cells**

Hidden cells that contain values are a separate case from empty cells. To include or exclude data from hidden worksheet rows and columns, see [Include Data from Hidden Rows and Columns](/net/slides/chart-workbook/#include-data-from-hidden-rows-and-columns).

An empty workbook cell represents missing data; a cell containing `0` represents a known numeric value. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatacell/value/" target="_blank" rel="nofollow noopener noreferrer">IChartDataCell.Value</a> to `null` to make a cell empty. A numeric zero remains a zero regardless of the blank-cell setting.

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichart/displayblanksas/" target="_blank" rel="nofollow noopener noreferrer">IChart.DisplayBlanksAs</a> to choose how the chart displays empty cells. This setting applies to the whole chart. It changes how blanks are plotted, without filling the empty workbook cell with zero or an interpolated value.

The following self-contained example creates a line chart with one series, clears the value for Day 3, and saves the same chart with each mode. No input file is required. The <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook</a> uses worksheet 0, column 0 for category labels, and column 1 for values; row 0 holds the series name. The final data is `10, 20, empty, 30, 40`.

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.LineWithMarkers, 40, 40, 640, 400);
var chartData = chart.ChartData;
var workbook = chartData.ChartDataWorkbook;

chartData.Series.Clear();
chartData.Categories.Clear();

var seriesNameCell = workbook.GetCell(0, 0, 1, "Measurements");
var series = chartData.Series.Add(seriesNameCell, chart.Type);
var values = new[] { 10, 20, 25, 30, 40 };

for (var i = 0; i < values.Length; i++)
{
    var categoryCell = workbook.GetCell(0, i + 1, 0, $"Day {i + 1}");
    chartData.Categories.Add(categoryCell);
    var valueCell = workbook.GetCell(0, i + 1, 1, values[i]);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
}

// Leave Day 3 genuinely empty, while retaining its category and data point.
workbook.GetCell(0, 3, 1).Value = null;

var modes = new[] { DisplayBlanksAsType.Gap, DisplayBlanksAsType.Zero, DisplayBlanksAsType.Span };
foreach (var mode in modes)
{
    chart.DisplayBlanksAs = mode;
    presentation.Save($"empty_cells_{mode}.pptx", SaveFormat.Pptx);
}
```

Each output file stores the mode assigned before saving: `empty_cells_Gap.pptx`, `empty_cells_Zero.pptx`, and `empty_cells_Span.pptx`. To save only one version, assign the desired mode and save the presentation once instead of iterating over the modes.

The comparison below shows the same data in all three files. Day 3 is empty in the workbook in every case:

![Line charts with identical data: Gap breaks the line at Day 3, Zero drops the line to zero, and Span connects Day 2 to Day 4.](/net/slides/images/e02676ce5315f3f8-display_blanks_as.png)

The visible effect depends on the chart type. A line chart makes all three modes easy to compare. Bar and column charts have no line to connect across a missing category, so `Span` cannot produce the connecting segment shown above; a missing column and a zero-height column can also look alike. Similarly, a scatter chart with markers only has no connecting line. Do not expect three distinct results for every chart type; check the output for the type you use.

## **Set the Series Gap Width**

Gap width is the space between adjacent bar or column clusters, expressed as a percentage of the bar or column width. Like overlap, it belongs to the parent series group rather than to one series. Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/gapwidth/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup.GapWidth</a> once for the group. A larger value creates more space between clusters; a smaller value makes them denser.

The following example changes the gap width and saves only the final presentation:

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const int firstSlideIndex = 0;
const int firstSeriesIndex = 0;
const int gapWidthPercent = 30;

using var presentation = new Presentation();
var slide = presentation.Slides[firstSlideIndex];

var chart = slide.Shapes.AddChart(ChartType.StackedColumn, 20, 20, 500, 200);

var series = chart.ChartData.Series[firstSeriesIndex];
series.ParentSeriesGroup.GapWidth = gapWidthPercent;

presentation.Save("gap_width_30.pptx", SaveFormat.Pptx);
```

## **Show or Hide Series Lines**

Series lines visually connect related parts of a chart. Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/hasserieslines/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup.HasSeriesLines</a> to show or hide them in supported stacked bar and OfPie charts. In two-dimensional stacked bar and column charts, they connect corresponding stack boundaries across categories. In Pie of Pie and Bar of Pie charts, they connect the main plot to the secondary plot. This setting is not a general-purpose connector for other chart types.

Access the group through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/parentseriesgroup/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.ParentSeriesGroup</a>. The setting applies to every series in that group. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/hasserieslines/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.HasSeriesLines</a> is read-only and reflects the parent group's setting; change the group property to update it.

The following example creates one <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">PieOfPie</a> chart with default data. It saves the same chart with series lines enabled and then disabled, producing two presentations for comparison.

```cs
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.PieOfPie, 50, 50, 600, 400);
var series = chart.ChartData.Series[0];
var seriesGroup = series.ParentSeriesGroup;

seriesGroup.HasSeriesLines = true;
presentation.Save("series_lines_enabled.pptx", SaveFormat.Pptx);

seriesGroup.HasSeriesLines = false;
presentation.Save("series_lines_disabled.pptx", SaveFormat.Pptx);
```

Series lines differ from data label leader lines, which connect labels to their data points; gridlines, which mark intervals along chart axes; and the lines in a line chart, which represent data values. This setting does not control those elements.

## **FAQ**

**Which chart types support data series?**

All chart types represented by the <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> enumeration use chart data, but their series do not all have the same value structure or settings. For example, category charts use categories and values, scatter charts use X and Y values, and bubble charts add bubble sizes. Use the data-point creation method that matches the series type. Options such as overlap and gap width apply only to compatible bar or column groups.

**What is a chart series group?**

An <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup</a> contains compatible series that share group-level plotting settings. A combination chart can contain more than one group, so changing the group reached through one series does not necessarily change every series in the chart.

**Does a newly created chart contain default data?**

Yes. By default, <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addchart/" target="_blank" rel="nofollow noopener noreferrer">IShapeCollection.AddChart</a> creates sample series, categories, and values. You can edit those cells or clear both the series and category collections before adding a completely custom data set. An overload can also create a chart without default data.

**How are chart objects connected to workbook cells?**

Series names, category labels, and data-point values reference cells in an <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook</a>. Changing a referenced cell updates the corresponding chart element. When you build custom data, keep category rows and series-value rows aligned so that each point is plotted under the intended category.

**How do I clear one point instead of the whole series?**

Set the relevant value cell to `null` to retain the point's category position as an empty point. Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/clear/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPointCollection.Clear</a> only when you intend to remove all points from that series. If you also remove categories, update every series so their values remain aligned with the category collection.

**How are empty points displayed?**

The result depends on the chart type and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichart/displayblanksas/" target="_blank" rel="nofollow noopener noreferrer">IChart.DisplayBlanksAs</a>. Supported charts can display blanks as gaps, as zero values, or by connecting neighboring points. Choose the setting that matches the meaning of missing data in your presentation. See [Control the Display of Empty Cells](/net/slides/chart-series/#control-the-display-of-empty-cells) for a complete example and visual comparison.

**How are negative values formatted?**

For supported bar, column, and bubble series, enable <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/invertifnegative/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.InvertIfNegative</a> and set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/invertedsolidfillcolor/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.InvertedSolidFillColor</a>. You can override the behavior for an individual point with <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapoint/invertifnegative/" target="_blank" rel="nofollow noopener noreferrer">IChartDataPoint.InvertIfNegative</a>. These properties affect formatting, not the stored numeric values.

**Which formatting wins when both a series and a point are formatted?**

Explicit data-point formatting takes precedence for that point. Other points continue to use the explicit series format or, when the series format is not defined, the automatic chart style and theme. Group properties such as overlap and gap width control layout and are not point-level formatting overrides.

**Is there a limit to how many series a chart can contain?**

Aspose.Slides does not impose a separate fixed series-count limit. In practice, presentation file constraints, available memory, rendering time, and chart readability determine a useful limit.

**What should I change when columns are too close together or too far apart?**

Set <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/gapwidth/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup.GapWidth</a> on the appropriate parent series group. Increase the value to widen the space between clusters, or decrease it to bring the clusters closer together.

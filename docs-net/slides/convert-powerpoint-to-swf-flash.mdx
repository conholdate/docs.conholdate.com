## **Overview**

This article explains how to convert PowerPoint presentations to SWF by using Aspose.Slides. It shows how to save a presentation as an SWF file with the <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> method and how to configure the export with <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a>, including viewer settings and notes or comments layout.

## **Convert Presentations to Flash**

The <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method exposed by <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> class can be used to convert the whole presentation into SWF document.  You can also include comments in generated SWF by using <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions" target="_blank" rel="nofollow noopener noreferrer">SWFOptions</a> class and <a href="https://reference.aspose.com/slides/net/aspose.slides.export/inotescommentslayoutingoptions" target="_blank" rel="nofollow noopener noreferrer">INotesCommentsLayoutingOptions </a>interface. The following example shows how to convert a presentation into SWF document by using options provided by SWFOptions class.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

// Instantiate a Presentation object that represents a presentation file
using (Presentation presentation = new Presentation("HelloWorld.pptx"))
{
    SwfOptions swfOptions = new SwfOptions();
    swfOptions.ViewerIncluded = false;

    swfOptions.SlidesLayoutOptions = new NotesCommentsLayoutingOptions
    {
        NotesPosition = NotesPositions.BottomFull
    };

    // Saving presentation and notes pages
    presentation.Save("SaveAsSwf_out.swf", SaveFormat.Swf, swfOptions);
    swfOptions.ViewerIncluded = true;
    presentation.Save("SaveNotes_out.swf", SaveFormat.Swf, swfOptions);
}
```

## **FAQ**

### Can I include hidden slides in the SWF?

Yes. Enable the <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/showhiddenslides/" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a> option in <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a>. By default, hidden slides are not exported.

### How can I control compression and the final SWF size?

Use the <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/compressed/" target="_blank" rel="nofollow noopener noreferrer">Compressed</a> flag (enabled by default) and adjust <a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/jpegquality/" target="_blank" rel="nofollow noopener noreferrer">JpegQuality</a> to balance file size and image fidelity.

### What is 'ViewerIncluded' for, and when should I disable it?

<a href="https://reference.aspose.com/slides/net/aspose.slides.export/swfoptions/viewerincluded/" target="_blank" rel="nofollow noopener noreferrer">ViewerIncluded</a> adds an embedded player UI (navigation controls, panels, search). Disable it if you plan to use your own player or need a bare SWF frame without UI.

### What happens if a source font is missing on the export machine?

Aspose.Slides will substitute the font you specify via <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveoptions/defaultregularfont/" target="_blank" rel="nofollow noopener noreferrer">DefaultRegularFont</a> in <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a> to avoid an unintended fallback.

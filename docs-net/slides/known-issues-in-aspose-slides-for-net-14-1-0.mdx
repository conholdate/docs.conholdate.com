This is a historical page. It lists the known issues published with Aspose.Slides for .NET 14.1.0, released in 2014, and does not describe the current version. For the changes in each version, see the <a href="https://releases.aspose.com/slides/net/release-notes/" target="_blank" rel="nofollow noopener noreferrer">release notes</a>.

The following are the Known Issues and Limitations in Aspose.Slides for .NET 14.1.0.

1. Some shapes have wrong geometry in serialized PPT documents (Call outs).
2. Not all PPTX text formatting features are supported in PPT serialization (tabulation, indentation and paragraph formatting limitations).
3. Info about text language and spelling settings is not present in serialized PPT documents.
4. Not all PPTX themes' features are supported in PPT serialization (only serialization of fill formats, line formats and font).
5. There are known issues in OLE/ActiveX PPT serialization to PPT.

## **Introduction**

Aspose.Slides allows you to convert presentations to output formats that support Handout mode. In this mode, multiple slides are arranged on a single page, which is useful for printing presentation materials for conferences, seminars, and similar events.

Handout mode is configured through the `SlidesLayoutOptions` property, which is available in <a href="https://reference.aspose.com/slides/net/aspose.slides.export/ipdfoptions/" target="_blank" rel="nofollow noopener noreferrer">IPdfOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/irenderingoptions/" target="_blank" rel="nofollow noopener noreferrer">IRenderingOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/ihtmloptions/" target="_blank" rel="nofollow noopener noreferrer">IHtmlOptions</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides.export/itiffoptions/" target="_blank" rel="nofollow noopener noreferrer">ITiffOptions</a>. To define the handout layout, use the <a href="https://reference.aspose.com/slides/net/aspose.slides.export/handoutlayoutingoptions/" target="_blank" rel="nofollow noopener noreferrer">HandoutLayoutingOptions</a> object.

To set the handout page dimensions and orientation before export, see [Notes Page Size](/net/slides/notes-size/).

## **Handout Mode Export**

To export a presentation in Handout mode, set the `SlidesLayoutOptions` property for the target export options and assign a <a href="https://reference.aspose.com/slides/net/aspose.slides.export/handoutlayoutingoptions/" target="_blank" rel="nofollow noopener noreferrer">HandoutLayoutingOptions</a> instance that defines the number of slides per page and related display parameters.

Below is a code example showing how to convert a presentation to PDF in Handout mode.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

// Load a presentation.
using var presentation = new Presentation("sample.pptx");

// Set the export options.
var pdfOptions = new PdfOptions
{
    SlidesLayoutOptions = new HandoutLayoutingOptions
    {
        Handout = HandoutType.Handouts4Horizontal,  // 4 slides on one page horizontally
        PrintSlideNumbers = true,                   // print slide numbers
        PrintFrameSlide = true,                     // print a frame around slides
        PrintComments = false                       // no comments
    }
};

// Export the presentation to PDF with the chosen layout.
presentation.Save("output.pdf", SaveFormat.Pdf, pdfOptions);
```

Keep in mind that the `SlidesLayoutOptions` property is available only for certain output formats, such as PDF, HTML, TIFF, and when rendering as images.

## **FAQ**

### What is the maximum number of slide thumbnails per page in Handout mode?

Aspose.Slides supports <a href="https://reference.aspose.com/slides/net/aspose.slides.export/handouttype/" target="_blank" rel="nofollow noopener noreferrer">presets</a> up to 9 thumbnails per page with horizontal or vertical ordering: 1, 2, 3, 4 (horizontal/vertical), 6 (horizontal/vertical), and 9 (horizontal/vertical).

### Can I define a custom grid, such as 5 or 8 slides per page?

No. The number and ordering of thumbnails are controlled strictly by the <a href="https://reference.aspose.com/slides/net/aspose.slides.export/handouttype/" target="_blank" rel="nofollow noopener noreferrer">HandoutType</a> enumeration; arbitrary layouts are not supported.

### Can I include hidden slides in the Handout output?

Yes. Enable the `ShowHiddenSlides` option in the export settings for the target format, such as <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/htmloptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlOptions</a>, or <a href="https://reference.aspose.com/slides/net/aspose.slides.export/tiffoptions/" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a>.

## **Overview**

Aspose.Slides for .NET lets you create and format bulleted and numbered lists in PowerPoint and OpenDocument presentations. A list item is a paragraph whose bullet settings are controlled through its paragraph format.

Use the <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraph/paragraphformat/" target="_blank" rel="nofollow noopener noreferrer">IParagraph.ParagraphFormat</a> property to access paragraph-level list settings. The main entry point is <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/bullet/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormat.Bullet</a>, which returns an <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat</a> object. With this object, you can set the bullet type, symbol, picture, color, size, numbering style, and starting number.

This article shows how to:

- create a bulleted list with a custom symbol
- create a picture bullet
- create a multilevel list by setting paragraph depth
- create a numbered list
- inspect and change list formatting in an existing presentation
- read actual list markers and numbers alongside paragraph text

## **Create a Bulleted List**

To create a bulleted list, add <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraph/" target="_blank" rel="nofollow noopener noreferrer">IParagraph</a> objects to an <a href="https://reference.aspose.com/slides/net/aspose.slides/itextframe/" target="_blank" rel="nofollow noopener noreferrer">ITextFrame</a> and set <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/type/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Type</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/bullettype/" target="_blank" rel="nofollow noopener noreferrer">BulletType.Symbol</a>. You can then set <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/char/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Char</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/color/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Color</a>, and <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/height/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Height</a> to control the bullet appearance.

The following C# code demonstrates how to create a bulleted list in a slide:

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

static Paragraph CreateParagraph(string text)
{
    var paragraph = new Paragraph();
    paragraph.ParagraphFormat.Bullet.Type = BulletType.Symbol;
    paragraph.ParagraphFormat.Bullet.Char = '*';
    paragraph.ParagraphFormat.Indent = 15;
    paragraph.ParagraphFormat.Bullet.IsBulletHardColor = NullableBool.True;
    paragraph.ParagraphFormat.Bullet.Color.Color = Color.IndianRed;
    paragraph.ParagraphFormat.Bullet.Height = 100;
    paragraph.Text = text;
    return paragraph;
}

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var autoShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 200, 50);

var textFrame = autoShape.TextFrame;
textFrame.Paragraphs.Clear();

var paragraph1 = CreateParagraph("The first paragraph");
textFrame.Paragraphs.Add(paragraph1);

var paragraph2 = CreateParagraph("The second paragraph");
textFrame.Paragraphs.Add(paragraph2);

presentation.Save("symbol_bullets.pptx", SaveFormat.Pptx);
```

## **Create a Numbered List**

Use numbered lists when the order of items matters. Set <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/type/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Type</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/bullettype/" target="_blank" rel="nofollow noopener noreferrer">BulletType.Numbered</a>. You can also choose a numbering format with <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/numberedbulletstyle/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.NumberedBulletStyle</a> or set <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/numberedbulletstartwith/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.NumberedBulletStartWith</a> when the list should start from a value other than 1.

The following C# code shows how to create a numbered list in a slide:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var autoShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 90, 80);

var textFrame = autoShape.TextFrame;
textFrame.Paragraphs.Clear();

var paragraph1 = new Paragraph();
paragraph1.ParagraphFormat.Bullet.Type = BulletType.Numbered;
paragraph1.Text = "Apple";
textFrame.Paragraphs.Add(paragraph1);

var paragraph2 = new Paragraph();
paragraph2.ParagraphFormat.Bullet.Type = BulletType.Numbered;
paragraph2.Text = "Orange";
textFrame.Paragraphs.Add(paragraph2);

var paragraph3 = new Paragraph();
paragraph3.ParagraphFormat.Bullet.Type = BulletType.Numbered;
paragraph3.Text = "Banana";
textFrame.Paragraphs.Add(paragraph3);

presentation.Save("numbered_bullets.pptx", SaveFormat.Pptx);
```

## **Create a Picture Bullet**

Aspose.Slides allows you to replace a regular bullet symbol with an image. Picture bullets work best with simple images that remain readable at a small size, such as icons or small transparent PNG files.

Ideally, if you plan to replace the regular bullet symbol with an image, it's best to choose a simple graphic with a transparent background. Such images work well as custom bullet symbols.

Keep in mind that the image will be scaled down to a very small size. For that reason, we strongly recommend selecting an image that remains clear and visually effective when used as a bullet in a list.

To create a picture bullet, add an image to <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/images/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Images</a> and assign the returned image object to <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/picture/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Picture</a>. Set <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformat/type/" target="_blank" rel="nofollow noopener noreferrer">IBulletFormat.Type</a> to <a href="https://reference.aspose.com/slides/net/aspose.slides/bullettype/" target="_blank" rel="nofollow noopener noreferrer">BulletType.Picture</a> before assigning the image.

Let's say we have an "image.png":

![A picture for the bullets](/net/slides/images/1391d50b41780b24-picture_for_bullets.png)

The following C# code shows how to create picture bullets in a slide:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

static Paragraph CreateParagraph(string text, IPPImage image)
{
    var paragraph = new Paragraph();
    paragraph.ParagraphFormat.Bullet.Type = BulletType.Picture;
    paragraph.ParagraphFormat.Bullet.Picture.Image = image;
    paragraph.ParagraphFormat.Indent = 15;
    paragraph.ParagraphFormat.Bullet.Height = 100;
    paragraph.Text = text;
    return paragraph;
}

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var autoShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 200, 50);

var textFrame = autoShape.TextFrame;
textFrame.Paragraphs.Clear();

var imageBytes = File.ReadAllBytes("image.png");
var bulletImage = presentation.Images.AddImage(imageBytes);

var paragraph1 = CreateParagraph("The first paragraph", bulletImage);
textFrame.Paragraphs.Add(paragraph1);

var paragraph2 = CreateParagraph("The second paragraph", bulletImage);
textFrame.Paragraphs.Add(paragraph2);

presentation.Save("picture_bullets.pptx", SaveFormat.Pptx);
```

The result:

![The picture bullets](/net/slides/images/ce724f97bb014d5b-picture_bullets.png)

## **Create a Multilevel List**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/depth/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormat.Depth</a> to place list items on different levels. Level 0 is the top level, level 1 is nested below it, and so on.

The following C# code shows how to create a multilevel bulleted list:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var autoShape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 20, 20, 260, 110);

var textFrame = autoShape.TextFrame;
textFrame.Paragraphs.Clear();

var paragraph1 = new Paragraph();
paragraph1.ParagraphFormat.Depth = 0;
paragraph1.Text = "My text - Depth 0";
textFrame.Paragraphs.Add(paragraph1);

var paragraph2 = new Paragraph();
paragraph2.ParagraphFormat.Depth = 1;
paragraph2.Text = "My text - Depth 1";
textFrame.Paragraphs.Add(paragraph2);

var paragraph3 = new Paragraph();
paragraph3.ParagraphFormat.Depth = 2;
paragraph3.Text = "My text - Depth 2";
textFrame.Paragraphs.Add(paragraph3);

var paragraph4 = new Paragraph();
paragraph4.ParagraphFormat.Depth = 3;
paragraph4.Text = "My text - Depth 3";
textFrame.Paragraphs.Add(paragraph4);

presentation.Save("multilevel_bullets.pptx", SaveFormat.Pptx);
```

## **Change an Existing List**

To change list formatting in an existing presentation, access the target paragraph and update its <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/bullet/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormat.Bullet</a> settings. The same properties used to create lists can be used to inspect or modify lists loaded from a PPT, PPTX, or ODP file.

The following C# code changes the first paragraph in a text frame to use a numbered list style:

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("input.pptx");
var slide = presentation.Slides[0];
var autoShape = (IAutoShape)slide.Shapes[0];

var paragraph = autoShape.TextFrame.Paragraphs[0];
paragraph.ParagraphFormat.Bullet.Type = BulletType.Numbered;
paragraph.ParagraphFormat.Bullet.NumberedBulletStyle = NumberedBulletStyle.BulletRomanUCPeriod;
paragraph.ParagraphFormat.Bullet.NumberedBulletStartWith = 1;
paragraph.ParagraphFormat.MarginLeft = 30;
paragraph.ParagraphFormat.Indent = -20;

presentation.Save("updated_list.pptx", SaveFormat.Pptx);
```

## **Read Actual Bullet Values**

When extracting presentation content, keep list markers alongside paragraph text. Call <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/geteffective/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormat.GetEffective</a> and access <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformateffectivedata/bullet/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormatEffectiveData.Bullet</a> to obtain the effective bullet format. Check its <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformateffectivedata/type/" target="_blank" rel="nofollow noopener noreferrer">Type</a> before reading <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformateffectivedata/actualbulletvalue/" target="_blank" rel="nofollow noopener noreferrer">ActualBulletValue</a>.

For numbered lists, distinguish these three values:

- <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformateffectivedata/numberedbulletstyle/" target="_blank" rel="nofollow noopener noreferrer">NumberedBulletStyle</a> determines the format, such as Arabic numbers followed by a period or lowercase letters followed by a period.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformateffectivedata/numberedbulletstartwith/" target="_blank" rel="nofollow noopener noreferrer">NumberedBulletStartWith</a> specifies the starting number for a group of numbered paragraphs.
- <a href="https://reference.aspose.com/slides/net/aspose.slides/ibulletformateffectivedata/actualbulletvalue/" target="_blank" rel="nofollow noopener noreferrer">ActualBulletValue</a> returns the formatted marker for a particular paragraph. For example, the second item in a list starting at 5 returns `6.`.

Preserve <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/depth/" target="_blank" rel="nofollow noopener noreferrer">Depth</a> with each paragraph to retain its nesting level. The actual marker does not encode the full hierarchy: a nested item can return `c.` rather than a combined label such as `6.c.`.

The following self-contained example creates lists, saves them to a presentation, and reloads the presentation to report each paragraph's text, depth, bullet type, and actual value. The small blue picture marker is created from inline SVG.

```csharp
using System;
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Export;

using (var presentation = new Presentation())
{
    presentation.SlideSize.SetSize(720, 440, SlideSizeScaleType.DoNotScale);
    var slide = presentation.Slides[0];

    var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 30, 20, 660, 400);
    shape.FillFormat.FillType = FillType.NoFill;
    shape.LineFormat.FillFormat.FillType = FillType.NoFill;

    var textFrame = shape.TextFrame;
    textFrame.Paragraphs.Clear();

    // Create a picture marker without an external image file.
    var svg = new SvgImage("<svg xmlns='http://www.w3.org/2000/svg' width='16' height='16'><rect width='16' height='16' rx='4' fill='#0078D4'/></svg>");
    var bulletImage = presentation.Images.AddImage(svg);

    void AddParagraph(string text, short depth, BulletType type, short start = 1, NumberedBulletStyle style = NumberedBulletStyle.BulletArabicPeriod)
    {
        var paragraph = new Paragraph { Text = text };

        var format = paragraph.ParagraphFormat;
        format.Depth = depth;
        format.MarginLeft = 30 + depth * 40;
        format.Indent = -28;
        format.SpaceAfter = 8;
        format.DefaultPortionFormat.FontHeight = 22;
        format.DefaultPortionFormat.FillFormat.FillType = FillType.Solid;
        format.DefaultPortionFormat.FillFormat.SolidFillColor.Color = Color.Black;
        format.Bullet.Type = type;
        format.Bullet.IsBulletHardColor = NullableBool.True;
        format.Bullet.Color.Color = Color.Black;
        if (type == BulletType.Numbered)
        {
            format.Bullet.NumberedBulletStyle = style;
            format.Bullet.NumberedBulletStartWith = start;
        }
        else if (type == BulletType.Symbol)
        {
            format.Bullet.Char = '\u2022';
        }
        else if (type == BulletType.Picture)
        {
            format.Bullet.Picture.Image = bulletImage;
        }

        textFrame.Paragraphs.Add(paragraph);
    }

    AddParagraph("First item", 0, BulletType.Numbered, 5);
    AddParagraph("Second item", 0, BulletType.Numbered, 5);
    AddParagraph("Nested item", 1, BulletType.Numbered, 3, NumberedBulletStyle.BulletAlphaLCPeriod);
    AddParagraph("Next nested item", 1, BulletType.Numbered, 3, NumberedBulletStyle.BulletAlphaLCPeriod);
    AddParagraph("Deep item", 2, BulletType.Numbered, 4, NumberedBulletStyle.BulletRomanLCPeriod);
    AddParagraph("Back to top level", 0, BulletType.Numbered, 5);
    AddParagraph("Symbol marker", 0, BulletType.Symbol);
    AddParagraph("No bullet", 0, BulletType.None);
    AddParagraph("Picture marker", 0, BulletType.Picture);
    presentation.Save("actual_bullet_values.pptx", SaveFormat.Pptx);
}

using var loadedPresentation = new Presentation("actual_bullet_values.pptx");
var loadedShape = (IAutoShape)loadedPresentation.Slides[0].Shapes[0];
Console.WriteLine("Text | Depth | Type | Actual value");
foreach (var paragraph in loadedShape.TextFrame.Paragraphs)
{
    var bullet = paragraph.ParagraphFormat.GetEffective().Bullet;
    string marker;
    switch (bullet.Type)
    {
        case BulletType.Numbered:
        case BulletType.Symbol:
            marker = bullet.ActualBulletValue;
            break;
        case BulletType.None:
            marker = $"{bullet.ActualBulletValue ?? "null"} (no bullet)";
            break;
        case BulletType.Picture:
            marker = $"{bullet.ActualBulletValue ?? "null"} (image required)";
            break;
        default:
            marker = "unsupported bullet type";
            break;
    }
    Console.WriteLine($"{paragraph.Text} | {paragraph.ParagraphFormat.Depth} | {bullet.Type} | {marker}");
}
```

Handle these types separately: the former has no marker, while the latter requires extracting the bullet image separately. A picture bullet cannot be reproduced solely by extracting a text marker.

## **FAQ**

**Can bulleted and numbered lists be exported to PDF or images?**

Yes. Aspose.Slides preserves list formatting when the target format supports the corresponding text layout and bullet features.

**Can I edit lists in existing presentations?**

Yes. Load the presentation, access the target paragraph, inspect or update its <a href="https://reference.aspose.com/slides/net/aspose.slides/iparagraphformat/bullet/" target="_blank" rel="nofollow noopener noreferrer">IParagraphFormat.Bullet</a> settings, and save the presentation.

**Can lists contain non-Latin text?**

Yes. List item text can contain Unicode characters, so you can create lists in multilingual presentations. Make sure the fonts used in the presentation support the characters you need.

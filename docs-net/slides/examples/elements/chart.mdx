> Add, access, remove, and title PowerPoint charts with Aspose.Slides for .NET C# examples.
> 3

Add, access, remove, and title charts with **Aspose.Slides for .NET**. Each copied program creates its own presentation and uses its first slide. The download passes a slide to each case method.

Copy a C# block into `Program.cs` in a .NET project with `Aspose.Slides.NET6.CrossPlatform` installed. Each block is a complete program. Run one block at a time. The ZIP contains the IDE-ready project and its verification checks. The copied code runs in evaluation mode. For licensed output, apply your license before creating a presentation, as described in the [licensing guide](/net/slides/licensing/).

## **Download and run**

<a href="https://docs.aspose.com/slides/net/examples/elements/chart/example.zip" target="_blank" rel="nofollow noopener noreferrer">Download the complete project</a>, extract it, and open `Example.sln` or run:

```console
dotnet restore Example.sln
dotnet run --project Example.csproj -- --mode evaluation
```

The download includes every case below, its fixture helpers and inputs. `Program.cs` runs all cases; use `--action block-001` to run one independently. Outputs and an action report are written to the printed output directory. No previous example or working-directory setup is required. Evaluation adds a watermark and can truncate read-back text; the short fixtures still have explicit structural checks. For full text and no watermark, use `--mode licensed --license PATH` with your own valid license. See the [setup guide](/net/slides/examples/getting-started/) for supported SDKs and native prerequisites.

## **Add a Chart**

Add an Area chart to the first slide.

```csharp
using Aspose.Slides.Export;
using Aspose.Slides;
using Aspose.Slides.Charts;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

slide.Shapes.AddChart(ChartType.Area, 50, 50, 400, 300);

presentation.Save("chart-01.pptx", SaveFormat.Pptx);
```

## **Access a Chart**

After creating a chart, you can retrieve it through the shape collection.

```csharp
using System;
using Aspose.Slides.Export;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Charts;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

slide.Shapes.AddChart(ChartType.Line, 50, 50, 400, 300);

var firstChart = slide.Shapes.OfType<IChart>().First();
Console.WriteLine(firstChart.Type);

presentation.Save("chart-02.pptx", SaveFormat.Pptx);
```

## **Remove a Chart**

The following code removes a chart from a slide.

```csharp
using Aspose.Slides.Export;
using Aspose.Slides;
using Aspose.Slides.Charts;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Pie, 50, 50, 400, 300);
slide.Shapes.Remove(chart);

presentation.Save("chart-03.pptx", SaveFormat.Pptx);
```

## **Change the Chart Title**

Enable the chart title and set its text to "Sales".

```csharp
using Aspose.Slides.Export;
using Aspose.Slides;
using Aspose.Slides.Charts;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Column3D, 50, 50, 400, 300);
chart.HasTitle = true;
chart.ChartTitle.AddTextFrameForOverriding("Sales");

presentation.Save("chart-04.pptx", SaveFormat.Pptx);
```

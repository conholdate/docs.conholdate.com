> Set and read a tag on an existing ink shape or remove the shape with Aspose.Slides for .NET C# examples.
> 3

Use **Aspose.Slides for .NET** to set and read tags on an existing ink shape or remove the shape from the slide.

> ❗ **Note:** Ink shapes represent user input from specialized devices. Aspose.Slides cannot create new ink strokes programmatically, but you can read and modify existing ink.

For the copied blocks, pass the path to a PPTX with ink on its first slide, for example `dotnet run -- ink.pptx`. You can use your own deck or the <a href="https://docs.aspose.com/slides/net/examples/elements/ink/Fixtures/ink.pptx" target="_blank" rel="nofollow noopener noreferrer">sample input</a>.

Copy a C# block into `Program.cs` in a .NET project with `Aspose.Slides.NET6.CrossPlatform` installed. Each block is a complete program. Run one block at a time. The ZIP contains the IDE-ready project and its verification checks. The copied code runs in evaluation mode. For licensed output, apply your license before creating a presentation, as described in the [licensing guide](/net/slides/licensing/).

## **Download and run**

<a href="https://docs.aspose.com/slides/net/examples/elements/ink/example.zip" target="_blank" rel="nofollow noopener noreferrer">Download the complete project</a>, extract it, and open `Example.sln` or run:

For full text and no watermark, use `--mode licensed --license PATH` with your own valid license. ## **Set and Read an Ink Tag**

Set the kind tag on the first ink shape and read that same named tag. Existing tags are preserved. If the first slide has no ink, the program prints a message and exits without saving.

Pass a PPTX with ink on its first slide, such as the <a href="https://docs.aspose.com/slides/net/examples/elements/ink/Fixtures/ink.pptx" target="_blank" rel="nofollow noopener noreferrer">sample input</a>, using `dotnet run -- ink.pptx`.

```csharp
using System;
using Aspose.Slides.Export;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Ink;

// Pass the path to a PPTX file with ink on its first slide as the first argument.
if (args.Length != 1)
{
    Console.WriteLine("Usage: dotnet run -- <ink.pptx>");
    return;
}

using var presentation = new Presentation(args[0]);
var slide = presentation.Slides[0];

var inkShape = slide.Shapes.OfType<Ink>().FirstOrDefault();
if (inkShape == null)
{
    Console.WriteLine("No ink shape was found on the first slide.");
    return;
}

var tags = inkShape.CustomData.Tags;
tags["kind"] = "Ink";
Console.WriteLine($"kind: {tags["kind"]}");

presentation.Save("ink-01.pptx", SaveFormat.Pptx);
```

## **Remove Ink**

Delete the first ink shape while preserving other shapes. If no ink exists on the first slide, print a message and exit without saving.

Pass a PPTX with ink on its first slide, such as the <a href="https://docs.aspose.com/slides/net/examples/elements/ink/Fixtures/ink.pptx" target="_blank" rel="nofollow noopener noreferrer">sample input</a>, using `dotnet run -- ink.pptx`.

```csharp
using System;
using Aspose.Slides.Export;
using System.Linq;
using Aspose.Slides;
using Aspose.Slides.Ink;

// Pass the path to a PPTX file with ink on its first slide as the first argument.
if (args.Length != 1)
{
    Console.WriteLine("Usage: dotnet run -- <ink.pptx>");
    return;
}

using var presentation = new Presentation(args[0]);
var slide = presentation.Slides[0];

var inkShape = slide.Shapes.OfType<Ink>().FirstOrDefault();
if (inkShape == null)
{
    Console.WriteLine("No ink shape was found on the first slide.");
    return;
}

slide.Shapes.Remove(inkShape);

presentation.Save("ink-02.pptx", SaveFormat.Pptx);
```

> Create 3D charts in PowerPoint presentations with Aspose.Slides for .NET. Adjust rotation, height proportions, chart depth, and spacing between series with C# examples.
> 9

## **Overview**

Aspose.Slides for .NET lets you customize the view of a 3D chart through the <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichart/rotation3d/" target="_blank" rel="nofollow noopener noreferrer">IChart.Rotation3D</a> property. This article demonstrates how to adjust rotation, height proportions, depth, right-angle axes, and spacing between series, then save the presentation in PPTX format.

## **Set the Rotation and Depth of a 3D Chart**

The example below creates a <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> and uses <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addchart/" target="_blank" rel="nofollow noopener noreferrer">IShapeCollection.AddChart</a> to add a stacked 3D column chart to its first slide. It replaces the default series and categories with two series containing three values each. Worksheet index `0` identifies the chart's first data worksheet; row `0` holds series names, and column `0` holds category labels.

The <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/irotation3d/rotationx/" target="_blank" rel="nofollow noopener noreferrer">RotationX</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/irotation3d/rotationy/" target="_blank" rel="nofollow noopener noreferrer">RotationY</a> properties set the chart's rotation to 40 and 270 degrees, respectively. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/irotation3d/depthpercents/" target="_blank" rel="nofollow noopener noreferrer">DepthPercents</a> sets its depth to 150% of its width, while <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/irotation3d/rightangleaxes/" target="_blank" rel="nofollow noopener noreferrer">RightAngleAxes</a> enables right-angle axes instead of perspective. The resulting presentation contains the populated chart with these 3D view settings.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.StackedColumn3D, 0, 0, 500, 500);

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
var worksheetIndex = 0;

var values = new double[,] { { 20, 50, 30 }, { 30, 10, 60 } };

for (var categoryIndex = 0; categoryIndex < 3; categoryIndex++)
{
    var categoryCell = workbook.GetCell(worksheetIndex, categoryIndex + 1, 0, $"Category {categoryIndex + 1}");
    chart.ChartData.Categories.Add(categoryCell);
}

for (var seriesIndex = 0; seriesIndex < 2; seriesIndex++)
{
    var seriesCell = workbook.GetCell(worksheetIndex, 0, seriesIndex + 1, $"Series {seriesIndex + 1}");
    var series = chart.ChartData.Series.Add(seriesCell, chart.Type);

    for (var categoryIndex = 0; categoryIndex < 3; categoryIndex++)
    {
        var valueCell = workbook.GetCell(worksheetIndex, categoryIndex + 1, seriesIndex + 1, values[seriesIndex, categoryIndex]);
        series.DataPoints.AddDataPointForBarSeries(valueCell);
    }
}

chart.Rotation3D.RightAngleAxes = true;
chart.Rotation3D.RotationX = 40;
chart.Rotation3D.RotationY = 270;
chart.Rotation3D.DepthPercents = 150;

presentation.Save("Rotation3D_out.pptx", SaveFormat.Pptx);
```

## **Adjust the Height Proportions of a 3D Chart**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/irotation3d/heightpercents/" target="_blank" rel="nofollow noopener noreferrer">IRotation3D.HeightPercents</a> to set the height of a 3D chart as a percentage of its width. This changes the proportions of the 3D scene without resizing the chart object on the slide.

The following example creates a <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">Column3D</a> chart with the default data: three series and four categories. It saves three presentations with height proportions of 50%, 100%, and 200%. The chart's position, width, and height remain fixed. The data, rotation, depth, series spacing, and formatting are identical in all three files; only the height percentage changes.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Column3D, 40, 30, 620, 460);
chart.Rotation3D.RotationX = 20;
chart.Rotation3D.RotationY = 30;
chart.Rotation3D.RightAngleAxes = true;
chart.Rotation3D.DepthPercents = 100;
chart.ChartData.Series[0].ParentSeriesGroup.GapDepth = 150;

foreach (ushort heightPercent in new ushort[] { 50, 100, 200 })
{
    chart.Rotation3D.HeightPercents = heightPercent;
    presentation.Save($"chart_height_{heightPercent}.pptx", SaveFormat.Pptx);
}
```

## **Adjust the Gap Between Series**

Use <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/gapdepth/" target="_blank" rel="nofollow noopener noreferrer">IChartSeriesGroup.GapDepth</a> to control the distance between data series along the depth axis of a 3D chart, expressed as a percentage of the marker width. Use values from **0 to 500**, inclusive: `0` removes the gap, while larger values increase the spacing. With a fixed chart depth, increasing the gap makes the markers thinner along the depth axis.

Access the group through <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/parentseriesgroup/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.ParentSeriesGroup</a>. The setting applies to every series in that group, not just the series used to access it. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/gapdepth/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.GapDepth</a> is read-only and reflects the parent group's setting.

This setting affects 3D column and bar charts, including their cylinder, cone, and pyramid variants, as well as 3D line and area charts. The appearance depends on whether the series are arranged in depth, clustered, or stacked. For a clear comparison of gaps between separate series, use `ChartType.Column3D` from the <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> enumeration.

The following self-contained example uses the default chart data, which contains three series and four categories. It saves two presentations with identical data, rotation, gap width, and chart depth; only the gap depth changes.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Column3D, 40, 30, 620, 230);

chart.Rotation3D.RotationX = 20;
chart.Rotation3D.RotationY = 30;
chart.Rotation3D.DepthPercents = 100;

var series = chart.ChartData.Series[0];
var group = series.ParentSeriesGroup;
group.GapWidth = 150;

foreach (ushort gapDepth in new ushort[] { 0, 500 })
{
    group.GapDepth = gapDepth;

    var fileName = $"series_gap_depth_{gapDepth}.pptx";
    presentation.Save(fileName, SaveFormat.Pptx);

}
```

## **Change the 3D Series Type and Bar Shape**

In a clustered cylinder chart, the first series starts with a cylindrical bar shape. The example reads <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/type/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Type</a> and <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/bar3dshape/" target="_blank" rel="nofollow noopener noreferrer">IChartSeries.Bar3DShape</a> before and after each change.

```cs
using System;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredCylinder, 20, 20, 500, 300);
var series = chart.ChartData.Series[0];

Console.WriteLine($"{series.Type} | {series.Bar3DShape}");

series.Type = ChartType.ClusteredCone;
Console.WriteLine($"{series.Type} | {series.Bar3DShape}");

series.Bar3DShape = ChartShapeType.Box;
Console.WriteLine($"{series.Type} | {series.Bar3DShape}");

presentation.Save("series_shape.pptx", SaveFormat.Pptx);
```

<div className="docs-owner-markdown-table">

| Change to the first series | `Type` | `Bar3DShape` |
| ----------------------------- | ------------------- | ------------ |
| Create the chart | `ClusteredCylinder` | `Cylinder` |
| Set `Type` to `ClusteredCone` | `ClusteredCone` | `Cone` |
| Set `Bar3DShape` to `Box` | `ClusteredColumn3D` | `Box` |

</div>

Setting the shape to `Box` also changes the series type to `ClusteredColumn3D`. If your code branches on the series type, read `series.Type` after changing the shape. A value cached before the assignment would still select the `ClusteredCone` branch.

## **FAQ**

**Which chart types support 3D mode in Aspose.Slides?**

Aspose.Slides supports 3D variants of column charts, including Column 3D, Clustered Column 3D, Stacked Column 3D, and 100% Stacked Column 3D, along with related 3D types exposed through the <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> enumeration. For an exact, up-to-date list, check the <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> members in the API reference of your installed version.

**Can I get a raster image of a 3D chart for a report or the web?**

Yes. You can export a chart to an image with <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/getimage/" target="_blank" rel="nofollow noopener noreferrer">Shape.GetImage</a> or [render the entire slide](/net/slides/convert-powerpoint-to-png/) to formats like PNG or JPEG. This is useful when you need a raster preview or want to embed the chart into documents, dashboards, or web pages without requiring PowerPoint.

**How performant is building and rendering large 3D charts?**

Performance depends on data volume and visual complexity. For best results, keep 3D effects minimal, avoid heavy textures on walls and plot areas, limit the number of data points per series when possible, and render to an appropriately sized output (resolution and dimensions) to match the target display or print needs.

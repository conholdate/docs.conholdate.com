## **Introduction**

Since presentations are meant to present something, their visual appearance and interactive behavior are always taken into account during creation.

**PowerPoint animation** plays an important role in making a presentation eye-catching and engaging for viewers. Aspose.Slides for .NET provides a wide range of options to add animations to PowerPoint presentations:

- Apply various types of PowerPoint animation effects to shapes, charts, tables, OLE objects, and other presentation elements.
- Use multiple PowerPoint animation effects on a single shape.
- Utilize the animation timeline to control animation effects.
- Create custom animations.

In Aspose.Slides for .NET, various animation effects can be applied to shapes. Since every element on a slide, including text, pictures, OLE objects, and tables, is considered a shape, animation effects can be applied to any element on the slide.

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Slides.Animation</a> namespace provides classes to work with PowerPoint animations.

## **Custom Animation**

For complete C# examples that create, inspect, and modify behaviors and editable motion paths, see [Custom Animation](/net/slides/custom-animation/).

It is possible to create your own **custom animations** in Aspose.Slides. This can be achieved by combining several behaviors together into a new custom animation.

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/behavior" target="_blank" rel="nofollow noopener noreferrer">Behavior</a> is a building block of a PowerPoint animation effect. Combine behaviors to customize an effect, or add a behavior to extend a predefined effect. Repetition is configured through timing settings rather than a separate repeat behavior.

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/point" target="_blank" rel="nofollow noopener noreferrer">Animation Point</a> is a point at which a behavior should be applied.

## **Animation Time Line**

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/sequence" target="_blank" rel="nofollow noopener noreferrer">Sequence</a> is a collection of animation effects that can target different shapes.

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/animationtimeline" target="_blank" rel="nofollow noopener noreferrer">Timeline</a> is a set of sequences used in a specific slide. It is an animation engine introduced in PowerPoint 2002. In earlier versions of PowerPoint, adding animation effects to presentations was challenging and could only be achieved with various workarounds. The timeline replaces the old AnimationSettings class and provides a clearer object model for PowerPoint animations. A slide can have only one animation timeline.

## **Interactive Animation**

<a href="https://reference.aspose.com/slides/net/aspose.slides.animation/effecttriggertype" target="_blank" rel="nofollow noopener noreferrer">Trigger</a> allows you to define user actions (e.g., a button click) that will initiate a specific animation. Triggers were introduced in the latest version of PowerPoint.

## **FAQ**

**Will animations be preserved when exporting to PDF?**

No. PDF is a static format, so animations and [slide transitions](/net/slides/slide-transition/) don't play. If you need motion, export to [HTML5](/net/slides/export-to-html5/), [animated GIF](/net/slides/convert-powerpoint-to-animated-gif/), or [video](/net/slides/convert-powerpoint-to-video/) instead.

**Can I turn an animated presentation into a video and control the frame rate and frame size?**

Yes. You can [render the presentation as frames](/net/slides/convert-powerpoint-to-video/) and encode them into a video (e.g., via ffmpeg), choosing the FPS and resolution. Animations and slide transitions are played during rendering.

**Will animations remain intact when working with ODP (not just PPTX)?**

PPT, PPTX, and ODP are supported for [reading](/net/slides/open-presentation/) and [writing](/net/slides/save-presentation/), but this does not guarantee animation preservation. Custom animation data can be lost when converting to ODP. See [Custom Animation](/net/slides/custom-animation/) for a tested example and format limitations.

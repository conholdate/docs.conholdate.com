## Supported File Formats {#supported-file-formats}

The following table indicates the file formats that Aspose.3D for .NET - C# 3D file manipulation and conversion API can load and save.

| <a href="https://docs.fileformat.com/3d/ase/" target="_blank" rel="nofollow noopener noreferrer">ASE</a> | 3D Studio Max's ASCII Scene Exporter format | Supported |  |  |
| <a href="https://docs.fileformat.com/3d/rvm/" target="_blank" rel="nofollow noopener noreferrer">RVM</a> | Aveva Plant Design Management System Model | Supported | Supported |  |
| <a href="https://docs.fileformat.com/3d/blend/" target="_blank" rel="nofollow noopener noreferrer">Blender</a> | Used by Blender | Supported |  |  |

| <a href="https://docs.fileformat.com/3d/glb/" target="_blank" rel="nofollow noopener noreferrer">glTF</a> | Khronos Group's glTF | Supported | Supported | Including 1.0 ASCII/ Binary, 2.0 ASCII/Binary, 2.0 ASCII/Binary with Draco extension |

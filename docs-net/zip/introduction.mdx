Aspose.ZIP for .NET API lets work with creating and managing archives in your applications without the need of any other 3rd party applications. Its detailed implementation lets manage ZIP archives easily.

:::info
This article descibes manipulation with *zip* format only. Aspose.Zip support a lot of archive formats, they are listed [here](/net/zip/supported-file-formats/).
:::

## Basic Concepts of the API {#basic-concepts-of-the-api}

Aspose.ZIP API conceptualizes the functionality of each item in an archive as <a href="https://reference.aspose.com/zip/net/aspose.zip/archiveentry/" target="_blank" rel="nofollow noopener noreferrer">Entry</a>. Entry(ies) can be added, updated as well as removed from an archive. The API makes it simplified to work with an archive and its entries. This section gives an idea about different classes and methods exposed by the API and their usage.

### Working with Archives {#working-with-archives}

#### Creating Archive {#creating-archive}

An archive can be created using the <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/" target="_blank" rel="nofollow noopener noreferrer">Archive</a> class exposed by the API. A basic archive can be created using this class as shown in the following code sample.

```csharp
var archive = new Archive();
```

Such archive is prepared for compression.

#### Creating Archive with Custom Compression {#creating-archive-with-custom-compression}

Archives can be created with additional settings specifying custom Compression techniques.

```csharp
 var archive = new Archive(new ArchiveEntrySettings(new CompressionSettings(CompressionMethod.Store), new AesEcryptionSettings("p@s$", EncryptionMethod.AES256)));
```

#### Saving Archives {#saving-archives}

Archives can be <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/save/" target="_blank" rel="nofollow noopener noreferrer">saved</a> to the file system on the disc as well as to streams.

```csharp
archive.Save(stream, ArchiveSaveOptions saveOptions = null)

archive.Save(filePath, ArchiveSaveOptions saveOptions = null)
```

#### Archive Extraction {#archive-extraction}

Archives can be extracted by passing the source stream or path to the Archive <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/archive/#archive-constructor-2-of-3" target="_blank" rel="nofollow noopener noreferrer">extracting constructor</a>.

```csharp
FileStream zipFileStream = File.Open("myarchive.zip", FileMode.Open);
Archive archive = new Archive(zipFileStream);

or 

Archive archive = new Archive("myarchive.zip");
```

#### Extracting Encrypted Archives {#extracting-encrypted-archives}

Password-protected archives can be extracted by specifying the <a href="https://reference.aspose.com/zip/net/aspose.zip/archiveloadoptions/" target="_blank" rel="nofollow noopener noreferrer">ArchiveLoadOptions</a>

```csharp
Archive archive = new Archive(sourceStream, new ArchiveLoadOptions() { DecryptiptionPassword = "p@s$" });

or

Archive archive = new Archive("myarchive.zip", new ArchiveLoadOptions() { DecryptiptionPassword = "p@s$" });
```

### Working with Archive Entries {#working-with-archive-entries}

#### Adding Entries to Archive {#adding-entries-to-archive}

Entries can be added to an archive using the <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/createentry/" target="_blank" rel="nofollow noopener noreferrer">CreateEntry</a> method of Archive. The overloads offered by this method allow you to create entries in an archive from file path or stream along with specification Archive Entry settings. Files from a directory can also be added to an archive specifying the recursive search through the directory.

```csharp
CreateEntry(string name, Stream source, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name, data source, optional compression and encryption settings for the entry.

CreateEntry(string name, string path, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name and file source, optional compression and encryption settings for the entry.

CreateEntry(string name, FileInfo fileInfo, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name, file source, optional compression and encryption settings for the entry. Keeps attributes of NTFS file.

CreateEntry(string name, Stream source, ArchiveEntrySettings newEntriesSettings, FileSystemInfo fileInfo) - Creates single entry with given name, data source, compression and encryption settings for the entry. Keeps attributes of NTFS file and respects optional parameters.
```

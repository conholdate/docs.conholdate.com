## Vector Formats {#vector-formats}

The following table indicates the vector formats that Aspose.GIS for .NET can read or write.

<div className="docs-owner-markdown-table">

| **Description** | **Format** | **Read** | **Write** |
| ------------------------------- | ---------------------------- | --------- | --------- |
| ESRI Shapefile | .shp, .shx, .dbf, .qix, .cpg | Supported | Supported |
| GeoJSON | .json, .geojson | Supported | Supported |
| GeoJSON Seq | .json, .geojson | Supported | Supported |
| ESRI File Geodatabase (FileGDB) | .gdb | Supported | Supported |
| Geography Markup Language | .gml | Supported |  |
| Keyhole Markup Language | .kml | Supported | Supported |
| GPS Exchange Format | .gpx | Supported | Supported |
| TopoJSON | .json, .topojson | Supported | Supported |
| MapInfo Interchange Format | .mif | Supported |  |
| MapInfo TAB format | .tab, .dat, .dbf, .map, .id | Supported | Supported |
| OpenStreetMap (OSM) XML | .osm | Supported |  |
| Comma-Separated Values | .csv | Supported | Supported |

</div>

## Raster Formats {#raster-formats}

The following table indicates the raster formats that Aspose.GIS for .NET can only read.

| Geo TIFF, TIFF | .tiff, .tif | Supported |
| Esri ASCII | .ascii | Supported |

</div>

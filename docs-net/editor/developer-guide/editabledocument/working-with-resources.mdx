> This demonstration shows and explains different operations with resources, including retrieving, adjusting and saving them in different scenarios.

## Introduction

Almost all documents of any types have resources. It is first of all images, some document formats also hold fonts. Even for plain text document (TXT), when converting it to the HTML for editing, there will be one stylesheet, that is treated as a resource. WordProcessing documents of some format, Office Open XML usually, can also contain embedded audio files. GroupDocs.Editor allows to work with resources on editing phase, when document was loaded to the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a> class and opened for editing by generating the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> instance, that is produced by the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit</a> method. Instance of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> can be treated as an input document, converted to internal intermediate format, with possibilities to generate HTML markup and resources for passing them to the client-side WYSIWYG HTML-editor. GroupDocs.Editor classifies all resources onto three groups:

* Images, including: raster (PNG, BMP, JPEG, GIF, ICON) and vector (SVG and WMF).
* Fonts, including: TTF, EOT, WOFF, WOFF2.
* Textual resources: only CSS.
* Audio files: only MP3 (appear in version 21.10).

Every resource type has its own distinct class with metadata, constructors and other methods. They all are located within <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Editor.HtmlCss.Resources</a> namespace.

## Preparations

Let's prepare an <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> instance by loading and editing some input WordProcessing document, as always (using directive is omitted for the sake of simplification):

```csharp
string inputDocxPath = "C://input/document.docx";
Editor editor = new Editor(inputDocxPath, new WordProcessingLoadOptions());
WordProcessingEditOptions editOptions = new WordProcessingEditOptions();
editOptions.FontExtraction = FontExtractionOptions.ExtractAll;// Enable max font extraction - ExtractAll
EditableDocument beforeEdit = editor.Edit(editOptions);// Create EditableDocument instance
```

## Obtaining resources

Now, when <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> instance is ready, it is possible to obtains resources from it, and <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> provides several ways for this.

First of all, resources can be retrieved by their type. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> contains four properties for every resource type:

* <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/images" target="_blank" rel="nofollow noopener noreferrer">EditableDocument.Images</a> - returns a List of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images/iimageresource" target="_blank" rel="nofollow noopener noreferrer">IImageResource</a>, interface, that is common for all images, raster and vector.
* <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/fonts" target="_blank" rel="nofollow noopener noreferrer">EditableDocument.Fonts</a> - returns a List of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.fonts/fontresourcebase" target="_blank" rel="nofollow noopener noreferrer">FontResourceBase</a>, abstract class, that is common for all fonts.
* <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/css" target="_blank" rel="nofollow noopener noreferrer">EditableDocument.Css</a> - returns a List of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.textual/csstext" target="_blank" rel="nofollow noopener noreferrer">CssText</a>, class, that represents one CSS stylesheet.
* [EditableDocument.Audio]((https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/audio)) - returns a List of [Mp3Audio]((https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.audio/mp3audio)), class, that represents one MP3 audio file. Added in ver 21.10.

Secondly, completely all resources may be obtained with a single property <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/allresources" target="_blank" rel="nofollow noopener noreferrer">EditableDocument.AllResources</a>. It returns a List of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources/ihtmlresource" target="_blank" rel="nofollow noopener noreferrer">IHtmlResource</a>, interface, that is common for absolutely all HTML resources, including images, fonts, stylesheets, and audio. The collection, returned by the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/allresources" target="_blank" rel="nofollow noopener noreferrer">AllResources</a> property, in fact is a concatenation of previous four.

Here is a source code:

```csharp
List<IImageResource> images = beforeEdit.Images;
List<FontResourceBase> fonts = beforeEdit.Fonts;
List<CssText> stylesheets = beforeEdit.Css;
List<Mp3Audio> audiofiles = beforeEdit.Audio;
List<IHtmlResource> allTogether = beforeEdit.AllResources;
```

If user wants to manually save instance of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> as HTML file with resources, he may use something like this:

```csharp
string outputFolder = "C://output/document_resources/";
foreach (IImageResource oneImage in images)
{
    oneImage.Save(Path.Combine(outputFolder, oneImage.FilenameWithExtension));
}
foreach (FontResourceBase oneFont in fonts)
{
    oneFont.Save(Path.Combine(outputFolder, oneFont.FilenameWithExtension));
}
foreach (CssText oneStylesheet in stylesheets)
{
    oneStylesheet.Save(Path.Combine(outputFolder, oneStylesheet.FilenameWithExtension));
}
foreach (Mp3Audio oneMp3 in audiofiles)
{
    oneMp3.Save(Path.Combine(outputFolder, oneMp3.FilenameWithExtension));
}
System.IO.File.WriteAllText("c://output/document.html", beforeEdit.GetContent());
```

## CSS resources

There also is a third way, that is designed especially for the stylesheets. The reason is that stylesheets can contain external resources too, which are presented as links with urls. For example, it can be images, fonts, and other stylesheets. In such case it is necessary to adjust such link. For coping with this <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> contains two overloads of the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/getcsscontent" target="_blank" rel="nofollow noopener noreferrer">GetCssContent()</a> method.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/getcsscontent" target="_blank" rel="nofollow noopener noreferrer">First overload</a> is parameterless and returns a `List` of strings, each one represents one stylesheet. In most cases document has only one stylesheet, so such list will have only one item. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/getcsscontent/#getcsscontent_1" target="_blank" rel="nofollow noopener noreferrer">Second overload</a> obtains two string parameters: `externalImagesPrefix` and `externalFontsPrefix`. First parameter is designated for images, while second - for fonts. Both overloads are shown in example below:

```csharp
List<string> stylesheetsWithoutPrefixes = beforeEdit.GetCssContent();
string externalImagesPrefix = "http://www.mywebsite.com/images/id=";
string externalFontsPrefix = "http://www.mywebsite.com/fonts/id=";
List<string> stylesheetsWithPrefixes = beforeEdit.GetCssContent(externalImagesPrefix, externalFontsPrefix);
```

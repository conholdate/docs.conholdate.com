> This article describes classes and interfaces of <a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Editor**</a>, which represent all supportable family formats and individual formats.

GroupDocs.Editor supports different document formats, all of them are conditionally divided onto several family formats:

1. WordProcessing formats, which includes DOC, DOCX, DOCM, RTF, ODT etc.
2. Spreadsheet formats, which includes XLS, XLT, XLSX, XLSM, XLTX, ODS etc.
3. Delimiter-Separated Values (DSV) formats, also known as delimited text, that are text-based form of spreadsheets, and includes CSV, TSV, semicolon-delimited, whitespace-delimited etc.
4. Presentation formats, which includes PPT, PPS, POT, PPTX, PPTM etc.
5. Text-based formats, which includes TXT, HTML, XML etc.
6. Fixed-layout formats, which includes PDF and XPS formats, where their representation is "baked" to be uniform on every platform.
7. eBook formats, which includes Mobi, AZW3 and ePub.
8. Email formats, which includes MSG, EML, PST and others.

For representing some of these format families the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/" target="_blank" rel="nofollow noopener noreferrer">Formats</a> namespace and <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/idocumentformat" target="_blank" rel="nofollow noopener noreferrer">IDocumentFormat</a> interface exists, along with seven inheritors of this interface:

1. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">WordProcessingFormats</a>, which is common for all WordProcessing formats.
2. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/spreadsheetformats" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetFormats</a>, which is common for all Spreadsheet formats.
3. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/presentationformats" target="_blank" rel="nofollow noopener noreferrer">PresentationFormats</a>, which is common for all Presentation formats.
4. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/textualformats" target="_blank" rel="nofollow noopener noreferrer">TextualFormats</a>, which is common for all text-based formats, including plain text (TXT), markup formats (XML and HTML), and all Delimiter-Separated Values (DSV) formats.
5. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/ebookformats" target="_blank" rel="nofollow noopener noreferrer">EBookFormats</a>, which is common for all E-book formats, including MOBI, AZW3, and ePub.
6. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/fixedlayoutformats" target="_blank" rel="nofollow noopener noreferrer">FixedLayoutFormats</a>, which is common for only the PDF and XPS (this includes OpenXPS).
7. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/emailformats" target="_blank" rel="nofollow noopener noreferrer">EmailFormats</a>, which is common for all electronic mail formats.

All these types are immutable structs, all of them have text properties, which reflect their names, MIME codes, and file extensions, all of them are equatable. Every struct has a set of static fields, each one represents one specific format within given family format. For every struct there is a `FromExtension` static method, that obtains a file extension, parses it and returns an instance of appropriate format. Every struct has an `All` static field, which allows enumeration over all specific formats within given family format.

Example below demonstrates all main features for the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">WordProcessingFormats</a> struct; same is applicable for all other structs.

```csharp
//fetching one format
WordProcessingFormats dotm = Formats.WordProcessingFormats.Dotm;
Console.WriteLine("DOT Macro-enabled: Name is {0}, extension is {1}", dotm.Name, dotm.Extension);
//iterating over all formats within WordProcessing family
foreach (WordProcessingFormats oneFormat in Formats.WordProcessingFormats.All)
{
    Console.WriteLine("Name is {0}, extension is {1}", oneFormat.Name, oneFormat.Extension);
}
//Parsing from extension
Formats.WordProcessingFormats expectedDocm = WordProcessingFormats.FromExtension(".docm");
```

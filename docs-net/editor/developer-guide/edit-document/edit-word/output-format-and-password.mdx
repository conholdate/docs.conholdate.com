<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> class is responsible for tuning and adjusting the saving process, when <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> instance, that contains already edited document content, should be converted to the output document of some WordProcessing format. In other words, the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> class specifies how exactly the edited HTML should be saved to the output document.

Unlike load and edit options, <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> class has one mandatory <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/wordprocessingsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">constructor</a>, that obtains one parameter - `outputFormat`. The `outputFormat` parameter has a <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingFormats`</a> type. In turn, this type contains all supported formats from the <a href="https://docs.fileformat.com/word-processing/" target="_blank" rel="nofollow noopener noreferrer">family of WordProcessing formats</a>, which are supportable for saving document. Each field of <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingFormats`</a> struct represent one separate WordProcessing format - DOC, DOCX, RTF, ODT etc. There is also an <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats/fields/all" target="_blank" rel="nofollow noopener noreferrer">`All`</a> field, that allows to enumerate over all WordProcessing formats. So, with the `outputFormat` parameter user should select a specific format of the output WordProcessing document, which should be generated by the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`editor.Save()`</a> method.

This constructor is mandatory, because it is unacceptable to create a <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> instance without output format; otherwise, how GroupDocs.Editor "should know" into which specific format the document should be saved? However, output format can be changed later, after creating an instance of the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> class, with the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/outputformat" target="_blank" rel="nofollow noopener noreferrer">`OutputFormat`</a> property. This property also has a getter, that allows to obtain output format, specified previously in a constructor.

Almost all WordProcessing formats, especially with binary nature, support file encoding with the password. If such document is encoded, it is required to specify a password for opening it. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> class has the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/password" target="_blank" rel="nofollow noopener noreferrer">next property</a>, which allows to set a password:

```csharp
public string Password { get; set; }
```

By default the value of this property is `NULL`, which means that password will not be applied. If user specifies a string in this property, the output document will be encoded and protected with this string as a password. If user had specified some password in this property at some step, but then wants to dismiss password and do not encode the document, he can set the value to NULL or empty string, - both these values will be interpreted as "do not set a password" when calling the <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`editor.Save()`</a> method.

GroupDocs.Conversion provides the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> class to give you control over the conversion result while converting to JSON, XML or other web data formats. To convert your document to XML or JSON format, specify the desired format using the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> property.

The following code snippet shows how to convert a CSV spreadsheet to JSON format:

```csharp
using (Converter converter = new Converter("sample.csv"))
{
    WebConvertOptions options = new WebConvertOptions
    {
        Format = WebFileType.Json
    };
    converter.Convert("converted.json", options);
}
```

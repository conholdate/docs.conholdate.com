GroupDocs.Conversion provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a> to give you control over conversion result when convert to powerpoint presentation format. Along with [common convert options](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) from base class <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a> has the following additional options:

*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** specifies desired result document type. Available options are: *Ppt, Pps, Pptx, Ppsx, Odp, Otp, Potx, Pot, Potm, Pptm, Ppsm*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** whether the converted document will be password protected with the specified password.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a>** specifies the zoom level in percentage.

The following code snippet shows how to convert to Presentation with advanced options:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PresentationConvertOptions options = new PresentationConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Format = PresentationFileType.Ppt
    };
    converter.Convert("converted.ppt", options);
}
```

GroupDocs.Conversion provides the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a> class to give you control over conversion results. Along with [common convert options](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) you can specify the following additional options via the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a> class:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> sets the desired file type the input document should be converted to.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pagewidth" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a> sets the desired page width in points after conversion (1 point = 1/72 inch). When set, PageSize is automatically changed to Custom.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pageheight" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a> sets the desired page height in points after conversion (1 point = 1/72 inch). When set, PageSize is automatically changed to Custom.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> sets the desired page size. Available options are: *Default, A3, A4, A5, Letter, Legal, Tabloid*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pageorientation" target="_blank" rel="nofollow noopener noreferrer">PageOrientation</a> sets the page orientation. Available options are: *Default, Landscape, Portrait*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/fallbackpagesize" target="_blank" rel="nofollow noopener noreferrer">FallbackPageSize</a> sets the fallback page size to use when the input document's page size cannot be determined.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/dpi" target="_blank" rel="nofollow noopener noreferrer">Dpi</a> sets the desired page DPI after conversion
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> when specified, the resulting document will be protected with the specified password.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/margintop" target="_blank" rel="nofollow noopener noreferrer">MarginTop</a> sets the desired page top margin after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginbottom" target="_blank" rel="nofollow noopener noreferrer">MarginBottom</a> sets the desired page bottom margin after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginleft" target="_blank" rel="nofollow noopener noreferrer">MarginLeft</a> sets the desired page left margin after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginright" target="_blank" rel="nofollow noopener noreferrer">MarginRight</a> sets the desired page right margin after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a> defines the PDF-specific convert options. See [below](#pdfoptions).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/rotate" target="_blank" rel="nofollow noopener noreferrer">Rotate</a> sets the page rotation angle. Available options are: *None, On90, On180, On270*.

The following code snippet shows how to convert to PDF with advanced options:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Rotate = Rotation.On180,
        Dpi = 300,
        PageWidth = 595,   // A4 width in points (8.27 inches)
        PageHeight = 841   // A4 height in points (11.69 inches)
    };
    converter.Convert("converted.pdf", options);
}
```

## Page Size and Orientation

You can control page size and orientation using predefined sizes or custom dimensions.

### Using Predefined Page Size

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageSize = PageSize.A4,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("a4-portrait.pdf", options);
}
```

### Setting Landscape Orientation

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageSize = PageSize.Letter,
        PageOrientation = PageOrientation.Landscape
    };
    converter.Convert("letter-landscape.pdf", options);
}
```

### Using Fallback Page Size

The fallback page size is used when the input document's page size cannot be determined:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        FallbackPageSize = PageSize.A4
    };
    converter.Convert("with-fallback.pdf", options);
}
```

### PdfOptions

The <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a> class provides specific options when converting documents to different versions of PDF format.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/pdfformat" target="_blank" rel="nofollow noopener noreferrer">PdfFormat</a>  sets the specific PDF format of the converted document. Available options are: *Default, PdfA\_1A, PdfA\_1B, PdfA\_2A, PdfA\_3A, PdfA2B, PdfA\_2U, PdfA\_3B, PdfA\_3U, v1\_3, v1\_4, v1\_5, v1\_6, v1\_7, PdfX\_1A, PdfX\_3*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/removepdfacompliance" target="_blank" rel="nofollow noopener noreferrer">RemovePdfACompliance</a> whether to remove the Pdf-A compliance.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a> specifies the zoom level in percentage.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/linearize" target="_blank" rel="nofollow noopener noreferrer">Linearize</a> whether to linearize the document for the Web.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a> whether to convert the document to grayscale.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/optimizationoptions" target="_blank" rel="nofollow noopener noreferrer">OptimizationOptions</a> defines the PDF optimization options. See [below](#pdfoptimizationoptions).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/formattingoptions" target="_blank" rel="nofollow noopener noreferrer">FormattingOptions</a> defines the PDF formatting options. See [below](#pdfformattingoptions).

The following code snippet shows how to specify options via the `PdfOptions` class:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {        
        PdfOptions = new PdfOptions
        {
            Grayscale = true,
            Zoom = 200
        }
    };
    converter.Convert("converted.pdf", options);
}
```

### PdfOptimizationOptions

The <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptimizationOptions</a> class specifies options for adjusting the PDF conversion process and improving its speed.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/linkduplicatestreams" target="_blank" rel="nofollow noopener noreferrer">LinkDuplicateStreams</a> whether to link duplicate streams.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/removeunusedobjects" target="_blank" rel="nofollow noopener noreferrer">RemoveUnusedObjects</a> whether to remove unused objects.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/removeunusedstreams" target="_blank" rel="nofollow noopener noreferrer">RemoveUnusedStreams</a> whether to remove unused streams.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/compressimages" target="_blank" rel="nofollow noopener noreferrer">CompressImages</a> whether to re-compress all the images in the document. The amount of compression is defined by the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/imagequality" target="_blank" rel="nofollow noopener noreferrer">ImageQuality</a> property.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/imagequality" target="_blank" rel="nofollow noopener noreferrer">ImageQuality</a> defines the quality (in percentage) of image compression. Effective when the `CompressImages` property is set to `true`. To keep the original quality and image size set this property to 100. To decrease the image size set this property to less than 100.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/unembedfonts" target="_blank" rel="nofollow noopener noreferrer">UnembedFonts</a> whether to replace the embedded fonts with references to these fonts. Decreases the file size, but may change the original design of the document.

The following code snippet shows how to specify PDF optimization options:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {        
        PdfOptions = new PdfOptions
        {
            OptimizationOptions = new PdfOptimizationOptions
            { 
                CompressImages = true,
                ImageQuality = 70,
                UnembedFonts = true
            }
        }
    };
    converter.Convert("converted.pdf", options);
}
```

### PdfFormattingOptions

The <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions" target="_blank" rel="nofollow noopener noreferrer">PdfFormattingOptions</a> class provides different options to change the formatting of the resulting document.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/centerwindow" target="_blank" rel="nofollow noopener noreferrer">CenterWindow</a> whether to position the document's window in the center of the screen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/direction" target="_blank" rel="nofollow noopener noreferrer">Direction</a> defines the reading direction of the document: left to right or right to left. Available options are: *L2R, R2L*
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/displaydoctitle" target="_blank" rel="nofollow noopener noreferrer">DisplayDocTitle</a> whether to display the document title in the window's title bar.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/fitwindow" target="_blank" rel="nofollow noopener noreferrer">FitWindow</a> whether to resize the document window to fit the first displayed page.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidemenubar" target="_blank" rel="nofollow noopener noreferrer">HideMenuBar</a> whether to hide the menu bar when the document is active.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidetoolbar" target="_blank" rel="nofollow noopener noreferrer">HideToolBar</a> whether to hide the toolbar when the document is active.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidewindowui" target="_blank" rel="nofollow noopener noreferrer">HideWindowUI</a> whether to hide user interface elements when the document is active.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/nonfullscreenpagemode" target="_blank" rel="nofollow noopener noreferrer">NonFullScreenPageMode</a> - defines how to display the document when switching from the full-screen mode. Available options are: *UseNone, UseOutlines, UseThumbs, FullScreen, UseOC, UseAttachments*
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/pagelayout" target="_blank" rel="nofollow noopener noreferrer">PageLayout</a> defines the page layout to use when the document is opened. Available options are: *Default, SinglePage, OneColumn, TwoColumnLeft, TwoColumnRight, TwoPagesLeft, TwoPagesRight*
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/pagemode" target="_blank" rel="nofollow noopener noreferrer">PageMode</a> defines how to display the document when it is opened. Available options are: *UseNone, UseOutlines, UseThumbs, FullScreen, UseOC, UseAttachments*

The following code snippet shows how to specify PDF formatting options:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {
        PdfOptions = new PdfOptions
        {
            FormattingOptions = new PdfFormattingOptions
            {
                FitWindow = true,
                HideWindowUI = true,
                PageMode = PdfPageMode.UseThumbs
            }
        }
    };
    converter.Convert("converted.pdf", options);
}
```

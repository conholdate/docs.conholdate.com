GroupDocs.Conversion provides the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a> class to give you control over conversion result when convert to WordProcessing formats. Along with [common convert options](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) from base class <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a> has the following additional options:

*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** specifies desired result document type. Available options are: *Doc, Docm, Docx, Dot, Dotx, Rtf, Odt, Ott, Mobi, Txt, Md*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pagewidth" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a>** specifies desired page width in points after conversion (1 point = 1/72 inch). When set, PageSize is automatically changed to Custom.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pageheight" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a>** specifies desired page height in points after conversion (1 point = 1/72 inch). When set, PageSize is automatically changed to Custom.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a>** specifies page size. Available options are: *Default, A3, A4, A5, Letter, Legal, Tabloid*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pageorientation" target="_blank" rel="nofollow noopener noreferrer">PageOrientation</a>** specifies page orientation. Available options are: *Default, Landscape, Portrait*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/fallbackpagesize" target="_blank" rel="nofollow noopener noreferrer">FallbackPageSize</a>** specifies the fallback page size to use when the input document's page size cannot be determined.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/dpi" target="_blank" rel="nofollow noopener noreferrer">Dpi</a>** specifies desired page dpi after conversion. The default resolution is 96 dpi.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/margintop" target="_blank" rel="nofollow noopener noreferrer">MarginTop</a>** specifies the desired page top margin in points after conversion.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginbottom" target="_blank" rel="nofollow noopener noreferrer">MarginBottom</a>** specifies the desired page bottom margin in points after conversion.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginleft" target="_blank" rel="nofollow noopener noreferrer">MarginLeft</a>** specifies the desired page left margin in points after conversion.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginright" target="_blank" rel="nofollow noopener noreferrer">MarginRight</a>** specifies the desired page right margin in points after conversion.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** whether the converted document will be password protected with the specified password.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pdfrecognitionmode" target="_blank" rel="nofollow noopener noreferrer">PdfRecognitionMode</a>** specifies the recognition mode when converting from PDF. Available options are: *Textbox, Flow*. Flow mode is recommended for maximum content editability.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/rtfoptions" target="_blank" rel="nofollow noopener noreferrer">RtfOptions</a>** specifies RTF specific options. See [below](#rtfoptions).
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/markdownoptions" target="_blank" rel="nofollow noopener noreferrer">MarkdownOptions</a>** specifies Markdown specific options when converting to Markdown format.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a>** specifies the zoom level in percentage. Default is 100.

The following code snippet shows how to convert to WordProcessing with advanced options:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Format = WordProcessingFileType.Docx,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("converted.docx", options);
}
```

## Page Size and Dimensions

You can control page size using either predefined sizes or custom dimensions:

### Using Predefined Page Size

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageSize = PageSize.A4,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("a4-document.docx", options);
}
```

### Using Custom Dimensions

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageWidth = 612,   // 8.5 inches × 72 points/inch
        PageHeight = 792   // 11 inches × 72 points/inch
    };
    converter.Convert("custom-size.docx", options);
}
```

## Page Margins

Set custom margins for all four sides:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        MarginTop = 72,     // 1 inch
        MarginBottom = 72,  // 1 inch
        MarginLeft = 90,    // 1.25 inches
        MarginRight = 90    // 1.25 inches
    };
    converter.Convert("margins-document.docx", options);
}
```

## PDF Recognition Mode

When converting from PDF, control how content is interpreted:

```csharp
using (Converter converter = new Converter("document.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PdfRecognitionMode = PdfRecognitionMode.Flow  // Recommended for editable content
    };
    converter.Convert("editable-document.docx", options);
}
```

Available recognition modes:
- **Textbox** - Preserves exact layout using textboxes (less editable)
- **Flow** - Optimizes for content flow and editability (recommended)

### RtfOptions

The <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/rtfoptions" target="_blank" rel="nofollow noopener noreferrer">RtfOptions</a> class provides RTF-specific convert options:

*   **ExportImagesForOldReaders** - specifies whether the keywords for "old readers" are written to RTF or not. This can significantly affect the size of the RTF document.

The following code snippet shows how to convert to RTF with specific options:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        Format = WordProcessingFileType.Rtf,
        RtfOptions = new RtfOptions
        {
            ExportImagesForOldReaders = true
        }
    };
    converter.Convert("converted.rtf", options);
}
```

## Convert to Markdown

Convert documents to Markdown format:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        Format = WordProcessingFileType.Md
    };
    converter.Convert("converted.md", options);
}
```

Markdown output has dedicated options for controlling how images are handled - inlined as base64 (default) or routed through a custom callback. See [Convert to Markdown with advanced options](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-markdown-with-advanced-options/).

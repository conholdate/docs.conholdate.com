GroupDocs.Conversion provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> to give you control over conversion result when convert to image. Along with [common convert options](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) from the base class, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> has the following additional options:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> specifies desired result document type. Available options are: *Tiff, Tif, Jpg, Jpeg, Png, Gig, Bmp, Ico, Psd, Wmf, Emf, Dcm, Webp, Dng, Svg, Jp2, Odg, J2c, J2k, Jpx, Jpf, Jpm, Eps, Cgm, Cdr, Cmx, Dib, Jpc, Jls, DjVu*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> specifies desired image width after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> specifies desired image height after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/horizontalresolution" target="_blank" rel="nofollow noopener noreferrer">HorizontalResolution</a> specifies desired image horizontal resolution after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/verticalresolution" target="_blank" rel="nofollow noopener noreferrer">VerticalResolution</a> specifies desired image vertical resolution after conversion.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a> specifies if true converted image will be grayscaled.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/rotateangle" target="_blank" rel="nofollow noopener noreferrer">RotateAngle</a> specifies image rotation angle.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/flipmode" target="_blank" rel="nofollow noopener noreferrer">FlipMode</a> specifies image flip mode. Available options are: *None, FlipX, FlipY, FlipXY*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/brightness" target="_blank" rel="nofollow noopener noreferrer">Brightness</a> adjusts image brightness.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/contrast" target="_blank" rel="nofollow noopener noreferrer">Contrast</a> adjusts image contrast.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/gamma" target="_blank" rel="nofollow noopener noreferrer">Gamma</a> adjusts image gamma.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> sets the background color where supported by the source format.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/croparea" target="_blank" rel="nofollow noopener noreferrer">CropArea</a> crops a rectangular area from the raster image after conversion. Specify as Rectangle(x, y, width, height).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/jpegoptions" target="_blank" rel="nofollow noopener noreferrer">JpegOptions</a> contains JPEG specific convert options.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/tiffoptions" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a> contains TIFF specific convert options.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/psdoptions" target="_blank" rel="nofollow noopener noreferrer">PsdOptions</a> contains PSD specific convert options.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/webpoptions" target="_blank" rel="nofollow noopener noreferrer">WebpOptions</a> contains WebP specific convert options.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/usepdf" target="_blank" rel="nofollow noopener noreferrer">UsePdf</a>. Sometimes, for better rendering and elements positioning the source document should be converted to PDF first. If this property is set to *true*, the input firstly is converted to PDF and after that to desired format.

The following code snippet shows how to convert to image with advanced options:

```csharp
string outputFileTemplate = Path.Combine(@"c:\output", "converted-page-{0}.png");
Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format(outputFileTemplate, saveContext.Page), FileMode.Create);
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        FlipMode = ImageFlipModes.FlipY,
        Brightness = 50,
        Contrast = 50,
        Gamma = 0.5F,
        Grayscale = true,
        HorizontalResolution = 300,
        VerticalResolution = 100
    };

    converter.Convert(getPageStream, options);
}
```

## Setting Background Color

Set a background color for the converted image where supported by the source format:

```csharp
using System.Drawing;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.White  // Use System.Drawing.Color
    };
    converter.Convert("white-background.png", options);
}
```

You can use any color from System.Drawing.Color or create custom colors:

```csharp
using System.Drawing;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.FromArgb(173, 216, 230)  // Light blue (RGB)
    };
    converter.Convert("custom-background.png", options);
}
```

## Cropping Image Area

Crop a specific rectangular area from the converted image. The CropArea property takes a Rectangle with X, Y coordinates for the top-left corner, and Width, Height for the dimensions:

```csharp
using GroupDocs.Conversion.Contracts;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        CropArea = new Rectangle(100, 100, 400, 300)  // X, Y, Width, Height
    };
    converter.Convert("cropped-image.png", options);
}
```

You can combine BackgroundColor and CropArea:

```csharp
using System.Drawing;
using GroupDocs.Conversion.Contracts;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.LightGray,
        CropArea = new Rectangle(50, 50, 512, 512)
    };
    converter.Convert("background-and-crop.png", options);
}
```

### JpegOptions

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions" target="_blank" rel="nofollow noopener noreferrer">JpegOptions</a> is subset of <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> which allow enhanced control over conversions to JPEG format.

The following options are available:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/quality" target="_blank" rel="nofollow noopener noreferrer">Quality</a> specifies desired image quality.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/colormode" target="_blank" rel="nofollow noopener noreferrer">ColorMode</a> sets JPEG color mode. Available options are: *Rgb, YCbCr, Cmyk, Ycck, Grayscale*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> sets JPEG compression methods. Available options are: *Baseline, Progressive, Lossless, JpegLs*.

### TiffOptions

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/tiffoptions" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a> is subset of  <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> which allow enhanced control over conversions to TIFF format.

The following options are available:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/tiffoptions/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> sets TIFF compression method. Available options are: None, Lzw, Ccitt3, Ccitt4, Rle.

### PsdOptions

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions" target="_blank" rel="nofollow noopener noreferrer">PsdOptions</a> is subset of  <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> which allow enhanced control over conversions to PSD format.

The following options are available:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/channelbitscount" target="_blank" rel="nofollow noopener noreferrer">ChannelBitsCount</a> sets bits count per channel.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/channelscount" target="_blank" rel="nofollow noopener noreferrer">ChannelsCount</a> sets color channels count.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/colormode" target="_blank" rel="nofollow noopener noreferrer">ColorMode</a> sets PSD color mode. Available options are: *Bitmap, Grayscale, Indexed, Rgb, Cmyk, Multichannel, Duotone, Lab*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> sets PSD compression method. Available options are: *Raw, Rle, ZipWithoutPrediction, ZipWithPrediction*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/version" target="_blank" rel="nofollow noopener noreferrer">Version</a> sets desired PSD version.

### WebpOptions

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webpoptions" target="_blank" rel="nofollow noopener noreferrer">WebpOptions</a> is subset of  <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> which allow enhanced control over conversions to WebP format.

The following options are available:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webpoptions/lossless" target="_blank" rel="nofollow noopener noreferrer">Lossless</a> sets the compression of the converted image will be lossless.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webpoptions/quality" target="_blank" rel="nofollow noopener noreferrer">Quality</a> sets set the quality of converted image.

**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** allows you to apply a watermark to the converted document.  You can set the following options for controlling how the watermark will be stamped in the converted document:

### WatermarkOptions

* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>** - watermark text
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/watermarkfont" target="_blank" rel="nofollow noopener noreferrer">Font</a>** - watermark font name
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/color" target="_blank" rel="nofollow noopener noreferrer">Color</a>** - watermark color
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** - watermark width
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** - watermark height
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/top/" target="_blank" rel="nofollow noopener noreferrer">Top</a>** - watermark top position
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/left" target="_blank" rel="nofollow noopener noreferrer">Left</a>** - watermark left position
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/rotationangle" target="_blank" rel="nofollow noopener noreferrer">RotationAngle</a>** - watermark rotation angle
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/transparency" target="_blank" rel="nofollow noopener noreferrer">Transparency</a>** - watermark transparency
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/background" target="_blank" rel="nofollow noopener noreferrer">Background</a>** - specifies that the watermark is stamped as background. If the value is true, the watermark is laid at the bottom. By default is false and the watermark is laid on top

To add a watermark, follow these steps:

1. Create an instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class and pass source document path as a constructor parameter
2. Instantiate the appropriate <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> class e.g. **(<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>** etc.)
3. Create an instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions" target="_blank" rel="nofollow noopener noreferrer">WatermarkTextOptions</a> class. Set appropriate properties to specify the watermark color, width, height, text, image etc.
4. Set the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> property of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> instance with the instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions" target="_blank" rel="nofollow noopener noreferrer">WatermarkTextOptions</a> class created in the previous step
5. Call the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert" target="_blank" rel="nofollow noopener noreferrer">Convert</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class instance and pass filename for the converted document and the instance of <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> from the previous step

The following code snippet shows how to apply watermark to the output document:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    WatermarkOptions watermark = new WatermarkTextOptions("Sample watermark")
    {
        Color = Color.Red,
        Width = 100,
        Height = 100,
        Background = true
    };
    PdfConvertOptions options = new PdfConvertOptions
    {
        Watermark = watermark
    };
    converter.Convert("converted.pdf", options);
}
```

**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** allows you to get default predefined convert options for a desired target document format. This will allow you to get predefined convert options runtime, knowing the desired target format.

To get default convert options, follow these steps:

1.   Create an instance of <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class and pass source document path as a constructor parameter.
2.   Invoke the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversions</a> converter method.
3.   Use the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/item" target="_blank" rel="nofollow noopener noreferrer">file type</a> or <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/item/#possibleconversions-indexer-2-of-2" target="_blank" rel="nofollow noopener noreferrer">file extension</a> indexer of the received possible conversion and read the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/targetconversion/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> property.
4.   Call the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class instance and pass the filename of the converted document and the instance of <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> from the previous step.

The following code snippet shows how to get predefined convert options for a desired target format:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    var possibleConversion = converter.GetPossibleConversions();
    var convertOptions = possibleConversion["pdf"].ConvertOptions;
    converter.Convert(outputFile, convertOptions);
}
```

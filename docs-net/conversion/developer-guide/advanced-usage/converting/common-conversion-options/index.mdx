<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> has many different <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> which gives control over required conversion result. All <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> have some common properties which are:

* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a> specifies the page number from which the conversion should start from.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a> specifies the number of pages to be converted.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> is a list of specific page number to be converted.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> sets watermark options.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a> specifies the desired file type the input document should be converted to.

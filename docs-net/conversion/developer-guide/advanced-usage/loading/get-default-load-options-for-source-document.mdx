**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** allows you to get default load options for the source document format. This will allow you to get default load options runtime, knowing the source format.

To get default options, follow these steps:

1.   Call the static <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions/" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversion</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class with source file extension as a parameter.
2.   From received possible conversion read the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> property.
3.   Create an instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class and pass source document path as a constructor parameter and load options from the previous step.
4.   Instantiate the appropriate <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> class e.g. (**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>** etc.).
5.   Call the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class instance and pass filename for the converted document and the instance of <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> from the previous step.

The following code snippet shows how to get default load options for a Word processing document:

```csharp
var possibleConversions = Converter.GetPossibleConversions("docx");
var loadOptions = (WordProcessingLoadOptions) possibleConversions.LoadOptions;
loadOptions.Password = "12345";

using (Converter converter = new Converter("password_protected.docx", (LoadContext loadContext) => loadOptions))
{
    var convertOptions = new PdfConvertOptions();
    converter.Convert(outputFile, convertOptions);
}
```

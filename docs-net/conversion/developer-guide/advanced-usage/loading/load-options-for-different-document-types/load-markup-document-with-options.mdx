GroupDocs.Conversion provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions" target="_blank" rel="nofollow noopener noreferrer">WebLoadOptions</a> to give you control over how the source markup document will be processed. The following options could be set:
| Option | Description |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/basepath" target="_blank" rel="nofollow noopener noreferrer">BasePath</a>** | Specifies the base path/url for the HTML. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>** | Specifies the encoding to be used to load the document. If not specified, the encoding will be determined from the document's character set attribute. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/pagenumbering" target="_blank" rel="nofollow noopener noreferrer">PageNumbering</a>** | Whether to generate page numbers for the converted document. Default: false. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/resourceloadingtimeout" target="_blank" rel="nofollow noopener noreferrer">ResourceLoadingTimeout</a>** | Specifies the timeout of loading the external resources. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/skipexternalresources" target="_blank" rel="nofollow noopener noreferrer">SkipExternalResources</a>** | If enabled, the external resources (except for those listed in `WhitelistedResources`) will not be loaded during the conversion. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/whitelistedresources" target="_blank" rel="nofollow noopener noreferrer">WhitelistedResources</a>** | Specifies which external resources will be loaded even when the loading of other external resources is restricted. |

## Enable page numbering when converting to Word-processing formats

The following code snippet shows how to convert a markup document and insert page numbering:

```csharp
var source = "sample.html";
var loadOptions = new WebLoadOptions
{
    PageNumbering = true
};
using (var converter = new Converter(source, (LoadContext loadContext) => loadOptions))
{
    var options = new WordProcessingConvertOptions();
    converter.Convert("converted.docx" , options);
}
```

## Skip loading of external resources

External resources in the context of web documents refer to any files or data that a web page or website fetches from sources outside of its own domain or server. These external resources are essential for creating dynamic and feature-rich web experiences. Common external resources include images, audio, video, fonts, CSS, scripts, frameworks, and so on. 

In some cases, you may want to skip loading all or just some of the external resources during the conversion. For example, when these resources become unavailable. Read the [Skip loading of external resources](/net/conversion/developer-guide/advanced-usage/loading/skip-external-resources/) article to learn how to do this with **GroupDocs.Conversion for .NET**.

<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions" target="_blank" rel="nofollow noopener noreferrer">GisLoadOptions</a> to control how source GIS (Geographic Information System) documents are processed. GIS documents include formats like GeoJSON, KML, GPX, and other geospatial data files.

The following options are available:

| Option | Description |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | The document type is auto-detected during loading, but you can explicitly specify the source format. Available options include: *GeoJson, Gpx, Kml, Osm, TopoJson, Gml* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Sets the desired page width (in pixels) for rendering the GIS document. Default value is 1000. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Sets the desired page height (in pixels) for rendering the GIS document. Default value is 1000. |

## Load GeoJSON document

The following code snippet shows how to load a GeoJSON document with explicit format specification:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson
};

using (Converter converter = new Converter("map-data.geojson", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("map-data.pdf", options);
}
```

## Load GIS document with custom dimensions

The following code snippet shows how to load a GeoJSON document and set custom rendering dimensions:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson,
    Width = 1500,
    Height = 1200
};

using (Converter converter = new Converter("city-boundaries.geojson", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("city-boundaries.pdf", options);
}
```

## Convert GIS document to image

The following code snippet shows how to load a GeoJSON document and convert it to an image with custom dimensions:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson,
    Width = 800,
    Height = 600
};

using (Converter converter = new Converter("region-map.geojson", getLoadOptions))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png
    };
    converter.Convert("region-map.png", options);
}
```

## Convert between GIS formats

The following code snippet shows how to convert from GPX to KML format:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.Gpx
};

using (Converter converter = new Converter("hiking-trail.gpx", getLoadOptions))
{
    GisConvertOptions options = new GisConvertOptions
    {
        Format = GisFileType.Kml
    };
    converter.Convert("hiking-trail.kml", options);
}
```

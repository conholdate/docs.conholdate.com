<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions" target="_blank" rel="nofollow noopener noreferrer">CompressionLoadOptions</a> to control how source compression files are processed. Compression files include formats like ZIP, 7Z, RAR, TAR, GZIP, and other archive formats.

The following options are available:

| Option | Description |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | The document type is auto-detected during loading, but you can explicitly specify the source format. Available options include: *SevenZ, Bz2, Cab, Cpio, Gz, Gzip, Lz, Lzma, Rar, Tar, Xz, Z, Zip* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** | Set password to load protected archive |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/convertowned" target="_blank" rel="nofollow noopener noreferrer">ConvertOwned</a>** | The owned documents will be converted (read-only, set to true by default) |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/convertowner" target="_blank" rel="nofollow noopener noreferrer">ConvertOwner</a>** | The owner will not be converted (read-only, set to false by default) |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/depth" target="_blank" rel="nofollow noopener noreferrer">Depth</a>** | Controls recursion depth for nested documents. Default value is 3. |

## Load ZIP archive

The following code snippet shows how to load a ZIP archive with explicit format specification:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip
};

using (Converter converter = new Converter("documents-archive.zip", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("documents-archive.pdf", options);
}
```

## Convert between compression formats

The following code snippet shows how to convert from ZIP to 7Z format:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip
};

using (Converter converter = new Converter("source-archive.zip", getLoadOptions))
{
    CompressionConvertOptions options = new CompressionConvertOptions
    {
        Format = CompressionFileType.SevenZ
    };
    converter.Convert("source-archive.7z", options);
}
```

## Load password-protected archive

The following code snippet shows how to load a password-protected ZIP archive:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip,
    Password = "archive-password"
};

using (Converter converter = new Converter("protected-archive.zip", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("protected-archive.pdf", options);
}
```

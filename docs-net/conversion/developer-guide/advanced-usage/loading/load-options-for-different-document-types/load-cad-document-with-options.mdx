<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> provides <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions" target="_blank" rel="nofollow noopener noreferrer">CadLoadOptions</a> to give you control over how the source CAD document will be processed. The following options could be set:
| Option | Description |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | The source document type is auto-detected, but you could set the source document format explicitly with this property. Available options are: Dxf, Dwg, Dgn, Dwf, Stl, Ifc, Plt, Igs, Dwt |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/backgroundcolor/" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a>** | Specifies the background color for a CAD document. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/drawtype/" target="_blank" rel="nofollow noopener noreferrer">DrawType</a>** | Specifies the type of drawing of a CAD document. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Sets the desired page width |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Sets the desired page height |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/layoutnames" target="_blank" rel="nofollow noopener noreferrer">LayoutNames</a>** | Specifies which CAD layout to be converted |

### Specify layouts to be converted

The following code snippet shows how to convert a CAD document and convert only certain layouts:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CadLoadOptions
{
    LayoutNames = new []{ "Layout1", "Layout3" }
};
using (Converter converter = new Converter("with_layers_and_layouts.dwg", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Specify background color

The following code snippet shows how to convert a CAD document and specify its desired background color:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CadLoadOptions
{
    BackgroundColor = System.Drawing.Color.White
};
using (Converter converter = new Converter("sample.dwg", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

To load the source file from a local disk, use the following implementations of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class constructor:

* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_7" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath)</a>
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_8" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath, Func&lt;ConverterSettings&gt; settings)</a>
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_9" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath, Func&lt;LoadOptions&gt; loadOptions)</a>
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_10" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath, Func&lt;LoadOptions&gt; loadOptions, Func&lt;ConverterSettings&gt; settings)</a>
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_11" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath, Func&lt;FileType, LoadOptions&gt; loadOptions)</a>
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/converter/#constructor_12" target="_blank" rel="nofollow noopener noreferrer">Converter(string filePath, Func&lt;FileType, LoadOptions&gt; loadOptions, Func&lt;ConverterSettings&gt; settings)</a>

All these constructors have the `filePath` string parameter which specifies the location of the source file. File path can be absolute or relative. If the source file does not exist, an exception occurs.

GroupDocs.Conversion will open the file for reading only when any other methods of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class are called.

The following code snippet shows how to load a file from a local disk:

```csharp
public static void Run()
{
    // Specify source file location
    using (Converter converter = new Converter("c:\\files\\sample.docx")) 
    {
        PdfConvertOptions options = new PdfConvertOptions();
        // Specify output file location
        converter.Convert("c:\\files\\converted.pdf", options);
    }
}
```

You can also use the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/fluentconverter/load/#load_2" target="_blank" rel="nofollow noopener noreferrer">FluentConverter.Load(string fileName)</a> and [FluentConverter.Load(string[] fileName)](https://reference.groupdocs.com/conversion/net/groupdocs.conversion/fluentconverter/load/#load_3) [fluent syntax](/net/conversion/developer-guide/basic-usage/fluent-syntax/) methods to load the source file from a local disk.

```csharp
public static void Run()
{
FluentConverter
    // Specify source file location
    .Load("c:\\files\\sample.docx")
    // Specify output file location
    .ConvertTo("c:\\files\\converted.pdf")
    .Convert();
}
```

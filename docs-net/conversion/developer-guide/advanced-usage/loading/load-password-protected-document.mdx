<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> supports the conversion of documents that are protected with a password.

To load and convert a password-protected document, follow these steps:

1.   Define a Func&lt;<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>&gt; delegate, which should return an instance of document-specific load options with the password specified.
2.   Create an instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class and pass the source document path and the load options delegate as the constructor parameters.
3.   Instantiate the appropriate <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> class e.g. (**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>**, etc.)
4.   Call the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class instance and pass the filename for the converted document and the instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> from the previous step.

The following code snippet shows how to convert password protected document:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new WordProcessingLoadOptions
{
    Password = "12345"
};
using (Converter converter = new Converter("sample_with_password.docx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

You can also use [fluent syntax](/net/conversion/developer-guide/basic-usage/fluent-syntax/):

```csharp
FluentConverter
    .Load("sample_with_password.docx").WithOptions((LoadContext loadContext) => new WordProcessingLoadOptions
    {
        Password = "12345"
    })
    .ConvertTo("converted.pdf")
    .Convert();
```

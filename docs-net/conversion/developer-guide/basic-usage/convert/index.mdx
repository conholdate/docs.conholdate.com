**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** provides a quick and easy way to convert files from some source format to various ranges of target formats. The conversion process from the user's point of view is pretty simple - the source document is loaded to a converter and after conversion is completed, the result is saved to a desired file path on the local disk or other storage.  
  
By default, when performing internal calculations GroupDocs.Conversion for .NET uses some predefined settings that are most suitable for loading and saving specified file formats. However, the conversion process can always be adjusted by setting specific <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> to modify the way the source document is loaded - for example, it's needed to hide document comments, set up font substitution, set passwords for protected documents, etc. Also, the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> class is used to manage converted documents - add watermarks to resultant documents, change page orientation, set images height/width or resolution, and many more.  
  
The common conversion workflow always includes the following steps:

1. Loading the source document into a new instance of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class. You can provide a file path or a document stream.
2. Instantiate the appropriate <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> object according to your requirements and desired output format like <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a>, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>, and others.
3. Call the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> method of the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> object and pass the file path to save the resulting document with the convert options object from the previous step.

GroupDocs.Parser allows to get the list of all the supported file formats by the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> static method:

```csharp
IEnumerable<FileType> FileType.GetSupportedFileTypes();

```

This method returns a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> items with the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> | File type name e.g. "Microsoft Word Document". |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/extension" target="_blank" rel="nofollow noopener noreferrer">Extension</a> | Filename suffix (including the period ".") e.g. ".doc". |

Also <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> contains static fields that represent all the supported file formats.

Here are the steps to get all the supported file formats:

*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> static method and obtain a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> objects;
*   Iterate through the collection and get <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> or <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/extension" target="_blank" rel="nofollow noopener noreferrer">Extension</a> of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

The following example shows how to print all the supported file types:

```csharp
IEnumerable<FileType> supportedFileTypes = FileType.GetSupportedFileTypes();

foreach (FileType fileType in supportedFileTypes)
{
    Console.WriteLine(fileType);
}

```

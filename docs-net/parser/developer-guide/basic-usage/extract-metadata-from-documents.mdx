GroupDocs.Parser allows to extract basic metadata (document properties, file information) from documents of various formats: PDF, Emails, Ebooks, Microsoft Office: Word (DOC, DOCX), PowerPoint (PPT, PPTX), Excel (XLS, XLSX), LibreOffice formats and many others.


:::info
**Supported Formats:** For a complete list of formats that support metadata extraction, see the [Supported Document Formats](/net/parser/getting-started/supported-document-formats/) page.
:::


## Extract metadata from documents

To extract metadata from documents simply call the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method:

```csharp
IEnumerable<MetadataItem> GetMetadata();

```

This method returns a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem" target="_blank" rel="nofollow noopener noreferrer">MetadataItem</a> objects with following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> | The name of the metadata item |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem/properties/value" target="_blank" rel="nofollow noopener noreferrer">Value</a> | The value of the metadata item |

Here are the steps to extract metadata from the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method and obtain collection of document metadata objects;
*   Iterate through the collection and get metadata names and values.

The following example shows how to extract metadata from a document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract metadata from the document
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    // Check if metadata extraction is supported
    if (metadata == null)
    {
        Console.WriteLine("Metadata extraction isn't supported");
        return;
    }

    // Iterate over metadata items
    foreach (MetadataItem item in metadata)
    {
        // Print an item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

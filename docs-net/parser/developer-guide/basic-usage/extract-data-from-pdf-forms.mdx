GroupDocs.Parser allows to parse form data from PDF documents.

To extract PDF form data please call the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/parseform" target="_blank" rel="nofollow noopener noreferrer">ParseForm</a> method:

```csharp
DocumentData ParseForm()

```

This method returns an instance of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata" target="_blank" rel="nofollow noopener noreferrer">DocumentData</a> class with the extracted data.

Here are the steps to parse form of the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/parseform" target="_blank" rel="nofollow noopener noreferrer">ParseForm</a> method and obtain the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata" target="_blank" rel="nofollow noopener noreferrer">DocumentData</a> object;
*   Check if *data* isn't *null* (parse form is supported for the document);
*   Iterate over field data to obtain form data.

The following example shows how to parse a form of the document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract data from PDF document
    DocumentData data = parser.ParseForm();
    
    // Check if form extraction is supported
    if (data == null)
    {
        Console.WriteLine("Form extraction isn't supported");
        return;
    }
    
    // Iterate over extracted data
    for (int i = 0; i < data.Count; i++)
    {
        Console.Write(data[i].Name + ": ");
        PageTextArea area = data[i].PageArea as PageTextArea;
        Console.WriteLine(area == null ? "Not a template field" : area.Text);
    }
}
```

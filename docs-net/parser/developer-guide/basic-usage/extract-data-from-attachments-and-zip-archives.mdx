It is easy to extract data, text, images and use any GroupDocs.Parser feature for ZIP-archived documents. The same feature allows to get attachments from  PDF and Emails and extract data from them.

# Extract data from attachments and ZIP archives

To extract documents from ZIP files and get attachments from containers simply call the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> method:

```csharp
IEnumerable<ContainerItem> GetContainer()

```

This method returns a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a> objects:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> | The name of the item. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/directory" target="_blank" rel="nofollow noopener noreferrer">Directory</a> | The directory of the item. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/filepath" target="_blank" rel="nofollow noopener noreferrer">FilePath</a> | The full path of the item. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a> | The size of the item in bytes. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/metadata" target="_blank" rel="nofollow noopener noreferrer">Metadata</a> | The collection of item metadata. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/methods/openstream" target="_blank" rel="nofollow noopener noreferrer">OpenStream()</a> | Opens the stream of the item content. |
| Parser <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/methods/openparser" target="_blank" rel="nofollow noopener noreferrer">OpenParser()</a> | Creates the Parser object for the item content. |
| Parser <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.containeritem/openparser/methods/1" target="_blank" rel="nofollow noopener noreferrer">OpenParser(LoadOptions)</a> | Creates the Parser object for the item content with <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. |
| Parser <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.containeritem/openparser/methods/2" target="_blank" rel="nofollow noopener noreferrer">OpenParser(LoadOptions, ParserSettings)</a> | Creates the Parser object for the item content with <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> and <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a>. |

Container represents both container-only files (like zip archives, outlook storage) and documents with attachments (like emails, PDF Portfolios).

Here are the steps to extract an email text from outlook storage:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> method and obtain collection of document container item objects;
*   Check if *collection* isn't *null* (container extraction is supported for the document);
*   Iterate through the collection and obtain <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object to extract a text.

The following example shows how to extract a text from zip entities:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if (attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
    // Iterate over zip entities
    foreach (ContainerItem item in attachments)
    {
        // Print the file path
        Console.WriteLine(item.FilePath);
        try
        {
            // Create Parser object for the zip entity content
            using (Parser attachmentParser = item.OpenParser())
            {
                // Extract a zip entity text
                using (TextReader reader = attachmentParser.GetText())
                {
                    Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
                }
            }
        }
        catch (UnsupportedDocumentFormatException)
        {
            Console.WriteLine("Isn't supported.");
        }
    }
}
```

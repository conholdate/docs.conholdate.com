GroupDocs.Parser provides the functionality to get the basic document info by the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo</a> method:

```csharp
IDocumentInfo GetDocumentInfo();

```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo" target="_blank" rel="nofollow noopener noreferrer">IDocumentInfo</a> interface has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | The document type. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> | The total number of document pages. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a> | The size of the document in bytes. |

Here are the steps to get document info:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo</a> method and obtain the object with <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo" target="_blank" rel="nofollow noopener noreferrer">IDocumentInfo</a> interface;
*   Call properties such as <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> or <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>.

The following example shows how to get document info:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get the document info
    IDocumentInfo info = parser.GetDocumentInfo();
    
    // Print document information
    Console.WriteLine($"File Type: {info.FileType}");
    Console.WriteLine($"Page Count: {info.PageCount}");
    Console.WriteLine($"File Size: {info.Size} bytes");
}
```

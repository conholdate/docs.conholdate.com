GroupDocs.Parser .Net allows to scan barcode from PDF, Microsoft Office formats: Word (DOC, DOCX), PowerPoint (PPT, PPTX), LibreOffice formats and many others (see full list at [supported document formats](/net/parser/getting-started/supported-document-formats/) article).

GroupDocs.Parser's barcode scanner is easy to use and powerful at the same time. Our experience allowed us to implement sophisticated algorithms, which allows to read even damaged barcodes.

This article demonstrates how to implement the simplest scenario - read barcode from any supported format without additional settings (to resolve complex scenarios see [advanced usage section](/net/parser/developer-guide/advanced-usage/working-with-barcodes/). 

## How to scan barcode in .Net with GroupDocs.Parser

To scan barcode from your file, simply call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> method:

```csharp
IEnumerable<PageBarcodeArea> GetBarcodes();
```

This method returns a collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a> objects.

Here are the steps to extract a barcode from file:

- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial file;
- Check if the file supports barcodes extraction;
- Call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> method and obtain collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a> objects;
- Iterate through the collection and get a barcode value.

The following example shows how to scan barcodes:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the file supports barcode extraction
    if (!parser.Features.Barcodes)
    {
        Console.WriteLine("The file doesn't support barcode extraction.");
        return;
    }

    // Scan barcodes from the file
    IEnumerable<PageBarcodeArea> barcodes = parser.GetBarcodes();
    
    // Iterate over barcodes
    foreach (PageBarcodeArea barcode in barcodes)
    {
        // Print a barcode value
        Console.WriteLine(barcode.Value);
    }
}
```

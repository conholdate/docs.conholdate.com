GroupDocs.Parser allows to extract formatted text from documents for those cases when simple plain text is not enough and you may need to keep formatting like text style, table layout etc.

This feature allows to extract text with integrated HTML tags, or Markdown syntax. Even PlainText mode allows to convert your documents to high quality text with integrated ASCII formatting symbols for tables, lists etc.

## Extract formatted text from documents

To extract a formatted text from documents simply call the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText</a> method:

```csharp
TextReader GetFormattedText(FormattedTextOptions options);

```

Methods return an instance of <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a> class with an extracted text. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> has the following constructor:

```csharp
FormattedTextOptions(FormattedTextMode mode)

```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextmode" target="_blank" rel="nofollow noopener noreferrer">FormattedTextMode</a> enumeration has the following members:

| Member | Description |
| --- | --- |
| Html | Html format. |
| Markdown | Markdown format. |
| PlainText | Plain text format. |

Here are the steps to extract a HTML formatted text from the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> with HTML text mode;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText</a> method and obtain <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a> object;
*   Check if *reader* isn't *null* (formatted text extraction is supported for the document);
*   Read a text from *reader*.

The following example shows how to extract formatted text from a document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract formatted text as HTML
    using (TextReader reader = parser.GetFormattedText(new FormattedTextOptions(FormattedTextMode.Html)))
    {
        // If formatted text extraction isn't supported, reader is null
        Console.WriteLine(reader == null ? "Formatted text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

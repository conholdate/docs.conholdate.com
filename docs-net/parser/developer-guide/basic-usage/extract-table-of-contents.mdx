GroupDocs.Parser allows to extract table of contents from Microsoft Word (DOC, DOCX etc), PDF documents and Ebooks.

## Extract table of contents

To extract TOC from documents, please use the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method:

```csharp
IEnumerable<TocItem> GetToc()

```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> class has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/depth" target="_blank" rel="nofollow noopener noreferrer">Depth</a> | The depth level. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">PageIndex</a> | The page index. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | The text. |
| TextReader <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/extracttext" target="_blank" rel="nofollow noopener noreferrer">ExtractText()</a> | Extract a text from the document to which <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> object refers. For detail, see [Extract Text By Table of Contents Item](/net/parser/developer-guide/advanced-usage/working-with-text/extract-text-by-table-of-contents-item/) |

Here are the steps to extract extract table of contents from the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objects;
*   Check if *collection* isn't *null* (table of contents  extraction is supported for the document);
*   Iterate through the collection and get page index to extract a page text from the document.

The following example shows how to extract table of contents from CHM file:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if text extraction is supported
    if (!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported.");
        return;
    }
    // Check if toc extraction is supported
    if (!parser.Features.Toc)
    {
        Console.WriteLine("Toc extraction isn't supported.");
        return;
    }
    // Get table of contents
    IEnumerable<TocItem> toc = parser.GetToc();
    // Iterate over items
    foreach (TocItem i in toc)
    {
        // Print the Toc text
        Console.WriteLine(i.Text);
        // Check if page index has a value
        if (i.PageIndex == null)
        {
            continue;
        }
        // Extract a page text
        using (TextReader reader = parser.GetText(i.PageIndex.Value))
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}

```

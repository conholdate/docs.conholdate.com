GroupDocs.Parser provides the functionality to extract barcodes from documents by the <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> method:

```csharp
IEnumerable<PageBarcodeArea> GetBarcodes();
```

This method returns a collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a> objects:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | The page that contains the text area. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | The rectangular area on the page that contains the text area. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/properties/value" target="_blank" rel="nofollow noopener noreferrer">Value</a> | A string value that represents a value of the barcode page area. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/properties/codetypename" target="_blank" rel="nofollow noopener noreferrer">CodeTypeName</a> | A string value than represents a type name of the barcode. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/confidence/" target="_blank" rel="nofollow noopener noreferrer">Confidence</a> | The level of confidence of the parsered barcode. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/angle/" target="_blank" rel="nofollow noopener noreferrer">Angle</a> | The angle of the barcode. |

Here are the steps to extract all barcodes from the whole document:

- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
- Check if the document supports barcodes extraction;
- Call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> method and obtain collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a> objects;
- Iterate through the collection and get a barcode value.

The following example shows how to extract barcodes from a document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SamplePdfWithBarcodes))
{
    // Check if the document supports barcodes extraction
    if (!parser.Features.Barcodes)
    {
        Console.WriteLine("Document doesn't support barcodes extraction.");
        return;
    }

    // Extract barcodes from the document.
    IEnumerable<PageBarcodeArea> barcodes = parser.GetBarcodes();

    // Iterate over barcodes
    foreach (PageBarcodeArea barcode in barcodes)
    {
        // Print the page index
        Console.WriteLine("Page: " + barcode.Page.Index.ToString());
        // Print the barcode value
        Console.WriteLine("Value: " + barcode.Value);
    }
}
```

# Detect file type of container item

GroupDocs.Parser provides the functionality to detect a file type of container items by <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/containeritem/methods/detectfiletype" target="_blank" rel="nofollow noopener noreferrer">DetectFileType</a> method. <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/filetypedetectionmode" target="_blank" rel="nofollow noopener noreferrer">FileTypeDetectionMode</a> parameter provides the ability to control file type detection:

- Default. The file type is detected by the file extension; if the file extension  isn't recognized, the file type is detected by the file content.
- Extension. The file type is detected only by the file extension.
- Content. The file type is detected only by the file content.

Here are the steps to detect a file type of container items:

- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser </a>object for the initial document;
- Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> method and obtain the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a> objects;
- Check if *collection* isn't *null* (container extraction is supported for the document);
- Iterate through the collection and call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/containeritem/methods/detectfiletype" target="_blank" rel="nofollow noopener noreferrer">DetectFileType</a> method.

The following example shows how to detect a file type of container items:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if (attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
    // Iterate over attachments
    foreach (ContainerItem item in attachments)
    {
        // Detect the file type
        Options.FileType fileType = item.DetectFileType(Options.FileTypeDetectionMode.Default);
         
        // Print the name and file type
        Console.WriteLine(string.Format("{0}: {1}", item.Name, fileType));
    }
}
```

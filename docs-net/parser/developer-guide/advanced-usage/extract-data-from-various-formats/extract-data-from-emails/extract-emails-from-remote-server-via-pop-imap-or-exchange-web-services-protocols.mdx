GroupDocs.Parser allows you to extract emails from remote servers and data from the emails. The following email protocols are supported:

*   Post Office Protocol (POP)
*   Internet Message Access Protocol (IMAP)
*   Exchange Web Services (EWS)

To create an instance of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> class to extract emails from a remote server the following constructors are used:

```csharp
Parser(EmailConnection connection);
Parser(EmailConnection connection, ParserSettings parserSettings);
```

The second constructor allows to use <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a> object to control the process; for example, by adding [logging functionality](/net/parser/developer-guide/advanced-usage/logging/).

<a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailconnection" target="_blank" rel="nofollow noopener noreferrer">EmailConnection</a> is a base class. The following connection classes are used:

| Protocol | Class |
| --- | --- |
| POP | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailpopconnection" target="_blank" rel="nofollow noopener noreferrer">EmailPopConnection</a> |
| IMAP | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailimapconnection" target="_blank" rel="nofollow noopener noreferrer">EmailImapConnection</a> |
| Exchange Web Services | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailewsconnection" target="_blank" rel="nofollow noopener noreferrer">EmailEwsConnection</a> |

Here are the steps to extract emails from the remote server:

*   Prepare connection string (see table below);
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object with connection string;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/container" target="_blank" rel="nofollow noopener noreferrer">Features.Container</a> property to check if container extraction is supported;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> method and obtain collection of document container item objects;
*   Iterate through the collection and get <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for each item.

The following example shows how to extract emails from Exchange Server:

```csharp
// Create the connection object for Exchange Web Services protocol 
EmailConnection connection = new EmailEwsConnection(
    "https://outlook.office365.com/ews/exchange.asmx",
    "email@server",
    "password");
 
// Create an instance of Parser class to extract emails from the remote server
using (Parser parser = new Parser(connection))
{
    // Check if container extraction is supported
    if (!parser.Features.Container)
    {
        Console.WriteLine("Container extraction isn't supported.");
        return;
    }
 
    // Extract email messages from the server
    IEnumerable<ContainerItem> emails = parser.GetContainer();
 
    // Iterate over attachments
    foreach (ContainerItem item in emails)
    {
        // Create an instance of Parser class for email message
        using (Parser emailParser = item.OpenParser())
        {
            // Extract the email text
            using (TextReader reader = emailParser.GetText())
            {
                // Print the email text
                Console.WriteLine(reader == null ? "Text extraction isn't supported." : reader.ReadToEnd());
            }
        }
    }
}
```

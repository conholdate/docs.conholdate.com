To extract metadata from emails <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method is used. This method allows to extract the following metadata:

| Name | Description |
| --- | --- |
| subject | The email "subject" field. |
| email-sender | The email "from" field. |
| email-to | The email "to" field. May contain more than one address separated by semicolons. |
| email-cc | The email "cc" field. May contain more than one address separated by semicolons. |

Here are the steps to extract metadata from an email:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial email;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method and obtain collection of document metadata objects;
*   Iterate through the collection and get metadata names and values.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns *null* value if metadata extraction isn't supported for the document. For example, metadata extraction isn't supported for Zip archive. Therefore, for Zip archive <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns *null*. If an email has no metadata, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns an empty collection.
:::


The following example demonstrates how to extract metadata from an email:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract metadata from the email
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
 
    // Iterate over metadata items
    foreach(MetadataItem item in metadata)
    {
        // Print the item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

To extract hyperlinks from Microsoft Office Word document <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> method is used. This method returns XML representation of the document. Hyperlinks are represented by "hyperlink" tag; "link" attribute contains hyperlink's URL. For more details, see [Extract text structure](/net/parser/developer-guide/advanced-usage/working-with-text/extract-text-structure/). Hyperlink can contain a text:

```xml
<hyperlink link="www.google.com">google.com</hyperlink>
```


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> method returns *null* value if text structure extraction isn't supported for the document. For example, text structure extraction isn't supported for TXT files. Therefore, for TXT file <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> method returns *null*. If Microsoft Office Word document has no text, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a>[](https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata)method returns an empty <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a> object.
:::


Here are the steps to extract hyperlinks from Microsoft Office Word documents:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> method and obtain <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a> object;
*   Iterate through the XML document.

The following example demonstrates how to extract hyperlinks from Microsoft Office Word document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get the reader object for the document XML representation
    using (XmlReader reader = parser.GetStructure())
    {
        // Iterate over the document
        while (reader.Read())
        {
            // If it is the start tag of the hyperlink
            if (reader.IsStartElement() && reader.Name == "hyperlink")
            {
                // Print the link attribute
                Console.WriteLine(reader.GetAttribute("link"));
            }
        }
    }
}
```

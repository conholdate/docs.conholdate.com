GroupDocs.Parser provides the functionality to extract data from Microsoft Office Word documents. Both classic (doc, dot) and Open XML (docx, dotx) formats are supported. Also LibreOffice Writer (OpenOffice.org Writer) formats and RTF are supported.

The following table provides the list of supported formats:

| Format | Description |
| --- | --- |
| <a href="https://wiki.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a> | Microsoft Office Word Document |
| <a href="https://wiki.fileformat.com/word-processing/dot/" target="_blank" rel="nofollow noopener noreferrer">DOT</a> | Microsoft Office Word Document Template |
| <a href="https://wiki.fileformat.com/word-processing/docx/" target="_blank" rel="nofollow noopener noreferrer">DOCX</a> | Microsoft Office Open XML Document |
| <a href="https://wiki.fileformat.com/word-processing/docm/" target="_blank" rel="nofollow noopener noreferrer">DOCM</a> | Microsoft Office Open XML Macro-Enabled Document |
| <a href="https://wiki.fileformat.com/word-processing/dotx/" target="_blank" rel="nofollow noopener noreferrer">DOTX</a> | Microsoft Office Open XML Document Template |
| <a href="https://wiki.fileformat.com/word-processing/dotm/" target="_blank" rel="nofollow noopener noreferrer">DOTM</a> | Microsoft Office Open XML Document Macro-Enabled Template |
| <a href="https://wiki.fileformat.com/word-processing/txt/" target="_blank" rel="nofollow noopener noreferrer">TXT</a> | Plain text |
| <a href="https://wiki.fileformat.com/word-processing/odt/" target="_blank" rel="nofollow noopener noreferrer">ODT</a> | Open Document Text |
| <a href="https://wiki.fileformat.com/word-processing/ott/" target="_blank" rel="nofollow noopener noreferrer">OTT</a> | Open Document Text Template |
| <a href="https://wiki.fileformat.com/word-processing/rtf/" target="_blank" rel="nofollow noopener noreferrer">RTF</a> | Rich Text Format |

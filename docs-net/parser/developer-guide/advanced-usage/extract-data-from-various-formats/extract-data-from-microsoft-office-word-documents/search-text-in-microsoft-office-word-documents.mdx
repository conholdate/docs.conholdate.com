To search a keyword in Microsoft Office Word documents <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> method is used. This method returns the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects. For details, see [Search Text](/net/parser/developer-guide/advanced-usage/working-with-text/search-text/).

Here are the steps to search a keyword in Microsoft Office Word document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> method and obtain the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Iterate through the collection and get the position and text.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> method returns *null* value if search isn't supported for the document. For example, text extraction isn't supported for Zip archive. Therefore, for Zip archive <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> method returns *null*. For empty Microsoft Office Word document <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> method returns an empty collection.
:::


The following example shows how to find a keyword in Microsoft Office Word document:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("page number");
 
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(String, SearchOptions)</a> is used for the advanced search in Microsoft Office Word documents - like search with regular expressions, search by pages etc. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> parameter is used to customize a search.


:::warning
Search by pages in Microsoft Office Word document page is more resource consuming operation.
:::


Here are the steps to search with a regular expression in Microsoft Office Word document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> object with the parameters for the search;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> method and obtain the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Iterate through the collection and get the position and text.

The following example shows how to search with a regular expression in Microsoft Office Word document:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search with a regular expression with case matching
    IEnumerable<SearchResult> sr = parser.Search("page number: [0-9]+", new SearchOptions(true, false, true));
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

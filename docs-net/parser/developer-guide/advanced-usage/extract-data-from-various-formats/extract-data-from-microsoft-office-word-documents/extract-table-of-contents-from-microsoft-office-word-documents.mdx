## Overview

This guide explains how to extract the table of contents (TOC) from Microsoft Office Word documents (`.doc`, `.docx`) using GroupDocs.Parser for .NET. The TOC is automatically generated by detecting paragraphs with built-in heading styles (H1-H9)


## How TOC Extraction Works

The <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method analyzes your Word document and identifies all headings formatted with built-in heading styles. It returns a structured collection of TOC items that you can navigate programmatically.

To extract table of contents from Microsoft Office Word document <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method is used. Table of contents is generated by paragraphs with H1-H9 build-in styles.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns *null* value if table of contents extraction isn't supported for the document. For example, table of contents extraction isn't supported for TXT files. Therefore, for TXT file <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns *null*. If Microsoft Office Word document has no table of contents, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns an empty collection.
:::


<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objects. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">TocItem.GetText</a> method returns a text from the chapter to which table of contents item refers (without sub-chapters). :::warning
<a href="https://docs.microsoft.com/en-us/dotnet/api/system.invalidoperationexception?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">InvalidOperationException</a> is thrown if <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">tocItem.PageIndex</a> is *null*.
:::


Here are the steps to extract a text by an item of table of contents:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method and obtain the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objects;
*   Iterate through the collection and extract a text.

The following example shows how to extract a text by an item of table of contents:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SampleDocxWithToc))
{
    // Get table of contents
    IEnumerable<TocItem> tocItems = parser.GetToc();
    // Iterate over items
    foreach (TocItem tocItem in tocItems)
    {
        // Print the text of the chapter
        using (TextReader reader = tocItem.ExtractText())
        {
            Console.WriteLine("----");
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```

To extract metadata from EPUB e-books <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method is used. This method allows to extract the following metadata:

| Name | Description |
| --- | --- |
| title | The title of the e-book. |
| subject | The subject of the e-book. |
| author | The name of the e-book's author. |
| language | The language of the e-book. |
| published-date | The published date of the e-book. |
| description | The description of the e-book. |
| publisher | The publisher of the e-book. |
| copyrights | The copyrights of the e-book. |

Here are the steps to extract metadata from EPUB e-book:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial e-book;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method and obtain collection of document metadata objects;
*   Iterate through the collection and get metadata names and values.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns *null* value if metadata extraction isn't supported for the document. For example, metadata extraction isn't supported for Zip archive. Therefore, for Zip archive <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns *null*. If EPUB e-book has no metadata, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> method returns an empty collection.
:::


The following example demonstrates how to extract metadata from EPUB e-book:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract metadata from the e-book
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
 
    // Iterate over metadata items
    foreach(MetadataItem item in metadata)
    {
        // Print the item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

To extract table of contents from EPUB e-books <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method is used.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns *null* value if table of contents extraction isn't supported for the document. For example, table of contents extraction isn't supported for TXT files. Therefore, for TXT file <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns *null*. If EPUB e-book has no table of contents, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method returns an empty collection.
:::


Here are the steps to extract extract table of contents from EPUB e-book:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial e-book;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objects;
*   Iterate through the collection and get page index to extract a page text from the document.

The following example shows how to extract table of contents from EPUB e-book:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get table of contents
    IEnumerable<TocItem> toc = parser.GetToc();
    // Iterate over items
    foreach (TocItem i in toc)
    {
        // Print the Toc text
        Console.WriteLine(i.Text);
        // Check if page index has a value
        if (i.PageIndex == null)
        {
            continue;
        }
        // Extract a page text
        using (TextReader reader = parser.GetText(i.PageIndex.Value))
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```

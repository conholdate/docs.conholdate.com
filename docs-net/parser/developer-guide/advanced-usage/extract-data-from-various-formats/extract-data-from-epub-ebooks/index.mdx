GroupDocs.Parser provides the functionality to extract data from EPUB e-books. Also CHM and FB2 formats are supported.

The following table provides the list of supported formats:

| Format | Description |
| --- | --- |
| <a href="https://wiki.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">CHM</a> | Compiled HTML Help File |
| <a href="https://wiki.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> | Digital E-Book File Format |
| <a href="https://wiki.fileformat.com/ebook/fb2/" target="_blank" rel="nofollow noopener noreferrer">FB2</a> | FictionBook 2.0 File |

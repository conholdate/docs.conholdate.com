GroupDocs.Parser provides the functionality to extract data from Microsoft Office PowerPoint presentations. Both classic (ppt, pot) and Open XML (pptx, potx) formats are supported. Also LibreOffice Impress (OpenOffice.org Impress) formats are supported.

The following table provides the list of supported formats:

| Format | Description |
| --- | --- |
| <a href="https://wiki.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> | Microsoft Office PowerPoint Presentation |
| <a href="https://wiki.fileformat.com/presentation/pps/" target="_blank" rel="nofollow noopener noreferrer">PPS</a> | Microsoft Office PowerPoint Slideshow |
| <a href="https://wiki.fileformat.com/presentation/pot/" target="_blank" rel="nofollow noopener noreferrer">POT</a> | Microsoft Office PowerPoint Template |
| <a href="https://wiki.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">PPTX</a> | Microsoft Office Open XML Presentation |
| <a href="https://wiki.fileformat.com/presentation/pptm/" target="_blank" rel="nofollow noopener noreferrer">PPTM</a> | Microsoft Office Open XML Macro-Enabled Presentation |
| <a href="https://wiki.fileformat.com/presentation/potx/" target="_blank" rel="nofollow noopener noreferrer">POTX</a> | Microsoft Office Open XML Presentation Template |
| <a href="https://wiki.fileformat.com/presentation/potm/" target="_blank" rel="nofollow noopener noreferrer">POTM</a> | Microsoft Office Open XML Macro-Enabled Presentation Template |
| <a href="https://wiki.fileformat.com/presentation/ppsx/" target="_blank" rel="nofollow noopener noreferrer">PPSX</a> | Microsoft Office Open XML Presentation Slideshow |
| <a href="https://wiki.fileformat.com/presentation/ppsm/" target="_blank" rel="nofollow noopener noreferrer">PPSM</a> | Microsoft Office Open XML Macro-Enabled Presentation Slideshow |
| <a href="https://wiki.fileformat.com/presentation/odp/" target="_blank" rel="nofollow noopener noreferrer">ODP</a> | Open Document Presentation |
| <a href="https://wiki.fileformat.com/presentation/otp/" target="_blank" rel="nofollow noopener noreferrer">OTP</a> | Open Document Presentation Template |

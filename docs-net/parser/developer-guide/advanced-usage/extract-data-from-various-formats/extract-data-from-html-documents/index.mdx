GroupDocs.Parser provides the functionality to extract data from HTML documents and other markup formats.

The following table provides the list of supported formats:

| Format | Description |
| --- | --- |
| <a href="https://wiki.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">HTML</a> | Hypertext Markup Language File |
| <a href="https://wiki.fileformat.com/web/xhtml/" target="_blank" rel="nofollow noopener noreferrer">XHTML</a> | Extensible Hypertext Markup Language File |
| <a href="https://wiki.fileformat.com/web/mhtml/" target="_blank" rel="nofollow noopener noreferrer">MHTML</a> | MIME HTML File |
| <a href="https://wiki.fileformat.com/word-processing/md/" target="_blank" rel="nofollow noopener noreferrer">MD</a> | Markdown |
| <a href="https://wiki.fileformat.com/web/xml/" target="_blank" rel="nofollow noopener noreferrer">XML</a> | XML File |

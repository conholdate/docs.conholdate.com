GroupDocs.Parser provides the functionality to extract a text by an item of table of contents. This feature is supported for Word Processing, PDF, ePUB and CHM documents (for more details, see [Supported Document Formats](/net/parser/getting-started/supported-document-formats/)).

Text is extracted by <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/extracttext" target="_blank" rel="nofollow noopener noreferrer">TocItem.ExtractText</a> method:

```csharp
// Get the first item of table of contents
TocItem tocItem = parser.GetToc().First();

// Print the text of the chapter
using (TextReader reader = tocItem.ExtractText())
{
    Console.WriteLine("----");
    Console.WriteLine(reader.ReadToEnd());
}
```

:::warning
<a href="https://docs.microsoft.com/en-us/dotnet/api/system.invalidoperationexception?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">InvalidOperationException</a> is thrown if <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">tocItem.PageIndex</a> is *null*.
:::


Here are the steps to extract a text by an item of table of contents:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> method and obtain the collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objects;
*   Check if *collection* isn't *null* (table of contents extraction is supported for the document);
*   Iterate through the collection and extract a text by <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a> method.  

The following example shows how to extract text by table of contents items:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get table of contents
    IEnumerable<TocItem> toc = parser.GetToc();
    
    // Check if TOC extraction is supported
    if (toc == null)
    {
        Console.WriteLine("Table of contents extraction isn't supported");
        return;
    }
    
    // Iterate over items
    foreach (TocItem i in toc)
    {
        // Check if page index has a value
        if (i.PageIndex == null)
        {
            continue;
        }
        // Extract a page text
        using (TextReader reader = i.ExtractText())
        {
            Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
        }
    }
}
```

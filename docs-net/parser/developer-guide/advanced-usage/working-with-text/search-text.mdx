GroupDocs.Parser provides the functionality to search text from documents by the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> and <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> methods:

```csharp
IEnumerable<SearchResult> Search(string keyword);
IEnumerable<SearchResult> Search(string keyword, SearchOptions options);
```

The *keyword* parameter can contain a text or a regular expression. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> class contains every occurrence of the keyword in the document text. This class has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> | A zero-based index of the start position of the search result. Depending on <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/searchbypages" target="_blank" rel="nofollow noopener noreferrer">SearchOptions.SearchByPages</a> property value this index starts from the document start or the document page start. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">PageIndex</a> | The page index where the text is found. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | The found text. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/lefthighlightitem" target="_blank" rel="nofollow noopener noreferrer">LeftHighlightItem</a> | The left highlight. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/righthighlightitem" target="_blank" rel="nofollow noopener noreferrer">RightHighlightItem</a> | The right highlight. |

## Search text by keyword

Here are the steps to search a keyword in the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Check if *collection* isn't null (search is supported for the document);
*   Iterate through the collection and get position and text.

The following example shows how to find a keyword in a document:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("page number");
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }

    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

## Search text by regular expression

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> parameter is used to customize a search. This class has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/matchcase" target="_blank" rel="nofollow noopener noreferrer">MatchCase</a> | The value that indicates whether a text case isn't ignored. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/matchwholeword" target="_blank" rel="nofollow noopener noreferrer">MatchWholeWord</a> | The value that indicates whether text search is limited by the whole word. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/searchbypages" target="_blank" rel="nofollow noopener noreferrer">SearchByPages</a> | The value that indicates whether the search is performed by pages. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/useregularexpression" target="_blank" rel="nofollow noopener noreferrer">UseRegularExpression</a> | The value that indicates whether a regular expression is used. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/lefthighlightoptions" target="_blank" rel="nofollow noopener noreferrer">LeftHighlightOptions</a> | The options for the left highlight. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/righthighlightoptions" target="_blank" rel="nofollow noopener noreferrer">RightHighlightOptions</a> | The options for the right highlight. |

Here are the steps to search with a regular expression in the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> object with the parameters for the search;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Check if *collection* isn't *null* (search is supported for the document);
*   Iterate through the collection and get position and text.

The following example shows how to search with a regular expression in a document:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search with a regular expression with case matching
    IEnumerable<SearchResult> sr = parser.Search("page number: [0-9]+", new SearchOptions(true, false, true));
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }

    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

## Search text with highlights

Here are the steps to search text with a highlights:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> object with the parameters for the highlight extraction;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> object with the parameters for the search;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Check if *collection* isn't *null* (search is supported for the document);
*   Iterate through the collection and get position and text.

The following example shows how to search a text with the highlights:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SamplePdf))
{
    HighlightOptions highlightOptions = new HighlightOptions(15);
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("lorem", new SearchOptions(true, false, false, highlightOptions));
    // Check if search is supported
    if (sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }
    // Iterate over search results
    foreach (SearchResult s in sr)
    {
        // Print the found text and highlights: 
        Console.WriteLine(string.Format("{0}{1}{2}", s.LeftHighlightItem.Text, s.Text, s.RightHighlightItem.Text));
    }
}
```

## Search text with page numbers

Here are the steps to search text with page numbers:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a>  object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> object with the parameters for the search;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objects;
*   Check if *collection* isn't null (search is supported for the document);
*   Iterate through the collection and get position, text and page number.

The following example shows how to search a text with page numbers:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(Constants.SamplePdf))
{
    // Search a keyword with page numbers
    IEnumerable<SearchResult> sr = parser.Search("lorem", new SearchOptions(false, false, false, true));
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }
 
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index, page number and found text:
        Console.WriteLine(string.Format("At {0} (page {1}): {2}", s.Position, s.PageIndex, s.Text));
    }
}
```

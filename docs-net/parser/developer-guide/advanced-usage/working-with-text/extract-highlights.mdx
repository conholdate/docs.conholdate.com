GroupDocs.Parser provides the functionality to extract a highlight (a part of the text which is usually used to explain the context of the found text in the search functionality) from documents by the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gethighlight" target="_blank" rel="nofollow noopener noreferrer">GetHighlight</a> method:

```csharp
HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options);
```

The *position* parameter defines the start position from which the highlight is extracted. The *isDirect* parameter indicates whether highlight extraction is direct: *true* if the highlight is extracted by the right of the position; otherwise, *false*. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> parameter is used to define the end of the highlight.

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> class has the following constructors:

```csharp
// Highlight is limited to maxLength text length.
HighlightOptions(int maxLength);
// Highlight is limited to the start (or the end) of a text line (or maxLength text length - if set).
HighlightOptions(int? maxLength, bool isLineLimited);
// Highlight is limited to word count (or maxLength text length - if set).
HighlightOptions(int? maxLength, int wordCount);
// General constructor
HighlightOptions(int? maxLength, int? wordCount, bool isLineLimited);
```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> class has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> | The position in the document text. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | The highlight text. |

Here are the steps to extract highlight from the document:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> object with the extraction parameters;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gethighlight" target="_blank" rel="nofollow noopener noreferrer">GetHighlight</a> method and obtain the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> object;
*   Check if <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> isn't null (highlight extraction is supported for the document);
*   Call properties such as  <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> and <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>.

The following example shows how to extract a highlight that contains 3 words:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract a highlight:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    // Check if highlight extraction is supported
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    // Print an extracted highlight
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```

GroupDocs.Parser provides the functionality to extract images from document page area by the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImages(PageAreaOptions)</a> and <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/3" target="_blank" rel="nofollow noopener noreferrer">GetImages(int, PageAreaOptions)</a> methods:

```csharp
IEnumerable<PageImageArea> GetImages(PageAreaOptions options);
IEnumerable<PageImageArea> GetImages(int pageIndex, PageAreaOptions options);

```

The methods return a collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a> objects:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | The page that contains the text area. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | The rectangular area on the page that contains the text area. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | The format of the image. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> | The rotation angle of the image. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/getimagestream" target="_blank" rel="nofollow noopener noreferrer">GetImageStream()</a> | Returns the image stream. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/getimagestream/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImageStream(ImageOptions)</a> | Returns the image stream in a different format. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> | Saves the image to the file. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/save/methods/1" target="_blank" rel="nofollow noopener noreferrer">Save(string, ImageOptions)</a> | Saves the image to the file in a different format. |

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> class is used to define the image format into which the image is converted. The following image formats are supported:

*   Bmp
*   Gif
*   Jpeg
*   Png
*   WebP

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> parameter is used to customize text areas extraction process. This class has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | The rectangular area that contains a text area. |

Here are the steps to extract images from the upper-left corner:

*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> with the rectangular area;
*   Call <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImages(PageAreaOptions)</a> method and obtain collection of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a> objects;
*   Check if *collection* isn't *null* (images extraction is supported for the document);
*   Iterate through the collection and get sizes, image types and image contents.

The following example shows how to extract only images from the upper-left corner:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Create the options which are used for images extraction
    PageAreaOptions options = new PageAreaOptions(new Rectangle(new Point(0, 0), new Size(300, 100)));
    // Extract images from the upper-left corner of a page:
    IEnumerable<PageImageArea> images = parser.GetImages(options);
    // Check if images extraction is supported
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Print a page index, rectangle and image type:
        Console.WriteLine(string.Format("Page: {0}, R: {1}, Type: {2}", image.Page.Index, image.Rectangle, image.FileType));
    }
}

```

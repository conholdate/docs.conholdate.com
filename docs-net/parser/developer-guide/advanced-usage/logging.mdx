<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> interface is used to receive the information about errors, warnings and events which occur while data extraction. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> interface has the following members:

| Member | Description |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/error" target="_blank" rel="nofollow noopener noreferrer">Error(string, Exception)</a> | Logs an error that occurred during data extraction. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/warning" target="_blank" rel="nofollow noopener noreferrer">Warning(string)</a> | Logs a warning that occurred during data extraction. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/trace" target="_blank" rel="nofollow noopener noreferrer">Trace(string)</a> | Logs an event occurred during data extraction. |

Here are the steps to receive the information via <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> interface:

*   Implement the class with <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> interface implementation;
*   Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a>  object with <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a> object.

The following example shows how to receive the information via <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> interface.

```csharp
try
{
    // Create an instance of Logger class
    Logger logger = new Logger();
    // Create an instance of Parser class with the parser settings
    using (Parser parser = new Parser(Constants.SamplePassword, null, new ParserSettings(logger)))
    {
        // Check if text extraction is supported
        if (!parser.Features.Text)
        {
            Console.WriteLine("Text extraction isn't supported.");
            return;
        }
        // Print the document text
        using (TextReader reader = parser.GetText())
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
catch (InvalidPasswordException)
{
    ; // Ignore the exception
}

private class Logger : ILogger
{
    public void Error(string message, Exception exception)
    {
        // Print error message
        Console.WriteLine("Error: " + message);
    }
    public void Trace(string message)
    {
        // Print event message
        Console.WriteLine("Event: " + message);
    }
    public void Warning(string message)
    {
        // Print warning message
        Console.WriteLine("Warning: " + message);
    }
}
```

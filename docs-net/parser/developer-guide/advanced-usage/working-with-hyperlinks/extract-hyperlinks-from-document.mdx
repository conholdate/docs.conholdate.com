GroupDocs.Parser provides the functionality to extract hyperlinks from documents by the <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/gethyperlinks" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks</a> method:

```csharp
IEnumerable<PageHyperlinkArea> GetHyperlinks();
```

This method returns a collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a> object:

| Member | Description |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | The page that contains the text area. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | The rectangular area on the page that contains the text area. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | The hyperlink text. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/url" target="_blank" rel="nofollow noopener noreferrer">Url</a> | The hyperlink URL. |

Here are the steps to extract all hyperlinks from the whole document:

- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
- Check if the document supports hyperlink extraction;
- Call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/gethyperlinks" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks</a> method and obtain collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a> objects;
- Iterate through the collection and get a hyperlink text and URL.

The following example shows how to extract all hyperlinks from the whole document:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports hyperlink extraction
    if (!parser.Features.Hyperlinks)
    {
        Console.WriteLine("Document isn't supports hyperlink extraction.");
        return;
    }
    // Extract hyperlinks from the document
    IEnumerable<PageHyperlinkArea> hyperlinks = parser.GetHyperlinks();
    // Iterate over hyperlinks
    foreach (PageHyperlinkArea h in hyperlinks)
    {
        // Print the hyperlink text
        Console.WriteLine(h.Text);
        // Print the hyperlink URL
        Console.WriteLine(h.Url);
        Console.WriteLine();
    }
}
```


:::info
Hyperlinks are read from the document as text - GroupDocs.Parser never resolves, follows, or requests them. See [Network access and data privacy](/net/parser/getting-started/network-access-and-data-privacy/) for the complete list of operations that do and do not generate network traffic.
:::

GroupDocs.Parser provides the functionality to extract hyperlinks from document page area by the <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(PageAreaOptions)</a> and <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/3" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(Int32, PageAreaOptions)</a> methods:

```csharp
IEnumerable<PageHyperlinkArea> GetHyperlinks(int pageIndex, PageAreaOptions options);
IEnumerable<PageHyperlinkArea> GetHyperlinks(PageAreaOptions options);
```

These methods return a collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a> object:

| Member | Description |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | The page that contains the text area. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | The rectangular area on the page that contains the text area. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | The hyperlink text. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/url" target="_blank" rel="nofollow noopener noreferrer">Url</a> | The hyperlink URL. |

Here are the steps to extract hyperlinks from the document page area:

- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> object for the initial document;
- Check if the document supports hyperlink extraction;
- Instantiate <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> with the rectangular area;
- Call <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(PageAreaOptions)</a> method and obtain collection of <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a> objects;
- Iterate through the collection and get a hyperlink text and URL.

The following example shows how to extract hyperlinks from the document page area:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports hyperlink extraction
    if (!parser.Features.Hyperlinks)
    {
        Console.WriteLine("Document isn't supports hyperlink extraction.");
        return;
    }
    // Create the options which are used for hyperlink extraction
    PageAreaOptions options = new PageAreaOptions(new Rectangle(new Point(380, 90), new Size(150, 50)));
    // Extract hyperlinks from the document page area
    IEnumerable<PageHyperlinkArea> hyperlinks = parser.GetHyperlinks(options);
    // Iterate over hyperlinks
    foreach (PageHyperlinkArea h in hyperlinks)
    {
        // Print the hyperlink text
        Console.WriteLine(h.Text);
        // Print the hyperlink URL
        Console.WriteLine(h.Url);
        Console.WriteLine();
    }
}
```

Aspose.PSD is a PSD Format SDK and C# .NET Photoshop Manipulation API, that can convert from PSD format to PNG Format.

For this PSD conversion you should use the following C# code:

Below provided sample code demonstrates how to convert PSD to Png:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-psd/Aspose.PSD-for-.NET

string inputFile = dataDir + "PsdConvertToPngExample.psd";

using (var psdImage = (PsdImage)Image.Load(inputFile, new PsdLoadOptions() { ReadOnlyMode = true }))
{
    psdImage.Save(dataDir + "PsdConvertedToPng.png",
        new PngOptions() { ColorType = PngColorType.TruecolorWithAlpha, Progressive = true, CompressionLevel = 9 });
}
```

You can specify the Png Format compression level from 0 to 9, where 9 is the highest compression. You can use Png Progressive compression and change the Color Type of the Png File.<a href="https://reference.aspose.com/psd/net/aspose.psd.imageoptions/pngoptions" target="_blank" rel="nofollow noopener noreferrer">Png Options</a> have different properties for any cases of PSD Export.

Using the Semitransparent Png with Alpha channel for your site or work is a good solution. Adobe Photoshop file can be pixel-perfect exported with <a href="https://reference.aspose.com/psd/net/aspose.psd.imageloadoptions/psdloadoptions/properties/readonlymode" target="_blank" rel="nofollow noopener noreferrer">Read-Only Mode</a>

Here the example of an exported PSD file with the <a href="https://docs.aspose.com/display/psdjava/Apply+Masking" target="_blank" rel="nofollow noopener noreferrer">Applied Mask</a>, <a href="https://reference.aspose.com/psd/net/aspose.psd.fileformats.psd.layers/textlayer" target="_blank" rel="nofollow noopener noreferrer">Layer with Text</a>, and Transparent <a href="https://reference.aspose.com/psd/net/aspose.psd.fileformats.psd.layers.filllayers/filllayer" target="_blank" rel="nofollow noopener noreferrer">Fill Color Layer</a> (Aspose.PSD support all types of the <a href="https://docs.aspose.com/display/psdjava/Support+of+Fill+Layers" target="_blank" rel="nofollow noopener noreferrer">Adobe Photoshop Fill Layer</a>). Also, you can see the [shadow effect](/net/psd/shadow-effects-in-psd-file/) on the PSD Shape Layer.

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to get the following file information:

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> represents the document file type (PDF, Word document, Excel spreadsheet, PowerPoint presentation or image etc.).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> represents count of document pages.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">FileSize</a> represents the document file size.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PagesInfo</a> represents the page information.

The following code samples show how to get file information:

## Get file info for the file from local disk


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Interfaces;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    IDocumentInfo info = comparer.Source.GetDocumentInfo();
    for (int i = 0; i < info.PageCount; i++)
    {
        Console.WriteLine("\n" +
            "Page number: {5}\n" +
            "File type: {0}\n" +
            "Number of pages: {1}\n" +
            "Document size: {2} bytes\n" +
            "Width: {3}\n" +
            "Height: {4} ",
            info.FileType, 
            info.PageCount, 
            info.Size, 
            info.PagesInfo[i].Width, 
            info.PagesInfo[i].Height, i + 1
        );
    }
}
```

## Get file info for the file from stream


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Interfaces;
using System.IO;
// ...

using (Comparer comparer = new Comparer(File.OpenRead("source.docx")))
{
    IDocumentInfo info = comparer.Source.GetDocumentInfo();
    for (int i = 0; i < info.PageCount; i++)
    {
        Console.WriteLine("\n" +
            "Page number: {5}\n" +
            "File type: {0}\n" +
            "Number of pages: {1}\n" +
            "Document size: {2} bytes\n" +
            "Width: {3}\n" +
            "Height: {4} ",
            info.FileType, 
            info.PageCount, 
            info.Size, 
            info.PagesInfo[i].Width, 
            info.PagesInfo[i].Height, i + 1
        );
    }
}
```

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to get the list of all [supported file formats](/net/comparison/getting-started/supported-document-formats/). To do this, follow these steps:

1. Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> method of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class.
2. Enumerate through the collection of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> objects.

The following code snippet shows how to get list of supported file formats:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using System;
using System.Collections.Generic;
using System.Linq;
using GroupDocs.Comparison.Result;
// ...

IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to compare values from the `string` type variables.

To compare text from variables, follow these steps:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object. Set the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions/properties/loadtext" target="_blank" rel="nofollow noopener noreferrer">LoadText</a> property to `true` (this indicates that passed string contains text to be compared, not file path).
2.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source variable of the `string` type and the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object created in the previous step.
3.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify target variable of the `string` type and the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object created in the previous step.
4.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> method.
5.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/getresultstring" target="_blank" rel="nofollow noopener noreferrer">GetResultString</a> method to get string with comparison result.

The following code snippet shows how to load values from variables:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source text", new LoadOptions() { LoadText = true }))
{
    comparer.Add("target text", new LoadOptions() { LoadText = true });
    comparer.Compare();
    string result = compare.GetResultString();
    Console.WriteLine("Result string: \n" + comparer.GetResultString());
}
```

The following code snippet shows how to combine the different ways of specifying documents:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Stream sourceStream = File.OpenRead("./source.docx"))
{
    using (Comparer comparer = new Comparer(sourceStream))
    {
        comparer.Add("target text", new LoadOptions() { LoadText = true });
        comparer.Compare();
        string result = compare.GetResultString();
        Console.WriteLine(result);
    }
}
```

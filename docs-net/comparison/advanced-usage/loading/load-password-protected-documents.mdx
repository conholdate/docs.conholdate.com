<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to compare documents that are protected with a password.  

To compare password-protected documents, follow these steps:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object. Specify source document password;
2.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source document path or stream and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object created in the previous step.
3.  Instantiate another <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object. Specify target document password.
4.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target document path or stream and the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object created in the previous step.
5.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> method.

The following code snippet shows how to compare password protected documents:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

LoadOptions sourceLoadOptions = new LoadOptions(){ Password = "1234" };

using (Comparer comparer = new Comparer("source.docx", sourceLoadOptions))
{
    LoadOptions targetLoadOptions =	new LoadOptions() { Password = "5678" };
    comparer.Add("target.docx", targetLoadOptions);
    comparer.Compare("result.docx");
}
```

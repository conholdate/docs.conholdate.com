To avoid the saving stream as a file, <a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to work with file streams directly.

To work with stream, follow these steps:

1.  Obtain file stream.
2.  Pass opened source file stream to the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> class constructor or pass opened target file stream to the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method.

The following code snippet shows how to load file from stream:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using System.IO;
// ...

using (Stream sourceStream = File.OpenRead("source.docx"))
using (Stream targetStream = File.OpenRead("target.docx"))
{
    using (Comparer comparer = new Comparer(sourceStream))
    {
        comparer.Add(targetStream);
        comparer.Compare(File.Create("result.docx"));
    }
}
```

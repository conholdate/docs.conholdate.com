<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to compare documents that contains non-standard fonts.

To connect custom fonts and compare documents, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object. Specify a list of directories with custom fonts.
2. Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object with source document path or stream and the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object created in the previous step.
3. Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target document path or stream.
4. Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> method.

The following code snippet shows how to connect custom fonts and compare documents:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

// Instantiate the LoadOptions object and create a list of custom font directories.
LoadOptions loadOptions = new LoadOptions();
loadOptions.FontDirectories.Add("./fontPath/");

using (Comparer comparer = new Comparer("source.docx", loadOptions))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
}
```

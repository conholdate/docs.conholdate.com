<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to protect output document with password.

To protect output document, follow these steps:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source document path or stream.
2.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target document path or stream.
3.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> object. Set the  <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/passwordsaveoption" target="_blank" rel="nofollow noopener noreferrer">PasswordSaveOption</a> to `PasswordSaveOption.User`.
4.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object. Use the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions/properties/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> property to specify a password string.
5.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a> method. Specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> objects as parameters.

The following code snippet shows how to compare documents and protect the output document with password:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions cOptions = new CompareOptions
    {
        PasswordSaveOption = PasswordSaveOption.User
    };
    SaveOptions sOptions = new SaveOptions()
    {
        Password = "3333"
    };
    comparer.Compare("result.docx", sOptions, cOptions);
}
```

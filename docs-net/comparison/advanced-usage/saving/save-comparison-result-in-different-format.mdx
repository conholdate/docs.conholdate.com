<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to save output document in different formats.

To save output document in different format, follow these steps:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source document path or stream.
2.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target document path or stream.
3.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a> method. Specify the result document path with the required format.

The following code snippet shows how to save comparison result in different format:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
// ...

using (Comparer comparer = new Comparer("source.txt"))
{
    // Add target document
    comparer.Add("target.txt");

    // Compare and save comparison result
    comparer.Compare("result.pdf");
}
```

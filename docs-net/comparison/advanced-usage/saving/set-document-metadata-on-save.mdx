Document can contain some metadata information, such as author, organization, etc. <a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to select metadata source when saving output document.  

Possible metadata sources are as follows:

- Source document metadata
- Target document metadata
- User-defined metadata

To set output document metadata, follow these steps:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source document path or stream.
2.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target document path or stream.
3.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object. Set the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions/properties/clonemetadatatype" target="_blank" rel="nofollow noopener noreferrer">CloneMetadataType</a> property to the appropriate <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/metadatatype" target="_blank" rel="nofollow noopener noreferrer">MetadataType</a> variant.
4.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a> method. Specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object as a parameter.

The following code snippets show how to set output document metadata:

## Set metadata from source file


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx", new SaveOptions() { CloneMetadataType = MetadataType.Source });
}
```

</TabItem>


</Tabs>

<Tabs groupId="example2">

</TabItem>

## Set user-defined metadata 


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    SaveOptions saveOptions = new SaveOptions()
    {
        CloneMetadataType = MetadataType.FileAuthor,
        FileAuthorMetadata = new FileAuthorMetadata
        {
            Author = "Tom",
            Company = "GroupDocs",
            LastSaveBy = "Jack"
        }
    };
    comparer.Compare("result.docx", saveOptions);
}
```

</TabItem>


</Tabs>

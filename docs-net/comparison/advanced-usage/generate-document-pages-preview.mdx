<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to generate page previews for source, target and output document(s) using the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class.

Use the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class to manage the preview generation process - specify desired page numbers, image format, etc.

To generate the document preview using GroupDocs.Comparison API, follow these steps:

1.  Create an instance of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> class. Specify the source document path as a constructor parameter.
2.  Add the target document to comparison using the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method.
3.  The <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/source" target="_blank" rel="nofollow noopener noreferrer">Source</a> and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/targets" target="_blank" rel="nofollow noopener noreferrer">Targets</a> properties of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object allows you to access source and target documents and provides the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method;
4.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> object. Specify the following parameters:
    *   delegate for each page stream creation (see the CreatePageStream event handler)
    *   image preview format - PNG / JPG / BMP
    *   page numbers to process
    *   custom size of preview images (if needed)
    
:::info
Stream created by the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> delegate is disposed automatically when preview image is generated. If you need to implement the custom disposing of the image preview stream, specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> argument to clean up resources.
:::

5.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method of the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/source" target="_blank" rel="nofollow noopener noreferrer">Source</a> and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/targets" target="_blank" rel="nofollow noopener noreferrer">Targets</a> documents. Specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>.

The <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class main properties are as follows:

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> is a delegate which defines method to create output page preview stream
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> is a delegate which defines method to remove output page preview stream. This is can be used when need advanced control for resources handling
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> is preview image width. Use this property to customize output image width
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> is preview image height. Use this property to customize output image height
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/Resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a> allows to configure horizontal and vertical resolution values for image preview generation
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/pagenumbers" target="_blank" rel="nofollow noopener noreferrer">PageNumbers</a> defines numbers of pages to be previewed;
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/previewformat" target="_blank" rel="nofollow noopener noreferrer">PreviewFormat</a> gets or sets the preview image format which provides ability to choose between image quality and size. Use the BMP format for the best image quality. Use the JPG format to produce smallest image size (and faster loading image previews), but with lower quality than BMP. By default GroupDocs.Comparison uses the PNG format to provide appropriate image quality and size.

The following code snippet shows how to generate document previews:

## Get page previews for source document


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"D:\Temp\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    comparer.Source.GeneratePreview(previewOptions);
}
```

</Tabs>

## Get page previews for target document


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    comparer.Targets[0].GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Get page previews for output document


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
    Document document = new Document(File.OpenRead("result.docx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Set specific size and resolution for preview images


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.pptx"))
{
    comparer.Add("target.pptx");
    comparer.Compare("result.pptx");
    Document document = new Document(File.OpenRead("result.pptx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    previewOptions.Height = 1000;
    previewOptions.Width = 1000;

    previewOptions.Resolution = new PreviewResolution()
    {
      HorizontalResolution = 300,
      VerticalResolution = 300
    };

    document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>



:::info
This feature is not supported for WordProcessing documents.
:::


## Get page previews and clean resources manually


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

// Method should match with ReleasePageStream delegate signature
private void UserReleaseStreamMethod(int pageNumber, Stream stream)
{
    Console.WriteLine($"Releasing memory for page: {pageNumber}");
    stream.Close();
}

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
    Document document = new Document(File.OpenRead("result.docx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    // here we set delegate target method
    previewOptions.ReleasePageStream = UserReleaseStreamMethod;
    document.GeneratePreview(previewOptions);
}
```

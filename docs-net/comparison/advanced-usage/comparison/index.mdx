<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> provides many ways to customize the logic of the changes' detection algorithm and output file creation by setting the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> class properties.   

You can customize the following parameters:

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/calculatecoordinates" target="_blank" rel="nofollow noopener noreferrer">CalculateCoordinates</a> indicates if calculate coordinates for changed components.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/changeditemstyle" target="_blank" rel="nofollow noopener noreferrer">ChangedItemStyle</a> specifies the style of the changed items.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/deleteditemstyle" target="_blank" rel="nofollow noopener noreferrer">DeletedItemStyle</a> specifies the style of the deleted items.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/detalisationlevel" target="_blank" rel="nofollow noopener noreferrer">DetalisationLevel</a> gets of sets the comparison detalization level.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/detectstylechanges" target="_blank" rel="nofollow noopener noreferrer">DetectStyleChanges</a> indicates if  detect style changes or not.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/diagrammastersetting" target="_blank" rel="nofollow noopener noreferrer">DiagramMasterSetting</a> gets or sets the path to the master, or uses comparison without a master (this option is for diagrams only).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/generatesummarypage" target="_blank" rel="nofollow noopener noreferrer">GenerateSummaryPage</a> indicates if add summary page with detected changes statistics for output document or not.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/inserteditemstyle" target="_blank" rel="nofollow noopener noreferrer">InsertedItemStyle</a> specifies style of inserted items.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/markchangedcontent" target="_blank" rel="nofollow noopener noreferrer">MarkChangedContent</a> indicates if use frames for shapes in Word Processing and for rectangles in Image documents.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/marknestedcontent" target="_blank" rel="nofollow noopener noreferrer">MarkNestedContent</a> indicates if accept inserted/deleted styles for all children of inserted/deleted items.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/originalsize" target="_blank" rel="nofollow noopener noreferrer">OriginalSize</a> gets or sets the original sizes of comparing documents.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/passwordsaveoption" target="_blank" rel="nofollow noopener noreferrer">PasswordSaveOption</a> gets or sets the password save option. For details, see [here](/net/comparison/advanced-usage/saving/set-password-for-resultant-document/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/sensitivityofcomparison" target="_blank" rel="nofollow noopener noreferrer">SensitivityOfComparison</a> gets or sets the comparison sensitivity. For details, see [here](/net/comparison/advanced-usage/comparison/adjusting-comparison-sensitivity/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> indicates if show deleted components in output document or not.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> indicates if show inserted components in output document or not.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/wordsseparatorchars" target="_blank" rel="nofollow noopener noreferrer">WordsSeparatorChars</a> sets an array of delimiters to split text into words.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparebookmarks" target="_blank" rel="nofollow noopener noreferrer">CompareBookmarks</a> indicates if compare bookmarks. See [Compare bookmarks in Word](/net/comparison/advanced-usage/comparison/compare-bookmarks-in-word/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparevariableproperty" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a> indicates if compare variable properties. See [Compare variables and document properties](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparedocumentproperty" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a> indicates if compare built and custom properties. See [Compare variables and document properties](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showrevisions" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a> indicates if show other revisions in the output document. See [Show revisions](/net/comparison/advanced-usage/comparison/show-revisions/).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> indicates if show empty lines instead of inserted/deleted components in the final document. See [Show gap lines](/net/comparison/advanced-usage/comparison/show-gap-lines/).

For details, see the following guides:


:::tip
**Format-specific options:** For Word documents, you can use [WordCompareOptions](/net/comparison/advanced-usage/comparison/word-compare-options/) to control revision display mode, author attribution, and bookmark comparison in addition to the general `CompareOptions` above.
:::

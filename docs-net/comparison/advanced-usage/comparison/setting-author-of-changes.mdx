<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to set author of changes name in the resulting document. To do this, follow these steps:
1. Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify a source file path or an input stream.
2. Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify a target file path or an input stream.
3. Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a> object. Set <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DisplayMode</a> to `Revisions` and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/showrevisions/" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a> to `true`.
4. Set author of changes by changing the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionAuthorName</a> property.
5. Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Compare</a> method. Specify the `WordCompareOptions` object from previous step.

The following code snippet shows how to change author of changes:


<Tabs groupId="example1">


<TabItem value="net" label=".NET" default>

```cs
using (Comparer comparer = new Comparer("source.docx"))
{
  comparer.Add("target.docx");

  WordCompareOptions options = new WordCompareOptions()
  {
    DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions,
    ShowRevisions = true,
    RevisionAuthorName = "New author",
  };

  comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>

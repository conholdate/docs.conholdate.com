<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> provides the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a> class for configuring comparison of Word documents (`.doc`, `.docx`, `.rtf`, and other word-processing formats). It inherits from <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> and adds Word-specific properties - most notably the `DisplayMode` property, which controls how detected changes are written into the result document.

## Display modes

The <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DisplayMode</a> property accepts one of two values from the `WordCompareOptions.ComparisonDisplayMode` enumeration:

- **Revisions** - changes are emitted as native Word revision (track-changes) markup. The result opens in Microsoft Word with the **Review → Accept / Reject** controls ready.
- **Highlight** - inserted, deleted, and modified text is rendered with inline colour highlights directly in the document body. No track-changes metadata is added.

### Revisions mode


<Tabs groupId="example-revisions">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions
    };

    comparer.Compare("result.docx", options);
}
```

## Detect style changes

Set <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DetectStyleChanges</a> to `true` to include formatting differences (bold, font size, colour, etc.) alongside textual edits.


<Tabs groupId="example-style">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions,
        DetectStyleChanges = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


## Compare headers and footers

Set <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">HeaderFootersComparison</a> to `true` to include header and footer content in the comparison.


<Tabs groupId="example-headers">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        HeaderFootersComparison = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


## Mark line breaks

Set <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">MarkLineBreaks</a> to `true` to visually mark paragraph (line) breaks that differ between documents.


<Tabs groupId="example-linebreaks">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    {
        MarkLineBreaks = true
    };

    comparer.Compare("result.docx", options);
}
```

## Other Word-specific properties

The properties below are also available on `WordCompareOptions`. Several of them are documented in dedicated articles - follow the links for details:

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareBookmarks</a> - compare bookmarks in the source and target documents. See [Compare bookmarks in Word documents](/net/comparison/advanced-usage/comparison/compare-bookmarks-in-word/).
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a> - compare document variable properties (e.g. `DOCVARIABLE` fields). See [Compare document properties and variables](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a> - compare built-in and custom document properties. See [Compare document properties and variables](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionAuthorName</a> - author name stamped on revisions when `DisplayMode = Revisions`. See [Setting author of changes](/net/comparison/advanced-usage/comparison/setting-author-of-changes/).
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a> - controls whether revision markup remains visible in the result. See [Show Revisions](/net/comparison/advanced-usage/comparison/show-revisions/).
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> - leave empty lines in place of inserted or deleted content to preserve layout.

All <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> base properties - `InsertedItemStyle`, `DeletedItemStyle`, `ChangedItemStyle`, `SensitivityOfComparison`, `GenerateSummaryPage`, and others - are also available on `WordCompareOptions`.

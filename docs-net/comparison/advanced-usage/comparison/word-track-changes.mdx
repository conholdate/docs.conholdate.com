> **This page has moved.**
>
> The legacy `WordTrackChanges` property has been replaced by the dedicated <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a> class. Track-changes output is now configured through `DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions`.
>
> Please continue reading on the new page: **[Word document comparison options](/net/comparison/advanced-usage/comparison/word-compare-options/)**.

The new page covers:

- `DisplayMode` - choose between **Revisions** (Word track-changes markup) and **Highlight** (inline colour highlights) output.
- `DetectStyleChanges`, `HeaderFootersComparison`, `MarkLineBreaks`, and other Word-specific properties.
- Links to dedicated articles on bookmarks, document properties, revision author name, and revision visibility.

For a step-by-step tutorial with both modes side by side, see the related blog article: <a href="https://blog.groupdocs.com/comparison/word-comparison-net-revision-track-vs-highlight-modes/" target="_blank" rel="nofollow noopener noreferrer">Word Comparison in .NET: Revision Track vs Highlight Modes</a>.

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to adjust appearance of the output document.

By default, changes from the two input files (source and target files) are added to the output document and highlighted. Use the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> properties to configure the content of the output file.

Use the <a href="https://reference.groupdocs.com/error/404?path=comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> property to adjust the display of the output document, which allows to replace changed content with empty lines. To use this property, activate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> and <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> properties.

Follow these steps to adjust appearance of the output document:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source file path or stream.
2.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target file path or stream.
3.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> object. Sets the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a>, <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a>, and/or <a href="https://reference.groupdocs.com/error/404?path=comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> properties.
4.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> method. Specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> object from the previous step.

The following code snippet shows how get the desired result


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    CompareOptions options = new CompareOptions();
    options.ShowInsertedContent = false;
    options.ShowDeletedContent = false;
    options.LeaveGaps = true;

    comparer.Compare("result.docx", options);
}
```

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> allows you to disable image comparison in PDF documents.

By default, the CompareImagesPdf option is `true`. Follow these steps to turn off image comparison:

1.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> object. Specify the source file path or stream.
2.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the target file path or stream.
3.  Instantiate the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> object. Set the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/compareimagespdf" target="_blank" rel="nofollow noopener noreferrer">CompareImagesPdf</a> property to `false`;
3.  Set the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/imagesinheritancemode" target="_blank" rel="nofollow noopener noreferrer">ImagesInheritanceMode</a> property to `ImagesInheritance.Source` or `ImagesInheritance.Target`;
4.  Call the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> method. Specify the <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> object from the previous step.

The following code snippet shows how to disable image comparison in PDF documents:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.pdf"))
{
    comparer.Add("target.pdf");
    CompareOptions compareOptions = new CompareOptions()
    {
        CompareImagesPdf = false,
        ImagesInheritanceMode = ImagesInheritance.Target
    }
    comparer.Compare("result.pdf", compareOptions);
}
```

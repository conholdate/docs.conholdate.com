:::info
GroupDocs.Assembly for .NET is included in Conholdate.Total for .NET.
:::

GroupDocs.Assembly is built on top of several Aspose products. Some of the products use <a href="https://www.nuget.org/packages/SkiaSharp/" target="_blank" rel="nofollow noopener noreferrer">SkiaSharp</a> to deal with graphics-related tasks within .NET Standard 2.0, whereas the others prefer <a href="https://www.nuget.org/packages/System.Drawing.Common/" target="_blank" rel="nofollow noopener noreferrer">System.Drawing.Common</a>. That is why, GroupDocs.Assembly depends on the both packages.

A recommended way to deal with these and other GroupDocs.Assembly for .NET Standard 2.0 dependencies is installing of <a href="https://www.nuget.org/packages/GroupDocs.Assembly/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly NuGet package</a>. Otherwise, you can install all dependencies listed at <a href="https://www.nuget.org/packages/GroupDocs.Assembly/" target="_blank" rel="nofollow noopener noreferrer">the NuGet package page</a> manually.

Depending on OS you work on, you may need to install some additional dependencies as explained further.

## Using GroupDocs.Assembly for .NET Standard 2.0 in Windows

No additional dependencies arise.

## Using GroupDocs.Assembly for .NET Standard 2.0 in Linux

In addition to GroupDocs.Assembly NuGet package dependencies, <a href="https://www.nuget.org/packages/SkiaSharp.NativeAssets.Linux/" target="_blank" rel="nofollow noopener noreferrer">SkiaSharp.NativeAssets.Linux</a> should be installed. Also, installing of additional components is required as shown by the following commands:

```
apt-get update && apt-get install -y libfontconfig1
```

```
apt-get update && apt-get install -y --allow-unauthenticated libc6-dev libgdiplus libx11-dev
```

## Using GroupDocs.Assembly for .NET Standard 2.0 in macOS

In addition to GroupDocs.Assembly NuGet package dependencies, <a href="https://www.nuget.org/packages/runtime.osx.10.10-x64.CoreCompat.System.Drawing/" target="_blank" rel="nofollow noopener noreferrer">runtime.osx.10.10-x64.CoreCompat.System.Drawing</a> should be installed.

## Using GroupDocs.Assembly for .NET Standard 2.0 in Docker

Additional steps required to use GroupDocs.Assembly for .NET Standard 2.0 in Docker correspond to a type of containers being used. For example, for Linux containers, you should take the same additional steps as per "Using GroupDocs.Assembly for .NET Standard 2.0 in Linux" section.

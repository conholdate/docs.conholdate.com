GroupDocs.Assembly for .NET API supports the removal of paragraphs becoming empty after template syntax tags are removed or replaced with empty values. A new member **RemoveEmptyParagraphs** is added to <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassemblyoptions" target="_blank" rel="nofollow noopener noreferrer">DocumentAssemblyOptions</a>**.** When this new option is applied to <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> options through <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler/properties/options" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler.Options</a>, the engine additionally removes empty paragraphs.

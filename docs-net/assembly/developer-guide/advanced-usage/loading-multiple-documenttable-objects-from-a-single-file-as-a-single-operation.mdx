## Loading Multiple DocumentTable Objects

GroupDocs.Assembly for .NET API provides the ability to load multiple DocumentTable objects from a single file as a single operation. Following classes and interfaces of the <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly.Data</a> namespace have been added:

*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttableset" target="_blank" rel="nofollow noopener noreferrer">DocumentTableSet</a>
*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttablecollection" target="_blank" rel="nofollow noopener noreferrer">DocumentTableCollection</a>
*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/idocumenttableloadhandler" target="_blank" rel="nofollow noopener noreferrer">IDocumentTableLoadHandler</a>
*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttableloadargs" target="_blank" rel="nofollow noopener noreferrer">DocumentTableLoadArgs.</a>

Moreover, following properties of the <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttable" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly.Data.DocumentTable</a> class have been added:

*   Name
*   IndexInDocument

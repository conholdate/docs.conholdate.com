## The Bulleted List

As per wikipedia, a Bulleted List can be described as:

&gt; In <a href="https://en.wikipedia.org/wiki/Typography" target="_blank" rel="nofollow noopener noreferrer">typography</a>, a **bullet** ( • ) is a typographical symbol or <a href="https://en.wikipedia.org/wiki/Glyph" target="_blank" rel="nofollow noopener noreferrer">glyph</a> used to introduce items in a <a href="https://en.wiktionary.org/wiki/list" target="_blank" rel="nofollow noopener noreferrer">list</a>. For example:
&gt; 
&gt; *   Item 1
&gt; *   Item 2
&gt; *   Item 3

For more information, please visit <a href="https://en.wikipedia.org/wiki/Bullet_(typography" target="_blank" rel="nofollow noopener noreferrer">wikipedia article</a>).

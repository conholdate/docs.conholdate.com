### The Recipe

*   Set up the source document template path
*   Set up destination report path
*   Instantiate DocumentAssembler class
*   Set options, **<a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassemblyoptions" target="_blank" rel="nofollow noopener noreferrer">DocumentAssemblyOptions.UpdateFieldsAndFormulas</a>**
*   Generate report

## Define Relations Between Document Table Instances

API provides ability to define relations between <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttable" target="_blank" rel="nofollow noopener noreferrer">DocumentTable</a> instances loaded from a single document. The following classes of the <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly.Data</a> namespace have been added:

*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttablerelation" target="_blank" rel="nofollow noopener noreferrer">DocumentTableRelation</a>
*   <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttablerelationcollection" target="_blank" rel="nofollow noopener noreferrer">DocumentTableRelationCollection</a>

Moreover, the **Relations** property of the <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly.data/documenttableset" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly.Data.DocumentTableSet</a> class has been added.

## Rendering CAD drawings requires adding assembly binding redirect

When rendering CAD drawings using GroupDocs.Viewer, it is required to add the <a href="https://docs.microsoft.com/en-us/dotnet/framework/configure-apps/redirect-assembly-versions" target="_blank" rel="nofollow noopener noreferrer">assembly binding redirect</a> to the app.config or web.config project files. The following example shows the required assembly binding redirect to render CAD drawings with GroupDocs.Viewer for .NET 20.6.1 and earlier.


<Tabs groupId="example1">


<TabItem value="project-file" label="Project file" default>

```xml
<configuration>
    <!--...-->
    <runtime>
        <!--...-->
        <assemblyBinding xmlns="urn:schemas-microsoft-com:asm.v1">
            <!--...-->
            <dependentAssembly>
                <assemblyIdentity name="Aspose.PDF" publicKeyToken="716fcc553a201e56" culture="neutral"/>
                <bindingRedirect oldVersion="0.0.0.0-20.5.0.0" newVersion="20.5.0.0"/>
                <publisherPolicy apply="no"/>
            </dependentAssembly>
        </assemblyBinding>
    </runtime>
</configuration>
```

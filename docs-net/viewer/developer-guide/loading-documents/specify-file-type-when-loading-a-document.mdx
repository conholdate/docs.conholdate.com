GroupDocs.Viewer for .NET is included in Conholdate.Total for .NET.
:::


When loading a document by specifying a path to a file or using <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.filestream" target="_blank" rel="nofollow noopener noreferrer">FileStream</a>, GroupDocs.Viewer determines file type by extension. Otherwise, GroupDocs.Viewer tries to determine file type by its signature or content. It takes time and may affect performance. 

You can specify the file type using <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. If you do this, GroupDocs.Viewer skips file type detection and use the specified type.

The following code snippet shows how to specify the file type when loading a document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

Stream stream = GetFileStream("sample.docx"); //TODO: implement your method

// Specify the file type.
LoadOptions loadOptions = new LoadOptions(FileType.DOCX);

//Render a file.
using (Viewer viewer = new Viewer(stream, loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim stream As Stream = GetFileStream("sample.docx") 'TODO: implement your method
    
        ' Specify the file type.
        Dim loadOptions As LoadOptions = New LoadOptions(FileType.DOCX)
    
        'Render a file.
        Using viewer As Viewer = New Viewer(stream, loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

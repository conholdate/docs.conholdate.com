GroupDocs.Viewer preserves the page order in the source document. Instead, you may reorder pages in the output PDF document.

To reorder pages, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> object.
2. Create the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> object.
3. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> method of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> object. Specify the new page order in the last parameters.

The following code snippet shows how to reorder pages:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer;
// ...

using (Viewer viewer = new Viewer("sample.docx"))            
{     
    // Create view options.
    PdfViewOptions viewOptions = new PdfViewOptions();

    // Pass page numbers in the order you want to render them.                
    viewer.View(viewOptions, 2, 1);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()

            ' Pass page numbers in the order you want to render them.                
            viewer.View(viewOptions, 2, 1)
        End Using
    End Sub
End Module
```

<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render web documents as PDF, PNG, and JPEG files. Use this library to view web files within your .NET application. 

To start using the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass a web document you want to view to the class constructor. You can load the document from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the document to PDF or image format. These methods allow you to render the entire document or specific pages.

<a href="https://products.groupdocs.app/viewer/web" target="_blank" rel="nofollow noopener noreferrer">View web files online</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">View demos and examples on GitHub</a>

## Supported web file formats

GroupDocs.Viewer supports the following web file formats:

* <a href="https://docs.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">Hypertext Markup Language Format</a> (.HTML / .HTM)
* <a href="https://docs.fileformat.com/web/mhtml/" target="_blank" rel="nofollow noopener noreferrer">MIME HTML Format</a> (.MHTML)
* <a href="https://docs.fileformat.com/web/mht/" target="_blank" rel="nofollow noopener noreferrer">MHTML Web Archive</a> (.MHT)
* <a href="https://docs.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">Compiled HTML Help Format</a> (.CHM)

GroupDocs.Viewer can detect the document format automatically by analyzing file contents.

## Render web documents as PDF

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a web file to PDF. The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file, reorder its pages, and specify the quality of document images. Refer to the following documentation section for details: [Rendering to PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Create a PDF file for the document.
    // Specify the PDF file name.
    var viewOptions = new PdfViewOptions("output.pdf");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("groupdocs-documentation.mhtml")
            ' Create a PDF file for the document.
            ' Specify the PDF file name.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Render web documents as PNG

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a web file to PNG. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> properties to specify the output image size in pixels.


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the web file to PNG.
    // {0} is replaced with the page numbers in the output image names.
    var viewOptions = new PngViewOptions("output_{0}.png");
    viewer.View(viewOptions);
}
```

## Convert CHM files to HTML

<a href="https://docs.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">CHM</a> is a Microsoft proprietary online help format that is often used for software documentation. With GroupDocs.Viewer, you can convert a CHM file to HTML to display this file in a web browser. To do this, create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Create an HTML file with embedded resources

To save all elements of an HTML page (including text, graphics, and stylesheets) into a single file, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.chm"))
{
    // Convert the CHM file to HTML.
    // {0} is replaced with the page numbers in the output file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("chm_result_{0}.html");
    // Enable the following option to display all CHM content on a single HTML page.
    // options.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

### Create an HTML file with external resources

If you want to store an HTML file and additional resource files (such as fonts, images, and stylesheets) separately, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.chm"))
{
    // Convert the CHM file to HTML.
    // Specify the output file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

## Specify rendering options

GroupDocs.Viewer supports the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions</a> class that allows you to specify different options for rendering web files. To access these options, use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/webdocumentoptions" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions</a> property for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

### Adjust page margins

Use the following properties to specify the size of page margins in the output files when you convert your web documents to HTML, PDF, and image formats: 

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/topmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.TopMargin</a>---Specifies the distance (in points) between the top edge of the page and the top boundary of the body text. The default value is 72 points.
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/bottommargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.BottomMargin</a>---Specifies the distance (in points) between the bottom edge of the page and the bottom boundary of the body text. The default value is 72 points.
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/leftmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.LeftMargin</a>---Specifies the distance (in points) between the left edge of the page and the left boundary of the body text. The default value is 5 points.
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/rightmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.RightMargin</a>---Specifies the distance (in points) between the right edge of the page and the right boundary of the body text. The default value is 5 points.

The example below converts a web document to PDF and specifies page margins for the output file. 


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the size of page margins in points.
    viewOptions.WebDocumentOptions.LeftMargin = 40;
    viewOptions.WebDocumentOptions.RightMargin = 40;
    viewOptions.WebDocumentOptions.TopMargin = 40;
    viewOptions.WebDocumentOptions.BottomMargin = 40;
    viewer.View(viewOptions);
}
```

</TabItem>

### Set the output page size

GroupDocs.Viewer allows you to specify page size for the output file when you convert your web document to another format. Assign a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> enumeration member to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/pagesize" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.PageSize</a> property to select one of the predefined page sizes (Letter, Ledger, A0, A1, A2, A3, or A4).

The following example specifies page size for the output PDF file:


<Tabs groupId="example7">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the page size.
    viewOptions.WebDocumentOptions.PageSize = PageSize.A3;
    viewer.View(viewOptions);
}
```

</TabItem>

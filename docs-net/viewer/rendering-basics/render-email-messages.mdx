<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render your email messages in HTML, PDF, PNG, and JPEG formats. You do not need to use third-party email clients to view the contents of email files within your .NET application (web or desktop). 

To start with the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass an email message you want to view to the class constructor. You can load the message from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the loaded message to HTML, PDF, or image format. These methods allow you to render the entire message or specific pages.

## Supported email file formats

GroupDocs.Viewer supports the following email file formats:

* <a href="https://docs.fileformat.com/email/eml" target="_blank" rel="nofollow noopener noreferrer">Email Message</a> (.EML)
* <a href="https://docs.fileformat.com/email/emlx" target="_blank" rel="nofollow noopener noreferrer">Apple Mail Message</a> (.EMLX)
* <a href="https://docs.fileformat.com/email/mbox/" target="_blank" rel="nofollow noopener noreferrer">Email Mailbox File</a> (.MBOX)
* <a href="https://docs.fileformat.com/email/msg" target="_blank" rel="nofollow noopener noreferrer">Outlook Message Item File</a> (.MSG)
* <a href="https://docs.fileformat.com/email/vcf/" target="_blank" rel="nofollow noopener noreferrer">vCard (Virtual Contact) File</a> (.VCF, .VCARD)

GroupDocs.Viewer can detect the email file format automatically based on information in the file header.

## Render email messages as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert an email message to HTML. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and exclude specific fonts. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/). 

### Create an HTML file with embedded resources

To embed an email message in an HTML page, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
   // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.eml")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Create an HTML file with external resources

To save an email message to a separate folder, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name in the output file name.
    var viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.eml")
            ' Specify the HTML file name and location of external resources.
            ' {0} is replaced with the resource name in the output file name.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("output.html",   "output/resource_{0}", "output/resource_{0}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file, reorder its pages, and specify the quality of document images. ## Specify rendering options

GroupDocs.Viewer supports the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/emailoptions" target="_blank" rel="nofollow noopener noreferrer">EmailOptions</a> class that allows you to specify different options for rendering email messages. To access these options, use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/emailoptions/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions</a> property for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

### Set the output page size

GroupDocs.Viewer allows you to specify page size for the output file when you convert an email message to HTML, PDF, or image format. Assign a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pagesize/" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> enumeration member to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/pagesize/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.PageSize</a> property to select one of the predefined page sizes (Letter, Ledger, A0, A1, A2, A3, or A4).

The following example specifies page size for the output PDF file:


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create a PDF file.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the page size.
    viewOptions.EmailOptions.PageSize = PageSize.Letter;
    viewer.View(viewOptions);
}
```

### Rename fields in the message header

GroupDocs.Viewer allows you to change how standard fields (such as _From_, _To_, _Subject_, and so on) are displayed in the email message header.

![Default fields in the message header](/net/viewer/images/rendering-basics/render-email-messages/default-message-fields.png)

Use the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/emailoptions/properties/fieldtextmap" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.FieldTextMap</a> property to specify custom field labels. Static fields of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/field/" target="_blank" rel="nofollow noopener noreferrer">Field</a> class allow you to access default email header fields, as shown in the example below.


<Tabs groupId="example7">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Specify custom field labels.
    viewOptions.EmailOptions.FieldTextMap[Field.From] = "Sender";
    viewOptions.EmailOptions.FieldTextMap[Field.To] = "Recipient";
    viewOptions.EmailOptions.FieldTextMap[Field.Sent] = "Date";
    viewOptions.EmailOptions.FieldTextMap[Field.Subject] = "Email subject";
    viewer.View(viewOptions);
}
```

</TabItem>

### Specify the date and time format and change the time zone

When rendering email messages, GroupDocs.Viewer formats date and time information in the message header based on the system's date and time settings. If you want to change the default date and time format or specify the time zone offset, use the following properties:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/datetimeformat/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.DateTimeFormat</a>---Allows you to define a custom date and time format. See the following topics for details: 
    * <a href="https://learn.microsoft.com/en-us/dotnet/standard/base-types/standard-date-and-time-format-strings" target="_blank" rel="nofollow noopener noreferrer">Standard date and time format strings</a>
    * <a href="https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings" target="_blank" rel="nofollow noopener noreferrer">Custom date and time format strings</a>
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/timezoneoffset/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.TimeZoneOffset</a>---Specifies the hours and minutes offset from UTC. The offset is displayed with a leading sign. A plus sign (+) indicates time ahead of UTC, and a minus sign (-) indicates time behind UTC. 


<Tabs groupId="example8">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Apply a custom format to the date in the email message header.
    viewOptions.EmailOptions.DateTimeFormat = "MMMM dd, yyyy H:mm:ss zzz";
    // Specify the time zone offset. 
    viewOptions.EmailOptions.TimeZoneOffset = new TimeSpan(-7, 0, 0);
    viewer.View(viewOptions);
}
```

</TabItem>

## Get mail message metadata before rendering

Sometimes it is necessary to know some metadata of the email message, loaded to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> class, before its actual rendering through the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/view/#view" target="_blank" rel="nofollow noopener noreferrer">`Viewer.View()`</a> method. GroupDocs.Viewer for such cases provides the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a> class that can be obtained by calling a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/getviewinfo/#getviewinfo" target="_blank" rel="nofollow noopener noreferrer">`Viewer.GetViewInfo()`</a> method. However, this <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a> class is common for all supported document formats and has no specific properties, which are present only in the mail messages.

Starting from the version 26.1 the GroupDocs.Viewer public API has a new class <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/mailmessageviewinfo/" target="_blank" rel="nofollow noopener noreferrer">`MailMessageViewInfo`</a>. This class is a direct inheritor of the common class <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a>, so it has all its properties, but also introduce the few new ones, specific for the mail messages:

- `Sent` property of `DateTime` type - returns a date and time, stored in the mail message in its original form "as-is", without adjusting it to the local date time and so on.
- `Subject` of `String` type - return a subject of the mail message.
- `From` of `String` type - returns a "From" email address.

To obtain a metadata of the given mail message, this mail message initially should be loaded to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> class through its <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/viewer/#constructor_4" target="_blank" rel="nofollow noopener noreferrer">constructor</a>, and then the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/getviewinfo/#getviewinfo" target="_blank" rel="nofollow noopener noreferrer">`Viewer.GetViewInfo()`</a> method should be called. This method then returns the instance of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a> class, which should be casted to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/mailmessageviewinfo/" target="_blank" rel="nofollow noopener noreferrer">`MailMessageViewInfo`</a> type. And that's all! Source code is below:


<Tabs groupId="Get-view-info-example">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("sample.eml"))
{
    ViewInfo generalInfo = viewer.GetViewInfo(ViewInfoOptions.ForHtmlView());
    // explicit casting
    MailMessageViewInfo mailMessageInfo = (MailMessageViewInfo)generalInfo;
    Console.WriteLine("From: {0}; Subject: {1}; Sent: {2}.", mailMessageInfo.From, mailMessageInfo.Subject, mailMessageInfo.Sent);

    // Render to any output format if needed
    viewer.View(HtmlViewOptions.ForEmbeddedResources());
}
```

</TabItem>


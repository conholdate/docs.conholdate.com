<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to load images in various formats and convert them to HTML, PDF, PNG, and JPEG. Incorporate this library into your .NET application (web or desktop) to build your own image viewer.

To start with the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass an image you want to view to the class constructor. You can load the image from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the image to HTML, PDF, PNG, or JPEG format. For multipage images (such as TIFF, CDR, DICOM, WebP, and so on), you can specify the pages to render.

<a href="https://products.groupdocs.app/viewer/image" target="_blank" rel="nofollow noopener noreferrer">View image files online</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">View demos and examples on GitHub</a>

## Render images as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert an image to HTML. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/). 

### Create an HTML file with embedded resources

To embed an image in an HTML page, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("vector-image.svg"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("vector-image.svg")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Create an HTML file with external resources

To save an image to a separate folder, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("vector-image.svg"))
{
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name in the output file name.
    var viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("vector-image.svg")
            ' Specify the HTML file name and location of external resources.
            ' {0} is replaced with the resource name in the output file name.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}",    "output/resource_{0}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Render images as PDF

The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file, reorder its pages, and specify the quality of document images. Refer to the following documentation section for details: [Rendering to PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

## Convert images to PNG

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert an image to PNG. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> properties to specify the output image size in pixels.


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

// ...

{
    // Create a PNG image.
    var viewOptions = new PngViewOptions("output.png");
    // Set width and height.
    viewOptions.Width = 1600;
    viewOptions.Height = 900;
    viewer.View(viewOptions);
}
```

## Render a PSD file with custom fonts

When you render a PSD file with custom fonts, you can specify a folder that contains necessary fonts to prevent font substitution during rendering. To do this, follow the steps below:

1. Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/folderfontsource" target="_blank" rel="nofollow noopener noreferrer">FolderFontSource</a> class instance and specify a path to the folder that stores custom fonts. Pass a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/folderfontsource/properties/searchoption" target="_blank" rel="nofollow noopener noreferrer">SearchOption</a> enumeration member to the class constructor to define the search scope. The following options are available:
    * `TopFolderOnly`---Searches for the fonts only in the current folder.
    * `AllFolders`---Searches for the fonts in the current folder and its subfolders.

2. Call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/fontsettings/methods/setfontsources" target="_blank" rel="nofollow noopener noreferrer">FontSettings.SetFontSources</a> static method and pass the specified font source to this method as a parameter. This method allows you to specify multiple font sources.

You can also set the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/defaultfontname" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.DefaultFontName</a> property to specify the default font that should be used when a particular font is not found.


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Fonts;
using GroupDocs.Viewer.Options;
// ...

// Specify a folder that stores custom fonts used in a PSD file.
var fontSource = new FolderFontSource(@"C:\custom_fonts_folder", SearchOption.AllFolders);
FontSettings.SetFontSources(fontSource);

using (var viewer = new Viewer("sample.psd"))
{
    // Convert a PSD file to PNG.
    var viewOptions = new PngViewOptions("output.png");
    // Specify the default font that should be used to replace missing fonts.
    viewOptions.DefaultFontName = "Arial";
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

' ...

        End Using
    End Sub
End Module
```

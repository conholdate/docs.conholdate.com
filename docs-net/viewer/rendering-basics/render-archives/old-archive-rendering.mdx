<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to view the contents of archive files in HTML, PDF, PNG, and JPEG formats. You do not need to use third-party file archiver and compression software to display archive file contents within your .NET application (web or desktop). 

To start using the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass an archive file you want to view to the class constructor. You can load the archive from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the archive file to HTML, PDF, or image format.

<a href="https://products.groupdocs.app/viewer/archive" target="_blank" rel="nofollow noopener noreferrer">View archive files online</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">View demos and examples on GitHub</a>

## Supported archive and compressed file formats

GroupDocs.Viewer supports the following archive file formats:

* <a href="https://docs.fileformat.com/compression/7z" target="_blank" rel="nofollow noopener noreferrer">.7Z (7-Zip Compressed File)</a>
* <a href="https://docs.fileformat.com/compression/bz2" target="_blank" rel="nofollow noopener noreferrer">.BZ2 (Bzip2 Compressed File)</a>
* <a href="https://docs.fileformat.com/compression/gz" target="_blank" rel="nofollow noopener noreferrer">.GZ (Gnu Zipped Archive)</a>
* <a href="https://docs.fileformat.com/compression/rar" target="_blank" rel="nofollow noopener noreferrer">.RAR (WinRAR Compressed Archive)</a>
* <a href="https://docs.fileformat.com/compression/tar" target="_blank" rel="nofollow noopener noreferrer">.TAR (Consolidated Unix File Archive)</a>
* <a href="https://docs.fileformat.com/compression/tgz/" target="_blank" rel="nofollow noopener noreferrer">.TGZ / .TAR.GZ (Gzipped Tar File)</a>
* <a href="https://docs.fileformat.com/compression/xz/" target="_blank" rel="nofollow noopener noreferrer">.TXZ / .TAR.XZ (XZ Compressed Tar Archive)</a>
* <a href="https://docs.fileformat.com/compression/xz/" target="_blank" rel="nofollow noopener noreferrer">.XZ (XZ Compressed Archive)</a>
* <a href="https://docs.fileformat.com/compression/zip" target="_blank" rel="nofollow noopener noreferrer">.ZIP (Zipped File)</a>
* <a href="https://docs.fileformat.com/compression/zst/" target="_blank" rel="nofollow noopener noreferrer">.ZST / .TAR.ZST / .TZST (Zstandard)</a>
* <a href="https://docs.fileformat.com/compression/iso/" target="_blank" rel="nofollow noopener noreferrer">.ISO (Optical Disk Image ISO-9660)</a>

GroupDocs.Viewer can detect the archive file format automatically based on information in the file header.

## Render archive files as HTML

To convert an archive file to HTML, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method to create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass this instance to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file for the top folder and each subfolder in the archive.
    // {0} is replaced with the current page number in the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("Documents.zip")
            ' Create an HTML file for the top folder and each subfolder in the archive.
            ' {0} is replaced with the current page number in the output file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Specify the number of items to render

GroupDocs.Viewer supports the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/itemsperpage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ArchiveOptions.ItemsPerPage</a> option that allows you to specify the number of archive items to display on each HTML page. The default property value is **16**.

The following example demonstrates how to set this option in code:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file for the top folder and each subfolder in the archive.
    // {0} is replaced with the current page number in the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    // Specify the number of items to display on each HTML page.
    viewOptions.ArchiveOptions.ItemsPerPage = 10;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

    Sub Main(args As String())

            ' Specify the number of items to display on each HTML page.
            viewOptions.ArchiveOptions.ItemsPerPage = 10
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Create a single HTML page

If you need to display the contents of an archive file on a single HTML page, enable the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.RenderToSinglePage</a> option, as shown below:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Render the archive file to a single page.
    viewOptions.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

    Sub Main(args As String())
        Using viewer = New Viewer("Documents.zip")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            ' Render the archive file to a single page.
            viewOptions.RenderToSinglePage = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file or reorder its pages. Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert an archive file to PNG. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> properties to specify the output image size in pixels.


<Tabs groupId="example5">

```csharp
    // Set width and height.
```

## Obtain information about folders in an archive file

Follow the steps below to obtain information about folders contained in an archive file. You can use this information to [specify which folder to display in the output file](#render-a-specific-folder).

1. Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> instance for a specific view.
2. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a> method, pass the `ViewInfoOptions` instance to this method as a parameter, and cast the returned object to the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/archiveviewinfo" target="_blank" rel="nofollow noopener noreferrer">ArchiveViewInfo</a> type.
3. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/archiveviewinfo/folders/" target="_blank" rel="nofollow noopener noreferrer">ArchiveViewInfo.Folders</a> property to obtain the lists of folders in the archive file.


<Tabs groupId="example7">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    var viewInfo = viewer.GetViewInfo(viewInfoOptions) as ArchiveViewInfo;

    if (viewInfo != null)
    {
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");
        Console.WriteLine("Folders: ");
        // Display the list of folders in the archive file.
        foreach (string folder in viewInfo.Folders)
            Console.WriteLine($" - {folder}");
    }
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("Documents.zip")
            Dim viewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo = TryCast(viewer.GetViewInfo(viewInfoOptions), ArchiveViewInfo)

            If viewInfo IsNot Nothing Then
                Console.WriteLine($"File type: {viewInfo.FileType}")
                Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}")
                Console.WriteLine("Folders: ")
                ' Display the list of folders in the archive file.
                For Each folder As String In viewInfo.Folders
                    Console.WriteLine($" - {folder}")
                Next
            End If
        End Using
    End Sub
End Module
```

</TabItem>

## Render a specific folder

When you convert an archive file to HTML, PDF, or image format, GroupDocs.Viewer renders items from all folders contained in the archive. If you need to render items from a specific folder, specify the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/properties/folder" target="_blank" rel="nofollow noopener noreferrer">ArchiveOptions.Folder</a> property for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>


<Tabs groupId="example8">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Specify a folder to render items from.
    viewOptions.ArchiveOptions.Folder = "Documents/CAD files";
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
    End Sub
End Module
```

## Specify the archive file name

When rendering an archive file, GroupDocs.Viewer displays the archive file name in the header of each page. If you need to change or hide this name, define the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/filename/" target="_blank" rel="nofollow noopener noreferrer">ArchiveOptions.FileName</a> property for a target view. You can set this option to one of the following values:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/filename/source/" target="_blank" rel="nofollow noopener noreferrer">FileName.Source</a>--- Returns the name of the source file (this name is used by default).
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/archiveoptions/properties/filename/empty" target="_blank" rel="nofollow noopener noreferrer">FileName.Empty</a>---Specifies an empty name. Use this value to hide the archive file name in the output file.
* A <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/filename/filename/" target="_blank" rel="nofollow noopener noreferrer">FileName</a> instance with a custom name you want to display in the output file.

The following code snippet demonstrates how to use a custom name when rendering an archive file to HTML:


<Tabs groupId="example9">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file for the top folder and each subfolder in the archive.
    // {0} is replaced with the current page number in the output file name.

    // Specify a custom filename
    viewOptions.ArchiveOptions.FileName = new FileName("Sample Files");

}
```

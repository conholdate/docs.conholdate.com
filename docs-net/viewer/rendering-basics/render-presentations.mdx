<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render your presentations in HTML, PDF, PNG, and JPEG formats. You do not need to use Microsoft PowerPoint or other software to load and view presentations within your .NET application (web or desktop). 

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance to get started with the GroupDocs.Viewer API. Pass a presentation you want to view to the class constructor. You can load the presentation from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the presentation to HTML, PDF, or image format. These methods allow you to render the entire presentation or specific slides.

## Supported presentation file formats

GroupDocs.Viewer supports the following presentation file formats:

* <a href="https://docs.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Presentation</a> (.PPTX)
* <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Presentation</a> (.PPT)
* <a href="https://docs.fileformat.com/presentation/potx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Template</a> (.POTX)
* <a href="https://docs.fileformat.com/presentation/pot" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Template</a> (.POT)
* <a href="https://docs.fileformat.com/presentation/potm" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Template</a> (.POTM)
* <a href="https://docs.fileformat.com/presentation/ppsx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Slide Show</a> (.PPSX)
* <a href="https://docs.fileformat.com/presentation/ppsm" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Slide Show</a> (.PPSM)
* <a href="https://docs.fileformat.com/presentation/pps" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Slide Show</a> (.PPS)
* <a href="https://docs.fileformat.com/presentation/pptmx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Presentation</a> (.PPTM)

GroupDocs.Viewer can detect the document format automatically based on information in the file header.

## Render presentations as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a presentation file to HTML. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/). 

### Create an HTML file with embedded resources

To save all elements of an HTML page (including text, graphics, and stylesheets) into a single file, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Create an HTML file for each slide.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.pptx")
            ' Create an HTML file for each slide.
            ' {0} is replaced with the current page number in the file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Create an HTML file with external resources

If you want to store an HTML file and additional resource files (such as fonts, images, and stylesheets) separately, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Create an HTML file for each slide.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources(
        "page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

### Generate pure HTML/CSS markup

Before <a href="https://releases.groupdocs.com/viewer/net/release-notes/2024/groupdocs-viewer-for-net-24-5-release-notes/" target="_blank" rel="nofollow noopener noreferrer">version 24.5</a>, the GroupDocs.Viewer for .NET was able to render presentations to the HTML in only one mode, which is heavily based on SVG images. Actually, the whole slide is converted to a single vector image in <a href="https://docs.fileformat.com/page-description-language/svg/" target="_blank" rel="nofollow noopener noreferrer">SVG format</a>, and the HTML here is served only as a wrapper around a SVG element. This mode has an undeniable advantage of 100% accurate reproduction of the original presentation. In other words, what you see in MS PowerPoint when opening a presentation, this is exactly what you see in the web-browser after opening the same presentation in the GroupDocs.Viewer. This is possible because GroupDocs.Viewer scans the original presentation document and reproduces it by drawing every tiny element, every pixel on a SVG canvas while preserving the position, shape and orientation.

But because of its SVG-based nature this mode also has the disadvantages - the SVG markup is too complex, full-text search may not work as expected, and, actually, this is not the "real" HTML- and CSS-markup. So if you want to implement something like modification or post-processing the document after obtaining it from GroupDocs.Viewer, you may encounter troubles, because standard tools like HTML parsers or CSS queries usually are not working with SVG markup.

That's why we represent the new HTML conversion mode for the Presentations - pure HTML/CSS mode. In this mode no SVG images are generated at all, only pure HTML and CSS markup.

By default this mode is disabled, and the existing SVG-based mode is activated. For enabling the new pure HTML/CSS conversion mode, please set the boolean flag `RenderToPureHtml` to `true` value in the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/presentationoptions/" target="_blank" rel="nofollow noopener noreferrer">`PresentationOptions`</a> property of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> class. 

Code example below shows converting the same presentation file to the pure HTML/CSS markup in two variations - with embedded and external resources:


<Tabs groupId="example_pure">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...
string inputPresentationPath = "SamplePresentation.pptx";

//preparing HTML options for embedded and external resources
HtmlViewOptions embeddedOptions = HtmlViewOptions.ForEmbeddedResources("slide_{0}_embedded.html");
HtmlViewOptions externalOptions = HtmlViewOptions.ForExternalResources("slide_{0}.html", "slide_{0}_{1}", "slide_{0}_{1}");
//enabling the pure HTML/CSS mode for both options
embeddedOptions.PresentationOptions.RenderToPureHtml = externalOptions.PresentationOptions.RenderToPureHtml = true;

using (Viewer viewer = new Viewer(inputPresentationPath))
{
    viewer.View(embeddedOptions);
    viewer.View(externalOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim inputPresentationPath As String = "SamplePresentation.pptx"
        'preparing HTML options for embedded and external resources
        Dim embeddedOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources("slide_{0}_embedded.html")
        Dim externalOptions As HtmlViewOptions = HtmlViewOptions.ForExternalResources("slide_{0}.html", "slide_{0}_{1}", "slide_{0}_{1}")
        'enabling the pure HTML/CSS mode for both options
        embeddedOptions.PresentationOptions.RenderToPureHtml = True
        externalOptions.PresentationOptions.RenderToPureHtml = True
        Using viewer = New Viewer(inputPresentationPath)
            viewer.View(embeddedOptions)
            viewer.View(externalOptions)
        End Using
    End Sub
End Module
```

</TabItem>


</Tabs>


Need to mention that this new pure HTML/CSS mode also has the next limitations and disadvantages:

1. Its fidelity is generally worse compared to the original SVG-based mode, especially on presentations with complex slides layout and sophisticated text formatting.
2. For this moment rendering comments and notes are not supported, so the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/rendercomments/" target="_blank" rel="nofollow noopener noreferrer">`RenderComments`</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/rendernotes/" target="_blank" rel="nofollow noopener noreferrer">`RenderNotes`</a> properties of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> class are ignored.
3. <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/resolution/" target="_blank" rel="nofollow noopener noreferrer">`Resolution`</a> property of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/" target="_blank" rel="nofollow noopener noreferrer">`PresentationOptions`</a> class is also not supported for this moment, the images are exported to the output HTML document in their original resolution.
4. <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">`RenderToSinglePage`</a> boolean property of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> class is not supported too, so every slide of the presentation will be saved to the distinct HTML document.
5. <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/renderresponsive/" target="_blank" rel="nofollow noopener noreferrer">`RenderResponsive`</a> boolean property of <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> class belongs to the existing SVG-based conversion mode, so its value is ignored while converting in pure HTML/CSS mode, - HTML- and CSS-markup are already 100% responsive.

We plan to add support for most of these missing features in the near future by constantly improving this new pure HTML/CSS converter, adding new features and fixing bugs.

## Render presentations as PDF

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a presentation file to PDF. The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file, reorder its pages, and specify the quality of document images. Refer to the following documentation section for details: [Rendering to PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

## Specify image resolution

When you convert presentations with high-resolution images to other formats, you may need to lower image resolution to reduce the output file size. GroupDocs.Viewer supports the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">PresentationOptions.Resolution</a> option that allows you to compress images in the output HTML and PDF files. To access this option, use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/presentationoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.PresentationOptions</a> or <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/presentationoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions.PresentationOptions</a> property (depending on the output file format).

You can set the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">PresentationOptions.Resolution</a> property to one of the following <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a> field values:

| Resolution field | DPI | Remarks |
| --- | --- | --- |
| DocumentResolution | As in the source file | This is the default value. |
| Dpi72 | 72 | Maximum image compression and minimum file size. |
| Dpi96 | 96 | Good for web pages and projectors. |
| Dpi150 | 150 | Good for web pages and projectors. |
| Dpi220 | 220 | Excellent quality on most printers and screens. |
| Dpi330 | 330 | Good quality for high-definition (HD) displays. |

The following example shows how to specify image resolution in code: 


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Convert the presentation to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify resolution.
    viewOptions.PresentationOptions.Resolution = Resolution.Dpi150;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">


## Render hidden slides

The following code example uses this option to display hidden slides in the generated PDF file:


<Tabs groupId="example7">

## Render speaker notes

A presentation file can contain speaker notes that help presenters recall important information during the presentation. Speaker notes appear in the **Notes** pane below each slide.

![Speaker notes in Microsoft PowerPoint](/net/viewer/images/rendering-basics/render-presentations/presentation-speaker-notes.png)

Enable the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/rendernotes" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.RenderNotes</a> property for a target view to display speaker notes in the output HTML, PDF, or image files.

The following code sample renders a presentation with speaker notes to PDF:


<Tabs groupId="example9">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Convert the presentation to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Enable speaker notes rendering.
    viewOptions.RenderNotes = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.pptx")
            ' Convert the presentation to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Enable speaker notes rendering.
            viewOptions.RenderNotes = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

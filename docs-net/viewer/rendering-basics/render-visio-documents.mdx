<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render your Visio diagrams in HTML, PDF, PNG, and JPEG formats. You do not need to use Microsoft Visio or other diagramming software to load and view Visio files within your .NET application (web or desktop). 

To start using the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass a document you want to view to the class constructor. You can load the document from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the document to HTML, PDF, or image format. These methods allow you to render the entire document or specific pages.

## Supported Visio file formats

GroupDocs.Viewer supports the following Visio file formats:

* <a href="https://docs.fileformat.com/visio/vsdx/" target="_blank" rel="nofollow noopener noreferrer">Visio Drawing</a> (.VSDX)
* <a href="https://docs.fileformat.com/visio/vsd/" target="_blank" rel="nofollow noopener noreferrer">Visio 2003-2010 Drawing</a> (.VSD)
* <a href="https://docs.fileformat.com/visio/vsdm/" target="_blank" rel="nofollow noopener noreferrer">Visio Macro-Enabled Drawing</a> (.VSDM)
* <a href="https://docs.fileformat.com/visio/vssx/" target="_blank" rel="nofollow noopener noreferrer">Visio Stencil</a> (.VSSX)
* <a href="https://docs.fileformat.com/visio/vss/" target="_blank" rel="nofollow noopener noreferrer">Visio 2003-2010 Stencil</a> (.VSS)
* <a href="https://docs.fileformat.com/visio/vssm/" target="_blank" rel="nofollow noopener noreferrer">Visio Macro-Enabled Stencil</a> (.VSSM)
* <a href="https://docs.fileformat.com/visio/vstx/" target="_blank" rel="nofollow noopener noreferrer">Visio Template</a> (.VSTX)
* <a href="https://docs.fileformat.com/visio/vst/" target="_blank" rel="nofollow noopener noreferrer">Visio 2003-2010 Template</a> (.VST)
* <a href="https://docs.fileformat.com/visio/vstm/" target="_blank" rel="nofollow noopener noreferrer">Visio Macro-Enabled Template</a> (.VSTM)
* <a href="https://docs.fileformat.com/visio/vdx/" target="_blank" rel="nofollow noopener noreferrer">Visio Drawing XML File</a> (.VDX)
* <a href="https://docs.fileformat.com/visio/vsx/" target="_blank" rel="nofollow noopener noreferrer">Visio Stencil XML File</a> (.VSX)
* <a href="https://docs.fileformat.com/visio/vtx/" target="_blank" rel="nofollow noopener noreferrer">Visio Template XML File</a> (.VTX)
* <a href="https://docs.fileformat.com/visio/vdw/" target="_blank" rel="nofollow noopener noreferrer">Visio Web Drawing</a> (.VDW)

GroupDocs.Viewer can detect the document format automatically based on information in the file header.


:::info
Family of Visio file formats currently are not supported by the `net6.0` runtime (<a href="https://www.nuget.org/packages/GroupDocs.Viewer.Net60" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer.Net60</a>). They are supported on Windows with `net462` and `net6.0-windows`.
:::


## Render Visio files as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a Visio file to HTML. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/). 

### Create an HTML file with embedded resources

To save all elements of an HTML page (including text, graphics, and stylesheets) into a single file, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create an HTML file for each drawing page.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("flowchart.vsdx")
            ' Create an HTML file for each drawing page.
            ' {0} is replaced with the current page number in the file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Create an HTML file with external resources

If you want to store an HTML file and additional resource files (such as fonts, images, and stylesheets) separately, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create an HTML file for each drawing page.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources(
        "page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("flowchart.vsdx")
            ' Create an HTML file for each drawing page.
            ' Specify the HTML file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Render Visio files as PDF

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a Visio file to PDF. The `PdfViewOptions` class properties allow you to control the conversion process. For instance, you can protect the output PDF file, reorder its pages, and specify the quality of document images. Refer to the following documentation section for details: [Rendering to PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

// ...

{
    // Create a PDF file for the document.
    // Specify the PDF file name.
    var viewOptions = new PdfViewOptions("output.pdf");
    viewer.View(viewOptions);
}
```

## Render Visio files as PNG

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a Visio file to PNG. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> properties to specify the output image size in pixels.


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create a PNG image for each drawing page.
    // {0} is replaced with the current page number in the image name.
    var viewOptions = new PngViewOptions("output_{0}.png");
    // Set width and height.
    viewOptions.Width = 950;
    viewOptions.Height = 800;
    viewer.View(viewOptions);
}
```

## Render only diagram shapes

GroupDocs.Viewer allows you to render shapes used in a Visio diagram or stored in a Visio stencil file. These shapes are displayed in the **Document Stencil** pane in Microsoft Visio.

![Document Stencil pane in Visio](/net/viewer/images/rendering-basics/render-visio-documents/visio-document-stencil.png)

To render only master shapes contained in Visio file, enable the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/visiorenderingoptions/properties/renderfiguresonly" target="_blank" rel="nofollow noopener noreferrer">VisioRenderingOptions.RenderFiguresOnly</a> property for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

The <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/visiorenderingoptions/properties/figurewidth" target="_blank" rel="nofollow noopener noreferrer">VisioRenderingOptions.FigureWidth</a> property allows you to specify the shape width in pixels. The height is calculated automatically based on the aspect ratio of each shape.


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("map.vsdx"))
{
    // Convert the Visio file to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Render the master shapes only.
    viewOptions.VisioRenderingOptions.RenderFiguresOnly = true;
    // Specify shape width in pixels.
    viewOptions.VisioRenderingOptions.FigureWidth = 200;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("map.vsdx")
            ' Convert the Visio file to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Render the master shapes only.
            viewOptions.VisioRenderingOptions.RenderFiguresOnly = True
            ' Specify shape width in pixels.
            viewOptions.VisioRenderingOptions.FigureWidth = 200
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

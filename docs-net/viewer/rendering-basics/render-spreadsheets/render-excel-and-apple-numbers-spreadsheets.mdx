<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render your spreadsheet files in HTML, PDF, PNG, and JPEG formats. You do not need to use Microsoft Excel or other spreadsheet programs to load and view Excel documents within your .NET application (web or desktop). 

To start with the GroupDocs.Viewer API, create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance. Pass a spreadsheet file you want to view to the class constructor. You can load the document from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the document to HTML, PDF, or image format. These methods allow you to render the entire document or specific pages.

## Supported spreadsheet file formats

GroupDocs.Viewer supports the following spreadsheet file formats:

* <a href="https://docs.fileformat.com/spreadsheet/xlsx" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Workbook</a> (.XLSX)
* <a href="https://docs.fileformat.com/spreadsheet/xls" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel 97-2003 Workbook</a> (.XLS)
* <a href="https://docs.fileformat.com/spreadsheet/xlsb" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Binary Workbook</a> (.XLSB)
* <a href="https://docs.fileformat.com/spreadsheet/xlsm" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Macro-Enabled Workbook</a> (.XLSM)
* <a href="https://docs.fileformat.com/spreadsheet/xltx" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Template</a> (.XLTX)
* <a href="https://docs.fileformat.com/spreadsheet/xlt" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel 97-2003 Template</a> (.XLT)
* <a href="https://docs.fileformat.com/spreadsheet/xltm" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Macro-Enabled Template</a> (.XLTM)
* <a href="https://docs.fileformat.com/spreadsheet/xlam/" target="_blank" rel="nofollow noopener noreferrer">Microsoft Excel Add-In</a> (.XLAM)
* <a href="https://en.wikipedia.org/wiki/SpreadsheetML" target="_blank" rel="nofollow noopener noreferrer">XML Spreadsheet 2003</a> (.XML)
* <a href="https://docs.fileformat.com/spreadsheet/ods" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Spreadsheet</a> (.ODS)
* <a href="https://docs.fileformat.com/spreadsheet/ots/" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Spreadsheet Template</a> (.OTS)
* <a href="https://docs.fileformat.com/spreadsheet/fods/" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Flat XML Spreadsheet</a> (.FODS)
* <a href="https://docs.fileformat.com/spreadsheet/csv" target="_blank" rel="nofollow noopener noreferrer">Comma Separated Values File</a> (.CSV)
* <a href="https://docs.fileformat.com/spreadsheet/tsv" target="_blank" rel="nofollow noopener noreferrer">Tab Separated Values File</a> (.TSV)
* <a href="https://docs.fileformat.com/spreadsheet/sxc/" target="_blank" rel="nofollow noopener noreferrer">StarOffice Calc Spreadsheet</a> (.SXC)
* <a href="https://docs.fileformat.com/spreadsheet/numbers" target="_blank" rel="nofollow noopener noreferrer">Apple Numbers Spreadsheet</a> (.NUMBERS)

GroupDocs.Viewer can detect the document format automatically based on information in the file header.

## Render spreadsheets as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a spreadsheet file to HTML. The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

<a name="unique-ID"></a>
When rendering spreadsheets to HTML format, regardless of the exact rendering mode (one HTML file per one worksheet, or single HTML for all worksheets, embedded or external resources), there always is an HTML `<table>`, that contains all the data from a worksheet, and a set of different CSS properties, which are applied to different parts of this table (rows, cells, or their ranges) and decorate them. There always is a CSS stylesheet (embedded or external) with a set of rulesets and at-rules, which are binded with a HTML table and its content by different selectors.

In some cases it is required to embed the GroupDocs.Viewer into the other web-application. In this scenario may occur an issue, when the styles from the GroupDocs.Viewer interfere with the styles of the parent web application. In particular, when GroupDocs.Viewer converts the spreadsheet to the HTML, it creates several rulesets with `<TR>`, `<TD>`, `<COL>`, `<BR>` type-selector, and these rulesets may corrupt the behavior of the parent web-page.

It was a problem in the GroupDocs.Viewer before the version 24.3. Starting from <a href="https://releases.groupdocs.com/viewer/net/release-notes/2024/groupdocs-viewer-for-net-24-3-release-notes/" target="_blank" rel="nofollow noopener noreferrer">version 24.3</a>, when rendering spreadsheet documents, the GroupDocs.Viewer adds the unique ID value to every HTML element and CSS selector in order to eliminate any interference with styles of the parent application. So now all the type-selectors are replaced to be the combined id-type descendant selectors like `#gdt-id-1 td`, `#gdt-id-2 tr`, and so on. This excludes any style conflicts once and for all.


### Create an HTML file with embedded resources

To save all elements of an HTML page (including text, graphics, and stylesheets) into a single file, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.

#### Convert an Excel workbook to HTML


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to HTML.
    // {0} is replaced with the current page number in the file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            ' Convert the spreadsheet to HTML.
            ' {0} is replaced with the current page number in the file names.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Create an HTML file with external resources

If you want to store an HTML file and additional resource files (such as fonts, images, and stylesheets) separately, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format

#### Convert an Excel workbook to HTML


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to HTML.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

### Convert all Excel worksheets to one HTML file

To convert all worksheets to one HTML file, set the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.RenderToSinglePage</a> property to `true`. This feature is supported in both cases - when converting to HTML with embedded and external resources.


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Personal_net_worth_calculator.xlsx"))
{
    // Convert all Excel worksheets to one HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page.html");
    // Enable converting all worksheets to one file.
    viewOptions.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("Personal_net_worth_calculator.xlsx")
            ' Convert all Excel worksheets to one HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page.html")
            ' Enable converting all worksheets to one file.
            viewOptions.RenderToSinglePage = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>


</Tabs>

## Render spreadsheets as PNG

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a spreadsheet file to PNG. ## Detect a CSV/TSV separator

If you load a CSV/TSV file to convert it to another format, enable the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/detectseparator" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.DetectSeparator</a> property for a target view to automatically detect a delimiter used to separate values in the source file.

GroupDocs.Viewer can detect the following separators:

* A comma (the default separator)
* A semicolon


<Tabs groupId="example12">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.csv"))
{
    // Convert the spreadsheet to HTML.
    // {0} is replaced with the current page number in the file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    // Detect a CSV/TSV separator.
    viewOptions.SpreadsheetOptions.DetectSeparator = true;
    viewer.View(viewOptions);
}          
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
```

## Get worksheet names

GroupDocs.Viewer allows you to obtain information about the source spreadsheet file. For example, you can retrieve worksheet names, as described below:

1. Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> instance for a specific view.
2. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a> method and pass the `ViewInfoOptions` instance to this method as a parameter.
3. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/properties/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> property of the returned <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo" target="_blank" rel="nofollow noopener noreferrer">ViewInfo</a> object to iterate through the list of worksheets and retrieve the worksheet names.


<Tabs groupId="example13">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("sample.xlsx"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    // Call this method to create a single page for each worksheet.
    viewInfoOptions.SpreadsheetOptions = SpreadsheetOptions.ForOnePagePerSheet();

    var viewInfo = viewer.GetViewInfo(viewInfoOptions);

    // Print the worksheet names in the console window.
    Console.WriteLine("The document contains the following worksheets:");
    foreach (Page page in viewInfo.Pages)
    {
        Console.WriteLine($" - Worksheet {page.Number}: '{page.Name}'");
    }
}
```

</TabItem>

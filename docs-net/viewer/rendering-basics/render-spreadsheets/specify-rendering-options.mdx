GroupDocs.Viewer ships with the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions</a> class that allows you to specify different spreadsheet rendering options (for example, you can display row and column headings in the output file, render grid lines, or adjust cell text overflow). To access these options, use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/spreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions</a> property for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

## Render row and column headings

Rows and columns in a worksheet have unique names displayed on the worksheet's left and top side. Rows are numbered (1, 2, 3, ..., 1048576), and columns are lettered (A, B, C, ..., XFD).

![Row and column headings in a worksheet](/net/viewer/images/rendering-basics/render-spreadsheets/excel-row-and-column-headings.png)

Enable the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/renderheadings" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.RenderHeadings</a> property to display row and column headings in the output file when you render your spreadsheet in HTML, PDF, PNG, or JPEG format.

The following example demonstrates how to convert an Excel workbook to PDF and display row and column headings in the output PDF file:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Render row and column headings.
    viewOptions.SpreadsheetOptions.RenderHeadings = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            ' Convert the spreadsheet to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Render row and column headings.
            viewOptions.SpreadsheetOptions.RenderHeadings = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>


</Tabs>

The following code example demonstrates how to convert an Excel workbook to PDF and display gridlines in the output PDF file:

## Control cell text overflow

The <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.TextOverflowMode</a> option allows you to prevent text overflow in worksheet cells (see the image below) when you convert your spreadsheet file to HTML, PDF, or image format.

![Text overflow in a cell](/net/viewer/images/rendering-basics/render-spreadsheets/excel-text-overflow.png)

You can set the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode</a> property to one of the following values:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.OverlayIfNextIsEmpty</a> (default) --- Allows text to overflow into adjacent cells if these cells have no data. If adjacent cells are not empty, the overflowing text is truncated.

    ![TextOverflowMode.OverlayIfNextIsEmpty](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-overlay-if-empty.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.Overlay</a> --- Text always overflows into adjacent cells even if these cells contain data.

    ![TextOverflowMode.Overlay](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-overlay.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.AutoFitColumn</a> --- Increases the column width to fit cell text.

    ![TextOverflowMode.AutoFitColum](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-autofit-column.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.HideText</a> --- Hides text that overflows the cell boundaries.
  
    ![TextOverflowMode.HideText](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-hide-text.png)

The following example demonstrates how to set this option in code:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the AutoFitColumn mode.
    viewOptions.SpreadsheetOptions.TextOverflowMode = TextOverflowMode.AutoFitColumn;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")

            ' Specify the AutoFitColumn mode.
            viewOptions.SpreadsheetOptions.TextOverflowMode = TextOverflowMode.AutoFitColumn
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Render hidden rows and columns

Use the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/renderhiddenrows" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.SpreadsheetOptions.RenderHiddenRows</a> and <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/renderhiddencolumns" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.SpreadsheetOptions.RenderHiddenColumns</a> properties to display hidden rows and columns in the output file when you render your spreadsheet in HTML, PDF, PNG, or JPEG format.

The example below demonstrates how to set this option in code. The rows **20** and **21** and the column **E** are hidden in the source Excel workbook. 

![Hidden rows and columns in a worksheet](/net/viewer/images/rendering-basics/render-spreadsheets/excel-hidden-columns-and-rows.png)


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Enable rendering hidden rows and columns.
    viewOptions.SpreadsheetOptions.RenderHiddenRows = true;
    viewOptions.SpreadsheetOptions.RenderHiddenColumns = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            ' Convert the spreadsheet to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Enable rendering hidden rows and columns.
            viewOptions.SpreadsheetOptions.RenderHiddenRows = True
            viewOptions.SpreadsheetOptions.RenderHiddenColumns = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Skip empty rows and columns

GroupDocs.Viewer supports the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/skipemptyrows" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.SkipEmptyRows</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/skipemptycolumns" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.SkipEmptyColumns</a> properties that allow you to skip blank rows and columns when you convert your spreadsheet file to HTML, PDF, or image format.


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

    viewOptions.SpreadsheetOptions.SkipEmptyColumns = true;
    viewer.View(viewOptions);
}
```

## Render cell comments

Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/rendercomments" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.RenderComments</a> option to display cell comments in the output file when you render your spreadsheet in HTML, PDF, PNG, or JPEG format.


<Tabs groupId="example7">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

// ...

{
    // Convert the spreadsheet to PNG.
    // {0} is replaced with the current page number in the file names.
    var viewOptions = new PngViewOptions("output_{0}.png");
```

## Set worksheet margins in the output pdf pages

Use the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/rendergridlines" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.RenderGridLines</a> properties to set margins for worksheets in the output pdf. If margins are set to value less than 0 or not set then default value will be used.

The following code example demonstrates how to convert an Excel workbook to PDF and set optional margins for worksheets in the output PDF file:


<Tabs groupId="example8">


<TabItem value="c" label="C#" default>

```cs
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    var viewOptions = new PdfViewOptions("output.pdf");
	
    // Set margins for worksheets in the output pdf pages
    viewOptions.SpreadsheetOptions.LeftMargin = 0;
    viewOptions.SpreadsheetOptions.RightMargin = 0.5;
    viewOptions.SpreadsheetOptions.TopMargin = 1;
    viewOptions.SpreadsheetOptions.BottomMargin = -10; // set to default value
	
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            Dim viewOptions = New PdfViewOptions("output.pdf")
        
            ' Set margins for worksheets in the output pdf pages
            viewOptions.SpreadsheetOptions.LeftMargin = 0
            viewOptions.SpreadsheetOptions.RightMargin = 0.5
            viewOptions.SpreadsheetOptions.TopMargin = 1
            viewOptions.SpreadsheetOptions.BottomMargin = -10 ' set to default value
        
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

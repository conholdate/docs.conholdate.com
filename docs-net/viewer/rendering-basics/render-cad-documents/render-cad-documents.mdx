<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> allows you to render your CAD drawings and 3D models in HTML, PDF, PNG, and JPEG formats. You do not need to use AutoCAD or other CAD software to load and view CAD files within your .NET application (web or desktop).

Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> class instance to get started with the GroupDocs.Viewer API. Pass a CAD drawing you want to view to the class constructor. You can load the drawing from a file or stream. Call one of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method overloads to convert the drawing to HTML, PDF, or image format.

<a href="https://products.groupdocs.app/viewer/cad" target="_blank" rel="nofollow noopener noreferrer">View CAD files online</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">View demos and examples on GitHub</a>

## Supported CAD file formats

GroupDocs.Viewer supports the following CAD and 3D file formats:

* <a href="https://docs.fileformat.com/cad/dwg/" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Drawing</a> (.DWG)
* <a href="https://docs.fileformat.com/cad/dwt" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Drawing Template</a> (.DWT)
* <a href="https://docs.fileformat.com/cad/dwf/" target="_blank" rel="nofollow noopener noreferrer">Design Web Format</a> (.DWF)
* <a href="https://docs.fileformat.com/cad/dxf" target="_blank" rel="nofollow noopener noreferrer">Drawing Exchange Format</a> (.DXF)
* <a href="https://docs.fileformat.com/cad/plt" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Plotter Document</a> (.PLT)
* <a href="https://docs.fileformat.com/cad/dgn" target="_blank" rel="nofollow noopener noreferrer">MicroStation Design File (V7)</a> (.DGN)
* <a href="https://docs.fileformat.com/cad/ifc" target="_blank" rel="nofollow noopener noreferrer">Industry Foundation Classes</a> (.IFC)
* <a href="https://docs.fileformat.com/cad/stl" target="_blank" rel="nofollow noopener noreferrer">Stereolithography File</a> (.STL)
* <a href="https://docs.fileformat.com/3d/obj/" target="_blank" rel="nofollow noopener noreferrer">Wavefront 3D Object File</a> (.OBJ)
* <a href="https://docs.fileformat.com/cad/cf2/" target="_blank" rel="nofollow noopener noreferrer">Common File Format</a> (.CF2)
* <a href="https://docs.fileformat.com/cad/igs/" target="_blank" rel="nofollow noopener noreferrer">IGES (Initial Graphics Exchange Specification) Drawing</a> (.IGS)
* <a href="https://docs.fileformat.com/cad/hpgl/" target="_blank" rel="nofollow noopener noreferrer">HPGL (Hewlett-Packard Graphics Language) Plot File</a> (.HPG)

GroupDocs.Viewer can detect the document format automatically based on information in the file header.

## Render CAD drawings as HTML

Create an <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class instance and pass it to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> method to convert a CAD file to HTML. During the conversion, GroupDocs.Viewer creates an <a href="https://docs.fileformat.com/page-description-language/svg/" target="_blank" rel="nofollow noopener noreferrer">SVG</a> image from the CAD drawing and embeds this image in an <a href="https://docs.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">HTML</a> document.

The `HtmlViewOptions` class properties allow you to control the conversion process. For instance, you can embed all external resources in the generated HTML file, minify the output file, and optimize it for printing. Refer to the following documentation section for details: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/). 

### Create an HTML file with embedded resources

To save all elements of an HTML page (including text, graphics, and stylesheets) into a single file, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> method and specify the output file name.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Create an HTML file for the drawing.
    // Specify the HTML file name.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("HousePlan.dwg")
            ' Create an HTML file for the drawing.
            ' Specify the HTML file name.
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Create an HTML file with external resources

If you want to store an HTML file and additional resource files (such as fonts, images, and style sheets) separately, call the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> method and pass the following parameters:

  * The output file path format
  * The path format for the folder with external resources
  * The resource URL format


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Create an HTML file for the drawing.
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

## Get information about existing layouts and layers

Follow the steps below to obtain information about layouts and layers contained in a CAD drawing. You can use this information to specify which layers and layouts to display in the output file.

1. Create a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> instance for a specific view.
2. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a> method, pass the `ViewInfoOptions` instance to this method as a parameter, and cast the returned object to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo</a> type.
3. Use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo/properties/layouts" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo.Layouts</a> and <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo/properties/layers" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo.Layers</a> properties to obtain the lists of layouts and layers in the CAD file.


<Tabs groupId="example6">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    ViewInfoOptions viewInfoOptions = ViewInfoOptions.ForHtmlView();
    // Enable this option to see the list of all layouts contained in the CAD file.
    viewInfoOptions.CadOptions.RenderLayouts = true;
    CadViewInfo viewInfo = viewer.GetViewInfo(viewInfoOptions) as CadViewInfo;

    if (viewInfo != null)
    {
        // Display information about the CAD file.
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");

        // Display the list of existing layouts.
        Console.WriteLine("The drawing contains the following layout(s):");
        foreach (Layout layout in viewInfo.Layouts)
            Console.WriteLine(layout.Name);

        // Display the list of existing layers.
        Console.WriteLine("The drawing contains the following layer(s):");
        foreach (Layer layer in viewInfo.Layers)
            Console.WriteLine(layer);
    }
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

                For Each layout As Layout In viewInfo.Layouts
                    Console.WriteLine(layout.Name)
                Next
        
                ' Display the list of existing layers.
                Console.WriteLine("The drawing contains the following layer(s):")

                Next
            End If
        End Using
    End Sub
```

## Render all or specific layouts

When you convert a CAD drawing to HTML, PDF, or image format, GroupDocs.Viewer renders only the model-space layout (*Model*). If you also need to render all paper space layouts contained in your CAD file, enable the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> option for one of the following classes (depending on the output file format):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

Each layout is rendered on a separate page.

The following example renders all layouts when converting a CAD drawing to PDF:


<Tabs groupId="example7">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.dwg"))
{
   // Convert the document to PDF.
   PdfViewOptions viewOptions = new PdfViewOptions("output.pdf");
   // Render the Model and all non-empty paper space layouts. 
   viewOptions.CadOptions.RenderLayouts = true;
   viewer.View(viewOptions);
}
```

</TabItem>

```vb
        End Using
    End Sub
End Module
```

## Render specific layers

A CAD drawing can contain many layers. Each layer is used to draw a specific object type. For example, the drawing below contains layers for walls, furniture, plants, and so on. You can control the visibility of objects on the drawing by turning specific layers on or off.

![Layers in a CAD file](/net/viewer/images/rendering-basics/render-cad-documents/autocad-drawing-layers.png)

When you convert a CAD drawing to HTML, PDF, or image format, GroupDocs.Viewer renders all available layers. You can specify which layers to display in the output file, as described below:

1. Access the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/cadoptions" target="_blank" rel="nofollow noopener noreferrer">CadOptions</a> property for a target view:

  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> 
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>

2. Assign the list of layers you want to render to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layers" target="_blank" rel="nofollow noopener noreferrer">CadOptions.Layers</a> property.

The following example renders layers with walls and furniture to PDF:


<Tabs groupId="example9">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
using System.Collections.Generic;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Convert the document to PDF.
    PdfViewOptions viewOptions = new PdfViewOptions("output.pdf");
    // Specify a list of layers to display.
    viewOptions.CadOptions.Layers = new List<Layer>
    {
        new Layer("Base"),
        new Layer("Walls"),
        new Layer("Furniture")
    };
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Results
Imports System.Collections.Generic
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("HousePlan.dwg")
            ' Convert the document to PDF.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions("output.pdf")
            ' Specify a list of layers to display.
            viewOptions.CadOptions.Layers = New List(Of Layer) From {
                New Layer("Base"),
                New Layer("Walls"),
                New Layer("Furniture")
                }
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

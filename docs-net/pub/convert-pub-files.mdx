## Overview to .pub conversion functionality via .NET {#overview-to-pub-conversion-functionality-via-net}

Converting PUB files is an option when you want to open or edit Microsoft Publisher files in other software. Let's consider other reasons why would you want to convert PUB files:

- Not all software or devices support the PUB file format so conversion will let you open and view it on many platforms.

- If you need to collaborate with others who don't have Microsoft Publisher, converting PUB files to a common format allows everyone to access and work on the files.

- Converting PUB files to formats such as PDF or XPS will let you exclude all the possible printing issues.

- PUB files to a more standard format ensures their long-term accessibility so, you can still access your documents in the future, even if Microsoft Publisher becomes outdated.

There are [various file formats you can convert PUB files to](/net/pub/supported-file-formats/), such as PDF, DOCX (Microsoft Word), RTF (Rich Text Format), or HTML (web page format). The choice of format depends on your specific needs and the software or platform you intend to use. And if you want to do it online without coding anything you can use <a href="https://products.conholdate.app/conversion" target="_blank">cross-platform converters</a> for such a purpose.

## PUB to PDF Conversion using C# {#pub-to-pdf-conversion-using-c}

Aspose.PUB for .NET can read and convert publication files (.pub) to <a href="https://wiki.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>. The  <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">PubFactory</a> class creates content from a .pub file for further processing by the Document class of the API.

:::info
At present, the API doesn't support the conversion of images in a PUB file to output PDF.
:::

Portable Document Format (PDF) was introduced by Adobe to represent documents that can be read on digital devices. PUB files require Microsoft Publisher to be installed on the computer in order to open these files. Aspose.PUB for .NET lets you convert PUB files to PDF that can be opened on almost all computers without the need for Microsoft Publisher being installed. The following steps and code snippet show how to convert PUB to PDF using C# in your .NET applications.

:::info
Aspose.PUB for .NET supports converting multi-page PUB documents to PDF using the same lines of code given in this article.
:::

The provided code snippet uses Aspose.PUB library for .NET to convert a Microsoft Publisher (.pub) file into a PDF format. Here's a breakdown of the code:

In these examples, `DataDir` is the input directory and `OutputDir` is the output directory. Set them to your own directories and ensure the output directory exists. Import the `Aspose.Pub` and `System.IO` namespaces when using the snippets in your application.

1. Construct the input path with `Path.Combine(DataDir, "halloween-flyer.pub")` and store it in `fileName`.

2. Call the `CreateParser` method from <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">*PubFactory*</a> with `fileName` to obtain an `IPubParser`.

3. Call `parser.Parse()` to read the PUB file into a `Document` object named `doc`.

4. Construct `outPath` with `Path.Combine(OutputDir, "halloween-flyer_out.pdf")`.

5. Call `PubFactory.CreatePdfConverter()` to create a PDF converter, then call <a href="https://reference.aspose.com/pub/net/aspose.pub/ipdfconverter/converttopdf/" target="_blank" rel="nofollow noopener noreferrer">*ConvertToPdf*</a> with `doc` and `outPath` to save the PDF file.

```java
// Convert a PUB document to PDF

// Parse the input Publisher document.
string fileName = Path.Combine(DataDir, "halloween-flyer.pub");
IPubParser parser = PubFactory.CreateParser(fileName);
Document doc = parser.Parse();

// Convert the document to PDF and save the result.
string outPath = Path.Combine(OutputDir, "halloween-flyer_out.pdf");
PubFactory.CreatePdfConverter().ConvertToPdf(doc, outPath);
```

## PUB to JPEG Conversion using C# {#pub-to-jpeg-conversion-using-c}

The C# code below demonstrates the conversion of the Publisher (.pub) file to JPEG using Aspose.PUB for .NET library that provides <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">*PubFactory*</a> and related classes. Here's a breakdown of what the code does:

1. Construct the input path with `Path.Combine(DataDir, "halloween-flyer.pub")`.
2. Create an `IPubParser` using <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/createparser/#createparser_1" target="_blank" rel="nofollow noopener noreferrer">*PubFactory.CreateParser(fileName)*</a>, then call `parser.Parse()` to obtain a `Document` object.
3. Construct `outPath` with `Path.Combine(OutputDir, "halloween-flyer_out.jpg")`.
4. Call `PubFactory.CreatePubConverter()` to create a converter, then call `ConvertToFormat(doc, outPath, PubExportFormats.Jpg)` to save the JPEG file.

You can convert PUB to another format in a similar way, using one of the supported <a href="https://reference.aspose.com/pub/net/aspose.pub/pubexportformats/" target="_blank" rel="nofollow noopener noreferrer">*PubExportFormats*</a>

```java
// Convert a PUB document to JPEG

// Parse the input Publisher document.
string fileName = Path.Combine(DataDir, "halloween-flyer.pub");
IPubParser parser = PubFactory.CreateParser(fileName);
Document doc = parser.Parse();

// Convert the document to JPEG and save the result.
string outPath = Path.Combine(OutputDir, "halloween-flyer_out.jpg");
PubFactory.CreatePubConverter().ConvertToFormat(doc, outPath, PubExportFormats.Jpg);
```

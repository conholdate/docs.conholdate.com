## Moving a Page from one PDF Document to Another {#moving-a-page-from-one-pdf-document-to-another}

This topic explains how to move page from one PDF document to the end of another document using C#.

The following code snippet also work with [Aspose.PDF.Drawing](/net/pdf/drawing/) library.

To move an page we should:

1. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class object with the source PDF file.
2. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class object with the destination PDF file.
3. Get Page from the the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/pagecollection" target="_blank" rel="nofollow noopener noreferrer">PageCollection</a> collection's.
4. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/add/methods/1" target="_blank" rel="nofollow noopener noreferrer">Add</a> page to the destination document.
5. Save the output PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.
6. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/delete/methods/1" target="_blank" rel="nofollow noopener noreferrer">Delete</a> page in source document.
7. Save the source PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

The following code snippet shows you how to move one page.

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void MovingAPageFromOnePdfDocumentToAnother()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_Pages();

    // Open PDF documents
    using (var srcDocument = new Aspose.Pdf.Document(dataDir + "MovingPageInput.pdf"))
    {
        using (var dstDocument = new Aspose.Pdf.Document())
        {
            var page = srcDocument.Pages[2];
            dstDocument.Pages.Add(page);
            // Save PDF document
            dstDocument.Save(dataDir + "MovingPage_out.pdf");
            srcDocument.Pages.Delete(2);
            // Save PDF document
            srcDocument.Save(dataDir + "MovingPageInput_out.pdf");
        }
    }
}
```

## Moving bunch of Pages from one PDF Document to Another {#moving-bunch-of-pages-from-one-pdf-document-to-another}

1. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class object with the source PDF file.
2. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class object with the destination PDF file.
3. Define an array with page numbers to be moved.
4. Run loop through array:
   1. Get Page from the the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/pagecollection" target="_blank" rel="nofollow noopener noreferrer">PageCollection</a> collection's.
   2. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/add/methods/1" target="_blank" rel="nofollow noopener noreferrer">Add</a> page to the destination document.
5. Save the output PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.
6. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/delete/methods/2" target="_blank" rel="nofollow noopener noreferrer">Delete</a> page in source document using array.
7. Save the source PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

The following code snippet shows you how to move a bunch of pages from one PDF document to another.

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void MovingBunchOfPagesFromOnePdfDocumentToAnother()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_Pages();

    // Open PDF documents
    using (var srcDocument = new Aspose.Pdf.Document(dataDir + "MovingBunchOfPagesInput.pdf"))
    {
        using (var dstDocument = new Aspose.Pdf.Document())
        {
            var pages = new[] { 1, 3 };
            foreach (int pageIndex in pages)
            {
                var page = srcDocument.Pages[pageIndex];
                dstDocument.Pages.Add(page);
            }
            // Save PDF document
            dstDocument.Save(dataDir + "MovingBunchOfPages_out.pdf");
            srcDocument.Pages.Delete(pages);
            // Save PDF document
            srcDocument.Save(dataDir + "MovingBunchOfPagesInput_out.pdf";
        }
    }
}
```

## Moving a Page in new location in the current PDF Document {#moving-a-page-in-new-location-in-the-current-pdf-document}

1. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class object with the source PDF file.
2. Get Page from the the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/pagecollection" target="_blank" rel="nofollow noopener noreferrer">PageCollection</a> collection's.
3. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/add/methods/1" target="_blank" rel="nofollow noopener noreferrer">Add</a> page to the new location (for example to end).
4. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.pagecollection/delete/methods/1" target="_blank" rel="nofollow noopener noreferrer">Delete</a> page in previous location.
5. Save the output PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void MovingAPageInNewLocationInTheCurrentPdfDocument()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_Pages();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "MovingAPageInNewLocationInTheCurrentPdfDocumentInput.pdf"))
    {
        var page = document.Pages[2];
        document.Pages.Add(page);
        document.Pages.Delete(2);
        // Save PDF document
        document.Save(dataDir + "MovingAPageInNewLocationInTheCurrentPdfDocument_out.pdf");
    }
}
```

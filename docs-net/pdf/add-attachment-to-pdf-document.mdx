Attachments can contain a wide variety of information and can be of a variety of file types. This article explains how to add an attachment to a PDF file.

The next code snippet also works with [Aspose.Drawing](/net/pdf/drawing/) library.

1. Create a new C# project.
2. Add a reference to Aspose.PDF DLL.
3. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> object.
4. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/filespecification" target="_blank" rel="nofollow noopener noreferrer">FileSpecification</a> object with the file you are adding, and file description.
5. Add the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/filespecification" target="_blank" rel="nofollow noopener noreferrer">FileSpecification</a> object to the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> object's <a href="https://reference.aspose.com/pdf/net/aspose.pdf/embeddedfilecollection" target="_blank" rel="nofollow noopener noreferrer">EmbeddedFiles</a> collection, with the collection's Add method.

The <a href="https://reference.aspose.com/pdf/net/aspose.pdf/embeddedfilecollection" target="_blank" rel="nofollow noopener noreferrer">EmbeddedFiles</a> collection contains all the attachments in the PDF file. The following code snippet shows you how to add an attachment in a PDF document.

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void AddEmbeddedFile()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_Attachments();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "AddAttachment.pdf"))
    {
        // Setup new file to be added as attachment
        Aspose.Pdf.FileSpecification fileSpecification = new Aspose.Pdf.FileSpecification(dataDir + "test.txt", "Sample text file");

        // Add attachment to document's attachment collection
        document.EmbeddedFiles.Add(fileSpecification);

        // Save PDF document
        document.Save(dataDir + "AddAnnotations_out.pdf");
    }
}
```

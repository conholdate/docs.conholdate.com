**Basic operations** section describes the first, simplest, and popular operation with PDF documents in Aspose.PDF for .NET:

- [Create PDF Document](/net/pdf/create-document/) - this article describes how to create PDF file using C#.
- [Open PDF Document](/net/pdf/open-pdf-document/) - this article describes a various ways how to open a PDF document in .NET application.
- [Save PDF Document](/net/pdf/save-pdf-document/) - this article describes a various ways how to save a PDF document to file, stream, send to Web or save as PDF/A (or PDF/X) document.
- [Merge PDF](/net/pdf/merge-pdf-documents/) - merge multiple PDF files into a single PDF document using C#.
- <a href="https://docs.aspose.com/pdf/net/split-document/" target="_blank" rel="nofollow noopener noreferrer">Split PDF</a> - split PDF pages into individual PDF files in your .NET applications.
- [Encrypt and Decrypt PDF File](/net/pdf/set-privileges-encrypt-and-decrypt-pdf-file/)- encrypt, and decrypt PDF files.

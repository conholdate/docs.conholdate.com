**Parse PDF** documents is a term releated to extraction variuous kind of information from PDF file. This section covers how to:

- [Extract Text from PDF](/net/pdf/extract-text-from-pdf/) - text Parsing or Extraction is the most popular operation with ready-made PDFs. You will learn about text parsing from a whole document, a particular page, or a particular region in a page.
- [Extract Images from PDF](/net/pdf/extract-images-from-the-pdf-file/) - image Extraction does the same for images as the operation above for text.
- [Extract Fonts from PDF](/net/pdf/extract-fonts-from-pdf/) - font Extraction is a specific operation with fonts in PDFs.
- [Extract Data from the Form](/net/pdf/extract-data-from-acroform/) - if you have a bunch of PDF documents with Forms, probably you need to get the data from those forms. This article will help to understand how to extract AcroForms data with Aspose.PDF for .NET.
- [Extract Text From Stamps](/net/pdf/extract-text-from-stamps/) - get text information from your PDF document.
- [Extract Data from Table](/net/pdf/extract-data-from-table-in-pdf/) - get data from table in PDF document.
- [Extract Vector Data from PDF](/net/pdf/extract-vector-data-from-pdf/) - you can get the vector data (path, polygon, polyline), such as position, color, linewidth, etc.

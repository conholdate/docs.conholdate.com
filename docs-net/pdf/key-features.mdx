## Cross-platform software

Supports various platforms and .NET versions. See [System Requirements](/net/pdf/system-requirements/) for details.

## General Features

Aspose.PDF provides powerful Document Object Model (DOM) to explore and modify all types of PDF content. Supports loading from and saving to a wide list of [file formats](/net/pdf/supported-file-formats/).

## Supported PDF standards

- ISO 32000-1 (PDF 1.2, PDF 1.3, PDF 1.4, PDF 1.5, PDF 1.6, PDF 1.7).
- ISO 32000-2 (PDF 2.0).
- ISO 19005 (PDF/A), ISO 15930 (PDF/X), ISO 24517 (PDF/E), ISO 14289 (PDF/UA).

## AI capabilities

Supports various AI providers with the ability to load data from PDF documents.

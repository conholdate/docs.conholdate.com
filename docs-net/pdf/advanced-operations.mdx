**Advanced Operations** is a section about how to deals with existing PDF files programatically, be they documents created with Aspose.PDF as discussed in [Basic Operations](/net/pdf/basic-operations/), or PDFs created with Adobe Acrobat, Google Docs, Microsoft Office, Open Office or any other PDF producer.

You'll learn different ways to:

- [Working with Documents](/net/pdf/working-with-documents/) - compress, split, and merge documents and make other operations with the whole document.
- [Working with Pages](/net/pdf/working-with-pages/) - add, move or remove, crop pages, add watermarks, stamps.
- [Working with Text](/net/pdf/working-with-text/) - add, format, search and replace text in PDF.
- [Working with Images](/net/pdf/working-with-images/) - insert, remove, extract image in document.
- [Working with Tables](/net/pdf/working-with-tables/) - insert, decorate table in PDF, extract tabular data.
- [Working with Forms](/net/pdf/working-with-forms/) - deal with interact PDF documents, add formfields, extract data.
- [Working with Graphs](/net/pdf/working-with-graphs/) - manipulate with shapes on the page.
- [Working with XML](/net/pdf/working-with-xml/) - construct PDF documents based on the XML structure.
- [Working with Operators](/net/pdf/working-with-operators/) - make low-level operations in PDF.
- [Working with Vector Graphics](/net/pdf/working-with-vector-graphics/) - describes the features of working with GraphicsAbsorber.
- [Working with ZUGFeRD](/net/pdf/working-with-zugferd/) - create ZUGFeRD-compliant PDF invoices.
- [Working with Javascript](/net/pdf/working-with-javascript/) - add, remove Javascript code in PDF.
- [Compare PDF documents](/net/pdf/compare-pdf-documents/) - possible to compare PDF documents content.
- [Navigation and Interaction](/net/pdf/navigation-and-interaction/) - deal with actions, bookmarks, navigate pages.
- [PDF AI Copilot](/net/pdf/ai-copilot/) - allow to process PDF documents using LLMs from different providers.
- [PDF Chunking and Embedding](/net/pdf/pdf-chunking-and-embedding/) - split PDF documents into semantic chunks and generate vector embeddings for RAG pipelines and semantic search.
- [Annotations](/net/pdf/annotations/) - Annotations allow users to add custom content on PDF pages. You can add, delete and modify the annotation from the PDF documents.
- [Artifacts](/net/pdf/artifacts/) - deal with watermarks and other special objects in PDF.
- [Accessibility. Tagged PDF](/net/pdf/accessibility-tagged-pdf/) - Tagging is essential for PDF accessibility. Aspose.PDF allows to add tags into PDF and establish logical reading order and to provide a means for indicating structure and type.
- [Attachments](/net/pdf/attachments/) - PDF documents may contain file attachments. These attachments can be other PDF documents, or any kind of file, like audio files, Microsoft Office documents etc. You will learn how to add attachments to pdf, get the information of an attachment, and save it to file, delete the attachment from PDF programmatically with C#.
- [Metadata in PDFs](/net/pdf/pdf-file-metadata/) - get or set meta data in documents, dealing with XMP data.
- [Securing and Signing](/net/pdf/securing-and-signing/) - protect and sign your PDF document programmatically.
- [Printing Document](/net/pdf/printing-document/) - print PDFs in various types of applications (WinForms, WPF, etc.).
- [Interrupt save operation hanging](/net/pdf/interrupt-save-operation/) - allows to protect PDF document processing from hangs.

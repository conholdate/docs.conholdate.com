**Aspose.PDF for .NET** enables you to convert a PDF file to a PDF/E-1 compliant PDF file. This article explains how.

- [Convert PDF to PDF/E-1](/net/pdf/convert-pdf-to-pdfe/#csharp-convert-pdf-to-pdfe)

The following code snippets also work with [Aspose.PDF.Drawing](/net/pdf/drawing/) library.

## Convert PDF file to PDF/E-1 {#convert-pdf-file-to-pdfe-1}

<a id="csharp-convert-pdf-to-pdfe"></a>**Convert PDF to PDF/E-1**

The following code snippet shows how to convert PDF files to PDF/E-1 compliant PDF and validate the conformance.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void ConvertPdfToPdfE()
{
    // The path to the documents directory
    string dataDir = RunExamples.GetDataDir_AsposePdf_DocumentConversion();
    
    // Open PDF document
    using (Aspose.Pdf.Document document = new Aspose.Pdf.Document(dataDir + "PDFToPDFE.pdf"))
    {
        // Set up the PDF/E-1 format with PdfFormatConversionOptions
        Aspose.Pdf.PdfFormatConversionOptions options = new Aspose.Pdf.PdfFormatConversionOptions(Aspose.Pdf.PdfFormat.PDF_E_1, Aspose.Pdf.ConvertErrorAction.Delete);

        // Convert to PDF/E-1 compliant document
        document.Convert(options);
        
        // Save PDF document
        document.Save(dataDir + "PDFToPDFE1_out.pdf");
    }
}

private static void ValidatePdfEStandard()
{
    // The path to the documents directory
    string dataDir = RunExamples.GetDataDir_AsposePdf_WorkingDocuments();
    
    // Open PDF document
    using (Aspose.Pdf.Document document = new Aspose.Pdf.Document(dataDir + "ValidatePDFEStandard.pdf"))
    {
        // Validate PDF for PDF/E-1
        document.Validate(dataDir + "ValidationResultPdfE.xml", Aspose.Pdf.PdfFormat.PDF_E_1);
    }
}
```

## Convert PDF/A document to PDF {#convert-pdfa-document-to-pdf}

Convert PDF/A document to PDF means removing PDF/A restriction from the original document. Class <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> has method <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document/methods/removepdfacompliance" target="_blank" rel="nofollow noopener noreferrer">RemovePdfaCompliance(..)</a> to remove the PDF compliance information from input/source file.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void ConvertPDFAtoPDF()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_DocumentConversion();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "PDFAToPDF.pdf"))
    {
        // Remove PDF/A compliance information
        document.RemovePdfaCompliance();
    
        // Save PDF document
        document.Save(dataDir + "PDFAToPDF_out.pdf");
    }
}
```

</TabItem>

PDF/A conformance may also be removed if you make any changes in the document (e.g. add pages). In the following example, the output document loses PDF/A compliance after a new page is added.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void ConvertPDFAtoPDFAdvanced()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_DocumentConversion();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "PDFAToPDF.pdf"))
    {
        // Adding a new (empty) page removes PDF/A compliance information.
        document.Pages.Add();

        // Save PDF document
        document.Save(dataDir + "PDFAToPDF_out.pdf");
    }
}
```

</TabItem>

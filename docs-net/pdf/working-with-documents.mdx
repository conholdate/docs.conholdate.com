PDF stands for the Portable Document Format, used to display documents in an electronic form independent of the software, hardware, or operating system they are viewed on.

The PDF is an open standard, maintained by the International Organisation for Standardisation (ISO) today.

The original goal was to preserve and protect the content and layout of a document - no matter what platform or computer program it is viewed on. This is why PDFs are hard to edit and sometimes even extracting information from them is a challenge.

But **Aspose.PDF for .NET** can help you cope with most of the tasks that arise when working with a PDF document.

You are able to do the following:

- [Formatting PDF Document](/net/pdf/formatting-pdf-document/) - create a document, get and set document properties, embedding fonts, and other operations with PDF files.
- [Manipulate PDF Document](/net/pdf/manipulate-pdf-document/) - validate a PDF document for PDF A standard, work with TOC, set PDF expiry date, etc.
- [Optimize PDF](/net/pdf/optimize-pdf/) - optimize page content, optimize file size, remove unused objects, compress all images for successful document optimization.
- [Merge PDF](/net/pdf/merge-pdf-documents/) - merge multiple PDF files into a single PDF document using C#.
- <a href="https://docs.aspose.com/pdf/net/split-document/" target="_blank" rel="nofollow noopener noreferrer">Split PDF</a> - split PDF pages into individual PDF files in your .NET applications.
- <a href="https://docs.aspose.com/pdf/net/concatenate-pdf-documents/#concatenating-all-pdf-files-in-particular-folder" target="_blank" rel="nofollow noopener noreferrer">Concatenate PDF files in folder</a> - concatenate all PDF files in a particular folder using PdfFileEditor class.
- <a href="https://docs.aspose.com/pdf/net/concatenate-pdf-documents/" target="_blank" rel="nofollow noopener noreferrer">Concatenate multiple PDF files using MemoryStreams</a> - you will learn how to concatenate multiple PDF files using MemoryStreams with C#.
- [Create Crash Reports](/net/pdf/generate-crash-reports/) - generate crash reports using C#.
- [Working with Headings](/net/pdf/working-with-headings/) - you can create numbering in headings in your PDF document with C#.
- [Clearing hidden data](/net/pdf/clear-hidden-data/) - you can clear hidden data in your PDF document with C#.

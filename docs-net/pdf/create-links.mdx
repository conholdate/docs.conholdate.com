## Create Links {#create-links}

By adding a link to an application into a document, it is possible to link to applications from a document. This is useful when you want readers to take a certain action at a specific point in a tutorial, for example, or to create a feature-rich document. To create an application link:

1. <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Create a Document</a> object.
2. Get the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> you want to add link to.
3. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> object using the Page and <a href="https://reference.aspose.com/pdf/net/aspose.pdf/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> objects.
4. Set the link attributes using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> object.
5. Also, set the to <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/launchaction" target="_blank" rel="nofollow noopener noreferrer">LaunchAction</a> object's Action property.
6. When creating the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/launchaction" target="_blank" rel="nofollow noopener noreferrer">LaunchAction</a> object, specify the application you want to launch.
7. Add the link to the Page object's <a href="https://reference.aspose.com/pdf/net/aspose.pdf/page/properties/annotations" target="_blank" rel="nofollow noopener noreferrer">Annotations</a> property.
8. Finally, save the updated PDF using the Document object's <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

The following code snippet shows how to create a link to an application in a PDF file.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void CreateLinkAnnotation()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_LinksActions();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "CreateApplicationLink.pdf"))
    {
        // Create link
        var page = document.Pages[1];
        var link = new Aspose.Pdf.Annotations.LinkAnnotation(page, new Aspose.Pdf.Rectangle(100, 100, 300, 300));
        link.Color = Aspose.Pdf.Color.FromRgb(System.Drawing.Color.Green);
        link.Action = new Aspose.Pdf.Annotations.LaunchAction(document, dataDir + "CreateApplicationLink.pdf");
        page.Annotations.Add(link);

        // Save PDF document
        document.Save(dataDir + "CreateApplicationLink_out.pdf");
    }
}
```

### Create PDF Document Link in a PDF File {#create-pdf-document-link-in-a-pdf-file}

Aspose.PDF for .NET allows you to add a link to an external PDF file so that you can link several documents together. To create a PDF document link:

1. First, create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> object.
2. Then, get the particular <a href="https://reference.aspose.com/pdf/net/aspose.pdf/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> you want to add the link to.
3. Create a <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> object using the Page and <a href="https://reference.aspose.com/pdf/net/aspose.pdf/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> objects.
4. Set the link attributes using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> object.
5. Set the Action property to the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.annotations/gotoremoteaction" target="_blank" rel="nofollow noopener noreferrer">GoToRemoteAction</a> object.
6. While creating the GoToRemoteAction object, specify the PDF file that should launch, as well as the page number it should open on.
7. Add the link to the Page object's Annotations collection.
8. Save the updated PDF using the Document object's <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

The following code snippet shows how to create PDF document link in a PDF file.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void CreateLinkAnnotation()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf_LinksActions();

    // Open PDF document
    using (var document = new Aspose.Pdf.Document(dataDir + "CreateDocumentLink.pdf"))
    {
        // Create link
        var page = document.Pages[1];
        var link = new Aspose.Pdf.Annotations.LinkAnnotation(page, new Aspose.Pdf.Rectangle(100, 100, 300, 300));
        link.Color = Aspose.Pdf.Color.FromRgb(System.Drawing.Color.Green);
        link.Action = new Aspose.Pdf.Annotations.GoToRemoteAction(dataDir + "RemoveOpenAction.pdf", 1);
        page.Annotations.Add(link);

        // Save PDF document
        document.Save(dataDir + "CreateDocumentLink_out.pdf");
    }
}
```

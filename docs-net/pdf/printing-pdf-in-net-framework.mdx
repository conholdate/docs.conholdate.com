## Print Pdf File in C# - Print PDF File to Default Printer using Printer and Page Settings {#print-pdf-file-in-c---print-pdf-file-to-default-printer-using-printer-and-page-settings}

This article describes how to Print PDF File to Default Printer using Printer and Page Settings in C#.

The <a href="https://reference.aspose.com/pdf/net/aspose.pdf.facades/pdfviewer" target="_blank" rel="nofollow noopener noreferrer">PdfViewer</a> class allows you to print a PDF file to the default printer. You need to create a PdfViewer object and open the PDF using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.facades.pdfviewer/bindpdf/methods/2" target="_blank" rel="nofollow noopener noreferrer">BindPdf</a> method. To specify different print settings, use the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.printing/pagesettings/" target="_blank" rel="nofollow noopener noreferrer">PageSettings</a> and <a href="https://reference.aspose.com/pdf/net/aspose.pdf.printing/printersettings/" target="_blank" rel="nofollow noopener noreferrer">PrinterSettings</a> classes. Finally, call the <a href="https://reference.aspose.com/pdf/net/aspose.pdf.facades/pdfviewer/methods/printdocumentwithsettings" target="_blank" rel="nofollow noopener noreferrer">PrintDocumentWithSettings</a> method to print the PDF to the default printer. The following code snippet shows how to print PDF to the default printer with printer and page settings.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void SimplePrint()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdfFacades_Printing();

    // Create PdfViewer object
    using (var viewer = new Aspose.Pdf.Facades.PdfViewer())
    {
        // Bind PDF document
        viewer.BindPdf(dataDir + "PrintDocument.pdf");

        // Set attributes for printing
        // Print the file with adjusted size
        viewer.AutoResize = true;
        // Print the file with adjusted rotation
        viewer.AutoRotate = true;
        // Do not produce the page number dialog when printing
        viewer.PrintPageDialog = false;

        // Create objects for printer and page settings and PrintDocument
        var ps = new Aspose.Pdf.Printing.PrinterSettings();
        var pgs = new Aspose.Pdf.Printing.PageSettings();
        var prtdoc = new System.Drawing.Printing.PrintDocument();

        // Set printer name
        ps.PrinterName = prtdoc.PrinterSettings.PrinterName;

        // Set PageSize (if required)
        pgs.PaperSize = Aspose.Pdf.Printing.PaperSizes.A4;

        // Set PageMargins (if required)
        pgs.Margins = new Aspose.Pdf.Devices.Margins(0, 0, 0, 0);

        // Print document using printer and page settings
        viewer.PrintDocumentWithSettings(pgs, ps);
    }
}
```

        {
            // Document printing code goes here

            // Convert PrinterSettings and PageSettings to Aspose.PDF counterparts via extension methods
            // provided in the Aspose.Pdf.Printing namespace
            Aspose.Pdf.Printing.PrinterSettings ps = printDialog.PrinterSettings.ToAsposePrinterSettings();

            // Print document using printer and page settings
            viewer.PrintDocumentWithSettings(pgs, ps);
        }
    }
}

## Choosing paper source by PDF page size {#choosing-paper-source-by-pdf-page-size}

Since the 24.4 release, choosing paper source by PDF page size in the print dialog is possible. The next code snippet enables picking a printer tray based on the PDF's page size.

This preference can be switched on and off using the <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document/picktraybypdfsize/" target="_blank" rel="nofollow noopener noreferrer">Document.PickTrayByPdfSize</a> property.

<Tabs groupId="frameworks">

<TabItem value="net-core-3-1" label=".NET Core 3.1" default>

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void PickTrayByPdfSize()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdfFacades_Printing();

    // Create PDF document
    using (var document = new Aspose.Pdf.Document())
    {
        // Add page
        var page = document.Pages.Add();
        page.Paragraphs.Add(new Aspose.Pdf.Text.TextFragment("Hello world!"));

        // Set the flag to choose a paper tray using the PDF page size
        document.PickTrayByPdfSize = true;

        // Save PDF document
        document.Save(dataDir + "PickTrayByPdfSize_out.pdf");
    }
}
```

</TabItem>

This page describes the most interesting new Aspose.Words features introduced in recent releases.

## Aspose.Words for .NET 26.9, 26.10 {#asposewords-for-net-269-2610}

Aspose.Words 26.9 expands platform support with Windows-specific builds for .NET Core 9 and .NET Core 10, adds more control over document comparison and digital signature timestamping, and improves PDF accessibility. The release also enhances PDF layout tagging for footnotes and endnotes.

Aspose.Words 26.10 introduces on-premise AI-powered document processing, improves floating table positioning, and expands chart customization capabilities. The release also enhances MathML and mathematical formula rendering and strengthens PDF/UA-2 compliance.

### AI-powered Features {#ai-powered-features}

#### On-premise AI Engine Integration 26.10 {#on-premise-ai-engine-integration-2610}

The ability to process documents using AI without sending document content outside the machine has been introduced by integrating Aspose.LLM into Aspose.Words, enabling on-premise inference entirely within the current process.

### Platforms {#platforms}

#### Windows-specific .NET Core Builds 26.9 {#windows-specific-net-core-builds-269}

The ability to use Aspose.Words with .NET Core 9 and .NET Core 10 on Windows has been introduced by adding Windows-specific builds for these target frameworks.

### Converting, Loading, and Saving Documents {#converting-loading-and-saving-documents}

#### PDF/UA-2 Compliance 26.10 {#pdfua-2-compliance-2610}

PDF export has been enhanced by implementing structure destination (`/SD`) generation for document outline entries, ensuring compliance with PDF/UA-2 requirements.

### Rendering {#rendering}

#### Improved PDF Accessibility 26.9 {#improved-pdf-accessibility-269}

PDF layout tagging has been improved by placing footnote and endnote tags according to accessibility best practices.

#### Improved Floating Table Positioning 26.10 {#improved-floating-table-positioning-2610}

Floating table positioning has been improved by implementing Microsoft Word-like behavior when balancing floating tables against footnotes, resulting in more accurate document layout.

#### Enhanced Chart Plot Area Formatting 26.10 {#enhanced-chart-plot-area-formatting-2610}

The ability to customize the fill and line formatting of a chart's plot area has been introduced, providing greater control over chart appearance.

#### Waterfall Chart Total Data Points 26.10 {#waterfall-chart-total-data-points-2610}

The ability to determine whether a data point represents a total in a waterfall chart has been introduced, enabling more precise identification of total columns.

#### MathML Background Color Remapping 26.10 {#mathml-background-color-remapping-2610}

MathML background rendering has been improved by implementing color remapping according to compatibility settings, ensuring more accurate rendering across different document compatibility modes.

#### Rendering FormCheckBox Fields in OfficeMath 26.10 {#rendering-formcheckbox-fields-in-officemath-2610}

The ability to render `FormCheckBox` fields located within `OfficeMath` formulas has been introduced, improving the rendering of documents containing mathematical expressions and form fields.

### Other {#other}

- The ability to control whether list definition content is included when comparing documents has been introduced by adding the <a href="https://reference.aspose.com/words/net/aspose.words.comparing/advancedcompareoptions/comparelistdefinitions/" target="_blank" rel="nofollow noopener noreferrer">CompareListDefinitions</a> property to the AdvancedCompareOptions class. 26.9
- The ability to add RFC 3161 timestamps to digital signatures has been introduced by adding the <a href="https://reference.aspose.com/words/net/aspose.words.digitalsignatures/signoptions/timestampsettings/" target="_blank" rel="nofollow noopener noreferrer">TimestampSettings</a> property to the SignOptions class. 26.9

## Aspose.Words for .NET 26.5, 26.6, 26.7, 26.8 {#asposewords-for-net-265-266-267-268}

Aspose.Words 26.5 introduces new digital signing and document importing capabilities, improves HTML and field rendering, and enhances support for AAT-enabled fonts in fixed-page output formats.

Aspose.Words 26.6 introduces printing support for Windows-specific .NET target frameworks, expands document customization capabilities, and improves PDF export quality and form field handling. This release also enhances table layout rendering and PDF hyphenation behavior.

Aspose.Words 26.7 introduces document readability statistics, expands PDF export capabilities, and improves rendering for mathematical equations, OLE objects, textboxes, and repeated table headers.

Aspose.Words 26.8 expands digital signature capabilities with support for post-quantum ML-DSA certificates, adds control over XPS compression, and improves PDF export reliability. The release also enhances MathML rendering for inline fractions and improves handling of corrupted JPEG images during PDF export.

### Converting, Loading, and Saving Documents {#converting-loading-and-saving-documents-1}

#### PDF Export {#pdf-export}

- Seamless export of datetime form fields to PDF, ensuring accurate transfer of date and time data, has been enabled. 26.6
- Support for JavaScript triggers for date/time fields in PDF AcroForms forms has been introduced. This makes exported forms more interactive and responsive. 26.6
- Hyphenation rendering has been improved. If the font does not contain an optional hyphen (U+00AD), a visual hyphen is now automatically used, while the text remains fully searchable. 26.6
- The overall quality of PDF output has been improved by fully preserving date picker content controls. 26.6
- The ability to export numbering fields as PDF AcroForms has been introduced when rendering documents to PDF. 26.7
- Link annotation joining has been implemented for tagged PDF output to improve accessibility and document structure. 26.7
- Improved handling of corrupted JPEG images during PDF export has been introduced through advanced image validation and automatic reprocessing. 26.8

#### Compression Level When Exporting to XPS 26.8 {#compression-level-when-exporting-to-xps-268}

The ability to control the compression level of XPS output has been introduced by adding the <a href="https://reference.aspose.com/words/net/aspose.words.saving/xpssaveoptions/compressionlevel/" target="_blank" rel="nofollow noopener noreferrer">CompressionLevel</a> property.

### Rendering {#rendering-1}

#### EQ Fields {#eq-fields}

- Support for Far East vertical orientation in HTML within EQ fields has been introduced. 26.5
- Improved visual rendering of the EQ field's frame has been implemented. 26.5
- The rendering of OLE objects within EQ fields has been implemented. 26.7

#### AAT-enabled Fonts 26.5 {#aat-enabled-fonts-265}

Improved handling of AAT-enabled fonts when rendering to fixed-page formats has been implemented.

#### Printing in .NET Core Apps Running on Windows 26.6 {#printing-in-net-core-apps-running-on-windows-266}

The ability to use <a href="https://reference.aspose.com/words/net/aspose.words/document/print/" target="_blank" rel="nofollow noopener noreferrer">Document.Print()</a> and related printing APIs in .NET Core applications running on Windows has been introduced by adding Windows-specific target framework monikers (net6.0-windows and net8.0-windows) to the NuGet package.

#### Repeated Table Header Row Handling 26.7 {#repeated-table-header-row-handling-267}

Repeated table header row handling has been improved to provide more accurate document layout during rendering.

#### Alternative Text for Inner Shapes 26.7 {#alternative-text-for-inner-shapes-267}

The rendering of alternative text for inner shapes contained in textboxes has been implemented.

### Other {#other-1}

- The ability to configure various additional digital signing options has been introduced. 26.5
- The ability to import nodes with expanded formatting options has been introduced. 26.5
- The ability to clear custom toolbars and keyboard shortcuts from a document has been introduced by adding a <a href="https://reference.aspose.com/words/net/aspose.words/document/removecustomizations/" target="_blank" rel="nofollow noopener noreferrer">new method</a> for resetting and protecting document settings. 26.6
- The handling of repeated table header rows has been improved to provide more consistent rendering and layout in multi-page tables. 26.6
- The ability to calculate **Flesch Reading Ease** and **Flesch-Kincaid Grade Level** readability statistics for document text has been introduced by adding the <a href="https://reference.aspose.com/words/net/aspose.words/readabilitystatistics/" target="_blank" rel="nofollow noopener noreferrer">ReadabilityStatistics</a> class. 26.7
- The ability to clear a custom tab stop from a list level has been introduced by adding a new <a href="https://reference.aspose.com/words/net/aspose.words.lists/listlevel/removetabstop/" target="_blank" rel="nofollow noopener noreferrer">RemoveTabStop</a> method. 26.7
- The wrapping algorithm for mathematical equations has been improved to provide more accurate rendering of complex formulas. 26.7
- Support for post-quantum PFX certificates based on ML-DSA has been introduced by <a href="https://reference.aspose.com/words/net/aspose.words.digitalsignatures/digitalsignatureutil/" target="_blank" rel="nofollow noopener noreferrer">enhancing the digital signature functionality</a> to allow documents to be signed with post-quantum certificates. 26.8
- Improved rendering of inline fractions in MathML objects has been introduced to provide more accurate rendering of mathematical content. 26.8

## Aspose.Words for .NET 26.1, 26.2, 26.3, 26.4 {#asposewords-for-net-261-262-263-264}

Aspose.Words 26.1 expands platform support with .NET 10.0, introduces Docling JSON export, enhances AI and document merging capabilities, and significantly improves PDF compliance, accessibility, and rendering accuracy for fields and mathematical equations.

Aspose.Words 26.2 improves chart customization, enhances the visual quality of mathematical equations, and aligns table layout behavior more closely with modern Microsoft Word rendering logic.

Aspose.Words for .NET 26.3 introduces improvements to AI integration, enhances document optimization capabilities, and updates font fallback handling for improved rendering of CJK Unified Ideographs Extension G range.

Aspose.Words 26.4 introduces improvements in PDF export, chart rendering capabilities, and reporting engine diagnostics, enhancing document structure fidelity, visualization accuracy, and debugging experience.

### AI-powered Features {#ai-powered-features-1}

#### Direct Instantiation of Google AI Models 26.1 {#direct-instantiation-of-google-ai-models-261}

The ability to work directly with Google AI models has been introduced by enabling <a href="https://reference.aspose.com/words/net/aspose.words.ai/googleaimodel/googleaimodel/" target="_blank" rel="nofollow noopener noreferrer">direct instantiation of the GoogleAiModel class</a> in the **Aspose.Words.AI** namespace.

#### Improved OpenAiModel Capabilities 26.3 {#improved-openaimodel-capabilities-263}

The ability to create an instance of the <a href="https://reference.aspose.com/words/net/aspose.words.ai/openaimodel/" target="_blank" rel="nofollow noopener noreferrer">OpenAiModel</a> class directly has been introduced, simplifying the integration of OpenAI-based AI features into document processing workflows.

### Supported Formats {#supported-formats}

#### New Docling JSON Export Format 26.1 {#new-docling-json-export-format-261}

The ability to export documents to the **Docling JSON format** has been introduced.

### Platforms {#platforms-1}

#### Support for the .NET 10.0 Target Framework 26.1 {#support-for-the-net-100-target-framework-261}

The ability to target the **.NET 10.0 framework** has been introduced by providing a dedicated Aspose.Words build.

### Converting, Loading, and Saving Documents {#converting-loading-and-saving-documents-2}

#### PDF AcroForm Tagging 26.1 {#pdf-acroform-tagging-261}

The ability to improve PDF accessibility has been introduced by adding support for tagging **PDF AcroForms**, making exported documents more accessible to assistive technologies.

#### Improved PDF Logical Structure 26.4 {#improved-pdf-logical-structure-264}

The ability to improve PDF logical structure by exporting node custom IDs to custom attributes during PDF export has been introduced.

### Rendering {#rendering-2}

#### Extended PDF Conformance Standards 26.1 {#extended-pdf-conformance-standards-261}

The **PdfSaveOptions** functionality has been extended by the <a href="https://reference.aspose.com/words/net/aspose.words.saving/pdfsaveoptions/preserveformfields/" target="_blank" rel="nofollow noopener noreferrer">PreserveFormFields</a> property to be compatible with all PDF compliance standards (including PDF/A and PDF/UA).

#### Rendering MathML using an East Asian Font 26.1 {#rendering-mathml-using-an-east-asian-font-261}

The ability to correctly render **MathML** content with **East Asian characters** has been introduced, while preserving Latin and Hebrew text when an East Asian font is specified.

#### EQ-matrix MathML Elements Rendering 26.2 {#eq-matrix-mathml-elements-rendering-262}

The rendering of EQ-matrix MathML elements has been improved to achieve higher visual fidelity in mathematical content.

#### Orientation And Rotation of Chart Titles and Axis Titles 26.2 {#orientation-and-rotation-of-chart-titles-and-axis-titles-262}

The ability to control the <a href="https://reference.aspose.com/words/net/aspose.words.drawing.charts/charttitle/orientation/" target="_blank" rel="nofollow noopener noreferrer">orientation</a> and <a href="https://reference.aspose.com/words/net/aspose.words.drawing.charts/charttitle/rotation/" target="_blank" rel="nofollow noopener noreferrer">rotation</a> of chart titles and axis titles has been introduced, allowing more flexible and precise chart layout customization.

#### Font Fallback Table for CJK Unified Ideographs Extension G range 26.3 {#font-fallback-table-for-cjk-unified-ideographs-extension-g-range-263}

Rendering accuracy has been improved by updating the Microsoft Office font fallback table for the CJK Unified Ideographs Extension G range, ensuring more reliable font substitution when rendering documents containing these characters.

#### Enhanced Chart Rendering 26.4 {#enhanced-chart-rendering-264}

The ability to enhance chart rendering has been introduced by adding support for funnel chart <a href="https://reference.aspose.com/words/net/aspose.words.drawing.charts/chartdatalabelcollection/" target="_blank" rel="nofollow noopener noreferrer">data labels</a>, applying chart style settings to leader line rendering, and using locale IDs when rendering default axis titles in DrawingML charts.

### Other {#other-2}

- The handling of adjacent tables has been updated by implementing the latest Microsoft Word logic for merging or separating tables during layout processing. 26.2
- The document optimization capabilities have been improved by extending the <a href="https://reference.aspose.com/words/net/aspose.words/document/joinrunswithsameformatting/" target="_blank" rel="nofollow noopener noreferrer">JoinRunsWithSameFormatting</a> method, enabling more comprehensive content merging. 26.3
- The ability to improve report generation diagnostics in LINQ Reporting Engine has been introduced by providing detailed error information during the report building stage. 26.4

## Aspose.Words for .NET 25.9, 25.10, 25.11, 25.12 {#asposewords-for-net-259-2510-2511-2512}

Aspose.Words 25.9 enhances document loading reliability, expands shape and text formatting, improves Markdown export with math support, and strengthens font handling diagnostics.

Aspose.Words 25.10 introduces enhancements to text and PDF exports, improves accessibility compliance, and adds new options for resource management during Markdown export.

Aspose.Words 25.11 expands AI integration capabilities, enhances Markdown export, and introduces advanced control over print operations.

Aspose.Words 25.12 improves rendering accuracy across PDF, HTML-Fixed, and SVG formats, adds support for Variable Fonts and Funnel charts, and enhances text orientation handling in field rendering.

### AI-powered Features {#ai-powered-features-2}

#### Configure AI Model Service Endpoints 25.11 {#configure-ai-model-service-endpoints-2511}

The ability to configure <a href="https://reference.aspose.com/words/net/aspose.words.ai/aimodel/" target="_blank" rel="nofollow noopener noreferrer">AI model</a> service endpoints has been introduced by adding support for specifying <a href="https://reference.aspose.com/words/net/aspose.words.ai/aimodel/url/" target="_blank" rel="nofollow noopener noreferrer">custom URLs</a> and <a href="https://reference.aspose.com/words/net/aspose.words.ai/aimodel/timeout/" target="_blank" rel="nofollow noopener noreferrer">request timeouts</a>, allowing greater flexibility in AI-powered integrations.

### Converting, Loading, and Saving Documents {#converting-loading-and-saving-documents-3}

#### Control How Corrupted Documents Are Opened 25.9 {#control-how-corrupted-documents-are-opened-259}

The ability to control how corrupted documents are opened has been introduced by adding a new <a href="https://reference.aspose.com/words/net/aspose.words.loading/loadoptions/recoverymode/" target="_blank" rel="nofollow noopener noreferrer">RecoveryMode</a> option.

#### Export Mathematical Equations to LaTeX Expression {#export-mathematical-equations-to-latex-expression}

The ability to export mathematical equations (Office Math) to LaTeX expressions has been introduced:

- For export to Markdown format using the <a href="https://reference.aspose.com/words/net/aspose.words.saving/markdownsaveoptions/officemathexportmode/" target="_blank" rel="nofollow noopener noreferrer">MarkdownSaveOptions.OfficeMathExportMode</a> property. 25.9
- For export to TXT format using the <a href="https://reference.aspose.com/words/net/aspose.words.saving/txtsaveoptions/officemathexportmode/" target="_blank" rel="nofollow noopener noreferrer">TxtSaveOptions.OfficeMathExportMode</a> property. 25.10

#### Improved Document Conversion Fidelity to Markdown 25.11 {#improved-document-conversion-fidelity-to-markdown-2511}

The fidelity of document conversion to Markdown has been improved by enabling the <a href="https://reference.aspose.com/words/net/aspose.words.saving/markdownofficemathexportmode/" target="_blank" rel="nofollow noopener noreferrer">export of OfficeMath objects</a> into LaTeX format, ensuring compatibility with MarkItDown renderers.

#### Control Floating Shape Tagging When Exporting to PDF 25.10 {#control-floating-shape-tagging-when-exporting-to-pdf-2510}

A new save option <a href="https://reference.aspose.com/words/net/aspose.words.saving/pdfsaveoptions/exportfloatingshapesasinlinetag/" target="_blank" rel="nofollow noopener noreferrer">ExportFloatingShapesAsInlineTag</a> has been added to provide precise control over the tagging of floating shapes as either inline or block-level elements, improving layout accuracy and accessibility.

#### Control How Images and Other External Resources are Exported to Markdown 25.10 {#control-how-images-and-other-external-resources-are-exported-to-markdown-2510}

A new <a href="https://reference.aspose.com/words/net/aspose.words.saving/markdownsaveoptions/resourcesavingcallback/" target="_blank" rel="nofollow noopener noreferrer">resource-saving callback</a> has been implemented to give developers greater flexibility in controlling how images and other external resources are exported.

#### PDF/UA Export & Accessibility 25.10 {#pdfua-export--accessibility-2510}

Compliance with PDF/UA standards has been improved by correctly tagging horizontal rules as artifacts, enhancing a better experience for users of assistive technologies.

#### Handle Relative Hyperlinks When Exporting to PDF 25.12 {#handle-relative-hyperlinks-when-exporting-to-pdf-2512}

The ability to correctly resolve and handle relative hyperlinks when exporting to PDF has been introduced by adding Base URI processing during document export.

### Rendering {#rendering-3}

#### Fine-tune Shadow Effects 25.9 {#fine-tune-shadow-effects-259}

The ability to fine-tune <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shadowformat/" target="_blank" rel="nofollow noopener noreferrer">shadow effects</a> has been enhanced by introducing new public properties.

#### Improve Diagnostics for Font Substitution 25.9 {#improve-diagnostics-for-font-substitution-259}

The ability to improve diagnostics and error handling for <a href="https://reference.aspose.com/words/net/aspose.words/fontsubstitutionwarninginfo/" target="_blank" rel="nofollow noopener noreferrer">font substitution</a> has been implemented by adding typed warnings.

#### Support for Variable Fonts When Saving Documents to SVG and Html-Fixed 25.12 {#support-for-variable-fonts-when-saving-documents-to-svg-and-html-fixed-2512}

Robust support for Variable Fonts when saving documents to SVG and Html-Fixed formats has been added, ensuring that different font variations (including weight, width, and other parameters) defined within a single font file render correctly.

#### Render Funnel Charts 25.12 {#render-funnel-charts-2512}

The ability to render Funnel charts in documents has been added.

#### Render VerticalFarEast and HorizontalRotatedFarEast Text Orientations in EQ-field 25.12 {#render-verticalfareast-and-horizontalrotatedfareast-text-orientations-in-eq-field-2512}

The ability to render **VerticalFarEast** and **HorizontalRotatedFarEast** text orientations in EQ-field elements has been introduced.

### Other {#other-3}

- new advanced print control options have been added: 25.11
- <a href="https://reference.aspose.com/words/net/aspose.words.rendering/asposewordsprintdocument/" target="_blank" rel="nofollow noopener noreferrer">A new callback interface</a>, similar to `IWarningCallback`, has been introduced to allow programmatic control over page skipping during print operations.
- A new public property has been added to accurately <a href="https://reference.aspose.com/words/net/aspose.words.rendering/asposewordsprintdocument/totalpagesprinted/" target="_blank" rel="nofollow noopener noreferrer">retrieve the actual number of pages</a> rendered by a print job.
- The ability to specify distinct target printers for <a href="https://reference.aspose.com/words/net/aspose.words.rendering/asposewordsprintdocument/colormode/" target="_blank" rel="nofollow noopener noreferrer">color and monochrome</a> (black & white) pages within a single print job has also been introduced.

## Purpose Summary {#purpose-summary}

This page explains how to open an existing document and add text programmatically.
:::

On this page we will look at how to open an existing document and add text into it using Aspose.Words or Open XML SDK.

<Tabs groupId="frameworks">

<TabItem value="aspose-words" label="Aspose.Words" default>

In Aspose.Words, we normally use the <a href="https://reference.aspose.com/words/net/aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> class to create a document and the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> class to modify it.

The following code example shows how to open an existing document and add text into it:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Document.docx");
DocumentBuilder builder = new DocumentBuilder(doc);

builder.MoveToDocumentEnd();
builder.Writeln();
builder.Write("This is the text added to the end of the document.");

doc.Save(ArtifactsDir + "Add text - Aspose.Words.docx");
```

</TabItem>

<TabItem value="open-xml-sdk" label="Open XML SDK">

You can also do the same using the Open XML SDK. At the same time, note that it looks somewhat more complicated and more cumbersome.

Below is the code explaining this functionality:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
File.Copy(MyDir + "Document.docx", ArtifactsDir + "Add text - OpenXML.docx", true);

using WordprocessingDocument doc = WordprocessingDocument.Open(ArtifactsDir + "Add text - OpenXML.docx", true);

MainDocumentPart mainPart = doc.MainDocumentPart;
Body body = doc.MainDocumentPart.Document.Body;

// Create a new paragraph with the text you want to add
Paragraph newParagraph = new Paragraph();
Run newRun = new Run();
Text newText = new Text("This is the text added to the end of the document.");
newRun.Append(newText);
newParagraph.Append(newRun);

// Append the new paragraph to the body
body.Append(newParagraph);

// Save the changes
mainPart.Document.Save();
```

</TabItem>

</Tabs>

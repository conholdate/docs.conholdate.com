## Purpose Summary {#purpose-summary}

This page explains how to read and modify document properties.
:::

Document properties allow storing some useful information about your document. These properties can be divided into two groups:

- System or built-in that contain values such as document title, author name, document statistics, and others.
- User-defined or custom, provided as name-value pairs where the user can define both the name and value.

It is useful to know that information about API and Version Number is directly written to output documents. For example, upon converting a document to PDF, Aspose.Words fills in the "Application" field with "Aspose.Words", and the "PDF Producer" field with "Aspose.Words for .NET YY.M.N", where *YY.M.N* is the version of Aspose.Words used for conversion. For more details, see [Generator or Producer Name Included in Output Documents](/net/words/generator-or-producer-name-included-in-output-documents/).

:::info
Note that you **cannot direct** Aspose.Words to change or remove this information from output documents.
:::

## Access Document Properties {#access-document-properties}

To access document properties in Aspose.Words use:

- <a href="https://reference.aspose.com/words/net/aspose.words/document/builtindocumentproperties/" target="_blank" rel="nofollow noopener noreferrer">BuiltInDocumentProperties</a> to obtain built-in properties.

- <a href="https://reference.aspose.com/words/net/aspose.words/document/customdocumentproperties/" target="_blank" rel="nofollow noopener noreferrer">CustomDocumentProperties</a> to obtain custom properties.

**BuiltInDocumentProperties** and **CustomDocumentProperties** are collections of <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/" target="_blank" rel="nofollow noopener noreferrer">DocumentProperty</a> objects. These objects can be obtained through the indexer property by name or by index.

**BuiltInDocumentProperties** additionally provides access to document properties through a set of entered properties that return values of the appropriate type. **CustomDocumentProperties** enable you to add or remove document properties from a document.

The <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/" target="_blank" rel="nofollow noopener noreferrer">DocumentProperty</a> class allows you to get the name, value, and type of a document property. <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/value/" target="_blank" rel="nofollow noopener noreferrer">Value</a> returns an object, but there is a set of methods allowing you to get the property value converted to a specific type. After you get to know what type the property is, you can use one of the **DocumentProperty.ToXXX** methods, such as **DocumentProperty.**<a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/tostring/" target="_blank" rel="nofollow noopener noreferrer">ToString</a> and **DocumentProperty.**<a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/toint/" target="_blank" rel="nofollow noopener noreferrer">ToInt</a>, to obtain the value of the appropriate type.

The following code example shows how to enumerate all built-in and custom properties in a document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Properties.docx");
            
Console.WriteLine("1. Document name: {0}", doc.OriginalFileName);
Console.WriteLine("2. Built-in Properties");
            
foreach (DocumentProperty prop in doc.BuiltInDocumentProperties)
    Console.WriteLine("{0} : {1}", prop.Name, prop.Value);

Console.WriteLine("3. Custom Properties");
            
foreach (DocumentProperty prop in doc.CustomDocumentProperties)
    Console.WriteLine("{0} : {1}", prop.Name, prop.Value);
```

:::info
You can download the template file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/blob/master/Examples/Data/Properties.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

In Microsoft Word, you can access document properties using the "File → Properties" menu.

## Add or Remove Document Properties {#add-or-remove-document-properties}

You cannot add or remove built-in document properties using Aspose.Words. You can only change or update their values.

To add custom document properties with Aspose.Words, use the <a href="https://reference.aspose.com/words/net/aspose.words.properties/customdocumentproperties/add/#add/" target="_blank" rel="nofollow noopener noreferrer">Add</a> method, passing the new property name and the value of the appropriate type. The method returns the newly created **DocumentProperty** object.

To remove custom properties, use the <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentpropertycollection/remove/" target="_blank" rel="nofollow noopener noreferrer">Remove</a> method, passing it the property name to remove, or the <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentpropertycollection/removeat/" target="_blank" rel="nofollow noopener noreferrer">RemoveAt</a> method to remove the property by index. You can also remove all properties using the <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentpropertycollection/clear/" target="_blank" rel="nofollow noopener noreferrer">Clear</a> method.

The following code example checks whether a custom property with a given name exists in a document and adds a few more custom document properties:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Properties.docx");

CustomDocumentProperties customDocumentProperties = doc.CustomDocumentProperties;
            
if (customDocumentProperties["Authorized"] != null) return;
            
customDocumentProperties.Add("Authorized", true);
customDocumentProperties.Add("Authorized By", "John Smith");
customDocumentProperties.Add("Authorized Date", DateTime.Today);
customDocumentProperties.Add("Authorized Revision", doc.BuiltInDocumentProperties.RevisionNumber);
customDocumentProperties.Add("Authorized Amount", 123.45);
```

:::info
You can download the template file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/blob/master/Examples/Data/Properties.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

The following code example shows how to remove a custom document property:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Properties.docx");
doc.CustomDocumentProperties.Remove("Authorized Date");
```

## Update Built-In Document Properties {#update-built-in-document-properties}

Aspose.Words does not automatically update document properties, as Microsoft Word does with some properties, but provides a method to update some statistical built-in document properties. Call the <a href="https://reference.aspose.com/words/net/aspose.words/document/updatewordcount/#updatewordcount/" target="_blank" rel="nofollow noopener noreferrer">UpdateWordCount</a> method to recalculate and update the following properties:

- <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/characters/" target="_blank" rel="nofollow noopener noreferrer">Characters</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/characterswithspaces/" target="_blank" rel="nofollow noopener noreferrer">CharactersWithSpaces</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/words/" target="_blank" rel="nofollow noopener noreferrer">Words</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/paragraphs/" target="_blank" rel="nofollow noopener noreferrer">Paragraphs</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/lines/" target="_blank" rel="nofollow noopener noreferrer">Lines</a>

## Create a New Custom Property Linked to Content {#create-a-new-custom-property-linked-to-content}

Aspose.Words provides the <a href="https://reference.aspose.com/words/net/aspose.words.properties/customdocumentproperties/addlinktocontent/" target="_blank" rel="nofollow noopener noreferrer">AddLinkToContent</a> method to create a new custom document property linked to content. This property returns the newly created property object or null if the <a href="https://reference.aspose.com/words/net/aspose.words.properties/documentproperty/linksource/" target="_blank" rel="nofollow noopener noreferrer">LinkSource</a> is invalid.

The following code example shows how to configure a link to a custom property:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
            
builder.StartBookmark("MyBookmark");
builder.Writeln("Text inside a bookmark.");
builder.EndBookmark("MyBookmark");

// Retrieve a list of all custom document properties from the file.
CustomDocumentProperties customProperties = doc.CustomDocumentProperties;
// Add linked to content property.
DocumentProperty customProperty = customProperties.AddLinkToContent("Bookmark", "MyBookmark");
customProperty = customProperties["Bookmark"];

bool isLinkedToContent = customProperty.IsLinkToContent;
string linkSource = customProperty.LinkSource;
string customPropertyValue = customProperty.Value.ToString();
```

## Get Document Variables {#get-document-variables}

You can get a collection of document variables using the <a href="https://reference.aspose.com/words/net/aspose.words/document/variables/" target="_blank" rel="nofollow noopener noreferrer">Variables</a> property. Variable names and values are strings.

The following code example shows how to enumerate document variables:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Document.docx");
            
string variables = "";
foreach (KeyValuePair<string, string> entry in doc.Variables)
{
    string name = entry.Key;
    string value = entry.Value;
    if (variables == "")
        variables = "Name: " + name + "," + "Value: {1}" + value;
    else
        variables = variables + "Name: " + name + "," + "Value: {1}" + value;
}

Console.WriteLine("\nDocument have following variables " + variables);
```

:::info
You can download the template file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/blob/master/Examples/Data/Properties.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

## Remove Personal Information from Document {#remove-personal-information-from-document}

If you want to share a Word document with other people, you may want to remove personal information such as author name and company. To do this use the <a href="https://reference.aspose.com/words/net/aspose.words/document/removepersonalinformation/" target="_blank" rel="nofollow noopener noreferrer">RemovePersonalInformation</a> property to set the flag indicating that Microsoft Word will remove all user information from comments, revisions, and document properties upon saving the document.

The following code example shows how to remove personal information:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Properties.docx") { RemovePersonalInformation = true };

doc.Save(ArtifactsDir + "DocumentPropertiesAndVariables.RemovePersonalInformation.docx");
```

:::info
Setting this option does not actually remove personal information while processing a document in Aspose.Words and affects only the Microsoft Word behavior.
:::

## Purpose Summary {#purpose-summary}

This page clarifies why Aspose.Words can be a simpler and more powerful alternative to VSTO for programmatic document processing.
:::

When a user needs to programmatically create, modify and manage documents, it is always important to choose the right tool that suits the specific document development needs. This article aims to help developers make the right decision when comparing Aspose.Words and VSTO.

It is worth noting again that Aspose.Words and VSTO solve slightly different tasks. VSTO helps connect some applications such as Microsoft Office Word, Excel, and Outlook. Aspose.Words for .NET enables you to perform a wide variety of document processing tasks directly in your .NET applications. With Aspose.Words, you can create, modify, convert, display, and print documents without using Microsoft Word.

You can read more about the requirements and next steps on this page.

## Get Started with Aspose.Words {#get-started-with-asposewords}

After learning the [Installation](/net/words/installation/) page and completing the required steps, you are ready to start working with Aspose.Words.

Explore the [Getting Started](/net/words/getting-started/) section to familiarize yourself with the basic requirements and capabilities and the <a href="https://docs.aspose.com/words/net/developer-guide/" target="_blank" rel="nofollow noopener noreferrer">Developer Guide</a> section to learn about various practical use cases - how to achieve a certain document appearance, how to apply a particular function, and so on.

Some complex use cases can be implemented using VSTO, but many of the more regular tasks are easier and faster to implement using Aspose.Words.

Aspose.Words also provides source code examples for features missing in VSTO. You can find:

- A list of such features on the <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/releases/tag/MissingFeaturesofVSTOv1.1" target="_blank" rel="nofollow noopener noreferrer">Missing Features of VSTO</a> page

## Purpose Summary

This page explains how to work with textboxes in documents.

In Aspose.Words, the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/textbox/" target="_blank" rel="nofollow noopener noreferrer">TextBox</a> class is used to specify how text is displayed inside a shape. It exposes a public property named **Parent** to get the parent shape for the text box so that the customer can find the linked <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shape/" target="_blank" rel="nofollow noopener noreferrer">Shape</a> from the associated **TextBox**.

## Creating a Link

The **TextBox** class provides <a href="https://reference.aspose.com/words/net/aspose.words.drawing/textbox/isvalidlinktarget/" target="_blank" rel="nofollow noopener noreferrer">IsValidLinkTarget</a> method in order to check whether the **TextBox** can be linked to the target **Textbox**.

The following code example shows how to check if the `TextBox` can be linked to the target Textbox:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();

Shape shape1 = new Shape(doc, ShapeType.TextBox);
Shape shape2 = new Shape(doc, ShapeType.TextBox);

TextBox textBox1 = shape1.TextBox;
TextBox textBox2 = shape2.TextBox;

if (textBox1.IsValidLinkTarget(textBox2))
    textBox1.Next = textBox2;
```

## Check TextBox Sequence

There are several ways to display text in a shape. The <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shape/textbox/" target="_blank" rel="nofollow noopener noreferrer">TextBox</a> can be the Head, Middle, or Tail of a sequence.

The following code example shows how to check if **TextBox** is a Head, Tail, or Middle of the sequence:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();

Shape shape = new Shape(doc, ShapeType.TextBox);
TextBox textBox = shape.TextBox;

if (textBox.Next != null && textBox.Previous == null)
    Console.WriteLine("The head of the sequence");

if (textBox.Next != null && textBox.Previous != null)
    Console.WriteLine("The Middle of the sequence.");

if (textBox.Next == null && textBox.Previous != null)
    Console.WriteLine("The Tail of the sequence.");
```

## Breaking a Link

Using the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/textbox/breakforwardlink/" target="_blank" rel="nofollow noopener noreferrer">BreakForwardLink</a> method you can break the link to the next **TextBox**.

The following code example shows how to break a link for a **TextBox**:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();

Shape shape = new Shape(doc, ShapeType.TextBox);
TextBox textBox = shape.TextBox;

// Break a forward link.
textBox.BreakForwardLink();

// Break a forward link by setting a null.
textBox.Next = null;

// Break a link, which leads to this textbox.
textBox.Previous?.BreakForwardLink();
```

## FAQ

1. **Q:** How can I verify whether one TextBox can be linked to another?\
   **A:** Use the `TextBox.IsValidLinkTarget(TextBox target)` method. It returns `true` if the current TextBox can be linked to the specified target TextBox, otherwise `false`.

2. **Q:** How do I determine the position of a TextBox within a linked sequence?\
   **A:** Check the `TextBox.Previous` and `TextBox.Next` properties. The first TextBox in the linked chain has no `Previous`, the last one has no `Next`, and a middle one has both.

3. **Q:** What method should I use to break a forward link from a TextBox?\
   **A:** Invoke `TextBox.BreakForwardLink()`. This removes the link from the current TextBox to the next one in the sequence, leaving the remaining chain intact.

4. **Q:** How can I obtain the Shape that contains a TextBox?\
   **A:** Access the `TextBox.Parent` property, which returns the `Shape` object that hosts the TextBox. This allows you to manipulate shape-level properties such as size, position, or formatting.

## Purpose Summary {#purpose-summary}

This page explains how to insert a hyperlink.
:::

:::info
See more details in the <a href="https://docs.aspose.com/words/net/working-with-hyperlinks/" target="_blank" rel="nofollow noopener noreferrer">Working with Hyperlinks and HTML</a> article.
:::

The following code example shows how to inserts a hyperlink into a Word document using the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> class:

```csharp
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
builder.Write("Please make sure to visit ");

// Specify font formatting for the hyperlink.
builder.Font.Color = Color.Blue;
builder.Font.Underline = Underline.Single;

// Insert the link.
builder.InsertHyperlink("Aspose Website", "https://www.aspose.com", false);

// Revert to default formatting.
builder.Font.ClearFormatting();
builder.Write(" for more information.");
doc.Save("Insert_Hyperlink_In_Document.doc");
```

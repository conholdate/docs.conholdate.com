## Purpose Summary {#purpose-summary}

This page explains how to work with text inside a table, including formatting and extraction.
:::

As mentioned in previous articles, a table usually contains plain text, although other content such as images or even other tables can be placed in table cells.

Adding text or other content to the table is carried out using the appropriate methods of the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> class and is described in the **"Create a Table"** article. In this article, we will talk about how to work with text in an already existing table.

## Replace Text in a Table {#replace-text-in-a-table}

The table, like any other node in Aspose.Words, has access to the <a href="https://reference.aspose.com/words/net/aspose.words/range/" target="_blank" rel="nofollow noopener noreferrer">Range</a> object. Using the table range object, you can replace text in a table.

The ability to use special characters when replacing is currently supported, so it is possible to replace existing text with multi-paragraph text. To do this, you need to use the special metacharacters described in the corresponding <a href="https://reference.aspose.com/words/net/aspose.words/range/replace/" target="_blank" rel="nofollow noopener noreferrer">Replace</a> method.

:::info
Typically, text replacement should be done at the cell level (per cell) or at the paragraph level.
:::

The following code example shows how to replace all instances of a string of text in the cells of an entire table:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Tables.docx");

Table table = (Table)doc.GetChild(NodeType.Table, 0, true);

table.Range.Replace("Carrots", "Eggs", new FindReplaceOptions(FindReplaceDirection.Forward));
table.LastRow.LastCell.Range.Replace("50", "20", new FindReplaceOptions(FindReplaceDirection.Forward));

doc.Save(ArtifactsDir + "FindAndReplace.ReplaceTextInTable.docx");
```

## Extract Plain Text from Table or Cell {#extract-plain-text-from-table-or-cell}

Using the **Range** object, you can also call methods on the entire table range and extract the table as plain text. To do this, use the <a href="https://reference.aspose.com/words/net/aspose.words/range/text/" target="_blank" rel="nofollow noopener noreferrer">Text</a> property.

The following code example shows how to print the text range of a table:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Tables.docx");
            
Table table = (Table) doc.GetChild(NodeType.Table, 0, true);

// The range text will include control characters such as "\a" for a cell.
// You can call ToString and pass SaveFormat.Text on the desired node to find the plain text content.
Console.WriteLine("Contents of the table: ");
Console.WriteLine(table.Range.Text);
```

The same technique is used to extract content from individual table cells only.

The following code example shows how to print a text range of row and table elements:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Console.WriteLine("\nContents of the row: ");
Console.WriteLine(table.Rows[1].Range.Text);

Console.WriteLine("\nContents of the cell: ");
Console.WriteLine(table.LastRow.LastCell.Range.Text);
```

## Working with Alternative Table Text {#working-with-alternative-table-text}

Microsoft Word tables have a `table title` and `table description` that provide an alternative textual representation of the information contained in the table.

In Aspose.Words, you can also add a table title and description using the <a href="https://reference.aspose.com/words/net/aspose.words.tables/table/title/" target="_blank" rel="nofollow noopener noreferrer">Title</a> and <a href="https://reference.aspose.com/words/net/aspose.words.tables/table/description/" target="_blank" rel="nofollow noopener noreferrer">Description</a> properties. These properties are meaningful for DOCX documents conforming to the ISO/IEC 29500. When saving in formats earlier than ISO/IEC 29500, these properties are ignored.

The following code example shows how to set the title and description properties of a table:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Tables.docx");

Table table = (Table) doc.GetChild(NodeType.Table, 0, true);
table.Title = "Test title";
table.Description = "Test description";

OoxmlSaveOptions options = new OoxmlSaveOptions { Compliance = OoxmlCompliance.Iso29500_2008_Strict };

doc.CompatibilityOptions.OptimizeFor(Aspose.Words.Settings.MsWordVersion.Word2016);

doc.Save(ArtifactsDir + "WorkingWithTableStylesAndFormatting.TableTitleAndDescription.docx", options);
```

## FAQ {#faq}

1. **Q:** How can I replace a specific string in all cells of a table?\
   **A:** Retrieve the table's `Range` object and call `Range.Replace("oldText", "newText")`. This operation scans every cell, paragraph, and run within the table and substitutes the matching text.

2. **Q:** How do I extract plain text from an entire table versus a single cell?\
   **A:** For the whole table, use `Table.Range.Text`. For a particular cell, access `Cell.Range.Text`. Both properties return the textual content without any formatting or markup.

3. **Q:** Can I replace text with line breaks or multiple paragraphs inside a cell?\
   **A:** Yes. Include the metacharacters `&p` (paragraph break) and `&l` (line break) in the replacement string when calling `Range.Replace`. Aspose.Words inserts the breaks during the replacement. A plain `\r` character in the replacement does not create a new paragraph.

4. **Q:** How can I add a title or description to a table for accessibility purposes?\
   **A:** Set the `Table.Title` and `Table.Description` properties. These are stored in the DOCX file according to the ISO/IEC 29500 standard and are ignored when saving to older Word formats.

5. **Q:** I need to replace text but keep the original formatting; how can I achieve that?\
   **A:** `Range.Replace` already does this: the replacement text keeps the formatting (font, style, and so on) of the text it replaces. No extra option is needed.

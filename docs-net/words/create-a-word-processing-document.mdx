## Purpose Summary {#purpose-summary}

This page describes how to create a new Word processing document from scratch and insert basic content such as paragraphs and runs.
:::

On this page we will look at how to create a document using Aspose.Words or Open XML SDK.

<Tabs groupId="frameworks">

<TabItem value="aspose-words" label="Aspose.Words" default>

In Aspose.Words, we normally use the <a href="https://reference.aspose.com/words/net/aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> class to create a document and the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> class to modify it.

The following code example shows how to create a document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);

builder.Writeln("Hello World!");

doc.Save(ArtifactsDir + "Create new document - Aspose.Words.docx");
```

</TabItem>

<TabItem value="open-xml-sdk" label="Open XML SDK">

You can also do the same using the Open XML SDK. At the same time, note that it looks somewhat more complicated and more cumbersome.

The following code example shows how to create a document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
using (WordprocessingDocument wordDocument = WordprocessingDocument.Create(ArtifactsDir + "Create new document - OpenXML.docx", 
    WordprocessingDocumentType.Document))
{
    // Add a main document part.
    MainDocumentPart mainPart = wordDocument.AddMainDocumentPart();

    // Create the document structure and add some text.
    mainPart.Document = new Document();
    Body body = new Body();
    Paragraph paragraph = new Paragraph();
    Run run = new Run();
    run.Append(new Text("Hello, Open XML!"));
    paragraph.Append(run);
    body.Append(paragraph);
    mainPart.Document.Append(body);
    mainPart.Document.Save();
}
```

</TabItem>

## Purpose Summary {#purpose-summary}

This page explains how to convert Word documents to TIFF format, including multipage output and compression options.
:::

:::info
To convert a Word document to TIFF, simply invoke the <a href="https://reference.aspose.com/words/net/aspose.words/document/save/#save/" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and specify a file name with the ".TIFF" extension.

See more details in the <a href="https://docs.aspose.com/words/net/save-a-document/" target="_blank" rel="nofollow noopener noreferrer">Save a Document</a> documentation section.
:::

The following code example shows how to convert document pages from DOC to TIFF:

```csharp
string fileDir = "../../data/";

// open the document
Document doc = new Document(fileDir + "test.doc");

// Save the document as multipage TIFF.
doc.Save("TestFile Out.tiff");
```

## Purpose Summary {#purpose-summary}

This page explains how to work with bookmarks in NPOI when handling Word documents.
:::

:::info
See more details in the <a href="https://docs.aspose.com/words/net/working-with-bookmarks/" target="_blank" rel="nofollow noopener noreferrer">Working with Bookmarks</a> article.
:::

Use the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/startbookmark/" target="_blank" rel="nofollow noopener noreferrer">StartBookmark</a> and <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/endbookmark/" target="_blank" rel="nofollow noopener noreferrer">EndBookmark</a> to create a bookmark by marking its start and end, respectively. Do not forget to pass the same bookmark name to both methods.

Bookmarks in a document can overlap and span any range. Badly formed bookmarks or bookmarks with duplicate names will be ignored when the document is saved.

The following code example shows how to set and get bookmarks:

```csharp
Document doc = new Document("../../data/document.doc");
DocumentBuilder builder = new DocumentBuilder(doc);

// ----- Set Bookmark
builder.StartBookmark("AsposeBookmark");
builder.Writeln("Text inside a bookmark.");
builder.EndBookmark("AsposeBookmark");

// ----- Get Bookmark

// By index.
Bookmark bookmark1 = doc.Range.Bookmarks[0];

// By name.
Bookmark bookmark2 = doc.Range.Bookmarks["AsposeBookmark"];
doc.Save("AsposeBookmarks.doc");
```

## Purpose Summary {#purpose-summary}

This page describes how to insert a group shape programmatically.
:::

Sometimes you need to add a group shape into a Word document. Such a group shape consists of multiple shapes.

In Microsoft Word, you can quickly add a group shape using the Group command/button. An individual shape in a group can be moved separately.

In Aspose.Words it is very easy to add a group shape using the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/groupshape/" target="_blank" rel="nofollow noopener noreferrer">GroupShape</a> class. **Shape** is created separately using the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shape/" target="_blank" rel="nofollow noopener noreferrer">Shape</a> class and then added to the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/groupshape/" target="_blank" rel="nofollow noopener noreferrer">GroupShape</a> object using the <a href="https://reference.aspose.com/words/net/aspose.words/compositenode/appendchild/" target="_blank" rel="nofollow noopener noreferrer">AppendChild</a> method.

The following code example shows how to add a group shape into a Word document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();
doc.EnsureMinimum();
            
GroupShape groupShape = new GroupShape(doc);
Shape accentBorderShape = new Shape(doc, ShapeType.AccentBorderCallout1) { Width = 100, Height = 100 };
groupShape.AppendChild(accentBorderShape);

Shape actionButtonShape = new Shape(doc, ShapeType.ActionButtonBeginning)
{
    Left = 100, Width = 100, Height = 200
};
groupShape.AppendChild(actionButtonShape);

groupShape.Width = 200;
groupShape.Height = 200;
groupShape.CoordSize = new Size(200, 200);

DocumentBuilder builder = new DocumentBuilder(doc);
builder.InsertNode(groupShape);

doc.Save(ArtifactsDir + "WorkingWithShapes.AddGroupShape.docx");
```

:::info
Below are some of the `Shape` types supported in Aspose.Words:

- Rectangle
- RoundRectangle
- RoundRectangle
- Ellipse
- Diamond
- Triangle
- RightTriangle
- Parallelogram
- Trapezoid
- Hexagon
- Octagon

For complete list, please check the <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shapetype" target="_blank" rel="nofollow noopener noreferrer">ShapeType</a> class.
:::

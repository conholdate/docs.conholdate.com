## Purpose Summary {#purpose-summary}

This page explains how to resize images inside a Word document using Aspose.Words.
:::

:::info
See more details in the <a href="https://docs.aspose.com/words/net/working-with-images/" target="_blank" rel="nofollow noopener noreferrer">Working with Images</a> documentation section.
:::

The <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> provides several overloads of the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/insertimage/#insertimage" target="_blank" rel="nofollow noopener noreferrer">InsertImage</a> method that allow you to insert an inline or floating image. For example, the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/insertimage/" target="_blank" rel="nofollow noopener noreferrer">InsertImage</a> method is used to insert an image from a file or `URL` into a document.

Using <a href="https://reference.aspose.com/words/net/aspose.words.drawing/shape/" target="_blank" rel="nofollow noopener noreferrer">Shape</a> class you can create or modify shapes in a Microsoft Word document.

The following code example shows how to resize an image:

```csharp
Document doc = new Document();

// Create New Document.
DocumentBuilder builder = new DocumentBuilder(doc);
builder.Write("Image Before Resize");
//insert image from disk
Shape shape = builder.InsertImage(@"../../data/aspose_Words-for-net.jpg");

// Write text in document.
builder.Write("ReSize image ");
shape = builder.InsertImage(@"../../data/aspose_Words-for-net.jpg");

// Changing image size. ConvertUtil Provides helper functions to convert between various measurement units. like Converts inches to points.
shape.Width = ConvertUtil.InchToPoint(0.5);
shape.Height = ConvertUtil.InchToPoint(0.5);

// Save document on file location.
builder.Document.Save("ImageReSize.doc");
```

:::info
The <a href="https://reference.aspose.com/words/net/aspose.words/convertutil/" target="_blank" rel="nofollow noopener noreferrer">ConvertUtil</a> class provides helper functions to convert between various measurement units, like conversion <a href="https://reference.aspose.com/words/net/aspose.words/convertutil/inchtopoint/" target="_blank" rel="nofollow noopener noreferrer">inches to points</a>.
:::

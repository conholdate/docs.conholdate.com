## Purpose Summary {#purpose-summary}

This page explains how to configure layout options that affect pagination and rendering.
:::

Aspose.Words enables you to create output documents with various layouts, depending on the parameters specified in properties of the <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/" target="_blank" rel="nofollow noopener noreferrer">LayoutOptions</a> class. Some of these properties resemble some of the Microsoft Word user interface menu options - they will be described in this article.

For a complete list of parameters such as <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/continuoussectionpagenumberingrestart/" target="_blank" rel="nofollow noopener noreferrer">ContinuousSectionPageNumberingRestart</a> to calculate page numbers in a continuous section that restarts page numbering, or <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/ignoreprintermetrics/" target="_blank" rel="nofollow noopener noreferrer">IgnorePrinterMetrics</a> to ignore the "Use printer metrics to lay out document" compatibility option, see the <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/" target="_blank" rel="nofollow noopener noreferrer">LayoutOptions</a> class page.

## Formatting Marks {#formatting-marks}

Aspose.Words allows to manage formatting marks using the following properties:

- <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/showhiddentext/" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenText</a> - a `Boolean` value, which specifies whether the hidden text is rendered.
- <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/showparagraphmarks/" target="_blank" rel="nofollow noopener noreferrer">ShowParagraphMarks</a> - a `Boolean` value, which specifies whether paragraph mark characters are rendered.

The page depicted in the example below contains three paragraphs. The second one is hidden. A user can change the **ShowHiddenText** option to display this hidden text on the page. Also, each paragraph has a paragraph mark at the end. The paragraph mark usually is not visible unless the **ShowParagraphMarks** property is set to render it.

## Comments and Revisions {#comments-and-revisions}

With Aspose.Words, you can render document comments that will look the same as in Microsoft Word. To specify whether comments are rendered, use the <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/commentdisplaymode/" target="_blank" rel="nofollow noopener noreferrer">CommentDisplayMode</a> property.

In Microsoft Word, this parameter is set using the "Track Changes Options" dialog box, as shown below:

![specify-layout-options_3](/net/words/images/ebd416cb4258f666-specify-layout-options-3.jpg)

Also, Aspose.Words allows you to display revisions in a document. Use the <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/revisionoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionOptions</a> property of the **LayoutOptions** class to define whether the document revisions are displayed. To control their appearance (revision highlighting color, revision bar color, etc.), use the <a href="https://reference.aspose.com/words/net/aspose.words.layout/revisionoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisonOptions</a> class.

You can also have revisions displayed as comments to the content. For this purpose, use the <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/commentdisplaymode/" target="_blank" rel="nofollow noopener noreferrer">CommentDisplayMode</a> property and <a href="https://reference.aspose.com/words/net/aspose.words.layout/commentdisplaymode/" target="_blank" rel="nofollow noopener noreferrer">ShowInBalloons</a> value.

The following code example shows how to customize revisions display:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Revisions.docx");

// Renders insert revisions inline, delete and format revisions in balloons.
doc.LayoutOptions.RevisionOptions.ShowInBalloons = ShowInBalloons.FormatAndDelete;
doc.LayoutOptions.RevisionOptions.MeasurementUnit = MeasurementUnits.Inches;
// Renders revision bars on the right side of a page.
doc.LayoutOptions.RevisionOptions.RevisionBarsPosition = HorizontalAlignment.Right;
            
doc.Save(ArtifactsDir + "WorkingWithRevisions.ShowRevisionsInBalloons.pdf");
```

## Text Shaper for Advanced Typography Rendering {#text-shaper-for-advanced-typography-rendering}

The <a href="https://reference.aspose.com/words/net/aspose.words.layout/layoutoptions/textshaperfactory/" target="_blank" rel="nofollow noopener noreferrer">TextShaperFactory</a> property enables you to set the text shaping functionality, as well as the `OpenType` features support.

Use text shaping for document processing in the following main cases:

- A document uses Kerning, Numeral Shaping, Numeral Forms, or Ligatures.
- A document uses Complex Scripts, such as Arabic, Khmer, Thai, etc.

:::info
Text shaping will be enabled only when exporting a document to PDF or XPS.
:::

## FAQ {#faq}

1. **Q:** How can I make hidden text visible in the rendered document?\
   **A:** Set the `ShowHiddenText` property of `LayoutOptions` to `true`. This tells Aspose.Words to render hidden text when the document is saved or exported. Example:

   ```csharp
   Document doc = new Document("input.docx");
   LayoutOptions layout = doc.LayoutOptions;
   layout.ShowHiddenText = true;
   doc.Save("output.pdf");
   ```

2. **Q:** My revisions are not appearing in the output; how do I display them?\
   **A:** Enable revision rendering by configuring `RevisionOptions` and, if desired, `CommentDisplayMode`. Set `RevisionOptions.ShowRevisionMarks` to `true` and choose how revisions are shown (e.g., in balloons with `RevisionOptions.ShowInBalloons`). Example:

   ```csharp
   Document doc = new Document("tracked.docx");
   LayoutOptions layout = doc.LayoutOptions;
   layout.RevisionOptions.ShowRevisionMarks = true;
   layout.CommentDisplayMode = CommentDisplayMode.ShowInBalloons;
   doc.Save("tracked_output.pdf");
   ```

3. **Q:** How do I enable proper rendering of complex scripts and OpenType features?\
   **A:** Assign a text shaper factory to `LayoutOptions.TextShaperFactory`, for example `HarfBuzzTextShaperFactory.Instance` from the Aspose.Words.Shaping.HarfBuzz package. Example:

   ```csharp
   Document doc = new Document("complex_script.docx");
   LayoutOptions layout = doc.LayoutOptions;
   layout.TextShaperFactory = HarfBuzzTextShaperFactory.Instance;
   doc.Save("complex_output.pdf");
   ```

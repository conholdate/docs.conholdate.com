## Purpose Summary {#purpose-summary}

This page explains how to insert images into a document.
:::

:::info
See more details in the <a href="https://docs.aspose.com/words/net/working-with-images/" target="_blank" rel="nofollow noopener noreferrer">Working with Images</a> documentation section.
:::

The <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> provides several overloads of the <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/insertimage/" target="_blank" rel="nofollow noopener noreferrer">InsertImage</a> method that allow you to insert an inline or floating image. If the image is an EMF or WMF metafile, it will be inserted into the document in metafile format. All other images will be saved in PNG format.

The following code example shows how to insert an image info a document:

```csharp
Document doc = new Document("../../data/document.doc");
DocumentBuilder builder = new DocumentBuilder(doc);

builder.InsertImage("../../data/HumpbackWhale.jpg");
doc.Save("insertedImage.docx");
```

## Purpose Summary {#purpose-summary}

This page explains which features Aspose.Words supports on document load.
:::

Aspose.Words allows users to work with documents in various formats and provides a wide range of options for this. For example, users can create a document from scratch or load an existing file in any [supported import format](/net/words/supported-document-formats/), make some changes to that document and then save the result. When importing a document in the selected format, the user can apply various load options.

:::info
It is important to know that many load options are common to all supported formats, and only some of the options are format-specific, such as PDF, HTML, RTF, and others.
:::

For a complete list of functions, see the API reference:

- <a href="https://reference.aspose.com/words/net/aspose.words.loading/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">load options for all formats</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.loading/chmloadoptions/" target="_blank" rel="nofollow noopener noreferrer">CHM load options</a> for CHM format
- <a href="https://reference.aspose.com/words/net/aspose.words.loading/htmlloadoptions/" target="_blank" rel="nofollow noopener noreferrer">HTML load options</a> for HTML format
- <a href="https://reference.aspose.com/words/net/aspose.words.loading/pdfloadoptions/" target="_blank" rel="nofollow noopener noreferrer">PDF load options</a> for PDF format
- <a href="https://reference.aspose.com/words/net/aspose.words.loading/rtfloadoptions/" target="_blank" rel="nofollow noopener noreferrer">RTF load options</a> for RTF format
- <a href="https://reference.aspose.com/words/net/aspose.words.loading/txtloadoptions/" target="_blank" rel="nofollow noopener noreferrer">TXT load options</a> for TXT format

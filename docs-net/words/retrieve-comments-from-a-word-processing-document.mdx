## Purpose Summary {#purpose-summary}

This page explains how to retrieve comments from a Word document programmatically.
:::

On this page we will look at how to retrieve comments from a Word Processing document using Aspose.Words or Open XML SDK.

<Tabs groupId="frameworks">

<TabItem value="aspose-words" label="Aspose.Words" default>

In Aspose.Words, use the <a href="https://reference.aspose.com/words/net/aspose.words/comment/" target="_blank" rel="nofollow noopener noreferrer">Comment</a> class and the <a href="https://reference.aspose.com/words/net/aspose.words/compositenode/getchildnodes/" target="_blank" rel="nofollow noopener noreferrer">Document.GetChildNodes</a> method to get all comments from a document.

The following code example shows how to retrieve comments from a Word Document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Comments.docx");

List<string> collectedComments = new();
NodeCollection comments = doc.GetChildNodes(NodeType.Comment, true);

// Look through all comments and gather information about them.
foreach (Comment comment in comments)
    collectedComments.Add(comment.Author + " " + comment.DateTime + " " + comment.ToString(SaveFormat.Text));

foreach (string collectedComment in collectedComments)
    Console.WriteLine(collectedComment);
```

</TabItem>

<TabItem value="open-xml-sdk" label="Open XML SDK">

You can also do the same using the Open XML SDK. At the same time, note that it looks somewhat more complicated and more cumbersome.

The following code example shows how to retrieve comments from a Word Document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
using WordprocessingDocument doc = WordprocessingDocument.Open(MyDir + "Comments.docx", false);

WordprocessingCommentsPart commentsPart = doc.MainDocumentPart.WordprocessingCommentsPart;

if (commentsPart?.Comments != null)
    foreach (Comment comment in commentsPart.Comments.Elements<Comment>())
        Console.WriteLine(comment.InnerText);
```

</TabItem>

## Purpose Summary {#purpose-summary}

This page explains how to remove fields from a Word document using Aspose.Words.
:::

Sometimes it is necessary to remove a field from a document. This may occur when it needs to be replaced with a different field type or when the field is no longer needed in the document. For example the `TOC` field when saving to HTML.

To remove a field inserted into a document using <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a>.<a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/insertfield/" target="_blank" rel="nofollow noopener noreferrer">InsertField</a>, use the returned <a href="https://reference.aspose.com/words/net/aspose.words.fields/field/" target="_blank" rel="nofollow noopener noreferrer">Field</a> object, which provides a convenient <a href="https://reference.aspose.com/words/net/aspose.words.fields/field/remove/" target="_blank" rel="nofollow noopener noreferrer">Remove</a> method for easily removing the field from the document.

The following code example shows how to remove a field from the document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Various fields.docx");
            
Field field = doc.Range.Fields[0];
field.Remove();
```

:::info
You can download the sample file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/blob/master/Examples/Data/Various%20fields.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

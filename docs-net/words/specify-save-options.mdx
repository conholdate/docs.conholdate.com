## Purpose Summary {#purpose-summary}

This page explains how to specify save options for different output formats.
:::

When saving a document, you can set some advanced properties. Aspose.Words provides you with the <a href="https://reference.aspose.com/words/net/aspose.words.saving/saveoptions/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class, which allows more precise control of the save process. There are overloads of the **Save** method that accept a **SaveOptions** object - it should be an object of a class derived from the **SaveOptions** class. Each save format has a corresponding class that holds save options for this save format, for example, there is <a href="https://reference.aspose.com/words/net/aspose.words.saving/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> for saving to PDF format, <a href="https://reference.aspose.com/words/net/aspose.words.saving/markdownsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">MarkdownSaveOptions</a> for saving to Markdown format, or <a href="https://reference.aspose.com/words/net/aspose.words.saving/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> for saving to an image. This article provides examples of working with some options classes derived from **SaveOptions**.

The following code example shows how to set the save options before saving the document into HTML:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Rendering.docx");

string imagesDir = Path.Combine(ArtifactsDir, "Images");

// The folder specified needs to exist and should be empty.
if (Directory.Exists(imagesDir))
    Directory.Delete(imagesDir, true);

Directory.CreateDirectory(imagesDir);

// Set an option to export form fields as plain text, not as HTML input elements.
HtmlSaveOptions saveOptions = new HtmlSaveOptions(SaveFormat.Html)
{
    ExportTextInputFormFieldAsText = true, ImagesFolder = imagesDir
};

doc.Save(ArtifactsDir + "WorkingWithHtmlSaveOptions.ExportTextInputFormFieldAsText.html", saveOptions);
```

:::info
You can download the template file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/blob/master/Examples/Data/Rendering.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

The article describes a few properties you can control when saving a document.

## Encrypt a Document With a Password {#encrypt-a-document-with-a-password}

Use the **Password** property to get or set a password for an encrypted document. Use the **Password** property of the corresponding class to work with the selected document format.

For example, when saving a document to DOC or DOT format, use the <a href="https://reference.aspose.com/words/net/aspose.words.saving/docsaveoptions/password/" target="_blank" rel="nofollow noopener noreferrer">Password</a> property of the <a href="https://reference.aspose.com/words/net/aspose.words.saving/docsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">DocSaveOptions</a> class.

The following code example shows how to set a password to encrypt a document using the RC4 encryption method:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);
            
builder.Write("Hello world!");

DocSaveOptions saveOptions = new DocSaveOptions { Password = "password" };

doc.Save(ArtifactsDir + "WorkingWithDocSaveOptions.EncryptDocumentWithPassword.docx", saveOptions);
```

When saving a document to Odt format, use the <a href="https://reference.aspose.com/words/net/aspose.words.saving/odtsaveoptions/password/" target="_blank" rel="nofollow noopener noreferrer">Password</a> property of the <a href="https://reference.aspose.com/words/net/aspose.words.saving/odtsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">OdtSaveOptions</a> class.

The following code example shows how to load and save OpenDocument encrypted with a password:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Encrypted.docx", new LoadOptions("docPassword"));

doc.Save(ArtifactsDir + "WorkingWithLoadOptions.LoadSaveEncryptedDocument.odt", new OdtSaveOptions("newPassword"));
```

Not all formats support encryption and the use of **Password** property.

## Show Document Saving Progress Notifications {#show-document-saving-progress-notifications}

Aspose.Words provides the ability to use the <a href="https://reference.aspose.com/words/net/aspose.words.saving/saveoptions/progresscallback/" target="_blank" rel="nofollow noopener noreferrer">ProgressCallback</a> property to get notifications about the progress of document saving.

It is now available when saving to DOCX, FlatOpc, DOCM, DOTM, DOTX, HTML, MHTML, EPUB, XamlFlow, XamlFlowPack, or TXT formats.

## Update the Document Creation Time {#update-the-document-creation-time}

Aspose.Words provides an ability to use the <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/createdtime/" target="_blank" rel="nofollow noopener noreferrer">CreatedTime</a> property to get or set the document creation date in UTC. You can also update this value before saving using the <a href="https://reference.aspose.com/words/net/aspose.words.saving/saveoptions/updatecreatedtimeproperty/" target="_blank" rel="nofollow noopener noreferrer">UpdateCreatedTimeProperty</a> option.

The following code example shows how to update the document creation time:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Rendering.docx");

PdfSaveOptions saveOptions = new PdfSaveOptions { UpdateLastPrintedProperty = true };

doc.Save(ArtifactsDir + "WorkingWithPdfSaveOptions.UpdateLastPrinted.pdf", saveOptions);
```

## Update Last Saved Property {#update-last-saved-property}

Aspose.Words provides an ability to use the <a href="https://reference.aspose.com/words/net/aspose.words.saving/saveoptions/updatelastsavedtimeproperty/" target="_blank" rel="nofollow noopener noreferrer">UpdateLastSavedTimeProperty</a> property to get or set a value determining whether the <a href="https://reference.aspose.com/words/net/aspose.words.properties/builtindocumentproperties/lastsavedtime/" target="_blank" rel="nofollow noopener noreferrer">LastSavedTime</a> property is updated before saving.

The following code example shows how to set this property and save the document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Document.docx");

OoxmlSaveOptions saveOptions = new OoxmlSaveOptions { UpdateLastSavedTimeProperty = true };

doc.Save(ArtifactsDir + "WorkingWithOoxmlSaveOptions.UpdateLastSavedTime.docx", saveOptions);
```

## Control External Resources When Saving a Document into HTML or SVG {#control-external-resources-when-saving-a-document-into-html-or-svg}

To convert HTML or SVG into PDF, simply invoke the <a href="https://reference.aspose.com/words/net/aspose.words/document/save/#save/" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and specify a file name with the ".PDF" extension. If you want to load images, CSS, etc. from external sources, you can use <a href="https://reference.aspose.com/words/net/aspose.words.saving/iresourcesavingcallback/" target="_blank" rel="nofollow noopener noreferrer">IResourceSavingCallback</a>.

## Save Black and White Image with One Bit Per Pixel Format {#save-black-and-white-image-with-one-bit-per-pixel-format}

To control image saving options, the **ImageSaveOptions** class is used. For example, you can use the <a href="https://reference.aspose.com/words/net/aspose.words.saving/imagesaveoptions/pixelformat/" target="_blank" rel="nofollow noopener noreferrer">PixelFormat</a> property to set the pixel format for the generated images. Please note that the pixel format of the output image may differ from the set value because of the work of GDI+.

The following code example shows how to save a black and white image with one bit per pixel format:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Rendering.docx");

ImageSaveOptions saveOptions = new ImageSaveOptions(SaveFormat.Png)
{
    PageSet = new PageSet(1),
    ImageColorMode = ImageColorMode.BlackAndWhite,
    PixelFormat = ImagePixelFormat.Format1bppIndexed
};

doc.Save(ArtifactsDir + "WorkingWithImageSaveOptions.Format1BppIndexed.Png", saveOptions);
```

## FAQ {#faq}

1. **Q:** How can I encrypt a document with a password when saving it?\
   **A:** Use the password option of the specific `SaveOptions` class for the target format (e.g., `PdfSaveOptions.EncryptionDetails` for PDF, `DocSaveOptions.Password` or `OoxmlSaveOptions.Password` for Word formats). Create the options object, set the password, and pass it to `Document.Save`. Example:

   ```csharp
   Document doc = new Document("input.docx");
   PdfSaveOptions options = new PdfSaveOptions();
   options.EncryptionDetails = new PdfEncryptionDetails("MySecret", string.Empty);
   doc.Save("output.pdf", options);
   ```

2. **Q:** How do I receive progress notifications while a large document is being saved?\
   **A:** Implement the `IDocumentSavingCallback` interface and assign it to the `ProgressCallback` property of the save options. Its `Notify` method receives `DocumentSavingArgs`, whose `EstimatedProgress` property gives the percentage completed. Progress is reported when saving to DOCX, FlatOpc, DOCM, DOTM, DOTX, DOC, DOT, HTML, MHTML, EPUB, XamlFlow, and XamlFlowPack; it is not reported for other formats such as PDF. Example:

   ```csharp
   Document doc = new Document("large.docx");
   OoxmlSaveOptions options = new OoxmlSaveOptions();
   options.ProgressCallback = new SavingProgressPrinter();
   doc.Save("large-copy.docx", options);

   class SavingProgressPrinter : IDocumentSavingCallback
   {
       public void Notify(DocumentSavingArgs args)
       {
           Console.WriteLine($"Saving progress: {args.EstimatedProgress:F0}%");
       }
   }
   ```

3. **Q:** How can I set the PDF compliance level (e.g., PDF/A‑1b) when saving to PDF?\
   **A:** Use the `Compliance` property of `PdfSaveOptions`. Choose a value from the `PdfCompliance` enumeration such as `PdfCompliance.PdfA1b`. Example:

   ```csharp
   Document doc = new Document("report.docx");
   PdfSaveOptions options = new PdfSaveOptions();
   options.Compliance = PdfCompliance.PdfA1b;
   doc.Save("report.pdf", options);
   ```

4. **Q:** How do I control the pixel format of images generated when saving a document as an image?\
   **A:** Set the `PixelFormat` property of `ImageSaveOptions` to the desired `ImagePixelFormat` value (e.g., `ImagePixelFormat.Format1bppIndexed` for black‑and‑white). Example:

   ```csharp
   Document doc = new Document("diagram.docx");
   ImageSaveOptions options = new ImageSaveOptions(SaveFormat.Png);
   options.PixelFormat = ImagePixelFormat.Format1bppIndexed;
   doc.Save("diagram.png", options);
   ```

## Purpose Summary

This page describes the LINQ Reporting Engine and its core concepts.

LINQ Reporting Engine is a part of the <a href="https://products.aspose.com/words/net/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words API</a> that enables you to build reports using an extended set of reporting features. The engine enables you to reference business objects of your application in report templates directly, which agrees well with <a href="https://en.wikipedia.org/wiki/Domain-driven_design" target="_blank" rel="nofollow noopener noreferrer">Domain-Driven Design</a> widely used in modern software development. Moreover, the engine uses a subset of C# language in its template syntax. These features enable you as a developer to compose report templates in a familiar and intuitive way.

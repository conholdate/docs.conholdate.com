## Purpose Summary

This page describes how to locate field properties in a document programmatically.

A field that is inserted using <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a>.<a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/insertfield/" target="_blank" rel="nofollow noopener noreferrer">InsertField</a> returns a <a href="https://reference.aspose.com/words/net/aspose.words.fields/field/" target="_blank" rel="nofollow noopener noreferrer">Field</a> object. This is a facade class that provides useful methods to quickly find some properties of a field.

The following code example shows how to find the field code and field result:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document(MyDir + "Hyperlinks.docx");

foreach (Field field in doc.Range.Fields)
{
    string fieldCode = field.GetFieldCode();
    string fieldResult = field.Result;
}
```

Note if you are only looking for the names of merge fields in a document, then you can instead use the built-in <a href="https://reference.aspose.com/words/net/aspose.words.mailmerging/mailmerge/getfieldnames/" target="_blank" rel="nofollow noopener noreferrer">GetFieldNames</a> method.

The following code example shows how to get names of all merge fields in a document:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document doc = new Document();

string[] fieldNames = doc.MailMerge.GetFieldNames();
```

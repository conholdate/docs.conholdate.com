## Purpose Summary {#purpose-summary}

This page explains which features Aspose.Words supports on document save.
:::

Aspose.Words allows users to work with documents in various formats and provides a wide range of features for this. For example, users can create a document from scratch or load it, make some changes, and then save those changes in the output file in any [supported export format](/net/words/supported-document-formats/). While saving the document in the selected format, the user can apply various save options.

:::info
It is important to know that many save options are common to all supported formats, and only some of the options are format-specific, such as PDF, DOCX, HTML, and others.
:::

For a complete list of functions, see the API reference:

- <a href="https://reference.aspose.com/words/net/aspose.words.saving/" target="_blank" rel="nofollow noopener noreferrer">save options for all formats</a>
- <a href="https://reference.aspose.com/words/net/aspose.words.saving/fixedpagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">fixed page save options</a> for <a href="https://docs.aspose.com/words/net/converting-to-fixed-page-format/" target="_blank" rel="nofollow noopener noreferrer">fixed-page formats</a>: PDF, XPS, images and others
- <a href="https://reference.aspose.com/words/net/aspose.words.saving/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PDF save options</a> for PDF format

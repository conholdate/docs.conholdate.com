## JPEG Merger .NET API

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> allows developers to combine multiple image documents in the preferred order and save them as a single JPEG file.

## About JPEG File Format

JPEG is a type of image format that is saved using the method of lossy compression. The output image, as result of compression, is a trade-off between storage size and image quality. Users can adjust the compression level to achieve the desired quality level while at the same time reduce the storage size. Image quality is negligibly affected if 10:1 compression is applied to the image. The higher the compression value, the higher the degradation in image quality.

### How to merge images to JPEG file

The following example demonstrates how to merge images to JPEG file with several lines of C# code:

* Create an instance of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class and pass source image file path as a constructor parameter. You may specify absolute or relative file path as per your requirements.
* Create an instance of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinoptions" target="_blank" rel="nofollow noopener noreferrer">ImageJoinOptions</a> class and pass enum value of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinmode" target="_blank" rel="nofollow noopener noreferrer">ImageJoinMode</a> as a constructor parameter.
* Add another image file to merge with <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> method and pass instance of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinoptions" target="_blank" rel="nofollow noopener noreferrer">ImageJoinOptions</a> class as a method parameter. Repeat this step for other image documents you want to merge.
* Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and specify the filename for the merged image file as parameter.

```csharp
// Load the source image file
using (Merger merger = new Merger(@"c:\sample1.jpeg"))
{
    // Define image join options with horizontal join mode
    ImageJoinOptions joinOptions = new ImageJoinOptions(ImageJoinMode.Horizontal);
    // Add another image file to merge
    merger.Join(@"c:\sample2.png", joinOptions);
    // Define image join options with vertical join mode
    joinOptions = new ImageJoinOptions(ImageJoinMode.Vertical);
    // Add next image file to merge
    merger.Join(@"c:\sample3.bmp", joinOptions);
    // Merge image files and save result
    merger.Save(@"c:\merged.jpeg");
}
```

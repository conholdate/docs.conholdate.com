## How to merge audio files in C\#

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> facilitates developers to combine multiple audio files according to their preferred sequence and save them as a single audio file. This eliminates the need for manual operations with desktop software, saving you valuable time. Currently, GroupDocs.Merger allows combining audio files having the same extensions. For example, WAV file with other WAV files, or MP3 file with other MP3 files.

Here's a C# code snippet demonstrating how to concatenate audio files:

* Create an instance of the <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class and pass the source audio file path as a constructor parameter. You may specify absolute or relative file paths as per your requirements.
* Add another audio file to merge with the <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> method. Audio file should be of the same format as the initial one. Repeat this step for other audio files you want to merge.
* Call the <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and specify the filename for the resulting audio file as a parameter.

```csharp
// Load the source WAV file
using (var merger = new GroupDocs.Merger.Merger(@"c:\sample1.wav"))
{
    // Add another WAV file to merge
    merger.Join(@"c:\sample2.wav");
    // Merge audio files and save result
    merger.Save(@"c:\merged.wav");
}
```

HTML (Hyper Text Markup Language) is the extension for web pages created for display in browsers. Known as language of the web, HTML has evolved with requirements of new information requirements to be displayed as part of web pages. The latest variant is known as HTML 5 that gives a lot of flexibility for working with the language. HTML pages are either received from server, where these are hosted, or can be loaded from local system as well.

## How to merge HTML files programmatically

When you need to merge multiple HTML pages into a single file you can do this  with help of <a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> and all content like text, images, tables, graphs, forms etc. will be preserved.

The following in an example of how to merge HTML files programmatically:

* Create an instance of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class and pass source HTML file path as a constructor parameter. You may specify absolute or relative file path as per your requirements.
* Add another HTML file to merge with <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> method. Repeat this step for other HTML documents you want to merge.
* Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and specify the filename for the merged HTML file as parameter.

```csharp
// Load the source HTML file
using (Merger merger = new Merger(@"c:\sample1.html"))
{
    // Add another HTML file to merge
    merger.Join(@"c:\sample2.html");
    // Merge HTML files and save result
    merger.Save(@"c:\merged.html");
}
```

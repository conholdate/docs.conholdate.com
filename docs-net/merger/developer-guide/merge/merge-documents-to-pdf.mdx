## Introduction

Consider the functionality for merging files of various formats such as <a href="https://docs.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a> / <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a>, <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> and <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a> into a PDF document. Let's see, why do we need to combine these files into a PDF document? This article discusses the PDF format, but those ones will be more in the near future. But turn back to the PDF format. It is a standard format that allows you to display information the same on any device with any platform. It is comfortable for transferring info via the Internet or to a printer. That is why this format is chosen for the current task of combining files of various formats.

## Merge documents to PDF / XPS

Multiple files (even different types of files such as <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a>, <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a>) can be combined into a single PDF / XPS file by using **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** API. You can also use this <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> method to combine multiple PDF / XPS files. This cross-format merge to PDF / XPS could be useful for the cases when there is no ability to merge only PDF / XPS files. For now, GroupDocs.Merger API allows to <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> other file types without password with the PDF / XPS document loaded into <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object.

The following example demonstrates how to merge PDF file with <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> and <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a> file types:

```csharp
using (Merger merger = new Merger(@"c:\document1.pdf"))
{
    merger.Join(@"c:\document2.doc");
    merger.Join(@"c:\document3.ppt");
    merger.Join(@"c:\document4.xls");
    merger.Save(@"c:\merged.pdf");
}
```

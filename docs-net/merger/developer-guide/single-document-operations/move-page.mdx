**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** provides a move page feature which allows you to manipulate page ordering by moving any page(s) to new position within a document.   
This can be done by following the steps below:

*   Initialise <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/moveoptions" target="_blank" rel="nofollow noopener noreferrer">MoveOptions</a> class and specify current and new page numbers;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/movepage" target="_blank" rel="nofollow noopener noreferrer">MovePage</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/moveoptions" target="_blank" rel="nofollow noopener noreferrer">MoveOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and pass desired file path to save resultant document.

The following code sample demonstrates on how to move page to a new position:

```csharp
int pageNumber = 6;
int newPageNumber = 1;
MoveOptions moveOptions = new MoveOptions(pageNumber, newPageNumber);

using (Merger merger = new Merger(@"c:\sample.xlsx"))
{
    merger.MovePage(moveOptions);
    merger.Save(@"c:\result.xlsx");
}
```

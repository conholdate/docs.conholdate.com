**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to set **Portrait** or **Landscape** page orientation for specific or all document pages.

Here are the steps to change page orientation:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/orientationoptions" target="_blank" rel="nofollow noopener noreferrer">OrientationOptions</a> class with desired orientation mode and page numbers;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/changeorientation" target="_blank" rel="nofollow noopener noreferrer">ChangeOrientation</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/orientationoptions" target="_blank" rel="nofollow noopener noreferrer">OrientationOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to change page orientation:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\result.docx";

OrientationOptions orientationOptions = new OrientationOptions(OrientationMode.Landscape, new int[] { 3, 4 });

using (Merger merger = new Merger(filePath))
{
    merger.ChangeOrientation(orientationOptions);
    merger.Save(filePathOut);
}
```

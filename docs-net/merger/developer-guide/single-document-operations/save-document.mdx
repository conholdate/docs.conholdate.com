**GroupDocs.Merger** allows to save PDF resultant document by specifying accesibility settings <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings" target="_blank" rel="nofollow noopener noreferrer">PdfAccesibilitySettings</a>.

There is an ability to set parameter <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings/enableautotagging" target="_blank" rel="nofollow noopener noreferrer">EnableAutoTagging</a> in order to enable auto tagging mode.

The steps to save document with auto tagging mode are the following:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> class and set parameter <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings/enableautotagging" target="_blank" rel="nofollow noopener noreferrer">EnableAutoTagging</a> as True;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> object to save a resultant document.

## Save the PDF document with auto tagging mode

The following code sample demonstrates how to save PDF document with auto tagging mode:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\result.pdf";

PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.AccesibilitySettings.EnableAutoTagging = true;
           
using (Merger merger = new Merger(filePath))
{
     merger.Save(filePathOut, pdfSaveOptions);
}  
```

## Save any document by default

The following code sample demonstrates how to save any document by default:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\result.docx";

using (Merger merger = new Merger(filePath))
{
     merger.Save(filePathOut);
}  
```

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** provides an ability to remove single page or a collection of specific page numbers from the source document.   
Here are the steps to remove document page(s):

*   Initialise <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/removeoptions" target="_blank" rel="nofollow noopener noreferrer">RemoveOptions</a> class with page numbers to remove;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/removepages" target="_blank" rel="nofollow noopener noreferrer">RemovePages</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/removeoptions" target="_blank" rel="nofollow noopener noreferrer">RemoveOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method and pass desired file path to save resultant document.

The following code sample demonstrates how to remove document pages:

```csharp
string filePath = @"c:\sample.one";
string filePathOut = @"c:\output\result.one";

RemoveOptions removeOptions = new RemoveOptions(new int[] { 3, 5 });

using (Merger merger = new Merger(filePath))
{
    merger.RemovePages(removeOptions);
    merger.Save(filePathOut);
}

```

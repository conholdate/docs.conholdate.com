**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to swap two pages positions within the source document. The result is a new document where two pages have their positions exchanged.

Here are the steps to swap document pages:
*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/swapoptions" target="_blank" rel="nofollow noopener noreferrer">SwapOptions</a> class with page numbers to swap;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/swappages" target="_blank" rel="nofollow noopener noreferrer">SwapPages</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/swapoptions" target="_blank" rel="nofollow noopener noreferrer">SwapOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to split document:

```csharp
string filePath = @"c:\sample.pptx";
string filePathOut = @"c:\output\result.pptx";

int pageNumber1 = 3;
int pageNumber2 = 6;
SwapOptions swapOptions = new SwapOptions(pageNumber2, pageNumber1);

using (Merger merger = new Merger(filePath))
{
    merger.SwapPages(swapOptions);
    merger.Save(filePathOut);
}
```

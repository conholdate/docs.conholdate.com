**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to change page rotation angle by setting it to 90, 180 or 270 degrees for specific or all document pages.  
Here are the steps to change page rotation:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/rotateoptions" target="_blank" rel="nofollow noopener noreferrer">RotateOptions</a> class with desired rotation angle and page numbers;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/rotatepages" target="_blank" rel="nofollow noopener noreferrer">RotatePages</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/rotateoptions" target="_blank" rel="nofollow noopener noreferrer">RotateOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to change page rotation:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

RotateOptions rotateOptions = new RotateOptions(RotateMode.Rotate180, new int[] { 2, 3, 6 });

using (Merger merger = new Merger(filePath))
{
    merger.RotatePages(rotateOptions);
    merger.Save(filePathOut);
}
```

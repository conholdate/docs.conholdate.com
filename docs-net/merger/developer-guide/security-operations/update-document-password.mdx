**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to update password from password-protected document. The resultant document will have new password.  
Here are the steps to update document password:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class specifying current password;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object to it;
*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/updatepasswordoptions" target="_blank" rel="nofollow noopener noreferrer">UpdatePasswordOptions</a> class specifying new document password;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/updatepassword" target="_blank" rel="nofollow noopener noreferrer">UpdatePassword</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/updatepasswordoptions" target="_blank" rel="nofollow noopener noreferrer">UpdatePasswordOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to update document password:

```csharp
string filePath = @"c:\sample.xlsx";
string filePathOut = @"c:\output\result.xlsx";

ILoadOptions loadOptions = new LoadOptions("SAMPLE_PASSWORD");
IUpdatePasswordOptions updateOptions = new UpdatePasswordOptions("NEW_SAMPLE_PASSWORD");

using (Merger merger = new Merger(filePath, loadOptions))
{
    merger.UpdatePassword(updateOptions);
    merger.Save(filePathOut);
}
```

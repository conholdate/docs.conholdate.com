You can easy protect PDF document with permissions, using the "GroupDocs.Merger for .NET" product.

The following example demonstrates how to secure PDF document with permissions in C# code:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityOptions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityOptions</a> class with new document password and set Permissions property with enum value of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityPermissions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityPermissions</a>;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/addpassword" target="_blank" rel="nofollow noopener noreferrer">AddPassword</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityOptions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

PdfSecurityOptions pdfSecurityOptions = new PdfSecurityOptions("SAMPLE_PASSWORD");
pdfSecurityOptions.Permissions = PdfSecurityPermissions.DenyModification;

using (Merger merger = new Merger(filePath))
{
    merger.AddPassword(pdfSecurityOptions);
    merger.Save(filePathOut);
}
```

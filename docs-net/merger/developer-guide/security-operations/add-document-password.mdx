**GroupDocs.Merger** allows to add document password. Here are the steps to add document password:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/addpasswordoptions" target="_blank" rel="nofollow noopener noreferrer">AddPasswordOptions</a> class with new document password;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/addpassword" target="_blank" rel="nofollow noopener noreferrer">AddPassword</a> method and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/addpasswordoptions" target="_blank" rel="nofollow noopener noreferrer">AddPasswordOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to add document password.

```csharp
string filePath = @"c:\sample.pptx";
string filePathOut = @"c:\output\result.pptx";

AddPasswordOptions addOptions = new AddPasswordOptions("SAMPLE_PASSWORD");

using (Merger merger = new Merger(filePath))
{
    merger.AddPassword(addOptions);
    merger.Save(filePathOut);
}
```

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to remove password from password-protected document. Here are the steps to remove document password:

*   Initialize <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class specifying current password;
*   Instantiate <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> object with source document path or stream and pass <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object to it;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/removepassword" target="_blank" rel="nofollow noopener noreferrer">RemovePassword</a> method;
*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> method specifying file path to save resultant document.

The following code sample demonstrates how to remove document password:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\result.docx";

LoadOptions loadOptions = new LoadOptions("SAMPLE_PASSWORD");

using (Merger merger = new Merger(filePath, loadOptions))
{
    merger.RemovePassword();
    merger.Save(filePathOut);
}
```

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to get the list of all [supported file types](/net/merger/getting-started/supported-document-formats/) by following the below steps:

*   Call <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class;
*   Enumerate through the collection of <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> objects.

The following code sample demonstrates how to get supported file formats list.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

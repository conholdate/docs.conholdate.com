There might be the case when source or target document is not physically located on the disk. Instead, you have the document in the form of a stream. In this case, to avoid the overhead of saving stream as a file on disk, **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** provides a way to work with document streams directly.   
The following are the steps to be followed:
*   Obtain document stream; 
*   Pass opened source document stream to <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class constructor.

Following code snippet describes this case.

```csharp
using (Stream stream = File.OpenRead(@"c:\sample.docx"))
{
	using (Merger merger = new Merger(stream))
    {
    	Console.WriteLine($"Document loaded from stream successfully.");
	}
}
```

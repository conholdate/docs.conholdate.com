When the source document is located on the local disk **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows you to load it via <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> class constructor specifying absolute or relative path to it.  
The following code snippet shows how to load documents from local disk.

```csharp
string filePath = @"c:\sample.docx";
using (Merger merger = new Merger(filePath))
{
	Console.WriteLine($"Document loaded from local disk successfully.");
}
```

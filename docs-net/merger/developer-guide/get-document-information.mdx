**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** allows to get document information which includes:
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/documentinfo/type" target="_blank" rel="nofollow noopener noreferrer">Type</a> - indicates document file type, extension, format name etc.
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/documentinfo/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> - indicates count of pages for text processing document, worksheets in a spreadsheet or slides in a presentation;
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/ipageinfo" target="_blank" rel="nofollow noopener noreferrer">Page info</a> - describes properties for each document page. For example, height and width in pixels when document page is previewed as image, page number, visibility etc.

The following code sample demonstrates how to get document information.
```csharp
using (Merger merger = new Merger(@"c:\sample.vsdx"))
{
    IDocumentInfo info = merger.GetDocumentInfo();
    Console.WriteLine(info);
}
```

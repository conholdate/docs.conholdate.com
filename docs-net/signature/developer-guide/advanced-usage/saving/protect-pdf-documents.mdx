### How to secure PDF document with permissions

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving signed documents with permission settings and password protection for access and modification. This capability is achieved using the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissionspassword/" target="_blank" rel="nofollow noopener noreferrer">PermissionsPassword</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> properties of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> class, which should be passed to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method.

You can secure a PDF document by setting the following parameters:
* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> object and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissionspassword" target="_blank" rel="nofollow noopener noreferrer">PermissionsPassword</a> property(optional). Configure the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/property" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> to control user actions (e.g., deny printing or modification).  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signature options and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> object to it.

Following example demonstrates how to save signed document with permissions.

```csharp
// Using the Signature class to create a signature for the specified PDF document
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions textSignOptions = new TextSignOptions("JohnSmith")
    {
        Left = 0,
        Top = 100,
        Width = 100,
        Height = 100,
        AllPages = true,
        ForeColor = Color.Black
    };

    // Create a new PdfSaveOptions object to configure the PDF save settings
    PdfSaveOptions saveOptions = new PdfSaveOptions();
    saveOptions.OverwriteExistingFiles = false;
    // Set permissions to deny printing and modification
    saveOptions.Permissions = Permissions.DenyPrinting | Permissions.DenyModification;
    // Set a password for modifying permissions(optional)
    saveOptions.PermissionsPassword = "0987654321";
    // Sign the document and save the result to a new file
    signature.Sign("result.pdf", textSignOptions, saveOptions);
}
```

### How to load PDF document with permissions

The <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports loading documents with specific permissions that are preserved after signing. This capability is managed through the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class, where the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> property is set when loading the document. These permissions remain enforced in the signed document, ensuring consistent restrictions from loading to final save output when passed to the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method.

To load a PDF document with permissions and ensure those permissions are preserved throughout the signing process, follow these steps:
* Create a new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> , configuring the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> property to set restrictions (e.g., deny printing, modification, or data extraction).
* Use this <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> instance to initialize the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class with the document path or stream.
* Instantiate the required signature options (e.g.,  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> ) to set signature position and appearance.
* Call the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class, passing the signature options. The document will retain the permissions specified in the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> , ensuring any restrictions applied during loading are preserved in the signed document.

Following example demonstrates how to load PDF document with permissions. 

```csharp
// Set up load options with specific permissions, denying all actions (printing, modification, extraction)
LoadOptions loadOptions = new LoadOptions()
{
    Permissions = Permissions.DenyAll
};

// Using the Signature class to create a signature for the specified PDF document
using (Signature signature = new Signature("sample.pdf", loadOptions))
{
    TextSignOptions textSignOptions = new TextSignOptions("JohnSmith")
    {
        Left = 0,
        Top = 100,
        Width = 100,
        Height = 100
    };
    
    signature.Sign("result.pdf", textSignOptions);
}
```

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving of Image signed documents with various image format types and extended options.

Following classes are inherited from base class <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> and allows to specify additional output image format settings.

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/bmpsaveoptions" target="_blank" rel="nofollow noopener noreferrer">BmpSaveOptions</a> class allows to save signed image document to **BMP** image format and setup additional options ( like compression, resolutions, bits per pixel etc);
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/gifsaveoptions" target="_blank" rel="nofollow noopener noreferrer">GifSaveOptions</a> class allows to save signed image document to **GIF**image format and setup additional options ( like compression, resolutions etc);
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/jpegsaveoptions" target="_blank" rel="nofollow noopener noreferrer">JpegSaveOptions</a> class allows to save signed image document to **JPEG** image format and setup additional options ( like compression, resolutions, quality etc);
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pngsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PngSaveOptions</a> class allows to save signed image document to **PNG** image format and setup additional options ( like bit depth, color type, compression, filters etc);
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/tiffsaveoptions" target="_blank" rel="nofollow noopener noreferrer">TiffSaveOptions</a> class allows to save signed image document to **TIFF** image format and setup additional options

Here are the steps to save signed Image document to special image output type with additional settings with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the one of required class of image format save options <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/bmpsaveoptions" target="_blank" rel="nofollow noopener noreferrer">BmpSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/gifsaveoptions" target="_blank" rel="nofollow noopener noreferrer">GifSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/jpegsaveoptions" target="_blank" rel="nofollow noopener noreferrer">JpegSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pngsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PngSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/tiffsaveoptions" target="_blank" rel="nofollow noopener noreferrer">TiffSaveOptions</a> object according to your requirements and specify its properties.  

* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object to it.

## Save signed image as BMP

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create Bmp save options with advanced settings
    saveOptions = new BmpSaveOptions()
    {
        AddMissingExtension = true,
        Compression = BitmapCompression.Rgb,
        HorizontalResolution = 7,
        VerticalResolution = 7,
        BitsPerPixel = 16,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("signedSample", signOptions, saveOptions);
}
```

## Save signed image as GIF

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create Gif save options with advanced settings
    saveOptions = new GifSaveOptions()
    {
        AddMissingExtension = true,
        BackgroundColorIndex = 2,
        ColorResolution = 7,
        DoPaletteCorrection = true,
        HasTrailer = true,
        Interlaced = false,
        IsPaletteSorted = true,
        PixelAspectRatio = 24
    };
    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

## Save signed image as JPEG

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create Jpeg save options with advanced settings
    saveOptions = new JpegSaveOptions()
    {
        AddMissingExtension = true,
        BitsPerChannel = 8,
        ColorType = JpegCompressionColorMode.Rgb,
        Comment = "signed jpeg file",
        CompressionType = JpegCompressionMode.Lossless,
        Quality = 100,
        SampleRoundingMode = JpegRoundingMode.Extrapolate
    };
    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

## Save signed image as PNG

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100

    saveOptions = new PngSaveOptions()
    {
        AddMissingExtension = true,
        BitDepth = 8,
        ColorType = PngColorType.Grayscale,
        CompressionLevel = 9,
        FilterType = PngFilterType.Adaptive,
        Progressive = true

    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

## Save signed image as TIFF

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create tiff save options with advanced settings
    saveOptions = new TiffSaveOptions()
    {
        AddMissingExtension = true,
        ExpectedTiffFormat = TiffFormat.TiffNoCompressionBw
    };
    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

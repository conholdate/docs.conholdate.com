<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving signed document with password protection. This ability is supported over <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> property of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class that should be passed to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method.

Here are the steps to protect signed document with password with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> property with required password string.  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> object to it.

Following example demonstrates how to save signed document with password.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QrCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    SaveOptions saveOptions = new SaveOptions()
    {
        Password = "1234567890",
        UseOriginalPassword = false
    };
    // sign document to file
    signature.Sign("SignedProtected.pdf", signOptions, saveOptions);
}
```

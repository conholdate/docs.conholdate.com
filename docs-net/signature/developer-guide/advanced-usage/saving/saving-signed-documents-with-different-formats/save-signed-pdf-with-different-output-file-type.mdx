<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving of Pdf signed documents to different formats. Each of document type has list of compatible saving type. These values are listed in enum <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PdfSaveFileFormat</a>.

Here are the steps to save signed Pdf document to different output type with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>  class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> object according to your requirements and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> as one of predefined values from <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PdfSaveFileFormat</a>.  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> object to it.

Following example demonstrates how to save signed PDF document with different output type

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR,
        Left = 100,
        Top = 100
    };
    PdfSaveOptions pdfSaveOptions = new PdfSaveOptions()
    {
        FileFormat = PdfSaveFileFormat.DocX,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedPdf.docx", signOptions, pdfSaveOptions);
}
```

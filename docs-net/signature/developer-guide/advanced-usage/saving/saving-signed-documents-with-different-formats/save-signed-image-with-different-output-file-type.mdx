<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving of Image signed documents with different formats. Each of document type has list of compatible saving type. These values are listed in enum <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesavefileformat" target="_blank" rel="nofollow noopener noreferrer">ImageSaveFileFormat</a>.

Here are the steps to save signed Image document to different output type with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> object according to your requirements and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> as one of predefined values from <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesavefileformat" target="_blank" rel="nofollow noopener noreferrer">ImageSaveFileFormat</a>.  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> to it.

Following example demonstrates how to save signed Image document with different output type

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    ImageSaveOptions saveOptions = new ImageSaveOptions()
    {
        FileFormat = ImageSaveFileFormat.Svg,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("signed.svg", signOptions, saveOptions);
}
```

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving of Spreadsheet signed documents with different output file types. Each document type has list of compatible saving type. These values are listed in enum <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetsavefileformat" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveFileFormat.</a>

Here are the steps to save signed Spreadsheet document to different output type with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveOptions</a> object according to your requirements and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> as one of predefined values from <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetsavefileformat" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveFileFormat</a>.  

* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveOptions</a> object to it.

Following example demonstrates how to save signed Spreadsheet document with different output type

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    SpreadsheetSaveOptions saveOptions = new SpreadsheetSaveOptions()
    {
        FileFormat = SpreadsheetSaveFileFormat.Pdf,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedXlsx.pdf", signOptions, saveOptions);
}
```

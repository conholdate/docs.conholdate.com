<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports saving of Presentation signed documents with different formats. Each of document type has list of compatible saving type. These values are listed in enum <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveFileFormat</a>.

Here are the steps to save signed Presentation document to different output type with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>  class and pass source document path or stream as a constructor parameter.
* Instantiate required signature options.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> object according to your requirements and specify <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> as one of predefined values from <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveFileFormat</a>.  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signatureoptions and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> [](https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions) object to it.

Following example demonstrates how to save signed Presentation document with different output type

```csharp
using (Signature signature = new Signature("sample.ppsx"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    PresentationSaveOptions saveOptions = new PresentationSaveOptions()
    {
        FileFormat = PresentationSaveFileFormat.Tiff,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedPPsx", signOptions, saveOptions);
}
```

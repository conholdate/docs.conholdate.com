<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides different classes of signatures to manipulate them by changing its properties over <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class. This method returns <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> object to analyze if signatures were successfully processed.

Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method modifies the same document that was passed to constructor of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class. The <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> contains list of successfully updated signatures and ones that failed. The signature could be failed to update due to several reasons:

* if signature object was initialized with constructor by incorrect signature identifier;
* if signature object was not found;
* there was an error occurred while updating signature in the document;
* the signature type is not supported for modification (Digital, Form Field or Metadata signature).

Here are the steps to update multiple signature in the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter;
* Instantiate one or several Search options with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method and pass created list of Search Options to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a> object(s) that should be updated;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method and pass one or several signatures to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> result to check whether signatures were updated or not.

## Update multiple signatures of different types in the document

This example shows how to update signature that was found using <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
// initialize Signature instance
using (Signature signature = new Signature("signed.pptx"))
{
    // define few search options
    BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions();
    QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions();
    // add options to list
    List<SearchOptions> listOptions = new List<SearchOptions>();
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrCodeOptions);
    // search for signatures in document
    SearchResult result = signature.Search(listOptions);
    if (result.Signatures.Count > 0)
    {
        Console.WriteLine("\nTrying to update all signatures...");
        // mark all signatures as actual Signatures
        foreach (BaseSignature baseSignature in result.Signatures)
        {
            baseSignature.IsSignature = true;
        }
        // update all found signatures
        UpdateResult updateResult = signature.Update(result.Signatures);
        if (updateResult.Succeeded.Count == result.Signatures.Count)
        {
            Console.WriteLine("\nAll signatures were successfully updated!");
        }
        else
        {
            Console.WriteLine($"Successfully updated signatures : {updateResult.Succeeded.Count}");
            Console.WriteLine($"Not updated signatures : {updateResult.Failed.Count}");
        }
        Console.WriteLine("\nList of updated signatures:");
        int number = 1;
        foreach (BaseSignature temp in updateResult.Succeeded)
        {
            Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
        }
    }
    else
    {
        Console.WriteLine("No one signature was found.");
    }
}
```

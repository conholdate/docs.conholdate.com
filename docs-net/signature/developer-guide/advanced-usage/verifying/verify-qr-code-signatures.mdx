<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides different properties in <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a> class to specify verification of QR Code signatures.

Here are the steps to verify QR Code signature within the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
*Instantiate the  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a> object according to your requirements and specify verification options  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a> to it.  
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verificationresult" target="_blank" rel="nofollow noopener noreferrer">VerificationResult</a> result if needed.
  
This example shows how to verify QR Code signature in the document. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verificationresult" target="_blank" rel="nofollow noopener noreferrer">VerificationResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    QrCodeVerifyOptions options = new QrCodeVerifyOptions()
    {
        // specify if all pages should be verified
        AllPages = false,
        PagesSetup = new PagesSetup() {  FirstPage = false, LastPage = true, OddPages = false, EvenPages = true },
        // specify text pattern
        Text = "John",
        // specify verification text pattern
        MatchType = TextMatchType.Contains,
        // specify types of QR code to verify
        EncodeType = QrCodeTypes.QR
    };
    // verify document signatures
    VerificationResult result = signature.Verify(options);
    if (result.IsValid)
    {
        Console.WriteLine("\nDocument was verified successfully!");
    }
    else
    {
        Console.WriteLine("\nDocument failed verification process.");
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides overloaded <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method that accepts list of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signaturetype" target="_blank" rel="nofollow noopener noreferrer">SignatureType</a> enumeration values.
Please be aware that this method modifies the same document that was passed to constructor of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.

Here are the steps to delete signature by certain types from the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or its stream as a constructor parameter;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method and pass list of the required <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signaturetype" target="_blank" rel="nofollow noopener noreferrer">SignatureType</a> enumerations to it.

This example shows how to delete various signatures types from the document at once.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // compose the list of signature types to delete
    var signedTypes = new List<SignatureType>
    {
        SignatureType.Text, 
        SignatureType.Image,
        SignatureType.Barcode,
        SignatureType.QrCode,
        SignatureType.Digital
    };
    // deleting QR-Code signatures from the document by signature types
    DeleteResult result = signature.Delete(signedTypes);
    if (result.Succeeded.Count > 0)
    {
        Console.WriteLine("Following signatures were removed:");
        int number = 1;
        foreach (BaseSignature temp in result.Succeeded)
        {
            Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}. Created: {temp.CreatedOn.ToShortDateString()}");
        }
    }
    else
    {
        Helper.WriteError("No one signature was deleted.");
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> supports processing documents that are protected with a password.

The following are the steps to work with password protected documents.

*   Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> object;
*   Set password in <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> property;
*   Create <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object and call any method.

The following code sample shows how to process password protected documents.

```csharp
LoadOptions loadOptions = new LoadOptions()
{
    Password = "1234567890"
};
using (Signature signature = new Signature("sampleProtected.pdf", loadOptions))
{
    QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR,
        Left = 100,
        Top = 100
    };
    // sign document to file
    signature.Sign("SignedSampleProtected", options);
}
```

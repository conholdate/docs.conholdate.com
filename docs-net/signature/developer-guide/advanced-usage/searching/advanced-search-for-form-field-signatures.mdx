<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> class to specify different options to search for Form Field Signatures.

Here are the steps to search for Form Field signatures within the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> object according to your requirements and specify search options
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> to it.

This example shows how to make advanced search for Form Field signatures in the document.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    FormFieldSearchOptions options = new FormFieldSearchOptions()
    {
        Value = "Value1",
        AllPages = true,
        Name = "TestField",
        Type = FormFieldType.Text
    };
    // search for signatures in document
    List<FormFieldSignature> signatures = signature.Search<FormFieldSignature>(options);
    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var formFieldSignature in signatures)
    {
        Console.WriteLine("FormField signature found. Name : {0}. Value: {1}", formFieldSignature.Name, formFieldSignature.Value);
    }
}
```

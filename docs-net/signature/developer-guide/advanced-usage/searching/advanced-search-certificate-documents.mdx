<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/certificatesearchoptions" target="_blank" rel="nofollow noopener noreferrer">CertificateSearchOptions</a> class to specify different options to search text data within the certificate documents. 
Please be aware that the search result will be always as the MetadataSignature.

Here are the steps to search for the values within the certificate document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/certificatesearchoptions" target="_blank" rel="nofollow noopener noreferrer">CertificateSearchOptions</a> object according to your requirements and specify search options.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/certificatesearchoptions" target="_blank" rel="nofollow noopener noreferrer">CertificateSearchOptions</a> to it.

This example shows how to make advanced search for text data within the certificate documents.

```csharp
var loadOptions = new LoadOptions()
{
    Password = "1234567890"
};

using (var signature = new Signature("certificate.pfx", loadOptions))
{
    var options = new CertificateSearchOptions()
    {
        // check the serial number
        Text = "AAD0D15C628A",
        // find exact math
        MatchType = TextMatchType.Contains,
    };

    // search for certificate data
    var result = signature.Search<MetadataSignature>(options);
    if (result.Count>0)
    {
        Console.WriteLine("\nCertificate contains following search results");
        foreach (MetadataSignature temp in result)
        {
            Console.WriteLine($"\t\t-{temp.Name} - {temp.Value}");
        }
    }
    else
    {
        Helper.WriteError("\nCertificate failed search process.");
    }
}
```

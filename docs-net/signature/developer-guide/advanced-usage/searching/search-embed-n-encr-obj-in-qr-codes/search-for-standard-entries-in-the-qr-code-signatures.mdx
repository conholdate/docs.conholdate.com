<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides additional features when searching for<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodesignature" target="_blank" rel="nofollow noopener noreferrer">QrCode Signature</a>  that were previously added to document with embedded standard entry objects. Following standard entries are supported to search for and receive object back from Qr-Code

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a> that keeps in the QR-code standard email information with recipient, subject and body.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/address" target="_blank" rel="nofollow noopener noreferrer">Address</a> with address information.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/vcard" target="_blank" rel="nofollow noopener noreferrer">V-Card</a> entry of visit card 3.0 specification with visited card details. More info could be found <a href="https://en.wikipedia.org/wiki/VCard" target="_blank" rel="nofollow noopener noreferrer">here</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mecard" target="_blank" rel="nofollow noopener noreferrer">Me-Card</a> entry implements similar to V-Card contact details standard. More details could be found <a href="https://en.wikipedia.org/wiki/MeCard_(QR_code" target="_blank" rel="nofollow noopener noreferrer">here</a>).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/epc" target="_blank" rel="nofollow noopener noreferrer">EPC</a> implements standard of the European Payments Council guidelines define the content of a QR code that can be used to initiate <a href="https://en.wikipedia.org/wiki/SEPA_credit_transfer" target="_blank" rel="nofollow noopener noreferrer">SEPA</a> credit transfer. More details could be found <a href="https://en.wikipedia.org/wiki/EPC_QR_code" target="_blank" rel="nofollow noopener noreferrer">here</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/event" target="_blank" rel="nofollow noopener noreferrer">Event</a> entry implements event standard.  
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/wifi" target="_blank" rel="nofollow noopener noreferrer">WiFi</a> entry implements WiFI settings standard.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/sms" target="_blank" rel="nofollow noopener noreferrer">SMS</a> entry implements sms properties.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/cryptocurrencytransfer/" target="_blank" rel="nofollow noopener noreferrer">CryptoCurrencyTransfer</a> entry implements event standard.

## Search for QR-code signatures and extract Email object

This example shows how to search for QR-code signature and obtain <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a> object.  

```csharp
// instantiating the signature object
using (Signature signature = new Signature("signed.pdf"))
{
    // search document
    List<QrCodeSignature> signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (QrCodeSignature qrSignature in signatures)
    {
        Console.WriteLine("Found QRCode signature: {0} with text {1}", qrSignature.EncodeType.TypeName, qrSignature.Text);
        Email email = qrSignature.GetData<Email>();
        if (email != null)
        {
           Console.WriteLine($"Found Email signature: {email.Address} {email.Subject} {email.Body}");
        }
    }
}

```

```csharp
// instantiating the signature object
using (Signature signature = new Signature("signed.pdf"))
{
    // search document
    List<QrCodeSignature> signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
 foreach (QrCodeSignature qrSignature in signatures)
    {
        Console.WriteLine("Found QRCode signature: {0} with text {1}", qrSignature.EncodeType.TypeName, qrSignature.Text);
        VCard vcard = qrSignature.GetData<VCard>();
        if (vcard != null)
        {

        }
    }
}
```

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class contains several events that are being called for different process stages

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signstarted" target="_blank" rel="nofollow noopener noreferrer">SignStarted</a> to handle process start event. This event is occur once <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method is called
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signprogress" target="_blank" rel="nofollow noopener noreferrer">SignProgress</a> to handle progress event. This event occurs each time on signing each signature was completed.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signcompleted" target="_blank" rel="nofollow noopener noreferrer">SignCompleted</a> to handle completion event. This event occurs once <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> process was completed.

Here are the steps to subscribe for signing process with <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Define required handler delegates to process signing events.
* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Subscribe for required events
* Instantiate required <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> object
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signature options in it

## Implement method for SignStarted event

GroupDocs.Signature expects <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/processprogresseventhandler" target="_blank" rel="nofollow noopener noreferrer">ProcessStartEventHandler</a> delegate to subscribe for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signstarted" target="_blank" rel="nofollow noopener noreferrer">SignStarted</a> event

```csharp
private static void OnSignStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Sign process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}
```

private static void OnSignCompleted(Signature signature, ProcessCompleteEventArgs args)

## Subscribing for signing process events

```csharp
private static void OnSignStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Sign process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}

private static void OnSignProgress(Signature signature, ProcessProgressEventArgs args)
{
    Console.WriteLine("Sign progress. Processed {0} signatures. Time spent {1} mlsec", args.ProcessedSignatures, args.Ticks);
}

private static void OnSignCompleted(Signature signature, ProcessCompleteEventArgs args)
{
    Console.WriteLine("Sign process completed at {0} with {1} total signatures. Process took {2} mlsec", args.Completed, args.TotalSignatures, args.Ticks);
}

public static void Run()
{
    using (Signature signature = new Signature("sample.pdf"))
    {
        signature.SignStarted += OnSignStarted;
        signature.SignProgress += OnSignProgress;
        signature.SignCompleted += OnSignCompleted;
        TextSignOptions options = new TextSignOptions("John Smith")
        {
            // set signature position
            Left = 100,
            Top = 100
        };

        // sign document to file
        signature.Sign("SignedSample", options);
    }
}
```

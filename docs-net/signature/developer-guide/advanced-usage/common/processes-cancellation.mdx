<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class supports cancellation for each of document processing (Sign, Verify, Search). The process cancellation happens over setting property <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/processprogresseventargs/cancel" target="_blank" rel="nofollow noopener noreferrer">Cancel</a> of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/processprogresseventargs/" target="_blank" rel="nofollow noopener noreferrer">ProcessProgressEventArgs</a> property in proper event handler.

* for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> process this flag should be set to true in handler of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signprogress" target="_blank" rel="nofollow noopener noreferrer">SignProgress</a> event. This event occurs each time on signing each signature was completed.
* for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> process this flag should be set to true in handler of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verifyprogress" target="_blank" rel="nofollow noopener noreferrer">VerifyProgress</a> event. This event occurs each time on verifying document page.
* for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> process this flag should be set to true in handler of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchprogress" target="_blank" rel="nofollow noopener noreferrer">SearchProgress</a> event. This event occurs each time on searching document page per each options.  

## Cancel signing process

Here are the steps to provide cancellation for signing process with GroupDocs.Signature:

* Define <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signprogress" target="_blank" rel="nofollow noopener noreferrer">SignProgress</a> event handler delegates to conditionally cancel the process.
* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Subscribe for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signprogress" target="_blank" rel="nofollow noopener noreferrer">SignProgress</a> event with proper handler method.
* Instantiate required <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> object.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass signature options in it.

```csharp
private static void OnSignProgress(Signature sender, ProcessProgressEventArgs args)
{
    // check if process takes more than 1 second (1000 milliseconds) processing cancellation
    if(args.Ticks > 1000)
    {
        args.Cancel = true;
        Console.WriteLine("Sign progress was cancelled. Time spent {0} mlsec", args.Ticks);
    }
}
/// <summary>
/// Sign document with text signature applying specific options
/// </summary>
public static void Run()
{
    using (Signature signature = new Signature("sample.docx"))
    {
        signature.SignProgress += OnSignProgress;
        TextSignOptions options = new TextSignOptions("John Smith")
        {
            // ...
        };
        // sign document to file
        signature.Sign("signedSample", options);
    }
}
```

## Cancel search process

Here are the steps to provide cancellation of searching process with GroupDocs.Signature:

* Define <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchprogress" target="_blank" rel="nofollow noopener noreferrer">SearchProgress</a> event handler delegates to conditionally cancel the process.
* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Subscribe for <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchprogress" target="_blank" rel="nofollow noopener noreferrer">SearchProgress</a> event with proper handler method.
* Instantiate required<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> object.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass search options in it.

```csharp
private static void OnSearchProgress(Signature sender, ProcessProgressEventArgs args)
{
    // check if process takes more than 1 second (1000 milliseconds) processing cancellation
    if (args.Ticks > 1000)
    {
        args.Cancel = true;
        Console.WriteLine("Sign progress was cancelled. Time spent {0} mlsec", args.Ticks);
    }
}
public static void Run()
{
    using (Signature signature = new Signature("sampleSigned.pdf"))
    {
        signature.SearchProgress += OnSearchProgress;
        QrCodeSearchOptions options = new QrCodeSearchOptions(QrCodeTypes.QR)
        {
            // ...
        };
        // search for signatures in document
        List<QrCodeSignature> signatures = signature.Search<QrCodeSignature>(options);
        Console.WriteLine("\nSource document contains following signatures.");
        foreach (var QrCodeSignature in signatures)
        {
            Console.WriteLine("QRCode signature found at page {0} with type {1} and text {2}", QrCodeSignature.PageNumber, QrCodeSignature.EncodeType, QrCodeSignature.Text);
        }
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> class to specify different options for Image signature as follow

* signature alignment (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>)
* margins (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>)
* additional extensions and appearances (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/extensions" target="_blank" rel="nofollow noopener noreferrer">Extensions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">Appearance</a>)

Here are the steps to add Image signature into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> object according to your requirements and specify image signature options.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.  

This example shows how to specify different Image signature options. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    ImageSignOptions options = new ImageSignOptions("sample.jpg")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // set signature alignment
        // when VerticalAlignment is set the Top coordinate will be ignored.
        // Use Margin properties Top, Bottom to provide vertical offset
        VerticalAlignment = Domain.VerticalAlignment.Top,
        // when HorizontalAlignment is set the Left coordinate will be ignored.
        // Use Margin properties Left, Right to provide horizontal offset
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Top = 20, Right = 20 },
        // set rotation
        RotationAngle = 45,
        // setup image additional appearance as Brightness and Border
        Appearance = new ImageAppearance()
        {
            Brightness = 0.9f          
        },
        Border = new Border()
        {
            Color = Color.DarkGreen,
            DashStyle = DashStyle.DashLongDashDot,
            Transparency = 0.5,
            Visible = true,
            Weight = 2
        }
    };

    // sign document to file
    SignResult signResult = signature.Sign("sgnedSample.xlsx", options);
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

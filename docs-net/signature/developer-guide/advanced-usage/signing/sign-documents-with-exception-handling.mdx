<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides different error messages due to validation issues, missing required data, files etc. For exception class <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a> is being used.

Here are the steps to handle exceptions from GroupDocs.Signature:

* Compose try-catch block above <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method with catching <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a> type error.  

This example shows how to handle GroupDocs.Signature exceptions.

```csharp
try
{
    using (Signature signature = new Signature("sample.xlsx"))
    {
        DigitalSignOptions options = new DigitalSignOptions()
        {
            CertificateFilePath = Constants.CertificatePfx,
            ImageFilePath = Constants.ImageHandwrite,
            // skip password specification
            //Password = "123456780"
        };
        // sign document to file
        signature.Sign("signed.xlsx", options);
    }
}
catch (GroupDocsSignatureException ex)
{
    Console.WriteLine("GroupDocs Signature Exception: " + ex.Message);
}
catch (Exception ex)
{
    Console.WriteLine("System Exception: " + ex.Message);
}
```

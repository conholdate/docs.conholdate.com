<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> supports signing archive files with formats like ZIP, TAR, 7Z, LZ, GZIP the same way as usual documents. The only difference in the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method will contain for archive files the lists of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/succeeded" target="_blank" rel="nofollow noopener noreferrer">Succeeded</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/failed" target="_blank" rel="nofollow noopener noreferrer">Failed</a> signatures as the list of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/documentresultsignature/" target="_blank" rel="nofollow noopener noreferrer">DocumentResultSignature</a> instances.

Here are the steps to sign the archive files like ZIP, TAR, 7z, LZ, GZIP with GroupDocs.Signature:

* Create a new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass the source archive path or stream of the archive as a constructor parameter.
* Instantiate the single <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> object or list of this class with the required options.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> to it.
* The passed signature options will be applied to the all documents within the archive.
* Analyze response <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> over the properties <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/succeeded" target="_blank" rel="nofollow noopener noreferrer">Succeeded</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/failed" target="_blank" rel="nofollow noopener noreferrer">Failed</a> signatures as the instances of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/documentresultsignature/" target="_blank" rel="nofollow noopener noreferrer">DocumentResultSignature</a>

## Sign archive document

This example shows how to sign archive document with few SignOptions.

```csharp
/// <summary>
/// Support Succeeded and Failed list as result of processing archives
/// </summary>
using (var signature = new Signature("sample.zip"))
{
    // create sign options
    var options = new TextSignOptions("signed!")
    {
        // set signature position
        Left = 100,
        Top = 100
    };
    // sign archive to new zip file
    SignResult result = signature.Sign("output.zip", options);
    // analyze signed documents
    foreach (DocumentResultSignature document in result.Succeeded)
    {
        Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
    }

        foreach (DocumentResultSignature document in result.Failed)
        {
            Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
        }
    }
}
```

## Sign single-file archive documents
LZ and GZIP formats compress individual files into single-file archives, optimizing them for storage and transmission.


:::note
The name of the archive file should match the name of the file contained.
:::


This example shows how to sign GZIP archive document with SignOptions.

```csharp
using (Signature signature = new Signature("sample.pdf.gz"))
{
    // create sign options
    TextSignOptions options = new TextSignOptions("signed!")
    {
        // set signature position
        Left = 100,
        Top = 100
    };
    // sign archive to new zip file
    SignResult result = signature.Sign("output.pdf.gz", options);
    // analyze signed documents
    foreach (DocumentResultSignature document in result.Succeeded)
    {
        Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contains <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> class that implements extra image adjustment setting like

* gray-scale (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a>)
* brightness (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/brightness" target="_blank" rel="nofollow noopener noreferrer">Brightness</a>)
* contrast (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/contrast" target="_blank" rel="nofollow noopener noreferrer">Contrast</a>)
* gamma correction (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/gammacorrection" target="_blank" rel="nofollow noopener noreferrer">GammaCorrection</a>)
* border (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/border" target="_blank" rel="nofollow noopener noreferrer">Border</a>)

Base signature class <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> property <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">Appearance</a> should be set with instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> class to provide additional image adjustment

Here are the steps to setup extra image appearance with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Compose object of<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> object with all required additional options.
* Set <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> property with <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a>  object.  
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.

## Sign document with image appearance

This example shows how to specify extra image appearances. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    ImageSignOptions options = new ImageSignOptions("sample.jpg")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // setup image additional appearance as Brightness and Border
        Appearance = new ImageAppearance()
        {
            Grayscale = true,
            Contrast = 0.2f,
            GammaCorrection = 0.3f,
            Brightness = 0.9f,
            Border = new Border()
            {
                Color = Color.DarkGreen,
                DashStyle = DashStyle.DashLongDashDot,
                Transparency = 0.5,
                Visible = true,
                Weight = 2
            }
        }
    };
    // sign document to file
    signature.Sign("signed.pdf", options);
}
```

## Sign PDF document with Text signature Sticker appearance

This example shows how to add Text signature to Pdf document with sticker look. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signed.docx", options);
}
```

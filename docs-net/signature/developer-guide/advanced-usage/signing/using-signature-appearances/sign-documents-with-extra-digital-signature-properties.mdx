<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contains <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> class that implements extra settings for digital signature of Word Processing and Spreadsheets documents

Base signature options <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> property <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> should be set with instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> class to provide additional digital signature look

Here are the steps to setup extra image appearance with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Compose object of<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> object with all required additional options.
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> property with <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> object and set its properties
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.  

This example shows how to setup extra digital signature look. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docs"))
{
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",

        // image as digital certificate appearance on document pages
        ImageFilePath = imagePath,
        //
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 10, Right = 10 },
        // Setup signature line appearance.
        // This appearance will add Signature Line on the first page.
        // Could be useful for .xlsx files.
        Appearance = new DigitalSignatureAppearance("John Smith", "Title", "jonny@test.com")

    };
    signature.Sign("signed.docx", options);
}


```

## Sign Pdf document with Text signature Sticker appearance

This example shows how to add Text signature to Pdf document with sticker look. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signed.docx", options);
}
```

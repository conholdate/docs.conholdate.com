<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contains classes that implements for Pdf document special signature appearances.

Base signature options <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> contains property <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> that expects instance of the following classes

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextannotationappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextAnnotationAppearance</a> class implements for Pdf documents signature as annotation area. Note that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> property must be set to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Annotation</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextstickerappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextStickerAppearance</a> class implements for Pdf documents signature as small sticker. Note that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> property must be set to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Sticker</a>

Here are the steps to setup special Pdf  document Text signature appearance with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Compose object of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> object with all required additional options.
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.Appearance</a> property with <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextannotationappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextAnnotationAppearance</a> object and set its properties
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.

## Sign Pdf document with Text signature Annotation appearance

This example shows how to add Text signature to Pdf document with annotation look. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Annotation,
        Appearance = new PdfTextAnnotationAppearance()
        {
            Border = new Border()
            {
                Color = Color.Blue,
                DashStyle = DashStyle.Dash,
                Weight = 2,
            },
            BorderEffect = PdfTextAnnotationBorderEffect.Cloudy,
            BorderEffectIntensity = 2,
            HCornerRadius = 10,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title",
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signedAnnotation.pdf", options);
}
```

## Sign Pdf document with Text signature Sticker appearance

This example shows how to add Text signature to Pdf document with sticker look. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature(filePath))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign(outputFilePath, options);
}
```

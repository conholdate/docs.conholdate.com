<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> class to specify different amount of settings for Digital signature

* digital certificate (file on local disk <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatefilepath/" target="_blank" rel="nofollow noopener noreferrer">CertificateFilePath</a> or stream <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatestream/" target="_blank" rel="nofollow noopener noreferrer">CertificateStream</a>) (required)
* password of digital certificate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/password/" target="_blank" rel="nofollow noopener noreferrer">Password</a> (required)
* digital signature details (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/reason/" target="_blank" rel="nofollow noopener noreferrer">Reason</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/contact/" target="_blank" rel="nofollow noopener noreferrer">Contact</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/location/" target="_blank" rel="nofollow noopener noreferrer">Location</a>)
* signature image as digital signature appearance on document page (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/imagefilepath" target="_blank" rel="nofollow noopener noreferrer">ImageFilePath</a> or <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/imagestream" target="_blank" rel="nofollow noopener noreferrer">ImageStream</a>)
* image signature appearance on document page (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">Alignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a> etc.)

Here are the steps to add Digital signature into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> object with required certificate and its password.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.  

This example shows how to add Digital signature to document. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // initialize digital option with certificate file path
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",
        // image as digital certificate appearance on document pages
        ImageFilePath = "sample.jpg",
        //
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() {  Bottom = 10, Right = 10},
    };
    signature.Sign("signed.pdf", options);
}
```

### Add Long-Term Validation (LTV)(Long-Term Validation) information for a signature

What is Long-Term Validation (LTV) for Digital Signatures?

Long-Term Validation (LTV) is a method used to ensure the continued validity of digital signatures over time, even after the signing certificate expires or is revoked. LTV embeds additional information within the signed document, such as the certificate's revocation status, timestamp, and the certificate chain, which allows anyone verifying the signature in the future to determine its authenticity, even if the original certificate is no longer available.

Why is LTV Important?

Digital signatures rely on certificates, which have expiration dates. Once the signing certificate expires or is revoked, the signature may no longer be considered valid. However, many legal, financial, and regulatory scenarios require documents to remain valid for years or decades. LTV solves this problem by embedding validation data directly into the signed document, ensuring that the signature's authenticity can be verified at any point in the future.

Here is an example of how to implement Long-Term Validation (LTV) for a PDF document using GroupDocs.Signature:

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // initialize digital option with certificate file path
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() {Bottom = 10, Right = 10},
        
        // Enable Long-Term Validation (LTV) to ensure signature validity over time
        UseLtv = true
    };
    signature.Sign("signed.pdf", options);
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> class to specify different amount of settings for Digital signature
* Class <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/digitalvba/" target="_blank" rel="nofollow noopener noreferrer">DigitalVBA</a> allows to configure certificate settings for macros signing

Here are the steps to add Digital signature into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source Excel document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> object
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/digitalvba/" target="_blank" rel="nofollow noopener noreferrer">DigitalVBA</a> object with certificatePath and password.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> to it.

This example shows how to add Digital signature to document. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp

 using (Signature signature = new Signature(excelFilePath))
{
     DigitalSignOptions signOptions = new DigitalSignOptions();
    //Add extension for signing VBA project digitally
    DigitalVBA digitalVBA = new DigitalVBA(certificatePath, password);
    //Set to true only for signing VBA project
    digitalVBA.SignOnlyVBAProject = true;
    digitalVBA.Comments = "VBA Comment";
    signOptions.Extensions.Add(digitalVBA);

    // sign document to file
    SignResult signResult = signature.Sign(outputFilePath, signOptions);
}

```

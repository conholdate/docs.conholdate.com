<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides ability to align signature on page with horizontal and vertical alignment settings. Signature options that implement interface <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/ialignment" target="_blank" rel="nofollow noopener noreferrer">IAlignment</a> contain following properties:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> - property of enumeration type <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> to specify horizontal alignment of signature. Values are <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">None, Left, Center, Right</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> - property of enumeration type <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> to specify vertical alignment of signature. Values are <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">None, Top, Center, Bottom</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>\- property of class <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/padding" target="_blank" rel="nofollow noopener noreferrer">Padding</a> to specify offset for signature alignment. Fields of class are <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/padding" target="_blank" rel="nofollow noopener noreferrer">Left, Top, Right, Bottom</a> to specify offset in measure units from alignment area.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/marginmeasuretype" target="_blank" rel="nofollow noopener noreferrer">MarginMeasureType</a> - property of enumeration type <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType</a> with values (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">Pixels, Millimeters, Percents</a>). See more details in this example [Locating signature on page with different measure units](/net/signature/developer-guide/advanced-usage/signing/locating-signature-on-document-page/locating-signature-on-page-with-different-measure-units/)

Here are the steps to align signature on page with GroupDocs.Signature:

* Create a new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate signature options (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> for example) with all required properties.
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> with one of enumeration value to align signature along page width
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> with one of enumeration value to align signature along page height
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a> property with required offsetfrom page border
* Set  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/marginmeasuretype" target="_blank" rel="nofollow noopener noreferrer">MarginMeasureType</a> property with non default value if there is need to specify offset from page border in another measure units like millimeters and page percents (from 100% width and 100% height)
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass the instance of signature options (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> for example) to it.

This example shows how to locate signature with different alignments.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // define qr-code size
    int qrWidth = 100;
    int qrHeight = 100;
    // define list of options
    List<SignOptions> listOptions = new List<SignOptions>();
    // walk through all alignment values to locate signature at all page alignment areas
    foreach (HorizontalAlignment horizontalAlignment in Enum.GetValues(typeof(HorizontalAlignment)))
    {
        foreach (VerticalAlignment verticalAlignment in Enum.GetValues(typeof(VerticalAlignment)))
        {
            if (verticalAlignment != VerticalAlignment.None && horizontalAlignment != HorizontalAlignment.None)
            {
                listOptions.Add(
                    new QrCodeSignOptions("Left-Top")
                    {
                    // set signature rectangle
                    Width = qrWidth,
                        Height = qrHeight,
                    // set signature alignment
                    HorizontalAlignment = horizontalAlignment,
                        VerticalAlignment = verticalAlignment,
                        Margin = new Padding(5),
                    });
            }
        }
    }
    // sign document to file
    signature.Sign("signed.pdf", listOptions);
}
```

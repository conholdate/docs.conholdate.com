A Word document offers a diverse selection of pre-designed headers and footers, providing you with options to enhance the design and layout of your document effortlessly. The header, positioned in the top margin, and the footer, located in the bottom margin, serve as integral sections of the document layout. Typically, headers and footers play host to supplementary details like page numbers, dates, author identification, and footnotes.

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides ability to locate signature in the footer and header of Word document. Use enumeration <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/shapeposition" target="_blank" rel="nofollow noopener noreferrer">ShapePosition</a> contains following valuesks

* Default - signature will be placed in the docx document body
* Header - signature will be placed in the word document header
* Footer - signature will be placed in the word document footer

Here are the steps to set signature mode with adding text into Word document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> and setup <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/shapeposition" target="_blank" rel="nofollow noopener noreferrer">ShapePosition</a> property
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance.

## Locate Signature Area in the Word header/footer
Now, users can easily create and customize text signatures directly within the headers and footers of their Word documents.

```csharp
    using (Signature signature = new Signature("sample.docx"))
    {
        var listOptions = new List<SignOptions>();

        var headerSign = new TextSignOptions("Hello header!")
        {
            ShapePosition = ShapePosition.Header
        };

        var footerSign = new TextSignOptions("Hello footer!")
        {
            ShapePosition = ShapePosition.Footer
        };

        listOptions.Add(headerSign);
        listOptions.Add(footerSign);

        signature.Sign(outputFilePath, listOptions);
    }
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides ability to stretch signature area along page width or height. Use enumeration <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">StretchMode</a> contains following values

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">None</a> - no stretch will be applied
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a> -  to stretch signature area along page width
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a> - to stretch signature area along page height
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageArea</a> - to stretch signature area along page width and height

Here are the steps to use stretch mode with adding text or images signatures into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> or <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a>  object with all required additional options and setup <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/stretch" target="_blank" rel="nofollow noopener noreferrer">Stretch</a> property
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and the instance of signature options (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> for example) to it.

## Locate Signature Area with Stretch Mode

This example shows how to locate signature with stretch mode.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // define several signature options of different types and settings
    TextSignOptions textOptions = new TextSignOptions("This is test message")
    {
        AllPages = true,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(50),
        Stretch = StretchMode.PageWidth
    };
    BarcodeSignOptions barcodeOptions = new BarcodeSignOptions("123456")
    {
        AllPages = true,
        EncodeType = BarcodeTypes.Code128,
        VerticalAlignment = VerticalAlignment.Bottom,
        Margin = new Padding(50),
        Stretch = StretchMode.PageWidth
    };
    ImageSignOptions imageOptions = new ImageSignOptions()
    {
        AllPages = true,
        Stretch = StretchMode.PageHeight,
        HorizontalAlignment = HorizontalAlignment.Right,
        ImageFilePath = Constants.ImageHandwrite
    };

    // define list of signature options
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(textOptions);
    listOptions.Add(barcodeOptions);
    listOptions.Add(imageOptions);
    // sign document to file
    signature.Sign("signed.pdf", listOptions);
}
```

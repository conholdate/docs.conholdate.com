<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> class to specify additional options for Barcode signature to specify following signature appearance

* signature alignment (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>)
* margins (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>)
* border and background settings (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/border" target="_blank" rel="nofollow noopener noreferrer">Border,</a> <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/background" target="_blank" rel="nofollow noopener noreferrer">Background</a>)
* font and colors (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/font" target="_blank" rel="nofollow noopener noreferrer">Font</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/forecolor" target="_blank" rel="nofollow noopener noreferrer">Forecolor</a>)

Here are the steps to add Barcode signature into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> object with all required additional options.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.  

This example shows how to add Barcode signature to document. See <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    // create barcode option with predefined barcode text
    BarcodeSignOptions options = new BarcodeSignOptions("12345678")
    {
        // setup Barcode encoding type
        EncodeType = BarcodeTypes.Code128,
        // set signature position
        Left = 100,
        Top = 100,
        // set signature alignment
        // when VerticalAlignment is set the Top coordinate will be ignored.
        // Use Margin properties Top, Bottom to provide vertical offset
        VerticalAlignment = Domain.VerticalAlignment.Top,
        // when HorizontalAlignment is set the Left coordinate will be ignored.
        // Use Margin properties Left, Right to provide horizontal offset
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Top = 20, Right = 20 },
        // adjust signature appearance
        // setup signature border
        Border = new Border()
        {
            Color = Color.DarkGreen,
            DashStyle = DashStyle.DashLongDashDot,
            Transparency = 0.5,
            Visible = true,
            Weight = 2
        },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
        // specify position of text with barcode line
        CodeTextAlignment = CodeTextAlignment.Above,
        // setup background
        Background = new Background()
        {
            Color = Color.LimeGreen,
            Transparency = 0.5,
            Brush = new LinearGradientBrush(Color.LimeGreen, Color.DarkGreen)
        }
    };
    // sign document to file
    SignResult signResult = signature.Sign("SampleSigned.docx", options);
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

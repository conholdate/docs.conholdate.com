<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibcliccombineddata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICCombinedData</a> class to create HIBC LIC barcode. It is used by manufacturers of health care products for identification purpose. Labelers can encode Primary Data and Secondary Data.

Here are the steps how to add HIBC LIC barcode signature into document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibcliccombineddata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICCombinedData</a>. Fill properties which correspond Primary Data and Secondary Data structure with models <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibclicprimarydata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICPrimaryData</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibclicsecondaryadditionaldata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICSecondaryAdditionalData</a> respectively.
* Instantiate the  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> object with all required additional options and set HIBCLICCombinedData object into Data property.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> to it.
* Analyze <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> result to check newly created signatures if needed.  

This example shows how to add HIBCLICCombinedData signature to document:

```csharp
using (Signature signature = new Signature(filePath))
{
    // Create HIBCLICCombinedData data object which composes Primary and Secondary data
    var hibclicCombinedData = new HIBCLICCombinedData()
    {
        PrimaryData = new HIBCLICPrimaryData()
        {
            ProductOrCatalogNumber = "12345",
            LabelerIdentificationCode = "A999",
            UnitOfMeasureID = 1
        },

        SecondaryAdditionalData = new HIBCLICSecondaryAdditionalData()
        {
            ExpiryDate = DateTime.Today,
            ExpiryDateFormat = HIBCLICDateFormat.MMDDYY,
            Quantity = 30,
            LotNumber = "LOT123",
            SerialNumber = "SERIAL123",
            DateOfManufacture = DateTime.Today
        }
    };

    // create options
    QrCodeSignOptions options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 100,
        // setup Data property to Mailmark2D instance
        Data = hibclicCombinedData
    };

    // sign document to file
    var signResult = signature.Sign(outputFilePath, options);
            
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

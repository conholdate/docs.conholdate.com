<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> class to manipulate text signatures location, size and textual content.  
Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method modifies the same document that was passed to constructor of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.

Here are the steps to update Text signature in the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter;
* Instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> object with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignatures</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> object(s) that should be updated;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method and pass one or several signatures to it.

This example shows how to update Text signature that was found using  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    TextSearchOptions options = new TextSearchOptions();
    // search for text signatures in document
    List<TextSignature> signatures = signature.Search<TextSignature>(options);
    if(signatures.Count > 0)
    {
        TextSignature textSignature = signatures[0];
        // change Text property
        textSignature.Text = "John Walkman";
        // change position
        textSignature.Left = textSignature.Left + 10;
        textSignature.Top = textSignature.Top + 10;
        // change size. Please note not all documents support changing signature size
        textSignature.Width = 200;
        textSignature.Height = 100;
        bool result = signature.Update(textSignature);
       if (result)
       {
           Console.WriteLine(
               $"Signature with Text '{textSignature.Text}' " +
               $"was updated in the document ['{fileName}']."
           );
       }
       else
       {
           Console.WriteLine(
               $"Signature was not updated in the document! " +
               $"Signature with Text '{textSignature.Text}' was not found!"
           );
       }
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a> class to manipulate barcode signatures location, size and textual content.
Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method modifies the same document that was passed to constructor of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.

### Here are the steps to update Barcode signature in the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter;
* Instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> object with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignatures</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a> object(s) that should be updated;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> method and pass one or several signatures to it.

This example shows how to update Barcode signature that was found using  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
// initialize Signature instance
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    BarcodeSearchOptions options = new BarcodeSearchOptions();
    List<BarcodeSignature> signatures = signature.Search<BarcodeSignature>(options);
    if (signatures.Count > 0)
    {
        BarcodeSignature barcodeSignature = signatures[0];
        // change position
        barcodeSignature.Left = 100;
        barcodeSignature.Top = 100;
        bool result = signature.Update(barcodeSignature);
        if (result)
        {
            Console.WriteLine($"Signature with Barcode '{barcodeSignature.Text}' was updated!");
        }
        else
        {
            Console.WriteLine($"Signature was not updated in the document!");
        }
    }
}
```

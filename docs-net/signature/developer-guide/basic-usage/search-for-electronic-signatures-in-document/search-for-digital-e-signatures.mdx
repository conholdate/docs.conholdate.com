<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> offers an ability to find Digital signatures that are applied to document and returns its digital signature certificate.  
Please follow these steps to search for Digital signatures within the document:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> object according to your requirements and specify search options
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> to it.

This example shows how to search for Digital signature in the document and analyze digital signature certificate.

```csharp
using (Signature signature = new Signature("spreadsheet.xlsx"))
{
    // search for signatures in document
    List<DigitalSignature> signatures = signature.Search<DigitalSignature>(SignatureType.Digital);

    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var digitalSignature in signatures)
    {
        Console.WriteLine("Digital signature found from {0} with validation flag {1}. Certificate SN {2}",
        digitalSignature.SignTime, digitalSignature.IsValid, digitalSignature.Certificate?.SerialNumber);
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides an easy and straightforward way to find all Barcode signatures that are present in a document.  
For the most simpler use case - just find all Barcode signatures within document its only needed to instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> class and pass it to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

Here are the exact steps to search for Barcode signatures within the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> object according to your requirements and specify search options
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> to it.

This example shows how to search for Barcode signature in the document.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // search for signatures in document
    List<BarcodeSignature> signatures = signature.Search<BarcodeSignature>(SignatureType.Barcode);

    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var barcodeSignature in signatures)
    {
        Console.WriteLine("Barcode signature found at page {0} with type {1} and text {2}",
            barcodeSignature.PageNumber, barcodeSignature.EncodeType, barcodeSignature.Text);
    }
}
```

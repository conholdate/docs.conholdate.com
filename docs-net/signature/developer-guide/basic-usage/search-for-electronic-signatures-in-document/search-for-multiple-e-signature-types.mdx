Sometimes you may want to search for electronic signatures of different types simultaneously. <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> allows searching documents for different signature types in an easy and intuitive way. In common words the idea is to pass collection of desired signature types to Search method.

Here are the steps to search for multiple signatures types within the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter.
* Instantiate search options for required signature types and them to collection of List&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a>&gt;  type.

The possible options are:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> - to search for Barcode signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> -  to search for Digital signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> - to search for Form-field signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> - to search for Image signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> - to search for Metadata signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSearchOptions</a> - to search for QR-code signatures;
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> to search for Text signatures.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass collection of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">search options</a> to it.

This example shows how to search for multiple electronic signature types in the document.

```csharp
using (Signature signature = new Signature("SingedSample.pdf"))
{
    // define few search options
    BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions()
    {
        EncodeType = BarcodeTypes.Code128
    };
    QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions()
    {
        EncodeType = QrCodeTypes.QR,
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    MetadataSearchOptions metadataOptions = new MetadataSearchOptions()
    {
        IncludeBuiltinProperties = true
    };

    // add options to list
    List<SearchOptions> listOptions = new List<SearchOptions>();
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrCodeOptions);
    listOptions.Add(metadataOptions);

    // search for signatures in document
    SearchResult result = signature.Search(listOptions);
    if (result.Signatures.Count > 0)
    {
        Console.WriteLine("\nSource document contains following signatures.");
        foreach (var resSignature in result.Signatures)
        {
            Console.WriteLine("Signature found at page {0} with type {1}", 
                resSignature.PageNumber,
                resSignature.SignatureType);
        }
    }
    else
    {
        Console.WriteLine("Signatures was not found.");
    }
}
```

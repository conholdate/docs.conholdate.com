## Overview

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> allows to get document information which includes:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a>
* Pages dimensions - <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pageinfo/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pageinfo/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> for each page in a document <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> collection.

## Get document information from file on local disk

The following code snippet demonstrates how to obtain information about document stored on local disk.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    IDocumentInfo documentInfo = signature.GetDocumentInfo();
    Console.WriteLine("Document properties {0}:", Path.GetFileName("sample.pdf"));
    Console.WriteLine(" - format : {0}", documentInfo.FileType.FileFormat);
    Console.WriteLine(" - extension : {0}", documentInfo.FileType.Extension);
    Console.WriteLine(" - size : {0}", documentInfo.Size);
    Console.WriteLine(" - page count : {0}", documentInfo.PageCount);
    foreach(PageInfo pageInfo in documentInfo.Pages)
    {
        Console.WriteLine(" - page-{0} Width {1}, Height {2}", pageInfo.PageNumber, pageInfo.Width, pageInfo.Height);
    }
}
```

## Get document information from a stream

The following code snippet demonstrates how to obtain information about document provided as a stream.

```csharp
string filePath = "sample.pdf";
using (var stream = File.OpenRead(filePath))
{
    using (Signature signature = new Signature(stream))
    {
        IDocumentInfo documentInfo = signature.GetDocumentInfo();
        Console.WriteLine("Document properties {0}:", Path.GetFileName(filePath));
        Console.WriteLine(" - format : {0}", documentInfo.FileType.FileFormat);
        Console.WriteLine(" - extension : {0}", documentInfo.FileType.Extension);
        Console.WriteLine(" - size : {0}", documentInfo.Size);
        Console.WriteLine(" - page count : {0}", documentInfo.PageCount);
        foreach (PageInfo pageInfo in documentInfo.Pages)
        {
            Console.WriteLine(" - page-{0} Width {1}, Height {2}", pageInfo.PageNumber, pageInfo.Width, pageInfo.Height);
        }
    }
}
```

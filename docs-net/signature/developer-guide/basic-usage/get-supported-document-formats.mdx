## Overview

With <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> you can get the [list of file formats](/net/signature/getting-started/supported-document-formats/) that allow adding electronic signatures by following the below steps:

* Call static function <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class;
* Enumerate through the collection of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> objects.

The following code sample demonstrates how to get supported file formats list.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
    .GetSupportedFileTypes()
    .OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
    Console.WriteLine(fileType);
```

## Overview

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> supports verification of documents for different signature types. This approach requires to add all required verification options to list.

Here are the steps to verify document for multiple signatures with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or stream as a constructor parameter.
* Instantiate required several <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a> objects (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalverifyoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textverifyoptions" target="_blank" rel="nofollow noopener noreferrer">TextVerifyOptions</a>) and add instances to List&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a>&gt; collection.
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> method of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass filled list of List&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a>&gt; to it.

This example shows how to search for different signature types in the document.

```csharp
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    TextVerifyOptions textVerifyOptions = new TextVerifyOptions()
    {
        AllPages = true, // this value is set by default
        SignatureImplementation = TextSignatureImplementation.Stamp,
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    BarcodeVerifyOptions barcVerifyOptions = new BarcodeVerifyOptions()
    {
        AllPages = true, // this value is set by default
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    QrCodeVerifyOptions qrcdVerifyOptions = new QrCodeVerifyOptions()
    {
        AllPages = true, // this value is set by default
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    DigitalVerifyOptions digtVerifyOptions = new DigitalVerifyOptions("certificate.pdf")
    {
        Comments = "Test comment"
    };
    // verify document signatures
    List<VerifyOptions> listOptions = new List<VerifyOptions>();
    listOptions.Add(textVerifyOptions);
    listOptions.Add(barcVerifyOptions);
    listOptions.Add(qrcdVerifyOptions);
    listOptions.Add(digtVerifyOptions);
    VerificationResult result = signature.Verify(listOptions);
    if (result.IsValid)
    {
        Console.WriteLine("\nDocument was verified successfully!");
    }
    else
    {
        Console.WriteLine("\nDocument failed verification process.");
    }
}
```

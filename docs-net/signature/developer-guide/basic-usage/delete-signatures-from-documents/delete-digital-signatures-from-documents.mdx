## Overview
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignature</a> class to manipulate digital electronic signatures and delete them from the documents.
Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method modifies the same document that was passed to constructor of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.

*Important information*. Please be aware that digitally signed documents with valid certificates (pfx files) are secured and verified. Changing digitally signed document makes them untrusted from the digital verification perspective. At this moment only Pdf documents support deletion of the specific digital signatures in case of many ones were added. Most documents support deletion of all digital signatures at once without separate certificates removal. It's strongly recommened to use deletion of electronic digital signatures by signature type Digital. See example [Delete Signatures of the certain type]

## How to delete Digital signature from the document
Here are the steps to delete Digital signature from the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path or its stream as a constructor parameter;
* Instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> object with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatures</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignature</a> object(s) that should be removed from the document;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method and pass one or several signatures to it.

This example shows how to delete Digital signature that was found using <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // Search for electronic Digital signatures in the document
    List<DigitalSignature> signatures = 
        signature.Search<DigitalSignature>(SignatureType.Digital);

    if (signatures.Count > 0)
    {
        DigitalSignature digitalSignature = signatures[0];
        bool result = signature.Delete(digitalSignature);

        if (result)
        {
            Console.WriteLine(
                $"Digital signature #{digitalSignature.Thumbprint} from " +
                $"{digitalSignature.SignTime.ToShortDateString()} was deleted."
            );
        }
        else
        {
            Console.WriteLine(
                $"Signature was not deleted from the document! " +
                $"Signature# {digitalSignature.Thumbprint} was not found!"
            );
        }
    }
}
```

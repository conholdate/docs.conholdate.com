## Overview
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> class to manipulate image signatures and delete them from the documents over <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method.  
Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method modifies the same document that was passed to constructor of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.

## How to delete Image signature from the document
Here are the steps to delete Image signature from the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter;
* Instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> object with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> object(s) that should be removed from the document;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method and pass one or several signatures to it.  

This example shows how to delete Image signature that was found using <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
using (Signature signature = new Signature("signed.pptx"))
{
    ImageSearchOptions options = new ImageSearchOptions();
    
    // Search for image signatures in the document
    List<ImageSignature> signatures = 
        signature.Search<ImageSignature>(options);

    if (signatures.Count > 0)
    {
        ImageSignature imageSignature = signatures[3];
        bool result = signature.Delete(imageSignature);

        if (result)
        {
            Console.WriteLine(
                $"Image signature at location {imageSignature.Left}x{imageSignature.Top} " +
                $"and size {imageSignature.Size} was deleted from document ['{fileName}']."
            );
        }
        else
        {
            Console.WriteLine(
                $"Signature was not deleted from the document! " +
                $"Signature at location {imageSignature.Left}x{imageSignature.Top} " +
                $"and size {imageSignature.Size} was not found!"
            );
        }
    }
}
```

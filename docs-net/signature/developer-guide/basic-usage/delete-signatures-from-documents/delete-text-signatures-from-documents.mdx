## Overview
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> provides <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> class to manipulate text signatures and delete them from the documents.
Please be aware that <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method modifies the same document that was passed to constructor of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class.
## How to delete Text signature from the document
Here are the steps to delete Text signature from the document with GroupDocs.Signature:

* Create new instance of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass source document path as a constructor parameter;
* Instantiate <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> object with desired properties;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method to obtain list of <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignatures</a>;
* Select from list <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> object(s) that should be removed from the document;
* Call <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> object <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> method and pass one or several signatures to it.

This example shows how to delete Text signature that was found using <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> method.

```csharp
using (Signature signature = new Signature("signed.pptx"))
{
    TextSearchOptions options = new TextSearchOptions();
    
    // Search for text signatures in the document
    List<TextSignature> signatures = 
        signature.Search<TextSignature>(options);

    if (signatures.Count > 0)
    {
        TextSignature textSignature = signatures[0];
        bool result = signature.Delete(textSignature);

        if (result)
        {
            Console.WriteLine(
                $"Signature with text '{textSignature.Text}' " +
                $"was deleted from the document."
            );
        }
        else
        {
            Console.WriteLine("Signature was not deleted from the document!");
        }
    }
}
```

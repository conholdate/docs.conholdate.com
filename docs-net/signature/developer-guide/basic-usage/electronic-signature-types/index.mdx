<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> for .NET supports a wide range of electronic signature types that are listed below:

* Barcode signatures;
* Digital signatures based on certificate files;
* Form-field signatures;
* Image signatures;
* Metadata signatures;
* QR-code signatures
* Stamp signatures;
* Text signatures.  

The following articles contain examples of how to eSign documents with each supported signature type.

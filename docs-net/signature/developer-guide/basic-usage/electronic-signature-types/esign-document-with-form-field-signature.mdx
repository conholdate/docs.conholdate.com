## What is a Form Field?

A **form field** is an interactive element located on a document page that allows user data input through various control types like free input text boxes, multi-line text boxes, checkboxes, drop-down lists, etc. Different document types support a specific list of form field types. These elements are used to collect information from users on template form. Each Form Field element has a unique name, settings and value field. Form Fields should have unique names within the form. The picture below demonstrates a possible document page with form fields.

![FormField](/net/signature/images/esign-document-with-form-field-signature.png)

## How to eSign document with Form Field signature

With <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> you can create new form fields or update the existing ones within the documents. The <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> class specifies different options for Form Field signature. The <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> class contains one <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/formfieldsignature/" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignature</a> object that specifies the properties of the desired signature.

Below are listed different Form Field signature classes that could be set to <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a>:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a> - represents a text input form field on a document page.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature</a> - represents a checkbox field on a document page.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/comboboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">ComboboxFormFieldSignature</a> - represents a combo box field signature input with a list of possible options.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/radiobuttonformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">RadioButtonFormFieldSignature</a> - represents a radio button signature on a document page.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a> - represents a digital signature input form on a document page.  

Here are the steps to add Form Field signatures into a document with GroupDocs.Signature:

* Create a new instance of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass the source document path as a constructor parameter;
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> object according to your requirements;
* Instantiate one of the objects - <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature,</a> <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/comboboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">ComboboxFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/radiobuttonformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">RadioButtonFormFieldSignature</a> or <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a>;
* Assign the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> property with the object created in a previous step;
* Call the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> object to it.


:::note
Currently GroupDocs.Signature supports the creation of Form Field signatures for PDF documents only.
:::


This example shows how to sign a PDF document with a Form Field electronic signature.

```csharp
            // The path to the documents directory.
            string filePath = "sample.pdf";
            string fileName = Path.GetFileName(filePath);

            string outputFilePath = Path.Combine("C:\output", fileName);

            using (Signature signature = new Signature(filePath))
            {
                // Instantiate text form field signature
                FormFieldSignature textSignature = new TextFormFieldSignature("FieldText", "Value1");

                // Instantiate options based on text form field signature
                FormFieldSignOptions options = new FormFieldSignOptions(textSignature)
                {
                    HorizontalAlignment = HorizontalAlignment.Left,
                    VerticalAlignment = VerticalAlignment.Top,
                    Margin = new Padding(10, 20, 0, 0),
                    Height = 10,
                    Width = 100
                };
                // Sign document and save to the file
                signature.Sign(outputFilePath, options);
            }
```

## How to eSign document with existing Form Field signatures

GroupDocs.Signature for .NET also provides a mechanism to update the existing form field signatures within the documents.

To update an existing form field signature within the document with GroupDocs.Signature:

* Create a new instance of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class and pass the source document path as a constructor parameter.
* Instantiate the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> object with all required additional options.
* Set the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> property with the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.FormField</a> value.
* Set the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtitle" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldTitle</a> and <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtype" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldType</a> properties with the proper values of form fields to be updated.
* Call the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> method of the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> class instance and pass the initialized <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> instance to it.
* Analyze the <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> object to check the newly created signatures if needed.  

This example shows how to sign a PDF document with the existing Form Field electronic signature and update its value.

```csharp
// The path to the documents directory.
string filePath = "sample.pdf";
string fileName = Path.GetFileName(filePath);

string outputFilePath = Path.Combine("C:\output", fileName);

using (Signature signature = new Signature(filePath))
{
    TextSignOptions ffOptions1 = new TextSignOptions("Document is approved")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.PlainText
    };
    TextSignOptions ffOptions2 = new TextSignOptions("John Smith")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.RichText,
        FormTextFieldTitle = "UserSignatureFullName"
    };
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(ffOptions1);
    listOptions.Add(ffOptions2);
    // sign document to file
    SignResult signResult = signature.Sign(outputFilePath, listOptions);
}
```
### Summary
This guide explains how to use **GroupDocs.Signature** to add form field signatures to documents. It covers loading a document, configuring form field properties such as name, type, and value, and saving the signed document. Advanced options, like customizing field appearance and placement, are also included. For more details, refer to related guides on document signing techniques.

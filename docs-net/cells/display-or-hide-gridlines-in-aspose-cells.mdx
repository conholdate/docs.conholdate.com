All Excel worksheets have gridlines by default. They help delineate cells, so that it is easy to enter data into particular cells. Gridlines enable us to view a worksheet as a collection of cells, where each cell is easily identifiable.
:::

## Controlling the Visibility of the Gridlines {#controlling-the-visibility-of-the-gridlines}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods for managing a worksheet. To control the visibility of gridlines, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class' <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isgridlinesvisible" target="_blank" rel="nofollow noopener noreferrer">**IsGridlinesVisible**</a> property. <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isgridlinesvisible" target="_blank" rel="nofollow noopener noreferrer">**IsGridlinesVisible**</a> is a Boolean property, which means that it can only store a **true** or **false** value.

A complete example is given below that demonstrates the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isgridlinesvisible" target="_blank" rel="nofollow noopener noreferrer">**IsGridlinesVisible**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class to hide the gridlines of the first worksheet of the Excel file.

In the screenshot below, you can see that the Book1.xls file contains three worksheets: Sheet1, Sheet2 and Sheet3. All worksheets have gridlines.

**Book1.xls: worksheet view before modification**

The Book1.xls file is opened using the Workbook class, and the gridlines on the first worksheet are hidden. The modified file is saved as output.xls.

**Output.xls: worksheet after modification**

![todo:image_alt_text](/net/cells/images/22ae1f67adc2fdb9-display-or-hide-gridlines-in-aspose-cells_2.png)

**C#**

```csharp
 //Creating a file stream containing the Excel file to be opened

FileStream fstream = new FileStream("book1.xls", FileMode.Open);

//Instantiating a Workbook object

//Opening the Excel file through the file stream

Workbook workbook = new Workbook(fstream);

//Accessing the first worksheet in the Excel file

Worksheet worksheet = workbook.Worksheets[0];

//Hiding the gridlines on the first worksheet of the Excel file

worksheet.IsGridlinesVisible = false;

//Saving the modified Excel file

workbook.Save("output.xls");

//Closing the file stream to free all resources

fstream.Close();
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Earlier, Aspose.Cells could not render Office Add‑Ins when the Excel file was saved to PDF format. Now Aspose.Cells renders them correctly. You do not need to use any special method or property to render Office Add‑Ins in the output PDF. Simply save your Excel file to PDF format and it will render the Office Add‑ins.

## Render Office Add‑Ins while converting Excel to PDF {#render-office-addins-while-converting-excel-to-pdf}

The following sample code saves the <a href="https://docs.aspose.com/cells/net/render-office-add-ins-while-converting-excel-to-pdf/60489769.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>, which contains the Office Add‑Ins. Please see the <a href="https://docs.aspose.com/cells/net/render-office-add-ins-while-converting-excel-to-pdf/60489770.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF generated with the previous version, i.e., 17.11</a> and the <a href="https://docs.aspose.com/cells/net/render-office-add-ins-while-converting-excel-to-pdf/60489771.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF generated with the newer version, i.e., 17.12 and onward</a>. The PDF generated by the previous version is blank, but the PDF generated by the newer version shows the Office Add‑Ins.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load the sample Excel file containing Office Add-Ins
Workbook wb = new Workbook("sampleRenderOfficeAdd-Ins.xlsx");

//Save it to Pdf format
wb.Save("output-" + CellsHelper.GetVersion() + ".pdf");
```

## Aspose.Cells - Set Worksheet Zoom Factor {#asposecells---set-worksheet-zoom-factor}

**C#**

```cs
 //Instantiating a Workbook object

Workbook workbook = new Workbook();

//Adding a new worksheet to the Workbook object

WorksheetCollection worksheets = workbook.Worksheets;

Worksheet worksheet = worksheets.Add("My Worksheet");

worksheet.Zoom = 75;

//Saving the Excel file

workbook.Save("../../data/newWorksheet.xls");
```

## NPOI - HSSF XSSF - Set Worksheet Zoom Factor {#npoi---hssf-xssf---set-worksheet-zoom-factor}

**C#**

```cs
 IWorkbook wb = new XSSFWorkbook();

ISheet sheet1 = wb.CreateSheet("First Sheet");

sheet1.SetZoom(3, 4); // 75 percent

FileStream sw = File.Create("../../data/newWorksheet.xls");

wb.Write(sw);

sw.Close();
```

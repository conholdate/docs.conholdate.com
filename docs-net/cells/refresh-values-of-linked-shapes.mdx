:::


:::info
Sometimes, you have a linked shape in your Excel file which is linked to some cell. In Microsoft Excel, changing the value of the linked cell also changes the value of the linked shape. This also works fine with Aspose.Cells if you want to save your workbook in XLS or XLSX format. However, if you want to save your workbook in PDF or HTML format, then you will have to call <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shapecollection/methods/updateselectedvalue" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Shapes.UpdateSelectedValue()**</a> method to refresh the value of the linked shape.
:::

## Example {#example}

The following screenshot shows the source Excel file used in the sample code below. It has a linked picture linked to cells A1 to E4. We will change the value of cell B4 with Aspose.Cells and then call <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shapecollection/methods/updateselectedvalue" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Shapes.UpdateSelectedValue()**</a> method to refresh the value of the picture and save it in PDF format.

### C# code to refresh the values of linked shapes {#c-code-to-refresh-the-values-of-linked-shapes}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

// Create workbook from source file
Workbook workbook = new Workbook(sourceDir + "sampleRefreshValueOfLinkedShapes.xlsx");

// Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Change the value of cell B4
Cell cell = worksheet.Cells["B4"];
cell.PutValue(100);

// Update the value of the Linked Picture which is linked to cell B4
worksheet.Shapes.UpdateSelectedValue();

// Save the workbook in PDF format
workbook.Save(outputDir + "outputRefreshValueOfLinkedShapes.pdf", SaveFormat.Pdf);
```

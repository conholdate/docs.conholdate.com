## Possible Usage Scenarios {#possible-usage-scenarios}

When you need to set styled data for a specific cell, you can assign an HTML string to the cell. You can also obtain the HTML string of the cell. Aspose.Cells offers this feature. Aspose.Cells provides the following property to help you achieve your goals.

- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/htmlstring" target="_blank" rel="nofollow noopener noreferrer">**Cell.HtmlString**</a>

## Get and set HTML string using Aspose.Cells {#get-and-set-html-string-using-asposecells}

This example shows how to:

1. Create a workbook and add some data.
2. Get the specific cell in the first worksheet.
3. Set HTML string to the cell.
4. Get HTML string of the cell.

```csharp
//Instantiating an Workbook object
Workbook workbook = new Workbook();
//Obtaining the reference of the newly added worksheet
Worksheet ws = workbook.Worksheets[0];
Cells cells = ws.Cells;

//Setting the value to the cells
Cell cell = cells["A1"];
cell.PutValue("Fruit");
cell = cells["B1"];
cell.PutValue("Count");
cell = cells["C1"];
cell.PutValue("Price");

cell = cells["A2"];
cell.PutValue("Apple");
cell = cells["A3"];
cell.PutValue("Mango");
cell = cells["A4"];
cell.PutValue("Blackberry");
cell = cells["A5"];
cell.PutValue("Cherry");

Cell c3 = cells["C3"];
//set html string for C3 cell.
c3.HtmlString = "<b>test bold</b>";

Cell c4 = cells["C4"];
//set html string for C4 cell.
c4.HtmlString = "<i>test italic</i>";

//get the html string of specific cell.
Console.WriteLine(c3.HtmlString);
Console.WriteLine(c4.HtmlString);
```

## Possible Usage Scenarios {#possible-usage-scenarios}

The row height automatically matches the font of the content, but when the height of the cached row does not match the height of the content in the file, MS Excel will automatically adjust the row height when loading the file, whereas Aspose.Cells does not adjust it automatically to improve performance. If you need to use Aspose.Cells to automatically match row heights when loading files, you can achieve this through the parameter <a href="https://reference.aspose.com/cells/net/aspose.cells/autofitteroptions/onlyauto/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.AutoFitterOptions.OnlyAuto</a>.

Please refer to the following image. We can observe that the cached row height in row 11 is 15, but Excel automatically adjusts the row height when loading the file.

![](/net/cells/images/7b46a44eef8b5ef8-1.png)

## Adjust Row Height using Aspose.Cells {#adjust-row-height-using-asposecells}

If you directly load the file and save it to PDF, the data will not be fully displayed in the PDF because its cached row height is only 15.

![](/net/cells/images/f3107e03a14c89c1-2.png)\
If you set the parameter <a href="https://reference.aspose.com/cells/net/aspose.cells/autofitteroptions/onlyauto/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.AutoFitterOptions.OnlyAuto</a> to **true** when loading the file, Aspose.Cells will automatically adjust the row height. The adjusted row height can effectively meet the text‑display requirements.

![](/net/cells/images/bf90e063db815dba-3.png)

## C# Sample Code {#c-sample-code}

```csharp
Workbook wb = new Workbook(filePath + "sample.xlsx");
wb.Save(filePath + "out.pdf");

LoadOptions loadOptions = new LoadOptions();
loadOptions.AutoFitterOptions = new AutoFitterOptions();
loadOptions.AutoFitterOptions.OnlyAuto = true;
Workbook book = new Workbook(filePath + "sample.xlsx", loadOptions);
book.Save(filePath + "out2.pdf");
```

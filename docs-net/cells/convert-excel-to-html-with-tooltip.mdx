## Convert Excel to HTML with tooltip {#convert-excel-to-html-with-tooltip}

There might be cases where the text is cut off in the generated HTML and you want to display the complete text as a tooltip on hover. Aspose.Cells supports this by providing <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/addtooltiptext" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.AddTooltipText**</a> property. Setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/addtooltiptext" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.AddTooltipText**</a> property to **true** will add the complete text as a tooltip in the generated HTML.

The following image shows the tooltip in the generated HTML file.

![todo:image_alt_text](/net/cells/images/5413ee67ca07532c-convert-excel-to-html-with-tooltip_1.jpg)

The following code sample loads the <a href="https://docs.aspose.com/cells/net/convert-excel-to-html-with-tooltip/98107416.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a> and generates the <a href="https://docs.aspose.com/cells/net/convert-excel-to-html-with-tooltip/98107417.zip" target="_blank" rel="nofollow noopener noreferrer">output HTML file</a> with the tooltip.

Sample Code

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";

// Open the template file
Workbook workbook = new Workbook(sourceDir + "AddTooltipToHtmlSample.xlsx");

HtmlSaveOptions options = new HtmlSaveOptions();
options.AddTooltipText = true;

// Save as Markdown
workbook.Save(outputDir + "AddTooltipToHtmlSample_out.html", options);
```

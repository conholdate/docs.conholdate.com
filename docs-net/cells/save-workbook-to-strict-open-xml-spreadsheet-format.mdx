## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells allows you to save the workbook in *Strict Open XML Spreadsheet* format. For that purpose, it provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/compliance" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.Compliance**</a> property. If you set its value as <a href="https://reference.aspose.com/cells/net/aspose.cells/ooxmlcompliance" target="_blank" rel="nofollow noopener noreferrer">**OoxmlCompliance.Iso29500_2008_Strict**</a>, then the output Excel file will be saved in Strict Open XML Spreadsheet format.

## Save Workbook to Strict Open XML Spreadsheet Format {#save-workbook-to-strict-open-xml-spreadsheet-format}

The following sample code creates a workbook and sets the value of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/compliance" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.Compliance**</a> property as <a href="https://reference.aspose.com/cells/net/aspose.cells/ooxmlcompliance" target="_blank" rel="nofollow noopener noreferrer">**OoxmlCompliance.Iso29500_2008_Strict**</a> and saves it as the <a href="https://docs.aspose.com/cells/net/save-workbook-to-strict-open-xml-spreadsheet-format/67338272.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. If you open the output Excel file in Microsoft Excel and open the Save As… dialog box, you will see that its format is *Strict Open XML Spreadsheet* as shown in this screenshot.

![todo:image_alt_text](/net/cells/images/5c80ed2d593e506b-save-workbook-to-strict-open-xml-spreadsheet-format_1.png)

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Create workbook.
Workbook wb = new Workbook();

// Specify - Strict Open XML Spreadsheet - Format.
wb.Settings.Compliance = OoxmlCompliance.Iso29500_2008_Strict;

// Add message in cell B4 of first worksheet.
Cell b4 = wb.Worksheets[0].Cells["B4"];
b4.PutValue("This Excel file has Strict Open XML Spreadsheet format.");

// Save to output Excel file.
wb.Save("outputSaveWorkbookToStrictOpenXMLSpreadsheetFormat.xlsx", SaveFormat.Xlsx);
```

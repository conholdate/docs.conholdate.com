## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/glow" target="_blank" rel="nofollow noopener noreferrer">Shape.Glow</a> property along with the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/gloweffect" target="_blank" rel="nofollow noopener noreferrer">GlowEffect</a> class to work with the glow effect of a shape or chart. The <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/gloweffect" target="_blank" rel="nofollow noopener noreferrer">GlowEffect</a> class contains the following properties which can be set to achieve different results as per application requirements.

- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/gloweffect/properties/size" target="_blank" rel="nofollow noopener noreferrer">GlowEffect.Size</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/gloweffect/properties/transparency" target="_blank" rel="nofollow noopener noreferrer">GlowEffect.Transparency</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/gloweffect/properties/color" target="_blank" rel="nofollow noopener noreferrer">GlowEffect.Color</a>

## Working with the Glow Effect of Shape or Chart {#working-with-the-glow-effect-of-shape-or-chart}

The following sample code loads the source Excel file (<a href="https://docs.aspose.com/cells/net/working-with-the-glow-effect-of-shape-or-chart/5115407.xlsx" target="_blank" rel="nofollow noopener noreferrer">5115407.xlsx</a>), accesses the first shape in the first worksheet, sets the sub‑properties of the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/glow" target="_blank" rel="nofollow noopener noreferrer">Shape.Glow</a> property, and then saves the workbook to the output Excel file (<a href="https://docs.aspose.com/cells/net/working-with-the-glow-effect-of-shape-or-chart/5115414.xlsx" target="_blank" rel="nofollow noopener noreferrer">5115414.xlsx</a>).

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Load your source excel file
Workbook wb = new Workbook(dataDir + "sample.xlsx");

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Access first shape
Shape sh = ws.Shapes[0];

// Set the glow effect of the shape, Set its Size and Transparency properties
GlowEffect ge = sh.Glow;
ge.Size = 30;
ge.Transparency = 0.4;

// Save the workbook in xlsx format
wb.Save(dataDir + "output_out.xlsx");
```

Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
Aspose.Cells supports converting Microsoft Excel‑oriented HTML into XLS/XLSX format. This means that the HTML generated by Microsoft Excel can be converted back to XLS/XLSX format using Aspose.Cells.

Similarly, if there is some simple HTML, Aspose.Cells can convert it into HTML Rich Text. Aspose.Cells provides <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/htmlstring" target="_blank" rel="nofollow noopener noreferrer">**Cell.HtmlString**</a> property which can take such simple HTML and convert it to formatted cell text.
:::

The code sample below shows how to add HTML rich text inside the cell. Please see the screenshot of the output Excel file.

![todo:image_alt_text](/net/cells/images/1ab0d8535840954c-adding-html-rich-text-inside-the-cell_1.png)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

Workbook workbook = new Workbook();

Worksheet worksheet = workbook.Worksheets[0];

Cell cell = worksheet.Cells["A1"];
cell.HtmlString = "<Font Style=\"FONT-WEIGHT: bold;FONT-STYLE: italic;TEXT-DECORATION: underline;FONT-FAMILY: Arial;FONT-SIZE: 11pt;COLOR: #ff0000;\">This is simple HTML formatted text.</Font>";

workbook.Save(dataDir + "output_out.xlsx");
```

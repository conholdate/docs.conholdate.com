:::info
You can use Aspose.Cells to set the AutoRecover property of a workbook. The default value of this property is **true**. When you set it to **false** on a workbook, Microsoft Excel disables AutoRecover (Autosave) for that Excel file.

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/autorecover" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.AutoRecover**</a> property to enable or disable this option.
:::

The following code demonstrates how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/autorecover" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.AutoRecover**</a> property of the workbook. The code first reads the default value of this property (which is **true**), then sets it to **false** and saves the workbook. It then reloads the workbook and reads the property value, which is now **false**.

## C# code to set the AutoRecover property of Workbook {#c-code-to-set-the-autorecover-property-of-workbook}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create workbook object
Workbook workbook = new Workbook();

// Read AutoRecover property
Console.WriteLine("AutoRecover: " + workbook.Settings.AutoRecover);

// Set AutoRecover property to false
workbook.Settings.AutoRecover = false;

// Save the workbook
workbook.Save(dataDir + "output_out.xlsx");

// Read the saved workbook again
workbook = new Workbook(dataDir + "output_out.xlsx");

// Read AutoRecover property
Console.WriteLine("AutoRecover: " + workbook.Settings.AutoRecover);
```

## Output {#output}

Here is the console output of the above sample code.

```java
AutoRecover: True

AutoRecover: False
```

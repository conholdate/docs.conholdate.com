:::info
Aspose.Cells provides a method <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstringvalue" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetStringValue()**</a> which can be used to get the string value of a cell with or without any formatting. Suppose you have a cell with the value 0.012345 and you have formatted it to display two decimal places only. It will then display as 0.01 in Excel. You can retrieve string values both as 0.01 and as 0.012345 using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstringvalue" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetStringValue()**</a> method. It takes the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellvalueformatstrategy/" target="_blank" rel="nofollow noopener noreferrer">**CellValueFormatStrategy**</a> enum as a parameter, which has the following values:

- CellValueFormatStrategy.CellStyle
- CellValueFormatStrategy.DisplayStyle
- CellValueFormatStrategy.DisplayString
- CellValueFormatStrategy.None
  :::

The following sample code explains the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstringvalue" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetStringValue()**</a> method.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Create workbook
Workbook workbook = new Workbook();

// Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Access cell A1
Cell cell = worksheet.Cells["A1"];

// Put value inside the cell
cell.PutValue(0.012345);

// Format the cell that it should display 0.01 instead of 0.012345
Style style = cell.GetStyle();
style.Number = 2;
cell.SetStyle(style);

// Get string value as Cell Style
string value = cell.GetStringValue(CellValueFormatStrategy.CellStyle);
Console.WriteLine(value);

// Get string value without any formatting
value = cell.GetStringValue(CellValueFormatStrategy.None);
Console.WriteLine(value);
```

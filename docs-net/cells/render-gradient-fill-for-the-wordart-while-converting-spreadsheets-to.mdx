## Possible Usage Scenarios {#possible-usage-scenarios}

Before Aspose.Cells 17.1, Aspose.Cells did not render the gradient fill of WordArt when the Excel file was converted to HTML format. Since the release of Aspose.Cells 17.1, WordArt gradient fill is supported. The following screenshot compares the gradient‑fill effect when converting the Excel file using Aspose.Cells 17.1 and an older version.

![todo:image_alt_text](/net/cells/images/a91fc12c242fc26c-render-gradient-fill-for-the-wordart-while-converting-spreadsheets-to-html_1.png)

## Render Gradient Fill for the WordArt while Converting Spreadsheets to HTML {#render-gradient-fill-for-the-wordart-while-converting-spreadsheets-to-html}

The following sample code converts the <a href="https://docs.aspose.com/cells/net/render-gradient-fill-for-the-wordart-while-converting-spreadsheets-to/22774111.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a> into <a href="https://docs.aspose.com/cells/net/render-gradient-fill-for-the-wordart-while-converting-spreadsheets-to/22774109.zip" target="_blank" rel="nofollow noopener noreferrer">output HTML format</a>. The source Excel file contains a WordArt object with gradient fill, as shown in the above screenshot.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Read the source excel file having text with gradient fill
Workbook book = new Workbook(dataDir + "sourceGradientFill.xlsx");

// Save workbook to html format
book.Save(dataDir + "out_sourceGradientFill.html");
```

:::info
You can digitally sign your VBA code project using Aspose.Cells with its <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/methods/sign" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.Sign()**</a> method. Please follow these steps to check if your Excel file is digitally signed with a certificate.

- Click **Visual Basic** from the **Developer** tab to open **Visual Basic for Applications IDE**
- Click **Tools** &gt; **Digital Signatures…** in the **Visual Basic for Applications IDE**

It will display the **Digital Signature Form**, indicating whether the document is digitally signed with a certificate.
:::

## Digitally Sign a VBA Code Project with Certificate in C# {#digitally-sign-a-vba-code-project-with-certificate-in-c}

The following sample code illustrates how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/methods/sign" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.Sign()**</a> method. Below are the input and output files for the sample code. You can use any Excel file and any certificate to test this code.

- <a href="https://docs.aspose.com/cells/net/digitally-sign-a-vba-code-project-with-certificate/5115028.xlsm" target="_blank" rel="nofollow noopener noreferrer">Source Excel file</a> used in the sample code.
- <a href="https://docs.aspose.com/cells/net/digitally-sign-a-vba-code-project-with-certificate/5115039.pfx" target="_blank" rel="nofollow noopener noreferrer">Sample pfx file</a> to create a digital signature. Please install it on your computer to run this code. Its password is 1234.
- <a href="https://docs.aspose.com/cells/net/digitally-sign-a-vba-code-project-with-certificate/5115029.xlsm" target="_blank" rel="nofollow noopener noreferrer">Output Excel file</a> generated by the sample code.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string password = "1234";
string pfxPath = sourceDir + "sampleDigitallySignVbaProjectWithCertificate.pfx";
string comment = "Signing Digital Signature using Aspose.Cells";
string sourceDir = "./";
string outputDir = "./";
// Set Digital Signature
DigitalSignature digitalSignature = new DigitalSignature(File.ReadAllBytes(pfxPath), password, comment, DateTime.Now);

// Create workbook object from excel file
Workbook workbook = new Workbook(sourceDir + "sampleDigitallySignVbaProjectWithCertificate.xlsm");

// Sign VBA Code Project with Digital Signature
workbook.VbaProject.Sign(digitalSignature);

// Save the workbook
workbook.Save(outputDir + "outputDigitallySignVbaProjectWithCertificate.xlsm");
```

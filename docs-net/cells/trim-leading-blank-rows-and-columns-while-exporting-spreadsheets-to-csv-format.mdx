## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes, your Excel or CSV file has leading blank columns or rows. For example, consider this line

```java
,,,data1,data2
```

Here, the first three cells or columns are blank. When you open such a CSV file in Microsoft Excel, Microsoft Excel discards these leading blank rows and columns.

By default, Aspose.Cells does not discard leading blank columns and rows on saving, but if you want to remove them just like Microsoft Excel does, Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/trimleadingblankrowandcolumn" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions.TrimLeadingBlankRowAndColumn**</a> property. Set it to **true**, and all the leading blank rows and columns will be discarded on saving.

:::info
Prior to the release of Aspose.Cells for .NET 20.4, the default value of <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/trimleadingblankrowandcolumn" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions.TrimLeadingBlankRowAndColumn**</a> was **false**. Since the 20.4 release, the default value of <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/trimleadingblankrowandcolumn" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions.TrimLeadingBlankRowAndColumn**</a> is **true**.
:::

## Trim Leading Blank Rows and Columns while exporting spreadsheets to CSV format {#trim-leading-blank-rows-and-columns-while-exporting-spreadsheets-to-csv-format}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/trim-leading-blank-rows-and-columns-while-exporting-spreadsheets-to-csv-format/sampleTrimBlankColumns.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a>, which has two leading blank columns. It first saves the Excel file in CSV format without any changes, and then sets the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/trimleadingblankrowandcolumn" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions.TrimLeadingBlankRowAndColumn**</a> property to **true** and saves it again. The screenshot shows the <a href="https://docs.aspose.com/cells/net/trim-leading-blank-rows-and-columns-while-exporting-spreadsheets-to-csv-format/sampleTrimBlankColumns.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a>, the <a href="https://docs.aspose.com/cells/net/trim-leading-blank-rows-and-columns-while-exporting-spreadsheets-to-csv-format/outputWithoutTrimBlankColumns.csv" target="_blank" rel="nofollow noopener noreferrer">output CSV file without trimming</a>, and the <a href="https://docs.aspose.com/cells/net/trim-leading-blank-rows-and-columns-while-exporting-spreadsheets-to-csv-format/outputTrimBlankColumns.csv" target="_blank" rel="nofollow noopener noreferrer">output CSV file with trimming</a>.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// The path to the documents directory.
string dataDir = "./";

//Load source worbook
Workbook wb = new Workbook(dataDir + "sampleTrimBlankColumns.xlsx");

//Save in csv format
wb.Save(dataDir + "outputWithoutTrimBlankColumns.csv", SaveFormat.Csv);

//Now save again with TrimLeadingBlankRowAndColumn as true
TxtSaveOptions opts = new TxtSaveOptions();
opts.TrimLeadingBlankRowAndColumn = true;

//Save in csv format
wb.Save(dataDir + "outputTrimBlankColumns.csv", opts);
```

:::info
Sometimes you may want to group certain shapes, pictures, or objects in a worksheet for easier manipulation (for example, moving them to a different location, copying them, and so on). Aspose.Cells supports this functionality. You can use Aspose.Cells to group shapes, pictures, or other objects. Furthermore, you can rotate, flip, move, or resize grouped shapes, pictures, or objects as if they were individual shapes or objects. You can also ungroup and regroup shapes at any time.

This article explains in detail how to group and ungroup shapes, pictures, or other objects in a worksheet.
:::

## Group shapes, pictures, or other objects {#group-shapes-pictures-or-other-objects}

This use case demonstrates how to use Aspose.Cells to group individual shapes, pictures, or objects in a worksheet.

This is the input file: <a href="https://docs.aspose.com/cells/net/group-or-ungroup/sample1.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample1.xlsx</a>

```csharp
string path = @"YourPath\";
string name = "sample";

// Create the workbook
Workbook workbook = new Workbook(path + name + ".xlsx");
//Get shapes, images, and objects
ShapeCollection shapes = workbook.Worksheets[0].Shapes;

//group 1
Shape[] shapeArr1 = new Shape[] { shapes[0], shapes[2] };
//group 2
Shape[] shapeArr2 = new Shape[] { shapes[1], shapes[3] };
shapes.Group(shapeArr1);
shapes.Group(shapeArr2);

// Save the modified workbook
workbook.Save(path + "outputGroup.xlsx", SaveFormat.Xlsx);
```

## Ungroup shapes, pictures, or other objects {#ungroup-shapes-pictures-or-other-objects}

This use case demonstrates how to use Aspose.Cells to split a group in a worksheet into individual shapes, pictures, or objects.

This is the input file: <a href="https://docs.aspose.com/cells/net/group-or-ungroup/sample2.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample2.xlsx</a>

```csharp
string path = @"YourPath\";
string name = "sample";

// Create the workbook
Workbook workbook = new Workbook(path + name + ".xlsx");
//Get shapes, images, and objects
ShapeCollection shapes = workbook.Worksheets[0].Shapes;
//Get the group 
GroupShape groupShape = (GroupShape)shapes[0];
//ungroup
shapes.Ungroup(groupShape);

// Save the modified workbook
workbook.Save(path + "outputUngroup.xlsx", SaveFormat.Xlsx);
```

## Possible Usage Scenarios {#possible-usage-scenarios}

You can change the **Version number** of an Excel file by right‑clicking the file, then selecting **Properties &gt; Details**, and then editing the **Version number** field. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/builtindocumentpropertycollection/properties/documentversion" target="_blank" rel="nofollow noopener noreferrer">**BuiltInDocumentPropertyCollection.DocumentVersion**</a> property to change it programmatically using Aspose.Cells APIs.

## Specify Document Version of the Excel File using BuiltIn Document Properties {#specify-document-version-of-the-excel-file-using-builtin-document-properties}

The following sample code creates a workbook and changes its built‑in document properties, including Title, Author(s), and the Version number. Please see the <a href="https://docs.aspose.com/cells/net/specify-document-version-of-the-excel-file-using-builtin-document-properties/64716811.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated by the code and a screenshot that shows the modified Version number using the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/builtindocumentpropertycollection/properties/documentversion" target="_blank" rel="nofollow noopener noreferrer">**BuiltInDocumentPropertyCollection.DocumentVersion**</a> property.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create workbook object
Workbook wb = new Workbook();

//Access built-in document property collection
Aspose.Cells.Properties.BuiltInDocumentPropertyCollection bdpc = wb.BuiltInDocumentProperties;

//Set the title
bdpc.Title = "Aspose File Format APIs";

//Set the author
bdpc.Author = "Aspose APIs Developers";

//Set the document version
bdpc.DocumentVersion = "Aspose.Cells Version - 18.3";

//Save the workbook in xlsx format
wb.Save("outputSpecifyDocumentVersionOfExcelFile.xlsx", SaveFormat.Xlsx);
```

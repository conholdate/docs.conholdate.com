## Convert Excel Workbook to JSON {#convert-excel-workbook-to-json}

No need to wonder how to convert an Excel workbook to JSON, because Aspose.Cells for .NET provides the best solution. The Aspose.Cells API provides support for converting spreadsheets to JSON format. To export the workbook to JSON, pass <a href="https://reference.aspose.com/cells/net/aspose.cells/saveformat" target="_blank" rel="nofollow noopener noreferrer">**SaveFormat.Json**</a> as the second parameter of <a href="https://reference.aspose.com/cells/net/aspose.cells.workbook/save/methods/3" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Save**</a> method. You may also use <a href="https://reference.aspose.com/cells/net/aspose.cells/JsonSaveoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonSaveOptions**</a> class to specify additional settings for exporting a worksheet to JSON.

The following code example demonstrates exporting an Excel workbook to JSON. Please see the code to convert <a href="https://docs.aspose.com/cells/net/convert-excel-to-json/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">source file</a> to the JSON file generated by the code for reference.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load your source workbook
Workbook workbook = new Workbook("sample.xlsx");

//Convert the workbook to json file.
workbook.Save("sample_out.json");
```

The following code example, which uses the JsonSaveOptions class to specify additional settings, demonstrates exporting an Excel workbook to JSON. Please see the code to convert <a href="https://docs.aspose.com/cells/net/convert-excel-to-json/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">source file</a> to the JSON file generated by the code for reference.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create an options of saving the file.
JsonSaveOptions options = new JsonSaveOptions();

//Set the exporting range.
options.ExportArea = CellArea.CreateCellArea("B1", "C4");
            
//Load your source workbook
Workbook workbook = new Workbook("sample.xlsx");

//Convert the workbook to json file.
workbook.Save("sample_out.json", options);
```

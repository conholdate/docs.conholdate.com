## Get Range with External Links {#get-range-with-external-links}

Often, Excel files access data from other Excel files using external links. Aspose.Cells provides a way to retrieve these external links using the <a href="https://reference.aspose.com/cells/net/aspose.cells/name/methods/getreferredareas" target="_blank" rel="nofollow noopener noreferrer">**Name.GetReferredAreas**</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/name/methods/getreferredareas" target="_blank" rel="nofollow noopener noreferrer">**Name.GetReferredAreas**</a> method returns an array of type <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea" target="_blank" rel="nofollow noopener noreferrer">**ReferredArea**</a>. The <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea" target="_blank" rel="nofollow noopener noreferrer">**ReferredArea**</a> class provides an <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/externalfilename" target="_blank" rel="nofollow noopener noreferrer">**ExternalFileName**</a> property which returns the name of the external file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea" target="_blank" rel="nofollow noopener noreferrer">**ReferredArea**</a> class exposes the following members.

- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/endcolumn" target="_blank" rel="nofollow noopener noreferrer">**EndColumn**</a>: The end column of the area
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/endrow" target="_blank" rel="nofollow noopener noreferrer">**EndRow**</a>: The end row of the area
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/externalfilename" target="_blank" rel="nofollow noopener noreferrer">**ExternalFileName**</a>: Get the external file name if this is an external reference
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/isarea" target="_blank" rel="nofollow noopener noreferrer">**IsArea**</a>: Indicates whether this is an area
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/isexternallink" target="_blank" rel="nofollow noopener noreferrer">**IsExternalLink**</a>: Indicates whether this is an external link
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/sheetname" target="_blank" rel="nofollow noopener noreferrer">**SheetName**</a>: Indicates which sheet this reference is in
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/startcolumn" target="_blank" rel="nofollow noopener noreferrer">**StartColumn**</a>: The start column of the area
- <a href="https://reference.aspose.com/cells/net/aspose.cells/referredarea/properties/startrow" target="_blank" rel="nofollow noopener noreferrer">**StartRow**</a>: The start row of the area

The sample code below demonstrates how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/name/methods/getreferredareas" target="_blank" rel="nofollow noopener noreferrer">**Name.GetReferredAreas**</a> method to retrieve ranges with external links.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Load source Excel file
Workbook workbook = new Workbook(sourceDir + "SampleExternalReferences.xlsx");

foreach (Name namedRange in workbook.Worksheets.Names)
{
    ReferredArea[] referredAreas = namedRange.GetReferredAreas(true);
    if (referredAreas != null)
    {
        for (int i = 0; i < referredAreas.Length; i++)
        {
            ReferredArea referredArea = referredAreas[i];
            // Print the data in Referred Area
            Console.WriteLine("IsExternalLink: " + referredArea.IsExternalLink);
            Console.WriteLine("IsArea: " + referredArea.IsArea);
            Console.WriteLine("SheetName: " + referredArea.SheetName);
            Console.WriteLine("ExternalFileName: " + referredArea.ExternalFileName);
            Console.WriteLine("StartColumn: " + referredArea.StartColumn);
            Console.WriteLine("StartRow: " + referredArea.StartRow);
            Console.WriteLine("EndColumn: " + referredArea.EndColumn);
            Console.WriteLine("EndRow: " + referredArea.EndRow);
        }
    }
}
```

HTML can have a variety of tag formats for empty tags, such as `<td></td>` or `<td/>`. Aspose.Cells now supports both of these formats, whereas earlier it only supported `<td></td>`‑style tags. This feature can be tested by converting the attached sample HTML file to an Excel file. The sample HTML file and output Excel file can be downloaded from the following links for testing.

<a href="https://docs.aspose.com/cells/net/recognise-self-closing-tags/sampleSelfClosingTags" target="_blank" rel="nofollow noopener noreferrer">sampleSelfClosingTags.html</a>

<a href="https://docs.aspose.com/cells/net/recognise-self-closing-tags/73990156.xlsx" target="_blank" rel="nofollow noopener noreferrer">outsampleSelfClosingTags.xlsx</a>

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
// Set Html load options and keep precision true
HtmlLoadOptions loadOptions = new HtmlLoadOptions(LoadFormat.Html);

// Load sample source file
Workbook wb = new Workbook(sourceDir + "sampleSelfClosingTags.html", loadOptions);

// Save the workbook
wb.Save(outputDir + "outsampleSelfClosingTags.xlsx");
```

:::info
This document describes the changes to the Aspose.Cells API from version 8.2.1 to 8.2.2 that may be of interest to module/application developers.
:::

## Added APIs {#added-apis}

### Added BuiltInDocumentPropertyCollection.Version Property {#added-builtindocumentpropertycollectionversion-property}

The new property Version has been added to the BuiltInDocumentPropertyCollection class in order to allow developers to retrieve the version of the application that created a given spreadsheet.

:::info
Please check the detailed article [Get Version of the Application that Created the Spreadsheet](/net/cells/get-the-version-number-of-the-application-that-created-the-excel-document/) for more information.
:::

**C#**

```csharp
 var book = new Workbook("sample.xlsx");

var properties = book.BuiltInDocumentProperties;

Console.WriteLine(properties.Version);
```

### Added Chart.Worksheet Property {#added-chartworksheet-property}

Before the release of Aspose.Cells 8.2.2, it was not possible to retrieve the Worksheet instance that a Chart object holds. Aspose.Cells 8.2.2 has filled this gap by providing the Chart.Worksheet property.

:::info
Please check the detailed article [Get Worksheet of the Chart](/net/cells/get-worksheet-of-the-chart/) for more information.
:::

**C#**

```csharp
 var workbook = new Workbook("sample.xlsx");

var chart  = workbook.Worksheets[0].Charts[0];

var  worksheet = chart.Worksheet;

Console.WriteLine("Chart's Sheet Name: " + worksheet.Name);
```

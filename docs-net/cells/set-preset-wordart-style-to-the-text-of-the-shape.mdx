## Possible Usage Scenarios {#possible-usage-scenarios}

You can apply a preset WordArt style to the text of the shape using Aspose.Cells. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells/fontsetting/methods/setwordartstyle" target="_blank" rel="nofollow noopener noreferrer">FontSetting.SetWordArtStyle()</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.texts/fontsettingcollection/methods/setwordartstyle" target="_blank" rel="nofollow noopener noreferrer">FontSettingCollection.SetWordArtStyle()</a> methods for this purpose.

## Set a preset WordArt style to the text of the shape {#set-a-preset-wordart-style-to-the-text-of-the-shape}

The following sample code creates a text box with some text and then sets a preset WordArt style for its text using <a href="https://reference.aspose.com/cells/net/aspose.cells/fontsetting/methods/setwordartstyle" target="_blank" rel="nofollow noopener noreferrer">FontSetting.SetWordArtStyle()</a> method. This is how the <a href="https://docs.aspose.com/cells/net/set-preset-wordart-style-to-the-text-of-the-shape/5115445.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> looks in Microsoft Excel.

![todo:image_alt_text](/net/cells/images/fd95d0a58aa31199-set-preset-wordart-style-to-the-text-of-the-shape_1.png)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
// Create workbook object
Workbook workbook = new Workbook();

// Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Create a textbox with some text
TextBox textbox = worksheet.Shapes.AddTextBox(0, 0, 0, 0, 100, 700);
textbox.Text = "Aspose File Format APIs";
textbox.Font.Size = 44;

// Sets preset WordArt style to the text of the shape.
FontSetting fntSetting = textbox.GetRichFormattings()[0] as FontSetting;
fntSetting.SetWordArtStyle(PresetWordArtStyle.WordArtStyle3);

// Save the workbook in xlsx format
workbook.Save(outputDir + "outputSetPresetWordArtStyle.xlsx");
```

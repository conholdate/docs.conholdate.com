## Introduction {#introduction}

Microsoft Excel provides the ability to add properties to spreadsheet files. These document properties provide useful information and are divided into 2 categories as detailed below.

- System-defined (built‑in) properties: Built‑in properties contain general information about the document like document title, author name, document statistics and so on.
- User-defined (custom) properties: Custom properties defined by the end user in the form of name‑value pairs.

:::info
The most important point to know about built‑in and custom properties is that built‑in properties can be accessed and modified, but not created or removed. However, custom properties can be created and managed.
:::

## How to Work with Document Properties Using Aspose.Cells {#how-to-work-with-document-properties-using-asposecells}

Developers can dynamically manage the document properties using the Aspose.Cells APIs. This feature helps developers to store useful information along with the file, such as when the file was received, processed, time‑stamped, and so on.

:::info
Aspose.Cells for .NET directly writes the information about API and version number in output documents. For example, upon rendering the document to PDF, Aspose.Cells for .NET populates **Application** field with the value 'Aspose.Cells' and **PDF Producer** field with the value, e.g., 'Aspose.Cells v17.9'.

Please note that you cannot instruct Aspose.Cells for .NET to change or remove this information from output documents.
:::

### How to Access Document Properties {#how-to-access-document-properties}

Aspose.Cells APIs support both types of document properties, built‑in and custom. Aspose.Cells' <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class represents an Excel file and, like an Excel file, the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class can contain multiple worksheets, each represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class, whereas the collection of worksheets is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> class.

Use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> to access the file's document properties as described below.

- To access built‑in document properties, use <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/properties/builtindocumentproperties" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection.BuiltInDocumentProperties**</a>.
- To access custom document properties, use <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/properties/customdocumentproperties" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection.CustomDocumentProperties**</a>.

Both the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/properties/builtindocumentproperties" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection.BuiltInDocumentProperties**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/properties/customdocumentproperties" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection.CustomDocumentProperties**</a> return an instance of <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentpropertycollection" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Properties.DocumentPropertyCollection**</a>. This collection contains <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Properties.DocumentProperty**</a> objects, each of which represents a single built‑in or custom document property.

It is up to the application requirement how to access a property, that is, by using the index or name of the property from the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentpropertycollection" target="_blank" rel="nofollow noopener noreferrer">**DocumentPropertyCollection**</a> as demonstrated in the example below.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a Workbook object
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "sample-document-properties.xlsx");

// Retrieve a list of all custom document properties of the Excel file
Aspose.Cells.Properties.DocumentPropertyCollection customProperties = workbook.Worksheets.CustomDocumentProperties;

// Accessing a custom document property by using the property name
Aspose.Cells.Properties.DocumentProperty customProperty1 = customProperties["ContentTypeId"];
Console.WriteLine(customProperty1.Name + " " + customProperty1.Value);

// Accessing the same custom document property by using the property index
Aspose.Cells.Properties.DocumentProperty customProperty2 = customProperties[0];
Console.WriteLine(customProperty2.Name + " " + customProperty2.Value);
```

The <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Properties.DocumentProperty**</a> class allows you to retrieve the name, value, and type of the document property:

- To get the property name, use <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/name" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.Name**</a>.
- To get the property value, use <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/value" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.Value**</a>. <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/value" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.Value**</a> returns the value as an object.
- To get the property type, use <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/type" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.Type**</a>. This returns one of the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/propertytype" target="_blank" rel="nofollow noopener noreferrer">**PropertyType**</a> enumeration values. After you get the property type, use one of the **DocumentProperty.ToXXX** methods to obtain the value of the appropriate type instead of using <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/value" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.Value**</a>. The **DocumentProperty.ToXXX** methods are described in the table below.

:::info
The <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty**</a> class also provides a set of methods that return the values of other data types.
:::

### How to Add or Remove Custom Document Properties {#how-to-add-or-remove-custom-document-properties}

As we described earlier, developers can't add or remove built‑in properties because these properties are system‑defined, but it is possible to add or remove custom properties because these are user‑defined.

### How to Add Custom Properties {#how-to-add-custom-properties}

Aspose.Cells APIs expose the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/customdocumentpropertycollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**Add**</a> method for the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/customdocumentpropertycollection" target="_blank" rel="nofollow noopener noreferrer">**CustomDocumentPropertyCollection**</a> class in order to add custom properties to the collection. The <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/customdocumentpropertycollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**Add**</a> method adds the property to the Excel file and returns a reference for the new document property as an <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Properties.DocumentProperty**</a> object.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a Workbook object
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "sample-document-properties.xlsx");

// Retrieve a list of all custom document properties of the Excel file
Aspose.Cells.Properties.CustomDocumentPropertyCollection customProperties = workbook.Worksheets.CustomDocumentProperties;

// Adding a custom document property to the Excel file
Aspose.Cells.Properties.DocumentProperty publisher = customProperties.Add("Publisher", "Aspose");

// Saving resultant spreadsheet
workbook.Save(dataDir + "out_sample-document-properties.xlsx");
```

### How to Configure "Link to content" Custom Property {#how-to-configure-link-to-content-custom-property}

To create a custom property linked to the content of a given range, call the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/customdocumentpropertycollection/methods/addlinktocontent" target="_blank" rel="nofollow noopener noreferrer">**CustomDocumentPropertyCollection.AddLinkToContent**</a> method and pass the property name and source. You can check whether a property is configured as linked to content using the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/islinkedtocontent" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty.IsLinkedToContent**</a> property. Moreover, it is also possible to get the source range using the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty/properties/source" target="_blank" rel="nofollow noopener noreferrer">**Source**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentproperty" target="_blank" rel="nofollow noopener noreferrer">**DocumentProperty**</a> class.

We use a simple template Microsoft Excel file in the example. The workbook has a defined named range labeled **MyRange** which refers to a cell value.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate an object of Workbook
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "sample-document-properties.xlsx");

// Retrieve a list of all custom document properties of the Excel file
Aspose.Cells.Properties.CustomDocumentPropertyCollection customProperties = workbook.Worksheets.CustomDocumentProperties;

// Add link to content.
customProperties.AddLinkToContent("Owner", "MyRange");

// Accessing the custom document property by using the property name
Aspose.Cells.Properties.DocumentProperty customProperty1 = customProperties["Owner"];

// Check whether the property is lined to content
bool islinkedtocontent = customProperty1.IsLinkedToContent;

// Get the source for the property
string source = customProperty1.Source;

// Save the file
workbook.Save(dataDir + "out_sample-document-properties.xlsx");
```

### How to Remove Custom Properties {#how-to-remove-custom-properties}

To remove custom properties using Aspose.Cells, call the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/documentpropertycollection/methods/remove" target="_blank" rel="nofollow noopener noreferrer">**DocumentPropertyCollection.Remove**</a> method and pass the name of the document property to be removed.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a Workbook object
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "sample-document-properties.xlsx");

// Retrieve a list of all custom document properties of the Excel file
Aspose.Cells.Properties.DocumentPropertyCollection customProperties = workbook.Worksheets.CustomDocumentProperties;

// Removing a custom document property
customProperties.Remove("Publisher");

// Save the file
workbook.Save(dataDir + "out_sample-document-properties.xlsx");
```

## How to monitor a running program {#how-to-monitor-a-running-program}

The following sample code shows how to monitor a running program. This code can be used to monitor the execution of Workbook‑related code. Simply use the <a href="https://reference.aspose.com/cells/net/aspose.cells/systemtimeinterruptmonitor/" target="_blank" rel="nofollow noopener noreferrer">SystemTimeInterruptMonitor</a> class to create a monitoring object, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions/interruptmonitor/" target="_blank" rel="nofollow noopener noreferrer">SetInterruptMonitor</a> function to add it to the <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> parameters, and then use the <a href="https://reference.aspose.com/cells/net/aspose.cells/systemtimeinterruptmonitor/startmonitor/" target="_blank" rel="nofollow noopener noreferrer">StartMonitor</a> function to set the expected interruption time (in milliseconds). If the running time of the monitored code exceeds the expected time, the program will be interrupted and an exception will be thrown.

## Sample Code {#sample-code}

```csharp
SystemTimeInterruptMonitor monitor = new SystemTimeInterruptMonitor(false);
LoadOptions lopts = new LoadOptions();
lopts.InterruptMonitor = monitor;
monitor.StartMonitor(1000); //time limit is 1 second
Workbook wb = new Workbook("Large.xlsx", lopts);
//if the time cost of loading the template file exceeds one second, interruption will be required and exception will be thrown here
//otherwise starts to monitor the save procedure
monitor.StartMonitor(1500); //time limit is 1.5 seconds
wb.Save("result.xlsx");
```

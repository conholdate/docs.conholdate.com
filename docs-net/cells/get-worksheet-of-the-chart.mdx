:::info
Sometimes you want to access a worksheet from a chart's reference. Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/properties/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Chart.Worksheet**</a> property, which returns the reference to the worksheet that contains the chart.
:::

The following example shows how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/properties/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Chart.Worksheet**</a> property. The code first prints the name of the worksheet, then accesses the first chart on the worksheet. It then prints the worksheet name again, using the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/properties/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Chart.Worksheet**</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create workbook from sample Excel file
Workbook workbook = new Workbook(dataDir + "sample.xlsx");

// Access first worksheet of the workbook
Worksheet worksheet = workbook.Worksheets[0];

// Print worksheet name
Console.WriteLine("Sheet Name: " + worksheet.Name);

// Access the first chart inside this worksheet
Chart chart = worksheet.Charts[0];

// Access the chart's sheet and display its name again
Console.WriteLine("Chart's Sheet Name: " + chart.Worksheet.Name);
```

Below is the console output produced by the sample code. As you can see, it prints the same worksheet name both times.

```java
Sheet Name: Portfolio

Chart's Sheet Name: Portfolio
```

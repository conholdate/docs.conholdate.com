:::info
Sometimes you need to insert a picture from the web (http\://) into a worksheet. To do so, specify the picture's URL and the picture will be downloaded every time the spreadsheet is opened in Microsoft Excel. The image is not physically embedded into the Excel document, but points to a web resource.
:::

## Using Microsoft Excel {#using-microsoft-excel}

In Microsoft Excel (for example, 2007):

1. Click the **Insert** menu and select **Picture**.
2. Specify the web address for the picture in the Insert Picture dialog.

## Using Aspose.Cells for .NET {#using-asposecells-for-net}

Aspose.Cells for .NET supports adding a linked image using the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shapecollection/methods/addlinkedpicture" target="_blank" rel="nofollow noopener noreferrer">**ShapeCollection.AddLinkedPicture(int upperLeftRow, int upperLeftColumn, int heightPixels, int widthPixels, string sourceFullName)**</a>. The method returns a <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/picture" target="_blank" rel="nofollow noopener noreferrer">**Picture**</a> object.

The following example shows how to add a linked picture from a web address to a worksheet.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
// Instantiate a new Workbook.
Workbook workbook = new Workbook();
// Insert a linked picture (from Web Address) to B2 Cell.
Aspose.Cells.Drawing.Picture pic = workbook.Worksheets[0].Shapes.AddLinkedPicture(1, 1, 100, 100, "http:// Www.aspose.com/Images/aspose-logo.jpg");
// Set the height and width of the inserted image.
pic.HeightInch = 1.04;
pic.WidthInch = 2.6;
// Save the Excel file.
workbook.Save(dataDir + "outLinkedPicture.out.xlsx");
```

Microsoft Excel's page setup settings provide several print options (also referred to as sheet options) that allow users to control how worksheet pages are printed.
:::

## Setting Print Options {#setting-print-options}

These print options allow users to:

- Select a specific print area on a worksheet.
- Print titles.
- Print gridlines.
- Print row/column headings.
- Achieve draft quality.
- Print comments.
- Print cell errors.
- Define page ordering.

Aspose.Cells supports all the print options offered by Microsoft Excel, and developers can easily configure these options for worksheets using the properties offered by the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class. How these properties are used is discussed below in more detail.

### Set Print Area {#set-print-area}

By default, the print area incorporates all areas of the worksheet that contain data. Developers can establish a specific print area for the worksheet.

To select a specific print area, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printarea" target="_blank" rel="nofollow noopener noreferrer">**PrintArea**</a> property. Assign a cell range that defines the print area to this property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the PageSetup of the worksheet
PageSetup pageSetup = workbook.Worksheets[0].PageSetup;

// Specifying the cells range (from A1 cell to T35 cell) of the print area
pageSetup.PrintArea = "A1:T35";

// Save the workbook.
workbook.Save(dataDir + "SetPrintArea_out.xls");
```

### Set Print Titles {#set-print-titles}

Aspose.Cells allows you to designate row and column headers to repeat on all pages of a printed worksheet. To do so, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printtitlecolumns" target="_blank" rel="nofollow noopener noreferrer">**PrintTitleColumns**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printtitlerows" target="_blank" rel="nofollow noopener noreferrer">**PrintTitleRows**</a> properties.

The rows or columns that will be repeated are defined by passing their row or column numbers. For example, rows are defined as $1:$2 and columns are defined as $A:$B.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the PageSetup of the worksheet
Aspose.Cells.PageSetup pageSetup = workbook.Worksheets[0].PageSetup;

// Defining column numbers A & B as title columns
pageSetup.PrintTitleColumns = "$A:$B";

// Defining row numbers 1 & 2 as title rows
pageSetup.PrintTitleRows = "$1:$2";

// Save the workbook.
workbook.Save(dataDir + "SetPrintTitle_out.xls");
```

### Set Other Print Options {#set-other-print-options}

The <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class also provides several other properties to set general print options as follows:

- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printgridlines" target="_blank" rel="nofollow noopener noreferrer">**PrintGridlines**</a>: a Boolean property that defines whether to print gridlines or not.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printheadings" target="_blank" rel="nofollow noopener noreferrer">**PrintHeadings**</a>: a Boolean property that defines whether to print row and column headings or not.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/blackandwhite" target="_blank" rel="nofollow noopener noreferrer">**BlackAndWhite**</a>: a Boolean property that defines whether to print the worksheet in black‑and‑white mode or not.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printcomments" target="_blank" rel="nofollow noopener noreferrer">**PrintComments**</a>: defines whether to display the print comments on the worksheet or at the end of the worksheet.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printdraft" target="_blank" rel="nofollow noopener noreferrer">**PrintDraft**</a>: a Boolean property that defines whether to print the sheet without graphics.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printerrors" target="_blank" rel="nofollow noopener noreferrer">**PrintErrors**</a>: defines whether to print cell errors as displayed, blank, dash, or N/A.

To set the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printcomments" target="_blank" rel="nofollow noopener noreferrer">**PrintComments**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printerrors" target="_blank" rel="nofollow noopener noreferrer">**PrintErrors**</a> properties, Aspose.Cells also provides two enumerations, <a href="https://reference.aspose.com/cells/net/aspose.cells/printcommentstype" target="_blank" rel="nofollow noopener noreferrer">**PrintCommentsType**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/printerrorstype" target="_blank" rel="nofollow noopener noreferrer">**PrintErrorsType**</a>, that contain predefined values to be assigned to these properties respectively.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the PageSetup of the worksheet
PageSetup pageSetup = workbook.Worksheets[0].PageSetup;

// Allowing to print gridlines
pageSetup.PrintGridlines = true;

// Allowing to print row/column headings
pageSetup.PrintHeadings = true;

// Allowing to print worksheet in black & white mode
pageSetup.BlackAndWhite = true;

// Allowing to print comments as displayed on worksheet
pageSetup.PrintComments = PrintCommentsType.PrintInPlace;

// Allowing to print worksheet with draft quality
pageSetup.PrintDraft = true;

// Allowing to print cell errors as N/A
pageSetup.PrintErrors = PrintErrorsType.PrintErrorsNA;

// Save the workbook.
workbook.Save(dataDir + "OtherPrintOptions_out.xls");
```

### Set Page Order {#set-page-order}

The <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/order" target="_blank" rel="nofollow noopener noreferrer">**Order**</a> property that is used to order multiple pages of your worksheet for printing. There are two possibilities for ordering the pages, as follows:

- **Down then over:** prints all the pages down before printing any pages to the right.
- **Over then down:** prints pages left to right before printing the pages below.

Aspose.Cells provides an enumeration, <a href="https://reference.aspose.com/cells/net/aspose.cells/printordertype" target="_blank" rel="nofollow noopener noreferrer">**PrintOrderType**</a>, that contains all predefined order types.

The predefined values of the <a href="https://reference.aspose.com/cells/net/aspose.cells/printordertype" target="_blank" rel="nofollow noopener noreferrer">**PrintOrderType**</a> enumeration are listed below.

workbook.Save(dataDir + "SetPageOrder_out.xls");

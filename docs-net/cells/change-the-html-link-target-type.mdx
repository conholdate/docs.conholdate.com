:::info
Aspose.Cells allows you to change the HTML link target type. **An** HTML link looks like this:

```java
<a href="http://www.aspose.com/" target="_self">
```

As you can see, the target attribute in the above HTML link is **\_self**. You can control this target attribute using the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/linktargettype" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.LinkTargetType**</a> property. This property takes the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmllinktargettype" target="_blank" rel="nofollow noopener noreferrer">**HtmlLinkTargetType**</a> enum which has the following values.

- HtmlLinkTargetType.Blank
- HtmlLinkTargetType.Parent
- HtmlLinkTargetType.Self
- HtmlLinkTargetType.Top
  :::

The following code illustrates the usage of <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/linktargettype" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.LinkTargetType**</a> property. It changes the link target type to **blank**. By default, it is the **parent**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
string inputPath = dataDir + "Sample1.xlsx";
string outputPath = dataDir + "Output.out.html";

Workbook workbook = new Workbook(dataDir + "Sample1.xlsx");

HtmlSaveOptions opts = new HtmlSaveOptions();
opts.LinkTargetType = HtmlLinkTargetType.Self;

workbook.Save(outputPath, opts);
Console.WriteLine("File saved: {0}", outputPath);
```

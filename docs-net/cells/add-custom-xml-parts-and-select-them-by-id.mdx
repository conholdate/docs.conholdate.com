## Possible Usage Scenarios {#possible-usage-scenarios}

Custom XML Parts are the XML data that are stored inside Microsoft Excel documents and are used by applications that work with them. There is no direct way of adding them using the Microsoft Excel UI at the moment. However, you can add them programmatically in various ways, e.g., using VSTO or using Aspose.Cells, etc. Please use **\[Workbook.CustomXmlParts.Add()]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/add" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/add</a>) method if you want to add a Custom XML Part using the Aspose.Cells API. You can also set its ID using the **\[CustomXmlPart.ID]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpart/properties/id" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpart/properties/id</a>) property. Similarly, if you want to select a Custom XML Part by ID, you can use **\[Workbook.CustomXmlParts.SelectByID()]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/selectbyid" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/selectbyid</a>) method.

## Add Custom XML Parts and Select Them by ID {#add-custom-xml-parts-and-select-them-by-id}

The following sample code first adds four Custom XML Parts using **\[Workbook.CustomXmlParts.Add()]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/add" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/add</a>) method. It then sets their IDs using the **\[CustomXmlPart.ID]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpart/properties/id" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpart/properties/id</a>) property. Finally, it finds or selects one of the added Custom XML Parts using **\[Workbook.CustomXmlParts.SelectByID()]**(<a href="https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/selectbyid" target="_blank" rel="nofollow noopener noreferrer">https://reference.aspose.com/cells/net/aspose.cells.markup/customxmlpartcollection/methods/selectbyid</a>) method. Please also see the console output of the code given below for reference.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Create empty workbook.
Workbook wb = new Workbook();

// Some data in the form of byte array.
// Please use correct XML and Schema instead.
byte[] btsData = new byte[] { 1, 2, 3 };
byte[] btsSchema = new byte[] { 1, 2, 3 };

// Create four custom xml parts.
wb.CustomXmlParts.Add(btsData, btsSchema);
wb.CustomXmlParts.Add(btsData, btsSchema);
wb.CustomXmlParts.Add(btsData, btsSchema);
wb.CustomXmlParts.Add(btsData, btsSchema);

// Assign ids to custom xml parts.
wb.CustomXmlParts[0].ID = "Fruit";
wb.CustomXmlParts[1].ID = "Color";
wb.CustomXmlParts[2].ID = "Sport";
wb.CustomXmlParts[3].ID = "Shape";

// Specify search custom xml part id.
String srchID = "Fruit";
srchID = "Color";
srchID = "Sport";

// Search custom xml part by the search id.
Aspose.Cells.Markup.CustomXmlPart cxp = wb.CustomXmlParts.SelectByID(srchID);

// Print the found or not found message on console.
if (cxp == null)
{
    Console.WriteLine("Not Found: CustomXmlPart ID " + srchID);
}
else
{
    Console.WriteLine("Found: CustomXmlPart ID " + srchID);
}

Console.WriteLine("AddCustomXMLPartsAndSelectThemByID executed successfully.");
```

By default, Aspose.Cells **saves** all **visible** worksheets in a workbook to a **PDF** file. With the **<a href="https://reference.aspose.com/cells/net/aspose.cells/paginatedsaveoptions/sheetset/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions.SheetSet</a>** option, you can save specified worksheets to a PDF file, e.g., you can save the active worksheet to PDF, save all worksheets (both visible and hidden) to PDF, or save custom multiple worksheets to PDF.

## Save Active Worksheet to PDF {#save-active-worksheet-to-pdf}

If you want to export only the active sheet to PDF, you can achieve this by passing **<a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetset/active/" target="_blank" rel="nofollow noopener noreferrer">SheetSet.Active</a>** to **<a href="https://reference.aspose.com/cells/net/aspose.cells/paginatedsaveoptions/sheetset/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions.SheetSet</a>** option.

The sheet `Sheet2` is the **active** sheet of the source file <a href="https://docs.aspose.com/cells/net/save-specified-worksheets-to-pdf/sheetset-example.xlsx" target="_blank" rel="nofollow noopener noreferrer">sheetset-example.xlsx</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Open the template excel file
Workbook wb = new Workbook("sheetset-example.xlsx");

// Set active sheet to output
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.SheetSet = SheetSet.Active;

// Save the pdf file with PdfSaveOptions
wb.Save("output.pdf", pdfSaveOptions);
```

## Save All Worksheets to PDF {#save-all-worksheets-to-pdf}

**<a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetset/visible/" target="_blank" rel="nofollow noopener noreferrer">SheetSet.Visible</a>** indicates visible sheets in a workbook, and **<a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetset/all/" target="_blank" rel="nofollow noopener noreferrer">SheetSet.All</a>** indicates all sheets, including both visible sheets and hidden/invisible sheets in a workbook. If you want to export all sheets to PDF, you can simply pass **<a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetset/all/" target="_blank" rel="nofollow noopener noreferrer">SheetSet.All</a>** to **<a href="https://reference.aspose.com/cells/net/aspose.cells/paginatedsaveoptions/sheetset/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions.SheetSet</a>** option.

The source file <a href="https://docs.aspose.com/cells/net/save-specified-worksheets-to-pdf/sheetset-example.xlsx" target="_blank" rel="nofollow noopener noreferrer">sheetset-example.xlsx</a> contains all four sheets with hidden sheet `Sheet3`.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Open the template excel file
Workbook wb = new Workbook("sheetset-example.xlsx");

// Set all sheets to output
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.SheetSet = SheetSet.All;

// Save the pdf file with PdfSaveOptions
wb.Save("output.pdf", pdfSaveOptions);
```

## Save Specified Worksheets to PDF {#save-specified-worksheets-to-pdf}

If you want to export desired/custom multiple sheets to PDF, you can achieve this by passing multiple sheet indices to the **<a href="https://reference.aspose.com/cells/net/aspose.cells/paginatedsaveoptions/sheetset/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions.SheetSet</a>** option.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Open the template excel file
Workbook wb = new Workbook("sheetset-example.xlsx");

// Set custom multiple sheets(Sheet1, Sheet3) to output
SheetSet sheetSet = new SheetSet(new int[] { 0, 2 });
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.SheetSet = sheetSet;

// Save the pdf file with PdfSaveOptions
wb.Save("output.pdf", pdfSaveOptions);
```

## Reorder Worksheets to PDF {#reorder-worksheets-to-pdf}

If you want to reorder sheets (e.g., in reverse order) to PDF without modifying the source file, you can achieve this by passing **reordered** sheet indices to the **<a href="https://reference.aspose.com/cells/net/aspose.cells/paginatedsaveoptions/sheetset/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions.SheetSet</a>** option.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Open the template excel file
Workbook wb = new Workbook("sheetset-example.xlsx");

// Reorder sheets(Sheet1, Sheet2, Sheet3, Sheet4) to sheets(Sheet4, Sheet3, Sheet2, Sheet1)
SheetSet sheetSet = new SheetSet(new int[] { 3, 2, 1, 0 });
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.SheetSet = sheetSet;

// Save the pdf file with PdfSaveOptions
wb.Save("output.pdf", pdfSaveOptions);
```

:::info
If your spreadsheet contains formulas, it is best to call **<a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/calculateformula" target="_blank" rel="nofollow noopener noreferrer">Workbook.CalculateFormula()</a>** just before rendering the spreadsheet to PDF format. Doing so will ensure that the formula‑dependent values are recalculated, and the correct values are rendered in the PDF.
:::

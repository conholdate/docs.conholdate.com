## Possible Usage Scenarios {#possible-usage-scenarios}

If you want to change the absolute path of the external link data source file, then please use the **<a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/absolutepath" target="_blank" rel="nofollow noopener noreferrer">Workbook.AbsolutePath</a>** property. Initially, this property will be set to the path from where the Excel file was loaded, but you can set it to an empty string, to a local folder path, or to a remote network path. Whenever you change this property, the path of the external link data source file will also be changed.

## Change the Absolute Path of External Link Data Source File {#change-the-absolute-path-of-external-link-data-source-file}

The following sample code loads the **<a href="https://docs.aspose.com/cells/net/change-the-absolute-path-of-external-link-data-source-file/5115146.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>** which contains an external link. It first prints the external link data source, which displays the remote path. Then it removes the remote path and prints again; this time it shows the external link data source with the local path. Then it changes the **<a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/absolutepath" target="_blank" rel="nofollow noopener noreferrer">Workbook.AbsolutePath</a>** property to a local and a remote path, prints the external link data source again, and the changes are reflected in the console output.

Here is the console (or debug) output after executing the above sample code with the sample Excel file.

```java
External Link Data Source: http:\\ws874dmErit\WebFiles\Files\300\ExternalAccounts.xlsx

External Link Data Source After Removing Remote Path: D:\Downloads\ExternalAccounts.xlsx

External Link Data Source After Changing Workbook.AbsolutePath to Local Path: C:\Files\Extra\ExternalAccounts.xlsx

External Link Data Source After Changing Workbook.AbsolutePath to Remote Path: http://www.aspose.com/WebFiles/ExcelFiles/ExternalAccounts.xlsx
```

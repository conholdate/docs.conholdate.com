## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells provides an abstract class <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**DrawObjectEventHandler**</a> which has a <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler/methods/draw" target="_blank" rel="nofollow noopener noreferrer">**Draw()**</a> method. The user can implement <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**DrawObjectEventHandler**</a> and utilize the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler/methods/draw" target="_blank" rel="nofollow noopener noreferrer">**Draw()**</a> method to get the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a> and bound while rendering Excel to PDF or image. Here is a brief description of the parameters of the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler/methods/draw" target="_blank" rel="nofollow noopener noreferrer">**Draw()**</a> method.

- **drawObject**: <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a> will be initialized and returned during rendering.
- **x**: Left coordinate of <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a>.
- **y**: Top coordinate of <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a>.
- **width**: Width of <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a>.
- **height**: Height of <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a>.

If you are rendering an Excel file to PDF, you can utilize the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**DrawObjectEventHandler**</a> class with <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.DrawObjectEventHandler**</a>. Similarly, if you are rendering an Excel file to an image, you can utilize the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**DrawObjectEventHandler**</a> class with <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions.DrawObjectEventHandler**</a>.

## Get DrawObject and Bound while rendering to PDF using DrawObjectEventHandler class {#get-drawobject-and-bound-while-rendering-to-pdf-using-drawobjecteventhandler-class}

Please see the following sample code. It loads the <a href="https://docs.aspose.com/cells/net/get-drawobject-and-bound-while-rendering-to-pdf-using-drawobjecteventhandler-class/64716821.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> and saves it as <a href="https://docs.aspose.com/cells/net/get-drawobject-and-bound-while-rendering-to-pdf-using-drawobjecteventhandler-class/64716822.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF</a>. While rendering to PDF, it utilizes <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/drawobjecteventhandler" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.DrawObjectEventHandler**</a> property and captures the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a> and bound of existing cells and objects, e.g., images, etc. If the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a> type is **Cell**, it prints its bound and string value. If the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/drawobject" target="_blank" rel="nofollow noopener noreferrer">**DrawObject**</a> type is **Image**, it prints its bound and shape name. Please see the console output of the sample code given below for more help.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using Aspose.Cells.Rendering;

namespace Aspose.Cells.Examples.CSharp.Rendering
{
    class GetDrawObjectAndBoundUsingDrawObjectEventHandler
    {
        //Implement the concrete class of DrawObjectEventHandler
        class clsDrawObjectEventHandler : DrawObjectEventHandler
        {
            public override void Draw(DrawObject drawObject, float x, float y, float width, float height)
            {
                Console.WriteLine("");

                //Print the coordinates and the value of Cell object
                if (drawObject.Type == DrawObjectEnum.Cell)
                {
                    Console.WriteLine("[X]: " + x + " [Y]: " + y + " [Width]: " + width + " [Height]: " + height + " [Cell Value]: " + drawObject.Cell.StringValue);
                }

                //Print the coordinates and the shape name of Image object
                if (drawObject.Type == DrawObjectEnum.Image)
                {
                    Console.WriteLine("[X]: " + x + " [Y]: " + y + " [Width]: " + width + " [Height]: " + height + " [Shape Name]: " + drawObject.Shape.Name);
                }

                Console.WriteLine("----------------------");
            }
        }

        public static void Run()
        {
            //Load sample Excel file
            Workbook wb = new Workbook("sampleGetDrawObjectAndBoundUsingDrawObjectEventHandler.xlsx");

            //Specify Pdf save options
            PdfSaveOptions opts = new PdfSaveOptions();

            //Assign the instance of DrawObjectEventHandler class
            opts.DrawObjectEventHandler = new clsDrawObjectEventHandler();

            //Save to Pdf format with Pdf save options
            wb.Save("outputGetDrawObjectAndBoundUsingDrawObjectEventHandler.pdf", opts);
        }
    }
}
```

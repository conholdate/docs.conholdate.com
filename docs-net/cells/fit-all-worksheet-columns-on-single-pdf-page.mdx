:::info
Sometimes you want to generate a PDF file that fits all of a worksheet's columns onto one page. The <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/allcolumnsinonepagepersheet" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.AllColumnsInOnePagePerSheet**</a> property provides this feature in a very easy-to-use manner. Complex calculations such as the height and width of the output PDF are handled internally and are based on the data in the worksheet.
:::

## Fit Worksheet Columns on Single PDF Page {#fit-worksheet-columns-on-single-pdf-page}

<a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/allcolumnsinonepagepersheet" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.AllColumnsInOnePagePerSheet**</a> ensures that all columns in a worksheet are rendered to a single PDF page, although rows may expand to several pages depending on the data in the worksheet.

The sample code below shows how to use <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/allcolumnsinonepagepersheet" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.AllColumnsInOnePagePerSheet**</a> property to render a large worksheet of 100 columns.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
// Create and initialize an instance of Workbook
Workbook book = new Workbook(dataDir + "TestBook.xlsx");
// Create and initialize an instance of PdfSaveOptions
PdfSaveOptions saveOptions = new PdfSaveOptions();
// Set AllColumnsInOnePagePerSheet to true
saveOptions.AllColumnsInOnePagePerSheet = true;
// Save Workbook to PDF fromart by passing the object of PdfSaveOptions
dataDir = dataDir+ "output.out.pdf";
book.Save(dataDir, saveOptions);
```

:::info
When a given worksheet has many columns, the rendered PDF file may show the content at a very small size. It is still readable when scaled up in a viewing application such as Acrobat Reader.
:::

:::info
If your spreadsheet contains formulas, it is best to call <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/calculateformula" target="_blank" rel="nofollow noopener noreferrer">**Workbook.CalculateFormula()**</a> just before rendering the spreadsheet to PDF format. Doing so will ensure that the formula‑dependent values are recalculated, and the correct values are rendered in the PDF.
:::

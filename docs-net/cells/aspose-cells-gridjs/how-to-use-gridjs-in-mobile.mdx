## Use GridJs on a mobile device {#use-gridjs-on-a-mobile-device}

You can use GridJs smoothly on the mobile device.

GridJs can adapt to the mobile screen.

Run the [demo of GridJs](https://github.com/aspose-cells/Aspose.Cells.Grid-for-.NET/tree/master/Examples_GridJs "demo of GridJs ")

The default port of the demo project is 24262.

You need to access the page via IP on the mobile terminal <a href="http://localhost:24262/GridJs2/List" target="_blank" rel="nofollow noopener noreferrer">http://localhost:24262/GridJs2/List</a>.

You can use a small tool such as iisexpress-proxy.

Install with the following command:

*npm install -g iisexpress-proxy*

Run the command to complete the port mapping:

*iisexpress-proxy 24262 to 82*

![todo:iisexpress command](/net/cells/images/87c2042934326192-iisproxy_port_map.png)

Then we can open the demo web page in the mobile browser.

Navigate to the page <a href="http://yourip:82/GridJs2/List" target="_blank" rel="nofollow noopener noreferrer">http://yourip:82/GridJs2/List</a> and select a file to open.

![todo:the screen navagation on mobile](/net/cells/images/667cad7b34c80464-gridjs_edit_on_mobile.png)

Then you can perform edit operations as on a PC device.

## Implement Custom Calculation Engine {#implement-custom-calculation-engine}

Aspose.Cells.GridJs has a powerful calculation engine that can calculate almost all of the Microsoft Excel formulas. Despite this, it also allows you to extend the default calculation engine which provides you greater power and flexibility.

The following classes are used in implementing this feature.

- <a href="https://reference.aspose.com/cells/net/aspose.cells.gridjs/gridabstractcalculationengine" target="_blank" rel="nofollow noopener noreferrer">**GridAbstractCalculationEngine**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.gridjs/gridcalculationdata" target="_blank" rel="nofollow noopener noreferrer">**GridCalculationData**</a>

The following code implements the Custom Calculation Engine. It implements the the interface <a href="https://reference.aspose.com/cells/net/aspose.cells.gridjs/gridabstractcalculationengine" target="_blank" rel="nofollow noopener noreferrer">**GridAbstractCalculationEngine**</a> which has a <a href="https://reference.aspose.com/cells/net/aspose.cells.gridjs/gridabstractcalculationengine/methods/calculate" target="_blank" rel="nofollow noopener noreferrer">**Calculate(GridCalculationData data)**</a> method. This method is called against all of your formulas. Inside this method, we capture the **MYTESTFUNC** formula and **multiply its first parameter value by 2**.

### Programming Sample {#programming-sample}

```csharp
class MyCalculation : GridAbstractCalculationEngine
        {
           public override void Calculate(GridCalculationData data)
            {
                if (!"MYTESTFUNC".Equals(data.FunctionName.ToUpper()))
                {
                    return;
                }
                data.CalculatedValue = (decimal)(2.0 * (double)data.GetParamValue(0));
            }
        }
// in the startup.cs when you do initialization ,set the CalculateEngine		
  MyCalculation ce = new MyCalculation();
  GridJsWorkbook.CalculateEngine = ce;
```

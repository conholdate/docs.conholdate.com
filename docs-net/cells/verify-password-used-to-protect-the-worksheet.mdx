:::info
Aspose.Cells APIs have enhanced the <a href="https://reference.aspose.com/cells/net/aspose.cells/protection" target="_blank" rel="nofollow noopener noreferrer">**Protection**</a> class by introducing some useful properties **and** methods. One such method is the <a href="https://reference.aspose.com/cells/net/aspose.cells/protection/methods/verifypassword" target="_blank" rel="nofollow noopener noreferrer">**VerifyPassword**</a> which allows specifying a password as a **string** and verifies if the same password has been used to protect the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a>.
:::

The <a href="https://reference.aspose.com/cells/net/aspose.cells/protection/methods/verifypassword" target="_blank" rel="nofollow noopener noreferrer">**Protection.VerifyPassword**</a> method returns **true** if the specified password matches the password used to protect the given worksheet and **false** if the specified password does not match. **The** following piece of code uses the <a href="https://reference.aspose.com/cells/net/aspose.cells/protection/methods/verifypassword" target="_blank" rel="nofollow noopener noreferrer">**Protection.VerifyPassword**</a> method in conjunction with the <a href="https://reference.aspose.com/cells/net/aspose.cells/protection/properties/isprotectedwithpassword" target="_blank" rel="nofollow noopener noreferrer">**Protection.IsProtectedWithPassword**</a> property to detect password protection and verify the password.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create an instance of Workbook and load a spreadsheet
var book = new Workbook(dataDir + "Sample.xlsx");

// Access the protected Worksheet
var sheet = book.Worksheets[0];

// Check if Worksheet is password protected
if (sheet.Protection.IsProtectedWithPassword)
{
    // Verify the password used to protect the Worksheet
    if (sheet.Protection.VerifyPassword("1234"))
    {
        Console.WriteLine("Specified password has matched");
    }
    else
    {
        Console.WriteLine("Specified password has not matched");
    }
}
```

## Introduction {#introduction}

Aspose .NET Import Users from Excel Module allows developers to import bulk users from an Excel file. This module demonstrates the powerful spreadsheet features by Aspose.Cells.

### Module Features {#module-features}

This initial version of the module is enriched with the following cool features to make the import process simple and easy to use:

- Allows you to upload an Excel file and automatically filters out existing users.
- Automatically skips the existing users to avoid any confusion.
- Generates dynamic passwords for the newly created users.
- Assigns "Registered Users" and "Subscribers" security roles to newly created users.

## Installing {#installing}

Once downloaded, please follow these steps to install the module into your DNN website:

1. Log into your site as either Host or another super‑user level account.
2. Navigate to the **Host** menu and select **Extensions**.
3. Click **Install Extension Wizard**.
4. As directed browse to the location of the downloaded zip file, select it then click **Open**.
5. Click **Next**, accept the license, continue through the install. When finished click the **Return** button.

Please check <a href="https://www.dnnsoftware.com/community/learn/video-library/view-video/video/542/view/details/how-to-install-a-module-in-dotnetnuke-7" target="_blank" rel="nofollow noopener noreferrer">this module installation video</a> from DNN for more details.

## Using {#using}

After you have installed the Aspose .NET Cells Import Users from Excel for DNN module, it is simple to start using it on your website. Please follow these simple steps to get started:

1. Make sure you are logged in to DNN with a Host or Admin level account.

2. Navigate to the page where you want to add the Import module.

3. Select **Modules** followed by **Add New Module** from the top ribbon.

4. From the list, select 'Aspose Import Users from Excel module for DNN' and drag it into position.

You have successfully added the Aspose .NET Cells Import Users from Excel module for DNN to your page. File upload controls will be visible along with the "Template File" link. You can download the template file and format your contents accordingly. Once you upload your Excel file, it will automatically process all the users and filter out existing users. You can select the users you want to import and press "Import Users" button.

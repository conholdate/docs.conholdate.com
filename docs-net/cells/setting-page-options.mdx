Sometimes, it is necessary to configure page setup settings for worksheets to control printing. These page setup settings offer various options.
:::

## Setting Page Options {#setting-page-options}

Page setup options are fully supported in Aspose.Cells. This article explains how to set page options with Aspose.Cells and shows code samples for setting:

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> property that is used to set the page setup options of the worksheet. In fact, this <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> property is an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class used to set different page layout options for a printed worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class provides various properties used to set page setup options. Some of these properties are discussed below.

### Page Orientation {#page-orientation}

Page orientation can be set to portrait or landscape using the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/orientation" target="_blank" rel="nofollow noopener noreferrer">**Orientation**</a> property. The <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/orientation" target="_blank" rel="nofollow noopener noreferrer">**Orientation**</a> property accepts one of the pre‑defined values in the <a href="https://reference.aspose.com/cells/net/aspose.cells/pageorientationtype" target="_blank" rel="nofollow noopener noreferrer">**PageOrientationType**</a> enumeration, listed below.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the orientation to Portrait
worksheet.PageSetup.Orientation = PageOrientationType.Portrait;

// Save the Workbook.
workbook.Save(dataDir + "PageOrientation_out.xls");
```

### Scaling Factor {#scaling-factor}

It is possible to reduce or enlarge a worksheet's size by adjusting the scaling factor with the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/zoom" target="_blank" rel="nofollow noopener noreferrer">**PageSetup.Zoom**</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the scaling factor to 100
worksheet.PageSetup.Zoom = 100;

// Save the workbook.
workbook.Save(dataDir + "ScalingFactor_out.xls");
```

### FitToPages Options {#fittopages-options}

To fit the contents of the worksheet to a specific number of pages, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopagestall" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesTall**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopageswide" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesWide**</a> properties. These properties are also used to scale worksheets.

:::info
You can either choose the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopagestall" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesTall**</a>/<a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopageswide" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesWide**</a> or the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/zoom" target="_blank" rel="nofollow noopener noreferrer">**Zoom**</a> property, but not both at the same time.
:::

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the number of pages to which the length of the worksheet will be spanned
worksheet.PageSetup.FitToPagesTall = 1;

// Setting the number of pages to which the width of the worksheet will be spanned
worksheet.PageSetup.FitToPagesWide = 1;

// Save the workbook.
workbook.Save(dataDir + "FitToPagesOptions_out.xls");
```

### Print Quality {#print-quality}

Set the print quality of the worksheets to be printed with the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/printquality" target="_blank" rel="nofollow noopener noreferrer">**PrintQuality**</a> property. The measuring unit for print quality is Dots Per Inch (DPI).

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the print quality of the worksheet to 180 dpi
worksheet.PageSetup.PrintQuality = 180;

// Save the Workbook.
workbook.Save(dataDir + "SetPrintQuality_out.xls");
```

### First Page Number {#first-page-number}

Start the numbering of worksheet pages using the <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/firstpagenumber" target="_blank" rel="nofollow noopener noreferrer">**FirstPageNumber**</a> property. The <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/firstpagenumber" target="_blank" rel="nofollow noopener noreferrer">**FirstPageNumber**</a> property sets the page number of the first worksheet page, and the subsequent pages are numbered in ascending order.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the first page number of the worksheet pages
worksheet.PageSetup.FirstPageNumber = 2;

// Save the Workbook.
workbook.Save(dataDir + "SetFirstPageNumber_out.xls");
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Early versions of Aspose.Cells were not able to handle automatic units of the chart axis properly when the chart is rendered to an image or PDF. Now, Aspose.Cells supports automatic units on the chart axis. There is no code change. Just convert your chart into an image or PDF, and it will render the chart axis just as Microsoft Excel does.

## Handle Automatic Units of Chart Axis like Microsoft Excel {#handle-automatic-units-of-chart-axis-like-microsoft-excel}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/handle-automatic-units-of-chart-axis-like-microsoft-excel/61767755.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> and generates the <a href="https://docs.aspose.com/cells/net/handle-automatic-units-of-chart-axis-like-microsoft-excel/61767752.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF chart</a>. The screenshot shows the automatic units of the chart axis in red rectangles and compares the sample Excel file chart with the output PDF chart. Both are exactly the same.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load the sample Excel file
Workbook wb = new Workbook("sampleHandleAutomaticUnitsOfChartAxisLikeMicrosoftExcel.xlsx");

//Access first worksheet
Worksheet ws = wb.Worksheets[0];

//Access first chart
Chart ch = ws.Charts[0];

//Render chart to pdf
ch.ToPdf("outputHandleAutomaticUnitsOfChartAxisLikeMicrosoftExcel.pdf");
```

You can check if your VBA project is signed or not using Microsoft Excel via **Tools &gt; Digital Signatures…** menu command. Similarly, you can check it programmatically using Aspose.Cells <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/properties/issigned" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.IsSigned**</a> property.
:::

## Check if VBA project in a Workbook is Signed in C# {#check-if-vba-project-in-a-workbook-is-signed-in-c}

The following code loads the workbook and checks if its VBA project is signed using the <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/properties/issigned" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.IsSigned**</a> property. The property will return **true** if the project is signed; otherwise, it will return **false**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

Workbook workbook = new Workbook(dataDir + "Sample1.xlsx");
Console.WriteLine("VBA Project is Signed: " + workbook.VbaProject.IsSigned);
```

Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
Aspose.Cells supports saving an ODS file (**OpenDocument Spreadsheet**) in the ODF (**OpenDocument Format**) 1.1, 1.2 and 1.3 specifications. Aspose.Cells has <a href="https://reference.aspose.com/cells/net/aspose.cells/odssaveoptions/odfstrictversion/" target="_blank" rel="nofollow noopener noreferrer">**OdsSaveOptions.OdfStrictVersion**</a> property that specifies the ODF version for saving ODS files. The default value of this property is <a href="https://reference.aspose.com/cells/net/aspose.cells.ods/opendocumentformatversiontype/" target="_blank" rel="nofollow noopener noreferrer">**OpenDocumentFormatVersionType.Odf12**</a>, so the ODS file saved without this setting uses the 1.2 specifications.
:::

The sample code below creates a workbook object, adds a value to cell A1 on the first worksheet, and then saves the ODS file in ODF 1.1, 1.2 and 1.3 specifications. By default, the ODS file is saved in ODF 1.2 specification.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create workbook
Workbook workbook = new Workbook();

// Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Put some value in cell A1
Cell cell = worksheet.Cells["A1"];
cell.PutValue("Welcome to Aspose!");

// Save ODS in ODF 1.2 version which is default
OdsSaveOptions options = new OdsSaveOptions();
workbook.Save(dataDir + "ODF1.2_out.ods", options);

// Save ODS in ODF 1.1 version
options.OdfStrictVersion = Aspose.Cells.Ods.OpenDocumentFormatVersionType.Odf11;

workbook.Save(dataDir + "ODF1.1_out.ods", options);

// Save ODS in ODF 1.3 version
options.OdfStrictVersion = Aspose.Cells.Ods.OpenDocumentFormatVersionType.Odf13;

workbook.Save(dataDir + "ODF1.3_out.ods", options);
```

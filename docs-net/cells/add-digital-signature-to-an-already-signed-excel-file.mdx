## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/adddigitalsignature" target="_blank" rel="nofollow noopener noreferrer">**Workbook.AddDigitalSignature(DigitalSignatureCollection digitalSignatureCollection)**</a> method that you can use to add a digital signature to an already signed Excel file.

:::info
Please note that while adding a digital signature to an already signed Excel document, if the original document is an Aspose.Cells‑generated document, it works well. However, if the original document is generated by other engines (e.g., Microsoft Excel, etc.), Aspose.Cells cannot keep the file unchanged after loading and re‑saving it; this will make the original signature invalid.
:::

## How to Add Digital Signature to an Already Signed Excel File {#how-to-add-digital-signature-to-an-already-signed-excel-file}

The following sample code demonstrates how to make use of <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/adddigitalsignature" target="_blank" rel="nofollow noopener noreferrer">**Workbook.AddDigitalSignature(DigitalSignatureCollection digitalSignatureCollection)**</a> method to add a digital signature to an already signed Excel file. Please check the <a href="https://docs.aspose.com/cells/net/add-digital-signature-to-an-already-signed-excel-file/50528280.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in this code. This file is already digitally signed. Please check the <a href="https://docs.aspose.com/cells/net/add-digital-signature-to-an-already-signed-excel-file/50528281.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated by the code. We have used the demo certificate named <a href="https://docs.aspose.com/cells/net/add-digital-signature-to-an-already-signed-excel-file/50528279.pfx" target="_blank" rel="nofollow noopener noreferrer">AsposeDemo.pfx</a> in this code which has the password **aspose**. The screenshot shows the effect of the sample code on the sample Excel file after execution.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Certificate file and its password
string certFileName = sourceDir + "AsposeDemo.pfx";
string password = "aspose";

//Load the workbook which is already digitally signed to add new digital signature
Aspose.Cells.Workbook workbook = new Aspose.Cells.Workbook(sourceDir + "sampleDigitallySignedByCells.xlsx");

//Create the digital signature collection
Aspose.Cells.DigitalSignatures.DigitalSignatureCollection dsCollection = new Aspose.Cells.DigitalSignatures.DigitalSignatureCollection();

//Create new certificate
System.Security.Cryptography.X509Certificates.X509Certificate2 certificate = new System.Security.Cryptography.X509Certificates.X509Certificate2(certFileName, password);

//Create new digital signature and add it in digital signature collection
Aspose.Cells.DigitalSignatures.DigitalSignature signature = new Aspose.Cells.DigitalSignatures.DigitalSignature(certificate, "Aspose.Cells added new digital signature in existing digitally signed workbook.", DateTime.Now);
dsCollection.Add(signature);

//Add digital signature collection inside the workbook
workbook.AddDigitalSignature(dsCollection);

//Save the workbook and dispose it.
workbook.Save(outputDir + "outputDigitallySignedByCells.xlsx");
workbook.Dispose();
```

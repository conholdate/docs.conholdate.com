## Threaded Comments {#threaded-comments}

MS Excel 365 provides a feature to add threaded comments. These comments work as conversations and can be used for discussions. The comments now come with a Reply box that allows for threaded conversations. The old comments are called Notes in Excel 365. The screenshot below shows how threaded comments are displayed when opened in Excel.

![todo:image_alt_text](/net/cells/images/ce895f951c875f28-threaded-comments_1.jpg)

Threaded comments are shown like this in older versions of Excel. The following images have been taken by opening the sample file in Excel 2016.

![todo:image_alt_text](/net/cells/images/efd0ab4e100a65a2-threaded-comments_2.jpg)

![todo:image_alt_text](/net/cells/images/9363b0137ce282a3-threaded-comments_3.jpg)

Aspose.Cells also provides the feature to manage threaded comments.

## Add Threaded Comments {#add-threaded-comments}

### Add Threaded Comment with Excel {#add-threaded-comment-with-excel}

To add threaded comments in Excel 365, follow these steps.

- Method 1
  - Click the **Review** tab
  - Click the **New Comment** button
  - This will open a dialog to enter a comment in the active cell.
  - ![todo:image_alt_text](/net/cells/images/e7749e1cf443d585-threaded-comments_4.jpg)
- Method 2
  - Right‑click on the cell where you want to insert the comment.
  - Click the **New Comment** option.
  - This will open a dialog to enter a comment in the active cell.
  - ![todo:image_alt_text](/net/cells/images/25db7fd2a0ed94af-threaded-comments_5.png)

### Add Threaded Comment using Aspose.Cells {#add-threaded-comment-using-asposecells}

Aspose.Cells provides **<a href="https://reference.aspose.com/cells/net/aspose.cells.commentcollection/addthreadedcomment/methods/1" target="_blank" rel="nofollow noopener noreferrer">Comments.AddThreadedComment</a>** method to add threaded comments. The **<a href="https://reference.aspose.com/cells/net/aspose.cells.commentcollection/addthreadedcomment/methods/1" target="_blank" rel="nofollow noopener noreferrer">Comments.AddThreadedComment</a>** method accepts the following three parameters.

- Cell Name: The name of the cell where the comment will be inserted.
- Comment Text: The text of the comment.
- **<a href="https://reference.aspose.com/cells/net/aspose.cells/threadedcommentauthor" target="_blank" rel="nofollow noopener noreferrer">ThreadedCommentAuthor</a>**: The author of the comment

The following code sample demonstrates the use of **<a href="https://reference.aspose.com/cells/net/aspose.cells.commentcollection/addthreadedcomment/methods/1" target="_blank" rel="nofollow noopener noreferrer">Comments.AddThreadedComment</a>** method to add a threaded comment to cell **A1**. Please see the **<a href="https://docs.aspose.com/cells/net/threaded-comments/89849859.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>** generated by the code for reference.

#### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string outDir = "./";

Workbook workbook = new Workbook();

// Add Author
int authorIndex = workbook.Worksheets.ThreadedCommentAuthors.Add("Aspose Test", "", "");
ThreadedCommentAuthor author = workbook.Worksheets.ThreadedCommentAuthors[authorIndex];

// Add Threaded Comment
workbook.Worksheets[0].Comments.AddThreadedComment("A1", "Test Threaded Comment", author);

workbook.Save(outDir + "AddThreadedComments_out.xlsx");
```

## Read Threaded Comments {#read-threaded-comments}

### Read Threaded Comments with Excel {#read-threaded-comments-with-excel}

To read threaded comments in Excel, simply hover your mouse over the cell containing comments to view the comments. The comments view will look like the view in the following image.

![todo:image_alt_text](/net/cells/images/ce895f951c875f28-threaded-comments_1.jpg)

### Read Threaded Comments using Aspose.Cells {#read-threaded-comments-using-asposecells}

Aspose.Cells provides **<a href="https://reference.aspose.com/cells/net/aspose.cells.commentcollection/getthreadedcomments/methods/1" target="_blank" rel="nofollow noopener noreferrer">Comments.GetThreadedComments</a>** method to retrieve threaded comments for the specified column. **<a href="https://reference.aspose.com/cells/net/aspose.cells.commentcollection/getthreadedcomments/methods/1" target="_blank" rel="nofollow noopener noreferrer">Comments.GetThreadedComments</a>** method accepts the column name as a parameter and returns the **<a href="https://reference.aspose.com/cells/net/aspose.cells/threadedcommentcollection" target="_blank" rel="nofollow noopener noreferrer">ThreadedCommentCollection</a>**. You can iterate over the **<a href="https://reference.aspose.com/cells/net/aspose.cells/threadedcommentcollection" target="_blank" rel="nofollow noopener noreferrer">ThreadedCommentCollection</a>** to view the comments.

The following example demonstrates reading comments from cell **A1** by loading the **sample Excel file**. Please see the console output generated by the code for reference.

#### Sample Code {#sample-code-1}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

Workbook workbook = new Workbook(sourceDir + "ThreadedCommentsSample.xlsx");

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Get Threaded Comments
ThreadedCommentCollection threadedComments = worksheet.Comments.GetThreadedComments("A1");

foreach (ThreadedComment comment in threadedComments)
{
    Console.WriteLine("Comment: " + comment.Notes);
    Console.WriteLine("Author: " + comment.Author.Name);
}
```

#### Console Output {#console-output}

```csharp
Comment: Test Threaded Comment

Author: Aspose Test
```

## Remove Threaded Comments {#remove-threaded-comments}

### Remove Threaded Comments with Excel {#remove-threaded-comments-with-excel}

To remove threaded comments in Excel, right‑click on the cell containing the comments and click the **Delete Comment** option as shown in the following image.

![todo:image_alt_text](/net/cells/images/958346a37a8d5e86-threaded-comments_8.jpg)

### Remove Threaded Comments using Aspose.Cells {#remove-threaded-comments-using-asposecells}

Aspose.Cells provides **<a href="https://reference.aspose.com/cells/net/aspose.cells/commentcollection/methods/removeat/index" target="_blank" rel="nofollow noopener noreferrer">Comments.RemoveAt</a>** method to remove comments for the specified column. **<a href="https://reference.aspose.com/cells/net/aspose.cells/commentcollection/methods/removeat/index" target="_blank" rel="nofollow noopener noreferrer">Comments.RemoveAt</a>** method accepts the column name as a parameter and removes the comments in that column.

The following example demonstrates removing comments in column **A1** by loading the **sample Excel file**. Please see the **<a href="https://docs.aspose.com/cells/net/threaded-comments/89849864.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>** generated by the code for reference.

#### Sample Code {#sample-code-4}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";
string outDir = "./";

Workbook workbook = new Workbook(sourceDir + "ThreadedCommentsSample.xlsx");

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

CommentCollection comments = worksheet.Comments;

// Get Author of first comment in A1
ThreadedCommentAuthor author = worksheet.Comments.GetThreadedComments("A1")[0].Author;

// Remove Comments
comments.RemoveAt("A1");

ThreadedCommentAuthorCollection authors = workbook.Worksheets.ThreadedCommentAuthors;

// Remove Author of first comment in A1
authors.RemoveAt(authors.IndexOf(author));

workbook.Save(outDir + "ThreadedCommentsSample_Out.xlsx");
```

:::info
Please note that by removing a comment with Aspose.Cells, the author is not removed automatically. If you need to remove the author as well, please use the **RemoveAt** method of **<a href="https://reference.aspose.com/cells/net/aspose.cells/threadedcommentauthorcollection" target="_blank" rel="nofollow noopener noreferrer">ThreadedCommentAuthorCollection</a>** class as shown in the example above.
:::

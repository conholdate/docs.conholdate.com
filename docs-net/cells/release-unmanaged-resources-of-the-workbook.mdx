:::info
Aspose.Cells provides <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/dispose" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Dispose()**</a> method to release the unmanaged resources of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> object. The dispose pattern is used only for objects that access unmanaged resources, such as file and pipe handles, registry handles, wait handles, or pointers to blocks of unmanaged memory. This is because the garbage collector is very efficient at reclaiming unused managed objects, but it is unable to reclaim unmanaged objects.
:::

The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> object now implements the *System.IDisposable* interface, which has a single method, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/dispose" target="_blank" rel="nofollow noopener noreferrer">**Dispose()**</a>. You can either call the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/dispose" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Dispose()**</a> method directly, or use the *using* statement to have this method called automatically.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Create workbook object
Workbook wb1 = new Workbook();

// Call Dispose method
wb1.Dispose();

// Call Dispose method via Using statement
using (Workbook wb2 = new Workbook())
{
    // Any other code goes here
}
```

## Possible Usage Scenarios {#possible-usage-scenarios}

You can add Word Art text with built‑in styles using Aspose.Cells. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shapecollection/methods/addwordart" target="_blank" rel="nofollow noopener noreferrer">ShapeCollection.AddWordArt()</a> method for this purpose.

## Add Word Art Text with Built-in Styles {#add-word-art-text-with-built-in-styles}

The following sample code adds Word Art text with different built‑in styles. Please check the <a href="https://docs.aspose.com/cells/net/add-word-art-text-with-built-in-styles/5115470.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated with this code. This is how the <a href="https://docs.aspose.com/cells/net/add-word-art-text-with-built-in-styles/5115470.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> looks in Microsoft Excel.

![todo:image_alt_text](/net/cells/images/23eeabc302c4eb88-add-word-art-text-with-built-in-styles_1.png)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create workbook object
Workbook wb = new Workbook();

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Add Word Art Text with Built-in Styles
ws.Shapes.AddWordArt(PresetWordArtStyle.WordArtStyle1, "Aspose File Format APIs", 00, 0, 0, 0, 100, 800);
ws.Shapes.AddWordArt(PresetWordArtStyle.WordArtStyle2, "Aspose File Format APIs", 10, 0, 0, 0, 100, 800);
ws.Shapes.AddWordArt(PresetWordArtStyle.WordArtStyle3, "Aspose File Format APIs", 20, 0, 0, 0, 100, 800);
ws.Shapes.AddWordArt(PresetWordArtStyle.WordArtStyle4, "Aspose File Format APIs", 30, 0, 0, 0, 100, 800);
ws.Shapes.AddWordArt(PresetWordArtStyle.WordArtStyle5, "Aspose File Format APIs", 40, 0, 0, 0, 100, 800);

// Save the workbook in xlsx format
wb.Save(dataDir + "output_out.xlsx");
```

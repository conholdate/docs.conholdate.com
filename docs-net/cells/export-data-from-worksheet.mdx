## How to Export Data from Worksheet {#how-to-export-data-from-worksheet}

Aspose.Cells not only facilitates its users to import data to worksheets from external data sources but also **allows** them to export their worksheet data to a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a>. As we know that <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> is part of ADO.NET and is used to hold data. Once the data is stored in a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a>, it can be used in any way according to the requirements of users. Developers can also store this data (stored in <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a>) directly to a database if they wish. So, we can see that it becomes easier for the developers to manipulate worksheet data if it is exported to a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a>.

## How to Export Data to DataTable Using Aspose.Cells {#how-to-export-data-to-datatable-using-asposecells}

Developers can easily export their worksheet data to a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> object by calling either <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatable/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTable**</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatableasstring/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTableAsString**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> class. Both methods are used in different scenarios, which are discussed below in more detail.

## Columns Containing Strongly Typed Data {#columns-containing-strongly-typed-data}

We know that a spreadsheet stores data as a sequence of rows and columns. If all values in the columns of a worksheet are strongly typed (that means all values in a column must have the same data type) then we can export the worksheet content by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatable/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTable**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatable/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTable**</a> method takes the following parameters to export worksheet data as a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> object:

- **Row number** - the row number of the first cell from which data will be exported.
- **Column number** - the column number of the first cell from which the data will be exported.
- **Number of rows** - the number of rows to export.
- **Number of columns** - the number of columns to export.
- **Export column names** - a Boolean property that indicates whether the data in the first row of the worksheet should be exported as column names of the <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> or not.

*Code Steps:*

1. Load your Excel file in a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/" target="_blank" rel="nofollow noopener noreferrer">Workbook</a> object.
   - The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/" target="_blank" rel="nofollow noopener noreferrer">Workbook</a> object can load Excel file formats, e.g., XLS, XLSX, XLSM, ODS, etc.
2. **Access** the first <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/" target="_blank" rel="nofollow noopener noreferrer">Worksheet</a> in the Excel file.
3. Choose your export area, e.g., 7 rows and 2 columns starting from the first cell of the **DataTable**.
4. Use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/exportdatatable/" target="_blank" rel="nofollow noopener noreferrer">ExportDataTable</a> method to export the data into a DataTable.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

string filePath = dataDir + "Book1.xlsx";

// Instantiating a Workbook object
Workbook workbook = new Workbook(filePath);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Exporting the contents of 7 rows and 2 columns starting from 1st cell to DataTable
DataTable dataTable = worksheet.Cells.ExportDataTable(0, 0, 11, 2, true);

foreach (DataRow r in dataTable.Rows)
{
    foreach (DataColumn c in dataTable.Columns)
    {
        Double value = r.Field<Double>(c);
        Console.Write(value + "    ");
    }
    Console.WriteLine();
}
```

## Columns Containing Non-Strongly Typed Data {#columns-containing-non-strongly-typed-data}

If all values in the columns of a worksheet are not strongly typed (that means the values in a column may have **different** data types) then we can export the worksheet content by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatableasstring/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTableAsString**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatableasstring/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTableAsString**</a> method takes the same set of parameters as that of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/exportdatatable/index" target="_blank" rel="nofollow noopener noreferrer">**ExportDataTable**</a> method to export worksheet data as a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> object.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

string filePath = dataDir + "Book1.xlsx";

// Instantiating a Workbook object
Workbook workbook = new Workbook(filePath);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Exporting the contents of 7 rows and 2 columns starting from 1st cell to DataTable
DataTable dataTable = worksheet.Cells.ExportDataTableAsString(0, 0, 11, 2, true);

foreach (DataRow r in dataTable.Rows)
{
    foreach (DataColumn c in dataTable.Columns)
    {
        string value = r.Field<string>(c);
        Console.Write(value + "            ");
    }
    Console.WriteLine();
}
```

## How to Export Range with Header {#how-to-export-range-with-header}

Data from a range can be exported to a <a href="https://docs.microsoft.com/en-gb/dotnet/api/system.data.datatable?view=netframework-4.8" target="_blank" rel="nofollow noopener noreferrer">**DataTable**</a> where a flag is available to skip the header row in the exported data. The following code exports a range of data to a DataTable with an argument **ExportTableOptions**, which contains the **ExportColumnName** flag. It is set to **true** if header information is present, in which case the header will be excluded from the data, and set to **false** if no header is present and all rows are considered data.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string sourceDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook(sourceDir + "Names.xlsx");

// Instantiating a WorkbookDesigner object
WorkbookDesigner designer = new WorkbookDesigner(workbook);

// Accessing the range having name "Names"
var range = designer.Workbook.Worksheets.GetRangeByName("Names");

// Instantiating the ExportTableOptions object
ExportTableOptions options = new ExportTableOptions();

// Setting the ExportColumnName flag to true shows that first line is header and not part of data
options.ExportColumnName = true;

// Exporting data with the selected information
var dataTable = range.ExportDataTable(options);
```

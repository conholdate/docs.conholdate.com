Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
It is possible to show formulas instead of calculated values in Microsoft Excel using the **Show Formulas** option from the **Formulas** ribbon. When formulas are shown, Microsoft Excel displays formulas in the worksheet. You can achieve the same thing using Aspose.Cells.
:::

Aspose.Cells provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/showformulas" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.ShowFormulas**</a> property. Set it to **true** to make Microsoft Excel display formulas.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

string filePath = dataDir + "source.xlsx";

// Load the source workbook
Workbook workbook = new Workbook(filePath);

// Access the first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Show formulas of the worksheet
worksheet.ShowFormulas = true;

// Save the workbook
workbook.Save(dataDir + ".out.xlsx");
```

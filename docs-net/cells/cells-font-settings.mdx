The look and feel of text can be controlled by changing font settings. The font settings may include the name, style, size, color and other effects of the fonts. Just like Microsoft Excel, Aspose.Cells also supports configuring the font settings of the cells.
:::

## Configuring Font Settings {#configuring-font-settings}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection represents an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstyle" target="_blank" rel="nofollow noopener noreferrer">**GetStyle**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setstyle" target="_blank" rel="nofollow noopener noreferrer">**SetStyle**</a> methods which are used to get and set a cell's formatting style. The <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> class provides properties for configuring font settings.

### Setting Font Name {#setting-font-name}

Developers can apply any font to text inside a cell by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/font" target="_blank" rel="nofollow noopener noreferrer">**Style.Font**</a> object's <a href="https://reference.aspose.com/cells/net/aspose.cells/font/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Adding a new worksheet to the Excel object
int i = workbook.Worksheets.Add();

// Obtaining the reference of the newly added worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[i];

// Accessing the "A1" cell from the worksheet
Aspose.Cells.Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Hello Aspose!");

// Obtaining the style of the cell
Style style = cell.GetStyle();

// Setting the font name to "Times New Roman"
style.Font.Name = "Times New Roman";

// Applying the style to the cell
cell.SetStyle(style);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls", SaveFormat.Excel97To2003);
```

### Setting Font Style to Bold {#setting-font-style-to-bold}

Developers can make text bold by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/font" target="_blank" rel="nofollow noopener noreferrer">**Style.Font**</a> object's <a href="https://reference.aspose.com/cells/net/aspose.cells/font/properties/isbold" target="_blank" rel="nofollow noopener noreferrer">**IsBold**</a> property to **true**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Adding a new worksheet to the Excel object
int i = workbook.Worksheets.Add();

// Obtaining the reference of the newly added worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[i];

// Accessing the "A1" cell from the worksheet
Aspose.Cells.Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Hello Aspose!");

// Obtaining the style of the cell
Style style = cell.GetStyle();

// Setting the font weight to bold
style.Font.IsBold = true;

// Applying the style to the cell
cell.SetStyle(style);

// Saving the Excel file
workbook.Save("out.xlsx");
```

:::info
This document describes changes to the Aspose.Cells API from version 8.1.1 to 8.1.2 that may be of interest to module/application developers. It includes not only new and updated public methods, but also a description of any changes in the behavior behind the scenes in Aspose.Cells.
:::

## Added Support for Warning if Font Substitution Occurs {#added-support-for-warning-if-font-substitution-occurs}

With Aspose.Cells for .NET 8.1.2, the `WarningInfo`, `WarningType` classes, `IWarningCallback` interface, and `SaveOptions.WarningCallback`, `ImageOrPrintOptions.WarningCallback` properties have been added to facilitate users receiving warnings if font substitution occurs while converting spreadsheets to images or PDF format.

:::info
Please check the detailed article on <a href="http://aspose.com/docs/display/cellsnet/Get+Warnings+for+Font+Substitution+while+Rendering+Excel+File" target="_blank" rel="nofollow noopener noreferrer">Getting Warnings for Font Substitution while Rendering Spreadsheets</a>
:::

## Deleted Obsolete PdfSaveOptions.ChartImageType Property {#deleted-obsolete-pdfsaveoptionschartimagetype-property}

Aspose.Cells for .NET 8.1.2 has removed the obsolete `PdfSaveOptions.ChartImageType` property from the public API.

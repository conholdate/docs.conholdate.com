:::info
You can use Aspose.Cells to merge or split a range of cells. Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/range/methods/merge" target="_blank" rel="nofollow noopener noreferrer">**Range.Merge()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/range/methods/unmerge" target="_blank" rel="nofollow noopener noreferrer">**Range.UnMerge()**</a> methods for this purpose. This article explains how to merge a range of cells into a single cell.
:::

## Example {#example}

The following sample code first creates a range - A1:D4 - then merges the cells in the range into a single cell using the <a href="https://reference.aspose.com/cells/net/aspose.cells/range/methods/merge" target="_blank" rel="nofollow noopener noreferrer">**Range.Merge()**</a> method. Similarly, you can unmerge cells by creating a range and calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/range/methods/unmerge" target="_blank" rel="nofollow noopener noreferrer">**Range.UnMerge()**</a> method.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
// Create a workbook
Workbook workbook = new Workbook();

// Access the first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Create a range
Range range = worksheet.Cells.CreateRange("A1:D4");

// Merge range into a single cell
range.Merge();

// Save the workbook
workbook.Save(dataDir + "output.out.xlsx");
```

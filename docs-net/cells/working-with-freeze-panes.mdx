## Aspose.Cells - Working with Freeze Panes {#asposecells---working-with-freeze-panes}

**C#**

```cs
 // Instantiating a Workbook object
Workbook workbook = new Workbook();

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

worksheet.FreezePanes(2, 2, 2, 0);

workbook.Save("output-FreezeFile-Aspose.Cells.xls");
```

:::info
For more details, visit <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/freezepanes/index" target="_blank" rel="nofollow noopener noreferrer">FreezePanes Method</a>.
:::

## NPOI - HSSF XSSF - Working with Freeze Panes {#npoi---hssf-xssf---working-with-freeze-panes}

**C#**

```cs
 HSSFWorkbook hssfworkbook = new HSSFWorkbook();

ISheet sheet1 = hssfworkbook.CreateSheet("new sheet");

ISheet sheet2 = hssfworkbook.CreateSheet("second sheet");

ISheet sheet3 = hssfworkbook.CreateSheet("third sheet");

// Freeze only one row
sheet1.CreateFreezePane(0, 2, 0, 2);

// Freeze only one column
sheet2.CreateFreezePane(2, 0, 2, 0);

// Freeze the columns and rows (ignore the scrolling position of the lower‑right quadrant).
sheet3.CreateFreezePane(2, 2);

FileStream file = new FileStream(@"output-FreezeFile-NPOI.xls", FileMode.Create);

hssfworkbook.Write(file);

file.Close();
```

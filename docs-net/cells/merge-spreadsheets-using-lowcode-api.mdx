## Introduction {#introduction}

Aspose.Cells for .NET provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a> namespace, which simplifies common spreadsheet processing tasks. This API is designed for developers who want to accomplish high‑level operations such as HTML conversion, image conversion, JSON conversion, PDF conversion, spreadsheet conversion, spreadsheet merger, spreadsheet locker, and spreadsheet splitter with minimal effort.

The LowCode API is ideal for scenarios where quick implementation is more important than fine‑grained control. Aspose.Cells LowCode APIs provide a high‑level, declarative way to perform common spreadsheet tasks (conversion, merging, splitting, etc.) without writing extensive boiler‑plate code. Let's take a closer look at the LowCode capabilities of Aspose.Cells for .NET.

## Merge Multiple Spreadsheets - SpreadsheetMerger {#merge-multiple-spreadsheets--spreadsheetmerger}

If you want to merge several workbooks into a single workbook, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> class to perform the merging task without writing extensive boiler‑plate code. The following code demonstrates how to merge two sample files (<a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-1.xlsx" target="_blank" rel="nofollow noopener noreferrer">file1.xlsx</a> and <a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-2.xlsx" target="_blank" rel="nofollow noopener noreferrer">file2.xlsx</a>) into one file.

```csharp
string[] templateFiles = { "lowcode-merger-1.xlsx", "lowcode-merger-2.xlsx" };
string resultFile = "merged_output.xlsx";

SpreadsheetMerger.Process(templateFiles, resultFile);
```

## Merge Multiple Spreadsheets - SpreadsheetMerger & LowCodeMergeOptions {#merge-multiple-spreadsheets--spreadsheetmerger--lowcodemergeoptions}

If you want to merge several workbooks into a single workbook, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> class to perform the merging task without writing extensive boiler‑plate code. <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodemergeoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeMergeOptions</a> lets you fine‑tune the merge behavior. The following code demonstrates how to merge two sample files (<a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-1.xlsx" target="_blank" rel="nofollow noopener noreferrer">file1.xlsx</a> and <a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-2.xlsx" target="_blank" rel="nofollow noopener noreferrer">file2.xlsx</a>) into one file using <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodemergeoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeMergeOptions</a>.

```csharp
string[] files = { filePath + "lowcode-merger-1.xlsx", filePath + "lowcode-merger-2.xlsx" };

CustomLoadOptionsMergerProvider provider = new CustomLoadOptionsMergerProvider(files);

LowCodeSaveOptions saveOptions = new LowCodeSaveOptions();
saveOptions.OutputFile = filePath + "merged_output.xlsx";
saveOptions.SaveFormat = SaveFormat.Xlsx;

LowCodeMergeOptions mergeOptions = new LowCodeMergeOptions();
mergeOptions.LoadOptionsProvider = provider;
mergeOptions.SaveOptions = saveOptions;

SpreadsheetMerger.Process(mergeOptions);

private class CustomLoadOptionsMergerProvider : AbstractLowCodeLoadOptionsProvider
{

    public IEnumerator fileIter;
    public CustomLoadOptionsMergerProvider(string[] files)
    {
        fileIter = files.GetEnumerator();
        current = new LowCodeLoadOptions();
    }
    private LowCodeLoadOptions current;

    public override LowCodeLoadOptions Current => current;

    public override bool MoveNext()
    {
        if (fileIter.MoveNext())
        {
            current = new LowCodeLoadOptions();
            current.InputFile = fileIter.Current.ToString();
            return true;
        }

        return false;
    }

    public override void Finish(LowCodeLoadOptions part)
    {
        base.Finish(part);
    }
}
```

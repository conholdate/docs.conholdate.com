## Possible Usage Scenarios {#possible-usage-scenarios}

You can read or write the values of ActiveX ComboBox Control using Aspose.Cells. Please access the ActiveX Control via <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/activexcontrol" target="_blank" rel="nofollow noopener noreferrer">Shape.ActiveXControl</a> property and check its type via <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.activexcontrols/activexcontrolbase/properties/type" target="_blank" rel="nofollow noopener noreferrer">ActiveXControl.Type</a> property, it should return <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.activexcontrols/controltype" target="_blank" rel="nofollow noopener noreferrer">ControlType.ComboBox</a> value and then typecast it into <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.activexcontrols/comboboxactivexcontrol" target="_blank" rel="nofollow noopener noreferrer">ComboBoxActiveXControl</a> object and read or modify its various properties.

Please download the <a href="https://docs.aspose.com/cells/net/update-activex-combobox-control/5115124.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample excel file</a> used in the following sample code.

## Sample Code {#sample-code}

The following sample code updates the value of ActiveX ComboBox Control present inside the <a href="https://docs.aspose.com/cells/net/update-activex-combobox-control/5115124.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample excel file</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a workbook
Workbook wb = new Workbook(dataDir + "SourceFile.xlsx");

// Access first shape from first worksheet
Shape shape = wb.Worksheets[0].Shapes[0];

// Access ActiveX ComboBox Control and update its value
if (shape.ActiveXControl != null)
{
    // Access Shape ActiveX Control
    ActiveXControl c = shape.ActiveXControl;

    // Check if ActiveX Control is ComboBox Control
    if (c.Type == ControlType.ComboBox)
    {
        // Type cast ActiveXControl into ComboBoxActiveXControl and change its value
        ComboBoxActiveXControl comboBoxActiveX = (ComboBoxActiveXControl)c;
        comboBoxActiveX.Value = "This is combo box control with updated value.";
    }
}

// Save the workbook
wb.Save(dataDir + "OutputFile_out.xlsx");
```

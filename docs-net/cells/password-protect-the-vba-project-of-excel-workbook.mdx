## Password Protect the VBA Project of Excel Workbook in C# {#password-protect-the-vba-project-of-excel-workbook-in-c}

You can password‑protect the VBA (Visual Basic for Applications) project of a workbook with Aspose.Cells using the <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/methods/protect" target="_blank" rel="nofollow noopener noreferrer">**VbaProject.Protect()**</a> method.

## Sample Code {#sample-code}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/password-protect-the-vba-project-of-excel-workbook/43352067.xlsm" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>, accesses its VBA project, and protects it with a password. Finally, it saves it as the <a href="https://docs.aspose.com/cells/net/password-protect-the-vba-project-of-excel-workbook/43352068.xlsm" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

```csharp
﻿// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//The path to the documents directory.
string dataDir = "./";

//Load your source Excel file.
Workbook wb = new Workbook(dataDir + "samplePasswordProtectVBAProject.xlsm");

//Access the VBA project of the workbook.
Aspose.Cells.Vba.VbaProject vbaProject = wb.VbaProject;

//Lock the VBA project for viewing with password.
vbaProject.Protect(true, "11");

//Save the output Excel file
wb.Save(dataDir + "outputPasswordProtectVBAProject.xlsm");
```

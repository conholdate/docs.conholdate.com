## How to Add Data to Cells {#how-to-add-data-to-cells}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection represents an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

Aspose.Cells allows developers to add data to the cells in worksheets by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/putvalue/index" target="_blank" rel="nofollow noopener noreferrer">**PutValue**</a> method. Aspose.Cells provides overloaded versions of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/putvalue/index" target="_blank" rel="nofollow noopener noreferrer">**PutValue**</a> method that let developers add different kinds of data to cells. Using these overloaded versions of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/putvalue/index" target="_blank" rel="nofollow noopener noreferrer">**PutValue**</a> method, it is possible to add Boolean, string, double, integer, or date/time values to the cell.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Adding a string value to the cell
worksheet.Cells["A1"].PutValue("Hello World");

// Adding a double value to the cell
worksheet.Cells["A2"].PutValue(20.5);

// Adding an integer  value to the cell
worksheet.Cells["A3"].PutValue(15);

// Adding a boolean value to the cell
worksheet.Cells["A4"].PutValue(true);

// Adding a date/time value to the cell
worksheet.Cells["A5"].PutValue(DateTime.Now);

// Setting the display format of the date
Style style = worksheet.Cells["A5"].GetStyle();
style.Number = 15;
worksheet.Cells["A5"].SetStyle(style);

// Saving the Excel file
workbook.Save(dataDir + "output.out.xls");
```

## How to Improve Efficiency {#how-to-improve-efficiency}

If you use <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/putvalue/index" target="_blank" rel="nofollow noopener noreferrer">**PutValue**</a> method to put a large amount of data to a worksheet, you should add values to the cells first by rows and then by columns. This approach greatly improves the efficiency of your applications.

## How to Retrieve Data from Cells {#how-to-retrieve-data-from-cells}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to worksheets in the file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection represents an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class provides several properties that allow developers to retrieve values from the cells according to their data types. These properties include:

- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/stringvalue" target="_blank" rel="nofollow noopener noreferrer">**StringValue**</a>: returns the string value of the cell.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/doublevalue" target="_blank" rel="nofollow noopener noreferrer">**DoubleValue**</a>: returns the double value of the cell.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/boolvalue" target="_blank" rel="nofollow noopener noreferrer">**BoolValue**</a>: returns the boolean value of the cell.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/datetimevalue" target="_blank" rel="nofollow noopener noreferrer">**DateTimeValue**</a>: returns the date/time value of the cell.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/floatvalue" target="_blank" rel="nofollow noopener noreferrer">**FloatValue**</a>: returns the float value of the cell.
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/intvalue" target="_blank" rel="nofollow noopener noreferrer">**IntValue**</a>: returns the integer value of the cell.

When a field is not filled, cells with <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/doublevalue" target="_blank" rel="nofollow noopener noreferrer">**DoubleValue**</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/floatvalue" target="_blank" rel="nofollow noopener noreferrer">**FloatValue**</a> throw an exception.

The type of data contained in a cell can also be checked by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/type" target="_blank" rel="nofollow noopener noreferrer">**Type**</a> property. In fact, the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/properties/type" target="_blank" rel="nofollow noopener noreferrer">**Type**</a> property is based on the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellvaluetype" target="_blank" rel="nofollow noopener noreferrer">**CellValueType**</a> enumeration whose pre‑defined values are listed below:

You can also use the above pre‑defined cell value types to compare with the Type of data present in each cell.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Opening an existing workbook
Workbook workbook = new Workbook(dataDir + "book1.xls");
            
// Accessing first worksheet
Worksheet worksheet = workbook.Worksheets[0];

foreach (Cell cell1 in worksheet.Cells)
{
    // Variables to store values of different data types
    string stringValue;
    double doubleValue;
    bool boolValue;
    DateTime dateTimeValue;

    // Passing the type of the data contained in the cell for evaluation
    switch (cell1.Type)
    {
        // Evaluating the data type of the cell data for string value
        case CellValueType.IsString:
            stringValue = cell1.StringValue;
            Console.WriteLine("String Value: " + stringValue);
            break;

        // Evaluating the data type of the cell data for double value
        case CellValueType.IsNumeric:
            doubleValue = cell1.DoubleValue;
            Console.WriteLine("Double Value: " + doubleValue);
            break;

        // Evaluating the data type of the cell data for boolean value
        case CellValueType.IsBool:
            boolValue = cell1.BoolValue;
            Console.WriteLine("Bool Value: " + boolValue);
            break;

        // Evaluating the data type of the cell data for date/time value
        case CellValueType.IsDateTime:
            dateTimeValue = cell1.DateTimeValue;
            Console.WriteLine("DateTime Value: " + dateTimeValue);
            break;

        // Evaluating the unknown data type of the cell data
        case CellValueType.IsUnknown:
            stringValue = cell1.StringValue;
            Console.WriteLine("Unknown Value: " + stringValue);
            break;

        // Terminating the type checking of type of the cell data is null
        case CellValueType.IsNull:
            break;
    }
}
```

:::info
While working on worksheets, users may add different types of data in the cells. These data types may include Boolean, integer, floating point, text or date/time values. With Aspose.Cells, you can get the appropriate values from the cells according to their data types.
:::

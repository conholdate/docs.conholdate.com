## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes converting large **Excel** files can take some time. During this time, you might want to show the document conversion progress instead of just a loading screen to enhance the usability of your application. Aspose.Cells supports tracking the document conversion process by providing the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/ipagesavingcallback" target="_blank" rel="nofollow noopener noreferrer">**IPageSavingCallback**</a> interface. The <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/ipagesavingcallback" target="_blank" rel="nofollow noopener noreferrer">**IPageSavingCallback**</a> interface provides <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/ipagesavingcallback/methods/pagestartsaving" target="_blank" rel="nofollow noopener noreferrer">**PageStartSaving**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/ipagesavingcallback/methods/pageendsaving" target="_blank" rel="nofollow noopener noreferrer">**PageEndSaving**</a> methods that you can implement in your custom class. You may also control which pages are rendered as demonstrated in the *TestPageSavingCallback* custom class.

## Track Conversion Progress of Excel to TIFF {#track-conversion-progress-of-excel-to-tiff}

The following code sample loads the <a href="https://docs.aspose.com/cells/net/track-conversion-progress-of-excel-to-tiff/95584311.xlsx" target="_blank" rel="nofollow noopener noreferrer">source **Excel** file</a> and prints its conversion progress in the console **using** the *TestPageSavingCallback* custom class that implements the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/ipagesavingcallback" target="_blank" rel="nofollow noopener noreferrer">**IPageSavingCallback**</a> interface. ## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

Workbook workbook = new Workbook(sourceDir + "sampleUseWorkbookRenderForImageConversion.xlsx");
ImageOrPrintOptions opts = new ImageOrPrintOptions();
opts.PageSavingCallback = new TestTiffPageSavingCallback();
opts.ImageType = ImageType.Tiff;

WorkbookRender wr = new WorkbookRender(workbook, opts);
wr.ToImage(outputDir + "DocumentConversionProgressForTiff_out.tiff");
```

The following is the code for the *TestTiffPageSavingCallback* custom class.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
public class TestTiffPageSavingCallback : IPageSavingCallback
{
    public void PageStartSaving(PageStartSavingArgs args)
    {
        Console.WriteLine("Start saving page index {0} of pages {1}", args.PageIndex, args.PageCount);

        //don't output pages before page index 2.
        if (args.PageIndex < 2)
        {
            args.IsToOutput = false;
        }
    }

    public void PageEndSaving(PageEndSavingArgs args)
    {
        Console.WriteLine("End saving page index {0} of pages {1}", args.PageIndex, args.PageCount);

        //don't output pages after page index 8.
        if (args.PageIndex >= 8)
        {
            args.HasMorePages = false;
        }
    }
}
```

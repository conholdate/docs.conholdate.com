### Sample Code {#sample-code}

The following sample code converts the sample Excel file into HTML, which is just a normal [Excel to HTML conversion](/net/cells/convert-workbook-to-different-formats/#converting-excel-workbook-to-html).

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Specify the file path
string filePath = dataDir + "sample.xlsx";

// Load your sample excel file in a workbook object
Workbook wb = new Workbook(filePath);

// Save it in HTML format
wb.Save(dataDir + "ConvertingToHTMLFiles_out.html", SaveFormat.Html);
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/threedformat" target="_blank" rel="nofollow noopener noreferrer">Shape.ThreeDFormat</a> property along with the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/threedformat" target="_blank" rel="nofollow noopener noreferrer">ThreeDFormat</a> class to work with the 3‑D format of a shape or chart. The <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/threedformat" target="_blank" rel="nofollow noopener noreferrer">ThreeDFormat</a> class contains various properties that can be set to achieve different results according to application requirements.

## Working with the ThreeDFormat of Shape or Chart {#working-with-the-threedformat-of-shape-or-chart}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/working-with-the-threedformat-of-shape-or-chart/5115419.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a>, accesses the first shape in the first worksheet, sets the sub‑properties of the `Shape.ThreeDFormat` property, and then saves the workbook to the <a href="https://docs.aspose.com/cells/net/working-with-the-threedformat-of-shape-or-chart/5115410.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Load excel file containing a shape
Workbook wb = new Workbook(dataDir + "sample.xlsx");

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Access first shape
Shape sh = ws.Shapes[0];

// Apply different three dimensional settings
ThreeDFormat n3df = sh.ThreeDFormat;
n3df.ContourWidth = 17;
n3df.ExtrusionHeight = 32;

// Save the output excel file in xlsx format
wb.Save(dataDir + "output_out.xlsx");
```

:::info
While loading an HTML file into a Workbook, Aspose.Cells imports every table it finds. With the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmltableloadoption/" target="_blank" rel="nofollow noopener noreferrer">**HtmlTableLoadOption**</a> class, you can control which tables are imported and into which worksheet each table is placed.
:::

## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells exposes the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlloadoptions/properties/tableloadoptions/" target="_blank" rel="nofollow noopener noreferrer">**HtmlLoadOptions.TableLoadOptions**</a> property that returns an <a href="https://reference.aspose.com/cells/net/aspose.cells/htmltableloadoptioncollection/" target="_blank" rel="nofollow noopener noreferrer">**HtmlTableLoadOptionCollection**</a> instance. The collection provides several `Add` overloads to define the tables to import:

- `Add(Int32)` - imports the table at the specified table index.
- `Add(Int32, Int32)` - imports the table at the specified table index into the worksheet with the given target index.
- `Add(HtmlTableLoadOption)` - imports a table described by an <a href="https://reference.aspose.com/cells/net/aspose.cells/htmltableloadoption/" target="_blank" rel="nofollow noopener noreferrer">**HtmlTableLoadOption**</a> instance.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/htmltableloadoption/" target="_blank" rel="nofollow noopener noreferrer">**HtmlTableLoadOption**</a> class exposes the following properties to describe a single table:

- **Id** - the id of the table to import from HTML.
- **TableIndex** - the index of the table to import from HTML.
- **OriginalSheetIndex** - the original index of the worksheet in the HTML.
- **TargetSheetIndex** - the target index of the worksheet where the table is to be located.
- **TableToListObject** - indicates whether to generate list objects from the imported table. The default value is **false**.

If no table load option is specified, all the tables are imported. When options are added, only the referenced tables are imported. Tables that target the same worksheet are placed into it one after another in the order of the added options.

## Sample Code {#sample-code}

The following sample code loads the sample HTML file twice. The first time, tables are selected by table index (`1`, `2`) and by table id (`id5`, `id6`), and all of them are imported into the first worksheet. The options are then cleared and built again, this time sending each table to a specific worksheet by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmltableloadoption/properties/targetsheetindex/" target="_blank" rel="nofollow noopener noreferrer">**TargetSheetIndex**</a> property. Please download the <a href="https://docs.aspose.com/cells/net/html-table-load-option/HtmlTableLoadOption.htm" target="_blank" rel="nofollow noopener noreferrer">sample HTML file</a> used by the code.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

using System;
using Aspose.Cells;

namespace AsposeCellsExamples
{
    public class HtmlTableLoadOptionExample
    {
        public static void Main(string[] args)
        {
            HtmlLoadOptions loadOptions = new HtmlLoadOptions();
            loadOptions.SupportDivTag = true;

            // Add tables by their table index.
            loadOptions.TableLoadOptions.Add(1);
            loadOptions.TableLoadOptions.Add(2);

            // Add tables by their table id.
            HtmlTableLoadOption tableLoadOption = new HtmlTableLoadOption
            {
                Id = "id5"
            };
            loadOptions.TableLoadOptions.Add(tableLoadOption);

            tableLoadOption = new HtmlTableLoadOption
            {
                Id = "id6"
            };
            loadOptions.TableLoadOptions.Add(tableLoadOption);

            // Load the HTML file. The selected tables are imported into the first worksheet.
            Workbook wb = new Workbook("HtmlTableLoadOption.htm", loadOptions);
            wb.Save("HtmlTableLoadOption1.xlsx");

            Console.WriteLine(wb.Worksheets[0].Cells["A1"].StringValue); // "222aaa"
            Console.WriteLine(wb.Worksheets[0].Cells["A2"].StringValue); // "333aaa"
            Console.WriteLine(wb.Worksheets[0].Cells["A4"].StringValue); // "555aaa"
            Console.WriteLine(wb.Worksheets[0].Cells["A7"].StringValue); // "666aaa"

            // Rebuild the options and send each table to a specific worksheet.
            loadOptions.TableLoadOptions.Clear();
            loadOptions.TableLoadOptions.Add(0, 2);
            loadOptions.TableLoadOptions.Add(1, 0);
            loadOptions.TableLoadOptions.Add(2, 1);

            tableLoadOption = new HtmlTableLoadOption
            {
                Id = "id5",
                TargetSheetIndex = 0
            };
            loadOptions.TableLoadOptions.Add(tableLoadOption);

            tableLoadOption = new HtmlTableLoadOption
            {
                Id = "id6",
                TargetSheetIndex = 1
            };
            loadOptions.TableLoadOptions.Add(tableLoadOption);

            tableLoadOption = new HtmlTableLoadOption
            {
                Id = "id4",
                TargetSheetIndex = 2
            };
            loadOptions.TableLoadOptions.Add(tableLoadOption);

            wb = new Workbook("HtmlTableLoadOption.htm", loadOptions);
            wb.Save("HtmlTableLoadOption2.xlsx");

            Console.WriteLine(wb.Worksheets[0].Cells["B1"].StringValue); // "222bbb"
            Console.WriteLine(wb.Worksheets[0].Cells["B2"].StringValue); // "555bbb"
            Console.WriteLine(wb.Worksheets[1].Cells["B1"].StringValue); // "333bbb"
            Console.WriteLine(wb.Worksheets[1].Cells["B3"].StringValue); // "666bbb"
            Console.WriteLine(wb.Worksheets[2].Cells["C1"].StringValue); // "111ccc"
            Console.WriteLine(wb.Worksheets[2].Cells["C2"].StringValue); // "444ccc"
        }
    }
}
```

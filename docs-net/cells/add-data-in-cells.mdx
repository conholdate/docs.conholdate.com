## How to Add Data in Cells Using Aspose.Cells for .NET {#how-to-add-data-in-cells-using-asposecells-for-net}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a **WorksheetCollection** that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a **Cells collection**. Each item in the **Cells** collection represents an object of the **Cell** class.

**C#**

```cs
 //Instantiating a Workbook object

Workbook workbook = new Workbook();

//Accessing the added worksheet in the Excel file

Worksheet worksheet = workbook.Worksheets[0];

int x = 1;

for (int i = 1; i <= 15; i++)
{
    for (int j = 0; j < 15; j++)
    {
        worksheet.Cells[i, j].Value = x++;
    }
}

workbook.Save("test.xlsx");
```

## NPOI HSSF XSSF - Add Data in Cells {#npoi-hssf-xssf---add-data-in-cells}

In NPOI, `row.CreateCell(1).SetCellValue` can be used to add data in cells.

**C#**

```cs
 IWorkbook workbook = new XSSFWorkbook();
ISheet sheet1 = workbook.CreateSheet("Sheet1");

sheet1.CreateRow(0).CreateCell(0).SetCellValue("This is a Sample");

int x = 1;

for (int i = 1; i <= 15; i++)
{
	IRow row = sheet1.CreateRow(i);
	for (int j = 0; j < 15; j++)
	{
		row.CreateCell(j).SetCellValue(x++);
	}
}

FileStream sw = File.Create("test.xlsx");
workbook.Write(sw);
sw.Close();
```

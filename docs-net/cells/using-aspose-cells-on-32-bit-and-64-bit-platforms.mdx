:::info
Aspose.Cells is a pure .NET component that can simplify your deployment process by using XCOPY deployment. To install Aspose.Cells, you can simply copy the component assembly (Aspose.Cells.dll) into a directory for your application: the application can start using it right away. This is possible because of the self‑describing nature of .NET components. This type of deployment also has zero impact on the installation process.
:::

## Deployment {#deployment}

Aspose.Cells supports both 32‑bit and 64‑bit environments. When you install the Aspose.Cells for .NET component using the Aspose.Cells MSI installer, different DLLs are added to different folders in the Aspose.Cells `${installation_Path}` folder(s). See the table for a description of which folder contains the assemblies you need to use with a particular version of the .NET Framework.

:::info
In VS.NET (for example, 2005, 2008, 2010, 2012, etc.) projects, when adding a reference to Aspose.Cells, the Add Reference dialog refers to Aspose.Cells.dll files in the net2.0 or net3.5 folder(s) respectively. (For further reference, read *Referencing Aspose.Cells from a .NET project*.) You can change the reference to the library according to your environment. Please note that if the project's target framework is .NET Framework 3.5/4 Client Profile, you should use the Aspose.Cells.dll component file located in the net3.5_ClientProfile folder.
:::

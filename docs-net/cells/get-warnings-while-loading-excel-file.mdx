## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes the user tries to load the workbook which is somewhat corrupt but loadable. In such a case, Aspose.Cells throws warnings while loading the workbook. You can catch these warnings by implementing the <a href="https://reference.aspose.com/cells/net/aspose.cells/iwarningcallback" target="_blank" rel="nofollow noopener noreferrer">**IWarningCallback**</a> interface and setting <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions/properties/warningcallback" target="_blank" rel="nofollow noopener noreferrer">**LoadOptions.WarningCallback**</a> property.

## Get Warnings while Loading Excel File {#get-warnings-while-loading-excel-file}

The following sample code explains how to get warnings while loading an Excel file. The code loads the <a href="https://docs.aspose.com/cells/net/get-warnings-while-loading-excel-file/sampleDuplicateDefinedName.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> which throws a <a href="https://reference.aspose.com/cells/net/aspose.cells/warningtype" target="_blank" rel="nofollow noopener noreferrer">**DuplicateDefinedName**</a> warning when loading. This warning is then caught by <a href="https://reference.aspose.com/cells/net/aspose.cells/iwarningcallback/methods/warning" target="_blank" rel="nofollow noopener noreferrer">**IWarningCallback.Warning()**</a> method that prints the warning messages on the console. The code then saves the workbook as the <a href="https://docs.aspose.com/cells/net/get-warnings-while-loading-excel-file/outputDuplicateDefinedName.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. If you open the sample Excel file in Microsoft Excel, it will also display this warning to you as shown in this screenshot. Please also check the console output of the code given below for better understanding.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Implement IWarningCallback interface to catch warnings while loading workbook
private class WarningCallback : IWarningCallback
{
    public void Warning(WarningInfo warningInfo)
    {
        if (warningInfo.WarningType == WarningType.DuplicateDefinedName)
        {
            Console.WriteLine("Duplicate Defined Name Warning: " + warningInfo.Description);
        }
    }
}//WarningCallback

//------------------------------------------------------------------

// The path to the documents directory.
string dataDir = "./";

//Create load options and set the WarningCallback property 
//to catch warnings while loading workbook
LoadOptions options = new LoadOptions();
options.WarningCallback = new WarningCallback();

//Load the source excel file
Workbook book = new Workbook(dataDir + "sampleDuplicateDefinedName.xlsx", options);

//Save the workbook 
book.Save(dataDir + "outputDuplicateDefinedName.xlsx");
```

## How to set series invisible in Excel Chart {#how-to-set-series-invisible-in-excel-chart}

In an Excel chart, you can right-click a chart, click "Select Data", and in the pop-up window, you can set whether a series is visible by checking or unchecking it.\
You can download the following <a href="https://docs.aspose.com/cells/net/how-to-set-series-invisible/SeriesFiltered.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample file</a> and work with it in Excel as shown in the figure to achieve this function. Next, we will tell you how to achieve this using the Aspose.Cells library.

![todo:image_alt_text](/net/cells/images/fdf2cc99a2ebd94c-series-invisible.png)

## How to set series invisible using Aspose.Cells {#how-to-set-series-invisible-using-asposecells}

We use the following code to set series invisible using Aspose.Cells:

```csharp
            //Set series invisible using Aspose.Cells
            string filePath = @"";
            Workbook workbook = new Workbook(filePath + "SeriesFiltered.xlsx");
            ChartCollection charts = workbook.Worksheets[0].Charts;
            Chart chart = charts["Chart 1"];
            SeriesCollection nSeriesFiltered = chart.FilteredNSeries;
            SeriesCollection nSeries = chart.NSeries;
            nSeries[1].IsFiltered = true;
            nSeries[0].IsFiltered = true;
            workbook.Save(filePath + "output.xlsx");
```

You can get the following <a href="https://docs.aspose.com/cells/net/how-to-set-series-invisible/SeriesFiltered.xlsx" target="_blank" rel="nofollow noopener noreferrer">Input file</a> and <a href="https://docs.aspose.com/cells/net/how-to-set-series-invisible/output.xlsx" target="_blank" rel="nofollow noopener noreferrer">output file</a>.

As shown in the figure below, the first two series which were originally visible have become invisible in the output file. ![todo:image_alt_text](/net/cells/images/8f681664380bed52-output.png)

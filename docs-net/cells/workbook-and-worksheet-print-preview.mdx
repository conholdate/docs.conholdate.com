After creating a worksheet, you often want to print a hard copy of it. This article explains how to print spreadsheets with Aspose.Cells.
:::

## Print Introduction {#print-introduction}

Microsoft Excel assumes that you want to print the entire worksheet area unless you specify a selection. To print using Aspose.Cells, first import the Aspose.Cells.Rendering namespace into the program. It has several useful classes, for example, <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender" target="_blank" rel="nofollow noopener noreferrer">**SheetRender**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookrender" target="_blank" rel="nofollow noopener noreferrer">**WorkbookRender**</a>.

### Print Using SheetRender {#print-usingsheetrender}

The <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Rendering.SheetRender**</a> class represents a worksheet and has the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender/methods/toprinter/index" target="_blank" rel="nofollow noopener noreferrer">**ToPrinter**</a> method which can print a worksheet. The following sample code shows how to print a worksheet.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a workbook with Excel file.
Workbook workbook = new Workbook(dataDir + "SampleBook.xlsx");

string printerName = "";

while (string.IsNullOrEmpty(printerName) && string.IsNullOrWhiteSpace(printerName))
{
    Console.WriteLine("Please Enter Your Printer Name:");
    printerName = Console.ReadLine();
}

// Define a worksheet.
Worksheet worksheet;

// Get the second sheet.
worksheet = workbook.Worksheets[1];

// Apply different Image/Print options.
Aspose.Cells.Rendering.ImageOrPrintOptions options = new Aspose.Cells.Rendering.ImageOrPrintOptions();
options.PrintingPage = PrintingPageType.Default;
SheetRender sr = new SheetRender(worksheet, options);

Console.WriteLine("Printing SampleBook.xlsx");
// Print the sheet.
try
{
    sr.ToPrinter(printerName);
    Console.WriteLine("Pinting finished.");
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

### Print Using WorkbookRender {#print-usingworkbookrender}

To print a whole workbook, iterate through the sheets and print them, or use the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookrender" target="_blank" rel="nofollow noopener noreferrer">**WorkbookRender**</a> class.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

// Instantiate a workbook with an Excel file.
Workbook workbook = new Workbook(sourceDir + "samplePrintingUsingWorkbookRender.xlsx");

string printerName = "doPDF 8";

// Apply different Image/Print options.
Aspose.Cells.Rendering.ImageOrPrintOptions options = new Aspose.Cells.Rendering.ImageOrPrintOptions();
options.ImageType = Drawing.ImageType.Tiff;
options.PrintingPage = PrintingPageType.Default;

// To print a whole workbook, iterate through the sheets and print them, or use the WorkbookRender class.
WorkbookRender wr = new WorkbookRender(workbook, options);
            
try
{
    // Print the workbook.
    wr.ToPrinter(printerName);
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

:::info
Aspose.Cells also provides overloads for the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering.workbookrender/toprinter/methods/3" target="_blank" rel="nofollow noopener noreferrer">**WorkbookRender.ToPrinter()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering.sheetrender/toprinter/methods/2" target="_blank" rel="nofollow noopener noreferrer">**SheetRender.ToPrinter()**</a> methods, so it's possible to set the print job name while printing Excel spreadsheets. By default, all print jobs are created with the name "Document".
:::

## Print Preview {#print-preview}

There may be cases where Excel files with millions of pages need to be converted to PDF or images. Processing such files will consume a lot of time and resources. In such cases, the Workbook and Worksheet Print Preview feature might prove to be useful. Before converting such files, the user can check the total number of pages and then decide whether the file is to be converted or not. This article focuses on using the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> classes to find out the total number of pages.

Aspose.Cells provides the print preview feature. For this, the API provides <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> classes. To create the print preview of the whole workbook, create an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> class by passing <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions**</a> objects to the constructor. The <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> class provides an <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview/properties/evaluatedpagecount" target="_blank" rel="nofollow noopener noreferrer">**EvaluatedPageCount**</a> property which returns the number of pages in the generated preview. Similar to <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> class, the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> class is used to generate a print preview for a specific worksheet. To create the print preview of a worksheet, create an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> class by passing <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions**</a> objects to the constructor. The <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> class also provides an <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview/properties/evaluatedpagecount" target="_blank" rel="nofollow noopener noreferrer">**EvaluatedPageCount**</a> property which returns the number of pages in the generated preview.

The following code snippet demonstrates the use of both <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**WorkbookPrintingPreview**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetprintingpreview" target="_blank" rel="nofollow noopener noreferrer">**SheetPrintingPreview**</a> classes by using the <a href="https://docs.aspose.com/cells/net/workbook-and-worksheet-print-preview/94896177.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

Workbook workbook = new Workbook(sourceDir + "Book1.xlsx");
ImageOrPrintOptions imgOptions = new ImageOrPrintOptions();
WorkbookPrintingPreview preview = new WorkbookPrintingPreview(workbook, imgOptions);
Console.WriteLine("Workbook page count: " + preview.EvaluatedPageCount);

SheetPrintingPreview preview2 = new SheetPrintingPreview(workbook.Worksheets[0], imgOptions);
Console.WriteLine("Worksheet page count: " + preview2.EvaluatedPageCount);
```

The following is the output generated by executing the above code.

### Console Output {#console-output}

```java
Workbook page count: 1
Worksheet page count: 1
```

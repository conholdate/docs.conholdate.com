## Possible Usage Scenarios {#possible-usage-scenarios}

You can find whether data points of a series are in the second pie of a *Pie of Pie* chart or in the bar of a *Bar of Pie* chart using Aspose.Cells. Please use the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chartpoint/properties/isinsecondaryplot" target="_blank" rel="nofollow noopener noreferrer">ChartPoint.IsInSecondaryPlot</a> property to determine this.

Please download the <a href="https://docs.aspose.com/cells/net/find-if-data-points-are-in-the-second-pie-or-bar-on-a-pie-of-pie-or-bar-of-pie-chart/5115193.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in the following sample code and see its console output. If you open the <a href="https://docs.aspose.com/cells/net/find-if-data-points-are-in-the-second-pie-or-bar-on-a-pie-of-pie-or-bar-of-pie-chart/5115193.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>, you will find that all the data points that are less than 10 are inside the bar of the *Bar of Pie* chart, as also shown by the console output.

## Find if Data Points are in the Second Pie or Bar on a Pie of Pie or Bar of Pie Chart {#find-if-data-points-are-in-the-second-pie-or-bar-on-a-pie-of-pie-or-bar-of-pie-chart}

The following sample code shows how to find if data points are in the second pie or bar on a *Pie of Pie* or *Bar of Pie* chart.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

//Load source excel file containing Bar of Pie chart
Workbook wb = new Workbook(dataDir + "PieBars.xlsx");

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Access first chart which is Bar of Pie chart and calculate it
Chart ch = ws.Charts[0];
ch.Calculate();

// Access the chart series
Series srs = ch.NSeries[0];

/* 
 * Print the data points of the chart series and 
 * check its IsInSecondaryPlot property to determine 
 * if data point is inside the bar or pie 
*/
for (int i = 0; i < srs.Points.Count; i++)
{
    //Access chart point
    ChartPoint cp = srs.Points[i];

    //Skip null values
    if (cp.YValue == null)
        continue;

   /* 
     * Print the chart point value and see if it is inside bar or pie.
     * If the IsInSecondaryPlot is true, then the data point is inside bar 
     * otherwise it is inside the pie. 
   */
    Console.WriteLine("Value: " + cp.YValue);
    Console.WriteLine("IsInSecondaryPlot: " + cp.IsInSecondaryPlot);
    Console.WriteLine();
}
```

## Possible Usage Scenarios {#possible-usage-scenarios}

This article explains the working of GridWeb when ASP.NET Session state mode is SQL Server.

## Working of GridWeb when ASP.NET Session state mode is SQL Server {#working-of-gridweb-when-aspnet-session-state-mode-is-sql-server}

If you want to use SQL Server or StateServer to hold sessions, use GridWeb Session Mode. The GridWeb control now supports serializing its data to SQL Server or StateServer.

Set the `GridWeb.SessionMode` to `SessionMode.Session` and use the following sample Web.Config settings. Please change the `sessionState` attributes as per your needs.

## Sample Web.Config Session State Settings {#sample-webconfig-session-state-settings}

```xml
<sessionState mode="SQLServer" sqlConnectionString="Password=11111111;Persist Security Info=True;User ID=testuser;Data Source=WINSHA-PC\NASIRSQL" timeout="20"></sessionState>
```

Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
This topic discusses showing the Add/Remove buttons for adding and removing worksheets in the Aspose.Cells.GridWeb control.
:::

Aspose.Cells GridWeb now supports adding and removing sheets by using buttons in the toolbar. For the buttons to be visible on the frontend, you need to set **GridWeb1.ShowAddButton** to **true**. The following code snippet demonstrates adding Add/Remove buttons to the GridWeb toolbar.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
protected void Page_Load(object sender, EventArgs e)
{
    GridWeb1.SheetAdded += GridSheetAdded;
    // If first visit this page clear GridWeb1 and load data 
    if (!IsPostBack && !GridWeb1.IsPostBack)
    {
		// Show button to add and delete sheet
        GridWeb1.ShowAddButton = true;
		
        GridWeb1.WorkSheets.Clear();
        GridWeb1.WorkSheets.Add();
    }
}

void GridSheetAdded(object sender, GridWorksheet sheet)
{
    sheet.Cells.StandardHeightPixels = 30;
    sheet.Cells.StandardWidthPixels = 100;
}
```

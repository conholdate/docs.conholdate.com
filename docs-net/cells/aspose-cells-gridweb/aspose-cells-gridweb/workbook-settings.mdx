For example, the following code sets **ReCalculateOnOpen** to false to stop the calculation when opening the file:

```csharp
    GridWorkbookSettings gws = new GridWorkbookSettings();
   //do not re-calculate all formulas on opening the file.
    gws.ReCalculateOnOpen = false;
    GridWeb1.Settings = gws;
    GridWeb1.ImportExcelFile(@"c:\test.xlsx");
```

The following code sets the author for the file:

```csharp
    GridWorkbookSettings gws = new GridWorkbookSettings();
   //set author.
    gws.Author = "peter";
    GridWeb1.Settings = gws;
    GridWeb1.ImportExcelFile(@"c:\test.xlsx");
```

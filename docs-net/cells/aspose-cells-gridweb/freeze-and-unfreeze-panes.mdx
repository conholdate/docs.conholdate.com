:::info
This topic explains how to freeze and unfreeze rows and columns. Freezing columns or rows allows users to keep the column headings or row titles visible while they scroll to other parts of the worksheet. This feature is very helpful when working with worksheets that contain large volumes of data. When users scroll, only the data is scrolled down and the headings stay in place, making the data easier to read. The Freeze Panes feature is only supported in Internet Explorer 6.0 or above.
:::

## Freezing Rows & Columns {#freezing-rows--columns}

To freeze a specific number of rows and columns:

1. Add the Aspose.Cells.GridWeb control to a Web Form.
2. Access a worksheet.
3. Freeze a number of rows and columns.

:::info
It is also possible to freeze a specific number of rows and columns using the interface. Right‑click a cell where you want to freeze rows and columns and select **Freeze** from the list.
:::

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Get user inputs for row, column, number of rows and number of columns
int row = Convert.ToInt16(txtRow.Text.Trim());
int column = Convert.ToInt16(txtColumn.Text.Trim());
int noOfRows = Convert.ToInt16(txtNoOfRows.Text.Trim());
int noOfColumns = Convert.ToInt16(txtNoOfColumns.Text.Trim());

// Accessing the reference of the worksheet that is currently active
GridWorksheet sheet = GridWeb1.WorkSheets[GridWeb1.ActiveSheetIndex];

// Freeze desired rows and columns
sheet.FreezePanes(row, column, noOfRows, noOfColumns);
```

## Unfreezing Rows & Columns {#unfreezing-rows--columns}

To unfreeze rows and columns:

1. Add the Aspose.Cells.GridWeb control to a Web Form.
2. Access a worksheet.
3. Unfreeze rows and columns.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Accessing the reference of the worksheet that is currently active
GridWorksheet sheet = GridWeb1.WorkSheets[GridWeb1.ActiveSheetIndex];

// Unfreezing rows and columns
sheet.UnFreezePanes();
```

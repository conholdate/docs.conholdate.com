## Introduction {#introduction}

Aspose.Cells for .NET provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a> namespace, which simplifies common spreadsheet processing tasks. This API is designed for developers who want to accomplish high‑level operations such as HTML conversion, image conversion, JSON conversion, PDF conversion, spreadsheet conversion, spreadsheet merging, spreadsheet locker, and spreadsheet splitter with minimal effort.

The LowCode API is ideal for scenarios where quick implementation is more important than fine‑grained control. Aspose.Cells LowCode APIs provide a high‑level, declarative way to perform common spreadsheet tasks (conversion, merging, splitting, etc.) without writing extensive boiler‑plate code. Let's take a closer look at the LowCode capabilities of Aspose.Cells for .NET.

## Lock a Spreadsheet - SpreadsheetLocker {#lock-a-spreadsheet--spreadsheetlocker}

If you want to lock a spreadsheet, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> class to perform the locking task without writing extensive boiler‑plate code. The following code demonstrates how to lock a <a href="https://docs.aspose.com/cells/net/lock-spreadsheets-using-lowcode-api/lowcode-locker.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample file</a> using the LowCode API.

```csharp
SpreadsheetLocker.Process("lowcode-locker.xlsx", "lowcode-locker-output.xlsx", "open123", "write123");
```

## Lock a Spreadsheet - SpreadsheetLocker & AbstractLowCodeProtectionProvider {#lock-a-spreadsheet--spreadsheetlocker--abstractlowcodeprotectionprovider}

If you want to lock a spreadsheet, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> class to perform the locking task without writing extensive boiler‑plate code. <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/abstractlowcodeprotectionprovider/" target="_blank" rel="nofollow noopener noreferrer">AbstractLowCodeProtectionProvider</a> lets you fine‑tune the lock behavior. The following code demonstrates how to lock a <a href="https://docs.aspose.com/cells/net/lock-spreadsheets-using-lowcode-api/lowcode-locker.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample file</a> using <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/abstractlowcodeprotectionprovider/" target="_blank" rel="nofollow noopener noreferrer">AbstractLowCodeProtectionProvider</a>.

```csharp
// Prepare LowCodeLoadOptions
LowCodeLoadOptions loadOptions = new LowCodeLoadOptions();
loadOptions.InputFile = filePath + "lowcode-locker.xlsx";

// Prepare LowCodeSaveOptions
LowCodeSaveOptions saveOptions = new LowCodeSaveOptions();
saveOptions.SaveFormat = SaveFormat.Xlsx;
saveOptions.OutputFile = filePath + "lowcode-locker-output.xlsx";

// Create a custom protection provider
CustomProtectionProvider provider = new CustomProtectionProvider();

// Call the static Process method with specified parameters
SpreadsheetLocker.Process(loadOptions, saveOptions, provider);


private class CustomProtectionProvider : AbstractLowCodeProtectionProvider
{
    public override string GetOpenPassword()
    {
        return "open123";
    }

    public override string GetWritePassword()
    {
        return "write123";
    }

    public override string GetWorkbookPassword()
    {
        return "workbook123";
    }

    public override ProtectionType GetWorkbookProtectionType()
    {
        return ProtectionType.All;
    }
}
```

Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
If you want to set the text of the chart's legend entry fill to none, so that it does not display inside the chart legend, then please set the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/legendentry/properties/istextnofill" target="_blank" rel="nofollow noopener noreferrer">**LegendEntry.IsTextNoFill**</a> to **true**.
:::

The following sample code sets the text of the chart's second legend entry fill to none. Please download the <a href="https://docs.aspose.com/cells/net/set-text-of-chart-legend-entry-fill-to-none-using-aspose-cells/5115219.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in this code and the <a href="https://docs.aspose.com/cells/net/set-text-of-chart-legend-entry-fill-to-none-using-aspose-cells/5115217.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated by it for your reference.

The following screenshot highlights the effect of this code on the <a href="https://docs.aspose.com/cells/net/set-text-of-chart-legend-entry-fill-to-none-using-aspose-cells/5115219.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>.

![todo:image_alt_text](/net/cells/images/d563fc1d7b6e518b-set-text-of-chart-legend-entry-fill-to-none-using-aspose-cells_1.png)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Open the template file.
Workbook workbook = new Workbook(dataDir + "Sample.xlsx");

// Access the first worksheet
Worksheet sheet = workbook.Worksheets[0];

// Access the first chart inside the sheet
Chart chart = sheet.Charts[0];

// Set text of second legend entry fill to none
chart.Legend.LegendEntries[1].IsTextNoFill = true;

// Save the workbook in xlsx format
workbook.Save(dataDir + "ChartLegendEntry_out.xlsx", SaveFormat.Xlsx);
```

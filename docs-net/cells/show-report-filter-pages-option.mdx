## Show report filter pages option {#show-report-filter-pages-option}

Excel supports creating pivot tables, adding report filters, and enabling the **"Show Report Filter Pages"** option. Aspose.Cells also supports this feature, enabling the **"Show Report Filter Pages"** option on the created pivot table. The following screenshot shows the **"Show Report Filter Pages"** option in Excel.

![todo:image_alt_text](/net/cells/images/a0841490663f9928-show-report-filter-pages-option_1.png)

Sample source file and output files can be downloaded from here for testing the sample code:

<a href="https://docs.aspose.com/cells/net/show-report-filter-pages-option/81920786.xlsx" target="_blank" rel="nofollow noopener noreferrer">Source Excel File</a>

<a href="https://docs.aspose.com/cells/net/show-report-filter-pages-option/81920787.xlsx" target="_blank" rel="nofollow noopener noreferrer">Output Excel File</a>

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Load template file
// The path to the documents directory.
string sourceDir = "./";
Workbook wb = new Workbook(sourceDir + "samplePivotTable.xlsx");

// Get first pivot table in the worksheet
PivotTable pt = wb.Worksheets[1].PivotTables[0];

// Set pivot field
pt.ShowReportFilterPage(pt.PageFields[0]);

// Set position index for showing report filter pages
pt.ShowReportFilterPageByIndex(pt.PageFields[0].Position);

// Set the page field name
pt.ShowReportFilterPageByName(pt.PageFields[0].Name);

// Save the output file
// The path to the documents directory.
string outputDir = "./";
wb.Save(outputDir + "outputSamplePivotTable.xlsx");
```

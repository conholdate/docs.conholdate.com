## Introduction {#introduction}

In this article, we will learn how to display certain rows and/or columns in separate panes by splitting the worksheet into two or four parts. When working with large datasets, we need to see a few areas of the same worksheet at a time to compare different subsets of data. The split screen function can meet your needs.

## How to split screen in Excel {#how-to-split-screen-in-excel}

To split up a worksheet into two or four parts, do the following:

1. Select the row/column/cell before which you want to place the split.
2. On the **View** tab, in the **Window** group, click the **Split** button.

**![Split Screen](/net/cells/images/4231a39f16692c94-Split-Screen.png)**

## Split worksheet vertically on columns {#split-worksheet-vertically-on-columns}

To separate two areas of the spreadsheet vertically, select the column to the right of the column where you wish the split to appear and click the **Split** button in Excel.

It's easy to split a worksheet vertically on columns programmatically with Aspose.Cells for .NET; we only need to select one cell in the top row as the active cell, then split with the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/split/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Split**</a> method.

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("Book1.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Sets C1 cell in the top row as the active cell.
sheet.ActiveCell = "C1";

//Split worksheet vertically on columns
sheet.Split();
```

## Split worksheet horizontally on rows {#split-worksheet-horizontally-on-rows}

To separate your Excel window horizontally, select the row below the row where you want the split to occur in Excel.

It's easy to split a worksheet horizontally on rows programmatically with Aspose.Cells for .NET; we only need to select one cell in the left column as the active cell, then split with the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/split/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Split**</a> method.

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("Book1.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Sets A6 cell in the left column as the active cell.
sheet.ActiveCell = "A6";

//Split worksheet horizontally on rows
sheet.Split();

workbook.Save("dest.xlsx");
```

## Split worksheet into four parts {#split-worksheet-into-four-parts}

To view four different sections of the same worksheet simultaneously, split your screen both vertically and horizontally in Excel.

It's easy to split a worksheet into four parts programmatically with Aspose.Cells for .NET; we only need to select one cell that is not in the first row or column as the active cell, then split with the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/split/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Split**</a> method.

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("Book1.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Sets E6 cell as the active cell.
sheet.ActiveCell = "E6";

//Split worksheet into four parts
sheet.Split();
```

## How to remove split {#how-to-remove-split}

To remove the worksheet split, just click the **Split** button again.

Aspose.Cells for .NET provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/removesplit/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.RemoveSplit**</a> method to remove the split setting.

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("Book1.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Remove split.
sheet.RemoveSplit();

//Split worksheet into four parts
sheet.Split();
```

Aspose.Cells provides a feature to replace text in a workbook using a regular expression. For this, the API provides the **<a href="https://reference.aspose.com/cells/net/aspose.cells/replaceoptions/properties/regexkey" target="_blank" rel="nofollow noopener noreferrer">RegexKey</a>** property of the **<a href="https://reference.aspose.com/cells/net/aspose.cells/replaceoptions" target="_blank" rel="nofollow noopener noreferrer">ReplaceOptions</a>** class. Setting the **RegexKey** to **true** indicates that the searched key will be a regular expression.

The following code snippet demonstrates the use of the **RegexKey** property by using the **sample Excel file**(<a href="https://docs.aspose.com/cells/net/replace-text-in-a-workbook-using-regular-expression/101089318.xlsx" target="_blank" rel="nofollow noopener noreferrer">101089318.xlsx</a>). The **output file**(<a href="https://docs.aspose.com/cells/net/replace-text-in-a-workbook-using-regular-expression/101089319.xlsx" target="_blank" rel="nofollow noopener noreferrer">101089319.xlsx</a>) generated by the following code snippet is attached for reference.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

Workbook workbook = new Workbook(sourceDir + "SampleRegexReplace.xlsx");

ReplaceOptions replace = new ReplaceOptions();
replace.CaseSensitive = false;
replace.MatchEntireCellContents = false;
// Set to true to indicate that the searched key is regex
replace.RegexKey = true;

workbook.Replace("\\bKIM\\b", "^^^TIM^^^", replace);
workbook.Save(outputDir + "RegexReplace_out.xlsx");
```

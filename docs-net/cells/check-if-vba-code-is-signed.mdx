:::info
Aspose.Cells allows the user to check whether a VBA code project is signed. Please use the <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/properties/issigned" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.IsSigned**</a> property to check if the VBA code project is signed.
:::

The following code explains how to check if the VBA code is signed using the <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbaproject/properties/issigned" target="_blank" rel="nofollow noopener noreferrer">**Workbook.VbaProject.IsSigned**</a> property. You can use any of your Excel files to test this code. For testing purposes, you can use <a href="https://docs.aspose.com/cells/net/check-if-vba-code-is-signed/5115032.xlsm" target="_blank" rel="nofollow noopener noreferrer">this Excel file used in the code</a>.

## Check if VBA Code is Signed in C# {#check-if-vba-code-is-signed-in-c}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

Workbook workbook = new Workbook(dataDir + "sampleVBAProjectSigned.xlsm");

Console.WriteLine("Is VBA Code Project Signed: " + workbook.VbaProject.IsSigned);
```

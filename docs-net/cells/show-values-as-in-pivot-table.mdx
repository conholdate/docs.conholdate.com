## Possible Usage Scenarios {#possible-usage-scenarios}

A pivot table normally aggregates each data field with an aggregate function such as `Sum` or `Count`. Excel's **Show Values As** feature replaces each displayed result with a secondary calculation derived from that aggregate-for example, a percentage of the grand total, a running total, a difference from a chosen base item, or a rank-so you can perform comparative analysis without helper formulas or calculated columns. Typical uses include share-of-total analysis, including percentages of a row, column, or grand total; cumulative reporting using a running total in a period field; variance analysis against a benchmark item using difference from or percentage difference from a base item; and ranking values from smallest to largest or largest to smallest. In Aspose.Cells for .NET, `PivotFieldDataDisplayFormat` selects the secondary calculation. The read-only `PivotField.ShowValuesSetting` property returns a `PivotShowValuesSetting` object, whose writable `CalculationType`, `BaseFieldIndex`, `BaseItemPositionType`, and `BaseItemIndex` properties configure the behavior; the convenience method `PivotField.ShowValuesAs(...)` applies the same four settings in one call. Apply these settings to a data or value field obtained from `PivotTable.DataFields`.

## PivotFieldDataDisplayFormat Enumeration Members {#pivotfielddatadisplayformat-enumeration-members}

The data field keeps its aggregate function, such as Sum or Count, while Show Values As transforms only how the aggregated value is displayed. Besides writing the `PivotShowValuesSetting` properties directly (see the last section), a one-call convenience method applies the same configuration:

```csharp
public void ShowValuesAs(PivotFieldDataDisplayFormat displayFormat, int baseField, PivotItemPositionType baseItemPositionType, int baseItem)
```

## Show Values as Percentage of Total {#show-values-as-percentage-of-total}

Call the `PivotField.ShowValuesAs` method with `PivotFieldDataDisplayFormat.PercentageOfTotal` to convert every data-field cell, including the grand total, into its share of the grand total. The displayed numbers therefore read as proportions of the complete result set. This format measures every value against the grand total only, so it needs no base field or base item - the trailing arguments (`0`, `PivotItemPositionType.Previous`, `0`) are placeholders the format ignores, as the parameter table above notes.

```csharp
using Aspose.Cells;
using Aspose.Cells.Pivot;
// Load or create a workbook with source data
Workbook workbook = new Workbook();
Worksheet dataSheet = workbook.Worksheets[0];
dataSheet.Cells["A1"].PutValue("Fruit");
dataSheet.Cells["B1"].PutValue("Amount");
string[] fruits = { "Apple", "Banana", "Apple", "Cherry", "Banana", "Apple" };
int[] amounts = { 10, 20, 30, 40, 50, 60 };
for (int i = 0; i < fruits.Length; i++)
{
    dataSheet.Cells[i + 1, 0].PutValue(fruits[i]);
    dataSheet.Cells[i + 1, 1].PutValue(amounts[i]);
}
// Add a pivot table on a new worksheet
int pivotSheetIndex = workbook.Worksheets.Add();
PivotTable pivotTable = workbook.Worksheets[pivotSheetIndex].PivotTables.Add("=Sheet1!A1:B7", 2, 2);
pivotTable.AddFieldToArea(PivotFieldType.Row, "Fruit");
pivotTable.AddFieldToArea(PivotFieldType.Data, "Amount");
pivotTable.CalculateData();
// Show the Amount data field as a percentage of the grand total with the
// one-call method; PercentageOfTotal takes no base item, so the trailing
// base arguments (0, Previous, 0) are placeholders the format ignores
PivotField dataField = pivotTable.DataFields[0];
dataField.ShowValuesAs(PivotFieldDataDisplayFormat.PercentageOfTotal, 0, PivotItemPositionType.Previous, 0);
pivotTable.CalculateData();
// Body now reads: Apple 47.62%, Banana 33.33%, Cherry 19.05%, Grand Total 100.00%
workbook.Save("ShowValuesAsPercentageOfTotal.xlsx");
```

## Get and Configure PivotField.ShowValuesSetting {#get-and-configure-pivotfieldshowvaluessetting}

Read the current configuration through `PivotField.ShowValuesSetting`: the read-only property returns the field's `PivotShowValuesSetting` object, whose four properties describe the active Show Values As calculation. To change the configuration, call the `PivotField.ShowValuesAs` method - it writes all four settings in one call, so you never need to assign the properties one by one. The `PivotShowValuesSetting` object exposes the four properties `ShowValuesAs` writes:

- `CalculationType` selects the `PivotFieldDataDisplayFormat` secondary calculation.
- `BaseFieldIndex` specifies the zero-based index of the base field within the pivot fields. It is used by the base-relative formats.
- `BaseItemPositionType` determines how the base item is positioned relative to the current item and accepts `PivotItemPositionType.Next`, `PivotItemPositionType.Previous`, or `PivotItemPositionType.Custom`.
- `BaseItemIndex` specifies the zero-based base item index and is used when `BaseItemPositionType` is `Custom`. After calling `ShowValuesAs`, call `PivotTable.CalculateData()` again so the pivot body is recalculated and rerendered with the updated configuration.

```csharp
using System;
using Aspose.Cells;
using Aspose.Cells.Pivot;
Workbook workbook = new Workbook("ShowValuesAsPercentageOfTotal.xlsx");
PivotTable pivotTable = workbook.Worksheets[1].PivotTables[0];
PivotField dataField = pivotTable.DataFields[0];
// Read the current show-values settings
PivotShowValuesSetting settings = dataField.ShowValuesSetting;
Console.WriteLine($"CalculationType: {settings.CalculationType}");
Console.WriteLine($"BaseFieldIndex: {settings.BaseFieldIndex}");
Console.WriteLine($"BaseItemPositionType: {settings.BaseItemPositionType}");
Console.WriteLine($"BaseItemIndex: {settings.BaseItemIndex}");
// Switch to a base-item calculation with the one-call method: difference
// from the value of the previous item in the row field
dataField.ShowValuesAs(PivotFieldDataDisplayFormat.DifferenceFrom,
    pivotTable.RowFields[0].BaseIndex, PivotItemPositionType.Previous, 0);
pivotTable.CalculateData();
// Note: the percentage number format saved by the previous example still
// clings to the data field cells; the underlying values are now differences
// Re-read the applied configuration
Console.WriteLine($"CalculationType now: {dataField.ShowValuesSetting.CalculationType}");
workbook.Save("ShowValuesAsDifferenceFrom.xlsx");
```

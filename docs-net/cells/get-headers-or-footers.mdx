:::info
Headers and footers are displayed only in Page Layout view, Print Preview, and on printed pages.

You can also use the Page Setup dialog box if you want to view headers or footers for more than one worksheet at a time.

For other sheet types, such as chart sheets, or charts, you can insert headers and footers only by using the Page Setup dialog box.
:::

## Getting Headers and Footers in MS Excel {#getting-headers-and-footers-in-ms-excel}

1. Click the worksheet where you want to view or change headers or footers.
2. On the **View** tab, in the Workbook Views group, click **Page Layout**.\
   Excel displays the worksheet in Page Layout view.
3. To view or edit a header or footer, click the left, center, or right header or footer text box at the top or the bottom of the worksheet page (under Header or above Footer).

## Getting Headers and Footers using Aspose.Cells for .NET {#getting-headers-and-footers-using-asposecells-for-net}

With <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/getheader/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.PageSetup.GetHeader**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/getfooter/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.PageSetup.GetFooter**</a> methods, a .NET developer can simply get headers or footers from the file.

1. Construct a Workbook to open the file.
2. Get the worksheet where you want to get the header or footer.
3. Get the header or footer with a specific section ID.

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("HeaderFooter.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Gets left section of header
Console.WriteLine(sheet.PageSetup.GetHeader(0));
//Gets center section of header
Console.WriteLine(sheet.PageSetup.GetHeader(1));
//Gets right section of header
Console.WriteLine(sheet.PageSetup.GetHeader(2));
//Gets center section of footer
Console.WriteLine(sheet.PageSetup.GetFooter(1));
```

## Parse Headers and Footers to Command List {#parse-headers-and-footers-to-command-list}

The header or footer text can contain special commands, for example, a placeholder for the page number, current date, or text formatting attributes.

Special commands are represented by a single letter with a leading ampersand ("&").

The header and footer strings are constructed using ABNF grammar. It's not easy to understand without a viewer.

Aspose.Cells for .NET provides <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/getcommands/" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.PageSetup.GetCommands**</a> method to parse headers and footers into a command list.

The following code shows how to parse a header or footer as a command list and process commands:

```csharp
// Instantiate a new Workbook.
Workbook workbook = new Workbook("HeaderFooter.xlsx");

Worksheet sheet = workbook.Worksheets[0];

//Gets left section of header
string headerSection = sheet.PageSetup.GetHeader(0);

HeaderFooterCommand[] commands = sheet.PageSetup.GetCommands(headerSection);
foreach (HeaderFooterCommand c in commands)
{
    switch (c.Type)
    {
        case HeaderFooterCommandType.SheetName:
            //embedded the name of the sheet to header or footer
            break;
    }
}
```

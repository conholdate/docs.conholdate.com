## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells returns the HTML string of the cell using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/gethtmlstring" target="_blank" rel="nofollow noopener noreferrer">**GetHtmlString**</a> method, which accepts a boolean parameter. If you pass **false** as a parameter, it will return normal HTML, but if you pass **true** as a parameter, it will return an HTML5 string.

## Get HTML5 string from Cell {#get-html5-string-from-cell}

The following sample code creates a workbook object and adds some text in cell A1 of the first worksheet. It then gets the normal HTML and HTML5 strings from cell A1 using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/gethtmlstring" target="_blank" rel="nofollow noopener noreferrer">**GetHtmlString**</a> method and prints them on the console.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create workbook.
Workbook wb = new Workbook();

//Access first worksheet.
Worksheet ws = wb.Worksheets[0];

//Access cell A1 and put some text inside it.
Cell cell = ws.Cells["A1"];
cell.PutValue("This is some text.");

//Get the Normal and Html5 strings.
string strNormal = cell.GetHtmlString(false);
string strHtml5 = cell.GetHtmlString(true);

//Print the Normal and Html5 strings on console.
Console.WriteLine("Normal:\r\n" + strNormal);
Console.WriteLine();
Console.WriteLine("Html5:\r\n" + strHtml5);
```

## Console Output {#console-output}

```java
 Normal:

<Font Style="FONT-FAMILY: Arial;FONT-SIZE: 10pt;COLOR: #000000;">This is some text.</Font>

HTML5:

<div Style="FONT-FAMILY: Arial;FONT-SIZE: 10pt;COLOR: #000000;">This is some text.</div>
```

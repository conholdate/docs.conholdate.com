## Possible Usage Scenarios {#possible-usage-scenarios}

You can link your cells to XML Map elements using Aspose.Cells. Please use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/linktoxmlmap" target="_blank" rel="nofollow noopener noreferrer">**Cells.LinkToXmlMap()**</a> method for this purpose.

## Link Cells to XML Map Elements {#link-cells-to-xml-map-elements}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/link-cells-to-xml-map-elements/5115471.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a>, which contains an XML Map, and then links cells A1, B2, C3, D4, E5, and F6 to XML Map elements FIELD1, FIELD2, FIELD4, FIELD5, FIELD7, and FIELD8, respectively, and then saves the workbook as the <a href="https://docs.aspose.com/cells/net/link-cells-to-xml-map-elements/5115467.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

If you open the <a href="https://docs.aspose.com/cells/net/link-cells-to-xml-map-elements/5115467.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> and click the **Developer &gt; Source** button, you will see the cells are linked to XML Map elements, and they will also be highlighted by Microsoft Excel as shown in this image.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Load sample workbook
Workbook wb = new Workbook(dataDir + "sample.xlsx");

// Access the Xml Map inside it
XmlMap map = wb.Worksheets.XmlMaps[0];

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Map FIELD1 and FIELD2 to cell A1 and B2
ws.Cells.LinkToXmlMap(map.Name, 0, 0, "/root/row/FIELD1");
ws.Cells.LinkToXmlMap(map.Name, 1, 1, "/root/row/FIELD2");

// Map FIELD4 and FIELD5 to cell C3 and D4
ws.Cells.LinkToXmlMap(map.Name, 2, 2, "/root/row/FIELD4");
ws.Cells.LinkToXmlMap(map.Name, 3, 3, "/root/row/FIELD5");

// Map FIELD7 and FIELD8 to cell E5 and F6
ws.Cells.LinkToXmlMap(map.Name, 4, 4, "/root/row/FIELD7");
ws.Cells.LinkToXmlMap(map.Name, 5, 5, "/root/row/FIELD8");

// Save the workbook in xlsx format
wb.Save(dataDir + "output.xlsx");
```

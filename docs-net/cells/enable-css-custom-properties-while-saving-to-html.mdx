## Possible Usage Scenarios {#possible-usage-scenarios}

When you save your Excel file to HTML, for scenarios where there are multiple occurrences of the same base64 image, the custom property allows the image data to be saved only once, so the performance of the resultant HTML can be improved. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/EnableCssCustomProperties" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.EnableCssCustomProperties**</a> property and set it **true** while saving to HTML. ![todo:image_alt_text](/net/cells/images/1f682918d19f74f6-enable-css-custom-properties-while-saving-to-html-1.jpg)

## Enable CSS Custom Properties while saving to HTML {#enable-css-custom-properties-while-saving-to-html}

The following sample code shows the usage of <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/enablecsscustomproperties" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.EnableCssCustomProperties**</a> property. The screenshot shows the effect of this property when it is not set to true. Please download the <a href="https://docs.aspose.com/cells/net/enable-css-custom-properties-while-saving-to-html/50528260.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in this code and the <a href="https://docs.aspose.com/cells/net/enable-css-custom-properties-while-saving-to-html/50528261.zip" target="_blank" rel="nofollow noopener noreferrer">output HTML</a> generated by it for a reference.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
//Load sample workbook
Workbook wb = new Workbook(sourceDir + "sampleEnableCssCustomProperties.xlsx");

HtmlSaveOptions opts = new HtmlSaveOptions();
opts.ExportImagesAsBase64 = true;

//Enable EnableCssCustomProperties
opts.EnableCssCustomProperties = true;

//Save the workbook in html
wb.Save(outputDir + "outputEnableCssCustomProperties.html", opts);
```

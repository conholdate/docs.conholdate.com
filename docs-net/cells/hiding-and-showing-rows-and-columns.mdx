:::info
Sometimes, it makes sense to hide certain rows or columns in a worksheet and display them later. Microsoft Excel provides this feature, and so does Aspose.Cells.
:::

## Controlling the Visibility of Rows and Columns {#controlling-the-visibility-of-rows-and-columns}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> that allows developers to access each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides several methods for managing rows or columns in a worksheet. A few of these are discussed below.

### Hiding Rows and Columns {#hiding-rows-and-columns}

Developers can hide a row or column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hiderow" target="_blank" rel="nofollow noopener noreferrer">**HideRow**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hidecolumn" target="_blank" rel="nofollow noopener noreferrer">**HideColumn**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection, respectively. Each method takes the appropriate row or column index as a parameter to hide the specific row or column.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Hiding the 3rd row of the worksheet
worksheet.Cells.HideRow(2);

// Hiding the 2nd column of the worksheet
worksheet.Cells.HideColumn(1);

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

:::info
It is also possible to hide a row or column by setting the row height or column width to 0, respectively.
:::

### Showing Rows and Columns {#showing-rows-and-columns}

Developers can show any hidden row or column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhiderow" target="_blank" rel="nofollow noopener noreferrer">**UnhideRow**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhidecolumn" target="_blank" rel="nofollow noopener noreferrer">**UnhideColumn**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection, respectively. Both methods take two parameters:

- **Row or column index** - the index of the row or column that is to be shown.
- **Row height or column width** - the height or width to assign to the row or column after unhiding.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Unhiding the 3rd row and setting its height to 13.5
worksheet.Cells.UnhideRow(2, 13.5);

// Unhiding the 2nd column and setting its width to 8.5
worksheet.Cells.UnhideColumn(1, 8.5);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

:::info
When making a hidden column visible, if you need to restore it to its previously assigned width-or to its original width-please unhide the column with a negative width. For example: `worksheet.Cells.UnhideColumn(5, -1)`
:::

### Hiding Multiple Rows and Columns {#hiding-multiple-rows-and-columns}

Developers can hide multiple rows or columns at once by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hiderows" target="_blank" rel="nofollow noopener noreferrer">**HideRows**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hidecolumns" target="_blank" rel="nofollow noopener noreferrer">**HideColumns**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection, respectively. Both methods take the starting row or column index and the number of rows or columns that should be hidden as parameters.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Hiding 3,4 and 5 rows in the worksheet
worksheet.Cells.HideRows(2, 3);

// Hiding 2 and 3 columns in the worksheet
worksheet.Cells.HideColumns(1, 2);

// Saving the modified Excel file
workbook.Save(dataDir + "outputxls");

// Closing the file stream to free all resources
fstream.Close();
```

:::info
It is also possible to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhiderows" target="_blank" rel="nofollow noopener noreferrer">**UnhideRows**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhidecolumns" target="_blank" rel="nofollow noopener noreferrer">**UnhideColumns**</a> methods to make multiple rows and columns visible.
:::

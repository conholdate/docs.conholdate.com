:::info
Any document loaded into Aspose.Cells can be converted to PDF that conforms to the <a href="https://docs.fileformat.com/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF 1.5</a> or <a href="https://docs.fileformat.com/pdf/a/" target="_blank" rel="nofollow noopener noreferrer">PDF/A-1b</a> specification. Aspose.Cells goes to great lengths to faithfully convert Microsoft Excel documents to PDF. Most of the time, the look of the final PDF document will be indistinguishable from the original Microsoft Excel document.
:::

## PDF in Aspose.Cells {#pdf-in-asposecells}

The Aspose solution thoroughly supports the following document features when converting to PDF:

- Cell Data and Text Formatting
- Charts and Pivot Tables
- Headers/Footers
- Conditional Formatting
- Borders, Border Colors
- Images, Textboxes and Drawing Shapes
- Bookmarks
- Hyperlinks
- Merged Cells, Page Breaks, Print Titles

You can also see the <a href="https://docs.aspose.com/cells/net/convert-excel-workbook-to-pdf/" target="_blank" rel="nofollow noopener noreferrer">detailed specification</a> about how Aspose.Cells converts a document to PDF.

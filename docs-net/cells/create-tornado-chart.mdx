## Introduction {#introduction}

A tornado chart, also known as a tornado diagram or tornado graph, is a type of data visualization that is often used for sensitivity analysis in Excel. It helps you understand the impact of changing variables on a particular outcome or result.

## How to Create a Tornado Chart in Excel {#how-to-create-a-tornado-chart-in-excel}

You can create a tornado chart in Excel by following these steps:

1. Select the data and go to **Insert → Charts → Insert Column or Bar Chart → Stacked Bar Chart**. Click on it.

   ![](/net/cells/images/8976ad5042e35bcd-1.png)
2. Change the Y‑axis: Right‑click on the Y‑axis. Click on **Format Axis**. In **Labels**, click on the label position drop‑down and select **Low**.

   ![](/net/cells/images/1fcb8e69b064de31-2.png)
3. Select any bar and go to **Formatting**. Set an appropriate gap width.

   ![](/net/cells/images/86c8be064a0d7701-3.png)
4. Let's remove the minus sign (‑) from the tornado chart. Select the X‑axis. Go to **Formatting**. In the axis options, click on **Number**. In **Category**, select **Custom**. In the format code, write `###0,###0`. Click **Add**.

   ![](/net/cells/images/5ba309efddd57bcf-4.png)
5. Click on the Y‑axis and go to the axis options. In the **Axis Options**, check **Categories in reverse order**.

   ![](/net/cells/images/e053efce9eaca898-5.png)

## How to Add a Tornado Chart in Aspose.Cells {#how-to-add-a-tornado-chart-in-asposecells}

Please see the following sample code. It loads the <a href="https://docs.aspose.com/cells/net/create-tornado-chart/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains some sample data. It then creates the stacked bar chart based on the initial data and sets relevant properties. Finally, it saves the workbook to <a href="https://docs.aspose.com/cells/net/create-tornado-chart/out.xlsx" target="_blank" rel="nofollow noopener noreferrer">output XLSX format</a>. The following screenshot shows the tornado chart created by Aspose.Cells in the output Excel file.

![](/net/cells/images/362a761bdb5f2cdb-6.png)

### Sample Code {#sample-code}

```csharp
Workbook wb = new Workbook("sample.xlsx");
Worksheet sheet = wb.Worksheets[0];
ChartCollection charts = sheet.Charts;
// Add bar chart
int index = charts.Add(ChartType.BarStacked, 8, 1, 24, 8);
Chart chart = charts[index];

// Set data for bar chart
chart.SetChartDataRange("A1:C7", true);

// Set properties for bar chart
chart.Title.Text = "Tornado chart";
chart.Style = 2;
chart.PlotArea.Area.ForegroundColor = Color.White;
chart.PlotArea.Border.Color = Color.White;
chart.Legend.Position = LegendPositionType.Bottom;

chart.CategoryAxis.TickLabelPosition = TickLabelPositionType.Low;
chart.CategoryAxis.IsPlotOrderReversed = true;

chart.GapWidth = 10;

Axis valueAxis = chart.ValueAxis;
valueAxis.TickLabels.NumberFormat = "#,##0;#,##0";            

wb.Save("out.xlsx");
```

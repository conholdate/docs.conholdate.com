:::


:::info
When working with large Microsoft Excel files (for example, a workbook that has many sheets, each with 50 columns and 300 or more rows of data), you might want the PDF output to show one page per worksheet, regardless of the size of the worksheet. This would mean that each page is likely to have a radically different page size. This can be achieved by using Aspose.Cells for .NET.
:::

Please see the following sample code that converts an Excel file with multiple worksheets to PDF.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
// Initialize a new Workbook
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "input.xlsx");

// Implement one page per worksheet option
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.OnePagePerSheet = true;

// Save the PDF file
workbook.Save(dataDir + "OutputFile.out.pdf", pdfSaveOptions);
```

:::info
If the <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/onepagepersheet" target="_blank" rel="nofollow noopener noreferrer">OnePagePerSheet</a> option is set to **true**, all sheet content will be rendered to one PDF page.
:::

:::info
If your spreadsheet contains formulas, you should call <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/calculateformula" target="_blank" rel="nofollow noopener noreferrer">Workbook.CalculateFormula()</a> just before rendering the spreadsheet to PDF. This ensures that the formula‑dependent values are recalculated, and the correct values are rendered in the PDF.
:::

## Possible Usage Scenarios {#possible-usage-scenarios}

When you share a workbook, you get an option saying ***Keep change history for N days*** as shown in the following screenshot. You can update the number of days for preserving history using Aspose.Cells with the <a href="https://reference.aspose.com/cells/net/aspose.cells.revisions/revisionlogcollection/properties/dayspreservinghistory" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection.RevisionLogs.DaysPreservingHistory**</a> property.

![todo:image_alt_text](/net/cells/images/58774c2009bb1ffe-update-days-preserving-history-of-revision-logs-in-shared-workbook_1.png)

## Update Days Preserving History of Revision Logs in Shared Workbook {#update-days-preserving-history-of-revision-logs-in-shared-workbook}

The following sample code creates an empty workbook, then shares it and updates the days preserving history of revision logs to 7 days, which is normally 30 days. Please see the <a href="https://docs.aspose.com/cells/net/update-days-preserving-history-of-revision-logs-in-shared-workbook/60489773.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated by the code for reference.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create empty workbook
Workbook wb = new Workbook();

//Share the workbook
wb.Settings.Shared = true;

//Update DaysPreservingHistory of RevisionLogs
wb.Worksheets.RevisionLogs.DaysPreservingHistory = 7;

//Save the workbook
wb.Save("outputShared_DaysPreservingHistory.xlsx");
```

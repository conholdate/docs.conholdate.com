:::info
When working with spreadsheets and adding data to rows or columns, you might need to change the height of rows or the width of columns. Sometimes, applying formatting on rows or columns means that the current height or width must change to display the data. Normally, users adjust row heights and column widths in a WYSIWYG environment using Microsoft Excel. But with Aspose.Cells developers can perform these operations at runtime.
:::

## Working with Rows {#working-with-rows}

### How to Adjust Row Height {#how-to-adjust-row-height}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides several methods to manage rows or columns in a worksheet. Some of these are discussed below in more detail.

### How to Set the Height of a Row {#how-to-set-the-height-of-a-row}

It is possible to set the height of a single row by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setrowheight" target="_blank" rel="nofollow noopener noreferrer">**SetRowHeight**</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setrowheight" target="_blank" rel="nofollow noopener noreferrer">**SetRowHeight**</a> method takes the following parameters:

- **Row index** - the index of the row whose height you are changing.
- **Row height** - the row height to apply.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the height of the second row to 13
worksheet.Cells.SetRowHeight(1, 13);

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

### How to Set the Height of All Rows in a Worksheet {#how-to-set-the-height-of-all-rows-in-a-worksheet}

If developers need to set the same row height for all rows in the worksheet, they can do it by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/standardheight" target="_blank" rel="nofollow noopener noreferrer">**StandardHeight**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection.

**Example:**

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the height of all rows in the worksheet to 15
worksheet.Cells.StandardHeight = 15;

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Working with Columns {#working-with-columns}

### How to Set the Width of a Column {#how-to-set-the-width-of-a-column}

Set the width of a column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setcolumnwidth" target="_blank" rel="nofollow noopener noreferrer">**SetColumnWidth**</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setcolumnwidth" target="_blank" rel="nofollow noopener noreferrer">**SetColumnWidth**</a> method takes the following parameters:

- **Column index** - the index of the column whose width you are changing.
- **Column width** - the desired column width.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the width of the second column to 17.5
worksheet.Cells.SetColumnWidth(1, 17.5);

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

### How to Set Column Width in Pixels {#how-to-set-column-width-in-pixels}

Set the width of a column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setcolumnwidthpixel" target="_blank" rel="nofollow noopener noreferrer">**SetColumnWidthPixel**</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/setcolumnwidthpixel" target="_blank" rel="nofollow noopener noreferrer">**SetColumnWidthPixel**</a> method takes the following parameters:

- **Column index** - the index of the column whose width you are changing.
- **Column width** - the desired column width in pixels.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";
string outDir = "./";

//Load source Excel file
Workbook workbook = new Workbook(sourceDir + "Book1.xlsx");

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Set the width of the column in pixels
worksheet.Cells.SetColumnWidthPixel(7, 200);

workbook.Save(outDir + "SetColumnWidthInPixels_Out.xlsx");
```

### How to Set the Width of All Columns in a Worksheet {#how-to-set-the-width-of-all-columns-in-a-worksheet}

To set the same column width for all columns in the worksheet, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/standardwidth" target="_blank" rel="nofollow noopener noreferrer">**StandardWidth**</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
            
// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the width of all columns in the worksheet to 20.5
worksheet.Cells.StandardWidth = 20.5;

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Check if VBA Project is Protected and Locked for Viewing in C# {#check-if-vba-project-is-protected-and-locked-for-viewing-in-c}

Aspose.Cells allows you to check if the VBA (Visual Basic for Applications) project of an Excel file is protected and locked for viewing. For this, the API provides the **VbaProject.IsLockedForViewing** property. If it is locked for viewing, then the **VbaProject.IsLockedForViewing** property returns **true**.

## Sample Code {#sample-code}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/check-if-vba-project-is-protected-and-locked-for-viewing/43352065.xlsm" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> and checks if the VBA (Visual Basic for Applications) project of the Excel file is protected and locked for viewing. Please also see its console output for reference.

```csharp
﻿// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//The path to the documents directory.
string dataDir = "./";

//Load your source Excel file.
Workbook wb = new Workbook(dataDir + "sampleCheckifVBAProjectisProtected.xlsm");

//Access the VBA project of the workbook.
Aspose.Cells.Vba.VbaProject vbaProject = wb.VbaProject;

//Whether "Lock project for viewing" is true or not.
Console.WriteLine("Is VBA Project Locked for Viewing: " + vbaProject.IslockedForViewing);
```

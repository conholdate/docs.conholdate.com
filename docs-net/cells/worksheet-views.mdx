## Page Break Preview {#page-break-preview}

All worksheets can be viewed in two modes:

- Normal view.
- Page break preview.

Normal view is a worksheet's default view. Page break preview is an editing view that displays a worksheet as it will print. Page break preview shows what data will go on each page so you can adjust the print area and page breaks. Using Aspose.Cells, developers can enable normal view or page break preview modes.

### Controlling View Modes {#controlling-view-modes}

Aspose.Cells provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods for managing worksheets. To enable normal or page break preview modes, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> property. <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> is a Boolean property, which means that it can only store either **true** or **false**.

#### Enabling Normal View {#enabling-normal-view}

Set a worksheet to normal view by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> property to **false**.

#### Enabling Page Break Preview {#enabling-page-break-preview}

Set any worksheet to page break preview by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> property to **true**. Doing so switches the worksheet from normal view to page break preview.

A complete example is given below that demonstrates how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> property to enable page break preview mode for the first worksheet of an Excel file.

The book1.xls file is opened by creating an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class. The view is switched to page break preview for the first worksheet by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/ispagebreakpreview" target="_blank" rel="nofollow noopener noreferrer">**IsPageBreakPreview**</a> property to **true**. The modified file is saved as output.xls.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Displaying the worksheet in page break preview
worksheet.IsPageBreakPreview = true;

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Zoom Factor {#zoom-factor}

### Using Microsoft Excel {#using-microsoft-excel}

Microsoft Excel provides a feature that lets users set a worksheet's zoom or scaling factor. This feature helps users to see the worksheet contents in smaller or larger views. Users can set the zoom factor to any value.

### Aspose.Cells & Zoom Factor {#asposecells--zoom-factor}

Aspose.Cells allows developers to set the worksheet's zoom factor.\
Aspose.Cells provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods for managing worksheets. To set a worksheet's zoom factor, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/zoom" target="_blank" rel="nofollow noopener noreferrer">**Zoom**</a> property. The zoom factor is set by assigning a numeric (integer) value to the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/zoom" target="_blank" rel="nofollow noopener noreferrer">**Zoom**</a> property.

A complete example is given below that demonstrates how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/zoom" target="_blank" rel="nofollow noopener noreferrer">**Zoom**</a> property to set the zoom factor of the first worksheet of the Excel file.

The book1.xls file is opened by creating an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class. The zoom factor of the first worksheet is set to 75 and the modified file is saved as output.xls.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting the zoom factor of the worksheet to 75
worksheet.Zoom = 75;

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Freeze Panes {#freeze-panes}

### Using Microsoft Excel {#using-microsoft-excel-1}

Freeze panes are a feature provided by Microsoft Excel. Freezing panes allows you to select data to remain visible when scrolling in a worksheet.

### Aspose.Cells & Freeze Panes {#asposecells--freeze-panes}

Aspose.Cells allows developers to apply freeze panes to worksheets at runtime.

Aspose.Cells provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods for managing worksheets. To configure freeze panes, call the Worksheet class's <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/freezepanes/index" target="_blank" rel="nofollow noopener noreferrer">**FreezePanes**</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/freezepanes/index" target="_blank" rel="nofollow noopener noreferrer">**FreezePanes**</a> method takes the following parameters:

- **Row**, the row index of the cell from which the freeze will start.
- **Column**, the column index of the cell from which the freeze will start.
- **Frozen rows**, the number of visible rows in the top pane.
- **Frozen columns**, the number of visible columns in the left pane.

The book1.xls file is opened by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class's constructor while instantiating it, and a few rows and columns are frozen in the first worksheet. The modified file is saved as output.xls.

A complete example is given below that shows how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/freezepanes/index" target="_blank" rel="nofollow noopener noreferrer">**FreezePanes**</a> method to freeze rows and columns (starting from C4, represented by the 4th row and 3rd column, where the rows and columns start from the 0 index) of the first worksheet of the Excel file.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Applying freeze panes settings
worksheet.FreezePanes(3, 2, 3, 2);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Split Panes {#split-panes}

If you need to split the screen to get two different views in the same worksheet, use split panes. Microsoft Excel offers a very handy feature that allows you to view more than one copy of your worksheet and scroll through each pane independently.

The panes work simultaneously. If you make a change in one, the change appears in the other at the same time. Aspose.Cells provides the split panes feature for users.

### Applying and Removing Split Panes {#applying-and-removing-split-panes}

#### Splitting Panes {#splitting-panes}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class provides a wide range of properties and methods for managing an Excel file. To implement split views, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/split" target="_blank" rel="nofollow noopener noreferrer">**Split**</a>. To remove the split panes, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/removesplit" target="_blank" rel="nofollow noopener noreferrer">**RemoveSplit**</a> method.

In the example, we use a simple template file that is loaded, then the split panes feature is applied on a cell in the first worksheet. The updated file is saved.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a new workbook and Open a template file
Workbook book = new Workbook(dataDir + "Book1.xls");

// Set the active cell
book.Worksheets[0].ActiveCell = "A20";

// Split the worksheet window
book.Worksheets[0].Split();

// Save the excel file
book.Save(dataDir + "output.xls");
```

After running the above code, the generated file will have a split view.

#### Removing Panes {#removing-panes}

Remove split panes using the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/removesplit" target="_blank" rel="nofollow noopener noreferrer">**RemoveSplit**</a> method.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiate a new workbook and Open a template file
Workbook book = new Workbook(dataDir + "Book1.xls");

// Set the active cell
book.Worksheets[0].ActiveCell = "A20";

// Split the worksheet window
book.Worksheets[0].RemoveSplit();

// Save the excel file
book.Save(dataDir + "output.xls");
```

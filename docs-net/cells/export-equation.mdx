Sometimes you may need to export Excel formulas to other formats in your code to meet your work needs, **and** Aspose.Cells library can meet your needs. The following content introduces some methods **for exporting** Excel formulas to other formats. **I hope these methods will be helpful to you.**

We have prepared sample code here to help you achieve your goals using Aspose.Cells. Necessary sample files are also provided.

Sample file: <a href="https://docs.aspose.com/cells/net/export-equation/Sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">Sample.xlsx</a>

## Export equations as LaTeX expressions {#export-equations-as-latex-expressions}

If you want to export equations in Excel as LaTeX expressions, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.equations/equationnode/tolatex/" target="_blank" rel="nofollow noopener noreferrer">ToLaTeX()</a> method.

The following sample code shows how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.equations/equationnode/tolatex/" target="_blank" rel="nofollow noopener noreferrer">ToLaTeX()</a> method and insert the generated results into HTML:

### C#-To-LaTeX {#c-to-latex}

```csharp

string dirPath = @"./";

Workbook workbook = new Workbook(dirPath + "Sample.xlsx");

StringBuilder sb = new StringBuilder();
sb.Append("<!DOCTYPE html>\r\n<html lang=\"en\">\r\n<head>\r\n    <meta charset=\"UTF-8\">\r\n    <title>Title</title>\r\n    <script type=\"text/javascript\" async src=\"https://cdnjs.cloudflare.com/ajax/libs/mathjax/2.7.7/MathJax.js?config=TeX-MML-AM_CHTML\"></script>\r\n    <script type=\"text/x-mathjax-config\">\r\n        MathJax.Hub.Config({\r\n\t    tex2jax: {\r\n\t        inlineMath: [['$','$'], ['\\\\(','\\\\)']],\r\n\t        processEscapes: true\r\n\t    }\r\n\t});\r\n    </script>\r\n</head>\r\n<body>");
ShapeCollection shapes = workbook.Worksheets[0].Shapes;
TextBox textBox = (TextBox)shapes[0];
EquationNode mathNode = textBox.GetEquationParagraph().GetChild(0);
string s = mathNode.ToLaTeX();
sb.AppendLine("<p>$" + s + "$</p>");
sb.Append("</body>\r\n</html>");
File.WriteAllText(@"result.html", sb.ToString());
```

## Export equations as MathML expressions {#export-equations-as-mathml-expressions}

If you want to export equations in Excel as MathML expressions, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.equations/equationnode/tomathml/" target="_blank" rel="nofollow noopener noreferrer">ToMathML()</a> method.

The following sample code shows how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing.equations/equationnode/tomathml/" target="_blank" rel="nofollow noopener noreferrer">ToMathML()</a> method and insert the generated results into HTML:

### C#-To-MathML {#c-to-mathml}

```csharp

string dirPath = @"./";

Workbook workbook = new Workbook(dirPath + "Sample.xlsx");

StringBuilder sb = new StringBuilder();
sb.Append("<!DOCTYPE html>\r\n<html lang=\"en\">\r\n<head>\r\n    <meta charset=\"UTF-8\">\r\n    <title>Title</title>\r\n    <script type=\"text/javascript\" async src=\"https://cdnjs.cloudflare.com/ajax/libs/mathjax/2.7.7/MathJax.js?config=TeX-MML-AM_CHTML\"></script>\r\n</head>\r\n<body>");
ShapeCollection shapes = workbook.Worksheets[0].Shapes;
TextBox textBox = (TextBox)shapes[0];
EquationNode mathNode = textBox.GetEquationParagraph().GetChild(0);
sb.AppendLine(mathNode.ToMathML());
sb.Append("</body>\r\n</html>");
File.WriteAllText(@"result.html", sb.ToString());
```

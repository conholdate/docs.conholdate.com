## Show and Hide Rows and Columns {#show-and-hide-rows-and-columns}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows developers to access each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides several methods for managing rows or columns in a worksheet. A few of these are discussed below.

### Show Rows and Columns {#show-rows-and-columns}

Developers can show any hidden row or column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhiderow" target="_blank" rel="nofollow noopener noreferrer">**UnhideRow**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/unhidecolumn" target="_blank" rel="nofollow noopener noreferrer">**UnhideColumn**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection respectively. Both methods take two parameters:

- **Row or column index** - the index of a row or column that is used to show the specific row or column.
- **Row height or column width** - the row height or column width assigned to the row or column after unhiding.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Unhiding the 3rd row and setting its height to 13.5
worksheet.Cells.UnhideRow(2, 13.5);

// Unhiding the 2nd column and setting its width to 8.5
worksheet.Cells.UnhideColumn(1, 8.5);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

:::info
While making a hidden column visible, if you need to restore it to its previously assigned width or its original width, please unhide the column with a negative width. For example: `worksheet.Cells.UnhideColumn(5, -1)`
:::

### Hide Rows and Columns {#hide-rows-and-columns}

Developers can hide a row or column by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hiderow" target="_blank" rel="nofollow noopener noreferrer">**HideRow**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hidecolumn" target="_blank" rel="nofollow noopener noreferrer">**HideColumn**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection respectively. Both methods take the row or column index as a parameter to hide the specific row or column.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Hiding the 3rd row of the worksheet
worksheet.Cells.HideRow(2);

// Hiding the 2nd column of the worksheet
worksheet.Cells.HideColumn(1);

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

:::info
It is also possible to hide a row or column by setting the row height or column width to 0 respectively.
:::

### Hide Multiple Rows and Columns {#hide-multiple-rows-and-columns}

Developers can hide multiple rows or columns at once by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hiderows" target="_blank" rel="nofollow noopener noreferrer">**HideRows**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/hidecolumns" target="_blank" rel="nofollow noopener noreferrer">**HideColumns**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection respectively. Both methods take the starting row or column index and the number of rows or columns that should be hidden as parameters.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Hiding 3,4 and 5 rows in the worksheet
worksheet.Cells.HideRows(2, 3);

// Hiding 2 and 3 columns in the worksheet
worksheet.Cells.HideColumns(1, 2);

// Saving the modified Excel file
workbook.Save(dataDir + "outputxls");

// Closing the file stream to free all resources
fstream.Close();
```

## Show and Hide Scroll Bars {#show-and-hide-scroll-bars}

Scroll bars are used to navigate the contents of any file. Normally, there are two kinds of scroll bars:

- Vertical scroll bars
- Horizontal scroll bars

Microsoft Excel also provides horizontal and vertical scroll bars so that users can scroll through worksheet contents. Using Aspose.Cells, developers can control the visibility of both types of scroll bars in Excel files.

### Controlling the Visibility of Scroll Bars {#controlling-the-visibility-of-scroll-bars}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents an Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class provides a wide range of properties and methods for managing an Excel file. To control the visibility of scroll bars, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class' <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/isvscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsVScrollBarVisible**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/ishscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsHScrollBarVisible**</a> properties. **WorkbookSettings.IsVScrollBarVisible** and **WorkbookSettings.IsHScrollBarVisible** are Boolean properties, which means that these properties can only store **true** or **false** values.

#### Making Scroll Bars Visible {#making-scroll-bars-visible}

Make scroll bars visible by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class' <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/isvscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsVScrollBarVisible**</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/ishscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsHScrollBarVisible**</a> property to **true**.

#### Hiding Scroll Bars {#hiding-scroll-bars}

Hide scroll bars by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class' <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/isvscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsVScrollBarVisible**</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/ishscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.IsHScrollBarVisible**</a> property to **false**.

**Sample Code**

Below is a complete code that opens an Excel file, `book1.xls`, hides both scroll bars, and then saves the modified file as `output.xls`.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Hiding the vertical scroll bar of the Excel file
workbook.Settings.IsVScrollBarVisible = false;

// Hiding the horizontal scroll bar of the Excel file
workbook.Settings.IsHScrollBarVisible = false;

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

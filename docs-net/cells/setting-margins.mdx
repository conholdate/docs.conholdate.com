:::info
Aspose.Cells fully supports Microsoft Excel's page setup options. Developers may need to configure page setup settings for worksheets to control the printing process. This topic discusses how to use Aspose.Cells to configure page margins.
:::

## Setting Margins {#setting-margins}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents an Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> property used to set the page setup options for a worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> property is an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class that enables developers to set different page layout options for a printed worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class provides various properties and methods used to set page setup options.

### Page Margins {#page-margins}

Set page margins (left, right, top, bottom) using <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class members. A few of the methods are listed below which are used to specify page margins:

- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/leftmargin" target="_blank" rel="nofollow noopener noreferrer">**LeftMargin**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/rightmargin" target="_blank" rel="nofollow noopener noreferrer">**RightMargin**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/topmargin" target="_blank" rel="nofollow noopener noreferrer">**TopMargin**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/bottommargin" target="_blank" rel="nofollow noopener noreferrer">**BottomMargin**</a>

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a workbook object
Workbook workbook = new Workbook();

// Get the worksheets in the workbook
WorksheetCollection worksheets = workbook.Worksheets;

// Get the first (default) worksheet
Worksheet worksheet = worksheets[0];

// Get the pagesetup object
PageSetup pageSetup = worksheet.PageSetup;

// Set bottom,left,right and top page margins
pageSetup.BottomMargin = 2;
pageSetup.LeftMargin = 1;
pageSetup.RightMargin = 1;
pageSetup.TopMargin = 3;

// Save the Workbook.
workbook.Save(dataDir + "SetMargins_out.xls");
```

### Center on Page {#center-on-page}

It is possible to center something on a page horizontally and vertically. For this, there are some useful members of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class, <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/centerhorizontally" target="_blank" rel="nofollow noopener noreferrer">**CenterHorizontally**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/centervertically" target="_blank" rel="nofollow noopener noreferrer">**CenterVertically**</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a workbook object
Workbook workbook = new Workbook();

// Get the worksheets in the workbook
WorksheetCollection worksheets = workbook.Worksheets;

// Get the first (default) worksheet
Worksheet worksheet = worksheets[0];

// Get the pagesetup object
PageSetup pageSetup = worksheet.PageSetup;

// Specify Center on page Horizontally and Vertically
pageSetup.CenterHorizontally = true;
pageSetup.CenterVertically = true;

// Save the Workbook.
workbook.Save(dataDir + "CenterOnPage_out.xls");
```

### Header and Footer Margins {#header-and-footer-margins}

Set header and footer margins with the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/pagesetup" target="_blank" rel="nofollow noopener noreferrer">**PageSetup**</a> class members such as <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/headermargin" target="_blank" rel="nofollow noopener noreferrer">**HeaderMargin**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/footermargin" target="_blank" rel="nofollow noopener noreferrer">**FooterMargin**</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a workbook object
Workbook workbook = new Workbook();

// Get the worksheets in the workbook
WorksheetCollection worksheets = workbook.Worksheets;

// Get the first (default) worksheet
Worksheet worksheet = worksheets[0];

// Get the pagesetup object
PageSetup pageSetup = worksheet.PageSetup;

// Specify Header / Footer margins
pageSetup.HeaderMargin = 2;
pageSetup.FooterMargin = 2;

// Save the Workbook.
workbook.Save(dataDir + "CenterOnPage_out.xls");
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Using the Aspose.Cells API, you can also set the theme color for the chart series.

## Change Theme Colors {#change-theme-colors}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/change-theme-colors-for-chart-series/Test.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> and generates the <a href="https://docs.aspose.com/cells/net/change-theme-colors-for-chart-series/Output.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

```csharp
            path = "";
            Workbook wb = new Workbook(path + "Test.xlsx");
            Chart chart1 = wb.Worksheets[0].Charts[0];
            chart1.NSeries.ChangeColors(ChartColorPaletteType.MonochromaticPalette6);
            wb.Save(path + "Output.xlsx");
```

In this sample code, <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chartcolorpalettetype/" target="_blank" rel="nofollow noopener noreferrer">ChartColorPaletteType.MonochromaticPalette6</a> indicates that the sixth theme color is used in the drop‑down box in the Excel interface.

## Create Style object using CellsFactory class {#create-style-object-using-cellsfactory-class}

The following sample code creates a <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">Style</a> object using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellsfactory" target="_blank" rel="nofollow noopener noreferrer">CellsFactory</a> class and then sets the default style of the workbook. Please download the <a href="https://docs.aspose.com/cells/net/create-style-object-using-cellsfactory-class/5115153.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> to see the results of this code.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a Style object using CellsFactory class
CellsFactory cf = new CellsFactory();
Style st = cf.CreateStyle();

// Set the Style fill color to Yellow
st.Pattern = BackgroundType.Solid;
st.ForegroundColor = Color.Yellow;

// Create a workbook and set its default style using the created Style object
Workbook wb = new Workbook();
wb.DefaultStyle = st;

// Save the workbook
wb.Save(dataDir + "output_out.xlsx");
```

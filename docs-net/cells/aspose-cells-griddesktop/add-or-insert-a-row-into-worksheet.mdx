:::info
Similar to one of our previous topics, this topic describes the feature of adding and inserting rows to the worksheets at runtime using the API of Aspose.Cells.GridDesktop. The basic difference between addition and insertion is that, in addition, a row is added at the end of the rows collection of the worksheet, whereas in insertion, a row can be added to any specified position in the worksheet.
:::

## Adding a Row to Worksheet {#adding-a-row-to-worksheet}

To add a new row to the worksheet, please follow the steps below:

- Add Aspose.Cells.GridDesktop control to your **Form**
- Access any desired <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a>
- Add **Row** to the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a>

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Accessing first worksheet of the Grid
Worksheet sheet = gridDesktop1.Worksheets[0];

// Adding row to the worksheet
sheet.AddRow();
```

## Inserting a Row into Worksheet {#inserting-a-row-into-worksheet}

To insert a new row into a worksheet at a specified position, please follow the steps below:

- Add Aspose.Cells.GridDesktop control to your **Form**
- Access any desired <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a>
- Insert **Row** into <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> (at a specific position by specifying the index of the row where to insert it)

```java
  

 // Accessing the first worksheet of the Grid  
 Aspose.Cells.GridDesktop.Worksheet sheet = gridDesktop1.Worksheets[0];  

 // Inserting a row into the worksheet at the first position  
 sheet.Cells.InsertRow(0);  
```

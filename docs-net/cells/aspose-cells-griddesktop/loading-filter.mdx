## Possible Usage Scenarios {#possible-usage-scenarios}

Please use <a href="https://reference.aspose.com/cells/net/aspose.cells.griddesktop/griddesktop/properties/loaddatafilter" target="_blank" rel="nofollow noopener noreferrer">GridDesktop.LoadDataFilter</a> property while filtering data from the workbook.

The <a href="https://reference.aspose.com/cells/net/aspose.cells.griddesktop.data/gridloaddatafilteroptions" target="_blank" rel="nofollow noopener noreferrer">GridLoadDataFilterOptions</a> enumeration has the following values.

- All
- BookSettings
- CellBlank
- CellBool
- CellData
- CellError
- CellNumeric
- CellString
- CellValue
- Chart
- ConditionalFormatting
- DataValidation
- DefinedNames
- DocumentProperties
- Formula
- Hyperlinks
- MergedArea
- PivotTable
- Settings
- Shape
- SheetData
- SheetSettings
- Structure
- Style
- Table
- VBA
- XmlMap

## Filter data while Loading Workbook {#filter-data-while-loading-workbook}

The following sample code illustrates how to filter drawings from the workbook. Please check the <a href="https://docs.aspose.com/cells/net/aspose-cells-griddesktop/loading-filter/5472489.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>. As you can see, all charts/shapes/images have been filtered out of the workbook.

![workbook without image](/net/cells/images/6890c2dd6b08df0f-nodrawing.png)

### Sample Code {#sample-code}

```csharp
// Filter all drawing objects(including Chart, Picture, OleObject and all other drawing objects) from the workbook.
  gridDesktop1.LoadDataFilter = GridLoadDataFilterOptions.All&~GridLoadDataFilterOptions.Drawing;
//here is another example ,if we want to filter to show styles and values only, we can use the below code ,notice here we use |
// gridDesktop1.LoadDataFilter = GridLoadDataFilterOptions.CellValue | GridLoadDataFilterOptions.Style;
  gridDesktop1.ImportExcelFile("5472489.xlsx");
```

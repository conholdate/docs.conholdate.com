## Possible Usage Scenarios {#possible-usage-scenarios}

Microsoft Excel allows you to split panes using the View &gt; Split menu command. Aspose.Cells also provides this feature. Please use GridDesktop.DoSplit() and GridDesktop.UnDoSplit() methods to split and unsplit panes in a GridDesktop worksheet.

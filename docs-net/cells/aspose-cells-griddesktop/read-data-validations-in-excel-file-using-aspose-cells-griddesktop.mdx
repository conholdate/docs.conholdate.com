:::info
Aspose.Cells.GridDesktop can read and apply **Data Validations** in your Excel file. Please load your Excel file in GridDesktop and all the Data Validations inside it will start working as they do in Microsoft Excel.
:::

## Reading Data Validations in Excel file using Aspose.Cells.GridDesktop {#reading-data-validations-in-excel-file-using-asposecellsgriddesktop}

The following sample code imports the <a href="https://docs.aspose.com/cells/net/aspose-cells-griddesktop/read-data-validations-in-excel-file-using-aspose-cells-griddesktop/5115550.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>, which contains some **Data Validations**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = Utils.GetDataDir(System.Reflection.MethodBase.GetCurrentMethod().DeclaringType);

// Import sample excel file in GridDesktop
gridDesktop1.ImportExcelFile(dataDir + "ValidationTesting.xlsx");
```

After importing the file into GridDesktop, when we try to change the value of cell A2 to greater than 100, it pops up the **Validation Error** message box.

:::

## Removing a Column from Worksheet {#removing-a-column-from-worksheet}

To remove a column from the worksheet, please follow the steps below:

- Access any desired **Worksheet**
- Remove **Column** from the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> by specifying the index of the column to be removed

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Accessing first worksheet of the Grid
Worksheet sheet = gridDesktop1.Worksheets[0];

// Removing the first column of the worksheet
sheet.RemoveColumn(0);
```

## Detect Hyperlink Type {#detect-hyperlink-type}

An Excel file can have different types of hyperlinks, such as external, cell reference, file path, etc. Aspose.Cells supports detecting the type of hyperlink. The types of hyperlinks are represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/targetmodetype" target="_blank" rel="nofollow noopener noreferrer">**TargetModeType**</a> enumeration. The <a href="https://reference.aspose.com/cells/net/aspose.cells/targetmodetype" target="_blank" rel="nofollow noopener noreferrer">**TargetModeType**</a> enumeration has the following members.

- External: External link
- FilePath: Local and full paths to files/folders.
- Email: Email
- CellReference: Link to a cell or named range.

To check the type of hyperlink, the <a href="https://reference.aspose.com/cells/net/aspose.cells/hyperlink" target="_blank" rel="nofollow noopener noreferrer">**Hyperlink**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/hyperlink/properties/linktype" target="_blank" rel="nofollow noopener noreferrer">**LinkType**</a> property with a return type of <a href="https://reference.aspose.com/cells/net/aspose.cells/targetmodetype" target="_blank" rel="nofollow noopener noreferrer">**TargetModeType**</a>. The following code snippet demonstrates the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells/hyperlink/properties/linktype" target="_blank" rel="nofollow noopener noreferrer">**LinkType**</a> property by using this source Excel file (94896195.xlsx).

### Source Code {#source-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//source directory
string SourceDir = "./";

Workbook workbook = new Workbook(SourceDir + "LinkTypes.xlsx");

// Get the first (default) worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Create a range A2:B3
Range range = worksheet.Cells.CreateRange("A1", "A7");

// Get Hyperlinks in range
Hyperlink[] hyperlinks = range.Hyperlinks;

foreach (Hyperlink link in hyperlinks)
{
    Console.WriteLine(link.TextToDisplay + ": " + link.LinkType);
}
```

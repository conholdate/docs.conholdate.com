## Possible Usage Scenarios {#possible-usage-scenarios}

Filtering data in Excel is a valuable tool that enhances data analysis, exploration, and presentation by enabling users to focus on specific subsets of data based on their criteria, making the overall data manipulation and interpretation process more efficient and effective.

## How to Filter Blanks or Non-Blanks in Excel {#how-to-filter-blanks-or-non-blanks-in-excel}

In Excel, you can easily filter blanks or non-blanks using the filtering options. Here's how you can do it:

### How to Filter Blanks in Excel {#how-to-filter-blanks-in-excel}

1. Select the Range: Click on the letter of the column header to select the entire column or select the range where you want to filter blanks.
2. Open the Filter Menu: Go to the "Data" tab in the ribbon.\
   ![](/net/cells/images/c431d5b8feac138e-1.png)
3. Filter Options: Click on the "Filter" button. This will add filter arrows to the selected range.
4. Filter Blanks: Click on the filter arrow in the column you want to filter blanks. Unselect all options except "Blanks" and click OK. This will display only the blank cells in that column.\
   ![](/net/cells/images/d0e5d2f286417230-2.png)
5. The result **is** as follows:\
   ![](/net/cells/images/0ec894e93410e537-3.png)

### How to Filter Non-Blanks in Excel {#how-to-filter-non-blanks-in-excel}

1. Select the Range: Click on the letter of the column header to select the entire column or select the range where you want to filter non-blanks.
2. Open the Filter Menu: Go to the "Data" tab in the ribbon.\
   ![](/net/cells/images/c431d5b8feac138e-1.png)
3. Filter Options: Click on the "Filter" button. This will add filter arrows to the selected range.
4. Filter Non-Blanks: Click on the filter arrow in the column you want to filter non-blanks. Unselect all options except "Non-blanks" or "Custom" and set the conditions accordingly. Click OK. This will display only the cells that are not blank in that column.\
   ![](/net/cells/images/e45c6f90a925da6a-4.png)
5. The result **is** as follows:\
   ![](/net/cells/images/09534bdc84fdcb71-5.png)

## How to Filter Blanks using Aspose.Cells {#how-to-filter-blanks-using-asposecells}

If a column contains text with a few blank cells and you need to filter rows where the cells are blank, you can use the <a href="https://reference.aspose.com/cells/net/aspose.cells/autofilter/matchblanks/" target="_blank" rel="nofollow noopener noreferrer">AutoFilter.MatchBlanks(int fieldIndex)</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/autofilter/addfilter/" target="_blank" rel="nofollow noopener noreferrer">AutoFilter.AddFilter(int fieldIndex, string criteria)</a> functions as demonstrated below.

Please see the following sample code that loads the <a href="https://docs.aspose.com/cells/net/how-to-filter-blanks-and-non-blanks/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> which contains some dummy data. The sample code uses three methods to filter blanks. It then saves the workbook as <a href="https://docs.aspose.com/cells/net/how-to-filter-blanks-and-non-blanks/FilteredBlanks.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

```csharp
// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook("sample.xlsx");

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

//Method 1: Call MatchBlanks function to apply the filter
//worksheet.AutoFilter.MatchBlanks(1);

//Method 2: Call AddFilter function and set criteria to ""
//worksheet.AutoFilter.AddFilter(1, "");

//Method 3: Call AddFilter function and set criteria to null
worksheet.AutoFilter.AddFilter(1, null);

// Call refresh function to update the worksheet
worksheet.AutoFilter.Refresh();

// Saving the modified Excel file
workbook.Save("FilteredBlanks.xlsx");
```

## How to Filter Non-Blanks using Aspose.Cells {#how-to-filter-non-blanks-using-asposecells}

Please see the following sample code that loads the <a href="https://docs.aspose.com/cells/net/how-to-filter-blanks-and-non-blanks/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> which contains some dummy data. After loading the file, call the <a href="https://reference.aspose.com/cells/net/aspose.cells/autofilter/matchnonblanks/" target="_blank" rel="nofollow noopener noreferrer">AutoFilter.MatchNonBlanks(int fieldIndex)</a> function to filter non‑blank data, and finally save the workbook as <a href="https://docs.aspose.com/cells/net/how-to-filter-blanks-and-non-blanks/FilteredNonBlanks.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>.

```csharp
// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook("sample.xlsx");

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Call MatchBlanks function to apply the filter
worksheet.AutoFilter.MatchNonBlanks(1);

// Call refresh function to update the worksheet
worksheet.AutoFilter.Refresh();

// Saving the modified Excel file
workbook.Save("FilteredNonBlanks.xlsx");
```

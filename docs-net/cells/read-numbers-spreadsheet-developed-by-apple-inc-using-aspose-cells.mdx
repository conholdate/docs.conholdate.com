## Possible Usage Scenarios {#possible-usage-scenarios}

Numbers is a spreadsheet application developed by Apple Inc. Aspose.Cells can read Numbers spreadsheets. It can read a Numbers spreadsheet's data, style, and formulas.

## Read Numbers Spreadsheet Developed by Apple Inc. using Aspose.Cells {#read-numbers-spreadsheet-developed-by-apple-inc-using-asposecells}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/read-numbers-spreadsheet-developed-by-apple-inc-using-aspose-cells/sampleNumbersByAppleInc.numbers" target="_blank" rel="nofollow noopener noreferrer">Sample Numbers Spreadsheet</a> and converts it to <a href="https://docs.aspose.com/cells/net/read-numbers-spreadsheet-developed-by-apple-inc-using-aspose-cells/outputNumbersByAppleInc.pdf" target="_blank" rel="nofollow noopener noreferrer">Output PDF Format</a>. You will have to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions" target="_blank" rel="nofollow noopener noreferrer">**LoadOptions**</a> class and specify <a href="https://reference.aspose.com/cells/net/aspose.cells/loadformat" target="_blank" rel="nofollow noopener noreferrer">**LoadFormat.Numbers**</a> as a parameter in its constructor to load it successfully. Please download both of them from the given links. You can try the code with any Numbers spreadsheet. Please also read the code comments for more help.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
//Specify load options, we want to load Numbers spreadsheet
LoadOptions opts = new LoadOptions(LoadFormat.Numbers);

//Load the Numbers spreadsheet in workbook with above load options
Workbook wb = new Workbook(sourceDir + "sampleNumbersByAppleInc.numbers", opts);

//Save the workbook to pdf format
wb.Save(outputDir + "outputNumbersByAppleInc.pdf", SaveFormat.Pdf);
```

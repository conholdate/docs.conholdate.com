## Introduction {#introduction}

:::info
Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstyle" target="_blank" rel="nofollow noopener noreferrer">**GetStyle**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setstyle" target="_blank" rel="nofollow noopener noreferrer">**SetStyle**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">Cell</a> class, used to get/set the formatting style of a cell. Aspose.Cells also provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> class.
:::

## How to Format Cells using GetStyle and SetStyle Methods {#how-to-format-cells-using-getstyle-and-setstyle-methods}

Apply different kinds of formatting styles on cells to set background or foreground colors, borders, fonts, horizontal and vertical alignments, indentation level, text direction, rotation angle and much more.

### How to Use the GetStyle and SetStyle Methods {#how-to-use-the-getstyle-and-setstyle-methods}

If developers need to apply different formatting styles to different cells then it's better to get the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> of the cell using <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstyle" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetStyle**</a> method, specify the style attributes and then apply the formatting using <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setstyle" target="_blank" rel="nofollow noopener noreferrer">**Cell.SetStyle**</a> method. An example is given below to demonstrate this approach to apply various formatting to a cell.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Accessing the "A1" cell from the worksheet
Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Hello Aspose!");

// Defining a Style object
Aspose.Cells.Style style;

// Get the style from A1 cell
style = cell.GetStyle();

// Setting the vertical alignment
style.VerticalAlignment = TextAlignmentType.Center;

// Setting the horizontal alignment
style.HorizontalAlignment = TextAlignmentType.Center;

// Setting the font color of the text
style.Font.Color = Color.Green;

// Setting to shrink according to the text contained in it
style.ShrinkToFit = true;

// Setting the bottom border color to red
style.Borders[BorderType.BottomBorder].Color = Color.Red;

// Setting the bottom border type to medium
style.Borders[BorderType.BottomBorder].LineStyle = CellBorderType.Medium;

// Applying the style to A1 cell
cell.SetStyle(style);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

### How to Use Style Object to Format Different Cells {#how-to-use-style-object-to-format-different-cells}

If developers need to apply the same formatting style to different cells then they can use a <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object. Please follow the steps below to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object:

1. Add a <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/createstyle" target="_blank" rel="nofollow noopener noreferrer">**CreateStyle**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class
2. Access the newly added <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object
3. Set the desired properties/attributes of the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object to apply the required formatting settings
4. Assign the configured <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object to your desired cells

This approach can greatly improve the efficiency of your applications and save memory too.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Adding a new worksheet to the Excel object
int i = workbook.Worksheets.Add();

// Obtaining the reference of the first worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[i];

// Accessing the "A1" cell from the worksheet
Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Hello Aspose!");
           
// Adding a new Style
Style style = workbook.CreateStyle();

// Setting the vertical alignment of the text in the "A1" cell
style.VerticalAlignment = TextAlignmentType.Center;

// Setting the horizontal alignment of the text in the "A1" cell
style.HorizontalAlignment = TextAlignmentType.Center;

// Setting the font color of the text in the "A1" cell
style.Font.Color = Color.Green;

// Shrinking the text to fit in the cell
style.ShrinkToFit = true;

// Setting the bottom border color of the cell to red
style.Borders[BorderType.BottomBorder].Color = Color.Red;

// Setting the bottom border type of the cell to medium
style.Borders[BorderType.BottomBorder].LineStyle = CellBorderType.Medium;

// Assigning the Style object to the "A1" cell
cell.SetStyle(style);


// Apply the same style to some other cells
worksheet.Cells["B1"].SetStyle(style);
worksheet.Cells["C1"].SetStyle(style);
worksheet.Cells["D1"].SetStyle(style);


// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

### How to Use Microsoft Excel 2007 Predefined Styles {#how-to-use-microsoft-excel-2007-predefined-styles}

If you need to apply different formatting styles for Microsoft Excel 2007, apply styles using the Aspose.Cells API. An example is given below to demonstrate this approach to apply a predefined style on a cell.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiate a new Workbook.
Workbook workbook = new Workbook();

// Create a style object .
Style style = workbook.CreateStyle();

// Input a value to A1 cell.
workbook.Worksheets[0].Cells["A1"].PutValue("Test");

// Apply the style to the cell.
workbook.Worksheets[0].Cells["A1"].SetStyle(style);

// Save the Excel 2007 file.
workbook.Save(dataDir + "book1.out.xlsx");
```

## How to Format Selected Characters in a Cell {#how-to-format-selected-characters-in-a-cell}

Dealing with Font Settings explains how to format text in cells, but it only explains how to format all of the cell content. What if you want to format only selected characters?

Aspose.Cells supports this feature too. This topic explains how to use this feature effectively.

### How to Format Selected Characters {#how-to-format-selected-characters}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection represents an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/characters" target="_blank" rel="nofollow noopener noreferrer">**Characters**</a> method that takes the following parameters to select a range of characters inside a cell:

- **Start Index**, the index of the character where the selection starts.
- **Number of Characters**, the number of characters to select.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/characters" target="_blank" rel="nofollow noopener noreferrer">**Characters**</a> method returns an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells/fontsetting" target="_blank" rel="nofollow noopener noreferrer">**FontSetting**</a> class that allows developers to format the characters in the same way they would format a cell, as shown below in the code example. In the output file, in the A1 cell, the word **Visit** will be formatted with the default font but **Aspose!** is bold and blue.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first(default) worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[0];

// Accessing the "A1" cell from the worksheet
Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Visit Aspose!");

// Setting the font of selected characters to bold
cell.Characters(6, 7).Font.IsBold = true;

// Setting the font color of selected characters to blue
cell.Characters(6, 7).Font.Color = Color.Blue;

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

:::info
If you are interested in formatting a portion of Rich Text in a cell, consider using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getcharacters" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetCharacters**</a> & <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setcharacters" target="_blank" rel="nofollow noopener noreferrer">**Cell.SetCharacters**</a> methods. The **Cell.GetCharacters** method is used to access the portions of the text and then amendments can be done using the **Cell.SetCharacters** method, whereas the **Get** method returns an array of <a href="https://reference.aspose.com/cells/net/aspose.cells/fontsetting" target="_blank" rel="nofollow noopener noreferrer">**FontSetting**</a> objects which can be manipulated to set various properties such as font name, font color, boldness, etc., and the **Set** method can be used to apply the changes.
:::

## How to Format Rows and Columns {#how-to-format-rows-and-columns}

Sometimes, developers need to apply the same formatting on rows or columns. Applying formatting on cells one by one often takes longer and is not a good solution.\
To address this issue, Aspose.Cells provides a simple, fast way discussed in detail in this article.

### Formatting Rows & Columns {#formatting-rows--columns}

Aspose.Cells provides a class, the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/rows" target="_blank" rel="nofollow noopener noreferrer">**Rows**</a> collection.

### How to Format a Row {#how-to-format-a-row}

Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/rows" target="_blank" rel="nofollow noopener noreferrer">**Rows**</a> collection represents a <a href="https://reference.aspose.com/cells/net/aspose.cells/row" target="_blank" rel="nofollow noopener noreferrer">**Row**</a> object. The <a href="https://reference.aspose.com/cells/net/aspose.cells/row" target="_blank" rel="nofollow noopener noreferrer">**Row**</a> object offers the <a href="https://reference.aspose.com/cells/net/aspose.cells/row/methods/applystyle" target="_blank" rel="nofollow noopener noreferrer">**ApplyStyle**</a> method used to set the row's formatting. To apply the same formatting to a row, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object. The steps below show how to use it.

1. Add a <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object to the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class by calling its <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/createstyle" target="_blank" rel="nofollow noopener noreferrer">**CreateStyle**</a> method.
2. Set the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object's properties to apply formatting settings.
3. Make the relevant attributes **on** for the <a href="https://reference.aspose.com/cells/net/aspose.cells/styleflag" target="_blank" rel="nofollow noopener noreferrer">**StyleFlag**</a> object.
4. Assign the configured <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object to the <a href="https://reference.aspose.com/cells/net/aspose.cells/row" target="_blank" rel="nofollow noopener noreferrer">**Row**</a> object.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first (default) worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[0];

// Adding a new Style to the styles
Style style = workbook.CreateStyle();

// Setting the vertical alignment of the text in the "A1" cell
style.VerticalAlignment = TextAlignmentType.Center;

// Setting the horizontal alignment of the text in the "A1" cell
style.HorizontalAlignment = TextAlignmentType.Center;

// Setting the font color of the text in the "A1" cell
style.Font.Color = Color.Green;

// Shrinking the text to fit in the cell
style.ShrinkToFit = true;

// Setting the bottom border color of the cell to red
style.Borders[BorderType.BottomBorder].Color = Color.Red;

// Setting the bottom border type of the cell to medium
style.Borders[BorderType.BottomBorder].LineStyle = CellBorderType.Medium;

// Creating StyleFlag
StyleFlag styleFlag = new StyleFlag();
styleFlag.HorizontalAlignment = true;
styleFlag.VerticalAlignment = true;
styleFlag.ShrinkToFit = true;
styleFlag.Borders = true;
styleFlag.FontColor = true;

// Accessing a row from the Rows collection
Row row = worksheet.Cells.Rows[0];

// Assigning the Style object to the Style property of the row
row.ApplyStyle(style, styleFlag);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

### How to Format a Column {#how-to-format-a-column}

The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection also provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/columns" target="_blank" rel="nofollow noopener noreferrer">**Columns**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/columns" target="_blank" rel="nofollow noopener noreferrer">**Columns**</a> collection represents a <a href="https://reference.aspose.com/cells/net/aspose.cells/column" target="_blank" rel="nofollow noopener noreferrer">**Column**</a> object. Similar to a <a href="https://reference.aspose.com/cells/net/aspose.cells/row" target="_blank" rel="nofollow noopener noreferrer">**Row**</a> object, the <a href="https://reference.aspose.com/cells/net/aspose.cells/column" target="_blank" rel="nofollow noopener noreferrer">**Column**</a> object also offers the <a href="https://reference.aspose.com/cells/net/aspose.cells/row/methods/applystyle" target="_blank" rel="nofollow noopener noreferrer">**ApplyStyle**</a> method for formatting a column.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first (default) worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[0];           

// Adding a new Style to the styles
Style style = workbook.CreateStyle();

// Setting the vertical alignment of the text in the "A1" cell
style.VerticalAlignment = TextAlignmentType.Center;

// Setting the horizontal alignment of the text in the "A1" cell
style.HorizontalAlignment = TextAlignmentType.Center;

// Setting the font color of the text in the "A1" cell
style.Font.Color = Color.Green;

// Shrinking the text to fit in the cell
style.ShrinkToFit = true;

// Setting the bottom border color of the cell to red
style.Borders[BorderType.BottomBorder].Color = Color.Red;

// Setting the bottom border type of the cell to medium
style.Borders[BorderType.BottomBorder].LineStyle = CellBorderType.Medium;

// Creating StyleFlag
StyleFlag styleFlag = new StyleFlag();
styleFlag.HorizontalAlignment = true;
styleFlag.VerticalAlignment = true;
styleFlag.ShrinkToFit = true;
styleFlag.Borders = true;
styleFlag.FontColor = true;

// Accessing a column from the Columns collection
Column column = worksheet.Cells.Columns[0];

// Applying the style to the column
column.ApplyStyle(style, styleFlag);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

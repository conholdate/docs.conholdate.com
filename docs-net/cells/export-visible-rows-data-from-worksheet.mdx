:::info
You can export data from worksheets into data tables using Aspose.Cells. Sometimes you want to export the data of visible rows only. Aspose.Cells provides a way to achieve this. Use **ExportTableOptions.PlotVisibleRows** to specify that you want to export only visible rows' data.
:::

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
string filePath = dataDir + "aspose-sample.xlsx";

// Load the source workbook
Workbook workbook = new Workbook(filePath);

// Access the first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Specify export table options
ExportTableOptions exportOptions = new ExportTableOptions();
exportOptions.PlotVisibleRows = true;
exportOptions.ExportColumnName = true;

// Export the data from worksheet with export options
DataTable dataTable = worksheet.Cells.ExportDataTable(0, 0, 10, 4, exportOptions);
```

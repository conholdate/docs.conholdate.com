:::info
Aspose.Cells allows you to load your **Excel** file without charts. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions/properties/loadfilter" target="_blank" rel="nofollow noopener noreferrer">**LoadOptions.LoadFilter**</a> property for this purpose.
:::

## Load Spreadsheet Without Charts {#load-spreadsheet-without-charts}

The following sample code loads the sample **Excel** file without charts and saves it in output PDF format.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
            
// Specify the load options and filter the data
LoadOptions options = new LoadOptions();

// Include everything except charts
options.LoadFilter = new LoadFilter(LoadDataFilterOptions.All & ~LoadDataFilterOptions.Chart);

// Load the workbook with specified load options
Workbook workbook = new Workbook(dataDir + "chart.xlsx", options);

// Save the workbook in PDF format
workbook.Save(dataDir + "ResultWithoutChart.pdf", SaveFormat.Pdf);
```

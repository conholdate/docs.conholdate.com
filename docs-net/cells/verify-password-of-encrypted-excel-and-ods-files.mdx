:::info
If Excel (xlsx, xlsb, xls, xlsm) and OpenOffice (ODS) files are locked with a password, Aspose supports simple password verification without parsing specific data of the files.
:::

## Verify the password of the encrypted file {#verify-the-password-of-the-encrypted-file}

To verify the password of the encrypted file, Aspose.Cells for .NET provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/fileformatutil/methods/verifypassword" target="_blank" rel="nofollow noopener noreferrer">**VerifyPassword**</a> method. This method accepts two parameters: the file stream and the password that needs to be verified.\
The following code snippet demonstrates the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells/fileformatutil/methods/verifypassword" target="_blank" rel="nofollow noopener noreferrer">**VerifyPassword**</a> method to verify whether the provided password is valid or not.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create a Stream object
FileStream fstream = new FileStream(dataDir + "EncryptedBook1.xlsx", FileMode.Open);

bool isPasswordValid = FileFormatUtil.VerifyPassword(fstream, "1234");

Console.WriteLine("Password is Valid: " + isPasswordValid);
```

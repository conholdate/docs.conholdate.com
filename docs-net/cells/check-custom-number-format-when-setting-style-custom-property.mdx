## Possible Usage Scenarios {#possible-usage-scenarios}

If you assign an invalid custom number format to the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/custom" target="_blank" rel="nofollow noopener noreferrer">**Style.Custom**</a> property, Aspose.Cells will not throw any exception. However, if you want Aspose.Cells to check whether the assigned custom number format is valid, set the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/checkcustomnumberformat" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.CheckCustomNumberFormat**</a> property to **true**.

## Check Custom Number Format when setting Style.Custom property {#check-custom-number-format-when-setting-stylecustom-property}

The following sample code assigns an invalid custom number format to the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/custom" target="_blank" rel="nofollow noopener noreferrer">**Style.Custom**</a> property. Since we have already set the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/checkcustomnumberformat" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.CheckCustomNumberFormat**</a> property to **true**, it throws an exception (e.g., Invalid number format). Please read the comments in the code for more information.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Create an instance of Workbook class
Workbook book = new Workbook();

// Setting this property to true will make Aspose.Cells to throw exception
// when invalid custom number format is assigned to Style.Custom property
book.Settings.CheckCustomNumberFormat = true;

// Access first worksheet
Worksheet sheet = book.Worksheets[0];

// Access cell A1 and put some number to it
Cell cell = sheet.Cells["A1"];
cell.PutValue(2347);

// Access cell's style and set its Style.Custom property
Style style = cell.GetStyle();

// This line will throw exception if Workbook.Settings.CheckCustomNumberFormat is set to true
style.Custom = "ggg @ fff"; //Invalid custom number format
```

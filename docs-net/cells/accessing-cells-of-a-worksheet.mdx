:::info
We know that all worksheets may contain data that is basically stored in cells, which make up a worksheet. A cell is a basic part of a worksheet that is used to construct the whole worksheet as a sequence of rows and columns. Before we try to access data from a worksheet, we need to get access to its cells. So, in this topic, we will discuss some basic approaches to access worksheet cells at runtime using Aspose.Cells.
:::

## How to Access Cells {#how-to-access-cells}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents an Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet.

We can use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection to access cells in a worksheet. Aspose.Cells provides three basic approaches to access cells in a worksheet:

1. Using the cell name.
2. Using a cell's row and column index.
3. Using a cell index in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection.

**IMPORTANT:** We have mentioned that the third approach is the fastest and the first approach is the slowest. The performance difference between the approaches is very small, so don't worry about performance degradation regardless of which approach you use.

### How to Get a Cell Object by Cell Name {#how-to-get-a-cell-object-by-cell-name}

Developers can access any specific cell by passing its cell name to the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class as an index.

If you create a blank worksheet at the start, the count of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection is zero. When you use this approach to access a cell, it will check whether this cell exists in the collection or not. If yes, it returns the cell object in the collection; otherwise, it creates a new <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> object, adds the object to the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection, and then returns the object. This approach is the easiest way to access the cell if you are familiar with Microsoft Excel, but it is the slowest compared to the other approaches.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

Workbook workbook = new Workbook(dataDir + "book1.xls");

// Using the Sheet 1 in Workbook
Worksheet worksheet = workbook.Worksheets[0];

// Accessing a cell using its name
Cell cell = worksheet.Cells["A1"];

string value = cell.Value.ToString();

Console.WriteLine(value);
```

### How to Get a Cell Object by Row & Column Index {#how-to-get-a-cell-object-by-row--column-index}

Developers can access any specific cell by passing the indices of its row and column to the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class.

This approach works in the same way as the first approach.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook(dataDir + "book1.xls");

// Using the Sheet 1 in Workbook
Worksheet worksheet = workbook.Worksheets[0];

// Accessing a cell using its row and column
Cell cell = worksheet.Cells[0,0];

string value = cell.Value.ToString();

Console.WriteLine(value);
```

### How to Get a Cell Object by Cell Index in the Cells Collection {#how-to-get-a-cell-object-by-cell-index-in-the-cells-collection}

A cell can also be accessed by passing the cell's numeric index to the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection.

If you use this approach to access cells, an exception can be thrown if the numeric index of the cell is out of range. This approach is the fastest one to access the cells, but it is important to note that the numeric index may change after new cells are added to the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. The cell objects in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection are internally sorted by row and column indices.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Open an existing worksheet
Workbook workbook = new Workbook(dataDir + "book1.xls");

// Using the Sheet 1 in Workbook
Worksheet worksheet = workbook.Worksheets[0];

// Accessing a cell using its row and column.
Cell cell = worksheet.Cells.CheckCell(0, 0);

if (cell != null)
{
    string value = cell.Value.ToString();

    Console.WriteLine(value);
}
```

## How to Get the Maximum Display Range of a Worksheet {#how-to-get-the-maximum-display-range-of-a-worksheet}

Aspose.Cells allows developers to access a worksheet's maximum display range. The maximum display range-the range of cells between the first and last cell with content-is useful when you need to copy, select, or display the entire contents of a worksheet in an image.

You can access a worksheet's maximum display range using <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/maxdisplayrange" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Cells.MaxDisplayRange**</a>. The following sample code illustrates how to access the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/maxdisplayrange" target="_blank" rel="nofollow noopener noreferrer">**MaxDisplayRange**</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

           

// Path to source file
string filePath = dataDir + "Book1.xlsx";
// Instantiating a Workbook object
Workbook workbook = new Workbook(filePath);

// Instantiate a workbook from source file
Workbook wb = new Workbook(filePath);

// Access the first workbook
Worksheet worksheet = wb.Worksheets[0];

// Access the Maximum Display Range
Range range = worksheet.Cells.MaxDisplayRange;

// Print the Maximum Display Range RefersTo property
Console.WriteLine("Maximum Display Range: " + range.RefersTo);
```

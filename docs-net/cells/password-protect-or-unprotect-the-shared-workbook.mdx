## Possible Usage Scenarios {#possible-usage-scenarios}

You can protect or unprotect the shared workbook with Microsoft Excel as shown in the following screenshot. ## Password Protect or Unprotect the Shared Workbook {#password-protect-or-unprotect-the-shared-workbook}

The following sample code creates a workbook, protects it while enabling sharing, and saves it as an <a href="https://docs.aspose.com/cells/net/password-protect-or-unprotect-the-shared-workbook/55541777.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. The screenshot shows that when you try to unprotect it, Microsoft Excel prompts you to enter the password.

![todo:image_alt_text](/net/cells/images/0041d2f0736d9826-password-protect-or-unprotect-the-shared-workbook_2.png)

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create empty Excel file
Workbook wb = new Workbook();

//Protect the Shared Workbook with Password
wb.ProtectSharedWorkbook("1234");

//Uncomment this line to Unprotect the Shared Workbook
//wb.UnprotectSharedWorkbook("1234");

//Save the output Excel file
wb.Save("outputProtectSharedWorkbook.xlsx");
```

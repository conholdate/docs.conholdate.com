## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes, the workbook contains external links that are hidden and cannot be viewed in Microsoft Excel. Aspose.Cells retrieves all the external links whether they are visible or hidden. However, you can check the <a href="https://reference.aspose.com/cells/net/aspose.cells/externallink/properties/isvisible" target="_blank" rel="nofollow noopener noreferrer">ExternalLink.IsVisible</a> property to determine whether the external link is visible.

## Check if Workbook contains hidden External Links {#check-if-workbook-contains-hidden-external-links}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/check-if-workbook-contains-hidden-external-links/5115413.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a> which contains hidden external links. These links cannot be viewed in Microsoft Excel but they are present inside the workbook. After printing the <a href="https://reference.aspose.com/cells/net/aspose.cells/externallink/properties/datasource" target="_blank" rel="nofollow noopener noreferrer">ExternalLink.DataSource</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/externallink/properties/isreferred" target="_blank" rel="nofollow noopener noreferrer">ExternalLink.IsReferred</a> properties, it prints the <a href="https://reference.aspose.com/cells/net/aspose.cells/externallink/properties/isvisible" target="_blank" rel="nofollow noopener noreferrer">ExternalLink.IsVisible</a> property. In the console output below, you can see that all of its external links are not visible.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Loads the workbook which contains hidden external links
Workbook workbook = new Workbook(dataDir + "sample.xlsx");

// Access the external link collection of the workbook
ExternalLinkCollection links = workbook.Worksheets.ExternalLinks;

// Print all the external links and check there IsVisible property
for (int i = 0; i < links.Count; i++)
{
    Console.WriteLine("Data Source: " + links[i].DataSource);
    Console.WriteLine("Is Referred: " + links[i].IsReferred);
    Console.WriteLine("Is Visible: " + links[i].IsVisible);
    Console.WriteLine();
}
```

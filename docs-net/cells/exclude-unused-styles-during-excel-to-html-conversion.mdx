## Possible Usage Scenarios {#possible-usage-scenarios}

A Microsoft Excel file may contain many unused styles. When you export the Excel file to HTML format, these unused styles are also exported. This can increase the size of the HTML. You can exclude the unused styles during the conversion of the Excel file to HTML using the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/excludeunusedstyles" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.ExcludeUnusedStyles**</a> property. When you set it **to true**, all unused styles are excluded from the output HTML. The following screenshot displays a sample unused style inside the output HTML.

## Exclude Unused Styles during Excel to HTML conversion {#exclude-unused-styles-during-excel-to-html-conversion}

The following sample code creates a workbook and also creates an unused named style. Since the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/excludeunusedstyles" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.ExcludeUnusedStyles**</a> is set **to true**, this unused named style will not be exported to the <a href="https://docs.aspose.com/cells/net/exclude-unused-styles-during-excel-to-html-conversion/61767778.zip" target="_blank" rel="nofollow noopener noreferrer">output HTML</a>. However, if you set it **to false**, this unused style will be present in the output HTML, which you can then see in the HTML markup as shown in the above screenshot.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create workbook
Workbook wb = new Workbook();

//Create an unused named style
wb.CreateStyle().Name = "UnusedStyle_XXXXXXXXXXXXXX";

//Access first worksheet
Worksheet ws = wb.Worksheets[0];

//Put some value in cell C7
ws.Cells["C7"].PutValue("This is sample text.");

//Specify html save options, we want to exclude unused styles
HtmlSaveOptions opts = new HtmlSaveOptions();

//Comment this line to include unused styles
opts.ExcludeUnusedStyles = true;

//Save the workbook in html format
wb.Save("outputExcludeUnusedStylesInExcelToHTML.html", opts);
```

:::info
Scroll bars are widely used to navigate the contents of any file. Normally, there are two kinds of scroll bars:

- Vertical scroll bars
- Horizontal scroll bars

Microsoft Excel also provides horizontal and vertical scroll bars so that users can scroll through worksheet contents. Using Aspose.Cells, developers can control the visibility of both types of scroll bars in Excel files.
:::

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents an Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class provides a wide range of properties and methods for managing an Excel file. To control the visibility of scroll bars, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/isvscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**IsVScrollBarVisible**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/ishscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**IsHScrollBarVisible**</a> properties. <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/isvscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**IsVScrollBarVisible**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/ishscrollbarvisible" target="_blank" rel="nofollow noopener noreferrer">**IsHScrollBarVisible**</a> are Boolean properties, which means that these properties can only store **true** or **false** values.

Below is complete code that opens an Excel file, book1.xls, hides both scroll bars, and then saves the modified file as output.xls.

The screenshot below shows Book1.xls file containing both scroll bars. The modified file is saved as output.xls, also shown below.

**C#**

```csharp
 //Creating a file stream containing the Excel file to be opened

FileStream fstream = new FileStream("book1.xls", FileMode.Open);

//Instantiating a Workbook object

//Opening the Excel file through the file stream

Workbook workbook = new Workbook(fstream);

//Hiding the vertical scroll bar of the Excel file

workbook.Settings.IsVScrollBarVisible = false;

//Hiding the horizontal scroll bar of the Excel file

workbook.Settings.IsHScrollBarVisible = false;

//Saving the modified Excel file

workbook.Save("output.xls");

//Closing the file stream to free all resources

fstream.Close();
```

## Possible Usage Scenarios {#possible-usage-scenarios}

By default, Aspose.Cells stores 17 significant digits of double values inside the Excel file, unlike Microsoft Excel which stores only 15 significant digits. You can change the default behavior of Aspose.Cells from 17 significant digits to 15 significant digits using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellshelper/properties/significantdigits" target="_blank" rel="nofollow noopener noreferrer">**CellsHelper.SignificantDigits**</a> property.

## Specifying Significant Digits to be Stored in Excel File {#specifying-significant-digits-to-be-stored-in-excel-file}

The following sample code enforces Aspose.Cells to use 15 significant digits while storing double values inside the Excel file. Please check the <a href="https://docs.aspose.com/cells/net/specifying-significant-digits-to-be-stored-in-excel-file/22774105.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. Change its extension to .zip and unzip it, and you will see that only 15 significant digits are stored inside the Excel file. The following screenshot explains the effect of <a href="https://reference.aspose.com/cells/net/aspose.cells/cellshelper/properties/significantdigits" target="_blank" rel="nofollow noopener noreferrer">**CellsHelper.SignificantDigits**</a> property on the output Excel file.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

//By default, Aspose.Cells stores 17 significant digits unlike
//MS-Excel which stores only 15 significant digits
CellsHelper.SignificantDigits = 15;

//Create workbook
Workbook workbook = new Workbook();

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

//Access cell A1
Cell c = worksheet.Cells["A1"];

//Put double value, only 15 significant digits as specified by
//CellsHelper.SignificantDigits above will be stored in excel file just like MS-Excel does
c.PutValue(1234567890.123451711);

//Save the workbook
workbook.Save(dataDir + "out_SignificantDigits.xlsx");
```

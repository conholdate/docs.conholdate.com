## Possible Usage Scenarios {#possible-usage-scenarios}

You can query cell areas mapped to the XML map path with Aspose.Cells using the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/xmlmapquery" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.XmlMapQuery()**</a> method. If the path exists, it will return the list of cell areas related to that path inside the XML map. The first parameter of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/xmlmapquery" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.XmlMapQuery()**</a> method specifies the XML element path, and the second parameter specifies the XML map you want to query.

## Query Cell Areas Mapped to XML Map Path using Worksheet.XmlMapQuery method {#query-cell-areas-mapped-to-xml-map-path-using-worksheetxmlmapquery-method}

The following screenshot shows Microsoft Excel displaying an XML map inside the <a href="https://docs.aspose.com/cells/net/query-cell-areas-mapped-to-xml-map-path-using-worksheet-xmlmapquery-method/55541790.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in the code. The code queries the XML map twice and prints the list of cell areas returned by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/methods/xmlmapquery" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.XmlMapQuery()**</a> method on the console as shown below.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load sample Excel file having Xml Map
Workbook wb = new Workbook("sampleXmlMapQuery.xlsx");

//Access first XML Map
XmlMap xmap = wb.Worksheets.XmlMaps[0];

//Access first worksheet
Worksheet ws = wb.Worksheets[0];

//Query Xml Map from Path - /MiscData
Console.WriteLine("Query Xml Map from Path - /MiscData");
ArrayList ret = ws.XmlMapQuery("/MiscData", xmap);

//Print returned ArrayList values
for (int i = 0; i < ret.Count; i++)
{
	Console.WriteLine(ret[i]);
}

Console.WriteLine("");

//Query Xml Map from Path - /MiscData/row/Color
Console.WriteLine("Query Xml Map from Path - /MiscData/row/Color");
ret = ws.XmlMapQuery("/MiscData/row/Color", xmap);

//Print returned ArrayList values
for (int i = 0; i < ret.Count; i++)
{
	Console.WriteLine(ret[i]);
}
```

## Get XML path from List Object/Table {#get-xml-path-from-list-objecttable}

XML data can be imported to worksheets. Sometimes an XML path is required from the ListObjects of the worksheet. This feature is available in Excel by using an expression like `Sheet1.ListObjects(1).XmlMap.DataBinding`. The same feature is available in Aspose.Cells by calling <a href="https://reference.aspose.com/cells/net/aspose.cells/xmldatabinding/properties/url" target="_blank" rel="nofollow noopener noreferrer">**ListObject.XmlMap.DataBinding.Url**</a>. The following example demonstrates this feature. Template files and other source files can be downloaded from the following links:

1. <a href="https://docs.aspose.com/cells/net/query-cell-areas-mapped-to-xml-map-path-using-worksheet-xmlmapquery-method/72417285.xlsx" target="_blank" rel="nofollow noopener noreferrer">XML Data.xlsx</a>
2. <a href="https://docs.aspose.com/cells/net/query-cell-areas-mapped-to-xml-map-path-using-worksheet-xmlmapquery-method/72417287.xml" target="_blank" rel="nofollow noopener noreferrer">Country List.xml</a>
3. <a href="https://docs.aspose.com/cells/net/query-cell-areas-mapped-to-xml-map-path-using-worksheet-xmlmapquery-method/72417286.xml" target="_blank" rel="nofollow noopener noreferrer">Food List.xml</a>

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Load XLSX file containing data from XML file
Workbook workbook = new Workbook("XML Data.xlsx");

// Access the first worksheet
Worksheet ws = workbook.Worksheets[0];

// Access ListObject from the first sheet
Aspose.Cells.Tables.ListObject listObject = ws.ListObjects[0];


// Get the url of the list object's xml map data binding
string url = listObject.XmlMap.DataBinding.Url;

// Display XML file name
Console.WriteLine(url);
```

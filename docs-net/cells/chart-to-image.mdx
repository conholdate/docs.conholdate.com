## Rendering Charts {#rendering-charts}

Aspose.Cells APIs support converting Excel charts to image formats without requiring any additional tools or applications. In order to provide rendering support, the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart" target="_blank" rel="nofollow noopener noreferrer">**Chart**</a> class has exposed <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/methods/toimage/index" target="_blank" rel="nofollow noopener noreferrer">**ToImage**</a> methods with a **variety** of overloads to best suit the application requirements.

### Rendering Charts to Images {#rendering-charts-to-images}

The <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/methods/toimage/index" target="_blank" rel="nofollow noopener noreferrer">**Chart.ToImage**</a> method has a **variety** of overloads to support simple as well as advanced rendering. If the application requirement is to render the chart in its default dimensions, we suggest you use the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/methods/toimage/index" target="_blank" rel="nofollow noopener noreferrer">**Chart.ToImage**</a> method **as follows**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();
// Adding a new worksheet to the Workbook
int sheetIndex = workbook.Worksheets.Add();
// Obtaining the reference of the newly added worksheet by passing its index to WorksheetCollection
Worksheet worksheet = workbook.Worksheets[sheetIndex];

// Adding sample values to cells
worksheet.Cells["A1"].PutValue(50);
worksheet.Cells["A2"].PutValue(100);
worksheet.Cells["A3"].PutValue(150);
worksheet.Cells["B1"].PutValue(4);
worksheet.Cells["B2"].PutValue(20);
worksheet.Cells["B3"].PutValue(50);

// Adding a chart to the worksheet
int chartIndex = worksheet.Charts.Add(Aspose.Cells.Charts.ChartType.Column, 5, 0, 15, 5);
// Accessing the instance of the newly added chart
Aspose.Cells.Charts.Chart chart = worksheet.Charts[chartIndex];
// Adding Series Collection (chart data source) to the chart ranging from "A1" cell to "B3"
chart.NSeries.Add("A1:B3", true);
            
// Converting chart to image
chart.ToImage(dataDir + "chartEMF_out.emf", ImageType.Emf);

// Converting chart to Bitmap
System.Drawing.Bitmap bitmap = chart.ToImage();
bitmap.Save(dataDir + "chartBMP_out.bmp", System.Drawing.Imaging.ImageFormat.Bmp);
```

It is also possible to render the charts to images with advanced settings. Aspose.Cells APIs have exposed an overload of the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/methods/toimage/index" target="_blank" rel="nofollow noopener noreferrer">**Chart.ToImage**</a> method that **can** accept an instance of <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions**</a>, while allowing you to specify parameters such as resolution, smoothing mode, image format, and so on.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();
// Adding a new worksheet to the Workbook
int sheetIndex = workbook.Worksheets.Add();
// Obtaining the reference of the newly added worksheet by passing its index to WorksheetCollection
Worksheet worksheet = workbook.Worksheets[sheetIndex];

// Adding sample values to cells
worksheet.Cells["A1"].PutValue(50);
worksheet.Cells["A2"].PutValue(100);
worksheet.Cells["A3"].PutValue(150);
worksheet.Cells["B1"].PutValue(4);
worksheet.Cells["B2"].PutValue(20);
worksheet.Cells["B3"].PutValue(50);

// Adding a chart to the worksheet
int chartIndex = worksheet.Charts.Add(Aspose.Cells.Charts.ChartType.Column, 5, 0, 15, 5);
// Accessing the instance of the newly added chart
Aspose.Cells.Charts.Chart chart = worksheet.Charts[chartIndex];
// Adding Series Collection (chart data source) to the chart ranging from "A1" cell to "B3"
chart.NSeries.Add("A1:B3", true);

// Create an instance of ImageOrPrintOptions and set a few properties
ImageOrPrintOptions options = new ImageOrPrintOptions()
{
    VerticalResolution = 300,
    HorizontalResolution = 300,
    SmoothingMode = System.Drawing.Drawing2D.SmoothingMode.AntiAlias
};
// Convert chart to image with additional settings
chart.ToImage(dataDir + "chartPNG_out.png", options);
```

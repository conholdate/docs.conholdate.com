## Convert Excel to HTML with headings {#convert-excel-to-html-with-headings}

Aspose.Cells provides the option to export headings while converting Excel to HTML. For this, you may set the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/exportheadings" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.ExportHeadings**</a> property to **true**. The default value of <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/exportheadings" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions.ExportHeadings**</a> property is **false**. ## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
//Load sample source file
Workbook workbook = new Workbook(sourceDir + "Book1.xlsx");

HtmlSaveOptions options = new HtmlSaveOptions();
options.ExportRowColumnHeadings = true;

// Save the workbook
workbook.Save(outputDir + "PrintHeadings_out.html", options);
```

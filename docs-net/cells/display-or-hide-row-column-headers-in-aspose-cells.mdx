:::info
All worksheets in an Excel file are composed of cells that are arranged in rows and columns. All rows and columns have unique values that are used to identify them, and to identify individual cells. For example, rows are numbered - 1, 2, 3, 4, etc. - and columns are ordered alphabetically - A, B, C, D, etc. The row and column values are displayed in the headers. Using Aspose.Cells, developers can control the visibility of these row and column headers.
:::

## Controlling the Visibility of the Worksheets {#controlling-the-visibility-of-the-worksheets}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a>, that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods for managing worksheets. To control the visibility of row and column headers, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isrowcolumnheadersvisible" target="_blank" rel="nofollow noopener noreferrer">**IsRowColumnHeadersVisible**</a> property. <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isrowcolumnheadersvisible" target="_blank" rel="nofollow noopener noreferrer">**IsRowColumnHeadersVisible**</a> is a Boolean property, which means that it can only store a **true** or **false** value.

A complete example is given below that shows how to use the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class's <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/isrowcolumnheadersvisible" target="_blank" rel="nofollow noopener noreferrer">**IsRowColumnHeadersVisible**</a> property to hide row and column headers on the first worksheet in a file.

The screenshot shows the **Book1.xls** input file. It contains three worksheets: Sheet1, Sheet2, and Sheet3. Each worksheet shows row and column headers.

**Book1.xls** is opened by calling the Workbook class's **Open** method, and the row and column headers on the first worksheet are hidden. The modified file is saved as **output.xls**.

**Output.xls: worksheet after modification**

![todo:image_alt_text](/net/cells/images/392a5821d75e8ccf-display-or-hide-row-column-headers-in-aspose-cells_2.png)

**C#**

```csharp
 //Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream("book1.xls", FileMode.Open);

//Instantiating a Workbook object
//Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

//Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

//Hiding the headers of rows and columns
worksheet.IsRowColumnHeadersVisible = false;

//Saving the modified Excel file
workbook.Save("output.xls");

//Closing the file stream to free all resources
fstream.Close();
```

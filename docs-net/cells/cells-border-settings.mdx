## Adding Borders to Cells {#adding-borders-to-cells}

Microsoft Excel allows users to format cells by adding borders. The type of border depends on where it is added. For example, a top border is one added to the top position of a cell. Users can also modify the borders' line style and color.

With Aspose.Cells, developers can add borders and customize how they look in the same flexible way as in Microsoft Excel.

### Adding Borders to Cells {#adding-borders-to-cells-1}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Each item in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection represents an object of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstyle/index" target="_blank" rel="nofollow noopener noreferrer">**GetStyle**</a> method in the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setstyle/index" target="_blank" rel="nofollow noopener noreferrer">**SetStyle**</a> method is used to set a cell's formatting style. The <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> class provides properties for adding borders to cells.

#### Adding Borders to a Cell {#adding-borders-to-a-cell}

Developers can add borders to a cell by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/style" target="_blank" rel="nofollow noopener noreferrer">**Style**</a> object's <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/borders" target="_blank" rel="nofollow noopener noreferrer">**Borders**</a> collection. The border type is passed as an index to the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/borders" target="_blank" rel="nofollow noopener noreferrer">**Borders**</a> collection. All border types are pre‑defined in the <a href="https://reference.aspose.com/cells/net/aspose.cells/bordertype" target="_blank" rel="nofollow noopener noreferrer">**BorderType**</a> enumeration.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/borders" target="_blank" rel="nofollow noopener noreferrer">**Borders**</a> collection stores all borders. Each border in the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/borders" target="_blank" rel="nofollow noopener noreferrer">**Borders**</a> collection is represented by a <a href="https://reference.aspose.com/cells/net/aspose.cells/border" target="_blank" rel="nofollow noopener noreferrer">**Border**</a> object which provides two properties, <a href="https://reference.aspose.com/cells/net/aspose.cells/border/properties/color" target="_blank" rel="nofollow noopener noreferrer">**Color**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/border/properties/linestyle" target="_blank" rel="nofollow noopener noreferrer">**LineStyle**</a> to set a border's line color and style respectively.

To set a border's line color, select a color using the Color enumeration (part of the .NET Framework) and assign it to the Border object's Color property.

The border's line style is set by selecting a line style from the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellbordertype" target="_blank" rel="nofollow noopener noreferrer">**CellBorderType**</a> enumeration.

Select one of the line styles and then assign it to the <a href="https://reference.aspose.com/cells/net/aspose.cells/border" target="_blank" rel="nofollow noopener noreferrer">**Border**</a> object's <a href="https://reference.aspose.com/cells/net/aspose.cells/border/properties/linestyle" target="_blank" rel="nofollow noopener noreferrer">**LineStyle**</a> property.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first (default) worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[0];

// Accessing the "A1" cell from the worksheet
Aspose.Cells.Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Visit Aspose!");

// Create a style object
Style style = cell.GetStyle();

// Setting the line style of the top border
style.Borders[BorderType.TopBorder].LineStyle = CellBorderType.Thick;

// Setting the color of the top border
style.Borders[BorderType.TopBorder].Color = Color.Black;

// Setting the line style of the bottom border
style.Borders[BorderType.BottomBorder].LineStyle = CellBorderType.Thick;

// Setting the color of the bottom border
style.Borders[BorderType.BottomBorder].Color = Color.Black;

// Setting the line style of the left border
style.Borders[BorderType.LeftBorder].LineStyle = CellBorderType.Thick;

// Setting the color of the left border
style.Borders[BorderType.LeftBorder].Color = Color.Black;

// Setting the line style of the right border
style.Borders[BorderType.RightBorder].LineStyle = CellBorderType.Thick;

// Setting the color of the right border
style.Borders[BorderType.RightBorder].Color = Color.Black;

// Apply the border styles to the cell
cell.SetStyle(style);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

:::info
You should set both line style and color at the same time. The two diagonal border lines should have the same line style and color.
:::

#### Adding Borders to a Range of Cells {#adding-borders-to-a-range-of-cells}

It is also possible to add borders to a range of cells rather than just a single cell. To do so, first create a range of cells by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells.cells/createrange/methods/1" target="_blank" rel="nofollow noopener noreferrer">**CreateRange**</a> method. It takes the following parameters:

- First Row - the first row of the range.
- First Column - the first column of the range.
- Number of Rows - the number of rows in the range.
- Number of Columns - the number of columns in the range.

The <a href="https://reference.aspose.com/cells/net/aspose.cells.cells/createrange/methods/1" target="_blank" rel="nofollow noopener noreferrer">**CreateRange**</a> method returns a <a href="https://reference.aspose.com/cells/net/aspose.cells/range" target="_blank" rel="nofollow noopener noreferrer">**Range**</a> object, which contains the specified range of cells. The <a href="https://reference.aspose.com/cells/net/aspose.cells/range" target="_blank" rel="nofollow noopener noreferrer">**Range**</a> object provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/range/methods/setoutlineborder" target="_blank" rel="nofollow noopener noreferrer">**SetOutlineBorder**</a> method that takes the following parameters to add a border to the range of cells:

- **Border Type** - the border type, selected from the <a href="https://reference.aspose.com/cells/net/aspose.cells/bordertype" target="_blank" rel="nofollow noopener noreferrer">**BorderType**</a> enumeration.
- **Line Style** - the border line style, selected from the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellbordertype" target="_blank" rel="nofollow noopener noreferrer">**CellBorderType**</a> enumeration.
- **Color** - the line color, selected from the Color enumeration.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Obtaining the reference of the first (default) worksheet by passing its sheet index
Worksheet worksheet = workbook.Worksheets[0];

// Accessing the "A1" cell from the worksheet
Cell cell = worksheet.Cells["A1"];

// Adding some value to the "A1" cell
cell.PutValue("Hello World From Aspose");

// Creating a range of cells starting from "A1" cell to 3rd column in a row
Range range = worksheet.Cells.CreateRange(0, 0, 1, 3);

// Adding a thick top border with blue line
range.SetOutlineBorder(BorderType.TopBorder, CellBorderType.Thick, Color.Blue);

// Adding a thick bottom border with blue line
range.SetOutlineBorder(BorderType.BottomBorder, CellBorderType.Thick, Color.Blue);

// Adding a thick left border with blue line
range.SetOutlineBorder(BorderType.LeftBorder, CellBorderType.Thick, Color.Blue);

// Adding a thick right border with blue line
range.SetOutlineBorder(BorderType.RightBorder, CellBorderType.Thick, Color.Blue);

// Saving the Excel file
workbook.Save(dataDir + "book1.out.xls");
```

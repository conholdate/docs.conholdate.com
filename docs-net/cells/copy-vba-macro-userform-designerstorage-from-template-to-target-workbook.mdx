## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells allows you to copy a VBA project from one Excel file into another Excel file. A VBA project consists of various types of modules, i.e., Document, Procedural, Designer, etc. All modules can be copied with simple code, but for the Designer module there is some extra data called Designer Storage that needs to be accessed or copied. The following two methods deal with Designer Storage.

- <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbamodulecollection/methods/getdesignerstorage" target="_blank" rel="nofollow noopener noreferrer">**VbaModuleCollection.GetDesignerStorage()**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbamodulecollection/methods/adddesignerstorage" target="_blank" rel="nofollow noopener noreferrer">**VbaModuleCollection.AddDesignerStorage()**</a>

## Copy VBA Macro UserForm DesignerStorage from Template to Target Workbook {#copy-vba-macro-userform-designerstorage-from-template-to-target-workbook}

Please see the following sample code. It copies the VBA project from the <a href="https://docs.aspose.com/cells/net/copy-vba-macro-userform-designerstorage-from-template-to-target-workbook/50528345.xlsm" target="_blank" rel="nofollow noopener noreferrer">template Excel file</a> into an empty workbook and saves it as the <a href="https://docs.aspose.com/cells/net/copy-vba-macro-userform-designerstorage-from-template-to-target-workbook/50528346.xlsm" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. If you open the VBA project inside the template Excel file, you will see a User Form as shown below. The User Form consists of Designer Storage, so it will be copied using <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbamodulecollection/methods/getdesignerstorage" target="_blank" rel="nofollow noopener noreferrer">**VbaModuleCollection.GetDesignerStorage()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.vba/vbamodulecollection/methods/adddesignerstorage" target="_blank" rel="nofollow noopener noreferrer">**VbaModuleCollection.AddDesignerStorage()**</a> methods.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
//Create empty target workbook
Workbook target = new Workbook();

//Load the Excel file containing VBA-Macro Designer User Form
Workbook templateFile = new Workbook(sourceDir + "sampleDesignerForm.xlsm");

//Copy all template worksheets to target workboook
foreach (Worksheet ws in templateFile.Worksheets)
{
	if (ws.Type == SheetType.Worksheet)
	{
		Worksheet s = target.Worksheets.Add(ws.Name);
		s.Copy(ws);

		//Put message in cell A2 of the target worksheet
		s.Cells["A2"].PutValue("VBA Macro and User Form copied from template to target.");
	}
}//foreach

//-----------------------------------------------

//Copy the VBA-Macro Designer UserForm from Template to Target 
foreach (VbaModule vbaItem in templateFile.VbaProject.Modules)
{
	if (vbaItem.Name == "ThisWorkbook")
	{
		//Copy ThisWorkbook module code
		target.VbaProject.Modules["ThisWorkbook"].Codes = vbaItem.Codes;

	}
	else
	{
		//Copy other modules code and data
		System.Diagnostics.Debug.Print(vbaItem.Name);

		int vbaMod = 0;
		Worksheet sheet = target.Worksheets.GetSheetByCodeName(vbaItem.Name);
		if (sheet == null)
		{
			vbaMod = target.VbaProject.Modules.Add(vbaItem.Type, vbaItem.Name);
		}
		else
		{
			vbaMod = target.VbaProject.Modules.Add(sheet);
		}

		target.VbaProject.Modules[vbaMod].Codes = vbaItem.Codes;

		if ((vbaItem.Type == VbaModuleType.Designer))
		{
			//Get the data of the user form i.e. designer storage
			byte[] designerStorage = templateFile.VbaProject.Modules.GetDesignerStorage(vbaItem.Name);

			//Add the designer storage to target Vba Project
			target.VbaProject.Modules.AddDesignerStorage(vbaItem.Name, designerStorage);
		}
	}
}//foreach

//Save the target workbook
target.Save(outputDir + "outputDesignerForm.xlsm", SaveFormat.Xlsm);
```

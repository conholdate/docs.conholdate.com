## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes, one pivot table uses another pivot table as a data source, so it is called a child pivot table or nested pivot table. You can find the child pivot tables of a parent pivot table using the <a href="https://reference.aspose.com/cells/net/aspose.cells.pivot/pivottable/methods/getchildren" target="_blank" rel="nofollow noopener noreferrer">**PivotTable.GetChildren()**</a> method.

## Find and Refresh the Nested or Child Pivot Tables of a Parent Pivot Table {#find-and-refresh-the-nested-or-child-pivot-tables-of-a-parent-pivot-table}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/find-and-refresh-the-nested-or-children-pivot-tables-of-parent-pivot-table/61767747.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains three pivot tables. The bottom two pivot tables are the children of the above pivot table as shown in this screenshot. The code finds the child pivot tables using the <a href="https://reference.aspose.com/cells/net/aspose.cells.pivot/pivottable/methods/getchildren" target="_blank" rel="nofollow noopener noreferrer">**PivotTable.GetChildren()**</a> method and then refreshes them one by one.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load sample Excel file
Workbook wb = new Workbook("sampleFindAndRefreshNestedOrChildrenPivotTables.xlsx");

//Access first worksheet
Worksheet ws = wb.Worksheets[0];

//Access third pivot table
PivotTable ptParent = ws.PivotTables[2];

//Access the children of the parent pivot table
PivotTable[] ptChildren = ptParent.GetChildren();

//Refresh all the children pivot table
int count = ptChildren.Length;
for (int idx = 0; idx < count; idx++)
{
	//Access the child pivot table
	PivotTable ptChild = ptChildren[idx];

	//Refresh the child pivot table
	ptChild.RefreshData();
	ptChild.CalculateData();
}
```

:::info
Unused styles in an Excel file not only take up space but also cause performance issues when converting to different formats such as PDF, HTML, etc. Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/removeunusedstyles" target="_blank" rel="nofollow noopener noreferrer">**Workbook.RemoveUnusedStyles()**</a> method to remove all unused styles inside the workbook.
:::

The following code explains the usage of <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/removeunusedstyles" target="_blank" rel="nofollow noopener noreferrer">**Workbook.RemoveUnusedStyles()**</a>. The code loads the <a href="https://docs.aspose.com/cells/net/remove-unused-styles-inside-the-workbook/5115520.xlsx" target="_blank" rel="nofollow noopener noreferrer">template Excel file</a> which you can download from the provided link. It contains an unused style named **AsposeStyle**; this style and all other unused styles will be removed after the execution of the code.

![todo:image_alt_text](/net/cells/images/c882e0a2e832d3e3-remove-unused-styles-inside-the-workbook_1.png)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Load template excel file containing unused styles
Workbook workbook = new Workbook(dataDir + "Template-With-Unused-Custom-Style.xlsx");

// Remove all unused styles inside the template this will also remove AsposeStyle which is an unused style inside the template
workbook.RemoveUnusedStyles();

// Save the file
workbook.Save(dataDir + "output_out.xlsx");
```

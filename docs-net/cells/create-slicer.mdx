## Possible Usage Scenarios {#possible-usage-scenarios}

A slicer is used to filter data quickly. It can be used to filter data both in a table **and** a pivot table. Microsoft Excel allows you to create a slicer by selecting a table or pivot table and then clicking *Insert &gt; Slicer*. Aspose.Cells also allows you to create a slicer using the <a href="https://reference.aspose.com/cells/net/aspose.cells.slicers/slicercollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Slicers.Add()**</a> method.

## Create a Slicer for a Pivot Table {#create-a-slicer-for-a-pivot-table}

Please see the following sample code. It loads the <a href="https://docs.aspose.com/cells/net/create-slicer/67338470.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains the pivot table. It then creates the slicer based on the first base pivot field. Finally, it saves the workbook in <a href="https://docs.aspose.com/cells/net/create-slicer/67338471.xlsx" target="_blank" rel="nofollow noopener noreferrer">output XLSX</a> and <a href="https://docs.aspose.com/cells/net/create-slicer/67338472.xlsb" target="_blank" rel="nofollow noopener noreferrer">output XLSB</a> format. The following screenshot shows the slicer created by Aspose.Cells in the output Excel file.

![todo:image_alt_text](/net/cells/images/db26fa06b4cd57a8-create-slicer-to-a-pivot-table_1.png)

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

// Load sample Excel file containing pivot table.
Workbook wb = new Workbook("sampleCreateSlicerToPivotTable.xlsx");

// Access first worksheet.
Worksheet ws = wb.Worksheets[0];

// Access first pivot table inside the worksheet.
Aspose.Cells.Pivot.PivotTable pt = ws.PivotTables[0];

// Add slicer relating to pivot table with first base field at cell B22.
int idx = ws.Slicers.Add(pt, "B22", pt.BaseFields[0]);

// Access the newly added slicer from slicer collection.
Aspose.Cells.Slicers.Slicer slicer = ws.Slicers[idx];

// Save the workbook in output XLSX format.
wb.Save("outputCreateSlicerToPivotTable.xlsx", SaveFormat.Xlsx);

// Save the workbook in output XLSB format.
wb.Save("outputCreateSlicerToPivotTable.xlsb", SaveFormat.Xlsb);
```

## Create a Slicer for an Excel Table {#create-a-slicer-for-an-excel-table}

Please see the following sample code. It loads the <a href="https://docs.aspose.com/cells/net/create-slicer/sampleCreateSlicerToExcelTable.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains a table. It then creates the slicer based on the first column. Finally, it saves the workbook in <a href="https://docs.aspose.com/cells/net/create-slicer/outputCreateSlicerToExcelTable.xlsx" target="_blank" rel="nofollow noopener noreferrer">output XLSX</a> format.

### Sample Code {#sample-code-1}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
// Load sample Excel file containing a table.
Workbook workbook = new Workbook(sourceDir + "sampleCreateSlicerToExcelTable.xlsx");

// Access first worksheet.
Worksheet worksheet = workbook.Worksheets[0];

// Access first table inside the worksheet.
ListObject table = worksheet.ListObjects[0];

// Add slicer
int idx = worksheet.Slicers.Add(table, 0, "H5");

// Save the workbook in output XLSX format.
workbook.Save(outputDir + "outputCreateSlicerToExcelTable.xlsx", SaveFormat.Xlsx);
```

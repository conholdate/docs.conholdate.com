## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes when you convert your Excel file to PDF, errors or exceptions occur and the conversion process terminates. You can ignore all such errors during the conversion process by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/ignoreerror" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.IgnoreError**</a> property. This way, the conversion process will complete smoothly without throwing any error or exception, but data loss may occur. Therefore, please use this property only if the loss of data is not critical for you.

## Ignore Errors while Rendering Excel to PDF {#ignore-errors-while-rendering-excel-to-pdf}

The following code loads the <a href="https://docs.aspose.com/cells/net/ignore-errors-while-rendering-excel-to-pdf/55541778.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a>; however, the sample Excel file is erroneous and throws an error during <a href="https://docs.aspose.com/cells/net/ignore-errors-while-rendering-excel-to-pdf/55541779.pdf" target="_blank" rel="nofollow noopener noreferrer">conversion to PDF</a> in version 17.11. Since we are using the <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/properties/ignoreerror" target="_blank" rel="nofollow noopener noreferrer">**PdfSaveOptions.IgnoreError**</a> property, the conversion does not throw an error. However, a *rounded red arrow‑like shape* shown in this screenshot is lost.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load the Sample Workbook that throws Error on Excel2Pdf conversion
Workbook wb = new Workbook("sampleErrorExcel2Pdf.xlsx");

//Specify Pdf Save Options - Ignore Error
PdfSaveOptions opts = new PdfSaveOptions();
opts.IgnoreError = true;

//Save the Workbook in Pdf with Pdf Save Options
wb.Save("outputErrorExcel2Pdf.pdf", opts);
```

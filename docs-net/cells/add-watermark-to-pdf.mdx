While converting an Excel file to PDF, you may have requirements to add a watermark to the PDF file. The following examples show how to add text and image watermarks to a PDF while rendering to PDF.

## Add text watermark to PDF {#add-text-watermark-to-pdf}

You can easily add a text watermark to PDF by specifying the text and the corresponding font. Additionally, you can set alignment, offset, rotation, opacity, foreground/background, and scale to the page in <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/renderingwatermark/" target="_blank" rel="nofollow noopener noreferrer">RenderingWatermark</a>.

```csharp
//prepare a workbook with 3 pages.
Workbook wb = new Workbook();
wb.Worksheets[0].Cells["A1"].PutValue("Page1");
int index = wb.Worksheets.Add();
wb.Worksheets[index].Cells["A1"].PutValue("Page2");
index = wb.Worksheets.Add();
wb.Worksheets[index].Cells["A1"].PutValue("Page3");
wb.Worksheets[index].PageSetup.PaperSize = PaperSizeType.PaperA3;

//create a font for watermark, and specify bold, italic, color.
RenderingFont font = new RenderingFont("Calibri", 68);
font.Italic = true;
font.Bold = true;
font.Color = Color.Blue;

//create a watermark from text and the specified font.
RenderingWatermark watermark = new RenderingWatermark("Watermark", font);

//specify horizontal and vertical alignment
watermark.HAlignment = TextAlignmentType.Center;
watermark.VAlignment = TextAlignmentType.Center;

//specify rotation
watermark.Rotation = 30;

//specify opacity
watermark.Opacity = 0.6f;

//specify the scale to page(e.g. 100, 50) in percent.
watermark.ScaleToPagePercent = 50;

//spcify watermark for rendering to pdf.
PdfSaveOptions options = new PdfSaveOptions();
options.Watermark = watermark;

wb.Save("output_text_watermark.pdf", options);
```

## Add image watermark to PDF {#add-image-watermark-to-pdf}

You can add an image watermark to PDF just by specifying the image bytes of an image. Additionally, you can set alignment, offset, rotation, opacity, foreground/background, and scale to the page in <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/renderingwatermark/" target="_blank" rel="nofollow noopener noreferrer">RenderingWatermark</a>.

```csharp
//prepare a workbook with 3 pages.
Workbook wb = new Workbook();
wb.Worksheets[0].Cells["A1"].PutValue("Page1");
int index = wb.Worksheets.Add();
wb.Worksheets[index].Cells["A1"].PutValue("Page2");
index = wb.Worksheets.Add();
wb.Worksheets[index].Cells["A1"].PutValue("Page3");
wb.Worksheets[index].PageSetup.PaperSize = PaperSizeType.PaperA3;

//create a watermark from image(you need to prepare image bytes).
byte[] imageBytes = null;
RenderingWatermark watermark = new RenderingWatermark(imageBytes);

//specify offset to alignment.
watermark.OffsetX = 100;
watermark.OffsetY = 200;

//specify rotation
watermark.Rotation = 30;

//specify watermark to background.
watermark.IsBackground= true;

//specify opacity
watermark.Opacity = 0.6f;

//specify the scale to page(e.g. 100, 50) in percent.
watermark.ScaleToPagePercent = 50;

//spcify watermark for rendering to pdf.
PdfSaveOptions options = new PdfSaveOptions();
options.Watermark = watermark;

wb.Save("oputput_image_watermark.pdf", options);
```

Aspose.Cells provides <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/contenttypepropertycollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**Workbook.ContentTypeProperties.Add**</a> method to add custom ContentTypeProperties to an **Excel** file. You may also make the property optional by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells.properties/contenttypeproperty/properties/isnillable" target="_blank" rel="nofollow noopener noreferrer">**ContentTypeProperty.IsNillable**</a> property to **true**. The following code snippet demonstrates adding optional custom ContentTypeProperties to an **Excel** file. The following image shows both properties that were added by the sample code.

![todo:image_alt_text](/net/cells/images/13a624a61c339480-working-with-contenttypeproperties_1.jpg)

The output file generated by the sample code is attached for reference.

<a href="https://docs.aspose.com/cells/net/working-with-contenttypeproperties/95584314.xlsx" target="_blank" rel="nofollow noopener noreferrer">Output File</a>

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//source directory
string outputDir = "./";

Workbook workbook = new Workbook(FileFormatType.Xlsx);
int index = workbook.ContentTypeProperties.Add("MK31", "Simple Data");
workbook.ContentTypeProperties[index].IsNillable = false;
index = workbook.ContentTypeProperties.Add("MK32", DateTime.Now.ToString("yyyy-MM-dd'T'hh:mm:ss"), "DateTime");
workbook.ContentTypeProperties[index].IsNillable = true;
workbook.Save(outputDir + "WorkingWithContentTypeProperties_out.xlsx");
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Instead of adjusting filters to show dates, you can use a PivotTable Timeline-a dynamic filter option that lets you easily filter by date/time and zoom in on the period you want with a slider control. Microsoft Excel allows you to create a timeline by selecting a pivot table and then clicking *Insert &gt; Timeline*. Aspose.Cells also allows you to create a timeline using the <a href="https://reference.aspose.com/cells/net/aspose.cells.timelines/timelinecollection/methods/index" target="_blank" rel="nofollow noopener noreferrer">**Worksheet.Timelines.Add()**</a> method.

## Create a Timeline for a Pivot Table {#create-a-timeline-for-a-pivot-table}

Please see the following sample code. It loads the <a href="https://docs.aspose.com/cells/net/create-timeline/input.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains the pivot table. It then creates the timeline based on the first base pivot field. Finally, it saves the workbook in <a href="https://docs.aspose.com/cells/net/create-timeline/output.xlsx" target="_blank" rel="nofollow noopener noreferrer">output XLSX</a> format. The following screenshot shows the timeline created by Aspose.Cells in the output Excel file.

![todo:image_alt_text](/net/cells/images/042af26f5f50faf7-create-timeline-to-a-pivot-table_1.png)

### Sample Code {#sample-code}

```csharp
// Load sample Excel file containing pivot table.
Workbook wb = new Workbook("input.xlsx");
// Access second worksheet.
Worksheet sheet = wb.Worksheets[1];

// Access first pivot table inside the worksheet.
PivotTable pivot = sheet.PivotTables[0];

// Add timeline relating to pivot table
int index = sheet.Timelines.Add(pivot, 15, 1, "Ship Date");

// Access the newly added timeline from timeline collection.
Timeline timeline = sheet.Timelines[index];

wb.Save("output.xlsx");
```

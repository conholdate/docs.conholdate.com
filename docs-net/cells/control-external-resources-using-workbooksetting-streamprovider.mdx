## Possible Usage Scenarios {#possible-usage-scenarios}

Sometimes, your Excel file contains external resources, e.g., linked images, etc. Aspose.Cells allows you to control these external resources using <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/streamprovider" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.StreamProvider**</a>, which takes an implementation of the <a href="https://reference.aspose.com/cells/net/aspose.cells/istreamprovider" target="_blank" rel="nofollow noopener noreferrer">**IStreamProvider**</a> interface. Whenever you try to render a worksheet containing external resources, e.g., linked images, the methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/istreamprovider" target="_blank" rel="nofollow noopener noreferrer">**IStreamProvider**</a> interface will be invoked, enabling you to take appropriate actions for those resources.

## Control External Resources using WorkbookSettings.StreamProvider {#control-external-resources-using-workbooksettingsstreamprovider}

The following sample code demonstrates the usage of the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/streamprovider" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.StreamProvider**</a>. It loads the <a href="https://docs.aspose.com/cells/net/control-external-resources-using-workbooksetting-streamprovider/61767863.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> containing a linked image. The code replaces the linked image with the <a href="https://docs.aspose.com/cells/net/control-external-resources-using-workbooksetting-streamprovider/61767862.png" target="_blank" rel="nofollow noopener noreferrer">Aspose Logo</a> and renders the entire sheet into a single image using the <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender" target="_blank" rel="nofollow noopener noreferrer">**SheetRender**</a> class. The screenshot below shows the sample Excel file and its <a href="https://docs.aspose.com/cells/net/control-external-resources-using-workbooksetting-streamprovider/61767865.png" target="_blank" rel="nofollow noopener noreferrer">rendered output image</a> for reference. As you can see, the broken linked image is replaced with the Aspose Logo.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
class ControlExternalResourcesUsingWorkbookSetting_StreamProvider
{
    //Source directory
    static string sourceDir = "./";

    //Output directory
    static string outputDir = "./";

    //Implementation of IStreamProvider
    class SP : IStreamProvider
    {
        public void CloseStream(StreamProviderOptions options)
        {

        }

        public void InitStream(StreamProviderOptions options)
        {
            //string sourceDir = "./";

            //Open the filestream of Aspose Logo and assign it to StreamProviderOptions.Stream property
            FileStream fi = new FileStream(sourceDir + "sampleControlExternalResourcesUsingWorkbookSetting_StreamProvider.png", FileMode.OpenOrCreate, FileAccess.Read);
            options.Stream = fi;
        }
    }
    public static void Run()
    {
        //Load sample Excel file containing the external resource e.g. linked image etc.
        Workbook wb = new Workbook(sourceDir + "sampleControlExternalResourcesUsingWorkbookSetting_StreamProvider.xlsx");

        //Provide your implementation of IStreamProvider
        wb.Settings.ResourceProvider = new SP();

        //Access first worksheet
        Worksheet ws = wb.Worksheets[0];

        //Specify image or print options, we need one page per sheet and png output
        ImageOrPrintOptions opts = new ImageOrPrintOptions();
        opts.OnePagePerSheet = true;
        opts.ImageType = ImageType.Png;

        //Create sheet render by passing required parameters
        SheetRender sr = new SheetRender(ws, opts);

        //Convert your entire worksheet into png image
        sr.ToImage(0, outputDir + "outputControlExternalResourcesUsingWorkbookSetting_StreamProvider.png");

        Console.WriteLine("ControlExternalResourcesUsingWorkbookSetting_StreamProvider executed successfully.");
    }
}
```

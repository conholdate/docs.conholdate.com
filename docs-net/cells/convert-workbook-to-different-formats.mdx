## Convert Excel Workbook to PDF {#convert-excel-workbook-to-pdf}

PDF files are widely used to exchange documents between organizations, government sectors, and individuals. It is a standard document format and software developers are often asked to find a way to convert Microsoft Excel files into PDF documents.

Aspose.Cells supports converting Excel files to PDF and maintains high visual fidelity in the conversion.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
            
// Instantiate the Workbook object
// Open an Excel file
Workbook workbook = new Workbook("Book1.xlsx");

// Save the document in PDF format
workbook.Save("output.pdf");
```

## Converting Excel Workbook to XPS {#converting-excel-workbook-to-xps}

The XPS document format consists of structured XML markup that defines the layout of a document and the visual appearance of each page, along with rendering rules for distributing, archiving, rendering, processing, and printing documents.

The markup language for XPS is a subset of XAML which allows it to incorporate vector graphics elements in documents, using XAML to mark up the Windows Presentation Foundation (WPF) primitives. The elements used are described in terms of paths and other geometrical primitives.

An XPS file is, in fact, a Unicode ZIP archive using the Open Packaging Conventions, containing the files which make up the document. These include an XML markup file for each page, text, embedded fonts, raster images, 2D vector graphics, as well as the digital rights management information. The contents of an XPS file can be examined simply by opening it in an application that supports ZIP files.

From Aspose.Cells 6.0.0, Microsoft Excel to XPS conversion is supported.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Open an Excel file
Aspose.Cells.Workbook workbook = new Aspose.Cells.Workbook(dataDir + "Book1.xls");

// Get the first worksheet
Aspose.Cells.Worksheet sheet = workbook.Worksheets[0];

// Apply different Image and Print options
Aspose.Cells.Rendering.ImageOrPrintOptions options = new Aspose.Cells.Rendering.ImageOrPrintOptions();
            
// Set the Format
options.SaveFormat = SaveFormat.Xps;
            
// Render the sheet with respect to specified printing options
Aspose.Cells.Rendering.SheetRender sr = new Aspose.Cells.Rendering.SheetRender(sheet, options);
            
// Save
sr.ToImage(0, dataDir + "out_printingxps.out.xps");

// Export the whole workbook to XPS
workbook.Save(dataDir + "out_whole_printingxps.out.xps", new XpsSaveOptions());
```

## Converting Excel Workbook to MHTML Files {#converting-excel-workbook-to-mhtml-files}

MHTML combines normal HTML with external resources (that is, content that is usually linked in, like images, animations, audio, and so on) into one file. They are used for emails with the .mht file extension.

Aspose.Cells supports reading and writing MHTML files.

The code example below shows how to save a workbook as an MHTML file.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Specify the file path
string filePath = dataDir + "Book1.xlsx";

// Specify the HTML Saving Options
HtmlSaveOptions sv = new HtmlSaveOptions(SaveFormat.MHtml);

// Instantiate a workbook and open the template XLSX file
Workbook wb = new Workbook(filePath);

// Save the MHT file
wb.Save(filePath + ".out.mht", sv);
```

## Setting the Image Preferences for HTML {#setting-the-image-preferences-for-html}

Starting from 8.0.2, Aspose.Cells has exposed <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/properties/imageoptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOptions**</a> for the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions" target="_blank" rel="nofollow noopener noreferrer">**HtmlSaveOptions**</a> class, allowing developers to specify image preferences when saving spreadsheets to HTML format.

Below are details of some of the image settings that can be applied:

- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/imagetype" target="_blank" rel="nofollow noopener noreferrer">**ImageType**</a>: Specifies the image type. Please note, all shapes, including charts, render as images in the output HTML.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/smoothingmode" target="_blank" rel="nofollow noopener noreferrer">**SmoothingMode**</a>: Specifies the anti-aliasing for lines, curves & edges of filled areas.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/textrenderinghint" target="_blank" rel="nofollow noopener noreferrer">**TextRenderingHint**</a>: Specifies the quality of text rendering.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/quality" target="_blank" rel="nofollow noopener noreferrer">**Quality**</a>: Specifies the quality of the image between 0 to 100, when <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/imagetype" target="_blank" rel="nofollow noopener noreferrer">**ImageType**</a> is specified as JPEG.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/verticalresolution" target="_blank" rel="nofollow noopener noreferrer">**VerticalResolution**</a>: Gets or sets the vertical resolution of the image in dots per inch.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/horizontalresolution" target="_blank" rel="nofollow noopener noreferrer">**HorizontalResolution**</a>: Gets or sets the horizontal resolution of the image in dots per inch.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/tiffcompression" target="_blank" rel="nofollow noopener noreferrer">**TiffCompression**</a>: Gets or sets the compression type for the images when <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/imagetype" target="_blank" rel="nofollow noopener noreferrer">**ImageType**</a> is specified as TIFF.
- <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions/properties/transparent" target="_blank" rel="nofollow noopener noreferrer">**Transparent**</a>: Indicates if the background of an image should be transparent when ImageFormat is specified as PNG.

See the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlsaveoptions/imageoptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlSaveOptions.ImageOptions API reference</a>.

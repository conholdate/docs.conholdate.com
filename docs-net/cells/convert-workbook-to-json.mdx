## Convert Excel Workbook to JSON {#convert-excel-workbook-to-json}

The Aspose.Cells API provides support for converting spreadsheets to JSON format. To export the workbook to JSON, pass <a href="https://reference.aspose.com/cells/net/aspose.cells/saveformat" target="_blank" rel="nofollow noopener noreferrer">**SaveFormat.Json**</a> as the second parameter of the <a href="https://reference.aspose.com/cells/net/aspose.cells.workbook/save/methods/3" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Save**</a> method. You may also use <a href="https://reference.aspose.com/cells/net/aspose.cells/JsonSaveoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonSaveOptions**</a> class to specify additional settings for exporting a worksheet to JSON.

The following code example demonstrates exporting the active worksheet to JSON by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/saveformat" target="_blank" rel="nofollow noopener noreferrer">**SaveFormat.Json**</a> enumeration member. Please see the code that converts the <a href="https://docs.aspose.com/cells/net/convert-workbook-to-json/book1.xlsx" target="_blank" rel="nofollow noopener noreferrer">source file</a> to the <a href="https://docs.aspose.com/cells/net/convert-workbook-to-json/book1.Json" target="_blank" rel="nofollow noopener noreferrer">output JSON file</a> generated by the code for reference.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Load your source workbook
Workbook workbook = new Workbook("Book1.xlsx");

// convert the workbook to json file.
 workbook.Save("book1.json");
```

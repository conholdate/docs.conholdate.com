Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
While working with large Microsoft Excel files with lots of images, you might need to compress images that have been added to reduce the output PDF file size and improve the overall conversion performance. Aspose.Cells supports resampling added images to reduce the output PDF file size and improve the performance somewhat.
:::

Please see the following sample code that describes how to perform the task using the Aspose.Cells API. The example converts a Microsoft Excel file to a PDF file while compressing the images in the file.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
// Initialize a new Workbook
// Open an Excel file
Workbook workbook = new Workbook(dataDir + "input.xlsx");

// Instantiate the PdfSaveOptions
PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
// Set Image Resample properties
pdfSaveOptions.SetImageResample(300, 70);

// Save the PDF file
workbook.Save(dataDir + "OutputFile_out_pdf", pdfSaveOptions);
```

:::info
Using the <a href="https://reference.aspose.com/cells/net/aspose.cells/pdfsaveoptions/methods/setimageresample" target="_blank" rel="nofollow noopener noreferrer">**SetImageResample**</a> option minimizes the size of the output PDF, but it may affect the image quality a bit.
:::

:::info
If your spreadsheet contains formulas, it is best to call <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/calculateformula" target="_blank" rel="nofollow noopener noreferrer">**Workbook.CalculateFormula()**</a> just before rendering the spreadsheet to PDF format. Doing so will ensure that the formula‑dependent values are recalculated, and the correct values are rendered in the PDF.
:::

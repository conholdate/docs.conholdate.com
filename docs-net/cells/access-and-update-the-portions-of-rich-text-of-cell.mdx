:::info
Aspose.Cells allows you to access and update the portions of the rich text of a cell. For this purpose, you can use <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getcharacters/index" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetCharacters()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setcharacters" target="_blank" rel="nofollow noopener noreferrer">**Cell.SetCharacters()**</a> methods. These methods will return and accept an array of <a href="https://reference.aspose.com/cells/net/aspose.cells/fontsetting" target="_blank" rel="nofollow noopener noreferrer">**FontSetting**</a> objects which you can use to access and update various properties of a font, such as the font name, font color, boldness, etc.
:::

## Access and Update the Portions of Rich Text of Cell {#access-and-update-the-portions-of-rich-text-of-cell}

The following code demonstrates the usage of <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getcharacters/index" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetCharacters()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/setcharacters" target="_blank" rel="nofollow noopener noreferrer">**Cell.SetCharacters()**</a> methods using the <a href="https://docs.aspose.com/cells/net/access-and-update-the-portions-of-rich-text-of-cell/5112369.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a> which you can download from the provided link. The source Excel file contains rich text in cell A1. It has three portions, and each portion has a different font. The following code snippet accesses these portions and updates the first portion with a new font name. Finally, it saves the workbook as the <a href="https://docs.aspose.com/cells/net/access-and-update-the-portions-of-rich-text-of-cell/5112366.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a>. When you open it, you will find that the font of the first portion of the text has changed to **"Arial"**.

### C# code to access and update the portions of Rich Text of Cell {#c-code-to-access-and-update-the-portions-of-rich-text-of-cell}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
string inputPath = dataDir + "Sample.xlsx";
string outputPath = dataDir + "Output.out.xlsx";

Workbook workbook = new Workbook(inputPath);

Worksheet worksheet = workbook.Worksheets[0];

Cell cell = worksheet.Cells["A1"];

Console.WriteLine("Before updating the font settings....");

FontSetting[] fnts = cell.GetCharacters();

for (int i = 0; i < fnts.Length; i++)
{
    Console.WriteLine(fnts[i].Font.Name);
}

// Modify the first FontSetting Font Name
fnts[0].Font.Name = "Arial";

// And update it using SetCharacters() method
cell.SetCharacters(fnts);

Console.WriteLine();

Console.WriteLine("After updating the font settings....");

fnts = cell.GetCharacters();

for (int i = 0; i < fnts.Length; i++)
{
    Console.WriteLine(fnts[i].Font.Name);
}

// Save workbook
workbook.Save(outputPath);
```

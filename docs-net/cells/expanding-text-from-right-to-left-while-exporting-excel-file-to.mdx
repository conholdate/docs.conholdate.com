:::info
Aspose.Cells now supports expanding text from right to left while exporting an Excel file to HTML. This feature has been implemented since version 8.9.0.0. Now, if your source Excel file contains any text that expands from right to left, Aspose.Cells will export it to HTML correctly.
:::

## Expanding text from right to left while exporting Excel file to HTML {#expanding-text-from-right-to-left-while-exporting-excel-file-to-html}

The following sample code converts the <a href="https://docs.aspose.com/cells/net/expanding-text-from-right-to-left-while-exporting-excel-file-to/5115502.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> into HTML. This screenshot shows how the sample Excel looks in Microsoft Excel 2013.

![todo:image_alt_text](/net/cells/images/a3dc3bb83903671e-expanding-text-from-right-to-left-while-exporting-excel-file-to-html_1.png)

This screenshot shows the <a href="https://docs.aspose.com/cells/net/expanding-text-from-right-to-left-while-exporting-excel-file-to/5115509" target="_blank" rel="nofollow noopener noreferrer">output HTML generated with an older version</a>.

![todo:image_alt_text](/net/cells/images/67be1725eb5d6159-expanding-text-from-right-to-left-while-exporting-excel-file-to-html_2.png)

This screenshot shows the <a href="https://docs.aspose.com/cells/net/expanding-text-from-right-to-left-while-exporting-excel-file-to/5115508" target="_blank" rel="nofollow noopener noreferrer">output HTML generated with a newer version</a>.

![todo:image_alt_text](/net/cells/images/20d96e1d3945b193-expanding-text-from-right-to-left-while-exporting-excel-file-to-html_3.png)

As you can see in the screenshots, the newer version expands the right‑aligned text to the left correctly, just like Microsoft Excel.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
            
// Load source excel file inside the workbook object
Workbook wb = new Workbook(dataDir + "sample.xlsx");

// Save workbook in html format
wb.Save(dataDir + "ExpandTextFromRightToLeft_out_" + CellsHelper.GetVersion() + ".html", SaveFormat.Html);
```

## Get Text Width of Cell Value {#get-text-width-of-cell-value}

Sometimes developers may need to calculate the width of a cell's value to arrange data in a layout. Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cellshelper/methods/gettextwidth" target="_blank" rel="nofollow noopener noreferrer">**CellsHelper.GetTextWidth**</a> method, which allows developers to obtain the text width of the cell's value. The following sample code illustrates how to use <a href="https://reference.aspose.com/cells/net/aspose.cells/cellshelper/methods/gettextwidth" target="_blank" rel="nofollow noopener noreferrer">**CellsHelper.GetTextWidth**</a> to access the text width of the cell's value.

The source file used in the following code snippet is attached for your reference.

<a href="https://docs.aspose.com/cells/net/get-text-width-of-cell-value/96928090.xlsx" target="_blank" rel="nofollow noopener noreferrer">Source File</a>

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
Workbook workbook = new Workbook(sourceDir + "GetTextWidthSample.xlsx");

Console.WriteLine("Text width: " + CellsHelper.GetTextWidth(workbook.Worksheets[0].Cells["A1"].StringValue, workbook.DefaultStyle.Font, 1));
```

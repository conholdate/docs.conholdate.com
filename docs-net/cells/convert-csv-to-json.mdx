## Convert CSV to JSON {#convert-csv-to-json}

Aspose.Cells supports converting CSV to JSON. For this, the API provides **<a href="https://reference.aspose.com/cells/net/aspose.cells.utility/exportrangetojsonoptions" target="_blank" rel="nofollow noopener noreferrer">ExportRangeToJsonOptions</a>** and **<a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonutility" target="_blank" rel="nofollow noopener noreferrer">JsonUtility</a>** classes. The **ExportRangeToJsonOptions** class provides the options for exporting a range to JSON. The **ExportRangeToJsonOptions** class has the following properties.

- **<a href="https://reference.aspose.com/cells/net/aspose.cells.utility/exportrangetojsonoptions/properties/exportasstring" target="_blank" rel="nofollow noopener noreferrer">ExportAsString</a>**: Exports the string values of the cells to JSON.
- **<a href="https://reference.aspose.com/cells/net/aspose.cells.utility/exportrangetojsonoptions/properties/hasheaderrow" target="_blank" rel="nofollow noopener noreferrer">HasHeaderRow</a>**: Indicates whether the range contains a header row.
- **<a href="https://reference.aspose.com/cells/net/aspose.cells.utility/exportrangetojsonoptions/properties/indent" target="_blank" rel="nofollow noopener noreferrer">Indent</a>**: Indicates the indentation.

The **JsonUtility** class exports the JSON using the export options set with the **ExportRangeToJsonOptions** class.

The following code sample demonstrates the use of **ExportRangeToJsonOptions** and **JsonUtility** classes to load the <a href="https://docs.aspose.com/cells/net/convert-csv-to-json/104398879.csv" target="_blank" rel="nofollow noopener noreferrer">source CSV file</a> and print the JSON output in the console.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

LoadOptions loadOptions = new LoadOptions(LoadFormat.Csv);
// Load CSV file
Workbook workbook = new Workbook(sourceDir + "SampleCsv.csv", loadOptions);
Cell lastCell = workbook.Worksheets[0].Cells.LastCell;

// Set JsonSaveOptions
JsonSaveOptions jsonSaveOptions = new JsonSaveOptions();
Range range = workbook.Worksheets[0].Cells.CreateRange(0, 0, lastCell.Row + 1, lastCell.Column + 1);
string data = JsonUtility.ExportRangeToJson(range, jsonSaveOptions);

// Print JSON
Console.WriteLine(data);
```

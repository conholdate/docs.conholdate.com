## Keep Separators for Blank Rows while exporting spreadsheets to CSV format {#keep-separators-for-blank-rows-while-exporting-spreadsheets-to-csv-format}

Aspose.Cells provides the ability to keep line separators while converting spreadsheets to CSV format. For this, you may use the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/keepseparatorsforblankrow" target="_blank" rel="nofollow noopener noreferrer">**KeepSeparatorsForBlankRow**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions**</a> class. <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/keepseparatorsforblankrow" target="_blank" rel="nofollow noopener noreferrer">**KeepSeparatorsForBlankRow**</a> is a boolean property. To keep the separators for blank lines while converting the Excel file to CSV, set the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/keepseparatorsforblankrow" target="_blank" rel="nofollow noopener noreferrer">**KeepSeparatorsForBlankRow**</a> property to **true**.

The following sample code loads the <a href="https://docs.aspose.com/cells/net/keep-separators-for-blank-rows-while-exporting-spreadsheets-to-csv-format/84378743.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a>. It sets the <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/keepseparatorsforblankrow" target="_blank" rel="nofollow noopener noreferrer">**TxtSaveOptions.KeepSeparatorsForBlankRow**</a> property to **true** and saves it as <a href="https://docs.aspose.com/cells/net/keep-separators-for-blank-rows-while-exporting-spreadsheets-to-csv-format/84378744.csv" target="_blank" rel="nofollow noopener noreferrer">output.csv</a>. The screenshot shows a comparison among the source Excel file, the default output generated when converting the spreadsheet to CSV, and the output generated by setting <a href="https://reference.aspose.com/cells/net/aspose.cells/txtsaveoptions/properties/keepseparatorsforblankrow" target="_blank" rel="nofollow noopener noreferrer">**KeepSeparatorsForBlankRow**</a> to **true**.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
string filePath = dataDir + "Book1.xlsx";

// Create a Workbook object and opening the file from its path
Workbook wb = new Workbook(filePath);

// Instantiate Text File's Save Options
TxtSaveOptions options = new TxtSaveOptions();

// Set KeepSeparatorsForBlankRow to true show separators in blank rows
options.KeepSeparatorsForBlankRow = true;

// Save the file with the options
wb.Save(dataDir + "output.csv", options);
```

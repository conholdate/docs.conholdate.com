## Get Cell Validation in ODS Files {#get-cell-validation-in-ods-files}

With Aspose.Cells, you can get the validation applied to a cell in ODS files. For this, the API provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getvalidation" target="_blank" rel="nofollow noopener noreferrer">**GetValidation**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell" target="_blank" rel="nofollow noopener noreferrer">**Cell**</a> class.

The following code sample demonstrates the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getvalidation" target="_blank" rel="nofollow noopener noreferrer">**GetValidation**</a> method by loading the <a href="https://docs.aspose.com/cells/net/get-cell-validation-in-ods-files/101089354.ods" target="_blank" rel="nofollow noopener noreferrer">source ODS</a> file and reading the validation of cell A9.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Load source Excel file
Workbook workbook = new Workbook(sourceDir + "SampleBook1.ods");

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

Cell cell = worksheet.Cells["A9"];

if (cell.GetValidation() != null)
{
    Console.WriteLine(cell.GetValidation().Type);
}
```

## Convert JSON to CSV {#convert-json-to-csv}

Aspose.Cells supports converting simple as well as nested JSON to CSV. For this, the API provides <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonLayoutOptions**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonutility" target="_blank" rel="nofollow noopener noreferrer">**JsonUtility**</a> classes. The <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonLayoutOptions**</a> class provides options for JSON layout such as <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions/properties/ignorearraytitle" target="_blank" rel="nofollow noopener noreferrer">**IgnoreArrayTitle**</a> (ignores the title if the array is a property of an object) or <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions/properties/arrayastable" target="_blank" rel="nofollow noopener noreferrer">**ArrayAsTable**</a> (processes the array as a table). The <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonutility" target="_blank" rel="nofollow noopener noreferrer">**JsonUtility**</a> class processes the JSON using the layout options set with the <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonLayoutOptions**</a> class.

The following code sample demonstrates the use of <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonlayoutoptions" target="_blank" rel="nofollow noopener noreferrer">**JsonLayoutOptions**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.utility/jsonutility" target="_blank" rel="nofollow noopener noreferrer">**JsonUtility**</a> classes to load the <a href="https://docs.aspose.com/cells/net/convert-json-to-csv/104398869.json" target="_blank" rel="nofollow noopener noreferrer">source JSON file</a> and generate the <a href="https://docs.aspose.com/cells/net/convert-json-to-csv/104398870.csv" target="_blank" rel="nofollow noopener noreferrer">output CSV file</a>.

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

// Read JSON file
string str = File.ReadAllText(sourceDir + "SampleJson.json");

// Create empty workbook
Workbook workbook = new Workbook();

// Get Cells
Cells cells = workbook.Worksheets[0].Cells;

// Set JsonLayoutOptions
JsonLayoutOptions importOptions = new JsonLayoutOptions();
importOptions.ConvertNumericOrDate = true;
importOptions.ArrayAsTable = true;
importOptions.IgnoreTitle = true;
JsonUtility.ImportData(str, cells, 0, 0, importOptions);

// Save Workbook
workbook.Save(outputDir + @"SampleJson_out.csv");
```

## Change Tick Label Direction {#change-tick-label-direction}

Aspose.Cells provides you with the ability to change the chart tick label direction by using the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/ticklabels/properties/directiontype" target="_blank" rel="nofollow noopener noreferrer">**TickLabels.DirectionType**</a> property. The <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/ticklabels/properties/directiontype" target="_blank" rel="nofollow noopener noreferrer">**TickLabels.DirectionType**</a> property accepts the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/charttextdirectiontype" target="_blank" rel="nofollow noopener noreferrer">**ChartTextDirectionType**</a> enumeration value. The <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/charttextdirectiontype" target="_blank" rel="nofollow noopener noreferrer">**ChartTextDirectionType**</a> enumeration provides the following members:

- Horizontal
- Vertical
- Rotate90
- Rotate270
- Stacked

The following code snippet changes the tick label direction from Rotate90 to Horizontal.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

string sourceDir = "./";
string outputDir = "./";
Workbook workbook = new Workbook(sourceDir + "SampleChangeTickLabelDirection.xlsx");

Worksheet worksheet = workbook.Worksheets[0];

// Load the chart from source worksheet
Chart chart = worksheet.Charts[0];

chart.CategoryAxis.TickLabels.DirectionType = ChartTextDirectionType.Horizontal;

// Output the file
workbook.Save(outputDir + "outputChangeChartDataLableDirection.xlsx");
```

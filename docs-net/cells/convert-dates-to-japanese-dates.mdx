:::info
In the Japanese calendar, a new era begins with the reign of a new emperor. On 1 May 2019, a new emperor came into power, which marked the end of the Heisei era and the beginning of the Reiwa era.
:::

Aspose.Cells provides a way to convert Gregorian dates to Japanese dates. During this conversion, the changes in the era are also considered. The following code snippet converts the <a href="https://docs.aspose.com/cells/net/convert-dates-to-japanese-dates/90112015.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel</a> file containing Gregorian dates to the <a href="https://docs.aspose.com/cells/net/convert-dates-to-japanese-dates/90112016.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF</a> with Japanese dates as shown in the image below.

![todo:image_alt_text](/net/cells/images/d0e89a988e0d9cfa-convert-dates-to-japanese-dates_1.jpg)

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

LoadOptions options = new LoadOptions(LoadFormat.Xlsx);
options.CultureInfo = new CultureInfo("ja-JP");

Workbook workbook = new Workbook(sourceDir + "JapaneseDates.xlsx", options);

workbook.Save(outputDir + "JapaneseDates.pdf", SaveFormat.Pdf);
```

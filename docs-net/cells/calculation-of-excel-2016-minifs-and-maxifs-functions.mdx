## Possible Usage Scenarios {#possible-usage-scenarios}

Microsoft Excel 2016 supports MINIFS and MAXIFS functions. These functions are not supported in Excel 2013 or earlier versions. Aspose.Cells also supports the calculation of these functions. The following screenshot illustrates the usage of these functions. Please read the red comments inside the screenshot to understand how these functions work.

## Calculation of Excel 2016 MINIFS and MAXIFS Functions {#calculation-of-excel-2016-minifs-and-maxifs-functions}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/calculation-of-excel-2016-minifs-and-maxifs-functions/5115149.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> and calls the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/calculateformula" target="_blank" rel="nofollow noopener noreferrer">Workbook.CalculateFormula()</a> method to perform the formula calculation via Aspose.Cells, and then saves the results in the <a href="https://docs.aspose.com/cells/net/calculation-of-excel-2016-minifs-and-maxifs-functions/5115154.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// Load your source workbook containing MINIFS and MAXIFS functions
Workbook workbook = new Workbook(sourceDir + "sampleMINIFSAndMAXIFS.xlsx");

// Perform Aspose.Cells formula calculation
workbook.CalculateFormula();

// Save the calculations result in pdf format
PdfSaveOptions options = new PdfSaveOptions();
options.OnePagePerSheet = true;
workbook.Save(outputDir + "outputMINIFSAndMAXIFS.pdf", options);
```

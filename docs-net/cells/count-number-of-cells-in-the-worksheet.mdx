Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


You may count the number of cells in the worksheet by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/count" target="_blank" rel="nofollow noopener noreferrer">**Cells.Count**</a> or <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/properties/countlarge" target="_blank" rel="nofollow noopener noreferrer">**Cells.CountLarge**</a> properties as shown in the code example given below.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Load source Excel file
Workbook workbook = new Workbook(sourceDir + "BookWithSomeData.xlsx");

//Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

//Print number of cell in the Worksheet
Console.WriteLine("Number of Cells: " + worksheet.Cells.Count);

// In the number of cells is greater than 2147483647, use CountLarge
Console.WriteLine("Number of Cells (CountLarge): " + worksheet.Cells.CountLarge);
```

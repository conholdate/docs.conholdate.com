## Export XML Data Linked to XML Map Inside the Workbook {#export-xml-data-linked-to-xml-map-inside-the-workbook}

Please use the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/methods/exportxml/index" target="_blank" rel="nofollow noopener noreferrer">**Workbook.ExportXml()**</a> method to export XML data linked to your XML Maps inside your workbook. The following sample code exports XML data of all XML Maps from the workbook one by one. Please check the <a href="https://docs.aspose.com/cells/net/export-xml-data-linked-to-xml-map-inside-the-workbook/5115497.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> used in this code and the <a href="https://docs.aspose.com/cells/net/export-xml-data-linked-to-xml-map-inside-the-workbook/5472487.xml" target="_blank" rel="nofollow noopener noreferrer">exported XML data of the first XML Map</a>.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Create directory if it is not already present.
bool IsExists = System.IO.Directory.Exists(dataDir);
if (!IsExists)
    System.IO.Directory.CreateDirectory(dataDir);

// Instantiating a Workbook object.
Workbook workbook = new Workbook(dataDir + "sample.xlsx");

// Export all XML data from all XML Maps from the Workbook.
for (int i = 0; i < workbook.Worksheets.XmlMaps.Count; i++)
{
    // Access the XML Map.
    XmlMap map = workbook.Worksheets.XmlMaps[i];

    // Exports its XML Data to file.
    workbook.ExportXml(map.Name, dataDir + map.Name + ".xml");
}
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Microsoft Excel allows you to share the workbook as shown in the following screenshot. When you share the workbook, more than one user can edit the workbook on the network. Aspose.Cells enables you to create a shared workbook with <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/shared" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.Shared**</a> property.

![todo:image_alt_text](/net/cells/images/968223924fd186a9-create-shared-workbook-with-aspose-cells_1.png)

## Create Shared Workbook with Aspose.Cells {#create-shared-workbook-with-asposecells}

The following sample code creates a shared workbook by setting <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/shared" target="_blank" rel="nofollow noopener noreferrer">**Workbook.Settings.Shared**</a> property as **true**. When you open the <a href="https://docs.aspose.com/cells/net/create-shared-workbook-with-aspose-cells/55541786.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> in Microsoft Excel, you will see **Shared** with the output workbook name as shown in this screenshot.

![todo:image_alt_text](/net/cells/images/b8b8a5ed4a2bcae1-create-shared-workbook-with-aspose-cells_2.png)

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//Create Workbook object
Workbook wb = new Workbook();

//Share the Workbook
wb.Settings.Shared = true;

//Save the Shared Workbook
wb.Save("outputSharedWorkbook.xlsx");
```

## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/shadoweffect" target="_blank" rel="nofollow noopener noreferrer">Shape.ShadowEffect</a> property along with the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect" target="_blank" rel="nofollow noopener noreferrer">ShadowEffect</a> class to work with the shadow effect of a shape or chart. The <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect" target="_blank" rel="nofollow noopener noreferrer">ShadowEffect</a> class contains the following properties, which can be set to achieve different results as per application requirements.

- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/angle" target="_blank" rel="nofollow noopener noreferrer">Angle</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/blur" target="_blank" rel="nofollow noopener noreferrer">Blur</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/color" target="_blank" rel="nofollow noopener noreferrer">Color</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/distance" target="_blank" rel="nofollow noopener noreferrer">Distance</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/presettype" target="_blank" rel="nofollow noopener noreferrer">PresetType</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shadoweffect/properties/transparency" target="_blank" rel="nofollow noopener noreferrer">Transparency</a>

## Working with the Shadow Effect of Shape or Chart {#working-with-the-shadow-effect-of-shape-or-chart}

The following sample code loads the source Excel file (<a href="https://docs.aspose.com/cells/net/working-with-the-shadow-effect-of-shape-or-chart/5115425.xlsx" target="_blank" rel="nofollow noopener noreferrer">5115425.xlsx</a>), accesses the first shape in the first worksheet, sets the sub‑properties of the <a href="https://reference.aspose.com/cells/net/aspose.cells.drawing/shape/properties/shadoweffect" target="_blank" rel="nofollow noopener noreferrer">Shape.ShadowEffect</a> property, and then saves the workbook to the output Excel file (<a href="https://docs.aspose.com/cells/net/working-with-the-shadow-effect-of-shape-or-chart/5115411.xlsx" target="_blank" rel="nofollow noopener noreferrer">5115411.xlsx</a>).

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Load your source excel file
Workbook wb = new Workbook(dataDir + "sample.xlsx");

// Access first worksheet
Worksheet ws = wb.Worksheets[0];

// Access first shape
Shape sh = ws.Shapes[0];

// Set the shadow effect of the shape, Set its Angle, Blur, Distance and Transparency properties
ShadowEffect se = sh.ShadowEffect;
se.Angle = 150;
se.Blur = 4;
se.Distance = 45;
se.Transparency = 0.3;

// Save the workbook in xlsx format
wb.Save(dataDir + "output_out.xlsx");
```

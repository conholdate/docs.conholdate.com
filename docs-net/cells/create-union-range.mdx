## Create Union Range {#create-union-range}

Aspose.Cells provides the ability to create a Union Range by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/methods/createunionrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetCollection.CreateUnionRange</a> method. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/methods/createunionrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetCollection.CreateUnionRange</a> method accepts two parameters: the address of the Union Range and the index of the worksheet. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/methods/createunionrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetCollection.CreateUnionRange</a> method returns a <a href="https://reference.aspose.com/cells/net/aspose.cells/unionrange" target="_blank" rel="nofollow noopener noreferrer">UnionRange</a> object.

The following code snippet demonstrates creating a Union Range by using the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection/methods/createunionrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetCollection.CreateUnionRange</a> method. The output file generated by the code is attached for reference.

- <a href="https://docs.aspose.com/cells/net/create-union-range/106364952.xlsx" target="_blank" rel="nofollow noopener noreferrer">Output File</a>

```csharp
// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Create union range
UnionRange unionRange = workbook.Worksheets.CreateUnionRange("sheet1!A1:A10,sheet1!C1:C10", 0);

// Put value "ABCD" in the range
unionRange.Value = "ABCD";

// Save the output workbook.
workbook.Save("CreateUnionRange_out.xlsx");
```

:::info
According to the definition, a page break is a place in a flow of text where one page ends and the next begins. Microsoft Excel lets users add page breaks into any selected cell of a worksheet.

When the page break is added at a cell, the page ends and the rest of the data after the page break is printed on the next page while printing. In simple words, page breaks divide your worksheet into multiple pages according to your specifications. You can also add page breaks to your worksheets at runtime using Aspose.Cells. Aspose.Cells allows developers to add two kinds of page breaks:

- Horizontal page break
- Vertical page break

In the rest of the discussion, we will describe how you can add horizontal or vertical page breaks into your worksheets using Aspose.Cells.
:::

## Page Breaks {#page-breaks}

Aspose.Cells provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class that represents an Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/worksheets" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in the Excel file.

A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a wide range of properties and methods used to manage a worksheet.

To add the page breaks, use the Worksheet class' <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/horizontalpagebreaks" target="_blank" rel="nofollow noopener noreferrer">**HorizontalPageBreaks**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/verticalpagebreaks" target="_blank" rel="nofollow noopener noreferrer">**VerticalPageBreaks**</a> properties.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/horizontalpagebreaks" target="_blank" rel="nofollow noopener noreferrer">**HorizontalPageBreaks**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/verticalpagebreaks" target="_blank" rel="nofollow noopener noreferrer">**VerticalPageBreaks**</a> properties are collections that may contain several page breaks. Each collection contains several methods for managing horizontal and vertical page breaks.

### Adding Page Breaks {#adding-page-breaks}

To add a page break in a worksheet, insert vertical and horizontal page breaks at the specified cell by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/horizontalpagebreakcollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**HorizontalPageBreakCollection.Add()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/verticalpagebreakcollection/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">**VerticalPageBreakCollection.Add()**</a> methods. Each **Add** method takes the name of the cell where the break should be added.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Add a page break at cell Y30
workbook.Worksheets[0].HorizontalPageBreaks.Add("Y30");
workbook.Worksheets[0].VerticalPageBreaks.Add("Y30");

// Save the Excel file.
workbook.Save(dataDir + "AddingPageBreaks_out.xls");
```

:::info
In Page Break Preview or Print Preview modes, you can see how these page breaks work.
:::

### Clearing All Page Breaks {#clearing-all-page-breaks}

To clear all page breaks in a worksheet, call the **Clear()** methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/horizontalpagebreakcollection" target="_blank" rel="nofollow noopener noreferrer">**HorizontalPageBreakCollection**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/verticalpagebreakcollection" target="_blank" rel="nofollow noopener noreferrer">**VerticalPageBreakCollection**</a> collections.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook();

// Clearing all page breaks
workbook.Worksheets[0].HorizontalPageBreaks.Clear();
workbook.Worksheets[0].VerticalPageBreaks.Clear();

// Save the Excel file.
workbook.Save(dataDir + "ClearAllPageBreaks_out.xls");
```

### Removing a Specific Page Break {#removing-a-specific-page-break}

To remove a specific page break, call the <a href="https://reference.aspose.com/cells/net/aspose.cells/horizontalpagebreakcollection/methods/removeat" target="_blank" rel="nofollow noopener noreferrer">**HorizontalPageBreakCollection.RemoveAt()**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/verticalpagebreakcollection/methods/removeat" target="_blank" rel="nofollow noopener noreferrer">**VerticalPageBreakCollection.RemoveAt()**</a> methods. Each **RemoveAt** method takes the index of the page break to be removed.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Instantiating a Workbook object
Workbook workbook = new Workbook(dataDir + "PageBreaks.xls");

// Removing a specific page break
workbook.Worksheets[0].HorizontalPageBreaks.RemoveAt(0);
workbook.Worksheets[0].VerticalPageBreaks.RemoveAt(0);

// Save the Excel file.
workbook.Save(dataDir + "RemoveSpecificPageBreak_out.xls");
```

## Important to Know {#important-to-know}

When you set **FitToPages** properties (that is <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopagestall" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesTall**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/pagesetup/properties/fittopageswide" target="_blank" rel="nofollow noopener noreferrer">**FitToPagesWide**</a>) in page‑setup settings, the page‑break settings are affected, so if you print the worksheet, the page‑break settings are not considered although they are still set.

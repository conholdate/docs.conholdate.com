## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells supports the *DBNum* custom pattern formatting. For example, if your cell value is 123 and you specify its custom formatting as `[DBNum2][$-804]General`, then it will be displayed like **壹佰贰拾叁**. You can specify your custom formatting for the cell using the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/methods/getstyle" target="_blank" rel="nofollow noopener noreferrer">**Cell.GetStyle()**</a> method and the <a href="https://reference.aspose.com/cells/net/aspose.cells/style/properties/custom" target="_blank" rel="nofollow noopener noreferrer">**Style.Custom**</a> property.

## Sample Code {#sample-code}

The following sample code illustrates how to specify *DBNum* custom pattern formatting. Please check its <a href="https://docs.aspose.com/cells/net/specifying-dbnum-custom-pattern-formatting/43352081.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF</a> for more help.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET

//The path to the documents directory.
string dataDir = "./";

//Create a workbook.
Workbook wb = new Workbook();
 
//Access first worksheet.
Worksheet ws = wb.Worksheets[0];
 
//Access cell A1 and put value 123.
Cell cell = ws.Cells["A1"];
cell.PutValue(123);
 
//Access cell style.
Style st = cell.GetStyle();
 
//Specifying DBNum custom pattern formatting.
st.Custom = "[DBNum2][$-804]General";
 
//Set the cell style.
cell.SetStyle(st);
 
//Set the first column width.
ws.Cells.SetColumnWidth(0, 30);
 
//Save the workbook in output pdf format.
wb.Save(dataDir + "outputDBNumCustomFormatting.pdf", SaveFormat.Pdf);
```

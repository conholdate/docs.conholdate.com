:::info
Aspose.Cells can now render custom date format patterns such as **g** and **ge.mm.dd**. Please check the attached <a href="https://docs.aspose.com/cells/net/render-custom-date-format-pattern-g-and-ge-mm-dd/5112361.xlsx" target="_blank" rel="nofollow noopener noreferrer">source Excel file</a> and the <a href="https://docs.aspose.com/cells/net/render-custom-date-format-pattern-g-and-ge-mm-dd/5112360.pdf" target="_blank" rel="nofollow noopener noreferrer">converted PDF</a> generated by Aspose.Cells for your reference.
:::

The following sample code converts the source Excel file, which contains date values with custom format patterns such as **g** and **ge.mm.dd**, into the output PDF.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

Workbook workbook = new Workbook(dataDir + "SourceFile.xlsx");
workbook.Save(dataDir + "CustomDateFormat_out.pdf");
```

:::info
Visual Studio.NET developers can easily drag controls from the **Toolbox** onto a Windows or Web form. Aspose.Cells Grid suite can be downloaded with an MSI installer, or as a set of DLLs package. This article explains what to do to make sure that Aspose.Cells.Grid controls can be used in Visual Studio.NET when it's installed using the DLLs instead of the installer.
:::

## Integrate Aspose.Cells Grid Controls with Visual Studio.NET {#integrate-asposecells-grid-controls-with-visual-studionet}

To integrate Aspose.Cells Grid controls with Visual Studio.NET:

1. Open the Toolbox.
2. Select the General tab (or any other tab you want to add controls to).
3. Right‑click the General tab.
4. In Visual Studio.NET, select **Choose Items** from the menu. The Customize Toolbox dialog will appear (this process is more or less the same for newer VS.NET IDEs, e.g., Visual Studio 2013/2015 or later).
5. Click **Browse** and locate the Aspose.Cells.GridDesktop.dll and Aspose.Cells.GridWeb.dll files.
6. Select the DLLs and then click **Open**. The Customize Toolbox dialog will now contain controls from Aspose.Cells Grid Suite. The newly added controls will be highlighted in the dialog.
7. Click **OK** to add the controls to your Visual Studio.NET Toolbox.

The Aspose.Cells Grid controls will have been added to the Toolbox's **General** tab. Only the GridWeb control is not active. This is because we are working on a Windows Forms application. GridWeb is only available when you are working on Web Forms, whereas GridDesktop can be used with Windows Forms only.

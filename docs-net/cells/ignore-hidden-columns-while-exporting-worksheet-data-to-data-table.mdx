Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
Sometimes, you want to ignore hidden columns while exporting worksheet data to a data table. You can achieve it using Aspose.Cells by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/exporttableoptions/properties/plotvisiblecolumns" target="_blank" rel="nofollow noopener noreferrer">**ExportTableOptions.PlotVisibleColumns**</a> to **true**. By default, its value is **false**, so you need to set it to **true** to ignore the hidden columns.
:::

The following sample code explains the usage of <a href="https://reference.aspose.com/cells/net/aspose.cells/exporttableoptions/properties/plotvisiblecolumns" target="_blank" rel="nofollow noopener noreferrer">**ExportTableOptions.PlotVisibleColumns**</a> property in ignoring the hidden columns while exporting the entire worksheet data to the data table.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string dataDir = "./";
string inputPath = dataDir + "Sample.xlsx";

Workbook workbook = new Workbook(inputPath);

Worksheet worksheet = workbook.Worksheets[0];

ExportTableOptions opts = new ExportTableOptions();
opts.PlotVisibleColumns = true;

int totalRows = worksheet.Cells.MaxRow + 1;
int totalColumns = worksheet.Cells.MaxColumn + 1;

DataTable dt = worksheet.Cells.ExportDataTable(0, 0, totalRows, totalColumns, opts);
```

## Draw Timeline while rendering Excel to PDF {#draw-timeline-while-rendering-excel-to-pdf}

If you have an Excel file that has a timeline applied to it and you want to export the Excel file to PDF with the timeline settings, Aspose.Cells now supports this by default. You simply export the Excel file with the timeline to PDF, and the generated PDF will show the timeline applied.

The following sample code loads the <a href="https://docs.aspose.com/cells/net/draw-timeline-while-rendering-excel-to-pdf/input.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains an existing timeline. It then saves the workbook as the <a href="https://docs.aspose.com/cells/net/draw-timeline-while-rendering-excel-to-pdf/out.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF file</a>. The following screenshot compares the source Excel file and the generated PDF file.

![](/net/cells/images/c45d6770b38c0791-out.png)

## Sample Code {#sample-code}

```csharp
// Load sample Excel file
Workbook wb = new Workbook("input.xlsx");
//Save file to pdf
wb.Save("out.pdf");
```

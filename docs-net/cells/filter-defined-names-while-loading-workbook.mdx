## Possible Usage Scenarios {#possible-usage-scenarios}

Aspose.Cells allows you to filter or remove defined names present inside the workbook. Please use <a href="https://reference.aspose.com/cells/net/aspose.cells/loaddatafilteroptions" target="_blank" rel="nofollow noopener noreferrer">**LoadDataFilterOptions.DefinedNames**</a> to load defined names and use ~~<a href="https://reference.aspose.com/cells/net/aspose.cells/loaddatafilteroptions" target="_blank" rel="nofollow noopener noreferrer">**LoadDataFilterOptions.DefinedNames**</a>~~ to remove them while loading the workbook. Please note that if you remove defined names, formulas inside the workbook may break.

## Filter Defined Names while loading Workbook {#filter-defined-names-while-loading-workbook}

The following sample code loads the <a href="https://docs.aspose.com/cells/net/filter-defined-names-while-loading-workbook/61767860.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> which has a formula in cell **C1** containing the defined names, i.e., `=SUM(MyName1, MyName2)`. Since we are using ~~<a href="https://reference.aspose.com/cells/net/aspose.cells/loaddatafilteroptions" target="_blank" rel="nofollow noopener noreferrer">**LoadDataFilterOptions.DefinedNames**</a>~~ to remove the defined names while loading the workbook, the formula in cell C1 of the <a href="https://docs.aspose.com/cells/net/filter-defined-names-while-loading-workbook/61767861.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> breaks, and you see `#NAME?` instead. Please see the following screenshot that shows the effect of the code on the sample Excel file.

![todo:image_alt_text](/net/cells/images/6372d878f4fd965f-filter-defined-names-while-loading-workbook_1.png)

## Sample Code {#sample-code}

```csharp
string sourceDir = "./";
string outputDir = "./";
//Specify the load options
LoadOptions opts = new LoadOptions();

//We do not want to load defined names
opts.LoadFilter = new LoadFilter(~LoadDataFilterOptions.DefinedNames);

//Load the workbook
Workbook wb = new Workbook(sourceDir + "sampleFilterDefinedNamesWhileLoadingWorkbook.xlsx", opts);

//Save the output Excel file, it will break the formula in C1
wb.Save(outputDir + "outputFilterDefinedNamesWhileLoadingWorkbook.xlsx");

Console.WriteLine("FilterDefinedNamesWhileLoadingWorkbook executed successfully.");
```

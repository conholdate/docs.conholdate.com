## Group Management of Rows and Columns {#group-management-of-rows-and-columns}

Aspose.Cells provides a class, <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**WorksheetCollection**</a> that allows access to each worksheet in the Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides several methods to manage rows or columns in a worksheet; a few of these are discussed below in more detail.

### Grouping Rows and Columns {#grouping-rows-and-columns}

It is possible to group rows or columns by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/grouprows/index" target="_blank" rel="nofollow noopener noreferrer">**GroupRows**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/groupcolumns/index" target="_blank" rel="nofollow noopener noreferrer">**GroupColumns**</a> methods of the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. Both methods take the following parameters:

- First row/column index - the first row or column in the group.
- Last row/column index - the last row or column in the group.
- Is hidden - a Boolean parameter that specifies whether to hide rows/columns after grouping or not.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Grouping first six rows (from 0 to 5) and making them hidden by passing true
worksheet.Cells.GroupRows(0, 5, true);

// Grouping first three columns (from 0 to 2) and making them hidden by passing true
worksheet.Cells.GroupColumns(0, 2, true);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

#### Group Settings {#group-settings}

Microsoft Excel allows you to configure group settings for display:

- Summary rows below detail.
- Summary columns to the right of detail.

Developers can configure these group settings using the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/outline" target="_blank" rel="nofollow noopener noreferrer">**Outline**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class.

### Summary Rows Below Detail {#summary-rows-below-detail}

It is possible to control whether summary rows are displayed below detail by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/outline" target="_blank" rel="nofollow noopener noreferrer">**Outline**</a> class' <a href="https://reference.aspose.com/cells/net/aspose.cells/outline/properties/summaryrowbelow" target="_blank" rel="nofollow noopener noreferrer">**SummaryRowBelow**</a> property to **true** or **false**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
Workbook workbook = new Workbook(dataDir + "sample.xlsx");
Worksheet worksheet = workbook.Worksheets[0];

// Grouping first six rows and first three columns
worksheet.Cells.GroupRows(0, 5, true);
worksheet.Cells.GroupColumns(0, 2, true);

// Setting SummaryRowBelow property to false
worksheet.Outline.SummaryRowBelow = false;

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");
```

### Summary Columns to Right of Detail {#summary-columns-to-right-of-detail}

Developers can also control displaying summary columns to the right of detail by setting the <a href="https://reference.aspose.com/cells/net/aspose.cells/outline/properties/summarycolumnright" target="_blank" rel="nofollow noopener noreferrer">**SummaryColumnRight**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/outline" target="_blank" rel="nofollow noopener noreferrer">**Outline**</a> class to **true** or **false**.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";
Workbook workbook = new Workbook(dataDir + "sample.xlsx");
Worksheet worksheet = workbook.Worksheets[0];

// Grouping first six rows and first three columns
worksheet.Cells.GroupRows(0, 5, true);
worksheet.Cells.GroupColumns(0, 2, true);

worksheet.Outline.SummaryColumnRight = true;

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");
```

## Ungrouping Rows and Columns {#ungrouping-rows-and-columns}

To ungroup any grouped rows or columns, call the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection's <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/ungrouprows/index" target="_blank" rel="nofollow noopener noreferrer">**UngroupRows**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/ungroupcolumns" target="_blank" rel="nofollow noopener noreferrer">**UngroupColumns**</a> methods. Both methods take two parameters:

- First row or column index - the first row/column to be ungrouped.
- Last row or column index - the last row/column to be ungrouped.

<a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/ungrouprows/index" target="_blank" rel="nofollow noopener noreferrer">**UngroupRows**</a> has an overload that takes a Boolean third parameter. Setting it to **true** removes all grouped information; otherwise, only the outer group information is removed.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Ungrouping first six rows (from 0 to 5)
worksheet.Cells.UngroupRows(0, 5);

// Ungrouping first three columns (from 0 to 2)
worksheet.Cells.UngroupColumns(0, 2);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xls");

// Closing the file stream to free all resources
fstream.Close();
```

## Draw Slicer while rendering Excel to PDF {#draw-slicer-while-rendering-excel-to-pdf}

If you have an Excel file that has a slicer applied to it and you want to export the Excel to PDF with the slicer settings, Aspose.Cells now supports this by default. You simply export the Excel file with the slicer to PDF, and the generated PDF will show the slicer applied.

The following sample code loads the <a href="https://docs.aspose.com/cells/net/draw-slicer-while-rendering-excel-to-pdf/94044165.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample Excel file</a> that contains an existing slicer. It then saves the workbook as <a href="https://docs.aspose.com/cells/net/draw-slicer-while-rendering-excel-to-pdf/94044166.pdf" target="_blank" rel="nofollow noopener noreferrer">output PDF file</a>. The following screenshot compares the source Excel file and the generated PDF file.

![todo:image_alt_text](/net/cells/images/ffb2ef7582e1302a-draw-slicer-while-rendering-excel-to-pdf_1.jpg)

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
string sourceDir = "./";
string outputDir = "./";
Workbook workbook = new Workbook(sourceDir + "SampleSlicerChart.xlsx");
workbook.Save(outputDir + "SampleSlicerChart.pdf", SaveFormat.Pdf);
```

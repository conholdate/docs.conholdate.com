:::info
Aspose.Cells for .NET is included in Conholdate.Total for .NET.
:::


:::info
Normally, the layout of DIV tags is ignored while loading HTML into an Excel workbook object. However, if you want the layout of DIV tags not to be ignored, please set the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlloadoptions/properties/supportdivtag" target="_blank" rel="nofollow noopener noreferrer">HTMLLoadOptions.SupportDivTag</a> property to **true**. The default value of this property is **false**.
:::

The following sample code illustrates the usage of the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlloadoptions/properties/supportdivtag" target="_blank" rel="nofollow noopener noreferrer">HTMLLoadOptions.SupportDivTag</a> property. Please download the <a href="https://docs.aspose.com/cells/net/support-the-layout-of-div-tags-while-loading-html-to-excel-workbook/5115218.png" target="_blank" rel="nofollow noopener noreferrer">Aspose Logo</a> used inside the input HTML and the <a href="https://docs.aspose.com/cells/net/support-the-layout-of-div-tags-while-loading-html-to-excel-workbook/5115220.xlsx" target="_blank" rel="nofollow noopener noreferrer">output Excel file</a> generated by the code.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

var export_html = @"
                    <html>
                    <body>
                        <table>
                            <tr>
                                <td>
                                    <div>This is some Text.</div>
                                    <div>
                                        <div>
                                            <span>This is some more Text</span>
                                        </div>
                                        <div>
                                            <span>abc@abc.com</span>
                                        </div>
                                        <div>
                                            <span>1234567890</span>
                                        </div>
                                        <div>
                                            <span>ABC DEF</span>
                                        </div>
                                    </div>
                                    <div>Generated On May 30, 2016 02:33 PM <br />Time Call Received from Jan 01, 2016 to May 30, 2016</div>
                                </td>
                                <td>";
export_html = export_html + " <img src=" + dataDir + "ASpose_logo_100x100.png" + @" />
                                   
                                </td>
                            </tr>
                        </table>
                    </body>
                    </html>";

using (MemoryStream ms = new MemoryStream(System.Text.Encoding.UTF8.GetBytes(export_html)))
{
    // Specify HTML load options, support div tag layouts
    HtmlLoadOptions loadOptions = new HtmlLoadOptions(LoadFormat.Html);
    loadOptions.SupportDivTag = true;

    // Create workbook object from the html using load options
    Workbook wb = new Workbook(ms, loadOptions);

    // Auto fit rows and columns of first worksheet
    Worksheet ws = wb.Worksheets[0];
    ws.AutoFitRows();
    ws.AutoFitColumns();

    // Save the workbook in xlsx format
    wb.Save(dataDir + "DivTagsLayout_out.xlsx", Aspose.Cells.SaveFormat.Xlsx);
}
```

## C# Convert HTML to PDF {#c-convert-html-to-pdf}

The following C# code sample shows how to convert an HTML document to a PDF using Aspose.Cells for .NET.

1. Create an instance of the <a href="https://reference.aspose.com/cells/net/aspose.cells/htmlloadoptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a> class.
2. Initialize a <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/" target="_blank" rel="nofollow noopener noreferrer">Workbook</a> object.
3. Save the output PDF document by calling the `Workbook.Save()` method.

```csharp
HtmlLoadOptions options = new HtmlLoadOptions(LoadFormat.Html);
Workbook book = new Workbook("sample.html", options);
book.Save("out.pdf");
```

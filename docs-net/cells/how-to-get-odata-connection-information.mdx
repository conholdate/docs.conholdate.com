## Get OData Connection Information {#get-odata-connection-information}

There might be cases where developers need to extract OData information from an Excel file. Aspose.Cells provides the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook/properties/datamashup" target="_blank" rel="nofollow noopener noreferrer">**Workbook.DataMashup**</a> property which returns the DataMashup information present in the Excel file. This information is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/datamashup" target="_blank" rel="nofollow noopener noreferrer">**DataMashup**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/datamashup" target="_blank" rel="nofollow noopener noreferrer">**DataMashup**</a> class provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/datamashup/properties/powerqueryformulas" target="_blank" rel="nofollow noopener noreferrer">**PowerQueryFormulas**</a> property that returns the <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/powerqueryformulacollction" target="_blank" rel="nofollow noopener noreferrer">**PowerQueryFormulaCollection**</a> collection. From the <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/powerqueryformulacollction" target="_blank" rel="nofollow noopener noreferrer">**PowerQueryFormulaCollection**</a>, you can get access to <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/powerqueryformula" target="_blank" rel="nofollow noopener noreferrer">**PowerQueryFormula**</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells.querytables/powerqueryformulaitem" target="_blank" rel="nofollow noopener noreferrer">**PowerQueryFormulaItem**</a>.

The following code snippet demonstrates the use of these classes to retrieve the OData information.

The Source file used in the following code snippet is attached for your reference.

<a href="https://docs.aspose.com/cells/net/how-to-get-odata-connection-information/96928098.xlsx" target="_blank" rel="nofollow noopener noreferrer">Source File</a>

### Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// source directory
string SourceDir = "./";

Workbook workbook = new Workbook(SourceDir + "ODataSample.xlsx");
PowerQueryFormulaCollection PQFcoll = workbook.DataMashup.PowerQueryFormulas;
foreach (PowerQueryFormula PQF in PQFcoll)
{
    Console.WriteLine("Connection Name: " + PQF.Name);
    PowerQueryFormulaItemCollection PQFIcoll = PQF.PowerQueryFormulaItems;
    foreach (PowerQueryFormulaItem PQFI in PQFIcoll)
    {
        Console.WriteLine("Name: " + PQFI.Name);
        Console.WriteLine("Value: " + PQFI.Value);
    }
}
```

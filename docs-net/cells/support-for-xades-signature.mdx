## Introduction {#introduction}

Aspose.Cells provides support for signing workbooks with XAdES signatures. For this, the API provides the <a href="https://reference.aspose.com/cells/net/aspose.cells.digitalsignatures/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">**DigitalSignature**</a> class and the <a href="https://reference.aspose.com/cells/net/aspose.cells.digitalsignatures/xadestype" target="_blank" rel="nofollow noopener noreferrer">**XAdESType**</a> enumeration.

## How to Add XAdES Signature for Excel {#how-to-add-xades-signature-for-excel}

The following code snippet demonstrates the use of the <a href="https://reference.aspose.com/cells/net/aspose.cells.digitalsignatures/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">**DigitalSignature**</a> class to sign the source workbook.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

Workbook workbook = new Workbook(sourceDir + "sourceFile.xlsx");
string password = "pfxPassword";
string pfx = "pfxFile";

DigitalSignature signature = new DigitalSignature(File.ReadAllBytes(pfx), password, "testXAdES", DateTime.Now);

signature.XAdESType = XAdESType.XAdES;
DigitalSignatureCollection dsCollection = new DigitalSignatureCollection();
dsCollection.Add(signature);

workbook.SetDigitalSignature(dsCollection);

workbook.Save(outputDir + "XAdESSignatureSupport_out.xlsx");
```

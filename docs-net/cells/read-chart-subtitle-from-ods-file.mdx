## Read Chart Subtitle from ODS File {#read-chart-subtitle-from-ods-file}

Aspose.Cells provides the ability to read chart subtitles from ODS files by using the <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/properties/subtitle" target="_blank" rel="nofollow noopener noreferrer">**Chart.SubTitle**</a> property. The following sample code loads the <a href="https://docs.aspose.com/cells/net/read-chart-subtitle-from-ods-file/89620481.ods" target="_blank" rel="nofollow noopener noreferrer">sample ODS file</a> and reads the chart subtitle using <a href="https://reference.aspose.com/cells/net/aspose.cells.charts/chart/properties/subtitle" target="_blank" rel="nofollow noopener noreferrer">**Chart.SubTitle**</a> property and prints it in the console window. Please see the console output of the code given below for reference.

## Sample Code {#sample-code}

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";
// Load excel file containing charts
Workbook workbook = new Workbook(sourceDir + "SampleChart.ods");

// Access first worksheet
Worksheet worksheet = workbook.Worksheets[0];

// Access first chart inside the worksheet
Chart chart = worksheet.Charts[0];

Console.WriteLine("Chart Subtitle: " + chart.SubTitle.Text);
```

## Console Output {#console-output}

```java
Chart Subtitle: Sample Chart Subtitle
```

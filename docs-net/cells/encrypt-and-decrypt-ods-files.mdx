:::info
OpenOffice.org is a full‑featured office suite which supports password‑protecting and encrypting files. However, an encrypted ODS file can only be opened by OpenOffice after providing the password. Excel cannot open the encrypted ODS file and may raise a warning message. The encryption options are not applicable to ODS files, unlike other file types.\
Aspose.Cells allows encrypting and decrypting ODS files. A decrypted ODS file can be opened both in Excel and OpenOffice.
:::

## Encrypt with OpenOffice Calc {#encrypt-with-openoffice-calc}

1. Select **Save As** and click the **Save With Password** box.
2. Click the **Save** button.
3. Type your desired password into both the **Enter Password to Open** and **Confirm Password** fields in the Set Password window that opens.
4. Click the **OK** button to save the file.

## Encrypt ODS file with Aspose.Cells for .NET {#encrypt-ods-file-with-asposecells-for-net}

For encrypting an ODS file, load the file and set the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/password" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.Password**</a> value to the actual password before saving it. The output encrypted ODS file can be opened in OpenOffice only.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string sourceDir = "./";

//Output directory
string outputDir = "./";

// Open an ODS file
Workbook workbook = new Workbook(sourceDir + "sampleODSFile.ods");

// Password protect the file
workbook.Settings.Password = "1234";

// Save the ODS file
workbook.Save(outputDir + "outputEncryptedODSFile.ods");
```

## Decrypt ODS file with Aspose.Cells for .NET {#decrypt-ods-file-with-asposecells-for-net}

For decrypting an ODS file, load the file by providing a password in the <a href="https://reference.aspose.com/cells/net/aspose.cells/loadoptions/properties/password" target="_blank" rel="nofollow noopener noreferrer">**LoadOptions.Password**</a>. Once the file is loaded, set the <a href="https://reference.aspose.com/cells/net/aspose.cells/workbooksettings/properties/password" target="_blank" rel="nofollow noopener noreferrer">**WorkbookSettings.Password**</a> string to `null`.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string sourceDir = "./";

//Output directory
string outputDir = "./";


// Open an encrypted ODS file
Aspose.Cells.LoadOptions loadOptions = new Aspose.Cells.LoadOptions(Aspose.Cells.LoadFormat.Ods);

// Set original password
loadOptions.Password = "1234";

// Load the encrypted ODS file with the appropriate load options
Workbook workbook = new Workbook(sourceDir + "sampleEncryptedODSFile.ods", loadOptions);

// Set the password to null
workbook.Settings.Password = null;

// Save the decrypted ODS file
workbook.Save(outputDir + "outputDecryptedODSFile.ods");
```

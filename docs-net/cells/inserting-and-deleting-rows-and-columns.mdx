## Introduction {#introduction}

Whether creating a new worksheet from scratch or working on an existing worksheet, we may need to add extra rows or columns to accommodate more data. Inversely, we may also need to delete rows or columns from specified positions in the worksheet.\
To fulfill these requirements, Aspose.Cells provides a very simple set of classes and methods, discussed below.

### Manage Rows and Columns {#manage-rows-and-columns}

Aspose.Cells provides a class <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> that represents a Microsoft Excel file. The <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">**Workbook**</a> class contains a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheetcollection" target="_blank" rel="nofollow noopener noreferrer">**Worksheets**</a> collection that allows access to each worksheet in an Excel file. A worksheet is represented by the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class. The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet" target="_blank" rel="nofollow noopener noreferrer">**Worksheet**</a> class provides a <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection that represents all cells in the worksheet.

The <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection provides several methods for managing rows and columns in a worksheet. Some of these are discussed below.

:::info
When rows or columns are added, the content in the worksheet is shifted down or to the right, and if rows or columns are removed, the content is shifted up or to the left.
:::

## Insert Rows and Columns {#insert-rows-and-columns}

### How to Insert a Row {#how-to-insert-a-row}

Insert a row into the worksheet at any location by calling the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/insertrow" target="_blank" rel="nofollow noopener noreferrer">**InsertRow**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/insertrow" target="_blank" rel="nofollow noopener noreferrer">**InsertRow**</a> method takes the index of the row where the new row will be inserted.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Inserting a row into the worksheet at 3rd position
worksheet.Cells.InsertRow(2);

// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

### How to Insert Multiple Rows {#how-to-insert-multiple-rows}

Compared to inserting one row at a time, the InsertRows method allows you to insert multiple rows at once, which greatly improves row insertion performance. As multiple rows are inserted, elements such as formulas, shapes, data and charts will move accordingly. To insert multiple rows into a worksheet, call the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/insertrows" target="_blank" rel="nofollow noopener noreferrer">**InsertRows**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/insertrows" target="_blank" rel="nofollow noopener noreferrer">**InsertRows**</a> method takes two parameters:

- Row index - the index of the row from where the new rows will be inserted.
- Number of rows - the total number of rows that need to be inserted.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Inserting 10 rows into the worksheet starting from 3rd row
worksheet.Cells.InsertRows(2, 10);


// Saving the modified Excel file
workbook.Save(dataDir + "output.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

### How to Insert a Row with Formatting {#how-to-insert-a-row-with-formatting}

To insert a row with formatting options, use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/insertrows" target="_blank" rel="nofollow noopener noreferrer">**InsertRows**</a> overload that takes <a href="https://reference.aspose.com/cells/net/aspose.cells/insertoptions" target="_blank" rel="nofollow noopener noreferrer">**InsertOptions**</a> as a parameter. Set the <a href="https://reference.aspose.com/cells/net/aspose.cells/insertoptions/properties/copyformattype" target="_blank" rel="nofollow noopener noreferrer">**CopyFormatType**</a> property of the <a href="https://reference.aspose.com/cells/net/aspose.cells/insertoptions" target="_blank" rel="nofollow noopener noreferrer">**InsertOptions**</a> class with the <a href="https://reference.aspose.com/cells/net/aspose.cells/insertoptions/properties/copyformattype" target="_blank" rel="nofollow noopener noreferrer">**CopyFormatType**</a> enumeration. The <a href="https://reference.aspose.com/cells/net/aspose.cells/insertoptions/properties/copyformattype" target="_blank" rel="nofollow noopener noreferrer">**CopyFormatType**</a> enumeration has three members as listed below.

- **SameAsAbove** - Formats the row the same as the row above.
- **SameAsBelow** - Formats the row the same as the row below.
- **Clear** - Clears the formatting.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "book1.xls", FileMode.Open);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Setting Formatting options
InsertOptions insertOptions = new InsertOptions();
insertOptions.CopyFormatType = CopyFormatType.SameAsAbove;

// Inserting a row into the worksheet at 3rd position
worksheet.Cells.InsertRows(2, 1, insertOptions);

// Saving the modified Excel file
workbook.Save(dataDir + "InsertingARowWithFormatting.out.xls");

// Closing the file stream to free all resources
fstream.Close();
```

### How to Insert a Column {#how-to-insert-a-column}

## Delete Rows and Columns {#delete-rows-and-columns}

### How to Delete Multiple Rows {#how-to-delete-multiple-rows}

To delete multiple rows from a worksheet, call the <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/deleterows" target="_blank" rel="nofollow noopener noreferrer">**DeleteRows**</a> method of the <a href="https://reference.aspose.com/cells/net/aspose.cells/worksheet/properties/cells" target="_blank" rel="nofollow noopener noreferrer">**Cells**</a> collection. The <a href="https://reference.aspose.com/cells/net/aspose.cells/cells/methods/deleterows" target="_blank" rel="nofollow noopener noreferrer">**DeleteRows**</a> method takes two parameters:

- Row index - the index of the row from where the rows will be deleted.
- Number of rows - the total number of rows that need to be deleted.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "Book1.xlsx", FileMode.OpenOrCreate);

// Instantiating a Workbook object
// Opening the Excel file through the file stream
Workbook workbook = new Workbook(fstream);

// Accessing the first worksheet in the Excel file
Worksheet worksheet = workbook.Worksheets[0];

// Deleting 10 rows from the worksheet starting from 3rd row
worksheet.Cells.DeleteRows(2, 10);

// Saving the modified Excel file
workbook.Save(dataDir + "output.xlsx");

// Closing the file stream to free all resources
fstream.Close();
```

## Possible Usage Scenarios {#possible-usage-scenarios}

When you only need to manipulate some data on the rows or columns, you need to know the data range of rows and columns. Aspose.Cells offers this feature. To obtain the maximum column index on a row, you can obtain the <a href="https://reference.aspose.com/cells/net/aspose.cells/row/lastcell/" target="_blank" rel="nofollow noopener noreferrer">Row.LastCell</a> and <a href="https://reference.aspose.com/cells/net/aspose.cells/row/lastdatacell/" target="_blank" rel="nofollow noopener noreferrer">Row.LastDataCell</a> properties, and then use the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/column/" target="_blank" rel="nofollow noopener noreferrer">Cell.Column</a> property to obtain the maximum column index and maximum data column index. But in order to obtain the maximum row index and maximum row data index on a column, you need to create a range on the column, then traverse the range to find the last cell, and finally obtain the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/row/" target="_blank" rel="nofollow noopener noreferrer">Cell.Row</a> attribute on the cell.

Aspose.Cells provides the following properties and methods to help you achieve your goals.

- <a href="https://reference.aspose.com/cells/net/aspose.cells/row/lastcell/" target="_blank" rel="nofollow noopener noreferrer">**Row.LastCell**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/row/lastdatacell/" target="_blank" rel="nofollow noopener noreferrer">**Row.LastDataCell**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/column/" target="_blank" rel="nofollow noopener noreferrer">**Cell.Column**</a>
- <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/row/" target="_blank" rel="nofollow noopener noreferrer">**Cell.Row**</a>

## Get Max Column Index in Row and Max Row Index in Column using Aspose.Cells {#get-max-column-index-in-row-and-max-row-index-in-column-using-asposecells}

This example shows how to:

1. Load the <a href="https://docs.aspose.com/cells/net/get-max-index-in-row-and-column/sample.xlsx" target="_blank" rel="nofollow noopener noreferrer">sample file</a>.
2. Get the row for which you need the maximum column index and maximum data column index.
3. Retrieve the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/column/" target="_blank" rel="nofollow noopener noreferrer">Cell.Column</a> attribute on the cell.
4. Create a range based on the column.
5. Obtain an iterator and traverse the range.
6. Retrieve the <a href="https://reference.aspose.com/cells/net/aspose.cells/cell/row/" target="_blank" rel="nofollow noopener noreferrer">Cell.Row</a> attribute on the cell.

```csharp
Workbook workbook = new Workbook(filePath + "sample.xlsx");
Worksheet sheet = workbook.Worksheets[0];
Cells cells = sheet.Cells;

Row row = cells.CheckRow(1);
if (row != null)
{
    //get Maximum column index of Row which contains data or style.
    Console.WriteLine("Max column index in row: " + row.LastCell.Column);

    //get Maximum column index of Row which contains data.
    Console.WriteLine("Max data column index in row: " + row.LastDataCell.Column);
}


// create the range of column B
Range columnRange = cells.CreateRange(1, 1, true);

IEnumerator colIter = columnRange.GetEnumerator();
int maxRow = 0;
int maxDataRow = 0;
while (colIter.MoveNext())
{
    Cell currCell = (Cell)colIter.Current;
    if (!string.IsNullOrEmpty(currCell.StringValue))
    {
        maxDataRow = currCell.Row;
    }
    if (!string.IsNullOrEmpty(currCell.StringValue) || currCell.HasCustomStyle)
    {
        maxRow = currCell.Row;
    }
}
//Maximum row index of Column which contains data or style.
Console.WriteLine("Max row index in Column: " + maxRow);

//Maximum row index of Column which contains data.
Console.WriteLine("Max data row index in Column: " + maxDataRow);
```

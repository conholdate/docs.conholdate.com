**<a href="https://products.groupdocs.com/markdown/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Markdown</a>** provides a quick and easy way to convert documents into clean, structured Markdown. The library offers two approaches: **static methods** for one-line conversions and an **instance API** for more control.

### Static methods (simplest)

Call `MarkdownConverter.ToMarkdown()` to get a Markdown string, or `MarkdownConverter.ToFile()` to write directly to disk:


<Tabs groupId="static-methods">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

string md = MarkdownConverter.ToMarkdown("business-plan.docx");
// # Quarterly Report
//
// ## Executive Summary
//
// This report covers the key initiatives...

MarkdownConverter.ToFile("business-plan.docx", "static-methods.md");
```

</TabItem>


</Tabs>


### Instance API

Create a <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown/markdownconverter/" target="_blank" rel="nofollow noopener noreferrer">MarkdownConverter</a> instance for advanced scenarios such as inspecting metadata before converting or reusing a loaded document:


<Tabs groupId="instance-api">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

using var converter = new MarkdownConverter("business-plan.docx");
converter.Convert("instance-api.md", new ConvertOptions { HeadingLevelOffset = 1 });
```

</TabItem>


</Tabs>


### Conversion options

Use <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown/convertoptions/" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> to customize the output -- select specific pages, control image handling, choose a Markdown flavor, add YAML front matter, and more. For loading customization, use <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown.options.load" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> to specify file format or provide a password.

## Build a project from scratch

You can build a project from scratch using Visual Studio or <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">.NET CLI</a>. We'll step you through both cases.

### Build a project using .NET CLI

1. Make sure you have .NET SDK installed <a href="https://dotnet.microsoft.com/download" target="_blank" rel="nofollow noopener noreferrer">https://dotnet.microsoft.com/download</a>.
2. Create a directory for your console app by executing the `mkdir my-console-app` command in your terminal.
3. Navigate to the `my-console-app` directory by executing the `cd my-console-app` command.
4. Create an empty console app by executing the `dotnet new console` command.
5. Add the GroupDocs.Markdown for .NET package by executing the `dotnet add package GroupDocs.Markdown` command.
6. Edit `Program.cs` and add the following lines to the `Main` method:

	using (var converter = new MarkdownConverter(documentPath))
	{
		converter.Convert(outputPath);
	}
  ```

### Build a project using Visual Studio

1. Open Visual Studio and go to **File** -> **New** -> **Project**.
2. Select the appropriate project type - Console App, ASP.NET Web Application etc.
3. Install **GroupDocs.Markdown for .NET** from Nuget or the official GroupDocs website following this [guide](/net/markdown/getting-started/installation/).
4. Add the following code to the `Main` method:

    using GroupDocs.Markdown;

    string documentPath = "business-plan.docx";

	using (var converter = new MarkdownConverter(documentPath))
	{
		converter.Convert(outputPath);
	}
  ```

## Run back-end examples

You can find many back-end examples in our <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a> repository. You can either download the ZIP file from <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">here</a> or clone the repository from GitHub using your favorite Git client.  
In case you download the ZIP file, extract the folders on your local disk.

1. Navigate to the `Examples` directory and open the `GroupDocs.Markdown.Examples.CSharp.sln` solution using Visual Studio.
2. Open the `RunExamples.cs` file and uncomment the example(s) that you would like to run.
3. Optionally, you can set the path to the license in `Utils.cs` file.

## Run demo projects

To run any demo from <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET/tree/master/Demos/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Markdown for .NET Demo projects</a>, you can either:

* Clone the repository:

  ```bash
  git clone git@github.com:groupdocs-markdown/GroupDocs.Markdown-for-.NET.git  
  ```

* or <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">download</a> the source code.

## Contribute

If you like to add or improve an example, we encourage you to contribute to the project. All examples in this repository are open source and can be freely used in your own applications.  
To contribute, you can fork the repository, edit the code and create a pull request. We will review the changes and include them in the repository if found helpful.

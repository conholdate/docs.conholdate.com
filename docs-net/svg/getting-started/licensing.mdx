You can install and try Aspose.SVG for .NET before applying a license. For applications that must produce unrestricted SVG, PDF, XPS, or image output, apply a license before processing documents.

## Evaluation Version Limitations {#evaluation-version-limitations}

The evaluation version is available from the <a href="https://releases.aspose.com/svg/net/" target="_blank" rel="nofollow noopener noreferrer">Aspose.SVG for .NET downloads page</a>. Without a license, the current product limitations are:

- A watermark is added to output files.
- Only the first four pages of an SVG document can be converted.
- Only 50% of the SVG document nodes are saved during serialization.

:::info
To test Aspose.SVG without evaluation limitations, request a <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">30-day temporary license</a>.
:::

## Choose a Licensing Method {#choose-a-licensing-method}

<div className="docs-owner-markdown-table">

| Scenario | Method |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Store a license alongside application deployment files | Load a license file with `License.SetLicense(string)` |
| Read a license from application storage or configuration infrastructure | Load a stream with `License.SetLicense(Stream)` |
| Ship the license inside an application assembly | Set the license file as an embedded resource and load it by name |
| Use consumption-based licensing | Apply public and private keys with `Metered.SetMeteredKey()` |

</div>

Apply the license once during application startup, before creating, loading, converting, or saving SVG documents.

## Apply a License from a File {#apply-a-license-from-a-file}

The `Aspose.Svg.License` class accepts a full path or a short file name. When a short name is provided, `SetLicense()` searches for the license in the following locations:

1. The explicit path, if one is provided.
2. The folder that contains the Aspose.SVG assembly.
3. The folder that contains the calling assembly.
4. The folder that contains the entry or startup assembly.
5. Embedded resources in the calling assembly.

The following example loads an `Aspose.SVG.lic` file available to the application:

```java
using Aspose.Svg;

// Create an Aspose.SVG license object.
License license = new License();

// Apply a license stored as an application file.
license.SetLicense("Aspose.SVG.lic");
```

If your solution uses more than one Aspose product, instantiate the license class for the product being licensed. For Aspose.SVG, use `Aspose.Svg.License`.

## Apply a License from a Stream {#apply-a-license-from-a-stream}

Use the stream overload when your application obtains the license from a protected file location, embedded configuration, or another storage provider.

```java
using System.IO;
using Aspose.Svg;

// Initialize an Aspose.SVG license object.
License license = new License();

// Open a stream that contains the license data.
using (FileStream stream = new FileStream("Aspose.SVG.lic", FileMode.Open))
{
    // Apply the license from the stream.
    license.SetLicense(stream);
}
```

## Apply a License from an Embedded Resource {#apply-a-license-from-an-embedded-resource}

Embedding a license can be convenient when the application is distributed as a single deployment unit.

1. Add the `.lic` file to your project.
2. In Visual Studio, select the license file and set **Build Action** to **Embedded Resource**.
3. Pass the embedded resource name to `SetLicense()`.

```java
using Aspose.Svg;

// Create an Aspose.SVG license object.
License license = new License();

// Resolve and apply the license from the embedded resource name.
license.SetLicense("Aspose.SVG.lic");
```

The `License` class looks for an embedded resource in the calling assembly when resolving the supplied license name.

## Apply a Metered License {#apply-a-metered-license}

Metered licensing uses public and private keys instead of a `.lic` file. It is intended for usage-based licensing scenarios; see the <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Metered Licensing FAQ</a> for purchasing and billing information.

Use the `Aspose.Svg.Metered` class to set your metered keys during application startup:

```java
using Aspose.Svg;

// Create a metered license object.
Metered metered = new Metered();

// Apply the purchased public and private metered keys.
metered.SetMeteredKey("public-key", "private-key");
```

The metered API also provides methods to check licensing state and consumption:

```java
// Check whether metered licensing is currently active.
bool isLicensed = Metered.IsMeteredLicensed();

// Read the current consumption quantity and credit.
decimal consumedQuantity = Metered.GetConsumptionQuantity();
decimal consumedCredit = Metered.GetConsumptionCredit();
```

A metered application must be able to report consumption data. The <a href="https://reference.aspose.com/svg/net/aspose.svg/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered API reference</a> explains behavior when consumption data cannot be uploaded.

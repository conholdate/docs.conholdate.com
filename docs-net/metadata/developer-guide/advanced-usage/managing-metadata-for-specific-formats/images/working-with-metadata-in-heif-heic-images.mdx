## Working with XMP metadata

GroupDocs.Metadata for .NET allows managing XMP metadata in TIFF images. For more details please refer to the following guide: [Working with XMP metadata](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-xmp-metadata/).

## Working with EXIF metadata

The GroupDocs.Metadata API supports handling EXIF metadata in TIFF images. Please find appropriate code samples in the [Working with EXIF metadata](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-exif-metadata/) section.

## Working with IPTC metadata

GroupDocs.Metadata for .NET is also able to work with IPTC metadata in TIFF images. Please find more information in the [Working with IPTC IIM metadata](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-iptc-iim-metadata/) section.

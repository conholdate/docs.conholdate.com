## Working with XMP metadata

GroupDocs.Metadata for .NET allows managing XMP metadata in HEIF/HEIC images. For more details please refer to the following guide: [Working with XMP metadata](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-xmp-metadata/).

## Working with EXIF metadata

The GroupDocs.Metadata API supports handling EXIF metadata in HEIF/HEIC images. Please find appropriate code samples in the [Working with EXIF metadata](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-exif-metadata/) section.

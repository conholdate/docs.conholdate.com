This example demonstrates how to export metadata properties to an Excel workbook. For more information please refer to the <a href="https://reference.groupdocs.com/metadata/net/groupdocs.metadata.export/exportmanager" target="_blank" rel="nofollow noopener noreferrer">ExportManager</a> class.

**AdvancedUsage.ExportingMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(@"D:\input.doc"))
{
	RootMetadataPackage root = metadata.GetRootPackage();
	if (root != null)
	{
		// Initialize the export manager with the root metadata package to export the whole metadata tree
		ExportManager manager = new ExportManager(root);
		manager.Export(@"D:\export.xls", ExportFormat.Xls);
	}
} 
```

## Remove all recognized metadata properties from a file

Sometimes you may need to just remove all or clean metadata properties without applying any filters. The best way to do this is to use the <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/sanitize" target="_blank" rel="nofollow noopener noreferrer">Sanitize</a> method.

This example demonstrates how to remove all detected metadata packages/properties.

1.  [Load](/net/metadata/developer-guide/basic-usage/clean-metadata/) a file to clean
2.  Call the <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/sanitize" target="_blank" rel="nofollow noopener noreferrer">Sanitize</a> method
3.  Check the actual number of removed packages/properties
4.  [Save](/net/metadata/developer-guide/basic-usage/clean-metadata/) the changes

**BasicUsage.CleanMetadata**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	// Remove detected metadata packages
	var affected = metadata.Sanitize();
	Console.WriteLine("Properties removed: {0}", affected);

	metadata.Save(Constants.OutputPdf);
}
```

As a result, we get a sanitized version of the original file.

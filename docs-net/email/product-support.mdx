## Technical Support {#technical-support}

Aspose provides unlimited free technical support for all its products. The support is available to all users, including ones running an evaluation.

If you need help, <a href="https://forum.conholdate.com/" target="_blank">**visit the Conholdate.Forums**</a>. Post your question in the Aspose.Email for .NET forum and it will be answered within few hours.

When expecting a reply in the forums, please allow for time zone differences.

### Reporting an Issue {#reporting-an-issue}

If you have an issue, follow these simple steps to make sure it is resolved efficiently:

- Make sure you use the latest version of the product before reporting the issue. See the <a href="https://downloads.aspose.com/email/net" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for .NET download page</a> to find out about the latest version.
- Have a look through the <a href="http://www.aspose.com/community/forums/default.aspx" target="_blank" rel="nofollow noopener noreferrer">forums</a>, this documentation Wiki and the <a href="https://apireference.aspose.com/email/net" target="_blank" rel="nofollow noopener noreferrer">API Reference</a> before reporting an issue. Your question may already have an answer.
- When reporting an issue, please include the original document and possibly a fragment of your code that causes the problem. If you need to attach multiple files, zip them into one. It is safe to attach your documents in the forums since only you and Aspose's developers have access to attached files.
- Please try to report one issue per thread. If you have another issue, report it in a separate thread.

:::info
Aspose does not provide technical support over the phone. Phone support is only available for sales and purchase questions.
:::

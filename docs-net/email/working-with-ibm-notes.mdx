## About IBM Notes {#about-ibm-notes}

IBM Notes is a client and IBM Domino is a server of a collaborative client-server software platform. IBM Notes provides collaboration features like email, calendars, to-do lists, contacts management, etc. The database file used by IBM Notes is saved in the Notes Storage Facility (NSF) format.

## Detect a File is in NSF Format {#detect-a-file-is-in-nsf-format}

The code sample below will show you how to recognize the NSF file format:

```cs
var formatType = FileFormatUtil.DetectFileFormat("storage.nsf").FileFormatType; // Returns FileFormatType.Nsf
```

## Read messages from NSF storage file {#read-messages-from-nsf-storage-file}

:::info
Note, the NSF implementation is quite limited. In general, it is possible to face some problems in the following cases:

1. The file was created by Notes version 7 and higher

2. LZ1 compression is used
   :::

Aspose.Email provides the <a href="https://reference.aspose.com/email/net/aspose.email.storage.nsf/notesstoragefacility/" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class to read NSF storage files. The <a href="https://reference.aspose.com/email/net/aspose.email.storage.nsf/notesstoragefacility/" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class provides the <a href="https://reference.aspose.com/email/net/aspose.email.storage.nsf/notesstoragefacility/enumeratemessages/#enumeratemessages" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages</a> method which iterates over the messages in the NSF storage file. The following sample code demonstrates the use of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.nsf/notesstoragefacility/" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class and the <a href="https://reference.aspose.com/email/net/aspose.email.storage.nsf/notesstoragefacility/enumeratemessages/#enumeratemessages" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages</a> method to read messages from the NSF storage file. 

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Email();

using (NotesStorageFacility nsf = new NotesStorageFacility(dataDir + "SampleNSF.nsf"))
{
    foreach (MailMessage eml in nsf.EnumerateMessages())
    {
        Console.WriteLine(eml.Subject);
    }
}
```

:::info
Please note that only message reading is implemented. Reading of folders is not supported yet due to lack of specification.
:::

## Manage Email Attachments {#manage-email-attachments}

An email attachment is a file that is sent along with an email message. The file may be sent as a separate message as well as a part of the message to which it is attached. The <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class is used with the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class. All messages include a body. In addition to the body, you might want to send additional files. These are sent as attachments and are represented as an instance of the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class. You can send any number of attachments but the size of the attachment is limited by the mail server. Gmail, for example, does not support file sizes greater than 10MB.

### Add an Attachment {#add-an-attachment}

To add an attachment to an email, please follow these steps:

1. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
2. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class.
3. Load attachment into the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> instance.
4. Add the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> instance into the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> instance.

The following code snippet shows you how to add an attachment to an email.

```csharp
// Create an instance of MailMessage class
var eml = new MailMessage
{
    From = "sender@from.com",
    To = "receiver@to.com",
    Subject = "This is message",
    Body = "This is body"
};

// Load an attachment
var attachment = new Attachment("1.txt");

// Add Multiple Attachment in instance of MailMessage class and Save message to disk
eml.Attachments.Add(attachment);

eml.AddAttachment(new Attachment("1.jpg"));
eml.AddAttachment(new Attachment("1.doc"));
eml.AddAttachment(new Attachment("1.rar"));
eml.AddAttachment(new Attachment("1.pdf"));
eml.Save("AddAttachments.eml");
```

Above, we described how to add attachments to your email message with Aspose.Email. What follows shows how to remove attachments, and display information about them on the screen.

### Add a Reference Attachment {#add-a-reference-attachment}

A reference attachment is a type of attachment that includes a link or a reference to a file or item, rather than including the file or item itself in the email message. When the recipients of the email click on the reference attachment, they will be able to access the linked file if they have the appropriate permissions to do so. By using a reference attachment, you can send a smaller email message and ensure that everyone has access to the most up-to-date version of the file or item.

The code snippet below shows how to add a reference attachment to an email. The code performs the following steps:

1. Loads the email message file using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/load/#load_2" target="_blank" rel="nofollow noopener noreferrer">MailMessage.Load()</a> method.
2. Creates a new ReferenceAttachment object called refAttach, passing the attachment URL "https\://\[attach_uri]" as a parameter to its constructor.
3. Sets the name of the attachment to "Document.docx" using the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/name/" target="_blank" rel="nofollow noopener noreferrer">Name</a> property of the refAttach object.
4. Sets the provider type of the attachment to <a href="https://reference.aspose.com/email/net/aspose.email/attachmentprovidertype/" target="_blank" rel="nofollow noopener noreferrer">AttachmentProviderType.OneDrivePro</a> using the <a href="https://reference.aspose.com/email/net/aspose.email/referenceattachment/providertype/" target="_blank" rel="nofollow noopener noreferrer">ProviderType</a> property of the refAttach object.
5. Sets the permission type of the attachment to <a href="https://reference.aspose.com/email/net/aspose.email/attachmentpermissiontype/" target="_blank" rel="nofollow noopener noreferrer">AttachmentPermissionType.AnyoneCanEdit</a> using the <a href="https://reference.aspose.com/email/net/aspose.email/referenceattachment/permissiontype/" target="_blank" rel="nofollow noopener noreferrer">PermissionType</a> property of the refAttach object.
6. Adds the refAttach object to the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/attachments/" target="_blank" rel="nofollow noopener noreferrer">Attachments</a> collection of the eml object using the <a href="https://reference.aspose.com/email/net/aspose.email/attachmentcollection/" target="_blank" rel="nofollow noopener noreferrer">Add()</a> method.

```cs
var eml = MailMessage.Load("fileName");

var refAttach = new ReferenceAttachment("https://[attach_uri]")
{
    Name = "Document.docx",
    ProviderType = AttachmentProviderType.OneDrivePro,
    PermissionType = AttachmentPermissionType.AnyoneCanEdit
};

eml.Attachments.Add(refAttach);
```

### Read the URI of a Reference Attachment {#read-the-uri-of-a-reference-attachment}

A reference attachment stores a link instead of the file itself. When reading a message you can tell such an attachment apart with the <a href="https://reference.aspose.com/email/net/aspose.email/attachment/isuri/" target="_blank" rel="nofollow noopener noreferrer">IsUri</a> property and then cast it to <a href="https://reference.aspose.com/email/net/aspose.email/referenceattachment/" target="_blank" rel="nofollow noopener noreferrer">ReferenceAttachment</a> to get the link from its <a href="https://reference.aspose.com/email/net/aspose.email/referenceattachment/uri/" target="_blank" rel="nofollow noopener noreferrer">Uri</a> property.

```cs
var eml = MailMessage.Load("message.eml");

foreach (Attachment attachment in eml.Attachments)
{
    if (attachment.IsUri && attachment is ReferenceAttachment reference)
    {
        Console.WriteLine(reference.Name + " -> " + reference.Uri);
    }
}
```

### Remove Attachment {#remove-attachment}

To remove an attachment, follow the steps given below:

- Create an instance of <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class.
- Load attachment in the instance of <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class.
- Add the attachment to the instance of <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
- Remove the attachments from the instance of <a href="https://reference.aspose.com/email/net/aspose.email/attachment/" target="_blank" rel="nofollow noopener noreferrer">Attachment</a> class using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class instance.

The following code snippet shows you how to remove an attachment.

```csharp
// Create an instance of MailMessage class
var eml = new MailMessage {From = "sender@sender.com", To = "receiver@gmail.com"};

// Load an attachment
var attachment = new Attachment("1.txt");
eml.Attachments.Add(attachment);

// Remove attachment from your MailMessage
eml.Attachments.Remove(attachment);
```

#### Retrieve Attachments from Signed Emails {#retrieve-attachments-from-signed-emails}

Signed emails contain a single **smime.p7m** attachment. It means that the email is encrypted by SMIME. **Smime.p7m** file format is the digital signature. To see the contents of this email use the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/removesignature/" target="_blank" rel="nofollow noopener noreferrer">RemoveSignature</a> method. The method returns a <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> object without a digital signature.

```csharp
var signedEml = MailMessage.Load("signed.eml");
        
if (signedEml.IsSigned)
{
    for (var i = 0; i < signedEml.Attachments.Count; i++)
    {
        Console.WriteLine($@"Signed email attachment{i}: {signedEml.Attachments[i].Name}");
    }
    
    // The email is signed. Remove a signature.
    var eml = signedEml.RemoveSignature();
    
    Console.WriteLine(@"Signature removed.");

    for (var i = 0; i < eml.Attachments.Count; i++)
    {
        Console.WriteLine($@"Email attachment{i}: {eml.Attachments[i].Name}");
    }
}
```

## Content-Type and Content-Disposition Parameters {#content-type-and-content-disposition-parameters}

Every attachment carries two MIME headers that describe it: `Content-Type` says what the data is, and `Content-Disposition` says how a client should present it. Aspose.Email exposes them as the <a href="https://reference.aspose.com/email/net/aspose.email/attachmentbase/contenttype/" target="_blank" rel="nofollow noopener noreferrer">ContentType</a> and <a href="https://reference.aspose.com/email/net/aspose.email/attachment/contentdisposition/" target="_blank" rel="nofollow noopener noreferrer">ContentDisposition</a> objects, each with a `Parameters` dictionary that holds the additional `name="value"` pairs of the header - including custom ones.

- <a href="https://reference.aspose.com/email/net/aspose.email.mime/contenttype/" target="_blank" rel="nofollow noopener noreferrer">ContentType</a> - `MediaType`, `Name`, `CharSet`, `Boundary` and `Parameters`.
- <a href="https://reference.aspose.com/email/net/aspose.email.mime/contentdisposition/" target="_blank" rel="nofollow noopener noreferrer">ContentDisposition</a> - `DispositionType`, `FileName`, `Inline`, `Size`, the creation/modification/read dates and `Parameters`.

```cs
var attachment = new Attachment("report.txt");

// Content-Type
attachment.ContentType.MediaType = "application/pdf";
attachment.ContentType.Name = "report.pdf";
attachment.ContentType.Parameters["x-internal-id"] = "42";

// Content-Disposition
attachment.ContentDisposition.FileName = "report.pdf";
attachment.ContentDisposition.Size = 1024;
attachment.ContentDisposition.Parameters["x-department"] = "finance";

Console.WriteLine(attachment.ContentType);
Console.WriteLine(attachment.ContentDisposition);
```

The code above produces the following two headers:

```text
application/pdf; name="report.pdf"; x-internal-id="42"
attachment; filename="report.pdf"; size="1024"; x-department="finance"
```

## Extract Linked Images in HTML Emails {#extract-linked-images-in-html-emails}

Extract linked image resources externally from the HTML body and embed them in HTML output with Aspose.Email for .NET. Set `HtmlSaveOptions.ExtractHTMLBodyResourcesAsAttachments` to True, and linked images and other resources in the HTML body will be extracted and embedded. This helps to preserve the original appearance of messages with linked content. The following code sample demonstrates how to load an email message, extract its external HTML resources as attachments, optionally handle resource rendering events, and then save the message as an HTML file using Aspose.Email for .NET.

```cs
// Load the email message
var mailMessage = MailMessage.Load("input.eml");

// Set options to extract external HTML resources
var options = new HtmlSaveOptions();
options.ExtractHTMLBodyResourcesAsAttachments = true;

// Optional: Handle resource rendering events
options.ResourceHtmlRendering += (sender, e) =>
{
    Console.WriteLine(e.PathToResourceFile + " " + ((Attachment)sender).ContentId);
};

// Save the HTML representation of the email
mailMessage.Save("output.html", options);
```

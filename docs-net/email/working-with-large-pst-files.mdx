:::


Performance may be degraded when processing large PST files. The following solutions will help you improve the performance of your app when processing large storage files.

:::info
Consider methods returning `IEnumerable` when traversing folders or messages in a pst.
:::

```csharp
using var pst = PersonalStorage.FromFile(@"storage.pst");

foreach (var folder in pst.RootFolder.EnumerateFolders())
foreach (var messageInfo in folder.EnumerateMessages())
{
    // Do something with message
}
```

:::info
Prefer <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/messageinfo/" target="_blank" rel="nofollow noopener noreferrer">MessageInfo</a> for accessing basic message properties.
:::

```csharp
foreach (var messageInfo in folder.EnumerateMessages())
{
    Console.WriteLine($"Subject: {messageInfo.Subject}");
    Console.WriteLine($"To: {messageInfo.DisplayTo}");
    Console.WriteLine($"Importance: {messageInfo.Importance}");
    Console.WriteLine($"Message Class: {messageInfo.MessageClass}");
}
```

:::info
Avoid using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/extractmessage/" target="_blank" rel="nofollow noopener noreferrer">ExtractMessage</a> or <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/enumeratemapimessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMapiMessages</a> methods for all messages unless you need to have access to all properties.
:::

:::info
Consider using <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/enumeratemessagesentryid/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessagesEntryId</a> to easily retrieve all message IDs contained in a folder.
:::

```csharp
foreach (var id in folder.EnumerateMessagesEntryId())
{
  // Use id to retrieve a property (ExtractProperty),
    // extract a MapiMessage (ExtractMessage),
    // extract message attachments (ExtractAttachments),
    // save msg to a stream(SaveMessageToStream).
}
```

:::info
Consider using <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/extractproperty/" target="_blank" rel="nofollow noopener noreferrer">ExtractProperty</a> to read a single property that is missing in MessageInfo.
:::

```csharp
foreach (var msgId in folder.EnumerateMessagesEntryId())
{
   var transportMessageHeaders =
       pst.ExtractProperty(Convert.FromBase64String(msgId), KnownPropertyList.TransportMessageHeaders.Tag)
           .GetString();
}
```

:::info
Consider using <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/extractattachments/" target="_blank" rel="nofollow noopener noreferrer">ExtractAttachments</a> if only the attachments are required.
:::

```csharp
foreach (var msgId in folder.EnumerateMessagesEntryId())
{
   var attachments = pst.ExtractAttachments(msgId);
}
```

:::info
Use [Search by Criteria](/net/email/managing-messages-in-pst-files/#search-by-criteria)-based filtering to get the messages you require.
:::

```csharp
using var pst = PersonalStorage.FromFile(@"storage.pst");

var builder = new PersonalStorageQueryBuilder();
// Unread messages
builder.HasNoFlags(MapiMessageFlags.MSGFLAG_READ);

foreach (var folder in pst.RootFolder.EnumerateFolders())
{
    var unread = folder.GetContents(builder.GetQuery());
}
```

:::info
Consider using <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/savemessagetostream/" target="_blank" rel="nofollow noopener noreferrer">SaveMessageToStream</a> if it is necessary to save messages from pst.
:::

Instead of using:

```csharp
foreach (var id in folder.EnumerateMessagesEntryId())
{
    var msg = pst.ExtractMessage(id);
    msg.Save(@"message.msg");
}
```

Use:

```csharp
foreach (var id in folder.EnumerateMessagesEntryId())
{
    pst.SaveMessageToStream(id, File.OpenWrite(@"message.msg"));
}
```

:::info
Prefer bulk methods to [add](/net/email/create-and-manage-pst-files/#add-bulk-messages-with-improved-performance) or [delete](/net/email/managing-messages-in-pst-files/#bulk-deletion) multiple items.
:::

## Display Email Information {#display-email-information}

The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> represents an email message and allows developers to access email message properties. The header information (discussed in [Extracting Email Headers](/net/email/extract-email-message-content/#extract-email-headers)) can be extracted and manipulated in different ways. This article explains how to display selected email header information and the email body on screen. To Display Email Information on Screen, follow these steps:

- Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
- Load an email message into the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> instance.
- Display the email content on the screen.

The following code snippet shows you how to display email information on the screen.

```csharp

// Create MailMessage instance by loading an Eml file
var message = MailMessage.Load("test.eml", new EmlLoadOptions());

// Gets the sender info, recipient info, Subject, htmlbody and textbody
Console.Write("From:");
Console.WriteLine(message.From);
Console.Write("To:");
Console.WriteLine(message.To);
Console.Write("Subject:");
Console.WriteLine(message.Subject);
Console.WriteLine("HtmlBody:");
Console.WriteLine(message.HtmlBody);
Console.WriteLine("TextBody");
Console.WriteLine(message.Body);
```

## Extract Email Headers {#extract-email-headers}

The email header represents an Internet and RFC defined standard set of header fields included in Internet email messages. An email header can be specified using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class. Common header types are defined in the <a href="https://reference.aspose.com/email/net/aspose.email/headertype/" target="_blank" rel="nofollow noopener noreferrer">HeaderType</a> class. It is a sealed class working like normal enumeration. To extract headers from an email, follow these steps:

1. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
2. Load an email message in the instance of <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
3. After an email message has been loaded, we will get its raw content.

The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class itself contains properties such as From, To, Cc, Subject and so on. These properties can be extracted from headers.

The headers of a loaded message are available through the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/headers/" target="_blank" rel="nofollow noopener noreferrer">Headers</a> property, which returns a <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/" target="_blank" rel="nofollow noopener noreferrer">HeaderCollection</a>. Its <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/allkeys/" target="_blank" rel="nofollow noopener noreferrer">AllKeys</a> property returns the names of all the headers present in the message, and the indexer returns the value of a header by its name.

The following code snippet shows you how to extract email headers.

```csharp
MailMessage mailMessage = MailMessage.Load(dataDir + "emlWithHeaders.eml");

// Enumerate all the header names and print the corresponding values
foreach (string headerName in mailMessage.Headers.AllKeys)
{
    Console.WriteLine(headerName + ": " + mailMessage.Headers[headerName]);
}
```

### Get Decoded Header Values {#get-decoded-header-values}

The following code snippet shows you how to get decoded header values.

```csharp
MailMessage mailMessage = MailMessage.Load(dataDir + "emlWithHeaders.eml");
string decodedValue = mailMessage.Headers.GetDecodedValue("Thread-Topic");
Console.WriteLine(decodedValue);
```

## Extract Email Body {#extract-email-body}

### Get Plain Text Body {#get-plain-text-body}

The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/body/" target="_blank" rel="nofollow noopener noreferrer">Body</a> property returns a plain text representation of a message body.

```csharp
string plainTextBody = mailMessage.Body;
```

Note: If the text/plain MIME part is present in a message, the property returns its text data. Otherwise, it returns the separated text content from the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/htmlbody/" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a> property without html markup.

### Get HTML Body as Plain Text {#get-html-body-as-plain-text}

The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class provides the feature to extract the HTML body of the message as plain text. The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class provides a <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/gethtmlbodytext/#gethtmlbodytext" target="_blank" rel="nofollow noopener noreferrer">GetHtmlBodyText</a> method that returns the HTML body in plain text. This method parses the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/htmlbody/" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a> property and returns separated plain text content ignoring the html markup. The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/gethtmlbodytext/#gethtmlbodytext" target="_blank" rel="nofollow noopener noreferrer">GetHtmlBodyText</a> method accepts a boolean parameter that indicates whether the body should contain URLs or not. Passing the parameter as true indicates that the HTML body should contain URLs.

The following code snippet demonstrates the use of <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/gethtmlbodytext/#gethtmlbodytext" target="_blank" rel="nofollow noopener noreferrer">GetHtmlBodyText</a> method to extract the HTML body of the email as plain text.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Email();

MailMessage mail = MailMessage.Load(dataDir + "HtmlWithUrlSample.eml");

string body_with_url = mail.GetHtmlBodyText(true);// body will contain URL
string body_without_url = mail.GetHtmlBodyText(false);// body will not contain URL

Console.WriteLine("Body with URL: " + body_with_url);
Console.WriteLine("Body without URL: " + body_without_url);
```

## Get the Message Date and Time {#get-the-message-date-and-time}

The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/date/" target="_blank" rel="nofollow noopener noreferrer">Date</a> property returns the value of the message `Date` header. <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/timezoneoffset/" target="_blank" rel="nofollow noopener noreferrer">TimeZoneOffset</a> returns the offset that was written with it, so the original local time of the sender can be reconstructed. The raw header is still available through the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/headers/" target="_blank" rel="nofollow noopener noreferrer">Headers</a> collection when the unparsed text is needed.

```cs
var eml = MailMessage.Load("message.eml");

Console.WriteLine("Date (as stored): " + eml.Date);
Console.WriteLine("Date (UTC):       " + eml.Date.ToUniversalTime());
Console.WriteLine("Time zone offset: " + eml.TimeZoneOffset);
Console.WriteLine("Raw Date header:  " + eml.Headers["Date"]);
```

## Read and Modify the Linked Resource Disposition Header {#read-and-modify-the-linked-resource-disposition-header}

Every linked resource carries a `Content-Disposition` header that tells the mail client whether the part is shown inline or offered as a download. Read it through the <a href="https://reference.aspose.com/email/net/aspose.email/linkedresource/contentdisposition/" target="_blank" rel="nofollow noopener noreferrer">ContentDisposition</a> property of <a href="https://reference.aspose.com/email/net/aspose.email/linkedresource/" target="_blank" rel="nofollow noopener noreferrer">LinkedResource</a> and change its fields in place.

Linked resources belong to the alternate view that references them, so iterate <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/alternateviews/" target="_blank" rel="nofollow noopener noreferrer">AlternateViews</a> rather than the message-level collection.

```cs
var eml = MailMessage.Load("inline-image.eml");

foreach (AlternateView view in eml.AlternateViews)
{
    foreach (LinkedResource resource in view.LinkedResources)
    {
        ContentDisposition disposition = resource.ContentDisposition;

        Console.WriteLine("Disposition: " + disposition.DispositionType);
        Console.WriteLine("Inline: " + disposition.Inline);
        Console.WriteLine("File name: " + disposition.FileName);

        // Modify the header
        disposition.FileName = "company-logo.png";
        disposition.Inline = true;
    }
}
```

## Access X.500 Exchange Address {#access-x500-exchange-address}

The <a href="https://reference.aspose.com/email/net/aspose.email/mailaddress/#mailaddress-class" target="_blank" rel="nofollow noopener noreferrer">MailAddress</a> class has the `X500Address` property which is built to expose Exchange X.500 formatted addresses if present in a message. It provides read-only access to the X.500 (Exchange) address string for <a href="https://reference.aspose.com/email/net/aspose.email/mailaddress/#mailaddress-class" target="_blank" rel="nofollow noopener noreferrer">MailAddress</a> instances and returns the X.500 address if it is included in message metadata, otherwise returns null or empty. No parsing required - the property returns the raw X.500 string.

```cs
var mailMessage = MailMessage.Load(fileName);
string exaddr = mailMessage.From.X500Address;
```

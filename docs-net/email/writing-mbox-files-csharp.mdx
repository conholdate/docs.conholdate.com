## Write MBOX Files {#write-mbox-files}

If you need to create or update MBOX files programmatically, use Aspose.Email <a href="https://reference.aspose.com/email/net/aspose.email.storage.mbox/mboxrdstoragewriter/" target="_blank" rel="nofollow noopener noreferrer">MboxrdStorageWriter</a> class which allows you to write new messages to Thunderbird mail storage file.

The following code snippet shows you how to write messages to Thunderbird mail storage:

1. Open the Thunderbird storage file in *FileStream*.
2. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.mbox/mboxrdstoragewriter/" target="_blank" rel="nofollow noopener noreferrer">MboxrdStorageWriter</a> class and pass the above stream to the constructor.
3. Prepare a new message using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class.
4. Call the <a href="https://reference.aspose.com/email/net/aspose.email.storage.mbox/mboxrdstoragewriter/writemessage/#writemessage/" target="_blank" rel="nofollow noopener noreferrer">WriteMessage()</a> method and pass the above <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> instance to add the message to Thunderbird storage.
5. Close all streams.

```cs
// Open the storage file with FileStream
var stream = new FileStream(dataDir + "ExampleMbox.mbox", FileMode.Open, FileAccess.Write);

// Initialize MboxrdStorageWriter and pass the above stream to it
var writer = new MboxrdStorageWriter(stream, new MboxSaveOptions());
// Prepare a new message using the MailMessage class
var message = new MailMessage("from@domain.com", "to@domain.com", Guid.NewGuid().ToString(), "added from Aspose.Email");
message.IsDraft = false;
// Add this message to storage
writer.WriteMessage(message);
// Close all related streams
writer.Dispose();
stream.Close();
```

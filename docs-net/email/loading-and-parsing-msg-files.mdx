Using Aspose.Email for .NET, developers can load as well as parse contents from Outlook message files.

- To load MSG files from disk, use the static <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/load/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage.Load</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class. The class provides several static loading functions for different scenarios.
- To parse MSG file contents, the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> exposes a number of methods and properties.

In this article you will learn how to load and parse an MSG file to display its contents. The code samples with steps will give you a clear understanding of how to implement the functionality of loading and parsing Outlook MSG files in your project.

First, learn to load MSG files from file or from stream.

## Load MSG Files {#load-msg-files}

The following code snippet shows you how to load MSG files.

```cs
// Create an instance of MapiMessage from file
var msg = MapiMessage.Load(@"message.msg");

// Get subject
Console.WriteLine("Subject:" + msg.Subject);

// Get from address
Console.WriteLine("From:" + msg.SenderEmailAddress);

// Get body
Console.WriteLine("Body:" + msg.Body);

// Get recipients information
foreach (var recipient in msg.Recipients)
{
    Console.WriteLine("Recipient: " + recipient.DisplayName + " <" + recipient.EmailAddress + ">");
}

// Get attachments
foreach (var att in msg.Attachments)
{
    Console.Write("Attachment Name: " + att.FileName);
    Console.Write("Attachment Display Name: " + att.DisplayName);
}
```

The following code example shows how to use MailMessage to load a message in MSG format.

```csharp

var eml = MailMessage.Load("message.msg");
```

It should be noted that a resulting message is converted to EML format, including embedded message attachments. Don't use this loading method if you want to preserve some specific msg format properties of the original message.

To preserve the original format of embedded message attachments, use the <a href="https://reference.aspose.com/email/net/aspose.email/loadoptions/preserveembeddedmessageformat/" target="_blank" rel="nofollow noopener noreferrer">MsgLoadOptions.PreserveEmbeddedMessageFormat</a> property.

```csharp

var msgLoadOptions = new MsgLoadOptions();
msgLoadOptions.PreserveEmbeddedMessageFormat = true;
var msg = MailMessage.Load("message.msg", msgLoadOptions);
```

## Load from Stream {#load-from-stream}

The following code snippet shows you how to load file from stream.

```cs
// Create an instance of MapiMessage from file
byte[] bytes = File.ReadAllBytes(@"message.msg");

using (MemoryStream stream = new MemoryStream(bytes))
{
    stream.Seek(0, SeekOrigin.Begin);
    // Create an instance of MapiMessage from file
    MapiMessage msg = MapiMessage.Load(stream);

    // Get subject
    Console.WriteLine("Subject:" + msg.Subject);

    // Get from address
    Console.WriteLine("From:" + msg.SenderEmailAddress);

    // Get body
    Console.WriteLine("Body:" + msg.Body);

}
```

## Convert EML to MSG While Preserving Embedded EML Format {#convert-eml-to-msg-while-preserving-embedded-eml-format}

EML files can be loaded into <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class by instantiating a <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> object and passing it to <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/frommailmessage/#frommailmessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage.FromMailMessage</a> method. If the EML file contains embedded EML files, use <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapiconversionoptions/preserveembeddedmessageformat/" target="_blank" rel="nofollow noopener noreferrer">MapiConversionOptions.PreserveEmbeddedMessageFormat</a> to retain the format of embedded EML files. The below code snippet shows how to load EML files into <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> while preserving the format of embedded EML files.

```cs
// Load the EML file into a MailMessage object
var mailMessage = MailMessage.Load(emlFilePath);

// Set conversion options to preserve the format of embedded EML messages
var options = new MapiConversionOptions
    {
        PreserveEmbeddedMessageFormat = true
    };

// Convert MailMessage to MapiMessage, preserving embedded EML files
var mapiMessage = MapiMessage.FromMailMessage(mailMessage, options);

// Save the converted message in MSG format
mapiMessage.Save(msgFilePath);
```

## Parse Outlook Message Files {#parse-outlook-message-files}

Aspose.Email for .NET provides the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class that is used to open and parse an MSG file. As there may be many recipients in an MSG file, the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class exposes the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessageitembase/recipients/" target="_blank" rel="nofollow noopener noreferrer">Recipients</a> property that returns a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipientcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipientCollection</a> which represents a collection of <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> objects. The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> object further exposes methods for working with recipient attributes.

The following sequence of steps serves this purpose:

1. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/load/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage.Load</a> static method.
2. Display the sender name, subject, and body from the MSG file using <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/sendername/" target="_blank" rel="nofollow noopener noreferrer">SenderName</a>, <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessageitembase/subject/" target="_blank" rel="nofollow noopener noreferrer">Subject</a> and <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/body/" target="_blank" rel="nofollow noopener noreferrer">Body</a> properties.
3. Use the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessageitembase/recipients/" target="_blank" rel="nofollow noopener noreferrer">Recipients</a> property to get a reference to the collection of <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> objects associated with the MSG file.
4. Loop through the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipientcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipientCollection</a> collection to display contents for each <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> object through its public methods.

```cs
//Instantiate an MSG file to load an MSG file from disk
var outlookMessageFile = MapiMessage.Load(dataDir + "message.msg");
//Display sender's name
Console.WriteLine("Sender Name : " + outlookMessageFile.SenderName);
//Display Subject
Console.WriteLine("Subject : " + outlookMessageFile.Subject);
//Display Body
Console.WriteLine("Body : " + outlookMessageFile.Body);
//Display Recipient's info
Console.WriteLine("Recipients : \n");

//Loop through the recipients collection associated with the MapiMessage object
foreach (var rcp in outlookMessageFile.Recipients)
{
	//Display recipient email address
	Console.WriteLine("Email : " + rcp.EmailAddress);
	//Display recipient name
	Console.WriteLine("Name : " + rcp.DisplayName);
	//Display recipient type
	Console.WriteLine("Recipient Type : " + rcp.RecipientType);
}
```

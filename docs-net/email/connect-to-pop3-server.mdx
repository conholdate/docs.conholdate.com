## Connect to POP3 Server {#connect-to-pop3-server}

The <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> class allows applications to manage email boxes using the Post Office Protocol, Version 3 (POP3). This class is the major entry for developers who want to add POP3 management to their .NET applications.

To connect to a POP3 server:

1. Create an instance of the <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> class.
2. Specify the host, username, and password in the <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> instance.

The following code snippet shows you how to connect with the POP3 server.

```csharp
// Create an instance of the Pop3Client class
Pop3Client client = new Pop3Client();

// Specify host, username, password, Port and SecurityOptions for your client
client.Host = "pop.gmail.com";
client.Username = "your.username@gmail.com";
client.Password = "your.password";
client.Port = 995;
client.SecurityOptions = SecurityOptions.Auto;
Console.WriteLine(Environment.NewLine + "Connected to POP3 server.");
```

### Connect to SSL server {#connect-to-ssl-server}

The process for connecting to an SSL enabled POP3 server is similar but requires that you set another few properties:

- <a href="https://reference.aspose.com/email/net/aspose.email.clients/securityoptions/" target="_blank" rel="nofollow noopener noreferrer">SecurityOptions</a>
- Port

To connect to an SSL enabled POP3 server, set the <a href="https://reference.aspose.com/email/net/aspose.email.clients/securityoptions/" target="_blank" rel="nofollow noopener noreferrer">SecurityOptions</a> and Port properties. The following code snippet shows you how to connect to an SSL enables POP3 server.

```csharp
// Create an instance of the Pop3Client class
Pop3Client client = new Pop3Client();
// Specify host, username and password, Port and  SecurityOptions for your client
client.Host = "pop.gmail.com";
client.Username = "your.username@gmail.com";
client.Password = "your.password";
client.Port = 995;
client.SecurityOptions = SecurityOptions.Auto; 
Console.WriteLine(Environment.NewLine + "Connecting to POP3 server using SSL.");
```

### Connect to APOP Server {#connect-to-apop-server}

POP stands for Post Office Protocol. APOP stands for Authenticated Post Office Protocol. APOP is an extended version of the POP3 server setting that encrypts your username and password and uses an authentication mechanism designed to protect your POP3 account password when checking email. APOP authentication does not require the account password to be sent as plain text to the POP3 mail server.

### Connect to Server via Proxy {#connect-to-server-via-proxy}

Proxy addresses are used for email clients to access mailboxes over the Internet. Aspose.Email provides support for versions 4, 4a and 5 of the SOCKS proxy protocol.

To retrieve email via a proxy server:

1. Initialize <a href="https://reference.aspose.com/email/net/aspose.email.clients/proxy/" target="_blank" rel="nofollow noopener noreferrer">Proxy</a> with the required information, that is, proxy address, port, and SOCKS version.
2. Initialize <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> with the host address, user name, password, and any other settings.
3. Set the Proxy property of a client to the <a href="https://reference.aspose.com/email/net/aspose.email.clients/proxy/" target="_blank" rel="nofollow noopener noreferrer">Proxy</a> object created above.

The following code snippet shows you how to retrieve email via proxy server.

```csharp

Pop3Client client = new Pop3Client("pop.domain.com", "username", "password");
// Set proxy address, Port and Proxy
string proxyAddress = "192.168.203.142"; 
int proxyPort = 1080; 
SocksProxy proxy = new SocksProxy(proxyAddress, proxyPort, Aspose.Email.Protocols.Proxy.SocksVersion.SocksV5);
client.SocksProxy = proxy;
Pop3MailboxInfo mailboxInfo = client.GetMailboxInfo();
```

### Connect to Server via HTTP Proxy {#connect-to-server-via-http-proxy}

```csharp
HttpProxy proxy = new HttpProxy("18.222.124.59", 8080);
using (Pop3Client client = new Pop3Client("imap.domain.com", "username", "password"))
{
    client.Proxy = proxy;
    Pop3MailboxInfo mailboxInfo = client.GetMailboxInfo();
}
```

### Connect with CRAM-MD5 Authentication {#connect-with-cram-md5-authentication}

Using CRAM-MD5 authentication, Aspose.Email for .NET allows users to securely authenticate and access email servers supporting this authentication method. The code sample below shows how to use the mechanism in your project:

```cs
popClient.AllowedAuthentication = Pop3KnownAuthenticationType.CramMD5;
```

### Connect with OAuth 2.0 {#connect-with-oauth-20}

Microsoft 365 and Google no longer accept a password on POP3; they require an OAuth 2.0 access token. <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> has two constructors for this.

Pass the token directly when the application already holds one - the `useOAuth` argument tells the client to authenticate with XOAUTH2 instead of a password:

```cs
using var client = new Pop3Client(
    "outlook.office365.com", 995, "user@domain.com", accessToken, true, SecurityOptions.Auto);

Console.WriteLine(client.GetMessageCount());
```

Pass an <a href="https://reference.aspose.com/email/net/aspose.email.clients/itokenprovider/" target="_blank" rel="nofollow noopener noreferrer">ITokenProvider</a> instead when the token has to be refreshed automatically - the client requests a fresh token from the provider whenever the current one expires:

```cs
using var client = new Pop3Client(
    "outlook.office365.com", 995, "user@domain.com", tokenProvider, SecurityOptions.Auto);

Console.WriteLine(client.GetMessageCount());
```

For obtaining the token itself and implementing a provider, see [Accessing Mail Services using OAuth](/net/email/accessing-mail-services-using-oauth/).

## List Server Extensions {#list-server-extensions}

<a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> lets you retrieve the server extensions that a server supports such as IDLE, UNSELECT, QUOTA, etc. This helps in identifying the availability of an extension before using the client for that particular functionality. The <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/getcapabilities/#getcapabilities" target="_blank" rel="nofollow noopener noreferrer">GetCapabilities()</a> method returns the supported extension types in the form of a string array.

### Retrieve Server Extensions {#retrieve-server-extensions}

The following code sample demonstrates retrieving server extensions using POP3Client for Gmail server.

```csharp
// Connect and log in to POP3
Pop3Client client = new Pop3Client("pop.gmail.com", "username", "password");
client.SecurityOptions = SecurityOptions.Auto;
client.Port = 993;
string[] getCaps = client.GetCapabilities();
foreach (string item in getCaps)
{
    Console.WriteLine(item);
}
```

## Set Timeout for Mail Operations {#set-timeout-for-mail-operations}

Each mail operation takes some time depending on many factors (network delays, data size, server performance, etc.). You can set a timeout for all mail operations. The code example below shows you how to do that using the <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/timeout/" target="_blank" rel="nofollow noopener noreferrer">Timeout</a> property. Note: you should not set large values to avoid long waits in your application.

```csharp
using (Pop3Client pop3Client = new Pop3Client("host", 995, "username", "password", SecurityOptions.Auto))
{
    pop3Client.Timeout = 60000; // 60 seconds

    // some code...
}
```

## Use Cryptographic Protocols with POP3 Client {#use-cryptographic-protocols-with-pop3-client}

Aspose.Email supports SSL (obsolete) and TLS cryptographic protocols to provide communications security. You can enable cryptographic encryption to protect data exchange between your application and mail servers.

> **_NOTE:_** You should set only those versions of the protocol, which are supported by .NET Framework. If some versions of the cryptographic protocol are not supported by your current version of .NET Framework, they will be ignored and skipped. In this case, exceptions won't be generated. Please use <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/setsupportedencryptionunsafe/#setsupportedencryptionunsafe" target="_blank" rel="nofollow noopener noreferrer">SetSupportedEncryptionUnsafe</a> method if you want to set the protocols without any compatibility checks.

The code example below shows you how to set TLS 1.3 for <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> class instance.

```csharp
using (Pop3Client pop3Client = new Pop3Client("host", 995, "username", "password", SecurityOptions.Auto))
{
    pop3Client.SupportedEncryption = EncryptionProtocols.Tls13;

    // some code...
}
```

In case of a specified encryption protocol is not supported in the current version of .NET Framework, the difference in behavior between <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/setsupportedencryptionunsafe/#setsupportedencryptionunsafe" target="_blank" rel="nofollow noopener noreferrer">SetSupportedEncryptionUnsafe</a> method and <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/supportedencryption/" target="_blank" rel="nofollow noopener noreferrer">SupportedEncryption</a> property is the following:

- If <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/supportedencryption/" target="_blank" rel="nofollow noopener noreferrer">SupportedEncryption</a> property is used, the email client downgrades the encryption protocol to a supported level.

- If <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/setsupportedencryptionunsafe/#setsupportedencryptionunsafe" target="_blank" rel="nofollow noopener noreferrer">SetSupportedEncryptionUnsafe</a> method is used, the email client throws exceptions.

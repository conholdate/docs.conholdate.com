This article covers storing and reading Outlook `MapiContact` items inside a PST file. To work with standalone `MapiContact` items and vCard (VCF) files, see [Outlook Contacts Management](/net/email/outlook-contacts-management/).

## Adding and Saving Contacts {#adding-and-saving-contacts}

### Add Contacts to PST {#add-contacts-to-pst}

The section [Creating and Managing PST Files](/net/email/create-and-manage-pst-files/) shows how to create a PST file and add a subfolder to it. With Aspose.Email you can add a MapiContact to the Contacts subfolder of a PST file that you have created or loaded. Below are the steps to add MapiContact to a PST:

1. Create a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> object.
2. Set the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact properties</a> using different constructors and methods.
3. Create a PST using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/create/#create/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.Create()</a> method.
4. Create a pre-defined folder (Contacts) at the root of the PST file by accessing the root folder and then calling the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/addmapimessageitem/#addmapimessageitem" target="_blank" rel="nofollow noopener noreferrer">AddMapiMessageItem()</a> method.

### Save Contacts in MSG Format {#save-contacts-in-msg-format}

This article explains how to access contact information from an Outlook PST file and save the contact to a disk in MSG format. The steps to get the contact information are:

1. Load the PST file in the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> object.
2. Browse the Contacts folder.
3. Get the contents of the Contacts folder via Loop through the messages.
4. Verify that the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/messageinfo/messageclass/" target="_blank" rel="nofollow noopener noreferrer">MessageInfo.MessageClass</a> property value matches the "IPM.Contact".
5. Call the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/extractmessage/#extractmessage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.ExtractMessage()</a> method to get the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object.
6. Call the MapiMessage.Save() method to save the contact to the disk in MSG format.

The following code snippet shows you how to retrieve all the contact information from the PST file and save to disk in MSG format.

```csharp
// Load the Outlook PST file
var pst = PersonalStorage.FromFile("SampleContacts.pst");

// Get the Contacts folder
var contactsFolder = pst.RootFolder.GetSubFolder("Contacts");

// Loop through all the contacts in this folder
foreach (MessageInfo messageInfo in contactsFolder.EnumerateMessages())
{
    if (messageInfo.MessageClass == "IPM.Contact")
    {
        // Get the contact information
        var msg = pst.ExtractMessage(messageInfo);
        
        // Save to disk in msg format
        string contactName = msg.Subject.Replace(":", " ").Replace("\\", " ").Replace("?", " ").Replace("/", " ");
        msg.Save($"{contactName}.msg", SaveOptions.DefaultMsgUnicode);
    }
}
```

### Save Contacts in VCF Format {#save-contacts-in-vcf-format}

This article shows how to access contact information from a Microsoft Outlook PST file and save the contact to disk in vCard (VCF) format. Use the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> and <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> classes to get contact information from the PST file. To get the contact information:

1. Load the PST file in the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class.
2. Browse the Contacts folder.
3. Get the contents of the Contacts folder via Loop through the messages.
4. Verify that the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/messageinfo/messageclass/" target="_blank" rel="nofollow noopener noreferrer">MessageInfo.MessageClass</a> property value matches the "IPM.Contact".
5. Call the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/extractmessage/#extractmessage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.ExtractMessage()</a> method to get the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object.
6. Call the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/tomapimessageitem/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage.ToMapiMessageItem()</a> and cast the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/imapimessageitem/" target="_blank" rel="nofollow noopener noreferrer">IMapiMessageItem</a> to <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> type.
7. Call the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">MapiContact.Save()</a> method to save the contact to disk in VCard format.

The following code snippet shows you how to export contacts from Outlook PST to vCard (VCF) format.

```csharp
// Load the Outlook PST file
var pst = PersonalStorage.FromFile("SampleContacts.pst");

// Get the Contacts folder
var contactsFolder = pst.RootFolder.GetSubFolder("Contacts");

// Loop through all the contacts in this folder
foreach (MessageInfo messageInfo in contactsFolder.EnumerateMessages())
{
    if (messageInfo.MessageClass == "IPM.Contact")
    {
        // Get the contact information
        var msg = pst.ExtractMessage(messageInfo);
        var contact = (MapiContact)msg.ToMapiMessageItem();

        // Display some contents on screen
        Console.WriteLine("Name: " + contact.NameInfo.DisplayName);

        // Save to disk in VCard format
        string contactName = contact.Subject.Replace(":", " ").Replace("\\", " ").Replace("?", " ").Replace("/", " ");
        contact.Save($"{contactName}.vcf", ContactSaveFormat.VCard);
    }
}
```

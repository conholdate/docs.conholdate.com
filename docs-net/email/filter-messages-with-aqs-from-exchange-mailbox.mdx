<a href="https://docs.microsoft.com/en-us/exchange/client-developer/exchange-web-services/how-to-perform-an-aqs-search-by-using-ews-in-exchange" target="_blank" rel="nofollow noopener noreferrer">Advanced Query Syntax (AQS)</a> is the query syntax used by Exchange as an alternative to searching filters for expressing search criteria. AQS is a more flexible way to perform searches and deliver search results for all commonly used fields on the items. AQS is also user-friendly, easy to understand and quickly to master. Using AQS is suitable for finding messages by attachments and recipients.

## Creating AQS Search Queries {#creating-aqs-search-queries}

You can create a search query with AQS by:

- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxQueryBuilder</a>, which represents the builder of search expression based on the Advanced Query Syntax (AQS). or
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxMailQuery</a>, which creates an AQS string directly based on the supported keywords.

### Using Query Builder {#using-query-builder}

To create a search query with <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxQueryBuilder</a> you need to:

- create an instance of <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient</a> using <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/ewsclient/getewsclient/" target="_blank" rel="nofollow noopener noreferrer">GetEWSClient</a> method

- create an instance of <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxQueryBuilder</a> and set necessary properties to build a query.

- call <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/listmessages/" target="_blank" rel="nofollow noopener noreferrer">ListMessages</a> or <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/listitems/" target="_blank" rel="nofollow noopener noreferrer">ListItems</a> method and pass <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> instance, returned by <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/getquery/" target="_blank" rel="nofollow noopener noreferrer">GetQuery</a> method, as one of its parameters.

The code sample below shows how the above steps can be accomplished:

```csharp
using (var client = EWSClient.GetEWSClient(...))
{
    var advancedBuilder = new ExchangeAdvancedSyntaxQueryBuilder();
    advancedBuilder.From.Equals("Jim Martin");
    advancedBuilder.Subject.Contains("report");
    advancedBuilder.HasAttachment.Equals(true);

    var messages = client.ListMessages(client.MailboxInfo.InboxUri, advancedBuilder.GetQuery());
}
```

### Direct AQS Queries {#direct-aqs-queries}

To create a search query with <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxMailQuery</a> you need to :

- create an instance of <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient</a> using <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/ewsclient/getewsclient/" target="_blank" rel="nofollow noopener noreferrer">GetEWSClient</a> method

- create an instance of <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxmailquery/#constructors" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxMailQuery</a> and pass an AQS string. See the <a href="https://docs.microsoft.com/en-us/exchange/client-developer/exchange-web-services/how-to-perform-an-aqs-search-by-using-ews-in-exchange" target="_blank" rel="nofollow noopener noreferrer">syntax description</a>.

- call <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/listmessages/" target="_blank" rel="nofollow noopener noreferrer">ListMessages</a> or <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/listitems/" target="_blank" rel="nofollow noopener noreferrer">ListItems</a> method and pass <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange/exchangeadvancedsyntaxquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">ExchangeAdvancedSyntaxMailQuery</a> instance as one of its parameters.

The code sample below shows how the above steps can be accomplished:

```csharp
using (var client = EWSClient.GetEWSClient(...))
{
    ExchangeAdvancedSyntaxMailQuery query = new ExchangeAdvancedSyntaxMailQuery("subject:(product AND report)");
    ExchangeMessageInfoCollection messages = client.ListMessages(client.MailboxInfo.InboxUri, query);
}
```

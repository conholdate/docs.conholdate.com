OLM is a file format used by Microsoft Outlook for Mac to store local data such as emails, attachments, notes, calendar data, contacts, tasks, and history. Unlike the PST format used by Outlook for Windows, OLM files are only compatible with Outlook for Mac and cannot be opened by Outlook for Windows directly.

Aspose.Email for .NET provides the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Storage.Olm</a> namespace, which lets you open, read, traverse, and convert OLM files without Microsoft Outlook installed. The main types you will use are:

- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> - represents an Outlook for Mac (.olm) storage file and provides access to the data it contains.
- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/" target="_blank" rel="nofollow noopener noreferrer">OlmFolder</a> - represents a folder inside the storage and exposes its messages and sub-folders.
- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> - provides short, read-only information about a message in the storage.
- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmitemcategory/" target="_blank" rel="nofollow noopener noreferrer">OlmItemCategory</a> - represents an Outlook item category with its name and color.

This section covers the following topics:

- [Opening OLM Files](/net/email/opening-olm-files/) - open an OLM file from a path or stream and load corrupted files with a traversal callback.
- [Navigating OLM Folders](/net/email/navigating-olm-folders/) - enumerate the folder hierarchy, retrieve folders by name, and read folder paths.
- [Reading and Extracting OLM Messages](/net/email/reading-and-extracting-olm-messages/) - list, filter, page through, and extract messages from folders.
- [Counting Items and Working with Categories](/net/email/counting-items-and-categories-in-olm/) - count items and read Outlook category colors.
- [Converting OLM to PST](/net/email/converting-olm-to-pst/) - migrate an OLM file to the Windows Outlook PST format.

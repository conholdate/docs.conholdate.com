## Using Aspose.Email.Verifications {#using-asposeemailverifications}

Aspose.Email.Verifications provides full support for validating email addresses. With the help of the Aspose.Email.Verifications.EmailValidator class, different types of validation can be performed, including email syntax checking, email domain checking and checking user accounts with mail servers. The ValidationPolicy enumeration is used to set the validation policy level:

- SyntaxOnly validates the email address syntax.
- SyntaxAndDomain validates the email address syntax, then the domain.
- MailServer validates the address by trying to connect to the mail server.

## Basic Validation Functionality {#basic-validation-functionality}

Use Aspose.Email.Verifications to verify the validity of email addresses. For this purpose, Aspose.Email.Verifications has the EmailValidator class.

### Validating Emails {#validating-emails}

Aspose.Email's validation functionality can be used to validate email addresses, domain names and mail servers. The following code snippet shows you how to use EmailValidator to validate an email address.

```csharp
EmailValidator ev = new EmailValidator();
ValidationResult result;
ev.Validate("user@domain.com", out result);
if (result.ReturnCode == ValidationResponseCode.ValidationSuccess)
{
    Console.WriteLine("the email address is valid.");
}
else
{
    Console.WriteLine("the mail address is invalid,for the {0}", result.Message);
}
```

### Validating Domain {#validating-domain}

Aspose.Email.Verifications can verify the validity of a domain name.

### Validating Mail Server {#validating-mail-server}

Aspose.Email.Verifications can verify the validity of a mail server.

## Validate Email Messages {#validate-email-messages}

Besides validating addresses, domains and mail servers, Aspose.Email can check that a message *file* is well formed. The <a href="https://reference.aspose.com/email/net/aspose.email.tools.verifications/messagevalidator/" target="_blank" rel="nofollow noopener noreferrer">MessageValidator</a> class inspects an EML, EMLX, MHT, MSG or OFT file and reports whether it conforms to its format. It exposes two static methods, both returning a <a href="https://reference.aspose.com/email/net/aspose.email.tools.verifications/messagevalidationresult/" target="_blank" rel="nofollow noopener noreferrer">MessageValidationResult</a>:

- `static MessageValidationResult Validate(string fileName)`
- `static MessageValidationResult Validate(Stream stream)`

The result carries the following members:

Each error exposes an `ErrorType` - a <a href="https://reference.aspose.com/email/net/aspose.email.tools.verifications/messagevalidationerrortype/" target="_blank" rel="nofollow noopener noreferrer">MessageValidationErrorType</a> value (`MessageStructureError`, `EmailAddressError`, `TransferEncodingError`, `EmptyMessageClassError` or `UnknownFormat`) - together with a `Description` and, where it is known, the `LineNumber` at which the problem was found.

```cs
MessageValidationResult result = MessageValidator.Validate("message.eml");

Console.WriteLine("Detected format: " + result.FormatType);
Console.WriteLine("Valid: " + result.IsSuccess);

if (!result.IsSuccess)
{
    Console.WriteLine("Summary: " + result.ErrorMessage);

    foreach (MessageValidationError error in result.Errors)
    {
        Console.WriteLine($"{error.ErrorType} (line {error.LineNumber}): {error.Description}");
    }
}
```

Validation works on a stream as well, which is convenient when the message never touches the file system:

```cs
using var stream = File.OpenRead("message.msg");

MessageValidationResult result = MessageValidator.Validate(stream);

Console.WriteLine(result.IsSuccess);
```

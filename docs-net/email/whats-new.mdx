## <a href="https://releases.aspose.com/email/net/release-notes/2025/aspose-email-for-net-25-8-release-notes/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for .NET 25.8</a> {#asposeemail-for-net-258}

- The `X500Address` property of the <a href="https://reference.aspose.com/email/net/aspose.email/mailaddress/" target="_blank" rel="nofollow noopener noreferrer">MailAddress</a> class provides access to the email address in Exchange (X.500) format, if available.

- The `Aspose.Email.Clients.Graph.ODataQueryBuilder` class simplifies the construction of OData query parameters for Microsoft Graph. This enhancement enables advanced filtering, ordering, selection, and paging when working with Graph data.

- The `Aspose.Email.Clients.Graph.IGraphClientAsync` interface enables asynchronous operations with the GraphClient for improved performance and responsiveness.

## <a href="https://releases.aspose.com/email/net/release-notes/2025/aspose-email-for-net-25-7-release-notes/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for .NET 25.7</a> {#asposeemail-for-net-257}

- Extract externally linked image resources from the HTML body and embed them directly into the HTML output. The original appearance of email messages containing linked content is preserved when saving or processing emails. The <a href="https://reference.aspose.com/email/net/aspose.email/headersformattingoptions/extracthtmlbodyresourcesasattachments/" target="_blank" rel="nofollow noopener noreferrer">HtmlSaveOptions.ExtractHTMLBodyResourcesAsAttachments</a> - when set to true - extracts linked images and other resources from the HTML body and embeds them as attachments, maintaining the message's visual fidelity.

## <a href="https://releases.aspose.com/email/net/release-notes/2025/aspose-email-for-net-25-6-release-notes/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for .NET 25.6</a> {#asposeemail-for-net-256}

- Enumerate messages that have been deleted twice **(soft-deleted)** in PST files. The <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/findandenumeratesoftdeleteditems/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.FindAndEnumerateSoftDeletedItems()</a> method returns an enumerable collection of <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/restoreditementry/" target="_blank" rel="nofollow noopener noreferrer">RestoredItemEntry</a> objects, each containing a deleted <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> and its corresponding FolderId.

- Retrieve folder contents from PST files in a **paginated manner** using the overloaded <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/getcontents/#getcontents_3" target="_blank" rel="nofollow noopener noreferrer">FolderInfo.GetContents(MailQuery query, int startIndex, int count)</a> method which retrieves a subset of messages that match the specified query, starting from a given index and limited by a count.

- Set the state of a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicalendar/" target="_blank" rel="nofollow noopener noreferrer">MapiCalendar</a> object, overriding its default behavior explicitly using the void <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicalendar/setstateforced/" target="_blank" rel="nofollow noopener noreferrer">MapiCalendar.SetStateForced(MapiCalendarState state)</a> method.

It returns a list of Appointment objects, allowing easy access and processing of each event individually.

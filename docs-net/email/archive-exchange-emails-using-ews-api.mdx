Aspose.Email for .NET offers a comprehensive API to manage and process emails on an Exchange Server. This guide demonstrates how to list emails in the Inbox folder of an Exchange mailbox and archive them programmatically using the <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient</a> interface. The <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient.ArchiveItem</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient</a> interface allows you to move items into users archive mailbox. It provides four overloads which are listed below:

- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem" target="_blank" rel="nofollow noopener noreferrer">ArchiveItem(string sourceFolderUri, Appointment appointment)</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem_1" target="_blank" rel="nofollow noopener noreferrer">ArchiveItem(string sourceFolderUri, ExchangeTask task)</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem_2" target="_blank" rel="nofollow noopener noreferrer">ArchiveItem(string sourceFolderUri, MapiMessageItemBase item)</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem_3" target="_blank" rel="nofollow noopener noreferrer">ArchiveItem(string sourceFolderUri, string uniqueId)</a>

The following code sample demonstrates how to use Aspose.Email to connect to the Exchange server, list messages, and archive them with the <a href="https://reference.aspose.com/email/net/aspose.email.clients.exchange.webservice/iewsclient/archiveitem/#archiveitem/" target="_blank" rel="nofollow noopener noreferrer">IEWSClient.ArchiveItem</a> method. Storing emails is achieved by moving each item to the Archive Mailbox using the UniqueUri.

```csharp
const string mailboxUri = "<HOST>";
const string domain = @"";
const string username = @"<USERNAME>";
const string password = @"<PASSWORD>";
NetworkCredential credentials = new NetworkCredential(username, password, domain);
IEWSClient client = EWSClient.GetEWSClient(mailboxUri, credentials);

ExchangeMessageInfoCollection msgCollection = client.ListMessages(client.MailboxInfo.InboxUri);

foreach (ExchangeMessageInfo msgInfo in msgCollection)
{
    Console.WriteLine("Subject:" + msgInfo.Subject);
    client.ArchiveItem(client.MailboxInfo.InboxUri, msgInfo.UniqueUri);
}
client.Dispose();
```

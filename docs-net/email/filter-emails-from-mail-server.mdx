## Filter Messages by Sender, Recipient or Date {#filter-messages-by-sender-recipient-or-date}

The <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> class, described in [Connect to POP3 Server](/net/email/connect-to-pop3-server/), provides the <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/listmessages/#listmessages/" target="_blank" rel="nofollow noopener noreferrer">ListMessages()</a> method which gets all the messages from a mailbox. To get only messages which match some condition, use the overloaded <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/listmessages/#listmessages/" target="_blank" rel="nofollow noopener noreferrer">ListMessages()</a> method which takes <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> as an argument. The <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> class provides various properties for specifying the query conditions, for example, date, subject, sender, recipient and so on. The <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">MailQueryBuilder</a> class is used to build the search expression. First, all the conditions and constraints are set and then <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> is filled with the query developed by <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">MailQueryBuilder</a>. The <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> class object is used by <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/" target="_blank" rel="nofollow noopener noreferrer">Pop3Client</a> to extract the filtered information from the server. This article shows how to filter email messages from a mailbox. The first example illustrates how to filter messages based on date and subject. We also show how to filter on other criteria and how to build more complex queries. It also shows the application of Date and Time filter to retrieve the specific emails from the mailbox. In addition, it also shows how to apply case-sensitive filtering.

## Filter Messages from Mailbox {#filter-messages-from-mailbox}

To filter messages from a mailbox:

1. [Connect to POP3 server](/net/email/connect-to-pop3-server/#connect-to-pop3-server).
2. Create an instance of <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> and set the desired properties.
3. Call the <a href="https://reference.aspose.com/email/net/aspose.email.clients.pop3/pop3client/listmessages/#listmessages_8" target="_blank" rel="nofollow noopener noreferrer">Pop3Client.ListMessages(MailQuery query)</a> method and pass the <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> in parameters to get the filtered messages only.

The following code snippet shows you how to connect to a POP3 mailbox and get messages that arrived today and have the word "newsletter" in the subject.

```csharp
// Connect and log in to POP3
const string host = "host";
const int port = 110;
const string username = "user@host.com";
const string password = "password";
Pop3Client client = new Pop3Client(host, port, username, password);

// Set conditions, Subject contains "Newsletter", Emails that arrived today
MailQueryBuilder builder = new MailQueryBuilder();      
builder.Subject.Contains("Newsletter");
builder.InternalDate.On(DateTime.Now);
// Build the query and Get list of messages
MailQuery query = builder.GetQuery();
Pop3MessageInfoCollection messages = client.ListMessages(query);
Console.WriteLine("Pop3: " + messages.Count + " message(s) found.");
```

## Retrieve Messages by Specific Criteria {#retrieve-messages-by-specific-criteria}

[The code samples above](/net/email/filter-emails-from-mail-server/#filter-messages-from-mailbox) shows how you can filter messages based on the email subject and date. We can use other properties to set other supported conditions as well. Below are some examples of setting the conditions using <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a>.

The code snippets that follow show how to filter emails on other criteria:

- Find emails delivered today.
- Find emails received within a range.
- Find emails from a specific sender.
- Find emails sent from a specific domain.
- Find emails sent to a specific recipient.

### Today's Date {#today}

The following code snippet shows you how to find emails delivered today.

```csharp
// Emails that arrived today
MailQueryBuilder builder = new MailQueryBuilder();
builder.InternalDate.On(DateTime.Now);
```

### Date Range {#date-range}

The following code snippet shows you how to find emails received within a range.

```csharp
// Emails that arrived in last 7 days
builder.InternalDate.Before(DateTime.Now);
builder.InternalDate.Since(DateTime.Now.AddDays(-7));
```

### Specific Sender {#specific-sender}

The following code snippet shows you how to find emails from a specific sender.

```csharp
// Get emails from specific sender
builder.From.Contains("saqib.razzaq@127.0.0.1");
```

### Specific Domain {#specific-domain}

The following code snippet shows you how to find emails sent from a specific domain.

```csharp
// Get emails from specific domain
builder.From.Contains("SpecificHost.com");
```

### Specific Recipient {#specific-recipient}

The following code snippet shows you how to find emails sent to a specific recipient.

```csharp
// Get emails sent to specific recipient
builder.To.Contains("recipient");
```

## Build Complex Queries {#build-complex-queries}

If different <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">MailQueryBuilder</a> properties are set in separate statements, then all the conditions would be matched. For example, if we want to get messages between a date range and from a specific host, we need to write three statements.

### Combine Queries with AND {#combine-queries-with-and}

The following code snippet shows you how to combine queries with AND.

```csharp
// Emails from specific host, get all emails that arrived before today and all emails that arrived since 7 days ago
builder.From.Contains("SpecificHost.com");
builder.InternalDate.Before(DateTime.Now);
builder.InternalDate.Since(DateTime.Now.AddDays(-7));
```

### Combine Queries with OR {#combine-queries-with-or}

<a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">MailQueryBuilder</a> provides the <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/or/#or" target="_blank" rel="nofollow noopener noreferrer">Or()</a> method which takes two <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> instances as parameters. It gets the messages that match any of the two conditions specified. The following code snippet shows how to filter messages that either have "test" in the subject or "noreply@host.com" as the sender. The following code snippet shows you how to combine queries with OR.

```csharp
// Specify OR condition
builder.Or(builder.Subject.Contains("test"), builder.From.Contains("noreply@host.com"));
```

### Case Sensitive Filters {#case-sensitive-filters}

The API also provides the capability to filter emails from the mailbox based on a case sensitive criteria. The following methods provide the capability to search emails specifying case sensitive flag.

- Method Aspose.Email.StringComparisonField.Contains(string value, bool ignoreCase)
- Method Aspose.Email.StringComparisonField.Equals(string value, bool ignoreCase)
- Method Aspose.Email.StringComparisonField.NotContains(string value, bool ignoreCase)
- Method Aspose.Email.StringComparisonField.NotEquals(string value, bool ignoreCase)

```csharp
// IgnoreCase is True
MailQueryBuilder builder1 = new MailQueryBuilder();
builder1.From.Contains("tesT", true);
MailQuery query1 = builder1.GetQuery();
Pop3MessageInfoCollection messageInfoCol1 = client.ListMessages(query1);
```

After you open an OLM file and locate a folder, you can list its messages, read short message information, filter and page through large folders, and extract individual messages as <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> objects. This article covers all of these operations.

## List Messages in a Folder {#list-messages-in-a-folder}

The <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/" target="_blank" rel="nofollow noopener noreferrer">OlmFolder</a> class provides two ways to iterate over the messages it contains:

- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/enumeratemessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages</a> returns an <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> object on each iteration. This object holds short information about the message and is the most efficient way to scan a folder.
- <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/enumeratemapimessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMapiMessages</a> returns a full <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object on each iteration, with all of the message's properties loaded.

### Using EnumerateMessages {#using-enumeratemessages}

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);
    foreach (var messageInfo in folder.EnumerateMessages())
    {
        Console.WriteLine(messageInfo.Subject);
    }
}
```

### Using EnumerateMapiMessages {#using-enumeratemapimessages}

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);

    foreach (var msg in folder.EnumerateMapiMessages())
    {
        // save the message in MSG format
        msg.Save($"{msg.Subject}.msg");
    }
}
```

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);

    foreach (OlmMessageInfo messageInfo in folder.EnumerateMessages())
    {
        Console.WriteLine($"Subject: {messageInfo.Subject}");
        Console.WriteLine($"From: {messageInfo.From}");
        Console.WriteLine($"To: {string.Join("; ", messageInfo.To)}");
        Console.WriteLine($"Date: {messageInfo.Date}");
        Console.WriteLine($"Modified: {messageInfo.ModifiedDate}");
        Console.WriteLine($"Has attachments: {messageInfo.HasAttachments}");
        Console.WriteLine($"Message class: {messageInfo.MessageClass}");
        Console.WriteLine(new string('-', 30));
    }
```

### Get the Modified Date of a Message {#get-the-modified-date-of-a-message}

The modified date represents the date and time when the OLM message was last modified. Use the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/modifieddate/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo.ModifiedDate</a> property to read it:

```cs
foreach (OlmMessageInfo messageInfo in inboxFolder.EnumerateMessages())
{
    DateTime modifiedDate = messageInfo.ModifiedDate;
}
```

## Filter Messages with a Query {#filter-messages-with-a-query}

For large folders, you can retrieve only the messages that match a set of criteria instead of iterating over everything. Pass a <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a> to the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/enumeratemessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages(MailQuery query)</a> overload. Build the query with a <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquerybuilder/" target="_blank" rel="nofollow noopener noreferrer">MailQueryBuilder</a>.

The example below enumerates only the messages received during the last seven days whose subject contains the word "Invoice":

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);

    var builder = new MailQueryBuilder();
    builder.InternalDate.Since(DateTime.Now.AddDays(-7));
    builder.Subject.Contains("Invoice");
    MailQuery query = builder.GetQuery();

    foreach (var messageInfo in folder.EnumerateMessages(query))
    {
        Console.WriteLine(messageInfo.Subject);
    }
}
```

## Page Through Messages {#page-through-messages}

When a folder contains a large number of messages, you can read them in batches with the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmfolder/enumeratemessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages(int skip, int count)</a> overload. The `skip` parameter is the number of messages to bypass, and `count` is the number of messages to return.

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);

    const int pageSize = 50;
    int pageIndex = 0;

    while (true)
    {
        var page = folder.EnumerateMessages(pageIndex * pageSize, pageSize).ToList();
        if (page.Count == 0)
        {
            break;
        }

        foreach (var messageInfo in page)
        {
            Console.WriteLine(messageInfo.Subject);
        }

        pageIndex++;
    }
}
```

## Extract a Message as a MapiMessage {#extract-a-message-as-a-mapimessage}

The <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class provides the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/extractmapimessage/" target="_blank" rel="nofollow noopener noreferrer">ExtractMapiMessage</a> method, which extracts a full <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> from an <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> object. This is useful when you first scan a folder with `EnumerateMessages` and then extract only the messages you actually need.

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var folder = olm.GetFolder("Inbox", true);

    foreach (var messageInfo in folder.EnumerateMessages())
    {
        if (messageInfo.Date.Date == DateTime.Today)
        {
            // extract today's messages from Inbox
            var msg = olm.ExtractMapiMessage(messageInfo);
            msg.Save($"{msg.Subject}.msg");
        }
    }
}
```

### Extract Messages by Identifier {#extract-messages-by-identifier}

Sometimes you need to extract selected messages by their identifiers. For example, an application can store identifiers in a database and extract a message on demand instead of traversing the entire storage each time. The <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/entryid/" target="_blank" rel="nofollow noopener noreferrer">EntryId</a> property of <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> provides the message entry identifier, and the overloaded <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/extractmapimessage/" target="_blank" rel="nofollow noopener noreferrer">ExtractMapiMessage(string id)</a> method retrieves the message by that identifier.

```cs
using (var olm = OlmStorage.FromFile(fileName))
{
    var olmFolder = olm.GetFolder("Inbox", true);

    foreach (OlmMessageInfo msgInfo in olmFolder.EnumerateMessages())
    {
        // store msgInfo.EntryId somewhere, then later:
        MapiMessage msg = olm.ExtractMapiMessage(msgInfo.EntryId);
    }
}
```

## Extract Items Using the Traversal API {#extract-items-using-the-traversal-api}

You can extract every item from an OLM file - as far as possible - without throwing exceptions, even when some data in the original file is corrupted. To do this, create the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> instance with the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/#constructors" target="_blank" rel="nofollow noopener noreferrer">OlmStorage(TraversalExceptionsCallback callback)</a> constructor and load the file with the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/load/" target="_blank" rel="nofollow noopener noreferrer">Load</a> method. The callback exposes the loading and traversal exceptions.

The `Load` method returns `true` if the file was loaded successfully and traversal is possible, and `false` if the file is corrupted and no traversal is possible. Note that when traversing items folder by folder, you call the storage's <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/enumeratemessages/" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages(OlmFolder folder)</a> method, passing the folder as an argument.

The steps are:

1. Create a new <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> instance, passing an exception-handling callback.
2. Load the OLM file by calling the <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/load/" target="_blank" rel="nofollow noopener noreferrer">Load</a> method.
3. If the file loads successfully, obtain the folder hierarchy by calling <a href="https://reference.aspose.com/email/net/aspose.email.storage.olm/olmstorage/getfolders/" target="_blank" rel="nofollow noopener noreferrer">GetFolders</a>.
4. Recursively iterate over each folder. For folders that have messages, enumerate them with the storage's `EnumerateMessages` method and process each one.
5. Recurse into any sub-folders.

```cs
using (var olm = new OlmStorage((exception, id) => { /* Exception handling code. */ }))
{
    if (olm.Load(fileName))
    {
        var folderHierarchy = olm.GetFolders();
        ExtractItems(olm, folderHierarchy);
    }
}

private static void ExtractItems(OlmStorage olm, IEnumerable<OlmFolder> folders)
{
    foreach (var folder in folders)
    {
        if (folder.HasMessages)
        {
            Console.WriteLine(folder);

            foreach (var msg in olm.EnumerateMessages(folder))
            {
                Console.WriteLine(msg.Subject);
            }
        }

        ExtractItems(olm, folder.SubFolders);
    }
}
```

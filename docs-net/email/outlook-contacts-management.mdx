This article covers standalone Outlook `MapiContact` items saved as MSG or vCard (VCF). For the format-neutral `VCardContact` class that reads and writes vCard files directly, see [Working with vCard (VCF) Files](/net/email/working-with-vcard-files/). To store and read contacts inside a PST, see [Managing Contacts in PST Files](/net/email/managing-contacts-in-pst-files/).

Like MapiMessage, Aspose.Email allows you to create Outlook contacts. The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class provides all the contact related properties required to create an Outlook contact. This article shows how to create, save and read an Outlook contact using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class.

## The MapiContact Structure {#the-mapicontact-structure}

<a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> does not expose one flat list of fields. Related properties are grouped into *property sets*, each of which is a separate object assigned to a property of the contact. Knowing the map makes it much easier to find where a particular Outlook field lives.

### Add Contact Event Information {#add-contact-event-information}

The `Events` property set carries the two date fields Outlook shows on the *Details* tab - the contact's birthday and wedding anniversary.

```cs
var contact = new MapiContact
{
    NameInfo = new MapiContactNamePropertySet("Bertha", "A.", "Buell"),
    Events = new MapiContactEventPropertySet
    {
        Birthday = new DateTime(1980, 5, 20),
        WeddingAnniversary = new DateTime(2005, 9, 12)
    }
};

contact.Save("contact.msg", ContactSaveFormat.Msg);

// Read the dates back
var loaded = (MapiContact)MapiMessage.Load("contact.msg").ToMapiMessageItem();

Console.WriteLine("Birthday: " + loaded.Events.Birthday.ToShortDateString());
Console.WriteLine("Anniversary: " + loaded.Events.WeddingAnniversary.ToShortDateString());
```

## Create and Save Outlook Contact {#create-and-save-outlook-contact}

To create a contact and save it to disc:

1. Instantiate a new object of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class.
2. Enter contact property information.
3. Add photo data (if any).
4. Save the contact as MSG or VCard format.

The following code snippet shows you how to create and save outlook contact.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Outlook();

MapiContact contact = new MapiContact();
contact.NameInfo = new MapiContactNamePropertySet("Bertha", "A.", "Buell");
contact.ProfessionalInfo = new MapiContactProfessionalPropertySet("Awthentikz", "Social work assistant");
contact.PersonalInfo.PersonalHomePage = "B2BTies.com";
contact.PhysicalAddresses.WorkAddress.Address = "Im Astenfeld 59 8580 EDELSCHROTT";
contact.ElectronicAddresses.Email1 = new MapiContactElectronicAddress("Experwas", "SMTP", "BerthaABuell@armyspy.com");
contact.Telephones = new MapiContactTelephonePropertySet("06605045265");
contact.PersonalInfo.Children = new string[] { "child1", "child2", "child3" };
contact.Categories = new string[] { "category1", "category2", "category3" };
contact.Mileage = "Some test mileage";
contact.Billing = "Test billing information";
contact.OtherFields.Journal = true;
contact.OtherFields.Private = true;
contact.OtherFields.ReminderTime = new DateTime(2014, 1, 1, 0, 0, 55);
contact.OtherFields.ReminderTopic = "Test topic";
contact.OtherFields.UserField1 = "ContactUserField1";
contact.OtherFields.UserField2 = "ContactUserField2";
contact.OtherFields.UserField3 = "ContactUserField3";
contact.OtherFields.UserField4 = "ContactUserField4";

// Add a photo
using (FileStream fs = File.OpenRead(dataDir + "Desert.jpg"))
{
    byte[] buffer = new byte[fs.Length];
    fs.Read(buffer, 0, buffer.Length);
    contact.Photo = new MapiContactPhoto(buffer,
        MapiContactPhotoImageFormat.Jpeg);
}
// Save the Contact in MSG format
contact.Save(dataDir + "MapiContact_out.msg",ContactSaveFormat.Msg);

// Save the Contact in VCF format
contact.Save(dataDir + "MapiContact_out.vcf", ContactSaveFormat.VCard);
```

## Save MAPI Distribution Lists to VCF Files {#save-mapi-distribution-lists-to-vcf-files}

The code sample below demonstrates how to save a distribution list to a multi-contact VCF file:

```cs
// convert the `msg` object to a `MapiDistributionList` object
var dlist = (MapiDistributionList)msg.ToMapiMessageItem();

//save the distribution list
var options = new MapiDistributionListSaveOptions(ContactSaveFormat.VCard);
dlist.Save("distribution_list.vcf", options);
```

## Convert Multi-Contact VCF Files to MapiDistributionList {#convert-multi-contact-vcf-files-to-mapidistributionlist}

Aspose.Email supports the conversion of multi-contact VCF files into `MapiDistributionList` objects, making it easy to manage and import multiple contacts directly into your applications. This feature is accessible through the following static methods in the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapidistributionlist/#mapidistributionlist-class" target="_blank" rel="nofollow noopener noreferrer">MapiDistributionList</a> class:

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapidistributionlist/fromvcf/#fromvcf_1" target="_blank" rel="nofollow noopener noreferrer">static MapiDistributionList FromVCF(string filePath)</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapidistributionlist/fromvcf/#fromvcf" target="_blank" rel="nofollow noopener noreferrer">static MapiDistributionList FromVCF(Stream stream)</a>

The code sample below demonstrates how to use this feature:

```csharp
// Convert a multi-contact VCF file to a MapiDistributionList
MapiDistributionList dlist = MapiDistributionList.FromVCF(fileName);
```

## Save Contacts in VCF Format {#save-contacts-in-vcf-format}

To save the contact in version 3 VCF format, use the <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardversion/" target="_blank" rel="nofollow noopener noreferrer">VCardVersion</a> enumeration to set the <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardsaveoptions/version/" target="_blank" rel="nofollow noopener noreferrer">VCardSaveOptions.Version</a> property. The following sample code demonstrates the use of <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardversion/" target="_blank" rel="nofollow noopener noreferrer">VCardVersion</a> enumeration to save the contact VCF version 3 format:

```cs
var options = new MapiDistributionListSaveOptions(ContactSaveFormat.VCard);
options.Version = VCardVersion.V30;
dlist.Save("distribution_list.vcf", options);
```

## Reading MAPI Contacts {#reading-mapi-contacts}

The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class can be used to load both Outlook MSG and VCard format contacts. The following code snippet shows you how to load Outlook contacts saved as MSG and VCF into a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a>.

### Load Contacts from MSG Files {#load-contacts-from-msg-files}

The following code snippet shows you how to load contacts from MSG.

```csharp
MapiMessage msg = MapiMessage.FromFile(dataDir + "Contact.msg");
MapiContact contact = (MapiContact)msg.ToMapiMessageItem();

Console.WriteLine(contact.NameInfo.DisplayName);
```

### Load Contacts from VCards {#load-contacts-from-vcards}

The following code snippet shows you how to load a vCard file into a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/fromvcard/" target="_blank" rel="nofollow noopener noreferrer">FromVCard</a> method. To load a vCard into a <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardcontact/" target="_blank" rel="nofollow noopener noreferrer">VCardContact</a> instead, see [Working with vCard (VCF) Files](/net/email/working-with-vcard-files/).

```csharp
MapiContact contact = MapiContact.FromVCard(dataDir + "Contact.vcf");
```

### Load MAPI Contacts from vCard with Custom Options {#load-mapi-contacts-from-vcard-with-custom-options}

To provide more flexibility when converting vCard (.vcf) files into MAPI contacts, Aspose.Email for .NET provides an overload <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/#methods" target="_blank" rel="nofollow noopener noreferrer">MapiContact.FromVCard(string filePath, VCardLoadOptions options)</a> method that accepts a <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardloadoptions/" target="_blank" rel="nofollow noopener noreferrer">VCardLoadOptions</a> object. It offers improved control over how vCard files are interpreted - especially when working with different vCard formats, encodings, or advanced parsing scenarios.

The following code sample demonstrates how to load a .vcf contact file into a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> object using the overload that accepts <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardloadoptions/" target="_blank" rel="nofollow noopener noreferrer">VCardLoadOptions</a>. The loaded contact can then be used within PST files, MSG export, or other Outlook-compatible formats.

```cs
var mapiContact = MapiContact.FromVCard("contact.vcf", new VCardLoadOptions());
Console.WriteLine(mapiContact.NameInfo.DisplayName);
```

### Load Contacts from VCards with Specified Encoding {#load-contacts-from-vcards-with-specified-encoding}

The encoding of a vCard file is specified through the <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardloadoptions/preferredencoding/" target="_blank" rel="nofollow noopener noreferrer">PreferredEncoding</a> property of the <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardloadoptions/" target="_blank" rel="nofollow noopener noreferrer">VCardLoadOptions</a> class. The following code snippet shows you how to load contacts from VCard with the specified encoding.

```csharp
var loadOptions = new VCardLoadOptions { PreferredEncoding = Encoding.UTF8 };
var contactReadFromFile = MapiContact.FromVCard(dataDir + @"Contact.vcf", loadOptions);
```

### Save VCard Files with Extended fields {#save-vcard-files-with-extended-fields}

The <a href="https://reference.aspose.com/email/net/aspose.email.personalinfo.vcard/vcardsaveoptions/useextensions/#vcardsaveoptionsuseextensions-property" target="_blank" rel="nofollow noopener noreferrer">UseExtensions</a> property allows you to control whether extended fields can be used when saving vCard files. When set to true (default), extensions are permitted, providing compatibility with custom fields and additional contact information.

The following code sample shows how to disable the extended fields when saving a contact:

```cs
var contact = MapiContact.FromVCard("contact.vcf");

var options = new VCardSaveOptions
{
    UseExtensions = false
};

contact.Save("contact_out.vcf", options);
```

## Render Contact Information to MHTML {#render-contact-information-to-mhtml}

Outlook Contact can be converted to MHTML using Aspose.Email API. This example shows how a VCard is loaded into <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> and then converted to MHTML with the help of <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> API.

```cs
//Load VCF Contact and convert to MailMessage for rendering to MHTML
var contact = MapiContact.FromVCard("Contact.vcf");

MemoryStream ms = new MemoryStream();
contact.Save(ms, ContactSaveFormat.Msg);
ms.Position = 0;
MapiMessage msg = MapiMessage.Load(ms, new MsgLoadOptions());
MailConversionOptions op = new MailConversionOptions();
MailMessage eml = msg.ToMailMessage(op);

//Prepare the MHT format options
MhtSaveOptions mhtSaveOptions = new MhtSaveOptions();
mhtSaveOptions.CheckBodyContentEncoding = true;
mhtSaveOptions.PreserveOriginalBoundaries = true;
MhtFormatOptions formatOp = MhtFormatOptions.WriteHeader | MhtFormatOptions.RenderVCardInfo;
mhtSaveOptions.RenderedContactFields = ContactFieldsSet.NameInfo | ContactFieldsSet.PersonalInfo | ContactFieldsSet.Telephones | ContactFieldsSet.Events;
mhtSaveOptions.MhtFormatOptions = formatOp;
eml.Save("ContactMhtml_out.mhtml", mhtSaveOptions);
```

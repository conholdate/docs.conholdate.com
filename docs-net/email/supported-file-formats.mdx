Aspose.Email for .NET provides a comprehensive suite of functionalities tailored for efficient handling of email messages and associated data. A fundamental aspect of the library lies in its robust support for a diverse array of file formats, empowering users to seamlessly process email-related data within their applications. Below is an overview of all the supported file formats:

<div className="docs-owner-markdown-table">

| **Format** | **Description** | **Load** | **Save** |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | --------- |
| <a href="https://docs.fileformat.com/email/msg/" target="_blank" rel="nofollow noopener noreferrer">MSG</a> | This format is used by Microsoft Outlook and Exchange to store email messages, contact, appointment, or other tasks. Aspose.Email supports reading, writing, and modifying MSG files. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/pst/" target="_blank" rel="nofollow noopener noreferrer">PST</a> | It represents Outlook Personal Storage Files that store emails, calendar items, notes, contacts, and several other file formats. It is used for archiving emailing data offline. Aspose.Email allows working with PST files, including reading, writing, and manipulating data. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/ost/" target="_blank" rel="nofollow noopener noreferrer">OST</a> | It represents the user's mailbox data in offline mode on the local machine upon registration with Exchange Server using Microsoft Outlook. Aspose.Email allows working with OST files, including reading and manipulating data. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/oft/" target="_blank" rel="nofollow noopener noreferrer">OFT</a> | Message template files that are created using Microsoft Outlook. Aspose.Email allows working with OFT files, including reading and writing. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/olm/" target="_blank" rel="nofollow noopener noreferrer">OLM</a> | This format is used by Microsoft Outlook for Mac for storing email messages, contacts, journals, calendar data, and other user application data. Aspose.Email supports the extraction, manipulation, and conversion of the data housed within these archives. | Supported |  |
| <a href="https://docs.fileformat.com/email/eml/" target="_blank" rel="nofollow noopener noreferrer">EML</a> | It represents email messages saved using Outlook and other relevant applications. Aspose.Email provides support for reading and writing EML files, as well as converting them to other formats. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/emlx/" target="_blank" rel="nofollow noopener noreferrer">EMLX</a> | It is a format used by Apple Mail to store a single email message. Aspose.Email enables reading and writing of EMLX files. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/mbox/" target="_blank" rel="nofollow noopener noreferrer">MBOX</a> | It represents a container for collection of electronic mail messages. Aspose.Email provides support for reading and writing MBOX files. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/ics/" target="_blank" rel="nofollow noopener noreferrer">ICS</a> | The iCalendar format is used for exchanging and deploying calendar events and scheduling. Aspose.Email provides support for reading and writing ICS files, allowing integration of calendar data into applications. | Supported | Supported |
| <a href="https://docs.fileformat.com/email/vcf/" target="_blank" rel="nofollow noopener noreferrer">VCF</a> | Virtual Card Format is a digital file format for storing contact information. Aspose.Email allows users to read, write, and manipulate contact data. | Supported | Supported |
| <a href="https://docs.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">HTML</a> | HTML (HyperText Markup Language) is the extension for web pages created for display in browsers. Aspose.Email equips developers with the capability to handle HTML files, facilitating the extraction and utilization of content from these files within their applications. | Supported | Supported |
| <a href="https://docs.fileformat.com/web/mhtml/" target="_blank" rel="nofollow noopener noreferrer">MHTML</a> | Web page archive format which saves the HTML code and associated resources in a single file. Aspose.Email supports reading MHTML files, allowing extraction of their content for use in applications. | Supported | Supported |

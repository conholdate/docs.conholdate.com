## Convert HTML to EML {#convert-html-to-eml}

Aspose.Email for .NET provides a method to convert HTML files to EML format using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/load/#load_3" target="_blank" rel="nofollow noopener noreferrer">MailMessage.Load</a> and <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/save/#save_3" target="_blank" rel="nofollow noopener noreferrer">MailMessage.Save</a> methods to load the existing HTML file and save it in EML format respectively:

```cs
var eml = MailMessage.Load("myContent.html", new HtmlLoadOptions());
eml.Save("output.eml", SaveOptions.DefaultEml);
```

In the code sample, the <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/#htmlloadoptions-class" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a> class allows you to specify additional options when loading a MailMessage from HTML format. The following code sample demonstrates the use of this class. In the example, it specifies a text representation of the message body:

```cs
// Create an instance of HtmlLoadOptions
var loadOptions = new HtmlLoadOptions();

// Set the ShouldAddPlainTextView property to true to generate a plain text view along with HTML
loadOptions.ShouldAddPlainTextView = true;

// Load an HTML file
var mailMessage = MailMessage.Load("input.html", loadOptions);

// Access the plain text view of the email message
var plainTextView = mailMessage.GetAlternateViewContent("text/plain");

// Print or further process the plain text view
Console.WriteLine("Plain Text View:");
Console.WriteLine(plainTextView);
```

## Convert HTML to EMLX {#convert-html-to-emlx}

You can easily convert HTML files to EMLX. All the properties and classes provided by the API for HTML to EML conversion are available for this type of conversion as well:

```cs
var eml = MailMessage.Load("myContent.html", new HtmlLoadOptions());
eml.Save("output.emlx", SaveOptions.DefaultEmlx);
```

For additional settings, see [Convert HTML to EML](/net/email/converting-between-formats/convert-html-to-other-formats/#convert-html-to-eml) paragraph.

## Convert HTML to ICS {#convert-html-to-ics}

To perform the task, the library offers the <a href="https://reference.aspose.com/email/net/aspose.email.calendar/appointment/#appointment-class" target="_blank" rel="nofollow noopener noreferrer">Appointment</a> class to represent and manage calendar events. The following code sample demonstrates how to create an appointment form HTML content and save it to an ICS (iCalendar) file format:

```cs
// Sample HTML content
var htmlContent = File.ReadAllText("content.html");

// Create and initialize an instance of the Appointment class
var appointment = new Appointment(
    "Meeting Room 3 at Office Headquarters",// Location
    "Monthly Meeting",                      // Summary
    "Please confirm your availability.",    // Description
    new DateTime(2015, 2, 8, 13, 0, 0),     // Start date
    new DateTime(2015, 2, 8, 14, 0, 0),     // End date
    "from@domain.com",                      // Organizer
    "attendees@domain.com")
{
    HtmlDescription = htmlContent
};

// Save the event to an ICS file
appointment.Save("output.ics", AppointmentSaveFormat.Ics);
```

## Generate MBOX from HTML content {#generate-mbox-from-html-content}

To perform HTML to MBOX conversion, use the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/load/#load_3" target="_blank" rel="nofollow noopener noreferrer">Load</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/#mailmessage-class" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class, specifying the HTML content file path and an instance of <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a>. This method parses the HTML content and generates a corresponding MailMessage object, preserving the structure and formatting of the original HTML. After loading the HTML content into a MailMessage object, write the message to an MBOX file using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.mbox/mboxrdstoragewriter/#mboxrdstoragewriter-class" target="_blank" rel="nofollow noopener noreferrer">MboxrdStorageWriter</a> class:

```cs
using (var eml = MailMessage.Load("content.html", new HtmlLoadOptions())){
    using (var writer = new MboxrdStorageWriter("output.mbox", false)){
        writer.WriteMessage(eml);
    }
}
```

## Convert HTML to MHTML {#convert-html-to-mhtml}

Use the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/load/#load_3" target="_blank" rel="nofollow noopener noreferrer">Load</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/#mailmessage-class" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class to load the existing file, specifying a path to it and an instance of <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a>. This method parses the HTML content and generates a corresponding MailMessage object, preserving the structure and formatting of the original HTML. After loading the HTML content into a MailMessage object, developers can save it as an MHTML file using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/save/#save_3" target="_blank" rel="nofollow noopener noreferrer">Save</a> method, specifying the desired output file path and utilizing the <a href="https://reference.aspose.com/email/net/aspose.email/saveoptions/defaultmhtml/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions.DefaultMhtml</a> option:

```cs
var eml = MailMessage.Load("content.html", new HtmlLoadOptions());
eml.Save("output.mhtml", SaveOptions.DefaultMhtml);
```

The <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/#mhtsaveoptions-class" target="_blank" rel="nofollow noopener noreferrer">MhtSaveOptions</a> class provides a variety of options for configuring the behavior and settings of the output MHTML file instead of the SaveOptions.DefaultMhtml. With its <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/#properties" target="_blank" rel="nofollow noopener noreferrer">properties</a>, you can specify additional options when saving MailMessage to MHTML format. The most popular of them are:

- <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/mhtformatoptions/" target="_blank" rel="nofollow noopener noreferrer">MhtFormatOptions</a> - Allows you to customize how the email message is saved in MHT format to best suit your needs.
- <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/saveattachments/" target="_blank" rel="nofollow noopener noreferrer">SaveAttachments</a> - Gets or sets a value indicating whether to save attachments.
- <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/saveallheaders/" target="_blank" rel="nofollow noopener noreferrer">SaveAllHeaders</a> - Defines whether need to save all headers in output mhtml or not. Default value is false.
- <a href="https://reference.aspose.com/email/net/aspose.email/mhtsaveoptions/preserveoriginaldate/" target="_blank" rel="nofollow noopener noreferrer">PreserveOriginalDate</a> - Defines whether need keep original date in mail message when saving or not. Default value is true.

The following code sample demonstrates how these properties can be used:

```cs
var mhtSaveOprtions = new MhtSaveOptions
{
    MhtFormatOptions = MhtFormatOptions.WriteHeader,
    SaveAttachments = true,
    SaveAllHeaders = true,
    PreserveOriginalDate = true
}
```

## Convert HTML to MSG {#convert-html-to-msg}

After loading the HTML content into a MailMessage object, save it as an MSG file using the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/save/#save_3" target="_blank" rel="nofollow noopener noreferrer">Save</a> method, specifying the desired output file path and utilizing the <a href="https://reference.aspose.com/email/net/aspose.email/saveoptions/defaultmsgunicode/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions.DefaultMsgUnicode</a> option. This option ensures that the output file is saved in the MSG format with Unicode encoding.

```cs
var eml = MailMessage.Load("content.html", new HtmlLoadOptions());
eml.Save("output.msg", SaveOptions.DefaultMsgUnicode);
```

## Add message with source HTML content to PST {#add-message-with-source-html-content-to-pst}

HTML to PST conversion involves creating a new PST (Personal Storage Table) file with a new folder, loading an HTML file and adding it to the new folder:

1. Create an instance of a PersonalStorage object representing a new PST file using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/create/#create_4" target="_blank" rel="nofollow noopener noreferrer">Create</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/#personalstorage-class" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class.
2. Access the root folder of the PST file and add a subfolder to it using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/addsubfolder/#addsubfolder" target="_blank" rel="nofollow noopener noreferrer">AddSubFolder</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/#folderinfo-class" target="_blank" rel="nofollow noopener noreferrer">FolderInfo</a> class.
3. Load the content of an HTML file into a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/#mapimessage-class" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/load/#load_3" target="_blank" rel="nofollow noopener noreferrer">Load</a> method with an instance of <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/#htmlloadoptions-class" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a> to specify that the content is in HTML format.
4. Add the loaded MapiMessage object (representing the HTML content) to the folder within the PST file using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/addmessage/" target="_blank" rel="nofollow noopener noreferrer">AddMessage</a> method.

```cs
using (var pst = PersonalStorage.Create("outputFile.pst", FileFormatVersion.Unicode))
{ 
    var inbox = pst.RootFolder.AddSubFolder("Inbox");
    var msg = MapiMessage.Load("content.html", new HtmlLoadOptions());
    inbox.AddMessage(msg);
}
```

## Add message with source HTML content to OST {#add-message-with-source-html-content-to-ost}

he following code sample with steps will show you how these components work together to add HTML content to OST file:

1. Load an existing OST file with the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/fromfile/#fromfile" target="_blank" rel="nofollow noopener noreferrer">FromFile</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/#personalstorage-class" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class used to represent the storage file that will store the email messages.
2. Load the HTML file using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/load/#load_3" target="_blank" rel="nofollow noopener noreferrer">Load</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/#mapimessage-class" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class representing an email message in Microsoft Outlook format.
3. Specify <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/#htmlloadoptions-class" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a> to enable additional options when loading MailMessage from HTML format.
4. Retrieve the root folder of the OST file using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/rootfolder/" target="_blank" rel="nofollow noopener noreferrer">RootFolder</a> property of the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/personalstorage/#personalstorage-class" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> object.
5. Obtain the Inbox folder within the OST file using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/getsubfolder/#getsubfolder" target="_blank" rel="nofollow noopener noreferrer">GetSubFolder</a> method on the root folder.
6. Add the loaded MapiMessage object (representing the HTML content) to the Inbox folder using the <a href="https://reference.aspose.com/email/net/aspose.email.storage.pst/folderinfo/addmessage/" target="_blank" rel="nofollow noopener noreferrer">AddMessage</a> method on the folder.

```cs
using (var ost = PersonalStorage.FromFile("storage.ost"))
{
    var msg = MapiMessage.Load("content.html", new HtmlLoadOptions());
    var folderInfo = ost.RootFolder.GetSubFolder("Inbox");
    folderInfo.AddMessage(msg);
}
```

## Convert HTML to VCF {#convert-html-to-vcf}

The following code sample demonstrates how to create a contact item, populate it with HTML content, and save it to a VCF file:

1. Read the content of an HTML file into a string variable using the File.ReadAllText method.
2. Create a new MapiContact object by instantiating the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/#mapicontact-class" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class.
3. Set the contact properties: display name, email address.
4. Set the body content of the contact to HTML using <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/setbodycontent/#setbodycontent" target="_blank" rel="nofollow noopener noreferrer">SetBodyContent</a>.
5. Save the contact as a VCF file using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapicontact/save/#save_4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method.

```cs
var content = File.ReadAllText("content.html");
            
// Create a new MapiContact
var contact = new MapiContact();
contact.NameInfo.DisplayName = "John Doe";
contact.ElectronicAddresses.Email1.EmailAddress = "john.doe@example.com";
contact.SetBodyContent(content, BodyContentType.Html);

// Save the contact to a VCF file
contact.Save("contact.vcf", ContactSaveFormat.VCard)
```

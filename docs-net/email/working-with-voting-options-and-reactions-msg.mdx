## Create Voting Options with MapiMessage {#create-voting-options-with-mapimessage}

Microsoft Outlook provides a feature to create a poll when composing a new email, allowing users to include voting options such as Yes, No, Maybe, etc. Aspose.Email allows similar functionality when creating a new Outlook message programmatically. The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/" target="_blank" rel="nofollow noopener noreferrer">FollowUpOptions</a> class provides the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/votingbuttons/" target="_blank" rel="nofollow noopener noreferrer">VotingButtons</a> property that can be used to set or get the voting options. <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> refers to a class within the Aspose.Email namespace that represents an email message in the Messaging Application Programming Interface (MAPI) format commonly used by Microsoft Outlook. By using the MapiMessage class, developers can add polling buttons to an email. This article provides a detailed example of how to create a MapiMessage with voting options to create a poll.

### Create Polls {#create-polls}

The following code snippet demonstrates how to create a poll in an Outlook message using Aspose.Email. The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/" target="_blank" rel="nofollow noopener noreferrer">FollowUpManager</a> class facilitates setting the voting options.

```csharp
// Create a MapiMessage with the sender, recipient, subject, and body
var msg = new MapiMessage(
    "from@test.com",
    "to@test.com",
    "Flagged message",
    "Make it nice and short, but descriptive. The description may appear in search engines' search results pages..."
);

// Create FollowUpOptions and set the voting buttons
var options = new FollowUpOptions
{
    VotingButtons = "Yes;No;Maybe;Exactly!"
};

// Apply the follow-up options to the message
FollowUpManager.SetOptions(msg, options);
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/" target="_blank" rel="nofollow noopener noreferrer">FollowUpOptions</a>: Provides properties to configure follow-up actions such as voting buttons.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/votingbuttons/" target="_blank" rel="nofollow noopener noreferrer">VotingButtons</a>: A string property where different voting options are separated by semicolons.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/setoptions/" target="_blank" rel="nofollow noopener noreferrer">FollowUpManager.SetOptions</a>: Applies the specified follow-up options to the message.

### Read Voting Options {#read-voting-options}

To retrieve voting options from a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a>, you can use the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/getoptions/" target="_blank" rel="nofollow noopener noreferrer">GetOptions</a> method. This method not only retrieves voting buttons but can also provide additional parameters like categories if necessary.

```csharp
// Retrieve follow-up options from the message
var options = FollowUpManager.GetOptions(msg);

// Voting buttons are returned as a string with a semicolon separator
string votingButtons = options.VotingButtons;

// Display the voting buttons
Console.WriteLine($"Voting Options: {votingButtons}");
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/getoptions/" target="_blank" rel="nofollow noopener noreferrer">GetOptions</a>: Retrieves the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/" target="_blank" rel="nofollow noopener noreferrer">FollowUpOptions</a> object from the message, which includes the voting buttons and potentially other properties.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupoptions/votingbuttons/" target="_blank" rel="nofollow noopener noreferrer">VotingButtons</a>: The options are extracted as a semicolon-separated string, allowing for easy display or manipulation.

### Read Voting Buttons {#read-voting-buttons}

If you need to access only voting buttons as a list of individual strings, you can use the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/getvotingbuttons/" target="_blank" rel="nofollow noopener noreferrer">GetVotingButtons</a> method, which returns them as a collection.

```csharp
// Read only voting buttons as a collection of string values
var votingButtons = FollowUpManager.GetVotingButtons(msg);

// Display each voting button
foreach (var button in votingButtons)
{
    Console.WriteLine($"Voting Button: {button}");
}
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/getvotingbuttons/" target="_blank" rel="nofollow noopener noreferrer">GetVotingButtons</a>: Returns a collection of voting button strings, making it convenient to iterate over them and perform operations like displaying or modifying.

### Add Voting Buttons {#add-voting-buttons}

You can add additional voting buttons to an existing message using the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/addvotingbutton/" target="_blank" rel="nofollow noopener noreferrer">AddVotingButton</a> method. This can be useful for dynamically updating the voting options.

```csharp
// Add a new voting button to the existing message
FollowUpManager.AddVotingButton(msg, "Indeed!");
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/addvotingbutton/" target="_blank" rel="nofollow noopener noreferrer">AddVotingButton</a>: Adds a new voting option to the message's existing voting buttons, allowing for dynamic customization of polls.

### Delete Voting Buttons {#delete-voting-buttons}

You may want to remove specific voting buttons or clear all buttons from a message. The following code demonstrates both actions using <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/removevotingbutton/" target="_blank" rel="nofollow noopener noreferrer">RemoveVotingButton</a> and <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/clearvotingbuttons/" target="_blank" rel="nofollow noopener noreferrer">ClearVotingButtons</a> methods.

```csharp
// Delete a specific voting button
FollowUpManager.RemoveVotingButton(msg, "Exactly!");

// Or delete all voting buttons from the MapiMessage
FollowUpManager.ClearVotingButtons(msg);
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/removevotingbutton/" target="_blank" rel="nofollow noopener noreferrer">RemoveVotingButton</a>: Deletes a specific voting button by name.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/clearvotingbuttons/" target="_blank" rel="nofollow noopener noreferrer">ClearVotingButtons</a>: Removes all voting buttons, effectively resetting the voting options.

### Read Vote Results {#read-vote-results}

Aspose.Email also allows reading vote results from a message's recipients. You can access properties like the recipient's response and response time.

```csharp
// Load a MapiMessage from a file
var msg = MapiMessage.Load("sample.msg");

// Iterate through each recipient and display their vote information
foreach (var recipient in msg.Recipients)
{
    Console.WriteLine($"Recipient: {recipient.DisplayName}");

    // Get the recipient's response using the appropriate MapiPropertyTag
    var response = recipient.Properties[MapiPropertyTag.PR_RECIPIENT_AUTORESPONSE_PROP_RESPONSE].GetString();
    Console.WriteLine($"Response: {response}");

    // Get the response time
    var responseTime = recipient.Properties[MapiPropertyTag.PR_RECIPIENT_TRACKSTATUS_TIME].GetDateTime();
    Console.WriteLine($"Response time: {responseTime}\n");
}
```

- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapirecipient/#mapirecipient-class" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a>: Represents a recipient in the MapiMessage, enabling access to individual response data.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapipropertytag/pr_recipient_autoresponse_prop_response/" target="_blank" rel="nofollow noopener noreferrer">PR_RECIPIENT_AUTORESPONSE_PROP_RESPONSE</a>: A property tag that stores the recipient's vote response.
- <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapipropertytag/pr_recipient_trackstatus_time/" target="_blank" rel="nofollow noopener noreferrer">PR_RECIPIENT_TRACKSTATUS_TIME</a>: A property tag that records the time when the recipient responded.

## Retrieve Reaction Information from MSG {#retrieve-reaction-information-from-msg}

The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/getreactions/" target="_blank" rel="nofollow noopener noreferrer">GetReactions</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/followupmanager/" target="_blank" rel="nofollow noopener noreferrer">FollowUpManager</a> class allows you to retrieve a list of reactions on a MAPI message, making it easy to analyze user engagement. The following code sample demonstrates how to retrieve available reactions for a specified message, providing insight into user interactions:

```cs
// Load the message file
var msg = MapiMessage.Load(fileName);

// Retrieve the list of reactions on the message
var reactions = FollowUpManager.GetReactions(msg);

// Iterate through each reaction and output the details to the console
foreach (var reaction in reactions)
{
    Console.WriteLine($"User: {reaction.Name}, Email: {reaction.Email}, Reaction: {reaction.Type}, Date: {reaction.ReactionDateTime}");
}
```

## Create and Save Outlook Notes {#create-and-save-outlook-notes}

Aspose.Email provides the facility to create Outlook notes and save them to disk in MSG format. The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class provides properties and methods for setting note information. This article shows how to create, save and read a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> from the disk.

The following steps can be used to create and save a note to disk:

1. Instantiate an object of the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class.
2. Set various properties.
3. Save the note to disk as an MSG file.

The following code snippet shows you how to create and save an Outlook Note.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Outlook();
// Create MapiNote and set Properties 
MapiNote note3 = new MapiNote();
note3.Subject = "Blue color note";
note3.Body = "This is a blue color note";
note3.Color = NoteColor.Blue;
note3.Height = 500;
note3.Width = 500;
note3.Save(dataDir + "MapiNote_out.msg", NoteSaveFormat.Msg);
```

## Read MAPI Notes {#read-mapi-notes}

The <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class object is used to cast the <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object that loads a note from the disk in MSG format. The following code snippet shows you how to read a <a href="https://reference.aspose.com/email/net/aspose.email.mapi/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a>.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Outlook();
MapiMessage note = MapiMessage.FromFile(dataDir + "MapiNote.msg");
MapiNote note2 = (MapiNote)note.ToMapiMessageItem();
```

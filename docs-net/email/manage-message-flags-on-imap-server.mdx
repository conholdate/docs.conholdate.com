## Set/Change Message Flags {#setchange-message-flags}

You can change message flags by setting new ones with the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/changemessageflags/#changemessageflags/" target="_blank" rel="nofollow noopener noreferrer">ChangeMessageFlags()</a> method. This method takes two parameters.

1. The sequence number of a message or its unique ID.
2. <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/" target="_blank" rel="nofollow noopener noreferrer">MessageFlag</a>.

The following flags can be set:

- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/answered/" target="_blank" rel="nofollow noopener noreferrer">Answered</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/deleted/" target="_blank" rel="nofollow noopener noreferrer">Deleted</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/draft/" target="_blank" rel="nofollow noopener noreferrer">Draft</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/empty/" target="_blank" rel="nofollow noopener noreferrer">Empty</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/flagged/" target="_blank" rel="nofollow noopener noreferrer">Flagged</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/isread/" target="_blank" rel="nofollow noopener noreferrer">IsRead</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/recent/" target="_blank" rel="nofollow noopener noreferrer">Recent</a>

The following code snippet shows you how to change message flags on an IMAP server with Aspose.Email.

```csharp
// Mark the message as read
client.ChangeMessageFlags(1, ImapMessageFlags.IsRead);
```

## Remove Message Flags {#remove-message-flags}

Message flags can also be removed with the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/removemessageflags/#removemessageflags/" target="_blank" rel="nofollow noopener noreferrer">RemoveMessageFlags()</a> method. Usage is similar to that of the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/changemessageflags/#changemessageflags/" target="_blank" rel="nofollow noopener noreferrer">ChangeMessageFlags()</a> method. It takes a sequence number or unique message ID and <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapmessageflags/" target="_blank" rel="nofollow noopener noreferrer">MessageFlag</a>. The following code snippet shows you how to remove message flags.

```csharp
// Remove the message flag
client.RemoveMessageFlags(1, ImapMessageFlags.IsRead);
```

## Set Custom Flags {#set-custom-flags}

You can also set custom flags to a message using the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> of the API. The ImapClient AddMessageFlags provides the ability to set custom flags on messages.

```csharp
// Create a message
MailMessage message = new MailMessage("user@domain1.com", "user@domain2.com", "subject", "message");

//Append the message to mailbox
string uid = client.AppendMessage(ImapFolderInfo.InBox, message);

//Add custom flags to the added messge
client.AddMessageFlags(uid, ImapMessageFlags.Keyword("custom1") | ImapMessageFlags.Keyword("custom1_0"));

//Retreive the messages for checking the presence of custom flag
client.SelectFolder(ImapFolderInfo.InBox);

ImapMessageInfoCollection messageInfos = client.ListMessages();
foreach (var inf in messageInfos)
{
    ImapMessageFlags[] flags = inf.Flags.Split();

    if (inf.ContainsKeyword("custom1"))
        Console.WriteLine("Keyword found");
}
```

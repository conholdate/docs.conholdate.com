## Encrypt/Decrypt Messages {#encryptdecrypt-messages}

Aspose.Email provides the facility to encrypt and decrypt email messages using the X509Certificates. This article shows how an existing or new message can be loaded and encrypted using <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/encrypt/#encrypt/" target="_blank" rel="nofollow noopener noreferrer">Encrypt()</a> and <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/decrypt/#decrypt/" target="_blank" rel="nofollow noopener noreferrer">Decrypt()</a> methods return a <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> object for the applied effects and need to be taken care of while encrypting/decrypting messages. Encrypting and decrypting messages involves the following steps:

1. Create a new message or load an existing one
2. Load an encryption certificate using the X509Certificate object
3. Encrypt the message using the certificate
4. Send the message or save it
5. Decrypt the message as required

The following code snippet shows you how to encrypt and decrypt messages.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_Email();

string publicCertFile = dataDir + "MartinCertificate.cer";
string privateCertFile = dataDir + "MartinCertificate.pfx";

X509Certificate2 publicCert = new X509Certificate2(publicCertFile);
X509Certificate2 privateCert = new X509Certificate2(privateCertFile, "anothertestaccount");

// Create a message
MailMessage msg = new MailMessage("atneostthaecrcount@gmail.com", "atneostthaecrcount@gmail.com", "Test subject", "Test Body");

// Encrypt the message
MailMessage eMsg = msg.Encrypt(publicCert);
if (eMsg.IsEncrypted == true)
    Console.WriteLine("Its encrypted");
else
    Console.WriteLine("Its NOT encrypted");

// Decrypt the message
MailMessage dMsg = eMsg.Decrypt(privateCert);
if (dMsg.IsEncrypted == true)
    Console.WriteLine("Its encrypted");
else
    Console.WriteLine("Its NOT encrypted");
```

### Verify Message Encryption {#verify-message-encryption}

Aspose.Email <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class allows you to check if a message is encrypted or not. The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/isencrypted/" target="_blank" rel="nofollow noopener noreferrer">IsEncrypted</a> property of <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> allows you to check this as shown in the following code sample.

```csharp
MailMessage mailMessageOrig = MailMessage.Load(Path.Combine(dataDir, "Message.msg"), new MsgLoadOptions());
X509Certificate2 publicCert = new X509Certificate2(publicCertFile);
X509Certificate2 privateCert = new X509Certificate2(privateCertFile, "anothertestaccount");

Console.WriteLine("Message is encrypted: {0}" , mailMessageOrig.IsEncrypted);
MailMessage mailMessage = mailMessageOrig.Encrypt(publicCert);
Console.WriteLine("Message is encrypted: {0}", mailMessage.IsEncrypted);
mailMessage = mailMessage.Decrypt(privateCert);
Console.WriteLine("Message is encrypted: {0}", mailMessage.IsEncrypted);
```

## Checking Secure Emails Signature {#checking-secure-emails-signature}

The <a href="https://reference.aspose.com/email/net/aspose.email/secureemailmanager/#secureemailmanager-class" target="_blank" rel="nofollow noopener noreferrer">SecureEmailManager</a> class allows you to check the signature of secure MailMessage objects.

The <a href="https://reference.aspose.com/email/net/aspose.email/smimeresult/#smimeresult-class" target="_blank" rel="nofollow noopener noreferrer">SmimeResult</a> class stores the results of the check.

The following methods of the <a href="https://reference.aspose.com/email/net/aspose.email/secureemailmanager/#secureemailmanager-class" target="_blank" rel="nofollow noopener noreferrer">SecureEmailManager</a> class and a code snippet will enable you to process a signature:

- <a href="https://reference.aspose.com/email/net/aspose.email/secureemailmanager/checksignature/#checksignature" target="_blank" rel="nofollow noopener noreferrer">SecureEmailManager.CheckSignature(MailMessage msg)</a> method.
- <a href="https://reference.aspose.com/email/net/aspose.email/secureemailmanager/checksignature/#checksignature_1" target="_blank" rel="nofollow noopener noreferrer">SecureEmailManager.CheckSignature(MailMessage msg, X509Certificate2 certificateForDecrypt)</a> method.
- <a href="https://reference.aspose.com/email/net/aspose.email/secureemailmanager/checksignature/#checksignature_2" target="_blank" rel="nofollow noopener noreferrer">SecureEmailManager.CheckSignature(MailMessage msg, X509Certificate2 certificateForDecrypt, X509Store store)</a> method.

Check the signature of a message without providing a certificate:

```cs
var eml = MailMessage.Load(fileName);
var result = new SecureEmailManager().CheckSignature(eml);
```

Check the signature of an encrypted message by providing the certificate for decryption and the store that holds the certificates used for the verification:

```cs
var certFileName = "cert.pfx";
var cert = new X509Certificate2(certFileName, "pass");
var eml = MailMessage.Load(fileName);

var store = new X509Store();
store.Open(OpenFlags.ReadWrite);
store.Add(cert);
store.Close();

var result = new SecureEmailManager().CheckSignature(eml, cert, store);
```

## Sign Emails with DKIM {#sign-emails-with-dkim}

:::info
**_NOTE:_** The feature is accessible only for the library versions targeting .NET Framework. Versions targeting .NET Core do not have this feature.
:::

Aspose.Email allows signing Email with DKIM (DomainKeys Identified Mail). This lets an organization take responsibility for a message that is in transit (<a href="https://www.dkim.org/" target="_blank" rel="nofollow noopener noreferrer">More Info</a>). DKIM adds a digital signature to the email message headers that can be validated by recipients. The public key of the sender enables the receiver to verify that the signature matches the message's contents. The <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/dkimsign/#dkimsign" target="_blank" rel="nofollow noopener noreferrer">DKIMSign</a> method of the <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class is used to set the cryptographic and signature information for signing the message. The following code snippet shows you how to sign emails with DKIM.

```cs
var eml = new MailMessage("sender@gmail.com", "receiver@gmail.com", "Some subject", "Some body text");

string privateKeyFile = "key2.pem";
RSACryptoServiceProvider rsa = PemReader.GetPrivateKey(privateKeyFile);
DKIMSignatureInfo signInfo = new DKIMSignatureInfo("test", "somedomain.com");

var signedEml = eml.DKIMSign(rsa, signInfo);
```

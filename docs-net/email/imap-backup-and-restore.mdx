## Standard Backup and Restore {#standard-backup-and-restore}

Aspose.Email for .NET provides the ability to backup and restore messages. For this, the API provides the following methods.

- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/backup/#backup/" target="_blank" rel="nofollow noopener noreferrer">ImapClient.Backup</a>
- <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/restore/" target="_blank" rel="nofollow noopener noreferrer">ImapClient.Restore</a>

This article demonstrates how to backup and restore messages using the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class.

### Backup Messages {#backup-messages}

To backup messages, use the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/backup/#backup/" target="_blank" rel="nofollow noopener noreferrer">ImapClient.Backup</a> method as demonstrated in the following code snippet.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_IMAP();
// Create an instance of the ImapClient class
ImapClient imapClient = new ImapClient();

// Specify host, username and password, and set port for your client
imapClient.Host = "imap.gmail.com";
imapClient.Username = "your.username@gmail.com";
imapClient.Password = "your.password";
imapClient.Port = 993;
imapClient.SecurityOptions = SecurityOptions.Auto;

ImapMailboxInfo mailboxInfo = imapClient.MailboxInfo;

ImapFolderInfo info = imapClient.GetFolderInfo(mailboxInfo.Inbox.Name);
ImapFolderInfoCollection infos = new ImapFolderInfoCollection();
infos.Add(info);

imapClient.Backup(infos, dataDir + @"\ImapBackup.pst", BackupOptions.Recursive);
```

### Restore Messages {#restore-messages}

To restore messages, use the <a href="https://reference.aspose.com/email/net/aspose.email.clients.imap/imapclient/restore/" target="_blank" rel="nofollow noopener noreferrer">ImapClient.Restore</a> method as demonstrated in the following code snippet.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_IMAP();
// Create an instance of the ImapClient class
ImapClient imapClient = new ImapClient();

// Specify host, username and password, and set port for your client
imapClient.Host = "imap.gmail.com";
imapClient.Username = "your.username@gmail.com";
imapClient.Password = "your.password";
imapClient.Port = 993;
imapClient.SecurityOptions = SecurityOptions.Auto;

RestoreSettings settings = new RestoreSettings();
settings.Recursive = true;
PersonalStorage pst = PersonalStorage.FromFile(dataDir + @"\ImapBackup.pst");
imapClient.Restore(pst, settings);
```

## IMAP Backup and Restore with MultiConnection {#imap-backup-and-restore-with-multiconnection}

When working with a large number of messages, the backup/restore operation can take a long time. For this, the API provides support for multiple connections during backup and restore operation. To enable the MultiConnection mode, set <a href="https://reference.aspose.com/email/net/aspose.email.clients/emailclient/usemulticonnection/" target="_blank" rel="nofollow noopener noreferrer">ImapClient.UseMultiConnection</a> property to <a href="https://reference.aspose.com/email/net/aspose.email.clients/multiconnectionmode/" target="_blank" rel="nofollow noopener noreferrer">MultiConnectionMode.Enable</a>. The following code snippets demonstrate backup and restore operation with MultiConnection mode enabled.

The following code snippets demonstrate **backup operation** with MultiConnection mode enabled.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_IMAP();
// Create an instance of the ImapClient class
ImapClient imapClient = new ImapClient();

// Specify host, username and password, and set port for your client
imapClient.Host = "imap.gmail.com";
imapClient.Username = "your.username@gmail.com";
imapClient.Password = "your.password";
imapClient.Port = 993;
imapClient.SecurityOptions = SecurityOptions.Auto;

imapClient.UseMultiConnection = MultiConnectionMode.Enable;

ImapMailboxInfo mailboxInfo = imapClient.MailboxInfo;

ImapFolderInfo info = imapClient.GetFolderInfo(mailboxInfo.Inbox.Name);
ImapFolderInfoCollection infos = new ImapFolderInfoCollection();
infos.Add(info);

imapClient.Backup(infos, dataDir + @"\ImapBackup.pst", BackupOptions.Recursive);
```

The following code snippets demonstrate **restore operation** with MultiConnection mode enabled.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_IMAP();
// Create an instance of the ImapClient class
ImapClient imapClient = new ImapClient();

// Specify host, username and password, and set port for your client

imapClient.Username = "your.username@gmail.com";
imapClient.Password = "your.password";
imapClient.Port = 993;
imapClient.SecurityOptions = SecurityOptions.Auto;

imapClient.UseMultiConnection = MultiConnectionMode.Enable;

settings.Recursive = true;
PersonalStorage pst = PersonalStorage.FromFile(dataDir + @"\Outlook.pst");
imapClient.Restore(pst, settings);
```

When you save a file using the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Annotator.Save()</a> method, the GroupDocs.Annotations creates a version of the annotated file. Versions list keeps annotations that you add, remove, and change. You can swap between different changes made with GroupDocs.Annotation. If needed, you can set custom version names.

By default, GroupDocs.Annotations names version using a GUID. If needed, you can specify a custom version name.

### Add version with custom name

You can specify a custom version name.
  
The following code snippet shows how to save version with custom name:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	annotator.Update(new AreaAnnotation{ Box = new Rectangle(100, 100, 100, 100) });
	annotator.Save("result.pdf", new SaveOptions { Version = "CUSTOM_VERSION" });
}
```

</TabItem>


</Tabs>



:::info
The <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/version" target="_blank" rel="nofollow noopener noreferrer">Version</a> property is object.
:::


## Get the list of version keys of a file

To get the list of version keys, call the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">GetVersionsList</a> method of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class.

The following code snippet shows how to get list of versions keys:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.pdf")) { 
      List<object> versionKeys = annotator.GetVersionsList();
}
```

</TabItem>


</Tabs>



:::info
The <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">Annotator.GetVersionsList()</a> method returns list of objects. If needed, you can convert them to appropriate type.
:::


## Get the list of annotations using version key

To get the list of annotations in a specific version, call the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">Annotator.GetVersion()</a> method of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class.

The following code snippets shows how to get list of annotations in a specific version:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.pdf"))
{
    List<AnnotationBase> annotations = annotator.GetVersion("CUSTOM_VERSION");
}
```

</TabItem>


</Tabs>



:::info
The <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">GetVersion</a> method returns list of objects. If needed, you can convert them to appropriate type.
:::


## Load a specific file version

To load a specific version of a file, specify the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions/properties/version" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.Version</a> property.

The following code snippets shows how load version using version property:


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
 using (Annotator annotator = new Annotator($"result.{ext}", new LoadOptions { Version = "CUSTOM_VERSION" }))
{
	annotator.Save("result_loaded.pdf");
}
```

</TabItem>


</Tabs>

GroupDocs.Annotation v21.5 and later allows you to generate preview for documents using custom fonts. To do this, specify the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions/properties/fontdirectories" target="_blank" rel="nofollow noopener noreferrer">FontDirectories</a> property of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class.

The following code snippet shows how to use custom fonts while generating preview:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator(fs, new LoadOptions { FontDirectories = new List<string> { $"D:/fonts" } }))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });

    annotator.Document.GeneratePreview(previewOptions);
}
```

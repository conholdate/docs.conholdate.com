<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to annotate documents that are protected with a password.

To load a password protected file, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the document path or stream.
2. Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class. Specify the source document password as a parameter.

The following code snippet shows how to load a password protected file:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf", new LoadOptions() { Password = "1234" }))
{
 	AreaAnnotation area = new AreaAnnotation()
    {
       	Box = new Rectangle(100, 100, 100, 100),
       	BackgroundColor = 65535,
    };
    annotator.Add(area);
    annotator.Save("result.pdf");
}
```

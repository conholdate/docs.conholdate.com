GroupDocs.Annotation v21.5 and later allows you to set resolution of the document's preview. By default, it is 96 points per inch. Set the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a> property of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class to change the resolution.

The following code snippets shows how to set preview resolution to 144 PPI:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"result_{pageNumber}.png";
        return File.Create(pagePath);
    })
    {
        // Set resolution
        Resolution = 144
    };

    annotator.Document.GeneratePreview(previewOptions);
}
```

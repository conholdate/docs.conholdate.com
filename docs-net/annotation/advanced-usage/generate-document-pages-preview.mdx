<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to generate document page previews. To do this, call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> class. 

Use the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class to manage the generation process: specify desired page numbers, image format, etc.

To generate a document preview, follow these steps:
1.  Create an instance of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the source document path as a parameter. The <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> property of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class provides access to source document and implements <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method.
3.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class. Follow these steps:
    a.   for each page, delegate stream creation (see the `CreatePageStream` event handler); 
    b.   specify the image preview format - PNG / JPG / BMP,
    c.   specify page numbers to process;
    d.   set the custom size of preview images (if needed).  

:::info
Stream created by the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> delegate are disposed automatically once after generation of preview image. To implement the custom image preview stream disposing, you have to specify an additional argument <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> to clean up resources.
:::
       
4.  Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Annotator.Document</a> class. Specify <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>.

    
The <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> class main properties are as follows:
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> is a delegate which defines the method to create output page preview stream.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> is a delegate which defines the method to remove output page preview stream. Use it for advanced control for resources handling.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> specifies the preview image width.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> specifies the preview image height.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/pagenumbers" target="_blank" rel="nofollow noopener noreferrer">PageNumbers</a> - Page numbers that will be previewed;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/previewformat" target="_blank" rel="nofollow noopener noreferrer">PreviewFormat</a> gets or sets the preview image format. Use the BMP format should be used for the best image quality. Use the JPG format in case of strict requirements to image size, but with lower quality than BMP. By default GroupDocs.Annotation uses the PNG format which is a golden mean between image quality and size.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/rendercomments" target="_blank" rel="nofollow noopener noreferrer">RenderComments</a> is an option to show or hide comments. By default it is `true`. Set it to `false` if you do not need to show comments. This property affects only on WordProcessing documents. The `RenderComments` value impacts any document comments.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/renderannotations" target="_blank" rel="nofollow noopener noreferrer">RenderAnnotations</a> is an option to show or hide annotations.By default it is `true`. Set it to `false` if you do not need to show annotations.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/worksheetcolumns" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumns</a> is a list of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/worksheetcolumnsrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumnsRange</a> objects that indicates which columns to generate on specified worksheet.

The following code snippet demonstrates how to generate document previews:

## Get document page previews 


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
    annotator.Document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Set specific size for preview images

You can set a specific size for preview images. For example, you can create small-sized thumbnails and full-sized previews.

The following code snippet shows how to set specific size for preview images:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
	previewOptions.Height = 100;
    previewOptions.Width = 80;
    annotator.Document.GeneratePreview(previewOptions);   
}

```

</TabItem>

## Get page previews with manual resource cleaning

By default, GroupDocs.Annotation deletes the image stream immediately after creating and rendering the document page. If necessary, you can implement a custom method to perform this operation.


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
// Method should match with ReleasePageStream delegate signature
private void UserReleaseStreamMethod(int pageNumber, Stream stream)
{
	Console.WriteLine($"Releasing memory for page: {pageNumber}");
    stream.Close();
}
 
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
	previewOptions.Height = 100;
    previewOptions.Width = 80;
 
    // here we set delegate target method
    previewOptions.ReleasePageStream = UserReleaseStreamMethod;
    annotator.Document.GeneratePreview(previewOptions);   
}
```

</TabItem>


</Tabs>


## Show and hide replies for WordsProcessing documents

Use the boolean <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/rendercomments/" target="_blank" rel="nofollow noopener noreferrer">RenderComments</a> property to show comments when rendering image preview.


:::info
This feature is supported for WordProcessign documents only.
:::


The default value of the property is `true`. To hide comments, set it to `false`. This property applies to all comments.

The following code snippet shows how to render an image preview without comments:


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
Annotator annotator = new Annotator(File.OpenRead(MakeStoragePath(inputPath)));
           PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
           {
               var pagePath = MakeStoragePath(inputPath.Replace("input.doc", $"result{pageNumber}.png"));
               return File.Create(pagePath);
           });
previewOptions.PreviewFormat = PreviewFormats.PNG;
previewOptions.RenderComments = false;
annotator.Document.GeneratePreview(previewOptions);
```

</TabItem>


</Tabs>


## Generate cells preview with specified columns

GroupDocs.Annotation v20.11 and later allows you to specify the columns you want to generate on the sheet you selected. To do this, use the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/worksheetcolumns" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumns</a> property.


:::info
This feature is supported for CellsProcessign documents only.
:::


The following code snippet shows how to set the list of columns to render:


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
PreviewOptions previewOptions =
    new PreviewOptions(pageNumber => new FileStream($"preview_pages/page{pageNumber}.png", FileMode.Create),
        (number, stream) => stream.Dispose());
previewOptions.WorksheetColumns.Add(new WorksheetColumnsRange("Sheet1", 2, 3));
previewOptions.WorksheetColumns.Add(new WorksheetColumnsRange("Sheet1", 1, 1));

using (Annotator annotator = new Annotator("input.xlsx"))
{
    annotator.Document.GeneratePreview(previewOptions);
}
```

</TabItem>

To export the specific page range, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class. Specify the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/firstpage/" target="_blank" rel="nofollow noopener noreferrer">FirstPage</a> and  <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/lastpage/" target="_blank" rel="nofollow noopener noreferrer">LastPage</a> parameters.
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method with the output document path or stream. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class as a parameter.

The following code demonstrates how to save the range of document page:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// for this example input document ("input.pdf") must have at least 4 pages
using (Annotator annotator = new Annotator("input.pdf"))
{
	//Result file will be contain only 3 pages (2, 3 and 4 page)
	annotator.Save("result.pdf", new SaveOptions { FirstPage = 2, LastPage = 4 });
}
```

The <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class provides the following properties to customize the saving process:
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/annotationtypes" target="_blank" rel="nofollow noopener noreferrer">AnnotationTypes</a> defines annotation types to be saved into output document;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/firstpage" target="_blank" rel="nofollow noopener noreferrer">FirstPage</a> defines the first page number to save specific page range;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/lastpage" target="_blank" rel="nofollow noopener noreferrer">LastPage</a> defines the last page number to save specific page range;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/onlyannotatedpages" target="_blank" rel="nofollow noopener noreferrer">OnlyAnnotatedPages</a> indicates whether to save only annotated pages or not.

We offer multiple solutions on how you can run GroupDocs.Annotation examples, by building your own or using our back-end or front-end examples out-of-the-box.

## Build project from scratch

To build a project from scratch, follow these steps:

1.   Open Visual Studio and navigate to **File** -> **New **\->** Project**.
2.   Select the appropriate project type - Console App, ASP.NET Web App etc.
3.   Install **GroupDocs.Annotation for .NET** from NuGet or official GroupDocs website as described in the [guide](/net/annotation/getting-started/installation/).
4.   Develop the application using **GroupDocs.Annotation for .NET** like this:

<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// Create list of annotations
List<AnnotationBase> annotations = new List<AnnotationBase>()
{
    new AreaAnnotation()
    {
        PageNumber = 0,
        Box = new Rectangle(100, 100, 100, 100),
        Message = "area"
    },
                
    new EllipseAnnotation()
        {
            PageNumber = 0,
            Box = new Rectangle(200, 200, 80, 80),
            Message = "ellipse"
        }
};

// Create annotator
using  (Annotator annotator = new Annotator("C:\output\input.pdf"))
{
    // Add annotations
    annotator.Add(annotations);
    // Save result to "C:\output\result.pdf"
    annotator.Save("C:\output\result.pdf", new SaveOptions());
}
```

</TabItem>


</Tabs>

5.   Build and run your project. 
6.   Rendered document pages appears in the `C:\\output\\` directory.

## Run back-end examples

You can find the complete package of the **GroupDocs.Annotation** examples on <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. You can either <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">download the ZIP file</a> or clone the GitHub repository using your any git client.  
If you downloaded the ZIP file, extract the folders to the local disk. The extracted files and folders look as follows:

![](/net/annotation/images/how-to-run-examples.png)

Find the CSharp solution file. The project is created in **Microsoft Visual Studio 2019**. The `Resources` folder contains all the sample documents and images used in the examples.  
To run the examples, open the solution file with Visual Studio and build the project. If needed, add missing references of GroupDocs.Annotation. All the functions are called in the **RunExamples.cs** file. Uncomment the function(s) you want to run and comment the rest.

![](/net/annotation/images/how-to-run-examples_1.png)

## Run MVC examples

To run the <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation for .NET MVC Example</a>, follow these steps:

1.   Download the <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">source code</a> from GitHub or clone the repository: 

<Tabs groupId="example2">


<TabItem value="git" label="Git" default>

```bash
git clone https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC
```

</TabItem>


</Tabs>

2.   Open solution with the Visual Studio. Update common parameters in **web.config** and example related properties in **configuration.yml** to meet your requirements.  
3.   Open <a href="http://localhost:8080/annotation" target="_blank" rel="nofollow noopener noreferrer">http://localhost:8080/annotation</a> in your favorite browser.

For details about project configuration please refer to this <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC#configuration" target="_blank" rel="nofollow noopener noreferrer">guide</a>.

## Run from Docker

Use the <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> image to try GroupDocs.Annotation for .NET features. Execute the following commands to run GroupDocs.Annotation for .NET from docker image:

<Tabs groupId="example4">


<TabItem value="powershell" label="PowerShell" default>

```
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples -v `pwd`/Licenses:/home/groupdocs/app/Licenses groupdocs/annotation
## Open http://localhost:8080/annotation in your favorite browser.
```

</TabItem>


</Tabs>

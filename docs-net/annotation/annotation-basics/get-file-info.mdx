GroupDocs.Annotation allows you to get the following file information:

*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> is a document file type (PDF, Word document, Excel spreadsheet, PowerPoint presentation or image etc.)
*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> is a count of document pages
*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">FileSize</a> is a file size;

<a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/idocumentinfo/properties/pagesinfo" target="_blank" rel="nofollow noopener noreferrer">PagesInfo</a> represents a `List` of the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a> objects which store information about each page. 

<a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a> has the following properties (in pixels):
* <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>
* <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> in pixels. 

This properties supports all formats except Email and Html. Width and height are the same for all pages except the Cells formats.

The following code snippet shows how to get information about a document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Get file info for the file from local disk
using (Annotator annotator = new Annotator("input.docx"))
{
	IDocumentInfo info = annotator.Document.GetDocumentInfo();
    int width = info.PagesInfo[0].Width;
    int height = info.PagesInfo[0].Height;
    Console.WriteLine("\nFile type: {0}\nNumber of pages: {1}\nDocument size: {2} bytes", info.FileType, info.PageCount, info.Size);
}
```

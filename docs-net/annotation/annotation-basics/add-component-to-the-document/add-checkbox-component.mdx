Checkbox component creates a checkbox as shown in the picture below: 

![](/net/annotation/images/add-checkbox-component.png)

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.formatspecificcomponents.pdf/checkboxcomponent" target="_blank" rel="nofollow noopener noreferrer">CheckBoxComponent</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.formatspecificcomponents.pdf/checkboxcomponent/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines the annotation position
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.formatspecificcomponents.pdf/checkboxcomponent/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> defines the frame color

To add a checkbox component, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.formatspecificcomponents.pdf/checkboxcomponent" target="_blank" rel="nofollow noopener noreferrer">CheckboxComponent</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.formatspecificcomponents.pdf/checkboxcomponent" target="_blank" rel="nofollow noopener noreferrer">CheckboxComponent</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.formatspecificcomponents.pdf/cropdowncomponent" target="_blank" rel="nofollow noopener noreferrer">CheckboxComponent</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	CheckBoxComponent checkbox = new CheckBoxComponent
    {
        Checked = true,
        Box = new Rectangle(100, 100, 100, 100),
        PenColor = 65535,
        Style = BoxStyle.Star,
        Replies = new List<Reply>
            {
                new Reply
                {
                    Comment = "First comment",
                    RepliedOn = DateTime.Now
                },
                new Reply
                {
                    Comment = "Second comment",
                    RepliedOn = DateTime.Now
                }
            }
    };
    annotator.Add(checkbox);
    annotator.Save("result.pdf");
}
```

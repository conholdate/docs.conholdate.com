<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to update annotation replies by accessing them using the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/annotationbase/properties/replies" target="_blank" rel="nofollow noopener noreferrer">Replies</a> collection.

To update annotation replies, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Call the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class to get collection of the document annotations.
3.   Access a reply object in the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/annotationbase/properties/replies" target="_blank" rel="nofollow noopener noreferrer">Replies</a> collection using its index (zero-based) and update its properties.
4.   Call the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/update" target="_blank" rel="nofollow noopener noreferrer">Update</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify annotations.
5.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream and the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class.
    

The following code snippet shows how to update reply by index: 


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("result.pdf"))
{
	// Obtain annotations collection from document
	List<AnnotationBase> annotations = annotator.Get();
                
	// Update first annotation first reply
	annotations[0].Replies[0].Comment = "Updated reply";
                
	// Save changes
	annotator.Update(annotations);
	annotator.Save("result.pdf");
}
```

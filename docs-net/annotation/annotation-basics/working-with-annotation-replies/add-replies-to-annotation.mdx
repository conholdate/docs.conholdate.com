<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to collaborate over document using annotations and annotation replies. 
  
To update an annotation reply, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/user" target="_blank" rel="nofollow noopener noreferrer">User</a> class.
3.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/reply" target="_blank" rel="nofollow noopener noreferrer">Reply</a> class(es).
4.   Instantiate the annotation object of the appropriate type. Available annotation types are listed <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels" target="_blank" rel="nofollow noopener noreferrer">here</a>.
5.   Assign the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/user" target="_blank" rel="nofollow noopener noreferrer">User</a> class to `Reply.User` property (by default it is "Guest").
6.   Assign the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/reply" target="_blank" rel="nofollow noopener noreferrer">Reply</a> class(es) to the `Replies` collection created at previous steps.
7.   Call the  <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the annotation.
8.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

The following code snippet shows how to add replies to annotation:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	User user1 = new User
	{
		Id = 1,
		Name = "Tom",
		Email = "somemail@mail.com"
	};
	User user2 = new User
	{
		Id = 2,
		Name = "Jack",
		Email = "somebody@mail.com"
	};
	AreaAnnotation area = new AreaAnnotation
	{
		Box = new Rectangle(100, 100, 100, 100),
		CreatedOn = DateTime.Now,
		Message = "This is an area annotation",
		PageNumber = 0,
		Replies = new List<Reply>
		{
			new Reply
			{
				Id = 1,
				Comment = "First comment",
				RepliedOn = DateTime.Now,
				User = user1
			},
			new Reply
			{
				Id = 2,
				Comment = "Second comment",
				RepliedOn = DateTime.Now,
				User = user2,
			}
		}
	};
annotator.Add(area);
annotator.Save("result.pdf");
}
```

You can remove specific or all replies using the <a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> API. To do this, remove the appropriate items from the <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1" target="_blank" rel="nofollow noopener noreferrer">List&lt;T&gt;</a> collection. 

To delete an annotation reply (replies), follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Call the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class to get collection of document annotations.
3.   Access the appropriate annotation and remove a reply in a suitable way:
    *   call the <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.removeat" target="_blank" rel="nofollow noopener noreferrer">RemoveAt(Int32)</a> or <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.remove" target="_blank" rel="nofollow noopener noreferrer">Remove(T)</a> method to remove specific reply;
    *   call the <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.removeall" target="_blank" rel="nofollow noopener noreferrer">RemoveAll(Predicate&lt;T&gt;)</a> method to remove all replies that match the conditions defined by the  predicate.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/update/index" target="_blank" rel="nofollow noopener noreferrer">Update</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the annotations collection.
5.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.
    

## Remove specific annotation reply 

The following code snippet shows how to remove annotation reply by its index:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("result.pdf"))
{
    // Obtain annotations collection from document
    List<AnnotationBase> annotations = annotator.Get();               
	// Remove first reply 
	annotations[0].Replies.RemoveAt(0);
	// Save changes
	annotator.Update(annotations);
	annotator.Save("result.pdf");
}
```

</TabItem>


</Tabs>


## Remove annotation replies by criteria

The following code snippet shows how to remove replies that match some criteria:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("annotated_file_with_replies.pdf"))
{
    // Obtain annotations collection from document
    List<AnnotationBase> annotations = annotator.Get();
    // Remove all replies where author name is "Tom"
    annotations[0].Replies.RemoveAll(x => x.User.Name == "Tom");
    // Save changes
    annotator.Update(annotations);
    annotator.Save("result.pdf");
}
```

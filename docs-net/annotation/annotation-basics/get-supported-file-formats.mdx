<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to get the list of supported file formats. To do this, follow these steps:

1.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> method of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class.
2.   Enumerate through the collection of <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> objects.

The following code snippet shows how to get supported file formats list:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

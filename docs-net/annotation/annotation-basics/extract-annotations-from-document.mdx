<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to extract annotations from a document and serialize them to the XML format.  

To do this, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> class and set `ImportAnnotation = true`.
3.   Define a variable of the `List&lt;AnnotationBase&gt;` type.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> method to get result to variable defined on the previous step.
5.   Instantiate the `XmlSerializer` class with the `List&lt;AnnotationBase&gt;` type.
6.   Using `FileStream` object, serialize annotations to the file.

The following code snippet shows how to extract annotations from a document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// for using this example input file ("annotated.pdf") must have annotations
using (Annotator annotator = new Annotator("annotated.pdf"))
{
	List<AnnotationBase> annotations = annotator.Get();
    XmlSerializer formatter = new XmlSerializer(typeof(List<AnnotationBase>));
    using (FileStream fs = new FileStream("annotations.xml", FileMode.Create))
    {
    	fs.SetLength(0);
        formatter.Serialize(fs, annotations);
    }
}
```

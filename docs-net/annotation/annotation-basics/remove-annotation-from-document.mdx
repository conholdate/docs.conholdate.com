<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> allows you to remove all previously added annotations. To do this, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class. Set `AnnotationTypes = AnnotationType.None`.
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

## Remove annotation using its index

The following code snippet shows how to remove annotation using its index:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	annotator.Remove(0);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>


## Remove annotation using the object

The following code snippet shows how to remove annotation using the object:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	var tmp = annotator.Get();
	annotator.Remove(tmp[0]);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>


## Remove annotations using the list of indexes

The following code snippet shows how to remove annotations using list of indexes:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	var idList = new List<int>{1, 2, 3};
	annotator.Remove(idList);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>

The following code snippet shows how to remove some annotations from document using list of objects:

<TabItem value="c" label="C#" default>

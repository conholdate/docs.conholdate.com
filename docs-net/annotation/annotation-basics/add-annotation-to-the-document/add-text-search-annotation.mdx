Search text annotation searches for specific text and highlight it as shown in the picture below:

![](/net/annotation/images/add-text-search-annotation.png)
                          

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> defines the area background color
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> defines the text to be found. If the document does not contain the specific text, nothing will be highlighted
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> defines the color of the text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontfamily" target="_blank" rel="nofollow noopener noreferrer">FontFamily</a> defines the name of text font
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontsize" target="_blank" rel="nofollow noopener noreferrer">FontSize</a> defines the text font size

To add a search text annotation, follow these steps: 

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchText</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

The following code snippet shows demonstrates how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add search text annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	SearchTextFragment searchText = new SearchTextFragment()
    {
    	Text = "Welcome to GroupDocs", //If the document does not contain this text, nothing will be highlighted
        FontSize = 10,
        FontFamily = "Calibri",
        FontColor = 65535,
        BackgroundColor = 16761035,
	};
    annotator.Add(searchText);
    annotator.Save("result.pdf");
} 
```

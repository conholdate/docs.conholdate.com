Text field annotation adds a rectangle with a text inside as shown in the picture below:

![](/net/annotation/images/add-text-field-annotation.png)

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> defines the area background color
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines the annotation position at the document page
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> defines the text to place in the rectangle
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> defines the color of the text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontfamily" target="_blank" rel="nofollow noopener noreferrer">FontFamily</a> defines the name of the text font
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontsize" target="_blank" rel="nofollow noopener noreferrer">FontSize</a> defines the size of the text font
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> allows you to set the annotation opacity
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> defines the frame line style (solid, dash, dot etc.)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> - defines frame line width in pixels
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> defines the frame color
*   [TextHorizontalAlignment]() defines the text horizontal alignment

To add a text field annotation, follow these steps: 

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.  

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add text field annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	TextFieldAnnotation textField = new TextFieldAnnotation
    {
    	BackgroundColor = 65535,
        Box = new Rectangle(100, 100, 100, 100),
        CreatedOn = DateTime.Now,
        Text = "Some text",
        FontColor = 65535,
        FontSize = 12,
        Message = "This is text field annotation",
        Opacity = 0.7,
        PageNumber = 0,
        PenStyle = PenStyle.Dot,
        PenWidth = 3,
        FontFamily = "Arial",
        TextHorizontalAlignment = HorizontalAlignment.Center,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
	};
    annotator.Add(textField);
    annotator.Save("result.pdf");
} 
```

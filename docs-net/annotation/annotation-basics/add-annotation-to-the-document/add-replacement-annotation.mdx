Replacement annotation replaces original text with specified text fragmentas shown in the picture below: 

![](/net/annotation/images/add-replacement-annotation.png)

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> defines the color of annotation text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> allows you to set the annotation opacity
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/points" target="_blank" rel="nofollow noopener noreferrer">Points</a> defines the annotation positions as array of points
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/texttoreplace" target="_blank" rel="nofollow noopener noreferrer">TextToReplace</a> defines the replacement text   
     

To add a replacement annotation, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a> class.
4.  Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream. 

  

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add replacement annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	ReplacementAnnotation replacement = new ReplacementAnnotation
    {
    	CreatedOn = DateTime.Now,
        FontColor = 65535,
        Message = "This is replacement annotation",
        Opacity = 0.7,
        PageNumber = 0,
        FontSize = 11,
        Points = new List<Point>
        {
        	new Point(80, 730), new Point(240, 730), new Point(80, 650), new Point(240, 650)
        },
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
                Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
         },
         TextToReplace = "replaced text"
     };
     annotator.Add(replacement);
     annotator.Save("result.pdf");
}
```

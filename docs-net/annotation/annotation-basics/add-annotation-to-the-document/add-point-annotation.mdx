Point annotation sticks comments to any point in a document as shown in the picture below:

![](/net/annotation/images/add-point-annotation.png)

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/pointannotation" target="_blank" rel="nofollow noopener noreferrer">PointAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/pointannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines the annotation position on the page
    

To add a point annotation, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/pointannotation" target="_blank" rel="nofollow noopener noreferrer">PointAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/pointannotation" target="_blank" rel="nofollow noopener noreferrer">PointAnnotation</a> class.
4.  Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream. 

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/pointannotation" target="_blank" rel="nofollow noopener noreferrer">PointAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add point annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	PointAnnotation point = new PointAnnotation
    {
    	Box = new Rectangle(100, 100, 0, 0),
        CreatedOn = DateTime.Now,
        Message = "This is point annotation",
        PageNumber = 0,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
             	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(point);
    annotator.Save("result.pdf"));
} 
```

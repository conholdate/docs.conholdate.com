Watermark annotation adds text watermark as shown in the picture below:

![](/net/annotation/images/add-watermark-annotation.png)

You can specify the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/watermarkannotation" target="_blank" rel="nofollow noopener noreferrer">WatermarkAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines the annotation position at the document page
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> defines the watermark text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> defines the color of the annotation text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/fontfamily" target="_blank" rel="nofollow noopener noreferrer">FontFamily</a> defines the font of the annotation text
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/fontsize" target="_blank" rel="nofollow noopener noreferrer">FontSize</a> defines the text font size. If the `AutoScale` property is `true`, GroupDocs.Annotation ignores this property
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> allows you to set the annotation opacity
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/properties/angle" target="_blank" rel="nofollow noopener noreferrer">Angle</a> defines the watermark text angle
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/verticalalignment/" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>  defines the vertical alignment
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/horizontalalignment/" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> defines the horizontal alignment
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/watermarkannotation/autoscale/" target="_blank" rel="nofollow noopener noreferrer">AutoScale</a> sets the watermark size  depending on the word length and the page size. If this property is `true`, GroupDocs.Annotation ignores the `FontSize` property

To add a watermark annotation, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/watermarkannotation" target="_blank" rel="nofollow noopener noreferrer">WatermarkAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/watermarkannotation" target="_blank" rel="nofollow noopener noreferrer">WatermarkAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

  

The following code snippet shows demonstrates how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/watermarkannotation" target="_blank" rel="nofollow noopener noreferrer">WatermarkAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add watermark annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	WatermarkAnnotation watermark = new WatermarkAnnotation
    {
    	Angle = 75,
        Box = new Rectangle(200, 200, 100, 50),
        CreatedOn = DateTime.Now,
        Text = "Watermark",
        FontColor = 65535,
        FontSize = 12,
        Message = "This is watermark annotation",
        Opacity = 0.7,
        AutoScale = true,
        HorizontalAlignment = HorizontalAlignment.Center,
        VerticalAlignment = VerticalAlignment.Center,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(watermark);
    annotator.Save("result.pdf");
} 
```

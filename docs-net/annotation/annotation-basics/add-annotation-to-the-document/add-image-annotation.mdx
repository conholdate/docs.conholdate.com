Image annotation allows you to add an image on document page as shown in the picture below:

![](/net/annotation/images/add-image-annotation.png)

You can set the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/imagepath" target="_blank" rel="nofollow noopener noreferrer">ImagePath</a> defines the image local or remote path
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines the annotation position on the page using the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> structure (image will be resized for specified width and height)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> allows you to set the annotation opacity (present in all supported formats, examples of it you can see above)
*   [Angle]() defines the annotation rotation angle

To add an image annotation, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
            {
                ImageAnnotation area = new ImageAnnotation
                {
                    Box = new Rectangle(100, 100, 100, 100),
                    Opacity = 0.7,
                    PageNumber = 0,
                    ImagePath = "www.google.com.ua/images/branding/googlelogo/2x/googlelogo_color_92x30dp.png",
                    Angle = 100
                };
                annotator.Add(area);
                annotator.Save("result.pdf");
            }
```

Distance annotation shows a distance between objects in a document as shown in the picture below: 

![](/net/annotation/images/add-distance-annotation.png)

You can set the following properties of the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/distanceannotation" target="_blank" rel="nofollow noopener noreferrer">DistanceAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> defines annotation position on a page
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> allows you to set the annotation opacity
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> defines the annotation color
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> defines the annotation line style (solid, dash, dot etc.)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> defines the line width in pixels

  
To add a distance annotation to document, follow these steps:  

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/distanceannotation" target="_blank" rel="nofollow noopener noreferrer">DistanceAnnotation</a> class. Set the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/distanceannotation" target="_blank" rel="nofollow noopener noreferrer">DistanceAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.  
      
    

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/distanceannotation" target="_blank" rel="nofollow noopener noreferrer">DistanceAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add distance annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	DistanceAnnotation distance = new DistanceAnnotation
    {
        Box = new Rectangle(200, 150, 200, 30),
        CreatedOn = DateTime.Now,
        Message = "This is distance annotation",
        Opacity = 0.7,
        PageNumber = 0,
        PenColor = 65535,
        PenStyle = PenStyle.Dot,
        PenWidth = 3,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(distance);
    annotator.Save("result.pdf");
}
```

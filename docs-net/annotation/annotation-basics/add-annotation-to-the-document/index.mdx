## What is a document annotation?

Annotation is a textual or graphic notes, comments and remarks attached to a specific part of a document content - sections, paragraphs, sentences or even words. Annotations are often used by a group of collaborators to edit and review documents in a quick and handy manner - the document is shared with reviewers who then mark it up and add notes. Then assigned team members read these annotations and modify document content accordingly.

Today annotations can be programmatically added to a documents and images of various  types - PDF, Microsoft Word and Open Document text documents, Microsoft Excel spreadsheets, Microsoft PowerPoint presentations, PNG / JPG / TIFF images etc. 

  

### Add annotation to the document

**<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a>** allows to apply various annotation types to the different document formats. Supported annotations list is described in a table below. 

### List of supported annotations

| Annotation | Description |
| --- | --- |
| [Area](/net/annotation/annotation-basics/add-annotation-to-the-document/add-area-annotation/) | Rectangle annotation that can be applied in random place on document page. |
| [Arrow](/net/annotation/annotation-basics/add-annotation-to-the-document/add-arrow-annotation/) | Annotation in the form of pointer or arrow. |
| [Distance](/net/annotation/annotation-basics/add-annotation-to-the-document/add-distance-annotation/) | Annotation looks like arrow but with arrows at both line ends. For most document formats this annotation can contains text value (this feature not support for Word documents). |
| [Ellipse](/net/annotation/annotation-basics/add-annotation-to-the-document/add-ellipse-annotation/) | Circle-based annotation. |
| [Link](/net/annotation/annotation-basics/add-annotation-to-the-document/add-link-annotation/) | Represents a web-link that can be applied to the part of text. This annotation supports only for PDF, Word processing text documents and presentations. |
| [Point](/net/annotation/annotation-basics/add-annotation-to-the-document/add-point-annotation/) | Represents abstract point annotation. |
| [Polyline](/net/annotation/annotation-basics/add-annotation-to-the-document/add-polyline-annotation/) | Represents free-hand drawing line. |
| [Resource redaction](/net/annotation/annotation-basics/add-annotation-to-the-document/add-resource-redaction-annotation/) | Represents free rectangle annotation with fixed position and black background. For this annotation is impossible to move it (in result document), and change any visual properties. |
| [Text field](/net/annotation/annotation-basics/add-annotation-to-the-document/add-text-field-annotation/) | This is a rectangle annotation with some text inside rectangle area. |
| [Highlight](/net/annotation/annotation-basics/add-annotation-to-the-document/add-highlight-annotation/) | This annotation highlight text. Applicable only for text. |
| [Text redaction](/net/annotation/annotation-basics/add-annotation-to-the-document/add-text-redaction-annotation/) | Same as resource redaction annotation, but applicable only for text. |
| [Replacement](/net/annotation/annotation-basics/add-annotation-to-the-document/add-replacement-annotation/) | Replace original document text by user text. Applicable only for text. |
| [Strikeout](/net/annotation/annotation-basics/add-annotation-to-the-document/add-strikeout-annotation/) | Make selected text strikeout. Applicable only for text. |
| [Underline](/net/annotation/annotation-basics/add-annotation-to-the-document/add-underline-annotation/) | Make selected text underline. Applicable only for text. |
| [Watermark](/net/annotation/annotation-basics/add-annotation-to-the-document/add-watermark-annotation/) | Add text watermark. PageNumber for this annotation is ignored, because annotation adds to all document pages. For some document formats can set Angle property, that determines annotation angle rotation. |

Link annotation adds a hyperlink to document as shown in the picture below:

![](/net/annotation/images/add-link-annotation.png)

You can set the following properties of the  <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> class:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/linkannotation/properties/url" target="_blank" rel="nofollow noopener noreferrer">Url</a> defines link to a web resource
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/linkannotation/properties/points" target="_blank" rel="nofollow noopener noreferrer">Points</a> defines the annotation positions as an array of points.  
    

To add a link annotation, follow these steps:

1.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> class. Specify the input document path or stream.
2.   Instantiate the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> class. Specify the appropriate properties (position, page number, etc).
3.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method. Specify the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> class.
4.   Call the <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> method. Specify the output document path or stream.

The following code snippet shows how to add <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/linkannotation" target="_blank" rel="nofollow noopener noreferrer">LinkAnnotation</a> to the document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add link annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	LinkAnnotation link= new LinkAnnotation
    {
    	Url = "https://www.groupdocs.com/",
        CreatedOn = DateTime.Now,
        Message = "This is link annotation",
        BackgroundColor = 65535,
        PageNumber = 0,
        Points = new List<Point>
        {
        	new Point(80, 730), new Point(240, 730), new Point(80, 650), new Point(240, 650)
        },
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(link);
    annotator.Save("result.pdf");
}
```

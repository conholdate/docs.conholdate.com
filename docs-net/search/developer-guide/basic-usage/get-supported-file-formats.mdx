The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class is used to obtain a list of supported file types.

An example of obtaining a list of supported file types is presented below.

**C#**

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
    .GetSupportedFileTypes()
    .OrderBy(ft => ft.Extension);
 
foreach (FileType fileType in supportedFileTypes)
{
    Console.WriteLine(fileType.Extension.PadRight(8) + " - " + fileType.Description);
}
```

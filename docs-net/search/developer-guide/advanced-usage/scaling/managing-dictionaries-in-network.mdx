To obtain a dictionary from a shard of a search network node, use the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/getdictionary/" target="_blank" rel="nofollow noopener noreferrer">GetDictionary</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> class. The first parameter of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/getdictionary/" target="_blank" rel="nofollow noopener noreferrer">GetDictionary</a> method is the type of the required dictionary, and the second parameter is the index of the shard in the network. The method returns an object of type <a href="https://reference.groupdocs.com/search/net/groupdocs.search.dictionaries/dictionarybase/" target="_blank" rel="nofollow noopener noreferrer">DictionaryBase</a>, which must be cast to the required dictionary type. In the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> class there are also methods that immediately return the desired dictionary type without casting the type and without specifying the type in the parameters.

You can then perform all operations on the dictionary object that are valid for a dictionary in a single index. For information about working with dictionaries, see articles <a href="https://docs.groupdocs.com/search/net/managing-dictionaries/" target="_blank" rel="nofollow noopener noreferrer">Managing Dictionaries</a>.

And after setting up the dictionary, you need to return the dictionary object back to the shard using the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/setdictionary/" target="_blank" rel="nofollow noopener noreferrer">SetDictionary</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> class, specifying the index of the desired shard. Alternatively, you can set the dictionary object to all shards by the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/setdictionary/" target="_blank" rel="nofollow noopener noreferrer">SetDictionary</a> method with one parameter without specifying the shard index.

The following code example demonstrates working with dictionaries on the search network.

**C#**

```csharp
Console.WriteLine("Adding synonyms");

Indexer indexer = node.Indexer;

int[] indices = node.GetShardIndices();
SynonymDictionary dictionary = indexer.GetSynonymDictionary(indices[0]);

if (clearBeforeAdding)
{
    dictionary.Clear();
}
dictionary.AddRange(new string[][] { group });

indexer.SetDictionary(dictionary);
```

If there is any communication interruption in the search network, some operations may not complete correctly. To resolve such problems, you need to call the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/synchronize/" target="_blank" rel="nofollow noopener noreferrer">Synchronize</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> class.

The asynchronous operation flag is available as an option. You can track the completion of the operation by subscribing to the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/synchronizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">SynchronizationCompleted</a> event.

The following code example demonstrates how to synchronize search network nodes.

**C#**

```csharp
Console.WriteLine("Synchronizing shards");
Indexer indexer = node.Indexer;
SynchronizeOptions options = new SynchronizeOptions();
indexer.Synchronize(options);
```

To obtain the extracted text of indexed documents in the search network, the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a> class is used.

The first parameter of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> method is a document represented by the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.results/networkdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">NetworkDocumentInfo</a> class. A list of all indexed documents in the search network can be obtained using the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getindexeddocuments/" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocuments</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a> class.

The second parameter of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> method is the result output adapter. In this operation, the same output adapter classes are used as those used in similar operations of a single index. For information about output adapters, see the article <a href="https://docs.groupdocs.com/search/net/output-adapters/" target="_blank" rel="nofollow noopener noreferrer">Output adapters</a>.

The following code example demonstrates retrieving the text of documents indexed in the search network, as well as outputting the resulting data to the console.

**C#**

```csharp
Searcher searcher = node.Searcher;

List<NetworkDocumentInfo> documents = new List<NetworkDocumentInfo>();
int[] shardIndices = node.GetShardIndices();
for (int i = 0; i < shardIndices.Length; i++)
{
    int shardIndex = shardIndices[i];
    NetworkDocumentInfo[] infos = searcher.GetIndexedDocuments(shardIndex);
    documents.AddRange(infos);
    for (int j = 0; j < infos.Length; j++)
    {
        NetworkDocumentInfo info = infos[j];
        NetworkDocumentInfo[] items = searcher.GetIndexedDocumentItems(info);
        documents.AddRange(items);
    }
}

for (int i = 0; i < documents.Count; i++)
{
    NetworkDocumentInfo document = documents[i];
    if (document.DocumentInfo.ToString().Contains(containsInPath))
    {
        Console.WriteLine();
        Console.WriteLine(document.DocumentInfo.ToString());

        StringOutputAdapter outputAdapter = new StringOutputAdapter(OutputFormat.PlainText);
        searcher.GetDocumentText(document, outputAdapter);

        Console.WriteLine(outputAdapter.GetResult());
        break;
    }
}
```

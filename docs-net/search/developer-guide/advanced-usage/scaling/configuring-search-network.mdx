Configuring a search network involves creating a configuration using the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/" target="_blank" rel="nofollow noopener noreferrer">Configurator</a> class and the fluent interface.

The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/" target="_blank" rel="nofollow noopener noreferrer">Configurator</a> class has methods for configuring general index settings, as well as for configuring each individual network node.

The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/setindexsettings/" target="_blank" rel="nofollow noopener noreferrer">SetIndexSettings</a> method creates an instance of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/" target="_blank" rel="nofollow noopener noreferrer">IndexSettingsConfigurator</a> class, which allows you to set the following settings for each index of the distributed search network:
 - Flag for using stop words when indexing (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setusestopwords/" target="_blank" rel="nofollow noopener noreferrer">SetUseStopWords</a> method).
 - Flag for using character replacements during indexing (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setusecharacterreplacements/" target="_blank" rel="nofollow noopener noreferrer">SetUseCharacterReplacements</a> method).
 - Flag for using the extracted text storage, as well as the degree of text compression in the storage (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/settextstoragesettings/" target="_blank" rel="nofollow noopener noreferrer">SetTextStorageSettings</a> method).
 - Index type (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setindextype/" target="_blank" rel="nofollow noopener noreferrer">SetIndexType</a> method).
 - Number of threads used for searching (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setsearchthreads/" target="_blank" rel="nofollow noopener noreferrer">SetSearchThreads</a> method).

To complete the configuration of index settings, you must call the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/completeindexsettings/" target="_blank" rel="nofollow noopener noreferrer">CompleteIndexSettings</a> method.

To configure individual search network nodes, use the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/addnode/" target="_blank" rel="nofollow noopener noreferrer">AddNode</a> method, which returns an instance of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/" target="_blank" rel="nofollow noopener noreferrer">NodeConfigurator</a> class.

The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/" target="_blank" rel="nofollow noopener noreferrer">NodeConfigurator</a> class allows you to set the following node parameters:
 - Set the required IP address and port number of the search network node (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/settcpendpoint/" target="_blank" rel="nofollow noopener noreferrer">SetTcpEndpoint</a> method).
 - Declare the node as a receiver of log messages for all other network nodes (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addlogsink/" target="_blank" rel="nofollow noopener noreferrer">AddLogSink</a> method).
 - Add an indexing service, which is the input for all operations that change the contents of shards in network nodes (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addindexer/" target="_blank" rel="nofollow noopener noreferrer">AddIndexer</a> method). This service must be presented on the network exactly once.
 - Add a search service, which is the input for all search queries to the network (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addsearcher/" target="_blank" rel="nofollow noopener noreferrer">AddSearcher</a> method).
 - Add an extraction service used to extract data from documents added to the search network (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addextractor/" target="_blank" rel="nofollow noopener noreferrer">AddExtractor</a> method). Increasing the number of extraction services (one per network node) increases the performance of search network indexing.
 - Add a shard service used to store extracted data in a form suitable for searching on the network (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addshard/" target="_blank" rel="nofollow noopener noreferrer">AddShard</a> method). Increasing the number of shards (one for each network node) increases the performance of searching the network.

To complete the configuration of a network node, you must call the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/completenode/" target="_blank" rel="nofollow noopener noreferrer">CompleteNode</a> method.

Once the search network configuration is complete, you must call the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/completeconfiguration/" target="_blank" rel="nofollow noopener noreferrer">CompleteConfiguration</a> method, which will return an instance of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configuration/" target="_blank" rel="nofollow noopener noreferrer">Configuration</a> class.

An instance of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configuration/" target="_blank" rel="nofollow noopener noreferrer">Configuration</a> class can be saved to a file or stream in the XML format using the Save method, and subsequently can be loaded from the file or stream using the Load method.

The following code example shows how to create a search network configuration that describes four nodes.

**C#**

```csharp
string address = "127.0.0.1";
Configuration configuration = new Configurator()
    .SetIndexSettings()
        .SetUseStopWords(false)
        .SetUseCharacterReplacements(false)
        .SetTextStorageSettings(true, Compression.High)
        .SetIndexType(IndexType.NormalIndex)
        .SetSearchThreads(NumberOfThreads.Default)
        .CompleteIndexSettings()
    .AddMasterNode(0)
        .AddIndexer(basePath + "Indexer0")
        .AddSearcher(basePath + "Searcher0")
        .CompleteNode()
    .AddSlaveNode(1)
        .SetTcpEndpoint(address, basePort + 1)
        .AddShard(basePath + "Shard1")
        .AddExtractor(basePath + "Extractor1")
        .CompleteNode()
    .AddSlaveNode(2)
        .SetTcpEndpoint(address, basePort + 2)
        .AddShard(basePath + "Shard2")
        .AddExtractor(basePath + "Extractor2")
        .CompleteNode()
    .AddSlaveNode(3)
        .SetTcpEndpoint(address, basePort + 3)
        .AddShard(basePath + "Shard3")
        .AddExtractor(basePath + "Extractor3")
        .CompleteNode()
    .CompleteConfiguration();
```

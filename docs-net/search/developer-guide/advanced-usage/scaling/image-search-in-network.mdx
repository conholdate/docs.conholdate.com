To run a reverse image search, use the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchfirst/#searchfirst" target="_blank" rel="nofollow noopener noreferrer">SearchFirst</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a> class. This method returns the first portion of results.

To continue the search, the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchnext/#searchnext" target="_blank" rel="nofollow noopener noreferrer">SearchNext</a> method is used, returning the second and subsequent portions of results.

The search image object and search options object are the same as those used for single index searches.

The following code example demonstrates performing a reverse image search on the search network.

**C#**

```csharp
Console.WriteLine("First image search");

Searcher searcher = node.Searcher;
ImageSearchOptions options = new ImageSearchOptions();
options.HashDifferences = hashDifferences;
int total = 0;

NetworkImageSearchResult result = searcher.SearchFirst(searchImage, options);
Console.WriteLine("Images found (shard " + result.ShardIndex + "): " + result.ImageCount);
total += result.ImageCount;

while (result.NetworkImageSearchToken != null)
{
    Console.WriteLine();
    Console.WriteLine("Next image search");

    result = searcher.SearchNext(result.NetworkImageSearchToken);
    Console.WriteLine("Images found (shard " + result.ShardIndex + "): " + result.ImageCount);
    total += result.ImageCount;
}

Console.WriteLine();
Console.WriteLine("Total images found (diffs = " + hashDifferences + "): " + total);
```

More information about reverse image search in the <a href="https://docs.groupdocs.com/search/net/reverse-image-search/" target="_blank" rel="nofollow noopener noreferrer">article</a>.

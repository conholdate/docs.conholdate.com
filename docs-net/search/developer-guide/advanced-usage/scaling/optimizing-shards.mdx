All search network shards can be optimized with a single call the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/optimize/" target="_blank" rel="nofollow noopener noreferrer">Optimize</a> method of the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> class.

The optimization minimizes the number of index segments on each shard. As a result, search performance increases.

An asynchronous execution flag is available as an option. In the case of asynchronous optimization, you can track the completion of the operation by subscribing to the <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/optimizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">OptimizationCompleted</a> event.

The following code example demonstrates how to perform search network optimization.

**C#**

```csharp
Console.WriteLine("Optimizing shards");
Indexer indexer = node.Indexer;
OptimizeOptions options = new OptimizeOptions();
indexer.Optimize(options);
```

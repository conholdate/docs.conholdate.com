Stop words are frequently used words that do not carry a semantic meaning and can be removed from an index to reduce its size.

You can enable or disable the use of stop words by setting a value of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/usestopwords" target="_blank" rel="nofollow noopener noreferrer">UseStopWords</a> property of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a> class. The default value is true, meaning that stop words are filtered during indexing and not added to an index.

A list of stop words to use during indexing can be specified in the stop word dictionary. By default, the stop word dictionary is filled with the most widely used pronouns and prepositions of English and Russian. The list of stop words used can be easily replaced or supplemented and it is saved when the index is reloaded. For information on managing the stop word dictionary, see the [Stop word dictionary](/net/search/developer-guide/advanced-usage/managing-dictionaries/stop-word-dictionary/) page in the [Managing dictionaries](/net/search/developer-guide/advanced-usage/managing-dictionaries/) section.

If you need to keep all text information extracted from documents, and you are not afraid of a significant increase in the size of the index, then an example of indexing without stop words can be found below.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index settings with disabled using of stop words
IndexSettings settings = new IndexSettings();
settings.UseStopWords = false;
 
// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Searching in the index
// Now in the index it is possible to search for the stop word 'on'
SearchResult result = index.Search("on");
```

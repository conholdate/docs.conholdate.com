This page contains a description of how to get a list of indexed documents from an index, and how to get the text of indexed documents in HTML or plain text format.

## Getting indexed documents

To get a list of indexed documents from an index, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getindexeddocuments" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocuments</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> class. Documents with the extensions ZIP, PST, OST can also contain internal documents. To get a list of internal documents, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getindexeddocumentitems" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocumentItems</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> class. For ZIP archives, this way you can access documents of arbitrary nesting depth. An example of obtaining a list of documents from an index is presented below.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Getting list of indexed documents
DocumentInfo[] documents = index.GetIndexedDocuments();
for (int i = 0; i < documents.Length; i++)
{
    DocumentInfo document = documents[i];
    Console.WriteLine(document.FilePath);
    DocumentInfo[] items = index.GetIndexedDocumentItems(document); // Getting list of document items
    for (int j = 0; j < items.Length; j++)
    {
        DocumentInfo item = items[j];
        Console.WriteLine("\t" + item.InnerPath);
    }
}
```

## Getting text of indexed documents

The text of the indexed document can also be extracted from an index if the option to save the text of documents in the index has been enabled. If this option was not enabled when creating an index, then when the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getdocumenttext/index" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> class is called, the text of the document will be retrieved again. Details about saving the text of documents in an index can be found on the page [Storing text of indexed documents](/net/search/developer-guide/advanced-usage/indexing/storing-text-of-indexed-documents/).

The generated text of the document is passed to an instance of a class derived from the abstract class <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/outputadapter" target="_blank" rel="nofollow noopener noreferrer">OutputAdapter</a>. Details on the output adapters are presented on the page [Output adapters](/net/search/developer-guide/advanced-usage/searching/output-adapters/).

After generating the text of a document into a file, this file can be opened by an Internet browser. The following example shows how to extract document text from an index.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Getting list of indexed documents
DocumentInfo[] documents = index.GetIndexedDocuments();
 
// Getting a document text
if (documents.Length > 0)
{
    FileOutputAdapter outputAdapter = new FileOutputAdapter(OutputFormat.Html, @"C:\Text.html");
    index.GetDocumentText(documents[0], outputAdapter);
}
```

To extract the text of a document from an index, the method overloading is also presented, which takes an instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textoptions" target="_blank" rel="nofollow noopener noreferrer">TextOptions</a> class as a parameter. In this class, the following options can be specified:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textoptions/properties/customextractor" target="_blank" rel="nofollow noopener noreferrer">CustomExtractor</a> is a custom extractor used during indexing, it is necessary if the text of the document was not saved in the index;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textoptions/properties/additionalfields" target="_blank" rel="nofollow noopener noreferrer">AdditionalFields</a> are additional document fields added during document indexing which are also necessary if the document text was not saved in the index;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textoptions/properties/cancellation" target="_blank" rel="nofollow noopener noreferrer">Cancellation</a> is an object used to cancel the operation;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textoptions/properties/metadataindexingoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataIndexingOptions</a> is an object for specifying metadata indexing options.

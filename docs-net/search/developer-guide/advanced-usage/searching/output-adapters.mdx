Output adapters are used to output generated HTML or plain text to various output objects. The following output adapters are currently supported:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/fileoutputadapter" target="_blank" rel="nofollow noopener noreferrer">FileOutputAdapter</a> is an output adapter that is used to output text to a file. The path to a file is specified in the constructor of the adapter.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/streamoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StreamOutputAdapter</a> is an output adapter that is used to output text to a stream. The stream is specified in the constructor of the adapter.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/stringoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StringOutputAdapter</a> is an output adapter that is used to output text to a string. The resulting string can be accessed through the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/stringoutputadapter/methods/getresult" target="_blank" rel="nofollow noopener noreferrer">GetResult</a> method of the adapter class.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/structureoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StructureOutputAdapter</a> is an output adapter that is used to output the text of each field of the document separately. The resulting array of fields can be accessed through the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/structureoutputadapter/methods/getresult" target="_blank" rel="nofollow noopener noreferrer">GetResult</a> method of the adapter class.

The example below demonstates how to use adapters of different types.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an index settings instance
IndexSettings settings = new IndexSettings();
settings.TextStorageSettings = new TextStorageSettings(Compression.High); // Enabling storage of extracted text in the index

// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Getting list of indexed documents
DocumentInfo[] documents = index.GetIndexedDocuments();

// Getting a document text
if (documents.Length > 0)
{
    DocumentInfo document = documents[0];

    // Output to a file
    FileOutputAdapter fileOutputAdapter = new FileOutputAdapter(OutputFormat.Html, @"C:\Text.html");
    index.GetDocumentText(document, fileOutputAdapter);

    // Output to a stream
    using (Stream stream = new MemoryStream())
    {
        StreamOutputAdapter streamOutputAdapter = new StreamOutputAdapter(OutputFormat.Html, stream);
        index.GetDocumentText(document, streamOutputAdapter);
    }

    // Output to a string
    StringOutputAdapter stringOutputAdapter = new StringOutputAdapter(OutputFormat.Html);
    index.GetDocumentText(document, stringOutputAdapter);
    string htmlText = stringOutputAdapter.GetResult();
    Console.WriteLine(htmlText);

    // Output to a structure
    StructureOutputAdapter structureOutputAdapter = new StructureOutputAdapter(OutputFormat.PlainText);
    index.GetDocumentText(document, structureOutputAdapter);
    DocumentField[] fields = structureOutputAdapter.GetResult();
    Console.WriteLine(document.ToString());
    for (int i = 0; i < fields.Length; i++)
    {
        DocumentField field = fields[i];
        Console.WriteLine("\t" + field.Name);
    }
}
```

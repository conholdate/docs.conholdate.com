## Multiple simultaneous searches

Search in an index is a thread safe operation. This means that calls to the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> and <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/searchnext/index" target="_blank" rel="nofollow noopener noreferrer">SearchNext</a> methods can be made from different threads to the same instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> class without any cross-threading problems.

## Search during indexing, updating, optimizing, or merging operation

Simultaneous search from different threads is a thread safe operation and can be performed even during indexing, updating, optimizing, and merging operations.

However, indexing, updating, optimizing, and merging operations themselves cannot be performed at the same time. A new start of one of these operations before the completion of the previous operation will result in an error.

Details on performing these operations can be found in the [Indexing](/net/search/developer-guide/advanced-usage/indexing/) section and on the [Merge indexes](/net/search/developer-guide/advanced-usage/indexing/merge-indexes/), [Optimize index](/net/search/developer-guide/advanced-usage/indexing/optimize-index/), and [Update index](/net/search/developer-guide/advanced-usage/indexing/update-index/) pages.

The search for different word forms allows you to search for nouns in the singular or plural, adjectives in the degree of comparison, forms of regular and irregular verbs, etc.

Search for different word forms is enabled if the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usewordformssearch" target="_blank" rel="nofollow noopener noreferrer">UseWordFormsSearch</a> property of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> class is set to true. By default, the search for different word forms is disabled.

To generate various forms of words, a class that implements the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/iwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">IWordFormsProvider</a> interface is used. The default class is <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/englishwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">EnglishWordFormsProvider</a>, which supports English-only word forms. To add support for word forms in other languages, see the [Word forms provider](/net/search/developer-guide/advanced-usage/managing-dictionaries/word-forms-provider/) page.

The following example demonstrates how to perform search for different word forms in an index.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Creating a search options instance
SearchOptions options = new SearchOptions();
options.UseWordFormsSearch = true; // Enabling search for word forms
 
// Searching in the index
SearchResult result = index.Search("relative", options);
 
// The following words can be found:
// relative
// relatives
// relatively
```

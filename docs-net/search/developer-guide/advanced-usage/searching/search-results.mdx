Search results are represented by the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> class, an instance of which is returned by the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> class. The <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> method of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository" target="_blank" rel="nofollow noopener noreferrer">IndexRepository</a> class also returns an instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> class.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> class contains the following members:

*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/documentcount" target="_blank" rel="nofollow noopener noreferrer">DocumentCount</a> property returns the number of documents found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> property returns the total number of occurrences found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/truncated" target="_blank" rel="nofollow noopener noreferrer">Truncated</a> property returns a value indicating that the result is truncated due to limits specified in the search options.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/warnings" target="_blank" rel="nofollow noopener noreferrer">Warnings</a> property returns a warnings describing the result, for example, a warning about the presence of stop word in a search query.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/nextchunksearchtoken" target="_blank" rel="nofollow noopener noreferrer">NextChunkSearchToken</a> property returns a chunk search token to search for the next chunk. For details on search by chunks, see the [Search by chunks](/net/search/developer-guide/advanced-usage/searching/search-by-chunks/) page.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/starttime" target="_blank" rel="nofollow noopener noreferrer">StartTime</a> property returns the start time of the search.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/endtime" target="_blank" rel="nofollow noopener noreferrer">EndTime</a> property returns the end time of the search.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/searchduration" target="_blank" rel="nofollow noopener noreferrer">SearchDuration</a> property returns the search duration.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/methods/getfounddocument" target="_blank" rel="nofollow noopener noreferrer">GetFoundDocument</a> method returns the found document by index.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/methods/getenumerator" target="_blank" rel="nofollow noopener noreferrer">GetEnumerator</a> method returns an enumerator that iterates through the collection of the documents found.

The found document is represented by an instance of a <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a> class. The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a> class contains the following members:

*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/documentinfo" target="_blank" rel="nofollow noopener noreferrer">DocumentInfo</a> property returns the document info object containing the file path, the file type, the format family, and the inner document path for items of container documents.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/relevance" target="_blank" rel="nofollow noopener noreferrer">Relevance</a> property returns the relevance of the document in the search result.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> property returns the number of occurrences found in the document.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/foundfields" target="_blank" rel="nofollow noopener noreferrer">FoundFields</a> property returns the found document fields.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/terms" target="_blank" rel="nofollow noopener noreferrer">Terms</a> property returns the found terms. The value is evaluated each time the property is accessed based on the data for each document field found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/termsequences" target="_blank" rel="nofollow noopener noreferrer">TermSequences</a> property returns the found term sequences.
*   The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocument/methods/serialize" target="_blank" rel="nofollow noopener noreferrer">Serialize</a> method serializes the current found document instance to a byte array.
*   The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocument/methods/deserialize" target="_blank" rel="nofollow noopener noreferrer">Deserialize</a> method deserializes an instance of found document from a byte array.

The found document field is represented by an instance of a <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a> class. The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a> class contains the following members:

*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/fieldname" target="_blank" rel="nofollow noopener noreferrer">FieldName</a> property returns the field name.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> property returns the number of occurrences found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/terms" target="_blank" rel="nofollow noopener noreferrer">Terms</a> property returns the terms found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsoccurrences" target="_blank" rel="nofollow noopener noreferrer">TermsOccurrences</a> property returns the occurrences of the found terms.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsequences" target="_blank" rel="nofollow noopener noreferrer">TermSequences</a> property returns the term sequences found.
*   The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsequencesoccurrences" target="_blank" rel="nofollow noopener noreferrer">TermSequencesOccurrences</a> property returns the occurrences of the found term sequences.
*   The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocumentfield/methods/serialize" target="_blank" rel="nofollow noopener noreferrer">Serialize</a> method serializes the current found document field instance to a byte array.
*   The <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocumentfield/methods/deserialize" target="_blank" rel="nofollow noopener noreferrer">Deserialize</a> method deserializes an instance of found document field from a byte array.

The following example shows how to print information on the documents found in the console.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Creating search options
SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new TableDiscreteFunction(3); // Setting the maximum number of differences to 3
 
// Search for documents containing the word 'Einstein' or the phrase 'Theory of Relativity'
SearchResult result = index.Search("Einstein OR \"Theory of Relativity\"", options);
 
// Printing the result
Console.WriteLine("Documents: " + result.DocumentCount);
Console.WriteLine("Total occurrences: " + result.OccurrenceCount);
for (int i = 0; i < result.DocumentCount; i++)
{
    FoundDocument document = result.GetFoundDocument(i);
    Console.WriteLine("\tDocument: " + document.DocumentInfo.FilePath);
    Console.WriteLine("\tOccurrences: " + document.OccurrenceCount);
    for (int j = 0; j < document.FoundFields.Length; j++)
    {
        FoundDocumentField field = document.FoundFields[j];
        Console.WriteLine("\t\tField: " + field.FieldName);
        Console.WriteLine("\t\tOccurrences: " + document.OccurrenceCount);
        // Printing found terms
        if (field.Terms != null)
        {
            for (int k = 0; k < field.Terms.Length; k++)
            {
                Console.WriteLine("\t\t\t" + field.Terms[k].PadRight(20) + field.TermsOccurrences[k]);
            }
        }
        // Printing found phrases
        if (field.TermSequences != null)
        {
            for (int k = 0; k < field.TermSequences.Length; k++)
            {
                string sequence = string.Join(" ", field.TermSequences[k]);
                Console.WriteLine("\t\t\t" + sequence.PadRight(30) + field.TermSequencesOccurrences[k]);
            }
        }
    }
}
```

This page contains a description of all search options that can be specified in an instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> class.

## Cancellation property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/cancellation" target="_blank" rel="nofollow noopener noreferrer">Cancellation</a> property allows you to specify the object to cancel the search operation. The search can be canceled without delay by calling the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/cancellation/methods/cancel" target="_blank" rel="nofollow noopener noreferrer">Cancel</a> method or by calling the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/cancellation/methods/cancelafter" target="_blank" rel="nofollow noopener noreferrer">CancelAfter</a> method with the delay in milliseconds as an argument.

## DateFormats property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/dateformats" target="_blank" rel="nofollow noopener noreferrer">DateFormats</a> property allows you to specify formats for the date range search feature. For details, see the [Date range search](/net/search/developer-guide/advanced-usage/searching/date-range-search/) page.

## FuzzySearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/fuzzysearch" target="_blank" rel="nofollow noopener noreferrer">FuzzySearch</a> property returns a fuzzy search options object that allows you to enable fuzzy search and set its options. By default, the fuzzy search feature is disabled. For details, see the [Fuzzy search](/net/search/developer-guide/advanced-usage/searching/fuzzy-search/) page.

## IsChunkSearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/ischunksearch" target="_blank" rel="nofollow noopener noreferrer">IsChunkSearch</a> property allows you to enable search by chunks. By default, the search by chunks feature is disabled. For details, see the [Search by chunks](/net/search/developer-guide/advanced-usage/searching/search-by-chunks/) page.

## KeyboardLayoutCorrector property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/keyboardlayoutcorrector" target="_blank" rel="nofollow noopener noreferrer">KeyboardLayoutCorrector</a> property returns a keyboard layout corrector options object, which allows you to enable keyboard layout correction in search queries. By default, the keyboard layout correction feature is disabled. See the [Keyboard layout correction](/net/search/developer-guide/advanced-usage/searching/keyboard-layout-correction/) page for details.

## MaxOccurrenceCountPerTerm property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/maxoccurrencecountperterm" target="_blank" rel="nofollow noopener noreferrer">MaxOccurrenceCountPerTerm</a> property allows you to specify the maximum number of occurrences of each word found that will be returned as a search result. The default value is 100000.

## MaxTotalOccurrenceCount property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/maxtotaloccurrencecount" target="_blank" rel="nofollow noopener noreferrer">MaxTotalOccurrenceCount</a> property allows you to specify the maximum number of occurrences in total for all found words, which will be returned as a search result. The default value is 500000.

## SearchDocumentFilter property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/searchdocumentfilter" target="_blank" rel="nofollow noopener noreferrer">SearchDocumentFilter</a> property allows you to specify the filter of documents returned as a search result. By default, all documents found will be returned as a search result. For details, see the [Document filtering in search result](/net/search/developer-guide/advanced-usage/searching/document-filtering-in-search-result/) page.

## SpellingCorrector property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/spellingcorrector" target="_blank" rel="nofollow noopener noreferrer">SpellingCorrector</a> property returns the spelling corrector options object, which allows you to enable spelling correction in search queries and specify spelling correction options. By default, spelling correction is disabled. See the [Spell checking](/net/search/developer-guide/advanced-usage/searching/spell-checking/) page for details.

## UseCaseSensitiveSearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usecasesensitivesearch" target="_blank" rel="nofollow noopener noreferrer">UseCaseSensitiveSearch</a> property allows you to perform case-sensitive search. Please note that case-sensitive search is not compatible with other types of searches. By default, case-insensitive search is performed. For details, see the [Case sensitive search](/net/search/developer-guide/advanced-usage/searching/case-sensitive-search/) page.

## UseHomophoneSearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usehomophonesearch" target="_blank" rel="nofollow noopener noreferrer">UseHomophoneSearch</a> property allows you to enable homophone search feature. By default, the homophone search feature is disabled. For details, see the [Homophone search](/net/search/developer-guide/advanced-usage/searching/homophone-search/) page.

## UseSynonymSearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usesynonymsearch" target="_blank" rel="nofollow noopener noreferrer">UseSynonymSearch</a> property allows you to enable synonym search feature. By default, the synonym search feature is disabled. For details, see the [Synonym search](/net/search/developer-guide/advanced-usage/searching/synonym-search/) page.

## UseWordFormsSearch property

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usewordformssearch" target="_blank" rel="nofollow noopener noreferrer">UseWordFormsSearch</a> property allows you to enable the word forms search feature. By default, the word forms search feature is disabled. For details, see the [Search for different word forms](/net/search/developer-guide/advanced-usage/searching/search-for-different-word-forms/) page.

This page describes how you can search by date with date range search. As well it describes the creation of date wise search queries, and also describes the management of formats for date range search.

## Creating date range search queries

Date range search allows you to search in documents dates from a given range in given date formats.

Queries for date range search in text form are specified in the following format:

*   daterange( date ~~ date )

where date is the date in yyyy-MM-dd format, for example, 2019-09-13. Please note that in a search query, dates are always set in the same format.

The following example demonstrates how to search by date using queries in text and object form.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search for dates using query in text form
string query1 = "daterange(2017-01-01 ~~ 2019-12-31)";
SearchResult result1 = index.Search(query1);
 
// Search for dates using query in text form
SearchQuery query2 = SearchQuery.CreateDateRangeQuery(new DateTime(2017, 1, 1), new DateTime(2019, 12, 31));
SearchResult result2 = index.Search(query2);
```

## Specifying date range search formats

To perform the date range search, the date templates specified in the search options are used. The following formats are used by default:

*   dd.MM.yyyy
*   MM/dd/yyyy
*   yyyy-MM-dd

Formats for date range search are set in the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/dateformats" target="_blank" rel="nofollow noopener noreferrer">DateFormats</a> property of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> class. To add a format, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method, to remove it, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/remove" target="_blank" rel="nofollow noopener noreferrer">Remove</a> method, to clear a collection of existing formats, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> method. Each format in the collection is defined by an instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformat" target="_blank" rel="nofollow noopener noreferrer">DateFormat</a> class. To create a new format, you must specify a sequence of format elements and a separator character. All available format elements are represented in the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement" target="_blank" rel="nofollow noopener noreferrer">DateFormatElement</a> class:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dayofmonth" target="_blank" rel="nofollow noopener noreferrer">DayOfMonth</a> specifies the day of month element, represented by one or two digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dayofmonthtwodigits" target="_blank" rel="nofollow noopener noreferrer">DayOfMonthTwoDigits</a> specifies the day of month element, represented by two digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/month" target="_blank" rel="nofollow noopener noreferrer">Month</a> specifies the month element, represented by one or two digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthtwodigits" target="_blank" rel="nofollow noopener noreferrer">MonthTwoDigits</a> specifies the month element, represented by two digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthabbreviatedname" target="_blank" rel="nofollow noopener noreferrer">MonthAbbreviatedName</a> specifies the month element, represented by abbreviated name;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthfullname" target="_blank" rel="nofollow noopener noreferrer">MonthFullName</a> specifies the month element, represented by full name;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/year" target="_blank" rel="nofollow noopener noreferrer">Year</a> specifies the year element, represented by one, two, three, or four digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/yeartwodigits" target="_blank" rel="nofollow noopener noreferrer">YearTwoDigits</a> specifies the year element, represented by two digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/yearfourdigits" target="_blank" rel="nofollow noopener noreferrer">YearFourDigits</a> specifies the year element, represented by four digits;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dateseparator" target="_blank" rel="nofollow noopener noreferrer">DateSeparator</a> specifies the date separator element.

An example of setting the date format for the search is presented below.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Setting date formats
SearchOptions options = new SearchOptions();
options.DateFormats.Clear(); // Removing default date formats
DateFormatElement[] elements = new DateFormatElement[]
{
    DateFormatElement.MonthTwoDigits,
    DateFormatElement.DateSeparator,
    DateFormatElement.DayOfMonthTwoDigits,
    DateFormatElement.DateSeparator,
    DateFormatElement.YearFourDigits,
};
// Creating a date format pattern 'MM/dd/yyyy'
DateFormat dateFormat = new DateFormat(elements, "/");
options.DateFormats.Add(dateFormat);
 
// Searching in the index.
// For the given query, for example, the date 09/27/2019 will be found,
// but the date 2019-09-27 will not be found, because it is presented in a format that is not specified in the search options.
SearchResult result = index.Search("daterange(2017-01-01 ~~ 2019-12-31)", options);
```

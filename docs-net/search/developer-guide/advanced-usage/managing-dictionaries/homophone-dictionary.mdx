The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary" target="_blank" rel="nofollow noopener noreferrer">HomophoneDictionary</a> class is designed to store homophones in an index. For information on searching using homophones, see the [Homophone search](/net/search/developer-guide/advanced-usage/searching/homophone-search/) page.

To get the number of homophones in the dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> property.

To add groups of homophones to the dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> method.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> method is used to remove all homophones from the dictionary.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/gethomophones" target="_blank" rel="nofollow noopener noreferrer">GetHomophones</a> method is used to get a list of synonyms for a given word.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/gethomophonegroups" target="_blank" rel="nofollow noopener noreferrer">GetHomophoneGroups</a> method is used to get all synonym groups to which a given word belongs.

To get all synonym groups from the dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/getallhomophonegroups" target="_blank" rel="nofollow noopener noreferrer">GetAllHomophoneGroups</a> method.

To export homophones to a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a> method.

To import homophones from a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a> method.

The following example demonstrates the use of methods of the homophone dictionary.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";

// Creating an index from in specified folder
Index index = new Index(indexFolder);

// Getting homophones for word 'braid'
string[] homophones = index.Dictionaries.HomophoneDictionary.GetHomophones("braid");
Console.WriteLine("Homophones for 'braid':");
for (int i = 0; i < homophones.Length; i++)
{
    Console.WriteLine(homophones[i]);
}

// Getting groups of homophones to which word 'braid' belongs to
string[][] groups = index.Dictionaries.HomophoneDictionary.GetHomophoneGroups("braid");
Console.WriteLine("Homophone groups for 'braid':");
for (int i = 0; i < groups.Length; i++)
{
    string[] group = groups[i];
    for (int j = 0; j < group.Length; j++)
    {
        Console.Write(group[j] + " ");
    }
    Console.WriteLine();
}

if (index.Dictionaries.HomophoneDictionary.Count > 0)
{
    // Removing all homophones from the dictionary
    index.Dictionaries.HomophoneDictionary.Clear();
}

// Adding homophones to the dictionary
string[][] homophoneGroups = new string[][]
{
    new string[] { "awe", "oar", "or", "ore" },
    new string[] { "aye", "eye", "i" },
};
index.Dictionaries.HomophoneDictionary.AddRange(homophoneGroups);

// Export homophones to a file
index.Dictionaries.HomophoneDictionary.ExportDictionary(@"C:\Homophones.dat");

// Import homophones from a file
index.Dictionaries.HomophoneDictionary.ImportDictionary(@"C:\Homophones.dat");
```

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector" target="_blank" rel="nofollow noopener noreferrer">SpellingCorrector</a> class is designed to correct spelling errors in search queries, as well as to store words with correct spelling. You can learn about spelling correction in search queries on the [Spell checking](/net/search/developer-guide/advanced-usage/searching/spell-checking/) page.

To get the number of words in the spelling corrector dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> property.

To get an array of words containing in the spelling corrector dictionary, the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/getwords" target="_blank" rel="nofollow noopener noreferrer">GetWords</a> method is used.

To add words to the spelling corrector dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> method.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> method is used to remove all words from the spelling corrector dictionary.

To export words to a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a> method.

To import words from a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a> method.

The following example demonstrates the use of methods of the spelling corrector.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
 
// Creating an index from in specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.SpellingCorrector.Count > 0)
{
    // Removing all words from the dictionary
    index.Dictionaries.SpellingCorrector.Clear();
}
 
// Adding words to the dictionary
string[] words = new string[] { "achieve", "accomplish", "attain", "reach" };
index.Dictionaries.SpellingCorrector.AddRange(words);
 
// Export words to a file
index.Dictionaries.SpellingCorrector.ExportDictionary(@"C:\Words.txt");
 
// Import words from a file
index.Dictionaries.SpellingCorrector.ImportDictionary(@"C:\Words.txt");
```

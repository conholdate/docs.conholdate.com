An instance of the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary" target="_blank" rel="nofollow noopener noreferrer">CharacterReplacementDictionary</a> class contains all the character replacements defined in an index. For detailed information on character replacement, see the [Character replacement during Indexing](/net/search/developer-guide/advanced-usage/indexing/character-replacement-during-indexing/) page.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> property allows you to get the number of character replacements defined in the dictionary.

To add character replacements to the dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> method.

To remove character replacements from the dictionary, the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/removerange/index" target="_blank" rel="nofollow noopener noreferrer">RemoveRange</a> method is used.

The <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/contains" target="_blank" rel="nofollow noopener noreferrer">Contains</a> method is used to determine if the dictionary contains a replacement for the specified character.

To get a replacement for the specified character, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/getreplacement" target="_blank" rel="nofollow noopener noreferrer">GetReplacement</a> method.

To remove all replacements from the dictionary, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> method.

To export all replacements to a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a> method.

To import character replacements from a file, use the <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a> method.

The following example demonstrates the use of the character replacement dictionary methods.

**C#**

```csharp
 string indexFolder = @"c:\MyIndex\";
 
// Creating an index from in specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.CharacterReplacements.Count > 0)
{
    // Deleting all character replacements from the dictionary
    index.Dictionaries.CharacterReplacements.Clear();
}
 
if (index.Dictionaries.CharacterReplacements.Contains('-'))
{
    int replacement = index.Dictionaries.CharacterReplacements.GetReplacement('-');
    Console.WriteLine("The replacement for hyphen is " + char.ConvertFromUtf32(replacement));
 
    // Deleting the hyphen character replacement from the dictionary
    index.Dictionaries.CharacterReplacements.RemoveRange(new char[] { '-' });
}
 
// Export character replacements to a file
index.Dictionaries.CharacterReplacements.ExportDictionary(@"C:\CharacterReplacements.dat");
 
// Import character replacements from a file
index.Dictionaries.CharacterReplacements.ImportDictionary(@"C:\CharacterReplacements.dat");
```

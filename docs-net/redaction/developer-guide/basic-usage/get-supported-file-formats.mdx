GroupDocs.Redaction allows to get the list of all supported file formats by these steps:

*   Call <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a>of <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class;
*   Enumerate through the collection of <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>objects*.*

The following example demonstrates how to get supported file formats list.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

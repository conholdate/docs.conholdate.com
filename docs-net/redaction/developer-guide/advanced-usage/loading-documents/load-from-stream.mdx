As an alternative to a local file, <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">Redac</a>[t](https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor)<a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">or</a> can open a document from stream.

The following example demonstrates how to load and redact a document using Stream:

**C#**

```csharp
using (Stream stream = File.Open(@"sample.docx", FileMode.Open, FileAccess.ReadWrite))
{
   using (Redactor redactor = new Redactor(stream))
   {
      // Here we can use document instance to make redactions
      redactor.Apply(new DeleteAnnotationRedaction());
      redactor.Save();
   }
}
```

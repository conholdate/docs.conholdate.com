The following example demonstrates how to create a <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">watermarker</a> for a local file system document:

**AdvancedUsage.LoadingDocuments.LoadFromLocalDisk**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
string filePath = "document.docx";
using (Watermarker watermarker = new Watermarker(filePath))
{
    // use watermarker methods to manage watermarks
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 12));
    watermarker.Add(watermark);
    watermarker.Save("document.docx");
}
```

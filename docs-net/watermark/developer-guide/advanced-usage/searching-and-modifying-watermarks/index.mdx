:::

GroupDocs.Watermark API allows you to search the possible watermarks placed in any document. You can also search the watermarks that are added using some third-party tool. The found possible watermarks can be removed or their properties can be changed. For more details please refer to the following guides:

* [Searching watermarks](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/searching-watermarks/ "Searching watermarks")
* [Modifing found watermark properties](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/modifing-found-watermark-properties/ "Modifing found watermark properties")
* [Removing found watermarks](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/removing-found-watermarks/ "Removing found watermarks")

:::

Saving a document with method <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save()</a>, GroupDocs.Watermark puts it in the same folder as the original file, rewriting original. If you need to save the document to any custom location, you'll have to use <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> method or <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/2" target="_blank" rel="nofollow noopener noreferrer">Save(Stream)</a> of <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a> class.

You can see examples of <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> methods in one of these guides:

* [Save document to the same file or stream](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-same-file-or-stream/ "Save document to the same file or stream")
* [Save document to the specified location](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-specified-location/ "Save document to the specified location")
* [Save document to the specified stream](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-specified-stream/ "Save document to the specified stream")

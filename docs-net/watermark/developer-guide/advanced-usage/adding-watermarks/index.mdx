GroupDocs.Watermark for .NET supports following watermark types.

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark" target="_blank" rel="nofollow noopener noreferrer">TextWatermark</a>
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a>

Adding watermark to any supported document format using GroupDocs.Watermark consists of some easy steps. Following are the steps to add watermark to a document.

1. Load the document
2. Create and initialize watermark object
3. Set watermark properties
4. Add watermark to the document
5. Save the document

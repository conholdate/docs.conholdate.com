One of the main features of the GroupDocs.Watermark library is adding image watermarks to documents. You may add watermarks to documents or images from local disks, as well as from streams. For a full list of supported document formats, check [Supported formats](/net/watermark/getting-started/supported-document-formats/).

To add an image watermark perform the following steps:

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> an instance of the `Watermarker` class for a local file or file stream;
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark/constructors/1" target="_blank" rel="nofollow noopener noreferrer">Create</a> an instance of the `ImageWatermark` class from the local image file;
3. (Optionally.) Specify the watermark <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">horizontal</a> and <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">vertical</a> alignments;
4. Call the <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method to apply the watermark to the document;
5. Call the <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method to store the document in a new location.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\contract.docx"))
{
    // Specify an absolute or relative path to the desired image
    ImageWatermark watermark = new ImageWatermark("C:\\Docs\\logo.png");
    // Specify watermark size, opacity and alignments
    watermark.Width = 200;
    watermark.Height = 200;
    watermark.Opacity = 0.5;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\img-watermarked-contract.docx");
}
```
Run the program. A new watermarked image will appear in the specified path.

GroupDocs.Watermark offers many capabilities to customize how the watermark would look and where it will be positioned within the document.

## Customizing text watermarks

To adjust a text watermark to your needs, use the properties of the <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/#properties" target="_blank" rel="nofollow noopener noreferrer">`TextWatermark`</a> class. 

The following options could be set:
| Option | Description |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a>** | Specifies the background color of the text. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/considerparentmargins" target="_blank" rel="nofollow noopener noreferrer">ConsiderParentMargins</a>** | Whether to take into account the existing page margins of the document when calculating the watermark's size and coordinates. Default: false. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/font" target="_blank" rel="nofollow noopener noreferrer">Font</a>** | Specifies the current font of the text watermark. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/foregroundcolor" target="_blank" rel="nofollow noopener noreferrer">ForegroundColor</a>** | Specifies the foreground color of the text. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Specifies the desired height of the watermark. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>** | Specifies the horizontal alignment of the watermark. Possible values are `None` (default), `Left`, `Center`, and `Right`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/isbackground" target="_blank" rel="nofollow noopener noreferrer">IsBackground</a>** | Whether to place the watermark below (true) or above (true) the main content. Default: false. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/margins" target="_blank" rel="nofollow noopener noreferrer">Margins</a>** | Specifies the watermark margins. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a>** | Defines the opacity of the watermark as a value ranging from 0 (fully transparent) to 1 (solid filling). |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/rotateangle/" target="_blank" rel="nofollow noopener noreferrer">RotateAngle</a>** | Defines the rotation angle of the watermark. A positive value corresponds to a clockwise rotation angle, negative - to a counterclockwise rotation angle. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/scalefactor" target="_blank" rel="nofollow noopener noreferrer">ScaleFactor</a>** | Specifies how the watermark size depends on the size of a parent document. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/sizingtype" target="_blank" rel="nofollow noopener noreferrer">SizingType</a>** | Specifies a way the watermark should be sized. Possible values are `Auto` (default), `Absolute`, `ScaleToParentDimensions`, and `ScaleToParentArea`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>** | Defines the text of the watermark. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/textalignment" target="_blank" rel="nofollow noopener noreferrer">TextAlignment</a>** | Specifies the alignment of text. Possible values are `Left` (default), `Center`, `Right`, and `Justify`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>** | Specifies the vertical alignment of the watermark. Possible values are `None` (default), `Left`, `Center`, and `Bottom`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Specifies the desired width of the watermark. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/x" target="_blank" rel="nofollow noopener noreferrer">X</a>** | Specifies the horizontal coordinate of the watermark within the parent document. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/y" target="_blank" rel="nofollow noopener noreferrer">Y</a>** | Specifies the vertical coordinate of the watermark within the parent document. |


The code below demonstrates how to specify the desired watermark appearance and position before applying it to the document:

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\sample.docx"))
{
    // Specify the desired text and font for the watermark
    TextWatermark watermark = new TextWatermark("Customized watermark.", 
        new Font("Arial", 24, FontStyle.Bold));
    // Specify the appearance and the position of the watermark
    watermark.ForegroundColor = Color.DarkOrange;
    watermark.ConsiderParentMargins = true;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Top;
    watermark.SizingType = SizingType.ScaleToParentDimensions;
    watermark.RotateAngle = 45;
    watermark.ScaleFactor = 0.7;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\watermarked-sample.docx");
}
```
Run the program. A watermark will be added at a specified position and will have the specified look.

The code below demonstrates how to specify the desired watermark appearance and position before applying it to the document:

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\seagull.jpg"))
{
    // Specify the desired text and font for the watermark
    ImageWatermark watermark = new ImageWatermark("C:\\Docs\\greetings-stamp.png");
    // Specify watermark position, rotation and opacity
    watermark.HorizontalAlignment = HorizontalAlignment.Right;
    watermark.VerticalAlignment = VerticalAlignment.Top;
    watermark.RotateAngle = 15;
    watermark.IsBackground = false;
    watermark.Opacity = 0.8;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\custom-image-watermark.jpg");
}
```
Run the program. An image watermark will be added at a specified position.

One of the main features of the GroupDocs.Watermark library is adding text watermarks to documents. You may add watermarks to documents or images from local disks, as well as from streams. For a full list of supported document formats, check [Supported formats](/net/watermark/getting-started/supported-document-formats/).

To add a text watermark perform the following steps:

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> an instance of the `Watermarker` class for a local file or file stream;
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark/constructors/main" target="_blank" rel="nofollow noopener noreferrer">Create</a> an instance of the `TextWatermark` class and specify the desired text and font for the watermark;
3. (Optionally.) Specify the watermark <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark/properties/foregroundcolor" target="_blank" rel="nofollow noopener noreferrer">color</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">horizontal</a> and <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">vertical</a> alignments;
4. Call the <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> method to apply the watermark to the document;
5. Call the <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> method to store the document in a new location.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\contract.docx"))
{
    // Specify the desired text and font for the watermark
    TextWatermark watermark = new TextWatermark("Contract Draft", 
        new Font("Arial", 60, FontStyle.Bold));
    // Specify font color and text opacity, rotation and alignments
    watermark.ForegroundColor = Color.DarkGreen;
    watermark.Opacity = 0.5;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\watermarked-contract.docx");
}
```
Run the program. A new watermarked document will appear in the specified path.

### What's next

GroupDocs.Watermark offers many more capabilities for adding text watermarks. For example, it allows specifying background and foreground colors, formatting, text opacity, use of absolute or relative positioning, and so on. To learn more about this, see the [Adding text watermarks](/net/watermark/developer-guide/advanced-usage/adding-watermarks/adding-text-watermarks/) article of the "Advanced usage" section.

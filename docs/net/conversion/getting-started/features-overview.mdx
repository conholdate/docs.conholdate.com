## File conversion
This article describes the salient features of file conversion API using C#.

GroupDocs.Conversion main feature is the ability to convert any document from any of supported source document formats into any supported target format (check the list of [supported formats](/net/conversion/getting-started/supported-document-formats/)). All these conversions are possible without any additional software installed (like Microsoft Office, Apache Open Office, Adobe Acrobat Reader and others).
GroupDocs.Conversion provides a flexible set of settings to customize the conversion process to fulfill your needs:

### Convert specific document page(s)

Along with the whole document conversion to the desired target format, it could be useful to convert specific document pages or page ranges. For such partial document conversion, you should specify desired page numbers to convert using the <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pages" rel="nofollow">Pages</a> property of the `ConvertOptions` class.

### Auto-detect source document format

In some cases, the source file could be presented in a form of a byte stream, so the file extension is unknown.
Luckily GroupDocs.Conversion for .NET is smart enough to [detect source document format](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-stream/#get-information-about-files-from-a-stream) on the fly.

### Load source document with extended options

There are lots of modifications that are possible during the file conversion process:

- specify a password for [password-protected documents](/net/conversion/developer-guide/advanced-usage/loading/load-password-protected-document/);
- show/hide document [comments](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/) and [annotations](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-pdf-document-with-options/);
- [show/hide markup and track changes](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/) for Word documents;
- [show hidden sheets](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-spreadsheet-document-with-options/) when converting Excel files or not;
- set the [text file encoding](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-txt-document-with-options/) and many more;

### Obtain all supported conversion formats list

You can obtain the [complete list of possible conversions](/net/conversion/developer-guide/basic-usage/get-possible-conversions/) that are supported by GroupDocs.Conversion for .NET library. Also, it is possible to get [allowed conversions](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/get-default-convert-options-for-target-format/) for the specific file format.

### Fonts replacement

It is a common use case when a source document references some specific fonts that are not present in the environment where you launch your application. GroupDocs.Conversion for .NET provides a solution - you can [substitute missing fonts](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/#specify-font-substitution) with fonts of your choice that will preserve your document appearance. You can also [subscribe to the `OnFontSubstituted` event](/net/conversion/developer-guide/advanced-usage/conversion-events/#font-substitution-notifications) to be notified whenever a font is substituted during conversion.

### Watermarking converted document

You can [add a text or an image watermark](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/add-watermark/) to any page of the converted document and choose its desired dimensions, color and font size.

## Document information extraction

GroupDocs.Conversion allows to obtain basic [information about source document](/net/conversion/developer-guide/basic-usage/get-document-info/) - file type, pages count etc. Dependent on the source file type some format-specific information can be extracted, for example:

- [CAD](/net/conversion/developer-guide/basic-usage/get-document-info/#cad-drawings) - list of layers and layouts in a CAD document;
- [Email](/net/conversion/developer-guide/basic-usage/get-document-info/#emails) – list of attachments;
- [PDF](/net/conversion/developer-guide/basic-usage/get-document-info/#pdf-documents) – title, author, table of contents and more;
- [Project Management](/net/conversion/developer-guide/basic-usage/get-document-info/#project-management-documents) – project start and end dates.

## Load documents from different sources

With GroupDocs.Conversion you are not limited to [local files](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-local-disk/) only. It also supports loading documents from [stream](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-stream/), [FTP](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-ftp/), [remote URLs](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-url/), as wel as from [Amazon S3](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-amazon-s3-storage/) and [Azure](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-azure-blob-storage/) clouds.

## Caching results

GroupDocs.Conversion supports [conversion result caching](/net/conversion/developer-guide/advanced-usage/caching/) to local disk by default. However, any type of cache storage can be supported by implementing appropriate interfaces – Amazon S3, Dropbox, Google Drive, Windows Azure, Redis or any other.

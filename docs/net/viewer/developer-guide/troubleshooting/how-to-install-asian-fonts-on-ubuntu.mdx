This page describes the installation of the Asian Fonts on <a href="https://wiki.ubuntu.com/Releases" rel="nofollow">Ubuntu 20.04 LTS</a> using the <a href="https://wiki.debian.org/apt-get" rel="nofollow">apt-get</a> utility. On the previous versions of Ubuntu, the process is quite the same.

To install Asian Fonts on Ubuntu, follow these steps:

1. Browse to <a href="https://packages.ubuntu.com/" rel="nofollow">packages.ubuntu.com</a>.

2. At <a href="https://packages.ubuntu.com/focal/translations/" rel="nofollow">packages.ubuntu.com/focal/translations/</a>, search for the Japanese language support packages. Find all entries starting with "language-pack-" and containing "Japanese" as follows:

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu.png)

3. Install the <a href="https://packages.ubuntu.com/focal/translations/language-pack-ja" rel="nofollow">language-pack-ja</a> package. The language-pack-ja-base package is installed automatically as first one depends on it.

4. Run Ubuntu in a Docker container:

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_1.png)

5. Execute the following command to update the packages list with updates and new packages:


<Tabs groupId="example1">


<TabItem value="shell" label="Shell" default>

```sh
apt-get update
```

</TabItem>


</Tabs>


![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_2.png)

6. Excecute the following command to install the Japanese language support:


<Tabs groupId="example2">


<TabItem value="shell" label="Shell" default>

```sh
apt-get install -y language-pack-ja
```

</TabItem>


</Tabs>


![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_3.png)

7. Wait for the message "Generation complete."

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_4.png)

To install other Asian languages, use the following commands:


<Tabs groupId="example3">


<TabItem value="shell" label="Shell" default>

```sh
apt-get install -y language-pack-zh*
apt-get install -y language-pack-ko
```

</TabItem>


</Tabs>

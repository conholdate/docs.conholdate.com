You can protect a PDF document by setting the following parameters:

* permissions
* password to open document
* password to change permissions

To protect a PDF document, follow these steps:

1. Create an instance of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a> class. Specify the source document path as a constructor parameter.
2. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security" rel="nofollow">Security</a> object.
3. To specify a password to open the document, set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security/properties/documentopenpassword" rel="nofollow">DocumentOpenPassword</a> property.
4. To specify a password to change restrictions, set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security/properties/permissionspassword" rel="nofollow">PermissionsPassword</a> property. 
5. To specify the document permissions, set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/permissions" rel="nofollow">Permissions</a> property.
6. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" rel="nofollow">PdfViewOptions</a> object. Specify the saving path format for the rendered document.
7. Initialize the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions/properties/security" rel="nofollow">Security</a> property of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" rel="nofollow">PdfViewOptions</a> object with the object created in steps 2-5.
8. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" rel="nofollow">View</a> method of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a> object. Specify the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" rel="nofollow">PdfViewOptions</a> object as the parameter.

The following code snippet shows how to protect the output PDF document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer;
// ...

using(Viewer viewer = new Viewer("sample.docx"))
{
    // Specify the security settings.
    Security security = new Security();
    security.DocumentOpenPassword = "o123";
    security.PermissionsPassword = "p123";
    security.Permissions = Permissions.AllowAll ^ Permissions.DenyPrinting;

    // Create a PDF file.
    PdfViewOptions viewOptions = new PdfViewOptions();
    
    // Apply the security settings
    viewOptions.Security = security;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Specify the security settings.
            Dim security As Security = New Security()
            security.DocumentOpenPassword = "o123"
            security.PermissionsPassword = "p123"
            security.Permissions = Permissions.AllowAll Xor Permissions.DenyPrinting

            ' Create a PDF file.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()

            ' Apply the security settings
            viewOptions.Security = security
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

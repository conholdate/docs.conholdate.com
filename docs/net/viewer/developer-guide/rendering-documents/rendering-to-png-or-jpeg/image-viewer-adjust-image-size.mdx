GroupDocs.Viewer for .NET is included in Conholdate.Total for .NET.
:::

To specify the output image size, set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/width" rel="nofollow">Width</a> and <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/height" rel="nofollow">Height</a> properties of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" rel="nofollow">JpgViewOptions</a> or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" rel="nofollow">PngViewOptions</a> classes. Specify the value in pixels.


:::info
GroupDocs.Viewer applies the aspect ratio automatically applied when you set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/width" rel="nofollow">Width</a> or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/height" rel="nofollow">Height</a> value.
:::


The following code snippet shows how to set the image width or height.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a JPG file.
    JpgViewOptions viewOptions = new JpgViewOptions();
    
    // Specify the width and height.
    viewOptions.Width = 600;
    viewOptions.Height = 800;
    
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create a JPG file.
            Dim viewOptions As JpgViewOptions = New JpgViewOptions()
        
            ' Specify the width and height.
            viewOptions.Width = 600
            viewOptions.Height = 800
        
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

Decreasing the JPG images quality reduces the size of the output file.

To adjust images quality, set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/quality" rel="nofollow">Quality</a> property of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" rel="nofollow">JpgViewOptions</a> class. The value must be between 1 (minimum quality) and 100. The default value is 90.

To set the image quality, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a> class. Specify the source document path as a constructor parameter.
1. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" rel="nofollow">JpgViewOptions</a> object.
2. Set the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/quality" rel="nofollow">Quality</a> value.
3. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" rel="nofollow">View</a> method of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a> object. Specify the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" rel="nofollow">JpgViewOptions</a> object as the parameter.

The following code snippet shows how to adjust quality of the output JPG image:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a JPG file.
    JpgViewOptions viewOptions = new JpgViewOptions();
    
    // Specify the JPG image quality.
    viewOptions.Quality = 50;    
    viewer.View(viewOptions);
}
```

</TabItem>

The encryption protects data and allows only authorized people to open the file. When a file is encrypted, the password must be specified to open the file. To learn how to identify the encrypted file, please refer to the [Check if a file is encrypted](/net/viewer/developer-guide/retrieving-document-information/how-to-check-if-file-is-encrypted/) page.

To load and render an encrypted document, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> (or <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, or <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>, or <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>) object.
2. Set a password in the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions/properties/password" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.Password</a> property.

:::info
If the password is not specified, GroupDocs.Viewer throws <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.exceptions/passwordrequiredexception" target="_blank" rel="nofollow noopener noreferrer">PasswordRequiredException</a>.
:::

3. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> method.

The following code snippet shows how to load and render an encrypted document:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Specify a password.
LoadOptions loadOptions = new LoadOptions();
loadOptions.Password = "123456";
// Render a file.
using (Viewer viewer = new Viewer("encrypted.docx", loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        ' Specify a password.
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.Password = "123456"
        ' Render a file.
        Using viewer As Viewer = New Viewer("encrypted.docx", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

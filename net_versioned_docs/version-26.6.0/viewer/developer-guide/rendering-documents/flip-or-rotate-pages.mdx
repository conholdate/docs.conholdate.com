![Flip or rotate pages](/net/viewer/images/flip-or-rotate-pages.png)

To rotate a page when rendering document, use the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/methods/rotatepage" target="_blank" rel="nofollow noopener noreferrer">RotatePage</a> method of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions" target="_blank" rel="nofollow noopener noreferrer">ViewOptions</a> class. This method has the following two parameters:

1. page number
2. rotation angle

The rotation angle is one of the following:

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On90Degree</a> rotate page on 90-degree clockwise
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On180Degree</a> rotate page on 180-degree clockwise
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On270Degree</a> rotate page on 270-degree clockwise

The following code snippet shows how to rotate output pages when rendering a document as PDF:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a PDF file.
    PdfViewOptions viewOptions = new PdfViewOptions();
    // Rotate the first page.
    viewOptions.RotatePage(1, Rotation.On90Degree);
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create a PDF file.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()
            ' Rotate the first page.
            viewOptions.RotatePage(1, Rotation.On90Degree)
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

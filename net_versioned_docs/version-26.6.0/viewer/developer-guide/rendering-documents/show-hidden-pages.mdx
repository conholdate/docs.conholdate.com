GroupDocs.Viewer for .NET is included in Conholdate.Total for .NET.
:::

By default, GroupDocs.Viewer does not render hidden items. To render them, set the RenderHiddenPages property of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewoptions/" target="_blank" rel="nofollow noopener noreferrer">ViewOptions</a> class to `true`.

This feature is supported for the following format families:

* Visio documents (for hidden pages)
* PowerPoint presentations (for hidden slides)
* Spreadsheets files (for hidden worksheets)

The following code snippet shows how to enable rendering of hidden items:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.pptx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();

    // Enable rendering of hidden items.
    viewOptions.RenderHiddenPages = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.pptx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
        
            ' Enable rendering of hidden items.
            viewOptions.RenderHiddenPages = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

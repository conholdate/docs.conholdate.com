The <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> and <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> classes implement the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/imaxsizeoptions" target="_blank" rel="nofollow noopener noreferrer">IMaxSizeOptions</a> interface that contains properties for size limits:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
/// <summary>
/// Limits of image size options interface. 
/// </summary>
public interface IMaxSizeOptions
{
    /// <summary>
    /// Max width of an output image in pixels.
    /// </summary>
    int MaxWidth { get; set; }

    /// <summary>
    /// Max height of an output image in pixels.
    /// </summary>
    int MaxHeight { get; set; }
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

    ''' <summary>

    ''' </summary>
    Property MaxWidth As Integer

    ''' <summary>
    ''' Max height of an output image in pixels.
    ''' </summary>
    Property MaxHeight As Integer
End Interface
```

</TabItem>

:::warning
If you set the ImageWidth/ImageHeight options, the ImageMaxWidth/ImageMaxHeight options are ignored.
:::


To set the ImageMaxWidth/ImageMaxHeight options, follow these steps:

1. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> object.
2. Instantiate the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> object.
3. Set MaxWidth and/or MaxHeight values.
4. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> method.

The following code snippet shows how to set the output image size limits:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.jpg"))
{
    // Create a JPG or PNG file.
    JpgViewOptions viewOptions = new JpgViewOptions("result_{0}.jpg");
    // or PngViewOptions viewOptions = new PngViewOptions("result_{0}.png");
    
    // Specify the maximum width and height.
    viewOptions.MaxWidth = 800;
    viewOptions.MaxHeight = 600;

    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb

            viewOptions.MaxWidth = 800
            viewOptions.MaxHeight = 600
        
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

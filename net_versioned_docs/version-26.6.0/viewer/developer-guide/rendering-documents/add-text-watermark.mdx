To add a watermark to the HTML/JPG/PNG/PDF output, follow these steps:

1. Create an instance of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> class (or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOption</a>, or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>);
2. Create a <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> object and populate its properties;
3. Assign the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> object to <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.Watermark</a> (or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Watermark</a>, or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions.</a>[Watermark](https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions), or <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions.Watermark</a>) property;
4. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> method.

The following code snippet shows how to apply the watermark to the output pages.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create an HTML file.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Add watermark
    viewOptions.Watermark = new Watermark("This is a watermark");
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create an HTML file.
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources   ()
            ' Add watermark
            viewOptions.Watermark = New Watermark("This is a watermark")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

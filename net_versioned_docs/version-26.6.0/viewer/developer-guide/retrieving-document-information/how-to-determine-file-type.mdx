A file type is a standard way that information is encoded for storage in a computer file. For example, Microsoft Word (.docx) and Adobe PDF (.pdf) are two different file types.

Using GroupDocs.Viewer, you can determine the file type in one of the following ways:
* [File extension](#determine-file-type-by-the-file-extension);
* [Media type](#determine-file-type-by-media-type);
* [File signature](#determine-file-type-by-stream).

## Determine the file type by the file extension

To determine the file type from the file extension, use the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/fromextension/#fromextension" target="_blank" rel="nofollow noopener noreferrer">FromExtension()</a> method of <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

The following code snippet shows how to determine a file type using the file extension:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

// Specify a file extension.
string extension = ".docx";
// Set a file type using the extension.
FileType fileType = FileType.FromExtension(extension);
// Display the extension and the file type.
Console.WriteLine($"Extension {extension}; File type: {fileType}.");
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        ' Specify a file extension.
        Dim extension As String = ".docx"
        ' Set a file type using the extension.
        Dim fileType As FileType = FileType.FromExtension(extension)
        ' Display the extension and the file type.
        Console.WriteLine($"Extension {extension}; File type: {fileType}.")
    End Sub
End Module
```

</TabItem>

## Determine file type by media type

If you receive a file via the Internet, you can check its media type header using the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/methods/frommediatype" target="_blank" rel="nofollow noopener noreferrer">FromMediaType()</a> method of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class.

The following code snippet shows how to determine a file type using the media header:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

string mediaType = "application/pdf";
FileType fileType = FileType.FromMediaType(mediaType);
Console.WriteLine($"Media-type {mediaType}; File type: {fileType}.");
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Dim mediaType As String = "application/pdf"
        Dim fileType As FileType = FileType.FromMediaType(mediaType)
        Console.WriteLine($"Media-type {mediaType}; File type: {fileType}.")
    End Sub
End Module
```

</TabItem>


</Tabs>

## Determine file type by the stream

When you do not know a file extension or media type header, you can try determining file type by using the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/methods/fromstream" target="_blank" rel="nofollow noopener noreferrer">FromStream()</a> method of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> class. GroupDocs.Viewer will try reading the signature and mapping it to the file type.

The following code snippet shows how to determine a file type using the file signature:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using System;
using System.IO;
using GroupDocs.Viewer;
// ...

using (Stream stream = File.OpenRead("sample.docx"))
{
    FileType fileType = FileType.FromStream(stream);
    Console.WriteLine($"File type: {fileType}.");
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports System.IO
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Using stream As Stream = File.OpenRead("sample.docx")
            Dim fileType As FileType = FileType.FromStream(stream)
            Console.WriteLine($"File type: {fileType}.")
        End Using
    End Sub
End Module
```

</TabItem>

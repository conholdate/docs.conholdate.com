Render attachments in the same way as any other documents.

To view attachments, follow these steps:

1. Instantiate the first <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> object. Specify a file that contains attachments.
2. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/saveattachment" target="_blank" rel="nofollow noopener noreferrer">SaveAttachment</a> method to save the attachment (to local disk, memory stream, etc).
3. Instantiate the second <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> object. Specify the previously saved attachment.
4. Specify the view options depending on the output format - <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>/<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>/<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>/<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>.
5. Call the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> method.

The following code snippet shows how to render attachments from the MSG file:


:::info
NOTE: provided code snippet suits all format families that support attachments: emails, Outlook data files, archives, and PDF documents.
:::



<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

// Specify attachment.
Attachment attachment = new Attachment("attachment-word.doc", @"C:\Output\attachment-word.doc");

// Create a stream for attachment.
MemoryStream attachmentStream = new MemoryStream();

//Save attachment
using (Viewer viewer = new Viewer("sample.msg"))
{
    viewer.SaveAttachment(attachment, attachmentStream);
}

// Render attachment
using (Viewer viewer = new Viewer(attachmentStream))
{
    HtmlViewOptions options = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(options);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        ' Specify attachment.
        Dim attachment As Attachment = New Attachment("attachment-word.doc", "C:\Output\attachment-word.doc")
    
        ' Create a stream for attachment.
        Dim attachmentStream As MemoryStream = New MemoryStream()
    
        'Save attachment
        Using viewer As Viewer = New Viewer("sample.msg")
            viewer.SaveAttachment(attachment, attachmentStream)
        End Using
    
        ' Render attachment
        Using viewer As Viewer = New Viewer(attachmentStream)
            Dim options As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(options)
        End Using
    End Sub
End Module
```

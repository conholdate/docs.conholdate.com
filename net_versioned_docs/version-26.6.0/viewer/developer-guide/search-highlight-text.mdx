Starting from <a href="https://releases.groupdocs.com/viewer/net/release-notes/2025/groupdocs-viewer-for-net-25-4-release-notes/" target="_blank" rel="nofollow noopener noreferrer">version 25.4</a> the GroupDocs.Viewer is able to search the text spans in the loaded documents and highlight the found text. This feature can be described with the next three basic statements:

1. Searching text is supported for almost all document family formats, which may have textual content: all formats within WordProcessing family (DOC, DOCX, ODT, RTF, etc.), Spreadsheet (XLS, XLSX, ODS, CSV, etc.), Presentation (PPT, PPTX, PPS, POT, etc.), e-Books (ePub, AZW3, Mobi), and fixed-layout formats (PDF and XPS).
2. Search may be performed by entered search term (text literal) or by a regular expression (RegEx).
3. Highlighting of the found text is adjustable — it is possible to set the color of the found text (foreground color) and/or the color of the background.


Once a search operation is performed and some text is found, the document may be rendered to the HTML, PDF, PNG, or JPEG, and the found text will be highlighted in these produced documents. Just need to remember that search must be done _before_ rendering the document, not after.

In order to perform a search a new public instance method was added to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> class — <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/search/" target="_blank" rel="nofollow noopener noreferrer">`void Search(Options.SearchHighlightOptions options)`</a>. As it is seen from its signature, this method obtains on input an instance of the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/SearchHighlightOptions/" target="_blank" rel="nofollow noopener noreferrer">`Options.SearchHighlightOptions`</a> class. This class contains both a search term (phrase), search options, and highlight options, applied to the found text. This is described in detail below:

- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/searchterm/" target="_blank" rel="nofollow noopener noreferrer">`SearchTerm`</a> property of a <a href="https://learn.microsoft.com/en-us/dotnet/api/system.string" target="_blank" rel="nofollow noopener noreferrer">`System.String`</a> type allows to specify a search text, which must be highlighted if found, or a regex pattern for search.
- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/issearchtermregex/" target="_blank" rel="nofollow noopener noreferrer">`IsSearchTermRegEx`</a> property of <a href="https://learn.microsoft.com/en-us/dotnet/api/system.boolean" target="_blank" rel="nofollow noopener noreferrer">boolean</a> type indicates whether the value of the previously described `SearchTerm` property should be treated as a text literal (`false`) or as a regular expression (`true`). Default is `false` — treat as a text literal.
- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/backgroundcolor/" target="_blank" rel="nofollow noopener noreferrer">`BackgroundColor`</a> property of <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.drawing/argb32color/" target="_blank" rel="nofollow noopener noreferrer">`Argb32Color`</a> type allows to specify a background color of the found text. By default, if this property is not specified, or its value is fully transparent, a yellow color will be applied to the background of the found text.
- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/foregroundcolor/" target="_blank" rel="nofollow noopener noreferrer">`ForegroundColor`</a> property of <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.drawing/argb32color/" target="_blank" rel="nofollow noopener noreferrer">`Argb32Color`</a> type allows to specify a color, which will be applied to the found text itself (foreground color). By default, if this property is not specified, or its value is fully transparent, the color of found text will be untouched.

Summing up, in order to search for some text and highlight it using GroupDocs.Viewer, need to perform the next four steps:

1. Load the input document to the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> class through its constructor.
2. Create an instance <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/SearchHighlightOptions/" target="_blank" rel="nofollow noopener noreferrer">`SearchHighlightOptions`</a> class and tune its options — specify at least a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/searchterm/" target="_blank" rel="nofollow noopener noreferrer">`SearchTerm`</a> property.
3. Invoke the <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/search/" target="_blank" rel="nofollow noopener noreferrer">`Viewer.Search(SearchHighlightOptions)`</a> method with a previously created and prepared <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/searchhighlightoptions/" target="_blank" rel="nofollow noopener noreferrer">`SearchHighlightOptions`</a> instance.
4. Render the document to the HTML, PDF, PNG, and/or JPEG using a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/view/#view" target="_blank" rel="nofollow noopener noreferrer">`Viewer.View()`</a> method.

Code sample below shows loading two distinct documents — DOCX and PDF, and performing search in them using text literal and RegEx. Finally, documents are saved to HTML and PNG.



<Tabs groupId="Search">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Creating two instances of SearchHighlightOptions and adjusting them
SearchHighlightOptions byLiteral = new SearchHighlightOptions()
{
    SearchTerm = "some text",
    IsSearchTermRegEx = false
};
SearchHighlightOptions byRegEx = new SearchHighlightOptions()
{
    SearchTerm = @"text\s*#(\d+)",
    IsSearchTermRegEx = true
};

// Loading two documents to the two instances of Viewer class
using (Viewer docxViewer = new Viewer("sample.docx"))
using (Viewer pdfViewer = new Viewer("sample.pdf"))
{
    // Performing search in both Viewer instances
    docxViewer.Search(byLiteral);
    pdfViewer.Search(byRegEx);

    // Rendering both documents - 1st to HTML and 2nd to PNG
    docxViewer.View(HtmlViewOptions.ForEmbeddedResources());
    pdfViewer.View(new PngViewOptions());
}
```

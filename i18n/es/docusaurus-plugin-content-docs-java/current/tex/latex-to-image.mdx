**Aspose.TeX para Java** proporciona funciones para convertir archivos LaTeX a diversos formatos de imágenes rasterizadas.

## Cómo convertir LaTeX a PNG {#how-to-convert-latex-to-png}
  
Echemos un vistazo más detallado al código Java que ofrece la forma más sencilla de convertir LaTeX al formato PNG.

Establezca `inputFile` en la ruta completa de su archivo LaTeX, como `hello-world.ltx`, y `outputDirectory` en una carpeta de salida existente. Importe las clases de `com.aspose.tex` y `com.aspose.tex.rendering` utilizadas en cada fragmento. El método que realiza la llamada debe manejar o declarar las excepciones. Aplique una licencia tal como se describe en la [guía de licencias](/java/tex/licensing/) para evitar restricciones de evaluación. Los ejemplos seleccionan el procesamiento no interactivo y cierran los recursos de salida. El ejemplo de PNG establece la resolución en 300 DPI. Para la entrada de una sola página `hello-world.ltx`, los archivos de salida automáticos son `hello-world.png`, `hello-world.jpg`, `hello-world.tif`, `hello-world.bmp` o `hello-world.svg`, según el formato seleccionado.

```java
// Convert LaTeX to PNG.
// inputFile is the full input path; outputDirectory is an existing output folder.
TeXOptions options = TeXOptions.consoleAppOptions(TeXConfig.objectLaTeX());
OutputFileSystemDirectory output = new OutputFileSystemDirectory(outputDirectory);
options.setOutputWorkingDirectory(output);
PngSaveOptions saveOptions = new PngSaveOptions();
saveOptions.setResolution(300);
options.setSaveOptions(saveOptions);
options.setInteraction(Interaction.NonstopMode);

ImageDevice device = new ImageDevice();
TeXJobResult result;
try {
    result = new TeXJob(inputFile, device, options).run();
} finally {
    device.dispose();
    output.close();
}
```

Entonces, lo primero que necesitamos hacer (a veces no lo primero, como descubriremos más adelante) es crear una instancia de la <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/" target="_blank" rel="nofollow noopener noreferrer">TeXOptions</a> clase. El único método estático que hace esto es <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#consoleAppOptions-com.aspose.tex.TeXConfig-" target="_blank" rel="nofollow noopener noreferrer">consoleAppOptions()</a>, así que no nos preocupemos por el significado de su nombre. El método toma el <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texconfig/#objectLaTeX--" target="_blank" rel="nofollow noopener noreferrer">instancia de `objectLaTeX()`</a> de la <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texconfig/" target="_blank" rel="nofollow noopener noreferrer">TeXConfig</a> clase, que es exactamente adecuada para convertir un archivo [LaTeX](/net/tex/latex-io/#latex-file). Esta configuración instruye al motor Object TeX para que cargue el formato Object LaTeX y esté listo para aceptar el archivo LaTeX. El formato Object LaTeX es en realidad solo el [LaTeX](/net/tex/what-is-latex/) formato, excepto que utiliza [Object TeX](/net/tex/aspose-tex-and-object-tex/#object-tex) primitivas específicas para configurar las métricas de la página.

La primera de las opciones requeridas es <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#getOutputWorkingDirectory--" target="_blank" rel="nofollow noopener noreferrer">DirectorioDeSalida</a> que define el espacio, o área, donde se escribirá la salida de TeX. [Aquí](/java/tex/aspose-tex-output/) son los detalles sobre el concepto de directorio de salida en **Aspose.TeX para Java**. En este ejemplo, utilizamos el <a href="https://reference.aspose.com/tex/java/com.aspose.tex/outputfilesystemdirectory/" target="_blank" rel="nofollow noopener noreferrer">OutputFileSystemDirectory</a> clase, que nos permite escribir la salida en el directorio o carpeta especificado.

La segunda opción es una <a href="https://reference.aspose.com/tex/java/com.aspose.tex.rendering/saveoptions/" target="_blank" rel="nofollow noopener noreferrer">OpcionesDeGuardado</a> instancia de clase que controlará la transformación del [object model](/net/tex/aspose-tex-and-object-tex/#why-the-new-tex-is-object) al formato de destino. Dado que estamos convirtiendo LaTeX a PNG, es el <a href="https://reference.aspose.com/tex/java/com.aspose.tex.rendering/pngsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">Opciones de guardado PNG</a> instancia de clase, lo que nos permite especificar la resolución de las imágenes de salida.

A continuación, debemos crear una instancia de la <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texjob/" target="_blank" rel="nofollow noopener noreferrer">TeXJob</a> clase. Al querer convertir un archivo LaTeX almacenado en el sistema de archivos, utilizamos <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texjob/#TeXJob-java.lang.String-com.aspose.tex.rendering.Device-com.aspose.tex.TeXOptions-" target="_blank" rel="nofollow noopener noreferrer">esto</a> versión del constructor. Deberíamos especificar la ruta completa al archivo. De lo contrario, el motor buscará el archivo en el directorio actual (que está definido <a href="https://docs.oracle.com/javase/7/docs/api/java/io/File.html" target="_blank" rel="nofollow noopener noreferrer">aquí</a>) y es muy probable que no lo encuentre. Sin embargo, podemos omitir la extensión si nuestro archivo tiene la extensión *.tex*; el motor la agregará automáticamente. El segundo argumento del constructor es un <a href="https://reference.aspose.com/tex/java/com.aspose.tex.rendering/device/" target="_blank" rel="nofollow noopener noreferrer">Dispositivo</a> instancia de clase. Dado que estamos convirtiendo LaTeX a PNG, es una <a href="https://reference.aspose.com/tex/java/com.aspose.tex.rendering/imagedevice/" target="_blank" rel="nofollow noopener noreferrer">Dispositivo de imagen</a> instancia de la clase (que es común a todos los formatos de imagen admitidos). Como último argumento, pasamos las opciones de conversión recién preparadas.

Todo lo que tenemos que hacer ahora es <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texjob/#run--" target="_blank" rel="nofollow noopener noreferrer">ejecutar</a> el trabajo.

Independientemente de si la ejecución fue exitosa o no, el primer resultado que veremos será la salida de la terminal. En caso de éxito, se ve algo así:

```java
This is ObjectTeX, Version 3.1415926-1.0 (Aspose.TeX 21.8)
entering extended mode

(<input_directory>\hello-world.ltx
LaTeX2e <2011/06/27>
(article.cls
Document Class: article 2007/10/19 v1.4h Standard LaTeX document class
(size10.clo))
No file hello-world.aux.
[1]
(<output_directory>\hello-world.aux) )
Output written on hello-world.png (1 page).
Transcript written on hello-world.log.
```

Encontraremos otros productos de la ejecución del motor en la carpeta que especificamos como directorio de salida. Estos serán el archivo de transcripción (`.log`) y, **¡Voilà!**, el archivo o archivos de imagen PNG principal.

## Una forma alternativa de escribir el archivo o archivos PNG de salida principal  {#an-alternative-way-to-write-the-main-output-png-files}
  
Existe otra forma de obtener los datos de la imagen como un array de arrays de bytes, donde cada array en la segunda dimensión representa los datos de imagen de una página independiente.

```java
// Convert LaTeX to PNG and save each page from the returned byte arrays.
// inputFile is the full input path; outputDirectory is an existing output folder.
TeXOptions options = TeXOptions.consoleAppOptions(TeXConfig.objectLaTeX());
OutputFileSystemDirectory output = new OutputFileSystemDirectory(outputDirectory);
options.setOutputWorkingDirectory(output);
PngSaveOptions saveOptions = new PngSaveOptions();
saveOptions.deviceWritesImages(false);
options.setSaveOptions(saveOptions);
options.setInteraction(Interaction.NonstopMode);

ImageDevice device = new ImageDevice();
TeXJobResult result;
try {
    result = new TeXJob(inputFile, device, options).run();
    byte[][] pages = device.getResult();
    for (int i = 0; i < pages.length; i++) {
        Files.write(Paths.get(outputDirectory, "page-" + (i + 1) + ".png"), pages[i]);
    }
} finally {
    device.dispose();
    output.close();
}
```

<a href="https://gist.github.com/aspose-com-gists/a30f406f6b8ace1b7d15c68a1df75c6d#file-example-convertlatextopng-alternative-java" target="_blank" rel="nofollow noopener noreferrer">Ejemplo: ConvertLaTeXToPNG-Alternative.java</a> alojado con ❤ por <a href="https://github.com/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>

El ejemplo manual también requiere `java.nio.file.Files` y `java.nio.file.Paths`. Guarda los datos de página de `ImageDevice.getResult()` como `page-1.png`, `page-2.png`, etc. Dado que establece `deviceWritesImages(false)`, la salida automática en PNG se deshabilita y las páginas guardadas manualmente no se duplican en el directorio de salida. Esto difiere de la [salida de flujo PDF](/java/tex/latex-to-pdf/#an-alternative-way-to-write-the-main-output-pdf-file), donde el flujo define el destino de un único documento PDF.

## Sobre las opciones de entrada {#about-input-options}
  
En caso de que nuestro archivo de entrada principal requiera dependencias, por ejemplo, paquetes, que no están incluidos en el sistema LaTeX básico ni en los paquetes admitidos, **DEBEMOS** establecer la opción <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#getRequiredInputDirectory--" target="_blank" rel="nofollow noopener noreferrer">RequiredInputDirectory</a> de forma similar a como establecemos la opción <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#getOutputWorkingDirectory--" target="_blank" rel="nofollow noopener noreferrer">OutputWorkingDirectory</a> y colocar las dependencias en ese directorio. Las dependencias pueden organizarse arbitrariamente en subdirectorios. En caso de que tengamos nuestros propios archivos que incluir durante el proceso de composición tipográfica, por ejemplo, archivos gráficos externos, **DEBEMOS** también establecer <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#getInputWorkingDirectory--" target="_blank" rel="nofollow noopener noreferrer">InputWorkingDirectory</a> utilizando la ruta hacia la ubicación donde se recopilan dichos archivos. También podemos colocar el archivo de entrada principal en algún lugar dentro del directorio de entrada y pasar la ruta relativa al constructor `TeXJob` (o no especificar ninguna ruta en absoluto si el archivo de entrada principal se encuentra en la raíz). [Aquí](/java/tex/aspose-tex-input/) se ofrecen detalles sobre el concepto de directorio de entrada en **Aspose.TeX para Java** y las implementaciones proporcionadas.

Otras opciones de trabajo de TeX se discuten [aquí](/java/tex/other-options/).

## Cómo convertir LaTeX a SVG {#how-to-convert-latex-to-svg}
  
Otro formato de destino admitido es <a href="https://en.wikipedia.org/wiki/SVG" target="_blank" rel="nofollow noopener noreferrer">**SVG**</a>. **Gráficos Vectoriales Escalables (SVG)** es un formato de imagen vectorial basado en XML para definir gráficos bidimensionales, con soporte para interactividad y animación.

Las imágenes **SVG** se definen en un formato de gráficos vectoriales y se almacenan en archivos de texto XML. Esto significa que las imágenes **SVG** pueden escalarse sin pérdida de calidad, y los archivos **SVG** pueden buscarse, indexarse, controlarse mediante scripts y comprimirse. Los archivos de texto XML pueden crearse y editarse con editores de texto o editores de gráficos vectoriales. Estos archivos son procesados por los navegadores web más utilizados.

Además, existe la biblioteca <a href="https://products.aspose.com/svg/" target="_blank" rel="nofollow noopener noreferrer">**Aspose.SVG**</a>, que ofrece diversas funcionalidades basadas en el formato **SVG**, como crear, cargar, editar y convertir documentos **SVG**.

La conversión a SVG es tan sencilla como la [conversión a formatos de imagen rasterizada](/java/tex/latex-to-image/), salvo que, además del <a href="https://reference.aspose.com/tex/java/com.aspose.tex/texoptions/#getSaveOptions--" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>, debemos cambiar el dispositivo por una instancia de la clase <a href="https://reference.aspose.com/tex/java/com.aspose.tex.rendering/svgdevice/" target="_blank" rel="nofollow noopener noreferrer">SvgDevice</a>.

```java
// Convert LaTeX to SVG.

options.setSaveOptions(new SvgSaveOptions());
options.setInteraction(Interaction.NonstopMode);

SvgDevice device = new SvgDevice();
TeXJobResult result;
try {
    result = new TeXJob(inputFile, device, options).run();
} finally {
    device.dispose();
    output.close();

```

### Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
La versión de evaluación de Aspose.TeX (sin una licencia especificada) proporciona toda la funcionalidad del producto, excepto que solo se pueden obtener hasta las primeras cuatro páginas en el documento de salida. Además, dichas páginas aparecerán marcadas con una marca de agua de modo de evaluación.

Si desea probar Aspose.TeX sin las limitaciones de la versión de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">How to get a Temporary License?</a> para obtener más información.

### Aplicar la licencia mediante un objeto de archivo o flujo {#apply-the-license-using-file-or-stream-object}
  
Utilice el método <a href="https://reference.aspose.com/tex/java/com.aspose.tex/license/#setLicense-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">License.setLicense</a> para licenciar el componente. En los ejemplos siguientes, reemplace `licenseFilePath` por la ruta completa al archivo de licencia. El método que realice la llamada debe manejar o declarar `Exception`.

#### Cargar una licencia desde un archivo {#loading-a-license-from-file}
  
Este fragmento de código aplica una licencia almacenada en un archivo.

```java
// Apply a license from a file.
// licenseFilePath is the full path to your Aspose.TeX for Java license.
com.aspose.tex.License license = new com.aspose.tex.License();
license.setLicense(licenseFilePath);
```

#### Carga de una licencia desde un objeto de flujo (Stream) {#loading-a-license-from-a-stream-object}
  
Estos fragmentos de código inicializan la licencia a partir de un objeto de flujo.

```java
// Apply a license from a stream and close the stream after use.
// licenseFilePath is the full path to your Aspose.TeX for Java license.
com.aspose.tex.License license = new com.aspose.tex.License();
try (java.io.InputStream licenseStream = new java.io.FileInputStream(licenseFilePath)) {
    license.setLicense(licenseStream);
}
```

### Licencia basada en uso (Metered License) {#metered-license}
  
Aspose.TeX ofrece un mecanismo alternativo de licencias denominado *Licencia basada en uso* (*Metered Licensing*). Si un cliente desea que se le facture según el uso de las funcionalidades de la API, puede aplicar una *Licencia basada en uso*, lo cual es tan sencillo como aplicar un par de claves criptográficas. Para obtener más detalles, consulte la <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">sección de preguntas frecuentes sobre la Licencia basada en uso</a>.

Las claves pública y privada de una licencia basada en uso pueden configurarse mediante una instancia de la clase <a href="https://reference.aspose.com/tex/java/com.aspose.tex/metered/" target="_blank" rel="nofollow noopener noreferrer">*Metered*</a>, como se muestra a continuación:

```java
// Apply a metered license using your own public and private keys.
new com.aspose.tex.Metered().setMeteredKey(
        "<type public key here>",
        "<type private key here>");
```

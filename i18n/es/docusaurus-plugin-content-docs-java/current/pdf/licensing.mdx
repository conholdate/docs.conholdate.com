## Limitación de la versión de evaluación {#limitation-of-an-evaluation-version}
  
Queremos que nuestros clientes prueben exhaustivamente nuestros componentes antes de comprarlos; por lo tanto, la versión de evaluación le permite utilizarla tal como lo haría normalmente.

- **PDF creado con una marca de agua de evaluación.** La versión de evaluación de Aspose.PDF para Java proporciona todas las funcionalidades del producto completo, pero todas las páginas de los documentos PDF generados tienen una marca de agua en la parte superior que dice: «Evaluation Only. Created with Aspose.PDF. Copyright 2002-2020 Aspose Pty Ltd».

- **Límite en la cantidad de elementos de una colección que se pueden procesar.** En la versión de evaluación, desde cualquier colección solo puede procesar cuatro elementos (por ejemplo, solo 4 páginas, 4 campos de formulario, etc.).

Puede descargar la versión de evaluación de **Aspose.PDF** para Java desde <a href="https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo/com/aspose/aspose-pdf" target="_blank" rel="nofollow noopener noreferrer">Aspose Repository</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia del producto. Además, la versión de evaluación se convierte simplemente en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

Una vez que esté satisfecho con su evaluación de **Aspose.PDF**, puede <a href="https://purchase.conholdate.com/" target="_blank">adquirir una licencia</a> en el sitio web de Aspose. Familiarícese con los distintos tipos de suscripción que ofrecemos. Si tiene alguna pregunta, no dude en comunicarse con el equipo de ventas de Aspose.

Cada licencia de Aspose incluye una suscripción gratuita de un año para actualizaciones a cualquier nueva versión o corrección lanzada durante ese período. El soporte técnico es gratuito, ilimitado y se proporciona tanto a usuarios con licencia como a usuarios de la versión de evaluación.

> Si desea probar Aspose.PDF para Java sin las limitaciones de la versión de evaluación, también puede solicitar una Licencia Temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">Cómo obtener una Licencia Temporal</a>.

## Licencia clásica {#classic-license}
  
La licencia puede cargarse desde un archivo o un objeto de flujo (stream). La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.PDF.dll y especificar el nombre del archivo sin una ruta de acceso, como se muestra en el siguiente ejemplo.

La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional invalidará el archivo.

Debe establecer una licencia antes de realizar cualquier operación con documentos. Solo es necesario establecer una licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo (stream) o archivo en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo aspose-pdf-xx.x.jar.

Utilice el método `License.setLicense` para licenciar el componente. Con frecuencia, la forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.PDF.jar y especificar únicamente el nombre del archivo, sin ruta de acceso, como se muestra en el siguiente ejemplo:

:::info
A partir de Aspose.PDF para Java 4.2.0, debe llamar a las siguientes líneas de código para inicializar la licencia.
:::

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
En este ejemplo, **Aspose.PDF** intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

```java
// Initialize License Instance
com.aspose.pdf.License license = new com.aspose.pdf.License();
// Call setLicense method to set license
license.setLicense("Aspose.Pdf.Java.lic");
```

### Carga de la licencia desde un objeto de flujo  {#loading-the-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```java
// Initialize License Instance
com.aspose.pdf.License license = new com.aspose.pdf.License();
// Set license from Stream
license.setLicense(new java.io.FileInputStream("Aspose.Pdf.Java.lic"));
```

### Validar la licencia {#validate-the-license}
  
Es posible validar si la licencia se ha configurado correctamente o no. La clase Document posee el método isLicensed, que devolverá true si la licencia se ha configurado correctamente.

```java
License license = new License();
license.setLicense("Aspose.Pdf.Java.lic");
// Check if license has been validated
if (com.aspose.pdf.Document.isLicensed()) {
    System.out.println("License is Set!");
}
```

## Licencia por medición  {#metered-license}
  
Aspose.PDF permite a los desarrolladores aplicar una clave de medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen facturarse según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.

Se ha introducido una nueva clase <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/Metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar la clave de medición. A continuación se muestra un ejemplo de código que demuestra cómo configurar la clave pública y la clave privada de medición.

```java
String publicKey = "";
String privateKey = "";

Metered m = new Metered();
m.setMeteredKey(publicKey, privateKey);

// Optionally, the following two lines returns true if a valid license has been applied;
// false if the component is running in evaluation mode.
License lic = new License();
System.out.println("License is set = " + lic.isLicensed());
```

## Uso de múltiples productos de Aspose {#using-multiple-products-from-aspose}
  
Si utiliza varios productos de Aspose en su aplicación, por ejemplo Aspose.PDF y Aspose.Words, a continuación se presentan algunos consejos útiles.

- **Establezca la licencia para cada producto de Aspose por separado.** Incluso si posee un único archivo de licencia para todos los componentes, por ejemplo «Aspose.Total.lic», aún debe llamar a **License.SetLicense** por separado para cada producto de Aspose que esté utilizando en su aplicación.  
- **Utilice el nombre de clase de licencia totalmente calificado.** Cada producto de Aspose tiene una clase **License** en su espacio de nombres. Por ejemplo, Aspose.PDF tiene la clase **com.aspose.pdf.License**, y Aspose.Words tiene la clase **com.aspose.words.License**. Utilizar el nombre de clase totalmente calificado le permite evitar cualquier confusión sobre qué licencia se aplica a qué producto.

```java
// Instantiate the License class of Aspose.Pdf
com.aspose.pdf.License license = new com.aspose.pdf.License();
// Set the license
license.setLicense("Aspose.Total.Java.lic");

// Setting license for Aspose.Words for Java

// Instantiate the License class of Aspose.Words
com.aspose.words.License licenseaw = new com.aspose.words.License();
// Set the license
licenseaw.setLicense("Aspose.Total.Java.lic");
```

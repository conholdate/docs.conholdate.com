Un ejemplo de «Hola Mundo» es el camino más corto para comprender el flujo de trabajo básico de creación de PDF. En este artículo, el ejemplo crea un nuevo PDF, coloca un fragmento de texto con estilo en la página y guarda el archivo de salida.

El ejemplo en Java sigue estos pasos:

1. Crear un objeto <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a>.
2. Agregar una <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/page/" target="_blank" rel="nofollow noopener noreferrer">Page</a> al documento.
3. Crear un <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textfragment/" target="_blank" rel="nofollow noopener noreferrer">TextFragment</a> con el texto `Hello, world!`.
4. Establecer la <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/position/" target="_blank" rel="nofollow noopener noreferrer">Position</a>, la fuente, el tamaño de fuente, el color de fondo y el color de primer plano mediante el <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textstate/" target="_blank" rel="nofollow noopener noreferrer">TextState</a> del fragmento.
5. Crear un <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textbuilder/" target="_blank" rel="nofollow noopener noreferrer">TextBuilder</a> para la página.
6. Agregar el <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textfragment/" target="_blank" rel="nofollow noopener noreferrer">TextFragment</a> a la <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/page/" target="_blank" rel="nofollow noopener noreferrer">Page</a>.
7. Guardar el <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> PDF.

El siguiente código en Java se basa en `GetStartedExamples.java`.

```java
public static void simpleExample(Path outputFile) {
    try (Document document = new Document()) {
        Page page = document.getPages().add();

        TextFragment textFragment = new TextFragment("Hello, world!");
        textFragment.setPosition(new Position(100, 600));
        textFragment.getTextState().setFontSize(12);
        textFragment.getTextState().setFont(FontRepository.findFont("TimesNewRoman"));
        textFragment.getTextState().setBackgroundColor(Color.getBlue());
        textFragment.getTextState().setForegroundColor(Color.getYellow());

        TextBuilder textBuilder = new TextBuilder(page);
        textBuilder.appendText(textFragment);

        document.save(outputFile.toString());
    }
}
```

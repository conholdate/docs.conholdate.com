## Características generales {#general-features}
  
- Escrito completamente en Java, compatible con JDK 1.8 y versiones posteriores  
- Compatible con todas las aplicaciones Java  
- Referencia de API en formato JavaDoc  
- Soporte para sistemas operativos de 32 bits  
- Soporte para sistemas operativos de 64 bits  

## Versiones de PDF compatibles {#supported-pdf-versions}
  
Aspose.PDF for Java admite las versiones de PDF 1.2, 1.3, 1.4, 1.5, 1.6 y 1.7.

## Gráficos {#graph}
  
- Se admiten distintas formas gráficas, como líneas, círculos, arcos y curvas  
- Los gráficos pueden dibujarse en cualquier ubicación de página especificada mediante coordenadas  
- Los gráficos pueden rotarse, escalarse o rellenarse, y pueden definirse estilos de línea de trazo y polí-trazo  
- Los gráficos se dibujan según coordenadas y tienen una posición absoluta, no relativa  
- Se admiten los espacios de color CMYK y escala de grises

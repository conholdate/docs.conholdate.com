**¡Bienvenido a Aspose.Tasks para Java!**

Aspose.Tasks para Java es una biblioteca de clases que permite a los desarrolladores de aplicaciones Java integrar la funcionalidad de procesamiento de documentos MPP/MPT/XLS sin necesidad de utilizar siquiera el software de Microsoft Project. Por lo tanto, la API elimina la necesidad de automatización de Microsoft Office en dichas aplicaciones. Derivado de su producto equivalente en .NET, Aspose.Tasks para Java es un producto maduro que ofrece estabilidad y flexibilidad. El componente proporciona una API fácil de usar para manipular archivos de proyecto, ahorrando tiempo y dinero en comparación con el desarrollo de características similares desde cero.
:::

## Beneficios {#benefits}
  
El uso de Aspose.Tasks para Java en sus aplicaciones le brinda los siguientes beneficios:

### Características avanzadas {#rich-features}
  
Aspose.Tasks ofrece una amplia gama de características para crear, leer, manipular y guardar archivos de proyecto:

- Leer, modificar y escribir documentos de Microsoft Project en formatos MPP/XML.  
- Leer proyectos MPP (formato nativo de Microsoft Project y formato de Microsoft Office 365 Project Online) y formatos de proyecto XML. Se admiten todas las versiones desde Microsoft Project 2003 hasta Microsoft Project 2019 en formatos MPP.  
- Crear, actualizar y escribir proyectos en formato XML de proyecto. Se admiten las versiones desde Microsoft Project 2003 hasta Microsoft Project 2019.  
- Leer archivos de proyecto MPP, actualizar su información resumida y escribirlos en el formato MPP original.  
- Leer archivos de proyecto MPP y convertirlos al formato XML mediante Aspose.Tasks para Java (el XML puede manipularse implementando un analizador XML personalizado).  
- Modificar la configuración principal del proyecto, como el tipo de programación, fechas de inicio y finalización.  
- Modificar la configuración predeterminada del proyecto, como la tarifa estándar predeterminada, la tarifa de horas extra predeterminada, el tipo de tarea predeterminado, el método de acumulación de costos fijos predeterminado, etc.  
- Gestionar atributos extendidos.  
- Definir días laborables para el proyecto.  
- Definir días laborables para calendarios y excepciones de calendario.  
- Leer y escribir calendarios para tareas y recursos.  
- Gestionar la programación base, duraciones y tareas.  
- Manejar restricciones en tareas.  
- Crear y gestionar enlaces entre tareas.  
- Leer, modificar y crear tareas, hitos, tareas críticas estimadas o tareas impulsadas por esfuerzo.  
- Gestionar costos y variaciones de recursos.  
- Acceder a costos y presupuestos de asignaciones.  
- Implementación de prefijos de recursos para recursos anidados.

### Independencia de plataforma {#platform-independence}
  
Utilice Aspose.Tasks para Java para crear cualquier tipo de aplicación Java de 32 o 64 bits, que pueda ejecutarse en cualquier máquina con el entorno de ejecución de Java instalado. Aspose.Tasks para Java puede utilizarse en una amplia variedad de aplicaciones, incluidas aplicaciones web y de escritorio.

### Rendimiento y escalabilidad {#performance-and-scalability}
  
Portado desde su versión equivalente en .NET, Aspose.Tasks para Java es una API estable que puede implementarse tanto en el servidor como en el lado del cliente, dentro de las aplicaciones. No se requieren otros módulos ni servicios para su funcionamiento.

### Soporte para complementos {#plugin-support}
  
Aspose.Tasks para Java puede ampliarse mediante complementos para [Ruby](/java/tasks/aspose-tasks-java-for-ruby/) y [PHP](/java/tasks/aspose-tasks-java-for-php/). Asimismo, están disponibles los asistentes de proyecto para [IntelliJ IDEA](/java/tasks/aspose-tasks-java-for-intellij-idea-maven/) y [Eclipse](/java/tasks/aspose-tasks-java-for-eclipse-maven/).

## Soporte técnico {#technical-support}
  
Aspose ofrece soporte técnico gratuito ilimitado para todos sus productos. Este soporte está disponible para todos los usuarios, incluidos aquellos que ejecutan una versión de evaluación.

Si necesita ayuda, <a href="https://forum.conholdate.com/" target="_blank">**visite los foros de Conholdate**</a>. Publique su pregunta en el foro de Aspose.Tasks y será respondida en cuestión de pocas horas.

Al esperar una respuesta en los foros, tenga en cuenta las diferencias de zona horaria.

### Reportar un problema {#reporting-an-issue}
  
Si tiene un problema, siga estos sencillos pasos para asegurarse de que se resuelva de forma eficiente:

- Asegúrese de utilizar la última versión del producto antes de reportar un problema. Consulte la <a href="https://releases.aspose.com/tasks/java" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a> de Aspose.Tasks para Java para conocer la última versión disponible.  
- Revise los <a href="https://forum.conholdate.com/" target="_blank">foros</a>, esta documentación (Wiki) y la <a href="https://reference.aspose.com/tasks/java" target="_blank" rel="nofollow noopener noreferrer">referencia de la API</a> antes de reportar un problema. Es posible que su pregunta ya tenga una respuesta.  
- Al reportar un problema, incluya el documento original y, si es posible, un fragmento de su código que cause el problema. Si necesita adjuntar varios archivos, comprímalos en un único archivo ZIP. Es seguro adjuntar sus documentos en los foros, ya que solo usted y los desarrolladores de Aspose tienen acceso a los archivos adjuntos.  
- Por favor, reporte un solo problema por hilo. Si tiene otro problema, repórtelo en un hilo independiente.

Aspose no proporciona soporte técnico por teléfono. El soporte telefónico solo está disponible para consultas relacionadas con ventas y compras.

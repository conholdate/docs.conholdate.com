:::info
Aspose.Tasks para Java le permite trabajar con archivos de Microsoft Project (MPP/XML) sin necesidad de tener Microsoft Project instalado ni utilizar la automatización de Microsoft Office. Una API potente y flexible, Aspose.Tasks le ahorra tiempo y esfuerzo al proporcionarle las herramientas necesarias para escribir código eficiente que manipule archivos de proyecto.

Aspose.Tasks puede abrir archivos existentes, pero también puede crear archivos nuevos. Este artículo explica cómo crear un archivo de proyecto nuevo y vacío a partir de un flujo o utilizando la clase <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Project</a>.
:::

## Creación de un archivo de proyecto vacío  {#creating-an-empty-project-file}
  
La clase <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Project</a> es la clase principal en Aspose.Tasks, utilizada para establecer y obtener propiedades asociadas con un proyecto, así como su comportamiento. El método `save` proporcionado por esta clase permite representar el proyecto en diversos formatos de salida, como XML, MPP, PDF, HTML, etc., con una única llamada a la API. Este método acepta un flujo de archivo o un nombre de archivo, y uno de los valores proporcionados por el tipo de enumeración `SaveFileFormat`.

Actualmente, Aspose.Tasks para Java ofrece la capacidad de crear únicamente archivos de proyecto en formato XML. Las siguientes líneas de código crean un archivo de proyecto simple en formato XML.

El archivo de proyecto XML puede abrirse en Microsoft Project:

1. En el menú **Archivo**, seleccione **Abrir**.
2. Seleccione la opción de formato XML (\*.xml) entre los tipos de archivo y navegue hasta el archivo XML de salida.
3. En el menú **Proyecto**, seleccione **Información del proyecto**.

// For complete examples and data files, please go to https://github.com/aspose-tasks/Aspose.Tasks-for-Java

## Lectura de un archivo de proyecto {#reading-a-project-file}

Aspose.Tasks para Java le permite abrir archivos existentes, manipularlos y también crear nuevos archivos. Este tema muestra cómo se puede leer un archivo de Proyecto utilizando el constructor de la clase `Project`.

El <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Proyecto</a> el constructor de la clase acepta un objeto FileInputStream válido o una ruta a un documento MPP o XML y devuelve un <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Proyecto</a> objeto que se puede utilizar para manipular los datos del proyecto.

```java
// For complete examples and data files, please go to https://github.com/aspose-tasks/Aspose.Tasks-for-Java
   try
   {
       FileInputStream prjStream = new FileInputStream(dataDir + "Project1.mpp");
       Project existingProject = new Project(prjStream);
       prjStream.close();
       
       System.out.println("Calendar : " + existingProject.get(Prj.NAME));
   }
   catch(Exception ex)
   {
       System.out.println(ex.getMessage());
   }
```

### Ignorar caracteres no válidos durante la carga del proyecto {#ignoring-invalid-characters-during-loading-project}
  
Algunos archivos pueden contener caracteres no válidos en los campos personalizados. Microsoft Project no permite caracteres no válidos, por lo que estos archivos se han creado o manipulado mediante automatización u otras herramientas. Si se cargan mediante la API, pueden provocar una excepción. Para ignorar dichos caracteres no válidos, se puede utilizar el constructor sobrecargado de la clase `Project` junto con el método de devolución de llamada `ParseErrorCallBack`.

```java
public static void main(String[] args) throws IOException {
    // For complete examples and data files, please go to https://github.com/aspose-tasks/Aspose.Tasks-for-Java
    
    // The path to the documents directory.
    String dataDir = Utils.getDataDir(ReadingProjectDatafromMicrosoftProjectDatabase.class);
            
    InputStream stream = null;
    try
    {
        stream = new ByteArrayInputStream(getModifiedXml().getBytes("utf-8"));
    }
    catch (UnsupportedEncodingException e)
    {
        e.printStackTrace();
    }
 
    Project project = new Project(stream, new ParseErrorCallback()
    {
        public Object invoke(Object sender, ParseErrorArgs args)
        {
            return customDurationHandler(sender, args);
        }
    });
    project.save(dataDir + "Project1.xml", SaveFileFormat.XML);
}

private static String getModifiedXml()
{
    StringBuilder xml = new StringBuilder();
 
    BufferedReader reader;
    String line;
    try
    {
        reader = new BufferedReader(new InputStreamReader(new FileInputStream("NewProductDev.xml"), "UTF8"));
        while ((line = reader.readLine()) != null)
        {
            xml.append(line).append("\n");
        }
    }
    catch (Exception e)
    {
        e.printStackTrace();
    }
 
    return xml.toString().replaceAll("PT(\\d+)H(\\d+)M(\\d+)S", "**$1Hrs$2Mins$3Secs**");
}
 
private static Object customDurationHandler(Object sender, ParseErrorArgs args)
{
    System.err.print(String.format("Object field : %s; Invalid value : %s; ", args.getFieldName(), args.getInvalidValue()));
    String duration = args.getInvalidValue().replaceAll("[*]{2}(\\d+)Hrs(\\d+)Mins(\\d+)Secs[*]{2}", "PT$1H$2M$3S");
    double newValue = Duration.parseTimeSpan(duration)*0.001/60/60;
    System.err.println(String.format("New value : %s", duration));
    Project project = new Project();
    return project.getDuration(newValue, TimeUnitType.Hour);
}
```

## Leer proyectos protegidos con contraseña (formato 2003) {#read-password-protected-projects-2003-format}
  
Este tema muestra cómo leer proyectos protegidos con contraseña en formato 2003 utilizando Aspose.Tasks para Java.

La clase <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Project</a> expone el constructor `Project()`, el cual es capaz de leer archivos protegidos con contraseña en formato 2003. Actualmente no se admite guardar archivos protegidos con contraseña.

Para leer un archivo de proyecto protegido con contraseña:

1. Cargue un archivo de Microsoft Project.  
2. En el constructor, proporcione la contraseña como segundo argumento.

El siguiente fragmento de código muestra cómo lograr esto utilizando Java.

```java
// For complete examples and data files, please go to https://github.com/aspose-tasks/Aspose.Tasks-for-Java
   // The path to the documents directory.
   String dataDir = Utils.getDataDir(ReadPasswordProtectedFiles.class);

   Project prj = new Project(dataDir + "PassProtected2003.mpp", "pass");

   //Display result of conversion.
   System.out.println("Process completed Successfully");
```

## Lectura de Project Online {#reading-project-online}
  
La clase <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/ProjectServerManager" target="_blank" rel="nofollow noopener noreferrer">ProjectServerManager</a> proporciona los métodos para recuperar proyectos desde la cuenta especificada de Project Online. La clase ProjectServerCredentials debe utilizarse para proporcionar las credenciales necesarias para conectarse a Project Online. Anteriormente, se utilizaba el ensamblado Microsoft.SharePoint.Client.Runtime para obtener el AuthToken, pero ahora Aspose.Tasks para Java ofrece la opción de especificar SiteUrl, nombre de usuario y contraseña para crear una conexión con Project Online.

Las siguientes líneas de código muestran cómo leer un proyecto en Project Online.

```java
String sharepointDomainAddress = "https://contoso.sharepoint.com";
String userName = "admin@contoso.onmicrosoft.com";
String password = "MyPassword";

ProjectServerCredentials credentials = new ProjectServerCredentials(sharepointDomainAddress, userName, password);
ProjectServerManager reader = new ProjectServerManager(credentials);

for (ProjectInfo p : (Iterable<ProjectInfo>)reader.getProjectList())
{
    System.out.println("Project Name:" + p.getName());
    System.out.println("Project Created Date:" + p.getCreatedDate());
    System.out.println("Project Last Saved Date:" + p.getLastSavedDate());
}

for (ProjectInfo p : (Iterable<ProjectInfo>)reader.getProjectList())
{
    Project project = reader.getProject(p.getId());
    System.out.println("Project " + p.getName() + " loaded.");
    System.out.println("Resources count:" + project.getResources().size());
}
        
```

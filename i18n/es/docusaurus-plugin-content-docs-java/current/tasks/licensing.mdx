#### Limitación de DateTime {#datetime-limitation}
  
El año de la fecha se convertirá a 2000 en los proyectos que se escriban mediante Aspose.Tasks for Java, como se explica en el siguiente ejemplo de código. Este ejemplo intenta crear un proyecto con dos tareas mediante Aspose.Tasks for Java sin utilizar un archivo de licencia.

El archivo de proyecto creado a partir del código se ve como el siguiente en Microsoft Project. Observe que las fechas de inicio y finalización de la Tarea1 se han convertido del 06-abr-2010 al 06-abr-2000. ## Cambios de fecha en la versión de evaluación de Aspose.Tasks {#date-changes-in-the-evaluation-version-of-asposetasks}

![changed dates in evaluated version of Aspose.Tasks for Java](/java/tasks/images/1da84d03eb8e56ad-licensing_1.png)

```java
java.util.Calendar calendar = java.util.Calendar.getInstance(TimeZone.getTimeZone("GMT"));
calendar.set(2010, java.util.Calendar.APRIL, 6, 0, 0, 0);
Date startDate = calendar.getTime();
Project prj = new Project();
Task rootTsk = new Task();
Task tsk1 = new Task("Task1");
tsk1.setActualStart(startDate);
calendar.set(2010, java.util.Calendar.APRIL,10,0,0,0);
startDate = calendar.getTime();
Task tsk2 = new Task("Task2");
tsk2.setActualStart(startDate);
//Add tsk1 and tsk2 to the rootTsk
rootTsk.getChildren().add(tsk1);
rootTsk.getChildren().add(tsk2);
//Set rootTsk as root task of the project
prj.setRootTask(rootTsk);
//Perform recalculations
prj.calcTaskIds();
prj.calcTaskUids();
//Save the Project as XML
prj.save("ResultingProject.xml", SaveFileFormat.XML);
```

### Soporte de escritura MPP {#mpp-write-support}
  
Aspose.Tasks para Java admite la lectura de archivos MPP, la actualización de la información resumen del proyecto y, posteriormente, la escritura de los archivos de proyecto actualizados en el formato MPP original. Es decir, si el formato MPP original pertenece a la versión de Microsoft Project 2003, el archivo MPP actualizado mediante Aspose.Tasks para Java también estará en formato MPP de Microsoft Project 2003. Lo mismo es válido para los formatos MPP de Microsoft Project 2007, 2010 y 2013. Sin embargo, este soporte solo está disponible en las versiones con licencia de Aspose.Tasks para Java.

## Aplicación de la licencia {#applying-the-license}
  
Puede descargar una versión de evaluación de **Aspose.Tasks** para Java desde su página de descarga. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia del producto. Además, la versión de evaluación simplemente se convierte en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

Una vez que esté satisfecho con su evaluación de **Aspose.Tasks para Java**, puede <a href="https://purchase.conholdate.com/buy" target="_blank">adquirir una licencia</a> en el sitio web de Aspose. Familiarícese con los distintos tipos de suscripción ofrecidos. Si tiene alguna pregunta, no dude en comunicarse con el equipo de ventas de Aspose.

Cada licencia de Aspose incluye una suscripción de un año para actualizaciones gratuitas a cualquier nueva versión o corrección publicada durante ese período. El soporte técnico es gratuito y ilimitado, y se proporciona tanto a usuarios con licencia como a usuarios de evaluación.

Si desea probar **Aspose.Tasks** sin las limitaciones de la versión de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">Cómo obtener una licencia temporal</a> para obtener más información.

### Establecimiento de una licencia {#setting-a-license}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional invalidará el archivo.

Debe establecer una licencia antes de utilizar **Aspose.Tasks** si desea evitar sus limitaciones de evaluación. Solo es necesario establecer una licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o un archivo en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo Aspose.Tasks.jar.

Utilice el método <a href="https://reference.aspose.com/tasks/java/com.aspose.tasks/license" target="_blank" rel="nofollow noopener noreferrer">License</a>.setLicense para licenciar el componente. A menudo, la forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Tasks.jar y especificar únicamente el nombre del archivo, sin la ruta, como se muestra en el siguiente ejemplo:

**Ejemplo 1**

En este ejemplo, Aspose.Tasks intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

```java
com.aspose.tasks.License license = new com.aspose.tasks.License();
license.setLicense("Aspose.Tasks.Java.lic");
```

**Ejemplo 2**

Inicializa una licencia a partir de un flujo.

```java
com.aspose.tasks.License license = new com.aspose.tasks.License();
license.setLicense(new java.io.FileInputStream("Aspose.Tasks.Java.lic"));
```

## Aplicación de una licencia medible (de pago por uso) {#applying-a-metered-pay-per-use-license}
  
Una licencia medible es un mecanismo de licenciamiento que permite facturar a los clientes según el uso de las funciones de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento medible</a>. Para activar la licencia medible, se necesitan claves pública y privada.

Aplicar una licencia medible es tan sencillo como estas dos líneas de código:

```java
Metered metered = new Metered();
metered.setMeteredKey("PublicKey", "PrivateKey");
```

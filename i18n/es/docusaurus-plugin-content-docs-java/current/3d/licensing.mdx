## Evaluar Aspose.3D {#evaluate-aspose3d}
  
Puede descargar e instalar fácilmente Aspose.3D para Java desde <a href="https://releases.aspose.com/java/repo/com/aspose/aspose-3d/" target="_blank" rel="nofollow noopener noreferrer">Aspose Repository</a> para evaluarlo. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia.

La versión de evaluación proporciona todas las funciones, excepto las siguientes:

- Los usuarios solo pueden abrir / importar un máximo de 50 documentos 3D a una escena.
- Los usuarios solo pueden guardar un máximo de 50 documentos 3D a una escena.
- Los usuarios también verán una marca de agua de evaluación en las imágenes renderizadas y en todos los demás archivos de salida.
- Cada nodo puede tener como máximo 5 nodos secundarios.
- Cada nodo puede tener como máximo 2 entidades adjuntas.
- Cada geometría puede tener como máximo 2 elementos de vértice adjuntos.
- Cada nodo puede tener como máximo 1 material.

:::info
Si está utilizando Aspose.3D sin una licencia adecuada, podría activarse una **com.aspose.threed.TrialException** cuando se alcancen las restricciones de uso sin licencia; puede desactivar esta excepción mediante:

- <a href="https://purchase.conholdate.com/buy" target="_blank">Adquirir una licencia completa</a>.
- Solicitar una licencia temporal de 30 días; consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">¿Cómo obtener una licencia temporal?</a> para obtener más información.
- Llamar a `com.aspose.threed.TrialException.setSuppressTrialException(true)` antes de sus métodos `open`/`save`; la `TrialException` no se lanzará durante la llamada a `open`/`save` en Scene, pero las restricciones mencionadas anteriormente no se eliminarán.
- Utilizar manualmente un bloque `try/catch` en `Scene.open/save`; esta excepción es solo una notificación, ignorarla no afectará la carga/guardado de la escena.
  :::

## Aplicación de una licencia {#applying-a-license}
  
La licencia es un archivo XML de texto plano que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de caducidad de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarse; incluso la adición accidental de un salto de línea adicional invalidará el archivo. Debe establecer una licencia antes de realizar cualquier operación con documentos. Asegúrese de hacerlo antes de crear un objeto Scene.

Las licencias pueden aplicarse desde varias ubicaciones:

- Ruta explícita  
- La carpeta que contiene el archivo JAR de Aspose.3D  
- Un recurso incrustado dentro del JAR denominado Aspose.3D JAR  

Utilice el método `License.setLicense` para licenciar las API. A menudo, la forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el JAR de Aspose.3D y especificar únicamente el nombre del archivo, sin la ruta.

### Aplicación de licencia mediante objeto archivo o flujo {#apply-license-using-file-or-stream-object}
  
En este ejemplo, Aspose.3D intentará localizar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

```java
License license = new License();
license.setLicense("Aspose._3D.lic");
```

Inicializa una licencia a partir de un flujo.

```java
License license = new License();
try(FileInputStream myStream = new FileInputStream("Aspose._3D.lic")) {
    license.setLicense(myStream);
}
```

### Incluir el archivo de licencia como un recurso incrustado {#including-the-license-file-as-an-embedded-resource}
  
Puede simplemente copiar el archivo LIC en la carpeta `resources` de su proyecto. Al reconstruir el proyecto, se incrustará el archivo .lic en el archivo .jar de la aplicación. Tras ello, puede aplicar la licencia utilizando un código como el siguiente:

```java
License lic = new License();
lic.setLicense(Program.class.getResourceAsStream("Aspose.3D.Java.lic"));
```

### Validar la licencia {#validate-the-license}
  
Es posible validar si la licencia se ha configurado correctamente o no. La clase License tiene el campo isLicensed, que devolverá true si la licencia se ha configurado correctamente.

```java
License license = new License();
license.setLicense("Aspose.3D.Java.lic");
    	  
if (License.isLicenseSet()) {
    System.out.println("License is Set!");
}
```

## Aplicar licencia por medición  {#apply-metered-license}
  
Aspose.3D permite a los desarrolladores aplicar una clave por medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen facturarse según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.

Se ha introducido una nueva clase `Metered` para aplicar la clave por medición. A continuación se muestra un ejemplo de código que demuestra cómo configurar la clave pública y la clave privada por medición.

```java
// Initialize a Metered license class object
Metered metered = new Metered();
// Set public and private keys
metered.setMeteredKey("your-public-key", "your-private-key");
```

## Cuándo aplicar una licencia {#when-to-apply-a-license}
  
Siga estas reglas sencillas:

- La licencia solo necesita configurarse una vez por dominio de aplicación.
- Debe configurar la licencia antes de utilizar cualquier otra clase de Aspose.3D.
- Llamar a `License.SetLicense` varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador.

Si está desarrollando una biblioteca de clases, puede llamar a `License.SetLicense` desde un constructor estático de su clase que utilice Aspose.3D. El constructor estático se ejecutará antes de que se cree una instancia de su clase, garantizando así que la licencia de Aspose.3D se configure correctamente.

## Puede cambiar el nombre del archivo de licencia {#you-can-change-the-license-file-name}
  
El nombre del archivo de licencia no tiene por qué ser `'Aspose.3D.LIC'`. Puede renombrarlo como desee y utilizar ese nombre al llamar a `License.SetLicense`.

## Excepción: No se encuentra el nombre del archivo de licencia {#exception-cannot-find-license-filename}
  
Cuando adquiere y descarga una licencia, el sitio web de Aspose nombra el archivo de licencia como `Aspose.3D.LIC`. Descarga el archivo de licencia mediante su navegador. Algunos navegadores reconocen el archivo de licencia como XML y le agregan una extensión `.xml`, por lo que el nombre completo del archivo en su ordenador se convierte en `Aspose.3D.lic.XML`.

Cuando Microsoft Windows, por ejemplo, está configurado para ocultar las extensiones de los tipos de archivo conocidos (por desgracia, esta es la configuración predeterminada en la mayoría de las instalaciones de Windows), el archivo de licencia aparecerá en el Explorador de Windows como `Aspose.3D.LIC`. Es probable que considere que este es el nombre real del archivo y llame a `License.SetLicense` pasándole `Aspose.3D.LIC`, pero no existe tal archivo, por lo que se produce la excepción.

Para solucionar este problema, renombre el archivo eliminando la extensión invisible `.xml`. También le recomendamos desactivar la opción «ocultar extensiones» en Microsoft Windows.

## Uso de varias API de Aspose {#using-multiple-apis-from-aspose}
  
Si utiliza varias API de Aspose en su aplicación, por ejemplo Aspose.3D y Aspose.Cells, aquí tiene algunos consejos útiles:

- Configure la licencia para cada API de Aspose por separado. Incluso si dispone de un único archivo de licencia para todas las API, por ejemplo `Aspose.Total.lic`, aún debe llamar a `License.setLicense` por separado para cada API de Aspose que utilice en su aplicación.
- Utilice el nombre completo de la clase License. Cada API de Aspose tiene una clase `License` en su espacio de nombres. Por ejemplo, Aspose.3D tiene `com.aspose.3d.License` y Aspose.Cells tiene la clase `com.aspose.cells.License`. Utilizar el nombre completo de la clase le permite evitar cualquier confusión sobre qué licencia se aplica a qué producto.

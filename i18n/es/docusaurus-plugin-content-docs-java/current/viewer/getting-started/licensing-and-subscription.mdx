Para estudiar el sistema, es posible que desee acceso rápido a la API. Para facilitar esto, GroupDocs.Viewer ofrece distintos planes de compra, así como una prueba gratuita y una licencia temporal de 30 días para su evaluación.

## Licencia Adquirida {#purchased-license}
  
Después de la compra, aplique el archivo de licencia o inclúyalo como un recurso incrustado.  

La licencia debe configurarse:  
- Solo una vez por dominio de aplicación  
- Antes de utilizar cualquier otra clase GroupDocs.Viewer
    
### Opciones de aplicación de licencia {#license-applying-options}
  
Las licencias pueden aplicarse desde distintas ubicaciones:

*   Ruta explícita  
*   La carpeta que contiene el archivo _groupdocs-viewer.jar_  
*   La carpeta que contiene el paquete que llamó a _groupdocs-viewer.jar_  
*   La carpeta que contiene el paquete de entrada (su _.jar_)  
*   Como una licencia basada en uso (Metered License), que le permite pagar según su consumo. Para más detalles, consulte la <a href="https://purchase.groupdocs.com/faqs/licensing/metered/" target="_blank" rel="nofollow noopener noreferrer">Preguntas frecuentes sobre licencias basadas en uso</a>.

Cuando hace referencia a _groupdocs-viewer.jar_ en su aplicación, la biblioteca se copia en su directorio de salida. El método más sencillo para configurar una licencia suele ser colocar el archivo de licencia en la misma carpeta que _groupdocs-viewer.jar_ y especificar únicamente el nombre del archivo, sin la ruta.

Utilice el método <a href="https://reference.groupdocs.com/viewer/java/com.groupdocs.viewer/license/#setLicense-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">setLicense</a> para licenciar un componente.

Llamar a `setLicense` varias veces no es perjudicial, simplemente consume tiempo de procesador innecesariamente.

Llamar a <a href="https://reference.groupdocs.com/viewer/java/com.groupdocs.viewer/metered/#setMeteredKey-java.lang.String-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setMeteredKey</a> varias veces tampoco es perjudicial, pero sí consume tiempo de procesador y puede acumular el consumo de forma incorrecta.

#### Aplicar la licencia {#apply-the-license}
  
Tras obtener la licencia, debe configurarla. Esta sección explica cómo hacerlo. Al desarrollar su aplicación, invoque el método `setLicense` en su código de inicio, antes de utilizar las clases GroupDocs.Viewer.

##### Configurar una licencia desde un archivo {#set-a-license-from-a-file}
  
El siguiente fragmento de código muestra cómo configurar una licencia desde un archivo:

<Tabs groupId="example1">

<TabItem value="java" label="Java" default>

```java
String licensePath = "path to the .lic file";
License license = new License();
license.setLicense(licensePath);
```

</TabItem>

</Tabs>

##### Establecer una licencia desde un flujo  {#set-a-license-from-a-stream}
  
El siguiente fragmento de código muestra cómo establecer una licencia desde un flujo:

<Tabs groupId="example2">

<TabItem value="java" label="Java" default>

```java
String licensePath = "path to the .lic file";
try (InputStream fileStream = new FileInputStream(licensePath)) {
    License license = new License();
    license.setLicense(fileStream);
}
```

</TabItem>

</Tabs>

#### Aplicar licencia medible {#apply-metered-license}
  
Puede configurar la licencia <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Esto resulta útil para los clientes que desean facturarse según el uso de las características de la API. Para obtener más detalles, consulte <a href="https://purchase.groupdocs.com/faqs/licensing/metered" target="_blank" rel="nofollow noopener noreferrer">Metered Licensing FAQ</a>.

El siguiente fragmento de código muestra cómo utilizar la licencia medible:

<Tabs groupId="example3">

<TabItem value="java" label="Java" default>

```java
// For complete examples and data files, please go to https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-Java
String publicKey = ""; // Your public license key
String privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.setMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
double amountConsumed = Metered.getConsumptionQuantity();
System.out.println("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
double creditsConsumed = Metered.getConsumptionCredit();
System.out.println("Credits consumed: " + creditsConsumed);
```

### Cambiar el nombre del archivo de licencia {#changing-the-license-file-name}
  
No es necesario que el archivo de licencia se llame "GroupDocs.Viewer.lic". Puede renombrarlo según su preferencia y utilizar ese nombre al configurar la licencia en su aplicación.

### Excepción «No se puede encontrar el nombre del archivo de licencia» {#cannot-find-license-filename-exception}
  
Cuando adquiere y descarga una licencia desde el sitio web de GroupDocs, el archivo de licencia recibe el nombre "GroupDocs.Viewer.lic". Descárguelo utilizando su navegador. A veces, los navegadores lo reconocen como XML y agregan la extensión .xml, lo que hace que el nombre completo del archivo en su computadora sea "GroupDocs.Viewer.lic.XML".

Si Microsoft Windows está configurado para ocultar las extensiones de archivo (lo cual es el valor predeterminado en la mayoría de las instalaciones), el archivo de licencia aparecerá en el Explorador de Windows como "GroupDocs.Viewer.lic". Podría asumir que este es el nombre real del archivo e invocar el método `setLicense` con "GroupDocs.Viewer.lic", pero dicho archivo no existe, lo que provocará una excepción.

Para solucionar este problema, renombre el archivo quitando la extensión oculta .xml. Además, le sugerimos desactivar la opción «Ocultar extensiones» en Microsoft Windows.

## Cómo evaluar GroupDocs.Viewer {#how-to-evaluate-groupdocs-viewer}
  
También puede probar GroupDocs.Viewer sin adquirir una licencia.

### Versión de prueba {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida; se convierte en una versión con licencia una vez que configura la licencia. Puede configurar la licencia mediante los métodos descritos en las siguientes secciones de este artículo.

La versión de prueba tiene las siguientes limitaciones:

- El procesamiento se limita a las primeras 2 páginas.
- Se agregan marcas de agua de prueba en la parte superior de cada página procesada.

### Licencia temporal {#temporary-license}
  
Si desea probar GroupDocs.Viewer sin las limitaciones de la versión de prueba, solicite una Licencia temporal de 30 días. Para más detalles, consulte la página <a href="https://purchase.groupdocs.com/temporary-license" target="_blank" rel="nofollow noopener noreferrer">"Obtener una licencia temporal"</a>.

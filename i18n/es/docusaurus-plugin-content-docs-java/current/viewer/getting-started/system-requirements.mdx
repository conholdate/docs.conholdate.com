GroupDocs.Viewer para Java está incluido en Conholdate.Total para Java.
:::

:::info
GroupDocs.Viewer para Java no requiere la instalación de ningún software externo, como Microsoft Word, Microsoft Excel o Microsoft PowerPoint. Para instalar GroupDocs.Viewer para Java, simplemente siga uno de los métodos descritos en la sección [Installation](/java/viewer/getting-started/installation/).
:::

## Sistemas Operativos Compatibles {#supported-operating-systems}

GroupDocs.Viewer para Java se puede utilizar en cualquier sistema operativo de 32 bits o 64 bits donde Java esté instalado, incluyendo, sin limitarse a:

### Windows {#windows}

* Microsoft Windows Server 2003 y versiones posteriores  
* Microsoft Windows XP (x64, x86)  
* Microsoft Windows Vista (x64, x86)  
* Microsoft Windows 7, 8, 8.1 (x64, x86)  
* Microsoft Windows 10 (x64, x86)  
* Microsoft Windows 11 (x64)  

### Linux {#linux}

* Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac {#mac}

* Mac OS X

## Versiones de Java compatibles {#supported-java-versions}

GroupDocs.Viewer para Java admite las versiones de Java que se indican a continuación. Para obtener más información sobre el soporte de plataformas, consulte <a href="https://products.groupdocs.com/viewer" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer</a> página.

* J2SE 8.0 (1.8) o superior (*por ejemplo, Java 17*)

## Entornos de desarrollo {#development-environments}

GroupDocs.Viewer para Java se puede utilizar para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a Java, pero los siguientes entornos están explícitamente soportados:

* Eclipse IDE  
* IntelliJ IDEA  
* NetBeans  

## Fuentes requeridas {#required-fonts}

Al trabajar con documentos que contienen los jeroglíficos chinos, para obtener resultados de renderizado válidos sin excepciones ni caracteres de sustitución (normalmente representados como cuadrados vacíos) en los documentos generados, es necesario que una <a href="https://learn.microsoft.com/en-us/typography/font-list/simsun" target="_blank" rel="nofollow noopener noreferrer">SimSun</a> la fuente debe estar instalada en el sistema operativo.

Al utilizar Microsoft Windows, esto no debería ser un problema, ya que SimSun está preinstalada en todas las versiones y ediciones de Windows a partir de Windows 2000 (por ejemplo, Windows XP tiene preinstalada la versión 3.03 de SimSun, Windows 7 tiene preinstalada la versión <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_7_font_list" target="_blank" rel="nofollow noopener noreferrer">5.03</a>y Windows 10 - versión SimSun <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_10_font_list" target="_blank" rel="nofollow noopener noreferrer">5.16</a>). Pero en Linux, SimSun generalmente no está instalado, por lo que es necesario instalarlo manualmente. Esto también es válido al ejecutar GroupDocs.Viewer en un entorno Docker y utilizar una imagen de Linux.

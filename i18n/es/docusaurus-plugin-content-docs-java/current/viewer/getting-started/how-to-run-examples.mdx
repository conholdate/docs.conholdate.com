## Ejecutar ejemplos mediante Maven {#run-examples-using-maven}
  
Para comenzar, asegúrese de que <a href="https://maven.apache.org/download.cgi" target="_blank" rel="nofollow noopener noreferrer">Maven</a> esté instalado.

1. Clonar el repositorio con los ejemplos `git clone https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-Java.git`  
2. Navegar a la carpeta de ejemplos `cd ./GroupDocs.Viewer-for-Java/Examples/`  
3. Resolver dependencias y compilar los ejemplos ejecutando `mvn compile`  
4. Ejecutar los ejemplos ejecutando `mvn exec:java`  

Tras ejecutar los ejemplos, la siguiente salida debería imprimirse en la consola:

De forma predeterminada, solo se ejecuta un ejemplo de `HelloWorld` y se deben crear dos archivos HTML en la carpeta `/src/GroupDocs.Viewer-for-Java/Examples/output/HelloWorld`.

Para verificar qué ejemplos están disponibles, abra el archivo `./src/main/java/com/groupdocs/viewer/examples/RunExamples.java` con su editor de texto favorito. Descomente los ejemplos que desee ejecutar y escriba `mvn compile exec:java` para iniciarlos.

## Ejecutar ejemplos mediante Eclipse IDE {#run-examples-using-eclipse-ide}
  
Para ejecutar los ejemplos mediante Eclipse IDE, importe el proyecto para comenzar:

1. Vaya al menú `File` y haga clic en `Open Projects from File System...`  
2. Abra la carpeta `Examples`  
3. Abra el archivo `RunExamples.java` y descomente los ejemplos que desee ejecutar  
4. Vaya al menú `Run` y haga clic en `Run`

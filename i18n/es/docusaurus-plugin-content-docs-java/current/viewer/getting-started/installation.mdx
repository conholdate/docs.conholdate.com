## Instalación mediante Maven {#install-using-maven}
  
Todos los paquetes de GroupDocs están alojados en <a href="https://releases.groupdocs.com/java/repo/com/groupdocs/groupdocs-viewer/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs Artifact Repository</a>. Puede descargar los paquetes o referenciar GroupDocs.Viewer para la API de Java directamente en su proyecto Maven utilizando los siguientes pasos. 

:::tip
[Descargar](/java/viewer/sample-apps/getting-started/installation/maven-app.zip/) una aplicación de ejemplo en Maven que demuestra el uso de GroupDocs.Viewer para Java. Puede ejecutar la aplicación localmente con el comando `mvn exec:java`.
:::

### Agregar el repositorio de artefactos de GroupDocs {#add-groupdocs-artifact-repository}
  
Agregue el repositorio de artefactos de GroupDocs a su archivo `pom.xml`:

<Tabs groupId="pom-repository">

<TabItem value="pom-xml" label="pom.xml" default>

```xml
<repositories>
    <repository>
        <id>GroupDocs Artifact Repository</id>
        <name>GroupDocs Artifact Repository</name>
        <url>https://releases.groupdocs.com/java/repo/</url>
    </repository>
</repositories>
```

</TabItem>

</Tabs>

### Agregue GroupDocs.Viewer como una dependencia {#add-groupdocs-viewer-as-a-dependency}
  
Defina GroupDocs.Viewer para la dependencia de la API de Java en su `pom.xml`:

<Tabs groupId="pom-dependency">

<TabItem value="pom-xml" label="pom.xml" default>

```xml
<dependencies>
    <dependency>
        <groupId>com.groupdocs</groupId>
        <artifactId>groupdocs-viewer</artifactId>
        <version>26.5</version> 
    </dependency>
</dependencies>
```

</TabItem>

</Tabs>

## Referencia en aplicación Java {#reference-in-java-application}
  
Para comenzar, descargue la versión más reciente de GroupDocs.Viewer para Java (archivo JAR) desde el Repositorio de Artefactos de GroupDocs. Asimismo, asegúrese de tener <a href="https://www.oracle.com/java/technologies/downloads/" target="_blank" rel="nofollow noopener noreferrer">Java</a> instalado.

### Crear aplicación {#create-application}

:::tip
Puedes [descargar](/java/viewer/sample-apps/getting-started/installation/java-app.zip/) la aplicación de ejemplo y proceder a compilarla.
:::

<Tabs groupId="java-app">

<TabItem value="app-java" label="App.java" default>

```java
import com.groupdocs.viewer.Viewer;
import com.groupdocs.viewer.options.*;

public class App {
    public static void main(String[] args) throws Exception {
        Viewer viewer = new Viewer("formatting.docx");
        viewer.view(HtmlViewOptions.forEmbeddedResources());
        viewer.close();
    }
}
```

</TabItem>

<TabItem value="formatting-docx" label="formatting.docx">

`formatting.docx` es un archivo DOCX de ejemplo que utilizaremos en este ejemplo. Haga clic [aquí](/java/viewer/sample-files/getting-started/installation/formatting.docx) para descargarlo.

</TabItem>

<TabItem value="groupdocs-viewer-jar" label="groupdocs-viewer.jar">

`groupdocs-viewer.jar` es GroupDocs.Viewer para el archivo JAR de Java, por ejemplo, <a href="https://releases.groupdocs.com/java/repo/com/groupdocs/groupdocs-viewer/24.4/groupdocs-viewer-24.4.jar" target="_blank" rel="nofollow noopener noreferrer">groupdocs-viewer-24.4.jar</a>.

</TabItem>

</Tabs>

### Compilar la aplicación  {#build-application}
  
Para compilar la aplicación Java, ejecute el siguiente comando. Este comando compila la aplicación y crea el archivo `App.class` en el directorio actual.

<Tabs groupId="java-app-build">

<TabItem value="windows" label="Windows" default>

```bash
javac -d . -cp ".;./groupdocs-viewer.jar" App.java
```

</TabItem>

<TabItem value="linux" label="Linux">

```bash
javac -d . -cp ".:./groupdocs-viewer.jar" App.java
```

</TabItem>

</Tabs>

### Ejecutar la aplicación  {#run-application}
  
Para ejecutar la aplicación, escriba el siguiente comando. Como resultado, se crearán dos documentos HTML en el directorio actual, correspondientes a las dos primeras páginas del documento.

<Tabs groupId="java-app-run">

<TabItem value="windows" label="Windows" default>

```bash
java -cp ".;./groupdocs-viewer.jar" App
```

</TabItem>

<TabItem value="linux" label="Linux">

```bash
java -Djava.awt.headless=true -cp ".:./groupdocs-viewer.jar" App
```

Tenga en cuenta que `-Djava.awt.headless=true` es obligatorio cuando su instalación de Java no incluye bibliotecas de interfaz gráfica.

</TabItem>

</Tabs>

## Funciones avanzadas {#rich-features}

**Crear**:

- Crear diagramas desde cero.

**Leer**:

- Leer el formato VDW de Microsoft Visio 2003/2007/2010.
- Leer el formato de diagrama de flujo y secuencia Mermaid.

**Leer y escribir**:

- Leer o escribir el formato VSD de Microsoft Visio 2003/2007/2010.
- Leer o escribir el formato VSS de Microsoft Visio 2003/2007/2010.
- Leer o escribir el formato VST de Microsoft Visio 2003/2007/2010.
- Leer o escribir el formato VSDX de Microsoft Visio 2013.
- Leer o escribir el formato VSSX de Microsoft Visio 2013.
- Leer o escribir el formato VSTX de Microsoft Visio 2013.
- Leer o escribir el formato VSDM de Microsoft Visio 2013.
- Leer o escribir el formato VSTM de Microsoft Visio 2013.
- Leer o escribir el formato VSSM de Microsoft Visio 2013.
- Leer o escribir el formato VDX de Microsoft Visio 2003/2007/2010.
- Leer o escribir el formato VSX de Microsoft Visio 2003/2007/2010.
- Leer o escribir el formato VTX de Microsoft Visio 2003/2007/2010.
- Leer o escribir HTML.
- Leer o escribir SVG.

**Exportar**:

- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a formatos de imagen populares (BMP, JPEG, TIFF, EMF, SVG y PNG).
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a PDF.
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a la Especificación de Papel XML (XPS).
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a XAML.
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a DRAWIO.

**Imprimir**:

- Imprimir diagramas de Visio con alta fidelidad.

**Acceder**:

- Acceder y leer las propiedades, incluidas las fórmulas, de objetos de Visio como Document, Page, Master, Shape, StyleSheet y Connect.

**Protección**:

- Proteger diagramas permite bloquear fondos, maestros (plantillas), formas y estilos para que no puedan modificarse.

## Plataformas compatibles {#platform-supported}

- Aplicación web empresarial
- Linux
- Unix

## Rendimiento y escalabilidad {#performance-and-scalability}

Aspose.Diagram for Java está diseñado para ofrecer un buen rendimiento tanto en un servidor como en un cliente. Los ensamblados de Aspose.Diagram for Java pueden implementarse con cualquier aplicación Java simplemente agregándolos. No es necesario preocuparse por otros servicios o módulos.

### Configuración de una licencia {#setting-a-license}
  
La licencia es un archivo XML en texto plano que contiene detalles como el nombre del producto, el número de desarrolladores a los que está autorizada, la fecha de caducidad de la suscripción, entre otros. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional en el archivo invalidará su validez.

Debe aplicar una licencia antes de realizar cualquier operación con documentos. Asegúrese de hacerlo antes de crear un objeto Diagram. Solo es necesario configurar una licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o un archivo ubicado en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo Aspose.Diagram.jar.

Utilice el método <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/License" target="_blank" rel="nofollow noopener noreferrer">License.setLicense()</a> para licenciar el componente. A menudo, la forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Diagram.jar y especificar únicamente el nombre del archivo, sin la ruta, como se muestra en el siguiente ejemplo:

#### Ejemplo 1 {#example-1}
  
En este ejemplo, **Aspose.Diagram** intentará encontrar el archivo de licencia en la carpeta que contiene los JARs de su aplicación.

**Java**

```csharp
 com.aspose.diagram.License license = new com.aspose.diagram.License();

license.setLicense("Aspose.Diagram.Java.lic");
```

#### Ejemplo 2 {#example-2}
  
Inicializa una licencia a partir de un flujo.

**Java**

```csharp
 com.aspose.diagram.License license = new com.aspose.diagram.License();

license.setLicense(new java.io.FileInputStream("Aspose.Diagram.Java.lic"));
```

### Validar la licencia  {#validate-the-license}
  
Es posible validar si la licencia se ha configurado correctamente o no. La clase <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/License" target="_blank" rel="nofollow noopener noreferrer">License</a> posee el campo `isLicensed`, que devolverá `true` si la licencia se ha configurado correctamente.

**Java**

```csharp
 License license = new License();

license.setLicense("Aspose.Diagram.Java.lic");

if (License.isLicensed()) {

    System.out.println("License is Set!");

}
```

## Aplicar licencia por medición  {#apply-metered-license}
  
La API de Aspose.Diagram para Java permite a los desarrolladores aplicar una licencia por medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.

Se ha agregado una nueva clase <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/Metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar la clave por medición. El siguiente ejemplo de código muestra cómo configurar las claves pública y privada por medición:

```java
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-Java
// Initialize a Metered license class object
Metered metered = new Metered();
// apply public and private keys
metered.setMeteredKey("your-public-key", "your-private-key");
```

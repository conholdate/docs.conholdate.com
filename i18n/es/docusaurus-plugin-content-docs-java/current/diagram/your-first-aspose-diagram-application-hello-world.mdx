Este tutorial muestra cómo crear una aplicación muy básica («Hola Mundo») utilizando la API sencilla de Aspose.Diagram. Esta aplicación sencilla crea un archivo de Microsoft Visio con el texto «Hello World» en una página especificada.
:::

## Crear la aplicación de "Hola Mundo" {#creating-the-hello-world-application}
  
Los pasos a continuación crean la aplicación de "Hola Mundo" utilizando la API de Aspose.Diagram:

1. Crear una instancia de la clase <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/diagram" target="_blank" rel="nofollow noopener noreferrer">Diagram</a>.  
2. Si posee una licencia, <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/License" target="_blank" rel="nofollow noopener noreferrer">aplíquela</a>. Si utiliza la versión de evaluación, omita las líneas de código relacionadas con la licencia.  
3. Crear un nuevo archivo de Visio o abrir un archivo de Visio existente.  
4. Crear un nuevo cuadro de texto.  
5. Insertar las palabras **¡Hola Mundo!** en el cuadro de texto.  
6. Generar el archivo de Microsoft Visio modificado.  

La implementación de los pasos anteriores se demuestra en los ejemplos siguientes.

### Ejemplo de código: Crear un nuevo diagrama {#code-sample-creating-a-new-diagram}
  
El siguiente ejemplo crea un nuevo diagrama desde cero, escribe "¡Hola Mundo!" en la primera página y guarda el archivo de Visio.

```java
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-Java
// The path to the documents directory.
String dataDir = Utils.getDataDir(CreateNewVisio.class);
// initialize a Diagram class
Diagram diagram = new Diagram();

// save diagram in the VSDX format
diagram.save(dataDir + "CreateNewVisio_Out.vsdx", SaveFileFormat.VSDX);
```

### Ejemplo de código: Apertura de un archivo existente  {#code-sample-opening-an-existing-file}
  
El siguiente ejemplo abre un archivo de plantilla existente de Microsoft Visio denominado «Sample.vsdx», introduce el texto «Hello World!» en la primera página y guarda el diagrama.

```java
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-Java
// The path to the documents directory.
String dataDir = Utils.getDataDir(ReadVisioDiagram.class);   
// Open the stream. Read only access is enough for Aspose.Diagram to load a diagram.
InputStream stream = new FileInputStream(dataDir + "Drawing1.vsdx");

//Call the diagram constructor to load diagram from a VSDX stream
Diagram vsdDiagram = new Diagram(stream);
stream.close();

//Call the diagram constructor to load diagram from a VDX file
Diagram vdxDiagram = new Diagram(dataDir + "Drawing1.vdx");

/*
 * Call diagram constructor to load diagram from a VSS file
 * providing load file format
*/
Diagram vssDiagram = new Diagram(dataDir + "Basic.vss", LoadFileFormat.VSS);

/*
 * Call diagram constructor to load diagram from a VSX file
 * providing load options
*/
LoadOptions loadOptions = new LoadOptions(LoadFileFormat.VSX);
Diagram vsxDiagram = new Diagram(dataDir + "Drawing1.vsx", loadOptions);
```

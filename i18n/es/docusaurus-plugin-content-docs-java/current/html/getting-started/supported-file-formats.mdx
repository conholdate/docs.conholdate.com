## Soporte de formatos de entrada y salida  {#input-and-output-format-support}
  
Un formato de **entrada** puede utilizarse como fuente en un flujo de trabajo compatible con Aspose.HTML para Java. Un formato de **salida** puede guardarse o generarse mediante una operación compatible de guardado, renderizado o conversión. Una marca de verificación en ambas columnas no implica que cada formato de entrada pueda convertirse directamente en cada formato de salida.

HTML, XHTML, MHTML, SVG y Markdown aparecen en ambas columnas, ya que cada uno puede utilizarse como fuente y también puede generarse en un flujo de trabajo compatible. EPUB es compatible como entrada para conversión, mientras que PDF, XPS, DOCX y los formatos de imagen rasterizada son formatos de salida.

Para las API, opciones y ejemplos en Java específicos de cada formato, consulte [Conversión entre formatos](/java/html/converting-between-formats/), [Convertidor HTML](/java/html/html-converter/), [Convertidor SVG](/java/html/svg-converter/), [Convertidor MHTML](/java/html/mhtml-converter/), [Convertidor EPUB](/java/html/epub-converter/) y [Convertidor Markdown](/java/html/markdown-converter/).

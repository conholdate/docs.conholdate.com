## Evaluar Aspose.HTML para Java {#evaluate-asposehtml-for-java}
  
Puede instalar y utilizar Aspose.HTML para Java sin proporcionar una licencia. Esto resulta útil para pruebas iniciales de la API, pero los documentos generados están sujetos a limitaciones de evaluación.

La versión de evaluación presenta las siguientes restricciones:  

- **El contenido de los documentos guardados contiene marcas de evaluación.** Dependiendo del flujo de trabajo, los HTML guardados o las imágenes renderizadas pueden incluir texto de evaluación o marcas de agua.
- **La salida convertida está limitada.** Los documentos convertidos contienen una marca de agua de evaluación, y la conversión se limita a las primeras cuatro páginas.

Aplique una licencia válida adquirida o temporal antes de generar la salida que necesite evaluar sin estas restricciones. Para obtener información sobre las condiciones de compra y licencia, consulte <a href="https://purchase.conholdate.com/policies/" target="_blank">Purchase Policies and FAQ</a>.

## Aplicar una licencia {#apply-a-license}
  
Aplique la licencia una sola vez durante el inicio de la aplicación y antes de la primera operación de Aspose.HTML que guarde, renderice o convierta un documento. La clase <a href="https://reference.aspose.com/html/java/com.aspose.html/license/" target="_blank" rel="nofollow noopener noreferrer">License</a> acepta un nombre de archivo de licencia, una ruta de archivo o un flujo de entrada a través de sus sobrecargas `setLicense()`.

Si la aplicación utiliza múltiples productos de Aspose, utilice el nombre de clase totalmente cualificado `com.aspose.html.License`. Cada producto expone su propia clase `License`, y el nombre del paquete deja claro que la licencia se está aplicando a Aspose.HTML.

### Aplicar una licencia desde un archivo {#apply-a-license-from-a-file}
  
Para aplicar una licencia desde el disco:  

1. Coloque el archivo `.lic` en una ubicación accesible para la aplicación en tiempo de ejecución.
2. Cree un objeto `com.aspose.html.License`.
3. Pase el nombre de archivo o la ruta de acceso del archivo de licencia a `setLicense()`.
4. Aplique la licencia antes de procesar documentos.

Si el archivo de licencia se almacena en la misma carpeta de tiempo de ejecución que el JAR del componente, puede pasar únicamente su nombre de archivo. De lo contrario, proporcione una ruta que la aplicación pueda resolver. A través de esta clase se puede cargar un archivo de licencia de Aspose.HTML para Java o una licencia aplicable de Aspose.Total para Java.

```java
// Set Aspose.HTML for Java license using file path string

// instantiate License object
com.aspose.html.License license = new com.aspose.html.License();
// license file path information
license.setLicense("Aspose.HTML.lic");
```

### Aplicar una licencia desde un flujo  {#apply-a-license-from-a-stream}
  
Utilice la sobrecarga de flujo cuando la licencia se obtenga desde recursos de la aplicación, almacenamiento protegido u otra fuente basada en flujos. El siguiente ejemplo crea un `FileInputStream` y lo pasa a `setLicense()`. En el código de la aplicación, cierre el flujo una vez que el método haya finalizado.

```java
// Set Aspose.HTML for Java license from stream

// Initialize License Instance
com.aspose.html.License license = new com.aspose.html.License();
// Set license from Stream
license.setLicense(new java.io.FileInputStream("Aspose.HTML.lic"));
```

### Aplicar una licencia basada en uso (Metered) {#apply-a-metered-license}
  
Una licencia basada en uso (metered) utiliza un par de claves pública y privada en lugar de un archivo de licencia, y registra el uso de la API para la facturación basada en consumo. Para obtener información sobre los términos de licencia y la guía de activación, consulte <a href="https://purchase.conholdate.com/faqs/licensing/metered/how-to-use/" target="_blank">Uso de su licencia basada en uso</a>.

Para aplicar la licencia basada en uso:  

1. Obtenga las claves pública y privada de Aspose.
2. Cree un objeto <a href="https://reference.aspose.com/html/java/com.aspose.html/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
3. Pase las claves a `setMeteredKey()` una sola vez durante el inicio de la aplicación.
4. Mantenga la clave privada fuera del control de versiones y de la configuración visible para el cliente.

```java
// Set Aspose.HTML for Java metered license using public and private keys with Metered class

// Initialize a metered object
com.aspose.html.Metered metered = new com.aspose.html.Metered();

// Apply the metered license using the public and private keys
metered.setMeteredKey("PublicKey", "PrivateKey");
```

<a href="https://gist.github.com/aspose-com-gists/b9c9c0eb44f17af6fe4c7291c51c8930#file-example_setasposehtmlmeteredlicense-java" target="_blank" rel="nofollow noopener noreferrer">Ejemplo_SetAsposeHtmlMeteredLicense.java</a> alojado con ❤ por <a href="https://github.com/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>

Normalmente, llame a `setMeteredKey()` una sola vez al inicio de la aplicación. La licencia basada en uso registra el consumo localmente y lo informa a los servicios de Aspose en intervalos regulares, por lo que la aplicación requiere acceso periódico a los servidores de licencias a través de la red. Las reglas del firewall deben permitir esta comunicación.

:::info
El comportamiento de reintento de conectividad y los períodos de gracia están definidos por la actual <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Preguntas frecuentes sobre licencias medibles</a>. Revise dicha política al planificar la implementación en producción, en lugar de depender de un intervalo fijo documentado en la aplicación.
:::

## Problemas Comunes de Licencias {#common-licensing-issues}

<div className="docs-owner-markdown-table">

| Problema | Causa probable | Qué comprobar |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| La salida sigue conteniendo marcas de agua de evaluación | La licencia se aplicó después de que comenzara el procesamiento del documento o el archivo no se encontró. | Llame a `setLicense()` al inicio y verifique la ruta de ejecución al archivo `.lic`. |
| Aspose.HTML permanece en modo de evaluación en una aplicación multiproducto | Se utilizó una clase `License` de otro paquete de Aspose. | Instancie `com.aspose.html.License` explícitamente. |
| La licencia funciona localmente pero falla en un servidor o en un contenedor | El archivo de licencia no está presente en la implementación o la ruta de ejecución es distinta. | Implemente o monte de forma segura el archivo de licencia, o cárguelo desde un flujo. |
| La licencia basada en uso no puede informar el uso | Las reglas de red o de firewall bloquean el acceso a los servicios de licencias de Aspose. | Permita la comunicación periódica necesaria y consulte la sección de preguntas frecuentes sobre licencia basada en uso. |

Aspose.HTML para Java es una biblioteca de procesamiento de documentos sin interfaz gráfica para crear, cargar, editar, navegar, guardar y convertir documentos relacionados con HTML. Admite formatos de entrada HTML, XHTML, SVG, EPUB, MHTML y Markdown, y proporciona APIs basadas en conceptos familiares de la plataforma web, como DOM, CSS, JavaScript, SVG y Canvas.

La biblioteca procesa documentos sin abrir una ventana de navegador interactiva. Está diseñada para manipulación de documentos, extracción de datos, guardado, renderizado y conversión, y no para automatización de la interfaz de usuario del navegador.

## Creación y edición de documentos {#document-creation-and-editing}
  
Aspose.HTML para Java proporciona una API basada en DOM centrada en la clase <a href="https://reference.aspose.com/html/java/com.aspose.html/htmldocument/" target="_blank" rel="nofollow noopener noreferrer">HTMLDocument</a> para trabajar con la estructura, contenido, atributos y estilos de los documentos.  

- [Crear o cargar un documento HTML](/java/html/create-a-document/) desde un archivo, URL, flujo o cadena HTML, o bien construir un documento programáticamente.
- [Editar un documento HTML](/java/html/edit-a-document/) creando, insertando, reemplazando o eliminando nodos DOM, así como actualizando atributos, texto y estilos CSS de los elementos.
- [Guardar un documento HTML](/java/html/save-a-document/) con recursos vinculados, o guardarlo como MHTML o Markdown mediante las opciones de guardado adecuadas.
- [Configurar el entorno del documento](/java/html/environment-configuration/) para controlar el aislamiento (sandboxing), el comportamiento en tiempo de ejecución, hojas de estilos, fuentes, red y procesamiento de recursos.

## Navegación y extracción de datos {#navigation-and-data-extraction}
  
Puede inspeccionar un documento cargado y seleccionar los nodos o valores necesarios para una aplicación.  

- Utilice las interfaces de navegación y recorrido del DOM para desplazarse por el árbol del documento.
- Utilice expresiones XPath para realizar consultas estructuradas sobre los nodos del documento.
- Utilice selectores CSS para encontrar elementos por etiqueta, ID, clase, atributo o relación estructural.
- Lea o actualice el texto, marcado HTML, atributos e información de estilo calculado o especificado de los elementos.

Consulte [Navegación HTML](/java/html/html-navigation/) para ver ejemplos en Java que usan recorrido DOM, XPath y selectores CSS.

## Conversión y renderizado {#conversion-and-rendering}
  
La clase <a href="https://reference.aspose.com/html/java/com.aspose.html.converters/converter/" target="_blank" rel="nofollow noopener noreferrer">Converter</a> proporciona métodos de conversión para fuentes relacionadas con HTML. Los flujos de trabajo de salida admitidos incluyen:  

- **Formatos de documento**: PDF, XPS y DOCX.
- **Formatos de imagen**: JPEG, PNG, BMP, TIFF y GIF.
- **Formatos web**: HTML a Markdown o MHTML, y Markdown a HTML.

La compatibilidad con la conversión depende del formato de entrada y de las opciones de guardado seleccionadas. Consulte [Formatos de archivo admitidos](/java/html/getting-started/supported-file-formats/) para la matriz de entradas y salidas, y [Conversión entre formatos](/java/html/converting-between-formats/) para flujos de trabajo específicos por formato en Java.

## Plataforma y soporte para desarrollo {#platform-and-development-support}
  
Aspose.HTML para Java puede utilizarse en aplicaciones Java en entornos compatibles con Windows, Linux y macOS. Puede gestionar la dependencia mediante Maven o Gradle, o bien agregar manualmente el JAR de la biblioteca. Se requiere un JDK para compilar y crear una aplicación, mientras que el entorno de ejecución debe ser compatible con la versión seleccionada de la biblioteca.

Consulte los [Requisitos del sistema](/java/html/getting-started/system-requirements/) para obtener información sobre la compatibilidad con Java y los sistemas operativos, y [Instalación](/java/html/getting-started/installation/) para configurar las dependencias.

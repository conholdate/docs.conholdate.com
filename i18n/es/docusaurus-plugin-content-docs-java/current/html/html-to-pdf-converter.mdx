## Convertir HTML a PDF en una sola línea de código Java {#convert-html-to-pdf-in-one-line-of-java-code}
  
El siguiente ejemplo pasa una cadena HTML, URI base, `PdfSaveOptions` y ruta de salida directamente a `Converter.convertHTML()`:

```java
// Convert HTML to PDF in one line using Java

// Invoke the convertHTML() method to convert the HTML to PDF
Converter.convertHTML("<h1>Convert HTML to PDF!</h1>", ".", new PdfSaveOptions(), "convert-with-single-line.pdf");
```

## Convertir un archivo HTML a PDF {#convert-an-html-file-to-pdf}
  
Siga estos pasos para convertir un archivo HTML existente:  

1. Crear el archivo HTML de origen y cargarlo con <a href="https://reference.aspose.com/html/java/com.aspose.html/htmldocument/" target="_blank" rel="nofollow noopener noreferrer">HTMLDocument</a>.
2. Crear `PdfSaveOptions`. El constructor sin parámetros utiliza la configuración predeterminada para guardar PDF.
3. Llamar a `Converter.convertHTML(document, options, outputPath)` para guardar el PDF.

```java
// Convert HTML to PDF using Java

// Prepare HTML code and save it to a file
String code = "<span>Hello, World!!</span>";
try (java.io.FileWriter fileWriter = new java.io.FileWriter("link-to-incoming-document.html")) {
    fileWriter.write(code);
}

// Initialize an HTML document from the file
HTMLDocument document = new HTMLDocument("link-to-incoming-document.html");

// Initialize PdfSaveOptions
PdfSaveOptions options = new PdfSaveOptions();

// Convert HTML to PDF
Converter.convertHTML(document, options, "document-output.pdf");
```

## Personalizar la salida PDF con PdfSaveOptions {#customize-pdf-output-with-pdfsaveoptions}
  
Utilice <a href="https://reference.aspose.com/html/java/com.aspose.html.saving/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> para configurar el diseño de página, la resolución, el color de fondo, la calidad de las imágenes JPEG, el procesamiento de CSS y el cifrado.

<div className="docs-owner-markdown-table">

| Método | Úselo para |
| -------------------------------- | --------------------------------------------------------------------------------- |
| `setJpegQuality(value)` | Establecer la calidad de compresión JPEG cuando se utiliza la compresión JPEG. El valor predeterminado es 95. |
| `setBackgroundColor(value)` | Establecer el color que llena cada página de salida. El valor predeterminado es transparente. |
| `getPageSetup()` | Acceder a la configuración de página utilizada para configurar el tamaño y los márgenes de la página de salida. |
| `setHorizontalResolution(value)` | Establecer la resolución horizontal para las imágenes internas. El valor predeterminado es 300 dpi. |
| `setVerticalResolution(value)` | Establecer la resolución vertical para las imágenes internas. El valor predeterminado es 300 dpi. |
| `getCss()` | Acceder a las opciones de procesamiento de CSS. |
| `setEncryption(value)` | Establecer los detalles de cifrado del PDF. No se aplica cifrado cuando esta opción no está configurada. |

</div>

El siguiente ejemplo demuestra una conversión personalizada de HTML a PDF:  

1. Cargue el archivo HTML de origen en un `HTMLDocument`.
2. Cree `PdfSaveOptions` y configure una resolución de 200 dpi, un fondo azul Alice, una calidad JPEG de 100 y una página de 500 × 300 píxeles con márgenes personalizados.
3. Llame a `Converter.convertHTML(document, options, outputPath)` para convertir HTML a PDF.

En este ejemplo, la entrada es `drawing.html`, y el resultado se guarda como `drawing-options.pdf`.

```java
// Convert HTML to PDF in Java with custom page settings

// Initialize an HTML document from a file
HTMLDocument document = new HTMLDocument("drawing.html");

// Initialize PdfSaveOptions. Set up the page-size 500x300 pixels, margins,
// resolutions and change the background color to AliceBlue
PdfSaveOptions options = new PdfSaveOptions();
options.setHorizontalResolution(new Resolution(200, UnitType.AUTO));
options.setVerticalResolution(new Resolution(200, UnitType.AUTO));
options.setBackgroundColor(Color.getAliceBlue());
options.setJpegQuality(100);
options.getPageSetup().setAnyPage(new Page(new Size(500, 300), new Margin(20, 10, 10, 10)));

// Convert HTML to PDF
Converter.convertHTML(document, options, "drawing-options.pdf");
```

### ¿Puedo convertir HTML a PDF de forma gratuita? {#can-i-convert-html-to-pdf-for-free}
  
Sí. Utilice el convertidor en línea gratuito de HTML a PDF para una conversión manual rápida. Aspose.HTML para Java es una API comercial para la conversión programática y puede evaluarse antes de su licencia; consulte [Licencia](/java/html/getting-started/licensing/).  

### ¿Puedo convertir directamente una cadena HTML a PDF? {#can-i-convert-an-html-string-directly-to-pdf}
  
Sí. Llame a una sobrecarga de `Converter.convertHTML()` que acepte la cadena HTML, un URI base, `PdfSaveOptions` y una ruta de salida. El URI base es necesario para resolver cualquier URL relativa presente en el HTML proporcionado.  

### ¿Cómo se resuelven CSS, imágenes y fuentes durante la conversión de HTML a PDF? {#how-are-css-images-and-fonts-resolved-during-html-to-pdf-conversion}
  
Las URLs relativas de CSS e imágenes se resuelven en función de la URL del documento HTML o del URI base proporcionado con la cadena HTML. Utilice un URI base válido y asegúrese de que los recursos referenciados estén accesibles durante la conversión. Las fuentes deben estar disponibles en el entorno de renderizado; para utilizar fuentes personalizadas, configure una carpeta de fuentes con `FontsSettings.setFontsLookupFolder()`. Consulte [Crear un documento HTML](/java/html/create-a-document/) y [Configuración del entorno](/java/html/environment-configuration/) para obtener más detalles.

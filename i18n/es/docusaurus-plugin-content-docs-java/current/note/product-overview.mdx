## ¡Bienvenido a la documentación de Aspose.Note para Java! {#welcome-to-the-asposenote-for-java-documentation}
  
Aspose.Note para Java es una biblioteca de clases que permite que las aplicaciones Java interactúen programáticamente con Microsoft Office OneNote sin necesidad de tener el software instalado en el servidor. La API de Aspose.Note permite a los desarrolladores leer, convertir, crear, editar y manipular el contenido del formato de archivo de Microsoft OneNote.

Con Aspose.Note para Java, es posible programar con archivos de Microsoft OneNote sin utilizar la automatización de Microsoft Office. La API es fácil de usar y ahorra tiempo y dinero en comparación con el desarrollo de soluciones similares desde cero.

El uso de Aspose.Note para Java en sus aplicaciones le aporta las siguientes ventajas:

- [Ricas funcionalidades](/java/note/product-overview/).  
- [Independencia de plataforma](/java/note/product-overview/).  
- [Rendimiento y escalabilidad](/java/note/product-overview/).  
- [Versiones de Microsoft OneNote compatibles](/java/note/product-overview/)  
  :::  

### Ricas funcionalidades {#rich-features}
  
Aspose.Note ofrece una amplia gama de funcionalidades para crear, leer, manipular y guardar archivos de proyecto:

- Renderizado de texto e imágenes desde archivos de OneNote a imágenes rasterizadas (PNG, JPEG, GIF, BMP, TIFF).  
- Renderizado de texto e imágenes desde archivos de OneNote al formato de documento portátil (PDF).  
- Carga de un documento de OneNote, edición y posterior guardado en formato OneNote.  
- Inserción de una imagen en el documento de OneNote.  
- Análisis y exportación de distintos formatos de listas numeradas.  
- Navegación a través del modelo de objetos de OneNote.  
- Extracción de texto: obtención de texto desde cualquier parte de un archivo de OneNote.  
- Lectura de información sobre formato de texto y diseño (tamaños y posiciones) mediante el modelo de objetos.  
- Sustitución e inserción de texto y otros elementos, y exportación a formatos de renderizado compatibles.  
- Cumple con el estándar FIPS 186-4 y utiliza la versión compatible con FIPS de Bouncy Castle en la API.  

### Independencia de plataforma {#platform-independence}
  
Aspose.Note para Java puede utilizarse para desarrollar aplicaciones de escritorio y aplicaciones web, ya que únicamente requiere que esté instalada la JRE subyacente.  

### Rendimiento y escalabilidad {#performance-and-scalability}
  
Aspose.Note para Java está diseñado para funcionar de manera óptima tanto en el servidor como en el cliente. Se trata de una única librería Java que puede desplegarse con cualquier aplicación Java simplemente copiándola. No es necesario preocuparse por otros servicios o módulos.  

### Versiones de Microsoft OneNote compatibles {#supported-microsoft-onenote-versions}
  
- Microsoft OneNote 2010  
- Microsoft OneNote 2013  
- Formato de archivo de OneNote Online (SharePoint)

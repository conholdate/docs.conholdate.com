## Limitaciones de la versión de evaluación  {#evaluation-version-limitations}
  
Puede descargar Aspose.Note para Java de forma gratuita para su evaluación. La versión de evaluación ofrece casi todas las funcionalidades del producto, con ciertas limitaciones. La misma versión de evaluación se convierte en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

### Información sobre el creador de PDF {#pdf-creator-information}
  
Tenga en cuenta que no puede establecer valores para los campos **Application** y **Producer** al convertir documentos a PDF, ya que se mostrarán Aspose Ltd. y Aspose.Note for Java x.x en estos campos.

### Limitaciones {#limitations}
  
La versión de evaluación proporciona todas las características, excepto las siguientes:

| **Contexto de uso** | **Restricciones** |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Documento de MS OneNote abierto | Se coloca una marca de agua de evaluación en la parte superior de cada página. Los datos del historial están limitados a un máximo de tres revisiones por página accesible (revisión actual y dos archivadas). Los elementos de texto se truncan a 500 caracteres. Los elementos de tabla se truncan a un tamaño de tres por tres. Las imágenes que superen el límite de 500 KB se reemplazan por un mensaje de evaluación como texto alternativo. |
| Documento de MS OneNote creado | Se coloca una marca de agua de evaluación en la parte superior de las dos primeras páginas. El resto de las páginas se eliminan. Las imágenes que superen el límite de 500 KB se reemplazan por un mensaje de evaluación como texto alternativo. |
| Cuaderno de MS OneNote abierto/creado | El número de secciones se limita a dos. El contenido del resto de las secciones se reemplaza por una página vacía con una marca de agua de evaluación en la parte superior. |
| Exportar MS OneNote a PDF | Se coloca una marca de agua de evaluación en la parte superior de las dos primeras páginas del archivo PDF. El resto de las páginas se eliminan. |
| Exportar MS OneNote a archivo de imagen | Se coloca una marca de agua de evaluación en la parte superior de la imagen. |

</div>

## Aplicar licencia mediante archivo u objeto de flujo  {#apply-license-using-file-or-stream-object}
  
Puede descargar una versión de evaluación de **Aspose.Note** para Java desde <a href="https://downloads.aspose.com/note/java" target="_blank" rel="nofollow noopener noreferrer">su página de descarga</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia del producto. Además, la versión de evaluación se convierte simplemente en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

Una vez que esté satisfecho con su evaluación de **Aspose.Note**, puede <a href="https://purchase.conholdate.com/buy" target="_blank">adquirir una licencia</a> en el sitio web de Aspose. Familiarícese con los distintos tipos de suscripción que se ofrecen. Si tiene alguna pregunta, no dude en comunicarse con el equipo de ventas de Aspose.

Cada licencia de Aspose incluye una suscripción de un año para actualizaciones gratuitas a cualquier nueva versión o corrección que se publique durante este período. El soporte técnico es gratuito, ilimitado y se proporciona tanto a usuarios con licencia como a usuarios de evaluación.

### Configuración de una licencia  {#setting-a-license}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional en el archivo invalidará la licencia.

Debe configurar una licencia antes de utilizar Aspose.Note si desea evitar sus limitaciones de evaluación. Solo es necesario configurar la licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o archivo en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo Aspose.Note.jar.

Utilice el método **License.setLicense()** para licenciar el componente. A menudo, la forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Note.jar y especificar únicamente el nombre del archivo sin la ruta, como se muestra en el siguiente ejemplo:

#### Ejemplo 1  {#example-1}
  
En este ejemplo, **Aspose.Note** intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

**Java**

```csharp
 com.aspose.note.License license = new com.aspose.note.License();

license.setLicense("Aspose.Note.Java.lic");
```

#### Ejemplo 2 {#example-2}
  
Inicializa una licencia a partir de un flujo.

**Java**

```csharp
 com.aspose.note.License license = new com.aspose.note.License();

license.setLicense(new java.io.FileInputStream("Aspose.Note.Java.lic"));
```

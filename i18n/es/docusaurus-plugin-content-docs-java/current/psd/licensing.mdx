## Limitaciones de la versión de evaluación  {#evaluation-version-limitations}
  
Puede descargar una versión de evaluación de Aspose.PSD para Java desde la página de <a href="http://maven.aspose.com/repository/simple/ext-release-local/com/aspose/aspose-psd/" target="_blank" rel="nofollow noopener noreferrer">descarga</a>. La versión de evaluación ofrece las mismas funcionalidades que la versión completamente licenciada del componente, con algunas restricciones. Al adquirir Aspose.PSD, simplemente aplicando la licencia se eliminan todas las restricciones de la versión de evaluación instalada.

La versión de evaluación de Aspose.PSD para Java proporciona toda la funcionalidad del producto, con solo dos limitaciones:  

- **Una marca de agua en cada imagen**: Cualquier imagen que guarde, modifique o exporte incluirá una marca de agua que dice "Evaluation Only. Created with Aspose.PSD. Copyright 2018-2019 Aspose Pty Ltd.". En imágenes pequeñas, donde no cabe la marca de agua completa, se muestran dos líneas diagonales sobre la imagen en su lugar.
- **Sin soporte para la funcionalidad básica de dibujo**: En modo de evaluación, no se pueden cargar ni guardar píxeles de imagen en la imagen. Para dibujar imágenes, utilice la funcionalidad avanzada de dibujo. Esta limitación afecta a las funcionalidades que dependen de la funcionalidad básica de dibujo. Aspose.PSD para Java le permite registrar su propio formato de archivo; sin embargo, esta característica depende de la funcionalidad básica de dibujo, por lo que no tiene sentido utilizarla en modo de evaluación, ya que no puede modificar el contenido de dichos archivos.

:::info
Si desea probar Aspose.PSD para Java sin las limitaciones de la versión de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">Cómo obtener una licencia temporal</a> para obtener más información.
:::

### Configuración de una licencia {#setting-a-license}
  
La licencia es un archivo XML en texto plano que contiene detalles como el nombre del producto, el número de desarrolladores a los que está autorizada, la fecha de caducidad de la suscripción, entre otros. Dicho archivo está firmado digitalmente, por lo que no debe modificarse; incluso la adición accidental de un salto de línea adicional invalidará el archivo.

Debe configurar una licencia antes de utilizar **Aspose.PSD** si desea evitar sus limitaciones de evaluación. Solo es necesario configurar la licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o un archivo ubicado en las siguientes ubicaciones:  

1. Ruta explícita.
2. La carpeta que contiene el archivo Aspose.PSD.jar.

Utilice el método <a href="http://www.aspose.com/api/java/psd/com.aspose.psd/classes/License" target="_blank" rel="nofollow noopener noreferrer">License</a>.setLicense para licenciar el componente. Con frecuencia, la forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.PSD.jar y especificar únicamente el nombre del archivo, sin la ruta, como se muestra en el siguiente ejemplo:

#### Ejemplo 1 {#example-1}
  
En este ejemplo, **Aspose.PSD** intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

**Java**

```csharp
 com.aspose.psd.License license = new com.aspose.psd.License();

license.setLicense("Aspose.PSD.Java.lic");
```

#### Ejemplo 2 {#example-2}
  
Inicializa una licencia a partir de un flujo.

**Java**

```csharp
 com.aspose.psd.License license = new com.aspose.psd.License();

license.setLicense(new java.io.FileInputStream("Aspose.PSD.Java.lic"));
```

### Validar la licencia {#validate-the-license}
  
Es posible validar si la licencia se ha configurado correctamente o no. La clase License tiene el campo isLicensed, que devolverá true si la licencia se ha configurado correctamente.

**Java**

```csharp
 License license = new License();

license.setLicense("Aspose.PSD.Java.lic");

if (License.isLicensed()) {

    System.out.println("License is Set!");

}
```

## Dónde aplicar una licencia en su aplicación  {#where-to-apply-a-license-in-your-application}
  
Depende del tipo de aplicación que esté desarrollando dónde aplicar una licencia. Siga estas reglas sencillas:  

- La licencia solo necesita establecerse una vez por dominio de aplicación. Llamar a License.setLicense varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Aplique la licencia antes de llamar a cualquier clase de Aspose.PSD.
- **Aplicaciones Java**: llame a License.SetLicense en el código de inicio.
- **Biblioteca de clases**: llame a License.setLicense desde un constructor estático de la clase que utilice Aspose.PSD. El constructor estático se ejecuta antes de que se cree una instancia de su clase, lo que garantiza que la licencia de Aspose.PSD se configure correctamente.  

## Uso de múltiples productos de Aspose  {#using-multiple-aspose-products}
  
Si utiliza más de un producto de Aspose en su aplicación, por ejemplo Aspose.PSD y Aspose.Cells, aquí tiene algunos consejos útiles:  

- **Aplique la licencia para cada producto de Aspose por separado**. Incluso si dispone de un único archivo de licencia para todos los componentes, por ejemplo «Aspose.Total.lic», aún debe llamar a License.setLicense por separado para cada producto de Aspose en su aplicación.
- **Utilice un nombre de clase de licencia totalmente calificado**. Cada producto de Aspose tiene una clase License en su espacio de nombres. Por ejemplo, Aspose.PSD tiene com.aspose.psd.license.License y Aspose.Cells tiene com.aspose.cells.License. Utilizar un nombre de clase totalmente calificado evita cualquier confusión sobre qué licencia se aplica a qué producto.

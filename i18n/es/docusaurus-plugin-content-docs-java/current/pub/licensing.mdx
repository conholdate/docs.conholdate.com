## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Queremos que nuestros clientes prueben exhaustivamente nuestros componentes antes de comprarlos, por lo que la versión de evaluación le permite utilizarla tal como lo haría normalmente. La API inserta una marca de agua de evaluación durante la conversión de archivos .pub al formato de archivo PDF.

## Aplicar licencia mediante un objeto de archivo o flujo {#apply-license-using-file-or-stream-object}
  
La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo aspose-pub-xx.x.jar y especificar el nombre del archivo, sin una ruta de acceso, como se muestra en el siguiente ejemplo.

:::info
Si está utilizando algún otro componente de Aspose para Java junto con Aspose.PUB para Java, especifique el espacio de nombres completo para la licencia, como `com.aspose.pub.License`.
:::

### Cargar una licencia desde un archivo  {#loading-a-license-from-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.PUB.jar y especificar únicamente el nombre del archivo, sin incluir una ruta.

Cuando invoque el método setLicense, el nombre de licencia que pase debe corresponder al nombre de su archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a "Aspose.PUB.lic.xml", pase ese nombre de archivo al método <a href="https://reference.aspose.com/pub/java/com.aspose.pub/license/#setLicense-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setLicense</a>. El archivo de licencia puede ser específico para Aspose.PUB para Java, o bien puede utilizar el archivo de licencia de Aspose.Total para Java.

```java
// For complete examples and data files, please go to https://github.com/aspose-pub/Aspose.PUB-for-Java
com.aspose.pub.License license = new com.aspose.pub.License();

license.setLicense("Aspose.Pub.Java.lic");
```

### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```java
// For complete examples and data files, please go to https://github.com/aspose-pub/Aspose.PUB-for-Java
com.aspose.pub.License license = new com.aspose.pub.License();
		
license.setLicense(new java.io.FileInputStream("Aspose.Pub.Java.lic"));	
```

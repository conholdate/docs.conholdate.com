**Bienvenido a Aspose.PUB para Java**

Aspose.PUB para Java es una biblioteca de clases que le proporciona la capacidad de leer archivos de Microsoft Publisher (.pub) y convertirlos a otros formatos de archivo, como PDF. La API no requiere que se adentre en los detalles del formato de archivo subyacente de los archivos .pub. Esta facilidad para trabajar con archivos .pub le permite crear aplicaciones complejas rápidamente. La API es fácil de usar y simplifica el trabajo con archivos de publicación en las principales plataformas. No es necesario tener instalado Microsoft Publisher en el servidor para trabajar con ella.
:::

## Descripción del producto {#product-description}
  
Aspose.PUB proporciona una interfaz de programación de aplicaciones (API) sencilla y conveniente, fácil de aprender y utilizar. Está implementada en Java y puede utilizarse con cualquier aplicación basada en Java, incluidas aplicaciones web como JSP, JSF, etc., así como aplicaciones de escritorio. La API incluye ejemplos completos y funcionales que facilitan el aprendizaje rápido, ya que le ayudan a familiarizarse rápidamente con las funcionalidades que ofrece Aspose.PUB para Java.

Aspose.PUB para Java es la primera opción de nuestros clientes a la hora de trabajar con archivos PUB, debido a su precio, su excelente rendimiento y su excelente soporte.

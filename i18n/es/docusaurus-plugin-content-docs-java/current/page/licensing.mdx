## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Queremos que nuestros clientes prueben exhaustivamente nuestros componentes antes de comprarlos, por lo que la versión de evaluación le permite utilizarlos tal como lo haría normalmente. Sin embargo, el producto sin licencia:  

- Permite convertir archivos PostScript cuyo tamaño no supere los 500 KB, y en tales casos el documento PDF resultante contendrá una marca de evaluación. 
- No permitirá manipular más de 4 elementos XPS, y en tales casos el documento o la imagen resultante también contendrá una marca de evaluación, es decir, "**Solo para evaluación. Creado con Aspose.Page. Copyright 2002-2026 Aspose Pty Ltd**" en la parte superior.

La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia consiste en colocar el archivo de licencia en la misma carpeta que el archivo aspose-page-xx.x.jar y especificar el nombre del archivo, sin ruta de acceso, como se muestra en el siguiente ejemplo.

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo aspose-page-xx.x.jar y especificar únicamente el nombre del archivo, sin incluir una ruta.

Al llamar al método setLicense, el nombre de licencia que pase debe corresponder al nombre de su archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a "Aspose.Page.Java.lic.xml", pase ese nombre de archivo al método com.aspose.page.License.setLicense(…). El archivo de licencia puede especificarse para Aspose.Page para Java, o bien puede utilizar el archivo de licencia de Aspose.Total para Java.

```java
// Apply a License from File

String licenseFilePath = getLicenseFullPath();

com.aspose.page.License license = new com.aspose.page.License();
license.setLicense(licenseFilePath);
```

## Licencia basada en uso (Metered License) {#metered-license}
  
Aspose.Page permite a los desarrolladores aplicar una clave basada en uso. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen facturarse según el uso de las características de la API pueden utilizar el licenciamiento basado en uso. Para más detalles, consulte la <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">sección de preguntas frecuentes sobre el licenciamiento basado en uso</a>.

Se ha introducido una nueva clase, `Metered`, para aplicar la clave basada en uso. A continuación se muestra un ejemplo de código que demuestra cómo establecer las claves pública y privada basadas en uso.

```java
// Apply a License from Stream Object

// set metered public and private keys
com.aspose.page.Metered metered = new com.aspose.page.Metered();
// Access the setMeteredKey property and pass public and private keys as parameters
metered.setMeteredKey(
    "<type public key here>",
    "<type private key here>");
```

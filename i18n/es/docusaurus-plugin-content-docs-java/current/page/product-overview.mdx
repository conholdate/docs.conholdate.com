**Bienvenido a Aspose.Page para Java**

Aspose.Page es una API de Java diseñada para manipular lenguajes de descripción de páginas (PDL, por sus siglas en inglés). Mediante esta API, puede convertir documentos XPS y EPS/PS a PDF e imágenes. Además, puede crear, editar y guardar documentos XPS existentes y nuevos. Ofrece amplias capacidades de manipulación y puede integrarse con cualquier tipo de aplicaciones de escritorio con interfaz gráfica (GUI), aplicaciones web y aplicaciones de consola.
:::

## Descripción del producto {#product-description}
  
Aspose.Page es una API diseñada para trabajar con documentos XPS y EPS/PS. La API permite convertir documentos XPS y EPS/PS a formatos de archivo PDF e imagen. Además, la API permite abrir documentos XPS existentes, crear nuevos documentos y guardarlos ya sea en un archivo o en un flujo (stream). En cuanto se crea una instancia del documento (clase XpsDocument) (se abre un documento existente o se crea uno nuevo), puede agregar (al final de la lista de páginas) o insertar (en una posición específica de la lista de páginas) páginas nuevas o previamente creadas, eliminar páginas y seleccionar una página por número como “activa”. Solo la página seleccionada como “activa” puede editarse. Una página puede crearse sin vincularla a un documento, y puede vincularla en cualquier momento que desee. Para una nueva instancia de documento, se selecciona la primera página (si se crea un documento nuevo, su primera página también se crea automáticamente).

Aspose.Page para Java puede utilizarse en aplicaciones de escritorio con interfaz gráfica (GUI), aplicaciones web y aplicaciones de consola, entre otras. Al igual que otros productos ofrecidos por Aspose, incluye demos completas y ejemplos funcionales escritos en Java. Para ayudar a los desarrolladores y permitirles comprender rápidamente la API, todos los ejemplos se alojan en <a href="https://github.com/aspose-page/Aspose.Page-for-Java" target="_blank" rel="nofollow noopener noreferrer">GitHub</a> en un repositorio público.

Aspose.Page para Java es una API robusta y ligera que convierte archivos XPS y EPS/PS a otros formatos de archivo de forma rápida y eficiente. Es segura para entornos multiproceso, siempre que solo un subproceso (thread) trabaje en un documento a la vez. Es un escenario típico tener un subproceso trabajando en un solo documento. Diferentes subprocesos pueden trabajar de forma segura en distintos documentos simultáneamente.

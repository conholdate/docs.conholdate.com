## Dithering para imágenes raster {#dithering-for-raster-images}
  
El *dithering* es una técnica que crea la ilusión de nuevos colores y tonos variando el patrón de puntos que realmente conforman una imagen. Es el método más común para reducir el rango de colores de las imágenes hasta 256 (o menos) colores.  

Aspose.Imaging proporciona soporte para *dithering* en la clase `RasterImage` mediante la introducción del método `Dither`, el cual acepta dos parámetros. El primero es de tipo `DitheringMethod` y puede tener dos opciones posibles: `FloydSteinbergDithering` y `ThresholdDithering`. El segundo parámetro del método `Dither` es `BitCount`, de tipo entero.

:::info
BitCount define el tamaño de muestreo para el resultado del dithering. El valor predeterminado es 1, que representa blanco y negro, mientras que los valores permitidos son 1, 4 y 8, generando paletas con 2, 4 y 256 colores, respectivamente.
:::

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
JpegImage image = (JpegImage) Image.load(dataDir + "aspose-logo.jpg");

// Perform Floyd Steinberg dithering on the current image
image.dither(DitheringMethod.ThresholdDithering, 4);

// Save the resultant image
image.save(dataDir + "DitheringRasterImages_out.bmp");
```

## Ajuste de brillo, contraste y gamma {#adjusting-brightness-contrast-and-gamma}
  
El ajuste de color en imágenes digitales es una de las características fundamentales que ofrecen la mayoría de las bibliotecas de procesamiento de imágenes. Los ajustes de color pueden clasificarse de la siguiente manera:

1. **Brillo**: se refiere a la luminosidad u oscuridad del color. Aumentar el brillo de una imagen aclara todos los colores, mientras que disminuirlo oscurece todos los colores.
2. **Contraste**: se refiere a hacer más evidentes los objetos o detalles dentro de una imagen. Aumentar el contraste de una imagen incrementa la diferencia entre las áreas claras y oscuras, de modo que las áreas claras se vuelven más claras y las oscuras más oscuras. Disminuir el contraste hace que las áreas claras y oscuras permanezcan aproximadamente iguales, pero la imagen en general se vuelve más homogénea.
3. **Gamma**: optimiza el contraste y el brillo de la iluminación indirecta que ilumina un objeto en la imagen.

### Ajuste de brillo {#adjusting-brightness}
  
La API de Aspose.Imaging para Java proporciona el método `adjustBrightness` para la clase `RasterImage`, que puede utilizarse para ajustar el **brillo** pasando un valor entero como parámetro.

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
Image image = Image.load(dataDir + "aspose-logo.jpg");
// Cast object of Image to RasterImage
RasterImage rasterImage = (RasterImage) image;

// Check if RasterImage is cached
if (!rasterImage.isCached()) {
	// Cache RasterImage for better performance
	rasterImage.cacheData();
}

// Adjust the brightness
rasterImage.adjustBrightness(70);

// Create an instance of TiffOptions for the resultant image
TiffOptions tiffOptions = new TiffOptions(TiffExpectedFormat.Default);
// Set various properties for the object of TiffOptions
tiffOptions.setBitsPerSample(new int[] { 8, 8, 8 });
tiffOptions.setPhotometric(TiffPhotometrics.Rgb);

// Save the resultant image to TIFF format
rasterImage.save(dataDir + "AdjustBrightness_out.tiff", tiffOptions);
```

El valor más alto del parámetro indica una imagen más brillante.

### Ajuste de Gamma {#adjusting-gamma}
  
El método `adjustGamma` expuesto por la clase `RasterImage` tiene dos versiones. Una de las sobrecargas acepta un único valor `float` y realiza la corrección **Gamma** para los coeficientes de los canales rojo, azul y verde. En cambio, la otra sobrecarga acepta tres parámetros `float` que representan cada coeficiente de color por separado.

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
Image image = Image.load(dataDir + "aspose-logo.jpg");
		
    // Cast object of Image to RasterImage
    RasterImage rasterImage = (RasterImage)image;

    // Check if RasterImage is cached
    if (!rasterImage.isCached())
    {
        // Cache RasterImage for better performance
        rasterImage.cacheData();
    }

    // Adjust the gamma
    rasterImage.adjustGamma(2.2f, 2.2f, 2.2f);

    // Create an instance of TiffOptions for the resultant image
    TiffOptions tiffOptions = new TiffOptions(TiffExpectedFormat.Default);
    // Set various properties for the object of TiffOptions
    tiffOptions.setBitsPerSample(new int[] { 8, 8, 8 });
    tiffOptions.setPhotometric(TiffPhotometrics.Rgb);

    // Save the resultant image to TIFF format
    rasterImage.save(dataDir + "AdjustingGamma_out.tiff", tiffOptions);
```

## Desenfocar una imagen {#blur-an-image}
  
Este artículo demuestra el uso de Aspose.Imaging para Java para aplicar el efecto de desenfoque a una imagen. La API de Aspose.Imaging expone métodos eficientes y fáciles de usar para lograr este objetivo.

Aspose.Imaging para Java expone la clase **GaussianBlurFilterOptions** para crear el efecto de desenfoque sobre la marcha. La clase **GaussianBlurFilterOptions** requiere valores de radio y sigma para generar el efecto de desenfoque en una imagen.

Los pasos para realizar el desenfoque son tan sencillos como los que se indican a continuación:

1. Cargar una imagen mediante el método de fábrica **Load** expuesto por la clase **Image**.  
2. Convertir la imagen en **RasterImage**.  
3. Crear una instancia de la clase **GaussianBlurFilterOptions** utilizando el constructor predeterminado o proporcionando los valores de radio y sigma en el constructor.  
4. Llamar al método **RasterImage.Filter**, especificando como rectángulo los límites de la imagen y pasando una instancia de la clase **GaussianBlurFilterOptions**.  
5. Guardar los resultados.  

El siguiente ejemplo de código demuestra cómo aplicar el efecto de desenfoque a una imagen.

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
Image image = Image.load(dataDir + "aspose-logo.jpg");
// Convert the image into RasterImage.
RasterImage rasterImage = (RasterImage) image;

// Pass Bounds[rectangle] of image and GaussianBlurFilterOptions
// instance to Filter method.
rasterImage.filter(rasterImage.getBounds(), new GaussianBlurFilterOptions(5, 5));

// Save the results to output path.
rasterImage.save(dataDir + "BluranImage_out.gif");
```

## Verificar la transparencia de la imagen  {#verify-image-transparency}
  
Este artículo demuestra el uso de Aspose.Imaging para Java para comprobar la transparencia de una imagen. Los pasos para verificar la transparencia de la imagen son tan sencillos como los que se indican a continuación:

1. Cargar una imagen mediante el método de fábrica `Load` expuesto por la clase `Image`.
2. Comprobar la opacidad de la imagen; si la opacidad es cero, la imagen es transparente.
3. El siguiente ejemplo de código demuestra cómo verificar si una imagen es transparente o no.

```java
String filePath = "Flower.png"; // specify your path
try (PngImage image = (PngImage)Image.load(filePath))
{
    float opacity = image.getImageOpacity(); // opacity = 0,470798
    System.out.println(opacity);
    if (opacity == 0)
    {
        // The image is fully transparent.
    }
}
```

## Exportar texto como forma durante la conversión de EMF MetaFile {#exporting-text-as-shape-while-converting-emf-metafile}
  
Con Aspose.Imaging para Java, los desarrolladores pueden obtener el texto como formas al convertir de EMF a formato SVG. Este tema explica detalladamente cómo convertir texto en forma durante la conversión de EMF a formato SVG. Aspose.Imaging para Java proporciona la propiedad **TextAsShapes** para obtener el texto como forma al convertir un metaarchivo EMF. A continuación se muestra una demostración de código de dicha funcionalidad.

```java
Image image = Image.load(dataDir + "picture1.emf");
try
{
	final EmfRasterizationOptions emfRasterizationOptions = new EmfRasterizationOptions();
	emfRasterizationOptions.setBackgroundColor(Color.getWhite());
	emfRasterizationOptions.setPageWidth(image.getWidth());
	emfRasterizationOptions.setPageHeight(image.getHeight());
	image.save(dataDir + "ExportTextasShape_out.svg", new SvgOptions() {
            {
                setVectorRasterizationOptions(emfRasterizationOptions);
                setTextAsShapes(true);
            }
        });
	image.save(dataDir + "ExportTextasShape_text_out.svg", new SvgOptions() {
            {
                setVectorRasterizationOptions(emfRasterizationOptions);
                setTextAsShapes(false);
            }
        });
} finally
{
	image.close();
}
```

## Implementar el compresor GIF con pérdida  {#implementlossy-gif-compressor}

Este artículo demuestra el uso de Aspose.Imaging para Java para aplicar el compresor GIF con pérdida en una imagen. La API de Aspose.Imaging expone métodos eficientes y fáciles de usar para lograr este objetivo. Con esta funcionalidad, los desarrolladores pueden establecer la diferencia entre píxeles. La compresión GIF se basa en un «diccionario» de cadenas de píxeles vistas. El codificador normal busca en el diccionario la cadena más larga de píxeles que coincida exactamente con los píxeles de la imagen. El codificador con pérdida selecciona la cadena más larga de píxeles que sea «suficientemente similar» a los píxeles de la imagen.

El siguiente ejemplo de código demuestra cómo aplicar el compresor GIF en una imagen.

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
       
 // Sets the maximum allowed pixel difference. If greater than zero, lossy compression will be used.
 //  Recommended value for optimal lossy compression is 80. 30 is very light compression, 200 is heavy.
 com.aspose.imaging.Image image = com.aspose.imaging.Image.load(dataDir + "aspose-logo.gif");
 GifOptions gifExport = new GifOptions();
 gifExport.setMaxDiff(80);
 image.save(dataDir+"anim_lossy-80.gif", gifExport);
```

## Redimensionamiento de archivos WMF al convertirlos a PNG {#resizing-wmf-file-while-converting-to-png}
  
Mediante Aspose.Imaging para Java, los desarrolladores pueden redimensionar el archivo metafile WMF al convertirlo a un formato raster. Este tema explica el enfoque para cargar archivos metafile existentes, redimensionarlos y convertirlos a formato raster. Aspose.Imaging para Java proporciona la clase **Image** para cargar archivos WMF, la cual también se puede utilizar para redimensionar y guardar la imagen en formato PNG. El siguiente fragmento de código muestra cómo redimensionar el archivo WMF al convertirlo a PNG.

```java
// Load an existing WMF image
Image image = Image.load(dataDir + "input.wmf");
try
{
	// Call the resize method of Image class and width,height values
	image.resize(100, 100);

	// calculate new PNG image height
	double k = (image.getWidth() * 1.00) / image.getHeight();

	// Create an instance of EmfRasterizationOptions class and set
	// different properties
	
    EmfRasterizationOptions emf = new EmfRasterizationOptions();
	emf.setPageWidth(100);
	emf.setPageHeight((int) Math.round(100 / k));
	emf.setBorderX(5);
	emf.setBorderY(10);
	emf.setBackgroundColor(Color.getWhiteSmoke());

	// Create an instance of PngOptions class and provide rasterization
	// option
	ImageOptionsBase options = new PngOptions();
	options.setVectorRasterizationOptions(emf);

	// Call the save method, provide output path and PngOptions to
	// convert the WMF file to PNG and save the output
	image.save(dataDir + "CreateEMFMetaFileImage_out.png", options);
}
finally
{
	image.close();
}
```

## Soporte para leer valores de píxeles de 48 bpp {#support-for-reading-pixel-values-of-48-bpp}
  
Con Aspose.Imaging para Java, los desarrolladores pueden cargar componentes de color de 16 bits desde TIFF RGB 48Bpp. Tenga en cuenta que solo se admiten TIFF con las siguientes opciones:

- Modelo de color: RGB 48Bpp o RGBA 64Bpp
- Compresión: Lzw, Deflate, Sin compresión
- Orden de bytes: Intel (Little Endian), Motorola (Big Endian)
- Estructura: Solo por bandas (Striped)
- Configuración planar: Contigua, Separada

El perfil ICC incrustado no se aplica a los componentes de color de 16 bits. A continuación se muestra una demostración de código de dicha funcionalidad. 

```java
// For complete examples and data files, please go to https://github.com/Muhammad-Adnan-Ahmad/Aspose.Imaging-for-Java
// The path to the documents directory.
String dataDir = Utils.getSharedDataDir(ReadingPixelVaules.class) + "files/";     
//String dir = "C:\\Errors\\1006\\";
String fileName = "16bit Uncompressed, BigEndian, Rgb, Contiguous Gamma1.0.tif";
 
// ICC profile is not applied for 16-bit color components at the moment, so disable that option explicitly.
LoadOptions loadOptions = new LoadOptions();
loadOptions.setUseIccProfileConversion(false);
 
Rectangle desiredArea = new Rectangle(470, 1350, 30, 30);
 
RasterImage image = (RasterImage)Image.load(dataDir + fileName, loadOptions);
try
{
    long[] colors64Bit = image.loadArgb64Pixels(image.getBounds());
 
    int alpha, red, green, blue;
    for (int y = desiredArea.getTop(); y < desiredArea.getBottom(); ++y)
    {
        for (int x = desiredArea.getLeft(); x < desiredArea.getRight(); ++x)
        {
            int offset = y * image.getWidth() + x;
            long color64 = colors64Bit[offset];
 
            alpha = (int)((color64 >> 48) & 0xffff);
            red = (int)((color64 >> 32) & 0xffff);
            green = (int)((color64 >> 16) & 0xffff);
            blue = (int)(color64 & 0xffff);
 
            System.out.format("A=%X, R=%X, G=%X, B=%X\n", alpha, red, green, blue);
        }
    }
}
finally{
    image.dispose();
}
```

## Características del producto {#product-features}
  
Las siguientes son las características principales de Aspose.Imaging:

- Leer imágenes.
- Escribir imágenes.
- Dibujar imágenes.
- Procesar imágenes.
- Convertir entre formatos.
- Cargar/modificar/guardar metadatos (Xmp, Exif, Jfif, Dicom).
- Soportar modo de recuperación de datos.
- Exportación de vector a mapa de bits.
- Imágenes personalizadas del usuario.

### Lista de características {#feature-list}
  
#### Creación de imágenes {#image-creations}
  
- APNG (PNG animado)  
- Bmp  
- Emf / Emz  
- Gif  
- Ico  
- Jpeg (a partir de la v2.3, admite su propio códec)  
- Jpeg2000 (v2.8)  
- Png (a partir de la v2.5, admite su propio códec)  
- Svg / Svgz  
- Tga  
- Tiff / BigTiff  
- WebP  
- Wmf / Wmz  

#### Carga de imágenes {#image-loading}
  
- Bmp  
- Cmx  
- Dib  
- Dicom  
- Djvu  
- Dng  
- Emf / Emz  
- Eps  
- Gif  
- Ico  
- Jpeg  
- Jpeg2000 (v2.8)  
- ODG  
- OTG  
- Png / Apng  
- Psd  
- Svg / Svgz  
- Tga  
- Tiff / BigTiff  
- WebP  
- Wmf / Wmz  

#### Procesamiento de datos sin procesar {#raw-data-processing}
  
- Bmp (v2.4, solo carga de datos sin procesar en parte)  
- Gif  
- Jpeg  
- Jpeg2000  
- Png  
- Psd  
- Tiff  

#### Compresión Bmp {#bmp-compression}
  
- Rgb  
- Rle  
- Bitfields  
- Dxt1  

#### Compresión Psd {#psd-compressions}
  
- Rle  
- Sin comprimir  

#### Compresión Tiff {#tiff-compressions}
  
- CCITT3  
- CCITT4  
- Rle  
- Sin comprimir  
- Lzw  
- Deflate (v2.6)  
- Jpeg (solo 8 bps)  
- Espacios de color Tiff  
  - RGB  
  - CMYK  
  - CIELAB  
  - YCrCb  

#### Espacios de color Tiff {#tiff-color-spaces}
  
- RGB  
- CMYK (solo lectura) (v2.1)  
- CIELAB (solo lectura) (v2.1)  
- YCrCb  

#### Características de dibujo {#drawing-features}
  
- Sistema de caché  
- Borrar  
- Recorte a región rectangular (se ha implementado el recorte a los límites de la imagen para los algoritmos de dibujo existentes)  
- Recortar (v2.4)  
- Dithering (v2.4)  
- Dibujado y relleno de formas básicas (línea, polígono, rectángulo, curva cúbica de Bézier, curva, arco, elipse, cuña, ruta)  
- Volteo  
- Imágenes grandes  
- Transformaciones matriciales (las transformaciones matriciales están implementadas parcialmente, principalmente para necesidades internas del motor de dibujo)  
- Rotar  
- Escalar  

#### Características de procesamiento de imágenes {#image-processing-features}
  
- Cambio de tamaño de imagen  
- Recorte de imagen  
- Dithering de imagen  
- Rotación de imagen  
- Enmascaramiento de imagen  
- Filtros de imagen  
  - Escala de grises  
  - Binarización  
  - Ajuste de brillo (v2.6)  
  - Ajuste de contraste (v2.6)  
  - Ajuste de gamma (v2.6)  
  - Otros  
- Corrección de inclinación de imagen

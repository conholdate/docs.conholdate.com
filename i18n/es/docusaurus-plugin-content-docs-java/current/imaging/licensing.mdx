## Limitaciones de la versión de evaluación  {#evaluation-version-limitations}
  
Puede descargar una versión de evaluación de Aspose.Imaging para Java desde la <a href="https://repository.aspose.com/repo/com/aspose/aspose-imaging/" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a>. La versión de evaluación ofrece las mismas funcionalidades que la versión completamente con licencia del componente, con algunas restricciones. Al adquirir Aspose.Imaging, simplemente aplicando la licencia se eliminan todas las restricciones de la versión de evaluación instalada.

La versión de evaluación de Aspose.Imaging para Java proporciona toda la funcionalidad del producto, con solo dos limitaciones:

- **Una marca de agua en cada imagen**: Cualquier imagen que guarde, modifique o exporte incluye una marca de agua que dice "Evaluation Only. Created with Aspose.Imaging. Copyright 2010-2019 Aspose Pty Ltd.". En imágenes pequeñas, donde no cabe la marca de agua completa, se muestran dos líneas diagonales sobre la imagen en su lugar.
- **Sin soporte para la funcionalidad básica de dibujo**: En modo de evaluación, no se pueden cargar ni guardar píxeles de imagen en la imagen. Para dibujar imágenes, utilice la funcionalidad avanzada de dibujo. Esta limitación afecta a las funcionalidades que dependen de la funcionalidad básica de dibujo. Aspose.Imaging para Java le permite registrar sus propios formatos de archivo; sin embargo, esta característica depende de la funcionalidad básica de dibujo, por lo que no tiene sentido utilizarla en modo de evaluación, ya que no puede modificar el contenido de dichos archivos.

:::info
Si desea probar Aspose.Imaging para Java sin las limitaciones de la versión de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">Cómo obtener una licencia temporal</a> para obtener más información.
:::

## Sobre el archivo de licencia  {#about-the-license-file}
  
Una vez que haya quedado satisfecho con su evaluación de Aspose.Imaging, puede adquirir una licencia en <a href="https://purchase.conholdate.com/buy" target="_blank">el sitio web de Aspose</a>. Familiarícese con los distintos tipos de suscripción ofrecidos. Si tiene alguna pregunta, no dude en comunicarse con <a href="https://about.conholdate.com/contact" target="_blank" rel="noopener noreferrer">el equipo de ventas de Conholdate</a>. Cada licencia de Aspose incluye una suscripción de un año para actualizaciones de software. Transcurrido el primer año, renueve sus suscripciones para seguir recibiendo las últimas características y correcciones. El soporte técnico es gratuito, ilimitado y se proporciona tanto a usuarios con licencia como a usuarios en evaluación a través de nuestros <a href="https://forum.conholdate.com/" target="_blank">foros de soporte</a>. La licencia es un archivo XML que contiene detalles como el nombre del producto, la cantidad de desarrolladores con licencia, la fecha de vencimiento de la suscripción, entre otros. Dicho archivo está firmado digitalmente, por lo que no debe modificarse: incluso agregar accidentalmente un salto de línea adicional invalida el archivo. Tras adquirir Aspose.Imaging, debe aplicar la licencia antes de crear, editar o manipular de cualquier otra manera imágenes. Si olvida aplicar la licencia, todas las imágenes generadas tendrán una marca de agua de evaluación. Solo necesita configurar la licencia una vez por aplicación o proceso que desarrolle.

## Dónde aplicar una licencia en su aplicación  {#where-to-apply-a-license-in-your-application}
  
El lugar donde debe aplicar la licencia depende del tipo de aplicación que esté desarrollando. Siga estas sencillas reglas:

- Aplique la licencia únicamente una vez por aplicación. Llamar a `License.setLicense` varias veces no es perjudicial, pero desperdicia tiempo de procesamiento.
- Aplique la licencia antes de invocar cualquier clase de Aspose.Imaging para Java.
- **Aplicaciones Java JavaFX/Swing/Consola**: invoque `License.setLicense` en el código de inicio, antes de utilizar cualquier clase de Aspose.Imaging para Java.
- **Biblioteca de clases**: invoque `License.setLicense` desde un constructor estático de la clase que utilice Aspose.Imaging. El constructor estático se ejecuta antes de que se cree una instancia de su clase, lo que garantiza que la licencia de Aspose.Imaging se configure correctamente.

## Aplicación de la licencia  {#applying-the-license}
  
Puede descargar fácilmente una versión de evaluación de Aspose.Imaging desde <a href="https://repository.aspose.com/repo/com/aspose/aspose-imaging/" target="_blank" rel="nofollow noopener noreferrer">su página de descarga</a> o mediante <a href="https://repository.aspose.com/repo/" target="_blank" rel="nofollow noopener noreferrer">el repositorio Maven</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia de Aspose.Imaging. Además, la versión de evaluación simplemente se convierte en una versión con licencia cuando adquiere una licencia y agrega unas pocas líneas de código para aplicarla.

### Uso de un archivo o un flujo  {#using-a-file-or-a-stream}
  
Si desea evitar las limitaciones de la versión de evaluación, debe configurar una licencia antes de utilizar Aspose.Imaging. Solo necesita configurar la licencia una vez por aplicación (o proceso).

### Aplicación de una licencia desde un archivo  {#applying-a-license-from-a-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo `aspose-imaging-XX.X-jdk16.jar` o en el directorio de trabajo utilizado. Luego puede especificar únicamente el nombre del archivo en el código, en lugar de la ruta completa.

```java
// Instantiate an instance of license and apply the license using a full path
com.aspose.imaging.License license = new com.aspose.imaging.License();

license.setLicense("/some-folder/Aspose.Imaging.lic");
```

Cuando llame al método `setLicense`, el nombre de la licencia debe coincidir exactamente con el nombre de su archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a `"Aspose.Imaging.lic.xml"`, debe utilizar este nombre de licencia para el método `setLicense`.

### Aplicación de una licencia mediante un flujo  {#applying-a-license-using-a-stream}
  
También es posible cargar una licencia desde un flujo, como se muestra a continuación.

```java
// Instantiate an instance of license and apply the license using a stream
com.aspose.imaging.License license = new com.aspose.imaging.License();

license.setLicense(myStream);
```

Dónde aplicar una licencia en su aplicación

Dónde aplicar una licencia depende del tipo de aplicación que esté desarrollando. Siga estas reglas sencillas:

- La licencia solo necesita establecerse una vez por dominio de aplicación. Llamar a `License.setLicense` varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Aplique la licencia antes de llamar a cualquier clase de Aspose.Imaging.
- **Aplicaciones Java**: llame a `License.setLicense` en el código de inicio.
- **Biblioteca de clases**: llame a `License.setLicense` desde un constructor estático de la clase que utiliza Aspose.Imaging. El constructor estático se ejecuta antes de que se cree una instancia de su clase, lo que garantiza que la licencia de Aspose.Imaging se configure correctamente.

## Uso de múltiples productos de Aspose {#using-multiple-aspose-products}

Si utiliza más de un producto de Aspose en su aplicación, por ejemplo Aspose.Imaging y Aspose.Cells, aquí tiene algunos consejos útiles:

- **Aplique la licencia para cada producto de Aspose por separado**. Incluso si dispone de un único archivo de licencia para todos los componentes, por ejemplo `'Aspose.Total.lic'`, aún debe llamar a `License.setLicense` por separado para cada producto de Aspose en su aplicación.
- **Utilice un nombre de clase de licencia totalmente calificado**. Cada producto de Aspose tiene una clase `License` en su espacio de nombres. Por ejemplo, Aspose.Imaging tiene `com.aspose.imaging.license.License` y Aspose.Cells tiene `com.aspose.cells.License`. Utilizar un nombre de clase totalmente calificado evita cualquier confusión sobre qué licencia se aplica a qué producto.

## Información general {#overview}
  
Crear interfaces sería mucho más sencillo si solo existiera un formato de fuente universal. Sin embargo, debido a la gran variedad de dispositivos, entornos, sistemas operativos y aplicaciones en las que se utilizan las fuentes, contamos con una amplia gama de formatos de fuentes adaptados a necesidades específicas. Cada formato de fuente presenta ventajas y desventajas, siendo algunos optimizados para páginas web y aplicaciones, mientras que otros son más adecuados para la edición y publicación. Para garantizar una representación óptima en distintas plataformas, puede ser necesario convertir fuentes de un formato a otro.

:::info
Para algunas tareas, una aplicación web será suficiente. Por ejemplo, si solo necesita convertir un documento de texto en otro documento con un tipo de fuente diferente. Y Aspose sí tiene dicha aplicación en su ecosistema. Pruebe <a href="https://products.conholdate.app/conversion" target="_blank">*Font Conversion application*</a> para ver si se ajusta a sus necesidades.
:::

Si sus necesidades van más allá de lo que puede ofrecer una aplicación web y requiere una solución más robusta para integrar en su producto, considere utilizar esta herramienta diseñada para agilizarle el proceso de conversión de fuentes. La biblioteca Aspose.Font para Java es una solución potente que facilita la conversión de fuentes entre diversos formatos populares:

Es una biblioteca flexible y fácil de usar, diseñada para trabajar con distintos tipos de archivos de fuentes, como `TrueType CFF`, `OpenType` y `Type1`. Además de las capacidades de conversión de fuentes, también ofrece diversas otras manipulaciones de fuentes, como recuperar detalles de la fuente, acceder a datos de glifos y métricas, identificar caracteres latinos, cargar fuentes, entre otras.

## Formatos de fuente admitidos {#supported-font-formats}
  
Los siguientes formatos son compatibles con Aspose.Font para Java:

<div className="docs-owner-markdown-table">

| **Formato** | **Descripción** |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TrueType` (`TTF`) | Es uno de los formatos más populares entre los sistemas operativos Mac OS y Microsoft Windows. Los fuentes `True type` tienen la extensión `.ttf`. Las fuentes de la familia `TrueType` son fáciles de escalar a cualquier tamaño en computadoras y otros dispositivos, como impresoras, teléfonos inteligentes, etc. Los representantes más famosos de las fuentes `TTF` son las familias Times Roman, Helvetica y Courier. |
| `Web Open Font Format` (`WOFF`) | Este formato de fuente se desarrolló para su renderizado en páginas web. Básicamente, se trata de una fuente `TrueType` o `OpenType` modificada mediante la adición de metadatos HTML y la aplicación de compresión. Este formato es compatible con todos los navegadores principales. |
| `Web Open Font Format version 2.0` (`WOFF2`) | Es la siguiente generación de `WOFF`. Ofrece una compresión promedio del 30 % en comparación con `WOFF`. Aun así, su adopción no es muy generalizada. |
| `Embedded OpenType format` (`EOT`) | Estas fuentes fueron desarrolladas por Microsoft y son compatibles con Internet Explorer, y se utilizan en la web. Debido a la compresión, los archivos de fuente son más pequeños. `EOT` también ofrece cierta protección de derechos de autor gracias al subconjunto (subsetting). |
| `Type 1` | (también conocido como `PostScript`, `PS1`, `T1`, `Adobe Type 1`, `Multiple Master` o `MM`). Este formato fue desarrollado por Adobe Systems para la composición tipográfica digital profesional. Este sistema utiliza el formato de archivo `PostScript` para codificar la información de la fuente. Dado que este formato de fuente está obsoleto y no es compatible con muchos entornos modernos, como dispositivos móviles y navegadores web, Adobe ya no lo admitirá a partir de 2023. La empresa recomienda utilizar el formato `Open type` en su lugar. |
| `Compact Font Format` (`CFF`) | También se conoce como formato de fuente `Type 2` o formato de fuente `CFF/Type 2`. Con este formato, puede almacenar distintas fuentes juntas en una única unidad llamada Fontset (conjunto de fuentes). Al permitir compartir datos entre fuentes y utilizar valores predeterminados para los datos que aparecen con frecuencia, ofrece un ahorro notable de espacio. |
| `Scalable Vector Graphics` (`SVG`) | SVG es un formato de archivo utilizado para mostrar gráficos e imágenes basados en vectores en la web. Las fuentes SVG, también conocidas como fuentes SVG-in-OpenType o SVGOT, son un tipo específico de formato de fuente dentro de SVG. Cada carácter en una fuente SVG se define como una ruta o forma SVG independiente, por lo que las fuentes SVG pueden escalarse sin perder calidad. |
| `OpenType Font` (`OTF`) | Los archivos `OTF` funcionan de forma nativa en Windows, macOS, Linux y entornos web sin necesidad de conversión de formato. `OTF` utiliza datos de contorno PostScript, lo que permite curvas vectoriales más suaves y un menor tamaño de almacenamiento en comparación con formatos anteriores. |

</div>

## ¿Cómo convertir la fuente al formato deseado? {#how-to-convert-the-font-into-the-desired-format}  

1. Cargue la fuente desde cualquiera de los formatos soportados y obtenga una referencia al objeto base `com.aspose.font.Font` que representa dicha fuente.
2. Guarde la fuente recién cargada en otro formato mediante el método <a href="https://reference.aspose.com/font/java/com.aspose.font/font/#saveToFormat-java.io.OutputStream-com.aspose.font.FontSavingFormats-" target="_blank" rel="nofollow noopener noreferrer">*saveToFormat()*</a> de la instancia de la clase abstracta base <a href="https://reference.aspose.com/font/java/com.aspose.font/Font#save-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">*Font*</a>. El método <a href="https://reference.aspose.com/font/java/com.aspose.font/font/#saveToFormat-java.io.OutputStream-com.aspose.font.FontSavingFormats-" target="_blank" rel="nofollow noopener noreferrer">*saveToFormat()*</a> acepta dos argumentos: un flujo de salida y la enumeración <a href="https://reference.aspose.com/font/java/com.aspose.font/FontSavingFormats" target="_blank" rel="nofollow noopener noreferrer">*FontSavingFormats*</a> para elegir el formato de salida de la fuente. El método <a href="https://reference.aspose.com/font/java/com.aspose.font/font/#saveToFormat-java.io.OutputStream-com.aspose.font.FontSavingFormats-" target="_blank" rel="nofollow noopener noreferrer">*saveToFormat()*</a> permite guardar fuentes en cualquiera de los formatos de salida soportados.

Debe utilizar las siguientes instrucciones:

```java
import java.io.FileOutputStream;
import java.io.IOException;
import java.nio.file.Paths;
import com.aspose.font.FileSystemStreamSource;
import com.aspose.font.Font;
import com.aspose.font.FontDefinition;
import com.aspose.font.FontFileDefinition;
import com.aspose.font.FontType;
import com.aspose.font.FontSavingFormats;
```

El siguiente ejemplo convierte `montserrat-bold.ttf` (Montserrat Bold) de `TTF` a `WOFF`. Reemplaza la entrada original Montserrat Regular. Proporcione `getDataDir()` y `getOutputDir()` para su aplicación y adapte la ruta de entrada hermana `TTF`; el directorio de salida debe existir y ser escribible. Coloque el código en un método que maneje o declare `IOException`. La secuencia de salida se cierra mediante try-with-resources.

Se realizaron los siguientes pasos:

1. Se abrió la fuente `TTF`.
2. Se agregaron las opciones de salida.
3. Se realizó la conversión de `TTF` a `WOFF` y se guardó el resultado.

```java
String fontPath = Paths.get(getDataDir(), "..", "TTF", "montserrat-bold.ttf").normalize().toString();
FontDefinition fontDefinition = new FontDefinition(FontType.TTF,
        new FontFileDefinition("ttf", new FileSystemStreamSource(fontPath)));
Font font = Font.open(fontDefinition);

String outPath = Paths.get(getOutputDir(), "TtfToWoff_out1.woff").toString();
try (FileOutputStream outStream = new FileOutputStream(outPath)) {
    font.saveToFormat(outStream, FontSavingFormats.WOFF);
}
```

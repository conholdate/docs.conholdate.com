## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Queremos que nuestros clientes prueben exhaustivamente nuestros componentes antes de comprarlos, por lo que la versión de evaluación le permite utilizarla tal como lo haría normalmente. La versión de evaluación de Aspose.Font (sin una licencia especificada) proporciona toda la funcionalidad del producto, excepto algunas limitaciones propias de la evaluación. La versión de evaluación admite únicamente el trabajo con las siguientes fuentes:  

- CFF
- Fuentes Type1 y Montserrat
- Noto Sans JP
- Merriweather
- Lora
- Source Code Pro
- Fuentes TTF  

## Aplicar licencia mediante un objeto de archivo o flujo {#apply-license-using-file-or-stream-object}
  
La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia consiste en colocar el archivo de licencia en la misma carpeta que el archivo aspose-font-xx.x.jar y especificar el nombre del archivo (sin ruta), como se muestra en el ejemplo siguiente.

:::info
Si está utilizando cualquier otro componente de Aspose para Java junto con Aspose.Font para Java, especifique el espacio de nombres completo para la licencia, como `com.aspose.font.License`.
:::

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.Font.jar y especificar únicamente el nombre del archivo, sin incluir una ruta.

Cuando invoques el método setLicense, el nombre de licencia que pases debe corresponder al nombre de tu archivo de licencia. Por ejemplo, si cambias el nombre del archivo de licencia a "Aspose.Font.lic", debes pasar ese nombre de archivo al método com.aspose.font.License.setLicense(…). El archivo de licencia puede ser específico para Aspose.Font para Java, o bien puedes utilizar el archivo de licencia de Aspose.Total para Java.

```java
// Apply a license from a file.
// licenseFilePath is the full path to your Aspose.Font for Java license.
com.aspose.font.License license = new com.aspose.font.License();
license.setLicense(licenseFilePath);
```

### Cargar una licencia desde un objeto de flujo {#loading-a-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```java
// Apply a license from a stream and close the stream after use.
// licenseFilePath is the full path to your Aspose.Font for Java license.
com.aspose.font.License license = new com.aspose.font.License();
try (InputStream licenseStream = new FileInputStream(licenseFilePath)) {
    license.setLicense(licenseStream);
}
```

## Cómo aplicar una licencia en el componente Aspose.Cells {#how-to-apply-a-license-in-asposecells-component}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de caducidad de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional en el archivo invalidará la licencia.

Debe establecer una licencia antes de utilizar Aspose.Cells si desea evitar sus limitaciones de evaluación. Solo es necesario establecer una licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o un archivo en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo Aspose.Cells.jar.

Utilice el método <a href="https://reference.aspose.com/cells/java/com.aspose.cells/license#setLicense-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">License.setLicense</a> para licenciar el componente. A menudo, la forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Cells.jar y especificar únicamente el nombre del archivo, sin la ruta, como se muestra en el siguiente ejemplo:

### Cómo aplicar una licencia desde el disco {#how-to-apply-a-license-from-disk}
  
En este ejemplo, **Aspose.Cells** intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

```csharp
com.aspose.cells.License license = new com.aspose.cells.License();

license.setLicense("Aspose.Cells.Java.lic");
```

### Cómo aplicar una licencia desde un flujo {#how-to-apply-a-license-from-stream}
  
Inicializa una licencia a partir de un flujo.

```csharp
com.aspose.cells.License license = new com.aspose.cells.License();

license.setLicense(new java.io.FileInputStream("Aspose.Cells.Java.lic"));
```

### Cómo aplicar una licencia en Aspose.Cells.GridWeb {#how-to-apply-a-license-in-asposecellsgridweb}
  
Se recomienda colocar el código de licencia en un lugar de su aplicación web donde deba procesarse primero.

```csharp
//Instantiate a license object and set the license file through its path

com.aspose.gridweb.License lic = new com.aspose.gridweb.License();

lic.setLicense("Aspose.Cells.lic");
```

## Cómo aplicar una licencia por medición {#how-to-apply-metered-license}
  
Aspose.Cells permite a los desarrolladores aplicar una clave de medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre el licenciamiento por medición</a>.

Se ha introducido una nueva clase <a href="https://reference.aspose.com/cells/java/com.aspose.cells/Metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar una clave de medición. A continuación se muestra un ejemplo de código que demuestra cómo configurar las claves públicas y privadas de medición.

```java
//Set metered public and private keys

Metered metered = new Metered();

//Call the setMeteredKey method and pass public and private keys as parameters

metered.setMeteredKey("************", "************");

//Instantiate a new Workbook

Workbook workbook = new Workbook();

//Check if the license is set

System.out.println(workbook.isLicensed());

//Get the consumption quantity

double amountBefore = Metered.getConsumptionQuantity();

System.out.println(amountBefore);

Workbook workbook2 = new Workbook("Book1.xlsx");

workbook2.save("out1.xlsx");

//Get the consumption quantity again which should be greater by a bit

double amountAfter = Metered.getConsumptionQuantity();

System.out.println(amountAfter);
```

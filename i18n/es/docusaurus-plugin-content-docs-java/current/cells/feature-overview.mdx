## Formatos de archivo y conversiones {#file-formats-and-conversions}
  
Muchos clientes de todo el mundo confían en las robustas funciones de importación y exportación de documentos proporcionadas por Aspose.Cells para Java.

<div className="docs-owner-markdown-table">

| **Característica** | **Descripción** | **Aspose.Cells para Java** |
| ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- | ------------------------- |
| Conversiones de alta calidad | Convierta rápidamente y de forma fiable entre varios formatos de documento populares. | Sí |
| Libro de Microsoft Excel (XLS) | La implementación más rápida y completa del formato XLS que puede encontrar. | Sí |
| SpreadsheetML (XLSX, XML) | Aspose.Cells admite OOXML, Flat OPC y también Excel 2003 XML. Además, |  |
| el componente admite todos los formatos de archivo principales de Excel 2007 y versiones posteriores, por ejemplo, XLSX, XLTX, XLSM, XLTM, XLSB, etc. | Sí |  |
| Valor separado por comas (CSV) | Soporte integral del formato CSV para interactuar con diversas aplicaciones. | Sí |
| HTML | Está disponible la opción de guardar como HTML. | Sí |
| OpenDocument (ODS) | Aspose.Cells puede cargar y guardar documentos en el formato de hoja de cálculo OpenDocument (.ods). | Sí |
| Adobe Portable Document Format (PDF) | Convierta cualquier hoja de cálculo a PDF con alta fidelidad. | Sí |
| Delimitado por tabulaciones | Cargue y guarde documentos en el formato de archivo delimitado por tabulaciones. | Sí |
| Texto sin formato (TXT) | Extraiga fácilmente texto guardando en formato de texto sin formato. | Sí |

</div>

<div className="docs-owner-markdown-table">

| **Característica** | **Aspose.Cells for Java** |
| --------------------------------------------------------------------------------------------------------- | ------------------------- |
| Diseñar el documento en páginas con alta fidelidad a Microsoft Excel® (exactamente como lo haría Microsoft Excel®). | Sí |
| Renderizar páginas de hojas de cálculo como imágenes rasterizadas (PNG, JPEG, BMP, etc.). | Sí |
| Renderizar páginas de hojas de cálculo como imágenes vectoriales (EMF). | Sí |
| Especificar resolución de imagen, calidad, compresión y otras opciones. | Sí |
| Imprimir hojas de cálculo utilizando la infraestructura de impresión de Java. El componente tiene un método de impresión integrado para imprimir |  |
| hojas de cálculo tal como se muestran en la vista previa de impresión de Microsoft Excel. | Sí |
| Actualizar números de página y otros campos antes de renderizar o imprimir. | Sí |

</div>

Este documento está diseñado para proporcionar a los desarrolladores una comprensión detallada de cómo convertir una hoja de cálculo en un archivo de imagen, y también cómo convertir una hoja de cálculo con varias páginas en un archivo de imagen por página.

A veces, es posible que necesite presentar hojas de cálculo como imágenes, por ejemplo, para utilizarlas en aplicaciones o páginas web. Podría necesitar insertar las imágenes en un documento de Word, un archivo PDF, una presentación de PowerPoint, o utilizarlas en algún otro escenario. En resumen, desea representar la hoja de cálculo como una imagen. Las API de Aspose.Cells admiten la conversión de hojas de cálculo en archivos de Microsoft Excel a imágenes. Además, Aspose.Cells admite la conversión de un libro de trabajo en múltiples archivos de imagen, uno por página.
:::

## **Uso de Aspose.Cells para convertir una hoja de cálculo en un archivo de imagen** {#using-asposecells-to-convert-worksheet-to-image-file}
  
Este artículo muestra cómo utilizar la API de Aspose.Cells para Java para convertir una hoja de cálculo en una imagen. La API proporciona varias clases útiles, como <a href="https://reference.aspose.com/cells/java/com.aspose.cells/SheetRender" target="_blank" rel="nofollow noopener noreferrer">**SheetRender**</a>, <a href="https://reference.aspose.com/cells/java/com.aspose.cells/ImageOrPrintOptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions**</a>, <a href="https://reference.aspose.com/cells/java/com.aspose.cells/WorkbookRender" target="_blank" rel="nofollow noopener noreferrer">**WorkbookRender**</a>, entre otras. La clase <a href="https://reference.aspose.com/cells/java/com.aspose.cells/SheetRender" target="_blank" rel="nofollow noopener noreferrer">**SheetRender**</a> representa una hoja de cálculo para la generación de imágenes y dispone de un método sobrecargado <a href="https://reference.aspose.com/cells/java/com.aspose.cells/sheetrender#toImage-int-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">**toImage**</a> que permite convertir directamente una hoja de cálculo en archivos de imagen, con cualquier atributo u opción configurado.

```java
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-Java
// The path to the documents directory.
String dataDir = "./";
// Create a new Workbook object
// Open a template excel file
Workbook book = new Workbook(dataDir + "book1.xlsx");
// Get the first worksheet
Worksheet sheet = book.getWorksheets().get(0);

// Define ImageOrPrintOptions
ImageOrPrintOptions imgOptions = new ImageOrPrintOptions();
// Specify the image format
imgOptions.setImageType(ImageType.JPEG);

// Render the sheet with respect to specified image/print options
SheetRender render = new SheetRender(sheet, imgOptions);
// Render the image for the sheet
render.toImage(0, dataDir + "CWToImageFile.jpg");
```

### **Resultado** {#result}
  
Después de ejecutar el código anterior, la hoja de cálculo denominada *Sheet1* se convierte en un archivo de imagen llamado *SheetImage.jpg*.

## **Uso de Aspose.Cells para convertir una hoja de cálculo en un archivo de imagen por página** {#using-asposecells-to-convert-worksheet-to-image-file-by-page}
  
Este ejemplo muestra cómo utilizar Aspose.Cells para convertir una hoja de cálculo de un libro de plantilla que contiene varias páginas en un archivo de imagen por página.

```java
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-Java
// The path to the documents directory.
String dataDir = "./";
// Create a new Workbook object
// Open a template excel file
Workbook book = new Workbook(dataDir + "ConvertWorksheetToImageByPage.xlsx");
// Get the first worksheet
Worksheet sheet = book.getWorksheets().get(0);
// Define ImageOrPrintOptions
ImageOrPrintOptions options = new ImageOrPrintOptions();
// Set Resolution
options.setHorizontalResolution(200);
options.setVerticalResolution(200);
options.setImageType(ImageType.TIFF);

// Sheet2Image by page conversion
SheetRender render = new SheetRender(sheet, options);
for (int j = 0; j < render.getPageCount(); j++) {
	render.toImage(j, dataDir + sheet.getName() + " Page" + (j + 1) + ".tif");
}
```

### **Resultado** {#result-1}
  
Después de ejecutar el código anterior, la hoja de cálculo denominada Sheet1 se convierte en dos archivos de imagen (uno por página): Sheet 1 Page 1.Tiff y Sheet 1 Page 2.Tiff.

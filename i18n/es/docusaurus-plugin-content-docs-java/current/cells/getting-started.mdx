## Requisitos del sistema {#system-requirements}
  
Aspose.Cells para Java admite las siguientes versiones de Java:

- J2SE 6.0 (1.6)  
- J2SE 7.0 (1.7)  
- o superior  

[Más detalles](/java/cells/system-requirements/)  

## Instalación {#installation}
  
### Instalar Aspose Cells para Java desde el repositorio de Maven {#install-aspose-cells-for-java-from-maven-repository}
  
Maven es la forma más sencilla de descargar e instalar Aspose.Cells para Java.

1. Especifique la configuración/ubicación del repositorio de Maven de Aspose en su archivo `pom.xml` de Maven.  
2. Defina la dependencia de la API de Aspose.Cells para Java en su `pom.xml`.  

[Más pasos para más detalles](/java/cells/installation/)  

### Instalar Aspose Cells para Java manualmente {#install-aspose-cells-for-java-manually}
  
1. <a href="https://releases.aspose.com/java/repo/com/aspose/aspose-cells/" target="_blank" rel="nofollow noopener noreferrer">Descargue los archivos JAR de Aspose.Cells</a> en una carpeta.  
2. Ingrese a la carpeta e instale manualmente los paquetes JAR con Eclipse o IntelliJ.

## Creación de la aplicación «Hola Mundo» {#creating-the-hello-world-application}
  
Los pasos a continuación crean la aplicación «Hola Mundo» utilizando la API de Aspose.Cells:

```java
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-Java
// Create workbook
Workbook workbook = new Workbook();

// Add worksheet
workbook.getWorksheets().add("HelloWorldPage");
		
// Set cell value
workbook.getWorksheets().get("HelloWorldPage").getCells().get(0, 0).setValue("HelloWorldCell");

// Save workbook
workbook.save("HelloWorld.xlsx");
```

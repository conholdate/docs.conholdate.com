> Cree presentaciones en Java con Aspose.Slides: genere archivos PPT, PPTX y ODP, aproveche el soporte para OpenDocument y guárdelos programáticamente para obtener resultados confiables.

## Descripción general {#overview}
  
Este artículo muestra cómo crear una presentación en Aspose.Slides, agregar una forma con texto a su primera diapositiva y guardar el resultado como un archivo PPTX. Para abrir una presentación existente y guardarla en otro formato, consulte [Abrir presentaciones](/java/slides/open-presentation/) y [Guardar presentaciones](/java/slides/save-presentation/). Al final se incluye una breve sección de preguntas frecuentes que aborda dudas comunes sobre formatos, plantillas, dimensiones de diapositivas, unidades, uso de memoria, subprocesamiento, licencias, firmas digitales y compatibilidad con VBA.

Antes de comenzar, agregue Aspose.Slides para Java a su proyecto desde el repositorio Maven de Aspose. Consulte [Instalación](/java/slides/installation/) para obtener instrucciones sobre la configuración de Maven y lo que se requiere adicionalmente en Linux.

## Crear una presentación {#create-a-presentation}
  
Crear un archivo de PowerPoint desde cero en Aspose.Slides para Java comienza con una instancia de la clase <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>. El constructor proporciona una presentación en blanco con una única diapositiva, lista para contener formas, texto, gráficos o cualquier otro contenido que necesite su aplicación. Una vez que modifique esa diapositiva o agregue nuevas, puede guardar el resultado en formatos PPTX, PPT heredado o OpenDocument.

Para crear una presentación y colocar una forma con texto en su primera diapositiva, siga estos pasos:

1. Cree una instancia de la clase <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>. Una nueva presentación ya contiene una diapositiva vacía.
2. Obtenga esa diapositiva mediante su índice, 0, desde la colección devuelta por <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">getSlides</a>.
3. Agregue una <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iautoshape/" target="_blank" rel="nofollow noopener noreferrer">IAutoShape</a> del tipo `Cloud` mediante el método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addAutoShape-int-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addAutoShape</a>, y establezca su texto con <a href="https://reference.aspose.com/slides/java/com.aspose.slides/itextframe/#setText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setText</a>.
4. Guarde la presentación como archivo PPTX mediante el método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">save</a>.

El ejemplo siguiente es un programa completo. En el proyecto Maven de [Instalación](/java/slides/installation/), guárdelo como *src/main/java/HelloSlides.java* y ejecútelo con `mvn compile exec:java`.

```java
import com.aspose.slides.*;

public class HelloSlides {
    public static void main(String[] args) {
        // Create a presentation. It already contains one empty slide.
        Presentation presentation = new Presentation();
        try {
            // Get the first slide.
            ISlide slide = presentation.getSlides().get_Item(0);

            // Add a cloud shape and put text in it.
            IAutoShape autoShape = slide.getShapes().addAutoShape(ShapeType.Cloud, 20, 20, 200, 80);
            autoShape.getTextFrame().setText("Hello, Aspose!");

            // Save the presentation as a PPTX file.
            presentation.save("new_presentation.pptx", SaveFormat.Pptx);
        } finally {
            presentation.dispose();
        }
    }
}
```

La esquina superior izquierda de la nube está ubicada a 20 puntos del borde izquierdo y a 20 puntos del borde superior de la diapositiva, y la forma tiene un ancho de 200 puntos y una altura de 80 puntos. El programa guarda *new_presentation.pptx* con una diapositiva que contiene la nube y su texto. Sin una licencia, Aspose.Slides también agrega una marca de agua de evaluación en cada diapositiva que guarda; consulte [Licensing](/java/slides/licensing/).

## Preguntas frecuentes {#faq}
  
### ¿En qué formatos puedo guardar una presentación nueva? {#what-formats-can-i-save-a-new-presentation-to}
  
Puede guardar en [PPTX, PPT y ODP](/java/slides/save-presentation/), y exportar a [PDF](/java/slides/convert-powerpoint-to-pdf/), [XPS](/java/slides/convert-powerpoint-to-xps/), [HTML](/java/slides/convert-powerpoint-to-html/), [SVG](/java/slides/render-a-slide-as-an-svg-image/) y [imágenes](/java/slides/convert-powerpoint-to-png/), entre otros.

### ¿Puedo partir de una plantilla (POTX/POTM) y guardarla como un PPTX normal? {#can-i-start-from-a-template-potx-potm-and-save-as-a-regular-pptx}
  
Sí. Cargue la plantilla y guárdela en el formato deseado; los formatos POTX/POTM/PPTM y similares [están admitidos](/java/slides/supported-file-formats/).

### ¿Cómo controlo el tamaño/relación de aspecto de las diapositivas al crear una presentación? {#how-do-i-control-slide-size-aspect-ratio-when-creating-a-presentation}
  
Configure el [tamaño de diapositiva](/java/slides/slide-size/) (incluidas plantillas predefinidas como 4:3 y 16:9, o dimensiones personalizadas) y elija cómo debe escalarse el contenido.

### ¿En qué unidades se miden los tamaños y las coordenadas? {#in-what-units-are-sizes-and-coordinates-measured}
  
En puntos: 1 pulgada equivale a 72 unidades.

### ¿Cómo manejo presentaciones muy grandes (con muchos archivos multimedia) para reducir el uso de memoria? {#how-do-i-handle-very-large-presentations-with-many-media-files-to-reduce-memory-usage}
  
Utilice [estrategias de gestión de BLOB](/java/slides/manage-blob/), limite el almacenamiento en memoria aprovechando archivos temporales y prefiera flujos de trabajo basados en archivos frente a flujos puramente en memoria.

### ¿Puedo crear/guardar presentaciones en paralelo? {#can-i-create-save-presentations-in-parallel}
  
No puede operar sobre la misma instancia de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> desde [varios subprocesos](/java/slides/multithreading/). Ejecute instancias separadas e aisladas por subproceso o proceso.

### ¿Cómo elimino el agua de marca de prueba y las limitaciones? {#how-do-i-remove-the-trial-watermark-and-limitations}
  
[Aplicar una licencia](/java/slides/licensing/) una vez por proceso. El XML de la licencia debe permanecer sin modificar, y la configuración de la licencia debe sincronizarse si intervienen varios subprocesos.

### ¿Puedo firmar digitalmente el PPTX que creo? {#can-i-digitally-sign-the-pptx-i-create}
  
Sí. Se admiten [firmas digitales](/java/slides/digital-signature-in-powerpoint/) (agregar y verificar) para presentaciones.

### ¿Se admiten macros (VBA) en las presentaciones creadas? {#are-macros-vba-supported-in-created-presentations}
  
Sí. Puede [crear/editar proyectos VBA](/java/slides/presentation-via-vba/) y guardar archivos con macros, como PPTM/PPSM.

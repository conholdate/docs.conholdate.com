## **Resumen** {#overview}
  
Aspose.Slides puede utilizarse en modo de evaluación o con una licencia válida. La versión de evaluación ofrece la misma funcionalidad que la versión con licencia, pero añade una marca de agua de evaluación en cada diapositiva de cada presentación que guarda y trunca el texto que su código lee a través de la API.

Este artículo explica cómo funciona la licencia en Aspose.Slides y cómo aplicar una licencia antes de utilizar la biblioteca. Una licencia puede cargarse desde un archivo, un flujo o un recurso incrustado mediante la clase `License`. El artículo también muestra cómo validar si la licencia se ha aplicado correctamente.

## **Evaluar Aspose.Slides** {#evaluate-aspose-slides}
  
:::info[Nota]  
Puede descargar una versión de evaluación de **Aspose.Slides para Java** desde su <a href="https://releases.aspose.com/java/repo/com/aspose/aspose-slides/" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a>. La versión de evaluación ofrece las mismas funcionalidades que la versión con licencia del producto. El paquete de evaluación es idéntico al paquete adquirido. La versión de evaluación simplemente se convierte en una versión con licencia tras agregar algunas líneas de código (para aplicar la licencia).

Cada licencia de Aspose incluye una suscripción gratuita de un año para actualizaciones a nuevas versiones o correcciones publicadas durante el período de suscripción. Los usuarios con productos con licencia (o incluso con versiones de evaluación) obtienen soporte técnico gratuito e ilimitado.
:::

**Limitaciones de la versión de evaluación**

- La versión de evaluación (sin una licencia especificada) proporciona toda la funcionalidad del producto, pero agrega un cuadro de texto con el texto de marca de agua de evaluación en cada diapositiva de cada presentación que guarda.
- El texto que su código lee a través de la API, incluido el texto que acaba de establecer, se trunca a sus primeros caracteres, seguido de un aviso sobre la limitación de evaluación. El texto que su código escribe se guarda en su totalidad.

:::info[Nota]  
Para probar Aspose.Slides sin limitaciones, puede solicitar una **Licencia Temporal de 30 Días**. Consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">Cómo obtener una Licencia Temporal</a> para obtener más información.

## **Licencias en Aspose.Slides** {#licensing-in-aspose-slides}
  
- Una versión de evaluación se convierte en una versión con licencia tras adquirir una licencia y agregar un par de líneas de código para aplicarla.  
- La licencia es un archivo XML de texto plano que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciada, la fecha de vencimiento de la suscripción, etc.  
- El archivo de licencia está firmado digitalmente, por lo que no debe modificarse. Incluso una adición accidental de un salto de línea adicional en el contenido del archivo invalidará la licencia.  
- Aspose.Slides para Java, por lo general, intenta encontrar la licencia en estas ubicaciones:  
  - Una ruta explícita  
  - La carpeta que contiene Aspose.Slides.jar  
- Para evitar las limitaciones asociadas con la versión de evaluación, debe establecer una licencia antes de utilizar **Aspose.Slides**. Solo necesita establecer una licencia una vez por aplicación o proceso.  

:::info[Nota]  
Es posible que desee consultar [Licencia basada en consumo](/java/slides/metered-licensing/).
:::

## **Aplicación de una licencia** {#applying-a-license}
  
Una licencia puede cargarse desde un **archivo** o un **flujo**.

:::info[Nota]  
Aspose.Slides proporciona la clase <a href="https://reference.aspose.com/slides/java/com.aspose.slides/license/" target="_blank" rel="nofollow noopener noreferrer">License</a> para operaciones de licenciamiento.
:::

:::warning[Advertencia]  
Las nuevas licencias solo pueden activar Aspose.Slides con la versión 21.4 o posterior. Las versiones anteriores utilizan un sistema de licencias diferente y no reconocerán estas licencias.
:::

### **Archivo** {#file}
  
El método más sencillo para configurar una licencia consiste en colocar el archivo de licencia en la carpeta que contiene `Aspose.Slides.jar` o el archivo JAR de su aplicación.

Este código Java le muestra cómo configurar un archivo de licencia:

```java
// Instantiates the License class
com.aspose.slides.License license = new com.aspose.slides.License();

// Sets the license file path
license.setLicense("Aspose.Slides.Java.lic");
```

:::warning[Advertencia]
Si coloca el archivo de licencia en un directorio diferente, al llamar al método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setLicense</a>, el nombre del archivo de licencia al final de la ruta especificada debe ser el mismo que el nombre de su archivo de licencia.

Por ejemplo, puede cambiar el nombre del archivo de licencia a *Aspose.Slides.Java.lic.xml*. Luego, en su código, debe pasar la ruta al archivo (terminando con *Aspose.Slides.Java.lic.xml*) al método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setLicense</a>.
:::

### **Stream** {#stream}
  
Puede cargar una licencia desde un flujo (stream). El siguiente código en Java le muestra cómo aplicar una licencia desde un flujo:

```java
// Instantiates the License class
com.aspose.slides.License license = new com.aspose.slides.License();

// Sets the license through a stream
license.setLicense(new java.io.FileInputStream("Aspose.Slides.Java.lic"));
```

### **PHP/Java Bridge** {#php-java-bridge}
  
Si utiliza Aspose.Slides para PHP a través de Java, puede establecer una licencia mediante un puente PHP/Java. Este puente le permite utilizar clases de Java en sintaxis PHP. Para obtener más información, consulte <a href="https://docs.aspose.com/slides/php-java/licensing/" target="_blank" rel="nofollow noopener noreferrer">Licencia en PHP</a>.

## **Validación de una licencia** {#validating-a-license}
  
Para comprobar si una licencia se ha establecido correctamente, puede validarla. El siguiente código Java le muestra cómo validar una licencia:

```java
import com.aspose.slides.*;

License license = new License();
license.setLicense("Aspose.Slides.Java.lic");

if (license.isLicensed()) 
{
    System.out.println("License is good!");
}
```

## **Seguridad en hilos** {#thread-safety}
  
:::warning[Advertencia]  
El método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/license/#setLicense-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">setLicense</a> no es seguro para hilos. Si este método debe llamarse simultáneamente desde varios hilos, es recomendable utilizar primitivas de sincronización (como un bloqueo) para evitar problemas.
:::

## **Preguntas frecuentes** {#faq}
  
### ¿Puedo aplicar la licencia en un entorno completamente sin conexión (sin acceso a internet)? {#can-i-apply-the-license-in-a-completely-offline-environment-no-internet-access}
  
Sí. La validación de la licencia se realiza localmente mediante el archivo de licencia; no se requiere conexión a internet.  

### ¿Qué ocurre tras la expiración de la suscripción de un año? ¿Dejará de funcionar la biblioteca? {#what-happens-after-the-one-year-subscription-expires-will-the-library-stop-working}
  
No. La licencia es perpetua: puede seguir utilizando las versiones publicadas antes de la fecha de finalización de su suscripción; simplemente no tendrá derecho a utilizar versiones más recientes sin renovarla.

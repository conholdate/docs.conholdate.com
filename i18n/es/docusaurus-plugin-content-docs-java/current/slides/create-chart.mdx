> Cree y personalice gráficos en presentaciones de PowerPoint utilizando Aspose.Slides para Java. Agregue, formatee y edite gráficos con ejemplos prácticos de código en Java.

## **Resumen** {#overview}
  
Este artículo ofrece una guía completa sobre cómo crear y personalizar gráficos mediante Aspose.Slides para Java. Aprenderá a agregar programáticamente un gráfico a una diapositiva, rellenarlo con datos y aplicar diversas opciones de formato para adaptarse a sus requisitos específicos de diseño. A lo largo del artículo, se presentan ejemplos de código detallados que ilustran cada paso, desde la inicialización de la presentación y del objeto gráfico hasta la configuración de series, ejes y leyendas. Al seguir esta guía, obtendrá una comprensión sólida sobre cómo integrar la generación dinámica de gráficos en sus aplicaciones Java, simplificando así el proceso de creación de presentaciones basadas en datos.

## **Crear un gráfico** {#create-a-chart}
  
Los gráficos ayudan a las personas a visualizar rápidamente los datos y obtener información que podría no ser evidente de inmediato a partir de una tabla o una hoja de cálculo.

**¿Por qué crear gráficos?**

Mediante el uso de gráficos, puede:

- agrupar, condensar o resumir grandes cantidades de datos en una sola diapositiva de una presentación;
- revelar patrones y tendencias en los datos;
- deducir la dirección y la magnitud de los cambios en los datos a lo largo del tiempo o con respecto a una unidad de medida específica;
- identificar valores atípicos, anomalías, desviaciones, errores y datos sin sentido;
- comunicar o presentar datos complejos.

En PowerPoint, puede crear gráficos mediante la función *Insertar*, que proporciona plantillas para diseñar muchos tipos de gráficos. Con Aspose.Slides, puede crear tanto gráficos estándar (basados en tipos de gráficos populares) como gráficos personalizados.

:::info[Nota]  
Utilice la enumeración <a href="https://reference.aspose.com/slides/java/com.aspose.slides/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> del paquete <a href="https://reference.aspose.com/slides/java/com.aspose.slides/" target="_blank" rel="nofollow noopener noreferrer">com.aspose.slides</a>. Los valores de esta enumeración corresponden a distintos tipos de gráficos.
:::

### **Crear gráficos de columnas agrupadas** {#create-clustered-column-charts}
  
Este ejemplo utiliza <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addChart-int-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addChart</a> para crear un gráfico de columnas agrupadas que compara dos series a través de tres categorías. Las series utilizan rellenos rojo y verde, y las etiquetas individuales muestran los nombres de las categorías, los nombres de las series y los valores. El índice de hoja 0 hace referencia a la primera hoja del libro de trabajo incrustado en el gráfico.

```java
import com.aspose.slides.*;
import java.awt.Color;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.ClusteredColumn, 20, 20, 500, 300);

    chart.getChartTitle().addTextFrameForOverriding("Sample Title");
    chart.getChartTitle().getTextFrameForOverriding().getTextFrameFormat().setCenterText(NullableBool.True);
    chart.getChartTitle().setHeight(20);
    chart.setTitle(true);

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    int worksheetIndex = 0;

    chart.getChartData().getSeries().clear();
    chart.getChartData().getCategories().clear();

    IChartDataCell seriesNameCell = workbook.getCell(worksheetIndex, 0, 1, "Series 1");
    chart.getChartData().getSeries().add(seriesNameCell, chart.getType());
    seriesNameCell = workbook.getCell(worksheetIndex, 0, 2, "Series 2");
    chart.getChartData().getSeries().add(seriesNameCell, chart.getType());

    IChartDataCell categoryCell = workbook.getCell(worksheetIndex, 1, 0, "Category 1");
    chart.getChartData().getCategories().add(categoryCell);
    categoryCell = workbook.getCell(worksheetIndex, 2, 0, "Category 2");
    chart.getChartData().getCategories().add(categoryCell);
    categoryCell = workbook.getCell(worksheetIndex, 3, 0, "Category 3");
    chart.getChartData().getCategories().add(categoryCell);

    IChartSeries series = chart.getChartData().getSeries().get_Item(0);

    IChartDataCell valueCell = workbook.getCell(worksheetIndex, 1, 1, 20);
    series.getDataPoints().addDataPointForBarSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 2, 1, 50);
    series.getDataPoints().addDataPointForBarSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 3, 1, 30);
    series.getDataPoints().addDataPointForBarSeries(valueCell);

    series.getFormat().getFill().setFillType(FillType.Solid);
    series.getFormat().getFill().getSolidFillColor().setColor(Color.RED);

    series = chart.getChartData().getSeries().get_Item(1);

    valueCell = workbook.getCell(worksheetIndex, 1, 2, 30);
    series.getDataPoints().addDataPointForBarSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 2, 2, 10);
    series.getDataPoints().addDataPointForBarSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 3, 2, 60);
    series.getDataPoints().addDataPointForBarSeries(valueCell);

    series.getFormat().getFill().setFillType(FillType.Solid);
    series.getFormat().getFill().getSolidFillColor().setColor(new Color(0, 128, 0));

    IDataLabel label = series.getDataPoints().get_Item(0).getLabel();
    label.getDataLabelFormat().setShowCategoryName(true);

    label = series.getDataPoints().get_Item(1).getLabel();
    label.getDataLabelFormat().setShowSeriesName(true);

    label = series.getDataPoints().get_Item(2).getLabel();
    label.getDataLabelFormat().setShowValue(true);
    label.getDataLabelFormat().setShowSeriesName(true);
    label.getDataLabelFormat().setSeparator("/");

    presentation.save("AsposeChart.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

### **Crear gráficos de dispersión** {#create-scatter-charts}
  
Los gráficos de dispersión (también conocidos como diagramas de dispersión o gráficos x-y) se utilizan frecuentemente para detectar patrones o demostrar correlaciones entre dos variables.

Utilice un gráfico de dispersión cuando:

- Tenga datos numéricos emparejados.
- Tenga dos variables que se relacionen bien entre sí.
- Desee determinar si ambas variables están relacionadas.
- Tenga una variable independiente que tenga múltiples valores para una variable dependiente.

Este ejemplo representa dos conjuntos de valores x-y. La primera serie utiliza líneas rectas con marcadores en forma de estrella, mientras que la segunda utiliza líneas suaves con marcadores circulares; ambas utilizan un tamaño de marcador de 10, configurado mediante <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imarker/#setSize-int-" target="_blank" rel="nofollow noopener noreferrer">setSize</a>. El método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imarker/#setSymbol-int-" target="_blank" rel="nofollow noopener noreferrer">setSymbol</a> controla la forma del marcador.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.ScatterWithSmoothLines, 20, 20, 500, 300);

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    int worksheetIndex = 0;

    chart.getChartData().getSeries().clear();

    IChartDataCell seriesNameCell = workbook.getCell(worksheetIndex, 1, 1, "Series 1");
    chart.getChartData().getSeries().add(seriesNameCell, chart.getType());
    seriesNameCell = workbook.getCell(worksheetIndex, 1, 3, "Series 2");
    chart.getChartData().getSeries().add(seriesNameCell, chart.getType());

    IChartSeries series = chart.getChartData().getSeries().get_Item(0);

    IChartDataCell xValueCell = workbook.getCell(worksheetIndex, 2, 1, 1);
    IChartDataCell yValueCell = workbook.getCell(worksheetIndex, 2, 2, 3);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    xValueCell = workbook.getCell(worksheetIndex, 3, 1, 2);
    yValueCell = workbook.getCell(worksheetIndex, 3, 2, 10);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    series.setType(ChartType.ScatterWithStraightLinesAndMarkers);

    series.getMarker().setSize(10);
    series.getMarker().setSymbol(MarkerStyleType.Star);

    series = chart.getChartData().getSeries().get_Item(1);

    xValueCell = workbook.getCell(worksheetIndex, 2, 3, 5);
    yValueCell = workbook.getCell(worksheetIndex, 2, 4, 2);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    xValueCell = workbook.getCell(worksheetIndex, 3, 3, 3);
    yValueCell = workbook.getCell(worksheetIndex, 3, 4, 1);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    xValueCell = workbook.getCell(worksheetIndex, 4, 3, 2);
    yValueCell = workbook.getCell(worksheetIndex, 4, 4, 2);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    xValueCell = workbook.getCell(worksheetIndex, 5, 3, 5);
    yValueCell = workbook.getCell(worksheetIndex, 5, 4, 1);
    series.getDataPoints().addDataPointForScatterSeries(xValueCell, yValueCell);

    series.getMarker().setSize(10);
    series.getMarker().setSymbol(MarkerStyleType.Circle);

    presentation.save("AsposeChart.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

### **Crear gráficos de pastel** {#create-pie-charts}
  
Los gráficos de pastel son ideales para mostrar la relación parte-todo en los datos, especialmente cuando los datos contienen etiquetas categóricas con valores numéricos. Sin embargo, si sus datos contienen muchas partes o etiquetas, podría considerar utilizar un gráfico de barras en su lugar.

Este ejemplo crea un gráfico de pastel con tres valores trimestrales. Cada porción tiene un relleno y un borde personalizados, y las etiquetas muestran distintas combinaciones de valores, porcentajes e información de series. El método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartseriesgroup/#setFirstSliceAngle-int-" target="_blank" rel="nofollow noopener noreferrer">setFirstSliceAngle</a> establece que la primera porción comience en 180 grados.

```java
import com.aspose.slides.*;
import java.awt.Color;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.Pie, 20, 20, 500, 300);

    chart.getChartTitle().addTextFrameForOverriding("Sample Title");
    chart.getChartTitle().getTextFrameForOverriding().getTextFrameFormat().setCenterText(NullableBool.True);
    chart.getChartTitle().setHeight(20);
    chart.setTitle(true);

    chart.getChartData().getSeries().get_Item(0).getLabels().getDefaultDataLabelFormat().setShowValue(true);

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    int worksheetIndex = 0;

    chart.getChartData().getSeries().clear();
    chart.getChartData().getCategories().clear();

    IChartDataCell categoryCell = workbook.getCell(0, 1, 0, "1st Qtr");
    chart.getChartData().getCategories().add(categoryCell);
    categoryCell = workbook.getCell(0, 2, 0, "2nd Qtr");
    chart.getChartData().getCategories().add(categoryCell);
    categoryCell = workbook.getCell(0, 3, 0, "3rd Qtr");
    chart.getChartData().getCategories().add(categoryCell);

    IChartDataCell seriesNameCell = workbook.getCell(0, 0, 1, "Series 1");
    IChartSeries series = chart.getChartData().getSeries().add(seriesNameCell, chart.getType());

    IChartDataCell valueCell = workbook.getCell(worksheetIndex, 1, 1, 20);
    series.getDataPoints().addDataPointForPieSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 2, 1, 50);
    series.getDataPoints().addDataPointForPieSeries(valueCell);
    valueCell = workbook.getCell(worksheetIndex, 3, 1, 30);
    series.getDataPoints().addDataPointForPieSeries(valueCell);

    chart.getChartData().getSeriesGroups().get_Item(0).setColorVaried(true);

    IChartDataPoint firstSlice = series.getDataPoints().get_Item(0);
    firstSlice.getFormat().getFill().setFillType(FillType.Solid);
    firstSlice.getFormat().getFill().getSolidFillColor().setColor(Color.CYAN);

    firstSlice.getFormat().getLine().getFillFormat().setFillType(FillType.Solid);
    firstSlice.getFormat().getLine().getFillFormat().getSolidFillColor().setColor(Color.GRAY);
    firstSlice.getFormat().getLine().setWidth(3.0);
    firstSlice.getFormat().getLine().setStyle(LineStyle.ThinThick);
    firstSlice.getFormat().getLine().setDashStyle(LineDashStyle.LargeDash);

    IChartDataPoint secondSlice = series.getDataPoints().get_Item(1);
    secondSlice.getFormat().getFill().setFillType(FillType.Solid);
    secondSlice.getFormat().getFill().getSolidFillColor().setColor(new Color(165, 42, 42));

    secondSlice.getFormat().getLine().getFillFormat().setFillType(FillType.Solid);
    secondSlice.getFormat().getLine().getFillFormat().getSolidFillColor().setColor(Color.BLUE);
    secondSlice.getFormat().getLine().setWidth(3.0);
    secondSlice.getFormat().getLine().setStyle(LineStyle.Single);
    secondSlice.getFormat().getLine().setDashStyle(LineDashStyle.LargeDashDot);

    IChartDataPoint thirdSlice = series.getDataPoints().get_Item(2);
    thirdSlice.getFormat().getFill().setFillType(FillType.Solid);
    thirdSlice.getFormat().getFill().getSolidFillColor().setColor(new Color(255, 127, 80));

    thirdSlice.getFormat().getLine().getFillFormat().setFillType(FillType.Solid);
    thirdSlice.getFormat().getLine().getFillFormat().getSolidFillColor().setColor(Color.RED);
    thirdSlice.getFormat().getLine().setWidth(2.0);
    thirdSlice.getFormat().getLine().setStyle(LineStyle.ThinThin);
    thirdSlice.getFormat().getLine().setDashStyle(LineDashStyle.LargeDashDotDot);

    IDataLabel firstLabel = series.getDataPoints().get_Item(0).getLabel();
    firstLabel.getDataLabelFormat().setShowValue(true);

    IDataLabel secondLabel = series.getDataPoints().get_Item(1).getLabel();
    secondLabel.getDataLabelFormat().setShowValue(true);
    secondLabel.getDataLabelFormat().setShowLegendKey(true);
    secondLabel.getDataLabelFormat().setShowPercentage(true);

    IDataLabel thirdLabel = series.getDataPoints().get_Item(2).getLabel();
    thirdLabel.getDataLabelFormat().setShowSeriesName(true);
    thirdLabel.getDataLabelFormat().setShowPercentage(true);

    series.getLabels().getDefaultDataLabelFormat().setShowLeaderLines(true);

    chart.getChartData().getSeriesGroups().get_Item(0).setFirstSliceAngle(180);

    presentation.save("PieChart.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

### **Crear gráficos de líneas** {#create-line-charts}
  
Los gráficos de líneas (también conocidos como gráficos lineales) son ideales para situaciones en las que se desea mostrar cambios en un valor a lo largo del tiempo. Con un gráfico de líneas, puede comparar una gran cantidad de datos de una sola vez, rastrear cambios y tendencias a lo largo del tiempo, resaltar anomalías en series de datos y más.

Este ejemplo utiliza <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addChart-int-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addChart</a> para crear un gráfico de líneas con las series y categorías predeterminadas, y luego guarda la presentación como archivo PPTX.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart lineChart = slide.getShapes().addChart(ChartType.Line, 20, 20, 500, 300);

    presentation.save("lineChart.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

De forma predeterminada, los puntos de un gráfico de líneas se unen mediante líneas rectas continuas. Si desea que los puntos se unan mediante guiones en su lugar, llame a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ilineformat/#setDashStyle-byte-" target="_blank" rel="nofollow noopener noreferrer">setDashStyle</a> con un valor de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/linedashstyle/" target="_blank" rel="nofollow noopener noreferrer">LineDashStyle</a>:

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart lineChart = slide.getShapes().addChart(ChartType.Line, 20, 20, 500, 300);

    for (IChartSeries series : lineChart.getChartData().getSeries())
    {
        series.getFormat().getLine().setDashStyle(LineDashStyle.Dash);
    }
}
finally
{
    presentation.dispose();
}
```

### **Crear gráficos de mapa de árboles** {#create-tree-map-charts}
  
Los gráficos de mapa de árboles son ideales para datos de ventas cuando se desea mostrar el tamaño relativo de las categorías de datos y destacar rápidamente los elementos que representan una gran contribución dentro de cada categoría.

Este ejemplo crea un mapa de árboles con ocho hojas agrupadas en cuatro tallos y dos ramas. El método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartcategorylevelsmanager/#setGroupingItem-int-java.lang.Object-" target="_blank" rel="nofollow noopener noreferrer">setGroupingItem</a> asigna tallos en el nivel de agrupación 1 y ramas en el nivel 2. Los valores determinan los tamaños relativos de los rectángulos, mientras que las etiquetas de categoría y las etiquetas de padres superpuestas identifican la jerarquía.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.Treemap, 20, 20, 500, 300);

    chart.getChartData().getCategories().clear();
    chart.getChartData().getSeries().clear();

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    workbook.clear(0);

    // Branch 1
    IChartDataCell categoryCell = workbook.getCell(0, "C1", "Leaf1");
    IChartCategory leaf = chart.getChartData().getCategories().add(categoryCell);
    leaf.getGroupingLevels().setGroupingItem(1, "Stem1");
    leaf.getGroupingLevels().setGroupingItem(2, "Branch1");

    categoryCell = workbook.getCell(0, "C2", "Leaf2");
    chart.getChartData().getCategories().add(categoryCell);

    categoryCell = workbook.getCell(0, "C3", "Leaf3");
    leaf = chart.getChartData().getCategories().add(categoryCell);
    leaf.getGroupingLevels().setGroupingItem(1, "Stem2");

    categoryCell = workbook.getCell(0, "C4", "Leaf4");
    chart.getChartData().getCategories().add(categoryCell);

    // Branch 2
    categoryCell = workbook.getCell(0, "C5", "Leaf5");
    leaf = chart.getChartData().getCategories().add(categoryCell);
    leaf.getGroupingLevels().setGroupingItem(1, "Stem3");
    leaf.getGroupingLevels().setGroupingItem(2, "Branch2");

    categoryCell = workbook.getCell(0, "C6", "Leaf6");
    chart.getChartData().getCategories().add(categoryCell);

    categoryCell = workbook.getCell(0, "C7", "Leaf7");
    leaf = chart.getChartData().getCategories().add(categoryCell);
    leaf.getGroupingLevels().setGroupingItem(1, "Stem4");

    categoryCell = workbook.getCell(0, "C8", "Leaf8");
    chart.getChartData().getCategories().add(categoryCell);

    IChartSeries series = chart.getChartData().getSeries().add(ChartType.Treemap);
    series.getLabels().getDefaultDataLabelFormat().setShowCategoryName(true);
    IChartDataCell valueCell = workbook.getCell(0, "D1", 4);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D2", 5);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D3", 3);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D4", 6);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D5", 9);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D6", 9);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D7", 4);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);
    valueCell = workbook.getCell(0, "D8", 3);
    series.getDataPoints().addDataPointForTreemapSeries(valueCell);

    series.setParentLabelLayout(ParentLabelLayoutType.Overlapping);

    presentation.save("Treemap.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

### **Crear gráficos de cascada** {#create-waterfall-charts}
  
Un gráfico de cascada muestra cómo los cambios positivos y negativos contribuyen a un valor final. Por ejemplo, un desglose de beneficios puede comenzar con los ingresos, restar los costos y sumar otros ingresos. Las columnas de cambio se ubican entre los valores anteriores y los nuevos valores acumulados, mientras que las columnas totales se extienden desde cero hasta el valor acumulado.

El siguiente ejemplo utiliza cantidades en miles de dólares estadounidenses:

<div className="docs-owner-markdown-table">

| Categoría | Valor del libro de trabajo | Tipo de columna |
| ------------------ | -------------: | ------------------ |
| Ingresos | 1000 | Aumento |
| Costo de ventas | -400 | Disminución |
| Beneficio bruto | 600 | Total intermedio |
| Gastos operativos | -200 | Disminución |
| Otros ingresos | 50 | Aumento |
| Beneficio neto | 450 | Total final |

</div>

Para marcar un punto como total intermedio o final, invoque su método <a href="https://reference.aspose.com/slides/java/com.aspose.slides/chartdatapoint/#setSetAsTotal-boolean-" target="_blank" rel="nofollow noopener noreferrer">setSetAsTotal</a> con `true`. Proporcione el importe acumulado real en la celda de la hoja de cálculo correspondiente a ese punto: `600` para la ganancia bruta (`1000 - 400`) y `450` para la ganancia neta (`600 - 200 + 50`). Este método marca la columna como un total, pero no calcula ni rellena el valor de la celda. No utilice cero como marcador de posición ni proporcione otro valor distinto para un punto total. Una columna total muestra el valor acumulado sin volver a sumarlo al valor en curso.

Este ejemplo completo en Java crea un gráfico utilizando el miembro `Waterfall` de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a>, borra los datos predeterminados y rellena la hoja de cálculo incrustada. El índice de hoja `0` selecciona la primera hoja; la columna A contiene los nombres de las categorías y la columna B contiene los valores. Cada celda de valor se agrega mediante <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartdatapointcollection/#addDataPointForWaterfallSeries-com.aspose.slides.IChartDataCell-" target="_blank" rel="nofollow noopener noreferrer">addDataPointForWaterfallSeries</a>. Los índices de punto basados en cero `2` y `5` identifican los totales intermedios y finales, respectivamente. Al invocar <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idatalabelformat/#setShowValue-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShowValue</a> con `true`, se muestran los importes sobre las columnas. No se requiere ninguna presentación de entrada ni hoja de cálculo.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.Waterfall, 20, 20, 680, 200);

    chart.setTitle(true);
    chart.getChartTitle().addTextFrameForOverriding("Profit breakdown (USD thousands)");
    chart.getChartTitle().setOverlay(false);
    chart.setLegend(false);

    chart.getChartData().getSeries().clear();
    chart.getChartData().getCategories().clear();

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    int worksheetIndex = 0;

    workbook.clear(worksheetIndex);

    IChartDataCell seriesNameCell = workbook.getCell(worksheetIndex, 0, 1, "Profit");
    IChartSeries series = chart.getChartData().getSeries().add(seriesNameCell, ChartType.Waterfall);
    String[] categories = new String[] { "Revenue", "Cost of sales", "Gross profit", "Operating expenses", "Other income", "Net profit" };
    double[] values = new double[] { 1000, -400, 600, -200, 50, 450 };

    for (int i = 0; i < categories.length; i++)
    {
        IChartDataCell categoryCell = workbook.getCell(worksheetIndex, i + 1, 0, categories[i]);
        chart.getChartData().getCategories().add(categoryCell);
        IChartDataCell valueCell = workbook.getCell(worksheetIndex, i + 1, 1, values[i]);
        series.getDataPoints().addDataPointForWaterfallSeries(valueCell);
    }

    // The third and sixth points represent totals, not additional changes.
    series.getDataPoints().get_Item(2).setSetAsTotal(true);
    series.getDataPoints().get_Item(5).setSetAsTotal(true);
    series.setShowConnectorLines(true);
    series.getLabels().getDefaultDataLabelFormat().setShowValue(true);

    presentation.save("WaterfallChart.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

Llame al método a nivel de serie <a href="https://reference.aspose.com/slides/java/com.aspose.slides/chartseries/#setShowConnectorLines-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShowConnectorLines</a> con `true` para mostrar líneas que conecten columnas consecutivas y facilitar el seguimiento del valor acumulado. Para ocultar estas líneas, reemplace la llamada al método en el ejemplo con `series.setShowConnectorLines(false);` antes de guardar. Esto solo cambia la visibilidad de las líneas, no los datos ni los totales.

### **Crear gráficos de histograma** {#create-histogram-charts}
  
Los gráficos de histograma muestran cómo se distribuyen los valores numéricos en intervalos (contenedores). Para informes mensuales sobre tiempos de procesamiento de pedidos, utilice la misma amplitud de contenedor y los mismos umbrales para mantener los intervalos consistentes y facilitar la comparación de las distribuciones.

Llame a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setAggregationType-int-" target="_blank" rel="nofollow noopener noreferrer">setAggregationType</a> en el eje horizontal con un modo de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/axisaggregationtype/" target="_blank" rel="nofollow noopener noreferrer">AxisAggregationType</a>. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setBinWidth-double-" target="_blank" rel="nofollow noopener noreferrer">setBinWidth</a> solo se aplica a `ByBinWidth`; <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setNumberOfBins-long-" target="_blank" rel="nofollow noopener noreferrer">setNumberOfBins</a> solo se aplica a `ByNumberOfBins`. Utilice `Automatic` para permitir que el gráfico elija los contenedores automáticamente.

#### **Utilizar una amplitud de contenedor fija** {#use-a-fixed-bin-width}
  
Este ejemplo agrupa los tiempos de procesamiento en intervalos de 10 minutos, con contenedores separados para tiempos de 10 minutos o menos y para tiempos superiores a 40 minutos. Active estos contenedores con <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setUnderflowBin-boolean-" target="_blank" rel="nofollow noopener noreferrer">setUnderflowBin</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setOverflowBin-boolean-" target="_blank" rel="nofollow noopener noreferrer">setOverflowBin</a>. Al proporcionar umbrales explícitos mediante <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setUnderflowBin-double-" target="_blank" rel="nofollow noopener noreferrer">setUnderflowBin</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setOverflowBin-double-" target="_blank" rel="nofollow noopener noreferrer">setOverflowBin</a>, llame a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setAutomaticUnderflowBin-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAutomaticUnderflowBin</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaxis/#setAutomaticOverflowBin-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAutomaticOverflowBin</a> con `false`.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try
{
    ISlide slide = presentation.getSlides().get_Item(0);

    IChart chart = slide.getShapes().addChart(ChartType.Histogram, 20, 20, 680, 200);

    chart.setLegend(false);
    chart.setTitle(false);

    chart.getChartData().getCategories().clear();
    chart.getChartData().getSeries().clear();

    IChartDataWorkbook workbook = chart.getChartData().getChartDataWorkbook();
    workbook.clear(0);

    IChartSeries series = chart.getChartData().getSeries().add(ChartType.Histogram);
    double[] values = { 5, 10, 10, 11, 15, 20, 20, 21, 25, 30, 30, 31, 35, 40, 40, 41, 50 };
    for (int i = 0; i < values.length; i++)
    {
        IChartDataCell valueCell = workbook.getCell(0, i, 0, values[i]);
        series.getDataPoints().addDataPointForHistogramSeries(valueCell);
    }

    IAxis axis = chart.getAxes().getHorizontalAxis();
    axis.setAggregationType(AxisAggregationType.ByBinWidth);
    axis.setBinWidth(10);
    axis.setUnderflowBin(true);
    axis.setAutomaticUnderflowBin(false);
    axis.setUnderflowBin(10);
    axis.setOverflowBin(true);
    axis.setAutomaticOverflowBin(false);
    axis.setOverflowBin(40);

    presentation.save("Histogram-bin-width.pptx", SaveFormat.Pptx);
}
finally
{
    presentation.dispose();
}
```

La presentación mostrada en PowerPoint muestra recuentos de bins de **3, 4, 4, 4 y 2**. El bin de subflujo incluye `5, 10, 10`, por lo que su umbral es inclusivo. El bin de sobreflujo incluye únicamente `41, 50`, por lo que su umbral es exclusivo; ambos valores iguales a `40` permanecen en el intervalo anterior. Los bins interiores contienen valores mayores que su límite inferior y menores o iguales que su límite superior.

#### **Especificar el número de contenedores** {#specify-the-number-of-bins}
  
Para un nivel de detalle fijo en lugar de intervalos fijos, solicite cinco contenedores para los mismos datos. Un gráfico combinado (o gráfico de combinación) une dos o más tipos de gráficos en una sola representación. Este tipo de gráfico permite resaltar, comparar o examinar las diferencias entre dos o más conjuntos de datos, ayudándole a identificar las relaciones entre ellos.

Este ejemplo combina dos series de columnas agrupadas con una serie de línea a través de cuatro categorías.     presentation.save("DefaultMarkersInChart.pptx", SaveFormat.Pptx);
```java
}
finally
{
    presentation.dispose();
}
```

## **Preguntas frecuentes** {#faq}
  
**¿Qué tipos de gráficos admite Aspose.Slides para Java?**  

Aspose.Slides para Java admite una amplia gama de tipos de gráficos, incluidos barras, líneas, sectores (tarta), áreas, dispersión, histograma, radar y muchos más. Esta flexibilidad le permite elegir el tipo de gráfico más adecuado para sus necesidades de visualización de datos.  

**¿Cómo agrego un gráfico nuevo a una diapositiva?**  

Para agregar un gráfico, primero crea una instancia de la clase <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>, recupera la diapositiva deseada mediante su índice y luego llama al método para agregar un gráfico, especificando el tipo de gráfico y los datos iniciales. Este proceso integra el gráfico directamente en su presentación.  

**¿Cómo puedo actualizar los datos mostrados en un gráfico?**  

Puede actualizar los datos de un gráfico accediendo a su libro de trabajo de datos (<a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartdataworkbook/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook</a>), borrando las series y categorías predeterminadas, y luego agregando sus datos personalizados. Esto le permite actualizar programáticamente el gráfico para reflejar los datos más recientes.  

**¿Es posible personalizar la apariencia del gráfico?**  

Sí, Aspose.Slides para Java ofrece amplias opciones de personalización. Puede modificar colores, fuentes, etiquetas, leyendas y otros elementos de formato para adaptar la apariencia del gráfico a sus requisitos específicos de diseño.

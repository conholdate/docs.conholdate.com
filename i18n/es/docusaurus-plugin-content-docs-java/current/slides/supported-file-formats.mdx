> Consulte qué formatos de archivo puede cargar, importar, guardar y representar Aspose.Slides para Java, y qué API lee o escribe cada uno.

## **Resumen** {#overview}
  
Aspose.Slides para Java abre y guarda presentaciones de PowerPoint y OpenDocument. También importa contenido de PDF y HTML a diapositivas, guarda presentaciones en formatos de documento, web e imagen, y representa diapositivas y formas individuales como imágenes. Este artículo enumera cada formato admitido e indica la API que lo lee o escribe.

Para una descripción general de las funciones de edición, consulte [Descripción general de funciones](/java/slides/features-overview/).

## **Versiones de Microsoft PowerPoint admitidas** {#supported-microsoft-powerpoint-versions}
  
- Microsoft PowerPoint 97  
- Microsoft PowerPoint 2000  
- Microsoft PowerPoint XP  
- Microsoft PowerPoint 2003  
- Microsoft PowerPoint 2007  
- Microsoft PowerPoint 2010  
- Microsoft PowerPoint 2013  
- Microsoft PowerPoint 2016  
- Microsoft PowerPoint 2019  
- Microsoft PowerPoint para Mac  
- PowerPoint para Microsoft 365 (anteriormente Office 365)  

:::info[Nota]  
Las presentaciones guardadas por PowerPoint 95 y versiones anteriores no pueden abrirse. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> reconoce un archivo de PowerPoint 95 y reporta `LoadFormat.Ppt95`, pero el constructor <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#Presentation-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> lanza <a href="https://reference.aspose.com/slides/java/com.aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> para este caso.
:::

## **Formatos de archivo compatibles** {#supported-file-formats}
  
La tabla utiliza cuatro operaciones:

- **Carga**: el constructor <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#Presentation-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> abre el archivo como una presentación editable.  
- **Importación**: un método de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slidecollection/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection</a> crea diapositivas a partir del contenido del archivo y las agrega a una presentación existente. El constructor Presentation no convierte estos archivos en diapositivas.  
- **Guardado**: <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> escribe la presentación en un archivo o flujo. Cada formato, excepto XAML, se selecciona mediante un valor de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a>.  
- **Renderizado**: un método de renderizado dibuja una diapositiva o una forma como una imagen. Los formatos que solo se renderizan no son valores de SaveFormat.

## **Carga e importación** {#load-and-import}
  
- **Carga:** Pase una ruta de archivo o un flujo al constructor de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#Presentation-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>. El formato se detecta a partir del contenido; <a href="https://reference.aspose.com/slides/java/com.aspose.slides/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> proporciona configuraciones como una contraseña. Para comprobar un archivo antes de abrirlo, llame a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a>, que devuelve un valor de tipo <a href="https://reference.aspose.com/slides/java/com.aspose.slides/loadformat/" target="_blank" rel="nofollow noopener noreferrer">LoadFormat</a>. Este método informa `LoadFormat.Unknown` para archivos XML de PowerPoint, pero el constructor sí abre dichos archivos, y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSourceFormat--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSourceFormat</a> devuelve `SourceFormat.Xml`. Consulte [Abrir presentaciones](/java/slides/open-presentation/) y [Determinar el formato original de la presentación](/java/slides/detect-presentation-source-format/).  
- **Importación:** <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slidecollection/#addFromPdf-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.addFromPdf</a> agrega una diapositiva por página PDF al final de la presentación. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slidecollection/#addFromHtml-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.addFromHtml</a> agrega diapositivas creadas a partir de HTML, y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slidecollection/#insertFromHtml-int-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.insertFromHtml</a> las inserta en una posición determinada. El constructor de Presentation no realiza importación: lanza <a href="https://reference.aspose.com/slides/java/com.aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> para archivos PDF y no convierte el marcado HTML en contenido de diapositivas. Consulte [Importar presentaciones desde PDF o HTML](/java/slides/import-presentation/).  

## **Guardado y renderizado** {#save-and-render}
  
- **Guardado:** <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> escribe la presentación en el formato especificado por un valor de tipo <a href="https://reference.aspose.com/slides/java/com.aspose.slides/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a>. Las sobrecargas que también aceptan un objeto de opciones controlan la salida, por ejemplo <a href="https://reference.aspose.com/slides/java/com.aspose.slides/pdfoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/htmloptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlOptions</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/html5options/" target="_blank" rel="nofollow noopener noreferrer">Html5Options</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/tiffoptions/" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/gifoptions/" target="_blank" rel="nofollow noopener noreferrer">GifOptions</a>. Las sobrecargas que aceptan un array de posiciones de diapositivas (empezando desde 1) escriben únicamente esas diapositivas; aceptan PDF, XPS, TIFF, HTML, HTML5, SWF, GIF y Markdown, pero no los formatos de presentación ni XML de PowerPoint. XAML tiene su propia sobrecarga, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-com.aspose.slides.IXamlOptions-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a>, que acepta <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ixamloptions/" target="_blank" rel="nofollow noopener noreferrer">IXamlOptions</a>. Consulte [Guardar presentaciones](/java/slides/save-presentation/), [Convertir presentaciones](/java/slides/convert-presentation/) y [Exportar presentaciones a XAML](/java/slides/export-to-xaml/).  
- **Renderizado:** <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slide/#getImage-float-float-" target="_blank" rel="nofollow noopener noreferrer">Slide.getImage</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/shape/#getImage--" target="_blank" rel="nofollow noopener noreferrer">Shape.getImage</a> devuelven un <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimage/" target="_blank" rel="nofollow noopener noreferrer">IImage</a>, y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimage/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">IImage.save</a> lo escribe como PNG, JPEG, BMP, GIF o TIFF, según el valor de <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imageformat/" target="_blank" rel="nofollow noopener noreferrer">ImageFormat</a> especificado. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getImages-com.aspose.slides.IRenderingOptions-" target="_blank" rel="nofollow noopener noreferrer">Presentation.getImages</a> renderiza todas las diapositivas o las seleccionadas de una sola vez. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slide/#writeAsSvg-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">Slide.writeAsSvg</a> y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/shape/#writeAsSvg-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">Shape.writeAsSvg</a> escriben SVG, y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slide/#writeAsEmf-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">Slide.writeAsEmf</a> escribe EMF. Consulte [Convertir diapositivas de presentación a imágenes](/java/slides/convert-slide/) y [Renderizar diapositivas de presentación como imágenes SVG](/java/slides/render-a-slide-as-an-svg-image/).  

:::warning[Advertencia]  
ImageFormat también tiene los valores `Emf`, `Wmf`, `Icon`, `Exif` y `MemoryBmp`, pero IImage.save no genera esos formatos: el archivo que escribe contiene datos PNG. Para obtener una imagen EMF de una diapositiva, utilice Slide.writeAsEmf.
:::

## **Preguntas frecuentes** {#faq}
  
**¿Puedo convertir una presentación PPT a PPTX u ODP?**  

Sí. Abra el archivo PPT con el constructor de Presentación y guárdelo con `SaveFormat.Pptx` o `SaveFormat.Odp`. Consulte [Convertir PPT a PPTX](/java/slides/convert-ppt-to-pptx/).

**¿Puedo abrir un archivo PDF o HTML como una presentación?**  

No. El constructor de Presentación lanza una excepción `PptUnsupportedFormatException` para un archivo PDF y no convierte el marcado HTML en diapositivas. Cree o abra una presentación, importe las páginas PDF o el contenido HTML en ella mediante los métodos de la colección de diapositivas descritos anteriormente y, a continuación, guárdela en cualquier formato admitido.

**¿Puedo cargar una imagen exportada PNG o SVG como una presentación editable?**  

No. La salida de imagen solo registra la apariencia de una diapositiva, no su texto, formas ni gráficos. Mantenga la presentación original si necesita editarla más adelante.

**¿Puedo guardar documentos PDF/A o PDF/UA?**  

Sí. Pase un valor <a href="https://reference.aspose.com/slides/java/com.aspose.slides/pdfcompliance/" target="_blank" rel="nofollow noopener noreferrer">PdfCompliance</a> a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/pdfoptions/#setCompliance-int-" target="_blank" rel="nofollow noopener noreferrer">PdfOptions.setCompliance</a>: PDF/A-1a, PDF/A-1b, PDF/A-2a, PDF/A-2b, PDF/A-2u, PDF/A-3a, PDF/A-3b o PDF/UA.

**¿Puedo comprobar si un archivo está protegido con contraseña antes de abrirlo?**  

Sí. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> inspecciona un archivo sin crear un objeto Presentation, y <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#isPasswordProtected--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.isPasswordProtected</a> indica si se requiere contraseña. Consulte [Proteger presentaciones con contraseña](/java/slides/password-protected-presentation/).

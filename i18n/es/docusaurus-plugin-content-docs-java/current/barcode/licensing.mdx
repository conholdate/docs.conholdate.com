## Información general {#overview}
  
El modo de evaluación de ***Aspose.BarCode para Java*** permite generar imágenes de códigos de barras sin restricciones. Sin embargo, aparecerá una marca de agua en la imagen resultante del código de barras (las palabras «Aspose»). La versión sin licencia puede utilizarse para leer códigos de barras de todos los tipos admitidos. Tenga en cuenta que únicamente *Code 39* puede decodificarse sin limitaciones; como consecuencia de la lectura de códigos de barras correspondientes a otros tipos, el 30 % del texto decodificado se enmascarará con « \* ». Todas las demás acciones con códigos de barras mediante ***Aspose.BarCode para Java*** requieren la configuración de una licencia. Tras adquirir una licencia, obtendrá acceso a toda la funcionalidad de la biblioteca y la capacidad de realizar la generación y lectura de códigos de barras sin limitaciones ni la colocación de marcas de agua.

## Cómo instalar la licencia {#how-to-install-license}
  
La licencia es un archivo XML de texto simple que incluye detalles como el nombre del producto, el número de desarrolladores para los que está licenciado, la fecha de caducidad de la suscripción y otros datos. El archivo de licencia está firmado digitalmente, por lo que no debe modificarse de ninguna manera. Incluso añadir un salto de línea adicional en el archivo de licencia invalidará la misma. Debe activar la licencia para habilitar el uso ilimitado de las funciones de la biblioteca. Solo es necesario activar la licencia una vez por aplicación (o proceso).

La licencia puede cargarse desde un flujo o un archivo. Debe llamar al método *setLicense* de la clase <a href="https://reference.aspose.com/barcode//java/com.aspose.barcode/license" target="_blank" rel="nofollow noopener noreferrer">*License*</a> para aplicar la licencia al componente.

### Uso de Singleton para la inicialización de la licencia {#using-singleton-for-license-initialization}
  
La forma más eficaz de implementar la licencia es mediante la inicialización diferida utilizando el patrón Singleton en su código. A continuación, mostramos cómo lograrlo con solo unas pocas líneas adicionales de código en su proyecto.

```java
public class LicenseSingleton
{
    private static LicenseSingleton instance;
    private LicenseSingleton(String pathToLicenseFile)
    {
      try
      {
      // Initialize the license
       com.aspose.barcode.License license = new com.aspose.barcode.License();
       license.setLicense(pathToLicenseFile);
      }
      catch (Exception e)
      {
        e.printStackTrace();
      }
    } 
}

public static synchronized void setLicense()
{
    if (instance == null)
    {
      instance = new LicenseSingleton(pathToLicenseFile);
    }
}
```

Ahora puedes inicializar la licencia en tu código simplemente llamando a `LicenseSingleton.setLicense()`:

```java
LicenseSingleton.setLicense();
BarCodeReader reader = new BarCodeReader(path, DecodeType.CODE_39_FULL_ASCII);
for (BarCodeResult result : reader.readBarCodes())
{
  System.out.printf("CodeText: %s%n", result.getCodeText());;
  System.out.printf("CodeType: %s%n", result.getCodeType());;
}
```

### Instalar licencia desde archivo  {#install-license-from-file}

```java
com.aspose.barcode.License license = new com.aspose.barcode.License();
license.setLicense(pathToLicenseFile);
```

o

```java
com.aspose.barcode.License license = new License();
license.setLicense(new File(pathToLicenseFile));
```

### Instalar licencia desde Stream {#install-license-from-stream}

```java
License license = new License();
Path filePath = Paths.get(pathToLicenseFile);
try (InputStream inputStream = Files.newInputStream(filePath))
{
  license.setLicense(inputStream);
}
catch (IOException e)
{
  e.printStackTrace();
}
```

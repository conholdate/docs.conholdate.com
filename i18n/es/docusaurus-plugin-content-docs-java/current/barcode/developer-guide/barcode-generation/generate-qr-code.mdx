<a id="generate-qr-codes"></a>

El código QR es una simbología bidimensional adecuada para URLs, identificadores, información de contacto, configuración de Wi-Fi y texto multilingüe. Aspose.BarCode para Java admite la generación de códigos QR estándar y Micro QR Code, niveles de corrección de errores, codificación ECI, dimensionado de módulos y personalización visual.

El código fuente completo de los ejemplos de este artículo está disponible en GitHub:

<a href="https://github.com/aspose-barcode/Aspose.BarCode-for-Java/blob/master/src/test/java/com/aspose/barcode/guide/generation/GenerateQRCode.java" target="_blank" rel="nofollow noopener noreferrer">Ver GenerateQRCode.java</a>

## Generar un código QR básico {#generate-a-basic-qr-code}
  
Crear un `BarcodeGenerator` con `EncodeTypes.QR`, proporcionar el texto del código y guardar la imagen.

```java
String codeText = "https://www.aspose.com";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.save("qrcode.png", BarCodeImageFormat.PNG);
```

Los parámetros de generación predeterminados son suficientes para un código QR básico.

## Configurar la corrección de errores {#configure-error-correction}
  
Los códigos QR admiten varios niveles de corrección de errores. Los niveles más altos permiten restaurar más módulos dañados, pero aumentan el tamaño del símbolo para los mismos datos.

```java
String codeText = "Data with error correction";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setErrorLevel(QRErrorLevel.LEVEL_H);

generator.save("qrcode_error_correction.png", BarCodeImageFormat.PNG);
```

Los niveles disponibles son:

- `LEVEL_L` – aproximadamente 7 % de recuperación;  
- `LEVEL_M` – aproximadamente 15 % de recuperación;  
- `LEVEL_Q` – aproximadamente 25 % de recuperación;  
- `LEVEL_H` – aproximadamente 30 % de recuperación.

Elija un nivel superior cuando el símbolo pueda rayarse, ocultarse o imprimirse en condiciones difíciles.

Las combinaciones disponibles de corrección de errores dependen de la variante y versión del código QR seleccionada. Micro QR admite menos combinaciones que el código QR estándar.

## Establecer el tamaño del módulo del código QR  {#set-qr-code-module-size}
  
Para los códigos QR, la dimensión X define el ancho y la altura de un módulo.

```java
String codeText = "Set QR size";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.getParameters().getBarcode().getXDimension().setPixels(4);
generator.getParameters().setResolution(300.0f);

generator.save("qrcode_sized.png", BarCodeImageFormat.PNG);
```

Aumentar la dimensión X amplía cada módulo y, por lo tanto, la imagen completa del código QR.

En este ejemplo, la dimensión X se especifica directamente en píxeles. El valor de resolución es principalmente relevante cuando las dimensiones del código de barras se especifican en unidades físicas, como milímetros, pulgadas o puntos. Establecer una resolución más alta no aumenta por sí sola una dimensión X que ya está definida en píxeles.

## Codificar texto Unicode con ECI {#encode-unicode-text-with-eci}
  
Utilice el modo ECI y UTF-8 cuando el texto del código contenga caracteres fuera de la codificación predeterminada.

```java
String codeText = "データ";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setEncodeMode(QREncodeMode.ECI);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setECIEncoding(ECIEncodings.UTF8);

generator.save("qrcode_utf8.png", BarCodeImageFormat.PNG);
```

La aplicación de lectura debe admitir la codificación ECI seleccionada para reconstruir el texto original correctamente.

La codificación ECI es compatible con el código QR estándar, pero no es compatible con el código Micro QR.

## Configurar un código QR completo {#configure-a-complete-qr-code}
  
El siguiente ejemplo combina el tamaño del módulo, la corrección de errores, la codificación ECI en UTF-8, los colores y un margen en blanco de cuatro módulos alrededor del símbolo.

```java
String codeText = "Aspose QR — データ";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.getParameters().getBarcode().getXDimension().setPixels(4);
generator.getParameters().setResolution(300.0f);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setErrorLevel(QRErrorLevel.LEVEL_M);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setEncodeMode(QREncodeMode.ECI);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setECIEncoding(ECIEncodings.UTF8);

generator.getParameters().setBackColor(java.awt.Color.WHITE);
generator.getParameters().getBarcode().setBarColor(java.awt.Color.BLACK);

// X-Dimension is 4 px, so 16 px reserves a four-module margin.
generator.getParameters().getBarcode().getPadding().getLeft().setPixels(16);
generator.getParameters().getBarcode().getPadding().getRight().setPixels(16);
generator.getParameters().getBarcode().getPadding().getTop().setPixels(16);
generator.getParameters().getBarcode().getPadding().getBottom().setPixels(16);

generator.save("qrcode_complete.png", BarCodeImageFormat.PNG);
```

Se recomienda un alto contraste entre los módulos y el fondo para un reconocimiento fiable. El margen en blanco requerido debe calcularse a partir del tamaño del módulo, en lugar de tratarse como un valor universal en píxeles.

## Generar un código Micro QR {#generate-a-micro-qr-code}
  
El código Micro QR es una variante compacta del código QR, diseñada para datos más cortos.

```java
String codeText = "MicroQR1234567";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.MICRO_QR,
        codeText
);

generator.getParameters().getBarcode().getXDimension().setPixels(4);
generator.save("micro_qr_basic.png", BarCodeImageFormat.PNG);
```

Use el código QR estándar para cargas útiles más grandes y una compatibilidad amplia. Utilice Micro QR cuando los datos sean breves y el área disponible esté limitada.

Micro QR no admite todas las características y combinaciones del código QR estándar. En particular, el modo ECI no es compatible.

## Codificar una URL {#encode-a-url}

```java
String codeText = "https://docs.aspose.com/";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        codeText
);

generator.save("url_qrcode.png", BarCodeImageFormat.PNG);
```

Los datos codificados son texto plano. La aplicación de escaneo determina si abrirlos como una URL.

## Comparar QR estándar y Micro QR {#compare-standard-qr-and-micro-qr}

```java
String standardQrText = "https://example.com/product/12345";
BarcodeGenerator standardQrGenerator = new BarcodeGenerator(
        EncodeTypes.QR,
        standardQrText
);
standardQrGenerator.save("standard_qr.png", BarCodeImageFormat.PNG);

String microQrText = "ID-12345";
BarcodeGenerator microQrGenerator = new BarcodeGenerator(
        EncodeTypes.MICRO_QR,
        microQrText
);
microQrGenerator.save("micro_qr_comparison.png", BarCodeImageFormat.PNG);
```

Las dos variantes difieren en capacidad, estructura de símbolos y configuraciones admitidas.

## Codificar un vCard {#encode-a-vcard}
  
Un código QR puede contener una representación en texto de un vCard. Este ejemplo utiliza un nombre de contacto en Unicode, por lo que la configuración ECI en UTF-8 tiene sentido.

```java
String vcard = "BEGIN:VCARD\n"
        + "VERSION:3.0\n"
        + "FN:山田 太郎\n"
        + "TEL:+81-3-1234-5678\n"
        + "EMAIL:taro@example.com\n"
        + "END:VCARD";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        vcard
);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setEncodeMode(QREncodeMode.ECI);

generator.getParameters()
        .getBarcode()
        .getQR()
        .setECIEncoding(ECIEncodings.UTF8);

generator.save("vcard_qrcode.png", BarCodeImageFormat.PNG);
```

La aplicación de contactos en el dispositivo de escaneo interpreta la estructura vCard.

## Codificar la configuración de Wi-Fi {#encode-wi-fi-configuration}
  
La configuración de Wi-Fi se codifica como una cadena de texto con formato.

```java
String wifi = "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;";

BarcodeGenerator generator = new BarcodeGenerator(
        EncodeTypes.QR,
        wifi
);

generator.save("wifi_qrcode.png", BarCodeImageFormat.PNG);
```

Tenga en cuenta que la contraseña de Wi-Fi se almacena directamente en la carga útil del código QR.

## Recomendaciones {#recommendations}

- Utilice una combinación de colores de alto contraste.
- Reservar suficiente espacio en blanco alrededor del código QR según el tamaño de módulo seleccionado.
- Seleccione la corrección de errores según el daño esperado y el área disponible del símbolo.
- Utilice ECI en UTF-8 para texto multilingüe cuando la interoperabilidad requiera una codificación explícita.
- No utilice el modo ECI con Micro QR.
- Utilice Micro QR únicamente cuando su capacidad más reducida y el conjunto de funciones admitidas sean suficientes.
- Pruebe las URL, las vCards y las cadenas de Wi-Fi con las aplicaciones de escaneo objetivo.

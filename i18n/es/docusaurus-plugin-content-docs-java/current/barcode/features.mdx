## Características de Aspose.BarCode para Java {#features-of-asposebarcode-for-java}
  
### 🧾 Generación de códigos de barras {#-barcode-generation}
  
- Generar códigos de barras en más de **80 simbologías**, incluidos tipos estándar **1D** y **2D**, así como formatos **postales especializados** como **Royal Mail Mailmark** y **Australia Post**  
- Personalizar la **apariencia del código de barras**: tamaño, rotación, resolución, colores, leyendas, márgenes, **altura de las barras**, **dimensión X**, y más  
- Soporte para **corrección de errores** (**ECC**, **ECI**) y **controles de suma de verificación**  
- Exportar códigos de barras a formatos **raster y vectoriales** populares: **JPEG**, **PNG**, **BMP**, **GIF**, **TIFF**, **EMF**, **SVG**  
- Generar **tipos complejos de códigos de barras** y aplicar **datos suplementarios**  

### 🔍 Reconocimiento de códigos de barras {#-barcode-recognition}
  
- Reconocer códigos de barras desde **imágenes raster y vectoriales**  
- Leer códigos de barras en **cualquier ángulo**, incluso en imágenes **dañadas** o **ruidosas**  
- Definir **tipos de códigos de barras objetivo** y **regiones de detección** para un procesamiento optimizado  
- Utilizar **reconocimiento multiproceso** para mejorar la velocidad  
- Validar **sumas de verificación** (para **códigos de barras 1D** y **postales**)  
- Ajustar el **motor de reconocimiento** mediante **configuraciones manuales** o **preajustes integrados**  

### 🛠 Opciones de procesamiento de imágenes y salida {#-imaging-and-output-options}
  
- Personalizar **bordes de la imagen**, **colores**, **márgenes**, **calidad** y **resolución**  
- Soporte para **anti-aliasing**, **ajuste automático de tamaño** y **rotación del código de barras**  
- Soporte completo para **Unicode** en codificación/decodificación multilingüe  
- Cargar y guardar códigos de barras mediante **flujos** o **archivos**

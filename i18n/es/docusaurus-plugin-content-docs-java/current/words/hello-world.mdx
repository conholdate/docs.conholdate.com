Un código de "¡Hola, Mundo!" suele ser el primer ejemplo sencillo que se escribe utilizando "Aspose.Words for Java", y también puede utilizarse como una prueba de integridad para asegurarse de que el software destinado a compilar o ejecutar el código fuente esté instalado correctamente.

La biblioteca "Aspose.Words for Java" proporciona a los desarrolladores acceso directo para crear, modificar, fusionar, convertir y comparar documentos de Word y web. Los formatos de archivo PDF, DOCX, DOC, RTF, ODT, EPUB, HTML y muchos otros están [soportados](/java/words/supported-document-formats/).

El fragmento de código siguiente sigue estos pasos:

1. Crear un nuevo <a href="https://reference.aspose.com/words/java/com.aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> vacío  
2. Inicializar la clase <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a>  
3. Insertar texto al inicio del documento mediante el método sencillo <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/#write-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Write</a>  
4. Abrir un <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#Document-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Document</a> existente desde un archivo. Detecta automáticamente el formato del archivo  
5. <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#appendDocument-com.aspose.words.Document-int" target="_blank" rel="nofollow noopener noreferrer">Append</a> el documento "A" al final del documento "B"  
6. <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#save-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Save</a> la salida como PDF  

El siguiente fragmento de código es un ejemplo de "¡Hola, Mundo!" que muestra el funcionamiento de la API de "Aspose.Words for Java":

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document docA = new Document();
DocumentBuilder builder = new DocumentBuilder(docA);

// Insert text to the document start.
builder.moveToDocumentStart();
builder.write("First Hello World paragraph");

Document docB = new Document(getMyDir() + "Document.docx");
// Add document B to the and of document A, preserving document B formatting.
docA.appendDocument(docB, ImportFormatMode.KEEP_SOURCE_FORMATTING);

docA.save(getArtifactsDir() + "HelloWorld.SimpleHelloWorld.pdf");
```

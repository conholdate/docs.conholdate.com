## Prueba Gratuita o Licencia Temporal {#free-trial-or-temporary-license}
  
Aspose.Words es un software increíble que los desarrolladores pueden probar antes de adquirirlo. Puede descargar e instalar fácilmente Aspose.Words para Java y Aspose.Words para Android mediante Java <a href="https://releases.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">desde Maven</a> para evaluarlo.

### Prueba Gratuita {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida; la versión de prueba simplemente se convierte en una versión con licencia al agregar unas pocas líneas de código para aplicar la licencia.

La versión de prueba de Aspose.Words para Java y Aspose.Words para Android mediante Java, sin la licencia especificada, proporciona todas las funcionalidades del producto, pero inserta una marca de agua de evaluación en la parte superior del documento al cargarlo y guardarlo, y limita el tamaño máximo del documento a unos pocos cientos de párrafos.

### Licencia Temporal {#temporary-license}
  
Si desea probar Aspose.Words para Java y Aspose.Words para Android mediante Java sin las limitaciones de la versión de prueba, también puede solicitar una Licencia Temporal de 30 días. Para obtener más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">Obtener una Licencia Temporal</a>.

The file is digitally signed, so do not modify the file. Even inadvertent addition of an extra line break into the file will invalidate it.

### Opciones de aplicación de licencia {#license-applying-options}
  
Las licencias pueden aplicarse desde varias ubicaciones:

- Ruta explícita  
- La carpeta que contiene el archivo *Aspose.Words JAR*  
- Un recurso incrustado dentro del JAR denominado *Aspose.Words JAR*  
- Como licencia basada en medición (Metered License): un nuevo mecanismo de licenciamiento  

Con frecuencia, la forma más sencilla de configurar una licencia consiste en colocar el archivo de licencia en la misma carpeta que *Aspose.Words JAR* y especificar únicamente el nombre del archivo, sin incluir la ruta.

```

Use the [SetLicense](https://reference.aspose.com/words/java/com.aspose.words/license/#setLicense-java.io.InputStream) method to license a component.

Calling **SetLicense** multiple times is not harmful, it just wastes processor time.

Calling [SetMeteredKey](https://reference.aspose.com/words/java/com.aspose.words/metered/#setMeteredKey-java.lang.String-java.lang.String) multiple times is not harmful either, but just wastes processor time and can accumulate consumption improperly.

```

#### Aplicar licencia mediante un archivo o un objeto de flujo  {#apply-license-using-a-file-or-stream-object}

```

Call **SetLicense** in your startup code before using Aspose.Words classes.

```

Al desarrollar una biblioteca de clases, puede llamar a **SetLicense** desde el constructor estático de su clase que utiliza Aspose.Words. El constructor estático se ejecutará antes de instanciar su clase, lo que garantiza que la licencia de Aspose.Words se instale correctamente.

##### Cargar una licencia desde un archivo  {#load-a-license-from-a-file}
  
Mediante el método <a href="https://reference.aspose.com/words/java/com.aspose.words/license/#setLicense-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>, puede intentar localizar el archivo de licencia en los recursos incrustados o en la carpeta que contiene los JAR de su aplicación, para su posterior uso.

El siguiente ejemplo de código muestra cómo inicializar una licencia desde una carpeta:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
License license = new License();

// This line attempts to set a license from several locations relative to the executable and Aspose.Words.dll.
// You can also use the additional overload to load a license from a stream, this is useful,
// for instance, when the license is stored as an embedded resource.
try
{
    license.setLicense("Aspose.Words.lic");
    
    System.out.println("License set successfully.");
}
catch (Exception e)
{
    // We do not ship any license with this example,
    // visit the Aspose site to obtain either a temporary or permanent license. 
    System.out.println("\nThere was an error setting the license: " + e.getMessage());
}
```

##### Cargar una licencia desde un objeto `Stream`  {#load-a-license-from-a-stream-object}
  
El siguiente ejemplo de código muestra cómo inicializar una licencia desde un flujo utilizando otro método <a href="https://reference.aspose.com/words/java/com.aspose.words/license/#setLicense-java.io.InputStream" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
License license = new License();

try
{
    license.setLicense(new FileInputStream(new File("Aspose.Words.lic")));
    
    System.out.println("License set successfully.");
}
catch (Exception e)
{
    // We do not ship any license with this example,
    // visit the Aspose site to obtain either a temporary or permanent license. 
    System.out.println("\nThere was an error setting the license: " + e.getMessage());
}
```

#### Incluir el archivo de licencia como un recurso incrustado {#include-the-license-file-as-an-embedded-resource}
  
Una forma elegante de empaquetar una licencia con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado. Simplemente puede copiar el archivo .lic en la carpeta de recursos de su proyecto.

Al reconstruir el proyecto, el archivo .lic se incrustará en el archivo .jar de la aplicación. Después de eso, puede solicitar una licencia utilizando el siguiente código:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
License license = new License();

try
{
    license.setLicense(ApplyLicense.class.getResourceAsStream("Aspose.Words.lic"));

    System.out.println("License set successfully.");
}
catch (Exception e)
{
    // We do not ship any license with this example,
    // visit the Aspose site to obtain either a temporary or permanent license.
    System.out.println("\nThere was an error setting the license: " + e.getMessage());
}
```

#### Aplicar licencia por uso (Metered) {#apply-metered-license}
  
Aspose.Words permite a los desarrolladores aplicar una clave por uso (metered). Se trata de un nuevo mecanismo de licenciamiento.

Este nuevo mecanismo de licenciamiento se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por uso (Metered Licensing).

Tras completar todos los pasos necesarios para obtener este tipo de licencia, recibirás las claves, no el archivo de licencia. Esta clave por uso puede aplicarse mediante la clase <a href="https://reference.aspose.com/words/java/com.aspose.words/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a>, específicamente introducida para este propósito.

No llames al método **SetMeteredKey** con frecuencia, para que este método de licenciamiento pueda acumular correctamente el consumo y reportarlo a nosotros. Simplemente instancia la biblioteca Aspose.Words, llama una sola vez a **SetMeteredKey**, y luego deja la biblioteca instanciada y reutilízala.

El siguiente ejemplo de código muestra cómo establecer las claves públicas y privadas por uso (metered):

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
try
{
    Metered metered = new Metered();
    metered.setMeteredKey("*****", "*****");

    Document doc = new Document(getMyDir() + "Document.docx");

    System.out.println(doc.getPageCount());
}
catch (Exception e)
{
    System.out.println("\nThere was an error setting the license: " + e.getMessage());
}
```

Normalmente, basta con aplicar la licencia medida una sola vez al iniciar la aplicación. Sin embargo, si el mecanismo de licencia medida no logra comunicarse con los servidores de Aspose durante 24 horas, Aspose.Words saldrá del modo con licencia y pasará al modo de evaluación. Para evitar este caso, puede utilizar el método <a href="https://reference.aspose.com/words/java/com.aspose.words/metered/#isMeteredLicensed" target="_blank" rel="nofollow noopener noreferrer">IsMeteredLicensed</a> para verificar el estado de la licencia y volver a aplicar la licencia medida si es necesario.

```

Please note that you must have a stable Internet connection for the correct use of the Metered license, since the Metered mechanism requires the constant interaction with our services for correct calculations.

For more details, refer to the [Metered Licensing FAQ](https://purchase.aspose.com/faqs/licensing/metered/) section.

```

### Cambiar el nombre del archivo de licencia  {#changing-the-license-file-name}
  
El nombre del archivo de licencia no tiene por qué ser «Aspose.Words.LIC». Puede renombrarlo según su preferencia y utilizar ese nombre al configurar la licencia en su aplicación.

### Excepción «No se puede encontrar el nombre del archivo de licencia»  {#cannot-find-license-filename-exception}
  
Cuando adquiere y descarga una licencia, el sitio web de Aspose denomina al archivo de licencia *«Aspose.Words.LIC»*. Descarga el archivo de licencia mediante su navegador. En este caso, algunos navegadores reconocen el archivo de licencia como XML y le agregan la extensión .xml, por lo que el nombre completo del archivo en su ordenador se convierte en *«Aspose.Words.lic.XML»*.

Cuando Microsoft Windows está configurado para ocultar las extensiones de los tipos de archivo conocidos (por desgracia, esta es la configuración predeterminada en la mayoría de las instalaciones de Windows), el archivo de licencia aparecerá como *«Aspose.Words. LIC»* en el Explorador de Windows. Probablemente creerá que este es el nombre real del archivo e invocará **SetLicense** pasándole *«Aspose.Words.LIC»*, pero dicho archivo no existe, por lo que se generará la excepción.

Para solucionar este problema, renombre el archivo eliminando la extensión invisible .xml. Asimismo, le recomendamos desactivar la opción «ocultar extensiones» en Microsoft Windows.

## Uso de varios productos de Aspose  {#using-multiple-aspose-products}
  
Si utiliza varios productos de Aspose en su aplicación, como Aspose.Words y `Aspose.Cells`, le ofrecemos algunos consejos útiles:

- Configure la licencia para cada producto de Aspose por separado. Incluso si dispone de un único archivo de licencia para todos los componentes, por ejemplo, «Aspose.Total.lic», sigue siendo necesario invocar **SetLicense** por separado para cada producto de Aspose que utilice en su aplicación.
- Utilice el nombre completo de la clase License. Cada producto de Aspose dispone de una clase `License` en su propio espacio de nombres. Por ejemplo, Aspose.Words tiene la clase **com.aspose.words.License**, y `Aspose.Cells` tiene la clase com.aspose.cells.License. El uso del nombre completo de la clase le permite evitar confusiones sobre qué licencia corresponde a cada producto.

Aspose.Words ofrece a los usuarios una amplia gama de funcionalidades. Los usuarios pueden realizar una gran cantidad de tareas relacionadas con documentos: desde la simple conversión de documentos de un formato admitido a otro y la modificación de dichos documentos durante el proceso de conversión, hasta tareas empresariales, como la creación de documentos estructurados y visualmente atractivos o la automatización de informes.

Los formatos y estándares de documentos modernos son complejos, y cuando se requieren funcionalidades de conversión de documentos u otras características de procesamiento de documentos en un proyecto, la única solución práctica suele ser recurrir a un componente de terceros que implemente la funcionalidad deseada. Sin embargo, el uso de un componente de terceros siempre conlleva cierto riesgo. Uno de los riesgos únicos en el procesamiento de documentos es la cuestión de qué tan completa y correcta es la implementación de un formato o estándar de documento específico por parte de la biblioteca.

Aspose se compromete a ofrecer las implementaciones más completas y precisas de formatos y estándares de documentos. El equipo de Aspose.Words demuestra su compromiso con la interoperabilidad al proporcionar notas detalladas de implementación para los formatos de documentos admitidos en múltiples plataformas.

Las tablas siguientes resumen las funcionalidades de Aspose.Words para Java y proporcionan enlaces a descripciones detalladas de las características.

## Características de informes  {#reporting-features}
  
El motor de informes LINQ es una herramienta avanzada de generación de informes que le permite crear documentos basados en plantillas y en datos obtenidos de diversas fuentes, incluidas bases de datos, XML, JSON, OData, objetos de tipos CLR personalizados, documentos externos y más, todo ello listo para usar.

<div className="docs-owner-markdown-table">

| Características clave |
| :------------------------------------------------------------------------------------------------------------------------- |
| Soporte de la sintaxis de C# y métodos de extensión LINQ directamente en plantillas (incluso para orígenes de datos `ADO.NET`) |
| Soporte de bloques de documentos repetibles y condicionales (bucles y condiciones) para tablas, listas y contenido general |
| Soporte de gráficos e imágenes generados dinámicamente |
| Soporte de inserción de documentos externos y bloques HTML dentro de un documento |
| Soporte de múltiples orígenes de datos (incluidos de distintos tipos) para la generación de un único documento |
| Soporte integrado de relaciones de datos (maestro-detalle) |
| Soporte exhaustivo de diversas manipulaciones de datos, como agrupación, ordenación, filtrado y otras, directamente en las plantillas |
| WYSIWYG: Un documento generado conserva el mismo formato de sus elementos que tiene la plantilla correspondiente |

</div>

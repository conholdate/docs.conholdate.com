Aspose.OCR para Java es un producto con licencia comercial que puede utilizarse en modo de prueba (evaluación).

## Prueba gratuita {#free-trial}
  
Puede comenzar a utilizar Aspose.OCR para Java inmediatamente tras la [instalación](/java/ocr/installation/). En modo de prueba (sin proporcionar una licencia), puede reconocer texto en cualquier [idioma](/java/ocr/recognition-languages/) admitido y guardar los resultados del reconocimiento en cualquiera de los [formatos](/java/ocr/supported-file-formats/) admitidos.

Sin embargo, se aplican las siguientes restricciones:

- Si el número de caracteres en una imagen reconocida supera los 300, solo se reconocen los primeros **300** caracteres.
- Si el número de caracteres en una imagen reconocida es inferior a 300, se reconocen el **60 %** inicial de los caracteres.

Para eliminar esta restricción, aplique una licencia.

## Obtención de una licencia temporal {#getting-a-temporary-license}
  
Una licencia temporal elimina la limitación de la versión de prueba durante **30 días**. Utilícela para comenzar a desarrollar una aplicación OCR totalmente funcional y tomar la decisión final de <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquirir</a> Aspose.OCR para Java más adelante.

Para solicitar una licencia temporal, visite la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">"Obtener una licencia temporal"</a>.

## Adquisición de una licencia {#purchasing-a-license}
  
Aspose.OCR para Java se licencia según el número de desarrolladores y ubicaciones (sitios) donde se utilizarán los productos (*licencias de desarrollador* y *licencias de sitio*) o según el uso por demanda (*licencias medibles*).

Consulte <a href="https://purchase.conholdate.com/policies/license-types" target="_blank">Tipos de licencia</a> para obtener detalles y <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquiera una licencia</a> que se ajuste mejor a sus necesidades.

## Aplicación de una licencia de desarrollador o de sitio {#applying-a-developer-or-site-license}
  
Tras adquirir una licencia u obtener una licencia temporal, recibirá un archivo con la extensión *.lic*. Si lo desea, puede renombrar este archivo y cambiar su extensión.

:::info
Mantenga los tokens de marcador de posición que aparecen en la entrada exactamente sin modificar.  
No agregue tokens de marcador de posición que no estén ya presentes en la entrada.  
Mantenga las tuberías y el recuento de filas de la tabla de Markdown sin modificar.  

No modifique el contenido del archivo de licencia. Incluso un salto de línea o un espacio adicional invalidará la licencia.
:::

La licencia debe aplicarse una vez por aplicación o ciclo de vida del proceso antes de que comience el reconocimiento.

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
Coloque el archivo de licencia en una carpeta de su computadora e inserte el siguiente código en su método de inicio:

```java
// Initialize the licensing component
com.aspose.ocr.License license = new com.aspose.ocr.License();

// Load the license from file
license.SetLicense("Aspose_OCR_License_File.lic");
```

Si solo se especifica el nombre del archivo de licencia (sin la ruta), el método `SetLicense` buscará el archivo de licencia en las siguientes ubicaciones:

- la carpeta que contiene Aspose.OCR.jar;
- la carpeta que contiene los archivos JAR de su aplicación.

Alternativamente, puede almacenar el archivo de licencia en cualquier carpeta de su computadora y especificar una ruta absoluta o relativa. Si prefiere cargar la licencia desde una ruta explícita, proporcione la ruta completa en el método `SetLicense`.

### Carga de una licencia desde un flujo  {#loading-a-license-from-stream}
  
Inserte el siguiente código en su método de inicio:

```java
// Initialize the licensing component
com.aspose.ocr.License license = new com.aspose.ocr.License();

// Load the license from stream
license.setLicense(new java.io.FileInputStream("Aspose_OCR_License_File.lic"));
```

## Aplicar una licencia medible {#applying-a-metered-license}
  
Cuando adquiera una licencia medible, recibirá un par de claves pública/privada en lugar de un archivo de licencia. Utilice el siguiente código en su método de inicio para aplicar las claves de licencia:

```java
// License key pair
String publicKey = "PUBLIC-LICENSE-KEY";
String privateKey = "PRIVATE-LICENSE-KEY";

// Initialize the metered license
Metered meteredLicense = new com.aspose.ocr.metered.Metered();
meteredLicense.setMeteredKey(publicKey, privateKey);
```

Su uso se registrará localmente y se informará periódicamente a los servidores de Aspose. Se le facturará mensualmente según lo que utilice. Este mecanismo de licencia requiere que el equipo que ejecute la aplicación de OCR tenga una conexión a Internet estable y que la aplicación no esté bloqueada por un firewall.

Lea <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en medición</a> para obtener detalles técnicos y comerciales detallados.

## Validación de la licencia {#validating-the-license}
  
Para verificar el estado actual de la licencia limitada en el tiempo (basada en archivo):

```java
// Initialize the licensing component
com.aspose.ocr.License license = new com.aspose.ocr.License();

// Load the license from file
license.SetLicense("Aspose_OCR_License_File.lic");

// Validate the license
if(License.isValid()) {
    System.out.println("The license is valid!");
} else {
    System.out.println("The license is invalid!");
}
```

Para verificar el uso de la licencia basada en medición:

```java
// License key pair
String publicKey = "PUBLIC-LICENSE-KEY";
String privateKey = "PRIVATE-LICENSE-KEY";

// Initialize the metered license
Metered meteredLicense = new com.aspose.ocr.metered.Metered();
meteredLicense.setMeteredKey(publicKey, privateKey);

// Remaining license limit
double remainingCalls = meteredLicense.getConsumptionCredit() - meteredLicense.getConsumptionQuantity();
```

## Licencia para múltiples productos de Aspose {#licensing-multiple-aspose-products}
  
Incluso si posee una única licencia para todos los productos de Aspose (como <a href="https://products.aspose.com/total/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Total for Java</a>), aún debe aplicar la licencia por separado a **cada** producto de Aspose que utilice en su aplicación.

Cada producto de Aspose incluye una clase `License` en su espacio de nombres. Al aplicar licencias a cada producto, utilice el nombre completo de la clase `License` para evitar ambigüedades. Por ejemplo:

```java
// Aspose.OCR
com.aspose.ocr.License ocrLicense = new com.aspose.ocr.License();
ocrLicense.SetLicense("Aspose_OCR_License_File.lic");

// Aspose.BarCode
com.aspose.barcode.License barcodeLicense = new com.aspose.barcode.License();
barcodeLicense.SetLicense("Aspose_BarCode_License_File.lic");
```

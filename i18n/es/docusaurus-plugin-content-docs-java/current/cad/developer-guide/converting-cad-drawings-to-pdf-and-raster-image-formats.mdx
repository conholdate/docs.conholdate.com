## Conversión de dibujos CAD a formatos de imagen rasterizada {#converting-cad-drawings-to-raster-image-formats}
  
Aspose.CAD para Java permite convertir formatos de dibujo CAD, como <a href="https://docs.fileformat.com/cad/dxf/" target="_blank" rel="nofollow noopener noreferrer">**DXF**</a> y <a href="https://docs.fileformat.com/cad/dwg/" target="_blank" rel="nofollow noopener noreferrer">**DWG**</a>, a formatos de imagen rasterizada compatibles, tales como <a href="https://docs.fileformat.com/image/png/" target="_blank" rel="nofollow noopener noreferrer">**PNG**</a>, <a href="https://docs.fileformat.com/image/bmp/" target="_blank" rel="nofollow noopener noreferrer">**BMP**</a>, <a href="https://docs.fileformat.com/image/tiff/" target="_blank" rel="nofollow noopener noreferrer">**TIFF**</a>, <a href="https://docs.fileformat.com/image/jpeg/" target="_blank" rel="nofollow noopener noreferrer">**JPEG**</a> y <a href="https://docs.fileformat.com/image/gif/" target="_blank" rel="nofollow noopener noreferrer">**GIF**</a>. La API de Aspose.CAD para Java proporciona medios eficientes y fáciles de usar para lograr este objetivo. Puede convertir cualquier formato de dibujo CAD compatible a formatos de imagen rasterizada siguiendo los sencillos pasos que se detallan a continuación.

1. Cargue el archivo CAD en una instancia de <a href="https://reference.aspose.com/cad/java/com.aspose.cad/Image" target="_blank" rel="nofollow noopener noreferrer">**Image**</a>.  
2. Cree una instancia de <a href="https://reference.aspose.com/cad/java/com.aspose.cad.imageoptions/CadRasterizationOptions" target="_blank" rel="nofollow noopener noreferrer">**CadRasterizationOptions**</a> y configure sus propiedades obligatorias, como <a href="https://reference.aspose.com/cad/java/com.aspose.cad.imageoptions/VectorRasterizationOptions#setPageWidth-float-" target="_blank" rel="nofollow noopener noreferrer">**PageWidth**</a> y <a href="https://reference.aspose.com/cad/java/com.aspose.cad.imageoptions/VectorRasterizationOptions#setPageHeight-float-" target="_blank" rel="nofollow noopener noreferrer">**PageHeight**</a>.  
3. Cree una instancia de **ImageOptionsBase** y configure su propiedad <a href="https://reference.aspose.com/cad/java/com.aspose.cad.imageoptions/VectorRasterizationOptions" target="_blank" rel="nofollow noopener noreferrer">**VectorRasterizationOptions**</a> con la instancia de **CadRasterizationOptions** creada en el paso anterior.  
4. Llame a **Image.save**, pasando la ruta del archivo (o un objeto de tipo MemoryStream), así como la instancia de <a href="https://reference.aspose.com/cad/java/com.aspose.cad.class-use/ImageOptionsBase" target="_blank" rel="nofollow noopener noreferrer">**ImageOptionsBase**</a> creada en el paso anterior.  

A continuación se muestra el código fuente completo.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		Image image = Image.load(srcFile); 
	    
		// Create an instance of CadRasterizationOptions
	    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
	    // Set page width & height
	    rasterizationOptions.setPageWidth(1200);
	    rasterizationOptions.setPageHeight(1200);

	    // Create an instance of PngOptions for the resultant image
	    ImageOptionsBase options = new PngOptions();
	    //Set rasterization options
	    options.setVectorRasterizationOptions(rasterizationOptions);

	    // Save resultant image
	    image.save(dataDir + "conic_pyramid_raster_image_out_.png", options);
```

De forma predeterminada, la API solo representa el diseño «Model». Sin embargo, también puede especificar los diseños de su elección al convertir dibujos CAD a formatos de imagen.

## Personalización de la conversión de CAD {#customizing-cad-conversion}
  
Los procedimientos de conversión de CAD a <a href="https://docs.fileformat.com/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a> y de CAD a imagen rasterizada son altamente configurables, ya que la clase <a href="https://reference.aspose.com/java/cad/com.aspose.cad.imageoptions/CadRasterizationOptions" target="_blank" rel="nofollow noopener noreferrer">**CadRasterizationOptions**</a> ha sido implementada de manera que proporciona muchas características opcionales que, al configurarse, pueden sobrescribir el proceso de representación según las necesidades de la aplicación.

### Clase CadRasterizationOptions {#cadrasterizationoptions-class}
  
La clase <a href="https://reference.aspose.com/cad/java/com.aspose.cad.imageoptions/CadRasterizationOptions" target="_blank" rel="nofollow noopener noreferrer">**CadRasterizationOptions**</a> es común para todos los formatos CAD admitidos, como <a href="https://docs.fileformat.com/cad/dwg/" target="_blank" rel="nofollow noopener noreferrer">**DWG**</a> y <a href="https://docs.fileformat.com/cad/dxf/" target="_blank" rel="nofollow noopener noreferrer">DXF</a>; por lo tanto, la información compartida en este artículo es válida para ambos formatos CAD mencionados.

Las propiedades más útiles de la clase **CadRasterizationOptions** son:

<div className="docs-owner-markdown-table">

| **Propiedad** | **Valor predeterminado** | **Obligatoria** | **Descripción** |
| --------------------------- | -------------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PageWidth** | **0** | Sí | Especifica el ancho de la página. |
| **PageHeight** | **0** | Sí | Especifica la altura de la página. |
| **ScaleMethod** | **ScaleType.ShrinkToFit** | No | Especifica si el dibujo debe escalarse automáticamente. El valor predeterminado reduce automáticamente la imagen para ajustarla al tamaño del lienzo. Cambie al modo **GrowToFit** o utilice la configuración **None** para desactivar la escala automática. |
| **BackgroundColor** | **Color.White** | No | Especifica el color de fondo de la imagen de salida. |
| **DrawType** | **CadDrawTypeMode.UseDrawColor** | No | Especifica el modo de colorización de la entidad. Especifique la opción **UseObjectColor** para dibujar las entidades utilizando su color nativo, o la opción **UseDrawColor** para anular los colores nativos. |
| **DrawColor** | **Color.Black** | No | Especifica el color anulado de la entidad (solo si **DrawType** está configurado con el valor de propiedad **UseDrawColor**). |
| **AutomaticLayoutsScaling** | False | No | Especifica si debe realizarse una escala automática de diseños para ajustarse al diseño del modelo. |

</div>

### Configuración del tamaño y modo del lienzo {#setting-the-canvas-size--mode}

Exportar desde CAD a PDF o a formatos de imagen rasterizada no es una tarea sencilla. Dado que el PDF o la imagen resultante requiere que se defina el tamaño del lienzo, es necesario especificar las dimensiones de salida para que la página PDF represente el dibujo correctamente. Establezca explícitamente las propiedades **CadRasterizationOptions.PageWidth** y **CadRasterizationOptions.PageHeight**, o bien podría obtener una **ImageSaveException**.

Además, puede especificar opciones de escala de dimensiones. Las opciones de escala se configuran mediante la propiedad **CadRasterizationOptions.ScaleMethod**. Utilice esta opción para ajustar automáticamente las dimensiones de la imagen según los valores de **CadRasterizationOptions.PageWidth** y **CadRasterizationOptions.PageHeight**. De forma predeterminada, **CadRasterizationOptions.ScaleMethod** está configurado en el modo **ScaleType.ShrinkToFit**. Esta propiedad define el siguiente comportamiento:

- Si las dimensiones del dibujo CAD superan el tamaño del lienzo resultante, las dimensiones del dibujo se reducen para ajustarse al lienzo resultante, preservando la relación de aspecto.
- Si las dimensiones del dibujo CAD son menores que el tamaño del lienzo resultante, establezca la propiedad **CadRasterizationOptions.ScaleMethod** en **ScaleType.GrowToFit** para aumentar el tamaño del dibujo y ajustarlo al lienzo PDF, preservando la relación de aspecto.
- O bien, desactive la escala automática con la opción **ScaleType.None**.

El siguiente ejemplo de código muestra la opción de autoescala en uso.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
	    com.aspose.cad.Image objImage = com.aspose.cad.Image.load(srcFile);
	    // Create an instance of CadRasterizationOptions and set its various properties
	    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
	    rasterizationOptions.setPageWidth(1600);
	    rasterizationOptions.setPageHeight(1600);
            
rasterizationOptions.setAutomaticLayoutsScaling(true); 
	    
rasterizationOptions.setNoScaling(true);

	    // Create an instance of PdfOptions
	    PdfOptions pdfOptions = new PdfOptions();

	    // Set the VectorRasterizationOptions property
	    pdfOptions.setVectorRasterizationOptions(rasterizationOptions);

	    // Export CAD to PDF
	    objImage.save(dataDir +"result_out_.pdf", pdfOptions);

	    // Create an instance of TiffOptions
	    TiffOptions tiffOptions = new TiffOptions(TiffExpectedFormat.Default);

	    // Set the VectorRasterizationOptions property
	    tiffOptions.setVectorRasterizationOptions(rasterizationOptions);

	    // Export CAD to TIFF
	    objImage.save(dataDir + "result_out_.tiff", tiffOptions);
```

### Configuración del color de fondo y de dibujo  {#setting-the-background--drawing-colors}
  
De forma predeterminada, la paleta de colores para el lienzo resultante se establece según el esquema común del documento. Esto significa que todas las entidades dentro del dibujo CAD se dibujan con una pluma de color negro sobre un fondo blanco sólido. Estas configuraciones pueden modificarse mediante las propiedades **CadRasterizationOptions.BackgroundColor** y **CadRasterizationOptions.DrawColor**. El cambio de la propiedad **CadRasterizationOptions.DrawColor** también requiere establecer la propiedad **CadRasterizationOptions.DrawType** para que se utilice el color de dibujo especificado. La propiedad **CadRasterizationOptions.DrawType** controla si las entidades CAD conservan sus colores originales o se convierten a colores personalizados. Para conservar los colores de las entidades, especifique **CadRasterizationOptions.DrawType** como **CadDrawTypeMode.UseObjectColor**; de lo contrario, especifique el valor **CadDrawTypeMode.UseDrawColor**.

El siguiente ejemplo de código muestra cómo utilizar distintas propiedades de color.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
	//	Image image = Image.load(srcFile);
	    com.aspose.cad.Image objImage = com.aspose.cad.Image.load(srcFile);	
	    // Create an instance of CadRasterizationOptions and set its various properties
	    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
	    rasterizationOptions.setPageWidth(1600);
	    rasterizationOptions.setPageHeight(1600);
	    rasterizationOptions.setBackgroundColor(com.aspose.cad.Color.getBeige());
	    rasterizationOptions.setDrawType(CadDrawTypeMode.UseDrawColor);
	    rasterizationOptions.setBackgroundColor(com.aspose.cad.Color.getBlue());
     

	    // Create an instance of PdfOptions
	    PdfOptions pdfOptions = new PdfOptions();
	    // Set the VectorRasterizationOptions property
	    pdfOptions.setVectorRasterizationOptions(rasterizationOptions);

	    // Export CAD to PDF
	    objImage.save(dataDir +"result_out_.pdf", pdfOptions);

	    // Create an instance of TiffOptions
	    TiffOptions tiffOptions = new TiffOptions(TiffExpectedFormat.Default);

	    // Set the VectorRasterizationOptions property
	    tiffOptions.setVectorRasterizationOptions(rasterizationOptions);

	    // Export CAD to TIFF
	    objImage.save(dataDir + "result_out_.tiff", tiffOptions);
```

### Configuración de la escala automática de diseño {#setting-auto-layout-scaling}

La mayoría de los dibujos CAD contienen más de un diseño almacenado en un único archivo, y cada diseño puede tener dimensiones distintas. Al convertir dichos dibujos CAD a PDF, cada página del PDF podría tener una escala distinta según el tamaño del diseño. Para lograr una conversión homogénea, las API de Aspose.CAD exponen la propiedad **CadRasterizationOptions.AutomaticLayoutsScaling**. Su valor predeterminado es **false**, pero cuando se establece en **true**, la API intentará buscar una escala correspondiente para cada diseño independiente y representarlos de manera adecuada mediante una operación automática de redimensionamiento según el tamaño de la página.

A continuación se explica cómo funciona la propiedad **CadRasterizationOptions.AutomaticLayoutsScaling** en colaboración con la propiedad **CadRasterizationOptions.ScaleMethod**:

1. Si **ScaleMethod** se establece en **ScaleType.ShrinkToFit** o **ScaleType.GrowToFit**, y **AutomaticLayoutsScaling** se establece en **false**, todos los diseños (incluido el modelo) se procesarán según la primera opción.
2. Si **ScaleMethod** se establece en **ScaleType.ShrinkToFit** o **ScaleType.GrowToFit**, y **AutomaticLayoutsScaling** se establece en **true**, todos los diseños (excepto el modelo) se procesarán según su tamaño, mientras que el modelo se procesará según la primera opción.
3. Si **ScaleMethod** se establece en **ScaleType.None**, ya sea con **AutomaticLayoutsScaling** establecido en **true** o **false**, no se realizará ninguna escala.

El siguiente ejemplo de código muestra cómo configurar la escala automática de diseño para la conversión de CAD a PDF.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		Image image = Image.load(srcFile);
		
	    // Create an instance of CadRasterizationOptions and set its various properties
	    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
	    rasterizationOptions.setPageWidth(1600);
	    rasterizationOptions.setPageHeight(1600);

	    // Set Auto Layout Scaling
	    rasterizationOptions.setAutomaticLayoutsScaling(true);

	    // Create an instance of PdfOptions
	    PdfOptions pdfOptions = new PdfOptions();
	    // Set the VectorRasterizationOptions property
	    pdfOptions.setVectorRasterizationOptions(rasterizationOptions);
	    
	    // Export the CAD to PDF
	    image.save(dataDir + "result_out_.pdf", pdfOptions);
```

## Conversión de diseños CAD a formatos de imagen rasterizada {#converting-cad-layouts-to-raster-image-formats}

La API Aspose.CAD para Java permite convertir diseños CAD de formatos compatibles, como DXF y DWG, a formatos de imagen rasterizada, como PNG, BMP, TIFF, JPEG y GIF. Asimismo, la API ofrece soporte para renderizar diseños específicos de un dibujo CAD en capas PSD distintas. La API de Aspose.CAD para Java expone medios eficientes y fáciles de usar para especificar la lista de diseños CAD requeridos y renderizarlos a formatos de imagen rasterizada. A continuación se explica cómo lograrlo en 5 sencillos pasos, como se indica a continuación:

1. Cargue el archivo CAD en una instancia de **Image** mediante el método de fábrica **load**.
2. Cree una instancia de **CadRasterizationOptions** y configure sus propiedades obligatorias, como **PageWidth** y **PageHeight**.
3. Especifique el nombre o nombres del diseño deseado mediante la propiedad **Layouts** de **CadRasterizationOptions**.
4. Cree una instancia de **ImageOptionsBase** y configure su propiedad **VectorRasterizationOptions** con la instancia de **CadRasterizationOptions** creada en el paso anterior.
5. Llame a **Image.Save**, pasando la ruta del archivo (o un objeto **MemoryStream**) así como la instancia de **ImageOptionsBase** creada en el paso anterior.

A continuación se muestra el código fuente completo.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		Image image = Image.load(srcFile);

		// Create an instance of CadRasterizationOptions
		CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();

		// Set page width & height
		rasterizationOptions.setPageWidth(1200);
		rasterizationOptions.setPageHeight(1200);

		// Specify a list of layout names
		rasterizationOptions.setLayouts(new String[] {"Model", "Layout1"});

		// Create an instance of TiffOptions for the resultant image
		ImageOptionsBase options = new TiffOptions(TiffExpectedFormat.Default);

		// Set rasterization options
		options.setVectorRasterizationOptions(rasterizationOptions);

		// Save resultant image
		image.save(dataDir + "conic_pyramid_layoutstorasterimage_out_.tiff", options);
```

:::info
La propiedad **CadRasterizationOptions.Layouts** es de tipo matriz de cadenas, por lo que puede especificar más de un diseño a la vez para su posible conversión a formatos de imagen. Al especificar múltiples diseños para la propiedad **CadRasterizationOptions.Layouts**, la imagen TIFF resultante tendrá varias páginas, la imagen GIF tendrá varios fotogramas y el formato PSD tendrá varias capas, donde cada página/fotograma/capa representa un diseño individual de AutoCAD. En caso de que se seleccione otro formato de imagen, como PNG, BMP o JPEG, para almacenar el resultado, la API solo representará el diseño predeterminado, es decir, "Model".
:::

## Habilitación del seguimiento para el proceso de renderizado de CAD  {#enabling-tracking-for-cad-rendering-process}
  
Aspose.CAD ha introducido una serie de clases y campos de enumeración auxiliares para facilitar el seguimiento del proceso de renderizado de CAD. Con estos cambios implementados, la conversión de CAD a PDF ahora se puede lograr de la siguiente manera, habilitando el seguimiento.

```java
// For complete examples and data files, please go to https://github.com/aspose-cad/Aspose.CAD-for-Java
        
// The path to the resource directory.
String dataDir = Utils.getDataDir(EnableTracking.class) + "DXFDrawings/";
        
Image image = Image.load(dataDir + "conic_pyramid.dxf");
{
    OutputStream stream = new FileOutputStream(dataDir + "output_conic_pyramid.pdf");
    {
        PdfOptions pdfOptions = new PdfOptions();
        CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
        pdfOptions.setVectorRasterizationOptions(cadRasterizationOptions);
        cadRasterizationOptions.setPageWidth(800);
        cadRasterizationOptions.setPageHeight(600);

        cadRasterizationOptions.RenderResult = new ErrorHandler();

        System.out.println("Exporting to pdf format");
        image.save(stream, pdfOptions);
    }
}
```

```java
// For complete examples and data files, please go to https://github.com/aspose-cad/Aspose.CAD-for-Java
public static class ErrorHandler extends CadRasterizationOptions.CadRenderHandler
{
    @Override
    public void invoke(CadRenderResult result) {
        System.out.println("Tracking results of exporting");

        if (result.isRenderComplete())
            return;

        System.out.println("Have some problems:");

        int idxError = 1;
        for (RenderResult rr : result.getFailures())
        {
            System.out.printf("{0}. {1}, {2}", idxError, rr.getRenderCode(), rr.getMessage());
            idxError++;
        }
    }
}
```

El seguimiento del proceso de renderizado de CAD puede detectar los siguientes problemas posibles.

1. Información de encabezado faltante o corrupta.  
2. Información de diseño faltante.  
3. Entidades de bloque faltantes.  
4. Estilos de acotación faltantes.  
5. Estilos faltantes.  

## Sustitución de fuentes durante la conversión de dibujos CAD {#substituting-fonts-while-converting-cad-drawings}
  
Es muy posible que un dibujo CAD específico utilice una fuente concreta que no esté disponible en la máquina donde se realiza la conversión de CAD a PDF o de CAD a imagen rasterizada. En tales situaciones, la API de Aspose.CAD generará una excepción adecuada para resaltar las fuentes faltantes y detendrá el proceso de conversión, ya que la API requiere estas fuentes para representar correctamente el contenido en el PDF y/o las imágenes resultantes. La API de Aspose.CAD proporciona una forma sencilla de utilizar el mecanismo para sustituir las fuentes necesarias por fuentes disponibles. La propiedad **CadImage.Styles** devuelve una instancia de **CadStylesDictionary**, que a su vez contiene un objeto **CadStyleTableObject** para cada estilo del dibujo CAD, mientras que la propiedad **CadStyleTableObject.PrimaryFontName** se puede utilizar para especificar el nombre de la fuente disponible.

El siguiente fragmento de código demuestra el uso de la API de Aspose.CAD para Java para cambiar la fuente de todos los estilos en un dibujo CAD.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		// Load a CAD drawing  in an instance of CadImage
		CadImage cadImage = (CadImage) Image.load(srcFile);

		// Iterate over the items of CadStylesDictionary
		for(Object style : cadImage.getStyles())
{
    // Set the font name
    ((com.aspose.cad.fileformats.cad.cadtables.CadStyleTableObject)style).setPrimaryFontName("Arial");
}
```

También es posible cambiar la fuente de un solo estilo específico accediendo a él mediante el nombre del estilo. El siguiente fragmento de código demuestra el uso de este enfoque.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		// Load a CAD drawing in an instance of CadImage
		CadImage cadImage = (CadImage)Image.load(srcFile);
		
		// Specify the font for one particular style
 
((com.aspose.cad.fileformats.cad.cadtables.CadStyleTableObject)cadImage.getStyles().get_Item(0)).setPrimaryFontName("Arial");
```

## Conversión de capas CAD a formatos de imagen raster {#converting-cad-layers-to-raster-image-formats}
  
La API Aspose.CAD para Java expone un método eficiente y fácil de usar para especificar el nombre de la capa CAD requerida y renderizarla a formatos de imagen raster. A continuación se muestra cómo lograrlo en 5 sencillos pasos, como se detalla a continuación:

1. Cargue el archivo CAD en una instancia de **Image** mediante el método de fábrica **load**.  
2. Cree una instancia de **CadRasterizationOptions** y configure sus propiedades obligatorias, como **PageWidth** y **PageHeight**.  
3. Agregue el nombre de la capa deseada utilizando el método **CadRasterizationOptions.Layers.add**.  
4. Cree una instancia de **ImageOptionsBase** y configure su propiedad **VectorRasterizationOptions** con la instancia de **CadRasterizationOptions** creada en el paso anterior.  
5. Llame al método **Image.save**, pasando la ruta del archivo (o un objeto de tipo MemoryStream), así como la instancia de **ImageOptionsBase** creada en el paso anterior.  

A continuación se presenta el código fuente completo.

```java
// The path to the resource directory.	        
              String dataDir = Utils.getDataDir(ConvertCADLayerToRasterImageFormat.class) + "CADConversion/";
	
      	String srcFile = dataDir + "conic_pyramid.dxf";
		
// Load a CAD drawing in an instance of Image
Image image = Image.load(srcFile);

// Create an instance of CadRasterizationOptions
CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
// Set image width & height
rasterizationOptions.setPageWidth(500);
rasterizationOptions.setPageHeight(500);

		

              List<String> stringList = new ArrayList<>(Arrays.asList("0"));
// Add the layer name to the CadRasterizationOptions's layer list
       rasterizationOptions.setLayers(stringList);
 
// Create an instance of JpegOptions (or any ImageOptions for raster formats)
JpegOptions options = new JpegOptions();
// Set VectorRasterizationOptions property to the instance of CadRasterizationOptions
options.setVectorRasterizationOptions(rasterizationOptions);
// Export each layer to JPEG format
image.save(dataDir + "CADLayersToRasterImageFormats_out_.jpg", options);
```

### Conversión de todas las capas de CAD en imágenes separadas  {#converting-all-cad-layers-to-separate-images}
  
Puede obtener todas las capas de un dibujo de CAD utilizando **CadImage.Layers** y renderizar cada capa en una imagen separada, como se muestra a continuación.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
		
		// Load a CAD drawing in an instance of CadImage
		CadImage image = (CadImage) Image.load(srcFile);

		// Create an instance of CadRasterizationOptions
		CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();

		// Set image width & height
		rasterizationOptions.setPageWidth(500);
		rasterizationOptions.setPageHeight(500);
		
		// Get the layers in an instance of CadLayersDictionary. 
		// Iterate over the layers
		for (String layer : image.getLayers().getLayersNames())
{
    // Display layer name for tracking
    System.out.println("Start with " +layer);

    List<String> stringList = Arrays.asList(layer);
    // Add the layer name to the CadRasterizationOptions's layer list
    rasterizationOptions.setLayers(stringList);
 
    // Create an instance of JpegOptions (or any ImageOptions for raster formats)
    JpegOptions options = new JpegOptions();
    // Set VectorRasterizationOptions property to the instance of CadRasterizationOptions
    options.setVectorRasterizationOptions(rasterizationOptions);
    // Export each layer to JPEG format
    image.save(dataDir + layer + "_out_.jpg", options);
		}
```

## Conversión de capas CAD DWF a formatos de imagen raster {#converting-dwf-cad-layers-to-raster-image-formats}
  
La API Aspose.CAD para Java expone un método eficiente y fácil de usar para especificar el nombre de la capa CAD requerida y renderizarla a formatos de imagen raster. A continuación se explica cómo lograrlo en 5 sencillos pasos, como se indica a continuación:

1. Cargue el archivo CAD DWF en una instancia de **Image** mediante el método de fábrica **Load**.  
2. Cree una instancia de **CadRasterizationOptions** y configure sus propiedades obligatorias, como **PageWidth** y **PageHeight**.  
3. Agregue el nombre de la capa deseada mediante el método **CadRasterizationOptions.Layers.Add**.  
4. Cree una instancia de **ImageOptionsBase** y configure su propiedad **VectorRasterizationOptions** con la instancia de **CadRasterizationOptions** creada en el paso anterior.  
5. Llame al método **Image.Save**, pasando la ruta del archivo (o un objeto de **MemoryStream**) así como la instancia de **ImageOptionsBase** creada en el paso anterior.

A continuación se muestra el código fuente completo.

```java
String fileName = (dataDir + "site.dwf");
               
com.aspose.cad.Image image = com.aspose.cad.Image.load(fileName);
        
BmpOptions bmpOptions = new BmpOptions();
           
CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
bmpOptions.setVectorRasterizationOptions(rasterizationOptions);
 
rasterizationOptions.setPageHeight(500);
rasterizationOptions.setPageWidth(500);
rasterizationOptions.setLayouts(new String[] { "Model" });
// export
String outPath = dataDir +"site.bmp";
image.save(outPath, bmpOptions);
```

## Aún no admitido {#not-yet-supported}
  
- Sombras, luces, materiales, cámaras adicionales, etc.  
- No se admite la mezcla de entidades naturalmente planas con entidades 3D en el mismo dibujo.  
- No se admite la creación de entidades mediante operaciones como intersección de entidades, unión de entidades, etc.

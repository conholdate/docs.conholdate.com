**Bienvenido a Aspose.CAD para Java**

![todo:image_alt_text](/java/cad/images/4e6f7122191022c8-qHeCKck.png)

Aspose.CAD para Java permite a los desarrolladores convertir archivos AutoCAD DWG, DWF, DWT y DXF a PDF e imágenes rasterizadas. Se trata de una API nativa que no requiere la instalación de AutoCAD ni de ningún otro software.

También puede convertir las capas y diseños seleccionados de los archivos de AutoCAD. La conversión a PDF e imágenes rasterizadas ofrece una calidad muy alta.

Utilizar Aspose.CAD para Java en su proyecto le aporta las siguientes ventajas:

- Amplio conjunto de funciones  
- Independencia de plataforma  
- Rendimiento y escalabilidad  
- Curva de aprendizaje mínima

## Características avanzadas de la API {#advanced-api-features}
  
- Admite las versiones más recientes de los archivos DWG, DWF, DWT y DXF de AutoCAD  
- Convierte los archivos de AutoCAD a PDF de alta calidad  
- Convierte los archivos de AutoCAD a imágenes rasterizadas de alta calidad  
- Selecciona y convierte diseños específicos  
- Selecciona y convierte capas específicas  
- Supervisa el proceso de conversión de archivos  

## Formatos de archivo admitidos {#supported-file-formats}
  
**Abrir, guardar y convertir desde DWG, DWF, DWT y DXF a otros formatos de archivo**  

Aspose.CAD para Java admite los formatos de archivo DWG, DWF, DXF, DWT, PDF e imágenes rasterizadas más utilizados.

![todo:image_alt_text](/java/cad/images/415b8c1c72fb7ac4-product-overview_1.png)

### Soporte para DXF / DWG / DGN {#support-for-dxf--dwg--dgn}
  
- Sólidos 3D (cónico, esfera, toro, cilindro, caja, cuña)  

### Soporte para DXF / DWG {#support-for-dxf--dwg}
  
- Modelos alámbricos  
- Posiciones básicas del cubo de vista  
- Caras 3D  

### Soporte para DXF / DGN {#support-for-dxf--dgn}
  
- Superficies, mallas  

### Soporte para DWT {#support-for-dwt}
  
### Aún no admitido {#not-yet-supported}
  
- Sombras, luces, materiales, cámaras adicionales, etc.  
- Sin soporte para entidades planas naturales mezcladas con entidades 3D en el mismo dibujo.  
- Sin soporte para entidades construidas mediante intersección, unión de entidades, etc.  

## Plataformas admitidas {#supported-platforms}
  
- Aplicaciones de escritorio en MS Windows y servidores  
- Aplicaciones web empresariales  
- Linux (Ubuntu, openSUSE, CentOS y otros)  
- Unix  

## Versiones de Java admitidas {#supported-java-versions}
  
- J2SE 6.0 (1.6)  
- J2SE 7.0 (1.7)  
- J2SE 8.0 (1.8)

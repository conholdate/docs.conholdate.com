## Configuración de una licencia {#setting-a-license}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores a los que está autorizada, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo; incluso la adición accidental de un salto de línea adicional invalidará el archivo.

Debe configurar una licencia antes de realizar cualquier operación con archivos de AutoCAD. Solo es necesario configurar la licencia una vez por aplicación o proceso.

La licencia puede cargarse desde un flujo o un archivo en las siguientes ubicaciones:

1. Ruta explícita.  
2. La carpeta que contiene el archivo Aspose.CAD.jar.

Utilice el método `License.setLicense()` para licenciar el componente. A menudo, la forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.CAD.jar y especificar únicamente el nombre del archivo, sin la ruta, como se muestra en el siguiente ejemplo:

### Ejemplo 1 {#example-1}
  
En este ejemplo, **Aspose.CAD** intentará encontrar el archivo de licencia en la carpeta que contiene los JAR de su aplicación.

```java
com.aspose.cad.License license = new com.aspose.cad.License();

license.setLicense("Aspose.CAD.Java.lic");
```

### Ejemplo 2 {#example-2}
  
Inicializa una licencia a partir de un flujo.

```java
com.aspose.cad.License license = new com.aspose.cad.License();

license.setLicense(new java.io.FileInputStream("Aspose.CAD.Java.lic"));
```

## Validar la licencia {#validate-the-license}
  
Es posible validar si la licencia se ha configurado correctamente o no. La clase License tiene el campo isLicensed, que devolverá true si la licencia se ha configurado correctamente.

```java
License license = new License();

license.setLicense("Aspose.CAD.Java.lic");

if (License.isLicensed()) {

    System.out.println("License is Set!");

}
```

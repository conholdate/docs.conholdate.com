## Crear un nuevo mensaje de correo electrónico {#create-new-email-message}
  
Aspose.Email para Java permite a los desarrolladores crear mensajes MIME (Multipurpose Internet Mail Extensions) desde cero. La clase principal para este propósito en la API de Aspose.Email para Java es la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. Este tema explica los pasos necesarios para crear mensajes de correo electrónico en los formatos de archivo EML, MSG y MHT utilizando Aspose.Email para Java.

Para crear un mensaje de correo electrónico desde cero:

1. Cree una instancia de la clase `MailMessage`.
2. Establezca el asunto del mensaje utilizando el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#setSubject-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setSubject()</a>.
3. Establezca el cuerpo del mensaje utilizando el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#setHtmlBody-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setHtmlBody()</a>.
4. Establezca el remitente del correo electrónico utilizando el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#setFrom-com.aspose.email.MailAddress-" target="_blank" rel="nofollow noopener noreferrer">setFrom()</a>.
5. Establezca el destinatario en el campo **TO** utilizando el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailaddresscollection/#add-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">getTo().add()</a>.
6. Establezca el destinatario en el campo **CC** utilizando el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailaddresscollection/#add-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">getCC().add()</a>.
7. Llame al método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#save-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">Save()</a> para guardar el archivo del mensaje en disco en los formatos MSG, EML y MHT.  

   ```java
   // For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
   // The path to the resource directory.
   String dataDir = Utils.getSharedDataDir(CreateNewEmail.class) + "email/";

   // Create a new instance of MailMessage class
   MailMessage message = new MailMessage();

   // Set subject of the message
   message.setSubject("New message created by Aspose.Email for Java");

   // Set Html body
   message.setHtmlBody("<b>This line is in bold.</b> <br/> <br/>" + "<font color=blue>This line is in blue color</font>");

   // Set sender information
   message.setFrom(new MailAddress("from@domain.com", "Sender Name", false));

   // Add TO recipients
   message.getTo().addMailAddress(new MailAddress("to1@domain.com", "Recipient 1", false));
   message.getTo().addMailAddress(new MailAddress("to2@domain.com", "Recipient 2", false));

   //Add CC recipients
   message.getCC().addMailAddress(new MailAddress("cc1@domain.com", "Recipient 3", false));
   message.getCC().addMailAddress(new MailAddress("cc2@domain.com", "Recipient 4", false));

   // Save message in EML, MSG and MHTML formats
   message.save(dataDir + "Message_out.eml", SaveOptions.getDefaultEml());
   message.save(dataDir + "Message_out.msg", SaveOptions.getDefaultMsg());
   message.save(dataDir + "Message_out.mhtml", SaveOptions.getDefaultMhtml());

   //Save as OFT
   try {
   	MsgSaveOptions options = SaveOptions.getDefaultMsgUnicode();
   	options.setSaveAsTemplate(true);
   	message.save(dataDir + "emlToOft_out.oft", options);
   } finally {
   	if (message != null)
   		((IDisposable) message).dispose();
   }
   ```

## Especificación de varios destinatarios {#specifying-multiple-recipients}
  
La <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> representa un mensaje de correo electrónico. Las instancias de la clase MailMessage se utilizan para construir mensajes de correo electrónico que se transmiten a un servidor SMTP mediante la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a>. Este tema muestra cómo especificar más de una dirección de correo electrónico. Las direcciones de correo electrónico se pueden especificar utilizando la clase MailMessage. Las direcciones de correo electrónico utilizadas en la clase MailMessage son:

- **To** (Para): las direcciones de destinatario se pueden especificar en el campo «To». Los destinatarios del campo «To» constituyen la audiencia principal del mensaje. Puede haber más de una dirección de destinatario.
- **Cc** (Copia): «Cc» significa «carbon copy» (copia en carbono) o «courtesy copy» (copia cortés), y le permite agregar destinatarios de correo electrónico que deben ver el mensaje, pero que no necesariamente se espera que actúen sobre él. Por ejemplo, gerentes o miembros de su equipo que necesiten estar al tanto de una conversación. Con Aspose.Email, las direcciones de Cc se pueden especificar en su código. De esta manera, los correos electrónicos automatizados, o todos los correos electrónicos hacia una dirección específica, pueden copiarse al personal relevante.
- **Bcc** (Copia oculta): «Bcc» significa «blind carbon copy» (copia en carbono oculta), y le permite enviar un correo electrónico a un destinatario cuya dirección permanece oculta para los demás destinatarios. A diferencia de Cc, que aparece en la información del correo visible para los destinatarios principales, Bcc no se muestra. Está diseñado para notificaciones ocultas.

Para especificar varias direcciones de correo electrónico en un mensaje, siga estos pasos:

1. Cree una instancia de la clase MailMessage.  
2. Especifique la dirección del remitente (From) y múltiples direcciones para los campos To, Cc y Bcc utilizando la instancia de MailMessage.  
3. Cree una instancia de la clase SmtpClient y envíe el correo electrónico mediante el método Send.

El siguiente ejemplo de código muestra cómo especificar múltiples direcciones para los campos To, Cc y Bcc.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Declare message as MailMessage instance
// Create an Instance of MailMessage class
MailMessage message = new MailMessage();

// Specify From address
message.setFrom(new MailAddress("sender@sender.com"));

//  Specify recipients’ mail addresses
MailAddressCollection toList = new MailAddressCollection();
toList.add("receiver1@receiver.com");
toList.add("receiver2@receiver.com");
toList.add("receiver3@receiver.com");
message.setTo(toList);

// Specify CC addresses
MailAddressCollection ccList = new MailAddressCollection();
ccList.add("CC1@receiver.com");
ccList.add("CC2@receiver.com");
message.setCC(ccList);

// Specify BCC addresses
MailAddressCollection bccList = new MailAddressCollection();
bccList.add("Bcc1@receiver.com");
bccList.add("Bcc2@receiver.com");
message.setBcc(bccList);

// Create an instance of SmtpClient Class
SmtpClient client = new SmtpClient();

// Specify your mailing host server, Username, Password, Port
client.setHost("smtp.server.com");
client.setUsername("Username");
client.setPassword("Password");
client.setPort(25);

try
{
    // Client.Send will send this message
    client.send(message);

    // Display ‘Message Sent’, only if message sent successfully
    System.out.println("Message sent");
}

catch (Exception ex)
{
    ex.printStackTrace();
}
```

## Cambio de direcciones de correo electrónico a nombres amigables {#changing-email-addresses-to-a-friendly-name}
  
Los ejemplos de programación a continuación muestran cómo cambiar direcciones de correo electrónico a nombres amigables en un mensaje de correo electrónico. Un nombre amigable es un nombre más amigable para el usuario que la dirección de correo electrónico, por ejemplo, *John Smith* en lugar de *js346@domain.com*. Al enviar un correo electrónico, podemos asociar un nombre amigable con una dirección de correo electrónico en el constructor de la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.

Para cambiar direcciones de correo electrónico a nombres amigables en un mensaje de correo electrónico, siga estos pasos:

- Cree una instancia de la clase **MailMessage** y especifique direcciones de correo electrónico en los campos **To** (Para) y **From** (De), junto con los nombres amigables correspondientes.
- Especifique las direcciones de correo electrónico en los campos **Cc** y **Bcc**, junto con los nombres amigables, llamando al constructor de la clase **MailMessage** en la instancia de **MailMessage**.
- Cree una instancia de la clase **SmtpClient** y envíe el correo electrónico mediante el método **Send**.

El siguiente fragmento de código muestra cómo mostrar nombres para las direcciones de correo electrónico.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MailMessage message = new MailMessage("Sender Name <sender@from.com>", "Kyle Huang <kyle@to.com>");

// A To address with a friendly name can also be specified like this
message.getTo().addMailAddress(new MailAddress("kyle@to.com", "Kyle Huang"));

// Specify Cc and Bcc email address along with a friendly name
message.getCC().addMailAddress(new MailAddress("guangzhou@cc.com", "Guangzhou Team"));
message.getBcc().addMailAddress(new MailAddress("ahaq@bcc.com", "Ammad ulHaq "));

// Create an instance of SmtpClient Class and Specify your mailing host server, Username, Password, Port
SmtpClient client = new SmtpClient();
client.setHost("smtp.server.com");
client.setUsername("Username");
client.setPassword("Password");
client.setPort(25);

try
{
    // Client.Send will send this message
    client.send(message);
    System.out.println("Message sent");
}

catch (Exception ex)
{
    ex.printStackTrace();
}
```

## Establecer el cuerpo del correo {#set-mail-body}
  
La clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> representa un mensaje de correo electrónico. Las instancias de la clase MailMessage se utilizan para construir mensajes de correo electrónico que se transmiten a un servidor SMTP para su entrega mediante la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a>. Un cuerpo de correo puede especificarse utilizando la clase MailMessage. El cuerpo de un correo electrónico puede especificarse mediante el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#setHtmlBody-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setHtmlBody</a> en MailMessage.

Además de <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#getHtmlBody--" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a>, Aspose.Email dispone de otro método relacionado con el cuerpo del correo:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#isBodyHtml--" target="_blank" rel="nofollow noopener noreferrer">isBodyHtml</a>: indica al usuario si el cuerpo es HTML o texto sin formato.

Este tema muestra cómo definir el texto HTML del cuerpo y establecer un texto alternativo.

### Establecer el cuerpo HTML {#setting-html-body}
  
<a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#getHtmlBody--" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a> se utiliza para especificar el contenido HTML del cuerpo del mensaje. HtmlBody debe estar encerrado entre etiquetas. El siguiente fragmento de código muestra cómo establecer el cuerpo HTML.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Declare message as MailMessage instance
MailMessage message = new MailMessage();

// Specify HtmlBody
message.setHtmlBody("<html><body>This is the HTML body</body></html>");
```

### Configuración del texto alternativo {#setting-alternate-text}
  
Utilice la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/alternateview/" target="_blank" rel="nofollow noopener noreferrer">AlternateView</a> para especificar copias de un mensaje de correo electrónico en distintos formatos. Por ejemplo, si envía un mensaje en HTML, es posible que también desee proporcionar una versión en texto plano por si algunos destinatarios utilizan lectores de correo que no pueden mostrar contenido HTML. Esta clase tiene dos propiedades, <a href="https://reference.aspose.com/email/java/com.aspose.email/alternateview/#getLinkedResources--" target="_blank" rel="nofollow noopener noreferrer">LinkedResources</a> y <a href="https://reference.aspose.com/email/java/com.aspose.email/alternateview/#getBaseUri--" target="_blank" rel="nofollow noopener noreferrer">BaseUri</a>, que se utilizan para resolver las URL dentro del contenido del correo electrónico.

- **LinkedResources** es una colección de objetos LinkedResources. Al representar el mensaje, las URL dentro del contenido del correo electrónico se comparan primero con las URL del enlace de contenido de cada objeto LinkedResources de la colección LinkedResources y, a continuación, se resuelven.
- **BaseUri** lo utiliza el lector de correo para resolver las URL relativas dentro del cuerpo del mensaje, así como las URL relativas de enlace de contenido de la colección LinkedResources.

El siguiente fragmento de código muestra cómo configurar el texto alternativo.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Declare message as MailMessage instance
MailMessage message = new MailMessage();

// Creates AlternateView to view an email message using the content specified in the //string
AlternateView alternate = AlternateView.createAlternateViewFromString("Alternate Text");

// Adding alternate text
message.getAlternateViews().addItem(alternate);
```

## Especificación de la codificación del cuerpo del correo electrónico {#specifying-mail-body-encoding}
  
El tipo de contenido define el formato del contenido del correo electrónico: el conjunto de caracteres. Por ejemplo, algunos conjuntos de caracteres comunes proporcionados en `java.nio.Charset` son:

- US-ASCII - ASCII de siete bits, también conocido como ISO646-US, también conocido como el bloque latino básico del conjunto de caracteres Unicode  
- ISO-8859-1 - Alfabeto latino ISO número 1, también conocido como ISO-LATIN-1  
- UTF-8 - Formato de transformación UCS de ocho bits  
- UTF-16BE - Formato de transformación UCS de dieciséis bits, orden de bytes big-endian  
- UTF-16LE - Formato de transformación UCS de dieciséis bits, orden de bytes little-endian  
- UTF-16 - Formato de transformación UCS de dieciséis bits, orden de bytes identificado mediante una marca opcional de orden de bytes  

Aspose.Email utiliza la propiedad <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#getBodyEncoding--" target="_blank" rel="nofollow noopener noreferrer">BodyEncoding</a> de la clase `MailMessage` para especificar la codificación del cuerpo del correo electrónico. Para codificar el cuerpo de un mensaje de correo electrónico, siga los pasos que se indican a continuación:

1. Cree una instancia de la clase `MailMessage`.  
2. Especifique el remitente, el destinatario y el cuerpo HTML del correo electrónico en la instancia de `MailMessage`.  
3. Especifique el valor de la propiedad `BodyEncoding`.  
4. Cree una instancia de la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> y envíe el correo electrónico mediante el método `Send`.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Declare message as MailMessage instance
MailMessage message = new MailMessage();

// Specify From, To, HtmlBody, BodyEncoding field
message.setFrom(new MailAddress("sender@sender.com"));
message.getTo().add("receiver@receiver.com");
message.setHtmlBody("<html><body>This is the Html body</body></html>");
message.setBodyEncoding(Charset.forName("US-ASCII"));

// Create an instance of SmtpClient Class and Specify your mailing host server, Username, Password and Port
SmtpClient client = new SmtpClient();
client.setHost("smtp.server.com");
client.setUsername("Username");
client.setPassword("Password");
client.setPort(25);

try
{
    // Client.Send will send this message
    client.send(message);
}
catch (Exception ex)
{
    ex.printStackTrace();
}
```

## Características de MailMessage {#mailmessage-features}
  
La clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> representa el contenido de un mensaje de correo electrónico. Las instancias de la clase MailMessage se utilizan para construir un mensaje de correo electrónico que se transmite a un servidor SMTP para su entrega mediante la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a>. Este artículo muestra cómo utilizar las funciones auxiliares de la clase MailMessage para controlar las siguientes características del correo electrónico:

- **Fecha y hora** – Mediante el método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#setDate-java.util.Date-" target="_blank" rel="nofollow noopener noreferrer">setDate</a> de la clase MailMessage se establece la fecha y hora de un correo electrónico.  
- **Prioridad del mensaje** – La clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailpriority/" target="_blank" rel="nofollow noopener noreferrer">MailPriority</a> especifica los niveles de prioridad para enviar un mensaje de correo electrónico. Puede ser baja, normal o alta. La prioridad influye en la velocidad de transmisión y en la entrega.  
- **Sensibilidad del mensaje** – La clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailsensitivity/" target="_blank" rel="nofollow noopener noreferrer">MailSensitivity</a> especifica cinco niveles de sensibilidad.  
- **Notificación de entrega** – Las notificaciones de entrega permiten al remitente saber que el correo electrónico que envió ha sido entregado en la bandeja de entrada del destinatario.  

De forma predeterminada, la fecha corresponde a la fecha real en que se envió el mensaje, y la hora es la hora en que se envió, tal como la muestra Microsoft Outlook. Sin embargo, la hora real de entrega del correo electrónico la añade el propio servidor SMTP en el encabezado del mensaje. ### Establecer propiedades adicionales {#set-additional-properties}
  
Además de la fecha, la prioridad y la sensibilidad descritas anteriormente, la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> expone la propiedad `XMailer`, que indica el nombre del software que creó el mensaje de correo electrónico. El fragmento de código siguiente ilustra cómo se utiliza cada una de estas propiedades:

```java
MailMessage eml = new MailMessage("sender@gmail.com", "receiver@gmail.com", "Some subject", "Some body text");

```

## Solicitar un recibo de lectura {#requesting-a-read-receipt}
  
Los ejemplos de programación que se muestran a continuación indican cómo puede solicitar un recibo de lectura. La propiedad de enumeración <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#getDeliveryNotificationOptions--" target="_blank" rel="nofollow noopener noreferrer">DeliveryNotificationOptions</a> de la clase MailMessage describe las <a href="https://reference.aspose.com/email/java/com.aspose.email/deliverynotificationoptions/" target="_blank" rel="nofollow noopener noreferrer">opciones de notificación de entrega</a> para un correo electrónico. Para solicitar un recibo de lectura tras enviar un correo electrónico, siga estos pasos:

1. Cree una instancia de la clase MailMessage.  
2. Especifique el remitente, el destinatario y el cuerpo HTML del correo electrónico en la instancia de MailMessage.  
3. Especifique las DeliveryNotificationOptions en otras instancias de MailMessage.  
4. Cree una instancia de la clase SmtpClient y envíe el correo electrónico mediante el método Send.  

Es posible que las solicitudes de recibo de lectura no siempre se cumplan, ya que:

- Un cliente de correo puede no implementar dicha funcionalidad.  
- El usuario final puede tener desactivada dicha funcionalidad.  
- El usuario final puede decidir no enviar uno.

## Establecer encabezados de correo electrónico {#set-email-headers}
  
Los encabezados de correo electrónico representan un estándar de Internet, y las RFC definen campos de encabezado que se incluyen en los mensajes de correo electrónico de Internet. Un encabezado de correo electrónico puede especificarse mediante la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. Los tipos de encabezado comunes se definen en la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/headertype/" target="_blank" rel="nofollow noopener noreferrer">HeaderType</a>. Se trata de una clase sellada que funciona como una enumeración normal.

Normalmente, un encabezado de correo electrónico contiene los siguientes campos:

- **To**: Las direcciones de destinatario pueden especificarse en el campo **To**. Los destinatarios del campo **To** constituyen la audiencia principal del mensaje. Puede haber más de una dirección de destinatario.
- **From**: Este campo presenta la dirección de correo electrónico del remitente del mensaje.
- **Cc**: Permite a los usuarios enviar un mensaje como “Copia carbón” o “Copia cortés”. Es decir, se espera que el destinatario no responda ni actúe. Normalmente, el personal de supervisión se notifica mediante CC.
- **Bcc**: Significa “Copia carbón ciega” y se refiere a la práctica de enviar un mensaje a múltiples destinatarios de modo que lo que reciben no contiene la lista completa de destinatarios. Está destinado a notificaciones ocultas.
- **ReplyTo**: Este campo de encabezado indica dónde deben enviarse las respuestas del remitente.
- **Subject**: Título, encabezado, asunto. A menudo se utiliza como indicador de hilo para mensajes que responden o comentan otros mensajes.
- **Date**: Este encabezado especifica una fecha (y hora). Normalmente, corresponde a la fecha en que se redactó y envió el mensaje.
- **X-Mailer**: Información sobre el software cliente del remitente. Ejemplo: `X-Mailer: Aspose.Email`. `X-Mailer` lo utiliza el cliente de correo. Diferentes clientes de correo tendrán distintos valores de `X-Mailer`. El valor de `X-Mailer` de MS Outlook es *Microsoft Office Outlook, Build 11.0.5510*. Es ignorado por el receptor o lector de correo electrónico.

Normalmente, un encabezado de correo electrónico tiene un aspecto similar a este:

```cs

 Reply-To: reply@reply.com

From: sender@sender.com

To: guangzhou@guangzhoo.com

Subject: test mail

Date: 6 Mar 2006 8:2:2 +0800

X-Mailer: Aspose.Email
```

Para personalizar un encabezado de correo electrónico, siga estos pasos:

- Cree una instancia de la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.
- Especifique los campos To, From, CC, Bcc, ReplyTo, Subject, Date y XMailer mediante una instancia de la clase MailMessage.
- Cree una instancia de la clase <a href="https://reference.aspose.com/email/java/com.aspose.email/mimeheader/" target="_blank" rel="nofollow noopener noreferrer">MimeHeader</a> y especifique el encabezado secreto.
- Agregue el encabezado secreto a la instancia de MailMessage.

En el código que se muestra a continuación, hemos personalizado un encabezado de correo electrónico.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Create a new instance of MailMessage class
MailMessage message = new MailMessage();

// Set subject of the message
message.setSubject("New message created by Aspose.Email for Java");

// Set Html body
message.setHtmlBody("<b>This line is in bold.</b> <br/> <br/>" +
		"<font color=blue>This line is in blue color</font>");

// Set sender information
message.setFrom(new MailAddress("from@domain.com", "Sender Name", false));

// Add TO recipients
message.getTo().addItem(new MailAddress("to@domain.com", "Recipient 1", false));

// Message subject
message.setSubject("Customizing Email Headers");

// Specify Date
Calendar calendar = Calendar.getInstance(TimeZone.getTimeZone("GMT"));

Date date = calendar.getTime();
message.setDate(date);

// Specify XMailer
message.setXMailer("Aspose.Email");

// Specify Secret Header
message.getHeaders().add("secret-header", "mystery");

// Save message to disc
message.save(dataDir + "SetEmailHeaders_out.msg", SaveOptions.getDefaultMsg());
```

El fragmento de código anterior genera una cabecera de correo electrónico en el siguiente formato. Esto se puede observar abriendo el archivo `MsgHeaders.msg` en Microsoft Outlook y luego viendo sus propiedades.

```cs

 Reply-To: reply@reply.com

From: sender@sender.com

To: receiver1@receiver.com

CC: receiver2@receiver.com

BCC: receiver3@receiver.com

Subject: test mail

Date: 6 Mar 2006 8:2:2 +0800

X-Mailer: Aspose.Email

secret-header: mystery
```

## Firmar correos electrónicos con DKIM {#sign-emails-with-dkim}
  
Aspose.Email permite firmar correos electrónicos con DKIM (DomainKeys Identified Mail). Esto permite que una organización asuma responsabilidad por un mensaje que se encuentra en tránsito (<a href="https://www.dkim.org/" target="_blank" rel="nofollow noopener noreferrer">acerca de DKIM</a>). DKIM agrega una firma digital a los encabezados del mensaje de correo electrónico, la cual puede ser validada por los destinatarios. La clave pública del remitente permite al receptor verificar que la firma coincide con el contenido del mensaje. El método <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/#dKIMSign-com.aspose.ms.System.Security.Cryptography.RSACryptoServiceProvider-com.aspose.email.DKIMSignatureInfo-" target="_blank" rel="nofollow noopener noreferrer">dKIMSign</a> de la clase MailMessage se utiliza para establecer la información criptográfica y de firma necesaria para firmar el mensaje. El siguiente fragmento de código muestra cómo firmar correos electrónicos con DKIM.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
String privateKeyFile = "key2.pem";
RSACryptoServiceProvider rsa = PemReader.getPrivateKey(privateKeyFile);
DKIMSignatureInfo signInfo = new DKIMSignatureInfo("test", "yandex.ru");
signInfo.getHeaders().addItem("From");
signInfo.getHeaders().addItem("Subject");
MailMessage mailMessage = new MailMessage("sender@gmail.com", "test@gmail.com");
mailMessage.setSubject("Signed DKIM message text body");
mailMessage.setBody("This is a text body signed DKIM message");
MailMessage signedMsg = mailMessage.dKIMSign(rsa, signInfo);

try
{
    SmtpClient client = new SmtpClient("smtp.domain.com",25, "username", "password");
    client.send(signedMsg);
}
catch (Exception ex)
{
    ex.printStackTrace();
}
finally
{}
```

El código siguiente envía un correo electrónico a una persona desde otras tres.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
public static void main(String[] args) {
	//create a new MailMessage instance as a template
	MailMessage template = new MailMessage();

	//add template field to subject
	template.setSubject("Hello, #FirstName#");
	template.setFrom(MailAddress.to_MailAddress("sale@aspose.com"));

	//add template field to receipt
	template.getTo().addMailAddress(new MailAddress("#Receipt#", true));

	//add template field to html body 
	//use GetSignment as the template routine, which will provide the same signment.
	template.setHtmlBody("Dear #FirstName# #LastName#, &lt;br&gt;&lt;br&gt;Thank you for your interest in &lt;STRONG&gt;Aspose.Network&lt;/STRONG&gt;.&lt;br&gt;&lt;br&gt;Have fun with it.&lt;br&gt;&lt;br&gt;#GetSignature()#");

	//create a new TemplateEngine with the template message.
	TemplateEngine engine = new TemplateEngine(template);

	//register the GetSignment as a template routine, for we use it in the template.
	engine.registerRoutine("GetSignature", new TemplateRoutine() {
		public Object invoke(Object[] args) {
			return getSignature(args);
		}
	});
	
	//fill a DataTable as data source
	DataTable dt = new DataTable();
	dt.getColumns().add("Receipt");
	dt.getColumns().add("FirstName");
	dt.getColumns().add("LastName");
	DataRow dr;
	dr = dt.newRow();
	dr.set("Receipt", "Nancy.Davolio&lt;Nancy@somedomain.com&gt;");
	dr.set("FirstName", "Nancy");
	dr.set("LastName", "Davolio");
	dt.getRows().add(dr);
	dr = dt.newRow();
	dr.set("Receipt", "Andrew.Fuller&lt;Andrew@somedomain.com&gt;");
	dr.set("FirstName", "Andrew");
	dr.set("LastName", "Fuller");
	dt.getRows().add(dr);
	dr = dt.newRow();
	dr.set("Receipt", "Janet.Leverling&lt;Janet@somedomain.com&gt;");
	dr.set("FirstName", "Janet");
	dr.set("LastName", "Leverling");
	dt.getRows().add(dr);

	MailMessageCollection messages;
	try
	{
		//create the messages from the template and datasource.
		messages = engine.instantiate(dt);
	}
	catch (MailException ex)
	{
		System.out.println(ex.toString());
	}
}
	
public static Object getSignature(Object[] args) {
    return "John Smith&lt;br&gt;Product Lead&lt;br&gt;Aspose Ltd.&lt;br&gt;".concat(DateTime.getNow().toShortDateString());
}
```

Aspose.Email para Java se divide en varios componentes independientes, cada uno con características específicas. A continuación se presenta una lista de las características de cada paquete principal.

## **Aspose.Email.Mail** {#asposeemailmail}

### **Características generales de correo electrónico** {#general-email-features}

- Crear correos electrónicos que contengan texto sin formato
- Crear correos electrónicos que contengan HTML
- Crear cuerpos de mensaje alternativos para garantizar la compatibilidad con clientes de correo electrónico que admitan HTML y los que no lo admitan
- Conectarse a cualquier servidor SMTP en un puerto especificado
- Enviar correos electrónicos a través de cualquier servidor SMTP
- Conectarse a un servidor SMTP habilitado para SSL
- Conectarse a un servidor SMTP basado en TLS

### **Características de archivos adjuntos** {#attachment-features}

- Agregar archivos adjuntos a correos electrónicos
- Eliminar archivos adjuntos de correos electrónicos
- Crear archivos adjuntos a partir de rutas de archivo
- Crear archivos adjuntos a partir de flujos (streams)
- Crear archivos adjuntos a partir de matrices de bytes

### **Características de objetos incrustados** {#embedded-object-features}

- Incrustar objetos (como imágenes, sonidos, etc.) en sus correos electrónicos
- Eliminar objetos incrustados de sus correos electrónicos
- Incrustar objetos a partir de rutas de archivo
- Incrustar objetos a partir de flujos (streams)
- Incrustar objetos a partir de matrices de bytes

### **Características de importación/exportación** {#importexport-features}

- Importar correos electrónicos en formato de mensaje de correo electrónico de Microsoft Outlook (MSG)
- Importar correos electrónicos en formato HTML de Microsoft (MHT)
- Importar correos electrónicos en formato de mensaje compatible con RFC822 (EML)
- Crear correos electrónicos a partir de contenido HTML
- Exportar correos electrónicos al formato HTML de Microsoft (MHT)
- Exportar correos electrónicos al formato de mensaje compatible con RFC822 (EML)
- Exportar correos electrónicos desde un archivo PST de Outlook a archivos MSG de Outlook

### **Características de correo masivo** {#bulk-mail-features}

- Admite el envío de correos electrónicos por lotes
- Función integrada de multiprocesamiento para el envío de correo masivo
- Admite el guardado de mensajes de correo masivo en una memoria intermedia de mensajes

### **Características de combinación de correspondencia** {#mail-merge-features}

- Combinación de correspondencia basada en plantillas utilizando distintas fuentes de datos
- Admite DataTable como fuente de datos
- Admite DataRowCollection como fuente de datos
- Admite DataReader como fuente de datos
- Crear plantilla de correo electrónico a partir de un archivo
- Crear plantilla de correo electrónico a partir de una instancia MailMessage
- Realizar combinación de correspondencia fila por fila para generar mensajes de correo electrónico

### **Características de calendario** {#calendar-features}

- Agregar eventos iCalendar a mensajes de correo electrónico
- Cancelar eventos iCalendar
- Enviar solicitudes de reunión por correo electrónico
- Enviar solicitudes de cita por correo electrónico

### **Características de control de eventos** {#event-handling-features}

- Admite una variedad de eventos útiles para brindar mayor control
- Realizar acciones cuando todos los correos electrónicos masivos hayan sido enviados
- Realizar acciones cuando un mensaje esté a punto de enviarse
- Recibir notificaciones mediante un evento cuando un correo electrónico haya sido completamente enviado

### **Características de utilidades** {#utility-features}

- Personalizar encabezados de correo electrónico
- Establecer prioridad, fecha y hora del mensaje
- Admite todos los juegos de caracteres
- Solicitar acuses de recibo

### **Características avanzadas** {#advanced-features}

- Modelos de programación asíncrona y síncrona
- Admite el análisis de correos electrónicos en formatos MSG, MHT y EML
- Admite el guardado de correos electrónicos en formatos MSG, MHT y EML
- Extraer archivos adjuntos de archivos de mensaje de correo electrónico de Microsoft Outlook (MSG)
- Leer mensajes desde archivos PST de Outlook
- Admite conexión de respaldo SMTP
- Especificar el número de intentos para conexiones SMTP

### **Características generales de análisis** {#general-parsing-features}
  
- Extraer cabeceras de correo electrónico y cuerpos de mensajes.  
- Recuperar nombres y valores de las cabeceras de correo electrónico.  
- Recuperar direcciones de remitente (From), destinatario (To), copia (Cc) y respuesta (Reply-To).  
- Recuperar y guardar adjuntos.  
- Recuperar y guardar objetos incrustados, como imágenes y sonidos.  

### **Características de importación/exportación** {#importexport-features-1}
  
- Importar correos electrónicos en formato de mensaje de Microsoft Outlook (MSG).  
- Importar correos electrónicos en formato HTML de Microsoft (MHT).  
- Importar correos electrónicos en formato de mensaje compatible con RFC822 (EML).  
- Exportar correos electrónicos al formato HTML de Microsoft (MHT).  
- Exportar correos electrónicos al formato de mensaje compatible con RFC822 (EML).  

### **Características de utilidad** {#utility-features-1}
  
- Admite múltiples cabeceras.  
- Admite múltiples partes.  
- Admite todos los conjuntos de caracteres.  
- Recuperar metadatos, como contentType, MimeVersion y XMailer.

:::

### **Características avanzadas de análisis** {#advance-parsing-features}
  
- Cargar y analizar correos electrónicos en formatos MSG, MHT y EML.  

## **Aspose.Email.Pop3** {#asposeemailpop3}
  
### **Características generales de POP3** {#general-pop3-features}
  
- Recuperar mensajes completos o solo encabezados.  
- Admite comandos básicos de POP3.  
- Listar mensajes de correo.  
- Recuperar correos electrónicos en formatos MIME y texto sin formato.  
- Recuperar información de buzón.  
- Mantener la conexión POP3 activa.  
- Características de gestión de correo electrónico.  
- Eliminar correos electrónicos seleccionados en el servidor POP3.  
- Eliminar todos los correos electrónicos.  
- Cancelar eliminación en el servidor POP3.  
- Conectarse a un servidor POP3 con SSL habilitado.  

### **Características de seguridad** {#security-features}
  
- Admite el Protocolo de Oficina Postales Autenticado (APOP).  
- Admite autenticación USER/PASS en texto claro.  
- Admite autenticación CRAM-MD5 según RFC 2195.  
- Admite autenticación DIGEST-MD5 según RFC 2831.  
- Admite autenticación por inicio de sesión.  
- Admite autenticación en texto claro TLS según RFC 2595.  

## **Aspose.Email.Exchange** {#asposeemailexchange}
  
### **Características generales de Exchange** {#general-exchange-features}
  
- Conectarse a Microsoft Exchange Server 2003, 2007, 2010 y 2013.  
- Recuperar correos electrónicos desde el servidor Exchange.  
- Listar mensajes de correo.  
- Recuperar información de buzón.  
- Características de gestión de correo electrónico.  
- Eliminar correos electrónicos seleccionados en el servidor Exchange.  

## **Características de utilidad** {#utility-features-2}
  
- Establecer tiempos de espera de conexión y lectura.  
- Establecer tamaño de búfer de envío y recepción.  
- Obtener identificadores únicos de correos electrónicos en un servidor.  
- Recuperar recuento de mensajes.  
- Recuperar tamaño de mensaje.  

## **Aspose.Email.Imap** {#asposeemailimap}
  
### **Características generales** {#general-features}
  
- Conectarse y comunicarse con servidores IMAP.  
- Manipular mensajes y carpetas de correo electrónico en el servidor.  
- Conectarse a un servidor IMAP con SSL habilitado.  
- Recibir notificaciones cuando se recibe un correo electrónico, evitando así sondear repetidamente el servidor.  

### **Características de gestión de mensajes** {#message-management-features}
  
- Recuperar mensajes de correo electrónico.  
- Recuperar encabezados de mensajes de correo electrónico.  
- Guardar mensajes de correo electrónico en el sistema de archivos local.  
- Eliminar mensajes de correo electrónico.  
- Listar mensajes de correo electrónico en la carpeta especificada.  
- Establecer marcas (leído, eliminado, etc.) para mensajes de correo electrónico especificados.  

### **Características de gestión de carpetas** {#folder-management-features}
  
- Crear carpetas de correo electrónico.  
- Eliminar carpetas de correo electrónico.  
- Renombrar carpetas de correo electrónico.  

### **Características de seguridad** {#security-features-1}
  
- Admite autenticación USER/PASS en texto claro.  
- Admite autenticación CRAM-MD5 según RFC 2195.  
- Admite autenticación DIGEST-MD5 según RFC 2831.  
- Admite autenticación por inicio de sesión.  
- Admite autenticación en texto claro TLS según RFC 2595.  

## **Aspose.Email.Verify** {#asposeemailverify}
  
### **Características de validación** {#validation-features}
  
- Validar direcciones de correo electrónico.  
- Admite validación de sintaxis de correo electrónico.  
- Admite validación de dominio de correo electrónico.  
- Admite validación de servidor de correo.  
- Admite validación de registros MX.  
- Validación asíncrona.  
- Resultados de validación flexibles.  

### **Características de utilidad** {#utility-features-3}
  
- Especificar servidores DNS.  
- Establecer tiempo de espera de solicitud.  

## **Aspose.iCalendar** {#asposeicalendar}
  
- Calcular fácil y confiablemente fechas y horas de ocurrencia incluso para patrones de recurrencia muy complejos.  
- Consumir y generar patrones de recurrencia en formato iCalendar (RFC 2445).  
- Crear patrones de recurrencia mediante programación mediante un modelo de objetos intuitivo.  
- Utilizar patrones de recurrencia anuales, mensuales, semanales, diarios, por hora, por minuto y por segundo.  
- Representar patrones de recurrencia en aplicaciones de escritorio, web o móviles.  

## **Soporte para archivos PST/OST** {#pstost-files-support}
  
- Soporte para archivos de almacenamiento personal y fuera de línea.  
- Generar y leer archivos OST y PST.  
- Admite archivos PST de todos los tipos.  
- Todos los tipos de OST son compatibles para lectura.  

## **Protocolos admitidos** {#protocols-supported}
  
- SMTP  
- MIME  
- POP3  
- IMAP  
- HTTP

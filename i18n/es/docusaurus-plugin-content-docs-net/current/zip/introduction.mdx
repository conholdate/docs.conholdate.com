La API de Aspose.ZIP para .NET permite trabajar con la creación y gestión de archivos comprimidos en sus aplicaciones, sin necesidad de ninguna otra aplicación de terceros. Su implementación detallada permite gestionar fácilmente archivos ZIP.

:::info
Este artículo describe la manipulación con el formato *zip* únicamente. Aspose.Zip admite muchos formatos de archivo comprimido, los cuales se enumeran [aquí](/net/zip/supported-file-formats/).
:::

## Conceptos Básicos de la API  {#basic-concepts-of-the-api}
  
La API de Aspose.ZIP conceptualiza la funcionalidad de cada elemento en un archivo como <a href="https://reference.aspose.com/zip/net/aspose.zip/archiveentry/" target="_blank" rel="nofollow noopener noreferrer">Entry</a>. Las entradas pueden agregarse, actualizarse y eliminarse de un archivo. La API simplifica el trabajo con un archivo y sus entradas. Esta sección brinda una idea sobre las distintas clases y métodos expuestos por la API y su uso.

### Trabajo con Archivos  {#working-with-archives}
  
#### Creación de Archivos  {#creating-archive}
  
Un archivo puede crearse utilizando la clase <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/" target="_blank" rel="nofollow noopener noreferrer">Archive</a> expuesta por la API. Un archivo básico puede crearse con esta clase, como se muestra en el siguiente ejemplo de código.

```csharp
var archive = new Archive();
```

Este archivo se prepara para la compresión.

#### Creación de archivo con compresión personalizada  {#creating-archive-with-custom-compression}
  
Los archivos pueden crearse con configuraciones adicionales que especifiquen técnicas de compresión personalizadas.

```csharp
 var archive = new Archive(new ArchiveEntrySettings(new CompressionSettings(CompressionMethod.Store), new AesEcryptionSettings("p@s$", EncryptionMethod.AES256)));
```

#### Guardar archivos  {#saving-archives}
  
Los archivos pueden <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/save/" target="_blank" rel="nofollow noopener noreferrer">guardarse</a> en el sistema de archivos del disco, así como en flujos.

```csharp
archive.Save(stream, ArchiveSaveOptions saveOptions = null)

archive.Save(filePath, ArchiveSaveOptions saveOptions = null)
```

#### Extracción de archivos {#archive-extraction}
  
Los archivos pueden extraerse pasando el flujo o la ruta de origen al constructor de extracción de <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/archive/#archive-constructor-2-of-3" target="_blank" rel="nofollow noopener noreferrer">Archive</a>.

```csharp
FileStream zipFileStream = File.Open("myarchive.zip", FileMode.Open);
Archive archive = new Archive(zipFileStream);

or 

Archive archive = new Archive("myarchive.zip");
```

#### Extracción de archivos comprimidos cifrados  {#extracting-encrypted-archives}
  
Los archivos comprimidos protegidos con contraseña se pueden extraer especificando <a href="https://reference.aspose.com/zip/net/aspose.zip/archiveloadoptions/" target="_blank" rel="nofollow noopener noreferrer">ArchiveLoadOptions</a>

```csharp
Archive archive = new Archive(sourceStream, new ArchiveLoadOptions() { DecryptiptionPassword = "p@s$" });

or

Archive archive = new Archive("myarchive.zip", new ArchiveLoadOptions() { DecryptiptionPassword = "p@s$" });
```

### Trabajar con entradas de archivo {#working-with-archive-entries}
  
#### Agregar entradas a un archivo {#adding-entries-to-archive}
  
Las entradas se pueden agregar a un archivo mediante el método <a href="https://reference.aspose.com/zip/net/aspose.zip/archive/createentry/" target="_blank" rel="nofollow noopener noreferrer">CreateEntry</a> de Archive. Las sobrecargas ofrecidas por este método permiten crear entradas en un archivo a partir de una ruta de archivo o un flujo, junto con la especificación de la configuración de la entrada de archivo. También se pueden agregar archivos de un directorio a un archivo especificando la búsqueda recursiva a través del directorio.

```csharp
CreateEntry(string name, Stream source, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name, data source, optional compression and encryption settings for the entry.

CreateEntry(string name, string path, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name and file source, optional compression and encryption settings for the entry.

CreateEntry(string name, FileInfo fileInfo, ArchiveEntrySettings newEntriesSettings) - Creates single entry with given name, file source, optional compression and encryption settings for the entry. Keeps attributes of NTFS file.

CreateEntry(string name, Stream source, ArchiveEntrySettings newEntriesSettings, FileSystemInfo fileInfo) - Creates single entry with given name, data source, compression and encryption settings for the entry. Keeps attributes of NTFS file and respects optional parameters.
```

Puede descargar Aspose.ZIP para .NET de forma gratuita para su evaluación. La versión de evaluación ofrece casi todas las funcionalidades del producto, con ciertas limitaciones. La misma versión de evaluación se convierte en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para [aplicar la licencia](/net/zip/licensing/#licensing-applylicenseusingfileorstreamobject).

Si desea probar Aspose.ZIP sin las limitaciones de la versión de evaluación, también puede solicitar una Licencia Temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">¿Cómo obtener una Licencia Temporal?</a>

### Limitaciones de la Versión de Evaluación {#evaluation-version-limitations}
  
La versión de evaluación de Aspose.ZIP (sin una licencia especificada) proporciona la funcionalidad completa del producto, excepto por algunas limitaciones propias de la evaluación.

## Aplicar una licencia {#applying-a-license}

Puede descargar fácilmente una versión de evaluación de Aspose.ZIP desde su  <a href="https://www.nuget.org/packages/Aspose.ZIP/" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia de Aspose.ZIP. Además, la versión de evaluación se convierte simplemente en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

### Sobre la licencia {#about-the-license}

La licencia es un archivo XML de texto plano que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de caducidad de la suscripción, entre otros. El archivo está firmado digitalmente, por lo que no debe modificarlo. Incluso la adición accidental de un salto de línea adicional en el archivo lo invalidará.

Debe establecer una licencia antes de utilizar Aspose.ZIP si desea evitar sus limitaciones de evaluación. Solo es necesario establecer la licencia una vez por aplicación (o proceso).

### Aplicar licencia mediante un objeto de archivo o flujo {#apply-license-using-file-or-stream-object}

#### Establecer una licencia en Aspose.ZIP para .NET {#setting-a-license-in-asposezip-for-net}

En Aspose.Zip, la licencia se puede cargar desde un archivo, un flujo o un recurso incrustado. Aspose.ZIP intenta encontrar la licencia en las siguientes ubicaciones:

- Ruta explícita
- La carpeta que contiene el DLL del componente (incluido en Aspose.ZIP)
- La carpeta que contiene el ensamblado que llamó al DLL del componente (incluido en Aspose.ZIP)
- La carpeta que contiene el ensamblado de entrada (su .exe)
- Un recurso incrustado en el ensamblado que llamó al DLL del componente (incluido en Aspose.ZIP). Hay dos métodos comunes para establecer la licencia, los cuales se discuten a continuación:

#### Aplicar licencia mediante un objeto de archivo o flujo {#apply-license-using-file-or-stream-object-1}

La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que la DLL del componente (incluida en Aspose.ZIP) y especificar únicamente el nombre del archivo, sin su ruta.

```csharp
// Instantiate an instance of license and set the license file through its path

Aspose.ZIP.License license = new Aspose.ZIP.License();

license.SetLicense("Aspose.ZIP.lic");
```

```csharp
// Instantiate an instance of license and set the license through a stream

Aspose.ZIP.License license = new Aspose.ZIP.License();

license.SetLicense(myStream);
```

Cuando llame al método `SetLicense`, el nombre de la licencia debe coincidir exactamente con el nombre de su archivo de licencia. Por ejemplo, puede cambiar el nombre del archivo de licencia a `"Aspose.ZIP.lic.xml"`. Luego, en su código, debe utilizar el nombre modificado de la licencia (es decir, `Aspose.ZIP.lic.xml`) para el método `SetLicense`.

## Incluir el archivo de licencia como un recurso incrustado  {#including-the-license-file-as-an-embedded-resource}
  
Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llaman a la DLL del componente (incluida en Aspose.ZIP). Para incluir el archivo de licencia como un recurso incrustado, realice los siguientes pasos:  

- En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto mediante el menú Archivo | Agregar elemento existente…
- Seleccione el archivo en el Explorador de soluciones y establezca Acción de compilación en Recurso incrustado en la ventana Propiedades
- Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), no es necesario invocar los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` del Microsoft .NET Framework. Todo lo que debe hacer es agregar el archivo de licencia como recurso incrustado en su proyecto y pasar el nombre del archivo de licencia al método `SetLicense` de la clase `License`. La clase `License` encontrará automáticamente el archivo de licencia en los recursos incrustados.

Consulte el ejemplo que se muestra a continuación para comprender este método de establecimiento de una licencia (incrustada) en sus aplicaciones.

```csharp
// Instantiate the License class

Aspose.ZIP.License license = new Aspose.ZIP.License();

// Pass only the name of the license file embedded in the assembly

license.SetLicense("Aspose.ZIP.lic");
```

### Aplicación de una licencia por uso (medida)  {#applying-a-metered-pay-per-use-license}
  
Una licencia por uso es un mecanismo de licenciamiento que permite facturar a los clientes según el uso de las características de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por uso</a>. Para activar la licencia por uso, se requieren claves pública y privada.  

Aplicar una licencia por uso es tan sencillo como estas dos líneas de código:

```csharp
var metered = new MeteredLicense();
metered.SetMeteredKey("<public key>", "<private key>");
```

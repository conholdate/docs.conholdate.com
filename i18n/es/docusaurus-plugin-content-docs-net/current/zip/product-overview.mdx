**Bienvenido a Aspose.ZIP para .NET**

Aspose.ZIP para .NET es una API de .NET flexible y fácil de usar que le permite trabajar con la compresión de archivos en el formato estándar ZIP. Le ahorra tiempo y esfuerzo al permitirle realizar la compresión/descompresión de archivos y carpetas sin tener que adentrarse en la complejidad subyacente de los formatos de archivo comprimidos.

Aspose.ZIP le brinda la capacidad de proteger con contraseña los archivos ZIP mediante técnicas de cifrado tradicionales y AES. La API es fácil de usar, robusta y está escrita en código administrado para su uso en aplicaciones .NET.
:::

**Descripción del producto**  
Aspose.ZIP para .NET está implementado utilizando C# administrado y puede utilizarse con cualquier lenguaje .NET: C#, VB.NET, F#. Puede integrarse con cualquier tipo de aplicación, desde aplicaciones web ASP.NET hasta aplicaciones de formularios en cualquier sistema operativo: Windows/Linux/macOS. También proporciona demos completas escritas en C#, lo que permite a los desarrolladores comenzar rápidamente. El uso de compresión paralela en archivos ZIP con varias entradas puede lograr un aumento de velocidad de hasta 5 veces. Aspose.ZIP puede utilizarse para realizar diversas tareas en aplicaciones. Por ejemplo:  

- Comprimir archivos y carpetas en formatos ZIP y 7z estándar
- Descomprimir archivos y carpetas
- Proteger con contraseña archivos ZIP
- Soporte para esquemas tradicionales de protección por contraseña
- Cifrar archivos mediante esquemas de cifrado AES
- Soporte para técnicas de cifrado AES 128, AES 192 y AES 256
- Aplicar un esquema de protección distinto a cada archivo dentro de un archivo comprimido
- Añadir archivos a un archivo ZIP existente
- Utilizar paralelismo para lograr una compresión eficiente
- Compresión LZMA, PPMd y BZip2 dentro de un archivo ZIP
- Compresión LZMA, LZMA2 o Bzip2 en archivos 7z

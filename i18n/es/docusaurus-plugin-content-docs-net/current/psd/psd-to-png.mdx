Aspose.PSD es un SDK del formato PSD y una API de manipulación de Photoshop en C# .NET, que permite convertir desde el formato PSD al formato PNG.

Para esta conversión de PSD, debe utilizar el siguiente código en C#:

A continuación se proporciona un ejemplo de código que demuestra cómo convertir PSD a PNG:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-psd/Aspose.PSD-for-.NET

string inputFile = dataDir + "PsdConvertToPngExample.psd";

using (var psdImage = (PsdImage)Image.Load(inputFile, new PsdLoadOptions() { ReadOnlyMode = true }))
{
    psdImage.Save(dataDir + "PsdConvertedToPng.png",
        new PngOptions() { ColorType = PngColorType.TruecolorWithAlpha, Progressive = true, CompressionLevel = 9 });
}
```

Puede especificar el nivel de compresión del formato PNG desde 0 hasta 9, donde 9 representa la compresión máxima. También puede utilizar la compresión progresiva PNG y modificar el tipo de color del archivo PNG. <a href="https://reference.aspose.com/psd/net/aspose.psd.imageoptions/pngoptions" target="_blank" rel="nofollow noopener noreferrer">Opciones PNG</a> presentan propiedades distintas según el caso de exportación de archivos PSD.

Utilizar PNG semitransparente con canal alfa para su sitio web o proyecto constituye una solución adecuada. El archivo de Adobe Photoshop puede exportarse con precisión píxel a píxel mediante <a href="https://reference.aspose.com/psd/net/aspose.psd.imageloadoptions/psdloadoptions/properties/readonlymode" target="_blank" rel="nofollow noopener noreferrer">Modo de solo lectura</a>.

A continuación se muestra un ejemplo de un archivo PSD exportado con <a href="https://docs.aspose.com/display/psdjava/Apply+Masking" target="_blank" rel="nofollow noopener noreferrer">Máscara aplicada</a>, <a href="https://reference.aspose.com/psd/net/aspose.psd.fileformats.psd.layers/textlayer" target="_blank" rel="nofollow noopener noreferrer">Capa con texto</a> y <a href="https://reference.aspose.com/psd/net/aspose.psd.fileformats.psd.layers.filllayers/filllayer" target="_blank" rel="nofollow noopener noreferrer">Capa de color de relleno transparente</a> (Aspose.PSD admite todos los tipos de <a href="https://docs.aspose.com/display/psdjava/Support+of+Fill+Layers" target="_blank" rel="nofollow noopener noreferrer">Capa de relleno de Adobe Photoshop</a>). Asimismo, puede observar el [efecto de sombra](/net/psd/shadow-effects-in-psd-file/) en la capa de forma PSD.

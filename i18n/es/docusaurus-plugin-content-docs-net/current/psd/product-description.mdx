**Bienvenido a Aspose.PSD para .NET**

![todo:image_alt_text](/net/psd/images/0465e5205ffeb726-product-description_1)

Aspose.PSD para .NET es un producto que permite una manipulación extensiva de los formatos de archivo PSD. Este producto no requiere que Adobe Photoshop esté instalado. Aspose.PSD para .NET permite editar archivos PSD, actualizar propiedades de capas, agregar marcas de agua, realizar operaciones gráficas o convertir un formato de archivo a otro. Este producto permite diferentes escenarios de automatización que ayudan a los desarrolladores en su labor.

Actualmente, Aspose.PSD para .NET admite los formatos de archivo PSD y PSB para cargar y manipular. Las versiones futuras permitirán cargar más formatos de archivo PSD. Aspose.PSD para .NET permite exportar a diversos formatos de archivo rasterizados, como TIFF, JPEG, JPEG2000, PNG, GIF, BMP y se agregarán más formatos de archivo compatibles con la exportación. El producto utiliza algoritmos que permiten editar archivos PSD de manera eficiente y mantienen un buen rendimiento. El producto se desarrolla activamente y se agregarán muchas funcionalidades útiles para satisfacer las demandas del mercado. Por ejemplo, el soporte para .NET Core se está desarrollando activamente.

## Descripción del producto {#product-description}
  
Aspose.PSD (escrito en C# administrado) está diseñado para utilizarse con cualquiera de los lenguajes compatibles con .NET, como C#, VB.NET y J#, entre otros. Aspose.PSD puede utilizarse con cualquier tipo de aplicación, desde aplicaciones web ASP.NET hasta aplicaciones de escritorio de Windows. Aspose.PSD proporciona demos completas y ejemplos funcionales escritos en C#. Estas demos ayudan a los desarrolladores a comprender rápidamente las funcionalidades del componente.

## Soporte técnico {#technical-support}
  
Aspose ofrece soporte técnico ilimitado y gratuito para todos sus productos. Este soporte está disponible para todos los usuarios, incluidos los que utilizan versiones de evaluación.

Si necesita ayuda con Aspose.PSD, considere lo siguiente:  

- El canal principal para obtener soporte es el <a href="https://forum.conholdate.com/" target="_blank">Foro de Conholdate</a>. Publique su pregunta en el <a href="https://forum.conholdate.com/" target="_blank">Foro de soporte de Conholdate.PSD</a> y será respondida en cuestión de pocas horas.
- Tenga en cuenta que Aspose no proporciona soporte técnico por teléfono. El soporte telefónico solo está disponible para consultas relacionadas con ventas y compras.
- Al esperar una respuesta en los foros, tenga en cuenta las diferencias de zona horaria.

Si tiene un problema con Aspose.PSD, siga estos sencillos pasos para asegurarse de que se resuelva de la manera más eficiente:  

- Asegúrese de utilizar la versión más reciente de Aspose.PSD antes de informar el problema; consulte <a href="https://www.nuget.org/packages/Aspose.PSD/" target="_blank" rel="nofollow noopener noreferrer">Descargas de Aspose.PSD para .NET</a> para conocer la versión más reciente.
- Revise los foros, esta documentación y la Referencia de la API antes de informar el problema; es posible que su pregunta ya haya sido respondida.
- Al informar un problema, incluya el documento o muestra original y, posiblemente, un fragmento de su código que cause el problema. Si necesita adjuntar varios archivos, comprímalos en un solo archivo ZIP. Es seguro adjuntar sus documentos en Aspose.Forums si el hilo está marcado/creado como Privado, ya que solo usted y los desarrolladores de Aspose tendrán acceso a los archivos adjuntos.
- Intente informar un solo problema por hilo. Si tiene otro problema, infórmelo en un hilo independiente.

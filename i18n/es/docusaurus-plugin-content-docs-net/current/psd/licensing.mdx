## Limitaciones de la versión de evaluación  {#evaluation-version-limitations}
  
Puede descargar una versión de evaluación de Aspose.PSD para .NET desde <a href="https://www.nuget.org/packages/Aspose.psd/" target="_blank" rel="nofollow noopener noreferrer">NuGet</a>. La versión de evaluación ofrece las mismas funcionalidades que la versión completamente con licencia del componente, con algunas restricciones. Al adquirir Aspose.PSD, simplemente aplicando la licencia se eliminan todas las restricciones de la versión de evaluación instalada. La versión de evaluación de Aspose.PSD para .NET proporciona toda la funcionalidad del producto, con únicamente dos limitaciones:  

- **Una marca de agua en cada imagen**: Cualquier imagen que guarde, modifique o exporte incluirá una marca de agua que dice "Evaluation Only. Created with Aspose.PSD. Copyright 2010-2018 Aspose Pty Ltd.". En imágenes pequeñas, donde no cabe la marca de agua completa, se muestran dos líneas diagonales sobre la imagen en su lugar.
- **Sin soporte para la funcionalidad básica de dibujo**: En modo de evaluación, no se pueden cargar ni guardar píxeles de imagen. Para dibujar imágenes, utilice la funcionalidad avanzada de dibujo. Esta limitación afecta a las funcionalidades que dependen de la funcionalidad básica de dibujo. Aspose.PSD para .NET le permite registrar su propio formato de archivo; sin embargo, esta característica depende de la funcionalidad básica de dibujo, por lo que no tiene sentido utilizarla en modo de evaluación, ya que no puede modificar el contenido de dichos archivos.  

Si desea probar Aspose.PSD para .NET sin las limitaciones de la versión de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">Cómo obtener una licencia temporal</a> para obtener más información.  

## Sobre el archivo de licencia  {#about-the-license-file}
  
Una vez que haya terminado de evaluar Aspose.PSD, puede adquirir una licencia en <a href="https://purchase.aspose.com/default.aspx" target="_blank" rel="nofollow noopener noreferrer">el sitio web de Aspose</a>. Familiarícese con los distintos tipos de suscripción ofrecidos. Si tiene alguna pregunta, no dude en ponerse en contacto con <a href="https://company.aspose.com/contact" target="_blank" rel="nofollow noopener noreferrer">el equipo de ventas de Aspose</a>. Cada licencia de Aspose incluye una suscripción de un año para actualizaciones de software. Transcurrido el primer año, renueve sus suscripciones para seguir recibiendo las últimas características y correcciones. El soporte técnico es gratuito, ilimitado y se proporciona tanto a usuarios con licencia como a usuarios de evaluación a través de nuestros <a href="https://forum.conholdate.com/" target="_blank">foros de soporte</a>. La licencia es un archivo XML que contiene detalles como el nombre del producto, el número de desarrolladores con licencia, la fecha de caducidad de la suscripción, etc. El archivo está firmado digitalmente, por lo que no lo modifique: incluso agregar accidentalmente un salto de línea adicional invalida el archivo. Tras adquirir Aspose.PSD, debe aplicar la licencia antes de crear, editar o manipular de cualquier otra manera las imágenes. Si olvida aplicar la licencia, todas las imágenes generadas tendrán una marca de agua de evaluación. Solo necesita configurar la licencia una vez por aplicación o proceso que desarrolle.  

## Dónde aplicar una licencia en su aplicación  {#where-to-apply-a-license-in-your-application}
  
El lugar donde debe aplicar la licencia depende del tipo de aplicación que esté desarrollando. Siga estas sencillas reglas:  

- Solo aplique la licencia una vez por dominio de aplicación. Llamar a License.SetLicense varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Aplique la licencia antes de llamar a cualquier clase de Aspose.PSD para .NET.
- **Aplicaciones Windows Forms o de consola**: llame a License.SetLicense en el código de inicio, antes de utilizar ninguna clase de Aspose.PSD para .NET.
- **Aplicaciones ASP.NET**: llame a License.SetLicense desde el archivo Global.asax.cs (Global.asax.vb), dentro del método protegido Application_Start. De esta forma, se ejecuta una única vez al iniciar la aplicación. No llame a License.SetLicense dentro de los métodos Page_Load, ya que la licencia se cargará cada vez que se cargue una página web.
- **Aplicaciones Silverlight**: llame a License.SetLicense desde el evento Application_Startup en el archivo App.xaml.cs (App.xaml.vb).
- **Biblioteca de clases**: llame a License.SetLicense desde un constructor estático de la clase que utilice Aspose.PSD. El constructor estático se ejecuta antes de que se cree una instancia de su clase, garantizando que la licencia de Aspose.PSD se configure correctamente.  

## Aplicación de una licencia  {#applying-a-license}
  
Puede descargar fácilmente una versión de evaluación de Aspose.PSD desde la página de <a href="https://www.nuget.org/packages/Aspose.psd/" target="_blank" rel="nofollow noopener noreferrer">descarga de NuGet</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia de Aspose.PSD. Además, la versión de evaluación simplemente se convierte en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.  

### Uso de un archivo o un flujo  {#using-a-file-or-a-stream}
  
Si desea evitar las limitaciones de la versión de evaluación, debe configurar una licencia antes de utilizar Aspose.PSD. Solo necesita configurar la licencia una vez por aplicación (o proceso).  

### Aplicación de una licencia desde un archivo  {#applying-a-license-from-a-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.PSD.dll. Luego puede especificar el nombre del archivo en el código en lugar de la ruta completa.

```java
 // Instantiate an instance of license and apply the license using a full path

Aspose.PSD.License license = new Aspose.PSD.License();

license.SetLicense("Aspose.PSD.lic");
```

Cuando llame al método `SetLicense`, el nombre de la licencia debe coincidir exactamente con el nombre de su archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a `"Aspose.PSD.lic.xml"`, debe utilizar este nombre de licencia para el método `SetLicense`.

### Aplicación de una licencia mediante un flujo  {#applying-a-license-using-a-stream}
  
También es posible cargar una licencia desde un flujo, como se muestra a continuación.

```java
// Instantiate an instance of license and apply the license using a stream

Aspose.PSD.License license = new Aspose.PSD.License();

license.SetLicense(myStream);
```

### Verificación del estado de la licencia {#checking-the-license-status}
  
La clase `Aspose.PSD.License` tiene la propiedad `IsLicensed`, que devolverá `true` si la licencia se ha configurado correctamente.

```java
 License license = new License();

license.SetLicense(licensePath);

if (license.IsLicensed)

{

    Console.WriteLine("License is Set!");

}
```

### Uso de un recurso incrustado  {#using-an-embedded-resource}
  
Una forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama a Aspose.PSD. Para incluir el archivo de licencia como un recurso incrustado:  

1. En Visual Studio .NET, haga clic en el menú **Archivo** y seleccione **Agregar elemento existente**.
2. Incluya el archivo de licencia (extensión .lic) en el proyecto.
3. Seleccione el archivo en el Explorador de soluciones.
4. En la ventana Propiedades, establezca **Acción de compilación** en **Recurso incrustado**.  

No es necesario llamar a los métodos `GetExecutingAssembly` o `GetManifestResourceStream` de `System.Reflection.Assembly` en el marco de trabajo de Microsoft .NET para acceder a una licencia incrustada. En su lugar, incruste el archivo como recurso en el proyecto y luego pase el nombre del archivo de licencia al método `SetLicense`. La clase `License` encuentra automáticamente el archivo de licencia en los recursos incrustados. El ejemplo siguiente muestra cómo incluir la licencia como un recurso incrustado y aplicarla a su aplicación.

```java
 // Instantiate the License class

Aspose.PSD.License license = new Aspose.PSD.License();



// Pass the name of the embedded license file

license.SetLicense("Aspose.PSD.lic");
```

{

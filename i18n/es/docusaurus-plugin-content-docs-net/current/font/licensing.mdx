## Evaluar Aspose.Font {#evaluate-asposefont}
  
Puede descargar fácilmente el producto Aspose.Font para .NET con fines de evaluación. Consulte la página de descarga de <a href="https://www.nuget.org/packages/Aspose.Font/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Font para .NET</a> para conocer la versión más reciente. La versión de evaluación es idéntica a la versión comprada. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia.

### Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
La versión de evaluación de Aspose.Font (sin una licencia especificada) proporciona toda la funcionalidad del producto, excepto algunas limitaciones propias de la evaluación. La versión de evaluación solo admite el trabajo con las siguientes fuentes:  

- CFF
- Tipos de fuentes Type1 y Montserrat
- Noto Sans JP
- Merriweather
- Lora
- Source Code Pro
- Fuentes TTF  

Si desea probar Aspose.Font sin limitaciones de evaluación, solicite una licencia temporal de 30 días. Consulte <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">¿Cómo obtener una licencia temporal?</a> para obtener más información.

## Aplicar una licencia {#applying-a-license}
  
Una vez que esté satisfecho con su evaluación de Aspose.Font para .NET, adquiera una licencia en el sitio web de Aspose: <a href="https://purchase.conholdate.com/pricing/?" target="_blank">Portal de compra</a>. Familiarícese con los distintos tipos de licencias disponibles. Si tiene alguna pregunta, <a href="https://about.conholdate.com/contact" target="_blank">comuníquese con el equipo de ventas de Conholdate</a> y con gusto le ayudarán.

Cada licencia de Aspose incluye una suscripción gratuita de un año para recibir actualizaciones a cualquier nueva versión o corrección publicada durante ese período. Proporcionamos soporte técnico gratuito e ilimitado tanto a usuarios con licencia como a usuarios en evaluación.

La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, la cantidad de desarrolladores con licencia, la fecha de vencimiento de la suscripción, entre otros. El archivo está firmado digitalmente, por lo tanto, no lo modifique: incluso agregar un salto de línea adicional invalida el archivo.

### Cuándo aplicar una licencia {#when-to-apply-a-license}
  
Siga estas reglas sencillas:  

- La licencia solo necesita configurarse una vez por dominio de aplicación.
- Debe configurar la licencia antes de usar cualquier otra clase de Aspose.Font.
- Llamar a SetLicense varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Si está desarrollando una aplicación de Windows Forms o de consola, llame a SetLicense en el código de inicio, antes de usar las clases de Aspose.Font.
- Al desarrollar una aplicación ASP.NET, llame a SetLicense desde el archivo Global.asax.cs, en el método protegido Application_Start. Este método se ejecuta una sola vez al iniciar la aplicación.
- No llame a SetLicense dentro de los métodos Page_Load, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
- Si está desarrollando una biblioteca de clases, llame a SetLicense desde un constructor estático de la clase que utiliza Aspose.Font. El constructor estático se ejecuta antes de que se cree una instancia de su clase, garantizando así que la licencia de Aspose.Font se configure correctamente.

### Aplicar licencia mediante archivo u objeto de flujo {#apply-license-using-file-or-stream-object}
  
Utilice el método <a href="https://reference.aspose.com/font/net/aspose.font/license/" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense</a> para licenciar el componente. La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Font.dll y especificar el nombre de archivo (sin ruta) como se muestra a continuación.

#### Cargar una licencia desde un archivo {#loading-a-license-from-file}
  
Este fragmento de código inicializa una licencia almacenada en un archivo o en un recurso incrustado.

```java
// Apply a License from a File

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.Font.Net.lic");

Aspose.Font.License license = new License();
license.SetLicense(licenseFilePath);
```

#### Carga de una licencia desde un objeto Stream {#loading-a-license-from-a-stream-object}
  
Estos fragmentos de código inicializan la licencia desde un stream.

```java
// Apply a License from the Stream Object

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.Font.Net.lic");
FileStream licenseStream = new FileStream(licenseFilePath, FileMode.Open);

Aspose.Font.License license = new License();
license.SetLicense(licenseStream);
licenseStream.Close();
```

## Información general {#overview}
  
Si alguna vez ha deseado contar con la funcionalidad de renderizar texto en una imagen, este artículo le enseñará cómo hacerlo con fuentes de cualquier formato admitido por la biblioteca Font mediante la solución Aspose.Font API. La biblioteca le permite convertir fácilmente texto en imágenes, así como agregar texto a cualquier imagen.

## Renderizado de texto {#rendering-text}
  
Para insertar texto en una imagen, deberá utilizar el método <a href="https://reference.aspose.com/font/net/aspose.font.renderers/renderingutils/drawtext/#drawtext" target="_blank" rel="nofollow noopener noreferrer">*DrawText*</a> de la clase <a href="https://reference.aspose.com/font/net/aspose.font.renderers/renderingutils/" target="_blank" rel="nofollow noopener noreferrer">*RenderingUtils*</a>. El ejemplo siguiente renderiza «Hello world» en Verdana y guarda el flujo PNG devuelto como `Text.png`.

Establezca `DataDir` en el directorio que contiene `TTF/verdana.ttf` y `TTF/LatoWeb-Regular.ttf`, y establezca `OutputDir` en un directorio de salida existente. Los ejemplos utilizan `Aspose.Font`, `Aspose.Font.Sources`, `Aspose.Font.Renderers`, `System` y `System.IO`. En el proyecto de prueba, estos directorios y la configuración de la licencia son proporcionados por `BaseTests`.

```java
// Render text to a PNG image

string fontPath = Path.Combine(DataDir, "TTF", "verdana.ttf");
Font font = Font.Open(new FontDefinition(FontType.TTF, "ttf", new FileSystemStreamSource(fontPath)));
string text = "Hello world";
string outFile = Path.Combine(OutputDir, "Text.png");
using (Stream image = RenderingUtils.DrawText(font, text, 18))
{
    image.Position = 0;
    using FileStream output = File.Create(outFile);
    image.CopyTo(output);
}
```

`DrawText()` devuelve un flujo PNG. Los ejemplos retroceden y copian ese flujo en un archivo, y luego liberan ambos flujos.

La familia de funciones para el método `DrawText()` cubre la salida de texto estándar o de texto multilínea. Sin embargo, en algunos casos, puede necesitar una salida personalizada del texto, por ejemplo, cuando desea comprimir, estirar o rotar el texto en un ángulo, o realizar alguna otra operación. En este caso, debe personalizar la salida según sus necesidades.

## Renderizado personalizado de texto {#custom-text-rendering}
  
Los siguientes ejemplos renderizan contornos de glifos utilizando `System.Drawing.Common` en Windows. Utilizan un lienzo de 960 x 720 píxeles a 300 DPI. Además de los espacios de nombres anteriores, importe `Aspose.Font.Glyphs`, `Aspose.Font.Rendering`, `Aspose.Font.RenderingPath`, `System.Drawing`, `System.Drawing.Drawing2D` y `System.Drawing.Imaging`.

Para dibujar [*glifos*](/net/font/what-is-font/glyph/), Aspose.Font utiliza uno de los métodos `RenderGlyph()` de la clase <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a>. Todos estos métodos sobrecargados se declaran en la interfaz <a href="https://reference.aspose.com/font/net/aspose.font.renderers/iglyphrenderer/" target="_blank" rel="nofollow noopener noreferrer">*IGlyphRenderer*</a>.

Como parámetro, debemos pasar a estos métodos una referencia a la fuente, el *glyphId* o el índice del glifo, y las coordenadas de salida del glifo. Para transferir el último parámetro, se utiliza una matriz especial representada por el objeto <a href="https://reference.aspose.com/font/net/aspose.font/transformationmatrix/" target="_blank" rel="nofollow noopener noreferrer">*TransformationMatrix*</a> de Aspose.Font. A continuación mostramos cómo utilizar objetos del tipo <a href="https://reference.aspose.com/font/net/aspose.font/transformationmatrix/" target="_blank" rel="nofollow noopener noreferrer">*TransformationMatrix*</a> para pasar las coordenadas de salida del glifo a los métodos de la familia `RenderGlyph()`.

Por lo tanto, para dibujar un glifo, debemos crear un objeto del tipo <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a>. Sin embargo, dicho objeto no puede dibujar un glifo por sí solo; requiere funcionalidad externa, la cual está descrita por la interfaz <a href="https://reference.aspose.com/font/net/aspose.font.rendering/iglyphoutlinepainter/" target="_blank" rel="nofollow noopener noreferrer">*IGlyphOutlinePainter*</a>. Para utilizar el objeto <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a>, debe proporcionarse una implementación de la interfaz <a href="https://reference.aspose.com/font/net/aspose.font.rendering/iglyphoutlinepainter/" target="_blank" rel="nofollow noopener noreferrer">*IGlyphOutlinePainter*</a>.

A continuación puede ver una implementación sencilla de esta interfaz. Crearemos la clase *GlyphOutlinePainter*, la cual requiere un objeto del tipo <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath?view=dotnet-plat-ext-7.0" target="_blank" rel="nofollow noopener noreferrer">*System.Drawing.Drawing2D.GraphicsPath*</a> para fines de dibujo gráfico.

La implementación de la interfaz se muestra a continuación. Agregue las sobrecargas `CustomDrawText()` y el método `FontWidthToImageWidth()` que se muestran más adelante como miembros de esta clase `GlyphOutlinePainter`. El proyecto de ejemplo ubica estos miembros en una segunda declaración parcial de la misma clase.

```java
// Implement a glyph outline painter

public partial class GlyphOutlinePainter : IGlyphOutlinePainter
{
    private readonly GraphicsPath path;
    private PointF currentPoint;

    public GlyphOutlinePainter(GraphicsPath path)
    {
        this.path = path;
    }

    public void MoveTo(MoveTo moveTo)
    {
        path.CloseFigure();
        currentPoint = new PointF((float)moveTo.X, (float)moveTo.Y);
    }

    public void LineTo(LineTo lineTo)
    {
        var next = new PointF((float)lineTo.X, (float)lineTo.Y);
        path.AddLine(currentPoint, next);
        currentPoint = next;
    }

    public void CurveTo(CurveTo curveTo)
    {
        var next = new PointF((float)curveTo.X3, (float)curveTo.Y3);
        path.AddBezier(currentPoint, new PointF((float)curveTo.X1, (float)curveTo.Y1),
            new PointF((float)curveTo.X2, (float)curveTo.Y2), next);
        currentPoint = next;
    }

    public void ClosePath()
    {
        path.CloseFigure();
    }
}
```

Tras la implementación de <a href="https://reference.aspose.com/font/net/aspose.font.rendering/iglyphoutlinepainter/" target="_blank" rel="nofollow noopener noreferrer">*IGlyphOutlinePainter*</a>, podemos utilizar objetos de su tipo para representar un glifo individual pasándolos al <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a> y llamando a los métodos sobrecargados correspondientes de la familia `RenderGlyph()`.

Para representar una cadena de texto, debemos obtener el *glyphId* para cada carácter y, a continuación, utilizando un objeto del tipo <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a>, llamar a uno de los métodos de la familia `RenderGlyph()`, pasando las coordenadas del glifo correspondiente.

Veamos un ejemplo de salida de una línea de texto utilizando la biblioteca Aspose.Font. Este ejemplo se implementará en forma del método `CustomDrawText()`, que acepta los siguientes parámetros: *CustomDrawText*(string text, IFont font, double fontSize, Brush backgroundBrush, Brush textBrush, string outFile).

Cree el método `CustomDrawText()`, que dibuja el texto especificado en un objeto <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.bitmap?view=dotnet-plat-ext-7.0" target="_blank" rel="nofollow noopener noreferrer">*System.Drawing.Bitmap*</a> y guarda la imagen resultante en disco.

Esto incluirá los siguientes pasos:

- Iterar sobre todos los símbolos de la cadena de texto.
- Obtener el identificador de glifo (gid) para cada símbolo procesado.
- Crear un objeto del tipo *GlyphOutlinePainter*, necesario para que el subsistema de representación dibuje el glifo actual.
- Crear un objeto del tipo <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*Aspose.Font.Renderers.GlyphOutlineRenderer*</a> y pasar el objeto *GlyphOutlinePainter* recién creado al constructor de <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a>. Este objeto <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a> está destinado a representar los glifos especificados.
- Representar el glifo actual mediante *GlyphOutlineRenderer.RenderGlyph()*. Una *TransformationMatrix* especifica sus coordenadas, y el parámetro *gid* identifica el glifo.

**Pasos auxiliares para esta estrategia**

- En modo horizontal, las coordenadas de la línea base del glifo en el eje 'Y' permanecen constantes; en modo vertical, se incrementan para cada glifo subsiguiente.
- En modo horizontal, la coordenada 'X' avanza según el ancho del glifo anterior y la corrección de emparejamiento (kerning), multiplicados por el coeficiente de espaciado.
- Ambas coordenadas, 'X' e 'Y', se pasan al objeto *TransformationMatrix* utilizado por <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a> para dibujar los glifos.
- El avance horizontal se calcula para cada glifo subsiguiente; en modo vertical, la coordenada X se mantiene fija.
- El objeto del tipo <a href="https://reference.aspose.com/font/net/aspose.font.renderers/glyphoutlinerenderer/" target="_blank" rel="nofollow noopener noreferrer">*GlyphOutlineRenderer*</a> dibuja los glifos mediante *GlyphOutlinePainter*, no directamente en el Bitmap, sino en un objeto <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath?view=dotnet-plat-ext-7.0" target="_blank" rel="nofollow noopener noreferrer">*GraphicsPath*</a> pasado al constructor de *GlyphOutlinePainter*; por lo tanto, utilizamos un objeto del tipo <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.graphics?view=dotnet-plat-ext-7.0" target="_blank" rel="nofollow noopener noreferrer">*System.Drawing.Graphics*</a> para dibujar <a href="https://learn.microsoft.com/en-us/dotnet/api/system.drawing.drawing2d.graphicspath?view=dotnet-plat-ext-7.0" target="_blank" rel="nofollow noopener noreferrer">*GraphicsPath*</a> en el Bitmap.
- El método *FontWidthToImageWidth()* convierte el ancho del glifo desde unidades de fuente a píxeles.

La primera sobrecarga crea y libera un bitmap. La segunda acepta un bitmap propiedad del llamante y admite espaciado, coordenadas, superposiciones y salida vertical. Agregue ambas sobrecargas a continuación en `GlyphOutlinePainter`:

```java
// Render text with spacing, coordinates, overlays and vertical layout

public static void CustomDrawText(string text, IFont font, double fontSize,
    Brush backgroundBrush, Brush textBrush, string outFile)
{
    using var bitmap = new Bitmap(960, 720);
    CustomDrawText(text, font, fontSize, backgroundBrush, textBrush, outFile, bitmap);
}

public static void CustomDrawText(string text, IFont font, double fontSize,
    Brush backgroundBrush, Brush textBrush, string outFile, Bitmap bitmap,
    double kerningCoefficient = 1, double coordinateX = 0, double coordinateY = 0, bool topDown = false)
{
    const double dpi = 300;
    double scale = fontSize * dpi / 72;
    bitmap.SetResolution((float)dpi, (float)dpi);
    using (Graphics graphics = Graphics.FromImage(bitmap))
    {
        // A transparent background preserves an existing image for overlays.
        graphics.FillRectangle(backgroundBrush, 0, 0, bitmap.Width, bitmap.Height);
        graphics.SmoothingMode = SmoothingMode.HighQuality;
        GlyphId? previousGid = null;
        double glyphXCoordinate = coordinateX;
        double glyphYCoordinate = coordinateY + scale;

        foreach (char character in text)
        {
            GlyphId gid = font.Encoding.DecodeToGid(character);
            if (gid == null) continue;
            Glyph glyph = font.GlyphAccessor.GetGlyphById(gid);
            if (glyph == null) continue;

            if (previousGid != null)
            {
                if (topDown)
                    glyphYCoordinate += scale;
                else
                {
                    double advance = FontWidthToImageWidth(font.Metrics.GetGlyphWidth(previousGid),
                        glyph.SourceResolution, fontSize, dpi);
                    double kerning = font.Metrics.GetKerningValue(previousGid, gid)
                        / (double)glyph.SourceResolution * scale;
                    // Like the source example, the coefficient scales the whole advance.
                    glyphXCoordinate += (advance + kerning) * kerningCoefficient;
                }
            }

            using var path = new GraphicsPath();
            var painter = new GlyphOutlinePainter(path);
            var renderer = new GlyphOutlineRenderer(painter);
            var matrix = new TransformationMatrix(new double[]
            {
                scale, 0, 0, -scale, glyphXCoordinate, glyphYCoordinate
            });
            renderer.RenderGlyph(font, gid, matrix);
            path.FillMode = FillMode.Winding;
            graphics.FillPath(textBrush, path);
            previousGid = gid;
        }
    }
    // The caller owns the supplied bitmap and may reuse it for another overlay.
    bitmap.Save(outFile, ImageFormat.Png);
}
```

### Kerning {#kerning}
  
El asistente obtiene el ajuste de parejas (kerning) de la fuente. Establecer `kerningCoefficient` en `1.25` incrementa el avance horizontal total (el ancho del glifo anterior más el ajuste de parejas) en un 25%. Este ejemplo utiliza Verdana y guarda `IncreasedSpacing.png`:

```java
// Increase the horizontal glyph advance

string fontPath = Path.Combine(DataDir, "TTF", "verdana.ttf");
Font font = Font.Open(new FontDefinition(FontType.TTF, "ttf", new FileSystemStreamSource(fontPath)));
string outFile = Path.Combine(OutputDir, "IncreasedSpacing.png");
using var bitmap = new Bitmap(960, 720);
GlyphOutlinePainter.CustomDrawText("Hello world", font, 18, Brushes.White, Brushes.Black,
    outFile, bitmap, kerningCoefficient: 1.25);
```

### Renderizado de texto por coordenadas {#rendering-text-by-coordinates}
  
Utilice `coordinateX` y `coordinateY` para posicionar el texto. `coordinateY` es el desplazamiento por encima de la primera línea de base; el asistente agrega `fontSize * 300 / 72` píxeles. A 18 puntos, `coordinateX: 300` y `coordinateY: 225` colocan la primera línea de base en (300, 300). El ejemplo guarda `PositionedText.png`:

```java
// Position text at explicit coordinates

string fontPath = Path.Combine(DataDir, "TTF", "verdana.ttf");
Font font = Font.Open(new FontDefinition(FontType.TTF, "ttf", new FileSystemStreamSource(fontPath)));
string outFile = Path.Combine(OutputDir, "PositionedText.png");
using var bitmap = new Bitmap(960, 720);
// At 18 points and 300 DPI the 75-pixel baseline offset makes the baseline Y=300.
GlyphOutlinePainter.CustomDrawText("Hello world", font, 18, Brushes.White, Brushes.Black,
    outFile, bitmap, coordinateX: 300, coordinateY: 225);
```

### Cómo agregar texto a una imagen  {#how-to-add-the-text-to-an-image}
  
Puede agregar texto a una imagen existente pasando un mapa de bits y un pincel de fondo transparente al auxiliar compartido. El pincel transparente conserva los píxeles existentes.

La sobrecarga de mapa de bits de `CustomDrawText()` mostrada anteriormente ya admite este escenario. Dibuja sobre el mapa de bits proporcionado y lo guarda como PNG; el llamador conserva la propiedad del mapa de bits.

El ejemplo primero crea `OverlayBase.png` en `OutputDir`, luego abre esa imagen para agregar una sombra gris y una anotación marrón. Guarda `Shadow.png` y `ShadowAnnotated.png` por separado; no se requiere ninguna imagen de entrada externa:

```java
// Add a shadow and annotation to an existing image

string fontPath = Path.Combine(DataDir, "TTF", "verdana.ttf");
Font font = Font.Open(new FontDefinition(FontType.TTF, "ttf", new FileSystemStreamSource(fontPath)));
string inputImagePath = Path.Combine(OutputDir, "OverlayBase.png");
GlyphOutlinePainter.CustomDrawText("Hello world", font, 17, Brushes.White, Brushes.Black, inputImagePath);
using var bitmap = new Bitmap(inputImagePath);
string shadowFile = Path.Combine(OutputDir, "Shadow.png");
GlyphOutlinePainter.CustomDrawText("Hello world", font, 17, Brushes.Transparent, Brushes.Gray,
    shadowFile, bitmap, coordinateX: -3);
string annotatedFile = Path.Combine(OutputDir, "ShadowAnnotated.png");
GlyphOutlinePainter.CustomDrawText("<= Shadow effect", font, 17, Brushes.Transparent, Brushes.Brown,
    annotatedFile, bitmap, coordinateX: 400);
```

### Generación del texto de arriba hacia abajo {#outputting-the-text-from-top-to-bottom}
  
La misma sobrecarga de mapa de bits admite la salida vertical mediante `topDown: true`. Coloca el primer glifo en la línea base inicial y avanza los glifos subsiguientes en `fontSize * 300 / 72` píxeles.

El ejemplo renderiza «Top down» en Verdana en X=400 y guarda `TopDown.png`. Con `coordinateY` en cero y una fuente de 18 puntos, la primera línea base se encuentra en Y=75 píxeles:

```java
// Render text vertically from top to bottom

string fontPath = Path.Combine(DataDir, "TTF", "verdana.ttf");
Font font = Font.Open(new FontDefinition(FontType.TTF, "ttf", new FileSystemStreamSource(fontPath)));
string outFile = Path.Combine(OutputDir, "TopDown.png");
using var bitmap = new Bitmap(960, 720);
GlyphOutlinePainter.CustomDrawText("Top down", font, 18, Brushes.White, Brushes.Black,
    outFile, bitmap, coordinateX: 400, topDown: true);
```

### Información adicional {#additional-information}
  
El auxiliar utiliza **300 DPI**. El valor `scale = fontSize * dpi / 72` convierte el tamaño de fuente en puntos a píxeles. `glyphXCoordinate` y `glyphYCoordinate` especifican la posición de la línea base del glifo. Para texto horizontal, la siguiente posición incluye el ancho del glifo anterior y el espaciado de pareja devuelto por la fuente; `kerningCoefficient` escala su suma.

## Prueba gratuita o licencia temporal {#free-trial-or-temporary-license}
  
Puede probar GroupDocs.Editor sin adquirir una licencia.

### Prueba gratuita {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida; simplemente, la versión de evaluación se convierte en una versión con licencia cuando establece la licencia. Puede configurar la licencia de varias maneras, descritas en las siguientes secciones de este artículo.

La versión de evaluación incluye las siguientes limitaciones:  

- Solo se procesan las primeras 2 páginas.
- Se colocan marcas de prueba en la parte superior de cada página del documento.

### Licencia temporal {#temporary-license}
  
Si desea probar GroupDocs.Editor sin las limitaciones de la versión de prueba, también puede solicitar una Licencia temporal de 30 días. Para obtener más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">«Obtener una licencia temporal»</a>.

## Cómo establecer una licencia {#how-to-set-a-license}
  
El archivo de licencia contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional invalidará el archivo. Debe establecer una licencia antes de utilizar la API de GroupDocs.Editor si desea evitar sus limitaciones de evaluación.

La licencia puede cargarse desde un archivo o un objeto de flujo (stream). La forma más sencilla de establecer la licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Editor.dll y especificar el nombre del archivo (sin ruta), como se muestra en los ejemplos siguientes.

### Establecer licencia desde un archivo {#setting-license-from-file}
  
El siguiente código explica cómo establecer la licencia del producto.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET
// Setup license.
License license = new License();
license.SetLicense(licensePath);
```

### Configuración de licencia desde un flujo  {#setting-license-from-stream}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET
using (FileStream fileStream = File.OpenRead("GroupDocs.Editor.lic"))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```


:::info
Llamar a <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/license" target="_blank" rel="nofollow noopener noreferrer">License</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/license/setlicense" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a> varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, invoque `License.SetLicense` en su código de inicio, antes de utilizar las clases de GroupDocs.Editor.  
Al desarrollar una aplicación ASP.NET, puede invocar `License.SetLicense` desde el archivo Global.asax.cs (Global.asax.vb), dentro del método protegido `Application_Start`. Este método se ejecuta una única vez al iniciar la aplicación.  
No invoque <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/license" target="_blank" rel="nofollow noopener noreferrer">License</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/license/setlicense" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a> dentro de los métodos `Page_Load`, ya que esto implica que la licencia se cargará cada vez que se cargue una página web.
:::


### Configuración de la licencia medible {#setting-metered-license}


:::info
También puede configurar <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como licencia alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean ser facturados según el uso de las características de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en uso</a>.
:::

A continuación se presentan los pasos sencillos para utilizar la clase `Metered`.  

1. Crear una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
2. Pasar las claves pública y privada al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered/setmeteredkey" target="_blank" rel="nofollow noopener noreferrer">SetMeteredKey</a>.
3. Realizar el procesamiento (ejecutar la tarea).
4. Llamar al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered/getconsumptionquantity" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionQuantity</a> de la clase `Metered`.
5. Este método devolverá la cantidad de solicitudes a la API que ha consumido hasta el momento.
6. Llamar al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered/getconsumptioncredit" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionCredit</a> de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
7. Este método devolverá el crédito que ha consumido hasta el momento.  

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Editor.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Editor.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

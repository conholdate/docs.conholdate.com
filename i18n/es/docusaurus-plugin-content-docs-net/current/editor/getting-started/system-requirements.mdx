## Información general  {#overview}
  
GroupDocs.Editor para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/editor/getting-started/installation/).

## Sistemas operativos compatibles  {#supported-operating-systems}
  
GroupDocs.Editor para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado el framework .NET o Mono, incluidos, entre otros:

### Windows  {#windows}  

* Microsoft Windows Server 2003 (x64, x86)
* Microsoft Windows Server 2008 (x64, x86)
* Microsoft Windows Server 2012 (x64, x86)
* Microsoft Windows Server 2012 R2 (x64, x86)
* Microsoft Windows Server 2016 (x64, x86)
* Microsoft Windows Server 2019 (x64, x86)
* Microsoft Windows Vista (x64, x86)
* Microsoft Windows 7 (x64, x86)
* Microsoft Windows 8, 8.1 (x64, x86)
* Microsoft Windows 10 (x64, x86)
* Microsoft Azure  

### Linux  {#linux}  

* Linux (Ubuntu, OpenSUSE, CentOS y otros)  

### Mac  {#mac}  

* Mac OS X  

## Frameworks compatibles  {#supported-frameworks}
  
GroupDocs.Editor para .NET es compatible con los frameworks .NET y Mono, según se indica a continuación:

### .NET Standard 2.0  {#net-standard-2-0}
  
Cualquier tipo de aplicación .NET Standard 2.0 es compatible.

### Frameworks .NET  {#net-frameworks}
  

* .NET Framework 4.6.1
* .NET Framework 4.6.2
* .NET Framework 4.7.0
* .NET Framework 4.7.1
* .NET Framework 4.7.2
* .NET Framework 4.8.0
* .NET Standard 2.0
* .NET Standard 2.1
* .NET Core 2.1
* .NET Core 2.2
* .NET Core 3.0
* .NET Core 3.1
* .NET 5.0
* .NET 6.0  

### Framework Mono  {#mono-framework}  

* Mono 2.6.7 o posterior  

## Entornos de desarrollo  {#development-environments}
  
GroupDocs.Editor para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET; sin embargo, los entornos explícitamente compatibles son los siguientes:  

* Microsoft Visual Studio 2010
* Microsoft Visual Studio 2011
* Microsoft Visual Studio 2012
* Microsoft Visual Studio 2013
* Microsoft Visual Studio 2015
* Microsoft Visual Studio 2017
* Microsoft Visual Studio 2019
* Microsoft Visual Studio 2022
* Xamarin.Android
* Xamarin.iOS
* Xamarin.Mac
* MonoDevelop 2.4 o posterior

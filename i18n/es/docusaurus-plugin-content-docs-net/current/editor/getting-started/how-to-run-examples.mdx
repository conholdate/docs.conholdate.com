Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de GroupDocs.Editor, ya sea construyendo los suyos propios o utilizando directamente nuestros ejemplos de backend o frontend.

Elija una opción de la siguiente lista:

## Construir el proyecto desde cero {#build-project-from-scratch}

* Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
* Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
* Instale **GroupDocs.Editor para .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/editor/getting-started/installation/).
* Desarrolle su primera aplicación con **GroupDocs.Editor para .NET**, como se muestra a continuación:

```csharp
string documentPath = @"C:\sample.docx"; // NOTE: Put here actual path for your document
using (Editor editor = new Editor(documentPath))
{
    // Obtain editable document from original DOCX document
    WordProcessingEditOptions editOptions = new WordProcessingEditOptions();
    EditableDocument editableDocument = editor.Edit(editOptions);

    // Pass EditableDocument object to WYSIWYG editor and edit there...
    // ...

    // Save edited EditableDocument object to some WordProcessing format - DOC for example
    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(Formats.WordProcessingFormats.Docx);
    editor.Save(editableDocument, @"C:\output\edited.docx", saveOptions);
}
```

* Compile y ejecute su proyecto.
* Las páginas de documentos renderizadas aparecerán en el directorio *"C:\\output\\"*.

## Ejecute los ejemplos del backend {#run-back-end-examples}

El paquete completo de ejemplos de **GroupDocs.Editor** está alojado en <a href="https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando su cliente de Git favorito.  
En caso de que descargue el archivo ZIP, extraiga las carpetas en su disco local. Los archivos y carpetas extraídos tendrán el aspecto que se muestra en la siguiente imagen:

![](/net/editor/images/how-to-run-examples.png)

En los archivos y carpetas extraídos, puede encontrar el archivo de solución de C#. El proyecto se creó con **Microsoft Visual Studio 2019**. La carpeta **Resources** contiene todos los archivos de documentos y imágenes de ejemplo utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias faltantes de **GroupDocs.Editor**, consulte [Entorno de desarrollo, instalación y configuración](/net/editor/getting-started/installation/). Todas las funciones se invocan desde **RunExamples.cs**.
Descomente la función que desea ejecutar y comente el resto.

![](/net/editor/images/how-to-run-examples_1.png)

Puede ejecutar el <a href="https://github.com/groupdocs-editor/GroupDocs.Editor-for-.NET-MVC" target="_blank" rel="nofollow noopener noreferrer">Ejemplo de GroupDocs.Editor para .NET MVC</a> siguiendo estos pasos:

## Ejecutar desde Docker {#run-from-docker}

Utilice la imagen de <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> para probar las funcionalidades de GroupDocs.Editor de forma sencilla. A continuación se muestran los comandos para ejecutar GroupDocs.Editor a partir de la imagen de Docker.

```csharp
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples -v `pwd`/Licenses:/home/groupdocs/app/Licenses groupdocs/Editor
## Open http://localhost:8080/editor in your favorite browser.
```

Para contribuir, puede bifurcar (fork) el repositorio, editar el código y crear una solicitud de extracción (pull request). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

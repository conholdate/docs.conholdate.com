Esta guía muestra cómo crear un nuevo documento en blanco en un formato específico utilizando la clase `Editor` de GroupDocs.Editor para .NET.

Es posible crear un nuevo documento en blanco en todos los formatos de documento principales, incluidos documentos de texto (DOCX), libros de cálculo (XLSX), presentaciones (PPTX), libros electrónicos (EPUB) y correos electrónicos (EML). Consulte la lista completa de <a href="https://docs.groupdocs.com/editor/net/supported-document-formats/" target="_blank" rel="nofollow noopener noreferrer">formatos de documento admitidos</a> y preste atención a la columna «Crear», que indica si es posible crear un nuevo documento en un formato determinado.

## Pasos para crear y editar un documento {#steps-to-create-and-edit-a-document}
  
### 1. Crear un nuevo documento y aplicar opciones de edición {#1-create-a-new-document-and-apply-edit-options}

```csharp
using System;
using System.IO;
using GroupDocs.Editor;
using GroupDocs.Editor.Formats;
using GroupDocs.Editor.Options;


    using (Editor editor = new Editor(WordProcessingFormats.Docx))
    WordProcessingEditOptions editOptions = new WordProcessingEditOptions
    {
        EnablePagination = false,
        EnableLanguageInformation = true
    };

    EditableDocument editable = editor.Edit(editOptions);
```

### 2. Modificar el contenido HTML {#2-modify-the-html-content}

```csharp
    string html = editable.GetEmbeddedHtml();

    string updatedHtml = html.Replace(
        "<span class = \"text001\">&#xa0;</span>",
        "<span class = \"text001\">New text</span>");

    EditableDocument updatedDoc = EditableDocument.FromMarkup(updatedHtml);
```

### 3. Guardar el documento final {#3-save-the-final-document}

```csharp
    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(WordProcessingFormats.Docx);
    saveOptions.EnablePagination = true;
    using Stream memoryStream = new MemoryStream();
    editor.Save(updatedDoc, memoryStream, saveOptions);

```

## Result {#result}
  
El código crea un nuevo documento DOCX, modifica su cuerpo HTML y guarda la versión final en memoria.  
Opcionalmente, puede guardarlo en un archivo físico o devolverlo mediante una API.

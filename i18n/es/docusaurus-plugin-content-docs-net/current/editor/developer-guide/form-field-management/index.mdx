El espacio de nombres <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/formfieldmanager/" target="_blank" rel="nofollow noopener noreferrer">`GroupDocs.Editor.Words.FieldManagement`</a> proporciona clases e interfaces para la gestión y manipulación de campos de formulario dentro de documentos de Word. Esta funcionalidad permite a los usuarios interactuar programáticamente con diversos tipos de campos de formulario, incluidos campos de texto, casillas de verificación, listas desplegables y más. Este artículo cubre las características principales y el uso de la gestión de campos en GroupDocs.Editor.

## Clases e interfaces clave {#key-classes-and-interfaces}

### IFormField {#iformfield}

La interfaz <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/iformfield/" target="_blank" rel="nofollow noopener noreferrer">`IFormField`</a> representa un campo de formulario genérico y define propiedades comunes compartidas por todos los campos de formulario.

#### Propiedades {#properties}

- **Stylesheet**: Obtiene la hoja de estilos asociada al campo de formulario.
- **Readonly**: Obtiene o establece un valor que indica si el campo de formulario es de solo lectura.
- **Name**: Obtiene el nombre del campo de formulario.
- **Type**: Obtiene el tipo del campo de formulario.
- **LocaleId**: Obtiene o establece el identificador de configuración regional del campo de formulario.
- **StatusText**: Obtiene o establece el texto de estado asociado al campo de formulario.
- **HelpText**: Obtiene o establece el texto de ayuda asociado al campo de formulario.

### Tipos específicos de campos de formulario {#specific-form-field-types}

El espacio de nombres incluye varias clases que implementan `IFormField` para tipos específicos de campos de formulario:

- **<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/checkboxform/" target="_blank" rel="nofollow noopener noreferrer">`CheckBoxForm`</a>**: Representa un campo de formulario de tipo casilla de verificación.
- **<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/dropdownformfield/" target="_blank" rel="nofollow noopener noreferrer">`DropDownFormField`</a>**: Representa un campo de formulario de tipo lista desplegable con una lista de valores de tipo cadena.
- **<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/numberformfield/" target="_blank" rel="nofollow noopener noreferrer">`NumberFormField`</a>**: Representa un campo de formulario de entrada numérica.
- **<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/textformfield/" target="_blank" rel="nofollow noopener noreferrer">`TextFormField`</a>**: Representa un campo de formulario de entrada de texto.
- **<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/dateformfield/" target="_blank" rel="nofollow noopener noreferrer">`DateFormField`</a>**: Representa un campo de formulario de entrada de fecha.

### FormFieldCollection {#formfieldcollection}

La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/formfieldcollection/" target="_blank" rel="nofollow noopener noreferrer">`FormFieldCollection`</a> gestiona una colección de campos de formulario dentro de un documento. Permite enumerar, insertar y recuperar campos de formulario por su nombre.

#### Métodos {#methods}

- **Insert(IFormField field)**: Agrega un nuevo campo de formulario a la colección.
- **GetEnumerator()**: Devuelve un enumerador que recorre la colección.
- **this[string name]**: Obtiene el campo de formulario con el nombre especificado.
- **GetFormField&lt;T&gt;(string name)**: Recupera un campo de formulario del tipo `T` por su nombre.

### InvalidFormField {#invalidformfield}

La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.words.fieldmanagement/invalidformfield/" target="_blank" rel="nofollow noopener noreferrer">`InvalidFormField`</a> representa un campo de formulario inválido que requiere ser renombrado. Se utiliza en el contexto de la corrección de nombres inválidos de campos de formulario.

#### Propiedades {#properties-1}

- **Name**: Obtiene el nombre original del campo de formulario.
- **FixedName**: Obtiene o establece el nuevo nombre del campo de formulario tras la reparación. El valor predeterminado es `string.Format("{0}_fixed", name)`.

### FieldManager {#fieldmanager}

La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/formfieldmanager/" target="_blank" rel="nofollow noopener noreferrer">`FormFieldManager`</a> proporciona una interfaz de alto nivel para la gestión de campos de formulario en un documento.

#### Propiedades {#properties-2}

- **FormFieldCollection**: Obtiene la colección de campos de formulario del documento.

#### Métodos {#methods-1}

- **UpdateFormFiled(FormFieldCollection formFieldCollection)**: Actualiza los campos de formulario del documento.
- **FixInvalidFormFieldNames(IEnumerable&lt;UpdateInvalidFormFieldNames&gt; updateInvalidFormFieldNames)**: Corrige los nombres inválidos de campos de formulario en el documento.
- **HasInvalidFormFields()**: Comprueba si el documento contiene campos de formulario inválidos.
- **RemoveFormFiled(IFormField formField)**: Elimina un campo de formulario específico.
- **RemoveFormFileds(IEnumerable&lt;IFormField&gt; formFields)**: Elimina varios campos de formulario.

## Conclusión {#conclusion}

El espacio de nombres `GroupDocs.Editor.Words.FieldManagement` proporciona un conjunto potente de herramientas para gestionar campos de formulario en documentos de Word. Con estas herramientas, los desarrolladores pueden interactuar, modificar y validar programáticamente los campos de formulario, garantizando que los documentos estén correctamente formateados y libres de campos de formulario duplicados o inválidos. Para obtener más detalles, consulte la documentación oficial de <a href="/es/net/editor/getting-started/">GroupDocs.Editor para .NET</a>.

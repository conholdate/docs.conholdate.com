> Este artículo describe cómo abrir para editar un documento previamente cargado, qué opciones deben aplicarse y cómo enviar el contenido del documento al editor HTML WYSIWYG o a cualquier otra aplicación de edición.

Cuando un documento se carga en una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>, es posible abrirlo para su edición. En términos de <a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Editor**</a>, abrir un documento para editar implica crear una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> mediante la llamada al método de instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a>. Existen dos sobrecargas del método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit</a>. La primera recibe un único parámetro: un heredero de la interfaz <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/ieditoptions" target="_blank" rel="nofollow noopener noreferrer">IEditOptions</a>.  
Cada familia de formatos tiene su propia implementación de la interfaz <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/ieditoptions" target="_blank" rel="nofollow noopener noreferrer">IEditOptions</a>. A continuación se listan en la tabla siguiente.

| Familia de formatos | Ejemplos de formatos | Clase de opciones de edición |
| --- | --- | --- |
| Procesamiento de textos | DOC, DOCX, DOCM, DOT, ODT | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingeditoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingEditOptions</a> |
| Hojas de cálculo | XLS, XLSX, XLSM, XLSB | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheeteditoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetEditOptions</a> |
| Valores separados por delimitadores (DSV) | CSV, TSV | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/delimitedtexteditoptions" target="_blank" rel="nofollow noopener noreferrer">DelimitedTextEditOptions</a> |
| Presentaciones | PPT, PPTX, PPS, POT | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationEditOptions</a> |
| Documentos de texto sin formato | TXT | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions" target="_blank" rel="nofollow noopener noreferrer">TextEditOptions</a> |
| Formatos de diseño fijo | PDF | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/pdfeditoptions" target="_blank" rel="nofollow noopener noreferrer">PdfEditOptions</a> |
| Formatos de diseño fijo | XPS (incluyendo OpenXPS) | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/xpseditoptions" target="_blank" rel="nofollow noopener noreferrer">XpsEditOptions</a> |
| XML | Cualquier formato basado en XML, como CSPROJ, SVG, etc. | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/xmleditoptions" target="_blank" rel="nofollow noopener noreferrer">XmlEditOptions</a> |
| Libros electrónicos | MOBI, AZW3, ePub | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/ebookeditoptions" target="_blank" rel="nofollow noopener noreferrer">EbookEditOptions</a> |
| Correo electrónico | EML, EMLX, TNEF, MSG, HTML, MHTML, ICS, VCF, PST, MBOX, OFT | <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/emaileditoptions" target="_blank" rel="nofollow noopener noreferrer">EmailEditOptions</a> |

La segunda sobrecarga no recibe parámetros y selecciona automáticamente las opciones de edición predeterminadas más adecuadas según el formato del documento de entrada.

La instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> contiene una versión del documento de entrada, convertida a un formato intermedio interno según las opciones de edición. Una vez listo, puede generar contenido HTML, CSS y otros elementos apropiados, los cuales pueden pasarse directamente al editor WYSIWYG. A continuación se muestra un ejemplo de esto.

```csharp
string inputFilePath = "C:\\input_path\\document.docx"; //path to some document
Editor editor = new Editor(inputFilePath, new WordProcessingLoadOptions());
EditableDocument openedDocument = editor.Edit();//with default edit options

WordProcessingEditOptions editOptions = new WordProcessingEditOptions();
editOptions.EnableLanguageInformation = true;
editOptions.EnablePagination = true;

EditableDocument anotherOpenedDocument = editor.Edit(editOptions);
```

Puede generarse varias instancias de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> a partir de una única instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a> con distintas opciones de edición. Por ejemplo, para un documento de procesamiento de textos, el usuario puede invocar por primera vez el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a> con el modo paginado deshabilitado y, en una segunda invocación, con el modo paginado habilitado. En otras palabras, puede generarse varias representaciones distintas de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> a partir de un único documento original. Otro ejemplo: puede haber múltiples instancias de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> para un único documento de hoja de cálculo de entrada, donde cada instancia representa una pestaña diferente del documento de hoja de cálculo. A continuación se muestra un ejemplo de este caso.

```csharp
string inputXlsxPath = "C://input/spreadsheet.xlsx";
Editor editor = new Editor(inputXlsxPath, new SpreadsheetLoadOptions());

SpreadsheetEditOptions editOptions1 = new SpreadsheetEditOptions();
editOptions1.WorksheetIndex = 0;//index is 0-based, so this is 1st tab
editOptions1.ExcludeHiddenWorksheets = true;
  
SpreadsheetEditOptions editOptions2 = new SpreadsheetEditOptions();
editOptions2.WorksheetIndex = 1;//index is 0-based, so this is 2nd tab
editOptions2.ExcludeHiddenWorksheets = false;
  
EditableDocument firstTab = editor.Edit(editOptions1);
EditableDocument secondTab = editor.Edit(editOptions2);
```

Cuando la instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> esté lista, puede emitir marcado HTML, marcado CSS y otros recursos en distintas formas para enviarlos al editor WYSIWYG HTML del lado del cliente o a cualquier otra aplicación que pueda editar documentos HTML. A continuación se muestra brevemente un ejemplo.

```csharp
EditableDocument document = editor.Edit();
string bodyContent = document.GetBodyContent();
List<IImageResource> onlyImages = document.Images;
List<IHtmlResource> allResourcesTogether = document.AllResources;
```

Para obtener más información sobre cómo obtener el marcado HTML y los recursos de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>, visite los artículos [Obtener marcado HTML en distintas formas](/net/editor/developer-guide/editabledocument/get-html-markup-in-different-forms/), [Trabajar con recursos](/net/editor/developer-guide/editabledocument/working-with-resources/) y [Guardar HTML en una carpeta](/net/editor/developer-guide/editabledocument/save-html-to-folder/).

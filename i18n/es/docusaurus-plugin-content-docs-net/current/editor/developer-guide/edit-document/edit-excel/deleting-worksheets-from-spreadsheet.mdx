Una **hoja de cálculo**, también conocida como **libro de trabajo**, es un <a href="https://docs.fileformat.com/spreadsheet/" target="_blank" rel="nofollow noopener noreferrer">familia de formatos de documento</a>, diseñada para trabajar con datos tabulares. Los formatos <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a>, <a href="https://docs.fileformat.com/spreadsheet/xlsx/" target="_blank" rel="nofollow noopener noreferrer">XLSX</a>, <a href="https://docs.fileformat.com/spreadsheet/ods/" target="_blank" rel="nofollow noopener noreferrer">ODS</a> y <a href="https://docs.fileformat.com/spreadsheet/csv/" target="_blank" rel="nofollow noopener noreferrer">CSV</a> son ejemplos comunes de dichos formatos de documento, mientras que Microsoft Excel, LibreOffice Calc y Apache OpenOffice Calc son ejemplos de procesadores de tablas: programas que permiten crear y editar este tipo de documentos. GroupDocs.Editor permite editar documentos de hojas de cálculo existentes desde sus inicios, y a partir de la <a href="https://releases.groupdocs.com/editor/net/release-notes/2024/groupdocs-editor-for-net-24-6-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 24.6</a>, adquirió la capacidad no solo de editar hojas de cálculo ya existentes, sino también de crear nuevas hojas de cálculo desde cero. Además, a partir de la <a href="https://releases.groupdocs.com/editor/net/release-notes/2025/groupdocs-editor-for-net-25-11-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 25.11</a>, GroupDocs.Editor obtuvo la funcionalidad para eliminar hojas de cálculo del documento editado durante el guardado.

Es importante tener en cuenta que no toda hoja de cálculo necesariamente posee hojas de cálculo individuales. Por ejemplo, los formatos basados en texto y delimitados por separadores, como <a href="https://docs.fileformat.com/spreadsheet/csv/" target="_blank" rel="nofollow noopener noreferrer">CSV</a> y <a href="https://docs.fileformat.com/spreadsheet/tsv/" target="_blank" rel="nofollow noopener noreferrer">TSV</a>, son básicamente archivos de texto y no contienen hojas de cálculo, por lo que no es posible eliminar una hoja de cálculo de ellos. Sin embargo, casi todos los formatos binarios de hojas de cálculo, como XLS, XLSX y ODS, sí las poseen.

En GroupDocs.Editor, el usuario edita una hoja de cálculo a la vez: la hoja de cálculo <a href="/es/net/editor/developer-guide/load-document/">se carga</a> en el constructor de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">`Editor`</a>, luego se especifica la hoja de cálculo mediante su número en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheeteditoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetEditOptions`</a>, y finalmente el documento se convierte a un formato editable representado por la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>. Directo y sencillo. No obstante, cuando el contenido de la hoja de cálculo ha sido editado por el usuario y devuelto a la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, existen dos opciones:

1. Los usuarios pueden guardar el contenido editado de la hoja de cálculo como una nueva hoja de cálculo que contenga únicamente esta hoja. Este es el comportamiento predeterminado que ha estado presente en GroupDocs.Editor desde sus inicios.
2. Los usuarios pueden guardar la hoja de cálculo editada insertándola en la hoja de cálculo original. Esta funcionalidad se introdujo a partir de la <a href="https://releases.groupdocs.com/editor/net/release-notes/2020/groupdocs-editor-for-net-20-10-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 20.10</a> y se describe en un <a href="/es/net/editor/developer-guide/edit-document/edit-excel/inserting-edited-worksheet-into-existing-spreadsheet/">artículo independiente</a>. Esta segunda opción también cuenta con dos subopciones:
    1. The edited worksheet can *replace* the original worksheet in the input spreadsheet. For instance, in the loaded spreadsheet with 3 worksheets the user has chosen the 2nd one for edit; this worksheet was edited and then inserted back to the input spreadsheet, replacing the original 2nd worksheet onto the edited one.
    2. The edited worksheet can be inserted into the input spreadsheet to stay *together* with the original one. For instance, in the loaded spreadsheet with 3 worksheets the user has chosen the 2nd one for edit; this worksheet was edited and then inserted back to the input spreadsheet, so now the spreadsheet contains 4 worksheets: the first, fourth, and two versions of the second (original and edited).

A partir de la versión 25.11, cuando se utiliza la segunda opción (insertar la hoja de cálculo editada en el archivo de hojas de cálculo original), los usuarios también pueden eliminar hojas de cálculo específicas de este. Se agregó una nueva propiedad a la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a>: <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumbersToDelete`</a>, de tipo `int[]`. Por defecto, esta propiedad tiene el valor `null`, lo que indica que no se deben eliminar hojas de cálculo. Sin embargo, si contiene uno o más números válidos de hojas de cálculo, dichas hojas se eliminarán al invocar el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`Editor.Save()`</a>.

Cabe destacar que los números de hoja de cálculo en la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumbersToDelete`</a> son base 1. Por ejemplo, para eliminar la primera y la cuarta hoja de cálculo, la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumbersToDelete`</a> debe tener el valor `new int[2] {1, 4}`.

Con la nueva funcionalidad de eliminación de hojas de cálculo, GroupDocs.Editor ejecuta el siguiente algoritmo durante el guardado del archivo de hojas de cálculo:


1. El usuario edita el contenido de la hoja de cálculo en el editor WYSIWYG, pasa el contenido editado a la instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> <a href="/es/net/editor/developer-guide/editabledocument/create-editabledocument-from-file-or-markup/">utilizando uno de sus métodos estáticos</a>, crea y ajusta la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a>, y pasa la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a> y el flujo de salida o la ruta del archivo de destino al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`Editor.Save()`</a>.
2. Si el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumber`</a> en la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a> está establecido en el valor predeterminado `0`, GroupDocs.Editor genera un nuevo archivo de hojas de cálculo con una única hoja. La propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumbersToDelete`</a> se ignora, independientemente de su valor.
3. Si el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumber`</a> en la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a> es distinto de cero, GroupDocs.Editor lo interpreta como una orden para insertar la hoja de cálculo editada en el archivo de hojas de cálculo original.
4. En función del valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/insertasnewworksheet/" target="_blank" rel="nofollow noopener noreferrer">`InsertAsNewWorksheet`</a>, GroupDocs.Editor reemplaza la hoja de cálculo antigua, especificada por el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumber" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumber`</a>, por la nueva obtenida de la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, o bien inserta la nueva hoja entre las hojas existentes sin reemplazar ninguna de ellas.
5. Finalmente, una vez completadas todas las inserciones y reordenaciones de hojas de cálculo, GroupDocs.Editor lee el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions/worksheetnumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`WorksheetNumbersToDelete`</a>, recorre todos los números especificados y elimina las hojas de cálculo indicadas del archivo.
6. El archivo de hojas de cálculo final, con las hojas actualizadas y eliminadas, se escribe en el flujo de salida o en el archivo.

El ejemplo siguiente muestra el ciclo completo de un archivo XLSX de entrada: se carga una hoja de cálculo que contiene 3 hojas de cálculo, su segunda hoja se convierte en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, luego se genera el marcado HTML desde la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, se modifica y el marcado HTML editado se convierte nuevamente en otra instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>. A partir de este punto, se crean dos instancias de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a>: una está destinada a generar la primera versión del archivo de salida con una nueva hoja y sin eliminación, por lo que contendrá en total 4 hojas (3 originales + 1 editada). La segunda instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`SpreadsheetSaveOptions`</a> tiene la propiedad WorksheetNumbersToDelete configurada para eliminar la primera y la última hojas, por lo que la segunda versión del archivo de salida contendrá en total 2 hojas (1 original + 1 editada).

El archivo XLSX de entrada, así como ambas versiones de los archivos XLSX de salida, pueden descargarse aquí:

```csharp
using GroupDocs.Editor;
using GroupDocs.Editor.Formats;
using GroupDocs.Editor.Options;
// ...

// Load input spreadsheet to the Editor and specify loading options
using (Editor editor = new Editor("Input3Worksheets.xlsx", new SpreadsheetLoadOptions()))
{
    // Prepare edit options and set 2nd worksheet to edit
    SpreadsheetEditOptions editOptions = new SpreadsheetEditOptions();
    editOptions.WorksheetIndex = 1;//2nd worksheet to edit, here WorksheetIndex is 0-based due to historical reasons

    //generate EditableDocument with original content of 2nd worksheet
    using (EditableDocument worksheet2OpenedForEdit = editor.Edit(editOptions))
    {
        // Get the HTML-markup from the EditableDocument with original content
        string originalHtmlContentOf2ndWorksheet = worksheet2OpenedForEdit.GetEmbeddedHtml();
        
        //emulate HTML content editing in WYSIWYG-editor in browser or somewhere else
        string editedHtmlContentOf2ndWorksheet = originalHtmlContentOf2ndWorksheet.Replace("2nd row", "Edited 2nd row at 1st column");

        //generate EditableDocument with edited content of 2nd worksheet
        using (EditableDocument worksheet2AfterEdit = EditableDocument.FromMarkup(editedHtmlContentOf2ndWorksheet))
        {
            //prepare save options without deletions
            SpreadsheetSaveOptions saveOptionsWithoutDelete = new SpreadsheetSaveOptions(SpreadsheetFormats.Xlsx);
            // let it be the 2nd worksheet...
            saveOptionsWithoutDelete.WorksheetNumber = 2;//here WorksheetNumber is 1-based
            //... and we also save the original 2nd worksheet, which is pushed to the 3rd position
            saveOptionsWithoutDelete.InsertAsNewWorksheet = true;

            // So now the spreadsheet must have 4 worksheets, not 3. Save it to file
            editor.Save(worksheet2AfterEdit, "Output4Worksheets-without-delete.xlsx", saveOptionsWithoutDelete);

            // Create another save options, with deletions at this time
            SpreadsheetSaveOptions saveOptionsWithDelete = new SpreadsheetSaveOptions(SpreadsheetFormats.Xlsx);
            // let the new worksheet will be 2nd for now, but after deleting it will became the 1st later
            saveOptionsWithDelete.WorksheetNumber = 2;

            //... and we also save the original 2nd worksheet, which will be next sibling to the newly inserted
            saveOptionsWithDelete.InsertAsNewWorksheet = true;

            // delete the 1st and last worksheet
            saveOptionsWithDelete.WorksheetNumbersToDelete = new int[2]
            {
                1,//1st worksheet
                4//last worksheet is 4, not 3, because we inserted the edited 2nd worksheet as the new worksheet instance, without rewriting the original 2nd worksheet
            };
            // Save it again to distinct file. Output XLSX should have 2 worksheets now.
            editor.Save(worksheet2AfterEdit, "Output2Worksheets-with-delete.xlsx", saveOptionsWithDelete);
        }
    }
}
```

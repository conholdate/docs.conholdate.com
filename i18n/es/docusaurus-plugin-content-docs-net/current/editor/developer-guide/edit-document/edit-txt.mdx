> Esta demostración muestra cómo cargar, abrir para editar y guardar documentos de texto, y explica las opciones de edición y guardado, así como su destino.

## ¿Cómo editar un archivo TXT? {#how-to-edit-txt-file}
  
Los documentos de texto son archivos de texto plano simples (TXT) que no contienen imágenes, páginas, párrafos, listas, tablas, etc. Sin embargo, los usuarios pueden crear cierto formato primitivo, como listas con marcadores iniciales, sangrías izquierdas con espacios en blanco, tablas con gráficos pseudo-gráficos, párrafos separados por saltos de línea, entre otros. <a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Editor**</a> puede reconocer algunas de estas estructuras. Otra característica menos evidente que ofrece GroupDocs.Editor es la capacidad de guardar el documento TXT editado no solo de nuevo como TXT, sino también en formato de procesamiento de textos (WordProcessing).

## Carga del archivo de texto para su edición {#loading-text-file-for-edit}
  
A diferencia de los documentos de procesamiento de textos y hojas de cálculo, los documentos DSV se cargan en la clase `Editor` sin ninguna opción de carga. Dado que son, por naturaleza, archivos de texto simples, no hay nada que ajustar:

```csharp
string inputTxtPath = "C://input/file.txt";
Editor editor = new Editor(inputTxtPath);
```

## Editar archivo de texto  {#edit-text-file}
  
Para abrir un documento de texto para su edición, creando una instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>, es necesario utilizar la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions" target="_blank" rel="nofollow noopener noreferrer">TextEditOptions</a>. Esta clase dispone de varias opciones (propiedades), descritas a continuación:  

1. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a> – permite establecer la codificación de caracteres del documento de texto de entrada. Por defecto, si no se especifica, es UTF8.  

2. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/recognizelists" target="_blank" rel="nofollow noopener noreferrer">RecognizeLists</a> – bandera booleana que indica cómo se reconocen exactamente los elementos de listas numeradas. Si esta opción se establece en `false` (valor predeterminado), el algoritmo de reconocimiento de listas detecta párrafos de lista cuando los números de lista terminan con un punto, un paréntesis derecho o símbolos de viñeta (como "•", "\*", "-" o "o"). Si esta opción se establece en `true`, los espacios en blanco también se utilizan como delimitadores de números de lista: el algoritmo de reconocimiento de listas para numeración estilo árabe (1., 1.1.2.) utiliza tanto espacios en blanco como el símbolo de punto (".").  

3. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/leadingspaces" target="_blank" rel="nofollow noopener noreferrer">LeadingSpaces</a> – bandera de tipo `enum` que indica cómo deben manejarse los espacios iniciales consecutivos: convertirlos en sangría izquierda (valor predeterminado), conservarlos como espacios consecutivos o recortarlos.  

4. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/trailingspaces" target="_blank" rel="nofollow noopener noreferrer">TrailingSpaces</a> – bandera de tipo `enum` que indica cómo deben manejarse los espacios finales consecutivos: recortarlos (valor predeterminado) o eliminarlos.  

5. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/enablepagination" target="_blank" rel="nofollow noopener noreferrer">EnablePagination</a> – bandera booleana que permite habilitar la vista por páginas del documento. En esencia, todos los documentos de texto carecen de páginas; sin embargo, GroupDocs.Editor permite dividirlos en páginas, tal como lo hace Microsoft Word.  

6. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/texteditoptions/direction" target="_blank" rel="nofollow noopener noreferrer">Direction</a> – bandera de tipo `enum` que permite especificar la dirección del flujo de texto en el documento de texto plano de entrada. Por defecto, es de izquierda a derecha.  

El código fuente siguiente demuestra el uso de esta clase de opciones y la apertura del documento de texto de entrada para su edición. Posteriormente, cuando la instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> esté lista, el ejemplo siguiente muestra cómo generar marcado HTML a partir de ella, editarlo y crear una nueva instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> a partir del contenido editado.

```csharp
TextEditOptions editOptions = new TextEditOptions();
editOptions.Encoding = System.Text.Encoding.UTF8;
editOptions.RecognizeLists = true;
editOptions.LeadingSpaces = TextLeadingSpacesOptions.ConvertToIndent;
editOptions.TrailingSpaces = TextTrailingSpacesOptions.Trim;
editOptions.Direction = TextDirection.Auto;

EditableDocument beforeEdit = editor.Edit(editOptions); // Create EditableDocument instance

string originalTextContent = beforeEdit.GetContent(); // Get HTML content
string updatedTextContent = originalTextContent.Replace("text", "EDITED text"); // Edit content
List<IHtmlResource> allResources = beforeEdit.AllResources; // Get resources (only one stylesheet actually in this case)

//Finally, create new EditableDocument
EditableDocument afterEdit = EditableDocument.FromMarkup(updatedTextContent, allResources);
```

## Guardar archivo de texto tras la edición  {#save-text-file-after-edit}
  
Tras su edición, el documento de texto puede guardarse nuevamente en formato TXT o en formato de procesamiento de textos. Para guardarlo de nuevo en formato TXT, el usuario debe utilizar la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/textsaveoptions" target="_blank" rel="nofollow noopener noreferrer">TextSaveOptions</a>, la cual posee tres propiedades descritas a continuación:  

1. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/textsaveoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a> – codificación de caracteres del documento de texto, que se aplicará al guardarlo. Por defecto, si no se especifica, es UTF8.  

2. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/textsaveoptions/addbidimarks" target="_blank" rel="nofollow noopener noreferrer">AddBidiMarks</a> – bandera booleana que determina si se deben agregar marcas de dirección bidireccional (BiDi) antes de cada segmento BiDi al guardar en formato de texto sin formato.  

3. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/textsaveoptions/addbidimarks" target="_blank" rel="nofollow noopener noreferrer">PreserveTableLayout</a> – bandera booleana que especifica si GroupDocs.Editor debe intentar preservar el diseño de las tablas al guardar en formato de texto sin formato. El valor predeterminado es `false`.  

El código fuente siguiente muestra cómo guardar <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> tanto en formato TXT como en formato de procesamiento de textos:

```csharp
TextSaveOptions txtSaveOptions = new TextSaveOptions();
txtSaveOptions.AddBidiMarks = true;
txtSaveOptions.PreserveTableLayout = true;

WordProcessingSaveOptions wordSaveOptions = new WordProcessingSaveOptions(WordProcessingFormats.Docm);

string outputTxtPath = "C:\output\document.txt";
string outputWordPath = "C:\output\document.docm";

editor.Save(afterEdit, outputTxtPath, txtSaveOptions);
editor.Save(afterEdit, outputWordPath, wordSaveOptions);
```

Como resultado, tras ejecutar este ejemplo, el usuario tendrá dos versiones del documento editado: en formatos TXT y DOCM.

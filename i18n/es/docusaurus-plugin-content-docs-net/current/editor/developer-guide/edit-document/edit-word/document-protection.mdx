El <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> propiedad, si se establece, habilita la protección del documento contra su apertura mediante su cifrado con la contraseña especificada. Sin embargo, casi todos los formatos de procesamiento de texto admiten una protección del documento contra la escritura, que es completamente distinta de la apertura. La protección del documento, al igual que la codificación del documento, también implica una contraseña como forma de clave, pero también admite diferentes niveles de protección: algunos solo permiten el modo de solo lectura, mientras que otros permiten editar campos de formulario, etc.

<a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Editor**</a> permite aplicar la protección del documento mediante el <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/protection" target="_blank" rel="nofollow noopener noreferrer">Protection</a> propiedad en la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> clase. De forma predeterminada, esta propiedad tiene un valor NULL, lo que significa que GroupDocs.Editor no aplicará la protección al documento.  

El <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/protection" target="_blank" rel="nofollow noopener noreferrer">Protection</a> propiedad tiene una <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection" target="_blank" rel="nofollow noopener noreferrer">WordProcessingProtection</a> tipo. Este tipo es una clase, la cual, a su vez, consta de dos propiedades: <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> y un <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a>.

<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection" target="_blank" rel="nofollow noopener noreferrer">WordProcessingProtection</a> la clase tiene dos constructores. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/wordprocessingprotection/#constructor" target="_blank" rel="nofollow noopener noreferrer">El primero</a> es sin parámetros, establece ambas propiedades de clase en sus valores predeterminados. Si el usuario utiliza este constructor y luego no establece valores en las propiedades de la instancia de la clase, la protección no se aplicará al documento. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/wordprocessingprotection/#constructor_1" target="_blank" rel="nofollow noopener noreferrer">Segundo constructor</a>, en contraparte, tiene dos parámetros, que establecen valores en las propiedades; por lo tanto, al utilizar este constructor, no es necesario usar las propiedades en absoluto.

El <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> la propiedad es responsable de establecer una contraseña para la protección del documento. De forma predeterminada, su valor es `NULL`, lo que significa que no se aplica protección. Si el usuario desea aplicar la protección del documento, *debe* asignar una cadena a esta propiedad (mediante <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/wordprocessingprotection/#constructor_1" target="_blank" rel="nofollow noopener noreferrer">constructor</a> o la propiedad en sí); de lo contrario, la protección no se aplicará, independientemente del valor de la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a> propiedad.

<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a> la propiedad tiene el tipo <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotectiontype" target="_blank" rel="nofollow noopener noreferrer">WordProcessingProtectionType</a>, que es un enum simple, y el valor de este enum determina el nivel de protección. Por defecto, el enum tiene un `NoProtection` valor, lo que significa que no se aplicará ninguna protección. Otros valores son:

1. `AllowOnlyRevisions` - El usuario solo puede agregar marcas de revisión al documento.
2. `AllowOnlyComments` - El usuario solo puede modificar comentarios en el documento.
3. `AllowOnlyFormFields` - El usuario solo puede ingresar datos en los campos del formulario del documento.
4. `ReadOnly` - No se permiten cambios en el documento.  

Tenga en cuenta que ambas propiedades <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> y un <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a> están vinculados entre sí. Si el usuario establece un valor válido, no nulo y no vacío <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>, pero el <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a> la propiedad tiene una <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotectiontype" target="_blank" rel="nofollow noopener noreferrer">WordProcessingProtectionType</a>. `NoProtection` valor, la protección no se aplicará. Y viceversa, si <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/protectiontype" target="_blank" rel="nofollow noopener noreferrer">ProtectionType</a> propiedad tiene una `AllowOnlyFormFields` valor, por ejemplo, pero <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingprotection/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> es NULL o una cadena vacía, entonces la protección tampoco se aplicará.

La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> se encarga de ajustar y personalizar el proceso de guardado, cuando una instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, que contiene el contenido del documento ya editado, debe convertirse en un documento de salida en algún formato de procesamiento de textos (WordProcessing). En otras palabras, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> define exactamente cómo debe guardarse el HTML editado en el documento de salida.

A diferencia de las opciones de carga y edición, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> tiene un parámetro <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/wordprocessingsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">constructor</a> obligatorio, que recibe un único parámetro: `outputFormat`. El parámetro `outputFormat` es de tipo <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingFormats`</a>. A su vez, este tipo contiene todos los formatos admitidos de la familia <a href="https://docs.fileformat.com/word-processing/" target="_blank" rel="nofollow noopener noreferrer"> de formatos de procesamiento de textos</a>, los cuales son compatibles con el guardado de documentos. Cada campo de la estructura <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingFormats`</a> representa un formato de procesamiento de textos independiente: DOC, DOCX, RTF, ODT, etc. También existe un campo <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/wordprocessingformats/fields/all" target="_blank" rel="nofollow noopener noreferrer">`All`</a>, que permite iterar sobre todos los formatos de procesamiento de textos. Por lo tanto, mediante el parámetro `outputFormat`, el usuario debe seleccionar el formato específico del documento de salida de procesamiento de textos que será generado por el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`editor.Save()`</a>.

Este constructor es obligatorio, ya que no es posible crear una instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> sin especificar un formato de salida; de lo contrario, ¿cómo sabría GroupDocs.Editor en qué formato concreto debe guardarse el documento? No obstante, el formato de salida puede modificarse posteriormente, tras la creación de una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a>, mediante la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/outputformat" target="_blank" rel="nofollow noopener noreferrer">`OutputFormat`</a>. Dicha propiedad también dispone de un método getter que permite obtener el formato de salida previamente especificado en el constructor.

Casi todos los formatos de procesamiento de textos, especialmente aquellos de naturaleza binaria, admiten el cifrado del archivo mediante contraseña. Si un documento está cifrado, es necesario especificar la contraseña para abrirlo. La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> dispone de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/password" target="_blank" rel="nofollow noopener noreferrer">siguiente</a>, que permite establecer la contraseña:

```csharp
public string Password { get; set; }
```

De forma predeterminada, el valor de esta propiedad es `NULL`, lo que significa que no se aplicará ninguna contraseña. Si el usuario especifica una cadena en esta propiedad, el documento de salida se codificará y protegerá utilizando dicha cadena como contraseña. Si el usuario hubiera especificado previamente una contraseña en esta propiedad en algún paso, pero luego desea cancelar la contraseña y no codificar el documento, puede establecer el valor en `NULL` o en una cadena vacía; ambos valores se interpretarán como «no establecer contraseña» al invocar el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`editor.Save()`</a>.

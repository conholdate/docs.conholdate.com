La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> contiene 3 propiedades muy similares del mismo tipo `System.Globalization.CultureInfo`:

```csharp
public System.Globalization.CultureInfo Locale { get; set; }
public System.Globalization.CultureInfo LocaleBi { get; set; }
public System.Globalization.CultureInfo LocaleFarEast { get; set; }
```

En la mayoría de los casos, el documento de WordProcessing de salida, que se genera a partir del <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> instancia por el <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`editor.Save()</a> método, contiene configuraciones regionales válidas para el contenido de texto. Sin embargo, en algunos casos es necesario establecer de forma forzosa y explícita una configuración regional específica para el documento de salida. Estas tres opciones proporcionan dicha posibilidad. No obstante, tenga en cuenta que solo son adecuadas cuando el documento debe tener una única configuración regional. Si el documento es multilingüe y contiene, por ejemplo, texto en inglés y español, establecer la configuración regional en inglés (por ejemplo, «en-GB») marcará también el texto en español como inglés, por lo que la corrección ortográfica en MS Word, por ejemplo, no funcionará correctamente para dicho texto.

De forma predeterminada, estas tres propiedades relacionadas con la configuración regional no están especificadas y sus valores son NULL. En tal caso, MS Word (u otro programa) detectará (o elegirá) la configuración regional del documento según sus propias configuraciones u otros factores. Además, si el documento es multilingüe, se recomienda encarecidamente habilitar la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingeditoptions/enablelanguageinformation" target="_blank" rel="nofollow noopener noreferrer">`EnableLanguageInformation`</a> propiedad en la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingeditoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingEditOptions</a> clase al editar el documento original, y no utilizar estas 3 propiedades. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/locale" target="_blank" rel="nofollow noopener noreferrer">`Locale`</a> la propiedad está destinada a establecer la configuración regional para el texto normal de izquierda a derecha, que consiste en letras.  
La <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/localebi" target="_blank" rel="nofollow noopener noreferrer">`LocaleBi`</a> la propiedad debe usarse cuando el texto es de derecha a izquierda (RTL), por ejemplo, <a href="https://en.wikipedia.org/wiki/Arabic_script" target="_blank" rel="nofollow noopener noreferrer">Guion árabe</a> o <a href="https://en.wikipedia.org/wiki/Hebrew_alphabet" target="_blank" rel="nofollow noopener noreferrer">Alfabeto hebreo</a>.  
El <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions/localefareast" target="_blank" rel="nofollow noopener noreferrer">`LocaleFarEast`</a> la propiedad debe usarse para texto de Asia Oriental (Lejano Oriente), incluyendo <a href="https://en.wikipedia.org/wiki/CJK_characters" target="_blank" rel="nofollow noopener noreferrer">Caracteres CJK</a>.

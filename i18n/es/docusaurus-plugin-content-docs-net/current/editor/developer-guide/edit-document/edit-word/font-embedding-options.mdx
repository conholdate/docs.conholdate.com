## Introducción {#introduction}
  
A partir de la versión 20.7, GroupDocs.Editor para .NET puede, además de extraer fuentes, incrustarlas en el documento de procesamiento de texto de salida. Esta funcionalidad puede considerarse similar a la característica de Microsoft Word que permite incrustar fuentes en el documento guardado tras su edición.

En contraste con el mecanismo de _extracción de fuentes_, mediante las clases correspondientes <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/fontextractionoptions" target="_blank" rel="nofollow noopener noreferrer">`FontExtractionOptions`</a>, encargadas de extraer los recursos tipográficos del documento de procesamiento de texto de entrada hacia un <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> intermedio, el mecanismo de incrustación de fuentes, mediante las clases correspondientes, se encarga de transferir las fuentes desde <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> hacia el documento de procesamiento de texto de salida mediante incrustación. Cuando el usuario obtiene el contenido de un documento editado en el editor WYSIWYG y crea una nueva instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> con dicho contenido editado, debe invocar el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">`Editor`</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`Save()`</a>, que generará el documento de procesamiento de texto de salida a partir de las clases <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> y <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> especificadas. La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> es el punto donde la incrustación de fuentes —deshabilitada de forma predeterminada— puede habilitarse y configurarse.

Cuando la incrustación de fuentes está habilitada, GroupDocs.Editor analiza el contenido del documento de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> y genera una lista con todas las fuentes utilizadas en el cuerpo del documento, por ejemplo, en párrafos, etiquetas, etc. A continuación, GroupDocs.Editor intenta localizar todas estas fuentes en los recursos tipográficos del <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> de entrada (propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/fonts" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument.Fonts`</a>). Si <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> contiene todos los recursos tipográficos utilizados en el cuerpo del documento, estos se incrustarán en el documento de procesamiento de texto de salida. Sin embargo, si existen fuentes utilizadas en el contenido del documento que no tengan recursos tipográficos correspondientes en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, GroupDocs.Editor intentará localizarlas en el sistema operativo (donde se ejecuta GroupDocs.Editor), extraerlas e incrustarlas en el documento de salida.

Puede darse el caso de que, durante la edición del documento en el editor WYSIWYG, el usuario final elimine algún texto, por ejemplo, un párrafo, que utilice una fuente específica, y tras dicha eliminación dicha fuente ya no se utilice, mientras que su recurso tipográfico correspondiente permanezca aún en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>. Durante la incrustación de fuentes, dichos recursos tipográficos huérfanos se detectan e ignoran, por lo que no se incluirán en el documento de salida.

Al trabajar con fuentes, GroupDocs.Editor debe operar con las llamadas _fuentes del sistema_. Las fuentes del sistema son aquellas esenciales para el funcionamiento del sistema operativo; por ejemplo, se utilizan en el Explorador de Windows, en la Consola y en las aplicaciones integradas del sistema operativo. Al realizar la incrustación de fuentes, el usuario puede definir si desea incrustar o no las fuentes del sistema en el documento de salida. Incluir las fuentes del sistema puede resultar útil si el usuario trabaja en un sistema de Asia Oriental y desea crear un documento que pueda leerse en otros sistemas que no dispongan de las fuentes necesarias para ese idioma. Por ejemplo, un usuario en un sistema japonés podría optar por incrustar las fuentes en un documento para que este sea legible en cualquier sistema.

## Uso {#usage}
  
Para admitir la incrustación de fuentes, a partir de la versión 20.7, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a> incorpora ahora una nueva propiedad: `FontEmbedding`. Esta propiedad es de tipo `FontEmbeddingOptions` —un enumerado con tres valores posibles. De forma predeterminada, al crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingSaveOptions`</a>, el valor de la propiedad `FontEmbedding` es `NotEmbed`; en este caso, GroupDocs.Editor no incrusta ninguna fuente y, por tanto, se comporta como en versiones anteriores, de modo que el código cliente existente no se verá afectado al actualizarse desde versiones anteriores a la 20.7.

El enumerado `FontEmbeddingOptions` contiene dos valores para la incrustación de fuentes, prácticamente idénticos salvo por una pequeña diferencia: 
* `EmbedAll`. Como se indica anteriormente, al seleccionar esta opción, GroupDocs.Editor analiza el contenido del documento en busca de las fuentes utilizadas y, a continuación, busca dichas fuentes en EditableDocument y, si es necesario, en el sistema operativo. Esta opción es similar a la opción «Incrustar fuentes en el archivo» de Microsoft Word 2007 y versiones posteriores, con todas sus subopciones desactivadas. 
* `EmbedWithoutSystem`. Esta opción es casi idéntica a la anterior, salvo por una pequeña diferencia: no incrusta las fuentes del sistema. Esta opción es similar a la opción «Incrustar fuentes en el archivo» de Microsoft Word 2007 y versiones posteriores, con la subopción «No incrustar fuentes del sistema comunes» activada.  

En el ejemplo siguiente se muestran todas estas opciones:

```csharp
Options.WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(Formats.WordProcessingFormats.Docx);
  
//By default fonts are not embedded
Assert.AreEqual(Options.FontEmbeddingOptions.NotEmbed, saveOptions.FontEmbedding);
  
//Embed all used fonts, including system fonts
saveOptions.FontEmbedding = Options.FontEmbeddingOptions.EmbedAll;
  
//Embed all used fonts, but except system fonts
saveOptions.FontEmbedding = Options.FontEmbeddingOptions.EmbedWithoutSystem;
```

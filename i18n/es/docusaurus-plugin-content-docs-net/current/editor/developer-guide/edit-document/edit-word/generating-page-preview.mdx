A partir de la versión <a href="https://docs.groupdocs.com/editor/net/groupdocs-editor-for-net-23-5-release-notes/" target="_blank" rel="nofollow noopener noreferrer">23.5</a>, GroupDocs.Editor para .NET permite generar una vista previa de cualquier página en un documento de procesamiento de textos cargado, como DOC, DOCX, DOCM, RTF, ODT, etc. La vista previa se genera en formato SVG, un formato de gráficos vectoriales ampliamente compatible con múltiples visores de imágenes y todos los navegadores modernos.

Gracias a esta funcionalidad, los usuarios pueden visualizar e inspeccionar cualquier documento del archivo de procesamiento de textos importado sin necesidad de editarlo. Dicha vista previa no puede ser editada por GroupDocs.Editor en sí; únicamente se obtiene en formato SVG y puede guardarse de forma habitual, ya sea en un flujo de bytes o en un archivo.

Esta funcionalidad funciona independientemente del modo de licencia de GroupDocs.Editor para .NET: opera de la misma manera tanto en modo de prueba como en modo con licencia, y no existen limitaciones de prueba para esta característica. Al generar las vistas previas de las páginas, GroupDocs.Editor no descuenta los bytes consumidos ni los créditos.

Con la introducción de esta funcionalidad, GroupDocs.Editor para .NET ahora admite finalmente la generación de vistas previas para las tres familias principales de formatos ofimáticos: procesamiento de textos, <a href="/es/net/editor/developer-guide/edit-document/edit-excel/generating-worksheet-preview-for-spreadsheet/">hojas de cálculo</a> y <a href="/es/net/editor/developer-guide/edit-document/edit-powerpoint/generating-slides-preview-for-presentation/">presentaciones</a>.

Para generar la vista previa de páginas de un documento de procesamiento de textos específico, el usuario debe realizar los siguientes pasos:

- Cargar el archivo de procesamiento de textos deseado en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/" target="_blank" rel="nofollow noopener noreferrer">`Editor`</a>.
- Llamar al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/getdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`GetDocumentInfo()`</a> y especificar la contraseña del documento cargado, en caso de que esté protegido con contraseña.
- Dado que el archivo cargado pertenece a la familia de formatos de procesamiento de textos (por ejemplo, DOCX, RTF, etc.), el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/getdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`GetDocumentInfo()`</a> debe devolver una instancia de la estructura <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`GroupDocs.Editor.Metadata.WordProcessingDocumentInfo`</a>, convertida a la interfaz <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/idocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`IDocumentInfo`</a>. Convertirla nuevamente desde <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/idocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`IDocumentInfo`</a> al tipo <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingDocumentInfo`</a>.
- En la estructura <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingDocumentInfo`</a> obtenida, invocar el método de instancia nuevo <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/generatepreview/" target="_blank" rel="nofollow noopener noreferrer">`GeneratePreview(int pageIndex)`</a>, especificando en este método el _índice_ (no confundir con los _números_ de página, que comienzan en 1) de la página deseada, en base cero. Si el índice especificado es menor que 0 o excede el número de páginas del documento dado, se lanzará la excepción <a href="https://learn.microsoft.com/en-us/dotnet/api/system.ArgumentOutOfRangeException?view=net-7.0" target="_blank" rel="nofollow noopener noreferrer">System.ArgumentOutOfRangeException</a>.
- El método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/generatepreview/" target="_blank" rel="nofollow noopener noreferrer">`GeneratePreview(int pageIndex)`</a> devuelve una vista previa de página como imagen vectorial SVG, encapsulada en la clase pública <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/svgimage/" target="_blank" rel="nofollow noopener noreferrer">`SvgImage`</a> del espacio de nombres <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/" target="_blank" rel="nofollow noopener noreferrer">`GroupDocs.Editor.HtmlCss.Resources.Images.Vector`</a>. Esta clase dispone de todos los métodos y propiedades necesarios para obtener el contenido de la imagen SVG en cualquier formato deseado, guardarlo en disco, en un flujo, etc.

El siguiente ejemplo de código muestra cómo abrir un archivo DOCX de procesamiento de textos sin contraseña, obtener el número total de páginas en dicho archivo DOCX y luego generar las vistas previas de cada página mediante un bucle. Posteriormente, estas vistas previas se guardan en disco. Téngase en cuenta que GroupDocs.Editor se está ejecutando en modo de prueba, pero se generan vistas previas para todas las páginas y ninguna de estas vistas previas incluye marcas de agua o copyright propias de la versión de prueba.

```csharp
// Obtain a valid full path to the WordProcessing file
string inputPath = "SampleDoc.docx";

// Load WordProcessing file to the Editor constructor
using (GroupDocs.Editor.Editor editor = new Editor(inputPath))
{
	// Get document info for this file
	IDocumentInfo infoUncasted = editor.GetDocumentInfo(null);

	//Make sure it is really a WordProcessing of DOCX format
	Assert.AreEqual(Formats.WordProcessingFormats.Docx, infoUncasted.Format);

	// Cast this document info to the WordProcessingDocumentInfo type
	WordProcessingDocumentInfo infoWordProcessing = (WordProcessingDocumentInfo)infoUncasted;

	// Get the number of all pages
	int pagesCount = infoWordProcessing.PageCount;	

	//Iterate through all pages and generate the preview on every iteration
	for (int pageIndex = 0; pageIndex < pagesCount; pageIndex++)
	{
		// Generate one preview as SVG image by page index
		SvgImage oneSvgPreview = infoWordProcessing.GeneratePreview(pageIndex);

		// Save SVG preview to the file
		oneSvgPreview.Save(Path.Combine(outputFolder, oneSvgPreview.FilenameWithExtension));
	}
}
```

Todos los formatos de procesamiento de texto pueden almacenar imágenes rasterizadas. Por lo tanto, cuando una página específica de un documento cargado contiene una o más imágenes rasterizadas y se genera una vista previa SVG para dicha página, esta/s imagen/es rasterizada/s se incrustará/n dentro del SVG en formato base64 mediante el esquema de URI de datos <a href="https://en.wikipedia.org/wiki/Data_URI_scheme" target="_blank" rel="nofollow noopener noreferrer">data URI scheme</a>.

En resumen, la nueva función de vista previa de página es, en esencia, un nuevo método público dentro de la estructura existente <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.metadata/wordprocessingdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">`WordProcessingDocumentInfo`</a>, que recibe un índice de página y devuelve una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/svgimage/" target="_blank" rel="nofollow noopener noreferrer">`SvgImage`</a>. Si el usuario final necesita obtener una vista previa de la página en formato rasterizado y no vectorial, puede utilizar el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/svgimage/savetopng/" target="_blank" rel="nofollow noopener noreferrer">`SaveToPng`</a> de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/svgimage/" target="_blank" rel="nofollow noopener noreferrer">`SvgImage`</a>: este método convierte el contenido SVG de la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.htmlcss.resources.images.vector/svgimage/" target="_blank" rel="nofollow noopener noreferrer">`SvgImage`</a> actual al formato PNG y lo guarda en el <a href="https://learn.microsoft.com/en-us/dotnet/api/system.IO.Stream?view=net-6.0" target="_blank" rel="nofollow noopener noreferrer">`System.IO.Stream`</a> especificado.

> Este ejemplo demuestra el ciclo estándar de abrir-editar-guardar con documentos de presentación, utilizando diferentes opciones en cada paso.

## Introducción {#introduction}
  
Los documentos de presentación se presentan en muchos formatos: PPT, PPTX, PPTM, PPS(X/M), POT(X/M) y otros, los cuales son soportados por GroupDocs.Editor como una familia de formatos independiente entre todas las demás. Al igual que ocurre con todas las demás familias de formatos, la familia de formatos de presentación posee sus propias opciones de carga, edición y guardado. El formato de presentación presenta una distinción significativa respecto a los formatos de procesamiento de texto y todos los formatos textuales, y al mismo tiempo una gran similitud con los formatos de hojas de cálculo: no posee páginas, sino que en su lugar tiene diapositivas (al igual que las hojas de cálculo tienen hojas). Al igual que las hojas en las hojas de cálculo, las diapositivas en las presentaciones son completamente independientes entre sí y no tienen una representación válida en marcado HTML; por lo tanto, la única forma de editar diapositivas es hacerlo de forma independiente, una diapositiva por cada procedimiento de edición.

Como resultado, un documento de presentación con múltiples diapositivas se carga en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>. Luego, para abrir el documento en modo de edición llamando al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit</a>, el usuario debe seleccionar la diapositiva deseada para editarla especificando su índice en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationEditOptions</a>. Como resultado, el usuario obtendrá una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>, que contiene dicha diapositiva editada. Para editar otra diapositiva, el usuario debe realizar otra llamada al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit</a> con otro índice de diapositiva, y obtener una nueva instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>. Finalmente, al guardar las diapositivas editadas de nuevo en formato de presentación, el usuario debe guardar cada instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> por separado.

Al igual que todos los formatos OOXML de Office, los documentos de presentación pueden estar cifrados con contraseña. GroupDocs.Editor admite la apertura de documentos de presentación protegidos con contraseña (la contraseña debe especificarse en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a>) y la creación de documentos protegidos con contraseña (la contraseña debe especificarse en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a>).

## Carga de la presentación para su edición {#loading-presentation-for-editing}
  
El primer paso para editar un documento es cargarlo. Para cargar una presentación en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>, el usuario debe utilizar la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a>. En algunos casos generales no es necesario: incluso sin <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a>, GroupDocs.Editor es capaz de reconocer el formato de presentación y aplicar automáticamente las opciones de carga predeterminadas correspondientes. Sin embargo, cuando la presentación está codificada, <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a> es la única forma de establecer la contraseña y cargar correctamente el documento.

Si el documento está codificado pero no se establece contraseña en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a>, o si <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a> no se especifica en absoluto, se lanzará la excepción <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/passwordrequiredexception" target="_blank" rel="nofollow noopener noreferrer">PasswordRequiredException</a>. Si se establece una contraseña pero esta es incorrecta, se lanzará <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/incorrectpasswordexception" target="_blank" rel="nofollow noopener noreferrer">IncorrectPasswordException</a>. Si se establece una contraseña pero el documento no está codificado, la contraseña será ignorada.

A continuación se muestra un ejemplo de carga de un documento de presentación desde una ruta de archivo, con opciones de carga y contraseña.

```csharp
string inputPptxPath = "C://input/presentation.pptx";
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
loadOptions.Password = "password";
Editor editor = new Editor(inputPptxPath, loadOptions);
```

## Editar presentación de PowerPoint  {#edit-powerpoint-presentation}
  
Para abrir un documento de presentación para su edición, se debe utilizar la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationEditOptions</a>. Esta clase posee dos propiedades: <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">SlideNumber</a>, de tipo entero, y <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions/showhiddenslides" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a>, que es una bandera booleana.  

<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">SlideNumber</a> es un índice basado en cero de una diapositiva, que permite especificar y seleccionar una diapositiva concreta de la presentación para editarla. Si su valor es menor que 0, se seleccionará la primera diapositiva (equivalente a *SlideNumber = 0*). Si supera el número total de diapositivas de la presentación, se seleccionará la última diapositiva. Si la presentación de entrada contiene únicamente una diapositiva, esta opción se ignorará y se editará dicha única diapositiva. Por defecto, su valor es 0, lo que implica que se editará la primera diapositiva.  

<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions/showhiddenslides" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a> es una bandera booleana que especifica si deben incluirse o no las diapositivas ocultas. El valor predeterminado es *false* (falso), lo que significa que las diapositivas ocultas no se muestran y se lanzará una excepción al intentar editarlas. Por ejemplo, si la presentación de entrada consta de 5 diapositivas, siendo la segunda oculta, y el usuario especifica *SlideNumber = 1* (segunda diapositiva) y simultáneamente *ShowHiddenSlides = false*, se lanzará la `InvalidOperationException`. A partir de este breve ejemplo puede observarse que los índices de las diapositivas ocultas no se descartan ni se ajustan, sino que se _niegan_: al intentar acceder a ellas, se produce la `InvalidOperationException`.  

Si se utiliza la sobrecarga sin parámetros del método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit</a>, se empleará la instancia predeterminada de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationEditOptions</a>: la primera diapositiva y <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions/showhiddenslides" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a> deshabilitado.  

El siguiente ejemplo de código demuestra todas las opciones descritas anteriormente. Supongamos que el documento de presentación, con al menos 3 diapositivas, ya ha sido cargado en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.

```csharp
//parameterless overload is used => default PresentationEditOptions is applied, which means 1st slide
EditableDocument firstSlide = editor.Edit();

PresentationEditOptions editOptions2 = new PresentationEditOptions();
editOptions2.SlideNumber = 1; //index is 0-based, so this is 2nd slide
EditableDocument secondSlide = editor.Edit(editOptions2);

PresentationEditOptions editOptions3 = new PresentationEditOptions();
editOptions3.SlideNumber = 2; //index is 0-based, so this is 3rd slide
editOptions3.ShowHiddenSlides = true; //if 3rd slide is hidden, it will be opened anyway
EditableDocument thirdSlide = editor.Edit(editOptions3);
```

## Guardar presentación tras la edición {#save-presentation-after-edit}
  
La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> está diseñada para guardar documentos de presentación editados. Esta clase tiene un <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/#constructors" target="_blank" rel="nofollow noopener noreferrer">constructor</a>, el cual acepta un único parámetro: el <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/presentationformats" target="_blank" rel="nofollow noopener noreferrer">formato de presentación</a> en el que se debe guardar el documento de salida. Este formato de salida está representado por la estructura <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.formats/presentationformats" target="_blank" rel="nofollow noopener noreferrer">PresentationFormats</a>. Tras crear una instancia, el formato de salida puede obtenerse o modificarse posteriormente mediante la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/outputformat" target="_blank" rel="nofollow noopener noreferrer">OutputFormat</a>. Este es el único parámetro necesario para guardar el documento; todos los demás son opcionales y pueden omitirse.

Además del formato, el usuario puede especificar una contraseña mediante la propiedad de cadena <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>; en tal caso, el documento de salida se codificará y protegerá con dicha contraseña. Por defecto, no se establece ninguna contraseña, lo que implica que el documento de salida no estará protegido. Esto se muestra en el siguiente ejemplo, donde se supone que el usuario dispone de una instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> con una diapositiva editada.

```csharp
PresentationSaveOptions saveOptions = new PresentationSaveOptions(PresentationFormats.Pptm);
saveOptions.Password = "new password";

EditableDocument afterEdit = /* obtain it from somewhere */;
FileStream outputStream = /* obtain it from somewhere */;

//saving edited slide to specified stream in PPTM format and with password encoding
editor.Save(afterEdit, outputStream, saveOptions);

```

A partir de la versión 20.4, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> contiene dos nuevas propiedades: <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">SlideNumber</a> y <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/insertasnewslide" target="_blank" rel="nofollow noopener noreferrer">InsertAsNewSlide</a>, las cuales están altamente relacionadas entre sí. Estas propiedades permiten insertar la diapositiva editada en una presentación existente en lugar de crear una nueva presentación con una única diapositiva editada, que sigue siendo el comportamiento predeterminado. Se explican con detalle en [este artículo independiente](/net/editor/developer-guide/edit-document/edit-powerpoint/inserting-edited-slide-into-existing-presentation/).

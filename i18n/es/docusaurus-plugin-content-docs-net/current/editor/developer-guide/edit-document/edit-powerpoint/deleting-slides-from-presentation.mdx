Existen muchos formatos de documentos de <a href="https://docs.fileformat.com/presentation/" target="_blank" rel="nofollow noopener noreferrer">presentación</a>: <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a>, <a href="https://docs.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">PPTX</a>, <a href="https://docs.fileformat.com/presentation/odp/" target="_blank" rel="nofollow noopener noreferrer">ODP</a> y muchos más. Todos ellos comparten una característica común: las *diapositivas*. Cada documento de presentación contiene una o más diapositivas, las cuales pueden considerarse contenedores de diversos tipos de contenido: texto, formas geométricas, imágenes rasterizadas y vectoriales, animaciones, video, audio, comentarios y objetos incrustados, entre otros. Desde sus inicios, GroupDocs.Editor ha permitido editar presentaciones, pero únicamente de forma individual por diapositiva: el usuario solo puede editar el contenido de una diapositiva a la vez.

Inicialmente, cuando se editaba el contenido de una diapositiva, solo era posible guardarla como una nueva presentación de una sola diapositiva. En concreto, el flujo de trabajo era el siguiente: el usuario carga una presentación en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">`Editor`</a>, selecciona la diapositiva que desea editar mediante <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationeditoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationEditOptions`</a>, obtiene <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, edita el contenido HTML de la diapositiva, guarda este contenido de nuevo en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> y, finalmente, genera un nuevo archivo de presentación con una sola diapositiva mediante el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`Editor.Save()`</a>.

Tras el lanzamiento de la <a href="https://releases.groupdocs.com/editor/net/release-notes/2020/groupdocs-editor-for-net-20-4-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 20.4</a>, con la introducción de la nueva propiedad SlideNumber, este flujo de trabajo se amplió: ahora es posible insertar la diapositiva editada en la presentación original de dos maneras distintas:

1. sustituyendo la diapositiva original, inicialmente seleccionada para su edición, por su versión editada,
2. o bien colocando la diapositiva editada para que coexista junto a su versión original anterior a la edición.

Este mecanismo se explica con detalle en un <a href="https://docs.groupdocs.com/editor/net/inserting-edited-slide-into-existing-presentation/" target="_blank" rel="nofollow noopener noreferrer">artículo independiente</a>.

A partir de la <a href="https://releases.groupdocs.com/editor/net/release-notes/2025/groupdocs-editor-for-net-25-11-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 25.11</a>, ya no solo es posible editar y sustituir diapositivas en la presentación resultante, sino también eliminarlas. La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a> ahora incluye una nueva propiedad: `int[]` <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`SlideNumbersToDelete`</a>, que básicamente es un array de enteros, donde cada entero representa el número de una diapositiva que debe eliminarse. Los números de diapositiva son base 1, por lo que la primera diapositiva tiene el número `1`, no `0`.

Con la nueva funcionalidad de eliminación de diapositivas, GroupDocs.Editor ejecuta el siguiente algoritmo durante el guardado de la presentación:

1. El usuario edita el contenido de una diapositiva en el editor WYSIWYG, pasa el contenido editado a la instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> <a href="https://docs.groupdocs.com/editor/net/create-editabledocument-from-file-or-markup/" target="_blank" rel="nofollow noopener noreferrer">utilizando uno de sus métodos estáticos</a>, crea y ajusta la <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a>, y pasa la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a> y el flujo de salida o la ruta del archivo de destino al método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">`Editor.Save()`</a>.
2. Si el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">`SlideNumber`</a> en la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a> es el valor predeterminado `0`, GroupDocs.Editor genera una nueva presentación con una única diapositiva. La propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`SlideNumbersToDelete`</a> se ignora, independientemente de su valor.
3. Si el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">`SlideNumber`</a> en la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a> es distinto de cero, GroupDocs.Editor lo interpreta como una instrucción para insertar la diapositiva editada en la presentación original.
4. En función de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/insertasnewslide" target="_blank" rel="nofollow noopener noreferrer">`InsertAsNewSlide`</a>, GroupDocs.Editor sustituye la diapositiva antigua, especificada por el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumber" target="_blank" rel="nofollow noopener noreferrer">`SlideNumber`</a>, por la nueva, obtenida de la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, o bien inserta la nueva diapositiva entre las diapositivas existentes sin sustituir ninguna de ellas.
5. Finalmente, una vez completadas todas las inserciones y reordenaciones de diapositivas, GroupDocs.Editor lee el valor de la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`SlideNumbersToDelete`</a>, recorre todos los números y elimina las diapositivas especificadas de la presentación.
6. La presentación final, con diapositivas actualizadas y eliminadas, se escribe en el flujo de salida o en el archivo.

El ejemplo siguiente muestra el ciclo completo de un archivo PPT de entrada: se carga una presentación con 21 diapositivas, su segunda diapositiva se convierte en <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, a continuación se genera el marcado HTML a partir de la instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>, se modifica y el marcado HTML editado se convierte de nuevo en otra instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a>. A partir de este punto, se crean dos instancias de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a>: una está destinada a generar la primera versión de la presentación de salida con una nueva diapositiva y sin eliminaciones, por lo que contendrá en total 22 diapositivas (21 originales + 1 editada). La segunda instancia <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">`PresentationSaveOptions`</a> tiene la propiedad <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/presentationsaveoptions/slidenumberstodelete/" target="_blank" rel="nofollow noopener noreferrer">`SlideNumbersToDelete`</a> configurada para eliminar la primera y la última diapositivas, por lo que la segunda versión de la presentación de salida contendrá en total 20 diapositivas (19 originales + 1 editada).

El archivo PPT de entrada, así como ambas versiones de los archivos PPTX de salida, pueden descargarse aquí:

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Editor;
using GroupDocs.Editor.Formats;
using GroupDocs.Editor.Options;
// ...

// Load input presentation to the Editor and specify loading options
using (Editor editor = new Editor("Presentations-Tips.ppt", new PresentationLoadOptions()))
{
    // Prepare edit options and set 2nd slide to edit
    PresentationEditOptions editOptions = new PresentationEditOptions();
    editOptions.ShowHiddenSlides = true;
    editOptions.SlideNumber = 1;//2nd slide to edit, here SlideNumber is 0-based due to historical reasons

    //generate EditableDocument with original content of 2nd slide
    using (EditableDocument slide2OpenedForEdit = editor.Edit(editOptions))
    {
        // Get the HTML-markup from the EditableDocument with original content
        string originalHtmlContentOf2ndSlide = slide2OpenedForEdit.GetEmbeddedHtml();

        //emulate HTML content editing in WYSIWYG-editor in browser or somewhere else
        string editedHtmlContentOf2ndSlide = originalHtmlContentOf2ndSlide.Replace("Tips to be Covered", "Edited tips on 2nd slide");

        //generate EditableDocument with edited content of 2nd slide
        using (EditableDocument slide2AfterEdit = EditableDocument.FromMarkup(editedHtmlContentOf2ndSlide))
        {
            //prepare save options without deletions
            PresentationSaveOptions saveOptionsWithoutDelete = new PresentationSaveOptions(PresentationFormats.Pptx);
            // let it be the 2nd slide...
            saveOptionsWithoutDelete.SlideNumber = 2;//here SlideNumber is 1-based
            //... and we also save the original 2nd slide, which is pushed to the 3rd position
            saveOptionsWithoutDelete.InsertAsNewSlide = true;

            // So now the presentation must have 22 slides, not 21. Save it to file
            editor.Save(slide2AfterEdit, "Output22Slides-without-delete.pptx", saveOptionsWithoutDelete);

            // Create another save options, with deletions at this time
            PresentationSaveOptions saveOptionsWithDelete = new PresentationSaveOptions(PresentationFormats.Pptx);
            // let the new slide will be 2nd for now, but after deleting it will became the 1st later
            saveOptionsWithDelete.SlideNumber = 2;

            //... and we also save the original 2nd slide, which will be next sibling to the newly inserted
            saveOptionsWithDelete.InsertAsNewSlide = true;

            // delete the 1st and last slide
            saveOptionsWithDelete.SlideNumbersToDelete = new int[2]
            {
                1,//1st slide
                22//last slide is 22, not 21, because we inserted the edited 2nd slide as the new slide instance, without rewriting the original 2nd slide
            };
            // Save it again to distinct file. Output PPTX should have 20 slides now.
            editor.Save(slide2AfterEdit, "Output20Slides-with-delete.pptx", saveOptionsWithDelete);
        }
    }
}
```

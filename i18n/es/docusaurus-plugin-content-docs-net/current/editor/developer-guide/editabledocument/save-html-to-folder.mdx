> Esta demostración muestra cómo abrir un documento de entrada, convertirlo al <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> intermedio y guardarlo en disco como un archivo HTML con una carpeta de recursos.

Casi todos los editores WYSIWYG del lado cliente HTML pueden abrir documentos HTML desde disco (desde una ruta). **GroupDocs.Editor** <a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer"></a> permite abrir cualquier documento compatible, convertirlo a HTML y guardarlo en disco, lo cual puede ser muy útil para editarlo posteriormente en algún editor WYSIWYG. El código siguiente demuestra este ejemplo.

```csharp
string inputFilePath = "C:\\input_path\\document.docx"; //path to some document
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
Editor editor = new Editor(inputFilePath, loadOptions); //passing path and load options to the constructor
EditableDocument document = editor.Edit(new WordProcessingEditOptions());
string outputHtmlFilePath = "C:\\output_path\\document.html"; //path to output HTML document
document.Save(outputHtmlFilePath);
```

En este ejemplo, cargamos el documento de entrada de WordProcessing (DOCX) en la clase `Editor` con opciones de carga específicas para este tipo de documento: <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingloadoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingLoadOptions</a>. Las opciones de carga se pasan correctamente. A continuación, el documento se convierte a <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> mediante el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a>, el cual, a su vez, obtiene el <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/wordprocessingeditoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingEditOptions</a> específico del documento. En la última línea, el contenido se guarda en un archivo HTML en disco, cuya ruta absoluta se especifica. Tenga en cuenta que GroupDocs.Editor creará automáticamente una carpeta adicional con los recursos en el mismo directorio donde se guarda el archivo HTML. Existe otra sobrecarga del método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument/save" target="_blank" rel="nofollow noopener noreferrer">Save()</a> que acepta dos parámetros: la ruta al archivo HTML y la ruta a una carpeta existente donde deben guardarse los recursos. Por ejemplo, las últimas dos líneas pueden reescribirse de la siguiente manera:

```csharp
string outputHtmlFilePath = "C:\\output_path\\document.html"; //path to output HTML document
string outputHtmlFolderPath = "C:\\output_path\\document_files\\";//path to folder, where resources will be saved
document.Save(outputHtmlFilePath, outputHtmlFolderPath);
```

Por cierto, no olvides liberar todos los recursos si no estás utilizando la directiva `using`.

```csharp
document.Dispose();
editor.Dispose();
```

La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> representa un documento de entrada en cualquier formato soportado, que ha sido convertido a un formato intermedio interno según las opciones de edición y que está listo para editarse en editores WYSIWYG HTML. Para ello, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> dispone de numerosos métodos para generar marcado HTML, hojas de estilo y recursos con distintas configuraciones.

## [Marcado HTML](/net/editor/developer-guide/editabledocument/get-html-markup-in-different-forms/) {#html-markup}
  
La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> es capaz de generar marcado HTML en distintas formas: documento completo con cabecera, solo el contenido del elemento BODY, con enlaces externos personalizados para imágenes, fuentes y hojas de estilo, o incluso una versión totalmente incrustada, donde todo el documento HTML con todos sus recursos se presenta como una única cadena de texto.

## [Guardado en disco](/net/editor/developer-guide/editabledocument/save-html-to-folder/) {#saving-to-disk}
  
Para algunos editores WYSIWYG, al cargar el contenido HTML en ellos, es necesario especificar dicho contenido mediante una ruta de archivo. Asimismo, el usuario podría necesitar guardar el documento como HTML en disco en lugar de pasárselo al editor WYSIWYG. Para estos casos, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> ofrece la posibilidad de guardar su contenido en disco como un documento HTML ordinario, representado mediante un archivo \*.html y una carpeta adicional con los recursos (imágenes, hojas de estilo, fuentes).

## [Obtención de recursos](/net/editor/developer-guide/editabledocument/working-with-resources/) {#obtaining-resources}
  
Cuando un documento de entrada en algún formato se convierte a <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> y posteriormente a un documento HTML, este último contiene no solo el marcado HTML, sino también una o más hojas de estilo, posiblemente imágenes y, a veces, incluso fuentes. Todos estos elementos se denominan *recursos*. La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> dispone de varios métodos y propiedades específicamente para trabajar con ellos.

## [Creación de nuevas instancias de EditableDocument](/net/editor/developer-guide/editabledocument/create-editabledocument-from-file-or-markup/) {#creating-new-editabledocument-instances}
  
Abrir un documento para editarlo implica crear instancias de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>, las cuales son devueltas por el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.<a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a>. No obstante, cuando el contenido HTML del documento ha sido enviado al editor HTML WYSIWYG y editado por el usuario final, para guardarlo de nuevo en el formato de salida, el usuario debe crear previamente una nueva instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>. Para ello, la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> dispone de tres métodos estáticos que permiten crear instancias a partir de documentos HTML guardados en disco (como archivo \*.html con carpeta de recursos), en memoria (como marcado HTML con clases de recursos) o generados directamente por el editor HTML WYSIWYG (como marcado HTML interno del elemento BODY y carpeta de recursos).

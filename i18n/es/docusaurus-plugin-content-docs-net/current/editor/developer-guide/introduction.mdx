> Este artículo explica los principios más comunes y fundamentales de GroupDocs.Editor, cómo funciona, cuál es su propósito y cómo debe utilizarse.

<a href="https://products.groupdocs.com/editor/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Editor**</a> es una biblioteca de clases .NET sin interfaz gráfica (GUI), lo que significa que solo dispone de una interfaz programática (API). Este hecho implica que, para editar un documento, el usuario debe utilizar GroupDocs.Editor junto con alguna aplicación de editor de terceros, a través de cuya GUI el usuario final pueda editar el contenido del documento. Para GroupDocs.Editor no es relevante qué software de editor concreto se utilice; sin embargo, dado que GroupDocs.Editor está orientado al desarrollo web, tiene un único requisito: el editor de terceros debe ser compatible con documentos HTML.

Para editar un documento con GroupDocs.Editor, el usuario debe realizar varios pasos secuenciales: cargar el documento en GroupDocs.Editor (mediante opciones de carga opcionales), abrir el documento para su edición (con opciones de edición opcionales), generar el marcado HTML con sus recursos (empleando distintas opciones y configuraciones), y pasar este marcado a un editor HTML WYSIWYG de terceros. A continuación, el usuario final edita el contenido del documento; una vez finalizada la edición y enviada la versión modificada, dicho marcado modificado debe devolverse a GroupDocs.Editor y convertirse en un documento de salida en el formato deseado.

Desde la perspectiva de GroupDocs.Editor, esta secuencia puede dividirse condicionalmente en tres etapas principales, que se describen a continuación.

## Carga del documento en GroupDocs.Editor {#loading-document-into-the-groupdocs-editor}

En la etapa de *[carga del documento](/net/editor/developer-guide/load-document/)*, el usuario debe crear una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">`Editor`</a> y pasarle el documento de entrada (mediante una ruta de archivo o un flujo de bytes), junto con las opciones de carga del documento. Las opciones de carga no son obligatorias, ya que GroupDocs.Editor puede detectar automáticamente el formato del documento y seleccionar las opciones predeterminadas más adecuadas para dicho formato. No obstante, se recomienda especificarlas explícitamente, ya que son imprescindibles al intentar cargar documentos protegidos con contraseña.

```csharp
string inputFilePath = "C:\\input_path\\document.docx"; //path to some document
Editor editor = new Editor(inputFilePath); //passing path to the constructor, default WordProcessingLoadOptions will be applied automatically
```

Una vez finalizada esta etapa, el documento queda listo para ser abierto y editado.

## Apertura de un documento para su edición {#opening-a-document-for-editing}

Dado que GroupDocs.Editor es una biblioteca sin interfaz gráfica (GUI), el documento no puede editarse directamente dentro de ella. Sin embargo, para editar un documento en un editor HTML WYSIWYG, GroupDocs.Editor debe generar una versión en HTML del documento, ya que cualquier editor WYSIWYG solo puede trabajar con marcado HTML/CSS. Cuando se crea una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a> en la primera etapa, el usuario debe *[abrir el documento para su edición](/net/editor/developer-guide/edit-document/)* invocando el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a> de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>. Este método devuelve una instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>. Dicha clase puede describirse como una versión convertida del documento de entrada, almacenada en un formato intermedio interno compatible con todos los formatos que admite GroupDocs.Editor. Con <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a>, el usuario puede obtener el marcado HTML del documento de entrada con distintas opciones, hojas de estilo, imágenes, fuentes, guardar el documento HTML en disco y otras acciones. Se supone que el marcado HTML generado por <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> se pasa posteriormente a un editor HTML WYSIWYG del lado del cliente, donde el usuario final puede editar efectivamente el documento.

Al igual que en la etapa de carga, el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/edit" target="_blank" rel="nofollow noopener noreferrer">Edit()</a> acepta herederos opcionales de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/ieditoptions" target="_blank" rel="nofollow noopener noreferrer">IEditOptions</a>, que controlan exactamente cómo se abrirá el documento para su edición.

```csharp
WordProcessingEditOptions editOptions = new WordProcessingEditOptions();
editOptions.EnableLanguageInformation = true;

EditableDocument readyToEdit = editor.Edit(editOptions);
```

Tras esta etapa, el documento está listo para ser pasado al editor HTML WYSIWYG, y su contenido puede ser editado por el usuario final.

## Guardado del documento {#saving-a-document}

*[Guardar un documento](/net/editor/developer-guide/save-document/)* es la etapa final, que se produce cuando el contenido del documento ha sido editado en el editor HTML WYSIWYG (o en cualquier otro software, lo cual no supone ninguna diferencia para GroupDocs.Editor) y debe guardarse nuevamente como un documento en algún formato (por ejemplo, DOCX, PDF o XLSX). En esta etapa, el usuario debe crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">EditableDocument</a> con el marcado HTML y los recursos de la versión editada del documento original, obtenida del usuario final. La clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> contiene varios métodos estáticos que permiten crear instancias a partir de documentos HTML que pueden presentarse en distintas formas. Una vez que la instancia de <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editabledocument" target="_blank" rel="nofollow noopener noreferrer">`EditableDocument`</a> está lista, es posible guardarla como un documento normal mediante el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/save" target="_blank" rel="nofollow noopener noreferrer">Save()</a> de la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a>.

```csharp
EditableDocument afterEdit = EditableDocument.FromMarkup("<body>HTML content of the document...</body>", null);
string outputFilePath = "C:\\output_path\\document.rtf";
Options.WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(WordProcessingFormats.Rtf);
editor.Save(afterEdit, outputFilePath, saveOptions);
```

A diferencia de las opciones anteriores de carga y edición, las opciones de guardado son obligatorias, ya que GroupDocs.Editor necesita conocer el formato exacto del documento para guardarlo.

## Detección del tipo de documento {#detecting-document-type}

En ocasiones es necesario *[detectar el tipo de documento y extraer sus metadatos](/net/editor/developer-guide/extracting-document-metainfo/)* antes de enviarlo para su edición. Para tales escenarios, GroupDocs.Editor permite detectar el tipo de documento y extraer la metainformación más necesaria, dependiendo del tipo de documento:

1. Si el documento está codificado o no;
2. Formato exacto del documento;
3. Tamaño del documento;
4. Número de páginas (pestañas);
5. Codificación de texto, si el documento es de texto.

Para detectar el tipo de documento y recopilar su metainformación, el usuario debe cargar el documento deseado en la clase <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor" target="_blank" rel="nofollow noopener noreferrer">Editor</a> y, a continuación, invocar el método <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor/editor/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo()</a>.

## Descripción de las opciones {#describing-options}

En cada etapa, el usuario puede ajustar (configurar) el procesamiento mediante distintas opciones:

1. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/iloadoptions" target="_blank" rel="nofollow noopener noreferrer">ILoadOptions</a> para *cargar* el documento.
2. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/ieditoptions" target="_blank" rel="nofollow noopener noreferrer">IEditOptions</a> para abrir el documento para su *edición*.
3. <a href="https://reference.groupdocs.com/editor/net/groupdocs.editor.options/isaveoptions" target="_blank" rel="nofollow noopener noreferrer">ISaveOptions</a> para *guardar* el documento editado.

Algunas de estas opciones pueden ser opcionales en casos específicos, mientras que otras son obligatorias. Por ejemplo, es posible cargar un documento en la clase `Editor` sin especificar opciones de carga; en tal caso, GroupDocs.Editor intentará detectar automáticamente el formato del documento y aplicar las opciones predeterminadas más adecuadas para el formato detectado.

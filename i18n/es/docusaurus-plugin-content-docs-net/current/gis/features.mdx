Aspose.GIS para .NET proporciona un conjunto amplio de funcionalidades para trabajar con datos almacenados en formatos de archivos GIS comunes. Puede leer y escribir datos vectoriales GIS, convertir entre formatos de archivos GIS, crear y analizar geometrías de entidades, y renderizar mapas en SVG.

## Formatos admitidos {#supported-formats}
  
Los principales formatos de archivo admitidos son:  

- Shapefile
- GeoJSON
- ESRI File Geodatabase (FileGDB)
- Geography Markup Language (GML)
- Keyhole Markup Language (KML)
- Scalable Vector Graphics (SVG)
- Bases de datos (PostGIS, SQL Server)
- GeoTIFF  

Consulte [Formatos de archivo admitidos](/net/gis/supported-file-formats/) para obtener la lista completa.

## Leer y escribir datos vectoriales {#read-and-write-vector-data}  

- Leer datos vectoriales
  - Iterar sobre las entidades de una capa
  - Leer entidades de capa por índice
  - Recuperar metadatos sobre capas vectoriales
- Escribir datos vectoriales
  - Crear nuevas capas y conjuntos de datos
- Trabajar con conjuntos de datos multilayer
  - Listar capas existentes
  - Añadir nuevas capas
  - Eliminar capas de un conjunto de datos
- Construir índices espaciales para acelerar consultas espaciales.

## Convertir datos vectoriales {#convert-vector-data}  

- Convertir datos a cualquier formato admitido
- Realizar reproyección durante la conversión de datos
- Ajustar atributos de entidades durante la conversión

## Visualizar datos {#visualize-data}  

- Renderizar mapas en SVG, PNG, JPEG o BMP
- Personalizar el estilo para cada tipo de geometría
- Combinar varios simbolizadores para realizar dibujos complejos
- Controlar la representación visual de una entidad mediante reglas de renderizado de capa
- Calcular parámetros de estilo de una entidad basándose en los valores de sus atributos  

Consulte [Renderizado de mapas](/net/gis/map-rendering/) para obtener más detalles.

## Manipular geometrías {#manipulate-geometries}  

- Crear puntos, líneas y polígonos desde cero
- Editar geometrías existentes
- Etiquetar objetos en un mapa.
- Construir geometrías no lineales (curvas)
- Linealizar geometrías no lineales (curvas)
- Importar y exportar geometrías desde/hacia WKT y WKB
- Controlar el modelo de precisión de los cálculos

## Realizar análisis de datos vectoriales {#perform-vector-data-analysis}  

- Determinar si dos geometrías se intersecan entre sí.
- Comprobar si las geometrías se superponen, se tocan en los bordes, se intersecan y otras relaciones entre geometrías.
- Calcular distancias entre geometrías
- Calcular envolventes convexas, centroides y áreas de buffer de geometrías
- Calcular intersecciones, uniones o diferencias entre cualquier geometría.

## Utilizar sistemas de referencia espacial {#use-spatial-reference-systems}  

- Buscar sistemas de referencia espacial por SRID
- Leer información SRS desde archivos de datos
- Asignar un SRS a los datos que crea
- Reproyectar geometrías individuales y capas completas
- Importar sistemas de referencia espacial desde WKT, exportar sistemas de referencia espacial a WKT

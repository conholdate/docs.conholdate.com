La siguiente tabla indica los formatos de vectores que Aspose.GIS para .NET puede leer o escribir.

<div className="docs-owner-markdown-table">

| **Descripción** | **Formato** | **Lectura** | **Escritura** |
| ------------------------------- | ---------------------------- | --------- | --------- |
| ESRI Shapefile | .shp, .shx, .dbf, .qix, .cpg | Compatible | Compatible |
| GeoJSON | .json, .geojson | Compatible | Compatible |
| GeoJSON Seq | .json, .geojson | Compatible | Compatible |
| ESRI File Geodatabase (FileGDB) | .gdb | Compatible | Compatible |
| Geography Markup Language | .gml | Compatible |  |
| Keyhole Markup Language | .kml | Compatible | Compatible |
| GPS Exchange Format | .gpx | Compatible | Compatible |
| TopoJSON | .json, .topojson | Compatible | Compatible |
| MapInfo Interchange Format | .mif | Compatible |  |
| MapInfo TAB format | .tab, .dat, .dbf, .map, .id | Compatible | Compatible |
| OpenStreetMap (OSM) XML | .osm | Compatible |  |
| Comma-Separated Values | .csv | Compatible | Compatible |

</div>

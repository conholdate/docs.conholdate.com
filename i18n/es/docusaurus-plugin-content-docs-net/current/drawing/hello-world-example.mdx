## Ejemplo de "Hola Mundo" {#hello-world-example}
  
Este ejemplo de "Hola Mundo" presenta las funciones de dibujo de la API Aspose.Drawing para .NET mediante un dibujo sencillo de gráficos vectoriales.  

Aspose.Drawing para .NET es una biblioteca de manipulación de imágenes y dibujo vectorial con muchas funciones, utilizada para dibujar primitivas gráficas vectoriales, como líneas, curvas y figuras. Estas se especifican mediante conjuntos de puntos en un sistema de coordenadas, para mostrar texto en diversas fuentes, tamaños y estilos, y para guardar los resultados del dibujo en formatos de archivo gráfico comúnmente utilizados. Este ejemplo muestra cómo dibujar un arco utilizando C# con los siguientes pasos.  

1. Instanciar un objeto de la clase Bitmap
2. Inicializar un objeto de la clase Graphics a partir de este mapa de bits
3. Definir un objeto Pen con los parámetros deseados
4. Utilizar el método DrawArc del objeto de la clase Graphics para dibujar un arco

```csharp
// For complete examples and data files, please go to https://github.com/aspose-drawing/Aspose.Drawing-for-.NET

using System.Drawing;

Bitmap bitmap = new Bitmap(1000, 800, System.Drawing.Imaging.PixelFormat.Format32bppPArgb);
Graphics graphics = Graphics.FromImage(bitmap);

Pen pen = new Pen(Color.Blue, 2);
graphics.DrawArc(pen, 0, 0, 700, 700, 0, 180);

bitmap.Save("DrawArc.png");
```

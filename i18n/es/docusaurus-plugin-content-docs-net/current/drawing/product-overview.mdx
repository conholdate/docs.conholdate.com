**Bienvenido a Aspose.Drawing para .NET**

Aspose.Drawing es una biblioteca gráfica 2D completa, totalmente administrada y multiplataforma, diseñada para dibujar texto, geometrías e imágenes. Aspose.Drawing proporciona una API compatible con System.Drawing, lo que facilita enormemente que su código existente que utiliza SystemDrawing se convierta verdaderamente en una solución multiplataforma. Construida sobre .NET Standard 2.0, Aspose.Drawing puede utilizarse en escenarios web, móviles, de escritorio, en la nube y de IoT. El motor de dibujo admite la representación de gráficos vectoriales (como líneas, curvas y figuras) y texto (en una amplia variedad de fuentes, tamaños y estilos) sobre imágenes rasterizadas en todos los formatos de archivo gráfico comúnmente utilizados.

## Descripción del producto {#product-description}
  
Aspose.Drawing para .NET es una biblioteca .NET robusta que permite a los desarrolladores trabajar con dibujos y gráficos bidimensionales sin necesidad de ningún otro software. Proporciona una interfaz de programación de aplicaciones (API) sencilla, fácil de aprender y utilizar.

Aspose.Drawing para .NET se implementa mediante C# administrado y puede utilizarse con cualquier lenguaje .NET, como C#, VB.NET y F#, entre otros. Puede integrarse con cualquier tipo de aplicación, ya sea una aplicación web ASP.NET o una aplicación de Windows. Para facilitar a los desarrolladores el inicio rápido, Aspose.Drawing para .NET proporciona demos completas y ejemplos funcionales escritos en C#. Mediante estas demos, los desarrolladores pueden aprender rápidamente sobre las funcionalidades ofrecidas por la API.

La biblioteca rápida y ligera crea imágenes de forma eficiente y ayuda a que su aplicación funcione mejor. Es segura para entornos multiproceso, siempre que solo un subproceso trabaje en una imagen a la vez. Es un escenario típico tener un subproceso trabajando en una sola imagen. Diferentes subprocesos pueden trabajar de forma segura en imágenes distintas simultáneamente.

## Declaración {#declaration}
  
Todas las bibliotecas de Aspose para .NET requieren el conjunto de permisos de plena confianza (*Full Trust*). Esto se debe a que las bibliotecas de Aspose para .NET necesitan acceder a la configuración del registro, archivos del sistema y otros recursos distintos del directorio virtual para ciertas operaciones, como el análisis de fuentes, entre otras. Además, las bibliotecas de Aspose para .NET se basan en clases fundamentales del sistema .NET, que en muchos casos también requieren el conjunto de permisos de plena confianza.

Los proveedores de servicios de Internet (ISP) que alojan múltiples aplicaciones de distintas empresas suelen imponer el nivel de seguridad de confianza media (*Medium Trust*). En el caso de .NET 2.0, este nivel de seguridad impone las siguientes restricciones:  

- **OleDbPermission no está disponible**. Esto significa que no puede utilizar el proveedor de datos administrado OLE DB de ADO.NET para acceder a bases de datos.
- **EventLogPermission no está disponible**. Esto significa que no puede acceder al registro de eventos de Windows.
- **ReflectionPermission no está disponible**. Esto significa que no puede utilizar reflexión.
- **RegistryPermission no está disponible**. Esto significa que no puede acceder al registro.
- **WebPermission está restringida**. Esto significa que su aplicación solo puede comunicarse con una dirección o rango de direcciones que usted defina en el elemento.
- **FileIOPermission está restringida**. Esto significa que solo puede acceder a archivos dentro de la jerarquía del directorio virtual de su aplicación.

Debido a las razones indicadas anteriormente, las bibliotecas de Aspose para .NET no pueden utilizarse en servidores que otorguen conjuntos de permisos distintos de plena confianza (*Full Trust*).

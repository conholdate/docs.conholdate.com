Un ejemplo de «Hola Mundo» se utiliza tradicionalmente para presentar las características de un lenguaje de programación o software mediante un caso de uso sencillo.

Aspose.PDF para .NET es una API de PDF rica en funciones que permite a los desarrolladores integrar capacidades de creación, manipulación y conversión de documentos PDF en sus aplicaciones .NET. Admite el trabajo con muchos formatos de archivo populares, incluidos PDF, XFA, TXT, HTML, PCL, XML, XPS, EPUB, TEX y formatos de archivo de imagen. En este artículo, creamos un documento PDF que contiene el texto «¡Hola Mundo!». Después de instalar Aspose.PDF para .NET en su entorno, puede ejecutar el siguiente fragmento de código para ver cómo funciona la API de Aspose.PDF.

El siguiente fragmento de código también funciona con la biblioteca [Aspose.PDF.Drawing](/net/pdf/drawing/).

El siguiente fragmento de código sigue estos pasos:  

1. Instanciar un objeto <a href="https://reference.aspose.com/pdf/net/aspose.pdf/document" target="_blank" rel="nofollow noopener noreferrer">Document</a>.
2. Agregar una <a href="https://reference.aspose.com/pdf/net/aspose.pdf/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> al objeto del documento.
3. Crear un objeto <a href="https://reference.aspose.com/pdf/net/aspose.pdf.text/textfragment" target="_blank" rel="nofollow noopener noreferrer">TextFragment</a>.
4. Agregar TextFragment a la colección <a href="https://reference.aspose.com/pdf/net/aspose.pdf/page/properties/paragraphs" target="_blank" rel="nofollow noopener noreferrer">Paragraph</a> de la página.
5. <a href="https://reference.aspose.com/pdf/net/aspose.pdf.document/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Guardar</a> el documento PDF resultante.

El siguiente fragmento de código es un programa «Hola Mundo» que muestra el funcionamiento de la API de Aspose.PDF para .NET.

```csharp
// For complete examples and data files, visit https://github.com/aspose-pdf/Aspose.PDF-for-.NET
private static void HelloWorld()
{
    // The path to the documents directory
    var dataDir = RunExamples.GetDataDir_AsposePdf();

    // Create PDF document
    using (var document = new Aspose.Pdf.Document())
    {
        // Add page
        var page = document.Pages.Add();
        // Add text to new page
        page.Paragraphs.Add(new Aspose.Pdf.Text.TextFragment("Hello World!"));
        // Save PDF document
        document.Save(dataDir + "HelloWorld_out.pdf");
    }
}
```

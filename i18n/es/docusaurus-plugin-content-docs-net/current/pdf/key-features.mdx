## Software multiplataforma {#cross-platform-software}
  
Admite diversas plataformas y versiones de .NET. Consulte [Requisitos del sistema](/net/pdf/system-requirements/) para obtener más detalles.

## Características generales {#general-features}
  
Aspose.PDF proporciona un modelo de objetos de documento (DOM) potente para explorar y modificar todo tipo de contenido PDF. Admite la carga desde y el guardado en una amplia lista de [formatos de archivo](/net/pdf/supported-file-formats/).

## Normas PDF admitidas {#supported-pdf-standards}  

- ISO 32000-1 (PDF 1.2, PDF 1.3, PDF 1.4, PDF 1.5, PDF 1.6, PDF 1.7).
- ISO 32000-2 (PDF 2.0).
- ISO 19005 (PDF/A), ISO 15930 (PDF/X), ISO 24517 (PDF/E), ISO 14289 (PDF/UA).

## Capacidades de IA {#ai-capabilities}
  
Admite diversos proveedores de IA con la capacidad de cargar datos desde documentos PDF.

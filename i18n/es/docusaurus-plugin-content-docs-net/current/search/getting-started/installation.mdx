## Instalación desde NuGet {#install-from-nuget}

NuGet es la forma más sencilla de descargar e instalar GroupDocs.Search para .NET. Existen varias formas de instalarlo en su proyecto.

#### Instalación mediante la interfaz gráfica del Administrador de paquetes {#install-via-package-manager-gui}

Siga estos pasos para hacer referencia a GroupDocs.Search mediante la interfaz gráfica del Administrador de paquetes:

*   Abra su solución/proyecto en Visual Studio.
*   Haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Administrar paquetes NuGet para la solución**.  
    You can also access the same option through the Solution Explorer. Right-click the solution or project and select Manage NuGet Packages from the context menu.
*   Seleccione la pestaña **Browse** y escriba «GroupDocs.Search» o «GroupDocs.Search.NETFramework» en el cuadro de texto de búsqueda.
*   Haga clic en el botón **Install** para instalar la versión más reciente de la API en su proyecto, como se muestra en la siguiente captura de pantalla.

![](/net/search/images/installation.png)

#### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}

Puede seguir los pasos que se indican a continuación para hacer referencia a GroupDocs.Search para .NET mediante la Consola del Administrador de Paquetes:

*   Abra su solución/proyecto en Visual Studio.
*   Seleccione **Herramientas** > **Administrador de paquetes NuGet** > **Consola del Administrador de paquetes** en el menú para abrir la consola del administrador de paquetes.
*   Escriba el comando `Install-Package GroupDocs.Search` o `Install-Package GroupDocs.Search.NETFramework` y presione Intro para instalar la versión más reciente en su aplicación.  
    After successful installation, GroupDocs.Search will be referenced in your application.  

![](/net/search/images/installation_1.png)

```
PM> NuGet\Install-Package GroupDocs.Search
```

```
PM> NuGet\Install-Package GroupDocs.Search.NETFramework
```

## Instalación desde el sitio web oficial de GroupDocs {#install-from-official-groupdocs-website}

Puede seguir los pasos que se indican a continuación para hacer referencia a GroupDocs.Search para .NET descargado desde la sección <a href="https://downloads.groupdocs.com/search/net" target="_blank" rel="nofollow noopener noreferrer">Descargas</a> del sitio web oficial:

1.  Descomprima el archivo ZIP o siga las instrucciones del asistente de instalación MSI.
2.  En el Explorador de soluciones, expanda el nodo del proyecto al que desea agregar una referencia.
3.  Haga clic con el botón derecho en el nodo **Referencias** del proyecto y seleccione **Agregar referencia** en el menú.
4.  En el cuadro de diálogo **Agregar referencia**, seleccione la pestaña **.NET** (normalmente ya está seleccionada de forma predeterminada).
5.  Si ha utilizado el instalador MSI para instalar GroupDocs.Search, verá **GroupDocs.Search** en el panel superior. Selecciónelo y, a continuación, haga clic en el botón **Seleccionar**.
6.  Si ha descargado y descomprimido únicamente el archivo DLL, haga clic en el botón **Examinar** y localice el archivo **GroupDocs.Search.dll**.   
    You have referenced GroupDocs.Search and it should appear in the **SelectedComponents** pane of the dialog box.
7. Haga clic en **Aceptar**.  
    GroupDocs.Search reference appears under the **References** node of the project.

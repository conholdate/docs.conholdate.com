Esta página contiene una lista de las características admitidas. Para obtener información detallada sobre una característica específica, consulte las páginas correspondientes en la sección [Uso avanzado](/net/search/developer-guide/advanced-usage/).

## Indexación {#indexing}

GroupDocs.Search proporciona las siguientes características de indexación:

*   Crear un índice en memoria o en disco.
*   Actualizar el índice para tener en cuenta los documentos modificados, eliminados y añadidos.
*   Fusionar varios índices en uno solo.
*   Optimizar el índice para mejorar el rendimiento de la búsqueda.
*   Capacidad de indexar desde un archivo, flujo o estructura.
*   Indexación de documentos protegidos con contraseña.
*   Indexación con palabras vacías (stop words).
*   Soporte para campos adicionales durante la indexación.
*   Soporte para caracteres combinados.
*   Soporte para caracteres indexados como palabras completas.
*   Soporte para sustitución de caracteres durante la indexación.
*   Soporte para extractores de texto personalizados.
*   Opciones para índices compactos y de metadatos.
*   Capacidad de guardar el texto extraído en el índice con distintos niveles de compresión.
*   Filtrado de documentos durante la indexación.
*   Eliminación de rutas indexadas del índice.
*   Capacidad de extraer datos de documentos de forma independiente y luego indexarlos.
*   Soporte para reconocimiento óptico de caracteres (OCR) en imágenes.
*   Cálculo e indexación de hashes de imágenes para la búsqueda inversa de imágenes.
*   Capacidad de crear una red de búsqueda distribuida que equilibre automáticamente la carga entre los nodos.

## Búsqueda {#searching}

GroupDocs.Search proporciona las siguientes características de búsqueda:

*   Búsqueda simple por palabras.
*   Búsqueda booleana.
*   Búsqueda mediante expresiones regulares.
*   Búsqueda por facetas.
*   Búsqueda sensible a mayúsculas y minúsculas.
*   Búsqueda difusa flexible.
*   Búsqueda de sinónimos.
*   Búsqueda de homófonos.
*   Búsqueda con comodines.
*   Búsqueda de frases con comodines.
*   Búsqueda de distintas formas de una palabra.
*   Búsqueda por rango de fechas.
*   Búsqueda por rango numérico.
*   Búsqueda por fragmentos (páginas).
*   Filtrado de documentos en los resultados de la búsqueda.
*   Búsqueda de distintos tipos de objetos: texto, números, fechas, nombres de archivos, tipos de documentos, campos de metadatos, fechas de creación/modificación de documentos.
*   Combinar distintos tipos de búsqueda en una única consulta.
*   Sustitución de alias en consultas de búsqueda.
*   Realizar corrección ortográfica durante la búsqueda.
*   Realizar corrección de diseño de teclado durante la búsqueda.
*   Consultas de búsqueda en formato de texto o de objeto flexible.
*   Resaltado de resultados de búsqueda en el texto completo del documento o en fragmentos de texto.
*   Búsqueda simultánea segura para subprocesos múltiples.
*   Búsqueda segura para subprocesos durante operaciones de indexación, actualización o fusión.
*   Búsqueda simultánea en varios índices.
*   Soporte integrado para la búsqueda inversa de imágenes.

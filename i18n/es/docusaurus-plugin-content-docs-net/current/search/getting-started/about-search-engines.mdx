Esta página trata sobre la clasificación de los motores de búsqueda y el lugar que ocupa la API de GroupDocs.Search dentro de dicha clasificación. Existen numerosas formas de clasificar los motores de búsqueda. A continuación se presentan las principales.

Según el área de búsqueda, los motores de búsqueda pueden dividirse condicionalmente en 3 grupos:

*   **Global.** Los motores de búsqueda globales están diseñados para buscar información en toda Internet o en una parte significativa de ella.
*   **Local.** Los motores de búsqueda locales están diseñados para buscar información en cualquier parte de la red global, por ejemplo, en uno o más sitios web o en una red local. Estos motores de búsqueda suelen utilizarse dentro de redes privadas (empresariales) o en sistemas de comercio electrónico (tiendas en línea).
*   **Personal.** Los motores de búsqueda personales se utilizan para buscar entre archivos en computadoras personales o en pequeñas redes locales.

Según la fuente de datos, los motores de búsqueda se dividen en los siguientes grupos:

*   **De escritorio.** Las herramientas de búsqueda de escritorio buscan información en la PC del usuario, incluyendo el historial del navegador web, archivos de correo electrónico, documentos de texto, archivos de audio, imágenes y videos.
*   **Federados.** La búsqueda federada es una tecnología de recuperación de información que permite al usuario buscar simultáneamente múltiples recursos de búsqueda de distintos tipos. El usuario realiza una única solicitud, que se aplica a bases de datos, índices u otros motores de búsqueda que participan en la federación. Los resultados de búsqueda se combinan y se presentan al usuario. La búsqueda federada se utiliza, por ejemplo, para integrar recursos de información dispares dentro de una organización grande.
*   **Humanos.** Un motor de búsqueda humano es un sistema que utiliza la participación humana para filtrar los resultados de búsqueda y ayudar a los usuarios a refinar su consulta. El objetivo es ofrecer a los usuarios un número limitado de resultados relevantes, a diferencia de los motores de búsqueda tradicionales, que suelen devolver muchos resultados, algunos de los cuales pueden ser relevantes y otros no.
*   **Metabúsqueda.** Un motor de metabúsqueda es una herramienta para buscar información en Internet que utiliza los resultados de otros motores de búsqueda web para obtener sus propios resultados. Los motores de metabúsqueda reciben la solicitud del usuario y realizan inmediatamente peticiones a los motores de búsqueda. Los resultados obtenidos se procesan y se presentan al usuario.
*   **Web.** Un motor de búsqueda web es un sistema de software diseñado para buscar en Internet. Los resultados de búsqueda suelen presentarse como un conjunto de enlaces a páginas web, imágenes, videos, infografías, artículos y otros tipos de archivos.

Según el tipo de contenido, los motores de búsqueda se dividen en:

*   **De texto completo.** La búsqueda de texto completo implica buscar uno o más documentos en una base de datos de texto completo. Cada uno de estos documentos es un archivo independiente en algún formato. La búsqueda de texto completo difiere de la búsqueda por metadatos o por fragmentos de textos originales presentes en bases de datos (como títulos, resúmenes, secciones individuales o referencias bibliográficas) y normalmente se realiza en todo el contenido de cada documento indexado.
*   **De imágenes.** Un motor de búsqueda de imágenes es un sistema informático para visualizar, buscar y recuperar imágenes de una gran base de datos de imágenes digitales. Para poder buscar imágenes, se añaden algunos metadatos a las imágenes, ya sea manualmente o mediante sistemas de reconocimiento de imágenes.
*   **De video.** Los motores de búsqueda de video son programas informáticos diseñados para buscar videos almacenados en dispositivos digitales. La búsqueda se realiza en metadatos indexados que se generan automáticamente a partir del material audiovisual.

Según el tipo de interfaz de interacción, los motores de búsqueda se dividen en:

*   **Búsqueda normal.** La búsqueda normal implica introducir una consulta de búsqueda y recuperar posteriormente los resultados en forma de lista.
*   **Búsqueda incremental.** La búsqueda incremental es un tipo de interfaz de búsqueda caracterizado por la provisión de resultados al usuario mientras este escribe la consulta de búsqueda. El usuario también puede elegir finalizar su consulta de búsqueda a partir de la lista propuesta.
*   **Búsqueda semántica.** La búsqueda semántica se refiere a la búsqueda con significado, a diferencia de la búsqueda léxica, en la que el motor de búsqueda busca coincidencias literales de palabras o sus variantes, sin comprender el significado general de la consulta.
*   **Búsqueda basada en selección.** Un sistema de búsqueda basado en selección es un motor de búsqueda en el que el usuario realiza una consulta seleccionando entre las opciones propuestas.
*   **Búsqueda por voz.** La búsqueda por voz es una interfaz que permite a los usuarios introducir consultas de búsqueda hablándolas en el micrófono de un dispositivo digital.

Los sistemas de gestión de bases de datos también son motores de búsqueda, ya que siempre disponen de mecanismos para indexar datos y realizar búsquedas sobre ellos. Diversas bases de datos difieren en la forma en que se almacenan los datos y en los tipos de índices creados:

*   **Sistema de gestión de bases de datos relacionales.** Una base de datos relacional es una base de datos digital basada en el modelo relacional u orientado a tablas de datos.
*   **Almacén de documentos.** Una base de datos orientada a documentos es un programa informático diseñado para almacenar, recuperar y gestionar información orientada a documentos, también conocida como datos semiestructurados.
*   **Almacén clave-valor.** Una base de datos clave-valor es un paradigma de almacenamiento de datos para almacenar, recuperar y gestionar arrays asociativos, así como una estructura de datos más conocida hoy en día como diccionario o tabla hash.
*   **Sistema de gestión de bases de datos de grafos.** Una base de datos de grafos es una base de datos que utiliza estructuras de grafos para consultas semánticas, con nodos, aristas y propiedades para representar y almacenar datos.
*   **Sistema de gestión de bases de datos orientadas a objetos.** Una base de datos orientada a objetos es una base de datos en la que la información se representa en forma de objetos, tal como se utilizan en la programación orientada a objetos.
*   **Sistema de gestión de bases de datos multimodelo.** Un sistema de gestión de bases de datos multimodelo es un SGBD que proporciona la capacidad de almacenar y trabajar con datos utilizando diversos paradigmas.

De acuerdo con los tipos de clasificación anteriores, la API de GroupDocs.Search pertenece a los siguientes tipos de motores de búsqueda:

*   **Según el área de búsqueda:** motor de búsqueda personal o corporativo (local) de texto completo.
*   **Según la fuente de datos:** índice de búsqueda de texto completo de escritorio o federado.
*   **Según el tipo de contenido:** base de datos de búsqueda de texto completo, motor de búsqueda de imágenes (búsqueda inversa de imágenes y OCR). Además, la API también puede extraer metadatos de archivos de imagen y video, así como añadir campos opcionales arbitrarios a cualquier documento indexado.
*   **Según el tipo de interfaz de interacción:** normal, con la capacidad de recuperar resultados por fragmentos (*chunks*).
*   **Según el tipo de índice:** base de datos de tipo almacén de documentos NoSQL.

## Descripción general {#overview}

GroupDocs.Search para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en la página [Instalación](/net/search/getting-started/installation/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Search para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado el framework .NET, incluidos, entre otros:

### Windows {#windows}

*   Microsoft Windows Server 2003 (x64, x86)
*   Microsoft Windows Server 2008 (x64, x86)
*   Microsoft Windows Server 2012 (x64, x86)
*   Microsoft Windows Server 2012 R2 (x64, x86)
*   Microsoft Windows Server 2016 (x64, x86)
*   Microsoft Windows Server 2019 (x64, x86)
*   Microsoft Windows Vista (x64, x86)
*   Microsoft Windows XP (x64, x86)
*   Microsoft Windows 7 (x64, x86)
*   Microsoft Windows 8, 8.1 (x64, x86)
*   Microsoft Windows 10 (x64, x86)
*   Microsoft Windows 11 (x64, x86)

### Linux {#linux}

- Linux (Ubuntu, OpenSUSE, CentOS y otros)

## Entornos de desarrollo {#development-environments}

GroupDocs.Search para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET; sin embargo, los entornos explícitamente compatibles son los siguientes:

*   Microsoft Visual Studio 2012
*   Microsoft Visual Studio 2013
*   Microsoft Visual Studio 2015
*   Microsoft Visual Studio 2017
*   Microsoft Visual Studio 2019
*   Microsoft Visual Studio 2022

GroupDocs.Search para .NET está incluido en Conholdate.Total for .NET.
:::


:::info
Puede utilizar GroupDocs.Search sin licencia. El uso y las funcionalidades son prácticamente iguales a los de la versión con licencia, pero enfrentará algunas limitaciones al utilizar la API sin licencia.
:::


## Limitaciones de la versión de evaluación {#evaluation-version-limitations}

Puede descargar fácilmente GroupDocs.Search para evaluación. La versión descargada para evaluación es idéntica a la versión descargada tras la compra. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. En caso de utilizar la API sin licencia, se enfrentará a las siguientes limitaciones.  

### Limitaciones de indexación {#indexing-limitations}

A continuación se presentan las limitaciones de indexación que el usuario encontrará al utilizar la versión de prueba de la **GroupDocs.Search API**:

*   El número total de documentos indexados en un índice o en varios índices de un repositorio de índices no puede superar los 100 archivos.
*   La indexación se detiene cuando el número de documentos indexados en un índice o en todos los índices del repositorio de índices alcanza los 100.
*   Todos los archivos modificados pueden actualizarse en un índice durante la operación de actualización.
*   Los nuevos archivos solo pueden agregarse a un índice durante la actualización si el número total de documentos indexados es inferior a 100.

### Limitaciones de búsqueda {#searching-limitations}

Solo se devuelven los primeros 10 documentos en el resultado de la búsqueda.

## Licenciamiento {#licensing}

El archivo de licencia contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará su validez. Debe establecer una licencia antes de utilizar la API de GroupDocs.Search si desea evitar sus limitaciones de evaluación. 

La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Search.dll y especificar el nombre del archivo, sin ruta de acceso, como se muestra en los ejemplos siguientes.

### Aplicación de licencia desde un archivo {#applying-license-from-file}

El siguiente código explica cómo aplicar la licencia del producto.

**C#**

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-search/GroupDocs.Search-for-.NET

//initialize License
License lic = new License();

//Set license
lic.SetLicense("GroupDocs.Search.lic");
```

### Aplicación de licencia desde un flujo {#applying-license-from-stream}

El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

**C#**

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-search/GroupDocs.Search-for-.NET
using (FileStream fileStream = new FileStream("GroupDocs.Search.lic", FileMode.Open, FileAccess.Read))
{
    License lic = new License();
    lic.SetLicense(fileStream);
}
```


:::info
Llamar a `License.SetLicense` varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, llame a `License.SetLicense` en su código de inicio, antes de utilizar las clases de GroupDocs.Search. Al desarrollar una aplicación ASP.NET, puede llamar a `License.SetLicense` desde el archivo `Global.asax.cs` (`Global.asax.vb`) dentro del método protegido `Application_Start`, el cual se ejecuta una única vez al iniciar la aplicación. No llame a `License.SetLicense` desde los métodos `Page_Load`, ya que esto implica que la licencia se cargará cada vez que se cargue una página web.
:::


### Aplicación de la licencia basada en uso {#applying-metered-license}


:::info
También puede configurar <a href="https://reference.groupdocs.com/net/search/groupdocs.search/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como licencia alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las características de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en uso</a>.
:::


A continuación se presentan los pasos sencillos para utilizar la clase `Metered`.

1.  Crear una instancia de la clase `Metered`.
2.  Pasar las claves pública y privada al método S`etMeteredKey`.
3.  Realizar el procesamiento (ejecutar la tarea).
4.  Llamar al método G`etConsumptionQuantity` de la clase `Metered`.
5.  Este método devolverá la cantidad/cantidad de solicitudes de API que ha consumido hasta el momento.
6.  Llamar al método G`etConsumptionCredit` de la clase `Metered` (desde la versión 19.5).
7.  Este método devolverá el crédito que ha consumido hasta el momento.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase `Metered`.

**C#**

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-search/GroupDocs.Search-for-.NET
string PublicKey = ""; // Your public license key
string PrivateKey = ""; // Your private license key
Metered metered = new Metered();
metered.SetMeteredKey(PublicKey, PrivateKey);

// Do indexing and searching in licensed mode 
Index index = new Index(indexPath);

// Adding documents to index
index.AddToIndex(documentsPath);

// Searching
SearchResults results = index.Search("arbitrary");

// Get consumption quantity
decimal consumptionQuantitiy = GroupDocs.Search.Metered.GetConsumptionQuantity();

// Get consumption credit
decimal consumptionCredit = GroupDocs.Search.Metered.GetConsumptionCredit();
```

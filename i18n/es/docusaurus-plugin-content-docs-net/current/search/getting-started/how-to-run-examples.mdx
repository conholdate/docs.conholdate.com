## Compilar proyecto desde cero {#build-project-from-scratch}

*   Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
*   Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
*   Instale **GroupDocs.Search para .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/search/getting-started/installation/).
*   Escriba su primera aplicación con **GroupDocs.Search para .NET**, como se muestra a continuación:
    

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\"; // NOTE: Put here actual path for your documents
string query = "Einstein";

Index index = new Index(indexFolder); // Creating index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder

SearchResult result = index.Search(query); // Searching in index
foreach (FoundDocument document in result)
{
    Console.WriteLine(document.DocumentInfo.FilePath);
}
```

*   Compile y ejecute su proyecto.
*   La lista de documentos encontrados aparecerá en la consola.

## Descargue ejemplos desde GitHub {#download-examples-from-github}

El paquete completo de ejemplos de **GroupDocs.Search** está alojado en <a href="https://github.com/groupdocs-search/GroupDocs.Search-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://codeload.github.com/groupdocs-search/GroupDocs.Search-for-.NET/zip/master" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando su cliente de GitHub favorito.

En caso de descargar el archivo ZIP, extraiga las carpetas en su disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![](/net/search/images/how-to-run-examples.jpg)

En los archivos y carpetas extraídos, puede encontrar el siguiente archivo de solución:

*   Archivo de solución de C#

El proyecto se crea en **Microsoft Visual Studio 2012**. La carpeta **Data** contiene todos los archivos de documento de ejemplo utilizados en los ejemplos.

Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias que faltan para **GroupDocs.Search**, consulte [Instalación](/net/search/getting-started/installation/). Todas las funciones se llaman desde **Program.cs**. Descomente la función que desea ejecutar y comente el resto.

![](/net/search/images/how-to-run-examples_1.jpg)

## Contribuir {#contribute}

Si deseas agregar o mejorar un ejemplo, te animamos a contribuir al proyecto. Todos los ejemplos de este repositorio son de código abierto y pueden utilizarse libremente en tus propias aplicaciones.

Para contribuir, puedes hacer un *fork* del repositorio, editar el código y crear una solicitud de extracción (*pull request*). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

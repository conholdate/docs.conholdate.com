Algunos idiomas, en particular los idiomas jeroglíficos, suelen requerir herramientas especiales para dividir el texto en palabras.
Esto es necesario debido a la ausencia de espacios entre palabras, las frases polisémicas, las expresiones fijas y las reglas léxicas complejas.

Actualmente, la biblioteca GroupDocs.Search no contiene algoritmos especiales para dividir texto en chino, japonés y coreano en palabras. Sin embargo, proporciona la capacidad de utilizar algoritmos personalizados externos para este propósito. Para integrar una biblioteca externa de segmentación de texto, debe implementar la interfaz <a href="https://reference.groupdocs.com/search/net/groupdocs.search.common/iwordsplitter/" target="_blank" rel="nofollow noopener noreferrer">IWordSplitter</a> y pasar un objeto que implemente dicha interfaz a la propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.events/fileindexingeventargs/wordsplitter/" target="_blank" rel="nofollow noopener noreferrer">WordSplitter</a> de los argumentos del evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.events/eventhub/fileindexing/" target="_blank" rel="nofollow noopener noreferrer">FileIndexing</a>.

El siguiente ejemplo de código muestra cómo utilizar la biblioteca externa <a href="https://www.nuget.org/packages/jieba.NET/" target="_blank" rel="nofollow noopener noreferrer">Jieba.NET</a> para la segmentación de texto en chino.

**C#**

```csharp
// Implementing custom word splitter
public class JiebaWordSplitter : IWordSplitter
{
    private readonly JiebaSegmenter segmenter;

    public JiebaWordSplitter()
    {
        segmenter = new JiebaSegmenter();
    }

    public IEnumerable<string> Split(string text)
    {
        IEnumerable<string> segments = segmenter.Cut(text, cutAll: false);
        return segments;
    }
}

...

string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an index in the specified folder
Index index = new Index(indexFolder);

// Using Jieba segmenter to break text into words
JiebaWordSplitter jiebaWordSplitter = new JiebaWordSplitter();
index.Events.FileIndexing += (s, e) =>
{
    if (e.DocumentFullPath.EndsWith("Chinese.txt"))
    {
        // We know that the text in this document is in Chinese
        e.WordSplitter = jiebaWordSplitter;
    }
};

// Indexing documents
index.Add(documentsFolder);

// Searching in the index
string query = "考虑"; // Consider
SearchResult result = index.Search(query);
```

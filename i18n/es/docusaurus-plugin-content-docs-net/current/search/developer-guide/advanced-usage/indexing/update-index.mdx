## Actualización de documentos indexados {#update-indexed-documents}

La operación de actualización se utiliza para reindexar documentos que han sido modificados, eliminados o añadidos a carpetas indexadas. Asimismo, modificar un filtro especificado mediante la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/documentfilter" target="_blank" rel="nofollow noopener noreferrer">DocumentFilter</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a> también puede provocar un cambio en la lista de documentos indexados.

Durante la actualización, se pueden especificar las mismas opciones en la instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/updateoptions" target="_blank" rel="nofollow noopener noreferrer">UpdateOptions</a> que se establecen en la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions" target="_blank" rel="nofollow noopener noreferrer">IndexingOptions</a> para definir las opciones de indexación. Consulte la página [Opciones de indexación](/net/search/developer-guide/advanced-usage/indexing/indexing-options/).

El siguiente ejemplo muestra cómo actualizar un índice utilizando 2 subprocesos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Change, delete, add documents in the document folder
// ...
 
UpdateOptions options = new UpdateOptions();
options.Threads = 2; // Setting the number of indexing threads
index.Update(options); // Updating the index
```

## Actualizar la versión del índice {#update-index-version}

A veces, cuando se publica una nueva versión de la biblioteca GroupDocs.Search, el formato para almacenar el índice en disco cambia. En este caso, también es necesario actualizar el índice. Sin embargo, la actualización de la versión del índice es distinta. Para ello, utilice la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexupdater" target="_blank" rel="nofollow noopener noreferrer">IndexUpdater</a>. Sin actualizar la versión del índice, la carga del índice de la versión anterior fallará.

Cuando se actualiza la versión del índice, los documentos se vuelven a indexar y guardan en una carpeta distinta de la original, en el nuevo formato. No obstante, el índice de la versión anterior no se modifica. La carpeta que contiene la versión antigua del índice puede eliminarse tras la actualización. El siguiente ejemplo muestra cómo actualizar un índice de una versión anterior.

**C#**

```csharp
string sourceIndexFolder = @"c:\MyOldIndex\";
string targetIndexFolder = @"c:\MyNewIndex\";
 
IndexUpdater updater = new IndexUpdater();
 
if (updater.CanUpdateVersion(sourceIndexFolder))
{
    // The index of old version does not change
    VersionUpdateResult result = updater.UpdateVersion(sourceIndexFolder, targetIndexFolder);
}
```

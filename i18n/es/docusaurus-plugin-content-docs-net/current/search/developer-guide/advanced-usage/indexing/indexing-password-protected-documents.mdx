Esta página describe cómo realizar la indexación de documentos protegidos con contraseña.

## Indexación mediante el diccionario de contraseñas {#indexing-using-the-password-dictionary}

Para realizar la indexación de documentos protegidos con contraseña mediante un diccionario de contraseñas, debe agregar las contraseñas de todos los documentos protegidos al diccionario antes de la indexación. Para agregar una contraseña de documento al diccionario, debe especificar la ruta completa al documento como clave y la contraseña real del documento. Para obtener más información sobre la gestión del diccionario de contraseñas, consulte la página [Contraseñas de documentos](/net/search/developer-guide/advanced-usage/managing-dictionaries/document-passwords/) en la sección [Gestión de diccionarios](/net/search/developer-guide/advanced-usage/managing-dictionaries/).

El diccionario de contraseñas se almacena en disco en forma cifrada. Sin embargo, se utiliza un cifrado muy simple, por lo que si desea proteger las propias contraseñas, es mejor utilizar el evento <a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/passwordrequired" target="_blank" rel="nofollow noopener noreferrer">PasswordRequired</a> para establecer las contraseñas.

El siguiente ejemplo muestra cómo realizar la indexación de documentos protegidos con contraseña mediante un diccionario de contraseñas.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Adding document passwords to the dictionary
string key = Path.GetFullPath(@"C:\MyDocuments\ProtectedDocument.pdf");
index.Dictionaries.DocumentPasswords.Add(key, "123456");
// ...
 
// Indexing documents from the specified folder
// Passwords will be automatically retrieved from the dictionary when necessary
index.Add(documentsFolder);
```

## Indexación mediante el evento PasswordRequired {#indexing-using-the-passwordrequired-event}

La contraseña del documento protegido también puede proporcionarse cuando se produce el evento **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/passwordrequired" target="_blank" rel="nofollow noopener noreferrer">PasswordRequired</a>**. Este método es más seguro, aunque requiere que se coincidan los documentos indexados y sus contraseñas en el controlador de eventos.

Ambos métodos descritos para proporcionar contraseñas de documentos pueden utilizarse conjuntamente. El índice primero comprueba la contraseña del documento en el diccionario de contraseñas y, si esta no existe, desencadena el evento **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/passwordrequired" target="_blank" rel="nofollow noopener noreferrer">PasswordRequired</a>**. Si no se proporciona la contraseña o se proporciona una contraseña incorrecta, el índice desencadenará el evento **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/erroroccurred" target="_blank" rel="nofollow noopener noreferrer">ErrorOccurred</a>** con el mensaje de error correspondiente y el documento no se indexará. Puede obtener más información sobre los eventos del índice en la página [Eventos del índice de búsqueda](/net/search/developer-guide/advanced-usage/creating-an-index/search-index-events/).

El siguiente ejemplo muestra cómo proporcionar la contraseña de un documento mediante el evento **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/passwordrequired" target="_blank" rel="nofollow noopener noreferrer">PasswordRequired</a>**.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Subscribing to the event
index.Events.PasswordRequired += (sender, args) =>
{
    if (args.DocumentFullPath.EndsWith("ProtectedDocument.pdf", StringComparison.InvariantCultureIgnoreCase))
    {
        args.Password = "123456"; // Providing password for the file 'ProtectedDocument.pdf'
    }
};
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
```

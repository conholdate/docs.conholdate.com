Esta página contiene descripciones de todos los tipos de caracteres. Los tipos de caracteres difieren en cómo se indexan los caracteres de dichos tipos. Para obtener más información sobre la gestión del alfabeto, consulte la página [Alphabet](/net/search/developer-guide/advanced-usage/managing-dictionaries/alphabet/) en la sección [Gestión de diccionarios](/net/search/developer-guide/advanced-usage/managing-dictionaries/).

## Caracteres normales {#regular-characters}

Los caracteres normales son separadores y letras. Durante la indexación, los separadores se utilizan para separar las palabras entre sí, y las palabras se forman a partir de secuencias continuas de letras.

El tipo de cada carácter concreto puede especificarse en el alfabeto. De forma predeterminada, se definen como letras los siguientes caracteres (se indican los números Unicode):

*   Dígitos: 0030-0039;
*   Letras mayúsculas latinas: 0041-005A;
*   Guion bajo: 005F;
*   Letras minúsculas latinas: 0061-007A;
*   Letras latinas: 00C0-00D6, 00D8-00F6, 00F8-00FF, 0100-017F, 0180-024F, 0250-02AF;
*   Letras griegas y coptas: 0370-0373, 0376-0377, 037F, 0386, 0388-038A, 038C, 038E-03A1, 03A3-03FC;
*   Letras cirílicas: 0400-0481, 048A-04FF, 0500-052F;
*   Letras armenias: 0531-0556, 0561-0587.

El resto de caracteres se definen como separadores en el alfabeto.

El siguiente ejemplo muestra cómo especificar únicamente números, el carácter de guion bajo y caracteres en inglés como letras en el alfabeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Configuring the alphabet
// Setting the separator type for all characters in the alphabet
index.Dictionaries.Alphabet.Clear();
// Creating a list of letter characters
List<char> list = new List<char>();
for (char i = (char)0x0030; i <= 0x0039; i++)
{
    list.Add(i); // Digits
}
for (char i = (char)0x0041; i <= 0x005A; i++)
{
    list.Add(i); // Latin capital letters
}
list.Add((char)0x005F); // Low line
for (char i = (char)0x0061; i <= 0x007A; i++)
{
    list.Add(i); // Latin small letters
}
// Setting the type of characters in the alphabet
char[] characters = list.ToArray();
index.Dictionaries.Alphabet.SetRange(characters, CharacterType.Letter);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Searching in the index
SearchResult result = index.Search("Einstein");
```

## Caracteres combinados {#blended-characters}

Los caracteres combinados son caracteres especiales que se indexan tanto como separadores como letras. Este tipo de carácter puede ser útil, por ejemplo, para indexar guiones. En este caso, las partes de una palabra compuesta que contiene un guion se indexan tanto como una única palabra con guion como individualmente sin guion. A continuación se presenta un ejemplo del uso de caracteres combinados.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Setting hyphen character type to blended
index.Dictionaries.Alphabet.SetRange(new char[] { '-' }, CharacterType.Blended);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Searching in the index
SearchResult result1 = index.Search("Elliot-Murray-Kynynmound");
SearchResult result2 = index.Search("Elliot");
SearchResult result3 = index.Search("Murray");
SearchResult result4 = index.Search("Kynynmound");
```

## Indexar cada carácter como una palabra completa {#indexing-each-character-as-a-whole-word}

Otro tipo especial de carácter es aquel que se indexa como una palabra independiente. Este tipo de carácter está diseñado para funcionar con lenguajes jeroglíficos y permite indexar cada carácter del texto como una palabra separada, independientemente de la presencia de separadores.

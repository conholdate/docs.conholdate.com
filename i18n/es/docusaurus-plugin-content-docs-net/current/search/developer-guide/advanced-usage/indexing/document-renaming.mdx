A veces surge una situación en la que un documento indexado se renombra, pero su contenido no ha cambiado. En este caso, para ahorrar recursos computacionales, puede notificar al índice sobre el renombramiento del documento, de modo que este no se vuelva a indexar durante la operación de actualización.

Para notificar a un índice sobre el renombramiento de un documento, se utiliza el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/index/methods/notify" target="_blank" rel="nofollow noopener noreferrer">Notify</a>, pasando como parámetro el objeto de notificación correspondiente.

Debe tener en cuenta que si se notifica al índice sobre el renombramiento de un documento, este no se volverá a indexar la próxima vez que invoque el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/index/methods/update" target="_blank" rel="nofollow noopener noreferrer">Update</a>, incluso si su contenido ha cambiado. El siguiente ejemplo demuestra cómo notificar al índice sobre el renombramiento de un documento.

**C#**

```csharp
string indexFolder = @"c:\MyIndex";
string documentFolder = @"c:\MyDocuments";
   
// Creating an index
Index index = new Index(indexFolder);
   
// Indexing documents in a document folder
index.Add(documentFolder);
   
// Renaming a document
string oldDocumentPath = @"c:\MyDocuments\OldDocumentName.txt";
string newDocumentPath = @"c:\MyDocuments\NewDocumentName.txt";
File.Move(oldDocumentPath, newDocumentPath);
   
// Notifying the index about renaming
Notification notification = Notification.CreateRenameNotification(oldDocumentPath, newDocumentPath);
bool result = index.Notify(notification);
   
// Updating the index
// The renamed document will not be reindexed
index.Update();
```

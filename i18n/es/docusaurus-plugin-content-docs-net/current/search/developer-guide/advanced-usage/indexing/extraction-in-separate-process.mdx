La extracción de datos de documentos constituye la operación más intensiva en recursos del proceso de indexación. En caso de memoria insuficiente, se produce una excepción que interrumpe por completo el proceso de indexación de un grupo de documentos. Para evitar esta situación, los datos pueden extraerse en un proceso independiente. En este caso, una memoria insuficiente durante la extracción de datos de un solo documento provocará el fallo únicamente en la indexación de dicho documento, mientras que la indexación de los documentos restantes del grupo continuará sin interrupciones.

Además, la extracción de datos en un proceso independiente resuelve otro problema: la interrupción inmediata del proceso de indexación de un documento cuando se excede el límite de tiempo asignado para su indexación.

Para extraer datos de documentos en un proceso independiente, es necesario configurar las opciones de indexación correspondientes y crear un proyecto de aplicación de consola sencilla que la biblioteca GroupDocs.Search ejecutará como servicio de extracción de datos en un proceso separado. El proyecto de aplicación de consola para la extracción de datos debe tener la biblioteca GroupDocs.Search como dependencia, al igual que el proyecto principal que utiliza la biblioteca. El código del proyecto de aplicación de consola se presenta en el siguiente listado.

**C#**

```csharp
public class Program
{
    static void Main(string[] args)
    {
        using (var host = new GroupDocs.Search.ExtractionHost(args))
        {
            host.Run();
        }
    }
}
```

Un ejemplo de configuración de opciones de indexación para la extracción de datos en un proceso independiente se muestra en el listado siguiente.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";

// Getting the path to the console application location
string assemblyPath = typeof(GroupDocs.Search.Extraction.Program).Assembly.Location;

// Creating an index in the specified folder
Index index = new Index(indexFolder);

// Setting indexing options for data extraction in a separate process
IndexingOptions options = new IndexingOptions();
options.SeparateProcessOptions.ExtractInSeparateProcess = true;
options.SeparateProcessOptions.AssemblyPath = assemblyPath;
options.SeparateProcessOptions.Timeout = new TimeSpan(0, 1, 0);

// Indexing documents from the specified folder
index.Add(documentFolder, options);
```

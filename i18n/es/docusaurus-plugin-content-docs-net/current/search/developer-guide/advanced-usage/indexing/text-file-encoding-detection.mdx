Para detectar automáticamente la codificación de un archivo de texto, se puede utilizar la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/autodetectencoding" target="_blank" rel="nofollow noopener noreferrer">AutoDetectEncoding</a> definida en la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/indexingoptions/" target="_blank" rel="nofollow noopener noreferrer">IndexingOptions</a>. Al establecer esta propiedad en `true`, se permite detectar las siguientes codificaciones:

*   UTF-32 LE,
*   UTF-32 BE,
*   UTF-16 LE,
*   UTF-16 BE,
*   UTF-8,
*   UTF-7,

De forma predeterminada, la detección automática de codificación de archivos de texto está deshabilitada. Sin embargo, en cualquier caso, la codificación de un archivo de texto puede establecerse durante la indexación cuando se genera el evento <a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/fileindexing" target="_blank" rel="nofollow noopener noreferrer">FileIndexing</a>. Si la codificación de un archivo de texto no se detecta ni se especifica en los argumentos del evento, se utiliza la codificación predeterminada, UTF-8. Las codificaciones disponibles se presentan en la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/encodings" target="_blank" rel="nofollow noopener noreferrer">Encodings</a>. Cuando se detecta y utiliza la codificación de un archivo de texto para la indexación, esta se guarda en el índice para su uso en métodos de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a>, como <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/highlight/index" target="_blank" rel="nofollow noopener noreferrer">Highlight</a> y <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getdocumenttext/index" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a>.

El ejemplo siguiente muestra cómo establecer la codificación de un archivo de texto durante la indexación.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Subscribing to the event
index.Events.FileIndexing += (sender, args) =>
{
    if (args.DocumentFullPath.EndsWith(".txt", StringComparison.InvariantCultureIgnoreCase))
    {
        args.Encoding = Encodings.Windows_1253; // Setting encoding for each text file
    }
};
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
```

Se pueden utilizar herramientas externas, como Utf.Unknown, para determinar la codificación de un archivo de texto durante la indexación.
Se puede detectar cualquier codificación, incluida ANSI.

```
PM> NuGet\Install-Package UTF.Unknown
```

A continuación se muestra un ejemplo de cómo utilizar una biblioteca externa para determinar la codificación de un archivo de texto.

**C#**

```csharp
index.Events.FileIndexing += (sender, args) =>
{
    byte[] data = File.ReadAllBytes(args.DocumentFullPath);
    UtfUnknown.DetectionResult result = UtfUnknown.CharsetDetector.DetectFromBytes(data);
    if (result.Detected != null)
    {
        Console.WriteLine("Encoding detected: " + result.Detected.EncodingName);
        args.Encoding = result.Detected.EncodingName;
    }
};
```

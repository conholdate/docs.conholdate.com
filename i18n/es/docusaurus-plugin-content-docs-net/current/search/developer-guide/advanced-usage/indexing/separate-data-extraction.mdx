La función descrita en este artículo permite separar las operaciones de extracción de datos de un documento y de adición de los datos extraídos al índice. Los datos extraídos pueden serializarse y deserializarse fácilmente según sea necesario.

Esta función puede resultar útil porque la operación de extracción de texto y otros datos de documentos puede ser muy larga para algunos formatos. Al mismo tiempo, la adición de datos al índice es una operación relativamente ligera. Por lo tanto, separar estas operaciones puede suponer un aumento significativo del tiempo total cuando el índice no está realizando ninguna operación. Además, la adición posterior de nuevos extractores de datos incrementará notablemente el rendimiento de la indexación. En este caso, los extractores de datos pueden incluso operar en servidores independientes, liberando por completo al servidor de indexación de las tareas de extracción.

La clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search/extractor" target="_blank" rel="nofollow noopener noreferrer">Extractor</a> se utiliza para extraer datos de documentos. Tras finalizar la operación, el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/extractor/methods/extract" target="_blank" rel="nofollow noopener noreferrer">Extract</a> devuelve una instancia de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.common/extracteddata" target="_blank" rel="nofollow noopener noreferrer">ExtractedData</a>, que se utiliza directamente para agregar los datos al índice.

El siguiente ejemplo muestra cómo realizar la extracción y la indexación de datos de forma separada.

**C#**

```csharp
string indexFolder = @"c:\MyIndex";
string documentPath = @"c:\MyDocuments\MyDocument.pdf";

// Extracting data from a document
Extractor extractor = new Extractor();
Document document = Document.CreateFromFile(documentPath);
ExtractionOptions extractionOptions = new ExtractionOptions();
extractionOptions.UseRawTextExtraction = false;
ExtractedData extractedData = extractor.Extract(document, extractionOptions);

// Serializing the data
byte[] array = extractedData.Serialize();

// Deserializing the data
ExtractedData deserializedData = ExtractedData.Deserialize(array);

// Creating an index
Index index = new Index(indexFolder);

if (deserializedData.IsExtractionSuccessful)
{
    // Indexing the data
    ExtractedData[] data = new ExtractedData[]
    {
        deserializedData
    };
    index.Add(data, new IndexingOptions());

    // Searching in the index
    SearchResult result = index.Search("Einstein");
}
```

Tenga en cuenta que, cuando los documentos indexados cambian y es necesario actualizarlos en el índice, se debe ejecutar el mismo código. Es decir, los datos deben extraerse por separado a partir de los documentos actualizados y, a continuación, los datos extraídos deben agregarse al índice.

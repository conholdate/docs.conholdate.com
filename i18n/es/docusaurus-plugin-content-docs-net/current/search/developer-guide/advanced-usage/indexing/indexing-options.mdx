Esta página contiene una descripción de todas las propiedades de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions" target="_blank" rel="nofollow noopener noreferrer">IndexingOptions</a>.

## Propiedad Cancellation {#cancellation-property}

La propiedad **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions/properties/cancellation" target="_blank" rel="nofollow noopener noreferrer">Cancellation</a>** se utiliza para especificar un objeto de tipo <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/cancellation" target="_blank" rel="nofollow noopener noreferrer">Cancellation</a>, utilizado para cancelar una operación de índice. El valor predeterminado de la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions/properties/cancellation" target="_blank" rel="nofollow noopener noreferrer">Cancellation</a> es null. Una operación puede cancelarse, si es necesario, con un retraso en el tiempo. Tenga en cuenta que, tras la cancelación, un índice puede no detener inmediatamente la operación, sino que lo hará con cierto retraso.

El siguiente ejemplo demuestra la cancelación de una operación de indexación.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Creating an instance of indexing options
IndexingOptions options = new IndexingOptions();
options.Cancellation = new Cancellation(); // Setting a cancellation object
options.Cancellation.CancelAfter(300000); // Setting a time period of 300 seconds after which the indexing operation will be cancelled
 
// Indexing documents from the specified folder
index.Add(documentFolder, options);
```

## Propiedad IsAsync {#isasync-property}

La propiedad **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions/properties/isasync" target="_blank" rel="nofollow noopener noreferrer">IsAsync</a>** se utiliza para especificar si la operación de indexación debe realizarse de forma asíncrona o síncrona. El valor predeterminado es `false`, lo que indica una ejecución síncrona. El ejemplo siguiente demuestra cómo realizar una indexación de forma asíncrona.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating index in the specified folder
Index index = new Index(indexFolder);
 
// Subscribing to the event
index.Events.StatusChanged += (sender, args) =>
{
    if (args.Status != IndexStatus.InProgress)
    {
        // A notification of the operation completion should be here
    }
};
 
// Creating an instance of indexing options
IndexingOptions options = new IndexingOptions();
options.IsAsync = true; // Specifying the asynchronous performing of the operation
 
// Indexing documents from the specified folder
// The method will return control before the indexing operation is completed
index.Add(documentFolder, options);
```

## Propiedad AutoDetectEncoding {#autodetectencoding-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/autodetectencoding/" target="_blank" rel="nofollow noopener noreferrer">AutoDetectEncoding</a> es una bandera que permite detectar automáticamente las siguientes codificaciones de archivos de texto durante la indexación: UTF-32 LE, UTF-32 BE, UTF-16 LE, UTF-16 BE, UTF-8 y UTF-7. De forma predeterminada, la detección automática de la codificación de archivos de texto está deshabilitada. Sin embargo, en cualquier caso, la codificación de un archivo de texto puede establecerse durante la indexación cuando se genera el evento <a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/fileindexing" target="_blank" rel="nofollow noopener noreferrer">FileIndexing</a>. La información detallada sobre la detección y el establecimiento de la codificación de archivos de texto se presenta en la página [Detección de la codificación de archivos de texto](/net/search/developer-guide/advanced-usage/indexing/text-file-encoding-detection/).

## Propiedad Encoding {#encoding-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/encoding/" target="_blank" rel="nofollow noopener noreferrer">Encoding</a> especifica la codificación utilizada para extraer texto de archivos de texto. El valor predeterminado es null, lo que significa que se utiliza la codificación predeterminada UTF-8. Si <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/autodetectencoding/" target="_blank" rel="nofollow noopener noreferrer">AutoDetectEncoding</a> es true, el valor de esta propiedad se utiliza como codificación predeterminada.

## Propiedad Threads {#threads-property}

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/indexingoptions/properties/threads" target="_blank" rel="nofollow noopener noreferrer">Threads</a> se utiliza para establecer el número de subprocesos utilizados para la indexación. El valor predeterminado es 1. El número de subprocesos de indexación no puede ser inferior a 1 ni superior a 4.

Un número mayor de subprocesos acelera el proceso de indexación. Sin embargo, tenga cuidado al especificar un número de subprocesos de indexación superior a 1, ya que la cantidad de memoria utilizada durante la indexación es directamente proporcional al número de subprocesos involucrados. Si el sistema dispone de 4 GB de RAM o menos, el uso de más de 1 subproceso puede provocar un error de memoria insuficiente. Además, el disco duro donde se encuentran los archivos que se van a indexar puede constituir el cuello de botella, y el rendimiento no aumentará.

El siguiente ejemplo muestra cómo realizar la indexación en 2 subprocesos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Creating an instance of indexing options
IndexingOptions options = new IndexingOptions();
options.Threads = 2; // Setting the number of indexing threads
 
// Indexing documents from the specified folder
index.Add(documentFolder, options); 
```

## Propiedad UseRawTextExtraction {#userawtextextraction-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/userawtextextraction/" target="_blank" rel="nofollow noopener noreferrer">UseRawTextExtraction</a> permite especificar un valor que indica si se debe utilizar el modo de extracción de texto sin procesar siempre que sea posible durante la indexación. El modo de extracción de texto sin procesar puede acelerar significativamente el proceso de indexación, aunque a costa de perder la calidad del formato del texto extraído. El valor predeterminado de esta propiedad es `true`.

## Propiedad UseBackupPrivilege {#usebackupprivilege-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/usebackupprivilege/" target="_blank" rel="nofollow noopener noreferrer">UseBackupPrivilege</a> permite especificar si el proceso debe utilizar el privilegio de copia de seguridad para acceder a archivos y directorios. Cuando se establece en `true`, esta propiedad permite que el proceso omita las comprobaciones de seguridad de archivos y directorios, lo que permite el acceso a recursos protegidos normalmente restringidos por ACL, siempre que el proceso disponga de los privilegios adecuados.

Esta característica solo es compatible con sistemas operativos Windows. En plataformas no Windows,
habilitar esta propiedad no tiene ningún efecto.

Tenga en cuenta que esto requiere que el proceso se ejecute con privilegios de administrador.

## Propiedad MetadataIndexingOptions {#metadataindexingoptions-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/metadataindexingoptions/" target="_blank" rel="nofollow noopener noreferrer">MetadataIndexingOptions</a> está representada por un objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataIndexingOptions</a>. Esta clase contiene propiedades para configurar las opciones de indexación de metadatos:

* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/indexingemptyvalues" target="_blank" rel="nofollow noopener noreferrer">IndexingEmptyValues</a> establece un valor que indica si se deben indexar o no los valores de campo vacíos. El valor predeterminado es `true`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/indexingemptynames" target="_blank" rel="nofollow noopener noreferrer">IndexingEmptyNames</a> establece un valor que indica si se deben indexar o no los nombres de campo vacíos. El valor predeterminado es `true`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/defaultfieldname" target="_blank" rel="nofollow noopener noreferrer">DefaultFieldName</a> establece el nombre de campo predeterminado utilizado para indexar nombres de campo vacíos. El valor predeterminado es `"unknown"`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/separatorincompoundname" target="_blank" rel="nofollow noopener noreferrer">SeparatorInCompoundName</a> establece el separador en el nombre compuesto de un campo. El valor predeterminado es `"."` (carácter de punto).
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/maxbytestoindexfield" target="_blank" rel="nofollow noopener noreferrer">MaxBytesToIndexField</a> establece el número máximo de valores indexados a partir de una matriz de valores `byte`. El valor predeterminado es `int.MaxValue`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/maxintstoindexfield" target="_blank" rel="nofollow noopener noreferrer">MaxIntsToIndexField</a> establece el número máximo de valores indexados a partir de una matriz de valores `int`. El valor predeterminado es `int.MaxValue`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/maxlongstoindexfield" target="_blank" rel="nofollow noopener noreferrer">MaxLongsToIndexField</a> establece el número máximo de valores indexados a partir de una matriz de valores `long`. El valor predeterminado es `int.MaxValue`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/maxdoublestoindexfield" target="_blank" rel="nofollow noopener noreferrer">MaxDoublesToIndexField</a> establece el número máximo de valores indexados a partir de una matriz de valores `double`. El valor predeterminado es `int.MaxValue`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/metadataindexingoptions/properties/separatorbetweenvalues" target="_blank" rel="nofollow noopener noreferrer">SeparatorBetweenValues</a> establece el separador entre valores en un campo de tipo matriz. El valor predeterminado es `" "` (carácter de espacio).

El siguiente ejemplo muestra cómo configurar las opciones de indexación de metadatos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex";
string documentFolder = @"c:\MyDocuments";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Setting the metadata indexing options
var options = new IndexingOptions();
options.MetadataIndexingOptions.DefaultFieldName = "default";
options.MetadataIndexingOptions.SeparatorInCompoundName = @"\";
options.MetadataIndexingOptions.MaxBytesToIndexField = 10;
options.MetadataIndexingOptions.MaxIntsToIndexField = 10;
options.MetadataIndexingOptions.MaxLongsToIndexField = 10;
options.MetadataIndexingOptions.MaxDoublesToIndexField = 10;
 
// Starting indexing operation
index.Add(documentFolder, options);
```

## Propiedad OcrIndexingOptions {#ocrindexingoptions-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/ocrindexingoptions/" target="_blank" rel="nofollow noopener noreferrer">OcrIndexingOptions</a> está representada por un objeto de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/ocrindexingoptions" target="_blank" rel="nofollow noopener noreferrer">OcrIndexingOptions</a>. Esta clase contiene propiedades para configurar las opciones de procesamiento OCR:

* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/ocrindexingoptions/properties/enabledforseparateimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForSeparateImages</a> establece un valor que indica si se debe reconocer texto en archivos de imagen independientes. El valor predeterminado es `false`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/ocrindexingoptions/properties/enabledforembeddedimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForEmbeddedImages</a> establece un valor que indica si se debe reconocer texto en imágenes incrustadas. El valor predeterminado es `false`.
* La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/ocrindexingoptions/properties/enabledforcontaineritemimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForContainerItemImages</a> establece un valor que indica si se debe reconocer texto en imágenes que son elementos de un contenedor (archivo ZIP, almacenamiento OST/PST). El valor predeterminado es `false`.
* La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/ocrindexingoptions/properties/ocrconnector" target="_blank" rel="nofollow noopener noreferrer">OcrConnector</a> establece un conector OCR que se utiliza para el procesamiento OCR. El valor predeterminado es `null`, lo que significa que no se utiliza OCR.

## Propiedad ImageIndexingOptions {#imageindexingoptions-property}

La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/baseoptions/imageindexingoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageIndexingOptions</a> está representada por un objeto de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/imageindexingoptions" target="_blank" rel="nofollow noopener noreferrer">ImageIndexingOptions</a>. Esta clase proporciona opciones de indexación de imágenes para la búsqueda inversa de imágenes:

* La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/imageindexingoptions/properties/enabledforseparateimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForSeparateImages</a> establece un valor que indica si se deben indexar archivos de imagen independientes. El valor predeterminado es `false`.
* La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/imageindexingoptions/properties/enabledforembeddedimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForEmbeddedImages</a> establece un valor que indica si se deben indexar imágenes incrustadas (por ejemplo, imágenes en un documento DOCX). El valor predeterminado es `false`.
* La propiedad <a href="https://reference.groupdocs.com/search/net/groupdocs.search.options/imageindexingoptions/properties/enabledforcontaineritemimages" target="_blank" rel="nofollow noopener noreferrer">EnabledForContainerItemImages</a> establece un valor que indica si se deben indexar imágenes que son elementos de un contenedor (archivo ZIP, almacenamiento OST/PST). El valor predeterminado es `false`.

GroupDocs.Search permite crear un índice de texto completo y/o de metadatos en documentos. Para indexar únicamente los metadatos sin el contenido principal de los documentos, basta con establecer `IndexType.MetadataIndex` al crear el índice. El tamaño de un índice de este tipo será muy reducido.

El siguiente ejemplo demuestra la creación de un índice de metadatos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an instance of index settings
IndexSettings settings = new IndexSettings();
settings.IndexType = IndexType.MetadataIndex; // Setting index type
 
// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Searching in the index
SearchResult result = index.Search("Einstein");
```

El texto extraído de documentos indexados puede almacenarse en un índice para proporcionar dicho texto al usuario más rápidamente al invocar el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getdocumenttext/index" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a>, así como para acelerar la generación de texto con resaltado de los resultados de búsqueda.

Para especificar los parámetros de almacenamiento, utilice la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/textstoragesettings" target="_blank" rel="nofollow noopener noreferrer">TextStorageSettings</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a>. El valor predeterminado es `null`, lo que significa que el texto de los documentos no se almacena en el índice.

Al guardar el texto en el índice, se utiliza la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/textstoragesettings/properties/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> para especificar el nivel de compresión del texto guardado. La compresión puede ser normal, alta o bien el texto puede guardarse sin compresión. La elección del nivel de compresión afecta tanto al tamaño final del índice como a la velocidad de indexación. Un nivel alto de compresión reduce el tamaño del índice y la velocidad de indexación, mientras que la ausencia de compresión maximiza tanto el tamaño del índice como la velocidad de indexación. El nivel predeterminado de compresión es normal.

El ejemplo siguiente demuestra cómo almacenar texto en un índice utilizando un nivel alto de compresión.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index settings instance
IndexSettings settings = new IndexSettings();
settings.TextStorageSettings = new TextStorageSettings(Compression.High); // Setting high compression ratio for the index text storage
 
// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);
 
// Indexing documents
index.Add(documentsFolder);
 
// Searching
SearchResult result = index.Search("Einstein");
```

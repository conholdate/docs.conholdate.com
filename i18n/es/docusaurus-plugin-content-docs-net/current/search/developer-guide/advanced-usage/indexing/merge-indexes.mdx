La operación de fusión está diseñada para combinar dos o más índices en un único índice, con el fin de acelerar las búsquedas y simplificar la gestión de índices. Durante la fusión, únicamente se modifica el índice sobre el cual se invoca el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/merge/index" target="_blank" rel="nofollow noopener noreferrer">Merge</a>. Como resultado de esta operación, dicho índice contendrá todos los documentos que estaban presentes en todos los índices combinados. Tras la fusión, el segundo índice o repositorio de índices puede eliminarse para liberar espacio en disco.

La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/mergeoptions" target="_blank" rel="nofollow noopener noreferrer">MergeOptions</a> incluye una propiedad para especificar un objeto de cancelación, así como otra propiedad para indicar si la operación se realizará de forma asíncrona. Por defecto, la operación de fusión de índices se ejecuta de manera síncrona.

La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a> ofrece sobrecargas de métodos para fusionar tanto un único índice como un repositorio completo de índices. Antes de realizar la fusión, se realizan comprobaciones para asegurar que los índices sean del mismo tipo. La fusión únicamente se lleva a cabo en aquellos índices cuyo valor de <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/indextype" target="_blank" rel="nofollow noopener noreferrer">IndexType</a> coincida con el del índice sobre el cual se invoca el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/merge/index" target="_blank" rel="nofollow noopener noreferrer">Merge</a>.

El siguiente ejemplo muestra cómo fusionar dos índices.

**C#**

```csharp
string indexFolder1 = @"c:\MyIndex1\";
string indexFolder2 = @"c:\MyIndex2\";
string documentsFolder1 = @"c:\MyDocuments1\";
string documentsFolder2 = @"c:\MyDocuments2\";
 
Index index1 = new Index(indexFolder1); // Creating index1
index1.Add(documentsFolder1); // Indexing documents
 
Index index2 = new Index(indexFolder2); // Creating index2
index2.Add(documentsFolder2); // Indexing documents
 
MergeOptions options = new MergeOptions();
options.Cancellation = new Cancellation(); // Creating cancellation object to be able to cancel the oparation
 
// Merging index2 into index1
// Files of index2 will not be changed
index1.Merge(index2, options);
```

Esta página contiene información sobre la creación y asignación de un registrador (logger) para un índice, así como sobre la implementación de un registrador personalizado.

## Uso del registrador de archivos estándar {#use-of-standard-file-logger}

Para guardar información sobre eventos y errores en un índice en un archivo, debe utilizar el registrador de archivos estándar o su propio registrador personalizado. Es importante recordar que cada vez que abra un índice existente, debe crear y asignar nuevamente una instancia del registrador, ya que el registrador no se guarda. La buena noticia es que se puede utilizar el mismo código tanto para crear un nuevo índice como para abrir uno existente. En este caso, al abrir un índice existente, se utilizará el registrador especificado en la configuración del índice pasada al constructor; el resto de la configuración del índice se cargará desde el disco.

El siguiente ejemplo demuestra el uso del registrador de archivos estándar. Los parámetros del constructor de este registrador son la ruta al archivo de registro y su tamaño máximo en MB.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";
string logPath = @"c:\Log.txt";
 
IndexSettings settings = new IndexSettings();
settings.Logger = new FileLogger(logPath, 4.0); // Specifying the path to the log file and a maximum length of 4 MB
 
Index index = new Index(indexFolder, settings); // Creating or loading an index from the specified folder
 
index.Add(documentsFolder); // Indexing documents from the specified folder
 
SearchResult result = index.Search(query); // Search in index
```

## Implementación de un registrador personalizado {#implementing-custom-logger}

En ocasiones, es necesario implementar su propio registrador, por ejemplo, para mostrar el registro en la consola. A continuación se presenta un ejemplo de implementación de dicho registrador.

**C#**

```csharp
public class ConsoleLogger : ILogger
{
    public ConsoleLogger()
    {
    }
 
    public void Error(string message)
    {
        Console.WriteLine("Error: " + message);
    }
 
    public void Trace(string message)
    {
        Console.WriteLine(message);
    }
}
```

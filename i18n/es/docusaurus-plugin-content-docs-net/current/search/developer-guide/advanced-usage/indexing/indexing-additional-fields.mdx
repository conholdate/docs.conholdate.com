A veces, al indexar, es necesario asociar cada documento con ciertos metadatos adicionales, por ejemplo, un conjunto de etiquetas, un número en el catálogo de la biblioteca, el tema de un documento, etc. Para llevar a cabo esta tarea, se pueden agregar campos adicionales a cada documento indexado, además de los ya presentes en el propio documento.

Los campos adicionales se asocian con el documento mediante los argumentos del evento <a href="https://reference.groupdocs.com/net/search/groupdocs.search.events/eventhub/events/fileindexing" target="_blank" rel="nofollow noopener noreferrer">FileIndexing</a>, que se produce antes de indexar cada documento añadido. Al agregar cada campo, se especifican su nombre y su contenido. El nombre del campo añadido puede coincidir con los nombres de otros campos añadidos o con los campos propios del documento. Durante la búsqueda dentro de los campos con el mismo nombre, se tendrán en cuenta las coincidencias con el texto de todos los campos que compartan dicho nombre.

El ejemplo siguiente demuestra cómo asociar campos adicionales con los documentos durante la indexación.

**C#**

```csharp
// Defining somewhere a dictionary containing subjects of documents
Dictionary<string, string> subjects = new Dictionary<string, string>();
subjects.Add(@"C:\MyDocuments\BhagavadGitaAsItIs.pdf".ToLowerInvariant(), "Spiritual");
// ...
 
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Subscribing to the event
index.Events.FileIndexing += (sender, args) =>
{
    string subject;
    if (subjects.TryGetValue(args.DocumentFullPath.ToLowerInvariant(), out subject)) // Getting a subject for the current document
    {
        args.AdditionalFields = new DocumentField[] // Setting additional fields for the current document
        {
            new DocumentField("Subject", subject)
        };
    }
};
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
```

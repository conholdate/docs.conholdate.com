Las palabras vacías son palabras utilizadas con frecuencia que no aportan significado semántico y pueden eliminarse de un índice para reducir su tamaño.

Puede habilitar o deshabilitar el uso de palabras vacías estableciendo un valor para la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/usestopwords" target="_blank" rel="nofollow noopener noreferrer">UseStopWords</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a>. El valor predeterminado es `true`, lo que significa que las palabras vacías se filtran durante la indexación y no se agregan al índice.

Una lista de palabras vacías que se utilizarán durante la indexación puede especificarse en el diccionario de palabras vacías. De forma predeterminada, el diccionario de palabras vacías contiene los pronombres y preposiciones más utilizados en inglés y ruso. La lista de palabras vacías utilizada puede reemplazarse o complementarse fácilmente, y se conserva cuando se vuelve a cargar el índice. Para obtener información sobre cómo gestionar el diccionario de palabras vacías, consulte la página [Diccionario de palabras vacías](/net/search/developer-guide/advanced-usage/managing-dictionaries/stop-word-dictionary/) en la sección [Gestión de diccionarios](/net/search/developer-guide/advanced-usage/managing-dictionaries/).

Si necesita conservar toda la información de texto extraída de los documentos y no le preocupa un aumento significativo en el tamaño del índice, a continuación se muestra un ejemplo de indexación sin palabras vacías.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index settings with disabled using of stop words
IndexSettings settings = new IndexSettings();
settings.UseStopWords = false;
 
// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Searching in the index
// Now in the index it is possible to search for the stop word 'on'
SearchResult result = index.Search("on");
```

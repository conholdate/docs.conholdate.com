Los informes de indexación se crean para las operaciones de indexación y actualización. Los informes de indexación pueden recuperarse del índice mediante el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getindexingreports" target="_blank" rel="nofollow noopener noreferrer">GetIndexingReports</a>. Los informes se almacenan en el índice únicamente mientras este se encuentra cargado en la memoria RAM para su uso. Si vuelve a cargar el índice, los informes no se restaurarán.

Puede configurar el número máximo de informes almacenados mediante la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/maxindexingreportcount" target="_blank" rel="nofollow noopener noreferrer">MaxIndexingReportCount</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a>. El valor predeterminado es 5. Obtenga más información sobre la configuración del índice en la página [Configuración del índice de búsqueda](/net/search/developer-guide/advanced-usage/creating-an-index/search-index-settings/).

Cada informe de indexación contiene la siguiente información:

*   Número total de documentos en el índice;
*   Número total de palabras en el índice;
*   Longitud total de los documentos indexados en MB;
*   Número de segmentos del índice;
*   Tamaño total del índice en disco, en bytes;
*   Hora de inicio de la indexación;
*   Hora de finalización de la indexación;
*   Duración de la indexación;
*   Lista de errores;
*   Lista de documentos indexados;
*   Lista de documentos actualizados;
*   Lista de documentos eliminados.

El siguiente ejemplo muestra cómo obtener los informes de indexación desde un índice.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder1 = @"c:\MyDocuments1\";
string documentsFolder2 = @"c:\MyDocuments2\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents
index.Add(documentsFolder1);
index.Add(documentsFolder2);
 
// Getting indexing reports
IndexingReport[] reports = index.GetIndexingReports();
 
// Printing information from reports to the console
foreach (IndexingReport report in reports)
{
    Console.WriteLine("Time: " + report.StartTime);
    Console.WriteLine("Duration: " + report.IndexingTime);
    Console.WriteLine("Documents total: " + report.TotalDocumentsInIndex);
    Console.WriteLine("Terms total: " + report.TotalTermCount);
    Console.WriteLine("Indexed documents size (MB): " + report.IndexedDocumentsSize);
    Console.WriteLine("Index size (MB): " + (report.TotalIndexSize / 1024.0 / 1024.0));
    Console.WriteLine();
}
```

Esta página contiene información sobre los métodos de creación de índices.

El índice de búsqueda de GroupDocs.Search para .NET puede crearse y almacenarse en disco o completamente en memoria RAM. Todos los cambios realizados en el índice almacenado en disco se guardan automáticamente y están disponibles tras volver a cargarlo. El índice en memoria es más rápido, pero consume más RAM y se destruye por completo al finalizar el trabajo con él.

Para crear un índice en memoria, debe utilizar un constructor cuya lista de parámetros no incluya una ruta a la carpeta del índice. El índice en memoria creado puede convertirse en un índice en disco mediante el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/index/saveto/" target="_blank" rel="nofollow noopener noreferrer">SaveTo</a>. Esto resulta útil cuando el índice en memoria se vuelve demasiado grande y ya no puede permanecer únicamente en RAM. Tras guardarlo en disco, el índice puede cargarse desde disco como habitualmente se hace. Obsérvese que un índice normal también puede guardarse en disco en una carpeta diferente del mismo modo. A continuación se muestra un ejemplo de creación de un índice en memoria y su conversión a un índice en disco.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an in-memory index
Index index = new Index();

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Saving the index to disk
index.SaveTo(indexFolder);

// Closing the in-memory index
index.Dispose();

// Opening the index from disk
index = new Index(indexFolder);

// Searching in the index
string query = "focus";
SearchResult result = index.Search(query);
```

Para crear o cargar un índice en disco, debe pasar la ruta de la carpeta del índice mediante el parámetro del constructor. El índice en disco creado puede convertirse en un índice en memoria utilizando el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/index/loadintomemorycompletely/#loadintomemorycompletely" target="_blank" rel="nofollow noopener noreferrer">LoadIntoMemoryCompletely</a>. Una vez que el índice se ha cargado completamente en memoria, cualquier cambio en él no se guarda automáticamente en disco. Debe llamar explícitamente al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search/index/saveto/" target="_blank" rel="nofollow noopener noreferrer">SaveTo</a> para guardar los cambios realizados en el índice. A continuación se muestra un ejemplo de creación de un índice en disco y su conversión a un índice en memoria.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating a regular index on disk
Index index = new Index(indexFolder);

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Closing the regular index
index.Dispose();

// Loading the index entirely in memory for increased performance
Index inMemoryIndex = Index.LoadIntoMemoryCompletely(indexFolder);

// Searching in the index
string query = "focus";
SearchResult result = inMemoryIndex.Search(query);
```

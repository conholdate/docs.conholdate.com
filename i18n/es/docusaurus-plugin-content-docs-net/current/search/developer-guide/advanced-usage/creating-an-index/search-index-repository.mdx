La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository" target="_blank" rel="nofollow noopener noreferrer">IndexRepository</a> permite combinar varios índices en un grupo para realizar búsquedas en todos ellos simultáneamente. Además, una única llamada al método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository/methods/update/index" target="_blank" rel="nofollow noopener noreferrer">Update</a> puede actualizar todos los índices del repositorio. Asimismo, el repositorio de índices actúa como un centro de eventos para todos los índices que contiene; por lo tanto, puede suscribirse a cualquier evento disponible para un índice también a través del repositorio de índices. Sin embargo, tenga en cuenta que la indexación de documentos se realiza de forma independiente para cada índice.

Para comenzar a utilizar el repositorio de índices, los índices deben crearse o cargarse y agregarse a una instancia del repositorio de índices. A continuación se presentan ejemplos de creación y adición de índices al repositorio.

**C#**

```csharp
string indexFolder1 = @"c:\MyIndex1\";
string indexFolder2 = @"c:\MyIndex2\";
string documentsFolder1 = @"c:\MyDocuments1\";
string documentsFolder2 = @"c:\MyDocuments2\";
 
// Creating an index repository instance
IndexRepository indexRepository = new IndexRepository();
 
// Creating or loading an index and adding to the index repository
Index index1 = new Index(indexFolder1);
indexRepository.AddToRepository(index1);
 
// Creating an index via the index repository by calling a single method
Index index2 = indexRepository.Create(indexFolder2);
 
// Adding documents to the index 1
index1.Add(documentsFolder1);
 
// Adding documents to the index 2
index2.Add(documentsFolder2);
```

El siguiente ejemplo muestra cómo suscribirse a los eventos del repositorio, actualizar los índices en el repositorio y realizar búsquedas en el repositorio.

**C#**

```csharp
string indexFolder1 = @"c:\MyIndex1\";
string indexFolder2 = @"c:\MyIndex2\";
string documentFolder1 = @"c:\MyDocuments1\";
string documentFolder2 = @"c:\MyDocuments2\";
 
// Creating an index repository instance
IndexRepository indexRepository = new IndexRepository();
 
// Subscribing to an event
indexRepository.Events.ErrorOccurred += (sender, args) =>
{
    Console.WriteLine("Index: " + args.IndexFolder);
    Console.WriteLine("Error: " + args.Message);
};
 
// Creating or loading an index and adding to the index repository
Index index1 = new Index(indexFolder1);
indexRepository.AddToRepository(index1);
 
// Creating or loading an index and adding to the index repository
Index index2 = new Index(indexFolder2);
indexRepository.AddToRepository(index2);
 
// Adding documents to the index 1
index1.Add(documentFolder1);
 
// Adding documents to the index 2
index2.Add(documentFolder2);
 
// Changing, deleting, adding documents to document folders
// ...
 
// Updating all indexes in the repository
indexRepository.Update();
 
// Searching in the repository
SearchResult result = indexRepository.Search("Einstein");
```

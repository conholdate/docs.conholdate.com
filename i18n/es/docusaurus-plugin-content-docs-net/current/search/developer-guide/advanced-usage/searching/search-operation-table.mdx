La tabla siguiente proporciona la sintaxis de todos los elementos permitidos en las consultas de búsqueda de texto. Consulte también [Especificación del lenguaje de consultas](/net/search/developer-guide/advanced-usage/searching/query-language-specification/) y [Flujo de búsqueda](/net/search/developer-guide/advanced-usage/searching/search-flow/).

| Elemento | Sintaxis | Descripción | Ejemplos |
| --- | --- | --- | --- |
| Paréntesis | ( *consulta-interna* ) | Los paréntesis se utilizan para especificar el orden de las operaciones. | término1 &#124; (término2 &amp; término3); (\"gastos totales\" &#124; \"costes totales\") &amp; (82000 ~~ 83000) |
| Especificador de campo | *nombre-campo* : *consulta-interna* | El especificador de campo se utiliza para especificar el nombre del campo. | contenido : término; fecha_creación : (2010 ~~ 2013); nombre_archivo : informe &amp; fecha_creación : 2009 |
| Especificador de consulta de frase exacta | \" *consulta-frase-exacta* \" | El especificador de consulta de frase exacta se utiliza para especificar una frase que debe buscarse como tal. | \"término1 término2 término3\"; \"teoría de la complejidad computacional\"; \"lenguaje formal\" AND harrison |
| Operación AND | *consulta-izquierda* &amp; *consulta-derecha*<br/>*consulta-izquierda* AND *consulta-derecha* | La operación AND se utiliza para encontrar documentos que contengan tanto la consulta izquierda como la derecha. | término1 &amp; término2; término1 AND término2; computacional &amp; complejidad |
| Operación OR | *consulta-izquierda* &#124; *consulta-derecha*<br/>*consulta-izquierda* &#124;&#124; *consulta-derecha*<br/>*consulta-izquierda* OR *consulta-derecha* | La operación OR se utiliza para encontrar documentos que contengan la consulta izquierda, la derecha o ambas. | término1 &#124; término2; término1 &#124;&#124; término2; término1 OR término2; \"función de distribución acumulada\" OR \"función de densidad acumulada\" |
| Operación NOT | ! *consulta-interna*<br/>NOT *consulta-interna* | La operación NOT se utiliza para encontrar todos los documentos que no contengan la consulta interna. | ! término; NOT término; autor : (Cardano AND NOT Gerolamo) |
| Especificador de nombre de macro | @*nombre-macro* | El especificador de nombre de macro se utiliza para especificar el nombre de una macro dentro de la consulta de búsqueda, la cual será sustituida por el cuerpo de la macro antes de analizar la consulta. | @query\_macro; @macro1 &amp; @macro2 |
| Especificador de expresión regular | ^*expresión-regular* | El especificador de expresión regular se utiliza para especificar una consulta que sea una expresión regular. | ^^\[0-9\]\{1,5\}$ |
| Especificador de rango numérico | *número-inicio* ~~ *número-fin* | El especificador de rango numérico se utiliza para especificar un rango para la búsqueda por rango numérico. | 13 ~~ 42; 10000000000 ~~ 100000000000 |
| Especificador de rango de fecha | daterange( *fecha-inicio* ~~ *fecha-fin*)<br/>donde *fecha-inicio* y *fecha-fin* son fechas en el formato \'aaaa-MM-dd\'. | El especificador de rango de fecha se utiliza para especificar un rango para la búsqueda por rango de fechas. | daterange(2017-09-28 ~~ 2017-11-11) |
| Comodín (desde v.18.12) | ? — carácter comodín,<br/>?(*N*~*M*) — rango de caracteres comodín,<br/>\**N* — palabra comodín,<br/>\**N*~~*M* — rango de palabras comodín,<br/>donde *N* y *M* están en el rango de 0 a 255. | Los caracteres comodín y las palabras comodín se utilizan para buscar palabras con caracteres desconocidos y frases con palabras desconocidas, respectivamente. | ?ffect — para \'affect\', \'effect\'; princip?(2\~4) — para \'principal\', \'principle\', \'principles\', \'principally\'; ?(0\~2)sure — para \'assure\', \'ensure\', \'sure\'; \"\\\"First law \*1 thermodynamics\\\"\" — para \'First law of thermodynamics\'; \"\\\"Frodo \*1~~5 Pippin\\\"\" — para \'Frodo habló con Pippin\', \'Frodo quitó las mantas a Pippin\' |
| Secuencia de escape (desde v.19.2) | \\*N*<br/>donde *N* puede ser uno de los siguientes:<br/>( ) : \" & &#124; ! ^ ~ \* ? \\<br/>\- o -<br/>s (para el carácter espacio)<br/>\- o -<br/>u*hhhh*<br/>donde *h* es un dígito hexadecimal (para cualquier carácter Unicode) | La secuencia de escape permite utilizar un carácter especial en una consulta tal como es. Nótese que el carácter escapado debe estar representado en el alfabeto para que sea indexado como un carácter válido (y no como separador). | \\& — escape del carácter &; \\~ — escape del carácter ~; \\s — escape del carácter espacio; \\u0026 — escape del carácter & (código Unicode); R\\&B — búsqueda de 'R&B' como una palabra completa (el carácter & debe tener el tipo adecuado en el alfabeto antes de la indexación) |

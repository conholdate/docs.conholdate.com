La búsqueda de diferentes formas de palabras le permite buscar sustantivos en singular o plural, adjetivos en grado comparativo, formas de verbos regulares e irregulares, etc.

La búsqueda de diferentes formas de palabras está habilitada si <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usewordformssearch" target="_blank" rel="nofollow noopener noreferrer">UseWordFormsSearch</a> propiedad del <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> la clase se establece en `true`. De forma predeterminada, la búsqueda de diferentes formas de palabra está deshabilitada.

Para generar varias formas de palabras, una clase que implementa la <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/iwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">IWordFormsProvider</a> se utiliza la interfaz. La clase predeterminada es <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/englishwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">EnglishWordFormsProvider</a>, que admite formas de palabras solo en inglés. Para agregar soporte para formas de palabras en otros idiomas, consulte [Proveedor de formas de palabras](/net/search/developer-guide/advanced-usage/managing-dictionaries/word-forms-provider/) página.

El siguiente ejemplo demuestra cómo realizar búsquedas de distintas formas de una palabra en un índice.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Creating a search options instance
SearchOptions options = new SearchOptions();
options.UseWordFormsSearch = true; // Enabling search for word forms
 
// Searching in the index
SearchResult result = index.Search("relative", options);
 
// The following words can be found:
// relative
// relatives
// relatively
```

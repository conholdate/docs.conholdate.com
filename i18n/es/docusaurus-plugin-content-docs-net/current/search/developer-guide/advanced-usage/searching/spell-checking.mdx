Durante la búsqueda, se puede verificar si hay errores ortográficos en las palabras de la consulta de búsqueda. Para habilitar la corrección ortográfica en las consultas de búsqueda, se establece la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions/properties/enabled" target="_blank" rel="nofollow noopener noreferrer">Enabled</a> de las opciones del corrector ortográfico en `true`. De forma predeterminada, la corrección ortográfica está deshabilitada.

El corrector ortográfico considera los siguientes tipos de errores tipográficos: adición de un carácter, eliminación de un carácter, sustitución de un carácter y, opcionalmente, intercambio de dos caracteres adyacentes.

De forma predeterminada, el diccionario del corrector ortográfico solo contiene palabras en inglés. Para gestionar el diccionario del corrector ortográfico, consulte la página [Corrector ortográfico](/net/search/developer-guide/advanced-usage/managing-dictionaries/spelling-corrector/) de la sección [Gestión de diccionarios](/net/search/developer-guide/advanced-usage/managing-dictionaries/).

La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions" target="_blank" rel="nofollow noopener noreferrer">SpellingCorrectorOptions</a> contiene las siguientes propiedades:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions/properties/maxmistakecount" target="_blank" rel="nofollow noopener noreferrer">MaxMistakeCount</a> es el número máximo de errores posibles en cada palabra de la consulta de búsqueda. El valor predeterminado es 2.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions/properties/onlybestresults" target="_blank" rel="nofollow noopener noreferrer">OnlyBestResults</a> es un valor que indica si el corrector ortográfico devolverá únicamente los mejores resultados. El valor predeterminado es `false`.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions/properties/onlybestresultsrange" target="_blank" rel="nofollow noopener noreferrer">OnlyBestResultsRange</a> es el exceso máximo sobre el número mínimo de errores detectados por el corrector ortográfico. El valor predeterminado es 0.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/spellingcorrectoroptions/properties/considertranspositions" target="_blank" rel="nofollow noopener noreferrer">ConsiderTranspositions</a> es un valor que indica si el corrector ortográfico debe considerar el intercambio de dos caracteres adyacentes como un único error (`true`) o como dos errores (`false`). El valor predeterminado es `true`.

El siguiente ejemplo muestra cómo realizar una búsqueda utilizando la corrección ortográfica.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Creating a search options instance
SearchOptions options = new SearchOptions();
options.SpellingCorrector.Enabled = true; // Enabling the spelling correction
options.SpellingCorrector.MaxMistakeCount = 1; // Setting the maximum number of mistakes
options.SpellingCorrector.OnlyBestResults = true; // Enabling the option for only the best results of the spelling correction
 
// Search for the word "Rleativity" containing a spelling error
// The word "Relativity" will be found that differs from the search query in two transposed letters
SearchResult result = index.Search("Rleativity", options);
```

Cada vez que realice una búsqueda en un índice, se genera un informe para dicha búsqueda. Se puede obtener un array de informes de búsqueda llamando al método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/getsearchreports" target="_blank" rel="nofollow noopener noreferrer">GetSearchReports</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a>. Los informes se almacenan en el índice únicamente mientras este se encuentra cargado en la memoria RAM para su uso. Si vuelve a cargar el índice, los informes no se restaurarán.

Puede configurar el número máximo de informes almacenados mediante la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings/properties/maxsearchreportcount" target="_blank" rel="nofollow noopener noreferrer">MaxSearchReportCount</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexsettings" target="_blank" rel="nofollow noopener noreferrer">IndexSettings</a>. El valor predeterminado es 10. Obtenga más información sobre la configuración del índice en la página [Configuración del índice de búsqueda](/net/search/developer-guide/advanced-usage/creating-an-index/search-index-settings/).

Cada informe de búsqueda de índice contiene la siguiente información:

*   La hora de inicio de la búsqueda;
*   La hora de finalización de la búsqueda;
*   La duración de la búsqueda;
*   El número de documentos encontrados;
*   El número total de ocurrencias encontradas;
*   La consulta de búsqueda;
*   Las opciones de búsqueda.

El siguiente ejemplo muestra cómo obtener los informes de búsqueda de un índice.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Searching in index
SearchResult result1 = index.Search("Einstein");
SearchResult result2 = index.Search("\"Theory of Relativity\"");
 
// Getting search reports
SearchReport[] reports = index.GetSearchReports();
 
// Printing reports to the console
foreach (SearchReport report in reports)
{
    Console.WriteLine("Query: " + report.TextQuery);
    Console.WriteLine("Time: " + report.StartTime);
    Console.WriteLine("Duration: " + report.SearchDuration);
    Console.WriteLine("Documents: " + report.DocumentCount);
    Console.WriteLine("Occurrences: " + report.OccurrenceCount);
    Console.WriteLine();
}
```

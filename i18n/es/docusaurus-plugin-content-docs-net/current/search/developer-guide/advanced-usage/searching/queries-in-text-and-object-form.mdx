Existen dos formas de crear una consulta de búsqueda: en forma de texto o en forma de objeto.

Una consulta de búsqueda en forma de texto es más sencilla, pero menos flexible. La flexibilidad de las consultas en forma de objeto radica en que es posible que cada subconsulta defina opciones de búsqueda independientes. En forma de objeto, también puedes utilizar, por ejemplo, una consulta con expresiones regulares como parte de una consulta más compleja. Todas las combinaciones posibles de anidamiento de consultas de búsqueda en forma de objeto se pueden encontrar en la página. [Anidación de consultas de búsqueda en forma de objeto](/net/search/developer-guide/advanced-usage/searching/nesting-search-queries-in-object-form/).

La correlación entre dos formas de consultas de búsqueda es que cada consulta de texto antes de la búsqueda se transforma en una consulta en forma de objeto. Por lo tanto, el procesador maneja las consultas en forma de objeto de manera más rápida.

La especificación completa del lenguaje de consulta en forma de texto se presenta en esta página. [Especificación del lenguaje de consultas](/net/search/developer-guide/advanced-usage/searching/query-language-specification/). Sintaxis con ejemplos de todos los elementos permitidos en las consultas de búsqueda de texto se presenta en la página [Tabla de operaciones de búsqueda](/net/search/developer-guide/advanced-usage/searching/search-operation-table/).

Cada ejemplo en esta documentación generalmente se presenta con la consulta de búsqueda tanto en forma de texto como en forma de objeto.

A continuación se muestra un ejemplo de consulta compleja en forma de objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating index
Index index = new Index(indexFolder);
 
// Indexing
index.Add(documentsFolder);
 
// Creating subquery 1 - simple word query
SearchQuery subquery1 = SearchQuery.CreateWordQuery("future");
subquery1.SearchOptions = new SearchOptions(); // Setting search options only for subquery 1
subquery1.SearchOptions.FuzzySearch.Enabled = true;
subquery1.SearchOptions.FuzzySearch.FuzzyAlgorithm = new TableDiscreteFunction(3); // The maximum number of differences is 3
 
// Creating subquery 2 - numeric range query
SearchQuery subquery2 = SearchQuery.CreateNumericRangeQuery(1, 1000000);
 
// Creating subquery 3 - regular expression query 
SearchQuery subquery3 = SearchQuery.CreateRegexQuery(@"(.)\1");
 
// Combining subqueries into one query - phrase search query
SearchQuery query = SearchQuery.CreatePhraseSearchQuery(subquery1, subquery2, subquery3);
 
// Creating overall search options with increased capacity of occurrences
SearchOptions options = new SearchOptions();
options.MaxOccurrenceCountPerTerm = 1000000;
options.MaxTotalOccurrenceCount = 10000000;
 
// Searching
SearchResult result = index.Search(query, options);
 
// The result may contain the following word sequences:
// futile 12 blessed
// father 7 excellent
// tyre 8 assyria
// return 147 229
```

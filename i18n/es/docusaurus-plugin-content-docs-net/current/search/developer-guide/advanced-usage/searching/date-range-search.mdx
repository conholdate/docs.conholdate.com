Esta página describe cómo realizar búsquedas por fecha mediante búsquedas por rango de fechas. Además, explica la creación de consultas de búsqueda por fecha y también describe la gestión de formatos para búsquedas por rango de fechas.

## Creación de consultas de búsqueda por rango de fechas {#creating-date-range-search-queries}

La búsqueda por rango de fechas permite buscar fechas en documentos dentro de un rango determinado y en formatos de fecha especificados.

Las consultas para búsquedas por rango de fechas en formato de texto se especifican en el siguiente formato:

*   daterange( fecha ~~ fecha )

donde *fecha* es la fecha en formato *aaaa-MM-dd*, por ejemplo, 2019-09-13. Tenga en cuenta que, en una consulta de búsqueda, las fechas siempre se especifican en el mismo formato.

El siguiente ejemplo demuestra cómo realizar búsquedas por fecha mediante consultas en formato de texto y de objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search for dates using query in text form
string query1 = "daterange(2017-01-01 ~~ 2019-12-31)";
SearchResult result1 = index.Search(query1);
 
// Search for dates using query in text form
SearchQuery query2 = SearchQuery.CreateDateRangeQuery(new DateTime(2017, 1, 1), new DateTime(2019, 12, 31));
SearchResult result2 = index.Search(query2);
```

## Especificación de formatos de búsqueda por rango de fechas {#specifying-date-range-search-formats}

Para realizar la búsqueda por rango de fechas, se utilizan las plantillas de fecha especificadas en las opciones de búsqueda. Los siguientes formatos se utilizan de forma predeterminada:

*   dd.MM.yyyy
*   MM/dd/yyyy
*   yyyy-MM-dd

Los formatos para la búsqueda por rango de fechas se configuran en la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/dateformats" target="_blank" rel="nofollow noopener noreferrer">DateFormats</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a>. Para agregar un formato, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>; para eliminarlo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/remove" target="_blank" rel="nofollow noopener noreferrer">Remove</a>; y para borrar la colección de formatos existentes, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatcollection/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a>. Cada formato de la colección está definido por una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformat" target="_blank" rel="nofollow noopener noreferrer">DateFormat</a>. Para crear un nuevo formato, debe especificar una secuencia de elementos de formato y un carácter separador. Todos los elementos de formato disponibles están representados en la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement" target="_blank" rel="nofollow noopener noreferrer">DateFormatElement</a>:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dayofmonth" target="_blank" rel="nofollow noopener noreferrer">DayOfMonth</a> especifica el elemento de día del mes, representado por uno o dos dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dayofmonthtwodigits" target="_blank" rel="nofollow noopener noreferrer">DayOfMonthTwoDigits</a> especifica el elemento de día del mes, representado por dos dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/month" target="_blank" rel="nofollow noopener noreferrer">Month</a> especifica el elemento de mes, representado por uno o dos dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthtwodigits" target="_blank" rel="nofollow noopener noreferrer">MonthTwoDigits</a> especifica el elemento de mes, representado por dos dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthabbreviatedname" target="_blank" rel="nofollow noopener noreferrer">MonthAbbreviatedName</a> especifica el elemento de mes, representado por nombre abreviado;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/monthfullname" target="_blank" rel="nofollow noopener noreferrer">MonthFullName</a> especifica el elemento de mes, representado por nombre completo;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/year" target="_blank" rel="nofollow noopener noreferrer">Year</a> especifica el elemento de año, representado por uno, dos, tres o cuatro dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/yeartwodigits" target="_blank" rel="nofollow noopener noreferrer">YearTwoDigits</a> especifica el elemento de año, representado por dos dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/yearfourdigits" target="_blank" rel="nofollow noopener noreferrer">YearFourDigits</a> especifica el elemento de año, representado por cuatro dígitos;
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/dateformatelement/properties/dateseparator" target="_blank" rel="nofollow noopener noreferrer">DateSeparator</a> especifica el elemento separador de fecha.

A continuación se presenta un ejemplo de configuración del formato de fecha para la búsqueda.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Setting date formats
SearchOptions options = new SearchOptions();
options.DateFormats.Clear(); // Removing default date formats
DateFormatElement[] elements = new DateFormatElement[]
{
    DateFormatElement.MonthTwoDigits,
    DateFormatElement.DateSeparator,
    DateFormatElement.DayOfMonthTwoDigits,
    DateFormatElement.DateSeparator,
    DateFormatElement.YearFourDigits,
};
// Creating a date format pattern 'MM/dd/yyyy'
DateFormat dateFormat = new DateFormat(elements, "/");
options.DateFormats.Add(dateFormat);
 
// Searching in the index.
// For the given query, for example, the date 09/27/2019 will be found,
// but the date 2019-09-27 will not be found, because it is presented in a format that is not specified in the search options.
SearchResult result = index.Search("daterange(2017-01-01 ~~ 2019-12-31)", options);
```

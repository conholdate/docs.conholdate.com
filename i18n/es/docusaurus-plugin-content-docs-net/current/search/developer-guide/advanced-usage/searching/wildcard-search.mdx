La búsqueda con comodines le permite buscar palabras con letras desconocidas o rangos de letras.

En la forma de texto de una consulta de búsqueda, existen 2 formas de caracteres comodín:

*   ? para un solo carácter;
*   ?(*n*~*m*) para un grupo de caracteres, donde *n* y *m* son números del 0 al 255, y *n* &lt;= *m*.

La búsqueda con comodines es similar a la búsqueda con [expresiones regulares](/net/search/developer-guide/advanced-usage/searching/regular-expression-search/), pero funciona significativamente más rápido cuando los grupos de caracteres comodín son menos y están más cerca del final de la consulta de búsqueda.

Es importante saber que la búsqueda con comodines es lo suficientemente flexible como para utilizarse en consultas de prefijo, ya que una consulta de prefijo es un caso especial de una consulta con comodines.

A continuación se presentan ejemplos de búsquedas con comodines utilizando consultas en forma de texto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search in the index
SearchResult result1 = index.Search("m?rry"); // Search for 'merry', 'marry', etc.
SearchResult result2 = index.Search("card?(1~6)"); // Search for 'cardiff', 'cardinal', 'cardio', 'cards', etc.
```

Para construir una consulta de búsqueda comodín en forma de objeto, utilice la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/wordpattern" target="_blank" rel="nofollow noopener noreferrer">WordPattern</a>. Esta clase contiene métodos para agregar partes conocidas de una palabra y comodines a una plantilla. A continuación se presenta un ejemplo de cómo construir una consulta en forma de objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search with pattern "m?rry"
// Search for 'merry', 'marry', etc.
WordPattern pattern1 = new WordPattern();
pattern1.AppendString("m");
pattern1.AppendOneCharacterWildcard();
pattern1.AppendString("rry");
SearchQuery query1 = SearchQuery.CreateWordPatternQuery(pattern1);
SearchResult result1 = index.Search(query1);
 
// Search with pattern "card?(1~6)"
// Search for 'cardiff', 'cardinal', 'cardio', 'cards', etc.
WordPattern pattern2 = new WordPattern();
pattern2.AppendString("card");
pattern2.AppendWildcard(1, 6);
SearchQuery query2 = SearchQuery.CreateWordPatternQuery(pattern2);
SearchResult result2 = index.Search(query2);
```

Los adaptadores de salida se utilizan para enviar el HTML o texto plano generado a diversos objetos de salida. Actualmente se admiten los siguientes adaptadores de salida:

*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/fileoutputadapter" target="_blank" rel="nofollow noopener noreferrer">FileOutputAdapter</a> es un adaptador de salida que se utiliza para escribir texto en un archivo. La ruta del archivo se especifica en el constructor del adaptador.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/streamoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StreamOutputAdapter</a> es un adaptador de salida que se utiliza para escribir texto en un flujo (stream). El flujo se especifica en el constructor del adaptador.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/stringoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StringOutputAdapter</a> es un adaptador de salida que se utiliza para escribir texto en una cadena (string). La cadena resultante se puede acceder mediante el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/stringoutputadapter/methods/getresult" target="_blank" rel="nofollow noopener noreferrer">GetResult</a> de la clase del adaptador.
*   <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/structureoutputadapter" target="_blank" rel="nofollow noopener noreferrer">StructureOutputAdapter</a> es un adaptador de salida que se utiliza para escribir por separado el texto de cada campo del documento. El array resultante de campos se puede acceder mediante el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.common/structureoutputadapter/methods/getresult" target="_blank" rel="nofollow noopener noreferrer">GetResult</a> de la clase del adaptador.

El ejemplo siguiente muestra cómo utilizar adaptadores de distintos tipos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an index settings instance
IndexSettings settings = new IndexSettings();
settings.TextStorageSettings = new TextStorageSettings(Compression.High); // Enabling storage of extracted text in the index

// Creating an index in the specified folder
Index index = new Index(indexFolder, settings);

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Getting list of indexed documents
DocumentInfo[] documents = index.GetIndexedDocuments();

// Getting a document text
if (documents.Length > 0)
{
    DocumentInfo document = documents[0];

    // Output to a file
    FileOutputAdapter fileOutputAdapter = new FileOutputAdapter(OutputFormat.Html, @"C:\Text.html");
    index.GetDocumentText(document, fileOutputAdapter);

    // Output to a stream
    using (Stream stream = new MemoryStream())
    {
        StreamOutputAdapter streamOutputAdapter = new StreamOutputAdapter(OutputFormat.Html, stream);
        index.GetDocumentText(document, streamOutputAdapter);
    }

    // Output to a string
    StringOutputAdapter stringOutputAdapter = new StringOutputAdapter(OutputFormat.Html);
    index.GetDocumentText(document, stringOutputAdapter);
    string htmlText = stringOutputAdapter.GetResult();
    Console.WriteLine(htmlText);

    // Output to a structure
    StructureOutputAdapter structureOutputAdapter = new StructureOutputAdapter(OutputFormat.PlainText);
    index.GetDocumentText(document, structureOutputAdapter);
    DocumentField[] fields = structureOutputAdapter.GetResult();
    Console.WriteLine(document.ToString());
    for (int i = 0; i < fields.Length; i++)
    {
        DocumentField field = fields[i];
        Console.WriteLine("\t" + field.Name);
    }
}
```

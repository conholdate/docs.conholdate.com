La búsqueda inversa de imágenes es una búsqueda de imágenes similares a una imagen de referencia dada.

En el índice de GroupDocs.Search, la búsqueda inversa de imágenes permite buscar imágenes similares en archivos ZIP, diversos documentos y archivos individuales.
La búsqueda de imágenes se realiza comparando el *hash* perceptual de la imagen de referencia con los *hashes* de las imágenes presentes en el índice. La idea detrás del *hash* perceptual es que, para imágenes muy similares, este presenta un valor con un número mínimo de bits diferentes, mientras que para imágenes muy distintas, produce un gran número de bits diferentes.

En el motor GroupDocs.Search, la búsqueda inversa de imágenes, al igual que la búsqueda de texto completo, consta de dos etapas: la etapa de indexación y la etapa de búsqueda propiamente dicha.

Para buscar imágenes en el índice, debe habilitar al menos una de las siguientes banderas en las opciones durante la etapa de indexación:
* **EnabledForSeparateImages**: para indexar imágenes en archivos independientes.
* **EnabledForEmbeddedImages**: para indexar imágenes incrustadas en diversos documentos.
* **EnabledForContainerItemImages**: para indexar imágenes que forman parte de documentos contenedor, como archivos ZIP o almacenamientos OST/PST.
Para obtener más información, consulte la página [Opciones de indexación](/net/search/developer-guide/advanced-usage/indexing/indexing-options/).

Durante la etapa de búsqueda, están disponibles las siguientes opciones:
* **HashDifferences**: establece el número máximo de bits diferentes permitidos entre los *hashes* de las imágenes encontradas. Este valor oscila entre 0 y 32.
* **MaxResultCount**: establece el número máximo de imágenes encontradas.
* **SearchDocumentFilter**: define un filtro para los documentos encontrados.
Para obtener más información, consulte la página [Opciones de búsqueda de imágenes](/net/search/developer-guide/advanced-usage/searching/image-search-options/).

El siguiente ejemplo de código demuestra todas las etapas de la búsqueda inversa de imágenes:

**C#**

```csharp
string indexFolder = @"c:\MyIndex";
string documentFolder = @"c:\MyDocuments";

// Creating an index
Index index = new Index(indexFolder);

// Setting the image indexing options
IndexingOptions indexingOptions = new IndexingOptions();
indexingOptions.ImageIndexingOptions.EnabledForContainerItemImages = true;
indexingOptions.ImageIndexingOptions.EnabledForEmbeddedImages = true;
indexingOptions.ImageIndexingOptions.EnabledForSeparateImages = true;

// Indexing documents in a document folder
index.Add(documentFolder, indexingOptions);

// Setting the image search options
ImageSearchOptions imageSearchOptions = new ImageSearchOptions();
imageSearchOptions.HashDifferences = 10;
imageSearchOptions.MaxResultCount = 100;
imageSearchOptions.SearchDocumentFilter = SearchDocumentFilter.CreateFileExtension(".zip", ".png", ".jpg");

// Creating a reference image for search
SearchImage searchImage = SearchImage.Create(@"c:\MyDocuments\image.png");

// Searching in the index
ImageSearchResult result = index.Search(searchImage, imageSearchOptions);

Console.WriteLine("Images found: " + result.ImageCount);
for (int i = 0; i < result.ImageCount; i++)
{
    FoundImageFrame image = result.GetFoundImage(i);
    Console.WriteLine(image.DocumentInfo.ToString());
}
```

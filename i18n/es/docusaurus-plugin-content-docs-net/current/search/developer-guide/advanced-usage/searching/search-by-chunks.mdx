La API de GroupDocs.Search proporciona la capacidad de realizar búsquedas por fragmentos (chunks). Esto significa que, en una única llamada al método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a>, solo se realiza la búsqueda en un segmento del índice. Esta funcionalidad resulta relevante al realizar búsquedas en índices grandes que contienen decenas y cientos de miles de documentos.

Al realizar búsquedas por fragmentos, primero se llama al método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> con la bandera <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/ischunksearch" target="_blank" rel="nofollow noopener noreferrer">IsChunkSearch</a> establecida en `true` en las opciones de búsqueda. A continuación, la búsqueda en cada segmento subsiguiente se lleva a cabo mediante el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/searchnext/index" target="_blank" rel="nofollow noopener noreferrer">SearchNext</a>, pasando como argumento el <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/nextchunksearchtoken" target="_blank" rel="nofollow noopener noreferrer">ChunkSearchToken</a> del siguiente fragmento.

El siguiente ejemplo demuestra la búsqueda por fragmentos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
string query = "Einstein";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Creating a search options instance
SearchOptions options = new SearchOptions();
options.IsChunkSearch = true; // Enabling the search by chunks
 
// Starting the search by chunks
SearchResult result = index.Search(query, options);
Console.WriteLine("Document count: " + result.DocumentCount);
Console.WriteLine("Occurrence count: " + result.OccurrenceCount);
 
// Continuing the search by chunks
while (result.NextChunkSearchToken != null)
{
    result = index.SearchNext(result.NextChunkSearchToken);
    Console.WriteLine("Document count: " + result.DocumentCount);
    Console.WriteLine("Occurrence count: " + result.OccurrenceCount);
}
```

La tabla siguiente muestra las etapas internas de cada operación de búsqueda. Consulte también [Especificación del lenguaje de consulta](/net/search/developer-guide/advanced-usage/searching/query-language-specification/), [Tabla de operaciones de búsqueda](/net/search/developer-guide/advanced-usage/searching/search-operation-table/).

| Operación | Flujo de búsqueda |
| --- | --- |
| Búsqueda de término simple (no sensible a mayúsculas/minúsculas) | Corrección de diseño de teclado<br/>Corrección ortográfica<br/>Búsqueda de homófonos<br/>Búsqueda de sinónimos<br/>Búsqueda de formas de palabra (desde la versión 18.7)<br/>Búsqueda difusa<br/>Recuperación de resultados |
| Búsqueda de término simple (sensible a mayúsculas/minúsculas) | Recuperación de resultados |
| Búsqueda comodín (desde la versión 18.12) | Búsqueda comodín<br/>Recuperación de resultados |
| Búsqueda por rango de fechas | Recuperación de resultados |
| Búsqueda por rango numérico | Recuperación de resultados |
| Búsqueda de frase | Recuperación de resultados para cada término de la frase<br/>Unión de conjuntos de resultados |
| Búsqueda con expresiones regulares | Búsqueda con expresiones regulares<br/>Búsqueda difusa<br/>Recuperación de resultados |
| And, Or | Recuperación de resultados para cada operando<br/>Combinación de conjuntos de resultados |
| Not | Recuperación de resultados para el operando<br/>Inversión del conjunto de resultados |

Los resultados de la búsqueda se representan mediante la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>, cuya instancia es devuelta por el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index" target="_blank" rel="nofollow noopener noreferrer">Index</a>. Asimismo, el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search/indexrepository" target="_blank" rel="nofollow noopener noreferrer">IndexRepository</a> también devuelve una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>.

La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> contiene los siguientes miembros:

*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/documentcount" target="_blank" rel="nofollow noopener noreferrer">DocumentCount</a> devuelve el número de documentos encontrados.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> devuelve el número total de ocurrencias encontradas.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/truncated" target="_blank" rel="nofollow noopener noreferrer">Truncated</a> devuelve un valor que indica que el resultado está truncado debido a los límites especificados en las opciones de búsqueda.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/warnings" target="_blank" rel="nofollow noopener noreferrer">Warnings</a> devuelve advertencias que describen el resultado, por ejemplo, una advertencia sobre la presencia de una palabra vacía en la consulta de búsqueda.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/nextchunksearchtoken" target="_blank" rel="nofollow noopener noreferrer">NextChunkSearchToken</a> devuelve un token de búsqueda por fragmentos para buscar el siguiente fragmento. Para obtener más información sobre la búsqueda por fragmentos, consulte la página [Búsqueda por fragmentos](/net/search/developer-guide/advanced-usage/searching/search-by-chunks/).
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/starttime" target="_blank" rel="nofollow noopener noreferrer">StartTime</a> devuelve la hora de inicio de la búsqueda.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/endtime" target="_blank" rel="nofollow noopener noreferrer">EndTime</a> devuelve la hora de finalización de la búsqueda.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/properties/searchduration" target="_blank" rel="nofollow noopener noreferrer">SearchDuration</a> devuelve la duración de la búsqueda.
*   El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/methods/getfounddocument" target="_blank" rel="nofollow noopener noreferrer">GetFoundDocument</a> devuelve el documento encontrado según su índice.
*   El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult/methods/getenumerator" target="_blank" rel="nofollow noopener noreferrer">GetEnumerator</a> devuelve un enumerador que recorre la colección de documentos encontrados.

El documento encontrado se representa mediante una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a>. La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a> contiene los siguientes miembros:

*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/documentinfo" target="_blank" rel="nofollow noopener noreferrer">DocumentInfo</a> devuelve el objeto de información del documento que contiene la ruta del archivo, el tipo de archivo, la familia de formatos y la ruta interna del documento para los elementos de documentos contenedor.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/relevance" target="_blank" rel="nofollow noopener noreferrer">Relevance</a> devuelve la relevancia del documento en el resultado de la búsqueda.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> devuelve el número de ocurrencias encontradas en el documento.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/foundfields" target="_blank" rel="nofollow noopener noreferrer">FoundFields</a> devuelve los campos del documento encontrados.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/terms" target="_blank" rel="nofollow noopener noreferrer">Terms</a> devuelve los términos encontrados. El valor se evalúa cada vez que se accede a la propiedad, basándose en los datos de cada campo de documento encontrado.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument/properties/termsequences" target="_blank" rel="nofollow noopener noreferrer">TermSequences</a> devuelve las secuencias de términos encontradas.
*   El método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocument/methods/serialize" target="_blank" rel="nofollow noopener noreferrer">Serialize</a> serializa la instancia actual del documento encontrado a una matriz de bytes.
*   El método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocument/methods/deserialize" target="_blank" rel="nofollow noopener noreferrer">Deserialize</a> deserializa una instancia de documento encontrado desde una matriz de bytes.

El campo del documento encontrado se representa mediante una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a>. La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a> contiene los siguientes miembros:

*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/fieldname" target="_blank" rel="nofollow noopener noreferrer">FieldName</a> devuelve el nombre del campo.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/occurrencecount" target="_blank" rel="nofollow noopener noreferrer">OccurrenceCount</a> devuelve el número de ocurrencias encontradas.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/terms" target="_blank" rel="nofollow noopener noreferrer">Terms</a> devuelve los términos encontrados.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsoccurrences" target="_blank" rel="nofollow noopener noreferrer">TermsOccurrences</a> devuelve las ocurrencias de los términos encontrados.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsequences" target="_blank" rel="nofollow noopener noreferrer">TermSequences</a> devuelve las secuencias de términos encontradas.
*   La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield/properties/termsequencesoccurrences" target="_blank" rel="nofollow noopener noreferrer">TermSequencesOccurrences</a> devuelve las ocurrencias de las secuencias de términos encontradas.
*   El método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocumentfield/methods/serialize" target="_blank" rel="nofollow noopener noreferrer">Serialize</a> serializa la instancia actual del campo de documento encontrado a una matriz de bytes.
*   El método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.results/founddocumentfield/methods/deserialize" target="_blank" rel="nofollow noopener noreferrer">Deserialize</a> deserializa una instancia de campo de documento encontrado desde una matriz de bytes.

El siguiente ejemplo muestra cómo imprimir en la consola la información sobre los documentos encontrados.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Creating search options
SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new TableDiscreteFunction(3); // Setting the maximum number of differences to 3
 
// Search for documents containing the word 'Einstein' or the phrase 'Theory of Relativity'
SearchResult result = index.Search("Einstein OR \"Theory of Relativity\"", options);
 
// Printing the result
Console.WriteLine("Documents: " + result.DocumentCount);
Console.WriteLine("Total occurrences: " + result.OccurrenceCount);
for (int i = 0; i < result.DocumentCount; i++)
{
    FoundDocument document = result.GetFoundDocument(i);
    Console.WriteLine("\tDocument: " + document.DocumentInfo.FilePath);
    Console.WriteLine("\tOccurrences: " + document.OccurrenceCount);
    for (int j = 0; j < document.FoundFields.Length; j++)
    {
        FoundDocumentField field = document.FoundFields[j];
        Console.WriteLine("\t\tField: " + field.FieldName);
        Console.WriteLine("\t\tOccurrences: " + document.OccurrenceCount);
        // Printing found terms
        if (field.Terms != null)
        {
            for (int k = 0; k < field.Terms.Length; k++)
            {
                Console.WriteLine("\t\t\t" + field.Terms[k].PadRight(20) + field.TermsOccurrences[k]);
            }
        }
        // Printing found phrases
        if (field.TermSequences != null)
        {
            for (int k = 0; k < field.TermSequences.Length; k++)
            {
                string sequence = string.Join(" ", field.TermSequences[k]);
                Console.WriteLine("\t\t\t" + sequence.PadRight(30) + field.TermSequencesOccurrences[k]);
            }
        }
    }
}
```

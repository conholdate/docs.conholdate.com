Al ingresar consultas de búsqueda, los usuarios de su software pueden cometer errores de entrada, por ejemplo, olvidando cambiar el diseño de teclado deseado. Por ejemplo, al escribir la palabra *'Einstein'* con el diseño de teclado en ruso, aparecerá la palabra *'Уштыеушт'*.

Para corregir automáticamente tales errores tipográficos, se puede utilizar la función de corrección del diseño de teclado. Para habilitar esta función, debe establecer el valor `true` para la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/keyboardlayoutcorrectoroptions/properties/enabled" target="_blank" rel="nofollow noopener noreferrer">Enabled</a> en las opciones de búsqueda. De forma predeterminada, esta función está deshabilitada.

El siguiente ejemplo demuestra el uso de la función de corrección del diseño de teclado.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an index in the specified folder
Index index = new Index(indexFolder);

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Creating a search options object
SearchOptions options = new SearchOptions();
options.KeyboardLayoutCorrector.Enabled = true; // Enabling keyboard layout correction

// Search for word 'Уштыеушт' gives documents containing word 'Einstein'
SearchResult result = index.Search("Уштыеушт", options);
```

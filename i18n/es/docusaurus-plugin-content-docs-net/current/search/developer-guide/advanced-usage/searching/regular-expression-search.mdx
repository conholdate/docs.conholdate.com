Las consultas de búsqueda mediante expresiones regulares (RegEx) son universales y muy flexibles, pero al mismo tiempo, en índices grandes, su rendimiento se vuelve extremadamente bajo. Otra limitación de las expresiones regulares es que la búsqueda con un patrón se realiza palabra por palabra, y no sobre el texto completo de un campo de documento.

Las consultas de este tipo siempre comienzan con el carácter circunflejo (^), y si la expresión regular en sí también comienza con el carácter circunflejo, entonces habrá dos caracteres circunflejo al inicio de la consulta.

Una consulta de búsqueda regex en forma de texto no se puede combinar con otros tipos de consultas. Consulte la página [Especificación del lenguaje de consultas](/net/search/developer-guide/advanced-usage/searching/query-language-specification/). Sin embargo, en forma de objeto, las expresiones regulares sí pueden combinarse con otras consultas. Consulte la página [Anidación de consultas de búsqueda en forma de objeto](/net/search/developer-guide/advanced-usage/searching/nesting-search-queries-in-object-form/).

El siguiente ejemplo demuestra la búsqueda regex en formas de texto y objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search for the phrase in text form
string query1 = "^^(.)\\1{1,}"; // The first caret character at the beginning indicates that this is a regular expression search query
SearchResult result1 = index.Search(query1); // Search for two or more identical characters at the beginning of a word
 
// Search for the phrase in object form
SearchQuery query2 = SearchQuery.CreateRegexQuery("^(.)\\1{1,}"); // Search for two or more identical characters at the beginning of a word
SearchResult result2 = index.Search(query2);
```

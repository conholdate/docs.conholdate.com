La búsqueda por sinónimos le permite encontrar no solo las palabras especificadas en la consulta de búsqueda, sino también sus sinónimos, es decir, palabras que tienen el mismo significado.

Para habilitar la búsqueda por sinónimos, debe establecer la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions/properties/usesynonymsearch" target="_blank" rel="nofollow noopener noreferrer">UseSynonymSearch</a> de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> en `true`. De forma predeterminada, la búsqueda por sinónimos está deshabilitada.

El diccionario de sinónimos predeterminado contiene sinónimos únicamente para el idioma inglés. Para gestionar el diccionario de sinónimos, consulte la página [Diccionario de sinónimos](/net/search/developer-guide/advanced-usage/managing-dictionaries/synonym-dictionary/) en la sección [Gestión de diccionarios](/net/search/developer-guide/advanced-usage/managing-dictionaries/).

El siguiente ejemplo demuestra la búsqueda por sinónimos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Creating a search options object
SearchOptions options = new SearchOptions();
options.UseSynonymSearch = true; // Enabling synonym search
 
// Search for the word 'answer'
// In addition to the word 'answer', the words 'reply' and 'response' will also be found
SearchResult result = index.Search("answer", options);
```

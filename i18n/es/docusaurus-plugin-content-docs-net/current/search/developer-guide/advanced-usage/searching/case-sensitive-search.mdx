La búsqueda sensible a mayúsculas y minúsculas le permite encontrar palabras considerando las letras mayúsculas y minúsculas como distintas. Por ejemplo, en una búsqueda sensible a mayúsculas y minúsculas, las palabras «Theory», «theory» y «THEORY» son todas diferentes.

Tenga en cuenta que la búsqueda sensible a mayúsculas y minúsculas no es compatible con otros tipos de búsqueda (consulte [Flujo de búsqueda](/net/search/developer-guide/advanced-usage/searching/search-flow/)).

El siguiente ejemplo muestra cómo realizar una búsqueda sensible a mayúsculas y minúsculas mediante una consulta en formato de texto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
Index index = new Index(indexFolder); // Creating index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder
 
SearchOptions options = new SearchOptions();
options.UseCaseSensitiveSearch = true; // Enabling case sensitive search
 
string query = "Windows";
SearchResult result = index.Search(query, options); // Searching
```

El siguiente ejemplo demuestra cómo realizar una búsqueda sensible a mayúsculas y minúsculas con una consulta en forma de objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
Index index = new Index(indexFolder); // Creating index in the specified folder
index.Add(documentsFolder); // Indexing documents from the specified folder
 
SearchOptions options = new SearchOptions();
options.UseCaseSensitiveSearch = true; // Enabling case sensitive search
 
SearchQuery query = SearchQuery.CreateWordQuery("Windows"); // Creating search query in object form
 
SearchResult result = index.Search(query, options); // Searching
```

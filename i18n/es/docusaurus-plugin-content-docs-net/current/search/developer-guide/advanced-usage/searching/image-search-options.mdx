Esta página contiene una descripción de todas las opciones de búsqueda que se pueden especificar en una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a>.

## Propiedad HashDifferences {#hashdifferences-property}

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/imagesearchoptions/properties/hashdifferences" target="_blank" rel="nofollow noopener noreferrer">HashDifferences</a> permite especificar el número máximo de bits distintos en el hash de la imagen. Si todos los bits del hash coinciden, las imágenes coinciden completamente. Cuantos más bits distintos haya, mayor será la diferencia entre las imágenes. El valor predeterminado de esta propiedad es 5. El valor debe estar en el rango de 0 a 32.

## Propiedad MaxResultCount {#maxresultcount-property}

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/imagesearchoptions/properties/maxresultcount" target="_blank" rel="nofollow noopener noreferrer">MaxResultCount</a> permite especificar el número máximo de imágenes encontradas para una solicitud de búsqueda inversa de imágenes. El valor predeterminado es 1000.

## Propiedad SearchDocumentFilter {#searchdocumentfilter-property}

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.options/imagesearchoptions/properties/searchdocumentfilter" target="_blank" rel="nofollow noopener noreferrer">SearchDocumentFilter</a> permite especificar el filtro de documentos que se devolverán como resultado de la búsqueda. De forma predeterminada, se devuelven como resultado de la búsqueda todos los documentos encontrados. Para obtener más información, consulte la página [Filtrado de documentos en el resultado de la búsqueda](/net/search/developer-guide/advanced-usage/searching/document-filtering-in-search-result/).

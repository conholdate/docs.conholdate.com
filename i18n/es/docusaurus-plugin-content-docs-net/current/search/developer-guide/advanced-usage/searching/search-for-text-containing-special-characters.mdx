En el caso de que la consulta de búsqueda deba contener caracteres especiales que no sean caracteres de control, dichos caracteres deben ser escapados.
Los caracteres especiales son:
<pre>
( ) : " & | ! ^ ~ * ? \ <i>espacio</i>
</pre>
Estos caracteres pueden ser escapados añadiendo un signo \\ a la izquierda del carácter. Por ejemplo:  
\\& — escape del carácter &;  
\\~ — escape del carácter ~;  
\\s — escape del carácter espacio.  
Consulte la [tabla de operaciones de búsqueda](/net/search/developer-guide/advanced-usage/searching/search-operation-table/) para obtener detalles sobre la sintaxis de la consulta de búsqueda.

Sin embargo, debe tenerse en cuenta que si el carácter escapado es un separador, este no se encontrará en el texto, ya que no está indexado. Como consecuencia, las palabras que contengan dichos caracteres tampoco se encontrarán al realizar una búsqueda de coincidencia exacta.

Si la consulta de búsqueda contiene caracteres separadores, las palabras que contengan dichos caracteres no se encontrarán. En efecto, al indexar, estos caracteres dividen la palabra en partes, y ellos mismos se eliminan y no se indexan.
Por lo tanto, al realizar una búsqueda, la consulta debe verificarse para detectar la presencia de caracteres separadores. Cada palabra que contenga dichos caracteres debe dividirse en varias palabras más pequeñas y formar una frase de búsqueda.

El orden de procesamiento de cada palabra en una consulta de búsqueda es el siguiente:
1. Si hay separadores en la palabra, estos se sustituyen por espacios y la búsqueda de la palabra se convierte en una búsqueda de frase.
2. Si hay caracteres especiales en la palabra, estos se escapan.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";

// Creating an index in the specified folder
Index index = new Index(indexFolder);

// Setting character types
index.Dictionaries.Alphabet.SetRange(new char[] { '&' }, CharacterType.Letter);
index.Dictionaries.Alphabet.SetRange(new char[] { '-' }, CharacterType.Separator);

// Indexing documents from the specified folder
index.Add(documentsFolder);

// Defining a search query
string word = "rock&roll-music";

// Replacing separators with the space characters
StringBuilder result = new StringBuilder();
for (int i = 0; i < word.Length; i++)
{
    char character = word[i];
    CharacterType characterType = index.Dictionaries.Alphabet.GetCharacterType(character);
    if (characterType == CharacterType.Separator)
    {
        result.Append(' ');
    }
    else
    {
        result.Append(character);
    }
}

// Escaping special characters
const string specialCharacters = "():\"&|!^~*?\\";
for (int i = result.Length - 1; i >= 0; i--)
{
    char c = result[i];
    if (specialCharacters.Contains(c.ToString()))
    {
        result.Insert(i, '\\');
    }
}

string query = result.ToString();
if (query.Contains(" "))
{
    query = "\"" + query + "\"";
}

// Searching
SearchResult searchResult = index.Search(query);
```

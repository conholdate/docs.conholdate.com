La búsqueda por rango numérico o búsqueda numérica le permite buscar en documentos cualquier número entero dentro del rango de 0 a 9223372036854775807 (Int64.MaxValue). Tenga en cuenta que el número en el texto no debe estar separado por espacios, ya que de lo contrario se considerará como varios números. Una consulta de búsqueda de este tipo se especifica de la siguiente manera:

número ~~ número

El ejemplo siguiente demuestra la búsqueda por rango numérico en forma de texto y de objeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Search with text query
SearchResult result1 = index.Search("500 ~~ 600");
 
// Search with object query
SearchQuery query2 = SearchQuery.CreateNumericRangeQuery(500, 600);
SearchResult result2 = index.Search(query2);
```

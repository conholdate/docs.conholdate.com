Una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary" target="_blank" rel="nofollow noopener noreferrer">AliasDictionary</a> contiene todos los alias definidos en un índice. La información sobre cómo utilizar alias para realizar búsquedas se proporciona en la página [Uso de alias](/net/search/developer-guide/advanced-usage/searching/using-aliases/).

Para obtener el número de alias existentes, utilice la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a>.

Utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> para agregar un nuevo par alias-sustituto.

Utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> para agregar una colección de nuevos pares alias-sustituto.

Para eliminar un alias del diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/remove" target="_blank" rel="nofollow noopener noreferrer">Remove</a>.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/contains" target="_blank" rel="nofollow noopener noreferrer">Contains</a> se utiliza para comprobar si un alias determinado existe en el diccionario.

Para obtener el sustituto de un alias determinado, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a>.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/aliasdictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> se utiliza para eliminar todos los alias existentes del diccionario.

Para exportar la lista de alias con sus sustitutos a un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a>.

Para importar la lista de alias desde un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a>.

El siguiente ejemplo demuestra el uso de los métodos del diccionario de alias.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
 
// Creating or opening an index from the specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.AliasDictionary.Count > 0)
{
    // Deleting all existing aliases
    index.Dictionaries.AliasDictionary.Clear();
}
 
// Adding aliases to the alias dictionary
index.Dictionaries.AliasDictionary.Add("t", "(theory OR relativity)");
index.Dictionaries.AliasDictionary.Add("e", "(Einstein OR Albert)");
AliasReplacementPair[] pairs = new AliasReplacementPair[]
{
    new AliasReplacementPair("d", "daterange(2017-01-01 ~~ 2019-12-31)"),
    new AliasReplacementPair("n", "(100 ~~ 900)"),
};
index.Dictionaries.AliasDictionary.AddRange(pairs);
 
if (index.Dictionaries.AliasDictionary.Contains("e"))
{
    // Getting an alias replacement
    string replacement = index.Dictionaries.AliasDictionary.GetText("e");
    Console.WriteLine("e - " + replacement);
}
 
// Export aliases to a file
index.Dictionaries.AliasDictionary.ExportDictionary(@"C:\Aliases.dat");
 
// Import aliases from a file
index.Dictionaries.AliasDictionary.ImportDictionary(@"C:\Aliases.dat");
 
// Search in the index
SearchResult result = index.Search("@t OR @e");
```

La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary" target="_blank" rel="nofollow noopener noreferrer">SynonymDictionary</a> está diseñada para almacenar sinónimos en un índice. Para obtener información sobre la búsqueda mediante sinónimos, consulte la página [Búsqueda con sinónimos](/net/search/developer-guide/advanced-usage/searching/synonym-search/).

Para obtener el número de sinónimos en el diccionario, utilice la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a>.

Para agregar grupos de sinónimos al diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a>.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> se utiliza para eliminar todos los sinónimos del diccionario.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/methods/getsynonyms" target="_blank" rel="nofollow noopener noreferrer">GetSynonyms</a> se utiliza para obtener una lista de sinónimos para una palabra determinada.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/methods/getsynonymgroups" target="_blank" rel="nofollow noopener noreferrer">GetSynonymGroups</a> se utiliza para obtener todos los grupos de sinónimos a los que pertenece una palabra determinada.

Para obtener todos los grupos de sinónimos del diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/synonymdictionary/methods/getallsynonymgroups" target="_blank" rel="nofollow noopener noreferrer">GetAllSynonymGroups</a>.

Para exportar los sinónimos a un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a>.

Para importar sinónimos desde un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a>.

El siguiente ejemplo demuestra el uso de los métodos del diccionario de sinónimos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";

// Creating an index from in specified folder
Index index = new Index(indexFolder);

// Getting synonyms for word 'make'
string[] synonyms = index.Dictionaries.SynonymDictionary.GetSynonyms("make");
Console.WriteLine("Synonyms for 'make':");
for (int i = 0; i < synonyms.Length; i++)
{
    Console.WriteLine(synonyms[i]);
}

// Getting groups of synonyms to which word 'make' belongs to
string[][] groups = index.Dictionaries.SynonymDictionary.GetSynonymGroups("make");
Console.WriteLine("Synonym groups for 'make':");
for (int i = 0; i < groups.Length; i++)
{
    string[] group = groups[i];
    for (int j = 0; j < group.Length; j++)
    {
        Console.Write(group[j] + " ");
    }
    Console.WriteLine();
}

if (index.Dictionaries.SynonymDictionary.Count > 0)
{
    // Removing all synonyms from the dictionary
    index.Dictionaries.SynonymDictionary.Clear();
}

// Adding synonyms to the dictionary
string[][] synonymGroups = new string[][]
{
    new string[] { "achieve", "accomplish", "attain", "reach" },
    new string[] { "accept", "take", "have" },
};
index.Dictionaries.SynonymDictionary.AddRange(synonymGroups);

// Export synonyms to a file
index.Dictionaries.SynonymDictionary.ExportDictionary(@"C:\Synonyms.dat");

// Import synonyms from a file
index.Dictionaries.SynonymDictionary.ImportDictionary(@"C:\Synonyms.dat");
```

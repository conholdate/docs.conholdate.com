Una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/alphabet" target="_blank" rel="nofollow noopener noreferrer">Alphabet</a> contiene los tipos de caracteres utilizados para la indexación. Para obtener información detallada sobre los tipos de caracteres, consulte la página [Tipos de caracteres](/net/search/developer-guide/advanced-usage/indexing/character-types/).

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/alphabet/methods/getcharactertype" target="_blank" rel="nofollow noopener noreferrer">GetCharacterType</a> se utiliza para obtener el tipo de un carácter específico.

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/alphabet/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> devuelve el número de caracteres cuyo tipo no es <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/charactertype" target="_blank" rel="nofollow noopener noreferrer">CharacterType</a>.Separator.

Para establecer los tipos de caracteres en el alfabeto, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/alphabet/methods/setrange" target="_blank" rel="nofollow noopener noreferrer">SetRange</a>.

Para establecer el tipo <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/charactertype" target="_blank" rel="nofollow noopener noreferrer">CharacterType</a>.Separator para todos los caracteres del alfabeto, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/alphabet/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a>.

Para exportar los tipos de todos los caracteres a un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a>.

Para importar los tipos de todos los caracteres desde un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a>.

El siguiente ejemplo demuestra el uso de los métodos del alfabeto.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
 
// Creating or opening an index from the specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.Alphabet.Count > 0)
{
    // Setting a type of all characters to Separator
    index.Dictionaries.Alphabet.Clear();
}
 
if (index.Dictionaries.Alphabet.GetCharacterType('-') != CharacterType.Blended)
{
    // Setting a type of hyphen character to Blended
    index.Dictionaries.Alphabet.SetRange(new char[] { '-' }, CharacterType.Blended);
}
 
// Export the alphabet to a file
index.Dictionaries.Alphabet.ExportDictionary(@"C:\Alphabet.dat");
 
// Import the alphabet from a file
index.Dictionaries.Alphabet.ImportDictionary(@"C:\Alphabet.dat");
```

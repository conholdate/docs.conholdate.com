El <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary" target="_blank" rel="nofollow noopener noreferrer">PasswordDictionary</a> La clase está diseñada para almacenar contraseñas de documentos que se van a indexar. La información sobre la indexación de documentos protegidos con contraseña se presenta en la [Indexación de documentos protegidos por contraseña](/net/search/developer-guide/advanced-usage/indexing/indexing-password-protected-documents/) página.

Para obtener la cantidad de contraseñas en el diccionario, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> propiedad.

Para obtener la contraseña de un documento desde el diccionario, la <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/methods/getpassword" target="_blank" rel="nofollow noopener noreferrer">GetPassword</a> se utiliza el método, pasando la ruta al documento como argumento.

El <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> El método se utiliza para eliminar todas las contraseñas del diccionario.

Para verificar la presencia de una contraseña en el diccionario para el documento especificado, el <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/methods/contains" target="_blank" rel="nofollow noopener noreferrer">Contains</a> se utiliza el método.

Para agregar una contraseña al diccionario, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> método. La clave es la ruta al documento.

Para eliminar una contraseña del diccionario, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/passworddictionary/methods/remove" target="_blank" rel="nofollow noopener noreferrer">Remove</a> método.

El siguiente ejemplo demuestra el uso de los métodos del diccionario de contraseñas.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
 
// Creating an index from in specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.DocumentPasswords.Count > 0)
{
    // Removing all passwords from the dictionary
    index.Dictionaries.DocumentPasswords.Clear();
}
 
string path = Path.GetFullPath(@"c:\MyIndex\Protected.pdf");
if (index.Dictionaries.DocumentPasswords.Contains(path))
{
    // Getting a password for a document
    string password = index.Dictionaries.DocumentPasswords.GetPassword(path);
    Console.WriteLine(path);
    Console.WriteLine("\tPassword: " + password);
 
    // Deleting the password from the dictionary
    index.Dictionaries.DocumentPasswords.Remove(path);
}
 
// Adding a password for a document
index.Dictionaries.DocumentPasswords.Add(path, "123456");
```

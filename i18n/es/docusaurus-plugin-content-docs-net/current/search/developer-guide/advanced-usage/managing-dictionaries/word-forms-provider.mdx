La interfaz <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/iwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">IWordFormsProvider</a> está diseñada para implementar un proveedor de formas de palabra para la búsqueda por formas de palabra. Para obtener información sobre la búsqueda por formas de palabra, consulte la página [Búsqueda de distintas formas de palabra](/net/search/developer-guide/advanced-usage/searching/search-for-different-word-forms/).

La interfaz <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/iwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">IWordFormsProvider</a> contiene únicamente un método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/iwordformsprovider/methods/getwordforms" target="_blank" rel="nofollow noopener noreferrer">GetWordForms</a>, que devuelve distintas formas para la palabra pasada como argumento. A continuación se presenta un ejemplo de implementación de un proveedor sencillo de formas de palabra.

**C#**

```csharp
public class SimpleWordFormsProvider : IWordFormsProvider
{
    public string[] GetWordForms(string word)
    {
        List<string> result = new List<string>();
 
        // We assume that the input word is in the plural, then we add the singular
        if (word.Length > 2 &&
            word.EndsWith("es", StringComparison.InvariantCultureIgnoreCase))
        {
            result.Add(word.Substring(0, word.Length - 2));
        }
        if (word.Length > 1 &&
            word.EndsWith("s", StringComparison.InvariantCultureIgnoreCase))
        {
            result.Add(word.Substring(0, word.Length - 1));
        }
 
        // Then we assume that the input word is in the singular, we add the plural
        if (word.Length > 1 &&
            word.EndsWith("e", StringComparison.InvariantCultureIgnoreCase))
        {
            result.Add(word + "s");
        }
        if (word.Length > 1 &&
            word.EndsWith("y", StringComparison.InvariantCultureIgnoreCase))
        {
            result.Add(word.Substring(0, word.Length - 1) + "is");
        }
        result.Add(word + "es");
        // All rules are implemented in the EnglishWordFormsProvider class
 
        return result.ToArray();
    }
}
```

De forma predeterminada, se utiliza la clase **<a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/englishwordformsprovider" target="_blank" rel="nofollow noopener noreferrer">EnglishWordFormsProvider</a>**, la cual, para el idioma inglés, genera diversas formas de sustantivos, adjetivos, pronombres, verbos, etc. A continuación se presenta un ejemplo de cómo configurar un proveedor personalizado de formas de palabras.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentsFolder = @"c:\MyDocuments\";
 
// Creating an index in the specified folder
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentsFolder);
 
// Setting the custom word forms provider instance
index.Dictionaries.WordFormsProvider = new SimpleWordFormsProvider();
 
// Creating a search options instance
SearchOptions options = new SearchOptions();
options.UseWordFormsSearch = true; // Enabling search for word forms
 
// Searching in the index
SearchResult result = index.Search("relative", options);
 
// The following words can be found:
// relative
// relatives
```

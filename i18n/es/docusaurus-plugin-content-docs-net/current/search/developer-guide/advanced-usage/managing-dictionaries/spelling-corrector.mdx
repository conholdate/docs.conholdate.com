El <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector" target="_blank" rel="nofollow noopener noreferrer">SpellingCorrector</a> La clase está diseñada para corregir errores ortográficos en consultas de búsqueda, así como para almacenar palabras con la ortografía correcta. Puede obtener más información sobre la corrección ortográfica en consultas de búsqueda en [Corrección ortográfica](/net/search/developer-guide/advanced-usage/searching/spell-checking/) página.

Para obtener el número de palabras en el diccionario del corrector ortográfico, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> propiedad.

Para obtener un array de palabras contenidas en el diccionario del corrector ortográfico, la <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/getwords" target="_blank" rel="nofollow noopener noreferrer">GetWords</a> se utiliza el método.

Para agregar palabras al diccionario del corrector ortográfico, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.

El <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/spellingcorrector/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> El método se utiliza para eliminar todas las palabras del diccionario del corrector ortográfico.

Para exportar palabras a un archivo, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a> método.

Para importar palabras desde un archivo, utilice <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a> método.

El siguiente ejemplo demuestra el uso de los métodos del corrector ortográfico.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
 
// Creating an index from in specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.SpellingCorrector.Count > 0)
{
    // Removing all words from the dictionary
    index.Dictionaries.SpellingCorrector.Clear();
}
 
// Adding words to the dictionary
string[] words = new string[] { "achieve", "accomplish", "attain", "reach" };
index.Dictionaries.SpellingCorrector.AddRange(words);
 
// Export words to a file
index.Dictionaries.SpellingCorrector.ExportDictionary(@"C:\Words.txt");
 
// Import words from a file
index.Dictionaries.SpellingCorrector.ImportDictionary(@"C:\Words.txt");
```

Una instancia de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary" target="_blank" rel="nofollow noopener noreferrer">CharacterReplacementDictionary</a> contiene todas las sustituciones de caracteres definidas en un índice. Para obtener información detallada sobre la sustitución de caracteres, consulte la página [Sustitución de caracteres durante la indexación](/net/search/developer-guide/advanced-usage/indexing/character-replacement-during-indexing/).

La propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> permite obtener el número de sustituciones de caracteres definidas en el diccionario.

Para agregar sustituciones de caracteres al diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a>.

Para eliminar sustituciones de caracteres del diccionario, se utiliza el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/removerange/index" target="_blank" rel="nofollow noopener noreferrer">RemoveRange</a>.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/contains" target="_blank" rel="nofollow noopener noreferrer">Contains</a> se utiliza para determinar si el diccionario contiene una sustitución para el carácter especificado.

Para obtener la sustitución correspondiente a un carácter especificado, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/getreplacement" target="_blank" rel="nofollow noopener noreferrer">GetReplacement</a>.

Para eliminar todas las sustituciones del diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/characterreplacementdictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a>.

Para exportar todas las sustituciones a un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a>.

Para importar sustituciones de caracteres desde un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a>.

El siguiente ejemplo demuestra el uso de los métodos del diccionario de sustitución de caracteres.

**C#**

```csharp
 string indexFolder = @"c:\MyIndex\";
 
// Creating an index from in specified folder
Index index = new Index(indexFolder);
 
if (index.Dictionaries.CharacterReplacements.Count > 0)
{
    // Deleting all character replacements from the dictionary
    index.Dictionaries.CharacterReplacements.Clear();
}
 
if (index.Dictionaries.CharacterReplacements.Contains('-'))
{
    int replacement = index.Dictionaries.CharacterReplacements.GetReplacement('-');
    Console.WriteLine("The replacement for hyphen is " + char.ConvertFromUtf32(replacement));
 
    // Deleting the hyphen character replacement from the dictionary
    index.Dictionaries.CharacterReplacements.RemoveRange(new char[] { '-' });
}
 
// Export character replacements to a file
index.Dictionaries.CharacterReplacements.ExportDictionary(@"C:\CharacterReplacements.dat");
 
// Import character replacements from a file
index.Dictionaries.CharacterReplacements.ImportDictionary(@"C:\CharacterReplacements.dat");
```

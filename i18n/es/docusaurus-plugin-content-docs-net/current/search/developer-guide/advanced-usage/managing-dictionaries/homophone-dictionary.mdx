La clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary" target="_blank" rel="nofollow noopener noreferrer">HomophoneDictionary</a> está diseñada para almacenar homófonos en un índice. Para obtener información sobre la búsqueda mediante homófonos, consulte la página [Búsqueda de homófonos](/net/search/developer-guide/advanced-usage/searching/homophone-search/).

Para obtener el número de homófonos en el diccionario, utilice la propiedad <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a>.

Para agregar grupos de homófonos al diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/addrange/index" target="_blank" rel="nofollow noopener noreferrer">AddRange</a>.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/clear" target="_blank" rel="nofollow noopener noreferrer">Clear</a> se utiliza para eliminar todos los homófonos del diccionario.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/gethomophones" target="_blank" rel="nofollow noopener noreferrer">GetHomophones</a> se utiliza para obtener una lista de sinónimos para una palabra dada.

El método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/gethomophonegroups" target="_blank" rel="nofollow noopener noreferrer">GetHomophoneGroups</a> se utiliza para obtener todos los grupos de sinónimos a los que pertenece una palabra dada.

Para obtener todos los grupos de sinónimos del diccionario, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/homophonedictionary/methods/getallhomophonegroups" target="_blank" rel="nofollow noopener noreferrer">GetAllHomophoneGroups</a>.

Para exportar los homófonos a un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/exportdictionary" target="_blank" rel="nofollow noopener noreferrer">ExportDictionary</a>.

Para importar homófonos desde un archivo, utilice el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search.dictionaries/dictionarybase/methods/importdictionary" target="_blank" rel="nofollow noopener noreferrer">ImportDictionary</a>.

El siguiente ejemplo demuestra el uso de los métodos del diccionario de homófonos.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";

// Creating an index from in specified folder
Index index = new Index(indexFolder);

// Getting homophones for word 'braid'
string[] homophones = index.Dictionaries.HomophoneDictionary.GetHomophones("braid");
Console.WriteLine("Homophones for 'braid':");
for (int i = 0; i < homophones.Length; i++)
{
    Console.WriteLine(homophones[i]);
}

// Getting groups of homophones to which word 'braid' belongs to
string[][] groups = index.Dictionaries.HomophoneDictionary.GetHomophoneGroups("braid");
Console.WriteLine("Homophone groups for 'braid':");
for (int i = 0; i < groups.Length; i++)
{
    string[] group = groups[i];
    for (int j = 0; j < group.Length; j++)
    {
        Console.Write(group[j] + " ");
    }
    Console.WriteLine();
}

if (index.Dictionaries.HomophoneDictionary.Count > 0)
{
    // Removing all homophones from the dictionary
    index.Dictionaries.HomophoneDictionary.Clear();
}

// Adding homophones to the dictionary
string[][] homophoneGroups = new string[][]
{
    new string[] { "awe", "oar", "or", "ore" },
    new string[] { "aye", "eye", "i" },
};
index.Dictionaries.HomophoneDictionary.AddRange(homophoneGroups);

// Export homophones to a file
index.Dictionaries.HomophoneDictionary.ExportDictionary(@"C:\Homophones.dat");

// Import homophones from a file
index.Dictionaries.HomophoneDictionary.ImportDictionary(@"C:\Homophones.dat");
```

Configurar una red de búsqueda implica crear una configuración utilizando <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/" target="_blank" rel="nofollow noopener noreferrer">Configurator</a> clase y la interfaz fluida.

El <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/" target="_blank" rel="nofollow noopener noreferrer">Configurator</a> La clase tiene métodos para configurar la configuración general del índice, así como para configurar cada nodo de red individualmente.

El <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/setindexsettings/" target="_blank" rel="nofollow noopener noreferrer">SetIndexSettings</a> método crea una instancia de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/" target="_blank" rel="nofollow noopener noreferrer">IndexSettingsConfigurator</a> clase, que le permite configurar los siguientes ajustes para cada índice de la red de búsqueda distribuida:
 - Bandera para usar palabras vacías al indexar (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setusestopwords/" target="_blank" rel="nofollow noopener noreferrer">SetUseStopWords</a> método).
 - Indicador para usar sustituciones de caracteres durante la indexación (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setusecharacterreplacements/" target="_blank" rel="nofollow noopener noreferrer">SetUseCharacterReplacements</a> método).
 - Bandera para usar el almacenamiento de texto extraído, así como el grado de compresión del texto en el almacenamiento (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/settextstoragesettings/" target="_blank" rel="nofollow noopener noreferrer">SetTextStorageSettings</a> método).
 - Tipo de índice (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setindextype/" target="_blank" rel="nofollow noopener noreferrer">SetIndexType</a> método).
 - Número de subprocesos utilizados para la búsqueda (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/setsearchthreads/" target="_blank" rel="nofollow noopener noreferrer">SetSearchThreads</a> método).

Para completar la configuración de los ajustes del índice, debe llamar a <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/indexsettingsconfigurator/completeindexsettings/" target="_blank" rel="nofollow noopener noreferrer">CompleteIndexSettings</a> método.

Para configurar nodos individuales de red de búsqueda, utilice <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/addnode/" target="_blank" rel="nofollow noopener noreferrer">AddNode</a> método, que devuelve una instancia de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/" target="_blank" rel="nofollow noopener noreferrer">NodeConfigurator</a> clase.

El <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/" target="_blank" rel="nofollow noopener noreferrer">NodeConfigurator</a> La clase le permite configurar los siguientes parámetros de nodo:
 - Establezca la dirección IP y el número de puerto requeridos del nodo de red de búsqueda (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/settcpendpoint/" target="_blank" rel="nofollow noopener noreferrer">SetTcpEndpoint</a> método).
 - Declara el nodo como receptor de mensajes de registro para todos los demás nodos de la red (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addlogsink/" target="_blank" rel="nofollow noopener noreferrer">AddLogSink</a> método).
 - Añada un servicio de indexación, que es la entrada para todas las operaciones que modifican el contenido de las shards en los nodos de red (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addindexer/" target="_blank" rel="nofollow noopener noreferrer">AddIndexer</a> método). Este servicio debe presentarse en la red exactamente una vez.
 - Agregue un servicio de búsqueda, que es la entrada para todas las consultas de búsqueda a la red (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addsearcher/" target="_blank" rel="nofollow noopener noreferrer">AddSearcher</a> método).
 - Añadir un servicio de extracción utilizado para extraer datos de documentos agregados a la red de búsqueda (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addextractor/" target="_blank" rel="nofollow noopener noreferrer">AddExtractor</a> (método). Aumentar el número de servicios de extracción (uno por nodo de red) mejora el rendimiento de la indexación de la red de búsqueda.
 - Agregue un servicio de fragmentación utilizado para almacenar datos extraídos en un formato adecuado para su búsqueda en la red (<a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/addshard/" target="_blank" rel="nofollow noopener noreferrer">AddShard</a> (método). Aumentar el número de fragmentos (uno por cada nodo de red) mejora el rendimiento de la búsqueda en la red.

Para completar la configuración de un nodo de red, debe llamar a <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/nodeconfigurator/completenode/" target="_blank" rel="nofollow noopener noreferrer">CompleteNode</a> método.

Una vez que se complete la configuración de la red de búsqueda, debe llamar a <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configurator/completeconfiguration/" target="_blank" rel="nofollow noopener noreferrer">CompleteConfiguration</a> método, que devolverá una instancia de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configuration/" target="_blank" rel="nofollow noopener noreferrer">Configuration</a> clase.

Una instancia de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.configuring/configuration/" target="_blank" rel="nofollow noopener noreferrer">Configuration</a> La clase se puede guardar en un archivo o flujo en formato XML mediante el método `Save`, y posteriormente se puede cargar desde el archivo o flujo mediante el método `Load`.

El siguiente ejemplo de código muestra cómo crear una configuración de red de búsqueda que describe cuatro nodos.

**C#**

```csharp
string address = "127.0.0.1";
Configuration configuration = new Configurator()
    .SetIndexSettings()
        .SetUseStopWords(false)
        .SetUseCharacterReplacements(false)
        .SetTextStorageSettings(true, Compression.High)
        .SetIndexType(IndexType.NormalIndex)
        .SetSearchThreads(NumberOfThreads.Default)
        .CompleteIndexSettings()
    .AddMasterNode(0)
        .AddIndexer(basePath + "Indexer0")
        .AddSearcher(basePath + "Searcher0")
        .CompleteNode()
    .AddSlaveNode(1)
        .SetTcpEndpoint(address, basePort + 1)
        .AddShard(basePath + "Shard1")
        .AddExtractor(basePath + "Extractor1")
        .CompleteNode()
    .AddSlaveNode(2)
        .SetTcpEndpoint(address, basePort + 2)
        .AddShard(basePath + "Shard2")
        .AddExtractor(basePath + "Extractor2")
        .CompleteNode()
    .AddSlaveNode(3)
        .SetTcpEndpoint(address, basePort + 3)
        .AddShard(basePath + "Shard3")
        .AddExtractor(basePath + "Extractor3")
        .CompleteNode()
    .CompleteConfiguration();
```

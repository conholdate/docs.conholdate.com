La red de búsqueda de GroupDocs.Search está compuesta por un nodo maestro y varios nodos esclavos. Cada nodo es un servidor físico con la plataforma .NET implementada en él. Dentro de la plataforma .NET, se implementa una aplicación que crea una instancia de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a>.

Una instancia de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a> proporciona los servicios descritos en la configuración:
 - Servicio de indexación;
 - Servicios de búsqueda;
 - Servicios de extracción;
 - Servicios de fragmentación (shard).

Los servicios de indexación y búsqueda también proporcionan una interfaz para acceder a todas las funcionalidades de la red de búsqueda.

Para implementar la red de búsqueda de GroupDocs.Search, debe realizar los siguientes pasos:
 - En cada servidor esclavo, cree una instancia de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a> y llame al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/start/" target="_blank" rel="nofollow noopener noreferrer">Start</a>.
 - En el servidor maestro, cree una instancia de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a>, pasando el objeto de configuración al constructor.
 - Llame al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/configureallnodes/" target="_blank" rel="nofollow noopener noreferrer">ConfigureAllNodes</a> del objeto <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a> en el servidor maestro.
 - Llame al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/start/" target="_blank" rel="nofollow noopener noreferrer">Start</a> del objeto <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a> en el servidor maestro.

El siguiente ejemplo de código demuestra cómo iniciar un nodo esclavo en el servidor.

**C#**

```csharp
SearchNetworkNode node1 = SearchNetworkNode.CreateSlaveNode(
    1,
    basePath + "Node1",
    new TcpSettings(basePort + 1, sendTimeout, receiveTimeout, connectTimeout, retryTimeout));
node1.Start();
```

El siguiente ejemplo de código demuestra cómo iniciar un nodo maestro en el servidor.

**C#**

```csharp
SearchNetworkNode node0 = SearchNetworkNode.CreateMasterNode(
    0,
    basePath + "Node0",
    new TcpSettings(basePort, sendTimeout, receiveTimeout, connectTimeout, retryTimeout),
    new ConsoleLogger(),
    configuration);

node0.Events.ConfigurationCompleted += (s, e) =>
{
    Console.WriteLine("Configuration complete");
};

Console.WriteLine();
Console.WriteLine("Configuring the search network");
node0.ConfigureAllNodes();

Console.WriteLine("Launching the search network");
node0.Start();
```

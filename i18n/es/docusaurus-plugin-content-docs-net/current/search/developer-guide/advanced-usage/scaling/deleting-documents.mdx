Los documentos pueden eliminarse de la red de búsqueda utilizando el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/delete/" target="_blank" rel="nofollow noopener noreferrer">Delete</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>.

Para eliminar documentos, debe pasar un array de claves de documentos, así como un objeto de opciones de eliminación, al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/delete/" target="_blank" rel="nofollow noopener noreferrer">Delete</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>.

Disponible una opción para la eliminación asíncrona. En caso de eliminación asíncrona, puede rastrear la finalización de la operación suscribiéndose al evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/deletioncompleted/" target="_blank" rel="nofollow noopener noreferrer">DeletionCompleted</a>.

El siguiente ejemplo de código demuestra cómo eliminar documentos de la red de búsqueda.

**C#**

```csharp
Console.WriteLine();
Console.WriteLine("Deleting documents");

string[] fileNames = new string[filePaths.Length];
for (int i = 0; i < filePaths.Length; i++)
{
    string filePath = filePaths[i];
    string fileName = Path.GetFileName(filePath);
    fileNames[i] = fileName;
}

Indexer indexer = node.Indexer;

DeleteOptions options = new DeleteOptions();
indexer.Delete(fileNames, options);
```

Esta página contiene información sobre el propósito y el uso de todos los eventos de la red de búsqueda.

## Evento ConfigurationCompleted {#configurationcompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/configurationcompleted/" target="_blank" rel="nofollow noopener noreferrer">ConfigurationCompleted</a> se produce cuando finaliza el proceso de configuración de la red de búsqueda.

## Evento IndexingCompleted {#indexingcompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/indexingcompleted/" target="_blank" rel="nofollow noopener noreferrer">IndexingCompleted</a> se produce cuando finaliza la indexación de todos los documentos encolados.

## Evento DeletionCompleted {#deletioncompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/deletioncompleted/" target="_blank" rel="nofollow noopener noreferrer">DeletionCompleted</a> se produce cuando finalizan todas las eliminaciones de documentos encoladas.

## Evento OptimizationCompleted {#optimizationcompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/optimizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">OptimizationCompleted</a> se produce cuando finaliza la optimización de todos los nodos.

## Evento SynchronizationCompleted {#synchronizationcompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/synchronizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">SynchronizationCompleted</a> se produce cuando finaliza la sincronización con todos los nodos.

## Evento AttributeChangesCompleted {#attributechangescompleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/attributechangescompleted/" target="_blank" rel="nofollow noopener noreferrer">AttributeChangesCompleted</a> se produce cuando finalizan todos los cambios de atributos encolados.

## Evento StatusChanged {#statuschanged-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/statuschanged/" target="_blank" rel="nofollow noopener noreferrer">StatusChanged</a> se produce cuando cambia el estado de la red de búsqueda.

## Evento DataExtracted {#dataextracted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/dataextracted/" target="_blank" rel="nofollow noopener noreferrer">DataExtracted</a> se produce cuando se extraen los datos de un documento.

## Evento DocumentIndexed {#documentindexed-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/documentindexed/" target="_blank" rel="nofollow noopener noreferrer">DocumentIndexed</a> se produce cuando se indexa un documento.

## Evento DocumentDeleted {#documentdeleted-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/documentdeleted/" target="_blank" rel="nofollow noopener noreferrer">DocumentDeleted</a> se produce cuando se elimina un documento.

## Evento ErrorOccurred {#erroroccurred-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/erroroccurred/" target="_blank" rel="nofollow noopener noreferrer">ErrorOccurred</a> se produce cuando ocurre un error en alguno de los nodos de la red de búsqueda.

## Evento IndexingProgressChanged {#indexingprogresschanged-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/indexingprogresschanged/" target="_blank" rel="nofollow noopener noreferrer">IndexingProgressChanged</a> se produce cuando cambia el progreso de la operación de indexación.

## Evento OptimizationProgressChanged {#optimizationprogresschanged-event}

El evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/optimizationprogresschanged/" target="_blank" rel="nofollow noopener noreferrer">OptimizationProgressChanged</a> se produce cuando cambia el progreso de la operación de optimización.

## Ejemplo de código {#code-example}

**C#**

```csharp
node.Events.IndexingCompleted += (s, e) =>
{
    Console.WriteLine("Indexing complete");
};
node.Events.DeletionCompleted += (s, e) =>
{
    Console.WriteLine("Deleting complete");
};
node.Events.OptimizationCompleted += (s, e) =>
{
    Console.WriteLine("Optimization complete");
};
node.Events.SynchronizationCompleted += (s, e) =>
{
    Console.WriteLine("Synchronization complete");
};
node.Events.AttributeChangesCompleted += (s, e) =>
{
    Console.WriteLine("Attribute changes complete");
};
node.Events.StatusChanged += (s, e) =>
{
    Console.WriteLine("Status changed: " + e.OldStatus + " -> " + e.NewStatus);
};
node.Events.DataExtracted += (s, e) =>
{
    Console.WriteLine("Data extracted (" + e.ExtractorIndex + "): " + e.DocumentKey);
};
node.Events.DocumentIndexed += (s, e) =>
{
    Console.WriteLine("Document indexed (" + e.ShardIndex + "): " + e.DocumentKey);
};
node.Events.DocumentDeleted += (s, e) =>
{
    Console.WriteLine("Document deleted (" + e.ShardIndex + "): " + e.DocumentKey);
};
node.Events.ErrorOccurred += (s, e) =>
{
    Console.WriteLine("Error occurred (" + e.NodeIndex + ", " + e.ServiceIndex + "): " + e.Message);
};
node.Events.IndexingProgressChanged += (s, e) =>
{
    Console.WriteLine("Indexing progress changed (" + e.NodeIndex + ", " + e.ServiceIndex + "): " + e.ProgressPercentage);
};
node.Events.OptimizationProgressChanged += (s, e) =>
{
    Console.WriteLine("Optimization progress changed (" + e.NodeIndex + ", " + e.ServiceIndex + "): " + e.ProgressPercentage);
};
```

Si se produce alguna interrupción de comunicación en la red de búsqueda, algunas operaciones podrían no completarse correctamente. Para resolver este tipo de problemas, debe invocar el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/synchronize/" target="_blank" rel="nofollow noopener noreferrer">Synchronize</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>.

La marca de operación asincrónica está disponible como opción. Puede rastrear la finalización de la operación suscribiéndose al evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/synchronizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">SynchronizationCompleted</a>.

El siguiente ejemplo de código muestra cómo sincronizar los nodos de la red de búsqueda.

**C#**

```csharp
Console.WriteLine("Synchronizing shards");
Indexer indexer = node.Indexer;
SynchronizeOptions options = new SynchronizeOptions();
indexer.Synchronize(options);
```

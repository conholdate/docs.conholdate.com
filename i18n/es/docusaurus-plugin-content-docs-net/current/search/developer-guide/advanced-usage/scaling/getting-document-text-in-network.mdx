Para obtener el texto extraído de los documentos indexados en la red de búsqueda, el <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> método de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a> se utiliza la clase.

El primer parámetro de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> método es un documento representado por el <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.results/networkdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">NetworkDocumentInfo</a> clase. Una lista de todos los documentos indexados en la red de búsqueda se puede obtener mediante el <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getindexeddocuments/" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocuments</a> método de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a> clase.

El segundo parámetro de la <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getdocumenttext/" target="_blank" rel="nofollow noopener noreferrer">GetDocumentText</a> `method` es el adaptador de salida del resultado. En esta operación, se utilizan las mismas clases de adaptadores de salida que en operaciones similares de un único índice. Para obtener información sobre los adaptadores de salida, consulte el artículo <a href="https://docs.groupdocs.com/search/net/output-adapters/" target="_blank" rel="nofollow noopener noreferrer">Adaptadores de salida</a>.

El siguiente ejemplo de código demuestra cómo recuperar el texto de los documentos indexados en la red de búsqueda, así como cómo mostrar los datos resultantes en la consola.

**C#**

```csharp
Searcher searcher = node.Searcher;

List<NetworkDocumentInfo> documents = new List<NetworkDocumentInfo>();
int[] shardIndices = node.GetShardIndices();
for (int i = 0; i < shardIndices.Length; i++)
{
    int shardIndex = shardIndices[i];
    NetworkDocumentInfo[] infos = searcher.GetIndexedDocuments(shardIndex);
    documents.AddRange(infos);
    for (int j = 0; j < infos.Length; j++)
    {
        NetworkDocumentInfo info = infos[j];
        NetworkDocumentInfo[] items = searcher.GetIndexedDocumentItems(info);
        documents.AddRange(items);
    }
}

for (int i = 0; i < documents.Count; i++)
{
    NetworkDocumentInfo document = documents[i];
    if (document.DocumentInfo.ToString().Contains(containsInPath))
    {
        Console.WriteLine();
        Console.WriteLine(document.DocumentInfo.ToString());

        StringOutputAdapter outputAdapter = new StringOutputAdapter(OutputFormat.PlainText);
        searcher.GetDocumentText(document, outputAdapter);

        Console.WriteLine(outputAdapter.GetResult());
        break;
    }
}
```

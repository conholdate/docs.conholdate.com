Para obtener una lista de documentos indexados en una partición específica de la red de búsqueda, debe invocar el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getindexeddocuments/" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocuments</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a>.

Para obtener una lista de particiones de la red de búsqueda, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/getshardindices/" target="_blank" rel="nofollow noopener noreferrer">GetShardIndices</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searchnetworknode/" target="_blank" rel="nofollow noopener noreferrer">SearchNetworkNode</a>.

También es posible obtener una lista de elementos anidados de un documento contenedor indexado. Para ello, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/getindexeddocumentitems/" target="_blank" rel="nofollow noopener noreferrer">GetIndexedDocumentItems</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a>.

El siguiente ejemplo de código demuestra cómo obtener una lista de documentos indexados en la red de búsqueda, así como cómo mostrar los datos resultantes en la consola.

**C#**

```csharp
Searcher searcher = node.Searcher;
Indexer indexer = node.Indexer;

int[] shardIndices = node.GetShardIndices();
Console.WriteLine();
for (int i = 0; i < shardIndices.Length; i++)
{
    int shardIndex = shardIndices[i];
    NetworkDocumentInfo[] infos = searcher.GetIndexedDocuments(shardIndex);
    for (int j = 0; j < infos.Length; j++)
    {
        NetworkDocumentInfo info = infos[j];
        int nodeIndex = node.GetNodeIndex(info.ShardIndex);
        Console.WriteLine(nodeIndex + ": " + info.ShardIndex + ": " + info.DocumentInfo.FilePath);
        string[] attributes = indexer.GetAttributes(info.DocumentInfo.FilePath);
        for (int k = 0; k < attributes.Length; k++)
        {
            Console.WriteLine("\t\t" + attributes[k]);
        }

        NetworkDocumentInfo[] items = searcher.GetIndexedDocumentItems(info);
        for (int k = 0; k < items.Length; k++)
        {
            NetworkDocumentInfo item = items[k];
            Console.WriteLine("\t" + nodeIndex + ": " + item.ShardIndex + ": " + item.DocumentInfo.ToString());
        }
    }
}
```

Los atributos de los documentos se modifican sin necesidad de volver a indexar los documentos en la red de búsqueda.

Para cambiar los atributos de los documentos, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/changeattributes/" target="_blank" rel="nofollow noopener noreferrer">ChangeAttributes</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>.

La bandera de operación asíncrona está disponible como opción. Puede rastrear la finalización de la operación suscribiéndose al evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/attributechangescompleted/" target="_blank" rel="nofollow noopener noreferrer">AttributeChangesCompleted</a>.

El siguiente ejemplo de código muestra cómo modificar los atributos de los documentos en la red de búsqueda.

**C#**

```csharp
Console.WriteLine("Adding attribute: " + attribute);

Indexer indexer = node.Indexer;

AttributeChangeBatch batch = new AttributeChangeBatch();
batch.Add(documentKey, attribute);
ChangeAttributesOptions options = new ChangeAttributesOptions();
indexer.ChangeAttributes(batch, options);
```

Para obtener todos los atributos de un documento, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/getattributes/" target="_blank" rel="nofollow noopener noreferrer">GetAttributes</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>. Debe pasar la clave del documento como parámetro.

El siguiente ejemplo de código muestra cómo recuperar los atributos del documento desde la red de búsqueda.

**C#**

```csharp
Searcher searcher = node.Searcher;
Indexer indexer = node.Indexer;

int[] shardIndices = node.GetShardIndices();
Console.WriteLine();
for (int i = 0; i < shardIndices.Length; i++)
{
    int shardIndex = shardIndices[i];
    NetworkDocumentInfo[] infos = searcher.GetIndexedDocuments(shardIndex);
    for (int j = 0; j < infos.Length; j++)
    {
        NetworkDocumentInfo info = infos[j];
        int nodeIndex = node.GetNodeIndex(info.ShardIndex);
        Console.WriteLine(nodeIndex + ": " + info.ShardIndex + ": " +
            HasErrors(info) + ": " + info.DocumentInfo.FilePath);
        string[] attributes = indexer.GetAttributes(info.DocumentInfo.FilePath);
        for (int k = 0; k < attributes.Length; k++)
        {
            Console.WriteLine("\t\t" + attributes[k]);
        }
    }
}
```

Más información sobre cómo trabajar con los atributos de texto de los documentos en el artículo <a href="/es/net/search/developer-guide/advanced-usage/indexing/document-attributes/">Atributos de documentos</a>.

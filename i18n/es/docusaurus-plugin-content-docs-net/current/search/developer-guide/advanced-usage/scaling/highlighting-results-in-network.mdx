Los resultados de búsqueda en la red de búsqueda pueden resaltarse en el texto del documento encontrado mediante el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/highlight/" target="_blank" rel="nofollow noopener noreferrer">Highlight</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a>.

El conjunto de clases disponibles para resaltar texto, así como las opciones de resaltado, son idénticos a los utilizados para resaltar resultados de búsqueda en un único índice. Consulte también la página <a href="/es/net/search/developer-guide/advanced-usage/searching/highlighting-search-results/">Resaltado de resultados de búsqueda</a>.

El siguiente ejemplo de código demuestra cómo resaltar resultados de búsqueda en la red de búsqueda.

**C#**

```csharp
Searcher searcher = node.Searcher;

FragmentHighlighter highlighter = new FragmentHighlighter(OutputFormat.PlainText);

HighlightOptions options = new HighlightOptions();
options.TermsAfter = 5;
options.TermsBefore = 5;
options.TermsTotal = 15;
searcher.Highlight(document, highlighter, options);

FragmentContainer[] result = highlighter.GetResult();
Console.WriteLine();
for (int i = 0; i < result.Length; i++)
{
    FragmentContainer container = result[i];
    if (container.Count == 0) continue;

    string[] fragments = container.GetFragments();
    Console.WriteLine(container.FieldName);
    int count = Math.Min(fragments.Length, maxFragments);
    for (int j = 0; j < count; j++)
    {
        Console.WriteLine("\t" + fragments[j]);
    }
}
```

Para realizar una búsqueda inversa de imágenes, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchfirst/#searchfirst" target="_blank" rel="nofollow noopener noreferrer">SearchFirst</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a>. Este método devuelve la primera parte de los resultados.

Para continuar la búsqueda, se utiliza el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchnext/#searchnext" target="_blank" rel="nofollow noopener noreferrer">SearchNext</a>, que devuelve la segunda y las partes subsiguientes de los resultados.

El objeto de imagen de búsqueda y el objeto de opciones de búsqueda son los mismos que se utilizan para búsquedas en un solo índice.

El siguiente ejemplo de código demuestra cómo realizar una búsqueda inversa de imágenes en la red de búsqueda.

**C#**

```csharp
Console.WriteLine("First image search");

Searcher searcher = node.Searcher;
ImageSearchOptions options = new ImageSearchOptions();
options.HashDifferences = hashDifferences;
int total = 0;

NetworkImageSearchResult result = searcher.SearchFirst(searchImage, options);
Console.WriteLine("Images found (shard " + result.ShardIndex + "): " + result.ImageCount);
total += result.ImageCount;

while (result.NetworkImageSearchToken != null)
{
    Console.WriteLine();
    Console.WriteLine("Next image search");

    result = searcher.SearchNext(result.NetworkImageSearchToken);
    Console.WriteLine("Images found (shard " + result.ShardIndex + "): " + result.ImageCount);
    total += result.ImageCount;
}

Console.WriteLine();
Console.WriteLine("Total images found (diffs = " + hashDifferences + "): " + total);
```

Más información sobre la búsqueda inversa de imágenes en el <a href="https://docs.groupdocs.com/search/net/reverse-image-search/" target="_blank" rel="nofollow noopener noreferrer">artículo</a>.

Para realizar una búsqueda de texto, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchfirst/#searchfirst_1" target="_blank" rel="nofollow noopener noreferrer">SearchFirst</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/" target="_blank" rel="nofollow noopener noreferrer">Searcher</a>. Este método devuelve la primera parte de los resultados.

Para continuar la búsqueda, se utiliza el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/searcher/searchnext/" target="_blank" rel="nofollow noopener noreferrer">SearchNext</a>, que devuelve la segunda y las partes subsiguientes de los resultados.

Se admiten tanto la forma de texto como la de objeto de la consulta de búsqueda, según las sobrecargas adecuadas del método `SearchFirst` que se utilicen. Las opciones para una búsqueda en red son las mismas que para una búsqueda en un único índice.

El siguiente ejemplo de código muestra cómo realizar una búsqueda de texto completo en la red de búsqueda.

**C#**

```csharp
Searcher searcher = node.Searcher;

SearchQuery query = SearchQuery.CreateWordQuery(word);
Console.WriteLine();
Console.WriteLine("First time search for: " + query);
SearchOptions options = new SearchOptions();
options.IsChunkSearch = true;
options.UseSynonymSearch = useSynonymSearch;
int totalOccurrences = 0;
List<NetworkFoundDocument> documents = new List<NetworkFoundDocument>();

NetworkSearchResult result = searcher.SearchFirst(query, options);

AddDocsFromResult(documents, result);
totalOccurrences += result.OccurrenceCount;
TraceResult(result);

while (result.NextChunkSearchToken != null)
{
    Console.WriteLine();
    Console.WriteLine("Next time search for: " + query);

    result = searcher.SearchNext(result.NextChunkSearchToken);

    AddDocsFromResult(documents, result);
    totalOccurrences += result.OccurrenceCount;
    TraceResult(result);
}

Console.WriteLine();
Console.WriteLine("Total occurrences: " + totalOccurrences);
```

Puede encontrar más información sobre las consultas de búsqueda en el artículo <a href="https://docs.groupdocs.com/search/net/queries-in-text-and-object-form/" target="_blank" rel="nofollow noopener noreferrer">Consultas en forma de texto y objeto</a>.

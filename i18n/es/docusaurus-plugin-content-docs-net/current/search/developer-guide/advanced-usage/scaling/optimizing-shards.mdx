Todos los fragmentos de red de búsqueda pueden optimizarse con una única llamada al método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/optimize/" target="_blank" rel="nofollow noopener noreferrer">Optimize</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>.

La optimización reduce al mínimo el número de segmentos de índice en cada fragmento. Como resultado, el rendimiento de las búsquedas mejora.

Como opción, está disponible una bandera para la ejecución asíncrona. En caso de optimización asíncrona, puede rastrear la finalización de la operación suscribiéndose al evento <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling.events/nodeeventhub/optimizationcompleted/" target="_blank" rel="nofollow noopener noreferrer">OptimizationCompleted</a>.

El siguiente ejemplo de código muestra cómo realizar la optimización de la red de búsqueda.

**C#**

```csharp
Console.WriteLine("Optimizing shards");
Indexer indexer = node.Indexer;
OptimizeOptions options = new OptimizeOptions();
indexer.Optimize(options);
```

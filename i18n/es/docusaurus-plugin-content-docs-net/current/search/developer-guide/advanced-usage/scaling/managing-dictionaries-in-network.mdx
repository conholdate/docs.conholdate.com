Para obtener un diccionario a partir de una partición (shard) de un nodo de red de búsqueda, utilice el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/getdictionary/" target="_blank" rel="nofollow noopener noreferrer">GetDictionary</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>. El primer parámetro del método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/getdictionary/" target="_blank" rel="nofollow noopener noreferrer">GetDictionary</a> es el tipo del diccionario requerido, y el segundo parámetro es el índice de la partición en la red. El método devuelve un objeto del tipo <a href="https://reference.groupdocs.com/search/net/groupdocs.search.dictionaries/dictionarybase/" target="_blank" rel="nofollow noopener noreferrer">DictionaryBase</a>, el cual debe ser convertido (cast) al tipo de diccionario deseado. En la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a> también existen métodos que devuelven directamente el tipo de diccionario deseado, sin necesidad de realizar conversiones ni especificar el tipo en los parámetros.

Posteriormente, puede realizar todas las operaciones válidas sobre el objeto diccionario en un índice único. Para obtener información sobre cómo trabajar con diccionarios, consulte los artículos <a href="https://docs.groupdocs.com/search/net/managing-dictionaries/" target="_blank" rel="nofollow noopener noreferrer">Gestión de diccionarios</a>.

Una vez configurado el diccionario, debe devolver el objeto diccionario a la partición correspondiente mediante el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/setdictionary/" target="_blank" rel="nofollow noopener noreferrer">SetDictionary</a> de la clase <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/" target="_blank" rel="nofollow noopener noreferrer">Indexer</a>, especificando el índice de la partición deseada. Alternativamente, puede establecer el objeto diccionario en todas las particiones mediante el método <a href="https://reference.groupdocs.com/search/net/groupdocs.search.scaling/indexer/setdictionary/" target="_blank" rel="nofollow noopener noreferrer">SetDictionary</a>, con un único parámetro y sin especificar el índice de la partición.

El siguiente ejemplo de código demuestra el uso de diccionarios en la red de búsqueda.

**C#**

```csharp
Console.WriteLine("Adding synonyms");

Indexer indexer = node.Indexer;

int[] indices = node.GetShardIndices();
SynonymDictionary dictionary = indexer.GetSynonymDictionary(indices[0]);

if (clearBeforeAdding)
{
    dictionary.Clear();
}
dictionary.AddRange(new string[][] { group });

indexer.SetDictionary(dictionary);
```

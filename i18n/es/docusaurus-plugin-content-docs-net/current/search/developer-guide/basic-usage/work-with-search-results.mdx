Trabajar con los resultados de búsqueda consiste en obtener información de los objetos de resultados de búsqueda y resaltar las ocurrencias en el texto de los documentos.

## Obtener información sobre los resultados de búsqueda {#obtain-search-result-information}

Cuando finaliza una búsqueda, el método <a href="https://reference.groupdocs.com/net/search/groupdocs.search/index/methods/search/index" target="_blank" rel="nofollow noopener noreferrer">Search</a> devuelve un objeto de tipo <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>. Esta página describe la información disponible en un objeto de tipo <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>.

A partir del objeto raíz del resultado de búsqueda, se dispone de información sobre el número de documentos encontrados, el número de ocurrencias de las palabras y frases halladas, así como información detallada sobre cada documento individual. La información sobre un documento encontrado individualmente está representada por un objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a>.

A partir del objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocument" target="_blank" rel="nofollow noopener noreferrer">FoundDocument</a>, se dispone de información sobre la ruta completa del documento, el número de ocurrencias, las palabras y frases encontradas, así como información detallada sobre cada campo del documento. La información sobre el campo del documento está representada por un objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a>.

A partir del objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/founddocumentfield" target="_blank" rel="nofollow noopener noreferrer">FoundDocumentField</a>, se dispone de información sobre el nombre del campo del documento, el número de ocurrencias, las palabras y frases encontradas, y el número de ocurrencias de cada palabra y frase.

A continuación se muestra un ejemplo de código que escribe en la consola la información detallada contenida en un objeto de la clase <a href="https://reference.groupdocs.com/net/search/groupdocs.search.results/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> sobre cada documento, campo de documento, palabra, frase y el número de sus ocurrencias en los campos del documento.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Creating search options
SearchOptions options = new SearchOptions();
options.FuzzySearch.Enabled = true; // Enabling the fuzzy search
options.FuzzySearch.FuzzyAlgorithm = new TableDiscreteFunction(3); // Setting the maximum number of differences to 3
 
// Search for documents containing the word 'Einstein' or the phrase 'Theory of Relativity'
SearchResult result = index.Search("Einstein OR \"Theory of Relativity\"", options);
 
// Printing the result
Console.WriteLine("Documents: " + result.DocumentCount);
Console.WriteLine("Total occurrences: " + result.OccurrenceCount);
for (int i = 0; i < result.DocumentCount; i++)
{
    FoundDocument document = result.GetFoundDocument(i);
    Console.WriteLine("\tDocument: " + document.DocumentInfo.FilePath);
    Console.WriteLine("\tOccurrences: " + document.OccurrenceCount);
    for (int j = 0; j < document.FoundFields.Length; j++)
    {
        FoundDocumentField field = document.FoundFields[j];
        Console.WriteLine("\t\tField: " + field.FieldName);
        Console.WriteLine("\t\tOccurrences: " + document.OccurrenceCount);
        // Printing found terms
        if (field.Terms != null)
        {
            for (int k = 0; k < field.Terms.Length; k++)
            {
                Console.WriteLine("\t\t\t" + field.Terms[k].PadRight(20) + field.TermsOccurrences[k]);
            }
        }
        // Printing found phrases
        if (field.TermSequences != null)
        {
            for (int k = 0; k < field.TermSequences.Length; k++)
            {
                string sequence = string.Join(" ", field.TermSequences[k]);
                Console.WriteLine("\t\t\t" + sequence.PadRight(30) + field.TermSequencesOccurrences[k]);
            }
        }
    }
}
```

## Resaltar resultados de búsqueda {#highlight-search-results}

Al finalizar una búsqueda, generalmente es necesario visualizar los resultados resaltando las palabras encontradas en el texto. Puede resaltar los resultados de búsqueda ya sea en el texto de un documento completo o en segmentos individuales. Para obtener información detallada sobre el resaltado de resultados de búsqueda, consulte la página [Resaltado de resultados de búsqueda](/net/search/developer-guide/advanced-usage/searching/highlighting-search-results/). A continuación se muestra un ejemplo de resaltado de resultados de búsqueda en el texto de un documento completo.

**C#**

```csharp
string indexFolder = @"c:\MyIndex\";
string documentFolder = @"c:\MyDocuments\";
 
// Creating an index
Index index = new Index(indexFolder);
 
// Indexing documents from the specified folder
index.Add(documentFolder);
 
// Search for the word 'eternity'
SearchResult result = index.Search("eternity");
 
// Highlighting occurrences in text
if (result.DocumentCount > 0)
{
    FoundDocument document = result.GetFoundDocument(0); // Getting the first found document
    OutputAdapter outputAdapter = new FileOutputAdapter(@"c:\Highlighted.html"); // Creating an output adapter to the file
    Highlighter highlighter = new HtmlHighlighter(outputAdapter); // Creating the highlighter object
    index.Highlight(document, highlighter); // Generating HTML formatted text with highlighted occurrences
}
```

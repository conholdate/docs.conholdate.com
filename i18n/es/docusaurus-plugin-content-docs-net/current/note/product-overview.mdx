**Bienvenido a la sección de documentación de Aspose.Note para .NET**

Aspose.Note para .NET es una biblioteca de clases que permite que las aplicaciones .NET interactúen con Microsoft Office OneNote de forma programática, sin necesidad de tener el software instalado en el servidor. La API de Aspose.Note permite a los desarrolladores leer, convertir, crear, editar y manipular el contenido del formato de archivo de Microsoft OneNote.

Con Aspose.Note para .NET, es posible programar con archivos de Microsoft OneNote sin utilizar la automatización de Microsoft Office. La API es fácil de usar y ahorra tiempo y dinero en comparación con el desarrollo de soluciones similares desde cero.
:::

## Beneficios {#benefits}
  
Utilizar Aspose.Note para .NET en sus aplicaciones le brinda los siguientes beneficios:

- Funciones avanzadas  
- Independencia de plataforma  
- Rendimiento y escalabilidad  
- Versiones de Microsoft OneNote compatibles  

### Funciones avanzadas {#rich-features}
  
Aspose.Note ofrece una amplia gama de funciones para crear, leer, manipular y guardar archivos de proyecto:

- Renderizado de texto e imágenes de un archivo de OneNote a imágenes rasterizadas (PNG, JPEG, GIF, BMP, TIFF).  
- Renderizado de texto e imágenes de un archivo de OneNote al formato de documento portátil (PDF).  
- Carga de un documento de OneNote, edición y posterior guardado en formato OneNote.  
- Inserción de una imagen en el documento de OneNote.  
- Análisis y exportación de distintos formatos de listas numeradas.  
- Navegación a través del modelo de objetos de OneNote.  
- Extracción de texto: obtención de texto desde cualquier parte de un archivo de OneNote.  
- Lectura de información sobre formato de texto y diseño (tamaños y posiciones) mediante el modelo de objetos.  
- Sustitución e inserción de texto y otros elementos, y exportación a formatos de renderizado compatibles.  

### Independencia de plataforma {#platform-independence}
  
Utilice Aspose.Note para .NET para crear aplicaciones .NET de 32 o 64 bits, incluidas ASP.NET, servicios web y aplicaciones de Windows. El paquete NuGet incluye ensamblados para:

- .NET Framework 4.0  
- .NET Framework 4.0 Client Profile  
- Entornos de ejecución que implementan .NET Standard 2.0  

Utilice un entorno de desarrollo que pueda dirigirse a estos entornos de ejecución, como las versiones actuales de Microsoft Visual Studio o compilaciones mediante la línea de comandos del SDK de .NET.  

### Rendimiento y escalabilidad {#performance-and-scalability}
  
Aspose.Note para .NET está diseñado para su uso en el lado del servidor y del cliente. Implemente mediante el paquete NuGet para que la aplicación reciba el ensamblado compatible y las dependencias declaradas para el entorno de ejecución de destino.  

### Versiones de Microsoft OneNote compatibles {#supported-microsoft-onenote-versions}
  
- Microsoft OneNote 2010  
- Microsoft OneNote 2013  
- Microsoft OneNote 2016  
- Soporte para los formatos de archivo .one y .onetoc2  
- Formato de archivo de OneNote Online (SharePoint)  

## Soporte técnico {#technical-support}
  
Aspose proporciona soporte técnico gratuito ilimitado para todos sus productos. Este soporte está disponible para todos los usuarios, incluidos quienes utilicen versiones de evaluación.

Si necesita ayuda con Aspose.Note para .NET, <a href="https://forum.conholdate.com/" target="_blank">**visite los foros de Conholdate**</a>. Publique su pregunta en el foro de Aspose.Note para .NET y será respondida en cuestión de pocas horas. Las preguntas son respondidas directamente por el equipo de soporte de Aspose.Note para .NET.

Al esperar una respuesta en los foros, tenga en cuenta las diferencias de huso horario.

Si tiene un problema con Aspose.Note para .NET, siga estos sencillos pasos para asegurarse de que se resuelva de la manera más eficiente:

- Asegúrese de utilizar la versión más reciente de Aspose.Note para .NET antes de informar el problema. Consulte la <a href="https://downloads.aspose.com/note/net" target="_blank" rel="nofollow noopener noreferrer">página de descarga de Aspose.Note para .NET</a> para conocer la versión más reciente.  
- Revise el <a href="https://forum.conholdate.com/" target="_blank">foro</a>, esta [wiki de documentación](/net/note/) y la Referencia de la API en busca de soluciones antes de informar el problema. Es posible que su pregunta ya tenga una respuesta.  
- Al informar un problema, incluya el documento original y, si es posible, un fragmento del código que cause el problema. Si necesita adjuntar varios archivos, comprímalos en un solo archivo ZIP. Es seguro adjuntar sus documentos en Aspose.Forums, ya que solo usted y los desarrolladores de Aspose tendrán acceso a los archivos adjuntos.  
- Intente informar un solo problema por hilo. Si tiene otro problema, infórmelo en un hilo independiente.

Aspose no proporciona soporte técnico por teléfono. El soporte telefónico solo está disponible para consultas relacionadas con ventas y compras.

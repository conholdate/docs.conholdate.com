## Limitaciones de la versión de evaluación  {#evaluation-version-limitations}
  
Una versión gratuita de evaluación de Aspose.Note para .NET puede descargarse desde la sección de descargas del sitio web de Aspose en: <a href="https://downloads.aspose.com/" target="_blank" rel="nofollow noopener noreferrer">https://downloads.aspose.com/</a>.

### Limitación  {#limitation}
  
La versión de evaluación proporciona todas las funciones, excepto las siguientes:

| **Contexto de uso** | **Restricciones** |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Documento de MS OneNote abierto | Se coloca una marca de agua de evaluación en la parte superior de cada página. La primera página tiene dos versiones completas de la página actual (la revisión actual y una archivada). Cada página adicional tiene un título con el cuerpo reemplazado por la marca de agua de evaluación. Los elementos de texto se recortan a 140 caracteres. Cada tercer elemento de texto se reemplaza por la marca de agua. Los elementos de tabla se recortan a un tamaño de tres por tres. Los elementos de imagen que superen el límite de 500 KB se modifican escribiendo un mensaje de evaluación sobre la imagen. Se borra cada segunda imagen. |
| Documento de MS OneNote creado | Se coloca una marca de agua de evaluación en la parte superior de cada página. La primera página se guarda incluyendo el contenido del cuerpo. El cuerpo de cada página adicional se reemplaza por la marca de agua de evaluación. Los elementos de imagen que superen el límite de 500 KB se modifican escribiendo un mensaje de evaluación sobre la imagen. Se borra cada segunda imagen. |
| Cuaderno de MS OneNote abierto/creado | El número de secciones se limita a dos. El contenido del resto de las secciones se reemplaza por una página vacía con una marca de agua de evaluación en la parte superior. |
| Exportar MS OneNote a PDF | Se coloca una marca de agua de evaluación en la parte superior de cada página del archivo PDF. Se elimina el cuerpo de cada página, excepto la primera. |
| Exportar MS OneNote a archivo de imagen | Se coloca una marca de agua de evaluación en la parte superior de la imagen. |

## Aplicar licencia mediante objeto de archivo o flujo {#apply-license-using-file-or-stream-object}

La licencia puede cargarse desde un objeto de archivo o flujo. Aspose.Note for .NET intentará encontrar la licencia en las siguientes ubicaciones:

1. Ruta explícita.
2. La carpeta que contiene Aspose.Note.dll.
3. La carpeta que contiene el ensamblado que llamó a Aspose.Note.dll.
4. La carpeta que contiene el ensamblado de entrada (su .exe).
5. Un recurso incrustado en el ensamblado que llamó a Aspose.Note.dll.

La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.Note.dll y especificar el nombre del archivo, sin ruta, como se muestra en el ejemplo siguiente.

Si utiliza alguna otra API de Aspose para .NET junto con Aspose.Note for .NET, especifique el espacio de nombres para la licencia como Aspose.Note.License.

### Cargar una licencia desde un archivo {#loading-a-license-from-file}

La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.Note.dll y especificar únicamente el nombre del archivo, sin ruta.

:::info
Cuando llame al método `SetLicense`, el nombre de la licencia que pase debe ser el del archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a `'Aspose.Note.lic.xml'`, pase ese nombre de archivo al método `Note.SetLicense`.
:::

```java
// For complete examples and data files, please go to https://github.com/aspose-note/Aspose.Note-for-.NET
Aspose.Note.License license = new Aspose.Note.License();
license.SetLicense("Aspose.Note.lic");
```

### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```java
// For complete examples and data files, please go to https://github.com/aspose-note/Aspose.Note-for-.NET
Aspose.Note.License license = new Aspose.Note.License();
FileStream myStream = new FileStream("Aspose.Note.lic", FileMode.Open);
license.SetLicense(myStream);
```

## Aplicar licencia mediante un recurso incrustado {#apply-license-using-embedded-resource}
  
Una forma de aplicar una licencia es configurarla mediante un objeto de archivo o flujo. Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama al DLL del componente (incluido en Aspose.Note).

Para incluir el archivo de licencia como un recurso incrustado:

1. En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto seleccionando **Archivo**, luego **Agregar elemento existente** y finalmente **Agregar**.
2. Seleccione el archivo en el Explorador de soluciones.
3. Establezca la **Acción de compilación** en **Recurso incrustado** en la ventana Propiedades.
4. Para acceder a la licencia incrustada en el ensamblado (como un recurso incrustado), simplemente agregue el archivo de licencia como un recurso incrustado al proyecto y pase el nombre del archivo de licencia al método `SetLicense`. La clase `License` encuentra automáticamente el archivo de licencia en los recursos incrustados. No es necesario llamar a los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` en el marco de trabajo de Microsoft .NET.

El ejemplo siguiente ilustra este método para aplicar una licencia.

```java
// For complete examples and data files, please go to https://github.com/aspose-note/Aspose.Note-for-.NET
// Instantiate the License class
Aspose.Note.License license = new Aspose.Note.License();

// Pass only the name of the license file embedded in the assembly
license.SetLicense("Aspose.Note.lic");
```

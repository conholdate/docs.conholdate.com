GroupDocs.Conversion para .NET está incluido en Conholdate.Total for .NET.
:::


A veces, bajo Mono/Linux, cuando la licencia se establece desde una ruta relativa, se generan excepciones inesperadas.

Bajo Mono/Linux, utilice una de las siguientes opciones para establecer la licencia:

1. Establezca la licencia con una ruta absoluta, por ejemplo:

    ```csharp
    license.SetLicense("/home/<USERNAME>/conversion-sample-src/GroupDocs.Conversion.NET.lic");
    ```

2. Proporcione el flujo de licencia cargado desde el archivo de licencia, por ejemplo:
    
    ```csharp
    using(var licenseStream = new FileStream("GroupDocs.Conversion.NET.lic", FileMode.Open)) {

        license.SetLicense(licenseStream);
        
    }
    ```

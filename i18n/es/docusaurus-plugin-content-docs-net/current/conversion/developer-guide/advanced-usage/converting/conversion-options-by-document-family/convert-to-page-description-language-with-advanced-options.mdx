GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pagedescriptionlanguageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PageDescriptionLanguageConvertOptions</a> para especificar la configuración de conversión de formatos de archivo en lenguaje de descripción de páginas (PDL, por sus siglas en inglés). Esta clase implementa <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPagedConvertOptions</a>, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagerangedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPageRangedConvertOptions</a> y <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/iwatermarkedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IWatermarkedConvertOptions</a> para la selección de páginas, la especificación de rangos de páginas y el soporte de marcas de agua.

## Formatos de Lenguaje de Descripción de Páginas (PDL) admitidos {#supported-page-description-language-formats}

Los siguientes formatos PDL (Page Description Language) son compatibles:

| Formato | Extensión | Descripción |
| -------- | ----------- | ------------- |
| **SVG** | .svg | Gráficos Vectoriales Escalables (formato vectorial basado en XML) |
| **SVGZ** | .svgz | SVG comprimido mediante GZIP |
| **XPS** | .xps | Especificación de Papel XML (Microsoft) |
| **OXPS** | .oxps | Especificación Abierta de Papel XML |
| **EPS** | .eps | PostScript Encapsulado |
| **PS** | .ps | Documento PostScript |
| **PCL** | .pcl | Lenguaje de Comandos para Impresoras (HP) |
| **TEX** | .tex | Documento Fuente LaTeX |
| **CGM** | .cgm | Metaarchivo de Gráficos por Computadora |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo PDL deseado. Las opciones disponibles son: *Svg, Svgz, Xps, Oxps, Eps, Ps, Pcl, Tex, Cgm*.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pagedescriptionlanguageconvertoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** – Establece el ancho deseado de la página en píxeles.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pagedescriptionlanguageconvertoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** – Establece la altura deseada de la página en píxeles.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a>** – Especifica el número de página inicial para la conversión.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a>** – Especifica el número de páginas a convertir.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a>** – Especifica una lista de números de página específicos a convertir.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/iwatermarkedconvertoptions/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a>** – Aplica una marca de agua al documento convertido.

## Ejemplos de conversión {#conversion-examples}

PageDescriptionLanguageConvertOptions admite la conversión entre formatos PDL. Los siguientes ejemplos muestran conversiones comunes.

### XPS a SVG {#xps-to-svg}

Convierte un documento XPS a SVG (Gráficos Vectoriales Escalables):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "document.xps";
string outputFile = "document.svg";

using (var converter = new Converter(sourceFile))
{
    var options = new PageDescriptionLanguageConvertOptions
    {
        Format = PageDescriptionLanguageFileType.Svg
    };
    converter.Convert(outputFile, options);
}
```

### EPS a XPS {#eps-to-xps}

Convierta un archivo EPS (Encapsulated PostScript) a XPS:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;

string outputFile = "illustration.xps";

        Format = PageDescriptionLanguageFileType.Xps

```

### PostScript a SVG {#postscript-to-svg}

Convertir un archivo PostScript (PS) a SVG:


## Dimensiones personalizadas {#custom-dimensions}

Controlar las dimensiones de la página de salida mediante las propiedades **Width** y **Height**:

### Uso de dimensiones de página personalizadas {#using-custom-page-dimensions}

Definir el ancho y la altura personalizados de la página en píxeles:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "technical-diagram.xps";
string outputFile = "technical-diagram.svg";

using (var converter = new Converter(sourceFile))
{
    var options = new PageDescriptionLanguageConvertOptions
    {
        Format = PageDescriptionLanguageFileType.Svg,
        Width = 800,   // Width in pixels
        Height = 600   // Height in pixels
    };
    converter.Convert(outputFile, options);
}
```

## Soporte de marca de agua {#watermark-support}

Agregue marcas de agua de texto o imagen a los documentos convertidos:

### Agregar marca de agua de texto {#adding-text-watermark}

Aplique una marca de agua de texto al documento convertido:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "confidential.xps";
string outputFile = "confidential.svg";

using (var converter = new Converter(sourceFile))
{
    var options = new PageDescriptionLanguageConvertOptions
    {
        Format = PageDescriptionLanguageFileType.Svg,
        Watermark = new WatermarkTextOptions("CONFIDENTIAL")
        {
            Color = System.Drawing.Color.Red,
            Width = 200,
            Height = 50,
            Top = 100,
            Left = 100
        }
    };
    converter.Convert(outputFile, options);
}
```

## Notas sobre el soporte de formatos {#format-support-notes}

Se admite la conversión de PDL a PDL para la mayoría de las combinaciones de formatos:
- XPS → SVG, EPS, PS, PCL, TEX
- EPS → SVG, XPS, PS, PCL, TEX
- PS → SVG, XPS, EPS, PCL, TEX
- SVG → XPS, EPS, PS, PCL, TEX
- TEX → SVG, XPS, EPS, PS, PCL
- PCL → SVG, XPS, EPS, PS, TEX

**Nota:** Para convertir **desde** formatos PDL a PDF o imágenes, utilice [PdfConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-pdf-with-advanced-options/) o [ImageConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-image-with-advanced-options/).

GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a> para brindarle control sobre los resultados de la conversión. Además de las [opciones comunes de conversión](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/), puede especificar las siguientes opciones adicionales mediante la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> establece el tipo de archivo deseado al que se convertirá el documento de entrada.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pagewidth" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a> establece el ancho deseado de la página en puntos tras la conversión (1 punto = 1/72 pulgada). Al establecerse, PageSize se cambia automáticamente a *Custom*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pageheight" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a> establece la altura deseada de la página en puntos tras la conversión (1 punto = 1/72 pulgada). Al establecerse, PageSize se cambia automáticamente a *Custom*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> establece el tamaño de página deseado. Las opciones disponibles son: *Default*, *A3*, *A4*, *A5*, *Letter*, *Legal*, *Tabloid*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/pageorientation" target="_blank" rel="nofollow noopener noreferrer">PageOrientation</a> establece la orientación de la página. Las opciones disponibles son: *Default*, *Landscape*, *Portrait*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/fallbackpagesize" target="_blank" rel="nofollow noopener noreferrer">FallbackPageSize</a> establece el tamaño de página de respaldo que se utilizará cuando no se pueda determinar el tamaño de página del documento de entrada.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/dpi" target="_blank" rel="nofollow noopener noreferrer">Dpi</a> establece la resolución DPI deseada de la página tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> cuando se especifica, el documento resultante se protegerá con la contraseña indicada.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/margintop" target="_blank" rel="nofollow noopener noreferrer">MarginTop</a> establece el margen superior deseado de la página tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginbottom" target="_blank" rel="nofollow noopener noreferrer">MarginBottom</a> establece el margen inferior deseado de la página tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginleft" target="_blank" rel="nofollow noopener noreferrer">MarginLeft</a> establece el margen izquierdo deseado de la página tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/marginright" target="_blank" rel="nofollow noopener noreferrer">MarginRight</a> establece el margen derecho deseado de la página tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a> define las opciones específicas de conversión para PDF. Consulte [a continuación](#pdfoptions).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions/rotate" target="_blank" rel="nofollow noopener noreferrer">Rotate</a> establece el ángulo de rotación de la página. Las opciones disponibles son: *None*, *On90*, *On180*, *On270*.

El siguiente fragmento de código muestra cómo realizar una conversión a PDF con opciones avanzadas:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Rotate = Rotation.On180,
        Dpi = 300,
        PageWidth = 595,   // A4 width in points (8.27 inches)
        PageHeight = 841   // A4 height in points (11.69 inches)
    };
    converter.Convert("converted.pdf", options);
}
```

## Tamaño y orientación de página {#page-size-and-orientation}

Puede controlar el tamaño y la orientación de la página utilizando tamaños predefinidos o dimensiones personalizadas.

### Uso de tamaños predefinidos de página {#using-predefined-page-size}

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageSize = PageSize.A4,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("a4-portrait.pdf", options);
}
```

### Configuración de orientación apaisada {#setting-landscape-orientation}

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        PageSize = PageSize.Letter,
        PageOrientation = PageOrientation.Landscape
    };
    converter.Convert("letter-landscape.pdf", options);
}
```

### Uso del tamaño de página de respaldo {#using-fallback-page-size}

El tamaño de página de respaldo se utiliza cuando no se puede determinar el tamaño de página del documento de entrada:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PdfConvertOptions options = new PdfConvertOptions
    {
        FallbackPageSize = PageSize.A4
    };
    converter.Convert("with-fallback.pdf", options);
}
```

### PdfOptions {#pdfoptions}

La clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a> proporciona opciones específicas al convertir documentos a distintas versiones del formato PDF.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/pdfformat" target="_blank" rel="nofollow noopener noreferrer">PdfFormat</a> establece el formato PDF específico del documento convertido. Las opciones disponibles son: *Default*, *PdfA_1A*, *PdfA_1B*, *PdfA_2A*, *PdfA_3A*, *PdfA2B*, *PdfA_2U*, *PdfA_3B*, *PdfA_3U*, *v1_3*, *v1_4*, *v1_5*, *v1_6*, *v1_7*, *PdfX_1A*, *PdfX_3*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/removepdfacompliance" target="_blank" rel="nofollow noopener noreferrer">RemovePdfACompliance</a> indica si se debe eliminar el cumplimiento de Pdf-A.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a> especifica el nivel de zoom en porcentaje.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/linearize" target="_blank" rel="nofollow noopener noreferrer">Linearize</a> indica si se debe linealizar el documento para la Web.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a> indica si se debe convertir el documento a escala de grises.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/optimizationoptions" target="_blank" rel="nofollow noopener noreferrer">OptimizationOptions</a> define las opciones de optimización del PDF. Consulte [a continuación](#pdfoptimizationoptions).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptions/formattingoptions" target="_blank" rel="nofollow noopener noreferrer">FormattingOptions</a> define las opciones de formato del PDF. Consulte [a continuación](#pdfformattingoptions).

El siguiente fragmento de código muestra cómo especificar opciones mediante la clase `PdfOptions`:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {        
        PdfOptions = new PdfOptions
        {
            Grayscale = true,
            Zoom = 200
        }
    };
    converter.Convert("converted.pdf", options);
}
```

### PdfOptimizationOptions {#pdfoptimizationoptions}

La clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions" target="_blank" rel="nofollow noopener noreferrer">PdfOptimizationOptions</a> especifica opciones para ajustar el proceso de conversión a PDF y mejorar su velocidad.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/linkduplicatestreams" target="_blank" rel="nofollow noopener noreferrer">LinkDuplicateStreams</a> indica si se deben vincular flujos duplicados.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/removeunusedobjects" target="_blank" rel="nofollow noopener noreferrer">RemoveUnusedObjects</a> indica si se deben eliminar objetos no utilizados.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/removeunusedstreams" target="_blank" rel="nofollow noopener noreferrer">RemoveUnusedStreams</a> indica si se deben eliminar flujos no utilizados.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/compressimages" target="_blank" rel="nofollow noopener noreferrer">CompressImages</a> indica si se deben recomprimir todas las imágenes del documento. El grado de compresión lo define la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/imagequality" target="_blank" rel="nofollow noopener noreferrer">ImageQuality</a>.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/imagequality" target="_blank" rel="nofollow noopener noreferrer">ImageQuality</a> define la calidad (en porcentaje) de la compresión de imágenes. Es efectiva cuando la propiedad `CompressImages` está establecida en `true`. Para conservar la calidad original y el tamaño de las imágenes, establezca esta propiedad en 100. Para reducir el tamaño de las imágenes, establezca esta propiedad en un valor inferior a 100.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfoptimizationoptions/unembedfonts" target="_blank" rel="nofollow noopener noreferrer">UnembedFonts</a> indica si se deben reemplazar las fuentes incrustadas por referencias a dichas fuentes. Reduce el tamaño del archivo, pero puede alterar el diseño original del documento.

El siguiente fragmento de código muestra cómo especificar las opciones de optimización de PDF:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {        
        PdfOptions = new PdfOptions
        {
            OptimizationOptions = new PdfOptimizationOptions
            { 
                CompressImages = true,
                ImageQuality = 70,
                UnembedFonts = true
            }
        }
    };
    converter.Convert("converted.pdf", options);
}
```

### PdfFormattingOptions {#pdfformattingoptions}

La clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions" target="_blank" rel="nofollow noopener noreferrer">PdfFormattingOptions</a> proporciona distintas opciones para modificar el formato del documento resultante.

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/centerwindow" target="_blank" rel="nofollow noopener noreferrer">CenterWindow</a> indica si se debe posicionar la ventana del documento en el centro de la pantalla.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/direction" target="_blank" rel="nofollow noopener noreferrer">Direction</a> define la dirección de lectura del documento: de izquierda a derecha o de derecha a izquierda. Las opciones disponibles son: *L2R, R2L*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/displaydoctitle" target="_blank" rel="nofollow noopener noreferrer">DisplayDocTitle</a> indica si se debe mostrar el título del documento en la barra de título de la ventana.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/fitwindow" target="_blank" rel="nofollow noopener noreferrer">FitWindow</a> indica si se debe redimensionar la ventana del documento para ajustarla a la primera página mostrada.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidemenubar" target="_blank" rel="nofollow noopener noreferrer">HideMenuBar</a> indica si se debe ocultar la barra de menús cuando el documento está activo.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidetoolbar" target="_blank" rel="nofollow noopener noreferrer">HideToolBar</a> indica si se debe ocultar la barra de herramientas cuando el documento está activo.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/hidewindowui" target="_blank" rel="nofollow noopener noreferrer">HideWindowUI</a> indica si se deben ocultar los elementos de la interfaz de usuario cuando el documento está activo.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/nonfullscreenpagemode" target="_blank" rel="nofollow noopener noreferrer">NonFullScreenPageMode</a> define cómo se debe mostrar el documento al salir del modo de pantalla completa. Las opciones disponibles son: *UseNone, UseOutlines, UseThumbs, FullScreen, UseOC, UseAttachments*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/pagelayout" target="_blank" rel="nofollow noopener noreferrer">PageLayout</a> define la disposición de páginas que se debe utilizar al abrir el documento. Las opciones disponibles son: *Default, SinglePage, OneColumn, TwoColumnLeft, TwoColumnRight, TwoPagesLeft, TwoPagesRight*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfformattingoptions/pagemode" target="_blank" rel="nofollow noopener noreferrer">PageMode</a> define cómo se debe mostrar el documento al abrirlo. Las opciones disponibles son: *UseNone, UseOutlines, UseThumbs, FullScreen, UseOC, UseAttachments*.

El siguiente fragmento de código muestra cómo especificar las opciones de formato PDF:

```csharp
using (Converter converter = new Converter("sample.docx"))
{

    PdfConvertOptions options = new PdfConvertOptions
    {
        PdfOptions = new PdfOptions
        {
            FormattingOptions = new PdfFormattingOptions
            {
                FitWindow = true,
                HideWindowUI = true,
                PageMode = PdfPageMode.UseThumbs
            }
        }
    };
    converter.Convert("converted.pdf", options);
}
```

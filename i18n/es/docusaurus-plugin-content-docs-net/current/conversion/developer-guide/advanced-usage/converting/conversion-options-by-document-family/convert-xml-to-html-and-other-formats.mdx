GroupDocs.Conversion para .NET le permite transformar datos XML en diversos formatos, incluidos documentos HTML, de procesamiento de texto (por ejemplo, DOCX) y PDF, utilizando hojas de estilo XSLT. Este método ofrece flexibilidad para definir el diseño, la estructura y el estilo del formato de destino, aprovechando las potentes capacidades de transformación XML de XSLT.

## Características clave {#key-features}

- Transforme datos XML en distintos formatos mediante plantillas XSLT personalizadas.
- Formatos de salida admitidos: HTML, DOCX y PDF.
- Transformación altamente personalizable basada en el diseño XSLT.

## Requisitos previos {#prerequisites}

Antes de proceder, asegúrese de lo siguiente:
1. GroupDocs.Conversion para .NET está instalado en su proyecto.
2. Disponga de un archivo XML con los datos que desea convertir.
3. Tenga una hoja de estilos XSLT que defina la lógica de transformación.

## Ejemplos {#examples}

### 1. Convertir XML a HTML {#1-convert-xml-to-html}

El siguiente código demuestra cómo convertir XML a un archivo HTML utilizando una plantilla XSLT:

```csharp
using (var converter = new Converter("books.xml", (LoadContext loadContext) => new XmlLoadOptions
       {
           XsltFactory = () => new FileStream("bookstore-template.xslt", FileMode.Open)
       }))
{
    var options = new WebConvertOptions();
    converter.Convert("converted.html", options);
}
```

### 2. Convertir XML a Wordprocessing {#2-convert-xml-to-wordprocessing}

El siguiente código demuestra cómo convertir XML a un archivo DOCX utilizando una plantilla XSLT:

```csharp
using (var converter = new Converter("books.xml", (LoadContext loadContext) => new XmlLoadOptions
       {
           XsltFactory = () => new FileStream("bookstore-template.xslt", FileMode.Open)
       }))
{
    var options = new WordProcessingConvertOptions();
    converter.Convert("converted.docx", options);
}
```

### 3. Convertir XML a PDF {#3-convert-xml-to-pdf}

El siguiente código demuestra cómo convertir un archivo XML a un archivo PDF utilizando una plantilla XSLT:

```csharp
using (var converter = new Converter("books.xml", (LoadContext loadContext) => new XmlLoadOptions
       {
           XsltFactory = () => new FileStream("bookstore-template.xslt", FileMode.Open)
       }))
{
    var options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

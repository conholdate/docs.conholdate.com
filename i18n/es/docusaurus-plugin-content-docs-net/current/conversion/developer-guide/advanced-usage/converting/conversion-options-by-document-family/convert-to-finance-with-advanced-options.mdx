GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/financeconvertoptions" target="_blank" rel="nofollow noopener noreferrer">FinanceConvertOptions</a> para especificar la configuración de conversión de formatos de datos financieros. Esta clase implementa <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPagedConvertOptions</a> para admitir la selección de páginas.

## Formatos financieros admitidos {#supported-finance-formats}

Los siguientes formatos de datos financieros son reconocidos:

| Formato | Extensión | Descripción | Caso de uso |
| -------- | ----------- | ------------- | ---------- |
| **XBRL** | .xbrl | Lenguaje Extensible de Reporte Empresarial | Reportes financieros, cumplimiento normativo |
| **iXBRL** | .ixbrl | XBRL en línea (HTML + XBRL) | Reportes financieros legibles tanto por humanos como por máquinas |
| **OFX** | .ofx | Open Financial Exchange | Datos bancarios, transacciones financieras |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo financiero deseado. Las opciones disponibles son: *Xbrl, IXbrl, Ofx*.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a>** – Especifica el número de página inicial para la conversión.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a>** – Especifica el número de páginas a convertir.

## Estructura de la API {#api-structure}

El siguiente ejemplo muestra la estructura de la API para FinanceConvertOptions:

```csharp
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

// Create options object
FinanceConvertOptions options = new FinanceConvertOptions
{
    Format = FinanceFileType.Xbrl,
    PageNumber = 1,      // Starting page (for multi-page sources)
    PagesCount = 10      // Number of pages to process
};
```

## Conversión entre formatos financieros {#converting-between-finance-formats}

Puede convertir entre formatos XBRL e iXBRL. Esto le permite transformar entre XBRL en línea legible por humanos y el formato XBRL estándar.

### Convertir XBRL a iXBRL {#convert-xbrl-to-ixbrl}

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

// Load the source XBRL file
using (Converter converter = new Converter("financial-report.xbrl"))
{
    // Configure iXBRL convert options
    FinanceConvertOptions options = new FinanceConvertOptions
    {
        Format = FinanceFileType.IXbrl
    };

    // Convert and save
    converter.Convert("financial-report.ixbrl", options);
}
```

### Convertir iXBRL a XBRL {#convert-ixbrl-to-xbrl}

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

// Load the source iXBRL file
using (Converter converter = new Converter("inline-report.ixbrl"))
{
    // Configure XBRL convert options
    FinanceConvertOptions options = new FinanceConvertOptions
    {
        Format = FinanceFileType.Xbrl
    };

    // Convert and save
    converter.Convert("inline-report.xbrl", options);
}
```

## Selección de formato {#format-selection}

Puede especificar distintos formatos financieros mediante la propiedad **Format**:

### Formato XBRL {#xbrl-format}

XBRL (eXtensible Business Reporting Language, o Lenguaje Extensible de Información Financiera) es la norma internacional para la presentación digital de informes empresariales:

```csharp
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

FinanceConvertOptions xbrlOptions = new FinanceConvertOptions
{
    Format = FinanceFileType.Xbrl
};
```

### Formato iXBRL {#ixbrl-format}

iXBRL (Inline XBRL) combina HTML legible por humanos con datos XBRL legibles por máquinas:

```csharp
FinanceConvertOptions ixbrlOptions = new FinanceConvertOptions
{
    Format = FinanceFileType.IXbrl
};
```

### Formato OFX {#ofx-format}

OFX (Open Financial Exchange) se utiliza para el intercambio de datos financieros entre instituciones y aplicaciones:

```csharp
FinanceConvertOptions ofxOptions = new FinanceConvertOptions
{
    Format = FinanceFileType.Ofx
};
```

## Notas sobre el soporte de formatos {#format-support-notes}

**Conversiones admitidas:**
- XBRL ↔ iXBRL (conversión bidireccional entre XBRL estándar e XBRL en línea)

**No admitido:**
- Conversión desde formatos de documento generales (PDF, Word, Excel) a formatos financieros
- Conversión desde formatos financieros a otros formatos (PDF, imágenes, etc.)
- Conversiones OFX hacia o desde XBRL o iXBRL

Los formatos financieros como XBRL requieren estructuras de datos, taxonomías y metadatos altamente específicos que no están presentes en documentos generales.

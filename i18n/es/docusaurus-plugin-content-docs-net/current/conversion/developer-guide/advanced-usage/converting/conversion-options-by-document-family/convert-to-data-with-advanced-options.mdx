GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> para brindarle control sobre el resultado de la conversión al convertir a formatos JSON, XML u otros formatos de datos web. Para convertir su documento al formato XML o JSON, especifique el formato deseado mediante la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>.

El siguiente fragmento de código muestra cómo convertir una hoja de cálculo CSV al formato JSON:

```csharp
using (Converter converter = new Converter("sample.csv"))
{
    WebConvertOptions options = new WebConvertOptions
    {
        Format = WebFileType.Json
    };
    converter.Convert("converted.json", options);
}
```

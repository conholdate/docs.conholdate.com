El siguiente fragmento de código muestra cómo convertir un archivo JSON en una hoja de cálculo. Esto significa que utilizas este JSON como fuente de datos y lo conviertes en una hoja de cálculo:

```csharp
using (Converter converter = new Converter("data.json"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions();
    converter.Convert("converted.xlsx", options);
}
```

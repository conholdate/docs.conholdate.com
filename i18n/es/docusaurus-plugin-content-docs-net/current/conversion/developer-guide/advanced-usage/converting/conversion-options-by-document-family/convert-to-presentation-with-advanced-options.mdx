:::

GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a> para ofrecerle control sobre el resultado de la conversión al convertir al formato de presentación de PowerPoint. Además de [las opciones comunes de conversión](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) de la clase base <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a>, presenta las siguientes opciones adicionales:

*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** especifica el tipo de documento de resultado deseado. Las opciones disponibles son: *Ppt, Pps, Pptx, Ppsx, Odp, Otp, Potx, Pot, Potm, Pptm, Ppsm*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** indica si el documento convertido estará protegido con contraseña mediante la contraseña especificada.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a>** especifica el nivel de zoom en porcentaje.

El siguiente fragmento de código muestra cómo realizar la conversión a presentación con opciones avanzadas:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PresentationConvertOptions options = new PresentationConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Format = PresentationFileType.Ppt
    };
    converter.Convert("converted.ppt", options);
}
```

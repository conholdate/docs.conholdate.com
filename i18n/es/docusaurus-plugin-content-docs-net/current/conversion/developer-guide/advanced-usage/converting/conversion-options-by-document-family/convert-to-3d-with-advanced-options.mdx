GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/threedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ThreeDConvertOptions</a> para especificar la configuración de conversión de archivos 3D. Esta clase implementa <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPagedConvertOptions</a> para admitir la selección de páginas.

## Formatos 3D admitidos {#supported-3d-formats}

Los siguientes formatos de archivo 3D (tridimensionales) están admitidos:

| Formato | Extensión | Descripción |
| -------- | ----------- | ------------- |
| **FBX** | .fbx | Autodesk FilmBox (captura de movimiento, animación) |
| **3DS** | .3ds | Formato de archivo de malla 3D Studio (DOS) |
| **3MF** | .3mf | Formato de fabricación 3D |
| **AMF** | .amf | Formato de archivo de fabricación aditiva |
| **ASE** | .ase | Exportación de escena ASCII de Autodesk |
| **DAE** | .dae | Intercambio de activos digitales (COLLADA) |
| **DRC** | .drc | 3D comprimido con Google Draco |
| **FBX** | .fbx | Autodesk FilmBox |
| **GLTF** | .gltf | Formato de transmisión GL (JSON) |
| **GLB** | .glb | Formato binario de transmisión GL |
| **OBJ** | .obj | Archivo de objeto 3D de Wavefront |
| **PLY** | .ply | Formato de archivo de polígonos |
| **RVM** | .rvm | Modelo de diseño de planta de AVEVA |
| **U3D** | .u3d | Formato universal de archivos 3D |
| **USD** | .usd | Descripción universal de escena |
| **USDZ** | .usdz | Descripción universal de escena (ZIP) |
| **VRML** | .vrml | Lenguaje de modelado de realidad virtual |
| **X** | .x | Gráficos 3D de DirectX (obsoleto) |
| **JT** | .jt | Tessellación Jupiter (ISO 14306) |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo 3D deseado. Las opciones disponibles incluyen: *Fbx, Obj, Gltf, ThreeDS, U3d, Dae, Drc, Rvm, Amf, Ply*, entre otras.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a>** – Especifica el número de página inicial para la conversión (cuando el archivo de origen tiene varias vistas/escenas).

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a>** – Especifica el número de páginas a convertir.

## Ejemplos de conversión {#conversion-examples}

ThreeDConvertOptions admite la conversión entre formatos 3D. Los siguientes ejemplos muestran conversiones comunes.

### FBX a OBJ {#fbx-to-obj}

Convierte un modelo Autodesk FBX al formato Wavefront OBJ:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "character-model.fbx";
string outputFile = "character-model.obj";

using (var converter = new Converter(sourceFile))
{
    var options = new ThreeDConvertOptions
    {
        Format = ThreeDFileType.Obj
    };
    converter.Convert(outputFile, options);
}
```

### OBJ a FBX {#obj-to-fbx}

Convierte un modelo Wavefront OBJ al formato Autodesk FBX:


## Notas sobre el soporte de formatos {#format-support-notes}

Se admite la conversión de 3D a 3D para la mayoría de las combinaciones de formatos:
- FBX → OBJ, GLTF, 3DS, U3D, DAE, DRC, AMF, PLY, RVM
- OBJ → FBX, GLTF, 3DS, U3D, DAE, DRC, AMF, PLY, RVM
- GLTF → FBX, OBJ, 3DS, U3D, DAE, DRC, AMF, PLY, RVM
- 3DS → FBX, OBJ, GLTF, U3D, DAE, DRC, AMF, PLY, RVM
- Todos los formatos 3D de origen → Formatos de destino comunes (FBX, OBJ, GLTF, etc.)

**Nota:** Para convertir **desde** formatos 3D a PDF, utilice [PdfConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-pdf-with-advanced-options/).

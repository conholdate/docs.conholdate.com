GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/cadconvertoptions" target="_blank" rel="nofollow noopener noreferrer">CadConvertOptions</a> para especificar la configuración de conversión de archivos CAD. Esta clase implementa <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPagedConvertOptions</a> para la selección de páginas y <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagesizeconvertoptions" target="_blank" rel="nofollow noopener noreferrer">IPageSizeConvertOptions</a> para el dimensionado de páginas.

## Formatos CAD admitidos {#supported-cad-formats}

Los siguientes formatos CAD (Diseño Asistido por Computadora) son reconocidos:

| Formato | Extensión | Descripción |
| -------- | ----------- | ------------- |
| **DWG** | .dwg | Base de datos de dibujo de AutoCAD (formato binario) |
| **DXF** | .dxf | Formato de intercambio de dibujos (ASCII/binario) |
| **DWF** | .dwf | Formato Web de Diseño (2D/3D comprimido) |
| **DWFX** | .dwfx | Formato Web de Diseño XPS |
| **DWT** | .dwt | Plantilla de dibujo de AutoCAD |
| **DGN** | .dgn | Archivo de diseño de MicroStation |
| **IFC** | .ifc | Clases Fundamentales de la Industria (BIM) |
| **STL** | .stl | Estereolitografía (impresión 3D) |
| **PLT** | .plt | Archivo de trazado HPGL |
| **IGS** | .igs | Archivo de dibujo IGES |
| **CF2** | .cf2 | Formato de archivo común (diseños de paquetes 3D) |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo CAD deseado. Las opciones disponibles son: *Dwg, Dxf, Dwf, Dwfx, Dwt, Dgn, Ifc, Stl, Plt, Igs, Cf2*.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagesizeconvertoptions/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a>** – Establece el tamaño de página (A3, A4, Carta, etc.) para el documento de salida.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagesizeconvertoptions/pagewidth" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a>** – Establece el ancho personalizado de página en puntos. Al establecerse, PageSize cambia automáticamente a Custom.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagesizeconvertoptions/pageheight" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a>** – Establece la altura personalizada de página en puntos. Al establecerse, PageSize cambia automáticamente a Custom.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a>** – Especifica el número de página inicial para la conversión.

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ipagedconvertoptions/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a>** – Especifica el número de páginas a convertir.

## Estructura de la API {#api-structure}

El siguiente ejemplo muestra la estructura de la API para CadConvertOptions:

```csharp
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

// Create options object
CadConvertOptions options = new CadConvertOptions
{
    Format = CadFileType.Dwg,
    PageSize = GroupDocs.Conversion.Options.Convert.PageSize.A4,
    PageNumber = 1,      // Starting page
    PagesCount = 10      // Number of pages to process
};
```

## Ejemplos de conversión {#conversion-examples}

CadConvertOptions admite la conversión entre formatos CAD. Los siguientes ejemplos muestran conversiones comunes.

### DWG a DXF {#dwg-to-dxf}

Convierte un archivo DWG de AutoCAD a DXF (Drawing Exchange Format):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "drawing.dwg";
string outputFile = "drawing.dxf";

using (var converter = new Converter(sourceFile))
{
    var options = new CadConvertOptions
    {
        Format = CadFileType.Dxf
    };
    converter.Convert(outputFile, options);
}
```

### DWG a DWF {#dwg-to-dwf}

Convierta un archivo DWG a DWF (Design Web Format):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "blueprint.dwg";
string outputFile = "blueprint.dwf";

using (var converter = new Converter(sourceFile))
{
    var options = new CadConvertOptions
    {
        Format = CadFileType.Dwf
    };
    converter.Convert(outputFile, options);
}
```

## Opciones de tamaño de página {#page-size-options}

Controle las dimensiones de la página de salida mediante PageSize o dimensiones personalizadas:

### Uso de tamaños de página estándar {#using-standard-page-size}

Establezca un tamaño de página estándar (A4, A3, Carta, etc.):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "technical-drawing.dwg";
string outputFile = "technical-drawing-a4.dxf";

using (var converter = new Converter(sourceFile))
{
    var options = new CadConvertOptions
    {
        Format = CadFileType.Dxf,
        PageSize = PageSize.A4
    };
    converter.Convert(outputFile, options);
}
```

### Uso de dimensiones de página personalizadas {#using-custom-page-dimensions}

Define el ancho y la altura personalizados de la página en puntos:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "floor-plan.dwg";
string outputFile = "floor-plan-custom.dxf";

using (var converter = new Converter(sourceFile))
{
    var options = new CadConvertOptions
    {
        Format = CadFileType.Dxf,
        PageWidth = 800,   // Width in points
        PageHeight = 600   // Height in points
    };
    converter.Convert(outputFile, options);
}
```

## Notas sobre el soporte de formatos {#format-support-notes}

Las conversiones entre formatos CAD son compatibles para ciertas combinaciones de formatos:
- DWG → DXF, DWF
- DGN → DXF, DWF
- DWT → DXF, DWF
- STL → DXF, DWF (soporte limitado)
- Otros formatos CAD → DXF, DWF (varía según el formato)

No se admiten conversiones desde formatos no CAD (PDF, Word, Excel) a formatos CAD.

**Nota:** Para convertir **desde** formatos CAD a PDF o imágenes, utilice [PdfConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-pdf-with-advanced-options/) o [ImageConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-image-with-advanced-options/).

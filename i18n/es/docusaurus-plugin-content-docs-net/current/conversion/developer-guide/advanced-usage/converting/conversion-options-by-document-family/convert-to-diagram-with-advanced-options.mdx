## Introducción {#introduction}

GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/diagramconvertoptions" target="_blank" rel="nofollow noopener noreferrer">DiagramConvertOptions</a> para convertir entre formatos de diagramas. Además de las [opciones de conversión comunes](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) heredadas de la clase base, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/diagramconvertoptions" target="_blank" rel="nofollow noopener noreferrer">DiagramConvertOptions</a> ofrece las siguientes opciones adicionales:

## Propiedades {#properties}

| Propiedad | Tipo | Descripción |
| ---------- | ------ | ------------- |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> | `DiagramFileType` | Especifica el formato de diagrama deseado |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/diagramconvertoptions/autofitpagetodrawingcontent" target="_blank" rel="nofollow noopener noreferrer">AutoFitPageToDrawingContent</a> | `bool` | Define si se debe ampliar la página para ajustar el contenido del dibujo |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a> | `int` | Especifica el número de página inicial para la conversión |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a> | `int` | Especifica el número de páginas a convertir |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> | `List<int>` | Especifica los números de página concretos a convertir |

## Uso básico {#basic-usage}

Convertir archivos de diagrama con las opciones predeterminadas:

```csharp
using (var converter = new Converter("flowchart.vsdx"))
{
    var options = new DiagramConvertOptions();
    converter.Convert("flowchart-copy.vsdx", options);
}
```

## Conversión entre formatos de diagramas {#converting-between-diagram-formats}

### Convertir VSDX a VSD {#convert-vsdx-to-vsd}

Convertir el formato moderno de Visio al formato binario heredado:

```csharp
using (var converter = new Converter("network-diagram.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        Format = DiagramFileType.Vsd
    };
    converter.Convert("network-diagram.vsd", options);
}
```

### Convertir VSD a VSDX {#convert-vsd-to-vsdx}

Modernice los archivos antiguos de Visio al formato actual:

```csharp
using (var converter = new Converter("legacy-diagram.vsd"))
{
    var options = new DiagramConvertOptions
    {
        Format = DiagramFileType.Vsdx
    };
    converter.Convert("modernized-diagram.vsdx", options);
}
```

## Ajustar automáticamente la página al contenido del dibujo {#auto-fit-page-to-drawing-content}

Ajusta automáticamente el tamaño de la página para que se adapte a todo el contenido del dibujo:

```csharp
using (var converter = new Converter("org-chart.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        AutoFitPageToDrawingContent = true
    };
    converter.Convert("org-chart-autofit.vsdx", options);
}
```

Esta función es útil cuando:
- Los diagramas tienen contenido que se extiende más allá de los límites de la página
- Desea eliminar el espacio en blanco excesivo
- Al crear PDFs o imágenes con dimensiones óptimas
- Al preparar diagramas para presentaciones

## Convertir páginas específicas {#converting-specific-pages}

Convierta solo las páginas seleccionadas de diagramas de varias páginas:

### Convertir solo la primera página {#convert-first-page-only}

```csharp
using (var converter = new Converter("multi-page-diagram.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        PageNumber = 1,
        PagesCount = 1
    };
    converter.Convert("selected-page.vsdx", options);
}
```

### Convertir un rango de páginas específico {#convert-specific-page-range}

```csharp
using (var converter = new Converter("architecture-plans.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        PageNumber = 2,   // Start from page 2
        PagesCount = 3    // Convert 3 pages (pages 2-4)
    };
    converter.Convert("selected-pages.vsdx", options);
}
```

## Formatos de diagrama admitidos {#supported-diagram-formats}

DiagramConvertOptions funciona con los siguientes formatos de Visio:

### Formatos modernos (Office 2013 y posteriores) {#modern-formats-office-2013}
- **VSDX** - Dibujo de Visio (formato predeterminado para Visio 2013 y versiones posteriores)
- **VSSX** - Plantilla de formas de Visio
- **VSTX** - Plantilla de Visio

### Formatos heredados (Office 2010 y anteriores) {#legacy-formats-office-2010-and-earlier}
- **VSD** - Dibujo de Visio (formato binario)
- **VSS** - Plantilla de formas de Visio (formato binario)
- **VST** - Plantilla de Visio (formato binario)

### Formatos con macros habilitadas {#macro-enabled-formats}
- **VSDM** - Dibujo de Visio con macros habilitadas
- **VSSM** - Plantilla de formas de Visio con macros habilitadas
- **VSTM** - Plantilla de Visio con macros habilitadas

### Formatos XML {#xml-formats}
- **VDX** - Dibujo de Visio en XML
- **VSX** - Plantilla de formas de Visio en XML
- **VTX** - Plantilla de Visio en XML

### Formato web {#web-format}
- **VDW** - Dibujo web de Visio

## Detalles del formato {#format-details}

### VSDX frente a VSD {#vsdx-vs-vsd}

**VSDX (formato moderno)**:
- Formato abierto basado en XML
- Tamaños de archivo más pequeños (compresión)
- Mejor compatibilidad con Office 365
- Recomendado para nuevos diagramas

**VSD (formato heredado)**:
- Formato binario
- Tamaños de archivo más grandes
- Necesario para versiones antiguas de Visio (2010 y anteriores)
- Utilícelo para compatibilidad hacia atrás

### Archivos de plantillas de formas (VSS/VSSX) {#stencil-files-vss-vssx}

Las plantillas de formas contienen formas y plantillas reutilizables:
- VSS - Formato heredado de plantilla de formas
- VSSX - Formato moderno de plantilla de formas
- Se utilizan para mantener elementos de diagrama coherentes

### Archivos de plantillas (VST/VSTX) {#template-files-vst-vstx}

Las plantillas proporcionan puntos de partida para nuevos diagramas:
- VST - Formato heredado de plantilla
- VSTX - Formato moderno de plantilla
- Incluyen diseños y estilos predefinidos

## Casos de uso comunes {#common-use-cases}

### 1. Modernización de formatos {#1-format-modernization}

Actualice archivos de Visio heredados al formato moderno:

```csharp
using (var converter = new Converter("legacy-flowchart.vsd"))
{
    var options = new DiagramConvertOptions
    {
        Format = DiagramFileType.Vsdx,
        AutoFitPageToDrawingContent = true
    };
    converter.Convert("modern-flowchart.vsdx", options);
}
```

### 2. Optimización de diagramas {#2-diagram-optimization}

Optimice los diagramas ajustando automáticamente el contenido:

```csharp
using (var converter = new Converter("process-diagram.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        AutoFitPageToDrawingContent = true
    };
    converter.Convert("optimized-diagram.vsdx", options);
}
```

### 3. Extracción de páginas {#3-page-extraction}

Extraer páginas específicas de conjuntos grandes de diagramas:

```csharp
using (var converter = new Converter("complete-architecture.vsdx"))
{
    var options = new DiagramConvertOptions
    {
        PageNumber = 5,
        PagesCount = 1
    };
    converter.Convert("network-layer.vsdx", options);
}
```

### 4. Conversión por lotes {#4-batch-conversion}

Estandarizar formatos de diagramas en toda una organización:

```csharp
string[] diagramFiles = Directory.GetFiles(@"C:\diagrams", "*.vsd");

foreach (var file in diagramFiles)
{
    using (var converter = new Converter(file))
    {
        var options = new DiagramConvertOptions
        {
            Format = DiagramFileType.Vsdx
        };

        string outputFile = Path.ChangeExtension(file, ".vsdx");
        converter.Convert(outputFile, options);
    }
}
```

## Cuándo usar DiagramConvertOptions {#when-to-use-diagramconvertoptions}

Utilice DiagramConvertOptions cuando necesite:

- **Convertir entre formatos de Visio** (VSD ↔ VSDX, etc.)
- **Modernizar diagramas heredados** al formato actual de Visio
- **Optimizar páginas de diagramas** con la funcionalidad de ajuste automático
- **Extraer páginas específicas** de diagramas de varias páginas
- **Estandarizar formatos de diagramas** en distintos proyectos
- **Preparar diagramas** para su archivo o distribución

## Conversión de diagramas a otros formatos {#converting-diagrams-to-other-formats}

Para convertir archivos de diagrama a formatos no diagrama (PDF, imágenes, documentos), utilice las opciones de conversión adecuadas para el formato de destino:

```csharp
// Convert diagram to PDF
using (var converter = new Converter("flowchart.vsdx"))
{
    var options = new PdfConvertOptions();
    converter.Convert("flowchart.pdf", options);
}

// Convert diagram to PNG images (page by page)
using (var converter = new Converter("org-chart.vsdx"))
{
    var options = new ImageConvertOptions
    {
        Format = ImageFileType.Png
    };
    converter.Convert("org-chart-page.png", options);
}

// Convert diagram to Word document
using (var converter = new Converter("process-flow.vsdx"))
{
    var options = new WordProcessingConvertOptions();
    converter.Convert("process-flow.docx", options);
}
```

## Prácticas recomendadas {#best-practices}

1. **Utilice formatos modernos** (VSDX, VSSX, VSTX) para diagramas nuevos:
   - Compresión mejorada
   - Compatibilidad mejorada
   - Funciones mejoradas

2. **Habilite el ajuste automático cuando sea apropiado**:
   - Elimina el espacio en blanco innecesario
   - Optimiza las dimensiones de salida
   - Mejora la legibilidad

3. **Convierta VSD a VSDX** para almacenamiento a largo plazo:
   - Tamaños de archivo reducidos
   - Formato más adecuado para archivo
   - Compatibilidad a prueba del futuro

4. **Extraiga páginas estratégicamente**:
   - Reduzca los tamaños de archivo
   - Enfoque en contenido específico
   - Mejore la velocidad de procesamiento

5. **Pruebe conversiones con macros habilitadas**:
   - VSDM, VSSM y VSTM contienen macros
   - Verifique los requisitos de macros en el entorno de destino
   - Considere las implicaciones de seguridad

- **Selección de páginas**: Convierta páginas o rangos de páginas específicos
- **Modernización de formatos**: Actualice archivos VSD heredados a VSDX modernos
- **Optimización de diagramas**: Optimice los tamaños de página y el ajuste del contenido

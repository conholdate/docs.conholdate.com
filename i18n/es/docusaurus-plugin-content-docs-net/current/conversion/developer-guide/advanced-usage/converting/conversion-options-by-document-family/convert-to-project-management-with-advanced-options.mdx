GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/projectmanagementconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ProjectManagementConvertOptions</a> para especificar la configuración de conversión de archivos de gestión de proyectos.

## Formatos de gestión de proyectos admitidos {#supported-project-management-formats}

Los siguientes formatos de gestión de proyectos son compatibles:

| Formato | Extensión | Descripción | Aplicación |
| -------- | ----------- | ------------- | ------------- |
| **MPP** | .mpp | Formato binario de Microsoft Project | Microsoft Project |
| **MPT** | .mpt | Plantilla de Microsoft Project | Microsoft Project |
| **MPX** | .mpx | Formato de intercambio de Microsoft Project (formato ASCII) | Microsoft Project y Primavera |
| **XER** | .xer | Formato Primavera P6 | Primavera P6 |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo de gestión de proyectos deseado. Las opciones disponibles son: *Mpp, Mpt, Mpx, Xer*.

## Ejemplos de conversión {#conversion-examples}

ProjectManagementConvertOptions admite la conversión entre formatos de gestión de proyectos. Los siguientes ejemplos muestran conversiones comunes.

### MPP a MPX {#mpp-to-mpx}

Convierte un archivo binario de Microsoft Project (MPP) a MPX (Formato de Intercambio de Proyectos):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "construction-plan.mpp";
string outputFile = "construction-plan.mpx";

using (var converter = new Converter(sourceFile))
{
    var options = new ProjectManagementConvertOptions
    {
        Format = ProjectManagementFileType.Mpx
    };
    converter.Convert(outputFile, options);
}
```

### XER (Primavera) a MPX {#xer-primavera-to-mpx}

Convierte un archivo de Primavera P6 (XER) al formato de intercambio de Microsoft Project (MPX):

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "engineering-project.xer";
string outputFile = "engineering-project.mpx";

using (var converter = new Converter(sourceFile))
{
    var options = new ProjectManagementConvertOptions
    {
        Format = ProjectManagementFileType.Mpx
    };
    converter.Convert(outputFile, options);
}
```

## Notas sobre el soporte de formatos {#format-support-notes}

Se admite la conversión entre formatos de gestión de proyectos para ciertas combinaciones de formatos:
- MPP → MPX, XER
- MPT → MPX, XER
- MPX → MPP, XER (aplican algunas restricciones)
- XER → MPX, MPP

**Nota:** Para convertir **desde** formatos de gestión de proyectos a PDF o imágenes, utilice [PdfConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-pdf-with-advanced-options/) o [ImageConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-image-with-advanced-options/).

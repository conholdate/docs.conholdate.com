GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> para ofrecerle control sobre el resultado de la conversión al convertir a imágenes. Además de las [opciones comunes de conversión](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) heredadas de la clase base, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> incluye las siguientes opciones adicionales:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> especifica el tipo de documento de resultado deseado. Las opciones disponibles son: *Tiff, Tif, Jpg, Jpeg, Png, Gig, Bmp, Ico, Psd, Wmf, Emf, Dcm, Webp, Dng, Svg, Jp2, Odg, J2c, J2k, Jpx, Jpf, Jpm, Eps, Cgm, Cdr, Cmx, Dib, Jpc, Jls, DjVu*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> especifica el ancho deseado de la imagen tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> especifica la altura deseada de la imagen tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/horizontalresolution" target="_blank" rel="nofollow noopener noreferrer">HorizontalResolution</a> especifica la resolución horizontal deseada de la imagen tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/verticalresolution" target="_blank" rel="nofollow noopener noreferrer">VerticalResolution</a> especifica la resolución vertical deseada de la imagen tras la conversión.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a> especifica si, al establecerse en *true*, la imagen convertida se convertirá a escala de grises.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/rotateangle" target="_blank" rel="nofollow noopener noreferrer">RotateAngle</a> especifica el ángulo de rotación de la imagen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/flipmode" target="_blank" rel="nofollow noopener noreferrer">FlipMode</a> especifica el modo de volteo de la imagen. Las opciones disponibles son: *None, FlipX, FlipY, FlipXY*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/brightness" target="_blank" rel="nofollow noopener noreferrer">Brightness</a> ajusta el brillo de la imagen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/contrast" target="_blank" rel="nofollow noopener noreferrer">Contrast</a> ajusta el contraste de la imagen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/gamma" target="_blank" rel="nofollow noopener noreferrer">Gamma</a> ajusta el gamma de la imagen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> establece el color de fondo, cuando lo admite el formato de origen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/croparea" target="_blank" rel="nofollow noopener noreferrer">CropArea</a> recorta un área rectangular de la imagen rasterizada tras la conversión. Especifíquelo como Rectangle(x, y, ancho, alto).
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/jpegoptions" target="_blank" rel="nofollow noopener noreferrer">JpegOptions</a> contiene opciones específicas de conversión para JPEG.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/tiffoptions" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a> contiene opciones específicas de conversión para TIFF.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/psdoptions" target="_blank" rel="nofollow noopener noreferrer">PsdOptions</a> contiene opciones específicas de conversión para PSD.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/webpoptions" target="_blank" rel="nofollow noopener noreferrer">WebpOptions</a> contiene opciones específicas de conversión para WebP.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions/usepdf" target="_blank" rel="nofollow noopener noreferrer">UsePdf</a>. En ocasiones, para lograr una mejor representación y posicionamiento de los elementos, el documento de origen debe convertirse primero a PDF. Si esta propiedad se establece en *true*, la entrada se convierte primero a PDF y posteriormente al formato deseado.

El siguiente fragmento de código muestra cómo realizar una conversión a imagen con opciones avanzadas:

```csharp
string outputFileTemplate = Path.Combine(@"c:\output", "converted-page-{0}.png");
Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format(outputFileTemplate, saveContext.Page), FileMode.Create);
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        FlipMode = ImageFlipModes.FlipY,
        Brightness = 50,
        Contrast = 50,
        Gamma = 0.5F,
        Grayscale = true,
        HorizontalResolution = 300,
        VerticalResolution = 100
    };

    converter.Convert(getPageStream, options);
}
```

## Configuración del color de fondo {#setting-background-color}

Establezca un color de fondo para la imagen convertida, cuando lo admita el formato de origen:

```csharp
using System.Drawing;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.White  // Use System.Drawing.Color
    };
    converter.Convert("white-background.png", options);
}
```

Puede utilizar cualquier color de `System.Drawing.Color` o crear colores personalizados:

```csharp
using System.Drawing;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.FromArgb(173, 216, 230)  // Light blue (RGB)
    };
    converter.Convert("custom-background.png", options);
}
```

## Recorte de área de imagen {#cropping-image-area}

Recorte un área rectangular específica de la imagen convertida. La propiedad `CropArea` acepta un `Rectangle` con coordenadas `X`, `Y` para la esquina superior izquierda, y `Width`, `Height` para las dimensiones:

```csharp
using GroupDocs.Conversion.Contracts;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        CropArea = new Rectangle(100, 100, 400, 300)  // X, Y, Width, Height
    };
    converter.Convert("cropped-image.png", options);
}
```

Puedes combinar `BackgroundColor` y `CropArea`:

```csharp
using System.Drawing;
using GroupDocs.Conversion.Contracts;
using (Converter converter = new Converter("sample.pdf"))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png,
        BackgroundColor = Color.LightGray,
        CropArea = new Rectangle(50, 50, 512, 512)
    };
    converter.Convert("background-and-crop.png", options);
}
```

### JpegOptions {#jpegoptions}

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions" target="_blank" rel="nofollow noopener noreferrer">JpegOptions</a> es un subconjunto de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> que permite un control mejorado sobre las conversiones al formato JPEG.

Las siguientes opciones están disponibles:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/quality" target="_blank" rel="nofollow noopener noreferrer">Quality</a> especifica la calidad deseada de la imagen.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/colormode" target="_blank" rel="nofollow noopener noreferrer">ColorMode</a> establece el modo de color JPEG. Las opciones disponibles son: *Rgb, YCbCr, Cmyk, Ycck, Grayscale*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/jpegoptions/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> establece los métodos de compresión JPEG. Las opciones disponibles son: *Baseline, Progressive, Lossless, JpegLs*.

### PsdOptions {#psdoptions}

<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions" target="_blank" rel="nofollow noopener noreferrer">PsdOptions</a> es un subconjunto de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a> que permite un control mejorado sobre las conversiones al formato PSD.

Las siguientes opciones están disponibles:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/channelbitscount" target="_blank" rel="nofollow noopener noreferrer">ChannelBitsCount</a> establece el número de bits por canal.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/channelscount" target="_blank" rel="nofollow noopener noreferrer">ChannelsCount</a> establece el número de canales de color.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/colormode" target="_blank" rel="nofollow noopener noreferrer">ColorMode</a> establece el modo de color PSD. Las opciones disponibles son: *Bitmap, Grayscale, Indexed, Rgb, Cmyk, Multichannel, Duotone, Lab*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/compression" target="_blank" rel="nofollow noopener noreferrer">Compression</a> establece el método de compresión PSD. Las opciones disponibles son: *Raw, Rle, ZipWithoutPrediction, ZipWithPrediction*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/psdoptions/version" target="_blank" rel="nofollow noopener noreferrer">Version</a> establece la versión PSD deseada.

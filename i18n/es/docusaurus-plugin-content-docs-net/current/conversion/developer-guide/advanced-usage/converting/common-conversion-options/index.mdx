<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> ofrece múltiples <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> que permiten controlar el resultado de la conversión requerida. Todos los <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> comparten algunas propiedades comunes, las cuales son:

* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a> especifica el número de página desde el cual debe iniciarse la conversión.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagescount" target="_blank" rel="nofollow noopener noreferrer">PagesCount</a> especifica la cantidad de páginas que se convertirán.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> es una lista de números de página específicos que se convertirán.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> establece las opciones de marca de agua.
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a> especifica el tipo de archivo deseado al que se convertirá el documento de entrada.

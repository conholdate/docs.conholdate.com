GroupDocs.Conversion proporciona el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a> Clase para brindarte control sobre el resultado de la conversión al convertir a formatos de procesamiento de texto. Junto con [opciones comunes de conversión](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) desde la clase base <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a> tiene las siguientes opciones adicionales:

*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** especifica el tipo de documento de resultado deseado. Las opciones disponibles son: *Doc, Docm, Docx, Dot, Dotx, Rtf, Odt, Ott, Mobi, Txt, Md*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pagewidth" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a>** especifica el ancho deseado de la página en puntos tras la conversión (1 punto = 1/72 pulgada). Cuando se establece, PageSize se cambia automáticamente a Personalizado.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pageheight" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a>** especifica la altura deseada de la página en puntos tras la conversión (1 punto = 1/72 pulgada). Cuando se establece, PageSize se cambia automáticamente a Personalizado.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a>** especifica el tamaño de página. Las opciones disponibles son: *Default, A3, A4, A5, Letter, Legal, Tabloid*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pageorientation" target="_blank" rel="nofollow noopener noreferrer">PageOrientation</a>** especifica la orientación de la página. Las opciones disponibles son: *Predeterminado, Apaisado, Vertical*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/fallbackpagesize" target="_blank" rel="nofollow noopener noreferrer">FallbackPageSize</a>** especifica el tamaño de página de respaldo que se utilizará cuando no se pueda determinar el tamaño de página del documento de entrada.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/dpi" target="_blank" rel="nofollow noopener noreferrer">Dpi</a>** especifica el DPI deseado de la página tras la conversión. La resolución predeterminada es 96 DPI.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/margintop" target="_blank" rel="nofollow noopener noreferrer">MarginTop</a>** especifica el margen superior deseado de la página en puntos tras la conversión.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginbottom" target="_blank" rel="nofollow noopener noreferrer">MarginBottom</a>** especifica el margen inferior deseado de la página en puntos después de la conversión.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginleft" target="_blank" rel="nofollow noopener noreferrer">MarginLeft</a>** especifica el margen izquierdo deseado de la página en puntos tras la conversión.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/marginright" target="_blank" rel="nofollow noopener noreferrer">MarginRight</a>** especifica el margen derecho deseado de la página en puntos tras la conversión.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** si el documento convertido estará protegido con contraseña utilizando la contraseña especificada.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/pdfrecognitionmode" target="_blank" rel="nofollow noopener noreferrer">PdfRecognitionMode</a>** especifica el modo de reconocimiento al convertir desde PDF. Las opciones disponibles son: *Textbox, Flow*. Se recomienda el modo Flow para una máxima editabilidad del contenido.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/rtfoptions" target="_blank" rel="nofollow noopener noreferrer">RtfOptions</a>** especifica opciones específicas de RTF. Consulte [a continuación](#rtfoptions).
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/markdownoptions" target="_blank" rel="nofollow noopener noreferrer">MarkdownOptions</a>** especifica opciones específicas de Markdown al convertir al formato Markdown.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a>** especifica el nivel de zoom en porcentaje. El valor predeterminado es 100.

El siguiente fragmento de código muestra cómo convertir a WordProcessing con opciones avanzadas:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Format = WordProcessingFileType.Docx,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("converted.docx", options);
}
```

## Tamaño y dimensiones de página {#page-size-and-dimensions}

Puede controlar el tamaño de página utilizando tamaños predefinidos o dimensiones personalizadas:

### Uso de tamaños de página predefinidos {#using-predefined-page-size}

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageSize = PageSize.A4,
        PageOrientation = PageOrientation.Portrait
    };
    converter.Convert("a4-document.docx", options);
}
```

### Uso de dimensiones personalizadas {#using-custom-dimensions}

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PageWidth = 612,   // 8.5 inches × 72 points/inch
        PageHeight = 792   // 11 inches × 72 points/inch
    };
    converter.Convert("custom-size.docx", options);
}
```

## Márgenes de página {#page-margins}

Establezca márgenes personalizados para los cuatro lados:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        MarginTop = 72,     // 1 inch
        MarginBottom = 72,  // 1 inch
        MarginLeft = 90,    // 1.25 inches
        MarginRight = 90    // 1.25 inches
    };
    converter.Convert("margins-document.docx", options);
}
```

## Modo de reconocimiento de PDF {#pdf-recognition-mode}

Al convertir desde PDF, controle cómo se interpreta el contenido:

```csharp
using (Converter converter = new Converter("document.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        PdfRecognitionMode = PdfRecognitionMode.Flow  // Recommended for editable content
    };
    converter.Convert("editable-document.docx", options);
}
```

Modos de reconocimiento disponibles:
- **Caja de texto** - Preserva el diseño exacto mediante cajas de texto (menos editable)
- **Flujo** - Optimizado para el flujo de contenido y la editabilidad (recomendado)

### RtfOptions {#rtfoptions}

La clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/rtfoptions" target="_blank" rel="nofollow noopener noreferrer">RtfOptions</a> proporciona opciones de conversión específicas para RTF:

*   **ExportImagesForOldReaders** - especifica si las palabras clave para "lectores antiguos" se escriben o no en RTF. Esto puede afectar significativamente el tamaño del documento RTF.

El siguiente fragmento de código muestra cómo realizar la conversión a RTF con opciones específicas:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        Format = WordProcessingFileType.Rtf,
        RtfOptions = new RtfOptions
        {
            ExportImagesForOldReaders = true
        }
    };
    converter.Convert("converted.rtf", options);
}
```

## Convertir a Markdown {#convert-to-markdown}

Convertir documentos al formato Markdown:

```csharp
using (Converter converter = new Converter("sample.pdf"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        Format = WordProcessingFileType.Md
    };
    converter.Convert("converted.md", options);
}
```

La salida en Markdown ofrece opciones dedicadas para controlar cómo se manejan las imágenes: se pueden incrustar como base64 (valor predeterminado) o redirigirlas mediante una devolución de llamada personalizada. Consulte [Convertir a Markdown con opciones avanzadas](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-markdown-with-advanced-options/).

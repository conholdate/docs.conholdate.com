## Introducción {#introduction}

GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ebookconvertoptions" target="_blank" rel="nofollow noopener noreferrer">EBookConvertOptions</a> para ofrecerle control sobre el resultado de la conversión al convertir a formatos de libros electrónicos. Además de las [opciones de conversión comunes](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) heredadas de la clase base, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ebookconvertoptions" target="_blank" rel="nofollow noopener noreferrer">EBookConvertOptions</a> ofrece las siguientes opciones adicionales:

## Uso básico {#basic-usage}

Convierta cualquier documento al formato EPUB con las opciones predeterminadas:

```csharp
using (var converter = new Converter("document.pdf"))
{
    var options = new EBookConvertOptions();
    converter.Convert("document.epub", options);
}
```

## Conversión a distintos formatos de libros electrónicos {#converting-to-different-ebook-formats}

Convierta documentos a los formatos EPUB, MOBI o AZW3 especificando el formato deseado:

### Convertir a EPUB {#convert-to-epub}

```csharp
using (var converter = new Converter("document.pdf"))
{
    var options = new EBookConvertOptions
    {
        Format = EBookFileType.Epub
    };
    converter.Convert("output.epub", options);
}
```

### Convertir a MOBI {#convert-to-mobi}

```csharp
using (var converter = new Converter("document.docx"))
{
    var options = new EBookConvertOptions
    {
        Format = EBookFileType.Mobi
    };
    converter.Convert("output.mobi", options);
}
```

### Convertir a AZW3 {#convert-to-azw3}

```csharp
using (var converter = new Converter("presentation.pptx"))
{
    var options = new EBookConvertOptions
    {
        Format = EBookFileType.Azw3
    };
    converter.Convert("output.azw3", options);
}
```

## Orientación de página {#page-orientation}

Establezca la orientación de página para el libro electrónico convertido:

```csharp
using (var converter = new Converter("landscape-document.pdf"))
{
    var options = new EBookConvertOptions
    {
        PageOrientation = PageOrientation.Landscape
    };
    converter.Convert("landscape-ebook.epub", options);
}
```

## Dimensiones de página personalizadas {#custom-page-dimensions}

Especifique el ancho y la altura personalizados de la página en puntos para un control preciso:

```csharp
using (var converter = new Converter("document.pdf"))
{
    var options = new EBookConvertOptions
    {
        PageWidth = 432,   // Width in points (6 inches × 72 points/inch)
        PageHeight = 648   // Height in points (9 inches × 72 points/inch)
    };
    converter.Convert("custom-size.epub", options);
}
```

## Convertir páginas específicas {#converting-specific-pages}

Convierte solo las páginas seleccionadas del documento de origen:

### Convertir solo la primera página {#convert-first-page-only}

```csharp
using (var converter = new Converter("multi-page.pdf"))
{
    var options = new EBookConvertOptions
    {
        PageNumber = 1,
        PagesCount = 1
    };
    converter.Convert("first-page.epub", options);
}
```

### Convertir un rango de páginas específico {#convert-specific-page-range}

```csharp
using (var converter = new Converter("report.pdf"))
{
    var options = new EBookConvertOptions
    {
        PageNumber = 2,   // Start from page 2
        PagesCount = 5    // Convert 5 pages (pages 2-6)
    };
    converter.Convert("selected-pages.epub", options);
}
```

## Formatos de origen admitidos {#supported-source-formats}

Puede convertir los siguientes tipos de documentos a formatos de libros electrónicos:

- **Documentos**: PDF, DOC, DOCX, RTF, ODT, TXT
- **Presentaciones**: PPT, PPTX, ODP
- **Hojas de cálculo**: XLS, XLSX, ODS, CSV
- **Web**: HTML, MHTML, HTM
- **Imágenes**: JPG, PNG, TIFF, BMP (una sola página o varias páginas)
- **Libros electrónicos**: Conversión entre formatos EPUB, MOBI y AZW3

## Detalles de los formatos de libros electrónicos {#ebook-format-details}

### EPUB (Publicación electrónica) {#epub-electronic-publication}

EPUB es el formato de libro electrónico más ampliamente admitido y es compatible con:
- Apple Books (iOS, macOS)
- Google Play Books
- Adobe Digital Editions
- La mayoría de los lectores de libros electrónicos (excepto Amazon Kindle)

**Casos de uso:**
- Distribución general de libros electrónicos
- Publicación para dispositivos distintos de Kindle
- Documentación académica y técnica
- Revistas y periódicos digitales

### MOBI (Mobipocket) {#mobi-mobipocket}

MOBI es el formato heredado de libros electrónicos de Amazon, compatible con:
- Dispositivos Kindle antiguos
- Aplicaciones Kindle (con limitaciones)

**Casos de uso:**
- Soporte para dispositivos Kindle antiguos
- Compatibilidad con lectores de libros electrónicos más antiguos

**Nota**: Para dispositivos Kindle modernos, utilice AZW3 en su lugar.

### AZW3 (Kindle Format 8) {#azw3-kindle-format-8}

AZW3 es el formato moderno de libros electrónicos de Amazon, que incluye funciones mejoradas:
- Tipografía y formato superiores
- Soporte para diseño fijo
- Manejo mejorado de imágenes
- Funciones exclusivas de Kindle

**Casos de uso:**
- Publicación en la tienda Kindle de Amazon
- Optimización para dispositivos Kindle
- Requisitos de formato mejorado

## Cuándo usar EBookConvertOptions {#when-to-use-ebookconvertoptions}

Utilice EBookConvertOptions cuando necesite:

- **Publicar contenido** para lectores electrónicos y aplicaciones móviles de lectura
- **Crear versiones portátiles** de documentos optimizadas para dispositivos de lectura
- **Distribuir documentación** en formatos de libro electrónico universalmente accesibles
- **Convertir entre formatos de libro electrónico** (EPUB a MOBI, etc.)
- **Personalizar el diseño de página** según las dimensiones específicas del lector electrónico
- **Extraer secciones** de documentos como libros electrónicos independientes
- **Optimizar la experiencia de lectura** con orientación y tamaño adecuados

## Prácticas recomendadas {#best-practices}

1. **Elija el formato adecuado**:
   - Utilice EPUB para máxima compatibilidad
   - Utilice MOBI para compatibilidad con dispositivos Kindle antiguos
   - Utilice AZW3 para dispositivos Kindle modernos

2. **Establezca dimensiones de página adecuadas**:
   - Libro electrónico estándar (6"×9"): 432×648 puntos
   - Lectores de tableta (8"×10.67"): 576×768 puntos
   - Dimensiones personalizadas para dispositivos específicos (1 punto = 1/72 pulgada)

3. **Considere la orientación**:
   - Retrato para contenido basado principalmente en texto
   - Paisaje para contenido con muchas imágenes o técnico

4. **Optimice los documentos de origen**:
   - Utilice estructuras claras de encabezados
   - Asegúrese de que el índice esté correctamente generado
   - Optimice las imágenes para su visualización en libro electrónico

## Resumen {#summary}

EBookConvertOptions proporciona un control integral sobre las conversiones de libros electrónicos:

- **Tres formatos**: compatibilidad con EPUB, MOBI y AZW3

- **Conversión selectiva**: convierta páginas o rangos de páginas específicos
- **Amplia compatibilidad**: convierta desde numerosos formatos de origen
- **Optimización para lectura**: adapte la salida a dispositivos y casos de uso específicos

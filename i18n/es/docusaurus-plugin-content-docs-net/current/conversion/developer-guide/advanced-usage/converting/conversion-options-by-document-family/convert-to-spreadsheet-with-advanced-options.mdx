GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a> para ofrecerle control sobre el resultado de la conversión al convertir a formatos de hoja de cálculo. Además de las [opciones comunes de conversión](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/) heredadas de la clase base <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>, incluye las siguientes opciones adicionales:

*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** especifica el tipo de documento de resultado deseado. Las opciones disponibles son: *Xls, Xlsx, Xlsm, Xlsb, Ods, Ots, Xltx, Xlt, Xltm, Tsc, Xlam, Csv, Tsv*.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>** especifica la codificación que se utilizará al convertir a formatos delimitados (CSV, TSV). El valor predeterminado es UTF-8.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions/separator" target="_blank" rel="nofollow noopener noreferrer">Separator</a>** especifica el carácter separador que se utilizará al convertir a formatos delimitados (CSV, TSV). Para CSV, el valor predeterminado es la coma (`,`). Para TSV, utilice el carácter de tabulación (`\t`).
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** indica si el documento convertido estará protegido con contraseña mediante la contraseña especificada.
*   **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a>** especifica el nivel de zoom en porcentaje. El valor predeterminado es 100.

El siguiente fragmento de código muestra cómo realizar la conversión a hoja de cálculo con opciones avanzadas:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        Format = SpreadsheetFileType.Xlsx,
        Zoom = 150
    };
    converter.Convert("converted.xlsx", options);
}
```

## Conversión a CSV con codificación {#converting-to-csv-with-encoding}

Al convertir al formato CSV, puede especificar la codificación de caracteres:

```csharp
using System.Text;
using (Converter converter = new Converter("sample.xlsx"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Csv,
        Encoding = Encoding.UTF8
    };
    converter.Convert("converted.csv", options);
}
```

## Conversión a CSV con separador personalizado {#converting-to-csv-with-custom-separator}

Utilice un carácter separador personalizado para la conversión a CSV. El punto y coma como separador es común en las configuraciones regionales europeas donde la coma se utiliza como separador decimal:

```csharp
using (Converter converter = new Converter("sample.xlsx"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Csv,
        Separator = ';'  // Semicolon separator for European locales
    };
    converter.Convert("converted.csv", options);
}
```

## Convertir a CSV con codificación y separador {#converting-to-csv-with-encoding-and-separator}

Combina tanto la configuración de codificación como la de separador para las exportaciones CSV internacionales:

```csharp
using System.Text;
using (Converter converter = new Converter("sample.xlsx"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Csv,
        Encoding = Encoding.UTF8,
        Separator = ';'
    };
    converter.Convert("international-data.csv", options);
}
```

## Convertir a TSV (Valores Separados por Tabulaciones) {#converting-to-tsv-tab-separated-values}

Convierte al formato TSV utilizando el carácter de tabulación como separador:

```csharp
using (Converter converter = new Converter("sample.xlsx"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Tsv,
        Separator = '\t'  // Tab character
    };
    converter.Convert("converted.tsv", options);
}
```

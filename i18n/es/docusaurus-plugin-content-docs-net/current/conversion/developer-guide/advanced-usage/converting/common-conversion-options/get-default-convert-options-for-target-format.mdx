**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** le permite obtener las opciones de conversión predefinidas por defecto para el formato de documento de destino deseado. Esto le permitirá obtener las opciones de conversión predefinidas en tiempo de ejecución, conociendo el formato de destino deseado.

Para obtener las opciones de conversión por defecto, siga estos pasos:

1.   Cree una instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> y pase la ruta del documento de origen como parámetro del constructor.
2.   Invocar el método de conversión <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversions</a>.
3.   Utilizar el indexador <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/item" target="_blank" rel="nofollow noopener noreferrer">tipo de archivo</a> o <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/item/#possibleconversions-indexer-2-of-2" target="_blank" rel="nofollow noopener noreferrer">extensión de archivo</a> del resultado posible de conversión recibido y leer la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/targetconversion/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a>.
4.   Llamar al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> de la instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> y pasar el nombre de archivo del documento convertido y la instancia de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> del paso anterior.

El siguiente fragmento de código muestra cómo obtener las opciones de conversión predefinidas para un formato de destino deseado:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    var possibleConversion = converter.GetPossibleConversions();
    var convertOptions = possibleConversion["pdf"].ConvertOptions;
    converter.Convert(outputFile, convertOptions);
}
```

GroupDocs.Conversion para .NET le permite transformar sin esfuerzo documentos XML en diversos formatos, como hojas de cálculo (XLSX), CSV o JSON, utilizando el contenido XML como fuente de datos estructurada. Esta guía ofrece un enfoque paso a paso para realizar estas conversiones, garantizando una integración fluida en sus aplicaciones. Ya sea que necesite analizar datos en Excel, exportarlos a un archivo CSV o estructurarlos en JSON, GroupDocs.Conversion simplifica y optimiza el proceso.

El siguiente fragmento de código muestra cómo convertir un archivo XML en una hoja de cálculo. Esto implica que utiliza este XML como fuente de datos y lo convierte en una hoja de cálculo:

```csharp
using (var converter = new Converter("data.xml", (LoadContext loadContext) => new XmlLoadOptions
       {
           UseAsDataSource = true
       }))
{
    var options = new SpreadsheetConvertOptions();
    converter.Convert("converted.xlsx", options);
}
```

## Convertir XML a CSV {#convert-xml-to-csv}

El siguiente fragmento de código demuestra cómo convertir un archivo XML a formato CSV. Al utilizar el XML como fuente de datos, se extraen los datos y se estructuran en un archivo de valores separados por comas (CSV) para facilitar su uso en aplicaciones como hojas de cálculo o herramientas de procesamiento de datos:

```csharp
using (var converter = new Converter("sample.xml", (LoadContext loadContext) => new XmlLoadOptions
       {
           UseAsDataSource = true
       }))
{
    var options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Csv
    };
    converter.Convert("converted.csv", options);
}
```

## Convertir XML a JSON {#convert-xml-to-json}

El siguiente fragmento de código ilustra cómo convertir un archivo XML a formato JSON. Al tratar el XML como una fuente de datos, su contenido se estructura y guarda en un archivo JSON, lo que lo hace adecuado para su uso en aplicaciones web, APIs u otros sistemas basados en JSON:

```csharp
using (var converter = new Converter(source, (LoadContext loadContext) => new XmlLoadOptions
       {
           UseAsDataSource = true
       }))
{
    var options = new WebConvertOptions()
    {
        Format = WebFileType.Json
    };
    converter.Convert("converted.json", options);
}
```

GroupDocs.Conversion proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/gisconvertoptions" target="_blank" rel="nofollow noopener noreferrer">GisConvertOptions</a> para especificar la configuración de conversión de formatos de archivo GIS (Sistema de Información Geográfica).

## Formatos GIS admitidos {#supported-gis-formats}

Los siguientes formatos GIS (Sistema de Información Geográfica) son compatibles:

| Formato | Extensión | Descripción |
| -------- | ----------- | ------------- |
| **GeoJSON** | .geojson | Formato basado en JSON para características geográficas |
| **KML** | .kml | Lenguaje de Marcado Keyhole (Google Earth) |
| **GPX** | .gpx | Formato de intercambio GPS |
| **TopoJSON** | .topojson | Extensión de GeoJSON con codificación de topología |
| **GML** | .gml | Lenguaje de Marcado Geográfico (basado en XML) |
| **OSM** | .osm | Formato XML de OpenStreetMap |
| **SHP** | .shp | Shapefile de ESRI |
| **GDB** | .gdb | Geodatabase de ESRI |

## Propiedades {#properties}

**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>** – Especifica el formato de archivo GIS deseado. Las opciones disponibles son: *GeoJson, Kml, Gpx, TopoJson, Gml, Osm, Shp, Gdb*.

## Ejemplos de conversión {#conversion-examples}

GisConvertOptions admite la conversión entre formatos GIS. Los siguientes ejemplos muestran conversiones comunes.

### GeoJSON a KML {#geojson-to-kml}

Convierte un archivo GeoJSON a KML (Lenguaje de Marcado Keyhole) para Google Earth:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "geographic-data.geojson";
string outputFile = "geographic-data.kml";

using (var converter = new Converter(sourceFile))
{
    var options = new GisConvertOptions
    {
        Format = GisFileType.Kml
    };
    converter.Convert(outputFile, options);
}
```

### De GPX a GeoJSON {#gpx-to-geojson}

Convierte un archivo GPX (GPS Exchange Format) a GeoJSON:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "tracking-route.gpx";
string outputFile = "tracking-route.geojson";

using (var converter = new Converter(sourceFile))
{
    var options = new GisConvertOptions
    {
        Format = GisFileType.GeoJson
    };
    converter.Convert(outputFile, options);
}
```

### De GeoJSON a TopoJSON {#geojson-to-topojson}

Convierte un archivo GeoJSON al formato TopoJSON para conversiones que preserven la topología:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.FileTypes;

string sourceFile = "map-boundaries.geojson";
string outputFile = "map-boundaries.topojson";

using (var converter = new Converter(sourceFile))
{
    var options = new GisConvertOptions
    {
        Format = GisFileType.TopoJson
    };
    converter.Convert(outputFile, options);
}
```

## Notas sobre el soporte de formatos {#format-support-notes}

Las conversiones entre formatos GIS son compatibles para la mayoría de combinaciones de formatos:
- GeoJSON → KML, GPX, TopoJSON, GML
- KML → GeoJSON, GPX, TopoJSON
- GPX → GeoJSON, KML, TopoJSON
- GML → GeoJSON, KML, GPX, TopoJSON
- OSM → GeoJSON, KML, GPX, TopoJSON
- TopoJSON → GeoJSON, KML, GPX

**Nota:** Para convertir **desde** formatos GIS hacia PDF, imágenes u otros formatos de documento, utilice [PdfConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-pdf-with-advanced-options/), [ImageConvertOptions](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-image-with-advanced-options/) u otras clases `ConvertOptions` adecuadas.

**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** permite aplicar una marca de agua al documento convertido. Puede configurar las siguientes opciones para controlar cómo se estampará la marca de agua en el documento convertido:

### OpcionesDeMarcaDeAgua {#watermarkoptions}

* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>** - texto de marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/watermarkfont" target="_blank" rel="nofollow noopener noreferrer">Font</a>** - nombre de la fuente de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions/color" target="_blank" rel="nofollow noopener noreferrer">Color</a>** - color de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** - ancho de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** - altura de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/top/" target="_blank" rel="nofollow noopener noreferrer">Top</a>** - posición superior de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/left" target="_blank" rel="nofollow noopener noreferrer">Left</a>** - posición izquierda de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/rotationangle" target="_blank" rel="nofollow noopener noreferrer">RotationAngle</a>** - ángulo de rotación de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/transparency" target="_blank" rel="nofollow noopener noreferrer">Transparency</a>** - transparencia de la marca de agua
* **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarkoptions/background" target="_blank" rel="nofollow noopener noreferrer">Background</a>** — especifica que la marca de agua se estampa como fondo. Si el valor es `true`, la marca de agua se coloca en la parte inferior. De forma predeterminada, es `false` y la marca de agua se coloca encima.

Para agregar una marca de agua, siga estos pasos:

1. Cree una instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> clase y pasar la ruta del documento fuente como parámetro del constructor
2. Instanciar el apropiado <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> clase, por ejemplo, **(<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>** etc.)
3. Cree una instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions" target="_blank" rel="nofollow noopener noreferrer">WatermarkTextOptions</a> clase. Establezca las propiedades adecuadas para especificar el color, ancho, altura, texto, imagen, etc., de la marca de agua.
4. Establezca el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> propiedad del <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> instancia con la instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/watermarktextoptions" target="_blank" rel="nofollow noopener noreferrer">WatermarkTextOptions</a> clase creada en el paso anterior
5. Llame a <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert" target="_blank" rel="nofollow noopener noreferrer">Convert</a> método de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> clase de instancia y pasar el nombre de archivo para el documento convertido y la instancia de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> del paso anterior

El siguiente fragmento de código muestra cómo aplicar una marca de agua al documento de salida:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    WatermarkOptions watermark = new WatermarkTextOptions("Sample watermark")
    {
        Color = Color.Red,
        Width = 100,
        Height = 100,
        Background = true
    };
    PdfConvertOptions options = new PdfConvertOptions
    {
        Watermark = watermark
    };
    converter.Convert("converted.pdf", options);
}
```

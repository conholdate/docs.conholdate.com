## Introducción {#introduction}

GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/emailconvertoptions" target="_blank" rel="nofollow noopener noreferrer">EmailConvertOptions</a> para convertir entre formatos de correo electrónico. **Importante**: `EmailConvertOptions` está diseñado específicamente para conversiones de correo electrónico a correo electrónico (por ejemplo, MSG a EML), no para convertir documentos generales a formatos de correo electrónico.

## Propiedades {#properties}

| Propiedad | Tipo | Descripción |
| ---------- | ------ | ------------- |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> | `EmailFileType` | Especifica el formato de correo electrónico deseado. Las opciones disponibles son: *Eml, Emlx, Msg, Vcf, Mbox, Pst, Ost, Olm* |
| <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/emailconvertoptions/attachmentcontenthandler" target="_blank" rel="nofollow noopener noreferrer">AttachmentContentHandler</a> | `Delegate` | Un delegado para manejar el procesamiento personalizado de los adjuntos de correo electrónico durante la conversión |

## Uso básico {#basic-usage}

Convertir archivos MSG al formato EML con opciones predeterminadas:

```csharp
using (var converter = new Converter("message.msg"))
{
    var options = new EmailConvertOptions();
    converter.Convert("message.eml", options);
}
```

## Conversión entre formatos de correo electrónico {#converting-between-email-formats}

### Convertir MSG a EML {#convert-msg-to-eml}

La conversión de formatos de correo electrónico más común: de Outlook MSG al formato estándar EML:

```csharp
using (var converter = new Converter("newsletter.msg"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Eml
    };
    converter.Convert("newsletter.eml", options);
}
```

### Convertir MSG a EMLX {#convert-msg-to-emlx}

Convertir mensajes de Outlook al formato de Apple Mail:

```csharp
using (var converter = new Converter("meeting-invite.msg"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Emlx
    };
    converter.Convert("meeting-invite.emlx", options);
}
```

### Convertir EML a MSG {#convert-eml-to-msg}

Convierta archivos EML estándar al formato MSG de Outlook:

```csharp
using (var converter = new Converter("customer-inquiry.eml"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Msg
    };
    converter.Convert("customer-inquiry.msg", options);
}
```

## Formatos de correo electrónico compatibles {#supported-email-formats}

EmailConvertOptions admite los siguientes formatos de correo electrónico:

- **EML** – formato estándar de correo electrónico RFC-822 (la mayoría de los clientes de correo electrónico)
- **EMLX** – formato de correo electrónico de Apple Mail (aplicación Mail de macOS)
- **MSG** – formato de Microsoft Outlook y Exchange
- **VCF** – formato de tarjeta virtual (información de contactos)
- **MBOX** – formato contenedor para colecciones de correos electrónicos
- **PST** – archivos de almacenamiento personal de Outlook
- **OST** – archivos de almacenamiento sin conexión de Outlook
- **OLM** – formato de Microsoft Outlook para macOS

**Nota**: No todas las combinaciones de formatos son compatibles. La biblioteca admite conversiones comúnmente utilizadas, como MSG↔EML, MSG→EMLX, etc.

## Detalles de los formatos de correo electrónico {#email-format-details}

### MSG (Mensaje de Microsoft Outlook) {#msg-microsoft-outlook-message}

MSG es el formato propietario utilizado por Microsoft Outlook:
- **Ventajas**: Preserva el formato específico de Outlook y admite metadatos avanzados
- **Plataforma**: Outlook en Windows, servidor Exchange
- **Caso de uso**: Sistemas empresariales de correo electrónico, integración con Outlook

### EML (Formato de correo electrónico electrónico) {#eml-electronic-mail-format}

EML es el formato estándar RFC-822 para correos electrónicos:
- **Ventajas**: Compatibilidad universal, basado en texto plano
- **Plataforma**: Multiplataforma (Thunderbird, Correo de Windows, Correo de macOS, correo web)
- **Caso de uso**: Archivado de correo electrónico, compatibilidad multiplataforma, copias de seguridad de correo

### EMLX (Formato de Apple Mail) {#emlx-apple-mail-format}

EMLX es la implementación de Apple del estándar EML:
- **Ventajas**: Optimizado para el Correo de macOS, incluye metadatos adicionales
- **Plataforma**: Aplicación Correo de macOS
- **Caso de uso**: Flujos de trabajo de correo específicos para Mac, integración con el ecosistema de Apple

## Casos de uso comunes {#common-use-cases}

### 1. Migración de correo electrónico {#1-email-migration}

Migre archivos de correo electrónico entre distintos clientes de correo:

```csharp
// Convert Outlook MSG archive to standard EML for cross-platform use
using (var converter = new Converter("archive-2024.msg"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Eml
    };
    converter.Convert("archive-2024.eml", options);
}
```

### 2. Migración de plataforma {#2-platform-migration}

Pasar de Windows Outlook a macOS Mail:

```csharp
// Convert MSG emails to EMLX for Apple Mail
using (var converter = new Converter("important-emails.msg"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Emlx
    };
    converter.Convert("important-emails.emlx", options);
}
```

### 3. Estandarización de correo electrónico {#3-email-standardization}

Convertir formatos propietarios a formatos basados en estándares:

```csharp
// Standardize various email formats to EML
using (var converter = new Converter("meeting-notes.msg"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Eml
    };
    converter.Convert("meeting-notes.eml", options);
}
```

### 4. Compatibilidad con clientes de correo electrónico {#4-email-client-compatibility}

Asegúrese de que los correos electrónicos puedan abrirse en diferentes clientes de correo electrónico:

```csharp
// Convert EML to MSG for Outlook users
using (var converter = new Converter("customer-feedback.eml"))
{
    var options = new EmailConvertOptions
    {
        Format = EmailFileType.Msg
    };
    converter.Convert("customer-feedback.msg", options);
}
```

## Cuándo usar EmailConvertOptions {#when-to-use-emailconvertoptions}

Utilice EmailConvertOptions cuando necesite:

- **Migrar sistemas de correo electrónico** entre distintas plataformas (Outlook ↔ Apple Mail ↔ Thunderbird)
- **Archivar correos electrónicos** en formatos estándar para almacenamiento a largo plazo
- **Garantizar compatibilidad** entre distintos clientes de correo electrónico
- **Convertir entre formatos** para integrarlos en flujos de trabajo
- **Estandarizar formatos de correo electrónico** dentro de una organización
- **Admitir el acceso al correo electrónico en múltiples plataformas**

## Limitaciones {#limitations}

### Solo conversión de correo electrónico a correo electrónico {#email-to-email-only}

EmailConvertOptions **no** está diseñado para convertir documentos generales a formatos de correo electrónico:

```csharp
// ❌ This will NOT work - cannot convert PDF to email format
using (var converter = new Converter("document.pdf"))
{
    var options = new EmailConvertOptions { Format = EmailFileType.Msg };
    converter.Convert("document.msg", options); // ConversionNotSupportedException
}
```

### Formatos de origen admitidos {#supported-source-formats}

EmailConvertOptions funciona con:
- Formatos de correo electrónico que se convierten a otros formatos de correo electrónico
- Algunas combinaciones de formatos pueden no estar admitidas (por ejemplo, MSG a MBOX)

## Conversión de correos electrónicos a otros formatos {#converting-emails-to-other-formats}

Para convertir mensajes de correo electrónico a documentos (PDF, DOCX, etc.), utilice las opciones de conversión adecuadas para el formato de destino:

```csharp
// ✅ Convert email to PDF
using (var converter = new Converter("message.msg"))
{
    var options = new PdfConvertOptions();
    converter.Convert("message.pdf", options);
}

// ✅ Convert email to Word document
using (var converter = new Converter("newsletter.eml"))
{
    var options = new WordProcessingConvertOptions();
    converter.Convert("newsletter.docx", options);
}
```

## Prácticas recomendadas {#best-practices}

1. **Elija el formato de destino adecuado**:
   - Utilice EML para una compatibilidad máxima entre plataformas
   - Utilice MSG para flujos de trabajo específicos de Outlook
   - Utilice EMLX para integración con el correo de macOS

2. **Pruebe combinaciones de formatos**:
   - No todas las conversiones de correo electrónico a correo electrónico están soportadas
   - Verifique que su ruta de conversión específica funcione antes de procesar por lotes

3. **Preserve la estructura del correo electrónico**:
   - Los formatos de correo electrónico preservan cabeceras, adjuntos y metadatos de forma diferente
   - Pruebe las conversiones para asegurarse de que la información crítica se conserve

4. **Maneje los adjuntos de forma adecuada**:
   - Los adjuntos de correo electrónico suelen conservarse durante la conversión de formatos
   - Utilice `AttachmentContentHandler` para necesidades personalizadas de procesamiento de adjuntos

## Resumen {#summary}

`EmailConvertOptions` proporciona control sobre las conversiones de formatos de correo electrónico:

- **Conversiones de correo a correo**: Convierta entre formatos de correo MSG, EML, EMLX y otros formatos de correo
- **Migración de plataforma**: Mueva correos electrónicos entre distintos clientes y plataformas de correo
- **Estandarización de formatos**: Convierta formatos propietarios a formatos basados en estándares
- **Limitación importante**: No puede convertir documentos generales a formatos de correo electrónico

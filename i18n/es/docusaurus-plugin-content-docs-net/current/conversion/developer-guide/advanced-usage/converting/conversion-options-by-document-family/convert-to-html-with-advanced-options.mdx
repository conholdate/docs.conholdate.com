GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> para brindarle control sobre el resultado de la conversión. Las siguientes opciones pueden configurarse:

*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/fixedlayout" target="_blank" rel="nofollow noopener noreferrer">FixedLayout</a> controla la generación de HTML. Si se establece en *true*, se utilizará un diseño fijo, por ejemplo, elementos HTML posicionados de forma absoluta.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/fixedlayoutshowborders" target="_blank" rel="nofollow noopener noreferrer">FixedLayoutShowBorders</a> controla la visualización de los bordes de página durante la conversión con diseño fijo. El valor predeterminado es *true*.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/embedfontresources" target="_blank" rel="nofollow noopener noreferrer">EmbedFontResources</a> especifica si se deben incrustar los recursos tipográficos dentro del HTML principal. El valor predeterminado es *false*. Nota: las fuentes se incrustan automáticamente cuando FixedLayout está habilitado.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/zoom" target="_blank" rel="nofollow noopener noreferrer">Zoom</a> especifica el nivel de zoom en porcentaje. El valor predeterminado es 100.
*   <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions/usepdf" target="_blank" rel="nofollow noopener noreferrer">UsePdf</a>. En ocasiones, para lograr una mejor representación y posicionamiento de los elementos, el documento de origen debe convertirse primero a PDF. Si esta propiedad se establece en *true*, la entrada se convierte primero a PDF y luego al formato deseado.

El siguiente fragmento de código muestra cómo realizar la conversión a HTML con opciones avanzadas

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    WebConvertOptions options = new WebConvertOptions
    {
        PageNumber = 2,
        PagesCount = 1,
        FixedLayout = true
    };
    converter.Convert("converted.html", options);
}
```

## Incrustación de recursos de fuentes {#embedding-font-resources}

Controla si los recursos de fuentes se incrustan dentro del archivo HTML:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    WebConvertOptions options = new WebConvertOptions
    {
        EmbedFontResources = true  // Embed fonts directly in HTML
    };
    converter.Convert("embedded-fonts.html", options);
}
```

Cuando `EmbedFontResources` se establece en `false` (valor predeterminado), los archivos de fuente se almacenan por separado y se hacen referencia desde el archivo HTML. Cuando se establece en `true`, todos los datos de fuente se incrustan directamente dentro del archivo HTML, lo que lo convierte en un archivo autónomo, aunque de mayor tamaño.

Nota: Cuando `FixedLayout` está habilitado, las fuentes se incrustan automáticamente independientemente del valor de `EmbedFontResources`.

### Controlar la visibilidad de los bordes de página {#control-page-borders-visibility}

El siguiente fragmento de código muestra cómo convertir a HTML y controlar la visibilidad de los bordes de página

```csharp
var source = "sample.docx";
using (var converter = new Converter(source))
{
    var options = new WebConvertOptions
    {
        FixedLayoutShowBorders = false
    };
    converter.Convert("converted.html" , options);
}
```

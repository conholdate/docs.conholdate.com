:::important[Obsoleto desde la v26.6 – utilice ConversionEvents en su lugar]
La interfaz `IConverterListener` y la propiedad `ConverterSettings.Listener` están marcadas como obsoletas en la v26.6 y están programadas para su eliminación en la v26.9. El código nuevo debe suscribirse a `OnConversionStarted` / `OnConversionProgress` / `OnConversionCompleted` en el agregador [ConversionEvents](/net/conversion/developer-guide/advanced-usage/conversion-events/) en su lugar.

El código existente que asigna un detector sigue funcionando en la v26.6: los callbacks `Started` / `Progress` / `Completed` se reenvían a los controladores `ConversionEvents` correspondientes durante la construcción del convertidor.
:::


En algunos casos, es necesario monitorear el proceso de conversión y recibir actualizaciones sobre el inicio, el progreso y la finalización de una conversión. Para tales situaciones, <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> expone un punto de extensión donde la aplicación cliente puede suscribirse y recibir actualizaciones. 

Para habilitar la escucha, siga estos pasos:

1.  Cree su propia implementación de la interfaz <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.reporting/iconverterlistener" target="_blank" rel="nofollow noopener noreferrer">IConverterListener</a>.
2.  Instancie la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/convertersettings" target="_blank" rel="nofollow noopener noreferrer">ConverterSettings</a> y pase una instancia de la clase creada en el primer paso.
3.  Pase el objeto fábrica <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/convertersettings" target="_blank" rel="nofollow noopener noreferrer">ConverterSettings</a> al constructor de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>.

El siguiente fragmento de código muestra cómo habilitar la escucha para los eventos de GroupDocs.Conversion:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Reporting;

IConverterListener listener = new ConverterListener();
Func<ConverterSettings> settingsFactory = () => new ConverterSettings
{
    Listener = listener
};
using (Converter converter = new Converter("sample.docx", settingsFactory))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}

public class ConverterListener : IConverterListener
{
    public void Started()
    {
        Console.WriteLine("Conversion started...");
    }
    public void Progress(byte current)
    {
        Console.WriteLine($"... {current} % ...");
    }
    public void Completed()
    {
        Console.WriteLine("... conversion completed");
    }
}
```

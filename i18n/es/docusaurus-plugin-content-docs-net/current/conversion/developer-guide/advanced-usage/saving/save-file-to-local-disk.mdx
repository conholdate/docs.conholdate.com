GroupDocs.Conversion para .NET está incluido en Conholdate.Total for .NET.
:::

Para guardar los resultados de la conversión en un disco local, utilice la implementación <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_16" target="_blank" rel="nofollow noopener noreferrer">Convert(string filePath, ConvertOptions convertOptions)</a> del método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert()</a>. Esta implementación acepta como parámetros la ruta del archivo de salida y las opciones del convertidor.

La ruta del archivo puede ser absoluta o relativa. Si el archivo resultante no existe, se creará.

El siguiente fragmento de código muestra cómo guardar un archivo en un disco local:

```csharp
public static void Run()
{
    // Specify source file location
    using (Converter converter = new Converter("c:\\files\\sample.docx")) 
    {
        PdfConvertOptions options = new PdfConvertOptions();
        // Specify output file location
        converter.Convert("c:\\files\\converted.pdf", options);
    }
}
```

También puedes utilizar el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.fluent/iconversionto/convertto/#convertto_2" target="_blank" rel="nofollow noopener noreferrer">ConvertirA(string nombreDeArchivo)</a> [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/) método para guardar un archivo en un disco local:

```csharp
public static void Run()
{
FluentConverter
    // Specify source file location
    .Load("c:\\files\\sample.docx")
    // Specify output file location
    .ConvertTo("c:\\files\\converted.pdf")
    .Convert();
}
```

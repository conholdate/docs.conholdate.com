Para guardar los resultados de la conversión en un flujo, siga estos pasos:

1.   Especifique el método para obtener el flujo en el que se enviará el archivo convertido.
2.   Pase el nombre del método como el parámetro `document` a las implementaciones del método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert()</a>. 

El parámetro `document` puede ser de tipo `Func<Stream>`, `Func<FileType, Stream>`, `Func<int, Stream>` o `Func<int, FileType, Stream>`.

El siguiente fragmento de código muestra cómo guardar un archivo en un flujo:

```csharp
public static void Run()
{
    Func<SaveContext, Stream> getOutputStream = saveContext => GetFileStream($"c:\\files\\converted.{saveContext.TargetFormat.Extension}");

    using (Converter converter = new Converter("c:\\files\\sample.docx"))
    {
        PdfConvertOptions options = new PdfConvertOptions();
        // Pass the output stream as parameter
        converter.Convert(getOutputStream, options);
    }

    Console.WriteLine($"\nSource file converted successfully.\nSent file to stream.");
}

// Obtain the stream for the conversion output
public static Stream GetFileStream(string outFile)
{
    return new FileStream(outFile, FileMode.OpenOrCreate);
}
```

También puedes utilizar el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.fluent/iconversionto/convertto/#convertto" target="_blank" rel="nofollow noopener noreferrer">ConvertirA(Func&lt;Stream&gt; `convertedStreamProvider`</a> [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/) método para guardar un archivo en un flujo:

```csharp
public static void Run()
{
    Func<SaveContext, Stream> getOutputStream = saveContext => GetFileStream($"c:\\files\\converted.{saveContext.TargetFormat.Extension}");

    FluentConverter
        // Specify source file location
        .Load("c:\\files\\sample.docx")
        // Pass the output stream as parameter
        .ConvertTo(getOutputStream)
        .Convert();
}

// Obtain the stream for the conversion output
public static Stream GetFileStream(string outFile)
{
    return new FileStream(outFile, FileMode.OpenOrCreate);
}
```

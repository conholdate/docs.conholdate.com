<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/txtloadoptions" target="_blank" rel="nofollow noopener noreferrer">TxtLoadOptions</a> para permitirle controlar cómo se procesará el documento de texto de origen. Se pueden configurar las siguientes opciones:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/txtloadoptions/detectnumberingwithwhitespaces" target="_blank" rel="nofollow noopener noreferrer">DetectNumberingWithWhitespaces</a>** | Permite especificar cómo se reconocen los elementos de lista numerada al convertir un documento de texto sin formato. Si esta opción se establece en `false`, el algoritmo de reconocimiento de listas detecta párrafos de lista cuando los números de lista terminan con un punto, un corchete derecho o símbolos de viñeta (como "•", "\*", "-" o "o"). Si esta opción se establece en `true`, también se utilizan los espacios en blanco como delimitadores de números de lista: el algoritmo de reconocimiento de listas con numeración estilo árabe (1., 1.1.2.) utiliza tanto espacios en blanco como puntos ("."). |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/txtloadoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>** | Especifica la codificación que se utilizará para cargar el documento. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/txtloadoptions/leadingspacesoptions" target="_blank" rel="nofollow noopener noreferrer">LeadingSpacesOptions</a>** | Especifica cómo se procesarán los espacios iniciales. Las opciones disponibles son: *ConvertToIdent*, *Preserve*, *Trim*. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/txtloadoptions/trailingspacesoptions" target="_blank" rel="nofollow noopener noreferrer">TrailingSpacesOptions</a>** | Especifica cómo se procesarán los espacios finales. Las opciones disponibles son: *Preserve*, *Trim*. |

### Controlar el comportamiento del procesamiento de espacios iniciales {#control-behavior-of-processing-leading-spaces}

El siguiente fragmento de código muestra cómo convertir un documento TXT y controlar el modo en que se procesan los espacios iniciales:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new TxtLoadOptions
{
    LeadingSpacesOptions = TxtLeadingSpacesOptions.ConvertToIndent,
    DetectNumberingWithWhitespaces = true
};
using (Converter converter = new Converter("sample.txt", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Control del comportamiento del procesamiento de espacios finales {#control-behavior-of-processing-trailing-spaces}

El siguiente fragmento de código muestra cómo convertir un documento TXT y cómo se procesan los espacios finales:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new TxtLoadOptions
{
    TrailingSpacesOptions = TxtTrailingSpacesOptions.Trim
};
using (Converter converter = new Converter("sample.txt", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Especificar codificación {#specify-encoding}

El siguiente fragmento de código muestra cómo convertir un documento TXT y especificar la codificación:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new TxtLoadOptions
{
    Encoding = Encoding.GetEncoding("shift_jis")
};
using (Converter converter = new Converter("sample.txt", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

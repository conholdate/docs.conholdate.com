<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/threedloadoptions" target="_blank" rel="nofollow noopener noreferrer">ThreeDLoadOptions</a> para controlar cómo se procesan los documentos de modelos 3D fuente. Los documentos 3D incluyen formatos como FBX, OBJ, GLTF, 3DS, U3D y otros formatos de archivos de modelado 3D.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| ---------------- | ---------------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/threedloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles incluyen: *Fbx, ThreeDS, ThreeMF, Amf, Ase, Dae, Drc, Gltf, Obj, Ply, Rvm, U3d, Usd, Usdz, Vrml, X* |

## Cargar documento FBX {#load-fbx-document}

El siguiente fragmento de código muestra cómo cargar un documento FBX (Filmbox) con especificación explícita del formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new ThreeDLoadOptions
{
    Format = ThreeDFileType.Fbx
};

using (Converter converter = new Converter("character-model.fbx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("character-model.pdf", options);
}
```

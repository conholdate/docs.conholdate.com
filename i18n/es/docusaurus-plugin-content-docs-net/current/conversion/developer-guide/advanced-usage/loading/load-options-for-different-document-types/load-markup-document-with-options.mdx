GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions" target="_blank" rel="nofollow noopener noreferrer">WebLoadOptions</a> para permitirle controlar cómo se procesará el documento de marcado de origen. Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/basepath" target="_blank" rel="nofollow noopener noreferrer">BasePath</a>** | Especifica la ruta/URL base para el HTML. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>** | Especifica la codificación que se utilizará para cargar el documento. Si no se especifica, la codificación se determinará a partir del atributo de conjunto de caracteres del documento. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/pagenumbering" target="_blank" rel="nofollow noopener noreferrer">PageNumbering</a>** | Indica si se deben generar números de página para el documento convertido. Valor predeterminado: `false`. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/resourceloadingtimeout" target="_blank" rel="nofollow noopener noreferrer">ResourceLoadingTimeout</a>** | Especifica el tiempo de espera para cargar los recursos externos. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/skipexternalresources" target="_blank" rel="nofollow noopener noreferrer">SkipExternalResources</a>** | Si se habilita, los recursos externos (excepto aquellos enumerados en `WhitelistedResources`) no se cargarán durante la conversión. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/whitelistedresources" target="_blank" rel="nofollow noopener noreferrer">WhitelistedResources</a>** | Especifica qué recursos externos se cargarán incluso cuando la carga de otros recursos externos esté restringida. |

## Habilitar numeración de páginas al convertir a formatos de procesamiento de texto {#enable-page-numbering-when-converting-to-word-processing-formats}

El siguiente fragmento de código muestra cómo convertir un documento de marcado e insertar numeración de páginas:

```csharp
var source = "sample.html";
var loadOptions = new WebLoadOptions
{
    PageNumbering = true
};
using (var converter = new Converter(source, (LoadContext loadContext) => loadOptions))
{
    var options = new WordProcessingConvertOptions();
    converter.Convert("converted.docx" , options);
}
```

## Omitir la carga de recursos externos {#skip-loading-of-external-resources}

En el contexto de documentos web, los recursos externos hacen referencia a cualquier archivo o dato que una página web o sitio web obtiene desde fuentes externas a su propio dominio o servidor. Estos recursos externos son esenciales para crear experiencias web dinámicas y ricas en funcionalidades. Entre los recursos externos más comunes se incluyen imágenes, audio, video, fuentes, CSS, scripts, marcos de trabajo (frameworks), entre otros. 

En algunos casos, es posible que desee omitir la carga de todos los recursos externos o solo de algunos durante la conversión. Por ejemplo, cuando estos recursos dejan de estar disponibles. Consulte el artículo [Omitir la carga de recursos externos](/net/conversion/developer-guide/advanced-usage/loading/skip-external-resources/) para aprender cómo hacerlo con **GroupDocs.Conversion for .NET**.

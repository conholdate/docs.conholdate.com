<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions" target="_blank" rel="nofollow noopener noreferrer">GisLoadOptions</a> para controlar cómo se procesan los documentos GIS (Sistemas de Información Geográfica) de origen. Los documentos GIS incluyen formatos como GeoJSON, KML, GPX y otros archivos de datos geoespaciales.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles incluyen: *GeoJson, Gpx, Kml, Osm, TopoJson, Gml* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Establece el ancho deseado de la página (en píxeles) para renderizar el documento GIS. El valor predeterminado es 1000. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/gisloadoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Establece la altura deseada de la página (en píxeles) para renderizar el documento GIS. El valor predeterminado es 1000. |

## Cargar documento GeoJSON {#load-geojson-document}

El siguiente fragmento de código muestra cómo cargar un documento GeoJSON con especificación explícita del formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson
};

using (Converter converter = new Converter("map-data.geojson", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("map-data.pdf", options);
}
```

## Cargar documento GIS con dimensiones personalizadas {#load-gis-document-with-custom-dimensions}

El siguiente fragmento de código muestra cómo cargar un documento GeoJSON y establecer dimensiones de renderizado personalizadas:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson,
    Width = 1500,
    Height = 1200
};

using (Converter converter = new Converter("city-boundaries.geojson", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("city-boundaries.pdf", options);
}
```

## Convertir documento GIS en imagen {#convert-gis-document-to-image}

El siguiente fragmento de código muestra cómo cargar un documento GeoJSON y convertirlo en una imagen con dimensiones personalizadas:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.GeoJson,
    Width = 800,
    Height = 600
};

using (Converter converter = new Converter("region-map.geojson", getLoadOptions))
{
    ImageConvertOptions options = new ImageConvertOptions
    {
        Format = ImageFileType.Png
    };
    converter.Convert("region-map.png", options);
}
```

## Convertir entre formatos GIS {#convert-between-gis-formats}

El siguiente fragmento de código muestra cómo convertir del formato GPX al formato KML:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new GisLoadOptions
{
    Format = GisFileType.Gpx
};

using (Converter converter = new Converter("hiking-trail.gpx", getLoadOptions))
{
    GisConvertOptions options = new GisConvertOptions
    {
        Format = GisFileType.Kml
    };
    converter.Convert("hiking-trail.kml", options);
}
```

<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pagedescriptionlanguageloadoptions" target="_blank" rel="nofollow noopener noreferrer">PageDescriptionLanguageLoadOptions</a> para controlar cómo se procesan los documentos del lenguaje de descripción de página (PDL, por sus siglas en inglés). Los documentos PDL incluyen formatos como XPS, SVG, EPS, PostScript (PS), TEX y PCL.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pagedescriptionlanguageloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles incluyen: *Xps, Eps, Svg, Ps, Tex, Pcl, Cgm, Oxps* |

## Cargar documento XPS {#load-xps-document}

El siguiente fragmento de código muestra cómo cargar un documento XPS especificando explícitamente el formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PageDescriptionLanguageLoadOptions
{
    Format = PageDescriptionLanguageFileType.Xps
};

using (Converter converter = new Converter("document.xps", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("document.pdf", options);
}
```

<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/financeloadoptions" target="_blank" rel="nofollow noopener noreferrer">FinanceLoadOptions</a> para controlar cómo se procesan los documentos financieros de origen. Los documentos financieros incluyen archivos XBRL (eXtensible Business Reporting Language) e iXBRL (XBRL en línea) utilizados para la elaboración de informes financieros.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/financeloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles son: *Xbrl, IXbrl* |

## Cargar documento XBRL {#load-xbrl-document}

El siguiente fragmento de código muestra cómo cargar un documento XBRL especificando explícitamente el formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new FinanceLoadOptions
{
    Format = FinanceFileType.Xbrl
};

using (Converter converter = new Converter("financial-report.xbrl", getLoadOptions))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions();
    converter.Convert("financial-report.xlsx", options);
}
```

## Convertir documento financiero a CSV {#convert-finance-document-to-csv}

El siguiente fragmento de código muestra cómo cargar un documento XBRL y convertirlo al formato CSV:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new FinanceLoadOptions
{
    Format = FinanceFileType.Xbrl
};

using (Converter converter = new Converter("quarterly-report.xbrl", getLoadOptions))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions
    {
        Format = SpreadsheetFileType.Csv
    };
    converter.Convert("quarterly-report.csv", options);
}
```

## Convertir entre formatos financieros {#convert-between-finance-formats}

El siguiente fragmento de código muestra cómo convertir de iXBRL a XBRL:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new FinanceLoadOptions
{
    Format = FinanceFileType.IXbrl
};

using (Converter converter = new Converter("annual-report.ixbrl", getLoadOptions))
{
    FinanceConvertOptions options = new FinanceConvertOptions
    {
        Format = FinanceFileType.Xbrl
    };
    converter.Convert("annual-report.xbrl", options);
}
```

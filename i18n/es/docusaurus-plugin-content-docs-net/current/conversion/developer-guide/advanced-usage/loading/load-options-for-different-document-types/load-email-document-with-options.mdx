<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/emailloadoptions" target="_blank" rel="nofollow noopener noreferrer">EmailLoadOptions</a> para permitirle controlar cómo se procesará el documento de correo electrónico de origen. Las opciones disponibles son: Msg, Eml, Emlx, Pst, Ost, Vcf, Mht |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/emailloadoptions/convertowned" target="_blank" rel="nofollow noopener noreferrer">ConvertOwned </a>** | Controla si los documentos contenidos dentro del contenedor deben convertirse |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/emailloadoptions/convertowner" target="_blank" rel="nofollow noopener noreferrer">ConvertOwner</a>** | Controla si el propio contenedor de documentos debe convertirse. Si esta propiedad es `true`, el contenedor de documentos se convertirá como el primer documento |

### Controlar la visibilidad de los campos {#control-fields-visibility}

El siguiente fragmento de código muestra cómo convertir un documento de correo electrónico y controlar la visibilidad de los campos:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new EmailLoadOptions
{
    DisplayHeader = false,
    DisplayFromEmailAddress = false,
    DisplayToEmailAddress = false,
    DisplayCcEmailAddress = false,
    DisplayBccEmailAddress = false
};
using (Converter converter = new Converter("sample.msg", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Conversión de adjuntos de correo electrónico {#converting-email-attachments}

El siguiente fragmento de código muestra cómo convertir un documento de correo electrónico y todos sus adjuntos:

```csharp
var source = "sample-with-attachment.eml";
var loadOptions = new EmailLoadOptions {
    ConvertOwner = true,
    ConvertOwned = true,
    // convert email itself and the attachments
    Depth = 2
};
using (var converter = new Converter(source, (LoadContext loadContext) => loadOptions))
{
    var index = 1;
    var options = new PdfConvertOptions();
    // Note: index = 1 is the email itself, all following indexes are attachments
    converter.Convert((SaveContext saveContext) => new FileStream($"converted-{index++}.{saveContext.TargetFormat.Extension}", FileMode.Create) , options);
}
```

### Localizar las etiquetas de los campos de correo electrónico {#localize-email-fields-captions}

El siguiente fragmento de código muestra cómo convertir un documento de correo electrónico y localizar los campos de correo electrónico:

```csharp
var source = "sample.eml";
var loadOptions = new EmailLoadOptions
{
    FieldTextMap = new Dictionary<EmailField, string>
    {
        { EmailField.Subject, "Gegenstand" },
        { EmailField.From, "Von" },
        { EmailField.Attachments, "Anhänge" }
    }
};
using (var converter = new Converter(source, (LoadContext loadContext) => loadOptions))
{
    var options = new PdfConvertOptions();
    converter.Convert("converted.pdf" , options);
}
```

### Control del formato de fecha/hora {#control-date-time-format}

El siguiente fragmento de código muestra cómo convertir un documento de correo electrónico y modificar el formato de fecha/hora:

```csharp
var source = "sample.eml";
CultureInfo.CurrentCulture = new CultureInfo("fr-FR");
using (var converter = new Converter(source))
{
    var options = new PdfConvertOptions();
    converter.Convert("converted.pdf" , options);
}
```

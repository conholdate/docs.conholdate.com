### Controlar el comportamiento de conversión de datos de fecha/hora y numéricos {#control-behavior-of-converting-date-time-and-numeric-data}

El siguiente fragmento de código muestra cómo convertir un documento CSV y controlar el modo en que se procesan los datos de fecha/hora y numéricos:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CsvLoadOptions
{
    ConvertDateTimeData = true,
    ConvertNumericData = true
};
using (Converter converter = new Converter("sample.csv", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CsvLoadOptions

```

### Especificar la codificación {#specify-encoding}

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CsvLoadOptions

```

### Ajustar filas automáticamente {#automatically-fit-rows}

Para ajustar el contenido de las filas de todas las filas durante la conversión, configure el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/spreadsheetloadoptions/autofitrows/" target="_blank" rel="nofollow noopener noreferrer">AutoFitRows</a> propiedad a `true`:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CsvLoadOptions
{
    AutoFitRows = true
};
using (Converter converter = new Converter("sample.csv", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

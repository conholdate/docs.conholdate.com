<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationLoadOptions</a> para permitirle controlar cómo se convertirá una presentación de Microsoft PowerPoint u Open Document al formato de destino. Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga; sin embargo, puede especificar explícitamente el tipo del documento de presentación de origen. Las opciones disponibles son: *Ppt, Pps, Pptx, Ppsx, Odp, Otp, Potx, Pot, Potm, Pptm, Ppsm* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** | Fuente predeterminada para renderizar la presentación. Esta fuente se utilizará si falta alguna fuente de la presentación. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/fontsubstitutes" target="_blank" rel="nofollow noopener noreferrer">FontSubstitutes</a>** | Sustituye fuentes específicas del documento de presentación de origen. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/hidecomments" target="_blank" rel="nofollow noopener noreferrer">HideComments</a>** | Indica que los comentarios de la presentación de origen deben ocultarse durante la conversión |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** | Contraseña para desbloquear el documento protegido |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/showhiddenslides" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a>** | Indica que las diapositivas ocultas deben incluirse en el documento convertido |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/skipexternalresources" target="_blank" rel="nofollow noopener noreferrer">SkipExternalResources</a>** | Si se habilita, los recursos externos (excepto aquellos enumerados en `WhitelistedResources`) no se cargarán durante la conversión. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/whitelistedresources" target="_blank" rel="nofollow noopener noreferrer">WhitelistedResources</a>** | Especifica qué recursos externos se cargarán incluso cuando la carga de otros recursos externos esté restringida. |

## Ocultar comentarios {#hide-comments}

Como muchas otras aplicaciones de Microsoft Office, PowerPoint ofrece la función de “Comentarios” para facilitar la revisión de la presentación. De forma predeterminada, el panel de Comentarios estará presente en el documento convertido. Si desea ocultar los comentarios, establezca la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/hidecomments" target="_blank" rel="nofollow noopener noreferrer">HideComments</a> en *true*, como se muestra en el siguiente fragmento de código:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PresentationLoadOptions
{
    HideComments = true
};
using (Converter converter = new Converter("sample.pptx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Especificar sustituciones de fuentes {#specify-font-substitutions}

Las presentaciones de PowerPoint originales pueden utilizar fuentes específicas y no estándar para el formato de texto que no están disponibles en el momento de la conversión. GroupDocs.Conversion para .NET le permite proporcionar sustituciones para las fuentes que faltan configurando la colección <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/fontsubstitutes" target="_blank" rel="nofollow noopener noreferrer">FontSubstitues</a> con pares de fuentes originales/sustitutas.

El siguiente fragmento de código muestra cómo convertir una presentación PPTX y especificar sustituciones para las fuentes que faltan:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PresentationLoadOptions
{
    DefaultFont = "Helvetica",
    FontSubstitutes = new List<FontSubstitute>
    {
       FontSubstitute.Create("Tahoma", "Arial"),
       FontSubstitute.Create("Times New Roman", "Arial"),
    }
};
using (Converter converter = new Converter("sample.pptx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Incluir diapositivas ocultas {#include-hidden-slides}

Al igual que puede mostrar u ocultar diapositivas manualmente en una presentación de Microsoft PowerPoint, GroupDocs.Conversion para .NET permite mostrar programáticamente las diapositivas ocultas en el documento convertido (de forma predeterminada, todas las diapositivas ocultas se excluyen del documento convertido). Solo debe establecer la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/presentationloadoptions/showhiddenslides" target="_blank" rel="nofollow noopener noreferrer">ShowHiddenSlides</a> en *true*.

El siguiente fragmento de código muestra cómo convertir una presentación PPTX incluyendo las diapositivas ocultas:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PresentationLoadOptions
{
    ShowHiddenSlides = true
};
using (Converter converter = new Converter("sample.pptx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Omitir la carga de recursos externos {#skip-loading-of-external-resources}

En el contexto de las presentaciones, los recursos externos suelen referirse a elementos o materiales que no están incrustados directamente en el archivo de presentación, sino que se hacen referencia o enlazan para mejorar el contenido o la funcionalidad de la presentación. Estos recursos externos pueden incluir diversos tipos de contenido y herramientas que complementan la presentación. Entre los recursos externos más comunes se encuentran imágenes, audio, video, fuentes, estilos, fuentes de datos, entre otros. 

En algunos casos, es posible que desee omitir la carga de todos los recursos externos o solo de algunos durante la conversión. Por ejemplo, cuando estos recursos ya no estén disponibles. Consulte el artículo [Omitir la carga de recursos externos](/net/conversion/developer-guide/advanced-usage/loading/skip-external-resources/) para aprender cómo hacerlo con **GroupDocs.Conversion for .NET**.

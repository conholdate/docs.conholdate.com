<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/diagramloadoptions" target="_blank" rel="nofollow noopener noreferrer">DiagramLoadOptions</a> para controlar cómo se procesan los archivos de diagrama de origen. Los archivos de diagrama incluyen formatos como VSD, VSDX, VDX, VSDM, VSSX y otros formatos de Microsoft Visio.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/diagramloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles incluyen: *Vsd, Vsdx, Vsx, Vtx, Vdx, Vssx, Vstx, Vsdm, Vssm, Vstm* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/diagramloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** | Fuente predeterminada para renderizar el diagrama. Esta fuente se utilizará si falta alguna fuente del diagrama. |

## Cargar archivo VSD {#load-vsd-file}

El siguiente fragmento de código muestra cómo cargar un archivo VSD (Visio Drawing) con especificación explícita del formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new DiagramLoadOptions
{
    Format = DiagramFileType.Vsd
};

using (Converter converter = new Converter("design-diagram.vsd", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("design-diagram.pdf", options);
}
```

## Cargar VSD con fuente predeterminada {#load-vsd-with-default-font}

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new DiagramLoadOptions
{
    Format = DiagramFileType.Vsd,
    DefaultFont = "Arial"
};

using (Converter converter = new Converter("network-diagram.vsd", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("network-diagram.pdf", options);
}
```

## Convertir entre formatos de diagramas {#convert-between-diagram-formats}

El siguiente fragmento de código muestra cómo convertir del formato VSD a VSDX:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new DiagramLoadOptions
{
    Format = DiagramFileType.Vsd
};

using (Converter converter = new Converter("legacy-diagram.vsd", getLoadOptions))
{
    DiagramConvertOptions options = new DiagramConvertOptions
    {
        Format = DiagramFileType.Vsdx
    };
    converter.Convert("legacy-diagram.vsdx", options);
}
```

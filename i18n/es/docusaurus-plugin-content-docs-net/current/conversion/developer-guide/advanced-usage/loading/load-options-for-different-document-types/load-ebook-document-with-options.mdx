## Introducción {#introduction}

La clase **EBookLoadOptions** le permite configurar cómo se cargan los documentos de libros electrónicos (ebooks) en GroupDocs.Conversion. Esta clase admite los formatos de ebook más populares utilizados en diversas plataformas y dispositivos de lectura.

EBookLoadOptions funciona con formatos de ebook comunes, incluidos MOBI (Kindle), EPUB (estándar universal) y AZW3 (Kindle Fire).

## Propiedades {#properties}

| Propiedad | Tipo | Descripción |
| ---------- | ------ | ------------- |
| `Format` | `EBookFileType` | El formato de entrada del ebook (solo lectura; get;) |

## Uso básico {#basic-usage}

En la mayoría de los escenarios, GroupDocs.Conversion detecta automáticamente el formato del ebook:

```csharp
using (var converter = new Converter("digital-novel.mobi"))
{
    converter.Convert("digital-novel.pdf", new PdfConvertOptions());
}
```

## Uso de EBookLoadOptions con LoadContext {#using-ebookloadoptions-with-loadcontext}

Cuando necesite un control explícito sobre el comportamiento de carga, utilice EBookLoadOptions con el patrón de delegado LoadContext:

```csharp
using (var converter = new Converter(
    "technical-manual.epub",
    (LoadContext loadContext) => new EBookLoadOptions()))
{
    converter.Convert("technical-manual.pdf", new PdfConvertOptions());
}
```

### EBook a PDF {#ebook-to-pdf}

Convierta libros electrónicos a PDF para garantizar compatibilidad universal e impresión:

using (var converter = new Converter(

    (LoadContext loadContext) => new EBookLoadOptions()))

    converter.Convert("cookbook-recipes.pdf", new PdfConvertOptions());

## Trabajo con distintos formatos de libros electrónicos {#working-with-different-ebook-formats}

GroupDocs.Conversion admite múltiples formatos de libros electrónicos mediante `EBookLoadOptions`. Cada formato debe especificarse explícitamente:

### MOBI (Mobipocket) {#mobi-mobipocket}

MOBI es un formato ampliamente utilizado, especialmente para dispositivos Amazon Kindle:

```csharp
using (var converter = new Converter(
    "mystery-novel.mobi",
    (LoadContext loadContext) => new EBookLoadOptions
    {
        Format = EBookFileType.Mobi
    }))
{
    converter.Convert("mystery-novel.pdf", new PdfConvertOptions());
}
```

### EPUB (Publicación Electrónica) {#epub-electronic-publication}

EPUB es un formato de código abierto admitido por la mayoría de los lectores de libros electrónicos:

```csharp
using (var converter = new Converter(
    "user-manual.epub",
    (LoadContext loadContext) => new EBookLoadOptions
    {
        Format = EBookFileType.Epub
    }))
{
    converter.Convert("user-manual.docx", new WordProcessingConvertOptions());
}
```

### AZW3 (Kindle Format 8) {#azw3-kindle-format-8}

AZW3 es el formato moderno de libros electrónicos de Amazon, que incluye funciones mejoradas:

```csharp
using (var converter = new Converter(
    "reference-book.azw3",
    (LoadContext loadContext) => new EBookLoadOptions
    {
        Format = EBookFileType.Azw3
    }))
{
    converter.Convert("reference-book.html", new WebConvertOptions());
}
```

## Formatos de libro electrónico compatibles {#supported-ebook-formats}

EBookLoadOptions funciona con:
- **MOBI** – formato Mobipocket (Amazon Kindle)
- **EPUB** – Publicación electrónica (estándar universal)
- **AZW3** – Kindle Format 8 (Kindle Fire y dispositivos más recientes)

## Casos de uso comunes {#common-use-cases}

Utilice EBookLoadOptions cuando necesite:

1. **Convertir publicaciones digitales** – Transformar libros electrónicos en formatos adecuados para distintas plataformas
2. **Crear versiones imprimibles** – Convertir libros electrónicos a PDF para impresión física
3. **Extraer contenido** – Convertir libros electrónicos a Word o HTML para edición y reutilización del contenido
4. **Compatibilidad multiplataforma** – Convertir entre distintos formatos de libro electrónico (por ejemplo, EPUB a MOBI)
5. **Flujos de trabajo editoriales** – Integrar la conversión de libros electrónicos en pipelines editoriales digitales

## Cuándo utilizar EBookLoadOptions {#when-to-use-ebookloadoptions}

Utilice EBookLoadOptions cuando:

- Trabaje con formatos de libro electrónico (MOBI, EPUB, AZW3)
- Convierta publicaciones digitales a otros formatos
- Desarrolle sistemas de gestión o publicación de libros electrónicos
- Genere salidas en múltiples formatos a partir de fuentes de libros electrónicos
- Necesite un control explícito sobre la carga de documentos de libro electrónico

## Sin EBookLoadOptions {#without-ebookloadoptions}

Para conversiones sencillas, puede confiar en la detección automática de formatos:

```csharp
using (var converter = new Converter("digital-novel.mobi"))
{
    converter.Convert("digital-novel.pdf", new PdfConvertOptions());
}
```

GroupDocs.Conversion detecta automáticamente el formato de libro electrónico en la mayoría de los casos, por lo que EBookLoadOptions es opcional, a menos que necesite una configuración específica de carga.

## Compatibilidad con formatos de salida {#output-format-compatibility}

Los libros electrónicos pueden convertirse en diversos formatos de salida:

- **Formatos de documento**: PDF, DOCX, RTF, TXT
- **Formatos web**: HTML, MHTML
- **Formatos de hojas de cálculo**: XLSX, XLS
- **Formatos de presentación**: PPTX, PPT
- **Otros formatos de libro electrónico**: EPUB, MOBI, AZW3

**Nota**: Los formatos de imagen (PNG, JPG) requieren una conversión página por página mediante SavePageContext, ya que los libros electrónicos son documentos multipágina.

<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions" target="_blank" rel="nofollow noopener noreferrer">CadLoadOptions</a> para brindarle control sobre cómo se procesará el documento CAD de origen. Se pueden configurar las siguientes opciones:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento de origen se detecta automáticamente, pero puede establecer explícitamente el formato del documento de origen mediante esta propiedad. Las opciones disponibles son: Dxf, Dwg, Dgn, Dwf, Stl, Ifc, Plt, Igs, Dwt |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/backgroundcolor/" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a>** | Especifica el color de fondo para un documento CAD. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/drawtype/" target="_blank" rel="nofollow noopener noreferrer">DrawType</a>** | Especifica el tipo de dibujo de un documento CAD. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Establece el ancho de página deseado |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Establece la altura de página deseada |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/cadloadoptions/layoutnames" target="_blank" rel="nofollow noopener noreferrer">LayoutNames</a>** | Especifica qué diseño CAD se convertirá |

### Especificar los diseños que se convertirán {#specify-layouts-to-be-converted}

El siguiente fragmento de código muestra cómo convertir un documento CAD y convertir únicamente ciertos diseños:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CadLoadOptions
{
    LayoutNames = new []{ "Layout1", "Layout3" }
};
using (Converter converter = new Converter("with_layers_and_layouts.dwg", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Especificar color de fondo {#specify-background-color}

El siguiente fragmento de código muestra cómo convertir un documento CAD y especificar su color de fondo deseado:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CadLoadOptions
{
    BackgroundColor = System.Drawing.Color.White
};
using (Converter converter = new Converter("sample.dwg", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

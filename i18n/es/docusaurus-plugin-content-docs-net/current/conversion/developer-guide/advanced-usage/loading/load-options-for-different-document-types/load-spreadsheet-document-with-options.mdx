<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/spreadsheetloadoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLoadOptions</a>, que controla cómo se procesará la hoja de cálculo de origen. A continuación se muestran algunas de las opciones de carga que puede utilizar al [convertir hojas de cálculo](/net/conversion/developer-guide/basic-usage/convert/spreadsheet/):

Sin embargo, puede especificar explícitamente el tipo del documento de hoja de cálculo de origen. ### Ocultar comentarios {#hide-comments}

El siguiente fragmento de código muestra cómo convertir una hoja de cálculo y ocultar los comentarios:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new SpreadsheetLoadOptions
{
    HideComments = true,
    OnePagePerSheet = true
};
using (Converter converter = new Converter("sample.xlsx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Especificar sustitución de fuentes {#specify-font-substitution}

El siguiente fragmento de código muestra cómo convertir una hoja de cálculo y especificar la sustitución de fuentes para las fuentes que faltan:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new SpreadsheetLoadOptions
{
    DefaultFont = "Helvetica",
    FontSubstitutes = new List<FontSubstitute>
    {
        FontSubstitute.Create("Tahoma", "Arial"),
        FontSubstitute.Create("Times New Roman", "Arial"),
    },
    OnePagePerSheet = true
};
using (Converter converter = new Converter("sample.xlsx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Especificar hojas concretas {#specify-particular-sheets}

Puede especificar las hojas que se van a convertir ya sea por sus nombres o por sus índices. 

El siguiente fragmento de código muestra cómo convertir una hoja de cálculo y especificar las hojas deseadas por sus nombres:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new SpreadsheetLoadOptions
{
    Sheets = new[] {"Expenses", "Taxes" },
    OnePagePerSheet = true
};
using (Converter converter = new Converter("sample.xlsx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

El siguiente fragmento de código muestra cómo convertir una hoja de cálculo y especificar las hojas deseadas mediante sus índices basados en cero:

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new SpreadsheetLoadOptions
{

using (Converter converter = new Converter("sample.xlsx", getLoadOptions))

### Ajustar automáticamente las filas {#automatically-fit-rows}

Para ajustar el contenido de todas las filas durante la conversión desde una hoja de cálculo, establezca la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/spreadsheetloadoptions/autofitrows/" target="_blank" rel="nofollow noopener noreferrer">AutoFitRows</a> en `true`:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new SpreadsheetLoadOptions
{
    AutoFitRows = true
};
using (Converter converter = new Converter("sample.xlsx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

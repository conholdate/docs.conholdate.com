<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/wordprocessingloadoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingLoadOptions</a> para permitirle controlar cómo se convertirá el documento de Microsoft Word de origen. Las siguientes opciones pueden configurarse:

Las opciones disponibles son: *Doc, Docm, Docx, Dot, Dotm, Dotx, Rtf, Odt, Ott, Mobi, Txt* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/wordprocessingloadoptions/autofontsubstitution" target="_blank" rel="nofollow noopener noreferrer">AutoFontSubstitution</a>** | Si es `false`, GroupDocs.Conversion utiliza la fuente predeterminada para sustituir las fuentes que faltan. ## Ocultar comentarios {#hide-comments}

Microsoft Word ofrece la función «Comentarios», que permite que varios autores o revisores discutan un documento sin necesidad de trabajar en él simultáneamente. Todos los comentarios añadidos se muestran en un panel situado a la derecha del texto del documento. Tras convertir el documento DOCX que contiene comentarios a otro formato, el panel de Comentarios también permanece presente en el documento resultante. Si es necesario ocultar los comentarios en el documento convertido de forma programática, puede utilizar el siguiente ejemplo de código, que requiere solo unas pocas líneas de código en C#:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new WordProcessingLoadOptions
{
    HideComments = true
};
using (Converter converter = new Converter("sample.docx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Ocultar los cambios rastreados {#hide-tracked-changes}

El rastreo de cambios es otra función de Microsoft Word que facilita la colaboración durante la corrección y revisión de documentos: es como marcar errores con una pluma y tomar algunas notas en los márgenes. Todos los cambios realizados por los compañeros de trabajo se resaltan y pueden rechazarse o aceptarse, convirtiéndose así en permanentes. De forma predeterminada, el panel de rastreo de cambios también se mostrará al convertir un documento DOCX a otro formato; sin embargo, existe una opción para ocultarlo completamente mediante la API de GroupDocs.Conversion para .NET. 

El siguiente fragmento de código muestra cómo convertir un documento DOCX a PDF y ocultar el panel de cambios rastreados:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new WordProcessingLoadOptions
{
    HideWordTrackedChanges = true
};
using (Converter converter = new Converter("sample.docx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Especificar sustitución de fuentes {#specify-font-substitution}

El contenido de documentos de Microsoft Word suele estar formateado con distintas fuentes, como Arial, Calibri, Times New Roman, etc., y estas fuentes suelen almacenarse en el equipo donde el documento se creó o editó originalmente. A veces, durante la conversión de un documento DOCX a otro formato, algunas fuentes utilizadas por el documento no están disponibles en el equipo donde se realiza la conversión. Como resultado, el documento convertido puede verse muy distinto del archivo original.

Por supuesto, GroupDocs.Conversion para .NET intentará seleccionar la sustitución de fuentes más adecuada a partir de las fuentes disponibles y de las fuentes incrustadas en el documento original, pero también puedes especificar explícitamente la sustitución de fuentes. Para ello, basta con invocar el método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/fontsubstitute/create" target="_blank" rel="nofollow noopener noreferrer">Create</a> de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/fontsubstitute" target="_blank" rel="nofollow noopener noreferrer">FontSubstitute</a> y proporcionar los nombres de la fuente original y la fuente de sustitución.

El siguiente fragmento de código muestra cómo convertir un documento DOCX aplicando sustitución de fuentes para las fuentes que faltan:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new WordProcessingLoadOptions
{
    AutoFontSubstitution = false,
	DefaultFont = "Helvetica",
    FontSubstitutes = new List<FontSubstitute>
    {
        FontSubstitute.Create("Tahoma", "Arial"),
        FontSubstitute.Create("Times New Roman", "Arial"),
    }
};
using (Converter converter = new Converter("sample.docx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Omitir la carga de recursos externos {#skip-loading-of-external-resources}

En el contexto de documentos de procesamiento de texto, los recursos externos hacen referencia a cualquier elemento, material o dato que no esté incrustado directamente en el documento, sino que se haga referencia a él o se enlace a él para mejorar el contenido o la funcionalidad del documento. Estos recursos externos pueden adoptar diversas formas y suelen utilizarse para complementar el texto y mejorar la calidad general y el nivel de detalle del documento. Entre los recursos externos más comunes se incluyen imágenes y gráficos, tablas y hojas de cálculo, audio y video, fuentes, estilos, fuentes de datos, ecuaciones matemáticas, entre otros. 

En algunos casos, es posible que desee omitir la carga de todos los recursos externos o solo de algunos durante la conversión. Por ejemplo, cuando estos recursos ya no estén disponibles. Consulte el artículo [Omitir la carga de recursos externos](/net/conversion/developer-guide/advanced-usage/loading/skip-external-resources/) para aprender cómo hacerlo con **GroupDocs.Conversion for .NET**.

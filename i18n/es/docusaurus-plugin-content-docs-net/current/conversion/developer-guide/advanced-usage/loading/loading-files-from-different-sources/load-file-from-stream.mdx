Puede darse el caso de que su archivo no se encuentre físicamente en el disco. En su lugar, dispone del archivo en forma de flujo (stream). En este caso, para evitar la sobrecarga de guardar el flujo como archivo en el disco, <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> le permite convertir directamente los flujos de archivos.

Para cargar un archivo desde un flujo, siga estos pasos:

1.  Especifique el método para obtener el flujo del archivo.
2.  Pase el nombre del método al constructor de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>.

El siguiente fragmento de código cumple esta finalidad:

```csharp
public static void Run()
{
    // Pass the source stream as parameter
    using (Converter converter = new Converter(GetFileStream)) 
    {
        PdfConvertOptions options = new PdfConvertOptions();
        converter.Convert("converted.pdf", options);
    }
}

// Obtain the stream for the source file
private static Stream GetFileStream() => File.OpenRead("sample.docx");
```
El fragmento anterior utiliza `FileStream` clase de instancia. Del mismo modo, puedes utilizar cualquier otro tipo de flujo. Solo asegúrate de que el flujo de origen contenga alguno de los [Formatos de archivo compatibles](/net/conversion/getting-started/supported-document-formats/). Por ejemplo, el siguiente código carga un archivo utilizando el `MemoryStream` clase instancia:

```csharp
public static void Run()
{
    // Pass the source stream as parameter
    using (Converter converter = new Converter(GetMemoryStream)) 
    {
        PdfConvertOptions options = new PdfConvertOptions();
        converter.Convert("converted.pdf", options);
    }
}

// Obtain the stream for the source file
private static Stream GetMemoryStream()
{
    MemoryStream memStream = new MemoryStream();

    using (FileStream fStream = File.Open("sample.docx", FileMode.Open))
    {
        fStream.CopyTo(memStream);
    }
    return memStream;
}
```

## Obtener información sobre archivos desde un flujo {#get-information-about-files-from-a-stream}
Al cargar archivos desde un flujo, es posible que no sepa de antemano los tipos exactos de archivos que está recibiendo. Sin embargo, para obtener esta y otra información sobre el archivo de origen, puede utilizar el método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Converter.GetDocumentInfo()</a>, como se describe en el artículo [Obtener información del documento](/net/conversion/developer-guide/basic-usage/get-document-info/).

El siguiente código muestra el formato del archivo de origen cargado desde un flujo:
```csharp
public static void Run()
{
    // Pass the source stream as parameter
    using (Converter converter = new Converter(GetFileStream)) 
    {
        IDocumentInfo docInfo = converter.GetDocumentInfo();
        Console.WriteLine("Source file format: {0}", docInfo.Format);

        PdfConvertOptions options = new PdfConvertOptions();
        converter.Convert("converted.pdf", options);
    }
}

// Obtain the stream for the source file
private static Stream GetFileStream() => File.OpenRead("sample.docx");
```

**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** le permite obtener las opciones de carga predeterminadas para el formato del documento de origen. Esto le permitirá obtener las opciones de carga predeterminadas en tiempo de ejecución, conociendo el formato de origen.

Para obtener las opciones predeterminadas, siga estos pasos:

1.   Llame al método estático <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions/" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversion</a> de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>, pasando como parámetro la extensión del archivo de origen.
2.   A partir de los resultados posibles de conversión recibidos, lea la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>.
3.   Cree una instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> y pase la ruta del documento de origen como parámetro del constructor, junto con las opciones de carga obtenidas en el paso anterior.
4.   Instancie la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> correspondiente, por ejemplo (**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>**, etc.).
5.   Llame al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> de la instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>, pasando el nombre de archivo para el documento convertido y la instancia de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> obtenida en el paso anterior.

El siguiente fragmento de código muestra cómo obtener las opciones de carga predeterminadas para un documento de procesamiento de textos:

```csharp
var possibleConversions = Converter.GetPossibleConversions("docx");
var loadOptions = (WordProcessingLoadOptions) possibleConversions.LoadOptions;
loadOptions.Password = "12345";

using (Converter converter = new Converter("password_protected.docx", (LoadContext loadContext) => loadOptions))
{
    var convertOptions = new PdfConvertOptions();
    converter.Convert(outputFile, convertOptions);
}
```

GroupDocs.Conversion proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/xmlloadoptions" target="_blank" rel="nofollow noopener noreferrer">XmlLoadOptions</a> para permitirle controlar cómo se procesará el documento XML de origen. Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/basepath" target="_blank" rel="nofollow noopener noreferrer">BasePath</a>** | Especifica la ruta/URL base para el HTML |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>** | Especifica la codificación que se utilizará para cargar el documento. Si no se especifica, la codificación se determinará a partir del atributo de conjunto de caracteres del documento |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/loadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | Tipo de archivo del documento de entrada |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/pagenumbering" target="_blank" rel="nofollow noopener noreferrer">PageNumbering</a>** | Indica si se deben generar números de página para el documento convertido. Valor predeterminado: false |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/resourceloadingtimeout" target="_blank" rel="nofollow noopener noreferrer">ResourceLoadingTimeout</a>** | Especifica el tiempo de espera para cargar los recursos externos. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/skipexternalresources" target="_blank" rel="nofollow noopener noreferrer">SkipExternalResources</a>** | Si se habilita, los recursos externos (excepto los enumerados en `WhitelistedResources`) no se cargarán durante la conversión. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/xmlloadoptions/useasdatasource" target="_blank" rel="nofollow noopener noreferrer">UseAsDataSource</a>** | Utilizar el documento XML de origen como fuente de datos |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/webloadoptions/whitelistedresources" target="_blank" rel="nofollow noopener noreferrer">WhitelistedResources</a>** | Especifica qué recursos externos se cargarán incluso cuando la carga de otros recursos externos esté restringida. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/xmlloadoptions/xslfofactory" target="_blank" rel="nofollow noopener noreferrer">XslFoFactory</a>** | Flujo de documento XSL para convertir XML-FO mediante XSL. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/xmlloadoptions/xsltfactory/" target="_blank" rel="nofollow noopener noreferrer">XsltFactory</a>** | Flujo de documento XSLT para convertir XML realizando una transformación XSL a HTML. |

### Convertir XML como fuente de datos a una hoja de cálculo {#convert-xml-as-a-data-source-to-a-spreadsheet}

El siguiente fragmento de código muestra cómo utilizar XML como fuente de datos y convertirlo a una hoja de cálculo:

```csharp
using (Converter converter = new Converter("data.xml", (LoadContext loadContext) => new XmlLoadOptions
{
    UseAsDataSource = true
}))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions();
    converter.Convert("converted.xlsx", options);
}
```

### Convertir XML transformado mediante XSLT a un PDF: {#convert-xml-transformed-through-xslt-to-a-pdf}

El siguiente código muestra cómo convertir un XML transformado mediante XSLT a un PDF:

```csharp
using (var converter = new Converter("books.xml", (LoadContext loadContext) => new XmlLoadOptions
   {
       XsltFactory = () => File.OpenRead("books.xsl")
   }))
{
    var options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

## Omitir la carga de recursos externos {#skip-loading-of-external-resources}

Los recursos externos hacen referencia a datos o contenido que se hace referencia o enlaza desde un documento XML, pero que se almacenan por separado, normalmente en archivos o ubicaciones distintas. Entre los recursos externos más comunes se incluyen DTD o esquemas XML, entidades, hojas de estilo XSLT, fuentes de datos, imágenes, multimedia, etc. 

En algunos casos, puede resultar útil omitir la carga de todos los recursos externos o solo de algunos durante la conversión. Por ejemplo, cuando dichos recursos dejan de estar disponibles. Consulte el artículo [Omitir la carga de recursos externos](/net/conversion/developer-guide/advanced-usage/loading/skip-external-resources/) para aprender cómo hacerlo con **GroupDocs.Conversion for .NET**.

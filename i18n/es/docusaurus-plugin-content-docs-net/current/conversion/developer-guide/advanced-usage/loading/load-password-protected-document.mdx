<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> admite la conversión de documentos protegidos con contraseña.

Para cargar y convertir un documento protegido por contraseña, siga estos pasos:

1.   Define una `Func`&lt;<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>&gt; delegado, que debe devolver una instancia de las opciones de carga específicas del documento con la contraseña especificada.
2.   Cree una instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> clase y pase la ruta del documento de origen y el delegado de opciones de carga como parámetros del constructor.
3.   Instanciar el apropiado <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> clase, por ejemplo, (**<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>**, **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/spreadsheetconvertoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetConvertOptions</a>**, etc.)
4.   Llame a <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> método de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> clase de instancia y pasar el nombre de archivo para el documento convertido y la instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> del paso anterior.

El siguiente fragmento de código muestra cómo convertir un documento protegido por contraseña:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new WordProcessingLoadOptions
{
    Password = "12345"
};
using (Converter converter = new Converter("sample_with_password.docx", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

También puedes usar [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/):

```csharp
FluentConverter
    .Load("sample_with_password.docx").WithOptions((LoadContext loadContext) => new WordProcessingLoadOptions
    {
        Password = "12345"
    })
    .ConvertTo("converted.pdf")
    .Convert();
```

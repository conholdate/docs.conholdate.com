<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions" target="_blank" rel="nofollow noopener noreferrer">NoteLoadOptions</a> para permitirle controlar cómo se procesará el documento de Nota de origen. Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** | Fuente predeterminada para el documento de Nota. La fuente especificada se utilizará si falta una fuente. Debe proporcionarse una ruta absoluta al archivo de fuente. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions/fontsubstitutes" target="_blank" rel="nofollow noopener noreferrer">FontSubstitutes</a>** | Sustituye fuentes específicas del documento de Nota. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** | Contraseña para desbloquear el documento protegido. |

### Configurar fuente predeterminada {#set-default-font}

GroupDocs.Conversion para .NET le permite establecer un nombre de fuente predeterminada cuando una fuente no está disponible en el documento. Puede utilizar la propiedad **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** de la clase **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions" target="_blank" rel="nofollow noopener noreferrer">NoteLoadOptions</a>** para establecer el nombre de la fuente predeterminada. En caso de que **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/noteloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** no se configure, se utilizará la fuente Times New Roman. El siguiente fragmento de código muestra cómo establecer un nombre de fuente predeterminada al convertir un documento de Nota a PDF:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new NoteLoadOptions
{
    DefaultFont = "Helvetica"
};
using (Converter converter = new Converter("sample.one", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

### Especificar sustitución de fuentes {#specify-font-substitution}

El siguiente fragmento de código muestra cómo convertir un documento de Note y especificar la sustitución de fuentes para las fuentes que faltan:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new NoteLoadOptions
{
    FontSubstitutes = new List<FontSubstitute>
    {
        FontSubstitute.Create("Tahoma", "Arial"),
        FontSubstitute.Create("Times New Roman", "Arial"),
    }
};
using (Converter converter = new Converter("sample.one", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.pdf", options);
}
```

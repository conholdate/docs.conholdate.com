<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions" target="_blank" rel="nofollow noopener noreferrer">CompressionLoadOptions</a> para controlar cómo se procesan los archivos comprimidos de origen. Los archivos comprimidos incluyen formatos como ZIP, 7Z, RAR, TAR, GZIP y otros formatos de archivo.

Las siguientes opciones están disponibles:

| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga, pero puede especificar explícitamente el formato de origen. Las opciones disponibles incluyen: *SevenZ, Bz2, Cab, Cpio, Gz, Gzip, Lz, Lzma, Rar, Tar, Xz, Z, Zip* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** | Establecer contraseña para cargar un archivo protegido |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/convertowned" target="_blank" rel="nofollow noopener noreferrer">ConvertOwned</a>** | Los documentos propietarios se convertirán (solo lectura, valor predeterminado: true) |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/convertowner" target="_blank" rel="nofollow noopener noreferrer">ConvertOwner</a>** | El propietario no se convertirá (solo lectura, valor predeterminado: false) |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/compressionloadoptions/depth" target="_blank" rel="nofollow noopener noreferrer">Depth</a>** | Controla la profundidad de recursión para documentos anidados. El valor predeterminado es 3. |

## Cargar archivo ZIP {#load-zip-archive}

El siguiente fragmento de código muestra cómo cargar un archivo ZIP especificando explícitamente el formato:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip
};

using (Converter converter = new Converter("documents-archive.zip", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("documents-archive.pdf", options);
}
```

## Convertir entre formatos de compresión {#convert-between-compression-formats}

El siguiente fragmento de código muestra cómo convertir del formato ZIP a 7Z:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip
};

using (Converter converter = new Converter("source-archive.zip", getLoadOptions))
{
    CompressionConvertOptions options = new CompressionConvertOptions
    {
        Format = CompressionFileType.SevenZ
    };
    converter.Convert("source-archive.7z", options);
}
```

## Cargar archivo ZIP protegido con contraseña {#load-password-protected-archive}

El siguiente fragmento de código muestra cómo cargar un archivo ZIP protegido con contraseña:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;
using GroupDocs.Conversion.Options.Load;

Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new CompressionLoadOptions
{
    Format = CompressionFileType.Zip,
    Password = "archive-password"
};

using (Converter converter = new Converter("protected-archive.zip", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("protected-archive.pdf", options);
}
```

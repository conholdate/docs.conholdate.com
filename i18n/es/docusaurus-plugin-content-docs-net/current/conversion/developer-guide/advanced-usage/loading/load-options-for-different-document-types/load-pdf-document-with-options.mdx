<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions" target="_blank" rel="nofollow noopener noreferrer">PdfLoadOptions</a> para permitirle controlar cómo se procesará el documento PDF de origen. Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/format" target="_blank" rel="nofollow noopener noreferrer">Format</a>** | El tipo de documento se detecta automáticamente durante la carga; sin embargo, puede especificar explícitamente el tipo del documento de origen. Las opciones disponibles son: *Pdf, Epub, Xps, Tex, Ps, Pcl* |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/defaultfont/" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** | Fuente predeterminada para el documento PDF. La fuente especificada se utilizará si falta alguna fuente en el documento. Debe proporcionarse una ruta absoluta al archivo de fuente. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/flattenallfields" target="_blank" rel="nofollow noopener noreferrer">FlattenAllFields</a>** | Indica que todos los campos del documento de origen deben aplanarse durante la conversión. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/fontsubstitutes" target="_blank" rel="nofollow noopener noreferrer">FontSubstitutes</a>** | Sustituye fuentes específicas del documento de origen. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/hidepdfannotations" target="_blank" rel="nofollow noopener noreferrer">HidePdfAnnotations</a>** | Indica que las anotaciones del documento de origen deben ocultarse. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a>** | Contraseña para desbloquear el documento protegido. |
| **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/removeembeddedfiles" target="_blank" rel="nofollow noopener noreferrer">RemoveEmbeddedFiles</a>** | Determina si se deben eliminar los archivos incrustados del documento de origen durante la conversión. |

### Aplanar todos los campos {#flatten-all-fields}

El siguiente fragmento de código muestra cómo convertir un documento PDF y aplanar todos sus campos:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PdfLoadOptions
{
    FlattenAllFields = true
};
using (Converter converter = new Converter("sample.pdf", getLoadOptions))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions();
    converter.Convert("converted.docx", options);
}
```

### Establecer la fuente predeterminada {#set-default-font}

GroupDocs.Conversion para .NET le permite establecer un nombre de fuente predeterminado cuando una fuente no está disponible en el documento. Puede utilizar la propiedad **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** de la clase **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions" target="_blank" rel="nofollow noopener noreferrer">PdfLoadOptions</a>** para establecer el nombre de la fuente predeterminada. En caso de que la propiedad **<a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load/pdfloadoptions/defaultfont" target="_blank" rel="nofollow noopener noreferrer">DefaultFont</a>** no esté configurada, se utilizará la fuente Times New Roman. El siguiente fragmento de código muestra cómo establecer un nombre de fuente predeterminado al convertir desde un documento PDF a un documento de procesamiento de texto:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PdfLoadOptions
{
    DefaultFont = "Helvetica"
};
using (Converter converter = new Converter("sample.pdf", getLoadOptions))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions();
    converter.Convert("converted.docx", options);
}
```

### Especificar sustitución de fuentes {#specify-font-substitution}

El siguiente fragmento de código muestra cómo convertir un documento PDF y especificar la sustitución de fuentes para las fuentes que faltan:

```csharp
Func<LoadContext, LoadOptions> getLoadOptions = loadContext => new PdfLoadOptions
{
    FontSubstitutes = new List<FontSubstitute>
    {
        FontSubstitute.Create("Tahoma", "Arial"),
        FontSubstitute.Create("Times New Roman", "Arial"),
    }
};
using (Converter converter = new Converter("sample.pdf", getLoadOptions))
{
    PdfConvertOptions options = new PdfConvertOptions();
    converter.Convert("converted.docx", options);
}
```

Los formatos de archivo de correo electrónico los utilizan las aplicaciones de correo electrónico para almacenar diversos datos, como mensajes de correo electrónico, archivos adjuntos, carpetas, libretas de direcciones, etc. Estos formatos de archivo suelen asociarse principalmente con los archivos de mensajes de correo electrónico de Outlook Express. Además, otros tipos de archivos también podrían utilizar la extensión de archivo de correo electrónico.

## Convertir desde formatos de correo electrónico {#convert-from-email-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir MSG a PDF sería como sigue:

```csharp
// Load the source MSG file
using (var converter = new GroupDocs.Conversion.Converter("sample.msg"))
{
    // Set the convert options for PDF format
   var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo de forma sencilla: simplemente carga un archivo MSG en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.

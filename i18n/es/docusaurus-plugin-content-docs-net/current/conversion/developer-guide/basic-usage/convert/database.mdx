Una base de datos es una colección de datos organizados en tablas y almacenados en un dispositivo de almacenamiento informático, al que se accede electrónicamente. Las bases de datos relacionales almacenan datos en tablas de base de datos que están vinculadas entre sí mediante técnicas formales de diseño y modelado. Los datos de una base de datos se analizan mediante el Sistema Gestor de Bases de Datos (DBMS, por sus siglas en inglés), que constituye la principal fuente de interacción con los usuarios finales, las aplicaciones y la propia base de datos.

Las extensiones y formatos de archivo de base de datos más populares incluyen SQLite, DB, ACCDB y MDB.

## Convertir desde formatos de base de datos {#convert-from-database-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>, puede convertir fácilmente su documento a otro formato de archivo.  
Por ejemplo, un fragmento de código para convertir un archivo LOG a PDF sería el siguiente:

```csharp
// Load the source LOG file
using (var converter = new GroupDocs.Conversion.Converter("sample.log"))
{
    // Set the convert options for PDF format
   var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo simplemente: solo carga un archivo LOG en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.

**<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** ofrece una forma rápida y sencilla de convertir archivos desde un formato de origen hacia diversas gamas de formatos de destino. Desde el punto de vista del usuario, el proceso de conversión es bastante simple: el documento de origen se carga en un convertidor y, una vez completada la conversión, el resultado se guarda en una ruta de archivo deseada en el disco local u otro almacenamiento.  
  
De forma predeterminada, al realizar cálculos internos, **GroupDocs.Conversion para .NET** utiliza cierta configuración predefinida que resulta más adecuada para cargar y guardar formatos de archivo específicos. Sin embargo, el proceso de conversión siempre puede ajustarse mediante la configuración de <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.load" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> específicos, con el fin de modificar la forma en que se carga el documento de origen; por ejemplo, es necesario ocultar los comentarios del documento, configurar la sustitución de fuentes, establecer contraseñas para documentos protegidos, etc. Asimismo, la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> se utiliza para gestionar los documentos convertidos: agregar marcas de agua a los documentos resultantes, cambiar la orientación de las páginas, establecer la altura/ancho o la resolución de las imágenes, y muchas más opciones.  
  
El flujo de trabajo de conversión común siempre incluye los siguientes pasos:

1. Cargar el documento de origen en una nueva instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>. Puede proporcionar una ruta de archivo o un flujo de documento.
2. Instanciar el objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> adecuado según sus requisitos y el formato de salida deseado, como <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a>, <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a>, entre otros.
3. Llamar al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_3" target="_blank" rel="nofollow noopener noreferrer">Convert</a> del objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> y pasar la ruta de archivo para guardar el documento resultante, junto con el objeto de opciones de conversión del paso anterior.

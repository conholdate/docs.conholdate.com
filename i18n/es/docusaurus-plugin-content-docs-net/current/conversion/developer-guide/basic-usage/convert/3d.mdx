## Acerca de los formatos de archivos 3D {#about-3d-file-formats}

La representación electrónica de un objeto tridimensional se conoce como archivo 3D. Un formato de archivo 3D se utiliza para almacenar información sobre modelos 3D. Normalmente, almacena información sobre modelos 3D como datos de texto plano o binarios. Existen literalmente cientos de formatos de archivo 3D ampliamente utilizados en juegos 3D, impresión, diseño asistido por computadora (CAD), fabricación, academia, ingeniería y más. Cada industria tiene sus propios formatos de archivo 3D por varias razones.

## Convertir desde formatos 3D {#convert-from-3d-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento 3D a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir de 3D a PDF se ve así:

```csharp
// Load the source 3D file
using (Converter converter = new Converter("sample.3ds"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Pongámoslo simplemente: solo cargas un archivo 3D en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a otro formato 3D {#convert-to-another-3d-format}

Por otro lado, convertir sus archivos a otro formato 3D también es bastante sencillo y natural.
El siguiente fragmento de código muestra cómo convertir un documento 3DS a FBX en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source 3DS file
using (Converter converter = new Converter("sample.3ds"))
{
    // Set the convert options for 3D format
    var options = new ThreeDConvertOptions { 
       Format = ThreeDFileType.Fbx
    };
    // Convert to FBX format
    converter.Convert("converted.fbx", options);
}
```

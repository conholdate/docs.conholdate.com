## Sobre los formatos de archivo de video {#about-video-file-formats}

Todos estamos familiarizados con los videos que vemos diariamente en dispositivos multimedia como televisores, pantallas de cine y canales de redes sociales como Facebook, Twitter, YouTube y muchos otros. ¿Pero alguna vez te has preguntado cómo se almacenan estos videos y en qué formatos pueden subirse para su visualización? ¿Cuál es el mejor formato de archivo para alojar tu video en distintos medios de almacenamiento? Los formatos de archivo de video comprenden muchos tipos distintos de video, destinados a almacenar videos y utilizados para diversos propósitos. Entre los formatos de archivo de video más populares que seguramente ya has conocido se incluyen AVI, MOV, WMV, M4V y MP4.

## Convertir a otro formato de video {#convert-to-another-video-format}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puedes convertir fácilmente tu archivo de video a otro formato de archivo de video.  

Para permitir conversiones de video, GroupDocs.Conversion proporciona un punto de extensión que delega la conversión real del video a una biblioteca de procesamiento de video, al tiempo que te ofrece la simplicidad de configuración de la conversión. El punto de extensión es la interfaz <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.integration.video/ivideoconnector" target="_blank" rel="nofollow noopener noreferrer">IVideoConnector</a>. 

En primer lugar, debes decidir qué biblioteca de procesamiento de video utilizarás. Distintas bibliotecas tienen distintos procesos de configuración.

En nuestro ejemplo, utilizaremos la biblioteca FFMPEG. Recomendamos utilizar <a href="https://chocolatey.org/" target="_blank" rel="nofollow noopener noreferrer">Chocolatey</a> para instalar <a href="https://ffmpeg.org/" target="_blank" rel="nofollow noopener noreferrer">FFMPEG</a> y todas las dependencias necesarias. 
Para instalar FFMPEG con Chocolatey, ejecuta el siguiente comando en la consola:
```shell
choco install ffmpeg
```

Una vez instalada la biblioteca de procesamiento de video, debe implementar la interfaz <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.integration.video/ivideoconnector" target="_blank" rel="nofollow noopener noreferrer">IVideoConnector</a>. Para esta implementación, se debe instalar el paquete NuGet <a href="https://www.nuget.org/packages/FFMpegCore" target="_blank" rel="nofollow noopener noreferrer">FFMpegCore</a>](https://www.nuget.org/packages/FFMpegCore) en su proyecto. El siguiente fragmento proporciona una implementación de ejemplo:

```csharp
public class VideoConnector : IVideoConnector
{
    private readonly Dictionary<VideoFileType, Action<FFMpegArgumentOptions>> _optionsMap = new();
    public VideoConnector()
    {
        _optionsMap.Add(VideoFileType.Avi, SetAviConvertOptions);
        _optionsMap.Add(VideoFileType.Flv, SetFlvConvertOptions);
        _optionsMap.Add(VideoFileType.Mkv, SetMkvConvertOptions);
        _optionsMap.Add(VideoFileType.Mp4, SetMp4ConvertOptions);
        _optionsMap.Add(VideoFileType.Wmv, SetWmvConvertOptions);
        _optionsMap.Add(VideoFileType.Mov, SetMovConvertOptions);
        _optionsMap.Add(VideoFileType.Webm, SetWebmConvertOptions);
    }

    public Stream ConvertVideo(Stream sourceStream, VideoConvertOptions convertOptions)
    { 
        var resultStream = new MemoryStream();

        var arguments = FFMpegArguments
            .FromPipeInput(new StreamPipeSource(sourceStream))
            .OutputToPipe(new StreamPipeSink(resultStream), options =>
            {
                if (_optionsMap.ContainsKey(convertOptions.Format))
                {
                    _optionsMap[convertOptions.Format].Invoke(options);
                }
                else
                {
                    throw new InvalidOperationException(
                        $"Conversion to {convertOptions.Format.Extension} is not supported at the moment");
                }
            });
        arguments.ProcessSynchronously();
            
        return resultStream;
    }

    private void SetAviConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("avi");
    }

    private void SetFlvConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("flv");
    }

    private void SetMkvConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("matroska");
    }

    private void SetMp4ConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("mp4");
        options.WithCustomArgument("-movflags empty_moov");
    }

    private void SetWmvConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("asf");
    }

    private void SetMovConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("mov");
        options.WithCustomArgument("-movflags empty_moov");
    }

    private void SetWebmConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("webm");
    }

}
```

Una vez que `IVideoConnector` 
interface se implementa, el fragmento de código para convertir AVI a MP4 se ve así:


```csharp
// Load the source AVI file
VideoLoadOptions loadOptions = new VideoLoadOptions();
loadOptions.SetVideoConnector(new VideoConnector());
using (Converter converter = new Converter("sample.avi", (LoadContext loadContext) => loadOptions))
{
    // Set the convert options for MP4 format
    VideoConvertOptions options = new VideoConvertOptions {
        Format = VideoFileType.Mp4
    };
    // Convert to MP4 format
    converter.Convert("converted.mp4", options);
}
```

Simplificándolo: instalas la biblioteca de procesamiento de video, implementas la `IVideoConnector` interfaz que enlaza el `GroupDocs.Conversion` con la biblioteca de procesamiento de video, cargue un archivo de video en el `Converter` clase que proporciona la `IVideoConnector` instancia, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Extraer pista de audio {#extract-audio-track}
Extraer una pista de audio de un video es similar a convertir un video; sin embargo, debe establecer la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/videoconvertoptions/extractaudioonly/" target="_blank" rel="nofollow noopener noreferrer">ExtractAudioOnly</a> en `true` y especificar el formato de salida deseado en la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/videoconvertoptions/audioformat/" target="_blank" rel="nofollow noopener noreferrer">AudioFormat</a>:

```csharp
// Load the source AVI file
VideoLoadOptions loadOptions = new VideoLoadOptions();
loadOptions.SetVideoConnector(new VideoConnector());
using (Converter converter = new Converter("sample_with_audio.avi", (LoadContext loadContext) => loadOptions))
{
    // Set the convert options
    VideoConvertOptions options = new VideoConvertOptions
    {
        ExtractAudioOnly = true,
        AudioFormat = AudioFileType.Ogg
    };
    // Convert to audio file
    converter.Convert("extracted_audio.ogg", options);
}
```

## Sobre los formatos de archivos para toma de notas {#about-note-taking-file-formats}

Los archivos de programas para toma de notas contienen secciones y páginas para almacenar notas. Un documento de notas puede ser tan simple como un documento de texto, o más complejo, incluyendo imágenes digitales, clips de audio/video y dibujos realizados a mano.

Las extensiones de archivo comunes de OneNote y sus formatos asociados son .ONE.

## Convertir desde formatos de toma de notas {#convert-from-note-taking-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento de OneNote a otro formato de archivo. Por ejemplo, el fragmento de código para convertir OneNote a PDF se ve así:

```csharp
// Load the source OneNote file
using (Converter converter = new Converter("sample.one"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo simplemente: solo carga un archivo de OneNote en el `Converter` clase de instancia, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::

## Sobre los formatos de archivos de libros electrónicos {#about-ebook-file-formats}

Los archivos de libros electrónicos (eBooks) son archivos electrónicos que pueden abrirse en dispositivos digitales conocidos como lectores de libros electrónicos (eReaders). Un lector de libros electrónicos puede ser cualquier dispositivo, como una computadora, una tableta o un smartphone. El formato de archivo de libro electrónico más popular es el ePub, basado en XML. Un libro electrónico puede contener distintos tipos de contenido, como texto, imágenes y videos. Las extensiones y formatos de archivo de libro electrónico más comunes incluyen EPUB (publicación electrónica), FB2 (FictionBook 2.0) y Mobi (archivo de libro electrónico MobiPocket).

## Convertir desde formatos de libros electrónicos {#convert-from-ebook-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento de libro electrónico a otro formato de archivo.  
Por ejemplo, un fragmento de código para convertir un libro electrónico a PDF sería el siguiente:

```csharp
// Load the source eBook file
using (Converter converter = new Converter("sample.mobi"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Básicamente, solo cargas un archivo de libro electrónico en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a formatos de libro electrónico {#convert-to-ebook-formats}

Por otro lado, convertir sus archivos al formato de libro electrónico también es bastante simple y natural. En mínimo, todo lo que necesita hacer es especificar el formato de salida deseado en el `Format` propiedad del <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/ebookconvertoptions/" target="_blank" rel="nofollow noopener noreferrer">EBookConvertOptions</a> instancia de clase.

El siguiente fragmento de código muestra cómo convertir un documento PDF a formato de libro electrónico (eBook) en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source PDF file
using (Converter converter = new Converter("sample.pdf"))
{
    // Set the convert options for eBook format
    var options = new EBookConvertOptions {
        Format = EBookFileType.Epub
    };
    // Convert to eBook format
    converter.Convert("converted.epub", options);
}
```

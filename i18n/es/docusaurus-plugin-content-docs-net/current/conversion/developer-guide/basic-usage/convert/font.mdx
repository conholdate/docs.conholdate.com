## Convertir a otro formato de fuente {#convert-to-another-font-format}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su archivo de fuente de un formato a otro.
Por ejemplo, el fragmento de código para convertir CFF a TTF se ve así:

```csharp
using GroupDocs.Conversion;
using GroupDocs.Conversion.FileTypes;
using GroupDocs.Conversion.Options.Convert;

// Load the source font file
using (Converter converter = new Converter("Lato-Regular.cff"))
{
    // Set the convert options
    var options = new FontConvertOptions
    {
        Format = FontFileType.Ttf
    };
    // Convert to TTF format
    converter.Convert("Lato-Regular.ttf", options);
}
```

Póngalo simplemente: solo carga un archivo CFF en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.

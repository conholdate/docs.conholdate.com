## Sobre los formatos de archivo comprimidos {#about-compression-file-formats}

La compresión de archivos es el proceso de reducir el tamaño de uno o más archivos. Reduce archivos grandes a versiones mucho más pequeñas eliminando datos innecesarios. El archivo archivado comprimido facilita el envío y la copia de seguridad de archivos grandes o grupos de archivos. Además, estos archivos permiten descargar contenido más rápido y sencillo, y también permiten almacenar más datos en soportes extraíbles. Existen diversos formatos de compresión. A continuación, describimos cómo convertir los formatos de archivo comprimidos más populares utilizando GroupDocs.Conversion.

## Extracción desde ZIP {#extract-from-zip}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede extraer fácilmente el contenido de sus archivos archivados. Por ejemplo, un fragmento de código para extraer contenido desde un archivo ZIP sería como sigue:

```csharp
// Load the source ZIP file
using (Converter converter = new Converter("sample.zip"))
{
    converter.Convert(_ => null, (ConvertedContext convertedContext) =>
    {
        // store extracted content
        string fileName = Path.Combine(outputFolder, convertedContext.SourceFileName);
        Directory.CreateDirectory(Path.GetDirectoryName(fileName)!);
        using (var fs = new FileStream(fileName, FileMode.Create))
        {
            convertedContext.ConvertedStream.CopyTo(fs);
        }
    });
}
```

Básicamente, solo cargas un archivo ZIP en el `Converter` clase, proporcione opciones de conversión nulas y un controlador en el que almacenar el resultado, y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://apireference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Extraer y convertir desde un archivo RAR {#extract-and-convert-from-a-rar}

También puede convertir el contenido del archivo comprimido durante la extracción al formato deseado. La extracción y conversión al formato PDF son igual de sencillas y naturales.
El siguiente fragmento de código muestra cómo convertir el contenido de un archivo RAR a PDF en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source RAR file
using (Converter converter = new Converter("sample.rar"))
{
    // Set the convert option for PDF format. This will convert each file in the archive to PDF
    PdfConvertOptions options = new PdfConvertOptions();
    int i = 0;
    // Extract and convert to PDF
    converter.Convert((SaveContext saveContext) => new FileStream(Path.Combine(outputFolder, $"converted-{++i}.{saveContext.TargetFormat.Extension}"), FileMode.Create), options);
}
```

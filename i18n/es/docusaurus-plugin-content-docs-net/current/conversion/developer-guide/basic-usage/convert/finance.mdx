Los formatos financieros proporcionan una estructura estandarizada para organizar y presentar datos financieros. Desempeñan un papel crucial en la optimización de los procesos financieros, la mejora de la precisión de los datos, el cumplimiento normativo, la transparencia y la facilitación del intercambio y análisis eficiente de datos en el sector financiero.
Las extensiones y formatos de archivo financieros más populares incluyen XBRL, IXBRL y OFX.

## Convertir desde formatos financieros {#convert-from-finance-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento financiero a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir XBRL a XLSX se ve así:

```csharp
// Load the source XBRL file
using (var converter = new GroupDocs.Conversion.Converter("sample.xbrl"))
{
    // Set the convert options for Spreadsheet format
   var options = new SpreadsheetConvertOptions();
    // Convert to XLSX format
    converter.Convert("converted.xlsx", options);
}
```

En términos simples: simplemente carga tu documento financiero en la clase `Converter`, selecciona el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto. 

## Convertir a otro formato financiero {#convert-to-another-finance-format}

Por otro lado, convertir tus archivos a otro formato financiero también es bastante sencillo y natural.
El siguiente fragmento de código muestra cómo convertir un documento XBRL al formato IXBRL en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source XBRL file
using (var converter = new GroupDocs.Conversion.Converter("sample.xbrl"))
{
    // Set the convert options for finance format
    var options = new FinanceConvertOptions { 
       Format = FinanceFileType.IXbrl
    };
    // Convert to IXBRL format
    converter.Convert("converted.ixbrl", options);
}
```

**Formato de Documento Portátil (PDF)** fue desarrollado para introducir un estándar de representación de documentos y otros materiales de referencia en un formato independiente del software de aplicación, del hardware y también de los sistemas operativos. El contenido de los archivos PDF no se limita únicamente al texto, sino que también puede incluir hipervínculos, imágenes, botones e formularios interactivos, firmas electrónicas, marcas de agua y mucho más. Por ello, con frecuencia es necesario convertir archivos PDF a otros formatos para editar o modificar su contenido. Con la biblioteca **GroupDocs.Conversion for .NET**, puede convertir archivos PDF a una amplia gama de formatos de archivo populares, y todo lo que necesita para lograrlo son solo unas pocas líneas de código en el lenguaje de programación C#.

GroupDocs.Conversion for .NET admite distintos tipos de conversiones desde documentos PDF a otros formatos de archivo, así como conversiones desde distintos formatos a PDF. Puede evaluar la calidad y precisión de las conversiones en línea mediante la demostración en vivo de la aplicación <a href="https://products.conholdate.app/conversion" target="_blank">Conholdate.Conversion App</a>. Funciona en cualquier dispositivo y es gratuita.

## Convertir PDF a Word {#convert-pdf-to-word}

Microsoft Word es una de las formas más convenientes para editar y gestionar el contenido de los documentos, por lo que la conversión de PDF a Word es tan popular. Transformar manualmente un archivo PDF en un documento de Word puede ser un proceso complejo y extenso. Mucho más sencillo es realizar esta conversión de PDF a Word mediante programación en C#.
De esta forma, cualquier archivo creado como PDF puede convertirse en un documento de Word para posterior manipulación y edición de su contenido: texto, tablas, imágenes, listas, etc.

GroupDocs.Conversion for .NET admite la conversión de PDF a todos los formatos populares de Microsoft Word, como DOC, DOCX, RTF, etc. El proceso de transformación del documento es bastante simple y directo desde la perspectiva del usuario: todo lo que necesita son dos o tres líneas de código. El formato predeterminado para la conversión de PDF a Word es DOCX, un formato ampliamente conocido para Microsoft Word 2007 y versiones posteriores, que combina archivos XML y binarios.  
A continuación se muestra un fragmento de código para la conversión de PDF a DOCX:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for DOCX format
   var options = new WordProcessingConvertOptions();
    // Convert to DOCX format
    converter.Convert("converted.docx", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted.docx")
    .Convert();
```

GroupDocs.Conversion para .NET también proporciona <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/wordprocessingfiletype" target="_blank" rel="nofollow noopener noreferrer">WordProcessingFileType</a> clase si necesita especificar otro formato de archivo de Word como destino para su conversión. Por ejemplo, el formato DOC representa documentos generados por Microsoft Word 97-2003 y sigue siendo bastante popular, y el fragmento de código para la conversión de PDF a DOC es el siguiente:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for DOC format
    var options = new WordProcessingConvertOptions  
    {  
      Format = GroupDocs.Conversion.FileTypes.WordProcessingFileType.Doc  
    };
    // Convert to DOC format
    converter.Convert("converted.doc", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted.doc").WithOptions(new WordProcessingConvertOptions  
    {  
      Format = GroupDocs.Conversion.FileTypes.WordProcessingFileType.Doc  
    })
    .Convert();
```

## Convertir PDF a Excel {#convert-pdf-to-excel}

Los formatos de hojas de cálculo están diseñados para representar datos en forma de filas y columnas, lo que facilita enormemente su uso. Por lo tanto, cuando es necesario transformar datos desde un archivo PDF al formato Excel, la biblioteca GroupDocs.Conversion resulta de gran utilidad.  
  
Puede elegir entre una amplia gama de formatos de hoja de cálculo compatibles:

* Microsoft Excel: XLS, XLSX, XLSM, XLSB, XLTX, XLT;
* OpenDocument: ODS, OTS;
* Apple iWork Numbers.

El formato de hoja de cálculo deseado puede especificarse mediante la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/spreadsheetfiletype" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetFileType</a>; sin embargo, el formato predeterminado para la conversión de PDF a hoja de cálculo es XLSX.
A continuación, se muestra cómo convertir PDF a Excel en C# con tan solo unas pocas líneas de código.

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for XLSX format
    var options = new SpreadsheetConvertOptions();
    // Convert to XLSX format
    converter.Convert("converted.xlsx", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted.xlsx")
    .Convert();
```

## Convertir PDF a PowerPoint {#convert-pdf-to-powerpoint}

Los formatos de archivo de presentación almacenan colecciones de registros para acomodar datos como diapositivas, formas, texto, animaciones, video, audio y objetos incrustados. La aplicación más popular para crear y editar presentaciones es Microsoft PowerPoint, con sus formatos de archivo PPT y PPTX, aunque también existen numerosas aplicaciones que trabajan con formatos OpenDocument, como ODP y OTP.

GroupDocs.Conversion for .NET es una opción inteligente cuando necesita convertir un archivo PDF al formato PowerPoint, y aquí tiene un fragmento de código que muestra cómo realizar la conversión de PDF a PPTX en el lenguaje C#:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for PPTX format
   var options = new PresentationConvertOptions();
    // Convert to PPTX format
    converter.Convert("converted.pptx", options);
}
```

o utilizando la sintaxis [fluent](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted.pptx")
    .Convert();
```

En caso de que necesite convertir un PDF a otro formato de presentación, utilice la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/presentationfiletype" target="_blank" rel="nofollow noopener noreferrer">PresentationFileType</a> para especificarlo.

## Convertir PDF a HTML {#convert-pdf-to-html}

Convertir un PDF al formato HTML resulta útil cuando necesita publicar contenido PDF en la web, incrustarlo en aplicaciones web o compartir documentos con usuarios que no disponen de software para visualizar PDF. La biblioteca GroupDocs.Conversion permite exportar documentos PDF a formatos HTML y MHTML, preservando la estructura y el formato del documento.

El fragmento de código para la conversión de PDF a HTML es bastante sencillo:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for HTML format
    var options = new WebConvertOptions();
    // Convert to HTML format
    converter.Convert("converted.html", options);
}
```

o utilizando la sintaxis [fluent](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted.html")
    .Convert();
```

Al convertir al formato MHTML, especifique el `Format` propiedad del <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> clase:

```csharp
var options = new WebConvertOptions
{
    Format = GroupDocs.Conversion.FileTypes.WebFileType.Mhtml
};
```

## Convertir PDF a imagen {#convert-pdf-to-image}

Un caso de uso muy común es cuando necesitas guardar todo el documento PDF o páginas específicas del mismo como una colección de imágenes. GroupDocs.Conversion para .NET permite convertir PDF a formatos de imagen populares, como TIFF, JPG, PNG, GIF, BMP y muchos otros.
El fragmento de código para esta conversión es ligeramente distinto al de otras conversiones, ya que debes declarar un delegado <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/savepagestream" target="_blank" rel="nofollow noopener noreferrer">SavePageStream</a> que especifique el formato de nombre para las imágenes guardadas. Puedes elegir el formato de imagen deseado utilizando la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/imagefiletype" target="_blank" rel="nofollow noopener noreferrer">ImageFileType</a>.

### Convertir PDF a PNG {#convert-pdf-to-png}

A continuación, puedes consultar un ejemplo completo de código para la conversión de PDF a PNG:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format("converted-page-{0}.png", saveContext.Page), FileMode.Create);

    // Set the convert options for PNG format
    var options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png };
    // Convert to PNG format
    converter.Convert(getPageStream, options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertByPageTo(saveContext => new FileStream(string.Format("converted-page-{0}.png", saveContext.Page), FileMode.Create))
    .WithOptions(new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png })
    .Convert();
```

### Convertir PDF a JPG {#convert-pdf-to-jpg}

La conversión de PDF a JPG es otro caso de uso muy común, y el fragmento de código para esta operación es similar al descrito anteriormente. La única diferencia radica en la extensión de los archivos de imagen de salida y en la propiedad `ImageConvertOptions.Format`, que debe establecerse en `ImageFileType.Jpg`:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format("converted-page-{0}.jpg", saveContext.Page), FileMode.Create);

    // Set the convert options for JPG format
    var options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Jpg };
    // Convert to JPG format
    converter.Convert(getPageStream, options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertByPageTo((SavePageContext saveContext) => new FileStream(string.Format("converted-page-{0}.jpg", saveContext.Page), FileMode.Create))
    .WithOptions(new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Jpg })
    .Convert();
```

### Convertir PDF a TIFF {#convert-pdf-to-tiff}

El formato de archivo de imagen etiquetada (TIFF, por sus siglas en inglés) es un poco especial, ya que puede contener imágenes multipágina. Por lo tanto, al convertir un PDF a TIFF, puedes guardar cada página como una imagen independiente o guardarla como una imagen multipágina.

Para guardar cada página por separado, utiliza el delegado <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/savepagestream" target="_blank" rel="nofollow noopener noreferrer">SavePageStream</a> y especifica el formato de salida mediante la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/imagefiletype" target="_blank" rel="nofollow noopener noreferrer">ImageFileType</a>:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format("converted-page-{0}.tiff", saveContext.Page), FileMode.Create);

    // Set the convert options for TIFF format
    var options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Tiff };
    // Convert to TIFF format
    converter.Convert(getPageStream, options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertByPageTo((SavePageContext saveContext) => new FileStream(string.Format("converted-page-{0}.tiff", saveContext.Page), FileMode.Create))
    .WithOptions(new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Tiff })
    .Convert();
```

Para guardar un PDF como TIFF de varias páginas, simplemente especifique el formato de salida utilizando el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/imagefiletype" target="_blank" rel="nofollow noopener noreferrer">ImageFileType</a> clase:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for TIFF format
    var options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Tiff };
    // Convert to TIFF format
    converter.Convert("multi-page.tiff", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("multi-page.tiff")
    .WithOptions(new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Tiff })
    .Convert();
```

### Convertir una sola página de un PDF a imagen {#convert-a-single-page-from-pdf-to-image}

Al trabajar con documentos PDF de varias páginas, es posible que necesite convertir solo una página específica en lugar de todo el documento. Esto resulta útil para crear miniaturas, extraer diagramas o compartir páginas individuales como imágenes.


:::info
Al convertir a formatos de imagen distintos de TIFF (como PNG, JPG, GIF, BMP), solo puede guardar una página por archivo de salida. Guardar varias páginas en un único archivo solo es compatible con el formato TIFF.
:::


Para convertir una sola página, utilice la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pagenumber" target="_blank" rel="nofollow noopener noreferrer">PageNumber</a> de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/imageconvertoptions" target="_blank" rel="nofollow noopener noreferrer">ImageConvertOptions</a>. Los números de página son basados en 1, lo que significa que la primera página es la página 1.

El siguiente fragmento de código muestra cómo convertir la página 2 de un documento PDF al formato PNG:

```csharp
// Load the source PDF file
using (var converter = new GroupDocs.Conversion.Converter("sample.pdf"))
{
    // Set the convert options for PNG format
    var options = new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png,
        PageNumber = 2
    };
    // Convert to PNG format
    converter.Convert("converted-page-2.png", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.pdf")
    .ConvertTo("converted-page-2.png")
    .WithOptions(new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png,
        PageNumber = 2
    })
    .Convert();
```

Para obtener más información sobre las opciones de selección de páginas, consulte [Convertir páginas específicas](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/convert-specific-pages/) y [Convertir N páginas consecutivas](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/convert-n-consecutive-pages/) artículos.

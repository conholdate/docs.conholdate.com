## Sobre los formatos de archivo de imagen {#about-image-file-formats}

Un formato de archivo de imagen es un método estándar para organizar y almacenar imágenes en dispositivos como computadoras, tabletas y teléfonos inteligentes. Las imágenes digitales almacenan datos de imagen en una cuadrícula bidimensional de píxeles, donde cada píxel representa un color mediante un número determinado de bits. Los tipos de archivo de imagen se clasifican en formatos de imagen vectorial y formatos de imagen rasterizada. Las imágenes 3D constituyen otro tipo de formato de archivo de imagen vectorial, utilizado para gestionar imágenes tridimensionales.

### Formatos rasterizados {#raster-formats}

Las **gráficas rasterizadas** son imágenes digitales compuestas por datos de píxeles que representan colores. Son los tipos de imagen más comunes para gráficos utilizados en la web, así como para fotografías digitales. Algunas imágenes rasterizadas pueden comprimirse para reducir el tamaño del archivo de imagen. Entre las extensiones y formatos de archivo de imagen rasterizada más comunes se incluyen **BMP** (archivo de imagen de mapa de bits), **PNG** (Gráficos de red portátiles) y **GIF** (Formato de intercambio de gráficos).

### Formatos vectoriales {#vector-formats}

Las **imágenes vectoriales** se definen mediante puntos bidimensionales, en lugar de píxeles, que se conectan para otorgar una forma geométrica a la imagen. Estos puntos poseen propiedades que definen la dirección de las rutas, el color, la forma, la curvatura, el grosor y el relleno. Entre las extensiones y formatos de archivo de imagen vectorial más comunes se incluyen **SVG** (Gráficos vectoriales escalables), **EPS** (Lenguaje PostScript encapsulado) y **PDF** (Formato de documento portátil).

## Convertir imagen a PDF {#convert-image-to-pdf}

Convertir una imagen en un archivo PDF es un caso de uso habitual, por ejemplo, cuando se necesita crear un documento PDF a partir de un papel escaneado. <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> permite resolver esta tarea fácil e intuitivamente, utilizando únicamente unas pocas líneas de código en C#, como se describe a continuación:

1. Crear una instancia de la clase `Converter` y pasar la ruta del archivo JPG de origen como parámetro del constructor. Puede especificar rutas absolutas o relativas según sus necesidades.
2. Crear una instancia de la clase `PdfConvertOptions`.
3. Llamar al método `Convert` y pasar como parámetros el nombre de archivo para el archivo PDF convertido y el objeto `PdfConvertOptions` del paso anterior.

```csharp
// Load the source JPG file
using (var converter = new GroupDocs.Conversion.Converter("sample.jpg"))
{
    // Set the convert options for PDF format
    var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.jpg")
    .ConvertTo("converted.pdf")
    .Convert();
```

NOTA: El ejemplo de código anterior es idéntico para la conversión de otros formatos de imagen a PDF; la única diferencia es que debe proporcionar el nombre del archivo con la extensión correspondiente.

## Convertir imagen a Excel {#convert-image-to-excel}

Si necesita extraer datos de sus declaraciones de impuestos anteriores a Excel y solo dispone de copias impresas, simplemente tome una foto de cada una y convierta estas imágenes en un libro de Excel (XLS/XLSX).

### Convertir JPG a XLS {#convert-jpg-to-xls}

```csharp
// Load the source JPG file
using (var converter = new GroupDocs.Conversion.Converter("sample.jpg"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions { Format = GroupDocs.Conversion.FileTypes.SpreadsheetFileType.Xls };
    // Save converted XLS file
    converter.Convert("jpg-converted-to.xls", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.jpg")
    .ConvertTo("jpg-converted-to.xls")
    .WithOptions(new SpreadsheetConvertOptions { Format = GroupDocs.Conversion.FileTypes.SpreadsheetFileType.Xls })
    .Convert();
```

### Convertir PNG a XLS {#convert-png-to-xls}

```csharp
// Load the source PNG file
using (var converter = new GroupDocs.Conversion.Converter("sample.png"))
{
    SpreadsheetConvertOptions options = new SpreadsheetConvertOptions { Format = GroupDocs.Conversion.FileTypes.SpreadsheetFileType.Xls };
    // Save converted XLS file
    converter.Convert("png-converted-to.xls", options);
}
```

Puede elegir entre una variedad de formatos de hojas de cálculo utilizando la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/spreadsheetfiletype" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetFileType</a>, incluidos XLS, XLSX, ODS y otros.

## Convertir imagen en presentación de PowerPoint {#convert-image-to-powerpoint-presentation}

Si necesita crear una presentación de PowerPoint a partir de imágenes en formatos **PNG**, **JPG/JPEG**, **TIF/TIFF**, **GIF** u otros, una solución posible es convertirlas programáticamente.  
A continuación, revisaremos varios ejemplos de código en lenguaje C# y veremos cómo transformar una imagen en una presentación PPT/PPTX.

### Convertir JPG a PPT {#convert-jpg-to-ppt}

```csharp
// Load the source JPG file
using (var converter = new GroupDocs.Conversion.Converter("sample.jpg"))
{
    PresentationConvertOptions options = new PresentationConvertOptions { Format = GroupDocs.Conversion.FileTypes.PresentationFileType.Ppt };
    // Save converted PPT file
    converter.Convert("jpg-converted-to.ppt", options);
}
```

o utilizando la sintaxis [fluent](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.jpg")
    .ConvertTo("jpg-converted-to.ppt")
    .WithOptions(new PresentationConvertOptions { Format = GroupDocs.Conversion.FileTypes.PresentationFileType.Ppt })
    .Convert();
```

### Convertir PNG a PPT {#convert-png-to-ppt}

```csharp
// Load the source PNG file
using (var converter = new GroupDocs.Conversion.Converter("sample.png"))
{
    PresentationConvertOptions options = new PresentationConvertOptions { Format = GroupDocs.Conversion.FileTypes.PresentationFileType.Ppt };
    // Save converted PPT file
    converter.Convert("png-converted-to.ppt", options);
}
```

Puede elegir entre una variedad de formatos de presentación utilizando la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/presentationfiletype" target="_blank" rel="nofollow noopener noreferrer">PresentationFileType</a>, incluidos PPT, PPTX, ODP y otros.

## Convertir entre formatos de imagen {#convert-between-image-formats}

Convertir entre distintos formatos de imagen es una necesidad frecuente. Por ejemplo, puede ser necesario convertir PNG a JPG para reducir el tamaño del archivo, o convertir a TIFF para fines de archivo.

### Convertir PNG a JPG {#convert-png-to-jpg}

```csharp
// Load the source PNG file
using (var converter = new GroupDocs.Conversion.Converter("sample.png"))
{
    var options = new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Jpg
    };
    // Save converted JPG file
    converter.Convert("png-converted-to.jpg", options);
}
```

o utilizando [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
FluentConverter
    .Load("sample.png")
    .ConvertTo("png-converted-to.jpg")
    .WithOptions(new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Jpg
    })
    .Convert();
```

### Convertir JPG a PNG {#convert-jpg-to-png}

```csharp
// Load the source JPG file
using (var converter = new GroupDocs.Conversion.Converter("sample.jpg"))
{
    var options = new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png
    };
    // Save converted PNG file
    converter.Convert("jpg-converted-to.png", options);
}
```

### Convertir imagen a TIFF {#convert-image-to-tiff}

TIFF (Tagged Image File Format) se utiliza ampliamente para almacenar imágenes de alta calidad. Puede convertir cualquier formato de imagen admitido a TIFF:

```csharp
// Load the source image file
using (var converter = new GroupDocs.Conversion.Converter("sample.jpg"))
{
    var options = new ImageConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.ImageFileType.Tiff
    };
    // Save converted TIFF file
    converter.Convert("converted.tiff", options);
}
```

Puede elegir entre una amplia gama de formatos de imagen compatibles mediante el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/imagefiletype" target="_blank" rel="nofollow noopener noreferrer">ImageFileType</a> clase, incluyendo: BMP, GIF, ICO, JP2, JPEG, PNG, PSD, SVG, TIFF, WEBP y muchos otros.

Para opciones avanzadas de conversión de imágenes, como establecer la calidad, la resolución y otros parámetros, consulte [Convertir a imagen con opciones avanzadas](/net/conversion/developer-guide/advanced-usage/converting/conversion-options-by-document-family/convert-to-image-with-advanced-options/) artículo.

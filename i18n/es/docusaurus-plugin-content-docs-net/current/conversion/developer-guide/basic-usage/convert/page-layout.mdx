## Formatos de diseño de página {#about-page-layout-formats}

Los lenguajes de diseño de página se utilizan en la publicación de escritorio y electrónica. El enfoque principal de estos lenguajes es facilitar un diseño gráfico bidimensional. Los formatos de diseño de página más populares incluyen TEX, SVG, PS y EPS.

## Convertir desde formatos de diseño de página {#convert-from-page-layout-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente un formato de archivo de diseño de página a otro formato de archivo.  
Por ejemplo, el fragmento de código para la conversión de TEX a PDF es el siguiente:

```csharp
// Load the source TEX file
using (var converter = new GroupDocs.Conversion.Converter("sample.tex"))
{
    // Set the convert options for PDF format
   var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Pongámoslo de forma sencilla: simplemente cargas un archivo de diseño de página en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a formatos de diseño de página {#convert-to-page-layout-formats}

Por otro lado, convertir sus archivos al formato de diseño de página también es bastante sencillo y natural.
El siguiente fragmento de código muestra cómo convertir un documento DOCX al formato TEX en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source DOCX file
using (var converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    // Set the convert options
    var options = new PageDescriptionLanguageConvertOptions()
    {
        Format = PageDescriptionLanguageFileType.Tex
    };
    // Convert to TEX format
    converter.Convert("converted.tex", options);
}
```

Cuando se trata de la creación y edición rápida y cómoda de documentos de texto, Microsoft Word es lo primero que se nos viene a la mente. Con frecuencia, surge la necesidad de transformar documentos DOC o DOCX a otro formato, como PDF, HTML o imágenes, para facilitar su envío por correo, impresión y compartición con otras personas.
GroupDocs.Conversion para .NET le permite convertir documentos de procesamiento de texto a otros formatos con un esfuerzo mínimo: todo lo que necesita son solo varias líneas de código C#.

Esta sección explica cómo convertir documentos de procesamiento de texto utilizando GroupDocs.Conversion para .NET.

## Convertir documento de Word a PDF {#convert-word-document-to-pdf}

Al convertir un archivo del formato de Microsoft Office Word a PDF, GroupDocs.Conversion para .NET realiza múltiples cálculos en segundo plano para preservar la apariencia original del documento y reproducir correctamente el diseño del documento PDF convertido, tal como fue diseñado en el documento DOC o DOCX inicial en Microsoft Word. Todo esto es necesario porque los documentos de Word están en formato de diseño fluido y su apariencia puede variar según el dispositivo y la plataforma utilizados para visualizarlos. En cambio, el formato PDF es de diseño fijo y tiene la misma apariencia en distintos dispositivos.  
  
La siguiente sección explica cómo convertir DOC o DOCX a PDF mediante programación, sin Microsoft Office y con la ayuda de GroupDocs.Conversion para .NET.  

### Convertir DOCX (o DOC) a PDF {#convert-docx-or-doc-to-pdf}

GroupDocs.Conversion ofrece una forma sencilla y concisa de convertir DOCX a PDF: todo lo que necesita son un par de líneas de código para:

1. Cargar su documento DOCX en el objeto `Converter` proporcionando un nombre de archivo con su extensión.
2. Invocar el método `Convert` del objeto `Converter` y especificar el formato de salida deseado como PDF, pasándole el objeto `PdfConvertOptions` junto con el nombre del archivo convertido.  
  
El siguiente ejemplo de código demuestra cómo convertir un documento de DOCX a formato PDF:

```csharp
// Load the source DOCX file
using(var converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    // Set the convert options for PDF format
    var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```
  

:::info
NOTA: Tenga en cuenta que el número de páginas en un documento de origen afecta el tiempo de conversión.
:::


## Convertir documentos de Word a HTML o MHTML {#convert-word-document-to-html-or-mhtml}

HTML es un formato de página web muy popular, ya que puede visualizarse en cualquier dispositivo y plataforma que disponga de un navegador web. Por su parte, el formato MHTML representa un formato de archivo de página web conocido como formato de archivo, ya que almacena el código HTML de la página web y sus recursos asociados en un único archivo. Estos recursos incluyen cualquier elemento vinculado a la página web, como imágenes, applets, animaciones, archivos de audio, etc. Los archivos MHTML pueden abrirse en diversas aplicaciones, como Internet Explorer y Microsoft Word.  

La conversión de documentos de Microsoft Word a formatos HTML o MHTML es una funcionalidad muy popular y demandada de GroupDocs.Conversion. El caso de uso básico de conversión de DOCX a HTML puede implementarse en varias líneas de código C#: todo lo que necesita hacer es especificar el nombre del archivo de origen con su extensión y llamar al método `Convert` de la clase `Converter`, pasándole como parámetro el nombre del archivo HTML de destino. A continuación, puede consultar el fragmento de código completo:

```csharp
// Load the source DOCX file
using(var converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    // Set the convert options for HTML format
    var options = new WebConvertOptions();
    // Save converted HTML file
    converter.Convert("converted.html", options);
}
```

Al convertir un archivo DOC o DOCX al formato MHTML, la única diferencia respecto al ejemplo de código anterior es que es necesario establecer la propiedad  <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> `Format` en **WebFileType.Mhtml**. El fragmento de código para la conversión de DOCX a MHTML será el siguiente:

```csharp
// Load the source DOCX file
using(var converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    var options = new WebConvertOptions
    {  
        Format = GroupDocs.Conversion.FileTypes.WebFileType.Mhtml
    };
    // Save converted HTML file
    converter.Convert("converted.html", options);
}
```

## Convertir documento de Word en imagen {#convert-word-document-to-image}

En ocasiones, es necesario obtener imágenes de las páginas de un documento DOC o DOCX: esto puede resultar útil como sustitución más rápida y, por tanto, más eficiente frente al escaneo físico de documentos, al generar vistas previas de páginas de documentos para su sitio web o aplicación, o al intentar mostrar documentos a alguien que no tiene Microsoft Word instalado en su estación de trabajo. En tal caso, la solución consiste en convertir el documento a un formato de imagen compatible, como JPG, PNG, TIFF o cualquier otro (consulte la lista completa de [conversiones disponibles](#supported-word-processing-file-conversions)). 

Al igual que en otros ejemplos de código ya explicados, todo lo necesario para convertir un documento de Word en una imagen es cargar el archivo DOC/DOCX de origen en el objeto `Converter` y llamar al método `Convert`. La única diferencia es que cada página del documento de Word de origen se guardará como un archivo de imagen independiente, por lo que es necesario especificar el formato de nomenclatura para las imágenes de salida (los números de página se asignarán dinámicamente).  

A continuación, puede consultar el ejemplo completo de código para convertir DOCX a PNG:

```csharp
string outputFileNameFormat = "converted-page-{0}.png";
Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format(outputFileNameFormat, saveContext.Page), FileMode.Create);

// Load the source DOCX file
using (Converter converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    // Set the convert options for PNG format
    ImageConvertOptions options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png };
    // Convert to PNG format
    converter.Convert(getPageStream, options);
}
```

## Convertir documento de Word a Markdown {#convert-word-document-to-markdown}

El formato Markdown ha ganado popularidad entre los desarrolladores debido a su versatilidad: aunque se utiliza para redactar descripciones y documentación de programas, su estructura es bastante simple y plana, lo que lo hace ideal para transformarlo a formatos como PDF, HTML, DOCX y otros.
GroupDocs.Conversion le permite convertir documentos de Microsoft Word a archivos Markdown con la extensión ".md" sin demasiado esfuerzo. Veamos cómo convertir DOCX a MD utilizando el lenguaje de programación C#.  

```csharp
// Load the source DOCX file
using (var converter = new GroupDocs.Conversion.Converter("sample.docx"))
{
    WordProcessingConvertOptions options = new WordProcessingConvertOptions
    {
        Format = GroupDocs.Conversion.FileTypes.WordProcessingFileType.Md
    };
    // Save converted MD file
    converter.Convert("converted.md", options);
}
```
  
Así que, nuevamente, todo lo que necesitas hacer para una conversión rápida con GroupDocs.Conversion para .NET es: cargar el documento de Word de origen en el `Converter` clase y llamar a `Convert` método para guardar el archivo convertido. ¡Eso es todo!

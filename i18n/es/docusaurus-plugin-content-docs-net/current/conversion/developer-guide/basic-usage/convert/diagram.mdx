## Sobre los formatos de diagramas {#about-diagram-formats}

Microsoft Visio se incluye como parte de la suite de Microsoft Office y se utiliza para aplicaciones de diagramación y dibujo vectorial. Se emplea para crear varios tipos distintos de diagramas, como diagramas de flujo, diagramas UML, diagramas de red y muchos otros.

Los formatos de archivo de Visio incluyen tipos de archivo como VSDX, VSX, VTX, VDX, VSSX, VSTX, VSDM, VSSM y VSTM, que se guardan en el disco cuando un usuario crea un proyecto en Microsoft Visio.

## Convertir desde formatos de diagrama {#convert-from-diagram-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento de diagrama a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir VSDX a PDF es el siguiente:

```csharp
// Load the source VSDX file
using (Converter converter = new Converter("sample.vsdx"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo de forma simple: simplemente carga un archivo de diagrama en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a otro formato de diagrama {#convert-to-another-diagram-format}

Por otro lado, convertir sus archivos de diagrama a otro formato de diagrama también es bastante sencillo y natural.
El siguiente fragmento de código muestra cómo convertir un archivo en formato VSDX a formato VDW en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source VSDX file
using (Converter converter = new Converter("sample.vsdx"))
{
    // Set the convert options for VDW format
    var options = new DiagramConvertOptions {
        Format = DiagramFileType.Vdw
    };
    // Convert to VDW format
    converter.Convert("converted.vdw", options);
}
```

## Sobre los formatos de Publisher {#about-publisher-formats}

Si trabaja en el ámbito del marketing digital, realiza campañas de correo electrónico o dirige alguna agencia de edición, seguramente conocerá Microsoft Publisher. Esta herramienta le permite crear diseños con estructuras visuales que incluyen texto, gráficos rasterizados y vectoriales. Estos diseños pueden utilizarse para elaborar boletines informativos, folletos, trípticos, tarjetas postales y contenido para correos electrónicos.

Los formatos de archivo de Publisher incluyen, entre otros, el formato de archivo PUB, que se guarda en un disco cuando el usuario crea un proyecto en Microsoft Publisher y lo guarda en el disco.

## Convertir desde formatos de Publisher {#convert-from-publisher-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su archivo de Publisher a otro formato de archivo. Por ejemplo, el fragmento de código para convertir un archivo de Publisher a PDF sería el siguiente:

```csharp
// Load the source Publisher file
using (Converter converter = new Converter("sample.pub"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo simplemente: solo carga un archivo de Publisher en el `Converter` clase de instancia, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::

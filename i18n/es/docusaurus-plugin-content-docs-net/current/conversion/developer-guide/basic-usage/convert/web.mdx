## Sobre HTML y otros formatos de archivo web {#about-html-and-other-web-file-formats}

HTML (HyperText Markup Language, o Lenguaje de Marcado de Hipertexto) es la extensión utilizada para páginas web creadas para su visualización en navegadores. Conocido como el lenguaje de la web, HTML ha evolucionado junto con las necesidades de mostrar nueva información como parte de las páginas web. 

Al construir una página web se utilizan muchos tipos de archivo. Los formatos de archivo web definen los estándares para el desarrollo de páginas web y están relacionados con la plataforma en la que se construyen. Un sitio web completo puede estar compuesto tanto por páginas web estáticas como dinámicas. 

Las extensiones y formatos de archivo web más comunes incluyen HTML (HyperText Markup Language), ASP (Active Server Pages), XML (Extensible Markup Language), CSS (Cascading Style Sheets), JSON (JavaScript Object Notation), entre otros.

## Convertir desde formatos web {#convert-from-web-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente un formato web a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir HTML a PDF se ve así:

```csharp
// Load the source HTML file
using (Converter converter = new Converter("sample.html"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Básicamente, solo cargas un archivo HTML en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a formatos web {#convert-to-web-formats}

Por otro lado, convertir sus archivos a formatos web también es bastante simple y natural.
El siguiente fragmento de código muestra cómo convertir un documento PDF a formato HTML en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source PDF file
using (Converter converter = new Converter("sample.pdf"))
{
    // Set the convert options for HTML format
    var options = new WebConvertOptions();
    // Convert to HTML format
    converter.Convert("converted.html", options);
}
```

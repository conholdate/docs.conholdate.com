## Sobre los formatos de archivos CAD {#about-cad-file-formats}

CAD significa *Computer-Aided Design* (Diseño Asistido por Computadora). También se utiliza el término CADD (*Computer-Aided Design and Drafting*, Diseño y Diseño Asistido por Computadora). Se refiere a un formato de archivo gráfico en 3D y puede contener diseños en 2D o 3D. Un archivo CAD es un formato de archivo digital de un objeto generado y utilizado por software de CAD. Un archivo CAD contiene un dibujo técnico, una planta, un esquema o una representación en 3D de un objeto. Puede haber otras herramientas CAD que se pueden utilizar para crear, abrir, editar y exportar estos archivos .cad a formatos de archivo de dibujo CAD más ampliamente utilizados. A continuación, describimos cómo convertir los formatos de archivo CAD más populares.

## Convertir desde formatos CAD {#convert-from-cad-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento CAD a otro formato de archivo.  
Por ejemplo, un fragmento de código para convertir DWG a PDF se ve así:

```csharp
// Load the source DWG file
using (Converter converter = new Converter("sample.dwg"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Básicamente, solo cargas un archivo CAD en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a otro formato CAD {#convert-to-another-cad-format}

Por otro lado, convertir sus archivos CAD a otro formato CAD también es bastante sencillo y natural.
El siguiente fragmento de código muestra cómo convertir un documento DWG a STL en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source DWG file
using (Converter converter = new Converter("sample.dwg"))
{
    // Set the convert options for STL format
    var options = new CadConvertOptions {
        Format = CadFileType.Stl
    };
    // Convert to STL format
    converter.Convert("converted.stl", options);
}
```

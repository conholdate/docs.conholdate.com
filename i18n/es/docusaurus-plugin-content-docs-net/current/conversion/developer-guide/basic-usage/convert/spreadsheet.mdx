Microsoft Excel, con sus populares formatos XLS y XLSX, es una referencia reconocida en el ámbito del trabajo con datos tabulares, informes, datos contables y números. Sin embargo, con frecuencia existen situaciones en las que no es posible instalar el software Excel para trabajar con hojas de cálculo, por diversas razones. Es precisamente en estos casos cuando convertir el libro de origen a otro formato puede constituir una solución. 

Aunque la conversión directa de tablas a otros formatos puede ser un proceso muy complejo, **GroupDocs.Conversion para .NET** resuelve con éxito este tipo de tareas: desde el punto de vista del desarrollador, basta con cargar el libro de origen y guardar el documento convertido en otro formato. ¡Eso es todo!

## Convertir un libro de Excel a PDF {#convert-excel-workbook-to-pdf}

Hoy en día, el formato PDF se ha convertido en una de las formas más comunes para compartir documentos entre personas y organizaciones de cualquier tipo. En el desarrollo de software, también es una caso de uso bastante frecuente convertir libros de Excel al formato PDF. GroupDocs.Conversion mantiene una gran precisión visual al convertir libros XLSX/XLS a PDF, y no se requiere ningún software adicional.  

Utilice la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> para guardar un libro de Excel en PDF mediante su método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_16" target="_blank" rel="nofollow noopener noreferrer">Convert</a>. A continuación se presenta una lista completa de los pasos que deben seguirse para convertir un archivo XLSX a PDF:  

1. Instancie un objeto de la clase `Converter` pasando el nombre del archivo XLSX de origen como parámetro.
2. Llame al método `Convert` y especifique el nombre del archivo de salida junto con el objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/pdfconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PdfConvertOptions</a>, ya que estamos convirtiendo el libro al formato PDF. El archivo PDF convertido se guardará con el nombre seleccionado.  

```csharp
// Load the source XLSX file
using (var converter = new GroupDocs.Conversion.Converter("sample.xlsx"))
{
    var options = new PdfConvertOptions();
    // Save converted PDF file
    converter.Convert("converted.pdf", options);
}
```

## Convertir libro de Excel a HTML/MHTML {#convert-excel-workbook-to-html-mhtml}

La biblioteca GroupDocs.Conversion permite exportar hojas de cálculo de Excel a formatos HTML y MHTML, que son formatos web muy utilizados, así como para correos electrónicos y otras áreas.
La principal diferencia entre HTML y MHTML es que este último combina todo el contenido del documento, como estilos CSS, imágenes, audio, etc., en un único archivo.  
El fragmento de código para convertir XLSX a HTML o MHTML utilizando el lenguaje de programación C# es bastante sencillo:  

```csharp
// Load the source XLSX file
using (var converter = new GroupDocs.Conversion.Converter("sample.xlsx"))
{
    var options = new WebConvertOptions();
    // Save converted HTML file
    converter.Convert("converted.html", options);
}
```

Al convertir a MHTML, puede utilizar el mismo ejemplo de código anterior; simplemente especifique el formato para <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/webconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WebConvertOptions</a> como esto:  

```csharp
var options = new WebConvertOptions
{  
    Format = GroupDocs.Conversion.FileTypes.MarkupFileType.Mhtml
};
```

## Convertir libro de Excel a DOCX {#convert-excel-workbook-to-docx}

La biblioteca GroupDocs.Conversion le brinda la capacidad de convertir archivos de Microsoft Excel en una amplia gama de formatos de Microsoft Word (consulte la lista completa de [conversiones admitidas](#supported-spreadsheet-file-conversions)). Los formatos de Microsoft Word más comúnmente utilizados son DOCX y DOC, y al convertir una hoja de cálculo XLSX, debe especificar el formato de destino deseado configurando el `Format` propiedad del  <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/wordprocessingconvertoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingConvertOptions</a> objeto.  

Aquí tienes un ejemplo completo de código para la conversión de XLSX a DOCX utilizando el lenguaje C#:

```csharp
// Load the source XLSX file
using (var converter = new GroupDocs.Conversion.Converter("sample.xlsx"))
{
    var options = new WordProcessingConvertOptions();
    // Save converted DOCX file
    converter.Convert("converted.docx", options);
}
```

## Convertir un libro de Excel a PPTX {#convert-excel-workbook-to-pptx}

Cuando sea necesario presentar datos y gráficos de Microsoft Excel a una audiencia amplia, puede resultar más conveniente transformar el libro XLS(X) al formato de Microsoft PowerPoint. La biblioteca GroupDocs.Conversion admite dichas conversiones de Excel a PowerPoint, al convertir las hojas de cálculo del libro en diapositivas de presentación.  

Al igual que en otras conversiones, puede elegir el formato de archivo de presentación deseado especificando la propiedad `Format` de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a>. PPTX es el formato predeterminado para presentaciones, por lo que, al convertir a PPTX, la propiedad `Format` puede omitirse.  

Consulte el fragmento de código que demuestra cómo convertir XLSX a PPTX utilizando el lenguaje C#:  

```csharp
// Load the source XLS file
using (var converter = new GroupDocs.Conversion.Converter("sample.xlsx"))
{
    var options = new PresentationConvertOptions();
    // Save converted PPTX file
    converter.Convert("converted.pptx", options);
}
```

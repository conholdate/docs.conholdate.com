Las presentaciones de Microsoft PowerPoint en formatos PPT y PPTX se utilizan ampliamente para presentaciones que contienen materiales multimedia enriquecidos y como sustituto moderno de los antiguos proyectores de diapositivas. La suite de Microsoft Office incluye PowerPoint y otras herramientas, como Word y Excel, para mejorar la productividad en el entorno de oficina.  
Aunque Microsoft Office ofrece la posibilidad de guardar presentaciones PPT o PPTX en otros formatos, como imágenes, HTML, XML, etc., puede resultar aburrido, consumidor de tiempo e ineficaz guardar manualmente numerosos archivos.    
  
En tales situaciones, **GroupDocs.Conversion for .NET** le ayudará a convertir presentaciones en una amplia gama de formatos de archivo de salida. ¡Ni siquiera necesitará instalar ningún software de terceros para ello! Todo puede lograrse con tan solo unas pocas líneas de código en C#.  
  
Este artículo explica cómo convertir programáticamente presentaciones PPT (o PPTX) a otros formatos de archivo utilizando el lenguaje C#.

## Convertir PPT a PPTX {#convert-ppt-to-pptx}

Antes de profundizar en la transformación de presentaciones PPT/PPTX a otros formatos, aprendamos cómo convertir PPT a PPTX (y viceversa).

La diferencia clave entre ambos formatos radica en que PPT especifica el formato binario utilizado por Microsoft PowerPoint 97-2003, mientras que el formato PPTX se basa en el formato de archivo de presentación Open XML de Microsoft PowerPoint, que puede abrirse en PC con PowerPoint 2007 (o en Mac con PowerPoint 2008) y versiones posteriores.  
  
La conversión básica de PPT a PPTX puede realizarse mediante el siguiente fragmento de código. La secuencia de pasos necesarios es bastante intuitiva: cargue el archivo PPT de origen en el objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> y llame al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/convert/#convert_16" target="_blank" rel="nofollow noopener noreferrer">Convert</a> para guardar el archivo PPTX convertido. El formato PPTX se elige como formato predeterminado al instanciar el objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/presentationconvertoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationConvertOptions</a> sin especificar explícitamente la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a>.

```csharp
// Load the source PPT file
using (var converter = new GroupDocs.Conversion.Converter("sample.ppt"))
{
    var options = new PresentationConvertOptions();
    // Save converted PPTX file
    converter.Convert("converted.pptx", options);
}
```

También se podría implementar una conversión inversa de PPTX a PPT con una cantidad mínima de código en C#. La principal diferencia es que la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/convertoptions-1/format/" target="_blank" rel="nofollow noopener noreferrer">Format</a> debe establecerse en <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.filetypes/presentationfiletype/ppt/" target="_blank" rel="nofollow noopener noreferrer">FileTypes.PresentationFileType.Ppt</a>. A continuación, se muestra un ejemplo de código:  

```csharp
// Load the source PPTX file
using (var converter = new GroupDocs.Conversion.Converter("sample.pptx"))
{
    PresentationConvertOptions options = new PresentationConvertOptions { Format = GroupDocs.Conversion.FileTypes.PresentationFileType.Ppt };
    // Save converted PPT file
    converter.Convert("converted.ppt", options);
}
```

## Convertir PowerPoint a PDF {#convert-powerpoint-to-pdf}

El formato de documento portátil (PDF, por sus siglas en inglés) es muy popular actualmente por muchas razones; por lo tanto, convertir presentaciones de PowerPoint al formato PDF también es una funcionalidad muy demandada por clientes de diversos sectores. Las presentaciones de PowerPoint pueden guardarse en múltiples formatos de archivo, como PPT, PPTX, PPSM, PPS, etc. A continuación, veremos cómo convertirlas a PDF mediante código en C#.  
  
El proceso real de conversión es muy sencillo: proporcione su archivo de presentación a la clase `Converter`, invoque el método `Convert`, el cual realizará todas las transformaciones necesarias y guardará el archivo PDF resultante en la ubicación deseada. A continuación, se presentan varios ejemplos de código para la conversión a PDF; en el caso de otros formatos de presentación, el procedimiento es prácticamente idéntico —la única diferencia radica en la extensión del archivo de entrada.

### Convertir PPTX a PDF {#convert-pptx-to-pdf}

A continuación se muestra un ejemplo de conversión de una presentación PPTX al formato PDF. Como puede observarse, es un proceso bastante simple y directo.  

```csharp
// Load the source PPTX file
using (var converter = new GroupDocs.Conversion.Converter("sample.pptx"))
{
    var options = new PdfConvertOptions();
    // Save converted PDF file
    converter.Convert("converted.pdf", options);
}
```

### Convertir PPSM a PDF {#convert-ppsm-to-pdf}

Los archivos con la extensión PPSM representan el formato de archivo de presentación con macro habilitada, creado con Microsoft PowerPoint 2007 o versiones posteriores. Otro formato de archivo similar es <a href="https://docs.fileformat.com/presentation/pptm/" target="_blank" rel="nofollow noopener noreferrer">PPTM</a>, que difiere en que se abre en Microsoft PowerPoint en formato editable en lugar de ejecutarse como presentación. Al ejecutarse como presentación, el archivo PPSM muestra las diapositivas de la presentación con su contenido intacto y, de forma predeterminada, está en modo de solo lectura. Los archivos PPSM aún pueden editarse en Microsoft PowerPoint al abrirlos en esta aplicación.

El código en C# necesario para convertir PPSM a PDF se proporciona a continuación.

```csharp
// Load the source PPSM file
using (var converter = new GroupDocs.Conversion.Converter("sample.ppsm"))
{
    var options = new PdfConvertOptions();
    // Save converted PDF file
    converter.Convert("converted.pdf", options);
}
```

## Convertir presentación a imagen {#convert-presentation-to-image}

A menudo se necesita transformar una presentación de PowerPoint en una colección de imágenes. Por supuesto, esto podría hacerse manualmente mediante la exportación con la ayuda de Microsoft PowerPoint, pero en caso de que no se cuente con esta aplicación disponible o cuando haya un gran número de presentaciones que convertir, resulta más conveniente realizar la conversión de la presentación a imágenes de forma programática.  
Sin importar el formato de imagen que elija, GroupDocs.Conversion admite una amplia gama de ellos: **PNG**, **JPG/JPEG**, **TIF/TIFF**, **GIF** (y muchos más [otros](/net/conversion/getting-started/supported-document-formats/)).  
  
Aquí tienes un fragmento de código que muestra cómo convertir un archivo PPTX a una imagen PNG en el lenguaje de programación C#:

```csharp
Func<SavePageContext, Stream> getPageStream = saveContext => new FileStream(string.Format("converted-slide-{0}.png", saveContext.Page), FileMode.Create);
// Load the source PPTX file
using (Converter converter = new GroupDocs.Conversion.Converter("sample.pptx"))
{
    // Set the convert options for PNG format
    ImageConvertOptions options = new ImageConvertOptions { Format = GroupDocs.Conversion.FileTypes.ImageFileType.Png };
    // Convert to PNG format
    converter.Convert(getPageStream, options);
}
```

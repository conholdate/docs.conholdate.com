Un archivo de proyecto es una colección de tareas, recursos y programación para obtener una salida medible en forma de producto o servicio. Los diagramas de Gantt se utilizan para establecer un flujo visual de actividades en función del tiempo para las tareas identificadas, y también pueden exportarse a formatos PDF o imagen para documentación.
Las extensiones de archivo comunes en gestión de proyectos y sus formatos asociados incluyen MPP, MPX y XER.

## Convertir desde formatos de gestión de proyectos {#convert-from-project-management-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su documento a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir MPP a PDF se ve así:

```csharp
// Load the source MPP file
using (var converter = new GroupDocs.Conversion.Converter("sample-project.mpp"))
{
    // Set the convert options for PDF format
   var options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Póngalo simplemente: solo carga un archivo MPP en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.

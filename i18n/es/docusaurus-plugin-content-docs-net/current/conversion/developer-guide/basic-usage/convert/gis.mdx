## Sobre los formatos de archivos GIS {#about-gis-file-formats}

Un archivo de mapa GIS (Sistema de Información Geográfica) contiene información espacial o geográfica sobre una ubicación o área determinada. Un software de mapeo GIS es un programa o conjunto de programas que presentan datos espaciales o geográficos a los usuarios para su visualización, análisis y gestión. Un archivo GIS puede crearse manualmente, extraerse de un dispositivo GPS o registrarse mediante dispositivos y aplicaciones de teledetección. El GIS se utiliza en prácticamente todos los campos de la vida: desde la agricultura hasta la planificación urbana, el análisis de recursos, la planificación urbana y la elaboración de estrategias para resolver problemas.

Las extensiones y formatos de archivo GIS más comunes incluyen GPX (Formato de Intercambio de GPS), KML (Lenguaje de Marcado de Keyhole) y SHP (Shapefile de ESRI).

## Convertir desde formatos GIS {#convert-from-gis-formats}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> puede convertir fácilmente su archivo de mapa GIS a otro formato de archivo.  
Por ejemplo, el fragmento de código para convertir GPX a PDF es el siguiente:

```csharp
// Load the source GPX file
using (Converter converter = new Converter("sample.gpx"))
{
    // Set the convert options for PDF format
    PdfConvertOptions options = new PdfConvertOptions();
    // Convert to PDF format
    converter.Convert("converted.pdf", options);
}
```

Básicamente, solo cargas un archivo GIS en el `Converter` clase, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.  


:::info
Consulte el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API</a> para más opciones de conversión y personalizaciones.
:::


## Convertir a otro formato GIS {#convert-to-another-gis-format}

Por otro lado, convertir sus archivos GIS a otro formato GIS también es bastante sencillo y natural.
El fragmento de código siguiente muestra cómo convertir un archivo GPX a KML en C# utilizando GroupDocs.Conversion.

```csharp
// Load the source GPX file
using (Converter converter = new Converter("sample.gpx"))
{
    // Set the convert options for KML format
    var options = new GisConvertOptions {
        Format = GisFileType.Kml
    };
    // Convert to KML format
    converter.Convert("converted.kml", options);
}
```

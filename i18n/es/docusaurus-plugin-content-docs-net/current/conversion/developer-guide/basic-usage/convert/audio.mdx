## Sobre los formatos de archivo de audio {#about-audio-file-formats}

El formato de archivo de audio es una categoría de formatos de archivo digitales destinados a representar información de audio junto con sus metadatos. Existen múltiples formatos de archivo de audio, dependiendo de la naturaleza de los datos contenidos en el archivo. Estos archivos pueden almacenarse en formatos comprimidos o sin comprimir. Entre los formatos de archivo de audio más populares se incluyen MP3, WAV, PCM y WMA.

## Convertir a otro formato de audio {#convert-to-another-audio-format}

Con <a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>, puede convertir fácilmente su archivo de audio a otro formato de archivo de audio.

Para permitir conversiones de audio, GroupDocs.Conversion proporciona un punto de extensibilidad que delega la conversión real de audio a una biblioteca de procesamiento de audio, al tiempo que le ofrece la simplicidad de la configuración de conversión. El punto de extensibilidad es la interfaz <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.integration.audio/iaudioconnector" target="_blank" rel="nofollow noopener noreferrer">IAudioConnector</a>. 

En primer lugar, debe decidir qué biblioteca de procesamiento de audio utilizará. Distintas bibliotecas tienen procesos de configuración diferentes.

En nuestro ejemplo, utilizaremos la biblioteca FFMPEG. Recomendamos utilizar <a href="https://chocolatey.org/" target="_blank" rel="nofollow noopener noreferrer">Chocolatey</a> para instalar la biblioteca <a href="https://ffmpeg.org/" target="_blank" rel="nofollow noopener noreferrer">FFMPG</a> y todas sus dependencias necesarias. 
Para instalar FFMPEG con Chocolatey, ejecute el siguiente comando en la consola:
```shell
choco install ffmpeg
```

Una vez instalada la biblioteca de procesamiento de audio, debe implementar una interfaz <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.integration.audio/iaudioconnector" target="_blank" rel="nofollow noopener noreferrer">IAudioConnector</a>. Para esta implementación, se debe instalar el paquete NuGet <a href="https://www.nuget.org/packages/FFMpegCore" target="_blank" rel="nofollow noopener noreferrer">FFMpegCore</a> en su proyecto. El siguiente fragmento proporciona un ejemplo de implementación:

```csharp
public class AudioConnector : IAudioConnector
{
    private readonly Dictionary<AudioFileType, Action<FFMpegArgumentOptions>> _optionsMap = new Dictionary<AudioFileType, Action<FFMpegArgumentOptions>>();

    public AudioConnector()
    {
        _optionsMap.Add(AudioFileType.Mp3, SetMp3ConvertOptions);
        _optionsMap.Add(AudioFileType.Ogg, SetOggConvertOptions);
        _optionsMap.Add(AudioFileType.Aac, SetAacConvertOptions);
        _optionsMap.Add(AudioFileType.Ac3, SetAc3ConvertOptions);
        _optionsMap.Add(AudioFileType.Flac, SetFlacConvertOptions);
        _optionsMap.Add(AudioFileType.Wma, SetWmaConvertOptions);
        _optionsMap.Add(AudioFileType.Wav, SetWavConvertOptions);
        _optionsMap.Add(AudioFileType.M4a, SetM4aConvertOptions);
        _optionsMap.Add(AudioFileType.Aiff, SetAiffConvertOptions);
    }

    public Stream ConvertAudio(Stream sourceStream, AudioConvertOptions convertOptions)
    { 
        var resultStream = new MemoryStream();

        var arguments = FFMpegArguments
            .FromPipeInput(new StreamPipeSource(sourceStream))
            .OutputToPipe(new StreamPipeSink(resultStream), options =>
            {
                if (_optionsMap.ContainsKey(convertOptions.Format))
                {
                    _optionsMap[convertOptions.Format].Invoke(options);
                }
                else
                {
                    throw new InvalidOperationException(
                        $"Conversion to {convertOptions.Format.Extension} is not supported at the moment");
                }
            });
        arguments.ProcessSynchronously();
            
        return resultStream;
    }

    private void SetMp3ConvertOptions(FFMpegArgumentOptions options)
    {
        options.WithAudioCodec(AudioCodec.LibMp3Lame);
        options.ForceFormat("mp3");
    }

    private void SetOggConvertOptions(FFMpegArgumentOptions options)
    {
        options.WithAudioCodec(AudioCodec.LibVorbis);
        options.ForceFormat("ogg");
    }

    private void SetAacConvertOptions(FFMpegArgumentOptions options)
    {
        options.WithAudioCodec(AudioCodec.Aac);
        options.ForceFormat("adts");
    }

    private void SetAc3ConvertOptions(FFMpegArgumentOptions options)
    {
        options.WithAudioCodec(AudioCodec.Ac3);
        options.ForceFormat("ac3");
    }

    private void SetFlacConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("flac");
    }

    private void SetWmaConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("asf");
    }

    private void SetWavConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("wav");
    }

    private void SetM4aConvertOptions(FFMpegArgumentOptions options)
    {
        options.WithAudioCodec(AudioCodec.Aac);
        options.ForceFormat("adts");
    }

    private void SetAiffConvertOptions(FFMpegArgumentOptions options)
    {
        options.ForceFormat("aiff");
    }
}
```

Una vez que `IAudioConnector` si se implementa la interfaz, el fragmento de código para convertir MP3 a FLAC se ve así:

```csharp
// Load the source MP3 file
AudioLoadOptions loadOptions = new AudioLoadOptions();
loadOptions.SetAudioConnector(new AudioConnector());
using (Converter converter = new Converter("sample.mp3", (LoadContext loadContext) => loadOptions))
{
    // Set the convert options for FLAC format
    AudioConvertOptions options = new AudioConvertOptions {
        Format = AudioFileType.Flac
    };
    // Convert to FLAC format
    converter.Convert("converted.flac", options);
}
```

Póngalo de forma sencilla: instala la biblioteca de procesamiento de audio, implementa la `IAudioConnector` interfaz que enlaza `GroupDocs.Conversion` con la biblioteca de procesamiento de audio, cargue un archivo de audio en el `Converter` clase que proporciona la `IAudioConnector` instancia, seleccione el formato de salida deseado y **GroupDocs.Conversion** se encarga del resto.

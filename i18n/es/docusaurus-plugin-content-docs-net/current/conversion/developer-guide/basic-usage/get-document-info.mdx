GroupDocs.Conversion proporciona una forma estándar de obtener información sobre el documento de origen. Funciona independientemente de cómo se haya cargado el documento: desde un disco, un flujo o un almacenamiento en la nube.

Para obtener la información del documento, utilice el método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Converter.GetDocumentInfo()</a>. Este método devuelve un objeto <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/documentinfo/" target="_blank" rel="nofollow noopener noreferrer">DocumentInfo</a> que contiene información común a todos los documentos admitidos: formato, fecha de creación, tamaño y número de páginas. 

Para recorrer las propiedades de la información del documento, utilice los enumeradores `PropertyNames` y `Item`. El siguiente fragmento de código muestra cómo enumerar todas las propiedades de información del documento disponibles:

```csharp
using (Converter converter = new Converter("sample.txt"))
{
    IDocumentInfo info = converter.GetDocumentInfo();
    
    foreach (var propertyName in info.PropertyNames)
    {
        Console.WriteLine(propertyName + ": "+ info[propertyName]);
    }
}
```
Según el tipo de formato, el objeto `DocumentInfo` resultante también contiene cierta información adicional:

* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/pdfdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Documentos PDF</a>: título, tabla de contenido, autor, si está cifrado, etc.;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/wordprocessingdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Documentos de procesamiento de texto</a>: título, tabla de contenido, autor, número de líneas, número de palabras, si está protegido con contraseña, etc.;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/projectmanagementdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Documentos de gestión de proyectos</a>: fechas de inicio y finalización del proyecto, número de tareas;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/imagedocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Images</a>: ancho, alto, bits por píxel;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/presentationdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Presentations</a>: título, autor, si está protegido con contraseña;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/spreadsheetdocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Spreadsheets</a>: título, autor, número de hojas de cálculo, si está protegido con contraseña;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/caddocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Dibujos CAD</a>: ancho, alto, colecciones de diseños y capas;
* <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/emaildocumentinfo/" target="_blank" rel="nofollow noopener noreferrer">Emails</a>: número y nombres de archivos adjuntos, si está cifrado, si está firmado, si su cuerpo está en formato HTML;

Consulte la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/" target="_blank" rel="nofollow noopener noreferrer">referencia de la API</a> para obtener una lista completa de los metadatos específicos por formato de documento.

Los ejemplos siguientes muestran cómo obtener la información del documento para diversos formatos.

### Documentos PDF {#pdf-documents}

```csharp
using (Converter converter = new Converter("sample-toc.pdf"))
{
    IDocumentInfo info = converter.GetDocumentInfo();
    PdfDocumentInfo docInfo = (PdfDocumentInfo) info;

    Console.WriteLine("Author: {0}", docInfo.Author);
    Console.WriteLine("Creation date: {0}", docInfo.CreationDate);
    Console.WriteLine("Title: {0}", docInfo.Title);
    Console.WriteLine("Version: {0}", docInfo.Version);
    Console.WriteLine("Pages count: {0}", docInfo.PagesCount);
    Console.WriteLine("Width: {0}", docInfo.Width);
    Console.WriteLine("Height: {0}", docInfo.Height);
    Console.WriteLine("Is landscaped: {0}", docInfo.IsLandscape);
    Console.WriteLine("Is Encrypted: {0}", docInfo.IsEncrypted);
    foreach (var tocItem in docInfo.TableOfContents)
    {
        Console.WriteLine($"{tocItem.Title}: {tocItem.Page}");
    }
}
```

- **Conversión de documentos**: Convierte documentos entre más de 50 formatos, incluidos PDF, DOCX, XLSX, PPTX, HTML, imágenes y más.
- **Conversión de imágenes**: Convierte imágenes entre formatos como JPG, PNG, BMP, TIFF y otros.
- **Conversión de correos electrónicos**: Convierte archivos de correo electrónico (EML, MSG) a PDF u otros formatos.
- **Conversión de dibujos CAD**: Convierte archivos CAD (DWG, DXF) a PDF e imágenes.
- **Conversión de diagramas**: Convierte archivos de diagramas (VSDX, VSD) a PDF e imágenes.
- **Conversión de archivos de archivado**: Extrae y convierte contenido de archivos ZIP, RAR y otros formatos de archivado.
- **Conversión de archivos de presentación**: Convierte archivos de presentación (PPTX, PPT) a PDF e imágenes.
- **Conversión de hojas de cálculo**: Convierte hojas de cálculo (XLSX, XLS) a PDF e imágenes.
- **Conversión de libros electrónicos**: Convierte archivos EPUB y MOBI a PDF.

## Ejemplo Básico de Conversión

El siguiente ejemplo muestra cómo convertir un archivo DOCX a PDF utilizando GroupDocs.Conversion:

```csharp
using GroupDocs.Conversion;

// Cargar el documento de origen
using (var converter = new Converter(\"document.docx\"))
{
    // Configurar opciones de conversión
    var options = new PdfConvertOptions();

    // Guardar el documento convertido
    converter.Convert(\"output.pdf\", options);
}
```

Este código carga un archivo DOCX, lo convierte a PDF y guarda el resultado en un archivo llamado `output.pdf`."

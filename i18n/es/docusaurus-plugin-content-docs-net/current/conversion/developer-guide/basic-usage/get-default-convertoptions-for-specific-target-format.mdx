<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Conversion**</a> permite obtener las opciones de conversión predeterminadas para un formato de destino específico siguiendo los pasos a continuación:

1.   Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> pasando la ruta del documento de origen como parámetro del constructor
2.   Llamar al método <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversions</a> del objeto convertidor
3.   Utilizar la extensión del archivo o `FileType` como clave para el índice del objeto recibido como valor en el paso anterior  

El siguiente fragmento de código muestra cómo obtener las conversiones posibles del documento de origen:

```csharp
using (var converter = new Converter("source.docx"))
{
    var possibleConversions = converter.GetPossibleConversions();
    var targetConversion = possibleConversions["pdf"];
    var convertOptions = targetConversion?.ConvertOptions;
    if (convertOptions != null)
    {
        converter.Convert("converted.pdf", convertOptions);
    }
}
```

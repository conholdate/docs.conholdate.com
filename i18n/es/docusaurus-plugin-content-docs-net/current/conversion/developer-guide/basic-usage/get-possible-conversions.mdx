Existen múltiples formatos de destino disponibles al convertir documentos con **<a href="https://products.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a>** y siempre puedes consultar [Formatos de archivo admitidos](/net/conversion/getting-started/supported-document-formats/) documentación para más detalles.

¿Pero qué hay de obtener las conversiones posibles de forma programática? Por ejemplo, podría permitir a los usuarios finales seleccionar el formato de destino para un documento específico o mostrar la lista completa de formatos admitidos. 
Afortunadamente, la API de GroupDocs.Conversion ofrece varias formas de lograr esto, por lo que le recomendamos revisar las opciones disponibles a continuación.

## Obtener conversiones posibles para un documento específico {#get-possible-conversions-for-a-specific-document}

Cuando necesite conocer las posibles conversiones para un documento de origen proporcionado, puede hacerlo siguiendo los pasos a continuación:

1.   Cree una instancia de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> clase pasando la ruta del documento de origen como parámetro del constructor.
2.   Llame a <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getpossibleconversions" target="_blank" rel="nofollow noopener noreferrer">GetPossibleConversions</a> método de la <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a> objeto.

El método devolverá el <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.contracts/possibleconversions" target="_blank" rel="nofollow noopener noreferrer">PossibleConversions</a> colección con una lista completa de las posibles conversiones para el tipo de documento de origen.

El siguiente fragmento de código muestra cómo obtener las conversiones posibles del documento de origen:

```csharp
using (Converter converter = new Converter("sample.docx"))
{
    PossibleConversions conversions = converter.GetPossibleConversions();
    Console.WriteLine("The source document is of type {0} and could be converted to:", conversions.Source.Extension);

    foreach (var conversion in conversions.All)
    {
        Console.WriteLine("\t {0} as {1} conversion.",
            conversion.Format,
            conversion.IsPrimary ? "primary" : "secondary");
    }    
}
```

O puedes usar un [sintaxis fluida](/net/conversion/developer-guide/basic-usage/fluent-syntax/)

```csharp
PossibleConversions conversions = FluentConverter.Load("sample.docx").GetPossibleConversions();
Console.WriteLine("The source document is of type {0} and could be converted to:", conversions.Source.Extension);

foreach (var conversion in conversions.All)
{
     Console.WriteLine("\t {0} as {1} conversion.",
        conversion.Format,
        conversion.IsPrimary ? "primary" : "secondary");
}    

```

## Obtener todas las conversiones disponibles {#get-all-available-conversions}

Si es necesario obtener programáticamente una colección de todas las conversiones admitidas, basta con invocar el método estático <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter/getallpossibleconversions" target="_blank" rel="nofollow noopener noreferrer">GetAllPossibleConversions</a> de la clase <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/converter" target="_blank" rel="nofollow noopener noreferrer">Converter</a>.

El siguiente fragmento de código muestra cómo obtener todas las conversiones posibles:

```csharp
var allPossibleConversions = Converter.GetAllPossibleConversions();
foreach (var possibleConversions in allPossibleConversions)
{
    Console.WriteLine($"Source format: {possibleConversions.Source.Description}");
    foreach (var conversion in possibleConversions.All)
    {
        Console.WriteLine("\t...can be converted to {0} format as {1} conversion.",
            conversion.Format,
            conversion.IsPrimary ? "primary" : "secondary");        
    }
}
```

GroupDocs.Conversion para .NET está incluido en Conholdate.Total for .NET.
:::


:::info
GroupDocs.Conversion para .NET no requiere la instalación de ningún software externo, como Microsoft Word, Microsoft Excel o Microsoft PowerPoint. Para instalar GroupDocs.Conversion para .NET, simplemente siga uno de los métodos descritos en la [Instalación](/net/conversion/getting-started/installation/) sección.
:::


## Sistemas operativos compatibles {#supported-operating-systems}


GroupDocs.Conversion for .NET puede utilizarse en cualquier sistema operativo donde esté instalado el framework .NET, incluidos, entre otros:

### Windows {#windows}

*   Microsoft Windows Server 2012 R2 y versiones posteriores
*   Microsoft Windows 7 SP1 y versiones posteriores (x64, x86)
*   Microsoft Windows 10 (x64, x86, Arm64)
*   Microsoft Windows 11 (x64, Arm64)

### Linux {#linux}

*   Ubuntu 18.04 y versiones posteriores
*   Debian 10 y versiones posteriores
*   CentOS 7 y versiones posteriores
*   Fedora 33 y versiones posteriores
*   Alpine 3.13 y versiones posteriores

### macOS {#macos}

*   macOS 10.15 (Catalina) y versiones posteriores (x64, Arm64)



## Frameworks compatibles {#supported-frameworks}

GroupDocs.Conversion for .NET admite los siguientes frameworks de .NET:

*   .NET Framework 4.6.2 y versiones posteriores
*   .NET 6.0 y versiones posteriores


## Entornos de desarrollo {#development-environments}

GroupDocs.Conversion for .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los entornos explícitamente compatibles son los siguientes:

*   Microsoft Visual Studio 2017 y versiones posteriores
*   JetBrains Rider
*   Visual Studio Code con la extensión de C#

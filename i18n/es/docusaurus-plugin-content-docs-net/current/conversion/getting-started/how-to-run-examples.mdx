## Crear un proyecto desde cero {#build-a-project-from-scratch}

Puede crear un proyecto desde cero utilizando Visual Studio o <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">.NET CLI</a>. Le guiaremos paso a paso en ambos casos.

### Crear un proyecto utilizando .NET CLI {#build-a-project-using-net-cli}

Este método se aplica a proyectos de .NET 6 o superior.

1. Asegúrese de tener instalado el SDK de .NET <a href="https://dotnet.microsoft.com/download" target="_blank" rel="nofollow noopener noreferrer">https://dotnet.microsoft.com/download</a>.
2. Cree un directorio para su aplicación de consola ejecutando el comando `mkdir my-console-app` en su terminal.
3. Navegue hasta el directorio `my-console-app` ejecutando el comando `cd my-console-app`.
4. Cree una aplicación de consola vacía ejecutando el comando `dotnet new console`.
5. Agregue el paquete GroupDocs.Conversion para .NET ejecutando el comando `dotnet add package GroupDocs.Conversion`.
6. Edite `Program.cs` y agregue las siguientes líneas al método `Main`:
  
  ```csharp
    using GroupDocs.Conversion;
	using GroupDocs.Conversion.Options.Convert;

    string documentPath = @"C:\sample.docx"; // NOTE: Put here actual path for your document
    string outputPath = @"C:\output\converted.pdf";
  
    using (Converter converter = new Converter(documentPath))
    {
        PdfConvertOptions convertOptions = new PdfConvertOptions();
        converter.Convert(outputPath, convertOptions);
    }
  ```
  
7. Reemplace el valor `documentPath` con la ruta real al documento que va a convertir.
8. Ejecute el proyecto ejecutando el comando `dotnet run`.
9. El documento convertido se guardará en el directorio `C:\\output\\`.

### Compilar un proyecto utilizando Visual Studio {#build-a-project-using-visual-studio}

Este método se aplica tanto a proyectos de .NET 6+ como a proyectos de .NET Framework 4.6.2+.

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2. Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
3. Instale el paquete NuGet **GroupDocs.Conversion** adecuado para su marco de destino:
   * <a href="https://www.nuget.org/packages/GroupDocs.Conversion" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> – para .NET 6+
   * <a href="https://www.nuget.org/packages/GroupDocs.Conversion.NETFramework" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion.NETFramework</a> – para .NET Framework 4.6.2+

   Para instrucciones detalladas de instalación, consulte la [guía de instalación](/net/conversion/getting-started/installation/).
4. Agregue el siguiente código al método `Main`:

  ```csharp
    using GroupDocs.Conversion;
	using GroupDocs.Conversion.Options.Convert;

    string documentPath = @"C:\sample.docx"; // NOTE: Put here actual path for your document
    string outputPath = @"C:\output\converted.pdf";
  
    using (Converter converter = new Converter(documentPath))
    {
        PdfConvertOptions convertOptions = new PdfConvertOptions();
        converter.Convert(outputPath, convertOptions);
    }
  ```

5. Reemplace el valor `documentPath` con la ruta real al documento que va a convertir.
6. Compile y ejecute su proyecto.
7. El documento convertido se guardará en el directorio `C:\\output\\`.

## Ejecute ejemplos del backend {#run-back-end-examples}

Puede encontrar muchos ejemplos de backend en nuestro repositorio de <a href="https://github.com/groupdocs-conversion/GroupDocs.Conversion-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-conversion/GroupDocs.Conversion-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio desde GitHub utilizando su cliente Git favorito.  
En caso de que descargue el archivo ZIP, extraiga las carpetas en su disco local.

1. Vaya al directorio `Examples` y abra la solución `GroupDocs.Conversion.Examples.CSharp.sln` utilizando Visual Studio.
2. Abra el archivo `RunExamples.cs` y descomente los ejemplos que desea ejecutar.
3. Opcionalmente, puede establecer la ruta de la licencia en el archivo `Utils.cs`.

### Demo con Docker {#docker-demo}

Utilice la imagen <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> para probar fácilmente las funcionalidades de GroupDocs.Conversion para .NET. A continuación se muestran los comandos para ejecutar GroupDocs.Conversion para .NET desde la imagen de Docker.

```bash
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost  \
    -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples  \
    -v `pwd`/Licenses:/home/groupdocs/app/Licenses  \
    groupdocs/conversion
## Open http://localhost:8080/conversion in your favorite browser.
```

## Contribuir {#contribute}

Si deseas agregar o mejorar un ejemplo, te animamos a contribuir al proyecto. Todos los ejemplos de este repositorio son de código abierto y pueden utilizarse libremente en tus propias aplicaciones.  
Para contribuir, puedes bifurcar (fork) el repositorio, editar el código y crear una solicitud de extracción (pull request). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

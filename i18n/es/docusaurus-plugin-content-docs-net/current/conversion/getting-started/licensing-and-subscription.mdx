## Prueba gratuita o licencia temporal {#free-trial-or-temporary-license}

Puede probar GroupDocs.Conversion sin adquirir una licencia.

### Prueba gratuita {#free-trial}

La versión de evaluación es idéntica a la versión adquirida; simplemente, la versión de evaluación se convierte en una versión con licencia cuando establece la licencia. Puede configurar la licencia de varias maneras, como se describe en las siguientes secciones de este artículo.

La versión de prueba incluye las siguientes limitaciones:

* Solo se procesan las primeras 3 páginas.
* No se admiten documentos con más de 3 páginas.
* Se colocan marcas de prueba en la parte superior de cada página del documento.
  
### Licencia temporal {#temporary-license}

Si desea probar GroupDocs.Conversion sin las limitaciones de la versión de prueba, también puede solicitar una licencia temporal de 30 días. Para obtener más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank" rel="noopener noreferrer">"Obtener una licencia temporal"</a>.

## Cómo configurar una licencia {#how-to-set-up-a-license}


:::info
Puede encontrar información sobre precios en la <a href="https://purchase.conholdate.com/pricing/" target="_blank" rel="noopener noreferrer">Información de precios</a> página.
:::


Una vez obtenida la licencia, debe configurarla. Esta sección describe las opciones disponibles para realizar esta configuración, así como respuestas a algunas preguntas frecuentes.

La licencia debe configurarse:

- Solo una vez por dominio de aplicación,
- y antes de utilizar cualquier otra clase de GroupDocs.Conversion.


:::info
La licencia se puede configurar varias veces por dominio de aplicación, pero recomendamos hacerlo solo una vez, ya que todas las llamadas a la `SetLicense` método, excepto el primero, simplemente desperdiciará tiempo de procesador.
:::



### Establecer licencia desde archivo {#set-license-from-file}

El siguiente código establece una licencia a partir de un archivo.

```csharp
string licensePath = "path to the .lic file";
License license = new License();
license.SetLicense(licensePath);
```

### Establecer licencia desde un flujo {#set-license-from-stream}

El siguiente ejemplo muestra cómo establecer una licencia desde un flujo.

```csharp
string licensePath = "path to the .lic file";
using (FileStream fileStream = File.OpenRead(licensePath))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```

### Configurar licencia medible {#set-metered-license}

También puede configurar la licencia <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las funcionalidades de la API. Para más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank" rel="noopener noreferrer">Preguntas frecuentes sobre licencias medibles</a>.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la licencia `Metered`.

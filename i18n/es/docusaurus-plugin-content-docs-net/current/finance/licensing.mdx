## Aplicación de una licencia  {#applying-a-license}
  
Una vez que esté satisfecho con su <a href="https://downloads.aspose.com/finance/net" target="_blank" rel="nofollow noopener noreferrer">evaluación</a> de Aspose.Finance para .NET, adquiera una licencia en el sitio web de Aspose: <a href="https://purchase.conholdate.com/buy" target="_blank">Portal de compra</a>. Familiarícese con los distintos tipos de licencia disponibles. Si tiene alguna pregunta, <a href="https://about.conholdate.com/contact" target="_blank">póngase en contacto con el equipo de ventas de Conholdate</a> y con gusto le ayudarán.

Cada licencia de Aspose incluye una suscripción de un año para recibir actualizaciones gratuitas a cualquier nueva versión o corrección publicada durante ese período. Proporcionamos soporte técnico gratuito y sin limitaciones tanto a usuarios con licencia como a usuarios en modo de evaluación.

La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores con licencia, la fecha de vencimiento de la suscripción, entre otros. Dicho archivo está firmado digitalmente, por lo tanto, no lo modifique: incluso agregar un salto de línea adicional invalida el archivo.

### Cuándo aplicar una licencia  {#when-to-apply-a-license}
  
Siga estas reglas sencillas:  

- La licencia solo necesita configurarse una vez por dominio de aplicación.
- Debe configurar la licencia antes de utilizar cualquier otra clase de Aspose.Finance.
- Llamar a SetLicense varias veces no es perjudicial, pero desperdicia tiempo de procesamiento.
- Si está desarrollando una aplicación de Windows Forms o de consola, llame a SetLicense en el código de inicio, antes de utilizar las clases de Aspose.Finance.
- Al desarrollar una aplicación ASP.NET, llame a SetLicense desde el archivo Global.asax.cs, dentro del método protegido Application_Start. Este método se ejecuta una única vez al iniciar la aplicación.
- No llame a SetLicense dentro de los métodos Page_Load, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
- Si está desarrollando una biblioteca de clases, llame a SetLicense desde un constructor estático de la clase que utilice Aspose.Finance. El constructor estático se ejecuta antes de que se cree una instancia de su clase, garantizando así que la licencia de Aspose.Finance se configure correctamente.

### Aplicar licencia mediante archivo u objeto de flujo  {#apply-license-using-file-or-stream-object}
  
Utilice el método <a href="https://reference.aspose.com/finance/net/aspose.finance/license" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense</a> para licenciar el componente. La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Finance.dll y especificar únicamente el nombre del archivo (sin ruta), como se muestra a continuación.

#### Cargar una licencia desde un archivo  {#loading-a-license-from-file}
  
Este fragmento de código inicializa una licencia almacenada en un archivo o en un recurso incrustado.

```csharp

public static void SetLicenseExample()
{
    // Initialize license object
    Aspose.Finance.License license = new Aspose.Finance.License();
    try
    {
        // Set license
        license.SetLicense("Aspose.Finance.lic");
    }
    catch (Exception)
    {
        // something went wrong
        throw;
    }
    Console.WriteLine("License set successfully.");
}
```

#### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
Estos fragmentos de código inicializan la licencia desde un flujo.

```csharp
public static void SetLicenseFromStream()
{
    // Initialize license object
    Aspose.Finance.License license = new Aspose.Finance.License();
    // Load license from the file stream
    System.IO.FileStream myStream =
        new System.IO.FileStream(
            "Aspose.Finance.lic",
            System.IO.FileMode.Open);
    // Set license
    license.SetLicense(myStream);
    Console.WriteLine("License set successfully.");
}
```

## Aplicar licencia por medición  {#apply-metered-license}
  
La API Aspose.Finance para .NET permite a los desarrolladores aplicar una licencia por medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.

Se ha agregado una nueva clase <a href="https://reference.aspose.com/finance/net/aspose.finance/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar la clave por medición. El siguiente ejemplo de código muestra cómo configurar las claves pública y privada por medición:

```csharp
public static void SetMeteredLicense()
{
    // Initialize a Metered license class object
    Aspose.Finance.Metered metered = new Aspose.Finance.Metered();
    // Apply public and private keys
    metered.SetMeteredKey("your-public-key", "your-private-key");
}
```

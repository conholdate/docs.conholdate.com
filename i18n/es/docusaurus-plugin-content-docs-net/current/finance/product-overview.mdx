## Información general  {#overview}
  
Aspose.Finance, al ser una biblioteca .NET pura, ofrece un rendimiento y una facilidad de uso significativamente superiores para manipular formatos relacionados con finanzas, como XBRL e iXBRL. La API de finanzas es extensible, fácil de usar, compacta y proporciona todas las funcionalidades comunes, lo que permite a los desarrolladores escribir menos código para realizar operaciones habituales.

El uso de Aspose.Finance para .NET en sus aplicaciones le aporta los siguientes beneficios.  

- Ricas funcionalidades
- Independencia de plataforma
- Rendimiento y escalabilidad

### Funcionalidades avanzadas {#rich-features}  

- Crear una instancia XBRL desde cero
- Leer formato XBRL
- Leer formato iXBRL
- Validación XBRL
- Validación iXBRL

### Independencia de plataforma {#platform-independence}
  
Puede utilizar Aspose.Finance para .NET para crear cualquier tipo de aplicación .NET de 32 o 64 bits, incluidas ASP.NET, servicios web y WinForms.

### Rendimiento y escalabilidad {#performance-and-scalability}
  
Aspose.Finance para .NET está diseñado para ofrecer un excelente rendimiento tanto en servidores como en clientes. Se trata de un único ensamblado .NET que puede implementarse con cualquier aplicación .NET simplemente copiándolo. No es necesario preocuparse por otros servicios o módulos.

## Soporte técnico {#technical-support}
  
users, including evaluation.

Si necesita ayuda con Aspose.Finance para .NET, considere lo siguiente:  

- El canal principal de soporte es Aspose.Forums. Publique su pregunta en el foro de Aspose.Finance para .NET y será respondida en cuestión de pocas horas. Las preguntas son respondidas directamente por el equipo de soporte de Aspose.Finance para .NET.
- Soporte en vivo. Cuando la diferencia horaria lo permita, puede comunicarse con nuestro soporte técnico en línea haciendo clic en el botón Chat en vivo de cualquier página web de Aspose.
- Tenga en cuenta que Aspose no proporciona soporte técnico por teléfono. El soporte telefónico solo está disponible para consultas relacionadas con ventas y compras.
- Al esperar una respuesta en los foros o en el soporte en vivo, tenga en cuenta las diferencias horarias.

Si tiene un problema con Aspose.Finance para .NET, siga estos sencillos pasos para asegurarse de que se resuelva de la forma más eficiente:  

- Asegúrese de utilizar la última versión de Aspose.Finance para .NET antes de informar del problema; consulte la descarga de Aspose.Finance para .NET para conocer la versión más reciente.
- Consulte los foros, esta documentación y la Referencia de la API antes de informar del problema; es posible que su pregunta ya haya sido respondida.
- Al informar de un problema, incluya el documento original y, si es posible, un fragmento de su código que cause el problema. Si necesita adjuntar varios archivos, comprímalos en un solo archivo ZIP. Es seguro adjuntar sus documentos en Aspose.Forums, ya que solo usted y los desarrolladores de Aspose tendrán acceso a los archivos adjuntos.
- Intente informar de un solo problema por hilo. Si tiene otro problema, infórmelo en un hilo independiente.

:::info
GroupDocs.Merger para .NET no requiere la instalación de ningún software externo ni herramientas de terceros. Para instalar GroupDocs.Merger para .NET, simplemente siga uno de los métodos descritos en la sección [Instalación](/net/merger/getting-started/installation/).
:::


## Sistemas Operativos Compatibles {#supported-operating-systems}


GroupDocs.Merger para .NET puede utilizarse en cualquier sistema operativo donde esté instalado el framework .NET, incluyendo, sin limitarse a:

### Windows {#windows}

*   Microsoft Windows Server 2012 R2 y versiones posteriores
*   Microsoft Windows 7 SP1 y versiones posteriores (x64, x86)
*   Microsoft Windows 10 (x64, x86, Arm64)
*   Microsoft Windows 11 (x64, Arm64)

### Linux {#linux}

*   Ubuntu 18.04 y versiones posteriores
*   Debian 10 y versiones posteriores
*   CentOS 7 y versiones posteriores
*   Fedora 33 y versiones posteriores
*   Alpine 3.13 y versiones posteriores

### macOS {#macos}

*   macOS 10.15 (Catalina) y versiones posteriores (x64, Arm64)



## Frameworks Compatibles {#supported-frameworks}

GroupDocs.Merger para .NET admite los siguientes frameworks de .NET:

*   .NET Framework 4.6.2 y versiones posteriores
*   .NET 6.0 y versiones posteriores


## Entornos de Desarrollo {#development-environments}

GroupDocs.Merger para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los siguientes entornos cuentan con soporte explícito:

*   Microsoft Visual Studio 2017 y versiones posteriores
*   JetBrains Rider
*   Visual Studio Code con la extensión de C#

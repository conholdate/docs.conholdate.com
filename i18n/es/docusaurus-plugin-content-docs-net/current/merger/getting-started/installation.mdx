Este tema describe cómo agregar la biblioteca GroupDocs.Merger a su proyecto .NET.

## Instalación desde NuGet {#install-from-nuget}

GroupDocs.Merger está disponible en NuGet. A partir de la versión 26.4, el paquete principal `GroupDocs.Merger` es un paquete meta que automáticamente incluye el paquete de tiempo de ejecución adecuado para el marco de destino de su proyecto.

### Uso de la CLI de .NET {#using-net-cli}

Abra una terminal en la carpeta de su proyecto y ejecute:

```bash
dotnet add package GroupDocs.Merger
```

### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}

En Visual Studio, abra **Herramientas** &gt; **Administrador de paquetes NuGet** &gt; **Consola del Administrador de paquetes** y ejecute:

```powershell
Install-Package GroupDocs.Merger
```

### Uso de PackageReference {#using-packagereference}

Añada directamente a su archivo `.csproj`:

```xml
<PackageReference Include="GroupDocs.Merger" Version="26.4.0" />
```

## Paquetes en tiempo de ejecución {#runtime-packages}

El paquete de NuGet incluye ensamblados para cuatro marcos de destino:

| Marco de destino | Paquete en tiempo de ejecución |
| ----------------------- | ------------------------------ |
| .NET Framework 4.6.2 | `GroupDocs.Merger.Net462` |
| .NET 6.0 | `GroupDocs.Merger.Net60` |
| .NET 8.0 | `GroupDocs.Merger.Net80` |
| .NET 10.0 | `GroupDocs.Merger.Net100` |

En la mayoría de los casos, instale únicamente el paquete principal `GroupDocs.Merger`: NuGet resolverá automáticamente el paquete en tiempo de ejecución adecuado. También puede instalar directamente un paquete en tiempo de ejecución específico si es necesario:

```bash
dotnet add package GroupDocs.Merger.Net80
```

## Descargar desde el sitio web oficial {#download-from-the-official-website}

También puede descargar los ensamblados como un archivo ZIP o un instalador MSI desde el sitio web <a href="https://releases.groupdocs.com/merger/net/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs Releases</a>.

1. Descargue el archivo ZIP o MSI correspondiente a la versión deseada.
2. Extraiga los archivos (ZIP) o ejecute el instalador (MSI).
3. En su proyecto, agregue una referencia al archivo `GroupDocs.Merger.dll` para el marco de trabajo objetivo que necesite (por ejemplo, `lib/net8.0/GroupDocs.Merger.dll`).

## Verificar la instalación {#verify-installation}

Tras la instalación, verifique que el paquete esté accesible imprimiendo la versión del ensamblado cargado:

```csharp
using GroupDocs.Merger;

Console.WriteLine(typeof(Merger).Assembly.GetName().Version);
```

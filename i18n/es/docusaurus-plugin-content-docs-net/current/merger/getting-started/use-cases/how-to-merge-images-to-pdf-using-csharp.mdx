## API de fusión de PDF para .NET {#pdf-merger-net-api}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores combinar múltiples documentos de imagen en el orden deseado y guardarlos como un único archivo PDF.

## Sobre el formato de archivo PDF {#about-pdf-file-format}

El formato de documento portátil (PDF, por sus siglas en inglés) es un tipo de documento creado por Adobe a finales de la década de 1990. El propósito de este formato de archivo fue establecer un estándar para representar documentos y otro material de referencia en un formato independiente del software de aplicación, el hardware y el sistema operativo. Los archivos PDF pueden abrirse en Adobe Acrobat Reader/Writer, así como en la mayoría de los navegadores modernos, como Chrome, Safari y Firefox, mediante extensiones o complementos.

### Cómo fusionar archivos de imagen en PDF {#how-to-merge-image-files-to-pdf}

El siguiente ejemplo demuestra cómo fusionar archivos de imagen en un archivo PDF con varias líneas de código en C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pase la ruta del archivo de imagen de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades. Además, pase una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> como segundo parámetro del constructor.
* Agregue otro archivo de imagen para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos de imagen que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PDF fusionado como parámetro.

```csharp

// Load the source image file
using (Merger merger = new Merger(@"c:\sample1.jpeg", new LoadOptions(FileType.PDF)))
{
    // Add another image file to merge
    merger.Join(@"c:\sample2.png");
    // Add next image file to merge
    merger.Join(@"c:\sample3.bmp");
    // Merge image files and save PDF result
    merger.Save(@"c:\merged.pdf");
}
```

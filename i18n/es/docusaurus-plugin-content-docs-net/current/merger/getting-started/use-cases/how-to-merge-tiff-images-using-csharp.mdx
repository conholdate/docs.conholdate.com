## Acerca del formato de archivo TIFF {#about-tiff-file-format}

TIFF (Tag Image File Format, formato de archivo de imagen etiquetada) es un archivo informático utilizado para almacenar gráficos rasterizados e información de imágenes. Muy popular entre los fotógrafos, los archivos TIFF son una opción práctica para almacenar imágenes de alta calidad antes de editarlas, especialmente si se desea evitar formatos de archivo con pérdida.

### Cómo fusionar archivos TIFF en modo vertical {#how-to-merge-tiff-files-in-vertical-mode}

El siguiente ejemplo demuestra cómo fusionar archivos de imagen en modo vertical con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo de imagen de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinoptions" target="_blank" rel="nofollow noopener noreferrer">ImageJoinOptions</a> clase y pasar el valor de enumeración de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinmode" target="_blank" rel="nofollow noopener noreferrer">ImageJoinMode</a> como un parámetro del constructor.
* Agregue otro archivo de imagen para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método y pasar una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/imagejoinoptions" target="_blank" rel="nofollow noopener noreferrer">ImageJoinOptions</a> clase como parámetro de método. Repita este paso para otros documentos de imagen que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo de imagen fusionada como parámetro.

```csharp
// Load the source image file
using (Merger merger = new Merger(@"c:\sample1.tiff"))
{
    // Define image join options with vertical join mode
    ImageJoinOptions joinOptions = new ImageJoinOptions(ImageJoinMode.Vertical);
    // Add another image file to merge
    merger.Join(@"c:\sample2.tiff", joinOptions);
    // Add next image file to merge
    merger.Join(@"c:\sample3.tiff", joinOptions);
    // Merge image files and save result
    merger.Save(@"c:\merged.tiff");
}
```

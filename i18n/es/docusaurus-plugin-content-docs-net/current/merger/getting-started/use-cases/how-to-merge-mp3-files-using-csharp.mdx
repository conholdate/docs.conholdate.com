## API de .NET para fusionar MP3 {#mp3-merger-net-api}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores combinar varios archivos de audio MP3 en el orden deseado y guardarlos como un único archivo.

## Sobre el formato de archivo MP3 {#about-mp3-file-format}

El formato de archivo MP3 (MPEG-1 Audio Layer 3) es un formato de compresión de audio ampliamente utilizado, conocido por su capacidad para reducir significativamente el tamaño de los archivos de grabaciones de audio, manteniendo al mismo tiempo una calidad de sonido razonablemente buena. MP3 es un formato de compresión con pérdida de datos, lo que significa que logra tamaños de archivo más pequeños eliminando algunos datos de audio que son menos perceptibles para el oído humano. 

MP3 es uno de los formatos de audio con mayor compatibilidad universal. Es compatible con una amplia gama de dispositivos, software y plataformas, lo que lo hace adecuado para compartir y reproducir en distintos sistemas.

### Cómo fusionar varios archivos MP3 en un único archivo {#how-to-merge-several-mp3-files-into-a-single-file}

El siguiente ejemplo muestra cómo fusionar varios archivos de audio con unas pocas líneas de código C#:

* Cree una instancia de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y pase la ruta del archivo de audio fuente como parámetro del constructor. Puede especificar rutas absolutas o relativas según sus necesidades.
* Agregue otro archivo de audio para fusionarlo mediante el método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a>. Repita este paso para los demás archivos de audio que desee fusionar.
* Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> y especifique el nombre de archivo para el archivo de audio resultante como parámetro.

```csharp
// Load the source MP3 file
using (var merger = new GroupDocs.Merger.Merger(@"c:\sample1.mp3"))
{
    // Add another MP3 file to merge
    merger.Join(@"c:\sample2.mp3");
    // Merge MP3 files and save result
    merger.Save(@"c:\merged.mp3");
}
```

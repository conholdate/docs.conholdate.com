Los desarrolladores pueden utilizar <a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> para concatenar múltiples archivos de audio WAV en la secuencia deseada y guardarlos como un único archivo.

## Sobre el formato de archivo WAV {#about-wav-file-format}

El formato WAV (Waveform Audio File Format, o formato de archivo de audio de onda) es un formato de archivo de audio ampliamente utilizado, comúnmente empleado para almacenar datos de audio sin comprimir. Este formato no aplica ninguna compresión al flujo de bits y almacena las grabaciones de audio con distintas tasas de muestreo y velocidades de bits. Ha sido y sigue siendo uno de los formatos estándar para los CD de audio. 

Los archivos WAV gozan de un amplio soporte por parte de software y dispositivos de hardware de audio, lo que los convierte en una opción versátil para la grabación, edición y reproducción de audio.

### Cómo fusionar varios archivos WAV en un único archivo {#how-to-merge-several-wav-files-into-a-single-file}

El siguiente ejemplo muestra cómo combinar varios archivos de audio mediante varias líneas de código C#:

* Crear una instancia de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y pasar la ruta del archivo de audio fuente como parámetro del constructor. Puede especificar rutas absolutas o relativas según sus necesidades.
* Añadir otro archivo de audio para fusionarlo mediante el método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a>. Repita este paso para los demás archivos de audio que desee fusionar.
* Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> y especificar el nombre de archivo para el archivo de audio resultante como parámetro.

```csharp
// Load the source WAV file
using (var merger = new GroupDocs.Merger.Merger(@"c:\sample1.wav"))
{
    // Add another WAV file to merge
    merger.Join(@"c:\sample2.wav");
    // Merge WAV files and save result
    merger.Save(@"c:\merged.wav");
}
```

## ZIP Merger .NET API {#zip-merger-net-api}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores combinar múltiples documentos archivados en el orden deseado y guardarlos como un único archivo ZIP.

## Acerca del formato de archivo ZIP {#about-zip-file-format}

Un archivo con la extensión .zip es un archivo archivado que puede contener uno o más archivos o directorios. Dicho archivo archivado puede aplicar compresión a los archivos incluidos con el fin de reducir el tamaño del archivo ZIP. El formato de archivo ZIP se hizo público en febrero de 1989 por Phil Katz, con el objetivo de lograr la archivación de archivos y carpetas. Este formato se integró en la utilidad PKZIP, creada por PKWARE, Inc. Poco después de la disponibilidad de las especificaciones, muchas empresas incorporaron el formato de archivo ZIP en sus utilidades de software, entre ellas Microsoft (desde Windows 7), Apple (Mac OS X) y muchas otras.

### Cómo fusionar archivos en un archivo ZIP {#how-to-merge-archives-to-zip-file}

El siguiente ejemplo demuestra cómo fusionar archivos en un archivo ZIP con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo de archivo fuente como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo de archivo para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos archivados que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo archivado fusionado como parámetro.

```csharp
// Load the source archive file
using (Merger merger = new Merger(@"c:\sample1.zip"))
{
    // Add another archive file to merge
    merger.Join(@"c:\sample2.tar");
    // Add next archive file to merge
    merger.Join(@"c:\sample3.rar");
    // Merge archive files and save result
    merger.Save(@"c:\merged.zip");
}
```

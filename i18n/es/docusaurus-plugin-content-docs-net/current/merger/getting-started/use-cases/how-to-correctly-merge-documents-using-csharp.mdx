# con Rutas de Archivos

La forma más sencilla y fiable de fusionar archivos PDF, utilizando el producto «GroupDocs.Merger for .NET», es emplear las rutas completas a estos archivos.

El siguiente ejemplo demuestra cómo fusionar archivos PDF utilizando rutas de archivo en código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta completa del archivo PDF como parámetro del constructor.
* Agregue otro archivo PDF para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PDF fusionado como parámetro.

```csharp
// Load the source PDF file
using (Merger merger = new Merger(@"c:\sample1.pdf"))
{
    // Add another PDF file to merge
    merger.Join(@"c:\sample2.pdf");
    // Merge PDF files and save result
    merger.Save(@"c:\merged.pdf");
}
```

# con File Streams

También existen varias formas de trabajar con flujos de archivos que deben combinarse utilizando el producto GroupDocs.Merger. La forma más fiable de combinar archivos sin parámetros adicionales es utilizar la clase `System.FileStream`.

El siguiente ejemplo demuestra cómo fusionar flujos de archivos DOCX en código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar el flujo de archivo DOCX como parámetro del constructor.
* Agregue otro flujo de archivo DOCX para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo DOCX fusionado como parámetro.

```csharp
string filePath1 = "c:/sample1.docx";
string filePath2 = "c:/sample2.docx";

FileStream fileStream1 = File.OpenRead(filePath1);
FileStream fileStream2 = File.OpenRead(filePath2);

// Load the source DOCX file stream
using (Merger merger = new Merger(fileStream1))
{
    // Add another DOCX file stream to merge
    merger.Join(fileStream2);
    // Merge DOCX file streams and save result
    merger.Save(@"c:\merged.docx");
}
```

# con flujos de memoria

Existen situaciones, y con bastante frecuencia, en las que es necesario trabajar con otras clases heredadas de `System.Stream`, por ejemplo, con `MemoryStream` u otras. En este caso, es necesario utilizar parámetros adicionales para especificar el tipo de archivo exacto que se utiliza en dicha situación, ya que el producto «GroupDocs.Merger for .NET» no siempre puede determinar con precisión el tipo de archivo a partir de su flujo. Por lo tanto, para evitar excepciones al fusionar archivos PDF y otros formatos, consulte el ejemplo siguiente:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> con el tipo de archivo PPTX como parámetro del constructor.
* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/joinoptions" target="_blank" rel="nofollow noopener noreferrer">JoinOptions</a> clase con el tipo de archivo PPTX como parámetro del constructor.
* Agregue otro flujo PPTX para fusionarlo con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método y pasar una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/joinoptions" target="_blank" rel="nofollow noopener noreferrer">JoinOptions</a> clase como parámetro de método.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PPTX fusionado como parámetro.

```csharp

string filePath1 = "c:/sample1.pptx";
string filePath2 = "c:/sample2.pptx";

FileType fileType1 = FileType.FromExtension(Path.GetExtension(filePath1));
FileType fileType2 = FileType.FromExtension(Path.GetExtension(filePath2));

MemoryStream memoryStream1 = new MemoryStream();
using (FileStream fileStream1 = File.OpenRead(filePath1))
{
    fileStream1.CopyTo(memoryStream1);
}

MemoryStream memoryStream2 = new MemoryStream();
using (FileStream fileStream2 = File.OpenRead(filePath2))
{
    fileStream2.CopyTo(memoryStream2);
}

// Init Load options with defined FileType
LoadOptions loadOptions = new LoadOptions(fileType1);

// Load the source PPTX stream
using (Merger merger = new Merger(memoryStream1, loadOptions))
{
    // Define join options with PPTX file type
    JoinOptions joinOptions = new JoinOptions(fileType2);
    // Add another PPTX stream to merge
    merger.Join(memoryStream2, joinOptions);
    // Merge PPTX streams and save result
    merger.Save(@"c:\merged.pptx");
}
```

# con Memoria Streams para fusión cruzada

También puede haber situaciones en las que sea necesario combinar diferentes tipos de flujos en un PDF. En este caso, puede utilizar el ejemplo siguiente:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> con el tipo de archivo DOCX de entrada y el tipo PDF de salida como parámetros del constructor.
* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/joinoptions" target="_blank" rel="nofollow noopener noreferrer">JoinOptions</a> clase con el tipo de archivo PPTX como parámetro del constructor.
* Agregue otro flujo PPTX para fusionarlo con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método y pasar una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/joinoptions" target="_blank" rel="nofollow noopener noreferrer">JoinOptions</a> clase como parámetro de método.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PDF fusionado como parámetro.

```csharp

string filePath1 = "c:/sample1.docx";
string filePath2 = "c:/sample2.pptx";

MemoryStream memoryStream1 = new MemoryStream();
using (FileStream fileStream1 = File.OpenRead(filePath1))
{
    fileStream1.CopyTo(memoryStream1);
}

MemoryStream memoryStream2 = new MemoryStream();
using (FileStream fileStream2 = File.OpenRead(filePath2))
{
    fileStream2.CopyTo(memoryStream2);
}

// Init Load options with defined FileTypes
LoadOptions loadOptions = new LoadOptions(FileType.DOCX, FileType.PDF);

// Load the source DOCX stream as PDF
using (Merger merger = new Merger(memoryStream1, loadOptions))
{
    // Define join options with PPTX file type
    JoinOptions joinOptions = new JoinOptions(FileType.PPTX);
    // Add another PPTX stream to merge
    merger.Join(memoryStream2, joinOptions);
    // Merge document streams and save PDF result
    merger.Save(@"c:\merged.pdf");
}
```

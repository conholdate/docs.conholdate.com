## API de fusión TIF para .NET {#tif-merger-net-api}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores combinar múltiples documentos TIF en el orden deseado y guardarlos como un único archivo.

### Sobre el formato de archivo TIF {#about-tif-file-format}

TIF (o TIFF) es un formato de imagen utilizado para contener gráficos de alta calidad. Significa «Tagged Image File Format» o «Tagged Image Format». El formato fue creado por Aldus Corporation, pero posteriormente Adobe adquirió el formato y realizó actualizaciones posteriores en el mismo. El archivo TIF puede contener tanto datos de imagen comprimidos con JPEG (con pérdida) como datos de imagen sin pérdida. También puede incluir datos gráficos basados en vectores. El formato de archivo TIF goza de un amplio soporte en aplicaciones de edición de imágenes, por lo que es un formato de imagen muy popular entre artistas gráficos, fotógrafos y editoriales. PaintShop Pro es una de las aplicaciones más populares disponibles para manejar imágenes TIF.

## Cómo fusionar archivos TIF {#how-to-merge-tif-files}
El siguiente ejemplo demuestra cómo fusionar archivos TIF con varias líneas de código en C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo TIF de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo TIF para fusionarlo con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos TIF que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo TIF fusionado como parámetro.

```csharp
// Load the source TIF file
using (Merger merger = new Merger(@"c:\sample1.tif"))
{
    // Add another TIF file to merge
    merger.Join(@"c:\sample2.tif");
    // Merge TIF files and save result
    merger.Save(@"c:\merged.tif");
}
```

NOTA: También puede fusionar otros formatos TIF, como TIFF, del mismo modo que se muestra anteriormente. Para ello, proporcione los archivos especificando sus nombres con la extensión correspondiente.

Ofrecemos múltiples formas de ejecutar los ejemplos de GroupDocs.Merger: puede crear su propio proyecto desde cero o clonar nuestro repositorio de ejemplos del lado del servidor y ejecutarlos directamente.

## Crear un proyecto desde cero {#build-a-project-from-scratch}

Puede crear un proyecto desde cero utilizando la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">CLI de .NET</a> o Visual Studio. Ambos caminos se describen a continuación.

### Crear un proyecto utilizando la CLI de .NET {#build-a-project-using-net-cli}

Este método es aplicable a proyectos de .NET 6 o superior.

1. Asegúrese de tener instalado el <a href="https://dotnet.microsoft.com/download" target="_blank" rel="nofollow noopener noreferrer">SDK de .NET</a>.
2. Cree un directorio para su aplicación de consola ejecutando el comando `mkdir my-console-app` en su terminal.
3. Navegue hasta el directorio `my-console-app` ejecutando el comando `cd my-console-app`.
4. Cree una aplicación de consola vacía ejecutando el comando `dotnet new console`.
5. Agregue el paquete GroupDocs.Merger para .NET ejecutando el comando `dotnet add package GroupDocs.Merger`.
6. Edite el archivo `Program.cs` y agregue las siguientes líneas al método `Main`:

    ```csharp
    using GroupDocs.Merger;

    // The path to the documents directory.
    string firstDocPath  = @"C:\sample.docx";  // NOTE: Put the actual path to your document here
    string secondDocPath = @"C:\sample2.docx"; // NOTE: Put the actual path to your document here
    string outputPath    = @"C:\output\result.docx";

    // Join two documents and save as result.docx.
    using (Merger merger = new Merger(firstDocPath))
    {
        merger.Join(secondDocPath);
        merger.Save(outputPath);
    }
    ```

7. Reemplace los valores `firstDocPath` y `secondDocPath` con las rutas reales a los documentos que desea fusionar.
8. Ejecute el proyecto ejecutando el comando `dotnet run`.
9. El documento fusionado se guardará en el directorio `C:\output\`.

### Compilar un proyecto utilizando Visual Studio {#build-a-project-using-visual-studio}

Este método se aplica tanto a proyectos de .NET 6+ como a proyectos de .NET Framework 4.6.2+.

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2. Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
3. Instale **GroupDocs.Merger para .NET** desde NuGet. Para instrucciones detalladas de instalación, consulte la guía [Instalación](/net/merger/getting-started/installation/).
4. Agregue el siguiente código al método `Main`:

    ```csharp
    using GroupDocs.Merger;

    // The path to the documents directory.
    string firstDocPath  = @"C:\sample.docx";  // NOTE: Put the actual path to your document here
    string secondDocPath = @"C:\sample2.docx"; // NOTE: Put the actual path to your document here
    string outputPath    = @"C:\output\result.docx";

    // Join two documents and save as result.docx.
    using (Merger merger = new Merger(firstDocPath))
    {
        merger.Join(secondDocPath);
        merger.Save(outputPath);
    }
    ```

5. Reemplace los valores `firstDocPath` y `secondDocPath` con las rutas reales de los documentos que desea fusionar.
6. Compile y ejecute su proyecto.
7. El documento fusionado se guardará en el directorio `C:\output\`.

## Ejemplos del backend {#run-back-end-examples}

El paquete completo de ejemplos de **GroupDocs.Merger** está alojado en <a href="https://github.com/groupdocs-merger/GroupDocs.Merger-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-merger/GroupDocs.Merger-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio utilizando su cliente Git favorito.

Si descarga el archivo ZIP, extraiga la carpeta en su disco local. El repositorio contiene:

* `Examples/GroupDocs.Merger.Examples.CSharp.sln` – la solución principal en C# que agrupa los proyectos de ejemplo para .NET (`GroupDocs.Merger.Examples.CSharp.Net`) y .NET Framework (`GroupDocs.Merger.Examples.CSharp.Framework`).
* `Examples/GroupDocs.Merger.Examples.CSharp/Resources/` – documentos e imágenes de ejemplo utilizados por los ejemplos.
* `Examples/GroupDocs.Merger.Examples.CSharp/RunExamples.cs` – el punto de entrada que redirige a cada método de ejemplo.

Para ejecutar los ejemplos:

1. Diríjase al directorio `Examples` y abra `GroupDocs.Merger.Examples.CSharp.sln` en su IDE (Visual Studio, JetBrains Rider o Visual Studio Code con la extensión de C#).
2. Restaure los paquetes de NuGet y compile la solución. Si faltan referencias a **GroupDocs.Merger**, consulte [Instalación](/net/merger/getting-started/installation/).
3. Abra `RunExamples.cs`, descomente los ejemplos que desea ejecutar y comente el resto.
4. Ejecute el proyecto. Los archivos de salida se escribirán en la ubicación especificada por cada ejemplo.

## Contribuir {#contribute}

Si desea agregar o mejorar un ejemplo, le animamos a que contribuya al proyecto. Todos los ejemplos del repositorio son de código abierto y pueden utilizarse libremente en sus propias aplicaciones.

Para contribuir, bifurque el repositorio, edite el código y abra una solicitud de extracción (pull request). Revisaremos los cambios y los incluiremos si se consideran útiles.

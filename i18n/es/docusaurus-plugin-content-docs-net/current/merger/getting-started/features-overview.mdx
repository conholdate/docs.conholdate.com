GroupDocs.Merger le permite unir múltiples documentos y manipular la estructura de un único documento a lo largo de una amplia gama de [tipos de documento compatibles](/net/merger/getting-started/supported-document-formats/), [tipos de audio compatibles](/net/merger/getting-started/supported-audio-formats/), [tipos de archivo comprimido compatibles](/net/merger/getting-started/supported-archive-formats/) y [tipos de fusión cruzada compatibles](/net/merger/getting-started/supported-cross-merging-formats/). A continuación, se presenta una breve lista de las acciones posibles:

## Operaciones con múltiples documentos {#multiple-document-operations}

### Unir documentos {#join-documents}

Esta función le permite [fusionar](/net/merger/developer-guide/merge/) dos o más documentos en uno solo, así como unir páginas específicas o rangos de páginas procedentes de varios documentos de origen en un único documento resultante.

## Operaciones con un único documento {#single-document-operations}

### Dividir documento {#split-document}

La operación **Dividir** permite [dividir](/net/merger/developer-guide/single-document-operations/split-document/) un documento de origen en varios documentos resultantes.

### Mover página {#move-page}

**MovePage** permite [mover una página](/net/merger/developer-guide/single-document-operations/move-page/) a otra posición dentro del documento.

### Eliminar páginas {#remove-pages}

La función **RemovePages** proporciona la capacidad de [eliminar](/net/merger/developer-guide/single-document-operations/remove-pages/) una página individual o un conjunto de números de página específicos del documento de origen.

### Rotar páginas {#rotate-pages}

La operación **RotatePages** le permite [rotar páginas](/net/merger/developer-guide/single-document-operations/rotate-pages/) dentro del documento. Puede rotar las páginas estableciendo el ángulo de rotación en 90, 180 o 270 grados.

### Intercambiar páginas {#swap-pages}

La operación **SwapPages** permite [intercambiar](/net/merger/developer-guide/single-document-operations/swap-pages/) las posiciones de dos páginas dentro del documento de origen. El resultado es un nuevo documento en el que ambas páginas han intercambiado sus posiciones.

### Extraer páginas {#extract-pages}

La función **ExtractPages** permite [extraer](/net/merger/developer-guide/single-document-operations/extract-pages/) páginas o rangos de páginas específicas del documento de origen. El resultado es un nuevo documento que contiene únicamente las páginas especificadas del documento de origen.

### Cambiar orientación de las páginas {#change-pages-orientation}

La operación **ChangeOrientation** le permite [establecer la orientación de página](/net/merger/developer-guide/single-document-operations/change-page-orientation/) (retrato o apaisado) para páginas específicas o para todas las páginas del documento.

## Operaciones de seguridad del documento {#document-security-operations}

La API de GroupDocs.Merger permite gestionar la protección por contraseña del documento mediante las siguientes operaciones de seguridad:

* [Comprobar si el documento está protegido por contraseña](/net/merger/developer-guide/security-operations/check-document-password-protection/);
* [Establecer contraseña del documento](/net/merger/developer-guide/security-operations/add-document-password/) si el documento no está protegido por contraseña;
* [Actualizar contraseña](/net/merger/developer-guide/security-operations/update-document-password/) si el documento ya está protegido por contraseña;
* [Eliminar contraseña](/net/merger/developer-guide/security-operations/remove-document-password/) si el documento está protegido por contraseña.

## Extracción de información del documento {#document-information-extraction}

GroupDocs.Merger permite obtener información básica sobre el documento de origen: tipo de archivo, tamaño, número de páginas, altura y ancho de página, etc.  
Esto puede ser muy útil para generar una vista previa del documento.

## Vista previa de las páginas del documento {#preview-document-pages}

La función de vista previa del documento permite generar representaciones en formato de imagen de las páginas del documento. Esto puede resultar útil para comprender mejor el contenido del documento y su estructura. La vista previa puede generarse para todas las páginas del documento (de forma predeterminada) o para números de página o rangos de páginas específicos.

Los formatos de imagen compatibles para la vista previa del documento son:

* PNG;
* JPG;
* BMP.

## Registro durante el procesamiento del documento {#logging-while-processing-document}

GroupDocs.Merger permite registrar la información de los procesos de manipulación de documentos mediante la interfaz <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.logging/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>. Existe la posibilidad de utilizar el <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.logging/consolelogger" target="_blank" rel="nofollow noopener noreferrer">ConsoleLogger</a> integrado o implementar su propia lógica de registro.

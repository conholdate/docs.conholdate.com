**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite intercambiar las posiciones de dos páginas dentro del documento de origen. El resultado es un nuevo documento en el que dos páginas han intercambiado sus posiciones.

A continuación se indican los pasos para intercambiar las páginas del documento:
*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/swapoptions" target="_blank" rel="nofollow noopener noreferrer">SwapOptions</a> con los números de página que se desean intercambiar;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/swappages" target="_blank" rel="nofollow noopener noreferrer">SwapPages</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/swapoptions" target="_blank" rel="nofollow noopener noreferrer">SwapOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde se guardará el documento resultante.

El siguiente ejemplo de código demuestra cómo dividir un documento:

```csharp
string filePath = @"c:\sample.pptx";
string filePathOut = @"c:\output\result.pptx";

int pageNumber1 = 3;
int pageNumber2 = 6;
SwapOptions swapOptions = new SwapOptions(pageNumber2, pageNumber1);

using (Merger merger = new Merger(filePath))
{
    merger.SwapPages(swapOptions);
    merger.Save(filePathOut);
}
```

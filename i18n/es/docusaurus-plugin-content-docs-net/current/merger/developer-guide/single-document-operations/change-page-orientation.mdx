**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite establecer la orientación de página **Retrato** u **Apaisado** para páginas específicas o para todas las páginas del documento.

A continuación se indican los pasos para cambiar la orientación de página:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/orientationoptions" target="_blank" rel="nofollow noopener noreferrer">OrientationOptions</a> con el modo de orientación deseado y los números de página;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/changeorientation" target="_blank" rel="nofollow noopener noreferrer">ChangeOrientation</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/orientationoptions" target="_blank" rel="nofollow noopener noreferrer">OrientationOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde guardar el documento resultante.

El siguiente ejemplo de código muestra cómo cambiar la orientación de página:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\result.docx";

OrientationOptions orientationOptions = new OrientationOptions(OrientationMode.Landscape, new int[] { 3, 4 });

using (Merger merger = new Merger(filePath))
{
    merger.ChangeOrientation(orientationOptions);
    merger.Save(filePathOut);
}
```

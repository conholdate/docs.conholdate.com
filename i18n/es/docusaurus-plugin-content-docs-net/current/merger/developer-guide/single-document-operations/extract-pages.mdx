**GroupDocs.Merger** permite extraer páginas del documento de origen. El resultado es un nuevo documento que contiene únicamente las páginas especificadas del documento de origen.

A continuación se indican los pasos para extraer páginas de un documento:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/extractoptions" target="_blank" rel="nofollow noopener noreferrer">ExtractOptions</a> con los números de página que deben aparecer en el documento resultante;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/extractpages" target="_blank" rel="nofollow noopener noreferrer">ExtractPages</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/extractoptions" target="_blank" rel="nofollow noopener noreferrer">ExtractOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde se guardará el documento resultante.

El siguiente ejemplo de código demuestra cómo extraer páginas de un documento **especificando los números de página exactos**:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

ExtractOptions extractOptions = new ExtractOptions(new int[] { 1, 4 }); // Resultant document will contain pages 1 and 4

using (Merger merger = new Merger(filePath))
{
    merger.ExtractPages(extractOptions);
    merger.Save(filePathOut);
}
```

El siguiente ejemplo de código muestra cómo extraer páginas de un documento **especificando un rango de números de página**:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

ExtractOptions extractOptions = new ExtractOptions(1, 3, RangeMode.EvenPages); // Resultant document will contain page 2
using (Merger merger = new Merger(filePath))
{
	merger.ExtractPages(extractOptions);
    merger.Save(filePathOut);
}
```

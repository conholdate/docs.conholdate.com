**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la capacidad de eliminar una sola página o una colección de números de página específicos del documento de origen.   
A continuación se indican los pasos para eliminar una o varias páginas del documento:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/removeoptions" target="_blank" rel="nofollow noopener noreferrer">RemoveOptions</a> con los números de página que se desean eliminar;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/removepages" target="_blank" rel="nofollow noopener noreferrer">RemovePages</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/removeoptions" target="_blank" rel="nofollow noopener noreferrer">RemoveOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle la ruta del archivo deseada para guardar el documento resultante.

El siguiente ejemplo de código muestra cómo eliminar páginas de un documento:

```csharp
string filePath = @"c:\sample.one";
string filePathOut = @"c:\output\result.one";

RemoveOptions removeOptions = new RemoveOptions(new int[] { 3, 5 });

using (Merger merger = new Merger(filePath))
{
    merger.RemovePages(removeOptions);
    merger.Save(filePathOut);
}

```

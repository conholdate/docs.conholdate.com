**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite dividir un archivo de texto en varios archivos de texto resultantes. El comportamiento predeterminado es dividir cada línea en un archivo independiente.  
A continuación se describen los pasos para dividir un archivo de texto:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/textsplitoptions" target="_blank" rel="nofollow noopener noreferrer">TextSplitOptions</a> con el formato de la ruta de los archivos de salida, el <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/textsplitmode" target="_blank" rel="nofollow noopener noreferrer">TextSplitMode</a> deseado y los números de línea;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/split/#split_1" target="_blank" rel="nofollow noopener noreferrer">Split</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/textsplitoptions" target="_blank" rel="nofollow noopener noreferrer">TextSplitOptions</a> para guardar los archivos de texto resultantes.

## Dividir un archivo de texto en varios archivos de una sola línea (según números de línea exactos) {#split-text-file-to-several-one-line-files-by-exact-line-numbers}

El siguiente ejemplo de código demuestra cómo dividir un archivo de texto en dos documentos de una página, utilizando las líneas 3.ª y 6.ª del archivo de origen:

```csharp
string filePath = @"c:\sample.txt";
string filePathOut = @"c:\output\line_{0}.{1}";

TextSplitOptions splitOptions = new TextSplitOptions(filePathOut, new int[] { 3, 6 });

using (Merger merger = new Merger(filePath))
{
    merger.Split(splitOptions);
}
```

Este fragmento de código producirá:

| Archivo de texto | Números de línea |
| --- | --- |
| línea_0 | 3 |
| línea_1 | 6 |

## Dividir archivo de texto en varios archivos multilínea {#split-text-file-to-several-multi-line-files}

El siguiente ejemplo de código demuestra cómo dividir un archivo de texto en varios archivos multilínea, comenzando desde la línea número 3 y terminando en la línea número 6:

```csharp
string filePath = @"c:\sample.txt";
string filePathOut = @"c:\output\text_{0}.{1}";

TextSplitOptions splitOptions = new TextSplitOptions(filePathOut, TextSplitMode.Interval, new int[] { 3, 6 });

using (Merger merger = new Merger(filePath))
{
    merger.Split(splitOptions);
}
```

Este fragmento de código producirá:

| Archivo de texto | Números de línea |
| --- | --- |
| text_0 | 1, 2 |
| text_1 | 3, 4, 5 |
| text_2 | 6 |

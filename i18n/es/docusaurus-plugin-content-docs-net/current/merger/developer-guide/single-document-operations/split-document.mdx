**GroupDocs.Merger** permite dividir un documento de origen en varios documentos resultantes. La división del documento puede realizarse de distintas formas, especificando un array de números de página o los números de página inicial y final, y configurando distintos modos de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/splitoptions" target="_blank" rel="nofollow noopener noreferrer">SplitOptions</a>.  
A continuación se presentan los casos de uso posibles:

1.  **Array de números de página** especificado y el modo de división establecido en <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/splitmode" target="_blank" rel="nofollow noopener noreferrer">SplitMode</a>. **Pages**: los números de página especificados indican los números exactos de página que se guardarán en documentos independientes de una sola página.  
    *Ex:* Array{ 3, 6, 8 } will produce 3 documents with 3rd, 6th and 8th pages.
    
2. **Matriz de números de página** especificada y el modo de división está configurado en <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/splitmode" target="_blank" rel="nofollow noopener noreferrer">SplitMode</a>.Intervalo: los números de página especificados indican los límites de los intervalos de página, los cuales se guardarán en documentos multipágina independientes.  
    *Ex:* Array{ 3, 6, 8 } will produce 4 page intervals 1-2, 3-5, 6-7, 8-10.    

También existe la posibilidad de establecer el parámetro <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/rangemode" target="_blank" rel="nofollow noopener noreferrer">RangeMode</a> y obtener únicamente las páginas pares o impares dentro del rango deseado.  
  
Los pasos para dividir un documento en varios documentos de una página son los siguientes:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/splitoptions" target="_blank" rel="nofollow noopener noreferrer">SplitOptions</a> con el formato de la ruta de los archivos de salida;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/split" target="_blank" rel="nofollow noopener noreferrer">Split</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/splitoptions" target="_blank" rel="nofollow noopener noreferrer">SplitOptions</a> para guardar los documentos resultantes.

## Dividir el documento en varios documentos de una página (según números de página exactos) {#split-the-document-to-several-one-page-documents-by-exact-page-numbers}

El siguiente ejemplo de código muestra cómo dividir un documento en tres documentos de una página, correspondientes a las páginas 3.ª, 6.ª y 8.ª:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\document_{0}.{1}";

SplitOptions splitOptions = new SplitOptions(filePathOut, new int[] { 3, 6, 8 });
           
using (Merger merger = new Merger(filePath))
{
     merger.Split(splitOptions);
}  
```

Este fragmento de código producirá:

| Nombre del documento | Números de página |
| --- | --- |
| document_3 | 3 |
| document_6 | 6 |
| document_8 | 8 |

## Dividir el documento en varios documentos de una página (según los números de página de inicio y fin) {#split-the-document-to-several-one-page-documents-by-start-end-page-numbers}

El siguiente ejemplo de código muestra cómo dividir un documento en varios documentos de una página, comenzando en la página número 3 y terminando en la página número 7:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\document_{0}.{1}";

SplitOptions splitOptions = new SplitOptions(filePathOut, 3, 7);
           
using (Merger merger = new Merger(filePath))
{
     merger.Split(splitOptions);
}  
```

Este fragmento de código producirá:

| Nombre del documento | Números de página |
| --- | --- |
| document_3 | 3 |
| document_4 | 4 |
| document_5 | 5 |
| document_6 | 6 |
| document_7 | 7 |

## Dividir el documento en varios documentos de una página (mediante números de página de inicio y fin, y filtro de páginas pares/impares) {#split-the-document-to-several-one-page-documents-by-start-end-page-numbers-and-even-odd-filter}

El siguiente ejemplo de código muestra cómo dividir un documento en varios documentos de una página, considerando únicamente las páginas impares, comenzando en la página número 3 y terminando en la página número 7:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\document_{0}.{1}";

SplitOptions splitOptions = new SplitOptions(filePathOut, 3, 7, RangeMode.OddPages);
           
using (Merger merger = new Merger(filePath))
{
     merger.Split(splitOptions);
}  
 
```

Este fragmento de código producirá:

| Nombre del documento | Números de página |
| --- | --- |
| document_3 | 3 |
| document_5 | 5 |
| document_7 | 7 |

## Dividir el documento en varios documentos de varias páginas {#split-the-document-to-several-multi-page-documents}

El siguiente ejemplo de código muestra cómo dividir un documento en varios documentos de varias páginas:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\output\document_{0}.{1}";

SplitOptions splitOptions = new SplitOptions(filePathOut, new int[] { 3, 6, 8 }, SplitMode.Interval);
           
using (Merger merger = new Merger(filePath))
{
     merger.Split(splitOptions);
}  
```

Este fragmento de código producirá:

| Nombre del documento | Números de página |
| --- | --- |
| document_0 | 1, 2 |
| document_1 | 3, 4, 5 |
| document_2 | 6, 7 |
| document_3 | 8, 9, 10 |

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** ofrece una función de movimiento de página que le permite manipular el orden de las páginas moviendo cualquier página(s) a una nueva posición dentro de un documento.   
Esto se puede hacer siguiendo los pasos a continuación:

*   Inicialice la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/moveoptions" target="_blank" rel="nofollow noopener noreferrer">MoveOptions</a> y especifique los números de página actual y nuevo;
*   Instancie el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/movepage" target="_blank" rel="nofollow noopener noreferrer">MovePage</a> y pásele el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/moveoptions" target="_blank" rel="nofollow noopener noreferrer">MoveOptions</a>;
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pásele la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código muestra cómo mover una página a una nueva posición:

```csharp
int pageNumber = 6;
int newPageNumber = 1;
MoveOptions moveOptions = new MoveOptions(pageNumber, newPageNumber);

using (Merger merger = new Merger(@"c:\sample.xlsx"))
{
    merger.MovePage(moveOptions);
    merger.Save(@"c:\result.xlsx");
}
```

**GroupDocs.Merger** permite guardar el documento PDF resultante especificando la configuración de accesibilidad <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings" target="_blank" rel="nofollow noopener noreferrer">PdfAccesibilitySettings</a>.

Existe la posibilidad de establecer el parámetro <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings/enableautotagging" target="_blank" rel="nofollow noopener noreferrer">EnableAutoTagging</a> para habilitar el modo de etiquetado automático.

Los pasos para guardar el documento en modo de etiquetado automático son los siguientes:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> y establecer el parámetro <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfaccesibilitysettings/enableautotagging" target="_blank" rel="nofollow noopener noreferrer">EnableAutoTagging</a> como `True`;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> para guardar el documento resultante.

## Guardar el documento PDF en modo de etiquetado automático {#save-the-pdf-document-with-auto-tagging-mode}

El siguiente ejemplo de código demuestra cómo guardar un documento PDF en modo de etiquetado automático:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\result.pdf";

PdfSaveOptions pdfSaveOptions = new PdfSaveOptions();
pdfSaveOptions.AccesibilitySettings.EnableAutoTagging = true;
           
using (Merger merger = new Merger(filePath))
{
     merger.Save(filePathOut, pdfSaveOptions);
}  
```

## Guardar cualquier documento de forma predeterminada {#save-any-document-by-default}

El siguiente ejemplo de código muestra cómo guardar cualquier documento de forma predeterminada:

```csharp
string filePath = @"c:\sample.docx";
string filePathOut = @"c:\result.docx";

using (Merger merger = new Merger(filePath))
{
     merger.Save(filePathOut);
}  
```

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite cambiar el ángulo de rotación de las páginas estableciéndolo en 90, 180 o 270 grados para páginas específicas o para todas las páginas del documento.  
A continuación se indican los pasos para cambiar la rotación de las páginas:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/rotateoptions" target="_blank" rel="nofollow noopener noreferrer">RotateOptions</a> con el ángulo de rotación deseado y los números de página;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta del documento de origen o con un flujo;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/rotatepages" target="_blank" rel="nofollow noopener noreferrer">RotatePages</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/rotateoptions" target="_blank" rel="nofollow noopener noreferrer">RotateOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde guardar el documento resultante.

El siguiente ejemplo de código muestra cómo cambiar la rotación de las páginas:

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

RotateOptions rotateOptions = new RotateOptions(RotateMode.Rotate180, new int[] { 2, 3, 6 });

using (Merger merger = new Merger(filePath))
{
    merger.RotatePages(rotateOptions);
    merger.Save(filePathOut);
}
```

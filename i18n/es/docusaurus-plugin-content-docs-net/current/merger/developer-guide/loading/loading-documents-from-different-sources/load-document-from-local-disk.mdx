Cuando el documento de origen se encuentra en el disco local **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** le permite cargarlo mediante el constructor de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a>, especificando una ruta absoluta o relativa hacia él.  
El siguiente fragmento de código muestra cómo cargar documentos desde el disco local.

```csharp
string filePath = @"c:\sample.docx";
using (Merger merger = new Merger(filePath))
{
	Console.WriteLine($"Document loaded from local disk successfully.");
}
```

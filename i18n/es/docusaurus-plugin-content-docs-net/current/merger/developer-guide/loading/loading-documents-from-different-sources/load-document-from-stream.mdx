Puede darse el caso de que el documento de origen o el de destino no se encuentre físicamente en el disco. En su lugar, dispone del documento en forma de flujo (stream). En este caso, para evitar la sobrecarga de guardar el flujo como archivo en el disco, **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona una forma de trabajar directamente con flujos de documentos.   
A continuación se indican los pasos a seguir:
*   Obtener el flujo del documento;
*   Pasar el flujo del documento de origen abierto al constructor de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a>.

El siguiente fragmento de código describe este caso.

```csharp
using (Stream stream = File.OpenRead(@"c:\sample.docx"))
{
	using (Merger merger = new Merger(stream))
    {
    	Console.WriteLine($"Document loaded from stream successfully.");
	}
}
```

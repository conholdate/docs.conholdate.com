**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite manipular documentos protegidos con contraseña.

A continuación se indican los pasos para cargar documentos protegidos con contraseña.

*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> y especificar la contraseña del documento de origen;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen y el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.

El siguiente ejemplo de código muestra cómo cargar documentos protegidos con contraseña.

```csharp
string filePath = @"c:\sample.docx";
LoadOptions loadOptions = new LoadOptions("SAMPLE_PASSWORD");
 
using (Merger merger = new Merger(filePath, loadOptions))
{
	Console.WriteLine($"Document loaded successfully.");                
}    
```

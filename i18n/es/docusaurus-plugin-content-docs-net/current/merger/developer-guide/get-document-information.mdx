**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite obtener información del documento, la cual incluye:
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/documentinfo/type" target="_blank" rel="nofollow noopener noreferrer">Type</a> – indica el tipo de archivo del documento, la extensión, el nombre del formato, etc.
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/documentinfo/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> – indica la cantidad de páginas para documentos de procesamiento de texto, hojas de cálculo en una hoja de cálculo o diapositivas en una presentación;
*   <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.result/ipageinfo" target="_blank" rel="nofollow noopener noreferrer">Información de página</a> – describe las propiedades de cada página del documento. Por ejemplo, altura y ancho en píxeles cuando la página del documento se previsualiza como una imagen, número de página, visibilidad, etc.

El siguiente ejemplo de código demuestra cómo obtener la información del documento.
```csharp
using (Merger merger = new Merger(@"c:\sample.vsdx"))
{
    IDocumentInfo info = merger.GetDocumentInfo();
    Console.WriteLine(info);
}
```

## ¿Qué es un objeto OLE para presentaciones? {#what-is-ole-object-for-presentation}

La tecnología «Enlace e inserción de objetos» (OLE, por sus siglas en inglés) permite incrustar otro documento dentro de la presentación que se está editando actualmente. En este caso, se utiliza un objeto marco para el contenido del documento incrustado. Los documentos de Word y PDF, las hojas de cálculo en formatos Excel y Open Document, así como otros tipos de documentos, pueden incrustarse en una presentación de PowerPoint como un marco predefinido con coordenadas X e Y y un tamaño determinado.

## Agregar un documento a la presentación mediante OLE {#add-document-to-presentation-via-ole}

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la capacidad de agregar otro documento individual como documento incrustado a una presentación.   
A continuación se detallan los pasos para lograrlo:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olepresentationoptions" target="_blank" rel="nofollow noopener noreferrer">OlePresentationOptions</a> con la ruta del archivo incrustado y el número de página;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/importdocument" target="_blank" rel="nofollow noopener noreferrer">ImportDocument</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olepresentationoptions" target="_blank" rel="nofollow noopener noreferrer">OlePresentationOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código demuestra cómo agregar otro documento individual como documento incrustado a una presentación:

```csharp
string filePath = @"c:\sample.ppt";
string filePathEmbedded = @"c:\embedded.pdf";
string filePathOut = @"c:\output\result.ppt";

int pageNumber = 2;
OlePresentationOptions olePresentationOptions = new OlePresentationOptions(filePathEmbedded, pageNumber);
olePresentationOptions.X = 10;
olePresentationOptions.Y = 10;

using (Merger merger = new Merger(filePath))
{
    merger.ImportDocument(olePresentationOptions);
    merger.Save(filePathOut);
}

```

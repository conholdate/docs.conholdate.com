## ¿Qué es un objeto OLE para hojas de cálculo? {#what-is-ole-object-for-spreadsheet}

La tecnología OLE proporcionada por Microsoft permite insertar contenido de otro documento dentro de una celda previamente seleccionada mediante el índice de fila (`RowIndex`) y el índice de columna (`ColumnIndex`) de la hoja de cálculo de Excel que se está editando actualmente. Por ejemplo, un documento PDF puede insertarse en un documento de hoja de cálculo de Excel como un enlace de imagen dentro de una celda predefinida, tal como se muestra en el siguiente ejemplo.

## Agregar un documento a una hoja de cálculo mediante OLE {#add-document-to-spreadsheet-via-ole}

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la capacidad de agregar otro documento individual como documento incrustado a una presentación.   
A continuación se presentan los pasos para lograrlo:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olespreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">OleSpreadsheetOptions</a> con la ruta del archivo incrustado y el número de página;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/importdocument" target="_blank" rel="nofollow noopener noreferrer">ImportDocument</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olespreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">OleSpreadsheetOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código demuestra cómo agregar otro documento individual como documento incrustado a una hoja de cálculo de Excel:

```csharp
string filePath = @"c:\sample.xlsx";
string filePathEmbedded = @"c:\embedded.pdf";
string filePathOut = @"c:\output\result.xlsx";

int pageNumber = 2;
OleSpreadsheetOptions oleSpreadsheetOptions = new OleSpreadsheetOptions(filePathEmbedded, pageNumber);
oleSpreadsheetOptions.RowIndex = 2;
oleSpreadsheetOptions.ColumnIndex = 2;

using (Merger merger = new Merger(filePath))
{
    merger.ImportDocument(oleSpreadsheetOptions);
    merger.Save(filePathOut);
}

```

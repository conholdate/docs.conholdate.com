Es un hecho conocido que los archivos PDF son ideales para fines de demostración, ya que el contenido impreso se verá exactamente igual que en la pantalla del dispositivo y no se perderá ningún formato. Otra característica valiosa, aunque menos conocida, es que el formato PDF ofrece una forma sencilla de organizar sus documentos cuando necesita almacenar varios archivos relacionados juntos. Simplemente puede adjuntar otros documentos, como archivos PDF, documentos de Microsoft Word, hojas de cálculo de Excel, presentaciones de PowerPoint, imágenes, archivos de audio o video, a su documento PDF original, y si lo mueve a otra ubicación, todos los archivos adjuntos se moverán también.

Muchas herramientas de escritorio ofrecen la posibilidad de adjuntar archivos a un documento PDF mediante sus interfaces de usuario, pero ¿qué sucede si necesita hacer lo mismo de forma programática? Aquí es donde GroupDocs.Merger entra en juego para ayudarle.   
Consulte la guía a continuación y aprenda cómo agregar un archivo adjunto a un documento PDF en 3 pasos.

## Cómo agregar un archivo adjunto a un documento PDF {#how-to-add-attachment-to-pdf-document}

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la capacidad de agregar archivos adjuntos a un documento PDF. A continuación se detallan los pasos necesarios:

*   Instancie un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/importdocument" target="_blank" rel="nofollow noopener noreferrer">ImportDocument</a> y pase un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pdfattachmentoptions" target="_blank" rel="nofollow noopener noreferrer">PdfAttachmentOptions</a> que contenga la ruta del archivo que se va a incrustar en el documento PDF;
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pase la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código muestra cómo agregar una presentación de PowerPoint como archivo adjunto a un documento PDF:

```csharp
using (Merger merger = new Merger(@"c:\sample.pdf"))
{
	PdfAttachmentOptions pdfAttachmentOptions = new PdfAttachmentOptions(@"c:\presentation-attachment.ppt");
    merger.ImportDocument(pdfAttachmentOptions);
    merger.Save(@"c:\document-with-attachment.pdf");
}

```

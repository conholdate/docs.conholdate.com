## ¿Qué es un objeto OLE? {#what-is-ole-object}

OLE es la sigla de *Object Linking and Embedding* (Vinculación e Inserción de Objetos), una tecnología proporcionada por Microsoft que permite importar e incrustar cierto contenido generado por otra aplicación en documentos que se están editando actualmente. Por ejemplo, una hoja de cálculo de Excel o una presentación de PowerPoint pueden incrustarse en documentos editados con un procesador de textos, entre otros casos. De esta forma, OLE permite almacenar todos los datos relacionados con el documento dentro de un único documento y compartir fácilmente dichos datos.

## Cómo agregar un objeto OLE a documentos de Microsoft Word {#how-to-add-ole-object-to-microsoft-word-documents}

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** ofrece la capacidad de insertar objetos OLE en documentos de procesamiento de texto de Microsoft Word y en formatos Open Document. A continuación se explica cómo hacerlo en 3 sencillos pasos:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/importdocument" target="_blank" rel="nofollow noopener noreferrer">ImportDocument</a> y pasarle un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olewordprocessingoptions" target="_blank" rel="nofollow noopener noreferrer">OleWordProcessingOptions</a> con la ruta del archivo incrustado y el número de página;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código demuestra cómo incrustar un archivo PDF en un documento DOCX como objeto OLE

```csharp
using (Merger merger = new Merger(@"c:\sample.docx"))
{
	int pageNumber = 2;
	OleWordProcessingOptions oleWordProcessingOptions = new OleWordProcessingOptions(@"c:\embedded.pdf", pageNumber);
	oleWordProcessingOptions.Width = 300;
	oleWordProcessingOptions.Height = 300;

    merger.ImportDocument(oleWordProcessingOptions);
    merger.Save(@"c:\output\result.docx");
}

```

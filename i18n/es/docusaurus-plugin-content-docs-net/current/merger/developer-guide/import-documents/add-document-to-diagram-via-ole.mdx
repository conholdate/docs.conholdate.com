## ¿Qué es un objeto OLE para un diagrama? {#what-is-ole-object-for-diagram}

La tecnología OLE proporcionada por Microsoft permite insertar contenido de otro documento dentro de una forma, utilizando el tamaño y las coordenadas previamente seleccionados mediante los valores X, Y, Ancho y Alto de la página del diagrama que se está editando actualmente. Por ejemplo, un documento de diapositivas puede insertarse dentro de una forma en un documento de diagrama, tal como se muestra en el ejemplo siguiente.

## Agregar un documento al diagrama mediante OLE {#add-document-to-diagram-via-ole}

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la capacidad de agregar otro documento individual como documento incrustado a una presentación.   
A continuación se detallan los pasos para lograrlo:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olediagramoptions" target="_blank" rel="nofollow noopener noreferrer">OleDiagramOptions</a> con la ruta del archivo incrustado y el número de página;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/importdocument" target="_blank" rel="nofollow noopener noreferrer">ImportDocument</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/olediagramoptions" target="_blank" rel="nofollow noopener noreferrer">OleDiagramOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y pasarle la ruta deseada para guardar el documento resultante.

El siguiente ejemplo de código demuestra cómo agregar otro documento individual como documento incrustado a una página de diagrama:

```csharp
string filePath = @"c:\sample.vsdx";
string filePathEmbedded = @"c:\embedded.pptx";
string filePathOut = @"c:\output\result.vsdx";

int pageNumber = 2;
OleDiagramOptions oleDiagramOptions = new OleDiagramOptions(filePathEmbedded, pageNumber);
oleDiagramOptions.X = 1;
oleDiagramOptions.Y = 1;
oleDiagramOptions.Width = 2;
oleDiagramOptions.Height = 1;

using (Merger merger = new Merger(filePath))
{
    merger.ImportDocument(oleDiagramOptions);
    merger.Save(filePathOut);
}

```

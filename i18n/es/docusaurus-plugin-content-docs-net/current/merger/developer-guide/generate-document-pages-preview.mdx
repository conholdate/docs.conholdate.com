**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** proporciona la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> para especificar distintas opciones para gestionar la vista previa de las páginas del documento.  
  
A continuación se indican los pasos para generar la vista previa del documento con GroupDocs.Merger:
*   Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y pasar la ruta del documento de origen como parámetro del constructor.
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> con:    
    *   delegate for each page stream creation (see event handler <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a>);         
    *   image preview format - PNG / JPG / BMP;        
    *   page numbers to process;        
    *   custom size of preview images (if needed).           

:::info
Las secuencias creadas por el delegado <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> se liberarán automáticamente tras la generación de la imagen de vista previa. Si necesita implementar una liberación personalizada de la secuencia de vista previa de imágenes, debe pasar el argumento adicional <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> para limpiar los recursos.
:::
     
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de la instancia de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y pase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> como argumento.
    

## Implementación del delegado CreatePageStream {#createpagestream-delegate-implementation}

GroupDocs.Merger espera el delegado <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> para obtener cada flujo de página durante el proceso de generación de vista previa de imágenes

```csharp
private static Stream CreatePageStream(int pageNumber)
{
    string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageNumber.ToString() + ".jpg");
    var folder = Path.GetDirectoryName(imageFilePath);
    if(!Directory.Exists(folder))
    {
        Directory.CreateDirectory(folder);
    }
    return new System.IO.FileStream(imageFilePath, FileMode.Create);
}
```

## Implementación del delegado ReleasePageStream {#releasepagestream-delegate-implementation}

```csharp
private static void ReleasePageStream(int pageNumber, Stream pageStream)
{
     pageStream.Dispose();
     string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageNumber.ToString() + ".jpg");
     Console.WriteLine("Image file {0} is ready for preview", imageFilePath);
}
```

## Generar vista previa del documento a partir de un archivo en el disco local {#generate-document-preview-from-file-on-local-disk}

```csharp
public static void GetPreview()
{   
    string filePath = @"c:\sample.xlsx";
    using (Merger merger = new Merger(filePath))
    {
        IPreviewOptions previewOption = new PreviewOptions(CreatePageStream, PreviewMode.JPEG);
```

## Generar vista previa de documento desde un flujo con un delegado personalizado para liberar el flujo {#generate-document-preview-from-stream-with-custom-stream-releasing-delegate}

```csharp
public static void GetPreview()
{
    string filePath = @"c:\sample.xlsx";
    using (Merger merger = new Merger(filePath))
    {
        IPreviewOptions previewOption = new PreviewOptions(CreatePageStream, ReleasePageStream, PreviewMode.JPEG);
        merger.GeneratePreview(previewOption);
    }
}
 
private static Stream CreatePageStream(int pageNumber)
{
    string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageNumber.ToString() + ".jpg");
    var folder = Path.GetDirectoryName(imageFilePath);
    if(!Directory.Exists(folder))
    {
        Directory.CreateDirectory(folder);
    }
    return new System.IO.FileStream(imageFilePath, FileMode.Create);
}

private static void ReleasePageStream(int pageNumber, Stream pageStream)
{
     pageStream.Dispose();
     string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageNumber.ToString() + ".jpg");
     Console.WriteLine("Image file {0} is ready for preview", imageFilePath);
}
```


:::info
NOTA: La secuencia creada mediante el delegado <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> se liberará automáticamente una vez finalizada la generación de la imagen de vista previa. Si necesita implementar una liberación personalizada de la secuencia de vista previa de la imagen, debe pasar el argumento adicional <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.common/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> para limpiar los recursos.
:::

**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite obtener la lista de todos los [tipos de archivo admitidos](/net/merger/getting-started/supported-document-formats/) siguiendo los pasos que se indican a continuación:

*   Llamar a <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>;
*   Recorrer la colección de objetos <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente ejemplo de código muestra cómo obtener la lista de formatos de archivo admitidos.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

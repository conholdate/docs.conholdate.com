La sintaxis fluida proporciona una llamada compacta para la mayoría de los métodos públicos de **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>**.

Estos métodos incluyen:
* Unir dos o más documentos,
* Unir una página específica o un grupo de páginas de distintos documentos,
* Dividir un documento en varios documentos resultantes,
* Dividir un documento especificando números de página concretos,
* Cambiar la posición de una página dentro de un documento,
* Eliminar una o varias páginas del documento,
* Rotar la página un ángulo de 90, 180 o 270 grados,
* Intercambiar la posición de dos páginas dentro de un documento,
* Extraer una página específica o un rango de páginas del documento,
* Cambiar la orientación de página (retrato o apaisado) de páginas específicas o de todas las páginas dentro de un documento,
* Establecer, actualizar o eliminar la contraseña del documento,
* etc.
  
Consulte el ejemplo a continuación sobre cómo utilizar la sintaxis fluida:

```csharp
using (Merger merger = new Merger(@"c:\document1.pdf"))
{
    merger
    .Join(@"c:\document2.docx")
    .Join(@"c:\document3.pptx")
    .Join(@"c:\document4.xlsx")
    .Save(@"c:\merged.pdf");
}
```

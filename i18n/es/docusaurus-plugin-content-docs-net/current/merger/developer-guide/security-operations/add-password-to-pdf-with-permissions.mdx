Puede proteger fácilmente un documento PDF con permisos utilizando el producto "GroupDocs.Merger para .NET".

El siguiente ejemplo demuestra cómo proteger un documento PDF con permisos mediante código en C#:

*   Inicialice la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityOptions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityOptions</a> con la nueva contraseña del documento y establezca la propiedad Permissions con el valor de enumeración de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityPermissions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityPermissions</a>;
*   Instancie el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta del documento de origen o con un flujo (stream);
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/addpassword" target="_blank" rel="nofollow noopener noreferrer">AddPassword</a> y pase el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/PdfSecurityOptions" target="_blank" rel="nofollow noopener noreferrer">PdfSecurityOptions</a> como argumento;
*   Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde se guardará el documento resultante.

```csharp
string filePath = @"c:\sample.pdf";
string filePathOut = @"c:\output\result.pdf";

PdfSecurityOptions pdfSecurityOptions = new PdfSecurityOptions("SAMPLE_PASSWORD");
pdfSecurityOptions.Permissions = PdfSecurityPermissions.DenyModification;

using (Merger merger = new Merger(filePath))
{
    merger.AddPassword(pdfSecurityOptions);
    merger.Save(filePathOut);
}
```

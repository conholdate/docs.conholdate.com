**GroupDocs.Merger** permite agregar una contraseña al documento. A continuación se indican los pasos para agregar una contraseña al documento:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/addpasswordoptions" target="_blank" rel="nofollow noopener noreferrer">AddPasswordOptions</a> con la nueva contraseña del documento;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/addpassword" target="_blank" rel="nofollow noopener noreferrer">AddPassword</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/addpasswordoptions" target="_blank" rel="nofollow noopener noreferrer">AddPasswordOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde se guardará el documento resultante.

El siguiente ejemplo de código demuestra cómo agregar una contraseña al documento.

```csharp
string filePath = @"c:\sample.pptx";
string filePathOut = @"c:\output\result.pptx";

AddPasswordOptions addOptions = new AddPasswordOptions("SAMPLE_PASSWORD");

using (Merger merger = new Merger(filePath))
{
    merger.AddPassword(addOptions);
    merger.Save(filePathOut);
}
```

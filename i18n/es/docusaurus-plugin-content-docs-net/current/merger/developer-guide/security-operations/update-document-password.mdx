**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite actualizar la contraseña de un documento protegido con contraseña. El documento resultante tendrá la nueva contraseña.  
A continuación se indican los pasos para actualizar la contraseña del documento:

*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> especificando la contraseña actual;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta o el flujo del documento de origen y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>;
*   Inicializar la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/updatepasswordoptions" target="_blank" rel="nofollow noopener noreferrer">UpdatePasswordOptions</a> especificando la nueva contraseña del documento;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/updatepassword" target="_blank" rel="nofollow noopener noreferrer">UpdatePassword</a> y pasarle el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/updatepasswordoptions" target="_blank" rel="nofollow noopener noreferrer">UpdatePasswordOptions</a>;
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> especificando la ruta del archivo donde guardar el documento resultante.

El siguiente ejemplo de código muestra cómo actualizar la contraseña del documento:

```csharp
string filePath = @"c:\sample.xlsx";
string filePathOut = @"c:\output\result.xlsx";

ILoadOptions loadOptions = new LoadOptions("SAMPLE_PASSWORD");
IUpdatePasswordOptions updateOptions = new UpdatePasswordOptions("NEW_SAMPLE_PASSWORD");

using (Merger merger = new Merger(filePath, loadOptions))
{
    merger.UpdatePassword(updateOptions);
    merger.Save(filePathOut);
}
```

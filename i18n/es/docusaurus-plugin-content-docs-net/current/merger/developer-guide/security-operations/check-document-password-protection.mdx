**<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>** permite verificar si un documento está protegido con contraseña. El resultado será **true** si el documento tiene establecida una contraseña para su apertura; en caso contrario, se devolverá **false**.

A continuación se indican los pasos para comprobar si un documento está protegido con contraseña:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> con la ruta del documento de origen o con un flujo (stream);
*   Llamar al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/ispasswordset" target="_blank" rel="nofollow noopener noreferrer">IsPasswordSet</a>.

El siguiente ejemplo de código muestra cómo comprobar si un documento está protegido con contraseña.

```csharp
bool isPasswordSet = false;
string filePath = @"C:\sample.xlsx";

using (Merger merger = new Merger(filePath))
{
	isPasswordSet = merger.IsPasswordSet();
}
```

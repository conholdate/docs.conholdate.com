## Cómo fusionar archivos de audio en C\# {#how-to-merge-audio-files-in-c}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> facilita a los desarrolladores combinar múltiples archivos de audio según la secuencia deseada y guardarlos como un único archivo de audio. Esto elimina la necesidad de realizar operaciones manuales con software de escritorio, ahorrándole tiempo valioso. Actualmente, GroupDocs.Merger permite combinar archivos de audio que tengan la misma extensión. Por ejemplo, un archivo WAV con otros archivos WAV, o un archivo MP3 con otros archivos MP3.

A continuación se muestra un fragmento de código en C# que demuestra cómo concatenar archivos de audio:

* Cree una instancia de la clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y pase la ruta del archivo de audio de origen como parámetro del constructor. Puede especificar rutas absolutas o relativas según sus necesidades.
* Agregue otro archivo de audio para fusionarlo mediante el método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a>. El archivo de audio debe tener el mismo formato que el archivo inicial. Repita este paso para los demás archivos de audio que desee fusionar.
* Llame al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> y especifique el nombre de archivo para el archivo de audio resultante como parámetro.

```csharp
// Load the source WAV file
using (var merger = new GroupDocs.Merger.Merger(@"c:\sample1.wav"))
{
    // Add another WAV file to merge
    merger.Join(@"c:\sample2.wav");
    // Merge audio files and save result
    merger.Save(@"c:\merged.wav");
}
```

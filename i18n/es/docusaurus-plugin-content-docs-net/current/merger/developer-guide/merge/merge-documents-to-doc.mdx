## Introducción {#introduction}

Considere la funcionalidad para fusionar archivos de diversos formatos, como <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>, <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a>, <a href="https://docs.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> y <a href="https://docs.fileformat.com/page-description-language/tex/" target="_blank" rel="nofollow noopener noreferrer">TEX</a> en un documento DOC. Veamos por qué es necesario combinar estos archivos en un documento DOC. Este artículo trata sobre el formato DOC, aunque en el futuro se abordarán otros formatos. Pero volvamos al formato DOC: se trata de un formato estándar que permite mostrar la información de forma idéntica en cualquier dispositivo y en cualquier plataforma. Es ideal para transferir información por Internet o para enviarla a una impresora. Por esta razón, se elige este formato para la tarea actual de fusionar archivos de distintos formatos.

## Fusionar documentos en DOC / DOCX {#merge-documents-to-doc-docx}

Se pueden combinar múltiples archivos (incluso distintos tipos de archivos PDF, como <a href="https://docs.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>, <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a>, <a href="https://docs.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> y <a href="https://docs.fileformat.com/page-description-language/tex/" target="_blank" rel="nofollow noopener noreferrer">TEX</a>) en un único archivo DOC / DOCX mediante la API **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>**. Asimismo, puede utilizar este <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método para fusionar varios archivos DOC / DOCX. Esta fusión entre formatos distintos hacia DOC / DOCX resulta útil en los casos en los que no es posible fusionar únicamente archivos DOC. Por ahora, la API GroupDocs.Merger permite <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> otros tipos de archivos sin contraseña en un documento DOC / DOCX cargado en un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a>.

El siguiente ejemplo muestra cómo fusionar un archivo DOC con archivos de los tipos <a href="https://docs.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>, <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a>, <a href="https://docs.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> y <a href="https://docs.fileformat.com/page-description-language/tex/" target="_blank" rel="nofollow noopener noreferrer">TEX</a>:

```csharp
using (Merger merger = new Merger(@"c:\document1.doc"))
{
    merger.Join(@"c:\document2.pdf");
    merger.Join(@"c:\document3.xps");
    merger.Join(@"c:\document4.epub");
    merger.Join(@"c:\document5.tex");
    merger.Save(@"c:\merged.doc");
}
```

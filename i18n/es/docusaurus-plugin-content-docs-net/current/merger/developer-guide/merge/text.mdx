Un archivo con la extensión .TXT representa un documento de texto que contiene texto sin formato en forma de líneas. Los párrafos en un documento de texto se reconocen mediante saltos de línea y se utilizan para una mejor organización del contenido del archivo. Un documento de texto estándar puede abrirse en cualquier editor de texto o aplicación de procesamiento de textos en distintos sistemas operativos. Todo el texto contenido en dicho archivo está en formato legible por humanos y se representa mediante una secuencia de caracteres.

## Cómo fusionar archivos de texto en C# {#how-to-merge-text-files-in-c}

Cuando es necesario organizar varios archivos de texto en un solo archivo, es posible resolver la tarea con la ayuda de <a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> solo y no es necesario utilizar ningún software de terceros.

El flujo de trabajo para combinar archivos es bastante sencillo:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo de texto fuente como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo TXT para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos TXT que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo TXT fusionado como parámetro.

El siguiente ejemplo demuestra cómo fusionar archivos TXT con varias líneas de código C#:

```csharp
// Load the source TXT file
using (Merger merger = new Merger(@"c:\sample1.txt"))
{
    // Add another TXT file to merge
    merger.Join(@"c:\sample2.txt");
    // Merge TXT files and save result
    merger.Save(@"c:\merged.txt");
}
```

## Introducción {#introduction}

Considere la funcionalidad para fusionar archivos de diversos formatos, como <a href="https://docs.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a> / <a href="https://docs.fileformat.com/page-description-language/xps/" target="_blank" rel="nofollow noopener noreferrer">XPS</a>, <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> y <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a> en un documento PDF. Veamos por qué necesitamos combinar estos archivos en un documento PDF. Este artículo trata sobre el formato PDF, aunque en el futuro se abordarán otros formatos. Pero volvamos al formato PDF: se trata de un formato estándar que permite mostrar la información de forma idéntica en cualquier dispositivo y en cualquier plataforma. Es ideal para transferir información por Internet o para enviarla a una impresora. Por esta razón, se elige este formato para la tarea actual de fusionar archivos de distintos formatos.

## Fusionar documentos en PDF / XPS {#merge-documents-to-pdf-xps}

Varios archivos (incluso de tipos distintos, como <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a>, <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a>) pueden combinarse en un único archivo PDF / XPS mediante la API **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>**. También puede utilizar este <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método para fusionar varios archivos PDF / XPS. Esta fusión entre formatos distintos a PDF / XPS resulta útil en los casos en los que no es posible fusionar únicamente archivos PDF / XPS. Por ahora, la API GroupDocs.Merger permite <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> otros tipos de archivos sin contraseña en un documento PDF / XPS cargado en un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a>.

El siguiente ejemplo muestra cómo fusionar un archivo PDF con archivos de los tipos <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a>, <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> y <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS</a>:

```csharp
using (Merger merger = new Merger(@"c:\document1.pdf"))
{
    merger.Join(@"c:\document2.doc");
    merger.Join(@"c:\document3.ppt");
    merger.Join(@"c:\document4.xls");
    merger.Save(@"c:\merged.pdf");
}
```

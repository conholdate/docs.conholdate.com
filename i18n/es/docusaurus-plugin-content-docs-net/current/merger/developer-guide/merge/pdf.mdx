## Cómo fusionar archivos PDF en C# {#how-to-merge-pdf-files-in-c}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores fusionar archivos PDF cuando es necesario organizar múltiples
 Archivos PDF en un solo documento o enviar menos archivos adjuntos, etc. Y todo esto sin necesidad de software de terceros ni trabajo manual.
 Con GroupDocs.Merger es posible combinar documentos PDF de cualquier tamaño y estructura: todo el texto, las imágenes, las tablas, los gráficos, los formularios y otro contenido se conservará.

El siguiente ejemplo demuestra cómo fusionar archivos PDF con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo PDF de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo PDF para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos PDF que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PDF fusionado como parámetro.

```csharp
// Load the source PDF file
using (Merger merger = new Merger(@"c:\sample1.pdf"))
{
    // Add another PDF file to merge
    merger.Join(@"c:\sample2.pdf");
    // Merge PDF files and save result
    merger.Save(@"c:\merged.pdf");
}
```

### Cómo fusionar archivos PDF con marcadores en C\# {#how-to-merge-pdf-files-with-bookmarks-in-c}

Además, existe la posibilidad de fusionar archivos PDF con marcadores; consulte el ejemplo correspondiente a continuación:

```csharp
// Load the source PDF file
using (Merger merger = new Merger(@"c:\sample1.pdf"))
{
    // Init PdfJoinOptions with UseBookmarks flag
    PdfJoinOptions pdfJoinOptions = new PdfJoinOptions();
    pdfJoinOptions.UseBookmarks = true;
    // Add another PDF file to merge
    merger.Join(@"c:\sample2.pdf", pdfJoinOptions);
    // Merge PDF files and save result
    merger.Save(@"c:\merged.pdf");
}
```

### Sobre el formato de archivo PDF {#about-pdf-file-format}

El formato de documento portátil (PDF, por sus siglas en inglés) es un tipo de documento creado por Adobe a finales de la década de 1990. El propósito de este formato de archivo fue introducir un estándar para la representación de documentos y otro material de referencia en un formato independiente del software de aplicación, el hardware y el sistema operativo. Los archivos PDF pueden abrirse en Adobe Acrobat Reader/Writer, así como en la mayoría de los navegadores modernos, como Chrome, Safari y Firefox, mediante extensiones o complementos.

## Cómo fusionar archivos EPUB en C# {#how-to-merge-epub-files-in-c}

Puede combinar fácilmente varios archivos EPUB en uno utilizando <a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> la API de la biblioteca y todo el contenido de los archivos se conservará.
El siguiente ejemplo demuestra cómo fusionar archivos EPUB con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo EPUB de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo EPUB para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos EPUB que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo EPUB fusionado como parámetro.

```csharp
// Load the source EPUB file
using (Merger merger = new Merger(@"c:\sample1.epub"))
{
    // Add another EPUB file to merge
    merger.Join(@"c:\sample2.epub");
    // Merge EPUB files and save result
    merger.Save(@"c:\merged.epub");
}
```

### Acerca del formato de archivo EPUB {#about-epub-file-format}

Los archivos con la extensión .EPUB constituyen un formato de archivo para libros electrónicos que proporciona un formato estándar para la publicación digital, tanto para editores como para consumidores. Dicho formato se ha vuelto tan común que es compatible con muchos lectores de libros electrónicos y aplicaciones de software. Por ejemplo, en Mac OS, la aplicación Books, preinstalada, ofrece soporte para abrir este tipo de archivos. Además, existen numerosas aplicaciones compatibles disponibles para teléfonos inteligentes, tabletas y ordenadores.

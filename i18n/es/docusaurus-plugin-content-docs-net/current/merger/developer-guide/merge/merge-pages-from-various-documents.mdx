Con **<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a>**, puede combinar distintas páginas de varios documentos de origen en un único documento. 

* Para fusionar todo el primer documento junto con páginas específicas de los segundos y siguientes documentos, puede utilizar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pagejoinoptions/" target="_blank" rel="nofollow noopener noreferrer">PageJoinOptions</a>, que se explica en esta página.
* Para fusionar páginas arbitrarias de todos los documentos de origen, puede utilizar el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.builders/pagebuilder/" target="_blank" rel="nofollow noopener noreferrer">PageBuilder</a>, que se explica detalladamente en la sección [Fusionar páginas en orden arbitrario](/net/merger/developer-guide/merge/merge-pages-in-arbitrary-order/).

Utilizando el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pagejoinoptions/" target="_blank" rel="nofollow noopener noreferrer">PageJoinOptions</a>, puede fusionar el documento de origen con páginas específicas de los documentos unidos en un único documento resultante, especificando los números de página o rangos de página deseados. Los documentos unidos deben tener el mismo formato.

 A continuación se indican los pasos para unir varias partes de un documento:

*   Crear un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> y proporcionar la ruta o el flujo del archivo de origen.
*   Crear un objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pagejoinoptions/" target="_blank" rel="nofollow noopener noreferrer">PageJoinOptions</a> y especificar los números de página o rangos de página deseados para unir.
*   Utilizar <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join/#join_3" target="_blank" rel="nofollow noopener noreferrer">Join</a> para añadir otro documento de origen. Proporcionar la ruta o el flujo del archivo de origen y el objeto <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger.domain.options/pagejoinoptions" target="_blank" rel="nofollow noopener noreferrer">PageJoinOptions</a> como parámetros. Repetir este paso para cada parte del documento que se desee unir.
*   Guardar el documento resultante llamando al método <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save/#save_1" target="_blank" rel="nofollow noopener noreferrer">Save</a> y proporcionando una ruta de archivo.

El siguiente ejemplo de código muestra cómo unir partes de un documento:

```csharp
string filePath = @"c:\sample.docx";
string filePath2 = @"c:\sample2.docx";
string filePathOut = @"c:\output\result.docx";

PageJoinOptions joinOptions = new PageJoinOptions(1, 4, RangeMode.OddPages);

using (Merger merger = new Merger(filePath))
{
    merger.Join(filePath2, joinOptions);
    merger.Save(filePathOut);
}
```

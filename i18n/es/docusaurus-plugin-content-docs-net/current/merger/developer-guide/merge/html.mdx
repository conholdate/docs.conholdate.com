HTML (Hyper Text Markup Language, o Lenguaje de Marcado de Hipertexto) es la extensión utilizada para las páginas web creadas para su visualización en navegadores. Conocido como el lenguaje de la web, HTML ha evolucionado junto con las nuevas necesidades de información que deben mostrarse como parte de las páginas web. La versión más reciente se denomina HTML 5, que ofrece gran flexibilidad para trabajar con este lenguaje. Las páginas HTML se reciben ya sea desde el servidor donde están alojadas, o bien pueden cargarse también desde el sistema local.

## Cómo fusionar archivos HTML de forma programática {#how-to-merge-html-files-programmatically}

Cuando necesite fusionar varias páginas HTML en un único archivo, puede hacerlo con la ayuda de <a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> y todo el contenido, como texto, imágenes, tablas, gráficos, formularios, etc., se conservará.

A continuación se muestra un ejemplo de cómo fusionar archivos HTML de forma programática:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo HTML de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo HTML para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos HTML que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo HTML fusionado como parámetro.

```csharp
// Load the source HTML file
using (Merger merger = new Merger(@"c:\sample1.html"))
{
    // Add another HTML file to merge
    merger.Join(@"c:\sample2.html");
    // Merge HTML files and save result
    merger.Save(@"c:\merged.html");
}
```

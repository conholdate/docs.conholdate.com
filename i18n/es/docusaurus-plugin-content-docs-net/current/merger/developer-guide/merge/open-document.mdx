### Acerca del formato de archivo ODP {#about-odp-file-format}

Los archivos ODT son un tipo de documentos creados con aplicaciones de procesamiento de texto que se basan en el formato de archivo de texto OpenDocument. Estos archivos se crean con aplicaciones de procesamiento de texto como el gratuito OpenOffice Writer y pueden contener contenido como texto, imágenes, objetos y estilos. El archivo ODT es al procesador de texto Writer lo que el archivo DOCX es a Microsoft Word. Varias aplicaciones, incluidas Google Docs y el procesador de texto basado en la web de Google incluido con Google Drive, pueden abrir los archivos ODT para editarlo. Microsoft Word también puede abrir archivos ODT y guardarlos en otros formatos, como DOC y DOCX.

### Acerca del formato de archivo ODT {#about-odt-file-format}

Los archivos ODT son un tipo de documentos creados con aplicaciones de procesamiento de texto que se basan en el formato de archivo de texto OpenDocument (OpenDocument Text File). Estos archivos se crean con aplicaciones de procesamiento de texto como el procesador de texto gratuito OpenOffice Writer y pueden contener contenido como texto, imágenes, objetos y estilos. El archivo ODT es al procesador de texto Writer lo que el archivo DOCX es a Microsoft Word. Varias aplicaciones, incluidas Google Docs y el procesador de texto basado en la web de Google incluido con Google Drive, pueden abrir los archivos ODT para editarlos. Microsoft Word también puede abrir archivos ODT y guardarlos en otros formatos, como DOC y DOCX.

### Acerca del formato de archivo ODS {#about-ods-file-format}

Los archivos con extensión ODS corresponden al formato de documento de hoja de cálculo OpenDocument, que es editable por el usuario. Los datos se almacenan dentro del archivo ODF en filas y columnas. Se trata de un formato basado en XML y es uno de los varios subtipos de la familia de formatos Open Document (ODF). Este formato se especifica como parte de las especificaciones ODF 1.2, publicadas y mantenidas por OASIS.

## Cómo fusionar archivos ODT {#how-to-merge-odt-files}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores fusionar archivos ODT cuando es necesario organizar múltiples
 Archivos ODT en un solo documento o enviar menos archivos adjuntos, etc. Y todo esto sin necesidad de software de terceros ni trabajo manual.
 Con GroupDocs.Merger es posible combinar documentos ODT de cualquier tamaño y estructura: todo el texto, las imágenes, las tablas, los gráficos, los formularios y otro contenido se conservará.

El siguiente ejemplo demuestra cómo fusionar archivos ODT con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo ODT de origen como un parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo ODT para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos ODT que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo ODT fusionado como parámetro.

```csharp
// Load the source ODT file
using (Merger merger = new Merger(@"c:\sample1.odt"))
{
    // Add another ODT file to merge
    merger.Join(@"c:\sample2.odt");
    // Merge ODT files and save result
    merger.Save(@"c:\merged.odt");
}
```

NOTA: También puede fusionar otros formatos de documentos abiertos, como ODP, OTP y ODS, de la misma manera que se muestra anteriormente. Para ello, proporcione los archivos especificando sus nombres con la extensión correspondiente.

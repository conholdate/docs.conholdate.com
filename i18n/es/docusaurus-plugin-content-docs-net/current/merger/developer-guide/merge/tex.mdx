## Cómo fusionar archivos TEX en C# {#how-to-merge-tex-files-in-c}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores fusionar archivos TEX cuando es necesario organizar múltiples
 Archivos TEX en un único documento o enviar menos archivos adjuntos, etc. Y todo esto sin necesidad de software de terceros ni trabajo manual.
 Con GroupDocs.Merger es posible combinar documentos TEX de cualquier tamaño y estructura: todo el texto, las imágenes, las tablas, los gráficos, los formularios y otro contenido se conservarán.

El siguiente ejemplo demuestra cómo fusionar archivos TEX con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo fuente TEX como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo TEX para fusionarlo con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos TEX que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo TEX fusionado como parámetro.

```csharp
// Load the source TEX file
using (Merger merger = new Merger(@"c:\sample1.tex"))
{
    // Add another TEX file to merge
    merger.Join(@"c:\sample2.tex");
    // Merge TEX files and save result
    merger.Save(@"c:\merged.tex");
}
```

### Acerca del formato de archivo TEX {#about-tex-file-format}

TeX es un lenguaje que combina características de programación y de marcado, utilizado para componer documentos tipográficos. Donald Knuth, de la Universidad de Stanford, es el creador de este potente sistema de composición tipográfica. En todo el mundo, TeX es la opción definitiva de autores y editores para producir documentos técnicos de alta calidad. TeX destaca especialmente en la correcta presentación de expresiones matemáticas complejas. Junto con una fotocompositora de alta calidad, TeX logra resultados comparables a los generados por los mejores sistemas tradicionales de composición tipográfica.

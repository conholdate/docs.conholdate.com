Debe estar familiarizado con los archivos con las extensiones **PPTX** y **PPT**, que son formatos de archivo de presentación utilizados para almacenar una colección de registros que contienen datos de presentación, como diapositivas, formas, texto, animaciones, video, audio y objetos incrustados. Una presentación también puede guardarse o convertirse en otros formatos de archivo, como PDF, BMP, PNG, JPEG y XPS.

Las extensiones de archivo de presentación comunes y sus formatos de archivo asociados incluyen **PPTX**, **PPT**, **PPSX** y **PPS**.

## Cómo fusionar presentaciones PPSX {#how-to-merge-ppsx-presentations}

Los archivos PPSX (PowerPoint Slide Show) se crean utilizando Microsoft PowerPoint 2007 y versiones posteriores con el propósito de presentaciones en modo diapositiva. Constituyen una actualización del formato de archivo PPS, el cual era compatible con las versiones de Microsoft PowerPoint 97 a 2003. Cuando un archivo PPSX se comparte con otro usuario y se abre, se inicia directamente como una presentación en modo diapositiva, a diferencia de los archivos PPTX, que se abren en modo editable. La secuencia de la presentación en diapositivas es idéntica a la de la presentación original. Todas las diapositivas incluyen imágenes, sonidos y otros medios incrustados, los cuales acompañan a las diapositivas durante la presentación en el archivo PPSX.

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo fuente PPSX como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo PPSX para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos PPSX que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo PPSX fusionado como parámetro.

```csharp
// Load the source PPSX file
using (Merger merger = new Merger(@"c:\sample1.ppsx"))
{
    // Add another PPSX file to merge
    merger.Join(@"c:\sample2.ppsx");
    // Merge PPSX files and save result
    merger.Save(@"c:\merged.ppsx");
}
```

NOTA: Puede fusionar otros formatos de presentación, como PPTX, PPT y PPS, de la misma manera que se muestra anteriormente. Para ello, proporcione los archivos especificando sus nombres con la extensión correspondiente.

Un archivo de procesamiento de textos contiene información de usuario en formato de texto plano o texto enriquecido. Un formato de archivo de **texto plano** contiene texto sin formato y no se pueden aplicar configuraciones de fuente ni de página. En contraste, un formato de archivo de **texto enriquecido** permite opciones de formato como establecer el tipo de fuente, estilos (negrita, cursiva, subrayado, etc.), márgenes de página, encabezados, viñetas y numeración, así como varias otras características de formato. El uso de archivos de texto plano ha disminuido significativamente con el paso del tiempo, ya que existen computadoras y programas más potentes disponibles para procesar archivos de texto enriquecido.

Las extensiones y formatos de archivo de texto plano más comunes incluyen **TXT** y **CSV**, mientras que las extensiones para documentos de texto enriquecido incluyen **DOCX**, **DOC** y **RTF**.
  
## Cómo fusionar documentos DOCX {#how-to-merge-docx-documents}

DOCX es un formato bien conocido para documentos de Microsoft Word. Introducido en 2007 con el lanzamiento de Microsoft Office 2007, la estructura de este nuevo formato de documento cambió de binario plano a una combinación de archivos XML y binarios. Los archivos DOCX pueden abrirse con Word 2007 y versiones posteriores, pero no con versiones anteriores de Microsoft Word, las cuales solo admiten archivos con la extensión DOC.

A continuación se muestra un fragmento de código en C# que demuestra cómo fusionar archivos DOCX en un único archivo.

```csharp
// Load the source DOCX file
using (Merger merger = new Merger(@"c:\sample1.docx"))
{
    // Add another DOCX file to merge
    merger.Join(@"c:\sample2.docx");
    // Merge DOCX files and save result
    merger.Save(@"c:\merged.docx");
}
```

## Cómo fusionar documentos de Word sin comenzar en una nueva página {#how-to-merge-word-documents-without-starting-from-a-new-page}

Existe una opción adicional para la unión de documentos de Word que permite fusionar dichos documentos sin un salto de página entre ellos, es decir, la última página del documento inicial se fusionará con la primera página del documento siguiente como una única página.

A continuación se muestra un fragmento de código en C# que demuestra cómo fusionar archivos DOC en un único archivo sin comenzar en una nueva página.

```csharp
// Load the source DOC file
using (Merger merger = new Merger(@"c:\sample1.doc"))
{
    // Define Word join options
    WordJoinOptions joinOptions = new WordJoinOptions();
    joinOptions.Mode = WordJoinMode.Continuous;
    // Add another DOC file to merge
    merger.Join(@"c:\sample2.doc", joinOptions);
    // Merge DOC files and save result
    merger.Save(@"c:\merged.doc");
}
```


## Cómo fusionar documentos de Word sin saltos de sección {#how-to-merge-word-documents-without-section-breaks}

También existe otra opción adicional para fusionar documentos de Word, que permite fusionar estos documentos sin interrumpir las secciones, es decir, todas las secciones y páginas de todos los documentos fusionados se combinarán sin interrupciones.

A continuación se muestra un fragmento de código en C# que demuestra cómo fusionar archivos DOC en un único archivo sin saltos de sección.

```csharp
// Load the source DOC file
using (Merger merger = new Merger(@"c:\sample1.doc"))
{
    // Define Word join options
    WordJoinOptions joinOptions = new WordJoinOptions();
    joinOptions.Mode = WordJoinMode.DisableSectionBreaks;
    // Add another DOC file to merge
    merger.Join(@"c:\sample2.doc", joinOptions);
    // Merge DOC files and save result
    merger.Save(@"c:\merged.doc");
}
```

## Cómo fusionar documentos de Word con un modo de cumplimiento predefinido {#how-to-merge-word-documents-with-pre-defined-compliance-mode}

Existe una opción adicional para la fusión de documentos de Word que permite combinar dichos documentos utilizando un modo de cumplimiento predefinido para los formatos Word Ooxml, como .docx, .docm, .dotx, .dotm, etc.

A continuación se muestra un fragmento de código en C# que demuestra cómo fusionar archivos DOCX en un único archivo con el nivel de cumplimiento ISO/IEC 29500:2008 Strict.

```csharp
// Load the source DOCX file
using (Merger merger = new Merger(@"c:\sample1.docx"))
{
    // Define Word join options
    WordJoinOptions joinOptions = new WordJoinOptions();
    joinOptions.Compliance = WordJoinCompliance.Iso29500_2008_Strict;
    // Add another DOCX file to merge
    merger.Join(@"c:\sample2.docx", joinOptions);
    // Merge DOCX files and save result
    merger.Save(@"c:\merged.docx");
}
```

## Cómo fusionar archivos TXT {#how-to-merge-txt-files}

Un archivo con la extensión .TXT representa un documento de texto que contiene texto sin formato en forma de líneas. Los párrafos en un documento de texto se reconocen mediante saltos de línea y se utilizan para una mejor organización del contenido del archivo. Un documento de texto estándar puede abrirse en cualquier editor de texto o aplicación de procesamiento de textos en distintos sistemas operativos. Todo el texto contenido en dicho archivo está en formato legible por humanos y se representa mediante una secuencia de caracteres.

Puede combinar cualquier número de archivos de texto, como se muestra en este ejemplo de código en C#:

```csharp
// Load the source TXT file
using (Merger merger = new Merger(@"c:\sample1.txt"))
{
    // Add another TXT file to merge
    merger.Join(@"c:\sample2.txt");
    // Merge TXT files and save result
    merger.Save(@"c:\merged.txt");
}
```

## Cómo fusionar archivos RTF {#how-to-merge-rtf-files}

Introducido y documentado por Microsoft, el formato de texto enriquecido (RTF, por sus siglas en inglés) representa un método para codificar texto y gráficos con formato, destinado a su uso dentro de aplicaciones. Este formato facilita el intercambio de documentos entre plataformas con otros productos de Microsoft, cumpliendo así la función de interoperabilidad. Esta capacidad lo convierte en un estándar para la transferencia de datos entre programas de procesamiento de textos, lo que permite transferir contenido de un sistema operativo a otro sin perder el formato del documento.

Unir varios documentos RTF en uno solo es bastante similar al procedimiento para cualquier otro formato: simplemente especifique los archivos que desea fusionar y guarde el documento resultante.

```csharp
// Load the source RTF file
using (Merger merger = new Merger(@"c:\sample1.rtf"))
{
    // Add another RTF file to merge
    merger.Join(@"c:\sample2.rtf");
    // Merge RTF files and save result
    merger.Save(@"c:\merged.rtf");
}
```

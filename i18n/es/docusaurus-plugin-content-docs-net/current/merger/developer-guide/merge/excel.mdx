Un archivo de **hoja de cálculo** contiene datos organizados en filas y columnas. Dicho archivo puede guardarse en varios formatos distintos, cada uno con una extensión de archivo única para su representación específica. Los datos se almacenan en celdas, ya sea en forma simple, como cadenas de texto, números, fechas, monedas, etc., o como fórmulas que modifican el valor de una celda cuando cambian los valores de las celdas a las que hace referencia.

Las extensiones de archivo de hojas de cálculo más comunes y sus formatos de archivo incluyen **XLSX** (Hoja de cálculo abierta de Microsoft Excel en formato Open XML), **ODS** (Hoja de cálculo de OpenDocument) y **XLS** (Formato binario de Microsoft Excel).

XLSX es un formato bien conocido para documentos de Microsoft Excel que fue introducido por Microsoft con el lanzamiento de Microsoft Office 2007. Basado en una estructura organizada según las Convenciones de Empaquetado Abierto, tal como se describe en la Parte 2 del estándar OOXML ECMA-376, el nuevo formato es un paquete ZIP que contiene varios archivos XML. La estructura subyacente y los archivos pueden examinarse simplemente descomprimiendo el archivo .xlsx.

## Cómo fusionar archivos XLSX de forma programática {#how-to-merge-xlsx-files-programmatically}

<a href="https://products.groupdocs.com/merger/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Merger</a> permite a los desarrolladores fusionar archivos XLSX cuando es necesario organizar múltiples
 Archivos XLSX en un solo documento o enviar menos archivos adjuntos, etc. Y todo esto sin necesidad de software de terceros ni trabajo manual.
 Con GroupDocs.Merger es posible combinar documentos XLSX de cualquier tamaño y estructura: todo el texto, las imágenes, las tablas, los gráficos, los formularios y otro contenido se conservarán.

El siguiente ejemplo demuestra cómo fusionar archivos XLSX con varias líneas de código C#:

* Crear una instancia de <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase y pasar la ruta del archivo XLSX de origen como parámetro del constructor. Puede especificar una ruta de archivo absoluta o relativa según sus necesidades.
* Agregue otro archivo XLSX para fusionar con <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/join" target="_blank" rel="nofollow noopener noreferrer">Join</a> método. Repita este paso para otros documentos XLSX que desee fusionar.
* Llamada <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger" target="_blank" rel="nofollow noopener noreferrer">Merger</a> clase <a href="https://reference.groupdocs.com/merger/net/groupdocs.merger/merger/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> método y especifique el nombre de archivo para el archivo XLSX fusionado como parámetro.

```csharp
// Load the source XLSX file
using (Merger merger = new Merger(@"c:\sample1.xlsx"))
{
    // Add another XLSX file to merge
    merger.Join(@"c:\sample2.xlsx");
    // Merge XLSX files and save result
    merger.Save(@"c:\merged.xlsx");
}
```

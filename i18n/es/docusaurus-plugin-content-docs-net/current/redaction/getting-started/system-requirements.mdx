## Información general {#overview}

GroupDocs.Redaction para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/redaction/getting-started/system-requirements/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Redaction para .NET admite diversos sistemas operativos x86, x64, Arm32 y Arm64 en los que esté instalada una plataforma .NET compatible, incluidos, entre otros:

### Windows {#windows}

*   Microsoft Windows Server 2008 SP2
*   Microsoft Windows Server 2012
*   Microsoft Windows Server 2012 R2
*   Microsoft Windows Server 2016
*   Microsoft Windows Server 2019
*   Microsoft Windows 7
*   Microsoft Windows 8, 8.1
*   Microsoft Windows 10
*   Microsoft Windows 11

### UNIX {#unix}

*   Linux Ubuntu
*   Linux Debian
*   Linux Red Hat
*   Linux Alpine
*   Linux Fedora, etc.

### Otros {#other}

*   macOS
*   Android (mediante .NET MAUI)
*   iOS (mediante .NET MAUI)

## Marcos de trabajo compatibles {#supported-frameworks}

GroupDocs.Redaction para .NET es compatible tanto con Microsoft .NET Framework como con versiones modernas de .NET, como .NET 6 y posteriores.

### Marcos de trabajo .NET {#net-frameworks}

*   .NET Framework 4.6.2

### .NET (plataforma unificada) {#net-unified-platform}

*   .NET 6.0
*   .NET 8.0
*   .NET 10.0

## Entornos de desarrollo {#development-environments}

GroupDocs.Redaction para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los entornos explícitamente compatibles son los siguientes:

*   Microsoft Visual Studio 2017
*   Microsoft Visual Studio 2019
*   Microsoft Visual Studio 2022
*   Microsoft Visual Studio 2026

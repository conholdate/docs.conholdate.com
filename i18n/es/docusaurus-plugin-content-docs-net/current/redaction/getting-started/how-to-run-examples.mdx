:::warning
Antes de ejecutar un ejemplo, asegúrese de que GroupDocs.Redaction se haya instalado correctamente.
:::


Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de GroupDocs.Redaction, ya sea construyendo su propia solución o utilizando directamente nuestros ejemplos de backend o frontend.

Elija una opción de la siguiente lista:


## Construir el proyecto desde cero {#build-project-from-scratch}

*   Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
*   Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
*   Instale **GroupDocs.Redaction para .NET** desde NuGet o desde el sitio web oficial de GroupDocs, siguiendo esta [guía](/net/redaction/getting-started/how-to-run-examples/).
*   Escriba su primera aplicación con **GroupDocs.Redaction para .NET**, como se muestra a continuación
    
    ```csharp
    string documentPath = @"C:\sample.docx"; // NOTE: Put here actual path for your document
    using (Redactor redactor = new Redactor(documentPath))
    {
          // replace with text
          redactor.Apply(new RegexRedaction("\\d{2}\\s*\\d{2}[^\\d]*\\d{6}", new ReplacementOptions("[removed]")));
          // replace with blue solid rectangle
          //redactor.Apply(new RegexRedaction(@"^\d+[,\.]{1}\d+$", new ReplacementOptions(System.Drawing.Color.Blue)));
          // Use GroupDocs.Redaction.Options.Drawing types instead of System.Drawing, which is scheduled for removal in future versions.
          redactor.Apply(new RegexRedaction(@"^\d+[,\.]{1}\d+$", new ReplacementOptions(GroupDocs.Redaction.Options.Drawing.Color.Blue)));
          redactor.Save();
    }
    ```
    
*   Compile y ejecute su proyecto.
*   El documento redactado aparecerá en el directorio de trabajo como *«sample\_Redacted.pdf».*

## Ejecute los ejemplos del backend {#run-back-end-examples}

El paquete completo de ejemplos de **GroupDocs.Redaction** está alojado en <a href="https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Github</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de Github utilizando su cliente de Git favorito.  
En caso de descargar el archivo ZIP, extraiga las carpetas en su disco local. Los archivos y carpetas extraídos tendrán el aspecto que se muestra en la siguiente imagen:

![](/net/redaction/images/how-to-run-examples.png)

En la carpeta **Examples** extraída puede encontrar el archivo de solución de C# **GroupDocs.Redaction.Examples**. El proyecto se creó con **Microsoft Visual Studio 2017**. La carpeta **Resources** contiene todos los archivos de documentos e imágenes de ejemplo utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias que faltan de **GroupDocs.Redaction**, consulte <a href="https://docs.groupdocs.com/display/redactionnet/Development+Environment%2C+Installation+and+Configuration" target="_blank" rel="nofollow noopener noreferrer">Entorno de desarrollo, instalación y configuración</a>. Todas las funciones se invocan desde **RunExamples.cs**.   
Descomente la función que desea ejecutar y comente el resto.

![](/net/redaction/images/how-to-run-examples_1.png)

## Contribuir {#contribute}

Si desea agregar o mejorar un ejemplo, lo animamos a contribuir al proyecto. Todos los ejemplos de este repositorio son de código abierto y pueden utilizarse libremente en sus propias aplicaciones.  
Para contribuir, puede bifurcar (fork) el repositorio, editar el código y crear una solicitud de extracción (pull request). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

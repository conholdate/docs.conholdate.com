## Herramienta de Redacción de Documentos {#document-redaction-tool}

El término "redactado" significa que se realiza un proceso de modificación o edición de un documento para eliminar la información confidencial antes de publicarlo. GroupDocs.Redaction es un software de redacción de alta calidad que proporciona una única interfaz independiente del formato para redactar información sensible y clasificada en documentos PDF, Word, Excel, PowerPoint e imágenes, incluyendo la capacidad de modificar los metadatos y eliminar comentarios. Con la herramienta GroupDocs.Redaction, puede redactar un documento PDF y guardarlo, convirtiendo todas las páginas en imágenes rasterizadas o manteniendo el documento en su formato original para su posterior edición.

Elegir el modo de redacción más adecuado depende de los motivos por los que desea eliminar la información clasificada del documento. A continuación, se analizan con detalle las diferencias entre la rasterización y el guardado en formato original, así como cómo seleccionar el más adecuado para su caso.  

#### Rasterización {#rasterization}

Puede ocultar partes de un archivo PDF u otro tipo de documento admitido con nuestra herramienta de redacción y crear un nuevo archivo PDF que contenga imágenes rasterizadas de las páginas del documento redactado. El documento sanitizado no contiene texto buscable ni metadatos del documento original. Al mismo tiempo, las anotaciones (comentarios, insignias, etc.) permanecen visibles, pero no son clickeables. Puede utilizar `DeleteAnnotationRedaction` para eliminar todos los comentarios del documento.

La rasterización es la mejor opción si:  

*   debes cumplir con las regulaciones de las autoridades, solicitando PDF como formato;
    
*   tiene un archivo PDF como formato original;  
    
*   necesita enviar el documento a terceros;
*   necesita que este documento se abra en distintas plataformas.  
    

Para todos estos casos, la rasterización es la opción adecuada.

#### Mantener el formato original {#keeping-original-format}

La herramienta GroupDocs.Redaction permite guardar el documento en su formato original tras aplicar las redacciones.

Mantener el formato original es la mejor opción si:  

*   necesita seguir trabajando y editando este documento en su aplicación original, asegurándose de que todos los datos confidenciales hayan sido eliminados;
    
*   debe enviar este documento a otra persona de su empresa para su edición, pero sin datos confidenciales;
    
*   necesita enviar el documento a terceros, como contratistas, pero ocultar su información confidencial.  
    

#### Redacciones de hojas de cálculo {#spreadsheet-redactions}

Un caso especial de conservación del formato original es la redacción de hojas de cálculo que contienen datos. Con GroupDocs.Redaction, puede definir el ámbito de una hoja individual o incluso de una columna específica dentro de ella, limitando así las redacciones de texto únicamente a dicho ámbito. En este caso, la expresión regular solo se aplicará dentro del ámbito especificado, no en todo el documento.

#### Redacciones de metadatos {#metadata-redactions}

El guardado del documento en su formato original requiere la eliminación o redacción de sus metadatos para suprimir toda la información confidencial. Para estos fines, GroupDocs.Redaction proporciona redacciones de metadatos.

#### Redacciones de anotaciones {#annotation-redactions}

Las redacciones de anotaciones le permiten eliminar anotaciones específicas o todas las anotaciones (comentarios, insignias, etc.) del documento. Puede utilizar expresiones regulares para identificar las anotaciones que desea redactar.

#### Redacciones de eliminación de páginas {#remove-page-redactions}

Las redacciones de eliminación de páginas le permiten quitar páginas de documentos PDF, diapositivas de presentaciones y hojas de cálculo de documentos de hojas de cálculo. Puede especificar el rango de páginas y su posición relativa para su eliminación.

## Redacciones de imágenes {#image-redactions}

Con la compatibilidad OCR de GroupDocs.Redaction, puede extraer texto de una imagen, buscar datos en ella y redactar la información confidencial contenida en la propia imagen. Como alternativa, puede colocar un rectángulo de color sobre un área determinada, como el encabezado, el pie de página o una zona donde se espera que aparezcan datos de clientes. Asimismo, puede utilizarlo para editar los metadatos EXIF o actuar como un eliminador de metadatos EXIF.

Puede utilizar GroupDocs.Redaction para redactar todo tipo de imágenes incrustadas en un documento:

*   Redactar cada página de un archivo PDF generado a partir de escaneos de páginas impresas;

*   Crear un archivo PDF rasterizado y editar sus páginas como imágenes;

*   Redactar todas las imágenes dentro de un documento PDF, Microsoft Office u Open Office.

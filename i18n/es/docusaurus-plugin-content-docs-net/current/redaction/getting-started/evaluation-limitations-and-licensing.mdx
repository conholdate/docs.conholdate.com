GroupDocs.Redaction para .NET está incluido en Conholdate.Total for .NET.
:::


:::info
Puede utilizar GroupDocs.Redaction sin licencia. El uso y las funcionalidades son prácticamente iguales a los de la versión con licencia, pero encontrará algunas limitaciones al utilizar la API sin licencia.
:::


## Limitaciones de la versión de evaluación {#evaluation-limitations}

Puede descargar fácilmente GroupDocs.Redaction para realizar una evaluación. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. Al utilizar la API sin licencia, se enfrentará a las siguientes limitaciones:  

*   Solo se puede abrir 1 documento por proceso.
*   Solo se puede aplicar 1 redacción al documento.
*   Cualquier redacción está limitada a 4 reemplazos o eliminaciones, incluso si existen más coincidencias.
*   Se colocan marcas de prueba en el documento, en la parte superior de cada página.

## Licenciamiento {#licensing}

El archivo de licencia contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará su validez. Debe establecer una licencia antes de utilizar la API de GroupDocs.Redaction si desea evitar sus limitaciones de evaluación.   
La licencia puede cargarse desde un archivo o un objeto de flujo (stream). La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Redaction.dll y especificar el nombre del archivo (sin ruta de acceso), como se muestra en los ejemplos siguientes.

#### Aplicación de licencia desde un archivo {#applying-license-from-file}

El siguiente código explica cómo aplicar la licencia del producto.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-.NET
// Setup the license.
License lic = new License();
lic.SetLicense(licensePath);
```

#### Aplicación de licencia desde un flujo {#applying-license-from-stream}

El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-.NET
using (FileStream fileStream = new FileStream("GroupDocs.Redaction.lic", FileMode.Open, FileAccess.Read))
{
    License lic = new License();
    lic.SetLicense(fileStream);
}
```


:::info
Llamar a `License.SetLicense` varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, llame a `License.SetLicense` en su código de inicio, antes de utilizar las clases de `GroupDocs.Redaction`. Al desarrollar una aplicación ASP.NET, puede llamar a `License.SetLicense` desde el archivo `Global.asax.cs` (`Global.asax.vb`) dentro del método protegido `Application_Start`, el cual se ejecuta una única vez al iniciar la aplicación. No llame a `License.SetLicense` desde dentro de los métodos `Page_Load`, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
:::


#### Aplicación de la licencia por medición {#applying-metered-license}


:::info
También puede configurar la licencia <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las funciones de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en uso</a>.
:::


A continuación se presentan los sencillos pasos para utilizar la clase `Metered`.

1.  Cree una instancia de la clase `Metered`.
2.  Pase las claves pública y privada al método S`etMeteredKey`.
3.  Realice el procesamiento (ejecute la tarea).
4.  Llame al método G`etConsumptionQuantity` de la clase `Metered`.
5.  Este método devolverá la cantidad/cantidad de solicitudes de API que ha consumido hasta el momento.
6.  Llame al método G`etConsumptionCredit` de la clase `Metered` (desde la versión 19.5).
7.  Este método devolverá el crédito que ha consumido hasta el momento.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase `Metered`.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-redaction/GroupDocs.Redaction-for-.NET
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Apply redaction to a document
using (Redactor redactor = new Redactor("D:\\test.docx"))
{
   //RedactorChangeLog result = redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(System.Drawing.Color.Red)));
   // Use GroupDocs.Redaction.Options.Drawing types instead of System.Drawing, which is scheduled for removal in future versions.
   RedactorChangeLog result = redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(GroupDocs.Redaction.Options.Drawing.Color.Red)));
   if (result.Status != RedactionStatus.Failed)
   {
      redactor.Save();
   };
}

// Get metered consumption quantity after usage of the comparison
decimal amountAfter = GroupDocs.Redaction.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountAfter);

// Get metered consumption credit
decimal creditAfter = GroupDocs.Redaction.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditAfter);
```

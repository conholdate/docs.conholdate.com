GroupDocs.Redaction permite eliminar fácilmente páginas de documentos PDF, diapositivas de presentaciones y hojas de cálculo de documentos de hojas de cálculo. 

Con la API de GroupDocs.Redaction puede eliminar páginas especificando un rango de páginas mediante su posición relativa (inicio o final), un índice basado en cero y la cantidad de páginas a eliminar. En este momento, los formatos admitidos son: PDF, presentaciones (Microsoft PowerPoint, OpenOffice Presentations), documentos de procesamiento de texto (Microsoft Word, OpenOffice Texts, archivos de texto enriquecido) y hojas de cálculo (Microsoft Excel, OpenOffice Spreadsheets, etc.), así como imágenes de múltiples fotogramas.

## Eliminar un rango de páginas {#remove-page-range}

En el siguiente ejemplo, eliminamos las páginas segunda, tercera y cuarta del documento, siempre que este tenga suficientes páginas:

**C#**

```csharp
using (Redactor redactor = new Redactor("sample.pdf"))
{
    // Removes 3 pages starting from 2nd one, requires at least 4 pages
    if (redactor.GetDocumentInfo().PageCount >= 4)
    {
        redactor.Apply(new RemovePageRedaction(PageSeekOrigin.Begin, 1, 3));
        redactor.Save();
    }
}
```

## Eliminar la última página {#remove-last-page}

En algunos casos, es posible que necesite eliminar la última página o un número determinado de páginas, independientemente de cuántas páginas contenga el documento.

El siguiente ejemplo muestra cómo eliminar la última página de un documento:

**C#**

```csharp
using (Redactor redactor = new Redactor("sample.pdf"))
{
    // Requires at least 1 page
    if (redactor.GetDocumentInfo().PageCount >= 1)
    {
        redactor.Apply(new RemovePageRedaction(PageSeekOrigin.End, 0, 1));
        redactor.Save();
    }
}
```

## Eliminar marco de la imagen {#remove-frame-from-image}

En el caso de una imagen con múltiples marcos, es posible que deba eliminar uno o varios marcos (tratados como “páginas”).

El siguiente ejemplo muestra cómo eliminar 3 marcos de una imagen GIF animada:

**C#**

```csharp
using (Redactor redactor = new Redactor("sample.gif"))
{
    // Removes 5 frames starting from 3nd one, requires at least 7 frames
    if (redactor.GetDocumentInfo().PageCount >= 7)
    {
        redactor.Apply(new RemovePageRedaction(PageSeekOrigin.Begin, 2, 5));
        redactor.Save();
    }
}
```

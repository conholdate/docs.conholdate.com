Con la API de GroupDocs.Redaction puede aplicar redacciones de metadatos a documentos de distintos formatos, como PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX y otros. Consulte la lista completa en el artículo [formatos de documento admitidos](/net/redaction/getting-started/supported-document-formats/).

GroupDocs.Redactions ofrece una API flexible que permite reemplazar o eliminar metadatos mediante filtros o búsquedas mediante expresiones regulares.

## Filtrado de metadatos {#filter-metadata}

La funcionalidad básica de todas las redacciones, derivada de la clase base <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/metadataredaction" target="_blank" rel="nofollow noopener noreferrer">MetadataRedaction</a>, es el *filtrado de metadatos*, y es obligatorio para las redacciones de metadatos. Utiliza la enumeración con marca <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/metadatafilters" target="_blank" rel="nofollow noopener noreferrer">MetadataFilters</a>, que contiene elementos para las entradas de metadatos más frecuentes. Puede establecer el filtro en *All* (todos) o en cualquier combinación de metadatos. Por ejemplo, el siguiente código establece el filtro en *Author* (autor), *Manager* (gerente) y *NameOfApplication* (nombre de la aplicación), ya sea para redactarlos o eliminarlos:

**C#**

```csharp
// redaction derived from MetadataRedaction
redaction.Filter = MetadataFilters.Author | MetadataFilters.Manager | MetadataFilters.NameOfApplication;
```

## Limpiar metadatos {#clean-metadata}

Puede reemplazar todos los metadatos o solo algunos específicos del documento con valores vacíos (en blanco o mínimos) utilizando la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/erasemetadataredaction" target="_blank" rel="nofollow noopener noreferrer">EraseMetadataRedaction</a>. El ejemplo siguiente borra todas las propiedades del documento:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.docx"))
{
   redactor.Apply(new EraseMetadataRedaction(MetadataFilters.All));

   redactor.Save();
}
```

Puede especificar <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/metadatafilters" target="_blank" rel="nofollow noopener noreferrer">MetadataFilter.All</a> o utilizar el constructor predeterminado para borrar todos los metadatos dentro del documento dado, o bien **Custom** para borrar todas las entradas de metadatos personalizados.

## Redactar metadatos {#redact-metadata}

Puede utilizar <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/metadatasearchredaction" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchRedaction</a> para eliminar datos confidenciales de los metadatos del documento mediante expresiones regulares. Por ejemplo, podemos eliminar cualquier mención a "Company Ltd.":

**C#**

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.docx"))
{
   redactor.Apply(new MetadataSearchRedaction("Company Ltd.", "--company--"));

   redactor.Save();
}
```

El primer argumento es una expresión regular y el segundo es una cadena de reemplazo. También puede establecer el ámbito para la redacción mediante un filtro, por ejemplo, <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/metadatafilters" target="_blank" rel="nofollow noopener noreferrer">MetadataFilter.Company</a>: esto dejará sin aplicar la redacción a las coincidencias de expresiones regulares en todos los elementos de metadatos, excepto en la propiedad “Company” (Empresa):

**C#**

```csharp
using (Redactor redactor = new Redactor(@"C:\sample.docx"))
{
   MetadataSearchRedaction redaction = new MetadataSearchRedaction("Company Ltd.", "--company--");
   redaction.Filter = MetadataFilters.Company;
   redactor.Apply(redaction);
   redactor.Save();
}
```

## Estado de la redacción de metadatos {#metadata-redaction-status}

Todas las redacciones de metadatos se aplican a cada elemento de metadatos por separado, y aunque la redacción de un elemento de metadatos falle, el resto de los elementos de metadatos se actualizarán. Puede encontrar una lista de los elementos de metadatos que fallaron, los que se omitieron (rechazados) y las razones correspondientes en la propiedad <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactionresult/properties/errormessage" target="_blank" rel="nofollow noopener noreferrer">ErrorMessage</a> del <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactorlogentry/properties/result" target="_blank" rel="nofollow noopener noreferrer">RedactorLogEntry.Result</a>.

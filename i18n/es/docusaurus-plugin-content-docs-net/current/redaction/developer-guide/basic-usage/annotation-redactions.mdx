Con la API de GroupDocs.Redaction, puede aplicar redacciones de anotaciones a documentos de distintos formatos, como PDF, DOC, DOCX, PPT, PPTX, XLS, XLSX y otros. Consulte la lista completa en el artículo [formatos de documento admitidos](/net/redaction/getting-started/supported-document-formats/).

GroupDocs.Redactions ofrece una API flexible que permite eliminar datos confidenciales del texto de las anotaciones o eliminar completamente las anotaciones mediante una expresión regular.

## Eliminar anotaciones (comentarios, etc.) {#remove-annotations-comments-etc}

Puede utilizar GroupDocs.Redaction para eliminar todos los comentarios y otras anotaciones del documento, o bien solo algunos específicos. Por ejemplo, podemos eliminar todos los comentarios del documento que contengan en su cuerpo los términos «use», «show» o «describe»:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"D:\test.docx"))
{
   redactor.Apply(new DeleteAnnotationRedaction("(?im:(use|show|describe))"));

   redactor.Save()
}
```

Puede utilizar el constructor sin argumentos para eliminar todas las anotaciones dentro del documento.

## Redactar anotaciones {#redact-annotations}

En lugar de eliminar todas las anotaciones o solo algunas específicas, puede eliminar los datos confidenciales del texto de la anotación. Por ejemplo, podemos eliminar todas las menciones a «John» en el documento dado, por ejemplo:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"C:\test.pdf"))
{
   redactor.Apply(new AnnotationRedaction("(?im:john)", "[redacted]"));

   redactor.Save()
}
```

GroupDocs.Redaction proporciona información general sobre el documento, la cual incluye:

*   FileType
*   PageCount
*   FileSize

Los siguientes ejemplos de código muestran cómo obtener la información del documento.

## Obtener información del archivo desde un archivo en el disco local {#get-file-info-for-a-file-from-local-disk}

```csharp
using (Redactor redactor = new Redactor("source.docx"))
{
	IDocumentInfo info = redactor.GetDocumentInfo();
    Console.WriteLine("\nFile type: {0}\nNumber of pages: {1}\nDocument size: {2} bytes", info.FileType, info.PageCount, info.Size);
}
```

## Obtener información de archivo para un archivo de Stream {#get-file-info-for-a-file-from-stream}

```csharp
using (Redactor redactor = new Redactor(File.OpenRead("source.docx"))
{
	IDocumentInfo info = redactor.GetDocumentInfo();
    Console.WriteLine("\nFile type: {0}\nNumber of pages: {1}\nDocument size: {2} bytes", info.FileType, info.PageCount, info.Size);
}
```

GroupDocs.Redaction permite obtener la lista de todos los formatos de archivo admitidos mediante los siguientes pasos:

*   Llame a <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>;
*   Recorra la colección de objetos <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.*.*

El siguiente ejemplo muestra cómo obtener la lista de formatos de archivo admitidos.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

GroupDocs.Redaction permite redactar datos de naturaleza confidencial o privada en documentos de hojas de cálculo en formatos como XLS, XLSX, ODS y otros. Consulte la lista completa en el artículo [formatos de documentos admitidos](/net/redaction/getting-started/supported-document-formats/).

## Filtrar por hoja de cálculo y columna {#filter-by-spreadsheet-and-column}

Si dispone de un documento con una o varias tablas organizadas en hojas de cálculo (una tabla por hoja), como los documentos de Microsoft Excel, puede utilizar un tipo específico de redacción de texto: <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/cellcolumnredaction" target="_blank" rel="nofollow noopener noreferrer">CellColumnRedaction</a>. Esta opción le permite delimitar el ámbito de la redacción a una hoja de cálculo y/o columna concretas. Las opciones disponibles son:

*   opcionalmente, establecer el nombre de la hoja de cálculo o su índice numérico (si ambos datos faltan, la redacción afectará a todas las hojas de cálculo)
*   opcionalmente, establecer una columna concreta (si no se define ningún filtro de columna, se utilizarán todas las columnas)

Si no se definen filtros, la redacción afectará a todo el documento. Todos los índices son de base cero. A continuación se muestra un ejemplo en el que se aplican todos los filtros para redactar la segunda columna, que contiene direcciones de correo electrónico (por ejemplo, cargadas desde una base de datos), en la hoja de cálculo denominada «Customers», dejando intactos todos los demás correos electrónicos del documento:

**C#**

```csharp
using (Redactor redactor = new Redactor("D:\\Sales in September.xslx"))
{
   var filter = new CellFilter()
   {
      ColumnIndex = 1, // zero-based 2nd column
      WorkSheetName = "Customers"
   };
   var expression = new Regex("^\\w+([-+.']\\w+)*@\\w+([-.]\\w+)*\\.\\w+([-.]\\w+)*$");
   RedactorChangeLog changeLog = redactor.Apply(new CellColumnRedaction(filter, expression, new ReplacementOptions("[customer email]")));
   if (result.Status != RedactionStatus.Failed)
   {
      doc.Save(new SaveOptions() { AddSuffix = true });
   };
}
```

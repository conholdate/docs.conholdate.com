GroupDocs.Redaction le permite establecer un ámbito basado en páginas para su redacción, de dos tipos:
*   rango de páginas: un número determinado de páginas a partir de una posición específica desde el inicio o el final del documento;
*   área de página (en cada página), que corresponde a un rectángulo basado en la esquina superior izquierda.  

Todos los filtros heredan de <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.redactions/redactionfilter/" target="_blank" rel="nofollow noopener noreferrer">RedactionFilter</a> y, como matriz, se asignan a la propiedad **Filters** de <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.redactions/replacementoptions/" target="_blank" rel="nofollow noopener noreferrer">ReplacementOptions</a>.

Puede combinar estos filtros en un único conjunto para definir el ámbito de redacción en un área específica de una página determinada. Para obtener más detalles, consulte el artículo [Uso de filtros de redacción en PDF](/net/redaction/developer-guide/advanced-usage/using-redaction-filters/use-pdf-redaction-filters/).

## Limitaciones de los filtros de redacción {#redaction-filters-limitations}

Con GroupDocs.Redaction v23.6, existen las siguientes limitaciones en los filtros de redacción:
*   No se admiten documentos PDF únicamente.  

Estamos trabajando para incorporar más formatos compatibles en futuras versiones de GroupDocs.Redaction.

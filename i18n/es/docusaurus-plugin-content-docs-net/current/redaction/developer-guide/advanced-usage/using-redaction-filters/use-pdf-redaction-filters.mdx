Puede combinar los filtros <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.redactions/pagerangefilter/" target="_blank" rel="nofollow noopener noreferrer">PageRangeFilter</a> y <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.redactions/pageareafilter/" target="_blank" rel="nofollow noopener noreferrer">PageAreaFilter</a> en un único conjunto para definir el ámbito de la redacción en un área específica de una página determinada. Debe establecer una matriz de instancias en la propiedad **Filters** del <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.redactions/replacementoptions/" target="_blank" rel="nofollow noopener noreferrer">ReplacementOptions</a>. 

El siguiente ejemplo muestra cómo aplicar la redacción a la mitad inferior de la última página de un documento PDF.

**C#**

```csharp
using GroupDocs.Redaction.Options.Drawing;

using (Redactor redactor = new Redactor("Sample.pdf"))
{
    // Get the actual size information for the last page:
    IDocumentInfo info = redactor.GetDocumentInfo();
    PageInfo lastPage = info.Pages[info.PageCount - 1];
    ReplacementOptions options = new Redactions.ReplacementOptions("[secret]");
    options.Filters = new RedactionFilter[] {
        new PageRangeFilter(PageSeekOrigin.End, 0, 1),
        //new PageAreaFilter(new System.Drawing.Point(0, lastPage.Height/2),
        //    new System.Drawing.Size(lastPage.Width, lastPage.Height/2))
        // Use GroupDocs.Redaction.Options.Drawing types instead of System.Drawing, which is scheduled for removal in future versions.
        new PageAreaFilter(new Point(0, lastPage.Height/2),
            new Size(lastPage.Width, lastPage.Height/2))
    };
    RedactorChangeLog result = redactor.Apply(new ExactPhraseRedaction("sample", false, options));
    if (result.Status != RedactionStatus.Failed)
    {
        redactor.Save();
    };
}

```

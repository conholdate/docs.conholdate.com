Este método puede utilizarse cuando, por alguna razón, los archivos tienen extensiones no estándar o cuando su formato es compatible, pero no está preconfigurado. Por ejemplo, se podrían abrir todo tipo de archivos de texto plano (archivos por lotes, archivos de comandos, etc.). En este caso, no es necesario crear un controlador de formato propio. Como se muestra a continuación, puede agregar la extensión de archivo (por ejemplo, ".dump") como si estuviera gestionada por el mismo *<a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance" target="_blank" rel="nofollow noopener noreferrer">DocumentFormatInstance</a>* que todos los archivos de texto plano:

**C#**

```csharp
var config = RedactorConfiguration.GetInstance();
var settings = config.FindFormat(".txt");
settings.ExtensionFilter = settings.ExtensionFilter + ",.dump";
using (Redactor redactor = new Redactor(@"C:\sample.dump"))
{
   // Here we can use the document instance to perform redactions
}
```

En detalle, la creación de sus propias instancias de formato de documento se cubre en otro artículo.

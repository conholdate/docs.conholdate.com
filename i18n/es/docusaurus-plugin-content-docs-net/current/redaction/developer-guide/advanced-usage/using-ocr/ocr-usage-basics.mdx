Aunque GroupDocs.Redaction en sí mismo no incluye OCR como parte de su distribución, le permite integrar cualquier solución de OCR, ya sea de pago o gratuita. 
Debe implementar la interfaz <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration.ocr/iocrconnector" target="_blank" rel="nofollow noopener noreferrer">IOcrConnector</a> y su método `RecognizeImage()`, el cual recibe como argumento un flujo que contiene una imagen y devuelve una representación estructurada del texto, incluyendo los rectángulos delimitadores. 

**C#**

```csharp
public class MyOwnOcrConnector : IOcrConnector
{
    public MyOwnOcrConnector()
    {
    }

    public RecognizedImage Recognize(Stream imageStream)
    {
	// TODO Create an instance of RecognizedImage class using OCR result returned by your OCR toolkit

        throw new NotImplementedException();
    }
}

```

Una vez que la instancia se pasa al constructor de <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.options/redactorsettings" target="_blank" rel="nofollow noopener noreferrer">RedactorSettings</a>, GroupDocs.Redaction la utilizará para los archivos de imagen y las imágenes incrustadas durante un proceso normal de redacción de texto.

**C#**

```csharp
using GroupDocs.Redaction.Options.Drawing;

using (Redactor redactor = new Redactor("\\Sample.docx", new LoadOptions(), new RedactorSettings(new MyOwnOcrConnector())))
{
    // Assign an instance before using Redactor
    // Use GroupDocs.Redaction.Options.Drawing types instead of System.Drawing, which is scheduled for removal in future versions.
    //redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(System.Drawing.Color.Black)));
    redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(Color.Black)));
    redactor.Save();
}

```

GroupDocs.Redaction proporciona tres ejemplos de implementación de `IOcrConnector`, disponibles libremente para su uso y personalización según sus necesidades. En primer lugar, la implementación [basada en el SDK de Aspose.OCR para la nube](/net/redaction/developer-guide/advanced-usage/using-ocr/use-aspose-ocr-for-cloud/). En segundo lugar, la implementación [basada en la API local de Aspose.OCR para .NET](/net/redaction/developer-guide/advanced-usage/using-ocr/use-aspose-ocr-on-premise/). En tercer lugar, la implementación [utiliza la API de Microsoft Azure Cognitive Services](/net/redaction/developer-guide/advanced-usage/using-ocr/use-microsoft-azure-computer-vision/). Ambos servicios ofrecen un plan de suscripción de prueba, pero puede utilizar cualquier otra solución OCR gratuita o de pago, basada en la web o local, creando su propia implementación de `<a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration.ocr/iocrconnector" target="_blank" rel="nofollow noopener noreferrer">IOcrConnector</a>`.

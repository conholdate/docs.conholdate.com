GroupDocs.Redaction admite ambos tipos de documentos de imagen para reconocimiento óptico de caracteres (OCR):
*   archivos de imagen, como escaneos de documentos impresos (PNG, JPG, etc.)
*   imágenes incrustadas en documentos ofimáticos (PDF, DOCX, etc.)  

Debe implementar la interfaz <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration.ocr/iocrconnector" target="_blank" rel="nofollow noopener noreferrer">IOcrConnector</a> y pasar la instancia al constructor de <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.options/redactorsettings" target="_blank" rel="nofollow noopener noreferrer">RedactorSettings</a>.

Para obtener más información, consulte el artículo [Conceptos básicos del uso del OCR](/net/redaction/developer-guide/advanced-usage/using-ocr/ocr-usage-basics/).

## Limitaciones del uso del OCR {#ocr-usage-limitations}

Las siguientes son las limitaciones del OCR en GroupDocs.Redaction v21.3:
*   no se admiten sustituciones textuales, por lo que debe utilizar sustituciones mediante cajas de color para redactar texto en imágenes.
*   No se admiten los tipos de documentos hojas de cálculo, HTML ni Markdown.  

Estamos trabajando para eliminar estas limitaciones en futuras versiones de GroupDocs.Redaction.

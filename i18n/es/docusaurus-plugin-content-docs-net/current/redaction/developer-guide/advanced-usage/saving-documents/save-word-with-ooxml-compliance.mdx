Al guardar un documento de procesamiento de textos en su formato original, puede establecer el nivel de cumplimiento OOXML mediante <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.options/wordprocessingsaveoptions/ooxmlcompliance/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions.WordprocessingSaveOptions.OoxmlCompliance</a>. Utilice valores de la enumeración <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.options/wordprocessingcompliancelevel/" target="_blank" rel="nofollow noopener noreferrer">WordProcessingComplianceLevel</a>, como `Ecma`, `Transitional` o `Strict`.

Si no establece esta propiedad, GroupDocs.Redaction conserva el nivel de cumplimiento del documento original. El nivel de cumplimiento estricto solo puede reducirse a transicional, no a Ecma.

Esta opción se aplica a formatos de Word basados en OOXML, como DOCX, DOCM, DOTX y DOTM. Establezca `RasterizeToPDF` en `false` para guardar el documento en su formato original de Word en lugar de guardarlo como un PDF rasterizado.

El siguiente ejemplo muestra cómo guardar un documento de Word redactado con el nivel de cumplimiento estricto de OOXML:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Here we can use document instance to perform redactions
    redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]")));

    // Save the document
    var options = new SaveOptions()
    {
        AddSuffix = true,
        RasterizeToPDF = false, // original format
        RedactedFileSuffix = "Strict"
    };
    // Set the OOXML compliance level to Strict
    // If not specified, the compliance level of the original document is preserved.
    options.WordprocessingSaveOptions.OoxmlCompliance = WordProcessingComplianceLevel.Strict;

    redactor.Save(options);
}
```

## Utilizar opciones avanzadas de rasterización {#use-advanced-rasterization-options}

Para utilizar las opciones avanzadas de rasterización, debe pasar una de estas opciones al método <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save</a>. En este caso, el documento se rasterizará a PDF, pero se aplicarán efectos simulados de escaneo a sus páginas.

El siguiente ejemplo muestra cómo aplicar <a href="https://reference.groupdocs.com/redaction/net/groupdocs.redaction.options/advancedrasterizationoptions/" target="_blank" rel="nofollow noopener noreferrer">AdvancedRasterizationOptions</a> con la configuración predeterminada. 

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Save the document with advanced options (convert pages into images, and save PDF with scan-like pages)
    var so = new SaveOptions();
    so.Rasterization.Enabled = true;
    so.RedactedFileSuffix = "_scan";
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Border);
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Noise);
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Grayscale);
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Tilt);
    redactor.Save(so);
}

```

### Opción de rasterización de borde {#use-border-rasterization-option}

Puede establecer el ancho personalizado del borde proporcionando el elemento de diccionario «border» con un valor entero.

El siguiente ejemplo muestra cómo aplicar la opción avanzada de rasterización de borde con configuraciones personalizadas.

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Save the document with a custom border
    var so = new SaveOptions();
    so.Rasterization.Enabled = true;
    so.RedactedFileSuffix = "_scan";
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Border, new Dictionary<string, string>() { { "border", "10" } });
    redactor.Save(so);
}

```

### Opción de rasterización en escala de grises {#use-grayscale-rasterization-option}

El siguiente ejemplo muestra cómo aplicar la opción avanzada de rasterización en escala de grises.

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Save the document with the custom grayscale effect
    var so = new SaveOptions();
    so.Rasterization.Enabled = true;
    so.RedactedFileSuffix = "_scan";
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Grayscale);
    redactor.Save(so);
}

```

### Usar la opción de rasterización con ruido {#use-noise-rasterization-option}

Puede configurar los efectos de ruido personalizados proporcionando los elementos del diccionario "maxSpots" y "spotMaxSize", cuyos valores deben ser enteros. El parámetro "maxSpots" define el número máximo de manchas, que es aleatorio, y "spotMaxSize" define el tamaño máximo permitido para las manchas.

El siguiente ejemplo muestra cómo aplicar la opción avanzada de rasterización con ruido con configuraciones personalizadas.

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Save the document with the custom number and size of noise effects
    var so = new SaveOptions();
    so.Rasterization.Enabled = true;
    so.RedactedFileSuffix = "_scan";
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Noise, 
                    new Dictionary<string, string>() { { "maxSpots", "150" }, { "spotMaxSize", "15" } });
    redactor.Save(so);
}

```

### Opción de rasterización inclinada {#use-tilt-rasterization-option}

Puede configurar los efectos inclinados personalizados proporcionando los elementos del diccionario «minAngle» y «randomAngleMax», ambos con valores enteros. El valor «minAngle» define el ángulo mínimo de rotación, mientras que «randomAngleMax» representa el ángulo máximo de rotación, que se suma aleatoriamente a «minAngle».

El siguiente ejemplo muestra cómo aplicar la opción avanzada de rasterización inclinada con configuraciones personalizadas.

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    // Save the document with the custom tilt effect
    var so = new SaveOptions();
    so.Rasterization.Enabled = true;
    so.RedactedFileSuffix = "_scan";
    so.Rasterization.AddAdvancedOption(AdvancedRasterizationOptions.Tilt,
                    new Dictionary<string, string>() { { "minAngle", "85" }, { "randomAngleMax", "5" } });
    redactor.Save(so);
}

```

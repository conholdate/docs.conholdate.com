Al guardar el documento como un PDF rasterizado, puede especificar el índice de la página inicial (basado en cero) y la cantidad de páginas a partir de ese índice que se guardarán. Asimismo, puede cambiar el nivel de conformidad de PDF/A-1b, que se utiliza de forma predeterminada, a PDF/A-1a:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
    //RedactorChangeLog result = redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(System.Drawing.Color.Red)));
    // Use GroupDocs.Redaction.Options.Drawing types instead of System.Drawing, which is scheduled for removal in future versions.
    RedactorChangeLog result = redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions(GroupDocs.Redaction.Options.Drawing.Color.Red)));
    if (result.Status != RedactionStatus.Failed)
    {
        var options = new SaveOptions();
        options.Rasterization.Enabled = true;                           // the same as options.RasterizeToPDF = true;
        options.Rasterization.PageIndex = 5;                            // start from 6th page (index is 0-based)
        options.Rasterization.PageCount = 1;                            // save only one page
        options.Rasterization.Compliance = PdfComplianceLevel.PdfA1a;   // by default PdfComplianceLevel.Auto or PDF/A-1b
        options.AddSuffix = true;
        redactor.Save(options);
    }
}
```

Al guardar un documento, GroupDocs.Redaction lo coloca en la misma carpeta que el archivo original, renombrándolo o sobrescribiéndolo. Si necesita guardar el documento en una ubicación personalizada, deberá abrir un *Stream* hacia dicha ubicación. Como opción de guardado predeterminada, *GroupDocs.Redaction* convierte todas las páginas (diapositivas, hojas de cálculo) de un documento en imágenes y las coloca en un único archivo PDF, de modo que pueda compartir el documento redactado sin necesidad de conversiones adicionales. Puede controlar este comportamiento mediante la propiedad *RasterizeToPdf* en *SaveOptions* o la propiedad *Enabled* en la clase *RasterizationOptions*.

Para documentos de procesamiento de textos guardados en el formato original, también puede establecer el nivel de cumplimiento OOXML mediante `SaveOptions.WordprocessingSaveOptions.OoxmlCompliance`.

Para rechazar o aprobar cambios específicos durante el proceso de redacción, o para mantener un registro completo de los cambios realizados en el documento, es necesario proporcionar una instancia de <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/iredactioncallback" target="_blank" rel="nofollow noopener noreferrer">IRedactionCallback</a> al constructor de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.options/redactorsettings" target="_blank" rel="nofollow noopener noreferrer">RedactorSettings</a>. Esta interfaz contiene únicamente un método, <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.redactions/iredactioncallback/methods/acceptredaction" target="_blank" rel="nofollow noopener noreferrer">AcceptRedaction()</a>, que recibe información detallada sobre la redacción propuesta y devuelve un valor *Boolean* que indica si se acepta o no.

A continuación, creamos una clase de devolución de llamada que registra los cambios en la consola del sistema:

**C#**

```csharp
public class RedactionDump : IRedactionCallback
{
    public RedactionDump()
    {
    }

    public bool AcceptRedaction(RedactionDescription description)
    {
        Console.Write("{0} redaction, {1} action, item {2}. ", description.RedactionType, description.ActionType, description.OriginalText);
        if (description.Replacement != null)
        {
            Console.Write("Text {0} is replaced with {1}. ", description.Replacement.OriginalText, description.Replacement.Replacement);
        }
        Console.WriteLine();
        // you can return "false" here to prevent particular change during redaction process
        return true;
    }
}

```

La instancia de esta clase debe pasarse al constructor de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">Redactor</a>:

**C#**

```csharp
using (Redactor redactor = new Redactor("\\Sample.docx", new LoadOptions(), new RedactorSettings(new RedactionDump())))
{
    // Assign an instance before using Redactor
    redactor.Apply(new ExactPhraseRedaction("John Doe", new ReplacementOptions("[personal]")));
    redactor.Save();
}

```

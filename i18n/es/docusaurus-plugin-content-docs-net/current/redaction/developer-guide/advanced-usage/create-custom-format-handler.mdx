Si el formato no es compatible, deberá implementar un controlador para él heredando de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance" target="_blank" rel="nofollow noopener noreferrer">DocumentFormatInstance</a>. Dependiendo de las características del documento y de las redacciones requeridas, también deberá implementar una o varias interfaces que permitan a GroupDocs.Redaction trabajar con este formato de documento.

| Interfaz | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/itextualformatinstance" target="_blank" rel="nofollow noopener noreferrer">ITextualFormatInstance</a> | Necesaria para que funcionen las redacciones de texto del documento; reemplaza las ocurrencias de la expresión regular dada por un texto o un bloque de color |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/imetadataaccess" target="_blank" rel="nofollow noopener noreferrer">IMetadataAccess</a> | Necesaria para las redacciones de metadatos; lee los metadatos y modifica un elemento específico de metadatos |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/iannotateddocument" target="_blank" rel="nofollow noopener noreferrer">IAnnotatedDocument</a> | Necesaria para las redacciones de anotaciones; modifica o elimina anotaciones que coincidan con la expresión regular dada |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/irasterizabledocument" target="_blank" rel="nofollow noopener noreferrer">IRasterizableDocument</a> | Necesaria para rasterizar (guardar el documento como un PDF con imágenes de página) |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/iimageformatinstance" target="_blank" rel="nofollow noopener noreferrer">IImageFormatInstance</a> | Necesaria para las redacciones en formatos de imagen rasterizada, basándose en las coordenadas de la esquina superior izquierda y el tamaño del área |
| <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/ipreviewable" target="_blank" rel="nofollow noopener noreferrer">IPreviewable</a> | Necesaria para proporcionar información general del documento y la funcionalidad de vista previa |

Cada una de estas interfaces es opcional, es decir, no es necesario implementar todas ellas; por ejemplo, <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/iimageformatinstance" target="_blank" rel="nofollow noopener noreferrer">IImageFormatInstance</a> — si no necesita su funcionalidad — o <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/imetadataaccess" target="_blank" rel="nofollow noopener noreferrer">IMetadataAccess</a>, si su formato no admite metadatos.

A continuación, creamos una clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance" target="_blank" rel="nofollow noopener noreferrer">DocumentFormatInstance</a> con lógica personalizada para el procesamiento de documentos de texto, que solo admite redacciones textuales:

**C#**

```csharp
public class CustomTextualDocument : DocumentFormatInstance, ITextualFormatInstance
{
    private RedactorSettings Settings { get; set; }
    private List<string> FileContent { get; set; }

    public CustomTextualDocument()
    {
        FileContent = new List<string>();
    }

    public override void Initialize(DocumentFormatConfiguration config, RedactorSettings settings)
    {
        Settings = settings;
    }

    public override void Load(System.IO.Stream input)
    {
        FileContent.Clear();
        using (var reader = new StreamReader(input))
        {
            while (!reader.EndOfStream)
            {
                FileContent.Add(reader.ReadLine());
            }
        }
    }

    public override void Save(System.IO.Stream output)
    {
        var writer = new StreamWriter(output);
        foreach (var line in FileContent)
        {
            writer.WriteLine(line);
        }
        writer.Flush();
    }

    public RedactionResult ReplaceText(Regex regex, Redactions.ReplacementOptions options)
    {
        try
        {
            if (options.ActionType != Redactions.ReplacementType.ReplaceString)
            {
                return new RedactionResult.Failed("This format allows only ReplaceString redactions!");
            }
            for (int i = 0; i < FileContent.Count; i++)
            {
                FileContent[i] = regex.Replace(FileContent[i], options.Replacement);
            }
            return RedactionResult.Successful();
        }
        catch (Exception ex)
        {
            return RedactionResult.Failed(ex.ToString());
        }
    }
}

```

Para utilizar esta clase, deberemos agregarla a los formatos preconfigurados, por ejemplo, como un controlador para archivos de volcado ("\*.dump"):

**C#**

```csharp
var config = RedactorConfiguration.GetInstance();
config.AvailableFormats.Add(new DocumentFormatConfiguration()
{
    ExtensionFilter = ".dump",
    DocumentType = typeof(CustomTextualDocument)
});
```

## Seguridad y protección con contraseña {#security-and-password-protection}

Si su formato admite opciones de seguridad, como la protección con contraseña, deberá pasar `true` o `false` al método <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance/methods/setaccessgranted" target="_blank" rel="nofollow noopener noreferrer">SetAccessGranted</a> de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance" target="_blank" rel="nofollow noopener noreferrer">DocumentFormatInstance</a> dentro de la implementación que sobrescriba del método <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.integration/documentformatinstance/methods/load" target="_blank" rel="nofollow noopener noreferrer">Load</a>, y lanzar <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.exceptions/incorrectpasswordexception" target="_blank" rel="nofollow noopener noreferrer">IncorrectPasswordException</a> o <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.exceptions/passwordrequiredexception" target="_blank" rel="nofollow noopener noreferrer">PasswordRequiredException</a>, si corresponde. Por ejemplo:

**C#**

```csharp
public override void Load(System.IO.Stream input)
{
    try
    {
		// check security and load document 

        SetAccessGranted(true);
    }
    catch (SomeSecurityException)
    {
        SetAccessGranted(false);
		// Password, provided with LoadOptions
        if (string.IsNullOrEmpty(Password))
            throw new Exceptions.PasswordRequiredException();
        else
            throw new Exceptions.IncorrectPasswordException();
    }
}

```

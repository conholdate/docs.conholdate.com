Como alternativa a un archivo local, <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">Redac</a>[t](https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor)<a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">or</a> puede abrir un documento desde un flujo (stream).

El siguiente ejemplo muestra cómo cargar y aplicar redacción a un documento mediante un flujo (stream):

**C#**

```csharp
using (Stream stream = File.Open(@"sample.docx", FileMode.Open, FileAccess.ReadWrite))
{
   using (Redactor redactor = new Redactor(stream))
   {
      // Here we can use document instance to make redactions
      redactor.Apply(new DeleteAnnotationRedaction());
      redactor.Save();
   }
}
```

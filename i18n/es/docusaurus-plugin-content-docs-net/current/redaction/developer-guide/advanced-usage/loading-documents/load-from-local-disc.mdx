La clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Redaction.Redactor</a> es la clase principal de la API de Redacción, proporcionando funcionalidad para abrir un documento. Cuando el documento se encuentra en el disco local, puede pasar su ruta al constructor de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/redactor" target="_blank" rel="nofollow noopener noreferrer">Redactor</a>.

El siguiente ejemplo muestra cómo abrir un documento desde el disco local:

**C#**

```csharp
using (Redactor redactor = new Redactor(@"sample.docx"))
{
   // Here we can use document instance to perform redactions   
   redactor.Apply(new DeleteAnnotationRedaction());
   redactor.Save();
}
```

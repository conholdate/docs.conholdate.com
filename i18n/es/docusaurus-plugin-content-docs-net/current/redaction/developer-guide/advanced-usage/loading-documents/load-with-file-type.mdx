Cuando abra un documento desde un [stream](/net/redaction/developer-guide/advanced-usage/loading-documents/load-from-stream/) sin un nombre de archivo, o cuando la extensión del archivo no coincida con el formato real, pase el formato esperado a través de <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction.options/loadoptions/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.FileType</a>. GroupDocs.Redaction omitirá la detección automática del formato y utilizará el tipo que usted especifique.

Establezca `FileType` en cualquier constante admitida de la clase <a href="https://reference.groupdocs.com/net/redaction/groupdocs.redaction/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>, por ejemplo `FileType.DOCX` o `FileType.PDF`. El valor predeterminado es `FileType.Unknown`, que mantiene el comportamiento de detección existente.

El siguiente ejemplo muestra cómo cargar un documento desde un flujo y desde una ruta de archivo, especificando explícitamente el tipo de archivo:

**C#**

```csharp
using System.IO;
using GroupDocs.Redaction.Options;
using GroupDocs.Redaction.Options.Drawing;
using GroupDocs.Redaction.Redactions;

string sourceFileStream = @"sample.docx";
using (Stream stream = File.Open(sourceFileStream, FileMode.Open, FileAccess.ReadWrite))
{
    using (Redactor redactor = new Redactor(stream, new LoadOptions(FileType.DOCX)))
    {
        redactor.Apply(new DeleteAnnotationRedaction());
        redactor.Save();
    }
}

string sourceFilePath = @"LoremIpsum.pdf";
using (Redactor redactor = new Redactor(sourceFilePath, new LoadOptions(FileType.PDF)))
{
    redactor.Apply(new ExactPhraseRedaction("Lorem", new ReplacementOptions(Color.Chocolate)));
    redactor.Save();
}
```

## Información general {#overview}
  
Aspose.Slides se puede utilizar en modo de evaluación o con una licencia válida. La versión de evaluación ofrece la misma funcionalidad que la versión con licencia, pero agrega una marca de agua de evaluación en cada diapositiva de cada presentación que guarda y trunca el texto que su código lee de las presentaciones.

Este artículo explica cómo funciona la licencia en Aspose.Slides y cómo aplicar una licencia antes de utilizar la biblioteca. Una licencia puede cargarse desde un archivo, un flujo o un recurso incrustado mediante la clase `License`. El artículo también muestra cómo validar si una licencia se ha aplicado correctamente.

## Licencias en Aspose.Slides {#licensing-in-aspose-slides}  

- Una versión de evaluación se convierte en una versión con licencia tras adquirir una licencia y agregarle un par de líneas de código (para aplicar la licencia).
- La licencia es un archivo XML de texto plano que contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciada, la fecha de vencimiento de la suscripción, entre otros.
- El archivo de licencia está firmado digitalmente, por lo que no debe modificarlo. Incluso una adición accidental de un salto de línea adicional en el contenido del archivo lo invalidará.
- Aspose.Slides para .NET normalmente intenta encontrar la licencia en las siguientes ubicaciones:
  - Una ruta explícita
  - La carpeta que contiene el archivo DLL del componente (incluido en Aspose.Slides)
  - La carpeta que contiene el ensamblado que llamó al DLL del componente (incluido en Aspose.Slides)
  - La carpeta que contiene el ensamblado de entrada (su .exe)
  - Un recurso incrustado en el ensamblado que llamó al DLL del componente (incluido en Aspose.Slides).
- Para evitar las limitaciones asociadas con la versión de evaluación, debe establecer una licencia antes de utilizar Aspose.Slides. Solo necesita establecer una licencia una vez por aplicación o proceso.

:::info[Nota]  
Es posible que desee consultar [Licencia basada en medición](/net/slides/metered-licensing/).
:::

## Aplicar una licencia {#apply-a-license}
  
Una licencia puede cargarse desde un **archivo**, un **flujo** o un **recurso incrustado**.

:::info[Nota]  
Aspose.Slides proporciona la clase <a href="https://reference.aspose.com/slides/net/aspose.slides/license" target="_blank" rel="nofollow noopener noreferrer">License</a> para operaciones de licenciamiento.
:::

:::warning[Advertencia]  
Las nuevas licencias solo pueden activar Aspose.Slides con la versión 21.4 o posterior. Las versiones anteriores utilizan un sistema de licencias diferente y no reconocerán estas licencias.
:::

### Archivo {#file}
  
El método más sencillo para establecer una licencia consiste en colocar el archivo de licencia en la misma carpeta que contiene el archivo DLL del componente (incluido en Aspose.Slides) y especificar únicamente el nombre del archivo, sin su ruta.

Este código en C# le muestra cómo establecer un archivo de licencia:

```csharp
// Instantiates the License class 
Aspose.Slides.License license = new Aspose.Slides.License();

// Sets the license file path
license.SetLicense("Aspose.Slides.lic");
```

:::warning[Advertencia]
Si coloca el archivo de licencia en un directorio diferente, al llamar al método <a href="https://reference.aspose.com/slides/net/aspose.slides/license/setlicense/#setlicense_1" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>, el nombre del archivo de licencia al final de la ruta especificada debe ser el mismo que el nombre de su archivo de licencia.

Por ejemplo, puede cambiar el nombre del archivo de licencia a *Aspose.Slides.lic.xml*. Luego, en su código, debe pasar la ruta al archivo (terminando con *Aspose.Slides.lic.xml*) al método <a href="https://reference.aspose.com/slides/net/aspose.slides/license/setlicense/#setlicense_1" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>.
:::

### Stream {#stream}
  
Puede cargar una licencia desde un flujo (stream). El siguiente código en C# le muestra cómo aplicar una licencia desde un flujo:

```csharp
// Instantiates the License class
Aspose.Slides.License license = new Aspose.Slides.License();

// Opens the license file as a stream
using FileStream licenseStream = File.OpenRead("Aspose.Slides.lic");

// Sets the license through a stream
license.SetLicense(licenseStream);
```

### Recurso integrado  {#embedded-resource}
  
Puede empaquetar la licencia junto con su aplicación (para evitar su pérdida) agregando la licencia como un recurso integrado en uno de los ensamblados que llaman al DLL del componente (incluido en Aspose.Slides).

A continuación se explica cómo agregar un archivo de licencia como recurso integrado:  

1. En Visual Studio, agregue el archivo de licencia (.lic) al proyecto de la siguiente manera: vaya a **Archivo** &gt; **Agregar elemento existente** &gt; **Agregar**.
2. Seleccione el archivo en el **Explorador de soluciones**.
3. En la ventana **Propiedades**, establezca la **Acción de compilación** en **Recurso integrado**.
4. Para acceder a la licencia integrada en el ensamblado, agregue el archivo de licencia como recurso integrado al proyecto y, a continuación, pase el nombre del archivo de licencia al método `SetLicense`.

La clase `License` encuentra automáticamente el archivo de licencia en los recursos integrados. No es necesario que llame a los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` en Microsoft .NET Framework.

El siguiente código en C# le muestra cómo establecer una licencia como recurso integrado:

```csharp
// Instantiates the License class
Aspose.Slides.License license = new Aspose.Slides.License();

// Passes the license file name embedded in the assembly
license.SetLicense("Aspose.Slides.lic");
```

## Validar una licencia {#validate-a-license}
  
Para comprobar si una licencia se ha configurado correctamente, puede validarla. El siguiente código en C# le muestra cómo validar una licencia:

```csharp
Aspose.Slides.License license = new Aspose.Slides.License();

license.SetLicense("Aspose.Slides.lic");

if (license.IsLicensed())
{
    Console.WriteLine("License is good!");
    Console.Read();
}
```

## Seguridad de subprocesos {#thread-safety}
  
:::warning[Advertencia]  
El método <a href="https://reference.aspose.com/slides/net/aspose.slides/license/setlicense/" target="_blank" rel="nofollow noopener noreferrer">license.SetLicense</a> no es seguro para subprocesos. Si este método debe llamarse simultáneamente desde varios subprocesos, es recomendable utilizar primitivas de sincronización (como un bloqueo) para evitar problemas.
:::

## Preguntas frecuentes {#faq}

### ¿Puedo aplicar la licencia en un entorno completamente sin conexión (sin acceso a internet)? {#can-i-apply-the-license-in-a-completely-offline-environment-no-internet-access}

Sí. La validación de la licencia se realiza localmente mediante el archivo de licencia; no se requiere conexión a internet.

### ¿Qué ocurre después de que vence la suscripción de un año? ¿Dejará de funcionar la biblioteca? {#what-happens-after-the-one-year-subscription-expires-will-the-library-stop-working}

No. La licencia es perpetua: puede seguir utilizando las versiones publicadas antes de la fecha de finalización de su suscripción; simplemente no tendrá derecho a utilizar versiones más recientes sin renovarla.

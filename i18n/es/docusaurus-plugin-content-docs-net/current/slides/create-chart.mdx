> Cree y personalice gráficos en presentaciones de PowerPoint mediante Aspose.Slides para .NET. Agregue, formatee y edite gráficos con ejemplos prácticos de código en C#.

## Información general {#overview}
  
Este artículo ofrece una guía completa sobre cómo crear y personalizar gráficos mediante Aspose.Slides para .NET. Aprenderá a agregar un gráfico a una diapositiva mediante programación, rellenarlo con datos y aplicar diversas opciones de formato para adaptarse a sus requisitos específicos de diseño. A lo largo del artículo, se presentan ejemplos de código detallados que ilustran cada paso, desde la inicialización de la presentación y del objeto gráfico hasta la configuración de series, ejes y leyendas. Al seguir esta guía, obtendrá una comprensión sólida sobre cómo integrar la generación dinámica de gráficos en sus aplicaciones .NET, simplificando así el proceso de creación de presentaciones basadas en datos.

## Crear un gráfico {#create-a-chart}
  
Los gráficos ayudan a las personas a visualizar rápidamente los datos y obtener información que podría no ser evidente de inmediato en una tabla o hoja de cálculo.

**¿Por qué crear gráficos?**

Mediante el uso de gráficos, puede:

- agregar, condensar o resumir grandes cantidades de datos en una sola diapositiva de una presentación;
- revelar patrones y tendencias en los datos;
- deducir la dirección y la magnitud de los datos a lo largo del tiempo o con respecto a una unidad de medida específica;
- detectar valores atípicos, anomalías, desviaciones, errores y datos sin sentido;
- comunicar o presentar datos complejos.

En PowerPoint, puede crear gráficos mediante la función *Insertar*, que proporciona plantillas para diseñar muchos tipos de gráficos. Con Aspose.Slides, puede crear tanto gráficos estándar (basados en tipos de gráficos populares) como gráficos personalizados.

:::info[Nota]  
Utilice la enumeración <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a> del espacio de nombres <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Slides.Charts</a>. Los valores de esta enumeración corresponden a distintos tipos de gráficos.
:::

### Crear gráficos de columnas agrupadas {#create-clustered-column-charts}
  
Este ejemplo utiliza <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addchart/" target="_blank" rel="nofollow noopener noreferrer">AddChart</a> para crear un gráfico de columnas agrupadas que compara dos series en tres categorías. Las series utilizan rellenos rojo y verde, y las etiquetas individuales muestran los nombres de las categorías, los nombres de las series y los valores. El índice de hoja 0 hace referencia a la primera hoja del libro de trabajo incrustado del gráfico.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 20, 20, 500, 300);

chart.ChartTitle.AddTextFrameForOverriding("Sample Title");
chart.ChartTitle.TextFrameForOverriding.TextFrameFormat.CenterText = NullableBool.True;
chart.ChartTitle.Height = 20;
chart.HasTitle = true;

var workbook = chart.ChartData.ChartDataWorkbook;
var worksheetIndex = 0;

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();

var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 1, "Series 1");
chart.ChartData.Series.Add(seriesNameCell, chart.Type);
seriesNameCell = workbook.GetCell(worksheetIndex, 0, 2, "Series 2");
chart.ChartData.Series.Add(seriesNameCell, chart.Type);

var categoryCell = workbook.GetCell(worksheetIndex, 1, 0, "Category 1");
chart.ChartData.Categories.Add(categoryCell);
categoryCell = workbook.GetCell(worksheetIndex, 2, 0, "Category 2");
chart.ChartData.Categories.Add(categoryCell);
categoryCell = workbook.GetCell(worksheetIndex, 3, 0, "Category 3");
chart.ChartData.Categories.Add(categoryCell);

var series = chart.ChartData.Series[0];

var valueCell = workbook.GetCell(worksheetIndex, 1, 1, 20);
series.DataPoints.AddDataPointForBarSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 2, 1, 50);
series.DataPoints.AddDataPointForBarSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 3, 1, 30);
series.DataPoints.AddDataPointForBarSeries(valueCell);

series.Format.Fill.FillType = FillType.Solid;
series.Format.Fill.SolidFillColor.Color = Color.Red;

series = chart.ChartData.Series[1];

valueCell = workbook.GetCell(worksheetIndex, 1, 2, 30);
series.DataPoints.AddDataPointForBarSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 2, 2, 10);
series.DataPoints.AddDataPointForBarSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 3, 2, 60);
series.DataPoints.AddDataPointForBarSeries(valueCell);

series.Format.Fill.FillType = FillType.Solid;
series.Format.Fill.SolidFillColor.Color = Color.Green;

var label = series.DataPoints[0].Label;
label.DataLabelFormat.ShowCategoryName = true;

label = series.DataPoints[1].Label;
label.DataLabelFormat.ShowSeriesName = true;

label = series.DataPoints[2].Label;
label.DataLabelFormat.ShowValue = true;
label.DataLabelFormat.ShowSeriesName = true;
label.DataLabelFormat.Separator = "/";

presentation.Save("AsposeChart.pptx", SaveFormat.Pptx);
```

### Crear gráficos de dispersión {#create-scatter-charts}
  
Los gráficos de dispersión (también conocidos como diagramas de dispersión o gráficos x-y) se utilizan frecuentemente para detectar patrones o demostrar correlaciones entre dos variables.

Utilice un gráfico de dispersión cuando:  

- Tenga datos numéricos emparejados.
- Tenga dos variables que se complementen bien entre sí.
- Desee determinar si ambas variables están relacionadas.
- Tenga una variable independiente que tenga múltiples valores para una variable dependiente.

Este ejemplo representa dos conjuntos de valores x-y. La primera serie utiliza líneas rectas con marcadores en forma de estrella, mientras que la segunda utiliza líneas suaves con marcadores circulares; ambas utilizan un <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/imarker/size/" target="_blank" rel="nofollow noopener noreferrer">Size</a> de 10. La propiedad <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/imarker/symbol/" target="_blank" rel="nofollow noopener noreferrer">Symbol</a> controla la forma del marcador.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.ScatterWithSmoothLines, 20, 20, 500, 300);

var workbook = chart.ChartData.ChartDataWorkbook;
var worksheetIndex = 0;

chart.ChartData.Series.Clear();

var seriesNameCell = workbook.GetCell(worksheetIndex, 1, 1, "Series 1");
chart.ChartData.Series.Add(seriesNameCell, chart.Type);
seriesNameCell = workbook.GetCell(worksheetIndex, 1, 3, "Series 2");
chart.ChartData.Series.Add(seriesNameCell, chart.Type);

var series = chart.ChartData.Series[0];

var xValueCell = workbook.GetCell(worksheetIndex, 2, 1, 1);
var yValueCell = workbook.GetCell(worksheetIndex, 2, 2, 3);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

xValueCell = workbook.GetCell(worksheetIndex, 3, 1, 2);
yValueCell = workbook.GetCell(worksheetIndex, 3, 2, 10);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

series.Type = ChartType.ScatterWithStraightLinesAndMarkers;

series.Marker.Size = 10;
series.Marker.Symbol = MarkerStyleType.Star;

series = chart.ChartData.Series[1];

xValueCell = workbook.GetCell(worksheetIndex, 2, 3, 5);
yValueCell = workbook.GetCell(worksheetIndex, 2, 4, 2);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

xValueCell = workbook.GetCell(worksheetIndex, 3, 3, 3);
yValueCell = workbook.GetCell(worksheetIndex, 3, 4, 1);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

xValueCell = workbook.GetCell(worksheetIndex, 4, 3, 2);
yValueCell = workbook.GetCell(worksheetIndex, 4, 4, 2);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

xValueCell = workbook.GetCell(worksheetIndex, 5, 3, 5);
yValueCell = workbook.GetCell(worksheetIndex, 5, 4, 1);
series.DataPoints.AddDataPointForScatterSeries(xValueCell, yValueCell);

series.Marker.Size = 10;
series.Marker.Symbol = MarkerStyleType.Circle;

presentation.Save("AsposeChart.pptx", SaveFormat.Pptx);
```

### Crear gráficos de pastel  {#create-pie-charts}
  
Los gráficos de pastel son ideales para mostrar la relación parte-todo en los datos, especialmente cuando los datos contienen etiquetas categóricas con valores numéricos. Sin embargo, si sus datos contienen muchas partes o etiquetas, podría considerar utilizar un gráfico de barras en su lugar.

Este ejemplo crea un gráfico de pastel con tres valores trimestrales. Cada porción tiene un relleno y un borde personalizados, y las etiquetas muestran distintas combinaciones de valores, porcentajes e información de series. La propiedad <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseriesgroup/firstsliceangle/" target="_blank" rel="nofollow noopener noreferrer">FirstSliceAngle</a> establece que la primera porción comience en 180 grados.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Pie, 20, 20, 500, 300);

chart.ChartTitle.AddTextFrameForOverriding("Sample Title");
chart.ChartTitle.TextFrameForOverriding.TextFrameFormat.CenterText = NullableBool.True;
chart.ChartTitle.Height = 20;
chart.HasTitle = true;

chart.ChartData.Series[0].Labels.DefaultDataLabelFormat.ShowValue = true;

var workbook = chart.ChartData.ChartDataWorkbook;
var worksheetIndex = 0;

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();

var categoryCell = workbook.GetCell(0, 1, 0, "1st Qtr");
chart.ChartData.Categories.Add(categoryCell);
categoryCell = workbook.GetCell(0, 2, 0, "2nd Qtr");
chart.ChartData.Categories.Add(categoryCell);
categoryCell = workbook.GetCell(0, 3, 0, "3rd Qtr");
chart.ChartData.Categories.Add(categoryCell);

var seriesNameCell = workbook.GetCell(0, 0, 1, "Series 1");
var series = chart.ChartData.Series.Add(seriesNameCell, chart.Type);

var valueCell = workbook.GetCell(worksheetIndex, 1, 1, 20);
series.DataPoints.AddDataPointForPieSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 2, 1, 50);
series.DataPoints.AddDataPointForPieSeries(valueCell);
valueCell = workbook.GetCell(worksheetIndex, 3, 1, 30);
series.DataPoints.AddDataPointForPieSeries(valueCell);

chart.ChartData.SeriesGroups[0].IsColorVaried = true;

var firstSlice = series.DataPoints[0];
firstSlice.Format.Fill.FillType = FillType.Solid;
firstSlice.Format.Fill.SolidFillColor.Color = Color.Cyan;

firstSlice.Format.Line.FillFormat.FillType = FillType.Solid;
firstSlice.Format.Line.FillFormat.SolidFillColor.Color = Color.Gray;
firstSlice.Format.Line.Width = 3.0;
firstSlice.Format.Line.Style = LineStyle.ThinThick;
firstSlice.Format.Line.DashStyle = LineDashStyle.LargeDash;

var secondSlice = series.DataPoints[1];
secondSlice.Format.Fill.FillType = FillType.Solid;
secondSlice.Format.Fill.SolidFillColor.Color = Color.Brown;

secondSlice.Format.Line.FillFormat.FillType = FillType.Solid;
secondSlice.Format.Line.FillFormat.SolidFillColor.Color = Color.Blue;
secondSlice.Format.Line.Width = 3.0;
secondSlice.Format.Line.Style = LineStyle.Single;
secondSlice.Format.Line.DashStyle = LineDashStyle.LargeDashDot;

var thirdSlice = series.DataPoints[2];
thirdSlice.Format.Fill.FillType = FillType.Solid;
thirdSlice.Format.Fill.SolidFillColor.Color = Color.Coral;

thirdSlice.Format.Line.FillFormat.FillType = FillType.Solid;
thirdSlice.Format.Line.FillFormat.SolidFillColor.Color = Color.Red;
thirdSlice.Format.Line.Width = 2.0;
thirdSlice.Format.Line.Style = LineStyle.ThinThin;
thirdSlice.Format.Line.DashStyle = LineDashStyle.LargeDashDotDot;

var firstLabel = series.DataPoints[0].Label;
firstLabel.DataLabelFormat.ShowValue = true;

var secondLabel = series.DataPoints[1].Label;
secondLabel.DataLabelFormat.ShowValue = true;
secondLabel.DataLabelFormat.ShowLegendKey = true;
secondLabel.DataLabelFormat.ShowPercentage = true;

var thirdLabel = series.DataPoints[2].Label;
thirdLabel.DataLabelFormat.ShowSeriesName = true;
thirdLabel.DataLabelFormat.ShowPercentage = true;

series.Labels.DefaultDataLabelFormat.ShowLeaderLines = true;

chart.ChartData.SeriesGroups[0].FirstSliceAngle = 180;

presentation.Save("PieChart.pptx", SaveFormat.Pptx);
```

### Crear gráficos de líneas {#create-line-charts}
  
Los gráficos de líneas (también conocidos como gráficos lineales) son ideales para situaciones en las que se desea mostrar cambios en un valor a lo largo del tiempo. Con un gráfico de líneas, puede comparar una gran cantidad de datos de una sola vez, rastrear cambios y tendencias a lo largo del tiempo, resaltar anomalías en series de datos, entre otras posibilidades.

Este ejemplo utiliza <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addchart/" target="_blank" rel="nofollow noopener noreferrer">AddChart</a> para crear un gráfico de líneas con las series y categorías predeterminadas, y luego guarda la presentación en formato PPTX.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var lineChart = slide.Shapes.AddChart(ChartType.Line, 20, 20, 500, 300);

presentation.Save("lineChart.pptx", SaveFormat.Pptx);
```

De forma predeterminada, los puntos de un gráfico de líneas se unen mediante líneas rectas continuas. Si desea que los puntos se unan mediante guiones en su lugar, establezca <a href="https://reference.aspose.com/slides/net/aspose.slides/ilineformat/dashstyle/" target="_blank" rel="nofollow noopener noreferrer">DashStyle</a> en un valor de <a href="https://reference.aspose.com/slides/net/aspose.slides/linedashstyle/" target="_blank" rel="nofollow noopener noreferrer">LineDashStyle</a>:

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var lineChart = slide.Shapes.AddChart(ChartType.Line, 20, 20, 500, 300);

foreach (var series in lineChart.ChartData.Series)
{
    series.Format.Line.DashStyle = LineDashStyle.Dash;
}
```

### Crear gráficos de mapa de árbol {#create-tree-map-charts}
  
Los gráficos de mapa de árbol son ideales para datos de ventas cuando se desea mostrar el tamaño relativo de las categorías de datos y destacar rápidamente los elementos que representan una contribución significativa dentro de cada categoría.

Este ejemplo crea un mapa de árbol con ocho hojas agrupadas en cuatro tallos y dos ramas. El método <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartcategorylevelsmanager/setgroupingitem/" target="_blank" rel="nofollow noopener noreferrer">SetGroupingItem</a> asigna tallos en el nivel de agrupación 1 y ramas en el nivel 2. Los valores determinan los tamaños relativos de los rectángulos, mientras que las etiquetas de categoría y las etiquetas de padre superpuestas identifican la jerarquía.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Treemap, 20, 20, 500, 300);

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

// Branch 1
var categoryCell = workbook.GetCell(0, "C1", "Leaf1");
var leaf = chart.ChartData.Categories.Add(categoryCell);
leaf.GroupingLevels.SetGroupingItem(1, "Stem1");
leaf.GroupingLevels.SetGroupingItem(2, "Branch1");

categoryCell = workbook.GetCell(0, "C2", "Leaf2");
chart.ChartData.Categories.Add(categoryCell);

categoryCell = workbook.GetCell(0, "C3", "Leaf3");
leaf = chart.ChartData.Categories.Add(categoryCell);
leaf.GroupingLevels.SetGroupingItem(1, "Stem2");

categoryCell = workbook.GetCell(0, "C4", "Leaf4");
chart.ChartData.Categories.Add(categoryCell);

// Branch 2
categoryCell = workbook.GetCell(0, "C5", "Leaf5");
leaf = chart.ChartData.Categories.Add(categoryCell);
leaf.GroupingLevels.SetGroupingItem(1, "Stem3");
leaf.GroupingLevels.SetGroupingItem(2, "Branch2");

categoryCell = workbook.GetCell(0, "C6", "Leaf6");
chart.ChartData.Categories.Add(categoryCell);

categoryCell = workbook.GetCell(0, "C7", "Leaf7");
leaf = chart.ChartData.Categories.Add(categoryCell);
leaf.GroupingLevels.SetGroupingItem(1, "Stem4");

categoryCell = workbook.GetCell(0, "C8", "Leaf8");
chart.ChartData.Categories.Add(categoryCell);

var series = chart.ChartData.Series.Add(ChartType.Treemap);
series.Labels.DefaultDataLabelFormat.ShowCategoryName = true;
var valueCell = workbook.GetCell(0, "D1", 4);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D2", 5);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D3", 3);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D4", 6);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D5", 9);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D6", 9);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D7", 4);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);
valueCell = workbook.GetCell(0, "D8", 3);
series.DataPoints.AddDataPointForTreemapSeries(valueCell);

series.ParentLabelLayout = ParentLabelLayoutType.Overlapping;

presentation.Save("Treemap.pptx", SaveFormat.Pptx);
```

### Crear gráficos de cascada {#create-waterfall-charts}
  
Un gráfico de cascada muestra cómo los cambios positivos y negativos contribuyen a un valor final. Por ejemplo, un desglose de beneficios puede comenzar con los ingresos, restar los costos y sumar otros ingresos. Las columnas intermedias se posicionan entre los valores anteriores y los nuevos valores acumulados, mientras que las columnas totales se extienden desde cero hasta el valor acumulado.

El siguiente ejemplo utiliza cantidades en miles de dólares estadounidenses:

<div className="docs-owner-markdown-table">

| Categoría | Valor del libro de trabajo | Tipo de columna |
| ------------------ | -------------: | ------------------ |
| Ingresos | 1000 | Aumento |
| Costo de ventas | -400 | Disminución |
| Beneficio bruto | 600 | Total intermedio |
| Gastos operativos | -200 | Disminución |
| Otros ingresos | 50 | Aumento |
| Beneficio neto | 450 | Total final |

</div>

Para marcar un punto como total intermedio o final, establezca su propiedad <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/chartdatapoint/setastotal/" target="_blank" rel="nofollow noopener noreferrer">SetAsTotal</a> en `true`. Proporcione el importe acumulado real en la celda del libro de trabajo correspondiente a ese punto: `600` para la ganancia bruta (`1000 - 400`) y `450` para la ganancia neta (`600 - 200 + 50`). Esta propiedad marca la columna como un total, pero no calcula ni rellena el valor de la celda. No utilice cero como marcador de posición ni proporcione otro valor distinto para un punto total. Una columna total muestra el valor acumulado sin volver a sumarlo al valor en curso.

Este ejemplo completo en C# crea un gráfico utilizando el miembro `Waterfall` de <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/charttype/" target="_blank" rel="nofollow noopener noreferrer">ChartType</a>, borra los datos predeterminados y rellena el libro de trabajo incrustado. El índice de hoja de cálculo `0` selecciona la primera hoja de cálculo; la columna A contiene los nombres de las categorías y la columna B contiene los valores. Cada celda de valor se agrega mediante <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdatapointcollection/adddatapointforwaterfallseries/" target="_blank" rel="nofollow noopener noreferrer">AddDataPointForWaterfallSeries</a>. Los índices de punto basados en cero `2` y `5` identifican los totales intermedios y finales. Al habilitar <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/idatalabelformat/showvalue/" target="_blank" rel="nofollow noopener noreferrer">ShowValue</a>, se muestran los importes sobre las columnas. No se requiere ninguna presentación de entrada ni libro de trabajo.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Waterfall, 20, 20, 680, 200);

chart.HasTitle = true;
chart.ChartTitle.AddTextFrameForOverriding("Profit breakdown (USD thousands)");
chart.ChartTitle.Overlay = false;
chart.HasLegend = false;

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
var worksheetIndex = 0;

workbook.Clear(worksheetIndex);

var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 1, "Profit");
var series = chart.ChartData.Series.Add(seriesNameCell, ChartType.Waterfall);
var categories = new[] { "Revenue", "Cost of sales", "Gross profit", "Operating expenses", "Other income", "Net profit" };
var values = new double[] { 1000, -400, 600, -200, 50, 450 };

for (var i = 0; i < categories.Length; i++)
{
    var categoryCell = workbook.GetCell(worksheetIndex, i + 1, 0, categories[i]);
```

### Crear gráficos de histograma {#create-histogram-charts}
  
Los gráficos de histograma muestran cómo se distribuyen los valores numéricos en intervalos (contenedores). Para informes mensuales sobre los tiempos de procesamiento de pedidos, utilice la misma amplitud de contenedor y los mismos umbrales para mantener los intervalos consistentes y facilitar la comparación de las distribuciones.

Establezca el eje horizontal <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/aggregationtype/" target="_blank" rel="nofollow noopener noreferrer">AggregationType</a> en un valor del tipo <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axisaggregationtype/" target="_blank" rel="nofollow noopener noreferrer">AxisAggregationType</a>. <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/binwidth/" target="_blank" rel="nofollow noopener noreferrer">BinWidth</a> solo se aplica a `ByBinWidth`; <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/numberofbins/" target="_blank" rel="nofollow noopener noreferrer">NumberOfBins</a> solo se aplica a `ByNumberOfBins`. Utilice `Automatic` para permitir que el gráfico elija automáticamente los contenedores.

#### Utilizar una amplitud de contenedor fija {#use-a-fixed-bin-width}
  
Este ejemplo agrupa los tiempos de procesamiento en intervalos de 10 minutos, con contenedores separados para tiempos de 10 minutos o menos y para tiempos superiores a 40 minutos. Active estos contenedores mediante <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isunderflowbin/" target="_blank" rel="nofollow noopener noreferrer">IsUnderflowBin</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isoverflowbin/" target="_blank" rel="nofollow noopener noreferrer">IsOverflowBin</a>. Al especificar explícitamente los umbrales <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/underflowbin/" target="_blank" rel="nofollow noopener noreferrer">UnderflowBin</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/overflowbin/" target="_blank" rel="nofollow noopener noreferrer">OverflowBin</a>, establezca <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isautomaticunderflowbin/" target="_blank" rel="nofollow noopener noreferrer">IsAutomaticUnderflowBin</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/axis/isautomaticoverflowbin/" target="_blank" rel="nofollow noopener noreferrer">IsAutomaticOverflowBin</a> en `false`.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.Histogram, 20, 20, 680, 200);

chart.HasLegend = false;
chart.HasTitle = false;

chart.ChartData.Categories.Clear();
chart.ChartData.Series.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;
workbook.Clear(0);

var series = chart.ChartData.Series.Add(ChartType.Histogram);
double[] values = { 5, 10, 10, 11, 15, 20, 20, 21, 25, 30, 30, 31, 35, 40, 40, 41, 50 };
for (var i = 0; i < values.Length; i++)
{
    var valueCell = workbook.GetCell(0, i, 0, values[i]);
    series.DataPoints.AddDataPointForHistogramSeries(valueCell);
}

var axis = chart.Axes.HorizontalAxis;
axis.AggregationType = AxisAggregationType.ByBinWidth;
axis.BinWidth = 10;
axis.IsUnderflowBin = true;
axis.IsAutomaticUnderflowBin = false;
axis.UnderflowBin = 10;
axis.IsOverflowBin = true;
axis.IsAutomaticOverflowBin = false;
axis.OverflowBin = 40;

presentation.Save("Histogram-bin-width.pptx", SaveFormat.Pptx);
```

La presentación mostrada en PowerPoint muestra recuentos de bins de **3, 4, 4, 4 y 2**. El bin de subflujo incluye `5, 10, 10`, por lo que su umbral es inclusivo. El bin de sobreflujo incluye únicamente `41, 50`, por lo que su umbral es exclusivo; ambos valores iguales a `40` permanecen en el intervalo anterior. Los bins interiores contienen valores mayores que su límite inferior y menores o iguales que su límite superior.

### Crear gráficos combinados {#create-combination-charts}
  
Un gráfico combinado (o gráfico de combinación) integra dos o más tipos de gráficos en una sola representación. Este tipo de gráfico permite resaltar, comparar o examinar las diferencias entre dos o más conjuntos de datos, ayudándole a identificar las relaciones entre ellos.

![The combination chart](/net/slides/images/4bde0f54acf47061-combination_chart.png)

Este ejemplo combina dos series de columnas agrupadas con una serie de línea a través de cuatro categorías. Las columnas utilizan el eje vertical principal, mientras que <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/plotonsecondaxis/" target="_blank" rel="nofollow noopener noreferrer">PlotOnSecondAxis</a> coloca la línea en un eje vertical secundario a la derecha. Las funciones auxiliares configuran el título, la leyenda, las etiquetas de los ejes y las líneas de la cuadrícula.

```csharp
using System.Drawing;
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

CreateComboChart();

static void CreateComboChart()
{
    using var presentation = new Presentation();
    var chart = CreateChartWithFirstSeries(presentation.Slides[0]);

    AddSecondSeriesToChart(chart);
    AddThirdSeriesToChart(chart);

    SetPrimaryAxesFormat(chart);
    SetSecondaryAxesFormat(chart);

    presentation.Save("combo-chart.pptx", SaveFormat.Pptx);
}

static IChart CreateChartWithFirstSeries(ISlide slide)
{
    var chart = slide.Shapes.AddChart(ChartType.ClusteredColumn, 50, 50, 600, 400);

    chart.HasTitle = true;
    chart.ChartTitle.AddTextFrameForOverriding("Chart Title");
    chart.ChartTitle.Overlay = false;
    var portionFormat = chart.ChartTitle.TextFrameForOverriding.Paragraphs[0].ParagraphFormat.DefaultPortionFormat;
    portionFormat.FontBold = NullableBool.False;
    portionFormat.FontHeight = 18f;

    chart.Legend.Position = LegendPositionType.Bottom;
    chart.Legend.TextFormat.PortionFormat.FontHeight = 12f;

    chart.ChartData.Series.Clear();
    chart.ChartData.Categories.Clear();

    var workbook = chart.ChartData.ChartDataWorkbook;
    var worksheetIndex = 0;

    var categoryCell = workbook.GetCell(worksheetIndex, 1, 0, "Category 1");
    chart.ChartData.Categories.Add(categoryCell);
    categoryCell = workbook.GetCell(worksheetIndex, 2, 0, "Category 2");
    chart.ChartData.Categories.Add(categoryCell);
    categoryCell = workbook.GetCell(worksheetIndex, 3, 0, "Category 3");
    chart.ChartData.Categories.Add(categoryCell);
    categoryCell = workbook.GetCell(worksheetIndex, 4, 0, "Category 4");
    chart.ChartData.Categories.Add(categoryCell);

    var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 1, "Series 1");
    var series = chart.ChartData.Series.Add(seriesNameCell, chart.Type);

    series.ParentSeriesGroup.Overlap = -25;
    series.ParentSeriesGroup.GapWidth = 220;

    var valueCell = workbook.GetCell(worksheetIndex, 1, 1, 4.3);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 2, 1, 2.5);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 3, 1, 3.5);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 4, 1, 4.5);
    series.DataPoints.AddDataPointForBarSeries(valueCell);

    return chart;
}

static void AddSecondSeriesToChart(IChart chart)
{
    var workbook = chart.ChartData.ChartDataWorkbook;
    const int worksheetIndex = 0;

    var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 2, "Series 2");
    var series = chart.ChartData.Series.Add(seriesNameCell, ChartType.ClusteredColumn);

    series.ParentSeriesGroup.Overlap = -25;
    series.ParentSeriesGroup.GapWidth = 220;

    var valueCell = workbook.GetCell(worksheetIndex, 1, 2, 2.4);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 2, 2, 4.4);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 3, 2, 1.8);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 4, 2, 2.8);
    series.DataPoints.AddDataPointForBarSeries(valueCell);
}

static void AddThirdSeriesToChart(IChart chart)
{
    var workbook = chart.ChartData.ChartDataWorkbook;
    const int worksheetIndex = 0;

    var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 3, "Series 3");
    var series = chart.ChartData.Series.Add(seriesNameCell, ChartType.Line);

    var valueCell = workbook.GetCell(worksheetIndex, 1, 3, 2.0);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 2, 3, 2.0);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 3, 3, 3.0);
    series.DataPoints.AddDataPointForLineSeries(valueCell);
    valueCell = workbook.GetCell(worksheetIndex, 4, 3, 5.0);
    series.DataPoints.AddDataPointForLineSeries(valueCell);

    series.PlotOnSecondAxis = true;
}

static void SetPrimaryAxesFormat(IChart chart)
{
    var horizontalAxis = chart.Axes.HorizontalAxis;
    horizontalAxis.TextFormat.PortionFormat.FontHeight = 12f;
    horizontalAxis.Format.Line.FillFormat.FillType = FillType.NoFill;

    SetAxisTitle(horizontalAxis, "X Axis");

    var verticalAxis = chart.Axes.VerticalAxis;
    verticalAxis.TextFormat.PortionFormat.FontHeight = 12f;
    verticalAxis.Format.Line.FillFormat.FillType = FillType.NoFill;

    SetAxisTitle(verticalAxis, "Y Axis 1");

    var majorGridLinesFormat = verticalAxis.MajorGridLinesFormat.Line.FillFormat;
    majorGridLinesFormat.FillType = FillType.Solid;
    majorGridLinesFormat.SolidFillColor.Color = Color.FromArgb(217, 217, 217);
}

static void SetSecondaryAxesFormat(IChart chart)
{
    var secondaryHorizontalAxis = chart.Axes.SecondaryHorizontalAxis;
    secondaryHorizontalAxis.Position = AxisPositionType.Bottom;
    secondaryHorizontalAxis.CrossType = CrossesType.Maximum;
    secondaryHorizontalAxis.IsVisible = false;
    secondaryHorizontalAxis.MajorGridLinesFormat.Line.FillFormat.FillType = FillType.NoFill;
    secondaryHorizontalAxis.MinorGridLinesFormat.Line.FillFormat.FillType = FillType.NoFill;

    var secondaryVerticalAxis = chart.Axes.SecondaryVerticalAxis;
    secondaryVerticalAxis.Position = AxisPositionType.Right;
    secondaryVerticalAxis.TextFormat.PortionFormat.FontHeight = 12f;
    secondaryVerticalAxis.Format.Line.FillFormat.FillType = FillType.NoFill;
    secondaryVerticalAxis.MajorGridLinesFormat.Line.FillFormat.FillType = FillType.NoFill;
    secondaryVerticalAxis.MinorGridLinesFormat.Line.FillFormat.FillType = FillType.NoFill;

    SetAxisTitle(secondaryVerticalAxis, "Y Axis 2");
}

static void SetAxisTitle(IAxis axis, string axisTitle)
{
    axis.HasTitle = true;
    axis.Title.Overlay = false;
    var titlePortionFormat = axis.Title.AddTextFrameForOverriding(axisTitle).Paragraphs[0].ParagraphFormat.DefaultPortionFormat;
    titlePortionFormat.FontBold = NullableBool.False;
    titlePortionFormat.FontHeight = 12f;
}
```

## Actualizar gráficos  {#update-charts}
  
Aspose.Slides para .NET le permite actualizar gráficos de PowerPoint modificando los datos del gráfico, su formato y su estilo. Esta funcionalidad simplifica el proceso de mantener las presentaciones actualizadas con contenido dinámico y garantiza que los gráficos reflejen con precisión los datos y los estándares visuales actuales.

Este ejemplo actualiza el gráfico denominado "My chart" en la primera diapositiva de una presentación existente. Requiere dos series de columnas con tres puntos de datos cada una, con etiquetas de categoría en la columna A y nombres de series en la primera fila de la primera hoja de cálculo. El ejemplo utiliza <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/getcell/" target="_blank" rel="nofollow noopener noreferrer">GetCell</a> para modificar celdas del libro de trabajo, actualiza los valores de las series, agrega una tercera serie y cambia el gráfico a cilindros agrupados mediante <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichart/type/" target="_blank" rel="nofollow noopener noreferrer">Type</a>.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const string chartName = "My chart";

using var presentation = new Presentation("ExistingChart.pptx");
var slide = presentation.Slides[0];

foreach (IShape shape in slide.Shapes)
{
    if (shape is IChart chart && chart.Name == chartName)
    {
        var worksheetIndex = 0;

        var workbook = chart.ChartData.ChartDataWorkbook;

        workbook.GetCell(worksheetIndex, 1, 0, "Modified Category 1");
        workbook.GetCell(worksheetIndex, 2, 0, "Modified Category 2");

        var series = chart.ChartData.Series[0];

        workbook.GetCell(worksheetIndex, 0, 1, "New_Series 1");
        series.DataPoints[0].Value.Data = 90;
        series.DataPoints[1].Value.Data = 123;
        series.DataPoints[2].Value.Data = 44;

        series = chart.ChartData.Series[1];

        workbook.GetCell(worksheetIndex, 0, 2, "New_Series 2");
        series.DataPoints[0].Value.Data = 23;
        series.DataPoints[1].Value.Data = 67;
        series.DataPoints[2].Value.Data = 99;

        var seriesNameCell = workbook.GetCell(worksheetIndex, 0, 3, "Series 3");
        series = chart.ChartData.Series.Add(seriesNameCell, chart.Type);

        var valueCell = workbook.GetCell(worksheetIndex, 1, 3, 20);
        series.DataPoints.AddDataPointForBarSeries(valueCell);
        valueCell = workbook.GetCell(worksheetIndex, 2, 3, 50);
        series.DataPoints.AddDataPointForBarSeries(valueCell);
        valueCell = workbook.GetCell(worksheetIndex, 3, 3, 30);
        series.DataPoints.AddDataPointForBarSeries(valueCell);

        chart.Type = ChartType.ClusteredCylinder;
    }
}

presentation.Save("AsposeChartModified.pptx", SaveFormat.Pptx);
```

## Establecer rango de datos para un gráfico {#set-data-range-for-a-chart}
  
Para inspeccionar el rango ya utilizado por un gráfico existente, consulte [Recuperar el rango de datos de un gráfico](/net/slides/chart-workbook/#retrieve-a-charts-data-range).

Aspose.Slides para .NET ofrece la flexibilidad para definir un rango de datos específico de una hoja de cálculo como fuente de los datos de su gráfico. Esto significa que puede asignar directamente una porción de su hoja de cálculo al gráfico, lo que le permite controlar qué celdas contribuyen a las series y categorías del gráfico. Como resultado, puede actualizar y sincronizar fácilmente sus gráficos con los cambios más recientes en los datos de su hoja de cálculo, garantizando que sus presentaciones de PowerPoint reflejen información actualizada y precisa.

Este ejemplo utiliza <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdata/setrange/" target="_blank" rel="nofollow noopener noreferrer">SetRange</a> para establecer la fuente de datos del gráfico denominado "My chart" en la primera diapositiva de una presentación existente en `Sheet1!A1:B4`. El libro del gráfico debe contener esa hoja de cálculo y un rango poblado con una cabecera de serie en la primera fila, etiquetas de categoría en la columna A y tres valores en la columna B.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

const string chartName = "My chart";

using var presentation = new Presentation("ExistingChart.pptx");
var slide = presentation.Slides[0];

foreach (IShape shape in slide.Shapes)
{
    if (shape is IChart chart && chart.Name == chartName)
    {
        chart.ChartData.SetRange("Sheet1!A1:B4");
    }
}

presentation.Save("SetDataRange.pptx", SaveFormat.Pptx);
```

## Usar marcadores predeterminados en gráficos  {#use-default-markers-in-charts}
  
Cuando utiliza marcadores predeterminados en gráficos, cada serie del gráfico recibe automáticamente un símbolo de marcador diferente.

Este ejemplo utiliza <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addchart/" target="_blank" rel="nofollow noopener noreferrer">AddChart</a> para crear un gráfico con dos series de líneas y una leyenda. La configuración de <a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartseries/marker/" target="_blank" rel="nofollow noopener noreferrer">Marker</a> conserva los símbolos de marcador asignados automáticamente. La primera serie incluye un valor negativo y un valor ausente, representado por `null`, mientras que la segunda tiene un valor para cada categoría.

```csharp
using Aspose.Slides;
using Aspose.Slides.Charts;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];

var chart = slide.Shapes.AddChart(ChartType.LineWithMarkers, 10, 10, 400, 400);

chart.ChartData.Series.Clear();
chart.ChartData.Categories.Clear();

var workbook = chart.ChartData.ChartDataWorkbook;

var seriesNameCell = workbook.GetCell(0, 0, 1, "Series 1");
var series = chart.ChartData.Series.Add(seriesNameCell, chart.Type);

var categoryCell = workbook.GetCell(0, 1, 0, "C1");
chart.ChartData.Categories.Add(categoryCell);
var valueCell = workbook.GetCell(0, 1, 1, 24);
series.DataPoints.AddDataPointForLineSeries(valueCell);

categoryCell = workbook.GetCell(0, 2, 0, "C2");
chart.ChartData.Categories.Add(categoryCell);
valueCell = workbook.GetCell(0, 2, 1, 23);
series.DataPoints.AddDataPointForLineSeries(valueCell);

categoryCell = workbook.GetCell(0, 3, 0, "C3");
chart.ChartData.Categories.Add(categoryCell);
valueCell = workbook.GetCell(0, 3, 1, -10);
series.DataPoints.AddDataPointForLineSeries(valueCell);

categoryCell = workbook.GetCell(0, 4, 0, "C4");
chart.ChartData.Categories.Add(categoryCell);
valueCell = workbook.GetCell(0, 4, 1, null);
series.DataPoints.AddDataPointForLineSeries(valueCell);

seriesNameCell = workbook.GetCell(0, 0, 2, "Series 2");
var secondSeries = chart.ChartData.Series.Add(seriesNameCell, chart.Type);

valueCell = workbook.GetCell(0, 1, 2, 30);
secondSeries.DataPoints.AddDataPointForLineSeries(valueCell);
valueCell = workbook.GetCell(0, 2, 2, 10);
secondSeries.DataPoints.AddDataPointForLineSeries(valueCell);
valueCell = workbook.GetCell(0, 3, 2, 60);
secondSeries.DataPoints.AddDataPointForLineSeries(valueCell);
valueCell = workbook.GetCell(0, 4, 2, 40);
secondSeries.DataPoints.AddDataPointForLineSeries(valueCell);

chart.HasLegend = true;
chart.Legend.Overlay = false;

presentation.Save("DefaultMarkersInChart.pptx", SaveFormat.Pptx);
```

## Preguntas frecuentes {#faq}
  
**¿Qué tipos de gráficos admite Aspose.Slides para .NET?**  

Aspose.Slides para .NET admite una amplia gama de tipos de gráficos, incluidos barras, líneas, torta, áreas, dispersión, histograma, radar y muchos más. Esta flexibilidad le permite elegir el tipo de gráfico más adecuado para sus necesidades de visualización de datos.  

**¿Cómo agrego un nuevo gráfico a una diapositiva?**  

Para agregar un gráfico, primero crea una instancia de la clase <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>, recupera la diapositiva deseada mediante su índice y luego llama al método para agregar un gráfico, especificando el tipo de gráfico y los datos iniciales. Este proceso integra el gráfico directamente en su presentación.  

**¿Cómo puedo actualizar los datos mostrados en un gráfico?**  

Puede actualizar los datos de un gráfico accediendo a su libro de datos (<a href="https://reference.aspose.com/slides/net/aspose.slides.charts/ichartdataworkbook/" target="_blank" rel="nofollow noopener noreferrer">IChartDataWorkbook</a>), borrando las series y categorías predeterminadas, y luego agregando sus datos personalizados. Esto le permite actualizar programáticamente el gráfico para reflejar los datos más recientes.  

**¿Es posible personalizar la apariencia del gráfico?**  

Sí, Aspose.Slides para .NET proporciona opciones extensas de personalización. Puede modificar colores, fuentes, etiquetas, leyendas y otros elementos de formato para adaptar la apariencia del gráfico a sus requisitos específicos de diseño.

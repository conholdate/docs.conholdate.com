> Consulte qué formatos de archivo puede cargar, importar, guardar y representar Aspose.Slides para .NET, y qué API lee o escribe cada uno.

## Información general {#overview}
  
Aspose.Slides para .NET abre y guarda presentaciones de PowerPoint y OpenDocument. También importa contenido de PDF y HTML a diapositivas, guarda presentaciones en formatos de documento, web e imagen, y representa diapositivas y formas individuales como imágenes. Este artículo enumera cada formato admitido e indica la API que lo lee o escribe.

Ambos paquetes de NuGet, Aspose.Slides.NET y Aspose.Slides.NET6.CrossPlatform, admiten los mismos formatos; consulte [Instalación](/net/slides/installation/) para elegir entre ellos. Para una descripción general de las funciones de edición, consulte [Descripción general de características](/net/slides/features-overview/).

## Versiones de Microsoft PowerPoint admitidas {#supported-microsoft-powerpoint-versions}  

- Microsoft PowerPoint 97
- Microsoft PowerPoint 2000
- Microsoft PowerPoint XP
- Microsoft PowerPoint 2003
- Microsoft PowerPoint 2007
- Microsoft PowerPoint 2010
- Microsoft PowerPoint 2013
- Microsoft PowerPoint 2016
- Microsoft PowerPoint 2019
- Microsoft PowerPoint para Mac
- PowerPoint para Microsoft 365 (anteriormente Office 365)

:::info[Nota]  
Las presentaciones guardadas por PowerPoint 95 y versiones anteriores no pueden abrirse. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a> reconoce un archivo de PowerPoint 95 y lo reporta como `LoadFormat.Ppt95`, pero el constructor <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> lanza <a href="https://reference.aspose.com/slides/net/aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> para este archivo.
:::

## Formatos de archivo compatibles {#supported-file-formats}
  
La tabla utiliza cuatro operaciones:  

- **Carga**: el constructor <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> abre el archivo como una presentación editable.
- **Importación**: un método de <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection</a> crea diapositivas a partir del contenido del archivo y las agrega a una presentación existente. El constructor Presentation no carga estos archivos como presentaciones.
- **Guardado**: <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> escribe la presentación en un archivo o flujo. Cada formato, excepto XAML, se selecciona mediante un valor de <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a>.
- **Renderizado**: un método de renderizado dibuja una diapositiva o una forma como una imagen. Los formatos que solo admiten renderizado no son valores de SaveFormat.

## Cargar e importar {#load-and-import}  

- **Cargar:** Pase una ruta de archivo o un flujo al constructor de <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>. El formato se detecta a partir del contenido; <a href="https://reference.aspose.com/slides/net/aspose.slides/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> proporciona configuraciones como una contraseña. Para comprobar un archivo antes de abrirlo, invoque <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a>, que devuelve un valor de tipo <a href="https://reference.aspose.com/slides/net/aspose.slides/loadformat/" target="_blank" rel="nofollow noopener noreferrer">LoadFormat</a>. Este método informa `LoadFormat.Unknown` para XML de PowerPoint, pero el constructor sí abre ese tipo de archivo, y <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/sourceformat/" target="_blank" rel="nofollow noopener noreferrer">Presentation.SourceFormat</a> devuelve `SourceFormat.Xml`. Consulte [Abrir presentaciones](/net/slides/open-presentation/) y [Determinar el formato original de la presentación](/net/slides/detect-presentation-source-format/).  

- **Importar:** <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfrompdf/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.AddFromPdf</a> agrega una diapositiva por página PDF al final de la presentación. <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/addfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.AddFromHtml</a> agrega diapositivas creadas a partir de HTML, y <a href="https://reference.aspose.com/slides/net/aspose.slides/slidecollection/insertfromhtml/" target="_blank" rel="nofollow noopener noreferrer">SlideCollection.InsertFromHtml</a> las inserta en una posición determinada. El constructor de Presentation no importa: lanza <a href="https://reference.aspose.com/slides/net/aspose.slides/pptunsupportedformatexception/" target="_blank" rel="nofollow noopener noreferrer">PptUnsupportedFormatException</a> para un archivo PDF y no convierte el marcado HTML en contenido de diapositivas. Consulte [Importar presentaciones desde PDF o HTML](/net/slides/import-presentation/).  

## Guardar y representar {#save-and-render}  

- **Guardar:** <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Presentation.Save</a> escribe la presentación en el formato indicado por un valor de tipo <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a>. Las sobrecargas que también aceptan un objeto de opciones controlan la salida, por ejemplo <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/htmloptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlOptions</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/html5options/" target="_blank" rel="nofollow noopener noreferrer">Html5Options</a>, <a href="https://reference.aspose.com/slides/net/aspose.slides.export/tiffoptions/" target="_blank" rel="nofollow noopener noreferrer">TiffOptions</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides.export/gifoptions/" target="_blank" rel="nofollow noopener noreferrer">GifOptions</a>. Las sobrecargas que aceptan un array de posiciones de diapositivas (empezando desde 1) escriben únicamente esas diapositivas; aceptan PDF, XPS, TIFF, HTML, HTML5, SWF, GIF y Markdown, pero no los formatos de presentación ni XML de PowerPoint. XAML tiene su propia sobrecarga que acepta <a href="https://reference.aspose.com/slides/net/aspose.slides.export.xaml/ixamloptions/" target="_blank" rel="nofollow noopener noreferrer">IXamlOptions</a>. Consulte [Guardar presentaciones](/net/slides/save-presentation/), [Convertir presentaciones](/net/slides/convert-presentation/) y [Exportar presentaciones a XAML](/net/slides/export-to-xaml/).  

- **Representar:** <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/getimage/" target="_blank" rel="nofollow noopener noreferrer">Slide.GetImage</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/getimage/" target="_blank" rel="nofollow noopener noreferrer">Shape.GetImage</a> devuelven un <a href="https://reference.aspose.com/slides/net/aspose.slides/iimage/" target="_blank" rel="nofollow noopener noreferrer">IImage</a>, y <a href="https://reference.aspose.com/slides/net/aspose.slides/iimage/save/" target="_blank" rel="nofollow noopener noreferrer">IImage.Save</a> lo escribe como PNG, JPEG, BMP, GIF o TIFF, según el valor de <a href="https://reference.aspose.com/slides/net/aspose.slides/imageformat/" target="_blank" rel="nofollow noopener noreferrer">ImageFormat</a> especificado. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/getimages/" target="_blank" rel="nofollow noopener noreferrer">Presentation.GetImages</a> representa todas las diapositivas o las seleccionadas de una sola vez. <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/writeassvg/" target="_blank" rel="nofollow noopener noreferrer">Slide.WriteAsSvg</a> y <a href="https://reference.aspose.com/slides/net/aspose.slides/shape/writeassvg/" target="_blank" rel="nofollow noopener noreferrer">Shape.WriteAsSvg</a> escriben SVG, y <a href="https://reference.aspose.com/slides/net/aspose.slides/slide/writeasemf/" target="_blank" rel="nofollow noopener noreferrer">Slide.WriteAsEmf</a> escribe EMF. Consulte [Convertir diapositivas de presentaciones en imágenes](/net/slides/convert-slide/) y [Representar una diapositiva como una imagen SVG](/net/slides/render-a-slide-as-an-svg-image/).  

:::warning[Advertencia]  
ImageFormat también tiene los valores `Emf`, `Wmf`, `Icon`, `Exif` y `MemoryBmp`, pero IImage.Save no genera esos formatos: el archivo que escribe contiene datos PNG. Para obtener una imagen EMF de una diapositiva, utilice Slide.WriteAsEmf.
:::

## Preguntas frecuentes {#faq}
  
**¿Puedo convertir una presentación PPT a PPTX u ODP?**  

Sí. Abra el archivo PPT con el constructor de Presentación y guárdelo con `SaveFormat.Pptx` o `SaveFormat.Odp`. Consulte [Convertir PPT a PPTX](/net/slides/convert-ppt-to-pptx/).  

**¿Puedo abrir un archivo PDF o HTML como una presentación?**  

No. Cree o abra una presentación, importe las páginas PDF o el contenido HTML en ella mediante los métodos de colección de diapositivas descritos anteriormente y, a continuación, guárdela en cualquier formato admitido.  

**¿Puedo cargar una imagen exportada PNG o SVG como una presentación editable?**  

No. La salida de imagen solo registra cómo se ve una diapositiva, no su texto, formas ni gráficos. Mantenga la presentación original si necesita editarla más adelante.  

**¿Puedo guardar documentos PDF/A o PDF/UA?**  

Sí. Establezca <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfoptions/compliance/" target="_blank" rel="nofollow noopener noreferrer">PdfOptions.Compliance</a> en un valor de <a href="https://reference.aspose.com/slides/net/aspose.slides.export/pdfcompliance/" target="_blank" rel="nofollow noopener noreferrer">PdfCompliance</a>: PDF/A-1a, PDF/A-1b, PDF/A-2a, PDF/A-2b, PDF/A-2u, PDF/A-3a, PDF/A-3b o PDF/UA.  

**¿Puedo comprobar si un archivo está protegido con contraseña antes de abrirlo?**  

Sí. <a href="https://reference.aspose.com/slides/net/aspose.slides/presentationfactory/getpresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.GetPresentationInfo</a> inspecciona un archivo sin crear un objeto Presentation, y su propiedad <a href="https://reference.aspose.com/slides/net/aspose.slides/ipresentationinfo/ispasswordprotected/" target="_blank" rel="nofollow noopener noreferrer">IsPasswordProtected</a> indica si se requiere contraseña. Consulte [Proteger presentaciones con contraseña](/net/slides/password-protected-presentation/).  

**¿Los dos paquetes NuGet admiten formatos distintos?**  

No. Aspose.Slides.NET y Aspose.Slides.NET6.CrossPlatform tienen los mismos valores de LoadFormat y SaveFormat, así como los mismos métodos de importación y renderizado. Difieren en las plataformas en las que se ejecutan y en lo que dichas plataformas requieren; consulte [Instalación](/net/slides/installation/).

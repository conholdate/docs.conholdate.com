> Cree presentaciones en .NET con Aspose.Slides: genere archivos PPT, PPTX y ODP, aproveche el soporte para OpenDocument y guárdelos programáticamente para obtener resultados confiables.

## Información general {#overview}
  
Este artículo muestra cómo crear una presentación en Aspose.Slides, agregar un cuadro de texto a su primera diapositiva y guardar el resultado como archivo. También muestra cómo crear y guardar una presentación vacía, y cómo abrir una presentación existente en un formato admitido y guardarla en otro formato. Al final se incluye una breve sección de preguntas frecuentes (FAQ) que aborda dudas comunes sobre formatos, plantillas, dimensionado de diapositivas, unidades, uso de memoria, subprocesamiento, licencias, firmas digitales y compatibilidad con VBA.

Antes de comenzar, agregue Aspose.Slides a su proyecto desde NuGet. Consulte [Instalación](/net/slides/installation/) para conocer el paquete que debe utilizarse en Windows, Linux y macOS.

## Crear una presentación de PowerPoint {#create-a-powerpoint-presentation}
  
Para crear una presentación y colocar un cuadro de texto en su primera diapositiva, siga estos pasos:  

1. Cree una instancia de la clase <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>. Una presentación nueva ya contiene una diapositiva vacía. 
2. Obtenga esa diapositiva de la colección <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/slides/" target="_blank" rel="nofollow noopener noreferrer">Slides</a> mediante su índice, 0. 
3. Agregue un rectángulo con el método <a href="https://reference.aspose.com/slides/net/aspose.slides/ishapecollection/addautoshape/" target="_blank" rel="nofollow noopener noreferrer">AddAutoShape</a> y configure su <a href="https://reference.aspose.com/slides/net/aspose.slides/itextframe/text/" target="_blank" rel="nofollow noopener noreferrer">text</a>. 
4. Guarde la presentación como archivo PPTX con el método <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/save/" target="_blank" rel="nofollow noopener noreferrer">Save</a>.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
var slide = presentation.Slides[0];
var shape = slide.Shapes.AddAutoShape(ShapeType.Rectangle, 50, 50, 400, 100);
shape.TextFrame.Text = "Hello, Aspose.Slides!";
presentation.Save("hello.pptx", SaveFormat.Pptx);
```

La esquina superior izquierda del rectángulo está ubicada a 50 puntos del borde izquierdo y a 50 puntos del borde superior de la diapositiva, y el rectángulo tiene un ancho de 400 puntos y una altura de 100 puntos. El archivo guardado contiene una diapositiva con ese rectángulo y su texto. Sin una licencia, Aspose.Slides también agrega una marca de agua de evaluación a cada diapositiva que guarda; consulte [Licensing](/net/slides/licensing/).

## Crear y guardar una presentación {#create-and-save-a-presentation}

<a name="csharp-create-save-presentation"></a>

Para crear una presentación vacía y guardarla, cree una instancia de la clase <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> y guárdela en cualquier formato de la enumeración <a href="https://reference.aspose.com/slides/net/aspose.slides.export/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a>. El resultado es una presentación con una diapositiva vacía.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation();
presentation.Save("OutputPresentation.pptx", SaveFormat.Pptx);
```

## Abrir y guardar una presentación {#open-and-save-a-presentation}
  
<a name="csharp-open-save-presentation"></a>  

Para convertir una presentación de un formato a otro, ábrala pasando su ruta al constructor de <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> y, a continuación, guárdala en el formato de destino. Aspose.Slides detecta el formato de entrada, como PPT, PPTX u ODP, a partir del propio archivo.  

El ejemplo siguiente espera una presentación OpenDocument denominada *Sample.odp* en el directorio de trabajo y la guarda como PPTX.

```csharp
using Aspose.Slides;
using Aspose.Slides.Export;

using var presentation = new Presentation("Sample.odp");
presentation.Save("OutputPresentation.pptx", SaveFormat.Pptx);
```

## FAQ {#faq}
  
### ¿En qué formatos puedo guardar una nueva presentación? {#what-formats-can-i-save-a-new-presentation-to}
  
Puede guardar en [PPTX, PPT y ODP](/net/slides/save-presentation/), y exportar a [PDF](/net/slides/convert-powerpoint-to-pdf/), [XPS](/net/slides/convert-powerpoint-to-xps/), [HTML](/net/slides/convert-powerpoint-to-html/), [SVG](/net/slides/render-a-slide-as-an-svg-image/) y [imágenes](/net/slides/convert-powerpoint-to-png/), entre otros.

### ¿Puedo partir de una plantilla (POTX/POTM) y guardarla como un PPTX normal? {#can-i-start-from-a-template-potx-potm-and-save-as-a-regular-pptx}
  
Sí. Cargue la plantilla y guárdela en el formato deseado; los formatos POTX/POTM/PPTM y similares [están soportados](/net/slides/supported-file-formats/).

### ¿Cómo controlo el tamaño/relación de aspecto de las diapositivas al crear una presentación? {#how-do-i-control-slide-size-aspect-ratio-when-creating-a-presentation}
  
Configure el [tamaño de diapositiva](/net/slides/slide-size/) (incluyendo preajustes como 4:3 y 16:9, o dimensiones personalizadas) y elija cómo debe escalarse el contenido.

### ¿En qué unidades se miden los tamaños y las coordenadas? {#in-what-units-are-sizes-and-coordinates-measured}
  
En puntos: 1 pulgada equivale a 72 unidades.

### ¿Cómo manejo presentaciones muy grandes (con muchos archivos multimedia) para reducir el uso de memoria? {#how-do-i-handle-very-large-presentations-with-many-media-files-to-reduce-memory-usage}
  
Utilice [estrategias de gestión de BLOB](/net/slides/manage-blob/), limite el almacenamiento en memoria aprovechando archivos temporales, y prefiera flujos de trabajo basados en archivos frente a flujos puramente en memoria.

### ¿Puedo crear/guardar presentaciones en paralelo? {#can-i-create-save-presentations-in-parallel}
  
No puede operar sobre la misma instancia de <a href="https://reference.aspose.com/slides/net/aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> desde [varios subprocesos](/net/slides/multithreading/). Ejecute instancias separadas e aisladas por subproceso o proceso.

### ¿Cómo elimino el agua de marca de prueba y las limitaciones? {#how-do-i-remove-the-trial-watermark-and-limitations}
  
[Aplicar una licencia](/net/slides/licensing/) una vez por proceso. El XML de la licencia debe permanecer sin modificar, y la configuración de la licencia debe sincronizarse si intervienen varios subprocesos.

### ¿Puedo firmar digitalmente el PPTX que creo? {#can-i-digitally-sign-the-pptx-i-create}
  
Sí. Las [firmas digitales](/net/slides/digital-signature-in-powerpoint/) (añadir y verificar) están soportadas para presentaciones.

### ¿Se admiten macros (VBA) en las presentaciones creadas? {#are-macros-vba-supported-in-created-presentations}
  
Sí. Puede [crear/editar proyectos VBA](/net/slides/presentation-via-vba/) y guardar archivos con macros, como PPTM/PPSM.

En Aspose.Email para .NET, un conjunto diverso de clases y métodos se organizan en espacios de nombres, cada uno con propósitos específicos relacionados con el procesamiento de correos electrónicos. Desde el manejo de protocolos de correo como SMTP, POP3 e IMAP hasta la gestión de tareas como la integración con calendarios y la programación de tareas, cada espacio de nombres está diseñado para abordar casos de uso concretos. Este enfoque estructurado no solo simplifica la programación, sino que también garantiza que los desarrolladores puedan implementar soluciones de correo electrónico con facilidad.

A continuación, exploraremos los distintos espacios de nombres proporcionados por Aspose.Email para .NET, analizando sus funciones principales y haciendo referencia a las clases más importantes.

## Aspose.Email {#asposeemail}

**Contiene clases comunes para manejar diversos aspectos de los mensajes de correo electrónico**

El componente central de este espacio de nombres es la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>, una entidad versátil y potente que facilita la creación, manipulación y procesamiento de mensajes de correo electrónico. La clase MailMessage admite una amplia gama de funcionalidades, como la redacción de correos electrónicos con formato de texto enriquecido, la inserción de imágenes, el adjuntado de archivos y la especificación de múltiples destinatarios con distintos roles (para, cc, cco). Además, ofrece potentes funcionalidades para analizar y leer mensajes entrantes, permitiendo a los desarrolladores extraer de forma sencilla detalles como el asunto, el remitente, los destinatarios y el contenido del cuerpo del mensaje. Asimismo, MailMessage se integra perfectamente con diversos protocolos de correo electrónico, como SMTP, IMAP y POP3, lo que garantiza que el envío y la recepción de correos electrónicos sean sencillos y fiables.

## Aspose.Email.Amp {#asposeemailamp}

**Proporciona clases para manejar mensajes con cuerpo en AMP HTML**

<a href="https://reference.aspose.com/email/net/aspose.email.amp/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Amp</a> ofrece un conjunto robusto de clases dedicadas al manejo de mensajes que incluyen cuerpos en AMP HTML, convirtiéndose así en una herramienta valiosa para los desarrolladores que desean incorporar contenido dinámico e interactivo en los correos electrónicos. El núcleo de esta capacidad es la clase <a href="https://reference.aspose.com/email/net/aspose.email.amp/ampmessage/#ampmessage-class" target="_blank" rel="nofollow noopener noreferrer">AmpMessage</a>, que actúa como componente principal para construir, manipular y renderizar mensajes de correo electrónico con contenido AMP. Esta clase permite integrar de forma sencilla elementos multimedia enriquecidos y componentes interactivos directamente en el cuerpo del correo electrónico, aprovechando la velocidad y las características atractivas de AMP HTML.

Con AmpMessage, puede agregar elementos como carruseles de imágenes, obtención de datos en tiempo real y formularios interactivos, todos diseñados para funcionar eficientemente dentro de un cliente de correo electrónico.

## Aspose.Email.AntiSpam {#asposeemailantispam}

**Ofrece clases para implementar filtros de autoaprendizaje con el fin de detectar correos electrónicos no deseados (spam)**

<a href="https://reference.aspose.com/email/net/aspose.email.antispam/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.AntiSpam</a> proporciona una solución para el filtrado de correo electrónico mediante su clase principal, <a href="https://reference.aspose.com/email/net/aspose.email.antispam/spamanalyzer/" target="_blank" rel="nofollow noopener noreferrer">SpamAnalyzer</a>, diseñada para detectar correos electrónicos no deseados utilizando un filtro bayesiano de autoaprendizaje. Esta clase permite a las aplicaciones analizar y clasificar los mensajes entrantes como spam o no spam, basándose en estadísticas bayesianas. SpamAnalyzer puede aprender a partir de la entrada del usuario, mejorando así su precisión con el tiempo al ajustar su modelo interno según los mensajes clasificados previamente.

<a href="https://reference.aspose.com/email/net/aspose.email.storage.zimbra/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Storage.Zimbra</a> es un espacio de nombres dentro de la biblioteca Aspose.Email que incluye la clase <a href="https://reference.aspose.com/email/net/aspose.email.storage.zimbra/tgzreader/#tgzreader-class" target="_blank" rel="nofollow noopener noreferrer">TgzReader</a>, diseñada para acceder y gestionar archivos comprimidos TGZ (Tar GZip) de Zimbra. La clase TgzReader ofrece capacidades para trabajar con archivos archivados de correo electrónico, incluida la capacidad de analizar y extraer correos electrónicos, contactos y elementos del calendario desde archivos TGZ; en concreto, permite leer archivos TGZ, recorrer su contenido y acceder programáticamente a elementos individuales para su procesamiento personalizado.

## Aspose.Email.Tools.Search {#asposeemailtoolssearch}
  
**Contiene clases base para la búsqueda de mensajes por criterios**

El espacio de nombres <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Tools.Search</a> está diseñado para simplificar el proceso de localización de mensajes de correo electrónico según una amplia gama de criterios. La pieza fundamental de este espacio de nombres es la clase <a href="https://reference.aspose.com/email/net/aspose.email.tools.search/mailquery/" target="_blank" rel="nofollow noopener noreferrer">MailQuery</a>, que actúa como componente principal para definir parámetros de búsqueda y ejecutar consultas contra almacenes de correo electrónico. Con MailQuery, se pueden especificar diversas condiciones de búsqueda, como remitente, destinatario, palabras clave en el asunto, rangos de fechas e incluso términos específicos del contenido. Esta capacidad permite filtrar y recuperar mensajes relevantes de archivos extensos o buzones actuales. MailQuery admite la construcción de consultas complejas mediante operadores lógicos.

## Aspose.Email.Windows.Forms {#asposeemailwindowsforms}
  
**Contiene clases para manejar archivos arrastrados desde Outlook en aplicaciones Windows Forms**

<a href="https://reference.aspose.com/email/net/aspose.email.windows.forms/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Windows.Forms</a> es un espacio de nombres especializado diseñado para facilitar la integración de funcionalidades relacionadas con correo electrónico en aplicaciones Windows Forms, centrándose especialmente en el manejo de archivos arrastrados desde Microsoft Outlook. La clase principal de este espacio de nombres, <a href="https://reference.aspose.com/email/net/aspose.email.windows.forms/filedroptargetmanager/" target="_blank" rel="nofollow noopener noreferrer">FileDropTargetManager</a>, proporciona a los desarrolladores capacidades para gestionar y procesar operaciones de arrastrar y soltar que involucran elementos de Outlook. FileDropTargetManager permite a las aplicaciones capturar, manejar y procesar mensajes de correo electrónico, adjuntos y otros elementos de Outlook cuando se arrastran hacia una aplicación Windows Forms. Con esta clase, se pueden implementar funciones como extraer y mostrar el contenido de los elementos arrastrados, guardar adjuntos en ubicaciones específicas o activar acciones personalizadas según el tipo de elemento soltado.

## Aspose.Email.Windows.WPF {#asposeemailwindowswpf}
  
**Contiene clases para manejar archivos arrastrados desde Outlook en aplicaciones Windows Presentation Foundation (WPF)**

El espacio de nombres <a href="https://reference.aspose.com/email/net/aspose.email.windows.wpf/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email.Windows.WPF</a> está diseñado para permitir la integración de funcionalidades relacionadas con correo electrónico en aplicaciones WPF, centrándose especialmente en el manejo de archivos arrastrados desde Microsoft Outlook. La pieza fundamental de este espacio de nombres es la clase <a href="https://reference.aspose.com/email/net/aspose.email.windows.wpf/filedroppanel/" target="_blank" rel="nofollow noopener noreferrer">FileDropPanel</a>, que permite a los desarrolladores implementar operaciones de arrastrar y soltar. FileDropPanel actúa como un panel especializado que captura elementos arrastrados desde Outlook, incluidos correos electrónicos, adjuntos y otros elementos relacionados. Detecta automáticamente cuando se sueltan elementos sobre el panel y proporciona eventos y métodos para procesar dichos elementos en consecuencia. Al utilizar FileDropPanel, los desarrolladores pueden extraer el contenido de los correos electrónicos, guardar adjuntos en ubicaciones especificadas o ejecutar lógica empresarial personalizada según el tipo de elemento recibido.

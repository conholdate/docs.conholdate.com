Aspose.Email para .NET proporciona un conjunto integral de funcionalidades diseñadas específicamente para el manejo eficiente de mensajes de correo electrónico y datos asociados. Un aspecto fundamental de la biblioteca radica en su sólido soporte para una amplia variedad de formatos de archivo, lo que permite a los usuarios procesar sin problemas datos relacionados con el correo electrónico dentro de sus aplicaciones. A continuación se presenta una descripción general de todos los formatos de archivo admitidos:

### Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
La versión de evaluación de Aspose.Email (sin una licencia especificada) proporciona toda la funcionalidad del producto, excepto por algunas limitaciones propias de la evaluación.  


1. El archivo License.txt se agrega al archivo de mensaje guardado mediante Aspose.Email
2. Solo se pueden extraer 50 correos electrónicos de una carpeta en un archivo PST
3. Solo se pueden extraer 3 archivos adjuntos, así como imágenes incrustadas, desde un archivo MSG
4. El número máximo de archivos adjuntos procesados en formato CFB es 1
5. El número máximo de destinatarios procesados en formato CFB es 1
6. Agrega "Evaluation Message" (Mensaje de evaluación) en el asunto al guardar en formatos CFB, EML o MSG
7. La fecha final no puede ser posterior al 31-12-2004 en el método GenerateOccurrences del patrón de recurrencia. Esto le permite probar el producto de forma significativa, aunque lo hace imposible de usar en una aplicación de producción. Por ejemplo, puede crear un patrón como "iniciar el 1 de enero de 2000 y repetirse cada último día laborable del mes" y generar sus ocurrencias. Las ocurrencias posteriores al 31 de diciembre de 2004 no se generarán en modo de evaluación
8. Agrega una "imagen de marca de agua de evaluación" al guardar en formatos XPS o TIFF.
9. El número máximo de direcciones de correo electrónico y nombres para mostrar ambiguos resueltos por el servidor MS Exchange Server es 20
10. La longitud máxima de datos permitida para arrastrar y soltar con FileDropPanel es 51200 bytes
11. Muestra un cuadro de mensaje con "Evaluation Message" (Mensaje de evaluación) durante una operación de arrastrar y soltar utilizada por FileDropPanel
12. Solo se extrae 1 archivo del flujo MSO dado mediante el método InlineAttachmentExtractor.EnumerateMsoPackage  

## Aplicación de una licencia {#applying-a-license}
  
Puede descargar fácilmente una versión de evaluación de Aspose.Email desde su <a href="https://www.nuget.org/packages/Aspose.Email/" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia de Aspose.Email. Además, la versión de evaluación simplemente se convierte en una versión con licencia cuando adquiere una licencia y agrega unas pocas líneas de código para aplicarla.  

### Sobre la licencia {#about-the-license}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo. Incluso la adición accidental de un salto de línea adicional invalidará el archivo.  

Debe establecer una licencia antes de utilizar Aspose.Email si desea evitar sus limitaciones de evaluación. Solo es necesario establecer una licencia una vez por aplicación (o proceso).  

### Aplicar licencia mediante archivo u objeto de flujo {#apply-license-using-file-or-stream-object}
  
#### Establecer una licencia en Aspose.Email para .NET {#setting-a-license-in-asposeemail-for-net}
  
En Aspose.Email, la licencia puede cargarse desde un archivo, un flujo o un recurso incrustado. Aspose.Email intenta encontrar la licencia en las siguientes ubicaciones:  

- Ruta explícita
- La carpeta que contiene el archivo dll del componente (incluido en Aspose.Email)
- La carpeta que contiene el ensamblado que llamó al dll del componente (incluido en Aspose.Email)
- La carpeta que contiene el ensamblado de entrada (su .exe)
- Un recurso incrustado en el ensamblado que llamó al dll del componente (incluido en Aspose.Email)  

Existen dos métodos comunes para establecer la licencia, los cuales se describen a continuación:  

#### Aplicar licencia mediante archivo u objeto de flujo {#apply-license-using-file-or-stream-object-1}
  
La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo dll del componente (incluido en Aspose.Email) y especificar únicamente el nombre del archivo, sin su ruta.

```java

 // Instantiate an instance of license and set the license file through its path

Aspose.Email.License license = new Aspose.Email.License();

license.SetLicense("Aspose.Email.lic");
```

```java

 // Instantiate an instance of license and set the license through a stream

Aspose.Email.License license = new Aspose.Email.License();

license.SetLicense(myStream);
```

Cuando llame al método `SetLicense`, el nombre de la licencia debe coincidir exactamente con el nombre del archivo de licencia. Por ejemplo, puede cambiar el nombre del archivo de licencia a `"Aspose.Email.lic.xml"`. Luego, en su código, debe utilizar el nombre modificado de la licencia (es decir, `Aspose.Email.lic.xml`) para el método `SetLicense`.

### Aplicar licencia por uso (Metered) {#apply-metered-license}
  
Aspose.Email permite a los desarrolladores aplicar una clave por uso (metered). Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por uso. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por uso</a>.

Se ha introducido una nueva clase `Metered` para aplicar la clave por uso. A continuación se muestra un ejemplo de código que demuestra cómo establecer las claves públicas y privadas por uso.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-.NET
Aspose.Email.Metered metered = new Aspose.Email.Metered();
// Access the SetMeteredKey property and pass public and private keys as parameters
metered.SetMeteredKey("*****", "*****");

// The path to the documents directory. 
string dataDir = RunExamples.GetDataDir_Email();

// Load the document from disk.
MailMessage eml = MailMessage.Load(dataDir + "Message.eml");
//Get the page count of document
Console.WriteLine(eml.Subject);
```

## Incluir el archivo de licencia como un recurso incrustado  {#including-the-license-file-as-an-embedded-resource}
  
Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama al DLL del componente (incluido en Aspose.Email). Para incluir el archivo de licencia como un recurso incrustado, realice los siguientes pasos:  

- En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto mediante el menú Archivo | Agregar elemento existente…
- Seleccione el archivo en el Explorador de soluciones y establezca Acción de compilación en Recurso incrustado en la ventana Propiedades
- Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), no es necesario invocar los métodos GetExecutingAssembly y GetManifestResourceStream de la clase System.Reflection.Assembly del Microsoft .NET Framework. Todo lo que se requiere hacer es agregar el archivo de licencia como recurso incrustado en su proyecto y pasar el nombre del archivo de licencia al método SetLicense de la clase License. La clase License encontrará automáticamente el archivo de licencia en los recursos incrustados.  

Consulte el ejemplo que se muestra a continuación para comprender este método de establecimiento de licencia (incrustada) en sus aplicaciones.

```java

 // Instantiate the License class

Aspose.Email.License license = new Aspose.Email.License();

// Pass only the name of the license file embedded in the assembly

license.SetLicense("Aspose.Email.lic");
```

## Cómo verificar el número de versión de Aspose.Email para .NET {#how-to-check-version-number-of-asposeemail-for-net}
  
Conocer el número de versión de la biblioteca con la que está trabajando puede ser crucial para la depuración, las comprobaciones de compatibilidad y para asegurarse de que está utilizando las características y correcciones de errores más recientes. Esta guía le mostrará cómo verificar el número de versión de Aspose.Email para .NET en diversos entornos.

### Uso de la API para verificar el número de versión {#using-the-api-to-check-version-number}
  
Aspose.Email para .NET ofrece una forma sencilla de recuperar el número de versión de forma programática. Puede acceder a esta información mediante la clase <a href="https://reference.aspose.com/email/net/aspose.email/buildversioninfo/" target="_blank" rel="nofollow noopener noreferrer">BuildVersionInfo</a>.

El siguiente fragmento de código en C# permite recuperar y mostrar el número de versión:

```csharp

using System;
using Aspose.Email;

class Program
{
    static void Main(string[] args)
    {
        // Get the version number of Aspose.Email for .NET
        string version = BuildVersionInfo.AssemblyVersion;
        
        // Display the version number
        Console.WriteLine("Aspose.Email for .NET Version: " + version);
    }
}
```

### Comprobar el número de versión en Visual Studio {#checking-version-number-in-visual-studio}
  
También puedes comprobar el número de versión directamente en Visual Studio sin escribir ningún código:  


1. **Explorador de soluciones:**  

- Abre tu proyecto en Visual Studio.
- Navega hasta el Explorador de soluciones.
- Expande el nodo "Referencias" bajo tu proyecto.  


2. **Propiedades de la referencia:**  

- Ubica "Aspose.Email" en la lista de referencias.
- Haz clic derecho sobre "Aspose.Email" y selecciona "Propiedades".
- En la ventana de propiedades, verás el número de versión listado bajo la propiedad "Versión".  

### Usar el Administrador de paquetes NuGet {#using-nuget-package-manager}
  
Si has instalado Aspose.Email mediante NuGet, puedes comprobar el número de versión a través del Administrador de paquetes NuGet:  


1. **Consola del Administrador de paquetes:**  

- Abre la Consola del Administrador de paquetes desde Herramientas &gt; Administrador de paquetes NuGet &gt; Consola del Administrador de paquetes.
- Escribe el siguiente comando para listar los paquetes instalados:

```text
Get-Package -Id Aspose.Email
```

- Esto mostrará el número de versión del paquete Aspose.Email instalado en su proyecto.  

2. **Administrar paquetes NuGet:**  

- Haga clic con el botón derecho en su proyecto en el Explorador de soluciones.
- Seleccione «Administrar paquetes NuGet».
- En la pestaña «Instalado», busque «Aspose.Email» para ver el número de versión.

### Comprobar el número de versión en las propiedades del DLL {#checking-version-number-in-dll-properties}
  
También puede comprobar el número de versión examinando las propiedades del DLL de Aspose.Email:  

1. **Ubicar el DLL:**  

Encuentre el archivo DLL de Aspose.Email en el directorio de su proyecto, generalmente dentro de la carpeta `bin`.  

2. **Ver propiedades:**  

- Haga clic con el botón derecho en el archivo DLL de Aspose.Email y seleccione «Propiedades».
- Vaya a la pestaña «Detalles». El número de versión aparecerá en el campo «Versión del producto» o «Versión del archivo».

Siguiendo cualquiera de estos métodos, podrá comprobar fácilmente el número de versión de Aspose.Email para .NET, asegurándose de tener la versión adecuada para sus necesidades de desarrollo. Para obtener más ayuda y actualizaciones, consulte la [documentación](/net/email/) de Aspose.Email para .NET.

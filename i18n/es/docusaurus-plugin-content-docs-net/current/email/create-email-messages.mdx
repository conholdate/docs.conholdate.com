## Crear un nuevo mensaje de correo electrónico {#create-new-email-message}
  
Para crear un nuevo mensaje de correo electrónico, puede utilizar la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. La clase **MailMessage** también inicializa las propiedades del mensaje de correo electrónico creado, como la dirección de correo electrónico del remitente, las direcciones de correo electrónico de los destinatarios, el asunto del correo electrónico y el contenido del cuerpo del correo en formato HTML.

Considere el siguiente código, con pasos detallados, para crear un nuevo mensaje de correo electrónico y establecer sus propiedades:  

1. Crear una nueva instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.
2. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/from/" target="_blank" rel="nofollow noopener noreferrer">From</a> en la dirección de correo electrónico del remitente.
3. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/to/" target="_blank" rel="nofollow noopener noreferrer">To</a> en una lista separada por comas de las direcciones de correo electrónico de los destinatarios.
4. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/subject/" target="_blank" rel="nofollow noopener noreferrer">Subject</a> en el asunto del correo electrónico.
5. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/htmlbody/" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a> en el contenido HTML del cuerpo del correo electrónico.

```cs
// Create a new instance of MailMessage class
var message = new MailMessage
{
    From = "from@domain.com",
    To = "to1@domain.com, to2@domain.com",
    Subject = "New message",
    HtmlBody = @"<!DOCTYPE html>
    <html>
     <head>
      <style>
       h3{font-family:Verdana, sans-serif;color:#000000;background-color:#ffffff;}
       p {font-family:Verdana, sans-serif;font-size:14px;font-style:normal;
         font-weight:normal;color:#000000;background-color:#ffffff;}
      </style>
     </head>
     <body>
       <h3>New message</h3>
       <p>This is a new message created by Aspose.Email.</p>
     </body>
    </html>"
};
```

### Establecer la codificación de texto predeterminada {#set-default-text-encoding}
  
Establezca la codificación de texto predeterminada para las siguientes propiedades:  

- De: Nombre para mostrar
- A: Nombre para mostrar
- Asunto
- Cuerpo  

Utilice la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/preferredtextencoding/" target="_blank" rel="nofollow noopener noreferrer">MailMessage.PreferredTextEncoding</a> para garantizar que todo el texto de las propiedades anteriores se codifique correctamente en el mensaje de correo electrónico. El siguiente fragmento de código muestra cómo utilizar una palabra en francés como nombre para mostrar en las direcciones de correo electrónico, el asunto y el cuerpo.

```csharp
// Create an instance of MailMessage
string dataDir = RunExamples.GetDataDir_Email();
MailMessage msg = new MailMessage();

// Set the default or preferred encoding. This encoding will be used as the default for the from/to email addresses, subject and body of message.
msg.PreferredTextEncoding = Encoding.GetEncoding(28591);

// Set email addresses, subject and body
msg.From = new MailAddress("dmo@domain.com", "démo");
msg.To.Add(new MailAddress("dmo@domain.com", "démo"));
msg.Subject = "démo";
msg.HtmlBody = "démo";
msg.Save(dataDir + "SetDefaultTextEncoding_out.msg", SaveOptions.DefaultMsg);
```

## Establecer el cuerpo del correo {#set-mail-body}
  
### Establecer el cuerpo en texto plano {#set-plain-text-body}
  
El cuerpo del correo puede especificarse mediante la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/body/" target="_blank" rel="nofollow noopener noreferrer">Body</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.

```cs
// Declare message as MailMessage instance
var eml = new MailMessage
{
    // Specify HtmlBody
    Body = "This is a plain text body"
};
```

### Establecer el cuerpo HTML {#set-html-body}
  
Un cuerpo de correo también puede especificarse mediante la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/htmlbody/" target="_blank" rel="nofollow noopener noreferrer">HtmlBody</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.

```cs
// Declare message as MailMessage instance
var eml = new MailMessage
{
    // Specify HtmlBody
    HtmlBody = "<html><body>This is the HTML body</body></html>"
};
```

Puedes simplificar la creación de correos electrónicos HTML cargando un archivo HTML existente junto con sus recursos incrustados (como imágenes). Aspose.Email automatiza el proceso de incrustar estos recursos como contenido en línea.

Aquí tienes cómo cargar un archivo HTML con sus recursos:

```cs
var htmlloadOptions = new HtmlLoadOptions
{
    PathToResources = @"C:\Temp", // folder where your images are stored
    ShouldAddPlainTextView = true
};

var mailMessage = MailMessage.Load(@"body_content.html", htmlloadOptions);

mailMessage.From = senderEmail;

mailMessage.Subject = "New message from HTML";

// Save the message in EML format
mailMessage.Save(EmlfilePath, SaveOptions.DefaultEml);
```

La clase <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/" target="_blank" rel="nofollow noopener noreferrer">HtmlLoadOptions</a> con la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/htmlloadoptions/properties/pathtoresources/" target="_blank" rel="nofollow noopener noreferrer">PathToResources</a> le indica a Aspose.Email dónde encontrar las imágenes referenciadas en su HTML. Durante la carga, la biblioteca incrusta automáticamente dichas imágenes como recursos integrados (CID). Internamente, el HTML se actualiza para hacer referencia a las imágenes incrustadas en lugar de a rutas de archivo.

Como resultado, el archivo .eml final resultante es independiente, y las imágenes seguirán mostrándose incluso después de que los archivos originales se hayan eliminado.

### Establecer texto alternativo {#set-alternate-text}
  
Una vista alternativa en un archivo EML es una representación adicional del contenido del correo electrónico que puede utilizarse para ofrecer una presentación distinta del mensaje. Por ejemplo, si envía un mensaje en HTML, quizás también desee proporcionar una versión en **texto sin formato**, por si algunos destinatarios usan lectores de correo que no pueden mostrar contenido HTML. Para este propósito, utilice la clase <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/" target="_blank" rel="nofollow noopener noreferrer">AlternateView</a>. Esta clase tiene dos propiedades: <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResources</a> y <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/baseuri/" target="_blank" rel="nofollow noopener noreferrer">BaseUri</a>, que se utilizan para resolver las URL dentro del contenido del correo electrónico.  

- <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResources</a> es una colección de objetos <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResource</a>. Al representar el contenido, las URL dentro del mensaje de correo electrónico se comparan primero con las URL del enlace de contenido de cada objeto <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResource</a> de la colección <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResources</a> y luego se resuelven.
- <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/baseuri/" target="_blank" rel="nofollow noopener noreferrer">BaseUri</a> es utilizado por el lector de correo para resolver las URL relativas dentro del cuerpo del mensaje, así como también las URL relativas de enlaces de contenido en la colección <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/linkedresources/" target="_blank" rel="nofollow noopener noreferrer">LinkedResources</a>.

Considere el siguiente código con pasos detallados para establecer un texto alternativo:  

1. Crear una instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.
2. Crear <a href="https://reference.aspose.com/email/net/aspose.email/alternateview/createalternateviewfromstring/" target="_blank" rel="nofollow noopener noreferrer">AlternateView</a> para visualizar el mensaje de correo electrónico utilizando el contenido especificado en una cadena.
3. Agregar texto alternativo mediante el método <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/addalternateview/" target="_blank" rel="nofollow noopener noreferrer">Add</a> de la colección <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/alternateviews/" target="_blank" rel="nofollow noopener noreferrer">MailMessage.AlternateViews</a>.

```cs
// Declare message as MailMessage instance
var eml = new MailMessage();

// Creates AlternateView to view an email message using the content specified in the //string
var alternate = AlternateView.CreateAlternateViewFromString("Alternate Text");

// Adding alternate text
 eml.AlternateViews.Add(alternate);
```

## Especificar varios destinatarios {#specify-multiple-recipients}
  
Existen tres formas de especificar los destinatarios de un mensaje de correo electrónico: mediante los campos **Para**, **CC** o **CCO**.  

- El campo **Para** corresponde al destinatario principal de su mensaje. Puede introducir una o varias direcciones de correo electrónico en este campo, separadas por comas. El campo Para es obligatorio en todo mensaje de correo electrónico.  

- El campo **CC** significa *carbon copy* (copia de carbón). Se utiliza para enviar una copia de su mensaje a otras personas interesadas o involucradas en el tema. El campo CC es opcional y también puede contener varias direcciones de correo electrónico. Los destinatarios incluidos en el campo CC pueden ver quiénes más han recibido el mensaje.  

- El campo **CCO** significa *blind carbon copy* (copia de carbón ciega). Es similar al campo CC, pero los destinatarios incluidos en el campo CCO permanecen ocultos para el resto de los destinatarios. El campo CCO resulta útil cuando desea proteger la privacidad de algunos destinatarios o evitar saturar sus buzones de entrada con respuestas. Este campo también es opcional y puede contener varias direcciones de correo electrónico.  

Considere el siguiente código, con pasos detallados, para especificar varios destinatarios en un mensaje de correo electrónico.  

**Pasos del código:**  

1. Crear una nueva instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.  

2. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/from/" target="_blank" rel="nofollow noopener noreferrer">From</a> en la dirección de correo electrónico del remitente.  

3. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/to/" target="_blank" rel="nofollow noopener noreferrer">To</a> en una matriz con las direcciones de correo electrónico de los destinatarios principales.  

4. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/cc/" target="_blank" rel="nofollow noopener noreferrer">CC</a> en una matriz con las direcciones de correo electrónico de los destinatarios que recibirán una copia del correo electrónico.  

5. Establecer la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/bcc/" target="_blank" rel="nofollow noopener noreferrer">Bcc</a> en una matriz con las direcciones de correo electrónico de los destinatarios que recibirán una copia ciega del correo electrónico.  

**Ejemplo de código:**

```cs
var eml = new MailMessage
{
    // Specify From address
    From = "sender@sender.com",
    //  Specify recipients’ mail addresses
    To = {"receiver1@receiver.com", "receiver2@receiver.com", "receiver3@receiver.com"},
    // Specify CC addresses
    CC = {"CC1@receiver.com", "CC2@receiver.com"},
    // Specify BCC addresses
    Bcc = {"Bcc1@receiver.com", "Bcc2@receiver.com"}
};
```

## Agregar nombres para mostrar a direcciones de correo electrónico  {#add-display-names-to-email-addresses}


Junto con una dirección de correo electrónico, se puede incluir un **nombre para mostrar** para identificar al remitente o destinatario del correo electrónico. Este puede incluir el nombre completo de una persona, un apodo u otro identificador.

Cuando un mensaje de correo electrónico se muestra en un cliente de correo electrónico o en una interfaz webmail, el nombre para mostrar suele aparecer junto con la dirección de correo electrónico, facilitando así al usuario identificar de quién proviene el mensaje o a quién está dirigido. Para agregar nombres para mostrar a direcciones de correo electrónico en un mensaje de correo electrónico, considere el siguiente código con pasos detallados:


1. Cargue el mensaje de correo electrónico desde un archivo utilizando el método `MailMessage.Load`.
2. Establezca el remitente del correo electrónico mediante la propiedad `From` del objeto eml, creando un nuevo objeto `MailAddress` con la dirección de correo electrónico y el nombre para mostrar del remitente.
3. Agregue un destinatario al correo electrónico utilizando la propiedad `To` del objeto eml; si es necesario, agregue una lista de copia (CC) mediante la propiedad `CC`, una lista de copia oculta (BCC) mediante la propiedad `Bcc` y llame al método `Add` con un nuevo objeto `MailAddress` que contenga la dirección de correo electrónico y el nombre para mostrar del destinatario.

**Ejemplo de código:**

```cs
// Load eml from file
var eml = MailMessage.Load("test.eml");

eml.From = new MailAddress("TimothyFairfield@from.com", "Timothy Fairfield");

// A To address with a friendly name can also be specified like this
eml.To.Add(new MailAddress("kyle@to.com", "Kyle Huang"));

// Specify Cc and Bcc email address along with a friendly name
eml.CC.Add(new MailAddress("guangzhou@cc.com", "Guangzhou Team"));
eml.Bcc.Add(new MailAddress("ahaq@bcc.com", "Ammad ulHaq "));
```

```cs
var eml = new MailMessage("sender@gmail.com", "receiver@gmail.com", "Some subject", "Some body text")
{
    Date = DateTime.Now,
    Priority = MailPriority.High,
    Sensitivity = MailSensitivity.Normal,
    XMailer = "Aspose.Email"
};
```

## Solicitar recibo de lectura  {#request-read-receipt}
  
Para solicitar un <a href="https://en.wikipedia.org/wiki/Return_receipt" target="_blank" rel="nofollow noopener noreferrer">recibo de lectura</a>, utilice la propiedad <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/deliverynotificationoptions/" target="_blank" rel="nofollow noopener noreferrer">DeliveryNotificationOptions</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. Esta propiedad contiene los valores de la enumeración <a href="https://reference.aspose.com/email/net/aspose.email/deliverynotificationoptions/#deliverynotificationoptions-enumeration" target="_blank" rel="nofollow noopener noreferrer">DeliveryNotificationOptions</a>.

Considere el siguiente **ejemplo de código**:

```cs
// Create an Instance of MailMessage class
var eml = new MailMessage
{
    // Specify From, To, HtmlBody, DeliveryNotificationOptions field
    From = "sender@sender.com",
    To = "receiver@receiver.com",
    HtmlBody = "<html><body>This is the Html body</body></html>",
    DeliveryNotificationOptions = DeliveryNotificationOptions.OnSuccess
};

eml.Headers.Add("Return-Receipt-To", "sender@sender.com");
eml.Headers.Add("Disposition-Notification-To", "sender@sender.com");

// Create an instance of SmtpClient Class
var client = new SmtpClient
{
    // Specify your mailing host server, Username, Password and Port No
    Host = "smtp.server.com",
    Username = "Username",
    Password = "Password",
    Port = 25
};

try
{
    // Client.Send will send this message
    client.Send(eml);
    // Display ‘Message Sent’, only if message sent successfully
    Console.WriteLine(@"Message sent");
}
catch (Exception ex)
{
    System.Diagnostics.Trace.WriteLine(ex.ToString());
}
```

**Nota**: Las solicitudes de confirmación de lectura pueden no cumplirse siempre debido a:

- Un cliente de correo electrónico podría no implementar dicha funcionalidad.
- El usuario final podría tener desactivada dicha funcionalidad.
- El usuario final podría decidir no enviar una confirmación.

## Personalizar encabezados de correo electrónico {#customize-email-headers}
  
Los encabezados de correo electrónico siguen un estándar de Internet: las RFC correspondientes definen los campos de encabezado que se incluyen en los mensajes de correo electrónico de Internet. Un encabezado de correo electrónico puede especificarse mediante la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. Los tipos de encabezado comunes se definen en la clase <a href="https://reference.aspose.com/email/net/aspose.email/headertype/" target="_blank" rel="nofollow noopener noreferrer">HeaderType</a>. Se trata de una clase sellada que funciona como una enumeración normal.

Normalmente, un encabezado de correo electrónico contiene estos campos:  

- **To** (Para): Las direcciones de destino pueden especificarse en el campo *To*. Los destinatarios indicados en este campo constituyen la audiencia principal del mensaje. Puede haber más de una dirección de destinatario.
- **From** (De): Este campo muestra la dirección de correo electrónico del remitente del mensaje.
- **Cc** (Copia): Permite enviar un mensaje como “copia carbón” o “copia de cortesía”, es decir, no se espera que el destinatario responda ni actúe. Normalmente, se notifica a personal de supervisión mediante CC.
- **Bcc** (Copia oculta): Significa “copia carbón ciega” y permite enviar un correo electrónico a un destinatario cuya identidad se oculta al resto de destinatarios.
- **ReplyTo** (Responder a): Este campo de encabezado indica dónde deben enviarse las respuestas que el remitente desea recibir.
- **Subject** (Asunto): Título, encabezado o asunto. Se utiliza frecuentemente como indicador de hilo para mensajes que responden o comentan otros mensajes.
- **Date** (Fecha): Este encabezado especifica una fecha (y hora). Normalmente corresponde a la fecha en que se redactó y envió el mensaje.
- **X-Mailer**: Información sobre el software cliente del remitente. Ejemplo: `X-Mailer: Aspose.Email`. El campo X-Mailer lo utiliza el cliente de correo electrónico. Distintos clientes de correo tendrán distintos valores para X-Mailer. El valor de X-Mailer de Microsoft Outlook es *Microsoft Office Outlook, Build 11.0.5510*. Este campo es ignorado por el receptor o lector de correo electrónico.

Normalmente, un encabezado de correo electrónico tiene un aspecto similar al siguiente:

```text
Reply-To: reply@reply.com
From: sender@sender.com
To: guangzhou@guangzhoo.com
Subject: test mail
Date: 6 Mar 2006 8:2:2 +0800
X-Mailer: Aspose.Email
```

Para personalizar el encabezado de un correo electrónico, siga estos **pasos de código**:

- Cree una instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.
- Especifique los campos To, From, Cc, Bcc, ReplyTo, Subject, Date y XMailer mediante una instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.
- Cree una instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email.mime/mimeheader/" target="_blank" rel="nofollow noopener noreferrer">MimeHeader</a> y especifique el encabezado personalizado.
- Agregue el encabezado personalizado a la instancia de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.

El siguiente **fragmento de código** le muestra cómo establecer los encabezados del correo electrónico.

```cs
var eml = new MailMessage
{
    ReplyToList = "reply@reply.com",
    From = "sender@sender.com",
    To = "receiver1@receiver.com",
    CC = "receiver2@receiver.com",
    Bcc = "receiver3@receiver.com",
    Subject = "test mail",
    Date = new System.DateTime(2006, 3, 6),
    XMailer = "Aspose.Email"
};
```

El fragmento de código anterior genera una cabecera de correo electrónico en el siguiente formato:

```text
Reply-To: reply@reply.com
From: sender@sender.com
To: receiver1@receiver.com
Cc: receiver2@receiver.com
Bcc: receiver3@receiver.com
Subject: test mail
Date: Mon, 6 Mar 2006 00:00:00 +0000
X-Mailer: Aspose.Email
```

### Insertar un encabezado en una ubicación específica  {#insert-a-header-at-a-specific-location}
  
El método <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/add/#add/" target="_blank" rel="nofollow noopener noreferrer">Add</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/" target="_blank" rel="nofollow noopener noreferrer">HeaderCollection</a> inserta un encabezado al final de la colección. Sin embargo, en ocasiones puede ser necesario insertar un encabezado en una ubicación específica. En tal caso, el método <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/add/#add/" target="_blank" rel="nofollow noopener noreferrer">Add</a> no será útil. Para lograrlo, utilice el método <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/insert/#insert" target="_blank" rel="nofollow noopener noreferrer">Insert</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email.mime/headercollection/" target="_blank" rel="nofollow noopener noreferrer">HeaderCollection</a>. Si la colección contiene encabezados con el mismo nombre, este encabezado se insertará antes que otros encabezados con el mismo nombre. El siguiente fragmento de código muestra cómo insertar un encabezado en una ubicación específica.

```cs
eml.Headers.Insert("Received", "Value");
```

### Agregar encabezados personalizados {#add-custom-headers}
  
Un encabezado de correo electrónico puede especificarse utilizando la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>. Para especificar un **encabezado personalizado** en un mensaje de correo electrónico, considere el siguiente ejemplo de código:

```cs
eml.Headers.Add("secret-header", "mystery");
```

El fragmento de código anterior genera una cabecera de correo electrónico en el siguiente formato:

```cs
secret-header: mystery
```

## Crear mensajes firmados {#create-signed-messages}
  
La API de Aspose.Email proporciona la capacidad de crear mensajes firmados mediante certificados. El método <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/attachsignature/#attachsignature/" target="_blank" rel="nofollow noopener noreferrer">AttachSignature</a> de la clase <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> puede utilizarse para firmar un mensaje antes de guardarlo o incluso enviarlo mediante <a href="https://reference.aspose.com/email/net/aspose.email.clients.smtp/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a>.

### Firmar un mensaje {#sign-a-message}
  
<a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/attachsignature/" target="_blank" rel="nofollow noopener noreferrer">AttachSignature</a> devuelve una *nueva* instancia de <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> firmada y deja el mensaje original sin modificar; por lo tanto, debe guardar o enviar el objeto devuelto. La firma puede eliminarse posteriormente mediante <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/removesignature/" target="_blank" rel="nofollow noopener noreferrer">RemoveSignature</a>, que devuelve el mensaje original con su cuerpo original.

El siguiente fragmento de código muestra cómo firmar un mensaje.

```csharp
// The path to the File directory.
string dataDir = RunExamples.GetDataDir_SMTP();
string privateCertFile = dataDir + "MartinCertificate.pfx";

// A private key is required for signing
X509Certificate2 privateCert = new X509Certificate2(privateCertFile, "password");

MailMessage msg = new MailMessage("userfrom@gmail.com", "userto@gmail.com", "Signed message only", "Test Body of signed message");

// AttachSignature returns a new signed message, the original msg is left intact
MailMessage signed = msg.AttachSignature(privateCert);
signed.Save(dataDir + "SignedMessage_out.eml", SaveOptions.DefaultEml);

// The signature can be removed to get the original message back
MailMessage unsigned = signed.RemoveSignature();
```

### Uso de la opción de certificado independiente  {#using-detached-certificate-option}
  
Los clientes de correo web pueden no poder mostrar el contenido del cuerpo de un mensaje firmado. Esto se puede solucionar separando el certificado antes de enviarlo a los clientes de correo web. La marca *detached* (independiente) en el método sobrecargado de <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/attachsignature/#attachsignature/" target="_blank" rel="nofollow noopener noreferrer">AttachSignature</a> permite lograr esto. Si se establece en **true**, el certificado se separa del correo electrónico; de lo contrario, permanece adjunto. Para ver el cuerpo del mensaje firmado en clientes web, debe crear <a href="https://reference.aspose.com/email/net/aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> con una firma independiente. El siguiente fragmento de código muestra cómo utilizar la opción de certificado independiente.

```csharp
string privateCertFile = dataDir + "MartinCertificate.pfx";
X509Certificate2 privateCert = new X509Certificate2(privateCertFile, "anothertestaccount");

MailMessage msg = new MailMessage("user@domain.com", "receiver@domain.com", "subject:Signed message only by AE", "body:Test Body of signed message by AE");

MailMessage signed = msg.AttachSignature(privateCert, true);
SmtpClient smtp = GetSmtpClient();
            
try
{
    smtp.Send(signed);
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

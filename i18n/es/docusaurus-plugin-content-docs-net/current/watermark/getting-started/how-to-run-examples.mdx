Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de GroupDocs.Watermark, ya sea construyendo su propio proyecto o utilizando nuestros ejemplos listos para usar.

Elija una opción de la siguiente lista:

## Construir el proyecto desde cero {#build-project-from-scratch}

* Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
* Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
* Instale **GroupDocs.Watermark para .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/watermark/getting-started/installation/).
* Desarrolle su primera aplicación con **GroupDocs.Watermark para .NET**, como se muestra a continuación

```csharp
string documentPath = "doc.pdf"; // NOTE: Put here actual path for your document
PdfLoadOptions loadOptions = new PdfLoadOptions();
using (Watermarker watermarker = new Watermarker(documentPath, loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 36, FontStyle.Bold | FontStyle.Italic));
    PdfXObjectWatermarkOptions options = new PdfXObjectWatermarkOptions();
    options.PageIndex = 0;

    watermarker.Add(watermark, options);
    watermarker.Save("watermarked.pdf");
}
```

* Compile y ejecute su proyecto.
* El documento con marca de agua aparecerá en el directorio de trabajo como *watermarked.pdf*.

## Ejecute los ejemplos {#run-examples}

El paquete completo de ejemplos de **GroupDocs.Watermark** está alojado en <a href="https://github.com/groupdocs-watermark/GroupDocs.Watermark-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-watermark/GroupDocs.Watermark-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando su cliente de Git favorito. Si descarga el archivo ZIP, extraiga las carpetas en su disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![how-to-run-examples](/net/watermark/images/how-to-run-examples.jpg)

En los archivos y carpetas extraídos, puede encontrar el archivo de solución de C#. El proyecto se creó con **Microsoft Visual Studio 2019**. La carpeta **Resources** contiene todos los archivos de documentos e imágenes de ejemplo utilizados en los ejemplos. Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias faltantes de **GroupDocs.Watermark**, consulte [Installation](/net/watermark/getting-started/installation/). Todas las funciones se llaman desde **RunExamples.cs**.

Descomente la función que desea ejecutar y comente el resto.

![how-to-run-examples_1](/net/watermark/images/how-to-run-examples_1.png)

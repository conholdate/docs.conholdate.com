En este artículo, aprenderá cómo crear una aplicación sencilla en C# que agregue una marca de agua de texto utilizando la API de GroupDocs.Watermark. 


:::info
Asumimos que ya posee conocimientos básicos sobre **Microsoft Visual Studio** y **C#**.
:::


## Requisitos {#requirements}

- Un sistema [compatible](/net/watermark/getting-started/system-requirements/) con Microsoft Visual Studio instalado. Como desarrollador individual, puede utilizar la edición gratuita Visual Studio Community Edition.
- **5 minutos** de su tiempo libre.

## Preparación {#preparing}

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2. Seleccione el tipo de proyecto **Aplicación de consola**.
3. [Instale](/net/watermark/getting-started/installation/) el paquete NuGet **GroupDocs.Watermark** en el proyecto.

## Codificación {#coding}

1. Cree una instancia de la clase `Watermarker` para el documento local. Puede especificar una ruta absoluta o relativa:
   ```csharp
   Watermarker watermarker = new Watermarker("C:\\Docs\\sample.docx")
   ```
2. Cree una instancia de la clase `TextWatermark` y especifique el texto y la fuente deseados para la marca de agua:
   ```csharp
   TextWatermark watermark = new TextWatermark("Hello, world!", new Font("Arial", 36));
   ```
3. Aplicar la marca de agua:
   ```csharp
   watermarker.Add(watermark);
   ```
4. Guarde el documento resultante:
   ```csharp
   watermarker.Save("C:\\Docs\\watermarked-sample.docx");
   ```

Código completo:

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\sample.docx"))
{
   // Specify the desired text and font for the watermark
   TextWatermark watermark = new TextWatermark("Test watermark", 
      new Font("Arial", 36, FontStyle.Bold | FontStyle.Italic));
      
   watermark.HorizontalAlignment = HorizontalAlignment.Center;
   watermark.VerticalAlignment = VerticalAlignment.Center;

   watermark.Opacity = 0.4;
   watermark.RotateAngle = 45;
   watermark.ForegroundColor = Color.Red;

    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\watermarked-sample.docx");
}
```

Además, si está seguro acerca de la extensión de su archivo o conoce de antemano el tipo de documento, puede especificar el FileType mediante la clase LoadOptions. Especificarlo elimina la necesidad de detección de formato, lo que permite un procesamiento de documentos más rápido y eficiente:

```csharp

var filePath = "C:\\Docs\\sample.docx";
var loadOptions = new LoadOptions()
{
    FileType = FileType.FromExtension(Path.GetExtension(filePath))
};

// Or set the FormatFamily property directly when using a stream, for example:
loadOptions.FormatFamily = FormatFamily.WordProcessing;

using (var watermarker = new Watermarker(filePath, loadOptions))
{ .... }

```

## Ejecutar {#running}

Ejecute el programa. Se generará un nuevo documento con marca de agua en la ruta especificada.

GroupDocs.Watermark para .NET está incluido en Conholdate.Total for .NET.
:::


:::info
Puede utilizar GroupDocs.Watermark sin licencia. El uso y las funcionalidades son prácticamente iguales a los de la versión con licencia; sin embargo, al utilizar la API sin licencia, se enfrentará a algunas limitaciones.
:::


Puede descargar fácilmente GroupDocs.Watermark para evaluarla. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. Al utilizar la API sin licencia, se enfrentará a las siguientes limitaciones.  

| Característica de la API | Limitación |
| --- | --- |
| Carga de documentos | Solo se pueden cargar 10 documentos por ejecución de la aplicación. |
| Búsqueda/eliminación de marcas de agua | No se permite la eliminación ni la sustitución de partes del documento en el modo de evaluación. |
| Adición de marcas de agua | Solo se puede agregar 1 marca de agua por documento por sesión de edición. |
| Guardado de documentos | Se agregará una marca de agua de advertencia de evaluación al documento. |

## Licenciamiento {#licensing}

El archivo de licencia contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional invalidará el archivo. Debe establecer una licencia antes de utilizar la API de GroupDocs.Watermark si desea evitar sus limitaciones de evaluación.

La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Watermark.dll y especificar el nombre del archivo, sin ruta de acceso, como se muestra en los ejemplos siguientes.

### Establecimiento de licencia desde un archivo {#setting-license-from-file}

El código siguiente explica cómo <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.license/setlicense/methods/1" target="_blank" rel="nofollow noopener noreferrer">set</a> producto <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/license" target="_blank" rel="nofollow noopener noreferrer">license</a> desde un archivo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-watermark/GroupDocs.Watermark-for-.NET
//initialize License
License lic = new License();

//Set license
lic.SetLicense("GroupDocs.Watermark.lic");
```

### Establecer licencia desde un flujo {#setting-license-from-stream}

El siguiente ejemplo muestra cómo <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/license/methods/setlicense" target="_blank" rel="nofollow noopener noreferrer">load</a> una <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/license" target="_blank" rel="nofollow noopener noreferrer">license</a> desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-watermark/GroupDocs.Watermark-for-.NET
using (FileStream fileStream = new FileStream("GroupDocs.Watermark.lic", FileMode.Open, FileAccess.Read))
{
    License lic = new License();
    lic.SetLicense(fileStream);
}
```


:::info
Llamar a <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.license/setlicense/methods/1" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense</a> varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesamiento. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, invoque `License.SetLicense` en su código de inicio, antes de utilizar las clases de GroupDocs.Watermark.

Al desarrollar una aplicación ASP.NET, puede invocar `License.SetLicense` desde el archivo `Global.asax.cs` (`Global.asax.vb`) dentro del método protegido `Application_Start`. Este método se ejecuta una única vez al iniciar la aplicación. No invoque `License.SetLicense` dentro de los métodos `Page_Load`, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
:::


### Configuración de licencia basada en uso {#setting-metered-license}

También puede configurar la <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las características de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en uso</a>.

A continuación se presentan los pasos sencillos para utilizar la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.

1. Crear una instancia de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
2. Pasar las claves pública y privada al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered/methods/setmeteredkey" target="_blank" rel="nofollow noopener noreferrer">SetMeteredKey</a>.
3. Realizar el procesamiento (ejecutar la tarea).
4. Llamar al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered/methods/getconsumptionquantity" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionQuantity</a> de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
5. Este método devolverá la cantidad/cantidad de solicitudes de API que ha consumido hasta el momento.
6. Llamar al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered/methods/getconsumptioncredit" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionCredit</a> de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
7. Este método devolverá los créditos que ha consumido hasta el momento.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase Metered.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-watermark/GroupDocs.Watermark-for-.NET
string PublicKey = ""; // Your public license key
string PrivateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(PublicKey, PrivateKey);

// Get amount (MB) consumed
decimal amountConsumed = Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

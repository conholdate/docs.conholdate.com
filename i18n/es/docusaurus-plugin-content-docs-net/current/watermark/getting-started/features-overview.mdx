## Watermark {#watermark}

Una marca de agua es una imagen o texto que se superpone intencionadamente sobre un documento o imagen. Su propósito es dificultar que el documento o imagen original sea copiado o utilizado sin permiso.

La API GroupDocs.Watermark para .NET ofrece una amplia gama de funcionalidades relacionadas con marcas de agua. A continuación se enumeran algunas características clave.

1. Añadir marca de agua de texto o imagen a formatos de documento compatibles
2. Buscar y eliminar marcas de agua de texto o imagen en formatos de documento compatibles
3. Buscar marcas de agua en objetos específicos
4. Añadir marca de agua a imágenes dentro de un documento
5. Modificar objetos de marca de agua existentes en formatos de documento compatibles
6. Extraer información de objetos de marca de agua en un documento
7. Rasterización de documentos PDF
8. Obtener información del documento
9. Buscar marcas de agua según el formato de texto (fuente, color, etc.)
10. Modificar hipervínculos asociados a entidades del documento (todos los formatos)
11. Establecer imagen de fondo para gráficos en documentos de Excel y PowerPoint
12. Modificar adjuntos y archivos PDF y de correo electrónico
13. Utilizar una cuenta *Dynabic.Metered* para emplear la API en modo con licencia

## Extracción de información del documento {#document-information-extraction}

GroupDocs.Watermark permite obtener información básica sobre el documento de origen: tipo de archivo, tamaño, número de páginas, altura y ancho de página, etc.  
Esto puede resultar muy útil para generar una vista previa del documento y para colocar con precisión la marca de agua dentro del documento.

## Vista previa de páginas del documento {#preview-document-pages}

La funcionalidad de vista previa del documento permite generar representaciones en imagen de las páginas del documento. Esto puede ser útil para comprender mejor el contenido y la estructura del documento,  
definir la posición adecuada de la marca de agua dentro del documento, aplicar un estilo de marca de agua apropiado, etc. La vista previa puede generarse para todas las páginas del documento (de forma predeterminada) o para números de página o rango de páginas específicos.

Los formatos de imagen admitidos para la vista previa del documento son:

* PNG;
* JPG;
* BMP.

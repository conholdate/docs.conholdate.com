## Resumen {#overview}

Las empresas que distribuyen contratos en PDF, materiales de marketing o manuales técnicos suelen incrustar marcas de agua para proteger la propiedad intelectual y hacer cumplir las normas de marca. Abrir manualmente cada archivo para verificar que una marca de agua de texto específica (por ejemplo, “Confidencial”) aparezca en cada página es propenso a errores, especialmente cuando se trata de miles de documentos. Este caso de uso muestra cómo automatizar una auditoría completa del documento mediante `Watermarker` y `TextSearchCriteria`, confirmar que la marca de agua requerida existe en todas las páginas, verificar las reglas de formato y generar un informe conciso de cumplimiento.

## Requisitos previos {#prerequisites}

- **Entorno de ejecución de .NET** 6.0 o posterior.
- Paquete NuGet **GroupDocs.Watermark** (`GroupDocs.Watermark`).
- Una clave de licencia temporal o permanente de GroupDocs.Watermark (opcional para evaluación).
- Archivos PDF ubicados en una carpeta local que desea auditar.

## Ejemplo de uso {#usage-example}

A continuación se presenta una guía paso a paso basada en el `Program.cs` real del repositorio de ejemplo.

### 1. Escanear un documento en busca de todas las marcas de agua existentes {#1-scan-a-document-for-all-existing-watermarks}

Utilice el método `Search()` sin parámetros en una instancia de `Watermarker` para enumerar todas las marcas de agua, incluyendo texto, posición, rotación y datos de imagen:

```csharp
using (Watermarker watermarker = new Watermarker(filePath))
{
    PossibleWatermarkCollection watermarks = watermarker.Search();

    foreach (PossibleWatermark wm in watermarks)
    {
        Console.WriteLine($"  Text: {wm.Text ?? "(image)"}");
        Console.WriteLine($"  Position: X={wm.X}, Y={wm.Y}");
        Console.WriteLine($"  Rotation: {wm.RotateAngle} degrees");
        Console.WriteLine($"  Page: {wm.PageNumber}");
    }
}
```

### 2. Verifique que el texto de marca de agua requerido esté presente {#2-verify-required-text-watermark-is-present}

Genere un `TextSearchCriteria` con `SkipUnreadableCharacters` habilitado para detectar marcas de agua ofuscadas o fragmentadas. La búsqueda devuelve una bandera de ÉXITO/FRACASO:

```csharp
using (Watermarker watermarker = new Watermarker(filePath))
{
    TextSearchCriteria criteria =
        new TextSearchCriteria(expectedText);
    criteria.SkipUnreadableCharacters = true;

    PossibleWatermarkCollection found = watermarker.Search(criteria);
    bool passed = found.Count > 0;

    Console.WriteLine($"  [{(passed ? "PASS" : "FAIL")}] " +
        $"expected '{expectedText}', " +
        $"found {found.Count} match(es)");
}
```

### 3. Ejecutar un informe de cumplimiento con múltiples reglas {#3-run-a-multi-rule-compliance-report}

Combine `TextSearchCriteria` con `TextFormattingSearchCriteria` utilizando el operador `.And()` para verificar la fuente, el tamaño y el estilo en negrita, además de la presencia del texto:

```csharp
var textCriteria = new TextSearchCriteria(expectedText);

// Check text + font name
var fontCriteria = new TextFormattingSearchCriteria
    { FontName = "Arial" };
CheckRule(watermarker, textCriteria.And(fontCriteria),
    "Font 'Arial'", ref passed, ref failed);

// Check text + minimum font size
var sizeCriteria = new TextFormattingSearchCriteria
    { MinFontSize = 15 };
CheckRule(watermarker, textCriteria.And(sizeCriteria),
    "Min font size >= 15", ref passed, ref failed);
```

Un asistente independiente verifica la cobertura de página recopilando los números de página con marca de agua y comparándolos con el recuento total de páginas. El veredicto final es “CUMPLIENTE” o “NO CUMPLIENTE”.

### 4. Reemplazar el texto de marca de agua obsoleto {#4-replace-outdated-watermark-text}

Ubique las marcas de agua según su texto antiguo, borre su `FormattedTextFragments` y agregue un nuevo texto con fuente y color actualizados:

```csharp
using (Watermarker watermarker = new Watermarker(filePath))
{
    var criteria = new TextSearchCriteria(oldText, false);
    var watermarks = watermarker.Search(criteria);

    foreach (PossibleWatermark wm in watermarks)
    {
        wm.FormattedTextFragments.Clear();
        wm.FormattedTextFragments.Add(
            newText,
            new Font("Arial", 19, FontStyle.Bold),
            Color.DarkBlue,
            Color.Transparent);
    }

    watermarker.Save(outputPath);
}
```

## Notas {#notes}

- El ejemplo funciona con cualquier formato de documento admitido por GroupDocs.Watermark (DOCX, PPTX, etc.). Reemplace el filtro `*.pdf` por `*.*` para auditar una carpeta con archivos mixtos.
- Para colecciones grandes, considere procesar los archivos en paralelo (`Parallel.ForEach`); el SDK de Watermark es seguro para subprocesos siempre que cada subproceso utilice su propia instancia de `Watermarker`.
- Si necesita auditar PDF cifrados, pase la contraseña a `Watermarker` mediante la sobrecarga del constructor.
- La licencia de evaluación gratuita limita el número de páginas procesadas; adquiera una licencia completa para cargas de trabajo en producción.

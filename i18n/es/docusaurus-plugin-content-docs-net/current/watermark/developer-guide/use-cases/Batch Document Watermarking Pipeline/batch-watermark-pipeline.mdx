## Visión general {#overview}

Muchas empresas necesitan marcar o proteger periódicamente miles de documentos: PDFs, archivos de Word, presentaciones y hojas de cálculo. Esta muestra incluye **cuatro tipos de documentos** (DOCX, PDF, XLSX, PPTX), de modo que se demuestra cada modo de canalización con formatos del mundo real. Realizar este proceso manualmente es propenso a errores y consume mucho tiempo; además, volver a ejecutar un trabajo por lotes puede crear accidentalmente marcas de agua duplicadas. Este caso de uso muestra cómo **aplicar marcas de agua de texto y logotipos en masa**, manteniendo al mismo tiempo el proceso **seguro frente a duplicados**, de modo que ejecutar el trabajo varias veces nunca genere marcas redundantes. La solución utiliza **GroupDocs.Watermark para .NET**, que abstracte la complejidad del manejo de formatos, los objetos de marca de agua buscables y la lógica inteligente de reemplazo.

## Requisitos previos {#prerequisites}

- **.NET 6.0** o posterior instalado en la máquina de desarrollo.
- Paquete NuGet **GroupDocs.Watermark** (última versión estable).
- Un archivo de licencia válido de **GroupDocs.Watermark** (temporal o permanente). Si el archivo no está presente, la muestra recurre al modo de evaluación; sin embargo, una compilación con licencia elimina las marcas de agua de evaluación.
- Conocimiento básico sobre aplicaciones de consola en C# y operaciones con el sistema de archivos.

## Instalación {#installation}

```bash
# Clone the sample repository
git clone https://github.com/groupdocs-watermark/batch-watermark-pipeline-using-groupdocs-watermark-dotnet.git
cd GroupDocs.Watermark-for-.NET/net/sample-project

# Add the Watermark library to the project
dotnet add package GroupDocs.Watermark

# Restore and build the solution
dotnet restore
dotnet build
```

Los comandos anteriores configuran una aplicación de consola lista para ejecutarse que demuestra la canalización de procesamiento por lotes completa.

## Ejemplo de uso {#usage-example}

A continuación se presenta una guía concisa que vincula los métodos auxiliares entre sí. Solo se muestran las partes esenciales de cada método; el código fuente completo se encuentra en `Program.cs`.

### Paso 1: Cargar la licencia {#step-1-load-the-license}

```csharp
try
{
    var license = new License();
    license.SetLicense("./GroupDocs.Watermark.lic");
    Console.WriteLine("License applied.");
}
catch
{
    Console.WriteLine("Running in evaluation mode - license not found.");
}
```

*El fragmento crea una instancia de `License` y la apunta hacia un archivo `.lic` local. Si el archivo no se puede localizar, el bloque catch evita un bloqueo y permite que la demostración continúe en modo de evaluación.*

### Paso 2: Descubrir documentos admitidos {#step-2-discover-supported-documents}

```csharp
var folder = "./InputDocuments";
var supported = FileType.GetSupportedFileTypes()
    .Select(ft => ft.Extension.ToLowerInvariant())
    .ToHashSet();

var files = Directory.GetFiles(folder, "*.*", SearchOption.AllDirectories)
    .Where(f => supported.Contains(Path.GetExtension(f).ToLowerInvariant()))
    .ToList();

Console.WriteLine($"Found {files.Count} supported file(s).");
```

*El código construye un conjunto de hash con las extensiones informadas por la API y luego filtra el directorio para que solo se devuelvan los archivos procesables.*

### Paso 3: Marca de agua de texto con detección de duplicados {#step-3-duplicate-safe-text-watermark}

```csharp
foreach (var file in files)
{
    using var watermarker = new Watermarker(file);
    var criteria = new TextSearchCriteria("CONFIDENTIAL", false);
    if (watermarker.Search(criteria).Count > 0) continue; // already watermarked

    var textWm = new TextWatermark("CONFIDENTIAL",
        new Font("Arial", 19, FontStyle.Bold))
    {
        ForegroundColor = Color.Red,
        Opacity = 0.3,
        RotateAngle = -30,
        TileOptions = new TileOptions
        {
            LineSpacing = new MeasureValue
            {
                MeasureType = TileMeasureType.Percent,
                Value = 12
            },
            WatermarkSpacing = new MeasureValue
            {
                MeasureType = TileMeasureType.Percent,
                Value = 10
            }
        }
    };
    watermarker.Add(textWm);
    watermarker.Save(Path.Combine("./Output", Path.GetFileName(file)));
}
```

![Text watermark applied to a document](/net/watermark/images/use-cases/batch-watermark-pipeline/1-example-text.png)

*La `TextSearchCriteria` verifica si la frase exacta *CONFIDENCIAL* ya existe. Si es así, se omite el archivo, garantizando que el lote pueda ejecutarse nuevamente de forma segura.*

### Paso 4: Marca de agua del logotipo por lotes {#step-4-batch-logo-watermark}

```csharp
var logoPath = "./Resources/old-logo.png";
foreach (var file in files)
{
    using var watermarker = new Watermarker(file);
    using var imgWm = new ImageWatermark(logoPath)
    {
        Opacity = 0.4,
        RotateAngle = -30,
        TileOptions = new TileOptions
        {
            LineSpacing = new MeasureValue
            {
                MeasureType = TileMeasureType.Percent,
                Value = 15
            },
            WatermarkSpacing = new MeasureValue
            {
                MeasureType = TileMeasureType.Percent,
                Value = 12
            }
        }
    };
    watermarker.Add(imgWm);
    watermarker.Save(Path.Combine("./Output", Path.GetFileName(file)));
}
```

![Tiled logo watermark applied to a document](/net/watermark/images/use-cases/batch-watermark-pipeline/3-example-image.png)

*Una marca de agua de imagen se repite en todas las páginas, utilizando la misma rotación y opacidad que la marca de agua de texto. El ejemplo funciona para archivos PDF, documentos de Office y formatos de imagen comunes.*

### Paso 5: Reemplazar un logotipo obsoleto {#step-5-replace-an-outdated-logo}

```csharp
var oldLogo = "./Resources/old-logo.png";
var newLogo = "./Resources/new-logo.png";
byte[] newData = File.ReadAllBytes(newLogo);

var settings = new WatermarkerSettings
{
    SearchableObjects = new SearchableObjects
    {
        PdfSearchableObjects = PdfSearchableObjects.All
    }
};

foreach (var file in files)
{
    using var watermarker = new Watermarker(file, settings);
    var dct = new ImageDctHashSearchCriteria(oldLogo) { MaxDifference = 0.4 };
    var hist = new ImageColorHistogramSearchCriteria(oldLogo) { MaxDifference = 0.5 };
    var criteria = dct.Or(hist);
    var matches = watermarker.Search(criteria);
    if (matches.Count == 0) continue;

    foreach (var wm in matches)
        wm.ImageData = newData; // swap image bytes

    watermarker.Save(Path.Combine("./Output", Path.GetFileName(file)));
}
```

![Old logo replaced with new logo](/net/watermark/images/use-cases/batch-watermark-pipeline/4-example-logo-replace.png)

*Dos estrategias complementarias de búsqueda de imágenes (hash DCT para precisión, histograma para tolerancia) localizan el antiguo logotipo corporativo tanto en documentos de Office como en archivos PDF. Las marcas de agua coincidentes se sobrescriben con los bytes del nuevo logotipo, lo que permite una rebrandización sin interrupciones.*


:::info
💡 **Consejo:** Ejecute los tres pasos de forma secuencial (texto → logotipo → reemplazar) para simular un flujo de trabajo de migración completo.
:::


## Notas {#notes}

- **Modo de evaluación**: agrega una marca de agua sutil en los archivos de salida; obtenga una licencia válida para eliminarla.
- Los **artefactos PDF** deben agregarse mediante `PdfArtifactWatermarkOptions` (como se muestra en el ayudante *SeedOldLogoSamples*) para que el logotipo sea buscable.
- El ejemplo escribe todos los archivos procesados en `./Output`. Asegúrese de que la carpeta exista o permita que el código la cree automáticamente.
- Los lotes grandes se benefician del paralelismo; los ejemplos son deliberadamente de un solo hilo para mayor claridad.

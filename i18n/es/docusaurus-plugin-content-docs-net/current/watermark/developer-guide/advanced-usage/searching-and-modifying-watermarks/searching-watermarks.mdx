## Búsqueda de marcas de agua posibles {#searching-possible-watermarks}

La API de GroupDocs.Watermark le permite buscar las marcas de agua posibles colocadas en cualquier documento. También puede buscar las marcas de agua agregadas mediante alguna herramienta de terceros. La API proporciona el método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> para buscar marcas de agua en todo el documento o en cualquier parte del mismo. El siguiente fragmento de código muestra cómo encontrar y obtener todas las marcas de agua posibles en un documento.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermark**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search();
    foreach (PossibleWatermark possibleWatermark in possibleWatermarks)
    {
        if (possibleWatermark.ImageData != null)
        {
            Console.WriteLine(possibleWatermark.ImageData.Length);
        }

        Console.WriteLine($"Text {possibleWatermark.Text}");
        Console.WriteLine($"X {possibleWatermark.X}");
        Console.WriteLine($"Y {possibleWatermark.Y}");
        Console.WriteLine($"RotateAngle {possibleWatermark.RotateAngle}");
        Console.WriteLine($"Width {possibleWatermark.Width}");
        Console.WriteLine($"Height {possibleWatermark.Height}");
        Console.WriteLine($"PageNumber {possibleWatermark.PageNumber}");
        Console.WriteLine("");
    }
}
```

## Criterios de búsqueda {#search-criteria}

Por lo general, los documentos grandes pueden contener demasiados objetos que podrían considerarse como marcas de agua. La sobrecarga del método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> sin parámetros devuelve solo algunos de ellos, por ejemplo, fondos u objetos flotantes que podrían haberse agregado durante el posprocesamiento del documento. Puede utilizar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/" target="_blank" rel="nofollow noopener noreferrer">criterios de búsqueda</a> para encontrar objetos que cumplan con ciertos parámetros específicos.

### Criterios de búsqueda por texto {#text-search-criteria}

El siguiente fragmento de código muestra cómo buscar marcas de agua que cumplan con un <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">criterio de texto</a> determinado.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermarkWithSearchString**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    // Search by exact string
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria("Â© 2017");
    // Find all possible watermarks containing some specific text
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(textSearchCriteria);
    Console.WriteLine("Found {0} possible watermark(s)", possibleWatermarks.Count);
}
```

### Criterios de búsqueda con expresiones regulares {#regular-expression-search-criteria}

Las expresiones regulares también son compatibles con <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">TextSearchCriteria</a>. El siguiente código de ejemplo utiliza una expresión regular para buscar marcas de agua.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermarkWithRegularExpression**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    Regex regex = new Regex(@"^Â© \d{4}$");
    // Search by regular expression
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria(regex);
    // Find possible watermarks using regular expression
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(textSearchCriteria);
    Console.WriteLine("Found {0} possible watermark(s).", possibleWatermarks.Count);
}
```


:::info
¿Qué sucede cuando el usuario pasa una instancia de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">TextSearchCriteria</a> al método?

1. Busca fragmentos del texto principal del documento que coincidan con una expresión regular (o que contengan la cadena de búsqueda exacta).
2. Comprueba el texto de otros objetos (formas, XObjects, anotaciones, etc.) para ver si coinciden con la expresión regular (o contienen la cadena de búsqueda exacta).

La búsqueda en el texto principal de un documento solo se realiza si pasa una instancia de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">TextSearchCriteria</a> al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search</a>.
:::


### Criterios de búsqueda de imágenes {#image-search-criteria}

A veces, un documento puede contener marcas de agua de imagen, y es necesario encontrarlas utilizando una imagen de ejemplo. Por ejemplo, es posible que desee encontrar todas las marcas de agua de imagen posibles que sean similares al logotipo de una empresa. El siguiente código de ejemplo busca marcas de agua de imagen que se asemejen a una imagen específica.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchImageWatermark**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    // Initialize criteria with the image
    ImageSearchCriteria imageSearchCriteria = 
        new ImageDctHashSearchCriteria("watermark.jpg");
    //Set maximum allowed difference between images
    imageSearchCriteria.MaxDifference = 0.9;
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(imageSearchCriteria);
    Console.WriteLine("Found {0} possible watermark(s).", possibleWatermarks.Count);
}
```

La propiedad <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/imagesearchcriteria/properties/maxdifference" target="_blank" rel="nofollow noopener noreferrer">MaxDifference</a> se utiliza para establecer la máxima diferencia permitida entre la imagen de muestra y la posible marca de agua. El valor debe estar comprendido entre 0 y 1. Un valor de 0 indica que solo se encontrarán imágenes idénticas.
El uso de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/imagedcthashsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">ImageDctHashSearchCriteria</a> constituye el método más eficiente para detectar marcas de agua en imágenes mediante una muestra. Este criterio emplea una función hash perceptual basada en la Transformada Discreta del Coseno (DCT, por sus siglas en inglés) para comparar la similitud entre imágenes. No obstante, existen otros criterios de búsqueda de imágenes basados en distintos algoritmos:

* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/imagecolorhistogramsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">ImageColorHistogramSearchCriteria</a> utiliza los histogramas de color de la imagen para calcular su similitud. Este criterio es invariante frente a rotaciones, escalados y traslaciones de la imagen.
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/imagethumbnailsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">ImageThumbnailSearchCriteria</a> emplea una miniatura binarizada de la imagen para calcular su similitud. Este criterio es invariante frente a rotaciones, escalados y cambios insignificantes en la paleta de colores.

### Criterios combinados de búsqueda {#combined-search-criteria}

La API de GroupDocs.Watermark también permite buscar marcas de agua mediante una combinación (<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/andsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">And</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/orsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">Or</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/notsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">Not</a>) de distintos criterios de búsqueda. El siguiente fragmento de código muestra cómo buscar una marca de agua utilizando una combinación de distintos criterios de búsqueda.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermarkWithCombinedSearch**

```csharp
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria("logo.png");
    imageSearchCriteria.MaxDifference = 0.9;
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria("Company Name");
    RotateAngleSearchCriteria rotateAngleSearchCriteria = new RotateAngleSearchCriteria(30, 60);
    SearchCriteria combinedSearchCriteria = imageSearchCriteria
        .Or(textSearchCriteria).And(rotateAngleSearchCriteria);
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(combinedSearchCriteria);
    Console.WriteLine("Found {0} possible watermark(s).", possibleWatermarks.Count);
}
```

### Criterios de búsqueda para formato de texto {#text-formatting-search-criteria}

GroupDocs.Watermark también le permite buscar marcas de agua basándose en cierto formato de texto específico. Puede proporcionar un criterio de búsqueda que incluya nombre de fuente, tamaño, color, etc., y la API encontrará las marcas de agua cuyas propiedades coincidan. El siguiente fragmento de código muestra cómo buscar una marca de agua con un determinado <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textformattingsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">formato de texto</a>.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermarkWithParticularTextFormatting**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    TextFormattingSearchCriteria criteria = new TextFormattingSearchCriteria();
    criteria.ForegroundColorRange = new ColorRange();
    criteria.ForegroundColorRange.MinHue = -5;
    criteria.ForegroundColorRange.MaxHue = 10;
    criteria.ForegroundColorRange.MinBrightness = 0.01f;
    criteria.ForegroundColorRange.MaxBrightness = 0.99f;
    criteria.BackgroundColorRange = new ColorRange();
    criteria.BackgroundColorRange.IsEmpty = true;
    criteria.FontName = "Arial";
    criteria.MinFontSize = 19;
    criteria.MaxFontSize = 42;
    criteria.FontBold = true;

    PossibleWatermarkCollection watermarks = watermarker.Search(criteria);

    // The code for working with found watermarks goes here.
    Console.WriteLine("Found {0} possible watermark(s).", watermarks.Count);
}
```

## Búsqueda de marcas de agua en objetos concretos {#searching-watermarks-in-particular-objects}

Esta función le permite especificar qué objetos deben incluirse en la búsqueda de marcas de agua. Al restringir los objetos buscables, puede aumentar significativamente el rendimiento de la búsqueda. El siguiente ejemplo de código muestra cómo configurar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarkersettings/properties/searchableobjects" target="_blank" rel="nofollow noopener noreferrer">objetos buscables</a> de forma global (para todos los documentos que se creen a partir de ese momento).

**AdvancedUsage.SearchAndRemoveWatermarks.SearchWatermarkInParticularObjectsAllInstances**

```csharp
WatermarkerSettings settings = new WatermarkerSettings();
settings.SearchableObjects = new SearchableObjects
    {
        WordProcessingSearchableObjects = WordProcessingSearchableObjects.Hyperlinks | WordProcessingSearchableObjects.Text,
        SpreadsheetSearchableObjects = SpreadsheetSearchableObjects.HeadersFooters,
        PresentationSearchableObjects = PresentationSearchableObjects.SlidesBackgrounds | PresentationSearchableObjects.Shapes,
        DiagramSearchableObjects = DiagramSearchableObjects.None,
        PdfSearchableObjects = PdfSearchableObjects.All
    };

string[] files = { "document.docx", "spreadsheet.xlsx", "presentation.pptx",
                   "diagram.vsdx", "document.pdf" };

foreach (string file in files)
{
    using (Watermarker watermarker = new Watermarker(file, settings))
    {
        PossibleWatermarkCollection watermarks = watermarker.Search();

        // The code for working with found watermarks goes here.
        Console.WriteLine("In {0} found {1} possible watermark(s).", 
            Path.GetFileName(file), watermarks.Count);
    }
}
```

## Búsqueda de marca de agua de texto: omisión de caracteres ilegibles {#searching-text-watermark-skipping-unreadable-characters}

Esta función permite encontrar la marca de agua de texto incluso si contiene caracteres ilegibles entre las letras. El siguiente ejemplo de código muestra cómo <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria/properties/skipunreadablecharacters" target="_blank" rel="nofollow noopener noreferrer">omitar los caracteres ilegibles</a> al buscar la marca de agua.

**AdvancedUsage.SearchAndRemoveWatermarks.SearchTextWatermarkSkippingUnreadableCharacters**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    string watermarkText = "Company name";
    TextSearchCriteria criterion = new TextSearchCriteria(watermarkText);

    // Enable skipping of unreadable characters
    criterion.SkipUnreadableCharacters = true;
    PossibleWatermarkCollection result = watermarker.Search(criterion);

    Console.WriteLine("Found {0} possible watermark(s).", result.Count);
}
```

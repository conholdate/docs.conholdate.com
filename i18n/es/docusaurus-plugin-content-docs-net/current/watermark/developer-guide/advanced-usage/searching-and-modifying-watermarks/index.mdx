La API de GroupDocs.Watermark le permite buscar las posibles marcas de agua colocadas en cualquier documento. También puede buscar las marcas de agua agregadas mediante alguna herramienta de terceros. Las posibles marcas de agua encontradas pueden eliminarse o modificarse sus propiedades. Para obtener más detalles, consulte las siguientes guías:

* [Búsqueda de marcas de agua](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/searching-watermarks/ "Searching watermarks")
* [Modificación de las propiedades de las marcas de agua encontradas](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/modifing-found-watermark-properties/ "Modifing found watermark properties")
* [Eliminación de las marcas de agua encontradas](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/removing-found-watermarks/ "Removing found watermarks")

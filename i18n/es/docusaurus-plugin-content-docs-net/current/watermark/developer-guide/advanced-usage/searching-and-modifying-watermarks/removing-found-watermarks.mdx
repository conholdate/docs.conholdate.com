## Eliminar marca de agua {#remove-watermark}

La API de GroupDocs.Watermark le permite fácilmente <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/search" target="_blank" rel="nofollow noopener noreferrer">find</a> y eliminar una <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search/possiblewatermark" target="_blank" rel="nofollow noopener noreferrer">watermark</a> específica de un documento. El siguiente código cumple con este propósito.

**AdvancedUsage.SearchAndRemoveWatermarks.RemoveWatermark**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search();

    // Remove possible watermark at the specified index from the document.
    possibleWatermarks.RemoveAt(0);

    // Remove specified possible watermark from the document.
    possibleWatermarks.Remove(possibleWatermarks[0]);

    watermarker.Save("document.pdf");
}
```

## Eliminar marca de agua con un formato de texto específico {#remove-watermark-with-particular-text-formatting}

GroupDocs.Watermark también le permite buscar y eliminar las marcas de agua según cierto <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textformattingsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">formato de texto</a>. Puede proporcionar un criterio de búsqueda que incluya <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textformattingsearchcriteria/properties/fontname" target="_blank" rel="nofollow noopener noreferrer">nombre de fuente</a>, tamaño, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textformattingsearchcriteria/properties/foregroundcolorrange" target="_blank" rel="nofollow noopener noreferrer">color</a>, etc., y la API encontrará las marcas de agua que coincidan con dichas propiedades. El siguiente fragmento de código muestra cómo buscar y eliminar marcas de agua con un formato de texto específico.

**AdvancedUsage.SearchAndRemoveWatermarks.RemoveWatermarkWithParticularTextFormatting**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    TextFormattingSearchCriteria criteria = new TextFormattingSearchCriteria();
    criteria.ForegroundColorRange = new ColorRange();
    criteria.ForegroundColorRange.MinHue = -5;
    criteria.ForegroundColorRange.MaxHue = 10;
    criteria.ForegroundColorRange.MinBrightness = 0.01f;
    criteria.ForegroundColorRange.MaxBrightness = 0.99f;
    criteria.BackgroundColorRange = new ColorRange();
    criteria.BackgroundColorRange.IsEmpty = true;
    criteria.FontName = "Arial";
    criteria.MinFontSize = 19;
    criteria.MaxFontSize = 42;
    criteria.FontBold = true;

    PossibleWatermarkCollection watermarks = watermarker.Search(criteria);
    watermarks.Clear();

    watermarker.Save("document.pdf");
}
```

## Eliminar marcas de agua de hipervínculos {#remove-hyperlink-watermarks}

La API de GroupDocs.Watermark le permite buscar y eliminar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search/hyperlinkpossiblewatermark" target="_blank" rel="nofollow noopener noreferrer">hyperlinks</a> en un documento de cualquier formato admitido. El siguiente ejemplo de código muestra cómo buscar y eliminar hipervínculos con una URL específica en un documento.

**AdvancedUsage.SearchAndRemoveWatermarks.RemoveHyperlinksWithParticularUrl**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    PossibleWatermarkCollection watermarks = watermarker.Search(new TextSearchCriteria(new Regex(@"someurl\.com")));
    for (int i = watermarks.Count - 1; i >= 0; i--)
    {
        // Ensure that only hyperlinks will be removed.
        if (watermarks[i] is HyperlinkPossibleWatermark)
        {
            // Output the full url of the hyperlink
            Console.WriteLine(watermarks[i].Text);

            // Remove hyperlink from the document
            watermarks.RemoveAt(i);
        }
    }

    watermarker.Save("document.pdf");
}
```

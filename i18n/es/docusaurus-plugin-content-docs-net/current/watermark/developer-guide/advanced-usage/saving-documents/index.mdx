Al guardar un documento mediante el método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save()</a>, GroupDocs.Watermark lo guarda en la misma carpeta que el archivo original, sobrescribiéndolo. Si necesita guardar el documento en una ubicación personalizada, deberá utilizar el método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> o <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/2" target="_blank" rel="nofollow noopener noreferrer">Save(Stream)</a> de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a>.

Puede ver ejemplos de los métodos <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save</a> en una de estas guías:

* [Guardar documento en el mismo archivo o flujo](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-same-file-or-stream/ "Save document to the same file or stream")
* [Guardar documento en la ubicación especificada](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-specified-location/ "Save document to the specified location")
* [Guardar documento en el flujo especificado](/net/watermark/developer-guide/advanced-usage/saving-documents/save-document-to-the-specified-stream/ "Save document to the specified stream")

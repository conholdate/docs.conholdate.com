Desde la versión 18.6, GroupDocs.Watermark proporciona una forma simplificada de proteger documentos de Word con contraseña. La API permite proteger y desproteger documentos de Word. Los siguientes tipos de protección son compatibles:

* *AllowOnlyRevisions*: el usuario solo puede agregar marcas de revisión al documento.
* *AllowOnlyComments*: el usuario solo puede modificar comentarios en el documento.
* *AllowOnlyFormFields*: el usuario solo puede introducir datos en los campos de formulario del documento.
* *ReadOnly*: no se permiten cambios en el documento.

Los tipos de protección se agregan a la enumeración <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingprotectiontype" target="_blank" rel="nofollow noopener noreferrer">*WordProcessingProtectionType*</a>. Los siguientes ejemplos de código muestran cómo proteger y desproteger documentos de Word.

## Protección de un documento {#protecting-a-document}

El siguiente ejemplo de código <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingcontent/methods/protect" target="_blank" rel="nofollow noopener noreferrer">protects</a> un documento de Word con contraseña.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingProtectDocument**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    content.Protect(WordProcessingProtectionType.ReadOnly, "7654321");
    watermarker.Save("document.docx");
}
```

## Desproteger un documento {#unprotecting-a-document}

El siguiente ejemplo de código muestra cómo <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingcontent/methods/unprotect" target="_blank" rel="nofollow noopener noreferrer">unprotect</a> un documento de Word sin importar la contraseña.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingUnProtectDocument**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    content.Unprotect();
    watermarker.Save("document.docx");
}
```

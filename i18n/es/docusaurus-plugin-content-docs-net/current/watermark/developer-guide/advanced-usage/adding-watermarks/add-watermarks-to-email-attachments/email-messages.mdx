Aprenda cómo agregar una marca de agua en los mensajes de correo electrónico de Outlook
## Modificación del cuerpo y el asunto del mensaje de correo electrónico {#modifying-body-and-subject-of-email-message}

GroupDocs.Watermark también le permite modificar el cuerpo y el asunto de un mensaje de correo electrónico. A continuación se muestra un ejemplo de código para modificar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/body" target="_blank" rel="nofollow noopener noreferrer">body</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/subject" target="_blank" rel="nofollow noopener noreferrer">subject</a> de un mensaje de correo electrónico:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailUpdateEmailBody**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();

    // Set the plain text body
    content.Body = "Test plain text body";

    // Set the html body
    content.HtmlBody = "<html><body>Test html body</body></html>";

    // Set the email subject
    content.Subject = "Test subject";

    // Save changes
    watermarker.Save("message.msg");
}
```

## Incorporación de imágenes en el cuerpo del mensaje de correo electrónico {#embedding-image-to-email-message-body}

GroupDocs.Watermark también ofrece la funcionalidad de incorporar imágenes en el cuerpo del mensaje de correo electrónico. A continuación se muestra un ejemplo de código para incrustar una imagen en un mensaje de correo:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailAddEmbeddedImage**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();

    content.EmbeddedObjects.Add(File.ReadAllBytes("sample.jpg"), "sample.jpg");
    EmailEmbeddedObject embeddedObject = content.EmbeddedObjects[content.EmbeddedObjects.Count - 1];
    content.HtmlBody = string.Format("<html><body>This is an embedded image: <img src=\"cid:{0}\"></body></html>", embeddedObject.ContentId);

    watermarker.Save("message.msg");
}
```

## Eliminar todas las imágenes incrustadas del cuerpo del mensaje de correo electrónico {#removing-all-embedded-images-from-email-message-body}

También puede eliminar las imágenes incrustadas del cuerpo del mensaje de correo electrónico. A continuación se muestra el código para eliminar las imágenes incrustadas:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailRemoveEmbeddedImages**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();
    for (int i = content.EmbeddedObjects.Count - 1; i >= 0; i--)
    {
        if (content.EmbeddedObjects[i].GetDocumentInfo().FileType == FileType.JPEG)
        {
            // Remove reference to the image from html body
            string pattern = string.Format("<img[^>]*src=\"cid:{0}\"[^>]*>", 
                content.EmbeddedObjects[i].ContentId);
            content.HtmlBody = Regex.Replace(content.HtmlBody, pattern, string.Empty);

            // Remove the image
            content.EmbeddedObjects.RemoveAt(i);
        }
    }
    watermarker.Save("message.msg");
}
```

## Búsqueda de texto en el cuerpo o asunto de un mensaje de correo electrónico {#searching-text-in-email-message-body-or-subject}

Con GroupDocs.Watermark, también puede buscar texto tanto en el asunto como en el cuerpo del mensaje de correo electrónico. A continuación se muestra un ejemplo de código para buscar texto en un mensaje de correo electrónico:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailSearchTextInBody**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    SearchCriteria criteria = new TextSearchCriteria("test", false);

    // Specify search locations
    watermarker.SearchableObjects.EmailSearchableObjects = EmailSearchableObjects.Subject 
        | EmailSearchableObjects.HtmlBody | EmailSearchableObjects.PlainTextBody;

    // Note, search is performed only if you pass TextSearchCriteria instance to FindWatermarks method
    PossibleWatermarkCollection watermarks = watermarker.Search(criteria);

    // Remove found text fragments
    watermarks.Clear();

    // Save changes
    watermarker.Save("message.msg");
}
```

## Listado de todos los destinatarios del mensaje {#listing-all-message-recipients}

GroupDocs.Watermark también permite listar todos los destinatarios del mensaje utilizando las propiedades <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/to" target="_blank" rel="nofollow noopener noreferrer">To</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/cc" target="_blank" rel="nofollow noopener noreferrer">Cc</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/bcc" target="_blank" rel="nofollow noopener noreferrer">Bcc</a>, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailListRecipients**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();

    // List all direct recipients
    foreach (EmailAddress address in content.To)
    {
        Console.WriteLine(address.Address);
    }

    // List all CC recipients
    foreach (EmailAddress address in content.Cc)
    {
        Console.WriteLine(address.Address);
    }

    // List all BCC recipients
    foreach (EmailAddress address in content.Bcc)
    {
        Console.WriteLine(address.Address);
    }
}
```

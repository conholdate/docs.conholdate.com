Las marcas de agua en documentos de Word suelen representarse mediante formas. Con la API de GroupDocs.Watermark puede eliminar fácilmente cualquier forma, independientemente de su tipo, desde cualquier nivel de la estructura del documento.

## Eliminar una marca de agua de una sección concreta {#removing-watermark-from-a-particular-section}

Eliminar una marca de agua de una sección específica de un documento de Word mediante GroupDocs.Watermark implica los siguientes pasos:

1. Cargar el documento
2. Crear e inicializar los criterios de búsqueda <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/imagesearchcriteria" target="_blank" rel="nofollow noopener noreferrer">image</a> o <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search.searchcriteria/textsearchcriteria" target="_blank" rel="nofollow noopener noreferrer">text</a>
3. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents/contentpart/methods/search" target="_blank" rel="nofollow noopener noreferrer">Find</a> marcas de agua posibles
4. Eliminar las marcas de agua encontradas
5. Guardar el documento

El siguiente ejemplo de código muestra cómo eliminar una marca de agua de una sección concreta:

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingRemoveWatermarkFromSection**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    // Initialize search criteria
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria("logo.png");
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria("Company Name");

    // Call Search method for the section
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    PossibleWatermarkCollection possibleWatermarks = content.Sections[0].Search(textSearchCriteria.Or(imageSearchCriteria));

    // Remove all found watermarks
    for (int i = possibleWatermarks.Count - 1; i >= 0; i--)
    {
        possibleWatermarks.RemoveAt(i);
    }

    watermarker.Save("document.docx");
}
```

### Buscar un encabezado o pie de página específico {#search-for-particular-header-or-footer}

También puede invocar el método *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents/contentpart/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>* para un <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingheaderfooter" target="_blank" rel="nofollow noopener noreferrer">encabezado o pie de página</a> específico, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingFindWatermarkInHeaderFooter**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    // Initialize search criteria
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria("logo.png");
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria("Company Name");

    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();

        .HeadersFooters[OfficeHeaderFooterType.HeaderPrimary]

    // Remove all found watermarks
    for (int i = possibleWatermarks.Count - 1; i >= 0; i--)
    {
        possibleWatermarks.RemoveAt(i);
    }

    watermarker.Save("document.docx");
}
```

## Extrayendo información sobre todas las formas en un documento de Word {#extracting-information-about-all-shapes-in-a-word-document}

El método *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>* devuelve una colección de instancias *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.search/possiblewatermark" target="_blank" rel="nofollow noopener noreferrer">PossibleWatermark</a>* para todos los tipos de documentos. Sin embargo, en algunos casos, es necesario obtener más información sobre las formas de Word de la que ofrece la API común. GroupDocs.Watermark le permite extraer la información sobre todas las <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingsection/properties/shapes" target="_blank" rel="nofollow noopener noreferrer">shapes</a>, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingGetShapesInformation**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    foreach (WordProcessingSection section in content.Sections)
    {
        foreach (WordProcessingShape shape in section.Shapes)
        {
            if (shape.HeaderFooter != null)
            {
                Console.WriteLine("In header/footer");
            }

            Console.WriteLine(shape.ShapeType);
            Console.WriteLine(shape.Width);
            Console.WriteLine(shape.Height);
            Console.WriteLine(shape.IsWordArt);
            Console.WriteLine(shape.RotateAngle);
            Console.WriteLine(shape.AlternativeText);
            Console.WriteLine(shape.Name);
            Console.WriteLine(shape.X);
            Console.WriteLine(shape.Y);
            Console.WriteLine(shape.Text);

            if (shape.Image != null)
            {
                Console.WriteLine(shape.Image.Width);
                Console.WriteLine(shape.Image.Height);
                Console.WriteLine(shape.Image.GetBytes().Length);
            }

            Console.WriteLine(shape.HorizontalAlignment);
            Console.WriteLine(shape.VerticalAlignment);
            Console.WriteLine(shape.RelativeHorizontalPosition);
            Console.WriteLine(shape.RelativeVerticalPosition);
        }
    }
}
```

## Trabajo con tipos de formas {#working-with-shape-types}

Puede extraer información sobre las formas existentes de tipos particulares. El enum *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshapetype" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Watermark.Contents.WordProcessing.WordProcessingShapeType</a>* está disponible para verificar los tipos de formas posiblemente disponibles.

El siguiente fragmento de código demuestra el uso del enum *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshapetype" target="_blank" rel="nofollow noopener noreferrer">WordProcessingShapeType</a>*.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingShapeTypeUsage**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    foreach (WordProcessingSection section in content.Sections)
    {
        foreach (WordProcessingShape shape in section.Shapes)
        {
            //Check for Diagonal Corners Rounded shapes
            if (shape.ShapeType == WordProcessingShapeType.DiagonalCornersRounded)
            {
                Console.WriteLine("Diagonal Corners Rounded shape found");

                //Write text on all Diagonal Corners Rounded shapes
                shape.FormattedTextFragments.Add("I am Diagonal Corner Rounded", new Font("Calibri", 8, FontStyle.Bold), Color.Red, Color.Aqua);
            }
        }
    }

    watermarker.Save("document.docx");
}
```

## Eliminación de una forma específica {#removing-a-particular-shape}

También puede eliminar una <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape" target="_blank" rel="nofollow noopener noreferrer">shape</a> específica de un documento de Word, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingRemoveShape**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();

    // Remove shape by index
    content.Sections[0].Shapes.RemoveAt(0);

    // Remove shape by reference

    watermarker.Save("document.docx");
}
```

## Eliminación de formas con un formato de texto específico {#removing-shapes-with-particular-text-formatting}

También puede buscar y eliminar las formas que tengan un <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/formattedtextfragments" target="_blank" rel="nofollow noopener noreferrer">formato de texto específico</a> en un documento de Word, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingRemoveShapesWithParticularTextFormatting**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();
    foreach (WordProcessingSection section in content.Sections)
    {
        for (int i = section.Shapes.Count - 1; i >= 0; i--)
        {
            foreach (FormattedTextFragment fragment in section.Shapes[i].FormattedTextFragments)
            {
                if (fragment.ForegroundColor == Color.Red && fragment.Font.FamilyName == "Arial")
                {
                    section.Shapes.RemoveAt(i);
                    break;
                }
            }
        }
    }

    watermarker.Save("document.docx");
}
```

## Eliminación o sustitución del hipervínculo asociado a una forma específica {#removing-or-replacing-hyperlink-associated-with-a-particular-shape}

Con GroupDocs.Watermark para .NET, también puede eliminar o sustituir <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/hyperlink" target="_blank" rel="nofollow noopener noreferrer">hyperlink</a> asociados a una forma específica dentro de un documento de Word. Utilice el siguiente ejemplo de código para lograr esta funcionalidad.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingRemoveHyperlinks**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();

    // Replace hyperlink
    content.Sections[0].Shapes[0].Hyperlink = "https://www.groupdocs.com/";

    // Remove hyperlink
    content.Sections[0].Shapes[1].Hyperlink = null;

    watermarker.Save("document.docx");
}
```

## Reemplazar texto para formas específicas {#replacing-text-for-particular-shapes}

### Reemplazar el texto de una forma {#replacing-shape-s-text}

GroupDocs.Watermark permite reemplazar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/text" target="_blank" rel="nofollow noopener noreferrer">text</a> para formas específicas en un documento de Word. El siguiente ejemplo de código muestra el uso de esta funcionalidad.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingReplaceTextForParticularShape**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();

    // Set shape's text
    foreach (WordProcessingShape shape in content.Sections[0].Shapes)
    {
        if (shape.Text.Contains("Some text"))
        {
            shape.Text = "Another text";
        }
    }

    // Save document
    watermarker.Save("document.docx");
}
```

## Modificación de propiedades de formas {#modifying-shape-properties}

GroupDocs.Watermark también ofrece la funcionalidad para modificar propiedades (<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/alternativetext" target="_blank" rel="nofollow noopener noreferrer">AlternativeText</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/rotateangle" target="_blank" rel="nofollow noopener noreferrer">RotateAngle</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/x" target="_blank" rel="nofollow noopener noreferrer">X</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/y" target="_blank" rel="nofollow noopener noreferrer">Y</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> o <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.wordprocessing/wordprocessingshape/properties/behindtext" target="_blank" rel="nofollow noopener noreferrer">BehindText</a>) de formas específicas en un documento de Word. El siguiente ejemplo de código muestra cómo utilizar esta funcionalidad.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingModifyShapeProperties**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    WordProcessingContent content = watermarker.GetContent<WordProcessingContent>();

    // Change shape properties
    foreach (WordProcessingShape shape in content.Sections[0].Shapes)
    {
        if (shape.Text.Contains("Some text"))
        {
            shape.AlternativeText = "watermark";
            shape.RotateAngle = 30;
            shape.X = 200;
            shape.Y = 200;
            shape.Height = 100;
            shape.Width = 400;
            shape.BehindText = false;
        }
    }

    // Save document
    watermarker.Save("document.docx");
}
```

Descubra las distintas formas en que Groupdocs.watermark puede agregar marcas de agua en documentos PDF.

## XObjects {#xobjects}

Cuando se invoca el método *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>* de la clase *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a>*, se agrega un XObject simple al documento PDF.


:::info
**Referencia de PDF 1.7**  

Un objeto externo (comúnmente denominado XObject) es un objeto gráfico cuyo contenido está definido por un flujo de contenido independiente y autocontenido, distinto del flujo de contenido en el que se utiliza. Existen tres tipos de objetos externos:

* Un XObject de imagen representa una imagen visual muestreada, como una fotografía.
* Un XObject de forma es una descripción autocontenido de una secuencia arbitraria de objetos gráficos.
* Un XObject de PostScript contiene un fragmento de código expresado en el lenguaje de descripción de páginas PostScript. Los XObjects de PostScript ya no se recomiendan.
:::


Los objetos X de imagen y los objetos X de formulario se utilizan en la API de GroupDocs.Watermark para agregar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark" target="_blank" rel="nofollow noopener noreferrer">TextWatermark</a>, respectivamente. Los objetos X se consideran como el contenido real de la página; por lo tanto, no se eliminan con Adobe Acrobat durante la limpieza del documento.

## Artefactos {#artifacts}


:::info
**Referencia de PDF 1.7**
Los objetos gráficos de un documento pueden dividirse en dos clases:

* El contenido real de un documento comprende objetos que representan el material originalmente introducido por el autor del documento.
* Los artefactos son objetos gráficos que, por lo general, no forman parte del contenido original del autor, sino que son generados por la aplicación productora de PDF durante los procesos de paginación, diseño u otros procesos estrictamente mecánicos. Asimismo, los artefactos pueden utilizarse para describir áreas del documento en las que el autor emplea un fondo gráfico con el fin de mejorar la experiencia visual. En tal caso, el fondo no es necesario para comprender el contenido.
:::


Según la definición del artefacto, la marca de agua puede representarse mediante un artefacto en un documento PDF. El siguiente ejemplo muestra cómo agregar una marca de agua de artefacto a un documento con GroupDocs.Watermark utilizando <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.pdf/pdfartifactwatermarkoptions" target="_blank" rel="nofollow noopener noreferrer">PdfArtifactWatermarkOptions</a>.

**AdvancedUsage.AddingWatermarks.AddWatermarksToPdf.PdfAddArtifactWatermark**

```csharp
PdfLoadOptions loadOptions = new PdfLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf", loadOptions))
{
    PdfArtifactWatermarkOptions options = new PdfArtifactWatermarkOptions();
    // Add text watermark
    TextWatermark textWatermark = new TextWatermark("This is an artifact watermark", 
        new Font("Arial", 8));
    textWatermark.HorizontalAlignment = HorizontalAlignment.Right;
    watermarker.Add(textWatermark, options);
    // Add image watermark
    using (ImageWatermark imageWatermark = new ImageWatermark("logo.bmp"))
    {
        watermarker.Add(imageWatermark, options);
    }
    watermarker.Save("document.pdf");
}
```

## Anotaciones {#annotations}


:::info
**Referencia de PDF 1.7**
Una anotación asocia un objeto, como una nota, un sonido o una película, con una ubicación específica en una página de un documento PDF, o proporciona una forma de interactuar con el usuario mediante el ratón y el teclado. PDF incluye una amplia variedad de tipos estándar de anotaciones.
Una anotación de marca de agua (PDF 1.6) se utiliza para representar gráficos que se espera se impriman en un tamaño y posición fijos en una página, independientemente de las dimensiones de la página impresa.
:::


La anotación es el tercer tipo de entidades PDF mediante el cual se puede representar una marca de agua. Utilice el siguiente fragmento de código para agregar una anotación de marca de agua a un documento PDF mediante <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.pdf/pdfannotationwatermarkoptions" target="_blank" rel="nofollow noopener noreferrer">PdfAnnotationWatermarkOptions</a>.

**AdvancedUsage.AddingWatermarks.AddWatermarksToPdf.PdfAddAnnotationWatermark**

```csharp
PdfLoadOptions loadOptions = new PdfLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf", loadOptions))
{
    PdfAnnotationWatermarkOptions options = new PdfAnnotationWatermarkOptions();
    // Add text watermark
    TextWatermark textWatermark = new TextWatermark("This is a annotation watermark", 
        new Font("Arial", 8));
    textWatermark.HorizontalAlignment = HorizontalAlignment.Left;
    textWatermark.VerticalAlignment = VerticalAlignment.Top;
    watermarker.Add(textWatermark, options);
    // Add image watermark
    using (ImageWatermark imageWatermark = new ImageWatermark("protect.jpg"))
    {
        imageWatermark.HorizontalAlignment = HorizontalAlignment.Right;
        imageWatermark.VerticalAlignment = VerticalAlignment.Top;
        watermarker.Add(imageWatermark, options);
    }

    watermarker.Save("document.pdf");
}
```

## Anotaciones solo para impresión {#print-only-annotations}

También puede agregar una marca de agua de anotación solo para impresión al documento configurando la propiedad <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.pdf/pdfannotationwatermarkoptions/properties/printonly" target="_blank" rel="nofollow noopener noreferrer">PrintOnly</a> de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.pdf/pdfannotationwatermarkoptions" target="_blank" rel="nofollow noopener noreferrer">PdfAnnotationWatermarkOptions</a>. El siguiente código demuestra este enfoque.

**AdvancedUsage.AddingWatermarks.AddWatermarksToPdf.PdfAddPrintOnlyAnnotationWatermark**

```csharp
PdfLoadOptions loadOptions = new PdfLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.pdf"
using (Watermarker watermarker = new Watermarker("document.pdf", loadOptions))
{
    TextWatermark textWatermark = new TextWatermark("This is a print only test watermark. It won't appear in view mode.", new Font("Arial", 8));
    bool isPrintOnly = true;

    // Annotation will be printed, but not displayed in pdf viewing application
    PdfAnnotationWatermarkOptions options = new PdfAnnotationWatermarkOptions();
    options.PageIndex = 0;
    options.PrintOnly = isPrintOnly;

    watermarker.Add(textWatermark, options);
    watermarker.Save("document.pdf");
}
```

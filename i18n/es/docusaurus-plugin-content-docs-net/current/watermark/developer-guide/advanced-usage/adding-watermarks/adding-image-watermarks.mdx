La API de GroupDocs.Watermark admite la adición de los siguientes tipos de archivos de imagen como marca de agua de imagen:

* BMP;
* PNG;
* GIF;
* JPEG.

## Agregar marca de agua de imagen desde un archivo local {#add-image-watermark-from-local-file}

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a> a un documento. Si el documento consta de varias partes (páginas, hojas de cálculo, diapositivas, marcos, etc.), la marca de agua se agregará a cada una de ellas.

**AdvancedUsage.AddingImageWatermarks.AddImageWatermark**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx"))
{
    // Use path to the image as constructor parameter
    using (ImageWatermark watermark = new ImageWatermark("watermark.jpg"))
    {
        // Add watermark to the document
        watermarker.Add(watermark);

        watermarker.Save("presentation.pptx");
    }
}
```

## Agregar marca de agua de imagen desde un flujo {#add-image-watermark-from-stream}

También puede utilizar un flujo de la imagen para inicializar la instancia de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a>, como se muestra en el ejemplo siguiente.

**AdvancedUsage.AddingImageWatermarks.AddImageWatermarkUsingStream**

```csharp
// Specify an absolute or relative path to the watermark image. Ex: @"C:\Docs\watermark.jpg"
using (Stream watermarkStream = File.OpenRead("watermark.jpg"))
{
    using (Watermarker watermarker = new Watermarker("image.png"))
    {
        // Use stream containing an image as constructor parameter
        using (ImageWatermark watermark = new ImageWatermark(watermarkStream))
        {
            // Add watermark to the document
            watermarker.Add(watermark);

            watermarker.Save("image.png");
        }
    }
}
```


:::warning
La clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a> implementa la interfaz <a href="https://docs.microsoft.com/en-us/dotnet/api/system.idisposable" target="_blank" rel="nofollow noopener noreferrer">IDisposable</a>. Por lo tanto, es necesario llamar al método <a href="https://docs.microsoft.com/en-us/dotnet/api/system.idisposable.dispose" target="_blank" rel="nofollow noopener noreferrer">Dispose</a> cuando haya terminado de trabajar con la marca de agua. Como alternativa, puede utilizar la instrucción <a href="https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/using-statement" target="_blank" rel="nofollow noopener noreferrer">using</a>.
:::

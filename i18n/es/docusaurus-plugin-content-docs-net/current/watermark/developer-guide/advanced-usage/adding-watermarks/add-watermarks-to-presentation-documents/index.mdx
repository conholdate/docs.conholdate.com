Este artículo describe un conjunto de métodos para agregar marcas de agua a presentaciones de PowerPoint.
Como demostración, puede probar <a href="https://products.groupdocs.app/watermark/ppt" target="_blank" rel="nofollow noopener noreferrer">agregar una marca de agua a una presentación de PowerPoint</a> con nuestra aplicación en línea, desarrollada sobre GroupDocs.Watermark para .NET.

## Agregar una marca de agua a una diapositiva específica {#adding-watermark-to-a-particular-slide}

Con GroupDocs.Watermark, puede agregar una marca de agua a una diapositiva específica de una presentación de PowerPoint de forma sencilla. El proceso de agregar una marca de agua a una diapositiva concreta de una presentación de PowerPoint mediante GroupDocs.Watermark consta de los siguientes pasos:

1. Cargar el documento
2. Crear e inicializar el objeto de marca de agua
3. Establecer las propiedades de la marca de agua
4. Configurar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkslideoptions/properties/slideindex" target="_blank" rel="nofollow noopener noreferrer">SlideIndex</a> de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkslideoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationWatermarkSlideOptions</a>
5. Agregar la marca de agua al documento
6. Guardar el documento

El siguiente código muestra cómo agregar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark" target="_blank" rel="nofollow noopener noreferrer">TextWatermark</a> a la primera diapositiva y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a> a la segunda diapositiva.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />ToSlide**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    // Add text watermark to the first slide
    TextWatermark textWatermark = new TextWatermark("Test watermark", new Font("Arial", 8));
    PresentationWatermarkSlideOptions textWatermarkOptions = new PresentationWatermarkSlideOptions();
    textWatermarkOptions.SlideIndex = 0;
    watermarker.Add(textWatermark, textWatermarkOptions);

    // Add image watermark to the second slide
    using (ImageWatermark imageWatermark = new ImageWatermark("logo.jpg"))
    {
        PresentationWatermarkSlideOptions imageWatermarkOptions = new PresentationWatermarkSlideOptions();
        imageWatermarkOptions.SlideIndex = 1;
        watermarker.Add(imageWatermark, imageWatermarkOptions);
    }

    watermarker.Save("presentation.pptx");
}
```

## Protección de la marca de agua mediante caracteres no legibles {#protecting-watermark-using-unreadable-characters}

Esta función permite reforzar la protección de la marca de agua de texto. El uso de caracteres no legibles en el texto de la marca de agua impide su modificación mediante el cuadro de diálogo Buscar y reemplazar. El siguiente ejemplo de código muestra cómo incluir caracteres no legibles en el texto de la marca de agua utilizando las propiedades <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkbaseslideoptions/properties/islocked" target="_blank" rel="nofollow noopener noreferrer">IsLocked</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkbaseslideoptions/properties/protectwithunreadablecharacters" target="_blank" rel="nofollow noopener noreferrer">ProtectWithUnreadableCharacters</a> de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkslideoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationWatermarkSlideOptions</a>.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationProtectWatermark<wbr />UsingUnreadableCharacters**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Watermark text", new Font("Arial", 19));
    PresentationWatermarkSlideOptions options = new PresentationWatermarkSlideOptions();
    options.IsLocked = true;
    options.ProtectWithUnreadableCharacters = true;

    // Add watermark
    watermarker.Add(watermark, options);

    // Save document
    watermarker.Save("presentation.pptx");
}
```

## Agregar marca de agua a todas las imágenes dentro de una diapositiva específica {#add-watermark-to-all-images-inside-a-particular-slide}

GroupDocs.Watermark le permite agregar una marca de agua a las imágenes dentro de una diapositiva específica de PowerPoint mediante el método *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.image/watermarkableimage/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>*, como se muestra en el ejemplo siguiente.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />ToSlideImages**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Protected image", new Font("Arial", 8));
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    watermark.RotateAngle = 45;
    watermark.SizingType = SizingType.ScaleToParentDimensions;
    watermark.ScaleFactor = 1;

    // Get all images from the first slide
    PresentationContent content = watermarker.GetContent<PresentationContent>();
    WatermarkableImageCollection images = content.Slides[0].FindImages();

    // Add watermark to all found images
    foreach (WatermarkableImage image in images)
    {
        image.Add(watermark);
    }

    watermarker.Save("presentation.pptx");
}
```

## Trabajo con plantillas, diseños y notas {#working-with-masters-layouts-and-notes}

GroupDocs.Watermark le permite acceder a todos los tipos de diapositivas de servicio en una presentación de PowerPoint. Las siguientes propiedades de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationcontent" target="_blank" rel="nofollow noopener noreferrer">PresentationContent</a> permiten acceder a los distintos tipos de diapositivas mediante la API

* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationcontent/properties/masterslides" target="_blank" rel="nofollow noopener noreferrer">MasterSlides</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationcontent/properties/layoutslides" target="_blank" rel="nofollow noopener noreferrer">LayoutSlides</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationcontent/properties/masterhandoutslide" target="_blank" rel="nofollow noopener noreferrer">MasterHandoutSlide</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationcontent/properties/masternotesslide" target="_blank" rel="nofollow noopener noreferrer">MasterNotesSlide</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationslide/properties/notesslide" target="_blank" rel="nofollow noopener noreferrer">NoteSlide</a> (propiedad de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationslide" target="_blank" rel="nofollow noopener noreferrer">PresentationSlide</a>)

El siguiente código muestra cómo acceder a cada tipo de diapositiva en una presentación de PowerPoint.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />ToAllSlideTypes**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 8));
    PresentationContent content = watermarker.GetContent<PresentationContent>();

    // Add watermark to all master slides
    PresentationWatermarkMasterSlideOptions masterSlideOptions = new PresentationWatermarkMasterSlideOptions();
    masterSlideOptions.MasterSlideIndex = -1;
    watermarker.Add(watermark, masterSlideOptions);

    // Add watermark to all layout slides
    if (content.LayoutSlides != null)
    {
        PresentationWatermarkLayoutSlideOptions layoutSlideOptions = new PresentationWatermarkLayoutSlideOptions();
        layoutSlideOptions.LayoutSlideIndex = -1;
        watermarker.Add(watermark, masterSlideOptions);
    }

    // Add watermark to all notes slides
    for (int i = 0; i < content.Slides.Count; i++)
    {
        if (content.Slides[i].NotesSlide != null)
        {
            PresentationWatermarkNoteSlideOptions noteSlideOptions = new PresentationWatermarkNoteSlideOptions();
            noteSlideOptions.SlideIndex = i;
            watermarker.Add(watermark, noteSlideOptions);
        }
    }

    // Add watermark to handout master
    if (content.MasterHandoutSlide != null)
    {
        PresentationWatermarkMasterHandoutSlideOptions handoutSlideOptions = new PresentationWatermarkMasterHandoutSlideOptions();
        watermarker.Add(watermark, handoutSlideOptions);
    }

    // Add watermark to notes master
    if (content.MasterNotesSlide != null)
    {
        PresentationWatermarkMasterNotesSlideOptions masterNotesSlideOptions = new PresentationWatermarkMasterNotesSlideOptions();
        watermarker.Add(watermark, masterNotesSlideOptions);
    }

    watermarker.Save("presentation.pptx");
}
```

## ¿Qué es una marca de agua en PowerPoint? {#what-is-watermark-in-powerpoint}

Cuando se invoca el método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a> con un documento de presentación cargado, se agrega una forma sencilla al documento de PowerPoint. GroupDocs.Watermark ofrece algunas opciones adicionales al agregar una marca de agua en forma de forma. Utilice las clases descendientes de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationwatermarkbaseslideoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationWatermarkBaseSlideOptions</a> para configurar estas opciones, como se muestra en el ejemplo siguiente.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />WithSlidesShapeSettings**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 19));
    watermark.IsBackground = true;

    PresentationWatermarkSlideOptions options = new PresentationWatermarkSlideOptions();

    // Set the shape name
    options.Name = "Shape 1";

    // Set the descriptive (alternative) text that will be associated with the shape
    options.AlternativeText = "Test watermark";

    // Editing of the shape in PowerPoint is forbidden
    options.IsLocked = true;

    watermarker.Add(watermark, options);
    watermarker.Save("presentation.pptx");
}
```

### Aplicar efectos de texto {#applying-text-effects}

También puede aplicar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationtexteffects" target="_blank" rel="nofollow noopener noreferrer">efectos de texto</a> al agregar una marca de agua con forma en una diapositiva de PowerPoint.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />WithTextEffects**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Segoe UI", 19));

    PresentationTextEffects effects = new PresentationTextEffects();
    effects.LineFormat.Enabled = true;
    effects.LineFormat.Color = Color.Red;
    effects.LineFormat.DashStyle = OfficeDashStyle.DashDotDot;
    effects.LineFormat.LineStyle = OfficeLineStyle.Triple;
    effects.LineFormat.Weight = 1;

    PresentationWatermarkSlideOptions options = new PresentationWatermarkSlideOptions();
    options.Effects = effects;

    watermarker.Add(watermark, options);
    watermarker.Save("presentation.pptx");
}
```


:::warning
La configuración de formato de línea no está soportada para presentaciones de PPT en este momento.
:::


### Aplicación de efectos de imagen {#applying-image-effects}

La API también le permite aplicar <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.presentation/presentationimageeffects" target="_blank" rel="nofollow noopener noreferrer">efectos de imagen</a> a la marca de agua en forma utilizando el siguiente código.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermark<wbr />WithImageEffects**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    using (ImageWatermark watermark = new ImageWatermark("logo.png"))
    {
        PresentationImageEffects effects = new PresentationImageEffects();
        effects.Brightness = 0.7;
        effects.Contrast = 0.6;
        effects.ChromaKey = Color.Red;
        effects.BorderLineFormat.Enabled = true;
        effects.BorderLineFormat.Weight = 1;

        PresentationWatermarkSlideOptions options = new PresentationWatermarkSlideOptions();
        options.Effects = effects;

        watermarker.Add(watermark, options);
    }

    watermarker.Save("presentation.pptx");
}
```

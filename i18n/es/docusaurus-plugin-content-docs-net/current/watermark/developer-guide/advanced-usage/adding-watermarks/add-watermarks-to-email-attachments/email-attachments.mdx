## Extraer todos los adjuntos de un mensaje de correo electrónico {#extracting-all-attachments-from-email-message}

GroupDocs.Watermark le permite obtener información sobre los <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailcontent/properties/attachments" target="_blank" rel="nofollow noopener noreferrer">attachments</a> en un mensaje de correo electrónico. A continuación se muestra un fragmento de código para extraer adjuntos de correo electrónico.

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailExtractAllAttachments**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();
    foreach (EmailAttachment attachment in content.Attachments)
    {
        Console.WriteLine("Name: {0}", attachment.Name);
        Console.WriteLine("File format: {0}", attachment.GetDocumentInfo().FileType);
        File.WriteAllBytes(Path.Combine("SampleFiles\Output", attachment.Name), attachment.Content);
    }
}
```

## Eliminación de un adjunto específico de un mensaje de correo electrónico {#removing-particular-attachment-from-email-message}

Con GroupDocs.Watermark, puede <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common.removeonlylistbase/1/methods/removeat" target="_blank" rel="nofollow noopener noreferrer">remove</a> eliminar cualquier adjunto específico de un mensaje de correo electrónico. A continuación se muestra el código para eliminar un adjunto determinado:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailRemoveAttachment**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();
    for (int i = content.Attachments.Count - 1; i >= 0; i--)
    {
        EmailAttachment attachment = content.Attachments[i];

        // Remove all attached files with a particular name and format
        if (attachment.Name.Contains("sample") && attachment.GetDocumentInfo().FileType == FileType.DOCX)
        {
            content.Attachments.RemoveAt(i);
        }
    }

    // Save changes
    watermarker.Save("message.msg");
}
```

## Agregar archivo adjunto a un mensaje de correo electrónico {#adding-attachment-to-email-message}

También puede <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.email/emailattachmentcollection/methods/add" target="_blank" rel="nofollow noopener noreferrer">add</a> archivos adjuntos a los mensajes de correo electrónico utilizando GroupDocs.Watermark. A continuación se muestra un ejemplo de código para agregar un archivo adjunto:

**AdvancedUsage.AddingWatermarks.AddWatermarksToEmailAttachments.EmailAddAttachment**

```csharp
EmailLoadOptions loadOptions = new EmailLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\message.msg"
using (Watermarker watermarker = new Watermarker("message.msg", loadOptions))
{
    EmailContent content = watermarker.GetContent<EmailContent>();
    content.Attachments.Add(File.ReadAllBytes("sample.msg"), "sample.msg");

    // Save changes
    watermarker.Save("message.msg");
}
```

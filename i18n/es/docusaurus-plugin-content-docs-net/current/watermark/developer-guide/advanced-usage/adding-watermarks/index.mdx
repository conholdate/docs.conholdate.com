GroupDocs.Watermark para .NET admite los siguientes tipos de marcas de agua.

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark" target="_blank" rel="nofollow noopener noreferrer">TextWatermark</a>
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a>

La adición de una marca de agua a cualquier formato de documento admitido mediante GroupDocs.Watermark consta de algunos pasos sencillos. A continuación se indican los pasos para agregar una marca de agua a un documento.

1. Cargar el documento
2. Crear e inicializar el objeto de marca de agua
3. Establecer las propiedades de la marca de agua
4. Agregar la marca de agua al documento
5. Guardar el documento

Al agregar una marca de agua en la aplicación de Microsoft Word, se coloca una forma con el contenido adecuado en los encabezados de sección. La API de GroupDocs.Watermark utiliza el mismo enfoque. Al llamar al método *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>* de la clase *<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a>*, la forma se agrega al documento.

## Uso de las propiedades de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.wordprocessing/wordprocessingwatermarkbaseoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingWatermarkBaseOptions</a> {#using-properties-of-wordprocessingwatermarkbaseoptions}

También puede configurar algunas opciones adicionales (<a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.wordprocessing/wordprocessingwatermarkbaseoptions/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> o <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.wordprocessing/wordprocessingwatermarkbaseoptions/properties/alternativetext" target="_blank" rel="nofollow noopener noreferrer">AlternativeText</a>) al agregar una marca de agua en forma a un documento de Word mediante GroupDocs.Watermark. Los siguientes ejemplos de código lo demuestran.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingAddWatermarkWithShapeSettings**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 19));

    //Some settings for watermark
    watermark.VerticalAlignment = VerticalAlignment.Center;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.RotateAngle = 25.0;
    watermark.ForegroundColor = Color.Red;
    watermark.Opacity = 1.0;

    WordProcessingWatermarkSectionOptions options = new WordProcessingWatermarkSectionOptions();

    // Set the shape name
    options.Name = "Shape 1";

    // Set the descriptive (alternative) text that will be associated with the shape
    options.AlternativeText = "Test watermark";

    watermarker.Add(watermark, options);
    watermarker.Save("document.docx");
}
```

## Uso de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.wordprocessing/wordprocessingtexteffects" target="_blank" rel="nofollow noopener noreferrer">WordProcessingTextEffects</a> {#using-wordprocessingtexteffects}

También puede aplicar algunos efectos de texto a las marcas de agua en forma, como se muestra en el siguiente código.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingAddWatermarkWithTextEffects**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 19));

    WordProcessingTextEffects effects = new WordProcessingTextEffects();
    effects.LineFormat.Enabled = true;
    effects.LineFormat.Color = Color.Red;
    effects.LineFormat.DashStyle = OfficeDashStyle.DashDotDot;
    effects.LineFormat.LineStyle = OfficeLineStyle.Triple;
    effects.LineFormat.Weight = 1;

    WordProcessingWatermarkSectionOptions options = new WordProcessingWatermarkSectionOptions();
    options.Effects = effects;

    watermarker.Add(watermark, options);
    watermarker.Save("document.docx");
}
```

## Uso de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options.wordprocessing/wordprocessingimageeffects" target="_blank" rel="nofollow noopener noreferrer">WordProcessingImageEffects</a> {#using-wordprocessingimageeffects}

GroupDocs.Watermark también ofrece la posibilidad de aplicar efectos de imagen a las marcas de agua en forma de forma.

**AdvancedUsage.AddingWatermarks.AddWatermarksToWordProcessing.WordProcessingAddWatermarkWithImageEffects**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\document.docx"
using (Watermarker watermarker = new Watermarker("document.docx", loadOptions))
{
    using (ImageWatermark watermark = new ImageWatermark("logo.png"))
    {
        WordProcessingImageEffects effects = new WordProcessingImageEffects();
        effects.Brightness = 0.7;
        effects.Contrast = 0.6;
        effects.ChromaKey = Color.Red;
        effects.BorderLineFormat.Enabled = true;
        effects.BorderLineFormat.Weight = 1;

        WordProcessingWatermarkSectionOptions options = new WordProcessingWatermarkSectionOptions();
        options.Effects = effects;

        watermarker.Add(watermark, options);
    }

    watermarker.Save("document.docx");
}
```

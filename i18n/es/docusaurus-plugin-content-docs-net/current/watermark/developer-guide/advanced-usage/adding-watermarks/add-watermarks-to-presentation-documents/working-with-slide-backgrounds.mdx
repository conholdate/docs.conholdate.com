La API le permite extraer información sobre todos los fondos de diapositivas, eliminar un fondo específico y agregar una marca de agua a todas las imágenes de fondo.

## Extracción de información sobre todos los fondos de diapositivas {#extracting-information-about-all-slide-backgrounds}

La API le permite extraer información sobre todos los fondos de diapositivas en un documento de PowerPoint, como se muestra en el siguiente ejemplo de código utilizando la propiedad <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationimagefillformat/properties/backgroundimage" target="_blank" rel="nofollow noopener noreferrer">BackgroundImage</a> de <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationbaseslide/properties/imagefillformat" target="_blank" rel="nofollow noopener noreferrer">PresentationSlide.ImageFillFormat</a>.

**AdvancedUsage.AddingWatermarks.AddWatermarksToPresentations.PresentationGetSlideBackgroundsInformation**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    PresentationContent content = watermarker.GetContent<PresentationContent>();
    foreach (PresentationSlide slide in content.Slides)
    {
        if (slide.ImageFillFormat.BackgroundImage != null)
        {
            Console.WriteLine(slide.ImageFillFormat.BackgroundImage.Width);
            Console.WriteLine(slide.ImageFillFormat.BackgroundImage.Height);
            Console.WriteLine(slide.ImageFillFormat.BackgroundImage.GetBytes().Length);
        }
    }
}
```

## Eliminación de un fondo específico {#removing-a-particular-background}

El siguiente ejemplo de código muestra cómo eliminar la imagen de fondo de una diapositiva específica estableciendo la propiedad <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationimagefillformat/properties/backgroundimage" target="_blank" rel="nofollow noopener noreferrer">BackgroundImage</a> en `null`.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationRemoveSlideBackground**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    PresentationContent content = watermarker.GetContent<PresentationContent>();
    content.Slides[0].ImageFillFormat.BackgroundImage = null;

    watermarker.Save("presentation.pptx");
}
```

## Añadir marca de agua a todas las imágenes de fondo {#adding-watermark-to-all-background-images}

Con GroupDocs.Watermark, también puede <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.image/watermarkableimage/methods/add" target="_blank" rel="nofollow noopener noreferrer">add</a> añadir una marca de agua a las imágenes de fondo pertenecientes a un documento de PowerPoint, como se muestra en el siguiente ejemplo de código.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationAddWatermarkToSlideBackgroundImages**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    // Initialize image or text watermark
    TextWatermark watermark = new TextWatermark("Protected image", new Font("Arial", 8));
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    watermark.RotateAngle = 45;
    watermark.SizingType = SizingType.ScaleToParentDimensions;
    watermark.ScaleFactor = 1;

    PresentationContent content = watermarker.GetContent<PresentationContent>();
    foreach (PresentationSlide slide in content.Slides)
    {
        if (slide.ImageFillFormat.BackgroundImage != null)
        {
            // Add watermark to the image
            slide.ImageFillFormat.BackgroundImage.Add(watermark);
        }
    }

    watermarker.Save("presentation.pptx");
}
```

## Configuraciones adicionales para la imagen de fondo de la diapositiva {#additional-settings-for-slide-background-image}

GroupDocs.Watermark para .NET también proporciona la funcionalidad que le permite <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationimagefillformat/properties/tileastexture" target="_blank" rel="nofollow noopener noreferrer">tile</a> repetir la imagen en el fondo de la diapositiva. Asimismo, puede hacer que la imagen sea <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationimagefillformat/properties/transparency" target="_blank" rel="nofollow noopener noreferrer">semitransparente</a>. El siguiente ejemplo de código ilustra este propósito.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationSetTiledSemitransparentBackground**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    PresentationContent content = watermarker.GetContent<PresentationContent>();
    PresentationSlide slide = content.Slides[0];
    slide.ImageFillFormat.BackgroundImage = 
        new PresentationWatermarkableImage(File.ReadAllBytes("background.png"));
    slide.ImageFillFormat.TileAsTexture = true;
    slide.ImageFillFormat.Transparency = 0.5;

    watermarker.Save("presentation.pptx");
}
```

## Configuración de la imagen de fondo para gráficos {#settings-background-image-for-charts}

GroupDocs.Watermark para .NET también le permite establecer la imagen de fondo para un gráfico dentro de un documento de PowerPoint mediante la propiedad <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.contents.presentation/presentationbaseslide/properties/charts" target="_blank" rel="nofollow noopener noreferrer">Charts</a>. Puede utilizar el siguiente ejemplo de código para lograr esta funcionalidad.

**AdvancedUsage.AddingWatermarks.<wbr />AddWatermarksToPresentations.<wbr />PresentationSetBackgroundImageForChart**

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\presentation.pptx"
using (Watermarker watermarker = new Watermarker("presentation.pptx", loadOptions))
{
    PresentationContent content = watermarker.GetContent<PresentationContent>();
    content.Slides[0].Charts[0].ImageFillFormat.BackgroundImage = 
        new PresentationWatermarkableImage(File.ReadAllBytes("test.png"));
    content.Slides[0].Charts[0].ImageFillFormat.Transparency = 0.5;
    content.Slides[0].Charts[0].ImageFillFormat.TileAsTexture = true;

    watermarker.Save("presentation.pptx");
}
```

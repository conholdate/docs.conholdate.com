Los constructores <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Watermarker(String)</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/main" target="_blank" rel="nofollow noopener noreferrer">Watermarker(Stream)</a> pueden cargar un documento de cualquier formato admitido. Al cargar un documento, GroupDocs.Watermark detecta automáticamente su tipo y crea una instancia de la clase correspondiente. Si el formato del documento no es compatible, el constructor lanza <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.exceptions/unsupportedfiletypeexception" target="_blank" rel="nofollow noopener noreferrer">UnsupportedFileTypeException</a>. Si necesita especificar el formato del documento a cargar, puede utilizar los constructores con el parámetro <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>.

El siguiente ejemplo muestra cómo crear un marcadagua para un documento de hoja de cálculo:

**AdvancedUsage.LoadingDocuments.LoadingDocumentOfSpecificFormat**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\spreadsheet.xlsx"
string filePath = "spreadsheet.xlsx";
var loadOptions = new LoadOptions()
{
    FileType = FileType.FromExtension(Path.GetExtension(filePath))
};

// Or set the FormatFamily property directly when using a stream, for example:
loadOptions.FormatFamily = FormatFamily.Spreadsheet;

using (Watermarker watermarker = new Watermarker(filePath, loadOptions))
{
    // use watermarker methods to manage watermarks in the Spreadsheet document
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 12));
    watermarker.Add(watermark);
    watermarker.Save("spreadsheet.xlsx");
}

```

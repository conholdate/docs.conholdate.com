Algunos formatos de documento también admiten el cifrado del contenido. Para cargar este tipo de documentos, deberá proporcionar la contraseña. La API de GroupDocs.Watermark le permite cargar el contenido de estos documentos para gestionar la marca de agua.

## Cargar un documento protegido con contraseña de cualquier formato admitido {#load-password-protected-document-of-any-supported-format}

El siguiente ejemplo muestra cómo cargar un documento cifrado de cualquier formato admitido utilizando la contraseña. Si la contraseña es incorrecta, se lanza <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.exceptions/invalidpasswordexception" target="_blank" rel="nofollow noopener noreferrer">InvalidPasswordException</a>.

**AdvancedUsage.LoadingDocuments.LoadPasswordProtectedDocument**

```csharp
LoadOptions loadOptions = new LoadOptions();
loadOptions.Password = "P@$$w0rd";
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\protected-document.docx"
string filePath = "protected-document.docx";
using (Watermarker watermarker = new Watermarker(filePath, loadOptions))
{
    // use watermarker methods to manage watermarks in the document
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 12));

    watermarker.Add(watermark);

    watermarker.Save("protected-document.docx");
}
```

## Cargar documento de procesamiento de textos protegido con contraseña {#load-password-protected-word-processing-document}

El siguiente ejemplo demuestra cómo cargar un documento de procesamiento de textos cifrado (DOC, DOCX, etc.) utilizando la contraseña.

**AdvancedUsage.LoadingDocuments.LoadPasswordProtectedWordProcessingDocument**

```csharp
WordProcessingLoadOptions loadOptions = new WordProcessingLoadOptions();
loadOptions.Password = "P@$$w0rd";
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\protected-document.docx"
string filePath = "protected-document.docx";
using (Watermarker watermarker = new Watermarker(filePath, loadOptions))
{
    // use watermarker methods to manage watermarks in the WordProcessing document
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 12));
    watermarker.Add(watermark);
    watermarker.Save("protected-document.docx");
}

```

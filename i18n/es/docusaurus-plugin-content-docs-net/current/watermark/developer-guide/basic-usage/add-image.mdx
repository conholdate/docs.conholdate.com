Una de las características principales de la biblioteca GroupDocs.Watermark es la adición de marcas de agua de imagen a documentos. Puede agregar marcas de agua a documentos o imágenes desde discos locales, así como desde flujos de datos. Para obtener la lista completa de formatos de documento admitidos, consulte [Formatos admitidos](/net/watermark/getting-started/supported-document-formats/).

Para agregar una marca de agua de imagen, realice los siguientes pasos:

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> una instancia de la clase `Watermarker` para un archivo local o un flujo de archivo;
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark/constructors/1" target="_blank" rel="nofollow noopener noreferrer">Create</a> una instancia de la clase `ImageWatermark` desde el archivo de imagen local;
3. (Opcional.) Especifique las alineaciones <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">horizontal</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">vertical</a> de la marca de agua;
4. Llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> para aplicar la marca de agua al documento;
5. Llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\contract.docx"))
{
    // Specify an absolute or relative path to the desired image
    ImageWatermark watermark = new ImageWatermark("C:\\Docs\\logo.png");
    // Specify watermark size, opacity and alignments
    watermark.Width = 200;
    watermark.Height = 200;
    watermark.Opacity = 0.5;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\img-watermarked-contract.docx");
}
```
Ejecute el programa. Una nueva imagen con marca de agua aparecerá en la ruta especificada.

GroupDocs.Watermark ofrece numerosas capacidades para personalizar la apariencia de la marca de agua y su posición dentro del documento.

## Personalización de marcas de agua de texto {#customizing-text-watermarks}

Para ajustar una marca de agua de texto a sus necesidades, utilice las propiedades de la clase <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/#properties" target="_blank" rel="nofollow noopener noreferrer">`TextWatermark`</a>. 

Las siguientes opciones pueden configurarse:
| Opción | Descripción |
| -------- | ------------- |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a>** | Especifica el color de fondo del texto. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/considerparentmargins" target="_blank" rel="nofollow noopener noreferrer">ConsiderParentMargins</a>** | Indica si deben considerarse los márgenes de página existentes del documento al calcular el tamaño y las coordenadas de la marca de agua. Valor predeterminado: false. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/font" target="_blank" rel="nofollow noopener noreferrer">Font</a>** | Especifica la fuente actual de la marca de agua de texto. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/foregroundcolor" target="_blank" rel="nofollow noopener noreferrer">ForegroundColor</a>** | Especifica el color de primer plano del texto. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>** | Especifica la altura deseada de la marca de agua. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>** | Especifica la alineación horizontal de la marca de agua. Los valores posibles son `None` (predeterminado), `Left`, `Center` y `Right`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/isbackground" target="_blank" rel="nofollow noopener noreferrer">IsBackground</a>** | Indica si la marca de agua debe colocarse por debajo (true) o por encima (false) del contenido principal. Valor predeterminado: false. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/margins" target="_blank" rel="nofollow noopener noreferrer">Margins</a>** | Especifica los márgenes de la marca de agua. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a>** | Define la opacidad de la marca de agua como un valor comprendido entre 0 (totalmente transparente) y 1 (relleno sólido). |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/rotateangle/" target="_blank" rel="nofollow noopener noreferrer">RotateAngle</a>** | Define el ángulo de rotación de la marca de agua. Un valor positivo corresponde a un ángulo de rotación horario, y uno negativo a un ángulo antihorario. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/scalefactor" target="_blank" rel="nofollow noopener noreferrer">ScaleFactor</a>** | Especifica cómo depende el tamaño de la marca de agua del tamaño del documento principal. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/sizingtype" target="_blank" rel="nofollow noopener noreferrer">SizingType</a>** | Especifica la forma en que debe dimensionarse la marca de agua. Los valores posibles son `Auto` (predeterminado), `Absolute`, `ScaleToParentDimensions` y `ScaleToParentArea`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>** | Define el texto de la marca de agua. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/textwatermark/textalignment" target="_blank" rel="nofollow noopener noreferrer">TextAlignment</a>** | Especifica la alineación del texto. Los valores posibles son `Left` (predeterminado), `Center`, `Right` y `Justify`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>** | Especifica la alineación vertical de la marca de agua. Los valores posibles son `None` (predeterminado), `Left`, `Center` y `Bottom`. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>** | Especifica el ancho deseado de la marca de agua. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/x" target="_blank" rel="nofollow noopener noreferrer">X</a>** | Especifica la coordenada horizontal de la marca de agua dentro del documento principal. |
| **<a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermark/y" target="_blank" rel="nofollow noopener noreferrer">Y</a>** | Especifica la coordenada vertical de la marca de agua dentro del documento principal. |


El siguiente código demuestra cómo especificar la apariencia y la posición deseadas de la marca de agua antes de aplicarla al documento:

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\sample.docx"))
{
    // Specify the desired text and font for the watermark
    TextWatermark watermark = new TextWatermark("Customized watermark.", 
        new Font("Arial", 24, FontStyle.Bold));
    // Specify the appearance and the position of the watermark
    watermark.ForegroundColor = Color.DarkOrange;
    watermark.ConsiderParentMargins = true;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Top;
    watermark.SizingType = SizingType.ScaleToParentDimensions;
    watermark.RotateAngle = 45;
    watermark.ScaleFactor = 0.7;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\watermarked-sample.docx");
}
```
Ejecute el programa. Se agregará una marca de agua en una posición especificada y tendrá el aspecto indicado.

El siguiente código demuestra cómo especificar la apariencia y posición deseadas de la marca de agua antes de aplicarla al documento:

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\seagull.jpg"))
{
    // Specify the desired text and font for the watermark
    ImageWatermark watermark = new ImageWatermark("C:\\Docs\\greetings-stamp.png");
    // Specify watermark position, rotation and opacity
    watermark.HorizontalAlignment = HorizontalAlignment.Right;
    watermark.VerticalAlignment = VerticalAlignment.Top;
    watermark.RotateAngle = 15;
    watermark.IsBackground = false;
    watermark.Opacity = 0.8;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\custom-image-watermark.jpg");
}
```
Ejecute el programa. Se agregará una marca de agua de imagen en una posición especificada.

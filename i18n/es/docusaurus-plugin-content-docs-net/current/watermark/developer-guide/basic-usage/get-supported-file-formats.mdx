GroupDocs.Watermark permite obtener la [lista de todos los formatos de archivo admitidos](/net/watermark/getting-started/supported-document-formats/) siguiendo los pasos que se indican a continuación:

* Llamar al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>;
* Recorrer la colección de objetos <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente ejemplo de código demuestra cómo obtener la lista de formatos de archivo admitidos.

**BasicUsage.GetSupportedFileFormats**

```csharp
IEnumerable<FileType> supportedFileTypes = FileType.GetSupportedFileTypes();
foreach (FileType fileType in supportedFileTypes)
{
    Console.WriteLine(fileType);
}
```

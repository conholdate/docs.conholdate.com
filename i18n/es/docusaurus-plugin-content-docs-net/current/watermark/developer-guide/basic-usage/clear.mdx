Eliminar marcas de agua existentes es otra funcionalidad potente de la biblioteca GroupDocs.Watermark. Permite buscar y, a continuación, eliminar marcas de agua de texto o imagen en una amplia gama de documentos compatibles. La eliminación de marcas de agua es posible en algunos de los formatos admitidos. Para saber si esta funcionalidad está disponible para su formato, consulte [Formatos admitidos](/net/watermark/getting-started/supported-document-formats/).


:::info
La actualización de marcas de agua no está permitida en modo de evaluación. Configure una licencia según se describe en [Licenciamiento y evaluación](/net/watermark/getting-started/evaluation-limitations-and-licensing/).
:::


## Eliminación de marcas de agua de texto {#deleting-text-watermarks}

Para buscar y eliminar marcas de agua de texto:
1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `Watermarker` para un archivo local o un flujo de archivos;
2. Especifique el texto que desea buscar como marca de agua. Para definir los criterios, utilice una instancia de la clase <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/textsearchcriteria/" target="_blank" rel="nofollow noopener noreferrer">TextSearchCriteria</a>. En este ejemplo, buscaremos una coincidencia exacta de una cadena específica.
3. Llame al método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermarker/search/#search_1" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase `Watermarker` para realizar la búsqueda y obtener una colección de todas las marcas de agua posibles que cumplan con los criterios establecidos.
4. Utilice el método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.common/removeonlylistbase-1/clear/" target="_blank" rel="nofollow noopener noreferrer">Clear</a> de la clase `PossibleWatermarkCollection` para eliminar todas las marcas de agua encontradas.
5. Llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Search.SearchCriteria;
using GroupDocs.Watermark.Search;

using (Watermarker watermarker = new Watermarker("C:\\Docs\\watermarked-sample.docx"))
{
    // Search watermark matching a particular text
    TextSearchCriteria searchCriteria = new TextSearchCriteria("Contract Draft", false);
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(searchCriteria);    
    // Clear all found watermarks
    possibleWatermarks.Clear();
    // Save document
    watermarker.Save("C:\\Docs\\clean-sample.docx");
}
```
Ejecute el programa. Se eliminarán todas las ocurrencias encontradas de «Borrador de contrato» en las marcas de agua.

## Eliminación de marcas de agua en imágenes {#deleting-image-watermarks}

Para buscar y eliminar marcas de agua en imágenes dentro del documento:
1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `Watermarker` para un archivo local o un flujo de archivos;
2. especifique la imagen de la marca de agua que desea buscar. Para definir los criterios, utilice una instancia de la clase <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/imagesearchcriteria/" target="_blank" rel="nofollow noopener noreferrer">ImageSearchCriteria</a>;
3. (Opcional.) especifique la diferencia máxima permitida entre las imágenes mediante la propiedad <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/imagesearchcriteria/maxdifference/" target="_blank" rel="nofollow noopener noreferrer">MaxDifference</a>. Un umbral demasiado estricto podría no detectar todas las imágenes necesarias, mientras que un umbral demasiado permisivo podría coincidir con imágenes distintas;
4. llame al método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermarker/search/#search_1" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase `Watermarker` para realizar la búsqueda y obtener una colección de todas las marcas de agua posibles que cumplan los criterios establecidos;
5. utilice el método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.common/removeonlylistbase-1/clear/" target="_blank" rel="nofollow noopener noreferrer">Clear</a> de la clase `PossibleWatermarkCollection` para eliminar todas las marcas de agua encontradas;
6. llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Search.SearchCriteria;
using GroupDocs.Watermark.Search;

using (Watermarker watermarker = new Watermarker("watermarked-sample.docx"))
{
    // Initialize criteria with the image    
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria("logo.png");
    //Set maximum allowed difference between images
    imageSearchCriteria.MaxDifference = 0.9;
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(imageSearchCriteria);
    // Clear all found watermarks
    possibleWatermarks.Clear();
    // Save document
    watermarker.Save("clean-sample.docx");
}

```
Ejecute el programa. Se eliminarán todas las ocurrencias de marcas de agua de imagen encontradas.

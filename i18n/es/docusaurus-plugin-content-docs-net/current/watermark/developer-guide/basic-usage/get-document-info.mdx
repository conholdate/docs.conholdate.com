GroupDocs.Watermark permite obtener información del documento, la cual incluye:

* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>
* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.common/idocumentinfo/properties/isencrypted" target="_blank" rel="nofollow noopener noreferrer">IsEncrypted</a>

Los siguientes ejemplos de código muestran cómo obtener la información del documento.

## Obtener información del documento desde un archivo en el disco local {#get-document-information-from-a-file-from-local-disk}

Este ejemplo demuestra cómo obtener la información del documento desde un archivo local.

**BasicUsage.GetDocumentInfoForTheFileFromLocalDisk**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\source.docx"
using (Watermarker watermarker = new Watermarker("source.docx"))
{
    IDocumentInfo info = watermarker.GetDocumentInfo();
    Console.WriteLine("File type: {0}", info.FileType);
    Console.WriteLine("Number of pages: {0}", info.PageCount);
    Console.WriteLine("Document size: {0} bytes", info.Size);
}
```

## Obtener información del documento desde un flujo {#get-document-information-from-a-stream}

Este ejemplo muestra cómo obtener la información del documento desde el flujo de archivos.

**BasicUsage.GetDocumentInfoForTheFileFromStream**

```csharp
// Specify an absolute or relative path to your document. Ex: @"C:\Docs\source.docx"
using (FileStream stream = File.OpenRead("source.docx"))
{
    using (Watermarker watermarker = new Watermarker(stream))
    {
        IDocumentInfo info = watermarker.GetDocumentInfo();
        Console.WriteLine("File type: {0}", info.FileType);
        Console.WriteLine("Number of pages: {0}", info.PageCount);
        Console.WriteLine("Document size: {0} bytes", info.Size);
    }
}
```

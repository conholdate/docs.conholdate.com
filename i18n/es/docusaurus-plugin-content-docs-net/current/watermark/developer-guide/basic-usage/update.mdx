La biblioteca GroupDocs.Watermark también permite buscar en el documento marcas de agua de texto o imagen ya existentes. Estas pueden ser marcas de agua agregadas mediante cualquier herramienta de terceros, no únicamente por GroupDocs.Watermark. La búsqueda de marcas de agua es posible en algunos de los formatos compatibles. Para saber si esta funcionalidad está disponible para su formato, consulte [Formatos compatibles](/net/watermark/getting-started/supported-document-formats/). 

Una vez encontradas, puede actualizar dichas marcas de agua.


:::info
La actualización de marcas de agua no está permitida en modo de evaluación. Configure una licencia según se describe en [Licenciamiento y evaluación](/net/watermark/getting-started/evaluation-limitations-and-licensing/).
:::


## Actualización de marcas de agua de texto {#updating-text-watermarks}

Para buscar y actualizar marcas de agua de texto:
1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `Watermarker` para un archivo local o un flujo de archivos;
2. especifique el texto que desea buscar en las marcas de agua. Para definir los criterios, utilice una instancia de la clase <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/textsearchcriteria/" target="_blank" rel="nofollow noopener noreferrer">TextSearchCriteria</a>. En este ejemplo, buscaremos una coincidencia exacta de una cadena específica.
3. invoque el método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermarker/search/#search_1" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase `Watermarker` para realizar la búsqueda y obtener una colección de todas las marcas de agua posibles que cumplan con los criterios establecidos.
4. recorra la colección de marcas de agua posibles y actualice las ocurrencias de texto encontradas mediante la propiedad <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search/possiblewatermark/text/" target="_blank" rel="nofollow noopener noreferrer">Text</a>.
5. invoque el método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Search.SearchCriteria;
using GroupDocs.Watermark.Search;

using (Watermarker watermarker = new Watermarker("C:\\Docs\\watermarked-sample.docx"))
{
    // Search watermark matching a particular text
    TextSearchCriteria searchCriteria = new TextSearchCriteria("Contract Draft", false);
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(searchCriteria);
    Console.WriteLine("Found {0} possible watermark(s).", possibleWatermarks.Count);
    foreach (PossibleWatermark watermark in possibleWatermarks)
    {
        try
        {
            // Update text
            watermark.Text = "Contract is no longer valid";            
        }
        catch (Exception e)
        {
            // Found entity may not support text editing
            // Passed argument can have inappropriate value
            // Process such cases here
        }
    }
    // Save document
    watermarker.Save("C:\\Docs\\updated-sample.docx");
}
```
Ejecute el programa. Todas las ocurrencias encontradas de «Contract Draft» en las marcas de agua se cambiarán a «Contract is no longer valid».

### ¿Qué sigue? {#what-s-next}

Las capacidades de búsqueda de texto de GroupDocs.Watermark no se limitan a coincidencias simples de texto. Para aprender cómo realizar búsquedas mediante expresiones regulares, o buscar marcas de agua basándose en cierto formato de texto específico, o actualizar el formato del texto encontrado, consulte los artículos [Búsqueda de marcas de agua](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/searching-watermarks/) y [Modificación de propiedades de marcas de agua encontradas](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/modifing-found-watermark-properties/) de la sección «Uso avanzado».

## Actualización de marcas de agua de imagen {#updating-image-watermarks}

Para buscar y actualizar marcas de agua de texto:
1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `Watermarker` para un archivo local o un flujo de archivo;
2. especifique la imagen de marca de agua que desea buscar. Para definir los criterios, utilice una instancia de la clase <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/imagesearchcriteria/" target="_blank" rel="nofollow noopener noreferrer">ImageSearchCriteria</a>.
3. especifique la diferencia máxima permitida entre las imágenes mediante la propiedad <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search.searchcriteria/imagesearchcriteria/maxdifference/" target="_blank" rel="nofollow noopener noreferrer">MaxDifference</a>. Un umbral demasiado estricto podría no detectar todas las imágenes necesarias, mientras que un umbral demasiado permisivo podría coincidir con imágenes no similares.
4. llame al método <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark/watermarker/search/#search_1" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la clase `Watermarker` para realizar la búsqueda y obtener una colección de todas las marcas de agua posibles que cumplan los criterios de búsqueda.
5. recorra la colección de marcas de agua posibles y actualice las ocurrencias de imagen encontradas mediante la propiedad <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.search/possiblewatermark/imagedata/" target="_blank" rel="nofollow noopener noreferrer">ImageData</a>.
6. llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Search.SearchCriteria;
using GroupDocs.Watermark.Search;

using (Watermarker watermarker = new Watermarker("C:\\Docs\\watermarked-sample.docx"))

{
    // Initialize criteria with the image    
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria("C:\\Docs\\logo.png");
    //Set maximum allowed difference between images
    imageSearchCriteria.MaxDifference = 0.9;
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(imageSearchCriteria);
    Console.WriteLine("Found {0} possible watermark(s).", possibleWatermarks.Count);
    
    // Read new watermark image
    byte[] imageData = File.ReadAllBytes("C:\\Docs\\new-logo.png");
    foreach (PossibleWatermark watermark in possibleWatermarks)
    {
        try
        {
            // Replace image
            watermark.ImageData = imageData;
        }
        catch (Exception e)
        {
            // Found entity may not support text editing
            // Passed argument can have inappropriate value
            // Process such cases here
        }
    }
    // Save document
    watermarker.Save("C:\\Docs\\updated-sample.docx");    
}
```
Ejecute el programa. Se actualizarán todas las ocurrencias de marcas de agua de imagen encontradas.

### ¿Qué sigue? {#what-s-next-1}

La búsqueda por imágenes es una operación considerablemente más compleja que puede requerir encontrar un umbral de diferencia adecuado o incluso utilizar otros algoritmos de comparación de imágenes. GroupDocs.Watermark ofrece varios algoritmos de criterios de búsqueda de imágenes. Para obtener más información al respecto, consulte el artículo [Búsqueda de marcas de agua](/net/watermark/developer-guide/advanced-usage/searching-and-modifying-watermarks/searching-watermarks/) de la sección «Uso avanzado».

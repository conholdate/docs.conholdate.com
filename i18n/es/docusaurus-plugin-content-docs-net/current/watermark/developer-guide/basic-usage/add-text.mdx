Una de las características principales de la biblioteca GroupDocs.Watermark es la adición de marcas de agua de texto a documentos. Puede agregar marcas de agua a documentos o imágenes desde discos locales, así como desde flujos de datos. Para obtener la lista completa de formatos de documento compatibles, consulte [Formatos admitidos](/net/watermark/getting-started/supported-document-formats/).

Para agregar una marca de agua de texto, realice los siguientes pasos:

1. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/constructors/4" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `Watermarker` para un archivo local o un flujo de archivo;
2. <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark/constructors/main" target="_blank" rel="nofollow noopener noreferrer">Create</a> cree una instancia de la clase `TextWatermark` y especifique el texto y la fuente deseados para la marca de agua;
3. (Opcional.) Especifique las alineaciones <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark/properties/foregroundcolor" target="_blank" rel="nofollow noopener noreferrer">color</a>, <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">horizontal</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermark/properties/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">vertical</a> de la marca de agua;
4. Llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> para aplicar la marca de agua al documento;
5. Llame al método <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarker/save/methods/4" target="_blank" rel="nofollow noopener noreferrer">Save</a> para guardar el documento en una nueva ubicación.

```csharp
using GroupDocs.Watermark;
using GroupDocs.Watermark.Common;
using GroupDocs.Watermark.Watermarks;

// Specify an absolute or relative path to your document.
using (Watermarker watermarker = new Watermarker("C:\\Docs\\contract.docx"))
{
    // Specify the desired text and font for the watermark
    TextWatermark watermark = new TextWatermark("Contract Draft", 
        new Font("Arial", 60, FontStyle.Bold));
    // Specify font color and text opacity, rotation and alignments
    watermark.ForegroundColor = Color.DarkGreen;
    watermark.Opacity = 0.5;
    watermark.HorizontalAlignment = HorizontalAlignment.Center;
    watermark.VerticalAlignment = VerticalAlignment.Center;
    // Apply the watermark
    watermarker.Add(watermark);
    // Save the resulting document
    watermarker.Save("C:\\Docs\\watermarked-contract.docx");
}
```
Ejecute el programa. Se generará un nuevo documento con marca de agua en la ruta especificada.

### ¿Qué sigue? {#what-s-next}

GroupDocs.Watermark ofrece muchas más funcionalidades para agregar marcas de agua de texto. Por ejemplo, permite especificar colores de fondo y primer plano, formato, opacidad del texto, uso de posicionamiento absoluto o relativo, entre otras opciones. Para obtener más información al respecto, consulte el artículo [Agregar marcas de agua de texto](/net/watermark/developer-guide/advanced-usage/adding-watermarks/adding-text-watermarks/) de la sección «Uso avanzado».

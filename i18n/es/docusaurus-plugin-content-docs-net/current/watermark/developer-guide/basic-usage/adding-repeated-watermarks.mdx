## Marca de agua repetida {#rrepeated-watermark}

Potencie la apariencia visual y la identidad de marca de sus documentos mediante marcas de agua repetidas o en mosaico. Esta funcionalidad innovadora le permite integrar de forma fluida patrones de texto o imágenes en todas sus páginas, logrando un aspecto profesional y cohesivo. Ya sea que busque una identificación de marca sutil, una expresión artística o mayor seguridad documental, la capacidad de configurar el espaciado, la rotación y el estilo de estas marcas de agua ofrece una personalización sin igual. Explore las posibilidades y haga que sus documentos destaquen con la elegancia de las marcas de agua en mosaico.

### Marca de agua de texto repetida {#text-repeated-watermark}

El fragmento de código proporcionado demuestra cómo agregar una marca de agua en mosaico a un documento. Para configurar las opciones de mosaico, podemos utilizar la clase dedicada <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/tileoptions" target="_blank" rel="nofollow noopener noreferrer">TileOptions</a>. En este ejemplo, establecemos la propiedad `LineSpacing`, que determina el espaciado entre mosaicos paralelos, en un 12 % del tamaño de la página. Además, definimos la propiedad `WatermarkSpacing`, que establece el espaciado entre marcas de agua dentro de una línea, en un 10 % del tamaño de la página. La siguiente imagen ayuda a comprender el propósito de las configuraciones `LineSpacing` y `WatermarkSpacing`:
![adding-repeated-watermarks](/net/watermark/images/tilling-options.png)

Además, aplicamos una rotación de marca de agua de 30 grados para una personalización adicional.

```csharp
    using (Watermarker watermarker = new Watermarker("sample.pdf"))
    {
        // Initialize the font to be used for watermark
        Font font = new Font("Arial", 19, FontStyle.Bold | FontStyle.Italic);

        // Create the watermark object
        var watermark = new TextWatermark("Watermark", font);
        watermark.ForegroundColor = Color.Red;

        // Configure tile options
        watermark.TileOptions = new TileOptions()
        {
            LineSpacing = new MeasureValue()
            {
                MeasureType = TileMeasureType.Percent,
                Value = 12
            },
            WatermarkSpacing = new MeasureValue()
            {
                MeasureType = TileMeasureType.Percent,
                Value = 10
            },
        };

        // Set watermark properties
        watermark.Opacity = 0.2;
        watermark.RotateAngle = -30;

        // Add watermark
        watermarker.Add(watermark);
        watermarker.Save("result.pdf");
    }        
```

La salida del código mencionado anteriormente se representa a continuación, mostrando marcas de agua de texto repetidas:
![text repeated watermarks](/net/watermark/images/tilling-text-30.png)

La rotación común de las marcas de agua en la imagen anterior se realiza con respecto al borde izquierdo del documento. También es posible realizar la rotación común con respecto a la esquina inferior izquierda del documento. Para ello, es necesario establecer la propiedad <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/tileoptions/rotatearoundorigin/" target="_blank" rel="nofollow noopener noreferrer">RotateAroundOrigin</a> de la clase TileOptions en true.
```csharp
watermark.TileOptions.RotateAroundOrigin = true;
```
En tal caso, el resultado del marcador de agua repetido se ve así:
![repeated watermarks rotaion around the center](/net/watermark/images/tilling-text-center.png)

La clase `TileOptions` incluye un <a href="https://reference.groupdocs.com/watermark/net/groupdocs.watermark.watermarks/tiletype" target="_blank" rel="nofollow noopener noreferrer">TileType</a> propiedad, que proporciona la capacidad de configurar la plantilla del mosaico. El valor predeterminado es el modo recto, pero podemos cambiarlo. Por ejemplo, en el ejemplo anterior, si agregamos la configuración 
```csharp
   watermark.TileOptions.TileType = TileType.Offset
```
habilita el estilo de desplazamiento. En el contexto de marcas de agua y mosaicos, el «estilo de desplazamiento» se refiere a una disposición específica en la que cada mosaico se posiciona con un desplazamiento o desplazamiento respecto al anterior. En lugar de alinear los mosaicos de forma sencilla y paralela, el estilo de desplazamiento introduce un desplazamiento, generando un patrón más dinámico y visualmente atractivo. Este desplazamiento puede producirse horizontalmente, verticalmente o en ambas direcciones, según la configuración específica aplicada.
En este caso, la salida mostrará el siguiente efecto:
![adding-repeated-watermarks](/net/watermark/images/tilling-text-30-offset.png)

La enumeración `TileType` admite una variedad de plantillas de mosaico, incluidas `OneThirdOffset` y `BasketWeave`, para satisfacer necesidades de diseño diversas. Configuración
```csharp
   watermark.TileOptions.TileType = TileType.BasketWeave
```
Genera el siguiente resultado visual para el patrón de marca de agua en forma de tejido de cesta en el documento:
![adding-repeated-watermarks](/net/watermark/images/basket-weave.png)

### Marca de agua repetida {#image-repeated-watermark}

La función de marca de agua repetida también admite marcas de agua de imagen. El siguiente código en C# muestra cómo agregar marcas de agua de imagen repetidas a un documento PDF con rotación.

```csharp
    using (Watermarker watermarker = new Watermarker("sample.pdf"))
    {
        // Initialize the font to be used for watermark
        Font font = new Font("Arial", 19, FontStyle.Bold | FontStyle.Italic);

        // Create the image watermark object
        var watermark = new ImageWatermark(imagePath);

        // Configure tile options
        watermark.TileOptions = new TileOptions()
        {
            LineSpacing = new MeasureValue()
            {
                MeasureType = TileMeasureType.Percent,
                Value = 12
            },
            WatermarkSpacing = new MeasureValue()
            {
                MeasureType = TileMeasureType.Percent,
                Value = 10
            },
        };

        // Set watermark properties
        watermark.Opacity = 0.3;
        watermark.RotateAngle = -30;

        // Add watermark
        watermarker.Add(watermark);
        watermarker.Save("result.pdf");
    }        
```

![adding-repeated-watermarks](/net/watermark/images/tilling-image-30.png)

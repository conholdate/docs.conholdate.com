La biblioteca GroupDocs.Watermark proporciona la capacidad de manipular distintos tipos de marcas de agua, como <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/textwatermark" target="_blank" rel="nofollow noopener noreferrer">TextWatermark</a> y <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark.watermarks/imagewatermark" target="_blank" rel="nofollow noopener noreferrer">ImageWatermark</a>. Estas marcas de agua pueden añadirse a documentos, actualizarse, eliminarse o buscarse dentro de documentos ya marcados. Nuestro producto también proporciona información sobre el tipo y la estructura del documento: tipo de archivo, tamaño, número de páginas, etc., y genera vistas previas de las páginas del documento según las opciones proporcionadas.  

A continuación se presentan los conceptos principales de la API de GroupDocs.Watermark:

* <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a> es la clase principal que contiene todos los métodos necesarios para manipular las marcas de agua en documentos.
* La mayoría de los métodos esperan distintas opciones para añadir, actualizar, buscar o eliminar marcas de agua dentro de un documento.
* La clase <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a> implementa la interfaz <a href="https://docs.microsoft.com/en-us/dotnet/api/system.idisposable" target="_blank" rel="nofollow noopener noreferrer">IDisposable</a> para liberar correctamente los recursos utilizados —por ejemplo, cerrando de forma segura los flujos de documentos una vez completadas todas las operaciones.

## Definición del objeto Watermarker {#watermarker-object-definition}

El siguiente código muestra el patrón más utilizado para definir el objeto <a href="https://reference.groupdocs.com/net/watermark/groupdocs.watermark/watermarker" target="_blank" rel="nofollow noopener noreferrer">Watermarker</a> y llamar a sus métodos.

```csharp
// Add text watermark to PDF document
using (Watermarker watermarker = new Watermarker("document.pdf"))
{
    TextWatermark watermark = new TextWatermark("Test watermark", new Font("Arial", 36, FontStyle.Bold | FontStyle.Italic));
    watermarker.Add(watermark);
    watermarker.Save("Watermarked_document.pdf");
}
```

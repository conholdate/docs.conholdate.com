Aspose.OCR para .NET es un producto con licencia comercial que puede utilizarse en modo de prueba (evaluación).

## Prueba gratuita {#free-trial}
  
Puede comenzar a utilizar Aspose.OCR para .NET inmediatamente tras la [instalación](/net/ocr/installation/). En modo de prueba (sin proporcionar una licencia), puede reconocer texto en cualquier [idioma](/net/ocr/recognition-languages/) admitido y guardar los resultados del reconocimiento en cualquiera de los [formatos](/net/ocr/supported-file-formats/) admitidos.

Sin embargo, se aplican las siguientes restricciones:

- Si el número de caracteres en una imagen reconocida supera los 300, solo se reconocen los primeros **300** caracteres.
- Si el número de caracteres en una imagen reconocida es inferior a 300, se reconocen el **60 %** inicial de los caracteres.

Para eliminar esta restricción, aplique una licencia.

## Obtención de una licencia temporal {#getting-a-temporary-license}
  
Una licencia temporal elimina la limitación de la versión de prueba durante **30 días**. Utilícela para comenzar a desarrollar una aplicación OCR totalmente funcional y tomar la decisión final de <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquirir</a> Aspose.OCR para .NET más adelante.

Para solicitar una licencia temporal, visite la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">"Obtener una licencia temporal"</a>.

## Adquisición de una licencia {#purchasing-a-license}
  
Aspose.OCR para .NET se licencia según el número de desarrolladores y ubicaciones (sitios) donde se utilizará el producto (*licencias de desarrollador* y *licencias de sitio*), o mediante el modelo de pago por uso (*licencias medibles*).

Consulte <a href="https://purchase.conholdate.com/policies/license-types" target="_blank">Tipos de licencia</a> para obtener más detalles y <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquiera una licencia</a> que se ajuste mejor a sus necesidades.

## Aplicación de una licencia de desarrollador o de sitio {#applying-a-developer-or-site-license}
  
Tras adquirir una licencia u obtener una licencia temporal, recibirá un archivo con la extensión *.lic*. Si lo desea, puede renombrar este archivo y cambiar su extensión.

:::info
Mantenga los tokens de marcador de posición que aparecen en la entrada exactamente sin modificar.  
No agregue tokens de marcador de posición que no estén ya presentes en la entrada.  
Mantenga las tuberías y el recuento de filas de la tabla de Markdown sin modificar.  

No modifique el contenido del archivo de licencia. Incluso un salto de línea o un espacio adicional invalidará la licencia.
:::

La licencia debe aplicarse una vez por ciclo de vida de la aplicación o proceso, antes de que comience el reconocimiento. Para *aplicaciones de escritorio*, se recomienda cargar la licencia en el método `Initialize` del formulario principal. Para *aplicaciones web*, cárguela en el método `Session_Start()` del archivo **global.asax**.

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
Coloque el archivo de licencia en una carpeta de su equipo e inserte el siguiente código en su método de inicio:

```csharp
// Initialize the licensing object
Aspose.OCR.License license = new Aspose.OCR.License();

// Load the license from file
license.SetLicense("Aspose_OCR_License_File.lic");
```

Si solo se especifica el nombre del archivo de licencia (sin la ruta), el método `SetLicense` buscará el archivo de licencia en las siguientes ubicaciones:

- La carpeta que contiene el componente Aspose.OCR para .NET (*Aspose.OCR.dll*);
- La carpeta que contiene el ensamblado que realiza la llamada;
- La carpeta que contiene el ensamblado de entrada (ensamblado de inicio).

Alternativamente, puede almacenar el archivo de licencia en cualquier carpeta de su equipo y especificar una ruta absoluta o relativa. Si prefiere cargar la licencia desde una ruta explícita, proporcione la ruta completa en el método `SetLicense`.

### Carga de una licencia desde un flujo  {#loading-a-license-from-stream}
  
Inserte el siguiente código en su método de inicio:

```csharp
// Initialize the licensing object
Aspose.OCR.License license = new Aspose.OCR.License();

// Read the license from file
System.IO.FileStream lisenseStream = new System.IO.FileStream(@"C:\Aspose_OCR_License_File.lic", System.IO.FileMode.Open, System.IO.FileAccess.Read);

// Load the license
license.SetLicense(licenseStream);
```

### Incluir un archivo de licencia como recurso incrustado {#including-a-license-file-as-an-embedded-resource}
  
Puede incluir el archivo de licencia como un recurso incrustado en uno de los ensamblados que llaman a Aspose.OCR para .NET. Esto garantiza que el archivo no se pierda accidentalmente.

- En Microsoft Visual Studio, haga clic con el botón derecho en el proyecto en el **Explorador de soluciones** y seleccione **Agregar | Elemento existente…** en el menú contextual.
- Seleccione el archivo de licencia (*.lic*) y haga clic en el botón **Agregar**.
- Seleccione el archivo de licencia en el **Explorador de soluciones** y establezca su propiedad **Acción de compilación** en *Recurso incrustado*.

A continuación, inserte el siguiente código en su método de inicio:

```csharp
// Initialize the licensing object
Aspose.OCR.License license = new Aspose.OCR.License();

// Load the license from file
license.SetLicense("Aspose_OCR_License_File.lic");
```

No es necesario llamar a los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` para acceder a la licencia incrustada. La clase `Aspose.OCR.License` encontrará automáticamente el archivo de licencia en los recursos incrustados.

## Aplicación de una licencia basada en uso (metered) {#applying-a-metered-license}
  
Cuando adquiera una licencia basada en uso, recibirá un par de claves pública/privada en lugar de un archivo de licencia. Utilice el siguiente código en su método de inicio para aplicar las claves de licencia:

```csharp
// License key pair
string publicKey = "PUBLIC-LICENSE-KEY";
string privateKey = "PRIVATE-LICENSE-KEY";

// Initialize the metered license
Aspose.OCR.Metered meteredLicense = new Aspose.OCR.Metered();
meteredLicense.SetMeteredKey(publicKey, privateKey);
```

Su uso se registrará localmente y se informará periódicamente a los servidores de Aspose. Se le facturará mensualmente según lo que utilice. Este mecanismo de licencias requiere que el equipo que ejecute la aplicación OCR tenga una conexión a Internet estable y que la aplicación no esté bloqueada por un firewall.

Lea <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en consumo</a> para obtener detalles técnicos y comerciales detallados.

## Licencias para múltiples productos de Aspose {#licensing-multiple-aspose-products}
  
Incluso si posee una única licencia para todos los productos de Aspose (como <a href="https://products.aspose.com/total/net/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Total para .NET</a>), aún debe aplicar la licencia por separado a **cada** producto de Aspose que utilice en su aplicación.

Cada producto de Aspose incluye una clase `License` en su espacio de nombres. Al aplicar licencias a cada producto, utilice el nombre completo de la clase `License` para evitar ambigüedades. Por ejemplo:

```csharp
// Aspose.OCR
Aspose.OCR.License OCRLicense = new Aspose.OCR.License();
OCRLicense.SetLicense("Aspose_OCR_License_File.lic");

// Aspose.BarCode
Aspose.BarCode.License barcodeLicense = new Aspose.BarCode.License();
barcodeLicense.SetLicense("Aspose_BarCode_License_File.lic");
```

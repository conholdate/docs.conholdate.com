## Formatos de imagen reconocidos {#recognized-image-formats}
  
Aspose.OCR para .NET puede reconocer cualquier archivo que obtenga de un escáner o una cámara:

<div className="docs-owner-markdown-table">

| Extensión | Detalles |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **.PDF** | Portable Document Format |
| **.JPG** | JPEG, el formato más popular para fotos de teléfonos inteligentes |
| **.PNG** | Portable Network Graphics, 24 bits con transparencia |
| **.TIFF** o **.TIF** | Tag Image File Format, comúnmente utilizado para escaneos de alta calidad |
| **.GIF** | Graphics Interchange Format, limitado a 256 colores |
| **.BMP** | Archivo de imagen de mapa de bits |
| **.DJVU** | DjVu, diseñado principalmente para documentos escaneados, que contiene una combinación de texto, dibujos lineales, imágenes en color indexado y fotografías |

</div>

:::info
Los documentos PDF de varias páginas, las imágenes TIFF y DjVu están totalmente admitidos.
:::

## Resultados del reconocimiento {#recognition-results}
  
Los resultados del reconocimiento se devuelven en los formatos más populares para el intercambio de documentos y datos:

<div className="docs-owner-markdown-table">

| Formato | Detalles |
| --------- | ------------------------------------------------------------------------------------------------------------------- |
| **.TXT** | Texto sin formato |
| **.HTML** | Página web |
| **.RTF** | Un formato universal para intercambiar documentos de texto enriquecido entre distintos programas de procesamiento de texto |
| **.DOCX** | Documento de Microsoft Word |
| **.XLSX** | Hoja de cálculo de Microsoft Excel |
| **.PDF** | Formato de Documento Portátil |
| **.EPUB** | Formato de archivo de libro electrónico popular |
| **JSON** | Un formato estándar abierto popular, ampliamente utilizado en desarrollo de software e intercambio de datos |
| **XML** | Lenguaje de Marcado Extensible, un formato universal para la mayoría de los sistemas |
| **hOCR** | Formato de estándar abierto comúnmente utilizado que incluye texto extraído e información de diseño para generar PDFs buscables. |

</div>

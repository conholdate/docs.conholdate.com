<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> detecta cambios en texto (párrafos, palabras, caracteres), tablas, imágenes y formas en una amplia gama de formatos: Word, PDF, Excel, PowerPoint, HTML, AutoCAD, Visio, Outlook, OpenDocument, imágenes y más. La lista completa está disponible en la página [Formatos de documento admitidos](/net/comparison/getting-started/supported-document-formats/).

De forma predeterminada, GroupDocs.Comparison resalta los cambios detectados con los siguientes colores:  

*   Insertado - <font color="blue">**azul**</font>
*   Eliminado - <font color="red">**rojo**</font>
*   Estilo modificado - <font color="green">**verde**</font>

Estos son los valores predeterminados; puede anular los colores, fuentes y otros estilos mediante las propiedades `InsertedItemStyle`, `DeletedItemStyle` y `ChangedItemStyle`. Consulte [Personalizar los estilos de cambios](/net/comparison/advanced-usage/comparison/customize-changes-styles/) para obtener más detalles.

## Flujo de trabajo básico de comparación {#basic-comparison-workflow}
  
Para comparar dos documentos, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> con la ruta o secuencia del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> y especifique la ruta o secuencia del documento de destino.
3.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a>.

### Comparar documentos locales {#compare-local-documents}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
}
```

## Personalizar la comparación con opciones  {#customize-comparison-with-options}
  
Para controlar cómo se realiza la comparación y cómo se representa el resultado, pase un objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> al método `Compare`. Estas opciones funcionan con cualquier formato de documento admitido:


<Tabs groupId="example-options">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    CompareOptions options = new CompareOptions
    {
        DetectStyleChanges = true,
        GenerateSummaryPage = true,
        ShowDeletedContent = true,
        ShowInsertedContent = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


Para comportamientos específicos por formato, GroupDocs.Comparison proporciona subclases dedicadas de `CompareOptions`:  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a>: configuraciones específicas para Word, como `DisplayMode` (Revisiones / Resaltado), comparación de encabezados y pies de página, y comparación de marcadores. Consulte [Opciones de comparación de documentos de Word](/net/comparison/advanced-usage/comparison/word-compare-options/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/pdfcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfCompareOptions</a>: configuraciones específicas para PDF, como `DisplayMode` (En línea / Lado a lado / Intercalado), filtrado por rango de páginas y nombre del autor de anotaciones en PDF.  

Se recomienda utilizar una subclase específica por formato al comparar un tipo de documento conocido, ya que permite descubrir fácilmente las configuraciones exclusivas de Word o PDF y evita que pase opciones irrelevantes.  

## Configuración de carga con LoadOptions {#configure-loading-with-loadoptions}
  
Mientras que `CompareOptions` controla cómo se comparan los documentos, <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> controla cómo se cargan los archivos fuente y destino en `Comparer`. Se pasa al constructor de `Comparer` y a `Add`, antes de que se ejecute cualquier comparación.


<Tabs groupId="example-loadoptions">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

LoadOptions loadOptions = new LoadOptions
{
    FileType = FileType.DOCX
};

using (Comparer comparer = new Comparer("source.docx", loadOptions))
{
    comparer.Add("target.docx", loadOptions);
    comparer.Compare("result.docx");
}
```

</TabItem>


</Tabs>


Propiedades comunes de `LoadOptions`:  

- `Password` – abrir un documento fuente o destino protegido con contraseña. Consulte [Cargar documentos protegidos con contraseña](/net/comparison/advanced-usage/loading/load-password-protected-documents/).  

- `FileType` – especificar explícitamente el formato del documento y omitir la detección automática (más rápido para archivos grandes). Consulte [Especificar manualmente el tipo de archivo para la comparación](/net/comparison/advanced-usage/loading/specify-file-type-manually/).  

- `FontDirectories` – proporcionar directorios personalizados de fuentes utilizados durante la representación del resultado. Consulte [Cargar fuentes personalizadas](/net/comparison/advanced-usage/loading/load-custom-fonts/).

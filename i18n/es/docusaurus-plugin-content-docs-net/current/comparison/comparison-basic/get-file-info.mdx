<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite obtener la siguiente información del archivo:  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> representa el tipo de archivo del documento (PDF, documento de Word, hoja de cálculo de Excel, presentación de PowerPoint o imagen, etc.).
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> representa la cantidad de páginas del documento.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.interfaces/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">FileSize</a> representa el tamaño del archivo del documento.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PagesInfo</a> representa la información de la página.  

Los siguientes ejemplos de código muestran cómo obtener la información del archivo:  

## Obtener información del archivo desde el disco local  {#get-file-info-for-the-file-from-local-disk}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Interfaces;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    IDocumentInfo info = comparer.Source.GetDocumentInfo();
    for (int i = 0; i < info.PageCount; i++)
    {
        Console.WriteLine("\n" +
            "Page number: {5}\n" +
            "File type: {0}\n" +
            "Number of pages: {1}\n" +
            "Document size: {2} bytes\n" +
            "Width: {3}\n" +
            "Height: {4} ",
            info.FileType, 
            info.PageCount, 
            info.Size, 
            info.PagesInfo[i].Width, 
            info.PagesInfo[i].Height, i + 1
        );
    }
}
```

## Obtener información del archivo del archivo desde el flujo  {#get-file-info-for-the-file-from-stream}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Interfaces;
using System.IO;
// ...

using (Comparer comparer = new Comparer(File.OpenRead("source.docx")))
{
    IDocumentInfo info = comparer.Source.GetDocumentInfo();
    for (int i = 0; i < info.PageCount; i++)
    {
        Console.WriteLine("\n" +
            "Page number: {5}\n" +
            "File type: {0}\n" +
            "Number of pages: {1}\n" +
            "Document size: {2} bytes\n" +
            "Width: {3}\n" +
            "Height: {4} ",
            info.FileType, 
            info.PageCount, 
            info.Size, 
            info.PagesInfo[i].Width, 
            info.PagesInfo[i].Height, i + 1
        );
    }
}
```

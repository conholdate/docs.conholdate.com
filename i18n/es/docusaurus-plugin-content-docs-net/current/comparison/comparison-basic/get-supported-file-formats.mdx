<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite obtener la lista de todos los [formatos de archivo compatibles](/net/comparison/getting-started/supported-document-formats/). Para ello, siga estos pasos:  

1. Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.
2. Recorra en iteración la colección de objetos <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.  

El siguiente fragmento de código muestra cómo obtener la lista de formatos de archivo compatibles:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using System;
using System.Collections.Generic;
using System.Linq;
using GroupDocs.Comparison.Result;
// ...

IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

</TabItem>

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite obtener el modelo de objetos del documento resultado tras la comparación.

Para obtener el objeto del documento resultado, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare" target="_blank" rel="nofollow noopener noreferrer">Compare</a> y asigne su valor devuelto a un objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a>.

Puede recuperar el nombre, la contraseña, los cambios, el flujo y otra información del documento utilizando el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a>. Además, nuestro modelo de objetos es totalmente compatible con los modelos de objetos de las bibliotecas Aspose.

Los fragmentos de código siguientes muestran cómo obtener los cambios y crear un nuevo documento de Aspose Word utilizando el modelo de objetos del documento resultado:

## Obtener el objeto del documento resultado y recuperar los cambios  {#obtain-the-result-document-object-and-get-changes}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
      comparer.Add("target.docx");
      GroupDocs.Comparison.Document resultDocument = comparer.Compare("result.docx");
      foreach (var change in resultDocument.Changes)
      {
          Console.ForegroundColor = ConsoleColor.Green;
          Console.Write("Source test: ");
          Console.ForegroundColor = ConsoleColor.White;
          Console.WriteLine(change.SourceText);

          Console.ForegroundColor = ConsoleColor.Blue;
          Console.Write("Target test: ");
          Console.ForegroundColor = ConsoleColor.White;
          Console.WriteLine(change.TargetText + "\n");
      }
}
```

## Crear un nuevo documento de Word basado en el documento resultado y modificar su contenido  {#create-a-new-word-document-based-on-the-result-document-and-modify-its-contents}
  
Puede utilizar el objeto Comparison <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> para generar documentos de Aspose y realizar modificaciones de forma transparente. El `resultDocument.Stream` contendrá un objeto de documento de Aspose correspondiente al formato que se está comparando.


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using Aspose.Words;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
      // Add target document and save comparison result to Comparison.Document object
      comparer.Add("target.docx");
      GroupDocs.Comparison.Document resultDocument = comparer.Compare("result.docx");

      // Create a new Aspose Document object of corresponding format.
      Aspose.Words.Document asposeDocument = new Aspose.Words.Document(resultDocument.Stream);

      // Access the Document's builder to add content.
      DocumentBuilder builder = new DocumentBuilder(asposeDocument);

      // Add some text to the document.
      builder.Writeln("Hello, World!");
      builder.Write("This is an example of using Aspose.Words.");

      // Save the document to a file.
      asposeDocument.Save("output.docx");
}
```

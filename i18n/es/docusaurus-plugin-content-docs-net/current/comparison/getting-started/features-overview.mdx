## Comparación de archivos  {#file-comparison}
  
<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> permite detectar diferencias entre los archivos de origen y destino a nivel de párrafos, palabras y caracteres. Asimismo, puede identificar cambios en el estilo y formato, como negritas, cursivas, subrayados, tachados, tipos de fuente, etc. Consulte [Comparar documentos](/net/comparison/comparison-basic/compare-documents/) para ver un ejemplo funcional.

## Aplicar o rechazar cambios entre documentos  {#apply-reject-changes-between-documents}
  
Cada diferencia detectada entre los documentos comparados puede aplicarse o rechazarse, y posteriormente exportarse al documento de salida. Consulte [Aceptar o rechazar los cambios detectados](/net/comparison/advanced-usage/comparison/accept-or-reject-detected-changes/) y [Aceptar o rechazar revisiones](/net/comparison/advanced-usage/accept-or-reject-revisions/).

## Extracción de información del documento  {#document-information-extraction}
  
GroupDocs.Comparison permite obtener información básica sobre los documentos de origen, como el tipo de archivo, tamaño, número de páginas, etc. Por ejemplo, puede utilizar esta funcionalidad para generar vistas previas de los documentos comparados. Consulte [Obtener información del archivo](/net/comparison/comparison-basic/get-file-info/).

## Informe resumen de comparación  {#comparison-summary-report}
  
Una vez finalizado el proceso de comparación, puede guardar un informe resumen de diferencias que enumere todos los cambios detectados en los documentos comparados. Consulte [Obtener información extendida en la página resumen](/net/comparison/advanced-usage/comparison/get-extended-information-on-the-summary-page/).

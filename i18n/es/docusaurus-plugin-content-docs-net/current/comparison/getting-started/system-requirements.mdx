## Información general {#overview}

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison para .NET</a> no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Instalación](/net/comparison/getting-started/installation/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Comparison para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado .NET o .NET Core, incluidos, entre otros:

### Windows {#windows}

- Microsoft Windows Server 2003 y versiones posteriores
- Microsoft Windows Vista (x64, x86)
- Microsoft Windows XP (x64, x86)
- Microsoft Windows 7, 8, 8.1 (x64, x86)
- Microsoft Windows 10 (x64, x86)
- Microsoft Windows 11 (x64)

### Linux {#linux}

- Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac {#mac}

- Mac OS X

## Frameworks compatibles {#supported-frameworks}

GroupDocs.Comparison para .NET admite los siguientes frameworks de .NET:

### .NET {#net}
- .NET 6

### .NET Core {#net-core}
- .NET Core 3.1

### .NET Standard {#net-standard}
- .NET Standard 2.1

### .NET Framework {#net-framework}

- .NET Framework 2.0 (hasta GroupDocs.Comparison 22.6)
- .NET Framework 3.5 (hasta GroupDocs.Comparison 22.6)
- .NET Framework 4.0 (hasta GroupDocs.Comparison 23.8)
- .NET Framework 4.5.0 (hasta GroupDocs.Comparison 23.8)
- .NET Framework 4.5.1 (hasta GroupDocs.Comparison 23.8)
- .NET Framework 4.5.2 (hasta GroupDocs.Comparison 23.8)
- .NET Framework 4.6.0 (hasta GroupDocs.Comparison 23.8)
- .NET Framework 4.6.2
- .NET Framework 4.5.0
- .NET Framework 4.5.1
- .NET Framework 4.6.0
- .NET Framework 4.6.2
- .NET Framework 4.7
- .NET Framework 4.7.2
- .NET Framework 4.8

## Entornos de desarrollo {#development-environments}

GroupDocs.Comparison para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los entornos explícitamente compatibles son los siguientes:

- Microsoft Visual Studio 2010 y versiones posteriores
- Microsoft Visual Studio para Mac
- Rider de JetBrains

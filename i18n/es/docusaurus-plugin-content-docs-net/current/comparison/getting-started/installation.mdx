Este tema describe cómo agregar la biblioteca GroupDocs.Comparison a su proyecto .NET. Puede utilizar un paquete de NuGet para instalar esta biblioteca o descargar los DLL necesarios desde el sitio web de GroupDocs: <a href="https://releases.groupdocs.com/comparison/net/" target="_blank" rel="nofollow noopener noreferrer">https://releases.groupdocs.com/comparison/net/</a>.

## Instalar GroupDocs.Comparison mediante paquetes de NuGet {#install-groupdocs-comparison-using-nuget-packages}
  
Puede utilizar las siguientes herramientas para instalar el paquete de NuGet <a href="https://www.nuget.org/packages/GroupDocs.Comparison" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a>:  

 * [Administrador de paquetes de NuGet](#use-the-nuget-package-manager-in-visual-studio)
 * [Consola del Administrador de paquetes](#use-the-package-manager-console-in-visual-studio)
 * [CLI de .NET](#use-the-net-cli)

### Utilizar el Administrador de paquetes de NuGet {#use-the-nuget-package-manager}
  
Abra su proyecto o solución en Visual Studio y siga los pasos a continuación para instalar el paquete GroupDocs.Comparison mediante el <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-visual-studio" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes de NuGet</a>:  

1. En el **Explorador de soluciones**, haga clic con el botón derecho sobre el nombre de su proyecto y seleccione **Administrar paquetes de NuGet** para mostrar el Administrador de paquetes de NuGet.  

2. Seleccione la pestaña **Examinar** y escriba `GroupDocs.Compariso` en el cuadro de búsqueda. Seleccione la versión más reciente del paquete GroupDocs.Comparison y haga clic en **Instalar**.

    ![](/net/comparison/images/installation.png)

### Use the Package Manager Console {#use-the-package-manager-console}
  
El <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-powershell" target="_blank" rel="nofollow noopener noreferrer">Package Manager Console</a> utiliza comandos de PowerShell para instalar, actualizar y eliminar paquetes de NuGet. Abra el proyecto en Visual Studio y haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de paquetes** para abrir la ventana de la consola. Para instalar la versión más reciente de la biblioteca GroupDocs.Comparison, ejecute el siguiente comando:


<Tabs groupId="example1">


<TabItem value="powershell" label="PowerShell" default>

```
PM> Install-Package GroupDocs.Comparison
```

</TabItem>


</Tabs>


![Use Package Manager Console ](/net/comparison/images/installation_1.png)

### Utilice la CLI de .NET {#use-the-net-cli}
  
Puede utilizar la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">herramienta CLI de .NET</a> para instalar y actualizar paquetes de NuGet. En la carpeta de su proyecto, abra una terminal y ejecute el siguiente comando para instalar el paquete GroupDocs.Comparison:


<Tabs groupId="example2">


<TabItem value="net-cli" label=".NET CLI" default>

```
dotnet add package GroupDocs.Comparison
```

</TabItem>


</Tabs>


## Descargar GroupDocs.Comparison desde el sitio web oficial  {#download-groupdocs-comparison-from-the-official-website}
  
Visite la lista de versiones de GroupDocs.Comparison y descargue los ensamblados de GroupDocs.Comparison como un archivo ZIP o un instalador MSI. Para hacer referencia a los archivos de ensamblado descargados en su proyecto, siga estos pasos:  

1. Extraiga los archivos del archivo ZIP o ejecute el instalador MSI para instalar GroupDocs.Comparison en una ubicación específica de su computadora.
2. Abra su solución o proyecto en Visual Studio.
3. En el **Explorador de soluciones**, haga clic derecho en el nodo **Referencias** o **Dependencias**, y seleccione **Agregar referencia** (para un proyecto de .NET Framework) o **Agregar referencia de proyecto** (para un proyecto de .NET Core).
4. En el cuadro de diálogo **Administrador de referencias**, seleccione la pestaña **Examinar** y haga clic en **Examinar** para localizar el archivo _GroupDocs.Comparison.dll_ correspondiente al marco de trabajo objetivo.
5. Haga clic en **Aceptar** para agregar una referencia a la biblioteca GroupDocs.Comparison en su proyecto.


:::warning
Si su aplicación tiene como objetivo .NET Core / .NET 5 o versiones posteriores, asegúrese de que su proyecto tenga todas las dependencias necesarias instaladas. Consulte la siguiente página para obtener más detalles: <a href="https://www.nuget.org/packages/groupdocs.comparison#dependencies-body-tab" target="_blank" rel="nofollow noopener noreferrer">Dependencias de GroupDocs.Comparison</a>.
:::

A veces, para estudiar mejor el sistema, desea acceder al código lo más rápido posible. Para facilitar esto, GroupDocs.Comparison ofrece distintos planes de compra, o bien proporciona una prueba gratuita y una licencia temporal de 30 días para su evaluación.


:::info
Tenga en cuenta que existen varias políticas y prácticas generales que le guían sobre cómo evaluar, licenciar adecuadamente y adquirir nuestros productos. :::


## Prueba gratuita o licencia temporal  {#free-trial-or-temporary-license}
  
Puede probar GroupDocs.Comparison sin adquirir una licencia.  

### Prueba gratuita  {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida; simplemente, la versión de evaluación se convierte en una versión con licencia cuando establece la licencia. Puede configurar la licencia de varias maneras, como se describe en las siguientes secciones de este artículo.  

La versión de evaluación presenta las siguientes limitaciones:  

- Solo se pueden procesar las primeras 2 páginas.
- Se colocan marcas de prueba en la parte superior de cada página del documento.  

### Licencia temporal  {#temporary-license}
  
Si desea probar GroupDocs.Annotation sin las limitaciones de la versión de prueba, también puede solicitar una Licencia temporal de 30 días. Para más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">«Obtener una licencia temporal»</a>.  

## Cómo establecer una licencia  {#how-to-set-a-license}


:::info
Puede encontrar la información sobre precios en la página <a href="https://purchase.conholdate.com/pricing/" target="_blank">«Información sobre precios»</a>.
:::


Después de obtener la licencia, debe configurarla. Esta sección describe las distintas formas de configurar la licencia.

La licencia debe configurarse:

- Solo una vez por dominio de aplicación.
- Antes de utilizar cualquier otra clase de GroupDocs.Annotation.


:::info
La licencia se puede configurar varias veces por dominio de aplicación, pero recomendamos hacerlo una sola vez, ya que todas las llamadas a `SetLicense`, excepto la primera, solo desperdiciarán tiempo de procesador.
:::


### Establecer licencia desde un archivo  {#set-license-from-file}
  
El siguiente fragmento de código muestra cómo establecer una licencia desde un archivo:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>


```csharp
using GroupDocs.Comparison;
// ...

string licensePath = "path to the .lic file";
License license = new License();
license.SetLicense(licensePath);
```


</TabItem>


</Tabs>



### Establecer licencia desde un flujo  {#set-license-from-stream}
  
El siguiente fragmento de código muestra cómo establecer una licencia desde un flujo:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>


```csharp
using GroupDocs.Comparison;
using System.IO;
// ...

string licensePath = "path to the .lic file";
using (FileStream fileStream = File.OpenRead(licensePath))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```


</TabItem>


</Tabs>



### Establecer licencia medible  {#set-metered-license}
  
También puede configurar la licencia <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las funciones de la API. Para obtener más información, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias medibles</a>.  

El siguiente fragmento de código muestra cómo utilizar la licencia `Metered`:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>


```csharp
using System;
using GroupDocs.Comparison;
// ...

string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Comparison.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Comparison.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```


</TabItem>


</Tabs>

:::warning
Asegúrese de que GroupDocs.Comparison se haya instalado correctamente antes de ejecutar los ejemplos.
:::


Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de <a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a>, ya sea construyendo los suyos propios o utilizando directamente nuestros ejemplos de backend o frontend.

Elija una opción de la siguiente lista:

## Construir el proyecto desde cero {#build-project-from-scratch}

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2. Seleccione el tipo de proyecto adecuado: aplicación de consola, aplicación web ASP.NET, etc.
3. Instale **GroupDocs.Comparison para .NET** desde NuGet o desde el sitio web oficial de GroupDocs, siguiendo la [guía](/net/comparison/getting-started/installation/).
4. Desarrolle su primera aplicación con **GroupDocs.Comparison para .NET**, como se muestra a continuación:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
// ...

string sourceDocumentPath = @"C:\source.docx"; // NOTE: Put here actual path to source document
string targetDocumentPath = @"C:\target.docx"; // NOTE: Put here actual path to source document
string outputPath = @"C:\result.docx"; // NOTE: Put here actual path to source document

using (Comparer comparer = new Comparer(sourceDocumentPath))
{
    comparer.Add(targetDocumentPath);
    comparer.Compare(outputPath);
}
```

</TabItem>


</Tabs>


5. Compile y ejecute su proyecto.
6. Revise las páginas del documento renderizado en la ruta especificada en el parámetro _"outputPath"_.

## Ejecute ejemplos del backend {#run-back-end-examples}

El repositorio de <a href="https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a> alberga el paquete completo de ejemplos de GroupDocs.Comparison. Puede <a href="https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">descargar el archivo ZIP</a> o clonar el repositorio de GitHub utilizando su cliente de git preferido.  
Si descarga el archivo ZIP, extraiga su contenido en su disco local. Los archivos y carpetas extraídos tendrán la siguiente estructura:

![](/net/comparison/images/how-to-run-examples.jpg)

En los archivos y carpetas extraídos, puede encontrar el archivo de solución de C#. El proyecto se creó utilizando Visual Studio 2019. La carpeta **Resources** contiene todos los archivos de documentos y imágenes de ejemplo utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias faltantes de GroupDocs.Comparison, consulte [la guía de instalación](/net/comparison/getting-started/installation/). El archivo **RunExamples.cs** llama a todas las funciones.
Descomente la función que desea ejecutar y comente el resto.

![](/net/comparison/images/how-to-run-examples_1.png)

## Ejemplos de MVC {#run-mvc-examples}

Para ejecutar <a href="https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET-MVC" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison para .NET Ejemplo MVC</a>, siga estos pasos:

1. Descargue <a href="https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET-MVC/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">el código fuente</a> desde GitHub o clonar este repositorio:

<Tabs groupId="example2">


<TabItem value="cli" label="CLI" default>

  ```git
  git clone https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET-MVC
  ```

</TabItem>


</Tabs>


2. Abra la solución en Visual Studio. Actualice los parámetros comunes en **web.config** y las propiedades relacionadas con el ejemplo en **configuration.yml** para satisfacer sus necesidades.
3. Abra <a href="http://localhost:8080/comparison" target="_blank" rel="nofollow noopener noreferrer">http://localhost:8080/comparison</a> en su navegador favorito

Para obtener más detalles sobre la configuración del proyecto, consulte esta <a href="https://github.com/groupdocs-comparison/GroupDocs.Comparison-for-.NET-MVC#configuration" target="_blank" rel="nofollow noopener noreferrer">guía</a>.

## Ejecutar mediante Docker {#run-using-docker}

Utilice la imagen de <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> para probar fácilmente las funcionalidades de GroupDocs.Comparison para .NET. Ejecute los siguientes comandos para ejecutar GroupDocs.Comparison para .NET desde la imagen de Docker:


<Tabs groupId="example4">


<TabItem value="cli" label="CLI" default>

```powershell
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples -v `pwd`/Licenses:/home/groupdocs/app/Licenses groupdocs/comparison
## Open http://localhost:8080/comparison in your favorite browser.
```

</TabItem>


</Tabs>


## Contribuir {#contribute}

Para contribuir, puede bifurcar (fork) el repositorio, editar el código y crear una solicitud de extracción (pull request). Revisaremos los cambios e incluiremos la contribución en el repositorio si la consideramos útil.

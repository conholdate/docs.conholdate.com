:::info
GroupDocs.Comparison para .NET está incluido en Conholdate.Total for .NET.
:::


### ¿Por qué migrar?  {#why-to-migrate}
  
A continuación se presentan las principales razones para utilizar la nueva API actualizada proporcionada por GroupDocs.Comparison para .NET desde la versión 19.9:  

*   La clase `Comparer`, introducida como único punto de entrada para comparar documentos de cualquier formato de archivo admitido, con diversas opciones y la capacidad de aceptar o rechazar las diferencias en el documento de salida.
*    Opciones de comparación de documentos para todos los tipos de documentos. En lugar de utilizar opciones relacionadas con el documento, ahora las opciones están relacionadas únicamente con el tipo de comparación.
*    Las clases relacionadas con el documento en general se unificaron en una estructura común.
*    La arquitectura del producto se rediseñó desde cero para simplificar el paso de opciones y clases para manipular la comparación.
*    Los procedimientos para obtener información del documento y generar vistas previas se simplificaron.  

### ¿Cómo migrar?  {#how-to-migrate}
  
A continuación se presenta una breve comparación entre cómo comparar documentos con la API antigua y la nueva.  

### Estilo de codificación antiguo  {#old-coding-style}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

Comparer comparer = new Comparer();
ComparisonSettings settings = new ComparisonSettings()
{
    StyleChangeDetection = true
};
ICompareResult result = comparer.Compare("source.docx", @"target.docx", settings);
result.SaveDocument("result.docx");
```

</TabItem>


</Tabs>


### Nuevo estilo de codificación {#new-coding-style}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions compareOptions = new CompareOptions()
    {
        DetectStyleChanges = true
    };
	comparer.Compare("result.docx", compareOptions);
}
```

</TabItem>


</Tabs>

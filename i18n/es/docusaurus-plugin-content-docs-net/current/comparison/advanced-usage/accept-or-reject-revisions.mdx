<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite obtener revisiones desde un archivo en formato Docx, procesarlas y guardar el resultado del procesamiento.  
Para obtener revisiones de un documento, aceptar/rechazar revisiones y escribir el resultado del procesamiento en el archivo de salida, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler" target="_blank" rel="nofollow noopener noreferrer">RevisionHandler</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler/methods/getrevisions" target="_blank" rel="nofollow noopener noreferrer">GetRevisions</a> para obtener la lista de revisiones.
3.  Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisioninfo/properties/action" target="_blank" rel="nofollow noopener noreferrer">Action</a> del objeto que se va a modificar en el valor <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionaction" target="_blank" rel="nofollow noopener noreferrer">RevisionAction.Accept</a> o <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionaction" target="_blank" rel="nofollow noopener noreferrer">RevisionAction.Reject</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler/methods/applyrevisionchanges/index" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionChanges</a>. Especifique la instancia creada de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/applyrevisionoptions" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionOptions</a> y la ruta o el flujo del documento de salida, recopilando los cambios en las revisiones.  

Puede procesar todos los cambios juntos en una sola acción. Para manejar todos los cambios a la vez, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler" target="_blank" rel="nofollow noopener noreferrer">RevisionHandler</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler/methods/applyrevisionchanges/index" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionChanges</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/applyrevisionoptions" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionOptions</a> y uno de los valores (<a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionaction" target="_blank" rel="nofollow noopener noreferrer">RevisionAction.Accept</a>, <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionaction" target="_blank" rel="nofollow noopener noreferrer">RevisionAction.Reject</a> o <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionaction" target="_blank" rel="nofollow noopener noreferrer">RevisionAction.None</a>).  

Las propiedades principales de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/applyrevisionoptions" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionOptions</a> son las siguientes:  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/applyrevisionoptions/properties/changes" target="_blank" rel="nofollow noopener noreferrer">Changes</a> es una lista de cambios de revisión que deben aplicarse al documento final.
*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/applyrevisionoptions/fields/commonhandler" target="_blank" rel="nofollow noopener noreferrer">CommonHandler</a> le permite definir una única acción para manejar todas las revisiones.  

Si no especifica la ruta o el archivo del documento de salida para el método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.words.revision/revisionhandler/methods/applyrevisionchanges" target="_blank" rel="nofollow noopener noreferrer">ApplyRevisionChanges</a>, el archivo de origen se sobrescribe.  

Los fragmentos de código siguientes muestran cómo obtener revisiones de un documento, aceptar/rechazar las revisiones detectadas y guardar los cambios en el documento de salida:  

## Aceptar o rechazar revisiones desde el disco local  {#accept-or-reject-revisions-from-local-disk}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.Collections.Generic;
using GroupDocs.Comparison.Words.Revision;
// ...

using (RevisionHandler revisionHandler = new RevisionHandler(
    pathRevision + "Document_with_revision.docx"))
{
    List<RevisionInfo> revisionList = revisionHandler.GetRevisions();
    foreach (RevisionInfo revision in revisionList)
    {
        if (revision.Type == RevisionType.Insertion) revision.Action = RevisionAction.Accept;
    }
    revisionHandler.ApplyRevisionChanges(pathRevision + "result.docx", new ApplyRevisionOptions() 
    { 
        Changes = revisionList 
    });
}
```

</TabItem>


</Tabs>


## Aceptar o rechazar revisiones desde el flujo  {#accept-or-reject-revisions-from-stream}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.Collections.Generic;
using GroupDocs.Comparison.Words.Revision;
// ...

using (RevisionHandler revisionHandler = new RevisionHandler(
    File.OpenRead("Document_with_revision.docx")))
{
    List<RevisionInfo> revisionList = revisionHandler.GetRevisions();
    foreach (RevisionInfo revision in revisionList)
    {
        if (revision.Type == RevisionType.Insertion) revision.Action = RevisionAction.Accept;
    }
    revisionHandler.ApplyRevisionChanges(pathRevision + "result.docx", new ApplyRevisionOptions() 
    { 
        Changes = revisionList 
    });
}
```

</TabItem>


</Tabs>


## Aceptar o rechazar todas las revisiones  {#accept-or-reject-all-revisions}


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.Collections.Generic;
using GroupDocs.Comparison.Words.Revision;
// ...

using (RevisionHandler revisionHandler = new RevisionHandler(
    pathRevision + "Document_with_revision.docx"))
{
    revisionHandler.ApplyRevisionChanges(pathRevision + "result.docx", new ApplyRevisionOptions() 
    { 
        CommonHandler = RevisionAction.Accept 
    });
}
```

</TabItem>


</Tabs>

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite detectar los cambios entre los archivos de origen y destino, y mostrar dichos cambios en una página independiente: <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/generatesummarypage" target="_blank" rel="nofollow noopener noreferrer">SummaryPage</a>.  
También puede obtener información detallada sobre la comparación de documentos, la cual se muestra en <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/generatesummarypage" target="_blank" rel="nofollow noopener noreferrer">SummaryPage</a>.

Para obtener información detallada, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/extendedsummarypage" target="_blank" rel="nofollow noopener noreferrer">ExtendedSummaryPage</a> en `true`.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> obtenido en el paso anterior.

El siguiente fragmento de código muestra cómo obtener información detallada:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions options = new CompareOptions() {ExtendedSummaryPage = true};
    comparer.Compare("result.docx", options);
}
```

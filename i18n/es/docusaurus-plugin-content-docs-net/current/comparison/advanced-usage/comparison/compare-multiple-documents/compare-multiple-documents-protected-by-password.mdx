:::info
GroupDocs.Comparison para .NET está incluido en Conholdate.Total for .NET.
:::



:::info
Esta función solo está disponible para documentos de Word, PowerPoint y presentaciones de Open Document.
:::


<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite comparar más de dos documentos protegidos con contraseña.

Para comparar varios documentos protegidos con contraseña, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Especifique la contraseña del documento fuente.
2.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento fuente y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.
3.  Instancie otro objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> y especifique la contraseña del documento de destino.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a> y especifique la ruta o el flujo del documento de destino y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior. Repita los pasos 3 y 4 para cada documento de destino.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a>.

El siguiente fragmento de código muestra cómo comparar varios documentos protegidos con contraseña:

## Comparar varios documentos protegidos con contraseña desde el disco local {#compare-several-password-protected-documents-from-local-disk}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx", new LoadOptions() { Password = "1234" }))
{
    comparer.Add("target1.docx", new LoadOptions() { Password = "5678" });
    comparer.Add("target2.docx", new LoadOptions() { Password = "5678" });
    comparer.Add("target3.docx", new LoadOptions() { Password = "5678" });
    comparer.Compare("result.docx");
}
```

</TabItem>


</Tabs>


## Comparar varios documentos protegidos con contraseña desde un flujo  {#compare-several-password-protected-documents-from-stream}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer(
    File.OpenRead("source.docx"), new LoadOptions() { Password = "1234" }))
{
    comparer.Add(File.OpenRead("target1.docx"), new LoadOptions() { Password = "5678" });
    comparer.Add(File.OpenRead("target2.docx"), new LoadOptions() { Password = "5678" });
    comparer.Add(File.OpenRead("target3.docx"), new LoadOptions() { Password = "5678" });
    comparer.Compare(File.Create("result.docx"));
}
```

</TabItem>

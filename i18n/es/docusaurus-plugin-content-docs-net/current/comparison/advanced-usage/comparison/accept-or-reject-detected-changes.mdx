<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite aplicar o descartar cambios específicos entre los documentos fuente y destino, y guardar el documento de salida con (o sin) los cambios seleccionados.

Para aplicar/rechazar cambios en el documento de salida, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento fuente.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento destino.
3.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/getchanges/index" target="_blank" rel="nofollow noopener noreferrer">GetChanges</a> para obtener la lista de cambios.
5.  Establezca la <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/changeinfo/properties/comparisonaction" target="_blank" rel="nofollow noopener noreferrer">ComparisonAction</a> del objeto de cambio correspondiente en el valor <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/comparisonaction" target="_blank" rel="nofollow noopener noreferrer">ComparisonAction.Accept</a> o <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/comparisonaction" target="_blank" rel="nofollow noopener noreferrer">ComparisonAction.Reject</a>.
6.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/applychanges/index" target="_blank" rel="nofollow noopener noreferrer">ApplyChanges</a>. Especifique la colección de cambios.

La clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/applychangeoptions" target="_blank" rel="nofollow noopener noreferrer">ApplyChangeOptions</a> incluye las siguientes propiedades:  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/applychangeoptions/properties/changes" target="_blank" rel="nofollow noopener noreferrer">Changes</a> es una lista de cambios que deben aplicarse (o no) al documento de salida.  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/applychangeoptions/properties/saveoriginalstate" target="_blank" rel="nofollow noopener noreferrer">SaveOriginalState</a> es una opción para conservar el estado original del resultado comparado tras aplicar los cambios.

Los fragmentos de código siguientes muestran cómo aceptar/rechazar cambios:

## Aceptar o rechazar cambios para documentos almacenados en el disco local  {#accept-or-reject-changes-for-documents-stored-at-local-disk}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using GroupDocs.Comparison.Result;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare();
    ChangeInfo[] changes = comparer.GetChanges();
    changes[0].ComparisonAction = ComparisonAction.Reject;
    comparer.ApplyChanges(File.Create("result.docx"), new SaveOptions(), new ApplyChangeOptions() 
    { 
      Changes = changes 
    });
}
```

</TabItem>


</Tabs>

## Aceptar o rechazar cambios en documentos proporcionados como un flujo  {#accept-or-reject-changes-for-documents-provided-as-a-stream}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using GroupDocs.Comparison.Result;
using System.IO;
// ...

using (Comparer comparer = new Comparer(File.OpenRead("source.docx")))
{
    comparer.Add(File.OpenRead("target.docx"));
    comparer.Compare(new SaveOptions(), new CompareOptions());
    ChangeInfo[] changes = comparer.GetChanges(new GetChangeOptions());
    changes[0].ComparisonAction = ComparisonAction.Reject;
    comparer.ApplyChanges(File.Create("result.docx"), new SaveOptions(), new ApplyChangeOptions() 
    { 
      Changes = changes 
    });
}
```

## Aceptar o rechazar los cambios detectados mediante la opción SaveOriginalState  {#accept-or-reject-detected-changes-using-saveoriginalstate-option}


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using GroupDocs.Comparison.Result;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare();
    ChangeInfo[] changes = comparer.GetChanges();
    changes[0].ComparisonAction = ComparisonAction.Reject;
    comparer.ApplyChanges("resultWithRejectedChange.docx", new ApplyChangeOptions() 
    { 
      Changes = changes, SaveOriginalState = true 
    });
    changes = comparer.GetChanges();
    changes[0].ComparisonAction = ComparisonAction.Accept;
    comparer.ApplyChanges("resultWithAcceptedChange.docx", new ApplyChangeOptions() 
    { 
      Changes = changes 
    });
}
```

</TabItem>

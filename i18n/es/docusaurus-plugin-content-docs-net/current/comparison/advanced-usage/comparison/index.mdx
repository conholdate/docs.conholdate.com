<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> ofrece múltiples formas de personalizar la lógica del algoritmo de detección de cambios y la creación del archivo de salida mediante la configuración de las propiedades de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>.

Puede personalizar los siguientes parámetros:  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/calculatecoordinates" target="_blank" rel="nofollow noopener noreferrer">CalculateCoordinates</a> indica si se deben calcular las coordenadas de los componentes modificados.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/changeditemstyle" target="_blank" rel="nofollow noopener noreferrer">ChangedItemStyle</a> especifica el estilo de los elementos modificados.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/deleteditemstyle" target="_blank" rel="nofollow noopener noreferrer">DeletedItemStyle</a> especifica el estilo de los elementos eliminados.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/detalisationlevel" target="_blank" rel="nofollow noopener noreferrer">DetalisationLevel</a> obtiene o establece el nivel de detalle de la comparación.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/detectstylechanges" target="_blank" rel="nofollow noopener noreferrer">DetectStyleChanges</a> indica si se deben detectar o no los cambios de estilo.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/diagrammastersetting" target="_blank" rel="nofollow noopener noreferrer">DiagramMasterSetting</a> obtiene o establece la ruta al documento maestro, o bien utiliza la comparación sin un documento maestro (esta opción es solo para diagramas).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/generatesummarypage" target="_blank" rel="nofollow noopener noreferrer">GenerateSummaryPage</a> indica si se debe agregar una página resumen con estadísticas sobre los cambios detectados en el documento de salida o no.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/inserteditemstyle" target="_blank" rel="nofollow noopener noreferrer">InsertedItemStyle</a> especifica el estilo de los elementos insertados.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/markchangedcontent" target="_blank" rel="nofollow noopener noreferrer">MarkChangedContent</a> indica si se deben usar marcos para las formas en documentos de procesamiento de texto y para los rectángulos en documentos de imagen.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/marknestedcontent" target="_blank" rel="nofollow noopener noreferrer">MarkNestedContent</a> indica si se deben aceptar los estilos insertados/eliminados para todos los elementos secundarios de los elementos insertados/eliminados.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/originalsize" target="_blank" rel="nofollow noopener noreferrer">OriginalSize</a> obtiene o establece los tamaños originales de los documentos que se van a comparar.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/passwordsaveoption" target="_blank" rel="nofollow noopener noreferrer">PasswordSaveOption</a> obtiene o establece la opción de guardado de la contraseña. Para más detalles, consulte [aquí](/net/comparison/advanced-usage/saving/set-password-for-resultant-document/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/sensitivityofcomparison" target="_blank" rel="nofollow noopener noreferrer">SensitivityOfComparison</a> obtiene o establece la sensibilidad de la comparación. Para más detalles, consulte [aquí](/net/comparison/advanced-usage/comparison/adjusting-comparison-sensitivity/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> indica si se deben mostrar o no los componentes eliminados en el documento de salida.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> indica si se deben mostrar o no los componentes insertados en el documento de salida.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/wordsseparatorchars" target="_blank" rel="nofollow noopener noreferrer">WordsSeparatorChars</a> establece un array de delimitadores para dividir el texto en palabras.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparebookmarks" target="_blank" rel="nofollow noopener noreferrer">CompareBookmarks</a> indica si se deben comparar los marcadores. Consulte [Comparar marcadores en Word](/net/comparison/advanced-usage/comparison/compare-bookmarks-in-word/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparevariableproperty" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a> indica si se deben comparar las propiedades variables. Consulte [Comparar variables y propiedades del documento](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparedocumentproperty" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a> indica si se deben comparar las propiedades integradas y personalizadas. Consulte [Comparar variables y propiedades del documento](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showrevisions" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a> indica si se deben mostrar otras revisiones en el documento de salida. Consulte [Mostrar revisiones](/net/comparison/advanced-usage/comparison/show-revisions/).  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> indica si se deben mostrar líneas vacías en lugar de componentes insertados/eliminados en el documento final. Consulte [Mostrar líneas de separación](/net/comparison/advanced-usage/comparison/show-gap-lines/).

Para más detalles, consulte las siguientes guías:


:::tip
**Opciones específicas por formato:** Para documentos de Word, puede utilizar [WordCompareOptions](/net/comparison/advanced-usage/comparison/word-compare-options/) para controlar el modo de visualización de revisiones, la atribución de autores y la comparación de marcadores, además de las opciones generales `CompareOptions` mencionadas anteriormente.
:::

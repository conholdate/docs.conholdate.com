<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite detectar los cambios entre los documentos de origen y destino, y obtener las coordenadas de dichos cambios en las imágenes de vista previa del documento. Estas coordenadas pueden resultar útiles para resaltar los cambios en las imágenes de vista previa del documento.

Para obtener las coordenadas de los cambios, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/calculatecoordinates" target="_blank" rel="nofollow noopener noreferrer">CalculateCoordinates</a> en `true`.
4.  Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/calculatecoordinatesmode" target="_blank" rel="nofollow noopener noreferrer">CalculateCoordinatesMode</a> en `CalculateCoordinatesModeEnumeration.Source` o `CalculateCoordinatesModeEnumeration.Target` si desea obtener las coordenadas desde el documento de origen o destino, respectivamente.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> del paso anterior.
6.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/getchanges/index" target="_blank" rel="nofollow noopener noreferrer">GetChanges</a>.

El siguiente fragmento de código muestra cómo comparar múltiples documentos con opciones específicas:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Result;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions compareOptions = new CompareOptions(){ CalculateCoordinates = true };
    comparer.Compare(compareOptions);
    ChangeInfo[] changes = comparer.GetChanges();
    foreach (ChangeInfo change in changes)
        Console.WriteLine("Change Type: {0}, X: {1}, Y: {2}, Text: {3}", 
            change.Type, 
            change.Box.X, 
            change.Box.Y, 
            change.Text);
}
```

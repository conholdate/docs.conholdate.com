<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite establecer el nombre del autor de los cambios en el documento resultante. Para ello, siga estos pasos:  

1. Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta del archivo de origen o un flujo de entrada.  

2. Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta del archivo de destino o un flujo de entrada.  

3. Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a>. Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DisplayMode</a> en `Revisions` y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/showrevisions/" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a> en `true`.  

4. Establezca el autor de los cambios modificando la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionAuthorName</a>.  

5. Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Compare</a>. Especifique el objeto `WordCompareOptions` del paso anterior.  

El siguiente fragmento de código muestra cómo cambiar el autor de los cambios:


<Tabs groupId="example1">


<TabItem value="net" label=".NET" default>

```cs
using (Comparer comparer = new Comparer("source.docx"))
{
  comparer.Add("target.docx");

  WordCompareOptions options = new WordCompareOptions()
  {
    DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions,
    ShowRevisions = true,
    RevisionAuthorName = "New author",
  };

  comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>

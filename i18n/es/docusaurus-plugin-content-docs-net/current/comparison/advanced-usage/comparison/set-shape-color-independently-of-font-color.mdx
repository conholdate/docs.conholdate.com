<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> ofrece la opción de especificar el color para las formas modificadas.

Para comparar dos documentos con un color personalizado para las formas modificadas, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Especifique los parámetros <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/stylesettings/shapecolor/" target="_blank" rel="nofollow noopener noreferrer">ShapeColor</a> para los parámetros <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/inserteditemstyle/" target="_blank" rel="nofollow noopener noreferrer">InsertedItemStyle</a>/<a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/deleteditemstyle/" target="_blank" rel="nofollow noopener noreferrer">DeletedItemStyle</a>/<a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/changeditemstyle/" target="_blank" rel="nofollow noopener noreferrer">ChangedItemStyle</a>.
4. Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/markchangedcontent" target="_blank" rel="nofollow noopener noreferrer">MarkChangedContent</a> en true.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>.

Los fragmentos de código siguientes muestran cómo comparar documentos con opciones de color específicas para las formas:

## Comparar documentos desde el disco local con un color personalizado para las formas modificadas {#compare-documents-from-local-disk-with-custom-change-color-for-shapes}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions compareOptions = new CompareOptions()
    {
        DetectStyleChanges = true,
        MarkChangedContent = true,
        InsertedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Blue,
            ShapeColor = System.Drawing.Color.Purple
        },
        DeletedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Red,
            ShapeColor = System.Drawing.Color.Orange
        },
        ChangedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Green,
            ShapeColor = System.Drawing.Color.LightGreen
        }
    }
    comparer.Compare("result.docx", compareOptions);
}
```

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite ajustar la apariencia del documento de salida.

De forma predeterminada, los cambios procedentes de los dos archivos de entrada (archivo de origen y archivo de destino) se agregan al documento de salida y se resaltan. Utilice las propiedades <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> para configurar el contenido del archivo de salida.

Utilice la propiedad <a href="https://reference.groupdocs.com/error/404?path=comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a> para ajustar la visualización del documento de salida, lo que permite reemplazar el contenido modificado con líneas vacías. Para utilizar esta propiedad, active las propiedades <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a> y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a>.

Siga estos pasos para ajustar la apariencia del documento de salida:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del archivo de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del archivo de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Configure las propiedades <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showinsertedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowInsertedContent</a>, <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/showdeletedcontent" target="_blank" rel="nofollow noopener noreferrer">ShowDeletedContent</a> y/o <a href="https://reference.groupdocs.com/error/404?path=comparison/net/groupdocs.comparison.options/compareoptions/properties/leavegaps" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> del paso anterior.

El siguiente fragmento de código muestra cómo obtener el resultado deseado


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    CompareOptions options = new CompareOptions();
    options.ShowInsertedContent = false;
    options.ShowDeletedContent = false;
    options.LeaveGaps = true;

    comparer.Compare("result.docx", options);
}
```

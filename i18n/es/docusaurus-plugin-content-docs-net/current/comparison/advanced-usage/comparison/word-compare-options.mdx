<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> proporciona la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">WordCompareOptions</a> para configurar la comparación de documentos de Word (`.doc`, `.docx`, `.rtf` y otros formatos de procesamiento de texto). Dicha clase hereda de <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> e incorpora propiedades específicas para Word, destacando especialmente la propiedad `DisplayMode`, que controla cómo se escriben los cambios detectados en el documento resultante.

## Modos de visualización {#display-modes}
  
La propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DisplayMode</a> acepta uno de los dos valores de la enumeración `WordCompareOptions.ComparisonDisplayMode`:  

- **Revisions** (Revisión): los cambios se generan como marcas nativas de revisión (seguimiento de cambios) de Word. El documento resultante se abre en Microsoft Word con los controles **Revisar → Aceptar / Rechazar** listos para su uso.
- **Highlight** (Resaltado): el texto insertado, eliminado y modificado se representa mediante resaltados de color en línea directamente en el cuerpo del documento. No se añaden metadatos de seguimiento de cambios.

### Modo Revisions {#revisions-mode}


<Tabs groupId="example-revisions">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions
    };

    comparer.Compare("result.docx", options);
}
```

## Detectar cambios de estilo {#detect-style-changes}
  
Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">DetectStyleChanges</a> en `true` para incluir las diferencias de formato (negrita, tamaño de fuente, color, etc.) junto con las ediciones de texto.


<Tabs groupId="example-style">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        DisplayMode = WordCompareOptions.ComparisonDisplayMode.Revisions,
        DetectStyleChanges = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


## Comparar encabezados y pies de página  {#compare-headers-and-footers}
  
Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">HeaderFootersComparison</a> en `true` para incluir el contenido del encabezado y del pie de página en la comparación.


<Tabs groupId="example-headers">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        HeaderFootersComparison = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


## Marcar saltos de línea {#mark-line-breaks}
  
Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">MarkLineBreaks</a> en `true` para marcar visualmente los saltos de párrafo (línea) que difieren entre documentos.


<Tabs groupId="example-linebreaks">


<TabItem value="c" label="C#" default>

```csharp
using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");

    WordCompareOptions options = new WordCompareOptions
    {
        MarkLineBreaks = true
    };

    comparer.Compare("result.docx", options);
}
```

</TabItem>


</Tabs>


## Otras propiedades específicas de Word {#other-word-specific-properties}
  
Las propiedades que se indican a continuación también están disponibles en `WordCompareOptions`. Varias de ellas se documentan en artículos dedicados; siga los enlaces para obtener más detalles:  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareBookmarks</a>: compara marcadores en los documentos de origen y destino. Consulte [Comparar marcadores en documentos de Word](/net/comparison/advanced-usage/comparison/compare-bookmarks-in-word/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a>: compara propiedades de variables del documento (por ejemplo, campos `DOCVARIABLE`). Consulte [Comparar propiedades y variables del documento](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a>: compara propiedades integradas y personalizadas del documento. Consulte [Comparar propiedades y variables del documento](/net/comparison/advanced-usage/comparison/compare-of-variables-and-document-properties/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionAuthorName</a>: nombre del autor que se marca en las revisiones cuando `DisplayMode = Revisions`. Consulte [Establecer el autor de los cambios](/net/comparison/advanced-usage/comparison/setting-author-of-changes/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">ShowRevisions</a>: controla si las marcas de revisión permanecen visibles en el resultado. Consulte [Mostrar revisiones](/net/comparison/advanced-usage/comparison/show-revisions/).  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/wordcompareoptions/" target="_blank" rel="nofollow noopener noreferrer">LeaveGaps</a>: deja líneas vacías en lugar del contenido insertado o eliminado para preservar el diseño.  

Todas las propiedades base de <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> —`InsertedItemStyle`, `DeletedItemStyle`, `ChangedItemStyle`, `SensitivityOfComparison`, `GenerateSummaryPage`, y otras— también están disponibles en `WordCompareOptions`.

<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite deshabilitar la comparación de imágenes en documentos PDF.

De forma predeterminada, la opción `CompareImagesPdf` está `true`. Siga estos pasos para desactivar la comparación de imágenes:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta del archivo o el flujo de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta del archivo o el flujo de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/compareimagespdf" target="_blank" rel="nofollow noopener noreferrer">CompareImagesPdf</a> en `false`;
3.  Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/imagesinheritancemode" target="_blank" rel="nofollow noopener noreferrer">ImagesInheritanceMode</a> en `ImagesInheritance.Source` o `ImagesInheritance.Target`;
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> del paso anterior.

El siguiente fragmento de código muestra cómo deshabilitar la comparación de imágenes en documentos PDF:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.pdf"))
{
    comparer.Add("target.pdf");
    CompareOptions compareOptions = new CompareOptions()
    {
        CompareImagesPdf = false,
        ImagesInheritanceMode = ImagesInheritance.Target
    }
    comparer.Compare("result.pdf", compareOptions);
}
```

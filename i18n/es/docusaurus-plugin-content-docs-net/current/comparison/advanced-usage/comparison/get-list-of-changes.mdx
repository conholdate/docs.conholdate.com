<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite obtener una lista de cambios entre los documentos fuente y destino.

Para obtener la lista de cambios, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento fuente.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento destino.
3.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare" target="_blank" rel="nofollow noopener noreferrer">Compare</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/getchanges" target="_blank" rel="nofollow noopener noreferrer">GetChanges</a>.

La llamada Compare() sin argumentos realiza la comparación en memoria sin escribir un archivo de resultado; utilícela cuando solo necesite la lista de cambios y no necesite guardar el documento marcado.

Los fragmentos de código siguientes muestran cómo obtener la lista de todos los cambios:

## Obtener la lista de cambios desde el disco local  {#get-list-of-changes-from-local-disk}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare();
    ChangeInfo[] changes = comparer.GetChanges();
    foreach (ChangeInfo change in changes)
        Console.WriteLine("Change Type: {0}, Page: {1}, Change ID: {2}, Text: {3}", 
            change.Type, 
            change.PageInfo.PageNumber, 
            change.Id, 
            change.Text
        );
}
```

</TabItem>


</Tabs>

## Obtener lista de cambios desde el flujo  {#get-list-of-changes-from-stream}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer(File.OpenRead("source.docx")))
{
    comparer.Add(File.OpenRead("target.docx"));
    comparer.Compare();
    ChangeInfo[] changes = comparer.GetChanges();
    foreach (ChangeInfo change in changes)
        Console.WriteLine("Change Type: {0}, Page: {1}, Change ID: {2}, Text: {3}", 
            change.Type, 
            change.PageInfo.PageNumber, 
            change.Id, 
            change.Text
        );
}
```

</TabItem>

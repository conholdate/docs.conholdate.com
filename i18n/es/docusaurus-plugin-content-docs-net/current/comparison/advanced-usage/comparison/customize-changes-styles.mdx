<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> proporciona una colección de opciones de comparación para configurar la velocidad y calidad adecuadas de la comparación.

Para comparar dos documentos con configuraciones personalizadas de estilo de cambio, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Especifique los parámetros adecuados.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>.

Los fragmentos de código siguientes muestran cómo comparar documentos con opciones específicas:

## Comparar documentos desde el disco local con estilos de cambio personalizados {#compare-documents-from-local-disk-with-custom-change-styles}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions compareOptions = new CompareOptions()
    {
        InsertedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Red,
            FontColor = System.Drawing.Color.Green,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        },
        DeletedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Azure,
            FontColor = System.Drawing.Color.Brown,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        },
        ChangedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Crimson,
            FontColor = System.Drawing.Color.Firebrick,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        }
    };
    comparer.Compare("result.docx", compareOptions);
}
```

## Comparar documentos del flujo con estilos de cambio personalizados  {#compare-documents-from-stream-with-custom-change-styles}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer(File.OpenRead("source.docx")))
{
    comparer.Add(File.OpenRead("target.docx"));
    CompareOptions compareOptions = new CompareOptions()
    {
        InsertedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Red,
            FontColor = System.Drawing.Color.Green,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        },
        DeletedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Azure,
            FontColor = System.Drawing.Color.Brown,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        },
        ChangedItemStyle = new StyleSettings()
        {
            HighlightColor = System.Drawing.Color.Crimson,
            FontColor = System.Drawing.Color.Firebrick,
            IsUnderline = true,
            IsBold = true,
            IsStrikethrough = true,
            IsItalic = true
        }
    };
    comparer.Compare(File.Create("result.docx"), compareOptions);
}
```

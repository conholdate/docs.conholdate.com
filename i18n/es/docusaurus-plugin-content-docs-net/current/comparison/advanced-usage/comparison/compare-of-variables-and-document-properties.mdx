<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite comparar diversas propiedades de un documento de Word, como las propiedades _Variable_, _Incorporadas_ y _Personalizadas_.

Utilice los siguientes campos de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> para habilitar las funciones de comparación de propiedades del documento:  

- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparevariableproperty" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a> permite la comparación de propiedades _variables_
- <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparedocumentproperty" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a> permite la comparación de propiedades _incorporadas_ y _personalizadas_.

Para activar la comparación de propiedades del documento, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta del archivo o el flujo de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta del archivo o el flujo de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparevariableproperty" target="_blank" rel="nofollow noopener noreferrer">CompareVariableProperty</a> en `true` para las propiedades _variables_ y/o en <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/comparedocumentproperty" target="_blank" rel="nofollow noopener noreferrer">CompareDocumentProperty</a> para las propiedades _incorporadas_ y _personalizadas_.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> del paso anterior.

El siguiente fragmento de código muestra cómo activar la comparación de las propiedades Variable, Incorporadas y Personalizadas:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions options = new CompareOptions();
    options.CompareVariableProperty = true; // to activate the comparison of variable properties
    options.CompareDocumentProperty = true; // to activate the comparison of built and custom properties

    comparer.Compare("result.docx", options);
}
```

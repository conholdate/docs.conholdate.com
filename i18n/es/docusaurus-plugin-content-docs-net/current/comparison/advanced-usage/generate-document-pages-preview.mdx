<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite generar vistas previas de página para el documento de origen, el documento de destino y los documentos de salida, utilizando el método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document" target="_blank" rel="nofollow noopener noreferrer">Document</a>.

Utilice la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> para gestionar el proceso de generación de vistas previas: especifique los números de página deseados, el formato de imagen, etc.

Para generar la vista previa del documento mediante la API de GroupDocs.Comparison, siga estos pasos:

1.  Cree una instancia de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta del documento de origen como parámetro del constructor.
2.  Añada el documento de destino a la comparación mediante el método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>.
3.  Las propiedades <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/source" target="_blank" rel="nofollow noopener noreferrer">Source</a> y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/targets" target="_blank" rel="nofollow noopener noreferrer">Targets</a> del objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> le permiten acceder a los documentos de origen y destino, y proporcionan el método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a>;
4.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>. Especifique los siguientes parámetros:
    *   delegate for each page stream creation (see the CreatePageStream event handler)
    *   image preview format - PNG / JPG / BMP
    *   page numbers to process
    *   custom size of preview images (if needed)
    
:::info  
El flujo creado por el delegado <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> se libera automáticamente cuando se genera la imagen de vista previa. Si necesita implementar la liberación personalizada del flujo de vista previa de la imagen, especifique el argumento <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> para limpiar los recursos.
:::

5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de los documentos <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/source" target="_blank" rel="nofollow noopener noreferrer">Source</a> y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/properties/targets" target="_blank" rel="nofollow noopener noreferrer">Targets</a>. Especifique el <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>.

Las propiedades principales de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> son las siguientes:  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> es un delegado que define el método para crear el flujo de vista previa de la página de salida.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/fields/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> es un delegado que define el método para eliminar el flujo de vista previa de la página de salida. Esto puede utilizarse cuando se requiere un control avanzado sobre la gestión de recursos.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> es el ancho de la imagen de vista previa. Utilice esta propiedad para personalizar el ancho de la imagen de salida.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> es el alto de la imagen de vista previa. Utilice esta propiedad para personalizar el alto de la imagen de salida.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/Resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a> permite configurar los valores de resolución horizontal y vertical para la generación de la vista previa de la imagen.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/pagenumbers" target="_blank" rel="nofollow noopener noreferrer">PageNumbers</a> define el número de páginas que se generarán como vista previa.  

*   <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/previewoptions/properties/previewformat" target="_blank" rel="nofollow noopener noreferrer">PreviewFormat</a> obtiene o establece el formato de la imagen de vista previa, lo que permite elegir entre calidad y tamaño de imagen. Utilice el formato BMP para obtener la mejor calidad de imagen. Utilice el formato JPG para obtener el tamaño de imagen más pequeño (y vistas previas de carga más rápidas), aunque con una calidad inferior a la del BMP. De forma predeterminada, GroupDocs.Comparison utiliza el formato PNG para ofrecer una calidad y tamaño de imagen adecuados.

El siguiente fragmento de código muestra cómo generar vistas previas de documentos:  

## Obtener vistas previas de página para el documento de origen {#get-page-previews-for-source-document}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"D:\Temp\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    comparer.Source.GeneratePreview(previewOptions);
}
```

## Obtener vistas previas de página para el documento de destino {#get-page-previews-for-target-document}


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    comparer.Targets[0].GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Obtener vistas previas de página para el documento de salida {#get-page-previews-for-output-document}


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
    Document document = new Document(File.OpenRead("result.docx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Establecer tamaño y resolución específicos para las imágenes de vista previa  {#set-specific-size-and-resolution-for-preview-images}


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Comparer comparer = new Comparer("source.pptx"))
{
    comparer.Add("target.pptx");
    comparer.Compare("result.pptx");
    Document document = new Document(File.OpenRead("result.pptx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    previewOptions.Height = 1000;
    previewOptions.Width = 1000;

    previewOptions.Resolution = new PreviewResolution()
    {
      HorizontalResolution = 300,
      VerticalResolution = 300
    };

    document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>



:::info
Esta función no es compatible con documentos de procesamiento de texto.
:::


## Obtener vistas previas de páginas y limpiar recursos manualmente  {#get-page-previews-and-clean-resources-manually}


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

// Method should match with ReleasePageStream delegate signature
private void UserReleaseStreamMethod(int pageNumber, Stream stream)
{
    Console.WriteLine($"Releasing memory for page: {pageNumber}");
    stream.Close();
}

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx");
    Document document = new Document(File.OpenRead("result.docx"));
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = Path.Combine(@"C:\", $"result_{pageNumber}.png");
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2 };
    // here we set delegate target method
    previewOptions.ReleasePageStream = UserReleaseStreamMethod;
    document.GeneratePreview(previewOptions);
}
```

</TabItem>

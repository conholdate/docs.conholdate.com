<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite comparar el contenido de una carpeta (directorio), procesar y guardar el resultado del procesamiento. A continuación se describen los pasos para _iniciar la comparación_ y _configurar_ la visualización del resultado del procesamiento en el archivo resultante.

1. Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>.
1. Establezca la propiedad `DirectoryCompare` en `true`.
1. Si es necesario, establezca la propiedad `setFolderComparisonExtension` para cambiar el formato de salida a `HTML`. De forma predeterminada, el formato es `TXT`.
1. Si es necesario, establezca la propiedad `ShowOnlyChanged` en `true` para mostrar únicamente los elementos modificados.
2. Inicialice el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta de la primera carpeta a comparar y el objeto `CompareOptions`.
3. Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/add/#add_*" target="_blank" rel="nofollow noopener noreferrer">Add</a> del objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta de la segunda carpeta y el objeto `CompareOptions`.
4. Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/compare/#compare" target="_blank" rel="nofollow noopener noreferrer">Compare</a> del objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta donde guardar los resultados de la comparación y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>.

El siguiente fragmento de código muestra cómo comparar las carpetas `SourceFolder` y `TargetFolder`:


<Tabs groupId="example1">


<TabItem value="net" label=".NET" default>

```cs
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
class YoursProgram
{
    static void Main(string[] args)
    {
        CompareOptions compareOptions = new CompareOptions
        {
            DirectoryCompare = true,
        };
        Comparer comparer = new Comparer("C:\\SourceFolder", compareOptions);
        comparer.Add("C:\\TargetFolder", compareOptions);
        comparer.Compare("C:\\Folder_to_save_result\\", compareOptions);
    }
}
```

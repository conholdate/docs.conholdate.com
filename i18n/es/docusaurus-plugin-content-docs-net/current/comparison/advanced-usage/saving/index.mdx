<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> ofrece distintas formas de guardar el documento de salida: con contraseña, selección del origen de los metadatos del documento, etc.

La clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> proporciona las siguientes propiedades para personalizar el proceso de guardado:  

*   CloneMetadataType: obtiene o establece un valor que indica si se deben clonar los metadatos en el documento de destino o no.  

*   FileAuthorMetadata: permite establecer los valores de metadatos proporcionados por el usuario.  

*   Password: obtiene o establece la contraseña para el documento resultante.

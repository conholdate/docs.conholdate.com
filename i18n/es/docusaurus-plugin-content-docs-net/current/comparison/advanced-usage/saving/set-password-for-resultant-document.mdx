<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite proteger el documento de salida con una contraseña.

Para proteger el documento de salida, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a>. Establezca <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions/properties/passwordsaveoption" target="_blank" rel="nofollow noopener noreferrer">PasswordSaveOption</a> en `PasswordSaveOption.User`.
4.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>. Utilice la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions/properties/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> para especificar una cadena de contraseña.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a>. Pase los objetos <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> y <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/compareoptions" target="_blank" rel="nofollow noopener noreferrer">CompareOptions</a> como parámetros.

El siguiente fragmento de código muestra cómo comparar documentos y proteger el documento de salida con una contraseña:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    CompareOptions cOptions = new CompareOptions
    {
        PasswordSaveOption = PasswordSaveOption.User
    };
    SaveOptions sOptions = new SaveOptions()
    {
        Password = "3333"
    };
    comparer.Compare("result.docx", sOptions, cOptions);
}
```

El documento puede contener cierta información de metadatos, como autor, organización, etc. <a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite seleccionar el origen de los metadatos al guardar el documento de salida.

Los posibles orígenes de metadatos son los siguientes:

- Metadatos del documento de origen
- Metadatos del documento de destino
- Metadatos definidos por el usuario

Para establecer los metadatos del documento de salida, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen.
2.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino.
3.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions/properties/clonemetadatatype" target="_blank" rel="nofollow noopener noreferrer">CloneMetadataType</a> en la variante <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/metadatatype" target="_blank" rel="nofollow noopener noreferrer">MetadataType</a> adecuada.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/compare/index" target="_blank" rel="nofollow noopener noreferrer">Compare</a>. Especifique el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> como parámetro.

Los fragmentos de código siguientes muestran cómo establecer los metadatos del documento de salida:

## Establecer metadatos desde el archivo de origen {#set-metadata-from-source-file}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    comparer.Compare("result.docx", new SaveOptions() { CloneMetadataType = MetadataType.Source });
}
```

</TabItem>


</Tabs>

## Establecer metadatos definidos por el usuario  {#set-user-defined-metadata}


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source.docx"))
{
    comparer.Add("target.docx");
    SaveOptions saveOptions = new SaveOptions()
    {
        CloneMetadataType = MetadataType.FileAuthor,
        FileAuthorMetadata = new FileAuthorMetadata
        {
            Author = "Tom",
            Company = "GroupDocs",
            LastSaveBy = "Jack"
        }
    };
    comparer.Compare("result.docx", saveOptions);
}
```

</TabItem>


</Tabs>

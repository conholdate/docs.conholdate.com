Para evitar guardar el flujo como un archivo, <a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite trabajar directamente con flujos de archivos.

Para trabajar con flujos, siga estos pasos:

1.  Obtenga el flujo del archivo.
2.  Pase el flujo del archivo de origen abierto al constructor de la clase <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a> o pase el flujo del archivo de destino abierto al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>.

El siguiente fragmento de código muestra cómo cargar un archivo desde un flujo:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using System.IO;
// ...

using (Stream sourceStream = File.OpenRead("source.docx"))
using (Stream targetStream = File.OpenRead("target.docx"))
{
    using (Comparer comparer = new Comparer(sourceStream))
    {
        comparer.Add(targetStream);
        comparer.Compare(File.Create("result.docx"));
    }
}
```

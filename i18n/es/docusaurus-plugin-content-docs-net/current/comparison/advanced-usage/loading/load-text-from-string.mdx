<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite comparar valores de variables del tipo `string`.

Para comparar texto proveniente de variables, siga estos pasos:

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions/properties/loadtext" target="_blank" rel="nofollow noopener noreferrer">LoadText</a> en `true` (esto indica que la cadena pasada contiene texto que debe compararse, no una ruta de archivo).
2.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la variable de origen de tipo `string` y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.
3.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la variable de destino de tipo `string` y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/getresultstring" target="_blank" rel="nofollow noopener noreferrer">GetResultString</a> para obtener una cadena con el resultado de la comparación.

El siguiente fragmento de código muestra cómo cargar valores desde variables:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

using (Comparer comparer = new Comparer("source text", new LoadOptions() { LoadText = true }))
{
    comparer.Add("target text", new LoadOptions() { LoadText = true });
    comparer.Compare();
    string result = compare.GetResultString();
    Console.WriteLine("Result string: \n" + comparer.GetResultString());
}
```

El siguiente fragmento de código muestra cómo combinar las distintas formas de especificar documentos:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using System.IO;
// ...

using (Stream sourceStream = File.OpenRead("./source.docx"))
{
    using (Comparer comparer = new Comparer(sourceStream))
    {
        comparer.Add("target text", new LoadOptions() { LoadText = true });
        comparer.Compare();
        string result = compare.GetResultString();
        Console.WriteLine(result);
    }
}
```

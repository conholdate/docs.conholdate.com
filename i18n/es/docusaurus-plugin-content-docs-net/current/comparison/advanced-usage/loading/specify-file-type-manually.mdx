<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite especificar explícitamente el tipo de archivo del documento mediante <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions/filetype/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.FileType</a>, en lugar de depender de la detección automática del formato.

## ¿Por qué especificar el tipo de archivo? {#why-specify-the-file-type}

Cuando no se proporciona un tipo de archivo, GroupDocs.Comparison examina el contenido del archivo para determinar su formato. Esta detección es fiable, pero añade tiempo de procesamiento, lo cual puede ser notable para **archivos grandes**.

Si ya conoce el formato —por ejemplo, porque la entrada está restringida por su aplicación—, al pasarlo explícitamente se omite la detección y permite que la biblioteca pase directamente a la carga. En pipelines de alto rendimiento o trabajos por lotes con documentos grandes, esto puede generar una mejora de velocidad medible.

## Especificar explícitamente el tipo de archivo {#specify-the-file-type-explicitly}

Utilice este enfoque cuando el formato del documento se conozca en tiempo de compilación.


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

LoadOptions loadOptions = new LoadOptions
{
    FileType = FileType.DOCX
};

using (Comparer comparer = new Comparer("source.docx", loadOptions))
{
    comparer.Add("target.docx", loadOptions);
    comparer.Compare("result.docx");
}
```

</TabItem>


</Tabs>


## Derivar el tipo de archivo a partir de una ruta de archivo  {#derive-the-file-type-from-a-file-path}
  
Cuando la ruta de archivo esté disponible y su extensión sea fiable, utilice <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.result/filetype/" target="_blank" rel="nofollow noopener noreferrer">FileType.FromFileNameOrExtension</a> para resolver el `FileType` a partir de la extensión. Esto sigue omitiendo la detección automática basada en el contenido, pero mantiene el código de llamada genérico.


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
using GroupDocs.Comparison.Result;
// ...

string sourcePath = "source.docx";
string targetPath = "target.docx";

LoadOptions sourceLoadOptions = new LoadOptions
{
    FileType = FileType.FromFileNameOrExtension(sourcePath)
};

LoadOptions targetLoadOptions = new LoadOptions
{
    FileType = FileType.FromFileNameOrExtension(targetPath)
};

using (Comparer comparer = new Comparer(sourcePath, sourceLoadOptions))
{
    comparer.Add(targetPath, targetLoadOptions);
    comparer.Compare("result.docx");
}
```

</TabItem>


</Tabs>

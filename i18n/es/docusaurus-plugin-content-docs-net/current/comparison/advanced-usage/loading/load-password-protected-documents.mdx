<a href="https://products.groupdocs.com/comparison/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Comparison</a> le permite comparar documentos protegidos con contraseña.  

Para comparar documentos protegidos con contraseña, siga estos pasos:  

1.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Especifique la contraseña del documento de origen;
2.  Instancie el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>. Especifique la ruta o el flujo del documento de origen y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.
3.  Instancie otro objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Especifique la contraseña del documento de destino.
4.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer/methods/add/index" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la ruta o el flujo del documento de destino y el objeto <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> creado en el paso anterior.
5.  Llame al método <a href="https://reference.groupdocs.com/comparison/net/groupdocs.comparison/comparer" target="_blank" rel="nofollow noopener noreferrer">Comparer</a>.  

El siguiente fragmento de código muestra cómo comparar documentos protegidos con contraseña:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;
// ...

LoadOptions sourceLoadOptions = new LoadOptions(){ Password = "1234" };

using (Comparer comparer = new Comparer("source.docx", sourceLoadOptions))
{
    LoadOptions targetLoadOptions =	new LoadOptions() { Password = "5678" };
    comparer.Add("target.docx", targetLoadOptions);
    comparer.Compare("result.docx");
}
```

Este artículo demuestra cómo comparar **hojas de cálculo de Excel** (XLSX, XLS) mediante **GroupDocs.Comparison para .NET**.  
El proyecto de ejemplo proporciona ejemplos listos para usar que permiten a los desarrolladores identificar rápidamente las diferencias a nivel de celda, con estilos personalizables, controles de visibilidad, páginas resumen y opciones avanzadas de comparación.

La comparación de hojas de cálculo de Excel es esencial para la **auditoría financiera**, la **validación de datos**, el **control de versiones**, los **informes de cumplimiento** y la **edición colaborativa**.  
Con GroupDocs.Comparison para .NET, puede automatizar los flujos de trabajo de comparación de Excel y generar documentos de resultado que resalten inserciones, eliminaciones y modificaciones, con estilos visuales configurables.

> 💡 Utilice este enfoque cuando necesite detectar y resaltar automáticamente las diferencias entre versiones de hojas de cálculo de Excel sin revisión manual.

### Comparación básica  {#basic-comparison}
  
El método `BasicComparison` realiza una comparación sencilla utilizando la configuración predeterminada:

```csharp
using GroupDocs.Comparison;
using GroupDocs.Comparison.Options;

private static void BasicComparison(string sourcePath, string targetPath, string resultPath)
{
    EnsureFileExists(sourcePath, "source Excel file");
    EnsureFileExists(targetPath, "target Excel file");

    using (var comparer = new Comparer(sourcePath))
    {
        comparer.Add(targetPath);
        comparer.Compare(resultPath);
    }

    Console.WriteLine("Basic comparison completed.");
}
```

Este código utiliza la clase `Comparer` de GroupDocs.Comparison para comparar dos archivos de Excel con el estilo predeterminado, resaltando automáticamente todas las diferencias.

### Comparación con estilo personalizado  {#styled-comparison-with-custom-formatting}
  
El método `StyledComparison` aplica un formato personalizado y genera una página de resumen:

```csharp
private static void StyledComparison(string sourcePath, string targetPath, string resultPath)
{
    EnsureFileExists(sourcePath, "source Excel file");
    EnsureFileExists(targetPath, "target Excel file");

    var compareOptions = new CompareOptions
    {
        InsertedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Green,
            IsUnderline = true,
            IsBold = true,
            IsItalic = true
        },
        DeletedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Brown,
            IsUnderline = true,
            IsBold = true,
            IsItalic = true
        },
        ChangedItemStyle = new StyleSettings()
        {
            FontColor = System.Drawing.Color.Firebrick,
            IsUnderline = true,
            IsBold = true,
            IsItalic = true
        },
        GenerateSummaryPage = true,
        ShowDeletedContent = false,
    };

    using (var comparer = new Comparer(sourcePath))
    {
        comparer.Add(targetPath);
        comparer.Compare(resultPath, compareOptions);
    }

    Console.WriteLine("Styled comparison completed (changes highlighted, summary page generated).");
}
```

Este ejemplo demuestra las clases `CompareOptions` y `StyleSettings` de GroupDocs.Comparison para el formato personalizado. Las celdas insertadas aparecen en verde, las celdas eliminadas en marrón y las celdas modificadas en rojo ladrillo, todas con formato en negrita, cursiva y subrayado.

### Ocultar contenido insertado  {#hide-inserted-content}
  
El método `HideInsertedContentComparison` se centra en las eliminaciones y modificaciones:

```csharp
private static void HideInsertedContentComparison(string sourcePath, string targetPath, string resultPath)
{
    EnsureFileExists(sourcePath, "source Excel file");
    EnsureFileExists(targetPath, "target Excel file");

    var compareOptions = new CompareOptions
    {
        ShowInsertedContent = false
    };

    using (var comparer = new Comparer(sourcePath))
    {
        comparer.Add(targetPath);
        comparer.Compare(resultPath, compareOptions);
    }

    Console.WriteLine("Comparison completed (inserted content hidden).");
}
```

Al establecer `ShowInsertedContent` en `false`, este ejemplo oculta la visualización de cualquier celda recién agregada en el documento resultante, haciendo que las eliminaciones y modificaciones sean más visibles.

Establecer `ShowDeletedContent` en `false` elimina cualquier indicación visual de celdas eliminadas, resaltando únicamente las adiciones y modificaciones.

### Dejar espacios para el contenido eliminado  {#leave-gaps-for-deleted-content}
  
El método `LeaveGapsComparison` conserva la estructura del documento:

```csharp
private static void LeaveGapsComparison(string sourcePath, string targetPath, string resultPath)
{
    EnsureFileExists(sourcePath, "source Excel file");
    EnsureFileExists(targetPath, "target Excel file");

    var compareOptions = new CompareOptions
    {
        LeaveGaps = true
    };

    using (var comparer = new Comparer(sourcePath))
    {
        comparer.Add(targetPath);
        comparer.Compare(resultPath, compareOptions);
    }

    Console.WriteLine("Comparison completed (gaps left for deleted content).");
}
```

Habilitar `LeaveGaps` conserva las celdas vacías donde se produjeron eliminaciones, manteniendo intacta la estructura de la hoja de cálculo y haciendo visible inmediatamente el contenido ausente.

### Ocultar tanto el contenido insertado como el eliminado  {#hide-both-inserted-and-deleted-content}
  
El método `HideBothContentComparison` muestra únicamente las modificaciones:

```csharp
private static void HideBothContentComparison(string sourcePath, string targetPath, string resultPath)
{
    EnsureFileExists(sourcePath, "source Excel file");
    EnsureFileExists(targetPath, "target Excel file");

    var compareOptions = new CompareOptions
    {
        ShowInsertedContent = false,
        ShowDeletedContent = false,
        LeaveGaps = true
    };

    using (var comparer = new Comparer(sourcePath))
    {
        comparer.Add(targetPath);
        comparer.Compare(resultPath, compareOptions);
    }

    Console.WriteLine("Comparison completed (both inserted and deleted content hidden, gaps left).");
}
```

Ambas `ShowInsertedContent` y `ShowDeletedContent` están deshabilitadas, mientras que `LeaveGaps` permanece en `true` para conservar el diseño. El resultado resalta únicamente las celdas cuyo valor haya cambiado, lo cual es ideal para el análisis de impacto de los cambios.

### Gestión de licencias  {#license-management}
  
Aplique la licencia de GroupDocs.Comparison antes de realizar comparaciones:

```csharp
private static void ApplyLicense()
{
    string licensePath = "path to your license file";
    License license = new License();
    license.SetLicense(licensePath);
}
```

Actualice la variable `licensePath` con la ruta a su archivo de licencia. Sin una licencia válida, la biblioteca se ejecuta en modo de evaluación con capacidades limitadas.

### Validación de archivos  {#file-validation}
  
El método auxiliar `EnsureFileExists` valida la presencia del archivo:

```csharp
private static void EnsureFileExists(string path, string description)
{
    if (!File.Exists(path))
    {
        throw new FileNotFoundException($"The {description} was not found. Path: {path}", path);
    }
}
```

Esta utilidad valida la existencia del archivo antes de realizar cualquier operación de comparación, proporcionando un mensaje de excepción claro que facilita la depuración.

## Ejecutar los ejemplos  {#running-the-examples}  

1. Coloque sus archivos de Excel en el directorio `sample-files`:
   - `source.xlsx` – El archivo de Excel original
   - `target.xlsx` – El archivo de Excel modificado con el que se realizará la comparación  

2. Actualice la ruta de la licencia en `Program.cs`:
   ```csharp
   string licensePath = "path to your license file";
   ```

3. Ejecute el proyecto:
   ```bash
   dotnet run
   ```

4. Consulte el directorio `output` para ver los resultados de la comparación:
   - `result_basic.xlsx` – Resultado básico de la comparación
   - `result_styled.xlsx` – Comparación con estilo y página de resumen
   - `result_hide_inserted.xlsx` – Resultado con el contenido insertado oculto
   - `result_hide_deleted.xlsx` – Resultado con el contenido eliminado oculto
   - `result_leave_gaps.xlsx` – Resultado con espacios vacíos para el contenido eliminado
   - `result_hide_both.xlsx` – Resultado que muestra únicamente las modificaciones

## Notas {#notes}

- Reemplace las rutas de archivo por las ubicaciones reales de sus documentos.
- El estilo predeterminado utiliza colores estándar para el contenido insertado, eliminado y modificado.
- La generación de la página de resumen ofrece una vista consolidada de todos los cambios en una única página.
- Los controles de visibilidad le permiten centrarse en tipos específicos de cambios según sus necesidades de análisis.
- La opción `LeaveGaps` conserva la estructura del documento, facilitando la identificación de dónde se eliminó contenido.

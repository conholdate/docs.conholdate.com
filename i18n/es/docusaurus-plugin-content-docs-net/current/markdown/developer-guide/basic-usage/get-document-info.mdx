Utilice `GetDocumentInfo()` o el método estático `GetInfo()` para recuperar los metadatos del documento sin realizar una conversión completa. Esto resulta útil para construir navegadores de archivos, pipelines de validación e interfaces de usuario previas a la conversión.

### Uso del método estático  {#using-static-method}


<Tabs groupId="get-info-static">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

DocumentInfo info = MarkdownConverter.GetInfo("business-plan.docx");

Console.WriteLine($"Format:    {info.FileFormat}");    // Docx
Console.WriteLine($"Pages:     {info.PageCount}");     // 42
Console.WriteLine($"Title:     {info.Title}");         // "Q3 Report"
Console.WriteLine($"Author:    {info.Author}");        // "Jane Doe"
Console.WriteLine($"Encrypted: {info.IsEncrypted}");   // false
```

</TabItem>

### Propiedades de DocumentInfo {#documentinfo-properties}
  
| Propiedad | Tipo | Descripción |  
| --- | --- | --- |  
| `FileFormat` | `FileFormat` | Formato de archivo detectado (por ejemplo, `FileFormat.Docx`) |  
| `PageCount` | `int` | Número de páginas o hojas de cálculo |  
| `Title` | `string` | Título del documento extraído de los metadatos |  
| `Author` | `string` | Autor del documento extraído de los metadatos |  
| `IsEncrypted` | `bool` | Indica si el documento está protegido con contraseña |

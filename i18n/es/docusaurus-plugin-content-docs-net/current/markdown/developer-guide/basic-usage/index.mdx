## Inicio rápido con la API de GroupDocs.Markdown {#quick-start-with-groupdocs-markdown-api}
  
GroupDocs.Markdown proporciona tanto métodos estáticos como una API basada en instancias para convertir documentos a Markdown con tan solo unas pocas líneas de código.

**Métodos estáticos**: invoque `MarkdownConverter.ToMarkdown()` o `MarkdownConverter.ToFile()` para realizar conversiones en una sola línea, sin necesidad de gestionar el ciclo de vida del objeto.

**API basada en instancias**: cree una instancia de `MarkdownConverter` cuando necesite inspeccionar previamente los metadatos del documento mediante `GetDocumentInfo()`, o realizar múltiples operaciones sobre el mismo documento.

Explore los temas de esta sección:  

* [Convertir archivos](/net/markdown/developer-guide/basic-usage/convert/) — convierta documentos PDF, Word, Excel, EPUB y de texto a Markdown.  

* [Obtener información del documento](/net/markdown/developer-guide/basic-usage/get-document-info/) — recupere metadatos del documento, como formato, número de páginas, título y autor, sin realizar una conversión completa.

Utilice GroupDocs.Markdown para convertir archivos TXT, XML y otros formatos basados en texto a Markdown limpio.

### Uso del método estático  {#using-static-method}
  
La forma más sencilla de convertir un archivo de texto:


<Tabs groupId="export-text-static">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

// Set license (optional)
if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

// Convert XML to Markdown string
string markdown = MarkdownConverter.ToMarkdown("llms-tech.xml");

// Or save directly to a file
MarkdownConverter.ToFile("llms-tech.xml", "export-text-static.md");
```

</TabItem>


<TabItem value="llms-tech-xml" label="llms-tech.xml">

`llms-tech.xml` es un archivo de ejemplo utilizado en este ejemplo. Haga clic [aquí](/net/markdown/_sample_files/developer-guide/basic-usage/convert/llms-tech.xml/) para descargarlo.

</TabItem>

### Uso de la API de instancia con opciones {#using-instance-api-with-options}
  
Para mayor control, utilice la API de instancia:


<Tabs groupId="export-text-instance">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

using var converter = new MarkdownConverter("llms-tech.xml");
var options = new ConvertOptions
{
    HeadingLevelOffset = 1
};

converter.Convert("export-text-instance.md", options);
```

</TabItem>

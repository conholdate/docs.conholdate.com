Utilice GroupDocs.Markdown para convertir documentos PDF a Markdown limpio.

### Uso del método estático  {#using-static-method}
  
La forma más sencilla de convertir un archivo PDF:


<Tabs groupId="export-pdf-static">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

// Set license (optional)
if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

// Convert PDF to Markdown string
string markdown = MarkdownConverter.ToMarkdown("business-plan.pdf");

// Or save directly to a file
MarkdownConverter.ToFile("business-plan.pdf", "export-pdf-static.md");
```

</TabItem>

### Uso de la API de instancia con opciones {#using-instance-api-with-options}
  
Para mayor control, utilice la API de instancia:


<Tabs groupId="export-pdf-instance">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

using var converter = new MarkdownConverter("business-plan.pdf");
var options = new ConvertOptions
{
    ImageExportStrategy = new ExportImagesToFileSystemStrategy("images")
    {
        ImagesRelativePath = "images"
    },
    HeadingLevelOffset = 1
};

converter.Convert("export-pdf-instance.md", options);
```

</TabItem>

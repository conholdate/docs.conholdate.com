Utilice GroupDocs.Markdown para convertir formatos de libros electrónicos como EPUB, MOBI y otros a Markdown limpio.

### Uso del método estático  {#using-static-method}
  
La forma más sencilla de convertir un archivo de libro electrónico:


<Tabs groupId="export-ebook-static">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

// Set license (optional)
if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

// Convert EPUB to Markdown string
string markdown = MarkdownConverter.ToMarkdown("business-plan.epub");

// Or save directly to a file
MarkdownConverter.ToFile("business-plan.epub", "export-ebook-static.md");
```

</TabItem>

### Uso de la API de instancia con opciones {#using-instance-api-with-options}
  
Para mayor control, utilice la API de instancia:


<Tabs groupId="export-ebook-instance">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");

using var converter = new MarkdownConverter("business-plan.epub");
var options = new ConvertOptions
{
    ImageExportStrategy = new ExportImagesToFileSystemStrategy("images")
    {
        ImagesRelativePath = "images"
    },
    HeadingLevelOffset = 1
};

converter.Convert("export-ebook-instance.md", options);
```

</TabItem>

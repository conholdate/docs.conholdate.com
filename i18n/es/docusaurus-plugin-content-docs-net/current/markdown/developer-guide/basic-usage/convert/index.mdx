**<a href="https://products.groupdocs.com/markdown/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Markdown</a>** proporciona una forma rápida y sencilla de convertir documentos en Markdown limpio y estructurado. La biblioteca ofrece dos enfoques: **métodos estáticos** para conversiones en una sola línea y una **API de instancia** para mayor control.

### Métodos estáticos (más sencillos) {#static-methods-simplest}
  
Llame a `MarkdownConverter.ToMarkdown()` para obtener una cadena en Markdown, o a `MarkdownConverter.ToFile()` para escribir directamente en disco:


<Tabs groupId="static-methods">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

string md = MarkdownConverter.ToMarkdown("business-plan.docx");
// # Quarterly Report
//
// ## Executive Summary
//
// This report covers the key initiatives...

MarkdownConverter.ToFile("business-plan.docx", "static-methods.md");
```

</TabItem>


</Tabs>


### API de instancia  {#instance-api}
  
Cree una instancia de <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown/markdownconverter/" target="_blank" rel="nofollow noopener noreferrer">MarkdownConverter</a> para escenarios avanzados, como inspeccionar metadatos antes de convertir o reutilizar un documento cargado:


<Tabs groupId="instance-api">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Markdown;

using var converter = new MarkdownConverter("business-plan.docx");
converter.Convert("instance-api.md", new ConvertOptions { HeadingLevelOffset = 1 });
```

</TabItem>


</Tabs>


### Opciones de conversión  {#conversion-options}
  
Utilice <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown/convertoptions/" target="_blank" rel="nofollow noopener noreferrer">ConvertOptions</a> para personalizar la salida: seleccione páginas específicas, controle el manejo de imágenes, elija un estilo de Markdown, agregue encabezado YAML y más. Para personalizar la carga, utilice <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown.options.load" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> para especificar el formato de archivo o proporcionar una contraseña.

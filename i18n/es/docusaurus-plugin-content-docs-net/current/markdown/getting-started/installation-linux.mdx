Este artículo explica cómo instalar y ejecutar **GroupDocs.Markdown para .NET** en Linux. El paquete NuGet de GroupDocs.Markdown hace referencia a todas las bibliotecas nativas necesarias.

## Requisitos previos {#prerequisites}
  
Instale el SDK de .NET (versión 6.0 o posterior) para su distribución. Consulte <a href="https://learn.microsoft.com/en-us/dotnet/core/install/linux" target="_blank" rel="nofollow noopener noreferrer">Instalar .NET en Linux</a> para obtener instrucciones.

## Instalación del paquete {#install-the-package}
  
Cree un nuevo proyecto o navegue hasta uno existente y, a continuación, agregue el paquete:

```bash
dotnet new console -n MarkdownDemo
cd MarkdownDemo
dotnet add package GroupDocs.Markdown
```

## Ejecutar su aplicación {#run-your-application}

```bash
dotnet run
```

## Docker {#docker}
  
GroupDocs.Markdown se ejecuta en contenedores Docker sin dependencias adicionales más allá del entorno de ejecución de .NET.

### Ejemplo de Dockerfile {#example-dockerfile}

```dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /app
COPY . .
RUN dotnet publish -c Release -o /publish

FROM mcr.microsoft.com/dotnet/runtime:8.0
WORKDIR /app
COPY --from=build /publish .
ENTRYPOINT ["dotnet", "MarkdownDemo.dll"]
```

### Compilar y ejecutar  {#build-and-run}

```bash
docker build -t markdown-demo .
docker run --rm -v $(pwd)/files:/app/files markdown-demo
```

## Distribuciones compatibles  {#supported-distributions}
  
GroupDocs.Markdown para .NET funciona en cualquier distribución de Linux que admita .NET 6.0 o superior, incluyendo:  

- Ubuntu 20.04+
- Debian 11+
- CentOS 8+, RHEL 8+
- Fedora 36+
- Alpine 3.16+
- Amazon Linux 2023

## Sistemas operativos compatibles {#supported-operating-systems}

### Windows {#windows}

*   Microsoft Windows 10 (x64, x86)
*   Microsoft Windows 11 (x64)
*   Microsoft Windows Server 2016 y versiones posteriores

### Linux {#linux}

*   Ubuntu 20.04+, Debian 11+, CentOS 8+, Fedora 36+, Alpine 3.16+
*   Cualquier distribución que admita el entorno de ejecución .NET 6.0 o posterior

### macOS {#macos}

*   macOS 12 (Monterey) y versiones posteriores – Intel y Apple Silicon (serie M)

## Frameworks compatibles {#supported-frameworks}

GroupDocs.Markdown para .NET se distribuye con ensamblados para los siguientes marcos de destino:

| Marco de destino | Versión | Notas |
| --- | --- | --- |
| .NET Framework | 4.6.2+ | Solo Windows |
| .NET | 6.0 | Windows y Linux |
| .NET | 8.0 | Windows y Linux (LTS) |
| .NET | 10.0 | Windows y Linux (última versión) |

Todos los ensamblados TFM se incluyen en el paquete NuGet. El entorno de ejecución selecciona automáticamente la mejor coincidencia para su proyecto.

## Entornos de desarrollo {#development-environments}

GroupDocs.Markdown para .NET puede utilizarse en cualquier entorno de desarrollo que apunte a .NET. Los entornos explícitamente compatibles son los siguientes:

*   Microsoft Visual Studio 2022 y versiones posteriores
*   Microsoft Visual Studio Code con C# Dev Kit
*   JetBrains Rider 2024.1 y versiones posteriores

## Prueba gratuita o licencia temporal {#free-trial-or-temporary-license}
  
Puede probar GroupDocs.Markdown sin adquirir una licencia.  

### Prueba gratuita {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida; simplemente se convierte en una versión con licencia cuando establezca la licencia. Puede configurar la licencia de varias maneras, descritas en las siguientes secciones de este artículo.  

La versión de evaluación presenta las siguientes limitaciones:  

* Solo se procesan las primeras 3 páginas.
* No se admiten documentos con más de 3 páginas.
* Se coloca una marca de agua de evaluación en la parte superior de cada página.  

### Licencia temporal {#temporary-license}
  
Si desea probar GroupDocs.Markdown sin las limitaciones de la versión de prueba, también puede solicitar una Licencia temporal de 30 días. Para obtener más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">«Obtener una licencia temporal»</a>.  

## Cómo establecer una licencia {#how-to-set-a-license}


:::info
Puede encontrar información sobre precios en la página <a href="https://purchase.conholdate.com/pricing/" target="_blank">"Información sobre precios"</a>.
:::


Después de obtener una licencia, debe configurarla. Esta sección describe las opciones disponibles para realizar esta configuración, así como responde a algunas preguntas frecuentes.

La licencia debe configurarse:

- Solo una vez por dominio de aplicación.
- Antes de utilizar cualquier otra clase de GroupDocs.Markdown.


:::info
La licencia se puede configurar varias veces por dominio de aplicación, pero recomendamos hacerlo una sola vez, ya que todas las llamadas posteriores solo desperdiciarán tiempo de procesador.
:::


### Establecer licencia desde archivo (método estático) {#set-license-from-file-static-method}
  
El método estático `License.Set()` es la forma más sencilla de aplicar una licencia. No es necesario crear una instancia de `License`.


<Tabs groupId="license-static-file">


<TabItem value="c" label="C#" default>

```csharp
// Set the license using the static method
if (File.Exists("GroupDocs.Markdown.lic")) License.Set("GroupDocs.Markdown.lic");
```

</TabItem>


</Tabs>


### Establecer licencia desde archivo (método de instancia)  {#set-license-from-file-instance-method}
  
Alternativamente, puede crear una instancia de `License` y llamar a `SetLicense()`:


<Tabs groupId="license-instance-file">


<TabItem value="c" label="C#" default>

```csharp
string licensePath = "GroupDocs.Markdown.lic";
License license = new License();
license.SetLicense(licensePath);
```

</TabItem>


</Tabs>


### Establecer licencia desde un flujo (método estático) {#set-license-from-stream-static-method}
  
También puede aplicar una licencia desde un flujo utilizando el método estático `License.Set()`:


<Tabs groupId="license-static-stream">


<TabItem value="c" label="C#" default>

```csharp
using (FileStream stream = File.OpenRead("GroupDocs.Markdown.lic"))
{
    License.Set(stream);
}
```

</TabItem>


</Tabs>


### Establecer licencia desde un flujo (método de instancia)  {#set-license-from-stream-instance-method}
  
El siguiente ejemplo muestra cómo establecer una licencia desde un flujo utilizando el método de instancia:


<Tabs groupId="license-instance-stream">


<TabItem value="c" label="C#" default>

```csharp
using (FileStream stream = File.OpenRead("GroupDocs.Markdown.lic"))
{
    License license = new License();
    license.SetLicense(stream);
}
```

</TabItem>


</Tabs>


### Configurar licencia medible {#set-metered-license}
  
También puede configurar una licencia <a href="https://reference.groupdocs.com/markdown/net/groupdocs.markdown/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa a un archivo de licencia. Se trata de un mecanismo de licencia basado en el uso, cuyo costo se calcula según las características de la API consumidas. Para obtener más información, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias medibles</a>.  

Utilice la clase `Metered` para configurar la licencia medible y consultar su consumo:


<Tabs groupId="license-metered">


<TabItem value="c" label="C#" default>

```csharp
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

</TabItem>

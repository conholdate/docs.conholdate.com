## Visión general {#overview}
  
GroupDocs.Markdown para .NET convierte documentos desde diversos formatos en Markdown limpio y estructurado. Utiliza un renderizador personalizado basado en DOM que brinda control total sobre cada aspecto de la salida.

## Formatos de entrada admitidos {#supported-input-formats}
  
Convierta desde más de 20 formatos de documento, incluidos Word (DOCX, DOC, RTF), Excel (XLSX, XLS, CSV), PDF, EPUB, MOBI, TXT y CHM. Consulte la lista completa de [formatos admitidos](/net/markdown/getting-started/supported-document-formats/).

## Características principales {#key-features}
  
### Métodos estáticos convenientes {#static-convenience-methods}
  
Conversiones en una sola línea que generan una excepción en caso de error: no requieren comprobación manual del resultado.

```csharp
string md = MarkdownConverter.ToMarkdown("business-plan.docx");
MarkdownConverter.ToFile("business-plan.docx", "output.md");
```

### Control de sabor de Markdown {#markdown-flavor-control}
  
Dirigido a GitHub Flavored Markdown (tablas con tuberías, tachado) o a CommonMark estricto:

```csharp
var options = new ConvertOptions { Flavor = MarkdownFlavor.GitHub };
```

### Manejo flexible de imágenes {#flexible-image-handling}
  
Elija cómo se procesan las imágenes durante la conversión:  

- **Incrustación en Base64**: las imágenes se incluyen directamente en el Markdown (valor predeterminado)  

- **Exportación al sistema de archivos**: guardar las imágenes en disco con rutas relativas  

- **Omitir**: excluir las imágenes de la salida  

- **Personalizado**: renombrar, reemplazar o redirigir imágenes mediante una devolución de llamada  

### Cabecera YAML {#yaml-front-matter}
  
Extraer los metadatos del documento en una cabecera YAML para generadores de sitios estáticos (Jekyll, Hugo, Docusaurus):

```csharp
var options = new ConvertOptions { IncludeFrontMatter = true };
```

### Desplazamiento del Nivel de Encabezado  {#heading-level-offset}
  
Desplaza todos los niveles de encabezado al incrustar contenido convertido dentro de un documento más grande:

```csharp
var options = new ConvertOptions { HeadingLevelOffset = 2 };
// # Title → ### Title
```

### Opciones de hojas de cálculo  {#spreadsheet-options}
  
Controla cómo se representan las tablas de Excel y CSV:  

- Truncado de columnas y filas con indicadores de elipsis  

- Separadores de hojas personalizados  

- Filtrado de hojas ocultas  

### Inspección de documentos  {#document-inspection}
  
Recupera los metadatos del documento (formato, número de páginas, título, autor) sin realizar una conversión completa:

```csharp
DocumentInfo info = MarkdownConverter.GetInfo("business-plan.docx");
```

### Selección de Páginas  {#page-selection}
  
Convierta páginas o hojas de cálculo específicas en lugar del documento completo:

```csharp
var options = new ConvertOptions { PageNumbers = new[] { 1, 3, 5 } };
```

### Rutas de imágenes relativas  {#relative-image-paths}
  
Controla cómo aparecen las rutas de archivos de imagen en la salida de Markdown:

```csharp
var strategy = new ExportImagesToFileSystemStrategy("output/images")
{
    ImagesRelativePath = "images"
};
```

### Reemplazo de imágenes  {#image-replacement}
  
Reemplace imágenes en el documento de origen con imágenes diferentes durante la conversión mediante `IImageSavingHandler`.

### API asíncrona  {#async-api}
  
Todos los métodos estáticos e de instancia tienen contrapartes asíncronas con E/S de archivos verdaderamente asíncrona:

```csharp
string md = await MarkdownConverter.ToMarkdownAsync("business-plan.docx");
```

### Manejo adecuado de errores  {#proper-error-handling}
  
Tipos específicos de excepciones para escenarios comunes de error:  

- `DocumentProtectedException`: contraseña incorrecta o ausente  

- `InvalidFormatException`: archivo corrupto o no reconocido  

- `GroupDocsMarkdownException`: error general de conversión  

### Advertencias de conversión  {#conversion-warnings}
  
Los problemas no fatales se informan mediante `ConvertResult.Warnings`; por ejemplo, cuando las tablas de hojas de cálculo se truncan.  

### Documentos protegidos con contraseña  {#password-protected-documents}
  
Cargue documentos cifrados proporcionando una contraseña mediante `LoadOptions`:

```csharp
var loadOptions = new LoadOptions(FileFormat.Docx) { Password = "secret" };
```

### Soporte multiplataforma {#cross-platform-support}
  
Funciona en Windows, Linux y macOS con .NET Framework 4.6.2+, .NET 6.0+, .NET 8.0+ y .NET 10.0+.

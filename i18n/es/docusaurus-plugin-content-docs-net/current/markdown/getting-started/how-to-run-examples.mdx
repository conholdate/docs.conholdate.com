## Crear un proyecto desde cero  {#build-a-project-from-scratch}
  
Puede crear un proyecto desde cero utilizando Visual Studio o <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">.NET CLI</a>. Le guiaremos paso a paso en ambos casos.

### Crear un proyecto utilizando .NET CLI  {#build-a-project-using-net-cli}  

1. Asegúrese de tener instalado el SDK de .NET <a href="https://dotnet.microsoft.com/download" target="_blank" rel="nofollow noopener noreferrer">https://dotnet.microsoft.com/download</a>.
2. Cree un directorio para su aplicación de consola ejecutando el comando `mkdir my-console-app` en su terminal.
3. Navegue hasta el directorio `my-console-app` ejecutando el comando `cd my-console-app`.
4. Cree una aplicación de consola vacía ejecutando el comando `dotnet new console`.
5. Agregue el paquete GroupDocs.Markdown para .NET ejecutando el comando `dotnet add package GroupDocs.Markdown`.
6. Edite `Program.cs` y agregue las siguientes líneas al método `Main`:
  

<Tabs groupId="dotnet-cli-example">


<TabItem value="c" label="C#" default>

  ```csharp
    using GroupDocs.Markdown;

    string documentPath = "business-plan.docx";
    string outputPath = "converted.md";
  
	using (var converter = new MarkdownConverter(documentPath))
	{
		converter.Convert(outputPath);
	}
  ```

</TabItem>

### Compilar un proyecto utilizando Visual Studio {#build-a-project-using-visual-studio}

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2. Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
3. Instale **GroupDocs.Markdown para .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/markdown/getting-started/installation/).
4. Agregue el siguiente código al método `Main`:

  ```csharp
	{
		converter.Convert(outputPath);
	}
  ```

## Ejecutar ejemplos del backend {#run-back-end-examples}

Puede encontrar muchos ejemplos de backend en nuestro repositorio de <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-markdown/GroupDocs.Markdown-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio desde GitHub utilizando su cliente Git favorito.  
En caso de descargar el archivo ZIP, extraiga las carpetas en su disco local.  

1. Vaya al directorio `Examples` y abra la solución `GroupDocs.Markdown.Examples.CSharp.sln` utilizando Visual Studio.
2. Abra el archivo `RunExamples.cs` y descomente los ejemplos que desea ejecutar.
3. Opcionalmente, puede establecer la ruta de la licencia en el archivo `Utils.cs`.

## Contribuir {#contribute}
  
Si desea agregar o mejorar un ejemplo, le animamos a contribuir al proyecto. Todos los ejemplos de este repositorio son de código abierto y pueden utilizarse libremente en sus propias aplicaciones.  
Para contribuir, puede bifurcar (fork) el repositorio, editar el código y crear una solicitud de extracción (pull request). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

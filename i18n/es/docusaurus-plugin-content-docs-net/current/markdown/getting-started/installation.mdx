Este tema describe cómo agregar la biblioteca **GroupDocs.Markdown** a su proyecto .NET.

## Instalar desde NuGet {#install-from-nuget}
  
<a href="https://www.nuget.org/packages/GroupDocs.Markdown" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Markdown</a> está disponible en NuGet. El paquete principal es un meta-paquete que automáticamente descarga el paquete de tiempo de ejecución adecuado para el framework de destino de su proyecto.

### Usando la CLI de .NET {#using-net-cli}
  
Abra una terminal en la carpeta de su proyecto y ejecute:

```bash
dotnet add package GroupDocs.Markdown
```

### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}
  
En Visual Studio, abra **Herramientas** > **Administrador de paquetes NuGet** > **Consola del Administrador de paquetes** y ejecute:

```powershell
Install-Package GroupDocs.Markdown
```

### Uso de PackageReference {#using-packagereference}
  
Agregue directamente a su archivo `.csproj`:

```xml
<PackageReference Include="GroupDocs.Markdown" Version="26.3" />
```

## Paquetes de tiempo de ejecución  {#runtime-packages}
  
El paquete de NuGet incluye ensamblados para cuatro marcos de destino:  

| Marco de destino | Paquete de tiempo de ejecución |  
| --- | --- |  
| .NET Framework 4.6.2 | GroupDocs.Markdown.Net462 |  
| .NET 6.0 | GroupDocs.Markdown.Net60 |  
| .NET 8.0 | GroupDocs.Markdown.Net80 |  
| .NET 10.0 | GroupDocs.Markdown.Net100 |  

En la mayoría de los casos, instale únicamente el paquete principal `GroupDocs.Markdown`. NuGet resolverá automáticamente el paquete de tiempo de ejecución adecuado. También puede instalar directamente un paquete de tiempo de ejecución específico si es necesario:

```bash
dotnet add package GroupDocs.Markdown.Net80
```

## Descargar desde el sitio web oficial  {#download-from-the-official-website}
  
También puede descargar los ensamblados como un archivo ZIP o un instalador MSI desde el sitio web <a href="https://releases.groupdocs.com/markdown/net/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs Releases</a>.  

1. Descargue el archivo ZIP o MSI para la versión deseada.
2. Extraiga los archivos (ZIP) o ejecute el instalador (MSI).
3. En su proyecto, agregue una referencia al archivo `GroupDocs.Markdown.dll` para el marco de destino que necesite (por ejemplo, `bin/net8.0/GroupDocs.Markdown.dll`).

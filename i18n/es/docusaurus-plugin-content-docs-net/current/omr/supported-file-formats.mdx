## Fuentes de plantillas  {#template-sources}
  
Aspose.OMR para .NET admite un lenguaje de marcado especializado para diseñar formularios OMR. El diseño del formulario puede proporcionarse en uno de los siguientes formatos:

<div className="docs-owner-markdown-table">

| Formato | Detalles |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| <a href="https://docs.aspose.com/omr/json-markup/" target="_blank" rel="nofollow noopener noreferrer">**JSON**</a> | Un popular formato de archivo <a href="https://www.json.org/" target="_blank" rel="nofollow noopener noreferrer">estándar abierto</a> para describir estructuras de datos anidadas. |
| <a href="https://docs.aspose.com/omr/txt-markup/" target="_blank" rel="nofollow noopener noreferrer">**text**</a> | Marcado de texto ligero específicamente diseñado para formularios Aspose.OMR. |
| [**Object**](/net/omr/programmatic-layout/) | Describe el formulario OMR directamente en el código de la aplicación. |

</div>

## Formularios imprimibles {#printable-forms}
  
Una vez que el código fuente de la plantilla esté listo, puede generar un documento imprimible a partir de él. Aspose.OMR para .NET selecciona inteligentemente el formato de archivo según la extensión proporcionada:

<div className="docs-owner-markdown-table">

| Extensión | Detalles |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **.PDF** | Portable Document Format, el estándar de facto de la industria para documentos impresos. |
| **.JPG** | JPEG, un formato ampliamente utilizado para imágenes digitales. Archivos de tamaño pequeño, pero la calidad de la imagen puede reducirse ligeramente debido a la compresión con pérdida. |
| **.PNG** | Portable Network Graphics, un formato de imagen abierto y extensible con compresión sin pérdida. |
| **.TIFF** o **.TIF** | Tag Image File Format, abreviado como *TIFF* o *TIF*. El formato gráfico de alta calidad más popular entre artistas, fotógrafos y la industria editorial. |
| **.GIF** | Archivos de imagen de tamaño pequeño, limitados a 256 colores. Ideal para sitios web y redes lentas. |
| **.BMP** | Archivo de imagen de mapa de bits. Compatible con casi cualquier dispositivo, pero el tamaño del archivo puede ser muy grande. |

</div>

## Formularios rellenados {#filled-forms}
  
Aspose.OMR para .NET puede reconocer cualquier archivo que obtenga de un escáner o una cámara:

<div className="docs-owner-markdown-table">

| Extensión | Detalles |
| --------------------- | ------------------------------------------------------------------------------ |
| **.PDF** | Formato de Documento Portátil (incluye documentos de varias páginas). |
| **.JPG** | JPEG, el formato más popular para fotos tomadas con teléfonos inteligentes. |
| **.PNG** | Gráficos de Red Portátil. |
| **.TIFF** o **.TIF** | Imagen TIFF de una o varias páginas, comúnmente utilizada para escaneos de alta calidad. |
| **.GIF** | Formato de Intercambio de Gráficos. Limitado a 256 colores. |
| **.BMP** | Archivo de imagen de mapa de bits. |

</div>

## Resultados del reconocimiento {#recognition-results}
  
Los resultados del reconocimiento se devuelven en los formatos de almacenamiento de datos más populares, que pueden importarse en cualquier base de datos o sistema de análisis ampliamente utilizado:

<div className="docs-owner-markdown-table">

| Formato | Detalles |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **JSON** | Un <a href="https://www.json.org/" target="_blank" rel="nofollow noopener noreferrer">estándar abierto</a> popular para describir estructuras de datos anidadas. Ideal para bases de datos NoSQL o aplicaciones web. |
| **XML** | Lenguaje de Marcado Extensible, un formato universal para la mayoría de los sistemas. |
| **CSV** | Un formato de texto ligero que utiliza una coma para separar los valores. Ideal para aplicaciones de hojas de cálculo y tablas simples de bases de datos relacionales. |

</div>

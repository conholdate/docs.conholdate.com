Aspose.OMR para .NET es un producto con licencia comercial que puede utilizarse en modo de prueba (evaluación).

## Prueba gratuita  {#free-trial}
  
Puede comenzar a utilizar Aspose.OMR para .NET inmediatamente tras la [instalación](/net/omr/installation/).

En modo de prueba (sin proporcionar una licencia), puede diseñar, generar y reconocer formularios OMR. Sin embargo, aplican las siguientes restricciones:  

- Se añade una **marca de agua** a los formularios impresos generados por Aspose.OMR para .NET.
- Sólo se procesan los primeros **5** elementos del origen de la plantilla en los formularios impresos. El resto de elementos se ignoran.
- Sólo se reconocen las primeras **5** respuestas en los formularios rellenados. El resto de respuestas se ignoran.

Para eliminar estas restricciones, aplique una licencia.

## Obtención de una licencia temporal  {#getting-a-temporary-license}
  
Una licencia temporal elimina todas las limitaciones de la versión de prueba durante **30 días**. Utilícela para comenzar a desarrollar una aplicación OMR totalmente funcional y tomar la decisión final de <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquirir</a> Aspose.OMR para .NET más adelante.

Para solicitar una licencia temporal, visite la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">"Obtener una licencia temporal"</a>.

## Adquisición de una licencia  {#purchasing-a-license}
  
Aspose.OMR para .NET se licencia según el número de desarrolladores y ubicaciones (sitios) donde se utilizará el producto (licencias *Developer* y *Site*) o según el uso por demanda (licencias *Metered*).

Consulte <a href="https://purchase.conholdate.com/policies/license-types" target="_blank">Tipos de licencia</a> para obtener más información y <a href="https://purchase.conholdate.com/pricing/" target="_blank">adquiera una licencia</a> que se ajuste mejor a sus necesidades.

## Aplicación de una licencia  {#applying-a-license}
  
Tras recibir una licencia adquirida o temporal, cárguela en el código de su aplicación o incluya el archivo de licencia en la aplicación como recurso incrustado.

:::info
Puede renombrar el archivo de licencia e incluso cambiar su extensión.
:::

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
Coloque el archivo de licencia (* .lic *) en una de las siguientes ubicaciones:  

- ruta explícita;  

- la carpeta que contiene el ensamblado de Aspose.OMR para .NET;  

- la carpeta que contiene el ensamblado que realiza la llamada;  

- la carpeta que contiene el ensamblado de entrada (de inicio).  

A continuación, inserte el siguiente código en su método de inicio, antes de llamar a cualquier otra clase de Aspose.OMR:

```csharp
// Initialize the licensing object
Aspose.OMR.License omrLicense = new Aspose.OMR.License();

// Load the license from file
omrLicense.SetLicense("Aspose_OMR_License_File.lic");
```

Si no se proporciona una ruta, el método `SetLicense` buscará el archivo de licencia en la carpeta que contiene el componente Aspose.OMR para .NET, en la carpeta que contiene el ensamblado que realiza la llamada y en la carpeta del ensamblado de entrada. Si prefiere cargar la licencia desde una ruta explícita, proporcione la ruta completa en el método `SetLicense`.

### Carga de una licencia desde un flujo  {#loading-a-license-from-stream}
  
Inserte el siguiente código en su método de inicio, antes de llamar a cualquier otra clase de Aspose.OMR:

```csharp
// Initialize the licensing object
Aspose.OMR.License omrLicense = new Aspose.OMR.License();

// Read the license from file
FileStream licenseStream = new FileStream(@"C:\Aspose_OMR_License_File.lic", FileMode.Open);

// Load the license
omrLicense.SetLicense(licenseStream);
```

:::info
Mantenga los tokens de marcador de posición que aparecen en la entrada exactamente sin cambios.  
No agregue tokens de marcador de posición que no estén ya presentes en la entrada.  
Mantenga las tuberías y el recuento de filas de la tabla de Markdown sin cambios.  

No olvide agregar ``using System.IO;`` a su código para acceder a la clase **FileStream** sin hacer referencia a ella mediante su espacio de nombres completo.
:::

### Incluir un archivo de licencia como un recurso incrustado {#including-a-license-file-as-an-embedded-resource}
  
Puede incluir el archivo de licencia como un recurso incrustado en uno de los ensamblados que llaman a Aspose.OMR para .NET. Esto garantiza que el archivo no se pierda accidentalmente.  

- En Microsoft Visual Studio, haga clic con el botón derecho en el proyecto en el **Explorador de soluciones** y seleccione **Agregar | Elemento existente…** en el menú contextual.
- Seleccione el archivo de licencia (*.lic*) y haga clic en el botón **Agregar**.
- Seleccione el archivo de licencia en el **Explorador de soluciones** y establezca su propiedad **Acción de compilación** en *Recurso incrustado*.  

A continuación, inserte el siguiente código en su método de inicio, antes de llamar a cualquier otra clase de Aspose.OMR:

```csharp
// Initialize the licensing object
Aspose.OMR.License omrLicense = new Aspose.OMR.License();

// Load the license from file
omrLicense.SetLicense("Aspose_OMR_License_File.lic");

// Indicate that license will be embedded to the application
omrLicense.Embedded = true;
```

## Licencia para múltiples productos de Aspose {#licensing-multiple-aspose-products}  

- Incluso si posee un único archivo de licencia para todos los productos de Aspose (como <a href="https://products.aspose.com/total/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Total</a>), aún debe aplicar la licencia por separado a **cada** producto de Aspose que utilice en su aplicación.  

- Cada producto de Aspose posee una clase **License** en su espacio de nombres. Al aplicar licencias a cada producto, utilice el nombre completo de la clase **License** para evitar ambigüedades; por ejemplo:

  ```csharp
  // Aspose.OMR
  Aspose.OMR.License omrLicense = new Aspose.OMR.License();
  omrLicense.SetLicense("Aspose_OMR_License_File.lic");

  // Aspose.BarCode
  Aspose.BarCode.License barcodeLicense = new Aspose.BarCode.License();
  barcodeLicense.SetLicense("Aspose_BarCode_License_File.lic");
  ```

En este artículo, aprenderá cómo crear una aplicación mínima para generar y reconocer un cuestionario sencillo con **Aspose.OMR para .NET**.

:::info
Asumimos que ya tiene un conocimiento básico de **Microsoft Visual Studio** y **C#**.
:::

## Requisitos necesarios {#you-will-need}  

- Un sistema operativo [compatible](/net/omr/system-requirements/) con Microsoft Visual Studio instalado. Como desarrollador individual, puede utilizar gratuitamente la edición Visual Studio Community.
- Una impresora para generar copias impresas (formularios impresos).
- Un bolígrafo, un lápiz o un marcador.
- Un smartphone moderno con una cámara de alta resolución.
- **15 minutos** de tiempo libre.

## Pasos a seguir {#steps-to-be-taken}
  
Aunque nuestra aplicación OMR requiere una cantidad mínima de código, el proceso subyacente es algo más complejo que el típico *«Hola Mundo»*. A continuación, analizamos los pasos necesarios que deben realizarse.

![Necessary steps to be taken](/net/omr/images/ad2e3b36c6e91e93-steps.png)

1. **Diseñar** el cuestionario.  

2. **Generar** un formulario imprimible y archivos de patrón de reconocimiento.  

3. **Imprimir** el formulario.  

4. **Rellenar** el formulario.  

5. **Escanear** o tomar una foto del formulario.  

6. **Reconocer** el formulario.  

## Diseño del cuestionario {#designing-the-questionnaire}
  
Aspose.OMR para .NET no solo realiza el reconocimiento, sino que también le permite diseñar formularios OMR de cualquier diseño y complejidad.  

La estructura y el diseño del cuestionario (fuente de la plantilla) se definen en un archivo de texto simple que utiliza una notación especial. Puede crearlo con cualquier editor de texto, incluido el Bloc de notas.

```text
?text=Hello, World!
	font_style=bold
	font_size=24
	align=center

#How are you doing today?
	() Pretty good, thanks! () I won't respond until I see my lawyer.
```

En este artículo, no profundizaremos en la <a href="https://docs.aspose.com/omr/txt-markup/" target="_blank" rel="nofollow noopener noreferrer">sintaxis completa</a> de la plantilla. Simplemente echemos un vistazo a sus componentes clave:


- El texto que sigue a la palabra clave `?text=` se representa como un párrafo simple. Opcionalmente, puede darle formato agregando atributos de diseño (fuente, estilo, etc.) en las líneas inmediatamente posteriores al texto. Cada definición de atributo debe ir precedida por un **carácter de tabulación**.  

- El texto de la pregunta se proporciona en una nueva línea que comienza con un numeral (`#`). El numeral en sí no se representa.  

- Las respuestas se proporcionan en líneas nuevas inmediatamente posteriores a la pregunta. Puede colocar todas las respuestas en una sola línea o en varias líneas, agregando saltos de línea. Cada línea debe comenzar con un **carácter de tabulación**.

Guarde el código fuente de la plantilla en algún lugar de su disco con el nombre **template.txt**. Lo necesitará en el siguiente paso.

## Generación de un formulario  {#generating-a-form}
  
Una vez que haya finalizado la estructura y el diseño del cuestionario, construyamos una utilidad sencilla que genere un formulario imprimible a partir de él.


1. Cree un nuevo proyecto en C# en Visual Studio. Puede utilizar una plantilla de proyecto muy básica, como **Console App (.NET framework)**.  

2. [Instale](/net/omr/installation/) el paquete NuGet **Aspose.OMR** en el proyecto.  

3. Copie el archivo de plantilla de formulario (**template.txt**) creado en el paso anterior en el directorio **bin\Debug** del proyecto.  

4. Cree una instancia de la clase **Aspose.OMR.Api.OmrEngine**:

   ```csharp
   Aspose.OMR.Api.OmrEngine omrEngine = new Aspose.OMR.Api.OmrEngine();
   ```

5. Genere un formulario a partir del archivo de origen de la plantilla:

   ```csharp
   Aspose.OMR.Generation.GenerationResult generationResult = omrEngine.Generate("template.txt");
   ```

6. Guardar el resultado:

   ```csharp
   generationResult.Save("", "Hello.OMR");
   ```

**Listado completo:**

```csharp
namespace HelloOMR
{
	internal class Program
	{
		static void Main(string[] args)
		{
			Aspose.OMR.Api.OmrEngine omrEngine = new Aspose.OMR.Api.OmrEngine();
			Aspose.OMR.Generation.GenerationResult generationResult = omrEngine.Generate("template.txt");
			generationResult.Save("", "Hello.OMR");
		}
	}
}
```

Ahora ejecute el programa. Si la plantilla es correcta, obtendrá 2 archivos en el directorio **bin\Debug** del proyecto:  

- **Hello.OMR.png**\  
Un formulario imprimible en formato PNG. Dado que no hemos proporcionado una [licencia](/net/omr/licensing/), aparecerá una marca de agua en la página.
  ![Printable form](/net/omr/images/660d9b7d0a1c02f0-print-form.png)
- **Hello.OMR.omr**\
  Un patrón de reconocimiento utilizado por el motor de reconocimiento Aspose.OMR. **Este archivo es necesario para reconocer formularios rellenados; asegúrese de no borrarlo accidentalmente.**

## Responder el cuestionario {#answering-the-questionnaire}

Hagamos una pausa en la computadora y volvamos a la vieja y buena pluma y papel.

1. Imprima el formulario (**Hello.OMR.png**) generado en el paso anterior.
2. Marque una burbuja de respuesta.
3. Tome una foto del formulario rellenado (toda la hoja con las 4 marcas de recorte) con su teléfono inteligente.
   ![Filled form - photo](/net/omr/images/db41bdcd98d656ca-filled-form.png)

## Reconocimiento del cuestionario {#recognizing-the-questionnaire}
  
Ahora estamos listos para lo que significa OMR: reconocimiento óptico de marcas.  

1. Cree un nuevo proyecto en C# en Visual Studio. Puede utilizar una plantilla de proyecto muy básica, como **Aplicación de consola (.NET Framework)**.  

2. [Instale](/net/omr/installation/) el paquete NuGet **Aspose.OMR** en el proyecto.  

3. Copie la foto del formulario rellenado (por ejemplo, **IMG_20220401.jpg**) en el directorio **bin\Debug** del proyecto.  

4. Copie el patrón de reconocimiento generado previamente (**Hello.OMR.omr**) en el directorio **bin\Debug** del proyecto.  

5. Cree una instancia de la clase **Aspose.OMR.Api.OmrEngine**:

   ```csharp
   Aspose.OMR.Api.OmrEngine omrEngine = new Aspose.OMR.Api.OmrEngine();
   ```

6. Cargue el patrón de reconocimiento desde el archivo **Hello.OMR.omr**:

   ```csharp
   Aspose.OMR.Api.TemplateProcessor templateProcessor = omrEngine.GetTemplateProcessor("Hello.OMR.omr");
   ```

7. Reconocer la foto del formulario rellenado:

   ```csharp
   Aspose.OMR.Model.RecognitionResult recognitionResult = templateProcessor.Recognize("IMG_20220401.jpg");
   ```

8. Convierta el resultado del reconocimiento al formato de valores separados por comas (CSV) y guárdelo en la consola:

   ```csharp
   string result = recognitionResult.GetCsv();
   Console.WriteLine(result);
   ```

**Listado completo:**

```csharp
using System;

namespace HelloOMR
{
	internal class Program
	{
		static void Main(string[] args)
		{
			Aspose.OMR.Api.OmrEngine omrEngine = new Aspose.OMR.Api.OmrEngine();
			Aspose.OMR.Api.TemplateProcessor templateProcessor = omrEngine.GetTemplateProcessor("Hello.OMR.omr");
			Aspose.OMR.Model.RecognitionResult recognitionResult = templateProcessor.Recognize("IMG_20220401.jpg");
			string result = recognitionResult.GetCsv();
			Console.WriteLine(result);
			Console.ReadLine();
		}
	}
}
```

### Resultado del reconocimiento {#recognition-result}
  
Ahora ejecute el programa. Debería ver los resultados del reconocimiento en la salida de la consola:

```text
Element Name,Value,
Question1,"A"
```

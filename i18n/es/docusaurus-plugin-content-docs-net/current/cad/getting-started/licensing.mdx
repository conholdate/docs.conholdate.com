## Cuándo aplicar una licencia {#when-to-apply-a-license}
  
Siga estas reglas sencillas:

- La licencia solo necesita configurarse una vez por dominio de aplicación.
- Debe configurar la licencia antes de utilizar cualquier otra clase de Aspose.CAD.
- Llamar a SetLicense varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Si está desarrollando una aplicación de Windows Forms o de consola, llame a SetLicense en el código de inicio, antes de utilizar las clases de Aspose.CAD.
- Al desarrollar una aplicación ASP.NET, llame a SetLicense desde el archivo Global.asax.cs (Global.asax.vb), en el método protegido Application_Start. Este método se ejecuta una única vez al iniciar la aplicación.
- No llame a SetLicense dentro de los métodos Page_Load, ya que esto haría que la licencia se cargara cada vez que se cargue una página web.
- Si está desarrollando una biblioteca de clases, llame a SetLicense desde un constructor estático de la clase que utilice Aspose.CAD. El constructor estático se ejecuta antes de que se cree una instancia de su clase, lo que garantiza que la licencia de Aspose.CAD se configure correctamente.

## Aplicar licencia mediante un objeto archivo o flujo {#apply-license-using-file-or-stream-object}
  
Utilice el método **<a href="https://reference.aspose.com/cad/net/aspose.cad.license/setlicense/methods/1" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense</a>** para licenciar el componente. La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.CAD.dll y especificar el nombre de archivo (sin ruta) como se muestra a continuación.

### Cargar una licencia desde un archivo {#loading-a-license-from-file}
  
Este fragmento de código inicializa una licencia almacenada en un archivo o en un recurso incrustado.

```csharp
// Set path of the license file, i.e. c:\temp\
string dataDir = @"c:\temp\";

License license = new License();
license.SetLicense(dataDir + "Aspose.CAD.lic");
```

### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
Este fragmento de código inicializa la licencia desde un flujo.

```csharp
// Set path of the license file, i.e. c:\temp\
string dataDir = @"c:\temp\";
// Load an existing file in the stream
FileStream LicStream = new FileStream(dataDir + "Aspose.CAD.lic", FileMode.Open);

License license = new License();
license.SetLicense(LicStream);
```

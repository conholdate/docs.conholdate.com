**Bienvenido a Aspose.CAD para .NET**

![todo:image_alt_text](/net/cad/images/7e1a5af7ea498d85-home_1.png)

Aspose.CAD para .NET permite a los desarrolladores convertir archivos AutoCAD DWG, DWF, DWT y DXF a PDF e imágenes rasterizadas. Se trata de una API nativa que no requiere la instalación de AutoCAD ni de ningún otro software. También puede convertir las capas y diseños seleccionados de los archivos de AutoCAD. La conversión a PDF e imágenes rasterizadas ofrece una calidad muy alta.

Utilizar Aspose.CAD para .NET en su proyecto le aporta las siguientes ventajas:

- Amplio conjunto de funciones  
- Independencia de plataforma  
- Rendimiento y escalabilidad  
- Curva de aprendizaje mínima

## Funciones avanzadas de la API {#advanced-api-features}

- Admite las versiones más recientes de los archivos DWG, DWF, DWT y DXF de AutoCAD  
- Convierte los archivos de AutoCAD a PDF de alta calidad  
- Convierte los archivos de AutoCAD a imágenes rasterizadas de alta calidad  
- Selecciona y convierte diseños específicos  
- Selecciona y convierte capas específicas  
- Supervisa el proceso de conversión de archivos  

## Independencia de plataforma {#platform-independence}

Aspose.CAD para .NET admite  

- .NET Framework (incluidas aplicaciones ASP.NET y aplicaciones de Windows)  
- .NET Core

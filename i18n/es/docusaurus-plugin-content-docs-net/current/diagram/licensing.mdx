## Evaluar Aspose.Diagram {#evaluate-asposediagram}

Puede descargar fácilmente el producto Aspose.Diagram para .NET con fines de evaluación. Consulte el <a href="https://www.nuget.org/packages/Aspose.Diagram/" target="_blank" rel="nofollow noopener noreferrer">Página de descarga de Aspose.Diagram para .NET</a> para conocer la versión más reciente. La descarga de evaluación es idéntica a la descarga comprada. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia.

La versión de evaluación de Aspose.Diagram (sin una licencia especificada) proporciona toda la funcionalidad del producto, pero inserta una marca de agua de evaluación en el centro del documento al abrirlo y guardarlo, y limita a solo lectura las primeras diez formas de la primera página de su diagrama de Visio.

### Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
La versión de evaluación proporciona todas las funciones, excepto las siguientes:

- Solo puede leer las primeras diez formas de la primera página del diagrama de Visio.  
- También verá una marca de agua de evaluación en las imágenes y archivos PDF exportados.

## Aplicación de una licencia {#applying-a-license}
  
Una vez que esté satisfecho con su <a href="https://downloads.aspose.com/diagram/net" target="_blank" rel="nofollow noopener noreferrer">evaluación</a> de Aspose.Diagram para .NET, adquiera una licencia en el sitio web de Aspose: <a href="https://purchase.conholdate.com/buy" target="_blank">Portal de compra</a>. Familiarícese con los distintos tipos de licencia disponibles. Si tiene alguna pregunta, <a href="https://about.conholdate.com/contact" target="_blank">póngase en contacto con el equipo de ventas de Conholdate</a> y con gusto le ayudarán.

Cada licencia de Aspose incluye una suscripción de un año para actualizaciones gratuitas a cualquier nueva versión o corrección publicada durante este período. Proporcionamos soporte técnico gratuito y sin limitaciones tanto a usuarios con licencia como a usuarios en modo de evaluación.

La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores con licencia, la fecha de vencimiento de la suscripción, entre otros. Dicho archivo está firmado digitalmente, por lo que no debe modificarlo: incluso agregar un salto de línea adicional invalida el archivo.

### Cuándo aplicar una licencia {#when-to-apply-a-license}
  
Siga estas reglas sencillas:

- La licencia solo debe configurarse una vez por dominio de aplicación.
- Debe configurar la licencia antes de utilizar cualquier otra clase de Aspose.Diagram.
- Llamar a SetLicense varias veces no es perjudicial, pero desperdicia tiempo de procesador.
- Si está desarrollando una aplicación de Windows Forms o de consola, llame a SetLicense en el código de inicio, antes de utilizar las clases de Aspose.Diagram.
- Al desarrollar una aplicación ASP.NET, llame a SetLicense desde el archivo Global.asax.cs, dentro del método protegido Application_Start. Este método se ejecuta una única vez al iniciar la aplicación.
- No llame a SetLicense dentro de los métodos Page_Load, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
- Si está desarrollando una biblioteca de clases, llame a SetLicense desde un constructor estático de la clase que utilice Aspose.Diagram. El constructor estático se ejecuta antes de que se cree una instancia de su clase, garantizando así que la licencia de Aspose.Diagram se configure correctamente.

### Aplicar licencia mediante archivo u objeto Stream {#apply-license-using-file-or-stream-object}
  
Utilice el método <a href="https://reference.aspose.com/diagram/net/aspose.diagram/license" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense</a> para licenciar el componente. La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Diagram.dll y especificar el nombre del archivo (sin ruta) como se muestra a continuación.

#### Cargar una licencia desde un archivo {#loading-a-license-from-file}
  
Este fragmento de código inicializa una licencia almacenada en un archivo o en un recurso incrustado.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-.NET
// Set path of the license file, i.e. c:\temp\
string dataDir = @"c:\temp\";

License license = new License();
license.SetLicense(dataDir + "Aspose.Diagram.lic");
```

#### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
Estos fragmentos de código inicializan la licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-.NET
// Set path of the license file, i.e. c:\temp\
string dataDir = @"c:\temp\";
// Load an existing Visio file in the stream
FileStream LicStream = new FileStream(dataDir + "Aspose.Diagram.lic", FileMode.Open);

License license = new License();
license.SetLicense(LicStream);
```

## Aplicar licencia por medición  {#apply-metered-license}
  
La API de Aspose.Diagram para .NET permite a los desarrolladores aplicar una licencia por medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.

Se ha agregado una nueva clase <a href="https://reference.aspose.com/diagram/net/aspose.diagram/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar la clave por medición. El siguiente ejemplo de código muestra cómo configurar las claves pública y privada por medición:

```csharp
// Initialize a Metered license class object
Aspose.Diagram.Metered metered = new Aspose.Diagram.Metered();
// apply public and private keys
metered.SetMeteredKey("your-public-key", "your-private-key");
```

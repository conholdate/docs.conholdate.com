## Funciones avanzadas {#rich-features}

**Crear**:

- Crear diagramas desde cero.

**Leer**:

- Leer formato VDW de Microsoft Visio 2003/2007/2010.
- Leer formato de diagrama de flujo Mermaid y formato de secuencia Mermaid.

**Leer y escribir**:

- Leer o escribir formato VSD de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato VSDX de Microsoft Visio 2013.
- Leer o escribir formato VSTX de Microsoft Visio 2013.
- Leer o escribir formato VSSX de Microsoft Visio 2013.
- Leer o escribir formato VSDM de Microsoft Visio 2013.
- Leer o escribir formato VSTM de Microsoft Visio 2013.
- Leer o escribir formato VSSM de Microsoft Visio 2013.
- Leer o escribir formato VDX de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato VSX de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato VTX de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato VSS de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato VST de Microsoft Visio 2003/2007/2010.
- Leer o escribir formato HTML.
- Leer o escribir formato SVG.

**Exportar**:

- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a formatos de imagen populares (BMP, JPEG, TIFF, EMF, SVG y PNG).
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a PDF.
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a HTML.
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a Especificación de Papel XML (XPS).
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) al formato de archivo Flash de Macromedia (SWF).
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a XAML.
- Exportar diagramas (VSD, VSDX, VSS, VSSX, VTX, VDX, VDW, VST, VSTX y VSX) a DRAWIO.

**Imprimir**:

- Imprimir diagramas de Visio con alta fidelidad.
- Imprimir diagramas de Visio en un servidor mediante la API XpsPrint.

**Acceder**:

- Acceder y leer las propiedades, incluidas las fórmulas, de objetos de Visio como Document, Page, Master, Shape, StyleSheet y Connect.

**Protección**:

- Proteger diagramas permite bloquear fondos, maestros (plantillas), formas y estilos para que no puedan modificarse.

## Independencia de plataforma {#platform-independence}

Utilice Aspose.Diagram for .NET para crear cualquier tipo de aplicación .NET de 32 o 64 bits, incluidas ASP.NET, servicios web y WinForms. Aspose.Diagram.dll cumple con el CLS, está escrito completamente en C# y contiene únicamente código administrado seguro.

## Rendimiento y escalabilidad {#performance-and-scalability}

Aspose.Diagram for .NET está diseñado para funcionar eficazmente tanto en un servidor como en un cliente. Aspose.Diagram for .NET es un único ensamblado .NET que se puede implementar con cualquier aplicación .NET simplemente copiándolo. No es necesario preocuparse por otros servicios o módulos.

## Ventajas {#benefits}

El uso de Aspose.Diagram for .NET en sus aplicaciones le aporta las siguientes ventajas:

- Funciones avanzadas
- Independencia de plataforma
- Rendimiento y escalabilidad

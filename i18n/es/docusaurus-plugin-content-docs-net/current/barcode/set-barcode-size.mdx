Este artículo describe las capacidades proporcionadas por ***Aspose.BarCode for .NET*** para personalizar las unidades de medida de códigos de barras (pulgadas, milímetros, puntos o píxeles) y la resolución de las imágenes de códigos de barras generadas.

## Información general {#overview}
  
En sistemas de coordenadas cartesianas, los datos de imagen se representan como las coordenadas de píxeles u objetos dibujables, respectivamente, para imágenes rasterizadas o vectoriales.  
En ***Aspose.BarCode for .NET***, para vincular los valores de dichas coordenadas con unidades de medida del mundo real, como pulgadas o milímetros, la clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/barcodegenerator" target="_blank" rel="nofollow noopener noreferrer">*BarcodeGenerator*</a> incluye la clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/unit" target="_blank" rel="nofollow noopener noreferrer">*Unit*</a> y su propiedad específica denominada <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/unit/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">*Resolution*</a>, que se expresa en puntos por pulgada (dpi). La clase *Unit* sirve para convertir automáticamente los valores del tamaño del código de barras definidos en píxeles, milímetros, pulgadas o puntos a cualquiera de las unidades de medida admitidas. De esta manera, el tamaño de los elementos en unidades de medida del mundo real se puede convertir en píxeles para realizar la generación de la imagen del código de barras.

## Definir el tamaño del código de barras en diferentes unidades  {#define-barcode-size-in-different-units}
  
La clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/unit" target="_blank" rel="nofollow noopener noreferrer">*Unit*</a> se utiliza para establecer las unidades de medida de diversos parámetros de la clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/barcodegenerator" target="_blank" rel="nofollow noopener noreferrer">*BarcodeGenerator*</a>, como *BarCodeHeight*, *BarCodeWidth*, *XDimension*, *FontUnit* y otros. En ***Aspose.BarCode para .NET***, esta clase se implementa como una representación interna de la clase .NET <a href="https://docs.microsoft.com/uk-ua/dotnet/api/system.drawing.graphicsunit?view=windowsdesktop-5.0" target="_blank" rel="nofollow noopener noreferrer">*GraphicsUnit Enum*</a>. La clase *Unit* permite convertir distintas unidades de medida en las deseadas: *Inches* (pulgadas), *Millimeters* (milímetros), *Pixels* (píxeles), *Point* (1/72 de pulgada) o *Document* (1/300 de pulgada). La unidad de medida predeterminada para la generación de códigos de barras es *Millimeters* (milímetros).

A continuación se muestran ejemplos de imágenes de códigos de barras generadas utilizando distintas configuraciones de unidades (tres píxeles y dos milímetros).

<div className="docs-owner-markdown-table">

| Unidades de tamaño | Píxeles | Milímetros |
| ------------------ | ----------------------------------------------------------- | ---------------------------------------------------------------- |
| | ![](/net/barcode/images/a1f0844ba0fee096-unitin3pixels.png) | ![](/net/barcode/images/5f3f96ca6d8fb763-unitin2millimeters.png) |

</div>

El siguiente fragmento de código ilustra cómo implementar la configuración según las etiquetas de código de barras proporcionadas.

```csharp

BarcodeGenerator gen = new BarcodeGenerator(EncodeTypes.DataMatrix, "ASPOSE");
//set unit size in 3 pixels
gen.Parameters.Barcode.XDimension.Pixels = 3;
gen.Save($"{path}UnitIn3Pixels.png", BarCodeImageFormat.Png);
//set unit size in 2 millimeters
gen.Parameters.Barcode.XDimension.Millimeters = 2;
gen.Save($"{path}UnitIn2Millimeters.png", BarCodeImageFormat.Png);
```

## Establecer la resolución de la imagen del código de barras {#set-barcode-image-resolution}
  
***Aspose.BarCode para .NET*** permite configuraciones personalizadas para la resolución de la imagen del código de barras. Para implementar esto, la clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/barcodegenerator" target="_blank" rel="nofollow noopener noreferrer">*BarcodeGenerator*</a> proporciona la propiedad <a href="https://reference.aspose.com/barcode/net/aspose.barcode.generation/basegenerationparameters/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">*Resolution*</a>, que se utiliza para obtener o establecer la resolución de una imagen de código de barras y está destinada a convertir todos los valores de tamaño del código de barras que no están en píxeles a coordenadas digitales medidas en píxeles. La propiedad *Resolution* se define de forma uniforme para todas las dimensiones de una imagen de código de barras y se expresa en dpi. Su valor predeterminado es 96 dpi.

A continuación se muestran etiquetas de códigos de barras creadas con diferentes configuraciones de resolución (96 dpi y 300 dpi).

<div className="docs-owner-markdown-table">

| Resolución | Está configurado a 96 dpi | Está configurado a 300 dpi |
| ---------- | --------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
|  | ![](/net/barcode/images/42c6b4305b8e3c6d-unitin1millimeterresolution96.png) | ![](/net/barcode/images/a8f4afd7b793eeb6-unitin1millimeterresolution300.png) |

</div>

El siguiente ejemplo de código se proporciona para demostrar cómo personalizar la configuración de resolución.

```csharp

BarcodeGenerator gen = new BarcodeGenerator(EncodeTypes.DataMatrix, "ASPOSE");
//set unit size in 1 millimeter, resolution 96
gen.Parameters.Barcode.XDimension.Millimeters = 1;
gen.Parameters.Resolution = 96;
gen.Save($"{path}UnitIn1MillimeterResolution96.png", BarCodeImageFormat.Png);
//set unit size in 1 millimeter, resolution 300
gen.Parameters.Barcode.XDimension.Millimeters = 1;
gen.Parameters.Resolution = 300;
gen.Save($"{path}UnitIn1MillimeterResolution300.png", BarCodeImageFormat.Png);
```

## Información general {#overview}
  
***Aspose.BarCode para .NET*** sin licencia puede utilizarse para generar etiquetas de código de barras sin restricciones; en este caso, se colocará una marca de agua en la imagen resultante del código de barras (las palabras “Aspose”). Además, la versión sin licencia de la biblioteca permite leer todos los tipos de códigos de barras; sin embargo, solo la simbología *Code39* puede utilizarse sin limitaciones; para todos los demás tipos de códigos de barras, el 30 % del texto descifrado se enmascarará con “ \* ”. Todas las demás acciones con códigos de barras mediante ***Aspose.BarCode para .NET*** requieren configurar previamente la licencia. La licencia activa el acceso a toda la funcionalidad de la biblioteca, lo que le permite generar y reconocer códigos de barras sin ninguna limitación ni marcas de agua.

## Cómo instalar la licencia {#how-to-install-license}
  
La licencia es un archivo XML de texto simple que contiene diversas informaciones, como el nombre del producto, el número de desarrolladores autorizados a utilizar la licencia, la fecha de caducidad de la suscripción y otros detalles. El archivo está firmado digitalmente, por lo que no debe modificarse, ya que agregar un salto de línea adicional invalida la licencia. Debe configurar la licencia antes de generar códigos de barras sin marca de agua. Solo necesita configurar la licencia una vez por aplicación (o proceso).

La configuración de la licencia puede realizarse llamando al método *SetLicense* de la clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode/license" target="_blank" rel="nofollow noopener noreferrer">*Aspose.BarCode.License*</a>. Esto debe hacerse antes de ejecutar cualquier acción con la biblioteca. El método *SetLicense* puede invocarse de distintas formas: en la sección de inicialización de una aplicación (o aplicación web), mediante el patrón Singleton o a través de un archivo/flujo.

A continuación se proporcionan los detalles sobre cómo configurar la licencia mediante estos métodos en este artículo.

### Uso de Singleton {#using-singleton}
  
El mejor enfoque es implementar la licencia mediante inicialización perezosa (lazy initialization) utilizando el patrón Singleton en los puntos clave del código. A continuación se muestra cómo hacerlo agregando algunas líneas de código a su proyecto.

```csharp
internal class LicenseSingleton
{
    private static LicenseSingleton _instance = new LicenseSingleton();
    private LicenseSingleton()
    {
        // init the license
        (new Aspose.BarCode.License()).SetLicense(@"{path}Aspose.Total.Product.Family.lic");
    }

    public static void SetLicense()
    {
        LicenseSingleton local = _instance;
    }
}
	
	//lazy initialization before using the library
	LicenseSingleton.SetLicense();
```

### Desde archivo o flujo  {#from-file-or-stream}
  
La configuración de la licencia también se puede realizar desde un archivo o un flujo, como se muestra a continuación.

***Configuración de la licencia desde archivo***

```csharp
//set path to file
(new Aspose.BarCode.License()).SetLicense(@"{path}Aspose.Total.Product.Family.lic");
```

***Establecer la licencia desde el flujo***

```csharp
System.IO.MemoryStream ms = new System.IO.MemoryStream();
//load license data to stream
//set position to 0 to start reading from beginning
ms.Position = 0;
//set license as stream
(new Aspose.BarCode.License()).SetLicense(ms);
```

### Desde el recurso de la aplicación  {#from-application-resource}
  
Otra forma de agregar la licencia en una aplicación es incluirla como un recurso incrustado en uno de los ensamblados que llaman a ***Aspose.BarCode for .NET***. De esta manera, la licencia puede incrustarse en la aplicación como un recurso y luego cargarse desde el recurso como un flujo. A continuación se muestra cómo se puede realizar la configuración de la licencia en este modo.

***Incrustar la licencia como recurso***

```xml
<ItemGroup>
	<EmbeddedResource Include="{path}Aspose.Total.Product.Family.lic" LogicalName="Aspose.Total.Product.Family.lic"/>
</ItemGroup>
```

***Cargando licencia como flujo***

```csharp
using (System.IO.Stream stream = System.Reflection.Assembly.GetExecutingAssembly().GetManifestResourceStream("Aspose.Total.Product.Family.lic"))
	(new Aspose.BarCode.License()).SetLicense(stream);
```

### Otras formas de instalación {#additional-installation-ways}
  
La licencia se puede configurar utilizando el nombre del archivo correspondiente o del recurso incrustado. Si el nombre de la licencia se pasa al método *SetLicense* sin especificar la ruta completa, la biblioteca la buscará en las siguientes ubicaciones:

- Directorio raíz del archivo .exe  
- Carpeta que contiene la biblioteca *Aspose.BarCode.dll*  
- Carpeta que contiene el ensamblado que llama a *Aspose.BarCode.dll*  
- Recursos incrustados de la aplicación, donde el nombre del recurso coincida con el nombre de licencia especificado

```csharp
//license name, file, or resource
(new Aspose.BarCode.License()).SetLicense("Aspose.Total.Product.Family.lic");
```

## Protección contra robo de licencia {#protection-from-license-theft}
  
Si comparte su software con la licencia aplicada fuera de su organización sin implementar ninguna protección, es posible que se produzca un acceso no autorizado a la licencia. Para evitar este riesgo, recomendamos cifrar el archivo fuente de la licencia. A continuación se muestra un ejemplo de cómo implementar dicha protección.

```csharp
//load the license from a file to stream
System.IO.MemoryStream originalStream = null;
using (System.IO.FileStream fs = new System.IO.FileStream(@"{path}Aspose.Total.Product.Family.lic", System.IO.FileMode.Open))
{
    byte[] buf = new byte[fs.Length];
    fs.Read(buf, 0, buf.Length);
    originalStream = new System.IO.MemoryStream(buf);
}

//ENCRYPT LICENSE FILE
//encription key
byte[] encriptionKey = { 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08 };
//initialization vector
byte[] ivKey = { 0x09, 0x10, 0x11, 0x12, 0x13, 0x14, 0x15, 0x16 };
System.IO.MemoryStream encryptedStream = null;
using (System.Security.Cryptography.DES des = System.Security.Cryptography.DES.Create())
{
    //set intialization value and key
    des.Key = encriptionKey;
    des.IV = ivKey;
    //encrypt
    System.IO.MemoryStream dataStream = new System.IO.MemoryStream();
    using (System.Security.Cryptography.CryptoStream csEncrypt = new System.Security.Cryptography.CryptoStream(dataStream, des.CreateEncryptor(),
        System.Security.Cryptography.CryptoStreamMode.Write))
    {
        //file length
        csEncrypt.Write(System.BitConverter.GetBytes((int)originalStream.Length), 0, 4);
        //file data
        csEncrypt.Write(originalStream.ToArray(), 0, (int)originalStream.Length);
    }
    encryptedStream = new System.IO.MemoryStream(dataStream.ToArray());
}

//DECRYPT LICENSE FILE
//same encription key and initialization vector
System.IO.MemoryStream decryptedStream = null;
using (System.Security.Cryptography.DES des = System.Security.Cryptography.DES.Create())
{
    //set the intialization value and the key
    des.Key = encriptionKey;
    des.IV = ivKey;
    //decrypt
    System.IO.MemoryStream dataStream = new System.IO.MemoryStream(encryptedStream.ToArray());
    dataStream.Position = 0;
    using (System.Security.Cryptography.CryptoStream csDecrypt = new System.Security.Cryptography.CryptoStream(dataStream, des.CreateDecryptor(),
        System.Security.Cryptography.CryptoStreamMode.Read))
    {
        //read length
        byte[] buffLen = new byte[4];
        csDecrypt.Read(buffLen, 0, buffLen.Length);
        int dataLen = System.BitConverter.ToInt32(buffLen, 0);
        //read data
        byte[] buf = new byte[dataLen];
        csDecrypt.Read(buf, 0, buf.Length);
        decryptedStream = new System.IO.MemoryStream(buf);
    }
}

//set license
(new Aspose.BarCode.License()).SetLicense(decryptedStream);
```

## Establecer licencia medible {#set-metered-license}
  
[Aspose.BarCode for .NET](/net/barcode/) permite a los desarrolladores aplicar la clave medible. Se trata de un nuevo mecanismo de licencias que puede utilizarse junto con uno de los métodos de licencia existentes. Los clientes que deseen ser facturados según el uso de las características de la API pueden aplicar la licencia medible. Para obtener más detalles, consulte <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias medibles</a>.

Se ha introducido la nueva clase <a href="https://reference.aspose.com/barcode/net/aspose.barcode/metered" target="_blank" rel="nofollow noopener noreferrer">*Metered*</a> para aplicar la clave medible. A continuación se proporciona un código de ejemplo que muestra cómo establecer las claves pública y privada medibles.

```csharp
    // set metered public and private keys
    Aspose.BarCode.Metered metered = new Aspose.BarCode.Metered();

    // Access the setMeteredKey property and pass the public and private keys as parameters
    metered.SetMeteredKey("*****", "*****");
    
    // DO PROCESSING
    
    // get the metered data amount
    decimal amount = Aspose.BarCode.Metered.GetConsumptionQuantity();
    
    // Display information
    Console.WriteLine("Amount Consumed : " + amount.ToString());
```

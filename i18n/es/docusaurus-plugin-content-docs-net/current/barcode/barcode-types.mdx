***Aspose.BarCode para .NET*** admmite más de 80 tipos diferentes de <a href="https://en.wikipedia.org/wiki/Barcode#Types_of_barcodes" target="_blank" rel="nofollow noopener noreferrer">códigos de barras</a> utilizados en diversas industrias, a saber: 1D (lineales), 2D (incluidos los códigos QR) y simbologías postales. La información detallada sobre la generación de códigos de barras mediante diversos estándares de códigos de barras se encuentra en la sección [Detalles de generación para simbologías](/net/barcode/generate-barcode-with-different-symbology/)

Los **tipos de códigos de barras lineales**, o *códigos de barras 1D*, corresponden a la primera generación de códigos de barras unidimensionales (1D), utilizados para representar información mediante variaciones en el ancho y el espaciado de líneas paralelas. Algunas simbologías 1D permiten codificar únicamente números, mientras que otras permiten también codificar letras.

Los **códigos de barras DataBar** (anteriormente RSS-14) son códigos de barras 1D y 1D apilados, desarrollados para codificar eficientemente los datos del <a href="https://ref.gs1.org/ai/?lang=en" target="_blank" rel="nofollow noopener noreferrer">*Identificador de Aplicación GS1*</a>.

Los **códigos de barras matriciales**, también conocidos como *códigos de barras 2D*, se introdujeron como una forma bidimensional de codificar información. Los códigos de barras bidimensionales (2D) se generan mediante diversos símbolos y formas. Este tipo de código de barras se considera más eficiente, ya que almacena más datos por unidad de área y la mayoría de ellos son autocorregibles.

Los **códigos de barras postales** son simbologías específicas utilizadas por los servicios postales en distintos países.

Los **códigos de barras HIBC** codifican datos en un <a href="https://www.hibcc.org/udi-labeling-standards/barcode-standards/" target="_blank" rel="nofollow noopener noreferrer">formato especial</a> utilizado en la industria de la salud. Como transporte, estos códigos de barras utilizan otros códigos de barras 1D y 2D y codifican los datos en formato alfanumérico.

Los **códigos de barras GS1** utilizan otros códigos de barras 1D y 2D para codificar los datos del <a href="https://ref.gs1.org/ai/?lang=en" target="_blank" rel="nofollow noopener noreferrer">*Identificador de Aplicación GS1*</a>.

## Resumen de propósito  {#purpose-summary}
  
Esta página explica cómo funciona la licencia en Aspose.Words para .NET, incluyendo cómo aplicar licencias, el comportamiento en modo de evaluación y problemas comunes.

A veces, con el fin de estudiar mejor el sistema, desea acceder al código lo más rápido posible. Para facilitar esto, Aspose.Words ofrece distintos planes de compra, así como una prueba gratuita y una licencia temporal de 30 días para evaluación.

```

Note that there are a number of general policies and practices that guide you on how to evaluate, properly license, and purchase our products. You can find them in the [Purchase Policies and FAQ](https://purchase.aspose.com/policies/) section.

```

## Prueba gratuita o licencia temporal {#free-trial-or-temporary-license}
  
Aspose.Words es un software increíble que los desarrolladores pueden probar antes de comprarlo.

### Prueba gratuita {#free-trial}
  
La versión de evaluación es idéntica a la versión adquirida: la <a href="https://releases.aspose.com/words/" target="_blank" rel="nofollow noopener noreferrer">versión de prueba</a> simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia.

La versión de prueba de Aspose.Words sin la licencia especificada ofrece toda la funcionalidad del producto, pero inserta una marca de agua de evaluación en la parte superior del documento al cargarlo y guardarlo, y limita el tamaño máximo del documento a unos pocos cientos de párrafos.

### Licencia temporal {#temporary-license}
  
Si desea probar Aspose.Words sin las limitaciones de la versión de prueba, también puede solicitar una licencia temporal de 30 días. Para obtener más detalles, consulte la página <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">Obtener una licencia temporal</a>.

### Opciones de aplicación de licencia {#license-applying-options}
  
Las licencias pueden aplicarse desde varias ubicaciones:  

- Ruta explícita
- La carpeta que contiene el archivo `Aspose.Words.dll`
- La carpeta que contiene el ensamblado que llamó a `Aspose.Words.dll`
- La carpeta que contiene el ensamblado de entrada (su `.exe`)
- Un recurso incrustado en el ensamblado al que se llamó `Aspose.Words.dll`
- Como licencia basada en medición: un nuevo mecanismo de licencias  

Cuando haga referencia a `Aspose.Words.dll` en la aplicación, la biblioteca se copiará en su directorio de salida (a menos que la propiedad *Copy Local* de esa entrada esté establecida en *false*). Con frecuencia, la forma más sencilla de configurar una licencia consiste en colocar el archivo de licencia en la misma carpeta que `Aspose.Words.dll` y especificar únicamente el nombre del archivo, sin la ruta.

```

Use the [SetLicense](https://reference.aspose.com/words/net/aspose.words/license/setlicense/#setlicense) method to license a component.

Calling **SetLicense** multiple times is not harmful, it just wastes processor time.

Calling [SetMeteredKey](https://reference.aspose.com/words/net/aspose.words/metered/setmeteredkey/) multiple times is not harmful either, but just wastes processor time and can accumulate consumption improperly.

```

#### Aplicar licencia mediante un archivo u objeto de flujo  {#apply-license-using-a-file-or-stream-object}
  
Al desarrollar su aplicación, llame a **SetLicense** en su código de inicio, antes de utilizar las clases de Aspose.Words.

##### Cargar una licencia desde un archivo  {#load-a-license-from-a-file}
  
Mediante el método <a href="https://reference.aspose.com/words/net/aspose.words/license/setlicense/" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>, puede intentar localizar el archivo de licencia en los recursos incrustados o en las carpetas del ensamblado para su posterior uso.

El siguiente ejemplo de código muestra cómo inicializar una licencia desde una carpeta:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
License license = new License();

// This line attempts to set a license from several locations relative to the executable and Aspose.Words.dll.
// You can also use the additional overload to load a license from a stream, this is useful,
// for instance, when the license is stored as an embedded resource.
try
{
    license.SetLicense("Aspose.Words.lic");
    
    Console.WriteLine("License set successfully.");
}
catch (Exception e)
{
    // We do not ship any license with this example,
    // visit the Aspose site to obtain either a temporary or permanent license. 
    Console.WriteLine("\nThere was an error setting the license: " + e.Message);
}
```

##### Cargar una licencia desde un objeto de flujo  {#load-a-license-from-a-stream-object}
  
El siguiente ejemplo de código muestra cómo inicializar una licencia desde un flujo utilizando otro método <a href="https://reference.aspose.com/words/net/aspose.words/license/setlicense/" target="_blank" rel="nofollow noopener noreferrer">SetLicense</a>:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
License license = new License();

try
{
    license.SetLicense(new MemoryStream(File.ReadAllBytes("Aspose.Words.lic")));
    
    Console.WriteLine("License set successfully.");
}
catch (Exception e)
{
    // We do not ship any license with this example,
    // visit the Aspose site to obtain either a temporary or permanent license. 
    Console.WriteLine("\nThere was an error setting the license: " + e.Message);
}
```

#### Incluir el archivo de licencia como un recurso incrustado {#include-the-license-file-as-an-embedded-resource}
  
Una forma eficaz de empaquetar una licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llaman a Aspose.Words. Para incluir un archivo como recurso incrustado, siga estos pasos:  

1. En Visual Studio, incluya el archivo .lic en el proyecto mediante el menú **Archivo | Agregar elemento existente…**.
2. Seleccione el archivo en el Explorador de soluciones y establezca **Acción de compilación como Recurso incrustado** en la ventana Propiedades.
3. En su código, invoque **SetLicense**, pasando únicamente el nombre corto del archivo de recurso.

#### Aplicar licencia basada en medición {#apply-metered-license}
  
Aspose.Words permite a los desarrolladores aplicar una clave de medición. Se trata de un nuevo mecanismo de licencias.

Este nuevo mecanismo de licencias se utilizará junto con el método de licencias existente. Los clientes que deseen facturarse según el uso de las características de la API pueden utilizar la licencia basada en medición.

Tras completar todos los pasos necesarios para obtener este tipo de licencia, recibirá las claves, no el archivo de licencia. Esta clave de medición puede aplicarse mediante la clase <a href="https://reference.aspose.com/words/net/aspose.words/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a>, específicamente introducida para este propósito.

No invoque con frecuencia el método **SetMeteredKey**, para que este método de licencias pueda acumular correctamente el consumo y reportarlo a nosotros. Simplemente instancie la biblioteca Aspose.Words, invoque **SetMeteredKey** una sola vez, y luego deje la biblioteca instanciada y reutilícela.

El siguiente ejemplo de código muestra cómo establecer claves públicas y privadas limitadas:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
try
{
    Metered metered = new Metered();
    metered.SetMeteredKey("*****", "*****");

    Document doc = new Document(MyDir + "Document.docx");

    Console.WriteLine(doc.PageCount);
}
catch (Exception e)
{
    Console.WriteLine("\nThere was an error setting the license: " + e.Message);
}
```

Normalmente, basta con aplicar la licencia medida una sola vez al iniciar la aplicación. Sin embargo, si el mecanismo de licencia medida no logra comunicarse con los servidores de Aspose durante 24 horas, Aspose.Words saldrá del modo con licencia y pasará al modo de evaluación. Para evitar este caso, puede utilizar el método <a href="https://reference.aspose.com/words/net/aspose.words/metered/ismeteredlicensed/" target="_blank" rel="nofollow noopener noreferrer">IsMeteredLicensed</a> para verificar el estado de la licencia y volver a aplicar la licencia medida si es necesario.

```

Please note that you must have a stable Internet connection for the correct use of the Metered license, since the Metered mechanism requires the constant interaction with our services for correct calculations. For more details, refer to the [Metered Licensing FAQ](https://purchase.aspose.com/faqs/licensing/metered/) section.

```

### Cambiar el nombre del archivo de licencia {#changing-the-license-file-name}
  
El nombre del archivo de licencia no tiene por qué ser «Aspose.Words.LIC». Puede renombrarlo según su preferencia y utilizar ese nombre al configurar la licencia en su aplicación.

### Excepción «No se puede encontrar el nombre del archivo de licencia» {#cannot-find-license-filename-exception}
  
Cuando adquiere y descarga una licencia, el sitio web de Aspose asigna al archivo de licencia el nombre *«Aspose.Words.LIC»*. Usted descarga el archivo de licencia mediante su navegador. En este caso, algunos navegadores reconocen el archivo de licencia como XML y le agregan la extensión .xml, por lo que el nombre completo del archivo en su computadora se convierte en *«Aspose.Words.lic.XML»*.

Cuando Microsoft Windows está configurado para ocultar las extensiones de los tipos de archivo conocidos (por desgracia, esta es la configuración predeterminada en la mayoría de las instalaciones de Windows), el archivo de licencia aparecerá como *«Aspose.Words. LIC»* en el Explorador de Windows. Probablemente creerá que este es el nombre real del archivo e invocará **SetLicense** pasándole *«Aspose.Words.LIC»*, pero dicho archivo no existe, por lo que se generará la excepción.

Para solucionar este problema, renombre el archivo para eliminar la extensión .xml invisible. También le recomendamos desactivar la opción «ocultar extensiones» en Microsoft Windows.

## Uso de múltiples productos de Aspose {#using-multiple-aspose-products}
  
Si utiliza varios productos de Aspose en su aplicación, como Aspose.Words y `Aspose.Cells`, le ofrecemos algunos consejos útiles:  

- Configure la licencia para cada producto de Aspose por separado. Incluso si posee un único archivo de licencia para todos los componentes, por ejemplo, «Aspose.Total.lic», aún debe invocar **SetLicense** por separado para cada producto de Aspose que utilice en su aplicación.
- Utilice el nombre completo de la clase License. Cada producto de Aspose dispone de una clase **License** en su propio espacio de nombres. Por ejemplo, Aspose.Words tiene <a href="https://reference.aspose.com/words/net/aspose.words/license/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words.License</a> y `Aspose.Cells` tiene la clase `Aspose.Cells`.License. El uso del nombre completo de la clase le permite evitar confusiones sobre qué licencia corresponde a cada producto.

## Preguntas frecuentes {#faq}  

1. P: ¿Cómo aplico una licencia a Aspose.Words para .NET?  
   R: Llame al método `SetLicense` de la clase `Aspose.Words.License` antes de utilizar cualquier otra clase de Aspose.Words. Puede pasar una ruta de archivo, un flujo o el nombre corto de un recurso incrustado que contenga el archivo de licencia.  

2. P: ¿Cuál es la diferencia entre una licencia de prueba y una licencia temporal?  
   R: Una licencia de prueba es el modo de evaluación predeterminado, que agrega una marca de agua y limita el tamaño del documento. Una licencia temporal elimina estas restricciones durante un máximo de 30 días y se obtiene mediante una solicitud en el sitio web de Aspose.  

3. P: ¿Puedo renombrar el archivo de licencia y seguir utilizando `SetLicense`?  
   R: Sí. El archivo de licencia puede tener cualquier nombre; simplemente proporcione el nombre exacto del archivo (o del recurso) que haya utilizado al invocar `SetLicense`.  

4. P: ¿Son compatibles las licencias de versiones anteriores de Aspose.Words con las versiones más recientes?  
   R: Las licencias son generalmente compatibles hacia adelante; una licencia adquirida para una versión anterior funcionará con las versiones más recientes de Aspose.Words para .NET. Sin embargo, las características introducidas tras la adquisición de la licencia podrían requerir una nueva licencia de un nivel superior.  

5. P: ¿Cómo funciona la licencia basada en medición y cómo puedo verificar su estado?  
   R: La licencia basada en medición utiliza claves públicas y privadas configuradas mediante `SetMeteredKey`. La biblioteca registra el uso y lo informa a los servidores de Aspose. Utilice `IsMeteredLicensed` para comprobar si la licencia basada en medición está activa actualmente y vuelva a aplicar las claves si la conexión se ha perdido.

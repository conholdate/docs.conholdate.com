## Resumen del propósito {#purpose-summary}

Esta página explica las plataformas y marcos de trabajo admitidos.

## .NET Framework {#net-framework}

Puede utilizar con confianza Aspose.Words for .NET para crear cualquier tipo de aplicación .NET de x86 o x64 (32 o 64 bits), incluidas ASP.NET, servicios web y WinForms. Aspose.Words for .NET es fácil de implementar, ya que consta de un único ensamblado sin dependencias (salvo el propio .NET Framework). `Aspose.Words.dll` cumple con el CLS, está escrito completamente en C# y contiene únicamente código administrado seguro. Aspose.Words for .NET admite todas las versiones del Microsoft .NET Framework desde la 2.0 hasta la 4.8. Se proporciona un único instalador MSI que cubre tanto entornos de 32 como de 64 bits. El instalador contiene los siguientes elementos:

- `Aspose.Words.dll` ensamblados para distintas versiones del .NET Framework
- Proyectos de demostración para ASP.NET y WinForms en C# y `VB.NET`
- Documentación de Aspose.Words en formato Microsoft Help

## .NET Standard 2.0 {#net-standard-20}

El <a href="https://docs.microsoft.com/en-us/dotnet/standard/net-standard" target="_blank" rel="nofollow noopener noreferrer">.NET Standard</a> es una especificación formal de las API de .NET destinadas a estar disponibles en todas las implementaciones de .NET. La motivación detrás del .NET Standard es establecer una mayor uniformidad en el ecosistema de .NET. Las carpetas «netstandard2.0» y «netstandard2.0_AuthenticodeSigned» contienen los ensamblados de Aspose.Words para utilizarlos con marcos de trabajo que implementan .NET Standard 2.0, como .NET Core 2.0/2.1/2.2/3.0/3.1. La última versión de la API de Aspose.Words también admite .NET 5.0, .NET 6.0 y .NET 7.0.

## Xamarin.Android {#xamarinandroid}

Xamarin.Android permite realizar desarrollo nativo para Android en C#, ya sea con Visual Studio o con Xamarin Studio. Puede utilizar la API de Aspose.Words para llevar a cabo una amplia gama de tareas de procesamiento de documentos de Word directamente dentro de sus aplicaciones Android nativas.

## Xamarin.iOS {#xamarinios}

Xamarin.iOS permite realizar desarrollo nativo para iOS en C#, ya sea con Visual Studio o con Xamarin Studio. Puede utilizar la API de Aspose.Words para llevar a cabo una amplia gama de tareas de procesamiento de documentos de Word directamente dentro de sus aplicaciones iOS nativas.

## `Xamarin.Mac` {#xamarinmac}

`Xamarin.Mac` permite a los desarrolladores de C# crear aplicaciones Cocoa totalmente nativas para Mac OS X y permite desarrollar aplicaciones nativas que pueden publicarse en la Mac App Store. Puede utilizar la API de Aspose.Words para llevar a cabo una amplia gama de tareas de procesamiento de documentos de Word directamente dentro de sus aplicaciones nativas para Mac.

## COM {#com}

Aspose.Words for .NET puede utilizarse como un objeto `COM` para desarrollar aplicaciones en entornos de desarrollo anteriores a .NET, como PHP, ASP, VBScript, JScript, Delphi, C++, etc. Aunque es posible utilizar Aspose.Words for .NET desde COM, algunas clases y métodos (por ejemplo, aquellos que dependen de constructores con parámetros o de métodos estáticos) no están disponibles para aplicaciones COM.

## Mono {#mono}

¿Qué tal crear una aplicación que genere archivos DOC, o quizás convierta DOC y DOCX a PDF y mucho más, todo ello en openSUSE o Ubuntu? Sí, puedes ejecutar Aspose.Words for .NET con Mono. <a href="https://www.mono-project.com/Main_Page/" target="_blank" rel="nofollow noopener noreferrer">Mono</a> es un proyecto liderado por Novell (anteriormente por Ximian) para crear un conjunto de herramientas compatibles con .NET y conforme al estándar ECMA, incluyendo, entre otras, un compilador de C# y un Common Language Runtime. Mono puede ejecutarse en los sistemas operativos Linux, FreeBSD, UNIX, Mac OS X, Solaris y Windows (para más información, consulte <a href="https://en.wikipedia.org/wiki/Mono_\(software\" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/Mono(software)</a>). Aspose.Words for .NET puede utilizarse con Mono 2.4 y versiones posteriores.

## Windows Azure {#windows-azure}

La plataforma Windows Azure (Azure) es una plataforma de servicios en la nube a escala de internet alojada en los centros de datos de Microsoft. Azure permite a los desarrolladores crear rápidamente y con facilidad aplicaciones que se ejecutan en la nube, utilizando sus conocimientos sobre el .NET Framework. Las aplicaciones que se ejecutan en Windows Azure, en esencia, se ejecutan dentro de máquinas virtuales de 64 bits que ejecutan Microsoft Server 2008. Cada máquina virtual proporciona el .NET Framework 3.5 y puede ofrecer un entorno ASP.NET.

**¿Por qué Aspose.Words en Azure?**

Azure proporciona servicios para ejecutar aplicaciones y almacenar datos. Un gran número de aplicaciones web y corporativas conectadas a internet se construirán para ejecutarse en Azure. Estas aplicaciones requerirán capacidades para generar, transformar y almacenar diversos tipos de documentos. Los documentos podrían ser contratos, informes, políticas, currículums, facturas, etc. Aspose.Words para .NET es una biblioteca de clases que puede utilizarse en un servidor para generar, convertir y procesar documentos en una amplia variedad de formatos. Tiene todo el sentido del mundo utilizar Aspose.Words para .NET para resolver tareas de programación de documentos al desarrollar una aplicación que se ejecute en Windows Azure. A continuación se presentan solo algunas ideas sobre cómo puede utilizar Aspose.Words para .NET en Azure:

- Convertir documentos subidos por usuarios en diversos formatos a un formato estándar, por ejemplo, DOCX, y almacenarlos en Windows Azure Storage.
- Cargar una plantilla de documento desde Windows Azure Storage y rellenarla con datos procedentes de SQL Azure para generar un informe, contrato u otro documento.
- Generar un documento (por ejemplo, una factura) y convertirlo al formato PDF o XPS, y enviarlo al navegador del cliente.
- Convertir un documento a PDF/A o TIFF para su archivado a largo plazo en Windows Azure Storage.
- Aceptar solicitudes de los clientes en una aplicación `WebRole` mediante páginas ASP.NET o llamadas WCF y realizar el procesamiento real de documentos en aplicaciones WorkerRole con equilibrio de carga.

Puede utilizar todas las características de Aspose.Words para .NET desde aplicaciones de Windows Azure. Aspose.Words para .NET no depende de Azure.

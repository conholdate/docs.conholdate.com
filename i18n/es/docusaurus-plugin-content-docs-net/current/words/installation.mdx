## Resumen del propósito {#purpose-summary}

Esta página describe los pasos de instalación para Aspose.Words.
:::

Asegúrese de que su máquina cumpla con los [requisitos del sistema](/net/words/system-requirements/) antes de comenzar.

Este artículo explica cómo instalar Aspose.Words para .NET en su computadora.

## Instalar o actualizar Aspose.Words para .NET mediante *Manage NuGet Packages* {#install-or-update-aspose-words-for-net-using-nuget}

NuGet es la forma más sencilla de descargar e instalar las <a href="https://www.nuget.org/packages/Aspose.Words/" target="_blank" rel="nofollow noopener noreferrer">API de Aspose.Words para .NET</a>. Para hacerlo, siga estos pasos:

1. Abra *Microsoft Visual Studio* y seleccione *Manage NuGet Packages* desde el menú para abrir el administrador de paquetes
2. Busque "aspose" o "aspose.words" para encontrar la API de Aspose deseada
   ![aspose-words-nuget](/net/words/images/7bbc5f2b8a7c244e-aspose-words-nuget.png)
3. Seleccione la API de Aspose deseada y haga clic en "Instalar"

La API seleccionada se descargará y se referenciará en su proyecto.

También puede actualizar Aspose.Words para .NET a la versión deseada mediante *Administrar paquetes NuGet*.

## Instalar o actualizar Aspose.Words mediante la Consola del Administrador de Paquetes {#install-or-update-asposewords-using-package-manager-console}

También puede instalar o actualizar las API de Aspose.Words para .NET utilizando la *Consola del Administrador de Paquetes*. Para ello, siga estos pasos:

1. Abra *Microsoft Visual Studio* y la *Consola del Administrador de Paquetes* desde el menú para abrir la consola del administrador de paquetes\
   ![aspose-words-nuget-update](/net/words/images/4f8fba43b797463f-aspose-words-nuget-update.png)
2. Escriba el comando `Install-Package Aspose.Words` y presione Enter para instalar la última versión completa en su aplicación\
   ![aspose-words-nuget-update-2](/net/words/images/276232153d635034-aspose-words-nuget-update-2.png)

:::info
Además, puede agregar el `-prerelease` sufijo al comando para especificar que también se debe instalar la última versión, incluidas las correcciones de emergencia.
:::

3. Una vez descargado, verá mensajes de confirmación\
   ![aspose-words-nuget-istalled](/net/words/images/28826da6f8d3826b-aspose-words-nuget-istalled.png)

:::info
Si no está familiarizado con la <a href="https://about.aspose.com/legal/eula/" target="_blank" rel="nofollow noopener noreferrer">EULA de Aspose</a>, se recomienda leer la licencia a la que se hace referencia en la URL.
:::

4. Ahora puede encontrar que Aspose.Words se ha agregado y referenciado correctamente en su aplicación
   ![aspose-words-nuget-references](/net/words/images/00819189210451c3-aspose-words-nuget-references.png)

En *Package Manager Console*, también puede utilizar el comando `Update-Package Aspose.Words` para comprobar si hay actualizaciones del paquete Aspose.Words e instalarlas si están disponibles. También puede agregar el sufijo `-prerelease` para actualizar a la última versión.

## Instalar Aspose.Words para .NET mediante el instalador {#install-asposewords-for-net-using-installer}

Aspose.Words para .NET puede instalarse descargando directamente el instalador MSI desde la <a href="https://releases.aspose.com/words/" target="_blank" rel="nofollow noopener noreferrer">sección de descargas</a>.

:::info
Debe haber iniciado sesión para descargar el instalador. Si aún no está registrado, puede registrarse gratuitamente.
:::

Para instalar Aspose.Words para .NET, siga estos pasos:

1. Descargue `Aspose.Words_{LatestVersion}.msi` desde la sección de descargas
2. Haga doble clic en el archivo descargado, lo que iniciará el asistente de instalación; siga las instrucciones del asistente de instalación\
   ![aspose-words-setup-1](/net/words/images/c13ffbc519b29eb3-aspose-words-setup-1.png)
3. Cuando el asistente de configuración finaliza la instalación, los archivos necesarios estarán disponibles en la carpeta ubicada en la ruta de carpeta proporcionada\
   ![aspose-words-setup-4](/net/words/images/3f044a8ca3f47c03-aspose-words-setup-4.jpg)
4. Abra su solución/proyecto en Visual Studio
5. Haga clic con el botón derecho en su proyecto en el *Explorador de soluciones* y agregue la referencia a los ensamblados instalados
6. Los ensamblados de Aspose.Words para .NET instalados aparecerán en las extensiones bajo la sección Ensamblados: simplemente seleccione el componente DLL requerido\
   ![aspose-words-setup-5](/net/words/images/2ab927c937855dec-aspose-words-setup-5.png)
7. Finalmente, haga clic en Aceptar

## Consideraciones al ejecutarse en un entorno de servidor compartido {#considerations-when-running-in-a-shared-server-environment}

Se recomienda encarecidamente que todos los componentes de Aspose .NET se ejecuten con el conjunto de permisos *Full Trust* (*Confianza total*). Esto se debe a que los componentes de Aspose .NET, en ocasiones, necesitan acceder a configuraciones del registro y archivos ubicados en lugares distintos del directorio virtual, como la lectura de fuentes. Además, los componentes `Aspose.NET` se basan en clases fundamentales del sistema .NET, algunas de las cuales también requieren permisos *Full Trust* para ejecutarse en ciertos casos.

Los proveedores de servicios de Internet (ISP) que alojan múltiples aplicaciones de distintas empresas suelen imponer el nivel de seguridad *Medium Trust* (*Confianza media*). En el caso de .NET 2.0, este nivel de seguridad puede imponer las siguientes restricciones, las cuales podrían afectar la capacidad de Aspose.Words para funcionar correctamente:

- **RegistryPermission** no está disponible. Esto significa que no puede acceder al registro, lo cual es necesario para enumerar las fuentes instaladas al representar documentos.
- **FileIOPermission** está restringida. Esto implica que solo puede acceder a archivos dentro de la jerarquía del directorio virtual de su aplicación. Esto también podría significar que no se puedan leer fuentes durante la exportación.

Por las razones anteriormente indicadas, se recomienda ejecutar Aspose.Words con permisos *Full Trust*. Es posible que algunas funcionalidades de la biblioteca funcionen al realizar distintas tareas con *Medium Trust*, mientras que otras no lo harán, por ejemplo, la representación. Esto puede deberse a llamadas de procesamiento de imágenes de GDI+.

## Preguntas frecuentes {#faq}

1. **P:** ¿Cómo aplico mi licencia de Aspose.Words tras instalar la biblioteca?\
   **R:** Agregue el archivo de licencia (por ejemplo, `Aspose.Words.lic`) a su proyecto y cárguelo en tiempo de ejecución mediante `License license = new License(); license.SetLicense("Aspose.Words.lic");`. Esto debe realizarse antes de cualquier llamada a la API de Aspose.Words para garantizar que se desactive el modo de evaluación.

2. **P:** ¿Son compatibles las licencias de versiones más recientes de Aspose.Words con versiones anteriores de la biblioteca?\
   **R:** Sí. Las licencias de Aspose suelen ser compatibles hacia atrás; una licencia generada para una versión más reciente funciona con versiones anteriores de Aspose.Words. No obstante, las funcionalidades introducidas tras la versión anterior no estarán disponibles.

3. **P:** ¿Necesito reinstalar la licencia al actualizar Aspose.Words mediante NuGet?\
   **R:** No. El archivo de licencia forma parte de su aplicación, no del paquete NuGet. Tras actualizar el paquete, mantenga el mismo archivo de licencia en su proyecto y continúe cargándolo como lo hacía anteriormente.

4. **P:** ¿Por qué Aspose.Words requiere Full Trust y puedo ejecutarlo bajo Medium Trust?\
   **R:** Se requiere Full Trust para operaciones que acceden al registro (enumeración de fuentes) y al sistema de archivos fuera de la carpeta de la aplicación. Bajo Medium Trust, algunas funcionalidades —especialmente la representación a imágenes o PDFs— podrían fallar. Si debe utilizar Medium Trust, limite las operaciones a aquellas que no requieren recursos externos.

5. **P:** ¿Qué debo hacer si el instalador no agrega los ensamblados al GAC ni a la lista de referencias de Visual Studio?\
   **R:** Agregue manualmente una referencia a los DLL instalados (por ejemplo, `Aspose.Words.dll`) haciendo clic con el botón derecho en el proyecto → *Agregar referencia* → *Examinar* hasta la carpeta de instalación. Asegúrese de que el marco de destino de su proyecto coincida con la versión del DLL.

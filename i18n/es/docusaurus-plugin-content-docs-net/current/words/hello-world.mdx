## Resumen del propósito {#purpose-summary}

Esta página describe un ejemplo básico de "Hola Mundo".

Un código de "¡Hola, Mundo!" suele ser el primer ejemplo sencillo que se escribe utilizando "Aspose.Words for .NET", y también puede utilizarse como una prueba de integridad para garantizar que el software destinado a compilar o ejecutar código fuente esté instalado correctamente.

La biblioteca C# "Aspose.Words for .NET" proporciona a los desarrolladores acceso directo para crear, modificar, fusionar, convertir y comparar documentos de Word y web. Los formatos de archivo PDF, DOCX, DOC, RTF, ODT, EPUB, HTML y muchos otros están [soportados](/net/words/supported-document-formats/).

El fragmento de código siguiente sigue estos pasos:

1. Cree un nuevo <a href="https://reference.aspose.com/words/net/aspose.words/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> vacío.
2. Inicialice una instancia de la clase <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a>.
3. Inserte texto al inicio del documento utilizando el método <a href="https://reference.aspose.com/words/net/aspose.words/documentbuilder/write/" target="_blank" rel="nofollow noopener noreferrer">Write</a>.
4. Abra un <a href="https://reference.aspose.com/words/net/aspose.words/document/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> existente desde un archivo. El formato del archivo se detecta automáticamente.
5. <a href="https://reference.aspose.com/words/net/aspose.words/document/appenddocument/" target="_blank" rel="nofollow noopener noreferrer">Añada</a> el documento "A" al final del documento "B".
6. <a href="https://reference.aspose.com/words/net/aspose.words/document/save/" target="_blank" rel="nofollow noopener noreferrer">Guarde</a> la salida como PDF.

El siguiente fragmento de código es un ejemplo de «¡Hola, Mundo!» para mostrar el funcionamiento de la API de **Aspose.Words para .NET**:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-.NET.git.
Document docA = new Document();            
DocumentBuilder builder = new DocumentBuilder(docA);

// Insert text to the document start.
builder.MoveToDocumentStart();
builder.Write("First Hello World paragraph");

Document docB = new Document(MyDir + "Document.docx");
// Add document B to the and of document A, preserving document B formatting.
docA.AppendDocument(docB, ImportFormatMode.KeepSourceFormatting);
            
docA.Save(ArtifactsDir + "HelloWorld.SimpleHelloWorld.pdf");
```

## Preguntas frecuentes {#faq}  

1. **P:** ¿Cómo aplico mi licencia de Aspose.Words para evitar las restricciones de evaluación?  
**R:** Descargue el archivo de licencia (`.lic`) desde su cuenta de Aspose y configúrelo antes de realizar cualquier llamada a la API:

   ```csharp
   License license = new License();
   license.SetLicense("Aspose.Words.lic");
   ```

   Esto debe hacerse una vez por inicio de la aplicación; de lo contrario, recibirá una excepción «Licencia no establecida».  

2. **P:** ¿En qué formatos de archivo puedo guardar directamente el documento desde el ejemplo de «Hola Mundo»?  
   **R:** El método `Document.Save` admite todos los formatos que aparecen en la página **Formatos de documento admitidos**, incluidos PDF, DOCX, DOC, RTF, ODT, EPUB, HTML y más. Especifique el formato deseado utilizando la extensión de archivo correspondiente, por ejemplo, `document.Save("output.pdf");`.  

3. **P:** ¿Cómo puedo convertir el documento creado a PDF sin modificar el código que escribe el texto?  
   **R:** Tras construir el documento, simplemente llame a `Save` con una extensión `.pdf`:

   ```csharp
   Document doc = new Document();
   DocumentBuilder builder = new DocumentBuilder(doc);
   builder.Write("Hello, World!");
   doc.Save("HelloWorld.pdf");
   ```

   Aspose.Words realiza automáticamente la conversión.  

4. **P:** ¿Por qué obtengo un error «File not found» (archivo no encontrado) cuando el ejemplo intenta abrir un documento existente?  
   **R:** El constructor `Document` espera una ruta válida. Asegúrese de que el archivo exista en relación con el directorio de trabajo de la aplicación o proporcione una ruta absoluta. También puede verificar la ruta con `System.IO.File.Exists(path)` antes de cargar el documento. Si el archivo está incrustado como recurso, cárguelo mediante un flujo en lugar de una ruta de archivo.

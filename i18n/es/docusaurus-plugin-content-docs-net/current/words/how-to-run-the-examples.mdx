## Resumen del propósito {#purpose-summary}

Esta página describe cómo ejecutar los ejemplos proporcionados.
:::

Para familiarizarse más con las posibilidades y características que ofrece Aspose.Words, proporcionamos ejemplos que pueden descargarse desde nuestro repositorio de GitHub, ejecutarse y estudiarse en detalle.

En este artículo, puede encontrar los requisitos del sistema, así como información sobre cómo ejecutar los ejemplos.

## Requisitos de software y prerequisitos {#software-requirements-and-prerequisites}

Asegúrese de cumplir con los siguientes requisitos antes de descargar y ejecutar los ejemplos:

1. Visual Studio Code, Visual Studio 2019.
2. NuGet Package Manager instalado y la última versión de la API de NuGet para Visual Studio.
3. Opción **nuget.org** seleccionada en el cuadro de diálogo "Herramientas → Opciones", bajo "NuGet Package Manager → Orígenes de paquetes".
4. Una conexión activa a Internet para utilizar la función de `NuGet` Restauración automática de paquetes en el proyecto de ejemplos. Si no dispone de una conexión activa a Internet en la máquina donde se van a ejecutar los ejemplos, consulte el artículo [Instalación](/net/words/installation/) y agregue manualmente una referencia a `Aspose.Words.dll` en el proyecto de ejemplos.

## Descarga y ejecución de los ejemplos {#download-and-run-the-examples}

Todos los ejemplos de Aspose.Words para .NET están alojados en <a href="https://github.com/aspose-words/Aspose.Words-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede clonar el repositorio utilizando su cliente de GitHub favorito o descargar <a href="https://github.com/aspose-words/Aspose.Words-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">el archivo ZIP</a>.

Tras obtener una copia del repositorio, puede encontrar lo siguiente:

- Todos los ejemplos se encuentran en la carpeta **Examples**.
- Existen archivos de solución de Visual Studio para C# y Xamarin, creados en Visual Studio 2019.

Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto:

- Para los ejemplos de **Referencia de API**, la estructura se basa en los nombres de las clases; para los ejemplos de **Docs**, en su mayoría se basa en la sección de documentación <a href="https://docs.aspose.com/words/net/developer-guide/" target="_blank" rel="nofollow noopener noreferrer">Guía para desarrolladores</a>.
- En la primera ejecución, las dependencias se descargarán automáticamente mediante NuGet.
- La carpeta **Data**, ubicada en la carpeta raíz de **Examples**, contiene los archivos de entrada utilizados en los ejemplos.
- Todos los ejemplos pueden ejecutarse como pruebas unitarias.

## Preguntas frecuentes (FAQ) {#faq}

1. **P:** ¿Necesito una licencia de Aspose.Words para ejecutar los proyectos de ejemplo?
   **R:** No. Los ejemplos se distribuyen con una licencia de evaluación temporal, por lo que pueden compilarse y ejecutarse sin una licencia adquirida. Si agrega su propio archivo de licencia al proyecto, los ejemplos se ejecutarán con funcionalidad completa y sin restricciones de evaluación.

2. **P:** ¿Cómo puedo ejecutar los ejemplos en una máquina que no tiene conexión a Internet?
   **R:** Primero, descargue el repositorio y los paquetes NuGet necesarios en una máquina con conexión a Internet. Luego, copie la carpeta `packages` completa (o el archivo `Aspose.Words.dll`) en la máquina sin conexión y agregue una referencia manualmente al archivo DLL en el proyecto. Después de eso, podrá compilar y ejecutar los ejemplos sin necesidad de restaurar paquetes en línea.

3. **P:** ¿Puedo ejecutar los ejemplos con .NET 8 o Visual Studio 2022?
   **R:** Sí. Abra la solución en Visual Studio 2022, cambie el marco de destino de los proyectos de ejemplo a `.NET 8.0` (o cualquier versión posterior admitida), restaure los paquetes NuGet y vuelva a compilar. El código es compatible con versiones más recientes de .NET, aunque algunos proyectos de ejemplo más antiguos pueden hacer referencia a API heredadas que requieren ajustes menores.

4. **P:** ¿Por qué obtengo el error «No se puede localizar el paquete Aspose.Words» al compilar la solución?
   **R:** Esto generalmente significa que el origen de NuGet `nuget.org` no está habilitado o que la máquina no puede acceder a Internet. Verifique que `nuget.org` esté seleccionado en **Herramientas → Opciones → Administrador de paquetes NuGet → Fuentes de paquetes** y que la red permita el acceso a `https://api.nuget.org/v3/index.json`. Si se encuentra detrás de un proxy, configure los ajustes del proxy en Visual Studio o restaure los paquetes manualmente como se describe anteriormente.

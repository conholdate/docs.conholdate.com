## Resumen del propósito {#purpose-summary}

Esta página explica los requisitos del sistema para utilizar Aspose.Words.
:::

Aspose.Words para .NET no requiere la instalación de ningún producto de terceros, como Microsoft Word. Aspose.Words es, por sí mismo, un motor para crear, modificar, convertir y representar documentos en diversos formatos, incluidos los formatos de documento de Microsoft Word.

## PREGUNTAS FRECUENTES {#faq}

1. **P:** ¿Necesito tener Microsoft Word instalado para usar Aspose.Words para .NET?\
   **R:** No. Aspose.Words es un motor independiente y no requiere que Microsoft Word ni ningún otro producto de Office de terceros esté instalado en la máquina de destino.

2. **P:** ¿Se requiere una licencia para su uso en producción?\
   **R:** Sí. Aunque se ofrece una licencia de evaluación gratuita para pruebas, debe aplicarse una licencia comercial para cualquier implementación en producción. Una licencia es válida para las versiones de la biblioteca lanzadas antes de la fecha de vencimiento de su suscripción; para utilizar versiones posteriores, debe renovar la suscripción y aplicar el nuevo archivo de licencia.

3. **P:** ¿Puedo ejecutar Aspose.Words en plataformas en la nube como AWS o Azure?\
   **R:** Por supuesto. La biblioteca funciona en cualquier servicio en la nube que admita el entorno de ejecución de .NET requerido, incluidos Amazon Web Services, Microsoft Azure y otras plataformas que puedan alojar aplicaciones .NET Core/.NET 5+.

## PREGUNTAS FRECUENTES {#faq}

1. **P:** ¿Qué formatos de archivo puede cargar (importar) Aspose.Words para .NET?
   **R:** Aspose.Words puede cargar formatos de procesamiento de textos como DOC, DOT, DOCX, DOCM, DOTX, DOTM, variantes FlatOpc, XML, RTF, WordML, HTML, MHTML, ODT, OTT, TXT, MD, PDF, EPUB, MOBI, AZW3, CHM y varios formatos de libros electrónicos. La capacidad de carga se indica con una marca de verificación (✔) en la columna "Carga" de la tabla.

2. **P:** ¿Qué formatos de archivo puede guardar (exportar) Aspose.Words para .NET?
   **R:** La biblioteca puede guardar en todos los formatos que tengan una marca de verificación en la columna "Guardar", incluidos los mismos formatos de procesamiento de textos que para la carga, además de formatos de salida adicionales como XLSX, EPS, XPS, XamlFixed, SVG, HtmlFixed, OpenXps, PS, PCL, TIFF, PNG, BMP, EMF, JPEG, GIF, WebP y otros enumerados en la tabla.

3. **P:** ¿Puedo convertir directamente un documento DOCX a PDF mediante Aspose.Words para .NET?
   **R:** Sí. Cargue el archivo DOCX (compatible con la carga) y luego llame a `Document.Save("output.pdf", SaveFormat.Pdf);`. La conversión se realiza completamente en memoria, sin necesidad de archivos intermedios.

4. **P:** ¿Por qué la tabla muestra XLSX como un formato de solo guardar?
   **R:** Aspose.Words no interpreta datos de hojas de cálculo, por lo que no puede cargar archivos XLSX. Sin embargo, puede exportar el contenido tabular de un documento de Word a un libro de trabajo XLSX, razón por la cual solo aparece marcada la columna "Guardar".

5. **P:** ¿Existen alguna limitación al guardar en formatos de imagen como PNG o JPEG?
   **R:** Los formatos de imagen son salidas rasterizadas; renderizan cada página como una imagen independiente. Los diseños complejos, los documentos de muy alta resolución o los documentos con muchas páginas pueden generar archivos de imagen grandes o un mayor uso de memoria. Utilice la clase `ImageSaveOptions` para controlar la resolución, el rango de páginas y otros ajustes.

## Resumen del propósito {#purpose-summary}

Esta página explica el soporte de plataformas y las consideraciones de interoperabilidad para Aspose.Words.

Aspose.Words es una biblioteca de clases que permite que sus aplicaciones realicen una amplia gama de tareas de procesamiento de documentos. Aspose.Words está disponible como cuatro productos distintos para .NET, Java, C++ y Python. Sin embargo, además de construir aplicaciones para .NET, Java, C++ y Python, es posible y a menudo tiene mucho sentido utilizar Aspose.Words al desarrollar aplicaciones para otras plataformas.

Esta sección proporciona información sobre el uso de Aspose.Words para .NET en algunas plataformas.

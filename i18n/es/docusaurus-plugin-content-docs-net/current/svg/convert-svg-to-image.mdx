## Métodos de conversión de SVG a imagen {#svg-to-image-conversion-methods}
  
Aspose.SVG para .NET admite flujos de trabajo de conversión directa y de dispositivo de renderizado. Ambos enfoques pueden generar salida en formato rasterizado, pero se adaptan a distintos diseños de aplicaciones.

<div className="docs-owner-markdown-table">

| Escenario | API recomendada | ¿Por qué usarla? |
| -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Convertir un archivo SVG, flujo, URL o documento en una imagen | `Converter.ConvertSVG()` con `ImageSaveOptions` | Mejor opción predeterminada para conversiones comunes de SVG a PNG, JPG, WebP, BMP, TIFF o GIF. |
| Renderizar un documento existente mediante un dispositivo de imagen | `SVGDocument.RenderTo()` con `ImageDevice` y `ImageRenderingOptions` | Útil cuando su aplicación ya controla dispositivos de renderizado o requiere una configuración explícita de renderizado. |
| Configurar el formato de imagen, fondo, tamaño de página, resolución, antialiasing o compresión TIFF | `ImageSaveOptions` o `ImageRenderingOptions` | Estas opciones controlan la salida en mapa de bits sin modificar el SVG de origen. |
| Convertir SVG en flujos de trabajo web, por lotes o en la nube | `SVGDocument` más entrada y salida basadas en flujos | Ayuda a evitar archivos temporales innecesarios y facilita el manejo de errores. |

</div>

## ¿Qué formato de imagen deberías elegir? {#which-image-format-should-you-choose}

<div className="docs-owner-markdown-table">

| Formato de salida | Ideal para | Notas |
| ------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| PNG | Iconos, gráficos de interfaz de usuario, capturas de pantalla, gráficos que requieren transparencia | La salida sin pérdidas y los fondos transparentes son razones comunes para elegir PNG. |
| JPG/JPEG | Fotografías o contenido SVG con imágenes fotográficas incrustadas | No conserva la transparencia; configure `BackgroundColor` al convertir contenido SVG transparente. Consulte [Cambiar el color de fondo del SVG](/net/svg/change-svg-background-color/). |
| WebP | Entrega web donde se prefieren archivos ráster más pequeños | Ideal para salidas orientadas a la web cuando el entorno de consumo admite WebP. |
| BMP | Salida ráster sin comprimir simple | Por lo general, archivos grandes; rara vez es la mejor opción para entrega web. |
| TIFF | Impresión, escaneo, archivado y flujos de trabajo de publicación multiherramienta | Utilice configuraciones de compresión cuando el tamaño del archivo sea relevante. |
| GIF | Salida simple de color indexado y flujos de trabajo web heredados | No es un reemplazo para la renderización de animaciones SVG; utilícelo cuando los sistemas posteriores requieran GIF. |

</div>

## Convertir SVG a JPG {#convert-svg-to-jpg}
  
JPG es uno de los formatos de imagen más utilizados. Su característica principal es la pérdida controlada de calidad durante la compresión. Por ello, se utiliza ampliamente para almacenar y transmitir por la web contenido gráfico digital (fotos, copias escaneadas, imágenes digitalizadas). Con Aspose.SVG, puede convertir SVG a JPG, SVG a PNG, SVG a BMP, SVG a GIF o SVG a TIFF mediante programación, con control total sobre una amplia gama de parámetros de conversión.

### Uso del método ConvertSVG() {#using-the-convertsvg-method}
  
El uso de los métodos <a href="https://reference.aspose.com/svg/net/aspose.svg.converters/converter/" target="_blank" rel="nofollow noopener noreferrer">ConvertSVG()</a> es la forma más común de convertir SVG a diversos formatos populares. El siguiente fragmento de código muestra cómo convertir SVG a JPG:  

- Abrir el documento SVG de origen ( <a href="https://docs.aspose.com/svg/files/owl-edited1.svg" target="_blank" rel="nofollow noopener noreferrer">owl-edited.svg</a>).
- Crear una instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.saving/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a>.
- Utilizar el método <a href="https://reference.aspose.com/svg/net/aspose.svg.converters/converter/convertsvg/" target="_blank" rel="nofollow noopener noreferrer">ConvertSVG()</a> para convertir y guardar el SVG como archivo JPG.

```java
using System.IO;
using Aspose.Svg.Saving;
using Aspose.Svg.Converters;
using Aspose.Svg.Rendering.Image;
```

```java
// Convert SVG to JPG in C# using ImageSaveOptions

// Initialize an SVG document from a file
using (SVGDocument document = new SVGDocument(Path.Combine(DataDir, "owl-edited.svg")))
{
    // Initialize ImageSaveOptions
    ImageSaveOptions saveOptions = new ImageSaveOptions(ImageFormat.Jpeg);

    // Convert SVG to JPG
    Converter.ConvertSVG(document, saveOptions, Path.Combine(OutputDir, "owl-edited.jpg"));
}
```

### Uso del método RenderTo() {#using-the-renderto-method}
  
Considere cómo convertir un documento de SVG a JPG utilizando el método RenderTo():  

- Abra un documento SVG de origen ( <a href="https://docs.aspose.com/svg/files/owl.svg" target="_blank" rel="nofollow noopener noreferrer">owl.svg</a>).
- Utilice el constructor <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagerenderingoptions/imagerenderingoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageRenderingOptions()</a> y especifique las opciones de renderizado del documento.
- Cree una nueva instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagedevice/" target="_blank" rel="nofollow noopener noreferrer">ImageDevice</a>, que actuará como dispositivo de salida.
- Convierta el documento mediante el método <a href="https://reference.aspose.com/svg/net/aspose.svg/svgdocument/renderto/" target="_blank" rel="nofollow noopener noreferrer">RenderTo()</a>.  

El siguiente ejemplo muestra cómo aplicar las propiedades `Format` y `UseAntialiasing` para convertir SVG a JPG:

```java
using Aspose.Svg;
using System.IO;
using Aspose.Svg.Rendering;
using Aspose.Svg.Rendering.Image;
```

```java
// Render SVG to JPEG in C# with and without antialiasing

// Initialize an SVG document from a file
using (SVGDocument document = new SVGDocument(Path.Combine(DataDir, "owl.svg")))
{
    // Set Format and UseAntialiasing for jpgOptions1
    ImageRenderingOptions jpegOptions1 = new ImageRenderingOptions(ImageFormat.Jpeg);
    jpegOptions1.UseAntialiasing = true;

    // Set Format and UseAntialiasing for jpgOptions2
    ImageRenderingOptions jpegOptions2 = new ImageRenderingOptions(ImageFormat.Jpeg);
    jpegOptions2.UseAntialiasing = false;

    // Initialize an instance of the ImageDevice class
    using (IDevice device = new ImageDevice(jpegOptions1, Path.Combine(OutputDir, "owl_out1.jpg")))
    {
        // Render SVG to JPG
        document.RenderTo(device);
    }
    using (IDevice device = new ImageDevice(jpegOptions2, Path.Combine(OutputDir, "owl_out2.jpg")))
    {
        document.RenderTo(device);
    }
}
```

:::info
Utilice `UseAntialiasing = true` cuando desee mejorar la calidad visual de las formas, el texto y las imágenes renderizadas en su aplicación, especialmente cuando la claridad y los bordes suaves son esenciales. Habilitar el *antialiasing* suaviza los bordes dentados al mezclar los colores de los píxeles adyacentes a los bordes, lo que produce un aspecto más suave y refinado.

Aunque `UseAntialiasing = true` ofrece una mejor calidad visual, también puede aumentar el tiempo de procesamiento. Para aplicaciones en las que la velocidad de renderizado es prioritaria, puede ser óptimo configurar `UseAntialiasing = false`.
:::

## Convertir SVG a PNG {#convert-svg-to-png}
  
El formato PNG utiliza un algoritmo de compresión sin pérdidas para almacenar imágenes rasterizadas. Solo admite el modelo de color RGB y no está diseñado para impresión. PNG se utiliza ampliamente para transmitir imágenes por la red y mostrar fotos y gráficos en páginas web y repositorios de nubes.

### Uso del método ConvertSVG() {#using-the-convertsvg-method-1}
  
El siguiente fragmento de código muestra cómo preparar un archivo SVG desde cero y convertirlo a PNG:  

- Preparar el código SVG y guardarlo en un archivo.
- Crear una instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.saving/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a>.
- Utilizar el método <a href="https://reference.aspose.com/svg/net/aspose.svg.converters/converter/convertsvg/" target="_blank" rel="nofollow noopener noreferrer">ConvertSVG()</a> para convertir y guardar el SVG como archivo PNG.

El siguiente ejemplo muestra cómo utilizar <a href="https://reference.aspose.com/svg/net/aspose.svg.saving/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> y convertir SVG a PNG con opciones de guardado personalizadas:

```java
using Aspose.Svg;
using System.IO;
using Aspose.Svg.Saving;
using Aspose.Svg.Converters;
```

```java
// Convert SVG to PNG in C# with a custom background color

// Prepare SVG code and save it to a file
string code = "<svg xmlns='http://www.w3.org/2000/svg'>" +
              "<circle cx='100' cy='150' r='50' stroke='#2F4F4F' stroke-width='4' fill='#FF7F50' />" +
              "<circle cx='180' cy='200' r='60' stroke='#2F4F4F' stroke-width='4' fill='#008B8B' />" +
              "</svg>";
File.WriteAllText("example.svg", code);

// Initialize an SVG document from the file
using (SVGDocument document = new SVGDocument("example.svg"))
{
    // Initialize an instance of the ImageSaveOptions class and set the BackgroundColor property
    ImageSaveOptions saveOptions = new ImageSaveOptions();
    saveOptions.BackgroundColor = System.Drawing.Color.Gainsboro;

    // Convert SVG to PNG
    Converter.ConvertSVG(document, saveOptions, Path.Combine(OutputDir, "output.png"));
}
```

### Uso del método RenderTo() {#using-the-renderto-method-1}
  
Veamos cómo convertir SVG a PNG utilizando el método RenderTo():


- Inicializar un documento mediante uno de los constructores de <a href="https://reference.aspose.com/svg/net/aspose.svg/svgdocument/svgdocument/" target="_blank" rel="nofollow noopener noreferrer">SVGDocument()</a> ( <a href="https://docs.aspose.com/svg/files/snowflake.svg" target="_blank" rel="nofollow noopener noreferrer">snowflake.svg</a>).
- Crear una instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagerenderingoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageRenderingOptions</a>.
- Crear una nueva instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagedevice/" target="_blank" rel="nofollow noopener noreferrer">ImageDevice</a>.
- Convertir SVG a PNG mediante el método <a href="https://reference.aspose.com/svg/net/aspose.svg/svgdocument/renderto/" target="_blank" rel="nofollow noopener noreferrer">RenderTo(`device`)</a>.

```java
using Aspose.Svg;
using System.IO;
using Aspose.Svg.Rendering;
using Aspose.Svg.Rendering.Image;
```

```java
// Render SVG to PNG in C# using ImageDevice

// Prepare a path to a source SVG file
string documentPath = Path.Combine(DataDir, "snowflake.svg");

// Initialize an SVG document from the file
using (SVGDocument document = new SVGDocument(documentPath))
{
    // Create the ImageDevice, set image Format and specify an output file to render
    using (IDevice device = new ImageDevice(new ImageRenderingOptions(), Path.Combine(OutputDir, "snowflake.png")))
```

## Convertir SVG a TIFF {#convert-svg-to-tiff}
  
TIFF es un formato para almacenar imágenes gráficas rasterizadas con una amplia paleta de colores. TIFF es compatible con aplicaciones de escaneo, fax, procesamiento de texto, reconocimiento óptico de caracteres (OCR), manipulación de imágenes y diseño de páginas. Se utiliza ampliamente en poligrafía y en la impresión offset de revistas.

La API de Aspose.SVG puede convertir un documento de SVG al formato TIFF mediante varios pasos:  

- Abrir un documento SVG de origen ( <a href="https://docs.aspose.com/svg/files/conclusion.svg" target="_blank" rel="nofollow noopener noreferrer">conclusion.svg</a>).
- Utilizar el constructor <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagerenderingoptions/imagerenderingoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageRenderingOptions()</a> y especificar `Format` y otras propiedades del documento.
- Crear una nueva instancia de la clase <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imagedevice/" target="_blank" rel="nofollow noopener noreferrer">ImageDevice</a>.
- Convertir el documento mediante el método <a href="https://reference.aspose.com/svg/net/aspose.svg/svgdocument/renderto/" target="_blank" rel="nofollow noopener noreferrer">RenderTo()</a>.

```java
using Aspose.Svg;
using System.IO;
using Aspose.Svg.Rendering;
using Aspose.Svg.Rendering.Image;
```

```java
// Convert SVG to TIFF in C# with custom settings

using (SVGDocument document = new SVGDocument(Path.Combine(DataDir, "conclusion.svg")))
{
    // Initialize an instance of the ImageRenderingOptions class and set the Format and Compression properties

}
```

```java
using Aspose.Svg;
```

## Convertir SVGZ a PNG en C# {#convert-svgz-to-png-in-c}
  
SVGZ es un archivo SVG comprimido, no un modelo de dibujo independiente. Aspose.SVG para .NET puede cargar `.svgz` mediante `SVGDocument`; posteriormente, puede renderizar el documento a PNG utilizando el mismo flujo de trabajo `ImageSaveOptions` y `Converter.ConvertSVG()` utilizado para SVG:

```java
using Aspose.Svg;
using Aspose.Svg.Converters;
using Aspose.Svg.Saving;

using (var document = new SVGDocument("input.svgz"))
{
    var options = new ImageSaveOptions();
    Converter.ConvertSVG(document, options, "output.png");
}
```

PNG es el formato de imagen predeterminado para `ImageSaveOptions`, por lo que la propiedad `Format` no es necesaria para la conversión de SVGZ a PNG. Utilice este flujo de trabajo cuando necesite miniaturas, vistas previas en formato rasterizado o imágenes para la web a partir de recursos SVG comprimidos. Si necesita obtener un marcado editable antes de la renderización, consulte [Convertir SVGZ a SVG en C#](/net/svg/convert-svgz-to-svg/).

Esto ayuda a mantener la coherencia de las miniaturas, las vistas previas, los informes y las imágenes para la web en el desarrollo local, en los servidores y en los contenedores.

## Preguntas frecuentes {#faq}
  
**¿Puedo convertir un SVG creado o editado en memoria?** Sí. Cree o actualice un `SVGDocument`, configure `ImageSaveOptions` y pase la instancia del documento a `Converter.ConvertSVG()`. Esto resulta útil cuando edita elementos, estilos o colores SVG antes de renderizar la imagen final.  

**¿Puedo modificar el contenido del SVG antes de convertirlo en una imagen?** Sí. Puede actualizar primero el DOM del SVG, por ejemplo mediante selectores CSS, y luego renderizar el documento modificado. Consulte [Editar SVG mediante selectores CSS en C#](/net/svg/edit-svg-using-css-selectors/) y [Modificar estilos SVG mediante programación en C#](/net/svg/modify-svg-styles-programmatically/).  

**¿La conversión de SVG a imagen conserva los datos vectoriales?** No. PNG, JPG, WebP, BMP, TIFF y GIF son formatos de salida en mapa de bits. El resultado son datos de imagen basados en píxeles. Si necesita mantener el marcado vectorial editable, guarde el documento como SVG o utilice compresión SVGZ.  

**¿Puedo utilizar el mismo código en una aplicación de servidor?** Sí. Las aplicaciones de servidor suelen cargar SVG desde un archivo, flujo, URL o cadena generada, y luego escriben la imagen renderizada en un almacenamiento gestionado por la aplicación. Configure explícitamente las fuentes, las rutas de recursos y las dimensiones de salida para obtener resultados coherentes.  

**¿Por dónde debo empezar si la imagen renderizada no coincide con el SVG original?** Compruebe las dimensiones, `viewBox`, las fuentes, los recursos vinculados, el CSS, el color de fondo y el suavizado (antialiasing). La tabla [Errores comunes y soluciones](/net/svg/convert-svg-to-image/#common-mistakes-and-fixes), mostrada anteriormente, enlaza con los artículos de solución de problemas más relevantes.

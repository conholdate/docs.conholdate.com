## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
La versión de evaluación está disponible en la <a href="https://releases.aspose.com/svg/net/" target="_blank" rel="nofollow noopener noreferrer">página de descargas de Aspose.SVG for .NET</a>. Sin una licencia, las limitaciones actuales del producto son:  

- Se agrega una marca de agua a los archivos de salida.
- Solo se pueden convertir las primeras cuatro páginas de un documento SVG.
- Solo se guardan el 50 % de los nodos del documento SVG durante la serialización.

## Elegir un método de licencia  {#choose-a-licensing-method}

<div className="docs-owner-markdown-table">

| Escenario | Método |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Almacenar una licencia junto con los archivos de implementación de la aplicación | Cargar un archivo de licencia con `License.SetLicense(string)` |
| Leer una licencia desde el almacenamiento de la aplicación o la infraestructura de configuración | Cargar un flujo con `License.SetLicense(Stream)` |
| Incluir la licencia dentro de un ensamblado de la aplicación | Establecer el archivo de licencia como un recurso incrustado y cargarlo por nombre |

Aplique la licencia una sola vez durante el inicio de la aplicación, antes de crear, cargar, convertir o guardar documentos SVG.

## Aplicar una licencia desde un archivo  {#apply-a-license-from-a-file}
  
La clase `Aspose.Svg.License` acepta una ruta completa o un nombre de archivo corto. Cuando se proporciona un nombre corto, `SetLicense()` busca la licencia en las siguientes ubicaciones:  

1. La ruta explícita, si se proporciona una.
2. La carpeta que contiene el ensamblado Aspose.SVG.
3. La carpeta que contiene el ensamblado que realiza la llamada.
4. La carpeta que contiene el ensamblado de entrada o de inicio.
5. Recursos incrustados en el ensamblado que realiza la llamada.  

El siguiente ejemplo carga un archivo `Aspose.SVG.lic` disponible para la aplicación:

```java
using Aspose.Svg;

// Create an Aspose.SVG license object.
License license = new License();

// Apply a license stored as an application file.
license.SetLicense("Aspose.SVG.lic");
```

Si su solución utiliza más de un producto de Aspose, instancie la clase de licencia para el producto que se está licenciando. Para Aspose.SVG, utilice `Aspose.Svg.License`.

## Aplicar una licencia desde un flujo  {#apply-a-license-from-a-stream}
  
Utilice la sobrecarga de flujo cuando su aplicación obtenga la licencia desde una ubicación de archivo protegida, una configuración incrustada u otro proveedor de almacenamiento.

```java
using System.IO;
using Aspose.Svg;

// Initialize an Aspose.SVG license object.
License license = new License();

// Open a stream that contains the license data.
using (FileStream stream = new FileStream("Aspose.SVG.lic", FileMode.Open))
{
    // Apply the license from the stream.
    license.SetLicense(stream);
}
```

## Aplicar una licencia desde un recurso incrustado  {#apply-a-license-from-an-embedded-resource}
  
Incrustar una licencia puede resultar conveniente cuando la aplicación se distribuye como una única unidad de implementación.  

1. Agregue el archivo `.lic` a su proyecto.
2. En Visual Studio, seleccione el archivo de licencia y establezca **Acción de compilación** en **Recurso incrustado**.
3. Pase el nombre del recurso incrustado a `SetLicense()`.

```java
using Aspose.Svg;

// Create an Aspose.SVG license object.
License license = new License();

// Resolve and apply the license from the embedded resource name.
license.SetLicense("Aspose.SVG.lic");
```

La clase `License` busca un recurso incrustado en el ensamblado que realiza la llamada al resolver el nombre de licencia proporcionado.

## Aplicar una licencia medida  {#apply-a-metered-license}
  
La licencia medida utiliza claves públicas y privadas en lugar de un archivo `.lic`. Está diseñada para escenarios de licencia basados en el uso; consulte la <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Preguntas frecuentes sobre licencias medidas</a> para obtener información sobre adquisición y facturación.

Utilice la clase `Aspose.Svg.Metered` para configurar sus claves medidas durante el inicio de la aplicación:

```java
using Aspose.Svg;

// Create a metered license object.
Metered metered = new Metered();

// Apply the purchased public and private metered keys.
metered.SetMeteredKey("public-key", "private-key");
```

La API medible también proporciona métodos para verificar el estado de la licencia y el consumo:

```java
// Check whether metered licensing is currently active.
bool isLicensed = Metered.IsMeteredLicensed();

// Read the current consumption quantity and credit.
decimal consumedQuantity = Metered.GetConsumptionQuantity();
decimal consumedCredit = Metered.GetConsumptionCredit();
```

Una aplicación medible debe poder informar datos de consumo. La <a href="https://reference.aspose.com/svg/net/aspose.svg/metered/" target="_blank" rel="nofollow noopener noreferrer">Referencia de la API Medible</a> explica el comportamiento cuando no es posible cargar los datos de consumo.

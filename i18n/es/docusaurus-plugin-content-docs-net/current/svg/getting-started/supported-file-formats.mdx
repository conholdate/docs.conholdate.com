Aspose.SVG para .NET funciona con formatos de archivo de más de una manera. Un archivo SVG o SVGZ se puede cargar como un documento y editarse mediante la API. El mismo documento se puede renderizar a un documento de diseño fijo o a una imagen rasterizada. Las ilustraciones rasterizadas también pueden utilizarse como entrada para la vectorización, generando un nuevo documento SVG.

La tabla siguiente distingue estos flujos de trabajo, de modo que “compatible” no implica la misma operación para todos los formatos.

## Trabajar con documentos SVG y SVGZ {#work-with-svg-and-svgz-documents}
  
SVG es el formato nativo de documentos de la API. Las aplicaciones pueden crear contenido SVG, cargar un documento existente, modificar su DOM y guardar el archivo SVG actualizado. SVGZ contiene la misma marca SVG en forma comprimida; es útil cuando un documento SVG requiere una representación almacenada o transferida más pequeña.

Para operaciones a nivel de documento, comience con [Crear, cargar y leer archivos SVG en C#](/net/svg/create-svg-document/) y [Guardar un documento SVG en C#](/net/svg/save-svg-document/). Guías especializadas muestran cómo [convertir SVG a SVGZ](/net/svg/convert-svg-to-svgz/) y [convertir SVGZ a SVG](/net/svg/convert-svgz-to-svg/).

## Renderizar SVG a documentos e imágenes {#render-svg-to-documents-and-images}
  
El renderizado toma un documento SVG y genera una salida destinada a su distribución, visualización, impresión o procesamiento posterior. Aspose.SVG para .NET renderiza SVG a PDF y XPS, así como a imágenes rasterizadas en formatos PNG, JPEG, BMP, TIFF, GIF y WebP. La salida WebP se representa mediante el valor <a href="https://reference.aspose.com/svg/net/aspose.svg.rendering.image/imageformat/" target="_blank" rel="nofollow noopener noreferrer">`ImageFormat.Webp`</a> en la API de renderizado de imágenes.

Consulte [Convertir archivos SVG en C#](/net/svg/convert-svg/) para conocer el flujo de trabajo de conversión y [Convertir SVG a imágenes en C#](/net/svg/convert-svg-to-image/) para la configuración de renderizado de imágenes. La apariencia de la salida puede depender de fuentes, efectos, recursos y opciones de imagen; [Calidad del renderizado SVG y coherencia de la salida](/net/svg/getting-started/rendering-quality-comparisons/) explica qué evaluar antes del despliegue.

## Vectorizar imágenes rasterizadas a SVG {#vectorize-raster-images-to-svg}
  
La vectorización de imágenes es una operación distinta del renderizado. Acepta una entrada rasterizada y traza el contenido visible como rutas SVG. Aspose.SVG para .NET admite flujos de trabajo de vectorización para imágenes PNG, JPEG/JPG, BMP, TIFF, GIF e ICO. El SVG resultante es especialmente útil para logotipos, iconos, diagramas y obras de arte con formas claras y un número manejable de colores.

Consulte [Vectorización de imágenes y texto](/net/svg/vectorization/) para una visión general, o comience con la guía enfocada [Convertir PNG a SVG en C#](/net/svg/convert-png-to-svg/).

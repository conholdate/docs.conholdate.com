**Aspose.SVG for .NET** es una biblioteca para aplicaciones que necesitan trabajar con contenido SVG en código: generar gráficos vectoriales, leer o editar documentos existentes, renderizar la salida o construir flujos de trabajo gráficos automatizados.
:::

## ¿Qué es Aspose.SVG para .NET? {#what-is-asposesvg-for-net}
  
Aspose.SVG para .NET proporciona a las aplicaciones .NET una API orientada a documentos para gráficos vectoriales escalables. En lugar de tratar un archivo SVG únicamente como una imagen para mostrar, su código puede trabajar con su estructura: elementos, atributos, texto, estilos, rutas, degradados, filtros y recursos referenciados.

El tipo central es <a href="https://reference.aspose.com/svg/net/aspose.svg/svgdocument/" target="_blank" rel="nofollow noopener noreferrer">`SVGDocument`</a>, que representa la jerarquía del documento SVG. Una aplicación puede crear un documento desde cero o cargar contenido SVG y SVGZ, inspeccionar o actualizar el documento mediante las API de DOM, guardar un archivo vectorial editable y pasar el contenido a flujos de trabajo de renderizado o conversión.

Esto hace que la biblioteca sea adecuada cuando el manejo de SVG forma parte de la propia aplicación, en lugar de ser un paso manual realizado en un editor gráfico.

## Dónde encaja la biblioteca {#where-the-library-fits}
  
Aspose.SVG para .NET resulta útil en software que requiere control repetible sobre contenido vectorial. Ejemplos típicos incluyen:  

- Generar gráficos con marca, etiquetas, diagramas, ilustraciones u otros activos SVG a partir de datos de la aplicación.
- Editar plantillas SVG o documentos cargados modificando texto, colores, rutas, estilos o elementos seleccionados.
- Renderizar contenido SVG a una salida fija para informes, publicaciones, generación de documentos, vistas previas o flujos de trabajo de archivo.
- Crear herramientas que conviertan imágenes rasterizadas a vectoriales o conviertan texto SVG en rutas.
- Procesar colecciones de documentos en servicios, trabajos programados, herramientas de escritorio o aplicaciones web.

Para un resumen por funcionalidad, consulte [Características de Aspose.SVG para .NET](/net/svg/getting-started/features-list/).

## Diseñada para flujos de trabajo de procesamiento de SVG {#built-for-svg-processing-workflows}
  
SVG es tanto un formato de imagen como un formato de documento estructurado. Un flujo de trabajo de producción puede necesitar preservar la fuente editable, manipular elementos específicos del documento, gestionar fuentes o recursos externos, y generar salida en otro formato. Aspose.SVG reúne estas tareas en una biblioteca diseñada para código de aplicaciones .NET.

La API incluye creación y carga de documentos, navegación e inspección del DOM, API de SVG Builder, guardado, renderizado, conversión, vectorización, optimización, filtros, degradados, transformaciones y configuración del entorno. Ejemplos detallados de implementación están organizados en el capítulo [Cómo trabajar con la API de Aspose.SVG](/net/svg/how-to-work-with-aspose-svg-api/).

## Instalación, implementación y evaluación {#installation-deployment-and-evaluation}
  
Aspose.SVG para .NET está disponible como paquete NuGet <a href="https://www.nuget.org/packages/Aspose.SVG/" target="_blank" rel="nofollow noopener noreferrer">Aspose.SVG</a>. Comience con [Instalación](/net/svg/getting-started/installation/) para agregarlo a un proyecto .NET.

Antes de la implementación, revise los [Requisitos del sistema](/net/svg/getting-started/system-requirements/) para entornos compatibles y consideraciones de renderizado. Las aplicaciones que dependan de fuentes, estilos o recursos externos deben probarse con documentos SVG representativos en el entorno donde se ejecutarán.

Puede probar la biblioteca en modo de evaluación. Para obtener salida sin restricciones, aplique una licencia completa o temporal, según se describe en [Licencias](/net/svg/getting-started/licensing/).

### Introducción {#introduction}

#### ¿Qué es Sitefinity? {#what-is-sitefinity}

Sitefinity es un sistema moderno de gestión de contenido web (CMS) basado en ASP.NET, que ofrece una gestión intuitiva del contenido web y un entorno de desarrollo robusto para profesionales empresariales. A continuación se presentan los proyectos que hemos creado para este CMS popular.

#### Aspose.Cells para .NET {#asposecells-for-net}

Aspose.Cells para .NET es una biblioteca de clases avanzada para .NET que le permite realizar una amplia gama de tareas de procesamiento de hojas de cálculo directamente dentro de sus aplicaciones .NET.

Con Aspose.Cells puede generar, modificar, convertir, representar e imprimir hojas de cálculo sin necesidad de utilizar Microsoft Excel.

Aspose.Cells para .NET admite XLS, XLSX, OpenOffice y muchos otros formatos.

## Introducción {#introduction}

El módulo Aspose .NET DNN Data Exporter to Excel permite a los usuarios exportar datos directamente desde tablas, vistas y consultas personalizadas de bases de datos locales o remotas a Microsoft Excel o a hojas de cálculo de OpenOffice. Este módulo demuestra la potente funcionalidad de creación de hojas de cálculo proporcionada por Aspose.Cells.

### Características del módulo {#module-features}

Esta versión inicial del módulo incluye las siguientes características para simplificar y facilitar el proceso de exportación:

- Permite la conexión a una base de datos MS SQL Server local
- Permite la conexión a una base de datos MS SQL Server remota
- Popula todas las tablas de la base de datos conectada
- Popula todas las vistas de la base de datos conectada
- Permite escribir consultas personalizadas
- Ajusta automáticamente el ancho de las columnas según la longitud del contenido
- Permite omitir cadenas de más de 32 KB en celdas de Excel (LoadOptions)
- Aplica formato de encabezado de columna como texto en negrita
- Puede utilizarse como fuente de datos (tablas, vistas, consulta personalizada)
- Exporta datos a documentos de Microsoft Excel (.xls, .xlsx y .xlsb)
- Exporta datos a documentos de texto delimitados por tabulaciones (\*.txt)
- Exporta datos a CSV (delimitado por comas) (\*.csv)
- Exporta datos a hojas de cálculo OpenDocument (\*.ods)
- Opción para seleccionar el formato de salida deseado antes de la exportación
- El documento exportado se envía automáticamente al navegador para su descarga

## Instalación {#installing}

Una vez descargado, siga estos pasos para instalar el módulo en su sitio web DNN:

1. Inicie sesión en su sitio como Host o como una cuenta con nivel de superusuario.
2. Vaya al menú **Host** y seleccione **Extensiones**.
3. Haga clic en **Asistente para instalar extensión**.
4. Como se indica, busque la ubicación del archivo ZIP descargado, selecciónelo y haga clic en **Abrir**.
5. Haga clic en **Siguiente**, acepte la licencia y continúe con la instalación. Al finalizar, haga clic en el botón **Volver**.

Consulte <a href="https://www.dnnsoftware.com/community/learn/video-library/view-video/video/542/view/details/how-to-install-a-module-in-dotnetnuke-7" target="_blank" rel="nofollow noopener noreferrer">este video de instalación del módulo</a> de DNN para obtener más detalles.

## Uso {#using}

Después de instalar el módulo Aspose .NET Database Data Exporter para DNN, resulta sencillo comenzar a utilizarlo en su sitio web. Siga estos pasos para empezar:

1. Asegúrese de haber iniciado sesión en DNN con una cuenta de nivel Host o Admin.
2. Navegue hasta la página donde desea agregar el módulo de exportación.
3. Seleccione **Módulos** y luego **Agregar nuevo módulo** desde la cinta superior.
4. En la lista, seleccione **Aspose.NET DNN Data Exporter to Excel Using Aspose.Cells** y arrástrelo a la posición deseada.

![todo:image_alt_text](/net/cells/images/ac482c492f505891-picture2.png)

Ha agregado correctamente el módulo Aspose .NET Database Data Exporter to Excel for DNN a su página.

![todo:image_alt_text](/net/cells/images/ad7d4148462b8a3a-picture3.png)

5. Introduzca o utilice una cadena de conexión precompletada para MS SQL Server.
6. Seleccione el tipo de origen de datos (Tabla, Vista, Consulta personalizada).
7. Seleccione o introduzca el origen de datos (Tabla, Vista, Consulta personalizada).
8. Seleccione el tipo de exportación.
9. Haga clic en **Exportar datos**.
10. El archivo deseado se descargará automáticamente.

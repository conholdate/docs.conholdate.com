:::info
Este documento está diseñado para proporcionar a los desarrolladores una comprensión detallada de cómo convertir una hoja de cálculo en un archivo de imagen **y** una hoja de cálculo con varias páginas en un archivo de imagen por página.

A veces, es posible que necesite presentar hojas de cálculo como imágenes, por ejemplo, para usarlas en aplicaciones o páginas web. Podría necesitar insertar las imágenes en un documento de Word, un archivo PDF, una presentación de PowerPoint o utilizarlas en algún otro escenario. En resumen, desea representar la hoja de cálculo como una imagen. Aspose.Cells admite la conversión de hojas de cálculo en archivos de Microsoft Excel a imágenes. Además, Aspose.Cells admite la conversión de un libro de trabajo en varios archivos de imagen, uno por página.

Podría utilizar la automatización de Office para lograr esto, pero la automatización de Office presenta sus propias desventajas. Existen varias razones y problemas involucrados: por ejemplo, seguridad, estabilidad, escalabilidad/velocidad, costo y características. En resumen, hay muchas razones, pero la principal es que la propia Microsoft recomienda encarecidamente no utilizar la automatización de Office.
:::

## Uso de Aspose.Cells para convertir una hoja de cálculo en un archivo de imagen  {#using-asposecells-to-convert-worksheet-to-image-file}
  
Este artículo muestra cómo crear una aplicación de consola en Visual Studio, convertir una hoja de cálculo en una imagen y convertir una hoja de cálculo en una imagen por página, utilizando unas pocas líneas de código con la API de Aspose.Cells.

Debe importar el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Rendering**</a> a su programa/proyecto. Este espacio de nombres contiene varias clases útiles, como <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender" target="_blank" rel="nofollow noopener noreferrer">**SheetRender**</a>, <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/imageorprintoptions" target="_blank" rel="nofollow noopener noreferrer">**ImageOrPrintOptions**</a>, <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/workbookrender" target="_blank" rel="nofollow noopener noreferrer">**WorkbookRender**</a>, entre otras. La clase <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender" target="_blank" rel="nofollow noopener noreferrer">**Aspose.Cells.Rendering.SheetRender**</a> representa una hoja de cálculo para generar imágenes de la misma y dispone de un método sobrecargado <a href="https://reference.aspose.com/cells/net/aspose.cells.rendering/sheetrender/methods/toimage/index" target="_blank" rel="nofollow noopener noreferrer">**ToImage**</a> que permite convertir directamente una hoja de cálculo en archivos de imagen, con cualquier atributo u opción especificado. Puede devolver un objeto System.Drawing.Bitmap, y posteriormente guardar la imagen en disco o en una secuencia. Se admiten varios formatos de imagen, por ejemplo: BMP, PNG, GIF, JPG, JPEG, TIFF, EMF y otros.

Este artículo explica cómo:

- Convertir una hoja de cálculo en una imagen
- Convertir cada página de una hoja de cálculo en una imagen

Esta tarea muestra cómo utilizar Aspose.Cells para convertir una hoja de cálculo de un libro de plantilla en un archivo de imagen.

### Configuración del proyecto  {#setup-project}  

1. Primero, <a href="https://downloads.aspose.com/cells/net" target="_blank" rel="nofollow noopener noreferrer">descargue Aspose.Cells para .NET</a>.
2. Instálelo en su equipo de desarrollo. Todos los componentes de <a href="http://www.aspose.com/" target="_blank" rel="nofollow noopener noreferrer">Aspose</a>, al instalarse, funcionan en modo de evaluación. Este modo no tiene límite de tiempo, pero solo inyecta marcas de agua en los documentos generados. A continuación, inicie Visual Studio .NET y cree una nueva aplicación de consola. Este ejemplo utiliza una aplicación de consola en C#, aunque también puede utilizar VB.NET. Agregue una referencia a Aspose.Cells en el proyecto creado.

### Convertir una hoja de cálculo en un archivo de imagen  {#convert-worksheet-to-image-file}
  
He creado un nuevo libro en Microsoft Excel y agregado algunos datos en la primera hoja de cálculo: **Testbook.xlsx** (1 hoja de cálculo). A continuación, se convierte la hoja Sheet1 del archivo de plantilla en un archivo de imagen llamado SheetImage.jpg.

A continuación se muestra el código utilizado por el componente para realizar esta tarea. Convierte Sheet1 en **Testbook.xlsx** en un archivo de imagen, ilustrando lo sencillo que resulta esta conversión.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

// Open a template excel file
Workbook book = new Workbook(sourceDir + "sampleConvertWorksheettoImageFile.xlsx");

// Get the first worksheet.
Worksheet sheet = book.Worksheets[0];

// Define ImageOrPrintOptions
ImageOrPrintOptions imgOptions = new ImageOrPrintOptions();
imgOptions.OnePagePerSheet = true;

// Specify the image format
imgOptions.ImageType = Drawing.ImageType.Jpeg;
            
// Render the sheet with respect to specified image/print options
SheetRender sr = new SheetRender(sheet, imgOptions);
            
// Render the image for the sheet
Bitmap bitmap = sr.ToImage(0);

// Save the image file
bitmap.Save(outputDir + "outputConvertWorksheettoImageFile.jpg");
```

## Uso de Aspose.Cells para convertir una hoja de cálculo en un archivo de imagen por página {#using-asposecells-to-convert-worksheet-to-image-file-by-page}
  
Este ejemplo muestra cómo utilizar Aspose.Cells para convertir una hoja de cálculo de un libro de plantilla que contiene varias páginas en un archivo de imagen por página.

### Convertir hoja de cálculo en imagen por página {#convert-worksheet-to-image-by-page}
  
Creé un nuevo libro en Microsoft Excel y agregué algunos datos en la primera hoja de cálculo: **Testbook2.xlsx** (1 hoja de cálculo).

Ahora, convierta la hoja de cálculo Sheet1 del archivo de plantilla en archivos de imagen (un archivo por página). Como ya he creado la aplicación de consola para realizar la tarea de copia, omitiré esos pasos de creación de la aplicación de consola y pasaré directamente a los pasos de conversión de la hoja de cálculo.

A continuación se muestra el código utilizado por el componente para realizar la tarea. Convierte Sheet1 en **Testbook2.xlsx** en archivos de imagen por página.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
//Source directory
string sourceDir = "./";

//Output directory
string outputDir = "./";

Workbook book = new Workbook(sourceDir + "sampleConvertWorksheetToImageByPage.xlsx");

Worksheet sheet = book.Worksheets[0];

Aspose.Cells.Rendering.ImageOrPrintOptions options = new Aspose.Cells.Rendering.ImageOrPrintOptions();
options.HorizontalResolution = 200;
options.VerticalResolution = 200;
options.ImageType = Drawing.ImageType.Tiff;

// Sheet2Image By Page conversion
SheetRender sr = new SheetRender(sheet, options);
for (int j = 0; j < sr.PageCount; j++)
{
    sr.ToImage(j, outputDir + "outputConvertWorksheetToImageByPage_" + (j + 1) + ".tif");
}
```

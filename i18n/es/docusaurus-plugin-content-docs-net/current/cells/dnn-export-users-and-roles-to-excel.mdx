## Introducción {#introduction}

El módulo Aspose .NET Exportar usuarios y roles a Excel permite a los desarrolladores exportar usuarios de DNN junto con sus roles a Microsoft Excel u Hojas de cálculo de OpenOffice. Este módulo demuestra la potente funcionalidad de creación de hojas de cálculo proporcionada por Aspose.Cells.

### Características del módulo {#module-features}

Esta versión inicial del módulo incluye las siguientes características para simplificar y facilitar el proceso de exportación.

- Exportar usuarios a documentos de Microsoft Excel (.xls, .xlsx y .xlsb)
- Exportar usuarios a documentos de texto delimitados por tabulaciones (\*.txt)
- Exportar usuarios a CSV (delimitado por comas) (\*.csv)
- Exportar usuarios a hojas de cálculo OpenDocument (\*.ods)
- Opción para seleccionar el formato de salida deseado antes de la exportación.
- Opción para exportar todos los usuarios o solo los seleccionados al formato de documento de salida elegido.
- El documento exportado se envía automáticamente al navegador para su descarga.

## Instalación {#installing}

Una vez descargado, siga estos pasos para instalar el módulo en su sitio web DNN:

1. Inicie sesión en su sitio como Host o como otra cuenta con nivel de superusuario.
2. Vaya al menú **Host** y seleccione **Extensiones**.
3. Haga clic en **Asistente para instalar extensión**.
4. Como se indica, navegue hasta la ubicación del archivo zip descargado, selecciónelo y haga clic en **Abrir**.
5. Haga clic en **Siguiente**, acepte la licencia y continúe con la instalación. Al finalizar, haga clic en el botón **Volver**.

Consulte <a href="https://www.dnnsoftware.com/community/learn/video-library/view-video/video/542/view/details/how-to-install-a-module-in-dotnetnuke-7" target="_blank" rel="nofollow noopener noreferrer">este video de instalación del módulo</a> de DNN para obtener más detalles.

## Uso {#using}

Después de instalar el módulo Aspose .NET Cells Export Users and Roles for DNN, resulta muy sencillo comenzar a usarlo en su sitio web. Siga estos sencillos pasos para empezar:

1. Asegúrese de haber iniciado sesión en DNN con una cuenta de nivel Host o Admin.

2. Vaya a la página donde desea agregar el módulo de exportación.

3. Seleccione **Módulos** y luego **Agregar nuevo módulo** desde la cinta superior.

4. En la lista, seleccione **Aspose Export Users and Roles to Excel** y arrástrelo a la posición deseada.

Ha agregado correctamente el módulo Aspose .NET Export Users and Roles to Excel para DNN a su página. Todos los usuarios de DNN aparecerán en la cuadrícula, y podrá seleccionar los usuarios que desea exportar y hacer clic en el botón **Exportar** tras elegir el formato de salida deseado desde el menú desplegable. El archivo deseado se descargará automáticamente.

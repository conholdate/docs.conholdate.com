## Introducción {#introduction}

El módulo Aspose .NET Importar usuarios desde Excel permite a los desarrolladores importar usuarios en masa desde un archivo de Excel. Este módulo demuestra las potentes características de hojas de cálculo de Aspose.Cells.

### Características del módulo {#module-features}

Esta versión inicial del módulo incluye las siguientes características avanzadas para simplificar y facilitar el proceso de importación:

- Permite cargar un archivo de Excel y filtrar automáticamente los usuarios existentes.
- Omite automáticamente los usuarios existentes para evitar cualquier confusión.
- Genera contraseñas dinámicas para los usuarios recién creados.
- Asigna los roles de seguridad «Usuarios registrados» y «Suscriptores» a los usuarios recién creados.

## Instalación {#installing}

Una vez descargado, siga estos pasos para instalar el módulo en su sitio web DNN:

1. Inicie sesión en su sitio como Host o como otra cuenta con nivel de superusuario.
2. Vaya al menú **Host** y seleccione **Extensiones**.
3. Haga clic en **Asistente para instalar extensión**.
4. Como se indica, navegue hasta la ubicación del archivo zip descargado, selecciónelo y haga clic en **Abrir**.
5. Haga clic en **Siguiente**, acepte la licencia y continúe con la instalación. Al finalizar, haga clic en el botón **Volver**.

Consulte <a href="https://www.dnnsoftware.com/community/learn/video-library/view-video/video/542/view/details/how-to-install-a-module-in-dotnetnuke-7" target="_blank" rel="nofollow noopener noreferrer">este video de instalación del módulo</a> de DNN para obtener más detalles.

## Uso {#using}

Después de instalar el módulo Aspose .NET Cells Import Users from Excel para DNN, resulta sencillo comenzar a utilizarlo en su sitio web. Siga estos sencillos pasos para empezar:

1. Asegúrese de haber iniciado sesión en DNN con una cuenta de nivel Host o Admin.

2. Vaya a la página donde desea agregar el módulo de importación.

3. Seleccione **Módulos** y luego **Agregar nuevo módulo** desde la cinta superior.

4. En la lista, seleccione «Aspose Import Users from Excel module for DNN» y arrástrelo a la posición deseada.

Ha agregado correctamente el módulo Aspose .NET Cells Import Users from Excel para DNN a su página. Aparecerán controles para cargar archivos junto con el enlace «Archivo de plantilla». Puede descargar el archivo de plantilla y formatear su contenido en consecuencia. Una vez que cargue su archivo Excel, se procesarán automáticamente todos los usuarios y se filtrarán los usuarios existentes. Puede seleccionar los usuarios que desea importar y presionar el botón «Importar usuarios».

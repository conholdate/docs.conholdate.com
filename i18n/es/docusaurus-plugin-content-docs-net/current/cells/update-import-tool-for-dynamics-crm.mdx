## Introducción {#introduction}

La herramienta de importación y actualización de Aspose es un complemento de código abierto destinado a su uso en Microsoft Dynamics CRM. Este complemento permite actualizar y/o exportar automáticamente datos desde CRM a hojas de cálculo de Aspose.Cells. No es necesario realizar ninguna tarea manualmente; basta con instalar este complemento para facilitar y agilizar el trabajo.

Este complemento ofrece funcionalidad para actualizar y/o exportar automáticamente desde CRM. Con un solo clic se importa/exporta el registro desde/hacia CRM.

Las principales características de este complemento son:

- Establecer una conexión con el CRM deseado.
- Permitir al usuario seleccionar la entidad y los campos deseados.
- Obtener los registros de CRM y mostrarlos en una cuadrícula.
- Exportar los registros a una hoja de cálculo de Aspose.Cells.
- Obtener los registros desde una hoja de cálculo de Aspose.Cells y mostrarlos en una cuadrícula.
- Exportar los registros desde la cuadrícula hacia CRM.

## Requisitos del sistema y plataformas compatibles {#system-requirements-and-supported-platforms}

### Requisitos del sistema {#system-requirements}

Para instalar y utilizar Aspose .NET Update Import Tool para Microsoft Dynamics CRM, debe tener instalada una de las siguientes versiones de CRM:

- Microsoft Dynamics CRM 2013.
- Microsoft Dynamics CRM 2015.
- Microsoft Dynamics CRM Online.

No dude en contactarnos si encuentra algún problema al instalar o utilizar este complemento.

### Plataformas compatibles {#supported-platforms}

Este complemento funcionará con todas las versiones de Microsoft Dynamics CRM:

- Microsoft Dynamics CRM 2013.
- Microsoft Dynamics CRM 2015.
- Microsoft Dynamics CRM Online.

## Instalación o desinstalación {#installing-or-uninstalling}

Se trata de una herramienta desarrollada a medida y no requiere instalación ni desinstalación.
Simplemente debe descargar la herramienta, extraerla en su unidad y estará lista para su uso.

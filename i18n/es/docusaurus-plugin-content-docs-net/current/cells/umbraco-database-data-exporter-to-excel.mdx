## Introducción {#introduction}

El módulo Aspose .NET Database Data Exporter to Excel para Umbraco permite a los usuarios exportar datos directamente desde tablas, vistas locales o remotas de una base de datos, así como mediante una consulta personalizada, a Microsoft Excel u hojas de cálculo de OpenOffice. Este módulo demuestra la potente funcionalidad de creación de hojas de cálculo proporcionada por Aspose.Cells. Esta versión inicial del módulo incluye las siguientes características avanzadas para simplificar y facilitar el proceso de exportación.

### Características del módulo {#module-features}

Esta versión inicial del complemento incluye las siguientes características:

- Permite conectarse a una base de datos local de MS SQL Server
- Permite conectarse a una base de datos remota de MS SQL Server
- Rellena todas las tablas de la base de datos conectada
- Rellena todas las vistas de la base de datos conectada
- Permite escribir una consulta personalizada
- Ajusta automáticamente el ancho de las columnas según la longitud del contenido.
- Permite omitir cadenas de más de 32 KB en celdas de Excel (LoadOptions)
- Aplica formato de encabezado de columna como texto en negrita
- Permite utilizar como fuente de datos (tabla, vista, consulta personalizada)
- Exporta datos a documentos de Microsoft Excel (.xls, .xlsx y .xlsb)
- Exporta datos a documentos de texto delimitados por tabulaciones (\*.txt)
- Exporta datos a CSV (delimitado por comas) (\*.csv)
- Exporta datos a hojas de cálculo OpenDocument (\*.ods)
- Opción para seleccionar el formato de salida deseado antes de la exportación.
- El documento exportado se envía automáticamente al navegador para su descarga.

## Requisitos del sistema y plataformas compatibles {#system-requirements-and-supported-platforms}

### Requisitos del sistema {#system-requirements}

Para configurar el módulo **Aspose .NET Database Data Exporter to Excel for Umbraco**, debe cumplir con los siguientes requisitos:

- Umbraco 6.2.5 y versiones 6 de Umbraco
- Umbraco con MS SQL Server
- Microsoft .NET Framework 4.0

**Nota:** En esta versión no se admite Umbraco 7 ni versiones posteriores. Agradecemos sus comentarios y esperamos agregar soporte para Umbraco 7 en la próxima versión.

### Plataformas compatibles {#supported-platforms}

El módulo es compatible con todas las versiones de

- Umbraco 6.0 ejecutándose en ASP.NET 4.0

## Instalación {#installing}

Una vez descargado, siga estos pasos para instalar este paquete en su sitio web de Umbraco:

1. Inicie sesión en la sección **Developer** de Umbraco, por ejemplo `http://www.myblog.com/umbraco`
2. En el árbol, expanda la carpeta **Packages**.
3. Desde aquí hay dos formas de instalar un paquete: seleccione **Install local package** o navegue por el **Umbraco Package Repository**.
4. Si instala un **paquete local**, no descomprima el paquete; cargue directamente el archivo ZIP en Umbraco.
5. Siga las instrucciones que aparecen en pantalla.

**Nota:** Es posible que reciba un error «Maximum request length exceeded» («Longitud máxima de solicitud excedida») durante la instalación. Puede solucionar fácilmente este problema actualizando el valor `maxRequestLength` en su archivo Umbraco `web.config`.

```xml
<httpRuntime requestValidationMode="2.0" enableVersionHeader="false" maxRequestLength="25000" />
```

## Uso de {#using}

Una vez que haya instalado el módulo Aspose .NET Database Data Exporter to Excel para Umbraco, resulta muy sencillo comenzar a utilizarlo en su sitio web. Siga estos sencillos pasos para empezar:

1. Asegúrese de haber iniciado sesión en la sección **Developer** de Umbraco, por ejemplo `http://www.myblog.com/umbraco/`
2. Haga clic en **Settings** (Configuración) en la lista de secciones ubicada en la esquina inferior izquierda de la pantalla.
3. Expanda el nodo **Templates** (Plantillas) y seleccione la plantilla a la que desea agregar el botón, por ejemplo Textpage.
4. Elija la posición dentro de la plantilla seleccionada donde desea agregar el botón de exportación. Por lo general, es recomendable colocarlo en la esquina superior derecha o en la parte inferior de la página.
5. Haga clic en **Insert Macro** (Insertar macro) en la cinta superior.
6. En **Choose a macro** (Elegir una macro) (Aspose .NET Database Data Exporter to Excel para Umbraco), seleccione la macro recién instalada de Aspose .NET Database Data Exporter to Excel para Umbraco y haga clic en **OK** (Aceptar).

Consulte la captura de pantalla a continuación para obtener más detalles.

Ha agregado correctamente el módulo Aspose .NET Database Data Exporter to Excel a su página.

![todo:image_alt_text](/net/cells/images/14a70db8c7b0d5c8-umbraco-database-data-exporter-to-excel_1.png)

1. Introduzca o utilice la cadena de conexión precompletada de MS SQL Server
2. Seleccione el tipo de origen de datos (Tabla, Vista, Consulta personalizada)

4. Seleccione el tipo de exportación
5. Haga clic en **Exportar datos**
6. El archivo deseado se descargará automáticamente.

## Introducción {#introduction}

Aspose.Cells para .NET proporciona el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a>, que simplifica las tareas comunes de procesamiento de hojas de cálculo. Esta API está diseñada para desarrolladores que desean realizar operaciones de alto nivel, como conversión a HTML, conversión a imagen, conversión a JSON, conversión a PDF, conversión de hojas de cálculo, fusión de hojas de cálculo, bloqueo de hojas de cálculo y división de hojas de cálculo, con el mínimo esfuerzo posible.

La API LowCode es ideal para escenarios donde la implementación rápida es más importante que el control detallado. Las API LowCode de Aspose.Cells ofrecen una forma declarativa y de alto nivel para realizar tareas comunes de hojas de cálculo (conversión, fusión, división, etc.) sin escribir una gran cantidad de código repetitivo. Echemos un vistazo más de cerca a las capacidades LowCode de Aspose.Cells para .NET.

## Bloquear una hoja de cálculo - SpreadsheetLocker {#lock-a-spreadsheet--spreadsheetlocker}

Si desea bloquear una hoja de cálculo, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> para realizar la tarea de bloqueo sin escribir una gran cantidad de código repetitivo. El siguiente código demuestra cómo bloquear un <a href="https://docs.aspose.com/cells/net/lock-spreadsheets-using-lowcode-api/lowcode-locker.xlsx" target="_blank" rel="nofollow noopener noreferrer">archivo de ejemplo</a> utilizando la API LowCode.

```csharp
SpreadsheetLocker.Process("lowcode-locker.xlsx", "lowcode-locker-output.xlsx", "open123", "write123");
```

## Bloquear una hoja de cálculo: SpreadsheetLocker y AbstractLowCodeProtectionProvider {#lock-a-spreadsheet--spreadsheetlocker--abstractlowcodeprotectionprovider}

Si desea bloquear una hoja de cálculo, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> para realizar la tarea de bloqueo sin escribir un código repetitivo extenso. <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/abstractlowcodeprotectionprovider/" target="_blank" rel="nofollow noopener noreferrer">AbstractLowCodeProtectionProvider</a> le permite ajustar finamente el comportamiento del bloqueo. El siguiente código demuestra cómo bloquear un <a href="https://docs.aspose.com/cells/net/lock-spreadsheets-using-lowcode-api/lowcode-locker.xlsx" target="_blank" rel="nofollow noopener noreferrer">archivo de ejemplo</a> utilizando <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetlocker/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetLocker</a> y <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/abstractlowcodeprotectionprovider/" target="_blank" rel="nofollow noopener noreferrer">AbstractLowCodeProtectionProvider</a>.

```csharp
// Prepare LowCodeLoadOptions
LowCodeLoadOptions loadOptions = new LowCodeLoadOptions();
loadOptions.InputFile = filePath + "lowcode-locker.xlsx";

// Prepare LowCodeSaveOptions
LowCodeSaveOptions saveOptions = new LowCodeSaveOptions();
saveOptions.SaveFormat = SaveFormat.Xlsx;
saveOptions.OutputFile = filePath + "lowcode-locker-output.xlsx";

// Create a custom protection provider
CustomProtectionProvider provider = new CustomProtectionProvider();

// Call the static Process method with specified parameters
SpreadsheetLocker.Process(loadOptions, saveOptions, provider);


private class CustomProtectionProvider : AbstractLowCodeProtectionProvider
{
    public override string GetOpenPassword()
    {
        return "open123";
    }

    public override string GetWritePassword()
    {
        return "write123";
    }

    public override string GetWorkbookPassword()
    {
        return "workbook123";
    }

    public override ProtectionType GetWorkbookProtectionType()
    {
        return ProtectionType.All;
    }
}
```

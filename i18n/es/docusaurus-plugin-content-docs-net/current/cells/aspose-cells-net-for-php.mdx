#### Requisitos del sistema {#system-requirements}

**A continuación se indican los requisitos del sistema para utilizar Aspose.Cells .NET para PHP:**

- IIS con PHP y PHP Manager instalados.
- Aspose.Total APIs.
- DLL e archivo TLB de Aspose.Cells Interop.

#### Plataformas compatibles {#supported-platforms}

**A continuación se indican las plataformas compatibles:**

- PHP 5.3 o superior
- Sistema operativo Windows

### Descarga y configuración {#download-and-configure}

#### Descarga de bibliotecas necesarias {#download-required-libraries}

Descargue las bibliotecas necesarias que se indican a continuación. Estas son necesarias para ejecutar los ejemplos de Aspose.Cells .NET para PHP.

- <a href="https://downloads.aspose.com/cells/net" target="_blank" rel="nofollow noopener noreferrer">Descargue los archivos DLL o MSI de Aspose.Cells para .NET desde la sección de descargas</a>
- <a href="https://downloads.aspose.com/cells/net" target="_blank" rel="nofollow noopener noreferrer">Descargue la DLL de Interop de Aspose.Cells para .NET</a>

Si descarga la versión MSI, encontrará **Aspose.Cells.dll** en la ubicación de instalación, que es `C:\Program Files (x86)\Aspose\Aspose.Cells for .NET\Bin\net2.0` de forma predeterminada.\
Si ha descargado la versión DLL, puede extraerla y luego copiar **Aspose.Cells.dll** desde la carpeta .NET 2.0 a su carpeta `C:\temp` para facilitar su uso.\
De forma similar, extraiga el archivo zip de Interop y copie **Aspose.Interop.dll** en `C:\temp`.

#### Cómo configurar el código fuente en la plataforma Windows {#how-to-configure-the-source-code-on-windows-platform}

Siga estos sencillos pasos para abrir y ampliar el código fuente mientras lo utiliza:

##### 1. Registre ambos archivos DLL e Interop DLL (por ejemplo, Aspose.Cells.dll y Aspose.Cells.Interop.dll). {#1-register-both-dll-and-interop-dll-files-eg-asposecellsdll-and-asposecellsinteropdll}

```java
Register both DLL and Interop DLL files e.g. Aspose.Cells.dll and Aspose.Cells.Interop.dll.

C:\Windows\Microsoft.NET\Framework\v2.0.50727>regasm c:\cells\Aspose.Cells.dll /codebase

Microsoft (R) .NET Framework Assembly Registration Utility 2.0.50727.7905

Copyright (C) Microsoft Corporation 1998-2004. All rights reserved.

Types registered successfully

C:\Windows\Microsoft.NET\Framework\v2.0.50727>regasm c:\cells\Aspose.Cells.Interop.dll /codebase
```

##### 2. Habilitar COM y extensiones de .NET en PHP. {#2-enable-com-and-net-extensions-in-php}

En IIS, abra PHP Manager y luego haga clic en **Habilitar/Deshabilitar Extensión**. Busque `php_com_dotnet.dll` y asegúrese de que esté habilitado.

##### 3. Configurar Aspose.Cells .NET para ejemplos de PHP {#3-configure-asposecells-net-for-php-examples}

###### Método 1 {#method-1}

Clone los ejemplos de PHP desde <a href="https://github.com/aspose-cells/Aspose.Cells-for-.NET/tree/master/Plugins/Aspose_Cells_NET_for_PHP" target="_blank" rel="nofollow noopener noreferrer">GitHub</a> y ejecute el siguiente comando:

```java
composer install
```

######  Método 2 {#method-2}

En el archivo `composer.json` de su proyecto PHP, agregue las siguientes líneas:

```java
{
    "require": {
        "aspose-cells/Aspose.Cells-for-.NET_for_php": "dev-master"
    }
}
```

y ejecute el comando de instalación:

```java
composer install
```

Para obtener más información sobre Composer, visite <a href="https://getcomposer.org/" target="_blank" rel="nofollow noopener noreferrer">https://getcomposer.org/</a>

## Guía del nuevo usuario: Trabajo con Cells AI {#new-user-guide-working-with-cells-ai}

¡Bienvenido a Cells AI! Esta guía le guiará a través de los pasos básicos para configurar y utilizar la biblioteca Cells AI.

## Requisitos previos {#prerequisites}

Antes de utilizar Cells AI, asegúrese de tener lo siguiente:

- Una **clave de API** válida de OpenAI u otro proveedor de IA de su elección.
- Un entorno de desarrollo .NET configurado para programación en C#.

## Configurar modelo de IA {#configure-ai-model}

Para comenzar a utilizar Cells AI, debe configurar un modelo de IA. Puede crear un modelo nuevo o utilizar uno de los modelos predefinidos.

### Ejemplo: {#example}

#### Configurar un nuevo modelo de IA {#setup-a-new-ai-model}

```csharp
Config.Model = new Model("gpt-4-32k");
```

#### Utilizar un modelo de IA predefinido {#use-predefined-ai-model}

```csharp
Config.Model = Model.Gpt4OMini;
```

## Crear instancia de IA {#create-ai-instance}

Debe inicializar una instancia de CellsAI proporcionando la URL raíz de la API y su clave de API. Alternativamente, puede proporcionar la URL completa de la API si es necesario.

### Ejemplo: {#example-1}

#### Inicializar con la URL raíz del chat de IA {#initialize-with-ai-chat-root-url}

```csharp
String APIKey = "sk-xxxxx";
String APIRootUrl = "https://api.openai.com/";
CellsAI cellsAI = new CellsAI(APIRootUrl, APIKey);
```

#### Inicializar con la URL completa del chat de IA {#initialize-with-ai-chat-full-url}

```csharp
String APIKey = "sk-xxxxx";
String FullAPIRootUrl = "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions";
CellsAI cellsAI = new CellsAI(FullAPIRootUrl, true, APIKey);
```

## Procesar archivos con IA {#process-files-with-ai}

Una vez que haya configurado el modelo de IA y creado una instancia de IA, puede utilizar las capacidades de la IA para procesar archivos de hojas de cálculo.

### Resumir una hoja de cálculo: {#summarize-a-spreadsheet}

#### Obtener el resumen de la hoja de cálculo {#get-summary-of-the-spreadsheet}

```csharp
// Get summary of the spreadsheet
string summary = cellsAI.SpreadsheetSummarize("c:/student.xlsx");
```

#### También puede enviar el resumen a un TextWriter: {#you-can-also-output-the-summary-to-a-textwriter}

```csharp
// Use the TextWriter approach, output summary to a TextWriter (Console)
TextWriter writer = Console.Out;
await cellsAI.SpreadsheetSummarize("c:/student.xlsx", writer);
```

### Hacer preguntas sobre una hoja de cálculo: {#ask-questions-about-a-spreadsheet}

#### Puede hacer preguntas sobre el contenido de una hoja de cálculo: {#you-can-ask-questions-about-the-content-of-a-spreadsheet}

```csharp
// Ask a question about the spreadsheet
await cellsAI.SpreadsheetQuestion("c:/student.xlsx", "Who is the best student?", writer);
```

### Crear una hoja de cálculo basada en las solicitudes del usuario: {#build-a-spreadsheet-based-on-user-requests}

#### Ejemplo: {#example-2}

Puede crear una nueva hoja de cálculo basada en una solicitud específica. Por ejemplo, generar un plan semanal de comidas:

```csharp
await cellsAI.BuildSpreadsheet("Provide weekly daily three-meal recipes, including nutritional value, preparation methods, ingredients, and cost, one day per row, and add total cost at last row.", null, "c:/foodsweekly.xlsx");
```

También puede predecir las ventas basándose en datos históricos:

```csharp
await cellsAI.BuildSpreadsheet("Based on the sales history data from row 3 to row 10, predict the sales situation for the next year. Add it in row 11.", "c:/Sales Report Year.xlsx", "c:/Sales Report Forecast.xlsx");
```

O, actualice las calificaciones de los estudiantes con un ranking:

```csharp
await cellsAI.BuildSpreadsheet("Add a new column named \"Ranking\" and fill in the content of this column based on the students' total scores ranking", "c:\\student_score.xlsx", "c:\\student_score_with_rank.xlsx");
```

#### Uso del modelo de IA con solicitudes localizadas: {#using-ai-model-with-localized-requests}

Puede utilizar el modelo de IA Qianwen de Alibaba u otros modelos de IA localizados. A continuación se explica cómo especificar una configuración regional:

```csharp
// Set to use QwenPlus AI model
Config.Model = Model.QwenPlus;
// Set locale info (e.g., Chinese)
Config.Locale = "zh";

// User request in Chinese
string userRequest = "增加新的一列,列名称是\"排名\" 并根据学生的总分大小排名填入这一列的内容";
string outfile = "D:\\学生排行.xlsx";
string inputfile = "D:\\student_score_zh.xlsx";
await cellsAI.BuildSpreadsheet(userRequest, inputfile, outfile);
```

### Obtención de fórmulas de Excel: {#getting-excel-formulas}

#### Puede consultar directamente las fórmulas de Excel desde la hoja de cálculo: {#you-can-query-excel-formulas-directly-from-the-spreadsheet}

```csharp
// Get formula from the spreadsheet
string formula = cellsAI.GetExcelFormula("c:/student.xlsx", "get the total score for Xiaomin");
```

## Utilice la configuración de proxy si no puede acceder directamente al servidor de IA {#use-proxy-settings-if-you-cannot-access-the-ai-server-directly}

Si trabaja detrás de un proxy, puede configurar la configuración de proxy para permitir que Cells AI se conecte al servidor.

```csharp
// Set up proxy for Cells AI
string proxyAddress = "http://127.0.0.1:58591";
WebProxy proxy = new WebProxy(proxyAddress)
{
    BypassProxyOnLocal = false,
    UseDefaultCredentials = false,
};

// Apply the proxy setting
cellsAI.Proxy = proxy;
```

## Funcionalidades adicionales y personalizaciones {#additional-features-and-customizations}

Cells AI permite diversas personalizaciones, como ajustar el modelo de IA, configurar configuraciones regionales y modificar los resultados de los datos. Asegúrese de explorar la API y experimentar con distintas configuraciones según su caso de uso específico.

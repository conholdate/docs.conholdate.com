A continuación se muestran los pasos con capturas de pantalla que debemos seguir para utilizar la herramienta:

![todo:image_alt_text](/net/cells/images/df60380c901b79d3-using-and-configuring-crm-update-import-tool_1.png)

- Para crear una conexión con CRM, haga clic en **Iniciar sesión en CRM** y agregue la información de su organización de CRM.

![todo:image_alt_text](/net/cells/images/c5953fca1a991829-using-and-configuring-crm-update-import-tool_2.png)

- Una vez establecida la conexión, seleccione la Entidad y la lista de atributos deseada.

![todo:image_alt_text](/net/cells/images/8e958bba46c20146-using-and-configuring-crm-update-import-tool_3.png)

- **Obtener desde CRM:** Haga clic aquí para mostrar los datos de CRM en la cuadrícula.
- **Exportar a Excel:** Haga clic aquí para exportar los datos de CRM a un archivo de Excel.
- **Obtener desde Excel:** Haga clic aquí, seleccione un archivo de Excel de origen y se mostrarán los datos del archivo de Excel en la cuadrícula.
- **Exportar a CRM:** Haga clic aquí, seleccione un archivo de Excel de origen y se importarán los datos de Excel de nuevo a CRM para la entidad seleccionada. (Tenga en cuenta que los nombres de las columnas en el archivo de Excel deben coincidir con el nombre del esquema en CRM.)

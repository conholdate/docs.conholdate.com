## Prefacio: {#preface}

Cada vez más usuarios están utilizando diversos productos de nuestra empresa en Docker y encuentran diversos problemas. Este artículo presenta brevemente cómo utilizar Aspose.Cells para Python mediante .NET en un entorno Docker basado en Debian Linux.

## Ejemplo: {#example}

Ilustramos el uso con un ejemplo sencillo. En este caso, la funcionalidad es straightforward: simplemente abrir un archivo de Excel que contenga texto en japonés en `aspose_test.py`. Aquí utilizamos `python:3.11` como imagen base, y el Dockerfile correspondiente es el siguiente:

```plain
FROM python:3.11 AS base

# For drawing, e.g., convert to PDF
RUN apt-get update && apt-get install -y libgdiplus

# Install ICU version supported by .NET Core 3.1
RUN wget http://archive.ubuntu.com/ubuntu/pool/main/i/icu/libicu70_70.1-2_amd64.deb
RUN dpkg -i libicu70_70.1-2_amd64.deb

RUN pip install -i aspose-cells-python
CMD ["python", "aspose_test.py"]
```

Luego, cuando ejecutamos el siguiente comando, obtenemos el resultado final:

- Compilar imagen de Docker

```plain
docker build -t python_test .
```

- Ejecutar imagen de Docker

```plain
docker run python_test 
```

## Nota: {#note}

Para admitir la apertura de archivos de Excel que contengan diversos idiomas, es necesario instalar ICU. Dado que el contenedor de Python mediante .NET se basa en .NET Core 3.1, y .NET Core 3.1 tiene requisitos específicos de versión para ICU (que no deben superar la versión 70), es necesario instalar una versión específica de ICU.

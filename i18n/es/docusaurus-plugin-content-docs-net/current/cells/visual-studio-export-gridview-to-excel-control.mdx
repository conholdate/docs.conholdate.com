## Introducción {#introduction}

Export GridView To Excel Control es un control de servidor ASP.NET que permite exportar el contenido de un GridView a hojas de cálculo de Microsoft Excel u OpenOffice mediante <a href="https://products.aspose.com/cells/net/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells</a>. Agrega un botón **Exportar a Excel** en la parte superior del control GridView. Al hacer clic en este botón, se exporta dinámicamente el contenido del control GridView a una hoja de cálculo de Microsoft Excel u OpenOffice y, a continuación, se descarga automáticamente el archivo exportado en la ubicación del disco seleccionada por el usuario, todo ello en tan solo unos segundos.

### Características del módulo {#module-features}

Esta versión inicial del control proporciona las siguientes características:

- Obtener una copia sin conexión del contenido de GridView en línea favorito para editarlo, compartirlo e imprimirlo.
- Heredado del control GridView predeterminado de ASP.NET y, por lo tanto, dispone de todas sus características y propiedades.
- Exportar GridView a Xlsx, Xlsb, Xls, Txt, Csv y Ods.
- Funciona con todas las versiones de .NET a partir de .NET 2.0.
- Capacidad de personalizar/localizar el texto del botón Exportar.
- Aplicar el estilo y diseño de su propio tema al botón Exportar mediante CSS.
- Opción para agregar un encabezado personalizado en la parte superior del documento exportado.
- Opción para guardar cada documento exportado en el servidor en una ruta de disco configurable.
- Opción para exportar la página actual o todas las páginas cuando la paginación está habilitada.

![todo:image_alt_text](/net/cells/images/f4f75a3917f13ed5-visual-studio-export-gridview-to-excel-control_1.png)

Este control le permite exportar el GridView en los siguientes formatos de archivo diferentes.

1. Exportar GridView a Excel
2. Exportar GridView a Xlsx
3. Exportar GridView a Xlsb
4. Exportar GridView a Xls
5. Exportar GridView a Txt
6. Exportar GridView a Csv
7. Exportar GridView a Ods

## Requisitos del sistema y plataformas compatibles {#system-requirements-and-supported-platforms}

### Requisitos del sistema {#system-requirements}

El control Exportar GridView a Excel para Visual Studio puede utilizarse en cualquier sistema que tenga instalado IIS y .NET Framework 2.0 o superior.

### Plataformas compatibles {#supported-platforms}

El control Exportar GridView a Excel para Visual Studio es compatible con todas las versiones de ASP.NET que se ejecuten sobre .NET Framework 2.0 o superior. Puede utilizar cualquiera de las siguientes versiones de Visual Studio para emplear este control en sus aplicaciones ASP.NET:

- Visual Studio 2005
- Visual Studio 2008
- Visual Studio 2010
- Visual Studio 2012
- Visual Studio 2013

## Instalación {#installing}

La instalación del control Exportar GridView a Excel es muy sencilla y fácil; siga estos sencillos pasos.

### Para Visual Studio 2010, 2012 y 2013 {#for-visual-studio-2010-2012-and-2013}

1. Extraiga el archivo zip descargado.
2. Haga doble clic en el archivo VSIX `Aspose.Excel.GridViewExport.vsix`.
3. Aparecerá un cuadro de diálogo que le mostrará las versiones de Visual Studio disponibles y compatibles instaladas en su máquina.
4. Seleccione las que desee para agregar el control **Exportar cuadrícula en Excel**.
5. Haga clic en **Instalar**.

Recibirá un cuadro de diálogo de éxito una vez completada la instalación.

**Nota:** Asegúrese de reiniciar Visual Studio para que los cambios surtan efecto.

### Para Visual Studio 2005, 2008 y ediciones Express {#for-visual-studio-2005-2008-and-express-editions}

Siga estos pasos para integrar el control **Exportar cuadrícula en Excel** en Visual Studio, de modo que pueda arrastrarlo y soltarlo fácilmente, al igual que otros controles de ASP.NET.

1. Extraiga el archivo zip descargado.

2. Asegúrese de ejecutar Visual Studio como administrador.

   En el menú **Herramientas**, haga clic en **Elegir elementos de la caja de herramientas**.

3. Haga clic en **Examinar**.\
   Aparecerá el cuadro de diálogo Abrir.

4. Vaya a la carpeta extraída y seleccione `Aspose.Excel.GridViewExport.dll`.

5. Haga clic en **Aceptar**.

Cuando abra un control .aspx o .ascx, en la caja de herramientas del lado izquierdo verá **ExportGridViewToExcel** bajo la pestaña **General**.

### Agregación manual del control ExportGridViewToExcel {#manually-adding-exportgridviewtoexcel-control}

Si experimenta algún problema al utilizar los métodos anteriores que emplean la caja de herramientas de Visual Studio, puede agregar manualmente este control a su aplicación ASP.NET que se ejecute en cualquier versión del .NET Framework superior a la 2.0.

1. Si utiliza Visual Studio, asegúrese de ejecutarlo como administrador.
2. Agregue una referencia a **Aspose.Excel.GridViewExport.dll** (disponible en el paquete descargado y extraído) en su proyecto ASP.NET o aplicación web. Asegúrese de que su aplicación web/Visual Studio tenga acceso completo a esta carpeta; de lo contrario, podría obtener una excepción de tipo "Acceso denegado".
3. Agregue esta línea al principio de la página, el control o la página maestra:

```java
<%@ Register assembly="Aspose.Excel.GridViewExport" namespace="Aspose.Excel.GridViewExport" tagprefix="aspose" %>
```

4. Agregue lo siguiente donde desee que aparezca el control:

```java
<aspose:ExportGridViewToExcel ID="ExportGridViewToExcel1" runat="server"></aspose:ExportGridViewToExcel>
```

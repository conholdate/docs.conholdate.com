## Introducción {#introduction}

Aspose.Cells para .NET proporciona el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a>, que simplifica las tareas comunes de procesamiento de hojas de cálculo. Esta API está diseñada para desarrolladores que desean realizar operaciones de alto nivel, como conversión a HTML, conversión a imagen, conversión a JSON, conversión a PDF, conversión de hojas de cálculo, fusión de hojas de cálculo, bloqueo de hojas de cálculo y división de hojas de cálculo, con el mínimo esfuerzo posible.

La API LowCode es ideal para escenarios donde la implementación rápida es más importante que el control detallado. Las API LowCode de Aspose.Cells ofrecen una forma declarativa y de alto nivel para realizar tareas comunes de hojas de cálculo (conversión, fusión, división, etc.) sin tener que escribir una gran cantidad de código repetitivo. Echemos un vistazo más de cerca a las capacidades LowCode de Aspose.Cells para .NET.

## Convertir una hoja de cálculo: SpreadsheetConverter {#convert-a-spreadsheet--spreadsheetconverter}

Si desea convertir una hoja de cálculo a otros formatos, puede utilizar la clase **SpreadsheetConverter** para realizar la conversión sin tener que escribir una gran cantidad de código repetitivo. El siguiente código demuestra cómo convertir un archivo XLSX (<a href="https://docs.aspose.com/cells/net/convert-spreadsheets-using-lowcode-api/lowcode-converter.xlsx" target="_blank" rel="nofollow noopener noreferrer">lowcode-converter.xlsx</a>) al formato XLSB mediante la API LowCode.

```csharp
SpreadsheetConverter.Process("lowcode-converter.xlsx", "lowcode-converter-output.xlsb");
```

## Convertir una hoja de cálculo: SpreadsheetConverter, LowCodeLoadOptions y LowCodeSaveOptions {#convert-a-spreadsheet--spreadsheetconverter--lowcodeloadoptions--lowcodesaveoptions}

Si desea convertir una hoja de cálculo a otros formatos, puede utilizar la clase **SpreadsheetConverter** para realizar la conversión sin escribir un código extenso y repetitivo. **LowCodeLoadOptions** y **LowCodeSaveOptions** le permiten ajustar finamente el comportamiento de la conversión. El siguiente código demuestra cómo convertir un archivo XLSX (<a href="https://docs.aspose.com/cells/net/convert-spreadsheets-using-lowcode-api/lowcode-converter.xlsx" target="_blank" rel="nofollow noopener noreferrer">lowcode-converter.xlsx</a>) al formato XLSB mediante **SpreadsheetConverter**, **LowCodeLoadOptions** y **LowCodeSaveOptions**.

```csharp
// Create load options with input file
LowCodeLoadOptions loadOptions = new LowCodeLoadOptions();
loadOptions.InputFile = "lowcode-converter.xlsx";

// Create save options with output file
LowCodeSaveOptions saveOptions = new LowCodeSaveOptions();
saveOptions.OutputFile = "lowcode-converter-output.xlsb";

// Execute conversion
SpreadsheetConverter.Process(loadOptions, saveOptions);
```

## Introducción {#introduction}

Aspose.Cells para .NET proporciona el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a>, que simplifica las tareas comunes de procesamiento de hojas de cálculo. Esta API está diseñada para desarrolladores que desean realizar operaciones de alto nivel, como conversión a HTML, conversión a imagen, conversión a JSON, conversión a PDF, conversión de hojas de cálculo, fusión de hojas de cálculo, bloqueo de hojas de cálculo y división de hojas de cálculo, con el mínimo esfuerzo posible.

La API LowCode es ideal para escenarios donde la implementación rápida es más importante que el control detallado. Las API LowCode de Aspose.Cells ofrecen una forma declarativa y de alto nivel para realizar tareas comunes de hojas de cálculo (conversión, fusión, división, etc.) sin tener que escribir una gran cantidad de código repetitivo. Echemos un vistazo más de cerca a las capacidades LowCode de Aspose.Cells para .NET.

## Fusionar varias hojas de cálculo: SpreadsheetMerger {#merge-multiple-spreadsheets--spreadsheetmerger}

Si desea fusionar varios libros en un único libro, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> para realizar la tarea de fusión sin tener que escribir una gran cantidad de código repetitivo. El siguiente código demuestra cómo fusionar dos archivos de ejemplo (<a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-1.xlsx" target="_blank" rel="nofollow noopener noreferrer">file1.xlsx</a> y <a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-2.xlsx" target="_blank" rel="nofollow noopener noreferrer">file2.xlsx</a>) en un solo archivo.

```csharp
string[] templateFiles = { "lowcode-merger-1.xlsx", "lowcode-merger-2.xlsx" };
string resultFile = "merged_output.xlsx";

SpreadsheetMerger.Process(templateFiles, resultFile);
```

## Fusionar varias hojas de cálculo: SpreadsheetMerger y LowCodeMergeOptions {#merge-multiple-spreadsheets--spreadsheetmerger--lowcodemergeoptions}

Si desea fusionar varios libros en un único libro, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> para realizar la tarea de fusión sin escribir un código repetitivo extenso. <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodemergeoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeMergeOptions</a> le permite ajustar finamente el comportamiento de la fusión. El siguiente código demuestra cómo fusionar dos archivos de ejemplo (<a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-1.xlsx" target="_blank" rel="nofollow noopener noreferrer">file1.xlsx</a> y <a href="https://docs.aspose.com/cells/net/merge-spreadsheets-using-lowcode-api/lowcode-merger-2.xlsx" target="_blank" rel="nofollow noopener noreferrer">file2.xlsx</a>) en un solo archivo utilizando <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetmerger/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMerger</a> y <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodemergeoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeMergeOptions</a>.

```csharp
string[] files = { filePath + "lowcode-merger-1.xlsx", filePath + "lowcode-merger-2.xlsx" };

CustomLoadOptionsMergerProvider provider = new CustomLoadOptionsMergerProvider(files);

LowCodeSaveOptions saveOptions = new LowCodeSaveOptions();
saveOptions.OutputFile = filePath + "merged_output.xlsx";
saveOptions.SaveFormat = SaveFormat.Xlsx;

LowCodeMergeOptions mergeOptions = new LowCodeMergeOptions();
mergeOptions.LoadOptionsProvider = provider;
mergeOptions.SaveOptions = saveOptions;

SpreadsheetMerger.Process(mergeOptions);

private class CustomLoadOptionsMergerProvider : AbstractLowCodeLoadOptionsProvider
{

    public IEnumerator fileIter;
    public CustomLoadOptionsMergerProvider(string[] files)
    {
        fileIter = files.GetEnumerator();
        current = new LowCodeLoadOptions();
    }
    private LowCodeLoadOptions current;

    public override LowCodeLoadOptions Current => current;

    public override bool MoveNext()
    {
        if (fileIter.MoveNext())
        {
            current = new LowCodeLoadOptions();
            current.InputFile = fileIter.Current.ToString();
            return true;
        }

        return false;
    }

    public override void Finish(LowCodeLoadOptions part)
    {
        base.Finish(part);
    }
}
```

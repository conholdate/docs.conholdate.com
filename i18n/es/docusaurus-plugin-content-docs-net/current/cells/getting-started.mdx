## Instalación {#installation}
  
### Instalar Aspose.Cells mediante NuGet {#install-asposecells-through-nuget}
  
NuGet es la forma más sencilla de descargar e instalar Aspose.Cells para .NET.  

1. Abra Microsoft Visual Studio y el administrador de paquetes NuGet.
2. Busque "Aspose.Cells" para encontrar Aspose.Cells para .NET deseado.
3. Haga clic en "Install". Aspose.Cells para .NET se descargará y se referenciará en su proyecto.
   **![Install Aspose Cells through NuGet](/net/cells/images/d1d688d880d901e2-install-through-nuget.png)**

También puede descargarlo desde la página web de NuGet para Aspose.Cells:\
<a href="https://www.nuget.org/packages/Aspose.Cells/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells para .NET paquete NuGet</a>

[Más pasos para más detalles](/net/cells/installation/)

### Instalar Aspose.Cells en Windows {#install-asposecells-on-windows}  

1. Descargue Aspose.Cells.msi desde la siguiente página:\
   <a href="https://downloads.aspose.com/cells/net/" target="_blank" rel="nofollow noopener noreferrer">Descargar Aspose.Cells.msi</a>
2. Haga doble clic en Aspose.Cells.msi y siga las instrucciones para instalarlo:

### Instalar Aspose.Cells en Linux {#install-asposecells-on-linux}
  
En este ejemplo, se utiliza Ubuntu para mostrar cómo comenzar a utilizar Aspose.Cells en Linux.  

1. Cree una aplicación .NET Core denominada **AsposeCellsTest**.  

2. Abra el archivo **AsposeCellsTest.csproj** y agregue las siguientes líneas para las referencias al paquete Aspose.Cells:

   ```plain
     <ItemGroup>
       <PackageReference Include="Aspose.Cells" Version="26.10" />
     </ItemGroup>
   ```

3. Abra el proyecto con VS Code en Ubuntu:
   **![Install Aspose Cells on linux](/net/cells/images/4140c1678cbdc7c3-install-on-linux.png)**

4. Ejecute la prueba con el siguiente código:

   ```csharp
   ﻿// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
   Aspose.Cells.Workbook wb1 = new Aspose.Cells.Workbook();
   wb1.Worksheets.Add("linux");
   wb1.Worksheets["linux"].Cells[0, 0].Value = "Using Aspose Cells on linux with VS Code.";
   wb1.Save("linux.xlsx");
   ```

Tenga en cuenta que Aspose.Cells para .NET Standard puede satisfacer su requisito en Linux.

Aplica a: .NET Standard 2.0, .NET Core 2.1, .NET Core 3.1, .NET 5.0, .NET 6.0 y versiones posteriores.

2. Abra la aplicación con Visual Studio para Mac y, a continuación, instale Aspose.Cells a través de NuGet:
   **![Install Aspose Cells on macOS](/net/cells/images/86edb3765aee79f5-install-on-mac-os.png)**

Aplica a: .NET Standard 2.0, .NET Core 2.1, .NET Core 3.1, .NET 5.0, .NET 6.0 y versiones posteriores.

## Creación de la aplicación «Hola Mundo» {#creating-the-hello-world-application}
  
Los pasos siguientes crean la aplicación «Hola Mundo» utilizando la API de Aspose.Cells:  

1. Si posee una licencia, [aplíquesela](/net/cells/licensing/).\
   Si utiliza la versión de evaluación, omita las líneas de código relacionadas con la licencia.
2. Cree una instancia de la clase <a href="https://reference.aspose.com/cells/net/aspose.cells/workbook" target="_blank" rel="nofollow noopener noreferrer">Workbook</a> para crear un archivo nuevo de Excel o abrir uno existente.
3. Acceda a cualquier celda deseada de una hoja de cálculo en el archivo de Excel.
4. Inserte las palabras **¡Hola Mundo!** en la celda accedida.
5. Genere el archivo de Microsoft Excel modificado.

La implementación de los pasos anteriores se demuestra en los ejemplos siguientes.

### Ejemplo de código: Creación de un nuevo libro {#code-sample-creating-a-new-workbook}
  
El siguiente ejemplo crea un nuevo libro desde cero, inserta **¡Hola Mundo!** en la celda **A1** de la primera hoja de cálculo y lo guarda como archivo de Excel.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

try
{
    // Create a License object
    License license = new License();

    // Set the license of Aspose.Cells to avoid the evaluation limitations
    license.SetLicense(dataDir + "Aspose.Cells.lic");
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}

// Instantiate a Workbook object that represents Excel file.
Workbook wb = new Workbook();

// When you create a new workbook, a default "Sheet1" is added to the workbook.
Worksheet sheet = wb.Worksheets[0];

// Access the "A1" cell in the sheet.
Cell cell = sheet.Cells["A1"];

// Input the "Hello World!" text into the "A1" cell
cell.PutValue("Hello World!");

// Save the Excel file.
wb.Save(dataDir + "MyBook_out.xlsx");
```

### Ejemplo de código: Apertura de un archivo existente  {#code-sample-opening-an-existing-file}
  
El siguiente ejemplo abre un archivo de plantilla de Microsoft Excel existente **Sample.xlsx**, inserta **Hello World!** en la celda **A1** de la primera hoja de cálculo y lo guarda como un archivo de Excel.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-cells/Aspose.Cells-for-.NET
// The path to the documents directory.
string dataDir = "./";

try
{
    // Create a License object
    License license = new License();

    // Set the license of Aspose.Cells to avoid the evaluation limitations
    license.SetLicense("Aspose.Cells.lic");
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}

// Creating a file stream containing the Excel file to be opened
FileStream fstream = new FileStream(dataDir + "Sample.xlsx", FileMode.Open);

// Instantiate a Workbook object that represents the existing Excel file
Workbook workbook = new Workbook(fstream);

// Get the reference of "A1" cell from the cells collection of a worksheet
Cell cell = workbook.Worksheets[0].Cells["A1"];

// Put the "Hello World!" text into the "A1" cell
cell.PutValue("Hello World!");

// Save the Excel file
workbook.Save(dataDir + "HelloWorld_out.xlsx");

// Closing the file stream to free all resources
fstream.Close();
```

## ¿Qué es Microsoft Dynamics CRM? {#what-is-microsoft-dynamics-crm}

Microsoft Dynamics CRM es un paquete de software de gestión de relaciones con los clientes (CRM, por sus siglas en inglés) desarrollado por Microsoft. De forma predeterminada, el producto se centra principalmente en los sectores de Ventas, Marketing y Servicio (servicio de asistencia), pero Microsoft ha posicionado Dynamics CRM como una plataforma XRM y ha estado incentivando a sus socios a utilizar su marco propietario (basado en .NET) para personalizarlo. Forma parte de la familia de aplicaciones empresariales Microsoft Dynamics.

Dynamics CRM es una aplicación cliente-servidor que, al igual que Microsoft SharePoint, es principalmente una aplicación web basada en IIS y que también admite interfaces extensas de servicios web. Los clientes acceden a Dynamics CRM ya sea mediante un navegador o mediante un complemento de cliente completo para Microsoft Outlook.

## Aspose.Cells para .NET {#asposecells-for-net}

Aspose.Cells para .NET proporciona el conjunto más flexible de componentes que permiten a las aplicaciones .NET crear y gestionar hojas de cálculo de Excel sin necesidad de tener instalado Microsoft Excel en el servidor. Aspose.Cells es uno de los componentes líderes para la manipulación de todos los tipos de formatos de Excel.

Aspose.Cells no solo admite la generación de hojas de cálculo y otras características básicas de formato de archivos, sino que también admite numerosas características avanzadas. Estas características avanzadas facilitan mucho más a los desarrolladores manipular el contenido de las hojas de cálculo, el formato de celdas y la protección de archivos. Aspose.Cells también permite importar datos en hojas de cálculo desde distintas fuentes de datos, agregar fórmulas y funciones comunes y complejas de tipo matemático, DateTime, financiero y de texto; además, admite la manipulación de gráficos, imágenes, comentarios, objetos de dibujo, controles, etc.

## Aspose.Cells para CRM {#asposecells-for-crm}

Aspose.Cells para .NET se puede utilizar con Dynamics CRM de varias maneras. Al trabajar con hojas de cálculo, ya sea para generar o procesar hojas de cálculo, debe considerar las API de Aspose que permiten obtener resultados rápidos con un número mínimo de líneas de código.

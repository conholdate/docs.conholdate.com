## Cómo aplicar una licencia en el componente Aspose.Cells {#how-to-apply-a-license-in-asposecells-component}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará la licencia. Debe establecer una licencia antes de utilizar Aspose.Cells si desea evitar sus limitaciones de evaluación. Solo es necesario establecer una licencia una vez por aplicación (o proceso). La licencia puede cargarse desde un archivo, un flujo o un recurso incrustado.

Aspose.Cells intenta encontrar la licencia en las siguientes ubicaciones:  

- Ruta explícita
- La carpeta que contiene Aspose.Cells.dll
- La carpeta que contiene el ensamblado que llamó a Aspose.Cells.dll
- La carpeta que contiene el ensamblado de entrada (su .exe)
- Un recurso incrustado en el ensamblado que llamó a Aspose.Cells.dll

Existen dos métodos comunes para aplicar una licencia: desde un archivo o flujo, o como un recurso incrustado.

### Cómo aplicar una licencia desde disco o flujo {#how-to-apply-a-license-from-disk-or-stream}
  
La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que Aspose.Cells.dll y especificar únicamente el nombre del archivo, sin su ruta.

```csharp
 //Instantiate an instance of license and set the license file through its path

Aspose.Cells.License license = new Aspose.Cells.License();

license.SetLicense("Aspose.Cells.lic");
```

:::info
Cuando llame al método `SetLicense`, el nombre de la licencia debe ser idéntico al nombre del archivo de licencia. Por ejemplo, puede cambiar el nombre del archivo de licencia a **Aspose.Cells.lic.xml**. Luego, en su código, debe utilizar el nombre modificado de la licencia (**Aspose.Cells.lic.xml**) para el método `SetLicense`.
:::

También es posible cargar una licencia desde un flujo.

```csharp
 //Instantiate an instance of license and set the license through a stream

Aspose.Cells.License license = new Aspose.Cells.License();

license.SetLicense(myStream);
```

### Cómo aplicar una licencia por medición  {#how-to-apply-metered-license}
  
Aspose.Cells permite a los desarrolladores aplicar una clave de medición. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen facturarse según el uso de las características de la API pueden utilizar el licenciamiento por medición. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por medición</a>.  

Se ha introducido una nueva clase <a href="https://reference.aspose.com/cells/net/aspose.cells/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> para aplicar una clave de medición. A continuación se muestra un ejemplo de código que demuestra cómo configurar la clave pública y la clave privada de medición.

```csharp
 //Set metered public and private keys

Metered metered = new Metered();

//Access the setMeteredKey method and pass public and private keys as parameters

metered.SetMeteredKey("*************", "*************");

//Instantiate a new Workbook

Workbook workbook = new Workbook();

//Check if the license is set

Console.WriteLine(workbook.IsLicensed);

//Get the Consumption quantity

decimal amountBefore = Metered.GetConsumptionQuantity();

Console.WriteLine(amountBefore);

Workbook workbook2 = new Workbook("e:\\test2\\Book1.xlsx");

workbook2.Save("e:\\test2\\out1.xlsx");

//Since uploading data is already running on another thread, so you might need to wait for some time (optional)

System.Threading.Thread.Sleep(10000);

//Get the Consumption quantity again which should be greater a bit

decimal amountAfter = Metered.GetConsumptionQuantity();

Console.WriteLine(amountAfter);
```

### Cómo usar un recurso incrustado  {#how-to-use-an-embedded-resource}
  
Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama a Aspose.Cells. Para incluir el archivo de licencia como recurso incrustado, realice los siguientes pasos:  

1. En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto seleccionando **Agregar elemento existente** en el menú **Archivo**.
2. Seleccione el archivo en el Explorador de soluciones y establezca **Acción de compilación** en **Recurso incrustado** en la ventana Propiedades.  

Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), no es necesario llamar a los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` del marco de trabajo de Microsoft .NET. Todo lo que se requiere hacer es agregar el archivo de licencia como recurso incrustado al proyecto y pasar el nombre del archivo de licencia al método `SetLicense`. La clase **Aspose.Cells.License** encontrará automáticamente el archivo de licencia en los recursos incrustados. Consulte el ejemplo que se muestra a continuación para comprender este método de establecimiento de licencia (incrustada) en sus aplicaciones.

```csharp
 //Instantiate the License class

Aspose.Cells.License license = new Aspose.Cells.License();

//Pass only the name of the license file embedded in the assembly

license.SetLicense("Aspose.Cells.lic");
```

## Cómo establecer la licencia en los controles Aspose.Cells Grid  {#how-to-set-license-in-asposecells-grid-controls}


En Aspose.Cells Grid Suite, la licencia puede cargarse desde un archivo, un flujo o un recurso incrustado. Aspose.Cells.GridDesktop / Aspose.Cells.GridWeb intenta buscar la licencia en las siguientes ubicaciones:

| 
1. Ruta explícita
2. | La carpeta que contiene el archivo DLL del componente (incluido en Aspose.Cells.GridDesktop o Aspose.Cells.GridWeb) |
| 
3. La carpeta que contiene el ensamblado que llamó al DLL del componente (incluido en Aspose.Cells.GridDesktop o Aspose.Cells.GridWeb)
4. | La carpeta que contiene el ensamblado de entrada (su archivo .exe) |
| 
5. Un recurso incrustado en el ensamblado que llamó al DLL del componente (incluido en Aspose.Cells.GridDesktop o Aspose.Cells.GridWeb) |

:::info
Si está utilizando el control Aspose.Cells.GridDesktop, la clase de licencia será `Aspose.Cells.GridDesktop.License`; sin embargo, si está utilizando el control Aspose.Cells.GridWeb, se utilizará la clase `Aspose.Cells.GridWeb.License` para establecer la licencia.
:::

### Cómo aplicar una licencia desde disco o desde un flujo  {#how-to-apply-a-license-from-disk-or-stream-1}
  
La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo DLL del componente (incluido en Aspose.Cells.GridWeb) y especificar únicamente el nombre del archivo, sin su ruta.

```csharp
//Instantiate an instance of license and set the license file through its path

Aspose.Cells.GridWeb.License license = new Aspose.Cells.GridWeb.License();

license.SetLicense("MyLicense.lic");
```

:::info
Cuando llame al método `SetLicense`, el nombre de la licencia debe coincidir exactamente con el nombre de su archivo de licencia. Por ejemplo, puede cambiar el nombre del archivo de licencia a `"MyLicense.lic.xml"`. Luego, en su código, debe utilizar el nombre de licencia modificado (es decir, `MyLicense.lic.xml`) para el método `SetLicense`.
:::

También es posible cargar una licencia desde un flujo.

```csharp
//Instantiate an instance of license and set the license through a stream

Aspose.Cells.GridWeb.License license = new Aspose.Cells.GridWeb.License();

license.SetLicense(myStream);
```

### Cómo aplicar una licencia como un recurso incrustado  {#how-to-apply-a-license-as-an-embedded-resource}
  
Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama al archivo DLL del componente (incluido en Aspose.Cells.GridDesktop). Para incluir el archivo de licencia como un recurso incrustado, realice los siguientes pasos:  

1. En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto mediante la opción **Agregar elemento existente** del menú **Archivo**.
2. Seleccione el archivo en el Explorador de soluciones y establezca la acción de compilación en **Recurso incrustado** en la ventana Propiedades.
3. Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), no es necesario llamar a los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` del Microsoft .NET Framework. En su lugar, agregue el archivo de licencia como un recurso incrustado en su proyecto y pase el nombre del archivo de licencia al método `SetLicense`. La clase `License` encuentra automáticamente el archivo de licencia en los recursos incrustados.  

Consulte el ejemplo que se muestra a continuación para comprender este método de aplicación de licencia como recurso incrustado en sus aplicaciones.

```csharp
 //Instantiate the License class

Aspose.Cells.GridDesktop.License license = new Aspose.Cells.GridDesktop.License();

//Pass only the name of the license file embedded in the assembly

license.SetLicense("Aspose.Total.lic");
```

## Cómo aplicar una licencia en Aspose.Cells.GridDesktop para una aplicación de WinForm {#how-to-apply-a-license-in-asposecellsgriddesktop-for-a-winform-application}
  
Se recomienda colocar el código de licencia antes de que inicie su aplicación y aplicarlo solo una vez. Por ejemplo, para una aplicación de Windows en C#, coloque el código de licencia en el método `Main`.

```csharp
public class Form1 : System.Windows.Forms.Form

{

private Aspose.Cells.GridDesktop.GridDesktop gridDesktop1;

/// <summary>

/// Required designer variable.

/// </summary>

private System.ComponentModel.Container components = null;

public Form1()

{

//

// Required for Windows Form Designer support

//

InitializeComponent();

//

// TODO: Add any constructor code after InitializeComponent call

//

}

/// The main entry point for the application.

/// </summary>

.

.

.

.

[STAThread]

static void Main()

{

Aspose.Cells.GridDesktop.License lic = new Aspose.Cells.GridDesktop.License();

//Use this line if you are using an explicit path for the license file.

lic.SetLicense(@"C:\MyLicense.lic");

//Or use the line below if you are using the license file as an embedded resource.

//lic.SetLicense("MyLicense.lic");

Application.Run(new Form1());

}

private void Form1_Load(object sender, System.EventArgs e)

{

Aspose.Cells.GridDesktop.Worksheet sheet = this.gridDesktop1.Worksheets.Add("MySheet");

sheet.Cells["A1"].SetCellValue("Hello");

gridDesktop1.ActiveSheetIndex = 1;

}

}
```

## Notas sobre la aplicación de una licencia en Aspose.Cells.GridWeb {#notes-on-applying-a-license-in-asposecellsgridweb}
  
Se recomienda colocar el código de licencia en el archivo Global.asax.cs de su aplicación web (se supone que este archivo de licencia se encuentra en la unidad «d:\»):

```csharp
 protected void Application_Start(Object sender, EventArgs e)

{

    Aspose.Cells.GridWeb.License lic = new Aspose.Cells.GridWeb.License();

    lic.SetLicense(@"d:\Aspose.Cells.GridWeb.lic.xml");

}
```

Cargando una licencia desde un flujo

```csharp
 protected void Application_Start(Object sender, EventArgs e)

{

    Aspose.Cells.GridWeb.License lic = new Aspose.Cells.GridWeb.License();

    lic.SetLicense(myStream);

}
```

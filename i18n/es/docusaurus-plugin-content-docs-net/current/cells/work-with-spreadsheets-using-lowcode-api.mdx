## Introducción {#introduction}

Aspose.Cells para .NET proporciona el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a>, que simplifica las tareas comunes de procesamiento de hojas de cálculo. Esta API está diseñada para desarrolladores que desean realizar operaciones de alto nivel, como conversión a HTML, conversión a imágenes, conversión a JSON, conversión a PDF, conversión de hojas de cálculo, fusión de hojas de cálculo, bloqueo de hojas de cálculo y división de hojas de cálculo, con el mínimo esfuerzo posible.

La API LowCode es ideal para escenarios donde la implementación rápida es más importante que el control detallado. Las APIs LowCode de Aspose.Cells ofrecen una forma declarativa y de alto nivel para realizar tareas comunes de hojas de cálculo (conversión, fusión, división, etc.) sin necesidad de escribir una gran cantidad de código repetitivo. A continuación, analizamos con mayor detalle las capacidades LowCode de Aspose.Cells para .NET.

## Características disponibles en la API LowCode {#available-features-in-lowcode-api}

El espacio de nombres Aspose.Cells.LowCode actualmente admite:

1. Convertidor para conversión entre archivos HTML (HTML o MHT) y otros formatos de archivo de hoja de cálculo.
2. Convertidor para convertir un archivo de plantilla en imágenes.
3. Convertidor para conversión entre estructuras de datos JSON y otros formatos de archivo de hoja de cálculo.
4. Convertidor para convertir un archivo de plantilla en PDF.
5. Convertidor para conversión entre distintos formatos de archivo de hoja de cálculo, como XLS, XLSX, XLSB, XLSM, etc.
6. Convertidor para conversión entre formatos basados en texto (CSV, TSV, DIF, etc.) y otros formatos de archivo de hoja de cálculo.
7. Bloquear archivo de hoja de cálculo.
8. Fusionar varios archivos de plantilla en uno solo.
9. Dividir archivo de hoja de cálculo en varios archivos.

## Introducción {#introduction}

Aspose.Cells para .NET proporciona el espacio de nombres <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells.LowCode</a>, que simplifica las tareas comunes de procesamiento de hojas de cálculo. Esta API está diseñada para desarrolladores que desean realizar operaciones de alto nivel, como conversión a HTML, conversión a imagen, conversión a JSON, conversión a PDF, conversión de hojas de cálculo, fusión de hojas de cálculo, bloqueo de hojas de cálculo y división de hojas de cálculo, con el mínimo esfuerzo posible.

La API LowCode es ideal para escenarios donde la implementación rápida es más importante que el control detallado. Las APIs LowCode de Aspose.Cells ofrecen una forma declarativa y de alto nivel para realizar tareas comunes de hojas de cálculo (conversión, fusión, división, etc.) sin tener que escribir una gran cantidad de código repetitivo. Echemos un vistazo más de cerca a las capacidades LowCode de Aspose.Cells para .NET.

## Dividir una hoja de cálculo: SpreadsheetSplitter {#split-a-spreadsheet--spreadsheetsplitter}

Si desea dividir un único libro en varios libros, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetsplitter/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSplitter</a> para realizar la tarea de división sin tener que escribir una gran cantidad de código repetitivo. El siguiente código demuestra cómo dividir un <a href="https://docs.aspose.com/cells/net/split-spreadsheets-using-lowcode-api/lowcode-splitter.xlsx" target="_blank" rel="nofollow noopener noreferrer">archivo de ejemplo</a> en varias hojas de cálculo.

```csharp
// Define result output pattern
string resultPattern = "SplitResult.xlsx";
// Process template directly using the static method
SpreadsheetSplitter.Process("lowcode-splitter.xlsx", resultPattern);
```

## Dividir una hoja de cálculo – SpreadsheetSplitter y LowCodeSplitOptions {#split-a-spreadsheet--spreadsheetsplitter--lowcodesplitoptions}

Si desea dividir un único libro en varios libros, puede utilizar la clase <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetsplitter/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSplitter</a> para realizar la tarea de división sin escribir un código repetitivo extenso. <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodesplitoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeSplitOptions</a> le permite ajustar finamente el comportamiento de la división. El siguiente código demuestra cómo dividir un archivo <a href="https://docs.aspose.com/cells/net/split-spreadsheets-using-lowcode-api/lowcode-splitter.xlsx" target="_blank" rel="nofollow noopener noreferrer">de ejemplo</a> en varias hojas de cálculo utilizando <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/spreadsheetsplitter/" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSplitter</a> y <a href="https://reference.aspose.com/cells/net/aspose.cells.lowcode/lowcodesplitoptions/" target="_blank" rel="nofollow noopener noreferrer">LowCodeSplitOptions</a>.

```csharp
// Initialize split options
LowCodeSplitOptions splitOptions = new LowCodeSplitOptions
{
    LoadOptions = new LowCodeLoadOptions { InputFile = "lowcode-splitter.xlsx" },
    SaveOptionsProvider = new CustomLowCodeSaveOptionsProvider()
};
// Execute spreadsheet splitting using static method
SpreadsheetSplitter.Process(splitOptions);


// Concrete implementation of AbstractLowCodeSaveOptionsProvider
public class CustomLowCodeSaveOptionsProvider : AbstractLowCodeSaveOptionsProvider
{
    public override void Finish(LowCodeSaveOptions part)
    {
        base.Finish(part);
    }
    // Implement the required abstract method
    public override LowCodeSaveOptions GetSaveOptions(SplitPartInfo partInfo)
    {
        if (partInfo == null)
        {
            throw new ArgumentNullException(nameof(partInfo));
        }

        LowCodeSaveOptions result = new LowCodeSaveOptions();
        result.SaveFormat = SaveFormat.Xlsx;
        result.OutputFile = partInfo.SheetName + "_split.xlsx";
        Console.WriteLine(result.OutputFile);
        return result;
    }
}
```

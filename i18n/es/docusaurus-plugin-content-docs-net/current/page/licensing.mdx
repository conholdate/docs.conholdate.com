## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Queremos que nuestros clientes prueben exhaustivamente nuestros componentes antes de comprarlos, por lo que la versión de evaluación le permite utilizarlos tal como lo haría normalmente. Sin embargo, el producto sin licencia:  

- Permite convertir archivos PostScript cuyo tamaño no supere los 500 KB, y en tales casos el documento PDF resultante contendrá una marca de evaluación. 
- No permitirá manipular más de 4 elementos XPS, y en tales casos el documento o la imagen resultante también contendrá una marca de evaluación, es decir, "**Solo para evaluación. Creado con Aspose.Page. Copyright 2002-2026 Aspose Pty Ltd**" en la parte superior.

## Licencia clásica {#classic-license}
  
La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia consiste en colocar el archivo de licencia en la misma carpeta que el archivo Aspose.Page.dll y especificar el nombre del archivo, sin ruta de acceso, como se muestra en el siguiente ejemplo.

### Carga de una licencia desde un archivo {#loading-a-license-from-file}
  
La forma más sencilla de aplicar una licencia consiste en colocar el archivo de licencia en la misma carpeta que el archivo Aspose.Page.dll y especificar únicamente el nombre del archivo, sin ruta de acceso.

:::info
Si está utilizando algún otro componente de Aspose para .NET junto con Aspose.Page para .NET, especifique el espacio de nombres para la licencia como `Aspose.Page.License`.
:::

```java
// Apply a License from File

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.Page.Net.lic");

Aspose.Page.License license = new License();
license.SetLicense(licenseFilePath);
```

<a href="https://gist.github.com/aspose-com-gists/ffbf7fd2313cf7abd191d8941ec012c2#file-example-setlicensefromfile-cs" target="_blank" rel="nofollow noopener noreferrer">Ejemplo-SetLicenseFromFile.cs</a> alojado con ❤ por <a href="https://github.com/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>

Cuando llame al método `SetLicense`, el nombre de licencia que pase debe corresponder al nombre de su archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a `"Aspose.Page.lic.xml"`, pase ese nombre de archivo al método `license.SetLicense(…)`.

### Cargar una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```java
// Apply a License from Stream Object

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.Page.Net.lic");
FileStream licenseStream = new FileStream(licenseFilePath, FileMode.Open);

Aspose.Page.License license = new License();
license.SetLicense(licenseStream);
licenseStream.Close();
```

### Uso como recurso incrustado {#using-as-embedded-resource}
  
Para aplicar una licencia, puede cargarla desde un archivo o un flujo. Otra forma práctica de empaquetar la licencia junto con su aplicación es incluirla como un recurso incrustado en uno de los ensamblados que llama a Aspose.Page para .NET.

Para incluir el archivo como recurso incrustado:  

1. En Visual Studio .NET, incluya el archivo .lic en el proyecto haciendo clic en el menú **Archivo** y seleccionando **Agregar elemento existente**.
2.  Seleccione el archivo en el Explorador de soluciones.
3.  En la ventana Propiedades, establezca la **Acción de compilación** en **Recurso incrustado**.

Un punto que requiere consideración: tenga en cuenta que los recursos incrustados se incluyen en el ensamblado tal como se agregan; es decir, si agrega un archivo de texto como recurso incrustado en la aplicación y abre el archivo EXE resultante en el Bloc de notas, verá exactamente el contenido del archivo de texto. Por lo tanto, al utilizar un archivo de licencia como recurso incrustado, cualquier persona puede abrir el archivo .exe con algún editor de texto sencillo y ver o extraer el contenido de la licencia incrustada.

Por lo tanto, para añadir una capa adicional de seguridad al incrustar la licencia con la aplicación, puede comprimir o cifrar la licencia y, posteriormente, incrustarla en el ensamblado. Una utilidad gratuita, DotNetZip ( <a href="http://dotnetzip.codeplex.com/" target="_blank" rel="nofollow noopener noreferrer">http://dotnetzip.codeplex.com/</a>), puede ayudarle a cumplir con este requisito. Supongamos que tenemos el archivo de licencia Aspose.Total.NET.lic; por lo tanto, creemos Aspose.Total.NET.lic.zip con la contraseña *test* e incrustemos este archivo zip en la solución. El siguiente fragmento de código puede utilizarse para inicializar la licencia:

```java
// Apply a License that is embedded in assembly as a resource

// Initialize license object
Aspose.Page.License license = new License();

// Set license
license.SetLicense("Aspose.Page.Net.lic");

// Set the value to indicate that license will be embedded in the application
license.Embedded = true;
```

## Licencia basada en uso (Metered License) {#metered-license}
  
Aspose.Page permite a los desarrolladores aplicar una clave basada en uso. Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento basado en uso. Para obtener más detalles, consulte la <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">sección de preguntas frecuentes sobre el licenciamiento basado en uso</a>.

Se ha introducido una nueva clase, `Metered`, para aplicar la clave basada en uso. A continuación se muestra un ejemplo de código que demuestra cómo establecer las claves pública y privada basadas en uso.

```java
// Apply a License from Stream Object

// set metered public and private keys
Aspose.Page.Metered metered = new Aspose.Page.Metered();
// Access the setMeteredKey property and pass public and private keys as parameters
metered.SetMeteredKey(
    "<type public key here>",
    "<type private key here>");
```

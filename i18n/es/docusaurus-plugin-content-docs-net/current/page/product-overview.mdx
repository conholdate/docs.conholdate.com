**Bienvenido a Aspose.Page para .NET**

Aspose.Page para .NET le permite trabajar con documentos XPS y EPS/PS en cualquier aplicación .NET. Mediante la API, puede crear, editar y guardar documentos XPS existentes y nuevos. Además, puede convertir documentos XPS y EPS a PDF e imágenes. Aspose.Page para .NET se implementa utilizando C# administrado y puede utilizarse con cualquier lenguaje .NET, como C#, VB.NET y J#, entre otros. Puede integrarse con cualquier tipo de aplicación, ya sea una aplicación web ASP.NET o una aplicación de consola (también se admiten sistemas operativos no Windows).
:::

## Descripción del producto {#product-description}
  
Aspose.Page es una API diseñada para trabajar con documentos XPS y EPS/PS. La API permite convertir documentos XPS y EPS/PS a formatos de archivo PDF e imagen. Además, la API permite abrir documentos XPS existentes, crear nuevos documentos y guardarlos ya sea en un archivo o en un flujo (stream). En cuanto se crea una instancia del documento (clase XpsDocument) (se abre un documento existente o se crea uno nuevo), puede agregar (al final de la lista de páginas) o insertar (en una posición específica de la lista de páginas) páginas nuevas o previamente creadas, eliminar páginas y seleccionar una página por número como “activa”. Solo la página seleccionada como “activa” puede editarse. Una página puede crearse sin vincularla a un documento, y puede vincularla en cualquier momento que desee. Para una instancia de documento recién creada, se selecciona la primera página (si se crea un documento nuevo, su primera página también se crea automáticamente).

Aspose.Page para .NET es una API administrada en C# que puede utilizarse con cualquier lenguaje .NET, como C#, VB.NET y J#, entre otros. Dado que se trata de una API basada en .NET, puede utilizarla en cualquier aplicación .NET, por ejemplo, aplicaciones web ASP.NET, aplicaciones WinForms o aplicaciones de consola para Windows, Linux, macOS y cualquier otro sistema operativo para el cual exista un SDK de .NET.

Al igual que otros productos ofrecidos por Aspose, Aspose.Page para .NET incluye demos completas y ejemplos funcionales escritos en C#. Para ayudar a los desarrolladores y permitirles comprender rápidamente la API, todos los ejemplos se alojan en <a href="https://github.com/aspose-page/Aspose.Page-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a> en un repositorio público.

Aspose.Page para .NET es una API robusta y ligera que convierte archivos XPS y EPS/PS a otros formatos de archivo de forma rápida y eficiente.

Aspose.Page para .NET es seguro para entornos multiproceso, siempre que solo un subproceso (thread) trabaje en un documento a la vez. Es un escenario típico tener un subproceso trabajando en un solo documento. Diferentes subprocesos pueden trabajar de forma segura en distintos documentos simultáneamente.

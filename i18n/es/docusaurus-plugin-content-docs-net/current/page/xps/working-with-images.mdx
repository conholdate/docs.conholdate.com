### Agregar imagen dentro de documentos XPS {#add-image-inside-xps-documents}
  
Aspose.Page para .NET ofrece la clase <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpspath/" target="_blank" rel="nofollow noopener noreferrer">XpsPath</a>, con la cual puede agregar una imagen en un documento XPS. Debe crear <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpsmatrix/" target="_blank" rel="nofollow noopener noreferrer">XpsMatrix</a> y <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpsimage/" target="_blank" rel="nofollow noopener noreferrer">XpsImageBrush</a>, y guardar <a href="https://reference.aspose.com/page/net/aspose.page.xps/xpsdocument/" target="_blank" rel="nofollow noopener noreferrer">XpsDocument</a>. El siguiente fragmento de código muestra la funcionalidad completa para agregar una imagen en un documento XPS:

```java
// Add image to XPS document.

// Create new XPS Document
XpsDocument doc = new XpsDocument();

string outputFileName = "AddImage_outXPS.xps";

// Add Image
XpsPath path = doc.AddPath(doc.CreatePathGeometry("M 30,20 l 258.24,0 0,56.64 -258.24,0 Z"));
//Creating a matrix is optional, it can be used for proper positioning
path.RenderTransform = doc.CreateMatrix(0.7f, 0f, 0f, 0.7f, 0f, 20f);
//Create Image Brush
path.Fill = doc.CreateImageBrush(DataDir + "QL_logo_color.tif", new RectangleF(0f, 0f, 258.24f, 56.64f), new RectangleF(50f, 20f, 193.68f, 42.48f));
// Save resultant XPS document
doc.Save(OutputDir + outputFileName);
```

### Agregar imagen mosaico {#add-tiled-image}
  
La solución ofrece la clase <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpspath/" target="_blank" rel="nofollow noopener noreferrer">XpsPath</a>, con la cual puede agregar imágenes en documentos XPS. Para ello, primero debe crear <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpsmatrix/" target="_blank" rel="nofollow noopener noreferrer">XpsMatrix</a> y un <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpsimage/" target="_blank" rel="nofollow noopener noreferrer">XpsImageBrush</a>, luego especificar el modo <a href="https://reference.aspose.com/page/net/aspose.page.xps.xpsmodel/xpstilemode/" target="_blank" rel="nofollow noopener noreferrer">XpsTileMode.Tile</a> y guardar <a href="https://reference.aspose.com/page/net/aspose.page.xps/xpsdocument/" target="_blank" rel="nofollow noopener noreferrer">XpsDocument</a>.

El siguiente fragmento de código muestra la funcionalidad completa para agregar una imagen mosaico en un documento XPS:

```java
// Paint rectangle with tiled image (texture pattern) in XPS document.

// Create new XPS Document
XpsDocument doc = new XpsDocument();

string outputFileName = "AddTextureTilingPattern_outXPS.xps";

// Tile image
// ImageBrush filled rectangle in the right top bellow
XpsPath path = doc.AddPath(doc.CreatePathGeometry("M 10,160 L 228,160 228,305 10,305"));
path.Fill = doc.CreateImageBrush(DataDir + "R08LN_NN.jpg", new RectangleF(0f, 0f, 128f, 96f), new RectangleF(0f, 0f, 64f, 48f));
((XpsImageBrush)path.Fill).TileMode = XpsTileMode.Tile;
path.Fill.Opacity = 0.5f;
// Save resultant XPS document
doc.Save(OutputDir + outputFileName);
```

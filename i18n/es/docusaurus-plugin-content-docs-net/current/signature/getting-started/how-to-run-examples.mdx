Este artículo describe cómo ejecutar ejemplos de código de la API de firma digital de .NET.

:::warning
Antes de ejecutar un ejemplo, asegúrese de que GroupDocs.Signature se haya instalado correctamente.
:::


Ofrecemos múltiples soluciones para ejecutar los ejemplos de GroupDocs.Signature: puedes construir tu propio proyecto desde cero o utilizar directamente nuestros ejemplos de backend o frontend.

Por favor, elige una opción de la siguiente lista:

## Construir proyecto desde cero {#build-project-from-scratch}

* Abre Visual Studio y ve a **Archivo** -> **Nuevo** -> **Proyecto**.
* Selecciona el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
* Instala **GroupDocs.Signature for .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/signature/getting-started/installation/).
* Escribe tu primera aplicación con **GroupDocs.Signature for .NET**, como se muestra a continuación

    ```csharp
    // The path to the documents directory.
    string filePath = @"C:\sample.docx"; // NOTE: Put here actual path for your document
    string fileName = Path.GetFileName(filePath);
    string outputFilePath = Path.Combine(@"C:\output", fileName);

    // Sign document with text signature.
    using (Signature signature = new Signature(filePath))
    {
        TextSignOptions textSignOptions = new TextSignOptions("John Smith");
        signature.Sign(outputFilePath, textSignOptions);
    }
    ```

* Compila y ejecuta tu proyecto.
* El documento firmado aparecerá en el directorio "*C:\\output\\"*.

## Ejecutar ejemplos del backend {#run-back-end-examples}

El paquete completo de ejemplos de **GroupDocs.Signature** está alojado en <a href="https://github.com/groupdocs-signature/GroupDocs.Signature-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puedes descargar el archivo ZIP desde <a href="https://github.com/groupdocs-signature/GroupDocs.Signature-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando tu cliente de Git favorito.  
Si descargas el archivo ZIP, extrae las carpetas en tu disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![HowToRun](/net/signature/images/how-to-run-examples.png)

En los archivos y carpetas extraídos, puede encontrar el archivo de solución de C#. El proyecto se creó en **Microsoft Visual Studio 2019**. La carpeta **Resources** contiene todos los archivos de documentos e imágenes de ejemplo utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias faltantes de **GroupDocs.Signature**, consulte [Entorno de desarrollo, instalación y configuración](/net/signature/getting-started/installation/). Todas las funciones se llaman desde **RunExamples.cs**.
Descomenta la función que deseas ejecutar y comenta el resto.

![HowToRun](/net/signature/images/how-to-run-examples_1.png)

Puede ejecutar <a href="https://github.com/groupdocs-signature/GroupDocs.Signature-for-.NET-MVC" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Signature for .NET MVC Example</a> siguiendo estos pasos:

## Ejecutar desde Docker {#run-from-docker}

Utilice la imagen <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> para probar fácilmente las funcionalidades de GroupDocs.Signature para .NET. A continuación se muestran los comandos para ejecutar GroupDocs.Signature para .NET desde la imagen de Docker.

```csharp
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples -v `pwd`/Licenses:/home/groupdocs/app/Licenses groupdocs/signature
## Open http://localhost:8080/signature in your favorite browser.
```

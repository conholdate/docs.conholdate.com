## Firma electrónica {#electronic-signature}

**Firma electrónica** es un concepto abstracto que denota datos en formato electrónico asociados a un documento determinado y que expresan el consentimiento del firmante con la información contenida en dicho documento.
GroupDocs.Signature proporciona diversas implementaciones de firmas electrónicas, como se indica a continuación:

* Firmas de texto nativas como sellos de texto, etiquetas de texto, anotaciones, adhesivos y marcas de agua, con una amplia gama de opciones para efectos visuales, opacidad, colores, fuentes, etc.;
* Firmas de texto como imágenes, con una amplia variedad de opciones adicionales para especificar cómo se verá el texto, colores y efectos de imagen adicionales;
* Firmas de imagen, con opciones para especificar efectos de imagen adicionales, rotación, etc.;
* Firmas digitales basadas en archivos de certificados digitales y capacidad para admitir firmas digitales según el tipo de documento (PDF, documentos de Microsoft Word y hojas de cálculo de Microsoft Excel);
* Firmas de código de barras/códigos QR, con una gran variedad de opciones;
* Firmas de imagen que simulan sellos generados, basadas en líneas predefinidas con texto personalizado, colores, ancho, etc.;
* Firmas de metadatos para almacenar firmas ocultas dentro del documento;
* Firmas de campos de formulario.

Firmar documentos en .NET mediante nuestra API de firma electrónica (eSign) es sencillo, fiable y seguro. Las firmas de documentos pueden crearse y agregarse al documento mediante una colección de distintas opciones que especifican todas las características visuales posibles: ajustes de color, alineación, fuente, márgenes, relleno y distintos estilos. Según los requisitos de la aplicación, puede firmar documentos con uno o varios tipos de firma simultáneamente.

## Búsqueda de firmas {#search-for-signatures}

Obtenga la lista de firmas aplicadas al documento:

* Información sobre firmas de texto en todos los formatos admitidos;
* Información sobre firmas de imagen;
* Información sobre firmas digitales en PDF, documentos de Microsoft Word y hojas de cálculo de Microsoft Excel;
* Información sobre firmas de código de barras/códigos QR en todos los formatos admitidos;
* Información sobre firmas de metadatos en todos los formatos admitidos;
* Información sobre firmas de campos de formulario en todos los formatos admitidos.

## Verificación de firmas {#verify-signatures}

Determine si el documento contiene firmas que cumplan los criterios especificados.
Los tipos de firma admitidos son:

* Firmas de texto;
* Firmas digitales;
* Firmas de código de barras/códigos QR;
* Firmas de metadatos;
* Firmas de campos de formulario.

## Extracción de información del documento {#document-information-extraction}

GroupDocs.Signature permite obtener información básica sobre el documento de origen: tipo de archivo, tamaño, número de páginas, altura y ancho de página, etc.  
Esto puede resultar muy útil para generar una vista previa del documento y colocar con precisión la firma dentro del documento.

## Vista previa de las páginas del documento {#preview-document-pages}

La función de vista previa del documento permite generar representaciones en imagen de las páginas del documento. Esto puede ser útil para comprender mejor el contenido y la estructura del documento,  
establecer la posición adecuada de la firma dentro del documento, aplicar un estilo de firma apropiado, etc. La vista previa puede generarse para todas las páginas del documento (de forma predeterminada) o para números de página o rango de páginas específicos.

Los formatos de imagen admitidos para la vista previa del documento son:

* PNG;
* JPG;
* BMP.

Los códigos de barras representan información textual como una imagen muy pequeña que puede escanearse automáticamente. Este enfoque abre nuevas posibilidades para el procesamiento informático de documentos, como su clasificación o el seguimiento a través de un flujo de trabajo empresarial. En este artículo, discutiremos formas útiles de firmar documentos electrónicos con datos cifrados en códigos de barras o códigos QR utilizando C# en aplicaciones .NET.

### Firmar un documento con un código de barras Codabar en C\# {#signing-a-document-with-a-codabar-in-c}

Para generar un código de barras y firmar un documento específico con él:

* Instanciar la clase `Signature`, proporcionando la ruta al documento de origen o un flujo de documentos.
* Crear la instancia de `BarcodeSignOptions` y configurar todos los campos requeridos.
* Invocar el método `Sign` para procesar el documento, proporcionando la ruta del archivo de salida y las opciones de firma.

```cs
            // instantiating the signature object
            using (Signature signature = new Signature(@"source.pdf"))
            {
                // setup barcode signature options
                BarcodeSignOptions signOptions = new BarcodeSignOptions()
                {
                    HorizontalAlignment = HorizontalAlignment.Right,
                    Top = 150,
                    EncodeType = BarcodeTypes.Codabar,
                    Text = "Approved_19/06/2022"
                };
                // sign document
                signature.Sign(@"signed_codabar.pdf", signOptions);
            }
```

## Generación de códigos de barras e imágenes en C\# {#barcode-and-image-generation-in-c}

Otra forma de mejorar los documentos es generar primero el código de barras y luego agregarlo a los documentos mediante herramientas de terceros. En este caso, es posible generar el código como una imagen.

* Crear una instancia de la clase `BarcodeSignOptions` y configurar todos los campos requeridos.
* Instanciar el objeto `PreviewSignatureOptions`, proporcionando los métodos para su creación y liberación.
* Invocar el método `GenerateSignaturePreview` para obtener la imagen del código de barras como un flujo (stream).
* Utilizar el flujo resultante del código de barras de cualquier manera posible.

```cs
            MemoryStream result = new MemoryStream();
            // setup barcode signature options
            BarcodeSignOptions signOptions = new BarcodeSignOptions()
            {
                EncodeType = BarcodeTypes.Code93,
                Text = "Case 148.01"
            };

            //Instantiate preview options
            var previewOptions = new PreviewSignatureOptions(
                signOptions,
                delegate (PreviewSignatureOptions options) { return result; },
                delegate (PreviewSignatureOptions options, Stream signatureStream) { }
                );

            //Generate image to stream
            GroupDocs.Signature.Signature.GenerateSignaturePreview(previewOptions);

```

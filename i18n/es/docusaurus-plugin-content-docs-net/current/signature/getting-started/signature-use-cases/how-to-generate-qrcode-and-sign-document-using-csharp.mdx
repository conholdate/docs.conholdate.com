El código QR generado puede descargarse y utilizarse para incluirlo en contratos comerciales y documentos oficiales. Cualquier código QR contiene información textual única que confirma la identidad del firmante o autoriza el documento comercial. La verificación del código QR puede realizarse automáticamente al leer los datos incrustados en su interior. Estas firmas pueden escanearse automáticamente. El código QR permite almacenar más de 2 kilobytes de datos.

## Firmar un documento con un código QR de evento en C\# {#signing-a-document-with-an-event-qr-code-in-c}

A veces es necesario informar a los compañeros de trabajo sobre eventos empresariales. En tales casos, un código QR de evento puede proporcionar toda la información requerida de una manera muy eficaz. Este tema describe cómo firmar un documento PDF con el código QR de evento generado.

* Instanciar la clase `Signature`, proporcionando la ruta al documento de origen o al flujo de documentos.
* Establecer los datos del evento en la instancia del objeto `Event`.
* Crear el objeto `QrCodeSignOptions` y configurar todos los campos requeridos.
* Invocar el método `Sign` para procesar el documento, proporcionando la ruta del archivo de salida y las opciones de firma.

```cs
            // instantiating the signature object
            using (Signature signature = new Signature(@"source.pdf"))
            {
                //provide event data
                Event eventQr = new Event()
                {
                    Title = "Meeting",
                    Description = "Productivity issues",
                    Location = "room 408",
                    StartDate = new DateTime(2022, 06, 19, 15, 30, 0),
                    EndDate = new DateTime(2022, 06, 19, 17, 0, 0)
                };

                // setup qrcode signature options
                QrCodeSignOptions signOptions = new QrCodeSignOptions()
                {
                    HorizontalAlignment = HorizontalAlignment.Right,
                    VerticalAlignment = VerticalAlignment.Bottom,
                    EncodeType = QrCodeTypes.QR,
                    Text = "",
                    Data = eventQr
                };

                // sign document
                signature.Sign(@"signed_event.pdf", signOptions);
            }
```

## Generación de imágenes de código QR en C\# {#qr-code-image-generation-in-c}

Otra forma de mejorar los documentos es generar primero el código QR y luego agregarlo a los documentos mediante herramientas de terceros. En este caso, es posible generar el código como una imagen.

* Crear la instancia de `QrCodeSignOptions` y configurar todos los campos requeridos.
* Instanciar el objeto `PreviewSignatureOptions`, proporcionando los métodos para su creación y liberación.
* Invocar el método `GenerateSignaturePreview` para obtener la imagen del código QR como un flujo (stream).
* Utilizar el flujo resultante del código QR de cualquier manera posible.

```cs
            MemoryStream result = new MemoryStream();
            // setup QR Code signature options
            QrCodeSignOptions signOptions = new QrCodeSignOptions()
            {
                EncodeType = QRCodeTypes.Code93,
                Text = "Case 148.01"
            };

            //Instantiate preview options
            var previewOptions = new PreviewSignatureOptions(
                signOptions,
                delegate (PreviewSignatureOptions options) { return result; },
                delegate (PreviewSignatureOptions options, Stream signatureStream) { }
                );

            //Generate image to stream
            GroupDocs.Signature.Signature.GenerateSignaturePreview(previewOptions);

```

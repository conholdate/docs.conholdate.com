:::info
GroupDocs.Signature para .NET está incluido en Conholdate.Total for .NET.
:::


:::info
Puede utilizar GroupDocs.Signature sin licencia. El uso y las funcionalidades son prácticamente iguales a los de la versión con licencia, pero enfrentará algunas limitaciones al utilizar la API sin licencia.
:::


## Limitaciones de la versión de evaluación {#evaluation-limitations}

Puede descargar fácilmente GroupDocs.Signature para evaluación. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. Al utilizar la API sin licencia, se enfrentará a las siguientes limitaciones:

* Solo se procesan las primeras 2 páginas.
* Se colocan marcas de agua de prueba en la parte superior de cada página del documento.

## Licencias {#licensing}

El archivo de licencia contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de caducidad de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará la licencia. Debe establecer una licencia antes de utilizar la API de GroupDocs.Signature si desea evitar sus limitaciones de evaluación.
La licencia puede cargarse desde un archivo o desde un objeto de flujo (stream). La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Signature.dll y especificar el nombre del archivo (sin ruta), como se muestra en los ejemplos siguientes.

### Establecer licencia desde un archivo {#setting-license-from-file}

El siguiente código explica cómo establecer la licencia del producto.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-Signature/GroupDocs.Signature-for-.NET
// Setup license.
License license = new License();
license.SetLicense(licensePath);
```

#### Establecer licencia desde un flujo {#setting-license-from-stream}

El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-Signature/GroupDocs.Signature-for-.NET
using (FileStream fileStream = File.OpenRead("GroupDocs.Signature.lic"))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```


:::info
Llamar a `License.SetLicense` varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesamiento. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, invoque `License.SetLicense` en su código de inicio, antes de utilizar las clases de GroupDocs.Signature.
Al desarrollar una aplicación ASP.NET, puede invocar `License.SetLicense` desde el archivo `Global.asax.cs` (`Global.asax.vb`) dentro del método protegido `Application_Start`. Este método se ejecuta una única vez al iniciar la aplicación.  
No invoque `License.SetLicense` dentro de los métodos `Page_Load`, ya que esto provocaría que la licencia se cargara cada vez que se cargue una página web.
:::


#### Configuración de licencia por uso {#setting-metered-license}


:::info
También puedes configurar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> licencia como alternativa al archivo de licencia. Es un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Es útil para los clientes que desean facturarse según el uso de las características de la API. Para más detalles, consulte <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias por medición</a> sección.
:::

A continuación se presentan los pasos sencillos para utilizar la clase `Metered`.

1. Cree una instancia de la clase `Metered`.
2. Pase las claves pública y privada al método `SetMeteredKey`.
3. Realice el procesamiento (ejecute la tarea).
4. Llame al método `GetConsumptionQuantity` de la clase `Metered`.
5. Este método devolverá la cantidad/cantidad de solicitudes de API que ha consumido hasta el momento.
6. Llame al método `GetConsumptionCredit` de la clase `Metered`.
7. Este método devolverá el crédito que ha consumido hasta el momento.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase `Metered`.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-Signature/GroupDocs.Signature-for-.NET
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Signature.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Signature.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

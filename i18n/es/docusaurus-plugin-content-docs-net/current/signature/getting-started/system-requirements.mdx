## Información general {#overview}

GroupDocs.Signature para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/signature/getting-started/installation/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Signature para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado el framework .NET o Mono, incluidos, entre otros:

### Windows {#windows}

* Microsoft Windows Server 2003 (x64, x86)
* Microsoft Windows Server 2008 (x64, x86)
* Microsoft Windows Server 2012 (x64, x86)
* Microsoft Windows Server 2012 R2 (x64, x86)
* Microsoft Windows Server 2016 (x64, x86)
* Microsoft Windows Server 2019 (x64, x86)
* Microsoft Windows Vista (x64, x86)
* Microsoft Windows XP (x64, x86)
* Microsoft Windows 7 (x64, x86)
* Microsoft Windows 8, 8.1 (x64, x86)
* Microsoft Windows 10 (x64, x86)
* Microsoft Azure

### Linux {#linux}

* Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac {#mac}

* Mac OS X

GroupDocs.Signature para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los entornos explícitamente compatibles son los siguientes:

* Microsoft Visual Studio 2010

* Microsoft Visual Studio 2012
* Microsoft Visual Studio 2013
* Microsoft Visual Studio 2015
* Microsoft Visual Studio 2017
* Microsoft Visual Studio 2019
* Xamarin.Android
* Xamarin.IOS

* MonoDevelop 2.4 y posteriores

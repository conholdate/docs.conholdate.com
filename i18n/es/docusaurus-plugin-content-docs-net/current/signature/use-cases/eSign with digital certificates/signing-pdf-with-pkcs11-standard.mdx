Este artículo muestra cómo firmar documentos con **tokens de hardware PKCS#11** (HSM, tarjetas inteligentes y tokens USB) mediante **GroupDocs.Signature para .NET**.\
El proyecto de ejemplo integra la biblioteca <a href="https://github.com/Pkcs11Interop/Pkcs11Interop" target="_blank" rel="nofollow noopener noreferrer">Pkcs11Interop</a>, la cual proporciona una interfaz de .NET para dispositivos PKCS#11.

Los dispositivos PKCS#11 pueden incluir **módulos de seguridad de hardware (HSM)**, **tarjetas inteligentes** y **llaveros USB (dongles)**.  
Los llaveros USB se utilizan con frecuencia en entornos corporativos como una forma portátil y segura de almacenar claves privadas.  
Con GroupDocs.Signature para .NET, puede utilizar un dongle de la misma manera que otros tokens PKCS#11 para aplicar firmas digitales a sus documentos.


> 💡 Utilice este enfoque cuando necesite firmar documentos de forma segura con una clave privada almacenada en hardware, en lugar de en un archivo local.

## Requisitos previos {#prerequisites}

Antes de comenzar, asegúrese de tener:

-   **GroupDocs.Signature para .NET** instalado. <a href="https://releases.groupdocs.com/signature/net/" target="_blank" rel="nofollow noopener noreferrer">Obtenga una prueba gratuita</a>.
-   Un dispositivo compatible con PKCS#11 (HSM, tarjeta inteligente o token).
-   <a href="https://github.com/Pkcs11Interop/Pkcs11Interop" target="_blank" rel="nofollow noopener noreferrer">Pkcs11Interop</a>.
-   .NET 6.0 o posterior (el ejemplo también es compatible con .NET Framework 4.6.2).

### Configuración de los ajustes de PKCS#11 {#configure-pkcs-11-settings}

`Settings.cs` define la ruta de la biblioteca PKCS#11, el PIN del token y el asunto del certificado:

``` csharp
{
    public static string Pkcs11LibraryPath = "<PKCS11_LIBRARY_PATH>";
    public static string TokenPin = "<TOKEN_PIN>";
    public static string CertificateSubject = "<CERT_SUBJECT>";
}
```

### Firmar un documento {#sign-a-document}

`Program.cs` muestra cómo firmar utilizando GroupDocs.Signature.

Este ejemplo demuestra dos flujos:\
1. **Directamente desde un dispositivo PKCS#11**\
2. **Desde el almacén de certificados de Windows**

``` csharp
using GroupDocs.Signature;
using GroupDocs.Signature.Options;
using System;

class Program
{
    static void Main()
    {
        string filePath = "sample.pdf";
        string outputPath = "signed.pdf";

        // (1) Sign using PKCS#11 device
        var pkcs11Signer = new Pkcs11DigitalSigner();
        var certificate = pkcs11Signer.GetCertificateFromPkcs11();

        using (var signature = new Signature(filePath))
        {
            var options = new DigitalSignOptions(certificate)
            {
                Comments = "Signed with PKCS#11 device",
                SignTime = DateTime.Now
            };

            signature.Sign(outputPath, options);
        }

        // (2) Sign using certificate from Windows store
        // var windowsCert = Helpers.GetCertificateFromWindowsStore(Settings.CertificateSubject);
        // (sign in the same way with windowsCert)
    }
}
```

## Notas {#notes}

-   Reemplace `<PKCS11_LIBRARY_PATH>`, `<TOKEN_PIN>` y `<CERT_SUBJECT>` con sus valores reales.
-   Ambos flujos, PKCS#11 y el almacén de certificados de Windows, son compatibles. Seleccione el que se ajuste a su infraestructura.
-   Para obtener métodos auxiliares detallados y escenarios avanzados, consulte el <a href="https://github.com/groupdocs-signature/esign-documents-with-pkcs11-using-groupdocs-signature-dotnet" target="_blank" rel="nofollow noopener noreferrer">repositorio completo</a>.

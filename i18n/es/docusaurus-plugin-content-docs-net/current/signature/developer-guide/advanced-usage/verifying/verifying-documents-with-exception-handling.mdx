<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona distintos mensajes de error debido a problemas de validación, datos obligatorios ausentes, archivos, etc. Para manejar estas excepciones, se debe utilizar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.

A continuación se indican los pasos para manejar las excepciones de GroupDocs.Signature durante la verificación del documento:

* Construya un bloque try-catch alrededor del método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a>, capturando el error de tipo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.  

Este ejemplo muestra cómo manejar las excepciones de GroupDocs.Signature.

```csharp
try
{
    using (Signature signature = new Signature("sample.pdf"))
    {
        DigitalVerifyOptions options = new DigitalVerifyOptions()
        {
            CertificateFilePath = "dummy.pfx",
            // skip password specification
            // Password = "1234567890"
        };
        // sign document to file
        VerificationResult result = signature.Verify(options);
    }
}
catch (GroupDocsSignatureException ex)
{
    Console.WriteLine("GroupDocs Signature Exception: " + ex.Message);
}
catch (Exception ex)
{
    Console.WriteLine("System Exception: " + ex.Message);
}
```

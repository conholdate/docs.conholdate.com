<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona diferentes propiedades en la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a> para especificar la verificación de firmas de código QR.

A continuación se indican los pasos para verificar una firma de código QR dentro de un documento con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a> según sus requisitos y especificar las opciones de verificación.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verificationresult" target="_blank" rel="nofollow noopener noreferrer">VerificationResult</a> si es necesario.
  
Este ejemplo muestra cómo verificar una firma de código QR en un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verificationresult" target="_blank" rel="nofollow noopener noreferrer">VerificationResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    QrCodeVerifyOptions options = new QrCodeVerifyOptions()
    {
        // specify if all pages should be verified
        AllPages = false,
        PagesSetup = new PagesSetup() {  FirstPage = false, LastPage = true, OddPages = false, EvenPages = true },
        // specify text pattern
        Text = "John",
        // specify verification text pattern
        MatchType = TextMatchType.Contains,
        // specify types of QR code to verify
        EncodeType = QrCodeTypes.QR
    };
    // verify document signatures
    VerificationResult result = signature.Verify(options);
    if (result.IsValid)
    {
        Console.WriteLine("\nDocument was verified successfully!");
    }
    else
    {
        Console.WriteLine("\nDocument failed verification process.");
    }
}
```

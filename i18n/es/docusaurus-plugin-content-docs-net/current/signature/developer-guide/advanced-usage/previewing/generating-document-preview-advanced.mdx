<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> para especificar distintas opciones que permiten controlar el proceso de generación de vistas previas de páginas de documentos. A partir de la versión 19.12, existe la posibilidad de ocultar firmas en documentos. Utilizando la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions/hidesignatures" target="_blank" rel="nofollow noopener noreferrer">HideSignature</a> de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>, será posible ocultar las firmas en la vista previa del documento.  
  
A continuación se indican los pasos para generar una vista previa del documento con GroupDocs.Signature, ocultando las firmas:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> con:
* un delegado para la creación de cada flujo de página (consulte el controlador de eventos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a>);
* la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions/hidesignatures" target="_blank" rel="nofollow noopener noreferrer">HideSignature</a> establecida en `true`;
* el formato de vista previa de imagen: PNG / JPG / BMP;
* los números de página que se van a procesar;
* el tamaño personalizado de las imágenes de vista previa (si es necesario).  

:::info
Las secuencias creadas por `CreatePageStreamDelegate` se liberarán automáticamente una vez finalizada la generación de la imagen de vista previa. Si necesita implementar una liberación personalizada de la secuencia de vista previa de imagen, debe pasar el argumento adicional <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> para limpiar los recursos.
:::
  
* Llame al método GeneratePreview de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> como argumento.

## Genere una vista previa del documento sin firmas en él {#generate-document-preview-without-signatures-on-it}

```csharp
public static void GetPreview()
{
    // The path to the documents directory.
    string filePath = Constants.SAMPLE_WORD_SIGNED;
    using (Signature signature = new Signature(filePath))
    {
        // create preview options object
        PreviewOptions previewOption = new PreviewOptions(CreatePageStream, ReleasePageStream)
        {
            PreviewFormat = PreviewOptions.PreviewFormats.JPEG,
            // set property to hide all known signatures
            HideSignatures = true
        };
        // generate preview
        signature.GeneratePreview(previewOption);
    }
}

private static Stream CreatePageStream(PreviewPageData pageData)
{
    string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageData.PageNumber.ToString() + ".jpg");
    var folder = Path.GetDirectoryName(imageFilePath);
    if(!Directory.Exists(folder))
    {
       Directory.CreateDirectory(folder);
    }
    return new System.IO.FileStream(imageFilePath, FileMode.Create);
}

private static void ReleasePageStream(PreviewPageData pageData, Stream pageStream)
{
    pageStream.Dispose();
    string imageFilePath = Path.Combine("GeneratePreviewFolder", "image-" + pageData.PageNumber.ToString() + ".jpg");
    Console.WriteLine("Image file {0} is ready for preview", imageFilePath);
}
```

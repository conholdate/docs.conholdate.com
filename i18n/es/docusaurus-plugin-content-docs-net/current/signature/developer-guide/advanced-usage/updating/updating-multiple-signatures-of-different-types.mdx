<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona diferentes clases de firmas para manipularlas cambiando sus propiedades a lo largo del tiempo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase. Este método devuelve <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> objeto para analizar si las firmas se procesaron correctamente.

Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase. La <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> contiene una lista de firmas actualizadas correctamente y de las que fallaron. La actualización de una firma puede haber fallado por varias razones:

* si el objeto de firma se inicializó mediante el constructor con un identificador de firma incorrecto;
* si el objeto de firma no se encontró;
* se produjo un error al actualizar la firma en el documento;
* el tipo de firma no es compatible con la modificación (firma digital, campo de formulario o firma de metadatos).

Aquí están los pasos para actualizar varias firmas en el documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar una o varias opciones de búsqueda con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método y pasar la lista de opciones de búsqueda creada para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a> objeto(s) que deben actualizarse;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método y pasarle una o varias firmas.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> resultado para verificar si las firmas se actualizaron o no.

## Actualizar múltiples firmas de diferentes tipos en el documento {#update-multiple-signatures-of-different-types-in-the-document}

Este ejemplo muestra cómo actualizar una firma que se encontró usando <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
// initialize Signature instance
using (Signature signature = new Signature("signed.pptx"))
{
    // define few search options
    BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions();
    QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions();
    // add options to list
    List<SearchOptions> listOptions = new List<SearchOptions>();
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrCodeOptions);
    // search for signatures in document
    SearchResult result = signature.Search(listOptions);
    if (result.Signatures.Count > 0)
    {
        Console.WriteLine("\nTrying to update all signatures...");
        // mark all signatures as actual Signatures
        foreach (BaseSignature baseSignature in result.Signatures)
        {
            baseSignature.IsSignature = true;
        }
        // update all found signatures
        UpdateResult updateResult = signature.Update(result.Signatures);
        if (updateResult.Succeeded.Count == result.Signatures.Count)
        {
            Console.WriteLine("\nAll signatures were successfully updated!");
        }
        else
        {
            Console.WriteLine($"Successfully updated signatures : {updateResult.Succeeded.Count}");
            Console.WriteLine($"Not updated signatures : {updateResult.Failed.Count}");
        }
        Console.WriteLine("\nList of updated signatures:");
        int number = 1;
        foreach (BaseSignature temp in updateResult.Succeeded)
        {
            Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
        }
    }
    else
    {
        Console.WriteLine("No one signature was found.");
    }
}
```

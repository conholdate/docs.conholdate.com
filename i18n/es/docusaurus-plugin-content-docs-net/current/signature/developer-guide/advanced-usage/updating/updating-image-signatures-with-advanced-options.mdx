<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> Clase para manipular la ubicación y el tamaño de las firmas de imagen sobre… <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase. Este método devuelve <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> objeto para analizar si las firmas se procesaron correctamente.

Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase. La <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> contiene una lista de firmas actualizadas correctamente y de las que fallaron. La firma de la imagen podría haber fallado al actualizarse por varias razones:

* si el objeto de firma se inicializó mediante el constructor con un identificador de firma incorrecto;
* si el objeto de firma no se encontró;
* Se produjo un error al actualizar la firma en el documento.

Aquí están los pasos para actualizar la firma de imagen en el documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> objeto con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> objeto(s) que deben actualizarse;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método y pasarle una o varias firmas.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> resultado para verificar si las firmas se actualizaron o no.

Aquí tienes los pasos alternativos para actualizar la firma de imagen en el documento con GroupDocs.Signature. Este enfoque se basa en el ID de las firmas guardadas después de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> métodos.

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar uno o varios <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> objetos con la firma `Id(s)` pasados al constructor;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método y pasarle una o varias firmas;
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/updateresult" target="_blank" rel="nofollow noopener noreferrer">UpdateResult</a> resultado para verificar si las firmas se actualizaron o no.

## Actualizar la firma de imagen en el documento tras la búsqueda {#update-image-signature-in-the-document-after-search}

Este ejemplo muestra cómo actualizar una firma de imagen que se encontró mediante el método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>.

```csharp
using (Signature signature = new Signature("sampleSigned.xlsx"))
{
    ImageSearchOptions options = new ImageSearchOptions();
    // search for image signatures in document
    List<ImageSignature> signatures = signature.Search<ImageSignature>(options);
    // adjust signature properties
    foreach (ImageSignature temp in signatures)
    {
        // apply some condition to adjust signature properties
        temp.Left = temp.Left + 10;
        temp.Top = temp.Top + 10;
        if (temp.Size > 10000)
        {
            temp.IsSignature = false;
        }
    }
    // update all found signatures
    UpdateResult updateResult = signature.Update(signatures.ConvertAll(p => (BaseSignature)p));
    if (updateResult.Succeeded.Count == signatures.Count)
    {
        Console.WriteLine("All signatures were successfully updated!");
    }
    else
    {
        Console.WriteLine($"Successfully updated signatures : {updateResult.Succeeded.Count}");
        Console.WriteLine($"Not updated signatures : {updateResult.Failed.Count}");
    }
    Console.WriteLine("List of updated signatures:");
    foreach (BaseSignature temp in updateResult.Succeeded)
    {
        Console.WriteLine($"Signature# Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

## Actualizar la firma de imagen en el documento mediante un identificador de firma conocido {#update-image-signature-in-document-by-known-signature-identifier}

Este ejemplo muestra cómo actualizar una firma de imagen en el documento utilizando un identificador de firma conocido (que se obtuvo previamente mediante el método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>).

```csharp
// initialize Signature instance
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    // read from some data source signature Id value
    string[] signatureIdList = new string[]
    {
        "1dd21cf3-b904-4da9-9413-1ff1dab51974",
        "9e386726-a773-4971-b2fc-eaadfce65ffd"
    };
    // create list of Image Signature by known SignatureId
    List<BaseSignature> signatures = new List<BaseSignature>();
    signatureIdList.ToList().ForEach(p => signatures.Add(new ImageSignature(p)));
    // update all found signatures
    UpdateResult updateResult = signature.Update(signatures);
    if (updateResult.Succeeded.Count == signatures.Count)
    {
        Console.WriteLine("All signatures were successfully updated!");
    }
    else
    {
        Console.WriteLine($"Successfully updated signatures : {updateResult.Succeeded.Count}");
        Console.WriteLine($"Not updated signatures : {updateResult.Failed.Count}");
    }
    Console.WriteLine("List of updated signatures:");
    foreach (BaseSignature temp in updateResult.Succeeded)
    {
        Console.WriteLine($"Signature# Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

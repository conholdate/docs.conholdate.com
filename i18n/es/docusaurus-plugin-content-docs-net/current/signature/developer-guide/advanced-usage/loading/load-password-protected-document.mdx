<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> admite el procesamiento de documentos protegidos con contraseña.

A continuación se indican los pasos para trabajar con documentos protegidos por contraseña.

*   Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> objeto;
*   Establecer contraseña en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> propiedad;
*   Crear <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto y llamar a cualquier método.

El siguiente ejemplo de código muestra cómo procesar documentos protegidos con contraseña.

```csharp
LoadOptions loadOptions = new LoadOptions()
{
    Password = "1234567890"
};
using (Signature signature = new Signature("sampleProtected.pdf", loadOptions))
{
    QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR,
        Left = 100,
        Top = 100
    };
    // sign document to file
    signature.Sign("SignedSampleProtected", options);
}
```

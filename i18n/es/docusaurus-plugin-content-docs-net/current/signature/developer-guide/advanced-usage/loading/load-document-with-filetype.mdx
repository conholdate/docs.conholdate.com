<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite especificar el tipo de archivo al cargar documentos. Al cargar un documento mediante una ruta de archivo o un FileStream, **GroupDocs.Signature** comprueba la extensión del archivo para determinar su tipo, lo que puede tardar cierto tiempo. Con esta nueva funcionalidad, puede especificar directamente el tipo de archivo en **LoadOptions**, y **GroupDocs.Signature** omitirá el proceso de detección y utilizará inmediatamente el tipo especificado.

A continuación se indican los pasos para trabajar con documentos protegidos con contraseña.

*   Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> y establecer el tipo de archivo;
*   Crear un Stream para el archivo del documento mediante `File.OpenRead(filePath)`;
*   Crear el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> pasando el flujo del documento y las opciones de carga a su constructor;
*   Llamar al método **Sign** para firmar el documento y guardar la versión firmada en la ruta de salida.

El siguiente ejemplo de código muestra cómo especificar el tipo de archivo al cargar un documento.

```csharp
// The path to the documents directory.
string filePath = Constants.SAMPLE_PDF;
string fileName = Path.GetFileName(filePath);
string outputFilePath = Path.Combine(Constants.OutputPath, "LoadWithFileType", fileName);

using (Stream stream = File.OpenRead(filePath))
{
    // Specify the file type (PDF) while loading the document
    LoadOptions loadOptions = new LoadOptions(FileType.PDF);

    // Initialize the Signature instance with the file stream and load options
    using (Signature signature = new Signature(stream, loadOptions))
    {
        QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith")
        {
            EncodeType = QrCodeTypes.QR,
            Left = 100,
            Top = 100
        };
        // sign document to file
        signature.Sign(outputFilePath, options);
    }
}
Console.WriteLine("\nSource document signed successfully.\nFile saved at " + outputFilePath);
```

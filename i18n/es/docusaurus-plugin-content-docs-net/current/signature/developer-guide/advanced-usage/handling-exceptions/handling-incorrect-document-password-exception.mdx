La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> admite el manejo de contraseñas incorrectas proporcionadas al abrir documentos protegidos mediante la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/incorrectpasswordexception" target="_blank" rel="nofollow noopener noreferrer">IncorrectPasswordException</a>.

A continuación se indican los pasos para manejar la excepción de contraseña incorrecta al trabajar con documentos protegidos en GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta o el flujo del documento de origen como parámetro del constructor.
* Cubrir con un bloque try-catch el código que utiliza los métodos del objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/#sign_4" target="_blank" rel="nofollow noopener noreferrer">Sign</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update" target="_blank" rel="nofollow noopener noreferrer">Update</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a>), incluyendo la captura de la excepción <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/incorrectpasswordexception" target="_blank" rel="nofollow noopener noreferrer">IncorrectPasswordException</a>.

## Manejo de la excepción de contraseña incorrecta {#handling-incorrect-password-exception}

El siguiente ejemplo demuestra cómo manejar la excepción de contraseña incorrecta.

```csharp
// initialize LoadOptions with incorrect Password
LoadOptions loadOptions = new LoadOptions() { Password = "1" };
using (Signature signature = new Signature("ProtectedPwd.pdf", loadOptions))
{
    try
    {
        QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith")
        {
            EncodeType = QrCodeTypes.QR,
            Left = 100,
            Top = 100
        };
        // try to sign document to file, we expect for PasswordRequiredException
        signature.Sign(outputFilePath, options);
        Console.WriteLine("\nSource document signed successfully.\nFile saved at " + outputFilePath);
    }
    catch (IncorrectPasswordException ex)
    {
        Console.WriteLine($"HandlingIncorrectPasswordException: {ex.Message}");
    }
    catch (GroupDocsSignatureException ex)
    {
        Console.WriteLine($"Common GroupDocsSignatureException: {ex.Message}");
    }
    catch (Exception ex)
    {
        Console.WriteLine($"Common Exception happens only at user code level: {ex.Message}");
    }
    finally
    {
    }
}
```

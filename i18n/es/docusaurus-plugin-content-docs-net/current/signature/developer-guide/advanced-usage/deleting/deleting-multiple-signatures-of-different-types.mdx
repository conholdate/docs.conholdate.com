<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona diferentes clases de firmas para manipularlas y eliminarlas de los documentos. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método.

Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase. Este método devuelve <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/deleteresult" target="_blank" rel="nofollow noopener noreferrer">DeleteResult</a> objeto que contiene una lista de firmas actualizadas correctamente y de las que fallaron. La firma podría haber fallado al eliminarse por varias razones:

* si el objeto de firma se inicializó mediante el constructor con un identificador de firma incorrecto;
* si el objeto de firma no se encontró;
* se produjo un error al eliminar la firma en el documento;
* el tipo de firma no es compatible con la eliminación en la versión actual (para la versión 19.12, estas firmas son de tipo Digital, Campo de formulario o Firma de metadatos).

Aquí están los pasos para eliminar varias firmas en el documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar una o varias opciones de búsqueda con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método y pasar la lista creada de Opciones de Búsqueda para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature" target="_blank" rel="nofollow noopener noreferrer">BaseSignatures</a> objeto(s) que deben eliminarse;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método y pasarle una o varias firmas.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/deleteresult" target="_blank" rel="nofollow noopener noreferrer">DeleteResult</a> resultado para verificar si las firmas se actualizaron o no.

## Eliminar múltiples firmas en el documento {#delete-multiple-signatures-in-the-document}

Este ejemplo muestra cómo eliminar múltiples firmas que se encontraron utilizando <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
// initialize Signature instance
using (Signature signature = new Signature("signed.docx"))
{
    // define few search options
    BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions();
    QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions();
    // add options to list
    List<SearchOptions> listOptions = new List<SearchOptions>();
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrCodeOptions);
    // search for signatures in document
    SearchResult result = signature.Search(listOptions);
    if (result.Signatures.Count > 0)
    {
        Console.WriteLine("Trying to delete signatures...");
        List<BaseSignature> signaturesToDelete = new List<BaseSignature>();
        // collect image signatures to delete
        foreach (BaseSignature temp in result.Signatures)
        {
            if (temp.SignatureType == SignatureType.Image)
            {
                signaturesToDelete.Add(temp);
            }
        }
        // delete signatures
        DeleteResult deleteResult = signature.Delete(signaturesToDelete);
        if (deleteResult.Succeeded.Count == signaturesToDelete.Count)
        {
            Console.WriteLine("All signatures were successfully deleted!");
        }
        else
        {
            Console.WriteLine($"Successfully deleted signatures : {deleteResult.Succeeded.Count}");
            Console.WriteLine($"Not deleted signatures : {deleteResult.Failed.Count}");
        }
        Console.WriteLine("List of deleted signatures:");
        foreach (BaseSignature temp in deleteResult.Succeeded)
        {
            Console.WriteLine($"Signature# Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
        }
    }
    else
    {
        Console.WriteLine("No one signature was found.");
    }
}
```

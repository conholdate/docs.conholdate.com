<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona sobrecargas <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método que acepta una lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signaturetype" target="_blank" rel="nofollow noopener noreferrer">SignatureType</a> valores de enumeración.
Tenga en cuenta que este método modifica el mismo documento que se pasó al constructor de la <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase.

Aquí tienes los pasos para eliminar firmas de ciertos tipos del documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o su flujo como parámetro del constructor;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método y pasar la lista de los requeridos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signaturetype" target="_blank" rel="nofollow noopener noreferrer">SignatureType</a> enumeraciones a él.

Este ejemplo muestra cómo eliminar varios tipos de firmas del documento a la vez.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // compose the list of signature types to delete
    var signedTypes = new List<SignatureType>
    {
        SignatureType.Text, 
        SignatureType.Image,
        SignatureType.Barcode,
        SignatureType.QrCode,
        SignatureType.Digital
    };
    // deleting QR-Code signatures from the document by signature types
    DeleteResult result = signature.Delete(signedTypes);
    if (result.Succeeded.Count > 0)
    {
        Console.WriteLine("Following signatures were removed:");
        int number = 1;
        foreach (BaseSignature temp in result.Succeeded)
        {
            Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}. Created: {temp.CreatedOn.ToShortDateString()}");
        }
    }
    else
    {
        Helper.WriteError("No one signature was deleted.");
    }
}
```

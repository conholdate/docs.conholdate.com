<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a> Clase para manipular firmas de código de barras y eliminarlas de los documentos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método.  
Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase.

Aquí están los pasos para eliminar la firma de código de barras del documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> objeto con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a> objeto(s) que deben eliminarse del documento;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método y pasarle una o varias firmas.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/deleteresult" target="_blank" rel="nofollow noopener noreferrer">DeleteResult</a> resultado para verificar si las firmas se actualizaron o no.

Aquí tienes los pasos alternativos para eliminar la firma de código de barras del documento con GroupDocs.Signature. Este enfoque se basa en el ID de las firmas guardadas después de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> métodos.

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar uno o varios <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodesignature" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignature</a> objetos con la firma `Id(s)` pasados al constructor;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método y pasarle una o varias firmas;
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/deleteresult" target="_blank" rel="nofollow noopener noreferrer">DeleteResult</a> resultado para verificar si las firmas se actualizaron o no.

## Eliminar la firma de código de barras del documento después de la búsqueda {#delete-barcode-signature-from-the-document-after-search}

Este ejemplo muestra cómo eliminar una firma de código de barras que se encontró utilizando <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
// initialize Signature instance
using (Signature signature = new Signature("signed.docx"))
{
    BarcodeSearchOptions options = new BarcodeSearchOptions();
    List<BarcodeSignature> signatures = signature.Search<BarcodeSignature>(options);
    List<BaseSignature> signaturesToDelete = new List<BaseSignature>();
    // collect signatures to delete
    foreach (BarcodeSignature temp in signatures)
    {
        if (temp.Text.Contains("John"))
        {
            signaturesToDelete.Add(temp);
        }
    }
    // delete signatures
    DeleteResult deleteResult = signature.Delete(signaturesToDelete);
    if (deleteResult.Succeeded.Count == signaturesToDelete.Count)
    {
        Console.WriteLine("All signatures were successfully deleted!");
    }
    else
    {
        Console.WriteLine($"Successfully deleted signatures : {deleteResult.Succeeded.Count}");
        Console.WriteLine($"Not deleted signatures : {deleteResult.Failed.Count}");
    }
    Console.WriteLine("List of deleted signatures:");
    foreach (BaseSignature temp in deleteResult.Succeeded)
    {
        Console.WriteLine($"Signature# Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

## Eliminar la firma de código de barras del documento mediante el identificador de firma conocido {#delete-barcode-signature-from-the-document-by-known-signature-identifier}

Este ejemplo muestra cómo eliminar la firma de código de barras en un documento mediante el ID de firma conocido (que se obtuvo mediante <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método anteriormente).

```csharp
// initialize Signature instance
using (Signature signature = new Signature("signed.docx"))
{
    // read from some data source signature Id value
    string[] signatureIdList = new string[]
    {
        "1dd21cf3-b904-4da9-9413-1ff1dab51974",
        "9e386726-a773-4971-b2fc-eaadfce65ffd"
    };
    // create list of Barcode Signature by known SignatureId
    List<BaseSignature> signatures = new List<BaseSignature>();
    signatureIdList.ToList().ForEach(p => signatures.Add(new BarcodeSignature(p)));
    // delete required signatures
    DeleteResult deleteResult = signature.Delete(signatures);
    if (deleteResult.Succeeded.Count == signatures.Count)
    {
        Console.WriteLine("All signatures were successfully deleted!");
    }
    else
    {
        Console.WriteLine($"Successfully deleted signatures : {deleteResult.Succeeded.Count}");
        Console.WriteLine($"Not deleted signatures : {deleteResult.Failed.Count}");
    }
    Console.WriteLine("List of deleted signatures:");
    foreach (BaseSignature temp in deleteResult.Succeeded)
    {
        Console.WriteLine($"Signature# Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

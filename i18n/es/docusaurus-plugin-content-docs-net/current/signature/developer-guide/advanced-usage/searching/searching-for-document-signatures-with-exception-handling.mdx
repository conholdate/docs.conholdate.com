<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona distintos mensajes de error debido a problemas de validación, datos obligatorios ausentes, archivos, etc. Para manejar estas excepciones, se debe utilizar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.

A continuación se indican los pasos para manejar las excepciones de GroupDocs.Signature al buscar firmas en documentos:

* Construya un bloque try-catch alrededor del método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>, capturando errores del tipo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.

## Manejo de excepciones al buscar firmas en documentos {#exception-handling-while-searching-for-document-signatures}

Este ejemplo muestra cómo manejar las excepciones de GroupDocs.Signature.

```csharp
try
{
    // dont specify Password on protected document
    LoadOptions loadOptions = new LoadOptions();
    using (Signature signature = new Signature("samplePasswordProtected.pdf"))
    {
        DigitalSearchOptions options = new DigitalSearchOptions()
        {
        };
        // sign document to file
        List<DigitalSignature> signatures = signature.Search<DigitalSignature>(options);
    }
}
catch (GroupDocsSignatureException ex)
{
    Console.WriteLine("GroupDocs Signature Exception: " + ex.Message);
}
catch (Exception ex)
{
    Console.WriteLine("System Exception: " + ex.Message);
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite incrustar en la firma de código QR entradas estándar como correo electrónico, tarjeta de contacto v-card, dirección, etc., configuraciones de WiFi y tarjetas de contacto MeCard. Esta función admite la representación estándar de entradas en códigos QR. Por el momento, se admiten las siguientes entradas estándar de código QR:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a>: entrada que permite especificar en el código QR información de correo electrónico estándar con destinatario, asunto y cuerpo.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/address" target="_blank" rel="nofollow noopener noreferrer">Address</a>: entrada que contiene información de dirección.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/vcard" target="_blank" rel="nofollow noopener noreferrer">V-Card</a>: entrada que implementa la especificación estándar de tarjeta de visita 3.0. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/VCard" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mecard" target="_blank" rel="nofollow noopener noreferrer">Me-Card</a>: entrada que implementa un estándar similar a V-Card para detalles de contacto. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/MeCard_(QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/epc" target="_blank" rel="nofollow noopener noreferrer">EPC</a>: implementa el estándar de las directrices del Consejo Europeo de Pagos, que define el contenido de un código QR que se puede utilizar para iniciar una transferencia <a href="https://en.wikipedia.org/wiki/SEPA_credit_transfer" target="_blank" rel="nofollow noopener noreferrer">SEPA</a>. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/EPC_QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/event" target="_blank" rel="nofollow noopener noreferrer">Event</a>: entrada que implementa el estándar de eventos.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/wifi" target="_blank" rel="nofollow noopener noreferrer">WiFi</a>: entrada que implementa el estándar de configuración de WiFi.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/sms" target="_blank" rel="nofollow noopener noreferrer">SMS</a>: entrada que implementa propiedades de SMS.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/cryptocurrencytransfer/" target="_blank" rel="nofollow noopener noreferrer">CryptoCurrencyTransfer</a>: entrada que implementa el estándar de eventos.

A continuación se indican los pasos para extraer una entrada estándar de una firma de código QR con GroupDocs.Signature:  

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Llamar al método genérico <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search/#search_2/" target="_blank" rel="nofollow noopener noreferrer">Search</a> de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> con el tipo genérico <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodesignature/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignature</a> y pasar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signaturetype/" target="_blank" rel="nofollow noopener noreferrer">SignatureType.QRCode</a> como argumento.
* Recorrer la respuesta con la lista de firmas [QrCodeSignature] (https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodesignature/) y llamar al método genérico [GetData] (https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodesignature/getdata/#getdata) para recuperar la instancia requerida del objeto.

## Ejemplo 1: Cómo obtener el objeto de código QR de dirección en el documento {#example-1-how-to-get-address-qr-code-object-in-the-document}

El siguiente ejemplo muestra cómo buscar el objeto de dirección de código QR en un documento PDF.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    var signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (var qrSignature in signatures)
    {
        var address = qrSignature.GetData<Address>();
        if (address != null)
        {
            Console.WriteLine($"Found Address: {Address.Country} {Address.State} {Address.City} {Address.ZIP}");
        }
    }
}
```

## Ejemplo 2: cómo obtener el objeto de código QR de correo electrónico en el documento {#example-2-how-to-get-email-qr-code-object-in-the-document}

El siguiente ejemplo muestra cómo buscar el objeto de código QR de correo electrónico en un documento PDF.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    var signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (var qrSignature in signatures)
    {
        var email = qrSignature.GetData<Email>();
        if (email != null)
        {
            Console.WriteLine($"Found Email signature: {email.Address}: [{email.Subject}] : {email.Body}");
        }
    }
}
```

## Ejemplo 3: cómo recuperar el objeto QR Code VCard desde una imagen o documento {#example-3-how-to-retrieve-vcard-qr-code-object-from-image-or-document}

El siguiente ejemplo muestra cómo recuperar el objeto VCard de contacto a partir de la firma QR Code.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    var signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (var qrSignature in signatures)
    {
        var vCard = qrSignature.GetData<VCard>();
        if (vCard != null)
        {
            Console.WriteLine($"Found VCard signature: {vcard.FirstName} {vcard.LastName} from {vcard.Company}. Tel: {vcard.CellPhone}");
        }
    }
}
```

## Ejemplo 4: Cómo encontrar los datos EPC en el código QR de una imagen o documento {#example-4-how-to-find-the-epc-data-in-the-qr-code-from-image-or-document}

El siguiente ejemplo muestra cómo encontrar los datos EPC (código QR del Consejo Europeo de Pagos) en un código QR contenido en una imagen o documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    var signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (var qrSignature in signatures)
    {
        var payment = qrSignature.GetData<EPC>();
        if (payment != null)
        {
            Console.WriteLine($"EPC: {payment.Name}, IBAN {payment.IBAN}. Amount {payment.Amount}. Ref: {payment.Reference} / {payment.Remittance}");
        }
    }
}
```

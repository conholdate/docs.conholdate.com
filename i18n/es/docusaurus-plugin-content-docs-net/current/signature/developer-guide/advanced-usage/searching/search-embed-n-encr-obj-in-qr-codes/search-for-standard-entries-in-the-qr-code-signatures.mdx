<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece características adicionales al buscar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodesignature" target="_blank" rel="nofollow noopener noreferrer">firmas QRCode</a> previamente agregadas a documentos con objetos de entrada estándar incrustados. A continuación se indican las entradas estándar admitidas para su búsqueda y recuperación del objeto desde el código QR
:
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a> que almacena en el código QR la información estándar de correo electrónico con destinatario, asunto y cuerpo.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/address" target="_blank" rel="nofollow noopener noreferrer">Address</a> con información de dirección.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/vcard" target="_blank" rel="nofollow noopener noreferrer">V-Card</a>, entrada según la especificación de tarjeta de visita 3.0 con los detalles de la tarjeta de visita. Puede obtener más información <a href="https://en.wikipedia.org/wiki/VCard" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mecard" target="_blank" rel="nofollow noopener noreferrer">Me-Card</a>, entrada que implementa un estándar similar al de V-Card para los datos de contacto. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/MeCard_(QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/epc" target="_blank" rel="nofollow noopener noreferrer">EPC</a> implementa el estándar de las directrices del Consejo Europeo de Pagos, que define el contenido de un código QR que puede utilizarse para iniciar una transferencia <a href="https://en.wikipedia.org/wiki/SEPA_credit_transfer" target="_blank" rel="nofollow noopener noreferrer">SEPA</a>. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/EPC_QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/event" target="_blank" rel="nofollow noopener noreferrer">Event</a>, entrada que implementa el estándar de eventos.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/wifi" target="_blank" rel="nofollow noopener noreferrer">WiFi</a>, entrada que implementa el estándar de configuración de Wi-Fi.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/sms" target="_blank" rel="nofollow noopener noreferrer">SMS</a>, entrada que implementa las propiedades de SMS.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/cryptocurrencytransfer/" target="_blank" rel="nofollow noopener noreferrer">CryptoCurrencyTransfer</a>, entrada que implementa el estándar de eventos.

## Búsqueda de firmas QR-code y extracción del objeto Email {#search-for-qr-code-signatures-and-extract-email-object}

Este ejemplo muestra cómo buscar una firma QR-code y obtener el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a>.  

```csharp
// instantiating the signature object
using (Signature signature = new Signature("signed.pdf"))
{
    // search document
    List<QrCodeSignature> signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    foreach (QrCodeSignature qrSignature in signatures)
    {
        Console.WriteLine("Found QRCode signature: {0} with text {1}", qrSignature.EncodeType.TypeName, qrSignature.Text);
        Email email = qrSignature.GetData<Email>();
        if (email != null)
        {
           Console.WriteLine($"Found Email signature: {email.Address} {email.Subject} {email.Body}");
        }
    }
}

```

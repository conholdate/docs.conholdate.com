<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> para especificar distintas opciones de búsqueda de firmas digitales.

A continuación se indican los pasos para buscar firmas digitales en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> según sus necesidades y especificar las opciones de búsqueda.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a>.

Este ejemplo muestra cómo realizar una búsqueda avanzada de firmas digitales en un documento.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    DigitalSearchOptions options = new DigitalSearchOptions()
    {
        // specify special search criteria
        Comments = "Test comment",
        // certificate issues criteria
        IssuerName = "John",
        // digital certificate subject
        SubjectName = "Test",
        // specify date range period of signature
        SignDateTimeFrom = DateTime.Now.AddMonths(-1),
        SignDateTimeTo = DateTime.Now,
        //
    };
    // search for signatures in document
    List<DigitalSignature> signatures = signature.Search<DigitalSignature>(options);
    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var digitalSignature in signatures)
    {
        Console.WriteLine("Digital signature found from {0} with validation flag {1}. Certificate SN {2}",
            digitalSignature.SignTime, digitalSignature.IsValid, digitalSignature.Certificate?.SerialNumber);
    }
}
```

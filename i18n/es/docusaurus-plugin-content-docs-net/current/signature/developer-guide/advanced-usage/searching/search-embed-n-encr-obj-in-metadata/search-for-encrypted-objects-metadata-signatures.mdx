<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la capacidad de buscar objetos incrustados en firmas de metadatos con cifrado estándar o personalizado. El cifrado estándar se implementa mediante la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a>. La creación de este objeto requiere 3 argumentos: una enumeración del algoritmo de cifrado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricalgorithmtype" target="_blank" rel="nofollow noopener noreferrer">SymmetricAlgorithmType</a> con uno de los siguientes valores (DES, TripleDES, RC2, Rijndael), una cadena que represente la clave y una cadena que represente la sal.

A continuación se indican los pasos para buscar una firma de metadatos incrustada con cifrado estándar utilizando GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro del constructor la ruta del documento de origen o un flujo.
* Construir un objeto de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a> con los mismos parámetros utilizados al firmar el código QR protegido.
* Crear objetos de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> y configurar la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/dataencryption" target="_blank" rel="nofollow noopener noreferrer">DataEncryption</a> con una instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignature/getdata" target="_blank" rel="nofollow noopener noreferrer">GetData&lt;Type&gt;()</a> del objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignature" target="_blank" rel="nofollow noopener noreferrer">MetadataSignature</a> cifrado para recuperar un objeto del tipo Type.

## Definición de la clase {#definition-of-class}

Este ejemplo muestra cómo definir una clase personalizada con propiedades de serialización y cifrado, así como cómo configurar los atributos de formato para las propiedades.

```csharp
public class DocumentSignatureData
{
    [Format("SignID")]
    public string ID { get; set; }
    [Format("SAuth")]
    public string Author { get; set; }
    [Format("SDate", "yyyy-MM-dd")]
    public DateTime Signed { get; set; }
    [Format("SDFact", "N2")]
    public decimal DataFactor { get; set; }
    [SkipSerialization]
    public string Comments { get; set; }
}
```

## Buscar objetos incrustados en firmas de metadatos {#search-for-embedded-object-in-metadata-signatures}

Este ejemplo muestra cómo buscar objetos incrustados en firmas de metadatos.

```csharp
using (Signature signature = new Signature("MetadataEncryptedObject.docx"))
{
    // setup key and passphrase
    string key = "1234567890";
    string salt = "1234567890";
    // create data encryption
    IDataEncryption encryption = new SymmetricEncryption(SymmetricAlgorithmType.Rijndael, key, salt);
    MetadataSearchOptions options = new MetadataSearchOptions()
    {
        DataEncryption = encryption
    };
    // search for signatures in document
    List<WordProcessingMetadataSignature> signatures = signature.Search<WordProcessingMetadataSignature>(options);
    Console.WriteLine("\nSource document contains following signatures.");
    // get required metadata signatures
    WordProcessingMetadataSignature mdSignature = signatures.FirstOrDefault(p => p.Name == "Signature");
    if (mdSignature != null)
    {
        DocumentSignatureData documentSignatureData = mdSignature.GetData<DocumentSignatureData>();
        if (documentSignatureData != null)
        {
            Console.WriteLine("Signature has DocumentSignatureData object:\n ID = {0}, Author = {1}, Signed = {2}, DataFactor {3}",
                documentSignatureData.ID, documentSignatureData.Author, documentSignatureData.Signed.ToShortDateString(), documentSignatureData.DataFactor);
        }
    }
    // get required metadata signatures
    WordProcessingMetadataSignature mdAuthor = signatures.FirstOrDefault(p => p.Name == "Author");
    if (mdAuthor != null)
    {
        Console.WriteLine("Metadata signature found. Name : {0}. Value: {1}", mdAuthor.Name, mdAuthor.GetData<string>());
    }
    // get required metadata signatures
    WordProcessingMetadataSignature mdDocId = signatures.FirstOrDefault(p => p.Name == "DocumentId");
    if (mdDocId != null)
    {
        Console.WriteLine("Metadata signature found. Name : {0}. Value: {1}", mdDocId.Name, mdDocId.GetData<string>());
    }
}
```

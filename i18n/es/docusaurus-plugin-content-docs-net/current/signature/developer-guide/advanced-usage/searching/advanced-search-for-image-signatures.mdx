<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> Clase para especificar diferentes opciones para buscar firmas de imagen

* La propiedad `ReturnContent` permite devolver en la firma de la imagen su contenido;
* La propiedad `long MinContentSize` con un valor distinto de cero limita el tamaño mínimo de la imagen que se devolverá;
* La propiedad `MaxContentSize` de tipo `long` con un valor distinto de cero limita el tamaño máximo de la imagen que se devolverá.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> La propiedad `ReturnContentType` permite especificar el tipo de contenido exacto de la imagen.

Aquí están los pasos para buscar firmas de imagen dentro del documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a>  objeto según sus requisitos y especifique las opciones de búsqueda
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> a él.
* Analizar si es necesario la lista de la lista devuelta <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignatures</a>

Este ejemplo muestra cómo realizar una búsqueda avanzada de firmas de imagen en un documento y realizar análisis adicionales sobre las firmas de imagen, incluida la保存ación del contenido de la imagen.

```csharp
using (Signature signature = new Signature("sampleSignaed.docx"))
{
    // setup search options
    ImageSearchOptions searchOptions = new ImageSearchOptions()
    {
        // enable grabbing image content feature
        ReturnContent = true,
        // set minimum size if needed
        MinContentSize = 0,
        // set maximum size if needed
        MaxContentSize = 0,
        // specify exact image type to be returned
        ReturnContentType = FileType.JPEG,
    };
    // search document
    List<ImageSignature> signatures = signature.Search<ImageSignature>(searchOptions);
    Console.WriteLine($"\nSource document ['{fileName}'] contains following image signature(s).");
    // output signatures
    foreach (ImageSignature imageSignature in signatures)
    {
        Console.Write($"Found Image signature at page {imageSignature.PageNumber} and size {imageSignature.Size}.");
        Console.WriteLine($"Location at {imageSignature.Left}-{imageSignature.Top}. Size is {imageSignature.Width}x{imageSignature.Height}.");
    }
    //Save signature images
    string outputPath = System.IO.Path.Combine(Constants.OutputPath, "SearchForImageAdvanced");
    if (!Directory.Exists(outputPath))
    {
        Directory.CreateDirectory(outputPath);
    }
    int i = 0;
    foreach (ImageSignature imageSignature in signatures)
    {
        Console.Write($"Found Image signature at page {imageSignature.PageNumber} and size {imageSignature.Size}.");
        Console.WriteLine($"Location at {imageSignature.Left}-{imageSignature.Top}. Size is {imageSignature.Width}x{imageSignature.Height}.");
        string outputFilePath = System.IO.Path.Combine(outputPath, $"image{i}{imageSignature.Format.Extension}");
        using (FileStream fs = new FileStream(outputFilePath, FileMode.Create))
        {
            fs.Write(imageSignature.Content, 0, imageSignature.Content.Length);
        }
        i++;
    }
}
```

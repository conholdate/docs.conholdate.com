<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de buscar firmas de metadatos y convertir los valores obtenidos en diversos tipos de datos.

A continuación se presentan los pasos para buscar firmas de metadatos y obtener el tipo de datos requerido con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen o un flujo como parámetro del constructor.
* Crear un objeto de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>. Ajustar sus propiedades según sea necesario: establecer <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> junto con <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/namematchtype" target="_blank" rel="nofollow noopener noreferrer">NameMatchType</a> para conservar únicamente las entradas cuyos nombres coincidan, o establecer <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/includebuiltinproperties" target="_blank" rel="nofollow noopener noreferrer">IncludeBuiltinProperties</a> en `true` para obtener también las propiedades integradas del documento (esta bandera solo tiene sentido para documentos de procesamiento de texto, hojas de cálculo y presentaciones).
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>.
* Llamar al método de conversión adecuado para obtener el valor de metadatos correspondiente en el tipo de datos requerido.

## Buscar valores de firma electrónica de metadatos con diversos tipos de datos {#search-for-electronic-metadata-signature-values-with-various-data-type}

Este ejemplo muestra cómo buscar valores de firma de metadatos con diversos tipos de datos.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // set up search options: default options return all metadata signatures of the document
    MetadataSearchOptions searchOptions = new MetadataSearchOptions();
    // search for signatures in document
    List<PdfMetadataSignature> signatures = signature.Search<PdfMetadataSignature>(searchOptions);
    // try to get each Pdf signature with proper data type added in Basic usage example SignPdfWithMetadata
    PdfMetadataSignature mdSignature;
    // See example SignPdfWithMetadata with added various data type values to signatures
    try
    {
        mdSignature = signatures.FirstOrDefault(p => p.Name == "Author");
        Console.WriteLine($"\t[{mdSignature.Name}] as String = {mdSignature.ToString()}");
        mdSignature = signatures.FirstOrDefault(p => p.Name == "CreatedOn");
        Console.WriteLine($"\t[{mdSignature.Name}] as DateTime = {mdSignature.ToDateTime().ToShortDateString()}");
        mdSignature = signatures.FirstOrDefault(p => p.Name == "DocumentId");
        Console.WriteLine($"\t[{mdSignature.Name}] as Integer = {mdSignature.ToInteger()}");
        mdSignature = signatures.FirstOrDefault(p => p.Name == "SignatureId");
        Console.WriteLine($"\t[{mdSignature.Name}] as Double = {mdSignature.ToDouble()}");
        mdSignature = signatures.FirstOrDefault(p => p.Name == "Amount");
        Console.WriteLine($"\t[{mdSignature.Name}] as Decimal = {mdSignature.ToDecimal()}");
        mdSignature = signatures.FirstOrDefault(p => p.Name == "Total");
        Console.WriteLine($"\t[{mdSignature.Name}] as Float = {mdSignature.ToSingle()}");
    }
    catch (Exception ex)
    {
        Console.WriteLine($"Error obtaining signature: {ex.Message}");
    }

    // narrow the search down to metadata signatures whose names end with "Id"
    MetadataSearchOptions filteredOptions = new MetadataSearchOptions
    {
        Name = "Id",
        NameMatchType = TextMatchType.EndsWith
    };
    List<PdfMetadataSignature> filteredSignatures = signature.Search<PdfMetadataSignature>(filteredOptions);
    Console.WriteLine($"Found {filteredSignatures.Count} metadata signature(s) with name ending with 'Id'");
}
```


:::info
La búsqueda de metadatos es una parte del flujo de trabajo general de metadatos de documentos. Consulte [Trabajar con metadatos de documentos](/net/signature/developer-guide/basic-usage/work-with-document-metadata/) Página para la visión completa: agregar firmas de metadatos, leer propiedades integradas, proteger valores y limitaciones conocidas.
:::

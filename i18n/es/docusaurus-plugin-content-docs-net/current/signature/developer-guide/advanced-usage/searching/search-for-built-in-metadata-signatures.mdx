<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> para especificar distintas opciones de búsqueda de firmas de metadatos.

La mayoría de los tipos de documentos, como procesadores de texto, hojas de cálculo y presentaciones, contienen propiedades de metadatos integradas. La propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/includebuiltinproperties" target="_blank" rel="nofollow noopener noreferrer">IncludeBuiltinProperties</a> de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> permite recopilar todas las propiedades de metadatos integrados admitidas por el documento. Estas propiedades incluyen, por ejemplo, el autor del documento, la fecha de creación, las palabras clave, los títulos, etc.

A continuación se indican los pasos para buscar firmas de metadatos dentro de un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> según sus necesidades y establecer <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions/includebuiltinproperties" target="_blank" rel="nofollow noopener noreferrer">IncludeBuiltinProperties</a> en `true`.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>.

Este ejemplo muestra cómo obtener las firmas de metadatos integrados.

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    MetadataSearchOptions options = new MetadataSearchOptions()
    {
        Name = "Producer",
        IncludeBuiltinProperties = true,
        NameMatchType = TextMatchType.Contains
    };
    // search for signatures in document
    List<SpreadsheetMetadataSignature> signatures = signature.Search<SpreadsheetMetadataSignature>(options);
    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var metadataSignature in signatures)
    {
        Console.WriteLine("Metadata signature found. Name : {0}. Value: {1}. Type: {2}", metadataSignature.Name, metadataSignature.Value,metadataSignature.Type);
    }
}
```

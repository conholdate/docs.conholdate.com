<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la propiedad booleana <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> para especificar si el proceso de búsqueda debe excluir las firmas externas (las firmas externas son aquellas que se agregaron mediante un software de terceros y no con GroupDocs.Signature).

Desde la versión 19.12, cada vez que se firma un documento, la información sobre las firmas del documento se almacena en los metadatos del mismo. Esto significa que todas las firmas creadas mediante GroupDocs.Signature pueden distinguirse del contenido real del documento, y la bandera <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature/issignature" target="_blank" rel="nofollow noopener noreferrer">IsSignature</a> se establecerá como verdadera. La propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature/issignature" target="_blank" rel="nofollow noopener noreferrer">IsSignature</a> especifica si un componente del documento (texto/imagen/código de barras/código QR) constituye una firma real o un elemento del contenido del documento.

Para convertir las firmas agregadas mediante software de terceros o por versiones anteriores de GroupDocs.Signature, simplemente ejecute <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> con la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> establecida en falso (este es el valor predeterminado) y actualice <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature/issignature" target="_blank" rel="nofollow noopener noreferrer">IsSignature</a> para cada firma devuelta por el resultado de la búsqueda.

Existen varias formas de manipular los resultados de la búsqueda de firmas del documento:

* Si una firma ya no es necesaria, puede eliminarse del documento mediante el método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a>;
* La firma puede marcarse como contenido nativo del documento estableciendo la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature/issignature" target="_blank" rel="nofollow noopener noreferrer">IsSignature</a> = falso; en este caso, el campo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> permitirá que el método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> omita esta firma;
* Las firmas agregadas antes de la versión 19.12 se tratan como no firmas, ya que la información sobre ellas aún no se ha almacenado en el documento. Establecer la bandera <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> en verdadero excluirá estas firmas del resultado de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>.

A continuación se indican los pasos para buscar firmas y excluir los componentes externos del documento mediante GroupDocs.Signature:

* Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta del documento de origen como parámetro del constructor.
* Instancie el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> según sus necesidades y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> como verdadero.
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> como argumento.

## Exclusión de firmas externas de la búsqueda {#excluding-external-signatures-from-search}

 El siguiente ejemplo demuestra el uso de la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions/skipexternal" target="_blank" rel="nofollow noopener noreferrer">SkipExternal</a> para excluir de los resultados de la búsqueda aquellas firmas que no son reales.

### Uso de la propiedad SkipExternal de SearchOptions para excluir firmas no reales del resultado de la búsqueda {#using-searchoptions-skipexternal-property-to-exclude-non-actual-signatures-from-search}

```csharp
using (Signature signature = new Signature("sample_signed.pdf"))
{
    TextSearchOptions options = new TextSearchOptions()
    {
        // specify SkipExternal value to exclude non signature objects from Search result
        SkipExternal = true,
        // specify search on all pages
        AllPages = false
    };
    // search for text signatures in document
    List<TextSignature> signatures = signature.Search<TextSignature>(options);
    Console.WriteLine("\nSource document contains following text signature(s).");
    // enumerate all signature for output
    foreach (TextSignature textSignature in signatures)
    {
        if (textSignature != null)
        {
            Console.WriteLine($"Found Text signature at page {textSignature.PageNumber} with type [{textSignature.SignatureImplementation}] and text '{textSignature.Text}'.");
            Console.WriteLine($"Location at {textSignature.Left}-{textSignature.Top}. Size is {textSignature.Width}x{textSignature.Height}.");
        }
    }
}
```

## Actualización de firmas desde GroupDocs.Signature 19.11 y versiones anteriores {#updating-signatures-from-groupdocs-signature-19-11-and-below}

Los siguientes ejemplos muestran cómo marcar las firmas en un documento como firmas reales (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/basesignature/issignature" target="_blank" rel="nofollow noopener noreferrer">IsSignature</a> = true)

### Cómo marcar las firmas en un documento como firmas reales {#how-to-mark-signatures-in-document-as-actual-signatures}

```csharp
 // initialize Signature instance
 using (Signature signature = new Signature("sample_signed.pdf"))
 {
     // define search options to select required signatures om the document
     BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions();
     QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions();
     TextSearchOptions textOptions = new TextSearchOptions();
     // add options to list
     List<SearchOptions> listOptions = new List<SearchOptions>();
     listOptions.Add(barcodeOptions);
     listOptions.Add(qrCodeOptions);
     listOptions.Add(textOptions);
     // search for signatures in document
     SearchResult result = signature.Search(listOptions);
     if (result.Signatures.Count > 0)
     {
         Console.WriteLine("\nTrying to update all signatures...");
         // mark all signatures as actual Signatures
         foreach(BaseSignature baseSignature in result.Signatures)
         {
             baseSignature.IsSignature = true;
         }
         // update all found signatures
         UpdateResult updateResult = signature.Update(result.Signatures);
         if(updateResult.Succeeded.Count == result.Signatures.Count)
         {
             Console.WriteLine("\nAll signatures were successfully updated!");
         }
         else
         {
             Console.WriteLine($"Successfully updated signatures : {updateResult.Succeeded.Count}");
             Console.WriteLine($"Not updated signatures : {updateResult.Failed.Count}");
         }
         Console.WriteLine("\nList of updated signatures:");
         int number = 1;
         foreach(BaseSignature temp in updateResult.Succeeded)
         {
             Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
         }
     }
     else
     {
         Console.WriteLine("No one signature was found.");
     }
 }
```

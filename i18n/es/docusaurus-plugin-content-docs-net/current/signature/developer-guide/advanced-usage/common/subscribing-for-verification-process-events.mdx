<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase contiene varios eventos que se invocan en diferentes etapas del proceso de verificación.

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verifystarted" target="_blank" rel="nofollow noopener noreferrer">VerifyStarted</a> para manejar el evento de inicio del proceso. Este evento ocurre una sola vez. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> se llama el método
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verifyprogress" target="_blank" rel="nofollow noopener noreferrer">VerifyProgress</a> para manejar el evento de progreso. Este evento se produce cada vez que se completa la verificación de una firma.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verifycompleted" target="_blank" rel="nofollow noopener noreferrer">VerifyCompleted</a> para manejar el evento de finalización. Este evento ocurre una vez <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> el proceso se completó.

Aquí están los pasos para suscribirse al proceso de verificación con GroupDocs.Signature:

* Defina los delegados de controladores necesarios para procesar eventos de firma.
* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento fuente o el flujo como parámetro del constructor.
* Suscribirse a los eventos requeridos
* `required` debe ser instanciado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a> objeto
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar opciones de verificación en ella

## Implementar método para el evento `VerifyStarted` {#implement-method-for-verifystarted-event}

GroupDocs.Signature espera <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/processprogresseventhandler" target="_blank" rel="nofollow noopener noreferrer">ProcessStartEventHandler</a> delegar para suscribirse a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verifystarted" target="_blank" rel="nofollow noopener noreferrer">VerifyStarted</a> evento

```csharp
private static void OnVerifyStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Verify process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}
```

## Suscripción a eventos del proceso de verificación {#subscribing-for-verification-process-events}

```csharp
private static void OnVerifyStarted(Signature sender, ProcessStartEventArgs args)
{
    Console.WriteLine("Verify process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}
/// <summary>
/// Defines on progress event
/// </summary>
/// <param name="sender"></param>
/// <param name="args"></param>
private static void OnVerifyProgress(Signature sender, ProcessProgressEventArgs args)
{
    Console.WriteLine("Verify progress. Processed {0} signatures. Time spent {1} mlsec", args.ProcessedSignatures, args.Ticks);
}
/// <summary>
/// Defines on completed event
/// </summary>
/// <param name="sender"></param>
/// <param name="args"></param>
private static void OnVerifyCompleted(Signature sender, ProcessCompleteEventArgs args)
{
    Console.WriteLine("Verify process completed at {0} with {1} total signatures. Process took {2} mlsec", args.Completed, args.TotalSignatures, args.Ticks);
}
/// <summary>
/// Verify document with text signature applying specific options and subscribe for events
/// </summary>
public static void Run()
{
    // The path to the documents directory.
    string filePath = Constants.SAMPLE_PDF;
    using (Signature signature = new Signature(filePath))
    {
        signature.VerifyStarted += OnVerifyStarted;
        signature.VerifyProgress += OnVerifyProgress;
        signature.VerifyCompleted += OnVerifyCompleted;
        TextVerifyOptions options = new TextVerifyOptions("John Smith")
        {
           AllPages = true
        };
        // verify document
        VerificationResult result = signature.Verify(options);
        if (result.IsValid)
        {
            Console.WriteLine("\nDocument was verified successfully!");
        }
        else
        {
            Console.WriteLine("\nDocument failed verification process.");
        }
    }
}
```

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase contiene varios eventos que se invocan en diferentes etapas del proceso de búsqueda.

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchstarted" target="_blank" rel="nofollow noopener noreferrer">SearchStarted</a> para manejar el evento de inicio del proceso. Este evento ocurre una sola vez. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> se llama el método
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchprogress" target="_blank" rel="nofollow noopener noreferrer">SearchProgress</a> para manejar el evento de progreso. Este evento se produce cada vez que se busca en cada página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/searchcompleted" target="_blank" rel="nofollow noopener noreferrer">SearchCompleted</a> para manejar el evento de finalización. Este evento ocurre una vez <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> el proceso se completó.

Aquí están los pasos para suscribirse al proceso de búsqueda con GroupDocs.Signature:

* Defina los delegados de controladores necesarios para procesar eventos de búsqueda.
* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Suscribirse a los eventos requeridos.
* `required` debe ser instanciado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> objeto.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar las opciones de búsqueda en ella.

## Implementar método para el evento `SearchStarted` {#implement-method-for-searchstarted-event}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> espera que el delegado `ProcessStartEventHandler` se suscriba al evento `SearchStarted`

```csharp
private static void OnSearchStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Search process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}
```

```csharp
private static void OnSearchCompleted(Signature signature, ProcessCompleteEventArgs args)
{

```

## Suscripción a eventos del proceso de búsqueda {#subscribing-for-search-process-events}

```csharp
private static void OnSearchStarted(Signature sender, ProcessStartEventArgs args)
{
    Console.WriteLine("Search process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}

private static void OnSearchProgress(Signature sender, ProcessProgressEventArgs args)
{
    Console.WriteLine("Search progress. Processed {0} signatures. Time spent {1} mlsec", args.ProcessedSignatures, args.Ticks);
}

private static void OnSearchCompleted(Signature sender, ProcessCompleteEventArgs args)
{
    Console.WriteLine("Search process completed at {0} with {1} total signatures. Process took {2} mlsec", args.Completed, args.TotalSignatures, args.Ticks);
}

public static void Run()
{
    using (Signature signature = new Signature("SignedSample.pdf"))
    {
        signature.SearchStarted += OnSearchStarted;
        signature.SearchProgress += OnSearchProgress;
        signature.SearchCompleted += OnSearchCompleted;
        BarcodeSearchOptions options = new BarcodeSearchOptions()
        {
            // specify special pages to search on
            AllPages = true
        };
        // search for signatures in document
        List<BarcodeSignature> signatures = signature.Search<BarcodeSignature>(options);
        Console.WriteLine("\nSource document contains following signatures.");
        foreach (var barcodeSignature in signatures)
        {
            Console.WriteLine("Barcode signature found at page {0} with type {1} and text {2}",
                  barcodeSignature.PageNumber, barcodeSignature.EncodeType, barcodeSignature.Text);
        }
    }
}
```

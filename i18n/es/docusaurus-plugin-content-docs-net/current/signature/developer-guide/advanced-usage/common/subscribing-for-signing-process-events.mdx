La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> contiene varios eventos que se invocan en distintas etapas del proceso

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signstarted" target="_blank" rel="nofollow noopener noreferrer">SignStarted</a> para controlar el evento de inicio del proceso. Este evento se produce una única vez cuando se llama al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signprogress" target="_blank" rel="nofollow noopener noreferrer">SignProgress</a> para controlar el evento de progreso. Este evento se produce cada vez que se completa la firma de una firma individual.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signcompleted" target="_blank" rel="nofollow noopener noreferrer">SignCompleted</a> para controlar el evento de finalización. Este evento se produce una única vez que se completa el proceso <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>.

A continuación se indican los pasos para suscribirse al proceso de firma con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Definir los delegados del controlador necesarios para procesar los eventos de firma.
* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro en el constructor la ruta del documento de origen o un flujo.
* Suscribirse a los eventos requeridos.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> requerido.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar las opciones de firma como argumento.

## Implementar el método para el evento SignStarted {#implement-method-for-signstarted-event}

GroupDocs.Signature espera un delegado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/processprogresseventhandler" target="_blank" rel="nofollow noopener noreferrer">ProcessStartEventHandler</a> para suscribirse al evento <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/signstarted" target="_blank" rel="nofollow noopener noreferrer">SignStarted</a>

```csharp
private static void OnSignStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Sign process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}
```

## Suscripción a eventos del proceso de firma {#subscribing-for-signing-process-events}

```csharp
private static void OnSignStarted(Signature signature, ProcessStartEventArgs args)
{
    Console.WriteLine("Sign process started at {0} with {1} total signatures to be put in document", args.Started, args.TotalSignatures);
}

private static void OnSignProgress(Signature signature, ProcessProgressEventArgs args)
{
    Console.WriteLine("Sign progress. Processed {0} signatures. Time spent {1} mlsec", args.ProcessedSignatures, args.Ticks);
}

private static void OnSignCompleted(Signature signature, ProcessCompleteEventArgs args)
{
    Console.WriteLine("Sign process completed at {0} with {1} total signatures. Process took {2} mlsec", args.Completed, args.TotalSignatures, args.Ticks);
}

public static void Run()
{
    using (Signature signature = new Signature("sample.pdf"))
    {
        signature.SignStarted += OnSignStarted;
        signature.SignProgress += OnSignProgress;
        signature.SignCompleted += OnSignCompleted;
        TextSignOptions options = new TextSignOptions("John Smith")
        {
            // set signature position
            Left = 100,
            Top = 100
        };

        // sign document to file
        signature.Sign("SignedSample", options);
    }
}
```

GroupDocs.Signature proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> para especificar opciones adicionales para la firma de código QR, con las siguientes opciones de apariencia de la firma:

* Alineación de la firma (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>)
* Márgenes (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>)
* Configuración del borde y del fondo (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/border" target="_blank" rel="nofollow noopener noreferrer">Border, </a> <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/background" target="_blank" rel="nofollow noopener noreferrer">Background</a>)
* Fuente y colores (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/font" target="_blank" rel="nofollow noopener noreferrer">Font</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/forecolor" target="_blank" rel="nofollow noopener noreferrer">Forecolor</a>)

A continuación se indican los pasos para agregar una firma de código QR en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> con todas las opciones adicionales requeridas.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo agregar una firma de código de barras a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
 using (Signature signature = new Signature("sample.docx"))
 {
     // create QRCode option with predefined QRCode text
     QrCodeSignOptions options = new QrCodeSignOptions("12345678")
     {
         // setup QRCode encoding type
         EncodeType = QrCodeTypes.QR,
         // set signature position
         Left = 100,
         Top = 100,
         // set signature alignment
         // when VerticalAlignment is set the Top coordinate will be ignored.
         // Use Margin properties Top, Bottom to provide vertical offset
         VerticalAlignment = VerticalAlignment.Top,
         // when HorizontalAlignment is set the Left coordinate will be ignored.
         // Use Margin properties Left, Right to provide horizontal offset
         HorizontalAlignment = HorizontalAlignment.Right,
         Margin = new Padding() { Top = 20, Right = 20 },
         // adjust signature appearance
         // setup signature border
         Border = new Border()
         {
             Color = Color.DarkGreen,
             DashStyle = DashStyle.DashLongDashDot,
             Transparency = 0.5,
             Visible = true,
             Weight = 2
         },
         // set text color and Font
         ForeColor = Color.Red,
         Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
         // setup background
         Background = new Background()
         {
             Color = Color.LimeGreen,
             Transparency = 0.5,
             Brush = new LinearGradientBrush(Color.LimeGreen, Color.DarkGreen)
         }
     };
     // sign document to file
     SignResult signResult = signature.Sign("signed.docx", options);
     Console.WriteLine("\nList of newly created signatures:");
     int number = 1;
     foreach (BaseSignature temp in signResult.Succeeded)
     {
         Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
     }
 }
```

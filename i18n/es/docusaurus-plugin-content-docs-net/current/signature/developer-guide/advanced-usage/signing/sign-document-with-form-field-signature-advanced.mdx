<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> para especificar distintas opciones para la firma de campo de formulario. La firma de campo de formulario es un control de campo de entrada predefinido en el documento, con un nombre único dentro del contenido del documento, que espera una entrada por parte del usuario.

Actualmente, GroupDocs.Signature solo admite la creación de firmas de campo de formulario para documentos PDF.

La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> contiene un objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/formfieldsignature/" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignature</a> que se insertará en el documento.

A continuación se muestra la lista de distintas clases de firmas de campo de formulario que pueden configurarse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a>
:
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a> – representa un campo de entrada de texto en la página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature</a> – representa un campo de casilla de verificación en la página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/comboboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">ComboboxFormFieldSignature</a> – representa una firma de campo de lista desplegable (combo box) con una lista de opciones posibles en la página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/radiobuttonformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">RadioButtonFormFieldSignature</a> – representa una firma de botón de opción (radio button) en la página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a> – representa un campo de entrada de firma digital en la página del documento.  

A continuación se indican los pasos para agregar firmas de campo de formulario a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> según sus requisitos.
* Instanciar una de las clases derivadas del objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/formfieldsignature/" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignature</a>. Puede tratarse de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a>.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> con el objeto creado.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>, si es necesario, para verificar las firmas recién creadas.

Los siguientes ejemplos muestran distintos escenarios de uso de campos de formulario en la página del documento. Estos ejemplos son compatibles únicamente con documentos PDF.

## Firmar un documento PDF con distintas firmas de campo de formulario {#sign-pdf-document-with-various-form-field-signatures}

Este ejemplo muestra cómo agregar distintas firmas de campo de formulario a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    List<SignOptions> listOptions = new List<SignOptions>();

    // instantiate text form field signature
    FormFieldSignature textSignature = new TextFormFieldSignature("tbData1", "Value-1");
    // instantiate options based on text form field signature
    FormFieldSignOptions optionsTextFF = new FormFieldSignOptions(textSignature)
    {
        HorizontalAlignment = HorizontalAlignment.Left,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(10, 20, 0, 0),
        Height = 10,
        Width = 100
    };
    // instantiate text form field signature
    CheckboxFormFieldSignature chbSignature = new CheckboxFormFieldSignature("chbData1", true);
    // instantiate options based on text form field signature
    FormFieldSignOptions optionsTextCHB = new FormFieldSignOptions(chbSignature)
    {
        HorizontalAlignment = HorizontalAlignment.Center,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(0, 0, 0, 0),
        Height = 10,
        Width = 100,
    };
    // instantiate text form field signature
    DigitalFormFieldSignature digSignature = new DigitalFormFieldSignature("dgData1");
    // instantiate options based on text form field signature
    FormFieldSignOptions optionsTextDIG = new FormFieldSignOptions(digSignature)
    {
        HorizontalAlignment = HorizontalAlignment.Right,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(0, 50, 0, 0),
        Height = 10,
        Width = 100,
    };
    listOptions.Add(optionsTextFF);
    listOptions.Add(optionsTextCHB);
    listOptions.Add(optionsTextDIG);
    // sign document to file
    signature.Sign("signedSample.pdf", listOptions);

}
```

## Firmar documento PDF con campo de formulario Combobox como firma {#sign-pdf-document-with-combobox-form-field-signature}

Este ejemplo muestra cómo agregar una firma de campo de formulario de cuadro combinado a un documento PDF. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>  

```csharp
// initialize Signature instance
using (Signature signature = new Signature(filePath))
{
    // instantiate combo box form field signature
    List<string> items = new List<string>() { "Red", "Green", "Blue" };
    ComboboxFormFieldSignature combobox = new ComboboxFormFieldSignature("combo1", items, "Blue");
    // instantiate options based on text form field signature
    FormFieldSignOptions options = new FormFieldSignOptions(combobox)
    {
        HorizontalAlignment = HorizontalAlignment.Right,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(0, 0, 0, 0),
        Height = 100,
        Width = 300,
    };
    // sign document to file
    SignResult signResult = signature.Sign("sampleSigned.pdf", options);
}
```

## Firmar documento PDF con una firma de campo de formulario de botones de opción {#sign-pdf-document-with-radio-buttons-form-field-signature}

Este ejemplo muestra cómo agregar una firma de campo de formulario de botones de opción a un documento PDF. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>  

```csharp
// initialize Signature instance
using (Signature signature = new Signature(filePath))
{
    // instantiate radio-button form field signature
    List<string> radioOptions = new List<string>() { "One", "Two", "Three" };
    RadioButtonFormFieldSignature radioSignature = new RadioButtonFormFieldSignature("radioData1", radioOptions, "Two");
    // instantiate options based on text form field signature
    FormFieldSignOptions options = new FormFieldSignOptions(radioSignature)
    {
        HorizontalAlignment = HorizontalAlignment.Right,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(0, 0, 0, 0),
        Height = 100,
        Width = 300,
    };
    // sign document to file
    SignResult signResult = signature.Sign("sampleSigned.pdf", options );
}
```

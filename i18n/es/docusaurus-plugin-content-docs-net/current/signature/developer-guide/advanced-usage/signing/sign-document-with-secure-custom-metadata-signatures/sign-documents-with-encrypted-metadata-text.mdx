<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de proteger firmas de metadatos mediante cifrado estándar o personalizado. El cifrado estándar se implementa mediante la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a>. La creación de este objeto requiere tres argumentos: una enumeración del algoritmo de cifrado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricalgorithmtype" target="_blank" rel="nofollow noopener noreferrer">SymmetricAlgorithmType</a> con uno de los siguientes valores (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricalgorithmtype" target="_blank" rel="nofollow noopener noreferrer">DES, TripleDES, RC2, Rijndael</a>), una clave de tipo cadena y una sal de tipo cadena.

A continuación se indican los pasos para proteger valores de metadatos de tipo cadena mediante cifrado estándar con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro del constructor la ruta del documento de origen o un flujo.
* Construir un objeto de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a> con el algoritmo requerido y la pareja clave/sal segura.
* Crear objetos de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> y configurar la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/dataencryption" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions.DataEncryption</a> con una instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a>. En este caso, todas las firmas de metadatos agregadas a la colección de opciones se cifrarán.
* Una forma alternativa para cifrar únicamente las firmas de metadatos seleccionadas es configurar la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignature/dataencryption" target="_blank" rel="nofollow noopener noreferrer">MetadataSignature.DataEncryption</a> en cada firma que requiera protección.
* Crear la colección requerida de objetos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignature" target="_blank" rel="nofollow noopener noreferrer">MetadataSignature</a> con la clase adecuada según el tipo de documento (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PdfMetadataSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagemetadatasignature" target="_blank" rel="nofollow noopener noreferrer">ImageMetadataSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PresentationMetadataSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMetadataSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">WordProcessingMetadataSignature</a>).
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> como argumento.

## Implementación de una firma de metadatos cifrada {#implementation-of-encrypted-metadata-signature}

Este ejemplo muestra cómo firmar un documento mediante firmas de metadatos cifradas sobre .

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    // setup key and passphrase
    string key = "1234567890";
    string salt = "1234567890";
    // create data encryption
    IDataEncryption encryption = new SymmetricEncryption(SymmetricAlgorithmType.Rijndael, key, salt);
    // setup options with text of signature
    MetadataSignOptions options = new MetadataSignOptions()
    {

    };

    // setup signature metadata - this text will not be encrypted
    WordProcessingMetadataSignature mdAuthor = new WordProcessingMetadataSignature("Author", "Mr.Scherlock Holmes");

    // setup data of document id
    WordProcessingMetadataSignature mdDocId = new WordProcessingMetadataSignature("DocumentId", Guid.NewGuid().ToString());
    // set encryption for separate metadata signatures for this options
    mdDocId.DataEncryption = encryption

    // add signatures to options
    options.Signatures.Add(mdAuthor);
    options.Signatures.Add(mdDocId);
    // sign document to file
    signature.Sign("MetadataEncryptedText.docx", options);

}
```

## Implementación de la firma de metadatos cifrada sobre el cifrado de MetadataSignOptions {#implementation-of-encrypted-metadata-signature-over-metadatasignoptions-encryption}

Este ejemplo muestra cómo firmar un documento con firmas de metadatos cifradas sobre .

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    // setup key and passphrase
    string key = "1234567890";
    string salt = "1234567890";
    // create data encryption
    IDataEncryption encryption = new SymmetricEncryption(SymmetricAlgorithmType.Rijndael, key, salt);
    // setup options with text of signature
    MetadataSignOptions options = new MetadataSignOptions()
    {
        // set encryption for all metadata signatures for this options
        // if you need separate encryption use own MetadataSignature.DataEncryption property
        DataEncryption = encryption
    };

    // setup signature metadata
    WordProcessingMetadataSignature mdAuthor = new WordProcessingMetadataSignature("Author", "Mr.Scherlock Holmes");
    // setup data of document id
    WordProcessingMetadataSignature mdDocId = new WordProcessingMetadataSignature("DocumentId", Guid.NewGuid().ToString());

    // add signatures to options
    options.Signatures.Add(mdAuthor);
    options.Signatures.Add(mdDocId);
    // sign document to file
    signature.Sign("MetadataEncryptedText.docx", options);

}
```

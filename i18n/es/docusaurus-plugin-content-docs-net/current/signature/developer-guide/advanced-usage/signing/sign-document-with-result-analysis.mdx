<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona cada resultado del método como una implementación de la interfaz <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/iresult/" target="_blank" rel="nofollow noopener noreferrer">IResult</a>, la cual contiene las métricas del proceso.

A continuación se presentan los pasos para analizar el resultado del proceso con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> con las opciones requeridas y establecer la propiedad ZOrder.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> como argumento.
* Analizar la respuesta <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> del método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>.


## Firmar documento con análisis del resultado {#sign-document-with-result-analysis}

Este ejemplo muestra cómo analizar el resultado del proceso de firma.

```csharp
public static void Run()
{
    using (Signature signature = new Signature("sample.pdf"))
    {
        // create QRCode option with predefined QRCode text
        QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith");

        // sign document to file
        SignResult signResult = signature.Sign("output.pdf", options);

        // analyze SignResult (IResult properties)
        Console.WriteLine($"Sign-process was executed for {signResult.ProcessingTime} mls");
        Console.WriteLine($"Input document size {signResult.SourceDocumentSize} bytes");
        Console.WriteLine($"Output document size {signResult.DestinDocumentSize} bytes");
        Console.WriteLine($"Total processed signatures {signResult.TotalSignatures}");
        if (signResult.Failed.Count == 0)
        {
            Console.WriteLine("\nAll signatures were successfully created!");
        }
        else
        {
            Console.WriteLine($"Successfully created signatures : {signResult.Succeeded.Count}");
            Helper.WriteError($"Failed signatures : {signResult.Failed.Count}");
        }
        Console.WriteLine("\nList of newly created signatures:");
        int number = 1;
        foreach (BaseSignature temp in signResult.Succeeded)
        {
            Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}");
        }
    }
}
```

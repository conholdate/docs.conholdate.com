<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> para especificar distintas configuraciones para la firma digital
* . La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/digitalvba/" target="_blank" rel="nofollow noopener noreferrer">DigitalVBA</a> permite configurar los ajustes del certificado para la firma de macros

. A continuación se indican los pasos para agregar una firma digital a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento Excel de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a>.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/digitalvba/" target="_blank" rel="nofollow noopener noreferrer">DigitalVBA</a> con la ruta del certificado y la contraseña.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a>.

Este ejemplo muestra cómo agregar una firma digital a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp

 using (Signature signature = new Signature(excelFilePath))
{
     DigitalSignOptions signOptions = new DigitalSignOptions();
    //Add extension for signing VBA project digitally
    DigitalVBA digitalVBA = new DigitalVBA(certificatePath, password);
    //Set to true only for signing VBA project
    digitalVBA.SignOnlyVBAProject = true;
    digitalVBA.Comments = "VBA Comment";
    signOptions.Extensions.Add(digitalVBA);

    // sign document to file
    SignResult signResult = signature.Sign(outputFilePath, signOptions);
}

```

GroupDocs.Signature permite incluir en la firma de código QR objetos de datos complejos. En general, la generación avanzada de códigos de barras, como los códigos de barras matriciales 2D, se basa en modelos y estándares predefinidos para codificar y representar con precisión conjuntos diversos de datos. Estos códigos de barras se han convertido en una parte esencial de la gestión moderna de la información, permitiendo una captura y recuperación eficientes de datos en una amplia gama de aplicaciones.

* Capacidad para incrustar el código de barras 2D Royal Mail Mailmark
* Capacidad para incrustar el código HIBCC LIC (HIBC Labeler Identification Code), estándar de código de barras HIBC para etiquetado de proveedores
* Capacidad para incrustar la simbología Swiss QR
* Capacidad para incrustar la simbología HIBC PAS QR
* Capacidad para incrustar MaxiCode

A continuación, en los temas siguientes, encontrará ejemplos y detalles sobre cada una de estas funcionalidades

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> con la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">SignatureImplementation</a> de tipo enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation</a> para especificar diversas implementaciones de firmas de texto, con los siguientes valores y sus significados:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Stamp</a> – componente de sello de texto (etiqueta) sobre la página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Annotation</a> – anotación de texto con distintas opciones de apariencia. Esta implementación depende del tipo de documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Image</a> – el texto se transforma en una imagen y se coloca sobre la página del documento. Esta implementación es útil cuando se requiere ajustar efectos de apariencia avanzados, los cuales solo son posibles mediante manipulación de imágenes (como opacidad, rotación libre, desvanecimiento, sombras, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Sticker</a> – icono de adhesivo de texto con distintas opciones de apariencia. Esta implementación depende del tipo de documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.FormField</a> – este tipo se utiliza para actualizar campos de formulario existentes en el documento. Para ello, utilice la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtitle" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldTitle</a> para configurar el nombre del campo de formulario y la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtype" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldType</a> para especificar el tipo de campo de formulario.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Watermark</a> – marca de agua de texto a lo largo de la página del documento, debajo de todos los componentes del documento. Esta implementación depende del tipo de documento.

A continuación se indican los pasos para agregar una firma de texto en un documento mediante distintos tipos de implementación de firmas de texto con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> con todas las opciones adicionales requeridas.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">SignatureImplementation</a> del objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> con el valor requerido del tipo de enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle la instancia <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> inicializada.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.

##  Firmar documento con firma de texto e implementación de tipo sello {#sign-document-with-text-signature-and-stamp-implementation-type}

Este ejemplo muestra cómo agregar una firma de texto con implementación de tipo sello al documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.Stamp,
        // set alignment
        VerticalAlignment = VerticalAlignment.Top,
        HorizontalAlignment = HorizontalAlignment.Right,
        // set margin with 20 pixels for all sides
        Margin = new Padding(20)
    };
    // sign document to file
    SignResult signResult = signature.Sign("signed.pdf", options);
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId},
            Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

## Firmar documento con firma de texto e implementación de tipo de anotación {#sign-document-with-text-signature-and-annotation-implementation-type}

Este ejemplo muestra cómo agregar una firma de texto con implementación de firma de anotación al documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.Annotation,
        // for Pdf document type ther's ability to setup exteneded appearences
        Appearance = new PdfTextAnnotationAppearance()
        {
            Border = new Border()
            {
                Color = Color.Blue,
                DashStyle = DashStyle.Dash,
                Weight = 2,
            },
            BorderEffect = PdfTextAnnotationBorderEffect.Cloudy,
            BorderEffectIntensity = 2,
            HCornerRadius = 10,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title",
        },
        // set alignment
        VerticalAlignment = VerticalAlignment.Top,
        HorizontalAlignment = HorizontalAlignment.Right,
        // set margin with 20 pixels for all sides
        Margin = new Padding(20)
    };
    // sign document to file
    SignResult signResult = signature.Sign("signed.pdf", options);
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId},
            Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

## Firmar documento con firma de texto e implementación de tipo de campo de formulario {#sign-document-with-text-signature-and-form-field-implementation-type}

Este ejemplo muestra cómo agregar una firma de texto con implementación de firma de campo de formulario al documento.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    TextSignOptions ffOptions1 = new TextSignOptions("John Smith")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.PlainText,
        FormTextFieldTitle = "UserSignatureFullName"
    };
    TextSignOptions ffOptions2 = new TextSignOptions("Document is approved")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.RichText,
        FormTextFieldTitle = "UserSignatureComment"
    };
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(ffOptions1);
    listOptions.Add(ffOptions2);
    // sign document to file
    SignResult signResult = signature.Sign("signed.docx", listOptions);
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId},
            Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
}
```

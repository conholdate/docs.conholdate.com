<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contiene <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> Clase que implementa configuraciones adicionales para la firma digital de documentos de procesamiento de textos y hojas de cálculo

Opciones de firma base <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> debe configurarse con una instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> Clase para proporcionar un aspecto adicional de firma digital

Aquí están los pasos para configurar la apariencia adicional de la imagen con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Componer objeto de<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> objeto con todas las opciones adicionales requeridas.
* Establecer  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> propiedad con <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a> objeto y establecer sus propiedades
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> a él.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> resultado para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo configurar un aspecto adicional para la firma digital. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docs"))
{
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",

        // image as digital certificate appearance on document pages
        ImageFilePath = imagePath,
        //
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 10, Right = 10 },
        // Setup signature line appearance.
        // This appearance will add Signature Line on the first page.
        // Could be useful for .xlsx files.
        Appearance = new DigitalSignatureAppearance("John Smith", "Title", "jonny@test.com")

    };
    signature.Sign("signed.docx", options);
}


```

## Firmar documento PDF con apariencia de adhesivo de firma de texto {#sign-pdf-document-with-text-signature-sticker-appearance}

Este ejemplo muestra cómo agregar una firma de texto a un documento PDF con aspecto de adhesivo. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signed.docx", options);
}
```

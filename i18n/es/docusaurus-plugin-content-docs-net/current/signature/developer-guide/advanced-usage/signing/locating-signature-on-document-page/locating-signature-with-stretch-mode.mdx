<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de estirar el área de la firma a lo largo del ancho o la altura de la página. Utilice la enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">StretchMode</a>, que contiene los siguientes valores:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">None</a> – no se aplicará estiramiento
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageWidth</a> – para estirar el área de la firma a lo largo del ancho de la página
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageHeight</a> – para estirar el área de la firma a lo largo de la altura de la página
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/stretchmode" target="_blank" rel="nofollow noopener noreferrer">PageArea</a> – para estirar el área de la firma a lo largo del ancho y la altura de la página

A continuación se indican los pasos para utilizar el modo de estiramiento al agregar firmas de texto o imágenes en un documento con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> con todas las opciones adicionales requeridas y configurar la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/stretch" target="_blank" rel="nofollow noopener noreferrer">Stretch</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle la instancia de las opciones de firma (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a>).

##  Ubicar el área de firma con el modo de estiramiento {#locate-signature-area-with-stretch-mode}

Este ejemplo muestra cómo ubicar una firma con el modo de estiramiento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // define several signature options of different types and settings
    TextSignOptions textOptions = new TextSignOptions("This is test message")
    {
        AllPages = true,
        VerticalAlignment = VerticalAlignment.Top,
        Margin = new Padding(50),
        Stretch = StretchMode.PageWidth
    };
    BarcodeSignOptions barcodeOptions = new BarcodeSignOptions("123456")
    {
        AllPages = true,
        EncodeType = BarcodeTypes.Code128,
        VerticalAlignment = VerticalAlignment.Bottom,
        Margin = new Padding(50),
        Stretch = StretchMode.PageWidth
    };
    ImageSignOptions imageOptions = new ImageSignOptions()
    {
        AllPages = true,
        Stretch = StretchMode.PageHeight,
        HorizontalAlignment = HorizontalAlignment.Right,
        ImageFilePath = Constants.ImageHandwrite
    };

    // define list of signature options
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(textOptions);
    listOptions.Add(barcodeOptions);
    listOptions.Add(imageOptions);
    // sign document to file
    signature.Sign("signed.pdf", listOptions);
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> Clase para especificar opciones adicionales para la firma de código de barras, para especificar la apariencia de la siguiente firma

* alineación de firmas<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a>)
* márgenes (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>)
* Configuración del borde y del fondo<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/border" target="_blank" rel="nofollow noopener noreferrer">Borde,</a> <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/background" target="_blank" rel="nofollow noopener noreferrer">Background</a>)
* fuente y colores (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/font" target="_blank" rel="nofollow noopener noreferrer">Font</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/forecolor" target="_blank" rel="nofollow noopener noreferrer">Forecolor</a>)

Aquí están los pasos para agregar una firma de código de barras a un documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> objeto con todas las opciones adicionales requeridas.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> a él.
* Analizar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> resultado para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo agregar una firma de código de barras a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    // create barcode option with predefined barcode text
    BarcodeSignOptions options = new BarcodeSignOptions("12345678")
    {
        // setup Barcode encoding type
        EncodeType = BarcodeTypes.Code128,
        // set signature position
        Left = 100,
        Top = 100,
        // set signature alignment
        // when VerticalAlignment is set the Top coordinate will be ignored.
        // Use Margin properties Top, Bottom to provide vertical offset
        VerticalAlignment = Domain.VerticalAlignment.Top,
        // when HorizontalAlignment is set the Left coordinate will be ignored.
        // Use Margin properties Left, Right to provide horizontal offset
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Top = 20, Right = 20 },
        // adjust signature appearance
        // setup signature border
        Border = new Border()
        {
            Color = Color.DarkGreen,
            DashStyle = DashStyle.DashLongDashDot,
            Transparency = 0.5,
            Visible = true,
            Weight = 2
        },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
        // specify position of text with barcode line
        CodeTextAlignment = CodeTextAlignment.Above,
        // setup background
        Background = new Background()
        {
            Color = Color.LimeGreen,
            Transparency = 0.5,
            Brush = new LinearGradientBrush(Color.LimeGreen, Color.DarkGreen)
        }
    };
    // sign document to file
    SignResult signResult = signature.Sign("SampleSigned.docx", options);
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

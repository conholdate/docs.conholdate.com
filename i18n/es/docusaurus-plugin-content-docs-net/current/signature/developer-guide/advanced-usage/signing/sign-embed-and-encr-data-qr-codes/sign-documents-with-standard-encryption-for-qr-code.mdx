<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de cifrar firmas de código QR mediante algoritmos simétricos. La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricencryption" target="_blank" rel="nofollow noopener noreferrer">SymmetricEncryption</a> implementa uno de los siguientes algoritmos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/symmetricalgorithmtype" target="_blank" rel="nofollow noopener noreferrer">DES, TripleDES, RC2, Rijndael o AES</a>), una clave de tipo cadena y una sal (salt) también de tipo cadena.

A continuación se presentan los pasos para cifrar el texto de un código QR mediante el cifrado integrado de GroupDocs.Signature:

* Crear uno o varios objetos del tipo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> utilizando la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/data" target="_blank" rel="nofollow noopener noreferrer">Data</a> o la propiedad Text
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> según sus requisitos y asignar el objeto personalizado a la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/data" target="_blank" rel="nofollow noopener noreferrer">Data</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> como argumento.  

## Cómo cifrar una firma de código QR {#how-to-encrypt-qr-code-signature}

 Este ejemplo muestra cómo cifrar una firma de código QR.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // setup key and passphrase
    string key = "1234567890";
    string salt = "1234567890";
    // create data encryption
    IDataEncryption encryption = new SymmetricEncryption(SymmetricAlgorithmType.AES, key, salt);
    // setup QR-Code options
    QrCodeSignOptions options = new QrCodeSignOptions()
    {
        // set QR-code text
        Text = "This is secure text that will be encrypted",
        // QR-code type
        EncodeType = QrCodeTypes.QR,
        // specify serialization encryption
        DataEncryption = encryption,
        // locate and aligh signature
        Height = 100,
        Width = 100,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() { Right = 10, Bottom = 10 }
    };
    // sign document to file
    signature.Sign("QrCodeEncrypted.pdf", options);
}
```

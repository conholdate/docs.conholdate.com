<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> admite la localización de la firma en la página del documento utilizando diferentes unidades de medida. Enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType</a> maneja los siguientes tipos

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType.Pixels</a> permite ubicar la posición y el tamaño de la firma en píxeles (valor predeterminado)
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType.Millimeters</a> permite localizar la firma en la página y configurar su tamaño estableciendo milímetros
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType.Percents</a> permite localizar la posición y el tamaño de la firma como porcentaje del tamaño de la página  
  
Aquí tienes los pasos para localizar y dimensionar el área de firma con diferentes tipos de unidades de medida:

* Establecer propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/locationmeasuretype" target="_blank" rel="nofollow noopener noreferrer">LocationMeasureType</a> con uno de los valores anteriores para especificar cómo implementar valores en propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/left" target="_blank" rel="nofollow noopener noreferrer">Left</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/top" target="_blank" rel="nofollow noopener noreferrer">Top</a>
* Establecer propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/sizemeasuretype" target="_blank" rel="nofollow noopener noreferrer">SizeMeasureType</a> con uno de los valores anteriores para especificar cómo implementar el tamaño de los valores de firma en las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>
* Establecer propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/marginmeasuretype" target="_blank" rel="nofollow noopener noreferrer">MarginMeasureType</a> con uno de los valores anteriores para especificar cómo implementar valores en la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>

## Establecer la posición de la firma en milímetros {#set-signature-positioning-in-millimeters}

Este ejemplo muestra cómo especificar la posición en milímetros.

```csharp
 using (Signature signature = new Signature("sample.docx"))
 {
     // create barcode option with predefined barcode text
     BarcodeSignOptions options = new BarcodeSignOptions("12345678")
     {
         // setup Barcode encoding type
         EncodeType = BarcodeTypes.Code128,
         // set signature position in absolute position
         LocationMeasureType = MeasureType.Millimeters,
         Left = 40,
         Top = 50,
         // set signature area in millimeters
         SizeMeasureType = MeasureType.Millimeters,
         Width = 20,
         Height = 10,
         // set margin in millimeters
         MarginMeasureType = MeasureType.Millimeters,
         Margin = new Padding() { Left =5, Top = 5, Right = 5 },
     };
     // sign document to file
     signature.Sign("signedSample.docx", options);
 }
```

## Establecer la posición de la firma en porcentajes {#set-signature-positioning-in-percents}

Este ejemplo muestra cómo establecer diferentes propiedades de posición en porcentajes.

```csharp
 using (Signature signature = new Signature("sample.pdf"))
 {
     // create barcode option with predefined barcode text
     BarcodeSignOptions options = new BarcodeSignOptions("12345678")
     {
         // setup Barcode encoding type
         EncodeType = BarcodeTypes.Code128,
         // set signature position in absolute position
         LocationMeasureType = MeasureType.Percents,
         Left = 5,
         Top = 5,
         // set signature area in millimeters
         SizeMeasureType = MeasureType.Percents,
         Width = 10,
         Height = 5,
         // set margin in millimeters
         MarginMeasureType = MeasureType.Percents,
         Margin = new Padding() { Left = 1, Top = 1, Right = 1 },
     };
     // sign document to file
     signature.Sign("signed.docx", options);
 }
```

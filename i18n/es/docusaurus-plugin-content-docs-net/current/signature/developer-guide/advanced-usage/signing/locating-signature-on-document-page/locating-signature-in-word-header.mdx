Un documento de Word ofrece una amplia variedad de encabezados y pies de página predefinidos, brindándole opciones para mejorar fácilmente el diseño y la disposición del documento. El encabezado, ubicado en el margen superior, y el pie de página, situado en el margen inferior, constituyen secciones esenciales de la disposición del documento. Por lo general, los encabezados y pies de página contienen información adicional, como números de página, fechas, identificación del autor y notas al pie.

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la capacidad de localizar firmas en el encabezado y el pie de página de un documento de Word. Utilice la enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/shapeposition" target="_blank" rel="nofollow noopener noreferrer">ShapePosition</a>, que contiene los siguientes valores:

* **Default** – la firma se colocará en el cuerpo del documento .docx
* **Header** – la firma se colocará en el encabezado del documento de Word
* **Footer** – la firma se colocará en el pie de página del documento de Word

A continuación se presentan los pasos para configurar el modo de firma al agregar texto en un documento de Word mediante GroupDocs.Signature:
1.
* Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta del documento de origen como parámetro del constructor.   2.
* Instancie <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> y configure la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/shapeposition" target="_blank" rel="nofollow noopener noreferrer">ShapePosition</a>.   3.
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>.

## Ubicación del área de firma en el encabezado/pie de página de Word {#locate-signature-area-in-the-word-header-footer}
Ahora, los usuarios pueden crear y personalizar fácilmente firmas de texto directamente dentro de los encabezados y pies de página de sus documentos de Word.

```csharp
    using (Signature signature = new Signature("sample.docx"))
    {
        var listOptions = new List<SignOptions>();

        var headerSign = new TextSignOptions("Hello header!")
        {
            ShapePosition = ShapePosition.Header
        };

        var footerSign = new TextSignOptions("Hello footer!")
        {
            ShapePosition = ShapePosition.Footer
        };

        listOptions.Add(headerSign);
        listOptions.Add(footerSign);

        signature.Sign(outputFilePath, listOptions);
    }
```

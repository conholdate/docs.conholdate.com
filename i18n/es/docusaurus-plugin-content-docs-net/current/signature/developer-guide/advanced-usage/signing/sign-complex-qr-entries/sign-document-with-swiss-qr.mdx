<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/swissqr/" target="_blank" rel="nofollow noopener noreferrer">SwissQR</a> para crear códigos QR suizos. El código QR suizo se utiliza principalmente en la factura QR (*QR-bill*), un documento diseñado para reemplazar los formularios de pago tradicionales y actualmente utilizado en transacciones de pago en Suiza.

A continuación se indican los pasos para agregar una firma de código QR suizo en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/swissqr/" target="_blank" rel="nofollow noopener noreferrer">SwissQR</a> con todas las opciones adicionales requeridas.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> con todas las opciones adicionales requeridas y asignar el objeto SwissQR a la propiedad Data.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> como argumento.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.

```csharp
using (Signature signature = new Signature(filePath))
{
    // create SwissQR data object
    var swissQR = new SwissQR()
    {
        Account = "CH4431999123000889012",
        Amount = 1000.25m,
        Currency = "CHF",
        Reference = "210000000003139471430009017",
        Creditor = new SwissAddress
        {
            Name = "Muster & Söhne",
            Street = "Musterstrasse",
            HouseNo = "12b",
            PostalCode = "8200",
            Town = "Zürich",
            CountryCode = "CH"
        },

        Debtor = new SwissAddress
        {
            Name = "Muster AG",
            Street = "Musterstrasse",
            HouseNo = "1",
            PostalCode = "3030",
            Town = "Bern",
            CountryCode = "CH"
        }
    };

    // create options
    QrCodeSignOptions options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 100,
        // setup Data property to SwissQR instance
        Data = swissQR
    };

    // sign document to file
    var signResult = signature.Sign(outputFilePath, options);
            
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

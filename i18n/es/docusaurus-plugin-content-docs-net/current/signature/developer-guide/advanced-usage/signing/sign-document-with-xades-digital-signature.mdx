<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> para especificar distintas configuraciones para la firma digital, al igual que la propiedad XAdES del tipo de enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/xadestype/" target="_blank" rel="nofollow noopener noreferrer">XAdES</a>. Esta propiedad especifica la implementación del formato <a href="https://en.wikipedia.org/wiki/XAdES" target="_blank" rel="nofollow noopener noreferrer">XAdES</a> únicamente para documentos de hojas de cálculo (por ahora).

A continuación se indican los pasos para agregar una firma de tipo XAdES en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> con el certificado requerido y su contraseña.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/xadestype" target="_blank" rel="nofollow noopener noreferrer">XAdESType</a> al valor XAdES.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> como argumento.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo agregar una firma digital a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // set XAdES type
        XAdESType = XAdESType.XAdES,
        // certificate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1"
    };
    SignResult signResult = signature.Sign(outputFilePath, options);
}
```

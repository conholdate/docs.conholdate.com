<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de alinear la firma en la página mediante configuraciones de alineación horizontal y vertical. Las opciones de firma que implementan la interfaz <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/ialignment" target="_blank" rel="nofollow noopener noreferrer">IAlignment</a> contienen las siguientes propiedades:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> – propiedad de tipo enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> para especificar la alineación horizontal de la firma. Los valores posibles son <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">None, Left, Center, Right</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> – propiedad de tipo enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> para especificar la alineación vertical de la firma. Los valores posibles son <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">None, Top, Center, Bottom</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a> – propiedad de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/padding" target="_blank" rel="nofollow noopener noreferrer">Padding</a> para especificar el desplazamiento de la alineación de la firma. Los campos de esta clase son <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/padding" target="_blank" rel="nofollow noopener noreferrer">Left, Top, Right, Bottom</a>, y permiten especificar el desplazamiento, en unidades de medida, desde el área de alineación.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/marginmeasuretype" target="_blank" rel="nofollow noopener noreferrer">MarginMeasureType</a> – propiedad de tipo enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">MeasureType</a> con valores (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/measuretype" target="_blank" rel="nofollow noopener noreferrer">Pixels, Millimeters, Percents</a>). Consulte más detalles en este ejemplo: [Ubicación de la firma en la página con distintas unidades de medida](/net/signature/developer-guide/advanced-usage/signing/locating-signature-on-document-page/locating-signature-on-page-with-different-measure-units/)

A continuación se indican los pasos para alinear la firma en la página con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro del constructor la ruta o el flujo del documento de origen.
* Instanciar las opciones de firma (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a>) con todas las propiedades requeridas.
* Establecer <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">HorizontalAlignment</a> con uno de los valores de la enumeración para alinear la firma a lo largo del ancho de la página.
* Establecer <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/verticalalignment" target="_blank" rel="nofollow noopener noreferrer">VerticalAlignment</a> con uno de los valores de la enumeración para alinear la firma a lo largo de la altura de la página.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a> con el desplazamiento requerido desde el borde de la página.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/marginmeasuretype" target="_blank" rel="nofollow noopener noreferrer">MarginMeasureType</a> con un valor distinto del predeterminado si se desea especificar el desplazamiento desde el borde de la página en otras unidades de medida, como milímetros o porcentajes de página (respecto al 100 % del ancho y al 100 % de la altura).
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle como argumento la instancia de las opciones de firma (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a>).

Este ejemplo muestra cómo ubicar la firma con distintas alineaciones.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // define qr-code size
    int qrWidth = 100;
    int qrHeight = 100;
    // define list of options
    List<SignOptions> listOptions = new List<SignOptions>();
    // walk through all alignment values to locate signature at all page alignment areas
    foreach (HorizontalAlignment horizontalAlignment in Enum.GetValues(typeof(HorizontalAlignment)))
    {
        foreach (VerticalAlignment verticalAlignment in Enum.GetValues(typeof(VerticalAlignment)))
        {
            if (verticalAlignment != VerticalAlignment.None && horizontalAlignment != HorizontalAlignment.None)
            {
                listOptions.Add(
                    new QrCodeSignOptions("Left-Top")
                    {
                    // set signature rectangle
                    Width = qrWidth,
                        Height = qrHeight,
                    // set signature alignment
                    HorizontalAlignment = horizontalAlignment,
                        VerticalAlignment = verticalAlignment,
                        Margin = new Padding(5),
                    });
            }
        }
    }
    // sign document to file
    signature.Sign("signed.pdf", listOptions);
}
```

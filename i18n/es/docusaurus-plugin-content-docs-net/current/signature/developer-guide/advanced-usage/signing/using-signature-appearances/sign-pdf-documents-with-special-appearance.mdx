<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contiene clases que implementan apariencias especiales de firma para documentos PDF.

Las opciones base de firma <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> contienen la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a>, que espera una instancia de las siguientes clases:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextannotationappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextAnnotationAppearance</a>: clase que implementa la firma en documentos PDF como un área de anotación. Tenga en cuenta que la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> debe establecerse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Annotation</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextstickerappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextStickerAppearance</a>: clase que implementa la firma en documentos PDF como una pegatina pequeña. Tenga en cuenta que la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> debe establecerse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Sticker</a>.

A continuación se indican los pasos para configurar la apariencia especial de una firma de texto en documentos PDF con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Construir un objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> con todas las opciones adicionales requeridas.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.Appearance</a> con un objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextannotationappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextAnnotationAppearance</a> y configurar sus propiedades.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.

## Firmar documento PDF con apariencia de firma de texto como anotación {#sign-pdf-document-with-text-signature-annotation-appearance}

Este ejemplo muestra cómo agregar una firma de texto a un documento PDF con apariencia de anotación. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Annotation,
        Appearance = new PdfTextAnnotationAppearance()
        {
            Border = new Border()
            {
                Color = Color.Blue,
                DashStyle = DashStyle.Dash,
                Weight = 2,
            },
            BorderEffect = PdfTextAnnotationBorderEffect.Cloudy,
            BorderEffectIntensity = 2,
            HCornerRadius = 10,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title",
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signedAnnotation.pdf", options);
}
```

## Firmar documento PDF con apariencia de adhesivo de firma de texto {#sign-pdf-document-with-text-signature-sticker-appearance}

Este ejemplo muestra cómo agregar una firma de texto a un documento PDF con aspecto de adhesivo. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature(filePath))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign(outputFilePath, options);
}
```

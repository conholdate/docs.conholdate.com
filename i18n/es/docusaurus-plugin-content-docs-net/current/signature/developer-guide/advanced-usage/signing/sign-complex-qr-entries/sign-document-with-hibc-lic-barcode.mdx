<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibcliccombineddata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICCombinedData</a> para crear códigos de barras HIBC LIC. Esta clase se utiliza por fabricantes de productos sanitarios con fines de identificación. Los etiquetadores pueden codificar datos primarios y datos secundarios.

A continuación se indican los pasos para agregar una firma de código de barras HIBC LIC en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibcliccombineddata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICCombinedData</a>. Rellenar las propiedades correspondientes a la estructura de datos primarios y secundarios con los modelos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibclicprimarydata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICPrimaryData</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/hibclicsecondaryadditionaldata/" target="_blank" rel="nofollow noopener noreferrer">HIBCLICSecondaryAdditionalData</a>, respectivamente.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> con todas las opciones adicionales requeridas y asignar el objeto HIBCLICCombinedData a la propiedad Data.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> como argumento.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo agregar una firma HIBCLICCombinedData a un documento:

```csharp
using (Signature signature = new Signature(filePath))
{
    // Create HIBCLICCombinedData data object which composes Primary and Secondary data
    var hibclicCombinedData = new HIBCLICCombinedData()
    {
        PrimaryData = new HIBCLICPrimaryData()
        {
            ProductOrCatalogNumber = "12345",
            LabelerIdentificationCode = "A999",
            UnitOfMeasureID = 1
        },

        SecondaryAdditionalData = new HIBCLICSecondaryAdditionalData()
        {
            ExpiryDate = DateTime.Today,
            ExpiryDateFormat = HIBCLICDateFormat.MMDDYY,
            Quantity = 30,
            LotNumber = "LOT123",
            SerialNumber = "SERIAL123",
            DateOfManufacture = DateTime.Today
        }
    };

    // create options
    QrCodeSignOptions options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 100,
        // setup Data property to Mailmark2D instance
        Data = hibclicCombinedData
    };

    // sign document to file
    var signResult = signature.Sign(outputFilePath, options);
            
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite incrustar en la firma QR entradas estándar como correo electrónico, tarjeta de contacto (v-card), dirección, etc. Esta función admite la representación estándar de entradas en códigos QR. Por el momento, se admiten las siguientes entradas estándar para códigos QR:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/email" target="_blank" rel="nofollow noopener noreferrer">Email</a>: entrada que permite especificar en el código QR información de correo electrónico estándar, incluyendo destinatario, asunto y cuerpo.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/address" target="_blank" rel="nofollow noopener noreferrer">Address</a>: entrada que contiene información de dirección.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/vcard" target="_blank" rel="nofollow noopener noreferrer">**V-Card**</a>: entrada que implementa la especificación estándar de tarjeta de visita versión 3.0. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/VCard" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mecard" target="_blank" rel="nofollow noopener noreferrer">**Me-Card**</a>: entrada que implementa un estándar similar a V-Card para detalles de contacto. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/MeCard_(QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/epc" target="_blank" rel="nofollow noopener noreferrer">EPC</a>: implementa el estándar de las directrices del Consejo Europeo de Pagos, que define el contenido de un código QR utilizado para iniciar una transferencia <a href="https://en.wikipedia.org/wiki/SEPA_credit_transfer" target="_blank" rel="nofollow noopener noreferrer">SEPA</a>. Puede encontrar más detalles <a href="https://en.wikipedia.org/wiki/EPC_QR_code" target="_blank" rel="nofollow noopener noreferrer">aquí</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/event" target="_blank" rel="nofollow noopener noreferrer">Event</a>: entrada que implementa el estándar para eventos.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/cryptocurrencytransfer/" target="_blank" rel="nofollow noopener noreferrer">CryptoCurrencyTransfer</a>: entrada que implementa el estándar para eventos.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/wifi" target="_blank" rel="nofollow noopener noreferrer">WiFi</a>: entrada que implementa el estándar para configuraciones de Wi-Fi.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/sms" target="_blank" rel="nofollow noopener noreferrer">SMS</a>: entrada que implementa propiedades de SMS.

A continuación se indican los pasos para incrustar una entrada estándar en un código QR mediante GroupDocs.Signature:  

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro del constructor la ruta del documento de origen.
* Crear una nueva instancia de una de las clases de entradas estándar.
* Crear uno o varios objetos del tipo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a>, asignando a su propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/data" target="_blank" rel="nofollow noopener noreferrer">Data</a> el objeto estándar previamente inicializado.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> según sus requisitos y asignar el objeto personalizado a la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/data" target="_blank" rel="nofollow noopener noreferrer">Data</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a>.

## Firmar PDF con objeto QR de correo electrónico {#sign-pdf-with-email-qr-code-object}

Este ejemplo muestra cómo firmar un PDF mediante un objeto QR de correo electrónico.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create Email object
    var email = new Email()
    {
        Address = "sherlock@holmes.com",
        Subject = "Very important e-mail",
        Body = "Hello, Watson. Reach me ASAP!"
    };

    // create options
    var options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        // setup Data property to Address instance
        Data = email,
        // set right bottom corner
        HorizontalAlignment = HorizontalAlignment.Right,
        VerticalAlignment = VerticalAlignment.Bottom,
        Width = 100,
        Height = 100,
        Margin = new Padding(10)
    };

    // sign document to file
    signature.Sign("output.pdf", options);
}


```

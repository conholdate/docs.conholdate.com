<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona distintos mensajes de error debido a problemas de validación, datos obligatorios ausentes, archivos, etc. Para las clases de excepción se utiliza <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.

A continuación se indican los pasos para manejar las excepciones de GroupDocs.Signature:

* Construya un bloque try-catch alrededor del método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>, capturando errores del tipo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/groupdocssignatureexception" target="_blank" rel="nofollow noopener noreferrer">GroupDocsSignatureException</a>.  

Este ejemplo muestra cómo manejar las excepciones de GroupDocs.Signature.

```csharp
try
{
    using (Signature signature = new Signature("sample.xlsx"))
    {
        DigitalSignOptions options = new DigitalSignOptions()
        {
            CertificateFilePath = Constants.CertificatePfx,
            ImageFilePath = Constants.ImageHandwrite,
            // skip password specification
            //Password = "123456780"
        };
        // sign document to file
        signature.Sign("signed.xlsx", options);
    }
}
catch (GroupDocsSignatureException ex)
{
    Console.WriteLine("GroupDocs Signature Exception: " + ex.Message);
}
catch (Exception ex)
{
    Console.WriteLine("System Exception: " + ex.Message);
}
```

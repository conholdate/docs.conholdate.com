<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> para especificar distintas configuraciones para la firma digital

* certificado digital (archivo en disco local <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatefilepath/" target="_blank" rel="nofollow noopener noreferrer">CertificateFilePath</a> o flujo <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatestream/" target="_blank" rel="nofollow noopener noreferrer">CertificateStream</a>) (obligatorio)
* contraseña del certificado digital <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/password/" target="_blank" rel="nofollow noopener noreferrer">Password</a> (obligatoria)
* detalles de la firma digital (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/reason/" target="_blank" rel="nofollow noopener noreferrer">Reason</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/contact/" target="_blank" rel="nofollow noopener noreferrer">Contact</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/location/" target="_blank" rel="nofollow noopener noreferrer">Location</a>)
* imagen de firma como apariencia de la firma digital en la página del documento (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/imagefilepath" target="_blank" rel="nofollow noopener noreferrer">ImageFilePath</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/imagestream" target="_blank" rel="nofollow noopener noreferrer">ImageStream</a>)
* apariencia de la firma de imagen en la página del documento (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/horizontalalignment" target="_blank" rel="nofollow noopener noreferrer">Alignment</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions/margin" target="_blank" rel="nofollow noopener noreferrer">Margin</a>, etc.)

A continuación se indican los pasos para agregar una firma digital a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> con el certificado requerido y su contraseña.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo agregar una firma digital a un documento. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // initialize digital option with certificate file path
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",
        // image as digital certificate appearance on document pages
        ImageFilePath = "sample.jpg",
        //
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() {  Bottom = 10, Right = 10},
    };
    signature.Sign("signed.pdf", options);
}
```

### Agregar información de Validación a Largo Plazo (LTV) (Long-Term Validation) para una firma {#add-long-term-validation-ltv-long-term-validation-information-for-a-signature}

¿Qué es la Validación a Largo Plazo (LTV) para firmas digitales?

La Validación a Largo Plazo (LTV, por sus siglas en inglés: Long-Term Validation) es un método utilizado para garantizar la validez continua de las firmas digitales a lo largo del tiempo, incluso después de que el certificado de firma haya caducado o sido revocado. LTV incrusta información adicional dentro del documento firmado, como el estado de revocación del certificado, la marca de tiempo y la cadena de certificados, lo que permite a cualquier persona que verifique la firma en el futuro determinar su autenticidad, incluso si el certificado original ya no está disponible.

¿Por qué es importante la LTV?

Las firmas digitales dependen de certificados que tienen fechas de caducidad. Una vez que el certificado de firma caduca o es revocado, la firma ya podría considerarse inválida. Sin embargo, muchos escenarios legales, financieros y regulatorios exigen que los documentos permanezcan válidos durante años o incluso décadas. La LTV resuelve este problema al incrustar directamente los datos de validación dentro del documento firmado, garantizando que la autenticidad de la firma pueda verificarse en cualquier momento en el futuro.

A continuación se muestra un ejemplo de cómo implementar la Validación a Largo Plazo (LTV) para un documento PDF utilizando GroupDocs.Signature:

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // initialize digital option with certificate file path
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // certifiate password
        Password = "1234567890",
        // digital certificate details
        Reason = "Sign",
        Contact = "JohnSmith",
        Location = "Office1",
        AllPages = true,
        Width = 80,
        Height = 60,
        VerticalAlignment = VerticalAlignment.Bottom,
        HorizontalAlignment = HorizontalAlignment.Right,
        Margin = new Padding() {Bottom = 10, Right = 10},
        
        // Enable Long-Term Validation (LTV) to ensure signature validity over time
        UseLtv = true
    };
    signature.Sign("signed.pdf", options);
}
```

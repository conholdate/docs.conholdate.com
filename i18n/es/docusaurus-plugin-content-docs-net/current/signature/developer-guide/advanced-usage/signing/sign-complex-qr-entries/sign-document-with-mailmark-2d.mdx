<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mailmark2d/mailmark2d" target="_blank" rel="nofollow noopener noreferrer">Mailmark2D</a> para crear códigos de barras 2D Royal Mail Mailmark. Estos códigos de barras pueden almacenar diversos datos, incluyendo información sobre el remitente, destinatario, franqueo y destino. El uso de códigos de barras Mailmark 2D permite un seguimiento más preciso y detallado de los artículos postales a lo largo de su recorrido en el sistema postal.

A continuación se indican los pasos para agregar una firma de código de barras Mailmark2D a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mailmark2d/mailmark2d/" target="_blank" rel="nofollow noopener noreferrer">Mailmark2D</a> con todas las opciones adicionales requeridas.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> con todas las opciones adicionales requeridas y asignar el objeto Mailmark2D a la propiedad Data.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> como argumento.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>, si es necesario, para verificar las firmas recién creadas.  

Este ejemplo muestra cómo agregar una firma Mailmark2D a un documento. Se utiliza la enumeración <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/mailmark2dtype/" target="_blank" rel="nofollow noopener noreferrer">Mailmark2DType</a> para especificar el tipo de código de barras 2D, lo cual determina la forma del código de barras:

![Types](/net/signature/images/mailmark2dtype.png)

```csharp
using (Signature signature = new Signature(filePath))
{
    // create Mailmark2D data object
    Mailmark2D mailmark2D = new Mailmark2D()
    {
        UPUCountryID = "JGB ",
        InformationTypeID = "0",
        Class = "1",
        SupplyChainID = 123,
        ItemID = 1234,
        DestinationPostCodeAndDPS = "QWE1",
        RTSFlag = "0",
        ReturnToSenderPostCode = "QWE2",
        DataMatrixType = Mailmark2DType.Type_7,
        CustomerContentEncodeMode = DataMatrixEncodeMode.C40,
        CustomerContent = "CUSTOM"
    };

    // create options
    QrCodeSignOptions options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 100,
        // setup Data property to Mailmark2D instance
        Data = mailmark2D
    };

    // sign document to file
    var signResult = signature.Sign(outputFilePath, options);
            
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

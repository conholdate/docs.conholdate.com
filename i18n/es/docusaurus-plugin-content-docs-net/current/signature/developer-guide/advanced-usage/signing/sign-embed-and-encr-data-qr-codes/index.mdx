GroupDocs.Signature permite incluir texto cifrado dentro de una firma de código QR o incrustar objetos de datos personalizados. Esta funcionalidad se implementa mediante serialización y cifrado de datos. Asimismo, ofrece la posibilidad de proporcionar serialización y cifrado personalizados para proteger de forma óptima los datos de su firma. A continuación se presenta un resumen de esta funcionalidad:

* Posibilidad de cifrar el texto de la firma de código QR
* Posibilidad de incrustar entradas estándar de código QR (como correo electrónico, tarjeta de visita V-Card, URL web, dirección)
* Posibilidad de incrustar objetos personalizados en firmas de código QR con cifrado de datos
* Posibilidad de especificar el cifrado de objetos personalizados
* Posibilidad de implementar serialización de datos personalizada

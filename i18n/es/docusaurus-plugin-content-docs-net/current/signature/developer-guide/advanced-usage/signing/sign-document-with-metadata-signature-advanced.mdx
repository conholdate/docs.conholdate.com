<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de proteger las firmas de metadatos, así como incrustar objetos de datos dentro de ellas. Estas funcionalidades se implementan mediante serialización y cifrado de datos. Asimismo, permite especificar serialización y cifrado personalizados para proteger de la forma más segura posible los datos de su firma. A continuación se presenta un resumen de las características:

* Capacidad para cifrar los valores de tipo cadena de las firmas de metadatos
* Capacidad para incrustar objetos personalizados dentro de firmas de metadatos con cifrado de datos
* Capacidad para especificar el cifrado de objetos personalizados
* Capacidad para implementar serialización de datos personalizada

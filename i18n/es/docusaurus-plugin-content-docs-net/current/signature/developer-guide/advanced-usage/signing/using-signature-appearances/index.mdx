GroupDocs.Signature incluye varias clases de apariencia de firma que implementan representaciones especiales de firma orientadas a documentos.

Las opciones básicas de firma <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> contienen la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a>, la cual espera una instancia de las siguientes clases:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextannotationappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextAnnotationAppearance</a>: clase que implementa la firma para documentos PDF como un área de anotación. Nótese que la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> debe establecerse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Annotation</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdftextstickerappearance" target="_blank" rel="nofollow noopener noreferrer">PdfTextStickerAppearance</a>: clase que implementa la firma para documentos PDF como una pequeña etiqueta adhesiva. Nótese que la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> debe establecerse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.Sticker</a>.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a>: clase que extiende cualquier firma basada en imagen con distintos ajustes de imagen (como escala de grises, contraste, brillo, correcciones, borde, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/digitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatureAppearance</a>: clase que extiende las apariencias de firma digital para documentos de procesamiento de textos y hojas de cálculo como una línea de información en el encabezado de la página.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/pdfdigitalsignatureappearance" target="_blank" rel="nofollow noopener noreferrer">PdfDigitalSignatureAppearance</a>: clase que extiende las apariencias de firma digital para documentos PDF, permitiendo ajustar etiquetas y colores.

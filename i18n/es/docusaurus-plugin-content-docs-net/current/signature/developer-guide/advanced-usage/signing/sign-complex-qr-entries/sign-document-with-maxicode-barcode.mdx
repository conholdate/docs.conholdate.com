<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/maxicodemode2/" target="_blank" rel="nofollow noopener noreferrer">MaxiCodeMode2</a> para crear códigos de barras MaxiCode, diseñados para el seguimiento y la gestión del envío de paquetes

A continuación se indican los pasos para agregar una firma de código de barras MaxiCode a un documento mediante .NET GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain.extensions/maxicodemode2/" target="_blank" rel="nofollow noopener noreferrer">MaxiCodeMode2</a>. Rellenar las propiedades
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> con todas las opciones adicionales requeridas y asignar el objeto HIBCLICCombinedData a la propiedad Data.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> como argumento.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>, si es necesario, para verificar las firmas recién creadas.  

Este ejemplo muestra cómo agregar una firma HIBCPASData a un documento mediante C#:

```csharp
using (Signature signature = new Signature(filePath))
{
    var data = new MaxiCodeMode2()
    {
        PostalCode = "524032140",
        CountryCode = 056,
        ServiceCategory = 999,
        SecondMessage = new MaxiCodeSecondMessage()
        {
            Message = "Test message"
        }
    };

    // create options
    QrCodeSignOptions options = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 100,        
        Data = data
    };

    // sign document to file
    var signResult = signature.Sign(outputFilePath, options);
            
    // analyzing result
    Console.WriteLine("List of newly created signatures:");
    int number = 1;
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"Signature #{number++}: Type: {temp.SignatureType} Id:{temp.SignatureId}, Location: {temp.Left}x{temp.Top}. Size: {temp.Width}x{temp.Height}");
    }
 }
```

Este ejemplo muestra cómo decodificar la firma MaxiCodeMode2 desde el documento utilizando C#:
```csharp
using (Signature.Signature signature = new Signature.Signature(outputFilePath))
{
    List<QrCodeSignature> signatures = signature.Search<QrCodeSignature>(SignatureType.QrCode);
    QrCodeSignature qrCode = signatures.FirstOrDefault();
    var data = qrCode.GetData<MaxiCodeMode2>();
}

```

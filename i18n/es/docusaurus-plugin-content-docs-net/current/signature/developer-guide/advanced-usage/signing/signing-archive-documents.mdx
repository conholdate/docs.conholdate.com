<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite firmar archivos de archivo con formatos como ZIP, TAR, 7Z, LZ y GZIP de la misma manera que los documentos normales. La única diferencia en la <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> del método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> radica en que, para archivos de archivo, contendrá listas de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/succeeded" target="_blank" rel="nofollow noopener noreferrer">Succeeded</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/failed" target="_blank" rel="nofollow noopener noreferrer">Failed</a> firmas como una lista de instancias de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/documentresultsignature/" target="_blank" rel="nofollow noopener noreferrer">DocumentResultSignature</a>.

A continuación se presentan los pasos para firmar archivos de archivo como ZIP, TAR, 7z, LZ y GZIP con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del archivo de origen o un flujo del archivo como parámetro del constructor.
* Instanciar un único objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> o una lista de esta clase con las opciones requeridas.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a>.
* Las opciones de firma pasadas se aplicarán a todos los documentos contenidos dentro del archivo.
* Analizar la respuesta <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> a través de las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/succeeded" target="_blank" rel="nofollow noopener noreferrer">Succeeded</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult/failed" target="_blank" rel="nofollow noopener noreferrer">Failed</a>, las cuales contienen instancias de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/documentresultsignature/" target="_blank" rel="nofollow noopener noreferrer">DocumentResultSignature</a>.

## Firmar documento de archivo {#sign-archive-document}

Este ejemplo muestra cómo firmar un documento de archivo con varias opciones de firma (SignOptions).

```csharp
/// <summary>
/// Support Succeeded and Failed list as result of processing archives
/// </summary>
using (var signature = new Signature("sample.zip"))
{
    // create sign options
    var options = new TextSignOptions("signed!")
    {
        // set signature position
        Left = 100,
        Top = 100
    };
    // sign archive to new zip file
    SignResult result = signature.Sign("output.zip", options);
    // analyze signed documents
    foreach (DocumentResultSignature document in result.Succeeded)
    {
        Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
    }

        foreach (DocumentResultSignature document in result.Failed)
        {
            Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
        }
    }
}
```

## Firmar documentos de archivo de un solo archivo {#sign-single-file-archive-documents}
Los formatos LZ y GZIP comprimen archivos individuales en archivos de un solo archivo, optimizándolos para almacenamiento y transmisión.


:::note
El nombre del archivo de archivo debe coincidir con el nombre del archivo contenido.
:::


Este ejemplo muestra cómo firmar un documento de archivo GZIP con `SignOptions`.

```csharp
using (Signature signature = new Signature("sample.pdf.gz"))
{
    // create sign options
    TextSignOptions options = new TextSignOptions("signed!")
    {
        // set signature position
        Left = 100,
        Top = 100
    };
    // sign archive to new zip file
    SignResult result = signature.Sign("output.pdf.gz", options);
    // analyze signed documents
    foreach (DocumentResultSignature document in result.Succeeded)
    {
        Console.WriteLine($"Document {document.FileName}. Processed: {document.ProcessingTime}, mls");
    }
}
```

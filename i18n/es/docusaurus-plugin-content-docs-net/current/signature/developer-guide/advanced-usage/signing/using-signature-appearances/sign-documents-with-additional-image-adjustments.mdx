<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> contiene la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> que implementa ajustes adicionales para la imagen, como

* escala de grises (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/grayscale" target="_blank" rel="nofollow noopener noreferrer">Grayscale</a>)
* brillo (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/brightness" target="_blank" rel="nofollow noopener noreferrer">Brightness</a>)
* contraste (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/contrast" target="_blank" rel="nofollow noopener noreferrer">Contrast</a>)
* corrección gamma (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/gammacorrection" target="_blank" rel="nofollow noopener noreferrer">GammaCorrection</a>)
* borde (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance/border" target="_blank" rel="nofollow noopener noreferrer">Border</a>)

La clase base de firma <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> tiene la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">Appearance</a>, la cual debe configurarse con una instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> para proporcionar ajustes adicionales de la imagen

A continuación se indican los pasos para configurar la apariencia adicional de la imagen con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Construir un objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a> con todas las opciones adicionales requeridas.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions/appearance" target="_blank" rel="nofollow noopener noreferrer">SignOptions.Appearance</a> con el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options.appearances/imageappearance" target="_blank" rel="nofollow noopener noreferrer">ImageAppearance</a>.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a>.
* Analizar el resultado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.

## Firmar documento con apariencia de imagen {#sign-document-with-image-appearance}

Este ejemplo muestra cómo especificar apariencias adicionales de la imagen. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    ImageSignOptions options = new ImageSignOptions("sample.jpg")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // setup image additional appearance as Brightness and Border
        Appearance = new ImageAppearance()
        {
            Grayscale = true,
            Contrast = 0.2f,
            GammaCorrection = 0.3f,
            Brightness = 0.9f,
            Border = new Border()
            {
                Color = Color.DarkGreen,
                DashStyle = DashStyle.DashLongDashDot,
                Transparency = 0.5,
                Visible = true,
                Weight = 2
            }
        }
    };
    // sign document to file
    signature.Sign("signed.pdf", options);
}
```

## Firmar documento PDF con una firma de texto y apariencia de adhesivo {#sign-pdf-document-with-text-signature-sticker-appearance}

Este ejemplo muestra cómo agregar una firma de texto a un documento PDF con apariencia de adhesivo. Consulte <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a>

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // setup proper signature implementation
        SignatureImplementation = TextSignatureImplementation.Sticker,
        Appearance = new PdfTextStickerAppearance()
        {
            // select sticker icon
            Icon = PdfTextStickerIcon.Star,
            // setup if popup annotation will be opened by default
            Opened = false,
            // text content of an annotation
            Contents = "Sample",
            Subject = "Sample subject",
            Title = "Sample Title"
        },
        // set signature alignment
        VerticalAlignment = Domain.VerticalAlignment.Bottom,
        HorizontalAlignment = Domain.HorizontalAlignment.Right,
        Margin = new Padding() { Bottom = 20, Right = 20 },
        // set text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" },
    };
    // sign document to file
    signature.Sign("signed.docx", options);
}
```

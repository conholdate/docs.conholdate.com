Las opciones de firma base <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> contienen la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pagessetup/" target="_blank" rel="nofollow noopener noreferrer">SignOptions.PagesSetup</a>, que permite configurar números de página específicos.

Este ejemplo muestra cómo firmar páginas específicas en un documento TIFF multipágina mediante la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pagessetup/pagenumbers/" target="_blank" rel="nofollow noopener noreferrer">PagesSetup.PageNumbers</a> de valores enteros.

```csharp
using (var signature = new Signature("multipage.tiff"))
{
    var options = new QrCodeSignOptions("Patient #36363393. R: No-Issues")
    {
        // set signature position 
        Left = 10,
        Top = 10,
        // set signature rectangle
        Width = 200,
        Height = 200,
        //specify pages numbers which we want to sign
        PagesSetup = new PagesSetup()
        {
            PageNumbers = new List<int> { 1, 3 }
        }
    };

    // sign document to file
    SignResult signResult = signature.Sign(outputFilePath, options);
    Console.WriteLine($"\nDocument signed with {signResult.Succeeded.Count} signatures");
    Console.WriteLine("\nList of newly created signatures:");
    foreach (BaseSignature temp in signResult.Succeeded)
    {
        Console.WriteLine($"{temp.SignatureType} at page #{temp.PageNumber}: Id:{temp.SignatureId}.");
    }
}
```

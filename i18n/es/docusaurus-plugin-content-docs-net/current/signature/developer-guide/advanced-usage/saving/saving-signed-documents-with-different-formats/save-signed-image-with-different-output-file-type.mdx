<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite el guardado de documentos de imagen firmados en diferentes formatos. Cada tipo de documento tiene una lista de tipos de guardado compatibles. Estos valores se enumeran en una enumeración. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesavefileformat" target="_blank" rel="nofollow noopener noreferrer">ImageSaveFileFormat</a>.

Aquí están los pasos para guardar un documento de imagen firmado en diferentes tipos de salida con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> objeto según sus requisitos y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> como uno de los valores predefinidos de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesavefileformat" target="_blank" rel="nofollow noopener noreferrer">ImageSaveFileFormat</a>.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesaveoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> a él.

El siguiente ejemplo demuestra cómo guardar un documento de imagen firmado con diferentes tipos de salida

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    ImageSaveOptions saveOptions = new ImageSaveOptions()
    {
        FileFormat = ImageSaveFileFormat.Svg,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("signed.svg", signOptions, saveOptions);
}
```

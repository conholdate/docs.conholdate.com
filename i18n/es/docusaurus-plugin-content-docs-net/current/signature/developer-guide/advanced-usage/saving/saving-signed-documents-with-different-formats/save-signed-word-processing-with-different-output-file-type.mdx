<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite el guardado de documentos de procesamiento de texto firmados en distintos formatos. Cada tipo de documento tiene una lista de formatos de guardado compatibles. Estos valores se enumeran en una enumeración. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingsavefileformat" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveFileFormat</a>.

Aquí tienes los pasos para guardar un documento de procesamiento de textos firmado en un tipo de salida diferente con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> objeto según sus requisitos y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> como uno de los valores predefinidos de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingsavefileformat" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveFileFormat</a>.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> objeto a ello.

El siguiente ejemplo demuestra cómo guardar un documento de procesamiento de texto firmado con diferentes tipos de salida.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions()
    {
        FileFormat = WordProcessingSaveFileFormat.Odt,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedDocx.odt", signOptions, saveOptions);
}
```

<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite el guardado de documentos de hojas de cálculo firmados con distintos tipos de archivo de salida. Cada tipo de documento tiene una lista de tipos de guardado compatibles. Estos valores se enumeran en la enumeración. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetsavefileformat" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveFileFormat.</a>

Aquí están los pasos para guardar un documento de hoja de cálculo firmado en un tipo de salida diferente con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveOptions</a> objeto según sus requisitos y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> como uno de los valores predefinidos de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetsavefileformat" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveFileFormat</a>.  

* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/spreadsheetsaveoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetSaveOptions</a> objeto a ello.

El siguiente ejemplo demuestra cómo guardar un documento de hoja de cálculo firmado con diferentes tipos de salida.

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    SpreadsheetSaveOptions saveOptions = new SpreadsheetSaveOptions()
    {
        FileFormat = SpreadsheetSaveFileFormat.Pdf,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedXlsx.pdf", signOptions, saveOptions);
}
```

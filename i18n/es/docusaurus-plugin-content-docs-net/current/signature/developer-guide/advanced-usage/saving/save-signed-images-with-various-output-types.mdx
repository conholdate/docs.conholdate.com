<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite el guardado de documentos firmados con imágenes en varios formatos de imagen y opciones extendidas.

Las siguientes clases heredan de la clase base <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> y permite especificar configuraciones adicionales para el formato de la imagen de salida.

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/bmpsaveoptions" target="_blank" rel="nofollow noopener noreferrer">BmpSaveOptions</a> La clase permite guardar un documento de imagen firmado en el formato de imagen **BMP** y configurar opciones adicionales (como compresión, resoluciones, bits por píxel, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/gifsaveoptions" target="_blank" rel="nofollow noopener noreferrer">GifSaveOptions</a> La clase permite guardar un documento de imagen firmado en el formato de imagen **GIF** y configurar opciones adicionales (como compresión, resoluciones, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/jpegsaveoptions" target="_blank" rel="nofollow noopener noreferrer">JpegSaveOptions</a> La clase permite guardar el documento de imagen firmado en el formato de imagen **JPEG** y configurar opciones adicionales (como compresión, resoluciones, calidad, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pngsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PngSaveOptions</a> La clase permite guardar un documento de imagen firmado en el formato de imagen **PNG** y configurar opciones adicionales (como profundidad de bits, tipo de color, compresión, filtros, etc.).
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/tiffsaveoptions" target="_blank" rel="nofollow noopener noreferrer">TiffSaveOptions</a> La clase permite guardar un documento de imagen firmado en el formato de imagen **TIFF** y configurar opciones adicionales.

A continuación se presentan los pasos para guardar un documento de imagen firmado en un tipo de salida de imagen especial con configuraciones adicionales utilizando GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar una de las clases requeridas de opciones de guardado de formato de imagen <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/bmpsaveoptions" target="_blank" rel="nofollow noopener noreferrer">BmpSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/gifsaveoptions" target="_blank" rel="nofollow noopener noreferrer">GifSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/jpegsaveoptions" target="_blank" rel="nofollow noopener noreferrer">JpegSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pngsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PngSaveOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/tiffsaveoptions" target="_blank" rel="nofollow noopener noreferrer">TiffSaveOptions</a> objeto según sus requisitos y especifique sus propiedades.  

* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> objeto a ello.

## Guardar imagen firmada como BMP {#save-signed-image-as-bmp}

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create Bmp save options with advanced settings
    saveOptions = new BmpSaveOptions()
    {
        AddMissingExtension = true,
        Compression = BitmapCompression.Rgb,
        HorizontalResolution = 7,
        VerticalResolution = 7,
        BitsPerPixel = 16,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("signedSample", signOptions, saveOptions);
}
```

## Guardar imagen firmada como JPEG {#save-signed-image-as-jpeg}

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100
    };
    SaveOptions saveOptions;
    // create Jpeg save options with advanced settings
    saveOptions = new JpegSaveOptions()
    {
        AddMissingExtension = true,
        BitsPerChannel = 8,
        ColorType = JpegCompressionColorMode.Rgb,
        Comment = "signed jpeg file",
        CompressionType = JpegCompressionMode.Lossless,
        Quality = 100,
        SampleRoundingMode = JpegRoundingMode.Extrapolate
    };
    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

## Guardar imagen firmada como PNG {#save-signed-image-as-png}

```csharp
using (Signature signature = new Signature("sample.jpg"))
{
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR, Left = 100, Top = 100

    // create png save options with advanced settings
    saveOptions = new PngSaveOptions()
    {
        AddMissingExtension = true,
        BitDepth = 8,
        ColorType = PngColorType.Grayscale,

        FilterType = PngFilterType.Adaptive,

    // sign document to file
    signature.Sign("SignedSample", signOptions, saveOptions);
}
```

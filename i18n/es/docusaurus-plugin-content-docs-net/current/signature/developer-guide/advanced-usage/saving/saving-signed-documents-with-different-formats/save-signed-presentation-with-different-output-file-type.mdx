<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase `supports` permite guardar documentos de presentación firmados en diferentes formatos. Cada tipo de documento tiene una lista de formatos de guardado compatibles. Estos valores se enumeran en una enumeración (`enum`). <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveFileFormat</a>.

Aquí tienes los pasos para guardar el documento de presentación firmado en un tipo de salida diferente con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>  clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> objeto según sus requisitos y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> como uno de los valores predefinidos de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveFileFormat</a>.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PresentationSaveOptions</a> [](https://reference.groupdocs.com/signature/net/groupdocs.signature.options/presentationsaveoptions) objeto a él.

El siguiente ejemplo demuestra cómo guardar un documento de presentación firmado con diferentes tipos de salida.

```csharp
using (Signature signature = new Signature("sample.ppsx"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QRCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    PresentationSaveOptions saveOptions = new PresentationSaveOptions()
    {
        FileFormat = PresentationSaveFileFormat.Tiff,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedPPsx", signOptions, saveOptions);
}
```

### Cómo proteger un documento PDF con permisos {#how-to-secure-pdf-document-with-permissions}

La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> admite el guardado de documentos firmados con configuraciones de permisos y protección por contraseña para acceso y modificación. Esta funcionalidad se logra mediante las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissionspassword/" target="_blank" rel="nofollow noopener noreferrer">PermissionsPassword</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a>, las cuales deben pasarse al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>.

Puede proteger un documento PDF configurando los siguientes parámetros:
* Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta o el flujo del documento de origen como parámetro del constructor.
* Instancie las opciones de firma requeridas.
* Instancie el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> y especifique la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissionspassword" target="_blank" rel="nofollow noopener noreferrer">PermissionsPassword</a> (opcional). Configure <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/property" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> para controlar las acciones del usuario (por ejemplo, denegar la impresión o la modificación).
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase las opciones de firma y el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> a este.

El siguiente ejemplo demuestra cómo guardar un documento firmado con permisos.

```csharp
// Using the Signature class to create a signature for the specified PDF document
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions textSignOptions = new TextSignOptions("JohnSmith")
    {
        Left = 0,
        Top = 100,
        Width = 100,
        Height = 100,
        AllPages = true,
        ForeColor = Color.Black
    };

    // Create a new PdfSaveOptions object to configure the PDF save settings
    PdfSaveOptions saveOptions = new PdfSaveOptions();
    saveOptions.OverwriteExistingFiles = false;
    // Set permissions to deny printing and modification
    saveOptions.Permissions = Permissions.DenyPrinting | Permissions.DenyModification;
    // Set a password for modifying permissions(optional)
    saveOptions.PermissionsPassword = "0987654321";
    // Sign the document and save the result to a new file
    signature.Sign("result.pdf", textSignOptions, saveOptions);
}
```

### Cómo cargar un documento PDF con permisos {#how-to-load-pdf-document-with-permissions}

La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> admite la carga de documentos con permisos específicos que se conservan tras la firma. Esta funcionalidad se gestiona mediante la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>, donde la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> se establece al cargar el documento. Estos permisos permanecen aplicados en el documento firmado, garantizando restricciones coherentes desde la carga hasta la salida final guardada, cuando se pasa al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a>.

Para cargar un documento PDF con permisos y asegurar que dichos permisos se conserven durante todo el proceso de firma, siga estos pasos:
* Cree una nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>, configurando la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/permissions/" target="_blank" rel="nofollow noopener noreferrer">Permissions</a> para establecer restricciones (por ejemplo, denegar impresión, modificación o extracción de datos).
* Utilice esta instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> para inicializar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> con la ruta del documento o el flujo.
* Instancie las opciones de firma requeridas (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a>) para configurar la posición y la apariencia de la firma.
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>, pasando las opciones de firma. El documento conservará los permisos especificados en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/loadoptions/" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>, garantizando que cualquier restricción aplicada durante la carga se conserve en el documento firmado.

El siguiente ejemplo demuestra cómo cargar un documento PDF con permisos. 

```csharp
// Set up load options with specific permissions, denying all actions (printing, modification, extraction)
LoadOptions loadOptions = new LoadOptions()
{
    Permissions = Permissions.DenyAll
};

// Using the Signature class to create a signature for the specified PDF document
using (Signature signature = new Signature("sample.pdf", loadOptions))
{
    TextSignOptions textSignOptions = new TextSignOptions("JohnSmith")
    {
        Left = 0,
        Top = 100,
        Width = 100,
        Height = 100
    };
    
    signature.Sign("result.pdf", textSignOptions);
}
```

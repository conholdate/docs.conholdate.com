<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite el guardado de documentos PDF firmados en distintos formatos. Cada tipo de documento tiene una lista de formatos de guardado compatibles. Estos valores se enumeran en una enumeración. <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PdfSaveFileFormat</a>.

Aquí están los pasos para guardar el documento PDF firmado en diferentes tipos de salida con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>  clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> objeto según sus requisitos y especifique <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> como uno de los valores predefinidos de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfsavefileformat" target="_blank" rel="nofollow noopener noreferrer">PdfSaveFileFormat</a>.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/pdfsaveoptions" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> objeto a ello.

El siguiente ejemplo demuestra cómo guardar un documento PDF firmado con diferentes tipos de salida.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QRCodeTypes.QR,
        Left = 100,
        Top = 100
    };
    PdfSaveOptions pdfSaveOptions = new PdfSaveOptions()
    {
        FileFormat = PdfSaveFileFormat.DocX,
        OverwriteExistingFiles = true
    };
    // sign document to file
    signature.Sign("SignedPdf.docx", signOptions, pdfSaveOptions);
}
```

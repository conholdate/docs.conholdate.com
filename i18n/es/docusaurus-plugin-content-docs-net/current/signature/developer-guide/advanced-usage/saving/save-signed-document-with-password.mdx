<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase admite guardar documentos firmados con protección por contraseña. Esta funcionalidad está disponible a través de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> propiedad de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> clase que debe pasarse a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método.

Aquí tienes los pasos para proteger un documento firmado con contraseña con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o el flujo como parámetro del constructor.
* Instanciar las opciones de firma requeridas.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> objeto y especificar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> propiedad con contraseña requerida de tipo cadena.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar `signatureoptions` y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> objeto a ello.

El siguiente ejemplo demuestra cómo guardar un documento firmado con contraseña.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions signOptions = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QrCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    SaveOptions saveOptions = new SaveOptions()
    {
        Password = "1234567890",
        UseOriginalPassword = false
    };
    // sign document to file
    signature.Sign("SignedProtected.pdf", signOptions, saveOptions);
}
```

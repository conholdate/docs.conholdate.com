Algunas herramientas descendentes de OOXML solo admiten niveles de cumplimiento específicos. Por ejemplo, <a href="https://github.com/plutext/docx4j/issues/321" target="_blank" rel="nofollow noopener noreferrer">Docx4j</a> no lee la salida en formato ISO/IEC 29500:2008 Strict, por lo que los consumidores que dependen de dichas bibliotecas necesitan que el documento firmado se genere en formato Transitional (o ECMA-376) en su lugar.

A partir de GroupDocs.Signature para .NET 26.6, el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> La clase conserva el nivel de cumplimiento con OOXML del documento de procesamiento de texto de origen al guardarlo, y le permite anularlo mediante <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a>.

## Cómo se maneja la conformidad con OOXML {#how-ooxml-compliance-is-handled}

* La fuente `OoxmlCompliance` El valor se detecta al cargar el documento y se conserva al guardar de forma predeterminada.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> expone un valor nullable `OoxmlCompliance` propiedad.
  * `null` (predeterminado): mantener el cumplimiento del documento cargado.
  * `set`: sobrescribe el valor de origen con el nivel de cumplimiento especificado.
* Solo se otorga por los formatos de salida de OOXML: `Docx`, `Docm`, `Dotx`, `Dotm` y sus `FlatOpc` variantes.

## Niveles de cumplimiento admitidos {#supported-compliance-levels}

El `OoxmlCompliance` `enum` define los niveles que puedes solicitar al guardar:

```csharp
public enum OoxmlCompliance
{
    /// <summary>Specifies ECMA-376 compliance level.</summary>
    Ecma,
    /// <summary>Specifies ISO/IEC 29500:2008 Transitional compliance level.</summary>
    Transitional,
    /// <summary>Specifies ISO/IEC 29500:2008 Strict compliance level.</summary>
    Strict
}
```

## Pasos para anular el cumplimiento de OOXML al guardar {#steps-to-override-ooxml-compliance-on-save}

* Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta o secuencia del documento de origen como parámetro del constructor.
* Instancie las opciones de firma requeridas (por ejemplo, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a>).
* Instancie <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/wordprocessingsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">WordProcessingSaveOptions</a> y establezca la propiedad `OoxmlCompliance` en el nivel requerido (`Ecma`, `Transitional` o `Strict`).
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase las opciones de firma y el objeto `WordProcessingSaveOptions` a este.

## Ejemplo: forzar ISO/IEC 29500:2008 Strict al guardar {#example-force-iso-iec-29500-2008-strict-on-save}

```csharp
using (Signature signature = new Signature(filePath))
{
    TextSignOptions signOptions = new TextSignOptions("John Smith")
    {
        Left = 100,
        Top = 100,
        Width = 200,
        Height = 60
    };

    // Force ISO 29500:2008 Strict on save regardless of the source's compliance.
    // Other allowed values: OoxmlCompliance.Ecma, OoxmlCompliance.Transitional.
    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(WordProcessingSaveFileFormat.Docx)
    {
        OoxmlCompliance = OoxmlCompliance.Strict
    };

    SignResult result = signature.Sign(outputFilePath, signOptions, saveOptions);
}
```

## Ejemplo: guardar como Transicional para compatibilidad descendente {#example-save-as-transitional-for-downstream-compatibility}

Utilice `OoxmlCompliance.Transitional` cuando el consumidor del documento firmado solo lea DOCX en formato ISO/IEC 29500:2008 Transicional (o ECMA-376), por ejemplo, cuando el archivo será procesado posteriormente por una biblioteca que no admite el formato estricto.

```csharp
using (Signature signature = new Signature(filePath))
{
    TextSignOptions signOptions = new TextSignOptions("John Smith")
    {
        Left = 100,
        Top = 100,
        Width = 200,
        Height = 60
    };

    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(WordProcessingSaveFileFormat.Docx)
    {
        OoxmlCompliance = OoxmlCompliance.Transitional
    };

    signature.Sign(outputFilePath, signOptions, saveOptions);
}
```

## Ejemplo: conservar el nivel de cumplimiento del documento de origen {#example-keep-the-source-document-s-compliance}

Deje `OoxmlCompliance` sin establecer (o establezca explícitamente `null`) para conservar el nivel de cumplimiento en el que se redactó el documento cargado.

```csharp
using (Signature signature = new Signature(filePath))
{
    TextSignOptions signOptions = new TextSignOptions("John Smith")
    {
        Left = 100,
        Top = 100,
        Width = 200,
        Height = 60
    };

    // OoxmlCompliance not set => source compliance is preserved on save.
    WordProcessingSaveOptions saveOptions = new WordProcessingSaveOptions(WordProcessingSaveFileFormat.Docx);

    signature.Sign(outputFilePath, signOptions, saveOptions);
}
```

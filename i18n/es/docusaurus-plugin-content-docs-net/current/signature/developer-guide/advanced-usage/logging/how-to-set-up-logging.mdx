De forma predeterminada, el registro (logging) está deshabilitado al procesar documentos; sin embargo, el producto proporciona una forma de guardar el registro mediante una implementación integrada que permite guardar eventos en la consola y en archivos.

Existe una interfaz que podemos utilizar:

* <a href="https://reference.groupdocs.com/net/signature/groupdocs.signature.logging/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> – define la interfaz para registrar distintos eventos del proceso, como errores, advertencias y mensajes de información (trazas).

Existen clases que podemos utilizar:

* <a href="https://reference.groupdocs.com/net/signature/groupdocs.signature.logging/consolelogger" target="_blank" rel="nofollow noopener noreferrer">ConsoleLogger</a> – define los métodos necesarios para registrar en la consola.
* <a href="https://reference.groupdocs.com/net/signature/groupdocs.signature.logging/filelogger" target="_blank" rel="nofollow noopener noreferrer">FileLogger</a> – define los métodos necesarios para registrar en archivos.

Existen 3 tipos de mensajes en el archivo de registro:

* **Error** – para excepciones no recuperables
* **Advertencia** – para excepciones recuperables, esperadas o conocidas
* **Trazaza (Trace)** – para información general

## Registro en archivo {#logging-to-file}

En este ejemplo, registraremos en un archivo, por lo que necesitaremos utilizar la clase <a href="https://reference.groupdocs.com/net/signature/groupdocs.signature.logging/filelogger" target="_blank" rel="nofollow noopener noreferrer">FileLogger</a>.

```csharp
// Create logger and specify the output file
FileLogger fileLogger = new FileLogger("output.log");

// Create SignatureSettings and specify FileLogger
var settings = new SignatureSettings(fileLogger);

using (var signature = new Signature("sample.docx", settings))
{
    var options = new QrCodeSignOptions("JohnSmith");
    // sign document to file
    signature.Sign(outputFilePath, options);
}
```

## Registro en consola {#logging-to-console}

En este ejemplo, registraremos en la consola, por lo que necesitamos utilizar la clase <a href="https://reference.groupdocs.com/net/signature/groupdocs.signature.logging/consolelogger" target="_blank" rel="nofollow noopener noreferrer">ConsoleLogger</a>.

```csharp
// Create logger and specify the output file
var consoleLogger = new ConsoleLogger();

// Create SignatureSettings and specify ConsoleLogger instance
var settings = new SignatureSettings(consoleLogger);

using (var signature = new Signature("sample.docx", settings))
{
    var options = new QrCodeSignOptions("JohnSmith");
    // sign document to file
    signature.Sign(outputFilePath, options);
}
```

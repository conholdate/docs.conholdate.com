## Vista general {#overview}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite obtener información del documento, la cual incluye:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a>
* Dimensiones de las páginas: <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pageinfo/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pageinfo/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> para cada página en la colección <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/idocumentinfo/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> del documento.

## Obtener información del documento desde un archivo en el disco local {#get-document-information-from-file-on-local-disk}

El siguiente fragmento de código demuestra cómo obtener información sobre un documento almacenado en el disco local.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    IDocumentInfo documentInfo = signature.GetDocumentInfo();
    Console.WriteLine("Document properties {0}:", Path.GetFileName("sample.pdf"));
    Console.WriteLine(" - format : {0}", documentInfo.FileType.FileFormat);
    Console.WriteLine(" - extension : {0}", documentInfo.FileType.Extension);
    Console.WriteLine(" - size : {0}", documentInfo.Size);
    Console.WriteLine(" - page count : {0}", documentInfo.PageCount);
    foreach(PageInfo pageInfo in documentInfo.Pages)
    {
        Console.WriteLine(" - page-{0} Width {1}, Height {2}", pageInfo.PageNumber, pageInfo.Width, pageInfo.Height);
    }
}
```

## Obtener información del documento a partir de un flujo {#get-document-information-from-a-stream}

El siguiente fragmento de código demuestra cómo obtener información sobre un documento proporcionado como un flujo.

```csharp
string filePath = "sample.pdf";
using (var stream = File.OpenRead(filePath))
{
    using (Signature signature = new Signature(stream))
    {
        IDocumentInfo documentInfo = signature.GetDocumentInfo();
        Console.WriteLine("Document properties {0}:", Path.GetFileName(filePath));
        Console.WriteLine(" - format : {0}", documentInfo.FileType.FileFormat);
        Console.WriteLine(" - extension : {0}", documentInfo.FileType.Extension);
        Console.WriteLine(" - size : {0}", documentInfo.Size);
        Console.WriteLine(" - page count : {0}", documentInfo.PageCount);
        foreach (PageInfo pageInfo in documentInfo.Pages)
        {
            Console.WriteLine(" - page-{0} Width {1}, Height {2}", pageInfo.PageNumber, pageInfo.Width, pageInfo.Height);
        }
    }
}
```

## Información general {#overview}

Con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>, puede obtener la [lista de formatos de archivo](/net/signature/getting-started/supported-document-formats/) que permiten agregar firmas electrónicas siguiendo los pasos a continuación:

* Llamar a la función estática <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>;
* Recorrer la colección de objetos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente ejemplo de código muestra cómo obtener la lista de formatos de archivo admitidos.

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
    .GetSupportedFileTypes()
    .OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
    Console.WriteLine(fileType);
```

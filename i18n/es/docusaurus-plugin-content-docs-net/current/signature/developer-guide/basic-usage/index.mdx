<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs Signature**</a> proporciona la capacidad de manipular distintos tipos de firmas electrónicas, como texto, imagen, digital, código de barras, código QR, sello, campo de formulario y metadatos. Estas firmas electrónicas pueden añadirse a un documento, actualizarse, eliminarse, verificarse o buscarse dentro de documentos ya firmados. Asimismo, nuestro producto ofrece información sobre el tipo y estructura del documento: tipo de archivo, tamaño, número de páginas, etc., y genera una vista previa de las páginas del documento según las opciones proporcionadas.  

A continuación se presentan los conceptos principales de la API de GroupDocs Signature:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> es la clase principal que contiene todos los métodos necesarios para manipular las firmas electrónicas de un documento.
* La mayor parte de los métodos espera distintas opciones para firmar electrónicamente un documento, verificarlo y buscar firmas electrónicas dentro del mismo.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> implementa la interfaz <a href="https://docs.microsoft.com/en-us/dotnet/api/system.idisposable" target="_blank" rel="nofollow noopener noreferrer">IDisposable</a> para liberar correctamente los recursos utilizados —por ejemplo, cerrar de forma segura los flujos de documentos una vez finalizadas todas las operaciones.

## Referencia a los espacios de nombres necesarios {#referencing-required-namespaces}

El siguiente código muestra cómo incluir el espacio de nombres necesario para todos los ejemplos de código.

```csharp
using GroupDocs.Signature;
using GroupDocs.Signature.Domain;
using GroupDocs.Signature.Options;
using GroupDocs.Signature.Domain.Extensions;
```  

## Definición del objeto Signature {#signature-object-definition}

El siguiente código muestra el patrón más utilizado para definir el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y llamar a sus métodos.  

```csharp
// Sign document with text signature.
using (Signature signature = new Signature("sample.docx"))
{
   TextSignOptions textSignOptions = new TextSignOptions("John Smith");
   signature.Sign("SampleSigned.docx", textSignOptions);
}
```

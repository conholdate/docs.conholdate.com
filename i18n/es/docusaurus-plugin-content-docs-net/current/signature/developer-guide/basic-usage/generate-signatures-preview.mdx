## Vista general {#overview}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewsignatureoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewSignatureOptions</a> clase para especificar distintas opciones para gestionar el proceso de generación de la vista previa de las firmas.  
  
A continuación se indican los pasos para generar una vista previa de la firma con GroupDocs.Signature:

* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/signoptions" target="_blank" rel="nofollow noopener noreferrer">SignOptions</a> requerido con la configuración deseada para generar la vista previa
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewsignatureoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewSignatureOptions</a> con:
* un delegado para la creación del flujo de la firma (véase el controlador de eventos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/createsignaturestream" target="_blank" rel="nofollow noopener noreferrer">CreateSignatureStream</a>);
* el formato de vista previa de imagen: PNG / JPG / BMP,
* un identificador único de la firma.


:::info
Los flujos creados por el delegado <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/createsignaturestream" target="_blank" rel="nofollow noopener noreferrer">CreateSignatureStream</a> se liberarán automáticamente tras la generación de la imagen de vista previa. Si necesita implementar la liberación personalizada del flujo de vista previa de imagen, debe pasar el argumento adicional <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/releasesignaturestream" target="_blank" rel="nofollow noopener noreferrer">ReleaseSignatureStream</a> para limpiar los recursos.
:::

* Llame al método estático <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/generatesignaturepreview" target="_blank" rel="nofollow noopener noreferrer">GenerateSignaturePreview</a> de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/previewsignatureoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewSignatureOptions</a> como argumento.

## Generar vista previa de la firma {#generate-signature-preview}

Este ejemplo muestra cómo generar una imagen de vista previa para una firma de código QR utilizando GroupDocs.Signature con tamaños predeterminados.

```csharp
public static void GetPreview()
{
    // Create QR code sign options
    QrCodeSignOptions signOptions = new QrCodeSignOptions
    {
        EncodeType = QrCodeTypes.QR,
        Data = new GroupDocs.Signature.Domain.Extensions.Address
        {
            Street = "221B Baker Street",
            City = "London",
            State = "NW",
            ZIP = "NW16XE",
            Country = "England"
        },
        HorizontalAlignment = HorizontalAlignment.Left,
        VerticalAlignment = VerticalAlignment.Center,
        Margin = new Padding(10)
    };

    // Create signature preview options
    PreviewSignatureOptions previewOption = new PreviewSignatureOptions(
        signOptions, 
        CreateSignatureStream, 
        ReleaseSignatureStream
    )
    {
        SignatureId = Guid.NewGuid().ToString(),
        PreviewFormat = PreviewSignatureOptions.PreviewFormats.JPEG
    };

    // Generate signature preview
    Signature.GenerateSignaturePreview(previewOption);
}

private static Stream CreateSignatureStream(PreviewSignatureOptions previewOptions)
{
    string imageFilePath = 
        $"signature-{previewOptions.SignatureId}-" +
        $"{previewOptions.SignOptions.GetType().Name}.jpg";

    return new FileStream(imageFilePath, FileMode.Create);
}

private static void ReleaseSignatureStream(PreviewSignatureOptions previewOptions, 
    Stream signatureStream)
{
    signatureStream.Dispose();
    Console.WriteLine(
        $"Signature {previewOptions.SignatureId}-" +
        $"{previewOptions.SignOptions.GetType().Name} is ready for preview"
    );
}
```

##  Renderizado adaptativo para las vistas previas de firmas de código QR {#adaptive-rendering-for-qr-code-signature-previews}


:::info
Si el ancho y la altura especificados no son adecuados para generar una vista previa legible del código QR, el sistema utilizará automáticamente valores predeterminados de tamaño. Estos valores predeterminados se eligen como las dimensiones óptimas más cercanas para garantizar que el código QR siga siendo claro y escaneable.
:::


Este ejemplo demuestra cómo generar una imagen de vista previa para una firma de código QR utilizando GroupDocs.Signature. Verá cómo configurar la apariencia del código QR, incluyendo su tamaño, color y alineación del texto, así como cómo generar y guardar el flujo de la imagen de vista previa.

```csharp
public static void GetPreview()
{
    // Initialize QR Code signing options
    QrCodeSignOptions qrSignOptions = new QrCodeSignOptions("GROUP DOCS", QrCodeTypes.QR)
    {
        Width = 250,                          // Width of the QR code
        Height = 270,                         // Height of the QR code
        ForeColor = Color.Red,                // Color of the QR code
        CodeTextAlignment = CodeTextAlignment.Below, // Text alignment relative to the QR code
        Text = "GROUP DOCS"                   // Text displayed below the QR code
    };

    // Configure preview generation options for the QR code signature
    PreviewSignatureOptions previewOptions = new PreviewSignatureOptions(
        qrSignOptions,
        CreateSignatureStream,   // Delegate to create the stream
        ReleaseSignatureStream   // Delegate to release the stream
    )
    {
        SignatureId = Guid.NewGuid().ToString(),  // Unique identifier for the preview
        PreviewFormat = PreviewSignatureOptions.PreviewFormats.PNG  // Output format of preview
    };

    // Generate the signature preview image
    Signature.GenerateSignaturePreview(previewOptions);
}

private static Stream CreateSignatureStream(PreviewSignatureOptions previewOptions)
{
    string imageFilePath = 
        $"signature-{previewOptions.SignatureId}-" +
        $"{previewOptions.SignOptions.GetType().Name}.jpg";

    return new FileStream(imageFilePath, FileMode.Create);
}

private static void ReleaseSignatureStream(PreviewSignatureOptions previewOptions, 
    Stream signatureStream)
{
    signatureStream.Dispose();
    Console.WriteLine(
        $"Signature {previewOptions.SignatureId}-" +
        $"{previewOptions.SignOptions.GetType().Name} is ready for preview"
    );
}
```

Cuando el ancho y la altura proporcionados para la vista previa del código de barras no son adecuados, la generación de la vista previa recurrirá a los valores predeterminados de tamaño. Estos valores predeterminados se seleccionan para producir una imagen de código de barras que sea legible y se renderice correctamente.
:::


Esta sección muestra cómo crear una vista previa para una firma de código de barras. El ejemplo cubre la configuración de propiedades del código de barras, como tipo, tamaño y color, así como la generación de la imagen de vista previa mediante un controlador de flujo personalizado.

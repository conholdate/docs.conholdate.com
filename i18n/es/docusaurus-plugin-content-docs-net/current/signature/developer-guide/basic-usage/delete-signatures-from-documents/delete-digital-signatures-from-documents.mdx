## Resumen {#overview}
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignature</a> Clase para manipular firmas electrónicas digitales y eliminarlas de los documentos.
Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> el método modifica el mismo documento que se pasó al constructor de la <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase.

*Información importante*. Tenga en cuenta que los documentos firmados digitalmente con certificados válidos (archivos .pfx) están protegidos y verificados. Modificar un documento firmado digitalmente lo vuelve no confiable desde la perspectiva de la verificación digital. En este momento, solo los documentos PDF admiten la eliminación de firmas digitales específicas en caso de que se hayan agregado varias. La mayoría de los documentos admiten la eliminación de todas las firmas digitales a la vez, sin necesidad de eliminar certificados por separado. Se recomienda encarecidamente utilizar la eliminación de firmas digitales electrónicas por tipo de firma: **Digital**. Consulte el ejemplo [Eliminar firmas de un tipo determinado].

## Cómo eliminar la firma digital de un documento {#how-to-delete-digital-signature-from-the-document}
Aquí están los pasos para eliminar la firma digital del documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pase la ruta del documento de origen o su flujo como parámetro del constructor;
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> objeto con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalSignature</a> objeto(s) que deben eliminarse del documento;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/delete" target="_blank" rel="nofollow noopener noreferrer">Delete</a> método y pase una o varias firmas a él.

Este ejemplo muestra cómo eliminar una firma digital que se encontró utilizando <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // Search for electronic Digital signatures in the document
    List<DigitalSignature> signatures = 
        signature.Search<DigitalSignature>(SignatureType.Digital);

    if (signatures.Count > 0)
    {
        DigitalSignature digitalSignature = signatures[0];
        bool result = signature.Delete(digitalSignature);

        if (result)
        {
            Console.WriteLine(
                $"Digital signature #{digitalSignature.Thumbprint} from " +
                $"{digitalSignature.SignTime.ToShortDateString()} was deleted."
            );
        }
        else
        {
            Console.WriteLine(
                $"Signature was not deleted from the document! " +
                $"Signature# {digitalSignature.Thumbprint} was not found!"
            );
        }
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> Clase para manipular la ubicación, el tamaño y el contenido textual de las firmas de código de barras.
Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase.

Aquí están los pasos para actualizar la firma de código de barras en el documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> objeto con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagesignature" target="_blank" rel="nofollow noopener noreferrer">ImageSignature</a> objeto(s) que deben actualizarse;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método y pasarle una o varias firmas.  

Este ejemplo muestra cómo actualizar la firma de imagen que se encontró utilizando  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    ImageSearchOptions options = new ImageSearchOptions();
    // search for image signatures in document
    List<ImageSignature> signatures = signature.Search<ImageSignature>(options);
    if(signatures.Count > 0)
    {
        ImageSignature imageSignature = signatures[0];
        // change Image properties
        signatureToUpdate.Top = 200;
        signatureToUpdate.Left = 200;
        signatureToUpdate.Width = 300;
        signatureToUpdate.Height = 150;

        bool result = signature.Update(imageSignature);
        if (result)
        {
            Console.WriteLine(
                $"Signature with Top '{imageSignature.Top}' " +
                $"was updated in the document ['{fileName}']."
            );
        }
        else
        {
            Console.WriteLine(
                $"Signature was not updated in the document! " +
                $"Signature with Top '{imageSignature.Top}' was not found!"
            );
        }
    }
}
```

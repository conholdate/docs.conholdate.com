<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> Clase para manipular la ubicación, el tamaño y el contenido textual de las firmas.  
Tenga en cuenta que <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> El método modifica el mismo documento que se pasó al constructor de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase.

Aquí están los pasos para actualizar la firma de texto en el documento con GroupDocs.Signature:

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor;
* Instanciar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> objeto con las propiedades deseadas;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método para obtener la lista de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignatures</a>;
* Seleccionar de la lista <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignature" target="_blank" rel="nofollow noopener noreferrer">TextSignature</a> objeto(s) que deben actualizarse;
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/update/" target="_blank" rel="nofollow noopener noreferrer">Update</a> método y pasarle una o varias firmas.

Este ejemplo muestra cómo actualizar una firma de texto que se encontró utilizando  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> método.

```csharp
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    TextSearchOptions options = new TextSearchOptions();
    // search for text signatures in document
    List<TextSignature> signatures = signature.Search<TextSignature>(options);
    if(signatures.Count > 0)
    {
        TextSignature textSignature = signatures[0];
        // change Text property
        textSignature.Text = "John Walkman";
        // change position
        textSignature.Left = textSignature.Left + 10;
        textSignature.Top = textSignature.Top + 10;
        // change size. Please note not all documents support changing signature size
        textSignature.Width = 200;
        textSignature.Height = 100;
        bool result = signature.Update(textSignature);
       if (result)
       {
           Console.WriteLine(
               $"Signature with Text '{textSignature.Text}' " +
               $"was updated in the document ['{fileName}']."
           );
       }
       else
       {
           Console.WriteLine(
               $"Signature was not updated in the document! " +
               $"Signature with Text '{textSignature.Text}' was not found!"
           );
       }
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textverifyoptions" target="_blank" rel="nofollow noopener noreferrer">TextVerifyOptions</a> para especificar distintas opciones para la verificación de firmas de texto.

A continuación se indican los pasos para verificar una firma de texto dentro de un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textverifyoptions" target="_blank" rel="nofollow noopener noreferrer">TextVerifyOptions</a> según sus necesidades y especificar las opciones de verificación.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textverifyoptions" target="_blank" rel="nofollow noopener noreferrer">TextVerifyOptions</a> como argumento.

Este ejemplo muestra cómo verificar una firma de texto en un documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextVerifyOptions options = new TextVerifyOptions()
    {
        AllPages = true, // this value is set by default
        SignatureImplementation = TextSignatureImplementation.Stamp,
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    // verify document signatures
    VerificationResult result = signature.Verify(options);
    if(result.IsValid)
    {
        Console.WriteLine("\nDocument was verified successfully!");
    }
    else
    {
        Console.WriteLine("\nDocument failed verification process.");
    }
}
```

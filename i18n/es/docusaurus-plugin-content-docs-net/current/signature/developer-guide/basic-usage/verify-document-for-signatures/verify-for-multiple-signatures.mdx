## Vista general {#overview}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite verificar documentos para distintos tipos de firmas. Este enfoque requiere agregar todas las opciones de verificación necesarias a una lista.

A continuación se indican los pasos para verificar un documento que contiene múltiples firmas mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar como parámetro del constructor la ruta del documento de origen o un flujo (stream).
* Instanciar varios objetos <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a> (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodeverifyoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalverifyoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalVerifyOptions</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textverifyoptions" target="_blank" rel="nofollow noopener noreferrer">TextVerifyOptions</a>) y agregar las instancias a la colección List&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a>&gt;.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/verify" target="_blank" rel="nofollow noopener noreferrer">Verify</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle la lista rellenada de List&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/verifyoptions" target="_blank" rel="nofollow noopener noreferrer">VerifyOptions</a>&gt;.

Este ejemplo muestra cómo buscar distintos tipos de firmas en un documento.

```csharp
using (Signature signature = new Signature("sampleSigned.pdf"))
{
    TextVerifyOptions textVerifyOptions = new TextVerifyOptions()
    {
        AllPages = true, // this value is set by default
        SignatureImplementation = TextSignatureImplementation.Stamp,
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    BarcodeVerifyOptions barcVerifyOptions = new BarcodeVerifyOptions()
    {
        AllPages = true, // this value is set by default
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    QrCodeVerifyOptions qrcdVerifyOptions = new QrCodeVerifyOptions()
    {
        AllPages = true, // this value is set by default
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    DigitalVerifyOptions digtVerifyOptions = new DigitalVerifyOptions("certificate.pdf")
    {
        Comments = "Test comment"
    };
    // verify document signatures
    List<VerifyOptions> listOptions = new List<VerifyOptions>();
    listOptions.Add(textVerifyOptions);
    listOptions.Add(barcVerifyOptions);
    listOptions.Add(qrcdVerifyOptions);
    listOptions.Add(digtVerifyOptions);
    VerificationResult result = signature.Verify(listOptions);
    if (result.IsValid)
    {
        Console.WriteLine("\nDocument was verified successfully!");
    }
    else
    {
        Console.WriteLine("\nDocument failed verification process.");
    }
}
```

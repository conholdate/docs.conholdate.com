## ¿Qué es un metadato? {#what-is-a-metadata}

Un **metadato** es información sobre un recurso u otros datos. Desde la perspectiva del documento, un **metadato** constituye una **capa oculta del documento** que contiene un mapa basado en diccionario con nombres únicos y sus valores correspondientes. El nombre del metadato es una cadena de caracteres única, y el valor del metadato puede contener diversos tipos de datos, como valores enteros, decimales, matrices de datos, cadenas, etc. Cada tipo de documento tiene una especificación personalizada de metadatos, con registros predefinidos y filas de metadatos personalizables.

Los metadatos resumidos pueden contener la siguiente información, como una firma electrónica:

* Información descriptiva sobre el firmante del documento, los destinatarios y los remitentes. Entradas personalizadas sobre título, asunto, autor, herramientas y palabras clave;
* Cálculos ocultos del documento, estadísticas y metadatos de referencia sobre el contenido y la calidad;
* Metadatos personalizados que contienen cualquier objeto serializado como cadena y codificado en el valor del metadato.

Las notas siguientes especifican las diferencias entre los distintos tipos de documento desde la perspectiva de los metadatos:

* La capa de metadatos de documentos PDF admite nombres predeterminados para describir la información resumida del documento. Cada fila de metadatos es única según su nombre y su prefijo, lo que permite personalizar el uso de los metadatos. El identificador único del metadato tiene la forma de un par **<a href="http://tagname" target="_blank" rel="nofollow noopener noreferrer">etiqueta:nombre</a>**, al que se asigna un valor de forma predeterminada.
* Los documentos de procesamiento de textos (formatos de Microsoft Office Word: DOC, DOCX, RTF, y formatos de Open Office: ODT, OTT) contienen una capa de metadatos estándar predefinida y una colección de metadatos personalizables.
* Los documentos de hojas de cálculo (formatos de Microsoft Office Excel: XLSX, XLS y formatos de Open Office: OTS, ODS) almacenan colecciones de metadatos estándar y personalizables similares.
* Los documentos de presentación siguen el mismo patrón que los documentos de procesamiento de textos y hojas de cálculo.
* Los metadatos de las imágenes se distinguen por un identificador numérico entero, no por nombre. La mayoría de los intervalos de identificadores están registrados para mantener información estándar o personalizada sobre metadatos de imágenes, como información del creador, proveedor de origen, ubicación geográfica, etc.

GroupDocs.Signature permite almacenar en los metadatos y extraer de nuevo cualquier objeto de datos definido por el usuario, con serialización y cifrado personalizados posteriores. Este mecanismo permite incrustar y transferir en el documento información oculta y segura a través de comparticiones públicas, sin preocupaciones sobre la privacidad personalizada de dicha información oculta.

## ¿Cómo firmar electrónicamente un documento con una firma de metadatos? {#how-to-esign-document-with-metadata-signature}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> para especificar distintas opciones para la firma de metadatos. La firma electrónica como metadato permite almacenar cualquier tipo de valor u objetos definidos por el usuario, y recuperar dichos datos mediante métodos de búsqueda.  
Distintos formatos de documento implementan los metadatos de manera propia. Los formatos de documentos de oficina, como hojas de cálculo, procesamiento de textos y presentaciones, proporcionan propiedades de metadatos como pares *"nombre-valor"*. Los documentos PDF aportan un prefijo adicional de atributo. Los documentos de imagen implementan propiedades de metadatos como una lista de pares *"identificador-valor"*. Cada formato de documento requiere un nombre o identificador único de metadato (para imágenes).

La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> contiene una lista de objetos MetadataSignature para insertar o actualizar en el documento.  
Los metadatos del documento pueden almacenar una gran cantidad de datos, lo que permite guardar objetos personalizados serializados, con cifrado adicional, dentro del documento.

A continuación se indican los pasos para agregar firmas de metadatos a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> según sus necesidades.
* Instanciar una o varias firmas de metadatos (objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignature" target="_blank" rel="nofollow noopener noreferrer">MetadataSignature</a>) utilizando la clase correspondiente a cada tipo de documento.
* para hojas de cálculo, usar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMetadataSignature</a>;
* para procesamiento de textos, usar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">WordProcessingMetadataSignature</a>;
* para presentaciones, usar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PresentationMetadataSignature</a>;
* para PDF, usar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PdfMetadataSignature</a>;
* para imágenes, usar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagemetadatasignature" target="_blank" rel="nofollow noopener noreferrer">ImageMetadataSignature</a>.
* Agregar los objetos de firma de metadatos inicializados a la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a> de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a>;
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a>.

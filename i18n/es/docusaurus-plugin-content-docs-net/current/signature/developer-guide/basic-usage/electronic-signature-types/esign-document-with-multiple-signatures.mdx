<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite firmar un documento con varias firmas simultáneamente e incluso aplicar firmas de distintos tipos al mismo documento.

Hacer esto es tan sencillo como:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta o el flujo del documento de origen como parámetro del constructor.
* Instanciar todos los objetos de opciones de firma requeridos según el tipo de firma:
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> - for Barcode signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> - for Digital signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> - for Form-field signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> - for Image signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> - for Metadata signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> - for QR-code signatures
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/stampsignoptions" target="_blank" rel="nofollow noopener noreferrer">StampSIgnOptions</a> - for Stamp signatures;
    * <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> - for Text signatures.
* Rellene la colección con las opciones de firma del paso anterior.
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la colección de opciones de firma como argumento.

El fragmento de código siguiente muestra cómo firmar electrónicamente un documento PDF con múltiples firmas al mismo tiempo.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // define several signature options of different types and settings
    TextSignOptions textOptions = new TextSignOptions("This is test message")
    {
        VerticalAlignment = VerticalAlignment.Top,
        HorizontalAlignment = HorizontalAlignment.Left
    };

    BarcodeSignOptions barcodeOptions = new BarcodeSignOptions("123456")
    {
        EncodeType = BarcodeTypes.Code128,
        Left = 100,
        Top = 100
    };
    QrCodeSignOptions qrcodeOptions = new QrCodeSignOptions("JohnSmith")
    {
        EncodeType = QrCodeTypes.QR,
        Left = 100,
        Top = 200
    };
    DigitalSignOptions digitalOptions = new DigitalSignOptions("certificate.pfx")
    {
        ImageFilePath = Constants.ImageHandwrite,
        VerticalAlignment = VerticalAlignment.Center,
        HorizontalAlignment = HorizontalAlignment.Center,
        Password = "1234567890"
    };
    // define list of signature options
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(textOptions);
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrcodeOptions);
    listOptions.Add(digitalOptions);

    // sign document to file
    signature.Sign("signed.pdf", listOptions);
}    
```
### Resumen {#summary}
Esta guía muestra cómo aplicar múltiples tipos de firmas electrónicas (por ejemplo, texto, código de barras, imagen) a un documento mediante **GroupDocs.Signature**. Explica cómo combinar distintos tipos de firmas, configurar cada una y guardar el documento firmado con múltiples estilos de firma.

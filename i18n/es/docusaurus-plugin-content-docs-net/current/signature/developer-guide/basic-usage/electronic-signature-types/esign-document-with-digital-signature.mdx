## Introducción {#introduction}

En la era digital actual, garantizar la autenticidad y la integridad de los documentos electrónicos es fundamental. Un método altamente eficaz para lograrlo es el uso de firmas digitales. En esta guía exploraremos el mundo de las firmas digitales, explicando qué son, por qué son esenciales y cómo puede utilizar GroupDocs.Signature para firmar electrónicamente sus documentos de forma sencilla.

## ¿Qué es una firma digital? {#what-is-a-digital-signature}

Una firma digital es un mecanismo criptográfico utilizado para verificar la autenticidad y la integridad de los documentos electrónicos. Proporciona una garantía sólida de que el documento proviene de un remitente conocido y no ha sido modificado por fuentes no autorizadas. Las firmas digitales suelen representarse mediante certificados que contienen claves privadas (para firmar) y públicas (para verificar). Para este propósito se utilizan comúnmente diversos estándares de criptografía de clave pública, como el formato PFX.
La imagen siguiente muestra cómo se ve una firma digital en una página de documento PDF de forma predeterminada.

![Digital](/net/signature/images/esign-document-with-digital-signature.png)

## ¿Por qué utilizar firmas digitales? {#why-use-digital-signatures}

- **Seguridad mejorada:** Las firmas digitales ofrecen un nivel superior de seguridad para los documentos, lo que hace extremadamente difícil que terceros no autorizados modifiquen su contenido.
- **Autenticación:** Permiten verificar de forma fiable la identidad del remitente del documento.
- **No repudio:** Impiden que el remitente niegue la autenticidad del documento firmado.


## Cómo firmar un documento con una firma digital {#how-to-sign-a-document-with-a-digital-signature}

**<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Signature</a>** admite la creación de firmas digitales basadas en certificados PFX existentes. Para especificar diversas configuraciones, la biblioteca proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a>, que permite ajustar las propiedades de la firma digital en el documento:

* Las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatefilepath/" target="_blank" rel="nofollow noopener noreferrer">FilePath</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/certificatestream/" target="_blank" rel="nofollow noopener noreferrer">Stream</a> definen el origen del certificado;
* La propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/password/" target="_blank" rel="nofollow noopener noreferrer">password</a> especifica la contraseña del certificado;
* Las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/contact/" target="_blank" rel="nofollow noopener noreferrer">Contact</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/reason/" target="_blank" rel="nofollow noopener noreferrer">Reason</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/location/" target="_blank" rel="nofollow noopener noreferrer">Location</a> especifican descripciones adicionales;
* La propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/visible/" target="_blank" rel="nofollow noopener noreferrer">Visible</a> indica si la firma debe mostrarse visible en la página del documento o no;
* La propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/xadestype/" target="_blank" rel="nofollow noopener noreferrer">XAdES type</a> define si la firma electrónica debe ser del tipo Firma Electrónica Avanzada XML (XAdES).

### Siga estos pasos para firmar sus documentos con una firma digital {#follow-these-steps-to-sign-your-documents-with-a-digital-signature}

1. Instale el paquete <a href="https://www.nuget.org/packages/groupdocs.signature" target="_blank" rel="nofollow noopener noreferrer">NuGet package</a> de GroupDocs.Signature en su aplicación .NET.
2. Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta del documento de origen como parámetro al constructor.
3. Instancie el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> con el certificado y su contraseña correspondientes.
4. Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsignoptions/" target="_blank" rel="nofollow noopener noreferrer">DigitalSignOptions</a> como argumento.

El ejemplo siguiente muestra cómo firmar un documento PDF con una firma electrónica digital utilizando el lenguaje C#. De igual forma, se puede firmar cualquier otro formato de documento admitido.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // initialize digital option with certificate file path
    DigitalSignOptions options = new DigitalSignOptions("certificate.pfx")
    {
        // optional: setup image file path
        ImageFilePath = "sample.jpg",

        // set signature position
        Left = 100,
        Top = 100,

        // set
        Password = "1234567890"
    };
    signature.Sign("sampleSigned.pdf", options);
}
```

## ¿Qué es un código de barras? {#what-is-a-barcode}

Un **código de barras** o **bar code** es una forma de presentar datos en un formato visual legible por máquinas. En términos generales, un código de barras es una imagen de forma rectangular que consta de líneas negras paralelas y espacios blancos de diferentes anchos.  
Los códigos de barras se utilizan en diversas áreas donde se requiere una identificación rápida: como parte del proceso de compra en tiendas minoristas, en almacenes para rastrear el inventario, y en facturas para facilitar la contabilidad, entre muchos otros usos.

![Barcode](/net/signature/images/esign-document-with-barcode-signature.gif)

Los códigos de barras permiten almacenar datos relacionados con productos, como fechas de fabricación y caducidad, nombre del fabricante, país de origen y precio del producto. Actualmente existen numerosos tipos de códigos de barras, ya que distintas empresas utilizan distintas combinaciones de números y barras según sus necesidades. En lo que respecta a la firma del documento, el código de barras puede contener distintos caracteres (letras, dígitos o símbolos) y puede tener diversas longitudes y tamaños, dependiendo del tipo y de la configuración, para almacenar información de firma, título, asunto o datos breves cifrados.  

## Cómo firmar un documento electrónicamente con una firma de código de barras {#how-to-esign-document-with-barcode-signature}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> admite una amplia gama de tipos de códigos de barras que se pueden utilizar para crear firmas electrónicas dentro de los documentos. Consulte el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/barcodetypes/#fields" target="_blank" rel="nofollow noopener noreferrer">BarcodeTypes</a> descripción para obtener la lista completa de códigos de barras admitidos.  
Para especificar diferentes opciones para la firma de código de barras, GroupDocs.Signature para .NET proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> clase. Los campos principales son:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions/encodetype" target="_blank" rel="nofollow noopener noreferrer">EncodeType</a> - especifica el tipo de código de barras (AustralianPost, Codabar, EAN13, OPC, etc.);
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> - especifica el texto del código de barras.


Aquí están los pasos para firmar electrónicamente un documento con una firma de código de barras utilizando la API de GroupDocs.Signature para .NET:
* Crear una nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> objeto según sus requisitos y especifique el tipo de código de barras configurando el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions/encodetype" target="_blank" rel="nofollow noopener noreferrer">EncodeType</a> propiedad con uno de los tipos predefinidos admitidos. Establezca el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> valor de la propiedad.
* Llame a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de la <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase de instancia y pasar la <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSignOptions</a> a él.

Este ejemplo muestra cómo firmar un documento PDF con una firma de código de barras.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    BarcodeSignOptions options = new BarcodeSignOptions("JohnSmith")
    {
        // setup Barcode encoding type
        EncodeType = BarcodeTypes.Code128,
        // set signature position
        Left = 100,
        Top = 100
    };
    signature.Sign("SampleSigned.pdf", options);
}
```

## Resumen {#overview}
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">WordProcessingMetadataSignature</a> clase para especificar diferentes objetos de firma de metadatos para <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> instancia para firmar archivos de documentos de procesamiento de texto.
Los metadatos de documentos de procesamiento de texto son atributos ocultos, algunos de los cuales solo son visibles al ver las propiedades estándar del documento, como Autor, Fecha de creación, Productor, Entrada, Palabras clave, etc.  
Los metadatos de un documento de procesamiento de texto contienen un par de nombre y valor, y el nombre debe ser único dentro del documento.  
Los metadatos de documentos de procesamiento de texto podrían contener una gran cantidad de datos, lo que permite almacenar objetos personalizados serializados, junto con cifrado adicional.

### Aquí tienes los pasos para agregar firmas de metadatos en un documento de procesamiento de texto con GroupDocs.Signature: {#here-are-the-steps-to-add-metadata-signatures-into-word-processing-document-with-groupdocs-signature}

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> objeto según sus requisitos.
* Instanciar uno o varios<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/wordprocessingmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">WordProcessingMetadataSignature</a> objetos y agregarlos a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a la colección de firmas de metadatos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a>) vía <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/addrange" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a él.

## Cómo firmar electrónicamente un documento de procesamiento de texto con una firma de metadatos {#how-to-esign-word-processing-document-with-metadata-signature}

Este ejemplo muestra cómo firmar un documento de procesamiento de texto con una firma electrónica basada en metadatos.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    MetadataSignOptions options = new MetadataSignOptions();

    // Create few WordProcessing Metadata signatures
    WordProcessingMetadataSignature[] signatures = new WordProcessingMetadataSignature[]
    {
        new WordProcessingMetadataSignature("Author", "Mr.Scherlock Holmes"),
        new WordProcessingMetadataSignature("DateCreated", DateTime.Now),
        new WordProcessingMetadataSignature("DocumentId", 123456),
        new WordProcessingMetadataSignature("SignatureId", 123.456M)
    };
    options.Signatures.AddRange(signatures);
  
    // add these signatures to options
    options.Signatures.AddRange(signatures);
    signature.Sign("SampleSigned.docx", options);
}
```

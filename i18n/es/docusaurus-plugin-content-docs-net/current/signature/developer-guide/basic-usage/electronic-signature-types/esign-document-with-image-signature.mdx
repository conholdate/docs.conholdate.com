## ¿Qué es una firma de imagen? {#what-is-an-image-signature}

Una **firma de imagen** es una forma alternativa de representar cualquier dato presentado en un formato visual. Este tipo de firma electrónica permite crear imágenes personalizadas que incluyen el logotipo de la empresa, las iniciales del remitente, nombres, etc.

![Images](/net/signature/images/esign-document-with-image-signature.png)

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> para especificar distintas configuraciones para la firma de imagen, como el contenido de la imagen (desde archivo o flujo), ubicación, colores y efectos avanzados.

A continuación se indican los pasos para crear una firma de imagen en una página del documento:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a> según sus necesidades y especificar las opciones de la firma de imagen;
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSignOptions</a>.

## Cómo firmar electrónicamente un documento con una firma de imagen {#how-to-esign-document-with-image-signature}

Este ejemplo muestra cómo firmar un documento PDF con una firma de imagen.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    ImageSignOptions options = new ImageSignOptions("signature.jpg")
    {
        // set signature position
        Left = 100,
        Top = 100,
        //
        AllPages = true
    };
    signature.Sign("SampleSigned.pdf", options);
}
```

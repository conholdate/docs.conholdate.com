## ¿Qué es un código QR? {#what-is-a-qr-code}

El código QR (o *Quick Response code*, código de respuesta rápida) es un tipo de [código de barras](/net/signature/developer-guide/basic-usage/electronic-signature-types/esign-document-with-barcode-signature/) bidimensional compuesto por cuadrados negros dispuestos en una cuadrícula cuadrada sobre un fondo blanco. Los códigos QR pueden leerse mediante las cámaras de los smartphones o dispositivos especializados dedicados exclusivamente a la lectura de códigos QR, como escáneres portátiles, terminales móviles, escáneres de escritorio, escáneres integrados, entre otros. Por lo general, los códigos QR contienen datos que apuntan a un sitio web o aplicación, correos electrónicos, números de teléfono, identificadores de productos o rastreadores. Por lo tanto, el ámbito de aplicación de los códigos QR abarca desde el marketing general y la identificación de artículos hasta la gestión documental.

Al agregar una firma electrónica mediante código QR a un documento, las configuraciones principales son el texto que se codificará y el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/qrcodetypes/#fields" target="_blank" rel="nofollow noopener noreferrer">tipo del código QR</a>, los cuales deben especificarse mediante la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a>.  

A continuación se presentan los pasos para firmar electrónicamente un documento con una firma de código QR:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.

* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a> según sus requisitos y especificar las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions/encodetype" target="_blank" rel="nofollow noopener noreferrer">EncodeType</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>.
  
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesignoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSignOptions</a>.

El fragmento de código siguiente demuestra cómo firmar un documento PDF con una firma de código QR.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // create QRCode option with predefined QRCode text
    QrCodeSignOptions options = new QrCodeSignOptions("JohnSmith")
    {
        // setup QRCode encoding type
        EncodeType = QrCodeTypes.QR,
        // set signature position
        Left = 100,
        Top = 100
    };
    signature.Sign("SampleSigned.pdf", options);
}
```
### Resumen {#summary}
Esta guía muestra cómo agregar firmas de código QR a documentos mediante **GroupDocs.Signature**. Incluye pasos para generar una firma de código QR, configurar sus propiedades, como tamaño y codificación, y aplicarla a un documento. Las firmas de código QR pueden utilizarse para verificar rápidamente el documento firmado.

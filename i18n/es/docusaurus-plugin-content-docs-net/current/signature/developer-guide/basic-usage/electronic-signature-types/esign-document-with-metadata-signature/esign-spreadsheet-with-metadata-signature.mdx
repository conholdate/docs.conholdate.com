## Resumen {#overview}
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMetadataSignature</a> clase para especificar diferentes objetos de firma de metadatos para <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> instancia para firmar archivos de documentos de hojas de cálculo.
Los metadatos de documentos de hojas de cálculo son atributos ocultos, algunos de los cuales solo son visibles al ver las propiedades estándar del documento, como Autor, Fecha de creación, Productor, Entrada, Palabras clave, etc.  
Los metadatos de un documento de hoja de cálculo contienen un par de nombre y valor, donde el nombre debe ser único dentro del documento.  
Los metadatos de un documento de hoja de cálculo podrían contener una gran cantidad de datos, lo que permite almacenar objetos personalizados serializados, junto con cifrado adicional.

### Aquí tienes los pasos para agregar firmas de metadatos en un documento de hoja de cálculo con GroupDocs.Signature: {#here-are-the-steps-to-add-metadata-signatures-into-spreadsheet-document-with-groupdocs-signature}

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> objeto según sus requisitos.
* Instanciar uno o varios<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/spreadsheetmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetMetadataSignature</a> objetos y agregarlos a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a la colección de firmas de metadatos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a>) vía <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/addrange" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a él.

## Cómo firmar electrónicamente una hoja de cálculo con una firma de metadatos {#how-to-esign-spreadsheet-with-metadata-signature}

Este ejemplo muestra cómo agregar una firma electrónica de metadatos a un documento de hoja de cálculo.

```csharp
using (Signature signature = new Signature("sample.xlsx"))
{
    MetadataSignOptions options = new MetadataSignOptions();

    // Create few Spreadsheet Metadata signatures
    SpreadsheetMetadataSignature[] signatures = new SpreadsheetMetadataSignature[]
    {
        new SpreadsheetMetadataSignature("Author", "Mr.Scherlock Holmes"),
        new SpreadsheetMetadataSignature("DateCreated", DateTime.Now),
        new SpreadsheetMetadataSignature("DocumentId", 123456),
        new SpreadsheetMetadataSignature("SignatureId", 123.456M)
    };
  
    // add these signatures to options
    options.Signatures.AddRange(signatures);
    signature.Sign("SampleSigned.xlsx", options);
}
```

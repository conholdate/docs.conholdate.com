## Resumen {#overview}
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PresentationMetadataSignature</a> clase para especificar diferentes objetos de firma de metadatos para <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> instancia para firmar archivos de documentos de presentación.
Los metadatos del documento de presentación son atributos ocultos, algunos de los cuales solo son visibles al ver las propiedades estándar del documento, como Autor, Fecha de creación, Productor, Entrada, Palabras clave, etc.  
Los metadatos de presentación contienen un par de Nombre y Valor, y el Nombre debe ser único dentro del documento.  
Los metadatos del documento de presentación podrían contener una gran cantidad de datos que permiten almacenar objetos personalizados serializados, junto con cifrado adicional.

### Aquí están los pasos para agregar firmas de metadatos en un documento de presentación con GroupDocs.Signature: {#here-are-the-steps-to-add-metadata-signatures-into-presentation-document-with-groupdocs-signature}

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> objeto según sus requisitos.
* Instanciar uno o varios<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/presentationmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PresentationMetadataSignature</a> objetos y agregarlos a  <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a la colección de firmas de metadatos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a>) vía <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/addrange" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a él.

## Cómo firmar electrónicamente una presentación con una firma de metadatos {#how-to-esign-presentation-with-metadata-signature}

Este ejemplo muestra cómo agregar una firma de metadatos a un documento de presentación.

```csharp
using (Signature signature = new Signature("sample.ppsx"))
{
    MetadataSignOptions options = new MetadataSignOptions();

    // Create few Presentation Metadata signatures
    PresentationMetadataSignature[] signatures = new PresentationMetadataSignature[]
    {
        new PresentationMetadataSignature("Author", "Mr.Scherlock Holmes"),
        new PresentationMetadataSignature("DateCreated", DateTime.Now),
        new PresentationMetadataSignature("DocumentId", 123456),
        new PresentationMetadataSignature("SignatureId", 123.456M)
    };
    options.Signatures.AddRange(signatures);
    signature.Sign("SampleSigned.ppsx", options);
}
```

## ¿Qué es una firma digital de imagen? {#what-is-an-image-digital-signature}

Una **firma digital de imagen** utiliza **esteganografía** (técnica LSB: *Least Significant Bit*, o bit menos significativo) para incrustar firmas digitales directamente en los píxeles de imágenes rasterizadas. Este método permite agregar firmas invisibles y protegidas con contraseña a las imágenes, manteniendo la calidad visual del archivo. Los datos de la firma se incrustan en los bits menos significativos de los píxeles de la imagen, lo que hace que la firma sea indetectable a simple vista.

### Características principales {#key-features}

* **Firmas invisibles**: las firmas se incrustan directamente en los píxeles de la imagen mediante esteganografía
* **Protección con contraseña**: las firmas están protegidas mediante una contraseña (mínimo 4 caracteres)
* **Compatibilidad con formatos**: funciona con formatos de imagen PNG y JPG
* **Preservación de calidad**: la calidad de la imagen permanece prácticamente inalterada
* **Requisitos de tamaño**: las imágenes deben cumplir con requisitos mínimos de tamaño (8×8 píxeles, 16.384 píxeles en total)

## Requisitos {#requirements}

### Requisitos de tamaño de imagen {#image-size-requirements}

* **Anchura mínima**: 8 píxeles
* **Altura mínima**: 8 píxeles
* **Píxeles totales mínimos**: 16.384 píxeles (anchura × altura)

### Requisitos de contraseña {#password-requirements}

* **Longitud mínima**: 4 caracteres
* **Distingue mayúsculas y minúsculas**: sí
* **Caracteres especiales**: permitidos

### Formatos admitidos {#supported-formats}

* ✅ **PNG**: totalmente compatible
* ✅ **JPG/JPEG**: totalmente compatible
* ❌ **BMP**: no compatible para firmas digitales mediante esteganografía

## Cómo firmar digitalmente una imagen {#how-to-esign-image-with-digital-signature}

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagedigitalsignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageDigitalSignOptions</a> para especificar la configuración de las firmas digitales en imágenes mediante esteganografía.

A continuación se indican los pasos para firmar una imagen con una firma digital:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta de la imagen de origen como parámetro del constructor
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagedigitalsignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageDigitalSignOptions</a> y establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagedigitalsignoptions/password" target="_blank" rel="nofollow noopener noreferrer">Password</a> (mínimo 4 caracteres)
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagedigitalsignoptions" target="_blank" rel="nofollow noopener noreferrer">ImageDigitalSignOptions</a>

Este ejemplo muestra cómo firmar una imagen con una firma digital mediante esteganografía.

```csharp
using (Signature signature = new Signature("image.png"))
{
    // Create sign options with password
    ImageDigitalSignOptions signOptions = new ImageDigitalSignOptions
    {
        Password = "MySecurePassword123"
    };

    // Sign the image
    SignResult signResult = signature.Sign("signed_image.png", signOptions);
    
    Console.WriteLine($"Image signed successfully. Found {signResult.Succeeded.Count} signatures.");
}
```

### Firmar imágenes desde flujos {#signing-images-from-streams}

También puede firmar imágenes utilizando flujos en lugar de rutas de archivos:

```csharp
using (Stream inputStream = new FileStream("image.png", FileMode.Open, FileAccess.Read))
using (Signature signature = new Signature(inputStream))
{
    ImageDigitalSignOptions signOptions = new ImageDigitalSignOptions
    {
        Password = "MySecurePassword123"
    };

    using (Stream outputStream = new FileStream("signed_image.png", FileMode.Create))
    {
        SignResult signResult = signature.Sign(outputStream, signOptions);
        Console.WriteLine($"Signed: {signResult.Succeeded.Count} signature(s) added.");
    }
}
```

### Manejo de errores {#error-handling}

La biblioteca valida automáticamente la longitud de la contraseña y los requisitos de tamaño de imagen. Maneje las excepciones adecuadamente:

```csharp
try
{
    using (Signature signature = new Signature("image.png"))
    {
        ImageDigitalSignOptions signOptions = new ImageDigitalSignOptions
        {
            Password = "MyPassword123"  // Minimum 4 characters required
        };

        SignResult signResult = signature.Sign("signed_image.png", signOptions);
        Console.WriteLine("✓ Image signed successfully!");
    }
}
catch (ArgumentException ex)
{
    Console.WriteLine($"Password validation error: {ex.Message}");
    // Password must be at least 4 characters long
}
catch (InvalidOperationException ex)
{
    Console.WriteLine($"Image size error: {ex.Message}");
    // Image is too small for digital steganography signature
}
```

## Limitaciones y consideraciones {#limitations-and-considerations}

### Limitaciones de formato {#format-limitations}

* **PNG**: Totalmente compatible ✅
* **JPG/JPEG**: Totalmente compatible ✅
* **BMP**: No compatible ❌
* **Otros formatos**: No compatibles ❌

### Limitaciones de tamaño de imagen {#image-size-limitations}

* Las imágenes de menos de 8x8 píxeles no pueden firmarse
* Las imágenes con menos de 16.384 píxeles no pueden firmarse

### Consideraciones sobre esteganografía {#steganography-considerations}

* La compresión de imágenes (especialmente JPG) puede afectar la detección de la firma
* La edición de imágenes puede corromper las firmas incrustadas
* Mantenga siempre las imágenes firmadas originales para su verificación
* La firma se incrusta de forma invisible en los píxeles de la imagen

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> para .NET admite una amplia gama de tipos de firmas electrónicas, que se enumeran a continuación:

* Firmas de código de barras;
* Firmas digitales basadas en archivos de certificado;
* Firmas de campos de formulario;
* Firmas de imagen;
* Firmas de metadatos;
* Firmas de código QR
* Firmas de sello;
* Firmas de texto.  

Los siguientes artículos contienen ejemplos sobre cómo firmar electrónicamente documentos con cada tipo de firma admitido.

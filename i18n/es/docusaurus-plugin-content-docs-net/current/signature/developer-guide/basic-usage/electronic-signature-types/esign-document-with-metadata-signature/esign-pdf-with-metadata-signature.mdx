## Resumen {#overview}
<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PdfMetadataSignature</a> clase para especificar diferentes objetos de firma de metadatos para <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> instancia.
Los metadatos de un documento PDF son atributos ocultos, algunos de los cuales solo son visibles al ver las propiedades estándar del documento, como Autor, Fecha de creación, Productor, Entrada, Palabras clave, etc.  
Los metadatos del documento PDF contienen 3 campos: **Name**, **Value** y **TagPrefix**; la combinación de **Name** y **TagPrefix** debe ser única.

Los metadatos de un documento PDF podrían contener una gran cantidad de datos, lo que permite almacenar objetos personalizados serializados con cifrado adicional. Consulte [Ejemplos avanzados sobre cómo incrustar datos seguros](/net/signature/developer-guide/advanced-usage/signing/sign-document-with-secure-custom-metadata-signatures/).

### Aquí están los pasos para agregar firmas de metadatos en un documento PDF con GroupDocs.Signature: {#here-are-the-steps-to-add-metadata-signatures-into-pdf-document-with-groupdocs-signature}

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> objeto según sus requisitos.
* Instanciar uno o varios<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/pdfmetadatasignature" target="_blank" rel="nofollow noopener noreferrer">PdfMetadataSignature</a> objetos y agregarlos a <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a la colección de firmas de metadatos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a>) vía <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/addrange" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.
* Llamada <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a él.

## Cómo firmar electrónicamente un PDF con una firma de metadatos {#how-to-electronic-signature-pdf-with-metadata-signature}

Este ejemplo muestra cómo firmar un documento PDF con varias firmas electrónicas como metadatos.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    MetadataSignOptions options = new MetadataSignOptions();

    options
       .Add(new PdfMetadataSignature("Author", "Mr.Scherlock Holmes")) // String value
       .Add(new PdfMetadataSignature("CreatedOn", DateTime.Now))       // DateTime values
       .Add(new PdfMetadataSignature("DocumentId", 123456))            // Integer value
       .Add(new PdfMetadataSignature("SignatureId", 123.456D))         // Double value
       .Add(new PdfMetadataSignature("Amount", 123.456M))              // Decimal value
       .Add(new PdfMetadataSignature("Total", 123.456F));              // Float value
    // add these signatures to options
    options.Signatures.AddRange(signatures);
    signature.Sign("SampleSigned.pdf", options);
}
```

## Cómo firmar electrónicamente un PDF con firmas de metadatos estándar {#how-to-electronic-signature-pdf-with-standard-metadata-signatures}

Este ejemplo muestra cómo firmar un documento PDF mediante firmas de metadatos PDF integradas estándar. Si ya existe una firma de metadatos PDF con el mismo nombre, su valor se sobrescribirá.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    MetadataSignOptions options = new MetadataSignOptions();
    // Using standard Pdf Metadata Signatures with new values
    MetadataSignature[] signatures = new MetadataSignature[]
    {
        PdfMetadataSignatures.Author.Clone("Mr.Scherlock Holmes"),
        PdfMetadataSignatures.CreateDate.Clone(DateTime.Now.AddDays(-1)),
        PdfMetadataSignatures.MetadataDate.Clone(DateTime.Now.AddDays(-2)),
        PdfMetadataSignatures.CreatorTool.Clone("GD.Signature-Test"),
        PdfMetadataSignatures.ModifyDate.Clone(DateTime.Now.AddDays(-13)),
        PdfMetadataSignatures.Producer.Clone("GroupDocs-Producer"),
        PdfMetadataSignatures.Entry.Clone("Signature"),
        PdfMetadataSignatures.Keywords.Clone("GroupDocs, Signature, Metadata, Creation Tool"),
        PdfMetadataSignatures.Title.Clone("Metadata Example"),
        PdfMetadataSignatures.Subject.Clone("Metadata Test Example"),
        PdfMetadataSignatures.Description.Clone("Metadata Test example description"),
        PdfMetadataSignatures.Creator.Clone("GroupDocs.Signature"),
    };
    options.Signatures.AddRange(signatures);
    // sign document to file
    signature.Sign("sample_signed.pdf", options);
}
```

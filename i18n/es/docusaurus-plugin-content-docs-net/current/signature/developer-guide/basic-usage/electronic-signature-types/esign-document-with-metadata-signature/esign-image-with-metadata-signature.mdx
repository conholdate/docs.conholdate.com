## Resumen {#overview}
Firma de metadatos para documentos de imagen: es una firma electrónica basada en el estándar de metadatos de imagen. La mayoría de los formatos de imagen admiten la especificación de metadatos o <a href="https://en.wikipedia.org/wiki/Exif" target="_blank" rel="nofollow noopener noreferrer">EXIF</a>. Los metadatos de la imagen son un mapa de diccionario con un identificador entero corto único en el rango 0-65535. Algunos identificadores están reservados por <a href="https://www.exiv2.org/tags.html" target="_blank" rel="nofollow noopener noreferrer">Especificación EXIF.</a> Desde la perspectiva de la firma, los metadatos de la imagen pueden contener cualquier valor oculto de tipo estándar (int, char, string) o personalizado (clase definida por el usuario), y pueden ser cifrados y descifrados nuevamente mediante una clave conocida a través del método de búsqueda.

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagemetadatasignature" target="_blank" rel="nofollow noopener noreferrer">ImageMetadataSignature</a> clase para especificar la firma electrónica de metadatos para documentos de imagen. Los metadatos de documentos de imagen contienen un par con identificador único `Id` y su `Value`.  
Los metadatos de documentos de imagen pueden contener una gran cantidad de datos, lo que permite almacenar objetos personalizados serializados con cifrado adicional. Consulte más ejemplos [aquí](/net/signature/developer-guide/advanced-usage/signing/sign-document-with-secure-custom-metadata-signatures/).

### Aquí están los pasos para agregar firmas de metadatos en una imagen con GroupDocs.Signature: {#here-are-the-steps-to-add-metadata-signatures-into-image-with-groupdocs-signature}

* Crear nueva instancia de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase y pasar la ruta del documento fuente como parámetro del constructor.
* Instanciar el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> objeto según sus requisitos.
* Instanciar uno o varios <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/imagemetadatasignature" target="_blank" rel="nofollow noopener noreferrer">ImageMetadataSignature</a> objetos y agregarlos en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a la colección de firmas de metadatos (<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions/signatures" target="_blank" rel="nofollow noopener noreferrer">Signatures</a>) vía <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/metadatasignaturecollection/addrange" target="_blank" rel="nofollow noopener noreferrer">AddRange</a> método.
* Llamar <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> método de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> clase, instancia y `pass` <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasignoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSignOptions</a> a él.

## Cómo firmar digitalmente una imagen con una firma de metadatos {#how-to-esign-image-with-metadata-signature}

Este ejemplo muestra cómo firmar una imagen PNG con firmas electrónicas de metadatos

```csharp
using (Signature signature = new Signature("sample.png"))
{
    // create Metadata option with predefined Metadata text
    var options = new MetadataSignOptions();
    // Specify different Metadata Signatures and add them to options signature collection
    ushort imgsMetadataId = 41996;
    // Create several Image Metadata signatures with different types
    options
        .Add(new ImageMetadataSignature(imgsMetadataId++, "Mr.Scherlock Holmes")) // String value
        .Add(new ImageMetadataSignature(imgsMetadataId++, DateTime.Now))          // Date Time value
        .Add(new ImageMetadataSignature(imgsMetadataId++, 123456))                // Integer value
        .Add(new ImageMetadataSignature(imgsMetadataId++, 123.456D))              // Double value
        .Add(new ImageMetadataSignature(imgsMetadataId++, 123.456M))              // Decimal value
        .Add(new ImageMetadataSignature(imgsMetadataId++, 123.456F));             // Float value

    // add these signatures to options
    options.Signatures.AddRange(signatures);
    signature.Sign("SampleSigned.png", options);
}
```

## ¿Qué es una firma de texto? {#what-is-a-text-signature}

Una **firma electrónica de texto** es un texto arbitrario que se agrega a un documento de forma nativa, según el tipo del documento. GroupDocs.Signature proporciona la funcionalidad de firma de texto y permite personalizar una amplia gama de configuraciones de texto: desde el nombre, tamaño y color de la fuente hasta la alineación, bordes, efectos de sombra, etc. Así es como puede verse una firma de texto:

## Cómo firmar un documento electrónicamente con una firma de texto {#how-to-esign-document-with-text-signature}

Intentemos agregar una firma de texto a un PDF de forma programática.

Para manipular firmas de texto de forma programática, <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> y todo el flujo de trabajo es tan sencillo como se indica a continuación:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> según sus requisitos y especificar las opciones de firma.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a>.

Este ejemplo muestra cómo agregar una firma de texto a un documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    TextSignOptions options = new TextSignOptions("John Smith")
    {
        // set signature position
        Left = 100,
        Top = 100,
        // set signature rectangle
        Width = 100,
        Height = 30,
        // set Text color and Font
        ForeColor = Color.Red,
        Font = new SignatureFont { Size = 12, FamilyName = "Comic Sans MS" }
    };
    // sign document to file
    signature.Sign("sample_signed.pdf", options);
}
```
### Resumen {#summary}
Esta guía explica cómo agregar firmas basadas en texto a documentos con **GroupDocs.Signature**. Cubre la configuración de propiedades de texto, como fuente, color, tamaño y posición, así como la aplicación de la firma de texto a un documento. El documento firmado se guarda posteriormente con la firma de texto añadida.

## ¿Qué es una firma de sello? {#what-is-a-stamp-signature}

Una **firma de sello** es un tipo especial de firma electrónica que tiene la apariencia visual de un sello redondo, cuyos parámetros visuales pueden configurarse programáticamente.
Cada firma de sello puede tener múltiples «líneas de sello» con texto personalizado y distintos grosores de línea, colores, pesos de fuente y tamaños. A continuación se muestra un ejemplo de cómo podría verse una firma de sello creada con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>:

![Stamp](/net/signature/images/esign-document-with-stamp-signature.png)

GroupDocs.Signature proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/stampsignoptions" target="_blank" rel="nofollow noopener noreferrer">StampSignOptions</a> para especificar distintas opciones para la firma de sello:

* Tipo de sello: redondo o cuadrado;
* Altura y ancho en píxeles;
* Alineación y posición dentro de la página del documento;
* y muchas más.

Cada opción de sello contiene líneas internas y externas. Las líneas internas representan líneas verticales dentro del sello, mientras que las líneas externas representan círculos (o rectángulos según el tipo de sello) alrededor del sello, con su propio texto, configuración de borde, fondo, etc.

A continuación se indican los pasos para agregar una firma de sello a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/stampsignoptions" target="_blank" rel="nofollow noopener noreferrer">StampSignOptions</a> según sus necesidades y especificar las opciones adecuadas.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle el <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/stampsignoptions" target="_blank" rel="nofollow noopener noreferrer">StampSignOptions</a>.

## Cómo firmar electrónicamente un documento con una firma de sello {#how-to-esign-document-with-stamp-signature}

Este ejemplo muestra cómo agregar una firma de sello a un documento.

```csharp
using (Signature signature = new Signature("sample.docx"))
{
    StampSignOptions options = new StampSignOptions()
    {
        // set stamp signature position
        Left = 100,
        Top = 100,
    };
    // setup first external line of Stamp
    StampLine outerLine = new StampLine();
    outerLine.Text = " * European Union * European Union  * European Union  *";
    outerLine.Font.FontSize = 12;
    outerLine.Height = 22;
    outerLine.TextBottomIntent = 6;
    outerLine.TextColor = Color.WhiteSmoke;
    outerLine.BackgroundColor = Color.DarkSlateBlue;
    options.OuterLines.Add(outerLine);
    //Inner square lines - horizontal lines inside the rings
    StampLine innerLine = new StampLine();
    innerLine.Text = "John";
    innerLine.TextColor = Color.MediumVioletRed;
    innerLine.Font.FontSize = 20;
    innerLine.Font.Bold = true;
    innerLine.Height = 40;
    options.InnerLines.Add(innerLine);

    signature.Sign("SampleSigned.docx", options);
}
```
### Resumen {#summary}
Esta guía explica cómo aplicar firmas basadas en sellos a documentos mediante **GroupDocs.Signature**. Cubre el proceso de creación de una firma de sello, la personalización de su apariencia y la posición que se le asigna en el documento. El documento firmado puede guardarse posteriormente con la firma de sello aplicada.

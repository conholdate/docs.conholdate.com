## ¿Qué es un campo de formulario? {#what-is-a-form-field}

Un **campo de formulario** es un elemento interactivo ubicado en una página de documento que permite la entrada de datos del usuario mediante diversos tipos de controles, como cuadros de texto de entrada libre, cuadros de texto multilínea, casillas de verificación, listas desplegables, etc. Distintos tipos de documentos admiten una lista específica de tipos de campos de formulario. Estos elementos se utilizan para recopilar información del usuario en una plantilla de formulario. Cada elemento de campo de formulario tiene un nombre único, configuraciones y un campo de valor. Los campos de formulario deben tener nombres únicos dentro del formulario. La imagen siguiente muestra una página de documento posible con campos de formulario.

## Cómo firmar un documento con una firma de campo de formulario {#how-to-esign-document-with-form-field-signature}

Con <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>, puede crear nuevos campos de formulario o actualizar los existentes dentro de los documentos. La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> especifica distintas opciones para la firma de campo de formulario. La clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> contiene un objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/formfieldsignature/" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignature</a> que especifica las propiedades de la firma deseada.

A continuación se enumeran las distintas clases de firmas de campo de formulario que pueden configurarse en <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a>:

* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a> – representa un campo de entrada de texto en una página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature</a> – representa un campo de casilla de verificación en una página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/comboboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">ComboboxFormFieldSignature</a> – representa una firma de campo de lista desplegable (combo box) con una lista de opciones posibles.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/radiobuttonformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">RadioButtonFormFieldSignature</a> – representa un campo de botón de opción (radio button) en una página del documento.
* <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a> – representa un campo de entrada de firma digital en una página del documento.  

A continuación se indican los pasos para agregar firmas de campo de formulario a un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> según sus requisitos;
* Instanciar uno de los objetos: <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">TextFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/checkboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">CheckboxFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/comboboxformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">ComboboxFormFieldSignature</a>, <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/radiobuttonformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">RadioButtonFormFieldSignature</a> o <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/digitalformfieldsignature" target="_blank" rel="nofollow noopener noreferrer">DigitalFormFieldSignature</a>;
* Asignar la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a> con el objeto creado en el paso anterior;
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsignoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSignOptions</a>.


:::note
Actualmente, GroupDocs.Signature solo admite la creación de firmas de campos de formulario para documentos PDF.
:::


Este ejemplo muestra cómo firmar un documento PDF con una firma electrónica en un campo de formulario.

```csharp
            // The path to the documents directory.
            string filePath = "sample.pdf";
            string fileName = Path.GetFileName(filePath);

            string outputFilePath = Path.Combine("C:\output", fileName);

            using (Signature signature = new Signature(filePath))
            {
                // Instantiate text form field signature
                FormFieldSignature textSignature = new TextFormFieldSignature("FieldText", "Value1");

                // Instantiate options based on text form field signature
                FormFieldSignOptions options = new FormFieldSignOptions(textSignature)
                {
                    HorizontalAlignment = HorizontalAlignment.Left,
                    VerticalAlignment = VerticalAlignment.Top,
                    Margin = new Padding(10, 20, 0, 0),
                    Height = 10,
                    Width = 100
                };
                // Sign document and save to the file
                signature.Sign(outputFilePath, options);
            }
```

## Cómo firmar electrónicamente un documento con firmas de campo de formulario existentes {#how-to-esign-document-with-existing-form-field-signatures}

GroupDocs.Signature para .NET también proporciona un mecanismo para actualizar las firmas de campo de formulario existentes dentro de los documentos.

Para actualizar una firma de campo de formulario existente dentro de un documento con GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> con todas las opciones adicionales requeridas.
* Establecer la propiedad <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/signatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions.SignatureImplementation</a> con el valor <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/textsignatureimplementation" target="_blank" rel="nofollow noopener noreferrer">TextSignatureImplementation.FormField</a>.
* Establecer las propiedades <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtitle" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldTitle</a> y <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions/formtextfieldtype" target="_blank" rel="nofollow noopener noreferrer">FormTextFieldType</a> con los valores adecuados de los campos de formulario que se van a actualizar.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/sign/" target="_blank" rel="nofollow noopener noreferrer">Sign</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle la instancia <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsignoptions" target="_blank" rel="nofollow noopener noreferrer">TextSignOptions</a> inicializada.
* Analizar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.domain/signresult" target="_blank" rel="nofollow noopener noreferrer">SignResult</a> para verificar las firmas recién creadas, si es necesario.  

Este ejemplo muestra cómo firmar electrónicamente un documento PDF con una firma electrónica de campo de formulario existente y actualizar su valor.

```csharp
// The path to the documents directory.
string filePath = "sample.pdf";
string fileName = Path.GetFileName(filePath);

string outputFilePath = Path.Combine("C:\output", fileName);

using (Signature signature = new Signature(filePath))
{
    TextSignOptions ffOptions1 = new TextSignOptions("Document is approved")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.PlainText
    };
    TextSignOptions ffOptions2 = new TextSignOptions("John Smith")
    {
        // set alternative signature implementation on document page
        SignatureImplementation = TextSignatureImplementation.FormField,
        FormTextFieldType = FormTextFieldType.RichText,
        FormTextFieldTitle = "UserSignatureFullName"
    };
    List<SignOptions> listOptions = new List<SignOptions>();
    listOptions.Add(ffOptions1);
    listOptions.Add(ffOptions2);
    // sign document to file
    SignResult signResult = signature.Sign(outputFilePath, listOptions);
}
```

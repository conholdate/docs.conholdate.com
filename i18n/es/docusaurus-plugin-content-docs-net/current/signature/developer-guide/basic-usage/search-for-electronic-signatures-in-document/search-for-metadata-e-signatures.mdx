<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona una clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> para buscar firmas electrónicas de metadatos dentro de un documento.  
A continuación se indican los pasos para buscar firmas de metadatos mediante la API de GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a> según sus necesidades y especificar opciones adicionales de búsqueda (si es necesario);
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>.

Este fragmento de código demuestra cómo buscar una firma electrónica de metadatos en un documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    MetadataSearchOptions options = new MetadataSearchOptions();
    // search for signatures in document
    List<MetadataSignature> signatures = signature.Search<MetadataSignature>(options);
    foreach (var metadataSignature in signatures)
    {
        Console.WriteLine("Metadata signature found. Name : {0}. Value: {1}. Type: {2}",
            metadataSignature.Name, metadataSignature.Value,metadataSignature.Type);
    }
}
```

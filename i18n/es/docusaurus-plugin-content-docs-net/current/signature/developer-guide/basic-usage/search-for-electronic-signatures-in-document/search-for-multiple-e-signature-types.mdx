A veces puede que desee buscar simultáneamente firmas electrónicas de distintos tipos. <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> permite buscar en documentos distintos tipos de firmas de forma sencilla e intuitiva. En términos generales, la idea consiste en pasar una colección de los tipos de firmas deseados al método **Search**.

A continuación se indican los pasos para buscar múltiples tipos de firmas en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar las opciones de búsqueda para los tipos de firma requeridos y añadirlas a una colección de tipo `List<&lt;<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a>&gt;>`.

Las opciones posibles son:

* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a>` – para buscar firmas de código de barras;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a>` – para buscar firmas digitales;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a>` – para buscar firmas de campos de formulario;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a>` – para buscar firmas de imagen;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/metadatasearchoptions" target="_blank" rel="nofollow noopener noreferrer">MetadataSearchOptions</a>` – para buscar firmas de metadatos;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/qrcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">QrCodeSearchOptions</a>` – para buscar firmas de código QR;
* `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a>` – para buscar firmas de texto.
* Llamar al método `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>` de la instancia de la clase `<a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a>` y pasarle la colección de <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">opciones de búsqueda</a>.

Este ejemplo muestra cómo buscar múltiples tipos de firmas electrónicas en un documento.

```csharp
using (Signature signature = new Signature("SingedSample.pdf"))
{
    // define few search options
    BarcodeSearchOptions barcodeOptions = new BarcodeSearchOptions()
    {
        EncodeType = BarcodeTypes.Code128
    };
    QrCodeSearchOptions qrCodeOptions = new QrCodeSearchOptions()
    {
        EncodeType = QrCodeTypes.QR,
        Text = "John",
        MatchType = TextMatchType.Contains
    };
    MetadataSearchOptions metadataOptions = new MetadataSearchOptions()
    {
        IncludeBuiltinProperties = true
    };

    // add options to list
    List<SearchOptions> listOptions = new List<SearchOptions>();
    listOptions.Add(barcodeOptions);
    listOptions.Add(qrCodeOptions);
    listOptions.Add(metadataOptions);

    // search for signatures in document
    SearchResult result = signature.Search(listOptions);
    if (result.Signatures.Count > 0)
    {
        Console.WriteLine("\nSource document contains following signatures.");
        foreach (var resSignature in result.Signatures)
        {
            Console.WriteLine("Signature found at page {0} with type {1}", 
                resSignature.PageNumber,
                resSignature.SignatureType);
        }
    }
    else
    {
        Console.WriteLine("Signatures was not found.");
    }
}
```

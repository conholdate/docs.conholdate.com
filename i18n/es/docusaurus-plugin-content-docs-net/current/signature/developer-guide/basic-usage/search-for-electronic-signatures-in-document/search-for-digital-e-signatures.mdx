<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece la capacidad de buscar firmas digitales aplicadas a un documento y devolver su certificado de firma digital.  
Siga los siguientes pasos para buscar firmas digitales dentro de un documento:

* Cree una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase la ruta del documento de origen como parámetro del constructor.
* Instancie el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> según sus requisitos y especifique las opciones de búsqueda.
* Llame al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/digitalsearchoptions" target="_blank" rel="nofollow noopener noreferrer">DigitalSearchOptions</a> como argumento.

Este ejemplo muestra cómo buscar una firma digital en un documento y analizar su certificado de firma digital.

```csharp
using (Signature signature = new Signature("spreadsheet.xlsx"))
{
    // search for signatures in document
    List<DigitalSignature> signatures = signature.Search<DigitalSignature>(SignatureType.Digital);

    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var digitalSignature in signatures)
    {
        Console.WriteLine("Digital signature found from {0} with validation flag {1}. Certificate SN {2}",
        digitalSignature.SignTime, digitalSignature.IsValid, digitalSignature.Certificate?.SerialNumber);
    }
}
```

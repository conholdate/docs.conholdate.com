<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> ofrece una forma sencilla y directa para encontrar todas las firmas de código de barras presentes en un documento.  
Para el caso de uso más sencillo —es decir, encontrar todas las firmas de código de barras dentro de un documento— solo es necesario instanciar la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> y pasarla al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a>.

A continuación se detallan los pasos exactos para buscar firmas de código de barras en un documento mediante GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> según sus necesidades y especificar las opciones de búsqueda.
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/barcodesearchoptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeSearchOptions</a> como argumento.

Este ejemplo muestra cómo buscar una firma de código de barras en un documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // search for signatures in document
    List<BarcodeSignature> signatures = signature.Search<BarcodeSignature>(SignatureType.Barcode);

    Console.WriteLine("\nSource document contains following signatures.");
    foreach (var barcodeSignature in signatures)
    {
        Console.WriteLine("Barcode signature found at page {0} with type {1} and text {2}",
            barcodeSignature.PageNumber, barcodeSignature.EncodeType, barcodeSignature.Text);
    }
}
```

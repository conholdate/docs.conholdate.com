<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> para especificar distintas opciones de búsqueda de firmas electrónicas de tipo imagen.

 A continuación se indican los pasos para buscar firmas de imagen dentro de un documento mediante la API de GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> según sus necesidades y especificar opciones adicionales de búsqueda (si es necesario);
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/imagesearchoptions" target="_blank" rel="nofollow noopener noreferrer">ImageSearchOptions</a> como argumento.

El fragmento de código siguiente muestra cómo buscar una firma electrónica de tipo imagen en un documento.

```csharp
string fileName = "sample.pdf";
using (Signature signature = new Signature(fileName))
{
    // search document
    List<ImageSignature> signatures = signature.Search<ImageSignature>(SignatureType.Image);
    Console.WriteLine($"\nSource document ['{fileName}'] contains following image signature(s).");
    // output signatures
    foreach (ImageSignature imageSignature in signatures)
    {
        Console.WriteLine($"Image signature found at page {imageSignature.PageNumber} " +
                          $"with size {imageSignature.Size}. Created {imageSignature.CreatedOn}, " +
                          $"modified {imageSignature.ModifiedOn}");
    }
}
```

<a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a> proporciona la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> para especificar distintas opciones de búsqueda de firmas electrónicas de texto dentro de un documento.

A continuación se indican los pasos para buscar firmas electrónicas de texto mediante la API de GroupDocs.Signature:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor;
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a> según sus necesidades y especificar opciones adicionales de búsqueda (si es necesario);
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/textsearchoptions" target="_blank" rel="nofollow noopener noreferrer">TextSearchOptions</a>.

Este ejemplo muestra cómo buscar una firma electrónica de texto en un documento.

```csharp
using (Signature signature = new Signature("sample.pdf"))
{
    // setup search options
    TextSearchOptions searchOptions = new TextSearchOptions()
    {
        // search only page with specified number
        PageNumber = null,
        // specify as true to search all pages of a document
        AllPages = true,
        // specify text to search
        Text = "JS_",
        // specify text math type
        MatchType = TextMatchType.Contains
    };
    // search document
    List<TextSignature> signatures = signature.Search<TextSignature>(searchOptions);
    // output signatures
    foreach (TextSignature textSignature in signatures)
    {
         Console.Write($"Found Text signature: {textSignature.SignatureImplementation} " +
                       $"with text {textSignature.Text}.");
         Console.WriteLine($"Location at {textSignature.Left}-{textSignature.Top}. " +
                           $"Size is {textSignature.Width}x{textSignature.Height}.");
    }
}
```

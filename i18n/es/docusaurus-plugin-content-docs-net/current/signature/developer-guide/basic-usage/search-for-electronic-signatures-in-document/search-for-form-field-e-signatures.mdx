Para buscar firmas electrónicas de campos de formulario dentro de un documento, debe pasar una instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> al método **Search** de <a href="https://products.groupdocs.com/signature/net" target="_blank" rel="nofollow noopener noreferrer">**GroupDocs.Signature**</a>.  
A continuación se presenta una guía para buscar firmas electrónicas de campos de formulario:

* Crear una nueva instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasar la ruta del documento de origen como parámetro del constructor.
* Instanciar el objeto <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a> según sus requisitos y especificar opciones adicionales de búsqueda (si es necesario);
* Llamar al método <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature/search" target="_blank" rel="nofollow noopener noreferrer">Search</a> de la instancia de la clase <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature/signature" target="_blank" rel="nofollow noopener noreferrer">Signature</a> y pasarle <a href="https://reference.groupdocs.com/signature/net/groupdocs.signature.options/formfieldsearchoptions" target="_blank" rel="nofollow noopener noreferrer">FormFieldSearchOptions</a>.

Este ejemplo muestra cómo buscar firmas de campos de formulario en un documento.

```csharp
using (Signature signature = new Signature("signed.pdf"))
{
    // search for signatures in document
    List<FormFieldSignature> signatures = signature.Search<FormFieldSignature>(SignatureType.FormField);

    foreach (var formFieldSignature in signatures)
    {
        Console.WriteLine("FormField signature found. Name : {0}. Value: {1}", 
            formFieldSignature.Name, formFieldSignature.Value);
    }
}
```

Utilizando GroupDocs.Metadata para .NET, puede buscar fácilmente metadatos y extraer las propiedades de metadatos deseadas de archivos PDF, DOCX, PPTX, XLSX, imágenes, audio, video y muchos otros tipos de archivos en su solución .NET.

GroupDocs.Metadata para .NET admite muchos formatos de archivo. Consulte la lista completa en el artículo [supported file formats](/net/metadata/getting-started/supported-document-formats/).

## Utilizar etiquetas para encontrar las propiedades de metadatos más comunes {#use-tags-to-find-most-common-metadata-properties}
  
Para facilitar la manipulación de metadatos en su código, adjuntamos etiquetas específicas a las propiedades de metadatos más comúnmente utilizadas extraídas de un archivo. Algunos estándares de metadatos pueden tener una estructura bastante compleja. Además, en la mayoría de los casos, una imagen, un video o un documento contiene más de un paquete de metadatos. Mediante el uso de etiquetas, puede buscar las propiedades deseadas con unas pocas líneas de código, incluso sin conocer el formato exacto del archivo cargado.

En este artículo demostraremos cómo buscar y extraer metadatos de una presentación de Microsoft PowerPoint en formato PPTX. Con el mismo código, puede buscar fácilmente las propiedades de metadatos de cualquier formato de archivo admitido.

Los siguientes pasos y el ejemplo de código en C# a continuación muestran **cómo buscar propiedades de metadatos específicas mediante etiquetas en una solución .NET**:

1.  [Load](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo para examinarlo.
2.  Defina un predicado que verifique si una etiqueta específica está asignada a una propiedad (alternativamente, puede utilizar una combinación de etiquetas).
3.  Pase el predicado al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/findproperties" target="_blank" rel="nofollow noopener noreferrer">FindProperties</a>.
4.  Recorra las propiedades encontradas.

**BasicUsage.FindMetadataProperties**

```csharp
// Constants.InputPptx is an absolute or relative path to your document. Ex: @"C:\Docs\source.pptx"
using (Metadata metadata = new Metadata(Constants.InputPptx))
{
	// Fetch all the properties satisfying the predicate:
	// property contains the name of the last document editor OR the date/time the document was last modified
	var properties = metadata.FindProperties(p => p.Tags.Contains(Tags.Person.Editor) || p.Tags.Contains(Tags.Time.Modified));

	foreach (var property in properties)
	{
		Console.WriteLine("Property name: {0}, Property value: {1}", property.Name, property.Value);
	}
}
```

Como resultado, obtenemos todas las propiedades de metadatos que contienen el nombre de la persona que editó por última vez el documento, así como todas las propiedades que almacenan la fecha y hora en que el documento fue editado por última vez.

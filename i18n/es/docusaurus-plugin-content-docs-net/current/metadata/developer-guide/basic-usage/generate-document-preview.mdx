Si necesita implementar una interfaz de usuario para su aplicación, puede ser útil generar vistas previas de imagen para un documento con el que los usuarios van a trabajar. Estas vistas previas pueden mostrarse fácilmente en una página web o en un componente adecuado de una aplicación de escritorio/móvil. El siguiente ejemplo de código demuestra cómo generar vistas previas de imagen para ciertas páginas de un documento.

A continuación se indican los pasos para generar una vista previa de documento para una página específica:

1.  [Cargar](/net/metadata/developer-guide/basic-usage/generate-document-preview/) un documento para obtener su vista previa  
2.  Especificar un delegado que se utilizará para crear los flujos de página (consulte el delegado <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.options/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> para obtener más información)  
3.  Especificar los números de página  
4.  Generar vistas previas para las páginas deseadas mediante el método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata" target="_blank" rel="nofollow noopener noreferrer">Metadata</a>  

**BasicUsage.GenerateFilePreview**

```csharp
using (Metadata metadata = new Metadata(Constants.InputDocx))
{
	PreviewOptions previewOptions = new PreviewOptions(pageNumber => File.Create($"{Constants.OutputPath}\\result_{pageNumber}.png"));
	previewOptions.PreviewFormat = PreviewOptions.PreviewFormats.PNG;
	previewOptions.PageNumbers = new int[] { 1 };
	metadata.GeneratePreview(previewOptions);
}
```

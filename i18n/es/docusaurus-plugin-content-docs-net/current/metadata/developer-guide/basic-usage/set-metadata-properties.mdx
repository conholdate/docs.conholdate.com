## Actualizar o agregar propiedades de metadatos que satisfagan un predicado {#update-or-add-metadata-properties-satisfying-a-predicate}
  
El <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/setproperties" target="_blank" rel="nofollow noopener noreferrer">SetProperties</a> se utiliza para actualizar o agregar metadatos. Puede agregar fácilmente metadatos a fotos, PDFs o actualizar/agregar datos a archivos MP3. Este ejemplo de código combina en realidad dos operaciones: agregar y actualizar. Si una propiedad existente satisface el predicado especificado, su valor se actualiza. Si falta una propiedad conocida en un paquete de metadatos y dicha propiedad satisface el predicado, se agrega al paquete correspondiente.

El fragmento de código siguiente muestra un escenario básico de uso del método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/setproperties" target="_blank" rel="nofollow noopener noreferrer">SetProperties</a>.

1.  [Abrir](/net/metadata/developer-guide/basic-usage/set-metadata-properties/) un archivo para actualizar  
2.  Especificar un predicado que se utilizará para agregar/actualizar propiedades de metadatos  
3.  Especificar el valor que desea agregar a los paquetes de metadatos existentes en el archivo  
4.  Verificar el número real de propiedades agregadas/actualizadas  
5.  [Guardar](/net/metadata/developer-guide/basic-usage/set-metadata-properties/) los cambios  

**BasicUsage.SetMetadataProperties**

```csharp
// Constants.InputVsdx is an absolute or relative path to your document. Ex: @"C:\Docs\source.vsdx"
using (Metadata metadata = new Metadata(Constants.InputVsdx))
{
	// Set the value of each property that satisfies the predicate:
	// property contains the date/time the document was created OR modified
	var affected = metadata.SetProperties(
		p => p.Tags.Contains(Tags.Time.Created) || p.Tags.Contains(Tags.Time.Modified),
		new PropertyValue(DateTime.Now));
	Console.WriteLine("Properties set: {0}", affected);
	metadata.Save(Constants.OutputVsdx);
}
```

Como resultado, actualizamos todas las propiedades de metadatos existentes que contienen la fecha en que el documento fue creado/actualizado. Si un paquete de metadatos no contiene dichas propiedades, pero estas deberían formar parte de su estructura, se añaden.

## Eliminar todas las propiedades de metadatos reconocidas de un archivo  {#remove-all-recognized-metadata-properties-from-a-file}
  
A veces puede que necesite simplemente eliminar todas las propiedades de metadatos o limpiarlas sin aplicar ningún filtro. La mejor forma de hacerlo es utilizar el método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/sanitize" target="_blank" rel="nofollow noopener noreferrer">Sanitize</a>.

Este ejemplo demuestra cómo eliminar todos los paquetes/propiedades de metadatos detectados.

1.  [Load](/net/metadata/developer-guide/basic-usage/clean-metadata/) un archivo para limpiar  
2.  Llamar al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/sanitize" target="_blank" rel="nofollow noopener noreferrer">Sanitize</a>  
3.  Verificar el número real de paquetes/propiedades eliminados  
4.  [Save](/net/metadata/developer-guide/basic-usage/clean-metadata/) los cambios  

**BasicUsage.CleanMetadata**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	// Remove detected metadata packages
	var affected = metadata.Sanitize();
	Console.WriteLine("Properties removed: {0}", affected);

	metadata.Save(Constants.OutputPdf);
}
```

Como resultado, obtenemos una versión sanitizada del archivo original.

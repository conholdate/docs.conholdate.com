## Eliminar propiedades de metadatos mediante diversos criterios  {#remove-metadata-properties-using-various-criteria}
  
La forma más sencilla de eliminar propiedades de metadatos de un archivo es utilizar etiquetas correspondientes que le permitan localizar las propiedades deseadas en todos los paquetes de metadatos. Sin embargo, en ocasiones es necesario eliminar entradas de metadatos que tengan un valor concreto. Mediante el motor de búsqueda de GroupDocs.Metadata, puede buscar y eliminar propiedades que cumplan un predicado tan complejo como desee. Simplemente trabaje con árboles de metadatos utilizando expresiones lambda, como suele hacer con colecciones .NET habituales a través de LINQ.

El siguiente ejemplo muestra cómo eliminar propiedades de metadatos específicas mediante una combinación de criterios.

1.  [Cargar](/net/metadata/developer-guide/basic-usage/remove-metadata-properties/) un archivo para actualizar  
2.  Utilizar un predicado para buscar y eliminar cualquier propiedad de metadatos deseada  
3.  Comprobar el número de propiedades que realmente se eliminaron (consulte el valor devuelto del método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/removeproperties" target="_blank" rel="nofollow noopener noreferrer">RemoveProperties</a>)  
4.  [Guardar](/net/metadata/developer-guide/basic-usage/remove-metadata-properties/) los cambios  

**BasicUsage.RemoveMetadataProperties**

```csharp
// Constants.InputDocx is an absolute or relative path to your document. Ex: @"C:\Docs\source.docx"
using (Metadata metadata = new Metadata(Constants.InputDocx))
{
	// Remove all the properties satisfying the predicate:
	// property contains the name of the document author OR
	// it refers to the last editor OR
	// the property value is a string that contains the substring "John" (to remove any mentions of John from the detected metadata)
	var affected = metadata.RemoveProperties(
		p => p.Tags.Contains(Tags.Person.Creator) ||
			 p.Tags.Contains(Tags.Person.Editor) ||
			 p.Value.Type == MetadataPropertyType.String && p.Value.ToString().Contains("John"));
	Console.WriteLine("Properties removed: {0}", affected);

	metadata.Save(Constants.OutputDocx);
}
```

Como resultado de la ejecución del fragmento de código anterior, eliminamos todas las menciones al autor/editor del documento y todas las demás propiedades de metadatos de tipo cadena que contengan el nombre “John”.

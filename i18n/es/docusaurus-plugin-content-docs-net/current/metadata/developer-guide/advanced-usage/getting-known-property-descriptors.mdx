Este fragmento de código demuestra cómo extraer información sobre propiedades conocidas que pueden encontrarse en un paquete determinado.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo para examinarlo  
2.  Obtener una colección de <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.common/propertydescriptor" target="_blank" rel="nofollow noopener noreferrer">PropertyDescriptor</a> para cualquier paquete de metadatos deseado  
3.  Recorrer los descriptor extraídos  

**AdvancedUsage.GettingKnownPropertyDescriptors**

```csharp
using (Metadata metadata = new Metadata(Constants.InputDoc))
{
	var root = metadata.GetRootPackage<WordProcessingRootPackage>();
	foreach (var descriptor in root.DocumentProperties.KnowPropertyDescriptors)
	{
		Console.WriteLine(descriptor.Name);
		Console.WriteLine(descriptor.Type);
		Console.WriteLine(descriptor.AccessLevel);

		foreach (var tag in descriptor.Tags)
		{
			Console.WriteLine(tag);
		}

		Console.WriteLine();
	}
}
```


:::info
No se presentan todas las propiedades posibles en la colección <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.common/metadatapackage/properties/knowpropertydescriptors" target="_blank" rel="nofollow noopener noreferrer">KnowPropertyDescriptors</a>. La biblioteca solo proporciona información sobre las propiedades más utilizadas con frecuencia. Si no existe un descriptor para alguna propiedad, esta sigue estando accesible mediante el motor de búsqueda de GroupDocs.Metadata en modo de solo lectura.
:::

El ejemplo a continuación demuestra cómo actualizar propiedades de metadatos existentes mediante una combinación de criterios. Tenga en cuenta que el método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/updateproperties" target="_blank" rel="nofollow noopener noreferrer">UpdateProperties</a> verifica el tipo de todas las propiedades antes de aplicar cualquier cambio. Si una propiedad satisface el predicado pero tiene un tipo distinto del valor pasado, no se actualizará. La comprobación explícita del tipo en el ejemplo se realiza porque utilizamos el valor existente para filtrar las propiedades de metadatos.

1.  [Abrir](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo que se va a actualizar  
2.  Especifique un predicado que se utilizará para filtrar las propiedades de metadatos deseadas  
3.  Especifique un valor que desee asignar a las propiedades seleccionadas  
4.  Pase el predicado y el nuevo valor al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/updateproperties" target="_blank" rel="nofollow noopener noreferrer">UpdateProperties</a>  
5.  Verifique el número real de propiedades actualizadas  
6.  [Guardar](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios
      
    

**UsoAvanzado.ActualizaciónDeMetadatos**

```csharp
DateTime today = DateTime.Today;
DateTime threeDaysAgo = today.AddDays(-3);
foreach (string file in Directory.GetFiles(Constants.InputPath))
{
	using (Metadata metadata = new Metadata(file))
	{
		if (metadata.FileFormat != FileFormat.Unknown && !metadata.GetDocumentInfo().IsEncrypted)
		{
			Console.WriteLine();
			Console.WriteLine(file);

			// Update the file creation date/time if the existing value is older than 3 days
			var affected = metadata.UpdateProperties(p => p.Tags.Contains(Tags.Time.Created) &&
														  p.Value.Type == MetadataPropertyType.DateTime &&
														  p.Value.ToStruct<DateTime>() < threeDaysAgo, new PropertyValue(today));
			Console.WriteLine("Affected properties: {0}", affected);

			metadata.Save(Path.Combine(Constants.OutputPath, "output" + Path.GetExtension(file)));
		}
	}
}
```

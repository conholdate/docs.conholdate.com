### ¿Qué es MakerNote? {#what-is-makernote}
  
Los metadatos MakerNote hacen referencia a la información de imagen que es escrita por cámaras digitales de distintos fabricantes. Por lo general, las propiedades de los metadatos MakerNote contienen configuraciones de la cámara y otras condiciones bajo las cuales se tomó la fotografía. La mayoría de los fabricantes almacenan las propiedades MakerNote en un formato binario propietario derivado de EXIF. GroupDocs.Metadata permite extraer los metadatos MakerNote guardados por los siguientes fabricantes:

*   Canon  
*   Nikon  
*   Panasonic  
*   Sony  

### Leer todas las propiedades de MakerNote en forma de etiquetas TIFF/EXIF {#read-all-makernote-properties-in-the-form-of-tiff-exif-tags}
  
Mediante el uso de la API de GroupDocs.Metadata, el usuario puede leer todas las propiedades de metadatos, independientemente del formato exacto de MakerNote.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo de imagen sin procesar que contenga metadatos MakerNote  
2.  Extraer el paquete MakerNote utilizando la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/jpegrootpackage/properties/makernotepackage" target="_blank" rel="nofollow noopener noreferrer">MakerNotePackage</a>  
3.  Iterar a través de las etiquetas EXIF 

```csharp
using (Metadata metadata = new Metadata(Constants.CanonJpeg))
{
	var root = metadata.GetRootPackage<JpegRootPackage>();
	if (root.MakerNotePackage != null)
	{
		foreach (var tag in root.MakerNotePackage.ToList())
		{
			// Please note that tag ids used by camera manufacturers may intersect with the ids defined in the TIFF/EXIF specification
			Console.WriteLine("{0} = {1}", (int) tag.TagID, tag.Value);
		}
	}
}
```

Para ayudarle a interpretar las etiquetas extraídas, implementamos clases que representan paquetes específicos de metadatos MakerNote. Por favor, convierta el valor devuelto por la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/jpegrootpackage/properties/makernotepackage" target="_blank" rel="nofollow noopener noreferrer">MakerNotePackage</a> en una de las clases que se indican a continuación para obtener capacidades más específicas según el formato:

*   <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.standards.exif.makernote/canonmakernotepackage" target="_blank" rel="nofollow noopener noreferrer">CanonMakerNotePackage</a>  
*   <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.standards.exif.makernote/nikonmakernotepackage" target="_blank" rel="nofollow noopener noreferrer">NikonMakerNotePackage</a>  
*   <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.standards.exif.makernote/panasonicmakernotepackage" target="_blank" rel="nofollow noopener noreferrer">PanasonicMakerNotePackage</a>  
*   <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.standards.exif.makernote/sonymakernotepackage" target="_blank" rel="nofollow noopener noreferrer">SonyMakerNotePackage</a>  

### Leer propiedades de MakerNote de Canon {#read-canon-makernote-properties}

```csharp
using (Metadata metadata = new Metadata(Constants.CanonJpeg))
{
	var root = metadata.GetRootPackage<JpegRootPackage>();
	var makerNote = (CanonMakerNotePackage)root.MakerNotePackage;
	if (makerNote != null)
	{
		Console.WriteLine(makerNote.CanonFirmwareVersion);
		Console.WriteLine(makerNote.CanonImageType);
		Console.WriteLine(makerNote.OwnerName);
		Console.WriteLine(makerNote.CanonModelID);

		// ...

		if (makerNote.CameraSettings != null)
		{
			Console.WriteLine(makerNote.CameraSettings.AFPoint);
			Console.WriteLine(makerNote.CameraSettings.CameraIso);
			Console.WriteLine(makerNote.CameraSettings.Contrast);
			Console.WriteLine(makerNote.CameraSettings.DigitalZoom);

			// ...
		}
	}
}
```

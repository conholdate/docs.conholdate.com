## ¿Qué es ID3v1? {#what-is-id3v1}
  
ID3v1 es una etiqueta de metadatos que normalmente se utiliza con archivos de audio MP3. La etiqueta completa ocupa 128 bytes y permite agregar propiedades de metadatos como título, artista, álbum, número de pista, etc. El estándar ID3v1 se introdujo en 1996, pero sigue siendo ampliamente compatible con diversos reproductores y decodificadores de audio. Para obtener más información sobre las etiquetas ID3v1, visite <a href="http://id3.org/ID3v1" target="_blank" rel="nofollow noopener noreferrer">http://id3.org/ID3v1</a>.

## Lectura de una etiqueta ID3v1 {#reading-an-id3v1-tag}
  
Los pasos siguientes muestran cómo leer la etiqueta ID3v1 en un archivo MP3.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Obtener la etiqueta ID3v1 mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v1" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V1</a>  
4.  Si la etiqueta ID3v1 no es nula, comprobar todas sus propiedades  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3ReadID3V1Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V1))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.ID3V1 != null)
	{
		Console.WriteLine(root.ID3V1.Album);
		Console.WriteLine(root.ID3V1.Artist);
		Console.WriteLine(root.ID3V1.Title);
		Console.WriteLine(root.ID3V1.Version);
		Console.WriteLine(root.ID3V1.Comment);

		// ...
	}
}
```

## Actualización de una etiqueta ID3v1 {#updating-an-id3v1-tag}
  
Los siguientes son los pasos para actualizar la etiqueta ID3v1 en un archivo MP3.  

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Crear la etiqueta ID3v1 si no existe  
4.  Actualizar los campos ID3v1 mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v1" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V1</a>  
5.  [Guardar](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios  

El siguiente fragmento de código muestra cómo actualizar la etiqueta ID3v1 en un archivo MP3.  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3UpdateID3V1Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V1))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.ID3V1 == null)
	{
		root.ID3V1 = new ID3V1Tag();
	}
	root.ID3V1.Album = "test album";
	root.ID3V1.Artist = "test artist";
	root.ID3V1.Title = "test title";
	root.ID3V1.Comment = "test comment";
	root.ID3V1.Year = "2019";

	// ...

	metadata.Save(Constants.OutputMp3);
}
```

## Eliminación de una etiqueta ID3v1 {#removing-an-id3v1-tag}
  
Para eliminar la etiqueta ID3v1 de un archivo de audio MP3, simplemente asigne `null` a la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v1" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V1</a>. El siguiente ejemplo de código muestra cómo eliminar la etiqueta ID3v1 de un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3RemoveID3V1Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V1))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	root.ID3V1 = null;
	metadata.Save(Constants.OutputMp3);
}
```

## Trabajar con metadatos XMP {#working-with-xmp-metadata}
  
GroupDocs.Metadata para .NET permite gestionar metadatos XMP en imágenes TIFF. Para más detalles, consulte la siguiente guía: [Trabajar con metadatos XMP](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-xmp-metadata/).

## Trabajar con metadatos EXIF {#working-with-exif-metadata}
  
La API de GroupDocs.Metadata admite el manejo de metadatos EXIF en imágenes TIFF. Puede encontrar ejemplos de código adecuados en la sección [Trabajar con metadatos EXIF](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-exif-metadata/).

## Trabajar con metadatos IPTC {#working-with-iptc-metadata}
  
GroupDocs.Metadata para .NET también puede trabajar con metadatos IPTC en imágenes TIFF. Puede encontrar más información en la sección [Trabajar con metadatos IPTC IIM](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-iptc-iim-metadata/).

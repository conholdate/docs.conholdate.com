## ¿Qué es ID3v2? {#waht-is-id3v2}
  
ID3v2 es un estándar de metadatos que se utiliza principalmente con archivos mp3. Aunque lleva el nombre de ID3, su estructura es muy distinta a la de [ID3v1](/net/metadata/developer-guide/advanced-usage/managing-metadata-for-specific-formats/audio/working-with-mp3-metadata/handling-the-id3v2-tag/). Las etiquetas ID3v2 están compuestas por un número de marcos, cada uno de los cuales contiene un fragmento de metadatos.


:::info
Para obtener más información sobre el estándar ID3v2, visite http://id3.org/id3v2.3.0. Tenga en cuenta que existen tres versiones de ID3v2: ID3v2.2, ID3v2.3 e ID3v2.4.
:::


## Lectura de una etiqueta ID3v2  {#reading-an-id3v2-tag}
  
La API de GroupDocs.Metadata permite leer la etiqueta ID3v2 en un archivo de audio MP3. Para obtener más información sobre las etiquetas ID3, visite: <a href="https://en.wikipedia.org/wiki/ID3" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/ID3</a>  

Los siguientes pasos muestran cómo leer la etiqueta ID3v2 en un archivo MP3.  

1. [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2. Extraer el paquete de metadatos raíz  
3. Obtener la etiqueta ID3v2 mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v2" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V2</a>  
4. Si la etiqueta ID3v2 no es nula, verificar todas sus propiedades  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3ReadID3V2Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V2))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.ID3V2 != null)
	{
		Console.WriteLine(root.ID3V2.Album);
		Console.WriteLine(root.ID3V2.Artist);
		Console.WriteLine(root.ID3V2.Band);
		Console.WriteLine(root.ID3V2.Title);
		Console.WriteLine(root.ID3V2.Composers);
		Console.WriteLine(root.ID3V2.Copyright);
		Console.WriteLine(root.ID3V2.Publisher);
		Console.WriteLine(root.ID3V2.OriginalAlbum);
		Console.WriteLine(root.ID3V2.MusicalKey);

		if (root.ID3V2.AttachedPictures != null)
		{
			foreach (var attachedPicture in root.ID3V2.AttachedPictures)
			{
				Console.WriteLine(attachedPicture.AttachedPictureType);
				Console.WriteLine(attachedPicture.MimeType);
				Console.WriteLine(attachedPicture.Description);

				// ...
			}
		}

		// ...
	}
}
```

## Actualización de una etiqueta ID3v2 {#updating-an-id3v2-tag}
  
La API de GroupDocs.Metadata admite la actualización de la etiqueta ID3v2 en un archivo de audio MP3.

A continuación se indican los pasos para actualizar la etiqueta ID3v2 en un archivo MP3:

1.  [Load](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Crear la etiqueta ID3v2 si no existe  
4.  Actualizar los campos ID3v2 mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v2" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V2</a>  
5.  [Save](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios  

El siguiente fragmento de código muestra cómo actualizar la etiqueta ID3v2 en un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3UpdateID3V2Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V2))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.ID3V2 == null)
	{
		root.ID3V2 = new ID3V2Tag();
	}

	root.ID3V2.Album = "test album";
	root.ID3V2.Artist = "test artist";
	root.ID3V2.Band = "test band";
	root.ID3V2.TrackNumber = "1";
	root.ID3V2.MusicalKey = "C#";
	root.ID3V2.Title = "code sample";
	root.ID3V2.Date = "2019";

	// ...
	metadata.Save(Constants.OutputMp3);
}
```

## Eliminación de una etiqueta ID3v2 {#removing-an-id3v2-tag}
  
Para eliminar la etiqueta ID3v2 de un archivo de audio MP3, simplemente asigne `null` a la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/id3v2" target="_blank" rel="nofollow noopener noreferrer">Mp3RootPackage.ID3V2</a>. El siguiente ejemplo de código muestra cómo eliminar la etiqueta ID3v2 de un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3RemoveID3V2Tag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V2))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	root.ID3V2 = null;
	metadata.Save(Constants.OutputMp3);
}
```

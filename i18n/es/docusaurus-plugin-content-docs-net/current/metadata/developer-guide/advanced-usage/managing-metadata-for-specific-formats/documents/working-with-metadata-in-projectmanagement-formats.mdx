GroupDocs.Metadata para .NET proporciona funcionalidad que permite trabajar con archivos MPP creados por diferentes versiones de Microsoft Project. Consulte los ejemplos de código a continuación para obtener más información.

## Lectura de propiedades de metadatos integradas {#reading-built-in-metadata-properties}
  
Para acceder a los metadatos integrados de un documento de ProjectManagement, utilice la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1/properties/documentproperties" target="_blank" rel="nofollow noopener noreferrer">DocumentProperties</a> definida en la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1" target="_blank" rel="nofollow noopener noreferrer">DocumentRootPackage</a>.

El fragmento de código siguiente extrae las propiedades de metadatos integradas y las muestra en pantalla.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.ProjectManagement.<wbr />ProjectManagementReadBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMpp))
{
	var root = metadata.GetRootPackage<ProjectManagementRootPackage>();

	Console.WriteLine(root.DocumentProperties.Author);
	Console.WriteLine(root.DocumentProperties.CreationDate);
	Console.WriteLine(root.DocumentProperties.Company);
	Console.WriteLine(root.DocumentProperties.Category);
	Console.WriteLine(root.DocumentProperties.Keywords);
	Console.WriteLine(root.DocumentProperties.Revision);
	Console.WriteLine(root.DocumentProperties.Subject);

	// ... 
}
```

## Lectura de propiedades de metadatos personalizados  {#reading-custom-metadata-properties}
  
Si necesita extraer propiedades de metadatos personalizados de un documento ProjectManagement, siga el ejemplo de código a continuación.  
**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.ProjectManagement.<wbr />ProjectManagementReadCustomProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMpp))
{
    var root = metadata.GetRootPackage<ProjectManagementRootPackage>();
    var customProperties = root.DocumentProperties.FindProperties(p => !p.Tags.Contains(Tags.Document.BuiltIn));
    foreach (var property in customProperties)
    {
        Console.WriteLine("{0} = {1}", property.Name, property.Value);
    }
}
```

## Actualización de propiedades de metadatos integradas  {#updating-built-in-metadata-properties}
  
Actualizar cualquier propiedad integrada de documento es tan sencillo como obtenerlas. El siguiente ejemplo de código demuestra cómo actualizar propiedades de metadatos integradas en un documento de ProjectManagement.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.ProjectManagement.<wbr />ProjectManagementUpdateBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMpp))
{
	var root = metadata.GetRootPackage<ProjectManagementRootPackage>();

	root.DocumentProperties.Author = "test author";
	root.DocumentProperties.CreationDate = DateTime.Now;
	root.DocumentProperties.Company = "GroupDocs";
	root.DocumentProperties.Comments = "test comment";
	root.DocumentProperties.Keywords = "metadata, built-in, update";

	// ... 

	metadata.Save(Constants.OutputMpp);
}
```

## Agregar o actualizar propiedades de metadatos personalizados  {#adding-or-updating-custom-metadata-properties}
  
La API de GroupDocs.Metadata también permite agregar y actualizar propiedades de metadatos personalizados en un documento de gestión de proyectos. Consulte el ejemplo de código a continuación.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.ProjectManagement.<wbr />ProjectManagementUpdateCustomProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMpp))
{
    var root = metadata.GetRootPackage<ProjectManagementRootPackage>();
 
    root.DocumentProperties.Set("customProperty1", "some value");
    root.DocumentProperties.Set("customProperty2", 7);
    root.DocumentProperties.Set("customProperty3", true);
 
    // ...
 
    metadata.Save(Constants.OutputMpp);
}
```

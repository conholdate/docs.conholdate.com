GroupDocs.Metadata para .NET proporciona funcionalidad que permite manejar los formatos de mensajes de correo electrónico más populares: EML y MSG. A continuación se presentan algunos escenarios comúnmente utilizados al trabajar con el contenido y los metadatos del mensaje.

## Lectura de metadatos de mensajes EML  {#reading-eml-message-metadata}
  
El formato de mensaje EML lo utilizan muchos clientes de correo electrónico, entre ellos Novell GroupWise, Microsoft Outlook Express, Lotus Notes, Windows Mail, Mozilla Thunderbird y Postbox. Los archivos contienen el contenido del correo electrónico como texto sin formato en formato MIME, incluyendo la cabecera y el cuerpo del mensaje, así como los adjuntos en uno o más de varios formatos. El siguiente ejemplo de código muestra cómo extraer metadatos de un mensaje EML.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Email.EmlReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputEml))
{
	var root = metadata.GetRootPackage<EmlRootPackage>();

	Console.WriteLine(root.EmailPackage.Sender);
	Console.WriteLine(root.EmailPackage.Subject);

	foreach (string recipient in root.EmailPackage.Recipients)
	{
		Console.WriteLine(recipient);
	}

	foreach (var attachedFileName in root.EmailPackage.AttachedFileNames)
	{
		Console.WriteLine(attachedFileName);
	}

	foreach (var header in root.EmailPackage.Headers)
	{
		Console.WriteLine("{0} = {1}", header.Name, header.Value);
	}

	// ...
}
```

## Lectura de metadatos MSG {#reading-msg-metadata}
  
Los archivos MSG suelen crearse con el cliente de correo electrónico Microsoft Outlook. El formato MSG se utiliza para representar mensajes de correo electrónico individuales, citas, contactos, tareas, etc., en el sistema de archivos. El siguiente fragmento de código muestra cómo leer las propiedades más comunes de un mensaje de correo electrónico almacenado como un archivo MSG.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Email.MsgReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMsg))
{
	var root = metadata.GetRootPackage<MsgRootPackage>();

	Console.WriteLine(root.EmailPackage.Sender);
	Console.WriteLine(root.EmailPackage.Subject);

	foreach (string recipient in root.EmailPackage.Recipients)
	{
		Console.WriteLine(recipient);
	}

	foreach (var attachedFileName in root.EmailPackage.AttachedFileNames)
	{
		Console.WriteLine(attachedFileName);
	}

	foreach (var header in root.EmailPackage.Headers)
	{
		Console.WriteLine("{0} = {1}", header.Name, header.Value);
	}

	Console.WriteLine(root.EmailPackage.Body);
	Console.WriteLine(root.EmailPackage.DeliveryTime);

	// ...
}
```

## Eliminación de adjuntos de correo electrónico {#removing-email-attachments}
  
Ambas clases raíz del paquete que representan metadatos en mensajes de correo electrónico (<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.email/emlrootpackage" target="_blank" rel="nofollow noopener noreferrer">EmlRootPackage</a> y <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.email/msgrootpackage" target="_blank" rel="nofollow noopener noreferrer">MsgRootPackage</a>) comparten un antepasado común, la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.email/emailrootpackage" target="_blank" rel="nofollow noopener noreferrer">EmailRootPackage</a>. Dado que los formatos MSG y EML tienen funcionalidades muy similares, en la mayoría de los casos no es necesario conocer el tipo exacto del mensaje cargado. Es posible hacer referencia a la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.email/emailrootpackage" target="_blank" rel="nofollow noopener noreferrer">EmailRootPackage</a> para acceder a todas las características básicas relacionadas con los mensajes de correo electrónico. El siguiente ejemplo de código muestra cómo eliminar todos los adjuntos de un mensaje de correo electrónico utilizando una instancia de la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.email/emailrootpackage" target="_blank" rel="nofollow noopener noreferrer">EmailRootPackage</a>.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Email.EmailRemoveAttachments**

```csharp
using (Metadata metadata = new Metadata(Constants.InputEml))
{
	var root = metadata.GetRootPackage<EmailRootPackage>();

	root.ClearAttachments();

	metadata.Save(Constants.OutputEml);
}
```

## Actualización de campos de correo electrónico  {#updating-email-fields}
  
GroupDocs.Metadata para .NET también permite al usuario actualizar algunos campos comunes de correo electrónico. El siguiente ejemplo de código muestra cómo modificar el asunto y los destinatarios del correo electrónico.

**AdvancedUsage.ManagingMetadataForSpecificFormats.Email.EmailUpdateEmailFields**

```csharp
using (Metadata metadata = new Metadata(Constants.InputEml))
{
    var root = metadata.GetRootPackage<EmailRootPackage>();
    root.EmailPackage.Recipients = new string[] { "sample@aspose.com" };
    root.EmailPackage.CarbonCopyRecipients = new string[] { "sample@groupdocs.com" };
    root.EmailPackage.Subject = "RE: test subject";
    metadata.Save(Constants.OutputEml);
}
```

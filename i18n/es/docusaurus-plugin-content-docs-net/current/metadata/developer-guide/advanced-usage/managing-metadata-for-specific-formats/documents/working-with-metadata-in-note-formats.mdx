GroupDocs.Metadata para .NET proporciona funcionalidad que permite trabajar con archivos ONE creados por distintas versiones de Microsoft OneNote. Consulte los ejemplos de código a continuación para obtener más información.

## Inspección de documentos de notas  {#inspecting-note-documents}
  
La función de inspección que se presenta en esta sección no funciona directamente con los metadatos, sino que extrae ciertos fragmentos útiles de información que, bajo ciertas circunstancias, pueden considerarse metadatos. Por ejemplo, es posible que desee obtener información sobre las páginas de un documento de notas. Siga el ejemplo a continuación para aprender cómo hacerlo.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento de notas  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/noterootpackage/properties/inspectionpackage" target="_blank" rel="nofollow noopener noreferrer">InspectionPackage</a> para inspeccionar el documento  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Note.<wbr />NoteReadInspectionProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputOne))
{
	var root = metadata.GetRootPackage<NoteRootPackage>();

	if (root.InspectionPackage.Pages != null)
	{
		foreach (var page in root.InspectionPackage.Pages)
		{
			Console.WriteLine(page.Title);
			Console.WriteLine(page.Author);
			Console.WriteLine(page.CreationTime);
			Console.WriteLine(page.LastModificationTime);
		}
	}
}
```

## Lectura de estadísticas del documento  {#reading-document-statistics}
  
La mayoría de las aplicaciones ofimáticas pueden mostrar estadísticas de texto simples para los documentos cargados. Estas pueden incluir, por ejemplo, una estimación de la cantidad de palabras, páginas, caracteres, etc. La API de GroupDocs.Metadata ofrece una funcionalidad similar para algunos formatos de documentos. El siguiente ejemplo de código demuestra cómo obtener las estadísticas de texto para un documento de Note.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Note.<wbr />NoteReadDocumentStatistics**

```csharp
using (Metadata metadata = new Metadata(Constants.InputOne))
{
    var root = metadata.GetRootPackage<NoteRootPackage>();
    Console.WriteLine(root.DocumentStatistics.CharacterCount);
    Console.WriteLine(root.DocumentStatistics.PageCount);
    Console.WriteLine(root.DocumentStatistics.WordCount);
}
```

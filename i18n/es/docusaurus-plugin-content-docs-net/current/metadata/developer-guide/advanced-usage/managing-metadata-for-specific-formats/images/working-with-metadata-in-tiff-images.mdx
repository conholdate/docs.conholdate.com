## Trabajar con metadatos XMP {#working-with-xmp-metadata}
  
GroupDocs.Metadata para .NET permite gestionar metadatos XMP en imágenes HEIF/HEIC. Para más detalles, consulte la siguiente guía: [Trabajar con metadatos XMP](/net/metadata/developer-guide/advanced-usage/working-with-metadata-standards/working-with-xmp-metadata/).

## Lectura de propiedades de metadatos de Photoshop {#reading-photoshop-metadata-properties}
  
La API de GroupDocs Metadata permite al usuario leer los metadatos de Adobe Photoshop asociados a una imagen PSD. Para obtener más información sobre el formato de archivo de Photoshop y los bloques de metadatos, consulte la especificación: <a href="https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/" target="_blank" rel="nofollow noopener noreferrer">https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/</a>.

El siguiente ejemplo de código muestra cómo extraer los bloques de recursos de imagen (componentes fundamentales del formato de archivo de Photoshop) desde una imagen PSD.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo PSD  
2.  Obtener el paquete de metadatos raíz  
3.  Extraer la instancia de <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/imageresourcepackage" target="_blank" rel="nofollow noopener noreferrer">ImageResourcePackage</a> y obtener una lista de objetos <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/imageresourceblock" target="_blank" rel="nofollow noopener noreferrer">ImageResourceBlock</a>  
4.  Recorrer la colección de bloques de recursos  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Psd.PsdReadImageResourceBlocks**

```csharp
using (Metadata metadata = new Metadata(Constants.PsdWithIrb))
{
	var root = metadata.GetRootPackage<PsdRootPackage>();
	if (root.ImageResourcePackage != null)
	{
		foreach (var block in root.ImageResourcePackage.ToList())
		{
			Console.WriteLine(block.Signature);
			Console.WriteLine(block.ID);
			Console.WriteLine(block.Name);
			Console.WriteLine(block.Data);
		}
	}
}
```

## Lectura del encabezado de la imagen y de la información sobre las capas de PSD {#reading-the-image-header-and-information-about-psd-layers}
  
La API de GroupDocs.Metadata también admite la extracción de otra información específica del formato a partir de imágenes PSD.

A continuación se indican los pasos para leer el encabezado de un archivo PSD y extraer la información sobre las capas de PSD:

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) una imagen PSD  
2.  Obtener el paquete de metadatos raíz  
3.  Extraer el paquete de metadatos nativo mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/psdrootpackage/properties/psdpackage" target="_blank" rel="nofollow noopener noreferrer">PsdRootPackage.PsdPackage</a>  
4.  Leer el encabezado y la información de las capas de PSD  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Psd.PsdReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.PsdWithIptc))
{
	var root = metadata.GetRootPackage<PsdRootPackage>();

	Console.WriteLine(root.PsdPackage.ChannelCount);
	Console.WriteLine(root.PsdPackage.ColorMode);
	Console.WriteLine(root.PsdPackage.Compression);
	Console.WriteLine(root.PsdPackage.PhotoshopVersion);

	foreach (var layer in root.PsdPackage.Layers)
	{
		Console.WriteLine(layer.Name);
		Console.WriteLine(layer.BitsPerPixel);
		Console.WriteLine(layer.ChannelCount);
		Console.WriteLine(layer.Flags);
		Console.WriteLine(layer.Height);
		Console.WriteLine(layer.Width);

		// ...
	}

	// ...
}
```

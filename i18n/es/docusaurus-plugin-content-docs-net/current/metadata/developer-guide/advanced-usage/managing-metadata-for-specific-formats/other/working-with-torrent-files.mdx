En el sistema de distribución de archivos BitTorrent, un archivo torrent o METAINFO es un archivo informático que contiene metadatos sobre los archivos y carpetas que se van a distribuir, y normalmente también una lista de las ubicaciones en red de los *trackers*, que son computadoras que ayudan a los participantes del sistema a encontrarse entre sí y formar grupos de distribución eficientes llamados *swarms*. Un archivo torrent no contiene el contenido que se va a distribuir; solo contiene información sobre esos archivos, como sus nombres, tamaños, estructura de carpetas y valores de hash criptográfico para verificar la integridad de los archivos. 


:::info
Para obtener más información sobre los archivos torrent, consulte este artículo: https://en.wikipedia.org/wiki/Torrent_file
:::


## Lectura de metadatos de archivos TORRENT {#reading-torrent-file-metadata}
  
Para obtener los metadatos de un archivo TORRENT, se deben seguir los siguientes pasos:  

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo TORRENT  
2.  Obtener el paquete de metadatos raíz  
3.  Extraer el paquete de metadatos nativo mediante <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.peer2peer/torrentrootpackage/properties/torrentpackage" target="_blank" rel="nofollow noopener noreferrer">TorrentRootPackage.TorrentPackage</a>  
4.  Leer las propiedades del archivo TORRENT  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Peer2Peer.TorrentReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputTorrent))
{
	var root = metadata.GetRootPackage<TorrentRootPackage>();

	Console.WriteLine(root.TorrentPackage.Announce);
	Console.WriteLine(root.TorrentPackage.Comment);
	Console.WriteLine(root.TorrentPackage.CreatedBy);
	Console.WriteLine(root.TorrentPackage.CreationDate);

	foreach (var file in root.TorrentPackage.SharedFiles)
	{
		Console.WriteLine(file.Name);
		Console.WriteLine(file.Length);
	}

	// ...
}
```

## Actualización de los metadatos del archivo TORRENT {#updating-torrent-file-metadata}
  
La API de GroupDocs.Metadata también admite la actualización de algunas propiedades de metadatos de un archivo TORRENT. Consulte el fragmento de código a continuación para aprender cómo hacerlo.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Peer2Peer.TorrentReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputTorrent))
{
	var root = metadata.GetRootPackage<TorrentRootPackage>();
	Console.WriteLine(root.TorrentPackage.Announce);
	Console.WriteLine(root.TorrentPackage.Comment);
	Console.WriteLine(root.TorrentPackage.CreatedBy);
	Console.WriteLine(root.TorrentPackage.CreationDate);

	foreach (var file in root.TorrentPackage.SharedFiles)
	{
		Console.WriteLine(file.Name);
		Console.WriteLine(file.Length);
	}

	// ...
}
```

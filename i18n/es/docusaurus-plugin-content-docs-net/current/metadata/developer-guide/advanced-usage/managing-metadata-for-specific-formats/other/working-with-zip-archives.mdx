## Obtener metadatos en formato ZIP {#get-zip-format-metadata}
  
La API permite detectar archivos ZIP y leer sus metadatos de formato. Los pasos siguientes deben seguirse:

*   [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo ZIP  
*   Obtener el paquete de metadatos raíz  
*   Extraer el paquete de metadatos nativo mediante <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.archive/ziprootpackage/properties/zippackage" target="_blank" rel="nofollow noopener noreferrer">ZipRootPackage.ZipPackage</a>  
*   Leer las propiedades del archivo ZIP  
*   Recorrer <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.archive/zippackage/properties/files" target="_blank" rel="nofollow noopener noreferrer">ZipPackage.Files</a> para extraer información sobre los archivos archivados  

El fragmento de código siguiente muestra cómo obtener los metadatos de un archivo ZIP.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Archive.ZipReadNativeMetadataProperties**

```csharp
Encoding encoding = Encoding.GetEncoding(866);
using (Metadata metadata = new Metadata(Constants.InputZip))
{
	var root = metadata.GetRootPackage<ZipRootPackage>();

	Console.WriteLine(root.ZipPackage.Comment);
	Console.WriteLine(root.ZipPackage.TotalEntries);

	foreach (var file in root.ZipPackage.Files)
	{
		Console.WriteLine(file.Name);
		Console.WriteLine(file.CompressedSize);
		Console.WriteLine(file.CompressionMethod);
		Console.WriteLine(file.Flags);
		Console.WriteLine(file.ModificationDateTime);
		Console.WriteLine(file.UncompressedSize);

		// Use a specific encoding for the file names
		Console.WriteLine(encoding.GetString(file.RawName));
	}
}
```

## Actualización del comentario del usuario  {#updating-the-user-comment}
  
GroupDocs.Metadata para .NET le permite actualizar el comentario del usuario en un archivo ZIP. Los siguientes pasos deben seguirse:  

*   [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo ZIP  
*   Obtener el paquete de metadatos raíz  
*   Actualizar el comentario utilizando el setter <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.archive/zippackage/properties/comment" target="_blank" rel="nofollow noopener noreferrer">ZipPackage.Comment</a>  
*   Guardar los cambios  

El siguiente fragmento de código demuestra el uso de esta funcionalidad.  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Archive.ZipUpdateArchiveComment**

```csharp
using (Metadata metadata = new Metadata(Constants.InputZip))
{
	var root = metadata.GetRootPackage<ZipRootPackage>();
	root.ZipPackage.Comment = "updated comment";

	metadata.Save(Constants.OutputZip);
}
```

## Eliminar el comentario del usuario  {#removing-the-user-comment}
  
GroupDocs.Metadata para .NET le permite eliminar el comentario del usuario asociado a un archivo ZIP. El siguiente fragmento de código demuestra el uso de esta funcionalidad.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Archive.ZipRemoveArchiveComment**

```csharp
using (Metadata metadata = new Metadata(Constants.InputZip))
{
	var root = metadata.GetRootPackage<ZipRootPackage>();
	root.ZipPackage.Comment = null;

	metadata.Save(Constants.OutputZip);
}
```

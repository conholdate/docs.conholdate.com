## ¿Qué es APEv2? {#what-is-apev2}
  
La etiqueta APE es un estándar utilizado para agregar metadatos, como el título, el artista o el número de pista, a archivos de audio digital. La etiqueta APEv1 se diseñó para el formato Monkey's Audio. En los archivos MP3, la etiqueta APE originalmente se almacenaba al final del archivo, sin ninguna declaración en línea en el cuerpo del archivo. Sin embargo, posteriormente el estándar se amplió para incluir una cabecera, lo que permite que las etiquetas APE se ubiquen al inicio de los archivos y que los valores de los metadatos sean Unicode en lugar de únicamente ASCII. El estándar mejorado se denomina APEv2. 


:::info
Puede encontrar más información en https://en.wikipedia.org/wiki/APE_tag
:::


## Lectura de una etiqueta APEv2 {#reading-an-apev2-tag}
  
La API de GroupDocs.Metadata permite leer la etiqueta APEv2 en un archivo de audio MP3.  

Los siguientes pasos muestran cómo leer la etiqueta APEv2 en un archivo MP3.  

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Obtener la etiqueta APEv2 mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/apev2" target="_blank" rel="nofollow noopener noreferrer">MP3RootPackage.ApeV2</a>  
4.  Si la etiqueta APEv2 no es nula, comprobar todas sus propiedades  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3ReadApeTag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithApe))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();

	if (root.ApeV2 != null)
	{
		Console.WriteLine(root.ApeV2.Album);
		Console.WriteLine(root.ApeV2.Title);
		Console.WriteLine(root.ApeV2.Artist);
		Console.WriteLine(root.ApeV2.Composer);
		Console.WriteLine(root.ApeV2.Copyright);
		Console.WriteLine(root.ApeV2.Genre);
		Console.WriteLine(root.ApeV2.Language);

		// ...
	}
}
```

## Eliminación de una etiqueta APEv2 {#removing-an-apev2-tag}
  
La API de GroupDocs.Metadata admite la eliminación de la etiqueta APEv2 de un archivo de audio MP3.  

A continuación se indican los pasos para eliminar la etiqueta APEv2 de un archivo MP3:  

1. [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2. Obtener el paquete de metadatos raíz  
3. Eliminar la etiqueta llamando al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/methods/removeapev2" target="_blank" rel="nofollow noopener noreferrer">RemoveApeV2</a>  
4. [Guardar](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3RemoveApeTag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithApe))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();

	root.RemoveApeV2();

	metadata.Save(Constants.OutputMp3);
}
```

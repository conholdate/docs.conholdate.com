## Lectura de propiedades de metadatos de Photoshop {#reading-photoshop-metadata-properties}
  
La API de GroupDocs Metadata permite al usuario leer los metadatos de Adobe Photoshop asociados con una imagen JPEG. Para obtener más información sobre el formato de archivo de Photoshop y los bloques de metadatos que pueden adjuntarse a imágenes de distintos formatos, consulte la especificación: <a href="https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/" target="_blank" rel="nofollow noopener noreferrer">https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/</a>.

El siguiente ejemplo de código muestra cómo extraer bloques de recursos de imagen (componentes básicos del formato de archivo de Photoshop) desde una imagen JPEG.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) una imagen JPEG  
2.  Obtener el paquete de metadatos raíz  
3.  Extraer la instancia de <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/imageresourcepackage" target="_blank" rel="nofollow noopener noreferrer">ImageResourcePackage</a> y obtener una lista de objetos <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/imageresourceblock" target="_blank" rel="nofollow noopener noreferrer">ImageResourceBlock</a>  
4.  Recorrer la colección de bloques de recursos  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Jpeg.JpegReadImageResourceBlocks**

```csharp
using (Metadata metadata = new Metadata(Constants.JpegWithIrb))
{
	var root = metadata.GetRootPackage<JpegRootPackage>();

	if (root.ImageResourcePackage != null)
	{
		foreach (var block in root.ImageResourcePackage.ToList())
		{
			Console.WriteLine(block.Signature);
			Console.WriteLine(block.ID);
			Console.WriteLine(block.Name);
			Console.WriteLine(block.Data);
		}
	}
}
```

## Eliminación de propiedades de metadatos de Photoshop {#removing-photoshop-metadata-properties}
  
GroupDocs.Metadata para .NET también admite la eliminación de bloques de metadatos de Photoshop de una imagen JPEG. A continuación se muestra un ejemplo de código que demuestra cómo eliminar todo el paquete de metadatos de Photoshop de una imagen JPEG.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Jpeg.JpegRemoveImageResourceBlocks**

```csharp
using (Metadata metadata = new Metadata(Constants.JpegWithIrb))
{
	var root = metadata.GetRootPackage<JpegRootPackage>();

	root.RemoveImageResourcePackage();

	metadata.Save(Constants.OutputJpeg);
}
```

## Detección de códigos de barras en una imagen JPEG {#detecting-barcodes-in-a-jpeg-image}
  
Esta función le permite detectar códigos de barras de distintos tipos en una imagen JPEG. El fragmento de código siguiente detecta todos los códigos de barras presentes en una imagen JPEG y devuelve sus tipos.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Jpeg.JpegDetectBarcodes**

```csharp
using (Metadata metadata = new Metadata(Constants.JpegWithBarcodes))
{
	var root = metadata.GetRootPackage<JpegRootPackage>();

	var barcodeTypes = root.DetectBarcodeTypes();
	foreach (var barcodeType in barcodeTypes)
	{
		Console.WriteLine(barcodeType);
	}
}
```

## Detección de la versión del GIF {#detecting-the-gif-version}
  
El siguiente fragmento de código le ayudará a detectar la versión de una imagen GIF cargada y extraer información adicional sobre el formato de archivo.  

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) una imagen GIF  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/gifrootpackage/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> para obtener información sobre el formato de archivo  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.Gif.GifReadFileFormatProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputGif))
{
	var root = metadata.GetRootPackage<GifRootPackage>();

	Console.WriteLine(root.FileType.FileFormat);
	Console.WriteLine(root.FileType.Version);
	Console.WriteLine(root.FileType.ByteOrder);
	Console.WriteLine(root.FileType.MimeType);
	Console.WriteLine(root.FileType.Extension);
	Console.WriteLine(root.FileType.Width);
	Console.WriteLine(root.FileType.Height);
}
```

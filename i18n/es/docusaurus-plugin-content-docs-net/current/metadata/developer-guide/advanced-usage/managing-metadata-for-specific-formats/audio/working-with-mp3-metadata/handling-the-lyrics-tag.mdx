## ¿Qué es la etiqueta Lyrics? {#what-is-lyrics-tag}
  
La etiqueta Lyrics3 es un bloque de datos que comienza con «LYRICSBEGIN», termina con «LYRICSEND» y contiene las letras entre estas palabras clave. Este bloque de datos se guarda luego en el archivo de audio, entre la sección de audio y la etiqueta ID3. Si no existe ninguna etiqueta ID3, se debe adjuntar una.


:::info
Para obtener más información, visite: http://id3.org/Lyrics3
:::


## Lectura de una etiqueta Lyrics {#reading-a-lyrics-tag}
  
La API de GroupDocs.Metadata permite leer la etiqueta Lyrics3 en un archivo MP3.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Obtener la etiqueta Lyrics mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/lyrics3v2" target="_blank" rel="nofollow noopener noreferrer">MP3RootPackage.Lyrics3V2</a>  
4.  Si la etiqueta Lyrics no es nula, comprobar todas sus propiedades  

El siguiente fragmento de código lee la etiqueta Lyrics desde un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3ReadLyricsTag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithLyrics))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.Lyrics3V2 != null)
	{
		Console.WriteLine(root.Lyrics3V2.Lyrics);
		Console.WriteLine(root.Lyrics3V2.Album);
		Console.WriteLine(root.Lyrics3V2.Artist);
		Console.WriteLine(root.Lyrics3V2.Track);

		// ...

		// Alternatively, you can loop through a full list of tag fields
		foreach (var field in root.Lyrics3V2.ToList())
		{
			Console.WriteLine("{0} = {1}", field.ID, field.Data);
		}
	}
}
```

## Actualización de una etiqueta Lyrics {#updating-a-lyrics-tag}
  
La API de GroupDocs.Metadata admite la actualización de la etiqueta Lyrics en un archivo de audio MP3.

A continuación se indican los pasos para actualizar la etiqueta Lyrics en un archivo MP3:

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Extraer el paquete de metadatos raíz  
3.  Crear la etiqueta Lyrics si no existe  
4.  Actualizar los campos Lyrics mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/lyrics3v2" target="_blank" rel="nofollow noopener noreferrer">MP3RootPackage.Lyrics3V2</a>  
5.  [Guardar](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios  

El siguiente fragmento de código muestra cómo actualizar la etiqueta Lyrics en un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3UpdateLyricsTag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithLyrics))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	if (root.Lyrics3V2 == null)
	{
		root.Lyrics3V2 = new LyricsTag();
	}
	root.Lyrics3V2.Lyrics = "[00:01]Test lyrics";
	root.Lyrics3V2.Artist = "test artist";
	root.Lyrics3V2.Album = "test album";
	root.Lyrics3V2.Track = "test track";

	// You can add a fully custom field to the tag
	root.Lyrics3V2.Set(new LyricsField("ABC", "custom value"));

	// ...

	metadata.Save(Constants.OutputMp3);
}
```

## Eliminar una etiqueta Lyrics {#removing-a-lyrics-tag}
  
Para eliminar la etiqueta Lyrics de un archivo de audio MP3, simplemente asigne `null` a la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/lyrics3v2" target="_blank" rel="nofollow noopener noreferrer">MP3RootPackage.Lyrics3V2</a>. El siguiente ejemplo de código muestra cómo eliminar la etiqueta Lyrics de un archivo MP3.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3RemoveLyricsTag**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithLyrics))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();
	root.Lyrics3V2 = null;

	metadata.Save(Constants.OutputMp3);
}
```

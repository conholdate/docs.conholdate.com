Para todos los formatos de imagen admitidos, la API de GroupDocs.Metadata permite extraer propiedades comunes de las imágenes, como ancho y alto, tipo MIME, orden de bytes, etc. Consulte el fragmento de código a continuación para obtener más información sobre esta funcionalidad.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) una imagen  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.image/imagerootpackage/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> para obtener información sobre el formato del archivo  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Image.ImageReadFileFormatProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPng))
{
	var root = metadata.GetRootPackage<ImageRootPackage>();

	Console.WriteLine(root.FileType.FileFormat);
	Console.WriteLine(root.FileType.ByteOrder);
	Console.WriteLine(root.FileType.MimeType);
	Console.WriteLine(root.FileType.Extension);
	Console.WriteLine(root.FileType.Width);
	Console.WriteLine(root.FileType.Height);
}
```

## Detección de la versión de un documento PDF {#detecting-the-version-of-a-pdf-document}
  
El siguiente fragmento de código le ayudará a detectar la versión del PDF de un documento cargado y extraer información adicional sobre el formato del archivo.  

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento PDF  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdfrootpackage/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> para obtener información sobre el formato del archivo  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfReadFileFormatProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	Console.WriteLine(root.FileType.FileFormat);
	Console.WriteLine(root.FileType.Version);
	Console.WriteLine(root.FileType.MimeType);
	Console.WriteLine(root.FileType.Extension);
}
```

## Lectura de propiedades de metadatos integradas  {#reading-built-in-metadata-properties}
  
Para acceder a los metadatos integrados de un documento PDF, utilice la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1/properties/documentproperties" target="_blank" rel="nofollow noopener noreferrer">DocumentProperties</a> definida en la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1" target="_blank" rel="nofollow noopener noreferrer">DocumentRootPackage</a>.  

El siguiente fragmento de código extrae las propiedades de metadatos integradas y las muestra en pantalla.  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfReadBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	Console.WriteLine(root.DocumentProperties.Author);
	Console.WriteLine(root.DocumentProperties.CreatedDate);
	Console.WriteLine(root.DocumentProperties.Subject);
	Console.WriteLine(root.DocumentProperties.Producer);
	Console.WriteLine(root.DocumentProperties.Keywords);

	// ... 
}
```

## Lectura de propiedades de metadatos personalizados  {#reading-custom-metadata-properties}
  
Si necesita extraer propiedades de metadatos personalizados de un documento PDF, siga el ejemplo de código a continuación.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfReadCustomProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	var customProperties = root.DocumentProperties.FindProperties(p => !p.Tags.Contains(Tags.Document.BuiltIn));
	foreach (var property in customProperties)
	{
		Console.WriteLine("{0} = {1}", property.Name, property.Value);
	}
}
```

Como puede verse, el ejemplo de código utiliza el motor de búsqueda de GroupDocs.Metadata para recuperar todas las propiedades que no están marcadas con la etiqueta `BuiltIn`. Dado que llamamos al método `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.common/metadatapackage/methods/findproperties" target="_blank" rel="nofollow noopener noreferrer">FindProperties</a>` sobre un paquete de metadatos específico (una instancia de la clase `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdfpackage" target="_blank" rel="nofollow noopener noreferrer">PdfPackage</a>`), el resultado de la búsqueda solo contendrá propiedades de metadatos específicas para documentos PDF.

## Inspección de documentos PDF {#inspecting-pdf-documents}
  
La función de inspección que se presenta en esta sección no funciona directamente con los metadatos, sino que extrae ciertos datos útiles que, bajo ciertas circunstancias, pueden considerarse metadatos. Por ejemplo, es posible que desee obtener información sobre las firmas digitales asociadas a un documento, extraer campos de formularios, adjuntos, marcadores, etc. Siga el ejemplo siguiente para aprender cómo hacerlo.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento PDF  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdfrootpackage/properties/inspectionpackage" target="_blank" rel="nofollow noopener noreferrer">InspectionPackage</a>` para inspeccionar el documento  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfReadInspectionProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.SignedPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();
	if (root.InspectionPackage.Annotations != null)
	{
		foreach (var annotation in root.InspectionPackage.Annotations)
		{
			Console.WriteLine(annotation.Name);
			Console.WriteLine(annotation.Text);
			Console.WriteLine(annotation.PageNumber);
		}
	}

	if (root.InspectionPackage.Attachments != null)
	{
		foreach (var attachment in root.InspectionPackage.Attachments)
		{
			Console.WriteLine(attachment.Name);
			Console.WriteLine(attachment.MimeType);
			Console.WriteLine(attachment.Description);
		}
	}

	if (root.InspectionPackage.Bookmarks != null)
	{
		foreach (var bookmark in root.InspectionPackage.Bookmarks)
		{
			Console.WriteLine(bookmark.Title);
		}
	}

	if (root.InspectionPackage.DigitalSignatures != null)
	{
		foreach (var signature in root.InspectionPackage.DigitalSignatures)
		{
			Console.WriteLine(signature.CertificateSubject);
			Console.WriteLine(signature.Comments);
			Console.WriteLine(signature.SignTime);

			// ...
		}
	}

	if (root.InspectionPackage.Fields != null)
	{
		foreach (var field in root.InspectionPackage.Fields)
		{
			Console.WriteLine(field.Name);
			Console.WriteLine(field.Value);

			// ...
		}
	}
}
```

## Lectura de estadísticas del documento  {#reading-document-statistics}
  
La mayoría de las aplicaciones de oficina pueden mostrar estadísticas de texto simples para los documentos cargados. Estas pueden incluir, por ejemplo, una estimación de la cantidad de palabras, páginas, caracteres, etc. La API de GroupDocs.Metadata ofrece una funcionalidad similar para algunos formatos de documentos. El siguiente ejemplo de código demuestra cómo obtener las estadísticas de texto para un documento PDF.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfReadDocumentStatistics**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	Console.WriteLine(root.DocumentStatistics.CharacterCount);
	Console.WriteLine(root.DocumentStatistics.PageCount);
	Console.WriteLine(root.DocumentStatistics.WordCount);
}
```

## Actualización de propiedades de metadatos integradas  {#updating-built-in-metadata-properties}
  
Actualizar cualquier propiedad integrada de documento es tan sencillo como obtenerlas. El siguiente ejemplo de código demuestra cómo actualizar propiedades de metadatos integradas en un documento PDF.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfUpdateBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	root.DocumentProperties.Author = "test author";
	root.DocumentProperties.CreatedDate = DateTime.Now;
	root.DocumentProperties.Title = "test title";
	root.DocumentProperties.Keywords = "metadata, built-in, update";

	// ... 

	metadata.Save(Constants.OutputPdf);
}
```

## Agregar o actualizar propiedades de metadatos personalizados  {#adding-or-updating-custom-metadata-properties}
  
La API de GroupDocs.Metadata también permite agregar y actualizar propiedades de metadatos personalizados en un documento PDF. Consulte el siguiente ejemplo de código.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfUpdateCustomProperties**

```csharp
	var root = metadata.GetRootPackage<PdfRootPackage>();

}
```

## Actualización de propiedades de inspección  {#updating-inspection-properties}
  
Cuando inspecciona un documento, GroupDocs.Metadata para .NET forma un paquete de metadatos que contiene la información extraída. La clase del paquete también proporciona algunos métodos básicos que permiten eliminar las propiedades extraídas. El siguiente ejemplo de código demuestra cómo eliminar las propiedades de inspección de un documento PDF.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Pdf.<wbr />PdfUpdateInspectionProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.SignedPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	root.InspectionPackage.ClearAnnotations();
	root.InspectionPackage.ClearAttachments();
	root.InspectionPackage.ClearFields();
	root.InspectionPackage.ClearBookmarks();
	root.InspectionPackage.ClearDigitalSignatures();

	metadata.Save(Constants.OutputPdf);
}
```

## Lectura de propiedades específicas del formato MOV  {#reading-mov-format-specific-properties}
  
La API de GroupDocs.Metadata admite la extracción de átomos QuickTime de un video MOV. El átomo es la unidad de datos básica en cualquier archivo QuickTime. Para obtener más información sobre los átomos QuickTime, consulte la especificación oficial: <a href="https://developer.apple.com/library/archive/documentation/QuickTime/QTFF/QTFFPreface/qtffPreface.html" target="_blank" rel="nofollow noopener noreferrer">https://developer.apple.com/library/archive/documentation/QuickTime/QTFF/QTFFPreface/qtffPreface.html</a>

A continuación se indican los pasos para extraer átomos QuickTime de un video MOV.

1. [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un video MOV  
2. Obtener el paquete de metadatos raíz  
3. Extraer el paquete de metadatos nativo mediante <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.video/movrootpackage/properties/movpackage" target="_blank" rel="nofollow noopener noreferrer">MovRootPackage.MovPackage</a>  
4. Leer los átomos QuickTime  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Video.Mov.MovReadQuickTimeAtoms**

```csharp
using (Metadata metadata = new Metadata(Constants.InputMov))
{
	var root = metadata.GetRootPackage<MovRootPackage>();
	foreach (var atom in root.MovPackage.Atoms)
	{
		Console.WriteLine(atom.Type);
		Console.WriteLine(atom.Offset);
		Console.WriteLine(atom.Size);

		// ...
	}
}
```

GroupDocs.Metadata para .NET proporciona funcionalidad que permite trabajar con diferentes tipos de formatos de hojas de cálculo, como XLS, XLSX, ODS, etc. Para obtener la lista completa de formatos de documento admitidos, consulte [Supported Document Formats](/net/metadata/getting-started/supported-document-formats/).

## Detección del tipo exacto de un documento {#detecting-the-exact-type-of-a-document}
  
El siguiente ejemplo de código le ayudará a detectar el tipo exacto de una hoja de cálculo cargada y extraer información adicional sobre el formato de archivo.

1. [Load](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento de hoja de cálculo  
2. Extraiga el paquete de metadatos raíz  
3. Utilice la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/spreadsheetrootpackage/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> para obtener información sobre el formato de archivo  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetReadFileFormatProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXlsx))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	Console.WriteLine(root.FileType.FileFormat);
	Console.WriteLine(root.FileType.SpreadsheetFormat);
	Console.WriteLine(root.FileType.MimeType);
	Console.WriteLine(root.FileType.Extension);
}
```

## Lectura de propiedades de metadatos integradas  {#reading-built-in-metadata-properties}
  
Para acceder a los metadatos integrados de una hoja de cálculo, utilice la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1/properties/documentproperties" target="_blank" rel="nofollow noopener noreferrer">DocumentProperties</a> definida en la clase <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document.documentrootpackage/1" target="_blank" rel="nofollow noopener noreferrer">DocumentRootPackage</a>.

El siguiente fragmento de código extrae las propiedades de metadatos integradas y las muestra en pantalla.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetReadBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXlsx))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	Console.WriteLine(root.DocumentProperties.Author);
	Console.WriteLine(root.DocumentProperties.CreatedTime);
	Console.WriteLine(root.DocumentProperties.Company);
	Console.WriteLine(root.DocumentProperties.Category);
	Console.WriteLine(root.DocumentProperties.Keywords);
	Console.WriteLine(root.DocumentProperties.Language);
	Console.WriteLine(root.DocumentProperties.ContentType);

	// ... 
}
```

## Lectura de propiedades de metadatos personalizados  {#reading-custom-metadata-properties}
  
Si necesita extraer propiedades de metadatos personalizados de una hoja de cálculo, siga el ejemplo de código a continuación.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetReadCustomProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXls))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	var customProperties = root.DocumentProperties.FindProperties(p => !p.Tags.Contains(Tags.Document.BuiltIn));
	foreach (var property in customProperties)
	{
		Console.WriteLine("{0} = {1}", property.Name, property.Value);
	}

	// Extract only content type properties if required
	foreach (var contentTypeProperty in root.DocumentProperties.ContentTypeProperties.ToList())
	{
		Console.WriteLine("{0}, {1} = {2}", contentTypeProperty.SpreadsheetPropertyType, contentTypeProperty.Name, contentTypeProperty.SpreadsheetPropertyValue);
	}
}
```

Como puede verse, el ejemplo de código utiliza el motor de búsqueda de GroupDocs.Metadata para recuperar todas las propiedades que no están marcadas con la etiqueta `BuiltIn`. Dado que se llama al método `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.common/metadatapackage/methods/findproperties" target="_blank" rel="nofollow noopener noreferrer">FindProperties</a>` sobre un paquete de metadatos específico (una instancia de la clase `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/spreadsheetpackage" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetPackage</a>`), el resultado de la búsqueda solo contendrá propiedades de metadatos específicas para hojas de cálculo.

## Inspección de hojas de cálculo  {#inspecting-spreadsheets}
  
La función de inspección que se presenta en esta sección no funciona directamente con los metadatos, sino que extrae ciertos fragmentos útiles de información que, bajo ciertas circunstancias, pueden considerarse metadatos. Por ejemplo, es posible que desee obtener información sobre las firmas digitales asociadas a una hoja de cálculo, extraer comentarios de usuario del contenido de la hoja de cálculo, obtener hojas ocultas, etc. Siga el ejemplo siguiente para aprender cómo hacerlo.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento de hoja de cálculo  
2.  Extraer el paquete de metadatos raíz  
3.  Utilizar la propiedad `<a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/spreadsheetrootpackage/properties/inspectionpackage" target="_blank" rel="nofollow noopener noreferrer">InspectionPackage</a>` para inspeccionar el documento  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetReadInspectionProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXls))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();
	if (root.InspectionPackage.Comments != null)
	{
		foreach (var comment in root.InspectionPackage.Comments)
		{
			Console.WriteLine(comment.Author);
			Console.WriteLine(comment.Text);
			Console.WriteLine(comment.SheetNumber);
			Console.WriteLine(comment.Row);
			Console.WriteLine(comment.Column);
		}
	}

	if (root.InspectionPackage.DigitalSignatures != null)
	{
		foreach (var signature in root.InspectionPackage.DigitalSignatures)
		{
			Console.WriteLine(signature.CertificateSubject);
			Console.WriteLine(signature.Comments);
			Console.WriteLine(signature.SignTime);

			// ...
		}
	}

	if (root.InspectionPackage.HiddenSheets != null)
	{
		foreach (var sheet in root.InspectionPackage.HiddenSheets)
		{
			Console.WriteLine(sheet.Name);
			Console.WriteLine(sheet.Number);
		}
	}
}
```

## Actualización de propiedades de metadatos integradas  {#updating-built-in-metadata-properties}
  
Actualizar cualquier propiedad integrada de documento es tan sencillo como obtenerlas. El siguiente ejemplo de código demuestra cómo actualizar propiedades de metadatos integradas en una hoja de cálculo.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetUpdateBuiltInProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXlsx))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	root.DocumentProperties.Author = "test author";
	root.DocumentProperties.CreatedTime = DateTime.Now;
	root.DocumentProperties.Company = "GroupDocs";
	root.DocumentProperties.Category = "test category";
	root.DocumentProperties.Keywords = "metadata, built-in, update";

	// ... 

	metadata.Save(Constants.OutputXlsx);
}
```

## Agregar o actualizar propiedades de metadatos personalizados  {#adding-or-updating-custom-metadata-properties}
  
La API de GroupDocs.Metadata también permite agregar y actualizar propiedades de metadatos personalizados (incluidas las propiedades de tipo de contenido) en una hoja de cálculo. Consulte el ejemplo de código a continuación.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetUpdateCustomProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXls))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	root.DocumentProperties.Set("customProperty1", "some value");
	root.DocumentProperties.Set("customProperty2", 7);

	// Set a content type property
	root.DocumentProperties.ContentTypeProperties.Set("customContentTypeProperty", "custom value");

	metadata.Save(Constants.OutputXls);
}
```

## Actualización de propiedades de inspección  {#updating-inspection-properties}
  
Cuando inspecciona una hoja de cálculo, GroupDocs.Metadata para .NET forma un paquete de metadatos que contiene la información extraída. La clase del paquete también proporciona algunos métodos básicos que permiten eliminar las propiedades extraídas. El siguiente ejemplo de código demuestra cómo eliminar las propiedades de inspección en una hoja de cálculo.

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Document.Spreadsheet.<wbr />SpreadsheetUpdateInspectionProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputXlsx))
{
	var root = metadata.GetRootPackage<SpreadsheetRootPackage>();

	root.InspectionPackage.ClearComments();
	root.InspectionPackage.ClearDigitalSignatures();
	root.InspectionPackage.ClearHiddenSheets();

	metadata.Save(Constants.OutputXlsx);
}
```

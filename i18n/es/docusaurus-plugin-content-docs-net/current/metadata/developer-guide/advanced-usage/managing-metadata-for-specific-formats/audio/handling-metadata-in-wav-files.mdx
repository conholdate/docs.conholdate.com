## Lectura de detalles de audio {#reading-audio-details}
  
La API de GroupDocs.Metadata admite la extracción de información técnica de audio desde archivos WAV.

A continuación se indican los pasos para leer los detalles de audio:

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo de audio WAV  
2.  Obtener el paquete de metadatos raíz  
3.  Extraer el paquete de metadatos nativo mediante la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/wavrootpackage/properties/wavpackage" target="_blank" rel="nofollow noopener noreferrer">WavRootPackage.WavPackage</a>  
4.  Leer las propiedades del audio WAV  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.Wav.WavReadNativeMetadataProperties**

```csharp
using (Metadata metadata = new Metadata(Constants.InputWav))
{
	var root = metadata.GetRootPackage<WavRootPackage>();
	if (root.WavPackage != null)
	{
		Console.WriteLine(root.WavPackage.AudioFormat);
		Console.WriteLine(root.WavPackage.BitsPerSample);
		Console.WriteLine(root.WavPackage.BlockAlign);
		Console.WriteLine(root.WavPackage.ByteRate);
		Console.WriteLine(root.WavPackage.NumberOfChannels);
		Console.WriteLine(root.WavPackage.SampleRate);
	}
}
```

## Extraer metadatos del bloque INFO de RIFF  {#extract-riff-info-chunk-metadata}
  
El formato WAV se deriva del contenedor RIFF, que actúa como un contenedor para diversos formatos de codificación de audio y video. Como derivado de RIFF, los archivos WAV pueden etiquetarse con metadatos en el bloque INFO. Este bloque puede incluir información como el título de la obra, el autor, la fecha de creación y los datos de derechos de autor. A continuación se muestra un ejemplo de cómo se pueden extraer los metadatos INFO de RIFF:

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.Wav.WavReadInfoMetadata**

```csharp
using (Metadata metadata = new Metadata(Constants.InputWav))
{
    var root = metadata.GetRootPackage<WavRootPackage>();
    if (root.RiffInfoPackage != null)
    {
        Console.WriteLine(root.RiffInfoPackage.Artist);
        Console.WriteLine(root.RiffInfoPackage.Comment);
        Console.WriteLine(root.RiffInfoPackage.Copyright);
        Console.WriteLine(root.RiffInfoPackage.CreationDate);
        Console.WriteLine(root.RiffInfoPackage.Software);
        Console.WriteLine(root.RiffInfoPackage.Engineer);
        Console.WriteLine(root.RiffInfoPackage.Genre);
 
        // ...
    }
}
```

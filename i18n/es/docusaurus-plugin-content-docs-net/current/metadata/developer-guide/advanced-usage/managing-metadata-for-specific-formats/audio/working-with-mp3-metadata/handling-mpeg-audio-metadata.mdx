## Lectura de metadatos de audio MPEG {#reading-mpeg-audio-metadata}

    
MP3 (formalmente MPEG-1 Audio Layer III o MPEG-2 Audio Layer III) es un formato de codificación para audio digital. Originalmente definido como el tercer formato de audio de la norma MPEG-1, se conservó y amplió posteriormente, definiendo velocidades de bits adicionales y soporte para más canales de audio, como el tercer formato de audio de la subsiguiente norma MPEG-2. La API de GroupDocs.Metadata permite leer algunas propiedades comunes de audio MPEG de archivos MP3.


:::info
Para obtener más información sobre los estándares MP3 y MPEG, consulte los siguientes artículos:  
* <a href="https://en.wikipedia.org/wiki/MP3" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/MP3</a>  
* <a href="https://en.wikipedia.org/wiki/Moving_Picture_Experts_Group" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/Moving\_Picture\_Experts\_Group</a>
:::


  

Los siguientes pasos muestran cómo leer los metadatos de audio MPEG de un archivo MP3.

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo MP3  
2.  Obtener el paquete de metadatos raíz  
3.  Utilizar la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.audio/mp3rootpackage/properties/mpegaudiopackage" target="_blank" rel="nofollow noopener noreferrer">MP3RootPackage.MpegAudioPackage</a> para leer los valores de los metadatos  

**AdvancedUsage.ManagingMetadataForSpecificFormats.<wbr />Audio.MP3.MP3ReadMpegAudioMetadata**

```csharp
using (Metadata metadata = new Metadata(Constants.MP3WithID3V2))
{
	var root = metadata.GetRootPackage<MP3RootPackage>();

	Console.WriteLine(root.MpegAudioPackage.Bitrate);
	Console.WriteLine(root.MpegAudioPackage.ChannelMode);
	Console.WriteLine(root.MpegAudioPackage.Emphasis);
	Console.WriteLine(root.MpegAudioPackage.Frequency);
	Console.WriteLine(root.MpegAudioPackage.HeaderPosition);
	Console.WriteLine(root.MpegAudioPackage.Layer);

	// ...
} 
```

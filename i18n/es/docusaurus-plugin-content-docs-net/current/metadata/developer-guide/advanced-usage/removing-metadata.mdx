No todas las propiedades de metadatos extraídas de un archivo están marcadas con etiquetas. Algunos formatos de archivo y estándares de metadatos permiten agregar propiedades completamente personalizadas que no pueden etiquetarse adecuadamente mediante la biblioteca, ya que su propósito no está definido claramente en la especificación correspondiente del formato/estándar. En tales casos, puede utilizar el nombre de la propiedad para localizarla y eliminarla. El siguiente ejemplo demuestra algunos escenarios de uso avanzado del motor de búsqueda de GroupDocs.Metadata que permiten eliminar propiedades de metadatos.

1.  [Load](/net/metadata/developer-guide/advanced-usage/loading-files/) un archivo que se va a modificar  
2.  Pase un predicado de búsqueda al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/removeproperties" target="_blank" rel="nofollow noopener noreferrer">RemoveProperties</a>.  
3.  Verifique la cantidad de propiedades que realmente se eliminaron  
4.  [Save](/net/metadata/developer-guide/advanced-usage/saving-files/) los cambios  

**AdvancedUsage.RemovingMetadata**

```csharp
foreach (string file in Directory.GetFiles(Constants.InputPath))
{
	using (Metadata metadata = new Metadata(file))
	{
		if (metadata.FileFormat != FileFormat.Unknown && !metadata.GetDocumentInfo().IsEncrypted)
		{
			Console.WriteLine();
			Console.WriteLine(file);

			// Remove all mentions of any people contributed in file creation
			// Remove all properties with the specified name
			var affected = metadata.RemoveProperties(p => p.Tags.Any(t => t.Category == Tags.Person) || p.Name == "CustomProperty");

			Console.WriteLine("Affected properties: {0}", affected);

			metadata.Save(Path.Combine(Constants.OutputPath, "output" + Path.GetExtension(file)));
		}
	}
}
```

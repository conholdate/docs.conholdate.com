PDF/A es una versión estandarizada por ISO del formato PDF, especializada en la preservación digital y el archivado a largo plazo de documentos electrónicos. A diferencia del PDF estándar, PDF/A prohíbe características inadecuadas para el archivado a largo plazo, como el enlace de fuentes y el cifrado, y exige que se incluyan ciertas características, como fuentes incrustadas y perfiles de color.

Existen varios niveles de conformidad definidos en múltiples versiones de PDF/A:

*   **PDF/A-1** (ISO 19005-1): basado en PDF 1.4, con niveles de conformidad **a** (accesible) y **b** (básico)
*   **PDF/A-2** (ISO 19005-2): basado en PDF 1.7, que añade el nivel de conformidad **u** (Unicode)
*   **PDF/A-3** (ISO 19005-3): idéntico a PDF/A-2, pero permite incrustar formatos de archivo arbitrarios como adjuntos

Utilizando GroupDocs.Metadata para .NET, puede detectar rápidamente si un documento PDF cargado cumple con un estándar PDF/A y determinar su versión exacta y nivel de conformidad.

## Detección de conformidad con PDF/A {#detecting-pdf-a-conformance}
  
Los pasos y el ejemplo de código en C# que se muestran a continuación indican **cómo detectar el tipo PDF/A de un documento PDF en una solución .NET**:

1.  [Cargar](/net/metadata/developer-guide/advanced-usage/loading-files/) un documento PDF  
2.  Extraer el paquete de metadatos raíz  
3.  Leer la propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdftypepackage/properties/pdfaversion" target="_blank" rel="nofollow noopener noreferrer">PdfAVersion</a> desde el paquete <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdfrootpackage/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>  

**AdvancedUsage.DetectingPdfADocument**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	if (root.FileType.PdfAVersion != PdfAVersion.None)
	{
		Console.WriteLine("The document is PDF/A compliant.");
		Console.WriteLine("PDF/A version: {0}", root.FileType.PdfAVersion);
	}
	else
	{
		Console.WriteLine("The document is not PDF/A compliant.");
	}
}
```

La propiedad <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdftypepackage/properties/pdfaversion" target="_blank" rel="nofollow noopener noreferrer">PdfAVersion</a> devuelve uno de los valores predefinidos de la enumeración <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata.formats.document/pdfaversion" target="_blank" rel="nofollow noopener noreferrer">PdfAVersion</a>, por ejemplo `PdfA1a`, `PdfA1b`, `PdfA2a`, `PdfA2b`, `PdfA2u`, `PdfA3a`, `PdfA3b`, `PdfA3u` o `None` cuando el documento no cumple con ninguna norma PDF/A.

## Detección conjunta del tipo y la versión de PDF/A {#detecting-pdf-a-type-and-version-information-together}
  
El siguiente ejemplo de código muestra cómo recuperar información detallada sobre el cumplimiento de PDF/A junto con propiedades generales del formato de archivo PDF.

**AdvancedUsage.DetectingPdfADocumentWithFileFormatInfo**

```csharp
using (Metadata metadata = new Metadata(Constants.InputPdf))
{
	var root = metadata.GetRootPackage<PdfRootPackage>();

	Console.WriteLine("File format : {0}", root.FileType.FileFormat);
	Console.WriteLine("PDF version : {0}", root.FileType.Version);
	Console.WriteLine("MIME type   : {0}", root.FileType.MimeType);
	Console.WriteLine("PDF/A version: {0}", root.FileType.PdfAVersion);
}
```


:::info
La información de conformidad con PDF/A se almacena en los metadatos XMP del documento bajo el espacio de nombres `pdfaid`. GroupDocs.Metadata lee esta información automáticamente y la expone mediante la propiedad `PdfAVersion`, por lo que no es necesario analizar manualmente el flujo XMP.
:::

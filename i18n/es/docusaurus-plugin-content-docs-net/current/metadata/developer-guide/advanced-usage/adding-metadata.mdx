Agregar propiedades de metadatos es la función más sofisticada del motor de búsqueda de GroupDocs.Metadata. Cuando se llama al método <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metadata/methods/addproperties" target="_blank" rel="nofollow noopener noreferrer">AddProperties</a>, este examina todos los paquetes de metadatos disponibles e intenta identificar una propiedad conocida que cumpla con el predicado especificado. Tenga en cuenta que la propiedad se agregará únicamente a los paquetes de metadatos que cumplan con los siguientes criterios:

1. Solo se afectarán los paquetes de metadatos existentes. No se agregan nuevos paquetes durante esta operación.
2. Debe existir una propiedad de metadatos conocida en la estructura del paquete que cumpla con la condición de búsqueda, pero que de hecho no esté presente en el paquete. Por lo general, todas las propiedades admitidas por un paquete determinado se definen en la especificación de un estándar de metadatos concreto.

**AdvancedUsage.AddingMetadata**

```csharp
foreach (string file in Directory.GetFiles(Constants.InputPath))
{
	using (Metadata metadata = new Metadata(file))
	{
		if (metadata.FileFormat != FileFormat.Unknown && !metadata.GetDocumentInfo().IsEncrypted)
		{
			Console.WriteLine();
			Console.WriteLine(file);

			// Add a property containing the file last printing date
			var affected = metadata.AddProperties(p => p.Tags.Contains(Tags.Time.Printed), new PropertyValue(DateTime.Now));
			Console.WriteLine("Affected properties: {0}", affected);

			metadata.Save(Path.Combine(Constants.OutputPath, "output" + Path.GetExtension(file)));
		}
	}
}
```

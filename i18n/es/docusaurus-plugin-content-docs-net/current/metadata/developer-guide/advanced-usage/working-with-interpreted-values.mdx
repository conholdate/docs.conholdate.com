A veces no es realmente obvio lo que supuestamente significa una propiedad de metadatos específica. Un buen ejemplo de tal propiedad vaga es una bandera numérica o una enumeración. Por ejemplo, aquí se presenta la descripción de la etiqueta EXIF `ExposureProgram` tomada de la especificación oficial de EXIF:


:::info
La clase del programa utilizado por la cámara para establecer la exposición cuando se toma la foto. Los valores de la etiqueta son los siguientes:

| Valor | Descripción              |
|-------|--------------------------|
| 0     | No definido              |
| 1     | Manual                   |
| 2     | Programa normal          |
| 3     | Prioridad de apertura    |
| 4     | Prioridad de obturador   |
| 5     | Programa creativo        |
| 6     | Programa de acción       |
| 7     | Modo retrato             |
| 8     | Modo paisaje             |
:::


Como puede verse, todos los modos están representados por valores numéricos. Si no está familiarizado con la especificación, le resultará difícil convertir estos números aislados en algo significativo. Aquí es donde entran en juego los valores interpretados: ofrecen una descripción amigable para el usuario del valor original de la propiedad. El fragmento de código siguiente muestra cómo extraer la propiedad `ExposureProgram` y mostrar tanto su valor original como su valor interpretado.


```csharp
using (Metadata metadata = new Metadata(@"D:\input.heic"))
{
    var root = (IExif)metadata.GetRootPackage();
    if (root.ExifPackage != null)
    {
        var property = root.ExifPackage.ExifIfdPackage[TiffTagID.ExposureProgram] as TiffShortTag;
        if (property != null)
        {
            Console.WriteLine(property.TagValue[0]); // 2
            Console.WriteLine(property.InterpretedValue); // Normal program
        }
    }
}
```

De una versión a otra, agregamos intérpretes a las propiedades de metadatos extraídas de diversos formatos. Para obtener una lista completa de las propiedades que tienen valores interpretados para un archivo en particular, utilice el siguiente ejemplo:

**AdvancedUsage.WorkingWithInterpretedValues**

```csharp
foreach (string file in Directory.GetFiles(Constants.InputPath))
{
    using (Metadata metadata = new Metadata(file))
    {
        if (metadata.FileFormat != FileFormat.Unknown && !metadata.GetDocumentInfo().IsEncrypted)
        {
            Console.WriteLine();
            Console.WriteLine(file);
            var properties = metadata.FindProperties(p => p.InterpretedValue != null);
            foreach (var property in properties)
            {
                Console.WriteLine(property.Name);
                Console.WriteLine(property.Value.RawValue);
                Console.WriteLine(property.InterpretedValue.RawValue);
            }
        }
    }
}
```

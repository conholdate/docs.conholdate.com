## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Puede descargar fácilmente GroupDocs.Metadata para evaluación. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. Al utilizar la API sin licencia, se enfrentará a las siguientes limitaciones:  

| API | Limitaciones |
| --- | --- |
| Propiedades del documento (PDF, Word, Excel, PowerPoint, Visio, etc.) | Solo se pueden leer las primeras 5 propiedades |
| API XMP | Solo se pueden leer los primeros 2 esquemas XMP |
| API EXIF | El IFD de GPS y la miniatura de la imagen no están disponibles |
| API EXIF | Solo se pueden leer las primeras 5 propiedades |
| API IPTC | Solo se pueden leer las primeras 5 propiedades |
| Etiquetas Id3v2, Lyrics3 y APEv2 | Solo se pueden leer las primeras 5 propiedades |
| Átomos QuickTime | Solo se pueden leer los primeros 5 átomos |
| Apertura de archivos | Se pueden abrir un máximo de 15 archivos; de lo contrario, la API lanza una excepción |
| Guardado de archivos | No es compatible en el modo de prueba |

## Licencias  {#licensing}
  
El archivo de licencia contiene detalles como el nombre del producto, la cantidad de desarrolladores a los que está licenciado, la fecha de caducidad de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará su validez. Debe establecer una licencia antes de utilizar la API de GroupDocs.Metadata si desea evitar sus limitaciones de evaluación.  

La licencia puede cargarse desde un archivo o un objeto de flujo. La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Metadata.dll y especificar el nombre del archivo, sin ruta de acceso, como se muestra en los ejemplos siguientes.  

### Aplicación de la licencia desde un archivo {#applying-license-from-file}
  
El código siguiente explica cómo aplicar una licencia del producto.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-metadata/GroupDocs.Metadata-for-.NET

// initialize License
License lic = new License();

// apply license
lic.SetLicense("GroupDocs.Metadata.lic");

```

### Aplicar licencia desde un flujo  {#applying-license-from-stream}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-metadata/GroupDocs.Metadata-for-.NET

using (FileStream fileStream = new FileStream("GroupDocs.Metadata.lic", FileMode.Open, FileAccess.Read))
{
    License lic = new License();
    lic.SetLicense(fileStream);
}
```

:::info
Llamar a `License.SetLicense` varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, llame a `License.SetLicense` en su código de inicio, antes de utilizar las clases de `GroupDocs.Metadata`. Al desarrollar una aplicación ASP.NET, puede llamar a `License.SetLicense` desde el archivo `Global.asax.cs` (`Global.asax.vb`) dentro del método protegido `Application_Start`, el cual se ejecuta una única vez al iniciar la aplicación. No llame a `License.SetLicense` desde dentro de los métodos `Page_Load`, ya que esto implica que la licencia se cargará cada vez que se cargue una página web.
:::

### Aplicación de la licencia por medición  {#applying-metered-license}

:::info
También puede configurar la licencia <a href="https://reference.groupdocs.com/net/metadata/groupdocs.metadata/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean facturarse según el uso de las características de la API. Para obtener más detalles, consulte la sección <a href="https://purchase.groupdocs.com/faqs/licensing/metered" target="_blank" rel="nofollow noopener noreferrer">Preguntas frecuentes sobre licencias basadas en uso</a>.
:::

A continuación se presentan los pasos sencillos para utilizar la clase `Metered`.

1.  Cree una instancia de la clase `Metered`.
2.  Pase las claves pública y privada al método `setMeteredKey`.
3.  Realice el procesamiento (ejecute la tarea).
4.  Llame al método `getConsumptionQuantity` de la clase `Metered`.
5.  Este método devolverá la cantidad/cantidad de solicitudes de API que ha consumido hasta el momento.
6.  Llame al método `getConsumptionCredit` de la clase `Metered` (desde la versión 19.5).
7.  Este método devolverá el crédito que ha consumido hasta el momento.

A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase `Metered`.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-metadata/GroupDocs.Metadata-for-.NET

// initialize Metered API
Metered metered = new Metered();

// set-up credentials
metered.SetMeteredKey("publicKey", "privateKey");

```

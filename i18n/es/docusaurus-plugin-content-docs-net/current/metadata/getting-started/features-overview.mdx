## Características de GroupDocs.Metadata para .NET {#groupdocs-metadata-for-net-features}

Una API de metadatos para .NET puede utilizarse eficazmente para eliminar, actualizar y leer metadatos en una amplia variedad de formatos. Es muy eficaz para eliminar metadatos de imágenes. Admite metadatos IPTC, EXIF y XMP. A continuación se muestra la lista de características admitidas por la API GroupDocs.Metadata para .NET:

*   Lectura, actualización y eliminación de metadatos en una amplia variedad de formatos  
*   Búsqueda, actualización y eliminación de propiedades de metadatos específicas que satisfagan un predicado especificado  
*   Uso de etiquetas para manipular fácilmente las propiedades de metadatos más comunes de forma unificada  
*   Trabajo con documentos protegidos con contraseña  
*   Extracción de información sobre páginas ocultas del documento, firmas digitales, comentarios de usuario, revisiones, etc.  
*   Trabajo con los estándares de metadatos más populares: IPTC, XMP, EXIF, Image Resources  
*   Manipulación de propiedades de metadatos nativas en diversos formatos, extracción de información técnica de imágenes, archivos de audio y video  
*   Cálculo de estadísticas comunes de documentos (recuento de palabras, recuento de caracteres, etc.)  
*   Detección del formato y tipo MIME de un archivo mediante su estructura interna  
*   Trabajo con diversas etiquetas de audio (ID3, Lyrics, APE)

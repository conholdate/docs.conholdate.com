## Instalación de GroupDocs.Metadata para .NET mediante NuGet {#installing-groupdocs-metadata-for-net-through-nuget}
  
NuGet es la forma más sencilla de descargar e instalar GroupDocs.Metadata para .NET. A continuación se presentan algunas formas de instalar GroupDocs.Metadata para .NET en su proyecto utilizando NuGet.  
Para instalarlo, puede utilizar cualquiera de los comandos adecuados para su entorno <a href="https://www.nuget.org/packages/GroupDocs.Metadata" target="_blank" rel="nofollow noopener noreferrer">NugetInstall</a>.  
A continuación se muestran ejemplos de cómo instalarlo cuando se utiliza Visual Studio.

### Utilizar la interfaz gráfica del Administrador de paquetes {#using-package-manager-gui}
  
Siga estos pasos para hacer referencia a GroupDocs.Metadata mediante la interfaz gráfica del Administrador de paquetes:

*   Abra su solución/proyecto en Visual Studio.  
*   Haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Administrar paquetes NuGet para la solución**. También puede acceder a esta misma opción desde el Explorador de soluciones: haga clic con el botón derecho en la solución o el proyecto y seleccione **Administrar paquetes NuGet** en el menú contextual.  
*   Seleccione la pestaña **Examinar** y escriba «GroupDocs.Metadata» en el cuadro de texto de búsqueda.  
*   Haga clic en el botón **Instalar** para instalar la versión más reciente de la API en su proyecto, como se muestra en la siguiente captura de pantalla.

![](/net/metadata/images/installation.png)

### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}
  
Puede seguir los pasos a continuación para hacer referencia a GroupDocs.Metadata mediante la Consola del Administrador de Paquetes:

*   Abra su solución/proyecto en Visual Studio.  
*   Seleccione **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de Paquetes** en el menú para abrir la consola del administrador de paquetes.  
*   Escriba el comando `Install-Package GroupDocs.Metadata` y presione Enter para instalar la versión más reciente en su aplicación.  
*   Tras la instalación correcta, GroupDocs.Metadata quedará referenciado en su aplicación.

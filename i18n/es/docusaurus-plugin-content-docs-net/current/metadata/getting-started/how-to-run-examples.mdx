## Descargar desde GitHub {#download-from-github}
  
El paquete completo de ejemplos de **GroupDocs.Metadata** está alojado en <a href="https://github.com/groupdocsmetadata/GroupDocs_Metadata_NET" target="_blank" rel="nofollow noopener noreferrer">Github</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocsmetadata/GroupDocs_Metadata_NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando su cliente de GitHub favorito.

En caso de descargar el archivo ZIP, extraiga las carpetas en su disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![](/net/metadata/images/how-to-run-examples.png)

Este proyecto se crea en **Microsoft Visual Studio 2017**. La carpeta **SampleFiles** contiene todos los archivos de documento e imagen de ejemplo utilizados en los ejemplos.

Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Todas las funciones se llaman desde **RunExamples.cs**. Descomente la función que desea ejecutar.

![](/net/metadata/images/how-to-run-examples_1.png)

## Contribuir {#contribute}
  
Si deseas agregar o mejorar un ejemplo, te animamos a contribuir al proyecto. Todos los ejemplos de este repositorio son de código abierto y pueden utilizarse libremente en tus propias aplicaciones.  
Para contribuir, puedes bifurcar el repositorio, editar el código y crear una solicitud de extracción (*pull request*). Revisaremos los cambios y los incluiremos en el repositorio si se consideran útiles.

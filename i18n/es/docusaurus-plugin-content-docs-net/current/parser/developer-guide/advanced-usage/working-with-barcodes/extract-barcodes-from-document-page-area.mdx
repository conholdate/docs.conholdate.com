GroupDocs.Parser proporciona la funcionalidad para extraer códigos de barras de documentos mediante <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/getbarcodes/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> método:

```csharp
IEnumerable<PageBarcodeArea> GetBarcodes(PageAreaOptions options);
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular en la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/properties/value" target="_blank" rel="nofollow noopener noreferrer">Value</a> | Un valor de tipo cadena que representa un valor del área de la página del código de barras. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/properties/codetypename" target="_blank" rel="nofollow noopener noreferrer">CodeTypeName</a> | Un valor de tipo cadena que representa el nombre del tipo del código de barras. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/confidence/" target="_blank" rel="nofollow noopener noreferrer">Confidence</a> | El nivel de confianza del código de barras analizado. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea/angle/" target="_blank" rel="nofollow noopener noreferrer">Angle</a> | El ángulo del código de barras. |

A continuación se indican los pasos para extraer todos los códigos de barras del documento completo:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
- Comprobar si el documento admite la extracción de códigos de barras;
- Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/BarcodeOptions" target="_blank" rel="nofollow noopener noreferrer">BarcodeOptions</a> con el área rectangular;
- Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/getbarcodes/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>;
- Recorrer la colección y obtener el valor del código de barras.

El siguiente ejemplo muestra cómo extraer códigos de barras desde la esquina superior derecha:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SamplePdfWithBarcodes))
{
    // Check if the document supports barcodes extraction
    if (!parser.Features.Barcodes)
    {
        Console.WriteLine("Document doesn't support barcodes extraction.");
        return;
    }

    // Create the options which are used for barcodes extraction
    BarcodeOptions options = new BarcodeOptions(new Rectangle(new Point(590, 80), new Size(150, 150)));
    // Extract barcodes from the upper-right corner.
    IEnumerable<PageBarcodeArea> barcodes = parser.GetBarcodes(options);

    // Iterate over barcodes
    foreach (PageBarcodeArea barcode in barcodes)
    {
        // Print the page index
        Console.WriteLine("Page: " + barcode.Page.Index.ToString());
        // Print the barcode value
        Console.WriteLine("Value: " + barcode.Value);
    }
}
```

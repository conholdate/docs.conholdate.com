GroupDocs.Parser proporciona la funcionalidad para extraer tablas de documentos, incluidas **hojas de cálculo de Excel (XLS, XLSX)**, documentos de Word, archivos PDF y otros formatos admitidos, mediante el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/gettables" target="_blank" rel="nofollow noopener noreferrer">GetTables(PageTableAreaOptions)</a>.

## Extraer tablas de Excel en C# {#extract-tables-from-excel-c}

Para **extraer tablas de Excel en aplicaciones C#**, GroupDocs.Parser admite la extracción de datos estructurados de tablas desde hojas de cálculo de Excel. Esto resulta especialmente útil para procesar programáticamente archivos de Excel que contienen grandes cantidades de datos.

```csharp
IEnumerable<PageTableArea> GetTables(PageTableAreaOptions options);
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagetablearea" target="_blank" rel="nofollow noopener noreferrer">PageTableArea</a>:

| Miembro | Descripción |
| ------------------------------------------------------------ | ----------------------------------------------- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular que delimita el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La información de la página (índice de página y tamaño de página). |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/properties/rowcount" target="_blank" rel="nofollow noopener noreferrer">RowCount</a> | El número total de filas de la tabla. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/properties/columncount" target="_blank" rel="nofollow noopener noreferrer">ColumnCount</a> | El número total de columnas de la tabla. |
| PageTableAreaCell <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/properties/item" target="_blank" rel="nofollow noopener noreferrer">Item</a> | La celda de la tabla según los índices de fila y columna. |
| double <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/methods/getrowheight" target="_blank" rel="nofollow noopener noreferrer">GetRowHeight(int)</a> | La altura de la fila. |
| double <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/methods/getcolumnwidth" target="_blank" rel="nofollow noopener noreferrer">GetColumnWidth(int)</a> | Devuelve el ancho de la columna. |

<a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/gettables" target="_blank" rel="nofollow noopener noreferrer">GetTables(PageTableAreaOptions)</a> acepta un objeto <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/pagetableareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageTableAreaOptions</a> que contiene un objeto <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.templates/templatetablelayout" target="_blank" rel="nofollow noopener noreferrer">TemplateTableLayout</a> con el diseño de la tabla (consulte [este artículo](/net/parser/developer-guide/advanced-usage/working-with-templates/) para obtener más detalles).

### Pasos básicos {#basic-steps}

A continuación se presentan los pasos básicos para extraer tablas de documentos:

1. Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento (Excel, Word, PDF, etc.);
2. Verificar si el documento admite la **extracción de tablas** mediante la propiedad `Features.Tables`;
3. Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/gettables" target="_blank" rel="nofollow noopener noreferrer">GetTables(PageTableAreaOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagetablearea" target="_blank" rel="nofollow noopener noreferrer">PageTableArea</a>;
4. Iterar a través de la colección y acceder a las celdas de la tabla.

### Ejemplo: Extraer tablas de una hoja de cálculo de Excel {#example-extract-tables-from-excel-spreadsheet}

```csharp
using GroupDocs.Parser;
using GroupDocs.Parser.Options;
using GroupDocs.Parser.Data;
using GroupDocs.Parser.Templates;

// Excel file path
string excelPath = "sample.xlsx";

using (Parser parser = new Parser(excelPath))
{
    // Check if table extraction is supported for Excel
    if (!parser.Features.Tables)
    {
        Console.WriteLine("Table extraction is not supported for this Excel file.");
        return;
    }
    
    // Extract all tables from the Excel spreadsheet
    // Pass null to extract tables automatically
    IEnumerable<PageTableArea> tables = parser.GetTables();
    
    int tableIndex = 0;
    foreach (PageTableArea table in tables)
    {
        Console.WriteLine($"\n=== Table {++tableIndex} ===");
        Console.WriteLine($"Rows: {table.RowCount}, Columns: {table.ColumnCount}");
        
        // Iterate over rows
        for (int row = 0; row < table.RowCount; row++)
        {
            // Iterate over columns
            for (int column = 0; column < table.ColumnCount; column++)
            {
                // Get the table cell
                PageTableAreaCell cell = table[row, column];
                if (cell != null)
                {
                    // Print the cell text
                    Console.Write($"{cell.Text}\t");
                }
            }
            Console.WriteLine();
        }
    }
}
```

### Ejemplo: Extraer tablas con diseño personalizado {#example-extract-tables-with-custom-layout}

El siguiente ejemplo muestra cómo extraer tablas de documentos cuando se conoce la estructura exacta de la tabla (posiciones de columnas y filas):

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports table extraction
    if (!parser.Features.Tables)
    {
        Console.WriteLine("Document isn't supports tables extraction.");
        return;
    }
    // Create the layout of tables
    TemplateTableLayout layout = new TemplateTableLayout(
        new double[] { 50, 95, 275, 415, 485, 545 },
        new double[] { 325, 340, 365, 395 });
    // Create the options for table extraction
    PageTableAreaOptions options = new PageTableAreaOptions(layout);
    // Extract tables from the document
    IEnumerable<PageTableArea> tables = parser.GetTables(options);
    // Iterate over tables
    foreach (PageTableArea t in tables)
    {
        // Iterate over rows
        for (int row = 0; row < t.RowCount; row++)
        {
            // Iterate over columns
            for (int column = 0; column < t.ColumnCount; column++)
            {
                // Get the table cell
                PageTableAreaCell cell = t[row, column];
                if (cell != null)
                {
                    // Print the table cell text
                    Console.Write(cell.Text);
                    Console.Write(" | ");
                }
            }
            Console.WriteLine();
        }
        Console.WriteLine();
    }
}
```

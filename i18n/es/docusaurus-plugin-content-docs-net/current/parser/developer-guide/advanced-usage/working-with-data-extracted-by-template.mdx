## Clase DocumentData {#documentdata-class}

Los datos extraídos se almacenan en una instancia de la clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata" target="_blank" rel="nofollow noopener noreferrer">DocumentData</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata/properties/count" target="_blank" rel="nofollow noopener noreferrer">Count</a> | El número total de campos de datos. |
| DataField <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata/properties/item" target="_blank" rel="nofollow noopener noreferrer">Item</a> | El campo de datos. |
| IList&lt;FieldData&gt; <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/documentdata/methods/getfieldsbyname" target="_blank" rel="nofollow noopener noreferrer">GetFieldsByName(String)</a> | Devuelve la colección de campos de datos cuyo nombre coincide con el nombre proporcionado. |

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata" target="_blank" rel="nofollow noopener noreferrer">FieldData</a> La clase tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> | El nombre del campo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">PageIndex</a> | El índice de página. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata/properties/pagearea" target="_blank" rel="nofollow noopener noreferrer">PageArea</a> | El valor del campo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata/properties/linkedfield" target="_blank" rel="nofollow noopener noreferrer">LinkedField</a> | El campo vinculado. |

Los datos del campo se almacenan en la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/fielddata/properties/pagearea" target="_blank" rel="nofollow noopener noreferrer">PageArea</a>. Dependiendo del tipo de valor, puede contener una instancia de las clases <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea" target="_blank" rel="nofollow noopener noreferrer">PageTextArea</a> o <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea" target="_blank" rel="nofollow noopener noreferrer">PageTableArea</a>:

```csharp
// Get the field data
FieldData field = data[i];
// Check if the field data contains a text
if(field.PageArea is PageTextArea)
{
    // Print the field value
    Console.WriteLine((field.PageArea as PageTextArea).Text);
}
```

La clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea" target="_blank" rel="nofollow noopener noreferrer">PageTextArea</a> representa un bloque de texto en la página. Esta clase tiene los siguientes miembros:

| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La información de la página (índice de página y tamaño de página). |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El valor del área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea/properties/baseline" target="_blank" rel="nofollow noopener noreferrer">BaseLine</a> | La línea base del área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea/properties/textstyle" target="_blank" rel="nofollow noopener noreferrer">TextStyle</a> | El estilo del bloque de texto (por ejemplo, nombre de fuente, tamaño de fuente, etc.). |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetextarea/properties/areas" target="_blank" rel="nofollow noopener noreferrer">Areas</a> | La colección de áreas de texto secundarias. |

El área de texto puede ser simple o compuesta. En el primer caso, contiene un texto delimitado por un área rectangular. En el segundo caso, contiene otras áreas de texto; las propiedades de texto y tabla se calculan a partir de las áreas de texto secundarias.

La clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea" target="_blank" rel="nofollow noopener noreferrer">PageTableArea</a> representa una tabla. Esta clase tiene los siguientes miembros:

| Miembro | Descripción |

| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La información de la página (índice de página y tamaño de página). |

| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/properties/columncount" target="_blank" rel="nofollow noopener noreferrer">ColumnCount</a> | El número total de columnas de la tabla. |
| PageTableAreaCell <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagetablearea/properties/item" target="_blank" rel="nofollow noopener noreferrer">Item</a> | La celda de la tabla según los índices de fila y columna. |

Existen dos formas de trabajar con los datos de los campos.

## Iterar a través de los campos {#iterate-through-fields}

El siguiente ejemplo muestra cómo iterar sobre los datos extraídos de los campos:

```csharp
for (int i = 0; i < data.Count; i++) {
    Console.Write(data[i].Name + ": ");
    PageTextArea area = data[i].PageArea as PageTextArea;
    Console.WriteLine(area == null ? "Not a template field" : area.Text);
}
```

## Obtener campo por nombre {#get-field-by-name}

El siguiente ejemplo muestra cómo obtener un campo por su nombre:

```csharp
// Get all the fields with "Address" name
IList<FieldData> addressFields = data.GetFieldsByName("Address");
if(addressFields.Count == 0) {
    Console.WriteLine("Address not found");
}
else {
    Console.WriteLine("Address");
    // Iterate over the fields collection
    for (int i = 0; i < addressFields.Count; i++) {
        PageTextArea area = addressFields[i].PageArea as PageTextArea;
        Console.WriteLine(area == null ? "Not a template field" : area.Text);        
        
        // If it's a related field:
        if(addressFields[i].LinkedField != null) {
            Console.Write("Linked to ");
            PageTextArea linkedArea = addressFields[i].LinkedField.PageArea as PageTextArea;
            Console.WriteLine(linkedArea == null ? "Not a template field" : linkedArea.Text);            
        }
    }
}
```

Esta funcionalidad permite recorrer todos los campos de datos y seleccionar el más adecuado. Por ejemplo, si más de un valor de texto cumple la condición de la expresión regular, el usuario puede recorrerlos y seleccionar el más adecuado.

## Trabajo con tablas {#working-with-tables}

El siguiente ejemplo muestra cómo trabajar con tablas extraídas:

```csharp
// Print all extracted data
for (int i = 0; i < data.Count; i++)
{
    Console.Write(data[i].Name + ": ");
    // Check if the field is a table
    PageTableArea area = data[i].PageArea as PageTableArea;
    if (area == null)
    {
        continue;
    }
    // Iterate via table rows
    for (int row = 0; row < area.RowCount; row++)
    {
        // Iterate via table columns
        for (int column = 0; column < area.ColumnCount; column++)
        {
            // Get the cell value
            PageTextArea cellValue = area[row, column].PageArea as PageTextArea;
            // Print the space between columns
            if (column > 0)
            {
                Console.Write("\t");
            }
            // Print the cell value
            Console.Write(cellValue == null ? "" : cellValue.Text);
        }
        // Print a new line
        Console.WriteLine();
    }
}
```

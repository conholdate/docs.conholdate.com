Para evitar la sobrecarga de guardar documentos en el disco, GroupDocs.Parser permite extraer datos directamente desde una URL.

El siguiente ejemplo muestra cómo cargar un documento desde una URL:

```csharp
// Create an instance of Parser class with the url
using (Parser parser = new Parser(url))
{
    // Extract a text into the reader
    using (TextReader reader = parser.GetText())
    {
        // Print a text from the document
        // If text extraction isn't supported, a reader is null
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```


:::info
Este constructor hace que GroupDocs.Parser descargue el documento en sí. Si la URL proviene de una entrada no confiable, validela antes de usarla. Consulte [Acceso a la red y privacidad de datos](/net/parser/getting-started/network-access-and-data-privacy/) para la lista completa de situaciones en las que la biblioteca realiza solicitudes de red salientes.
:::

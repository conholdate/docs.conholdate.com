GroupDocs.Parser proporciona la funcionalidad para extraer datos de documentos ubicados en el disco local.

El siguiente ejemplo muestra cómo cargar un documento desde el disco local:

```csharp
// Create an instance of Parser class with the filePath
using (Parser parser = new Parser(filePath))
{
    // Extract a text into the reader
    using (TextReader reader = parser.GetText())
    {
        // Print a text from the document
        // If text extraction isn't supported, a reader is null
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

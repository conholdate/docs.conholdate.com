Puede haber casos en los que el documento se presente únicamente como un flujo (sin una copia en el disco local). Para evitar la sobrecarga de guardar documentos en el disco, GroupDocs.Parser permite extraer datos directamente desde flujos.

El siguiente ejemplo muestra cómo cargar un documento desde un flujo:

```csharp
// Create an instance of Parser class with the stream
using (Parser parser = new Parser(stream))
{
    // Extract a text into the reader
    using (TextReader reader = parser.GetText())
    {
        // Print a text from the document
        // If text extraction isn't supported, a reader is null
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

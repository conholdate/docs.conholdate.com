GroupDocs.Parser proporciona la funcionalidad para manejar la carga de recursos externos en HTML.

A continuación se indican los pasos para manejar la carga de recursos externos en HTML.

*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a> y pasarle el controlador de recursos externos;
*   Crear el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> y llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getimages/" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>.

El siguiente ejemplo de código muestra cómo manejar la carga de recursos externos en HTML.

```csharp
// Create an instance of ParserSettings to pass External Resource Handler
ParserSettings settings = new ParserSettings(new Handler());

// Create an instance of Parser class to generate spreadsheet page previews
using (Parser parser = new Parser(Constants.SampleHtmlWithImages, settings))
{
    // Extract images from HTML document
    IEnumerable<PageImageArea> images = parser.GetImages();

    // Iterate over extracted images
    foreach (PageImageArea i in images)
    {
        // Print the type of image
        Console.WriteLine(i.FileType);
    }
}

/// <summary>
/// This class provides the ability to filter extracted images.
/// </summary>
private class Handler : ExternalResourceHandler
{
    /// <summary>
    /// Called before any external resource loads. It allows to skip unnesesary file loading.
    /// </summary>
    public override void OnLoading(ExternalResourceLoadingArgs args)
    {
        // Check if the file name ends with installation.png
        if (!args.Uri.EndsWith("installation.png"))
        {
            // Otherwise skip this file
            args.Skipped = true;
        }

        base.OnLoading(args);
    }
}
```


:::warning
La carga de recursos externos está habilitada de forma predeterminada, lo que significa que el análisis de un documento procedente de una fuente no confiable puede provocar solicitudes HTTP salientes a hosts especificados dentro de dicho documento, por ejemplo, imágenes remotas o hojas de estilos a las que se hace referencia en un archivo HTML o MHTML, o en el cuerpo HTML de un correo electrónico, imágenes vinculadas en documentos de procesamiento de texto y campos `INCLUDEPICTURE`.

A partir de la versión 26.6.1, `ExternalResourceHandler` intercepta únicamente la extracción de imágenes desde HTML y MHTML; otros métodos de extracción y otros formatos no pasan por este mecanismo. Para garantizar que no se realice ninguna solicitud saliente, bloquee el tráfico saliente a nivel de red o de proceso. Consulte [Acceso a la red y privacidad de los datos](/net/parser/getting-started/network-access-and-data-privacy/) para conocer el comportamiento medido por formato.
:::

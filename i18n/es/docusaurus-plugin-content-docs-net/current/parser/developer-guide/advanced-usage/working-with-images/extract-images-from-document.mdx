GroupDocs.Parser proporciona la funcionalidad para extraer imágenes de documentos mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>:

```csharp
IEnumerable<PageImageArea> GetImages();
```

Los métodos devuelven una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular en la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | El formato de la imagen. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> | El ángulo de rotación de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/getimagestream" target="_blank" rel="nofollow noopener noreferrer">GetImageStream()</a> | Devuelve el flujo de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/getimagestream/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImageStream(ImageOptions)</a> | Devuelve el flujo de la imagen en un formato diferente. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> | Guarda la imagen en un archivo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/save/methods/1" target="_blank" rel="nofollow noopener noreferrer">Save(string, ImageOptions)</a> | Guarda la imagen en un archivo en un formato diferente. |

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> La clase se utiliza para definir el formato en el que se convierte la imagen. Los formatos de imagen admitidos son los siguientes:

*   Bmp
*   Gif
*   Jpeg
*   Png
*   WebP

A continuación se indican los pasos para extraer imágenes del documento completo:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>;
*   Comprobar si la *colección* no es *nula* (la extracción de imágenes es compatible con el documento);
*   Iterar a través de la colección y obtener los tamaños, tipos e contenido de las imágenes.

El siguiente ejemplo muestra cómo extraer imágenes de un documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract images
    IEnumerable<PageImageArea> images = parser.GetImages();
    
    // Check if image extraction is supported
    if (images == null)
    {
        Console.WriteLine("Image extraction isn't supported");
        return;
    }
    
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Print page index and image type
        Console.WriteLine($"Page: {image.Page.Index + 1}, Type: {image.FileType}");
    }
}
```

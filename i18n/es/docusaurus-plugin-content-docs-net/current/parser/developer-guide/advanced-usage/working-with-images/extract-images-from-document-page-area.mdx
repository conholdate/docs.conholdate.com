GroupDocs.Parser proporciona la funcionalidad para extraer imágenes del área de página de un documento mediante <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/1" target="_blank" rel="nofollow noopener noreferrer">ObtenerImágenes(OpcionesDeAreaDePágina)</a> y <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/3" target="_blank" rel="nofollow noopener noreferrer">GetImages(int, PageAreaOptions)</a> métodos:

```csharp
IEnumerable<PageImageArea> GetImages(PageAreaOptions options);
IEnumerable<PageImageArea> GetImages(int pageIndex, PageAreaOptions options);

```

Los métodos devuelven una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular de la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | El formato de la imagen. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> | El ángulo de rotación de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/getimagestream" target="_blank" rel="nofollow noopener noreferrer">GetImageStream()</a> | Devuelve el flujo de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/getimagestream/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImageStream(ImageOptions)</a> | Devuelve el flujo de la imagen en un formato diferente. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> | Guarda la imagen en un archivo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/save/methods/1" target="_blank" rel="nofollow noopener noreferrer">Save(string, ImageOptions)</a> | Guarda la imagen en un archivo en un formato diferente. |

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> se utiliza para definir el formato en el que se convierte la imagen. Los formatos de imagen admitidos son los siguientes:

*   Bmp
*   Gif
*   Jpeg
*   Png
*   WebP

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> se utiliza para personalizar el proceso de extracción de áreas de texto. Esta clase tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular que contiene un área de texto. |

A continuación se indican los pasos para extraer imágenes desde la esquina superior izquierda:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> con el área rectangular;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImages(PageAreaOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>;
*   Comprobar si la *colección* no es *null* (la extracción de imágenes es compatible con el documento);
*   Iterar sobre la colección y obtener tamaños, tipos de imagen y contenido de las imágenes.

El siguiente ejemplo muestra cómo extraer únicamente las imágenes desde la esquina superior izquierda:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Create the options which are used for images extraction
    PageAreaOptions options = new PageAreaOptions(new Rectangle(new Point(0, 0), new Size(300, 100)));
    // Extract images from the upper-left corner of a page:
    IEnumerable<PageImageArea> images = parser.GetImages(options);
    // Check if images extraction is supported
    if (images == null)
    {
        Console.WriteLine("Page images extraction isn't supported");
        return;
    }
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Print a page index, rectangle and image type:
        Console.WriteLine(string.Format("Page: {0}, R: {1}, Type: {2}", image.Page.Index, image.Rectangle, image.FileType));
    }
}

```

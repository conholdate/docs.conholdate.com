GroupDocs.Parser proporciona la funcionalidad para extraer imágenes de una página de documento mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/2" target="_blank" rel="nofollow noopener noreferrer">GetImages(int)</a>:

```csharp
IEnumerable<PageImageArea> GetImages(int pageIndex);
```

Los métodos devuelven una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular en la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | El formato de la imagen. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/properties/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> | El ángulo de rotación de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/getimagestream" target="_blank" rel="nofollow noopener noreferrer">GetImageStream()</a> | Devuelve el flujo de la imagen. |
| Stream <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/getimagestream/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetImageStream(ImageOptions)</a> | Devuelve el flujo de la imagen en un formato diferente. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea/methods/save" target="_blank" rel="nofollow noopener noreferrer">Save(string)</a> | Guarda la imagen en un archivo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.pageimagearea/save/methods/1" target="_blank" rel="nofollow noopener noreferrer">Save(string, ImageOptions)</a> | Guarda la imagen en un archivo en un formato diferente. |

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> se utiliza para definir el formato en el que se convierte la imagen. Los formatos de imagen admitidos son los siguientes:

*   Bmp
*   Gif
*   Jpeg
*   Png
*   WebP

A continuación se indican los pasos para extraer imágenes de la página del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar a la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/images" target="_blank" rel="nofollow noopener noreferrer">Features.Images</a> para comprobar si la extracción de imágenes es compatible con el documento;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getimages/methods/2" target="_blank" rel="nofollow noopener noreferrer">GetImages(int)</a> pasando el índice de página y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pageimagearea" target="_blank" rel="nofollow noopener noreferrer">PageImageArea</a>;
*   Recorrer la colección y obtener los tamaños, tipos e contenido de las imágenes.

El siguiente ejemplo muestra cómo extraer imágenes de una página del documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports images extraction
    if (!parser.Features.Images)
    {
        Console.WriteLine("Document isn't supports images extraction.");
        return;
    }
    // Get the document info
    IDocumentInfo documentInfo = parser.GetDocumentInfo();
    // Check if the document has pages
    if (documentInfo.PageCount == 0)
    {
        Console.WriteLine("Document hasn't pages.");
        return;
    }
    // Iterate over pages
    for (int pageIndex = 0; pageIndex < documentInfo.PageCount; pageIndex++)
    {
        // Print a page number 
        Console.WriteLine(string.Format("Page {0}/{1}", pageIndex + 1, documentInfo.PageCount));
        // Iterate over images
        // We ignore null-checking as we have checked images extraction feature support earlier
        foreach (PageImageArea image in parser.GetImages(pageIndex))
        {
            // Print a rectangle and image type
            Console.WriteLine(string.Format("R: {0}, Text: {1}", image.Rectangle, image.FileType));
        }
    }
}
```

# Detección del tipo de archivo de elementos contenedores

GroupDocs.Parser proporciona la funcionalidad para detectar el tipo de archivo de los elementos contenedores mediante el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/containeritem/methods/detectfiletype" target="_blank" rel="nofollow noopener noreferrer">DetectFileType</a>. El parámetro <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/filetypedetectionmode" target="_blank" rel="nofollow noopener noreferrer">FileTypeDetectionMode</a> permite controlar la detección del tipo de archivo:

- Predeterminado. El tipo de archivo se detecta mediante la extensión del archivo; si la extensión no se reconoce, el tipo de archivo se determina mediante el contenido del archivo.
- Extension. El tipo de archivo se detecta únicamente mediante la extensión del archivo.
- Content. El tipo de archivo se detecta únicamente mediante el contenido del archivo.

A continuación se indican los pasos para detectar el tipo de archivo de los elementos contenedores:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser </a> para el documento inicial;
- Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>;
- Comprobar si la *colección* no es *null* (la extracción de contenedores es compatible con el documento);
- Iterar sobre la colección y llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/containeritem/methods/detectfiletype" target="_blank" rel="nofollow noopener noreferrer">DetectFileType</a>.

El siguiente ejemplo muestra cómo detectar el tipo de archivo de los elementos contenedores:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if (attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
    // Iterate over attachments
    foreach (ContainerItem item in attachments)
    {
        // Detect the file type
        Options.FileType fileType = item.DetectFileType(Options.FileTypeDetectionMode.Default);
         
        // Print the name and file type
        Console.WriteLine(string.Format("{0}: {1}", item.Name, fileType));
    }
}
```

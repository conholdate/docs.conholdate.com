GroupDocs.Parser proporciona la funcionalidad para extraer elementos de contenedores mediante <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> método:

```csharp
IEnumerable<ContainerItem> GetContainer();
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>:

A continuación se indican los pasos para extraer el contenedor del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>;
*   Comprobar si la *colección* no es *null* (la extracción de contenedores es compatible con el documento);
*   Iterar sobre la colección y obtener los nombres, tamaños y contenido de los elementos contenedores.

El siguiente ejemplo muestra cómo extraer archivos adjuntos de un contenedor:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if(attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }

    // Iterate over attachments
    foreach(ContainerItem item in attachments)
    {
        // Print an item name and size
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Size));
    }
}
```

El contenedor representa tanto archivos que contienen únicamente contenedores (como archivos ZIP o almacenamientos de Outlook) como documentos con adjuntos (como correos electrónicos o PDF Portfolios).

En el caso del almacenamiento de Outlook (archivos OST/PST), el contenedor está compuesto por documentos de correo electrónico (archivos MSG).

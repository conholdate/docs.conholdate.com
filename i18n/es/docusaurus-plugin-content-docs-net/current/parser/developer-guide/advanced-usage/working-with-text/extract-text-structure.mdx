GroupDocs.Parser proporciona la funcionalidad para extraer la estructura de texto de los documentos mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a>:

```csharp
XmlReader GetStructure();
```

Este método devuelve la representación XML de un documento. Un documento tiene la siguiente estructura:

![](/net/parser/images/extract-text-structure.png)


| Etiqueta | Descripción |
| --- | --- |
| document | Etiqueta raíz |
| section | Representa una sección del documento. Dependiendo del tipo de documento, puede representar una hoja de cálculo, una diapositiva, etc. Puede contener los siguientes atributos: **style**: el estilo de la sección; **name**: el nombre de la sección (por ejemplo, el nombre de la hoja) |
| p | Representa un párrafo de texto. Puede contener el siguiente atributo: **style**: el estilo del párrafo |
| ul | Representa una lista desordenada |
| ol | Representa una lista ordenada |
| li | Representa un elemento de lista |
| shape | Representa un objeto de forma |
| table | Representa una tabla |
| tr | Representa una fila de tabla |
| td | Representa una celda de tabla. Puede contener los siguientes atributos: **rowIndex**: índice de fila (base cero); **columnIndex**: índice de columna (base cero); **rowSpan**: número total de filas que contiene la celda; **columnSpan**: número total de columnas que contiene la celda |

Las etiquetas tienen las siguientes relaciones:

*   **document** puede contener cualquier número de etiquetas **section**
*   **section** puede contener cualquier número de etiquetas **p**, **ul**, **ol** o **table**, en cualquier orden
*   **table** puede contener cualquier número de etiquetas **tr**
*   **tr** puede contener cualquier número de etiquetas **td**
*   **td** puede contener una etiqueta **p**

Las etiquetas **p** y **li** pueden contener las etiquetas **hyperlink**, **strong**, **em** y el valor que representa un texto:

![](/net/parser/images/extract-text-structure_1.png))![](/net/parser/images/extract-text-structure_2.png)

| Etiqueta | Descripción |
| --- | --- |
| hyperlink | Representa un hipervínculo. Puede contener el siguiente atributo: link — URL |
| strong | Representa un énfasis fuerte (texto en negrita) |
| em | Representa un énfasis normal (texto en cursiva) |
| br | Representa un salto de línea (etiqueta vacía) |

## Características de la extracción de texto para distintos formatos {#features-of-text-extraction-for-different-formats}

### Documentos de procesamiento de texto {#word-processing-documents}

Los documentos de procesamiento de texto presentan una estructura más compleja: una celda de tabla puede contener un número arbitrario de formas, y un párrafo también puede contener un número arbitrario de formas.

Una celda de tabla puede contener un número arbitrario de párrafos, listas y tablas:

![](/net/parser/images/extract-text-structure_3.png)

Una forma puede contener un único hipervínculo (etiqueta vacía) para toda la forma, así como cualquier número de párrafos, listas o tablas:

![](/net/parser/images/extract-text-structure_4.png)

### Presentaciones {#presentations}

Las presentaciones tienen celdas de tabla y secciones más complejas, y una sección puede contener cualquier número de formas.

Una celda de tabla puede contener cualquier número de párrafos o listas:

![](/net/parser/images/extract-text-structure_5.png)

Una forma puede contener un único hipervínculo (etiqueta vacía) para toda la forma y cualquier número de párrafos o listas:

![](/net/parser/images/extract-text-structure_6.png)

### Hojas de cálculo {#spreadsheets}

Las hojas de cálculo tienen la siguiente estructura de documento:

![](/net/parser/images/extract-text-structure_7.png)

Es más simple que otros. Una sección puede contener cualquier número de formas y únicamente una tabla. Una forma puede contener un único hipervínculo (etiqueta vacía) para toda la forma y cualquier número de párrafos.

## Ejemplos {#examples}

A continuación se indican los pasos para extraer los hipervínculos del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a>;
*   Verificar que *reader* no sea nulo (la extracción de la estructura de texto está soportada para el documento);
*   Procesar el documento XML.

El siguiente ejemplo muestra cómo extraer los hipervínculos del documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract text structure to the XML reader
    using (XmlReader reader = parser.GetStructure())
    {
        // Check if text structure extraction is supported
        if (reader == null)
        {
            Console.WriteLine("Text structure extraction isn't supported.");
            return;
        }

		// Process the XML document
        // Read the XML document to search hyperlinks
        while (reader.Read())
        {
            // Check if this is a start element with "hyperlink" name
            if (reader.NodeType == XmlNodeType.Element && reader.IsStartElement() && reader.Name.ToLowerInvariant() == "hyperlink")
            {
                // Extract "link" attribute
                string value = reader.GetAttribute("link");
                if (value != null)
                {
                    Console.WriteLine(value);
                }
            }
        }
    }
}
```

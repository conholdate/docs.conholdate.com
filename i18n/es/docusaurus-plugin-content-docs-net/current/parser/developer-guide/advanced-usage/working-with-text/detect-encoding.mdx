GroupDocs.Parser proporciona la funcionalidad para detectar la codificación de un archivo de texto sin formato. Las siguientes codificaciones son compatibles:

*   UTF32 LE
*   UTF32 BE
*   UTF16 LE
*   UTF16 BE
*   UTF8
*   UTF7
*   ANSI  

La codificación puede detectarse mediante el BOM (Byte Order Mark) o mediante el contenido del archivo (si no está presente el BOM). 

A continuación se indican los pasos para detectar la codificación del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> con la codificación ANSI predeterminada;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo</a> y convertir el resultado a <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/textdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">TextDocumentInfo</a>;
*   Leer la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/textdocumentinfo/properties/encoding" target="_blank" rel="nofollow noopener noreferrer">Encoding</a>.

El siguiente ejemplo muestra cómo detectar la codificación del documento:

```csharp
// Create an instance of LoadOptions class with the default ANSI encoding.
// This encoding is returned for ANSI text documents.
LoadOptions loadOptions = new LoadOptions(FileFormat.WordProcessing, null, null, Encoding.GetEncoding(1251));
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SampleText, loadOptions))
{
    // Get the document info
    TextDocumentInfo info = parser.GetDocumentInfo() as TextDocumentInfo;
    // Check if it's the document info of a plain text document
    if (info == null)
    {
        Console.WriteLine("Isn't a plain text document");
        return;
    }

    // Print the encoding
    Console.WriteLine("Encoding: " + info.Encoding.WebName);
}
```

GroupDocs.Parser proporciona la funcionalidad para extraer texto con formato de documentos mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText(FormattedTextOptions)</a>:

```csharp
TextReader GetFormattedText(FormattedTextOptions options);
```

Los métodos devuelven una instancia de <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">Lector de texto</a> Clase con el texto extraído. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> tiene el siguiente constructor:

```csharp
FormattedTextOptions(FormattedTextMode mode);
```

La enumeración <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextmode" target="_blank" rel="nofollow noopener noreferrer">FormattedTextMode</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| Html | Formato HTML. |
| Markdown | Formato Markdown. |
| PlainText | Formato de texto sin formato. |

A continuación se indican los pasos para extraer texto con formato HTML del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> con el modo de texto HTML;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText(FormattedTextOptions)</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Comprobar si *reader* no es *null* (la extracción de texto con formato es compatible con el documento);
*   Leer el texto desde *reader*.

El siguiente ejemplo muestra cómo extraer el texto de un documento como texto en formato HTML:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract a formatted text into the reader
    using (TextReader reader = parser.GetFormattedText(new FormattedTextOptions(FormattedTextMode.Html)))
    {
        // Print a formatted text from the document
        // If formatted text extraction isn't supported, a reader is null
        Console.WriteLine(reader == null ? "Formatted text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

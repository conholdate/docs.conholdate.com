GroupDocs.Parser proporciona la funcionalidad para extraer texto con formato desde una página del documento mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getformattedtext/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText(int, FormattedTextOptions)</a>:

```csharp
TextReader GetFormattedText(int pageIndex, FormattedTextOptions options);

```

Los métodos devuelven una instancia de <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">Lector de texto</a> Clase con el texto extraído. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> tiene el siguiente constructor:

```csharp
FormattedTextOptions(FormattedTextMode mode);
```

La enumeración <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextmode" target="_blank" rel="nofollow noopener noreferrer">FormattedTextMode</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| Html | Formato HTML. |
| Markdown | Formato Markdown. |
| PlainText | Formato de texto sin formato. |

A continuación se indican los pasos para extraer el texto de una página en formato HTML del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Comprobar si la extracción de texto con formato es compatible con el documento;
*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> con el modo de texto HTML;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/getformattedtext/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText(int, FormattedTextOptions)</a> pasando el índice de página y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Leer el texto del *lector*.

El siguiente ejemplo muestra cómo extraer el texto de una página del documento en formato Markdown:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports formatted text extraction
    if (!parser.Features.FormattedText)
    {
        Console.WriteLine("Document isn't supports formatted text extraction.");
        return;
    }

    // Get the document info
    IDocumentInfo documentInfo = parser.GetDocumentInfo();
    // Check if the document has pages
    if (documentInfo.PageCount == 0)
    {
        Console.WriteLine("Document hasn't pages.");
        return;
    }
   
    // Iterate over pages
    for (int p = 0; p < documentInfo.PageCount; p++)
    {
        // Print a page number 
        Console.WriteLine(string.Format("Page {0}/{1}", p + 1, documentInfo.PageCount));
        // Extract a formatted text into the reader
        using (TextReader reader = parser.GetFormattedText(p, new FormattedTextOptions(FormattedTextMode.Html)))
        {
            // Print a formatted text from the document
            // We ignore null-checking as we have checked formatted text extraction feature support earlier
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```

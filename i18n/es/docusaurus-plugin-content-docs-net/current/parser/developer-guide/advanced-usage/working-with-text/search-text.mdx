GroupDocs.Parser proporciona la funcionalidad para buscar texto en documentos mediante <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Buscar(cadena)</a> y <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Buscar(string, OpcionesDeBúsqueda)</a> métodos:

```csharp
IEnumerable<SearchResult> Search(string keyword);
IEnumerable<SearchResult> Search(string keyword, SearchOptions options);
```

El parámetro *keyword* puede contener un texto o una expresión regular. La clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> contiene todas las ocurrencias de la palabra clave en el texto del documento. Esta clase tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> | Índice de base cero de la posición inicial del resultado de la búsqueda. Dependiendo del valor de la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/searchbypages" target="_blank" rel="nofollow noopener noreferrer">SearchOptions.SearchByPages</a>, este índice comienza desde el inicio del documento o desde el inicio de la página del documento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">PageIndex</a> | Índice de página donde se encuentra el texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El texto encontrado. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/lefthighlightitem" target="_blank" rel="nofollow noopener noreferrer">LeftHighlightItem</a> | La resaltado izquierdo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult/properties/righthighlightitem" target="_blank" rel="nofollow noopener noreferrer">RightHighlightItem</a> | El resaltado derecho. |

## Buscar texto por palabra clave {#search-text-by-keyword}

A continuación se indican los pasos para buscar una palabra clave en el documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Comprobar si la *colección* no es nula (la búsqueda está admitida para el documento);
*   Iterar a través de la colección y obtener la posición y el texto.

El siguiente ejemplo muestra cómo encontrar una palabra clave en un documento:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("page number");
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }

    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

## Buscar texto mediante expresión regular {#search-text-by-regular-expression}

El parámetro <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> se utiliza para personalizar una búsqueda. Esta clase tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/matchcase" target="_blank" rel="nofollow noopener noreferrer">MatchCase</a> | El valor que indica si se distingue entre mayúsculas y minúsculas en el texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/matchwholeword" target="_blank" rel="nofollow noopener noreferrer">MatchWholeWord</a> | El valor que indica si la búsqueda de texto está limitada a palabras completas. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/searchbypages" target="_blank" rel="nofollow noopener noreferrer">SearchByPages</a> | El valor que indica si la búsqueda se realiza por páginas. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/useregularexpression" target="_blank" rel="nofollow noopener noreferrer">UseRegularExpression</a> | El valor que indica si se utiliza una expresión regular. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/lefthighlightoptions" target="_blank" rel="nofollow noopener noreferrer">LeftHighlightOptions</a> | Las opciones para el resaltado izquierdo. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions/properties/righthighlightoptions" target="_blank" rel="nofollow noopener noreferrer">RightHighlightOptions</a> | Las opciones para el resaltado derecho. |

A continuación se indican los pasos para realizar una búsqueda mediante expresión regular en un documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> con los parámetros para la búsqueda;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Comprobar si la *colección* no es *null* (la búsqueda es compatible con el documento);
*   Iterar a través de la colección y obtener la posición y el texto.

El siguiente ejemplo muestra cómo realizar una búsqueda mediante expresión regular en un documento:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search with a regular expression with case matching
    IEnumerable<SearchResult> sr = parser.Search("page number: [0-9]+", new SearchOptions(true, false, true));
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }

    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

## Búsqueda de texto con resaltados {#search-text-with-highlights}

A continuación se indican los pasos para buscar texto con resaltados:

*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> con los parámetros para la extracción de resaltados;
*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> con los parámetros para la búsqueda;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Verificar si la *colección* no es *nula* (la búsqueda es compatible con el documento);
*   Iterar a través de la colección y obtener la posición y el texto.

El siguiente ejemplo muestra cómo buscar texto con resaltados:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SamplePdf))
{
    HighlightOptions highlightOptions = new HighlightOptions(15);
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("lorem", new SearchOptions(true, false, false, highlightOptions));
    // Check if search is supported
    if (sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }
    // Iterate over search results
    foreach (SearchResult s in sr)
    {
        // Print the found text and highlights: 
        Console.WriteLine(string.Format("{0}{1}{2}", s.LeftHighlightItem.Text, s.Text, s.RightHighlightItem.Text));
    }
}
```

## Búsqueda de texto con números de página {#search-text-with-page-numbers}

A continuación se indican los pasos para realizar una búsqueda de texto con números de página:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> con los parámetros de la búsqueda;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Verificar que la *colección* no sea nula (la búsqueda es compatible con el documento);
*   Iterar sobre la colección y obtener la posición, el texto y el número de página.

El siguiente ejemplo muestra cómo realizar una búsqueda de texto con números de página:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(Constants.SamplePdf))
{
    // Search a keyword with page numbers
    IEnumerable<SearchResult> sr = parser.Search("lorem", new SearchOptions(false, false, false, true));
    // Check if search is supported
    if(sr == null)
    {
        Console.WriteLine("Search isn't supported");
        return;
    }
 
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index, page number and found text:
        Console.WriteLine(string.Format("At {0} (page {1}): {2}", s.Position, s.PageIndex, s.Text));
    }
}
```

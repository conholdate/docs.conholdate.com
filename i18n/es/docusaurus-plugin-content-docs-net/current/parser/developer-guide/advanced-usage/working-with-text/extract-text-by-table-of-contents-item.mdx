GroupDocs.Parser proporciona la funcionalidad para extraer texto a partir de un elemento del índice. Esta característica está disponible para documentos de procesamiento de texto, PDF, ePUB y CHM (para más detalles, consulte [Formatos de documento admitidos](/net/parser/getting-started/supported-document-formats/)).

El texto se extrae mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/extracttext" target="_blank" rel="nofollow noopener noreferrer">TocItem.ExtractText</a>:

```csharp
// Get the first item of table of contents
TocItem tocItem = parser.GetToc().First();

// Print the text of the chapter
using (TextReader reader = tocItem.ExtractText())
{
    Console.WriteLine("----");
    Console.WriteLine(reader.ReadToEnd());
}
```

Este método devuelve un texto del capítulo al que se refiere el elemento del índice (sin subcapítulos). Por ejemplo, "Título 1.2" de la página

:::warning
<a href="https://docs.microsoft.com/en-us/dotnet/api/system.invalidoperationexception?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">`InvalidOperationException`</a> se lanza si <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">tocItem.PageIndex</a> es *null*.
:::


A continuación se indican los pasos para extraer texto a partir de un elemento del índice:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a>;
*   Verificar que la *colección* no sea *nula* (la extracción del índice está admitida para el documento);
*   Iterar sobre la colección y extraer el texto mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a>.  

El siguiente ejemplo muestra cómo extraer texto a partir de los elementos del índice:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get table of contents
    IEnumerable<TocItem> toc = parser.GetToc();
    
    // Check if TOC extraction is supported
    if (toc == null)
    {
        Console.WriteLine("Table of contents extraction isn't supported");
        return;
    }
    
    // Iterate over items
    foreach (TocItem i in toc)
    {
        // Check if page index has a value
        if (i.PageIndex == null)
        {
            continue;
        }
        // Extract a page text
        using (TextReader reader = i.ExtractText())
        {
            Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
        }
    }
}
```

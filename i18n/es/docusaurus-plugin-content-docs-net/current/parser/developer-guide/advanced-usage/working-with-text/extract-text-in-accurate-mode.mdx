GroupDocs.Parser proporciona la funcionalidad para extraer texto de documentos.

El modo **Preciso** es el modo predeterminado de extracción de texto y significa que la calidad del texto será la mejor posible.

Puede extraer el texto completo del documento o únicamente el texto de una página del documento.

Para extraer texto del documento en el modo Preciso, se utilizan los métodos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a> y <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/gettext/methods/2" target="_blank" rel="nofollow noopener noreferrer">GetText(int)</a> de la clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a>:

```csharp
TextReader GetText();
TextReader GetText(int pageIndex);
```

Los métodos devuelven una instancia de la clase <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a> con el texto extraído. El primer método extrae el texto de todo el documento. El segundo método extrae el texto de una página del documento. Para obtener el número total de páginas del documento, se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentIn</a>[fo](https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo) (véase a continuación).

## Extraer texto {#extract-text}

A continuación se indican los pasos para extraer texto del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Comprobar que *reader* no es nulo (la extracción de texto es compatible con el documento);
*   Leer el texto desde *reader*.

El siguiente ejemplo muestra cómo extraer texto de un documento:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract a text into the reader
    using(TextReader reader = parser.GetText())
    {
        // Print a text from the document
        // If text extraction isn't supported, a reader is null
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

## Extraer texto de una página de documento {#extract-text-from-a-document-page}

A continuación se indican los pasos para extraer texto de una página de documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar a la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/text" target="_blank" rel="nofollow noopener noreferrer">Features.Text</a> para verificar si la extracción de texto es compatible con el documento;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/gettext/methods/2" target="_blank" rel="nofollow noopener noreferrer">GetText(int)</a> pasando el índice de página y obtener un objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Leer el texto del *lector*.

El siguiente ejemplo muestra cómo extraer texto de una página del documento:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Check if the document supports text extraction
    if(!parser.Features.Text)
    {
        Console.WriteLine("Document isn't supports text extraction.");
        return;   
	}

    // Get the document info
    IDocumentInfo documentInfo = parser.GetDocumentInfo();
    // Check if the document has pages
    if(documentInfo.PageCount == 0)
    {
        Console.WriteLine("Document hasn't pages.");
        return;
    }
 
    // Iterate over pages
    for(int p = 0; p < documentInfo.PageCount; p++)
    {
        // Print a page number 
        Console.WriteLine(string.Format("Page {0}/{1}", p + 1, documentInfo.PageCount));
 
        // Extract a text into the reader
        using(TextReader reader = parser.GetText(p))
        {
            // Print a text from the document
            // We ignore null-checking as we have checked text extraction feature support earlier
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```

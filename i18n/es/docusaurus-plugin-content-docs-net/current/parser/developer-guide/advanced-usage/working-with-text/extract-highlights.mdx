GroupDocs.Parser proporciona la funcionalidad para extraer un resaltado (una parte del texto que normalmente se utiliza para explicar el contexto del texto encontrado en la funcionalidad de búsqueda) de documentos mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gethighlight" target="_blank" rel="nofollow noopener noreferrer">GetHighlight</a>:

```csharp
HighlightItem GetHighlight(int position, bool isDirect, HighlightOptions options);
```

El parámetro *position* define la posición inicial desde la cual se extrae la resaltación. El parámetro *isDirect* indica si la extracción de la resaltación es directa: *true* si la resaltación se extrae desde la derecha de la posición; en caso contrario, *false*. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> `parameter` se utiliza para definir el final del resaltado.

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> La clase tiene los siguientes constructores:

```csharp
// Highlight is limited to maxLength text length.
HighlightOptions(int maxLength);
// Highlight is limited to the start (or the end) of a text line (or maxLength text length - if set).
HighlightOptions(int? maxLength, bool isLineLimited);
// Highlight is limited to word count (or maxLength text length - if set).
HighlightOptions(int? maxLength, int wordCount);
// General constructor
HighlightOptions(int? maxLength, int? wordCount, bool isLineLimited);
```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> La clase tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> | La posición en el texto del documento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El texto resaltado. |

Aquí están los pasos para extraer los resaltados del documento:

*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> objeto para el documento inicial;
*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/highlightoptions" target="_blank" rel="nofollow noopener noreferrer">HighlightOptions</a> objeto con los parámetros de extracción;
*   Llamada <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gethighlight" target="_blank" rel="nofollow noopener noreferrer">GetHighlight</a> método y obtener el <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> objeto;
*   Verifique si <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem" target="_blank" rel="nofollow noopener noreferrer">HighlightItem</a> no es nulo (la extracción de resaltados es compatible con el documento);
*   Propiedades de llamada como  <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/position" target="_blank" rel="nofollow noopener noreferrer">Position</a> y <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/highlightitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a>.

El siguiente ejemplo muestra cómo extraer un resaltado que contiene 3 palabras:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract a highlight:
    HighlightItem hl = parser.GetHighlight(2, true, new HighlightOptions(3));
    // Check if highlight extraction is supported
    if (hl == null)
    {
        Console.WriteLine("Highlight extraction isn't supported");
        return;
    }
    // Print an extracted highlight
    Console.WriteLine(string.Format("At {0}: {1}", hl.Position, hl.Text));
}
```

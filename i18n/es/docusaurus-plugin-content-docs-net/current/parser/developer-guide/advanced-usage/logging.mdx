La interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> se utiliza para recibir información sobre errores, advertencias y eventos que ocurren durante la extracción de datos. La interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/error" target="_blank" rel="nofollow noopener noreferrer">Error(string, Exception)</a> | Registra un error que ocurrió durante la extracción de datos. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/warning" target="_blank" rel="nofollow noopener noreferrer">Warning(string)</a> | Registra una advertencia que ocurrió durante la extracción de datos. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger/methods/trace" target="_blank" rel="nofollow noopener noreferrer">Trace(string)</a> | Registra un evento que ocurrió durante la extracción de datos. |

A continuación se indican los pasos para recibir la información mediante la interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>:

*   Implementar una clase con la implementación de la interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> con un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a>.

El siguiente ejemplo muestra cómo recibir la información mediante la interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>.

```csharp
try
{
    // Create an instance of Logger class
    Logger logger = new Logger();
    // Create an instance of Parser class with the parser settings
    using (Parser parser = new Parser(Constants.SamplePassword, null, new ParserSettings(logger)))
    {
        // Check if text extraction is supported
        if (!parser.Features.Text)
        {
            Console.WriteLine("Text extraction isn't supported.");
            return;
        }
        // Print the document text
        using (TextReader reader = parser.GetText())
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
catch (InvalidPasswordException)
{
    ; // Ignore the exception
}

private class Logger : ILogger
{
    public void Error(string message, Exception exception)
    {
        // Print error message
        Console.WriteLine("Error: " + message);
    }
    public void Trace(string message)
    {
        // Print event message
        Console.WriteLine("Event: " + message);
    }
    public void Warning(string message)
    {
        // Print warning message
        Console.WriteLine("Warning: " + message);
    }
}
```

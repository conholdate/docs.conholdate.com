GroupDocs.Parser proporciona la funcionalidad para extraer hipervínculos de una página de documento mediante <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/2" target="_blank" rel="nofollow noopener noreferrer">ObtenerHipervínculos(Int32)</a> método:

```csharp
IEnumerable<PageHyperlinkArea> GetHyperlinks(int pageIndex);
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a>:

| Miembro | Descripción |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular en la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El texto del hipervínculo. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/url" target="_blank" rel="nofollow noopener noreferrer">Url</a> | La URL del hipervínculo. |

A continuación se indican los pasos para extraer hipervínculos de la página del documento:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
- Comprobar si el documento admite la extracción de hipervínculos;
- Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/2" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(Int32)</a> pasando el índice de página y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a>;
- Recorrer la colección y obtener el texto y la URL del hipervínculo.

El siguiente ejemplo muestra cómo extraer hipervínculos de la página del documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports hyperlink extraction
    if (!parser.Features.Hyperlinks)
    {
        Console.WriteLine("Document isn't supports hyperlink extraction.");
        return;
    }
    // Get the document info
    IDocumentInfo documentInfo = parser.GetDocumentInfo();
    // Check if the document has pages
    if (documentInfo.PageCount == 0)
    {
        Console.WriteLine("Document hasn't pages.");
        return;
    }
    // Iterate over pages
    for (int pageIndex = 0; pageIndex < documentInfo.PageCount; pageIndex++)
    {
        // Print a page number 
        Console.WriteLine(string.Format("Page {0}/{1}", pageIndex + 1, documentInfo.PageCount));
        // Extract hyperlinks from the document page
        IEnumerable<PageHyperlinkArea> hyperlinks = parser.GetHyperlinks(pageIndex);
        // Iterate over hyperlinks
        foreach (PageHyperlinkArea h in hyperlinks)
        {
            // Print the hyperlink text
            Console.WriteLine(h.Text);
            // Print the hyperlink URL
            Console.WriteLine(h.Url);
            Console.WriteLine();
        }
    }
}
```

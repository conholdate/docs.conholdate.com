GroupDocs.Parser proporciona la funcionalidad para extraer hipervínculos del área de una página del documento mediante los métodos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(PageAreaOptions)</a> y <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/3" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(Int32, PageAreaOptions)</a>:

```csharp
IEnumerable<PageHyperlinkArea> GetHyperlinks(int pageIndex, PageAreaOptions options);
IEnumerable<PageHyperlinkArea> GetHyperlinks(PageAreaOptions options);
```

Estos métodos devuelven una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a>:

| Miembro | Descripción |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/page" target="_blank" rel="nofollow noopener noreferrer">Page</a> | La página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/pagearea/properties/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> | El área rectangular en la página que contiene el área de texto. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El texto del hipervínculo. |
| <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea/properties/url" target="_blank" rel="nofollow noopener noreferrer">Url</a> | La URL del hipervínculo. |

A continuación se indican los pasos para extraer hipervínculos del área de página del documento:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
- Comprobar si el documento admite la extracción de hipervínculos;
- Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/pageareaoptions" target="_blank" rel="nofollow noopener noreferrer">PageAreaOptions</a> con el área rectangular;
- Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.parser/gethyperlinks/methods/1" target="_blank" rel="nofollow noopener noreferrer">GetHyperlinks(PageAreaOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagehyperlinkarea" target="_blank" rel="nofollow noopener noreferrer">PageHyperlinkArea</a>;
- Iterar sobre la colección y obtener el texto y la URL del hipervínculo.

El siguiente ejemplo muestra cómo extraer hipervínculos del área de página del documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the document supports hyperlink extraction
    if (!parser.Features.Hyperlinks)
    {
        Console.WriteLine("Document isn't supports hyperlink extraction.");
        return;
    }
    // Create the options which are used for hyperlink extraction
    PageAreaOptions options = new PageAreaOptions(new Rectangle(new Point(380, 90), new Size(150, 50)));
    // Extract hyperlinks from the document page area
    IEnumerable<PageHyperlinkArea> hyperlinks = parser.GetHyperlinks(options);
    // Iterate over hyperlinks
    foreach (PageHyperlinkArea h in hyperlinks)
    {
        // Print the hyperlink text
        Console.WriteLine(h.Text);
        // Print the hyperlink URL
        Console.WriteLine(h.Url);
        Console.WriteLine();
    }
}
```

GroupDocs.Parser para .NET proporciona la capacidad de extraer texto de archivos de imagen y de PDF compuestos por imágenes.


:::info
Para utilizar la funcionalidad OCR en .NET Framework, establezca PlatformTarget en x64. Si se utiliza la versión descargable (msi o zip) de GroupDocs.Parser, consulte el archivo readme.txt para obtener información adicional.
:::


Cabe destacar que no todos los idiomas representados por la clase <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/language/" target="_blank" rel="nofollow noopener noreferrer">Language</a> están actualmente soportados para reconocimiento sin descargar implícitamente recursos adicionales desde internet. Sin embargo, si se dispone de acceso a internet, todos los recursos necesarios se descargarán implícitamente al seleccionar cualquier idioma para el reconocimiento. Los idiomas actualmente soportados sin descargas adicionales son: inglés, chino, japonés, coreano y árabe.

El siguiente ejemplo muestra cómo extraer texto de imágenes y PDFs:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser("scanned.pdf"))
{
    // Set OCR options
    TextOptions options = new TextOptions(false, true);
    options.OcrOptions = new OcrOptions();
    options.OcrOptions.Language = Language.Chinese;
    options.OcrOptions.PagePreviewOptions = new PagePreviewOptions();
    options.OcrOptions.PagePreviewOptions.Dpi = 144;
    // Extract text using OCR
    using(TextReader reader = parser.GetText(options))
    {
        // Print text or 'not supported' message
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

`TextOptions` se puede omitir si el archivo es una imagen:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser("scanned.jpg"))
{
    // Extract text using OCR
    using(TextReader reader = parser.GetText())
    {
        // Print text or 'not supported' message
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

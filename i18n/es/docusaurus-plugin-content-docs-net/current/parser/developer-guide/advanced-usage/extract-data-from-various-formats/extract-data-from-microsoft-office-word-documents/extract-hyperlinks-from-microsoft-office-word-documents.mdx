Para extraer hipervínculos de un documento de Microsoft Office Word <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> se utiliza el método. Este método devuelve la representación XML del documento. Los hipervínculos se representan mediante la etiqueta "hyperlink"; el atributo "link" contiene la URL del hipervínculo. Para obtener más detalles, consulte [Extraer estructura de texto](/net/parser/developer-guide/advanced-usage/working-with-text/extract-text-structure/). El hipervínculo puede contener un texto:

```xml
<hyperlink link="www.google.com">google.com</hyperlink>
```


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> el método devuelve un valor *null* si la extracción de estructura de texto no es compatible con el documento. Por ejemplo, la extracción de estructura de texto no es compatible con archivos TXT. Por lo tanto, para un archivo TXT <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> el método devuelve *null*. Si el documento de Microsoft Office Word no tiene texto, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a>[] (https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata) método devuelve un valor vacío <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a> objeto.
:::


A continuación se indican los pasos para extraer hipervínculos de documentos de Microsoft Office Word:

*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a>;
*   Iterar a través del documento XML.

El siguiente ejemplo muestra cómo extraer hipervínculos de un documento de Microsoft Office Word:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get the reader object for the document XML representation
    using (XmlReader reader = parser.GetStructure())
    {
        // Iterate over the document
        while (reader.Read())
        {
            // If it is the start tag of the hyperlink
            if (reader.IsStartElement() && reader.Name == "hyperlink")
            {
                // Print the link attribute
                Console.WriteLine(reader.GetAttribute("link"));
            }
        }
    }
}
```

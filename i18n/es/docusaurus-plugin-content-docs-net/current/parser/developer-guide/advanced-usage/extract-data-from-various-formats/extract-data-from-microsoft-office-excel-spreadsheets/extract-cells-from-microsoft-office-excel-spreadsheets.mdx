GroupDocs.Parser proporciona la funcionalidad para extraer celdas de hojas de cálculo. Los siguientes métodos se utilizan para este propósito:

* <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getworksheetinfo#getworksheetinfo_1" target="_blank" rel="nofollow noopener noreferrer">GetWorksheetInfo</a>() – devuelve la información sobre la hoja de cálculo
* <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getworksheetinfo#getworksheetinfo" target="_blank" rel="nofollow noopener noreferrer">GetWorksheetInfo</a>(int) – devuelve la información sobre todas las hojas de cálculo presentes en la hoja de cálculo
* <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getworksheetcells#getworksheetcells" target="_blank" rel="nofollow noopener noreferrer">GetWorksheetCells</a>(int) – devuelve la colección de celdas
* <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getworksheetcells#getworksheetcells_1" target="_blank" rel="nofollow noopener noreferrer">GetWorksheetCells</a>(int, WorksheetOptions) – devuelve una colección de celdas contenidas en los rangos especificados.

A continuación se indican los pasos para extraer celdas de una hoja de cálculo de Microsoft Office Excel:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para la hoja de cálculo inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getworksheetcells#getworksheetcells" target="_blank" rel="nofollow noopener noreferrer">GetWorksheetCells</a>(int) y obtener la colección de objetos []();
*   Recorrer la colección de <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/worksheetcell" target="_blank" rel="nofollow noopener noreferrer">WorksheetCell</a> y obtener el valor de texto de cada celda.

El siguiente ejemplo muestra cómo extraer celdas de una hoja de cálculo de Microsoft Office Excel.

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SampleXlsx))
{
    // Check if worksheet cells extraction is supported
    if (!parser.Features.Worksheet)
    {
        throw new NotSupportedException("Worksheet cells extraction isn't supported");
    }

    // Get the information about worksheets
    IEnumerable<WorksheetInfo> info = parser.GetWorksheetInfo();
   
    // Iterate over worksheet information
    foreach(WorksheetInfo i in info)
    {
        // Print the worksheet name
        Console.WriteLine(i.Name);
        Console.WriteLine();

        // Get the worksheet cells
        IEnumerable<WorksheetCell> cells = parser.GetWorksheetCells(i.Index);

        // Iterate over cells
        foreach (WorksheetCell c in cells)
        {
            // Print the cell information and text value
            Console.WriteLine($"Row: {c.RowIndex} Column: {c.ColumnIndex} RowSpan: {c.RowSpan} ColumnSpan: {c.ColumnSpan}");
            Console.WriteLine(c.Text);
            Console.WriteLine();
        }
    }
}
```

El siguiente ejemplo muestra cómo extraer celdas de una hoja de cálculo de Microsoft Office Excel con personalización:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SampleXlsx))
{
    // Check if worksheet cells extraction is supported
    if (!parser.Features.Worksheet)
    {
        throw new NotSupportedException("Worksheet cells extraction isn't supported");
    }

    // Get the information about the first worksheet
    WorksheetInfo info = parser.GetWorksheetInfo(0);

    // Print the worksheet name
    Console.WriteLine(info.Name);
    Console.WriteLine();

    // Create the range that represents the first two rows
    WorksheetRange range = new WorksheetRange(
        info.MinRowIndex,
        Math.Min(info.MinRowIndex + 1, info.MaxRowIndex),
        info.MinColumnIndex,
        info.MaxColumnIndex);

    // Get the worksheet cells from the first two rows
    IEnumerable<WorksheetCell> cells = parser.GetWorksheetCells(0, new WorksheetOptions(range));

    // Iterate over cells
    foreach (WorksheetCell c in cells)
    {
        // Print the cell information and text value
        Console.WriteLine($"Row: {c.RowIndex} Column: {c.ColumnIndex} RowSpan: {c.RowSpan} ColumnSpan: {c.ColumnSpan}");
        Console.WriteLine(c.Text);
        Console.WriteLine();
    }
}
```

Las presentaciones de Microsoft Office PowerPoint (.ppt, .pptx) suelen contener **anotaciones**: comentarios en las diapositivas dejados por revisores durante una revisión. Con **GroupDocs.Parser for .NET**, puede leer fácilmente estas anotaciones mediante programación utilizando el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a>.

Esta guía muestra paso a paso cómo extraer anotaciones de presentaciones de Microsoft Office PowerPoint en C#.
---
## ¿Qué son las anotaciones de PowerPoint? {#what-are-powerpoint-annotations}

Las anotaciones son comentarios que los revisores adjuntan a las diapositivas de una presentación de PowerPoint (.ppt, .pptx); por ejemplo, observaciones dejadas sobre una forma o diapositiva específica durante una revisión. El método `GetAnnotations` lee esta marca y la devuelve como una colección de objetos `AnnotationItem`, cada uno expone una `Value` con el texto del comentario, junto con metadatos como el autor y la marca de tiempo.

El método tiene dos sobrecargas:

| Sobrecarga | Descripción |
| --- | --- |
| **GetAnnotations()** | Extrae anotaciones de toda la presentación de PowerPoint |
| **GetAnnotations(int pageIndex)** | Extrae anotaciones de una diapositiva específica (índice basado en cero) |

⚡ *Nota: La extracción de anotaciones es compatible tanto con el formato binario heredado (.ppt) como con el formato Open XML (.pptx).*
---
## Cómo extraer anotaciones de una presentación de PowerPoint en C# {#how-to-extract-annotations-from-a-powerpoint-presentation-in-c}

Siga estos pasos para obtener las anotaciones de un archivo .ppt o .pptx:

1. **Cree un objeto `Parser`** y cargue la presentación de PowerPoint.
2. **Llame al método `GetAnnotations`** para recuperar la colección de anotaciones.
3. **Itere a través de la colección** y lea el valor de cada anotación.

### Ejemplo: Extraer anotaciones de PowerPoint en C# {#example-extract-powerpoint-annotations-in-c}

```csharp
using (Parser parser = new Parser(@"MyPresentation.pptx"))
{
    // Extract annotations
    IEnumerable<AnnotationItem> annotations = parser.GetAnnotations();

    // Display annotations
    foreach (AnnotationItem item in annotations)
    {
        Console.WriteLine(item.Value);
    }
}
```


:::warning
<a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a> el método devuelve *null* si la extracción de anotaciones no es compatible con el documento. Si la presentación de PowerPoint no tiene comentarios, <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a> El método devuelve una colección vacía.
:::


## Extraer texto de PowerPoint junto con anotaciones {#extract-powerpoint-text-together-with-annotations}

A veces resulta útil obtener el texto de la presentación y sus comentarios en una sola operación, en lugar de llamar a `GetAnnotations` por separado. Establezca `IncludeAnnotations` en `true` en `TextOptions` y páselo al método `GetText`: el texto de los comentarios se incluirá en la salida extraída junto con el texto normal de las diapositivas.

### Ejemplo: Extraer texto con anotaciones en C# {#example-extract-text-with-annotations-in-c}

```csharp
using (Parser parser = new Parser(@"MyPresentation.pptx"))
{
    TextOptions options = new TextOptions
    {
        IncludeAnnotations = true
    };

    using (TextReader reader = parser.GetText(options))
    {
        string text = reader.ReadToEnd();
        Console.WriteLine(text);
    }
}
```

## Lectura de metadatos de comentarios en PowerPoint {#reading-powerpoint-comment-metadata}

Cada `AnnotationItem` también expone metadatos que ayudan a rastrear quién dejó un comentario en una diapositiva y cuándo:

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `AnnotationType` | `string` | El tipo de anotación. |
| `PageIndex` | `int` | Índice basado en cero de la diapositiva donde se encuentra el comentario. |
| `Timestamp` | `DateTime?` | Fecha y hora en que se creó o modificó por última vez el comentario. |
| `AuthorName` | `string` | Nombre del autor que creó o modificó por última vez el comentario. |
| `AuthorInitials` | `string` | Iniciales del autor que creó o modificó por última vez el comentario. |

### Ejemplo: Lectura de metadatos de comentarios en C# {#example-reading-comment-metadata-in-c}

```csharp
using (Parser parser = new Parser(@"MyPresentation.pptx"))
{
    IEnumerable<AnnotationItem> annotations = parser.GetAnnotations();

    foreach (AnnotationItem annotation in annotations)
    {
        Console.WriteLine($"Slide: {annotation.PageIndex}, Author: {annotation.AuthorName} ({annotation.AuthorInitials})");
        Console.WriteLine($"Created/Modified: {annotation.Timestamp}, Type: {annotation.AnnotationType}");
        Console.WriteLine($"Comment: {annotation.Value}");
    }
}
```

## ¿Por qué extraer anotaciones de presentaciones de PowerPoint? {#why-extract-annotations-from-powerpoint-presentations}

Extraer comentarios de presentaciones de Microsoft Office PowerPoint resulta útil para:

*   Flujos de trabajo de revisión: recopilar los comentarios de los revisores dejados en las diapositivas durante un ciclo de revisión.
*   Colaboración: mostrar los comentarios de las diapositivas sin necesidad de abrir PowerPoint.
*   Auditoría: rastrear quién comentó en una presentación y cuándo, a lo largo del tiempo.

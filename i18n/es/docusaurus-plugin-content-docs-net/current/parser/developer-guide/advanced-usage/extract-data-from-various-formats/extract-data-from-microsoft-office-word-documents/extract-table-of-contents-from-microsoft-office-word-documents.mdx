## Información general {#overview}

Esta guía explica cómo extraer la tabla de contenidos (TOC, por sus siglas en inglés) de documentos de Microsoft Office Word (`.doc`, `.docx`) mediante GroupDocs.Parser para .NET. La TOC se genera automáticamente al detectar párrafos con estilos de encabezado integrados (H1-H9)


## Cómo funciona la extracción de la TOC {#how-toc-extraction-works}

El método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> analiza su documento de Word e identifica todos los encabezados con formato utilizando los estilos de encabezado integrados. Devuelve una colección estructurada de elementos de la TOC que puede navegar programáticamente.

Para extraer la tabla de contenidos de un documento de Microsoft Office Word, se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a>. La tabla de contenidos se genera a partir de los párrafos con estilos integrados H1-H9.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> el método devuelve un valor *null* si la extracción del índice no es compatible con el documento. Por ejemplo, la extracción del índice no es compatible con archivos TXT. Por lo tanto, para un archivo TXT <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> el método devuelve *null*. Si el documento de Microsoft Office Word no tiene una tabla de contenido, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> El método devuelve una colección vacía.
:::


<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> el método devuelve una colección de <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> objetos. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">TocItem.GetText</a> El método devuelve un texto del capítulo al que se refiere el elemento del índice (sin subcapítulos). Por ejemplo, "Título 1.2" de la página.

A continuación se indican los pasos para extraer un texto a partir de un elemento del índice:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a>;
*   Iterar sobre la colección y extraer el texto.

El siguiente ejemplo muestra cómo extraer un texto a partir de un elemento del índice:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SampleDocxWithToc))
{
    // Get table of contents
    IEnumerable<TocItem> tocItems = parser.GetToc();
    // Iterate over items
    foreach (TocItem tocItem in tocItems)
    {
        // Print the text of the chapter
        using (TextReader reader = tocItem.ExtractText())
        {
            Console.WriteLine("----");
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}
```

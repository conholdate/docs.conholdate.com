Para extraer metadatos de libros electrónicos EPUB se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>. Este método permite extraer los siguientes metadatos:

| Nombre | Descripción |
| --- | --- |
| title | El título del libro electrónico. |
| subject | El tema o asunto del libro electrónico. |
| author | El nombre del autor del libro electrónico. |
| language | El idioma del libro electrónico. |
| published-date | La fecha de publicación del libro electrónico. |
| description | La descripción del libro electrónico. |
| publisher | El editor del libro electrónico. |
| copyrights | Los derechos de autor del libro electrónico. |

A continuación se indican los pasos para extraer metadatos de un libro electrónico EPUB:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el libro electrónico inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> y obtener la colección de objetos de metadatos del documento;
*   Recorrer la colección y obtener los nombres y valores de los metadatos.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve un valor *null* si la extracción de metadatos no es compatible con el documento. Por ejemplo, la extracción de metadatos no es compatible con archivos ZIP. Por lo tanto, para un archivo ZIP <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve *null*. Si el libro electrónico EPUB no tiene metadatos, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> El método devuelve una colección vacía.
:::


El siguiente ejemplo demuestra cómo extraer metadatos de un libro electrónico en formato EPUB:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract metadata from the e-book
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
 
    // Iterate over metadata items
    foreach(MetadataItem item in metadata)
    {
        // Print the item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

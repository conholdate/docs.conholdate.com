Los documentos de Microsoft Office Word (.doc, .docx) suelen contener **anotaciones**: comentarios, cambios rastreados o notas incrustadas dejadas por los revisores. Con **GroupDocs.Parser for .NET**, puede leer fácilmente estas anotaciones mediante programación utilizando el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a>.

Esta guía muestra paso a paso cómo extraer anotaciones de documentos de Microsoft Office Word en C#.
---
## ¿Qué son las anotaciones de Word? {#what-are-word-annotations}

Las anotaciones son comentarios, cambios rastreados u otras notas incrustadas que los revisores adjuntan a un documento de Word (.doc, .docx) durante una revisión. El método `GetAnnotations` lee esta marca y la devuelve como una colección de objetos `AnnotationItem`, cada uno expone una `Value` con el texto de la anotación, junto con metadatos como el autor y la marca de tiempo.

El método tiene dos sobrecargas:

| Sobrecarga | Descripción |
| --- | --- |
| **GetAnnotations()** | Extrae anotaciones del documento de Word completo |
| **GetAnnotations(int pageIndex)** | Extrae anotaciones de una página específica (índice basado en cero) |

⚡ *Nota: La extracción de anotaciones es compatible con documentos de texto electrónicos, incluido el formato Open XML (.docx), el formato binario heredado (.doc), RTF y TXT.*
---
## Cómo extraer anotaciones de un documento de Word en C# {#how-to-extract-annotations-from-a-word-document-in-c}

Siga estos pasos para obtener las anotaciones de un archivo .doc o .docx:

1. **Cree un objeto `Parser`** y cargue el documento de Word.
2. **Llame al método `GetAnnotations`** para recuperar la colección de anotaciones.
3. **Itere a través de la colección** y lea el valor de cada anotación.

### Ejemplo: Extraer anotaciones de Word en C# {#example-extract-word-annotations-in-c}

```csharp
using (Parser parser = new Parser(@"MyDocument.docx"))
{
    // Extract annotations
    IEnumerable<AnnotationItem> annotations = parser.GetAnnotations();

    // Display annotations
    foreach (AnnotationItem item in annotations)
    {
        Console.WriteLine(item.Value);
    }
}
```


:::warning
<a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a> el método devuelve *null* si la extracción de anotaciones no es compatible con el documento. Si el documento de Word no tiene comentarios, <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/getannotations/#getannotations" target="_blank" rel="nofollow noopener noreferrer">GetAnnotations</a> El método devuelve una colección vacía.
:::


## Extraer texto de Word junto con anotaciones {#extract-word-text-together-with-annotations}

A veces resulta útil obtener el texto del documento y sus comentarios en una sola operación, en lugar de llamar a `GetAnnotations` por separado. Establezca `IncludeAnnotations` en `true` en `TextOptions` y páselo al método `GetText`: el texto de las anotaciones se incluirá en la salida extraída junto con el texto normal del documento.

### Ejemplo: Extraer texto con anotaciones en C# {#example-extract-text-with-annotations-in-c}

```csharp
using (Parser parser = new Parser(@"MyDocument.docx"))
{
    TextOptions options = new TextOptions
    {
        IncludeAnnotations = true
    };

    using (TextReader reader = parser.GetText(options))
    {
        string text = reader.ReadToEnd();
        Console.WriteLine(text);
    }
}
```

## Lectura de metadatos de anotaciones de palabras {#reading-word-annotation-metadata}

Cada `AnnotationItem` también expone metadatos que ayudan a rastrear quién dejó un comentario en un documento y cuándo:

| Propiedad | Tipo | Descripción |
| --- | --- | --- |
| `AnnotationType` | `string` | El tipo de anotación. |
| `PageIndex` | `int` | Índice basado en cero de la página donde se encuentra la anotación. |
| `Timestamp` | `DateTime?` | Fecha y hora en que se creó o modificó por última vez la anotación. |
| `AuthorName` | `string` | Nombre del autor que creó o modificó por última vez la anotación. |
| `AuthorInitials` | `string` | Iniciales del autor que creó o modificó por última vez la anotación. |

### Ejemplo: Lectura de metadatos de anotaciones en C# {#example-reading-annotation-metadata-in-c}

```csharp
using (Parser parser = new Parser(@"MyDocument.docx"))
{
    IEnumerable<AnnotationItem> annotations = parser.GetAnnotations();

    foreach (AnnotationItem annotation in annotations)
    {
        Console.WriteLine($"Page: {annotation.PageIndex}, Author: {annotation.AuthorName} ({annotation.AuthorInitials})");
        Console.WriteLine($"Created/Modified: {annotation.Timestamp}, Type: {annotation.AnnotationType}");
        Console.WriteLine($"Comment: {annotation.Value}");
    }
}
```

## ¿Por qué extraer anotaciones de documentos de Word? {#why-extract-annotations-from-word-documents}

Extraer comentarios de documentos de Microsoft Office Word resulta útil para:

*   Flujos de trabajo de revisión: recopilar los comentarios de los revisores dejados en los documentos durante un ciclo de revisión.
*   Colaboración: mostrar los comentarios del documento sin necesidad de abrir Word.
*   Auditoría: rastrear quién comentó un documento y cuándo, a lo largo del tiempo.

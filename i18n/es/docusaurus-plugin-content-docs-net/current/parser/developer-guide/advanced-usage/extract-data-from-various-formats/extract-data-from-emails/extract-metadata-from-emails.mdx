Para extraer metadatos de correos electrónicos se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>. Este método permite extraer los siguientes metadatos:

| Nombre | Descripción |
| --- | --- |
| subject | Campo “asunto” del correo electrónico. |
| email-sender | Campo “de” (from) del correo electrónico. |
| email-to | Campo “para” (to) del correo electrónico. Puede contener más de una dirección, separadas por punto y coma. |
| email-cc | Campo “cc” del correo electrónico. Puede contener más de una dirección, separadas por punto y coma. |

A continuación se indican los pasos para extraer metadatos de un correo electrónico:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el correo electrónico inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> y obtener la colección de objetos de metadatos del documento;
*   Recorrer la colección y obtener los nombres y valores de los metadatos.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve un valor *null* si la extracción de metadatos no es compatible con el documento. Por ejemplo, la extracción de metadatos no es compatible con archivos ZIP. Por lo tanto, para un archivo ZIP <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve *null*. Si un correo electrónico no tiene metadatos, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> El método devuelve una colección vacía.
:::


El siguiente ejemplo demuestra cómo extraer metadatos de un correo electrónico:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract metadata from the email
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
 
    // Iterate over metadata items
    foreach(MetadataItem item in metadata)
    {
        // Print the item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

Para extraer correos electrónicos desde el almacenamiento de Outlook, se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a>. Este método devuelve la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>.

Un elemento del almacenamiento de Outlook puede contener los siguientes metadatos:

| Nombre | Descripción |
| --- | --- |
| fecha | La hora y fecha en que el elemento del almacenamiento de Outlook se modificó por última vez. |
| email-sender | El valor del campo "sender" (remitente). |
| email-to | El valor del campo "to" (destinatario). |
| subject | El valor del campo "subject" (asunto). |

El contenedor del almacenamiento de Outlook está compuesto por documentos de correo electrónico (archivos .msg).

A continuación se indican los pasos para extraer el texto de un correo electrónico desde el almacenamiento de Outlook:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>;
*   Comprobar si la *colección* no es *nula* (la extracción del contenedor es compatible con el documento);
*   Recorrer la colección, obtener los nombres, tamaños y contenido de los elementos del contenedor.

El siguiente ejemplo muestra cómo extraer texto de los correos electrónicos contenidos en el almacenamiento de Outlook:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if(attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }

    // Iterate over attachments
    foreach(ContainerItem item in attachments)
    {
		// Print the file path
		Console.WriteLine(item.FilePath);
        
        // Print metadata
        foreach (MetadataItem metadata in item.Metadata)
        {
            Console.WriteLine(string.Format("{0}: {1}", metadata.Name, metadata.Value));
        }

		try
        {
            // Create Parser object for the email content
            using (Parser attachmentParser = item.OpenParser())
            {
                // Extract an email text
                using (TextReader reader = attachmentParser.GetText())
                {
                    Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
                }
            }
        }
        catch (UnsupportedDocumentFormatException)
        {
            Console.WriteLine("Isn't supported.");
        }
	}
}
```

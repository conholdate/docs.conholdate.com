Los archivos PDF suelen contener **metadatos**, como el título, el asunto, el autor, la fecha de creación y la aplicación utilizada para generar el documento. Con **GroupDocs.Parser para .NET**, puede extraer fácilmente estas propiedades de metadatos mediante programación utilizando el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>.  

Esta guía muestra paso a paso cómo extraer metadatos de documentos PDF en C#.

---

## ¿Qué metadatos se pueden extraer? {#what-metadata-can-be-extracted}

El método `GetMetadata` puede devolver las siguientes propiedades de un documento PDF:

| Campo de metadatos | Descripción |
| --- | --- |
| **title** | Título del documento PDF |
| **subject** | Asunto del documento PDF |
| **keywords** | Palabras clave asociadas al documento |
| **author** | Autor del documento |
| **application** | Aplicación que creó el PDF |
| **application-version** | Versión de la aplicación |
| **created-time** | Fecha y hora en que se creó el PDF |
| **last-saved-time** | Fecha y hora de la última modificación del PDF |

⚡ *Nota: La disponibilidad de metadatos depende del propio archivo PDF. No todos los campos necesariamente están presentes en cada documento.*

---

## Cómo extraer metadatos de PDF en C# {#how-to-extract-pdf-metadata-in-c}

Siga estos pasos para obtener los metadatos de un documento PDF:

1. **Cree un objeto `Parser`** y cargue el archivo PDF.
2. **Llame al método `GetMetadata`** para recuperar los elementos de metadatos.
3. **Itere sobre la colección** y lea los nombres y valores de los metadatos.  

### Ejemplo: Extraer metadatos de PDF en C# {#example-extract-pdf-metadata-in-c}
```csharp
// Load the PDF file
using (Parser parser = new Parser(filePath))
{
    // Extract metadata
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
  
    // Display metadata fields
    foreach (MetadataItem item in metadata)
    {
        Console.WriteLine($"{item.Name}: {item.Value}");
    }
}
```


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve un valor *null* si la extracción de metadatos no es compatible con el documento. Por ejemplo, la extracción de metadatos no es compatible con archivos TXT. Por lo tanto, para un archivo TXT <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve *null*. Si el documento PDF no tiene metadatos, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> El método devuelve una colección vacía.
:::


## ¿Por qué extraer metadatos de PDF? {#why-extract-pdf-metadata}

Extraer metadatos de PDF es útil para:
*   Gestión de documentos: encontrar y categorizar rápidamente archivos por autor, tema o palabras clave.
*   Verificación de cumplimiento: confirmar fechas de creación y modificación.
*   Indexación para búsquedas: mejorar la precisión de las búsquedas al incluir propiedades del documento.

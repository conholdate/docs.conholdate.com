GroupDocs.Parser ofrece la funcionalidad para extraer datos de presentaciones de Microsoft Office PowerPoint. Se admiten tanto los formatos clásicos (ppt, pot) como los formatos Open XML (pptx, potx). Asimismo, se admiten los formatos de LibreOffice Impress (anteriormente OpenOffice.org Impress).

La siguiente tabla proporciona la lista de formatos admitidos:

| Formato | Descripción |
| --- | --- |
| <a href="https://wiki.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">PPT</a> | Presentación de Microsoft Office PowerPoint |
| <a href="https://wiki.fileformat.com/presentation/pps/" target="_blank" rel="nofollow noopener noreferrer">PPS</a> | Presentación de diapositivas de Microsoft Office PowerPoint |
| <a href="https://wiki.fileformat.com/presentation/pot/" target="_blank" rel="nofollow noopener noreferrer">POT</a> | Plantilla de Microsoft Office PowerPoint |
| <a href="https://wiki.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">PPTX</a> | Presentación Open XML de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/pptm/" target="_blank" rel="nofollow noopener noreferrer">PPTM</a> | Presentación Open XML con macros habilitadas de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/potx/" target="_blank" rel="nofollow noopener noreferrer">POTX</a> | Plantilla de presentación Open XML de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/potm/" target="_blank" rel="nofollow noopener noreferrer">POTM</a> | Plantilla de presentación Open XML con macros habilitadas de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/ppsx/" target="_blank" rel="nofollow noopener noreferrer">PPSX</a> | Presentación de diapositivas Open XML de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/ppsm/" target="_blank" rel="nofollow noopener noreferrer">PPSM</a> | Presentación de diapositivas Open XML con macros habilitadas de Microsoft Office |
| <a href="https://wiki.fileformat.com/presentation/odp/" target="_blank" rel="nofollow noopener noreferrer">ODP</a> | Presentación de documentos abiertos (Open Document) |
| <a href="https://wiki.fileformat.com/presentation/otp/" target="_blank" rel="nofollow noopener noreferrer">OTP</a> | Plantilla de presentación de documentos abiertos (Open Document) |

## ¿Qué es los metadatos de un documento de Word? {#what-is-word-document-metadata}

Los metadatos de un documento de Word son información oculta almacenada dentro de sus archivos .doc y .docx. Es como una “huella digital digital” que contiene detalles sobre el documento, tales como:

- Quién escribió el documento
- Cuándo se creó y modificó por última vez
- Cuánto tiempo se dedicó a redactarlo
- El título, asunto y palabras clave del documento
- Qué versión de Word se utilizó

Puede ver parte de esta información haciendo clic derecho en un archivo de Word y seleccionando “Propiedades”; sin embargo, con GroupDocs.Parser, puede extraer estos datos programáticamente mediante código C#.

## ¿Por qué extraer los metadatos de un documento de Word? {#why-extract-word-metadata}

A continuación se presentan escenarios comunes en los que resulta útil extraer los metadatos de documentos de Word:

**Gestión de documentos:**
- Organizar automáticamente los documentos por autor o fecha de creación
- Crear bibliotecas de documentos buscables
- Rastrear versiones y cambios en los documentos

**Aplicaciones empresariales:**
- Encontrar todos los documentos creados por un empleado específico
- Monitorear la actividad de edición de documentos
- Garantizar la atribución adecuada de los documentos

**Cumplimiento y auditoría:**
- Rastrear el historial de documentos para requisitos legales
- Monitorear el acceso a documentos confidenciales
- Mantener registros del ciclo de vida de los documentos

## ¿Qué información se puede extraer? {#what-information-can-you-extract}

El método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> puede extraer los siguientes detalles de los documentos de Word:

| Información | Qué información proporciona |
| --- | --- |
| **title** | El título del documento |
| **author** | Quién creó el documento |
| **subject** | De qué trata el documento |
| **keywords** | Etiquetas o palabras clave asociadas al documento |
| **comments** | Comentarios añadidos al documento |
| **company** | Nombre de la empresa asociado al archivo |
| **manager** | Gerente asociado al documento |
| **created-time** | Cuándo se creó el documento por primera vez |
| **last-saved-time** | Cuándo se guardaron por última vez los cambios |
| **last-printed-time** | Cuándo se imprimió por última vez el documento |
| **total-editing-time** | Cuántos minutos se dedicaron a editar |
| **revision-number** | Cuántas veces se ha revisado el archivo |
| **template** | Qué plantilla de Word se utilizó |
| **application** | Qué aplicación creó el documento |
| **application-version** | La versión de Word que lo creó |

*Además, incluye detalles técnicos adicionales como hyperlink-base, content-status, category y last-author.*

## Cómo extraer los metadatos de un documento de Word {#how-to-extract-word-metadata}

¡Es muy sencillo! Simplemente siga estos 3 pasos fáciles:

### Paso 1: Crear un analizador (Parser) {#step-1-create-a-parser}
Apunte el analizador (Parser) a su documento de Word:

```csharp
using(Parser parser = new Parser("your-document.docx"))
{
    // Your code goes here
}
```

### Paso 2: Obtener los metadatos {#step-2-get-the-metadata}
Extraer toda la información de metadatos:

```csharp
IEnumerable<MetadataItem> metadata = parser.GetMetadata();
```

### Paso 3: Leer los resultados {#step-3-read-the-results}
Recorra y muestre lo que encontró:

```csharp
foreach(MetadataItem item in metadata)
{
    Console.WriteLine($"{item.Name}: {item.Value}");
}
```

### Ejemplo completo de funcionamiento {#complete-working-example}

A continuación se muestra el código completo que extrae y muestra todos los metadatos de un documento de Word:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract metadata from the document
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    
    // Iterate over metadata items
    foreach(MetadataItem item in metadata)
    {
        // Print the item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```


:::warning
**Nota**: Si un documento de Word no tiene metadatos o el formato de archivo no es compatible, es posible que no obtenga resultados. Esto es normal: no todos los documentos tienen información de metadatos completa.
:::


## Formatos de archivo de Word admitidos {#supported-word-file-formats}

Esto funciona con todos los formatos comunes de Microsoft Word:
- **.doc** – Documentos antiguos de Word (Word 97-2003)
- **.docx** – Documentos más recientes de Word (Word 2007 y versiones posteriores)
- **.dot** – Plantillas de documentos de Word
- **.dotx** – Archivos de plantilla de Word

## Ejemplos prácticos {#practical-examples}

### Ejemplo 1: Buscar documentos por autor {#example-1-find-documents-by-author}

Supongamos que desea encontrar todos los documentos de Word en una carpeta que hayan sido creados por una persona específica:

```csharp
string[] documents = Directory.GetFiles(@"C:\MyDocuments", "*.docx");

foreach (string document in documents)
{
    using (Parser parser = new Parser(document))
    {
        var metadata = parser.GetMetadata();
        var author = metadata.FirstOrDefault(m => m.Name == "author");
        
        if (author?.Value?.ToString() == "John Smith")
        {
            Console.WriteLine($"Found document by John Smith: {Path.GetFileName(document)}");
        }
    }
}
```

### Ejemplo 2: Informe de resumen de documentos {#example-2-document-summary-report}

Cree un informe de resumen que muestre la información clave sobre sus documentos de Word:

```csharp
using (Parser parser = new Parser("report.docx"))
{
    var metadata = parser.GetMetadata();
    
    Console.WriteLine("=== Document Summary ===");
    Console.WriteLine($"Title: {GetValue(metadata, "title")}");
    Console.WriteLine($"Author: {GetValue(metadata, "author")}");
    Console.WriteLine($"Created: {GetValue(metadata, "created-time")}");
    Console.WriteLine($"Last Modified: {GetValue(metadata, "last-saved-time")}");
    Console.WriteLine($"Total Editing Time: {GetValue(metadata, "total-editing-time")} minutes");
}

string GetValue(IEnumerable<MetadataItem> metadata, string name)
{
    return metadata.FirstOrDefault(m => m.Name == name)?.Value?.ToString() ?? "Not available";
}
```

## Solución de problemas comunes {#troubleshooting-common-issues}

**Problema**: ¿No se obtienen metadatos?
- **Solución**: Es posible que el documento no tenga propiedades de metadatos definidas o que el formato de archivo no sea compatible

**Problema**: ¿Error «archivo no encontrado»?
- **Solución**: Compruebe que la ruta del archivo sea correcta y que el archivo exista

**Problema**: ¿No se pueden leer documentos protegidos con contraseña?
- **Solución**: Elimine primero la protección con contraseña, ya que los documentos cifrados requieren un manejo especial

**Problema**: ¿Algunos campos de metadatos están vacíos?
- **Solución**: Esto es normal; no todos los documentos de Word tienen todos los campos de metadatos rellenados

## Prácticas recomendadas {#best-practices}

1. **Utilice siempre sentencias `using`** para desechar correctamente los objetos Parser
2. **Compruebe los valores nulos** al acceder a campos específicos de metadatos
3. **Maneje las excepciones** para archivos corruptos o inaccesibles
4. **Pruebe con distintas versiones de Word** para garantizar la compatibilidad
5. **Valide los formatos de archivo** antes de intentar extraer metadatos

# Extraer metadatos de hojas de cálculo de Excel en C# .NET

Los archivos de Microsoft Excel suelen contener **metadatos** ocultos, como el autor, la empresa, la fecha de creación, la hora de la última modificación y más. Con **GroupDocs.Parser for .NET**, puede extraer fácilmente estos metadatos de hojas de cálculo de Excel (`.xls` y `.xlsx`) mediante el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>.  

Esta guía explica cómo extraer metadatos de archivos de Excel mediante programación en solo unos pocos pasos.

---

## ¿Qué metadatos se pueden extraer? {#what-metadata-can-be-extracted}


El método `GetMetadata` le permite acceder a una amplia gama de propiedades de las hojas de cálculo de Excel:

| Campo de metadatos | Descripción |
| --- | --- |
| **title** | Título de la hoja de cálculo |
| **subject** | Asunto de la hoja de cálculo |
| **keywords** | Palabras clave de la hoja de cálculo |
| **comments** | Comentarios del usuario |
| **content-status** | Estado de la hoja de cálculo |
| **category** | Categoría de la hoja de cálculo |
| **company** | Nombre de la empresa |
| **manager** | Nombre del responsable |
| **author** | Autor original |
| **last-author** | Último modificador |
| **hyperlink-base** | URL base para hipervínculos relativos |
| **application** | Aplicación utilizada para crear el archivo |
| **application-version** | Versión de la aplicación |
| **template** | Nombre de la plantilla |
| **created-time** | Hora de creación |
| **last-saved-time** | Hora del último guardado |
| **last-printed-time** | Hora de la última impresión |
| **revision-number** | Número de revisión |
| **total-editing-time** | Tiempo total de edición (en minutos) |

---


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve un valor *null* si la extracción de metadatos no es compatible con el documento. Por ejemplo, la extracción de metadatos no es compatible con archivos CSV. Por lo tanto, para un archivo CSV <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> el método devuelve *null*. Si la hoja de cálculo de Microsoft Office Excel no tiene metadatos, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> El método devuelve una colección vacía.
:::


## Cómo extraer metadatos de Excel en C# {#how-to-extract-excel-metadata-in-c}

Siga estos pasos para extraer metadatos de un archivo de Excel:

1. **Instancie el objeto Parser** para la hoja de cálculo de Excel.
2. **Llame al método `GetMetadata`** para recuperar todos los elementos de metadatos.
3. **Itere a través de la colección** e imprima los nombres y valores de los metadatos.  

```csharp
// Load the Excel file
using (Parser parser = new Parser(filePath))
{
    // Extract metadata
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
 
    // Iterate through metadata items
    foreach (MetadataItem item in metadata)
    {
        Console.WriteLine($"{item.Name}: {item.Value}");
    }
}
```

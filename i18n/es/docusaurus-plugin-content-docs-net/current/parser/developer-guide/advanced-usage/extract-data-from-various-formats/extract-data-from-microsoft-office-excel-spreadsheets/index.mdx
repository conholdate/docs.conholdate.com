GroupDocs.Parser ofrece una funcionalidad completa para **extraer tablas desde aplicaciones Excel en C#** y extraer datos de hojas de cálculo de Microsoft Office Excel. Se admiten tanto los formatos clásicos (xls, xlt) como los formatos Open XML (xlsx, xltx). Asimismo, se admiten los formatos de LibreOffice Calc (OpenOffice.org Calc), CSV y Apple iWork Numbers.

Puede extraer:
- **Contenido de texto** de hojas de cálculo completas o de hojas individuales
- **Tablas** con estructura y formato preservados
- **Metadatos**, como autor, fecha de creación y propiedades del documento
- **Imágenes** incrustadas en archivos Excel

Para ejemplos detallados sobre la extracción de tablas, consulte la guía [Extraer tablas de un documento](/net/parser/developer-guide/advanced-usage/working-with-tables/extract-tables-from-document/).

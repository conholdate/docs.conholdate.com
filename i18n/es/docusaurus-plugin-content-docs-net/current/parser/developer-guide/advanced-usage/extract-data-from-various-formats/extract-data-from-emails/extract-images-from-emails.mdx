Para extraer imágenes de correos electrónicos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> se utiliza el método. De forma predeterminada, las imágenes se extraen en su formato original. Al usar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> Es posible extraer imágenes de los correos electrónicos en los formatos BMP, GIF, JPEG, PNG y WebP.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>[ ](https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata) el método devuelve un valor *null* si la extracción de imágenes no es compatible con el documento. Por ejemplo, la extracción de imágenes no es compatible con archivos TXT. Por lo tanto, para un archivo TXT <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> el método devuelve *null*. Si un correo electrónico no tiene imágenes, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> El método devuelve una colección vacía.
:::


A continuación se indican los pasos para extraer imágenes de un correo electrónico y guardarlas como archivos PNG:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el correo electrónico inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> y obtener la colección de objetos de imagen;
*   Recorrer la colección y guardar el contenido de las imágenes en archivos.

El siguiente ejemplo muestra cómo extraer imágenes de un correo electrónico:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract images from the email
    IEnumerable<PageImageArea> images = parser.GetImages();
 
    // Create the options to save images in PNG format
    ImageOptions options = new ImageOptions(ImageFormat.Png);
 
    int imageNumber = 0;
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Save the image to the png file
        image.Save(imageNumber.ToString() + ".png", options);
        imageNumber++;
    }
}
```


:::info
La extracción de imágenes de un correo electrónico no genera solicitudes salientes: las imágenes a las que hace referencia el cuerpo HTML mediante una URL absoluta no se descargan mediante <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>. Otros métodos de extracción se comportan de forma diferente: consulte [Acceso a la red y privacidad de los datos](/net/parser/getting-started/network-access-and-data-privacy/).
:::

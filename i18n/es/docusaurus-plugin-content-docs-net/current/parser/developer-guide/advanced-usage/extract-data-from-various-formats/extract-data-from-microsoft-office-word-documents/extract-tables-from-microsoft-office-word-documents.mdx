Esta guía explica cómo extraer tablas de documentos de Microsoft Office Word (`.doc`, `.docx`) utilizando GroupDocs.Parser para .NET.

## Cómo funciona la extracción de tablas {#how-table-extraction-works}

GroupDocs.Parser convierte el diseño de un documento en un formato XML estructurado. Las tablas se representan mediante etiquetas `<table>` dentro de este XML. El proceso de extracción implica leer esta estructura XML para identificar y procesar el contenido de las tablas.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> el método devuelve un valor *null* si la extracción de estructura de texto no es compatible con el documento. Por ejemplo, la extracción de estructura de texto no es compatible con archivos TXT. Por lo tanto, para un archivo TXT <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a> el método devuelve *null*. Si el documento de Microsoft Office Word no tiene texto, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a>[] (https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata) método devuelve un valor vacío <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a> objeto.
:::


## Guía paso a paso {#step-by-step-guide}

### 1. Crear una instancia del analizador {#1-create-a-parser-instance}
Comience inicializando el analizador con la ruta de su documento.

```csharp
using (Parser parser = new Parser("YourDocument.docx"))
{
    // Extraction code goes here
}
```

### 2. Recuperar la estructura del documento {#2-retrieve-document-structure}
Obtiene la representación XML de la estructura del documento.

```csharp
using (XmlReader reader = parser.GetStructure())
{
    if (reader == null)
    {
        Console.WriteLine("Text structure extraction isn't supported for this document.");
        return;
    }
    // Process the XML structure
}
``` 

### 3. Encontrar y procesar tablas {#3-find-and-process-tables}
Iterar a través del XML para localizar y procesar los elementos de tabla.

```csharp
while (reader.Read())
{
    // Look for table start elements
    if (reader.NodeType == XmlNodeType.Element && reader.Name == "table")
    {
        Console.WriteLine("Found a table:");
        ProcessTable(reader);
    }
}
```

### 4. Método de procesamiento de tablas {#4-table-processing-method}
Este método maneja la extracción de filas y celdas de cada tabla.

```csharp
private static void ProcessTable(XmlReader reader)
{
    StringBuilder cellValue = new StringBuilder();
    int rowIndex = 0;

    while (reader.Read())
    {
        // Exit when table ends
        if (reader.NodeType == XmlNodeType.EndElement && reader.Name == "table")
        {
            break;
        }

        // Detect new rows
        if (reader.NodeType == XmlNodeType.Element && reader.Name == "tr")
        {
            rowIndex++;
            Console.WriteLine($"[Row {rowIndex}]");
        }

        // Reset cell value at cell start
        if (reader.NodeType == XmlNodeType.Element && reader.Name == "td")
        {
            cellValue.Clear();
        }

        // Output cell value at cell end
        if (reader.NodeType == XmlNodeType.EndElement && reader.Name == "td")
        {
            Console.WriteLine($"  {cellValue}");
        }

        // Accumulate cell text content
        if (reader.NodeType == XmlNodeType.Text)
        {
            cellValue.Append(reader.Value);
        }
    }
}
```

### Ejemplo completo {#complete-example}
A continuación se presenta un ejemplo completo y funcional que extrae y muestra tablas de un documento de Word:

```csharp
using System;
using System.Text;
using System.Xml;
using GroupDocs.Parser;

public static class WordTableExtractor
{
    public static void ExtractTables(string filePath)
    {
        using (Parser parser = new Parser(filePath))
        {
            using (XmlReader reader = parser.GetStructure())
            {
                if (reader == null)
                {
                    Console.WriteLine("Text structure extraction isn't supported for this document.");
                    return;
                }

                Console.WriteLine($"Analyzing: {filePath}");
                Console.WriteLine("----------------------------------------");

                while (reader.Read())
                {
                    if (reader.NodeType == XmlNodeType.Element && reader.Name == "table")
                    {
                        Console.WriteLine("\n>>> TABLE FOUND");
                        ProcessTable(reader);
                    }
                }
            }
        }
    }

    private static void ProcessTable(XmlReader reader)
    {
        StringBuilder cellValue = new StringBuilder();
        int rowIndex = 0;

        while (reader.Read())
        {
            if (reader.NodeType == XmlNodeType.EndElement && reader.Name == "table")
            {
                break;
            }

            if (reader.NodeType == XmlNodeType.Element && reader.Name == "tr")
            {
                rowIndex++;
                Console.WriteLine($"[Row {rowIndex}]");
            }

            if (reader.NodeType == XmlNodeType.Element && reader.Name == "td")
            {
                cellValue.Clear();
            }

            if (reader.NodeType == XmlNodeType.EndElement && reader.Name == "td")
            {
                Console.WriteLine($"  {cellValue}");
            }

            if (reader.NodeType == XmlNodeType.Text)
            {
                cellValue.Append(reader.Value);
            }
        }
    }
}
```

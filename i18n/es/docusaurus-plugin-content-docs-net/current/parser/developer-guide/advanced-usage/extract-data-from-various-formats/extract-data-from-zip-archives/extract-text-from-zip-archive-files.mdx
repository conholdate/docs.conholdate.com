Para extraer archivos de archivos ZIP se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a>. Este método devuelve la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>.

Una entrada ZIP puede contener los siguientes metadatos:

| Nombre | Descripción |
| --- | --- |
| fecha | La hora y fecha en que el archivo indicado por la entrada ZIP fue modificado por última vez. |

Estos metadatos se refieren al propio elemento contenedor, no al documento.

A continuación se indican los pasos para extraer el texto de un correo electrónico de archivos ZIP:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el archivo ZIP inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>;
*   Comprobar si la *colección* no es *nula* (la extracción de contenedores es compatible con el documento);
*   Recorrer la colección y obtener los nombres, tamaños y contenido de los elementos del contenedor.

El siguiente ejemplo muestra cómo extraer texto de archivos ZIP:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();

    // Iterate over files
    foreach(ContainerItem item in attachments)
    {
		// Print the file path
		Console.WriteLine(item.FilePath);

        // Print metadata
        foreach(MetadataItem metadata in item.Metadata)
        {
            Console.WriteLine(string.Format("{0}: {1}", metadata.Name, metadata.Value));
        }
       
        try
        {
            // Create Parser object for the file content
            using (Parser fileParser = item.OpenParser())
            {
                // Extract the file text
                using (TextReader reader = fileParser.GetText())
                {
                    Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
                }
            }
        }
        catch (UnsupportedDocumentFormatException)
        {
            Console.WriteLine("Isn't supported.");
        }
	}
}
```

Para extraer imágenes de presentaciones de Microsoft Office PowerPoint <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> se utilizan métodos. De forma predeterminada, las imágenes se extraen en su formato original. Al utilizar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> Es posible extraer imágenes de presentaciones de Microsoft Office PowerPoint en los formatos BMP, GIF, JPEG, PNG y WebP.


:::warning
El método `GetImages` devuelve un valor nulo si la extracción de imágenes no es compatible con el documento. Por ejemplo, la extracción de imágenes no es compatible con archivos TXT; por lo tanto, para un archivo TXT, el método `GetImages` devuelve `null`. Si una presentación de Microsoft Office PowerPoint no contiene imágenes, el método `GetImages` devuelve una colección vacía.
:::


A continuación se indican los pasos para extraer imágenes de una presentación de Microsoft Office PowerPoint y guardarlas como archivos PNG:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para la presentación inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> y obtener la colección de objetos de imagen;
*   Recorrer la colección y guardar el contenido de las imágenes en archivos.

El siguiente ejemplo muestra cómo extraer imágenes de una presentación de Microsoft Office PowerPoint:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract images from presentation
    IEnumerable<PageImageArea> images = parser.GetImages();
  
    // Create the options to save images in PNG format
    ImageOptions options = new ImageOptions(ImageFormat.Png);
  
    int imageNumber = 0;
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Save the image to the png file
        image.Save(imageNumber.ToString() + ".png", options);
        imageNumber++;
    }
}
```

GroupDocs.Parser proporciona la funcionalidad para extraer datos de libros electrónicos en formato EPUB. Asimismo, se admiten los formatos CHM y FB2.

La siguiente tabla muestra la lista de formatos admitidos:

| Formato | Descripción |
| --- | --- |
| <a href="https://wiki.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">CHM</a> | Archivo de ayuda HTML compilado |
| <a href="https://wiki.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> | Formato de archivo de libro electrónico digital |
| <a href="https://wiki.fileformat.com/ebook/fb2/" target="_blank" rel="nofollow noopener noreferrer">FB2</a> | Archivo FictionBook 2.0 |

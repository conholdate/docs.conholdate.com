GroupDocs.Parser le permite extraer correos electrónicos desde servidores remotos y extraer datos de dichos correos electrónicos. Los siguientes protocolos de correo electrónico son compatibles:

*   Protocolo de oficina postal (POP)
*   Protocolo de acceso a mensajes de Internet (IMAP)
*   Servicios web de Exchange (EWS)

Para crear una instancia de la clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> con el fin de extraer correos electrónicos desde un servidor remoto, se utilizan los siguientes constructores:

```csharp
Parser(EmailConnection connection);
Parser(EmailConnection connection, ParserSettings parserSettings);
```

El segundo constructor permite utilizar el objeto <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/parsersettings" target="_blank" rel="nofollow noopener noreferrer">ParserSettings</a> para controlar el proceso; por ejemplo, agregando funcionalidad de [registro (logging)](/net/parser/developer-guide/advanced-usage/logging/).

<a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailconnection" target="_blank" rel="nofollow noopener noreferrer">EmailConnection</a> es una clase base. Las siguientes clases de conexión se utilizan:

| Protocolo | Clase |
| --- | --- |
| POP | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailpopconnection" target="_blank" rel="nofollow noopener noreferrer">EmailPopConnection</a> |
| IMAP | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailimapconnection" target="_blank" rel="nofollow noopener noreferrer">EmailImapConnection</a> |
| Exchange Web Services | <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.options/emailewsconnection" target="_blank" rel="nofollow noopener noreferrer">EmailEwsConnection</a> |

A continuación se indican los pasos para extraer correos electrónicos desde el servidor remoto:

*   Preparar la cadena de conexión (consulte la tabla a continuación);
*   Instanciar el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> con la cadena de conexión;
*   Llamar a la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/container" target="_blank" rel="nofollow noopener noreferrer">Features.Container</a> para verificar si la extracción de contenedores está soportada;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos de elemento de contenedor de documentos;
*   Iterar a través de la colección y obtener el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para cada elemento.

El siguiente ejemplo muestra cómo extraer correos electrónicos desde un servidor Exchange:

```csharp
// Create the connection object for Exchange Web Services protocol 
EmailConnection connection = new EmailEwsConnection(
    "https://outlook.office365.com/ews/exchange.asmx",
    "email@server",
    "password");
 
// Create an instance of Parser class to extract emails from the remote server
using (Parser parser = new Parser(connection))
{
    // Check if container extraction is supported
    if (!parser.Features.Container)
    {
        Console.WriteLine("Container extraction isn't supported.");
        return;
    }
 
    // Extract email messages from the server
    IEnumerable<ContainerItem> emails = parser.GetContainer();
 
    // Iterate over attachments
    foreach (ContainerItem item in emails)
    {
        // Create an instance of Parser class for email message
        using (Parser emailParser = item.OpenParser())
        {
            // Extract the email text
            using (TextReader reader = emailParser.GetText())
            {
                // Print the email text
                Console.WriteLine(reader == null ? "Text extraction isn't supported." : reader.ReadToEnd());
            }
        }
    }
}
```

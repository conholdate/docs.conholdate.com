Para buscar una palabra clave en libros electrónicos EPUB, se utiliza el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a>. Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>. Para más detalles, consulte [Buscar texto](/net/parser/developer-guide/advanced-usage/working-with-text/search-text/).

A continuación se presentan los pasos para buscar una palabra clave en un libro electrónico EPUB:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el libro electrónico inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Iterar a través de la colección y obtener la posición y el texto.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Buscar(String)</a> el método devuelve un valor *null* si la búsqueda no es compatible con el libro electrónico. Por ejemplo, la extracción de texto no es compatible con el archivo ZIP. Por lo tanto, para un archivo ZIP <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Buscar(String)</a> El método devuelve `*null*`. Para un libro electrónico EPUB vacío. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Buscar(String)</a> El método devuelve una colección vacía.
:::


El siguiente ejemplo muestra cómo buscar una palabra clave en un libro electrónico EPUB:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("page number");
   
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(String, SearchOptions)</a> se utiliza para la búsqueda avanzada en libros electrónicos EPUB, como la búsqueda con expresiones regulares, la búsqueda por páginas, etc. El parámetro <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> se utiliza para personalizar la búsqueda.

A continuación se indican los pasos para realizar una búsqueda con expresión regular en un libro electrónico EPUB:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el libro electrónico inicial;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> con los parámetros para la búsqueda;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Iterar a través de la colección y obtener la posición y el texto.

El siguiente ejemplo muestra cómo realizar una búsqueda con expresión regular en un libro electrónico EPUB:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search with a regular expression with case matching
    IEnumerable<SearchResult> sr = parser.Search("page number: [0-9]+", new SearchOptions(true, false, true));
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

Para extraer imágenes de documentos PDF <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> se utilizan métodos. De forma predeterminada, las imágenes se extraen en su formato original. Al utilizar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/imageoptions" target="_blank" rel="nofollow noopener noreferrer">ImageOptions</a> Es posible extraer imágenes de documentos PDF en los formatos BMP, GIF, JPEG, PNG y WebP.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>[ ](https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata) método devuelve un valor *null* si la extracción de imágenes no es compatible con el documento. Por ejemplo, la extracción de imágenes no es compatible con archivos TXT. Por lo tanto, para archivos TXT, el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> devuelve *null*. Si un documento PDF no contiene imágenes, el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> devuelve una colección vacía.
:::


A continuación se indican los pasos para extraer imágenes de un documento PDF y guardarlas como archivos PNG:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a> y obtener la colección de objetos de imagen;
*   Iterar sobre la colección y guardar el contenido de cada imagen en un archivo.

El siguiente ejemplo muestra cómo extraer imágenes de un documento PDF:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract images from document
    IEnumerable<PageImageArea> images = parser.GetImages();
  
    // Create the options to save images in PNG format
    ImageOptions options = new ImageOptions(ImageFormat.Png);
  
    int imageNumber = 0;
    // Iterate over images
    foreach (PageImageArea image in images)
    {
        // Save the image to the png file
        image.Save(imageNumber.ToString() + ".png", options);
        imageNumber++;
    }
}
```

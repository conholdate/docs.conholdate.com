GroupDocs.Parser ofrece la funcionalidad para extraer datos de documentos de Microsoft Office Word. Se admiten tanto los formatos clásicos (doc, dot) como los formatos Open XML (docx, dotx). Asimismo, se admiten los formatos de LibreOffice Writer (anteriormente OpenOffice.org Writer) y RTF.

La siguiente tabla proporciona la lista de formatos admitidos:

| Formato | Descripción |
| --- | --- |
| <a href="https://wiki.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC</a> | Documento de Microsoft Office Word |
| <a href="https://wiki.fileformat.com/word-processing/dot/" target="_blank" rel="nofollow noopener noreferrer">DOT</a> | Plantilla de documento de Microsoft Office Word |
| <a href="https://wiki.fileformat.com/word-processing/docx/" target="_blank" rel="nofollow noopener noreferrer">DOCX</a> | Documento Open XML de Microsoft Office |
| <a href="https://wiki.fileformat.com/word-processing/docm/" target="_blank" rel="nofollow noopener noreferrer">DOCM</a> | Documento Open XML con macros habilitadas de Microsoft Office |
| <a href="https://wiki.fileformat.com/word-processing/dotx/" target="_blank" rel="nofollow noopener noreferrer">DOTX</a> | Plantilla Open XML de Microsoft Office |
| <a href="https://wiki.fileformat.com/word-processing/dotm/" target="_blank" rel="nofollow noopener noreferrer">DOTM</a> | Plantilla Open XML con macros habilitadas de Microsoft Office |
| <a href="https://wiki.fileformat.com/word-processing/txt/" target="_blank" rel="nofollow noopener noreferrer">TXT</a> | Texto sin formato |
| <a href="https://wiki.fileformat.com/word-processing/odt/" target="_blank" rel="nofollow noopener noreferrer">ODT</a> | Texto Open Document |
| <a href="https://wiki.fileformat.com/word-processing/ott/" target="_blank" rel="nofollow noopener noreferrer">OTT</a> | Plantilla de texto Open Document |
| <a href="https://wiki.fileformat.com/word-processing/rtf/" target="_blank" rel="nofollow noopener noreferrer">RTF</a> | Formato de texto enriquecido (Rich Text Format) |

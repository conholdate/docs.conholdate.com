GroupDocs.Parser proporciona la funcionalidad para extraer datos de correos electrónicos. Se admiten tanto los formatos de mensaje de correo electrónico (eml, msg) como los formatos de almacenamiento de Outlook (ost, pst). Asimismo, se admiten los protocolos POP, IMAP y Exchange Web Services.

La siguiente tabla proporciona la lista de formatos admitidos:

| Formato | Descripción |
| --- | --- |
| <a href="https://wiki.fileformat.com/email/eml/" target="_blank" rel="nofollow noopener noreferrer">EML</a> | Mensaje de correo electrónico |
| <a href="https://wiki.fileformat.com/email/emlx/" target="_blank" rel="nofollow noopener noreferrer">EMLX</a> | Mensaje de correo de Apple Mail |
| <a href="https://wiki.fileformat.com/email/msg/" target="_blank" rel="nofollow noopener noreferrer">MSG</a> | Mensaje de correo de Microsoft Outlook |
| <a href="https://wiki.fileformat.com/email/pst/" target="_blank" rel="nofollow noopener noreferrer">PST</a> | Archivo de almacenamiento de información personal de Microsoft Outlook |
| <a href="https://wiki.fileformat.com/email/ost/" target="_blank" rel="nofollow noopener noreferrer">OST</a> | Archivo de datos sin conexión de Microsoft Outlook |


:::warning
Los mensajes con un cuerpo en HTML pueden hacer referencia a imágenes y hojas de estilo alojadas en servidores remotos. Extraer texto con formato o la estructura del documento de dicho mensaje provoca que GroupDocs.Parser solicite esos recursos, lo que implica que los píxeles de seguimiento (tracking pixels) presentes en un mensaje entrante se activarán. `GetText` no se ve afectado. Si procesa correos electrónicos que provienen de fuera de su organización, lea [Acceso a la red y privacidad de datos](/net/parser/getting-started/network-access-and-data-privacy/).
:::

Para buscar una palabra clave en documentos HTML <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Buscar(String)</a> se utiliza el método. Este método devuelve la colección de <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a> objetos. Para más detalles, consulte [Buscar texto](/net/parser/developer-guide/advanced-usage/working-with-text/search-text/).


:::warning
El análisis no ejecuta JavaScript ni obtiene contenido externo; para HTML generado dinámicamente, se debe preprocesar o extraer el contenido de texto real antes de realizar la búsqueda.
:::


A continuación se indican los pasos para buscar una palabra clave en un documento HTML:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(string)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Iterar a través de la colección y obtener la posición y el texto.


:::warning
<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> devuelve un valor *null* si la búsqueda no es compatible con el documento. Por ejemplo, la extracción de texto no es compatible con archivos ZIP. Por lo tanto, para un archivo ZIP, el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> devuelve *null*. Para un documento HTML vacío, el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> devuelve una colección vacía.
:::


El siguiente ejemplo muestra cómo buscar una palabra clave en un documento HTML:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search a keyword:
    IEnumerable<SearchResult> sr = parser.Search("page number");
   
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(String, SearchOptions)</a> se utiliza para realizar búsquedas avanzadas en documentos HTML, como búsquedas con expresiones regulares. El parámetro <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> se emplea para personalizar la búsqueda.

A continuación se indican los pasos para realizar una búsqueda con expresión regular en un documento HTML:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/searchoptions" target="_blank" rel="nofollow noopener noreferrer">SearchOptions</a> con los parámetros de la búsqueda;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search(string, SearchOptions)</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/searchresult" target="_blank" rel="nofollow noopener noreferrer">SearchResult</a>;
*   Iterar sobre la colección y obtener la posición y el texto.

El siguiente ejemplo muestra cómo realizar una búsqueda con expresión regular en un documento HTML:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser(filePath))
{
    // Search with a regular expression with case matching
    IEnumerable<SearchResult> sr = parser.Search("page number: [0-9]+", new SearchOptions(true, false, true));
    // Iterate over search results
    foreach(SearchResult s in sr)
    {
        // Print an index and found text:
        Console.WriteLine(string.Format("At {0}: {1}", s.Position, s.Text));
    }
}
```

### Resultados: colección nula frente a colección vacía {#null-vs-empty-collection-results}

El método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.parser/search/methods/1" target="_blank" rel="nofollow noopener noreferrer">Search()</a> se comporta de forma distinta según el tipo de documento y su contenido de texto:

- **Devuelve `null`** → cuando el tipo de documento no admite búsquedas (por ejemplo, archivos ZIP, imágenes u otros formatos no textuales).
- **Devuelve una colección vacía** → cuando el documento admite búsquedas (como HTML), pero no contiene texto buscable.  


### Ejemplo 1: Búsqueda en un documento no buscable (devuelve `null`) {#example-1-search-in-a-non-searchable-document-returns-null}
```csharp
using (Parser parser = new Parser("sample.zip")) // ZIP archives are not searchable
{
    var results = parser.Search("example");    
    
    if (results == null)
        Console.WriteLine("Search returned null: document type does not support searching.");
}
```

### Ejemplo 2: Búsqueda en un archivo HTML vacío (devuelve una colección vacía) {#example-2-search-in-an-empty-html-file-returns-empty-collection}
```csharp
using (Parser parser = new Parser("empty.html")) // Empty HTML without text
{
    var results = parser.Search("example");
    if (results != null && results.Count == 0)
        Console.WriteLine("Search returned empty collection: no text found in the document.");
}
```

### Ejemplo 3: Búsqueda en un archivo HTML válido (devuelve resultados) {#example-3-search-in-a-valid-html-file-returns-results}
```csharp
using (Parser parser = new Parser("sample.html")) // Contains text
{
    var results = parser.Search("example");
    if (results != null)
    {
        foreach (var result in results)
            Console.WriteLine($"Found: '{result.Text}' at position {result.Position}");
    }
}
```

## Recomendaciones de preprocesamiento {#preprocessing-recommendations}

GroupDocs.Parser trabaja con el **contenido de texto sin procesar** de los documentos HTML.  
**No** ejecuta JavaScript ni carga recursos externos (como CSS, imágenes o scripts).  
Si su archivo HTML depende de JavaScript para generar contenido dinámicamente, el analizador podría devolver una colección vacía.

Para mejorar los resultados, considere los siguientes pasos de preprocesamiento:

### 1. Utilice HTML pre-renderizado {#1-use-pre-rendered-html}
Asegúrese de que el archivo HTML que proporciona ya contenga el texto visible.  
Si su HTML es generado por una aplicación web, guarde o exporte la versión **completamente renderizada** de la página antes de pasársela al analizador.

### 2. Elimine marcas innecesarias {#2-remove-unnecessary-markup}
Si es posible, simplifique su HTML eliminando scripts, estilos o metadatos que no afecten el texto visible.  
Esto reduce el ruido y mejora la precisión de los resultados de búsqueda.

### 3. Normalice las codificaciones {#3-normalize-encodings}
Verifique que el archivo HTML utilice una codificación estándar (como UTF-8).  
Codificaciones inesperadas o inconsistentes pueden provocar texto ausente o ilegible durante la búsqueda.

### 4. Valide la presencia de texto {#4-validate-text-presence}
Si los resultados de la búsqueda están vacíos, abra el archivo HTML en un editor de texto para confirmar si el texto real está presente en el marcado.  
Si el contenido solo aparece tras ejecutar JavaScript en un navegador, no será buscable.

**Resumen**:  
Proporcione **HTML estático y basado en texto** siempre que sea posible.  
El HTML dinámico o generado mediante scripts no producirá resultados a menos que se convierta en texto plano o se pre-renderice antes del análisis.

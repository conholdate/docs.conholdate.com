GroupDocs.Parser ofrece la funcionalidad para extraer datos de documentos HTML y otros formatos de marcado.

La siguiente tabla proporciona la lista de formatos compatibles:

| Formato | Descripción |
| --- | --- |
| <a href="https://wiki.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">HTML</a> | Archivo de Lenguaje de Marcado de Hipertexto |
| <a href="https://wiki.fileformat.com/web/xhtml/" target="_blank" rel="nofollow noopener noreferrer">XHTML</a> | Archivo de Lenguaje de Marcado de Hipertexto Extensible |
| <a href="https://wiki.fileformat.com/web/mhtml/" target="_blank" rel="nofollow noopener noreferrer">MHTML</a> | Archivo HTML MIME |
| <a href="https://wiki.fileformat.com/word-processing/md/" target="_blank" rel="nofollow noopener noreferrer">MD</a> | Markdown |
| <a href="https://wiki.fileformat.com/web/xml/" target="_blank" rel="nofollow noopener noreferrer">XML</a> | Archivo XML |

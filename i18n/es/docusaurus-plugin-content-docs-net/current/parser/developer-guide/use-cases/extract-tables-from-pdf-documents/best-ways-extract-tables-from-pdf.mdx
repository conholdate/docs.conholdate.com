## Método 1: Extraer tablas de una página específica {#method-1-extract-tables-from-a-specific-page}

**Caso de uso:** Extracción específica por página | **Dificultad:** Fácil | **Ideal para:** Documentos con ubicaciones conocidas de tablas, procesamiento de una sola página

Este método extrae tablas de una página específica de un documento PDF. Es ideal cuando ya se conoce la página que contiene las tablas necesarias, como extraer los conceptos de una factura desde la primera página o procesar secciones específicas de un informe.

### Implementación {#implementation}

```csharp
static void ExtractTablesPerParticluarPage()
{
    string sample = "Invoices.pdf";
    
    // Initialize parser with PDF document
    using (var parser = new Parser(sample))
    {
        // Get document information
        var documentInfo = parser.GetDocumentInfo();
        int pageCount = documentInfo.PageCount;
        
        // Extract tables from first page (pageIndex = 0)
        var pageIndex = 0;
        var tables = parser.GetTables(pageIndex);

        if (tables != null && tables.Any())
        {
            int tableNumber = 1;
            foreach (var table in tables)
            {
                // Process each table
                // Display table dimensions and content
                Console.WriteLine($"  Table {tableNumber}: {table.RowCount} rows x {table.ColumnCount} columns");
                ProcessTable(table);
                tableNumber++;
            }
        }
    }
}
```

## Método 2: Extraer todas las tablas del documento completo {#method-2-extract-all-tables-from-entire-document}

**Caso de uso:** Procesamiento completo del documento | **Dificultad:** Fácil | **Ideal para:** Documentos de varias páginas, extracción exhaustiva de datos

Este método extrae todas las tablas de todas las páginas de un documento PDF y las organiza por página. Es perfecto para procesar documentos completos cuando se requieren datos tabulares exhaustivos en varias páginas.

### Implementación {#implementation-1}

```csharp
static void ExtractAllTablesFromDocument()
{
    string sample = "TablesReport.pdf";

    using (var parser = new Parser(sample))
    {   
        // Get all tables from entire document
        var tables = parser.GetTables();

        if (tables != null && tables.Any())
        {
            // Group tables by page index
            var tablesByPage = tables
                .GroupBy(table => table.Page.Index)
                .OrderBy(group => group.Key);

            foreach (var pageGroup in tablesByPage)
            {
                int pageIndex = pageGroup.Key;
                Console.WriteLine($"Tables in the Page {pageIndex + 1}");
                Console.WriteLine();

                int tableNumber = 1;
                foreach (var table in pageGroup)
                {
                    Console.WriteLine($"  Table {tableNumber}: {table.RowCount} rows x {table.ColumnCount} columns");
                    ProcessTable(table);
                    tableNumber++;
                }
                Console.WriteLine();
            }
        }
    }
}
```

### Características principales {#key-features-1}

- **Cobertura completa:** Extrae tablas de cada página automáticamente
- **Organización por página:** Agrupa las tablas por página para facilitar la navegación
- **Procesamiento escalable:** Maneja documentos con cientos de páginas
- **Ideal para:** Informes financieros, facturas de varias páginas y extracción de datos exhaustiva

### Cuándo utilizar este método {#when-to-use-this-method-1}

- Procesar informes financieros completos con tablas distribuidas en varias páginas
- Extraer todos los datos de facturas de varias páginas
- Análisis exhaustivo de documentos que requieren todos los datos de las tablas
- Escenarios de procesamiento por lotes en los que se necesita una extracción completa

## Método 3: Acceder a celdas individuales de tablas con salida formateada {#method-3-access-individual-table-cells-with-formatted-output}

**Caso de uso:** Procesamiento a nivel de celda | **Dificultad:** Media | **Ideal para:** Transformación de datos, formateo personalizado y análisis celda por celda

Este método proporciona acceso detallado a celdas individuales de tablas y formatea la salida para su visualización o procesamiento posterior. Calcula anchos óptimos de columna y genera visualizaciones de tablas formateadas con la alineación adecuada.

### Implementación {#implementation-2}

```csharp
static void ProcessTable(PageTableArea table)
{
    // Calculate column widths for proper alignment using LINQ
    int[] columnWidths = Enumerable.Range(0, table.ColumnCount)
        .Select(col => Math.Max(3, Enumerable.Range(0, table.RowCount)
            .Max(row => table[row, col]?.Text?.Length ?? 0)))
        .ToArray();

    // Display table with borders
    string separator = "+" + string.Join("+", columnWidths.Select(w => new string('-', w + 2))) + "+";
    
    // Display header row (first row)
    Console.WriteLine("    " + separator);
    Console.Write("    |");
    for (int col = 0; col < table.ColumnCount; col++)
    {
        string cellText = GetCellText(table, 0, col);
        Console.Write($" {cellText.PadRight(columnWidths[col])} |");
    }
    Console.WriteLine();
    Console.WriteLine("    " + separator);

    // Display data rows
    for (int row = 1; row < table.RowCount; row++)
    {
        Console.Write("    |");
        for (int col = 0; col < table.ColumnCount; col++)
        {
            string cellText = GetCellText(table, row, col);
            Console.Write($" {cellText.PadRight(columnWidths[col])} |");
        }
        Console.WriteLine();
    }
    Console.WriteLine("    " + separator);
}

static string GetCellText(PageTableArea table, int row, int col)
{
    return table[row, col]?.Text ?? "";
}
```

### Características clave {#key-features-2}

- **Tamaño dinámico de columnas:** Calcula automáticamente el ancho óptimo de las columnas según el contenido
- **Visualización con formato:** Crea bordes y alineación profesionales para la tabla
- **Acceso a nivel de celda:** Acceso directo a cualquier celda mediante el índice de fila y columna
- **Separación de encabezados:** Separa visualmente la fila de encabezado de las filas de datos
- **Ideal para:** Salida en consola, validación de datos, requisitos de formato personalizado

```csharp
static void ExtractTablesWithFiltering()
{
    string sample = "TablesReport.pdf";

    using (var parser = new Parser(sample))
    {
        var tables = parser.GetTables();

        if (tables != null && tables.Any())
        {
            // Filter tables with more than 5 rows
            var largeTables = tables
                .Where(table => table.RowCount > 5)
                .ToList();

            // Group by page and count tables per page
            var tablesPerPage = tables
                .GroupBy(table => table.Page.Index)
                .Select(group => new
                {
                    Page = group.Key + 1,
                    TableCount = group.Count(),
                    TotalRows = group.Sum(t => t.RowCount)
                })
                .OrderBy(x => x.Page);

            // Extract specific columns from all tables
            foreach (var table in tables)
            {
                if (table.ColumnCount >= 2)
                {
                    // Extract first two columns from each table
                    var firstTwoColumns = Enumerable.Range(0, table.RowCount)
                        .Select(row => new
                        {
                            Column1 = GetCellText(table, row, 0),
                            Column2 = GetCellText(table, row, 1)
                        })
                        .ToList();
                }
            }
        }
    }
}
```

## Preguntas frecuentes {#common-questions}

**P: ¿Necesito plantillas para extraer tablas?**  
R: No. GroupDocs.Parser detecta automáticamente las estructuras de tabla en documentos PDF sin necesidad de plantillas. Las plantillas son opcionales y se usan en escenarios avanzados con documentos escaneados o diseños complejos.

**P: ¿Puedo extraer tablas de PDF escaneados?**  
R: Sí, con soporte OCR. GroupDocs.Parser puede trabajar con conectores OCR para extraer tablas de PDF escaneados. Se recomienda la extracción basada en plantillas para documentos escaneados con diseños consistentes.

**P: ¿Qué precisión tiene la detección automática de tablas?**  
R: La detección automática de tablas funciona excelente en PDF basados en texto con estructuras de tabla claras. La precisión depende de la calidad del documento y del formato de la tabla. Las tablas bien estructuradas logran una extracción casi perfecta.

**P: ¿Puedo extraer columnas o filas específicas?**  
R: Sí. Una vez extraídas las tablas, puede acceder a celdas individuales mediante el índice de fila y columna, lo que le permite filtrar, transformar o extraer elementos de datos específicos.

**P: ¿GroupDocs.Parser admite otros formatos de documento?**  
R: Sí. GroupDocs.Parser admite más de 50 formatos de documento, incluidos Word, Excel, PowerPoint y más. Sin embargo, esta guía se centra en la extracción de tablas en PDF.

**P: ¿Cómo manejo documentos con varias tablas por página?**  
R: El método `GetTables()` devuelve todas las tablas encontradas en una página. Puede recorrer la colección y procesar cada tabla individualmente, o filtrarlas según tamaño, posición o contenido.

**P: ¿Puedo exportar tablas extraídas a otros formatos?**  
R: Sí. Tras la extracción, puede procesar los datos de la tabla y exportarlos a formatos CSV, Excel, JSON o bases de datos mediante bibliotecas estándar de .NET o las API de conversión de GroupDocs.

GroupDocs.Parser permite extraer metadatos básicos (propiedades del documento, información del archivo) de documentos en diversos formatos: PDF, correos electrónicos, libros electrónicos, Microsoft Office: Word (DOC, DOCX), PowerPoint (PPT, PPTX), Excel (XLS, XLSX), formatos de LibreOffice y muchos otros.

:::


## Extraer metadatos de documentos {#extract-metadata-from-documents}

Para extraer metadatos de documentos, simplemente invoque el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>:

```csharp
IEnumerable<MetadataItem> GetMetadata();

```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem" target="_blank" rel="nofollow noopener noreferrer">MetadataItem</a> con los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> | El nombre del elemento de metadatos |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/metadataitem/properties/value" target="_blank" rel="nofollow noopener noreferrer">Value</a> | El valor del elemento de metadatos |

A continuación se indican los pasos para extraer los metadatos del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a> y obtener la colección de objetos de metadatos del documento;
*   Recorrer la colección y obtener los nombres y valores de los metadatos.

El siguiente ejemplo muestra cómo extraer los metadatos de un documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract metadata from the document
    IEnumerable<MetadataItem> metadata = parser.GetMetadata();
    // Check if metadata extraction is supported
    if (metadata == null)
    {
        Console.WriteLine("Metadata extraction isn't supported");
        return;
    }

    // Iterate over metadata items
    foreach (MetadataItem item in metadata)
    {
        // Print an item name and value
        Console.WriteLine(string.Format("{0}: {1}", item.Name, item.Value));
    }
}
```

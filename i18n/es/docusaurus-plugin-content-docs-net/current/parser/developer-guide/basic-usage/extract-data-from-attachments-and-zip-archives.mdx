Es sencillo extraer datos, texto e imágenes, así como utilizar cualquier función de GroupDocs.Parser para documentos archivados en formato ZIP. La misma funcionalidad permite obtener los archivos adjuntos de documentos PDF y correos electrónicos, y extraer datos de dichos adjuntos.

# Extraer datos desde archivos adjuntos y archivos ZIP

Para extraer documentos desde archivos ZIP y obtener los archivos adjuntos de contenedores, simplemente invoque el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a>:

```csharp
IEnumerable<ContainerItem> GetContainer()

```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem" target="_blank" rel="nofollow noopener noreferrer">ContainerItem</a>:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/name" target="_blank" rel="nofollow noopener noreferrer">Name</a> | El nombre del elemento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/directory" target="_blank" rel="nofollow noopener noreferrer">Directory</a> | El directorio del elemento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/filepath" target="_blank" rel="nofollow noopener noreferrer">FilePath</a> | La ruta completa del elemento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a> | El tamaño del elemento en bytes. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/properties/metadata" target="_blank" rel="nofollow noopener noreferrer">Metadata</a> | La colección de metadatos del elemento. |

| Parser <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/containeritem/methods/openparser" target="_blank" rel="nofollow noopener noreferrer">OpenParser()</a> | Crea el objeto Parser para el contenido del elemento. |
| Parser <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data.containeritem/openparser/methods/1" target="_blank" rel="nofollow noopener noreferrer">OpenParser(LoadOptions)</a> | Crea el objeto Parser para el contenido del elemento con <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. |

Container representa tanto archivos contenedor únicamente (como archivos zip o almacenamientos de Outlook) como documentos con adjuntos (como correos electrónicos o PDF Portfolios).

A continuación se indican los pasos para extraer el texto de un correo electrónico desde un almacenamiento de Outlook:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y obtener la colección de objetos de elementos contenedor del documento;
*   Verificar que la *colección* no sea *null* (la extracción de contenedor es compatible con el documento);
*   Iterar sobre la colección y obtener el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para extraer el texto.

El siguiente ejemplo muestra cómo extraer texto desde entidades zip:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract attachments from the container
    IEnumerable<ContainerItem> attachments = parser.GetContainer();
    // Check if container extraction is supported
    if (attachments == null)
    {
        Console.WriteLine("Container extraction isn't supported");
    }
    // Iterate over zip entities
    foreach (ContainerItem item in attachments)
    {
        // Print the file path
        Console.WriteLine(item.FilePath);
        try
        {
            // Create Parser object for the zip entity content
            using (Parser attachmentParser = item.OpenParser())
            {
                // Extract a zip entity text
                using (TextReader reader = attachmentParser.GetText())
                {
                    Console.WriteLine(reader == null ? "No text" : reader.ReadToEnd());
                }
            }
        }
        catch (UnsupportedDocumentFormatException)
        {
            Console.WriteLine("Isn't supported.");
        }
    }
}
```

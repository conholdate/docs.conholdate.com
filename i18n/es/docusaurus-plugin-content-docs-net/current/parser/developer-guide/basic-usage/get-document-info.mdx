GroupDocs.Parser proporciona la funcionalidad para obtener la información básica del documento mediante <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo</a> método:

```csharp
IDocumentInfo GetDocumentInfo();

```

La interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo" target="_blank" rel="nofollow noopener noreferrer">IDocumentInfo</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> | El tipo de documento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> | El número total de páginas del documento. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a> | El tamaño del documento en bytes. |

A continuación se indican los pasos para obtener la información del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo</a> y obtener el objeto con la interfaz <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo" target="_blank" rel="nofollow noopener noreferrer">IDocumentInfo</a>;
*   Llamar a propiedades como <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> o <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">Size</a>.

El siguiente ejemplo muestra cómo obtener la información del documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Get the document info
    IDocumentInfo info = parser.GetDocumentInfo();
    
    // Print document information
    Console.WriteLine($"File Type: {info.FileType}");
    Console.WriteLine($"Page Count: {info.PageCount}");
    Console.WriteLine($"File Size: {info.Size} bytes");
}
```

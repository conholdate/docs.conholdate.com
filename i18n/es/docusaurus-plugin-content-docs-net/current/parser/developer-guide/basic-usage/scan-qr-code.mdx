GroupDocs.Parser para .NET permite escanear códigos QR en archivos PDF, documentos de Microsoft Word (DOC, DOCX), presentaciones de Microsoft PowerPoint (PPT, PPTX), formatos de LibreOffice y muchos otros (consulte la lista completa en el artículo [formatos de documento admitidos](/net/parser/getting-started/supported-document-formats/)).

El escáner de códigos QR de GroupDocs.Parser es fácil de usar y, al mismo tiempo, muy potente. Nuestros algoritmos sofisticados permiten leer incluso códigos de barras dañados.

Este artículo muestra cómo implementar un lector de códigos QR para cualquier formato admitido. 

## Cómo escanear un código QR en .NET con GroupDocs.Parser {#how-to-scan-qr-code-in-net-with-groupdocs-parser}

Para escanear un código QR desde su archivo, simplemente invoque el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a>:

```csharp
IEnumerable<PageBarcodeArea> GetBarcodes();
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>.

A continuación se indican los pasos para extraer un código QR desde un archivo:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el archivo inicial;
- Comprobar si el archivo admite la extracción de códigos de barras;
- Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>;
- Recorrer la colección y obtener el valor del código de barras.

El siguiente ejemplo muestra cómo escanear un código de barras:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(Constants.SamplePdfWithBarcodes))
{
    // Check if the file supports barcodes extraction
    if (!parser.Features.Barcodes)
    {
        Console.WriteLine("The file doesn't support barcodes extraction.");
        return;
    }

    // Scan barcodes with type "QR" from your file.
    IEnumerable<PageBarcodeArea> qrcodes = parser.GetBarcodes().Where(i => i.CodeTypeName == "QR");

    // Iterate over barcodes
    foreach (PageBarcodeArea qrcode in qrcodes)
    {
        // Print the page index
        Console.WriteLine("Page: " + qrcode.Page.Index.ToString());
        // Print the qrcode value
        Console.WriteLine("Value: " + qrcode.Value);
    }
}
```

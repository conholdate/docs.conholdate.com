GroupDocs.Parser permite obtener la lista de todos los formatos de archivo admitidos por <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> método estático:

```csharp
IEnumerable<FileType> FileType.GetSupportedFileTypes();

```

Este método devuelve una colección de elementos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> con los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> | Nombre del tipo de archivo, por ejemplo, "Documento de Microsoft Word". |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/extension" target="_blank" rel="nofollow noopener noreferrer">Extension</a> | Sufijo del nombre de archivo (incluido el punto ".") por ejemplo, ".doc". |

Además, <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> contiene campos estáticos que representan todos los formatos de archivo admitidos.

A continuación se indican los pasos para obtener todos los formatos de archivo admitidos:

*   Llamar al método estático <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> y obtener una colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>;
*   Recorrer la colección y obtener <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/fileformat" target="_blank" rel="nofollow noopener noreferrer">FileFormat</a> o <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype/properties/extension" target="_blank" rel="nofollow noopener noreferrer">Extension</a> de <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente ejemplo muestra cómo imprimir todos los tipos de archivo admitidos:

```csharp
IEnumerable<FileType> supportedFileTypes = FileType.GetSupportedFileTypes();

foreach (FileType fileType in supportedFileTypes)
{
    Console.WriteLine(fileType);
}

```

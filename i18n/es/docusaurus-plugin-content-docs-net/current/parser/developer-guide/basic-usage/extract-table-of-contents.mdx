GroupDocs.Parser permite extraer la tabla de contenidos de documentos de Microsoft Word (DOC, DOCX, etc.), documentos PDF y libros electrónicos.

## Extraer tabla de contenidos {#extract-table-of-contents}

Para extraer la tabla de contenidos de los documentos, utilice el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a>:

```csharp
IEnumerable<TocItem> GetToc()

```

La clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/depth" target="_blank" rel="nofollow noopener noreferrer">Depth</a> | El nivel de profundidad. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/pageindex" target="_blank" rel="nofollow noopener noreferrer">PageIndex</a> | El índice de página. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El texto. |
| TextReader <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem/methods/extracttext" target="_blank" rel="nofollow noopener noreferrer">ExtractText()</a> | Extrae texto del documento al que hace referencia el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a>. Para más detalles, consulte [Extraer texto mediante un elemento del índice](/net/parser/developer-guide/advanced-usage/working-with-text/extract-text-by-table-of-contents-item/) |

A continuación se indican los pasos para extraer el índice del documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.data/tocitem" target="_blank" rel="nofollow noopener noreferrer">TocItem</a>;
*   Verificar que la *colección* no sea *nula* (la extracción del índice está admitida para el documento);
*   Iterar a través de la colección y obtener el índice de página para extraer el texto de dicha página del documento.

El siguiente ejemplo muestra cómo extraer el índice de un archivo CHM:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if text extraction is supported
    if (!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported.");
        return;
    }
    // Check if toc extraction is supported
    if (!parser.Features.Toc)
    {
        Console.WriteLine("Toc extraction isn't supported.");
        return;
    }
    // Get table of contents
    IEnumerable<TocItem> toc = parser.GetToc();
    // Iterate over items
    foreach (TocItem i in toc)
    {
        // Print the Toc text
        Console.WriteLine(i.Text);
        // Check if page index has a value
        if (i.PageIndex == null)
        {
            continue;
        }
        // Extract a page text
        using (TextReader reader = parser.GetText(i.PageIndex.Value))
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}

```

GroupDocs.Parser para .NET permite escanear códigos de barras desde archivos PDF, formatos de Microsoft Office: Word (DOC, DOCX), PowerPoint (PPT, PPTX), formatos de LibreOffice y muchos otros (consulte la lista completa en el artículo [formatos de documento admitidos](/net/parser/getting-started/supported-document-formats/)).

El escáner de códigos de barras de GroupDocs.Parser es fácil de usar y potente al mismo tiempo. Nuestra experiencia nos ha permitido implementar algoritmos sofisticados que permiten leer incluso códigos de barras dañados.

Este artículo demuestra cómo implementar el escenario más simple: leer un código de barras desde cualquier formato admitido sin configuraciones adicionales (para resolver escenarios complejos, consulte la [sección de uso avanzado](/net/parser/developer-guide/advanced-usage/working-with-barcodes/)). 

## Cómo escanear un código de barras en .NET con GroupDocs.Parser {#how-to-scan-barcode-in-net-with-groupdocs-parser}

Para escanear un código de barras desde su archivo, simplemente invoque el método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a>:

```csharp
IEnumerable<PageBarcodeArea> GetBarcodes();
```

Este método devuelve una colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>.

A continuación se indican los pasos para extraer un código de barras de un archivo:

- Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el archivo inicial;
- Verificar si el archivo admite la extracción de códigos de barras;
- Llamar al método <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser/parser/methods/getbarcodes" target="_blank" rel="nofollow noopener noreferrer">GetBarcodes</a> y obtener la colección de objetos <a href="https://reference.groupdocs.com/parser/net/groupdocs.parser.data/pagebarcodearea" target="_blank" rel="nofollow noopener noreferrer">PageBarcodeArea</a>;
- Iterar a través de la colección y obtener el valor del código de barras.

El siguiente ejemplo muestra cómo escanear códigos de barras:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Check if the file supports barcode extraction
    if (!parser.Features.Barcodes)
    {
        Console.WriteLine("The file doesn't support barcode extraction.");
        return;
    }

    // Scan barcodes from the file
    IEnumerable<PageBarcodeArea> barcodes = parser.GetBarcodes();
    
    // Iterate over barcodes
    foreach (PageBarcodeArea barcode in barcodes)
    {
        // Print a barcode value
        Console.WriteLine(barcode.Value);
    }
}
```

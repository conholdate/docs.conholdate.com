GroupDocs.Parser permite extraer texto de archivos PDF, correos electrónicos, libros electrónicos y formatos de Microsoft Office: Word (DOC, DOCX), PowerPoint (PPT, PPTX), Excel (XLS, XLSX), así como formatos de LibreOffice y muchos otros (consulte la lista completa en el artículo [formatos de documentos admitidos](/net/parser/getting-started/supported-document-formats/)).

El extractor de texto de GroupDocs.Parser es fácil de usar y, al mismo tiempo, potente (para resolver escenarios complejos, consulte la [sección de uso avanzado](/net/parser/developer-guide/advanced-usage/working-with-text/)).

Este artículo demuestra cómo implementar el escenario más simple: extraer texto de cualquier formato admitido sin configuraciones adicionales.

## Extraer texto de documentos {#extract-text-from-documents}

Para extraer texto de documentos, simplemente invoque el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a>:

```csharp
TextReader GetText();


```

Los métodos devuelven una instancia de la clase <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a> con el texto extraído. 

A continuación se indican los pasos para extraer el texto de un documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Leer el texto desde *reader*.

El siguiente ejemplo muestra cómo extraer el texto de un documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract a text into the reader
    using (TextReader reader = parser.GetText())
    {
        // Print a text from the document
        // If text extraction isn't supported, reader is null
        Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

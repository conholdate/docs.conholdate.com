El conjunto de características admitidas depende del formato del documento. GroupDocs.Parser proporciona la funcionalidad para comprobar si una característica es compatible con el documento. La propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/properties/features" target="_blank" rel="nofollow noopener noreferrer">Features</a> se utiliza para este propósito.

<a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features" target="_blank" rel="nofollow noopener noreferrer">Features</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| bool <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/methods/isfeaturesupported" target="_blank" rel="nofollow noopener noreferrer">IsFeatureSupported(string featureName)</a> | Devuelve un valor que indica si la **característica** es compatible. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> | El valor que indica si se admite la **extracción de texto**. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/textpage" target="_blank" rel="nofollow noopener noreferrer">TextPage</a> | El valor que indica si se admite la **extracción de texto por página**. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/formattedtext" target="_blank" rel="nofollow noopener noreferrer">FormattedText</a> | El valor que indica si se admite la **extracción de texto con formato**. |
| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/formattedtextpage" target="_blank" rel="nofollow noopener noreferrer">FormattedTextPage</a> | El valor que indica si se admite la **extracción de texto con formato por página**. |

| <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/features/properties/highlight" target="_blank" rel="nofollow noopener noreferrer">Highlight</a> | El valor que indica si se admite la **extracción de resaltados**. |

A continuación se indican los pasos para comprobar si una característica es compatible:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Llamar a la propiedad correspondiente de <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/properties/features" target="_blank" rel="nofollow noopener noreferrer">Feature</a> para comprobar si la característica es compatible.

El siguiente ejemplo muestra cómo comprobar si la característica de extracción de texto es compatible:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser("doc.zip"))
{
    // Check if text extraction is supported for the document
    if(!parser.Features.Text)
    {
        Console.WriteLine("Text extraction isn't supported");
        return;
    }

    // Extract a text from the document
    using(TextReader reader = parser.GetText())
    {
        Console.WriteLine(reader.ReadToEnd());
    }
}
```

Si la característica no es compatible, el método devuelve `null` en lugar del valor. Por lo tanto, si se omite la comprobación de las propiedades <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/properties/features" target="_blank" rel="nofollow noopener noreferrer">Features</a>, el resultado se verifica como *null*:

```csharp
// Create an instance of Parser class
using(Parser parser = new Parser("doc.zip"))
{
    // Extract a text from the document 
    using(TextReader reader = parser.GetText())
    {
        // Check if reader isn't null
        if(reader == null)
        {
            Console.WriteLine("Text extraction isn't supported");
        }
        else
        {
            Console.WriteLine(reader.ReadToEnd());
        }
    }
}

```

Este ejemplo imprime "La extracción de texto no es compatible" porque no hay texto en el archivo ZIP.

Algunas operaciones pueden consumir un tiempo considerable. Por lo tanto, no es óptimo llamar al método únicamente para verificar si la función es compatible. Para este propósito se utiliza la propiedad <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/properties/features" target="_blank" rel="nofollow noopener noreferrer">Features</a>.

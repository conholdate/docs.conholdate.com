GroupDocs.Parser permite extraer texto con formato de documentos en aquellos casos en los que un texto simple no es suficiente y es necesario conservar el formato, como el estilo del texto, el diseño de tablas, etc.

Esta función permite extraer texto con etiquetas HTML integradas o sintaxis Markdown. Incluso el modo PlainText permite convertir sus documentos en texto de alta calidad con símbolos de formato ASCII integrados para tablas, listas, etc.

## Extraer texto con formato de documentos {#extract-formatted-text-from-documents}

Para extraer texto con formato de documentos, simplemente llame al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText</a>:

```csharp
TextReader GetFormattedText(FormattedTextOptions options);

```

Los métodos devuelven una instancia de <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">Lector de texto</a> Clase con un texto extraído. <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> tiene el siguiente constructor:

```csharp
FormattedTextOptions(FormattedTextMode mode)

```

La enumeración <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextmode" target="_blank" rel="nofollow noopener noreferrer">FormattedTextMode</a> tiene los siguientes miembros:

| Miembro | Descripción |
| --- | --- |
| Html | Formato HTML. |
| Markdown | Formato Markdown. |
| PlainText | Formato de texto sin formato. |

A continuación se indican los pasos para extraer texto con formato HTML desde un documento:

*   Instanciar un objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser" target="_blank" rel="nofollow noopener noreferrer">Parser</a> para el documento inicial;
*   Instanciar <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.options/formattedtextoptions" target="_blank" rel="nofollow noopener noreferrer">FormattedTextOptions</a> con modo de texto HTML;
*   Llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText</a> y obtener el objeto <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.textreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">TextReader</a>;
*   Comprobar si *reader* no es *null* (la extracción de texto con formato es compatible con el documento);
*   Leer el texto desde *reader*.

El siguiente ejemplo muestra cómo extraer texto con formato desde un documento:

```csharp
// Create an instance of Parser class
using (Parser parser = new Parser(filePath))
{
    // Extract formatted text as HTML
    using (TextReader reader = parser.GetFormattedText(new FormattedTextOptions(FormattedTextMode.Html)))
    {
        // If formatted text extraction isn't supported, reader is null
        Console.WriteLine(reader == null ? "Formatted text extraction isn't supported" : reader.ReadToEnd());
    }
}
```

## Limitaciones de la versión de evaluación {#evaluation-limitations}

  
Puede descargar fácilmente GroupDocs.Parser para evaluación. La versión de evaluación descargada es idéntica a la versión adquirida. La versión de evaluación simplemente se convierte en una versión con licencia cuando agrega algunas líneas de código para aplicar la licencia. Al utilizar la API sin licencia, se enfrentará a las siguientes limitaciones:    
  

| API | Limitación |
| --- | --- |
|  | Solo 100 archivos por sesión |
|  | Solo 5 páginas (diapositivas, hojas) de un documento |
| **Extracción de texto** | Solo 20 líneas por archivo<br/>Solo los primeros 1600 símbolos<br/>Solo las primeras 5 páginas (diapositivas, hojas)<br/>\+ Marcas de evaluación |
| **Extracción de texto con formato y estructura de texto** | Solo 20 filas para **hojas de cálculo**<br/>Solo los primeros 1600 símbolos<br/>Solo las primeras 5 páginas (diapositivas, hojas)<br/>\+ Marcas de evaluación |
| **Extracción de metadatos** | Solo 5 propiedades por archivo |

## Licencias {#licensing}

El archivo de licencia contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, entre otros. Contiene una firma digital, por lo que no debe modificar el archivo. Incluso la adición accidental de una línea adicional en el archivo invalidará su validez. Debe establecer una licencia antes de utilizar la API de GroupDocs.Parser si desea evitar sus limitaciones de evaluación.  
La licencia puede cargarse desde un archivo o un objeto de flujo (stream). La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el archivo GroupDocs.Parser.dll y especificar el nombre del archivo, sin ruta de acceso, como se muestra en los ejemplos a continuación.

#### Establecer licencia desde un archivo {#setting-license-from-file}

El siguiente código explica cómo establecer la licencia del producto.  
  

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-parser/GroupDocs.Parser-for-.NET
// Setup license.
License license = new License();
license.SetLicense(licensePath);
```

#### Establecer licencia desde un flujo {#setting-license-from-stream}

El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.  
  

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-parser/GroupDocs.Parser-for-.NET
using (FileStream fileStream = File.OpenRead("GroupDocs.Parser.lic"))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```

:::info
Llamar a <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.license/setlicense/methods/1" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense(String)</a> varias veces no es perjudicial, pero simplemente desperdicia tiempo de procesador. Si está desarrollando una aplicación de Windows Forms o una aplicación de consola, llame a <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.license/setlicense/methods/1" target="_blank" rel="nofollow noopener noreferrer">License.SetLicense(String)</a> en su código de inicio, antes de utilizar las clases de GroupDocs.Parser.
:::

#### Configuración de licencia basada en uso {#setting-metered-license}

:::info
También puede configurar una licencia medible como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean ser facturados según el uso de las características de la API. Para obtener más detalles, consulte la sección de preguntas frecuentes sobre licencias medibles.
:::



:::warning
Una licencia basada en medición requiere conectividad de red. La clave se valida al llamar a <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered/methods/setmeteredkey" target="_blank" rel="nofollow noopener noreferrer">SetMeteredKey</a>, y los datos de consumo se cargan periódicamente en el punto final de licencias posteriormente. Se transmite el volumen de uso, pero nunca el contenido de sus documentos. Si los datos de consumo no pueden cargarse durante más de 24 horas, la licencia vuelve al estado de evaluación; por lo tanto, una licencia basada en medición no es adecuada para implementaciones sin conexión (air-gapped). Consulte [Acceso a la red y privacidad de los datos](/net/parser/getting-started/network-access-and-data-privacy/).
:::

  
A continuación se presentan los pasos sencillos para utilizar la clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.
*       Create an instance of <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> class.
*       Pass public & private keys to <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered/methods/setmeteredkey" target="_blank" rel="nofollow noopener noreferrer">SetMeteredKey</a> method.
*       Do processing (perform task).
*       call method <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered/methods/getconsumptionquantity" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionQuantity</a> of the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> class.
*       It will return the amount/quantity of API requests that you have consumed so far.
*       call method <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered/methods/getconsumptioncredit" target="_blank" rel="nofollow noopener noreferrer">GetConsumptionCredit</a> of the <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> class.
*       It will return the credit that you have consumed so far.

  
A continuación se muestra un ejemplo de código que demuestra cómo utilizar la clase <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a>.

```csharp
// For complete examples and data files, please go to https://github.com/groupdocs-parser/GroupDocs.Parser-for-.NET
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Parser.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Parser.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

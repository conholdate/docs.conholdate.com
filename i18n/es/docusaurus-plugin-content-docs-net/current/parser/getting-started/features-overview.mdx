:::info
GroupDocs.Parser es una API de análisis de datos de documentos con muchas funcionalidades. Aquí puede encontrar la descripción de las características más importantes.
:::



## Extraer datos de documentos {#parse-data-from-documents}

GroupDocs.Parser permite extraer datos de documentos mediante plantillas definidas por el usuario.

Es sencillo crear una plantilla con definiciones de campos de datos y definiciones de tablas. Luego, resulta fácil utilizar dicha plantilla (simplemente pase el objeto <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser.templates/template" target="_blank" rel="nofollow noopener noreferrer">Template</a> al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/parsebytemplate" target="_blank" rel="nofollow noopener noreferrer">ParseByTemplate</a>) y extraer datos como precios, facturas y tablas de sus documentos típicos.

## Extraer texto {#extract-text}

GroupDocs.Parser proporciona varios métodos de extracción de texto que cubren diversas situaciones de recuperación de texto.

*   Extraer texto sin formato de cualquier documento admitido;
*   Extraer texto con formato HTML o Markdown para una vista previa rápida;
*   Extraer texto estructurado;
*   Extraer áreas de texto con coordenadas, estilo de texto y otra información;
*   Buscar texto mediante una palabra clave o una expresión regular; obtener el texto circundante de la palabra encontrada.

A continuación se describen distintos aspectos de la extracción de texto:

### Modo de extracción de texto preciso {#accurate-text-extraction-mode}

Una de las características más demandadas es la extracción precisa de texto. GroupDocs.Parser permite implementarla fácilmente mediante el método simple <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettext" target="_blank" rel="nofollow noopener noreferrer">GetText</a>.

### Modo de extracción de texto en bruto (Raw) {#raw-text-extraction-mode}

GroupDocs.Parser ofrece una forma de mejorar el rendimiento de la extracción de texto mediante el modo **Raw** (en bruto) para algunos formatos. El texto no se ve tan preciso, pero el rendimiento es mayor.

Esta característica resulta útil en escenarios de extracción de texto en los que la calidad del texto no es prioritaria, pero el rendimiento sí lo es.

### Extraer texto con formato {#extract-formatted-text}

Además de los modos estándar de extracción de texto, la API de GroupDocs.Parser proporciona el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getformattedtext" target="_blank" rel="nofollow noopener noreferrer">GetFormattedText(FormattedTextOptions)</a> para extraer texto con formato en aquellos casos en los que un texto sin formato simple no es suficiente y es necesario conservar el formato, como el estilo del texto, el diseño de tablas, etc.

En este momento, los siguientes formatos están admitidos:

*   Texto sin formato
*   Markdown
*   HTML

#### Texto sin formato {#plain-text}

Con el modo Texto sin formato, GroupDocs.Parser aplica formato al texto plano para que el texto extraído se parezca más al original. Esto se logra mediante una posición especial del texto y caracteres de dibujo de cajas, entre otros.

#### Markdown {#markdown}

Este modo resulta útil cuando necesita exportar el texto extraído a cualquier sistema que admita texto con formato <a href="https://en.wikipedia.org/wiki/Markdown" target="_blank" rel="nofollow noopener noreferrer">Markdown</a>.

En este momento, se admiten los siguientes formatos:

*   Texto en negrita
*   Texto en cursiva
*   Hipervínculos
*   Encabezados
*   Listas numeradas y con viñetas
*   Tablas

#### HTML {#html}

GroupDocs.Parser también admite el formato HTML.

Actualmente, se admiten las siguientes etiquetas HTML al extraer texto con este modo de formato:

| Etiqueta | Descripción |
| --- | --- |
| `<p>` | El párrafo está rodeado por la etiqueta `<p>` |
| `<a>` | Hipervínculos |
| `<b>` | El texto en negrita está rodeado por la etiqueta `<b>` |
| `<i>` | El texto en cursiva está rodeado por la etiqueta `<i>` |
| `<h1>` - `<h6>` | Si el encabezado tiene el estilo «Encabezado X», está rodeado por la etiqueta `<hX>` |
| `<ol>`/`` | Listas numeradas y con viñetas |
| `<table>` | Tablas |

### Extraer texto estructurado {#extract-structured-text}

Muchos formatos de documento no contienen únicamente texto. Por lo general, el texto puede organizarse en párrafos divididos en secciones con encabezados. Además, el texto puede contener hipervínculos, listas y tablas. Para este escenario, GroupDocs.Parser proporciona la extracción de texto estructurado con la capacidad de extraer el texto junto con su estructura. Esta característica es fácil de usar: simplemente llame al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getstructure" target="_blank" rel="nofollow noopener noreferrer">GetStructure</a>, que devuelve un <a href="https://docs.microsoft.com/en-us/dotnet/api/system.xml.xmlreader?view=netframework-2.0" target="_blank" rel="nofollow noopener noreferrer">XmlReader</a> con el texto estructurado en formato XML.

### Extraer áreas de texto {#extract-text-areas}

GroupDocs.Parser proporciona una API que permite extraer áreas de texto con coordenadas y estilo de texto.

Esta característica permite implementar escenarios avanzados relacionados con el análisis de texto en sus aplicaciones. Simplemente llame al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettextareas" target="_blank" rel="nofollow noopener noreferrer">GetTextAreas</a> y obtendrá todos los objetos de área de texto.

### Buscar texto en documentos {#search-text-in-documents}

GroupDocs.Parser permite realizar búsquedas en el documento cargado mediante palabras clave o expresiones regulares. Utilice el método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/search" target="_blank" rel="nofollow noopener noreferrer">Search(String)</a> y luego recorra la colección de resultados de la búsqueda.

## Extraer metadatos {#extract-metadata}

GroupDocs.Parser proporciona una API que permite extraer metadatos de formatos de documento admitidos mediante una simple llamada al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getmetadata" target="_blank" rel="nofollow noopener noreferrer">GetMetadata</a>.

## Extraer imágenes {#extract-images}

GroupDocs.Parser admite la extracción de imágenes de documentos. Puede llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getimages" target="_blank" rel="nofollow noopener noreferrer">GetImages</a>, que devuelve toda la información sobre las imágenes del documento y permite guardarlas.

## Extraer datos de archivos adjuntos y archivos ZIP {#extract-data-from-attachments-and-zip-archives}

GroupDocs.Parser permite extraer datos (texto, imágenes y otros métodos de extracción admitidos) de formatos que contienen otros documentos, como archivos ZIP, portafolios de PDF, correos electrónicos y contenedores OST.

Simplemente puede llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/getcontainer" target="_blank" rel="nofollow noopener noreferrer">GetContainer</a> y trabajar con los documentos adjuntos o archivados extraídos como si fueran archivos de documento normales.

## Extraer datos de formularios {#parse-form-data}

GroupDocs.Parser proporciona la funcionalidad para extraer datos de formularios de documentos PDF. Puede llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/parseform" target="_blank" rel="nofollow noopener noreferrer">ParseForm</a> e iterar a través de los campos de formulario extraídos.

## Extraer tabla de contenidos {#extract-table-of-contents}

GroupDocs.Parser permite extraer la tabla de contenidos de algunos formatos de documento. Para ello, puede llamar al método <a href="https://reference.groupdocs.com/net/parser/groupdocs.parser/parser/methods/gettoc" target="_blank" rel="nofollow noopener noreferrer">GetToc</a>.

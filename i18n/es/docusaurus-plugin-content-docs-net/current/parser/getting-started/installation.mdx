## Requisitos previos {#prerequisites}

### Requisitos del framework {#framework-requirements}

GroupDocs.Parser para .NET admite los siguientes frameworks:

| Framework | Versión mínima | Paquete |
| ----------- | ---------------- | --------- |
| .NET Framework | 4.6.1 | `GroupDocs.Parser.Framework` |
| .NET Core | 2.0 | `GroupDocs.Parser` |
| .NET Standard | 2.0 | `GroupDocs.Parser` |
| .NET | 5.0 o superior | `GroupDocs.Parser` |


:::info
**Para .NET Framework 4.5 y versiones anteriores:** Debe actualizar a .NET Framework 4.6.1 o una versión superior, o bien dirigirse a paquetes compatibles con .NET Standard 2.0. GroupDocs.Parser requiere compatibilidad con .NET Standard 2.0.
:::


## Instalación desde NuGet {#install-from-nuget}

NuGet es la forma más sencilla de descargar e instalar GroupDocs.Parser para .NET. Existen múltiples formas de instalarlo en su proyecto.

#### Instalación mediante la interfaz gráfica del Administrador de paquetes {#install-via-package-manager-gui}

Siga estos pasos para hacer referencia a GroupDocs.Parser mediante la interfaz gráfica del Administrador de paquetes:

*   Abra su solución/proyecto en Visual Studio.
*   Haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Administrar paquetes NuGet para la solución**.  
    You can also access the same option through the Solution Explorer. Right-click the solution or project and select Manage NuGet Packages from the context menu
*   Seleccione la pestaña **Browse** y escriba «GroupDocs.Parser» en el cuadro de texto de búsqueda.
*   Haga clic en el botón **Install** para instalar la versión más reciente de la API en su proyecto, como se muestra en la siguiente captura de pantalla.

![](/net/parser/images/installation.png)

#### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}

Puede seguir los pasos que se indican a continuación para hacer referencia a GroupDocs.Parser para .NET mediante la Consola del Administrador de Paquetes:

*   Abra su solución/proyecto en Visual Studio.
*   Seleccione **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de paquetes** en el menú para abrir la consola del administrador de paquetes.
*   Escriba el comando según su marco de trabajo objetivo:
    - For .NET Core/.NET 5+: `Install-Package GroupDocs.Parser`
    - For .NET Framework: `Install-Package GroupDocs.Parser.Framework`
*   Presione Enter para instalar la última versión en su aplicación.
*   Tras la instalación correcta, GroupDocs.Parser se referenciará en su aplicación.

#### Uso de .NET CLI (.NET Core/.NET 5+) {#using-net-cli-net-core-net-5}

Para proyectos de .NET Core, .NET 5, .NET 6 o versiones posteriores:

```bash
# Create a new console project
dotnet new console -n MyParserApp
cd MyParserApp

# Add the package
dotnet add package GroupDocs.Parser

# Restore packages
dotnet restore
```

#### Inicio rápido con .NET Core {#quick-start-with-net-core}

A continuación se presenta un ejemplo completo para configurar un proyecto de .NET Core:

```bash
# 1. Create new project
dotnet new console -n GroupDocsParserDemo
cd GroupDocsParserDemo

# 2. Install package
dotnet add package GroupDocs.Parser

# 3. Run the project
dotnet run
```

Luego, actualice `Program.cs`:

```csharp
using GroupDocs.Parser;

namespace GroupDocsParserDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            using (Parser parser = new Parser("sample.pdf"))
            {
                using (var reader = parser.GetText())
                {
                    if (reader != null)
                    {
                        Console.WriteLine(reader.ReadToEnd());
                    }
                }
            }
        }
    }
}
```

A partir de la versión 24.2, GroupDocs.Parser se divide en dos paquetes: uno para .NET Framework y otro para .NET Standard. El paquete GroupDocs.Parser para .NET Framework se recomienda utilizarlo en proyectos .NET Framework. El paquete GroupDocs.Parser está diseñado para funcionar con proyectos .NET. Es necesario <a href="https://stackoverflow.com/questions/43365736/assembly-binding-redirect-how-and-why" target="_blank" rel="nofollow noopener noreferrer">configurar la redirección de enlaces</a> para que funcione con .NET Framework. En el caso de un proyecto .NET Framework habitual, es necesario <a href="https://learn.microsoft.com/en-us/dotnet/framework/configure-apps/how-to-enable-and-disable-automatic-binding-redirection" target="_blank" rel="nofollow noopener noreferrer">habilitar la redirección automática de enlaces</a>. En proyectos de pruebas unitarias, también es necesario especificar `GenerateBindingRedirectsOutputType` en el archivo del proyecto:

```
<PropertyGroup>
    <AutoGenerateBindingRedirects>true</AutoGenerateBindingRedirects>
    <GenerateBindingRedirectsOutputType>true</GenerateBindingRedirectsOutputType>
</PropertyGroup>
```

## Instalación desde el sitio web oficial de GroupDocs {#install-from-official-groupdocs-website}

Puede seguir los pasos que se indican a continuación para hacer referencia a GroupDocs.Parser para .NET descargado desde la sección de descargas del sitio web oficial:

*   Descomprima el archivo ZIP o siga las instrucciones del asistente de instalación MSI.
*   En el Explorador de soluciones, expanda el nodo del proyecto al que desea agregar una referencia.
*   Haga clic con el botón derecho en el nodo Referencias del proyecto y seleccione Agregar referencia en el menú.
*   En el cuadro de diálogo Agregar referencia, seleccione la pestaña .NET (normalmente ya está seleccionada de forma predeterminada).
*   Si ha utilizado el instalador MSI para instalar GroupDocs.Parser, verá GroupDocs.Parser en el panel superior. Selecciónelo y haga clic en el botón Seleccionar.
*   Si ha descargado y descomprimido únicamente el archivo DLL, haga clic en el botón Examinar y localice el archivo GroupDocs.Parser.dll.
*   Ha referenciado GroupDocs.Parser y este debería aparecer en el panel Componentes seleccionados del cuadro de diálogo.
*   Haga clic en Aceptar.

La referencia a GroupDocs.Parser aparece bajo el nodo Referencias del proyecto.

## Entorno Linux {#linux-environment}

Para que GroupDocs.Parser.Net funcione correctamente en Linux, es necesario instalar los siguientes paquetes:

* Paquete libgdiplus
* Paquete libc6-dev
* Paquete con fuentes compatibles con Microsoft: ttf-mscorefonts-installer (por ejemplo: sudo apt-get install ttf-mscorefonts-installer)

Además, GroupDocs.Parser.Net en entornos Linux tiene la siguiente referencia externa:

| Paquete | Versión |
| --- | --- |
| SkiaSharp.NativeAssets.Linux.NoDependencies | 2.80.2 |

## Visión general {#overview}

GroupDocs.Parser para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/parser/getting-started/installation/).

No es necesario tener una conexión a Internet para ejecutar GroupDocs.Parser ni para validar una licencia. Sin embargo, tenga en cuenta que los documentos que hagan referencia a imágenes o hojas de estilo remotas pueden generar solicitudes salientes durante la extracción; consulte [Acceso a la red y privacidad de los datos](/net/parser/getting-started/network-access-and-data-privacy/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Parser para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado el framework .NET o Mono, incluidos, entre otros:

### Windows {#windows}

*   Microsoft Windows Server 2003 (x64, x86)
*   Microsoft Windows Server 2008 (x64, x86)
*   Microsoft Windows Server 2012 (x64, x86)
*   Microsoft Windows Server 2012 R2 (x64, x86)
*   Microsoft Windows Server 2016 (x64, x86)
*   Microsoft Windows Server 2019 (x64, x86)
*   Microsoft Windows Vista (x64, x86)
*   Microsoft Windows XP (x64, x86)
*   Microsoft Windows 7 (x64, x86)
*   Microsoft Windows 8, 8.1 (x64, x86)
*   Microsoft Windows 10 (x64, x86)
*   Microsoft Azure

### Linux {#linux}

*   Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac {#mac}

*   Mac OS X

## Frameworks compatibles {#supported-frameworks}

GroupDocs.Parser para .NET es compatible con los frameworks .NET y Mono, según se indica a continuación:

### .NET Standard 2.0 {#net-standard-2-0}

Se admite cualquier tipo de aplicación .NET Standard 2.0.

### Frameworks .NET {#net-frameworks}

*   .NET Framework 4.6.1 o superior (recomendado)
*   .NET Core 2.0 o superior
*   .NET Standard 2.0 o superior
*   .NET 5.0 o superior
*   .NET 6.0 o superior
*   .NET 7.0 o superior
*   .NET 8.0 o superior


:::info
**Nota:** Para .NET Framework 4.5 y versiones anteriores, debe dirigirse a paquetes compatibles con .NET Standard 2.0. La versión mínima recomendada es .NET Framework 4.6.1.
:::


### Marco de trabajo Mono {#mono-framework}

*   Mono 2.6.7 o posterior

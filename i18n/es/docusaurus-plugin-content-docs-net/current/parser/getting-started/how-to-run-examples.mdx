:::warning
Antes de ejecutar un ejemplo, asegúrese de que GroupDocs.Parser se haya instalado correctamente.
:::


Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de GroupDocs.Parser, ya sea construyendo su propio proyecto o utilizando directamente nuestros ejemplos listos para usar.

Elija una opción de la siguiente lista:


## Construir proyecto desde cero {#build-project-from-scratch}

*   Abra Visual Studio y vaya a **Archivo** -> **Nuevo** \-> **Proyecto**;
*   Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.;
*   Instale **GroupDocs.Parser para .NET** desde NuGet o desde el sitio web oficial de GroupDocs siguiendo esta [guía](/net/parser/getting-started/installation/);
*   Escriba su primera aplicación con **GroupDocs.Parser para .NET**, como se muestra a continuación:
    
    ```csharp
    // Create an instance of Parser class
    using (Parser parser = new Parser("c:\\documents\\sample.docx")) // NOTE: Put here actual path for your document
    {
        // Extract a text to the reader
        using (TextReader reader = parser.GetText())
        {
            // Print an extracted text (or "not supported" message)
            Console.WriteLine(reader == null ? "Text extraction isn't supported" : reader.ReadToEnd());
        }
    }
    ```
    

*   Compila y ejecuta tu proyecto;
*   El texto extraído aparecerá en la consola.

## Ejecutar ejemplos {#run-examples}

El paquete completo de ejemplos de **GroupDocs.Parser** está alojado en <a href="https://github.com/groupdocs-parser/GroupDocs.Parser-for-.NET/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puedes descargar el archivo ZIP desde <a href="https://github.com/groupdocs-parser/GroupDocs.Parser-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando tu cliente de Git favorito.  
Si descargas el archivo ZIP, extrae las carpetas en tu disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![](/net/parser/images/how-to-run-examples.png)

En los archivos y carpetas extraídos, puede encontrar el archivo de solución de C#. El proyecto se creó con **Microsoft Visual Studio 2019**. La carpeta **Resources** contiene todos los archivos de documentos e imágenes de ejemplo utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias faltantes de **GroupDocs.Parser**, consulte [Entorno de desarrollo, instalación y configuración](/net/parser/getting-started/installation/). Todas las funciones se invocan desde **RunExamples.cs**.
Descomente la función que desea ejecutar y comente el resto.

![](/net/parser/images/how-to-run-examples_1.png)

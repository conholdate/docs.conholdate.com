**Bienvenido a Aspose.Tasks para .NET**

Aspose.Tasks para .NET es una biblioteca de clases multiplataforma que permite a las aplicaciones .NET leer y escribir archivos MPP/XML sin necesidad de utilizar el software Microsoft Project. Actualmente, es el único componente .NET que ofrece esta funcionalidad. Aspose.Tasks para .NET es un producto maduro que permite a sus aplicaciones realizar una amplia gama de tareas de procesamiento de documentos con estabilidad y flexibilidad. Al igual que todos los componentes de gestión de archivos de Aspose, Aspose.Tasks para .NET funciona perfectamente tanto con aplicaciones de formularios de Windows (WinForms) como con aplicaciones WebForm.

Con Aspose.Tasks para .NET, es posible programar con archivos de Microsoft Project (MPP/XML) sin necesidad de utilizar Microsoft Project. El componente proporciona una API fácil de usar para manipular archivos de proyecto, lo que ahorra tiempo y dinero en comparación con el desarrollo de características similares desde cero.
:::

## Beneficios {#benefits}
  
Aspose.Tasks para .NET admite los formatos MPP, MPT, XML, XLSX, HTML, PDF, XAML y otros. Puede generar, modificar, convertir, representar e imprimir documentos sin necesidad de utilizar el software Microsoft Project. Utilizar Aspose.Tasks para .NET en sus aplicaciones le aporta las siguientes ventajas:

### Características avanzadas {#rich-features}
  
Aspose.Tasks ofrece una amplia gama de características para crear, leer, manipular y guardar archivos de proyecto:

- Leer, modificar y escribir documentos de Microsoft Project u Oracle Primavera: se admiten los formatos MPP/XML/P6XML.  
- Leer proyectos MPP y formatos de proyecto XML. Se admiten los formatos MPP de Microsoft Project 2003, 2007, 2010, 2013, 2016, 2019 y 2021.  
- Leer y escribir proyectos desde o hacia Project Server o Project Online mediante la API de PWA (Project Web Access).  
- Crear, actualizar y escribir proyectos en formato de proyecto XML.  
- Leer archivos de proyecto MPP, actualizar su información resumida y escribirlos en el formato MPP original.  
- Leer archivos de proyecto MPP y convertirlos al formato XML mediante Aspose.Tasks para .NET (el XML puede manipularse implementando un analizador XML personalizado).  
- Modificar la configuración principal del proyecto, como el tipo de planificación, fechas de inicio y finalización.  
- Modificar la configuración predeterminada del proyecto, como la tarifa estándar predeterminada, la tarifa de horas extra predeterminada, el tipo de tarea predeterminado, el método de acumulación de costos fijos predeterminado, etc.  
- Gestionar atributos extendidos.  
- Definir días laborables para el proyecto.  
- Definir días laborables para calendarios y excepciones de calendario.  
- Leer y escribir calendarios para tareas y recursos.  
- Gestionar la programación y duración de la línea base de las tareas.  
- Manejar restricciones en las tareas.  
- Crear y gestionar enlaces entre tareas.  
- Leer, modificar y crear tareas, hitos, tareas críticas estimadas o tareas impulsadas por esfuerzo.  
- Gestionar costos y desviaciones de recursos.  
- Acceder a costos y presupuestos de asignaciones.  
- Soporte para la codificación de archivos MPX.  
- Implementación de prefijos de recursos para recursos anidados.  
- Soporte para establecer prefijos CSS en la exportación a HTML.  
- Establecer formato de fecha personalizado al exportar a PDF.  
- Se admite la lectura de [información VBA](/net/tasks/reading-vba-information-from-mpp-file/) (referencias, módulos, atributos de módulo) desde archivos MPP.

### Independencia de plataforma {#platform-independence}
  
Utilice Aspose.Tasks para .NET para crear cualquier tipo de aplicación .NET de 32 o 64 bits, incluidas ASP.NET, WCF, WPF, servicios web y WinForms. Es posible utilizar Aspose.Tasks para .NET mediante COM Interop desde ASP, Perl, PHP y Python. También puede utilizar Aspose.Tasks para .NET para crear aplicaciones con Mono.

Aspose.Tasks para .NET admite:

- Visual Studio 2005  
- Visual Studio 2008  
- Visual Studio 2010  
- Visual Studio 2012  
- Visual Studio 2015  
- Visual Studio 2017  
- Visual Studio 2019  

### Rendimiento y escalabilidad {#performance-and-scalability}
  
Aspose.Tasks para .NET está diseñado para funcionar de forma óptima tanto en el lado del servidor como del cliente. Aspose.Tasks para .NET es un único ensamblado .NET que puede implementarse con cualquier aplicación .NET simplemente copiándolo. No es necesario preocuparse por otros servicios o módulos. Literalmente puede generar miles de documentos en cuestión de minutos con Aspose.Tasks, lo que implica abrir un documento, modificar su contenido y formato, rellenarlo con datos y guardarlo.

Aspose.Tasks está desarrollado de forma que solo un subproceso trabaje en un documento a la vez. Es un escenario típico tener un subproceso trabajando en un documento. Diferentes subprocesos pueden trabajar de forma segura en distintos documentos simultáneamente.

## Declaración {#declaration}
  
Todos los componentes de Aspose .NET requieren permiso de plena confianza (*Full Trust*). Esto se debe a que los componentes de Aspose .NET necesitan acceder a la configuración del registro, archivos del sistema (distintos de un directorio virtual) para ciertas operaciones, como analizar fuentes. Además, los componentes de Aspose .NET se basan en clases fundamentales del sistema .NET, que en muchos casos también requieren permiso de plena confianza.

Los proveedores de servicios de Internet que alojan múltiples aplicaciones de distintas empresas suelen imponer el nivel de seguridad de confianza media (*Medium Trust*). En el caso de .NET 2.0, este nivel de seguridad impone las siguientes restricciones:

- OleDbPermission no está disponible. Esto significa que no puede utilizar el proveedor de datos administrado OLE DB de ADO.NET para acceder a bases de datos.  
- EventLogPermission no está disponible. Esto significa que no puede acceder al registro de eventos de Windows.  
- ReflectionPermission no está disponible. Esto significa que no puede utilizar reflexión.  
- RegistryPermission no está disponible. Esto significa que no puede acceder al registro.  
- WebPermission está restringida. Esto significa que su aplicación solo puede comunicarse con una dirección o rango de direcciones que defina en el elemento.  
- FileIOPermission está restringida. Esto significa que solo puede acceder a archivos dentro de la jerarquía de directorios virtuales de su aplicación.

Por las razones indicadas anteriormente, los componentes de Aspose .NET no pueden utilizarse en servidores que otorguen permisos distintos de *Full Trust*.

## Soporte técnico {#technical-support}
  
Aspose ofrece soporte técnico gratuito ilimitado para todos sus productos. Este soporte está disponible para todos los usuarios, incluidos aquellos que ejecutan una versión de evaluación.

Si necesita ayuda, <a href="https://forum.conholdate.com/" target="_blank">**visite los foros de Conholdate.Forums**</a>. Publique su pregunta en el foro de Aspose.Tasks para .NET y será respondida en cuestión de pocas horas.

Al esperar una respuesta en los foros, tenga en cuenta las diferencias de zona horaria.

### Informar de un problema {#reporting-an-issue}
  
Si tiene un problema, siga estos sencillos pasos para asegurarse de que se resuelva de forma eficiente:

- Asegúrese de utilizar la última versión del producto antes de informar de un problema.  
- Consulte los <a href="https://forum.conholdate.com/" target="_blank">foros</a>, esta documentación Wiki y la <a href="https://reference.aspose.com/tasks/net" target="_blank" rel="nofollow noopener noreferrer">referencia de la API</a> antes de informar de un problema. Es posible que su pregunta ya tenga respuesta.  
- Al informar de un problema, incluya el documento original y, si es posible, un fragmento de su código que cause el problema. Si necesita adjuntar varios archivos, comprímalos en un único archivo ZIP. Es seguro adjuntar sus documentos en los foros, ya que solo usted y los desarrolladores de Aspose tienen acceso a los archivos adjuntos.  
- Por favor, informe de un solo problema por hilo. Si tiene otro problema, infórmelo en un hilo independiente.

Aspose no proporciona soporte técnico por teléfono. El soporte telefónico solo está disponible para consultas relacionadas con ventas y compras.

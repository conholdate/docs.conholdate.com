## Introducción al soporte de formatos de archivo en Aspose.Tasks para .NET {#introduction-to-file-format-support-in-asposetasks-for-net}
  
Aspose.Tasks para .NET es una API integral de gestión de proyectos que permite a los desarrolladores crear, manipular y convertir archivos de proyecto de forma programática, sin necesidad de instalar Microsoft Project. La biblioteca ofrece un amplio soporte para diversos formatos de archivo comúnmente utilizados en los flujos de trabajo de gestión de proyectos.

### Capacidades de formato de archivo de entrada y salida {#input-and-output-file-format-capabilities}
  
Aspose.Tasks para .NET admite una amplia gama de formatos de archivo tanto para cargar (entrada) como para guardar (salida). La API puede trabajar con los formatos nativos de Microsoft Project, como MPP, XML y MPT, así como con formatos de Primavera, incluidos XER, P6 XML y MPX. En cuanto a las capacidades de salida, la biblioteca va más allá de los formatos específicos de gestión de proyectos para incluir formatos de documento comunes, como PDF, HTML y diversos formatos de imagen (TIFF, PNG, JPEG, etc.), ofreciendo así capacidades versátiles para la generación de informes y la visualización de datos.

### Características principales {#key-features}
  
- **Soporte de formato de Microsoft Project**: Cargar y guardar proyectos en formato MPP en todas las versiones modernas (2003-2021)  
- **Integración con Primavera**: Importar y exportar archivos XER y P6 XML de Primavera  
- **Exportación de vista gráfica**: Guardar vistas de proyecto como PDF o diversos formatos de imagen  
- **Exportación de datos**: Convertir datos de proyecto a hojas de cálculo de Excel, CSV o archivos de texto  
- **Compatibilidad multiplataforma**: Crear visualizaciones de proyectos independientes de la plataforma mediante HTML y SVG

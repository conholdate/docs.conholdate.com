Aspose.Tasks para .NET le permite trabajar con archivos de Microsoft Project (MPP/XML) sin necesidad de tener Microsoft Project instalado ni depender de la automatización de Microsoft Office. Proporciona una **API potente y flexible** que ayuda a los desarrolladores a ahorrar tiempo y esfuerzo al ofrecer una forma coherente de manipular datos de proyectos en distintos formatos.

Con Aspose.Tasks, puede:

- Crear nuevos archivos de proyecto desde cero o basados en plantillas  
- Abrir archivos existentes en diversos formatos (MPP, MPT, MPX, XML, XER, P6 XML)  
- Guardar proyectos en múltiples formatos, incluidos MPP, XML, PDF, HTML, entre otros  

Este artículo explica cómo **crear, leer y guardar archivos de proyecto** mediante la clase `Project`.

## Crear un archivo de proyecto vacío  {#creating-an-empty-project-file}
  
La clase <a href="https://reference.aspose.com/tasks/net/aspose.tasks/project" target="_blank" rel="nofollow noopener noreferrer">Project</a> es la clase principal en Aspose.Tasks, utilizada para establecer y obtener propiedades asociadas con un proyecto, así como su comportamiento. El método `Save` ofrecido por esta clase permite representar el proyecto en diversos formatos de salida, como XML, MPP, PDF, HTML, etc., con una única llamada a la API. Este método acepta un flujo de archivo o un nombre de archivo, y uno de los valores proporcionados por el tipo de enumeración <a href="https://reference.aspose.com/tasks/net/aspose.tasks.saving/savefileformat" target="_blank" rel="nofollow noopener noreferrer">SaveFileFormat</a>.

Las siguientes líneas de código crean un archivo de proyecto simple en formato XML.

### Crear un proyecto vacío y guardarlo como archivo XML  {#create-an-empty-project-and-saving-as-xml-file}
  
Este ejemplo demuestra cómo crear un proyecto completamente nuevo y guardarlo como un archivo XML que puede abrirse en Microsoft Project.

```java
Project project = new Project();
project.Save("EmptyProjectSaveXML_out.xml", SaveFileFormat.XML);
```

El archivo de proyecto XML resultante puede abrirse en Microsoft Project utilizando los siguientes pasos:

1. En el menú **Archivo**, seleccione **Abrir**.
2. Seleccione la opción de formato XML (\*.xml) entre los tipos de archivo y navegue hasta el archivo XML de salida.
3. En el menú **Proyecto**, seleccione **Información del proyecto**.

### Crear un proyecto vacío y guardarlo en un flujo  {#create-an-empty-project-and-save-to-stream}
  
Si necesita trabajar con proyectos en memoria (por ejemplo, en aplicaciones web o entornos en la nube), puede guardarlo directamente en un `MemoryStream` en lugar de escribirlo en un archivo.

```java
// Create a project instance
Project newProject = new Project();

// Create a file stream
using (FileStream stream = new FileStream("EmptyProjectSaveStream_out.xml", FileMode.Create, FileAccess.Write))
{
    // Write the stream into XML format
    newProject.Save(stream, SaveFileFormat.XML);
}
```

### Crear un proyecto vacío y guardarlo como MPP {#create-an-empty-project-and-save-to-mpp}
  
Este ejemplo muestra cómo generar programáticamente un archivo **MPP** nativo de Microsoft Project.

```java
// there is no more need to load MPP template to save it into MPP
// add tasks, resources, etc.
Project project = new Project();

// !The project will be saved into MPP by using internal MPP template.
project.Save("New Project.mpp", SaveFileFormat.MPP);
```

## Leer un archivo de proyecto {#read-a-project-file}
  
Aspose.Tasks para .NET le permite leer proyectos existentes en distintos formatos: **XML**, **MPP**, **MPT**, **MPX**, **XER**, Primavera P6 XML, etc., y guardarlos nuevamente en formato MPP u otro formato tras actualizarlos. Los fragmentos siguientes muestran cómo se puede leer un archivo de proyecto utilizando el constructor de la clase `Project`.

### Leer archivos de proyecto como plantilla {#reading-project-files-as-a-template}
  
Este ejemplo muestra cómo cargar un proyecto utilizando el constructor `Project` y tratarlo como una plantilla para su posterior uso.

```java
// Read existing project template file
Project project = new Project("New Project.mpp");
```

Para escenarios en los que los proyectos se cargan o almacenan en flujos, puede cargarlos directamente desde objetos `Stream`.


### Ignorar caracteres no válidos durante la carga de Project {#ignoring-invalid-characters-during-loading-project}
  
Algunos archivos pueden contener caracteres no válidos en los campos personalizados. Microsoft Project no permite caracteres no válidos, por lo que estos archivos se han creado o manipulado mediante automatización u otras herramientas. Si se cargan mediante la API, pueden provocar una excepción. Para ignorar dichos caracteres no válidos, se puede utilizar el constructor sobrecargado de la clase `Project` junto con el método de devolución de llamada `ParseErrorCallBack`.

```java
static void Run()
{
    // Open modified xml stream
    using (MemoryStream stream = new MemoryStream(Encoding.UTF8.GetBytes(GetModifiedXml())))
    {
        Project project = new Project(stream, new ParseErrorCallback(CustomDurationHandler));
    }
}

static string GetModifiedXml()
{
    // Open valid xml file and modify it
    using (TextReader reader = new StreamReader("IgnoreInvalidCharacters.xml"))
    {
        string xml = reader.ReadToEnd();
        Regex regex = new Regex("PT(\\d+)H(\\d+)M(\\d+)S");
        return regex.Replace(xml, "**$1Hrs$2Mins$3Secs**");
    }
}

static object CustomDurationHandler(object sender, ParseErrorArgs args)
{
    Regex regex = new Regex("[*]{2}(\\d+)Hrs(\\d+)Mins(\\d+)Secs[*]{2}");
    if (args.FieldType == typeof(TimeSpan))
    {
        Debug.Print("Object field : {0}, Invalid value : {1}", args.FieldName, args.InvalidValue);
        string duration = regex.Replace(args.InvalidValue, "PT$1H$2M$3S");
        TimeSpan newValue = Duration.ParseTimeSpan(duration);
        Debug.Print("New value : {0}", newValue);
        return newValue;
    }
    // Here we handle only TimeSpan instances, so rethrow original exception with other types
    throw args.Exception;
}
```

## Trabajar con Codificaciones  {#working-with-encodings}
  
Al trabajar con archivos MPX, es posible que deba especificar la codificación correcta del archivo. Esto garantiza que los datos de texto se lean y muestren correctamente. Aspose.Tasks para .NET proporciona soporte para la codificación de archivos MPX. El siguiente ejemplo de código muestra la configuración de codificación.

```java
// Specify Encodings
using (StreamReader streamReader = new StreamReader("Project.mpx", System.Text.Encoding.GetEncoding("ISO-8859-1")))
{
    Project project = new Project(streamReader.BaseStream);
}
```

Aspose.Tasks para .NET brinda a los desarrolladores control total sobre los archivos de Microsoft Project sin necesidad de tener instalado MS Project.\
Con la clase `Project`, puede:

- Crear nuevos proyectos (XML, MPP) y guardarlos en un archivo o flujo
- Leer proyectos existentes en múltiples formatos
- Trabajar con integraciones de Project Server y bases de datos (soporte heredado)
- Manejar problemas de codificación y caracteres no válidos de forma adecuada

Ya sea que esté creando una solución de escritorio o una aplicación web, Aspose.Tasks proporciona una **API coherente y fiable** para gestionar datos de proyectos mediante programación.

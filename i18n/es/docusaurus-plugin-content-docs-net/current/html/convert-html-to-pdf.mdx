## Convertir HTML a PDF con una sola línea de C# {#convert-html-to-pdf-with-one-line-of-c}
  
Para entradas sencillas, la clase estática <a href="https://reference.aspose.com/html/net/aspose.html.converters/converter/" target="_blank" rel="nofollow noopener noreferrer">Converter</a> ofrece un camino rápido para convertir contenido HTML en un archivo PDF. El ejemplo siguiente pasa el código HTML, un URI base, los valores predeterminados de `PdfSaveOptions` y la ruta del archivo de salida a `ConvertHTML()`.

```java
// Convert HTML to PDF using C#

// Invoke the ConvertHTML() method to convert HTML to PDF
Converter.ConvertHTML(@"<h1>Convert HTML to PDF!</h1>", ".", new PdfSaveOptions(), Path.Combine(OutputDir, "convert-with-single-line.pdf"));
```

## Convertir un archivo HTML a PDF en C# {#convert-an-html-file-to-pdf-in-c}
  
Una conversión típica basada en archivos utiliza una instancia de <a href="https://reference.aspose.com/html/net/aspose.html/htmldocument/" target="_blank" rel="nofollow noopener noreferrer">HTMLDocument</a>, un objeto `PdfSaveOptions` y `Converter.ConvertHTML()`. Puede cargar HTML desde un archivo local, código HTML, flujo o URL. Para obtener más patrones de carga, consulte [Creación de un documento HTML](/net/html/creating-a-document/).

El flujo de trabajo es el siguiente:  

1. Cargar el archivo HTML mediante un constructor de `HTMLDocument`.
2. Crear una instancia de `PdfSaveOptions`.
3. Llamar a `Converter.ConvertHTML(document, options, savePath)` para escribir el archivo PDF.

El siguiente ejemplo utiliza el archivo de muestra <a href="https://docs.aspose.com/html/files/spring.html" target="_blank" rel="nofollow noopener noreferrer">spring.html</a>. El siguiente código en C# convierte `spring.html` en `spring-output.pdf`.

```java
// Convert HTML to PDF in C#

// Prepare a path to a source HTML file
string documentPath = Path.Combine(DataDir, "spring.html");

// Prepare a path to save the converted file
string savePath = Path.Combine(OutputDir, "spring-output.pdf");

// Initialize an HTML document from the file
using HTMLDocument document = new HTMLDocument(documentPath);

// Initialize PdfSaveOptions
PdfSaveOptions options = new PdfSaveOptions();

// Convert HTML to PDF
Converter.ConvertHTML(document, options, savePath);
```

## Recetas cortas: HTML a PDF  {#short-html-to-pdf-recipes}  

- Convertir una cadena HTML a PDF: pase el contenido HTML, el URI base, `PdfSaveOptions` y la ruta de salida a `Converter.ConvertHTML()`.
- Convertir un archivo HTML a PDF: cargue el archivo con `HTMLDocument`, cree `PdfSaveOptions` y llame a `Converter.ConvertHTML(document, options, savePath)`.
- Convertir HTML desde una URL a PDF: cree un `HTMLDocument` a partir de la URL y luego convierta el documento cargado con las opciones de guardado en PDF.
- Establecer tamaño de página y márgenes del PDF: configure `PdfSaveOptions.PageSetup`; consulte [Redimensionar documento durante la conversión](/net/html/resize-document/).
- Renderizar HTML con fuentes personalizadas: establezca una carpeta de fuentes antes de la conversión; consulte [Establecer carpeta de fuentes para renderizar HTML a PDF](/net/html/how-to-set-font-folder/#set-font-folder-to-render-html-to-pdf).
- Guardar la salida en PDF en memoria o en almacenamiento personalizado: implemente `ICreateStreamProvider` y pásela al flujo de trabajo de conversión.  

## Personalizar HTML a PDF con PdfSaveOptions {#customize-html-to-pdf-with-pdfsaveoptions}
  
Utilice <a href="https://reference.aspose.com/html/net/aspose.html.saving/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> cuando el PDF de salida requiera configuraciones de renderizado personalizadas. El objeto de opciones se pasa a `ConvertHTML()` y controla cómo se renderiza el documento HTML a PDF.

<div className="docs-owner-markdown-table">

| Opción | Úsela para controlar |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `JpegQuality` | La calidad de compresión JPEG para las imágenes en la salida PDF. El valor predeterminado es 95. |
| `Css` | El comportamiento del procesamiento de CSS mediante `CssOptions`. |
| `DocumentInfo` | Los metadatos del documento PDF generado. |
| `BackgroundColor` | El color utilizado para rellenar el fondo de la página. El valor predeterminado es transparente. |
| `PageSetup` | El tamaño de página, los márgenes y la configuración de diseño de página. |
| `HorizontalResolution` y `VerticalResolution` | Los valores de resolución de salida utilizados por el proceso de renderizado. El valor predeterminado es 300 dpi para cada propiedad. |
| `Encryption` | La configuración de cifrado PDF cuando la salida debe protegerse. |

</div>

El siguiente ejemplo crea un PDF con tamaño de página personalizado, márgenes, color de fondo, calidad de imagen y configuraciones de resolución personalizadas.

```java
// Convert HTML to PDF in C# with custom page settings

// Prepare a path to a source HTML file
string documentPath = Path.Combine(DataDir, "drawing.html");

// Prepare a path to save the converted file
string savePath = Path.Combine(OutputDir, "drawing-options.pdf");

// Initialize an HTML document from the file
using HTMLDocument document = new HTMLDocument(documentPath);

// Initialize PdfSaveOptions. Set up the page-size 600x300 pixels, margins, resolutions and change the background color to AliceBlue 
PdfSaveOptions options = new PdfSaveOptions()
{
    HorizontalResolution = 200,
    VerticalResolution = 200,
    BackgroundColor = System.Drawing.Color.AliceBlue,
    JpegQuality = 100
};
options.PageSetup.AnyPage = new Page(new Aspose.Html.Drawing.Size(600, 300), new Margin(20, 10, 10, 10));

// Convert HTML to PDF
Converter.ConvertHTML(document, options, savePath);
```

## Guardar HTML en PDF con un proveedor de secuencias de salida {#save-html-to-pdf-with-an-output-stream-provider}
  
Utilice <a href="https://reference.aspose.com/html/net/aspose.html.io/icreatestreamprovider/" target="_blank" rel="nofollow noopener noreferrer">ICreateStreamProvider</a> cuando la salida de la conversión deba escribirse mediante secuencias en lugar de solo en una ruta de archivo. Esto resulta útil para flujos de trabajo basados en memoria, almacenamiento remoto, bases de datos o servicios que necesitan decidir dónde se almacena la salida renderizada.

La clase `MemoryStreamProvider` implementa `ICreateStreamProvider` y mantiene las secuencias generadas en memoria.

```java
// Implement a custom MemoryStream provider for advanced control over HTML rendering output streams

class MemoryStreamProvider : Aspose.Html.IO.ICreateStreamProvider
{
    // List of MemoryStream objects created during the document rendering
    public List<MemoryStream> Streams { get; } = new List<MemoryStream>();

    public Stream GetStream(string name, string extension)
    {
        // This method is called when only one output stream is required, for instance for XPS, PDF or TIFF formats
        MemoryStream result = new MemoryStream();
        Streams.Add(result);
        return result;
    }

    public Stream GetStream(string name, string extension, int page)
    {
        // This method is called when the creation of multiple output streams are required. For instance, during the rendering HTML to list of image files (JPG, PNG, etc.)
        MemoryStream result = new MemoryStream();
        Streams.Add(result);
        return result;
    }

    public void ReleaseStream(Stream stream)
    {
        // Here you can release the stream filled with data and, for instance, flush it to the hard-drive
    }

    public void Dispose()
    {
        // Releasing resources
        foreach (MemoryStream stream in Streams)
            stream.Dispose();
    }
}
```

:::info
Algunos formatos de salida generan un solo archivo, como PDF y XPS. Los formatos de imagen, como JPG o PNG, pueden generar múltiples flujos de salida cuando el documento renderizado tiene varias páginas.
:::

El siguiente ejemplo convierte HTML a PDF con `MemoryStreamProvider`, lee la secuencia de memoria generada y la guarda en un archivo PDF.

```java
// Convert HTML to PDF in C# using memory stream

// Create an instance of MemoryStreamProvider
using MemoryStreamProvider streamProvider = new MemoryStreamProvider();

// Initialize an HTML document
using HTMLDocument document = new HTMLDocument(@"<h1>Convert HTML to PDF File Format!</h1>", ".");

// Convert HTML to PDF using the MemoryStreamProvider
Converter.ConvertHTML(document, new PdfSaveOptions(), streamProvider);

// Get access to the memory stream that contains the result data
MemoryStream memory = streamProvider.Streams.First();
memory.Seek(0, SeekOrigin.Begin);

// Flush the result data to the output file
using (FileStream fs = File.Create(Path.Combine(OutputDir, "stream-provider.pdf")))
{
    memory.CopyTo(fs);
}
```

### ¿Por qué una página HTML puede verse diferente tras la conversión a PDF? {#why-can-an-html-page-look-different-after-pdf-conversion}
  
Un navegador muestra HTML en un área visible flexible, mientras que PDF utiliza páginas de tamaño fijo. Por lo tanto, el tamaño de página, los márgenes, el CSS de impresión, la disponibilidad de fuentes y la carga de recursos pueden alterar los saltos de línea y la paginación. Configure `PdfSaveOptions.PageSetup` y asegúrese de que todos los estilos, imágenes y fuentes necesarios estén accesibles durante la conversión.

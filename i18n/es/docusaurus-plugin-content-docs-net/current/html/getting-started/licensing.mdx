## Evaluar Aspose.HTML para .NET {#evaluate-asposehtml-for-net}
  
Puede descargar Aspose.HTML para .NET con fines de evaluación y utilizar las mismas API que están disponibles en la versión con licencia. Sin una licencia, la biblioteca ofrece toda la funcionalidad del producto, pero la salida generada y algunas colecciones están limitadas.

La versión de evaluación presenta las siguientes limitaciones:  

- **Los archivos HTML guardados contienen marcas de agua de evaluación.** Algunos contenidos del documento HTML guardado se reemplazan con la marca de agua de evaluación.
- **Los archivos SVG guardados contienen la marca de agua de evaluación y un número limitado de elementos.** Se eliminan algunos nodos del SVG guardado y se agrega la marca de agua de evaluación.
- **Los documentos convertidos contienen marcas de agua de evaluación y un número limitado de páginas.** Cada página convertida contiene la marca de agua de evaluación, y el número de páginas convertidas está limitado a cuatro.
- **El tamaño de las colecciones está limitado.** El tamaño de algunas colecciones está limitado.

## Aplicar una licencia {#applying-a-license}
  
Tras la compra, aplique el archivo de licencia antes de utilizar las API de Aspose.HTML que creen, guarden, rendericen o conviertan documentos. Puede cargar la licencia desde un disco, desde una secuencia, desde un recurso incrustado o utilizar una licencia basada en medición.

**Utilice el nombre completo de la clase de licencia.** Si utiliza otro componente de Aspose para .NET junto con Aspose.HTML para .NET, especifique el espacio de nombres completo para la clase de licencia, como <a href="https://reference.aspose.com/html/net/aspose.html/license/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Html.License</a> o <a href="https://reference.aspose.com/html/net/aspose.html/metered/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Html.Metered</a>. Cada producto de Aspose dispone de una clase `License` en su propio espacio de nombres. Por ejemplo, Aspose.HTML utiliza <a href="https://reference.aspose.com/html/net/aspose.html/license/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Html.License</a> y Aspose.SVG utiliza <a href="https://reference.aspose.com/svg/net/aspose.svg/license/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Svg.License</a>. El nombre completo de la clase ayuda a evitar aplicar una licencia al espacio de nombres incorrecto.

### Aplicar una licencia desde disco {#apply-a-license-from-disk}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que `Aspose.HTML.dll` y especificar únicamente el nombre del archivo, sin ruta de acceso.

Para aplicar un archivo de licencia en C#:  

1. Agregue el archivo `.lic` a la carpeta de la aplicación o a otra ruta accesible en tiempo de ejecución.
2. Cree una instancia de <a href="https://reference.aspose.com/html/net/aspose.html/license/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Html.License</a>.
3. Llame a <a href="https://reference.aspose.com/html/net/aspose.html/license/setlicense/" target="_blank" rel="nofollow noopener noreferrer">SetLicense()</a> antes de utilizar las API de procesamiento o conversión de documentos.
4. Ejecute la aplicación y verifique que los archivos de salida ya no contengan marcas de agua de evaluación.

```csharp
// Initialize a license object
Aspose.Html.License htmlLicense = new Aspose.Html.License();

// Apply the license using the file name
htmlLicense.SetLicense("Aspose.HTML.lic");
```

### Aplicar una licencia desde un flujo  {#apply-a-license-from-a-stream}
  
Utilice un flujo cuando el archivo de licencia se almacene fuera de la carpeta de la aplicación, se cargue desde un almacenamiento seguro o se proporcione mediante la configuración de implementación.

```csharp
// Initialize a license object
Aspose.Html.License htmlLicense = new Aspose.Html.License();

// Open a license file stream
using (var stream = new System.IO.FileStream("Aspose.HTML.lic", System.IO.FileMode.Open))
{
    // Apply the license using the stream
    htmlLicense.SetLicense(stream);
}
```

### Aplicar una licencia con inicialización perezosa  {#apply-a-license-with-lazy-initialization}
  
Un patrón común en aplicaciones es aplicar la licencia una sola vez al inicio o mediante inicialización perezosa antes de que se ejecute el primer flujo de trabajo de Aspose.HTML. Esto centraliza el código de licenciamiento y evita repetir `SetLicense()` en todo el proyecto.

```csharp
internal class LicenseSingleton
{
    private static LicenseSingleton _instance = new LicenseSingleton();

    private LicenseSingleton()
    {
        // Initialize the license
        (new Aspose.Html.License()).SetLicense(@"F:\aspose.html.net\testdata\license\Aspose.HTML.NET.lic");
    }

    public static void SetLicense()
    {
        LicenseSingleton local = _instance;
    }
}

static void Main(string[] args)
{
    // Lazy initialization before using the library
    LicenseSingleton.SetLicense();
}
```

### Aplicar una licencia como un recurso incrustado  {#apply-a-license-as-an-embedded-resource}
  
Otra forma de empaquetar una licencia con su aplicación es incluirla como un recurso incrustado en uno de los ensamblados que llama a Aspose.HTML para .NET.

Para incluir el archivo de licencia como un recurso incrustado:  

1. En Visual Studio, incluya el archivo `.lic` en su proyecto haciendo clic con el botón derecho en el proyecto y seleccionando **Agregar** &gt; **Elemento existente…**.
2.  Seleccione el archivo en el Explorador de soluciones.
3.  En la ventana **Propiedades**, establezca **Acción de compilación** en **Recurso incrustado**.
4.  En su código, llame a <a href="https://reference.aspose.com/html/net/aspose.html/license/setlicense/" target="_blank" rel="nofollow noopener noreferrer">SetLicense()</a> y pase únicamente el nombre corto del archivo de recurso.

```csharp
// Initialize a license object
Aspose.Html.License htmlLicense = new Aspose.Html.License();

// Apply the license using the embedded resource name
htmlLicense.SetLicense("Aspose.HTML.lic");
```

:::info
Los recursos se incrustan en un ensamblado sin modificación. Si agrega un archivo de licencia como un recurso incrustado, cualquier persona que pueda inspeccionar el ensamblado resultante podría ver o extraer el contenido de la licencia. Utilice este enfoque únicamente cuando coincida con sus requisitos de implementación y seguridad.
:::

### Aplicar una licencia basada en uso (Metered) {#apply-a-metered-license}
  
La licencia basada en uso (metered licensing) es un mecanismo de licenciamiento que se utiliza junto con el enfoque existente mediante archivo de licencia. Los clientes que deseen ser facturados según el uso de las características de la API pueden aplicar claves basadas en uso en lugar de un archivo de licencia. Para obtener más detalles, consulte <a href="https://purchase.conholdate.com/faqs/licensing/metered/how-to-use/" target="_blank">Uso de su licencia basada en uso</a>.

Tras completar los pasos necesarios para obtener este tipo de licencia, recibirá claves pública y privada en lugar de un archivo de licencia. Aplique estas claves mediante la clase <a href="https://reference.aspose.com/html/net/aspose.html/metered/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Html.Metered</a>.

```csharp
// Initialize a metered object
Aspose.Html.Metered metered = new Aspose.Html.Metered();

// Apply the metered license using the public and private keys
metered.SetMeteredKey("*****", "*****");
```

Normalmente, basta con aplicar la licencia medible una sola vez al iniciar la aplicación. Sin embargo, si el mecanismo de licencia medible no logra comunicarse con los servidores de Aspose durante 24 horas, Aspose.HTML sale del modo con licencia y pasa al modo de evaluación. Para evitar este caso, revise regularmente el estado de la licencia. Si Aspose.HTML pasa al modo de evaluación, vuelva a aplicar la licencia medible.

:::info
Para utilizar una licencia Medida correctamente, debe tener una conexión estable a Internet, ya que el mecanismo Medido requiere interacción regular con los servicios de Aspose para realizar cálculos correctos. Para obtener más información, consulte la <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Preguntas frecuentes sobre licencias Medidas</a>.
:::

## Problemas Comunes de Licencias {#common-licensing-issues}

<div className="docs-owner-markdown-table">

| Problema | Causa | Solución |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Los archivos de salida aún contienen marcas de agua de evaluación | La licencia no se aplicó antes de guardar o convertir los documentos, o la aplicación no puede encontrar el archivo `.lic` en tiempo de ejecución. | Llame a `SetLicense()` antes de usar las API de Aspose.HTML y verifique que el archivo de licencia se haya copiado en la carpeta de tiempo de ejecución o se cargue desde la ruta correcta. |
| El producto incorrecto de Aspose permanece en modo de evaluación | El proyecto utiliza varios productos de Aspose y la licencia se aplicó mediante una clase `License` de otro espacio de nombres. | Utilice el nombre de clase totalmente calificado, por ejemplo `Aspose.Html.License`, al aplicar la licencia de Aspose.HTML. |
| La licencia funciona localmente pero falla en un servidor o en Docker | El archivo de licencia no se implementa con la aplicación, la ruta es distinta o la imagen del contenedor no incluye el archivo. | Incluya la licencia en los artefactos de implementación, monte el archivo de forma segura o cárguelo desde un flujo o una fuente de configuración protegida. |
| La licencia integrada puede extraerse del ensamblado | Los recursos integrados se almacenan en el ensamblado sin cifrado ni modificación. | Utilice recursos integrados únicamente cuando esta compensación de seguridad sea aceptable. Para implementaciones más estrictas, cargue la licencia desde un almacenamiento protegido. |
| La licencia basada en uso (Metered) cambia al modo de evaluación | La aplicación no puede comunicarse con los servicios de Aspose durante 24 horas o más. | Mantenga una conexión estable a Internet para la licencia basada en uso y vuelva a aplicar las claves basadas en uso si la aplicación entra en modo de evaluación. |

## Preguntas frecuentes {#faq}

### ¿Es distinto el paquete de evaluación del paquete adquirido? {#is-the-evaluation-package-different-from-the-purchased-package}
  
No. La versión de evaluación y la versión adquirida utilizan el mismo paquete Aspose.HTML para .NET. El paquete se convierte en licenciado tras aplicar una licencia válida en el código.

### ¿Cuándo debo aplicar la licencia? {#when-should-i-apply-the-license}
  
Aplique la licencia al inicio de la aplicación o antes de la primera operación de Aspose.HTML que cargue, guarde, renderice o convierta documentos. Esto evita las marcas de agua de evaluación y las limitaciones en la salida.

### ¿Puedo utilizar una licencia temporal para pruebas? {#can-i-use-a-temporary-license-for-testing}
  
Sí. Una licencia temporal de 30 días le permite probar Aspose.HTML para .NET sin limitaciones de evaluación. Aplíquela mediante `Aspose.Html.License.SetLicense()` como si fuera un archivo de licencia adquirido.

### ¿Debo utilizar un archivo de licencia o una licencia basada en consumo (metered)? {#should-i-use-a-license-file-or-a-metered-license}
  
Utilice un archivo de licencia para licencias comerciales estándar. Utilice una licencia basada en consumo cuando su modelo de adquisición se base en el uso de la API y la aplicación pueda mantener acceso regular a los servicios de Aspose a través de Internet.

### ¿Puedo aplicar licencias para varios productos de Aspose en la misma aplicación? {#can-i-apply-licenses-for-several-aspose-products-in-the-same-application}
  
Sí. Aplique cada licencia de producto mediante su propia clase específica por espacio de nombres, como `Aspose.Html.License` para Aspose.HTML y `Aspose.Svg.License` para Aspose.SVG.

## Cómo leer la tabla de formatos  {#how-to-read-the-format-table}
  
Los formatos marcados como **Entrada** pueden cargarse o utilizarse como documentos de origen en los flujos de trabajo de Aspose.HTML para .NET. Los formatos marcados como **Salida** pueden guardarse o producirse durante la conversión. Algunos formatos, como HTML, XHTML, MHTML, SVG y Markdown, pueden funcionar tanto como formatos de entrada como de salida.

EPUB aparece listado como formato de entrada porque Aspose.HTML para .NET puede cargar documentos EPUB y convertirlos a formatos de salida admitidos. PDF, XPS y formatos de imagen rasterizada aparecen listados como formatos de salida porque son destinos típicos de renderizado para documentos de origen relacionados con HTML.

Para ejemplos prácticos de conversión, consulte [Conversión entre formatos](/net/html/converting-between-formats/), [Convertidor HTML](/net/html/html-converter/), [Convertidor SVG](/net/html/svg-converter/), [Convertidor MHTML](/net/html/mhtml-converter/), [Convertidor EPUB](/net/html/epub-converter/) y [Convertidor Markdown](/net/html/markdown-converter/).

## Problemas Comunes de Selección de Formato  {#common-format-selection-issues}

<div className="docs-owner-markdown-table">

| Problema | Causa | Solución |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Se espera EPUB como formato de salida | EPUB se admite como formato de entrada en esta tabla, no como destino de salida. | Cargue EPUB como fuente y conviértalo a formatos de salida admitidos, como PDF, XPS, DOCX o imágenes. |
| Se espera PDF como formato de entrada | PDF aparece listado como formato de salida para los flujos de trabajo de conversión de Aspose.HTML para .NET. | Utilice formatos de fuente relacionados con HTML, como HTML, XHTML, SVG, MHTML, EPUB o Markdown al trabajar con esta API. |
| La salida de imagen carece de texto en Linux o Docker | La salida en mapa de bits depende de las fuentes disponibles en el entorno de ejecución. | Instale las fuentes y los paquetes de configuración de fuentes necesarios. Consulte [Linux Docker Fonts for HTML to Image](/net/html/html-to-image-linux-docker-fonts/). |
| La salida JPG pierde transparencia | JPEG no admite transparencia. | Utilice PNG cuando se requiera un fondo transparente o soporte para el canal alfa. |
| El formato de salida elegido es difícil de editar posteriormente | Los formatos de diseño fijo y mapa de bits están diseñados para una representación estable, no para una edición semántica. | Utilice formatos de salida DOCX o de la familia HTML cuando el siguiente paso del flujo de trabajo requiera editar el contenido. |

</div>

## Preguntas frecuentes {#faq}

### ¿Qué formatos de origen puede cargar Aspose.HTML para .NET? {#which-source-formats-can-aspose-html-for-net-load}
  
Aspose.HTML para .NET puede cargar documentos de origen en formatos HTML, XHTML, MHTML, EPUB, SVG y Markdown para su procesamiento y conversiones compatibles.

### ¿Qué formatos de salida puede crear Aspose.HTML para .NET? {#which-output-formats-can-aspose-html-for-net-create}
  
Aspose.HTML para .NET puede crear documentos de salida en formatos HTML, XHTML, MHTML, SVG, Markdown, PDF, XPS, DOCX, TIFF, JPEG, PNG, BMP y GIF, según el flujo de trabajo de conversión y las opciones de guardado utilizadas.

### ¿Puede Aspose.HTML para .NET convertir archivos EPUB? {#can-aspose-html-for-net-convert-epub-files}
  
Sí. EPUB se admite como formato de entrada. Puede convertir documentos EPUB a formatos de salida compatibles, como PDF, XPS, DOCX y formatos de imagen.

### ¿Puede Aspose.HTML para .NET convertir documentos a PDF? {#can-aspose-html-for-net-convert-documents-to-pdf}
  
Sí. PDF se admite como formato de salida. Consulte [HTML a PDF](/net/html/convert-html-to-pdf/), [SVG a PDF](/net/html/convert-svg-to-pdf/), [MHTML a PDF](/net/html/convert-mhtml-to-pdf/) y [EPUB a PDF](/net/html/convert-epub-to-pdf/) para ver ejemplos.

### ¿Dónde puedo encontrar ejemplos específicos por formato? {#where-can-i-find-format-specific-examples}
  
Comience con el centro [Conversión entre formatos](/net/html/converting-between-formats/) y, a continuación, abra la sección del convertidor correspondiente al formato de origen que necesita.

Aspose.HTML para .NET es una biblioteca de C# sin interfaz gráfica para crear, cargar, editar, navegar, guardar y convertir documentos relacionados con HTML. Funciona con documentos fuente en HTML, XHTML, SVG, EPUB, MHTML y Markdown, y puede renderizarlos o guardarlos en formatos de salida compatibles como PDF, XPS, DOCX, Markdown, JPG, PNG, TIFF, BMP y GIF.

La API está diseñada en torno a conceptos de la plataforma web, como DOM, CSS, SVG, JavaScript, Canvas, carga de recursos y renderizado. Esta página resume las principales características de Aspose.HTML para .NET y proporciona enlaces a las secciones de documentación donde puede explorarlas con detalle.

## Manipulación de documentos {#document-manipulation}

Aspose.HTML para .NET le permite crear, cargar, inspeccionar, editar y guardar documentos de la familia HTML sin abrir una interfaz de usuario de navegador.

- [Crea un nuevo documento HTML](/net/html/creating-a-document/#create-a-new-html-document) o abrir un documento (X)HTML o [SVG existente](/net/html/creating-a-document/#svg-document). Puede cargar documentos desde un archivo local o directamente desde la web.
- [Guardar un documento HTML](/net/html/save-html-document/#save-html) junto con los recursos referenciados, como CSS e imágenes. El guardador puede almacenar el documento en sí, sus recursos vinculados y otros documentos a los que hace referencia.
- [Crear, editar, eliminar y reemplazar nodos HTML](/net/html/edit-html-document/) a través de una API basada en DOM alineada con la oficial <a href="https://dom.spec.whatwg.org/" target="_blank" rel="nofollow noopener noreferrer">Especificación del DOM</a>Mantenga los tokens de marcador de posición que aparecen en la entrada exactamente sin cambios.  
No agregue tokens de marcador de posición que no estén ya presentes en la entrada.  
Mantenga las tuberías y el recuento de filas de la tabla de Markdown sin cambios.
- [Configurar el entorno del documento](/net/html/environment-configuration/) para controlar las hojas de estilos del usuario, [carpetas de fuentes](/net/html/environment-configuration/#install-font-folder), [manejo de recursos externos](/net/html/environment-configuration/#network-service), servicios en tiempo de ejecución y comportamiento relacionado de procesamiento.

## Extracción de datos {#data-extraction}

Aspose.HTML para .NET no está diseñado como un *web scraper* por sí mismo, pero puede utilizarse para recopilar información de documentos HTML cargados y navegar por su estructura DOM.

- [Navegar a través de elementos HTML](/net/html/html-navigation/) con las API de DOM. Aspose.HTML para .NET implementa <a href="https://dom.spec.whatwg.org/#traversal" target="_blank" rel="nofollow noopener noreferrer">Recorrido</a> interfaces que le ayudan a moverse por el árbol DOM.
- [Consultar documentos HTML con XPath](/net/html/html-navigation/#xpath-query)Aspose.HTML para .NET admite las interfaces XPath 1.0 definidas para la navegación y consulta en el DOM.
- [Recopilar elementos con selectores CSS](/net/html/html-navigation/#css-selector). Las consultas de selectores CSS son útiles cuando necesitas encontrar elementos por etiqueta, clase, ID, atributo o relación estructural.

## Conversión {#conversion}

Uno de los objetivos principales de Aspose.HTML para .NET es proporcionar convertidores simples, personalizables y precisos para formatos de origen relacionados con HTML.

**Simplicidad.** La API de .NET puede convertir HTML, XHTML, SVG, EPUB, MHTML y Markdown a formatos compatibles mediante código C# conciso. El siguiente ejemplo convierte HTML a PDF:

```java
// Convert HTML to PDF using C#

Aspose.Html.Converters.Converter.ConvertHTML(@"<span>Hello, World!!</span>", ".", new Aspose.Html.Saving.PdfSaveOptions(), "output.pdf");
```

<a href="https://gist.github.com/aspose-com-gists/9a356b78ba78be0ac7330bd5065a4456#file-example-converthtmltopdfinonelineofcode-cs" target="_blank" rel="nofollow noopener noreferrer">Ejemplo: ConvertHtmlToPdfInOneLineOfCode.cs</a> alojado con ❤ por <a href="https://github.com/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>

**Personalización.** Aspose.HTML para .NET le permite [ajustar los convertidores](/net/html/fine-tuning-converters/) y controlar numerosos aspectos del procesamiento y conversión. Además del tamaño de página o la resolución de imagen, puede [personalizar el procesamiento de recursos externos](/net/html/environment-configuration/#network-service), configurar una [hoja de estilos personalizada](/net/html/environment-configuration/#user-style-sheet), definir fuentes, ajustar la configuración de página y controlar las opciones de salida.

**Precisión.** Los componentes principales están diseñados según las especificaciones oficiales de HTML, DOM, CSS y SVG, lo que ayuda a generar resultados predecibles en el análisis, el procesamiento y la conversión.

Los convertidores de Aspose.HTML para .NET pueden agruparse según el flujo de trabajo:

1. **Convertidores de diseño fijo** convierten HTML, XHTML, SVG, EPUB y MHTML a PDF, XPS, DOCX y formatos de imagen rasterizada como PNG, JPG, TIFF, BMP y GIF.
2. **Convertidores de Markdown** convierten [Markdown a HTML](/net/html/convert-markdown-to-html/) y [HTML a Markdown](/net/html/convert-html-to-markdown/).
3. **Convertidores de plantillas** crean un [archivo HTML a partir de una plantilla](/net/html/html-template/).

Explore el mapa completo del flujo de trabajo de conversión en [Conversión entre formatos](/net/html/converting-between-formats/).

## Independencia de Plataforma {#platform-independence}
  
Puede utilizar Aspose.HTML for .NET en aplicaciones .NET de 32 y 64 bits, incluidos proyectos web, de escritorio, de servicio y de línea de comandos. El paquete proporciona un ensamblado .NET Standard 2.0 y puede utilizarse en entornos compatibles con Windows, Linux y macOS, siempre que el entorno de ejecución .NET de destino y las dependencias nativas requeridas estén disponibles.

Para obtener la matriz detallada de compatibilidad, consulte [Requisitos del sistema](/net/html/getting-started/system-requirements/).

## Preguntas frecuentes {#faq}

### ¿Qué puede hacer Aspose.HTML for .NET? {#what-can-aspose-html-for-net-do}

Aspose.HTML for .NET permite crear, cargar, editar, navegar, guardar, extraer datos de y convertir documentos relacionados con HTML en aplicaciones C#.

### ¿Es Aspose.HTML for .NET un rastreador web (web scraper)? {#is-aspose-html-for-net-a-web-scraper}

No es un rastreador web dedicado, pero puede cargar documentos HTML y extraer datos mediante navegación DOM, consultas XPath y selectores CSS.

### ¿Qué formatos puede convertir Aspose.HTML for .NET? {#which-formats-can-aspose-html-for-net-convert}

Aspose.HTML for .NET admite flujos de trabajo de conversión para fuentes HTML, XHTML, SVG, MHTML, EPUB y Markdown hacia formatos de salida compatibles, como PDF, XPS, DOCX, Markdown e imágenes. Consulte la [Tablas de formatos de archivo compatibles](/net/html/getting-started/supported-file-formats/) para ver la tabla completa.

### ¿Puedo personalizar la salida de la conversión? {#can-i-customize-conversion-output}

Sí. Puede configurar opciones de guardado, configuración de página, resolución de imágenes, fuentes, hojas de estilos, manejo de recursos externos y comportamiento del entorno de ejecución de JavaScript, según el flujo de trabajo.

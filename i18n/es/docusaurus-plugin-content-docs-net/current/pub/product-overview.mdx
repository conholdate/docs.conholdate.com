**Bienvenido a Aspose.PUB para .NET**

Aspose.PUB para .NET es una suite de bibliotecas de clases .NET flexibles y fáciles de usar que le brindan la capacidad de leer archivos de Microsoft Publisher (.pub) y convertirlos a otros formatos de archivo. Le permite trabajar con archivos PUB sin necesidad de profundizar en los detalles de la estructura subyacente del formato de archivo. Esto le ayuda a crear aplicaciones complejas de forma rápida y sencilla. La API es fácil de usar y simplifica el trabajo con archivos de publicación en las principales plataformas. No requiere que Microsoft Publisher esté instalado en el servidor para trabajar.
:::

## Descripción del producto {#product-description}
  
Aspose.PUB para .NET se implementa utilizando C# administrado y puede utilizarse con cualquier lenguaje .NET, como C#, VB.NET, J#, etc. Permite desarrollar diversas aplicaciones .NET, desde aplicaciones de escritorio de Windows hasta aplicaciones web ASP.NET. La API incluye un conjunto amplio de ejemplos con funcionalidades completas escritos en C#, que los desarrolladores pueden utilizar para comenzar a trabajar con la API en cuestión de minutos. Por ahora, la API admite la lectura de archivos .pub y su conversión a PDF.

## Declaración {#declaration}
  
Todos los componentes de Aspose para .NET requieren el conjunto de permisos *Full Trust*. Esto se debe a que los componentes de Aspose para .NET necesitan acceder a la configuración del registro, archivos del sistema y otros recursos distintos del directorio virtual para realizar ciertas operaciones, como el análisis de fuentes, entre otras. Además, los componentes de Aspose para .NET se basan en clases fundamentales del sistema .NET, las cuales, en muchos casos, también requieren el conjunto de permisos *Full Trust*.

Los proveedores de servicios de Internet (ISP) que alojan múltiples aplicaciones de distintas empresas suelen imponer el nivel de seguridad *Medium Trust*. En el caso de .NET 2.0, este nivel de seguridad impone las siguientes restricciones:  

- OleDbPermission no está disponible. Esto significa que no se puede utilizar el proveedor de datos administrado OLE DB de ADO.NET para acceder a bases de datos.
- EventLogPermission no está disponible. Esto significa que no se puede acceder al registro de eventos de Windows.
- ReflectionPermission no está disponible. Esto significa que no se puede utilizar la reflexión.
- RegistryPermission no está disponible. Esto significa que no se puede acceder al registro.
- WebPermission está restringida. Esto significa que su aplicación solo puede comunicarse con una dirección o rango de direcciones que usted defina en el elemento.
- FileIOPermission está restringida. Esto significa que solo puede acceder a archivos dentro de la jerarquía del directorio virtual de su aplicación.

Debido a las razones mencionadas anteriormente, los componentes de Aspose para .NET no pueden utilizarse en servidores que otorguen un conjunto de permisos distinto de *Full Trust*.

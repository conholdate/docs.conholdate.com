Puede descargar Aspose.PUB para .NET de forma gratuita para su evaluación. La versión de evaluación ofrece casi todas las funcionalidades del producto, con ciertas limitaciones. La misma versión de evaluación se convierte en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para [aplicar la licencia](/net/pub/licensing/#applying-for-a-license).

## Solicitar una licencia {#applying-for-a-license}
  
Puede descargar fácilmente una versión de evaluación de Aspose.PUB desde su  <a href="https://www.nuget.org/packages/Aspose.Pub/" target="_blank" rel="nofollow noopener noreferrer">página de descarga</a>. La versión de evaluación ofrece exactamente las mismas capacidades que la versión con licencia de Aspose.PUB. Además, la versión de evaluación se convierte automáticamente en una versión con licencia cuando adquiere una licencia y agrega un par de líneas de código para aplicarla.

### Información sobre la licencia {#about-the-license}
  
La licencia es un archivo XML de texto simple que contiene detalles como el nombre del producto, el número de desarrolladores a los que está licenciado, la fecha de vencimiento de la suscripción, etc. El archivo está firmado digitalmente, por lo que no debe modificarlo. Incluso la adición accidental de un salto de línea adicional en el archivo invalidará la licencia.

Debe establecer una licencia antes de utilizar Aspose.PUB si desea evitar sus limitaciones de evaluación. Solo es necesario establecer una licencia una vez por aplicación (o proceso).

## Establecer una licencia en Aspose.PUB para .NET {#setting-a-license-in-asposepub-for-net}
  
En Aspose.PUB, la licencia puede cargarse desde un archivo, un flujo o un recurso incrustado. Aspose.PUB intenta buscar la licencia en las siguientes ubicaciones:  

- Ruta explícita
- La carpeta que contiene el DLL del componente (incluido en Aspose.PUB)
- La carpeta que contiene el ensamblado que llamó al DLL del componente (incluido en Aspose.PUB)
- La carpeta que contiene el ensamblado de entrada (su .exe)
- Un recurso incrustado en el ensamblado que llamó al DLL del componente (incluido en Aspose.PUB)  

Existen dos métodos comunes para establecer la licencia, los cuales se describen a continuación:

### Aplicar licencia mediante archivo {#apply-license-using-file}
  
La forma más sencilla de establecer una licencia es colocar el archivo de licencia en la misma carpeta que el DLL del componente (incluido en Aspose.PUB) y especificar únicamente el nombre del archivo, sin su ruta.

```java
// Apply a License from File

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.PUB.Net.lic");

Aspose.Pub.License license = new License();
license.SetLicense(licenseFilePath);
```

### Aplicar licencia desde un objeto Stream {#apply-license-from-stream-object}

```java
// Apply a License from Stream Object

string licenseFilePath = Path.Combine(LicenseDir, "Aspose.PUB.Net.lic");
FileStream licenseStream = new FileStream(licenseFilePath, FileMode.Open);

Aspose.Pub.License license = new License();
license.SetLicense(licenseStream);
licenseStream.Close();
```

Cuando invoque el método `SetLicense`, el nombre de la licencia debe coincidir exactamente con el nombre de su archivo de licencia. Por ejemplo, puede cambiar el nombre del archivo de licencia a "Aspose.PUB.lic.xml". Luego, en su código, debe utilizar el nombre modificado de la licencia (es decir, `Aspose.Pub.lic.xml`) para el método `SetLicense`.

### Incluir el archivo de licencia como un recurso incrustado  {#including-the-license-file-as-an-embedded-resource}
  
Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama a la DLL del componente (incluida en Aspose.PUB). Para incluir el archivo de licencia como un recurso incrustado, realice los siguientes pasos:  

- En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto mediante el menú Archivo → Agregar elemento existente…
- Seleccione el archivo en el Explorador de soluciones y establezca Acción de compilación en Recurso incrustado en la ventana Propiedades
- Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), no es necesario invocar los métodos `GetExecutingAssembly` y `GetManifestResourceStream` de la clase `System.Reflection.Assembly` del marco de trabajo Microsoft .NET. Todo lo que debe hacer es incluir el archivo de licencia como recurso incrustado en su proyecto y pasar el nombre del archivo de licencia al método `SetLicense` de la clase `License`. La clase `License` encontrará automáticamente el archivo de licencia en los recursos incrustados.

Consulte el ejemplo que se muestra a continuación para comprender este método de establecimiento de licencia (incrustada) en sus aplicaciones.

```java
// Apply a License that is embedded in assembly as a resource

// Initialize license object
Aspose.Pub.License license = new License();

// Pass only the name of the license file embedded in the assembly
license.SetLicense("Aspose.PUB.Net.lic");
```

## Aplicar licencia por uso (Metered License) {#apply-metered-license}
  
Aspose.PUB permite a los desarrolladores aplicar una clave por uso (metered key). Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar la licencia por uso. Para más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencia por uso</a>.

Se ha introducido una nueva clase, `Metered`, para aplicar la clave por uso. A continuación se muestra un ejemplo de código que demuestra cómo establecer las claves pública y privada de tipo metered.

```java
// Apply a license using Metered public and private keys

// Initialize the Metered class and set public and private keys
Aspose.Pub.Metered metered = new Aspose.Pub.Metered();

// Call the SetMeteredKey method passing the public and private keys as arguments
metered.SetMeteredKey(
    "<type public key here>",
    "<type private key here>");
```

## Visión general de la funcionalidad de conversión a .pub mediante .NET {#overview-to-pub-conversion-functionality-via-net}
  
Convertir archivos PUB es una opción cuando desea abrir o editar archivos de Microsoft Publisher en otro software. A continuación, se presentan otras razones por las que podría querer convertir archivos PUB:  

- No todos los software ni dispositivos admiten el formato de archivo PUB; por lo tanto, la conversión le permitirá abrirlo y visualizarlo en múltiples plataformas.  

- Si necesita colaborar con otras personas que no tienen Microsoft Publisher, convertir los archivos PUB a un formato común permite que todos accedan y trabajen en los archivos.  

- Convertir archivos PUB a formatos como PDF o XPS le permitirá evitar todos los posibles problemas de impresión.  

- Convertir archivos PUB a un formato más estándar garantiza su accesibilidad a largo plazo, por lo que podrá seguir accediendo a sus documentos en el futuro, incluso si Microsoft Publisher queda obsoleto.  

Existen [varios formatos de archivo a los que puede convertir archivos PUB](/net/pub/supported-file-formats/), como PDF, DOCX (Microsoft Word), RTF (Rich Text Format) o HTML (formato de página web). La elección del formato depende de sus necesidades específicas y del software o plataforma que pretenda utilizar. Además, si desea realizar la conversión en línea sin escribir código alguno, puede utilizar <a href="https://products.conholdate.app/conversion" target="_blank">convertidores multiplataforma</a> para este propósito.  

## Conversión de PUB a PDF mediante C# {#pub-to-pdf-conversion-using-c}
  
Aspose.PUB for .NET puede leer y convertir archivos de publicación (.pub) a <a href="https://wiki.fileformat.com/view/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a>. La clase <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">PubFactory</a> crea contenido a partir de un archivo .pub para su posterior procesamiento mediante la clase Document de la API.

:::info
Actualmente, la API no admite la conversión de imágenes en un archivo PUB a PDF de salida.
:::

El formato de documento portátil (PDF, por sus siglas en inglés) fue introducido por Adobe para representar documentos que pueden leerse en dispositivos digitales. Los archivos PUB requieren que Microsoft Publisher esté instalado en la computadora para poder abrirlos. Aspose.PUB para .NET le permite convertir archivos PUB a PDF, los cuales pueden abrirse en casi todas las computadoras sin necesidad de tener instalado Microsoft Publisher. Los siguientes pasos y fragmento de código muestran cómo convertir PUB a PDF utilizando C# en sus aplicaciones .NET.

:::info
Aspose.PUB para .NET admite la conversión de documentos PUB de varias páginas a PDF utilizando las mismas líneas de código indicadas en este artículo.
:::

El fragmento de código proporcionado utiliza la biblioteca Aspose.PUB para .NET para convertir un archivo de Microsoft Publisher (.pub) a formato PDF. A continuación se presenta un desglose del código:

En estos ejemplos, `DataDir` es el directorio de entrada y `OutputDir` es el directorio de salida. Establézcalos en sus propios directorios y asegúrese de que el directorio de salida exista. Importe los espacios de nombres `Aspose.Pub` y `System.IO` al utilizar los fragmentos en su aplicación.

1. Construya la ruta de entrada con `Path.Combine(DataDir, "halloween-flyer.pub")` y guárdela en `fileName`.  

2. Llame al método `CreateParser` de <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">*PubFactory*</a> con `fileName` para obtener un `IPubParser`.  

3. Llame a `parser.Parse()` para leer el archivo PUB en un objeto `Document` denominado `doc`.  

4. Construya `outPath` con `Path.Combine(OutputDir, "halloween-flyer_out.pdf")`.  

5. Llame a `PubFactory.CreatePdfConverter()` para crear un convertidor PDF y, a continuación, llame a <a href="https://reference.aspose.com/pub/net/aspose.pub/ipdfconverter/converttopdf/" target="_blank" rel="nofollow noopener noreferrer">*ConvertToPdf*</a> con `doc` y `outPath` para guardar el archivo PDF.

```java
// Convert a PUB document to PDF

// Parse the input Publisher document.
string fileName = Path.Combine(DataDir, "halloween-flyer.pub");
IPubParser parser = PubFactory.CreateParser(fileName);
Document doc = parser.Parse();

// Convert the document to PDF and save the result.
string outPath = Path.Combine(OutputDir, "halloween-flyer_out.pdf");
PubFactory.CreatePdfConverter().ConvertToPdf(doc, outPath);
```

## Conversión de PUB a JPEG mediante C# {#pub-to-jpeg-conversion-using-c}
  
El código C# siguiente demuestra la conversión de un archivo de Publisher (.pub) a JPEG utilizando la biblioteca Aspose.PUB para .NET, la cual proporciona <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/" target="_blank" rel="nofollow noopener noreferrer">*PubFactory*</a> y clases relacionadas. A continuación se detalla lo que hace el código:  

1. Construir la ruta de entrada con `Path.Combine(DataDir, "halloween-flyer.pub")`.
2. Crear un `IPubParser` mediante <a href="https://reference.aspose.com/pub/net/aspose.pub/pubfactory/createparser/#createparser_1" target="_blank" rel="nofollow noopener noreferrer">*PubFactory.CreateParser(fileName)*</a>, y luego llamar a `parser.Parse()` para obtener un objeto `Document`.
3. Construir `outPath` con `Path.Combine(OutputDir, "halloween-flyer_out.jpg")`.
4. Llamar a `PubFactory.CreatePubConverter()` para crear un convertidor, y luego llamar a `ConvertToFormat(doc, outPath, PubExportFormats.Jpg)` para guardar el archivo JPEG.  

Puede convertir PUB a otro formato de manera similar, utilizando uno de los <a href="https://reference.aspose.com/pub/net/aspose.pub/pubexportformats/" target="_blank" rel="nofollow noopener noreferrer">*PubExportFormats*</a> admitidos.

```java
// Convert a PUB document to JPEG

// Parse the input Publisher document.
string fileName = Path.Combine(DataDir, "halloween-flyer.pub");
IPubParser parser = PubFactory.CreateParser(fileName);
Document doc = parser.Parse();

// Convert the document to JPEG and save the result.
string outPath = Path.Combine(OutputDir, "halloween-flyer_out.jpg");
PubFactory.CreatePubConverter().ConvertToFormat(doc, outPath, PubExportFormats.Jpg);
```

## Características del producto {#product-features}
  
Las siguientes son las características principales de Aspose.Imaging:

- Leer imágenes  
- Escribir imágenes  
- Dibujar imágenes  
- Procesar imágenes  
- Convertir entre formatos  

### Lista de características {#feature-list}
  
#### Creación de imágenes {#image-creations}
  
- Bmp  
- Tiff  
- Jpeg (a partir de la v2.3, admite su propio códec)  
- Png (a partir de la v2.5, admite su propio códec)  
- Gif  
- Psd (a partir de la v2.7, se agregó compatibilidad con codificación/decodificación de miniaturas Jpeg)  
- Jpeg2000 (v2.8)  
- WebP  
- Ico  

#### Carga de imágenes {#image-loading}
  
- Bmp  
- Tiff  
- Jpeg  
- Png  
- Gif  
- Psd  
- Wmf  
- Emf  
- Jpeg2000 (v2.8)  
- Djvu  
- WebP  
- Dicom  
- Svg  
- Dng  
- ODG  
- OTG  
- Dib  
- Cmx  
- Ico  

#### Procesamiento de datos sin procesar {#raw-data-processing}
  
- Bmp (v2.4, solo carga parcial de datos sin procesar)  
- Gif  
- Jpeg  
- Jpeg2000  
- Png  
- Psd  
- Tiff  

#### Compresión Bmp {#bmp-compression}
  
- Rle  

#### Compresiones Psd {#psd-compressions}
  
- Rle  
- Sin compresión  

#### Compresiones Tiff {#tiff-compressions}
  
- CCITT3  
- CCITT4  
- Rle  
- Sin compresión  
- Lzw  
- Deflate (v2.6)  
- Carga de otros formatos (además de los admitidos por GDI+)  
- Jpeg (solo 8 bps)  
- Espacios de color Tiff  
- RGB  
- CMYK  
- CIELAB  
- YCrCb  

#### Espacios de color Tiff {#tiff-color-spaces}
  
- RGB  
- CMYK (solo lectura) (v2.1)  
- CIELAB (solo lectura) (v2.1)  
- YCrCb  

#### Características de dibujo {#drawing-features}
  
- Imágenes grandes  
- Rotación  
- Volteo  
- Escalado  
- Sistema de caché  
- Imágenes personalizadas del usuario  
- Certificado Sha-2 (v2.0)  
- Lectura/escritura de datos Exif (v2.0)  
- Recuperación de datos Tiff (v2.2)  
- Dithering (v2.2)  
- Firma dual (v2.3)  
- Recorte (v2.3)  
- Exportación de vector a mapa de bits  
- Actualización de brillo, contraste y gamma (v2.6)  
- Soporte de datos Xmp  
- Dibujo y relleno de formas básicas (línea, polígono, rectángulo, curva cúbica de Bézier, curva, arco, elipse, cuña, ruta)  
- Borrado  
- Recorte a región rectangular (se implementó recorte a los límites de la imagen para los algoritmos de dibujo existentes)  
- Transformaciones matriciales (las transformaciones matriciales están implementadas parcialmente, principalmente para necesidades internas del motor de dibujo)  

#### Características de procesamiento de imágenes {#image-processing-features}
  
- Enmascaramiento de imágenes  
- Filtros de imágenes  
- *Corrección de inclinación de imágenes*

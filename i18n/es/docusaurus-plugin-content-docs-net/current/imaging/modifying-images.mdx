## Dithering para imágenes raster {#dithering-for-raster-images}
  
El dithering es una técnica que crea la ilusión de nuevos colores y tonos variando el patrón de puntos que realmente conforman una imagen. Es el método más común para reducir el rango de colores de las imágenes hasta 256 (o menos) colores. Aspose.Imaging proporciona soporte para dithering en la clase <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage" target="_blank" rel="nofollow noopener noreferrer">RasterImage</a> mediante el método <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage" target="_blank" rel="nofollow noopener noreferrer">Dither</a>, el cual acepta dos parámetros. El primero es de tipo DitheringMethod y se aplica con dos opciones posibles: FloydSteinbergDithering y ThresholdDithering. El segundo parámetro del método <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage" target="_blank" rel="nofollow noopener noreferrer">Dither</a> es el BitCount en formato entero. BitCount define el tamaño de muestreo para el resultado del dithering. El valor predeterminado es 1, que representa blanco y negro, mientras que los valores permitidos son 1, 4 y 8, generando paletas con 2, 4 y 256 colores, respectivamente.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageOptions;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// Create an instance of JpegImage and load an image as of JpegImage
using (var image = (JpegImage)Image.Load(dataDir + "template.jpg"))
{
    // Peform Floyd Steinberg dithering on the current image and Save the resultant image
    image.Dither(DitheringMethod.ThresholdDithering, 4);
    image.Save(dataDir + "result.bmp");
}

File.Delete(dataDir + "result.bmp");
```

## Ajuste del brillo, contraste y gamma {#adjusting-brightness-contrast-and-gamma}
  
El ajuste de color en imágenes digitales es una de las características fundamentales que ofrecen la mayoría de las bibliotecas de procesamiento de imágenes. Los ajustes de color pueden clasificarse de la siguiente manera:

1. **Brillo**: se refiere a la luminosidad u oscuridad del color. Aumentar el brillo de una imagen aclara todos los colores, mientras que disminuirlo oscurece todos los colores.
2. **Contraste**: se refiere a hacer más evidentes los objetos o detalles dentro de una imagen. Aumentar el contraste de una imagen incrementa la diferencia entre las áreas claras y oscuras, de modo que las áreas claras se vuelven más luminosas y las oscuras más oscuras. Disminuir el contraste hace que las áreas claras y oscuras permanezcan aproximadamente iguales, pero la imagen en general se vuelve más homogénea.
3. **Gamma**: optimiza el contraste y el brillo de la iluminación indirecta que ilumina un objeto en la imagen.

### Ajuste del brillo {#adjusting-brightness}
  
La API de Aspose.Imaging para .NET proporciona el método <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage/methods/adjustbrightness" target="_blank" rel="nofollow noopener noreferrer">Adjustbrightness</a> para la clase <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage" target="_blank" rel="nofollow noopener noreferrer">RasterImage</a>, que puede utilizarse para ajustar el **brillo** pasando un valor entero como parámetro. El valor más alto del parámetro indica una imagen más brillante. A continuación se muestran la imagen original y la imagen resultante para su comparación.

### Ajustar Gamma {#adjusting-gamma}
  
El método `AdjustGamma` expuesto por la clase <a href="https://reference.aspose.com/imaging/net/aspose.imaging/rasterimage" target="_blank" rel="nofollow noopener noreferrer">RasterImage</a> tiene dos versiones. Una de las sobrecargas acepta un valor `float` y realiza la corrección **Gamma** para los coeficientes de los canales rojo, azul y verde. En cambio, la otra sobrecarga acepta tres parámetros `float` que representan cada coeficiente de color por separado. El siguiente ejemplo de código demuestra cómo aplicar `AdjustGamma` a una imagen.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageOptions;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// Load an image in an instance of Image
using (Image image = Image.Load(dataDir + "template.jpg"))
{
    // Cast object of Image to RasterImage
    RasterImage rasterImage = (RasterImage)image;

    // Check if RasterImage is cached and Cache RasterImage for better performance
    if (!rasterImage.IsCached)
    {
        rasterImage.CacheData();
    }

    // Adjust the contrast
    rasterImage.AdjustGamma(10);

    // Create an instance of TiffOptions for the resultant image, Set various properties for the object of TiffOptions and Save the resultant image to TIFF format
    TiffOptions tiffOptions = new TiffOptions(TiffExpectedFormat.Default);
    tiffOptions.BitsPerSample = new ushort[] { 8, 8, 8 };
    tiffOptions.Photometric = TiffPhotometrics.Rgb;
    rasterImage.Save(dataDir + "result.tiff", tiffOptions);
}

File.Delete(dataDir + "result.tiff");
```

## Desenfocar una imagen {#blur-an-image}

Este artículo demuestra el uso de Aspose.Imaging para .NET para aplicar el efecto de desenfoque a una imagen. Las API de Aspose.Imaging han expuesto métodos eficientes y fáciles de usar para lograr este objetivo. Aspose.Imaging para .NET ha expuesto la clase **GaussianBlurFilterOptions** para crear el efecto de desenfoque sobre la marcha. La clase **GaussianBlurFilterOptions** requiere valores de radio y sigma para generar el efecto de desenfoque en una imagen. Los pasos para realizar el desenfoque son tan sencillos como los que se indican a continuación:

1. Cargar una imagen mediante el método de fábrica **Load** expuesto por la clase **Image**.
2. Convertir la imagen en **RasterImage**.
3. Crear una instancia de la clase **GaussianBlurFilterOptions** utilizando el constructor predeterminado o proporcionando los valores de radio y sigma en el constructor.
4. Llamar al método **RasterImage.Filter**, especificando como parámetros el rectángulo que delimita la imagen y una instancia de la clase **GaussianBlurFilterOptions**.
5. Guardar los resultados.

El siguiente ejemplo de código demuestra cómo aplicar el efecto de desenfoque a una imagen.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// Load the image
using (Image image = Image.Load(dataDir + "template.gif"))
{
    // Convert the image into RasterImage, Pass Bounds[rectangle] of image and GaussianBlurFilterOptions instance to Filter method and Save the results
    RasterImage rasterImage = (RasterImage)image;
    rasterImage.Filter(rasterImage.Bounds, new GaussianBlurFilterOptions(5, 5));
    rasterImage.Save(dataDir + "result.gif");
}

File.Delete(dataDir + "result.gif");
```

## Verificar la transparencia de la imagen  {#verify-image-transparency}
  
Este artículo demuestra el uso de Aspose.Imaging para .NET para comprobar la transparencia de una imagen. Los pasos para verificar la transparencia de la imagen son tan sencillos como los que se indican a continuación:

1. Cargar una imagen mediante el método de fábrica `Load` expuesto por la clase `Image`.
2. Comprobar la opacidad de la imagen; si la opacidad es cero, la imagen es transparente.
3. El siguiente ejemplo de código demuestra cómo verificar si una imagen es transparente o no.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Png;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

using (PngImage image = (PngImage)Image.Load(dataDir + "template.png"))
{
    float opacity = image.ImageOpacity; // opacity = 0,470798    
    if (opacity == 0)
    {
        // The image is fully transparent.
    }
}
```

## Exportar texto como forma durante la conversión de EMF MetaFile {#exporting-text-as-shape-while-converting-emf-metafile}
  
Mediante Aspose.Imaging para .NET, los desarrolladores pueden obtener texto como formas al convertir EMF al formato SVG. Este tema explica detalladamente cómo convertir texto en forma durante la conversión de EMF a SVG. Aspose.Imaging para .NET proporciona la propiedad **TextAsShapes** para obtener texto como forma al convertir un metaarchivo EMF. A continuación se muestra una demostración en código de dicha funcionalidad.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Png;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

using (Image image = Image.Load(dataDir + "template.emf"))
{
    EmfRasterizationOptions emfRasterizationOptions = new EmfRasterizationOptions();
    emfRasterizationOptions.BackgroundColor = Color.White;
    emfRasterizationOptions.PageWidth = image.Width;
    emfRasterizationOptions.PageHeight = image.Height;
    image.Save(dataDir + "result.svg", new SvgOptions
    {
        VectorRasterizationOptions = emfRasterizationOptions,
        TextAsShapes = true
    });

    image.Save(dataDir + "result2.svg", new SvgOptions
    {
        VectorRasterizationOptions = emfRasterizationOptions,
        TextAsShapes = false
    });
}

File.Delete(dataDir + "result.svg");
File.Delete(dataDir + "result2.svg");
```

## Implementar compresor GIF con pérdida {#implementlossy-gif-compressor}
  
Con Aspose.Imaging para .NET, los desarrolladores pueden establecer la diferencia de píxeles. La compresión GIF se basa en un «diccionario» de cadenas de píxeles observadas. El codificador normal busca en el diccionario la cadena más larga de píxeles que coincida exactamente con los píxeles de la imagen. El codificador con pérdida selecciona la cadena más larga de píxeles que sea «suficientemente similar» a los píxeles de la imagen. A continuación se muestra una demostración de código de esta funcionalidad.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Png;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// Sets the maximum allowed pixel difference. If greater than zero, lossy compression will be used.
// Recommended value for optimal lossy compression is 80. 30 is very light compression, 200 is heavy.
GifOptions gifExport = new GifOptions();
gifExport.MaxDiff = 80;

using (Image image = Image.Load(dataDir + "template.gif"))
{
    image.Save(dataDir + "result.gif", gifExport);
}

File.Delete(dataDir + "result.gif");
```

## Redimensionar archivo WMF al convertirlo a PNG {#resizing-wmf-file-while-converting-to-png}
  
Con Aspose.Imaging para .NET, los desarrolladores pueden redimensionar el archivo metafile WMF al convertirlo a un formato raster. Este tema explica el enfoque para cargar archivos metafile existentes, redimensionarlos y convertirlos a formato raster. Aspose.Imaging para .NET proporciona la clase **Image** para cargar archivos WMF, la cual también se puede utilizar para redimensionar y guardar la imagen en formato PNG. El siguiente fragmento de código muestra cómo redimensionar el archivo WMF al convertirlo a PNG.

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Png;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// Load an existing WMF image
using (Image image = Image.Load(dataDir + "template.emf"))
{
    // Call the resize method of Image class and width,height values and Calculate new PNG image height
    image.Resize(100, 100);
    double k = (image.Width * 1.00) / image.Height;

    // Create an instance of EmfRasterizationOptions class and set different properties
    EmfRasterizationOptions emfRasterization = new EmfRasterizationOptions
    {
        BackgroundColor = Color.WhiteSmoke,
        PageWidth = 100,
        PageHeight = (int)Math.Round(100 / k),
        BorderX = 5,
        BorderY = 10
    };

    // Create an instance of PngOptions class and provide rasterization option
    ImageOptionsBase imageOptions = new PngOptions();
    imageOptions.VectorRasterizationOptions = emfRasterization;

    // Call the save method, provide output path and PngOptions to convert the WMF file to PNG and save the output
    image.Save(dataDir + "result.png", imageOptions);
}
 
File.Delete(dataDir + "result.png");
```

## Soporte para leer valores de píxeles de 48 bpp {#support-for-reading-pixel-values-of-48-bpp}
  
Con Aspose.Imaging para .NET, los desarrolladores pueden cargar componentes de color de 16 bits desde TIFF RGB 48Bpp. Tenga en cuenta que solo se admiten los TIFF con las siguientes opciones:

- Modelo de color: RGB 48Bpp o RGBA 64Bpp
- Compresión: Lzw, Deflate, Sin compresión
- Orden de bytes: Intel (Little Endian), Motorola (Big Endian)
- Estructura: Solo por bandas (Striped)
- Configuración planar: Contigua, Separada

El perfil ICC incrustado no se aplica a los componentes de color de 16 bits. A continuación se muestra una demostración de código de dicha funcionalidad. 

```csharp
using Aspose.Imaging;
using Aspose.Imaging.FileFormats.Jpeg;
using Aspose.Imaging.FileFormats.Png;
using Aspose.Imaging.FileFormats.Tiff.Enums;
using Aspose.Imaging.ImageFilters.FilterOptions;
using Aspose.Imaging.ImageOptions;
using System;
using System.IO;

string templatesFolder = @"c:\Users\USER\Downloads\templates\";
string dataDir = templatesFolder;

// ICC profile is not applied for 16-bit color components at the moment, so disable that option explicitly.
LoadOptions loadOptions = new LoadOptions();
loadOptions.UseIccProfileConversion = false;

Rectangle desiredArea = new Rectangle(470, 1350, 30, 30);

using (RasterImage image = (RasterImage)Image.Load(dataDir + "template.tiff", loadOptions))
{
	int[] colors32Bit = image.LoadArgb32Pixels(image.Bounds);
}
```

## Información general {#overview}
  
El artículo explica los siguientes temas utilizando la biblioteca de manipulación de archivos 3D en C#.

- Crear una escena 3D vacía en C# desde cero  
- Leer o cargar una escena 3D existente en C#  
- Guardar la escena 3D en formatos 3D compatibles mediante C#  
- Trabajar con propiedades de escena 3D en C#  

## Crear una escena 3D vacía y guardarla en formatos de archivo 3D compatibles {#create-an-empty-3d-scene-and-save-in-supported-3d-file-formats}
  
La API de Aspose.3D admite la creación de nuevas escenas 3D desde cero y su posterior guardado en cualquier formato de archivo compatible. Asimismo, los desarrolladores pueden cargar una escena 3D existente para modificarla, agregarle contenido o procesarla.

### Crear un documento de escena 3D {#creating-a-3d-scene-document}
  
Siga estos pasos en C# para crear un documento de escena 3D mediante las API de Aspose.3D:

1. Cree una instancia de la clase <a href="https://reference.aspose.com/3d/net/aspose.threed/scene" target="_blank" rel="nofollow noopener noreferrer">`Scene`</a>, que representa un documento de escena 3D.  
2. Genere un documento de escena 3D llamando al método <a href="https://reference.aspose.com/3d/net/aspose.threed/scene/methods/save" target="_blank" rel="nofollow noopener noreferrer">`Save`</a> del objeto de la clase Scene.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET

// Create an object of the Scene class
Scene scene = new Scene();
// Save 3D scene document
scene.Save("document.fbx");
```

## Lectura de una escena 3D {#reading-a-3d-scene}
  
Con la API de Aspose.3D, los desarrolladores pueden cargar todos los documentos 3D admitidos. Los constructores disponibles de la clase `Scene` permiten realizar esta tarea y aceptan una cadena de ruta de archivo válida. Los formatos de archivo legibles admitidos son los siguientes:

1. FBX 7.5 (ASCII, binario)  
2. FBX 7.4 (ASCII, binario)  
3. FBX 7.3 (ASCII, binario)  
4. FBX 7.2 (ASCII, binario)  
5. FBX 6.1 (ASCII, binario)  
6. STL (ASCII, binario)  
7. WavefrontOBJ  
8. Discreet3DS  
9. Universal3D  
10. Collada  
11. glTF (ASCII, binario)  
12. Maya (ASCII, binario)  
13. OpenUSD (USD, USDZ)  
14. Blender  
15. DXF  
16. PLY (ASCII, binario)  
17. X (ASCII, binario)  
18. Draco  
19. 3MF  
20. RVM (texto, binario)  
21. ASE  

Los constructores de la clase `Scene` detectan internamente el formato del documento 3D.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
// The path to the documents directory.

// Initialize a Scene class object
Scene scene = new Scene();
// Load an existing 3D document
scene.Open("document.fbx");
```

## Trabajo con propiedades de escenas 3D  {#working-with-3d-scene-properties}
  
La API de Aspose.3D le permite leer las propiedades de escenas 3D mediante los nodos secundarios de la escena. El siguiente ejemplo de código en C# demuestra el uso de esta funcionalidad.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
Scene scene = Scene.FromFile("EmbeddedTexture.fbx");
Material material = scene.RootNode.ChildNodes[0].Material;
PropertyCollection props = material.Properties;
//List all properties using foreach
foreach (var prop in props)
{
    Console.WriteLine("{0} = {1}", prop.Name, prop.Value);
}
//or using ordinal for loop
for (int i = 0; i < props.Count; i++)
{
    var prop = props[i];
    Console.WriteLine("{0} = {1}", prop.Name, prop.Value);
}
//Get property value by name
var diffuse = props["Diffuse"];
Console.WriteLine(diffuse);
//modify property value by name
props["Diffuse"] = new Vector3(1, 0, 1);
//Get property instance by name
Property pdiffuse = props.FindProperty("Diffuse");
Console.WriteLine(pdiffuse);
//Since Property is also inherited from A3DObject
//It's possible to get the property of the property
Console.WriteLine("Property flags = {0}", pdiffuse.GetProperty("flags"));
//and some properties that only defined in FBX file:
Console.WriteLine("Label = {0}", pdiffuse.GetProperty("label"));
Console.WriteLine("Type Name = {0}", pdiffuse.GetProperty("typeName"));
//so traversal on property's property is possible
foreach (var pp in pdiffuse.Properties)
{
    Console.WriteLine("Diffuse.{0} = {1}", pp.Name, pp.Value);
}
```

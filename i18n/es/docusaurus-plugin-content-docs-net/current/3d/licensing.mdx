Resumen de los requisitos de licencia y las limitaciones de la versión de evaluación para el procesamiento de formatos de archivos 3D en C#.

## Limitaciones de la versión de evaluación {#evaluation-version-limitations}
  
Una versión de evaluación gratuita de Aspose.3D para .NET puede descargarse desde la sección de descargas del sitio web de Aspose en: <a href="https://www.nuget.org/packages/Aspose.3D" target="_blank" rel="nofollow noopener noreferrer">Download Aspose.3D API</a>.

### Limitación {#limitation}
  
La versión de evaluación proporciona todas las funciones, excepto las siguientes:

- Los usuarios solo pueden abrir/importar un máximo de 50 documentos 3D en una escena.
- Cada nodo puede tener como máximo 5 nodos secundarios.
- Cada nodo puede tener como máximo 2 entidades adjuntas.
- Cada geometría puede tener como máximo 2 elementos de vértice adjuntos.
- Cada nodo puede tener como máximo 1 material.
- Los usuarios solo pueden guardar un máximo de 50 documentos 3D en una escena.
- Los usuarios también verán una marca de agua de evaluación en las imágenes renderizadas y en todos los demás archivos de salida.

:::info
Si está utilizando Aspose.3D sin una licencia adecuada, podría activarse una `Aspose.ThreeD.TrialException` cuando se alcancen las restricciones para usuarios no licenciados; puede desactivar esta excepción mediante:

- <a href="https://purchase.conholdate.com/buy" target="_blank">Adquirir una licencia completa con todas las funciones</a>.
- Solicitar una licencia temporal de 30 días; consulte <a href="https://purchase.conholdate.com/temporary-license" target="_blank">¿Cómo obtener una licencia temporal?</a> para obtener más información.
- Establecer `Aspose.ThreeD.TrialException.SuppressTrialException` en `true`; la `TrialException` no se generará durante la llamada a `Open/Save` en Scene, pero las restricciones mencionadas anteriormente no se eliminarán.
- Utilizar manualmente un bloque `try/catch` en `Scene.Open/Save`; esta excepción es únicamente una notificación, ignorarla no afectará la carga/guardado de la escena.
  :::

## Aplicar licencia mediante un objeto archivo o flujo  {#apply-license-using-file-or-stream-object}

La licencia puede cargarse desde un [archivo](/net/3d/licensing/#Licensing-LoadingaLicensefromFile) o un [objeto de flujo](/net/3d/licensing/#Licensing-LoadingaLicensefromaStreamObject). Aspose.3D para .NET buscará la licencia en las siguientes ubicaciones:

1. Ruta explícita.
2. La carpeta que contiene Aspose.3D.dll.
3. La carpeta que contiene el ensamblado que llamó a Aspose.3D.dll.
4. La carpeta que contiene el ensamblado de entrada (su .exe).
5. Un recurso incrustado en el ensamblado que llamó a Aspose.3D.dll.

La forma más sencilla de configurar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.3D.dll y especificar el nombre del archivo (sin ruta) como se muestra en el siguiente ejemplo.

:::info
Si está utilizando alguna otra API de Aspose para .NET junto con Aspose.3D para .NET, especifique el espacio de nombres para la licencia como `Aspose.ThreeD.License`.
:::

### Carga de una licencia desde un archivo  {#loading-a-license-from-file}
  
La forma más sencilla de aplicar una licencia es colocar el archivo de licencia en la misma carpeta que el archivo Aspose.3D.dll y especificar únicamente el nombre del archivo, sin incluir una ruta.

:::info
Cuando llame al método `SetLicense`, el nombre de la licencia que pase debe ser el del archivo de licencia. Por ejemplo, si cambia el nombre del archivo de licencia a "Aspose.3D.lic.xml", pase ese nombre de archivo al método `threeD.SetLicense(…)`.
:::

**Ejemplo:**

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
Aspose.ThreeD.License license = new Aspose.ThreeD.License();
license.SetLicense("Aspose._3D.lic");
```

### Carga de una licencia desde un objeto de flujo  {#loading-a-license-from-a-stream-object}
  
El siguiente ejemplo muestra cómo cargar una licencia desde un flujo.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
Aspose.ThreeD.License license = new Aspose.ThreeD.License();
FileStream myStream = new FileStream("Aspose._3D.lic", FileMode.Open);
license.SetLicense(myStream);
```

## Aplicar licencia mediante recurso incrustado  {#apply-license-using-embedded-resource}

Una forma de aplicar una licencia es configurarla mediante un objeto de archivo o flujo. Otra forma práctica de empaquetar la licencia junto con su aplicación y asegurarse de que no se pierda es incluirla como un recurso incrustado en uno de los ensamblados que llama al DLL del componente (incluido en Aspose.3D).

Para incluir el archivo de licencia como recurso incrustado:

1. En Visual Studio .NET, incluya el archivo de licencia (.lic) en el proyecto seleccionando **Archivo**, luego **Agregar elemento existente** y finalmente **Agregar**.
2. Seleccione el archivo en el Explorador de soluciones.
3. Establezca la **Acción de compilación** en **Recurso incrustado** en la ventana Propiedades.
4. Para acceder a la licencia incrustada en el ensamblado (como recurso incrustado), simplemente agregue el archivo de licencia como recurso incrustado al proyecto y pase el nombre del archivo de licencia al método SetLicense. La clase License encuentra automáticamente el archivo de licencia en los recursos incrustados. No es necesario llamar a los métodos GetExecutingAssembly y GetManifestResourceStream de la clase System.Reflection.Assembly en el marco de trabajo Microsoft .NET.

El siguiente fragmento de código se utiliza para configurar la licencia.

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
// Instantiate the License class
Aspose.ThreeD.License license = new Aspose.ThreeD.License();

// Pass only the name of the license file embedded in the assembly
license.SetLicense("Aspose._3D.lic");
```

## Aplicar licencia por uso (Metered License) {#apply-metered-license}
  
La API de Aspose.3D para .NET permite a los desarrolladores aplicar una licencia por uso (metered license). Se trata de un nuevo mecanismo de licenciamiento que se utilizará junto con el método de licenciamiento existente. Los clientes que deseen ser facturados según el uso de las características de la API pueden utilizar el licenciamiento por uso. Para obtener más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licenciamiento por uso</a>.

Se ha agregado una nueva clase <a href="https://reference.aspose.com/3d/net/aspose.threed/metered" target="_blank" rel="nofollow noopener noreferrer">`Metered`</a> para aplicar la clave por uso. El siguiente ejemplo de código muestra cómo establecer las claves pública y privada por uso:

```csharp
// For complete examples and data files, please go to https://github.com/aspose-3d/Aspose.3D-for-.NET
// Initialize a Metered license class object
Aspose.ThreeD.Metered metered = new Aspose.ThreeD.Metered();
// Set public and private keys
metered.SetMeteredKey("your-public-key", "your-private-key");
```

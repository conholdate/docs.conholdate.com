<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite convertir documentos web en archivos PDF, PNG y JPEG. Utilice esta biblioteca para visualizar archivos web dentro de su aplicación .NET.

Para comenzar a utilizar la API de GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase al constructor de la clase el documento web que desea visualizar; puede cargar el documento desde un archivo o un flujo. Luego, invoque una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento a formato PDF o imagen. Estos métodos le permiten renderizar todo el documento o páginas específicas.

<a href="https://products.groupdocs.app/viewer/web" target="_blank" rel="nofollow noopener noreferrer">Ver archivos web en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>

## Formatos de archivo web admitidos {#supported-web-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo web:

* <a href="https://docs.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">Formato Hypertext Markup Language</a> (.HTML / .HTM)  
* <a href="https://docs.fileformat.com/web/mhtml/" target="_blank" rel="nofollow noopener noreferrer">Formato MIME HTML</a> (.MHTML)  
* <a href="https://docs.fileformat.com/web/mht/" target="_blank" rel="nofollow noopener noreferrer">Web Archive MHTML</a> (.MHT)  
* <a href="https://docs.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">Formato Compiled HTML Help</a> (.CHM)

GroupDocs.Viewer puede detectar automáticamente el formato del documento analizando su contenido.

## Renderizar documentos web como PDF {#render-web-documents-as-pdf}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo web a PDF. Las propiedades de la clase `PdfViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede proteger el archivo PDF resultante, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado a PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Create a PDF file for the document.
    // Specify the PDF file name.
    var viewOptions = new PdfViewOptions("output.pdf");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("groupdocs-documentation.mhtml")
            ' Create a PDF file for the document.
            ' Specify the PDF file name.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Renderizar documentos web como PNG {#render-web-documents-as-png}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo web a PNG. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the web file to PNG.
    // {0} is replaced with the page numbers in the output image names.
    var viewOptions = new PngViewOptions("output_{0}.png");
    viewer.View(viewOptions);
}
```

## Convertir archivos CHM a HTML {#convert-chm-files-to-html}
  
<a href="https://docs.fileformat.com/web/chm/" target="_blank" rel="nofollow noopener noreferrer">CHM</a> es un formato propietario de Microsoft para ayuda en línea, comúnmente utilizado en documentación de software. Con GroupDocs.Viewer, puede convertir un archivo CHM a HTML para visualizarlo en un navegador web. Para ello, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a>. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.chm"))
{
    // Convert the CHM file to HTML.
    // {0} is replaced with the page numbers in the output file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("chm_result_{0}.html");
    // Enable the following option to display all CHM content on a single HTML page.
    // options.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilo) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.chm"))
{
    // Convert the CHM file to HTML.
    // Specify the output file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.chm")
            ' Convert the CHM file to HTML.
            ' Specify the output file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

## Especificar opciones de renderizado  {#specify-rendering-options}
  
GroupDocs.Viewer admite la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions</a>, que le permite especificar distintas opciones para el renderizado de archivos web. Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/webdocumentoptions" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions</a> en una de las siguientes clases (según el formato del archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

### Ajustar los márgenes de página  {#adjust-page-margins}
  
Utilice las siguientes propiedades para especificar el tamaño de los márgenes de página en los archivos de salida al convertir sus documentos web a formatos HTML, PDF e imágenes:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/topmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.TopMargin</a> — Especifica la distancia (en puntos) entre el borde superior de la página y el límite superior del texto del cuerpo. El valor predeterminado es 72 puntos.  
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/bottommargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.BottomMargin</a> — Especifica la distancia (en puntos) entre el borde inferior de la página y el límite inferior del texto del cuerpo. El valor predeterminado es 72 puntos.  
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/leftmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.LeftMargin</a> — Especifica la distancia (en puntos) entre el borde izquierdo de la página y el límite izquierdo del texto del cuerpo. El valor predeterminado es 5 puntos.  
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/rightmargin" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.RightMargin</a> — Especifica la distancia (en puntos) entre el borde derecho de la página y el límite derecho del texto del cuerpo. El valor predeterminado es 5 puntos.  

El ejemplo siguiente convierte un documento web a PDF y especifica los márgenes de página para el archivo de salida. 

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the size of page margins in points.
    viewOptions.WebDocumentOptions.LeftMargin = 40;
    viewOptions.WebDocumentOptions.RightMargin = 40;
    viewOptions.WebDocumentOptions.TopMargin = 40;
    viewOptions.WebDocumentOptions.BottomMargin = 40;
    viewer.View(viewOptions);
}
```

</TabItem>

### Establecer el tamaño de página de salida {#set-the-output-page-size}
  
GroupDocs.Viewer le permite especificar el tamaño de página para el archivo de salida cuando convierte su documento web a otro formato. Asigne un miembro de la enumeración <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> a la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/webdocumentoptions/properties/pagesize" target="_blank" rel="nofollow noopener noreferrer">WebDocumentOptions.PageSize</a> para seleccionar uno de los tamaños de página predefinidos (Letter, Ledger, A0, A1, A2, A3 o A4).  

El siguiente ejemplo especifica el tamaño de página para el archivo PDF de salida:

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("groupdocs-documentation.mhtml"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the page size.
    viewOptions.WebDocumentOptions.PageSize = PageSize.A3;
    viewer.View(viewOptions);
}
```

</TabItem>

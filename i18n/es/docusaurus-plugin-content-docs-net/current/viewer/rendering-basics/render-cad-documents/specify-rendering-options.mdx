GroupDocs.Viewer incluye la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions" target="_blank" rel="nofollow noopener noreferrer">CadOptions</a>, que le permite especificar distintas opciones para [renderizar archivos CAD](/net/viewer/render-cad-documents/). Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/cadoptions" target="_blank" rel="nofollow noopener noreferrer">CadOptions</a> en una de las siguientes clases (según el formato del archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

## Especificar el color de fondo {#specify-the-background-color}
  
Utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">CadOptions.BackgroundColor</a> para especificar el color de fondo del archivo de salida.  

El siguiente fragmento de código convierte un dibujo CAD a PDF y establece el color de fondo de las páginas PDF en amarillo claro:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Drawing;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("HousePlan.dwg"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");

    // Specify the background color.
    viewOptions.CadOptions.BackgroundColor = Argb32Color.Transparent;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Drawing
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("HousePlan.dwg")
            ' Convert the document to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
        
            ' Specify the background color.
            viewOptions.CadOptions.BackgroundColor = Argb32Color.Transparent
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Configurar el tamaño de la imagen de salida {#configure-the-output-image-size}
  
<a name="ctors"></a>Al representar un dibujo CAD, GroupDocs.Viewer genera una imagen cuya dimensión más grande (ancho o alto) se establece en 2000 píxeles. La otra dimensión se calcula según la relación de aspecto del dibujo original. Puede utilizar los siguientes métodos para modificar el ancho y el alto del archivo de salida:

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbywidth" target="_blank" rel="nofollow noopener noreferrer">CadOptions.ForRenderingByWidth</a>: especifica el ancho de la imagen de salida en píxeles. El alto de la imagen se calcula según la relación de aspecto del dibujo CAD original.  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbyheight" target="_blank" rel="nofollow noopener noreferrer">CadOptions.ForRenderingByHeight</a>: especifica el alto de la imagen de salida en píxeles. El ancho de la imagen se calcula según la relación de aspecto del dibujo CAD original.  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbywidthandheight" target="_blank" rel="nofollow noopener noreferrer">CadOptions.ForRenderingByWidthAndHeigh</a>: especifica el ancho y el alto de la imagen de salida en píxeles.  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbyscalefactor" target="_blank" rel="nofollow noopener noreferrer">CadOptions.ForRenderingByScaleFactor</a>: especifica un factor de escala que se aplicará a la imagen de salida. Los valores comprendidos entre 0 y 1 reducen el tamaño de la imagen, y los valores mayores que 1 lo aumentan.  

El siguiente ejemplo convierte un dibujo CAD al formato PNG y reduce el ancho y el alto de la imagen de salida en un 50 %:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("HousePlan.dwg"))
{
    // Convert the diagram to PNG.
    var viewOptions = new PngViewOptions("output.png");
    // Specify a scale factor.
    viewOptions.CadOptions = CadOptions.ForRenderingByScaleFactor(0.5f);
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

            viewOptions.CadOptions = CadOptions.ForRenderingByScaleFactor(0.5F)
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

Cuando se procesan todas las plantillas/hojas contenidas en un archivo CAD (la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> tiene el valor `true`), cada plantilla/hoja se procesa como una página/imagen independiente y tiene su propio tamaño. En este caso, si solo se especifica el valor de <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbywidth" target="_blank" rel="nofollow noopener noreferrer">width</a> o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbyheight" target="_blank" rel="nofollow noopener noreferrer">height</a>, el otro lado se escala proporcionalmente para mantener la relación de aspecto de cada plantilla/hoja. Si se establecen tanto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/methods/forrenderingbywidthandheight" target="_blank" rel="nofollow noopener noreferrer">width and height</a>, todas las imágenes generadas tendrán el mismo tamaño y podrían verse distorsionadas. Para evitar esto, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layoutname" target="_blank" rel="nofollow noopener noreferrer">CadOptions.LayoutName</a> para procesar cada plantilla/hoja por separado y definir su tamaño.

### Aplicar la configuración del archivo PC3 {#apply-the-pc3-file-settings}
  
AutoCAD le permite configurar la configuración de la impresora y guardarla como un archivo PC3 (Plotter Configuration Version 3) para su uso posterior. Con GroupDocs.Viewer, puede aplicar los valores de ancho y alto de un archivo PC3 al archivo de salida al convertir su dibujo CAD a formato HTML, PDF o imagen. Utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/pc3file" target="_blank" rel="nofollow noopener noreferrer">CadOptions.Pc3File</a> para la vista de destino, especificando la ruta al archivo PC3 que contiene la configuración deseada. La ubicación predeterminada de los archivos PC3 es "*C:\Users\\[Username]\\AppData\Roaming\Autodesk\AutoCAD [Version]\\[Version Code]\\[Language]\Plotters*".

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.dwg"))
{
    // Convert the diagram to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify a path to the PC3 file.
    viewOptions.CadOptions.Pc3File = "small_page.pc3";
    viewer.View(viewOptions);
}
```

</TabItem>

## Dividir un dibujo en mosaicos {#split-a-drawing-into-tiles}
  
Con GroupDocs.Viewer, puede dividir un dibujo CAD (en formato DWG o DWT) en partes (_mosaicos_) y representar cada parte por separado. La representación en mosaicos permite reducir el uso de memoria al convertir dibujos grandes a formato HTML, PDF o imagen. Cuando la representación en mosaicos está habilitada, GroupDocs.Viewer representa únicamente el diseño del espacio de modelo (_Model_) e ignora los valores de las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layoutname" target="_blank" rel="nofollow noopener noreferrer">CadOptions.LayoutName</a>.

![Split a CAD drawing into tiles](/net/viewer/images/rendering-basics/render-cad-documents/split-drawing-into-tiles.png)

Para crear una mosaico individual, instancie un objeto `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/tile" target="_blank" rel="nofollow noopener noreferrer">Tile</a>`. Especifique las coordenadas *x* e *y* de la esquina inferior izquierda del mosaico, así como su ancho y alto (en píxeles). La imagen siguiente ilustra el sistema de coordenadas utilizado para definir la posición del mosaico. El origen (0,0) se encuentra en la esquina inferior izquierda del dibujo. El eje *x* positivo se extiende horizontalmente hacia la derecha, y el eje *y* positivo está orientado verticalmente de abajo hacia arriba.

![Tile coordinates](/net/viewer/images/rendering-basics/render-cad-documents/tile-coordinates.png)

Después de crear todas las teselas, agréguelas a la lista <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/tiles" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.CadOptions.Tiles</a> y llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir estas teselas en el formato deseado. Cada tesela se representará como una página/imagen independiente.

El siguiente ejemplo muestra cómo dividir un dibujo CAD en cuatro teselas (2x2) de igual tamaño:

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("HousePlan.dwg"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    var viewInfo = viewer.GetViewInfo(viewInfoOptions);

    // Get the width and height of the CAD drawing.
    int width = viewInfo.Pages[0].Width;
    int height = viewInfo.Pages[0].Height;

    // Specify the number of rows and columns to split the drawing into.
    int columns = 2;
    int rows = 2;

    // Calculate the width and height of each tile.
    int tileWidth = width / columns;
    int tileHeight = height / rows;
    int pointX = 0;
    int pointY = 0;

    // Split the drawing into tiles and convert them to HTML.
    // {0} is replaced with the tile number in the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    for (int i = 0; i < columns; i++)
        for (int j = 0; j < rows; j++)
        {
            Tile tile = new Tile(pointX + tileWidth * i, pointY + tileHeight * j,
                tileWidth, tileHeight);
            viewOptions.CadOptions.Tiles.Add(tile);
        }
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

            Dim width As Integer = viewInfo.Pages(0).Width
            Dim height As Integer = viewInfo.Pages(0).Height
        
            ' Specify the number of rows and columns to split the drawing into.
            Dim columns As Integer = 2
            Dim rows As Integer = 2
        
            ' Calculate the width and height of each tile.
            Dim tileWidth As Integer = width / columns
            Dim tileHeight As Integer = height / rows
            Dim pointX As Integer = 0
            Dim pointY As Integer = 0
        
            ' Split the drawing into tiles and convert them to HTML.
            ' {0} is replaced with the tile number in the output file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            For i As Integer = 0 To columns - 1
                For j As Integer = 0 To rows - 1
                    Dim tile As Tile = New Tile(pointX + tileWidth * i, pointY + tileHeight * j, tileWidth, tileHeight)
                    viewOptions.CadOptions.Tiles.Add(tile)
                Next
            Next
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

En el ejemplo anterior, GroupDocs.Viewer generará cuatro archivos HTML llamados “page_1.html”, “page_2.html”, “page_3.html” y “page_4.html”, donde cada uno de estos archivos HTML contiene una única tesela en forma de imagen vectorial SVG. También se puede utilizar el método estático <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/forexternalresources/#forexternalresources" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions.ForExternalResources()`</a> (con todas sus sobrecargas); en este caso, los archivos SVG no se incrustarán dentro de los archivos HTML de salida, sino que se guardarán por separado, mientras que el HTML solo los referencia mediante el elemento HTML `A`.

Antes de la versión 24.3 de GroupDocs.Viewer, el renderizado por teselas de archivos CAD solo estaba disponible para el renderizado en HTML. A partir de la versión 24.3, el renderizado por teselas de CAD también es compatible con PDF: en este caso, GroupDocs.Viewer genera un único archivo PDF, donde una de sus páginas representa una tesela. Por lo tanto, si en el ejemplo anterior reemplazamos <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> por <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`PdfViewOptions`</a>, entonces GroupDocs.Viewer producirá un único archivo PDF con cuatro páginas en su interior.

## Elegir velocidad de renderizado en lugar de calidad  {#choose-rendering-speed-instead-of-quality}
  
De forma predeterminada, GroupDocs.Viewer convierte y renderiza todos los documentos dentro de la familia de formatos CAD con la máxima calidad posible. En caso de que el archivo CAD de entrada (por ejemplo, DWG) sea muy complejo, esto puede provocar tiempos de procesamiento considerablemente largos. Asimismo, el tamaño del archivo HTML o imagen (vectorial o rasterizada) generado también puede ser excesivamente grande.

A partir de la versión 24.2, GroupDocs.Viewer introduce una nueva propiedad pública dentro de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions" target="_blank" rel="nofollow noopener noreferrer">`CadOptions`</a>: la marca booleana `EnablePerformanceConversionMode`. De forma predeterminada, su valor es `false`, y GroupDocs.Viewer se comporta como en versiones anteriores, preservando la máxima calidad. Sin embargo, al establecer su valor en `true`, se habilita el modo de conversión orientado al rendimiento, lo que reduce significativamente el tiempo de conversión y también el tamaño en bytes del documento de salida.

Habilitar este modo es muy sencillo: simplemente cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions" target="_blank" rel="nofollow noopener noreferrer">`CadOptions`</a> utilizando [cualquiera de los métodos estáticos descritos anteriormente](#ctors) y, a continuación, establezca el valor de la propiedad `EnablePerformanceConversionMode`. A continuación se muestra un ejemplo:

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("input.dwg"))
{
   HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources("Output-Page#{0}.html");                    
   viewOptions.CadOptions = CadOptions.ForRenderingByWidth(1000);
   viewOptions.CadOptions.EnablePerformanceConversionMode = true;

   viewer.View(viewOptions);
}
```

</TabItem>

Si se toma un archivo DWG ordinario como muestra, la comparación entre los modos de «calidad» y «rendimiento» es la siguiente:

| Modo de conversión | Tamaño del archivo de salida, MiB | Tiempo de procesamiento, s |
| --- | --- | --- |
| Orientado a calidad (predeterminado) | 46.8 | 7.87 |
| Orientado a rendimiento (nuevo) | 5.04 | 4.47 |

La captura de pantalla siguiente ilustra las diferencias visuales entre estos modos: el modo predeterminado orientado a calidad se encuentra a la izquierda, y el nuevo modo orientado a rendimiento se encuentra a la derecha:

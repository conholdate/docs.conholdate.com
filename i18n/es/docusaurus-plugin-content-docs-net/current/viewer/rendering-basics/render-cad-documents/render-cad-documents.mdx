<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite representar sus dibujos CAD y modelos 3D en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar AutoCAD ni otro software CAD para cargar y visualizar archivos CAD dentro de su aplicación .NET (web o de escritorio).

Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> para comenzar a utilizar la API GroupDocs.Viewer. Pase un dibujo CAD que desee visualizar al constructor de la clase. Puede cargar el dibujo desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el dibujo en formato HTML, PDF o imagen.

## Formatos de archivo CAD admitidos {#supported-cad-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo CAD y 3D:

* <a href="https://docs.fileformat.com/cad/dwg/" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Drawing</a> (.DWG)  
* <a href="https://docs.fileformat.com/cad/dwt" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Drawing Template</a> (.DWT)  
* <a href="https://docs.fileformat.com/cad/dwf/" target="_blank" rel="nofollow noopener noreferrer">Design Web Format</a> (.DWF)  
* <a href="https://docs.fileformat.com/cad/dxf" target="_blank" rel="nofollow noopener noreferrer">Drawing Exchange Format</a> (.DXF)  
* <a href="https://docs.fileformat.com/cad/plt" target="_blank" rel="nofollow noopener noreferrer">AutoCAD Plotter Document</a> (.PLT)  
* <a href="https://docs.fileformat.com/cad/dgn" target="_blank" rel="nofollow noopener noreferrer">MicroStation Design File (V7)</a> (.DGN)  
* <a href="https://docs.fileformat.com/cad/ifc" target="_blank" rel="nofollow noopener noreferrer">Industry Foundation Classes</a> (.IFC)  
* <a href="https://docs.fileformat.com/cad/stl" target="_blank" rel="nofollow noopener noreferrer">Stereolithography File</a> (.STL)  
* <a href="https://docs.fileformat.com/3d/obj/" target="_blank" rel="nofollow noopener noreferrer">Wavefront 3D Object File</a> (.OBJ)  
* <a href="https://docs.fileformat.com/cad/cf2/" target="_blank" rel="nofollow noopener noreferrer">Common File Format</a> (.CF2)  
* <a href="https://docs.fileformat.com/cad/igs/" target="_blank" rel="nofollow noopener noreferrer">IGES (Initial Graphics Exchange Specification) Drawing</a> (.IGS)  
* <a href="https://docs.fileformat.com/cad/hpgl/" target="_blank" rel="nofollow noopener noreferrer">HPGL (Hewlett-Packard Graphics Language) Plot File</a> (.HPG)  

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.

## Representar dibujos CAD como HTML {#render-cad-drawings-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo CAD a HTML. Durante la conversión, GroupDocs.Viewer genera una imagen <a href="https://docs.fileformat.com/page-description-language/svg/" target="_blank" rel="nofollow noopener noreferrer">SVG</a> a partir del dibujo CAD e incrusta esta imagen en un documento <a href="https://docs.fileformat.com/web/html/" target="_blank" rel="nofollow noopener noreferrer">HTML</a>.

Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Rendering to HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Create an HTML file for the drawing.
    // Specify the HTML file name.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

            ' Create an HTML file for the drawing.
            ' Specify the HTML file name.
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilo) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Create an HTML file for the drawing.
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("HousePlan.dwg")
            ' Create an HTML file for the drawing.
            ' Specify the HTML file name and location of external resources.
            ' {0} is replaced with the resource name.
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Obtener información sobre diseños y capas existentes {#get-information-about-existing-layouts-and-layers}
  
Siga los pasos a continuación para obtener información sobre los diseños y capas contenidos en un dibujo CAD. Puede utilizar esta información para especificar qué capas y diseños se deben mostrar en el archivo de salida.

1. Cree una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> para una vista específica.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a>, pase la instancia `ViewInfoOptions` como parámetro a este método y convierta el objeto devuelto al tipo <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo</a>.  
3. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo/properties/layouts" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo.Layouts</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/cadviewinfo/properties/layers" target="_blank" rel="nofollow noopener noreferrer">CadViewInfo.Layers</a> para obtener las listas de diseños y capas del archivo CAD.

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    ViewInfoOptions viewInfoOptions = ViewInfoOptions.ForHtmlView();
    // Enable this option to see the list of all layouts contained in the CAD file.
    viewInfoOptions.CadOptions.RenderLayouts = true;
    CadViewInfo viewInfo = viewer.GetViewInfo(viewInfoOptions) as CadViewInfo;

    if (viewInfo != null)
    {
        // Display information about the CAD file.
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");

        // Display the list of existing layouts.
        Console.WriteLine("The drawing contains the following layout(s):");
        foreach (Layout layout in viewInfo.Layouts)
            Console.WriteLine(layout.Name);

        // Display the list of existing layers.
        Console.WriteLine("The drawing contains the following layer(s):");
        foreach (Layer layer in viewInfo.Layers)
            Console.WriteLine(layer);
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("HousePlan.dwg")
            Dim viewInfoOptions As ViewInfoOptions = ViewInfoOptions.ForHtmlView()
            ' Enable this option to see the list of all layouts contained in the CAD file.
            viewInfoOptions.CadOptions.RenderLayouts = True
            Dim viewInfo As CadViewInfo = TryCast(viewer.GetViewInfo(viewInfoOptions), CadViewInfo)
        
            If viewInfo IsNot Nothing Then
                ' Display information about the CAD file.
                Console.WriteLine($"File type: {viewInfo.FileType}")
                Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}")
        
                ' Display the list of existing layouts.
                Console.WriteLine("The drawing contains the following layout(s):")
                For Each layout As Layout In viewInfo.Layouts
                    Console.WriteLine(layout.Name)
                Next
        
                ' Display the list of existing layers.
                Console.WriteLine("The drawing contains the following layer(s):")
                For Each layer As Layer In viewInfo.Layers
                    Console.WriteLine(layer)
                Next
            End If
        End Using
    End Sub
End Module
```

## Renderizar todas las disposiciones o disposiciones específicas  {#render-all-or-specific-layouts}
  
Cuando convierta un dibujo CAD a formato HTML, PDF o imagen, GroupDocs.Viewer solo renderiza la disposición del espacio del modelo (*Model*). Si también necesita renderizar todas las disposiciones del espacio de papel contenidas en su archivo CAD, habilite la opción <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> para una de las siguientes clases (según el formato de archivo de salida):

| Clase | Descripción |
|-------|-------------|
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> | Opciones para vista HTML |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> | Opciones para vista PDF |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> | Opciones para vista PNG |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> | Opciones para vista JPG |

Cada disposición se renderiza en una página independiente.

El siguiente ejemplo renderiza todas las disposiciones al convertir un dibujo CAD a PDF:

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.dwg"))
{
   // Convert the document to PDF.
   PdfViewOptions viewOptions = new PdfViewOptions("output.pdf");
   // Render the Model and all non-empty paper space layouts. 
   viewOptions.CadOptions.RenderLayouts = true;
   viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

:::info
1. Las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layoutname" target="_blank" rel="nofollow noopener noreferrer">CadOptions.LayoutName</a> solo se aplican a los siguientes formatos de archivo: DWG, DWT, DXF y DWF.

2. Si utiliza la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layoutname" target="_blank" rel="nofollow noopener noreferrer">CadOptions.LayoutName</a> para representar un diseño específico, la opción <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/cadoptions/properties/renderlayouts" target="_blank" rel="nofollow noopener noreferrer">CadOptions.RenderLayouts</a> se ignora.
:::

## Renderizar capas específicas  {#render-specific-layers}
  
Un dibujo CAD puede contener muchas capas. Cada capa se utiliza para dibujar un tipo específico de objeto. Por ejemplo, el dibujo siguiente contiene capas para paredes, muebles, plantas, etc. Puede controlar la visibilidad de los objetos en el dibujo activando o desactivando capas específicas.

![Layers in a CAD file](/net/viewer/images/rendering-basics/render-cad-documents/autocad-drawing-layers.png)

Cuando conviertes un dibujo CAD a formato HTML, PDF o imagen, GroupDocs.Viewer representa todas las capas disponibles. Puedes especificar qué capas mostrar en el archivo de salida, como se describe a continuación:

1. Accede a la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/cadoptions" target="_blank" rel="nofollow noopener noreferrer">CadOptions</a> para la vista de destino:

  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
  * <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

2. Asigna la lista de capas que deseas representar a la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/cadoptions/properties/layers" target="_blank" rel="nofollow noopener noreferrer">CadOptions.Layers</a>.

El siguiente ejemplo representa las capas con muros y muebles en PDF:

<Tabs groupId="example9">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
using System.Collections.Generic;
// ...

using (Viewer viewer = new Viewer("HousePlan.dwg"))
{
    // Convert the document to PDF.
    PdfViewOptions viewOptions = new PdfViewOptions("output.pdf");
    // Specify a list of layers to display.
    viewOptions.CadOptions.Layers = new List<Layer>
    {
        new Layer("Base"),
        new Layer("Walls"),
        new Layer("Furniture")
    };
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
Imports System.Collections.Generic
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("HousePlan.dwg")
            ' Convert the document to PDF.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions("output.pdf")
            ' Specify a list of layers to display.
            viewOptions.CadOptions.Layers = New List(Of Layer) From {
                New Layer("Base"),
                New Layer("Walls"),
                New Layer("Furniture")
                }
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

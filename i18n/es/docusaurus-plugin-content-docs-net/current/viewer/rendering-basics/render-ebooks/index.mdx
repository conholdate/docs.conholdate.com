<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite renderizar sus libros electrónicos (EPUB, MOBI) en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar ningún lector de libros para cargar y visualizar libros electrónicos dentro de su aplicación .NET (web o de escritorio).

Para comenzar a utilizar la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el libro que desea visualizar al constructor de la clase. Puede cargar el libro desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el libro electrónico a formato HTML, PDF o imagen.

<a href="https://products.groupdocs.app/viewer/ebook" target="_blank" rel="nofollow noopener noreferrer">Ver libros electrónicos en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>

## Formatos de archivo de libros electrónicos compatibles {#supported-ebooks-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de libros electrónicos:

* <a href="https://docs.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> (.EPUB)  
* <a href="https://docs.fileformat.com/ebook/mobi/" target="_blank" rel="nofollow noopener noreferrer">MOBI</a> (.MOBI)  
* <a href="https://docs.fileformat.com/ebook/azw3/" target="_blank" rel="nofollow noopener noreferrer">AZW3</a> (.AZW3)  

GroupDocs.Viewer puede detectar automáticamente el formato del libro basándose en la información del encabezado del archivo.

## Renderizar libros electrónicos como HTML {#render-ebooks-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo de libro electrónico a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("abook.epub"))
{
    // Create an HTML file for each document page.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

        End Using
    End Sub
End Module
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilo) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("abook.epub"))
{
    // Create an HTML file for each document page.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("abook.epub")
            ' Create an HTML file for each document page.
            ' Specify the HTML file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_ {1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Renderizar EBooks como PDF {#render-ebooks-as-pdf}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un EBook a PDF. Las propiedades de la clase `PdfViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede proteger el archivo PDF de salida, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

// ...

    // Create a PDF file for the document.
    // Specify the PDF file name.
    var viewOptions = new PdfViewOptions("output.pdf");
    viewer.View(viewOptions);
}
```

## Renderizar EBooks como PNG {#render-ebooks-as-png}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un EBook a PNG. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("abook.epub"))
{
    // Create a PNG image for each document page.
    // {0} is replaced with the current page number in the image name.
    var viewOptions = new PngViewOptions("output_{0}.png");

    // Set width and height.
    viewOptions.Width = 800;
    viewOptions.Height = 900;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
        End Using
    End Sub
End Module
```

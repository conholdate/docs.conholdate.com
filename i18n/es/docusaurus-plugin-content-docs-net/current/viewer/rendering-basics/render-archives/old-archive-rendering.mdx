<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite visualizar el contenido de archivos de archivo en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar software de terceros para archivar y comprimir archivos para mostrar el contenido de archivos de archivo dentro de su aplicación .NET (web o de escritorio).

Para comenzar a utilizar la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el archivo de archivo que desea visualizar al constructor de la clase. Puede cargar el archivo desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el archivo de archivo en formato HTML, PDF o imagen.

## Formatos de archivo de archivo y comprimidos admitidos {#supported-archive-and-compressed-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de archivo:

* <a href="https://docs.fileformat.com/compression/7z" target="_blank" rel="nofollow noopener noreferrer">.7Z (archivo comprimido 7-Zip)</a>  
* <a href="https://docs.fileformat.com/compression/bz2" target="_blank" rel="nofollow noopener noreferrer">.BZ2 (archivo comprimido Bzip2)</a>  
* <a href="https://docs.fileformat.com/compression/gz" target="_blank" rel="nofollow noopener noreferrer">.GZ (archivo comprimido Gnu Zipped)</a>  
* <a href="https://docs.fileformat.com/compression/rar" target="_blank" rel="nofollow noopener noreferrer">.RAR (archivo comprimido WinRAR)</a>  
* <a href="https://docs.fileformat.com/compression/tar" target="_blank" rel="nofollow noopener noreferrer">.TAR (archivo consolidado de archivos Unix)</a>  
* <a href="https://docs.fileformat.com/compression/tgz/" target="_blank" rel="nofollow noopener noreferrer">.TGZ / .TAR.GZ (archivo Tar comprimido con Gzip)</a>  
* <a href="https://docs.fileformat.com/compression/xz/" target="_blank" rel="nofollow noopener noreferrer">.TXZ / .TAR.XZ (archivo Tar comprimido con XZ)</a>  
* <a href="https://docs.fileformat.com/compression/xz/" target="_blank" rel="nofollow noopener noreferrer">.XZ (archivo comprimido XZ)</a>  
* <a href="https://docs.fileformat.com/compression/zip" target="_blank" rel="nofollow noopener noreferrer">.ZIP (archivo comprimido ZIP)</a>  
* <a href="https://docs.fileformat.com/compression/zst/" target="_blank" rel="nofollow noopener noreferrer">.ZST / .TAR.ZST / .TZST (Zstandard)</a>  
* <a href="https://docs.fileformat.com/compression/iso/" target="_blank" rel="nofollow noopener noreferrer">.ISO (imagen de disco óptico ISO-9660)</a>  

GroupDocs.Viewer puede detectar automáticamente el formato del archivo de archivo basándose en la información del encabezado del archivo.

## Renderizar archivos de archivo como HTML {#render-archive-files-as-html}
  
Para convertir un archivo de archivo a HTML, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> para crear una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pase esta instancia al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a>.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file for the top folder and each subfolder in the archive.
    // {0} is replaced with the current page number in the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

            ' {0} is replaced with the current page number in the output file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Especificar la cantidad de elementos que se deben representar {#specify-the-number-of-items-to-render}
  
GroupDocs.Viewer admite la opción <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/itemsperpage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ArchiveOptions.ItemsPerPage</a>, que le permite especificar la cantidad de elementos del archivo que se mostrarán en cada página HTML. El valor predeterminado de esta propiedad es **16**.

El siguiente ejemplo muestra cómo configurar esta opción en código:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file for the top folder and each subfolder in the archive.
    // {0} is replaced with the current page number in the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    // Specify the number of items to display on each HTML page.
    viewOptions.ArchiveOptions.ItemsPerPage = 10;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb

        End Using
```

### Crear una única página HTML {#create-a-single-html-page}
  
Si necesita mostrar el contenido de un archivo de archivo en una única página HTML, habilite la opción <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.RenderToSinglePage</a>, como se muestra a continuación:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Render the archive file to a single page.
    viewOptions.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>

## Obtener información sobre carpetas en un archivo de archivo {#obtain-information-about-folders-in-an-archive-file}
  
Siga los pasos a continuación para obtener información sobre las carpetas contenidas en un archivo de archivo. Puede utilizar esta información para [especificar qué carpeta mostrar en el archivo de salida](#render-a-specific-folder).

1. Cree una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> para una vista específica.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a>, pase la instancia `ViewInfoOptions` como parámetro a este método y convierta el objeto devuelto al tipo <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/archiveviewinfo" target="_blank" rel="nofollow noopener noreferrer">ArchiveViewInfo</a>.  
3. Utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/archiveviewinfo/folders/" target="_blank" rel="nofollow noopener noreferrer">ArchiveViewInfo.Folders</a> para obtener las listas de carpetas en el archivo de archivo.

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    var viewInfo = viewer.GetViewInfo(viewInfoOptions) as ArchiveViewInfo;

    if (viewInfo != null)
    {
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");
        Console.WriteLine("Folders: ");
        // Display the list of folders in the archive file.
        foreach (string folder in viewInfo.Folders)
            Console.WriteLine($" - {folder}");
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("Documents.zip")
            Dim viewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo = TryCast(viewer.GetViewInfo(viewInfoOptions), ArchiveViewInfo)

            If viewInfo IsNot Nothing Then
                Console.WriteLine($"File type: {viewInfo.FileType}")
                Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}")
                Console.WriteLine("Folders: ")
                ' Display the list of folders in the archive file.
                For Each folder As String In viewInfo.Folders
                    Console.WriteLine($" - {folder}")
                Next
            End If
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Renderizar una carpeta específica {#render-a-specific-folder}
  
Cuando convierte un archivo comprimido a formato HTML, PDF o imagen, GroupDocs.Viewer representa los elementos de todas las carpetas contenidas en el archivo comprimido. Si necesita representar elementos de una carpeta específica, especifique la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/properties/folder" target="_blank" rel="nofollow noopener noreferrer">ArchiveOptions.Folder</a> en una de las siguientes clases (según el formato de archivo de salida):

| Clase | Descripción |
|-------|-------------|
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> | Opciones para renderizado en HTML |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> | Opciones para renderizado en PDF |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> | Opciones para renderizado en PNG |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> | Opciones para renderizado en JPG |

<Tabs groupId="example8">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Documents.zip"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Specify a folder to render items from.
    viewOptions.ArchiveOptions.Folder = "Documents/CAD files";
    viewer.View(viewOptions);
}
```

</TabItem>

## Especificar el nombre del archivo de archivo {#specify-the-archive-file-name}
  
Al generar un archivo de archivo, GroupDocs.Viewer muestra el nombre del archivo de archivo en el encabezado de cada página. Si necesita cambiar u ocultar este nombre, defina la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/archiveoptions/filename/" target="_blank" rel="nofollow noopener noreferrer">ArchiveOptions.FileName</a> para la vista de destino. Puede establecer esta opción en uno de los siguientes valores:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/filename/source/" target="_blank" rel="nofollow noopener noreferrer">FileName.Source</a> — Devuelve el nombre del archivo de origen (este nombre se utiliza de forma predeterminada).  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/archiveoptions/properties/filename/empty" target="_blank" rel="nofollow noopener noreferrer">FileName.Empty</a> — Especifica un nombre vacío. Utilice este valor para ocultar el nombre del archivo de archivo en el archivo de salida.  
* Una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/filename/filename/" target="_blank" rel="nofollow noopener noreferrer">FileName</a> con un nombre personalizado que desee mostrar en el archivo de salida.  

El siguiente fragmento de código demuestra cómo utilizar un nombre personalizado al generar un archivo de archivo en HTML:

<Tabs groupId="example9">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...
```

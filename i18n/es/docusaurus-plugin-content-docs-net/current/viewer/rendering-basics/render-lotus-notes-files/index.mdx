<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite representar archivos <a href="https://docs.fileformat.com/database/nsf/" target="_blank" rel="nofollow noopener noreferrer">Lotus Notes Storage Facility (NSF)</a> en formatos HTML, PDF, PNG y JPEG. Utilice esta biblioteca para mostrar el contenido de archivos NSF dentro de su aplicación .NET (web o de escritorio).  

Para comenzar con la GroupDocs.Viewer API, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el documento que desea visualizar al constructor de la clase. Puede cargar el documento desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento a formato HTML, PDF o imagen. Estos métodos le permiten representar todo el documento o páginas específicas.  

<a href="https://products.groupdocs.app/viewer/nsf" target="_blank" rel="nofollow noopener noreferrer">Ver archivos NSF en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>  

## Representar archivos de base de datos Lotus Notes como HTML {#render-lotus-notes-database-files-as-html}
  
Para convertir un archivo NSF a HTML, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> para crear una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pase esta instancia al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a>.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.nsf"))
{
   // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.nsf")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Renderizar archivos de base de datos de Lotus Notes como PDF {#render-lotus-notes-database-files-as-pdf}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo NSF a PDF. Las propiedades de la clase `PdfViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede proteger el archivo PDF resultante, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado a PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

## Renderizar archivos de base de datos de Lotus Notes como PNG {#render-lotus-notes-database-files-as-png}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo NSF a PNG. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.nsf"))
{
    // Convert the NSF file to PNG.
    // {0} is replaced with the page numbers in the output image names.
    var viewOptions = new PngViewOptions("output_{0}.png");
    //  Set width and height.
    viewOptions.Width = 800;
    viewOptions.Height = 1000;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
            '  Set width and height.
            viewOptions.Width = 800
            viewOptions.Height = 1000
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

## Especificar opciones de representación {#specify-rendering-options}
  
GroupDocs.Viewer admite la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/mailstorageoptions/" target="_blank" rel="nofollow noopener noreferrer">MailStorageOptions</a>, que le permite especificar distintas opciones para representar archivos de base de datos de Lotus Notes. Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/mailstorageoptions/" target="_blank" rel="nofollow noopener noreferrer">MailStorageOptions</a> en una de las siguientes clases (según el formato de archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

### Limitar el número de elementos a representar {#limit-the-number-of-items-to-render}
  
Cuando carga archivos grandes de base de datos de Lotus Notes, puede tardar una cantidad significativa de tiempo en recuperar y representar el contenido del archivo. Para mejorar el rendimiento de la representación, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/mailstorageoptions/maxitems/" target="_blank" rel="nofollow noopener noreferrer">MailStorageOptions.MaxItems</a> para limitar el número de elementos representados. El valor predeterminado de esta propiedad es **0** (todos los elementos existentes aparecen en el archivo de salida).  

El siguiente ejemplo muestra cómo especificar el número máximo de elementos a representar:

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.nsf"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Specify the maximum items to render.
    viewOptions.MailStorageOptions.MaxItems = 20;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.nsf")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
            ' Specify the maximum items to render.
            viewOptions.MailStorageOptions.MaxItems = 20
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Filtrar mensajes  {#filter-messages}
  
IBM Notes le permite filtrar mensajes según palabras específicas en el cuerpo del mensaje o según parte de la dirección del remitente o del destinatario.

![Filter messages in IBM Notes](/net/viewer/images/rendering-basics/render-lotus-notes-data-files/filter-nsf-messages.png)

Con GroupDocs.Viewer, también puede filtrar mensajes antes de convertir un archivo de base de datos de Lotus Notes a formato HTML, PDF o imagen. Para hacerlo, utilice las siguientes propiedades:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/mailstorageoptions/textfilter/" target="_blank" rel="nofollow noopener noreferrer">MailStorageOptions.TextFilter</a> — Le permite convertir todos los mensajes que contengan un texto específico en el asunto o en el cuerpo.
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/mailstorageoptions/addressfilter/" target="_blank" rel="nofollow noopener noreferrer">MailStorageOptions.AddressFilter</a> — Le permite convertir todos los mensajes que contengan un texto específico en la dirección del remitente o del destinatario.

El siguiente ejemplo de código filtra mensajes en un archivo NSF antes de convertirlo a HTML:

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.nsf"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Set filters.
    viewOptions.MailStorageOptions.TextFilter = "Viewer";
    viewOptions.MailStorageOptions.AddressFilter = "groupdocs@mail.com";
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">


<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite renderizar sus mensajes de correo electrónico en formatos HTML, PDF, PNG y JPEG. No necesita utilizar clientes de correo electrónico de terceros para visualizar el contenido de los archivos de correo electrónico dentro de su aplicación .NET (web o de escritorio).

Para comenzar con la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase al constructor de la clase el mensaje de correo electrónico que desea visualizar; puede cargar el mensaje desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el mensaje cargado en formato HTML, PDF o imagen. Estos métodos le permiten renderizar todo el mensaje o páginas específicas.

<a href="https://products.groupdocs.app/viewer/email" target="_blank" rel="nofollow noopener noreferrer">Ver archivos de correo electrónico en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>

## Formatos de archivo de correo electrónico admitidos {#supported-email-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de correo electrónico:

* <a href="https://docs.fileformat.com/email/eml" target="_blank" rel="nofollow noopener noreferrer">Mensaje de correo electrónico</a> (.EML)  
* <a href="https://docs.fileformat.com/email/emlx" target="_blank" rel="nofollow noopener noreferrer">Mensaje de correo de Apple</a> (.EMLX)  
* <a href="https://docs.fileformat.com/email/mbox/" target="_blank" rel="nofollow noopener noreferrer">Archivo de buzón de correo</a> (.MBOX)  
* <a href="https://docs.fileformat.com/email/msg" target="_blank" rel="nofollow noopener noreferrer">Archivo de elemento de mensaje de Outlook</a> (.MSG)  
* <a href="https://docs.fileformat.com/email/vcf/" target="_blank" rel="nofollow noopener noreferrer">Archivo vCard (contacto virtual)</a> (.VCF, .VCARD)

GroupDocs.Viewer puede detectar automáticamente el formato del archivo de correo electrónico basándose en la información del encabezado del archivo.

## Renderizar mensajes de correo electrónico como HTML {#render-email-messages-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un mensaje de correo electrónico a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y excluir fuentes específicas. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para incrustar un mensaje de correo electrónico en una página HTML, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
   // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.eml")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Para guardar un mensaje de correo electrónico en una carpeta independiente, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

| Parámetro | Descripción |
|-----------|-------------|
| El formato de la ruta del archivo de salida | |
| El formato de la ruta de la carpeta con los recursos externos | |
| El formato de la URL del recurso | |

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name in the output file name.
    var viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.eml")
            ' Specify the HTML file name and location of external resources.
            ' {0} is replaced with the resource name in the output file name.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("output.html",   "output/resource_{0}", "output/resource_{0}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

### Establecer el tamaño de página de salida  {#set-the-output-page-size}
  
GroupDocs.Viewer le permite especificar el tamaño de página para el archivo de salida al convertir un mensaje de correo electrónico a formato HTML, PDF o imagen. Asigne un miembro de la enumeración <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pagesize/" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> a la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/pagesize/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.PageSize</a> para seleccionar uno de los tamaños de página predefinidos (Letter, Ledger, A0, A1, A2, A3 o A4).

El siguiente ejemplo especifica el tamaño de página para el archivo PDF de salida:

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create a PDF file.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the page size.
    viewOptions.EmailOptions.PageSize = PageSize.Letter;
    viewer.View(viewOptions);
}
```

### Renombrar campos en el encabezado del mensaje  {#rename-fields-in-the-message-header}
  
GroupDocs.Viewer le permite modificar cómo se muestran los campos estándar (como _De_, _Para_, _Asunto_, etc.) en el encabezado del mensaje de correo electrónico.

![Default fields in the message header](/net/viewer/images/rendering-basics/render-email-messages/default-message-fields.png)

Use la propiedad `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/emailoptions/properties/fieldtextmap" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.FieldTextMap</a>` para especificar etiquetas personalizadas de campo. Los campos estáticos de la clase `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/field/" target="_blank" rel="nofollow noopener noreferrer">Field</a>` le permiten acceder a los campos de encabezado de correo electrónico predeterminados, como se muestra en el ejemplo siguiente.

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Specify custom field labels.
    viewOptions.EmailOptions.FieldTextMap[Field.From] = "Sender";
    viewOptions.EmailOptions.FieldTextMap[Field.To] = "Recipient";
    viewOptions.EmailOptions.FieldTextMap[Field.Sent] = "Date";
    viewOptions.EmailOptions.FieldTextMap[Field.Subject] = "Email subject";
    viewer.View(viewOptions);
}
```

</TabItem>

### Especificar el formato de fecha y hora y cambiar la zona horaria {#specify-the-date-and-time-format-and-change-the-time-zone}
  
Al procesar mensajes de correo electrónico, GroupDocs.Viewer da formato a la información de fecha y hora en el encabezado del mensaje según la configuración de fecha y hora del sistema. Si desea cambiar el formato predeterminado de fecha y hora o especificar el desplazamiento de la zona horaria, utilice las siguientes propiedades:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/datetimeformat/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.DateTimeFormat</a>: le permite definir un formato personalizado de fecha y hora. Consulte los siguientes temas para obtener más detalles: 
    * <a href="https://learn.microsoft.com/en-us/dotnet/standard/base-types/standard-date-and-time-format-strings" target="_blank" rel="nofollow noopener noreferrer">Standard date and time format strings</a>
    * <a href="https://learn.microsoft.com/en-us/dotnet/standard/base-types/custom-date-and-time-format-strings" target="_blank" rel="nofollow noopener noreferrer">Custom date and time format strings</a>
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/emailoptions/timezoneoffset/" target="_blank" rel="nofollow noopener noreferrer">EmailOptions.TimeZoneOffset</a>---Especifica el desplazamiento en horas y minutos respecto a la hora universal coordinada (UTC). El desplazamiento se muestra con un signo inicial. Un signo más (+) indica una hora adelantada respecto a UTC, y un signo menos (-) indica una hora retrasada respecto a UTC. 

<Tabs groupId="example8">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.eml"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Apply a custom format to the date in the email message header.
    viewOptions.EmailOptions.DateTimeFormat = "MMMM dd, yyyy H:mm:ss zzz";
    // Specify the time zone offset. 
    viewOptions.EmailOptions.TimeZoneOffset = new TimeSpan(-7, 0, 0);
    viewer.View(viewOptions);
}
```

</TabItem>

## Obtener metadatos del mensaje de correo electrónico antes de representarlo {#get-mail-message-metadata-before-rendering}

A veces es necesario conocer algunos metadatos del mensaje de correo electrónico cargado en la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> antes de su representación real mediante el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/view/#view" target="_blank" rel="nofollow noopener noreferrer">`Viewer.View()`</a>. GroupDocs.Viewer proporciona, para tales casos, la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a>, la cual se puede obtener llamando al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/getviewinfo/#getviewinfo" target="_blank" rel="nofollow noopener noreferrer">`Viewer.GetViewInfo()`</a>. Sin embargo, esta clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a> es genérica para todos los formatos de documento admitidos y no posee propiedades específicas, únicamente presentes en los mensajes de correo electrónico.

A partir de la versión 26.1, la API pública de GroupDocs.Viewer incluye una nueva clase: <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/mailmessageviewinfo/" target="_blank" rel="nofollow noopener noreferrer">`MailMessageViewInfo`</a>. Esta clase es heredera directa de la clase genérica <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a>, por lo que hereda todas sus propiedades, pero también introduce algunas nuevas propiedades específicas para los mensajes de correo electrónico:

- Propiedad `Sent` de tipo `DateTime`: devuelve una fecha y hora almacenada en el mensaje de correo electrónico en su forma original «tal cual», sin ajustarla a la fecha y hora local, entre otras.
- Propiedad `Subject` de tipo `String`: devuelve el asunto del mensaje de correo electrónico.
- Propiedad `From` de tipo `String`: devuelve la dirección de correo electrónico del remitente («From»).

Para obtener los metadatos de un mensaje de correo electrónico determinado, este mensaje debe cargarse inicialmente en la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> mediante su constructor <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/viewer/#constructor_4" target="_blank" rel="nofollow noopener noreferrer">constructor</a>, y luego debe llamarse al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/getviewinfo/#getviewinfo" target="_blank" rel="nofollow noopener noreferrer">`Viewer.GetViewInfo()`</a>. Este método devuelve una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/" target="_blank" rel="nofollow noopener noreferrer">`ViewInfo`</a>, la cual debe convertirse al tipo <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/mailmessageviewinfo/" target="_blank" rel="nofollow noopener noreferrer">`MailMessageViewInfo`</a>. ¡Y eso es todo! A continuación se muestra el código fuente:

using System;

    // explicit casting

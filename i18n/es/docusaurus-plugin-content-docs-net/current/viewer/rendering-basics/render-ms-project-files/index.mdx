<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite renderizar archivos de Project en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar Microsoft Project ni otro software de gestión de proyectos para cargar y visualizar archivos de Project dentro de su aplicación .NET (web o de escritorio).

Para comenzar a utilizar la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el documento que desea visualizar al constructor de la clase. Puede cargar el documento desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento a formato HTML, PDF o imagen. Estos métodos le permiten renderizar todo el documento o páginas específicas.

## Formatos de archivo de gestión de proyectos admitidos {#supported-project-management-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de gestión de proyectos:

* <a href="https://docs.fileformat.com/project-management/mpp" target="_blank" rel="nofollow noopener noreferrer">Microsoft Project</a> (.MPP)  
* <a href="https://docs.fileformat.com/project-management/mpt" target="_blank" rel="nofollow noopener noreferrer">Plantilla de Microsoft Project</a> (.MPT)  
* <a href="https://docs.fileformat.com/project-management/mpx" target="_blank" rel="nofollow noopener noreferrer">Archivo de intercambio de Microsoft Project</a> (.MPX)

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.

:::info
Familia de los formatos de archivo de gestión de proyectos (MPP, MPT y MPX) actualmente no es compatible con el entorno de ejecución `net6.0` (<a href="https://www.nuget.org/packages/GroupDocs.Viewer.Net60" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer.Net60</a>). Son compatibles en Windows con `net462` y `net6.0-windows`.
:::

## Renderizar archivos de proyecto como HTML {#render-project-files-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo de Project a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).  

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    // Render the project's active view as HTML.
    // {0} is replaced with the current page number in the output file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

            ' {0} is replaced with the current page number in the output file names.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilos) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    // Render the project's active view as HTML.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("SoftwareDevelopmentPlan.mpp")
            ' Render the project's active view as HTML.
            ' Specify the HTML file names and location of external resources.
            ' {0} and {1} are replaced with the page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Renderizar archivos de Project como PNG {#render-project-files-as-png}

## Obtener información sobre un archivo de Proyecto  {#get-information-about-a-project-file}
  
Siga los pasos a continuación para obtener información sobre un archivo de Proyecto (el formato del archivo, el número de páginas, las fechas de inicio y finalización del proyecto):  

1. Cree una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> para una vista específica.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a>, pase la instancia de `ViewInfoOptions` como parámetro a este método y convierta el objeto devuelto al tipo <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/projectmanagementviewinfo" target="_blank" rel="nofollow noopener noreferrer">ProjectManagementViewInfo</a>.  
3. Utilice las propiedades de la clase `ProjectManagementViewInfo` para recuperar información sobre el archivo de Proyecto.

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    var viewInfo = viewer.GetViewInfo(viewInfoOptions) as ProjectManagementViewInfo;

    if (viewInfo != null)
    {
        // Display information about the Project file.
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");
        Console.WriteLine($"Project start date: {viewInfo.StartDate}");
        Console.WriteLine($"Project end date: {viewInfo.EndDate}");
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("SoftwareDevelopmentPlan.mpp")
            Dim viewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo = TryCast(viewer.GetViewInfo(viewInfoOptions), ProjectManagementViewInfo)
        
            If viewInfo IsNot Nothing Then
                ' Display information about the Project file.
                Console.WriteLine($"File type: {viewInfo.FileType}")
                Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}")
                Console.WriteLine($"Project start date: {viewInfo.StartDate}")
                Console.WriteLine($"Project end date: {viewInfo.EndDate}")
            End If
        End Using
    End Sub
End Module
```

</TabItem>

## Especificar el tamaño de página  {#specify-the-output-page-size}
  
GroupDocs.Viewer le permite especificar el tamaño de página para el archivo de salida al convertir su documento de Project a formato HTML, PDF o imagen. Asigne un miembro de la enumeración <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pagesize" target="_blank" rel="nofollow noopener noreferrer">PageSize</a> a la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/projectmanagementoptions/properties/pagesize" target="_blank" rel="nofollow noopener noreferrer">ProjectManagementOptions.PageSize</a> para seleccionar uno de los tamaños de página predefinidos (Letter, Ledger, A0, A1, A2, A3 o A4). Puede acceder a esta propiedad en las siguientes clases (según el formato de archivo de salida):

| Clase | Descripción |
|-------|-------------|
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> | Opciones para vista HTML |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> | Opciones para vista PDF |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> | Opciones para vista PNG |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> | Opciones para vista JPG |

El siguiente ejemplo especifica el tamaño de página para el archivo PDF de salida:

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

{

    viewOptions.ProjectManagementOptions.PageSize = PageSize.A3;
    viewer.View(viewOptions);
}
```

## Ajustar la unidad de tiempo  {#adjust-the-time-unit}
  
Al representar un archivo de proyecto, GroupDocs.Viewer selecciona la unidad de tiempo más pequeña en una escala temporal según la duración total del proyecto. Puede ajustar la escala temporal para mostrar unidades de tiempo más pequeñas o más grandes (desde días hasta meses). Para ello, establezca la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/projectmanagementoptions/properties/timeunit" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.ProjectManagementOptions.TimeUnit</a> en una de las siguientes opciones del enumerador <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/timeunit" target="_blank" rel="nofollow noopener noreferrer">TimeUnit</a>:

* `Days` muestra los días en la escala temporal.  
* `ThirdsOfMonths` muestra el Inicio/Medio/Final (B/M/E) de cada mes en la escala temporal.  
* `Months` muestra los meses en la escala temporal.  
* `Unspecified` indica que la unidad de escala temporal no está especificada.  

El siguiente ejemplo de código muestra cómo especificar la unidad de escala temporal al representar un archivo de proyecto en HTML:

<Tabs groupId="example8">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    // Convert the document to HTML.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output_{0}.html");
    // Specify the time unit.
    viewOptions.ProjectManagementOptions.TimeUnit = TimeUnit.ThirdsOfMonths;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">


## Renderizar fechas específicas  {#render-specific-dates}
  
Con GroupDocs.Viewer, puede representar solo una porción de la línea de tiempo del proyecto al convertir su archivo de Proyecto a formato HTML, PDF o imagen. Establezca las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/projectmanagementoptions/properties/startdate" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.ProjectManagementOptions.StartDate</a> y <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/projectmanagementoptions/properties/enddate" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.ProjectManagementOptions.EndDate</a> para una vista objetivo, a fin de especificar un rango de fechas que la línea de tiempo debe mostrar. Si establece únicamente la propiedad `StartDate`, la línea de tiempo mostrará información de las tareas desde la fecha indicada hasta la fecha final del proyecto. Si establece únicamente la propiedad `EndDate`, la línea de tiempo contendrá fechas desde la fecha inicial del proyecto hasta la fecha indicada.

El ejemplo siguiente muestra cómo convertir un archivo de Proyecto a PDF y establecer el rango de fechas de la línea de tiempo.

<Tabs groupId="example9">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the date range.
    viewOptions.ProjectManagementOptions.StartDate = new DateTime(2022, 08, 01);
```

## Notas de representación {#render-notes}
  
Microsoft Project le permite agregar notas a tareas, recursos y asignaciones.

![Speaker notes in Microsoft PowerPoint](/net/viewer/images/rendering-basics/render-ms-project-files/project-task-notes.png)

Si necesita mostrar estas notas en archivos HTML, PDF o imágenes de salida, habilite la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/rendernotes" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.RenderNotes</a> para la vista de destino.

El siguiente ejemplo de código convierte un archivo de Proyecto con notas de tareas a PDF:

<Tabs groupId="example10">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("SoftwareDevelopmentPlan.mpp"))
{
    // Convert the document to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Enable notes rendering.
    viewOptions.RenderNotes = true;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
Imports GroupDocs.Viewer

            viewer.View(viewOptions)
        End Using
    End Sub
```

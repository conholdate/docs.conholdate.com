<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite renderizar sus presentaciones en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar Microsoft PowerPoint ni otro software para cargar y visualizar presentaciones dentro de su aplicación .NET (web o de escritorio).

Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> para comenzar a utilizar la API de GroupDocs.Viewer. Pase la presentación que desea visualizar al constructor de la clase. Puede cargar la presentación desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir la presentación en formato HTML, PDF o imagen. Estos métodos le permiten renderizar toda la presentación o solo diapositivas específicas.

## Formatos de archivo de presentación admitidos {#supported-presentation-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de presentación:

* <a href="https://docs.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Presentation</a> (.PPTX)  
* <a href="https://docs.fileformat.com/presentation/ppt/" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Presentation</a> (.PPT)  
* <a href="https://docs.fileformat.com/presentation/potx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Template</a> (.POTX)  
* <a href="https://docs.fileformat.com/presentation/pot" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Template</a> (.POT)  
* <a href="https://docs.fileformat.com/presentation/potm" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Template</a> (.POTM)  
* <a href="https://docs.fileformat.com/presentation/ppsx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Slide Show</a> (.PPSX)  
* <a href="https://docs.fileformat.com/presentation/ppsm" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Slide Show</a> (.PPSM)  
* <a href="https://docs.fileformat.com/presentation/pps" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint 97-2003 Slide Show</a> (.PPS)  
* <a href="https://docs.fileformat.com/presentation/pptmx" target="_blank" rel="nofollow noopener noreferrer">Microsoft PowerPoint Macro-Enabled Presentation</a> (.PPTM)  
* <a href="https://docs.fileformat.com/presentation/odp" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Presentation</a> (.ODP)  
* <a href="https://docs.fileformat.com/presentation/otp" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Presentation Template</a> (.OTP)  
* <a href="https://docs.fileformat.com/" target="_blank" rel="nofollow noopener noreferrer">OpenDocument Flat XML Presentation</a> (.FODP)  

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.

## Renderizar presentaciones como HTML {#render-presentations-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo de presentación a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Create an HTML file for each slide.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.pptx")
            ' Create an HTML file for each slide.
            ' {0} is replaced with the current page number in the file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilos) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pptx"))
{
    // Create an HTML file for each slide.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources(
        "page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

Module Program

            ' Specify the HTML file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

### Generar marcado HTML/CSS puro  {#generate-pure-html-css-markup}
  
Antes de <a href="https://releases.groupdocs.com/viewer/net/release-notes/2024/groupdocs-viewer-for-net-24-5-release-notes/" target="_blank" rel="nofollow noopener noreferrer">la versión 24.5</a>, GroupDocs.Viewer for .NET solo era capaz de renderizar presentaciones en HTML en un único modo, profundamente basado en imágenes SVG. De hecho, toda la diapositiva se convierte en una única imagen vectorial en <a href="https://docs.fileformat.com/page-description-language/svg/" target="_blank" rel="nofollow noopener noreferrer">formato SVG</a>, y el HTML aquí solo sirve como contenedor alrededor de un elemento SVG. Este modo tiene la ventaja indiscutible de una reproducción exacta al 100 % de la presentación original. En otras palabras, lo que se ve en Microsoft PowerPoint al abrir una presentación es exactamente lo que se ve en el navegador web tras abrir la misma presentación en GroupDocs.Viewer. Esto es posible porque GroupDocs.Viewer analiza el documento de presentación original y lo reproduce dibujando cada elemento, incluso cada píxel, sobre un lienzo SVG, preservando su posición, forma y orientación.

Sin embargo, debido a su naturaleza basada en SVG, este modo también presenta ciertas desventajas: el marcado SVG resultante es demasiado complejo, la búsqueda de texto completo puede no funcionar como se espera y, en realidad, no se trata de marcado HTML y CSS «reales». Por lo tanto, si desea implementar algo como la modificación o el procesamiento posterior del documento tras obtenerlo de GroupDocs.Viewer, es probable que encuentre problemas, ya que las herramientas estándar, como analizadores HTML o consultas CSS, normalmente no funcionan con marcado SVG.

Por esta razón, presentamos un nuevo modo de conversión a HTML para Presentations: el modo HTML/CSS puro. En este modo no se generan imágenes SVG en absoluto, solo marcado HTML y CSS puro.

De forma predeterminada, este modo está desactivado y se activa el modo existente basado en SVG. Para habilitar el nuevo modo de conversión HTML/CSS puro, establezca la bandera booleana `RenderToPureHtml` en el valor `true` en la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/presentationoptions/" target="_blank" rel="nofollow noopener noreferrer">`PresentationOptions`</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a>.

El siguiente ejemplo de código muestra la conversión del mismo archivo de presentación a marcado HTML/CSS puro en dos variantes: con recursos incrustados y con recursos externos:

<Tabs groupId="example_pure">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...
string inputPresentationPath = "SamplePresentation.pptx";

//preparing HTML options for embedded and external resources
HtmlViewOptions embeddedOptions = HtmlViewOptions.ForEmbeddedResources("slide_{0}_embedded.html");
HtmlViewOptions externalOptions = HtmlViewOptions.ForExternalResources("slide_{0}.html", "slide_{0}_{1}", "slide_{0}_{1}");
//enabling the pure HTML/CSS mode for both options
embeddedOptions.PresentationOptions.RenderToPureHtml = externalOptions.PresentationOptions.RenderToPureHtml = true;

using (Viewer viewer = new Viewer(inputPresentationPath))
{
    viewer.View(embeddedOptions);
    viewer.View(externalOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim inputPresentationPath As String = "SamplePresentation.pptx"
        'preparing HTML options for embedded and external resources
        Dim embeddedOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources("slide_{0}_embedded.html")
        Dim externalOptions As HtmlViewOptions = HtmlViewOptions.ForExternalResources("slide_{0}.html", "slide_{0}_{1}", "slide_{0}_{1}")
        'enabling the pure HTML/CSS mode for both options
        embeddedOptions.PresentationOptions.RenderToPureHtml = True
        externalOptions.PresentationOptions.RenderToPureHtml = True
        Using viewer = New Viewer(inputPresentationPath)
            viewer.View(embeddedOptions)
            viewer.View(externalOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

Es necesario mencionar que este nuevo modo puramente en HTML/CSS también presenta las siguientes limitaciones y desventajas:

1. Su fidelidad es generalmente inferior en comparación con el modo original basado en SVG, especialmente en presentaciones con diseños complejos de diapositivas y formato de texto sofisticado.
2. Por el momento, no se admite el procesamiento de comentarios y notas; por lo tanto, las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/rendercomments/" target="_blank" rel="nofollow noopener noreferrer">`RenderComments`</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/rendernotes/" target="_blank" rel="nofollow noopener noreferrer">`RenderNotes`</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> se ignoran.
3. La propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/resolution/" target="_blank" rel="nofollow noopener noreferrer">`Resolution`</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/" target="_blank" rel="nofollow noopener noreferrer">`PresentationOptions`</a> tampoco se admite por el momento; las imágenes se exportan al documento HTML de salida en su resolución original.
4. La propiedad booleana <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">`RenderToSinglePage`</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> tampoco se admite, por lo que cada diapositiva de la presentación se guardará en un documento HTML distinto.
5. La propiedad booleana <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/renderresponsive/" target="_blank" rel="nofollow noopener noreferrer">`RenderResponsive`</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a> pertenece al modo de conversión existente basado en SVG; por lo tanto, su valor se ignora al convertir en modo puramente HTML/CSS, ya que el marcado HTML y CSS ya es 100 % responsivo.

Planeamos agregar soporte para la mayoría de estas características faltantes en un futuro cercano, mejorando continuamente este nuevo convertidor puramente HTML/CSS, añadiendo nuevas funcionalidades y corrigiendo errores.

Por ejemplo, puede proteger el archivo PDF de salida, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado a PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

## Especificar la resolución de la imagen {#specify-image-resolution}
  
Cuando convierta presentaciones que contengan imágenes de alta resolución a otros formatos, es posible que necesite reducir la resolución de las imágenes para disminuir el tamaño del archivo de salida. GroupDocs.Viewer admite la opción <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">PresentationOptions.Resolution</a>, que le permite comprimir las imágenes en los archivos HTML y PDF generados. Para acceder a esta opción, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/presentationoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.PresentationOptions</a> o <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/presentationoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions.PresentationOptions</a> (según el formato del archivo de salida).

Puede establecer la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/presentationoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">PresentationOptions.Resolution</a> en uno de los siguientes valores del campo <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a>:

| Campo Resolution | DPI | Observaciones |
| --- | --- | --- |
| DocumentResolution | Tal como aparece en el archivo de origen | Este es el valor predeterminado. |
| Dpi72 | 72 | Compresión máxima de imágenes y tamaño mínimo de archivo. |
| Dpi96 | 96 | Ideal para páginas web y proyectores. |
| Dpi150 | 150 | Ideal para páginas web y proyectores. |
| Dpi220 | 220 | Excelente calidad en la mayoría de impresoras y pantallas. |
| Dpi330 | 330 | Buena calidad para pantallas de alta definición (HD). |

El siguiente ejemplo muestra cómo especificar la resolución de la imagen en código: 

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...
```

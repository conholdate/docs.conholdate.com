<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite cargar imágenes en diversos formatos y convertirlas a HTML, PDF, PNG y JPEG. Incorpore esta biblioteca en su aplicación .NET (web o de escritorio) para crear su propio visor de imágenes.

Para comenzar con la API de GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase la imagen que desea visualizar al constructor de la clase. Puede cargar la imagen desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir la imagen al formato HTML, PDF, PNG o JPEG. Para imágenes multipágina (como TIFF, CDR, DICOM, WebP, etc.), puede especificar las páginas que desea renderizar.

## Renderizar imágenes como HTML {#render-images-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir una imagen a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).  

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para incrustar una imagen en una página HTML, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("vector-image.svg"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("vector-image.svg")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Para guardar una imagen en una carpeta independiente, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("vector-image.svg"))
{
    // Specify the HTML file name and location of external resources.
    // {0} is replaced with the resource name in the output file name.
    var viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}", "output/resource_{0}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("vector-image.svg")
            ' Specify the HTML file name and location of external resources.
            ' {0} is replaced with the resource name in the output file name.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("output.html", "output/resource_{0}",    "output/resource_{0}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Convertir imágenes a PNG {#convert-images-to-png}

Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

// ...

using (var viewer = new Viewer("vector-image.svg"))
{
    // Create a PNG image.
    var viewOptions = new PngViewOptions("output.png");
    // Set width and height.
    viewOptions.Width = 1600;
    viewOptions.Height = 900;
    viewer.View(viewOptions);
```

## Renderizar un archivo PSD con fuentes personalizadas  {#render-a-psd-file-with-custom-fonts}
  
Cuando renderice un archivo PSD con fuentes personalizadas, puede especificar una carpeta que contenga las fuentes necesarias para evitar la sustitución de fuentes durante la renderización. Para ello, siga los pasos siguientes:  

1. Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/folderfontsource" target="_blank" rel="nofollow noopener noreferrer">FolderFontSource</a> y especifique la ruta de la carpeta que almacena las fuentes personalizadas. Pase un miembro de la enumeración <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/folderfontsource/properties/searchoption" target="_blank" rel="nofollow noopener noreferrer">SearchOption</a> al constructor de la clase para definir el ámbito de búsqueda. Las opciones disponibles son:
    * `TopFolderOnly`---Searches for the fonts only in the current folder.
    * `AllFolders`---Searches for the fonts in the current folder and its subfolders.

2. Llame al método estático <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.fonts/fontsettings/methods/setfontsources" target="_blank" rel="nofollow noopener noreferrer">FontSettings.SetFontSources</a> y pase la fuente de fuentes especificada como parámetro a este método. Este método le permite especificar múltiples fuentes de fuentes.

También puede establecer la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/defaultfontname" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.DefaultFontName</a> para especificar la fuente predeterminada que debe utilizarse cuando no se encuentra una fuente específica.

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Fonts;
using GroupDocs.Viewer.Options;
// ...

// Specify a folder that stores custom fonts used in a PSD file.
var fontSource = new FolderFontSource(@"C:\custom_fonts_folder", SearchOption.AllFolders);
FontSettings.SetFontSources(fontSource);

using (var viewer = new Viewer("sample.psd"))
{
    // Convert a PSD file to PNG.
    var viewOptions = new PngViewOptions("output.png");
    // Specify the default font that should be used to replace missing fonts.
    viewOptions.DefaultFontName = "Arial";
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">


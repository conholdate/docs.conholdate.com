<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite representar archivos de datos de Microsoft Outlook en formatos HTML, PDF, PNG y JPEG. Utilice esta biblioteca para mostrar el contenido de archivos OST y PST dentro de su aplicación .NET (web o de escritorio).  

Para comenzar con la API de GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el documento que desea visualizar al constructor de la clase. Puede cargar el documento desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento en formato HTML, PDF o imagen. Estos métodos le permiten representar todo el documento o páginas específicas.  

<a href="https://products.groupdocs.app/viewer/outlook" target="_blank" rel="nofollow noopener noreferrer">Ver archivos de Outlook en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>  

## Formatos de archivo de datos de Outlook admitidos {#supported-outlook-data-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de datos de Outlook:  

* <a href="https://docs.fileformat.com/email/ost" target="_blank" rel="nofollow noopener noreferrer">Outlook Offline Storage Table</a> (.OST)  
* <a href="https://docs.fileformat.com/email/pst" target="_blank" rel="nofollow noopener noreferrer">Outlook Personal Storage Table</a> (.PST)  

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.  

## Representar archivos de datos de Outlook como HTML {#render-outlook-data-files-as-html}
  
Para convertir un archivo OST o PST a HTML, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> para crear una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pase esta instancia al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a>.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.pst")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Renderizar archivos de datos de Outlook como PDF {#render-outlook-data-files-as-pdf}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo OST o PST a PDF. Las propiedades de la clase `PdfViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede proteger el archivo PDF resultante, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

## Renderizar archivos de datos de Outlook como PNG {#render-outlook-data-files-as-png}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo OST o PST a PNG. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Convert the PST file to PNG.
    // {0} is replaced with the page numbers in the output image names.
    var viewOptions = new PngViewOptions("output_{0}.png");
    // Set width and height.
    viewOptions.Width = 800;
    viewOptions.Height = 900;
    viewer.View(viewOptions);
}
```

</TabItem>

## Obtener información sobre carpetas en un archivo de datos de Outlook {#get-information-about-folders-in-an-outlook-data-file}
  
Siga los pasos a continuación para obtener información sobre las carpetas contenidas en un archivo de datos de Outlook.

1. Cree una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> para una vista específica.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a>, pase la instancia `ViewInfoOptions` como parámetro a este método y convierta el objeto devuelto al tipo <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/outlookviewinfo" target="_blank" rel="nofollow noopener noreferrer">OutlookViewInfo</a>.  
3. Utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/outlookviewinfo/properties/folders" target="_blank" rel="nofollow noopener noreferrer">OutlookViewInfo.Folders</a> para obtener la lista de carpetas del archivo de datos de Outlook.

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Create an HTML file.
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    var viewInfo = viewer.GetViewInfo(viewInfoOptions) as OutlookViewInfo;

    if (viewInfo != null)
    {
        // Display information about the PST file.
        Console.WriteLine($"File type: {viewInfo.FileType}");
        Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}");

        // Display the list of folders that the PST file contains.
        Console.WriteLine("The file contains the following folders:");
        foreach (string folder in viewInfo.Folders)
            Console.WriteLine(folder);
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.pst")
            ' Create an HTML file.
            Dim viewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo = TryCast(viewer.GetViewInfo(viewInfoOptions), OutlookViewInfo)
        
            If viewInfo IsNot Nothing Then
                ' Display information about the PST file.
                Console.WriteLine($"File type: {viewInfo.FileType}")
                Console.WriteLine($"The number of pages: {viewInfo.Pages.Count}")
        
                ' Display the list of folders that the PST file contains.
                Console.WriteLine("The file contains the following folders:")
                For Each folder As String In viewInfo.Folders
                    Console.WriteLine(folder)
                Next
            End If
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Especificar opciones de renderizado  {#specify-rendering-options}
  
GroupDocs.Viewer admite la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/outlookoptions" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions</a>, que le permite especificar distintas opciones para el renderizado de archivos de datos de Outlook. Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/outlookoptions" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions</a> en una de las siguientes clases (según el formato del archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

### Renderizar una carpeta específica  {#render-a-specific-folder}
  
Cuando convierte un archivo OST o PST a formato HTML, PDF o imagen, GroupDocs.Viewer renderiza los mensajes de todas las carpetas contenidas en el archivo (incluidas las carpetas anidadas). Si desea renderizar elementos de una carpeta específica, establezca la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/outlookoptions/properties/folder" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions.Folder</a> en la vista de destino. Especifique el nombre de la carpeta de la siguiente manera: `{Parent folder name}\\{Subfolder name}`.

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Render messages from the "Inbox" folder and its subfolders.
    viewOptions.OutlookOptions.Folder = "Inbox";
    // Render messages from a specific subfolder in the "Inbox" folder.
    // viewOptions.OutlookOptions.Folder = "Inbox\\Work\\Urgent";
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
' ...

            ' viewOptions.OutlookOptions.Folder = "Inbox\\Work\\Urgent";

    End Sub
```

### Limitar la cantidad de elementos de carpeta que se representan {#limit-the-number-of-folder-items-to-render}
  
Cuando cargue archivos grandes de datos de Outlook, puede tardar una cantidad significativa de tiempo en recuperar y representar el contenido del archivo. Para mejorar el rendimiento de la representación, utilice la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/outlookoptions/properties/maxitemsinfolder" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions.MaxItemsInFolder</a> para limitar la cantidad de elementos representados (mensajes, contactos o tareas) en cada carpeta. El valor predeterminado de esta propiedad es **50**. Establezca esta propiedad en **0** para representar todos los elementos existentes.  

El siguiente ejemplo muestra cómo especificar el número máximo de elementos de carpeta que se representarán:

<Tabs groupId="example7">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Specify the maximum number of folder items.
    viewOptions.OutlookOptions.MaxItemsInFolder = 30;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer.Options
```

### Filtrar mensajes  {#filter-messages}
  
Microsoft Outlook le permite filtrar mensajes por palabras específicas en el cuerpo del mensaje o por parte de la dirección del remitente o del destinatario.

![Filter messages in Microsoft Outlook](/net/viewer/images/rendering-basics/render-outlook-files/filter-messages.png)

Con GroupDocs.Viewer, también puede filtrar mensajes antes de convertir un archivo de datos de Outlook a formato HTML, PDF o imagen. Para hacerlo, utilice las siguientes propiedades:

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/outlookoptions/properties/textfilter" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions.TextFilter</a>: le permite convertir todos los mensajes que contengan un texto específico en el asunto o en el cuerpo.
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/outlookoptions/properties/addressfilter" target="_blank" rel="nofollow noopener noreferrer">OutlookOptions.AddressFilter</a>: le permite convertir todos los mensajes que contengan un texto específico en la dirección del remitente o del destinatario.

El siguiente ejemplo de código filtra los mensajes de un archivo PST antes de convertirlo a HTML:

<Tabs groupId="example8">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.pst"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Set filters.
    viewOptions.OutlookOptions.TextFilter = "Viewer";
    viewOptions.OutlookOptions.AddressFilter = "groupdocs.com";
    viewer.View(viewOptions);
}
```

</TabItem>

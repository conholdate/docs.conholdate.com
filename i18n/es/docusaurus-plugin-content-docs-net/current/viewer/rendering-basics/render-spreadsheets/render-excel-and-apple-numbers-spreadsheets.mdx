<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite convertir sus archivos de hojas de cálculo a formatos HTML, PDF, PNG y JPEG. No es necesario utilizar Microsoft Excel ni otros programas de hojas de cálculo para cargar y visualizar documentos de Excel dentro de su aplicación .NET (web o de escritorio).

Para comenzar con la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase al constructor de la clase el archivo de hoja de cálculo que desea visualizar. Puede cargar el documento desde un archivo o desde un flujo (stream). Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento a formato HTML, PDF o imagen. Estos métodos le permiten renderizar todo el documento o páginas específicas.

<a href="https://products.groupdocs.app/viewer/excel" target="_blank" rel="nofollow noopener noreferrer">Ver hojas de cálculo de Excel en línea</a> <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" target="_blank" rel="nofollow noopener noreferrer">Ver demos y ejemplos en GitHub</a>

## Formatos de archivo de hoja de cálculo admitidos {#supported-spreadsheet-file-formats}

GroupDocs.Viewer admite los siguientes formatos de archivo de hoja de cálculo:

* <a href="https://docs.fileformat.com/spreadsheet/xlsx" target="_blank" rel="nofollow noopener noreferrer">Libro de Microsoft Excel</a> (.XLSX)  
* <a href="https://docs.fileformat.com/spreadsheet/xls" target="_blank" rel="nofollow noopener noreferrer">Libro de Microsoft Excel 97-2003</a> (.XLS)  
* <a href="https://docs.fileformat.com/spreadsheet/xlsb" target="_blank" rel="nofollow noopener noreferrer">Libro binario de Microsoft Excel</a> (.XLSB)  
* <a href="https://docs.fileformat.com/spreadsheet/xlsm" target="_blank" rel="nofollow noopener noreferrer">Libro habilitado para macros de Microsoft Excel</a> (.XLSM)  
* <a href="https://docs.fileformat.com/spreadsheet/xltx" target="_blank" rel="nofollow noopener noreferrer">Plantilla de Microsoft Excel</a> (.XLTX)  
* <a href="https://docs.fileformat.com/spreadsheet/xlt" target="_blank" rel="nofollow noopener noreferrer">Plantilla de Microsoft Excel 97-2003</a> (.XLT)  
* <a href="https://docs.fileformat.com/spreadsheet/xltm" target="_blank" rel="nofollow noopener noreferrer">Plantilla habilitada para macros de Microsoft Excel</a> (.XLTM)  
* <a href="https://docs.fileformat.com/spreadsheet/xlam/" target="_blank" rel="nofollow noopener noreferrer">Complemento de Microsoft Excel</a> (.XLAM)  
* <a href="https://en.wikipedia.org/wiki/SpreadsheetML" target="_blank" rel="nofollow noopener noreferrer">Hoja de cálculo XML de 2003</a> (.XML)  
* <a href="https://docs.fileformat.com/spreadsheet/ods" target="_blank" rel="nofollow noopener noreferrer">Hoja de cálculo OpenDocument</a> (.ODS)  
* <a href="https://docs.fileformat.com/spreadsheet/ots/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de hoja de cálculo OpenDocument</a> (.OTS)  
* <a href="https://docs.fileformat.com/spreadsheet/fods/" target="_blank" rel="nofollow noopener noreferrer">Hoja de cálculo OpenDocument Flat XML</a> (.FODS)  
* <a href="https://docs.fileformat.com/spreadsheet/csv" target="_blank" rel="nofollow noopener noreferrer">Archivo de valores separados por comas</a> (.CSV)  
* <a href="https://docs.fileformat.com/spreadsheet/tsv" target="_blank" rel="nofollow noopener noreferrer">Archivo de valores separados por tabulaciones</a> (.TSV)  
* <a href="https://docs.fileformat.com/spreadsheet/sxc/" target="_blank" rel="nofollow noopener noreferrer">Hoja de cálculo StarOffice Calc</a> (.SXC)  
* <a href="https://docs.fileformat.com/spreadsheet/numbers" target="_blank" rel="nofollow noopener noreferrer">Hoja de cálculo Apple Numbers</a> (.NUMBERS)  

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.

## Renderizar hojas de cálculo como HTML {#render-spreadsheets-as-html}

Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo de hoja de cálculo a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

<a name="unique-ID"></a>
Al renderizar hojas de cálculo en formato HTML, independientemente del modo de renderizado exacto (un archivo HTML por hoja de cálculo, o un único HTML para todas las hojas, con recursos incrustados o externos), siempre existe una tabla HTML `<table>` que contiene todos los datos de una hoja de cálculo, y un conjunto de propiedades CSS diferentes que se aplican a distintas partes de esta tabla (filas, celdas o sus rangos) y las decoran. Siempre existe una hoja de estilos CSS (incrustada o externa) con un conjunto de reglas y reglas @- (@at-rules), las cuales se vinculan con la tabla HTML y su contenido mediante diferentes selectores.

En algunos casos, es necesario integrar la GroupDocs.Viewer dentro de otra aplicación web. En este escenario puede surgir un problema cuando los estilos de la GroupDocs.Viewer interfieren con los estilos de la aplicación web principal. En particular, cuando GroupDocs.Viewer convierte la hoja de cálculo a HTML, crea varios conjuntos de reglas con selectores de tipo `<TR>`, `<TD>`, `<COL>`, `<BR>`, y dichos conjuntos de reglas pueden alterar el comportamiento de la página web principal.

Este era un problema en GroupDocs.Viewer antes de la versión 24.3. A partir de la <a href="https://releases.groupdocs.com/viewer/net/release-notes/2024/groupdocs-viewer-for-net-24-3-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 24.3</a>, al renderizar documentos de hojas de cálculo, GroupDocs.Viewer agrega un valor de ID único a cada elemento HTML y selector CSS, con el fin de eliminar cualquier interferencia con los estilos de la aplicación principal. Por lo tanto, ahora todos los selectores de tipo se reemplazan por selectores descendientes combinados de tipo e ID, como `#gdt-id-1 td`, `#gdt-id-2 tr`, etc. Esto elimina de forma definitiva cualquier conflicto de estilos.

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}

Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilos) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

#### Convertir un libro de Excel a HTML {#convert-an-excel-workbook-to-html}

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to HTML.
    // {0} is replaced with the current page number in the file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilo) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso  

#### Convertir un libro de Excel a HTML {#convert-an-excel-workbook-to-html-1}

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to HTML.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

### Convertir todas las hojas de cálculo de Excel en un solo archivo HTML {#convert-all-excel-worksheets-to-one-html-file}
  
Para convertir todas las hojas de cálculo en un solo archivo HTML, establezca la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/rendertosinglepage/" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.RenderToSinglePage</a> en `true`. Esta función es compatible en ambos casos: al convertir a HTML con recursos incrustados y con recursos externos.

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("Personal_net_worth_calculator.xlsx"))
{
    // Convert all Excel worksheets to one HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page.html");
    // Enable converting all worksheets to one file.
    viewOptions.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("Personal_net_worth_calculator.xlsx")
            ' Convert all Excel worksheets to one HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page.html")
            ' Enable converting all worksheets to one file.
            viewOptions.RenderToSinglePage = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Detectar un separador CSV/TSV  {#detect-a-csv-tsv-separator}
  
Si carga un archivo CSV/TSV para convertirlo a otro formato, habilite la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/detectseparator" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.DetectSeparator</a> en la vista de destino para detectar automáticamente el delimitador utilizado para separar los valores en el archivo de origen.

GroupDocs.Viewer puede detectar los siguientes separadores:

| Separador | Descripción |
|-----------|-------------|
| Coma (`,`) | Es el separador predeterminado |
| Punto y coma (`;`) | — |

<Tabs groupId="example12">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.csv"))
{
    // Convert the spreadsheet to HTML.
    // {0} is replaced with the current page number in the file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    // Detect a CSV/TSV separator.
    viewOptions.SpreadsheetOptions.DetectSeparator = true;
    viewer.View(viewOptions);
}          
```

</TabItem>

## Obtener nombres de hojas de cálculo {#get-worksheet-names}
  
GroupDocs.Viewer le permite obtener información sobre el archivo de hoja de cálculo de origen. Por ejemplo, puede recuperar los nombres de las hojas de cálculo, como se describe a continuación:  

1. Cree una instancia de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a> para una vista específica.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">Viewer.GetViewInfo</a> y pase la instancia de `ViewInfoOptions` como parámetro a este método.  
3. Utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo/properties/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> del objeto <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo" target="_blank" rel="nofollow noopener noreferrer">ViewInfo</a> devuelto para recorrer la lista de hojas de cálculo y recuperar los nombres de las hojas.

<Tabs groupId="example13">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (var viewer = new Viewer("sample.xlsx"))
{
    var viewInfoOptions = ViewInfoOptions.ForHtmlView();
    // Call this method to create a single page for each worksheet.
    viewInfoOptions.SpreadsheetOptions = SpreadsheetOptions.ForOnePagePerSheet();

    var viewInfo = viewer.GetViewInfo(viewInfoOptions);

    // Print the worksheet names in the console window.
    Console.WriteLine("The document contains the following worksheets:");
    foreach (Page page in viewInfo.Pages)
    {
        Console.WriteLine($" - Worksheet {page.Number}: '{page.Name}'");
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

            Dim viewInfo = viewer.GetViewInfo(viewInfoOptions)
        
            ' Print the worksheet names in the console window.
            Console.WriteLine("The document contains the following worksheets:")
            For Each page As Page In viewInfo.Pages
                Console.WriteLine($" - Worksheet {page.Number}: '{page.Name}'")
            Next
        End Using
    End Sub
End Module
```

GroupDocs.Viewer incluye la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions</a>, que le permite especificar distintas opciones de renderizado de hojas de cálculo (por ejemplo, puede mostrar encabezados de filas y columnas en el archivo de salida, representar líneas de cuadrícula o ajustar el desbordamiento del texto de las celdas). Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/spreadsheetoptions" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions</a> de una de las siguientes clases (según el formato del archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

## Renderizar encabezados de filas y columnas {#render-row-and-column-headings}
  
Las filas y columnas de una hoja de cálculo tienen nombres únicos que se muestran en el lado izquierdo y superior de la hoja. Las filas están numeradas (1, 2, 3, ..., 1048576) y las columnas están etiquetadas con letras (A, B, C, ..., XFD).

![Row and column headings in a worksheet](/net/viewer/images/rendering-basics/render-spreadsheets/excel-row-and-column-headings.png)

Habilite la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/renderheadings" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.RenderHeadings</a> para mostrar los encabezados de filas y columnas en el archivo de salida al renderizar su hoja de cálculo en formato HTML, PDF, PNG o JPEG.

El siguiente ejemplo demuestra cómo convertir un libro de Excel a PDF y mostrar los encabezados de filas y columnas en el archivo PDF de salida:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Render row and column headings.
    viewOptions.SpreadsheetOptions.RenderHeadings = true;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            ' Convert the spreadsheet to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Render row and column headings.
            viewOptions.SpreadsheetOptions.RenderHeadings = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Controlar el desbordamiento del texto en las celdas  {#control-cell-text-overflow}
  
La opción <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.TextOverflowMode</a> le permite evitar el desbordamiento del texto en las celdas de la hoja de cálculo (consulte la imagen a continuación) al convertir su archivo de hoja de cálculo a formato HTML, PDF o imagen.

![Text overflow in a cell](/net/viewer/images/rendering-basics/render-spreadsheets/excel-text-overflow.png)

Puede establecer la propiedad `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/spreadsheetoptions/properties/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode</a>` en uno de los siguientes valores:

* `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.OverlayIfNextIsEmpty</a>` (predeterminado): permite que el texto se desborde hacia las celdas adyacentes si estas no contienen datos. Si las celdas adyacentes no están vacías, el texto que se desborda se trunca.

    ![TextOverflowMode.OverlayIfNextIsEmpty](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-overlay-if-empty.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.Overlay</a> — El texto siempre se desborda hacia las celdas adyacentes, incluso si estas contienen datos.

    ![TextOverflowMode.Overlay](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-overlay.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.AutoFitColumn</a> --- Aumenta el ancho de la columna para ajustar el texto de la celda.

    ![TextOverflowMode.AutoFitColum](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-autofit-column.png)

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoverflowmode" target="_blank" rel="nofollow noopener noreferrer">TextOverflowMode.HideText</a> — Oculta el texto que se desborda de los límites de la celda.
  
    ![TextOverflowMode.HideText](/net/viewer/images/rendering-basics/render-spreadsheets/text-overflow-mode-hide-text.png)

El siguiente ejemplo demuestra cómo configurar esta opción en el código:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    // Convert the spreadsheet to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Specify the AutoFitColumn mode.
    viewOptions.SpreadsheetOptions.TextOverflowMode = TextOverflowMode.AutoFitColumn;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

    End Sub
```

## Renderizar filas y columnas ocultas  {#render-hidden-rows-and-columns}
  
Utilice las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/renderhiddenrows" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.SpreadsheetOptions.RenderHiddenRows</a> y <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/renderhiddencolumns" target="_blank" rel="nofollow noopener noreferrer">ViewOptions.SpreadsheetOptions.RenderHiddenColumns</a> para mostrar filas y columnas ocultas en el archivo de salida al renderizar su hoja de cálculo en formatos HTML, PDF, PNG o JPEG.

El ejemplo siguiente demuestra cómo configurar esta opción en código. Las filas **20** y **21** y la columna **E** están ocultas en el libro de Excel de origen. 

![Hidden rows and columns in a worksheet](/net/viewer/images/rendering-basics/render-spreadsheets/excel-hidden-columns-and-rows.png)

<Tabs groupId="example4">

```csharp
using GroupDocs.Viewer;

    viewOptions.SpreadsheetOptions.RenderHiddenColumns = true;
    viewer.View(viewOptions);
}
```

<TabItem value="vb-net" label="VB.NET">

## Establecer márgenes de hoja de cálculo en las páginas PDF de salida {#set-worksheet-margins-in-the-output-pdf-pages}
  
Utilice las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/spreadsheetoptions/properties/rendergridlines" target="_blank" rel="nofollow noopener noreferrer">SpreadsheetOptions.RenderGridLines</a> para establecer los márgenes de las hojas de cálculo en el PDF de salida. Si los márgenes se establecen en un valor menor que 0 o no se establecen, se utilizará el valor predeterminado.

El siguiente ejemplo de código demuestra cómo convertir un libro de Excel a PDF y establecer márgenes opcionales para las hojas de cálculo en el archivo PDF de salida:

<Tabs groupId="example8">

<TabItem value="c" label="C#" default>

```cs
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("invoice.xlsx"))
{
    var viewOptions = new PdfViewOptions("output.pdf");
	
    // Set margins for worksheets in the output pdf pages
    viewOptions.SpreadsheetOptions.LeftMargin = 0;
    viewOptions.SpreadsheetOptions.RightMargin = 0.5;
    viewOptions.SpreadsheetOptions.TopMargin = 1;
    viewOptions.SpreadsheetOptions.BottomMargin = -10; // set to default value
	
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("invoice.xlsx")
            Dim viewOptions = New PdfViewOptions("output.pdf")
        
            ' Set margins for worksheets in the output pdf pages
            viewOptions.SpreadsheetOptions.LeftMargin = 0
            viewOptions.SpreadsheetOptions.RightMargin = 0.5
            viewOptions.SpreadsheetOptions.TopMargin = 1
            viewOptions.SpreadsheetOptions.BottomMargin = -10 ' set to default value
        
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite convertir documentos de texto a formatos HTML, PDF, PNG y JPEG, de modo que pueda visualizar el contenido del documento en un navegador web, una aplicación de visor de PDF o una aplicación de visor de imágenes.

Para comenzar con la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase al constructor de la clase el documento de texto que desea visualizar. Puede cargar el documento desde un archivo o un flujo (stream). Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento a formato HTML, PDF, PNG o JPEG. Estos métodos le permiten representar todo el documento o páginas específicas.

Cuando carga un documento de texto desde un archivo o <a href="https://learn.microsoft.com/en-us/dotnet/api/system.io.filestream" target="_blank" rel="nofollow noopener noreferrer">FileStream</a>, GroupDocs.Viewer detecta el formato del documento en función de la extensión del nombre de archivo. Si utiliza otros tipos de flujos (stream) para cargar su documento (como <a href="https://learn.microsoft.com/en-us/dotnet/api/system.io.memorystream" target="_blank" rel="nofollow noopener noreferrer">MemoryStream</a> o <a href="https://learn.microsoft.com/en-us/dotnet/api/system.net.sockets.networkstream" target="_blank" rel="nofollow noopener noreferrer">NetworkStream</a>), GroupDocs.Viewer solo puede determinar el formato del archivo para los siguientes tipos de documentos: TXT, CS y VB. Para otros tipos de archivo, debe especificar explícitamente su formato. Para ello, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> con el parámetro <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> y pase esta instancia al constructor de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

## Renderizar archivos de texto como HTML {#render-text-files-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo de texto en HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).

### Crear archivos HTML con recursos incrustados {#create-html-files-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("TermsOfService.txt"))
{
    // Convert the text file to HTML.
    // {0} is replaced with the current page number in the output file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("TermsOfService.txt")
            ' Convert the text file to HTML.
            ' {0} is replaced with the current page number in the output file names.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear archivos HTML con recursos externos  {#create-html-files-with-external-resources}
  
Si desea almacenar los archivos HTML de salida y los archivos de recursos adicionales (como fuentes, imágenes y hojas de estilo) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta con los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("TermsOfService.txt"))
{
    // Convert the text file to HTML.
    // Specify the output file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("TermsOfService.txt")
            ' Convert the text file to HTML.
            ' Specify the output file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

### Crear una única página HTML {#create-a-single-html-page}
  
Si necesita mostrar todo el contenido del documento en una única página HTML, habilite la opción <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/properties/rendertosinglepage" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.RenderToSinglePage</a>, como se muestra a continuación:

<Tabs groupId="example5">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("TermsOfService.txt"))
{
    // Convert the text file to HTML.
    // Specify the output file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html");
    // Render the file to a single page. 
    viewOptions.RenderToSinglePage = true;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("TermsOfService.txt")
            ' Convert the text file to HTML.
            ' Specify the output file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("output.html")
            ' Render the file to a single page. 
            viewOptions.RenderToSinglePage = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Renderizar archivos de texto como PNG {#render-text-files-as-png}

## Especificar opciones de renderizado  {#specify-rendering-options}
  
GroupDocs.Viewer admite la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoptions" target="_blank" rel="nofollow noopener noreferrer">TextOptions</a>, que le permite especificar distintas opciones para el renderizado de archivos de texto. Para acceder a estas opciones, utilice la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/baseviewoptions/properties/textoptions" target="_blank" rel="nofollow noopener noreferrer">TextOptions</a> en una de las siguientes clases (según el formato del archivo de salida):

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>  

La clase `TextOptions` contiene las siguientes propiedades:

* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoptions/properties/maxrowsperpage" target="_blank" rel="nofollow noopener noreferrer">MaxRowsPerPage</a> — Especifica el número máximo de filas por página. El valor predeterminado es **55**.  
* <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/textoptions/properties/maxcharsperrow" target="_blank" rel="nofollow noopener noreferrer">MaxCharsPerRow</a> — Especifica el número máximo de caracteres por fila. El valor predeterminado es **85**.  

El siguiente ejemplo muestra cómo modificar la cantidad de filas mostradas en cada página HTML:

<Tabs groupId="example9">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("TermsOfService.txt"))
{
    // Convert the text file to HTML.
    // {0} is replaced with the current page number in the output file names.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    // Set the maximum number of rows per page.
    viewOptions.TextOptions.MaxRowsPerPage = 30;
    viewer.View(viewOptions);
}
```

</TabItem>

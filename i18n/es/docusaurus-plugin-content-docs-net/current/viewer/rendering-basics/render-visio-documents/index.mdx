<a href="https://products.groupdocs.com/viewer/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer for .NET</a> le permite representar sus diagramas de Visio en formatos HTML, PDF, PNG y JPEG. No es necesario utilizar Microsoft Visio ni otro software de creación de diagramas para cargar y visualizar archivos de Visio dentro de su aplicación .NET (web o de escritorio).

Para comenzar a utilizar la API GroupDocs.Viewer, cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el documento que desea visualizar al constructor de la clase. Puede cargar el documento desde un archivo o un flujo. Llame a una de las sobrecargas del método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir el documento en formato HTML, PDF o imagen. Estos métodos le permiten representar todo el documento o páginas específicas.

## Formatos de archivo de Visio admitidos {#supported-visio-file-formats}
  
GroupDocs.Viewer admite los siguientes formatos de archivo de Visio:

* <a href="https://docs.fileformat.com/visio/vsdx/" target="_blank" rel="nofollow noopener noreferrer">Dibujo de Visio</a> (.VSDX)  
* <a href="https://docs.fileformat.com/visio/vsd/" target="_blank" rel="nofollow noopener noreferrer">Dibujo de Visio 2003-2010</a> (.VSD)  
* <a href="https://docs.fileformat.com/visio/vsdm/" target="_blank" rel="nofollow noopener noreferrer">Dibujo habilitado para macros de Visio</a> (.VSDM)  
* <a href="https://docs.fileformat.com/visio/vssx/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de símbolos de Visio</a> (.VSSX)  
* <a href="https://docs.fileformat.com/visio/vss/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de símbolos de Visio 2003-2010</a> (.VSS)  
* <a href="https://docs.fileformat.com/visio/vssm/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de símbolos habilitada para macros de Visio</a> (.VSSM)  
* <a href="https://docs.fileformat.com/visio/vstx/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de Visio</a> (.VSTX)  
* <a href="https://docs.fileformat.com/visio/vst/" target="_blank" rel="nofollow noopener noreferrer">Plantilla de Visio 2003-2010</a> (.VST)  
* <a href="https://docs.fileformat.com/visio/vstm/" target="_blank" rel="nofollow noopener noreferrer">Plantilla habilitada para macros de Visio</a> (.VSTM)  
* <a href="https://docs.fileformat.com/visio/vdx/" target="_blank" rel="nofollow noopener noreferrer">Archivo XML de dibujo de Visio</a> (.VDX)  
* <a href="https://docs.fileformat.com/visio/vsx/" target="_blank" rel="nofollow noopener noreferrer">Archivo XML de plantilla de símbolos de Visio</a> (.VSX)  
* <a href="https://docs.fileformat.com/visio/vtx/" target="_blank" rel="nofollow noopener noreferrer">Archivo XML de plantilla de Visio</a> (.VTX)  
* <a href="https://docs.fileformat.com/visio/vdw/" target="_blank" rel="nofollow noopener noreferrer">Dibujo web de Visio</a> (.VDW)

GroupDocs.Viewer puede detectar automáticamente el formato del documento basándose en la información del encabezado del archivo.

:::info
La familia de formatos de archivos de Visio actualmente no es compatible con el entorno de ejecución `net6.0` (<a href="https://www.nuget.org/packages/GroupDocs.Viewer.Net60" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer.Net60</a>). Están soportados en Windows con `net462` y `net6.0-windows`.
:::

## Renderizar archivos Visio como HTML {#render-visio-files-as-html}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo Visio a HTML. Las propiedades de la clase `HtmlViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede incrustar todos los recursos externos en el archivo HTML generado, minimizar el archivo de salida y optimizarlo para su impresión. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado en HTML](/net/viewer/developer-guide/rendering-documents/rendering-to-html/).  

### Crear un archivo HTML con recursos incrustados {#create-an-html-file-with-embedded-resources}
  
Para guardar todos los elementos de una página HTML (incluidos texto, gráficos y hojas de estilo) en un único archivo, llame al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forembeddedresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForEmbeddedResources</a> y especifique el nombre del archivo de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create an HTML file for each drawing page.
    // {0} is replaced with the current page number in the file name.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("flowchart.vsdx")
            ' Create an HTML file for each drawing page.
            ' {0} is replaced with the current page number in the file name.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources("page_{0}.html")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

### Crear un archivo HTML con recursos externos  {#create-an-html-file-with-external-resources}
  
Si desea almacenar un archivo HTML y archivos de recursos adicionales (como fuentes, imágenes y hojas de estilos) por separado, invoque el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/methods/forexternalresources/index" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.ForExternalResources</a> y pase los siguientes parámetros:

  * El formato de la ruta del archivo de salida  
  * El formato de la ruta de la carpeta que contiene los recursos externos  
  * El formato de la URL del recurso

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create an HTML file for each drawing page.
    // Specify the HTML file names and location of external resources.
    // {0} and {1} are replaced with the current page number and resource name, respectively.
    var viewOptions = HtmlViewOptions.ForExternalResources(
        "page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("flowchart.vsdx")
            ' Create an HTML file for each drawing page.
            ' Specify the HTML file names and location of external resources.
            ' {0} and {1} are replaced with the current page number and resource name, respectively.
            Dim viewOptions = HtmlViewOptions.ForExternalResources("page_{0}.html", "page_{0}/resource_{0}_{1}", "page_{0}/resource_{0}_{1}")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Renderizar archivos Visio como PDF {#render-visio-files-as-pdf}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo Visio a PDF. Las propiedades de la clase `PdfViewOptions` le permiten controlar el proceso de conversión. Por ejemplo, puede proteger el archivo PDF resultante, reordenar sus páginas y especificar la calidad de las imágenes del documento. Consulte la siguiente sección de documentación para obtener más detalles: [Renderizado a PDF](/net/viewer/developer-guide/rendering-documents/rendering-to-pdf/).

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;

    viewer.View(viewOptions);
}
```

## Renderizar archivos Visio como PNG {#render-visio-files-as-png}
  
Cree una instancia de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y pásela al método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/view/index" target="_blank" rel="nofollow noopener noreferrer">Viewer.View</a> para convertir un archivo Visio a PNG. Utilice las propiedades <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Height</a> y <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Width</a> para especificar el tamaño de la imagen de salida en píxeles.

<Tabs groupId="example4">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("flowchart.vsdx"))
{
    // Create a PNG image for each drawing page.
    // {0} is replaced with the current page number in the image name.
    var viewOptions = new PngViewOptions("output_{0}.png");
    // Set width and height.
    viewOptions.Width = 950;
    viewOptions.Height = 800;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
            ' Set width and height.

            viewOptions.Height = 800
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Renderizar únicamente formas de diagrama {#render-only-diagram-shapes}
  
GroupDocs.Viewer le permite representar las formas utilizadas en un diagrama de Visio o almacenadas en un archivo de plantilla de Visio. Estas formas se muestran en el panel **Plantilla de documento** de Microsoft Visio.

![Document Stencil pane in Visio](/net/viewer/images/rendering-basics/render-visio-documents/visio-document-stencil.png)

Para representar únicamente las formas maestras contenidas en el archivo de Visio, habilite la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/visiorenderingoptions/properties/renderfiguresonly" target="_blank" rel="nofollow noopener noreferrer">VisioRenderingOptions.RenderFiguresOnly</a> en una de las siguientes clases (según el formato del archivo de salida):

| Clase | Descripción |
|-------|-------------|
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> | Opciones para representar en HTML |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> | Opciones para representar en PDF |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> | Opciones para representar en PNG |
| <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> | Opciones para representar en JPG |

La propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/visiorenderingoptions/properties/figurewidth" target="_blank" rel="nofollow noopener noreferrer">VisioRenderingOptions.FigureWidth</a> le permite especificar el ancho de la forma en píxeles. La altura se calcula automáticamente según la relación de aspecto de cada forma.

<Tabs groupId="example6">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("map.vsdx"))
{
    // Convert the Visio file to PDF.
    var viewOptions = new PdfViewOptions("output.pdf");
    // Render the master shapes only.
    viewOptions.VisioRenderingOptions.RenderFiguresOnly = true;
    // Specify shape width in pixels.
    viewOptions.VisioRenderingOptions.FigureWidth = 200;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("map.vsdx")
            ' Convert the Visio file to PDF.
            Dim viewOptions = New PdfViewOptions("output.pdf")
            ' Render the master shapes only.
            viewOptions.VisioRenderingOptions.RenderFiguresOnly = True
            ' Specify shape width in pixels.
            viewOptions.VisioRenderingOptions.FigureWidth = 200
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

De forma predeterminada, el registro (logging) está deshabilitado al renderizar documentos. Puede registrar en la consola o en un archivo.

Para realizar el registro, utilice la interfaz <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.logging/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>. Esta interfaz define los métodos necesarios para instanciar y liberar el flujo de salida del archivo. Asimismo, utilice las siguientes clases:

* La clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.logging/consolelogger" target="_blank" rel="nofollow noopener noreferrer">ConsoleLogger</a> define los métodos necesarios para registrar en la consola.
* La clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.logging/filelogger" target="_blank" rel="nofollow noopener noreferrer">FileLogger</a> define los métodos necesarios para registrar en un archivo.

El registro contiene los tres tipos siguientes de mensajes:

* Error: indica excepciones no recuperables.
* Advertencia: indica excepciones recuperables o esperadas.
* Rastreo (Trace): indica información general.

## Registro en un archivo {#logging-to-a-file}
  
El fragmento de código siguiente muestra cómo registrar en un archivo utilizando la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.logging/filelogger" target="_blank" rel="nofollow noopener noreferrer">FileLogger</a>:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Logging;
using GroupDocs.Viewer.Options;
// ...

// Create logger and specify the output file.
FileLogger fileLogger = new FileLogger("output.log");

// Create ViewerSettings and specify FileLogger.
ViewerSettings viewerSettings = new ViewerSettings(fileLogger);

// Render a document.
using (Viewer viewer = new Viewer("sample.docx",viewerSettings))
{
    ViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources("result.html");
    viewer.View(viewOptions);
}
```

</TabItem>

## Implementación de un registrador personalizado  {#implementing-custom-logger}
  
Para crear un registrador, implemente la interfaz <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.logging/ilogger" target="_blank" rel="nofollow noopener noreferrer">ILogger</a>:

* Para mensajes de seguimiento, implemente el método `public void Trace(string message)`.
* Para mensajes de advertencia, implemente el método `public void Warning(string message)`.
* Para mensajes de error, implemente el método `public void Error(string message)`.

El siguiente fragmento de código muestra cómo implementar un registrador de archivos simple:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using System;
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Logging;
using GroupDocs.Viewer.Options;
// ...

// Create logger and specify the output file.
CustomLogger customLogger = new CustomLogger("output.log");

// Create ViewerSettings and specify CustomLogger.
ViewerSettings viewerSettings = new ViewerSettings(customLogger);

// Render a document.
using (Viewer viewer = new Viewer("sample.docx",viewerSettings))
{
    ViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources("result.html");

    viewer.View(viewOptions);
}

/// <summary>
/// Writes log messages to a file.
/// </summary>
public class CustomLogger : ILogger
{
    private readonly string _fileName;

    private CustomLogger() { }

    /// <summary>
    /// Create logger to a file.
    /// </summary>
    /// <param name="fileName">Full file name with path</param>
    public CustomLogger(string fileName)
    {
        _fileName = fileName;
    }

    /// <summary>
    /// Writes trace message to the file.
    /// Trace log messages provide generally useful information about application flow.
    /// </summary>
    /// <param name="message">The trace message.</param>
    /// <exception cref="System.ArgumentNullException">Thrown when <paramref name="message"/> is null.</exception>
    public void Trace(string message)
    {
        if (message == null)
            throw new ArgumentNullException(nameof(message));

        using (StreamWriter wr = new StreamWriter(_fileName, true))
        {
            wr.WriteLine($"[TRACE] {message}");
        }
    }

    /// <summary>
    /// Writes warning message to the file;
    /// Warning log messages provide information about the unexpected and recoverable events in application flow.
    /// </summary>
    /// <param name="message">The warning message.</param>
    /// <exception cref="System.ArgumentNullException">Thrown when <paramref name="message"/> is null.</exception>
    public void Warning(string message)
    {
        if (message == null)
            throw new ArgumentNullException(nameof(message));

        using (StreamWriter wr = new StreamWriter(_fileName, true))
        {
            wr.WriteLine($"[WARN] {message}");
        }
    }

    /// <summary>
    /// Writes an error message to the file.
    /// Error log messages provide information about unrecoverable events in application flow.
    /// </summary>
    /// <param name="message">The error message.</param>
    /// <param name="exception">The exception.</param>
    /// <exception cref="System.ArgumentNullException">Thrown when <paramref name="message"/> is null.</exception>
    /// <exception cref="System.ArgumentNullException">Thrown when <paramref name="exception"/> is null.</exception>
    public void Error(string message, Exception exception)
    {
        if (message == null)
            throw new ArgumentNullException(nameof(message));
        if (exception == null)
            throw new ArgumentNullException(nameof(exception));

        using (StreamWriter wr = new StreamWriter(_fileName, true))
        {
            wr.WriteLine($"[ERROR] {message}, exception: {exception}");
        }
    }
}
```

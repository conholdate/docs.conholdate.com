Una vez cargado un documento, puede recuperar sus propiedades. Por ejemplo, puede obtener la familia de formatos y el número de páginas para seleccionar una estrategia de renderizado. Además, puede mostrar información sobre el documento durante el renderizado o con el documento renderizado.

Esta sección describe cómo recuperar las propiedades del documento. También muestra cómo obtener una lista de formatos de archivo admitidos.

Para más detalles, consulte las siguientes páginas:

:::info
* Un tipo de archivo es una forma estándar en la que la información se codifica para su almacenamiento en un archivo informático. Por ejemplo, Microsoft Word (.docx) y Adobe PDF (.pdf) son dos tipos de archivo diferentes.  
* Una familia de formatos es un grupo de varios tipos de archivo para los cuales una aplicación proporciona información adicional. Por ejemplo, los archivos comprimidos (.7z, .rar, .zip, etc.) o los archivos de Outlook (.ost, .pst) son familias de formatos.
:::

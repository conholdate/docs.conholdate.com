Una familia de formatos es un grupo de varios tipos de archivos para los cuales una aplicación proporciona información adicional. Por ejemplo, los archivos comprimidos (.7z, .rar, .zip, etc.) o los archivos de Outlook (.ost, .pst) son familias de formatos.

Puede obtener la familia de formatos y la información adicional utilizando el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/viewer/methods/getviewinfo" target="_blank" rel="nofollow noopener noreferrer">GetViewInfo</a>, que devuelve un objeto <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.results/viewinfo" target="_blank" rel="nofollow noopener noreferrer">ViewInfo</a>.

GroupDocs.Viewer proporciona información adicional para las siguientes familias de formatos:

* Archivos comprimidos: una colección de carpetas dentro del archivo comprimido (consulte [Obtener información sobre carpetas en un archivo comprimido](/net/viewer/rendering-basics/render-archives/));
* Dibujos CAD: una colección de diseños y capas (consulte [Obtener información sobre diseños y capas existentes](/net/viewer/rendering-basics/render-cad-documents/render-cad-documents/));
* Archivos de datos de Outlook: una colección de carpetas (consulte [Obtener información sobre carpetas en un archivo de datos de Outlook](/net/viewer/rendering-basics/render-outlook-data-files/));
* Documentos PDF: una bandera que indica si se permite la impresión del documento (consulte [Obtener información sobre un archivo PDF](/net/viewer/rendering-basics/render-pdf-documents/));
* Archivos de Microsoft Project: las fechas de inicio y finalización del proyecto (consulte [Obtener información sobre un archivo de Project](/net/viewer/rendering-basics/render-ms-project-files/)).

## Obtener el tipo de archivo y el número de páginas a partir de un archivo {#get-the-file-type-and-the-pages-count-from-a-file}
  
El siguiente fragmento de código muestra cómo obtener el tipo de archivo y el número de páginas a partir de un archivo:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("sample.pdf"))
{
    // Get file information.
    ViewInfoOptions viewInfoOptions = ViewInfoOptions.ForHtmlView();
    ViewInfo viewInfo = viewer.GetViewInfo(viewInfoOptions);

    // Display file type and pages count.
    Console.WriteLine("Document type is: " + viewInfo.FileType);
    Console.WriteLine("Pages count: " + viewInfo.Pages.Count);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.pdf")
            ' Get file information.
            Dim viewInfoOptions As ViewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo As ViewInfo = viewer.GetViewInfo(viewInfoOptions)

            ' Display file type and pages count.
            Console.WriteLine("Document type is: " & viewInfo.FileType.ToString())
            Console.WriteLine("Pages count: " & viewInfo.Pages.Count.ToString())
        End Using
    End Sub
End Module
```

</TabItem>

## Obtener el tipo de archivo y la cantidad de páginas desde un flujo  {#get-the-file-type-and-the-pages-count-from-a-stream}
  
El siguiente fragmento de código muestra cómo obtener el tipo de archivo y la cantidad de páginas desde un flujo:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using System;
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer(File.OpenRead("sample.pdf")))
{
    ViewInfoOptions viewInfoOptions = ViewInfoOptions.ForHtmlView();
    ViewInfo viewInfo = viewer.GetViewInfo(viewInfoOptions);
 
    Console.WriteLine("Document type is: " + viewInfo.FileType);
    Console.WriteLine("Pages count: " + viewInfo.Pages.Count);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer(File.OpenRead("sample.pdf"))
            Dim viewInfoOptions As ViewInfoOptions = ViewInfoOptions.ForHtmlView()
            Dim viewInfo As ViewInfo = viewer.GetViewInfo(viewInfoOptions)

            Console.WriteLine("Document type is: " & viewInfo.FileType.ToString())
            Console.WriteLine("Pages count: " & viewInfo.Pages.Count.ToString())
        End Using
    End Sub
End Module
```

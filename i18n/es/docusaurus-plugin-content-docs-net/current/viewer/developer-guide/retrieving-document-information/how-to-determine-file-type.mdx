Un tipo de archivo es una forma estándar en la que se codifica la información para su almacenamiento en un archivo informático. Por ejemplo, Microsoft Word (.docx) y Adobe PDF (.pdf) son dos tipos de archivo diferentes.

Utilizando GroupDocs.Viewer, puede determinar el tipo de archivo de una de las siguientes maneras:
* [Extensión del archivo](#determine-file-type-by-the-file-extension);
* [Tipo de medio](#determine-file-type-by-media-type);
* [Firma del archivo](#determine-file-type-by-stream).

## Determinar el tipo de archivo mediante la extensión del archivo {#determine-the-file-type-by-the-file-extension}

Para determinar el tipo de archivo a partir de la extensión del archivo, utilice el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/fromextension/#fromextension" target="_blank" rel="nofollow noopener noreferrer">FromExtension()</a> de <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente fragmento de código muestra cómo determinar un tipo de archivo mediante la extensión del archivo:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

// Specify a file extension.
string extension = ".docx";
// Set a file type using the extension.
FileType fileType = FileType.FromExtension(extension);
// Display the extension and the file type.
Console.WriteLine($"Extension {extension}; File type: {fileType}.");
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        ' Specify a file extension.
        Dim extension As String = ".docx"
        ' Set a file type using the extension.
        Dim fileType As FileType = FileType.FromExtension(extension)
        ' Display the extension and the file type.
        Console.WriteLine($"Extension {extension}; File type: {fileType}.")
    End Sub
End Module
```

</TabItem>

</Tabs>

## Determinar el tipo de archivo por tipo de medio  {#determine-file-type-by-media-type}
  
Si recibe un archivo a través de Internet, puede verificar su encabezado de tipo de medio utilizando el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/methods/frommediatype" target="_blank" rel="nofollow noopener noreferrer">FromMediaType()</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente fragmento de código muestra cómo determinar el tipo de archivo mediante el encabezado de medio:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

string mediaType = "application/pdf";
FileType fileType = FileType.FromMediaType(mediaType);
Console.WriteLine($"Media-type {mediaType}; File type: {fileType}.");
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Dim mediaType As String = "application/pdf"
        Dim fileType As FileType = FileType.FromMediaType(mediaType)
        Console.WriteLine($"Media-type {mediaType}; File type: {fileType}.")
    End Sub
End Module
```

</TabItem>

</Tabs>

## Determinar el tipo de archivo mediante el flujo  {#determine-file-type-by-the-stream}
  
Cuando no conozca la extensión del archivo ni la cabecera del tipo de medio, puede intentar determinar el tipo de archivo mediante el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype/methods/fromstream" target="_blank" rel="nofollow noopener noreferrer">FromStream()</a> de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>. GroupDocs.Viewer intentará leer la firma y asignarla al tipo de archivo correspondiente.

El fragmento de código siguiente muestra cómo determinar el tipo de archivo mediante la firma del archivo:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using System;
using System.IO;
using GroupDocs.Viewer;
// ...

using (Stream stream = File.OpenRead("sample.docx"))
{
    FileType fileType = FileType.FromStream(stream);
    Console.WriteLine($"File type: {fileType}.");
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports System.IO
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Using stream As Stream = File.OpenRead("sample.docx")
            Dim fileType As FileType = FileType.FromStream(stream)
            Console.WriteLine($"File type: {fileType}.")
        End Using
    End Sub
End Module
```

</TabItem>

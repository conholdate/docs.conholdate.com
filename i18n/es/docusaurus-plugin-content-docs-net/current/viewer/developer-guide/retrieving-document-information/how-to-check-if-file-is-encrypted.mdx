El cifrado protege los datos y permite que solo las personas autorizadas abran el archivo. Por lo tanto, solo quienes tengan una clave de cifrado (como una contraseña) pueden abrir y ver un archivo.

## Comprobar si un archivo está cifrado en línea {#check-if-a-file-is-encrypted-online}
  
1. Navegue hasta <a href="https://products.conholdate.app/viewer" target="_blank">Conholdate.Viewer App</a>. 

![GroupDocs.Viewer App](/net/viewer/images/developer-guide/retrieving-document-information/how-to-check-if-file-is-encrypted/viewe-app-upload-file.png)

2. Sube tu archivo. Si se te pide que ingreses una contraseña para abrir el archivo, este está cifrado.

![GroupDocs.Viewer App password prompt](/net/viewer/images/developer-guide/retrieving-document-information/how-to-check-if-file-is-encrypted/viewe-app-password-prompt.png)

:::warning
Es importante tener precaución al subir archivos sensibles a servicios en línea. Para archivos críticos, recomendamos utilizar un método programático.
:::

## Verificar programáticamente el cifrado de archivos  {#programmatically-check-for-file-encryption}
  
Utilice el método _GetFileInfo()_, que devuelve el tipo de archivo y una bandera que indica si el archivo está cifrado. El siguiente fragmento de código muestra cómo verificar si un archivo está cifrado. 

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("protected.pdf"))
{
    // Get file information.
    FileInfo fileInfo = viewer.GetFileInfo();

    // Display the file type and flag if the file is encrypted.
    Console.WriteLine("File type is: " + fileInfo.FileType);
    Console.WriteLine("File encrypted: " + fileInfo.Encrypted);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("protected.pdf")
            ' Get file information.
            Dim fileInfo As FileInfo = viewer.GetFileInfo()
        
            ' Display the file type and flag if the file is encrypted.
            Console.WriteLine("File type is: " & fileInfo.FileType.ToString())
            Console.WriteLine("File encrypted: " & fileInfo.Encrypted.ToString())
        End Using
    End Sub
End Module
```

</TabItem>

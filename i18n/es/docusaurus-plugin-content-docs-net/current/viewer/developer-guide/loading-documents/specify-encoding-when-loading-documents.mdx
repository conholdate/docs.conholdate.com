Esta función es compatible con los siguientes tipos de archivos:

* <a href="https://docs.fileformat.com/word-processing/txt/" target="_blank" rel="nofollow noopener noreferrer">Archivos de texto sin formato (.txt)</a>  
* <a href="https://docs.fileformat.com/spreadsheet/csv/" target="_blank" rel="nofollow noopener noreferrer">Valores separados por comas (.csv)</a>  
* <a href="https://docs.fileformat.com/spreadsheet/tsv/" target="_blank" rel="nofollow noopener noreferrer">Valores separados por tabulaciones (.tsv)</a>  
* <a href="https://docs.fileformat.com/email/eml/" target="_blank" rel="nofollow noopener noreferrer">Mensaje de correo electrónico (.eml)</a>  

Diferentes codificaciones utilizan distintas secuencias de bytes para representar caracteres, y abrir un archivo con la codificación incorrecta provoca una representación errónea de los caracteres. Para representar correctamente un archivo, se debe especificar la codificación adecuada al abrirlo. Otra opción consiste en convertirlo previamente a `UTF-8`. De forma predeterminada, GroupDocs.Viewer utiliza la codificación `UTF-8`.

Por ejemplo, cuando intenta abrir el archivo [sample-shift-jis.txt](/net/viewer/sample-files/developer-guide/loading-documents/specify-encoding-when-loading-documents/sample-shift-jis.txt) en el Bloc de notas, el texto `これはShift_JISエンコード用のサンプルテキストです。` aparecerá como símbolos extraños, ya que `ANSI` está interpretando incorrectamente los valores de byte específicos de `Shift_JIS`.

![Shift_Jis text file opened in Notepad](/net/viewer/images/developer-guide/loading-documents/specify-encoding-when-loading-documents/shift-jis-in-notepad.png)

Para representar correctamente un archivo de texto, puede establecer la codificación utilizando la clase `LoadOptions`. En el fragmento de código siguiente, estableceremos la codificación `Shift_JIS` y representaremos el archivo de texto en HTML:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System.Text;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Specify an encoding.
LoadOptions loadOptions = new LoadOptions();
loadOptions.Encoding = Encoding.GetEncoding("shift_jis");
// Render a file.
using (Viewer viewer = new Viewer("sample-shift-jis.txt", loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.Text
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        ' Specify an encoding.
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.Encoding = Encoding.GetEncoding("shift_jis")
        ' Render a file.
        Using viewer As Viewer = New Viewer("sample-shift-jis.txt", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

Para representar documentos, primero debe cargarlos. Esta sección describe las formas de cargar documentos implementadas en GroupDocs.Viewer.

También puede definir opciones de carga de documentos, como un tipo de documento o una contraseña para un documento protegido con contraseña. Para ello, utilice los parámetros del constructor y las propiedades de la clase <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>.

GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.
:::

Al cargar un documento especificando una ruta a un archivo o utilizando <a href="https://docs.microsoft.com/en-us/dotnet/api/system.io.filestream" target="_blank" rel="nofollow noopener noreferrer">FileStream</a>, GroupDocs.Viewer determina el tipo de archivo según su extensión. De lo contrario, GroupDocs.Viewer intenta determinar el tipo de archivo mediante su firma o contenido. Este proceso consume tiempo y puede afectar el rendimiento.

Puede especificar el tipo de archivo utilizando <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Si lo hace, GroupDocs.Viewer omite la detección del tipo de archivo y utiliza el tipo especificado.

El siguiente fragmento de código muestra cómo especificar el tipo de archivo al cargar un documento:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

Stream stream = GetFileStream("sample.docx"); //TODO: implement your method

// Specify the file type.
LoadOptions loadOptions = new LoadOptions(FileType.DOCX);

//Render a file.
using (Viewer viewer = new Viewer(stream, loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim stream As Stream = GetFileStream("sample.docx") 'TODO: implement your method
    
        ' Specify the file type.
        Dim loadOptions As LoadOptions = New LoadOptions(FileType.DOCX)
    
        'Render a file.
        Using viewer As Viewer = New Viewer(stream, loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

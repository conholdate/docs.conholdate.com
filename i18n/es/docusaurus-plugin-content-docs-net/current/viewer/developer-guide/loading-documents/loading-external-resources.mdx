Si el documento contiene recursos externos, como imágenes, GroupDocs.Viewer los carga al representar un documento. Esto permite que el documento se muestre correctamente, pero representa un riesgo potencial de seguridad.

GroupDocs.Viewer le permite gestionar la carga de los recursos externos contenidos en un documento. Estas funciones son compatibles con los siguientes formatos:  
- <a href="https://docs.fileformat.com/word-processing/" target="_blank" rel="nofollow noopener noreferrer">Formatos de archivo de procesamiento de texto</a>  
- <a href="https://docs.fileformat.com/web/" target="_blank" rel="nofollow noopener noreferrer">Formatos de archivo web</a>  
- <a href="https://docs.fileformat.com/spreadsheet/" target="_blank" rel="nofollow noopener noreferrer">Formatos de archivo de hoja de cálculo</a>  

Utilice el objeto <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> para gestionar la carga de recursos externos.

## Omitir la carga de recursos externos {#skip-loading-of-external-resources}
  
El siguiente fragmento de código muestra cómo denegar la carga de recursos externos:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

LoadOptions loadOptions = new LoadOptions();
loadOptions.SkipExternalResources = true; // Skip loading of external resources

using (Viewer viewer = new Viewer("business-flyer.docx", loadOptions))
{
    HtmlViewOptions viewOptions = 
        HtmlViewOptions.ForEmbeddedResources();

    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.SkipExternalResources = True ' Skip loading of external resources
    
        Using viewer As Viewer = New Viewer("business-flyer.docx", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
    
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

## Administrar una lista de permitidos para cargar recursos externos  {#manage-a-safelist-for-loading-external-resources}
  
El siguiente fragmento de código muestra cómo permitir la carga de recursos externos desde URL específicas:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

LoadOptions loadOptions = new LoadOptions();
loadOptions.SkipExternalResources = true; // Skip loading of all external resources
loadOptions.WhitelistedResources.Add("avatars.githubusercontent.com"); //Enable loading of external resources that has `avatars.githubusercontent.com` fragment in resource URL. 

using (Viewer viewer = new Viewer("business-flyer.docx", loadOptions))
{
    HtmlViewOptions viewOptions = 
        HtmlViewOptions.ForEmbeddedResources();

    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.SkipExternalResources = True ' Skip loading of all external resources
        loadOptions.WhitelistedResources.Add("avatars.githubusercontent.com") 'Enable loading of external resources that has `avatars.githubusercontent.com` fragment in resource URL. 
    
        Using viewer As Viewer = New Viewer("business-flyer.docx", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
    
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Establecer tiempo de espera para la carga de recursos externos  {#set-timeout-for-loading-of-external-resources}
  
El tiempo de espera predeterminado es de 30 segundos. GroupDocs.Viewer le permite cambiar este valor.

El siguiente fragmento de código muestra cómo establecer un tiempo de espera para cargar recursos externos:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Specify a timeout.
LoadOptions loadOptions = new LoadOptions();
loadOptions.ResourceLoadingTimeout = TimeSpan.FromSeconds(5);
// Render a file.
using (Viewer viewer = new Viewer("sample.docx", loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        ' Specify a timeout.
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.ResourceLoadingTimeout = TimeSpan.FromSeconds(5)
        ' Render a file.
        Using viewer As Viewer = New Viewer("sample.docx", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

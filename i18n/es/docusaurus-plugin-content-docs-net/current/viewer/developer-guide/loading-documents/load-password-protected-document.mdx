El cifrado protege los datos y permite que solo las personas autorizadas abran el archivo. Cuando un archivo está cifrado, se debe especificar una contraseña para abrirlo. Para saber cómo identificar un archivo cifrado, consulte la página [Check if a file is encrypted](/net/viewer/developer-guide/retrieving-document-information/how-to-check-if-file-is-encrypted/).

Para cargar y representar un documento cifrado, siga estos pasos:

1. Instancie el objeto <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> (o <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, o <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>, o <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>).
2. Establezca una contraseña en la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/loadoptions/properties/password" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.Password</a>.

:::info
Si la contraseña no se especifica, GroupDocs.Viewer lanza <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.exceptions/passwordrequiredexception" target="_blank" rel="nofollow noopener noreferrer">PasswordRequiredException</a>.
:::

3. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>.

El siguiente fragmento de código muestra cómo cargar y representar un documento cifrado:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Specify a password.
LoadOptions loadOptions = new LoadOptions();
loadOptions.Password = "123456";
// Render a file.
using (Viewer viewer = new Viewer("encrypted.docx", loadOptions))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        ' Specify a password.
        Dim loadOptions As LoadOptions = New LoadOptions()
        loadOptions.Password = "123456"
        ' Render a file.
        Using viewer As Viewer = New Viewer("encrypted.docx", loadOptions)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

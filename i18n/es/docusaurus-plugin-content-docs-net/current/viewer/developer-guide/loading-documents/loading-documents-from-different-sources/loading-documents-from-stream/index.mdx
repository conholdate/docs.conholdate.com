Puede cargar un documento desde un flujo sin guardarlo como un archivo en el disco. Puede utilizar esta funcionalidad para cargar un documento desde distintas fuentes, como una URL, FTP, etc.

Para cargar un documento desde un flujo, siga estos pasos:

1. Implemente un método para obtener el flujo del documento.  
2. Llame al constructor de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a> y especifique el método implementado en el paso anterior.

El siguiente fragmento de código muestra cómo cargar un documento desde un flujo:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

Stream stream = GetStream("sample.docx"); // TODO: implement this method

// Render a document from the stream.
using (Viewer viewer = new Viewer(stream))
{
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Dim stream As Stream = GetStream("sample.docx") ' TODO: implement this method
    
        ' Render a document from the stream.
        Using viewer As Viewer = New Viewer(stream)
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

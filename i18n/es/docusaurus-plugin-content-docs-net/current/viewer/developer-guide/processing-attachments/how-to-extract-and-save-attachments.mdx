Para obtener y guardar adjuntos, siga estos pasos:

1. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique un archivo que contenga adjuntos.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getattachments" target="_blank" rel="nofollow noopener noreferrer">GetAttachments</a>. Este método devuelve la colección de adjuntos.  
3. Recorra la colección. Para guardar un adjunto, llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/saveattachment" target="_blank" rel="nofollow noopener noreferrer">SaveAttachment</a>.  

El siguiente fragmento de código muestra cómo obtener y guardar todos los adjuntos del archivo MSG:

:::info
NOTA: el fragmento de código proporcionado es compatible con todas las familias de formatos que admiten archivos adjuntos: correos electrónicos, archivos de datos de Outlook, archivos comprimidos y documentos PDF.
:::

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using System.Collections.Generic;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("with_attachments.msg"))
{
    // Get list of attachments.
    IList<Attachment> attachments = viewer.GetAttachments();
    // Save each attachments.
    foreach (Attachment attachment in attachments)
    {
        string filePath = Path.Combine("output", attachment.FileName);
        viewer.SaveAttachment(attachment, File.OpenWrite(filePath));
    }
}      
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports System.Collections.Generic
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("with_attachments.msg")
            ' Get list of attachments.
            Dim attachments As IList(Of Attachment) = viewer.GetAttachments()
            ' Save each attachments.
            For Each attachment As Attachment In attachments
                Dim filePath As String = Path.Combine("output", attachment.FileName)
                viewer.SaveAttachment(attachment, File.OpenWrite(filePath))
            Next
        End Using
    End Sub
End Module
```

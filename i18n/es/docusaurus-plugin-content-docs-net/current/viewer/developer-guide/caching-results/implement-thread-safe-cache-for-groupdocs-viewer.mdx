Esta página describe cómo desarrollar una memoria caché segura para subprocesos utilizando la instrucción <a href="https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/lock-statement" target="_blank" rel="nofollow noopener noreferrer">C# lock</a> y la clase <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.concurrent.concurrentdictionary-2" target="_blank" rel="nofollow noopener noreferrer">ConcurrentDictionary&lt;,&gt;</a>.

## Introducción {#introduction}
  
Un método es seguro para subprocesos si varios subprocesos pueden invocarlo sin comprometer su funcionalidad. Lograr la seguridad para subprocesos es una tarea compleja, por lo que las clases de propósito general generalmente no son seguras para subprocesos. La forma más común de lograr la seguridad para subprocesos es bloquear el recurso para su uso exclusivo por un único subproceso en cualquier momento dado.

## Problema {#issue}
  
Debe desarrollar una aplicación web en la que múltiples usuarios puedan ver simultáneamente el mismo archivo. La aplicación web utiliza GroupDocs.Viewer en el lado del servidor. Debe garantizar que múltiples subprocesos puedan leer y escribir de forma segura en la memoria caché.

En GroupDocs.Viewer, puede utilizar la memoria caché para mejorar el rendimiento si el mismo documento se procesa varias veces ([lea más sobre la memoria caché aquí](
    /net/viewer/developer-guide/caching-results/).) The <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.caching/filecache" target="_blank" rel="nofollow noopener noreferrer">FileCache</a> class is an implementation of the <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.caching/icache" target="_blank" rel="nofollow noopener noreferrer">ICache</a> interface that uses a local disk to store the cache files. The FileCache is not thread safe, so you need to make it so.

## Solución {#solution}
  
La clase FileCache utiliza un disco local para leer y escribir archivos de salida. Debe implementar lectura y escritura seguras para subprocesos en el disco. Para ello, utilice una lista para almacenar la clave o el identificador del archivo y el objeto asociado que necesita bloquear. La forma más sencilla es utilizar la clase <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.concurrent.concurrentdictionary-2" target="_blank" rel="nofollow noopener noreferrer">ConcurrentDictionary&lt;,&gt;</a> del <a href="https://docs.microsoft.com/en-us/dotnet/standard/collections/thread-safe/" target="_blank" rel="nofollow noopener noreferrer">.NET Framework 4.0</a>. ConcurrentDictionary es una implementación segura para subprocesos de un diccionario de pares clave-valor. Implemente la clase ThreadSafeCache, que envuelve una clase no segura para subprocesos que implementa la interfaz ICache.

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer.Caching;
using System.Collections.Generic;

internal class ThreadSafeCache : ICache
{
    private readonly ICache _cache;
    private readonly IKeyLockerStore _keyLockerStore;

    public ThreadSafeCache(ICache cache, IKeyLockerStore keyLockerStore)
    {
        _cache = cache;
        _keyLockerStore = keyLockerStore;
    }

    public void Set(string key, object value)
    {
        lock (_keyLockerStore.GetLockerFor(key))
        {
            _cache.Set(key, value);
        }
    }

    public bool TryGetValue<TEntry>(string key, out TEntry value)
    {
        lock (_keyLockerStore.GetLockerFor(key))
        {
            return _cache.TryGetValue(key, out value);
        }
    }

    public IEnumerable<string> GetKeys(string filter)
    {
        lock (_keyLockerStore.GetLockerFor("get_keys"))
        {
            return _cache.GetKeys(filter);
        }
    }
}
```

Todos los métodos de la clase `ThreadSafeCache` utilizan bloqueos para hacer que las llamadas sean seguras en entornos multiproceso. La clase `ConcurrentDictionaryKeyLockerStore` utiliza `ConcurrentDictionary` para crear el objeto de bloqueo o recuperarlo si ya existe. Además, crea una clave única que identifica un archivo en caché.

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using System.Collections.Concurrent;
// ...

interface IKeyLockerStore
{
    object GetLockerFor(string key);
}

class ConcurrentDictionaryKeyLockerStore : IKeyLockerStore
{
    private readonly ConcurrentDictionary<string, object> _keyLockerMap;
    private readonly string _uniqueKeyPrefix;

    public ConcurrentDictionaryKeyLockerStore(ConcurrentDictionary<string, object> keyLockerMap, string uniqueKeyPrefix)
    {
        _keyLockerMap = keyLockerMap;
        _uniqueKeyPrefix = uniqueKeyPrefix;
    }

    public object GetLockerFor(string key)
    {
        string uniqueKey = GetUniqueKey(key);
        return _keyLockerMap.GetOrAdd(uniqueKey, k => new object());
    }

    private string GetUniqueKey(string key)
    {
        return $"{_uniqueKeyPrefix}_{key}";
    }
}
```

```csharp
using System.IO;
using System.Collections.Generic;
using System.Collections.Concurrent;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Caching;
using GroupDocs.Viewer.Interfaces;
using GroupDocs.Viewer.Options;

namespace ThreadSaveCacheExample
{
    static class Program
    {
        private static readonly ConcurrentDictionary<string, object> KeyLockerMap = new ConcurrentDictionary<string, object>();

        static void Main()
        {
            string fileName = "sample.pdf";
            string cacheFolder = fileName.Replace('.', '_');
            string cachePath = Path.Combine("cache", cacheFolder);
            string uniqueKeyPrefix = cachePath;

            ICache fileCache = new FileCache(cachePath);
            IKeyLockerStore keyLockerStore = new ConcurrentDictionaryKeyLockerStore(KeyLockerMap, uniqueKeyPrefix);
            ICache threadSafeCache = new ThreadSafeCache(fileCache, keyLockerStore);

            ViewerSettings viewerSettings = new ViewerSettings(threadSafeCache);

            List<MemoryStream> pages = new List<MemoryStream>();
            using (Viewer viewer = new Viewer(fileName, viewerSettings))
            {
                IPageStreamFactory pageStreamFactory = new MemoryPageStreamFactory(pages);
                ViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources(pageStreamFactory);
                viewer.View(viewOptions);
            }
        }
    }

    class ThreadSafeCache : ICache
    {
        private readonly ICache _cache;
        private readonly IKeyLockerStore _keyLockerStore;

        public ThreadSafeCache(ICache cache, IKeyLockerStore keyLockerStore)
        {
            _cache = cache;
            _keyLockerStore = keyLockerStore;
        }

        public void Set(string key, object value)
        {
            lock (_keyLockerStore.GetLockerFor(key))
            {
                _cache.Set(key, value);
            }
        }

        public bool TryGetValue<TEntry>(string key, out TEntry value)
        {
            lock (_keyLockerStore.GetLockerFor(key))
            {
                return _cache.TryGetValue(key, out value);
            }
        }

        public IEnumerable<string> GetKeys(string filter)
        {
            lock (_keyLockerStore.GetLockerFor("get_keys"))
            {
                return _cache.GetKeys(filter);
            }
        }
    }

    interface IKeyLockerStore
    {
        object GetLockerFor(string key);
    }

    class ConcurrentDictionaryKeyLockerStore : IKeyLockerStore
    {
        private readonly ConcurrentDictionary<string, object> _keyLockerMap;
        private readonly string _uniqueKeyPrefix;

        public ConcurrentDictionaryKeyLockerStore(ConcurrentDictionary<string, object> keyLockerMap, string uniqueKeyPrefix)
        {
            _keyLockerMap = keyLockerMap;
            _uniqueKeyPrefix = uniqueKeyPrefix;
        }

        public object GetLockerFor(string key)
        {
            string uniqueKey = GetUniqueKey(key);
            return _keyLockerMap.GetOrAdd(uniqueKey, k => new object());
        }

        private string GetUniqueKey(string key)
        {
            return $"{_uniqueKeyPrefix}_{key}";
        }
    }

    class MemoryPageStreamFactory : IPageStreamFactory
    {
        private readonly List<MemoryStream> _pages;

        public MemoryPageStreamFactory(List<MemoryStream> pages)
        {
            _pages = pages;
        }

        public Stream CreatePageStream(int pageNumber)
        {
            MemoryStream pageStream = new MemoryStream();
            _pages.Add(pageStream);

            return pageStream;
        }

        public void ReleasePageStream(int pageNumber, Stream pageStream)
        {
            //Do not release page stream as we'll need to keep the stream open
        }
    }
}
```

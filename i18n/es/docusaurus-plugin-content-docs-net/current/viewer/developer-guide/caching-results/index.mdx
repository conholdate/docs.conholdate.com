El almacenamiento en caché guarda los resultados del renderizado en una ubicación especificada, como un disco local. Cuando solicita nuevamente los resultados del renderizado, GroupDocs.Viewer no los vuelve a renderizar, sino que utiliza los resultados almacenados en caché.  
Dado que un documento puede tardar mucho tiempo en renderizarse, se recomienda utilizar el almacenamiento en caché si espera reutilizar los resultados del renderizado.

Para habilitar el almacenamiento en caché, siga estos pasos:

1. Instancie el objeto de caché deseado (por ejemplo, <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.caching/filecache" target="_blank" rel="nofollow noopener noreferrer">FileCache</a> para almacenar los resultados del renderizado del documento en la unidad local).  
2. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewersettings" target="_blank" rel="nofollow noopener noreferrer">ViewerSettings</a>. Especifique el objeto de caché como parámetro del constructor.  
3. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewersettings" target="_blank" rel="nofollow noopener noreferrer">ViewerSettings</a> como parámetro del constructor.  
4. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>.

El siguiente fragmento de código muestra cómo habilitar el almacenamiento en caché y muestra la diferencia entre renderizar un archivo y obtener los resultados almacenados en caché:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using System.Diagnostics;
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Caching;
using GroupDocs.Viewer.Options;
// ...

string outputDirectory = @"C:\output";
string cachePath = Path.Combine(outputDirectory, "cache");
string pageFilePathFormat = Path.Combine(outputDirectory, "page_{0}.html");
// Create a cache.
FileCache cache = new FileCache(cachePath);
ViewerSettings settings = new ViewerSettings(cache);

using (Viewer viewer = new Viewer(@"C:\sample.docx", settings))
{
    // Create an HTML file.
    HtmlViewOptions options = HtmlViewOptions.ForEmbeddedResources(pageFilePathFormat);
    // Render and display the rendering time.
    Stopwatch stopWatch = Stopwatch.StartNew();
    viewer.View(options);
    stopWatch.Stop();
    Console.WriteLine("Time taken on first call to View method {0} (ms).", stopWatch.ElapsedMilliseconds);
    // Get cached results and display the time.
    stopWatch.Restart();
    viewer.View(options);
    stopWatch.Stop();
    Console.WriteLine("Time taken on second call to View method {0} (ms).", stopWatch.ElapsedMilliseconds);
}
```

Imports System

Imports System.IO
Imports GroupDocs.Viewer

Module Program
    Sub Main(args As String())
            Dim outputDirectory As String = "C:\output"
            Dim cachePath As String = Path.Combine(outputDirectory, "cache")
            Dim pageFilePathFormat As String = Path.Combine(outputDirectory, "page_{0}.html")
            ' Create a cache.
            Dim cache As FileCache = New FileCache(cachePath)
            Dim settings As ViewerSettings = New ViewerSettings(cache)
        
            Using viewer As Viewer = New Viewer("C:\sample.docx", settings)
                ' Create an HTML file.
                Dim options As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources(pageFilePathFormat)
                ' Render and display the rendering time.
                Dim stopWatch As Stopwatch = Stopwatch.StartNew()
                viewer.View(options)
                stopWatch.[Stop]()
                Console.WriteLine("Time taken on first call to View method {0} (ms).", stopWatch.ElapsedMilliseconds)
                ' Get cached results and display the time.
                stopWatch.Restart()
                viewer.View(options)
                stopWatch.[Stop]()
                Console.WriteLine("Time taken on second call to View method {0} (ms).", stopWatch.ElapsedMilliseconds)
            End Using
    End Sub
End Module

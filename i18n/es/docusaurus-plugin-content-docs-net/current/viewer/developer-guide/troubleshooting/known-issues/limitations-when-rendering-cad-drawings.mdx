:::info
GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.
:::

:::info
Esta limitación existe en la versión 20.6.1 y anteriores. No configure una redirección de enlace de ensamblado si utiliza la versión 20.7 o posterior.
:::

## Renderizar dibujos CAD requiere agregar una redirección de enlace de ensamblado  {#rendering-cad-drawings-requires-adding-assembly-binding-redirect}
  
Al renderizar dibujos CAD mediante GroupDocs.Viewer, es necesario agregar la <a href="https://docs.microsoft.com/en-us/dotnet/framework/configure-apps/redirect-assembly-versions" target="_blank" rel="nofollow noopener noreferrer">redirección de enlace de ensamblado</a> a los archivos de proyecto app.config o web.config. El siguiente ejemplo muestra la redirección de enlace de ensamblado necesaria para renderizar dibujos CAD con GroupDocs.Viewer for .NET 20.6.1 y versiones anteriores.

<Tabs groupId="example1">

<TabItem value="project-file" label="Project file" default>

```xml
<configuration>
    <!--...-->
    <runtime>
        <!--...-->
        <assemblyBinding xmlns="urn:schemas-microsoft-com:asm.v1">
            <!--...-->
            <dependentAssembly>
                <assemblyIdentity name="Aspose.PDF" publicKeyToken="716fcc553a201e56" culture="neutral"/>
                <bindingRedirect oldVersion="0.0.0.0-20.5.0.0" newVersion="20.5.0.0"/>
                <publisherPolicy apply="no"/>
            </dependentAssembly>
        </assemblyBinding>
    </runtime>
</configuration>
```

</TabItem>

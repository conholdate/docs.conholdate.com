:::info
GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.
:::

**Problema**

Al utilizar el GroupDocs.Viewer junto con uno o más productos de Aspose (como Aspose.Pdf) en un único proyecto en Windows 11, pueden producirse conflictos no definidos e inesperados, principalmente en forma de excepciones en tiempo de ejecución de distintos tipos.

**Causa**

El problema se produce porque el proyecto con GroupDocs.Viewer y el producto de Aspose se ejecuta dentro de un entorno de desarrollo integrado (IDE) de 32 bits (esto puede incluir JetBrains Rider) en un sistema Windows 11 de 64 bits. Esta discrepancia entre el IDE y el sistema operativo provoca conflictos en la ejecución del código y en la carga de bibliotecas.

**Solución**

Reinstale el IDE instalando una versión correcta cuya <a href="https://en.wiktionary.org/wiki/bitness" target="_blank" rel="nofollow noopener noreferrer">arquitectura</a> coincida con la arquitectura del sistema operativo. En concreto, un IDE de 32 bits para un sistema operativo de 32 bits y un IDE de 64 bits para un sistema operativo de 64 bits.

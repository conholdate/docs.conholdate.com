Esta página describe la instalación de las fuentes asiáticas en <a href="https://wiki.ubuntu.com/Releases" target="_blank" rel="nofollow noopener noreferrer">Ubuntu 20.04 LTS</a> utilizando la utilidad <a href="https://wiki.debian.org/apt-get" target="_blank" rel="nofollow noopener noreferrer">apt-get</a>. En las versiones anteriores de Ubuntu, el proceso es bastante similar.

Para instalar las fuentes asiáticas en Ubuntu, siga estos pasos:

1. Vaya a <a href="https://packages.ubuntu.com/" target="_blank" rel="nofollow noopener noreferrer">packages.ubuntu.com</a>.

2. En <a href="https://packages.ubuntu.com/focal/translations/" target="_blank" rel="nofollow noopener noreferrer">packages.ubuntu.com/focal/translations/</a>, busque los paquetes de soporte para el idioma japonés. Encuentre todas las entradas que comiencen con «language-pack-» y contengan «Japanese», como se muestra a continuación:

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu.png)

3. Instale el paquete <a href="https://packages.ubuntu.com/focal/translations/language-pack-ja" target="_blank" rel="nofollow noopener noreferrer">language-pack-ja</a>. El paquete language-pack-ja-base se instala automáticamente, ya que el primero depende de este.

4. Ejecute Ubuntu en un contenedor Docker:

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_1.png)

5. Ejecute el siguiente comando para actualizar la lista de paquetes con actualizaciones y nuevos paquetes:

<Tabs groupId="example1">

<TabItem value="shell" label="Shell" default>

```sh
apt-get update
```

</TabItem>

</Tabs>

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_2.png)

6. Ejecute el siguiente comando para instalar el soporte del idioma japonés:

<Tabs groupId="example2">

<TabItem value="shell" label="Shell" default>

```sh
apt-get install -y language-pack-ja
```

</TabItem>

</Tabs>

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_3.png)

7. Espere el mensaje "Generation complete."

![](/net/viewer/images/how-to-install-asian-fonts-on-ubuntu_4.png)

Para instalar otros idiomas asiáticos, utilice los siguientes comandos:

<Tabs groupId="example3">

<TabItem value="shell" label="Shell" default>

```sh
apt-get install -y language-pack-zh*
apt-get install -y language-pack-ko
```

</TabItem>

</Tabs>

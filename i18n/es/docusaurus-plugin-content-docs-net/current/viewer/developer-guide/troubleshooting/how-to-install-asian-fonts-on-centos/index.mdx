Esto describe la instalación de las fuentes asiáticas en CentOS 8/7/6.

## CentOS 7/8 {#centos-7-8}
  
El proceso de instalación es el mismo para CentOS 7 y CentOS 8. Este tema describe el proceso de instalación para CentOS 8.

Para instalar un grupo de paquetes que incluye fuentes para idiomas asiáticos en CentOS 8/7, siga estos pasos:

1. Ejecute CentOS 8 en un contenedor Docker: 

![](/net/viewer/images/how-to-install-asian-fonts-on-centos.png)

2. Ejecute el siguiente comando para instalar el grupo de paquetes:

<Tabs groupId="example1">

<TabItem value="shell" label="Shell" default>

```sh
yum group install -y Fonts
```

</TabItem>

</Tabs>

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_1.png)

3. Espere el mensaje «¡Completado!». Instalación finalizada.
	
![](/net/viewer/images/how-to-install-asian-fonts-on-centos_2.png)

## CentOS 6 {#centos-6}
  
Para instalar un grupo de paquetes que incluye fuentes para idiomas asiáticos en CentOS 8/7, siga estos pasos:

1. Ejecute CentOS 8 en un contenedor Docker: 

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_3.png)

2. Los paquetes de fuentes están separados en grupos. Ejecute el siguiente comando para listarlos:

<Tabs groupId="example2">

<TabItem value="shell" label="Shell" default>

```sh
yum grouplist
```

</TabItem>

</Tabs>

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_4.png)

3. Busque el grupo de idiomas **"Chinese Support \[zh\]"**. Para ello, revise la sección **"Paquetes de idiomas instalados"** para ver los paquetes de idiomas ya instalados. A continuación, revise la sección **"Grupos de idiomas disponibles"**, que enumera los paquetes de paquetes que puede instalar.

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_5.png)

4. Si es necesario, instale el soporte para el idioma chino. Para ello, ejecute el siguiente comando:

<Tabs groupId="example3">

<TabItem value="shell" label="Shell" default>

```sh
yum groupinstall -y "Chinese Support"
```

</TabItem>

</Tabs>

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_6.png)

5. Espere el mensaje **"¡Completado!"**. Instalación finalizada.

![](/net/viewer/images/how-to-install-asian-fonts-on-centos_7.png)

Para instalar otros idiomas asiáticos, utilice los siguientes comandos:

<Tabs groupId="example4">

<TabItem value="shell" label="Shell" default>

```sh
yum groupinstall -y "Japanese Support"
yum groupinstall -y "Korean Support"
yum groupinstall -y "Hindi Support"
yum groupinstall -y "Kannada Support"
```

</TabItem>

</Tabs>

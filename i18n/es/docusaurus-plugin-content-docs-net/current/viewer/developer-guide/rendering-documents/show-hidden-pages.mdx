GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.
:::

De forma predeterminada, GroupDocs.Viewer no representa los elementos ocultos. Para representarlos, establezca la propiedad `RenderHiddenPages` de la clase `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/viewoptions/" target="_blank" rel="nofollow noopener noreferrer">ViewOptions</a>` en ``true``.

Esta función es compatible con las siguientes familias de formatos:

* Documentos de Visio (para páginas ocultas)  
* Presentaciones de PowerPoint (para diapositivas ocultas)  
* Archivos de hojas de cálculo (para hojas de cálculo ocultas)  

El siguiente fragmento de código muestra cómo habilitar la representación de elementos ocultos:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.pptx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();

    // Enable rendering of hidden items.
    viewOptions.RenderHiddenPages = true;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.pptx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
        
            ' Enable rendering of hidden items.
            viewOptions.RenderHiddenPages = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

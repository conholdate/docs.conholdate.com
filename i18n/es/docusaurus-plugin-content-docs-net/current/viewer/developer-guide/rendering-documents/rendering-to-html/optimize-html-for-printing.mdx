Para optimizar la salida HTML para impresión, utilice la propiedad booleana <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions/properties/forprinting" target="_blank" rel="nofollow noopener noreferrer">ForPrinting</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>.

Si la opción <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions/properties/forprinting" target="_blank" rel="nofollow noopener noreferrer">ForPrinting</a> está habilitada, las páginas HTML generadas se convierten al formato vectorial SVG.

Esta opción es compatible con las siguientes familias de formatos:

* Documentos de presentación: PPT, PPS, PPTX, PPSX, ODP, FODP, OTP, POT, POTX, POTM, PPTM, PPSM  
* Documentos de diagramas: VSD, VSDX, VSS, VST, VSX, VTX, VDW, VDX, VSSX, VSTX, VSDM, VSSM, VSTM  
* Formatos de archivos meta: WMF, WMZ, EMF, EMZ  

El siguiente fragmento de código muestra cómo renderizar un documento .docx a HTML optimizado para impresión:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();

    // Render a file optimized for printing.
    viewOptions.ForPrinting = true;
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
        
            ' Render a file optimized for printing.
            viewOptions.ForPrinting = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

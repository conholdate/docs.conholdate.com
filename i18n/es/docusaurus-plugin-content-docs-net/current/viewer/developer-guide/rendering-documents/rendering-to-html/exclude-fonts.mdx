De forma predeterminada, GroupDocs.Viewer incluye (exporta) las fuentes utilizadas en el documento cargado al HTML resultante. Esto garantiza una visualización correcta, independientemente de si las fuentes requeridas existen en el dispositivo del visor. Dependiendo del tipo de renderizado HTML, las fuentes se incluyen de las siguientes maneras:

1. Recursos incrustados: el contenido de la fuente se _incrusta_ (inserta, embebe) directamente dentro de la marca HTML mediante el esquema de URI de datos <a href="https://en.wikipedia.org/wiki/Data_URI_scheme" target="_blank" rel="nofollow noopener noreferrer">data</a> mediante la codificación <a href="https://en.wikipedia.org/wiki/Base64" target="_blank" rel="nofollow noopener noreferrer">base64</a>.
2. Recursos externos: el contenido de la fuente se almacena por separado del documento HTML, de forma externa; cada fuente puede almacenarse como un archivo independiente en el disco o su contenido puede escribirse en el flujo de bytes especificado por el usuario mediante un delegado <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.interfaces/createresourcestream/" target="_blank" rel="nofollow noopener noreferrer">`CreateResourceStream`</a>.

GroupDocs.Viewer admite una <a href="https://docs.groupdocs.com/viewer/net/supported-document-formats/" target="_blank" rel="nofollow noopener noreferrer">gran variedad de formatos de documento</a>, pero no para todos ellos es posible exportar las fuentes al HTML resultante. A continuación se presenta una lista de los formatos de archivo que admiten la exportación de fuentes al renderizarlos en formato HTML:

1. Portable Document Format (PDF)  
2. Formatos de Microsoft Word (DOC, DOCX, DOCM, DOT, DOTX, DOTM)  
3. Formatos de Microsoft PowerPoint (PPT, PPTX, PPS, PPSX)  
4. Formatos de Microsoft Outlook (MSG, EML)  
5. Apple Mail (EMLX)  
6. Formatos OpenDocument (ODT, OTT, ODP)  
7. Rich Text Format (RTF)  
8. Formatos de libros electrónicos (Publicación electrónica (EPUB), Mobipocket (MOBI), AZW3)  
9. LaTeX (TEX)  
10. Imágenes vectoriales (SVG)  

A veces no es deseable incluir fuentes en el documento HTML resultante: por ejemplo, el usuario podría tener todas las fuentes instaladas en el sistema operativo donde se debe visualizar el documento HTML, y el navegador podría utilizar las fuentes instaladas en el sistema. Además, al incluir las fuentes, se incrementa significativamente el tamaño del documento HTML resultante. Para evitar incluir fuentes que están disponibles en la mayoría de los dispositivos en el HTML resultante, GroupDocs.Viewer proporciona dos opciones: **excluir todas las fuentes** (exclusión completa de fuentes) y **excluir solo las fuentes especificadas** (exclusión selectiva de fuentes).

Ambas opciones se representan en la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> mediante distintas propiedades:

- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/excludefonts/" target="_blank" rel="nofollow noopener noreferrer">`ExcludeFonts`</a> es una bandera que deshabilita la exportación de **todas** las fuentes utilizadas al documento HTML resultante, cuando está habilitada (`true`). De forma predeterminada, esta opción está deshabilitada (`false`).
- <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/fontstoexclude/" target="_blank" rel="nofollow noopener noreferrer">`FontsToExclude`</a> es una lista de `string`, cada uno de los cuales representa el nombre de una fuente que debe excluirse del documento HTML resultante. De forma predeterminada, esta lista está vacía: no se excluyen fuentes. Tenga en cuenta que esta opción solo funciona si la propiedad `ExcludeFonts` está deshabilitada (`false`).

El siguiente fragmento de código muestra cómo excluir todas las fuentes del documento HTML resultante mediante la bandera `ExcludeFonts`.

<Tabs groupId="example-ExcludeFonts">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();    
    viewOptions.ExcludeFonts = true;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create an HTML file.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()            
            viewOptions.ExcludeFonts = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

El siguiente fragmento de código demuestra el funcionamiento de la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/fontstoexclude/" target="_blank" rel="nofollow noopener noreferrer">`FontsToExclude`</a>: muestra cómo evitar que se agreguen las fuentes **Times New Roman** y **Arial** al HTML.

<Tabs groupId="example-FontsToExclude">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("presentation.pptx"))
{
    // Create an HTML file.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();    
    viewOptions.FontsToExclude.Add("Times New Roman");// Exclude the Times New Roman font.
    viewOptions.FontsToExclude.Add("Arial");// Exclude the Arial font.
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("presentation.pptx")

            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()            
            viewOptions.FontsToExclude.Add("Times New Roman")' Exclude the Times New Roman font.
            viewOptions.FontsToExclude.Add("Arial")' Exclude the Arial font.
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

## Formatos admitidos para la exclusión  {#supported-formats-for-exclusion}
  
Es necesario mencionar que no todos los formatos enumerados anteriormente admiten la exclusión completa y selectiva de fuentes. A continuación se muestran dos listas que indican qué formatos son compatibles:

**Exclusión completa de fuentes mediante `ExcludeFonts`:**

1. Todos los formatos de Microsoft Word (DOX, DOCX, DOCM, …)  
2. Todos los formatos de presentación de PowerPoint (PPT, PPTX, PPTM, PPS, PPSX, PPSM, POT, POX, POTM)  
3. Todos los formatos de presentación OpenDocument (ODP, FODP, OTP)  
4. PDF  
5. OFD (OpenFixed-layout Document)  
6. XPS (incluido OpenXPS)  
7. PostScript (incluido PostScript encapsulado)  
8. ePuB  
9. TeX  
10. PCL  
11. CGM  
12. Documentos de Microsoft Project (MPT, MPP, MPX)  
13. Todos los archivos comprimidos admitidos  
14. Formato Microsoft OneNote ONE  
15. Imágenes vectoriales con soporte de fuentes (SVG)  
16. Todos los formatos de correo electrónico admitidos  

**Exclusión selectiva de fuentes mediante `FontsToExclude`:**

1. Todos los formatos de presentación de PowerPoint (PPT, PPTX, PPTM, PPS, PPSX, PPSM, POT, POX, POTM)  
2. Todos los formatos de presentación OpenDocument (ODP, FODP, OTP)  
3. PDF  
4. OFD (OpenFixed-layout Document)  
5. XPS (incluido OpenXPS)  
6. PostScript (incluido PostScript encapsulado)  
7. ePuB  
8. TeX  
9. PCL  
10. CGM

Cuando busca formas de optimizar la representación de documentos en HTML, una de las soluciones es la compresión del contenido de salida (HTML, CSS y SVG). Esto es adecuado si proporciona su contenido desde el servidor web a través de Internet. Cuanto menos tenga que descargar el usuario, más rápido accederá al documento representado.

:::info
La minificación no reduce el tamaño del contenido tanto como la compresión Gzip, por lo que debe utilizarse además de la compresión Gzip.
:::

## Minificación {#minification}
  
La minificación proporciona una salida que se ve idéntica al contenido original en todos los navegadores; sin embargo, el contenido HTML minificado no supera la validación HTML estricta. A continuación se describen los métodos de reducción de tamaño utilizados en la minificación.

### Minificación de HTML {#html-minification}
  
La minificación de HTML incluye lo siguiente:

* Eliminación completa de los comentarios (excepto aquellos que contengan sentencias condicionales de IE).
* Compresión de comentarios condicionales.
* Eliminación de espacios y saltos de línea dentro de las etiquetas y entre etiquetas.
* Simplificación de la declaración de tipo de documento a `<!DOCTYPE html>`.
* Eliminación de todas las propiedades de las etiquetas HTML.
* Eliminación de declaraciones de protocolo como `http:`, `https:` y `javascript:` de los valores de ruta.
* Sustitución de múltiples espacios entre palabras (excepto cuando ocurren dentro de las etiquetas `pre` o `textarea`) por un único espacio.
* Eliminación de comillas alrededor de los valores de las propiedades de las etiquetas (excepto en eventos en línea).
* Eliminación de atributos predeterminados para las etiquetas `script`, `style` y `link`.
* Simplificación de atributos booleanos, de modo que `<input type="text" disabled="disabled">` se convierte en `<input type=text disabled>`.

### Minificación de CSS {#css-minification}
  
La minificación de CSS incluye lo siguiente:

* Eliminación de todos los espacios en blanco insignificantes.
* Eliminación de todos los comentarios.
* Eliminación de todos los separadores de punto y coma innecesarios.
* Reducción de valores de color.
* Reducción de representaciones enteras eliminando ceros iniciales y finales.
* Eliminación de especificadores de unidad en valores numéricos cero.

## Cómo minificar HTML y CSS {#how-to-minify-html-and-css}
  
La clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> tiene la propiedad booleana <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/htmlviewoptions/minify/" target="_blank" rel="nofollow noopener noreferrer">Minify</a>, que actúa como indicador para minificar el contenido de salida.

El siguiente fragmento de código muestra cómo habilitar la minificación:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();

    // Render the minified file.
    viewOptions.Minify = true;
    viewer.View(viewOptions);
}
```

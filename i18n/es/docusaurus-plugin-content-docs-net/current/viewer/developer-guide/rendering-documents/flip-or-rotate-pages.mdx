![Flip or rotate pages](/net/viewer/images/flip-or-rotate-pages.png)

Para rotar una página al representar un documento, utilice el método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/methods/rotatepage" target="_blank" rel="nofollow noopener noreferrer">RotatePage</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions" target="_blank" rel="nofollow noopener noreferrer">ViewOptions</a>. Este método tiene los siguientes dos parámetros:

1. número de página  
2. ángulo de rotación  

El ángulo de rotación es uno de los siguientes:

* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On90Degree</a>: rota la página 90 grados en sentido horario  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On180Degree</a>: rota la página 180 grados en sentido horario  
* <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/rotation" target="_blank" rel="nofollow noopener noreferrer">Rotation.On270Degree</a>: rota la página 270 grados en sentido horario  

El siguiente fragmento de código muestra cómo rotar las páginas de salida al representar un documento como PDF:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a PDF file.
    PdfViewOptions viewOptions = new PdfViewOptions();
    // Rotate the first page.
    viewOptions.RotatePage(1, Rotation.On90Degree);
    viewer.View(viewOptions);
}
```

</TabItem>

```vb
Module Program

            viewOptions.RotatePage(1, Rotation.On90Degree)
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

Las clases <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a> y <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> implementan la interfaz <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/imaxsizeoptions" target="_blank" rel="nofollow noopener noreferrer">IMaxSizeOptions</a>, la cual contiene propiedades para los límites de tamaño:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
/// <summary>
/// Limits of image size options interface. 
/// </summary>
public interface IMaxSizeOptions
{
    /// <summary>
    /// Max width of an output image in pixels.
    /// </summary>
    int MaxWidth { get; set; }

    /// <summary>
    /// Max height of an output image in pixels.
    /// </summary>
    int MaxHeight { get; set; }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
''' <summary>
''' Limits of image size options interface. 
''' </summary>
Public Interface IMaxSizeOptions
    ''' <summary>
    ''' Max width of an output image in pixels.
    ''' </summary>
    Property MaxWidth As Integer

    ''' <summary>
    ''' Max height of an output image in pixels.
    ''' </summary>
    Property MaxHeight As Integer
End Interface
```

</TabItem>

</Tabs>

:::warning
Si configura las opciones `ImageWidth`/`ImageHeight`, las opciones `ImageMaxWidth`/`ImageMaxHeight` se ignoran.
:::

Para configurar las opciones `ImageMaxWidth`/`ImageMaxHeight`, siga estos pasos:

1. Instancie el objeto `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>`.
2. Instancie el objeto `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>` o `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>`.
3. Configure los valores de `MaxWidth` y/o `MaxHeight`.
4. Llame al método `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>`.

El siguiente fragmento de código muestra cómo configurar los límites del tamaño de la imagen de salida:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.jpg"))
{
    // Create a JPG or PNG file.
    JpgViewOptions viewOptions = new JpgViewOptions("result_{0}.jpg");
    // or PngViewOptions viewOptions = new PngViewOptions("result_{0}.png");
    
    // Specify the maximum width and height.
    viewOptions.MaxWidth = 800;
    viewOptions.MaxHeight = 600;

    viewer.View(viewOptions);
}
```

</TabItem>

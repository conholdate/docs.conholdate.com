Disminuir la calidad de las imágenes JPG reduce el tamaño del archivo de salida.

Para ajustar la calidad de las imágenes, configure la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/quality" target="_blank" rel="nofollow noopener noreferrer">Quality</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>. El valor debe estar comprendido entre 1 (calidad mínima) y 100. El valor predeterminado es 90.

Para establecer la calidad de la imagen, siga estos pasos:

1. Instancie la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique la ruta del documento de origen como parámetro del constructor.
1. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>.
2. Establezca el valor de <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/quality" target="_blank" rel="nofollow noopener noreferrer">Quality</a>.
3. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> del objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> como parámetro.

El siguiente fragmento de código muestra cómo ajustar la calidad de la imagen JPG de salida:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a JPG file.
    JpgViewOptions viewOptions = new JpgViewOptions();
    
    // Specify the JPG image quality.
    viewOptions.Quality = 50;    
    viewer.View(viewOptions);
}
```

</TabItem>

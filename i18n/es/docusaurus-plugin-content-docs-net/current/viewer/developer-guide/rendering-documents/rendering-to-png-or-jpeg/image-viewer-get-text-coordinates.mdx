GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.

Utilice la propiedad `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewinfooptions/properties/extracttext" target="_blank" rel="nofollow noopener noreferrer">ExtractText</a>` de la clase `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewinfooptions" target="_blank" rel="nofollow noopener noreferrer">ViewInfoOptions</a>` para obtener el texto contenido en un documento de origen y sus coordenadas. A continuación, puede utilizar estos datos para agregar un texto seleccionable sobre la imagen o para implementar una búsqueda de texto en una representación basada en imágenes.

El siguiente fragmento de código muestra cómo recuperar e imprimir el texto (`<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/page/properties/lines" target="_blank" rel="nofollow noopener noreferrer">lines</a>` / `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/line/properties/words" target="_blank" rel="nofollow noopener noreferrer">words</a>` / `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/word/properties/characters" target="_blank" rel="nofollow noopener noreferrer">characters</a>`) en cada `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.results/page" target="_blank" rel="nofollow noopener noreferrer">page</a>` del documento junto con sus coordenadas:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Get the file information and extract it text.
    bool extractText = true;
    ViewInfoOptions viewInfoOptions = ViewInfoOptions.ForPngView(extractText);
    ViewInfo viewInfo = viewer.GetViewInfo(viewInfoOptions);

    // Display the file information and text.
    foreach (Page page in viewInfo.Pages)
    {
        Console.WriteLine($"Page: {page.Number}");
        Console.WriteLine("Text lines/words/characters:");

        foreach (Line line in page.Lines)
        {
            Console.WriteLine(line);
            foreach (Word word in line.Words)
            {
                Console.WriteLine($"\t{word}");
                foreach (Character character in word.Characters)
                {
                    Console.WriteLine($"\t\t{character}");
                }
            }
        }
    }
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Get the file information and extract it text.
            Dim extractText As Boolean = True
            Dim viewInfoOptions As ViewInfoOptions = ViewInfoOptions.ForPngView(extractText)
            Dim viewInfo As ViewInfo = viewer.GetViewInfo(viewInfoOptions)
        
            ' Display the file information and text.
            For Each page As Page In viewInfo.Pages
                Console.WriteLine($"Page: {page.Number}")
                Console.WriteLine("Text lines/words/characters:")
        
                For Each line As Line In page.Lines
                    Console.WriteLine(line)
                    For Each word As Word In line.Words
                        Console.WriteLine($"	{word}")
                        For Each character As Character In word.Characters
                            Console.WriteLine($"		{character}")
                        Next
                    Next
                Next
            Next
        End Using
    End Sub
End Module
```

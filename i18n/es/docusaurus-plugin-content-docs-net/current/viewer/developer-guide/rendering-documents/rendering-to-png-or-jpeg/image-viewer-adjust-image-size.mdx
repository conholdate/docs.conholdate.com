:::info
GroupDocs.Viewer for .NET se incluye en Conholdate.Total for .NET.
:::

Para especificar el tamaño de la imagen de salida, configure las propiedades <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> y <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> de las clases <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a> o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>. Especifique el valor en píxeles.

:::info
GroupDocs.Viewer aplica automáticamente la relación de aspecto cuando se establece el valor de <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a>.
:::

El siguiente fragmento de código muestra cómo establecer el ancho o la altura de la imagen.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create a JPG file.
    JpgViewOptions viewOptions = new JpgViewOptions();
    
    // Specify the width and height.
    viewOptions.Width = 600;
    viewOptions.Height = 800;
    
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create a JPG file.
            Dim viewOptions As JpgViewOptions = New JpgViewOptions()
        
            ' Specify the width and height.
            viewOptions.Width = 600
            viewOptions.Height = 800
        
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

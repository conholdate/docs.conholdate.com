Puede proteger un documento PDF estableciendo los siguientes parámetros:

* permisos  
* contraseña para abrir el documento  
* contraseña para cambiar los permisos  

Para proteger un documento PDF, siga estos pasos:

1. Cree una instancia de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique la ruta del documento de origen como parámetro del constructor.  
2. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security" target="_blank" rel="nofollow noopener noreferrer">Security</a>.  
3. Para especificar una contraseña para abrir el documento, establezca la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security/properties/documentopenpassword" target="_blank" rel="nofollow noopener noreferrer">DocumentOpenPassword</a>.  
4. Para especificar una contraseña para cambiar las restricciones, establezca la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/security/properties/permissionspassword" target="_blank" rel="nofollow noopener noreferrer">PermissionsPassword</a>.  
5. Para especificar los permisos del documento, establezca la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/permissions" target="_blank" rel="nofollow noopener noreferrer">Permissions</a>.  
6. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>. Especifique el formato de la ruta de guardado para el documento renderizado.  
7. Inicialice la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions/properties/security" target="_blank" rel="nofollow noopener noreferrer">Security</a> del objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> con el objeto creado en los pasos 2–5.  
8. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> del objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Pase el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> como parámetro.  

El siguiente fragmento de código muestra cómo proteger el documento PDF de salida:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer;
// ...

using(Viewer viewer = new Viewer("sample.docx"))
{
    // Specify the security settings.
    Security security = new Security();
    security.DocumentOpenPassword = "o123";
    security.PermissionsPassword = "p123";
    security.Permissions = Permissions.AllowAll ^ Permissions.DenyPrinting;

    // Create a PDF file.
    PdfViewOptions viewOptions = new PdfViewOptions();
    
    // Apply the security settings
    viewOptions.Security = security;
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Specify the security settings.
            Dim security As Security = New Security()
            security.DocumentOpenPassword = "o123"
            security.PermissionsPassword = "p123"
            security.Permissions = Permissions.AllowAll Xor Permissions.DenyPrinting

            ' Create a PDF file.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()

            ' Apply the security settings
            viewOptions.Security = security
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

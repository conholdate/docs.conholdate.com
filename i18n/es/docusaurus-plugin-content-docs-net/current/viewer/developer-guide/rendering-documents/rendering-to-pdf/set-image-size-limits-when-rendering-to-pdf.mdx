Puede establecer el ancho y/o la altura de las imágenes de salida. Utilice uno de los siguientes métodos:

* Para renderizar una única imagen, configure las opciones **ImageWidth**/**ImageHeight**.
* Para renderizar varias imágenes, configure las opciones **ImageMaxWidth**/**ImageMaxHeight**. Si una imagen supera estos límites, se redimensiona proporcionalmente.

:::warning
Si configura las opciones `ImageWidth`/`ImageHeight`, las opciones `ImageMaxWidth`/`ImageMaxHeight` se ignoran.
:::

Para configurar las opciones `ImageMaxWidth`/`ImageMaxHeight`, siga estos pasos:

1. Instancie el objeto `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>`.
2. Instancie el objeto `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>`.
3. Establezca los valores de `ImageMaxWidth` y/o `ImageMaxHeight`;
4. Llame al método `<a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>`.

El siguiente fragmento de código muestra cómo establecer los límites del tamaño de la imagen de salida:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer;
// ...

using (Viewer viewer = new Viewer("sample.jpg"))
{
    // Create a PDF file.
    PdfViewOptions viewOptions = new PdfViewOptions();
    
    // Specify the maximum width and height.
    viewOptions.ImageMaxWidth = 800;
    viewOptions.ImageMaxHeight = 600;
    viewer.View(viewOptions);
}
```

</TabItem>

Para acelerar la impresión de un archivo PDF y reducir su tamaño, puede convertirlo desde el espacio de color RGB a escala de grises.

Para convertir un archivo PDF a escala de grises, establezca la propiedad <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/converttograyscale" target="_blank" rel="nofollow noopener noreferrer">ConvertToGrayScale</a> en `true`.

El siguiente fragmento de código muestra cómo convertir un archivo PDF a escala de grises:

<Tabs groupId="Example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.docx"))
{
    PdfViewOptions viewOptions = new PdfViewOptions();
    viewOptions.PdfOptimizationOptions = new PdfOptimizationOptions
    {
        ConvertToGrayScale = true
    };
     
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.docx")
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()
            viewOptions.PdfOptimizationOptions = New PdfOptimizationOptions With {
                .ConvertToGrayScale = True
                }
    
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

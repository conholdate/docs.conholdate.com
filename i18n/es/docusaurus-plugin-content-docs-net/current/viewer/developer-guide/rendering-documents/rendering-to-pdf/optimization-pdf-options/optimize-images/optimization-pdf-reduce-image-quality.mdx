Si el archivo PDF de salida contiene imágenes, puede reducir su tamaño mediante compresión de imágenes.

Para habilitar la compresión de imágenes, establezca la propiedad `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/compressimages/" target="_blank" rel="nofollow noopener noreferrer">CompressImages</a>` en ``true``. La `GroupDocs.Viewer` comprime todas las imágenes del archivo.

La propiedad `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/imagequality/" target="_blank" rel="nofollow noopener noreferrer">ImageQuality</a>` determina la relación de compresión. Es un valor de calidad expresado en porcentaje: 100 % significa calidad original.

El siguiente fragmento de código muestra cómo comprimir las imágenes en el archivo:

<Tabs groupId="Example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.docx"))
{
    PdfViewOptions viewOptions = new PdfViewOptions();
    viewOptions.PdfOptimizationOptions = new PdfOptimizationOptions
    {
        CompressImages = true,
        ImageQuality = 50
    };
     
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.docx")
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()
            viewOptions.PdfOptimizationOptions = New PdfOptimizationOptions With {
                .CompressImages = True,
                .ImageQuality = 50
                }

            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

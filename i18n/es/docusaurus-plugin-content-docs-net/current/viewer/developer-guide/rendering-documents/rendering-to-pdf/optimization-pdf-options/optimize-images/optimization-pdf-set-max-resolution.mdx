Si el archivo PDF de salida contiene imágenes, puede reducir su resolución.

Para permitir cambiar la resolución de las imágenes, establezca las propiedades `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/compressimages/" target="_blank" rel="nofollow noopener noreferrer">CompressImages</a>` y `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/resizeimages/" target="_blank" rel="nofollow noopener noreferrer">ResizeImages</a>` en ``true``. La propiedad `GroupDocs.Viewer` comprime todas las imágenes del archivo. La propiedad `<a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer.options/pdfoptimizationoptions/maxresolution/" target="_blank" rel="nofollow noopener noreferrer">MaxResolution</a>` determina la resolución máxima.

El siguiente fragmento de código muestra cómo reducir la resolución de las imágenes en el archivo:

<Tabs groupId="Example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (var viewer = new Viewer("sample.docx"))
{
    PdfViewOptions viewOptions = new PdfViewOptions();
    viewOptions.PdfOptimizationOptions = new PdfOptimizationOptions
    {
        CompressImages = true,
        ImageQuality = 50,
        ResizeImages = true,
        MaxResolution = 100
    };
     
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer = New Viewer("sample.docx")
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()
            viewOptions.PdfOptimizationOptions = New PdfOptimizationOptions With {
                .CompressImages = True,
                .ImageQuality = 50,
                .ResizeImages = True,
                .MaxResolution = 100
                }

            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

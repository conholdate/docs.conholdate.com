GroupDocs.Viewer le permite optimizar el archivo PDF de salida para un navegador web o reducir su tamaño de archivo optimizando los recursos.

La optimización para la web permite que un navegador muestre las primeras páginas de un archivo PDF al abrir el documento, en lugar de esperar a que se descargue el archivo completo.

La optimización de recursos le permite reducir el tamaño del archivo PDF de salida. Al optimizar, GroupDocs.Viewer puede reducir el tamaño o la calidad de las imágenes, eliminar notas o campos de formulario, eliminar objetos, fuentes o información personal del documento, entre otras acciones.

También puede optimizar un archivo PDF existente. Para ello, ábralo, especifique los parámetros de optimización y guarde el archivo de salida.

En GroupDocs.Viewer, el procesamiento (rendering) es el proceso de convertir un documento en uno o más archivos adecuados para su visualización. Los archivos resultantes pueden estar en uno de los siguientes formatos:

* HTML  
* PDF  
* Imágenes (JPG o PNG)

Si el documento de origen contiene varias páginas, el resultado del procesamiento a PDF es un único archivo paginado.  
El procesamiento de un documento de varias páginas a HTML o imágenes genera varios archivos, uno por cada página.

Por ejemplo, si tiene un archivo .docx con tres páginas, convertir ese archivo a HTML o imágenes produce tres archivos HTML o de imagen, cada uno representando una página del documento. Convertir este archivo a PDF produce un único archivo con tres páginas.

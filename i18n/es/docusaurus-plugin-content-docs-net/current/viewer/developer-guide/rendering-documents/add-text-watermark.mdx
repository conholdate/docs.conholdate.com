Para agregar una marca de agua a la salida en formato HTML/JPG/PNG/PDF, siga estos pasos:

1. Cree una instancia de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> (o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOption</a>, o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>);
2. Cree un objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> y configure sus propiedades;
3. Asigne el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/watermark" target="_blank" rel="nofollow noopener noreferrer">Watermark</a> a la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions.Watermark</a> (o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions.Watermark</a>, o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions.</a>[Watermark](https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions), o <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/viewoptions/properties/watermark" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions.Watermark</a>);
4. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>.

El siguiente fragmento de código muestra cómo aplicar la marca de agua a las páginas de salida.

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create an HTML file.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();
    // Add watermark
    viewOptions.Watermark = new Watermark("This is a watermark");
    viewer.View(viewOptions);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create an HTML file.
            Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources   ()
            ' Add watermark
            viewOptions.Watermark = New Watermark("This is a watermark")
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

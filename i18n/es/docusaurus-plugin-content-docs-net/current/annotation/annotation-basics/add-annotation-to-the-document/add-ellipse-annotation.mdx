La anotación elíptica dibuja una anotación elíptica en una página de documento, como se muestra en la imagen a continuación.

![](/net/annotation/images/add-ellipse-annotation.png)

Puede configurar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/ellipseannotation" target="_blank" rel="nofollow noopener noreferrer">EllipseAnnotation</a>: 

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> define el color de fondo de la elipse;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la posición de la anotación en la página;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite configurar la opacidad de la anotación;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> define el color del lápiz;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> define el estilo de línea (sólida, discontinua, punteada, etc.);
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> define el grosor de la línea en píxeles. 

Para agregar una anotación elíptica, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/ellipseannotation" target="_blank" rel="nofollow noopener noreferrer">EllipseAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/ellipseannotation" target="_blank" rel="nofollow noopener noreferrer">EllipseAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/ellipseannotation" target="_blank" rel="nofollow noopener noreferrer">EllipseAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add ellipse annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	EllipseAnnotation ellipse = new EllipseAnnotation
    {
    	BackgroundColor = 65535,
        Box = new Rectangle(100, 100, 100, 100),
        CreatedOn = DateTime.Now,
        Message = "This is ellipse annotation",
        Opacity = 0.7,
        PageNumber = 0,
        PenColor = 65535,
        PenStyle = PenStyle.Dot,
        PenWidth = 3,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
       }
   };
   annotator.Add(ellipse);
   annotator.Save("result.pdf");
}
```

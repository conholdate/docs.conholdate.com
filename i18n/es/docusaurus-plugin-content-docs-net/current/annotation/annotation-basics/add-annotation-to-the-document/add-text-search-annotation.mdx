Las búsquedas de anotaciones de texto buscan texto específico y lo resaltan, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-text-search-annotation.png)
                          

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> define el color de fondo del área
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> define el texto que se buscará. Si el documento no contiene el texto específico, no se resaltará nada
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> define el color del texto
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontfamily" target="_blank" rel="nofollow noopener noreferrer">FontFamily</a> define el nombre de la fuente del texto
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/searchtextannotation/properties/fontsize" target="_blank" rel="nofollow noopener noreferrer">FontSize</a> define el tamaño de fuente del texto

Para agregar una anotación de búsqueda de texto, siga estos pasos: 

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchText</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/searchtextannotation" target="_blank" rel="nofollow noopener noreferrer">SearchTextAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add search text annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	SearchTextFragment searchText = new SearchTextFragment()
    {
    	Text = "Welcome to GroupDocs", //If the document does not contain this text, nothing will be highlighted
        FontSize = 10,
        FontFamily = "Calibri",
        FontColor = 65535,
        BackgroundColor = 16761035,
	};
    annotator.Add(searchText);
    annotator.Save("result.pdf");
} 
```

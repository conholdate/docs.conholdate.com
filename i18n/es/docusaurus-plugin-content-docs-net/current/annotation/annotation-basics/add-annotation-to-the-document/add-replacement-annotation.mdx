La anotación de reemplazo sustituye el texto original por el fragmento de texto especificado, como se muestra en la imagen a continuación: 

![](/net/annotation/images/add-replacement-annotation.png)

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> define el color del texto de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite establecer la opacidad de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/points" target="_blank" rel="nofollow noopener noreferrer">Points</a> define las posiciones de la anotación como un array de puntos
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/replacementannotation/properties/texttoreplace" target="_blank" rel="nofollow noopener noreferrer">TextToReplace</a> define el texto de reemplazo   
     

Para agregar una anotación de reemplazo, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida. 

  

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/replacementannotation" target="_blank" rel="nofollow noopener noreferrer">ReplacementAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add replacement annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	ReplacementAnnotation replacement = new ReplacementAnnotation
    {
    	CreatedOn = DateTime.Now,
        FontColor = 65535,
        Message = "This is replacement annotation",
        Opacity = 0.7,
        PageNumber = 0,
        FontSize = 11,
        Points = new List<Point>
        {
        	new Point(80, 730), new Point(240, 730), new Point(80, 650), new Point(240, 650)
        },
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
                Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
         },
         TextToReplace = "replaced text"
     };
     annotator.Add(replacement);
     annotator.Save("result.pdf");
}
```

La anotación de imágenes le permite agregar una imagen en la página del documento, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-image-annotation.png)

Puede configurar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/imagepath" target="_blank" rel="nofollow noopener noreferrer">ImagePath</a> define la ruta local o remota de la imagen
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la posición de la anotación en la página utilizando la estructura <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/rectangle" target="_blank" rel="nofollow noopener noreferrer">Rectangle</a> (la imagen se redimensionará según el ancho y la altura especificados)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite configurar la opacidad de la anotación (presente en todos los formatos admitidos; ejemplos de esto se muestran anteriormente)
*   [Angle]() define el ángulo de rotación de la anotación

Para agregar una anotación de imagen, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/imageannotation" target="_blank" rel="nofollow noopener noreferrer">ImageAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
            {
                ImageAnnotation area = new ImageAnnotation
                {
                    Box = new Rectangle(100, 100, 100, 100),
                    Opacity = 0.7,
                    PageNumber = 0,
                    ImagePath = "www.google.com.ua/images/branding/googlelogo/2x/googlelogo_color_92x30dp.png",
                    Angle = 100
                };
                annotator.Add(area);
                annotator.Save("result.pdf");
            }
```

La anotación de campo de texto agrega un rectángulo con texto dentro, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-text-field-annotation.png)

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> define el color de fondo del área
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la posición de la anotación en la página del documento
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/text" target="_blank" rel="nofollow noopener noreferrer">Text</a> define el texto que se colocará dentro del rectángulo
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> define el color del texto
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontfamily" target="_blank" rel="nofollow noopener noreferrer">FontFamily</a> define el nombre de la fuente del texto
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/fontsize" target="_blank" rel="nofollow noopener noreferrer">FontSize</a> define el tamaño de la fuente del texto
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite establecer la opacidad de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> define el estilo de línea del marco (sólido, guiones, puntos, etc.)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> define el ancho de la línea del marco en píxeles
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textfieldannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> define el color del marco
*   [TextHorizontalAlignment]() define la alineación horizontal del texto

Para agregar una anotación de campo de texto, siga estos pasos: 

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.  

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textfieldannotation" target="_blank" rel="nofollow noopener noreferrer">TextFieldAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add text field annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	TextFieldAnnotation textField = new TextFieldAnnotation
    {
    	BackgroundColor = 65535,
        Box = new Rectangle(100, 100, 100, 100),
        CreatedOn = DateTime.Now,
        Text = "Some text",
        FontColor = 65535,
        FontSize = 12,
        Message = "This is text field annotation",
        Opacity = 0.7,
        PageNumber = 0,
        PenStyle = PenStyle.Dot,
        PenWidth = 3,
        FontFamily = "Arial",
        TextHorizontalAlignment = HorizontalAlignment.Center,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
	};
    annotator.Add(textField);
    annotator.Save("result.pdf");
} 
```

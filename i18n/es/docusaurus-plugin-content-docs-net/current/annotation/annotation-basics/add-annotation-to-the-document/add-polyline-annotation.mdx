La anotación de polilíneas le permite dibujar formas y líneas a mano alzada, como se muestra en la imagen siguiente: 

![](/net/annotation/images/add-polyline-annotation.png)

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/polylineannotation" target="_blank" rel="nofollow noopener noreferrer">PolylineAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la posición de la anotación en la página
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite establecer la opacidad de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> define el color del marco
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> define el estilo de línea del marco (sólido, guiones, puntos, etc.)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> define el grosor de la línea del marco en píxeles
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/polylineannotation/properties/svgpath" target="_blank" rel="nofollow noopener noreferrer">SvgPath</a> define la ruta SVG que describe la forma

Para agregar una anotación de polilínea, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/polylineannotation" target="_blank" rel="nofollow noopener noreferrer">PolylineAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/polylineannotation" target="_blank" rel="nofollow noopener noreferrer">PolylineAnnotation</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida. 

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/polylineannotation" target="_blank" rel="nofollow noopener noreferrer">PolylineAnnotation</a> al documento:

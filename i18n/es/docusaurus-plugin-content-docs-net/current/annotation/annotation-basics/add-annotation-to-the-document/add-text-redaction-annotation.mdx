La anotación de redacción de texto rellena una parte del texto con un rectángulo negro para ocultar el contenido, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-text-redaction-annotation.png)

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textredactionannotation" target="_blank" rel="nofollow noopener noreferrer">TextRedactionAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/textredactionannotation/properties/points" target="_blank" rel="nofollow noopener noreferrer">Points</a> define las posiciones de las anotaciones como un array de puntos 
    

Para agregar una anotación de redacción de texto, siga estos pasos:

1.  Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.  Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textredactionannotation" target="_blank" rel="nofollow noopener noreferrer">TextRedactionAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.  Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textredactionannotation" target="_blank" rel="nofollow noopener noreferrer">TextRedactionAnnotation</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.  

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/textredactionannotation" target="_blank" rel="nofollow noopener noreferrer">TextRedactionAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add text redaction annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	TextRedactionAnnotation textRedaction = new TextRedactionAnnotation
    {
    	CreatedOn = DateTime.Now,
        Message = "This is text redaction annotation",
        FontColor = 16761035,
        PageNumber = 0,
        Points = new List<Point>
        {
        	new Point(80, 730), new Point(240, 730), new Point(80, 650), new Point(240, 650)
        },
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
         }
     };
     annotator.Add(textRedaction);
     annotator.Save("result.pdf");
}
```

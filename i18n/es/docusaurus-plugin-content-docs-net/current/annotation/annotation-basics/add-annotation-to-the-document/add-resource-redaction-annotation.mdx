La anotación de redacción de recursos rellena un rectángulo negro con posición fija para ocultar un texto, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-resource-redaction-annotation.png)

Puede especificar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/resourcesredactionannotation" target="_blank" rel="nofollow noopener noreferrer">ResourcesRedactionAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/resourcesredactionannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la anotación en la página

Para agregar una anotación de redacción de recursos, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/resourcesredactionannotation" target="_blank" rel="nofollow noopener noreferrer">ResourceRedactionAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/resourcesredactionannotation" target="_blank" rel="nofollow noopener noreferrer">ResourceRedactionAnnotation</a>.
4.  Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida. 

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/resourcesredactionannotation" target="_blank" rel="nofollow noopener noreferrer">ResourcesRedactionAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add resource redaction annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	ResourcesRedactionAnnotation resourcesRedaction = new ResourcesRedactionAnnotation
    {
    	Box = new Rectangle(100, 100, 100, 100),
        CreatedOn = DateTime.Now,
        Message = "This is resources redaction annotation",
        PageNumber = 0,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
   };
   annotator.Add(resourcesRedaction);
   annotator.Save("result.pdf");
} 

```

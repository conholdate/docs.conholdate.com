La anotación de flecha dibuja una flecha en la página del documento y la anota como se muestra en la imagen a continuación. 

![](/net/annotation/images/add-arrow-annotation.png)

Puede configurar las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/arrowannotation" target="_blank" rel="nofollow noopener noreferrer">ArrowAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/box" target="_blank" rel="nofollow noopener noreferrer">Box</a> define la posición de la anotación en la página del documento
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite establecer la opacidad de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/pencolor" target="_blank" rel="nofollow noopener noreferrer">PenColor</a> define el color de la flecha
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penstyle" target="_blank" rel="nofollow noopener noreferrer">PenStyle</a> define el estilo de línea de la anotación (sólida, discontinua, punteada, etc.)
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/penwidth" target="_blank" rel="nofollow noopener noreferrer">PenWidth</a> define el grosor de la línea de la flecha en píxeles

Para agregar una anotación de flecha al documento, siga estos pasos:  

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/arrowannotation" target="_blank" rel="nofollow noopener noreferrer">ArrowAnnotation</a>. Configure las propiedades correspondientes (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/arrowannotation" target="_blank" rel="nofollow noopener noreferrer">ArrowAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.  

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/arrowannotation" target="_blank" rel="nofollow noopener noreferrer">ArrowAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	ArrowAnnotation arrow = new ArrowAnnotation
    {
        Box = new Rectangle(100, 100, 100, 100),
        CreatedOn = DateTime.Now,
        Message = "This is arrow annotation",
        Opacity = 0.7,
        PageNumber = 0,
        PenColor = 65535,
        PenStyle = PenStyle.Dot,
        PenWidth = 3,
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
             	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(arrow);
    annotator.Save("result.pdf");
}
```

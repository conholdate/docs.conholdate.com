## ¿Qué es una anotación de documento? {#what-is-a-document-annotation}

Una anotación son notas, comentarios u observaciones, ya sea textuales o gráficas, adjuntas a una parte específica del contenido de un documento: secciones, párrafos, oraciones o incluso palabras. Las anotaciones suelen utilizarse por un grupo de colaboradores para editar y revisar documentos de forma rápida y sencilla: el documento se comparte con los revisores, quienes lo marcan y añaden notas. Posteriormente, los miembros del equipo asignados leen dichas anotaciones y modifican el contenido del documento en consecuencia.

Hoy en día, las anotaciones pueden añadirse programáticamente a documentos e imágenes de diversos tipos: PDF, documentos de texto de Microsoft Word y Open Document, hojas de cálculo de Microsoft Excel, presentaciones de Microsoft PowerPoint, imágenes PNG / JPG / TIFF, etc. 

  

### Añadir una anotación al documento {#add-annotation-to-the-document}

**<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a>** permite aplicar diversos tipos de anotaciones a distintos formatos de documento. La lista de anotaciones admitidas se describe en la tabla siguiente. 

### Lista de anotaciones admitidas {#list-of-supported-annotations}

| Anotación | Descripción |
| --- | --- |
| [Área](/net/annotation/annotation-basics/add-annotation-to-the-document/add-area-annotation/) | Anotación rectangular que puede aplicarse en cualquier lugar de la página del documento. |
| [Flecha](/net/annotation/annotation-basics/add-annotation-to-the-document/add-arrow-annotation/) | Anotación en forma de puntero o flecha. |
| [Distancia](/net/annotation/annotation-basics/add-annotation-to-the-document/add-distance-annotation/) | Anotación similar a una flecha, pero con flechas en ambos extremos de la línea. En la mayoría de los formatos de documento, esta anotación puede contener un valor de texto (esta funcionalidad no está disponible para documentos de Word). |
| [Elipse](/net/annotation/annotation-basics/add-annotation-to-the-document/add-ellipse-annotation/) | Anotación basada en círculos. |
| [Enlace](/net/annotation/annotation-basics/add-annotation-to-the-document/add-link-annotation/) | Representa un enlace web que puede aplicarse a una parte del texto. Esta anotación solo es compatible con PDF, documentos de procesamiento de texto de Word y presentaciones. |
| [Punto](/net/annotation/annotation-basics/add-annotation-to-the-document/add-point-annotation/) | Representa una anotación puntual abstracta. |
| [Polilínea](/net/annotation/annotation-basics/add-annotation-to-the-document/add-polyline-annotation/) | Representa una línea dibujada a mano alzada. |
| [Redacción de recursos](/net/annotation/annotation-basics/add-annotation-to-the-document/add-resource-redaction-annotation/) | Representa una anotación rectangular libre con posición fija y fondo negro. Para esta anotación no es posible moverla (en el documento resultante) ni modificar ninguna propiedad visual. |
| [Campo de texto](/net/annotation/annotation-basics/add-annotation-to-the-document/add-text-field-annotation/) | Se trata de una anotación rectangular que contiene texto dentro del área del rectángulo. |
| [Resaltado](/net/annotation/annotation-basics/add-annotation-to-the-document/add-highlight-annotation/) | Resalta texto. Solo es aplicable al texto. |
| [Redacción de texto](/net/annotation/annotation-basics/add-annotation-to-the-document/add-text-redaction-annotation/) | Similar a la anotación de redacción de recursos, pero solo aplicable al texto. |
| [Reemplazo](/net/annotation/annotation-basics/add-annotation-to-the-document/add-replacement-annotation/) | Reemplaza el texto original del documento por el texto definido por el usuario. Solo es aplicable al texto. |
| [Tachado](/net/annotation/annotation-basics/add-annotation-to-the-document/add-strikeout-annotation/) | Aplica tachado al texto seleccionado. Solo es aplicable al texto. |
| [Subrayado](/net/annotation/annotation-basics/add-annotation-to-the-document/add-underline-annotation/) | Aplica subrayado al texto seleccionado. Solo es aplicable al texto. |
| [Marca de agua](/net/annotation/annotation-basics/add-annotation-to-the-document/add-watermark-annotation/) | Añade una marca de agua de texto. La propiedad PageNumber se ignora para esta anotación, ya que se añade a todas las páginas del documento. En algunos formatos de documento, se puede establecer la propiedad Angle, que determina el ángulo de rotación de la anotación. |

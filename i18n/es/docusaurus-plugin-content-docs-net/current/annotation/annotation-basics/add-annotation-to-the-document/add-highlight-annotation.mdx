Resalta las anotaciones y comentarios resaltando y seleccionando el texto, como se muestra en la imagen a continuación:

![](/net/annotation/images/add-highlight-annotation.png)

Puede establecer las siguientes propiedades de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/highlightannotation" target="_blank" rel="nofollow noopener noreferrer">HighlightAnnotation</a>:

*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/backgroundcolor" target="_blank" rel="nofollow noopener noreferrer">BackgroundColor</a> define el color de fondo de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/linkannotation/properties/fontcolor" target="_blank" rel="nofollow noopener noreferrer">FontColor</a> define el color del texto de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/areaannotation/properties/opacity" target="_blank" rel="nofollow noopener noreferrer">Opacity</a> le permite establecer la opacidad de la anotación
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/linkannotation/properties/points" target="_blank" rel="nofollow noopener noreferrer">Points</a> define las posiciones de la anotación como un array de puntos

Para agregar una anotación de resaltado, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/highlightannotation" target="_blank" rel="nofollow noopener noreferrer">HighlightAnnotation</a>. Especifique las propiedades adecuadas (posición, número de página, etc.).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a>. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/highlightannotation" target="_blank" rel="nofollow noopener noreferrer">HighlightAnnotation</a>.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida. 
      
    

El siguiente fragmento de código muestra cómo agregar <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/highlightannotation" target="_blank" rel="nofollow noopener noreferrer">HighlightAnnotation</a> al documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Add highlight annotation to the document from local disk
using (Annotator annotator = new Annotator("input.pdf"))
{
	HighlightAnnotation highlight = new HighlightAnnotation
    {
    	BackgroundColor = 65535,
        CreatedOn = DateTime.Now,
        FontColor = 0,
        Message = "This is highlight annotation",
        Opacity = 0.5,
        PageNumber = 0,
        Points = new List<Point>
        {
        	new Point(80, 730), new Point(240, 730), new Point(80, 650), new Point(240, 650)
        },
        Replies = new List<Reply>
        {
        	new Reply
            {
            	Comment = "First comment",
                RepliedOn = DateTime.Now
            },
            new Reply
            {
            	Comment = "Second comment",
                RepliedOn = DateTime.Now
            }
        }
    };
    annotator.Add(highlight);
    annotator.Save("result.pdf");
} 

```

GroupDocs.Annotation le permite obtener la siguiente información sobre el archivo:

*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a> es el tipo de archivo del documento (PDF, documento de Word, hoja de cálculo de Excel, presentación de PowerPoint o imagen, etc.).
*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/pagecount" target="_blank" rel="nofollow noopener noreferrer">PageCount</a> es el número de páginas del documento.
*   <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/idocumentinfo/properties/size" target="_blank" rel="nofollow noopener noreferrer">FileSize</a> es el tamaño del archivo.

<a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/idocumentinfo/properties/pagesinfo" target="_blank" rel="nofollow noopener noreferrer">PagesInfo</a> representa una `List` de los objetos <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a>, los cuales almacenan información sobre cada página. 

<a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a> tiene las siguientes propiedades (en píxeles):
* <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a>
* <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> en píxeles. 

Estas propiedades admiten todos los formatos, excepto los de correo electrónico y HTML. El ancho y la altura son idénticos para todas las páginas, excepto en los formatos de hojas de cálculo (Cells).

El siguiente fragmento de código muestra cómo obtener información sobre un documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
//Get file info for the file from local disk
using (Annotator annotator = new Annotator("input.docx"))
{
	IDocumentInfo info = annotator.Document.GetDocumentInfo();
    int width = info.PagesInfo[0].Width;
    int height = info.PagesInfo[0].Height;
    Console.WriteLine("\nFile type: {0}\nNumber of pages: {1}\nDocument size: {2} bytes", info.FileType, info.PageCount, info.Size);
}
```

<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite extraer anotaciones de un documento y serializarlas en formato XML.  

Para ello, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a> y configure `ImportAnnotation = true`.
3.   Defina una variable del tipo `List<AnnotationBase>`.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> para obtener el resultado en la variable definida en el paso anterior.
5.   Instancie la clase `XmlSerializer` con el tipo `List<AnnotationBase>`.
6.   Utilice el objeto `FileStream` para serializar las anotaciones en un archivo.

El siguiente fragmento de código muestra cómo extraer anotaciones de un documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// for using this example input file ("annotated.pdf") must have annotations
using (Annotator annotator = new Annotator("annotated.pdf"))
{
	List<AnnotationBase> annotations = annotator.Get();
    XmlSerializer formatter = new XmlSerializer(typeof(List<AnnotationBase>));
    using (FileStream fs = new FileStream("annotations.xml", FileMode.Create))
    {
    	fs.SetLength(0);
        formatter.Serialize(fs, annotations);
    }
}
```

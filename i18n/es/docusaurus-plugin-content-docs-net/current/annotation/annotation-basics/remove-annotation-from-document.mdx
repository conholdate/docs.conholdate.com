<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite eliminar todas las anotaciones previamente agregadas. Para ello, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>. Establezca `AnnotationTypes = AnnotationType.None`.
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

## Eliminar anotación mediante su índice {#remove-annotation-using-its-index}

El siguiente fragmento de código muestra cómo eliminar una anotación mediante su índice:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	annotator.Remove(0);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>


## Eliminar anotación mediante el objeto {#remove-annotation-using-the-object}

El siguiente fragmento de código muestra cómo eliminar la anotación mediante el objeto:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	var tmp = annotator.Get();
	annotator.Remove(tmp[0]);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>


## Eliminar anotaciones mediante una lista de índices {#remove-annotations-using-the-list-of-indexes}

El siguiente fragmento de código muestra cómo eliminar anotaciones mediante una lista de índices:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.xlsx"))
{
	var idList = new List<int>{1, 2, 3};
	annotator.Remove(idList);
	annotator.Save("removed.xlsx");
}
```

</TabItem>


</Tabs>

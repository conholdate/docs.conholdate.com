<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite actualizar anotaciones especificando sus propiedades <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/annotationbase/properties/id" target="_blank" rel="nofollow noopener noreferrer">Id</a>. Asimismo, puede actualizar anotaciones proporcionando una colección de objetos de anotación actualizados que reemplazan todas las anotaciones existentes del documento.  

Para actualizar anotaciones, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Cree una implementación de <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/annotationbase" target="_blank" rel="nofollow noopener noreferrer">AnnotationBase</a> y establezca el Id de una anotación existente (si no se encuentra una anotación con ese Id, se ignora) o bien una lista de rutas de anotaciones (se eliminarán todas las anotaciones existentes).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/update/index" target="_blank" rel="nofollow noopener noreferrer">Update</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique las anotaciones.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

El siguiente código demuestra cómo actualizar anotaciones:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
            {
                AreaAnnotation original = new AreaAnnotation
                {
                    Id = 1,
                    BackgroundColor = 65535,
                    Box = new Rectangle(100, 100, 100, 100),
                    CreatedOn = DateTime.Now,
                    Message = "This is original annotation",
                    Replies = new List<Reply>
                    {
                        new Reply
                        {
                            Comment = "Original first comment",
                            RepliedOn = DateTime.Now
                        },
                        new Reply
                        {
                            Comment = "Original second comment",
                            RepliedOn = DateTime.Now
                        }
                    }
                };
                // add original annotation
                annotator.Add(original);
                annotator.Save("result.pdf");
            }

            // open annotated document
            using (Annotator annotator = new Annotator("result.pdf"))
            {
                //assuming we are going to change some properties of existing annotation
                AreaAnnotation updated = new AreaAnnotation
                {
                    // It's important to set existed annotation Id
                    Id = 1,
                    BackgroundColor = 255,
                    Box = new Rectangle(0, 0, 50, 200),
                    CreatedOn = DateTime.Now,
                    Message = "This is updated annotation",
                    Replies = new List<Reply>
                    {
                        new Reply
                        {
                            Comment = "Updated first comment",
                            RepliedOn = DateTime.Now
                        },
                        new Reply
                        {
                            Comment = "Updated second comment",
                            RepliedOn = DateTime.Now
                        }
                    }
                };
                // update annotation
                annotator.Update(updated);
                annotator.Save("result.pdf");
            }
```

También puede actualizar anotaciones mediante su identificador (Id). También puede pasar una lista de anotaciones; en ese caso, todas las anotaciones anteriores se reemplazarán por la nueva lista.

Para hacerlo, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Cree una implementación de <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models.annotationmodels/annotationbase" target="_blank" rel="nofollow noopener noreferrer">AnnotationBase</a> y establezca el identificador (Id) de una anotación existente (si no se encuentra una anotación con ese Id, se ignora) o bien una lista de rutas de anotaciones (se eliminarán todas las anotaciones existentes).
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/update/index" target="_blank" rel="nofollow noopener noreferrer">Update</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>, especificando las anotaciones.
4.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>, especificando la ruta o el flujo del documento de salida.

El siguiente código demuestra cómo actualizar anotaciones mediante su identificador (Id):

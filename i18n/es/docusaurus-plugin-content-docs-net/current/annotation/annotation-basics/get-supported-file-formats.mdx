<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite obtener la lista de formatos de archivo admitidos. Para ello, siga estos pasos:

1.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype/methods/getsupportedfiletypes" target="_blank" rel="nofollow noopener noreferrer">GetSupportedFileTypes</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.
2.   Itere a través de la colección de objetos <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/filetype" target="_blank" rel="nofollow noopener noreferrer">FileType</a>.

El siguiente fragmento de código muestra cómo obtener la lista de formatos de archivo admitidos:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
IEnumerable<FileType> supportedFileTypes = FileType
	.GetSupportedFileTypes()
	.OrderBy(f => f.Extension);

foreach (FileType fileType in supportedFileTypes)
	Console.WriteLine(fileType);
```

<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite actualizar las respuestas a las anotaciones accediendo a ellas mediante la colección <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/annotationbase/properties/replies" target="_blank" rel="nofollow noopener noreferrer">Replies</a>.

Para actualizar las respuestas a las anotaciones, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Llame al método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> para obtener la colección de anotaciones del documento.
3.   Acceda a un objeto de respuesta en la colección <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels/annotationbase/properties/replies" target="_blank" rel="nofollow noopener noreferrer">Replies</a> utilizando su índice (basado en cero) y actualice sus propiedades.
4.   Llame al método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/update" target="_blank" rel="nofollow noopener noreferrer">Update</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique las anotaciones.
5.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida y la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>.
    

El siguiente fragmento de código muestra cómo actualizar una respuesta por índice: 


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("result.pdf"))
{
	// Obtain annotations collection from document
	List<AnnotationBase> annotations = annotator.Get();
                
	// Update first annotation first reply
	annotations[0].Replies[0].Comment = "Updated reply";
                
	// Save changes
	annotator.Update(annotations);
	annotator.Save("result.pdf");
}
```

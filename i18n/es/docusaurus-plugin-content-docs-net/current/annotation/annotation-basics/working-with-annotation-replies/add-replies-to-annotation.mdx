<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite colaborar en un documento mediante anotaciones y respuestas a anotaciones. 
  
Para actualizar una respuesta a una anotación, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/user" target="_blank" rel="nofollow noopener noreferrer">User</a>.
3.   Instancie la(s) clase(s) <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/reply" target="_blank" rel="nofollow noopener noreferrer">Reply</a>.
4.   Instancie el objeto de anotación del tipo adecuado. Los tipos de anotación disponibles se enumeran <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models.annotationmodels" target="_blank" rel="nofollow noopener noreferrer">here</a>.
5.   Asigne la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/user" target="_blank" rel="nofollow noopener noreferrer">User</a> a la propiedad `Reply.User` (por defecto es "Invitado").
6.   Asigne la(s) clase(s) <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.models/reply" target="_blank" rel="nofollow noopener noreferrer">Reply</a> a la colección `Replies` creada en los pasos anteriores.
7.   Llame al método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/add" target="_blank" rel="nofollow noopener noreferrer">Add</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la anotación.
8.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.

El siguiente fragmento de código muestra cómo agregar respuestas a una anotación:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	User user1 = new User
	{
		Id = 1,
		Name = "Tom",
		Email = "somemail@mail.com"
	};
	User user2 = new User
	{
		Id = 2,
		Name = "Jack",
		Email = "somebody@mail.com"
	};
	AreaAnnotation area = new AreaAnnotation
	{
		Box = new Rectangle(100, 100, 100, 100),
		CreatedOn = DateTime.Now,
		Message = "This is an area annotation",
		PageNumber = 0,
		Replies = new List<Reply>
		{
			new Reply
			{
				Id = 1,
				Comment = "First comment",
				RepliedOn = DateTime.Now,
				User = user1
			},
			new Reply
			{
				Id = 2,
				Comment = "Second comment",
				RepliedOn = DateTime.Now,
				User = user2,
			}
		}
	};
annotator.Add(area);
annotator.Save("result.pdf");
}
```

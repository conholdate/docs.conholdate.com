## ¿Qué son las respuestas a anotaciones? {#what-are-annotation-replies}

GroupDocs.Annotation le permite almacenar la discusión escrita directamente dentro de un documento y ofrece una forma eficaz de colaborar durante la revisión y corrección de documentos. Diferentes proveedores de software ofrecen sus propios métodos para comentar y anotar el contenido de los documentos; por lo tanto, cuando necesita colaborar en distintos tipos de documentos, es necesario tener varias aplicaciones instaladas en el dispositivo de cada colaborador.   
<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation para .NET</a> proporciona una API para agregar, editar o eliminar respuestas a anotaciones en una amplia gama de formatos de documento compatibles dentro de su aplicación.

Puede eliminar respuestas específicas o todas las respuestas mediante la API de <a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a>. Para ello, elimine los elementos correspondientes de la colección <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1" target="_blank" rel="nofollow noopener noreferrer">List&lt;T&gt;</a>. 

Para eliminar una o varias respuestas de anotaciones, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Llame al método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/get" target="_blank" rel="nofollow noopener noreferrer">Get</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> para obtener la colección de anotaciones del documento.
3.   Acceda a la anotación correspondiente y elimine una respuesta de la manera adecuada:
    *   call the <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.removeat" target="_blank" rel="nofollow noopener noreferrer">RemoveAt(Int32)</a> or <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.remove" target="_blank" rel="nofollow noopener noreferrer">Remove(T)</a> method to remove specific reply;
    *   call the <a href="https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.removeall" target="_blank" rel="nofollow noopener noreferrer">RemoveAll(Predicate&lt;T&gt;)</a> method to remove all replies that match the conditions defined by the  predicate.
4. Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/update/index" target="_blank" rel="nofollow noopener noreferrer">Update</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la colección de anotaciones.
5.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a>. Especifique la ruta o el flujo del documento de salida.
    

## Eliminar una respuesta de anotación específica {#remove-specific-annotation-reply}

El siguiente fragmento de código muestra cómo eliminar una respuesta de anotación por su índice:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("result.pdf"))
{
    // Obtain annotations collection from document
    List<AnnotationBase> annotations = annotator.Get();               
	// Remove first reply 
	annotations[0].Replies.RemoveAt(0);
	// Save changes
	annotator.Update(annotations);
	annotator.Save("result.pdf");
}
```

</TabItem>


</Tabs>


## Eliminar respuestas de anotaciones según criterios {#remove-annotation-replies-by-criteria}

El siguiente fragmento de código muestra cómo eliminar las respuestas que coincidan con ciertos criterios:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
// NOTE: Input document already contain annotations with replies
using (Annotator annotator = new Annotator("annotated_file_with_replies.pdf"))
{
    // Obtain annotations collection from document
    List<AnnotationBase> annotations = annotator.Get();
    // Remove all replies where author name is "Tom"
    annotations[0].Replies.RemoveAll(x => x.User.Name == "Tom");
    // Save changes
    annotator.Update(annotations);
    annotator.Save("result.pdf");
}
```

</TabItem>

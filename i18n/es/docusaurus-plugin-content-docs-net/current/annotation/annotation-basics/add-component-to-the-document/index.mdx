## ¿Qué es un componente de documento? {#what-is-a-document-component}

Un componente es una nota o comentario de texto o gráfico adjunto a una parte específica del contenido del documento: sección, párrafo, oración o palabras.

La principal diferencia entre componentes y anotaciones es que los componentes son específicos del formato de archivo. Esto significa que no se puede aplicar un componente de PDF a un archivo de Word, imagen o diagrama, etc.

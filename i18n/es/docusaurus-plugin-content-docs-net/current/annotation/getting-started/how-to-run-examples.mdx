Ofrecemos múltiples soluciones sobre cómo ejecutar los ejemplos de GroupDocs.Annotation, ya sea construyendo su propio proyecto o utilizando directamente nuestros ejemplos de backend o frontend.

## Construir el proyecto desde cero {#build-project-from-scratch}

Para construir un proyecto desde cero, siga estos pasos:

1.   Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.
2.   Seleccione el tipo de proyecto adecuado: Aplicación de consola, Aplicación web ASP.NET, etc.
3.   Instale **GroupDocs.Annotation para .NET** desde NuGet o desde el sitio web oficial de GroupDocs, tal como se describe en la [guía](/net/annotation/getting-started/installation/).
4.   Desarrolle la aplicación utilizando **GroupDocs.Annotation para .NET**, de la siguiente manera:

<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// Create list of annotations
List<AnnotationBase> annotations = new List<AnnotationBase>()
{
    new AreaAnnotation()
    {
        PageNumber = 0,
        Box = new Rectangle(100, 100, 100, 100),
        Message = "area"
    },
                
    new EllipseAnnotation()
        {
            PageNumber = 0,
            Box = new Rectangle(200, 200, 80, 80),
            Message = "ellipse"
        }
};

// Create annotator
using  (Annotator annotator = new Annotator("C:\output\input.pdf"))
{
    // Add annotations
    annotator.Add(annotations);
    // Save result to "C:\output\result.pdf"
    annotator.Save("C:\output\result.pdf", new SaveOptions());
}
```

</TabItem>


</Tabs>

5.   Compile y ejecute su proyecto.
6.   Las páginas de documentos renderizadas aparecen en el directorio `C:\\output\\`.

## Ejecute los ejemplos del backend {#run-back-end-examples}

Puede encontrar el paquete completo de los ejemplos de **GroupDocs.Annotation** en <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puede <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">descargar el archivo ZIP</a> o clonar el repositorio de GitHub utilizando cualquier cliente de Git.  
Si descargó el archivo ZIP, extraiga las carpetas en el disco local. Los archivos y carpetas extraídos se ven como sigue:

![](/net/annotation/images/how-to-run-examples.png)

Busque el archivo de solución de C#. El proyecto se crea en **Microsoft Visual Studio 2019**. La carpeta `Resources` contiene todos los documentos de ejemplo e imágenes utilizados en los ejemplos.  
Para ejecutar los ejemplos, abra el archivo de solución con Visual Studio y compile el proyecto. Si es necesario, agregue las referencias faltantes de GroupDocs.Annotation. Todas las funciones se llaman en el archivo **RunExamples.cs**. Descomente la(s) función(es) que desee ejecutar y comente el resto.

![](/net/annotation/images/how-to-run-examples_1.png)

## Ejemplos de MVC {#run-mvc-examples}

Para ejecutar el <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC" target="_blank" rel="nofollow noopener noreferrer">ejemplo de MVC de GroupDocs.Annotation para .NET</a>, siga estos pasos:

1.   Descargue el <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">código fuente</a> desde GitHub o clonar el repositorio: 

<Tabs groupId="example2">


<TabItem value="git" label="Git" default>

```bash
git clone https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC
```

</TabItem>


</Tabs>

2.   Abra la solución en Visual Studio. Actualice los parámetros comunes en **web.config** y las propiedades relacionadas con el ejemplo en **configuration.yml** para adaptarlas a sus necesidades.
3.   Abra <a href="http://localhost:8080/annotation" target="_blank" rel="nofollow noopener noreferrer">http://localhost:8080/annotation</a> en su navegador favorito.

Para obtener más detalles sobre la configuración del proyecto, consulte esta <a href="https://github.com/groupdocs-annotation/GroupDocs.Annotation-for-.NET-MVC#configuration" target="_blank" rel="nofollow noopener noreferrer">guía</a>.

## Ejecutar desde Docker {#run-from-docker}

Utilice la imagen de <a href="https://www.docker.com/" target="_blank" rel="nofollow noopener noreferrer">Docker</a> para probar las funcionalidades de GroupDocs.Annotation para .NET. Ejecute los siguientes comandos para ejecutar GroupDocs.Annotation para .NET desde la imagen de Docker:

<Tabs groupId="example4">


<TabItem value="powershell" label="PowerShell" default>

```
mkdir DocumentSamples
mkdir Licenses
docker run -p 8080:8080 --env application.hostAddress=localhost -v `pwd`/DocumentSamples:/home/groupdocs/app/DocumentSamples -v `pwd`/Licenses:/home/groupdocs/app/Licenses groupdocs/annotation
## Open http://localhost:8080/annotation in your favorite browser.
```

</TabItem>


</Tabs>

Este tema describe cómo agregar la biblioteca GroupDocs.Annotation a su proyecto .NET. Puede utilizar un paquete de NuGet para instalar esta biblioteca o descargar los DLLs necesarios desde el sitio web de GroupDocs: <a href="https://releases.groupdocs.com/annotation/net/" target="_blank" rel="nofollow noopener noreferrer">https://releases.groupdocs.com/annotation/net/</a>.

## Instalar GroupDocs.Annotation mediante paquetes de NuGet {#install-groupdocs-annotation-using-nuget-packages}

Puede utilizar las siguientes herramientas para instalar el paquete <a href="https://www.nuget.org/packages/GroupDocs.Annotation" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> de NuGet: 

 * [Administrador de paquetes NuGet](#use-the-nuget-package-manager-in-visual-studio)
 * [Consola del Administrador de paquetes](#use-the-package-manager-console-in-visual-studio)
 * [.NET CLI](#use-the-net-cli)

### Utilizar el Administrador de paquetes NuGet {#use-the-nuget-package-manager}

Abra su proyecto o solución en Visual Studio y siga los pasos a continuación para instalar el paquete **GroupDocs.Annotation** mediante el <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-visual-studio" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes NuGet</a>:

1. En el **Explorador de soluciones**, haga clic con el botón derecho sobre el nombre de su proyecto y seleccione **Administrar paquetes NuGet** para mostrar el Administrador de paquetes NuGet.

    ![Manage NuGet packages in Visual Studio](/net/annotation/images/manage-nuget-packages.png)

2. Seleccione la pestaña **Examinar** y escriba **GroupDocs.Annotation** en el cuadro de búsqueda. Seleccione la versión más reciente del paquete **GroupDocs.Annotation** y haga clic en **Instalar**.

    ![](/net/annotation/images/install-nuget-package.png)

### Use the Package Manager Console {#use-the-package-manager-console}

El <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-powershell" target="_blank" rel="nofollow noopener noreferrer">Package Manager Console</a> utiliza comandos de PowerShell para instalar, actualizar y eliminar paquetes de NuGet. Abra su proyecto en Visual Studio y haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de paquetes** para abrir la ventana de la consola. Ejecute el siguiente comando para instalar la versión más reciente de la biblioteca **GroupDocs.Annotation**:


<Tabs groupId="example1">


<TabItem value="powershell" label="PowerShell" default>

```
PM> Install-Package GroupDocs.Annotation
```

</TabItem>


</Tabs>


![Use Package Manager Console ](/net/annotation/images/package-manager-console.png)

### Utilice la CLI de .NET {#use-the-net-cli}

También puede utilizar la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">herramienta CLI de .NET</a> para instalar y actualizar paquetes de NuGet. Abra una terminal en la carpeta de su proyecto y ejecute el siguiente comando para instalar el paquete **GroupDocs.Annotation**:


<Tabs groupId="example2">


<TabItem value="net-cli" label=".NET CLI" default>

```
dotnet add package GroupDocs.Annotation
```

</TabItem>


</Tabs>


## Descargue GroupDocs.Annotation desde el sitio web oficial {#download-groupdocs-annotation-from-the-official-website}

Visite https://releases.groupdocs.com/annotation/net/ y descargue los ensamblados de **GroupDocs.Annotation** como un archivo ZIP o un instalador MSI. Para hacer referencia a los archivos de ensamblado descargados en su proyecto, realice los siguientes pasos:

1. Extraiga los archivos del archivo ZIP o ejecute el instalador MSI para instalar **GroupDocs.Annotation** en una ubicación específica de su equipo.
2. Abra su solución o proyecto en Visual Studio.
3. En el **Explorador de soluciones**, haga clic derecho en el nodo **Referencias** o **Dependencias** y seleccione **Agregar referencia** (para un proyecto de .NET Framework) o **Agregar referencia de proyecto** (para un proyecto de .NET Core).
4. En el cuadro de diálogo **Administrador de referencias**, seleccione la pestaña **Examinar** y haga clic en **Examinar** para localizar el archivo _GroupDocs.Annotation.dll_ correspondiente al marco de trabajo objetivo.

    ![Browse for the GroupDocs.Annotation assembly](/net/annotation/images/browse-for-groupdocs-dll.png)

5. Haga clic en **Aceptar** para agregar una referencia a la biblioteca **GroupDocs.Annotation** en su proyecto.


:::warning
Si su aplicación está dirigida a .NET Core / .NET 5 o versiones posteriores, asegúrese de que su proyecto tenga instaladas todas las dependencias necesarias. Consulte la siguiente página para obtener más detalles: <a href="https://www.nuget.org/packages/groupdocs.annotation#dependencies-body-tab" target="_blank" rel="nofollow noopener noreferrer">Dependencias de GroupDocs.Annotation</a>.
:::

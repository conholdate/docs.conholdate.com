## Añadir, editar y eliminar anotaciones {#adding-editing-and-removing-annotations}

La característica principal de GroupDocs.Annotation para .NET es la anotación de documentos, que admite más de 13 tipos distintos de anotaciones para más de 35 formatos de archivo.

Puede utilizar diversos tipos de anotaciones gráficas, de texto y de marca de agua. Consulte los tipos de anotaciones disponibles en la lista siguiente.

### Anotaciones gráficas {#graphic-annotations}

*   Área: marca una zona con un rectángulo y le añade notas
*   Flecha: dibuja una flecha en el documento
*   Distancia: mide la distancia entre objetos en un documento
*   Punto: adjunta comentarios a cualquier punto del documento
*   Polilínea: dibuja formas y líneas a mano alzada
*   Redacción: rellena un rectángulo negro con una posición fija (utilícelo si desea ocultar cierto texto)
*   Campo de texto: añade un rectángulo con texto en su interior
*   Elipse: dibuja una anotación elíptica en el documento

### Anotaciones de texto {#text-annotations}

*   Resaltado: resalta y comenta el texto seleccionado
*   Sustitución: reemplaza el texto original por el texto definido por el usuario
*   Tachado: marca el texto con un estilo de tachado
*   Subrayado: marca el texto con un estilo de subrayado

### Anotaciones de marca de agua {#watermark-annotations}

*   Horizontal: añade una marca de agua de texto horizontal
*   Diagonal: añade una marca de agua de texto diagonal

## Importación de anotaciones {#import-annotations}

GroupDocs.Annotation para .NET proporciona la capacidad de trabajar con anotaciones añadidas por otros programas.

## Añadir y eliminar comentarios {#adding-and-removing-comments}

Cada tipo de anotación admite la colaboración mediante comentarios. Añada, elimine o responda a comentarios en cualquier anotación.

## Exportación del documento anotado {#export-of-annotated-document}

GroupDocs.Annotation para .NET guarda el documento anotado en el formato original para la mayoría de los tipos de archivo admitidos. Para más detalles, consulte la [lista de formatos admitidos](/net/annotation/getting-started/supported-document-formats/)

## Generación de vistas previas y miniaturas de las páginas del documento {#generation-of-document-pages-previews-thumbnails}

GroupDocs.Annotation para .NET le permite representar las páginas del documento como imágenes para sus aplicaciones de front-end de escritorio, móvil o web. Puede visualizar cualquier documento, calcular con mayor precisión las coordenadas de las anotaciones o generar una vista previa o miniaturas.

## Almacenamiento en caché de resultados {#caching-results}

De forma predeterminada, GroupDocs.Annotation almacena la caché en un disco local. 
No obstante, GroupDocs.Annotation le permite utilizar una caché personalizada implementando las interfaces correspondientes, como Amazon S3, Dropbox, Google Drive, Windows Azure, Redis u otras.

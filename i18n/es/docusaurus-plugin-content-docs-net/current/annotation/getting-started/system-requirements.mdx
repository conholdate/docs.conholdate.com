## Descripción general {#overview}

GroupDocs.Annotation para .NET no requiere la instalación de ningún software externo ni herramientas de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/annotation/getting-started/installation/).

## Sistemas operativos compatibles {#supported-operating-systems}

GroupDocs.Annotation para .NET es compatible con cualquier sistema operativo de 32 o 64 bits en el que esté instalado .NET o .NET Core, incluidos, entre otros:

### Windows {#windows}

*   Microsoft Windows 2003 y versiones posteriores
*   Microsoft Windows Vista (x64, x86)
*   Microsoft Windows XP (x64, x86)
*   Microsoft Windows 7 (x64, x86)
*   Microsoft Windows 8, 8.1 (x64, x86)
*   Microsoft Windows 10 (x64, x86)

### Linux {#linux}

*   Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac {#mac}

*   Mac OS X

## Marcos de trabajo compatibles {#supported-frameworks}

GroupDocs.Annotation para .NET es compatible con los siguientes marcos de trabajo .NET:

### .NET Core {#net-core}

*   .NET Core 3.1

### .NET Standard {#net-standard}

*   .NET Standard 2.1

### .NET Frameworks {#net-frameworks}

*   .NET Framework 2.0 (hasta GroupDocs.Annotation 22.5)
*   .NET Framework 3.5 (hasta GroupDocs.Annotation 22.5)
*   .NET Framework 4.0
*   .NET Framework 4.5.0
*   .NET Framework 4.5.1
*   .NET Framework 4.5.2
*   .NET Framework 4.6.0
*   .NET Framework 4.6.2
*   .NET Framework 4.5.0
*   .NET Framework 4.5.1
*   .NET Framework 4.6.0
*   .NET Framework 4.6.2
*   .NET Framework 4.7
*   .NET Framework 4.7.2
*   .NET Framework 4.8

## Entornos de desarrollo {#development-environments}

GroupDocs.Annotation para .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo orientado a la plataforma .NET, aunque los entornos explícitamente compatibles son los siguientes:

*   Microsoft Visual Studio 2010 y versiones posteriores
*   Microsoft Visual Studio para Mac
*   Rider de JetBrains

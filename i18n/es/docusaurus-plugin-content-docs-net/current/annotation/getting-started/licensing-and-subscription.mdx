A veces, para estudiar mejor el sistema, desea acceder al código lo antes posible. Para facilitar esto, GroupDocs.Annotation ofrece distintos planes de compra, así como una prueba gratuita y una licencia temporal de 30 días para su evaluación.

Puede encontrarlas en la sección <a href="https://purchase.conholdate.com/policies" target="_blank">«Políticas de compra y preguntas frecuentes»</a>.
:::


## Prueba gratuita o licencia temporal {#free-trial-or-temporary-license}

Puede probar GroupDocs.Annotation sin adquirir una licencia.

### Prueba gratuita {#free-trial}

La versión de evaluación es idéntica a la versión adquirida; simplemente, la versión de evaluación se convierte en una versión con licencia cuando establece la licencia. Puede configurar la licencia de varias maneras, como se describe en las siguientes secciones de este artículo.

La versión de evaluación presenta las siguientes limitaciones:

- Solo se pueden procesar las primeras 2 páginas.
- Se colocan marcas de prueba en la parte superior de cada página del documento.

### Licencia temporal {#temporary-license}

Si desea probar GroupDocs.Annotation sin las limitaciones de la versión de prueba, también puede solicitar una licencia temporal de 30 días. Para obtener más información, consulte la página <a href="https://purchase.conholdate.com/temporary-license" target="_blank">"Obtener una licencia temporal"</a>.

## Cómo configurar una licencia {#how-to-set-a-license}


:::info
Puede encontrar la información sobre precios en la página <a href="https://purchase.conholdate.com/pricing/" target="_blank">«Información sobre precios»</a>.
:::


Una vez obtenida la licencia, debe configurarla. Esta sección describe las distintas formas de configurar la licencia.

La licencia debe configurarse:

- Solo una vez por dominio de aplicación.
- Antes de utilizar cualquier otra clase de GroupDocs.Annotation.


:::info
La licencia puede establecerse varias veces por dominio de aplicación, pero recomendamos hacerlo una sola vez, ya que todas las llamadas posteriores a `SetLicense`, excepto la primera, solo desperdiciarán tiempo de procesador.
:::


### Establecer licencia desde archivo {#set-license-from-file}

El siguiente fragmento de código muestra cómo establecer una licencia desde un archivo:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>


```csharp
string licensePath = "path to the .lic file";
License license = new License();
license.SetLicense(licensePath);
```


</TabItem>


</Tabs>



### Establecer licencia desde un flujo {#set-license-from-stream}

El siguiente fragmento de código muestra cómo establecer una licencia desde un flujo:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>


```csharp
string licensePath = "path to the .lic file";
using (FileStream fileStream = File.OpenRead(licensePath))
{
    License license = new License();
    license.SetLicense(fileStream);
}
```


</TabItem>


</Tabs>



### Configurar licencia basada en uso {#set-metered-license}

También puede configurar la licencia <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a> como alternativa al archivo de licencia. Se trata de un nuevo mecanismo de licencias que se utilizará junto con el método de licencias existente. Es útil para los clientes que desean ser facturados según el uso de las funciones de la API. Para más detalles, consulte la sección <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Preguntas frecuentes sobre licencias basadas en uso</a>.

El siguiente fragmento de código muestra cómo utilizar la licencia `Metered`:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>


```csharp
string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```


</TabItem>

GroupDocs.Annotation v21.12 y versiones posteriores le permiten rotar la página del documento PDF en 90, 180 o 270 grados en sentido horario. Para ello, especifique el número de página en la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/processpages/" target="_blank" rel="nofollow noopener noreferrer">ProcessPages</a> y, a continuación, configure la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/rotation/" target="_blank" rel="nofollow noopener noreferrer">Rotation</a> en uno de los siguientes valores:

* None: no rota el documento
* on90: rota el documento 90 grados en sentido horario
* on180: rota el documento 180 grados en sentido horario
* on270: rota el documento 270 grados en sentido horario

De forma predeterminada, la propiedad se establece en `None`.

El siguiente fragmento de código muestra cómo rotar la primera página 90 grados en sentido horario:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("annotated_file.pdf"))
{
	annotator.ProcessPages = 1;
	annotator.Rotation = RotationDocument.on90;
    annotator.Save("result.pdf");
}
```

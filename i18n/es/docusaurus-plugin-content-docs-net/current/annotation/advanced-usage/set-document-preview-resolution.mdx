GroupDocs.Annotation v21.5 y versiones posteriores le permiten configurar la resolución de la vista previa del documento. De forma predeterminada, esta es de 96 puntos por pulgada. Para cambiar la resolución, configure la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/resolution" target="_blank" rel="nofollow noopener noreferrer">Resolution</a> de la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>.

El siguiente fragmento de código muestra cómo configurar la resolución de la vista previa a 144 PPI:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"result_{pageNumber}.png";
        return File.Create(pagePath);
    })
    {
        // Set resolution
        Resolution = 144
    };

    annotator.Document.GeneratePreview(previewOptions);
}
```

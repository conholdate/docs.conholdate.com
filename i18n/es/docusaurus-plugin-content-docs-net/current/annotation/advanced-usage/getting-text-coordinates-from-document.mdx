GroupDocs v21.3 y versiones posteriores le permiten obtener información no solo sobre el ancho y la altura de cualquier página, sino también sobre el número de página y el contenido de texto. Para ello, utilice la estructura <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a> llamando al método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/document/methods/getdocumentinfo" target="_blank" rel="nofollow noopener noreferrer">GetDocumentInfo()</a> de la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/document" target="_blank" rel="nofollow noopener noreferrer">Document</a>.

La estructura <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/pageinfo" target="_blank" rel="nofollow noopener noreferrer">PageInfo</a> representa cada página y contiene la lista de <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/textlineinfo" target="_blank" rel="nofollow noopener noreferrer">TextLineinfo</a>. Cada <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.models/textlineinfo" target="_blank" rel="nofollow noopener noreferrer">TextLineinfo</a> almacena los márgenes superior e izquierdo del texto, el ancho, la altura y el propio texto. De esta forma, cada página se representa como una secuencia de líneas de texto. Cada línea de texto se describe mediante sus parámetros (ancho, altura y márgenes).

El siguiente fragmento de código muestra cómo obtener datos de las estructuras descritas:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.docx"))
{
    IDocumentInfo documentInfo = annotator.Document.GetDocumentInfo();

    foreach (PageInfo page in documentInfo.PagesInfo)
    {
        //Here you can access PageInfo fields
        Console.WriteLine("Page number {0}, width: {1} and height: {2}", page.PageNumber, page.Width, page.Height);

        foreach (TextLineInfo textLine in page.TextLines)
        {
            //Here you can access TextLineInfo fields
            Console.WriteLine("\tText line. '{0}'", textLine.Text);
            Console.WriteLine("\t\tText width {0} and height {1}. Top indent: {2}, left indent: {3}", 
                textLine.Width, textLine.Height, textLine.TopIndent, textLine.LeftIndent);
        }
    }
}
```

### Formatos admitidos {#supported-formats}

GroupDocs.Annotation le permite extraer información de texto de archivos en los siguientes formatos: Word, PDF, archivos de Excel, diagramas de Visio, presentaciones de PowerPoint, HTML y correo electrónico. Puede extraer texto directamente de archivos en todos los formatos especificados, excepto HTML (.htm, .html, etc.) y correo electrónico (.eml, .msg, etc.). Para extraer texto de archivos HTML y de correo electrónico, GroupDocs.Annotation los convierte a formato .docx.

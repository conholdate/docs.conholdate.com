GroupDocs.Annotation v22.1 y versiones posteriores le permiten importar anotaciones desde archivos XML.

El siguiente fragmento de código muestra cómo importar anotaciones desde un archivo XML:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf-file")) // specify the path to the file with the annotated
{
	annotator.ImportAnnotationsFromDocument("result.XML-file"); // specify the path to the result XML file
}
```

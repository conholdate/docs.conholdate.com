Para guardar únicamente anotaciones de tipos específicos, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>. Establezca la propiedad <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions/properties/annotationtypes" target="_blank" rel="nofollow noopener noreferrer">AnnotationType</a> especificando el/los tipo(s) de anotación que desea guardar.
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> pasando la ruta o el flujo del documento de salida. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> como parámetro.

El siguiente fragmento de código muestra cómo guardar únicamente las páginas que contienen un tipo específico de anotación:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp

using (Annotator annotator = new Annotator("input.pdf"))
{
	AreaAnnotation area = new AreaAnnotation()
    {
    	Box = new Rectangle(100, 100, 100, 100),
        BackgroundColor = 65535,
        PageNumber = 1
    };
    EllipseAnnotation ellipse = new EllipseAnnotation()
    {
        Box = new Rectangle(100, 100, 100, 100),
        BackgroundColor = 123456,
        PageNumber = 1
    };
    annotator.Add(new List<AnnotationBase>() { area, ellipse });
	
	//Result file will contains only ellipse annotations.
    annotator.Save("result.pdf" new SaveOptions { AnnotationTypes = AnnotationType.Ellipse});
}
```

</TabItem>


</Tabs>


Si necesita guardar anotaciones de varios tipos, utilice el operador **OR** ("|").

El siguiente fragmento de código muestra cómo guardar páginas con tipos específicos de anotaciones:

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	...
    annotator.Save("result.pdf" new SaveOptions { AnnotationTypes = AnnotationType.Ellipse|AnnotationType.Watermark});
}
```

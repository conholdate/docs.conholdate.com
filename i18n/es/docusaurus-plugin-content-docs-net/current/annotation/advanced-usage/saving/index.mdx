La clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> proporciona las siguientes propiedades para personalizar el proceso de guardado:
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/annotationtypes" target="_blank" rel="nofollow noopener noreferrer">AnnotationTypes</a> define los tipos de anotaciones que se guardarán en el documento de salida;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/firstpage" target="_blank" rel="nofollow noopener noreferrer">FirstPage</a> define el número de la primera página para guardar un rango de páginas específico;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/lastpage" target="_blank" rel="nofollow noopener noreferrer">LastPage</a> define el número de la última página para guardar un rango de páginas específico;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/onlyannotatedpages" target="_blank" rel="nofollow noopener noreferrer">OnlyAnnotatedPages</a> indica si se deben guardar únicamente las páginas anotadas o no.

Para exportar el rango específico de páginas, siga estos pasos:

1.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta o el flujo del documento de entrada.
2.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>. Especifique los parámetros <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/firstpage/" target="_blank" rel="nofollow noopener noreferrer">FirstPage</a> y <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/lastpage/" target="_blank" rel="nofollow noopener noreferrer">LastPage</a>.
3.   Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Save</a> con la ruta o el flujo del documento de salida. Especifique la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/saveoptions" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> como parámetro.

El siguiente código demuestra cómo guardar un rango de páginas del documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
// for this example input document ("input.pdf") must have at least 4 pages
using (Annotator annotator = new Annotator("input.pdf"))
{
	//Result file will be contain only 3 pages (2, 3 and 4 page)
	annotator.Save("result.pdf", new SaveOptions { FirstPage = 2, LastPage = 4 });
}
```

<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite generar vistas previas de las páginas de un documento. Para ello, invoque el método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Document</a>. 

Utilice la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> para gestionar el proceso de generación: especifique los números de página deseados, el formato de imagen, etc.

Para generar una vista previa del documento, siga estos pasos:
1.  Cree una instancia de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta del documento de origen como parámetro. La propiedad <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Document</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a> proporciona acceso al documento de origen e implementa el método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a>.
3.   Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>. Siga estos pasos:
    a.   for each page, delegate stream creation (see the `CreatePageStream` event handler); 
    b.   specify the image preview format - PNG / JPG / BMP,
    c.   specify page numbers to process;
    d.   set the custom size of preview images (if needed).  

:::info
La secuencia creada por el delegado <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> se libera automáticamente tras la generación de la imagen de vista previa. Para implementar la liberación personalizada de la secuencia de vista previa de imágenes, debe especificar un argumento adicional, <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a>, para limpiar los recursos.
:::
       
4. Llame al método <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/document/methods/generatepreview" target="_blank" rel="nofollow noopener noreferrer">GeneratePreview</a> de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator/properties/document" target="_blank" rel="nofollow noopener noreferrer">Annotator.Document</a>. Especifique <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a>.

    
Las propiedades principales de la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/previewoptions" target="_blank" rel="nofollow noopener noreferrer">PreviewOptions</a> son las siguientes:
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/createpagestream" target="_blank" rel="nofollow noopener noreferrer">CreatePageStream</a> es un delegado que define el método para crear el flujo de vista previa de la página de salida.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/releasepagestream" target="_blank" rel="nofollow noopener noreferrer">ReleasePageStream</a> es un delegado que define el método para eliminar el flujo de vista previa de la página de salida. Utilícelo para un control avanzado del manejo de recursos.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/width" target="_blank" rel="nofollow noopener noreferrer">Width</a> especifica el ancho de la imagen de vista previa.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/height" target="_blank" rel="nofollow noopener noreferrer">Height</a> especifica la altura de la imagen de vista previa.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/pagenumbers" target="_blank" rel="nofollow noopener noreferrer">PageNumbers</a> – Números de página que se mostrarán en la vista previa;
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/previewformat" target="_blank" rel="nofollow noopener noreferrer">PreviewFormat</a> obtiene o establece el formato de la imagen de vista previa. Se debe utilizar el formato BMP para obtener la mejor calidad de imagen. Utilice el formato JPG si existen requisitos estrictos sobre el tamaño de la imagen, aunque con una calidad inferior a la del BMP. De forma predeterminada, GroupDocs.Annotation utiliza el formato PNG, que representa un equilibrio óptimo entre calidad y tamaño de la imagen.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/rendercomments" target="_blank" rel="nofollow noopener noreferrer">RenderComments</a> es una opción para mostrar u ocultar comentarios. De forma predeterminada, su valor es `true`. Establézcalo en `false` si no desea mostrar los comentarios. Esta propiedad solo afecta a los documentos de procesamiento de texto (WordProcessing). El valor `RenderComments` afecta a los comentarios de cualquier tipo de documento.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/renderannotations" target="_blank" rel="nofollow noopener noreferrer">RenderAnnotations</a> es una opción para mostrar u ocultar anotaciones. De forma predeterminada, su valor es `true`. Establézcalo en `false` si no desea mostrar las anotaciones.
*   <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/worksheetcolumns" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumns</a> es una lista de objetos <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/worksheetcolumnsrange" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumnsRange</a> que indica qué columnas generar en la hoja de cálculo especificada.

El siguiente fragmento de código demuestra cómo generar vistas previas de documentos:

## Obtener vistas previas de las páginas del documento {#get-document-page-previews}


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
    annotator.Document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>


## Establecer un tamaño específico para las imágenes de vista previa {#set-specific-size-for-preview-images}

Puede establecer un tamaño específico para las imágenes de vista previa. Por ejemplo, puede crear miniaturas de tamaño pequeño y vistas previas a tamaño completo.

El siguiente fragmento de código muestra cómo establecer un tamaño específico para las imágenes de vista previa:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
	previewOptions.Height = 100;
    previewOptions.Width = 80;
    annotator.Document.GeneratePreview(previewOptions);   
}

```

</TabItem>


</Tabs>


## Obtención de vistas previas de páginas con limpieza manual de recursos {#get-page-previews-with-manual-resource-cleaning}

De forma predeterminada, GroupDocs.Annotation elimina el flujo de imagen inmediatamente después de crear y representar la página del documento. Si es necesario, puede implementar un método personalizado para realizar esta operación.


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
// Method should match with ReleasePageStream delegate signature
private void UserReleaseStreamMethod(int pageNumber, Stream stream)
{
	Console.WriteLine($"Releasing memory for page: {pageNumber}");
    stream.Close();
}
 
using (Annotator annotator = new Annotator("input.pdf"))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });
    previewOptions.PreviewFormat = PreviewFormats.PNG;
    previewOptions.PageNumbers = new int[] { 1, 2, 3, 4 };
	previewOptions.Height = 100;
    previewOptions.Width = 80;
 
    // here we set delegate target method
    previewOptions.ReleasePageStream = UserReleaseStreamMethod;
    annotator.Document.GeneratePreview(previewOptions);   
}
```

</TabItem>


</Tabs>


## Mostrar y ocultar respuestas en documentos de WordsProcessing {#show-and-hide-replies-for-wordsprocessing-documents}

Utilice la propiedad booleana <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/rendercomments/" target="_blank" rel="nofollow noopener noreferrer">RenderComments</a> para mostrar los comentarios al representar la vista previa de la imagen.


:::info
Esta función solo está disponible para documentos de procesamiento de texto.
:::


El valor predeterminado de la propiedad es `true`. Para ocultar los comentarios, establezca este valor en `false`. Esta propiedad se aplica a todos los comentarios.

El siguiente fragmento de código muestra cómo representar una vista previa de imagen sin comentarios:


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
Annotator annotator = new Annotator(File.OpenRead(MakeStoragePath(inputPath)));
           PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
           {
               var pagePath = MakeStoragePath(inputPath.Replace("input.doc", $"result{pageNumber}.png"));
               return File.Create(pagePath);
           });
previewOptions.PreviewFormat = PreviewFormats.PNG;
previewOptions.RenderComments = false;
annotator.Document.GeneratePreview(previewOptions);
```

</TabItem>


</Tabs>


## Generar vista previa de celdas con columnas especificadas {#generate-cells-preview-with-specified-columns}

GroupDocs.Annotation v20.11 y versiones posteriores le permiten especificar las columnas que desea generar en la hoja seleccionada. Para ello, utilice la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/previewoptions/properties/worksheetcolumns" target="_blank" rel="nofollow noopener noreferrer">WorksheetColumns</a>.


:::info
Esta función solo está disponible para documentos de procesamiento de celdas.
:::


El siguiente fragmento de código muestra cómo establecer la lista de columnas que se van a representar:


<Tabs groupId="example5">


<TabItem value="c" label="C#" default>

```csharp
PreviewOptions previewOptions =
    new PreviewOptions(pageNumber => new FileStream($"preview_pages/page{pageNumber}.png", FileMode.Create),
        (number, stream) => stream.Dispose());
previewOptions.WorksheetColumns.Add(new WorksheetColumnsRange("Sheet1", 2, 3));
previewOptions.WorksheetColumns.Add(new WorksheetColumnsRange("Sheet1", 1, 1));

using (Annotator annotator = new Annotator("input.xlsx"))
{
    annotator.Document.GeneratePreview(previewOptions);
}
```

</TabItem>


</Tabs>

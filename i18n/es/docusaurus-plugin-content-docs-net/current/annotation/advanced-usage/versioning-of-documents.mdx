Cuando guarda un archivo utilizando el método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/save/index" target="_blank" rel="nofollow noopener noreferrer">Annotator.Save()</a>, GroupDocs.Annotations crea una versión del archivo anotado. La lista de versiones conserva las anotaciones que agrega, elimina y modifica. Puede cambiar entre las distintas modificaciones realizadas con GroupDocs.Annotation. Si es necesario, puede establecer nombres personalizados para las versiones.

De forma predeterminada, GroupDocs.Annotations nombra las versiones mediante un GUID. Si es necesario, puede especificar un nombre personalizado para la versión.

### Agregar versión con nombre personalizado {#add-version-with-custom-name}

Puede especificar un nombre personalizado para la versión.
  
El siguiente fragmento de código muestra cómo guardar una versión con nombre personalizado:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf"))
{
	annotator.Update(new AreaAnnotation{ Box = new Rectangle(100, 100, 100, 100) });
	annotator.Save("result.pdf", new SaveOptions { Version = "CUSTOM_VERSION" });
}
```

</TabItem>


</Tabs>



:::info
El <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/saveoptions/properties/version" target="_blank" rel="nofollow noopener noreferrer">Version</a> la propiedad es un objeto.
:::


## Obtener la lista de claves de versión de un archivo {#get-the-list-of-version-keys-of-a-file}

Para obtener la lista de claves de versión, invoque el método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">GetVersionsList</a> de la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>.

El siguiente fragmento de código muestra cómo obtener la lista de claves de versión:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.pdf")) { 
      List<object> versionKeys = annotator.GetVersionsList();
}
```

</TabItem>


</Tabs>



:::info
El <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">Annotator.GetVersionsList()</a> el método devuelve una lista de objetos. Si es necesario, puedes convertirlos al tipo adecuado.
:::


## Obtener la lista de anotaciones mediante la clave de versión {#get-the-list-of-annotations-using-version-key}

Para obtener la lista de anotaciones en una versión específica, invoque el método <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">Annotator.GetVersion()</a> de la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>.

El siguiente fragmento de código muestra cómo obtener la lista de anotaciones en una versión específica:


<Tabs groupId="example3">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("result.pdf"))
{
    List<AnnotationBase> annotations = annotator.GetVersion("CUSTOM_VERSION");
}
```

</TabItem>


</Tabs>



:::info
El <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation/annotator/methods/getversionslist" target="_blank" rel="nofollow noopener noreferrer">GetVersion</a> el método devuelve una lista de objetos. Si es necesario, puedes convertirlos al tipo adecuado.
:::


## Cargar una versión específica de un archivo {#load-a-specific-file-version}

Para cargar una versión específica de un archivo, especifique la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions/properties/version" target="_blank" rel="nofollow noopener noreferrer">LoadOptions.Version</a>.

El siguiente fragmento de código muestra cómo cargar una versión utilizando la propiedad de versión:


<Tabs groupId="example4">


<TabItem value="c" label="C#" default>

```csharp
 using (Annotator annotator = new Annotator($"result.{ext}", new LoadOptions { Version = "CUSTOM_VERSION" }))
{
	annotator.Save("result_loaded.pdf");
}
```

</TabItem>


</Tabs>

GroupDocs.Annotation v21.5 y versiones posteriores le permiten generar una vista previa de documentos utilizando fuentes personalizadas. Para ello, especifique la propiedad <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions/properties/fontdirectories" target="_blank" rel="nofollow noopener noreferrer">FontDirectories</a> de la clase <a href="https://reference.groupdocs.com/annotation/net/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>.

El siguiente fragmento de código muestra cómo utilizar fuentes personalizadas al generar la vista previa:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator(fs, new LoadOptions { FontDirectories = new List<string> { $"D:/fonts" } }))
{
    PreviewOptions previewOptions = new PreviewOptions(pageNumber =>
    {
        var pagePath = $"D:/result_{pageNumber}.png";
        return File.Create(pagePath);
    });

    annotator.Document.GeneratePreview(previewOptions);
}
```

</TabItem>

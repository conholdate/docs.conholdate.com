<a href="https://products.groupdocs.com/annotation/net" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Annotation</a> le permite anotar documentos protegidos con contraseña.

Para cargar un archivo protegido con contraseña, siga estos pasos:

1. Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation/annotator" target="_blank" rel="nofollow noopener noreferrer">Annotator</a>. Especifique la ruta del documento o el flujo.
2. Instancie la clase <a href="https://reference.groupdocs.com/net/annotation/groupdocs.annotation.options/loadoptions" target="_blank" rel="nofollow noopener noreferrer">LoadOptions</a>. Especifique la contraseña del documento de origen como parámetro.

El siguiente fragmento de código muestra cómo cargar un archivo protegido con contraseña:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using (Annotator annotator = new Annotator("input.pdf", new LoadOptions() { Password = "1234" }))
{
 	AreaAnnotation area = new AreaAnnotation()
    {
       	Box = new Rectangle(100, 100, 100, 100),
       	BackgroundColor = 65535,
    };
    annotator.Add(area);
    annotator.Save("result.pdf");
}
```

## Vista general {#overview}

GroupDocs.Assembly para .NET admite funciones agregadas basadas en LINQ que permiten calcular sumas, conteos, promedios y otros valores agregados directamente en las plantillas. Estas funciones operan sobre colecciones y le permiten mostrar totales, resúmenes e información estadística en sus documentos.

Las principales funciones agregadas son:
- `Sum()` – calcula la suma de valores numéricos
- `Count()` – cuenta el número de elementos
- `Average()` – calcula el promedio de valores numéricos
- `Min()` – encuentra el valor mínimo
- `Max()` – encuentra el valor máximo

A continuación se indican los pasos para utilizar funciones agregadas:

* Crear una plantilla con expresiones agregadas
* Utilizar métodos agregados de LINQ sobre colecciones
* Hacer referencia a los resultados agregados en su plantilla
* Generar el documento con sus datos


:::info
Las funciones de agregación utilizan la sintaxis de LINQ y funcionan con cualquier tipo de colección, incluidas listas, matrices, DataTables y otras colecciones enumerables.
:::


## Calcular Suma {#calculate-sum}

Calcula la suma de los valores en una colección:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public class OrderItem
{
    public string ProductName { get; set; }
    public decimal Price { get; set; }
    public int Quantity { get; set; }
}

public static void CalculateSum()
{
    List<OrderItem> items = new List<OrderItem>
    {
        new OrderItem { ProductName = "Laptop", Price = 999.99m, Quantity = 1 },
        new OrderItem { ProductName = "Mouse", Price = 29.99m, Quantity = 2 },
        new OrderItem { ProductName = "Keyboard", Price = 79.99m, Quantity = 1 }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("AggregatesTemplate.docx", "AggregatesOutput.docx", 
        new DataSourceInfo(items, "items"));
    
    Console.WriteLine("Sum calculated successfully.");
}
```

## Ejemplo de plantilla para Sum {#template-example-for-sum}

En su plantilla (AggregatesTemplate.docx):

```
Items:
<<foreach [in items]>>
<<[ProductName]>> - <<[Price]:"C">> x <<[Quantity]>>
<</foreach>>

Total: <<[items.Sum(i => i.Price * i.Quantity)]:"C">>
```

## Calcular promedio {#calculate-average}

Calcula el promedio de valores numéricos:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public class Sale
{
    public decimal Amount { get; set; }
}

public static void CalculateAverage()
{
    List<Sale> sales = new List<Sale>
    {
        new Sale { Amount = 1000.00m },
        new Sale { Amount = 1500.00m },
        new Sale { Amount = 800.00m },
        new Sale { Amount = 1200.00m }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("AggregatesTemplate.docx", "AggregatesOutput.docx", 
        new DataSourceInfo(sales, "sales"));
    
    Console.WriteLine("Average calculated successfully.");
}
```

Plantilla:

```
Sales:
<<foreach [in sales]>>
<<[Amount]:"C">>
<</foreach>>

Average Sale: <<[sales.Average(s => s.Amount)]:"C">>
```

## Agregados en informes de maestro-detalle {#aggregates-in-master-detail-reports}

Calcule agregados para registros detallados dentro de registros maestros:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public class Order
{
    public int OrderId { get; set; }
    public List<OrderItem> Items { get; set; }
}

public static void AggregatesInMasterDetail()
{
    List<Order> orders = new List<Order>
    {
        new Order
        {
            OrderId = 1001,
            Items = new List<OrderItem>
            {
                new OrderItem { ProductName = "Laptop", Price = 999.99m, Quantity = 1 },
                new OrderItem { ProductName = "Mouse", Price = 29.99m, Quantity = 2 }
            }
        }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("AggregatesTemplate.docx", "AggregatesOutput.docx", 
        new DataSourceInfo(orders, "orders"));
    
    Console.WriteLine("Master-detail aggregates calculated successfully.");
}
```

Plantilla:

```
<<foreach [in orders]>>
Order #<<[OrderId]>>
Items:
<<foreach [in Items]>>
  <<[ProductName]>> - <<[Price]:"C">> x <<[Quantity]>>
<</foreach>>
Order Total: <<[Items.Sum(i => i.Price * i.Quantity)]:"C">>
<</foreach>>
```


:::warning
Las funciones de agregación requieren colecciones. Asegúrese de que su origen de datos sea de un tipo colección (List, Array, DataTable, etc.) al utilizar funciones de agregación.
:::

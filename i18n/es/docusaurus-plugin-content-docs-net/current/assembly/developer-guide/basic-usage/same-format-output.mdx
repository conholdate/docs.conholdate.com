## Vista general {#overview}

De forma predeterminada, GroupDocs.Assembly para .NET guarda los documentos ensamblados en el mismo formato que la plantilla. Esto significa que una plantilla DOCX genera una salida en formato DOCX, una plantilla XLSX genera una salida en formato XLSX, y así sucesivamente. El formato de salida se determina según la extensión del archivo de la ruta de salida.

La clase principal implicada es:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – ensambla documentos y determina el formato de salida

A continuación se indican los pasos para generar la salida en el mismo formato:

* Crear un documento plantilla en el formato deseado (DOCX, XLSX, PPTX, etc.)
* Especificar una ruta de salida con la misma extensión de archivo que la plantilla
* Ensamblar el documento mediante DocumentAssembler
* La salida se generará automáticamente en el mismo formato que la plantilla


:::info
El formato de salida se determina automáticamente según la extensión del archivo de la ruta de salida. No se requiere ninguna configuración adicional para conservar el formato de la plantilla.
:::


## Generar DOCX a partir de una plantilla DOCX {#generate-docx-from-docx-template}

Generar un documento de Word a partir de una plantilla de Word:

```csharp
using GroupDocs.Assembly;

public static void GenerateDocxFromDocx()
{
    // Template and output are both DOCX
    string templatePath = "InvoiceTemplate.docx";
    string outputPath = "Invoice.docx";
    
    var invoiceData = new { 
        CustomerName = "ABC Corp", 
        Amount = 1500.00m,
        Date = DateTime.Now
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument(templatePath, outputPath, 
        new DataSourceInfo(invoiceData, "invoice"));
    
    Console.WriteLine("DOCX document generated from DOCX template.");
}
```

## Uso de flujos con el mismo formato {#using-streams-with-same-format}

Al utilizar flujos, el formato sigue preservándose según el formato de la plantilla:

```csharp
using GroupDocs.Assembly;
using System.IO;

public static void GenerateSameFormatFromStream()
{
    // Load DOCX template from stream
    byte[] templateBytes = File.ReadAllBytes("Template.docx");
    
    using (MemoryStream templateStream = new MemoryStream(templateBytes))
    using (FileStream outputStream = new FileStream("Output.docx", FileMode.Create))
    {
        var data = new { Name = "Test", Value = 100 };
        
        DocumentAssembler assembler = new DocumentAssembler();
        assembler.AssembleDocument(templateStream, outputStream, 
            new DataSourceInfo(data, "item"));
        
        Console.WriteLine("Document generated from stream in same format.");
    }
}
```

## Compatibilidad de formatos {#format-compatibility}

Los siguientes formatos admiten salida en el mismo formato:

- **Procesamiento de texto**: DOCX, DOC, RTF, ODT, OTT
- **Hoja de cálculo**: XLSX, XLS, XLSM, ODS
- **Presentación**: PPTX, PPT, PPTM, ODP
- **Correo electrónico**: MSG, EML, EMLX
- **Otros**: HTML, TXT, XML


:::warning
Algunos formatos más antiguos (como DOC, XLS y PPT) pueden presentar limitaciones en comparación con sus versiones más recientes (DOCX, XLSX y PPTX). Para obtener los mejores resultados, utilice los formatos más modernos de Office Open XML.
:::

## Información general {#overview}

GroupDocs.Assembly para .NET le permite generar documentos de salida en un formato distinto al de la plantilla. Por ejemplo, puede crear una plantilla en formato DOCX pero generar una salida en PDF, o bien crear una plantilla en formato XLSX pero generar una salida en HTML. El formato de salida se determina según la extensión del archivo de la ruta de salida.

La clase principal implicada es:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – ensambla documentos y los convierte al formato de salida

A continuación se indican los pasos para generar una salida en un formato diferente:

* Crear una plantilla en un formato determinado (por ejemplo, DOCX)
* Especificar una ruta de salida con una extensión de archivo distinta (por ejemplo, .pdf, .html)
* Ensamblar el documento mediante DocumentAssembler
* La salida se convertirá automáticamente al formato especificado


:::info
La conversión de formato es automática según la extensión del archivo de salida. Las conversiones admitidas dependen del formato de la plantilla: las plantillas de Word pueden convertirse a PDF, HTML y otros formatos, mientras que las plantillas de hojas de cálculo tienen opciones de conversión más limitadas.
:::


## Convertir plantilla DOCX a PDF {#convert-docx-template-to-pdf}

Generar un PDF a partir de una plantilla de Word:

```csharp
using GroupDocs.Assembly;

public static void ConvertDocxToPdf()
{
    // DOCX template, PDF output
    string templatePath = "InvoiceTemplate.docx";
    string outputPath = "Invoice.pdf";
    
    var invoiceData = new { 
        CustomerName = "ABC Corp", 
        Amount = 1500.00m,
        Date = DateTime.Now
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument(templatePath, outputPath, 
        new DataSourceInfo(invoiceData, "invoice"));
    
    Console.WriteLine("PDF generated from DOCX template.");
}
```

## Conversiones de formato admitidas {#supported-format-conversions}

Las siguientes conversiones son compatibles:

**Desde procesadores de texto (DOCX, DOC, RTF, etc.):**
- PDF, XPS, HTML, MHTML, EPUB, TIFF, SVG, PS, PCL, Markdown, TXT, XAML

**Desde hojas de cálculo (XLSX, XLS, etc.):**
- PDF, XPS, HTML, MHTML, TIFF

**Desde presentaciones (PPTX, PPT, etc.):**
- PDF, XPS, TIFF

**Desde correos electrónicos (MSG, EML, etc.):**
- PDF, XPS, HTML, MHTML, Markdown, TXT, XAML


:::warning
No todas las combinaciones de formatos son compatibles. Las plantillas de procesamiento de texto ofrecen la mayor cantidad de opciones de conversión, mientras que las plantillas de hojas de cálculo y presentaciones tienen formatos de salida más limitados.
:::

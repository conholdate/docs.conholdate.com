## Visión general {#overview}

GroupDocs.Assembly para .NET le permite insertar hipervínculos dinámicamente en documentos mediante etiquetas de enlace. Los hipervínculos pueden apuntar a URL externos, marcadores dentro del documento o celdas/ diapositivas específicas, según el tipo de documento.

Las clases principales involucradas son:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – ensambla documentos
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/datasourceinfo/" target="_blank" rel="nofollow noopener noreferrer">DataSourceInfo</a> – envuelve las fuentes de datos

A continuación se presentan los pasos para insertar hipervínculos dinámicamente:

* Crear un documento plantilla con etiquetas de enlace
* Utilizar la sintaxis `<<link [uri_expression][display_text_expression]>>`
* Proporcionar URI y texto de visualización opcional desde su fuente de datos
* Ensamblar el documento


:::info
Las etiquetas de enlace se reemplazan por hipervínculos interactivos durante la compilación del documento. La expresión URI es obligatoria, mientras que el texto de visualización es opcional.
:::


## Insertar hipervínculo con URL y texto {#insert-hyperlink-with-url-and-text}

Insertar un hipervínculo con URL y texto de visualización:

```csharp
using GroupDocs.Assembly;

public class Website
{
    public string Name { get; set; }
    public string Url { get; set; }
}

public static void InsertHyperlink()
{
    var website = new Website
    {
        Name = "Visit our website",
        Url = "https://www.example.com"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("HyperlinkTemplate.docx", "HyperlinkOutput.docx", 
        new DataSourceInfo(website, "website"));
    
    Console.WriteLine("Hyperlink inserted successfully.");
}
```

## Estructura de plantilla para hipervínculos {#template-structure-for-hyperlinks}

En su plantilla (HyperlinkTemplate.docx), utilice etiquetas de enlace:

```
Please <<link [website.Url][website.Name]>> for more information.
```

Después del ensamblaje:

```
Please Visit our website for more information.
```

(El texto "Visite nuestro sitio web" será un hipervínculo clickeable.)

## Hipervínculo con solo URL {#hyperlink-with-url-only}

Si omite el texto de visualización, se utilizará la URL como texto de visualización:

```csharp
using GroupDocs.Assembly;

public static void InsertHyperlinkUrlOnly()
{
    var website = new Website
    {
        Url = "https://www.example.com"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("HyperlinkTemplate.docx", "HyperlinkOutput.docx", 
        new DataSourceInfo(website, "website"));
    
    Console.WriteLine("Hyperlink with URL only inserted successfully.");
}
```

Plantilla:

```
Visit <<link [website.Url]>> for more information.
```

## Insertar varios hipervínculos desde una colección {#insert-multiple-hyperlinks-from-collection}

Insertar hipervínculos para cada elemento de una colección:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void InsertHyperlinksFromCollection()
{
    List<Website> websites = new List<Website>
    {
        new Website { Name = "Home", Url = "https://www.example.com" },
        new Website { Name = "About", Url = "https://www.example.com/about" },
        new Website { Name = "Contact", Url = "https://www.example.com/contact" }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("HyperlinksTemplate.docx", "HyperlinksOutput.docx", 
        new DataSourceInfo(websites, "websites"));
    
    Console.WriteLine("Hyperlinks inserted from collection successfully.");
}
```

Plantilla con foreach:

```
Links:
<<foreach [in websites]>>
- <<link [Url][Name]>>
<</foreach>>
```

## Enlace a marcador (documentos de Word) {#hyperlink-to-bookmark-word-documents}

Enlaces a marcadores dentro del mismo documento:

```csharp
using GroupDocs.Assembly;

public class Section
{
    public string Title { get; set; }
    public string BookmarkName { get; set; }
}

public static void InsertBookmarkLink()
{
    var section = new Section
    {
        Title = "Go to Introduction",
        BookmarkName = "Introduction"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("BookmarkLinkTemplate.docx", "BookmarkLinkOutput.docx", 
        new DataSourceInfo(section, "section"));
    
    Console.WriteLine("Bookmark hyperlink inserted successfully.");
}
```

Plantilla:

```
<<link [section.BookmarkName][section.Title]>>
```

## Vínculo a celdas (documentos de hojas de cálculo) {#hyperlink-to-cell-spreadsheet-documents}

Vínculos a celdas en documentos de hojas de cálculo:

```csharp
using GroupDocs.Assembly;

public static void InsertCellLink()
{
    var data = new { CellReference = "A1", DisplayText = "Go to Home" };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("CellLinkTemplate.xlsx", "CellLinkOutput.xlsx", 
        new DataSourceInfo(data, "data"));
    
    Console.WriteLine("Cell hyperlink inserted successfully.");
}
```

Plantilla:

```
<<link ["A1"]["Go to Home"]>>
```

## Uso de objetos Uri {#using-uri-objects}

Puede utilizar objetos Uri directamente:

```csharp
using GroupDocs.Assembly;
using System;

public class Website
{
    public Uri Url { get; set; }
    public string Name { get; set; }
}

public static void InsertHyperlinkWithUri()
{
    var website = new Website
    {
        Url = new Uri("https://www.example.com"),
        Name = "Visit our website"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("HyperlinkTemplate.docx", "HyperlinkOutput.docx", 
        new DataSourceInfo(website, "website"));
    
    Console.WriteLine("Hyperlink with Uri object inserted successfully.");
}
```


:::warning
Las etiquetas `<link>` no pueden utilizarse dentro de los gráficos. Para incluir hipervínculos en gráficos, utilice enfoques alternativos o coloque los enlaces fuera de los elementos del gráfico.
:::

## Vista general {#overview}

Los informes maestro-detalle muestran datos jerárquicos en los que cada registro maestro (padre) tiene registros de detalle asociados (hijos). GroupDocs.Assembly para .NET admite informes maestro-detalle mediante bandas de datos **foreach** anidadas, lo que permite mostrar registros padres junto con sus registros hijos relacionados.

Las clases principales involucradas son:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – ensambla documentos
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/datasourceinfo/" target="_blank" rel="nofollow noopener noreferrer">DataSourceInfo</a> – envuelve las fuentes de datos

A continuación se presentan los pasos para generar informes maestro-detalle:

* Definir estructuras de datos con relaciones padre-hijo
* Crear una plantilla con bandas de datos **foreach** anidadas
* El **foreach** externo itera sobre los registros maestros
* El **foreach** interno itera sobre los registros de detalle para cada maestro
* Ensamblar el documento con los datos jerárquicos


:::info
Los bandos de datos anidados con `foreach` permiten crear informes jerárquicos complejos. El bando externo procesa los registros maestros, mientras que los bandos internos procesan los registros de detalle relacionados.
:::


## Definir estructura de datos Maestro-Detalle {#define-master-detail-data-structure}

Comience definiendo clases con relaciones padre-hijo:

```csharp
public class Order
{
    public int OrderId { get; set; }
    public DateTime OrderDate { get; set; }
    public string CustomerName { get; set; }
    public List<OrderItem> Items { get; set; }
}

public class OrderItem
{
    public string ProductName { get; set; }
    public int Quantity { get; set; }
    public decimal Price { get; set; }
}
```

## Generar informe maestro-detalle {#generate-master-detail-report}

Cree un informe maestro-detalle a partir de datos jerárquicos:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void GenerateMasterDetailReport()
{
    // Create sample data with master-detail relationship
    List<Order> orders = new List<Order>
    {
        new Order
        {
            OrderId = 1001,
            OrderDate = new DateTime(2024, 1, 15),
            CustomerName = "John Doe",
            Items = new List<OrderItem>
            {
                new OrderItem { ProductName = "Laptop", Quantity = 1, Price = 999.99m },
                new OrderItem { ProductName = "Mouse", Quantity = 2, Price = 29.99m }
            }
        },
        new Order
        {
            OrderId = 1002,
            OrderDate = new DateTime(2024, 1, 16),
            CustomerName = "Jane Smith",
            Items = new List<OrderItem>
            {
                new OrderItem { ProductName = "Keyboard", Quantity = 1, Price = 79.99m }
            }
        }
    };
    
    // Assemble document
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("MasterDetailTemplate.docx", "MasterDetailOutput.docx", 
        new DataSourceInfo(orders, "orders"));
    
    Console.WriteLine("Master-detail report generated successfully.");
}
```

## Estructura de plantilla para Maestro-Detalle {#template-structure-for-master-detail}

En su plantilla (MasterDetailTemplate.docx), utilice bandas de datos foreach anidadas:

```
<<foreach [in orders]>>
Order #<<[OrderId]>>
Date: <<[OrderDate]:"yyyy-MM-dd">>
Customer: <<[CustomerName]>>

Items:
<<foreach [in Items]>>
  - <<[ProductName]>> (Qty: <<[Quantity]>>, Price: <<[Price]:"C">>)
<</foreach>>

Total: <<[Items.Sum(i => i.Price * i.Quantity)]:"C">>

<</foreach>>
```

Después del ensamblaje, obtendrás:

```
Order #1001
Date: 2024-01-15
Customer: John Doe

Items:
  - Laptop (Qty: 1, Price: $999.99)
  - Mouse (Qty: 2, Price: $29.99)

Total: $1,059.97

Order #1002
Date: 2024-01-16
Customer: Jane Smith

Items:
  - Keyboard (Qty: 1, Price: $79.99)

Total: $79.99
```

## Master-Detail en tablas {#master-detail-in-tables}

También puede crear informes maestro-detalle en formato de tabla:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void GenerateMasterDetailTable()
{
    List<Order> orders = new List<Order>
    {
        new Order
        {
            OrderId = 1001,
            CustomerName = "John Doe",
            Items = new List<OrderItem>
            {
                new OrderItem { ProductName = "Laptop", Quantity = 1, Price = 999.99m },
                new OrderItem { ProductName = "Mouse", Quantity = 2, Price = 29.99m }
            }
        }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("MasterDetailTableTemplate.docx", "MasterDetailTableOutput.docx", 
        new DataSourceInfo(orders, "orders"));
    
    Console.WriteLine("Master-detail table generated successfully.");
}
```

Estructura de la tabla de plantilla:

| ID de pedido | Cliente | Producto | Cantidad | Precio |
| ---------- | ---------- | --------- | ---------- | ------- |
| `<<foreach [in orders]>>` |  |  |  |  |
| `<<[OrderId]>>` | `<<[CustomerName]>>` | `<<foreach [in Items]>>` |  |  |
|  |  | `<<[ProductName]>>` | `<<[Quantity]>>` | `<<[Price]:"C">>` |
|  |  | `<<foreach>>` |  |  |
| `<<foreach>>` |  |  |  |  |

## Uso de agregados en maestro-detalle {#using-aggregates-in-master-detail}

Calcular totales y agregados para cada registro maestro:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void GenerateMasterDetailWithAggregates()
{
    List<Order> orders = new List<Order>
    {
        new Order
        {
            OrderId = 1001,
            CustomerName = "John Doe",
            Items = new List<OrderItem>
            {
                new OrderItem { ProductName = "Laptop", Quantity = 1, Price = 999.99m },
                new OrderItem { ProductName = "Mouse", Quantity = 2, Price = 29.99m }
            }
        }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("MasterDetailTemplate.docx", "MasterDetailOutput.docx", 
        new DataSourceInfo(orders, "orders"));
    
    Console.WriteLine("Master-detail report with aggregates generated successfully.");
}
```

Plantilla con agregados:

```
<<foreach [in orders]>>
Order #<<[OrderId]>> - <<[CustomerName]>>

Items:
<<foreach [in Items]>>
  <<[ProductName]>> - <<[Quantity]>> x <<[Price]:"C">> = <<[Quantity * Price]:"C">>
<</foreach>>

Subtotal: <<[Items.Sum(i => i.Price * i.Quantity)]:"C">>
Item Count: <<[Items.Count()]>>
<</foreach>>
```


:::warning
Al utilizar bandas de datos anidadas con `foreach`, asegúrese de cerrar correctamente las etiquetas. Cada apertura `<<foreach>>` debe tener un cierre correspondiente `<<foreach>>`.
:::

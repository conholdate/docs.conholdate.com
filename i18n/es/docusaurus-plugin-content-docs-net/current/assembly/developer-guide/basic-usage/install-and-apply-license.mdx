## Vista general {#overview}

Antes de poder comenzar a generar documentos con GroupDocs.Assembly para .NET, debe instalar la biblioteca y aplicar una licencia. Esta guía le muestra cómo instalar el paquete mediante NuGet y configurar la licencia para eliminar las limitaciones de la versión de evaluación.

Las clases principales involucradas son:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/license/" target="_blank" rel="nofollow noopener noreferrer">License</a> – para aplicar licencias
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – para ensamblar documentos

A continuación se presentan los pasos para comenzar:

* Instalar el paquete GroupDocs.Assembly mediante el Administrador de paquetes NuGet o la Consola del Administrador de paquetes
* Aplicar una licencia desde un archivo o flujo utilizando el método `License.SetLicense`
* Verificar que la licencia se haya aplicado correctamente antes de utilizar DocumentAssembler


:::info
Llamada `License.SetLicense` llamarlo varias veces no es perjudicial, pero desperdicia tiempo de procesador. En aplicaciones de Windows Forms o de consola, llámalo una sola vez durante el inicio. En aplicaciones ASP.NET, llámalo en `Application_Start` método en Global.asax.cs.
:::


## Instalación mediante el Administrador de paquetes NuGet {#install-via-nuget-package-manager}

La forma más sencilla de instalar GroupDocs.Assembly es mediante el Administrador de paquetes NuGet en Visual Studio.

1. Haga clic con el botón derecho en su proyecto en el Explorador de soluciones
2. Seleccione "Administrar paquetes NuGet"
3. Busque "GroupDocs.Assembly"
4. Haga clic en "Instalar" para instalar la versión más reciente

## Instalación mediante la Consola del Administrador de paquetes {#install-via-package-manager-console}

Alternativamente, puede instalar el paquete utilizando la Consola del Administrador de paquetes:

```csharp
// Run this command in Package Manager Console:
// Install-Package GroupDocs.Assembly
```

## Aplicar licencia desde archivo {#apply-license-from-file}

Tras la instalación, aplique su archivo de licencia para eliminar las limitaciones de evaluación:

```csharp
using GroupDocs.Assembly;

public static void ApplyLicenseFromFile()
{
    // Path to your license file
    string licensePath = "GroupDocs.Assembly.lic";
    
    // Apply the license
    License license = new License();
    license.SetLicense(licensePath);
    
    Console.WriteLine("License applied successfully from file.");
}
```

## Aplicar licencia desde un flujo {#apply-license-from-stream}

También puede cargar una licencia desde un flujo:

```csharp
using GroupDocs.Assembly;
using System.IO;

public static void ApplyLicenseFromStream()
{
    // Load license file into a stream
    using (FileStream stream = new FileStream("GroupDocs.Assembly.lic", FileMode.Open))
    {
        License license = new License();
        license.SetLicense(stream);
        
        Console.WriteLine("License applied successfully from stream.");
    }
}
```

## Verificación de la Aplicación de Licencia {#verify-license-application}

Para verificar que su licencia se ha aplicado correctamente, puede revisar la presencia de marcas de agua de evaluación en los documentos generados. Si no aparecen marcas de agua, la licencia está activa.

```csharp
using GroupDocs.Assembly;

public static void VerifyLicense()
{
    License license = new License();
    license.SetLicense("GroupDocs.Assembly.lic");
    
    // Try to assemble a simple document
    DocumentAssembler assembler = new DocumentAssembler();
    // If license is valid, no evaluation watermark will appear
    Console.WriteLine("License verification: Check generated documents for watermarks.");
}
```


:::warning
El archivo de licencia contiene una firma digital. No modifique el archivo de licencia, ya que incluso agregar un salto de línea adicional lo invalidará.
:::

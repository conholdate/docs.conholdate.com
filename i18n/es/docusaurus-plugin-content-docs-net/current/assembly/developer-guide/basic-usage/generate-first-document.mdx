## Vista general {#overview}

Esta guía le guiará paso a paso en la creación de su primer documento con GroupDocs.Assembly para .NET. Generará un documento sencillo a partir de un objeto .NET en memoria, demostrando el flujo de trabajo básico de la ensamblaje de documentos basado en plantillas.

Las clases principales implicadas son:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – la clase principal para ensamblar documentos
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/datasourceinfo/" target="_blank" rel="nofollow noopener noreferrer">DataSourceInfo</a> – envuelve objetos de origen de datos con nombres opcionales

A continuación se presentan los pasos para generar su primer documento:

* Crear una clase .NET sencilla con propiedades para representar sus datos
* Instanciar la clase y poblarla con datos de ejemplo
* Crear un documento de plantilla (DOCX) con etiquetas de expresión que hagan referencia a las propiedades del objeto
* Utilizar DocumentAssembler para ensamblar la plantilla con su objeto de datos
* Guardar el documento ensamblado en un archivo

## Definir una clase de datos sencilla {#define-a-simple-data-class}

En primer lugar, cree una clase sencilla para almacenar sus datos:

```csharp
public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
    public string Email { get; set; }
}
```

## Generar documento a partir de un objeto {#generate-document-from-object}

Ahora, cree un método para generar un documento a partir de este objeto:

```csharp
using GroupDocs.Assembly;
using System;

public static void GenerateFirstDocument()
{
    // Create sample data
    Person person = new Person
    {
        Name = "John Doe",
        Age = 30,
        Email = "john.doe@example.com"
    };
    
    // Paths for template and output
    string templatePath = "Template.docx";
    string outputPath = "Output.docx";
    
    // Assemble the document
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument(templatePath, outputPath, 
        new DataSourceInfo(person, "person"));
    
    Console.WriteLine($"Document generated successfully: {outputPath}");
}
```

## Ejemplo de documento de plantilla {#template-document-example}

Su documento de plantilla (Template.docx) debe contener etiquetas de expresión como esta:

```
Name: <<[person.Name]>>
Age: <<[person.Age]>>
Email: <<[person.Email]>>
```

Después del ensamblaje, la salida será:

```
Name: John Doe
Age: 30
Email: john.doe@example.com
```

## Uso del acceso a miembros de objeto contextual {#using-contextual-object-member-access}

También puedes utilizar el acceso contextual a miembros, que te permite omitir el nombre de la fuente de datos en escenarios simples:

```csharp
public static void GenerateDocumentWithContextualAccess()
{
    Person person = new Person
    {
        Name = "Jane Smith",
        Age = 28,
        Email = "jane.smith@example.com"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    // When using contextual access, you can omit the data source name
    assembler.AssembleDocument("Template.docx", "Output.docx", 
        new DataSourceInfo(person));
}
```

Con acceso contextual, su plantilla puede usar:

```
Name: <<[Name]>>
Age: <<[Age]>>
Email: <<[Email]>>
```


:::info
Al utilizar el acceso contextual a miembros de objetos, las expresiones de plantilla pueden hacer referencia directamente a las propiedades sin el prefijo del nombre de la fuente de datos. Esto resulta útil en escenarios simples que involucran un único objeto.
:::

## Vista general {#overview}

Las listas con viñetas son una forma común de mostrar colecciones de elementos en documentos. GroupDocs.Assembly para .NET facilita la generación de listas con viñetas mediante la iteración sobre colecciones de datos utilizando bandas de datos *foreach* dentro de estructuras de lista.

Las clases principales involucradas son:
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/documentassembler/" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> – ensambla documentos
- <a href="https://reference.groupdocs.com/assembly/net/groupdocs.assembly/datasourceinfo/" target="_blank" rel="nofollow noopener noreferrer">DataSourceInfo</a> – envuelve las fuentes de datos

A continuación se presentan los pasos para generar listas con viñetas:

* Crear una lista con viñetas en el documento plantilla
* Añadir una banda de datos *foreach* dentro de la lista para iterar sobre la colección
* Referenciar las propiedades de los elementos de la colección en los elementos de la lista
* Cerrar la banda de datos *foreach*
* Ensamblar el documento con los datos de la colección


:::info
La banda de datos `foreach` repite automáticamente los elementos de la lista para cada elemento de la colección, generando una lista con viñetas completa con todos los elementos de datos.
:::


## Generar una lista con viñetas a partir de una colección de .NET {#generate-bullet-list-from-net-collection}

Crear una lista con viñetas a partir de una lista de objetos:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public class Product
{
    public string Name { get; set; }
    public string Description { get; set; }
}

public static void GenerateBulletList()
{
    // Create sample data
    List<Product> products = new List<Product>
    {
        new Product { Name = "Laptop", Description = "High-performance laptop" },
        new Product { Name = "Mouse", Description = "Wireless mouse" },
        new Product { Name = "Keyboard", Description = "Mechanical keyboard" }
    };
    
    // Assemble document
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("BulletListTemplate.docx", "BulletListOutput.docx", 
        new DataSourceInfo(products, "products"));
    
    Console.WriteLine("Bullet list generated successfully.");
}
```

## Estructura de plantilla para listas con viñetas {#template-structure-for-bullet-lists}

En su documento de plantilla (BulletListTemplate.docx), cree una lista con viñetas con esta estructura:

```
We provide the following products:

<<foreach [in products]>>
• <<[Name]>> - <<[Description]>>
<</foreach>>
```

Después del ensamblaje, obtendrás:

```
We provide the following products:

• Laptop - High-performance laptop
• Mouse - Wireless mouse
• Keyboard - Mechanical keyboard
```

## Generar lista con viñetas a partir de DataTable {#generate-bullet-list-from-datatable}

También puede generar listas con viñetas a partir de un DataTable de ADO.NET:

```csharp
using GroupDocs.Assembly;
using System.Data;

public static void GenerateBulletListFromDataTable()
{
    // Create DataTable
    DataTable productsTable = new DataTable("Products");
    productsTable.Columns.Add("Name", typeof(string));
    productsTable.Columns.Add("Description", typeof(string));
    
    // Add rows
    productsTable.Rows.Add("Laptop", "High-performance laptop");
    productsTable.Rows.Add("Mouse", "Wireless mouse");
    productsTable.Rows.Add("Keyboard", "Mechanical keyboard");
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("BulletListTemplate.docx", "BulletListOutput.docx", 
        new DataSourceInfo(productsTable, "products"));
    
    Console.WriteLine("Bullet list generated from DataTable successfully.");
}
```

## Lista simple de viñetas (solo nombre) {#simple-bullet-list-name-only}

Para listas simples que muestren únicamente nombres:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void GenerateSimpleBulletList()
{
    List<string> items = new List<string> 
    { 
        "Item 1", 
        "Item 2", 
        "Item 3" 
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("SimpleBulletListTemplate.docx", "SimpleBulletListOutput.docx", 
        new DataSourceInfo(items, "items"));
    
    Console.WriteLine("Simple bullet list generated successfully.");
}
```

Plantilla para lista simple:

```
Items:
<<foreach [in items]>>
• <<[items_Text]>>
<</foreach>>
```

```csharp
        new DataSourceInfo(products, "products"));
    
    Console.WriteLine("Bullet list generated in spreadsheet successfully.");

```

## Lista con viñetas en correo electrónico {#bullet-list-in-email}

Genere listas con viñetas en mensajes de correo electrónico:

```csharp
using GroupDocs.Assembly;
using System.Collections.Generic;

public static void GenerateBulletListInEmail()
{
    List<Product> products = new List<Product>
    {
        new Product { Name = "Laptop", Description = "High-performance laptop" },
        new Product { Name = "Mouse", Description = "Wireless mouse" }
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("BulletListTemplate.msg", "BulletListOutput.msg", 
        new DataSourceInfo(products, "products"));
    
    Console.WriteLine("Bullet list generated in email successfully.");
}
```


:::warning
En los documentos de Word, asegúrese de que el formato de lista con viñetas se aplique en la plantilla. La banda de datos `foreach` repetirá el formato del elemento de lista para cada elemento de la colección.
:::

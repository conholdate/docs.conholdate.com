## Vista general {#overview}

GroupDocs.Assembly para .NET ofrece capacidades completas de formato para números, fechas y texto en plantillas. Puede utilizar cadenas de formato (similares al formato de .NET) y funciones integradas de transformación de texto para controlar cómo se muestran los datos en sus documentos.

Los elementos sintácticos principales son:
- Cadenas de formato: `<<[expression]:"format">>` – aplicar cadenas de formato de .NET
- Funciones de texto: `upper`, `lower`, `capital`, `firstcap` – transformar mayúsculas y minúsculas del texto

A continuación se indican los pasos para aplicar el formato:

* Utilizar cadenas de formato en etiquetas de expresión para números y fechas
* Aplicar funciones de transformación de texto para el formato de cadenas
* Combinar el formato con expresiones y cálculos
* Probar el formato para garantizar la salida deseada


:::info
Las cadenas de formato siguen las convenciones de formato de .NET. Utilice especificadores de formato numérico estándar (C, N, F, etc.) y cadenas de formato de fecha/hora (aaaa-MM-dd, etc.).
:::


## Formatear números {#format-numbers}

Formatee valores numéricos utilizando cadenas de formato:

```csharp
using GroupDocs.Assembly;

public class Invoice
{
    public decimal Amount { get; set; }
    public double Percentage { get; set; }
    public int Quantity { get; set; }
}

public static void FormatNumbers()
{
    var invoice = new Invoice
    {
        Amount = 1500.75m,
        Percentage = 0.15,
        Quantity = 25
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.docx", "FormattingOutput.docx", 
        new DataSourceInfo(invoice, "invoice"));
    
    Console.WriteLine("Numbers formatted successfully.");
}
```

## Ejemplos de plantillas para el formato de números {#template-examples-for-number-formatting}

En su plantilla, utilice cadenas de formato:

```
Amount: <<[invoice.Amount]:"C">>
Percentage: <<[invoice.Percentage]:"P">>
Quantity: <<[invoice.Quantity]:"N0">>
```

Cadenas de formato numérico comunes:
- `"C"` – Moneda (por ejemplo, $1,500.75)
- `"N"` o `"N2"` – Número con decimales (por ejemplo, 1,500.75)
- `"F"` o `"F2"` – Punto fijo (por ejemplo, 1500.75)
- `"P"` – Porcentaje (por ejemplo, 15.00%)
- `"D"` – Decimal (para enteros)

## Formatear fechas y horas {#format-dates-and-times}

Formatear valores de fecha y hora:

```csharp
using GroupDocs.Assembly;
using System;

public class Report
{
    public DateTime CreatedDate { get; set; }
    public DateTime DueDate { get; set; }
}

public static void FormatDates()
{
    var report = new Report
    {
        CreatedDate = new DateTime(2024, 1, 15, 14, 30, 0),
        DueDate = new DateTime(2024, 2, 15)
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.docx", "FormattingOutput.docx", 
        new DataSourceInfo(report, "report"));
    
    Console.WriteLine("Dates formatted successfully.");
}
```

## Ejemplos de plantillas para formato de fecha {#template-examples-for-date-formatting}

```
Created: <<[report.CreatedDate]:"yyyy-MM-dd HH:mm">>
Due Date: <<[report.DueDate]:"MMMM dd, yyyy">>
```

Cadenas comunes de formato de fecha:
- `"yyyy-MM-dd"` - 2024-01-15
- `"MM/dd/yyyy"` - 01/15/2024
- `"MMMM dd, yyyy"` - 15 de enero de 2024
- `"dd.MM.yyyy"` - 15.01.2024
- `"HH:mm"` - 14:30

## Formatear texto (transformación de mayúsculas y minúsculas) {#format-text-case-transformation}

Transformar el caso del texto utilizando funciones integradas:

```csharp
using GroupDocs.Assembly;

public class Product
{
    public string Name { get; set; }
    public string Description { get; set; }
}

public static void FormatText()
{
    var product = new Product
    {
        Name = "laptop computer",
        Description = "HIGH-PERFORMANCE DEVICE"
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.docx", "FormattingOutput.docx", 
        new DataSourceInfo(product, "product"));
    
    Console.WriteLine("Text formatted successfully.");
}
```

## Ejemplos de plantillas para formato de texto {#template-examples-for-text-formatting}

```
Name: <<[product.Name]:upper>>
Description: <<[product.Description]:lower>>
Title: <<[product.Name]:capital>>
```

Funciones de transformación de texto:
- `:upper` - CONVERTIR A MAYÚSCULAS
- `:lower` - Convertir a minúsculas
- `:capital` - Capitalizar Cada Palabra
- `:firstcap` - Capitalizar solo la primera letra

## Combinar formato con cálculos {#combine-formatting-with-calculations}

Formatear valores calculados:

```csharp
using GroupDocs.Assembly;

public class Order
{
    public int Quantity { get; set; }
    public decimal UnitPrice { get; set; }
}

public static void FormatCalculations()
{
    var order = new Order
    {
        Quantity = 5,
        UnitPrice = 29.99m
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.docx", "FormattingOutput.docx", 
        new DataSourceInfo(order, "order"));
    
    Console.WriteLine("Calculations formatted successfully.");
}
```

Plantilla:

```
Quantity: <<[order.Quantity]>>
Unit Price: <<[order.UnitPrice]:"C">>
Total: <<[order.Quantity * order.UnitPrice]:"C">>
```

## Formatos numéricos personalizados {#custom-numeric-formats}

Utilice cadenas de formato personalizadas para requisitos específicos:

```csharp
using GroupDocs.Assembly;

public static void CustomNumericFormats()
{
    var data = new { 
        Phone = 1234567890,
        Code = 42,
        Rate = 0.1234
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.docx", "FormattingOutput.docx", 
        new DataSourceInfo(data, "data"));
    
    Console.WriteLine("Custom formats applied successfully.");
}
```

Plantilla con formatos personalizados:

```
Phone: <<[data.Phone]:"(###) ###-####">>
Code: <<[data.Code]:"000">>
Rate: <<[data.Rate]:"0.00%">>
```

## Formato en distintos tipos de documentos {#formatting-in-different-document-types}

El formato funciona de forma coherente en todos los tipos de documentos:

```csharp
using GroupDocs.Assembly;

public static void FormatInSpreadsheet()
{
    var invoice = new Invoice
    {
        Amount = 1500.75m,
        CreatedDate = DateTime.Now
    };
    
    DocumentAssembler assembler = new DocumentAssembler();
    assembler.AssembleDocument("FormattingTemplate.xlsx", "FormattingOutput.xlsx", 
        new DataSourceInfo(invoice, "invoice"));
    
    Console.WriteLine("Formatting applied in spreadsheet successfully.");
}
```


:::warning
Las cadenas de formato distinguen mayúsculas de minúsculas. Utilice letras mayúsculas para los especificadores de formato estándar (C, N, F, P) y siga exactamente las convenciones de formato de .NET.
:::

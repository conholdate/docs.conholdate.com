## Sobre esta sección {#about-this-section}

Los artículos de esta sección abordarán conceptos técnicos que deben considerarse al crear plantillas de documentos con el fin de generar los informes requeridos. Tras completar esta sección, esperamos que comprendas la sintaxis de las plantillas, la composición de expresiones y otros elementos de programación compatibles con C#. Además, también discutiremos cómo el motor <a href="https://reference.groupdocs.com/net/assembly" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly</a> lee la sintaxis, evalúa las expresiones para rellenarlas con los datos asignados y, finalmente, genera el informe deseado según tus necesidades empresariales.

## Vista general {#at-a-glance}

### Pasos que debes seguir {#steps-you-follow}

En resumen, seguirás estos pasos al utilizar el motor <a href="https://reference.groupdocs.com/net/assembly" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly</a>:

1.  Crear una fuente de datos en uno de los formatos de datos admitidos
2.  Crear una plantilla que respete la sintaxis y las expresiones admitidas
3.  Pasar la fuente de datos y la plantilla al motor

#### Acciones realizadas por el motor GroupDocs.Assembly {#the-actions-by-groupdocs-assembly-engine}

Como resultado de pasar la plantilla y la fuente de datos, el motor llevará a cabo las siguientes acciones:

1.  Evaluar secuencialmente las expresiones frente al objeto de la fuente de datos proporcionada
2.  Procesar los resultados de las expresiones según su función
3.  Reemplazar las etiquetas correspondientes con el contenido adecuado

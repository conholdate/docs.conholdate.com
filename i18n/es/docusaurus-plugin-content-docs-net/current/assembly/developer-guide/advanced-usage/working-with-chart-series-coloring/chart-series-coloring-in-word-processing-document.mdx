## Coloreo de series de gráficos en documentos de procesamiento de texto {#chart-series-coloring-in-word-processing-document}

### Creación de un gráfico de columnas {#creating-a-column-chart}

Siguiendo los pasos siguientes, puede insertar un gráfico de columnas en MS Word 2013:

1.  Haga clic en el lugar del documento donde desee insertar el gráfico, vaya a la pestaña «Insertar» y, a continuación, haga clic en «Gráfico» en el grupo Ilustraciones para abrir el cuadro de diálogo «Insertar gráfico».
2.  En la barra lateral, seleccione «Columna»; verá una galería de gráficos.
3.  Elija «Columna apilada al 100 %» y pulse «Aceptar» para insertar el gráfico y la plantilla de hoja de cálculo en su documento.
4.  Edite la hoja de cálculo con sus datos para actualizar el gráfico. Consulte <a href="https://docs.groupdocs.com/assembly/net/chart-series-coloring-in-word-processing-document/#adding-syntax-to-be-evaluated-by-groupdocsassembly-engine" target="_blank" rel="nofollow noopener noreferrer">Datos del gráfico (Excel)</a>.
5.  Guarde el documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere compartir dinámicamente el precio del contrato por gerente, cumpliendo con los siguientes requisitos clave:

*   El informe debe mostrar el nombre del gerente.
*   El informe debe mostrar el precio total del contrato para cada gerente.
*   Color de serie que se utilizará en las series del gráfico.
*   El informe debe generarse en un documento de procesamiento de texto.

### Generación del informe {#generating-the-report}

Para un gráfico con datos dinámicos, puede definir dinámicamente los colores de las series del gráfico según expresiones. Para utilizar esta funcionalidad, siga los siguientes pasos:

*   Declare un gráfico con datos dinámicos de la forma habitual
*   Para que las series del gráfico se colorean dinámicamente, defina las expresiones de color correspondientes en los nombres de dichas series utilizando etiquetas **seriesColor** con la siguiente sintaxis:
  
    ```csharp
    <<seriesColor [color_expression]>>
    ```
    

Una expresión de color debe devolver un valor de uno de los siguientes tipos:

*   Una cadena que contiene el nombre de un color conocido, es decir, el nombre (sin distinción entre mayúsculas y minúsculas) de un miembro de la enumeración <a href="https://msdn.microsoft.com/en-us/library/system.drawing.knowncolor(v=vs.110" target="_blank" rel="nofollow noopener noreferrer">KnownColor</a>.aspx), como "red"
*   Un valor entero que define los componentes RGB (rojo, verde, azul) del color, como 0xFFFF00 (amarillo)
*   Un valor del tipo <a href="http://msdn.microsoft.com/en-us/library/system.drawing.color(v=vs.110" target="_blank" rel="nofollow noopener noreferrer">Color</a>.aspx)

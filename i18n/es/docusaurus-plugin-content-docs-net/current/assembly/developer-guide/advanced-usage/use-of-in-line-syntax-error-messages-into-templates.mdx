:::info
Esta versión proporciona la capacidad de mostrar errores de sintaxis de plantillas en línea en documentos generados, procesadores de texto, presentaciones, hojas de cálculo, correos electrónicos y documentos de texto sin formato.
:::


De forma predeterminada, Document Assembler lanza una excepción cuando encuentra un error de sintaxis en la plantilla. Dicha excepción proporciona información sobre la causa del error y especifica la etiqueta o la parte de la expresión donde se produce el error. En la mayoría de los casos, esta información es suficiente para localizar la sección de la plantilla que causa el error y corregirla.

Sin embargo, al trabajar con plantillas complejas que contienen un gran número de etiquetas, resulta más difícil localizar exactamente el lugar en la plantilla que está causando un error. Para facilitar esta tarea, el motor admite el <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassemblyoptions" target="_blank" rel="nofollow noopener noreferrer">DocumentAssemblyOptions.InlineErrorMessages</a> Opción que permite incrustar un mensaje de error de sintaxis directamente en un documento de plantilla, en la posición exacta donde ocurre el error durante la ejecución.


:::warning
Un mensaje de error de sintaxis de plantilla se escribe utilizando una fuente en negrita para que sea más evidente.
:::


Considere la siguiente plantilla.

```csharp
<<var [name]>>
```

De forma predeterminada, esta plantilla hace que el motor lance una excepción al generar un informe. Sin embargo, cuando se aplica `DocumentAssemblyOptions.InlineErrorMessages`, no se lanza ninguna excepción y el informe se ve de la siguiente manera.

```csharp
<<var [name] Error! An assignment operator is expected. >>
```


:::warning
Solo los mensajes que describan errores en la sintaxis de la plantilla pueden aparecer en línea; los mensajes que describan errores encontrados durante la evaluación de la expresión no pueden aparecer.
:::


Cuando se aplica **DocumentAssemblyOptions.InlineErrorMessages**, un valor booleano devuelto por una sobrecarga de <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler/methods/index" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler.AssembleDocument</a> indica si la generación del informe finalizó correctamente o se interrumpió debido a un error de sintaxis en la plantilla. Esto le permite procesar de forma distinta los informes cuya generación tuvo éxito o falló, como se muestra en el siguiente fragmento de código.

La API de GroupDocs.Assembly le permite utilizar una cadena como entrada y salida de plantilla, en lugar de un documento. Esta funcionalidad mejora la programabilidad al trabajar con cadenas en lugar de documentos; la cadena resultante puede utilizarse según las necesidades de la aplicación. Siga estos pasos para utilizar una cadena como entrada y salida de plantilla:

*   Inicialice <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a>
*   Defina **sourceString @"&lt;&lt;\[suValor\]&gt;&gt;"**
*   Convierta **sourceString** en **sourceBytes** mediante **Encoding.UTF8.GetBytes(sourceString)**
*   Obtenga **targetBytes** mediante <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler/methods/assembledocument/index" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler.AssembleDocument()</a>
*   Obtenga **targetString** mediante **Encoding.UTF8.GetString(targetBytes)**

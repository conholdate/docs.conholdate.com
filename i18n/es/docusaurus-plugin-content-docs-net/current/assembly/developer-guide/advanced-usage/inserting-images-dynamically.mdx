Puede insertar imágenes en sus informes de forma dinámica utilizando etiquetas de imagen. Para declarar una imagen insertada dinámicamente dentro de su plantilla, siga los siguientes pasos:

1.  Agregue un cuadro de texto en su plantilla en el lugar donde desea insertar una imagen.
2.  Configure los atributos comunes de la imagen, como el marco, el tamaño y otros, para el cuadro de texto, de modo que este último se vea como una imagen insertada en blanco.
3.  Especifique una etiqueta de imagen dentro del cuadro de texto utilizando la siguiente sintaxis.

```csharp
<<image [image_expression]>>
```

Y simplemente invoque el método del ensamblador para generar el informe, como se muestra en los siguientes fragmentos de código:

<a href="https://gist.github.com/GroupDocsGists/b06d6c5655c84fc772c6411d66016943" target="_blank" rel="nofollow noopener noreferrer">Ver ejemplo de código en GitHub Gist</a>

La expresión declarada dentro de una etiqueta de imagen es utilizada por el ensamblador para construir la imagen que se insertará. Dicha expresión debe devolver un valor de uno de los siguientes tipos:

*   Una matriz de bytes que contiene los datos de la imagen
*   Una instancia de <a href="http://msdn.microsoft.com/en-us/library/system.io.stream(v=vs.110" target="_blank" rel="nofollow noopener noreferrer">Stream</a>.aspx) capaz de leer los datos de la imagen
*   Un objeto <a href="http://msdn.microsoft.com/en-us/library/system.drawing.image(v=vs.110" target="_blank" rel="nofollow noopener noreferrer">Image</a>.aspx)
*   Una cadena que contiene una URI, una ruta o datos de imagen codificados en Base64

Al construir un informe, se aplica el siguiente procedimiento a la etiqueta de imagen:

1.  Se evalúa la expresión declarada dentro de la etiqueta y su resultado se utiliza para formar la imagen.
2.  La caja de texto correspondiente se rellena con esta imagen.
3.  La etiqueta se elimina de la caja de texto.


:::warning
Si la expresión declarada dentro de una etiqueta de imagen devuelve un objeto de flujo (*stream*), este se cierra por parte del ensamblador tan pronto como se construye la imagen correspondiente.
:::


De forma predeterminada, el ensamblador estira una imagen que llena un cuadro de texto hasta el tamaño del propio cuadro de texto. Sin embargo, puedes modificar este comportamiento de las siguientes maneras:

*   Para mantener el tamaño del cuadro de texto y estirar la imagen dentro de los límites del cuadro de texto, preservando la relación de aspecto de la imagen, utiliza el modificador *keepRatio* de la siguiente manera:
  
    ```csharp
    <<image [image_expression] -keepRatio>>
    ```
    
*   Para mantener el ancho del cuadro de texto y cambiar su altura preservando la proporción de la imagen, utilice el modificador `fitHeight` de la siguiente manera:
  
    ```csharp
    <<image [image_expression] -fitHeight>>
    ```
    
*   Para mantener la altura del cuadro de texto y cambiar su ancho preservando la relación de aspecto de la imagen, utilice el modificador `fitWidth` de la siguiente manera.
  
    ```csharp
    <<image [image_expression] -fitWidth>>
    ```
    
*   Para cambiar el tamaño del cuadro de texto según el tamaño de la imagen, utilice el interruptor `fitSize` de la siguiente manera:
  
    ```csharp
    <<image [image_expression] -fitSize>>
    ```
    
*   Para cambiar el tamaño del cuadro de texto según el tamaño de la imagen sin aumentar el tamaño del cuadro de texto, utilice el interruptor `fitSizeLim` de la siguiente manera.
  
    ```csharp
    <<image [image_expression] -fitSizeLim>>
    ```
    
    
:::warning
Si el tamaño de la imagen es mayor que el tamaño del cuadro de texto, entonces el interruptor `fitSizeLim` actúa como `fitHeight` o `fitWidth`. De lo contrario, el interruptor `fitSizeLim` actúa como `fitSize`.
:::

    


:::warning
La inserción dinámica de imágenes a partir de bytes codificados en Base64 está disponible para formatos de archivo donde la inserción dinámica de imágenes está disponible; prácticamente todos los formatos de archivo compatibles lo permiten.
:::

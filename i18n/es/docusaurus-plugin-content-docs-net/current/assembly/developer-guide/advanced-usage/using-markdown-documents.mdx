## Documentos Markdown (MD) {#markdown-documents-md}

**Markdown** es un <a href="https://en.wikipedia.org/wiki/Lightweight_markup_language" target="_blank" rel="nofollow noopener noreferrer">lenguaje de marcado ligero</a> diseñado para un único propósito: formatear texto en la web mediante una sintaxis de marcado en texto plano. Queda claro que Markdown no pretende reemplazar a HTML, ya que su sintaxis es muy reducida y solo incluye un subconjunto muy pequeño de etiquetas HTML. El objetivo de Markdown es facilitar la lectura, escritura y edición de textos en prosa. En otras palabras, podemos decir que HTML es un formato de publicación, mientras que Markdown es un formato de redacción.

Los archivos de texto creados con dialectos del lenguaje Markdown se guardan con la extensión **.MD** o **.MARKDOWN**. Los archivos MD se almacenan en formato de texto plano y utilizan el lenguaje Markdown, que también incluye símbolos de texto en línea para definir cómo se debe formatear el texto, como sangrías, formato de tablas, fuentes y encabezados.

## Trabajo con documentos Markdown {#working-with-markdown-documents}

Desde la versión 19.8, GroupDocs.Assembly ofrece capacidades para guardar documentos Markdown ensamblados en formatos de procesamiento de textos, así como para guardar documentos de procesamiento de textos y correos electrónicos ensamblados en Markdown. 

La API admite las siguientes características de Markdown:

*   Encabezados
*   Citas en bloque
*   Reglas horizontales
*   Énfasis en negrita
*   Énfasis en cursiva

### Ampliación del conjunto de características de Markdown admitidas {#extended-the-set-of-supported-markdown-features}


:::info
Esta función es compatible con la versión 19.11 o superior.
:::


A partir de la versión 19.11, se admiten las siguientes características de Markdown al guardar documentos Markdown ensamblados en formatos de procesamiento de textos y al guardar documentos y correos electrónicos de procesamiento de textos ensamblados en Markdown:

*   <a href="https://spec.commonmark.org/0.29/#indented-code-blocks" target="_blank" rel="nofollow noopener noreferrer">Bloques de código sangrados </a>
*   <a href="https://spec.commonmark.org/0.29/#fenced-code-blocks" target="_blank" rel="nofollow noopener noreferrer">Bloques de código delimitados por tildes (fenced code blocks)</a>
*   <a href="https://spec.commonmark.org/0.29/#code-spans" target="_blank" rel="nofollow noopener noreferrer">Tramos de código en línea (inline code spans)</a>
*   <a href="https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet#emphasis" target="_blank" rel="nofollow noopener noreferrer">Texto tachado (strikethrough text)</a>
*   Listas desordenadas (a partir de la versión 19.12)

El motor de informes LINQ le permite realizar operaciones comunes sobre datos secuenciales mediante los métodos de extensión integrados del motor para `IEnumerable`. Estos métodos de extensión imitan algunos métodos de extensión de <a href="http://msdn.microsoft.com/en-us/library/9eekhta0\(v=vs.110\" target="_blank" rel="nofollow noopener noreferrer">IEnumerable&amp;lt;T&amp;gt;</a>.aspx), proporcionando las mismas firmas y características de comportamiento. Por lo tanto, puede agrupar, ordenar y realizar otras manipulaciones de datos secuenciales en expresiones de plantilla de forma familiar.

La siguiente tabla describe estos métodos de extensión integrados. Dentro de la tabla se utilizan las siguientes convenciones de notación:

- `Selector` representa una función lambda que devuelve un valor y toma un elemento de la enumeración como único argumento. Consulte «Uso de funciones lambda» para obtener más información.
- `ComparableSelector` representa `Selector` que devuelve <a href="http://msdn.microsoft.com/en-US/library/system.icomparable\(v=vs.110\" target="_blank" rel="nofollow noopener noreferrer">IComparable</a>.aspx).
- `EnumerationSelector` representa `Selector` que devuelve `IEnumerable`.
- `Predicate` representa `Selector` que devuelve un valor booleano.

Los ejemplos de la siguiente tabla se proporcionan utilizando personas y `otherPersons`, que son enumeraciones de instancias de la clase `Person`, definida de la siguiente manera.
```csharp

public class Person
{
    public String Name { get { ... } }
    public int Age { get { ... } }
    public IEnumerable<Person> Children { get { ... } }
    ...
}
```

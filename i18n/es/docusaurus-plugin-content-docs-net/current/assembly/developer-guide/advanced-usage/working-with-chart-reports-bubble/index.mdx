## El gráfico de burbujas {#the-bubble-chart}

Según Wikipedia, un gráfico de burbujas puede describirse como:

> Un **gráfico de burbujas** es un tipo de <a href="https://en.wikipedia.org/wiki/Chart" target="_blank" rel="nofollow noopener noreferrer">gráfico</a> que muestra tres dimensiones de datos. Cada entidad, con su triplet (*v*<sub>1</sub>, *v*<sub>2</sub>, *v*<sub>3</sub>) de datos asociados, se representa como un disco que expresa dos de los valores *v*<sub>i</sub> mediante la posición *xy* del disco y el tercero mediante su tamaño. Los gráficos de burbujas pueden facilitar la comprensión de relaciones sociales, económicas, médicas y otras científicas.

Para obtener más información, consulte el <a href="https://en.wikipedia.org/wiki/Bubble_chart" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

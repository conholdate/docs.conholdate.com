## Gráfico de burbujas en un documento de Microsoft PowerPoint {#bubble-chart-in-microsoft-powerpoint-document}

### Creación de un gráfico de burbujas {#creating-a-bubble-chart}

Siga los pasos que se indican a continuación para crear un gráfico de burbujas en Microsoft PowerPoint 2013:

1.  Añada una nueva diapositiva a la presentación, haga clic en la pestaña «Insertar» y, a continuación, haga clic en «Gráfico» dentro del grupo Ilustraciones para abrir el cuadro de diálogo «Insertar gráfico».
2.  En la barra lateral, seleccione «X Y (Dispersión)»; verá una galería de gráficos.
3.  Elija «Burbuja» y pulse «Aceptar» para insertar el gráfico y la plantilla de hoja de cálculo en su documento.
4.  Edite la hoja de cálculo con sus datos para actualizar el gráfico. Consulte <a href="/es/net/assembly/developer-guide/advanced-usage/working-with-chart-reports-bubble/bubble-chart-in-presentation-document/#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine">Datos del gráfico (Excel)</a>.
5.  Guarde su documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le pide compartir dinámicamente sus ventas/pedidos cumpliendo los siguientes requisitos clave:

*   El informe debe mostrar la variación en los precios de las ventas/pedidos.
*   Debe indicar a qué mes corresponde cada venta/pedido.
*   El informe debe generarse en un documento de presentación.

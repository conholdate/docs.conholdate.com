## Inserción dinámica de documentos {#inserting-documents-dynamically}

Puede insertar dinámicamente el contenido de documentos externos en sus informes mediante etiquetas de documento (doc tags). Una etiqueta de documento representa un marcador de posición dentro de una plantilla para un documento que se insertará en tiempo de ejecución.

```csharp
<<doc [document_expression]>>
```


:::warning
Una etiqueta de documento (doc tag) se puede usar casi en cualquier lugar de un documento de plantilla, excepto en cajas de texto y gráficos.
:::


Una expresión declarada dentro de una etiqueta de documento es utilizada por el motor para cargar un documento que será insertado durante el tiempo de ejecución. La expresión debe devolver un valor de uno de los siguientes tipos:

*   Una matriz de bytes que contiene los datos del documento
*   Una instancia de Stream capaz de leer los datos del documento
*   Una instancia de la clase Document
*   Una cadena que contiene una URI de documento


:::warning
Si una expresión declarada dentro de una etiqueta de documento devuelve un objeto de flujo (*stream*), entonces el motor cierra ese flujo tan pronto como se carga el documento correspondiente.
:::


De forma predeterminada, un documento que se está insertando no se verifica contra la sintaxis de plantilla ni se rellena con datos. Sin embargo, puedes habilitar esta funcionalidad mediante un modificador de compilación, como se muestra a continuación.

```csharp
<<doc [document_expression] -build>>
```

Cuando se utiliza un interruptor de compilación, el motor trata un documento que se está insertando como una plantilla a la que se puede acceder a los siguientes datos disponibles en el ámbito de la etiqueta de documento correspondiente:

*   Fuentes de datos
*   Variables
*   Un objeto contextual (consulte "<a href="https://docs.aspose.com/display/wordsnet/Template+Syntax#nowhere" target="_blank" rel="nofollow noopener noreferrer">Uso del acceso a miembros de objetos contextuales</a>" para obtener más información)
*   Tipos externos conocidos (consulte "<a href="https://docs.aspose.com/display/wordsnet/Template+Syntax#nowhere" target="_blank" rel="nofollow noopener noreferrer">Configuración de tipos externos conocidos</a>" para obtener más información)


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>
:::

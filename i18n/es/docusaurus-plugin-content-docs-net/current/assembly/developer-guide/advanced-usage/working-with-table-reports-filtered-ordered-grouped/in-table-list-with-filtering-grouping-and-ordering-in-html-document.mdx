## Detalles maestro-detalle en tabla dentro de un documento HTML {#in-table-master-detail-in-html-document}


:::info
Esta función es compatible con la versión 17.3.0 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar la información de los pedidos de los clientes con los siguientes requisitos clave:

*   El informe debe mostrar a cada cliente junto con la suma de los precios de sus pedidos.
*   Debe representar toda la información en forma tabular.
*   El informe debe generarse en el documento de presentación.

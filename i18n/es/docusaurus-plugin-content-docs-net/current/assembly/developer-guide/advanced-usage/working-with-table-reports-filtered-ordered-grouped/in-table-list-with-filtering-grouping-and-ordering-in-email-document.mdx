## Lista en tabla con filtrado, agrupación y ordenación en documento de correo {#in-table-list-with-filtering-grouping-and-ordering-in-email-document}


:::info
Esta función es compatible con la versión 17.8.0 o superior
:::


### Creación de una lista en tabla con filtrado, agrupación y ordenación {#creating-a-in-table-list-with-filtering-grouping-and-ordering}

Siga los siguientes pasos para crear una plantilla de lista en tabla con filtrado, agrupación y ordenación en Microsoft Outlook 2013.

1.  Crear un nuevo correo electrónico.
2.  Pulse en la pestaña "Insertar" para insertar una tabla.
3.  Inserte una tabla de 2x2.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información contractual de los gerentes con los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar a cada cliente junto con la suma de los precios de sus pedidos.
*   Debe representar toda la información en forma tabular.

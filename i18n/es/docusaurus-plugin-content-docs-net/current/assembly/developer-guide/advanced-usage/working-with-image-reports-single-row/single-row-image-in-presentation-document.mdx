## Una sola fila en un documento de Microsoft PowerPoint {#single-row-in-microsoft-powerpoint-document}

### Creación de una sola fila {#creating-a-single-row}

Siga los pasos que se indican a continuación para crear una imagen con una sola fila en Microsoft PowerPoint 2013:

1.  Crear una nueva diapositiva en la presentación.
2.  Insertar la forma deseada para mostrar la imagen en su interior.
3.  Ir a la pestaña "Insertar" y seleccionar una forma haciendo clic en el icono "Forma".
4.  Escribir "Nombre" y "Número de contacto" para mostrar el nombre y la información de contacto del cliente.
5.  Guardar la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información del primer cliente único, cumpliendo con los siguientes requisitos clave:

*   El informe debe mostrar la imagen del cliente.
*   Debe mostrar el nombre y el número de contacto del cliente.
*   El informe debe generarse en un documento de presentación.

## Fila única en documento de presentación de OpenOffice {#single-row-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint Document (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de «fila única» en formato ODP. En cambio, guardaremos la plantilla existente en formato ODP utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente creada en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «Texto OpenDocument» en el menú desplegable «Tipo de archivo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODP entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

## Una sola fila en un documento de texto {#single-row-in-text-document}


:::info
Esta función es compatible con la versión 17.03 o superior.
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar la información del primer cliente único con los siguientes requisitos clave:

*   Debe mostrar el nombre y el número de contacto del cliente
*   El informe debe generarse en un documento de texto

### Adición de sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
Name:	<<[customer.CustomerName]>>
Contact Number:	<<[customer.CustomerContactNumber]>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.
:::

## Imagen de una sola fila en un documento de correo electrónico {#single-row-image-in-email-document}


:::info
Esta función es compatible con la versión 17.8.0 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar la información del primer gerente único, cumpliendo con los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo
*   El informe debe mostrar la imagen del gerente
*   Debe mostrar el nombre y el número de contacto del cliente

### Sintaxis a agregar y evaluar mediante el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
Name:	<<[customer.CustomerName]>>
Contact Number:	<<[customer.CustomerContactNumber]>>
```

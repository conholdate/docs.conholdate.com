## Imagen de una sola fila en un documento de Microsoft Word {#single-row-image-in-microsoft-word-document}

### Creación de una imagen de una sola fila {#creating-a-single-row-image}

Siga los pasos a continuación para crear una imagen de una sola fila en Microsoft Word 2013:

1.  Inserte la forma deseada para mostrar la imagen en ella.
2.  Vaya a la pestaña Insertar y seleccione una forma haciendo clic en el icono Forma.
3.  Escriba "Nombre" y "Número de contacto" para mostrar el nombre y la información de contacto del cliente.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información del primer cliente único con los siguientes requisitos clave:

*   El informe debe mostrar la imagen del cliente.
*   Debe mostrar el nombre y el número de contacto del cliente.
*   El informe debe generarse en un documento de procesamiento de textos.

## Fila única en documento de OpenOffice {#single-row-in-openoffice-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Text (ODT) es un formato de documento de procesamiento de textos que puede utilizarse como alternativa a los formatos de documento de Microsoft Word (DOC/DOCX). Dado que ODT no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODT, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de «fila única» en formato ODT. En su lugar, guardaremos la plantilla existente en formato ODT utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «Texto OpenDocument» en el menú desplegable «Tipo de archivo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODT en Apache OpenOffice {#odt-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODT entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODT creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODT generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

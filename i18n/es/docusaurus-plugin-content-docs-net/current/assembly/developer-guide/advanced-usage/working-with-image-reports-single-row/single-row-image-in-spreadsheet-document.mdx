## Una sola fila en un documento de Microsoft Excel {#single-row-in-microsoft-excel-document}

### Creación de una sola fila {#creating-a-single-row}

Siga los pasos que se indican a continuación para crear una imagen de una sola fila en Microsoft Excel 2013:

1.  Crear un nuevo libro.
2.  Insertar una forma deseada para mostrar la imagen en ella.
3.  Ir a la pestaña Insertar y seleccionar una forma haciendo clic en el icono de Forma.
4.  Escribir «Nombre» y «Número de contacto» para mostrar el nombre y la información de contacto del cliente.
5.  Guardar la plantilla.

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información del primer cliente único, cumpliendo con los siguientes requisitos clave:

*   El informe debe mostrar la imagen del cliente.
*   Debe mostrar el nombre y el número de contacto del cliente.
*   El informe debe generarse en un documento de hoja de cálculo.

## Fila única en documento de hoja de cálculo OpenOffice {#single-row-in-openoffice-spreadsheet-document}

### Creación de la plantilla {#creating-the-template}

El formato de documento de hoja de cálculo OpenDocument (ODS) es un formato de documento de hoja de cálculo que puede utilizarse como alternativa a los formatos de documento de Microsoft Excel (XLS/XLSX). Dado que ODS no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODS, visite el artículo de Wikipedia.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de «fila única» en formato ODS. En su lugar, guardaremos la plantilla existente en formato ODS utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  En el menú desplegable «Guardar como tipo», seleccione «Documento de hoja de cálculo OpenDocument».
4.  Haga clic en «Guardar».

### Plantilla e informe ODS en Apache OpenOffice {#ods-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODS entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODS creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

*   Abrimos el informe ODS generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

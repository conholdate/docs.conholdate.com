Puede establecer dinámicamente los valores de las casillas de verificación como seleccionadas o no seleccionadas en sus informes siguiendo los pasos siguientes:

1.  Agregue un control de contenido de casilla de verificación en su plantilla en el lugar donde desee que aparezca en el documento resultante.
2.  Al editar las propiedades del control de contenido, agregue una etiqueta de verificación al título del control de contenido de casilla de verificación utilizando la siguiente sintaxis.

```csharp
<<check [conditional_expression]>>
```

El código tendrá el siguiente aspecto:

<a href="https://gist.github.com/GroupDocsGists/b06d6c5655c84fc772c6411d66016943" target="_blank" rel="nofollow noopener noreferrer">Ver ejemplo de código en GitHub Gist</a>

Aquí, `conditional_expression` define una condición según la cual el valor del control de contenido de casilla de verificación se establecerá como seleccionado (o no seleccionado, si la condición no se cumple). La expresión condicional debe devolver un valor booleano.

Al generar un informe, la expresión condicional declarada dentro de la etiqueta `check` se evalúa y el valor del control de contenido de casilla de verificación que la contiene se establece en consecuencia. A continuación, la etiqueta `check` se elimina.


:::warning
La configuración dinámica del valor de las casillas de verificación solo está disponible para documentos de procesamiento de texto.
:::

## Lista con viñetas en un documento HTML {#bulleted-list-in-html-document}


:::info
Esta función es compatible con la versión 17.03 o superior.
:::


### Creación de una lista con viñetas {#creating-a-bulleted-list}

Siga los siguientes pasos para insertar una lista con viñetas en un documento HTML.

1.  Para agregar una lista con viñetas, inicie y finalice la lista con la etiqueta `<ul></ul>` y enumere todos los elementos encerrándolos entre las etiquetas `<li></li>`.
2.  Guarde el documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere cumplir con los siguientes requisitos clave:

*   El informe debe mostrar todos los productos en formato de lista con viñetas.
*   El informe debe generarse en un documento HTML.

### Adición de la sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<ul>
&lt;&lt;foreach [in products]&gt;&gt;
<li>&lt;&lt;[ProductName]&gt;&gt;</li>
&lt;&lt;/foreach&gt;&gt;
</ul>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="/es/net/assembly/developer-guide/basic-usage/working-with-groupdocs.assembly-engine/">Trabajar con el motor GroupDocs.Assembly</a>.
:::

## Lista con viñetas en el correo {#bulleted-list-in-email}


:::info
Esta función es compatible con la versión 17.8.0 o superior.
:::


#### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige compartir los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar todos los productos en formato de lista con viñetas.

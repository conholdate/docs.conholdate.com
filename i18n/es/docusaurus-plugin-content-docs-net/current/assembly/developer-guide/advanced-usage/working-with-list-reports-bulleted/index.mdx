## La lista con viñetas {#the-bulleted-list}

Según Wikipedia, una **lista con viñetas** puede describirse como:

> En <a href="https://en.wikipedia.org/wiki/Typography" target="_blank" rel="nofollow noopener noreferrer">tipografía</a>, una **viñeta** ( • ) es un símbolo tipográfico o <a href="https://en.wikipedia.org/wiki/Glyph" target="_blank" rel="nofollow noopener noreferrer">glifo</a> utilizado para introducir elementos en una <a href="https://en.wiktionary.org/wiki/list" target="_blank" rel="nofollow noopener noreferrer">lista</a>. Por ejemplo:
> 
> *   Elemento 1
> *   Elemento 2
> *   Elemento 3

Para obtener más información, visite el <a href="https://en.wikipedia.org/wiki/Bullet_(typography" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

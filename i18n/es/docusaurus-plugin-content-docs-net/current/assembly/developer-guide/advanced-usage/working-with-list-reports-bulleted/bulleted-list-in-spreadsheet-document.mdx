## Lista con viñetas en un documento de Microsoft Excel {#bulleted-list-in-microsoft-excel-document}

### Creación de una lista con viñetas {#creating-a-bulleted-list}

Siga los pasos indicados a continuación para insertar una lista con viñetas en Microsoft Excel 2013.  
La inserción de una lista con viñetas en Microsoft Excel difiere de la forma en que se hace en Microsoft Word. Además, existen dos métodos para aplicar listas con viñetas en Microsoft Excel:

*   Lista dentro de la celda
*   Lista en varias celdas

Siga los pasos indicados a continuación para crear la plantilla de lista dentro de la celda

1.  Agregue un nuevo libro.
2.  Haga clic en la pestaña **Insertar** (en la barra superior).
3.  Agregue el símbolo de viñeta haciendo clic en el icono **Símbolo**.
4.  Guarde el documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere compartir la información de los productos con los siguientes requisitos clave:

*   El informe debe mostrar todos los productos en formato de lista con viñetas.
*   El informe debe generarse en un documento de hoja de cálculo.

### Sintaxis a agregar y evaluar por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

**Lista dentro de la celda**

```csharp
We provide support for the following products:
<<foreach [in products]>>
-          <<[ProductName]>><</foreach>>
```

**Lista de varias celdas**

```csharp
We provide support for the following products:
<<foreach [in products]>>-          <<[ProductName]>>
```

cierra el bucle `foreach` en la siguiente columna

```csharp
<</foreach>>
```

## Lista con viñetas en documento de hoja de cálculo de OpenOffice {#bulleted-list-in-openoffice-spreadsheet-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Spreadsheet (ODS) es un formato de documento de hoja de cálculo que puede utilizarse como alternativa a los formatos Microsoft Excel (XLS/XLSX). Dado que ODS no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) que permiten crear, abrir, editar y guardar documentos en este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODS, consulte el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema no recrearemos una plantilla para generar un informe con lista de viñetas en formato ODS, sino que guardaremos la plantilla ya creada en formato ODS mediante Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creamos en el tema anterior.
2.  Haga clic en "Archivo" y seleccione "Guardar como".
3.  En el menú desplegable "Tipo de archivo", seleccione "OpenDocument Spreadsheet".
4.  Haga clic en "Guardar".

### Plantilla e informe ODS en Apache OpenOffice {#ods-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODS entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODS creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODS generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

## Lista con viñetas en un documento de texto {#bulleted-list-in-text-document}


:::info
Esta función es compatible con la versión 17.04 o superior
:::


### Creación de una lista con viñetas {#creating-a-bulleted-list}

Siga los siguientes pasos para insertar una lista con viñetas en un documento de texto.

1.  Para agregar una lista con viñetas, utilice • como viñeta para cada elemento de la lista.
2.  Guarde el documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, debe cumplir con los siguientes requisitos clave:

*   El informe debe mostrar todos los productos en formato de lista con viñetas.
*   El informe debe generarse en formato de documento de texto.

### Adición de la sintaxis que será evaluada por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<<foreach [in products]>>•	<<[ProductName]>>
<</foreach>>

```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="/es/net/assembly/developer-guide/basic-usage/working-with-groupdocs.assembly-engine/">Trabajar con el motor GroupDocs.Assembly</a>.
:::

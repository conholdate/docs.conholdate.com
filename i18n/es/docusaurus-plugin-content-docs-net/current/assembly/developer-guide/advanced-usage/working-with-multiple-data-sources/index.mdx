## Soporte explícito para múltiples orígenes de datos {#explicit-support-for-multiple-data-sources}

Mediante la sobrecarga **DocumentAssembler.AssembleDocument**, el usuario puede hacer referencia a múltiples objetos de origen de datos y a sus miembros dentro de la plantilla. Es obligatorio especificar nombres únicos para todos los orígenes de datos.

## Parámetros {#parameters}

### DataSources (Orígenes de datos) {#datasources}

Una matriz de objetos de origen de datos, como **object[] dataSources**.

### DataSourceNames (Nombres de orígenes de datos) {#datasourcenames}

Una matriz de nombres utilizados para hacer referencia a los objetos de origen de datos dentro de la plantilla, como **string[] dataSourceNames**.

## Generación de informe en documento de Microsoft Excel {#generating-report-in-microsoft-excel-document}

### Creación de una plantilla {#creating-a-template}

1.  Inserte la forma deseada para mostrar la imagen en ella.
2.  Vaya a la pestaña Insertar y seleccione una forma haciendo clic en el icono de Forma.
3.  Agregue una lista con viñetas en el lugar donde desee.
4.  Guarde su documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere generar un informe que obtenga datos de dos fuentes de datos distintas (por ejemplo, XML, JSON). El informe debe mostrar la siguiente información:

*   Nombre y foto del cliente
*   Lista de productos

## Generación del informe en un documento de hoja de cálculo de OpenOffice {#generating-report-in-openoffice-spreadsheet-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Text (ODT) es un formato de documento de procesamiento de textos que puede utilizarse como alternativa a los formatos de documento de Microsoft Word (DOC/DOCX). Dado que ODT no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODT, visite <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">el artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla para generar un informe en formato ODT. En su lugar, guardaremos la plantilla existente en formato ODT utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos que se indican a continuación:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en "Archivo" y seleccione "Guardar como".
3.  Seleccione "Texto OpenDocument" en el menú desplegable "Tipo de archivo de guardado".
4.  Haga clic en "Guardar".

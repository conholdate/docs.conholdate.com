## Maestro-Detalle en Tabla en un Documento de Microsoft PowerPoint {#in-table-master-detail-in-microsoft-powerpoint-document}

### Creación de una vista maestro-detalle dentro de una tabla {#creating-a-in-table-master-detail}

Practicando los siguientes pasos, puedes crear una plantilla maestro-detalle en tabla en Microsoft PowerPoint 2013.

1.  Añadir una nueva diapositiva de presentación.
2.  Haga clic en el documento donde desea agregar la tabla.
3.  Presione la pestaña "Insertar" para insertar la tabla.
4.  |  |  |  |  | |---|---|---|---| |  |  |  |  |
5.  Guardar la plantilla.

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar los precios totales de los pedidos de los clientes y el precio de cada producto por separado, con los siguientes requisitos clave:

*   El informe debe mostrar a cada cliente junto con el precio total de sus pedidos.
*   También debe mostrar cada producto individual ordenado por los clientes.
*   Debe mostrar la suma de los precios de los pedidos.
*   Debe representar toda la información en forma de tabla.
*   El informe debe generarse en el Documento de Presentación.

## Maestro-Detalle en Tabla en documento de presentación de OpenOffice {#in-table-master-detail-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) que permiten crear, abrir, editar y guardar documentos en este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, consulte el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema no recrearemos una plantilla para generar un informe “Maestro-Detalle en Tabla” en formato ODP, sino que guardaremos la plantilla existente en formato ODP utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente creada en el tema anterior.
2.  Haga clic en “Archivo” y seleccione “Guardar como”.
3.  En el menú desplegable “Guardar como tipo”, seleccione “Presentación de OpenDocument”.
4.  Haga clic en “Guardar”.

### Plantilla e informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

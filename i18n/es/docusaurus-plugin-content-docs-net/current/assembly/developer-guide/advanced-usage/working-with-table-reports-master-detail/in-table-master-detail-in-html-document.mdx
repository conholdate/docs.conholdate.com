## Master-Detalle en Tabla dentro de un Documento HTML {#in-table-master-detail-in-html-document}

### Requisito de Informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar los precios totales de los pedidos de los clientes y el precio de cada producto por separado, con los siguientes requisitos clave:

*   El informe debe mostrar a cada cliente junto con el precio total de sus pedidos.
*   También debe mostrar cada producto individual ordenado por los clientes.
*   Debe mostrar la suma de los precios de los pedidos.
*   Debe representar toda la información en forma tabular.
*   El informe debe generarse en un documento HTML.

### Añadiendo la sintaxis que será evaluada por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

<table className="tbl1">
	<tbody>
		<tr>
			<td colspan="2"> &lt;&lt;foreach [in customers]&gt;&gt; &lt;&lt;foreach [in Order]&gt;&gt; &lt;&lt;/foreach&gt;&gt; &lt;&lt;/foreach&gt;&gt;</td>
		</tr>
		<tr>
			<td>Customer</td>
			<td>Order Price</td>
		</tr>
		<tr>
			<td>&lt;&lt;[CustomerName]&gt;&gt;</td>
			<td>&lt;&lt;[Order.Sum(c => c.Price)]&gt;&gt;</td>
		</tr>
		<tr>
			<td colspan="2">  &lt;&lt;[Product.ProductName]&gt;&gt; &lt;&lt;[Price]&gt;&gt;</td>
		</tr>
		<tr>
			<td>Total:</td>
			<td>&lt;&lt;[Sum( m => m.Order.Sum( c => c.Price))]&gt;&gt;</td>
		</tr>
	</tbody>
</table>

## Generación de códigos de barras en Microsoft Excel {#barcode-generation-in-microsoft-spreadsheet}

### Sintaxis de plantilla {#template-syntax}

*   Agregue un cuadro de texto en su plantilla en el lugar donde desea insertar una imagen de código de barras.
*   Agregue la siguiente sintaxis:

```csharp
<<barcode [customer.Barcode] -qr>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="/es/net/assembly/developer-guide/basic-usage/working-with-groupdocs.assembly-engine/">Trabajar con el motor GroupDocs.Assembly</a>
:::

## Inserción dinámica de códigos de barras {#inserting-barcodes-dynamically}

Puede insertar imágenes de códigos de barras en sus documentos de forma dinámica mediante etiquetas de código de barras. Para declarar una imagen de código de barras insertada dinámicamente dentro de su plantilla, realice los siguientes pasos:

1.  Agregue un cuadro de texto en su plantilla en el lugar donde desea insertar la imagen del código de barras.
2.  Establezca atributos comunes de imagen, como tamaño, ángulo de rotación y otros, para el cuadro de texto, de modo que este último tenga la apariencia de una imagen de código de barras sin barras ni texto.
3.  Especifique una etiqueta de código de barras dentro del cuadro de texto utilizando la siguiente sintaxis:

```csharp
<<barcode [barcode_expression] -barcode_type>>
```

Durante el tiempo de ejecución, se evalúa una expresión declarada dentro de una etiqueta de código de barras, su valor se codifica utilizando el tipo de código de barras especificado y el cuadro de texto que contiene la etiqueta se rellena con una imagen de código de barras correspondiente. A continuación, la etiqueta se elimina del cuadro de texto.

### Escalado de símbolos de códigos de barras {#scaling-barcode-symbols}

Puede escalar los símbolos de códigos de barras de las imágenes insertadas dinámicamente especificando el atributo *scale* para una etiqueta de código de barras de la siguiente manera:

```csharp
<<barcode [barcode_expression] -barcode_type scale="scaling_hint">>
```

Un atributo de escala afecta el ancho y la altura de un símbolo de código de barras 2D, así como el ancho de un símbolo de código de barras 1D. El valor del atributo de escala representa el porcentaje de escalado del símbolo de código de barras.  
Sin embargo, el valor del atributo de escala no es más que una indicación. Es decir, el escalado real del símbolo de código de barras puede no ser exactamente igual al especificado. La razón es que el escalado podría dañar el símbolo de código de barras hasta el punto de hacerlo ilegible para los escáneres de códigos de barras. Por ello, el motor calcula el escalado real de modo que evite tales daños, intentando al mismo tiempo aproximarse lo máximo posible al escalado especificado.

### Configuración del escalado inicial de los símbolos de código de barras {#configuring-initial-scaling-of-barcode-symbols}

Puede influir en el escalado inicial de todos los símbolos de código de barras generados por una única instancia de **DocumentAssembler** mediante las propiedades **DocumentAssembler.BarcodeSettings.BaseXDimension** y **DocumentAssembler.BarcodeSettings.BaseYDimension**. Estas propiedades definen, respectivamente, el ancho y la altura mínimos de la unidad de módulos del código de barras. Por ejemplo, para que todos los símbolos de código de barras sean el doble de grandes de forma predeterminada, puede utilizar el siguiente código:

```csharp
DocumentAssembler assembler = new DocumentAssembler();
assembler.BarcodeSettings.BaseXDimension *= 2f;
assembler.BarcodeSettings.BaseYDimension *= 2f;
```

Los valores de las propiedades **DocumentAssembler.BarcodeSettings.BaseXDimension** y **DocumentAssembler.BarcodeSettings.BaseYDimension** se miden en las unidades definidas por la propiedad **DocumentAssembler.BarcodeSettings.GraphicsUnit**.


:::warning
Cuando se proporciona el atributo `scale` para una etiqueta de código de barras, las dimensiones reales en x e y se calculan mediante el motor como el porcentaje correspondiente de las dimensiones base en x e y.
:::


### Configuración de la altura de los símbolos de códigos de barras 1D {#setting-height-of-1d-barcode-symbols}

La altura de un símbolo de código de barras 1D no se ve afectada por el atributo `scale` de la etiqueta de código de barras correspondiente. Sin embargo, puede configurar la altura aplicando el atributo `barHeight`, como se muestra a continuación:

```csharp
<<barcode [barcode_expression] -barcode_type barHeight="height">>
```

El valor del atributo `barHeight` especifica el porcentaje de la altura total de la imagen del código de barras. Por ejemplo, para establecer la altura de un símbolo de código de barras igual a dos tercios de la altura total de su imagen de código de barras, puede utilizar la siguiente etiqueta de código de barras:

```csharp
<<barcode ["736192"] -codabar barHeight="67">>
```

### Personalización de los colores de primer plano y de fondo de las imágenes de código de barras {#customizing-fore-and-back-colors-of-barcode-images}

El color de primer plano de una imagen de código de barras insertada dinámicamente se utiliza para representar el símbolo y el texto del código de barras. Este color se deriva de la fuente de la etiqueta de código de barras correspondiente. El color de fondo de la imagen se deriva del relleno sólido del cuadro de texto que contiene la etiqueta.

### Personalización de la fuente y la posición del texto del código de barras {#customizing-font-and-placement-of-barcode-text}

La fuente utilizada para representar el texto del código de barras en una imagen insertada dinámicamente obtiene los siguientes atributos de la fuente de la etiqueta de código de barras correspondiente:

*   Nombre
*   Tamaño
*   Estilo (negrita y cursiva)
*   Color

La posición del texto del código de barras en una imagen insertada dinámicamente —a la izquierda, a la derecha o centrada— queda definida por la alineación del texto de la etiqueta de código de barras correspondiente.

### Uso de la autocorrección del texto del código de barras {#using-barcode-text-auto-correction}

Para una imagen de código de barras insertada dinámicamente, el motor corrige automáticamente el texto del código de barras si este no cumple con la especificación del código de barras, siempre que sea posible.


:::warning
La autocorrección no es posible para códigos de barras de algunos tipos, como Databar.
:::


Para deshabilitar la autocorrección y evitar que el motor genere una excepción en caso de un texto de código de barras no válido, puede establecer la propiedad **DocumentAssembler.BarcodeSettings.UseAutoCorrection** en `false`.

### Configuración de la resolución de la imagen del código de barras {#setting-barcode-image-resolution}

Puede establecer la resolución horizontal y vertical para las imágenes de códigos de barras insertadas dinámicamente, expresada en DPI (puntos por pulgada), mediante la propiedad **DocumentAssembler.BarcodeSettings.Resolution**. Por ejemplo, para establecer tanto la resolución horizontal como la vertical en 300 DPI, puede utilizar el siguiente código:

```csharp
DocumentAssembler assembler = new DocumentAssembler();
assembler.BarcodeSettings.Resolution = 300;
```


:::warning
De forma predeterminada, la resolución horizontal y vertical de las imágenes de códigos de barras insertadas dinámicamente es de 96 DPI.
:::

La API de GroupDocs.Assembly para .NET admite la eliminación de párrafos que quedan vacíos tras la eliminación o sustitución por valores vacíos de las etiquetas de sintaxis de plantilla. Se ha añadido un nuevo miembro **RemoveEmptyParagraphs** a <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassemblyoptions" target="_blank" rel="nofollow noopener noreferrer">DocumentAssemblyOptions</a>**.** Cuando esta nueva opción se aplica a las opciones <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a> mediante <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler/properties/options" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler.Options</a>, el motor elimina adicionalmente los párrafos vacíos.

GroupDocs.Assembly ofrece una funcionalidad destacada: la carga de documentos de plantilla HTML que hacen referencia a archivos de recursos externos, los cuales se ensamblan y guardan en formatos no HTML. 

Desde la versión 19.5, al cargar un documento HTML desde un archivo, su carpeta contenedora se utiliza como URI base para resolver las URIs relativas de los archivos de recursos externos a URIs absolutas de forma predeterminada, como se muestra en el siguiente ejemplo.

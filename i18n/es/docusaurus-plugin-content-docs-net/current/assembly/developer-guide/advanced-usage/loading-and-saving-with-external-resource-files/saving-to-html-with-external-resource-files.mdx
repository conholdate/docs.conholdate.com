Desde la versión 19.5, GroupDocs.Assembly ofrece una funcionalidad muy útil: el guardado de archivos de recursos externos cuando un documento ensamblado, cargado desde un formato no HTML, se guarda en formato HTML.

A partir de ahora, al guardar un documento ensamblado en un archivo HTML, de forma predeterminada, los archivos de recursos externos se almacenan en una carpeta cuyo nombre coincide con el nombre del archivo HTML (sin extensión) seguido del sufijo `\_files`. Esta carpeta se ubica en el mismo directorio que el archivo HTML. El siguiente ejemplo ilustra este escenario. El fragmento de código siguiente muestra cómo utilizar la API:

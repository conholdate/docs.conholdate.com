## Lista numerada multicolor en un documento de Microsoft PowerPoint {#multicolored-numbered-list-in-microsoft-powerpoint-document}

### Creación de una lista numerada multicolor {#creating-a-multicolored-numbered-list}

Siga los siguientes pasos para crear una plantilla de lista numerada multicolor en Microsoft PowerPoint 2013.

1.  En su documento, escriba una frase como: «Ofrecemos soporte para los siguientes productos:».
2.  Comience una lista numerada.
3.  Vaya a la pestaña «Diseño» y seleccione un color para convertir la lista en una lista coloreada.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere describir los servicios que ofrece con los siguientes requisitos clave:

*   El informe debe mostrar los productos en una lista numerada.
*   Debe resaltar los productos.
*   El informe debe generarse en un documento de presentación.

## Lista numerada multicolor en documento de presentación de OpenOffice {#multicolored-numbered-list-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) que permiten crear, abrir, editar y guardar documentos en este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, consulte el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no recrearemos la plantilla para generar un informe *Lista numerada multicolor* en formato ODP, sino que guardaremos la plantilla ya creada en formato ODP mediante Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente creada en el tema anterior.
2.  Haga clic en "Archivo" y seleccione "Guardar como".
3.  En el menú desplegable "Guardar como tipo", seleccione "Presentación de OpenDocument".
4.  Haga clic en "Guardar".

### Plantilla e informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODP entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

## Lista numerada multicolor en un documento de correo electrónico {#multicolored-numbered-list-in-email-document}

### Creación de una lista numerada multicolor {#creating-a-multicolored-numbered-list}

Siga los siguientes pasos para crear una plantilla de lista numerada multicolor en MS Outlook 2013.

1.  En su correo electrónico, escriba una frase como: «Ofrecemos soporte para los siguientes clientes:».
2.  Comience con una lista numerada.
3.  Vaya a la pestaña «Diseño» y seleccione un color para que la lista aparezca en colores.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere cumplir con los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar los productos en una lista numerada.
*   Debe resaltar los productos.
*   El informe debe generarse en un documento de presentación.

Utilizando GroupDocs.Assembly para .NET, puede fusionar celdas de tabla con contenidos textuales iguales dentro de sus informes de forma dinámica mediante etiquetas **cellMerge**. La sintaxis de una etiqueta **cellMerge** se define de la siguiente manera:

```
<<cellMerge -horz>>
```


:::warning
Un interruptor horizontal es opcional. Si el interruptor está presente, indica una operación de fusión de celdas en dirección horizontal. Si el interruptor no está presente, significa que se debe realizar una operación de fusión de celdas en dirección vertical (el valor predeterminado).
:::


Para que dos o más celdas de tabla contiguas se fusionen dinámicamente en cualquier dirección mediante el motor, deben cumplirse los siguientes requisitos:

*   Cada una de las celdas debe contener una etiqueta **cellMerge** que indique una operación de fusión de celdas en la misma dirección.
*   Cada una de las celdas no debe estar ya fusionada en otra dirección.
*   Las celdas deben tener contenidos textuales idénticos (ignorando los espacios en blanco iniciales y finales).

Considere la siguiente plantilla:

La etiqueta `cellMerge` solo funciona si `Variable1` y `Variable2` tienen los mismos valores.

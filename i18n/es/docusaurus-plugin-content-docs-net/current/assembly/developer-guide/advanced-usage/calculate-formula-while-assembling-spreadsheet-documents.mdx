*   Configurar la ruta de la plantilla del documento fuente
*   Configurar la ruta del informe de destino
*   Instanciar la clase DocumentAssembler
*   Establecer opciones, <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassemblyoptions" target="_blank" rel="nofollow noopener noreferrer">DocumentAssemblyOptions.UpdateFieldsAndFormulas</a>

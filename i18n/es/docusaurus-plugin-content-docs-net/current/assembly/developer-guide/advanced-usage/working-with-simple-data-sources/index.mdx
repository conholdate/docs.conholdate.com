## Soporte para fuentes de datos simples y autónomas {#support-simple-and-standalone-data-sources}

La API proporciona soporte para fuentes de datos autónomas y específicas para diversos tipos de datos, como JSON, XML, etc. El soporte está disponible actualmente para fuentes de datos XML, JSON y CSV.

## Lista común en un documento HTML {#common-list-in-html-document}

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere compartir los siguientes requisitos clave:

*   El informe debe mostrar la imagen y el nombre de varios clientes.
*   El informe debe generarse en formato de documento HTML.

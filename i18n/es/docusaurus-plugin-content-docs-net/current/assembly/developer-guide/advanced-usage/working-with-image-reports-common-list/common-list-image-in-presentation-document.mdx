## Lista común en un documento de Microsoft PowerPoint {#common-list-in-microsoft-powerpoint-document}

### Creación de una imagen de lista común {#creating-a-common-list-image}

Siga los siguientes pasos para crear una plantilla de lista común en Microsoft PowerPoint 2013:

1.  Cree una nueva diapositiva de presentación.
2.  Agrega dos formas para contener una imagen y un nombre.
3.  Guarda tu documento.

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información de los clientes con los siguientes requisitos clave:

*   Un informe debe mostrar la imagen y el nombre de varios clientes.
*   Debe generarse un informe en el documento de presentación.

### Agregando sintaxis que será evaluada por el motor de GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}


:::warning
No existe una forma de utilizar una imagen dentro de una etiqueta `foreach` en Microsoft PowerPoint.
:::


```csharp
<<foreach [in customers]>><<[CustomerName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.

## Lista común en documento de presentación de OpenOffice {#common-list-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint Document (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de «Lista común» en formato ODP. En su lugar, guardaremos la plantilla existente en formato ODP utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los siguientes pasos:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «Texto OpenDocument» en el menú desplegable «Tipo de archivo».
4.  Haga clic en «Guardar».

### Plantilla y informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para verificar la compatibilidad de ODP entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las siguientes pruebas:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

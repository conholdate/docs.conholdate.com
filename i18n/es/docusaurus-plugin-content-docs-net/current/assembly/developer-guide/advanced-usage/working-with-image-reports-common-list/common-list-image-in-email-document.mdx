## Lista común en el documento de correo electrónico {#common-list-in-email-document}

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige compartir los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico
*   El informe debe mostrar los nombres de varios clientes

### Sintaxis que debe evaluarse mediante GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
<<foreach [in customers]>><<[CustomerName]>>
<</foreach>>
```

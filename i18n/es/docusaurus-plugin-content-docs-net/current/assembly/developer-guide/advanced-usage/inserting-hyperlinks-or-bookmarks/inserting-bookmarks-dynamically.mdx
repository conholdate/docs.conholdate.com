## Inserción dinámica de hipervínculos {#inserting-hyperlinks-dynamically}

### Inserción dinámica de marcadores para documentos de procesamiento de textos y correos electrónicos con cuerpos en HTML y RTF {#dynamic-insertion-of-bookmarks-for-word-processing-documents-and-emails-with-html-and-rtf-bodies}

Puede insertar marcadores en sus informes de forma dinámica utilizando etiquetas de marcador. La sintaxis de una etiqueta de marcador se define de la siguiente manera:

```csharp
<<bookmark [bookmark_expression]>>
bookmarked_content
<</bookmark>>
```

Aquí, **bookmark\_expression** define el nombre de un marcador que se insertará en tiempo de ejecución. Esta expresión es obligatoria y debe devolver un valor no vacío. Al generar un informe, **bookmark\_expression** se evalúa y su resultado se utiliza para construir un inicio y un final de marcador que reemplazan, respectivamente, las etiquetas de apertura y cierre correspondientes del marcador.


:::warning
Una etiqueta de marcador no se puede utilizar dentro de un gráfico.
:::

## Inserción dinámica de hipervínculos {#inserting-hyperlinks-dynamically}

Con GroupDocs.Assembly, puede insertar hipervínculos en sus informes de forma dinámica mediante etiquetas de enlace. La sintaxis de una etiqueta de enlace se define de la siguiente manera:

```csharp
<<link [uri_expression][display_text_expression]>>
```

Aquí, **uri_expression** define la URI de un hipervínculo que se insertará dinámicamente. Esta expresión es obligatoria y debe devolver un valor no vacío. Por su parte, **display_text_expression** define el texto que se mostrará para el hipervínculo. Esta expresión es opcional. Si se omite o devuelve un valor vacío, durante el tiempo de ejecución se utilizará el valor de **uri_expression** también como texto de visualización. Los valores de **uri_expression** y **display_text_expression** pueden ser de cualquier tipo. Durante el tiempo de ejecución, se invoca **Object.ToString()** para obtener las representaciones textuales de los valores de estas expresiones, lo cual resulta útil, por ejemplo, para expresiones de tipos como **Uri**, al construir un informe. En ese momento, **uri_expression** y **display_text_expression** se evalúan y sus resultados se utilizan para construir un hipervínculo que reemplaza la etiqueta de enlace correspondiente.

:::info
Esta función es compatible con la versión 19.11 o superior.
:::


#### Inserción de vínculos en documentos de procesamiento de texto y correos electrónicos {#insertion-of-links-for-word-processing-documents-and-emails}

También puede insertar vínculos a marcadores en sus informes de forma dinámica mediante etiquetas de vínculo. La sintaxis de una etiqueta de vínculo se define de la siguiente manera:

```csharp
<<link [uri_or_bookmark_expression][display_text_expression]>>
```

Aquí, **uri\_or\_bookmark\_expression** define la URI o el nombre de un marcador dentro del mismo documento para insertar dinámicamente un hipervínculo. Esta expresión es obligatoria y debe devolver un valor distinto de vacío. Por su parte, **display\_text\_expression** define el texto que se mostrará para el hipervínculo. Esta expresión es opcional. Si se omite o devuelve un valor vacío, durante el tiempo de ejecución se utilizará el valor de **uri\_or\_bookmark\_expression** también como texto de visualización.


:::warning
* Los valores tanto de `uri_or_bookmark_expression` como de `display_text_expression` pueden ser de cualquier tipo. En tiempo de ejecución, se invoca `Object.ToString()` para obtener las representaciones textuales de los valores de estas expresiones, lo cual resulta útil, por ejemplo, para expresiones de tipos como `Uri`. Al generar un informe, se evalúan `uri_or_bookmark_expression` y `display_text_expression`, y sus resultados se utilizan para construir un hipervínculo que reemplaza la etiqueta de enlace correspondiente. Si `uri_or_bookmark_expression` devuelve el nombre de una marca de posición (bookmark) en el mismo documento, el hipervínculo navega hacia dicha marca de posición. De lo contrario, el hipervínculo navega hacia el recurso externo correspondiente.

* Una etiqueta de enlace no puede utilizarse dentro de un gráfico.
:::


#### Inserción de enlaces a celdas en documentos de hojas de cálculo {#insertion-of-links-to-cells-for-spreadsheet-documents}

En los documentos de hojas de cálculo, el comportamiento de las etiquetas de enlace se modifica de la siguiente manera: si una expresión definida dentro de una etiqueta de enlace se evalúa como una referencia a una celda o rango de celdas durante el tiempo de ejecución, la etiqueta se reemplaza por un enlace a la celda o rango de celdas correspondiente.

La siguiente tabla describe los formatos admitidos para referencias a celdas y rangos de celdas.

| Descripción | Formato | Ejemplo |
| --- | --- | --- |
| Referencia a una celda dentro de la misma hoja de cálculo | nombre\_celda | A1 |
| Referencia a una celda en otra hoja de cálculo | nombre\_hoja!nombre\_celda | Hoja1!A1 |
| Referencia a un rango de celdas dentro de la misma hoja de cálculo | celda\_inicial:celda\_final | A1:B2 |
| Referencia a un rango de celdas en otra hoja de cálculo | nombre\_hoja!celda\_inicial:celda\_final | Hoja1!A1:B2 |

A continuación se muestra un ejemplo de sintaxis, si se requiere insertar un enlace a la celda A1:

```csharp
<<link ["A1"] ["Home"]>>
```

#### Inserción de enlaces a diapositivas para documentos de presentación {#insertion-of-links-to-slides-for-presentation-documents}

En los documentos de presentación, el comportamiento de las etiquetas de enlace se modifica de la siguiente manera: si una expresión definida dentro de una etiqueta de enlace se evalúa como un valor “SlideN”, donde N es un índice basado en 1 de una diapositiva dentro del mismo documento de presentación, entonces la etiqueta se reemplaza por un enlace a la diapositiva correspondiente durante el tiempo de ejecución.

Consulte el siguiente ejemplo de sintaxis:

```csharp
<<link ["Slide1"] ["Home"]>>
```

GroupDocs.Assembly ofrece una potente funcionalidad para cambiar el formato de archivo de destino de un documento ensamblado mediante la extensión del archivo o mediante una especificación explícita. La API <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly</a> permite cambiar el formato de archivo de destino al ensamblar los siguientes formatos de archivo:

*   Documentos de procesamiento de texto
*   Documentos de hojas de cálculo
*   Documentos de presentación
*   Documentos de correo electrónico
*   Documentos de texto 

Los formatos de archivo de salida compatibles, según el formato de archivo de entrada, se pueden consultar en [esta página](/net/assembly/getting-started/introducing-groupdocs.assembly-for-.net/#supported-output-file-formats-depending-on-input-file-formats).

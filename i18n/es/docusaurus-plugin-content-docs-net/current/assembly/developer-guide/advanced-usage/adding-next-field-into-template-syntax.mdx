## Agregando sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

**Sintaxis de plantilla**

```csharp
We provide support for the following products:
. <<foreach [in products]>><<next>><<[ProductName]>>
<</foreach>>
```

## La Receta {#the-recipe}

*   Configurar la ruta de la plantilla del documento fuente
*   Configurar la ruta del informe de destino
*   Instanciar la clase <a href="https://reference.groupdocs.com/net/assembly/groupdocs.assembly/documentassembler" target="_blank" rel="nofollow noopener noreferrer">DocumentAssembler</a>
*   Generar el informe

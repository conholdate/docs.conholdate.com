## Lista en párrafo en documento de correo {#in-paragraph-list-in-email-document}


:::info
Esta función es compatible con la versión 17.8.0 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige compartir los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   Una línea descriptiva o informativa, como: «Ofrecemos soporte para los siguientes productos:».
*   Mostrar todos los productos junto con la frase anterior.

### Adición de sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<<foreach [in products]>><<[IndexOf() != 0 ? ", " : ""]>>
<<[ProductName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.
:::

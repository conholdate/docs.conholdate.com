## Lista dentro de un párrafo en un documento de Microsoft PowerPoint {#in-paragraph-list-in-microsoft-powerpoint-document}

### Creación de una lista dentro de un párrafo {#creating-a-in-paragraph-list}

Siga los siguientes pasos para crear una plantilla de lista dentro de un párrafo en Microsoft PowerPoint 2013.

1.  Añada una nueva diapositiva a la presentación.
2.  Escriba una frase, por ejemplo: «Ofrecemos soporte para los siguientes productos:».
3.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere describir los servicios que ofrece cumpliendo con los siguientes requisitos clave:

*   Una línea descriptiva o informativa, como: «Ofrecemos soporte para los siguientes productos:».
*   Mostrar todos los productos junto con la frase anterior.
*   El informe debe generarse en un documento de presentación.

## Lista dentro de un párrafo en un documento de presentación de OpenOffice {#in-paragraph-list-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint Document (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no recrearemos la rueda para generar una nueva plantilla que produzca un informe con una «lista dentro de un párrafo» en formato ODP. En cambio, guardaremos la plantilla existente en formato ODP utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos que se indican a continuación:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «OpenDocument Presentation» en el menú desplegable «Guardar como tipo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para verificar la compatibilidad de ODP entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las siguientes pruebas:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

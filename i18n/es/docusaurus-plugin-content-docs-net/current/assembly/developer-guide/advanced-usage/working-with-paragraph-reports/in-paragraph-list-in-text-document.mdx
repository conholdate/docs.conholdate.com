## Lista en párrafo en documento de texto {#in-paragraph-list-in-text-document}


:::info
Esta función es compatible con la versión 17.03 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige describir los servicios que proporciona con los siguientes requisitos clave:

*   Una línea descriptiva o informativa como “Proporcionamos soporte para los siguientes productos:”.
*   Mostrar todos los productos junto con la frase anterior.
*   El informe debe generarse en un documento de texto.

### Adición de sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<<foreach [in products]>><<[IndexOf() != 0 ? ", " : ""]>>
<<[ProductName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="/es/net/assembly/developer-guide/basic-usage/working-with-groupdocs.assembly-engine/">Trabajar con el motor GroupDocs.Assembly</a>.
:::

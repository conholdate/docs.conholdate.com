## Lista dentro de párrafo en un documento de Microsoft Excel {#in-paragraph-list-in-microsoft-excel-document}

### Creación de una lista dentro de párrafo {#creating-a-in-paragraph-list}

Siga los pasos siguientes para crear una plantilla de lista dentro de párrafo en MS Excel 2013.

1.  Añada un nuevo libro de trabajo.
2.  Escriba una frase, por ejemplo «Proporcionamos soporte para los siguientes productos:», en una única columna.
3.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere describir los servicios que ofrece con los siguientes requisitos clave:

*   Una línea descriptiva o informativa, como «Proporcionamos soporte para los siguientes productos:».
*   Mostrar todos los productos junto con la frase anterior.
*   El informe debe generarse en un documento de hoja de cálculo.

## Lista dentro de un párrafo en un documento de hoja de cálculo de OpenOffice {#in-paragraph-list-in-openoffice-spreadsheet-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Spreadsheet (ODS) es un formato de documento de hoja de cálculo que puede utilizarse como alternativa a los formatos Microsoft Excel Document (XLS/XLSX). Dado que ODS no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar documentos en este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODS, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe con una «lista dentro de un párrafo» en formato ODS. En su lugar, guardaremos la plantilla existente en formato ODS utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos que se indican a continuación:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «OpenDocument Spreadsheet» en el menú desplegable «Guardar como tipo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODS en Apache OpenOffice {#ods-template-and-report-in-apache-openoffice}

Para verificar la compatibilidad de ODS entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las siguientes pruebas:

*   Abrimos la plantilla ODS creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODS generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

## Lista numerada en un documento de Microsoft Word {#numbered-list-in-microsoft-word-document}

### Creación de una lista numerada {#creating-a-numbered-list}

Siga los pasos siguientes para crear una plantilla de lista numerada en MS Word 2013.

1.  En su documento, escriba una frase como: «Ofrecemos soporte para los siguientes productos:».
2.  Inicie la lista numerada.
3.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere describir los servicios que ofrece con los siguientes requisitos clave:

*   El informe debe mostrar los productos en la lista numerada.
*   El informe debe generarse en un documento de procesamiento de textos.

### Adición de sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
1.	<<foreach [in products]>><<[ProductName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.

## Lista numerada en documento OpenOffice {#numbered-list-in-openoffice-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Text (ODT) es un formato de documento de procesamiento de textos que puede utilizarse como alternativa a los formatos de documento de Microsoft Word (DOC/DOCX). Dado que ODT no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODT, visite el <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de 'lista numerada' en formato ODT. En su lugar, guardaremos la plantilla existente en formato ODT utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creamos en el tema anterior.
2.  Haga clic en "Archivo" y seleccione "Guardar como".
3.  Seleccione "Texto OpenDocument" en el menú desplegable "Guardar como tipo".
4.  Haga clic en "Guardar".

## Reinicio de numeración en lista numerada anidada {#numbering-restart-in-nested-numbered-list}


:::info
Esta función es compatible con la versión 19.7 o superior.
:::



El motor GroupDocs.Assembly permite reiniciar dinámicamente la numeración de listas dentro de sus documentos mediante las etiquetas *&lt;&lt;restartNum&gt;&gt;*. En particular, esta funcionalidad resulta útil al trabajar con una lista numerada anidada dentro de un bloque de datos.  

Supongamos que seleccionamos las clases *Order* y *Service*, tal como se definen en los *Objetos personalizados* de nuestro caso de uso empresarial.

<a href="https://gist.github.com/GroupDocsGists/cd8768711ff88414192c3f50a9b7c918" target="_blank" rel="nofollow noopener noreferrer">Ver ejemplo de código en GitHub Gist</a>

Dado que *orders* es una enumeración de instancias de la clase *Order*, puede intentar utilizar la siguiente plantilla para generar en un único documento la información relativa a varios pedidos.

```csharp
<<foreach [in orders]>><<[Customer.CustomerName]>> (<<[Customer.CustomerContactNumber]>>)
1.	<<foreach [in Services]>><<[ServiceName]>>
<</foreach>><</foreach>>
```

El informe generado tendrá el siguiente aspecto:

```
Jane Doe (+9211874)
	1.	Regular Cleaning
	2.	Oven Cleaning
John Smith (+458789)
	3.	Regular Cleaning
	4.	Oven Cleaning
	5.	Carpet Cleaning
John Smith (+458789)
	6.	Regular Cleaning
	7.	Carpet Cleaning
John Smith (+458789)
	8.	Oven Cleaning
```

Sin embargo, habría una única lista numerada para todos los pedidos, lo cual no es aplicable en este escenario. Por lo tanto, puedes hacer que la numeración de la lista se reinicie para cada pedido colocando un `*`&lt;&lt;`restartNum`&gt;&gt;* etiqueta en su plantilla antes de una correspondiente *&lt;&lt;`foreach`&gt;&gt;* etiquetar de la siguiente manera:

```csharp
<<foreach [in orders]>><<[ Customer.CustomerName]>> (<<[Customer.CustomerContactNumber]>>)
1.	<<restartNum>><<foreach [in Services]>><<[ServiceName]>>
<</foreach>><</foreach>>
```

 Luego, el informe generado tendrá el siguiente aspecto:

```
Jane Doe (+9211874)
	1.	Regular Cleaning
	2.	Oven Cleaning
John Smith (+458789)
	1.	Regular Cleaning
	2.	Oven Cleaning
	3.	Carpet Cleaning
John Smith (+458789)
	1.	Regular Cleaning
	2.	Carpet Cleaning
John Smith (+458789)
	1.	Oven Cleaning
```

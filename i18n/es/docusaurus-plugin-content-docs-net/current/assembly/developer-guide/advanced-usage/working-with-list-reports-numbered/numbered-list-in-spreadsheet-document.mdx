## Lista numerada en un documento de Microsoft Excel {#numbered-list-in-microsoft-excel-document}

### Creación de una lista numerada {#creating-a-numbered-list}

Siga los pasos indicados a continuación para crear una plantilla de lista numerada en MS Excel 2013.  
Puede crear dos tipos de lista numerada en Microsoft Excel.

*   Lista en la celda
*   Lista en varias celdas

Siga los pasos indicados a continuación para crear la plantilla **Lista en la celda**

1.  Agregue un nuevo libro.
2.  Escriba una oración, por ejemplo «Proporcionamos soporte para los siguientes productos:», en una sola celda y agregue la sintaxis correspondiente.
3.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere describir los servicios que ofrece con los siguientes requisitos clave:

*   El informe debe mostrar los productos en una lista numerada.
*   El informe debe generarse en un documento de hoja de cálculo.

### Adición de sintaxis que será evaluada por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

**Lista en la celda**

```csharp
"We provide support for the following products:<<foreach [in products]>>
<<[NumberOf()]>>.         <<[ProductName]>><</foreach>>"
```

**Lista de varias celdas**

```csharp
<<foreach [in products]>><<[NumberOf()]>>.         <<[ProductName]>>
```

y cerrar el `foreach` en la siguiente columna,

```csharp
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.
:::

## Lista numerada en documento de hoja de cálculo de OpenOffice {#numbered-list-in-openoffice-spreadsheet-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Spreadsheet (ODS) es un formato de documento de hoja de cálculo que puede utilizarse como alternativa a los formatos Microsoft Excel (XLS/XLSX). Dado que ODS no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODS, visite la <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">artículo de Wikipedia</a>.

En este tema, no vamos a reinventar la rueda para recrear una plantilla que genere un informe de 'lista numerada' en formato ODS. En su lugar, guardaremos la plantilla existente en formato ODS utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creamos en el tema anterior.
2.  Haga clic en "Archivo" y seleccione "Guardar como".
3.  Seleccione "OpenDocument Spreadsheet" en el menú desplegable "Guardar como tipo".
4.  Haga clic en "Guardar".

### Plantilla e informe ODS en Apache OpenOffice {#ods-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODS entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODS creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODS generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

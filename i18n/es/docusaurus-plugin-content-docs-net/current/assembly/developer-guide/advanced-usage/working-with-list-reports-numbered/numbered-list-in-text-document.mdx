## Lista numerada en un documento de texto {#numbered-list-in-text-document}

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige describir los servicios que proporciona con los siguientes requisitos clave:

*   El informe debe mostrar los productos en la lista numerada.
*   El informe debe generarse en el documento de texto.

### Añadir sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<<foreach [in products]>><<[NumberOf()]>>. <<[ProductName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.
:::

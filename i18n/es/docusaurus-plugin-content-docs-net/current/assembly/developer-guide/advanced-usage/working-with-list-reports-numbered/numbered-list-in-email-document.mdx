## Lista numerada en un documento de correo electrónico {#numbered-list-in-email-document}

### Creación de una lista numerada {#creating-a-numbered-list}

Siga los pasos siguientes para crear una plantilla de lista numerada en Microsoft Outlook 2013.

1.  Crear un nuevo correo electrónico.
2.  Escriba una frase como: «Ofrecemos soporte para los siguientes clientes:».
3.  Iniciar la lista numerada.
4.  Guardar la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar los productos en una lista numerada.

### Adición de sintaxis que será evaluada por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
We provide support for the following products:
<<foreach [in products]>><<[NumberOf()]>>. <<[ProductName]>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="https://docs.groupdocs.com/assembly/net/working-with-groupdocs-assembly-engine/" target="_blank" rel="nofollow noopener noreferrer">Trabajar con el motor GroupDocs.Assembly</a>.

## Reinicio de numeración en lista numerada anidada {#numbering-restart-in-nested-numbered-list}


:::info
Esta función es compatible con la versión 19.7 o superior.
:::



El motor GroupDocs.Assembly permite reiniciar dinámicamente la numeración de listas dentro de sus documentos mediante las etiquetas *&lt;&lt;restartNum&gt;&gt;*. En particular, esta funcionalidad resulta útil al trabajar con una lista numerada anidada dentro de una banda de datos.

Supongamos que seleccionamos las clases *Order* y *Service*, tal como se definen en los *Objetos personalizados* de nuestro caso de uso empresarial.

<a href="https://gist.github.com/GroupDocsGists/cd8768711ff88414192c3f50a9b7c918" target="_blank" rel="nofollow noopener noreferrer">Ver ejemplo de código en GitHub Gist</a>

Dado que *orders* es una enumeración de instancias de *Order*, puede intentar utilizar la siguiente plantilla para generar información sobre varios pedidos en un solo documento.

```csharp
<<foreach [in orders]>><<[Customer.CustomerName]>> (<<[Customer.CustomerContactNumber]>>)
1.	<<foreach [in Services]>><<[ServiceName]>>
<</foreach>><</foreach>>
```

El informe generado tendrá el siguiente aspecto:

```
Jane Doe (+9211874)
	1.	Regular Cleaning
	2.	Oven Cleaning
John Smith (+458789)
	3.	Regular Cleaning
	4.	Oven Cleaning
	5.	Carpet Cleaning
John Smith (+458789)
	6.	Regular Cleaning
	7.	Carpet Cleaning
John Smith (+458789)
	8.	Oven Cleaning
```

Sin embargo, habría una única lista numerada para todos los pedidos, lo cual no es aplicable en este escenario. Por lo tanto, puedes hacer que la numeración de la lista se reinicie para cada pedido colocando un `*`&lt;&lt;`restartNum`&gt;&gt;* etiqueta en su plantilla antes de una correspondiente *&lt;&lt;`foreach`&gt;&gt;* etiquetar de la siguiente manera:

```csharp
<<foreach [in orders]>><<[ Customer.CustomerName]>> (<<[Customer.CustomerContactNumber]>>)
1.	<<restartNum>><<foreach [in Services]>><<[ServiceName]>>
<</foreach>><</foreach>>
```

 Luego, el informe generado tendrá el siguiente aspecto:

```
Jane Doe (+9211874)
	1.	Regular Cleaning
	2.	Oven Cleaning
John Smith (+458789)
	1.	Regular Cleaning
	2.	Oven Cleaning
	3.	Carpet Cleaning
John Smith (+458789)
	1.	Regular Cleaning
	2.	Carpet Cleaning
John Smith (+458789)
	1.	Oven Cleaning
```

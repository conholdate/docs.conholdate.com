## Lista dentro de tabla con filas resaltadas en documento HTML {#in-table-list-with-highlighted-rows-in-html-document}

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información de los pedidos de los clientes con una condición de filtrado específica, cumpliendo los siguientes requisitos clave:

*   El informe debe mostrar a cada cliente junto con sus pedidos.
*   Mostrar un único cliente y el precio de su único pedido en una única fila.
*   Debe resaltar el registro cuyo precio de pedido sea mayor o igual a 400.
*   Debe mostrar la suma de los precios de los pedidos.
*   Debe representar toda la información en forma tabular.
*   El informe debe generarse en un documento de procesamiento de textos.

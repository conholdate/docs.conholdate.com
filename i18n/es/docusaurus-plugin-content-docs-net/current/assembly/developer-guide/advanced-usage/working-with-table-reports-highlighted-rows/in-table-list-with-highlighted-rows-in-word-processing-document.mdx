## Lista en tabla con filas resaltadas en un documento de Microsoft Word {#in-table-list-with-highlighted-rows-in-microsoft-word-document}

### Creación de una lista dentro de una tabla con filas resaltadas {#creating-a-in-table-list-with-highlighted-rows}

Siguiendo los siguientes pasos, puede crear una plantilla de lista en tabla con filas resaltadas en Microsoft Word 2013.

1.  Haga clic en el documento donde desea agregar la tabla.
2.  Presione la pestaña "Insertar" para insertar la tabla.
3.  |  |  |  |  | |---|---|---|---| |  |  |  |  |
4.  Haz clic en la celda que deseas resaltar.
5.  Haga clic en la pestaña **Diseño** y, a continuación, seleccione **Sombreado**.
6.  Guardar la plantilla.

### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información de los pedidos de los clientes con una condición de filtrado específica, cumpliendo los siguientes requisitos clave:

*   El informe debe mostrar a cada cliente junto con sus pedidos.
*   Mostrar al cliente único y el precio de su pedido único en una sola fila.
*   Debe resaltar el registro cuyo precio del pedido sea mayor o igual a 400.
*   Debe mostrar la suma de los precios de los pedidos.
*   Debe representar toda la información en forma de tabla.
*   El informe debe generarse en el documento de procesamiento de texto.

## Lista en tabla con filas resaltadas en documento OpenOffice {#in-table-list-with-highlighted-rows-in-openoffice-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Text (ODT) es un formato de documento de procesamiento de textos que puede utilizarse como alternativa a los formatos de documento de Microsoft Word (DOC/DOCX). Dado que ODT no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODT, visite <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">el artículo de Wikipedia</a>.

En este tema no vamos a recrear una plantilla para generar un informe de tipo «lista en tabla con filas resaltadas» en formato ODT. En su lugar, guardaremos la plantilla existente en formato ODT utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creamos en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «Texto OpenDocument» en el menú desplegable «Tipo de archivo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODT en Apache OpenOffice {#odt-template-and-report-in-apache-openoffice}

Para comprobar la compatibilidad de ODT entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las pruebas siguientes:

*   Abrimos la plantilla ODT creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODT generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

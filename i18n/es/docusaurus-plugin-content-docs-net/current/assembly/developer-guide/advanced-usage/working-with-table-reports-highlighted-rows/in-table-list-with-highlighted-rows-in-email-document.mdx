## Lista en tabla con filas resaltadas en documento de correo electrónico {#in-table-list-with-highlighted-rows-in-email-document}

### Creación de una lista en tabla con filas resaltadas {#creating-a-in-table-list-with-highlighted-rows}

Siga los siguientes pasos para crear una plantilla de lista en tabla con filas resaltadas en Microsoft Outlook 2013.

1.  Crear un nuevo correo electrónico.
2.  Pulse la pestaña "Insertar" para insertar una tabla.
3.  Inserte una tabla de 2 filas por 4 columnas.
4.  Haga clic en la celda que desea resaltar.
5.  Pulse la pestaña "Diseño" y, a continuación, seleccione "Sombreado".
6.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le exige cumplir los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar a cada cliente junto con sus pedidos.
*   Mostrar un único cliente y el precio de su único pedido en una única fila.
*   Debe resaltar el registro cuyo precio de pedido sea mayor o igual a 400.
*   Debe mostrar la suma de los precios de los pedidos.
*   Debe representar toda la información en forma tabular.

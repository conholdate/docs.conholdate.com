## Vinculación común maestro-detalle en documentos de texto {#common-master-detail-in-text-document}


:::info
Esta función es compatible con la versión 17.3.0 o superior.
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar la información de los clientes y los productos con los siguientes requisitos clave:

*   Debe asociar a los clientes con sus productos
*   El informe debe generarse en un documento HTML

### Añadir sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

```csharp
<<foreach [in customers]>><<[CustomerName()]>>
Products: <<foreach [in Order]>><<[indexOf() != 0 ? ", " : ""]>><<[Product.ProductName]>><</foreach>>
<</foreach>>
```


:::info
Para obtener información técnica detallada sobre la sintaxis, las expresiones y la generación de informes por parte del motor, visite: <a href="/es/net/assembly/developer-guide/basic-usage/working-with-groupdocs.assembly-engine/">Trabajar con el motor GroupDocs.Assembly</a>.
:::

## Vista maestro-detalle común en documentos de correo {#common-master-detail-in-email-document}


:::info
Esta función es compatible con la versión 17.8.0 o superior
:::


### Creación de una plantilla maestro-detalle común {#creating-a-common-master-detail}

Siga los pasos que se indican a continuación para crear una plantilla maestro-detalle común en Microsoft Outlook 2013:

1.  Crear un nuevo correo electrónico.
2.  Insertar dos formas: una para contener la imagen y otra para contener el resto de los detalles.
3.  Guardar el correo electrónico.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar la información de los gerentes y los clientes con los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar el nombre del cliente.
*   Debe asociar a los clientes con sus productos.

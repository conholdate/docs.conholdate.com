:::info
Esta función es compatible con la versión 17.03 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar la información de los clientes y productos con los siguientes requisitos clave:

*   El informe debe mostrar la imagen y el nombre de los clientes.
*   Debe asociar a los clientes con sus productos.
*   El informe debe generarse en un documento HTML.

## Lista dentro de una tabla con contenido alternativo en un documento de Microsoft PowerPoint {#in-table-list-with-alternate-content-in-microsoft-powerpoint-document}

### Creación de una lista dentro de una tabla con contenido alternativo {#creating-a-in-table-list-with-alternate-content}

Siga los siguientes pasos para crear una plantilla de lista dentro de una tabla con contenido alternativo en Microsoft PowerPoint 2013.

1.  Añada una nueva diapositiva a la presentación.
2.  Pulse en la pestaña "Insertar" para insertar una tabla.
3.  Inserte una tabla de 2 filas por 3 columnas.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar sus productos y sus precios cumpliendo los siguientes requisitos clave:

*   El informe debe mostrar cada producto junto con su precio.
*   Debe mostrar la suma de todos los precios.
*   Debe representar toda la información en forma tabular.
*   El informe debe generarse en un documento de presentación.

## Lista en tabla con contenido alternado en documento de presentación de OpenOffice {#in-table-list-with-alternate-content-in-openoffice-presentation-document}

### Creación de la plantilla {#creating-the-template}

OpenDocument Presentation (ODP) es un formato de documento de presentación que puede utilizarse como alternativa a los formatos Microsoft PowerPoint Document (PPT/PPTX). Dado que ODP no es un formato propietario de Microsoft, existen múltiples aplicaciones (incluidas Microsoft Office y Apache OpenOffice) disponibles para crear, abrir, editar y guardar este formato. Para obtener más información sobre las aplicaciones disponibles para trabajar con ODP, visite <a href="https://en.wikipedia.org/wiki/OpenDocument#Software" target="_blank" rel="nofollow noopener noreferrer">el artículo de Wikipedia</a>.

En este tema no recrearemos la plantilla desde cero para generar un informe de tipo «Lista en tabla con contenido alternado» en formato ODP. En su lugar, guardaremos la plantilla existente en formato ODP utilizando Microsoft Office. Para lograrlo, asumiendo que utiliza Microsoft Office 2010, siga los pasos siguientes:

1.  Abra la plantilla existente que creó en el tema anterior.
2.  Haga clic en «Archivo» y seleccione «Guardar como».
3.  Seleccione «Presentación de OpenDocument» en el menú desplegable «Tipo de archivo».
4.  Haga clic en «Guardar».

### Plantilla e informe ODP en Apache OpenOffice {#odp-template-and-report-in-apache-openoffice}

Para verificar la compatibilidad de ODP entre Microsoft Office 2010 y Apache OpenOffice 4.1.2, realizamos las siguientes pruebas:

*   Abrimos la plantilla ODP creada mediante Microsoft Office 2010 en Apache OpenOffice 4.1.2. La plantilla se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.
*   Abrimos el informe ODP generado mediante GroupDocs.Assembly en Apache OpenOffice 4.1.2. El informe se abrió correctamente en Apache OpenOffice sin ningún problema ni pérdida de formato.

## Lista en tabla con contenido alternativo en documento HTML {#in-table-list-with-alternate-content-in-html-document}


:::info
Esta función es compatible con la versión 17.03 o superior
:::


### Requisito de informe {#reporting-requirement}

Como desarrollador de informes, se le exige representar sus productos y sus precios cumpliendo los siguientes requisitos clave:

*   El informe debe mostrar cada producto junto con su precio.
*   Debe mostrar la suma de todos los precios.
*   Debe representar toda la información en forma tabular.
*   El informe debe generarse en un documento HTML.

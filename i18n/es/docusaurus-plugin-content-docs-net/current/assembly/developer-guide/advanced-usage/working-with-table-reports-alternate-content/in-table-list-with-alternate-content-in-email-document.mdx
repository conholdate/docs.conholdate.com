### Creación de una lista dentro de una tabla con contenido alternativo {#creating-a-in-table-list-with-alternate-content}

Siguiendo los pasos a continuación, puede crear una plantilla de lista dentro de una tabla con contenido alternativo en Microsoft Outlook 2013.

1.  Añadir un nuevo correo electrónico.
2.  Pulse la pestaña "Insertar" para insertar una tabla.
3.  Inserte una tabla de 2 filas por 3 columnas.
4.  Guarde la plantilla.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere representar a sus clientes y sus precios cumpliendo los siguientes requisitos clave:

*   El informe debe estar en formato .eml o .msg.
*   Debe incluir el destinatario del correo electrónico, el CSS y el asunto del correo electrónico.
*   El informe debe mostrar cada producto junto con su precio.
*   Debe mostrar la suma de todos los precios.
*   Debe representar toda la información en forma tabular.

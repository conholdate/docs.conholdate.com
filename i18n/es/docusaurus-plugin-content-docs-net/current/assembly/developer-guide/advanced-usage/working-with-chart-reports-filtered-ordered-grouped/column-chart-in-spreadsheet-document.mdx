## Gráfico de columnas en un documento de Microsoft Excel {#column-chart-in-microsoft-excel-document}

### Creación de un gráfico de columnas {#creating-a-column-chart}

Siga los pasos que se indican a continuación para crear un gráfico de columnas en MS Excel 2013:

1.  Crear un nuevo libro.
2.  Haga clic en la pestaña "Insertar" y, a continuación, haga clic en el icono "Insertar gráfico de columnas" del grupo Gráficos para ver la lista desplegable.
3.  Seleccione "Columna apilada al 100%" y presione "Aceptar" para insertar el gráfico y la plantilla de hoja de cálculo en su hoja de cálculo.
4.  Edite la hoja de cálculo con sus datos para actualizar el gráfico. Consulte <a href="/es/net/assembly/developer-guide/advanced-usage/working-with-chart-reports-filtered-ordered-grouped/column-chart-in-spreadsheet-document/#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine">Datos del gráfico</a>.
5.  Guarde su documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere compartir dinámicamente la cantidad de pedidos de los clientes con los siguientes requisitos clave:

*   El informe debe mostrar la cantidad de ventas/pedidos.
*   La cantidad de ventas/pedidos debe representarse por trimestres.
*   Debe asociar la cantidad de pedidos con el cliente correspondiente.
*   El informe debe generarse en un documento de hoja de cálculo.

### Adición de sintaxis que será evaluada por el motor GroupDocs.Assembly {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

#### Título del gráfico {#chart-title}

```csharp
Total Order Quantity by Quarters<<foreach [in orders
.Where(c => c.OrderDate.Year == 2015)
.GroupBy(c => c.Customer)
.OrderBy(g => g.Key.CustomerName)]>><<x [Key.CustomerName]>>

```

#### Datos del gráfico {#chart-data}

**Entradas de la leyenda**

```csharp
="1st Quarter<<y [Where(c => c.OrderDate.Month >= 1 && c.OrderDate.Month <= 3).Sum(c => c.ProductQuantity)]>>"
="2nd Quarter<<y [Where(c => c.OrderDate.Month >= 4 && c.OrderDate.Month <= 6).Sum(c => c.ProductQuantity)]>>"
="3rd Quarter<<y [Where(c => c.OrderDate.Month >= 7 && c.OrderDate.Month <= 9).Sum(c => c.ProductQuantity)]>>"
="4th Quarter<<y [Where(c => c.OrderDate.Month >= 10 && c.OrderDate.Month <= 12).Sum(c => c.ProductQuantity)]>>"

```

## Gráfico de columnas en un documento de Microsoft PowerPoint {#column-chart-in-microsoft-powerpoint-document}

### Creación de un gráfico de columnas {#creating-a-column-chart}

Siga los pasos que se indican a continuación para crear un gráfico de columnas en Microsoft PowerPoint 2013:

1.  Crear una nueva diapositiva de presentación
2.  Haga clic en la pestaña "Insertar" y, a continuación, haga clic en "Gráfico" dentro del grupo Ilustraciones para abrir el cuadro de diálogo "Insertar gráfico".
3.  En la barra lateral, seleccione "Columna"; verá una galería de gráficos.
4.  Elija "Columna apilada al 100%" y pulse "Aceptar" para insertar el gráfico y la plantilla de hoja de cálculo en su documento.
5.  Edite la hoja de cálculo con sus datos para actualizar el gráfico.
6.  Guarde el documento.

### Requisito del informe {#reporting-requirement}

Como desarrollador de informes, se le requiere compartir dinámicamente la cantidad de pedidos de los clientes, cumpliendo con los siguientes requisitos clave:

*   El informe debe mostrar la cantidad de ventas/pedidos.
*   La cantidad de ventas/pedidos debe representarse por trimestres.
*   Debe asociar la cantidad de pedidos con el cliente correspondiente.
*   El informe debe generarse en un documento de presentación.

### Adición de sintaxis que será evaluada por GroupDocs.Assembly Engine {#adding-syntax-to-be-evaluated-by-groupdocs-assembly-engine}

#### Título del gráfico {#chart-title}

```csharp
<<[title]>>foreach [in orders.Where(c => c.OrderDate.Year == 2015)
.GroupBy(c => c.Customer)
.OrderBy(g => g.Key.CustomerName)]>>
<<x [Key.CustomerName]>>
```

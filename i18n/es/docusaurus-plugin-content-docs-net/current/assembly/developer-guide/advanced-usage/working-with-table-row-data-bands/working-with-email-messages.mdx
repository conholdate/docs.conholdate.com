## Trabajo con mensajes de correo electrónico {#working-with-email-messages}

GroupDocs.Assembly le permite utilizar bandas de datos en filas de tablas en **mensajes de correo electrónico** con cuerpos en HTML y RTF. Una banda de datos de fila de tabla es una banda de datos cuyo cuerpo ocupa una o varias filas de una única tabla de documento. El cuerpo de dicha banda comienza al inicio de la primera fila ocupada y termina al final de la última fila ocupada, como se muestra a continuación. La sintaxis para utilizar bandas de datos en mensajes de correo electrónico es la siguiente:

<table className="gd-assembly">
	<tbody>
		<tr>
			<td>Manager</td>
			<td>Manager</td>
			<td>Contract Price</td>
		</tr>
		<tr>
			<td>&lt;&lt;foreach [c in ds]&gt;&gt;&lt;&lt;[c.Client]&gt;&gt;</td>
			<td>&lt;&lt;[c.Manager]&gt;&gt;</td>
			<td>&lt;&lt;[c.Price]&gt;&gt;&lt;&lt;/foreach&gt;&gt;</td>
		</tr>
	</tbody>
</table>

### Trabajo con bloques condicionales de filas de tabla {#working-with-table-row-conditional-blocks}

También puede utilizar un bloque condicional de fila de tabla cuyo cuerpo ocupe una o varias filas de una única tabla del documento. El cuerpo de dicho bloque (así como el cuerpo de cada una de sus opciones de plantilla) comienza al inicio de la primera fila ocupada y termina al final de la última fila ocupada, como se muestra a continuación:

| Columna 1 | Columna 2 | Columna 3 |
| ---------------------- | ------- | --------------- |
| **&lt;&lt;if ...&gt;&gt; ...** | **...** | **...** |
| **...** | **...** | **...** |
| **&lt;&lt;elseif ...&gt;&gt; ...** | **...** | **...** |
| **...** | **...** | **...** |
| **&lt;&lt;else&gt;&gt; ...** | **...** | **...** |
| **...** | **...** | **...** |
| **...** | **...** | **... &lt;&lt;/if&gt;&gt;** |
|  |  |  |

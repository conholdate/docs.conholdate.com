Este tema describe cómo agregar la biblioteca **GroupDocs.Assembly** a su proyecto .NET. Puede utilizar un paquete de NuGet para instalar esta biblioteca o descargar los DLL necesarios desde el sitio web de GroupDocs: <a href="https://releases.groupdocs.com/assembly/net/" target="_blank" rel="nofollow noopener noreferrer">https://releases.groupdocs.com/assembly/net/</a>.

## Instalar GroupDocs.Assembly mediante paquetes de NuGet {#install-groupdocs-assembly-using-nuget-packages}

Puede utilizar las siguientes herramientas para instalar los paquetes de NuGet de **GroupDocs.Assembly**: 

 * [Administrador de paquetes NuGet](#use-the-nuget-package-manager)
 * [Consola del Administrador de paquetes](#use-the-package-manager-console)
 * [.NET CLI](#use-the-net-cli)

### Utilizar el Administrador de paquetes NuGet {#use-the-nuget-package-manager}


:::tip
Las versiones anteriores de Visual Studio no incluyen el Administrador de paquetes NuGet. Se puede agregar como una extensión desde el <a href="https://marketplace.visualstudio.com/" target="_blank" rel="nofollow noopener noreferrer">Visual Studio Marketplace</a>.

* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManagerforVisualStudio2015" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes NuGet para Visual Studio 2015</a>
* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManagerforVisualStudio2013" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes NuGet para Visual Studio 2013</a>
* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManager" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes NuGet para Visual Studio 2010 y 2012</a>
:::


Abra su proyecto o solución en Visual Studio y siga los pasos a continuación para instalar el paquete **GroupDocs.Assembly** o **GroupDocs.Assembly.CrossPlatform** mediante el Administrador de paquetes NuGet:

1. En el **Explorador de soluciones**, haga clic con el botón derecho en el nombre de su proyecto y seleccione **Administrar paquetes NuGet** para mostrar el Administrador de paquetes NuGet.

    ![Add NuGet package in Visual Studio](/net/assembly/images/getting-started/installation/manage-nuget-packages.png)

2. Seleccione la pestaña **Examinar** y escriba **GroupDocs.Assembly** o **GroupDocs.Assembly.CrossPlatform** en el cuadro de búsqueda. Seleccione la versión más reciente del paquete y haga clic en **Instalar**.

    ![Install GroupDocs.Assembly NuGet package in Visual Studio](/net/assembly/images/getting-started/installation/install-nuget-package.png)

### Utilice la Consola del Administrador de Paquetes {#use-the-package-manager-console}

La <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-powershell" target="_blank" rel="nofollow noopener noreferrer">Consola del Administrador de Paquetes</a> utiliza comandos de PowerShell para instalar, actualizar y eliminar paquetes NuGet. Abra su proyecto en Visual Studio y haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de Paquetes** para abrir la ventana de la consola. Ejecute el siguiente comando para instalar la versión más reciente del paquete:


<Tabs groupId="example1">


<TabItem value="groupdocs-assembly-for-net" label="GroupDocs.Assembly for .NET" default>

```
PM> Install-Package GroupDocs.Assembly
```

</TabItem>


</Tabs>


![Use Package Manager Console ](/net/assembly/images/getting-started/installation/package-manager-console.png)

### Utilice la herramienta de la CLI de .NET {#use-the-net-cli}

También puede utilizar la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">herramienta de la CLI de .NET</a> para instalar y actualizar paquetes de NuGet. Abra una terminal en la carpeta de su proyecto y ejecute el siguiente comando para instalar el paquete:


<Tabs groupId="example2">


<TabItem value="groupdocs-assembly-for-net" label="GroupDocs.Assembly for .NET" default>

```
dotnet add package GroupDocs.Assembly
```

</TabItem>


</Tabs>


## Descargue GroupDocs.Assembly desde el sitio web oficial {#download-groupdocs-assembly-from-the-official-website}

Visite https://releases.groupdocs.com/assembly/net/ y descargue los ensamblados de **GroupDocs.Assembly** como un archivo ZIP o un instalador MSI. Para hacer referencia a los archivos de ensamblado descargados en su proyecto, realice los siguientes pasos:

1. Extraiga los archivos del archivo ZIP o ejecute el instalador MSI para instalar **GroupDocs.Assembly** en una ubicación específica de su equipo.
2. Abra su solución o proyecto en Visual Studio.
3. En el **Explorador de soluciones**, haga clic derecho en el nodo **Referencias** o **Dependencias**, y seleccione **Agregar referencia** (para un proyecto de .NET Framework) o **Agregar referencia de proyecto** (para un proyecto de .NET).

    ![Add project reference in Visual Studio](/net/assembly/images/getting-started/installation/add-project-reference.png)

4. En el cuadro de diálogo **Administrador de referencias**, seleccione la pestaña **Examinar** y haga clic en **Examinar** para ubicar el archivo _GroupDocs.Assembly.dll_ para el marco de trabajo objetivo.

    ![Browse for the GroupDocs.Assembly assembly](/net/assembly/images/getting-started/installation/browse-for-groupdocs-dll.png)

5. Haga clic en **Aceptar** para agregar una referencia a la biblioteca **GroupDocs.Assembly** en su proyecto.


:::warning
Si su aplicación tiene como objetivo .NET Core / .NET 5+, asegúrese de que su proyecto tenga todas las dependencias necesarias instaladas. Consulte la siguiente página para obtener más detalles: <a href="https://www.nuget.org/packages/groupdocs.assembly#dependencies-body-tab" target="_blank" rel="nofollow noopener noreferrer">Dependencias de GroupDocs.Assembly</a>.
:::

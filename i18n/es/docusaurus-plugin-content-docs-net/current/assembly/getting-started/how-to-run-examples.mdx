## Descargar desde GitHub {#download-from-github}

El paquete completo de ejemplos de **<a href="https://reference.groupdocs.com/net/assembly" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Assembly</a>** está alojado en <a href="https://github.com/groupdocsassembly/GroupDocs_Assembly_NET" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>. Puedes descargar el archivo ZIP desde <a href="https://github.com/groupdocsassembly/GroupDocs_Assembly_NET/archive/master.zip" target="_blank" rel="nofollow noopener noreferrer">aquí</a> o clonar el repositorio de GitHub utilizando tu cliente de GitHub favorito.

En caso de que descargues el archivo ZIP, extrae las carpetas en tu disco local. Los archivos y carpetas extraídos tendrán el siguiente aspecto:

![](https://github.com/groupdocs-assembly/GroupDocs.Assembly-for-.NET/blob/master/Examples/Data/Screenshots/Windows%20Explorer.png?raw=true)

En los archivos y carpetas extraídos, puede ver el archivo de solución para el proyecto de C#.

Este proyecto se creó en **Microsoft Visual Studio 2013**. La carpeta **Data** contiene algunas plantillas de entrada de ejemplo utilizadas en los ejemplos.

Para ejecutar los ejemplos, abra el archivo de solución en Visual Studio y compile el proyecto. Para agregar las referencias que faltan de **GroupDocs.Assembly**, consulte [Entorno de desarrollo, instalación y configuración](/net/assembly/getting-started/development-environment-installation-and-configuration/). Todas las funciones se llaman desde **Program.cs**. Descomente la función que desea ejecutar y comente el resto.

![](https://github.com/groupdocsassembly/GroupDocs_Assembly_NET/blob/master/Examples/Data/Screenshots/program.PNG?raw=true)

## Contribuir {#contribute}

Si deseas agregar o mejorar un ejemplo, te animamos a contribuir al proyecto. Todos los ejemplos y proyectos de demostración de este repositorio son de código abierto y pueden utilizarse libremente en tus propias aplicaciones.

Para contribuir, puedes bifurcar (fork) el repositorio, editar el ejemplo de código y crear una solicitud de extracción (pull request). Revisaremos los cambios e incluiremos la contribución en el repositorio si la consideramos útil.

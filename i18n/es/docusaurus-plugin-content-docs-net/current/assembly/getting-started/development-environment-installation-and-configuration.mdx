## Instalación de GroupDocs.Assembly para .NET mediante NuGet {#installing-groupdocs-assembly-for-net-through-nuget}

NuGet es la forma más sencilla de descargar e instalar GroupDocs.Assembly para .NET. A continuación se presentan algunas formas de instalar GroupDocs.Assembly para .NET en su proyecto mediante NuGet.

### Uso de la interfaz gráfica del Administrador de paquetes {#using-package-manager-gui}

Siga estos pasos para hacer referencia a GroupDocs.Assembly mediante la interfaz gráfica del Administrador de paquetes:

*   Abra su solución/proyecto en Visual Studio.
*   Haga clic en **Herramientas** -> **Administrador de paquetes NuGet** -> **Administrar paquetes NuGet para la solución**. También puede acceder a esta misma opción desde el Explorador de soluciones: haga clic con el botón derecho en la solución o el proyecto y seleccione **Administrar paquetes NuGet** en el menú contextual.
*   Seleccione la pestaña **Examinar** y escriba «GroupDocs.Assembly» en el cuadro de texto de búsqueda.
*   Haga clic en el botón **Instalar** para instalar la versión más reciente de la API en su proyecto, como se muestra en la siguiente captura de pantalla.

![](/net/assembly/images/development-environment-installation-and-configuration.png)

### Uso de la Consola del Administrador de Paquetes {#using-package-manager-console}

Puede seguir los pasos que se indican a continuación para hacer referencia a GroupDocs.Assembly mediante la Consola del Administrador de Paquetes:

*   Abra su solución o proyecto en Visual Studio.
*   Seleccione **Herramientas** -> **Administrador de paquetes NuGet** -> **Consola del Administrador de paquetes** en el menú para abrir la consola del administrador de paquetes.
*   Escriba el comando "Install-Package GroupDocs.Assembly" y presione Enter para instalar la última versión en su aplicación.
*   Tras la instalación correcta, GroupDocs.Assembly quedará referenciado en su aplicación.

![](/net/assembly/images/development-environment-installation-and-configuration_1.png)


:::warning
Estos pasos se escribieron utilizando Visual Studio 2015.
:::

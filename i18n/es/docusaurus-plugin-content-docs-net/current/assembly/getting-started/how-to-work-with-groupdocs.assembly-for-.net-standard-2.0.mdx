:::info
GroupDocs.Assembly para .NET está incluido en Conholdate.Total for .NET.
:::

GroupDocs.Assembly se construye sobre varias bibliotecas de Aspose. Algunas de estas bibliotecas utilizan <a href="https://www.nuget.org/packages/SkiaSharp/" target="_blank" rel="nofollow noopener noreferrer">SkiaSharp</a> para realizar tareas relacionadas con gráficos en .NET Standard 2.0, mientras que otras prefieren <a href="https://www.nuget.org/packages/System.Drawing.Common/" target="_blank" rel="nofollow noopener noreferrer">System.Drawing.Common</a>. Por ello, GroupDocs.Assembly depende de ambos paquetes.

La forma recomendada de gestionar estas dependencias, así como otras dependencias de GroupDocs.Assembly para .NET Standard 2.0, es instalando el <a href="https://www.nuget.org/packages/GroupDocs.Assembly/" target="_blank" rel="nofollow noopener noreferrer">paquete NuGet de GroupDocs.Assembly</a>. De lo contrario, puede instalar manualmente todas las dependencias listadas en <a href="https://www.nuget.org/packages/GroupDocs.Assembly/" target="_blank" rel="nofollow noopener noreferrer">la página del paquete NuGet</a>.

Dependiendo del sistema operativo que utilice, es posible que deba instalar algunas dependencias adicionales, como se explica a continuación.

## Uso de GroupDocs.Assembly para .NET Standard 2.0 en Windows {#using-groupdocs-assembly-for-net-standard-2-0-in-windows}

No surgen dependencias adicionales.

## Uso de GroupDocs.Assembly para .NET Standard 2.0 en Linux {#using-groupdocs-assembly-for-net-standard-2-0-in-linux}

Además de las dependencias del paquete NuGet de GroupDocs.Assembly, debe instalarse <a href="https://www.nuget.org/packages/SkiaSharp.NativeAssets.Linux/" target="_blank" rel="nofollow noopener noreferrer">SkiaSharp.NativeAssets.Linux</a>. Asimismo, es necesario instalar componentes adicionales, como se muestra en los siguientes comandos:

```
apt-get update && apt-get install -y libfontconfig1
```

```
apt-get update && apt-get install -y --allow-unauthenticated libc6-dev libgdiplus libx11-dev
```

## Uso de GroupDocs.Assembly para .NET Standard 2.0 en macOS {#using-groupdocs-assembly-for-net-standard-2-0-in-macos}

Además de las dependencias del paquete NuGet de GroupDocs.Assembly, debe instalarse <a href="https://www.nuget.org/packages/runtime.osx.10.10-x64.CoreCompat.System.Drawing/" target="_blank" rel="nofollow noopener noreferrer">runtime.osx.10.10-x64.CoreCompat.System.Drawing</a>.

## Uso de GroupDocs.Assembly para .NET Standard 2.0 en Docker {#using-groupdocs-assembly-for-net-standard-2-0-in-docker}

Los pasos adicionales necesarios para utilizar GroupDocs.Assembly para .NET Standard 2.0 en Docker dependen del tipo de contenedores que se esté utilizando. Por ejemplo, para contenedores Linux, debe seguir los mismos pasos adicionales indicados en la sección «Uso de GroupDocs.Assembly para .NET Standard 2.0 en Linux».

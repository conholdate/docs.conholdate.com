GroupDocs.Assembly para .NET es una API de automatización de documentos y generación de informes diseñada para crear documentos personalizados a partir de plantillas. Esta API de informes para .NET ensambla inteligentemente los datos proporcionados con la plantilla de documento definida y actúa como un **generador de informes**, que produce un documento de salida basado en la fuente de datos, en el formato de la plantilla o en el formato de salida especificado. Dado que GroupDocs.Assembly para .NET puede generar documentos basados en una fuente de datos, sirve esencialmente para dos propósitos: Automatización de Documentos y Generación de Informes.

## Concepto de Automatización de Documentos {#document-automation-concept}

Según Wikipedia, la automatización de documentos puede describirse como:

> **Automatización de documentos** (también conocida como **ensamblaje de documentos**) es el diseño de sistemas y <a href="https://en.wikipedia.org/wiki/Workflow" target="_blank" rel="nofollow noopener noreferrer">flujos de trabajo</a> que asisten en la creación de <a href="https://en.wikipedia.org/wiki/Electronic_document" target="_blank" rel="nofollow noopener noreferrer">documentos electrónicos</a>. Estos incluyen sistemas basados en lógica que utilizan segmentos de texto y/o datos preexistentes para ensamblar un nuevo documento. Este proceso se utiliza cada vez más en ciertas industrias para ensamblar documentos legales, contratos y cartas. Los sistemas de automatización de documentos también pueden utilizarse para automatizar todo el texto condicional, el texto variable y los datos contenidos en un conjunto de documentos.
> 
> Los sistemas de automatización permiten a las empresas minimizar la introducción de datos, reducir el tiempo dedicado a la revisión y reducir los riesgos asociados con los errores humanos. Otros beneficios incluyen: ahorro de tiempo y dinero debido a la reducción en el manejo de papel, carga de documentos, almacenamiento, distribución, envíos postales, faxes, telefonía, mano de obra y desechos.

Para más información, visite: <a href="https://en.wikipedia.org/wiki/Document_automation" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/Document\_automation</a>

## Concepto de Generación de Informes {#report-generation-concept}

Según Wikipedia, la generación de informes puede describirse como:

> Un **generador de informes** es un programa informático cuyo propósito es tomar datos de una fuente, como una base de datos, un flujo XML o una hoja de cálculo, y utilizarlos para producir un documento en un formato que satisfaga a un público lector humano específico.
> 
> La funcionalidad de generación de informes está casi siempre <a href="https://en.wikipedia.org/wiki/Wikipedia:Citation_needed" target="_blank" rel="nofollow noopener noreferrer">requiere citación</a> presente en <a href="https://en.wikipedia.org/wiki/Database_systems" target="_blank" rel="nofollow noopener noreferrer">sistemas de bases de datos</a>, donde la fuente de los datos es la propia base de datos. También puede argumentarse que la generación de informes forma parte del propósito de una <a href="https://en.wikipedia.org/wiki/Spreadsheet" target="_blank" rel="nofollow noopener noreferrer">hoja de cálculo</a>. Los generadores de informes independientes pueden trabajar con múltiples fuentes de datos y exportar informes a distintos formatos de documento.

Para más información, visite: <a href="https://en.wikipedia.org/wiki/Report_generator" target="_blank" rel="nofollow noopener noreferrer">https://en.wikipedia.org/wiki/Report\_generator</a>

## Formatos de Documento Soportados {#supported-document-formats}

GroupDocs.Assembly para .NET es capaz de reconocer y cargar múltiples formatos de documento en memoria y rellenar estas plantillas con la fuente de datos asignada. Por lo tanto, puede crear sus plantillas en cualquiera de los formatos de documento soportados. La versión inicial de GroupDocs.Assembly soporta documentos de procesamiento de textos, incluyendo documentos de Microsoft Word, documentos de hojas de cálculo, incluyendo libros de Microsoft Excel, y documentos de presentación, incluyendo presentaciones de Microsoft PowerPoint. Las futuras versiones de GroupDocs.Assembly soportarán más formatos de documento, y la sección [formatos de documento soportados](/net/assembly/getting-started/supported-document-formats/) se actualizará periódicamente cada vez que se soporten más formatos de documento en futuras versiones.

## Sintaxis de Plantilla Soportada {#supported-template-syntax}

Esencialmente, el motor de GroupDocs.Assembly para .NET soporta LINQ, pero no soporta la sintaxis LINQ real. En cambio, el motor soporta la sintaxis subyacente de C# para consultas LINQ, que es en realidad más corta que LINQ. Esto básicamente significa que los desarrolladores pueden utilizar la sintaxis de C# familiar y bien documentada para escribir consultas de enlace/recorrido de datos directamente en las plantillas de documentos. Como resultado, los desarrolladores pueden disfrutar de muchos beneficios, incluyendo una sintaxis de informes breve y concisa y el enlace a cualquier tipo de fuente de datos soportada, incluyendo objetos .NET personalizados. Para más información sobre la sintaxis basada en LINQ soportada, visite <a href="https://docs.groupdocs.com/assembly/net/template-syntax-part-1-of-2/" target="_blank" rel="nofollow noopener noreferrer">Sintaxis de Plantilla</a>. En el futuro, también está prevista la implementación del soporte para plantillas <a href="https://mustache.github.io/mustache.5.html" target="_blank" rel="nofollow noopener noreferrer">Mustache</a>.

## Fuentes de Datos Soportadas {#supported-data-sources}

GroupDocs.Assembly para .NET soporta las siguientes fuentes de datos:

*   Base de Datos
*   XML
*   OData
*   JSON
*   Objetos .NET Personalizados

Además, GroupDocs.Assembly para .NET soporta diversas funciones de manipulación de datos. Para más información, visite [Fuentes de Datos](/net/assembly/getting-started/features-overview/#data-sources#FeaturesOverview-DataSources).

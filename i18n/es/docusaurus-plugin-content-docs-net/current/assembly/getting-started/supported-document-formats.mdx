## Detalles de características admitidas para formatos de archivo de correo electrónico {#supported-features-detail-for-email-file-formats}

La siguiente tabla proporciona información sobre aquellas características de GroupDocs.Assembly que están parcialmente admitidas o no admitidas en absoluto para los formatos de archivo de correo electrónico.  

| Característica | MSG con cuerpo RTF | MSG, EML, MHTML con cuerpo HTML creado mediante Microsoft Outlook o Microsoft Word | MSG, EML, EMLX, MHTML con cuerpo HTML creado fuera de Microsoft Outlook o Microsoft Word | MSG, EML, EMLX, MHTML con cuerpo de texto sin formato |
| --- | --- | --- | --- | --- |
| Creación dinámica de gráficos | Admitido (fuera de bucles y condiciones) | Admitido (fuera de bucles y condiciones) | No admitido | No admitido |
| Inserción dinámica de documentos | Admitido | Admitido | Por admitir | No admitido |
| Inserción dinámica de imágenes | Admitido | Admitido | Admitido | No admitido |
| Inserción dinámica de códigos de barras | Admitido | Admitido | Por admitir | No admitido |

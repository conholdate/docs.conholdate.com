GroupDocs.Assembly para .NET no requiere la instalación de ningún software externo ni herramienta de terceros. Simplemente siga uno de los métodos descritos en [Entorno de desarrollo, instalación y configuración](/net/assembly/getting-started/development-environment-installation-and-configuration/).

## Sistemas Operativos Soportados {#supported-operating-systems}

GroupDocs.Assembly para .NET admite cualquier sistema operativo de 32 o 64 bits en el que esté instalado el framework .NET o Mono, incluyendo, sin limitarse a:

### Windows {#windows}

*   Microsoft Windows 2003 Server (x64, x86)
*   Microsoft Windows Server 2008 (x64, x86)
*   Microsoft Windows Server 2012 (x64, x86)
*   Microsoft Windows Server 2012 R2 (x64, x86)
*   Microsoft Windows Server 2016 (x64, x86)
*   Microsoft Windows Server 2019 (x64, x86)
*   Microsoft Windows Vista (x64, x86)
*   Microsoft Windows XP (x64, x86)
*   Microsoft Windows 7 (x64, x86)
*   Microsoft Windows 8, 8.1 (x64, x86)
*   Microsoft Windows 10 (x64, x86)
*   Microsoft Azure

### Linux {#linux}

*   Linux (Ubuntu, openSUSE, CentOS y otros)

### Mac {#mac}

*   Mac OS X

## Entornos de Desarrollo {#development-environments}

GroupDocs.Assembly for .NET se puede utilizar para desarrollar aplicaciones en cualquier entorno de desarrollo que apunte a la plataforma .NET, pero los siguientes entornos están explícitamente admitidos:

*   Microsoft Visual Studio 2010
*   Microsoft Visual Studio 2011
*   Microsoft Visual Studio 2012
*   Microsoft Visual Studio 2013
*   Microsoft Visual Studio 2015
*   Microsoft Visual Studio 2017
*   Microsoft Visual Studio 2019
*   Xamarin.Android
*   Xamarin.iOS
*   Xamarin.Mac
*   MonoDevelop 2.4 y versiones posteriores

## Pasos de ejecución {#execution-steps}

### Entradas {#inputs}

*   Una **plantilla** creada en uno de los formatos de documento admitidos, que cumpla con la sintaxis de plantilla admitida.
*   Una cadena de conexión para conectarse a una **base de datos** a la que se pueda acceder mediante DataSet / DataTable, etc.
*   Tipo de origen de datos. Por ejemplo, tabla / vistas, etc.
*   Origen de datos. Seleccione una tabla / vista de la base de datos conectada.

### Procesamiento del sistema {#system-processing}

*   Verifica el formato del documento de la plantilla.
*   Se conecta a una base de datos de Microsoft SQL Server mediante la cadena de conexión.
*   Prueba la conexión según la cadena de conexión proporcionada.
*   Carga todas las tablas de la base de datos conectada.
*   Carga todas las vistas de la base de datos conectada.
*   Permite introducir una consulta personalizada.
*   Pasa la plantilla y el origen de datos a GroupDocs.Assembly: GroupDocs.Assembly genera un informe según las entradas.
*   Devuelve el informe al navegador.

### Salida {#output}

*   Un informe generado basado en la sintaxis de la plantilla y el origen de datos. Este informe tendrá el mismo formato de documento que el formato de documento de la plantilla de origen.

## Introducción al Generador de Informes Web impulsado por GroupDocs.Assembly para .NET {#introduction-to-web-report-generator-powered-by-groupdocs-assembly-for-net}

El Generador de Informes Web es una aplicación ASP.NET Web Forms que utiliza GroupDocs.Assembly para .NET y demuestra las funcionalidades principales ofrecidas por esta biblioteca. El Generador de Informes Web permite al usuario crear fácilmente informes basados en: a) Plantillas personalizadas predefinidas (creadas en <a href="https://docs.groupdocs.com/assembly/net/supported-document-formats/" target="_blank" rel="nofollow noopener noreferrer">Formatos de documento admitidos</a> siguiendo <a href="https://docs.groupdocs.com/assembly/net/template-syntax-part-1-of-2/" target="_blank" rel="nofollow noopener noreferrer">Sintaxis de plantilla admitida</a>) y b) Su propia base de datos (MS SQL Server local o remoto), incluyendo tablas, vistas y también consultas personalizadas. La interfaz de usuario de la aplicación se ha diseñado de forma muy sencilla para facilitar su comprensión, y los desarrolladores pueden ampliar sus funcionalidades según sus propias necesidades, ya que se trata de un proyecto de código abierto.

![](https://raw.githubusercontent.com/groupdocsassembly/GroupDocs_Assembly_NET/master/Examples/Data/Screenshots/reportgenrator.png)

## Características {#features}

*   Conectarse a MS SQL Server local o remoto proporcionando una cadena de conexión.
*   Poblar y utilizar tablas de la base de datos conectada.
*   Poblar y utilizar vistas de la base de datos conectada.
*   Crear y utilizar consultas personalizadas sobre la base de datos conectada.
*   Cargar y utilizar archivos de plantilla de MS Word.
*   Cargar y utilizar archivos de plantilla de MS Excel.
*   Cargar y utilizar archivos de plantilla de MS PowerPoint.
*   Generar informes en el formato correspondiente al documento de plantilla de origen.
*   Descargar el informe generado desde el navegador web.

## Entorno de desarrollo {#development-environment}

### Marco de trabajo (Framework) {#framework}

Se admiten Microsoft .NET Framework 3.5 o versiones posteriores.

### Entorno de desarrollo integrado (IDE) {#ide}

La aplicación ha sido desarrollada utilizando **Microsoft Visual Studio 2010**. Por lo tanto, se puede utilizar cualquier IDE a partir de Visual Studio 2010.

### Herramienta de desarrollo de fuente de datos {#data-source-development-tool}

La base de datos de ejemplo (como fuente de datos) ha sido desarrollada en **Microsoft SQL Server 2008 R2**. Por lo tanto, para adjuntar la base de datos, se requiere al menos **Microsoft SQL Server 2008 R2** o versiones posteriores.

**Nota:** La base de datos no puede restaurarse en versiones anteriores a **Microsoft SQL Server 2008 R2**.

### Navegadores compatibles {#supported-browsers}

Se admiten los siguientes navegadores para acceder al Generador de Informes Web:

*   Mozilla Firefox
*   Internet Explorer (versión 9 o posterior)
*   Google Chrome
*   Apple Safari

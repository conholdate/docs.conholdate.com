## Complemento de Visual Studio para explorar ejemplos de GroupDocs.Assembly {#visual-studio-plugin-to-explore-groupdocs-assembly-examples}

El complemento de GroupDocs.Assembly para .NET facilita la compilación de los ejemplos de GroupDocs.Assembly para .NET 3.0.0 y su exploración. Reduce significativamente el esfuerzo necesario para descargar los ejemplos y el archivo DLL desde recursos distintos (GitHub, NuGet). Puede ejecutar rápidamente proyectos en C#. Por lo tanto, se han eliminado todos los pasos manuales previamente necesarios para explorar los ejemplos.

### Características {#features}

A continuación se presentan las características clave del complemento:

*   Aparece en el menú **Archivo** de Visual Studio.
*   Descarga automáticamente los ejemplos de código.
*   Descarga automáticamente la biblioteca **GroupDocs.Assembly**.
*   Agrega automáticamente la referencia a GroupDocs.Assembly.
*   Proporciona ejemplos en **C#**.
*   Admite **Visual Studio 2010**, **2012** y **2013**.
*   Abre el proyecto en pocos pasos.
*   Fácil de descargar e instalar.
*   Fácil de usar.
*   Ahorra tiempo y reduce el esfuerzo.

### Instalación {#installation}

La instalación del complemento de Visual Studio para los ejemplos de GroupDocs.Assembly es muy sencilla. El usuario únicamente debe descargar el archivo MSI y ejecutarlo. Tras finalizar la instalación, el complemento se integrará con Visual Studio y aparecerá en el menú **Archivo**.  
Es posible que deba agregar la referencia a **Newtonsoft.Json.DLL** para compilar cualquiera de los proyectos (C#).


:::info
Para una demostración en video, vea «Cómo instalar» en YouTube.
:::


### Uso {#usage}

Al igual que la instalación, el uso del complemento también es muy sencillo y amigable para el usuario. A continuación se presentan algunos pasos sencillos para ejecutar proyectos de ejemplo en Visual Studio.

*   Vaya a **Archivo** -> **GroupDocs** en Visual Studio.
*   Seleccione **Nuevo proyecto de ejemplo de GroupDocs.Assembly**.

Tras la instalación, verá las siguientes apariencias:

### Versiones compatibles de Visual Studio {#supported-versions-of-visual-studio}

Antes de instalar el complemento, debe tener instalado Visual Studio. Este complemento es compatible con las siguientes versiones de Visual Studio:

*   Visual Studio 2010
*   Visual Studio 2012
*   Visual Studio 2013

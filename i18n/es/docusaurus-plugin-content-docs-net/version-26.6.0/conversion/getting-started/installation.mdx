Este tema describe cómo agregar la biblioteca **GroupDocs.Conversion** a su proyecto .NET. Puede utilizar un paquete de NuGet para instalar esta biblioteca o descargar los DLL necesarios desde el sitio web de GroupDocs: <a href="https://downloads.groupdocs.com/conversion/net" target="_blank" rel="nofollow noopener noreferrer">https://downloads.groupdocs.com/conversion/net</a>.  

## Instalar GroupDocs.Conversion mediante paquetes de NuGet {#install-groupdocs-conversion-using-nuget-packages}

Existen dos paquetes de NuGet disponibles según su marco de trabajo objetivo:

* <a href="https://www.nuget.org/packages/GroupDocs.Conversion" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion</a> – para .NET 6 y versiones posteriores
* <a href="https://www.nuget.org/packages/GroupDocs.Conversion.NETFramework" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Conversion.NETFramework</a> – para .NET Framework 4.6.2 y versiones posteriores

Puede utilizar las siguientes herramientas para instalar el paquete de NuGet adecuado:

 * [Administrador de paquetes NuGet](#use-the-nuget-package-manager)
 * [Consola del Administrador de paquetes](#use-the-package-manager-console)
 * [.NET CLI](#use-the-net-cli)

### Utilizar el Administrador de paquetes NuGet {#use-the-nuget-package-manager}

Abra su proyecto o solución en Visual Studio y siga los pasos a continuación para instalar el paquete **GroupDocs.Conversion** mediante el <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-visual-studio" target="_blank" rel="nofollow noopener noreferrer">Administrador de paquetes NuGet</a>:

1. En el **Explorador de soluciones**, haga clic con el botón derecho sobre el nombre de su proyecto y seleccione **Administrar paquetes NuGet** para mostrar el Administrador de paquetes NuGet.

    ![Manage NuGet packages in Visual Studio](/net/conversion/images/getting-started/installation/manage-nuget-packages.png)

2. Seleccione la pestaña **Examinar** y escriba **GroupDocs.Conversion** en el cuadro de búsqueda. Seleccione el paquete adecuado para su marco de trabajo objetivo (**GroupDocs.Conversion** para .NET 6+ o **GroupDocs.Conversion.NETFramework** para .NET Framework) y haga clic en **Instalar**.

    ![Install NuGet packages in Visual Studio](/net/conversion/images/getting-started/installation/install-nuget-package.png)

### Utilizar la Consola del Administrador de Paquetes {#use-the-package-manager-console}

La <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-powershell" target="_blank" rel="nofollow noopener noreferrer">Consola del Administrador de Paquetes</a> utiliza comandos de PowerShell para instalar, actualizar y eliminar paquetes NuGet. Abra su proyecto en Visual Studio y haga clic en **Herramientas** -> **Administrador de Paquetes NuGet** -> **Consola del Administrador de Paquetes** para abrir la ventana de la consola. Ejecute uno de los siguientes comandos para instalar la versión más reciente de la biblioteca **GroupDocs.Conversion**:


<Tabs groupId="example1">


<TabItem value="net-6" label=".NET 6+" default>

```shell
PM> Install-Package GroupDocs.Conversion
```

</TabItem>


<TabItem value="net-framework" label=".NET Framework">

```shell
PM> Install-Package GroupDocs.Conversion.NETFramework
```

</TabItem>


</Tabs>


![Use Package Manager Console ](/net/conversion/images/getting-started/installation/package-manager-console.png)

### Utilice la CLI de .NET {#use-the-net-cli}

También puede utilizar la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" target="_blank" rel="nofollow noopener noreferrer">herramienta CLI de .NET</a> para instalar y actualizar paquetes de NuGet. Este método está disponible para proyectos de .NET 6 o superior. Abra una terminal en la carpeta de su proyecto y ejecute el siguiente comando para instalar el paquete **GroupDocs.Conversion**:


<Tabs groupId="example2">


<TabItem value="net-cli" label=".NET CLI" default>

```shell
dotnet add package GroupDocs.Conversion
```

</TabItem>


</Tabs>


## Descargue GroupDocs.Conversion desde el sitio web oficial {#download-groupdocs-conversion-from-the-official-website}

Visite <a href="https://releases.groupdocs.com/conversion/net/" target="_blank" rel="nofollow noopener noreferrer">https://releases.groupdocs.com/conversion/net/</a> y descargue los ensamblados de **GroupDocs.Conversion** como un archivo ZIP o un instalador MSI. Para hacer referencia a los archivos de ensamblado descargados en su proyecto, realice los siguientes pasos:

1. Extraiga los archivos del archivo ZIP o ejecute el instalador MSI para instalar **GroupDocs.Conversion** en una ubicación específica de su equipo.
2. Abra su solución o proyecto en Visual Studio.
3. En el **Explorador de soluciones**, haga clic derecho en el nodo **Referencias** o **Dependencias**, y seleccione **Agregar referencia** (para un proyecto de .NET Framework) o **Agregar referencia de proyecto** (para un proyecto de .NET).
4. En el cuadro de diálogo **Administrador de referencias**, seleccione la pestaña **Examinar** y haga clic en **Examinar** para localizar el archivo _GroupDocs.Conversion.dll_ correspondiente al marco de trabajo objetivo.

    ![Browse for the GroupDocs.Conversion assembly](/net/conversion/images/getting-started/installation/browse-for-groupdocs-dll.png)

5. Haga clic en **Aceptar** para agregar una referencia a la biblioteca **GroupDocs.Conversion** a su proyecto.


:::warning
Si su aplicación está dirigida a .NET 6 o superior, asegúrese de que su proyecto tenga todas las dependencias necesarias instaladas. Consulte la siguiente página para obtener más detalles: <a href="https://www.nuget.org/packages/groupdocs.conversion#dependencies-body-tab" target="_blank" rel="nofollow noopener noreferrer">Dependencias de GroupDocs.Conversion</a>.
:::

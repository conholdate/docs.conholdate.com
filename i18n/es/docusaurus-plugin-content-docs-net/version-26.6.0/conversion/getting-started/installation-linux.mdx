Este artículo explica cómo instalar y ejecutar **GroupDocs.Conversion for .NET** en un sistema basado en Linux utilizando .NET 6+. También incluye instrucciones para instalar las dependencias nativas que podrían ser necesarias al ejecutarse en un entorno sin interfaz gráfica (headless).

## Requisitos previos {#prerequisites}

Asegúrese de que las siguientes herramientas y paquetes estén instalados:

- .NET 6.0 SDK o posterior: <a href="https://learn.microsoft.com/en-us/dotnet/core/install/linux" target="_blank" rel="nofollow noopener noreferrer">Instalar .NET en Linux</a>
- Una distribución de Linux, como Ubuntu, Debian, CentOS/RHEL o Alpine
- `libgdiplus`, `fontconfig` y fuentes TrueType

## Instalación de dependencias {#installing-dependencies}

### Ubuntu / Debian {#ubuntu-debian}

Asegúrese de que el repositorio multiverse esté habilitado:

```bash
sudo add-apt-repository multiverse
sudo apt update
```

Instale los paquetes requeridos:

```bash
sudo apt install -y libgdiplus fontconfig ttf-mscorefonts-installer
```

> `ttf-mscorefonts-installer` se encuentra en el repositorio multiverso y descarga las fuentes de Microsoft.

### CentOS / RHEL {#centos-rhel}

Habilite el repositorio EPEL e instale los paquetes necesarios:

```bash
sudo yum install -y epel-release
sudo yum install -y libgdiplus fontconfig cabextract
```

Para instalar las fuentes Microsoft TrueType:

```bash
wget https://downloads.sourceforge.net/project/mscorefonts2/rpms/msttcore-fonts-installer-2.6-1.noarch.rpm
sudo yum install -y msttcore-fonts-installer-2.6-1.noarch.rpm
```

> Nota: Este método utiliza un RPM de terceros para las fuentes de Microsoft. Es posible que necesite `--nogpgcheck` según la configuración de su sistema.

### Alpine Linux {#alpine-linux}

Instale las dependencias mínimas utilizando `apk`:

```bash
apk add --no-cache libgdiplus fontconfig ttf-dejavu
```

> `ttf-dejavu` ofrece una buena compatibilidad de fuentes en Alpine.

## Instalar GroupDocs.Conversion mediante .NET CLI {#install-groupdocs-conversion-using-net-cli}

En el directorio de su proyecto:

```bash
dotnet add package GroupDocs.Conversion
dotnet restore
```

## Ejecute su proyecto {#run-your-project}

Compile y ejecute su proyecto:

```bash
dotnet run
```

## Solución de problemas {#troubleshooting}

- Si encuentra `System.DllNotFoundException`, verifique si `libgdiplus` está instalado.
- Si faltan fuentes o se renderizan incorrectamente, verifique que las fuentes estén presentes y accesibles.

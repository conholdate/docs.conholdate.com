## Conversión de archivos {#file-conversion}
Este artículo describe las características principales de la API de conversión de archivos utilizando C#.

La característica principal de GroupDocs.Conversion es la capacidad de convertir cualquier documento desde cualquiera de los formatos de documento de origen admitidos hacia cualquier formato de destino admitido (consulte la lista de [formatos admitidos](/net/conversion/getting-started/supported-document-formats/)). Todas estas conversiones son posibles sin necesidad de instalar software adicional (como Microsoft Office, Apache Open Office, Adobe Acrobat Reader y otros).
GroupDocs.Conversion proporciona un conjunto flexible de configuraciones para personalizar el proceso de conversión según sus necesidades:

### Convertir página(s) específica(s) del documento {#convert-specific-document-page-s}

Además de la conversión completa del documento al formato de destino deseado, puede resultar útil convertir páginas o rangos de páginas específicas del documento. Para dicha conversión parcial del documento, debe especificar los números de página deseados para convertir utilizando la propiedad <a href="https://reference.groupdocs.com/conversion/net/groupdocs.conversion.options.convert/commonconvertoptions-1/pages" target="_blank" rel="nofollow noopener noreferrer">Pages</a> de la clase `ConvertOptions`.

### Detección automática del formato del documento de origen {#auto-detect-source-document-format}

En algunos casos, el archivo de origen podría presentarse como un flujo de bytes, por lo que la extensión del archivo es desconocida.
Afortunadamente, GroupDocs.Conversion para .NET es lo suficientemente inteligente como para [detectar el formato del documento de origen](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-stream/#get-information-about-files-from-a-stream) sobre la marcha.

### Cargar documento de origen con opciones extendidas {#load-source-document-with-extended-options}

Existen numerosas modificaciones posibles durante el proceso de conversión de archivos:

- especificar una contraseña para [documentos protegidos con contraseña](/net/conversion/developer-guide/advanced-usage/loading/load-password-protected-document/);
- mostrar/ocultar [comentarios](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/) y [anotaciones](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-pdf-document-with-options/) del documento;
- [mostrar/ocultar marcas y seguimiento de cambios](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/) en documentos de Word;
- [mostrar hojas ocultas](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-spreadsheet-document-with-options/) al convertir archivos de Excel o no;
- establecer la [codificación de archivos de texto](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-txt-document-with-options/) y mucho más;

### Obtener la lista completa de formatos de conversión admitidos {#obtain-all-supported-conversion-formats-list}

Puede obtener la [lista completa de conversiones posibles](/net/conversion/developer-guide/basic-usage/get-possible-conversions/) admitidas por la biblioteca GroupDocs.Conversion para .NET. Asimismo, es posible obtener [conversiones permitidas](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/get-default-convert-options-for-target-format/) para un formato de archivo específico.

### Sustitución de fuentes {#fonts-replacement}

Es un caso de uso común que un documento de origen haga referencia a fuentes específicas que no están presentes en el entorno donde se ejecuta su aplicación. GroupDocs.Conversion para .NET proporciona una solución: puede [sustituir las fuentes que faltan](/net/conversion/developer-guide/advanced-usage/loading/load-options-for-different-document-types/load-wordprocessing-document-with-options/#specify-font-substitution) por fuentes de su elección, lo que preservará la apariencia de su documento. También puede [suscribirse al evento `OnFontSubstituted`](/net/conversion/developer-guide/advanced-usage/conversion-events/#font-substitution-notifications) para recibir notificaciones cada vez que se sustituya una fuente durante la conversión.

### Marcas de agua en documentos convertidos {#watermarking-converted-document}

Puede [agregar una marca de agua de texto o imagen](/net/conversion/developer-guide/advanced-usage/converting/common-conversion-options/add-watermark/) a cualquier página del documento convertido y elegir sus dimensiones, color y tamaño de fuente deseados.

## Extracción de información del documento {#document-information-extraction}

GroupDocs.Conversion permite obtener información básica [sobre el documento de origen](/net/conversion/developer-guide/basic-usage/get-document-info/): tipo de archivo, número de páginas, etc. Dependiendo del tipo de archivo de origen, se puede extraer información específica del formato, por ejemplo:

- [CAD](/net/conversion/developer-guide/basic-usage/get-document-info/#cad-drawings): lista de capas y diseños en un documento CAD;
- [Correo electrónico](/net/conversion/developer-guide/basic-usage/get-document-info/#emails): lista de adjuntos;
- [PDF](/net/conversion/developer-guide/basic-usage/get-document-info/#pdf-documents): título, autor, índice y más;
- [Gestión de proyectos](/net/conversion/developer-guide/basic-usage/get-document-info/#project-management-documents): fechas de inicio y finalización del proyecto.

## Cargar documentos desde distintas fuentes {#load-documents-from-different-sources}

Con GroupDocs.Conversion no está limitado únicamente a [archivos locales](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-local-disk/). También admite la carga de documentos desde [flujos](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-stream/), [FTP](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-ftp/), [URLs remotas](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-url/), así como desde nubes [Amazon S3](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-amazon-s3-storage/) y [Azure](/net/conversion/developer-guide/advanced-usage/loading/loading-files-from-different-sources/load-file-from-azure-blob-storage/).

## Almacenamiento en caché de resultados {#caching-results}

GroupDocs.Conversion admite [almacenamiento en caché del resultado de la conversión](/net/conversion/developer-guide/advanced-usage/caching/) en disco local de forma predeterminada. Sin embargo, se puede admitir cualquier tipo de almacenamiento en caché implementando las interfaces correspondientes: Amazon S3, Dropbox, Google Drive, Windows Azure, Redis o cualquier otro.

Para obtener una lista de todos los archivos adjuntos de un archivo de origen, siga estos pasos:

1. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique un archivo que contenga archivos adjuntos.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/getattachments" target="_blank" rel="nofollow noopener noreferrer">GetAttachments</a>. Este método devuelve la colección de archivos adjuntos.  
3. Recorra la colección.

El siguiente fragmento de código muestra cómo obtener una lista de archivos adjuntos desde un archivo MSG:

:::info
NOTA: el fragmento de código proporcionado es compatible con todas las familias de formatos que admiten archivos adjuntos: correos electrónicos, archivos de datos de Outlook, archivos comprimidos y documentos PDF.
:::

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System;
using System.Collections.Generic;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Results;
// ...

using (Viewer viewer = new Viewer("sample.msg"))
{
    // Get list of attachments.
    IList<Attachment> attachments = viewer.GetAttachments();

    // Display list of attachments.
    Console.WriteLine("\nAttachments:");
    foreach (Attachment attachment in attachments)
        Console.WriteLine(attachment);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System
Imports System.Collections.Generic
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.msg")
            ' Get list of attachments.
            Dim attachments As IList(Of Attachment) = viewer.GetAttachments()
        
            ' Display list of attachments.
            Console.WriteLine(Global.Microsoft.VisualBasic.Constants.vbLf & "Attachments:")
            For Each attachment As Attachment In attachments
                Console.WriteLine(attachment)
            Next
        End Using
    End Sub
End Module
```

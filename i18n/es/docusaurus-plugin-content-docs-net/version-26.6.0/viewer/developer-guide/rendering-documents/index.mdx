En GroupDocs.Viewer, el renderizado es el proceso de convertir un documento en uno o más archivos adecuados para su visualización. Los archivos resultantes pueden estar en uno de los siguientes formatos:

* HTML
* PDF
* Imágenes (JPG o PNG)

Si el documento de origen contiene varias páginas, el resultado del renderizado a PDF es un único archivo paginado.
El renderizado de un documento de varias páginas a HTML o imágenes produce varios archivos, uno por cada página.

Por ejemplo, si tiene un archivo .docx con tres páginas, convertir ese archivo a HTML o imágenes genera tres archivos HTML o de imagen que representan las páginas del documento. Convertir este archivo a PDF produce un único archivo con tres páginas.

Reducir la calidad de las imágenes JPG disminuye el tamaño del archivo de salida.

Para ajustar la calidad de las imágenes, configure la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions/properties/jpgquality" target="_blank" rel="nofollow noopener noreferrer">JpgQuality</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>. El valor debe estar entre 1 (calidad mínima) y 100. El valor predeterminado es 90.

Para establecer la calidad de la imagen, siga estos pasos:

1. Instancie la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique la ruta del documento de origen como parámetro del constructor.
1. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>.
2. Establezca el valor de <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions/properties/jpgquality" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions.JpgQuality</a>.
3. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> del objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a> como parámetro.

El siguiente fragmento de código muestra cómo ajustar la calidad de la imagen JPG en el documento PDF de salida:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    PdfViewOptions viewOptions = new PdfViewOptions();

    // Specify the JPG image quality.
    viewOptions.PdfOptimizationOptions = new PdfOptimizationOptions();
    viewOptions.PdfOptimizationOptions.ImageQuality = 50;
    viewer.View(viewOptions);
}
```

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions As PdfViewOptions = New PdfViewOptions()

            ' Specify the JPG image quality.
            viewOptions.PdfOptimizationOptions = New PdfOptimizationOptions()
            viewOptions.PdfOptimizationOptions.ImageQuality = 50
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

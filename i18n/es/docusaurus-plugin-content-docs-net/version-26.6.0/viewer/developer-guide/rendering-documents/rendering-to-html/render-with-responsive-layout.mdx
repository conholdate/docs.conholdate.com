El diseño responsivo tiene como objetivo que las páginas web se muestren correctamente en una variedad de dispositivos. GroupDocs.Viewer proporciona la propiedad <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions/properties/renderresponsive" target="_blank" rel="nofollow noopener noreferrer">RenderResponsive</a> de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> para representar páginas HTML con diseño responsivo. 

El siguiente fragmento de código muestra cómo representar un documento .docx en HTML con diseño responsivo:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForEmbeddedResources();
    
    // Render the file with responsive layout.
    viewOptions.RenderResponsive = true;
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
        
            ' Render the file with responsive layout.
            viewOptions.RenderResponsive = True
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

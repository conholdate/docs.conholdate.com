Al renderizar a HTML, GroupDocs.Viewer genera cada página del documento de origen como un documento HTML independiente.

GroupDocs.Viewer for .NET ofrece dos opciones para gestionar CSS, fuentes, imágenes y otros recursos:

1. HTML con recursos externos almacena los recursos de la página como archivos independientes. Esto permite reutilizar recursos comunes y reduce el tamaño de la página y mejora la velocidad de carga.
2. HTML con recursos incrustados integra los recursos de la página dentro del HTML. Esto hace que cada página del documento sea autónoma, pero incrementa el tamaño de la página y afecta negativamente la velocidad de carga.

Para renderizar archivos a HTML, siga estos pasos:

1. Cree una instancia de la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique la ruta del documento de origen como parámetro del constructor.
2. Instancie el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a>. Especifique una ruta para guardar las páginas renderizadas.
3. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a> del objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>. Especifique el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> como parámetro.

## Renderizado a HTML con recursos externos {#rendering-to-html-with-external-resources}

El siguiente fragmento de código muestra cómo renderizar un documento .docx a HTML con recursos externos: 


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    var viewOptions = HtmlViewOptions.ForExternalResources();
    viewer.View(viewOptions);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForExternalResources()
            viewer.View(viewOptions)
        End Using
    End Sub
End Module
```

</TabItem>

## Preservar o deshabilitar JavaScript al renderizar a HTML {#preserving-or-disabling-javascript-when-rendering-to-html}

Muchos de los formatos y familias de formatos compatibles con GroupDocs.Viewer pueden contener distintos scripts (y/o macros) dentro de su contenido. Esto incluye (pero no se limita a) PDF, la mayoría de los formatos de la familia de procesamiento de textos (DOCX, DOCM, RTF, ODT, ...), hojas de cálculo (XLSX, XLSM, ...), presentaciones (PPTX, PPTM, ...) y correo electrónico (MSG, EML, EMLX, MBOX, ...), entre otros. Antes de la <a href="https://releases.groupdocs.com/viewer/net/release-notes/2025/groupdocs-viewer-for-net-25-2-release-notes/" target="_blank" rel="nofollow noopener noreferrer">versión 25.2</a>, al renderizar documentos con scripts al formato HTML, GroupDocs.Viewer intentaba preservar todos los scripts e insertarlos en el documento HTML resultante sin ningún cambio ni validación. Sin embargo, en algunos casos este comportamiento no es deseado, ya que el documento puede contener scripts maliciosos o perjudiciales, siendo los inyecciones XSS los más comunes; por lo tanto, es necesario limpiar el documento HTML resultante de cualquier script.

A partir de la versión 25.2, el comportamiento predeterminado cambió: ahora GroupDocs.Viewer elimina todos los scripts del documento HTML resultante de forma predeterminada. En algunos casos, cuando el código JavaScript se encuentra en los enlaces, GroupDocs.Viewer lo reemplaza por la cadena `"javascript:void(0)"`, de modo que no se producirá una recarga de la página al abrir el documento HTML resultante en el navegador. Cabe mencionar que el documento original cargado en la instancia <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">`Viewer`</a> permanecerá intacto de todas formas.

Además del comportamiento predeterminado modificado, se agregó una nueva opción a la clase <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">`HtmlViewOptions`</a>: una propiedad pública `RemoveJavaScript` de tipo <a href="https://learn.microsoft.com/dotnet/api/system.boolean" target="_blank" rel="nofollow noopener noreferrer">`System.Boolean`</a>. De forma predeterminada, esta propiedad tiene el valor `true`: el JavaScript se eliminará del documento HTML resultante. Para preservar el JavaScript, como ocurría en las versiones anteriores de GroupDocs.Viewer (antes de la 25.2), se debe asignar el valor `false` a esta propiedad.

El siguiente ejemplo de código muestra cómo abrir un documento XLSX de ejemplo y renderizarlo dos veces:
1. al HTML con recursos incrustados y JavaScript deshabilitado;
2. al HTML con recursos externos y JavaScript habilitado.


<Tabs groupId="example-RemoveJavaScript">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

HtmlViewOptions withoutJavaScriptEmbedded = HtmlViewOptions.ForEmbeddedResources("without-js-page{0}.html");

HtmlViewOptions withJavaScriptExternal = HtmlViewOptions.ForExternalResources("with-js-page{0}.html", "with-js-page{0}/resource-{1}", "with-js-page{0}/resource-{1}");
withJavaScriptExternal.RemoveJavaScript = false;

using (var viewer = new Viewer("Spreadsheet-with-script.xlsx"))
{
    viewer.View(withoutJavaScriptEmbedded);
    viewer.View(withJavaScriptExternal);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

	viewer.View(withoutJavaScriptEmbedded)
	viewer.View(withJavaScriptExternal)
End Using
```

Puede renderizar solo parte de las páginas del documento. Puede especificar una lista de páginas del documento de las siguientes maneras:
* [Especificar una lista de páginas como parámetros del método View](#specify-pages-as-parameters)
* [Especificar una lista de páginas mediante un array](#specify-pages-by-using-an-array)

## Especificar páginas como parámetros {#specify-pages-as-parameters}

Para especificar páginas como parámetros del método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>, siga estos pasos:

1. Instanciar el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>.
2. Instanciar el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> (o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>, o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>).
3. Llamar al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>. Especificar los números de página como últimos parámetros.

El siguiente fragmento de código muestra cómo renderizar la primera y la tercera páginas de un documento:


<Tabs groupId="example1">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
    // Create view options.
    HtmlViewOptions viewOptions = HtmlViewOptions.ForEmbeddedResources();

    // Specify the page numbers.
    viewer.View(viewOptions, 1, 3);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
    Using viewer As Viewer = New Viewer("sample.docx")
        ' Create view options.
        Dim viewOptions As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
    
        ' Specify the page numbers.
        viewer.View(viewOptions, 1, 3)
    End Using
    End Sub
End Module
```

</TabItem>

## Especificar páginas mediante un array {#specify-pages-by-using-an-array}

Para especificar páginas mediante un array, siga estos pasos:

1. Instanciar el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" target="_blank" rel="nofollow noopener noreferrer">Viewer</a>;
2. Instanciar el objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" target="_blank" rel="nofollow noopener noreferrer">HtmlViewOptions</a> (o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" target="_blank" rel="nofollow noopener noreferrer">JpgViewOptions</a>, o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" target="_blank" rel="nofollow noopener noreferrer">PngViewOptions</a>, o el <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" target="_blank" rel="nofollow noopener noreferrer">PdfViewOptions</a>);
3. Llamar al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" target="_blank" rel="nofollow noopener noreferrer">View</a>. Especificar el array de números de página como el segundo parámetro.

El siguiente fragmento de código muestra cómo renderizar la primera, segunda y cuarta páginas de un documento:


<Tabs groupId="example2">


<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

// Create an array and specify page numbers.
int[] pageNumbers = new int[] { 1, 2, 4 };

using (Viewer viewer = new Viewer("sample.docx"))
{
   // Create view options.
   var viewOptions = HtmlViewOptions.ForEmbeddedResources();

   // Use array to render specific pages.
   viewer.View(viewOptions, pageNumbers);
}
```

</TabItem>


<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        ' Create an array and specify page numbers.
        Dim pageNumbers = New Integer() {1, 2, 4}
    
        Using viewer As Viewer = New Viewer("sample.docx")
            ' Create view options.
            Dim viewOptions = HtmlViewOptions.ForEmbeddedResources()
    
            ' Use array to render specific pages.
            viewer.View(viewOptions, pageNumbers)
        End Using
    End Sub
End Module
```

</TabItem>

Esta sección describe los problemas que puede encontrar al procesar archivos con GroupDocs.Viewer y las soluciones correspondientes. La subsección `Known issues` describe las limitaciones conocidas.

## En Linux, los caracteres chinos aparecen como caracteres corruptos o se representan como cuadros {#on-linux-chinese-characters-are-garbled-or-rendered-as-boxes}

La causa habitual es que no se ha instalado el soporte para idiomas y no existen fuentes para mostrar correctamente los caracteres. Instale el soporte para idiomas asiáticos tal como se describe en los artículos que aparecen a continuación.

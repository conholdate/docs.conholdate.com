Docker proporciona un entorno aislado para servicios y aplicaciones. En este tema contenedorizamos una aplicacion de ejemplo que utiliza GroupDocs.Viewer. Puede obtener mas informacion sobre la contenerizacion en <a href="https://learn.microsoft.com/en-us/dotnet/core/docker/introduction" target="_blank" rel="nofollow noopener noreferrer">Introduccion a .NET y Docker</a>.

Ejecutar GroupDocs.Viewer en Docker es sencillo. En primer lugar, preparamos una aplicacion de ejemplo que utiliza el paquete <a href="https://www.nuget.org/packages/GroupDocs.Viewer.CrossPlatform" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer.CrossPlatform</a> de NuGet y, a continuacion, compilamos una imagen de Docker y ejecutamos la aplicacion en un contenedor de Docker.

En este articulo de documentacion utilizaremos <a href="https://learn.microsoft.com/en-us/dotnet/architecture/microservices/net-core-net-framework-containers/official-net-docker-images" target="_blank" rel="nofollow noopener noreferrer">la imagen oficial de Docker para .NET</a>, que se basa en la distribucion de Linux Debian.

## Requisitos previos

**Docker:** Docker debe estar instalado en su sistema. Consulte la documentacion oficial de Docker para obtener instrucciones detalladas de instalacion en <a href="https://docs.docker.com/get-docker/" target="_blank" rel="nofollow noopener noreferrer">Instalar Docker</a>.

**Aplicacion .NET:** En este tema ejecutaremos una aplicacion de ejemplo basada en .NET 8. Puede descargarla desde [aqui](/net/viewer/sample-files/how-to-run-groupdocs-viewer-in-docker/DemoApp.zip). Como alternativa, puede utilizar su propia aplicacion basada en los fragmentos de codigo proporcionados a continuacion.

<Tabs groupId="demo-app">

<TabItem value="demoapp-csproj" label="DemoApp.csproj" default>

```xml
  <PropertyGroup>
    <OutputType>Exe</OutputType>

  </PropertyGroup>

  <ItemGroup>

  </ItemGroup>

  <ItemGroup>
    <None Update="formatting.docx">
      <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
    </None>
  </ItemGroup>

</Project>
```

</TabItem>

<TabItem value="program-cs" label="Program.cs">

```cs
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

namespace DemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            // Instantiate Viewer and pass file name
            using (Viewer viewer = new Viewer("formatting.docx"))
            {
                // Configure view options
                HtmlViewOptions viewOptions =
                    HtmlViewOptions.ForEmbeddedResources("output/page-{0}.html");

                // Render DOCX to HTML
                viewer.View(viewOptions);
            }
        }
    }
}
```

## Agregar Dockerfile

Para crear una imagen de Docker, agregue un archivo `Dockerfile` y un archivo `.dockerignore` a su proyecto. 

<Tabs groupId="dockerfile">

<TabItem value="dockerfile" label="Dockerfile" default>

```Dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0
WORKDIR /app

# Add `contrib` archive area to package sources list
RUN sed -i 's/^Components: main$/& contrib/' /etc/apt/sources.list.d/debian.sources

# Download the package lists from the repositories
# and install two packages `fontconfig` and `ttf-mscorefonts-installer`
RUN apt update && apt install -y \
    fontconfig \
    ttf-mscorefonts-installer 

# Copy the application and restore packages
COPY . .
RUN dotnet restore 

# Run the application
ENTRYPOINT ["dotnet", "run"]
```

</TabItem>

<TabItem value="dockerignore" label=".dockerignore">

```txt
**/.dockerignore
**/Dockerfile*
**/.vs
**/.vscode
**/*.*proj.user
**/bin
**/obj
```

</TabItem>

</Tabs>

En este punto, el arbol de carpetas deberia verse similar a la siguiente estructura de directorios:

```Directory
?? DemoApp
 +--DemoApp.csproj
 +--Program.cs
 +--formatting.docx
 +--Dockerfile
 L--.dockerignore
```

El `Dockerfile` contiene instrucciones para instalar dos dependencias requeridas por GroupDocs.Viewer:

**fontconfig:** Esta biblioteca configura y personaliza el acceso a las fuentes.

**ttf-mscorefonts-installer:** Este paquete proporciona las fuentes core TrueType de Microsoft. Esta disponible en el area de repositorio <a href="https://www.debian.org/doc/debian-policy/ch-archive#s-contrib" target="_blank" rel="nofollow noopener noreferrer">contrib</a>. (Nota: El uso de fuentes no libres puede tener implicaciones de licencia; por lo tanto, asegurese de revisar los terminos de la licencia.)

## Compilacion de la imagen Docker

En este punto ya estamos listos para compilar la imagen Docker. Asegurese de que Docker este activo y en ejecucion, dirijase al directorio `DemoApp` y ejecute el siguiente comando en la linea de comandos para compilar la imagen.

```bash
docker build -t viewer-demo-app .
```

`-t`: se utiliza para nombrar y etiquetar la imagen. Nombramos la imagen como `viewer-demo-app` sin etiqueta.

`.`: ruta del contexto de compilacion. En este ejemplo, es el directorio actual.

## Ejecutar el contenedor de Docker

Para ejecutar nuestra aplicacion contenida en un contenedor, utilice el siguiente comando en el directorio `DemoApp`.

```bash
docker run --rm -v ${pwd}/output:/app/output viewer-demo-app
```

`--rm`: Elimina el contenedor y limpia el sistema de archivos al finalizar.

`-v ${pwd}/output:/app/output`: Mapea el directorio `./output` del sistema operativo anfitrion al directorio `/app/output` dentro del contenedor Docker.

Despues de ejecutar la aplicacion, el directorio `./output` contendra dos archivos: `page-1.html` y `page-2.html`, debido a las limitaciones de la version de evaluacion. Para procesar todos los archivos, debe configurar una licencia valida. Obtenga mas informacion sobre las limitaciones de la evaluacion y la version de prueba gratuita en [Como evaluar GroupDocs.Viewer](/net/viewer/licensing-and-evaluation/).

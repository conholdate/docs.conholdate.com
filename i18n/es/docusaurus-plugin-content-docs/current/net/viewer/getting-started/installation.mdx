## Instalacion de GroupDocs.Viewer mediante paquetes NuGet {#install-groupdocs-viewer-using-nuget-packages}
  
Puede utilizar las siguientes herramientas para instalar los paquetes NuGet **GroupDocs.Viewer** o **GroupDocs.Viewer.CrossPlatform**:  

- [NuGet Package Manager](#use-the-nuget-package-manager)  
- [Package Manager Console](#use-the-package-manager-console)  
- [.NET CLI](#use-the-net-cli)  

### Uso del NuGet Package Manager {#use-the-nuget-package-manager}

:::tip
Las versiones anteriores de Visual Studio no incluyen el Administrador de paquetes NuGet. Este puede agregarse como una extension desde el <a href="https://marketplace.visualstudio.com/" rel="nofollow">Visual Studio Marketplace</a>.

* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManagerforVisualStudio2015" rel="nofollow">Administrador de paquetes NuGet para Visual Studio 2015</a>  
* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManagerforVisualStudio2013" rel="nofollow">Administrador de paquetes NuGet para Visual Studio 2013</a>  
* <a href="https://marketplace.visualstudio.com/items?itemName=NuGetTeam.NuGetPackageManager" rel="nofollow">Administrador de paquetes NuGet para Visual Studio 2010 y 2012</a>
:::

Abra su proyecto o solucion en Visual Studio y siga los pasos a continuacion para instalar el paquete **GroupDocs.Viewer** o **GroupDocs.Viewer.CrossPlatform** mediante el Administrador de paquetes NuGet:

1. En el **Explorador de soluciones**, haga clic con el boton derecho en el nombre de su proyecto y seleccione **Administrar paquetes NuGet** para mostrar el Administrador de paquetes NuGet.

    ![Add NuGet package in Visual Studio](/net/viewer/images/getting-started/installation/manage-nuget-packages.png)

2. Seleccione la pestana **Examinar** y escriba **GroupDocs.Viewer** o **GroupDocs.Viewer.CrossPlatform** en el cuadro de busqueda. Seleccione la version mas reciente del paquete y haga clic en **Instalar**.

    ![Install GroupDocs.Viewer NuGet package in Visual Studio](/net/viewer/images/getting-started/installation/install-nuget-package.png)

### Usar la consola del administrador de paquetes {#use-the-package-manager-console}

El <a href="https://learn.microsoft.com/en-us/nuget/consume-packages/install-use-packages-powershell" rel="nofollow">Consola del administrador de paquetes</a> usa comandos de PowerShell para instalar, actualizar y eliminar paquetes de NuGet. Abra su proyecto en Visual Studio y haga clic en **Herramientas** > **Administrador de paquetes NuGet** > **Consola del Administrador de paquetes** para abrir la ventana de la consola. Ejecute el siguiente comando para instalar la version mas reciente del paquete:

<Tabs groupId="example1">

<TabItem value="groupdocs-viewer-for-net" label="GroupDocs.Viewer for .NET" default>

```
PM> Install-Package GroupDocs.Viewer
```

</TabItem>

<TabItem value="groupdocs-viewer-crossplatform" label="GroupDocs.Viewer.CrossPlatform">

```
PM> Install-Package GroupDocs.Viewer.CrossPlatform
```

</TabItem>

</Tabs>

![Use Package Manager Console ](/net/viewer/images/getting-started/installation/package-manager-console.png)

## Descargar GroupDocs.Viewer desde el sitio web oficial {#download-groupdocs-viewer-from-the-official-website}
  
Visite https://releases.groupdocs.com/viewer/net/ y descargue los ensamblados **GroupDocs.Viewer** como un archivo ZIP o un instalador MSI. Para hacer referencia a los archivos de ensamblado descargados en su proyecto, realice los siguientes pasos:

1. Extraiga los archivos del archivo ZIP o ejecute el instalador MSI para instalar **GroupDocs.Viewer** en una ubicacion especifica de su equipo.  
2. Abra su solucion o proyecto en Visual Studio.  
3. En el **Explorador de soluciones**, haga clic con el boton derecho en el nodo **Referencias** o **Dependencias**, y seleccione **Agregar referencia** (para un proyecto de .NET Framework) o **Agregar referencia de proyecto** (para un proyecto de .NET).

    ![Add project reference in Visual Studio](/net/viewer/images/getting-started/installation/add-project-reference.png)

4. En el cuadro de dialogo **Administrador de referencias**, seleccione la pestana **Examinar** y haga clic en **Examinar** para localizar el archivo _GroupDocs.Viewer.dll_ correspondiente al marco de trabajo objetivo.

    ![Browse for the GroupDocs.Viewer assembly](/net/viewer/images/getting-started/installation/browse-for-groupdocs-dll.png)

5. Haga clic en **Aceptar** para agregar una referencia a la biblioteca **GroupDocs.Viewer** a su proyecto.

:::warning
Asegurese de que su proyecto tenga todas las dependencias necesarias instaladas si su aplicacion esta dirigida a .NET Core / .NET 5+. Consulte la siguiente pagina para obtener mas detalles: <a href="https://www.nuget.org/packages/groupdocs.viewer#dependencies-body-tab" rel="nofollow">GroupDocs.Viewer dependencias</a>.
:::

Para estudiar el sistema, es posible que desee acceso rapido a la API. Para facilitar esto, GroupDocs.Viewer ofrece distintos planes de compra, asi como una prueba gratuita y una licencia temporal de 30 dias para su evaluacion.

:::info
Tenga en cuenta que existen varias politicas y practicas generales que le guian sobre como evaluar, licenciar adecuadamente y adquirir nuestros productos. Puede encontrarlas en la seccion <a href="https://purchase.groupdocs.com/policies" rel="nofollow">Politicas de compra y preguntas frecuentes</a>.
:::

## Como evaluar GroupDocs.Viewer

Tambien puede probar GroupDocs.Viewer sin adquirir una licencia.

### Prueba gratuita

La version de evaluacion es identica a la version comprada; se convierte en una version con licencia una vez que configure la licencia. Puede configurar la licencia mediante los metodos descritos en las siguientes secciones de este articulo.

La version de evaluacion presenta las siguientes limitaciones:

- El procesamiento se limita a las primeras 2 paginas.
- Se agregan insignias de prueba en la parte superior de la pagina procesada.

### Licencia temporal

Si desea probar GroupDocs.Viewer sin las limitaciones de la version de prueba, solicite una Licencia temporal de 30 dias. Para obtener mas informacion, consulte la pagina <a href="https://purchase.groupdocs.com/temporary-license" rel="nofollow">Obtener una licencia temporal</a>.

## Licencia comprada

Tras la compra, aplique el archivo de licencia o incruste la licencia como un recurso embebido.

La licencia debe configurarse:
- Solo una vez por dominio de aplicacion
- Antes de utilizar cualquier otra clase de GroupDocs.Viewer

### Opciones para aplicar la licencia

Las licencias pueden aplicarse desde distintas ubicaciones:

*   Una ruta explicita
*   La carpeta que contiene el archivo _GroupDocs.Viewer.dll_
*   La carpeta que contiene el ensamblado que llamo a _GroupDocs.Viewer.dll_
*   La carpeta que contiene el ensamblado de entrada (su _.exe_)
*   Como una licencia basada en uso (Metered License), que le permite pagar segun su consumo. Para obtener mas informacion, consulte la pagina <a href="https://purchase.groupdocs.com/faqs/licensing/metered/" rel="nofollow">Preguntas frecuentes sobre licencias basadas en uso</a>.
*   Como un recurso embebido

Cuando haga referencia a _GroupDocs.Viewer.dll_ en su aplicacion, la biblioteca se copiara en su directorio de salida (a menos que la propiedad **Copiar localmente** de esa entrada este establecida en `false`). El metodo mas sencillo para configurar una licencia suele ser colocar el archivo de licencia en la misma carpeta que _GroupDocs.Viewer.dll_ y especificar unicamente el nombre del archivo, sin la ruta.

Utilice el metodo <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/license/setlicense/" rel="nofollow">SetLicense</a> para licenciar un componente.

Llamar varias veces a `SetLicense` no es perjudicial, simplemente consume tiempo de procesamiento innecesariamente.

Llamar varias veces a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/metered/setmeteredkey/" rel="nofollow">SetMeteredKey</a> tampoco es perjudicial, pero consume tiempo de procesamiento y puede acumular el consumo de forma incorrecta.

#### Aplicar la licencia

Tras obtener la licencia, configurela. Esta seccion explica como hacerlo. Durante el desarrollo de su aplicacion, invoque el metodo `SetLicense` en el codigo de inicio, antes de utilizar las clases de GroupDocs.Viewer.

##### Configurar una licencia desde un archivo

El siguiente fragmento de codigo muestra como configurar una licencia desde un archivo:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
// ...

string licensePath = "GroupDocs.Viewer.lic";
License license = new License();
license.SetLicense(licensePath);
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Dim licensePath As String = "GroupDocs.Viewer.lic"
        Dim license As License = New License()
        license.SetLicense(licensePath)
    End Sub
End Module
```

</TabItem>

</Tabs>

#### Aplicar licencia medible

Puede configurar la licencia <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/metered" rel="nofollow">Metered</a> como alternativa al archivo de licencia. Esto resulta util para los clientes que desean facturarse segun el uso de las funciones de la API. Para obtener mas detalles, consulte <a href="https://purchase.groupdocs.com/faqs/licensing/metered" rel="nofollow">Metered Licensing FAQ</a>.

El siguiente fragmento de codigo muestra como utilizar la licencia medible:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Viewer.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Viewer.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Dim publicKey As String = "" ' Your public license key
        Dim privateKey As String = "" ' Your private license key
    
        Dim metered As Metered = New Metered()
        metered.SetMeteredKey(publicKey, privateKey)

        ' Get count of credits consumed
        Dim creditsConsumed As Decimal = GroupDocs.Viewer.Metered.GetConsumptionCredit()
        Console.WriteLine("Credits consumed: " & creditsConsumed.ToString())
    End Sub
End Module
```

#### Aplicar licencia desde un recurso incrustado

En lugar de utilizar un archivo de licencia, puede instalar la licencia como un recurso incrustado. Para ello, agregue una licencia al proyecto y especifique el nombre de la licencia en el metodo `SetLicense` sin indicar la ruta completa a este archivo.

:::info
Para usar la licencia integrada, agreguela a su proyecto y establezca la propiedad **Build Action** de este archivo en "Embedded Resource". Asegurese de que el nombre de la licencia en los recursos integrados coincida con el parametro de tipo cadena del metodo `SetLicense`.
:::

El siguiente fragmento de codigo muestra como utilizar la licencia integrada:

using GroupDocs.Viewer;
// ...

### Cambiar el nombre del archivo de licencia

No es necesario que el archivo de licencia se llame "GroupDocs.Viewer.lic". Puede renombrarlo segun su preferencia y utilizar ese nombre al configurar la licencia en su aplicacion.

### Excepcion «No se puede encontrar el nombre del archivo de licencia»

Cuando adquiere y descarga una licencia desde el sitio web de GroupDocs, el archivo de licencia recibe el nombre "GroupDocs.Viewer.lic". Descarguelo utilizando su navegador. En ocasiones, los navegadores lo reconocen como XML y le agregan la extension .xml, lo que hace que el nombre completo del archivo en su computadora sea "GroupDocs.Viewer.lic.XML".

Si Microsoft Windows esta configurado para ocultar las extensiones de archivo (configuracion predeterminada en la mayoria de las instalaciones), el archivo de licencia aparecera en el Explorador de archivos como "GroupDocs.Viewer.lic". Podria asumir erroneamente que este es el nombre real del archivo e invocar el metodo `SetLicense` con "GroupDocs.Viewer.lic", cuando en realidad no existe tal archivo, lo que provocara una excepcion.

Para solucionar este problema, renombre el archivo eliminando la extension oculta .xml. Ademas, le sugerimos deshabilitar la opcion **Ocultar extensiones** en Microsoft Windows.

Ofrecemos multiples soluciones sobre como ejecutar ejemplos de GroupDocs.Viewer, ya sea construyendo los suyos propios o utilizando nuestros ejemplos de backend o frontend.

## Construir proyecto desde cero

Puede construir un proyecto desde cero utilizando Visual Studio o la <a href="https://docs.microsoft.com/en-us/dotnet/core/tools/" rel="nofollow">CLI de .NET</a>. Le guiaremos paso a paso en ambos casos.

### Construir proyecto utilizando la CLI de .NET

1. Asegurese de tener instalado .NET Core o el SDK de .NET <a href="https://dotnet.microsoft.com/download" rel="nofollow">https://dotnet.microsoft.com/download</a>.
2. Cree un directorio para su aplicacion de consola ejecutando, por ejemplo, `mkdir my-console-app` en su terminal.
3. Navegue hasta el directorio `my-console-app` ejecutando `cd my-console-app`.
4. Cree una aplicacion de consola vacia ejecutando `dotnet new console`
5. Agregue el paquete GroupDocs.Viewer for .NET `dotnet add package GroupDocs.Viewer`
6. Edite `Program.cs` y agregue las siguientes lineas al metodo `Main`

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
   string outputFilePathFormat = @"output\page-{0}.html";
   HtmlViewOptions options = HtmlViewOptions.ForEmbeddedResources(outputFilePathFormat);
   
   viewer.View(options);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            Dim outputFilePathFormat As String = "output\page-{0}.html"
            Dim options As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources(outputFilePathFormat)

            viewer.View(options)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

7. Reemplace el valor de `documentPath` con la ruta real al documento que va a renderizar.  
8. Ejecute el proyecto ejecutando `dotnet run`.  
9. Verifique la salida en el directorio `C:\\output\\`.  

### Compilar el proyecto utilizando Visual Studio  

1. Abra Visual Studio y vaya a **Archivo** -> **Nuevo** -> **Proyecto**.  
2. Seleccione el tipo de proyecto adecuado, por ejemplo, Aplicacion de consola o Aplicacion de consola (.NET Framework).  
3. Instale **GroupDocs.Viewer for .NET** desde NuGet o desde el sitio web oficial de GroupDocs, utilizando uno de los metodos indicados en la seccion «Instalacion» (/net/viewer/getting-started/installation/).  
4. Agregue el siguiente codigo al metodo `Main`:

<Tabs groupId="example2">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
// ...

using (Viewer viewer = new Viewer("sample.docx"))
{
   string outputFilePathFormat = @"output\page-{0}.html";
   HtmlViewOptions options = HtmlViewOptions.ForEmbeddedResources(outputFilePathFormat);
   viewer.View(options);
}
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
' ...

Module Program
    Sub Main(args As String())
        Using viewer As Viewer = New Viewer("sample.docx")
            Dim outputFilePathFormat As String = "output\page-{0}.html"
            Dim options As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources(outputFilePathFormat)
            viewer.View(options)
        End Using
    End Sub
End Module
```

</TabItem>

</Tabs>

5. Reemplace el valor de `documentPath` con la ruta real al documento que va a renderizar.  
6. Compile y ejecute su proyecto.  
7. Las paginas del documento renderizado se guardaran en el directorio `C:\\output\\`.

## Ejecutar ejemplos del backend

Puede encontrar varios ejemplos de backend en nuestro repositorio alojado en <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" rel="nofollow">Github</a>. Puede descargar el archivo ZIP desde <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/archive/master.zip" rel="nofollow">aqui</a> o clonar el repositorio de GitHub utilizando su cliente de Git favorito.  
En caso de descargar el archivo ZIP, extraiga las carpetas en su disco local.

1. Navegue hasta el directorio `Examples` y abra `GroupDocs.Viewer.Examples.CSharp.sln` con Visual Studio.  
2. Abra el archivo `RunExamples.cs` y descomente los ejemplos que desea ejecutar.  
3. Opcionalmente, puede establecer la ruta de la licencia en el archivo `Utils.cs`.

## Ejecutar proyectos de demostracion

Para ejecutar cualquier demostracion de los <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/tree/master/Demos/" rel="nofollow">GroupDocs.Viewer for .NET proyectos de demostracion</a>, puede:

* Clonar el repositorio:

<TabItem value="git" label="Git" default>

```bash
git clone git@github.com:groupdocs-viewer/GroupDocs.Viewer-for-.NET.git  
```

</TabItem>

</Tabs>

* O <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/archive/master.zip" rel="nofollow">descargue</a> el codigo fuente.

### Demostracion de ASP.NET Core

1. Clone o descargue el repositorio <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" rel="nofollow">"GroupDocs.Viewer-para-.NET"</a> desde GitHub o omita este paso si ya dispone del codigo.
2. Navegue hasta la carpeta `Demos/ASP.NET Core`.
3. Ejecute `dotnet run` en una terminal.
4. Abra <a href="http://localhost:8080/viewer" rel="nofollow">http://localhost:8080/viewer</a> en su navegador favorito.

### Demostracion de ASP.NET MVC

1. Clone o descargue el repositorio <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET" rel="nofollow">"GroupDocs.Viewer-para-.NET"</a> desde GitHub o omita este paso si ya dispone del codigo.
2. Navegue hasta la carpeta `Demos/MVC`.
3. Abra la solucion `GroupDocs.Viewer MVC.sln` ubicada en la carpeta `Demos/MVC` utilizando Visual Studio.
4. Actualice los parametros en **web.config** y las propiedades relacionadas con la demostracion en **configuration.yml** para satisfacer sus necesidades; consulte mas informacion sobre la configuracion de la demostracion en la seccion <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/tree/master/Demos/MVC#configuration" rel="nofollow">"Configuration"</a>.
5. Ejecute el proyecto y abra <a href="http://localhost:8080/viewer" rel="nofollow">http://localhost:8080/viewer</a> en su navegador favorito.

:::info
Para obtener mas detalles sobre la configuracion de la demostracion, consulte la seccion <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/tree/master/Demos/MVC#configuration" rel="nofollow">«Configuracion»</a>.
:::

### Demo de ASP.NET Web Forms

5. Abra <a href="http://localhost:8080/viewer" rel="nofollow">http://localhost:8080/viewer</a> en su navegador favorito.

:::info
Para obtener mas detalles sobre la configuracion de la demostracion, consulte la seccion <a href="https://github.com/groupdocs-viewer/GroupDocs.Viewer-for-.NET/tree/master/Demos/WebForms#configuration" rel="nofollow">«Configuracion»</a>.

## Contribuir

Para contribuir, puede bifurcar (fork) el repositorio, editar el codigo y crear una solicitud de extraccion (pull request). Revisaremos los cambios y los incluiremos en el repositorio si se consideran utiles.

Renderice los adjuntos de la misma manera que cualquier otro documento.

Para ver los adjuntos, siga estos pasos:

1. Instancie el primer objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a>. Especifique un archivo que contenga adjuntos.  
2. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/saveattachment" rel="nofollow">SaveAttachment</a> para guardar el adjunto (en disco local, flujo de memoria, etc.).  
3. Instancie el segundo objeto <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer" rel="nofollow">Viewer</a>. Especifique el adjunto guardado anteriormente.  
4. Especifique las opciones de vista según el formato de salida: <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/htmlviewoptions" rel="nofollow">HtmlViewOptions</a> / <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pngviewoptions" rel="nofollow">PngViewOptions</a> / <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/jpgviewoptions" rel="nofollow">JpgViewOptions</a> / <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer.options/pdfviewoptions" rel="nofollow">PdfViewOptions</a>.  
5. Llame al método <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/viewer/methods/view" rel="nofollow">View</a>.

El siguiente fragmento de código muestra cómo renderizar adjuntos desde un archivo MSG:

:::info
NOTA: el fragmento de código proporcionado es compatible con todas las familias de formatos que admiten archivos adjuntos: correos electrónicos, archivos de datos de Outlook, archivos comprimidos y documentos PDF.
:::

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using System.IO;
using GroupDocs.Viewer;
using GroupDocs.Viewer.Options;
using GroupDocs.Viewer.Results;
// ...

// Specify attachment.
Attachment attachment = new Attachment("attachment-word.doc", @"C:\Output\attachment-word.doc");

// Create a stream for attachment.
MemoryStream attachmentStream = new MemoryStream();

//Save attachment
using (Viewer viewer = new Viewer("sample.msg"))
{
    viewer.SaveAttachment(attachment, attachmentStream);
}

// Render attachment
using (Viewer viewer = new Viewer(attachmentStream))
{
    HtmlViewOptions options = HtmlViewOptions.ForEmbeddedResources();
    viewer.View(options);
}
```

<TabItem value="vb-net" label="VB.NET">

```vb
Imports System.IO
Imports GroupDocs.Viewer
Imports GroupDocs.Viewer.Options
Imports GroupDocs.Viewer.Results
' ...

Module Program
    Sub Main(args As String())
        ' Specify attachment.
        Dim attachment As Attachment = New Attachment("attachment-word.doc", "C:\Output\attachment-word.doc")
    
        ' Create a stream for attachment.
        Dim attachmentStream As MemoryStream = New MemoryStream()
    
        'Save attachment
        Using viewer As Viewer = New Viewer("sample.msg")
            viewer.SaveAttachment(attachment, attachmentStream)
        End Using
    
        ' Render attachment
        Using viewer As Viewer = New Viewer(attachmentStream)
            Dim options As HtmlViewOptions = HtmlViewOptions.ForEmbeddedResources()
            viewer.View(options)
        End Using
    End Sub
End Module
```

:::info
GroupDocs.Viewer for .NET (incluyendo GroupDocs.Viewer.CrossPlatform) no requiere la instalación de ningún software externo, como Microsoft Word, Microsoft Excel o Microsoft PowerPoint. Para instalar GroupDocs.Viewer for .NET, simplemente siga uno de los métodos descritos en la sección [Installation](/net/viewer/v26.5/getting-started/installation/).
:::

## Sistemas operativos compatibles

GroupDocs.Viewer for .NET puede utilizarse en cualquier sistema operativo de 32 o 64 bits en el que esté instalado .NET Framework 4.6.2 o superior, o .NET 6 o superior, incluidos, sin limitarse a:

### Windows

**GroupDocs.Viewer for .NET**:

* Microsoft Windows Server 2003 y versiones posteriores  
* Microsoft Windows XP (x64, x86)  
* Microsoft Windows Vista (x64, x86)  
* Microsoft Windows 7, 8, 8.1 (x64, x86)  
* Microsoft Windows 10 (x64, x86)  
* Microsoft Windows 11 (x64)  

**GroupDocs.Viewer.CrossPlatform** puede utilizarse en versiones de Microsoft Windows x86 y x64 que también admitan .NET 6.0:

* Microsoft Windows 7.1 SP1  
* Microsoft Windows 8.1  
* Microsoft Windows 10 Versión 1607+  
* Microsoft Windows 11 Versión 22000+  
* Microsoft Windows Server 2012+  
* Microsoft Windows Server Core 2012+  
* Microsoft Nano Server Versión 1809+  

### Linux

* Linux (Ubuntu, OpenSUSE, CentOS y otros)

### Mac

Tanto GroupDocs.Viewer for .NET como GroupDocs.Viewer.CrossPlatform admiten Mac OS X. GroupDocs.Viewer.CrossPlatform requiere macOS versión 10.15 o superior.

## Frameworks y entornos de ejecución de destino compatibles

**GroupDocs.Viewer for .NET** admite las plataformas .NET Framework y .NET. La versión actual admite .NET Framework 4.6.2 y superior, así como .NET 6 y superior. Las versiones anteriores de GroupDocs.Viewer for .NET también admitieron versiones anteriores de .NET Framework: el soporte para .NET Framework 2.0 y 3.5 se eliminó a partir de la versión 22.3, y el soporte para .NET Framework 4.0 a 4.6.0 se eliminó a partir de la versión 23.8.

**GroupDocs.Viewer.CrossPlatform** no admite .NET Framework. Su requisito mínimo es .NET 6.0 o superior.

## Entornos de desarrollo

GroupDocs.Viewer for .NET puede utilizarse para desarrollar aplicaciones en cualquier entorno de desarrollo que apunte a .NET, aunque los entornos explícitamente compatibles son los siguientes:

* Microsoft Visual Studio 2010 y versiones posteriores  
* Microsoft Visual Studio para Mac  
* Rider de JetBrains  

## Fuentes necesarias

Al trabajar con documentos que contengan jeroglíficos chinos, para obtener resultados de representación válidos sin excepciones ni caracteres de sustitución (normalmente representados como cuadrados vacíos) en los documentos generados, es necesario que una <a href="https://learn.microsoft.com/en-us/typography/font-list/simsun" rel="nofollow">SimSun</a> La fuente debe estar instalada en el sistema operativo.

Al utilizar Microsoft Windows, esto no debería suponer un problema, ya que SimSun está preinstalada en todas las versiones y ediciones de Windows a partir de Windows 2000 (por ejemplo, Windows XP tiene preinstalada la versión 3.03 de SimSun, y Windows 7 tiene preinstalada la versión :::info de SimSun). <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_7_font_list" rel="nofollow">5.03</a>y Windows 10 — versión SimSun <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_10_font_list" rel="nofollow">5.16</a>). Pero en Linux, SimSun generalmente no está instalado, por lo que es necesario instalarlo manualmente. Esto también es válido al ejecutar GroupDocs.Viewer en un entorno Docker y utilizar una imagen de Linux.

Para estudiar el sistema, es posible que desee acceso rápido a la API. Para facilitar esto, GroupDocs.Viewer ofrece distintos planes de compra, así como una prueba gratuita y una licencia temporal de 30 días para su evaluación.

:::info
Tenga en cuenta que existen varias políticas y prácticas generales que le guían sobre cómo evaluar, licenciar adecuadamente y adquirir nuestros productos. Puede encontrarlas en la sección <a href="https://purchase.groupdocs.com/policies" rel="nofollow">Políticas de compra y preguntas frecuentes</a>.
:::

## Cómo evaluar GroupDocs.Viewer

También puede probar GroupDocs.Viewer sin adquirir una licencia.

### Prueba gratuita

La versión de evaluación es idéntica a la versión comprada; se convierte en una versión con licencia una vez que configure la licencia. Puede configurar la licencia mediante los métodos descritos en las siguientes secciones de este artículo.

La versión de evaluación presenta las siguientes limitaciones:

- El procesamiento se limita a las primeras 2 páginas.
- Se agregan insignias de prueba en la parte superior de la página procesada.

### Licencia temporal

Si desea probar GroupDocs.Viewer sin las limitaciones de la versión de prueba, solicite una Licencia temporal de 30 días. Para obtener más información, consulte la página <a href="https://purchase.groupdocs.com/temporary-license" rel="nofollow">Obtener una licencia temporal</a>.

## Licencia comprada

Tras la compra, aplique el archivo de licencia o incruste la licencia como un recurso embebido.

La licencia debe configurarse:
- Solo una vez por dominio de aplicación
- Antes de utilizar cualquier otra clase de GroupDocs.Viewer

### Opciones para aplicar la licencia

Las licencias pueden aplicarse desde distintas ubicaciones:

*   Una ruta explícita
*   La carpeta que contiene el archivo _GroupDocs.Viewer.dll_
*   La carpeta que contiene el ensamblado que llamó a _GroupDocs.Viewer.dll_
*   La carpeta que contiene el ensamblado de entrada (su _.exe_)
*   Como una licencia basada en uso (Metered License), que le permite pagar según su consumo. Para obtener más información, consulte la página <a href="https://purchase.groupdocs.com/faqs/licensing/metered/" rel="nofollow">Preguntas frecuentes sobre licencias basadas en uso</a>.
*   Como un recurso embebido

Cuando haga referencia a _GroupDocs.Viewer.dll_ en su aplicación, la biblioteca se copiará en su directorio de salida (a menos que la propiedad **Copiar localmente** de esa entrada esté establecida en `false`). El método más sencillo para configurar una licencia suele ser colocar el archivo de licencia en la misma carpeta que _GroupDocs.Viewer.dll_ y especificar únicamente el nombre del archivo, sin la ruta.

Utilice el método <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/license/setlicense/" rel="nofollow">SetLicense</a> para licenciar un componente.

Llamar varias veces a `SetLicense` no es perjudicial, simplemente consume tiempo de procesamiento innecesariamente.

Llamar varias veces a <a href="https://reference.groupdocs.com/viewer/net/groupdocs.viewer/metered/setmeteredkey/" rel="nofollow">SetMeteredKey</a> tampoco es perjudicial, pero consume tiempo de procesamiento y puede acumular el consumo de forma incorrecta.

#### Aplicar la licencia

Tras obtener la licencia, configúrela. Esta sección explica cómo hacerlo. Durante el desarrollo de su aplicación, invoque el método `SetLicense` en el código de inicio, antes de utilizar las clases de GroupDocs.Viewer.

##### Configurar una licencia desde un archivo

El siguiente fragmento de código muestra cómo configurar una licencia desde un archivo:

<Tabs groupId="example1">

<TabItem value="c" label="C#" default>

```csharp
using GroupDocs.Viewer;
// ...

string licensePath = "GroupDocs.Viewer.lic";
License license = new License();
license.SetLicense(licensePath);
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb
Imports GroupDocs.Viewer
' ...

Module Program
    Sub Main(args As String())
        Dim licensePath As String = "GroupDocs.Viewer.lic"
        Dim license As License = New License()
        license.SetLicense(licensePath)
    End Sub
End Module
```

</TabItem>

</Tabs>

#### Aplicar licencia medible

Puede configurar la licencia <a href="https://reference.groupdocs.com/net/viewer/groupdocs.viewer/metered" rel="nofollow">Metered</a> como alternativa al archivo de licencia. Esto resulta útil para los clientes que desean facturarse según el uso de las funciones de la API. Para obtener más detalles, consulte <a href="https://purchase.groupdocs.com/faqs/licensing/metered" rel="nofollow">Metered Licensing FAQ</a>.

El siguiente fragmento de código muestra cómo utilizar la licencia medible:

<Tabs groupId="example3">

<TabItem value="c" label="C#" default>

```csharp
using System;
using GroupDocs.Viewer;
// ...

string publicKey = ""; // Your public license key
string privateKey = ""; // Your private license key

Metered metered = new Metered();
metered.SetMeteredKey(publicKey, privateKey);

// Get amount (MB) consumed
decimal amountConsumed = GroupDocs.Viewer.Metered.GetConsumptionQuantity();
Console.WriteLine("Amount (MB) consumed: " + amountConsumed);

// Get count of credits consumed
decimal creditsConsumed = GroupDocs.Viewer.Metered.GetConsumptionCredit();
Console.WriteLine("Credits consumed: " + creditsConsumed);
```

</TabItem>

<TabItem value="vb-net" label="VB.NET">

```vb

    End Sub
End Module
```

#### Aplicar licencia desde un recurso incrustado

En lugar de utilizar un archivo de licencia, puede instalar la licencia como un recurso incrustado. Para ello, agregue una licencia al proyecto y especifique el nombre de la licencia en el método `SetLicense` sin indicar la ruta completa a este archivo.

:::info
Para usar la licencia integrada, agréguela a su proyecto y establezca la propiedad **Build Action** de este archivo en "Embedded Resource". Asegúrese de que el nombre de la licencia en los recursos integrados coincida con el parámetro de tipo cadena del método `SetLicense`.
:::

### Cambiar el nombre del archivo de licencia

No es necesario que el archivo de licencia se llame "GroupDocs.Viewer.lic". Puede renombrarlo según su preferencia y utilizar ese nombre al configurar la licencia en su aplicación.

### Excepción «No se puede encontrar el nombre del archivo de licencia»

Cuando adquiere y descarga una licencia desde el sitio web de GroupDocs, el archivo de licencia recibe el nombre "GroupDocs.Viewer.lic". Descárguelo utilizando su navegador. En ocasiones, los navegadores lo reconocen como XML y le agregan la extensión .xml, lo que hace que el nombre completo del archivo en su computadora sea "GroupDocs.Viewer.lic.XML".

Si Microsoft Windows está configurado para ocultar las extensiones de archivo (configuración predeterminada en la mayoría de las instalaciones), el archivo de licencia aparecerá en el Explorador de archivos como "GroupDocs.Viewer.lic". Podría asumir erróneamente que este es el nombre real del archivo e invocar el método `SetLicense` con "GroupDocs.Viewer.lic", cuando en realidad no existe tal archivo, lo que provocará una excepción.

Para solucionar este problema, renombre el archivo eliminando la extensión oculta .xml. Además, le sugerimos deshabilitar la opción **Ocultar extensiones** en Microsoft Windows.

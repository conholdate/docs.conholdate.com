| *OpenType* | Scalable Computer Fonts | Supported |  |  |
| *WOFF* | Web Open Font Format | Supported | Supported |  |
| *WOFF2* | Web Open Font Format version 2.0 | Supported | Supported |  |

| *SVG* | Scalable Vector Graphics format |  | Supported |  |

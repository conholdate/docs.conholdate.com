### Evaluation Version Limitations {#evaluation-version-limitations}

The evaluation version of Aspose.TeX (without a license specified) provides full product functionality except that only up to four first pages can be obtained in the output document. Also, those pages will be stamped with an evaluation mode watermark.

If you want to try Aspose.TeX out without evaluation limitations, request a 30-day temporary license. Please refer to <a href="https://purchase.conholdate.com/temporary-license/" target="_blank">How to get a Temporary License?</a> for more information.

### Apply the License using File or Stream Object {#apply-the-license-using-file-or-stream-object}

Use the <a href="https://reference.aspose.com/tex/java/com.aspose.tex/license/#setLicense-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">License.setLicense</a> method to license the component. In the examples below, set `licenseFilePath` to the full path to your license file. The calling method must handle or declare `Exception`.

#### Loading a License from File {#loading-a-license-from-file}

This code snippet applies a license stored in a file.

```java
// Apply a license from a file.
// licenseFilePath is the full path to your Aspose.TeX for Java license.
com.aspose.tex.License license = new com.aspose.tex.License();
license.setLicense(licenseFilePath);
```

#### Loading a License from a Stream Object {#loading-a-license-from-a-stream-object}

These code snippets initialize the license from the stream.

```java
// Apply a license from a stream and close the stream after use.
// licenseFilePath is the full path to your Aspose.TeX for Java license.
com.aspose.tex.License license = new com.aspose.tex.License();
try (java.io.InputStream licenseStream = new java.io.FileInputStream(licenseFilePath)) {
    license.setLicense(licenseStream);
}
```

### Metered License {#metered-license}

Aspose.TeX has an alternative licensing mechanism called *Metered Licensing*. If a customer wishes to be billed based on the usage of the API features, they can apply a *Metered License*, which is actually as simple as applying a cryptographic key pair. For more details, please refer to the <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Metered Licensing FAQ section</a>.

The public and private keys of a metered license can be set using an instance of the <a href="https://reference.aspose.com/tex/java/com.aspose.tex/metered/" target="_blank" rel="nofollow noopener noreferrer">*Metered*</a> class, as shown below:

```java
// Apply a metered license using your own public and private keys.
new com.aspose.tex.Metered().setMeteredKey(
        "<type public key here>",
        "<type private key here>");
```

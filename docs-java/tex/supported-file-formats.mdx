## Supported File Formats {#supported-file-formats}

The following table indicates the file formats that Aspose.TeX for Java can load and save.

<div className="docs-owner-markdown-table">

| **Format** | **Description** | **Input** | **Output** | **Remarks** |
| ---------- | ------------------------------- | --------- | ---------- | ------------------------------------ |
| Plain text | TeX file | Supported | Supported | Only for output of tracing messages. |
| XPS | Typeset XPS document |  | Supported |  |
| PDF | Typeset PDF document |  | Supported |  |
| PNG | PNG images of typeset document |  | Supported |  |
| JPEG | JPEG images of typeset document |  | Supported |  |
| TIFF | TIFF images of typeset document |  | Supported |  |
| BMP | BMP images of typeset document |  | Supported |  |

</div>

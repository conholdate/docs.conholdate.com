## Install using Maven

All GroupDocs packages are hosted at <a href="https://releases.groupdocs.com/java/repo/com/groupdocs/groupdocs-viewer/" target="_blank" rel="nofollow noopener noreferrer">GroupDocs Artifact Repository</a>. You can download packages or reference GroupDocs.Viewer for Java API directly in your Maven project using following steps. 


:::tip
[Download](/java/viewer/sample-apps/getting-started/installation/maven-app.zip/) a sample Maven application that demonstrates using GroupDocs.Viewer for Java. You can run the application locally with `mvn exec:java` command.
:::


### Add GroupDocs Artifact Repository

Add GroupDocs Artifact Repository to your `pom.xml` file:


<Tabs groupId="pom-repository">


<TabItem value="pom-xml" label="pom.xml" default>

```xml
<repositories>
    <repository>
        <id>GroupDocs Artifact Repository</id>
        <name>GroupDocs Artifact Repository</name>
        <url>https://releases.groupdocs.com/java/repo/</url>
    </repository>
</repositories>
```

</TabItem>


</Tabs>


### Add GroupDocs.Viewer as a dependency

Define GroupDocs.Viewer for Java API dependency in your `pom.xml`:


<Tabs groupId="pom-dependency">


<TabItem value="pom-xml" label="pom.xml" default>

```xml
<dependencies>
    <dependency>
        <groupId>com.groupdocs</groupId>
        <artifactId>groupdocs-viewer</artifactId>
        <version>26.5</version> 
    </dependency>
</dependencies>
```

</TabItem>


</Tabs>


## Reference in Java application

To get started, download the latest version of GroupDocs.Viewer for Java (JAR file) from GroupDocs Artifact Repository. Also, make sure you have <a href="https://www.oracle.com/java/technologies/downloads/" target="_blank" rel="nofollow noopener noreferrer">Java</a> installed.

### Create application


:::tip
You can [download](/java/viewer/sample-apps/getting-started/installation/java-app.zip/) the sample application and proceed to building it.
:::



<Tabs groupId="java-app">


<TabItem value="app-java" label="App.java" default>

```java
import com.groupdocs.viewer.Viewer;
import com.groupdocs.viewer.options.*;

public class App {
    public static void main(String[] args) throws Exception {
        Viewer viewer = new Viewer("formatting.docx");
        viewer.view(HtmlViewOptions.forEmbeddedResources());
        viewer.close();
    }
}
```

</TabItem>


<TabItem value="formatting-docx" label="formatting.docx">

`formatting.docx` is sample DOCX file that we're going to use in this example. Click [here](/java/viewer/sample-files/getting-started/installation/formatting.docx) to download it.

</TabItem>


<TabItem value="groupdocs-viewer-jar" label="groupdocs-viewer.jar">

`groupdocs-viewer.jar` is GroupDocs.Viewer for Java JAR file e.g., <a href="https://releases.groupdocs.com/java/repo/com/groupdocs/groupdocs-viewer/24.4/groupdocs-viewer-24.4.jar" target="_blank" rel="nofollow noopener noreferrer">groupdocs-viewer-24.4.jar</a>.

</TabItem>


</Tabs>

### Build application

To build Java application run the command below. This comand compiles the application and creates `App.class` file in the current directory.


<Tabs groupId="java-app-build">


<TabItem value="windows" label="Windows" default>

```bash
javac -d . -cp ".;./groupdocs-viewer.jar" App.java
```

</TabItem>


<TabItem value="linux" label="Linux">

```bash
javac -d . -cp ".:./groupdocs-viewer.jar" App.java
```

</TabItem>


</Tabs>


### Run application

To run the application type the command below. As a result two HTML documents will be created in the current directory for the first two pages of the document.


<Tabs groupId="java-app-run">


<TabItem value="windows" label="Windows" default>

```bash
java -cp ".;./groupdocs-viewer.jar" App
```

</TabItem>


<TabItem value="linux" label="Linux">

```bash
java -Djava.awt.headless=true -cp ".:./groupdocs-viewer.jar" App
```

Please note that `-Djava.awt.headless=true` required when your Java installation does not inlude GUI libraries.


</TabItem>

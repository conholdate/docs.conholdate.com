GroupDocs.Viewer for Java is included in Conholdate.Total for Java.
:::


:::info
GroupDocs.Viewer for Java does not require any external software to be installed such as Microsoft Word, Microsoft Excel or Microsoft PowerPoint. To install GroupDocs.Viewer for Java just follow one of the ways as described in the [Installation](/java/viewer/getting-started/installation/) section.
:::


## Supported Operating Systems

GroupDocs.Viewer for Java can be used on any 32-bit or 64-bit operating system where Java is installed including, but not limited to:

### Windows

* Microsoft Windows Server 2003 and later
* Microsoft Windows XP (x64, x86)
* Microsoft Windows Vista (x64, x86)
* Microsoft Windows 7, 8, 8.1 (x64, x86)
* Microsoft Windows 10 (x64, x86)
* Microsoft Windows 11 (x64)

### Linux

* Linux (Ubuntu, OpenSUSE, CentOS and others)

### Mac

* Mac OS X

## Supported Java Versions

GroupDocs.Viewer for Java supports Java versions listed below. For more platform support please check <a href="https://products.groupdocs.com/viewer" target="_blank" rel="nofollow noopener noreferrer">GroupDocs.Viewer</a> page.

* J2SE 8.0 (1.8) or above (*for example Java 17*)

## Development Environments

GroupDocs.Viewer for Java can be used to develop applications in any development environment that targets Java, but the following environments are explicitly supported:

* Eclipse IDE
* IntelliJ IDEA
* NetBeans

## Required fonts

When working with the documents that contain the Chinese hieroglyphs, in order to obtain the valid rendering results without exceptions or replacement characters (usually represented as empty squares) in the produced documents, it is required that a <a href="https://learn.microsoft.com/en-us/typography/font-list/simsun" target="_blank" rel="nofollow noopener noreferrer">SimSun</a> font should be installed in the operating system.

When using Microsoft Windows this should not be the problem, because the SimSun is preinstalled in all the Windows versions and editions starting from the Windows 2000 (for example, Windows XP has preinstalled SimSun version 3.03, Windows 7 has preinstalled SimSun version <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_7_font_list" target="_blank" rel="nofollow noopener noreferrer">5.03</a>, and Windows 10 - SimSun version <a href="https://learn.microsoft.com/en-us/typography/fonts/windows_10_font_list" target="_blank" rel="nofollow noopener noreferrer">5.16</a>). But on Linux the SimSun is usually not installed, so it is required to install it manually. This also is valid when running GroupDocs.Viewer in Docker environment and using a Linux image.

Aspose.HTML for Java is a headless document-processing library for creating, loading, editing, navigating, saving, and converting HTML-related documents. It supports HTML, XHTML, SVG, EPUB, MHTML, and Markdown source formats and provides APIs based on familiar web platform concepts such as DOM, CSS, JavaScript, SVG, and Canvas.

The library processes documents without opening an interactive browser window. It is intended for document manipulation, data extraction, saving, rendering, and conversion rather than browser UI automation.

## Document Creation and Editing {#document-creation-and-editing}

Aspose.HTML for Java provides a DOM-based API centered on the <a href="https://reference.aspose.com/html/java/com.aspose.html/htmldocument/" target="_blank" rel="nofollow noopener noreferrer">HTMLDocument</a> class for working with document structure, content, attributes, and styles.

- [Create or load an HTML document](/java/html/create-a-document/) from a file, URL, stream, or HTML string, or build a document programmatically.
- [Edit an HTML document](/java/html/edit-a-document/) by creating, inserting, replacing, or removing DOM nodes and updating element attributes, text, and CSS styles.
- [Save an HTML document](/java/html/save-a-document/) with linked resources or save it as MHTML or Markdown by using the appropriate save options.
- [Configure the document environment](/java/html/environment-configuration/) to control sandboxing, runtime behavior, stylesheets, fonts, networking, and resource processing.

## Navigation and Data Extraction {#navigation-and-data-extraction}

You can inspect a loaded document and select the nodes or values needed by an application.

- Use DOM navigation and traversal interfaces to move through the document tree.
- Use XPath expressions for structured queries over document nodes.
- Use CSS selectors to match elements by tag, ID, class, attribute, or structural relationship.
- Read or update element text, HTML markup, attributes, and computed or specified style information.

See [HTML Navigation](/java/html/html-navigation/) for Java examples using DOM traversal, XPath, and CSS selectors.

## Conversion and Rendering {#conversion-and-rendering}

The <a href="https://reference.aspose.com/html/java/com.aspose.html.converters/converter/" target="_blank" rel="nofollow noopener noreferrer">Converter</a> class provides conversion methods for HTML-related sources. Supported output workflows include:

- **Document formats** - PDF, XPS, and DOCX.
- **Image formats** - JPEG, PNG, BMP, TIFF, and GIF.
- **Web formats** - HTML to Markdown or MHTML, and Markdown to HTML.

Conversion support depends on the source format and the selected save options. See [Supported File Formats](/java/html/getting-started/supported-file-formats/) for the input and output matrix and [Converting Between Formats](/java/html/converting-between-formats/) for format-specific Java workflows.

## Platform and Development Support

Aspose.HTML for Java can be used in Java applications on supported Windows, Linux, and macOS environments. You can manage the dependency with Maven or Gradle or add the library JAR manually. A JDK is required to compile and build an application, while the runtime must be compatible with the selected library release.

See [System Requirements](/java/html/getting-started/system-requirements/) for Java and operating system compatibility and [Installation](/java/html/getting-started/installation/) for dependency configuration.

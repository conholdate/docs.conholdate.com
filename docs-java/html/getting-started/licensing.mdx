## Evaluate Aspose.HTML for Java {#evaluate-asposehtml-for-java}

You can install and use Aspose.HTML for Java without supplying a license. This is useful for initial API testing, but the resulting documents are subject to evaluation restrictions.

The evaluation version has the following limitations:

- **Saved document content contains evaluation markings.** Depending on the workflow, saved HTML or rendered images can include evaluation text or watermarks.
- **Converted output is limited.** Converted documents contain an evaluation watermark, and conversion is limited to the first four pages.

Apply a valid purchased or temporary license before generating output that you need to evaluate without these restrictions. For purchasing and licensing terms, see <a href="https://purchase.conholdate.com/policies/" target="_blank">Purchase Policies and FAQ</a>.

## Apply a License {#apply-a-license}

Apply the license once during application startup and before the first Aspose.HTML operation that saves, renders, or converts a document. The <a href="https://reference.aspose.com/html/java/com.aspose.html/license/" target="_blank" rel="nofollow noopener noreferrer">License</a> class accepts a license file name, file path, or input stream through its `setLicense()` overloads.

If an application uses multiple Aspose products, use the fully qualified class name `com.aspose.html.License`. Each product exposes its own `License` class, and the package name makes it clear that the license is being applied to Aspose.HTML.

### Apply a License from a File {#apply-a-license-from-a-file}

To apply a license from disk:

1. Place the `.lic` file in a location available to the application at runtime.
2. Create a `com.aspose.html.License` object.
3. Pass the license file name or path to `setLicense()`.
4. Apply the license before processing documents.

If the license file is stored in the same runtime folder as the component JAR, you can pass only its file name. Otherwise, provide a path that the application can resolve. An Aspose.HTML for Java license file or an applicable Aspose.Total for Java license can be loaded through this class.

```java
// Set Aspose.HTML for Java license using file path string

// instantiate License object
com.aspose.html.License license = new com.aspose.html.License();
// license file path information
license.setLicense("Aspose.HTML.lic");
```

### Apply a License from a Stream {#apply-a-license-from-a-stream}

Use the stream overload when the license is obtained from application resources, protected storage, or another stream-based source. The following example creates a `FileInputStream` and passes it to `setLicense()`. In application code, close the stream after the method returns.

```java
// Set Aspose.HTML for Java license from stream

// Initialize License Instance
com.aspose.html.License license = new com.aspose.html.License();
// Set license from Stream
license.setLicense(new java.io.FileInputStream("Aspose.HTML.lic"));
```

### Apply a Metered License {#apply-a-metered-license}

A metered license uses a public and private key pair instead of a license file and reports API usage for usage-based billing. For licensing terms and activation guidance, see <a href="https://purchase.conholdate.com/faqs/licensing/metered/how-to-use/" target="_blank">Using Your Metered License</a>.

To apply metered licensing:

1. Obtain the public and private metered keys from Aspose.
2. Create a <a href="https://reference.aspose.com/html/java/com.aspose.html/metered/" target="_blank" rel="nofollow noopener noreferrer">Metered</a> object.
3. Pass the keys to `setMeteredKey()` once during application startup.
4. Keep the private key out of source control and client-visible configuration.

```java
// Set Aspose.HTML for Java metered license using public and private keys with Metered class

// Initialize a metered object
com.aspose.html.Metered metered = new com.aspose.html.Metered();

// Apply the metered license using the public and private keys
metered.setMeteredKey("PublicKey", "PrivateKey");
```

<a href="https://gist.github.com/aspose-com-gists/b9c9c0eb44f17af6fe4c7291c51c8930#file-example_setasposehtmlmeteredlicense-java" target="_blank" rel="nofollow noopener noreferrer">Example_SetAsposeHtmlMeteredLicense.java</a> hosted with ❤ by <a href="https://github.com/" target="_blank" rel="nofollow noopener noreferrer">GitHub</a>

Normally, call `setMeteredKey()` once at application startup. Metered licensing records usage locally and reports it to Aspose services at regular intervals, so the application requires periodic network access to the licensing servers. Firewall rules must allow this communication.

:::info
Connectivity retry behavior and grace periods are defined by the current <a href="https://purchase.conholdate.com/faqs/licensing/metered/" target="_blank">Metered Licensing FAQ</a>. Review that policy when planning production deployment instead of relying on a fixed interval in application documentation.
:::

## Common Licensing Issues

<div className="docs-owner-markdown-table">

| Issue | Likely cause | What to check |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Output still contains evaluation watermarks | The license was applied after document processing began, or the file was not found. | Call `setLicense()` at startup and verify the runtime path to the `.lic` file. |
| Aspose.HTML remains in evaluation mode in a multi-product application | A `License` class from another Aspose package was used. | Instantiate `com.aspose.html.License` explicitly. |
| Licensing works locally but fails on a server or in a container | The license file is missing from the deployment or the runtime path differs. | Deploy or securely mount the license file, or load it from a stream. |
| Metered licensing cannot report usage | Network or firewall rules block access to Aspose licensing services. | Allow the required periodic communication and review the Metered Licensing FAQ. |

</div>

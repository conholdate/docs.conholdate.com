A "Hello World" example is the shortest path to understanding the basic PDF creation workflow. In this article, the example creates a new PDF, places a styled text fragment on the page, and saves the output file.

The Java example follows these steps:

1. Create a <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> object.
2. Add a <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/page/" target="_blank" rel="nofollow noopener noreferrer">Page</a> to the document.
3. Create a <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textfragment/" target="_blank" rel="nofollow noopener noreferrer">TextFragment</a> with the text `Hello, world!`.
4. Set the <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/position/" target="_blank" rel="nofollow noopener noreferrer">Position</a>, font, font size, background color, and foreground color through the fragment <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textstate/" target="_blank" rel="nofollow noopener noreferrer">TextState</a>.
5. Create a <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textbuilder/" target="_blank" rel="nofollow noopener noreferrer">TextBuilder</a> for the page.
6. Append the <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/textfragment/" target="_blank" rel="nofollow noopener noreferrer">TextFragment</a> to the <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/page/" target="_blank" rel="nofollow noopener noreferrer">Page</a>.
7. Save the PDF <a href="https://reference.aspose.com/pdf/java/com.aspose.pdf/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a>.

The following Java code is based on `GetStartedExamples.java`.

```java
public static void simpleExample(Path outputFile) {
    try (Document document = new Document()) {
        Page page = document.getPages().add();

        TextFragment textFragment = new TextFragment("Hello, world!");
        textFragment.setPosition(new Position(100, 600));
        textFragment.getTextState().setFontSize(12);
        textFragment.getTextState().setFont(FontRepository.findFont("TimesNewRoman"));
        textFragment.getTextState().setBackgroundColor(Color.getBlue());
        textFragment.getTextState().setForegroundColor(Color.getYellow());

        TextBuilder textBuilder = new TextBuilder(page);
        textBuilder.appendText(textFragment);

        document.save(outputFile.toString());
    }
}
```

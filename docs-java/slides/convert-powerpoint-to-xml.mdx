> Convert PowerPoint and OpenDocument presentations to PowerPoint XML files or streams in Java with Aspose.Slides for Java.
> 9

## **Overview**

Aspose.Slides for Java can convert PowerPoint presentations to the PowerPoint XML Presentation format. XML output is useful when you need a text-based representation for inspecting presentation structure, troubleshooting generated documents, comparing output in automated tests, or integrating with a workflow that consumes XML instead of a presentation package.

Use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> method with the `Xml` value from the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/saveformat/" target="_blank" rel="nofollow noopener noreferrer">SaveFormat</a> class. You can write the result directly to a file or to a stream.

`SaveFormat.Xml` creates a PowerPoint XML Presentation. It does not extract the individual Office Open XML parts stored inside a PPTX package. If you need the exact PPTX package parts, such as `ppt/presentation.xml` or individual slide XML files, inspect the PPTX package itself.

## **Convert a Presentation to an XML File**

Load a source presentation with the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> class, and then pass the output path and `SaveFormat.Xml` to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a>. The source can be any presentation format supported for loading, such as PPT, PPTX, or ODP.

The following example converts a PPTX presentation to an XML file:

```java
import com.aspose.slides.Presentation;
import com.aspose.slides.SaveFormat;

Presentation presentation = new Presentation("presentation.pptx");
try {
    presentation.save("presentation.xml", SaveFormat.Xml);
} finally {
    presentation.dispose();
}
```

## **Write the XML Output to a Stream**

Use the stream overload of <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.io.OutputStream-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> when the XML must remain in memory or be passed to another component, such as a web service, storage provider, or XML processing pipeline. The following example writes the result to a <a href="https://docs.oracle.com/en/java/javase/16/docs/api/java.base/java/io/ByteArrayOutputStream.html" target="_blank" rel="nofollow noopener noreferrer">ByteArrayOutputStream</a> and obtains the resulting XML as a byte array:

```java
import com.aspose.slides.Presentation;
import com.aspose.slides.SaveFormat;
import java.io.ByteArrayOutputStream;

Presentation presentation = new Presentation("presentation.pptx");
try (ByteArrayOutputStream xmlStream = new ByteArrayOutputStream()) {
    presentation.save(xmlStream, SaveFormat.Xml);
    byte[] xmlData = xmlStream.toByteArray();

    // Pass xmlData to the next component in the workflow.
} finally {
    presentation.dispose();
}
```

## **Compare XML with Presentation and Export Formats**

Choose the output format according to how the result will be used:

<div className="docs-owner-markdown-table">

| Format | Output | Typical use |
| ----------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| PowerPoint XML (`.xml`) | A PowerPoint XML Presentation | Inspecting structure, troubleshooting, comparing generated output, and XML-based integration |
| PPT (`.ppt`) | A legacy binary presentation file | Compatibility with older PowerPoint workflows |
| PPTX (`.pptx`) | An Office Open XML package containing multiple parts | Regular PowerPoint editing and presentation exchange |
| PDF or TIFF | Fixed-layout pages or a multi-page image | Viewing, printing, and archiving |
| PNG, JPEG, or SVG | A rendered representation of an individual slide | Thumbnails, previews, and image assets |
| HTML or HTML5 | Web-oriented presentation output | Browser viewing and web publishing |

</div>

Unlike PPT and PPTX, XML output is primarily intended for inspection and data-oriented workflows. Unlike PDF, TIFF, HTML, and slide image formats, it represents presentation data rather than rendering slides as pages or visual assets. The [supported file formats](/java/slides/supported-file-formats/) table lists every format that Aspose.Slides can load, import, save, or render.

## **FAQ**

**Is `SaveFormat.Xml` the same as saving a PPTX file?**

No. PPTX is a package containing multiple Office Open XML parts, whereas `SaveFormat.Xml` creates a PowerPoint XML Presentation file.

**Can I save the XML output without creating a file on disk?**

Yes. Pass a writable stream to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.io.OutputStream-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a>. For example, use a <a href="https://docs.oracle.com/en/java/javase/16/docs/api/java.base/java/io/ByteArrayOutputStream.html" target="_blank" rel="nofollow noopener noreferrer">ByteArrayOutputStream</a> for in-memory processing.

**Can Aspose.Slides load the exported XML file again?**

Yes. Pass the XML file or a stream to the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#Presentation-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> constructor. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSourceFormat--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSourceFormat</a> then returns `SourceFormat.Xml`. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> reports `LoadFormat.Unknown` for this format, so do not use it to decide whether an XML file can be opened.

**Does XML conversion render each slide as a page or image?**

No. XML conversion writes structured presentation data. Use PDF or TIFF for page-oriented output, or PNG, JPEG, and SVG for individual slide images.

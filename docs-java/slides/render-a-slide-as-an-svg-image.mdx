> Export PowerPoint slides as SVG images in Java and control fonts, text, images, IDs, and events with Aspose.Slides.
> 1

## **Overview**

SVG is a scalable XML-based image format that works well for web publishing, slide viewers, accessibility workflows, and automated post-processing. Aspose.Slides exports each slide to a separate SVG file and lets you control how text, fonts, pictures, and SVG elements are written.

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/" target="_blank" rel="nofollow noopener noreferrer">SVGOptions</a> when the exported SVG must be compact, predictable across browsers, or ready for interactive use.

## **Export a Slide as SVG**

Create a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a>, select a slide, and write it to a stream with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#writeAsSvg-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">ISlide.writeAsSvg</a>. The following example exports every slide in a presentation as a separate SVG file.

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    for (ISlide slide : presentation.getSlides()) {
        String outputFileName = String.format("slide-%d.svg", slide.getSlideNumber());

        try (FileOutputStream svgStream = new FileOutputStream(outputFileName)) {
            slide.writeAsSvg(svgStream);
        }
    }
} finally {
    presentation.dispose();
}
```

The filename uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getSlideNumber--" target="_blank" rel="nofollow noopener noreferrer">ISlide.getSlideNumber</a> rather than the loop index. You can also export an individual shape with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishape/#writeAsSvg-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">IShape.writeAsSvg</a> when a slide viewer or web page needs only that shape.

## **Configure SVG Output**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/" target="_blank" rel="nofollow noopener noreferrer">SVGOptions</a> controls SVG rendering. For text frames, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setUseFrameSize-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setUseFrameSize</a> includes the text frame in the rendering area, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setUseFrameRotation-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setUseFrameRotation</a> determines whether the frame rotation is applied. Set <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setDisableFontLigatures-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setDisableFontLigatures</a> to `true` when text must be rendered without ligatures.

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    SVGOptions svgOptions = new SVGOptions();
    svgOptions.setDisableFontLigatures(true);
    svgOptions.setUseFrameSize(true);
    svgOptions.setUseFrameRotation(false);

    ISlide slide = presentation.getSlides().get_Item(0);
    try (FileOutputStream svgStream = new FileOutputStream("slide-with-custom-options.svg")) {
        slide.writeAsSvg(svgStream, svgOptions);
    }
} finally {
    presentation.dispose();
}
```

## **Control Line-End Cropping at Arrowheads**

SVG 1.1 has no marker inset setting to specify where a line should stop beneath an arrowhead. By default, Aspose.Slides shortens the exported line so its stroke does not protrude through the marker. Call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setDisableLineEndCropping-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setDisableLineEndCropping</a> with `true` to draw the stroke all the way to the line's original endpoint. This setting affects only the SVG output. The line keeps its position and length on the slide.

The example draws triangle and diamond arrowheads on lines 2 and 10 points wide. It exports the same slide twice, changing only the cropping option.

```java
import com.aspose.slides.*;
import java.awt.Color;
import java.io.FileOutputStream;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);
    int y = 40;
    
    for (byte style : new byte[] { LineArrowheadStyle.Triangle, LineArrowheadStyle.Diamond }) {
        for (int width : new int[] { 2, 10 }) {
            IAutoShape line = slide.getShapes().addAutoShape(ShapeType.Line, 40, y, 200, 0);
            ILineFormat format = line.getLineFormat();
            format.getFillFormat().setFillType(FillType.Solid);
            format.getFillFormat().getSolidFillColor().setColor(new Color(0, 0, 139));
            format.setWidth(width);
            format.setEndArrowheadStyle(style);
            y += 50;
        }
    }

    SVGOptions options = new SVGOptions();
    options.setDisableLineEndCropping(false);
    try (FileOutputStream cropped = new FileOutputStream("cropped.svg")) {
        slide.writeAsSvg(cropped, options);
    }

    options.setDisableLineEndCropping(true);
    try (FileOutputStream uncropped = new FileOutputStream("uncropped.svg")) {
        slide.writeAsSvg(uncropped, options);
    }
} finally {
    presentation.dispose();
}
```

The comparison shows the triangular arrowhead on the 10-point line. With cropping enabled, the tip is sharp. With cropping disabled, the stroke protrudes through the sloping sides of the marker and leaves a flat end.

![Enlarged 10-point triangle with a sharp tip when cropping is enabled and a flat end when cropping is disabled](/java/slides/images/5566b52e0eae04ac-line-end-cropping.png)

In the other lines from the example, the protruding stroke is less visible on the 2-point triangle. The filled diamond covers the end of the stroke at both widths.

## **Control Text and Fonts**

When exporting slides to SVG, you can control whether text remains as text or is converted to vector graphics, and how external fonts are included or referenced. The following options help you balance visual consistency, text selection, and font dependencies in the exported SVG.

### **Vectorize All Text**

Set <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setVectorizeText-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setVectorizeText</a> to `true` to write all slide text as vector graphics. This eliminates font dependencies and makes the visual result more consistent across browsers, but the text is no longer selectable or searchable as SVG text.

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    SVGOptions svgOptions = new SVGOptions();
    svgOptions.setVectorizeText(true);

    ISlide slide = presentation.getSlides().get_Item(0);
    try (FileOutputStream svgStream = new FileOutputStream("slide-with-vectorized-text.svg")) {
        slide.writeAsSvg(svgStream, svgOptions);
    }
} finally {
    presentation.dispose();
}
```

### **Choose How External Fonts Are Handled**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setExternalFontsHandling-int-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setExternalFontsHandling</a> uses a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgexternalfontshandling/" target="_blank" rel="nofollow noopener noreferrer">SvgExternalFontsHandling</a> value for fonts that are loaded externally. Choose `AddLinksToFontFiles` to reference separate font files, `Embed` to include font data in the SVG, or `Vectorize` to render only text that uses external fonts as graphics. Verify font licensing before embedding fonts.

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    SVGOptions linkedFontsOptions = new SVGOptions();
    linkedFontsOptions.setExternalFontsHandling(SvgExternalFontsHandling.AddLinksToFontFiles);
    try (FileOutputStream linkedFontsStream = new FileOutputStream("slide-with-font-links.svg")) {
        slide.writeAsSvg(linkedFontsStream, linkedFontsOptions);
    }

    SVGOptions embeddedFontsOptions = new SVGOptions();
    embeddedFontsOptions.setExternalFontsHandling(SvgExternalFontsHandling.Embed);
    try (FileOutputStream embeddedFontsStream = new FileOutputStream("slide-with-embedded-fonts.svg")) {
        slide.writeAsSvg(embeddedFontsStream, embeddedFontsOptions);
    }

    SVGOptions vectorizedExternalFontsOptions = new SVGOptions();
    vectorizedExternalFontsOptions.setExternalFontsHandling(SvgExternalFontsHandling.Vectorize);
    try (FileOutputStream vectorizedExternalFontsStream = new FileOutputStream("slide-with-vectorized-external-fonts.svg")) {
        slide.writeAsSvg(vectorizedExternalFontsStream, vectorizedExternalFontsOptions);
    }
} finally {
    presentation.dispose();
}
```

## **Reduce Embedded Image Size**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setPicturesCompression-int-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setPicturesCompression</a> to reduce the resolution of embedded pictures, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setDeletePicturesCroppedAreas-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setDeletePicturesCroppedAreas</a> to omit cropped source areas, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setJpegQuality-int-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setJpegQuality</a> to control JPEG encoding quality. These settings reduce file size at the cost of image fidelity or retained image data.

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    SVGOptions svgOptions = new SVGOptions();
    svgOptions.setPicturesCompression(PicturesCompression.Dpi150);
    svgOptions.setDeletePicturesCroppedAreas(true);
    svgOptions.setJpegQuality(80);

    ISlide slide = presentation.getSlides().get_Item(0);
    try (FileOutputStream svgStream = new FileOutputStream("compressed-slide.svg")) {
        slide.writeAsSvg(svgStream, svgOptions);
    }
} finally {
    presentation.dispose();
}
```

## **Control Metafile Rasterization Resolution**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setMetafileRasterizationDpi-int-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setMetafileRasterizationDpi</a> sets the lower resolution limit for rasterizing metafiles during SVG export. Use it to balance detail and file size when an EMF or WMF image is rasterized. It does not define a global DPI for the SVG or force every object on the slide to become a raster image.

Download <a href="https://docs.aspose.com/slides/java/render-a-slide-as-an-svg-image/metafile-rasterization.pptx" target="_blank" rel="nofollow noopener noreferrer">metafile-rasterization.pptx</a>, which contains an EMF image with closely spaced diagonal lines. The following example exports its first slide at three rasterization resolutions through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#writeAsSvg-java.io.OutputStream-com.aspose.slides.ISVGOptions-" target="_blank" rel="nofollow noopener noreferrer">ISlide.writeAsSvg</a>. All other export settings remain identical so that the results can be compared.

```java
import com.aspose.slides.PicturesCompression;
import com.aspose.slides.Presentation;
import com.aspose.slides.SVGOptions;
import java.io.FileOutputStream;

Presentation presentation = new Presentation("metafile-rasterization.pptx");
try {
    for (int dpi : new int[] { 72, 150, 300 }) {
        SVGOptions svgOptions = new SVGOptions();
        svgOptions.setMetafileRasterizationDpi(dpi);
        svgOptions.setPicturesCompression(PicturesCompression.Dpi330);
        svgOptions.setJpegQuality(90);

        String outputFileName = String.format("slide-%d.svg", dpi);
        try (FileOutputStream svgStream = new FileOutputStream(outputFileName)) {
            presentation.getSlides().get_Item(0).writeAsSvg(svgStream, svgOptions);
        }
    }
} finally {
    presentation.dispose();
}
```

In the output, the EMF became one embedded PNG in each SVG. The following measurements are for the supplied presentation; they are not a general formula for converting DPI to pixel dimensions.

## **Assign Stable IDs to Shapes and Text**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgshapeformattingcontroller/" target="_blank" rel="nofollow noopener noreferrer">ISvgShapeFormattingController</a> to set <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgshape/#setId-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">ISvgShape.setId</a> for each SVG shape. To set <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgtspan/#setId-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">ISvgTSpan.setId</a> values on text `tspan` elements as well, implement <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgshapeandtextformattingcontroller/" target="_blank" rel="nofollow noopener noreferrer">ISvgShapeAndTextFormattingController</a>. Assign either controller with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setShapeFormattingController-com.aspose.slides.ISvgShapeFormattingController-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setShapeFormattingController</a>.

The following controller uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishape/#getOfficeInteropShapeId--" target="_blank" rel="nofollow noopener noreferrer">IShape.getOfficeInteropShapeId</a>, which is stable for the lifetime of the shape, and a repeatable counter for its text spans. This makes the generated IDs suitable for post-processing an unchanged presentation.

```java
class StableSvgIdController implements ISvgShapeAndTextFormattingController {
    private String currentShapeId = "";
    private int textSpanIndex;

    public void formatShape(ISvgShape svgShape, IShape shape) {
        currentShapeId = String.format("shape-%d", shape.getOfficeInteropShapeId());
        textSpanIndex = 0;
        svgShape.setId(currentShapeId);
    }

    public void formatText(ISvgTSpan svgTSpan, IPortion portion, ITextFrame textFrame) {
        svgTSpan.setId(String.format("%s-text-%d", currentShapeId, textSpanIndex++));
    }
}

Presentation presentation = new Presentation("presentation.pptx");
try {
    SVGOptions svgOptions = new SVGOptions();
    svgOptions.setShapeFormattingController(new StableSvgIdController());

    ISlide slide = presentation.getSlides().get_Item(0);
    try (FileOutputStream svgStream = new FileOutputStream("slide-with-stable-ids.svg")) {
        slide.writeAsSvg(svgStream, svgOptions);
    }
} finally {
    presentation.dispose();
}
```

## **Add SVG Event Handlers**

In an <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgshapeformattingcontroller/" target="_blank" rel="nofollow noopener noreferrer">ISvgShapeFormattingController</a>, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/isvgshape/#setEventHandler-int-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">ISvgShape.setEventHandler</a> with a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgevent/" target="_blank" rel="nofollow noopener noreferrer">SvgEvent</a> value to add a JavaScript event handler to an exported shape. Assign the controller with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setShapeFormattingController-com.aspose.slides.ISvgShapeFormattingController-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setShapeFormattingController</a> and define the JavaScript function in the page or SVG document that hosts the result.

```java
class SvgEventController implements ISvgShapeFormattingController {
    public void formatShape(ISvgShape svgShape, IShape shape) {
        if ("ActionButton".equals(shape.getName())) {
            svgShape.setId("action-button");
            svgShape.setEventHandler(SvgEvent.OnClick, "handleShapeClick(event)");
        }
    }
}

Presentation presentation = new Presentation("presentation.pptx");
try {
    SVGOptions svgOptions = new SVGOptions();
    svgOptions.setShapeFormattingController(new SvgEventController());

    ISlide slide = presentation.getSlides().get_Item(0);
    try (FileOutputStream svgStream = new FileOutputStream("interactive-slide.svg")) {
        slide.writeAsSvg(svgStream, svgOptions);
    }
} finally {
    presentation.dispose();
}
```

The host page can define the JavaScript function referenced by the handler. Assigning IDs and event handlers enables slide viewers, accessibility enhancements, and other interactive SVG workflows.

## **FAQ**

**When should I use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setVectorizeText-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setVectorizeText</a> instead of <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgexternalfontshandling/" target="_blank" rel="nofollow noopener noreferrer">SvgExternalFontsHandling.Vectorize</a>?**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgoptions/#setVectorizeText-boolean-" target="_blank" rel="nofollow noopener noreferrer">SVGOptions.setVectorizeText</a> when all text must be independent of fonts. Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/svgexternalfontshandling/" target="_blank" rel="nofollow noopener noreferrer">SvgExternalFontsHandling.Vectorize</a> when only text that uses external fonts should be converted to graphics.

**What is the best way to make an SVG smaller?**

Start by compressing embedded pictures, deleting cropped image areas, and choosing linked font files when the target environment can serve them. Test the result because lower image resolution, lower JPEG quality, and vectorized text each have different quality and size tradeoffs.

**Can I modify exported SVG elements after export?**

Yes. Assign IDs through a formatting controller, then select the matching SVG elements in your post-processing tool or browser script.

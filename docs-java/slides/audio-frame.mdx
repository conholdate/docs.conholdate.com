## **Overview**

An audio frame lets you play a sound on a slide. With Aspose.Slides for Java, you can embed an audio clip, choose the image that represents it, adjust playback, and attach captions. You can also retrieve a sound assigned to a slide transition.

## **Create Audio Frames**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addAudioFrameEmbedded-float-float-float-float-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">addAudioFrameEmbedded</a> to embed a local audio clip on the first slide. The first two coordinates position the frame on the slide, and the next two values set its width and height, all in points. This example calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setPlayMode-int-" target="_blank" rel="nofollow noopener noreferrer">setPlayMode</a> to start the clip automatically and calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setVolume-int-" target="_blank" rel="nofollow noopener noreferrer">setVolume</a> to select the loud preset.

```java
import com.aspose.slides.*;
import java.io.FileInputStream;

Presentation presentation = new Presentation();
ISlide slide = presentation.getSlides().get_Item(0);

try (FileInputStream audioStream = new FileInputStream("audio.wav")) {
    IAudioFrame audioFrame = slide.getShapes().addAudioFrameEmbedded(50, 150, 100, 100, audioStream);
    audioFrame.setPlayMode(AudioPlayModePreset.Auto);
    audioFrame.setVolume(AudioVolumeMode.Loud);

    presentation.save("AudioFrameEmbed_out.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Change the Audio Frame Thumbnail**

By default, an audio frame displays a speaker icon. To display a custom thumbnail, add an image to the presentation with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimagecollection/#addImage-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">addImage</a> and set it on the frame's picture with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islidespicture/#setImage-com.aspose.slides.IPPImage-" target="_blank" rel="nofollow noopener noreferrer">setImage</a>. The example uses a JPEG as the thumbnail for an embedded audio clip.

```java
import com.aspose.slides.*;
import java.io.FileInputStream;

Presentation presentation = new Presentation();
ISlide slide = presentation.getSlides().get_Item(0);

try (FileInputStream audioStream = new FileInputStream("audio.wav");
     FileInputStream imageStream = new FileInputStream("eagle.jpeg")) {
    IPPImage thumbnail = presentation.getImages().addImage(imageStream);

    IAudioFrame audioFrame = slide.getShapes().addAudioFrameEmbedded(150, 100, 50, 50, audioStream);
    audioFrame.getPictureFormat().getPicture().setImage(thumbnail);

    presentation.save("example_out.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The example finds the first audio frame on the first slide, calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setPlayMode-int-" target="_blank" rel="nofollow noopener noreferrer">setPlayMode</a> to start playback on a click, and selects the low volume preset. The clip continues across slides with looping disabled. The icon stays hidden during the show, and the clip rewinds after playback.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("AudioFrameEmbed_out.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAudioFrame audioFrame = null;
    for (IShape shape : slide.getShapes()) {
        if (shape instanceof IAudioFrame) {
            audioFrame = (IAudioFrame) shape;
            break;
        }
    }

    if (audioFrame != null) {
        audioFrame.setPlayMode(AudioPlayModePreset.OnClick);
        audioFrame.setVolume(AudioVolumeMode.Low);
        audioFrame.setPlayAcrossSlides(true);
        audioFrame.setPlayLoopMode(false);
        audioFrame.setHideAtShowing(true);
        audioFrame.setRewindAudio(true);
        presentation.save("AudioFrameEmbed_changed.pptx", SaveFormat.Pptx);
    } else {
        System.out.println("The first slide has no audio frame.");
    }
} finally {
    presentation.dispose();
}
```

For a clip longer than 3.5 seconds, this example skips the first 1.5 seconds and the last 2 seconds. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setTrimFromEnd-float-" target="_blank" rel="nofollow noopener noreferrer">setTrimFromEnd</a> takes the duration to omit from the end of the clip. To get the end time shown in PowerPoint, subtract that offset from the full clip duration. The trimmed clip fades in over 200 milliseconds and fades out over 500 milliseconds. All four methods take values in milliseconds.

```java
import com.aspose.slides.*;
import java.io.FileInputStream;

Presentation presentation = new Presentation();
ISlide slide = presentation.getSlides().get_Item(0);

try (FileInputStream audioStream = new FileInputStream("audio.wav")) {
    IAudioFrame audioFrame = slide.getShapes().addAudioFrameEmbedded(50, 50, 100, 100, audioStream);
    audioFrame.setTrimFromStart(1500f);
    audioFrame.setTrimFromEnd(2000f);
    audioFrame.setFadeInDuration(200f);
    audioFrame.setFadeOutDuration(500f);

    presentation.save("AudioFrameTrimFade_out.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

To set the playback volume to a specific percentage, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setVolumeValue-float-" target="_blank" rel="nofollow noopener noreferrer">setVolumeValue</a>. This example sets the first audio frame on the first slide to 85%.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("AudioFrameEmbed_out.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAudioFrame audioFrame = null;
    for (IShape shape : slide.getShapes()) {
        if (shape instanceof IAudioFrame) {
            audioFrame = (IAudioFrame) shape;
            break;
        }
    }

    if (audioFrame != null) {
        audioFrame.setVolumeValue(85f);
        presentation.save("AudioFrameValue_out.pptx", SaveFormat.Pptx);
    } else {
        System.out.println("The first slide has no audio frame.");
    }
} finally {
    presentation.dispose();
}
```

## **Manage Audio Captions**

Each audio frame provides access to its caption tracks through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#getCaptionTracks--" target="_blank" rel="nofollow noopener noreferrer">getCaptionTracks</a>. Use the collection to attach WebVTT captions to the clip, export existing tracks, or remove them.

### **Add Audio Captions**

The example embeds an audio clip on the first slide and uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptionscollection/#add-java.lang.String-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">add</a> to attach a local WebVTT track. The first argument supplies the track label, and the second identifies the file containing the timed captions.

```java
import com.aspose.slides.*;
import java.io.FileInputStream;

Presentation presentation = new Presentation();
ISlide slide = presentation.getSlides().get_Item(0);

try (FileInputStream audioStream = new FileInputStream("audio.wav")) {
    IAudioFrame audioFrame = slide.getShapes().addAudioFrameEmbedded(10, 10, 50, 50, audioStream);
    audioFrame.getCaptionTracks().add("English", "track.vtt");

    presentation.save("audio_with_captions.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

### **Extract Audio Captions**

This example exports each caption track attached to an audio frame on the first slide. It writes the bytes returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptions/#getBinaryData--" target="_blank" rel="nofollow noopener noreferrer">getBinaryData</a> to a WebVTT file and uses the identifier returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptions/#getCaptionId--" target="_blank" rel="nofollow noopener noreferrer">getCaptionId</a> as the file name so that each track has a separate output.

```java
import com.aspose.slides.*;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

Presentation presentation = new Presentation("audio_with_captions.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    for (IShape shape : slide.getShapes()) {
        if (!(shape instanceof IAudioFrame)) {
            continue;
        }
        IAudioFrame audioFrame = (IAudioFrame) shape;
        for (ICaptions track : audioFrame.getCaptionTracks()) {
            Path output = Paths.get(track.getCaptionId() + ".vtt");
            Files.write(output, track.getBinaryData());
        }
    }
} finally {
    presentation.dispose();
}
```

### **Remove Audio Captions**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptionscollection/#remove-com.aspose.slides.ICaptions-" target="_blank" rel="nofollow noopener noreferrer">remove</a> or <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptionscollection/#removeAt-int-" target="_blank" rel="nofollow noopener noreferrer">removeAt</a> to delete an individual track. The example uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptionscollection/#clear--" target="_blank" rel="nofollow noopener noreferrer">clear</a> to remove all captions from the first audio frame on the first slide while preserving the clip.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("audio_with_captions.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAudioFrame audioFrame = null;
    for (IShape shape : slide.getShapes()) {
        if (shape instanceof IAudioFrame) {
            audioFrame = (IAudioFrame) shape;
            break;
        }
    }

    if (audioFrame != null) {
        audioFrame.getCaptionTracks().clear();
        presentation.save("audio_without_captions.pptx", SaveFormat.Pptx);
    } else {
        System.out.println("The first slide has no audio frame.");
    }
} finally {
    presentation.dispose();
}
```

### **Find a Line in Audio Captions**

To find a line in the audio captions on the first slide, search the text returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icaptions/#getDataAsString--" target="_blank" rel="nofollow noopener noreferrer">getDataAsString</a> in memory. In a plain-text WebVTT cue, the timing line contains `-->`, the caption lines follow it, and a blank line ends the cue. This example prints the track label and each caption line containing "café".

```java
import com.aspose.slides.*;
import java.util.Locale;

Presentation presentation = new Presentation("audio_with_captions.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    for (IShape shape : slide.getShapes()) {
        if (!(shape instanceof IAudioFrame)) {
            continue;
        }
        IAudioFrame audioFrame = (IAudioFrame) shape;
        for (ICaptions track : audioFrame.getCaptionTracks()) {
            boolean inCue = false;
            String captions = track.getDataAsString();
            for (String line : captions.split("\\R")) {
                if (line.isEmpty()) {
                    inCue = false;
                } else if (line.contains("-->")) {
                    inCue = true;
                } else if (inCue && line.toLowerCase(Locale.ROOT).contains("café")) {
                    System.out.println(track.getLabel() + ": " + line);
                }
            }
        }
    }
} finally {
    presentation.dispose();
}
```

## **Extract Audio**

A slide transition can have its own sound. To retrieve it, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islideshowtransition/#getSound--" target="_blank" rel="nofollow noopener noreferrer">getSound</a> on the slide transition. The example accesses the bytes returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudio/#getBinaryData--" target="_blank" rel="nofollow noopener noreferrer">getBinaryData</a> and prints the number of bytes. If the first slide has no transition sound, it prints a message instead.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("AudioSlide.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAudio sound = slide.getSlideShowTransition().getSound();
    if (sound != null) {
        byte[] audioData = sound.getBinaryData();
        System.out.println("Transition sound: " + audioData.length + " bytes.");
    } else {
        System.out.println("The first slide has no transition sound.");
    }
} finally {
    presentation.dispose();
}
```

## **FAQ**

**Can I reuse the same audio clip across multiple slides without duplicating it?**

Yes. Add the clip once to the presentation's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getAudios--" target="_blank" rel="nofollow noopener noreferrer">audio collection</a> and pass the same audio object to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addAudioFrameEmbedded-float-float-float-float-com.aspose.slides.IAudio-" target="_blank" rel="nofollow noopener noreferrer">addAudioFrameEmbedded</a> for each slide.

**Can I replace the sound in an existing audio frame?**

Yes. For a linked sound, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setLinkPathLong-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setLinkPathLong</a> to point to the replacement file. For an embedded sound, select another clip from the presentation's audio collection with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setEmbeddedAudio-com.aspose.slides.IAudio-" target="_blank" rel="nofollow noopener noreferrer">setEmbeddedAudio</a>. Both approaches preserve the existing frame.

**Does trimming change the audio data stored in the presentation?**

No. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setTrimFromStart-float-" target="_blank" rel="nofollow noopener noreferrer">setTrimFromStart</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#setTrimFromEnd-float-" target="_blank" rel="nofollow noopener noreferrer">setTrimFromEnd</a> set playback boundaries. You can still retrieve the full clip from <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iaudioframe/#getEmbeddedAudio--" target="_blank" rel="nofollow noopener noreferrer">getEmbeddedAudio</a>.

## **Overview**

PowerPoint stores equations as Office Math Markup Language (OMML). With Aspose.Slides for Java, you can create the same kind of math content programmatically: fractions, radicals, functions, limits, N-ary operators, matrices, arrays, and formatted math blocks.

In PowerPoint, users normally add equations from **Insert &gt; Equation**:

![PowerPoint Insert tab with the Equation command selected](/java/slides/images/56aa77b4a9073cd4-powerpoint-math-equations_1.png)

The result is editable math text on the slide:

![A PowerPoint slide containing an editable math equation](/java/slides/images/c3e05f23ce5e1207-powerpoint-math-equations_2.png)

Aspose.Slides builds that math text through three main objects:

- A math shape, created with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addMathShape-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addMathShape</a>, is the shape that contains the equation.
- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a> stores math content inside the shape text frame.
- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathparagraph/" target="_blank" rel="nofollow noopener noreferrer">MathParagraph</a> contains one or more <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathblock/" target="_blank" rel="nofollow noopener noreferrer">MathBlock</a> objects.

Most examples below use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a> and the fluent methods from <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/" target="_blank" rel="nofollow noopener noreferrer">IMathElement</a> to keep the code short and readable.

For MathML export scenarios, see [Export Math Equations from Presentations in Java](/java/slides/exporting-math-equations/).

## **Create an Equation**

This example uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addMathShape-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addMathShape</a> to create a math shape and adds the Pythagorean theorem:

![The equation c squared equals a squared plus b squared](/java/slides/images/81003d16cc005d98-powerpoint-math-equations_3.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape mathShape = slide.getShapes().addMathShape(20, 20, 700, 120);
    IMathParagraph mathParagraph = ((MathPortion) mathShape.getTextFrame().getParagraphs()
            .get_Item(0).getPortions().get_Item(0)).getMathParagraph();

    IMathBlock equation = new MathematicalText("c")
            .setSuperscript("2")
            .join("=")
            .join(new MathematicalText("a").setSuperscript("2"))
            .join("+")
            .join(new MathematicalText("b").setSuperscript("2"));

    mathParagraph.add(equation);

    presentation.save("pythagorean-theorem.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/ishapecollection/#addMathShape-float-float-float-float-" target="_blank" rel="nofollow noopener noreferrer">addMathShape</a> creates a shape that already contains a math paragraph. Access the first <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a>, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathportion/#getMathParagraph--" target="_blank" rel="nofollow noopener noreferrer">getMathParagraph</a>, and add math blocks or math elements to it.

### **Combine Math Blocks**

When parts of an equation are built independently as <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathblock/" target="_blank" rel="nofollow noopener noreferrer">IMathBlock</a> objects, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathblock/#joinBlock-com.aspose.slides.IMathBlock-" target="_blank" rel="nofollow noopener noreferrer">joinBlock</a> to combine them. The example builds `c² =` in the left block and `a² + b²` in the right block. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#setSuperscript-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setSuperscript</a> creates editable mathematical superscripts for all three powers.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape shape = slide.getShapes().addMathShape(20, 20, 600, 100);
    IMathPortion mathPortion = (IMathPortion) shape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0);
    IMathParagraph mathParagraph = mathPortion.getMathParagraph();

    MathBlock leftBlock = new MathBlock();
    leftBlock.add(new MathematicalText("c").setSuperscript("2"));
    leftBlock.add(new MathematicalText("="));

    MathBlock rightBlock = new MathBlock();
    rightBlock.add(new MathematicalText("a").setSuperscript("2"));
    rightBlock.add(new MathematicalText("+"));
    rightBlock.add(new MathematicalText("b").setSuperscript("2"));

    IMathBlock combinedBlock = leftBlock.joinBlock(rightBlock);
    mathParagraph.add(combinedBlock);

    presentation.save("equation.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathblock/#joinBlock-com.aspose.slides.IMathBlock-" target="_blank" rel="nofollow noopener noreferrer">joinBlock</a> returns `leftBlock` itself, now containing both parts in order, and leaves `rightBlock` empty. Add the combined block to the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathparagraph/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph</a> only once. After reopening `equation.pptx`, the paragraph contains one block representing `c² = a² + b²`, with all three powers preserved as mathematical superscripts.

Calling <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelementcollection/#add-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">add</a> as `leftBlock.add(rightBlock)` instead attempts to nest one block directly inside another and throws `InvalidOperationException`.

## **Add Fractions**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#divide-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">divide</a> to create a fraction. You can choose a fraction style with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathfractiontypes/" target="_blank" rel="nofollow noopener noreferrer">MathFractionTypes</a>.

![A skewed math fraction showing one divided by x](/java/slides/images/b3c6ff0c3496b955-powerpoint-math-equations_4.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape mathShape = slide.getShapes().addMathShape(20, 20, 700, 100);
    IMathParagraph mathParagraph = ((MathPortion) mathShape.getTextFrame().getParagraphs()
            .get_Item(0).getPortions().get_Item(0)).getMathParagraph();

    IMathFraction fraction = new MathematicalText("1")
            .divide("x", MathFractionTypes.Skewed);

    mathParagraph.add(new MathBlock(fraction));

    presentation.save("fraction.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

For a stacked fraction, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathfractiontypes/#Bar" target="_blank" rel="nofollow noopener noreferrer">MathFractionTypes.Bar</a>:

```java
import com.aspose.slides.*;

IMathFraction stackedFraction = new MathematicalText("x + 1").divide("y - 1", MathFractionTypes.Bar);
```

The current element becomes the base, and the argument becomes the degree.

### **Show or Hide the Degree of a Square Root**

A square root can display an explicit 2 or use the conventional √x notation. The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathradical/#setHideDegree-boolean-" target="_blank" rel="nofollow noopener noreferrer">setHideDegree</a> method of <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathradical/" target="_blank" rel="nofollow noopener noreferrer">IMathRadical</a> controls which form appears. Both forms retain the degree 2 and the radicand x in the editable equation.

![The same square root with the degree visible on the left and hidden on the right](/java/slides/images/1dfe7404d270f697-square-root-degree.png)

The example saves the same square root twice. In `visible-degree.pptx`, the 2 is visible. In `hidden-degree.pptx`, it is hidden.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);
    
    IMathRadical radical = new MathematicalText("x").radical("2");

    IAutoShape shape = slide.getShapes().addMathShape(20, 20, 200, 100);
    IMathPortion portion = (IMathPortion) shape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0);
    portion.getMathParagraph().add(new MathBlock(radical));

    radical.setHideDegree(false);
    presentation.save("visible-degree.pptx", SaveFormat.Pptx);

    radical.setHideDegree(true);
    presentation.save("hidden-degree.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Add Functions and Limits**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#asArgumentOfFunction-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">asArgumentOfFunction</a> or <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#function-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">function</a> for functions such as `sin(x)`, `log(x)`, or custom function names. For limits, put `lim` in a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathlimit/" target="_blank" rel="nofollow noopener noreferrer">MathLimit</a> or use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#setLowerLimit-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">setLowerLimit</a>.

![The limit of x as x approaches infinity](/java/slides/images/46a206162ccb53c7-powerpoint-math-equations_8.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape mathShape = slide.getShapes().addMathShape(20, 20, 700, 100);
    IMathParagraph mathParagraph = ((MathPortion) mathShape.getTextFrame().getParagraphs()
            .get_Item(0).getPortions().get_Item(0)).getMathParagraph();

    IMathFunction limit = new MathematicalText("lim")
            .setLowerLimit("x\u2192\u221E")
            .function("x");

    mathParagraph.add(new MathBlock(limit));

    presentation.save("functions-and-limits.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

For a custom function name, make the function name the current element and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#function-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">function</a> with its argument:

```java
import com.aspose.slides.*;

IMathFunction customFunction = new MathematicalText("f").function("x + 1");
```

## **Add N-ary Operators and Integrals**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#nary-int-com.aspose.slides.IMathElement-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">nary</a> for summations, unions, intersections, and other large operators. Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#integral-int-com.aspose.slides.IMathElement-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">integral</a> for integrals. Both methods let you set lower and upper limits.

![A summation with lower and upper limits](/java/slides/images/776e514436eb06a3-powerpoint-math-equations_7.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape mathShape = slide.getShapes().addMathShape(20, 20, 700, 120);
    IMathParagraph mathParagraph = ((MathPortion) mathShape.getTextFrame().getParagraphs()
            .get_Item(0).getPortions().get_Item(0)).getMathParagraph();

    IMathBlock summationBase = new MathematicalText("x")
            .setSuperscript("k")
            .join(new MathematicalText("a").setSuperscript("n-k"));

    IMathNaryOperator summation = summationBase.nary(MathNaryOperatorTypes.Summation, "k=0", "n");

    mathParagraph.add(new MathBlock(summation));

    presentation.save("nary-operators.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

N-ary operators are for large operators with optional limits. Simple operators such as `+`, `-`, and `=` are usually added as <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a> and joined into the expression.

For an integral, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#integral-int-com.aspose.slides.IMathElement-com.aspose.slides.IMathElement-" target="_blank" rel="nofollow noopener noreferrer">integral</a>:

```java
import com.aspose.slides.*;

IMathBlock integralBase = new MathematicalText("x").join(new MathematicalText("dx").toBox());
IMathNaryOperator integral = integralBase.integral(MathIntegralTypes.Simple, "0", "1");
```

## **Add Matrices**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathmatrix/" target="_blank" rel="nofollow noopener noreferrer">MathMatrix</a> for rows and columns. Matrices do not include brackets by default, so enclose the matrix when you need parentheses, brackets, or braces.

![A two-row math matrix with one empty cell](/java/slides/images/db139c375bd3c7bd-powerpoint-math-equations_10.png)

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    IAutoShape mathShape = slide.getShapes().addMathShape(20, 20, 700, 120);
    IMathParagraph mathParagraph = ((MathPortion) mathShape.getTextFrame().getParagraphs()
            .get_Item(0).getPortions().get_Item(0)).getMathParagraph();

    MathMatrix matrix = new MathMatrix(2, 3);
    matrix.set_Item(0, 0, new MathematicalText("1"));
    matrix.set_Item(0, 1, new MathematicalText("x"));
    matrix.set_Item(1, 0, new MathematicalText("x"));
    matrix.set_Item(1, 1, new MathematicalText("2"));
    matrix.set_Item(1, 2, new MathematicalText("y"));

    mathParagraph.add(new MathBlock(matrix));

    presentation.save("matrix.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

### **Edit an Existing Matrix**

Suppose a linear algebra lesson starts with the coefficient matrix in `matrix.pptx`, saved by the preceding example. For the next exercise, keep the first equation, replace the second with two new equations, and revise the set of variables. Open the existing matrix through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathmatrix/" target="_blank" rel="nofollow noopener noreferrer">IMathMatrix</a> to keep the coefficients that still apply.

![Original two-row coefficient matrix with entries 1, x, and an empty cell in the first row and x, 2, and y in the second](/java/slides/images/8afb2aecda93f822-matrix-before-edit.png)

Row and column indices start at zero and refer to the matrix as it stands at each call. Inserting a row before index 1 moves the original second row to index 2. Inserting after index 2 then appends a row. Deleting row 2 removes the original second equation and moves the appended row up one position. Columns shift in the same way.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("matrix.pptx");
try {
    IAutoShape shape = (IAutoShape) presentation.getSlides().get_Item(0).getShapes().get_Item(0);
    IMathPortion portion = (IMathPortion) shape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0);
    IMathMatrix matrix = (IMathMatrix) portion.getMathParagraph().get_Item(0).get_Item(0);

    matrix.insertRowBefore(1);
    matrix.insertRowAfter(2);
    matrix.deleteRow(2);

    matrix.insertColumnBefore(1);
    matrix.insertColumnAfter(3);
    matrix.deleteColumn(3);

    // New cells are initially null. Set the nonzero coefficients first.
    matrix.set_Item(1, 0, new MathematicalText("12"));
    matrix.set_Item(1, 1, new MathematicalText("1"));
    matrix.set_Item(2, 2, new MathematicalText("10"));
    matrix.set_Item(2, 3, new MathematicalText("1"));
    for (int row = 0; row < matrix.getRowCount(); row++) {
        for (int column = 0; column < matrix.getColumnCount(); column++) {
            if (matrix.get_Item(row, column) == null) {
                matrix.set_Item(row, column, new MathematicalText("0"));
            }
        }
    }

    matrix.setColumnAlignment(0, MathHorizontalAlignment.Left);
    matrix.setColumnsAlignment(1, 3, MathHorizontalAlignment.Right);

    presentation.save("updated-matrix.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathmatrix/#setColumnAlignment-int-int-" target="_blank" rel="nofollow noopener noreferrer">setColumnAlignment</a> aligns the first column to the left. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathmatrix/#setColumnsAlignment-int-long-int-" target="_blank" rel="nofollow noopener noreferrer">setColumnsAlignment</a> aligns three consecutive columns to the right, starting at index 1. In `updated-matrix.pptx`, the matrix has three equations and four variables. The original first-row coefficients `1` and `x` now appear in the first and third columns.

![Updated three-row matrix showing the rows 1, 0, x, 0; 12, 1, 0, 0; and 0, 0, 10, 1](/java/slides/images/72c7174520d1e1ca-matrix-after-edit.png)

### **Align an Array with Surrounding Elements**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/imatharray/#setBaseJustification-int-" target="_blank" rel="nofollow noopener noreferrer">setBaseJustification</a> controls the vertical alignment of an array relative to the mathematical elements beside it. The example below compares alignment with the first row, the center of the array, and the last row.

The following example creates three identical arrays, each with three rows and the neighboring elements `A=` and `=B`. All mathematical text uses Cambria Math at 24 points. Only the array alignment changes.

```java
import com.aspose.slides.*;
import java.awt.Color;

class MathTextFactory {
    MathematicalText createText(String value) {
        MathematicalText text = new MathematicalText(value);
        text.getFormat().setFontHeight(24);
        text.getFormat().setLatinFont(new FontData("Cambria Math"));
        return text;
    }
}

MathTextFactory factory = new MathTextFactory();
Presentation presentation = new Presentation();
try {
    presentation.getSlideSize().setSize(780, 200, SlideSizeScaleType.DoNotScale);
    ISlide slide = presentation.getSlides().get_Item(0);
    
    int[] alignments = { MathVerticalAlignment.Top, MathVerticalAlignment.Center, MathVerticalAlignment.Bottom };
    String[] alignmentNames = { "Top", "Center", "Bottom" };

    for (int i = 0; i < alignments.length; i++) {
        IAutoShape label = slide.getShapes().addAutoShape(ShapeType.Rectangle, 20 + i * 260, 10, 240, 30);
        label.getFillFormat().setFillType(FillType.NoFill);
        label.getLineFormat().getFillFormat().setFillType(FillType.NoFill);
        label.getTextFrame().setText(alignmentNames[i]);
        IPortionFormat labelFormat = label.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0).getPortionFormat();
        labelFormat.setFontHeight(16);
        labelFormat.getFillFormat().setFillType(FillType.Solid);
        labelFormat.getFillFormat().getSolidFillColor().setColor(Color.BLACK);

        IAutoShape mathShape = slide.getShapes().addMathShape(20 + i * 260, 60, 240, 130);
        mathShape.getTextFrame().getTextFrameFormat().setAnchoringType(TextAnchorType.Top);
        IMathParagraph mathParagraph = ((IMathPortion) mathShape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0)).getMathParagraph();
        mathParagraph.setJustification(MathJustification.LeftJustified);

        IMathElement[] rows = { factory.createText("x+y=3"), factory.createText("x-y=1"), factory.createText("x=2") };
        MathArray equationArray = new MathArray(rows[0]);
        equationArray.getArguments().add(rows[1]);
        equationArray.getArguments().add(rows[2]);
        equationArray.setBaseJustification(alignments[i]);
        MathematicalText leftText = factory.createText("A=");
        MathematicalText rightText = factory.createText("=B");
        IMathBlock equation = new MathBlock(leftText).join(equationArray).join(rightText);
        mathParagraph.add(equation);
    }

    presentation.save("equation-array-alignment.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The following comparison shows the saved presentation in PowerPoint. Notice the position of `A=` and `=B` beside each array.

### **Configure Row Spacing**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/imatharray/#setRowSpacingRule-int-" target="_blank" rel="nofollow noopener noreferrer">setRowSpacingRule</a> selects the spacing rule for rows within the array. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imatharray/#setRowSpacing-long-" target="_blank" rel="nofollow noopener noreferrer">setRowSpacing</a> supplies a numeric value for an explicit spacing rule and is ignored by the preset rules.

For exact spacing, the value is measured in points. For proportional spacing, it is measured in half-lines: the value `3` in the example specifies 1.5 lines. Set both properties when specifying an explicit value; changing the numeric value alone does not select a spacing rule.

The example below saves five presentations with the same equations, alignment, and font settings. The first three use presets; the last two show explicit values.

```java
import com.aspose.slides.*;

class MathTextFactory {
    MathematicalText createText(String value) {
        MathematicalText text = new MathematicalText(value);
        text.getFormat().setFontHeight(24);
        text.getFormat().setLatinFont(new FontData("Cambria Math"));
        return text;
    }
}

MathTextFactory factory = new MathTextFactory();
int[] rules = { MathRowSpacingRule.SingleLineGap, MathRowSpacingRule.OneAndAHalfLineGap, MathRowSpacingRule.TwoLineGap, MathRowSpacingRule.Exactly, MathRowSpacingRule.Multiple };
int[] spacingValues = { 0, 0, 0, 20, 3 };
String[] ruleNames = { "SingleLineGap", "OneAndAHalfLineGap", "TwoLineGap", "Exactly", "Multiple" };

for (int i = 0; i < rules.length; i++) {
    String fileName = "equation-array-" + ruleNames[i] + ".pptx";
    Presentation presentation = new Presentation();
    try {
        IAutoShape mathShape = presentation.getSlides().get_Item(0).getShapes().addMathShape(20, 20, 600, 300);
        IParagraph paragraph = mathShape.getTextFrame().getParagraphs().get_Item(0);
        paragraph.getParagraphFormat().setSpaceBefore(0);
        paragraph.getParagraphFormat().setSpaceAfter(0);
        IMathParagraph mathParagraph = ((IMathPortion) paragraph.getPortions().get_Item(0)).getMathParagraph();
        mathParagraph.setJustification(MathJustification.LeftJustified);

        IMathElement[] rows = { factory.createText("x+y=3"), factory.createText("x-y=1"), factory.createText("x=2") };
        MathArray equationArray = new MathArray(rows[0]);
        equationArray.getArguments().add(rows[1]);
        equationArray.getArguments().add(rows[2]);
        equationArray.setBaseJustification(MathVerticalAlignment.Center);
        equationArray.setRowSpacingRule(rules[i]);
        equationArray.setRowSpacing(spacingValues[i]);
        MathematicalText leftText = factory.createText("A=");
        MathematicalText rightText = factory.createText("=B");
        IMathBlock equation = new MathBlock(leftText).join(equationArray).join(rightText);
        mathParagraph.add(equation);

        presentation.save(fileName, SaveFormat.Pptx);
    } finally {
        presentation.dispose();
    }
}
```

Array row spacing is separate from paragraph spacing. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iparagraphformat/#setSpaceBefore-float-" target="_blank" rel="nofollow noopener noreferrer">setSpaceBefore</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iparagraphformat/#setSpaceAfter-float-" target="_blank" rel="nofollow noopener noreferrer">setSpaceAfter</a> add space around the containing paragraph, not between array rows. Likewise, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathparagraph/#setJustification-int-" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph.setJustification</a> positions the whole math paragraph horizontally; it does not replace the array's vertical alignment setting.

### **Align Right Subscripts and Superscripts**

When both scripts belong to the same base, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathrightsubsuperscriptelement/" target="_blank" rel="nofollow noopener noreferrer">MathRightSubSuperscriptElement</a>. ### **Size and Align Delimiters**

Pass `true` to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathdelimiter/#setGrowToMatchOperandHeight-boolean-" target="_blank" rel="nofollow noopener noreferrer">setGrowToMatchOperandHeight</a> to let the parentheses grow around a tall operand, or pass `false` to keep them at their normal size. Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathdelimiter/#setDelimiterShape-int-" target="_blank" rel="nofollow noopener noreferrer">setDelimiterShape</a> with one of two <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathdelimitershape/" target="_blank" rel="nofollow noopener noreferrer">MathDelimiterShape</a> values. `Centered` centers the parentheses on the math axis, which runs through the middle of the equals sign. `Match` aligns them with the enclosed content. Both settings affect only the delimiters. The expression inside stays the same.

The example places a fraction in the exponent of `x` so the expression extends farther above the baseline than below it. All four equations use the same parentheses and font settings.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation();
try {
    ISlide slide = presentation.getSlides().get_Item(0);
    for (int row = 0; row < 2; row++) {
        for (int column = 0; column < 2; column++) {
            IMathFraction fraction = new MathematicalText("a + b").divide("c + d");
            IMathSuperscriptElement power = new MathematicalText("x").setSuperscript(fraction);
            IMathDelimiter delimiter = power.enclose('(', ')');
            delimiter.setGrowToMatchOperandHeight(row == 0);
            delimiter.setDelimiterShape(column == 0 ? MathDelimiterShape.Centered : MathDelimiterShape.Match);

            IAutoShape mathShape = slide.getShapes().addMathShape(20 + 330 * column, 20 + 120 * row, 300, 100);
            MathPortion portion = (MathPortion) mathShape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0);
            portion.getPortionFormat().setFontHeight(32);
            IMathBlock equation = new MathematicalText("y = ").join(delimiter);
            portion.getMathParagraph().add(equation);
        }
    }
    presentation.save("delimiter-sizing.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

In PowerPoint, compare the rows to see the effect of growth. In the top row, the parentheses grow to enclose the exponent and look alike for both shapes. In the bottom row, growth is off. The smaller parentheses on the left (`Centered`) align with the equals sign, while those on the right (`Match`) sit higher around the expression.

## **Control Visibility and Layout with Phantom Elements**

Wrap an expression in <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathphantom/" target="_blank" rel="nofollow noopener noreferrer">MathPhantom</a> to control its visibility and the space it contributes to an equation independently. The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/" target="_blank" rel="nofollow noopener noreferrer">IMathPhantom</a> methods control the following:

<div className="docs-owner-markdown-table">

| Method | Effect |
| -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#setShow-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShow</a> | Pass `false` to hide the expression. Its dimensions still contribute to layout unless the corresponding methods below receive `true`. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#setZeroWidth-boolean-" target="_blank" rel="nofollow noopener noreferrer">setZeroWidth</a> | Treat the expression's horizontal width as zero, allowing neighboring elements to move closer together. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#setZeroAsc-boolean-" target="_blank" rel="nofollow noopener noreferrer">setZeroAsc</a> | Treat its ascent, the height above the baseline, as zero. This can reduce the space reserved above neighboring elements. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#setZeroDesc-boolean-" target="_blank" rel="nofollow noopener noreferrer">setZeroDesc</a> | Treat its descent, the depth below the baseline, as zero. This can move a fraction bar or other content below the expression closer to its neighbors. |

</div>

The baseline is the reference line on which ordinary mathematical letters sit. Hiding content does not remove its dimensions, and treating a dimension as zero does not delete the expression. The underlying expression remains available through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#getBase--" target="_blank" rel="nofollow noopener noreferrer">getBase</a>. Pass `true` to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathphantom/#setShow-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShow</a> to display it again; the dimension settings remain unchanged.

The example below creates five side-by-side variants: a visible fraction, a hidden fraction that reserves space, and three hidden fractions with one dimension treated as zero. Each variant uses the same surrounding expression and Cambria Math at 24 points. All equation shapes have the same top position, marked by the gray guide. Placing the phantom in the numerator of an outer fraction makes the vertical layout changes easier to see.

```java

    MathematicalText createText(String value) {
        MathematicalText text = new MathematicalText(value);
        text.getFormat().setFontHeight(24);
        text.getFormat().setLatinFont(new FontData("Cambria Math"));
        return text;
    }
}

MathTextFactory factory = new MathTextFactory();
Presentation presentation = new Presentation();
try {
    presentation.getSlideSize().setSize(1000, 180, SlideSizeScaleType.DoNotScale);
    ISlide slide = presentation.getSlides().get_Item(0);

    String[] labels = { "Visible", "Hidden: reserves space", "Hidden: ZeroWidth", "Hidden: ZeroAsc", "Hidden: ZeroDesc" };

    IAutoShape guide = slide.getShapes().addAutoShape(ShapeType.Line, 10, 60, 980, 0);
    guide.getLineFormat().getFillFormat().setFillType(FillType.Solid);
    guide.getLineFormat().getFillFormat().getSolidFillColor().setColor(Color.LIGHT_GRAY);

    for (int i = 0; i < labels.length; i++) {
        int left = 10 + i * 200;

        IAutoShape label = slide.getShapes().addAutoShape(ShapeType.Rectangle, left, 10, 190, 30);
        label.getFillFormat().setFillType(FillType.NoFill);
        label.getLineFormat().getFillFormat().setFillType(FillType.NoFill);
        label.getTextFrame().setText(labels[i]);

        IPortionFormat labelFormat = label.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0).getPortionFormat();
        labelFormat.setFontHeight(14);
        labelFormat.getFillFormat().setFillType(FillType.Solid);
        labelFormat.getFillFormat().getSolidFillColor().setColor(Color.BLACK);

        MathematicalText fractionNumerator = factory.createText("a+b");
        MathematicalText fractionDenominator = factory.createText("c+d");
        MathFraction fraction = new MathFraction(fractionNumerator, fractionDenominator);
        MathPhantom phantom = new MathPhantom(fraction);
        phantom.setShow(i == 0);
        phantom.setZeroWidth(i == 2);
        phantom.setZeroAsc(i == 3);
        phantom.setZeroDesc(i == 4);

        MathematicalText leftText = factory.createText("x+");
        MathematicalText rightText = factory.createText("+y");
        IMathBlock numerator = new MathBlock(leftText).join(phantom).join(rightText);
        MathematicalText denominator = factory.createText("z");
        MathFraction equation = new MathFraction(numerator, denominator);

        IAutoShape shape = slide.getShapes().addMathShape(left, 60, 190, 100);
        shape.getTextFrame().getTextFrameFormat().setAnchoringType(TextAnchorType.Top);

        IMathPortion mathPortion = (IMathPortion) shape.getTextFrame().getParagraphs().get_Item(0).getPortions().get_Item(0);
        IMathParagraph mathParagraph = mathPortion.getMathParagraph();
        mathParagraph.add(new MathBlock(equation));
    }

    presentation.save("math-phantom.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

### **Format Text in an Existing Equation**

To format text throughout an existing equation, traverse each math block's element tree. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathelement/#getChildren--" target="_blank" rel="nofollow noopener noreferrer">IMathElement.getChildren</a> returns only the immediate children, so call it recursively to reach text inside fractions, scripts, radicals, and other nested structures. Check the current element as well as its children to include the starting element when it is <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathematicaltext/" target="_blank" rel="nofollow noopener noreferrer">MathematicalText</a>.

This example assumes that `input.pptx` contains an equation such as `z = xᵢ / ∛y`, with a fraction containing a subscript in its numerator and a radical in its denominator. Processing only the block's top-level elements would miss the text inside the fraction. The example finds mathematical portions in slide text frames, accesses their blocks through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathportion/#getMathParagraph--" target="_blank" rel="nofollow noopener noreferrer">IMathPortion.getMathParagraph</a>, and uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseportionformat/#setFontHeight-float-" target="_blank" rel="nofollow noopener noreferrer">setFontHeight</a> to set the font size to 28 points through each text element's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathematicaltext/#getFormat--" target="_blank" rel="nofollow noopener noreferrer">getFormat</a> method.

```java
import com.aspose.slides.*;

class MathTextFormatter {
    void formatMathText(IMathElement element) {
        if (element instanceof MathematicalText) {
            MathematicalText text = (MathematicalText) element;
            text.getFormat().setFontHeight(28);
        }

        for (IMathElement child : element.getChildren()) {
            formatMathText(child);
        }
    }
}

MathTextFormatter formatter = new MathTextFormatter();
Presentation presentation = new Presentation("input.pptx");
try {
    for (ISlide slide : presentation.getSlides()) {
        for (IShape shape : slide.getShapes()) {
            if (!(shape instanceof IAutoShape)) {
                continue;
            }

            IAutoShape autoShape = (IAutoShape) shape;
            if (autoShape.getTextFrame() == null) {
                continue;
            }

            for (IParagraph paragraph : autoShape.getTextFrame().getParagraphs()) {
                for (IPortion portion : paragraph.getPortions()) {
                    if (portion instanceof IMathPortion) {
                        IMathPortion mathPortion = (IMathPortion) portion;
                        for (IMathBlock block : mathPortion.getMathParagraph()) {
                            formatter.formatMathText(block);
                        }
                    }
                }
            }
        }
    }

    presentation.save("formatted-equations.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The saved presentation contains the updated text formatting at every level of each processed equation, while preserving its text content and mathematical structure.

## **FAQ**

**Can I edit an existing PowerPoint equation?**

Yes. Open the presentation, find the shape that contains a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/mathportion/" target="_blank" rel="nofollow noopener noreferrer">MathPortion</a>, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathportion/#getMathParagraph--" target="_blank" rel="nofollow noopener noreferrer">getMathParagraph</a>, and update the math blocks in that paragraph.

**Are equations saved as editable PowerPoint math?**

Yes. When you save to PPTX, Aspose.Slides writes the equation as editable Office math content.

**Can I export equations to LaTeX?**

Yes. Get the equation's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathparagraph/" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph</a> from its <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathportion/" target="_blank" rel="nofollow noopener noreferrer">IMathPortion</a>, and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imathparagraph/#toLatex--" target="_blank" rel="nofollow noopener noreferrer">IMathParagraph.toLatex</a> to export it directly. For a complete example, see [Export Math Equations from Presentations in Java](/java/slides/exporting-math-equations/#export-math-equations-to-latex).

> Learn how to manage footer, date-time, slide-number, and header placeholders on slides, notes pages, and handouts with Aspose.Slides for Java.
> 8

## **Overview**

PowerPoint uses different header and footer placeholders depending on the page type. Aspose.Slides for Java lets you control the text and visibility of these placeholders through header/footer manager interfaces.

The available placeholders depend on the scope:

<div className="docs-owner-markdown-table">

| Scope | Header | Footer | Date/time | Slide/page number |
| -------------- | ------ | ------ | --------- | ----------------- |
| Regular slide | No | Yes | Yes | Yes |
| Notes master | Yes | Yes | Yes | Yes |
| Notes slide | Yes | Yes | Yes | Yes |
| Handout master | Yes | Yes | Yes | Yes |

</div>

A regular presentation slide does not have a header placeholder. Headers are available on notes pages and handouts. For regular slides, use footer, date/time, and slide-number placeholders instead.

The scope of a change depends on the manager you use. The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">ISlideHeaderFooterManager</a> interface controls one regular slide. The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">INotesSlideHeaderFooterManager</a> interface controls one notes slide. Master and layout managers can also propagate settings to dependent slides, while the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterHandoutSlideHeaderFooterManager</a> interface controls the handout master.

## **Update Header, Footer, and Date/Time Text Across a Presentation**

Use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getHeaderFooterManager--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getHeaderFooterManager</a> method to access <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IPresentationHeaderFooterManager</a>, to apply consistent text across a presentation without updating each page or master individually.

<div className="docs-owner-markdown-table">

| Method | Affected objects |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllHeadersText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setAllHeadersText</a> | Existing notes pages, notes master, and handout master |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllFootersText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setAllFootersText</a> | Regular slides, layouts, slide masters, existing notes pages, notes master, and handout master |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllDateTimesText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setAllDateTimesText</a> | Regular slides, layouts, slide masters, existing notes pages, notes master, and handout master |

</div>

Headers apply only to notes pages and handouts; regular slides do not support header placeholders. Handout settings are updated through the handout master.

Setting text does not make a placeholder visible. First use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllHeadersVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAllHeadersVisibility</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllFootersVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAllFootersVisibility</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationheaderfootermanager/#setAllDateTimesVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAllDateTimesVisibility</a> to enable the corresponding placeholders, then set their text. These visibility methods have the same scope as the corresponding text methods.

The following example assumes that a presentation contains regular slides, notes pages, a notes master, and a handout master. It applies corporate text and a fixed date label, then saves the result.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    IPresentationHeaderFooterManager manager = presentation.getHeaderFooterManager();

    manager.setAllHeadersVisibility(true);
    manager.setAllFootersVisibility(true);
    manager.setAllDateTimesVisibility(true);

    manager.setAllHeadersText("Contoso");
    manager.setAllFootersText("Internal use only");
    manager.setAllDateTimesText("October 2026");

    presentation.save("updated.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The text methods skip missing placeholders. Enabling visibility first creates the required placeholders on existing pages and masters. Neither the text methods nor the visibility methods create missing notes pages, notes masters, or handout masters. The date/time text is a fixed label, not an automatically updating date/time field.

For narrower changes, see the examples for [regular slides](/java/slides/presentation-header-and-footer/#set-footer-datetime-and-slide-numbers-on-regular-slides), the [notes master](/java/slides/presentation-header-and-footer/#set-headers-and-footers-on-the-notes-master), an [individual notes page](/java/slides/presentation-header-and-footer/#set-headers-and-footers-on-an-individual-notes-slide), and the [handout master](/java/slides/presentation-header-and-footer/#set-headers-and-footers-on-the-handout-master). See [Presentation Notes](/java/slides/presentation-notes/) for removing notes and managing notes masters.

## **Set Footer, Date/Time, and Slide Numbers on Regular Slides**

For regular slides, the basic workflow is to access each slide's header/footer manager, set the footer and date/time text, enable the required placeholders, and save the presentation. Slide numbers are generated by the presentation, so you only need to control their visibility.

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setFooterText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setFooterText</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setDateTimeText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setDateTimeText</a> to set text, and use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setFooterVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setFooterVisibility</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setDateTimeVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setDateTimeVisibility</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setSlideNumberVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setSlideNumberVisibility</a> to show the corresponding placeholders.

The following end-to-end example applies the same footer, date/time text, and slide-number visibility to all regular slides:

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    for (ISlide slide : presentation.getSlides()) {
        ISlideHeaderFooterManager headerFooterManager = slide.getHeaderFooterManager();

        headerFooterManager.setFooterText("Company Confidential");
        headerFooterManager.setFooterVisibility(true);

        headerFooterManager.setDateTimeText("Date and time text");
        headerFooterManager.setDateTimeVisibility(true);

        headerFooterManager.setSlideNumberVisibility(true);
    }

    presentation.save("presentation_with_slide_footers.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

If you need to update only one slide, access that slide directly through the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">getSlides</a> method instead of iterating through the entire collection.

## **Set Headers and Footers on the Notes Master**

The notes master defines common formatting and placeholder behavior for notes pages. Use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterNotesSlideHeaderFooterManager</a> interface when you want to change only the notes master itself.

The following example sets header, footer, and date/time text on the notes master and makes all supported placeholders visible on that master:

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    IMasterNotesSlide masterNotesSlide = presentation.getMasterNotesSlideManager().getMasterNotesSlide();

    if (masterNotesSlide != null) {
        IMasterNotesSlideHeaderFooterManager headerFooterManager = masterNotesSlide.getHeaderFooterManager();

        headerFooterManager.setHeaderText("Notes header");
        headerFooterManager.setHeaderVisibility(true);

        headerFooterManager.setFooterText("Notes footer");
        headerFooterManager.setFooterVisibility(true);

        headerFooterManager.setDateTimeText("Date and time text");
        headerFooterManager.setDateTimeVisibility(true);

        headerFooterManager.setSlideNumberVisibility(true);
    }

    presentation.save("presentation_with_notes_master_footers.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslidemanager/#getMasterNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterNotesSlide</a> method returns `null` when the presentation does not contain a notes master. To clean up a template without notes pages, see [Remove an Unused Notes Master](/java/slides/presentation-notes/#remove-an-unused-notes-master).

## **Apply Notes Master Settings to Child Notes Slides**

A notes master can apply header and footer settings to itself and to all dependent notes slides. Use the dedicated propagation methods on <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterNotesSlideHeaderFooterManager</a> when the same settings should be applied across the notes hierarchy.

For example, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setHeaderAndChildHeadersText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setHeaderAndChildHeadersText</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setHeaderAndChildHeadersVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setHeaderAndChildHeadersVisibility</a> update the notes master header and all child headers. Equivalent methods are available for footers, date/time, and slide numbers.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    IMasterNotesSlide masterNotesSlide = presentation.getMasterNotesSlideManager().getMasterNotesSlide();

    if (masterNotesSlide != null) {
        IMasterNotesSlideHeaderFooterManager headerFooterManager = masterNotesSlide.getHeaderFooterManager();

        headerFooterManager.setHeaderAndChildHeadersText("Notes header");
        headerFooterManager.setHeaderAndChildHeadersVisibility(true);

        headerFooterManager.setFooterAndChildFootersText("Notes footer");
        headerFooterManager.setFooterAndChildFootersVisibility(true);

        headerFooterManager.setDateTimeAndChildDateTimesText("Date and time text");
        headerFooterManager.setDateTimeAndChildDateTimesVisibility(true);

        headerFooterManager.setSlideNumberAndChildSlideNumbersVisibility(true);
    }

    presentation.save("presentation_with_child_notes_footers.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The propagation methods used above are <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setFooterAndChildFootersText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setFooterAndChildFootersText</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setFooterAndChildFootersVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setFooterAndChildFootersVisibility</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setDateTimeAndChildDateTimesText-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setDateTimeAndChildDateTimesText</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setDateTimeAndChildDateTimesVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setDateTimeAndChildDateTimesVisibility</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/#setSlideNumberAndChildSlideNumbersVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setSlideNumberAndChildSlideNumbersVisibility</a>.

## **Set Headers and Footers on an Individual Notes Slide**

A notes slide belongs to a specific regular slide. Use its <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">INotesSlideHeaderFooterManager</a> interface when you want to customize only that notes page.

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inotesslidemanager/#addNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">addNotesSlide</a> method returns the notes slide for the current slide and creates one if it does not already exist. The following example configures the notes page associated with the first presentation slide:

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);
    INotesSlide notesSlide = slide.getNotesSlideManager().addNotesSlide();
    INotesSlideHeaderFooterManager headerFooterManager = notesSlide.getHeaderFooterManager();

    headerFooterManager.setHeaderText("Header for the first notes page");
    headerFooterManager.setHeaderVisibility(true);

    headerFooterManager.setFooterText("Footer for the first notes page");
    headerFooterManager.setFooterVisibility(true);

    headerFooterManager.setDateTimeText("Date and time text");
    headerFooterManager.setDateTimeVisibility(true);

    headerFooterManager.setSlideNumberVisibility(true);

    presentation.save("presentation_with_custom_notes_footers.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

If you first propagate settings from the notes master and then change an individual notes slide, the later per-slide settings let you customize that notes page independently.

## **Set Headers and Footers on the Handout Master**

Handout pages use the handout master for their header, footer, date/time, and page-number placeholders. Unlike notes pages, handout settings are managed through the handout master rather than through individual handout slides.

Use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslidemanager/#getMasterHandoutSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterHandoutSlide</a> method to access the handout master. If it is not present, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslidemanager/#setDefaultMasterHandoutSlide--" target="_blank" rel="nofollow noopener noreferrer">setDefaultMasterHandoutSlide</a> to create the default handout master.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    IMasterHandoutSlide masterHandoutSlide = presentation.getMasterHandoutSlideManager().getMasterHandoutSlide();

    if (masterHandoutSlide == null) {
        masterHandoutSlide = presentation.getMasterHandoutSlideManager().setDefaultMasterHandoutSlide();
    }

    if (masterHandoutSlide != null) {
        IMasterHandoutSlideHeaderFooterManager headerFooterManager = masterHandoutSlide.getHeaderFooterManager();

        headerFooterManager.setHeaderText("Handout header");
        headerFooterManager.setHeaderVisibility(true);

        headerFooterManager.setFooterText("Handout footer");
        headerFooterManager.setFooterVisibility(true);

        headerFooterManager.setDateTimeText("Date and time text");
        headerFooterManager.setDateTimeVisibility(true);

        headerFooterManager.setSlideNumberVisibility(true);
    }

    presentation.save("presentation_with_handout_footers.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

To remove the entire handout master, including its formatting and placeholders, see [Remove a Handout Master](/java/slides/presentation-notes/#remove-a-handout-master). If you only need to hide a header or footer, change its visibility instead to preserve the master's other formatting.

## **Understand Scope and Inheritance**

Choose the header/footer manager that matches the scope you want to change:

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IPresentationHeaderFooterManager</a> updates supported placeholders throughout the presentation, as shown in the [presentation-wide example](/java/slides/presentation-header-and-footer/#update-header-footer-and-datetime-text-across-a-presentation).

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">ISlideHeaderFooterManager</a> changes footer, date/time, and slide-number settings for one regular slide.

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ilayoutslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">ILayoutSlideHeaderFooterManager</a> controls a layout slide and can propagate supported settings to dependent slides.

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterSlideHeaderFooterManager</a> controls a regular slide master and can propagate supported settings to dependent slides.

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterNotesSlideHeaderFooterManager</a> controls the notes master and can propagate settings to all dependent notes slides.

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inotesslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">INotesSlideHeaderFooterManager</a> changes one notes slide and supports a header placeholder in addition to footer, date/time, and slide number.

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslideheaderfootermanager/" target="_blank" rel="nofollow noopener noreferrer">IMasterHandoutSlideHeaderFooterManager</a> changes the handout master and supports all four placeholder types.

Use propagation from a master or layout when the same setting should apply throughout its hierarchy. Use an individual slide or notes-slide manager when you need a local setting for one page.

## **FAQ**

**Can I add a header to a regular slide?**

No. PowerPoint does not define a header placeholder for regular slides. On regular slides, use the footer, date/time, and slide-number placeholders. Header placeholders are available on notes pages and handouts.

**What if a footer, date/time, or slide-number placeholder is not visible?**

Use the corresponding header/footer manager to check its visibility and enable it when needed. For example, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#isFooterVisible--" target="_blank" rel="nofollow noopener noreferrer">isFooterVisible</a> reports whether a footer placeholder is present, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/baseslideheaderfootermanager/#setFooterVisibility-boolean-" target="_blank" rel="nofollow noopener noreferrer">setFooterVisibility</a> changes its visibility.

**How do I start slide numbering from a value other than 1?**

Call the presentation's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#setFirstSlideNumber-int-" target="_blank" rel="nofollow noopener noreferrer">setFirstSlideNumber</a> method. The slide-number placeholders then use the updated numbering sequence.

**What happens to headers and footers when exporting to PDF, images, or HTML?**

Visible header and footer elements are rendered with the rest of the presentation content in the output format. Their appearance depends on the page type being exported and the corresponding placeholder visibility settings.

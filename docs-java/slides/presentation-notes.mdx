> Remove slide notes and customize master notes text styles in PowerPoint and OpenDocument presentations with Aspose.Slides for Java.
> 8

## **Overview**

Aspose.Slides for Java lets you remove notes from individual slides or an entire presentation, customize the text style defined in the master notes slide, and remove notes and handout masters. This article shows how to perform these operations and save the updated presentation.

To read or change notes page dimensions, switch orientation, and check export behavior, see [Notes Page Size](/java/slides/notes-size/).

## **Remove Notes from a Slide**

To remove notes from a specific slide, call its <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slide/#getNotesSlideManager--" target="_blank" rel="nofollow noopener noreferrer">getNotesSlideManager</a> method and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/notesslidemanager/#removeNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">removeNotesSlide</a>. The example loads a presentation containing at least one slide and removes the notes from the first slide, accessed at index zero. Notes on other slides remain unchanged, and the updated presentation is saved in PPTX format.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    INotesSlideManager notesManager = presentation.getSlides().get_Item(0).getNotesSlideManager();
    notesManager.removeNotesSlide();

    presentation.save("presentation_without_first_slide_notes.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Remove Notes from All Slides**

To remove all slide notes, iterate through the collection returned by the presentation's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">getSlides</a> method and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/notesslidemanager/#removeNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">removeNotesSlide</a> for each slide. This example processes every slide in an existing presentation and saves a PPTX copy without slide notes.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    for (ISlide slide : presentation.getSlides()) {
        slide.getNotesSlideManager().removeNotesSlide();
    }

    presentation.save("presentation_without_notes.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Remove Notes and Handout Masters**

Notes and handout masters define shared formatting and placeholders for their respective page types. Removing a master is a separate operation from removing an individual slide's notes with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/notesslidemanager/#removeNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">removeNotesSlide</a>.

### **Remove an Unused Notes Master**

When cleaning up a template that has no notes pages, you can remove its unused notes master. Access <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getMasterNotesSlideManager--" target="_blank" rel="nofollow noopener noreferrer">getMasterNotesSlideManager</a>, check <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslidemanager/#getMasterNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterNotesSlide</a>, and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslidemanager/#removeMasterNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">removeMasterNotesSlide</a>.

The following example requires a presentation to contain no notes pages. It removes the notes master if one exists, including its formatting and header/footer placeholders, and saves the template.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("template_without_notes.pptx");
try {
    IMasterNotesSlideManager manager = presentation.getMasterNotesSlideManager();
    if (manager.getMasterNotesSlide() != null) {
        manager.removeMasterNotesSlide();
    }

    presentation.save("template_without_notes_master.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

After removal, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslidemanager/#getMasterNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterNotesSlide</a> returns `null`. If the master is already absent, the example skips removal and still saves the presentation.

### **Remove a Handout Master**

To remove a handout master, access <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getMasterHandoutSlideManager--" target="_blank" rel="nofollow noopener noreferrer">getMasterHandoutSlideManager</a>, check <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslidemanager/#getMasterHandoutSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterHandoutSlide</a>, and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslidemanager/#removeMasterHandoutSlide--" target="_blank" rel="nofollow noopener noreferrer">removeMasterHandoutSlide</a>.

For this example, use a presentation containing slide notes and customized notes and handout masters. Give the handout master a visible banner and header/footer text so that the effect of removal is easy to compare in handout output.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation_with_custom_masters.pptx");
try {
    IMasterHandoutSlideManager manager = presentation.getMasterHandoutSlideManager();
    if (manager.getMasterHandoutSlide() != null) {
        manager.removeMasterHandoutSlide();
    }

    presentation.save("presentation_without_handout_master.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

After removal, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasterhandoutslidemanager/#getMasterHandoutSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterHandoutSlide</a> returns `null`. Existing slide notes and the notes master remain unchanged. If the handout master is already absent, the example simply saves the presentation.

In handout output, the removed master's banner, formatting, and header, footer, date/time, and page-number placeholders no longer appear. The presentation slides still appear in the handout layout, including any footer or date text on the slides themselves. Slide numbers added by the handout export settings are separate from the master's page-number placeholder.

If you only want to hide handout headers or footers, change the corresponding placeholder visibility through the [handout master's header/footer manager](/java/slides/presentation-header-and-footer/#set-headers-and-footers-on-the-handout-master) instead. This keeps the master and its other formatting, such as a custom banner.

## **Add a Notes Style**

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/masternotesslide/#getNotesStyle--" target="_blank" rel="nofollow noopener noreferrer">getNotesStyle</a> method of <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslide/" target="_blank" rel="nofollow noopener noreferrer">IMasterNotesSlide</a> returns the master notes text style. The example accesses the existing notes master through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imasternotesslidemanager/#getMasterNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">getMasterNotesSlide</a> and uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/textstyle/#getLevel-int-" target="_blank" rel="nofollow noopener noreferrer">getLevel</a> with index zero to select the first paragraph level. It sets the bullet type to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/bullettype/#Symbol" target="_blank" rel="nofollow noopener noreferrer">BulletType.Symbol</a> and saves the presentation in PPTX format. The input must contain a master notes slide for the style change to take effect; otherwise, the presentation is saved without changing the notes style.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    IMasterNotesSlide notesMaster = presentation.getMasterNotesSlideManager().getMasterNotesSlide();
    if (notesMaster != null) {
        ITextStyle notesStyle = notesMaster.getNotesStyle();
        IParagraphFormat paragraphFormat = notesStyle.getLevel(0);
        paragraphFormat.getBullet().setType(BulletType.Symbol);
    }

    presentation.save("presentation_with_notes_style.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **FAQ**

**Which API provides access to the notes of a specific slide?**

Use the slide's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/slide/#getNotesSlideManager--" target="_blank" rel="nofollow noopener noreferrer">getNotesSlideManager</a> method. The manager's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/notesslidemanager/#getNotesSlide--" target="_blank" rel="nofollow noopener noreferrer">getNotesSlide</a> method returns the notes slide, or `null` if the slide has no notes.

**Does working with notes require Microsoft PowerPoint to be installed?**

No. Aspose.Slides works with notes in PowerPoint and OpenDocument presentations without requiring Microsoft PowerPoint to be installed.

## **Overview**

This article explains how to convert presentation slides to PNG images using Aspose.Slides for Java. You can load presentations in formats such as PPT, PPTX, and ODP, render each slide, and save it as a separate PNG image.

The examples below demonstrate rendering at the default scale, increasing the scale, specifying the output dimensions in pixels, and choosing a gradient rendering style.

## **Convert PowerPoint to PNG**

Load a presentation with the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> class and access its slides through the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSlides</a> collection. The example renders every slide with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getImage--" target="_blank" rel="nofollow noopener noreferrer">ISlide.getImage</a> without parameters to create a thumbnail. It then calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimage/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">IImage.save</a> with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/imageformat/#Png" target="_blank" rel="nofollow noopener noreferrer">ImageFormat.Png</a> to save each rendered slide as a PNG image.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    int slideCount = presentation.getSlides().size();
    for (int index = 0; index < slideCount; index++) {
        ISlide slide = presentation.getSlides().get_Item(index);
        IImage image = slide.getImage();
        try {
            image.save("slide_" + index + ".png", ImageFormat.Png);
        } finally {
            image.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```

The parameterless <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getImage--" target="_blank" rel="nofollow noopener noreferrer">ISlide.getImage</a> overload renders at a scale of 0.2. For example, a slide measuring 720 × 540 points produces a 144 × 108 pixel thumbnail. To control the output dimensions, use the overloads with scale factors or an explicit image size shown below.

## **Convert PowerPoint to PNG With Custom Dimensions**

Pass horizontal and vertical scale factors to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getImage-float-float-" target="_blank" rel="nofollow noopener noreferrer">ISlide.getImage</a> to control the rendered dimensions. In this example, both factors are 2, so a slide measuring 720 × 540 points produces a 1440 × 1080 pixel image. Equal scale factors preserve the slide's aspect ratio. Each image is saved in PNG format with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimage/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">IImage.save</a>.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("presentation.pptx");
try {
    float scaleX = 2f;
    float scaleY = scaleX;

    int slideCount = presentation.getSlides().size();
    for (int index = 0; index < slideCount; index++) {
        ISlide slide = presentation.getSlides().get_Item(index);
        IImage image = slide.getImage(scaleX, scaleY);
        try {
            image.save("slide_" + index + ".png", ImageFormat.Png);
        } finally {
            image.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```

## **Convert PowerPoint to PNG With Custom Size**

To specify output dimensions in pixels, pass a size to <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getImage-java.awt.Dimension-" target="_blank" rel="nofollow noopener noreferrer">ISlide.getImage</a> instead of scale factors. This example renders every slide at 960 × 720 pixels and saves the result with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iimage/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">IImage.save</a>. Choose dimensions that match the slide's aspect ratio to avoid stretching the image.

```java
import com.aspose.slides.*;
import java.awt.Dimension;

Presentation presentation = new Presentation("presentation.pptx");
try {
    Dimension imageSize = new Dimension(960, 720);

    int slideCount = presentation.getSlides().size();
    for (int index = 0; index < slideCount; index++) {
        ISlide slide = presentation.getSlides().get_Item(index);
        IImage image = slide.getImage(imageSize);
        try {
            image.save("slide_" + index + ".png", ImageFormat.Png);
        } finally {
            image.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```

## **Choose a Gradient Rendering Style**

Suppose a slide contains gradient fills, but the transitions in the exported PNG look lighter or otherwise different from what you see in PowerPoint. You can use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/saveoptions/#setGradientStyle-int-" target="_blank" rel="nofollow noopener noreferrer">SaveOptions.setGradientStyle</a> method inherited by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/renderingoptions/" target="_blank" rel="nofollow noopener noreferrer">RenderingOptions</a> to choose how the gradients are rendered.

Download <a href="https://docs.aspose.com/slides/java/convert-powerpoint-to-png/gradient-styles.pptx" target="_blank" rel="nofollow noopener noreferrer">gradient-styles.pptx</a> and place it in the application's working directory. Its first slide contains two linear gradients: cyan to orange at the top and blue to yellow at the bottom. Each gradient has two stops, at 0% and 100%.

The following example loads this presentation and renders the same first slide in both modes with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getImage-com.aspose.slides.IRenderingOptions-float-float-" target="_blank" rel="nofollow noopener noreferrer">ISlide.getImage</a>.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("gradient-styles.pptx");
try {
    ISlide slide = presentation.getSlides().get_Item(0);

    int[] gradientStyles = { GradientStyle.Default, GradientStyle.PowerPointUI };
    for (int style : gradientStyles) {
        RenderingOptions options = new RenderingOptions();
        options.setGradientStyle(style);

        String styleName = style == GradientStyle.Default ? "Default" : "PowerPointUI";
        IImage image = slide.getImage(options, 1f, 1f);
        try {
            image.save("gradient-" + styleName + ".png", ImageFormat.Png);
        } finally {
            image.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```

Choose `Default` when the standard Aspose.Slides output suits your needs. Try `PowerPointUI` when your priority is matching the appearance in PowerPoint. Compare both outputs with your intended result; neither mode is universally preferable.

## **FAQ**

**How can I export a specific shape, such as a chart or picture, instead of the entire slide?**

Aspose.Slides supports [generating thumbnails for individual shapes](/java/slides/create-shape-thumbnails/), allowing you to render a shape as a PNG image.

**Is parallel conversion supported on a server?**

Yes. Use a separate presentation instance for each thread or process; [do not share a single instance across threads](/java/slides/multithreading/).

**What are the evaluation limitations when exporting to PNG?**

Evaluation mode adds a watermark to output images and applies [other restrictions](/java/slides/licensing/) until a license is applied.

## **Overview**

This article explains how to convert PowerPoint presentations to SWF by using Aspose.Slides. It shows how to save a presentation as an SWF file with the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-com.aspose.slides.ISaveOptions-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> method and how to configure the export with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a>, including viewer settings and notes or comments layout.

## **Convert Presentations to Flash**

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/Presentation#save-java.lang.String-int-com.aspose.slides.ISaveOptions-" target="_blank" rel="nofollow noopener noreferrer">save</a> method exposed by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> class can be used to convert the whole presentation into **SWF** document. The following example shows how to convert a presentation into **SWF** document by using options provided by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/SwfOptions" target="_blank" rel="nofollow noopener noreferrer">**SWFOptions**</a> class.You can also include comments in generated SWF using <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ISwfOptions" target="_blank" rel="nofollow noopener noreferrer">**ISWFOptions**</a> class and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/INotesCommentsLayoutingOptions" target="_blank" rel="nofollow noopener noreferrer">**INotesCommentsLayoutingOptions**</a> interface.

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("Sample.pptx");
try {
    NotesCommentsLayoutingOptions layoutingOptions = new NotesCommentsLayoutingOptions();
    layoutingOptions.setNotesPosition(NotesPositions.BottomFull);

    SwfOptions swfOptions = new SwfOptions();
    swfOptions.setViewerIncluded(false);
    swfOptions.setSlidesLayoutOptions(layoutingOptions);

    // Saving presentation
    pres.save("Sample.swf", SaveFormat.Swf, swfOptions);
} finally {
    if (pres != null) pres.dispose();
}
```

## **FAQ**

### Can I include hidden slides in the SWF?

Yes. Enable the hidden slides using the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/#setShowHiddenSlides-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShowHiddenSlides</a> method in <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a>. By default, hidden slides are not exported.

### How can I control compression and the final SWF size?

Use the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/#setCompressed-boolean-" target="_blank" rel="nofollow noopener noreferrer">setCompressed</a> method and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/#setJpegQuality-int-" target="_blank" rel="nofollow noopener noreferrer">adjust JPEG quality</a> to balance file size and image fidelity.

### What is 'setViewerIncluded' for, and when should I disable it?

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/#setViewerIncluded-boolean-" target="_blank" rel="nofollow noopener noreferrer">setViewerIncluded</a> adds an embedded player UI (navigation controls, panels, search). Disable it if you plan to use your own player or need a bare SWF frame without UI.

### What happens if a source font is missing on the export machine?

Aspose.Slides will substitute the font you specify via <a href="https://reference.aspose.com/slides/java/com.aspose.slides/saveoptions/#setDefaultRegularFont-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">setDefaultRegularFont</a> in <a href="https://reference.aspose.com/slides/java/com.aspose.slides/swfoptions/" target="_blank" rel="nofollow noopener noreferrer">SwfOptions</a> to avoid an unintended fallback.

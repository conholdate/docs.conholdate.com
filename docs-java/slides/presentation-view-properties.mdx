## **Introduction**

In PowerPoint's normal view, the slide appears between a side pane for thumbnails or an outline and a notes pane below. Aspose.Slides for Java exposes the presentation's saved editing preferences through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getViewProperties--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getViewProperties</a>. These include the pane layout, zoom levels, grid spacing, and comment visibility.

## **About INormalViewProperties**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#getNormalViewProperties--" target="_blank" rel="nofollow noopener noreferrer">getNormalViewProperties</a> to access the <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/" target="_blank" rel="nofollow noopener noreferrer">INormalViewProperties</a> interface. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setShowOutlineIcons-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShowOutlineIcons</a> controls whether icons appear beside slide titles in the outline. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setSnapVerticalSplitter-boolean-" target="_blank" rel="nofollow noopener noreferrer">setSnapVerticalSplitter</a> lets the side pane snap to its minimized state when the user narrows it. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setPreferSingleView-boolean-" target="_blank" rel="nofollow noopener noreferrer">setPreferSingleView</a> indicates a preference for displaying one pane in the full window.

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setVerticalBarState-int-" target="_blank" rel="nofollow noopener noreferrer">setVerticalBarState</a> controls the divider between the side pane and the slide. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setHorizontalBarState-int-" target="_blank" rel="nofollow noopener noreferrer">setHorizontalBarState</a> controls the divider above the notes pane. Both accept a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/splitterbarstatetype/" target="_blank" rel="nofollow noopener noreferrer">SplitterBarStateType</a> value of `Minimized`, `Maximized`, or `Restored`.

## **About Restoring INormalViewProperties**

When a divider is restored, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#getRestoredLeft--" target="_blank" rel="nofollow noopener noreferrer">getRestoredLeft</a> supplies the saved size of the side pane and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#getRestoredTop--" target="_blank" rel="nofollow noopener noreferrer">getRestoredTop</a> supplies the saved size of the upper slide area. Both expose <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewrestoredproperties/" target="_blank" rel="nofollow noopener noreferrer">INormalViewRestoredProperties</a>. Its <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewrestoredproperties/#setDimensionSize-float-" target="_blank" rel="nofollow noopener noreferrer">setDimensionSize</a> method accepts a percentage from 0 to 100, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewrestoredproperties/#setAutoAdjust-boolean-" target="_blank" rel="nofollow noopener noreferrer">setAutoAdjust</a> controls whether the editor adjusts the size when the window is resized.

This example updates an existing presentation. It restores the horizontal divider, sets the size returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#getRestoredTop--" target="_blank" rel="nofollow noopener noreferrer">getRestoredTop</a> to 80% with automatic adjustment enabled, and maximizes the vertical divider. It also calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/inormalviewproperties/#setShowOutlineIcons-boolean-" target="_blank" rel="nofollow noopener noreferrer">setShowOutlineIcons</a> to display icons in outline view.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("demo.pptx");
try {
    INormalViewProperties normalView = presentation.getViewProperties().getNormalViewProperties();
    normalView.setHorizontalBarState(SplitterBarStateType.Restored);
    normalView.setVerticalBarState(SplitterBarStateType.Maximized);
    normalView.getRestoredTop().setAutoAdjust(true);
    normalView.getRestoredTop().setDimensionSize(80);
    normalView.setShowOutlineIcons(true);

    presentation.save("presentation_normal_view_state.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Set the Default Zoom Value**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#getSlideViewProperties--" target="_blank" rel="nofollow noopener noreferrer">getSlideViewProperties</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#getNotesViewProperties--" target="_blank" rel="nofollow noopener noreferrer">getNotesViewProperties</a> store independent zoom settings for the editor. These settings do not affect slide dimensions, slide-show playback, or image export resolution.

This example opens an existing presentation and calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icommonslideviewproperties/#setVariableScale-boolean-" target="_blank" rel="nofollow noopener noreferrer">setVariableScale</a> to fit the slide to the editing window. For the notes page, it disables automatic scaling and calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/icommonslideviewproperties/#setScale-int-" target="_blank" rel="nofollow noopener noreferrer">setScale</a> to set a fixed 80% zoom.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("demo.pptx");
try {
    IViewProperties viewProperties = presentation.getViewProperties();
    viewProperties.getSlideViewProperties().setVariableScale(true);
    viewProperties.getNotesViewProperties().setVariableScale(false);
    viewProperties.getNotesViewProperties().setScale(80);

    presentation.save("zoom.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

## **Set the Grid Spacing**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#setGridSpacing-float-" target="_blank" rel="nofollow noopener noreferrer">setGridSpacing</a> sets the distance between editing grid lines throughout the presentation. It takes a positive value in points, with 72 points per inch. This example prints the current spacing in an existing presentation and saves a quarter-inch grid by setting the interval to 18 points.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("demo.pptx");
try {
    IViewProperties viewProperties = presentation.getViewProperties();
    System.out.println("Current grid spacing: " + viewProperties.getGridSpacing() + " points");

    viewProperties.setGridSpacing(18f);
    
    presentation.save("grid-spacing.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

The grid repeats at a fixed interval. [Drawing guides](/java/slides/drawing-guides/) mark individual horizontal or vertical positions. Both are editing aids and appear only in editors that display them. Slide shows and exports to PDF, images, or SVG omit them.

## **Show or Hide Comments When Opening a Presentation**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#setShowComments-byte-" target="_blank" rel="nofollow noopener noreferrer">setShowComments</a> stores a preference that compatible editors use when opening the presentation. For an existing presentation with comments, this example prints the current setting and saves a copy with comments hidden. It also calls <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iviewproperties/#setLastView-int-" target="_blank" rel="nofollow noopener noreferrer">setLastView</a> with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/viewtype/#SlideView" target="_blank" rel="nofollow noopener noreferrer">ViewType.SlideView</a> so the copy opens in slide view.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("comments.pptx");
try {
    IViewProperties viewProperties = presentation.getViewProperties();
    System.out.println("Current comment visibility: " + viewProperties.getShowComments());

    viewProperties.setShowComments(NullableBool.False);
    viewProperties.setLastView(ViewType.SlideView);

    presentation.save("comments-hidden.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

Hiding comments preserves their text, authors, positions, replies, and statuses. To change the comments themselves, see [Presentation Comments](/java/slides/presentation-comments/). Export settings control whether comments appear in PDF, HTML, images, notes, or handouts.

## **FAQ**

**Why is the grid hidden when I reopen the presentation?**

The presentation stores the grid interval. To see the grid, enable grid visibility in the editor.

**Does clearing drawing guides change the grid spacing?**

No. Adding, moving, or clearing a guide leaves the grid interval unchanged.

**Can different sections of a presentation have different view settings?**

No. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getViewProperties--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getViewProperties</a> applies to the entire presentation.

**Can I save different view settings for different users?**

The file stores one set of view properties for everyone. An editor may also apply a user's local preferences.

**Can I save view settings in a template?**

Yes. Presentations created from the template inherit its saved view settings.

## **Overview**

Aspose.Slides can identify a presentation's format and read its document metadata without creating a complete presentation object model. This is useful when you need to classify files, build an inventory, or inspect properties before deciding whether to load and process the presentation content.

This article demonstrates lightweight inspection through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo</a>, as well as targeted updates through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/" target="_blank" rel="nofollow noopener noreferrer">IDocumentProperties</a>.

## **Check a Presentation Format**

If you already have a loaded presentation, see [Determine the Original Presentation Format](/java/slides/detect-presentation-source-format/) for detection after loading and the limitations of legacy PPT, PPS, and POT streams.

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> to inspect a file without creating a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> instance. The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#getLoadFormat--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.getLoadFormat</a> method reports the detected format, such as PPTX, PPT, or ODP.

```java
import com.aspose.slides.IPresentationInfo;
import com.aspose.slides.LoadFormat;
import com.aspose.slides.PresentationFactory;

String[] fileNames = { "pres.pptx", "pres.ppt", "pres.odp" };

for (String fileName : fileNames) {
    IPresentationInfo presentationInfo = PresentationFactory.getInstance().getPresentationInfo(fileName);
    int loadFormat = presentationInfo.getLoadFormat();
    String formatName = "Other (" + loadFormat + ")";

    if (loadFormat == LoadFormat.Pptx) {
        formatName = "PPTX";
    } else if (loadFormat == LoadFormat.Ppt) {
        formatName = "PPT";
    } else if (loadFormat == LoadFormat.Odp) {
        formatName = "ODP";
    }

    System.out.println(fileName + ": " + formatName);
}
```

## **Build a Lightweight Presentation Inventory**

When you process many presentation files, you may need a compact inventory for validation, indexing, or a document-management system. In this scenario, use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> to obtain an <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo</a> object, and then call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#readDocumentProperties--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.readDocumentProperties</a> to read the document metadata. This approach does not create a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> instance or require you to traverse the complete presentation object model.

The extended properties exposed by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/" target="_blank" rel="nofollow noopener noreferrer">IDocumentProperties</a> provide the following inventory values:

<div className="docs-owner-markdown-table">

| Method | Inventory value |
| -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">getSlides</a> | Total number of slides. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getHiddenSlides--" target="_blank" rel="nofollow noopener noreferrer">getHiddenSlides</a> | Number of hidden slides. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getNotes--" target="_blank" rel="nofollow noopener noreferrer">getNotes</a> | Number of slides that contain notes. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getParagraphs--" target="_blank" rel="nofollow noopener noreferrer">getParagraphs</a> | Total number of paragraphs, when available. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getWords--" target="_blank" rel="nofollow noopener noreferrer">getWords</a> | Total number of words. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getMultimediaClips--" target="_blank" rel="nofollow noopener noreferrer">getMultimediaClips</a> | Total number of audio and video clips. |

</div>

The following example reads these values without creating a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> object and prints a compact inventory. It also combines <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getHeadingPairs--" target="_blank" rel="nofollow noopener noreferrer">getHeadingPairs</a> with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getTitlesOfParts--" target="_blank" rel="nofollow noopener noreferrer">getTitlesOfParts</a> to display content groups such as fonts, themes, and slide titles.

```java
import com.aspose.slides.IDocumentProperties;
import com.aspose.slides.IHeadingPair;
import com.aspose.slides.IPresentationInfo;
import com.aspose.slides.LoadFormat;
import com.aspose.slides.PresentationFactory;
import java.nio.file.Paths;

String filePath = "sample.pptx";
IPresentationInfo presentationInfo = PresentationFactory.getInstance().getPresentationInfo(filePath);
IDocumentProperties documentProperties = presentationInfo.readDocumentProperties();

int loadFormat = presentationInfo.getLoadFormat();
String formatName = "Other (" + loadFormat + ")";

if (loadFormat == LoadFormat.Pptx) {
    formatName = "PPTX";
} else if (loadFormat == LoadFormat.Ppt) {
    formatName = "PPT";
} else if (loadFormat == LoadFormat.Odp) {
    formatName = "ODP";
}

System.out.println("File: " + Paths.get(filePath).getFileName());
System.out.println("Format: " + formatName);
System.out.println("Title: " + documentProperties.getTitle());
System.out.println("Author: " + documentProperties.getAuthor());
System.out.println("Statistics:");
System.out.println("  Slides: " + documentProperties.getSlides());
System.out.println("  Hidden slides: " + documentProperties.getHiddenSlides());
System.out.println("  Slides with notes: " + documentProperties.getNotes());
System.out.println("  Paragraphs: " + documentProperties.getParagraphs());
System.out.println("  Words: " + documentProperties.getWords());
System.out.println("  Multimedia clips: " + documentProperties.getMultimediaClips());

IHeadingPair[] headingPairs = documentProperties.getHeadingPairs();
String[] titlesOfParts = documentProperties.getTitlesOfParts();
headingPairs = headingPairs != null ? headingPairs : new IHeadingPair[0];
titlesOfParts = titlesOfParts != null ? titlesOfParts : new String[0];
int partIndex = 0;

if (headingPairs.length == 0 || titlesOfParts.length == 0) {
    System.out.println("Content groups: not available");
} else {
    System.out.println("Content groups:");

    for (IHeadingPair headingPair : headingPairs) {
        System.out.println("  " + headingPair.getName() + " (" + headingPair.getCount() + ")");

        for (int partOffset = 0; partOffset < headingPair.getCount() && partIndex < titlesOfParts.length; partOffset++) {
            System.out.println("    - " + titlesOfParts[partIndex]);
            partIndex++;
        }
    }

    if (partIndex < titlesOfParts.length) {
        System.out.println("  Other parts:");

        while (partIndex < titlesOfParts.length) {
            System.out.println("    - " + titlesOfParts[partIndex]);
            partIndex++;
        }
    }
}
```

Each <a href="https://reference.aspose.com/slides/java/com.aspose.slides/iheadingpair/" target="_blank" rel="nofollow noopener noreferrer">IHeadingPair</a> supplies a group name and the number of items in that group. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getTitlesOfParts--" target="_blank" rel="nofollow noopener noreferrer">IDocumentProperties.getTitlesOfParts</a> returns a flat, ordered array, so consume the number of consecutive titles specified by each heading pair.

### **Stored Metadata and Format Limitations**

The inventory properties returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#readDocumentProperties--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.readDocumentProperties</a> reflect metadata available in the source document. Aspose.Slides does not load and traverse the presentation object model to recalculate these values for this call. Missing properties are represented by default values, and stored values may be stale if the application that last saved the file did not update its document properties.

- **PPTX:** The format provides extended document properties for slide, note, hidden-slide, paragraph, word, and multimedia counts, as well as heading pairs and part titles. Availability depends on which properties were written by the document producer.
- **PPT:** The binary format can store corresponding document-summary properties. If a property is absent or was not refreshed by the document producer, Aspose.Slides returns its stored or default value rather than calculating it from the slides.
- **ODP:** OpenDocument metadata provides general document statistics, such as page, paragraph, and word counts, but these values do not map to every PowerPoint-specific extended property. Hidden-slide, notes-slide, multimedia, heading-pair, and part-title metadata may be unavailable, and the inventory properties may return default values. Do not treat a zero value or an empty array as authoritative proof that the corresponding content is absent.

Use the lightweight metadata approach for inventories and preliminary checks. Load the presentation and inspect its live object model when the result must reflect in-memory changes or when you need to verify the actual presentation content.

## **Update Presentation Properties**

The properties returned by <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#readDocumentProperties--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.readDocumentProperties</a> can also be changed without creating a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> instance. Apply the changes with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#updateDocumentProperties-com.aspose.slides.IDocumentProperties-" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.updateDocumentProperties</a>, and then write the bound presentation with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#writeBindedPresentation-java.io.OutputStream-" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.writeBindedPresentation</a>.

The following image shows the original document properties.

![Original document properties of the PowerPoint presentation](/java/slides/images/936441900f6985a7-input_properties.png)

The following example changes the title and last-saved time and writes the result to a new file:

```java
import com.aspose.slides.IDocumentProperties;
import com.aspose.slides.IPresentationInfo;
import com.aspose.slides.PresentationFactory;
import java.io.FileOutputStream;
import java.io.OutputStream;
import java.util.Date;

String sourceFile = "sample.pptx";
String outputFile = "sample_with_updated_properties.pptx";
IPresentationInfo presentationInfo = PresentationFactory.getInstance().getPresentationInfo(sourceFile);
IDocumentProperties documentProperties = presentationInfo.readDocumentProperties();

documentProperties.setTitle("Quarterly sales report");
documentProperties.setLastSavedTime(new Date());

presentationInfo.updateDocumentProperties(documentProperties);
try (OutputStream outputStream = new FileOutputStream(outputFile)) {
    presentationInfo.writeBindedPresentation(outputStream);
}
```

## **FAQ**

**How can I check whether fonts are embedded and which ones they are?**

Load the presentation and use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getFontsManager--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getFontsManager</a>. Call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ifontsmanager/#getEmbeddedFonts--" target="_blank" rel="nofollow noopener noreferrer">IFontsManager.getEmbeddedFonts</a> to obtain the embedded fonts and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ifontsmanager/#getFonts--" target="_blank" rel="nofollow noopener noreferrer">IFontsManager.getFonts</a> to obtain the fonts used by the presentation. Compare the two results to find fonts that are required for rendering but are not embedded.

**How can I quickly tell if the file has hidden slides and how many?**

When stored document metadata is sufficient, read <a href="https://reference.aspose.com/slides/java/com.aspose.slides/idocumentproperties/#getHiddenSlides--" target="_blank" rel="nofollow noopener noreferrer">IDocumentProperties.getHiddenSlides</a> through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentationfactory/#getPresentationInfo-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">PresentationFactory.getPresentationInfo</a> and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ipresentationinfo/#readDocumentProperties--" target="_blank" rel="nofollow noopener noreferrer">IPresentationInfo.readDocumentProperties</a>. This is suitable for a lightweight inventory. If the presentation has been modified in memory, the stored metadata may be missing or stale, or you need to verify live values, iterate through <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSlides</a> and inspect each slide's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islide/#getHidden--" target="_blank" rel="nofollow noopener noreferrer">ISlide.getHidden</a> method instead.

**Can I detect whether custom slide size and orientation are used, and whether they differ from the defaults?**

Yes. Load the presentation and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlideSize--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSlideSize</a>. Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islidesize/#getType--" target="_blank" rel="nofollow noopener noreferrer">ISlideSize.getType</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islidesize/#getSize--" target="_blank" rel="nofollow noopener noreferrer">ISlideSize.getSize</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/islidesize/#getOrientation--" target="_blank" rel="nofollow noopener noreferrer">ISlideSize.getOrientation</a> to compare the current settings with the expected preset and dimensions.

**Is there a quick way to see if charts reference external data sources?**

Yes. Locate each <a href="https://reference.aspose.com/slides/java/com.aspose.slides/chart/" target="_blank" rel="nofollow noopener noreferrer">Chart</a> and call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartdata/#getDataSourceType--" target="_blank" rel="nofollow noopener noreferrer">IChartData.getDataSourceType</a>. For an external workbook, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ichartdata/#getExternalWorkbookPath--" target="_blank" rel="nofollow noopener noreferrer">IChartData.getExternalWorkbookPath</a>. The data source type and path identify an external reference, but verifying whether the target is available requires a separate resource check.

**How can I assess 'heavy' slides that may slow rendering or PDF export?**

There is no single complexity property. Traverse <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#getSlides--" target="_blank" rel="nofollow noopener noreferrer">Presentation.getSlides</a> and each slide's <a href="https://reference.aspose.com/slides/java/com.aspose.slides/ibaseslide/#getShapes--" target="_blank" rel="nofollow noopener noreferrer">IBaseSlide.getShapes</a> collection. Use shape counts and the presence of large images, effects, animations, or multimedia as screening signals, and measure a representative render or export before treating a slide as a confirmed performance bottleneck.

## **Overview**

This section does not contain a list of open issues in the current version. It contains three pages:

- [Object Preview Placeholder When Adding OleObjectFrame](/java/slides/object-preview-issue-when-adding-oleobjectframe/) explains why an OLE object added with Aspose.Slides shows an "EMBEDDED OLE OBJECT" image until its preview is updated, and how to set your own preview image. This is by-design behavior of the current version.
- [Known Issues in Aspose.Slides for Java 14.3.0 (Historical)](/java/slides/known-issues-in-aspose-slides-for-java-14-3-0/) and [Known Issues in Aspose.Slides for Java 14.4.0 (Historical)](/java/slides/known-issues-in-aspose-slides-for-java-14-4-0/) are lists published with those versions, kept for reference.

For the changes and fixes in each version, see the <a href="https://releases.aspose.com/slides/java/release-notes/" target="_blank" rel="nofollow noopener noreferrer">release notes</a>. The metadata fields that Aspose.Slides writes with fixed values are described in [Output Metadata Limitations](/java/slides/api-limitations/). To check whether a problem is already known, or to report one, use the <a href="https://forum.conholdate.com/" target="_blank">support forum</a>.

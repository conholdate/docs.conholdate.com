> Use the Aspose.Slides low-code API in Java to convert and merge presentations, iterate through content, collect shapes, and reduce presentation size.

## **Overview**

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/" target="_blank" rel="nofollow noopener noreferrer">com.aspose.slides</a> package provides static helper classes for common presentation operations. These helpers wrap frequently used object-model workflows in focused methods, so you can convert or merge files, process presentation elements, collect shapes, and remove unused content with less code.

Low-code helpers are most useful when the operation applies to an entire file or presentation and the default workflow matches your requirements. Use the full <a href="https://reference.aspose.com/slides/java/com.aspose.slides/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Slides object model</a> when you need fine-grained control over individual slides, masters, layouts, shapes, export settings, or relationships between presentation elements.

The following table summarizes the available helpers:

<div className="docs-owner-markdown-table">

| Helper | Use it for |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert</a> | Converting a presentation to another format with a direct file-to-file call. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/merger/" target="_blank" rel="nofollow noopener noreferrer">Merger</a> | Combining complete presentation files of the same format. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> | Running an action for every slide, shape, paragraph, or text portion. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/collect/" target="_blank" rel="nofollow noopener noreferrer">Collect</a> | Retrieving shapes from the entire presentation for repeated processing or analysis. |
| <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> | Removing unused masters and layouts and reducing embedded font data. |

## **Convert a Presentation**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/convert/#autoByExtension-java.lang.String-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Convert.autoByExtension</a> when the output file extension is sufficient to select the export format. The method opens the source presentation, determines the required format from the output path, and writes the result.

```java
import com.aspose.slides.Convert;

Convert.autoByExtension("input.pptx", "output.pdf");
```

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/convert/" target="_blank" rel="nofollow noopener noreferrer">Convert</a> class also provides dedicated methods for PDF, SVG, JPEG, PNG, and TIFF output. Use the full object model when you need to inspect or modify the presentation before export or configure an export option that is not exposed by the selected helper. See [Convert Presentation](/java/slides/convert-presentation/) for format-specific workflows and options.

## **Merge Presentations**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/merger/#process-java.lang.String:A-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Merger.process</a> to combine complete presentation files with one call. The input presentations must have the same file format.

```java
import com.aspose.slides.Merger;

String[] inputFiles = { "part-1.pptx", "part-2.pptx" };
Merger.process(inputFiles, "merged.pptx");
```

The helper is appropriate when all slides should be appended to one result without selecting or remapping them individually. Use the full object model when you need to merge selected slides, apply a destination master or layout, preserve sections explicitly, or reconcile different slide sizes. See [Merge Presentations](/java/slides/merge-presentation/) for those scenarios.

## **Iterate Through Presentation Elements**

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> class invokes a callback for each requested type of presentation element. It avoids nested collection loops and is convenient for presentation-wide inspection or formatting changes.

The following example uses <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#slide-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachSlideCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.slide</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#shape-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachShapeCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.shape</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#paragraph-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachParagraphCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.paragraph</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#portion-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachPortionCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.portion</a> to inspect the corresponding elements:

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    ForEach.slide(presentation, (slide, index) -> {
        System.out.println(String.format("Slide %d: %d shapes", index, slide.getShapes().size()));
    });

    ForEach.shape(presentation, (shape, slide, index) -> {
        System.out.println(String.format("Shape %d on %s: %s", index, slide.getClass().getSimpleName(), shape.getName()));
    });

    ForEach.paragraph(presentation, (paragraph, slide, index) -> {
        System.out.println(String.format("Paragraph %d on %s: %s", index, slide.getClass().getSimpleName(), paragraph.getText()));
    });

    ForEach.portion(presentation, (portion, paragraph, slide, index) -> {
        System.out.println(String.format("Portion %d on %s: %s", index, slide.getClass().getSimpleName(), portion.getText()));
    });
} finally {
    presentation.dispose();
}
```

By default, presentation-wide shape and text traversal includes normal, master, and layout slides. Overloads with an `includeNotes` parameter can also process notes slides. Use direct collection loops when traversal order, early exit, filtering before callback invocation, or detailed parent-child control is important.

## **Collect Shapes**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/collect/#shapes-com.aspose.slides.Presentation-" target="_blank" rel="nofollow noopener noreferrer">Collect.shapes</a> when you need a collection of all shapes in a presentation rather than a callback for each shape. This is useful when the same set will be filtered, counted, or processed more than once.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    Iterable<Shape> shapes = Collect.shapes(presentation);

    for (Shape shape : shapes) {
        System.out.println(String.format("%s: %s", shape.getName(), shape.getClass().getSimpleName()));
    }
} finally {
    presentation.dispose();
}
```

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#shape-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachShapeCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.shape</a> instead when each shape can be handled immediately and you do not need to retain the collected result.

## **Compress Presentation Content**

The <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> class can remove unused structural elements and reduce embedded font data:

- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/#removeUnusedLayoutSlides-com.aspose.slides.Presentation-" target="_blank" rel="nofollow noopener noreferrer">Compress.removeUnusedLayoutSlides</a> removes layout slides that no normal slide references.
- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/#removeUnusedMasterSlides-com.aspose.slides.Presentation-" target="_blank" rel="nofollow noopener noreferrer">Compress.removeUnusedMasterSlides</a> removes master slides that are no longer used.
- <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/#compressEmbeddedFonts-com.aspose.slides.Presentation-" target="_blank" rel="nofollow noopener noreferrer">Compress.compressEmbeddedFonts</a> removes unused characters from embedded fonts.

```java
import com.aspose.slides.*;

Presentation presentation = new Presentation("input.pptx");
try {
    Compress.removeUnusedLayoutSlides(presentation);
    Compress.removeUnusedMasterSlides(presentation);
    Compress.compressEmbeddedFonts(presentation);

    presentation.save("compressed.pptx", SaveFormat.Pptx);
} finally {
    presentation.dispose();
}
```

Remove unused layouts before unused masters so a master that becomes unreferenced after layout cleanup can also be removed. Save the optimized presentation to a new file if you may need the original masters, layouts, or complete embedded font data later. For more detail, see [Slide Master](/java/slides/slide-master/) and [Embedded Font](/java/slides/embedded-font/).

## **FAQ**

**When should I use the low-code API instead of the full object model?**

Use low-code helpers when a standard operation applies to a complete file or presentation and does not require detailed control over individual elements. Use the full object model when you need to select specific slides, control master and layout relationships, inspect intermediate state, or configure behavior that the helper does not expose.

**Can Merger combine presentations in different file formats?**

No. <a href="https://reference.aspose.com/slides/java/com.aspose.slides/merger/#process-java.lang.String:A-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Merger.process</a> requires input presentations in the same format. Convert the input files to a common format first, for example with <a href="https://reference.aspose.com/slides/java/com.aspose.slides/convert/#autoByExtension-java.lang.String-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Convert.autoByExtension</a>, and then merge the converted files.

**Does ForEach process master, layout, and notes slides?**

<a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#slide-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachSlideCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.slide</a> iterates through normal presentation slides. Presentation-wide <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#shape-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachShapeCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.shape</a>, <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#paragraph-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachParagraphCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.paragraph</a>, and <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#portion-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachPortionCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.portion</a> operations include normal, master, and layout slides by default. Use their overloads with `includeNotes` set to `true` to include notes slides.

**What is the difference between ForEach.shape and Collect.shapes?**

Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/#shape-com.aspose.slides.Presentation-com.aspose.slides.ForEach.ForEachShapeCallback-" target="_blank" rel="nofollow noopener noreferrer">ForEach.shape</a> to process each shape immediately through a callback. Use <a href="https://reference.aspose.com/slides/java/com.aspose.slides/collect/#shapes-com.aspose.slides.Presentation-" target="_blank" rel="nofollow noopener noreferrer">Collect.shapes</a> when you need an iterable result that can be retained, filtered, counted, or traversed multiple times.

**Does Compress always make the presentation file smaller?**

Not necessarily. The result depends on whether the presentation contains unused layouts, unused masters, or embedded fonts with unused characters. If none of those are present, the corresponding <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a> operations may not reduce the file size.

**Are changes made by ForEach or Compress saved automatically?**

No. These helpers operate on the loaded <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/" target="_blank" rel="nofollow noopener noreferrer">Presentation</a> object in memory. After changing elements in a <a href="https://reference.aspose.com/slides/java/com.aspose.slides/foreach/" target="_blank" rel="nofollow noopener noreferrer">ForEach</a> callback or running <a href="https://reference.aspose.com/slides/java/com.aspose.slides/compress/" target="_blank" rel="nofollow noopener noreferrer">Compress</a>, call <a href="https://reference.aspose.com/slides/java/com.aspose.slides/presentation/#save-java.lang.String-int-" target="_blank" rel="nofollow noopener noreferrer">Presentation.save</a> to write the result.

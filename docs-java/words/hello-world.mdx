A "Hello, World!" code is often the first simple example to write uisng "Aspose.Words for Java", and it can also be used as a sanity test to ensure the software intended to compile or run source code is correctly installed.

"Aspose.Words for Java" library gives developers direct access to create, modify, merge, convert, compare Word and Web documents. PDF, DOCX, DOC, RTF, ODT, EPUB, HTML and many other file formats are [supported](/java/words/supported-document-formats/).

Below code snippet follows these steps:

1. Create a new empty <a href="https://reference.aspose.com/words/java/com.aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a>
2. Initialize a <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> class
3. Insert text to the document start using simple <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/#write-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Write</a> method
4. Open an existing <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#Document-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Document</a> from a file. Automatically detects the file format
5. <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#appendDocument-com.aspose.words.Document-int" target="_blank" rel="nofollow noopener noreferrer">Append</a> document "A" to the and of the document "B"
6. <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#save-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">Save</a> the output as PDF

The following code snippet is a "Hello, World!" example to exhibit working of "Aspose.Words for Java" API:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document docA = new Document();
DocumentBuilder builder = new DocumentBuilder(docA);

// Insert text to the document start.
builder.moveToDocumentStart();
builder.write("First Hello World paragraph");

Document docB = new Document(getMyDir() + "Document.docx");
// Add document B to the and of document A, preserving document B formatting.
docA.appendDocument(docB, ImportFormatMode.KEEP_SOURCE_FORMATTING);

docA.save(getArtifactsDir() + "HelloWorld.SimpleHelloWorld.pdf");
```

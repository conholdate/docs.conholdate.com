As already described in previous articles, there are operations with documents that are faster and more conveniently to perform using Aspose.Words than Open XML SDK. But there are also operations that are not provided by OpenXML. You can try to achieve the desired result using auxiliary tools and options, but even if successful, it will be quite expensive.

The following table contains some of the popular features supported by Aspose.Words and missed in Open XML SDK:

<div className="docs-owner-markdown-table">

| Aspose.Words feature | Corresponding documentation article or section |
| ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Convert between different document formats. For example, Word to PDF,  HTML to Markdown, DOCX to JPG, PDF to Word, Image to PDF, and others | The <a href="https://docs.aspose.com/words/java/convert-a-document/" target="_blank" rel="nofollow noopener noreferrer">Convert a Document</a> section |
| Mail Merge | The <a href="https://docs.aspose.com/words/java/mail-merge-and-reporting/" target="_blank" rel="nofollow noopener noreferrer">Mail Merge and Reporting</a> section |
| Rendering | The <a href="https://docs.aspose.com/words/java/rendering/" target="_blank" rel="nofollow noopener noreferrer">Rendering in Aspose.Words</a> section |
| Print a document | The <a href="https://docs.aspose.com/words/java/print-a-document-programmatically-or-using-dialogs/" target="_blank" rel="nofollow noopener noreferrer">Printing a Document Programmatically or Using Dialogs</a> article |
| Join multiple documents, including combine formatting of documents when importing content | The <a href="https://docs.aspose.com/words/java/insert-and-append-documents/" target="_blank" rel="nofollow noopener noreferrer">Insert and Append Documents</a> article |
| Find and Replace | The <a href="https://docs.aspose.com/words/java/find-and-replace/" target="_blank" rel="nofollow noopener noreferrer">Find and Replace</a> article |
| Updating fields | The <a href="https://docs.aspose.com/words/java/working-with-fields/" target="_blank" rel="nofollow noopener noreferrer">Working with Fields</a> section |
| Manage a Table of Content (TOC) | The <a href="https://docs.aspose.com/words/java/working-with-table-of-contents/" target="_blank" rel="nofollow noopener noreferrer">Working with Table of Contents</a> article |
| Manipulate form fields | The <a href="https://docs.aspose.com/words/java/working-with-form-fields/" target="_blank" rel="nofollow noopener noreferrer">Working with Form Fields</a> article |
| Manipulate tables | The <a href="https://docs.aspose.com/words/java/working-with-tables/" target="_blank" rel="nofollow noopener noreferrer">Working with Tables</a> section |

</div>

The table is not complete, so you can check <a href="https://docs.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">our documentation</a> for the feature you are interested in.

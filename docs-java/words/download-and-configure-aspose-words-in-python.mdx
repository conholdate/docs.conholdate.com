## How to configure the source code

Please follow these simple steps in order to open and extend the source code while using:

1. Install only Python 3.x.x.x from: <a href="https://www.python.org/downloads/" target="_blank" rel="nofollow noopener noreferrer">https://www.python.org/downloads/</a>
2. Install JPype from: <a href="https://pypi.org/project/JPype1/" target="_blank" rel="nofollow noopener noreferrer">https://pypi.org/project/JPype1/</a>
3. Install Java JDK from: <a href="https://www.oracle.com/java/technologies/downloads/" target="_blank" rel="nofollow noopener noreferrer">https://www.oracle.com/java/technologies/downloads/</a>
4. Download Aspose.Words for Java APIs you want to use in your python projects from: <a href="https://downloads.aspose.com/words/java" target="_blank" rel="nofollow noopener noreferrer">https://downloads.aspose.com/words/java</a> and copy downloaded APIs's .jars into %Python%/lib folder.
5. Clone <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Plugins/Aspose_Words_Java_for_Python" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words Java for Python Examples</a> from github.

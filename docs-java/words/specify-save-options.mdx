## Purpose Summary {#purpose-summary}

This page explains how to specify save options for different output formats.
:::

When saving a document, you can set some advanced properties. Aspose.Words provides you with the <a href="https://reference.aspose.com/words/java/com.aspose.words/saveoptions/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a> class, which allows more precise control of the save process. There are overloads of the **Save** method that accept a **SaveOptions** object - it should be an object of a class derived from the **SaveOptions** class. Each save format has a corresponding class that holds save options for this save format, for example, there is <a href="https://reference.aspose.com/words/java/com.aspose.words/pdfsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">PdfSaveOptions</a> for saving to PDF format, <a href="https://reference.aspose.com/words/java/com.aspose.words/markdownsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">MarkdownSaveOptions</a> for saving to Markdown format, or <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> for saving to an image. This article provides examples of working with some options classes derived from **SaveOptions**.

The following code example shows how to set the save options before saving the document into HTML:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");

File imagesDir = new File(Paths.get(getArtifactsDir(), "Images").toString());

// The folder specified needs to exist and should be empty.
if (imagesDir.exists())
    imagesDir.delete();

imagesDir.mkdir();

// Set an option to export form fields as plain text, not as HTML input elements.
HtmlSaveOptions saveOptions = new HtmlSaveOptions(SaveFormat.HTML);
saveOptions.setExportTextInputFormFieldAsText(true);
saveOptions.setImagesFolder(imagesDir.getPath());

doc.save(getArtifactsDir() + "WorkingWithHtmlSaveOptions.ExportTextInputFormFieldAsText.html", saveOptions);
```

:::info
You can download the template file of this example from <a href="https://github.com/aspose-words/Aspose.Words-for-Java/blob/master/Examples/Data/Rendering.docx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words GitHub</a>.
:::

The article describes a few properties you can control when saving a document.

## Encrypt a Document With a Password {#encrypt-a-document-with-a-password}

Use the **Password** property to get or set a password for an encrypted document. Use the **Password** property of the corresponding class to work with the selected document format.

For example, when saving a document to DOC or DOT format, use the <a href="https://reference.aspose.com/words/java/com.aspose.words/docsaveoptions/#getPassword" target="_blank" rel="nofollow noopener noreferrer">getPassword()</a> property of the <a href="https://reference.aspose.com/words/java/com.aspose.words/docsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">DocSaveOptions</a> class.

The following code example shows how to set a password to encrypt a document using the RC4 encryption method:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);

builder.write("Hello world!");

DocSaveOptions saveOptions = new DocSaveOptions();
saveOptions.setPassword("password");

doc.save(getArtifactsDir() + "WorkingWithDocSaveOptions.EncryptDocumentWithPassword.docx", saveOptions);
```

When saving a document to ODT format, use the <a href="https://reference.aspose.com/words/java/com.aspose.words/odtsaveoptions/#getPassword" target="_blank" rel="nofollow noopener noreferrer">getPassword()</a> property of the <a href="https://reference.aspose.com/words/java/com.aspose.words/odtsaveoptions/" target="_blank" rel="nofollow noopener noreferrer">OdtSaveOptions</a> class.

The following code example shows how to load and save OpenDocument encrypted with a password:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Encrypted.docx", new LoadOptions("docPassword"));

doc.save(getArtifactsDir() + "WorkingWithLoadOptions.LoadAndSaveEncryptedOdt.odt", new OdtSaveOptions("newPassword"));
```

Not all formats support encryption and the use of **Password** property.

## Show Document Saving Progress Notifications {#show-document-saving-progress-notifications}

Aspose.Words provides the ability to use the <a href="https://reference.aspose.com/words/java/com.aspose.words/saveoptions/#getProgressCallback" target="_blank" rel="nofollow noopener noreferrer">getProgressCallback()</a> property to get notifications about the progress of document saving.

It is now available when saving to DOCX, FlatOpc, DOCM, DOTM, DOTX, HTML, MHTML, EPUB, XamlFlow, XamlFlowPack, or TXT formats.

## Update the Document Creation Time {#update-the-document-creation-time}

Aspose.Words provides an ability to use the <a href="https://reference.aspose.com/words/java/com.aspose.words/builtindocumentproperties/#getCreatedTime" target="_blank" rel="nofollow noopener noreferrer">getCreatedTime()</a> property to get or set the document creation date in UTC. You can also update this value before saving using the <a href="https://reference.aspose.com/words/java/com.aspose.words/saveoptions/#getUpdateCreatedTimeProperty" target="_blank" rel="nofollow noopener noreferrer">getUpdateCreatedTimeProperty()</a> option.

The following code example shows how to update the document creation time:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");

PdfSaveOptions saveOptions = new PdfSaveOptions();
saveOptions.setUpdateLastPrintedProperty(true);

doc.save(getArtifactsDir() + "WorkingWithPdfSaveOptions.UpdateLastPrinted.pdf", saveOptions);
```

## Update Last Saved Property {#update-last-saved-property}

Aspose.Words provides an ability to use the <a href="https://reference.aspose.com/words/java/com.aspose.words/saveoptions/#getUpdateLastSavedTimeProperty" target="_blank" rel="nofollow noopener noreferrer">getUpdateLastSavedTimeProperty()</a> property to get or set a value determining whether the <a href="https://reference.aspose.com/words/java/com.aspose.words/builtindocumentproperties/#getLastSavedTime" target="_blank" rel="nofollow noopener noreferrer">getLastSavedTime()</a> property is updated before saving.

The following code example shows how to set this property and save the document:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Document.docx");

OoxmlSaveOptions saveOptions = new OoxmlSaveOptions();
saveOptions.setUpdateLastSavedTimeProperty(true);

doc.save(getArtifactsDir() + "WorkingWithOoxmlSaveOptions.UpdateLastSavedTime.docx", saveOptions);
```

## Control External Resources When Saving a Document into HTML or SVG {#control-external-resources-when-saving-a-document-into-html-or-svg}

To convert HTML or SVG into PDF, simply invoke the <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#save-java.lang.String" target="_blank" rel="nofollow noopener noreferrer">save()</a> method and specify a file name with the ".PDF" extension. If you want to load images, CSS, etc. from external sources, you can use <a href="https://reference.aspose.com/words/java/com.aspose.words/iresourcesavingcallback/" target="_blank" rel="nofollow noopener noreferrer">IResourceSavingCallback</a>.

## Save Black and White Image with One Bit Per Pixel Format {#save-black-and-white-image-with-one-bit-per-pixel-format}

To control image saving options, the **ImageSaveOptions** class is used. For example, you can use the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPixelFormat" target="_blank" rel="nofollow noopener noreferrer">getPixelFormat()</a> property to set the pixel format for the generated images. Please note that the pixel format of the output image may differ from the set value because of the work of GDI+.

The following code example shows how to save a black and white image with one bit per pixel format:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");

ImageSaveOptions saveOptions = new ImageSaveOptions(SaveFormat.PNG);
saveOptions.setPageSet(new PageSet(1));
saveOptions.setImageColorMode(ImageColorMode.BLACK_AND_WHITE);
saveOptions.setPixelFormat(ImagePixelFormat.FORMAT_1_BPP_INDEXED);

doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.Format1BppIndexed.Png", saveOptions);
```

## FAQ {#faq}

1. **Q:** How can I encrypt a saved document with a password in Java?\
   **A:** Use the save options class of the target format: call `setPassword(String)` on `DocSaveOptions`, `OoxmlSaveOptions`, or `OdtSaveOptions`; for PDF, call `PdfSaveOptions.setEncryptionDetails(new PdfEncryptionDetails(userPassword, ownerPassword))`. Then pass the options object to `Document.save(String, SaveOptions)`. The encryption method (RC4, AES) is chosen automatically based on the format.

2. **Q:** Is there a way to receive progress updates while a large document is being saved?\
   **A:** Yes, for some formats. Implement the `IDocumentSavingCallback` interface and pass an instance to `setProgressCallback` of the `SaveOptions`. Aspose.Words calls its `notify(DocumentSavingArgs args)` method during saving, and `args.getEstimatedProgress()` returns the percentage completed. Progress is reported when saving to DOCX, FLAT_OPC, DOCM, DOTM, DOTX, DOC, DOT, HTML, MHTML, EPUB, XAML_FLOW, and XAML_FLOW_PACK, but not to PDF.

3. **Q:** How do I change the document's creation time before saving?\
   **A:** Set the `getCreatedTime()` property of the `BuiltInDocumentProperties` object (`document.getBuiltInDocumentProperties().setCreatedTime(Date)`). To make the saved file reflect this value, enable `setUpdateCreatedTimeProperty(true)` on the `SaveOptions`.

4. **Q:** Can I prevent the `getLastSavedTime()` property from being updated when I save a document?\
   **A:** Yes. Set `setUpdateLastSavedTimeProperty(false)` on the `SaveOptions` you pass to `Document.save`. This tells Aspose.Words to keep the existing `getLastSavedTime()` value.

5. **Q:** How can I save images generated from a document as black‑and‑white (1‑bit) PNGs?\
   **A:** Use `ImageSaveOptions` and call `setPixelFormat(ImagePixelFormat.FORMAT_1_BPP_INDEXED)`. Then call `document.save("output.png", imageSaveOptions)`. The resulting PNG will be a 1‑bit per pixel black‑and‑white image.

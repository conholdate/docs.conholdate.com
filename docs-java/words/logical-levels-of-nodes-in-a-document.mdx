## Purpose Summary {#purpose-summary}

This page explains the logical levels of document nodes and describes how Aspose.Words structures content internally.
:::

This documentation sometimes refers to a group of node classes as belonging to a "level" in a document, such as "block-level", "inline-level" (also known as "inline"), or "row-level" nodes. These levels in a document are differentiated purely logically and are not explicitly expressed by inheritance or other Aspose.Words DOM means. The node level is used to describe the place in the document tree where the node would typically occur.

In the previous article, we already talked about the relationship between nodes and the fact that not all nodes are allowed to be a child of any nodes. For example, Cell can only be a Row child, and a Row can only be a Table child, and so on. These relationships are also applicable for logical division of nodes into levels in the document.

The following sections describe the logical levels of nodes in Aspose.Words and the classes that belong to each level.

## Document and Section Logical Level {#document-and-section-logical-level}

A Word document consists of one or more sections, represented by the <a href="https://reference.aspose.com/words/java/com.aspose.words/section/" target="_blank" rel="nofollow noopener noreferrer">Section</a> class and separated by section breaks. A section can define its own page size, margins, orientation, number of text columns, and headers and footers.

<a href="https://reference.aspose.com/words/java/com.aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/section/" target="_blank" rel="nofollow noopener noreferrer">Section</a> level nodes have the structure as shown in the following diagram.

![document-and-section-level-aspose-words-java](/java/words/images/1ea5c29abe22430e-document-and-section-level.png)

A section contains the main text, as well as headers and footers for the first, even, and odd pages. These different "flows" of text are called *stories*.

In Aspose.Words, the **Section** node contains the <a href="https://reference.aspose.com/words/java/com.aspose.words/body/" target="_blank" rel="nofollow noopener noreferrer">Body</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/headerfooter/" target="_blank" rel="nofollow noopener noreferrer">HeaderFooter</a> story nodes. The **Body** object stores the main text. The **HeaderFooter** objects store the text for each header and footer. The text of any story consists of paragraphs and tables, respectively represented by the **Paragraph** and **Table** objects of the Block-level.

Additionally, each Word document can contain a glossary, which is represented by the <a href="https://reference.aspose.com/words/java/com.aspose.words/glossarydocument/" target="_blank" rel="nofollow noopener noreferrer">GlossaryDocument</a> node in Aspose.Words. A glossary document contains <a href="https://reference.aspose.com/words/java/com.aspose.words/buildingblock/" target="_blank" rel="nofollow noopener noreferrer">BuildingBlocks</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/buildingblocktype/#AUTO-TEXT" target="_blank" rel="nofollow noopener noreferrer">AutoText</a>, and <a href="https://reference.aspose.com/words/java/com.aspose.words/buildingblocktype/#AUTO-CORRECT" target="_blank" rel="nofollow noopener noreferrer">AutoCorrect</a> entries.

**GlossaryDocument** includes <a href="https://reference.aspose.com/words/java/com.aspose.words/buildingblock/" target="_blank" rel="nofollow noopener noreferrer">BuildingBlock</a> nodes representing different types of glossary document entries. Each **BuildingBlock** contains sections that can be inserted, removed, and copied into documents.

## Block Logical Level {#block-logical-level}

Block-level nodes represent containers for content and content controls, and can occur in the document tree child nodes in the following nodes:

- Body
- Header
- Footer
- Footnote
- Comment
- Shape
- GroupShape
- Cell
- StructuredDocumentTag

Block-level nodes are represented by the following classes:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/" target="_blank" rel="nofollow noopener noreferrer">Tables</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/paragraph/" target="_blank" rel="nofollow noopener noreferrer">Paragraphs</a>, which are the most important block-level nodes
- Bookmarks, which occurs both at the block-level and at the inline-level
- <a href="https://reference.aspose.com/words/java/com.aspose.words/structureddocumenttag/" target="_blank" rel="nofollow noopener noreferrer">StructuredDocumentTag</a>, which represent custom markup and can contain both content and content controls

The following diagram shows block-level elements.

![block-level-aspose-words-java](/java/words/images/c40df5a042609489-block-level.png)

## Inline Logical Level {#inline-logical-level}

Inline-level nodes represent the actual content of the document and can be contained in the following containers:

- Paragraph - the most common container
- <a href="https://reference.aspose.com/words/java/com.aspose.words/smarttag/" target="_blank" rel="nofollow noopener noreferrer">SmartTag</a>
- StructuredDocumentTag

Inline-level elements are represented by the following classes:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/run/" target="_blank" rel="nofollow noopener noreferrer">Run</a> - runs of text formatted differently
- <a href="https://reference.aspose.com/words/java/com.aspose.words/bookmarkstart/" target="_blank" rel="nofollow noopener noreferrer">BookmarkStart</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/bookmarkend/" target="_blank" rel="nofollow noopener noreferrer">BookmarkEnd</a> represent bookmarks
- <a href="https://reference.aspose.com/words/java/com.aspose.words/commentrangeend/" target="_blank" rel="nofollow noopener noreferrer">CommentRangeEnd</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/comment/" target="_blank" rel="nofollow noopener noreferrer">Comment</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/footnote/" target="_blank" rel="nofollow noopener noreferrer">Footnote</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/fieldstart/" target="_blank" rel="nofollow noopener noreferrer">FieldStart</a> represent annotations
- <a href="https://reference.aspose.com/words/java/com.aspose.words/fieldchar/" target="_blank" rel="nofollow noopener noreferrer">FieldChar</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/fieldseparator/" target="_blank" rel="nofollow noopener noreferrer">FieldSeparator</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/fieldend/" target="_blank" rel="nofollow noopener noreferrer">FieldEnd</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/formfield/" target="_blank" rel="nofollow noopener noreferrer">FormField</a> that represent field characters, and <a href="https://reference.aspose.com/words/java/com.aspose.words/specialchar/" target="_blank" rel="nofollow noopener noreferrer">SpecialChar</a> represent Word fields
- <a href="https://reference.aspose.com/words/java/com.aspose.words/shape/" target="_blank" rel="nofollow noopener noreferrer">Shape</a> represents special characters in the document
- <a href="https://reference.aspose.com/words/java/com.aspose.words/groupshape/" target="_blank" rel="nofollow noopener noreferrer">GroupShape</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/groupshape/" target="_blank" rel="nofollow noopener noreferrer">GroupShape</a> represent shapes, drawings, images, etc.
- SmartTag and StructuredDocumentTag represent custom markup

The following diagram shows the inline-level nodes structure.

![inline-level-aspose-words-java](/java/words/images/a697d3090ee9812e-inline-level.png)

:::info
Shapes in Microsoft Word include Office Art AutoShapes, text boxes, images, OLE objects, and ActiveX controls, all of which are represented using the `Shape` class. Some shapes can also contain text, so Shape nodes in Aspose.Words can contain block-level nodes.

Shapes can be grouped inside each other using GroupShape nodes.
:::

:::info
Footnotes and comments can contain text, therefore Footnote and Comment nodes in Aspose.Words can contain block-level nodes.
:::

## Table, Row, and Cell Node Level {#table-row-and-cell-node-level}

The table consists of nodes of rows and cells. Table elements are represented by the following classes:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/row/" target="_blank" rel="nofollow noopener noreferrer">Row</a> represents a table row
- <a href="https://reference.aspose.com/words/java/com.aspose.words/cell/" target="_blank" rel="nofollow noopener noreferrer">Cell</a> represents a table cell
- StructuredDocumentTag represent custom markup

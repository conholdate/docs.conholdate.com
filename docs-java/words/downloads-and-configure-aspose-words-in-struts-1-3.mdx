## Downloading Aspose.Words Java for Struts 1.3

You can download/check out the project source codes from the following locations:

- <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Plugins/Aspose_Words_for_Struts" target="_blank" rel="nofollow noopener noreferrer">Github</a>

## Building Aspose.Words Java for Struts 1.3 from Source Codes

After checking out source codes from any of the above repositories, apply the following mvn commands:

```bash
$ mvn -U clean package 
```

This will build "Strutsbookapp.war" in the target folder.

To deploy the .war file just copy it to the running Apache tomcat server web app directory.

After [deploying the web application](/java/words/installation/).

1. Navigate to: `localhost:8080/StrutsbookApp/`
   You will come up with the following web page:
   ![build-aspose-words-java-for-struts-1](/java/words/images/cd73451fd1940f68-download-aspose-words-in-struts-1.jpeg)
2. You can add/edit or delete books from here by selecting from book's list.
   Click on "AddBook" button, which will show you the below web page:
   ![build-aspose-words-java-for-struts-2](/java/words/images/6a24675f0311aa67-download-aspose-words-in-struts-2.jpeg)
3. Add a new book name and Click "SaveBook", you will be navigated to the main book's list page as below:
   ![build-aspose-words-java-for-struts-3](/java/words/images/98befb3dfbe4fb7c-download-aspose-words-in-struts-3.jpeg)
4. Click on "ExportToWord" button on the right bottom to export / save the Book's list to MS-Word document file:
   ![build-aspose-words-java-for-struts-4](/java/words/images/2883f0eac267de62-download-aspose-words-in-struts-4.jpeg)
5. Below screen shows the saved /exported MS-Word document:
   ![build-aspose-words-java-for-struts-5](/java/words/images/ca941d03eb928946-download-aspose-words-in-struts-5.jpeg)

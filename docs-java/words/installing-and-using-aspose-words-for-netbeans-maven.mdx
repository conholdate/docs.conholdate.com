## Installing {#installing}

**Aspose.Words Java for NetBeans (Maven)** plugin can be easily installed from the Available **Plugin** tab in the Plugin dialog.

- To open it, select **Plugins** from the **Tools** menu in NetBeans.

![aspose-words-java-for-netbeans-1](/java/words/images/02aab48dd02e61fa-aspose-words-java-for-netbeans-1.jpeg)

- This adds the **Aspose.Words Maven Project** in New Project wizard and **Aspose.Words Code Example** in New File wizard of NetBeans IDE.

![aspose-words-java-for-netbeans-2](/java/words/images/2f4f97d78d9aae77-aspose-words-java-for-netbeans-2.jpeg)

## Using {#using}

### Aspose.Words Maven Project (wizard) {#asposewords-maven-project-wizard}

To create **Maven Project** by wizard for using <a href="https://reference.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a>:

1. Select **New Project**.
2. Select **Aspose.Words Maven Project** in the **Maven** category.
3. Click **Next**.\
   ![aspose-words-java-for-netbeans-3](/java/words/images/2f4f97d78d9aae77-aspose-words-java-for-netbeans-3.jpeg)
4. Provide **Project Name, Location, GroupId, ArtifactId** and **Version** for your Maven Project and click **Finish.**\
   ![aspose-words-java-for-netbeans-4](/java/words/images/2c6bf2da5353f178-aspose-words-java-for-netbeans-4.jpeg)
5. This will retrieve the <a href="https://products.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java</a> latest Maven Dependency reference from <a href="https://releases.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose Cloud Maven Repository</a> and configure it in **pom.xml**. If you have opted for **Also Download Code Examples,** downloading of the **Code Examples** will also begin from the <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API Examples Repository.</a>
6. Following **Maven** Project will be created on your **NetBeans IDE** on completion of the wizard:\
   ![aspose-words-java-for-netbeans-5](/java/words/images/bbd1390f65272c12-aspose-words-java-for-netbeans-5.jpeg)
7. The created **Maven Project** is configured to use **Aspose.Words for Java API** and ready to be enhanced as per your Project requirements.\
   If you have opted to download <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Code Examples</a>, you can use **Aspose.Words Code Example (wizard)** for importing needed **Code Examples** of Aspose.Words for Java API into your project.

### Aspose.Words Code Example (wizard) {#asposewords-code-example-wizard}

**Aspose.Words Code Example wizard** allows you to try out many samples provided for Aspose.Words for Java API.

:::info
To be able to use **Aspose.Words Code Example wizard** comfortably: it is recommended to always select **Also Download Code Examples** while creating **Maven Project** on **Aspose.Words Maven Project** **wizard**,
:::

To use examples, just:

1. Click **New File** in **NetBeans**.
2. Choose your project and then select **Aspose.Words Code Example** in the **Java** category.
3. Click **Next**.\
   ![aspose-words-java-for-netbeans-6](/java/words/images/4c4aa4835f433e82-aspose-words-java-for-netbeans-6.jpeg)
4. Expand the tree to select **Code Example** category and click **Finish**.\
   ![aspose-words-java-for-netbeans-7](/java/words/images/04e14af314972ba4-aspose-words-java-for-netbeans-7.jpeg)
5. This will copy the selected category **Code Examples** Java files into the project under **com.aspose.words.examples** package. Also any required resources needed by the Code Examples will be copied into **src/main/resources** folder, as shown below:\
   ![aspose-words-java-for-netbeans-8](/java/words/images/5a1485ee2442c800-aspose-words-java-for-netbeans-8.jpeg)
6. Review the example code, compile and run.
7. You can now test other examples and start building your own application using <a href="https://reference.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a>.

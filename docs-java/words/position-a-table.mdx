## Purpose Summary {#purpose-summary}

This page explains how to position tables precisely within a document using layout and formatting options.
:::

There are floating tables and inline tables:

- **Inline tables** are placed on the same layer as the text and are placed in a flow of text that only surrounds the table above and below. Inline tables will always appear between the paragraphs where you placed them.
- **Floating tables** are layered over the text, and the position of the table relative to the paragraph is determined by the table anchor. Because of this, the position of the floating table in the document is affected by the vertical and horizontal positioning settings.

Sometimes you need to position a table in a document in a certain way. To do this, you need to use the alignment tools and set the indents between the table and the surrounding text.

In this article, we will discuss what options Aspose.Words provides for positioning.

## Specify Inline Table Position {#specify-inline-table-position}

You can set the position of an inline table using the Aspose.Words API and the <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getAlignment" target="_blank" rel="nofollow noopener noreferrer">getAlignment()</a> property. Thus, you can adjust the alignment of the table relative to the document page.

The following code example shows how to set the position of an inline table:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Tables.docx");

Table table = (Table) doc.getChild(NodeType.TABLE, 0, true);
// Align the table to the center of the page.
table.setAlignment(TableAlignment.CENTER);
```

## Get Floating Table Alignment {#get-floating-table-alignment}

If the table text wrapping is set to **Around**, you can get the table's horizontal and vertical alignment using the <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getRelativeHorizontalAlignment" target="_blank" rel="nofollow noopener noreferrer">getRelativeHorizontalAlignment()</a> and <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getRelativeVerticalAlignment" target="_blank" rel="nofollow noopener noreferrer">getRelativeVerticalAlignment()</a> properties.

With **other types of text wrapping**, you can get inline table alignment using the <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getAlignment" target="_blank" rel="nofollow noopener noreferrer">getAlignment()</a> property.

The following code example shows how to get the table's alignment:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Tables.docx");

Table table = (Table) doc.getChild(NodeType.TABLE, 0, true);

if (table.getTextWrapping() == TextWrapping.AROUND)
{
    System.out.println(table.getRelativeHorizontalAlignment());
    System.out.println(table.getRelativeVerticalAlignment());
}
else
{
    System.out.println(table.getAlignment());
}
```

## Get Floating Table Position {#get-floating-table-position}

The position of a floating table is determined using the following properties:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getHorizontalAnchor" target="_blank" rel="nofollow noopener noreferrer">getHorizontalAnchor()</a> - an object for calculating the horizontal positioning of a floating table
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getVerticalAnchor" target="_blank" rel="nofollow noopener noreferrer">getVerticalAnchor()</a> - an object for calculating the vertical positioning of a floating table
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getAbsoluteHorizontalDistance" target="_blank" rel="nofollow noopener noreferrer">getAbsoluteHorizontalDistance()</a> - absolute horizontal floating table position
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getAbsoluteVerticalDistance" target="_blank" rel="nofollow noopener noreferrer">getAbsoluteVerticalDistance()</a> - absolute vertical floating table position
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getAllowOverlap" target="_blank" rel="nofollow noopener noreferrer">getAllowOverlap()</a> - option to enable/disable overlap with other floating objects
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getRelativeHorizontalAlignment" target="_blank" rel="nofollow noopener noreferrer">getRelativeHorizontalAlignment()</a> - floating table relative horizontal alignment.
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getRelativeVerticalAlignment" target="_blank" rel="nofollow noopener noreferrer">getRelativeVerticalAlignment()</a> - floating table relative vertical alignment.

The following code example shows how to get the position of a floating table:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Table wrapped by text.docx");
        
for (Table table : doc.getFirstSection().getBody().getTables())
{
    // If the table is floating type, then print its positioning properties.
    if (table.getTextWrapping() == TextWrapping.AROUND)
    {
        System.out.println(table.getHorizontalAnchor());
        System.out.println(table.getVerticalAnchor());
        System.out.println(table.getAbsoluteHorizontalDistance());
        System.out.println(table.getAbsoluteVerticalDistance());
        System.out.println(table.getAllowOverlap());
        System.out.println(table.getAbsoluteHorizontalDistance());
        System.out.println(table.getRelativeVerticalAlignment());
        System.out.println("..............................");
    }
}
```

## Set Floating Table Position {#set-floating-table-position}

Just like getting, you can set the position of a floating table using the same Aspose.Words API.

It is important to know that alignment and horizontal and vertical distance are combined properties and one can reset the other. For example, setting the **getRelativeHorizontalAlignment()** will reset the **getAbsoluteHorizontalDistance()** to its default value and vice versa. The same is true for the vertical arrangement.

The following code example shows how to set the position of a floating table:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Table wrapped by text.docx");

Table table = doc.getFirstSection().getBody().getTables().get(0);
table.setAbsoluteHorizontalDistance(10.0);
table.setRelativeVerticalAlignment(VerticalAlignment.CENTER);

doc.save(getArtifactsDir() + "WorkingWithTables.FloatingTablePosition.docx");
```

## Get Distance between Table and Surrounding Text {#get-distance-between-table-and-surrounding-text}

Aspose.Words also provides an opportunity to find out the distances between tables and surrounding texts:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getDistanceTop" target="_blank" rel="nofollow noopener noreferrer">getDistanceTop()</a> - the value of the distance from above
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getDistanceBottom" target="_blank" rel="nofollow noopener noreferrer">getDistanceBottom()</a> - the value of the distance of perception
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getDistanceRight" target="_blank" rel="nofollow noopener noreferrer">getDistanceRight()</a> - distance value on the right
- <a href="https://reference.aspose.com/words/java/com.aspose.words/table/#getDistanceLeft" target="_blank" rel="nofollow noopener noreferrer">getDistanceLeft()</a> - distance value on the left

The following code example shows how to get the distance between a table and its surrounding text:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Tables.docx");

System.out.println("\nGet distance between table left, right, bottom, top and the surrounding text.");
Table table = (Table) doc.getChild(NodeType.TABLE, 0, true);

System.out.println(table.getDistanceTop());
System.out.println(table.getDistanceBottom());
System.out.println(table.getDistanceRight());
System.out.println(table.getDistanceLeft());
```

## Limitations and Considerations {#limitations-and-considerations}

Limitations and considerations for table positioning in Aspose.Words include:

- Horizontal and vertical alignment properties (`getRelativeHorizontalAlignment()`, `getRelativeVerticalAlignment()`) and distance properties (`getAbsoluteHorizontalDistance()`, `getAbsoluteVerticalDistance()`) are interdependent. Setting one property in each pair will reset the other to its default value.
- Inline tables can only be positioned using the `Alignment` property and cannot be freely positioned like floating tables.
- Floating tables require proper anchor setup and their position is always relative to a paragraph anchor, even when using absolute distances.
- The `getAllowOverlap()` property only affects the visual layering of floating objects and does not prevent layout conflicts.
- Distance properties (`getDistanceTop()`, `getDistanceBottom()`, etc.) apply to both inline and floating tables but may behave differently depending on text wrapping settings.

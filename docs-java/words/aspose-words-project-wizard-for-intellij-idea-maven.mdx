## IntelliJ IDEA

**IntelliJ IDEA** is a Java integrated development environment (IDE) for software developers. It is developed by JetBrains. Originally created for Java, it currently supports a wide variety of languages, including JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure, and Kotlin.

In a 2010 **Infoworld** report, IntelliJ received the highest test center score out of the four top Java programming tools: Eclipse, IntelliJ IDEA, NetBeans and Oracle JDeveloper.

## Aspose.Words for Java

<a href="https://products.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java</a> is an advanced class library for Java that enables you to perform a great range of document processing tasks directly within your Java applications.

Aspose.Words for Java supports processing word (DOC, DOCX, OOXML, RTF) HTML, OpenDocument, PDF, EPUB, XPS, and all image formats. With Aspose.Words you can
generate, modify, and convert documents without using Microsoft Word.

## Aspose.Words Java for IntelliJ IDEA - Maven

- Aspose.Words Java for IntelliJ IDEA (Maven) is an **IntelliJ IDEA Plugin** which lets you create maven projects (i.e. created project contains Aspose.Words for Java API maven dependency) and download source code examples of the API for using <a href="https://reference.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a>.
- This plugin helps you to work with <a href="https://reference.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a> inside your favourite IntelliJ IDEA.

![aspose-words-java-for-intellij-idea](/java/words/images/7c3e784e32f8fba6-aspose-words-java-for-intellij-idea.png)

**WIZARDS**:
The plugin contains two wizards-----

` `**Wizard 1:** Aspose.Words Maven Project

- Plugin's **Aspose Maven Project Wizard** lets developers create Aspose.Words for Java API Maven project.
- The reference of Aspose.Words for Java API maven dependency is automatically fetched from <a href="https://releases.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose Cloud Maven Repository</a> and gets added in the pom.xml.
- The created project will always contain the most recent available version Maven Dependency for <a href="https://reference.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a>.
- The wizard steps also present with the option for downloading <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples for using Aspose.Words for Java API</a>

` `**Wizard 2:** Aspose.Words Examples

- **Aspose.Words Examples Wizard** lets you create/copy downloaded <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples of Aspose.Words for Java API</a> into your project. All the examples for the selected category will get copied to the project's "com.aspose.words.examples" package folder along with the required resources within "src/main/resources" folder needed to run the examples.
- <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples of Aspose.Words for Java API</a> are meant for demonstrating the different usages of the API.

## System Requirements and Supported Platforms

### System Requirements

- Microsoft Windows 8/7/Vista/2003/XP (incl.64-bit) / Linux GNOME or KDE desktop / Mac OS X 10.5 or higher
- 1 GB RAM minimum, 2 GB RAM recommended
- 300 MB hard disk space + at least 1 G for caches
- 1024x768 minimum screen resolution
- JDK 1.7 or higher recommended
- IntelliJ IDEA CE/UE (13.0.1, 13.1.2 or 14.0.2)
- Internet Connection (2 MB or faster recommended)

The plugin supports the following IntelliJ IDEA Versions:

- 13.0.1 (Community / Ultimate Edition)
- 13.1.2 (CE / UE)
- 14.0.2 (CE/ UE)

## Downloading

### Downloading IntelliJ IDEA

You will need to first install IntelliJ IDEA CE / UE before downloading the **Aspose.Words Java for IntelliJ IDEA (Maven)** plugin.

To download IntelliJ IDEA

1. Go to <a href="https://www.jetbrains.com/idea/download/" target="_blank" rel="nofollow noopener noreferrer">https://www.jetbrains.com/idea/download/</a>
2. Select your running OS
3. Click on UE or CE download.

### Downloading Aspose.Words Java for IntelliJ IDEA plugin - Maven

- The plugin can be directly downloaded from the <a href="https://plugins.jetbrains.com/plugin/7922-aspose-words-java-for-intellij-idea-maven/" target="_blank" rel="nofollow noopener noreferrer">JetBrains plugin hosting URL</a> - on IntelliJ IDEA Plugin Repository
  and later can be installed using the `IDE` option:
  - Go to **File** &gt; **Settings**...>**Plugins**
  - Select "**Install plugin from Disk"**
- Or it can be directly installed (without manual downloading from JetBrains plugin hosting URL) using the `IDE` options:
  - Go to **File** &gt; **Settings**...>**Plugins**
  - Select **"Browse Repositories"**
  - In Search Box type: "Aspose"
  - Select "**Aspose Words Java for IntelliJ IDEA Maven**" plugin to install.

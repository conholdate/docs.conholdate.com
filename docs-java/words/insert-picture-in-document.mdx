The <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/" target="_blank" rel="nofollow noopener noreferrer">DocumentBuilder</a> provides several overloads of the <a href="https://reference.aspose.com/words/java/com.aspose.words/documentbuilder/#insertImage-byte" target="_blank" rel="nofollow noopener noreferrer">InsertImage</a> method that allow you to insert an inline or floating image. If the image is an EMF or WMF metafile, it will be inserted into the document in metafile format. All other images will be saved in PNG format.

The following code example shows how to insert an image info a document:

```java
Document doc = new Document();
DocumentBuilder builder = new DocumentBuilder(doc);

builder.insertImage("image.jpg");
doc.save("insertedImage.docx");
```

:::


Aspose.Words allows users to work with documents in various formats and provides a wide range of features for this. For example, users can create a document from scratch or load it, make some changes, and then save those changes in the output file in any [supported export format](/java/words/supported-document-formats/). While saving the document in the selected format, the user can apply various save options.

:::info
It is important to know that many save options are common to all supported formats, and only some of the options are format-specific, such as PDF, DOCX, HTML, and others.
:::

For a complete list of functions, see the API reference:

To append documents using Aspose.Words, simply invoke the <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#appendDocument-com.aspose.words.Document-int" target="_blank" rel="nofollow noopener noreferrer">appendDocument()</a> method of the <a href="https://reference.aspose.com/words/java/com.aspose.words/document/" target="_blank" rel="nofollow noopener noreferrer">Document</a> class and specify the second document to append it at the end of the first one.

The following code example shows how to append a document:

```java
Document doc1 = new Document(dataDir + "doc1.doc");
Document doc2 = new Document(dataDir + "doc2.doc");

doc1.appendDocument(doc2, ImportFormatMode.KEEP_SOURCE_FORMATTING);
```

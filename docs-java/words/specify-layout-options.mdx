## Purpose Summary {#purpose-summary}

This page explains how to configure layout options that affect pagination and rendering.
:::

Aspose.Words enables you to create output documents with various layouts, depending on the parameters specified in properties of the <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/" target="_blank" rel="nofollow noopener noreferrer">LayoutOptions</a> class. Some of these properties resemble some of the Microsoft Word user interface menu options - they will be described in this article.

For a complete list of parameters such as <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getContinuousSectionPageNumberingRestart" target="_blank" rel="nofollow noopener noreferrer">getContinuousSectionPageNumberingRestart()</a> to calculate page numbers in a continuous section that restarts page numbering, or <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getIgnorePrinterMetrics" target="_blank" rel="nofollow noopener noreferrer">getIgnorePrinterMetrics()</a> to ignore the "Use printer metrics to lay out document" compatibility option, see the <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/" target="_blank" rel="nofollow noopener noreferrer">LayoutOptions</a> class page.

## Formatting Marks {#formatting-marks}

Aspose.Words allows to manage formatting marks using the following properties:

- <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getShowHiddenText" target="_blank" rel="nofollow noopener noreferrer">getShowHiddenText()</a> - a `Boolean` value, which specifies whether the hidden text is rendered.
- <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getShowParagraphMarks" target="_blank" rel="nofollow noopener noreferrer">getShowParagraphMarks()</a> - a `Boolean` value, which specifies whether paragraph mark characters are rendered.

The page depicted in the example below contains three paragraphs. The second one is hidden. A user can change the **getShowHiddenText()** option to display this hidden text on the page. Also, each paragraph has a paragraph mark at the end. The paragraph mark usually is not visible unless the **getShowParagraphMarks()** property is set to render it.

## Comments and Revisions {#comments-and-revisions}

With Aspose.Words, you can render document comments that will look the same as in Microsoft Word. To specify whether comments are rendered, use the <a href="https://reference.aspose.com/words/java/com.aspose.words/commentdisplaymode/" target="_blank" rel="nofollow noopener noreferrer">CommentDisplayMode</a> property.

In Microsoft Word, this parameter is set using the "Track Changes Options" dialog box, as shown below:

![specify-layout-options_3_java](/java/words/images/ebd416cb4258f666-specify-layout-options-3.jpg)

Also, Aspose.Words allows you to display revisions in a document. Use the <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getRevisionOptions" target="_blank" rel="nofollow noopener noreferrer">getRevisionOptions()</a> property of the **LayoutOptions** class to define whether the document revisions are displayed. To control their appearance (revision highlighting color, revision bar color, etc.), use the <a href="https://reference.aspose.com/words/java/com.aspose.words/revisionoptions/" target="_blank" rel="nofollow noopener noreferrer">RevisionOptions</a> class.

You can also have revisions displayed as comments to the content. For this purpose, use the <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getCommentDisplayMode" target="_blank" rel="nofollow noopener noreferrer">getCommentDisplayMode()</a> property and <a href="https://reference.aspose.com/words/java/com.aspose.words/commentdisplaymode/" target="_blank" rel="nofollow noopener noreferrer">ShowInBalloons</a> value.

The following code example shows how to customize revisions display:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Revisions.docx");

// Renders insert revisions inline, delete and format revisions in balloons.
doc.getLayoutOptions().getRevisionOptions().setShowInBalloons(ShowInBalloons.FORMAT_AND_DELETE);
doc.getLayoutOptions().getRevisionOptions().setMeasurementUnit(MeasurementUnits.INCHES);
// Renders revision bars on the right side of a page.
doc.getLayoutOptions().getRevisionOptions().setRevisionBarsPosition(HorizontalAlignment.RIGHT);

doc.save(getArtifactsDir() + "WorkingWithRevisions.ShowRevisionsInBalloons.pdf");
```

## Text Shaper for Advanced Typography Rendering {#text-shaper-for-advanced-typography-rendering}

The <a href="https://reference.aspose.com/words/java/com.aspose.words/layoutoptions/#getTextShaperFactory" target="_blank" rel="nofollow noopener noreferrer">getTextShaperFactory()</a> property enables you to set the text shaping functionality, as well as the `OpenType` features support.

Use text shaping for document processing in the following main cases:

- A document uses Kerning, Numeral Shaping, Numeral Forms, or Ligatures.
- A document uses Complex Scripts, such as Arabic, Khmer, Thai, etc.

:::info
Text shaping will be enabled only when exporting a document to PDF or XPS.
:::

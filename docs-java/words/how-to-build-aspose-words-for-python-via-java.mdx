To create "Aspose Words for Python via Java" package we use <a href="https://lucene.apache.org/pylucene/jcc/index.html" target="_blank" rel="nofollow noopener noreferrer">JCC</a>

## How to build JCC on Windows

Download and install <a href="https://www.oracle.com/java/technologies/downloads/#java8" target="_blank" rel="nofollow noopener noreferrer">JRE</a> (it is not necessary because you can use %JDK_HOME%\jre)

JCC requires <a href="https://www.oracle.com/java/technologies/downloads/#java8" target="_blank" rel="nofollow noopener noreferrer">JDK</a> so download and install it.

Download and install <a href="https://www.python.org/ftp/python/2.7.14/python-2.7.14.amd64.msi" target="_blank" rel="nofollow noopener noreferrer">Python</a>

Make sure Java's and Python's paths are on the environment variables list

![how-to-build-aspose-words-for-python-via-java-1](/java/words/images/b6a6eae0bf7011be-how-to-build-aspose-words-for-python-via-java-1.png)

Install wheel

```text
>  pip install wheel
```

Download and install <a href="https://wiki.python.org/moin/WindowsCompilers" target="_blank" rel="nofollow noopener noreferrer">Microsoft Visual C++ Compiler for Python 2.7</a>

Download and unzip <a href="https://pypi.org/project/JCC/" target="_blank" rel="nofollow noopener noreferrer">JCC</a>

Run following command in JCC directory

```text
JCC-3.0> python .\setup.py build
```

Then run install command

```text
JCC-3.0> python .\setup.py install
```

Check JCC egg has been installed

```text
    > ls C:\Python27\Lib\site-packages\JCC-3.0-py2.7-win-amd64.egg
```

## How to build JCC on Ubuntu

Check if python is installed

```text
> python
Python 2.7.13 (default, Jan 19 2017, 14:48:08)
[GCC 6.3.0 20170118] on linux2
Type "help", "copyright", "credits" or "license" for more information.
```

In order to get things working make sure Java is installed, if it isn't then do following:

```text
> sudo add-apt-repository ppa:webupd8team/java
\> sudo apt-get update
\> sudo apt-get install oracle-java8-installer
```

Install svn

```text
> sudo apt install subversion
```

Check out JCC's sources

```text
> svn co https://svn.apache.org/repos/asf/lucene/pylucene/trunk/jcc jcc
```

Make sure that <a href="https://pypi.org/project/setuptools/" target="_blank" rel="nofollow noopener noreferrer">setuptools</a> is installed

```text
> pip install setuptools
```

Run following commands

```text
> jcc/$ python setup.py build
\> jcc/$ python setup.py install --prefix=~/.local
```

Make sure JCC has been installed

```text
> ls /home/_username_/.local/lib/python2.7/site-packages
```

## How to create "Aspose Words for Python via Java" python package

Make sure Java, JCC and wheel are installed.

Then run <a href="https://docs.aspose.com/words/java/how-to-build-aspose-words-for-python-via-java/create_aspose_words.py" target="_blank" rel="nofollow noopener noreferrer">create_aspose_words.py</a> with appropriate arguments

```text
> python .\create_aspose_words.py .\Aspose.Words.jdk16.jar 17.8 aspose_words
```

The first argument is the path to the Aspose.Words jar;

The second is the version;

The third is the python module name.

Result *.whl* file will be saved in *.\dist* directory

## How to install "Aspose Words for Python via Java" on Windows

1. Download and install <a href="https://www.oracle.com/java/technologies/downloads/#java8" target="_blank" rel="nofollow noopener noreferrer">JRE</a>. We use JRE x64 version because our .whl was built for Windows x64;
2. Download and install <a href="https://www.python.org/ftp/python/2.7.14/python-2.7.14.amd64.msi" target="_blank" rel="nofollow noopener noreferrer">Python</a>. At the moment 2.7 version is used;
3. Add following path variables to the environment variables list:
   ![how-to-build-aspose-words-for-python-via-java-2](/java/words/images/420a911035e96443-how-to-build-aspose-words-for-python-via-java-2.png)
4. Then install the .whl package <a href="https://docs.aspose.com/words/java/how-to-build-aspose-words-for-python-via-java/create_aspose_words.py" target="_blank" rel="nofollow noopener noreferrer">create_aspose_words.py</a>

```text
> pip install .\aspose_words-17.8-cp27-none-win_amd64.whl
```

## How to install "Aspose Words for Python via Java" on Ubuntu

Check if python is installed

```text
> python
Python 2.7.13 (default, Jan 19 2017, 14:48:08)
[GCC 6.3.0 20170118] on linux2
Type "help", "copyright", "credits" or "license" for more information.
```

In order to get things working make sure Java is installed, if it isn't then do following:

```text
> sudo add-apt-repository ppa:webupd8team/java
\> sudo apt-get update
\> sudo apt-get install oracle-java8-installer
```

Make sure pip is installed if it isn't then

```text
> sudo apt install python-pip
```

Run terminal and use following command:

```text
> pip install --prefix=~/.local aspose_words-17.8-cp27-none-linux_x86_64.whl
```

## How to use "Aspose Words for Python via Java"

```text
> python
import aspose_words
aspose_words.initVM(aspose_words.CLASSPATH)
d = aspose_words.Document()
db = aspose_words.DocumentBuilder(d)
db.writeln('Hello world!')
d.save('/home/slava/test.docx')
```

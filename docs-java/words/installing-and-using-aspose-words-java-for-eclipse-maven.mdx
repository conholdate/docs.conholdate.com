## Installing {#installing}

**Aspose.Words Java for Eclipse (Maven)** plugin can be easily installed from the Available **Plugin** tab in the Plugin dialog.

- To open it, select **Plugins** from the **Tools** menu in Eclipse.

![installing-and-using-aspose-words-java-for-eclipse-maven-1](/java/words/images/2d9b153121f58686-1.png)

- This adds the **Aspose.Words Maven Project** in New Project wizard and **Aspose.Words Code Example** in New Other wizard of Eclipse IDE.

![installing-and-using-aspose-words-java-for-eclipse-maven-2](/java/words/images/372b840923dbe90e-2.png)

## Using {#using}

### Aspose.Words Maven Project (wizard) {#asposewords-maven-project-wizard}

To create **Maven Project** by wizard for using <a href="https://products.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API</a>:

1. Select **New -> Project**.
2. Select **Aspose.Words Maven Project** in the **Maven** category.
3. Click **Next**.\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-3](/java/words/images/372b840923dbe90e-3.png)
4. Provide **Project Name, Location, GroupId, ArtifactId** and **Version** for your Maven Project and click **Finish.**\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-4](/java/words/images/d80bc9423f278683-4.png)
5. This will retrieve the Aspose.Words for Java latest <a href="https://releases.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Maven Dependency</a> reference from Aspose Cloud Maven Repository and configure it in **pom.xml**. If you have opted for **Also Download Code Examples,** downloading of the **Code Examples** will also begin from the <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API Examples Repository.</a>
6. Following **Maven** Project will be created on your **Eclipse IDE** on completion of the wizard:\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-5](/java/words/images/04ea2aca277bdb5e-5.png)
7. The created **Maven Project** is configured to use **Aspose.Words for Java API** and ready to be enhanced as per your Project requirements.\
   If you have opted to download <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Code Examples</a>, you can use **Aspose.Words Code Example (wizard)** for importing needed **Code Examples** of Aspose.Words for Java API into your project.

### Aspose.Words Code Example (wizard) {#asposewords-code-example-wizard}

**Aspose.Words Code Example wizard** allows you to try out many samples provided for Aspose.Words for Java API.

:::info
To be able to use **Aspose.Words Code Example wizard** comfortably: it is recommended to always select **Also Download Code Examples** while creating **Maven Project** on **Aspose.Words Maven Project** **wizard**,
:::

To use examples, just:

1. Click **New -> Other** in **Eclipse**.
2. Select **Aspose.Words Code Example** in the **Java** category.
3. Click **Next**.\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-6](/java/words/images/5055c6b2c24b99c6-6.png)
4. Choose your project and then expand the tree to select **Code Example** category and click **Finish**.\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-7](/java/words/images/830bebf6a426b216-7.png)
5. This will copy the selected category **Code Examples** Java files into the project under **com.aspose.words.examples** package. Also any required resources needed by the Code Examples will be copied into **src/main/resources** folder, as shown below:\
   ![installing-and-using-aspose-words-java-for-eclipse-maven-8](/java/words/images/48ab5d285c9676fc-8.png)
6. Review the example code, compile and run.
7. You can now test other examples and start building your own application using Aspose.Words for Java API.

## Installing Aspose Words Java for IntelliJ IDEA - Maven

Steps below demonstrate how to install **Aspose.Words Java for IntelliJ IDEA (Maven)** plugin.

The plugin is listed on IntelliJ IDEA's CE <a href="https://plugins.jetbrains.com/plugin/7922-aspose-words-java-for-intellij-idea-maven/" target="_blank" rel="nofollow noopener noreferrer">official plugin website</a> - plugin repository as **Aspose Words Java for IntelliJ IDEA Maven**, so you don't need to download it manually and install it from disk, but this extra option still exists in IntelliJ IDEA.

**Aspose.Words Java for IntelliJ IDEA (Maven)** plugin can be easily installed (without manual downloading) from within IntelliJ IDEA. To do it:

1. Select **Settings** from the **File** menu.
2. Click **Plugins**, then browse the repositories in IntelliJ IDEA.

## Using

### Using Aspose.Words Maven Project Wizard

To create Aspose.Words Maven project for using Aspose.Words for Java API within IntelliJ IDEA, you need to have an internet connection.

Then follow the steps below:

1. Select **New Project**.
2. Select **Aspose.Words Maven Project**
3. Click **Next**.
   ![aspose-words-java-for-intellij-idea-6](/java/words/images/bd6bf9323e7e66c7-install-and-use-aspose-words-for-intellij-idea-maven-4.jpeg)
4. Provide a **GroupId, ArtifactId** and **Version** for your maven project and click **Next.**
   ![aspose-words-java-for-intellij-idea-7](/java/words/images/fe46bda68a24883f-install-and-use-aspose-words-for-intellij-idea-maven-5.jpeg)
   You can select "Also Download Examples Source Code" checkbox to download the sample usage examples of the API (as shown in above snapshot)
5. Provide a **Project Name** and **Location** just like when creating any Java application
   ![aspose-words-java-for-intellij-idea-8](/java/words/images/86c51b21d48bc8d4-install-and-use-aspose-words-for-intellij-idea-maven-6.jpeg)
6. Click **Finish**.
   This will retrieve the Aspose.Words for Java API latest maven dependency reference from Aspose Cloud Maven Repository and configure it in pom.xml
   If you have selected "Also Download Examples Source Code" checkbox. Downloading of the examples will also begin from the <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API GitHub Repository</a>
   ![aspose-words-java-for-intellij-idea-9](/java/words/images/57c5a20ea047e3ac-install-and-use-aspose-words-for-intellij-idea-maven-7.jpeg)
   ![aspose-words-java-for-intellij-idea-10](/java/words/images/092330594051319b-install-and-use-aspose-words-for-intellij-idea-maven-8.jpeg)
   Congratulations! Not supported You have successfully created Aspose.Words Maven project for using Aspose.Words for Java API.
   ![aspose-words-java-for-intellij-idea-11](/java/words/images/c337b295eb959a9e-install-and-use-aspose-words-for-intellij-idea-maven-9.jpeg)
   The created Aspose.Words for Java API Maven project is ready to be modified as per your project's requirements.
   If you have opted to download <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Examples Source Codes</a>, you can use [Aspose.Words Examples wizard](/java/words/installing-and-using-aspose-words-for-intellij-idea-maven/#asposewords-examples-wizard) to copy/create the downloaded examples into your project.

### Using Aspose.Words Examples Wizard

To create/copy <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Examples Source Codes</a> into the project using **Aspose.Words Examples Wizard**, you need to first download the examples by opting "Also Download Examples Source Code" on [Aspose.Words Maven Project Wizard.](/java/words/installing-and-using-aspose-words-for-intellij-idea-maven/#asposewords-maven-project-wizard)

Then follow the steps below on IntelliJ IDEA:

1. Select **File** => **New -** As shown below:
   ![aspose-words-java-for-intellij-idea-12](/java/words/images/c4db182456d89e82-install-and-use-aspose-words-for-intellij-idea-maven-10.jpeg)
   -OR- **Right-Click** (on project window) => **New** - As shown below:
   ![aspose-words-java-for-intellij-idea-13](/java/words/images/af9b0d03350ca82d-install-and-use-aspose-words-for-intellij-idea-maven-11.jpeg)
2. Select **Aspose.Words Example** Option from Menu - As shown below:
   ![aspose-words-java-for-intellij-idea-14](/java/words/images/b0bc20c975021aaf-install-and-use-aspose-words-for-intellij-idea-maven-12.jpeg)
   The wizard will refresh/check for the latest available <a href="https://github.com/aspose-words/Aspose.Words-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java API Examples</a>
   ![aspose-words-java-for-intellij-idea-15](/java/words/images/3967dcd8d8bf2184-install-and-use-aspose-words-for-intellij-idea-maven-13.jpeg)
3. **Aspose.Words Examples wizard** dialog will appear, where you can select any examples category to create/copy the examples into your project
   Select any examples category and click **Create**:
   ![aspose-words-java-for-intellij-idea-16](/java/words/images/5d4cea991c1ecf00-install-and-use-aspose-words-for-intellij-idea-maven-14.jpeg)
4. This will create/copy the selected category examples into the project under **com.aspose.words.examples** package.
   Also, any required resources for the execution of the examples will be copied to **src/main/resources** folder - As shown below:
   ![aspose-words-java-for-intellij-idea-17](/java/words/images/a4419120e1a666a9-install-and-use-aspose-words-for-intellij-idea-maven-15.jpeg)
   Congratulations! Not supported You have successfully done the following:

## Purpose Summary {#purpose-summary}

This page explains how to save a document as a multi-page TIFF image.
:::

When working with documents, you often need to convert your document to a raster image file(s). This is especially relevant if you have to present your document in a readable and printable, but not editable format. For example, you can use a raster image of the first page of your document as a preview. This article describes how to convert a document to a raster image using the example of the TIFF format - one of the more popular image formats.

## Converting DOC to Multi-Page TIFF {#converting-doc-to-multi-page-tiff}

In Aspose.Words, conversion from DOC to TIFF can be performed with one line of code, by simply passing the "save to" path and the relevant file extension to the <a href="https://reference.aspose.com/words/java/com.aspose.words/document/#save-java.io.OutputStream-com.aspose.words.SaveOptions" target="_blank" rel="nofollow noopener noreferrer">save()</a> method. The **Save** method automatically derives the `SaveFormat` from the file name extension specified in the path. The following example demonstrates how to convert a document to the TIFF format:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.MultipageTiff.tiff");
```

## Specifying Additional Options When Rendering TIFF {#specifying-additional-options-when-rendering-tiff}

You often need to specify additional options, which affect the rendering result. For this purpose, use the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> class, which contains properties that determine how the document is displayed on the image. You can specify the following:

- Save format to determine the list of available options (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getSaveFormat" target="_blank" rel="nofollow noopener noreferrer">getSaveFormat()</a>)
- Resolution (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getHorizontalResolution" target="_blank" rel="nofollow noopener noreferrer">getHorizontalResolution()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getVerticalResolution" target="_blank" rel="nofollow noopener noreferrer">getVerticalResolution()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#setResolution-float" target="_blank" rel="nofollow noopener noreferrer">setResolution()</a>)
- Number of pages (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPageSet" target="_blank" rel="nofollow noopener noreferrer">getPageSet()</a>)
- Color and lighting settings (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPaperColor" target="_blank" rel="nofollow noopener noreferrer">getPaperColor()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageColorMode" target="_blank" rel="nofollow noopener noreferrer">getImageColorMode()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageBrightness" target="_blank" rel="nofollow noopener noreferrer">getImageBrightness()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageContrast" target="_blank" rel="nofollow noopener noreferrer">getImageContrast()</a>)
- Image quality (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getJpegQuality" target="_blank" rel="nofollow noopener noreferrer">getJpegQuality()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getScale" target="_blank" rel="nofollow noopener noreferrer">getScale()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getTiffCompression" target="_blank" rel="nofollow noopener noreferrer">getTiffCompression()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getGraphicsQualityOptions" target="_blank" rel="nofollow noopener noreferrer">getGraphicsQualityOptions()</a>)
- The method used to binarize the image (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getTiffBinarizationMethod" target="_blank" rel="nofollow noopener noreferrer">getTiffBinarizationMethod()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getThresholdForFloydSteinbergDithering" target="_blank" rel="nofollow noopener noreferrer">getThresholdForFloydSteinbergDithering()</a>)
- Pixel format for generated images (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPixelFormat" target="_blank" rel="nofollow noopener noreferrer">getPixelFormat()</a>)
- Windows metafiles handling by Aspose.Words (<a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getMetafileRenderingOptions" target="_blank" rel="nofollow noopener noreferrer">getMetafileRenderingOptions()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getUseGdiEmfRenderer" target="_blank" rel="nofollow noopener noreferrer">getUseGdiEmfRenderer()</a>)
- Additional options that you can see in the **ImageSaveOptions** class

The following example shows how to convert DOC to TIFF with configured options:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");
doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.MultipageTiff.tiff");

ImageSaveOptions saveOptions = new ImageSaveOptions(SaveFormat.TIFF);
saveOptions.setPageSet(new PageSet(new PageRange(0, 1)));
saveOptions.setTiffCompression(TiffCompression.CCITT_4);
saveOptions.setResolution(160f);

doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.GetTiffPageRange.tiff", saveOptions);
```

## Threshold for TIFF Binarization {#threshold-for-tiff-binarization}

A TIFF image can be saved in 1bpp b/w format by setting the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPixelFormat" target="_blank" rel="nofollow noopener noreferrer">getPixelFormat()</a> property to Format1bppIndexed pixel format type, and the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getTiffCompression" target="_blank" rel="nofollow noopener noreferrer">getTiffCompression()</a> property to either Ccitt3 or Ccitt4.

For image segmentation, Aspose.Words uses the simplest method - thresholding. This method converts a gray-scale TIFF image into a binary image, using a threshold value. Therefore, when a document needs to be converted to the TIFF file format, it is possible to get or set the threshold for TIFF binarization via the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getThresholdForFloydSteinbergDithering" target="_blank" rel="nofollow noopener noreferrer">getThresholdForFloydSteinbergDithering()</a> property. The default value for this property is set to 128, and the higher this value, the darker the image.

The following example shows how to perform TIFF binarization with a specified threshold:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");

ImageSaveOptions saveOptions = new ImageSaveOptions(SaveFormat.TIFF);
saveOptions.setTiffCompression(TiffCompression.CCITT_3);
saveOptions.setImageColorMode(ImageColorMode.GRAYSCALE);
saveOptions.setTiffBinarizationMethod(ImageBinarizationMethod.FLOYD_STEINBERG_DITHERING);
saveOptions.setThresholdForFloydSteinbergDithering((byte) 254);

doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.ExposeThresholdControl.tiff", saveOptions);
```

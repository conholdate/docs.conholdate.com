## Purpose Summary {#purpose-summary}

This page explains how to convert a Word document into images (e.g., PNG, JPEG) using Aspose.Words.
:::

Sometimes it is required to get an image instead of documents in other formats, such as DOCX or PDF. For example, you need to add a preview of any document page to your website or application, or create a "scan" of a document to send an invoice. This is when you may need to convert a document in any <a href="https://reference.aspose.com/words/java/com.aspose.words/loadformat/" target="_blank" rel="nofollow noopener noreferrer">supported load format</a> to an image, again, in any <a href="https://reference.aspose.com/words/java/com.aspose.words/saveformat/" target="_blank" rel="nofollow noopener noreferrer">supported save format</a>.

## Convert to Image {#convert-to-image-format}

As with all conversion examples already described, you need to create a new document or load an existing one in any supported format, make the necessary changes, and save it in any available image format, for example, JPEG, PNG, or BMP.

The following code example shows how to convert DOCX to JPEG:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Document.docx");
doc.save(getArtifactsDir() + "BaseConversions.DocxToJpeg.jpeg");
```

## Specify Save Options when Converting to Image {#specify-save-options-when-converting-to-an-image}

Aspose.Words provides you with the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">ImageSaveOptions</a> class, which gives more control over how documents are saved in various image formats. Some properties of this class inherit or overload properties of base classes such as <a href="https://reference.aspose.com/words/java/com.aspose.words/fixedpagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">FixedPageSaveOptions</a> or <a href="https://reference.aspose.com/words/java/com.aspose.words/saveoptions/" target="_blank" rel="nofollow noopener noreferrer">SaveOptions</a>, but there are also options specific to saving images.

It is possible to specify the pages to be converted to image format using the <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPageSet" target="_blank" rel="nofollow noopener noreferrer">getPageSet()</a> property. For example, it can be applied if you only need a preview for the first or for a definite page.

It is also possible to control the output image quality and pixel format using the following properties - <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getHorizontalResolution" target="_blank" rel="nofollow noopener noreferrer">getHorizontalResolution()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getVerticalResolution" target="_blank" rel="nofollow noopener noreferrer">getVerticalResolution()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/" target="_blank" rel="nofollow noopener noreferrer">setResolution()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getScale" target="_blank" rel="nofollow noopener noreferrer">getScale()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPixelFormat" target="_blank" rel="nofollow noopener noreferrer">getPixelFormat()</a>, as well as set up image color settings, using the following properties - <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageBrightness" target="_blank" rel="nofollow noopener noreferrer">getImageBrightness()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageColorMode" target="_blank" rel="nofollow noopener noreferrer">getImageColorMode()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getImageContrast" target="_blank" rel="nofollow noopener noreferrer">getImageContrast()</a>, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getPaperColor" target="_blank" rel="nofollow noopener noreferrer">getPaperColor()</a>.

There are also properties that apply to a certain format, for example, <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getJpegQuality" target="_blank" rel="nofollow noopener noreferrer">getJpegQuality()</a> or <a href="https://reference.aspose.com/words/java/com.aspose.words/imagesaveoptions/#getTiffCompression" target="_blank" rel="nofollow noopener noreferrer">getTiffCompression()</a>.

The following code example shows how to create a preview of the first document page with applying some additional settings:

```java
// For complete examples and data files, please go to https://github.com/aspose-words/Aspose.Words-for-Java.git.
Document doc = new Document(getMyDir() + "Rendering.docx");

ImageSaveOptions options = new ImageSaveOptions(SaveFormat.JPEG);

// Set the "PageSet" to "0" to convert only the first page of a document.
options.setPageSet(new PageSet(0));

// Change the image's brightness and contrast.
// Both are on a 0-1 scale and are at 0.5 by default.
options.setImageBrightness(0.3f);
options.setImageContrast(0.7f);

// Change the horizontal resolution.
// The default value for these properties is 96.0, for a resolution of 96dpi.
options.setHorizontalResolution(72f);

doc.save(getArtifactsDir() + "WorkingWithImageSaveOptions.GetJpegPageRange.jpeg", options);
```

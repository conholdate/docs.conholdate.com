This article gives you an idea of getting started with Aspose.Words for Android via Java. It will demonstrate how to set up a new Android project from scratch, add a reference to the Aspose.Words JAR and create a new document which is saved to disk in DOCX format. This example uses <a href="https://developer.android.com/studio/index.html" target="_blank" rel="nofollow noopener noreferrer">Android Studio</a> for development and the application is run on the Android Emulator. To get started with Aspose.Words for Android via Java, please follow this step-by-step tutorial to create an app which uses Aspose.Words for Android via Java:

1. Download and the <a href="https://developer.android.com/studio/index.html" target="_blank" rel="nofollow noopener noreferrer">Android Studio</a> and install it to any location.
2. Run the Android Studio.
3. Create a new Android Application Project.
   ![install-aspose-words-for-android-via-java-3](/java/words/images/71b67c472ee40aad-install-aspose-words-for-android-via-java-3.jpg)
   ![install-aspose-words-for-android-via-java-4](/java/words/images/704b1085f87dd23d-install-aspose-words-for-android-via-java-4.png)
   ![install-aspose-words-for-android-via-java-5](/java/words/images/256d501be5974224-install-aspose-words-for-android-via-java-5.jpg)
   ![install-aspose-words-for-android-via-java-6](/java/words/images/eea8ee9f8b605451-install-aspose-words-for-android-via-java-6.jpg)
   ![install-aspose-words-for-android-via-java-7](/java/words/images/e10759cb17a29659-install-aspose-words-for-android-via-java-7.jpg)
4. Copy aspose-words-17.5-android.via.java.jar into your project's libs/folder
   ![install-aspose-words-for-android-via-java-8](/java/words/images/c9ccc8c4acb1d7ec-install-aspose-words-for-android-via-java-8.jpg)
5. Select Project Section (from the file menu and click on the Dependencies tab.
   1. Click on the "+" button, select the file dependency option.
   2. Select Aspose.Words library from libs folder and click on OK.
      ![install-aspose-words-for-android-via-java-9](/java/words/images/8f55e4c085a31bb6-install-aspose-words-for-android-via-java-9.png)
6. Sync the project with Gradle files if needed
   ![install-aspose-words-for-android-via-java-10](/java/words/images/2b2aaae12dbb3111-install-aspose-words-for-android-via-java-10.png)
7. In order to access the SDcard special permissions must be added. Click on the AndroidManifest.xml file and choose the XML view. Add the following line to the file\
   ![install-aspose-words-for-android-via-java-11](/java/words/images/d1f5193d9b3e2b8e-install-aspose-words-for-android-via-java-11.jpg)
8. Navigate back to the code section of the app and add the following imports:

```java
import java.io.File;
import com.aspose.words.Document;
import com.aspose.words.DocumentBuilder;
import android.os.Environment;
```

And then insert the following code in the body of the onCreate method to create a new document from scratch using Aspose.Words,
insert some text and save it to the SDCard in DOCX format.

```java
try
{
   Document doc = new Document();
   DocumentBuilder builder = new DocumentBuilder(doc);
   builder.writeln("Hello World!");
   String sdCardPath = Environment.getExternalStorageDirectory().getPath() + File.separator;
   doc.save(sdCardPath + "Document Out.docx");
}
catch (Exception e)
{
   e.printStackTrace();
}
```

1. Now run the application again. This time the Aspose.Words code will run in the background and generate a document that is saved to the SDcard.
   ![install-aspose-words-for-android-via-java-13](/java/words/images/9adf5cf07bb0d35e-install-aspose-words-for-android-via-java-13.jpg)
2. To view the created document navigate to the Tools menu then choose Android and choose Android Device Monitor
   ![install-aspose-words-for-android-via-java-14](/java/words/images/b15ed0944e7891f3-install-aspose-words-for-android-via-java-14.jpg)
   ![install-aspose-words-for-android-via-java-15](/java/words/images/13b4043c34d79fb3-install-aspose-words-for-android-via-java-15.jpg)
3. Use the default viewer to open the document. The output generated by the app with just a few lines of code looks like this:

## Introduction {#introduction}

### IntelliJ IDEA {#intellij-idea}

**IntelliJ IDEA** is a Java integrated development environment (IDE) for software developers. It is developed by JetBrains. Originally created for Java, it currently supports a wide variety of languages, including JavaScript, Groovy, HTML, CSS, RSS, R, Haskell, PHP, Ruby, Python, Scala, Clojure, and Kotlin.

In a 2010 **Infoworld** report, IntelliJ received the highest test center score out of the four top Java programming tools: Eclipse, IntelliJ IDEA, NetBeans and Oracle JDeveloper.

### Aspose.Email for Java {#asposeemail-for-java}

<a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java</a> is a Java class library that enables Java applications to read and write email message files in various formats without Microsoft Outlook. It provides classes to read and update MSG,EML,EMLX,OFT files, add/remove attachments and recipients, update subject, body and other MSG file properties.

### Aspose.Email Java for IntelliJ IDEA - Maven {#asposeemail-java-for-intellij-idea---maven}

- Aspose.Email Java for IntelliJ IDEA (Maven) is an **IntelliJ IDEA Plugin** which lets you create maven projects (i.e. created project contains Aspose.Email for Java API maven dependency) and download source code examples of the API for using <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a>.
- This plugin helps you to work with <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a> inside your favorite IntelliJ IDEA.

![todo:image_alt_text](/java/email/images/7c3e784e32f8fba6-KWKGljg.png)

**WIZARDS**: The plugin contains two wizards --

**Wizard 1:** Aspose.Email Maven Project

- Plugin's **Aspose Maven Project Wizard** lets developers to create <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a> Maven project.
- The reference of <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a> maven dependency is automatically fetched from <a href="https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo" target="_blank" rel="nofollow noopener noreferrer">Aspose Cloud Maven Repository</a> and gets added in the pom.xml.
- The created project will always contain most recent available version Maven Dependency for <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a>.
- The wizard steps also present with the option for downloading <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples for using Aspose.Email for Java API</a>

**Wizard 2:** Aspose.Email Examples

- **Aspose.Email Examples Wizard** lets you create / copy downloaded <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples of Aspose.Email for Java API</a> into your project. All the examples for the selected category will get copied to the project's  "com.aspose.email.examples" package folder along with the required resources within "src/main/resources" folder needed to run the examples.
- <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Source Code Examples of Aspose.Email for Java API</a> are meant for demonstrating the different usages of the API.

## Downloading {#downloading}

### Downloading IntelliJ IDEA {#downloading-intellij-idea}

You will need to first install IntelliJ IDEA CE / UE before downloading the **Aspose.Email Java for IntelliJ IDEA (Maven)** plugin.

To download IntellliJ IDEA

1. Goto <a href="https://www.jetbrains.com/idea/download/" target="_blank" rel="nofollow noopener noreferrer">https://www.jetbrains.com/idea/download/</a>
2. Select your running OS
3. Click on UE or CE download.

### Downloading Aspose.Email Java for IntelliJ IDEA plugin (Maven) {#downloading-asposeemail-java-for-intellij-idea-plugin-maven}

- The plugin can be directly downloaded from the <a href="https://plugins.jetbrains.com/plugin/7982-aspose-email-java-for-intellij-idea-maven/" target="_blank" rel="nofollow noopener noreferrer">JetBrains plugin hosting URL</a> - on IntelliJ IDEA Plugin Repository and later can be installed using the IDE option:
  - Goto **File** &gt; **Settings**…>**Plugins**
  - Select "**Install plugin from Disk"**
- Or it can be directly installed (without manual downloading from JetBrains plugin hosting URL) using the IDE options:
  - Goto **File** &gt; **Settings**…>**Plugins**
  - Select **"Browse Repositories"**
  - In Search Box type: "Aspose"
  - Select "**Aspose.Email Java for IntelliJ IDEA Maven**" plugin to install.

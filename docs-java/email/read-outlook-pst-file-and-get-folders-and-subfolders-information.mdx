:::info
Aspose.Email for Java lets you read Microsoft Outlook PST files. You can load a PST file from disk or stream into an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class and get the information about its contents, for example, folders, subfolders, and messages.
:::

## Load a PST File {#load-a-pst-file}

An Outlook PST file can be loaded into an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class. A code snippet for loading the PST file is given below:

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Load the Outlook PST file
PersonalStorage pst = PersonalStorage.fromFile(dataDir + "PersonalStorage.pst");
```

## Displaying Folders Information {#displaying-folders-information}

After loading the PST file into the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class, you can get the information about the file display name, root folder, subfolders and messages count. The following code snippet displays the name of a PST file, folders and number of messages in the folders:

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Load the Outlook PST file
PersonalStorage pst = PersonalStorage.fromFile(dataDir + "PersonalStorage.pst");

// Get the folders information
FolderInfoCollection folderInfoCollection = pst.getRootFolder().getSubFolders();
// Browse through each folder to display folder name and number of messages
for (int i = 0; i < folderInfoCollection.size(); i++) {
	FolderInfo folderInfo = (FolderInfo) folderInfoCollection.get_Item(i);
	System.out.println("FolderId: " + folderInfo.getEntryIdString());
	System.out.println("Folder: " + folderInfo.getDisplayName());
	System.out.println("Total items: " + folderInfo.getContentCount());
	System.out.println("Total unread items: " + folderInfo.getContentUnreadCount());
	System.out.println("-----------------------------------");
}
```

## Get user-defined folders only {#get-user-defined-folders-only}

A PST/OST files may contain folders that were created by the user. Aspose.Email provides the ability to access only user-defined folders by using the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstoragequerybuilder/#getOnlyFoldersCreatedByUser--" target="_blank" rel="nofollow noopener noreferrer">PersonalStorageQueryBuilder.OnlyFoldersCreatedByUser</a> property. You can set the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstoragequerybuilder/#getOnlyFoldersCreatedByUser--" target="_blank" rel="nofollow noopener noreferrer">PersonalStorageQueryBuilder.OnlyFoldersCreatedByUser</a> property to **true** to get only user-defined folders. The following code snippet demonstrates the use of <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstoragequerybuilder/#getOnlyFoldersCreatedByUser--" target="_blank" rel="nofollow noopener noreferrer">PersonalStorageQueryBuilder.OnlyFoldersCreatedByUser</a> to get user-defined folders.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
PersonalStorage pst = PersonalStorage.fromFile(dataDir + "Outlook.pst");
try {
	PersonalStorageQueryBuilder queryBuilder = new PersonalStorageQueryBuilder();
	queryBuilder.getOnlyFoldersCreatedByUser().equals(true);

	FolderInfoCollection subfolders = pst.getRootFolder().getSubFolders(queryBuilder.getQuery());
	for(FolderInfo folder : subfolders) {
		System.out.println(folder.getDisplayName());
	}
} finally {
	pst.dispose();
}
```

## Checking whether the folder is in a predefined folder {#checking-whether-the-folder-is-in-a-predefined-folder}

When opening and inspecting the folders within a PST (Personal Storage Table) file, you can check whether each folder is a predefined folder type or a subfolder of a predefined folder type, and obtain the information about each folder.

The <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/#getPredefinedType-boolean-" target="_blank" rel="nofollow noopener noreferrer">FolderInfo.getPredefinedType(boolean getForTopLevelParent)</a> method is used to check whether the folder is from <a href="https://reference.aspose.com/email/java/com.aspose.email/standardipmfolder/" target="_blank" rel="nofollow noopener noreferrer">StandardIpmFolder</a>.

If 'getForTopLevelParent' param is true, method returns a StandardIpmFolder enum value for the top-level parent folder. This determines whether the current folder is a subfolder of a predefined folder. If 'getForTopLevelParent' param is false, it returns a StandardIpmFolder enum value for the current folder.

```java
String fileName = "my.pst";

try (PersonalStorage pst = PersonalStorage.fromFile(fileName)) {
    checkFolders(pst.getRootFolder().getSubFolders());
}

private void checkFolders(FolderInfoCollection folders) {
    for (FolderInfo folder : folders) {
        System.out.println("Display Name: " + folder.getDisplayName());

        // Determines whether the current folder is a predefined folder
        int folderType = folder.getPredefinedType(false);
        String answer = folderType == StandardIpmFolder.Unspecified ? "No" : "Yes, " + folderType;
        System.out.println("Is StandardIpmFolder?: " + answer);

        // Determines whether the current folder is a subfolder of a predefined folder
        if (folderType == StandardIpmFolder.Unspecified) {
            folderType = folder.getPredefinedType(true);
            answer = folderType == StandardIpmFolder.Unspecified ? "No" : "Yes, " + folderType;
            System.out.println("Is subfolder from StandardIpmFolder parent?: " + answer);
        }

        System.out.println();

        checkFolders(folder.getSubFolders());
    }
}
```

## Retrieve Subfolder by Path {#retrieve-subfolder-by-path}

The `FolderInfo.getSubFolder(String name, boolean ignoreCase, boolean handlePathSeparator)` overload enables you to retrieve a subfolder with the specified name from the current PST folder.

The method takes the following parameters:

- **name** - specifies the name of the subfolder to retrieve.
- **ignoreCase** - determines whether the search for the subfolder name should be case-sensitive or case-insensitive. If set to `true`, the search is case-insensitive, otherwise it is case-sensitive.
- **handlePathSeparator** - specifies whether the given folder name should be treated as a path if it contains backslashes. If set to `true`, the method interprets the folder name as a path, attempting to navigate to the subfolder using that path. If set to `false`, the method treats the folder name as a simple name, searching for a subfolder with an exact name match.

The following code sample demonstrates how to use this method in your project:

```java
try (PersonalStorage pst = PersonalStorage.fromFile("mailbox.pst")) {
    FolderInfo folder = pst.getRootFolder().getSubFolder("Inbox\\Reports\\Jan", true, true);
    System.out.println(folder.getContainerClass());
}
```

In this sample, the method returns a folder named `Jan` located at the `Inbox\Reports\` path relative to the root folder.

## Get or Add a standard RSS Feeds folder in a PST File {#get-or-add-a-standard-rss-feeds-folder-in-a-pst-file}

Aspose.Email makes it possible to retrieve a reference to the predefined folder that holds RSS feeds. This could be useful if you want to programmatically access and manipulate the RSS feeds stored in an Outlook PST file. Give the value of RssFeeds to the <a href="https://reference.aspose.com/email/java/com.aspose.email/standardipmfolder/" target="_blank" rel="nofollow noopener noreferrer">StandardIpmFolder</a> enum.

The following code example shows how to get an RSS Feeds folder:

```java
try (PersonalStorage pst = PersonalStorage.fromFile("my.pst", false)) {
    FolderInfo rssFolder = pst.getPredefinedFolder(StandardIpmFolder.RssFeeds);
}
```

And the code sample below demonstrates how to add an RSS Feeds folder:

```java
try (PersonalStorage pst = PersonalStorage.create("my.pst", FileFormatVersion.Unicode)) {
    FolderInfo rssFolder = pst.createPredefinedFolder("RSS Feeds", StandardIpmFolder.RssFeeds);
}
```

## Parse Searchable Folders {#parse-searchable-folders}

A PST/OST may contain searchable folders in addition to the normal type of folders. Aspose.Email provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/folderkind/" target="_blank" rel="nofollow noopener noreferrer">FolderKind</a> enumerator for specifying the messages from such search folders with <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/#enumerateFolders--" target="_blank" rel="nofollow noopener noreferrer">EnumerateFolders</a> and <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/#getSubFolders--" target="_blank" rel="nofollow noopener noreferrer">GetSubFolders</a> methods.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
final PersonalStorage pst = PersonalStorage.fromFile(dataDir + "PersonalStorage.pst");

FolderInfo finder = pst.getFolderById("AAAAAOu+OWXNsrFFkK4GgGGmk0yCgAAA");
FolderInfoCollection coll = finder.getSubFolders(FolderKind.Search);
System.out.println(coll.size()); //This should print 17

coll = finder.getSubFolders(FolderKind.Normal);
System.out.println(coll.size()); //This should print 0

coll = finder.getSubFolders(FolderKind.Search | FolderKind.Normal);
System.out.println(coll.size()); //This should print 17
```

## Retrieve Parent Folder Information from MessageInfo {#retrieve-parent-folder-information-from-messageinfo}

The following code snippet shows you how to retrieve parent folder information from <a href="https://reference.aspose.com/email/java/com.aspose.email/messageinfo/" target="_blank" rel="nofollow noopener noreferrer">MessageInfo</a>.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
final PersonalStorage[] pst = { PersonalStorage.fromFile(dataDir + "PersonalStorage.pst") };
try {
	for (FolderInfo folder : (Iterable<FolderInfo>) pst[0].getRootFolder().getSubFolders()) {
		for (MessageInfo msg : (Iterable<MessageInfo>) folder.enumerateMessages()) {
			FolderInfo fi = pst[0].getParentFolder(msg.getEntryId());
		}
	}
} finally {
	if (pst[0] != null)
		((IDisposable) pst[0]).dispose();
}
```

## PST file traversal API {#pst-file-traversal-api}

The traversal API allows extracting all PST items as far as possible, without throwing out exceptions, even if some data of the original file is corrupted. The following steps show how to use this API.

Use <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> constructor and <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#load-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">load</a> method instead of fromFile method.

The constructor allows defining a callback method.

```java
try (PersonalStorage currentPst = new PersonalStorage(new TraversalExceptionsCallback() {
    public void invoke(TraversalAsposeException exception, String itemId) {
        // Exception handling code.
    }
})) {
    //
}
```

Loading and traversal exceptions will be available through the callback method.

The <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#load-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">load</a> method returns 'true' if the file has been loaded successfully and further traversal is possible. If a file is corrupted and no traversal is possible, 'false' is returned.

```java
if (currentPst.load(inputStream))
```

This allows to open and traverse even corrupted PST files without throwing out exceptions. Both exceptions and corrupted items will be handled by the callback method.

```java
try (PersonalStorage pst = new PersonalStorage(new TraversalExceptionsCallback() {
    public void invoke(TraversalAsposeException exception, String itemId) {
        // Exception handling code.
    }
})) {
    if (pst.load("test.pst")) {
        getAllMessages(pst, pst.getRootFolder());
    }
}

private static void getAllMessages(PersonalStorage pst, FolderInfo folder) {
    for (String messageEntryId : folder.enumerateMessagesEntryId()) {
        MapiMessage message = pst.extractMessage(messageEntryId);
    }
    for (FolderInfo subFolder : folder.getSubFolders()) {
        getAllMessages(pst, subFolder);
    }
}
```

## Retrieve Item Category Colors from PST Files {#retrieve-item-category-colors-from-pst-files}

Aspose.Email allows you to retrieve category information, including names and colors, from PST files. Category data can be extracted and matched with individual PST items. Use the following API members:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/outlookcategorycolor/" target="_blank" rel="nofollow noopener noreferrer">OutlookCategoryColor</a> enumeration - represents the color associated with a category.
- <a href="https://reference.aspose.com/email/java/com.aspose.email/pstitemcategory/" target="_blank" rel="nofollow noopener noreferrer">PstItemCategory</a> class - provides the category name and color.
- `PersonalStorage.getCategories()` - retrieves a list of categories with their names and colors.

### Retrieve available Categories from PST {#retrieve-available-categories-from-pst}

```java
try (PersonalStorage pst = PersonalStorage.fromFile("mailbox.pst")) {
    List<PstItemCategory> categories = pst.getCategories();

    for (PstItemCategory category : categories) {
        System.out.println(category.getName() + ": " + category.getColor());
    }
}
```

### Match a Category Name with its Color {#match-a-category-name-with-its-color}

```java
try (PersonalStorage pst = PersonalStorage.fromFile("mailbox.pst")) {
    // Get all categories from the PST
    List<PstItemCategory> availableCategories = pst.getCategories();

    // Extract a message from the PST and retrieve the list of category names for the message
    FolderInfo inbox = pst.getRootFolder().getSubFolder("Inbox");

    for (MessageInfo messageInfo : inbox.enumerateMessages()) {
        com.aspose.email.system.collections.IList messageCategoryList =
                FollowUpManager.getCategories(pst.extractMessage(messageInfo));

        // Iterate through each category of the message and match it with the PST category list
        for (Object messageCategory : messageCategoryList) {
            String name = (String) messageCategory;

            PstItemCategory found = null;
            for (PstItemCategory category : availableCategories) {
                if (category.getName().equalsIgnoreCase(name)) {
                    found = category;
                    break;
                }
            }

            System.out.println(found != null
                    ? found.getName() + ": " + found.getColor()
                    : "Category: " + name + ", Color: Not found");
        }
    }
}
```

:::info
`FollowUpManager.getCategories` returns a `com.aspose.email.system.collections.IList` of strings rather than a typed `List<String>`, so cast each element when reading it.
:::

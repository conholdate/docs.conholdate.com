## Installing {#installing}

### How to Install Aspose.Email Java for IntelliJ IDEA (Maven) {#how-to-install-asposeemail-java-for-intellij-idea-maven}

Steps below demonstrates how to install **Aspose.Email Java for IntelliJ IDEA (Maven)** plugin.

The  plugin is listed on IntelliJ IDEA's CE <a href="https://plugins.jetbrains.com/plugin/7982-aspose-email-java-for-intellij-idea-maven/" target="_blank" rel="nofollow noopener noreferrer">official plugin website</a> - plugin repository as **Aspose.Email Java for IntelliJ IDEA Maven**, so you don't need to download it manually and install it from disk, but this extra option still exists in IntelliJ IDEA.

**Aspose.Email Java for IntelliJ IDEA (Maven)** plugin can be easily installed (without manual downloading) from within IntelliJ IDEA. To do it:

1. Select **Settings** from the **File** menu.
2. Click **Plugins**, then browse the repositories in IntelliJ IDEA.

## Using {#using}

### Aspose.Email Maven Project Wizard {#asposeemail-maven-project-wizard-1}

To create Aspose.Email Maven project for using Aspose.Email for Java API within IntelliJ IDEA, you need to have internet connection.

Then follow the steps below:

1. Select **New Project**.
2. Select **Aspose.Email Maven Project**
3. Click **Next**.

![todo:image_alt_text](/java/email/images/0231048e9cb287c7-L3LFdZL.jpg)

4. Provide a **GroupId, ArtifactId** and **Version** for your maven project and click **Next.**

![todo:image_alt_text](/java/email/images/bbf18d97812a6171-bBR5fp3.jpg)

You can select "Also Download Examples Source Code" checkbox to download the sample usage examples of the API (as shown in above snapshot)

6. Provide a **Project Name** and **Location** just like when creating any Java application

![todo:image_alt_text](/java/email/images/2407795c9175e8ab-HJJQcRA.jpg)

7. Click **Finish**.     This will retrieve the Aspose.Email for Java API latest maven dependency reference from Aspose Cloud Maven Repository and configure it in pom.xml     If you have selected "Also Download Examples Source Code" checkbox. Downloading of the examples will also begin from the <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API GitHub Repository</a>

![todo:image_alt_text](/java/email/images/6eb940afea1b84da-yglB09p.jpg)

![todo:image_alt_text](/java/email/images/a101abdd063b444c-ZEUtDNG.jpg)

Congratulations ! ![circle](/java/email/images/8767981cc4c0a322-times-circle.svg) You have successfully created Aspose.Email Maven project for using Aspose.Email for Java API.

![todo:image_alt_text](/java/email/images/77c2eaa7464a0040-AWPN8cu.jpg)

The created Aspose.Email for Java API Maven project is ready to be modified as per your project's requirements.

If you have opted to download <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Example Source Codes</a>, you can use Aspose.Email Examples wizard to copy / create the downloaded examples into your project.

### Aspose.Email Examples Wizard {#asposeemail-examples-wizard}

To import/ copy <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Example Source Codes</a> into the project using **Aspose.Email Examples Wizard**, you need to first download the examples by opting  "Also Download Examples Source Code" on Aspose.Email Maven Project Wizard.

Then follow the steps below on IntelliJ IDEA:

1. Select **File** &gt; **New -** As shown below:

![todo:image_alt_text](/java/email/images/c4db182456d89e82-N8tT9Q0.jpg)

-OR- **Right Click** (on project window) => **New**  - As shown below:

![todo:image_alt_text](/java/email/images/af9b0d03350ca82d-aUBWkhp.jpg)

2. Select **Aspose.Email Example** Option from Menu - As shown below:

![todo:image_alt_text](/java/email/images/c13cf8ea26f9f465-uMacV7p.jpg)

The wizard will refresh / check for the latest available <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API Examples</a>

![todo:image_alt_text](/java/email/images/10bfff97f5285729-5PZwsuq.jpg)

3. **Aspose.Email Examples wizard** dialog will appear, where you can select any examples category to create / copy the examples into your project     Select any examples category and click **Create** :

![todo:image_alt_text](/java/email/images/e745dc233bbe13f5-oXCbKkV.jpg)

5. This will create / copy  the selected category examples into the project under **com.aspose.email.examples** package.     Also any required resources for the execution of the examples will be copied to **src/main/resources** folder - As shown below:

![todo:image_alt_text](/java/email/images/6f208aee28d94b16-JUpiGJG.jpg)

Congratulations ! ![circle](/java/email/images/8767981cc4c0a322-times-circle.svg) You have successfully done the following:

1\. You' have created Aspose.Email Maven Project using Aspose.Email Maven Project Wizard,

2\. You have downloaded <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API - Example Source Codes</a>

3\. You have created / copied Examples Source Codes into your project by using Aspose.Email Example Wizard.

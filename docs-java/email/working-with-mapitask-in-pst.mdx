## Adding MapiTask to PST {#adding-mapitask-to-pst}

[Create New PST, Add Sub-folders and Messages](/java/email/create-new-pst-add-sub-folders-and-messages/) showed how to create a PST file and add a subfolder to it. With Aspose.Email you can add MapiTask to the Tasks subfolder of a PST file that you have created or loaded.

Below are the steps to add MapiTask to a PST:

1. Create a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> object.
2. Set the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> properties using constructor and different methods.
3. Create a PST using the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#create-java.io.OutputStream-int-" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.create()</a> method.
4. Create a pre-defined folder (Tasks) at the root of the PST file by accessing the Root folder and then calling the <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/#addMapiMessageItem-com.aspose.email.IMapiMessageItem-" target="_blank" rel="nofollow noopener noreferrer">addMapiMessageItem()</a> method.

The code snippet below shows how to create a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> and then add it to the Tasks folder of a newly created PST file.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiTask task = new MapiTask("To Do", "Just click and type to add new task", new Date(), new Date());
task.setPercentComplete(20);
task.setEstimatedEffort(2000);
task.setActualEffort(20);
task.setHistory(MapiTaskHistory.Assigned);
task.setLastUpdate(new Date());
task.getUsers().setOwner("Darius");
task.getUsers().setLastAssigner("Harkness");
task.getUsers().setLastDelegate("Harkness");
task.getUsers().setOwnership(MapiTaskOwnership.AssignersCopy);

PersonalStorage pst = PersonalStorage.create(dataDir + "TaskPST_out.pst", FileFormatVersion.Unicode);
FolderInfo taskFolder = pst.createPredefinedFolder("Tasks", StandardIpmFolder.Tasks);
taskFolder.addMapiMessageItem(task);
```

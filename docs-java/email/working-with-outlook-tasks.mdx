## Creating, Saving and Reading Outlook Tasks {#creating-saving-and-reading-outlook-tasks}

Aspose.Email for Java allows developers to create Outlook tasks and save them as MSG format. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> class provides a number of properties such as <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/#getPercentComplete--" target="_blank" rel="nofollow noopener noreferrer">PercentComplete</a>, <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/#getEstimatedEffort--" target="_blank" rel="nofollow noopener noreferrer">EstimatedEffort</a>, <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/#getActualEffort--" target="_blank" rel="nofollow noopener noreferrer">ActualEffort</a>, <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/#getHistory--" target="_blank" rel="nofollow noopener noreferrer">History</a>, <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/#getLastUpdate--" target="_blank" rel="nofollow noopener noreferrer">LastUpdate</a>, etc., to accommodate and set information required for an Outlook task. This article shows how to create, save and read a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> from disk.

### Create and Save a MapiTask {#create-and-save-a-mapitask}

The following steps can be used to create and save a Task to disk.

1. Instantiate a new object of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> class.
2. Enter information for the task various properties.
3. Save the task to disk in MSG format.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
Calendar calendar = Calendar.getInstance(TimeZone.getTimeZone("GMT"));
calendar.set(2016, Calendar.NOVEMBER, 1, 0, 0, 0);
Date startDate = calendar.getTime();
calendar.set(2016, Calendar.DECEMBER, 1);
Date endDate = calendar.getTime();
MapiTask task = new MapiTask("To Do", "Just click and type to add new task", startDate, endDate);
task.setPercentComplete(20);
task.setEstimatedEffort(2000);
task.setActualEffort(20);
task.setHistory(MapiTaskHistory.Assigned);
task.getUsers().setOwner("Darius");
task.getUsers().setLastAssigner("Harkness");
task.getUsers().setLastDelegate("Harkness");
task.getUsers().setOwnership(MapiTaskOwnership.AssignersCopy);
String[] companies = { "company1", "company2", "company3" };
task.setCompanies(companies);
String[] categories = { "category1", "category2", "category3" };
task.setCategories(categories);
task.setMileage("Some test mileage");
task.setBilling("Test billing information");
task.getUsers().setDelegator("Test Delegator");
task.setSensitivity(MapiSensitivity.Personal);
task.setStatus(MapiTaskStatus.Complete);
task.save(dataDir + "MapiTask_out.msg", TaskSaveFormat.Msg);
```

#### Read a MapiTask {#read-a-mapitask}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> class object is used to cast the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object that loads a task from the disk in MSG format.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiMessage msg = MapiMessage.fromFile(dataDir + "MapiTask_out.msg");
MapiTask task2 = (MapiTask) msg.toMapiMessageItem();
```

#### Read a VToDo Task {#read-a-vtodo-task}

Google Tasks exported in iCalendar format as VToDo events can be loaded using the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> class as shown in the following code sample.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiTask task = MapiTask.fromVTodo(dataDir + "sample.ics");
task.save(dataDir + "Test_out.msg", TaskSaveFormat.Msg);
```

### Add Reminder Information to a MapiTask {#add-reminder-information-to-a-mapitask}

Similar to Microsoft Outlook, Aspose.Email can add reminder information to a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a>. The following code snippet shows you how to add reminder information to a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a>.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
Calendar calendar = Calendar.getInstance(TimeZone.getTimeZone("GMT"));
calendar.set(2012, Calendar.NOVEMBER, 1, 0, 0, 0);
Date date = calendar.getTime();
MapiTask testTask = new MapiTask("task with reminder", "this is a body", date, date);
testTask.setReminderSet(true);
testTask.setReminderTime(date);
testTask.setReminderFileParameter(dataDir + "Alarm01.wav");
testTask.save(dataDir + "OutputTask_out.msg", TaskSaveFormat.Msg);
```

### Add Attachment to a MapiTask {#add-attachment-to-a-mapitask}

The following code snippet shows you how to add attachments to a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a>.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiTask task = new MapiTask("To Do", "Just click and type to add new tasks", new Date(), new Date());
Path p = FileSystems.getDefault().getPath("", dataDir + "Attach.txt");
try
{
    task.getAttachments().add(dataDir + "TestAtt.txt", Files.readAllBytes(p));
}
catch (IOException e)
{
    e.printStackTrace();
}
task.save(dataDir + "MapiTask_out.msg", TaskSaveFormat.Msg);
```

### Add Recurrence to a MapiTask {#add-recurrence-to-a-mapitask}

Aspose.Email allows creating a recurring task where the recurrence can be daily, weekly, monthly, or yearly. The following code snippet shows you how to create a task with different recurrence types:

```java
Date startDate = new GregorianCalendar(2015, java.util.Calendar.APRIL, 30, 10, 0, 0).getTime();
Date endDate = new GregorianCalendar(2015, java.util.Calendar.APRIL, 30, 11, 0, 0).getTime();

MapiTask task = new MapiTask("abc", "def", startDate, endDate);
task.setState(MapiTaskState.NotAssigned);

// Set a daily recurrence
MapiCalendarDailyRecurrencePattern daily = new MapiCalendarDailyRecurrencePattern();
daily.setPatternType(MapiCalendarRecurrencePatternType.Day);
daily.setPeriod(1);
daily.setWeekStartDay(DayOfWeek.Sunday);
daily.setEndType(MapiCalendarRecurrenceEndType.NeverEnd);
daily.setOccurrenceCount(0);

task.setRecurrence(daily);
task.save("AsposeDaily_out.msg", TaskSaveFormat.Msg);

// Set a weekly recurrence
MapiCalendarWeeklyRecurrencePattern weekly = new MapiCalendarWeeklyRecurrencePattern();
weekly.setPatternType(MapiCalendarRecurrencePatternType.Week);
weekly.setPeriod(1);
weekly.setDayOfWeek(MapiCalendarDayOfWeek.Wednesday);
weekly.setEndType(MapiCalendarRecurrenceEndType.NeverEnd);
weekly.setOccurrenceCount(0);

task.setRecurrence(weekly);
task.save("AsposeWeekly_out.msg", TaskSaveFormat.Msg);

// Set a monthly recurrence
MapiCalendarMonthlyRecurrencePattern monthly = new MapiCalendarMonthlyRecurrencePattern();
monthly.setPatternType(MapiCalendarRecurrencePatternType.Month);
monthly.setPeriod(1);
monthly.setDay(30);
monthly.setEndType(MapiCalendarRecurrenceEndType.NeverEnd);
monthly.setOccurrenceCount(0);
monthly.setWeekStartDay(DayOfWeek.Sunday);

task.setRecurrence(monthly);
task.save("AsposeMonthly_out.msg", TaskSaveFormat.Msg);

// Set a yearly recurrence - a monthly pattern repeated every 12 months
MapiCalendarMonthlyRecurrencePattern yearly = new MapiCalendarMonthlyRecurrencePattern();
yearly.setPatternType(MapiCalendarRecurrencePatternType.Month);
yearly.setPeriod(12);
yearly.setEndType(MapiCalendarRecurrenceEndType.NeverEnd);
yearly.setOccurrenceCount(10);

task.setRecurrence(yearly);
task.save("AsposeYearly_out.msg", TaskSaveFormat.Msg);
```

### Converting Outlook Task to MHT {#converting-outlook-task-to-mht}

Aspose.Email can generate <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> like output during the conversion of a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapitask/" target="_blank" rel="nofollow noopener noreferrer">MapiTask</a> to MHT.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
String dataDir = Utils.getSharedDataDir(CreateAndSaveOutlookMessageFile.class) + "outlook/";
		
MapiMessage msg = MapiMessage.fromFile(dataDir + "MapiTask.msg");
MhtSaveOptions opt = SaveOptions.getDefaultMhtml();
opt.setMhtFormatOptions(MhtFormatOptions.RenderTaskFields | MhtFormatOptions.WriteHeader);

opt.getFormatTemplates().clear();
opt.getFormatTemplates().add(MhtTemplateName.Task.SUBJECT, "<span class='headerLineTitle'>Subject:</span><span class='headerLineText'>{0}</span><br/>");
opt.getFormatTemplates().add(MhtTemplateName.Task.ACTUAL_WORK, "<span class='headerLineTitle'>Actual Work:</span><span class='headerLineText'>{0}</span><br/>");
opt.getFormatTemplates().add(MhtTemplateName.Task.TOTAL_WORK, "<span class='headerLineTitle'>Total Work:</span><span class='headerLineText'>{0}</span><br/>");
opt.getFormatTemplates().add(MhtTemplateName.Task.STATUS, "<span class='headerLineTitle'>Status:</span><span class='headerLineText'>{0}</span><br/>");
opt.getFormatTemplates().add(MhtTemplateName.Task.OWNER, "<span class='headerLineTitle'>Owner:</span><span class='headerLineText'>{0}</span><br/>");
opt.getFormatTemplates().add(MhtTemplateName.Task.PRIORITY, "<span class='headerLineTitle'>Priority:</span><span class='headerLineText'>{0}</span><br/>");

msg.save(dataDir + "MapiTask_out.mht", opt);
```

## MSG to HTML Conversion Preserving Task Fields {#msg-to-html-conversion-preserving-task-fields}

The `HtmlFormatOptions.RenderTaskFields` value allows you to specify that task fields should be included in the header of the saved HTML file. The following code snippet shows how to preserve task fields in the header when saving an HTML file:

```java
MapiMessage msg = MapiMessage.load("task.msg");

HtmlSaveOptions opt = SaveOptions.getDefaultHtml();
opt.setHtmlFormatOptions(HtmlFormatOptions.WriteHeader | HtmlFormatOptions.RenderTaskFields);

msg.save("task.html", opt);
```

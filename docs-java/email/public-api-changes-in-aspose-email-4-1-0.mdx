## Added Enumeration Members {#added-enumeration-members}

### MhtFormatOptions Enumeration with Members WriteCompleteEmailAddressToMht and HideExtraPrintHeader {#mhtformatoptions-enumeration-with-members-writecompleteemailaddresstomht-and-hideextraprintheader}

Provides control of whether the top header is visible in MHT output. The <a href="https://apireference.aspose.com/email/java/com.aspose.email/MhtFormatOptions" target="_blank" rel="nofollow noopener noreferrer">MhtMessageFormatter</a>.format(<a href="https://apireference.aspose.com/email/java/com.aspose.email.class-use/MailMessage" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> message, Boolean writeCompleteEmailAddress) method is marked as deprecated. Use the <a href="https://apireference.aspose.com/email/java/com.aspose.email/MhtFormatOptions" target="_blank" rel="nofollow noopener noreferrer">MhtMessageFormatter</a>.format(<a href="https://apireference.aspose.com/email/java/com.aspose.email.class-use/MailMessage" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> message, int formatOptions) method instead.

### MailMessageSaveOptions.HideExtraPrintHeader Enumeration Member {#mailmessagesaveoptionshideextraprintheader-enumeration-member}

The <a href="https://apireference.aspose.com/email/java/com.aspose.email/SaveOptions" target="_blank" rel="nofollow noopener noreferrer">MailMessageSaveOptions</a>.HideExtraPrintHeader enumeration member provides control of the top header visibility in MHT output.
:::

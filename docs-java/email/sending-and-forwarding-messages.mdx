## Sending Emails Synchronously {#sending-emails-synchronously}

An email message can be sent synchronously using the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#send-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">send</a> method. It sends the specified email message through an SMTP server for delivery. The message sender, recipients, subject, and message body are specified using String objects. To send an email message synchronously, follow the steps given below:

1. Create an instance of <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class and set its properties.
2. Create an instance of <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class and specify the Host, port, username & Password.
3. Send the Message using the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#send-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">send</a> method and pass the <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> instance.

The following Java code snippet shows you how to send outlook emails synchronously.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java

// Declare msg as MailMessage instance
MailMessage msg = new MailMessage();

// Create an instance of SmtpClient class
SmtpClient client = new SmtpClient();

// Specify your mailing host server, Username, Password, Port # and Security option
client.setHost("mail.server.com");
client.setUsername("username");
client.setPassword("password");
client.setPort(587);
client.setSecurityOptions(SecurityOptions.SSLExplicit);

try {
    // Client.Send will send this message
    client.send(msg);
    System.out.println("Message sent");
} catch (Exception ex) {
    System.err.println(ex);
}
```

## Sending Emails Asynchronously {#sending-emails-asynchronously}

Sometimes, you may want to send mail asynchronously. For example, if you are sending a lot of mail through your application, the synchronous approach might not work. In such a scenario, you can use <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a>. The <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> method of the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class sends an email message to an SMTP server for delivery. This method does not block the calling thread and allows the caller to pass an object to the method that is invoked when the operation completes. To send an outlook email message asynchronously in Java, follow these steps:

1. Create an instance of <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> class and use its different properties.
2. Create an instance of <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class and specify the host, port, username, and password.
3. Create a user-defined instance that will be passed to the method and invoked when the asynchronous operation completes.
4. Send the message using <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> method of <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class and pass the <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> instance and user-defined instance in it along with a callback function to be called when the operation is completed.

To receive a notification when the email has been sent or the operation has been canceled, the callback function passed to the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> method is called. After calling the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> method it is not necessary to wait for an email message to be sent completely. We can call another method <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> at the same time. When an email has been sent using the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#beginSend-com.aspose.email.IConnection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">beginSend</a> method, the code snippet prints a message ("Message Sent"). The following Java program or code snippet shows you how to send emails asynchronously.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java

public static void run() {
    sendMail();
}

static SmtpClient getSmtpClient() {
    SmtpClient client = new SmtpClient();
    client.setHost("mail.server.com");
    // Specify your mail Username, Password, Port # and security option
    client.setUsername("username");
    client.setPassword("password");
    client.setPort(587);
    client.setSecurityOptions(SecurityOptions.SSLExplicit);
    return client;
}

static void sendMail() {
    try {

        // Declare msg as MailMessage instance
        MailMessage msg = new MailMessage("sender@gmail.com", "receiver@gmail.com", "Test subject", "Test body");
        SmtpClient client = getSmtpClient();
        Object state = new Object();
        IAsyncResult ar = client.beginSend(msg, callback, state);
        // If the user canceled the send, and mail hasn't been sent yet,
        client.cancelAsyncOperation(ar);

        msg.dispose();
        System.out.println("Goodbye.");
    } catch (Exception ex) {
        System.err.println(ex);
    }
}

static AsyncCallback callback = new AsyncCallback() {
    public void invoke(IAsyncResult ar) {
        IAsyncResultExt task = null;
        if (ar instanceof IAsyncResult)
            task = (IAsyncResultExt) ar;

        if (task != null && task.isCanceled()) {
            System.out.println("Send canceled.");
        }

        if (task != null && task.getErrorInfo() != null) {
            System.out.println(task.getErrorInfo());
        } else {
            System.out.println("Message Sent.");
        }
    }
};
```

## Sending Bulk Emails {#sending-bulk-emails}

## Get Information about Bulk Messages Sent {#get-information-about-bulk-messages-sent}

When you send messages in bulk, you can get information about the number of successfully sent messages and the list of these messages. The <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#setSucceededSending-com.aspose.ms.System.EventHandler-com.aspose.email.MailMessageEventArgs--" target="_blank" rel="nofollow noopener noreferrer">SucceededSending</a> event is used for this purpose.

The code sample below shows how to get information about the number of successfully sent messages:

```java
try (SmtpClient client = new SmtpClient(host, SecurityOptions.Auto)) {
    final AtomicInteger messageCount = new AtomicInteger(0);

    client.setSucceededSending(new EventHandler<MailMessageEventArgs>() {
        public void invoke(Object sender, MailMessageEventArgs eventArgs) {
            System.out.println("The message " + eventArgs.getMessage().getSubject() + " was successfully sent.");
            messageCount.incrementAndGet();
        }
    });

    client.send(messages);

    System.out.println(messageCount + " messages were successfully sent.");
}
```

## Sending Emails with MultiConnection {#sending-emails-with-multiconnection}

<a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> provides a <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#setUseMultiConnection-int-" target="_blank" rel="nofollow noopener noreferrer">UseMultiConnection</a> property which can be used to create multiple connections for heavy operations. You may also set the number of connections to be used during multiconnection mode by using <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#setConnectionsQuantity-int-" target="_blank" rel="nofollow noopener noreferrer">SmtpClient.ConnectionsQuantity</a>. The following code snippet demonstrates the use of the multiconnection mode for sending multiple messages.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java

SmtpClient smtpClient = new SmtpClient();
smtpClient.setHost("<HOST>");
smtpClient.setUsername("<USERNAME>");
smtpClient.setPassword("<PASSWORD>");
smtpClient.setPort(587);
smtpClient.setSupportedEncryption(EncryptionProtocols.Tls);
smtpClient.setSecurityOptions(SecurityOptions.SSLExplicit);

List<MailMessage> messages = new ArrayList<MailMessage>();
for (int i = 0; i < 20; i++) {
    MailMessage message = new MailMessage("<EMAIL ADDRESS>", "<EMAIL ADDRESS>", "Test Message - " + UUID.randomUUID().toString(),
            "SMTP Send Messages with MultiConnection");
    messages.add(message);
}

smtpClient.setConnectionsQuantity(5);

```

## Forward an Email using SMTP Client {#forward-an-email-using-smtp-client}

### Forwarding Email with SMTP client {#forwarding-email-with-smtp-client}

Forwarding an email is a common practice in daily life digital communication. An email received can be forwarded to specific recipients without sharing with the original senders. Aspose.Email API <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> provides the capability to forward an email to specific recipients. Its <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/#forward-java.lang.String-com.aspose.email.MailAddressCollection-com.aspose.email.MailMessage-" target="_blank" rel="nofollow noopener noreferrer">Forward</a> method can be used to forward a received or saved email to desired recipients as shown in this article. The following code snippet shows you how to forward an email using SMTP Client.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java

// Specify your mailing host server, Username, Password, Port and SecurityOptions

client.setPassword("password");
client.setPort(587);
client.setSecurityOptions(SecurityOptions.SSLExplicit);
MailMessage message = MailMessage.load(dataDir + "Message.eml");
client.forward("Recipient1@domain.com", "Recipient2@domain.com", message);
```

5. 14. In the sample below, #FirstName# indicates a <a href="https://reference.aspose.com/email/java/com.aspose.email/datatable/" target="_blank" rel="nofollow noopener noreferrer">DataTable</a> column, whose value is set by the user. The following code snippet shows you how to perform Mail Merge.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
public static void run() {
    // The path to the File directory.
    String dstEmail = dataDir + "EmbeddedImage.msg";

    // Create a new MailMessage instance
    MailMessage msg = new MailMessage();

    // Add subject and from address
    msg.setSubject("Hello, #FirstName#");
    msg.setFrom(MailAddress.to_MailAddress("sender@sender.com"));

    // Add email address to send email also Add mesage field to HTML body
    msg.getTo().add("your.email@gmail.com");
    String htmlBody = "Your message here/r/n" + "Thank you for your interest in <STRONG>Aspose.Email</STRONG>.";

    // Use GetSignment as the template routine, which will provide the same signature
    htmlBody += "<br><br>Have fun with it.<br><br>#GetSignature()#";

    msg.setHtmlBody(htmlBody);

    // Create a new TemplateEngine with the MSG message, Register GetSignature routine. It will be used in MSG.
    TemplateEngine engine = new TemplateEngine(msg);
    engine.registerRoutine("GetSignature", new TemplateRoutine() {
        public Object invoke(Object[] args) {
            return getSignature(args);
        }
    });

    // Create an instance of DataTable and Fill a DataTable as data source
    DataTable dt = new DataTable();
    dt.getColumns().add("Receipt");
    dt.getColumns().add("FirstName");
    dt.getColumns().add("LastName");

    DataRow dr;
    dr = dt.newRow();
    dr.set("Receipt", "Nancy&lt;Nancy@somedomain.com&gt;");
    dr.set("FirstName", "Nancy");
    dr.set("LastName", "Doe");
    dt.getRows().add(dr);
    dr = dt.newRow();
    dr.set("Receipt", "Andrew&lt;Andrew@somedomain.com&gt;");
    dr.set("FirstName", "Andrew");
    dr.set("LastName", "Doe");
    dt.getRows().add(dr);
    dr = dt.newRow();
    dr.set("Receipt", "Janet&lt;Janet@somedomain.com&gt;");
    dr.set("FirstName", "Janet");
    dr.set("LastName", "Doe");
    dt.getRows().add(dr);

    MailMessageCollection messages;
    try {
        // Create messages from the message and datasource.
        messages = engine.instantiate(dt);

        // Create an instance of SmtpClient and specify server, port, username and password
        SmtpClient client = new SmtpClient("smtp.gmail.com", 587, "your.email@gmail.com", "your.password");
        client.setSecurityOptions(SecurityOptions.Auto);

        // Send messages in bulk
        client.send(messages);
    } catch (MailException ex) {
        System.err.println(ex);
    }

    catch (SmtpException ex) {
        System.err.println(ex);
    }

    System.out.println("Message sent after performing mail merge.");
}

// Template routine to provide signature
static Object getSignature(Object[] args) {
    return "Aspose.Email Team<br>Aspose Ltd.<br>" + new Date().toString();
}
```

## Use an Office Document as the Message Body {#use-an-office-document-as-the-message-body}

An Office document rendered to HTML or MHTML makes a rich, ready-to-send message body. Aspose.Email itself does not read Office formats, so the document is converted first with the matching Aspose product and the result is handed over to a <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a>.

### Use a Microsoft Word Document as the Message Body {#use-a-microsoft-word-document-as-the-message-body}

Load the document with <a href="https://products.aspose.com/words/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Words for Java</a>, save it to a stream as MHTML, and load that stream into a MailMessage. See [Using a Microsoft Word Document as the Message Body and Sending Email](/java/email/using-a-microsoft-word-document-as-the-message-body-and-sending-email/) for the complete walkthrough.

### Use a Microsoft Excel Worksheet as the Message Body {#use-a-microsoft-excel-worksheet-as-the-message-body}

This example uses <a href="https://products.aspose.com/cells/java/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Cells for Java</a> to load an Excel workbook and convert it to HTML. Aspose.Email then uses the HTML as the body of a <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> and sends it through SMTP.

1. Load a Microsoft Excel workbook using the Aspose.Cells `Workbook` class.
2. Save the loaded workbook to a stream in HTML format.
3. Read the HTML from the stream as a string.
4. Create a new <a href="https://reference.aspose.com/email/java/com.aspose.email/mailmessage/" target="_blank" rel="nofollow noopener noreferrer">MailMessage</a> object and set its HTML body to the HTML content.
5. Send the email using the <a href="https://reference.aspose.com/email/java/com.aspose.email/smtpclient/" target="_blank" rel="nofollow noopener noreferrer">SmtpClient</a> class.

```java
// Load the desired workbook from disk
com.aspose.cells.Workbook workbook = new com.aspose.cells.Workbook("Data.xlsx");

// Save the workbook to a memory stream in HTML format
ByteArrayOutputStream ms = new ByteArrayOutputStream();
workbook.save(ms, com.aspose.cells.SaveFormat.HTML);

// Load the saved HTML into a string variable
String strHtmlBody = new String(ms.toByteArray(), StandardCharsets.UTF_8);

// Define a new MailMessage object and set its HTML body
MailMessage message = new MailMessage();
message.setHtmlBody(strHtmlBody);
message.setSubject("Inline Excel Message");
message.setFrom(new MailAddress("sender@abc.com"));
message.getTo().add("receiver@xyz.com");

try (SmtpClient client = new SmtpClient("smtp.gmail.com", 587, "Username", "Password")) {
    client.setSecurityOptions(SecurityOptions.Auto);
    client.send(message);
}
```

:::info
The fully qualified `com.aspose.cells.*` names are used deliberately, because `SaveFormat` exists in both Aspose.Cells and Aspose.Email.
:::

:::info
The `DnsClient` class used in the Aspose.Email for .NET *Send Mail Using DNS* sample, which delivers a message straight to the MX hosts of the recipient's domain, is not part of Aspose.Email for Java. Resolve the MX records with the JDK (`javax.naming.directory.InitialDirContext`) or another DNS library, then point `SmtpClient` at the resolved host on port 25.
:::

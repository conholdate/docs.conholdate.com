The <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class allows applications to manage IMAP mailboxes using the IMAP protocol. The <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class is used to connect to IMAP mail servers and manage emails in the IMAP email folders. To connect to an IMAP server

1. Create an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class.
2. Specify the hostname, username, and password in the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient constructor</a>.

Once the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> instance is initiated, the next call to any operation using this instance will connect to the server. The following code snippet shows you how to connect to an IMAP server using the steps above.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Create an imapclient with host, user and password
ImapClient client = new ImapClient("localhost", "user", "password");
```

## Connecting with SSL Enabled IMAP Server {#connecting-with-ssl-enabled-imap-server}

[Connecting with IMAP Server](/java/email/connecting-to-imap-server/) described how to connect to an IMAP server in four simple steps:

1. Create an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class.
2. Specify the hostname, username, and password.
3. Specify the port.
4. Specify the <a href="https://reference.aspose.com/email/java/com.aspose.email/securityoptions/" target="_blank" rel="nofollow noopener noreferrer">Security Options</a>.

The process for connecting to an SSL enabled IMAP server is similar but requires that you set another few properties:

- Set <a href="https://reference.aspose.com/email/java/com.aspose.email/securityoptions/" target="_blank" rel="nofollow noopener noreferrer">Security Options</a> to SSLImplicit.

The following code snippet shows how to

1. Set a username, password, and port.
2. Set security option.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Create an instance of the ImapClient class
ImapClient client = new ImapClient("imap.domain.com", 993, "user@domain.com", "pwd");

// Set the security mode to implicit
client.setSecurityOptions(SecurityOptions.SSLImplicit);
```

## Connecting to Server via Proxy {#connecting-to-server-via-proxy}

Proxy servers are commonly used to communicate with the outside world. In such cases, mail clients are not able to communicate over the Internet without specifying the proxy address. Aspose.Email provides support for versions 4, 4a and 5 of the SOCKS proxy protocol. This article provides a working sample of accessing the mailbox using a proxy mail server. To access the mailbox via a proxy server:

1. Initialize <a href="https://reference.aspose.com/email/java/com.aspose.email/socksproxy/" target="_blank" rel="nofollow noopener noreferrer">SocksProxy</a> with the required information, that is proxy address, port, and SOCKS version.
2. Initialize <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> with host address, user name, password, and any other settings.
3. Set the client <a href="https://reference.aspose.com/email/java/com.aspose.email/socksproxy/" target="_blank" rel="nofollow noopener noreferrer">SocksProxy</a> property to the <a href="https://reference.aspose.com/email/java/com.aspose.email/socksproxy/" target="_blank" rel="nofollow noopener noreferrer">SocksProxy</a> object created above.

The following code snippet shows you how to retrieve mailbox via a proxy server.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Connect and log in to IMAP and set SecurityOptions
ImapClient client = new ImapClient("imap.domain.com", "username", "password");
client.setSecurityOptions(SecurityOptions.Auto);

String proxyAddress = "192.168.203.142"; // proxy address
int proxyPort = 1080; // proxy port
SocksProxy proxy = new SocksProxy(proxyAddress, proxyPort, SocksVersion.SocksV5);

// Set the proxy
client.setProxy(proxy);

try {
    client.selectFolder("Inbox");
} catch (java.lang.RuntimeException ex) {
    System.out.println(ex.getMessage());
}
```

## Customize Authentication Mechanism {#customize-authentication-mechanism}

Retrieve the list of authentication mechanisms that are supported by the IMAP server using the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#getSupportedAuthentication--" target="_blank" rel="nofollow noopener noreferrer">getSupportedAuthentication</a> method of the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class. This method allows the client to determine which authentication methods are available for establishing a secure connection with the server. Then, using the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#setAllowedAuthentication-long-" target="_blank" rel="nofollow noopener noreferrer">setAllowedAuthentication</a> method which gets (or sets) enumeration of the authentication types allowed by user, choose the most appropriate authentication mechanism for the client-server communication. This allows you to set the authentication method for the mail client explicitly.

The following code sample shows how to customize email client authentication:

```java
imapClient.setAllowedAuthentication(ImapKnownAuthenticationType.Plain);
```

## Connecting to Server in Read-Only mode {#connecting-to-server-in-read-only-mode}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> class provides a <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#setReadOnly-boolean-" target="_blank" rel="nofollow noopener noreferrer">ReadOnly</a> property which when set to **true**, indicates that no changes should be made to the permanent state of the mailbox. The following code sample demonstrates the use of <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#setReadOnly-boolean-" target="_blank" rel="nofollow noopener noreferrer">ImapClient.ReadOnly</a> property. It gets the count of unread messages, then fetches one message and then gets the count of unread messages again in read-only mode. The count of the unread messages remains the same indicating that the permanent state of the mailbox was not changed.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
ImapClient imapClient = new ImapClient();
imapClient.setHost("<HOST>");
imapClient.setPort(993);
imapClient.setUsername("<USERNAME>");
imapClient.setPassword("<PASSWORD>");
imapClient.setSupportedEncryption(EncryptionProtocols.Tls);
imapClient.setSecurityOptions(SecurityOptions.SSLImplicit);

ImapQueryBuilder imapQueryBuilder = new ImapQueryBuilder();
imapQueryBuilder.hasNoFlags(ImapMessageFlags.isRead()); /* get unread messages. */
MailQuery query = imapQueryBuilder.getQuery();

imapClient.setReadOnly(true);
imapClient.selectFolder("Inbox");
ImapMessageInfoCollection messageInfoCol = imapClient.listMessages(query);
System.out.println("Initial Unread Count: " + messageInfoCol.size());
if (messageInfoCol.size() > 0) {
    imapClient.fetchMessage(messageInfoCol.get_Item(0).getSequenceNumber());

    messageInfoCol = imapClient.listMessages(query);
    // This count will be equal to the initial count
    System.out.println("Updated Unread Count: " + messageInfoCol.size());
} else {
    System.out.println("No unread messages found");
}
```

## Validate Mail Server Credentials Without Sending Email {#validate-mail-server-credentials-without-sending-email}

Sometimes it is necessary to verify credentials without sending an email. Aspose.Email provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#validateCredentials--" target="_blank" rel="nofollow noopener noreferrer">validateCredentials()</a> method to perform this operation. If the validation is successful, the code inside the if statement is executed, typically used to perform further actions or retrieve data from the IMAP server. The following code snippet demonstrates the validation of credentials without sending an email:

```java
try (ImapClient imapClient = new ImapClient(
        server.ImapUrl, server.ImapPort, "username", "password", SecurityOptions.Auto)) {
    imapClient.setTimeout(4000);

    if (imapClient.validateCredentials()) {
        // to do something
    }
}
```

## How to Restrict Greeting Timeout {#how-to-restrict-greeting-timeout}

The IMAP client may use the automatic mode to establish a connection. In this mode, the IMAP client goes through all possible connection parameters until the connection is established. An IMAP server in case of the correct connection sends a greeting string to the client. Servers may use implicit or explicit (START TLS) SSL/TLS connection initiation. If connection mode is mismatched (for instance, the server waits for an implicit SSL connection but the client tries to establish a non-secured or explicit SSL connection), the server won't send a greeting string and the user will wait a long time until the timeout reaches a greeting string, and the client goes to the next connection option. To avoid this problem, the GreetingTimeout has been introduced. This property allows you to set the timeout for the greeting string, and reduce the time of automatic connection establishment.

```java
ImapClient imapClient = new ImapClient();
imapClient.setGreetingTimeout(4000);
```

## Using Cryptographic Protocols with IMAP {#using-cryptographic-protocols-with-imap}

Aspose.Email supports SSL (obsolete) and TLS cryptographic protocols to provide communications security. You can enable cryptographic encryption to protect data exchange between your application and mail servers.

The supported values are listed in the <a href="https://reference.aspose.com/email/java/com.aspose.email/encryptionprotocols/" target="_blank" rel="nofollow noopener noreferrer">EncryptionProtocols</a> enumeration: `Ssl2`, `Ssl3`, `Tls`, `Tls11`, `Tls12` and `Tls13`. Values can be combined with the bitwise OR operator.

\{% alert color="primary" %\} Set only those versions of the protocol that are supported by your JRE. If a version is not supported, it is ignored and skipped, and no exception is generated. Use the `setSupportedEncryptionUnsafe` method if you want to set the protocols without any compatibility checks: `setSupportedEncryption` downgrades the encryption protocol to a supported level, while `setSupportedEncryptionUnsafe` throws an exception instead. \{% /alert %\}

The code example below shows you how to set TLS 1.3 for a <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> instance.

```java
try (ImapClient imapClient = new ImapClient("host", 993, "username", "password", SecurityOptions.SSLImplicit)) {
    imapClient.setSupportedEncryption(EncryptionProtocols.Tls13);

    // some code...
}
```

To allow more than one protocol version, combine the flags:

```java
try (ImapClient imapClient = new ImapClient("host", 993, "username", "password", SecurityOptions.SSLImplicit)) {
    imapClient.setSupportedEncryption(EncryptionProtocols.Tls12 | EncryptionProtocols.Tls13);

    // some code...
}
```

## Enable Activity Logging {#enable-activity-logging}

Activity logging is used for debugging, as well as for collecting and analyzing working information about the IMAP client. In Aspose.Email for Java, logging is configured in code through the properties inherited from the <a href="https://reference.aspose.com/email/java/com.aspose.email/emailclient/" target="_blank" rel="nofollow noopener noreferrer">EmailClient</a> class:

- `setEnableLogger(boolean)` - turns the logging on and off.
- `setLogFileName(String)` - specifies the relative or absolute path to the log file. The overload `setLogFileName(String, boolean)` also lets you append to an existing file instead of overwriting it.
- `setUseDateInLogFileName(boolean)` - adds the current date to the log file name, so that a separate file is written for every day.
- `resetLogSettings()` - restores the default logging settings.
- `EmailClient.setShowCredentialsInLog(boolean)` - a static switch that controls whether credentials appear in the log. Keep it disabled in production.

```java
try (ImapClient imapClient = new ImapClient("host", 993, "username", "password", SecurityOptions.SSLImplicit)) {
    // Never write credentials into the log file
    EmailClient.setShowCredentialsInLog(false);

    imapClient.setEnableLogger(true);
    imapClient.setUseDateInLogFileName(true);
    imapClient.setLogFileName("logs/imap.log");

    // some code...
}
```

\{% alert color="primary" %\} The `appsettings.json` and `App.config` configuration options described in the Aspose.Email for .NET documentation do not apply to Java - enable logging in code as shown above. \{% /alert %\}

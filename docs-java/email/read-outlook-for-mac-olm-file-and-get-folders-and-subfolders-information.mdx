:::info
Aspose.Email for Java allows you to read Outlook for Mac OLM files. You can load an OLM file from disk into an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class and get the information about its contents, for example, folders, subfolders, and messages.
:::

## Open OLM format files {#open-olm-format-files}

OLM format files can be opened in two ways:

- using constructor
- using static FromFile method

There are differences in behavior between these methods. See section below.

### Open files by constructor {#open-files-by-constructor}

To open a file, call constructor of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class and pass full file name or stream as an argument to it:

```java
OlmStorage olm = new OlmStorage("fileName");
```

### Open files using static method FromFile {#open-files-using-static-method-fromfile}

To open a file, use static method <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#fromFile-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">fromFile</a> and pass full file name as an argument to it:

```java
OlmStorage olm = OlmStorage.fromFile("fileName");
```

### Open files using static method FromStream {#open-files-using-static-method-fromstream}

To open a file using static method <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#fromStream-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">fromStream</a>, pass a stream name as an argument to it:

## Read OLM file {#read-olm-file}

The following code snippet shows you how to load the OLM file and get its content.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java

OlmStorage storage = new OlmStorage(dataDir + "OutlookforMac.olm");
try {
    for (OlmFolder folder : storage.getFolderHierarchy()) {
        if (folder.hasMessages()) {
            // extract messages from folder
            for (MapiMessage msg : storage.enumerateMessages(folder)) {
            	System.out.println("Subject: " + msg.getSubject());
            }
        }

        // read sub-folders
        if (folder.getSubFolders().size() > 0) {
            for (OlmFolder subFolder : folder.getSubFolders()) {
            	System.out.println("Subfolder: " + subFolder.getName());
            }
        }
    }
} finally {
    storage.dispose();
}
```

## Get folders {#get-folders}

To retrieve folders from an OLM (Outlook for Mac) file, load it with the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class first, and then use one of the following methods depending on your needs:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#getFolder-java.lang.String-boolean-" target="_blank" rel="nofollow noopener noreferrer">getFolder(String name, boolean ignoreCase)</a> - Gets the folder by name.
- <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#getFolders--" target="_blank" rel="nofollow noopener noreferrer">getFolders()</a> - Gets the folder hierarchy/collection of folders.
- <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#getFolderHierarchy--" target="_blank" rel="nofollow noopener noreferrer">getFolderHierarchy()</a> - Gets the folder hierarchy.

The code sample below will show you how to get a folder from an OLM file:

```java
// Get the folder by name
OlmStorage olm = OlmStorage.fromFile("fileName");

try {

    OlmFolder inbox = olm.getFolder("inbox", true);

} finally {

    olm.dispose();

}
```

When using the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#fromFile-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">fromFile</a> method to open an OLM file, the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#getFolderHierarchy--" target="_blank" rel="nofollow noopener noreferrer">getFolderHierarchy()</a> will return null. In this case, call the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#getFolders--" target="_blank" rel="nofollow noopener noreferrer">getFolders()</a> method explicitly to retrieve the list of directories in the OLM file.

### Get Folder Path {#get-folder-path}

You may also get the folder path of folders in the OML file. Aspose.Email provides <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/#getPath--" target="_blank" rel="nofollow noopener noreferrer">OlmFolder.Path</a> property which returns the folder path. The following code snippet demonstrates the use of <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/#getPath--" target="_blank" rel="nofollow noopener noreferrer">OlmFolder.Path</a> property to get the folder paths in the OML file.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
public static void main(String[] args) {
	OlmStorage storage = new OlmStorage(dataDir + "SampleOLM.olm");
	PrintPath(storage, storage.getFolderHierarchy());
}

public static void PrintPath(OlmStorage storage, List<OlmFolder> folders) {
	for (OlmFolder folder : folders) {
		// print the current folder path
		System.out.println(folder.getPath());

		if (folder.getSubFolders().size() > 0) {
			PrintPath(storage, folder.getSubFolders());
		}
	}
}
```

### Count the number of items in the folder {#count-the-number-of-items-in-the-folder}

You may also count the number of items in the folder. Aspose.Email provides <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/#getMessageCount--" target="_blank" rel="nofollow noopener noreferrer">OlmFolder.MessageCount</a> property which returns the number of items in the folder. The following code snippet demonstrates the use of <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/#getMessageCount--" target="_blank" rel="nofollow noopener noreferrer">OlmFolder.MessageCount</a> property to get the number of items in the folders of the OML file.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
public static void main(String[] args) {
	OlmStorage storage = new OlmStorage(dataDir + "SampleOLM.olm");
	PrintMessageCount(storage.getFolderHierarchy());
}

public static void PrintMessageCount(List<OlmFolder> folders) {
	for (OlmFolder folder : folders) {
		// print the current folder path
		System.out.println("Message Count [" + folder.getName() + "]: " + folder.getMessageCount());
	}
}
```

### Check Whether a Folder Has Messages {#check-whether-a-folder-has-messages}

The `OlmFolder.hasMessages()` method indicates whether a folder contains any messages, and `OlmFolder.getMessageCount()` returns how many.

```java
try (OlmStorage olm = OlmStorage.fromFile("storage.olm")) {
    OlmFolder folder = olm.getFolder("Inbox", true);

    if (folder.hasMessages()) {
        System.out.println("Message count: " + folder.getMessageCount());
    }
}
```

### Get the Total Number of Items in the Storage {#get-the-total-number-of-items-in-the-storage}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class has a `getTotalItemsCount()` method that returns the total number of message items contained in the whole OLM storage:

```java
try (OlmStorage olm = new OlmStorage("storage.olm")) {
    int count = olm.getTotalItemsCount();
    System.out.println("Total items: " + count);
}
```

## Enumerate Messages from a given Folder {#enumerate-messages-from-a-given-folder}

Aspose.Email provides the API to work with OLM storages and extract messages from a given folder. The <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/" target="_blank" rel="nofollow noopener noreferrer">OlmFolder</a> and <a href="https://reference.aspose.com/email/java/com.aspose.email/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> classes represent brief information about a folder and a message in the storage respectively. The <a href="https://reference.aspose.com/email/java/com.aspose.email/olmfolder/" target="_blank" rel="nofollow noopener noreferrer">OlmFolder</a> class provides the following methods:

- **OlmFolder.getSubFolder**(String subfolderName, boolean ignoreCase) - Gets the subfolder by name.

- **OlmFolder.enumerateMapiMessages()** - Exposes the enumerator, which supports an iteration of MapiMessages in the current folder.

- **OlmFolder.enumerateMessages()** - Exposes the enumerator, which supports an iteration of OlmMessageInfo's in the current folder.

- **OlmFolder.enumerateMessages**(int startIndex, int count) - Exposes the enumerator, which supports an iteration of OlmMessageInfo's within a given range.

- **OlmFolder.enumerateMessages**(MailQuery query) - Exposes the enumerator, which supports an iteration of OlmMessageInfo's by search criteria.

The code samples below will demonstrate the use of these methods:

```java
 // Enumerates all messages in a given folder

OlmStorage olm = OlmStorage.fromFile("fileName");

try {

    OlmFolder inbox = olm.getFolder("inbox", true);

   for (OlmMessageInfo messageInfo : inbox.enumerateMessages()) {

        System.out.println(messageInfo.getSubject());

   }

} finally {

    olm.dispose();

}

// Enumerates a range of messages in a given folder

OlmStorage olm = OlmStorage.fromFile("fileName");

try {

    OlmFolder inbox = olm.getFolder("inbox", true);

   int startIndex = 10;

   int count = 100;

   for (OlmMessageInfo messageInfo : inbox.enumerateMessages(startIndex, count)) {

        System.out.println(messageInfo.getSubject());

   }

} finally {

    olm.dispose();

}

// Enumerates messages by search criteria

OlmStorage olm = OlmStorage.fromFile("fileName");

try {

    OlmFolder inbox = olm.getFolder("inbox", true);

    MailQueryBuilder mailQueryBuilder = new MailQueryBuilder();

    mailQueryBuilder.getSubject().contains("invitation");

    mailQueryBuilder.getFrom().contains("Mark");

   for (OlmMessageInfo messageInfo : inbox.enumerateMessages(mailQueryBuilder.getQuery())) {

        System.out.println(messageInfo.getSubject());

   }

} finally {

    olm.dispose();

}

// Enumerates all messages and the extraction of some of them

OlmStorage olm = OlmStorage.fromFile("fileName");

try {

    OlmFolder inbox = olm.getFolder("inbox", true);

   for (OlmMessageInfo messageInfo : inbox.enumerateMessages()) {

       if (messageInfo.hasAttachments()) {

            MapiMessage msg = olm.extractMapiMessage(messageInfo);

       }

   }

} finally {

    olm.dispose();

}
```

## Extract Messages from OLM by Identifiers {#extract-messages-from-olm-by-identifiers}

Sometimes it is required to extract selected messages by identifiers. For example, your application stores identifiers in a database and extracts a message on demand. This is the efficient way to avoid traversing through the entire storage each time to find a specific message to extract. To implement this feature for OLM files, Aspose.Email provides the following methods and classes:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/olmmessageinfo/#getEntryId--" target="_blank" rel="nofollow noopener noreferrer">EntryId</a> property of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmmessageinfo/" target="_blank" rel="nofollow noopener noreferrer">OlmMessageInfo</a> class - Gets the message entry identifier.
- overloaded <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#extractMapiMessage-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">extractMapiMessage(String id)</a> method of the OlmStorage class - Gets the message from OLM.

The code sample below demonstrates how to extract messages from OLM by identifiers:

```java
for (OlmMessageInfo msgInfo : olmFolder.enumerateMessages()) {
    MapiMessage msg = storage.extractMapiMessage(msgInfo.getEntryId());
}
```

**Note:** The message ID is unique within the storage file. IDs are created by Aspose.Email and cannot be used in other third-party OLM processing libs or apps.

## Extract OLM Items from Corrupted Files {#extract-olm-items-from-corrupted-files}

Aspose.Email provides a traversal API which allows extracting all OLM items as far as possible, without throwing out exceptions, even if some data of the original file is corrupted.

Use the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#OlmStorage-com.aspose.email.TraversalExceptionsCallback-" target="_blank" rel="nofollow noopener noreferrer">OlmStorage(TraversalExceptionsCallback callback)</a> constructor and the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#load-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">load(String fileName)</a> method instead of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/#fromFile-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">fromFile</a> method.

The constructor allows defining a callback method.

```java
OlmStorage olm = new OlmStorage(new TraversalExceptionsCallback() {
    public void invoke(TraversalAsposeException exception, String itemId) {
        /* Exception handling  code. */
    }
});
```

Loading and traversal exceptions will be available through the callback method.

The load method returns 'true' if the file has been loaded successfully and further traversal is possible. If a file is corrupted and no traversal is possible, 'false' is returned.

```java
TraversalExceptionsCallback exceptionsCallback = new TraversalExceptionsCallback() {
    public void invoke(TraversalAsposeException exception, String itemId) {
        /* Exception handling  code. */
    }
};
try (OlmStorage olm = new OlmStorage(exceptionsCallback)) {
    if (olm.load(fileName)) {
        List<OlmFolder> folderHierarchy = olm.getFolders();
        extractItems(olm, folderHierarchy);
    }
}

private static void extractItems(OlmStorage olm, List<OlmFolder> folders) {
    for (OlmFolder folder : folders) {
        if (folder.hasMessages()) {
            System.out.println(folder);

            for (MapiMessage msg : olm.enumerateMessages(folder)) {
                System.out.println(msg.getSubject());
            }
        }

        if (folder.getSubFolders().size() > 0) {
            extractItems(olm, folder.getSubFolders());
        }
    }
}
```

## Retrieve Outlook Category Colors {#retrieve-outlook-category-colors}

To work with the Outlook item categories stored in an OLM file, Aspose.Email offers:

- the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmitemcategory/" target="_blank" rel="nofollow noopener noreferrer">OlmItemCategory</a> class - represents an Outlook item category, available by its name and associated color, represented in hexadecimal format;
- the `getCategories()` method of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class - retrieves the list of categories used in the storage.

The following sample lists every category used in the storage along with its color:

```java
try (OlmStorage olm = OlmStorage.fromFile("storage.olm")) {
    List<OlmItemCategory> categories = olm.getCategories();

    for (OlmItemCategory category : categories) {
        System.out.println("Category name: " + category.getName());

        // The color is represented as a hexadecimal value: #rrggbb
        System.out.println("Category color: " + category.getColor());
    }
}
```

### Get the Category Color of a Message {#get-the-category-color-of-a-message}

You can match the categories assigned to a particular message against the storage category list to resolve each category color. The example below reads the categories of every message in a folder and prints the color of each one:

```java
try (OlmStorage olm = OlmStorage.fromFile("storage.olm")) {
    List<OlmItemCategory> categories = olm.getCategories();
    OlmFolder folder = olm.getFolder("Inbox", true);

    for (MapiMessage msg : folder.enumerateMapiMessages()) {
        if (msg.getCategories() == null) {
            continue;
        }

        for (String msgCategory : msg.getCategories()) {
            System.out.println("Category name: " + msgCategory);

            String color = null;
            for (OlmItemCategory category : categories) {
                if (category.getName().equalsIgnoreCase(msgCategory)) {
                    color = category.getColor();
                    break;
                }
            }

            System.out.println(color != null ? "Category color: " + color : "Category color: Not found");
        }
    }
}
```

## Converting OLM to PST {#converting-olm-to-pst}

<a href="https://docs.fileformat.com/email/olm/" target="_blank" rel="nofollow noopener noreferrer">OLM</a> is a database file format used by Microsoft Outlook for Mac. OLM files store email messages, calendar data, contacts, and application settings, and they are not supported by Outlook for Windows. To migrate a mailbox from Outlook for Mac to Outlook for Windows, you need to convert the OLM file to the Outlook <a href="https://docs.fileformat.com/email/pst/" target="_blank" rel="nofollow noopener noreferrer">PST</a> format. Aspose.Email for Java lets you do this in code, without Microsoft Outlook installed.

### How the Conversion Works {#how-the-conversion-works}

1. Create an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/olmstorage/" target="_blank" rel="nofollow noopener noreferrer">OlmStorage</a> class to open the source OLM file.
2. Create a new PST file with the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.create</a> method.
3. Implement a `getContainerClass` method that maps a message class to the corresponding folder (container) class, so each folder is created with the correct type in the PST.
4. Implement an `addToPst` method that recursively reads each folder and its messages from the OLM file - using `enumerateMapiMessages()` - and adds them to the PST in the same order, using the `addSubFolder` and `addMessage` methods of <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/" target="_blank" rel="nofollow noopener noreferrer">FolderInfo</a>.

### Code Sample {#code-sample}

The main conversion loop:

```java
// Create an instance of the OlmStorage class to open the source OLM
// and create a new PST file
try (OlmStorage olm = new OlmStorage("my.olm");
     PersonalStorage pst = PersonalStorage.create("my.pst", FileFormatVersion.Unicode)) {

    // Recursively read each folder and its messages
    // and add them to the PST in the same order
    for (OlmFolder olmFolder : olm.getFolderHierarchy()) {
        addToPst(pst.getRootFolder(), olmFolder);
    }
}
```

The `getContainerClass` helper, which derives the PST folder type from the message class of the items being copied - OLM folders carry no folder type of their own:

```java
public static String getContainerClass(String messageClass) {
    if (messageClass.startsWith("IPM.Contact") || messageClass.startsWith("IPM.DistList")) {
        return "IPF.Contact";
    }

    if (messageClass.startsWith("IPM.StickyNote")) {
        return "IPF.StickyNote";
    }

    if (messageClass.startsWith("IPM.Activity")) {
        return "IPF.Journal";
    }

    if (messageClass.startsWith("IPM.Task")) {
        return "IPF.Task";
    }

    if (messageClass.startsWith("IPM.Appointment") || messageClass.startsWith("IPM.Schedule.meeting")) {
        return "IPF.Appointment";
    }

    return "IPF.Note";
}
```

The recursive `addToPst` helper:

```java
public static void addToPst(FolderInfo pstFolder, OlmFolder olmFolder) {
    FolderInfo pstSubFolder = pstFolder.getSubFolder(olmFolder.getName());

    for (MapiMessage msg : olmFolder.enumerateMapiMessages()) {
        if (pstSubFolder == null) {
            pstSubFolder = pstFolder.addSubFolder(olmFolder.getName(), getContainerClass(msg.getMessageClass()));
        }

        pstSubFolder.addMessage(msg);
    }

    if (pstSubFolder == null) {
        pstSubFolder = pstFolder.addSubFolder(olmFolder.getName());
    }

    for (OlmFolder olmSubFolder : olmFolder.getSubFolders()) {
        addToPst(pstSubFolder, olmSubFolder);
    }
}
```

:::info
Conversion in the opposite direction (PST to OLM) is not supported, because an OLM file is always created by Outlook for Mac when an account is added and synchronized with the mail server.
:::

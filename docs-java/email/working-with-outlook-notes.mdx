## Create, Save and Read Outlook Notes {#create-save-and-read-outlook-notes}

Aspose.Email provides the facility to create Outlook notes and save to disk in MSG format. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class provides properties and methods to set the desired information for a note. This article shows how to create, save and read a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> from the disk.

### Create and Save Outlook Note {#create-and-save-outlook-note}

The following steps can be used to create and save a note to disk.

1. Instantiate an object of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class.
2. Set various properties as desired.
3. Save the note to disk as an MSG file.  

   ```java
   // For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
   MapiNote note3 = new MapiNote();
   note3.setSubject("Blue color note");
   note3.setBody("This is a blue color note");
   note3.setColor(NoteColor.Blue);
   note3.setHeight(500);
   note3.setWidth(500);
   note3.save(dataDir + "MapiNote_out.msg", NoteSaveFormat.Msg);
   ```

### Read a MapiNote {#read-a-mapinote}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapinote/" target="_blank" rel="nofollow noopener noreferrer">MapiNote</a> class object is used to cast the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> object that loads a note from disk in MSG format.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiMessage note = MapiMessage.fromFile(dataDir + "MapiNote_out.msg");
MapiNote note2 = (MapiNote) note.toMapiMessageItem();
```

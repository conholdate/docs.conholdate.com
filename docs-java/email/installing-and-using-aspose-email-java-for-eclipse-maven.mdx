## Installing {#installing}

**Aspose.Email Java (Maven) for Eclipse** plugin can be easily installed from the Available **Plugin** tab in the Plugin dialog.

- To open it, select **Plugins** from the **Tools** menu in Eclipse.

![todo:image_alt_text](/java/email/images/11e746cd821a11f8-Nqb0Qul.png)

- This adds the **Aspose.Email Maven Project** in New Project wizard and **Aspose.Email Code Example** in New File wizard of Eclipse IDE.

## Using {#using}

### Aspose.Email Maven Project (wizard) {#asposeemail-maven-project-wizard}

To create **Maven Project** by wizard for using <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a>:

1. Select **New Project**.
2. Select **Aspose.Email Maven Project** in the **Maven** category.
3. Click **Next**.

![todo:image_alt_text](/java/email/images/c1d09c327d5d0887-BRKq0Oc.png)

1. Provide **Project Name, Location, GroupId, ArtifactId** and **Version** for your Maven Project and click **Finish.**

![todo:image_alt_text](/java/email/images/14b73d9b2e7c494f-p4Ko9VB.png)

1. This will retrieve the <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java</a> latest <a href="https://repository.aspose.com/webapp/#/artifacts/browse/tree/General/repo" target="_blank" rel="nofollow noopener noreferrer">Maven Dependency</a> reference from <a href="https://repository.aspose.com/webapp/#/" target="_blank" rel="nofollow noopener noreferrer">Aspose Cloud Maven Repository</a> and configure it in **pom.xml**. If you have opted for **Also Download Code Examples,** downloading of the **Code Examples** will also begin from the <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API Examples Repository.</a>

2. Following **Maven** Project will be created on your **Eclipse IDE** on completion of the wizard:

3. The created **Maven Project** is configured to use **Aspose.Email for Java API** and ready to be enhanced as per your Project requirements. If you have opted to download <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Examples" target="_blank" rel="nofollow noopener noreferrer">Code Examples</a>, you can use **Aspose.Email Code Example (wizard)** for importing needed **Code Examples** of <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java</a> API into your project.

### Aspose.Email Code Example (wizard) {#asposeemail-code-example-wizard}

**Aspose.Email Code Example wizard** allows you to try out many samples provided for <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java</a> API.

:::info
To be able to use **Aspose.Email Code Example wizard** comfortably: it is recommended to always select **Also Download Code Examples** while creating **Maven Project** on **Aspose.Email Maven Project** **wizard**,
:::

To use examples, just:

1. Click **New File** in **Eclipse**.
2. Choose your project and then select **Aspose.Email Code Example** in the **Java** category.
3. Click **Next**.

![todo:image_alt_text](/java/email/images/336b38efcd18e9d1-z4fpwBb.png)

1. Expand the tree to select **Code Example** category and click **Finish**.

![todo:image_alt_text](/java/email/images/21f9f19150b11159-8MeWhSb.png)

1. This will copy the selected category **Code Examples** Java files into the project under **com.aspose.email.examples** package. Also any required resources needed by the Code Examples will be copied into **src/main/resources** folder
2. Review the example code, compile and run.
3. You can now test other examples and start building your own application using <a href="http://www.aspose.com/java/email-component.aspx" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java API</a>

## Installing Aspose.Email for Java from Maven Repository {#installing-asposeemail-for-java-from-maven-repository}

Aspose hosts all Java APIs on <a href="https://releases.aspose.com/" target="_blank" rel="nofollow noopener noreferrer">Aspose Artifactory</a>. You can easily use <a href="https://releases.aspose.com/java/repo/com/aspose/aspose-email/" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email for Java</a> API directly in your Maven Projects with simple configurations.

### Specify Maven Repository Configuration {#specify-maven-repository-configuration}

First, you need to specify the Aspose Maven Repository configuration/location in your Maven pom.xml as follows:

```java

 <repositories>

    <repository>

        <id>AsposeJavaAPI</id>

        <name>Aspose Java API</name>

        <url>https://releases.aspose.com/java/repo/</url>

    </repository>

</repositories>
```

### Define Aspose.Email for Java API Dependency {#define-asposeemail-for-java-api-dependency}

Then define Aspose.Email for Java API dependency in your pom.xml as follows:

```java

 <dependencies>

    <dependency>

        <groupId>com.aspose</groupId>

        <artifactId>aspose-email</artifactId>

        <version>19.12</version>

        <classifier>jdk16</classifier>

 </dependency>

</dependencies>
```

After performing the above steps, Aspose.Email for Java dependency will finally be defined in your Maven Project.

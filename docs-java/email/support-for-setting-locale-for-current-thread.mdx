Aspose.Email provides the ability to set the Locale for the current thread. Aspose.Email provides a class <a href="https://apireference.aspose.com/java/email/com.aspose.email/CurrentThreadSettings" target="_blank" rel="nofollow noopener noreferrer">CurrentThreadSettings</a> that provides the <a href="https://apireference.aspose.com/java/email/com.aspose.email/CurrentThreadSettings#setLocale%5C%28java.util.Locale%5C%29" target="_blank" rel="nofollow noopener noreferrer">setLocale</a> method for this purpose. The following code snippet demonstrates the use of the <a href="https://apireference.aspose.com/java/email/com.aspose.email/CurrentThreadSettings" target="_blank" rel="nofollow noopener noreferrer">CurrentThreadSettings</a> class to set the current Locale. The snippet fist sets the Locale to an invalid value and then uses the <a href="https://apireference.aspose.com/java/email/com.aspose.email/CurrentThreadSettings#setLocale%5C%28java.lang.String%5C%29" target="_blank" rel="nofollow noopener noreferrer">CurrentThreadSettings.setLocale</a> method to set the Locale for the current thread.

```Java
Locale defaultLocale = Locale.getDefault();
try {
    // set incorrect default Locale
    Locale.setDefault(new Locale("en", "RU"));
    // set Current Thread Locale
    CurrentThreadSettings.setLocale("en-US");
    // or
    // CurrentThreadSettings.setLocale(new Locale("en", "US"));

    PersonalStorage.create(dataDir + "test.pst", FileFormatVersion.Unicode);
} finally {
    Locale.setDefault(defaultLocale);
}
```

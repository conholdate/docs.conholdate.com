## Parsing and Saving Attachments {#parsing-and-saving-attachments}

Outlook message files may contain one or more attachments. Aspose.Email lets developers loop through the attachments in an MSG file and save them to disk. This topic describes the process. It also describes how to embed an attachment.

Aspose.Email <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class is used to load an MSG file from disk and exposes the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getAttachments--" target="_blank" rel="nofollow noopener noreferrer">getAttachments()</a> method which references the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> object collection associated with the MSG file. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> object further exposes methods that perform actions on the attachment.

To save attachments in an MSG file to disk with the original name and extension:

1. Create an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class to load an MSG file using the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#load-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Load()</a> static method.
2. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> class <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getAttachments--" target="_blank" rel="nofollow noopener noreferrer">getAttachments()</a> method to get a reference to the collection of <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> objects associated with the MSG file.
3. Loop through the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachmentcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachmentCollection</a> to display contents regarding each <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> object through its public methods.
4. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> class <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/#save-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">save()</a> method to save attachment to the disk.  

   ```java
   // For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
   //Instantiate an MSG file to load an MSG file from disk
   MapiMessage outlookMessageFile = MapiMessage.fromFile(dataDir + "WithEmbeddedMsg.msg");

   //Loop through the attachments collection associated with the MapiMessage object
   for (int i = 0; i < outlookMessageFile.getAttachments().size(); i++) {
   	//Set a reference to the MapiAttachment object
   	MapiAttachment outlookMessageAttachment = (MapiAttachment) outlookMessageFile.getAttachments().get_Item(i);
   	//Display attachment type
   	System.out.println("Att Type : " + outlookMessageAttachment.getMimeTag());
   	//Display attached file name
   	System.out.println("File Name : " + outlookMessageAttachment.getLongFileName());
   	//Save attachment to the disk
   	outlookMessageAttachment.save(dataDir + outlookMessageAttachment.getDisplayName());
   }
   ```

Embedding Messages as Attachments

A Microsoft Outlook message can contain other Microsoft Outlook messages in attachments either as regular messages, described above, or embedded messages. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachmentcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachmentCollection</a> provides overloaded members of the add method for creating Outlook messages with both types of attachments. Outlook MSG files embedded in a MSG file contains a PR_ATTACH_METHOD with the value 5.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiMessage msg = new MapiMessage("from@test.com", "to@test.com", "Subj", "This is a message body");
MapiMessage attachMsg = MapiMessage.fromFile(dataDir + "message.msg");
msg.getAttachments().add("Weekly report", attachMsg);
msg.save(dataDir + "EmbededMessageAsAttachment.msg");
```

### Add MSG Attachments {#add-msg-attachments}

An Outlook message can contain other Microsoft Outlook messages in attachments, either as regular or as embedded messages. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachmentcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachmentCollection</a> provides overloaded members of the `add` method to create Outlook messages with both types of attachments:

- `add(String name, byte[] data)` - adds a regular attachment from a byte array.
- `add(String name, MapiMessage message)` - adds another Outlook message as an embedded message.

The following code snippet shows you how to add both types of attachments to a message:

```java
MapiMessage message = new MapiMessage("from@test.com", "to@test.com", "Subj", "This is a message body");

// Add a regular attachment from a byte array
message.getAttachments().add("note.txt", Files.readAllBytes(Paths.get("note.txt")));

// Add another Outlook message as an embedded message
MapiMessage attachMsg = MapiMessage.load("Message.msg");
message.getAttachments().add("Weekly report.msg", attachMsg);

message.save("WithAttachments_out.msg");
```

:::info
`MapiMessage.fromFile` does not exist in Aspose.Email for Java - use `MapiMessage.load` to read an MSG file from disk.
:::

### Add Reference Attachments to MapiMessages {#add-reference-attachments-to-mapimessages}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/referenceattachmentoptions/" target="_blank" rel="nofollow noopener noreferrer">ReferenceAttachmentOptions</a> class simplifies the addition of reference attachments by encapsulating all necessary properties in a single object:

- **sharedLink** - a fully qualified shared link to the attachment provided by the web service hosting the file;
- **url** - the file location or resource URL;
- **providerName** - the name of the reference attachment provider (e.g. Google Drive, Dropbox).

```java
MapiMessage msg = MapiMessage.load("message.msg");

ReferenceAttachmentOptions options = new ReferenceAttachmentOptions(
        "https://drive.google.com/file/d/1HJ-M3F2qq1oRrTZ2GZhUdErJNy2CT3DF/",
        "https://drive.google.com/drive/my-drive",
        "GoogleDrive");

// Add the reference attachment
msg.getAttachments().add("Document.pdf", options);

msg.save("with-reference-attachment.msg");
```

### Check Attachment Type (IsReference) {#check-attachment-type-isreference}

The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> class includes the `isReference()` method which allows developers to identify reference attachments in a message:

```java
MapiMessage msg = MapiMessage.load("message.msg");

for (MapiAttachment attachment : msg.getAttachments()) {
    if (attachment.isReference()) {
        // Process the reference attachment
        System.out.println("Reference attachment: " + attachment.getLongFileName());
    }
}
```

### Get Nested Mail Message Attachments {#get-nested-mail-message-attachments}

Embedded message attachments also appear in the attachment collection of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class. The `MapiMessage.fromProperties()` static method creates a new message from an embedded attachment. The following code snippet shows you how to get nested mail message attachments and save them to disk:

```java
MapiMessage msg = MapiMessage.load("message.msg");

for (MapiAttachment attachment : msg.getAttachments()) {
    if (attachment.getObjectData() == null) {
        continue;
    }

    // Create a MapiMessage object from the individual attachment
    MapiMessage nested = MapiMessage.fromProperties(attachment.getObjectData().getProperties());

    // Convert the embedded message to a MailMessage and save it to disk
    MailMessage mailMessage = nested.toMailMessage(new MailConversionOptions());
    mailMessage.save("NestedMailMessageAttachments_out.eml", SaveOptions.getDefaultEml());
}
```

### Remove Attachments {#remove-attachments}

Aspose.Email provides the functionality to remove attachments from Microsoft Outlook message (.msg) files. Call the static `removeAttachments()` method, which takes the path of the message file as a parameter:

```java
MapiMessage.removeAttachments("AttachmentsToRemove_out.msg");
```

You can also call the static `destroyAttachments()` method. It works faster than `removeAttachments()`, because the latter parses the message file:

```java
MapiMessage.destroyAttachments("AttachmentsToDestroy_out.msg");
```

## Attachments MSG Insertion and Replacement {#attachments-msg-insertion-and-replacement}

Aspose.Email API provides the capability to insert attachments at specific index in the parent message. It also provides the facility to replace contents of an attachment with another message attachment.

### Insert MSG Attachment at Specific Location {#insert-msg-attachment-at-specific-location}

Aspose.Email API provides the capability to insert an MSG attachment to a parent MSG using the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachmentcollection/#insert-int-java.lang.String-com.aspose.email.MapiMessage-" target="_blank" rel="nofollow noopener noreferrer">MapiAttachmentCollection.Insert()</a> method.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiMessage msg = MapiMessage.fromFile(dataDir + "WithEmbeddedMsg.msg");
msg.getAttachments().get_Item(0).save(dataDir + "attachment_out.msg");	
MapiMessage emb = MapiMessage.fromStream(new FileInputStream(dataDir + "WithEmbeddedMsg.msg"));
		
msg.getAttachments().insert(1, "new 11", emb);
		
msg.save(dataDir + "insertMSGAttachment_out.msg");
```

### Replace Embedded MSG Attachment Contents {#replace-embedded-msg-attachment-contents}

This can be used to replace embedded attachment contents with the new ones using the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachmentcollection/#replace-int-java.lang.String-com.aspose.email.MapiMessage-" target="_blank" rel="nofollow noopener noreferrer">Replace</a> method. However, it can not be used to insert attachment with PR_ATTACH_NUM = 4(for example) in the collection with collection.Count = 2.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
MapiMessage msg = MapiMessage.fromFile(dataDir + "insertMSGAttachment_out.msg");
msg.getAttachments().get_Item(0).save(dataDir + "attachment_out.msg");
MapiMessage emb = MapiMessage.fromStream(new FileInputStream(dataDir + "insertMSGAttachment_out.msg"));

msg.getAttachments().replace(1, "new 1", emb);
		
msg.save(dataDir + "replaceEmbeddedMSGAttachment_out.msg");
```

## Rename an Attachment in a MapiMessage {#rename-an-attachment-in-a-mapimessage}

Aspose.Email makes it possible to edit the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/#setDisplayName-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">DisplayName</a> property value in <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage attachments</a>.

The following code sample demonstrates how to update the display names of the first and second attachments within the loaded Mapi message:

```java
MapiMessage msg = MapiMessage.load(fileName);
msg.getAttachments().get_Item(0).setDisplayName("New display name 1");
msg.getAttachments().get_Item(1).setDisplayName("New display name 2");
```

## Check if an Attachment is Inline or Regular {#check-if-an-attachment-is-inline-or-regular}

The difference between inline and regular attachments is how they are presented within an email. Inline attachments are embedded within the body of the email and can be viewed without having to open a separate file or download anything. Regular attachments, on the other hand, are separate files that are attached to the email but are not displayed directly within the body of the message and need to be downloaded and opened externally. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/#isInline--" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment.IsInline</a> property of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> class gets a value indicating whether the attachment is inline or regular.

The following code sample loads an email message from a file and then retrieves information about the attachments, specifically printing the display name of each attachment and whether it is inline within the message or not:

```java
MapiMessage message = MapiMessage.load("fileName");

for (MapiAttachment attach : message.getAttachments()) {
    System.out.println(attach.getDisplayName() + ": " + attach.isInline());
}
```

## Extract Embedded OLE Objects from oledata.mso {#extract-embedded-ole-objects-from-oledatamso}

Sometimes embedded OLE data is represented as an `oledata.mso` attachment in a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiattachment/" target="_blank" rel="nofollow noopener noreferrer">MapiAttachment</a> and needs to be extracted manually. These `oledata.mso` files are in the Microsoft Compound Document File (MCDF) format, and support for such files is beyond the scope of Aspose.Email. However, Aspose.Email provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/inlineattachmentextractor/" target="_blank" rel="nofollow noopener noreferrer">InlineAttachmentExtractor</a> class to enumerate the MSO packages contained in the binary data of `oledata.mso`, which can then be passed to a compound-file reading library (for example <a href="https://poi.apache.org/components/poifs/" target="_blank" rel="nofollow noopener noreferrer">Apache POI POIFS</a>) for content extraction.

When the message body type is HTML (not RTF) and there are OLE objects in the message, the `MapiPropertyTag.PR_ATTACH_DATA_OBJ` property is absent. In this case, the information about the OLE objects is contained in `oledata.mso`.

The code below enumerates the MSO packages and writes each of them to a separate file, ready to be opened with a compound-file reader:

```java
MapiMessage msg = MapiMessage.load("double.msg");

for (MapiAttachment mapiAttachment : msg.getAttachments()) {
    if (!"oledata.mso".equals(mapiAttachment.getLongFileName())) {
        continue;
    }

    com.aspose.email.system.collections.generic.IGenericDictionary<String, byte[]> oledata =
            InlineAttachmentExtractor.enumerateMsoPackage(new ByteArrayInputStream(mapiAttachment.getBinaryData()));

    int index = 0;
    for (com.aspose.email.system.collections.generic.KeyValuePair<String, byte[]> oleItem : oledata) {
        // Each value is a compound file - read its CONTENTS stream with an MCDF library,
        // or store it as is for further processing
        Files.write(Paths.get(index + ".mso"), oleItem.getValue());
        index++;
    }
}
```

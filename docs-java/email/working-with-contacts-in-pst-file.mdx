## Reading Multiple Contacts in VCard Format {#reading-multiple-contacts-in-vcard-format}

The code sample below demonstrates how to read a VCF file, check if it contains multiple contacts, and if so, load the contacts from the file into a list of VCardContact objects. The code uses the following methods:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/vcardcontact/#isMultiContacts-java.io.InputStream-" target="_blank" rel="nofollow noopener noreferrer">isMultiContacts(InputStream stream)</a> - Checks whether source stream contains multi contacts.
- <a href="https://reference.aspose.com/email/java/com.aspose.email/vcardcontact/#loadAsMultiple-java.lang.String-java.nio.charset.Charset-" target="_blank" rel="nofollow noopener noreferrer">loadAsMultiple(String filePath, Charset encoding)</a> - Loads list of contacts from multi contact file.
- <a href="https://reference.aspose.com/email/java/com.aspose.email/vcardcontact/#loadAsMultiple-java.io.InputStream-java.nio.charset.Charset-" target="_blank" rel="nofollow noopener noreferrer">loadAsMultiple(InputStream stream, Charset encoding)</a> - Loads list of contacts from multi contact stream.

```java
try (InputStream stream = new FileInputStream("test.vcf")) {
    if (VCardContact.isMultiContacts(stream)) {
        List<VCardContact> contacts = VCardContact.loadAsMultiple(stream, Charset.forName("utf-8"));
    }
}
```

## Adding Contact to PST {#adding-contact-to-pst}

<a href="https://docs.aspose.com/email/java/working-with-contacts-in-pst-file/java/create-new-pst-add-sub-folders-and-messages/" target="_blank" rel="nofollow noopener noreferrer">Create New PST, Add Sub-folders and Messages</a> showed how to create a PST file and add a subfolder to it. With Aspose.Email you can add a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> to the Contacts subfolder of a PST file that you have created or loaded. Below are the steps to add <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> to a PST:

1. Create a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> object.
2. Set the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> properties using different constructors and methods.

4. Create a pre-defined folder (Contacts) at the root of the PST file by accessing the root folder and then calling the <a href="https://reference.aspose.com/email/java/com.aspose.email/folderinfo/#addMapiMessageItem-com.aspose.email.IMapiMessageItem-" target="_blank" rel="nofollow noopener noreferrer">addMapiMessageItem()</a> method.

## Save contacts information from PST file in MSG Format {#save-contacts-information-from-pst-file-in-msg-format}

This article shows how to access contact information from a Microsoft Outlook PST file and save contacts to disk in MSG format. To do so, use the <a href="https://apireference.aspose.com/email/java/com.aspose.email/PersonalStorage" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> and <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> classes to get and display the contact information.

To get a contact's information:

1. Load the PST file in the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class.
2. Browse the Contacts folder.
3. Get the contents of the Contacts folder to get the message collection.
4. Loop through the message collection.
5. Call <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#extractMessage-com.aspose.email.MessageInfo-" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.extractMessage()</a> and then <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#toMapiMessageItem--" target="_blank" rel="nofollow noopener noreferrer">toMapiMessageItem()</a> method to get the contact information in the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class.
6. Use <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> properties to access the contact information.
7. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#extractMessage-com.aspose.email.MessageInfo-" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.extractMessage()</a> method to get the contact information in the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class.
8. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#save-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">MapiMessage.save()</a> method to save the contact to disk in MSG format.

Below is a sample code that retrieves all the contacts information from the PST file and saves it to disk in MSG format.

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
String dataDir = Utils.getSharedDataDir(AccessContactInformationFromPSTFile.class) + "outlook/";

// Load the Outlook PST file
PersonalStorage pst = PersonalStorage.fromFile(dataDir + "SampleContacts.pst");

// Get the Contacts folder
FolderInfo folderInfo = pst.getRootFolder().getSubFolder("Contacts");

// Loop through all the contacts in this folder
MessageInfoCollection messageInfoCollection = folderInfo.getContents();

for (int i = 0; i < messageInfoCollection.size(); i++) {
	MessageInfo messageInfo = (MessageInfo) messageInfoCollection.get_Item(i);
	//  Get the contact information
	MapiContact contact = (MapiContact) pst.extractMessage(messageInfo).toMapiMessageItem();
	//  Display some contents on screen
	System.out.println("Name: " + contact.getNameInfo().getDisplayName() + "\n");
	//  Save to disk in MSG format
	if (contact.getNameInfo().getDisplayName() != null) {
		MapiMessage message = pst.extractMessage(messageInfo); // Get rid of illegal characters that cannot be used as a file name
		String messageName = message.getSubject().replace(":", " ").replace("\\", " ").replace("?", " ").replace("/", " ");
		message.save(dataDir + messageName + ".msg");
	}
}
```

## Save Contacts Information from Outlook PST to Disk in vCard format {#save-contacts-information-from-outlook-pst-to-disk-in-vcard-format}

This article shows how to access contact information from a Microsoft Outlook PST file and save the contact to disk in vCard (VCF) format. It uses the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> and <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> classes to get the contact information.

Below are the steps to get the contacts information:

1. Load the PST file in <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage</a> class.
2. Browse the Contacts folder.
3. Get the contents of the Contacts folder to get the message collection.
4. Loop through the message collection.
5. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/personalstorage/#extractMessage-com.aspose.email.MessageInfo-" target="_blank" rel="nofollow noopener noreferrer">PersonalStorage.extractMessage()</a> method to get the contact information in the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class.
6. Use the properties of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapicontact/" target="_blank" rel="nofollow noopener noreferrer">MapiContact</a> class to access the contact information.

The program below loads a PST file from disk and saves all the contacts in vCard (VCF) format. The VCF files can then be used in any other program that can load the standard vCard contact file. If you open any VCF file in Microsoft Outlook, it will look like the one in the below screenshot.

// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Load the Outlook PST file
PersonalStorage pst = PersonalStorage.fromFile(dataDir + "Outlook.pst");

FolderInfo folderInfo = pst.getRootFolder().getSubFolder("Contacts");

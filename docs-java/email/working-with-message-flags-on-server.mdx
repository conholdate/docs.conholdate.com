## Changing the Message Flags {#changing-the-message-flags}

You can change message flags by using the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#changeMessageFlags-com.aspose.email.IConnection-int-com.aspose.email.ImapMessageFlags-" target="_blank" rel="nofollow noopener noreferrer">changeMessageFlags()</a> method. This method takes two parameters.

1. The message sequence number or unique ID.
2. <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/" target="_blank" rel="nofollow noopener noreferrer">MessageFlag</a>.

The following flags can be set:

- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getAnswered--" target="_blank" rel="nofollow noopener noreferrer">Answered</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getDeleted--" target="_blank" rel="nofollow noopener noreferrer">Deleted</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getDraft--" target="_blank" rel="nofollow noopener noreferrer">Draft</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getEmpty--" target="_blank" rel="nofollow noopener noreferrer">Empty</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getFlagged--" target="_blank" rel="nofollow noopener noreferrer">Flagged</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#isRead--" target="_blank" rel="nofollow noopener noreferrer">isRead</a>
- <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/#getRecent--" target="_blank" rel="nofollow noopener noreferrer">Recent</a>

### Setting Message Flags {#setting-message-flags}

The following code snippet shows you how to change message flags on an IMAP server with Aspose.Email.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Mark the message as read
client.changeMessageFlags(1, ImapMessageFlags.isRead());
```

### Removing Message Flags {#removing-message-flags}

Message flags can also be removed with the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#removeMessageFlags-com.aspose.email.IConnection-int-com.aspose.email.ImapMessageFlags-" target="_blank" rel="nofollow noopener noreferrer">removeMessageFlags()</a> method. Usage is similar to that of the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#changeMessageFlags-com.aspose.email.IConnection-int-com.aspose.email.ImapMessageFlags-" target="_blank" rel="nofollow noopener noreferrer">changeMessageFlags()</a> method. It takes a sequence number or unique message ID and <a href="https://reference.aspose.com/email/java/com.aspose.email/imapmessageflags/" target="_blank" rel="nofollow noopener noreferrer">MessageFlag</a>. The following code snippet shows you how to remove message flags.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Remove the message flag
client.removeMessageFlags(1, ImapMessageFlags.isRead());
```

## Setting Custom Flags {#setting-custom-flags}

You can also set custom flags to a message using the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/" target="_blank" rel="nofollow noopener noreferrer">ImapClient</a> of the API. The ImapClient <a href="https://reference.aspose.com/email/java/com.aspose.email/imapclient/#addMessageFlags-com.aspose.email.IConnection-int-com.aspose.email.ImapMessageFlags-" target="_blank" rel="nofollow noopener noreferrer">AddMessageFlags</a> provides the ability to set custom flags on messages.

```Java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// Create a message
MailMessage message = new MailMessage("user@domain1.com", "user@domain2.com", "subject", "message");

// Append the message to mailbox
String uid = client.appendMessage(ImapFolderInfo.IN_BOX, message);

// Add custom flags to the added messge
client.addMessageFlags(uid, com.aspose.email.ImapMessageFlags.op_BitwiseOr(ImapMessageFlags.keyword("custom1"), ImapMessageFlags.keyword("custom1_0")));

// Retreive the messages for checking the presence of custom flag
client.selectFolder(ImapFolderInfo.IN_BOX);

ImapMessageInfoCollection messageInfos = client.listMessages();
for (ImapMessageInfo inf : messageInfos) {
    ImapMessageFlags[] flags = inf.getFlags().split();

    if (inf.containsKeyword("custom1"))
        System.out.println("Keyword found");
}
```

:::info
Using Aspose.Email for Java, developers can not only load but also parse contents from Outlook message files.

- To load MSG files from disk, use the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class static <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#load-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Load</a> method.
- To parse MSG file contents, the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> exposes a number of methods.

This topic shows how to load and then parse an MSG file to display its contents.
:::

Aspose.Email for Java provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class that is used to open and parse an MSG file. As there may be many recipients in an MSG file, the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class exposes the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getRecipients--" target="_blank" rel="nofollow noopener noreferrer">getRecipients()</a> method that returns a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipientcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipientCollection</a> which represents a collection of <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> objects. The <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> object further exposes methods for working with recipient attributes.

The following sequence of steps serves this purpose:

1. Create an instance of the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/" target="_blank" rel="nofollow noopener noreferrer">MapiMessage</a> class to load an MSG file from the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#load-java.lang.String-" target="_blank" rel="nofollow noopener noreferrer">Load</a> static method.
2. Display the sender name, subject, and body from the MSG file using <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getSenderName--" target="_blank" rel="nofollow noopener noreferrer">getSenderName()</a>, <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getSubject--" target="_blank" rel="nofollow noopener noreferrer">getSubject()</a> and <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getBody--" target="_blank" rel="nofollow noopener noreferrer">getBody()</a> methods.
3. Call the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapimessage/#getRecipients--" target="_blank" rel="nofollow noopener noreferrer">getRecipients()</a> method exposed by the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> class to get a reference to the collection of <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> objects associated with the MSG file.
4. Loop through the <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipientcollection/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipientCollection</a> collection to display contents for each <a href="https://reference.aspose.com/email/java/com.aspose.email/mapirecipient/" target="_blank" rel="nofollow noopener noreferrer">MapiRecipient</a> object through its public methods.

```java
// The path to the resource directory.
String dataDir = Utils.getSharedDataDir(ParsingOutlookMessageFiles.class) + "outlook/";

//Instantiate an MSG file to load an MSG file from disk
MapiMessage outlookMessageFile = MapiMessage.fromFile(dataDir + "message.msg");
//Display sender's name
System.out.println("Sender Name : " + outlookMessageFile.getSenderName());
//Display Subject
System.out.println("Subject : " + outlookMessageFile.getSubject());
//Display Body
System.out.println("Body : " + outlookMessageFile.getBody());
//Display Recipient's info
System.out.println("Recipients : \n");

//Loop through the recipients collection associated with the MapiMessage object
for (int i = 0; i < outlookMessageFile.getRecipients().size(); i++) {
	//Set a reference to the MapiRecipient object
	MapiRecipient rcp = (MapiRecipient) outlookMessageFile.getRecipients().get_Item(i);
	//Display recipient email address
	System.out.println("Email : " + rcp.getEmailAddress());
	//Display recipient name
	System.out.println("Name : " + rcp.getDisplayName());
	//Display recipient type
	System.out.println("Recipient Type : " + rcp.getRecipientType());
}
```

## Get an Item Type of a MAPI Message {#get-an-item-type-of-a-mapi-message}

Aspose.Email offers a <a href="https://reference.aspose.com/email/java/com.aspose.email/mapiitemtype/" target="_blank" rel="nofollow noopener noreferrer">MapiItemType</a> enum that represents an item type. It can be used for message conversion into an object of a corresponding class derived from the <a href="https://reference.aspose.com/email/java/com.aspose.email/imapimessageitem" target="_blank" rel="nofollow noopener noreferrer">IMapiMessageItem</a> interface. This avoids users from checking the MessageClass property value before message conversion.

The following code sample demonstrates how to iterate through the messages in a folder and convert each MAPI message to a corresponding MAPI item type, depending on the type of the message:

```java
for (MessageInfo messageInfo : folder.enumerateMessages()) {
    MapiMessage msg = pst.extractMessage(messageInfo);

    switch (msg.getSupportedType()) {
        // Non-supported type. MapiMessage cannot be converted to an appropriate item type.
        // Just use in MSG format.
        case MapiItemType.None:
            break;
        // An email message. Conversion isn't required.
        case MapiItemType.Message:
            break;
        // A contact item. Can be converted to MapiContact.
        case MapiItemType.Contact:
            MapiContact contact = (MapiContact) msg.toMapiMessageItem();
            break;
        // A calendar item. Can be converted to MapiCalendar.
        case MapiItemType.Calendar:
            MapiCalendar calendar = (MapiCalendar) msg.toMapiMessageItem();
            break;
        // A distribution list. Can be converted to MapiDistributionList.
        case MapiItemType.DistList:
            MapiDistributionList dl = (MapiDistributionList) msg.toMapiMessageItem();
            break;
        // A Journal entry. Can be converted to MapiJournal.
        case MapiItemType.Journal:
            MapiJournal journal = (MapiJournal) msg.toMapiMessageItem();
            break;
        // A StickyNote. Can be converted to MapiNote.
        case MapiItemType.Note:
            MapiNote note = (MapiNote) msg.toMapiMessageItem();
            break;
        // A Task item. Can be converted to MapiTask.
        case MapiItemType.Task:
            MapiTask task = (MapiTask) msg.toMapiMessageItem();
            break;
    }
}
```

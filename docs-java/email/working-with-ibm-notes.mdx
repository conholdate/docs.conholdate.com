## About IBM Notes {#about-ibm-notes}

IBM Notes is the client and IBM Domino is the server of a collaborative client-server software platform. IBM Notes provides collaboration features like email, calendars, to-do lists, contacts management, etc. The database file used by IBM Notes is saved in the Notes Storage Facility (NSF) format.

## Detect a File is in NSF Format {#detect-a-file-is-in-nsf-format}

The code sample below will show you how to recognize the NSF file format:

```java
// Returns FileFormatType.Nsf for an NSF storage file
int formatType = FileFormatUtil.detectFileFormat("storage.nsf").getFileFormatType();

if (formatType == FileFormatType.Nsf) {
    System.out.println("The file is in the NSF format.");
}
```

## Read messages from NSF storage file {#read-messages-from-nsf-storage-file}

:::info
Note, the NSF implementation is quite limited. In general, it is possible to face some problems in the following cases:

- The file was created by Notes version 7 and higher
- LZ1 compression is used
  :::

Aspose.Email provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/notesstoragefacility" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class to read NSF storage files. The <a href="https://reference.aspose.com/email/java/com.aspose.email/notesstoragefacility" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class provides the <a href="https://reference.aspose.com/email/java/com.aspose.email/NotesStorageFacility#enumerateMessages%5C%28%5C%29" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages</a> method which iterates over the messages in the NSF storage file. The following sample code demonstrates the use of the <a href="https://reference.aspose.com/email/java/com.aspose.email/notesstoragefacility" target="_blank" rel="nofollow noopener noreferrer">NotesStorageFacility</a> class and the <a href="https://reference.aspose.com/email/java/com.aspose.email/NotesStorageFacility#enumerateMessages%5C%28%5C%29" target="_blank" rel="nofollow noopener noreferrer">EnumerateMessages</a> method to read messages from the NSF storage file. 

```java
// For complete examples and data files, please go to https://github.com/aspose-email/Aspose.Email-for-Java
// The path to the resource directory.
String dataDir = Utils.getSharedDataDir(ReadMessagesFromNSFStorage.class) + "email/";

NotesStorageFacility nsf = new NotesStorageFacility(dataDir + "SampleNSF.nsf");
try {
	for (MailMessage eml : nsf.enumerateMessages()) {
		System.out.println(eml.getSubject());
	}
} finally {
	nsf.dispose();
}
```

:::info
Please note that only message reading is implemented. Reading of folders is not supported yet due to lack of specification.
:::

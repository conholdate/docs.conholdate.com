## Installing {#installing}

It is very simple and easy to install Aspose.Email Java for Ruby gem, please follow these simple steps:

1. Run following command.

```java

 $ gem install aspose-emailjava
```

1. Download required Aspose.Email for Java Component from following link. <a href="https://downloads.aspose.com/total" target="_blank" rel="nofollow noopener noreferrer">https://downloads.aspose.com/total</a>
2. Create "jars" folder at root of the Aspose.Email Java for Ruby gem and copy downloaded component into it.

## Using {#using}

Include the required files for working with the **createnewemail** example.

```java

 require File.dirname(File.dirname(File.dirname(__FILE__))) + '/lib/aspose-emailjava'

include Asposeemailjava

include Asposeemailjava::CreateNewEmail

initialize_aspose_email
```

Let's understand the above code.

1. The first line makes sure that the aspose email is loaded and available.
2. Include the files that are required to access the aspose email.
3. Initialize the libraries. The aspose JAVA classes are loaded from the path provided in the aspose.yml file

## How to configure the source code {#how-to-configure-the-source-code}

Please follow these simple steps in order to open and extend the source code while using:

1. Install only Python 2.7.x.x from: <a href="https://www.python.org/downloads/" target="_blank" rel="nofollow noopener noreferrer">https://www.python.org/downloads/</a>
2. Install JPype from: <a href="https://sourceforge.net/projects/jpype/files/JPype/" target="_blank" rel="nofollow noopener noreferrer">https://sourceforge.net/projects/jpype/files/JPype/</a>
3. Install Java JDK from: <a href="https://www.oracle.com/java/technologies/downloads/" target="_blank" rel="nofollow noopener noreferrer">https://www.oracle.com/java/technologies/downloads/</a>
4. Download Aspose.Email for Java APIs you want to use in your python projects from: <a href="https://downloads.aspose.com/total" target="_blank" rel="nofollow noopener noreferrer">https://downloads.aspose.com/total</a> and copy downloaded APIs's .jars into %Python%/lib folder.
5. Clone <a href="https://github.com/aspose-email/Aspose.Email-for-Java/tree/master/Plugins/Aspose.Email-for-Java_for_Python" target="_blank" rel="nofollow noopener noreferrer">Aspose.Email Java for Python Examples</a> from github.

### Setting a License {#setting-a-license}

The license is a plain text XML file that contains details such as the product name, number of developers it is licensed to, subscription expiry date and so on. The file is digitally signed, so do not modify the file; even the inadvertent addition of an extra line break into the file will invalidate it.

You need to apply a license before performing any operations with documents. Make sure you do this before creating a Diagram object. You are only required to set a license once per application or process.

The license can be loaded from a stream or file in the following locations:

1. Explicit path.
2. The folder that contains the Aspose.Diagram.jar.

Use the <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/License" target="_blank" rel="nofollow noopener noreferrer">License.setLicense()</a> method to license the component. Often the easiest way to set a license is to put the license file in the same folder as Aspose.Diagram.jar and specify just the file name without path as shown in the following example:

#### Example 1 {#example-1}

In this example **Aspose.Diagram** will attempt to find the license file in the folder that contain the JARs of your application.

**Java**

```csharp
 com.aspose.diagram.License license = new com.aspose.diagram.License();

license.setLicense("Aspose.Diagram.Java.lic");
```

#### Example 2 {#example-2}

Initializes a license from a stream.

**Java**

```csharp
 com.aspose.diagram.License license = new com.aspose.diagram.License();

license.setLicense(new java.io.FileInputStream("Aspose.Diagram.Java.lic"));
```

### Validate the License {#validate-the-license}

It is possible to validate if the license has been set properly or not. The <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/License" target="_blank" rel="nofollow noopener noreferrer">License</a> class has the isLicensed field that will return true if license has been properly set.

**Java**

```csharp
 License license = new License();

license.setLicense("Aspose.Diagram.Java.lic");

if (License.isLicensed()) {

    System.out.println("License is Set!");

}
```

## Apply Metered License {#apply-metered-license}

Aspose.Diagram for Java API allows developers to apply metered license. It is a new licensing mechanism. The new licensing mechanism will be used along with existing licensing method. Those customers who want to be billed based on the usage of the API features can use the metered licensing. For more details, please refer to <a href="https://purchase.conholdate.com/faqs/licensing/metered" target="_blank">Metered Licensing FAQ</a> section.

A new class <a href="https://reference.aspose.com/diagram/java/com.aspose.diagram/Metered" target="_blank" rel="nofollow noopener noreferrer">Metered</a> has been added to apply metered key. This code example demonstrates how to set metered public and private keys:

```java
// For complete examples and data files, please go to https://github.com/aspose-diagram/Aspose.Diagram-for-Java
// Initialize a Metered license class object
Metered metered = new Metered();
// apply public and private keys
metered.setMeteredKey("your-public-key", "your-private-key");
```

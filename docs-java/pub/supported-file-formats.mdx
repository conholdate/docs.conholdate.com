Aspose.PUB for Java supports the following file formats.

<div className="docs-owner-markdown-table">

| **Format** | **Description** | **Load** | **Save** |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------- | --------- | --------- |
| PUB | Default file format for saving Microsoft Publisher electronic publication files. | Supported |  |
| <a href="https://wiki.fileformat.com/pdf/" target="_blank" rel="nofollow noopener noreferrer">PDF</a> | Saves the document as PDF (Adobe Portable Document) format. |  | Supported |
| <a href="https://docs.fileformat.com/image/tiff/" target="_blank" rel="nofollow noopener noreferrer">TIFF</a> | Saves the document as TIFF (Tagged Image File Format) format |  | Supported |
| <a href="https://docs.fileformat.com/image/png/" target="_blank" rel="nofollow noopener noreferrer">PNG</a> | Saves the document as PNG (Portable Network Graphics) format |  | Supported |
| <a href="https://docs.fileformat.com/image/jpeg/" target="_blank" rel="nofollow noopener noreferrer">JPEG</a> | Saves the document as JPEG (Joint Photographic Experts Group) format |  | Supported |
| <a href="https://docs.fileformat.com/image/gif/" target="_blank" rel="nofollow noopener noreferrer">GIF</a> | Saves the document as GiF (Graphics Interchange Format) |  | Supported |
| <a href="https://docs.fileformat.com/image/bmp/" target="_blank" rel="nofollow noopener noreferrer">BMP</a> | Saves the document as BMP (Bitmap) image format |  | Supported |
| <a href="https://docs.fileformat.com/word-processing/doc/" target="_blank" rel="nofollow noopener noreferrer">DOC/DOCX</a> | Format of MS WORD files |  | Supported |
| <a href="https://docs.fileformat.com/spreadsheet/xls/" target="_blank" rel="nofollow noopener noreferrer">XLS/XLXL</a> | Format of files made in MS Excel |  | Supported |
| <a href="https://docs.fileformat.com/spreadsheet/csv/" target="_blank" rel="nofollow noopener noreferrer">CSV</a> | Comma-separated values (CSV) text file format |  | Supported |
| <a href="https://docs.fileformat.com/presentation/pptx/" target="_blank" rel="nofollow noopener noreferrer">PPTX</a> | MS PowerPoint open XML presentation file format |  | Supported |
| <a href="https://docs.aspose.com/page/net/what-is-xps-file/" target="_blank" rel="nofollow noopener noreferrer">XPS</a> | XML Paper Specification file format |  | Supported |
| <a href="https://docs.fileformat.com/ebook/epub/" target="_blank" rel="nofollow noopener noreferrer">EPUB</a> | Saves the document as EPUB (Electronic Publication) format |  | Supported |
| <a href="https://docs.aspose.com/tex/net/what-is-tex/" target="_blank" rel="nofollow noopener noreferrer">TEX</a> | Saves the document as TEX file |  | Supported |
| <a href="https://docs.aspose.com/html/net/tutorial/" target="_blank" rel="nofollow noopener noreferrer">HTML/MHTML</a> | HyperText Markup Language format |  | Supported |
| <a href="https://docs.aspose.com/svg/net/what-is-an-svg-document/" target="_blank" rel="nofollow noopener noreferrer">SVG</a> | Scalable Vector Graphics format |  | Supported |
